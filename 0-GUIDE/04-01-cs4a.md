## Key Terms

**Optimization Problem**: A mathematical formulation that seeks to find the best solution from a set of feasible solutions by minimizing or maximizing an objective function, subject to constraints. In machine learning, optimization problems involve finding model parameters that minimize prediction error or maximize likelihood.

**Gradient Descent Algorithm**: An iterative optimization algorithm that finds the minimum of a function by repeatedly taking steps proportional to the negative gradient of the function at the current point. It's fundamental to training neural networks and many machine learning models.

**Objective Function**: A mathematical function that defines the goal of an optimization problem, typically representing the error or cost that needs to be minimized, or the utility that needs to be maximized in machine learning contexts.

**Loss Function**: A specific type of objective function that measures the difference between predicted and actual values, quantifying how well or poorly a model performs on training data.

**Convex Optimization**: A subfield of optimization dealing with convex functions and convex sets, where any local minimum is guaranteed to be a global minimum, making optimization more tractable and reliable.

**Learning Rate**: A hyperparameter that controls the step size in gradient descent algorithms, determining how quickly or slowly the algorithm converges to the optimal solution.

**Convergence**: The property of an iterative algorithm to approach a stable solution as the number of iterations increases, indicating that the optimization process has found an optimal or near-optimal solution.

## Theoretical Foundation of Machine Learning Optimization

Machine learning fundamentally relies on optimization theory to solve complex prediction problems by finding optimal model parameters that minimize prediction errors. Understanding optimization provides the mathematical foundation for all machine learning algorithms, from simple linear regression to complex deep neural networks.

The core principle involves formulating machine learning as an optimization problem where we seek to minimize a loss function that measures the discrepancy between model predictions and actual outcomes. This mathematical framework enables systematic approaches to learning from data and making accurate predictions on unseen examples.

def timing_decorator(func):
    """Decorator to measure execution time"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        execution_time = time.time() - start_time
        logger.info(f"{func.__name__} executed in {execution_time:.4f} seconds")
        return result
    return wrapper

class OptimizationProblem(ABC):
    """Abstract base class for optimization problems"""
    
    def __init__(self, dimension: int):
        self.dimension = dimension
        self.function_evaluations = 0
        self.gradient_evaluations = 0
        
    @abstractmethod
    def objective_function(self, x: np.ndarray) -> float:
        """Objective function to minimize"""
        pass
        
    @abstractmethod
    def gradient(self, x: np.ndarray) -> np.ndarray:
        """Gradient of the objective function"""
        pass
        
    def hessian(self, x: np.ndarray) -> np.ndarray:
        """Hessian matrix (optional, for second-order methods)"""
        # Numerical approximation by default
        return self._numerical_hessian(x)
    
    def _numerical_hessian(self, x: np.ndarray, eps: float = 1e-8) -> np.ndarray:
        """Numerical approximation of Hessian matrix"""
        n = len(x)
        hessian = np.zeros((n, n))
        
        for i in range(n):
            for j in range(n):
                x_pp = x.copy()
                x_pp[i] += eps
                x_pp[j] += eps
                
                x_pm = x.copy()
                x_pm[i] += eps
                x_pm[j] -= eps
                
                x_mp = x.copy()
                x_mp[i] -= eps
                x_mp[j] += eps
                
                x_mm = x.copy()
                x_mm[i] -= eps
                x_mm[j] -= eps
                
                hessian[i, j] = (self.objective_function(x_pp) - 
                               self.objective_function(x_pm) -
                               self.objective_function(x_mp) + 
                               self.objective_function(x_mm)) / (4 * eps**2)
        
        return hessian

class QuadraticOptimization(OptimizationProblem):
    """Quadratic optimization problem: f(x) = 0.5 * x^T * A * x + b^T * x + c"""
    
    def __init__(self, A: np.ndarray, b: np.ndarray, c: float = 0.0):
        super().__init__(A.shape[0])
        self.A = A
        self.b = b
        self.c = c
        
        # Ensure A is positive definite for convexity
        eigenvals = np.linalg.eigvals(A)
        if np.any(eigenvals <= 0):
            logger.warning("Matrix A is not positive definite. Adding regularization.")
            self.A = A + np.eye(A.shape[0]) * (abs(min(eigenvals)) + 0.1)
    
    def objective_function(self, x: np.ndarray) -> float:
        """Quadratic objective function"""
        self.function_evaluations += 1
        return 0.5 * x.T @ self.A @ x + self.b.T @ x + self.c
    
    def gradient(self, x: np.ndarray) -> np.ndarray:
        """Analytical gradient of quadratic function"""
        self.gradient_evaluations += 1
        return self.A @ x + self.b
    
    def hessian(self, x: np.ndarray) -> np.ndarray:
        """Analytical Hessian of quadratic function"""
        return self.A
    
    def analytical_solution(self) -> np.ndarray:
        """Analytical solution for quadratic optimization"""
        return -np.linalg.solve(self.A, self.b)

class RosenbrockOptimization(OptimizationProblem):
    """Rosenbrock function optimization: challenging non-convex problem"""
    
    def __init__(self, dimension: int, a: float = 1.0, b: float = 100.0):
        super().__init__(dimension)
        self.a = a
        self.b = b
    
    def objective_function(self, x: np.ndarray) -> float:
        """Rosenbrock function"""
        self.function_evaluations += 1
        return sum(self.b * (x[1:] - x[:-1]**2)**2 + (self.a - x[:-1])**2)
    
    def gradient(self, x: np.ndarray) -> np.ndarray:
        """Analytical gradient of Rosenbrock function"""
        self.gradient_evaluations += 1
        grad = np.zeros_like(x)
        
        # Interior points
        grad[1:-1] = (2 * self.b * (x[1:-1] - x[:-2]**2) - 
                     4 * self.b * x[1:-1] * (x[2:] - x[1:-1]**2) - 
                     2 * (self.a - x[1:-1]))
        
        # First point
        grad[0] = -4 * self.b * x[0] * (x[1] - x[0]**2) - 2 * (self.a - x[0])
        
        # Last point
        grad[-1] = 2 * self.b * (x[-1] - x[-2]**2)
        
        return grad

class MLRegressionOptimization(OptimizationProblem):
    """Machine Learning regression optimization with regularization"""
    
    def __init__(self, X: np.ndarray, y: np.ndarray, 
                 regularization: str = 'l2', lambda_reg: float = 0.01):
        super().__init__(X.shape[1])
        self.X = X
        self.y = y
        self.regularization = regularization
        self.lambda_reg = lambda_reg
        self.n_samples, self.n_features = X.shape
    
    def objective_function(self, theta: np.ndarray) -> float:
        """Mean squared error with regularization"""
        self.function_evaluations += 1
        
        # Prediction error
        predictions = self.X @ theta
        mse = np.mean((predictions - self.y)**2)
        
        # Regularization term
        if self.regularization == 'l2':
            reg_term = self.lambda_reg * np.sum(theta**2)
        elif self.regularization == 'l1':
            reg_term = self.lambda_reg * np.sum(np.abs(theta))
        else:
            reg_term = 0
        
        return mse + reg_term
    
    def gradient(self, theta: np.ndarray) -> np.ndarray:
        """Gradient of MSE with regularization"""
        self.gradient_evaluations += 1
        
        # Gradient of MSE
        predictions = self.X @ theta
        mse_grad = (2 / self.n_samples) * self.X.T @ (predictions - self.y)
        
        # Gradient of regularization
        if self.regularization == 'l2':
            reg_grad = 2 * self.lambda_reg * theta
        elif self.regularization == 'l1':
            reg_grad = self.lambda_reg * np.sign(theta)
        else:
            reg_grad = np.zeros_like(theta)
        
        return mse_grad + reg_grad
    
    def analytical_solution(self) -> np.ndarray:
        """Analytical solution for L2 regularized regression"""
        if self.regularization == 'l2':
            A = self.X.T @ self.X + self.lambda_reg * np.eye(self.n_features)
            b = self.X.T @ self.y
            return np.linalg.solve(A, b)
        else:
            raise ValueError("Analytical solution only available for L2 regularization")

class GradientDescentOptimizer:
    """Advanced gradient descent optimizer with multiple variants"""
    
    def __init__(self, learning_rate: float = 0.01, 
                 variant: str = 'standard',
                 momentum: float = 0.9,
                 beta1: float = 0.9,
                 beta2: float = 0.999,
                 epsilon: float = 1e-8):
        self.learning_rate = learning_rate
        self.variant = variant
        self.momentum = momentum
        self.beta1 = beta1
        self.beta2 = beta2
        self.epsilon = epsilon
        
        # State variables for advanced variants
        self.velocity = None
        self.m = None  # First moment estimate (Adam)
        self.v = None  # Second moment estimate (Adam)
        self.t = 0     # Time step
    
    @timing_decorator
    def optimize(self, problem: OptimizationProblem, 
                initial_point: np.ndarray,
                max_iterations: int = 1000,
                tolerance: float = 1e-6) -> OptimizationResult:
        """Optimize using gradient descent variants"""
        
        x = initial_point.copy()
        convergence_history = []
        
        # Initialize state variables
        self._initialize_state(x)
        
        start_time = time.time()
        
        for iteration in range(max_iterations):
            # Compute current function value and gradient
            current_value = problem.objective_function(x)
            gradient = problem.gradient(x)
            
            convergence_history.append(current_value)
            
            # Check convergence
            gradient_norm = np.linalg.norm(gradient)
            if gradient_norm < tolerance:
                logger.info(f"Converged after {iteration} iterations")
                break
            
            # Update parameters based on variant
            x = self._update_parameters(x, gradient)
            
            if iteration % 100 == 0:
                logger.info(f"Iteration {iteration}: f(x) = {current_value:.6f}, "
                          f"||grad|| = {gradient_norm:.6f}")
        
        execution_time = time.time() - start_time
        
        return OptimizationResult(
            optimal_parameters=x,
            optimal_value=problem.objective_function(x),
            iterations=iteration + 1,
            convergence_history=convergence_history,
            execution_time=execution_time,
            gradient_norm=np.linalg.norm(problem.gradient(x)),
            success=gradient_norm < tolerance
        )
    
    def _initialize_state(self, x: np.ndarray):
        """Initialize state variables for advanced optimizers"""
        if self.variant in ['momentum', 'nesterov']:
            self.velocity = np.zeros_like(x)
        elif self.variant == 'adam':
            self.m = np.zeros_like(x)
            self.v = np.zeros_like(x)
            self.t = 0
    
    def _update_parameters(self, x: np.ndarray, gradient: np.ndarray) -> np.ndarray:
        """Update parameters based on optimizer variant"""
        
        if self.variant == 'standard':
            return x - self.learning_rate * gradient
        
        elif self.variant == 'momentum':
            self.velocity = self.momentum * self.velocity - self.learning_rate * gradient
            return x + self.velocity
        
        elif self.variant == 'nesterov':
            # Nesterov Accelerated Gradient
            self.velocity = self.momentum * self.velocity - self.learning_rate * gradient
            return x + self.momentum * self.velocity - self.learning_rate * gradient
        
        elif self.variant == 'adam':
            self.t += 1
            
            # Update biased first moment estimate
            self.m = self.beta1 * self.m + (1 - self.beta1) * gradient
            
            # Update biased second raw moment estimate
            self.v = self.beta2 * self.v + (1 - self.beta2) * gradient**2
            
            # Compute bias-corrected estimates
            m_hat = self.m / (1 - self.beta1**self.t)
            v_hat = self.v / (1 - self.beta2**self.t)
            
            # Update parameters
            return x - self.learning_rate * m_hat / (np.sqrt(v_hat) + self.epsilon)
        
        else:
            raise ValueError(f"Unknown optimizer variant: {self.variant}")

class OptimizationComparison:
    """Compare different optimization methods"""
    
    def __init__(self):
        self.results = {}
    
    def compare_methods(self, problem: OptimizationProblem, 
                       initial_point: np.ndarray) -> Dict:
        """Compare multiple optimization methods"""
        
        methods = {
            'Gradient Descent': self._gradient_descent_comparison,
            'SciPy BFGS': self._scipy_bfgs,
            'SciPy Nelder-Mead': self._scipy_nelder_mead,
            'SciPy L-BFGS-B': self._scipy_lbfgs,
            'Differential Evolution': self._differential_evolution
        }
        
        comparison_results = {}
        
        for method_name, method_func in methods.items():
            try:
                logger.info(f"Running {method_name}")
                result = method_func(problem, initial_point)
                comparison_results[method_name] = result
            except Exception as e:
                logger.error(f"Error in {method_name}: {e}")
                comparison_results[method_name] = None
        
        return comparison_results
    
    def _gradient_descent_comparison(self, problem: OptimizationProblem, 
                                   initial_point: np.ndarray) -> Dict:
        """Compare different gradient descent variants"""
        
        variants = ['standard', 'momentum', 'adam']
        gd_results = {}
        
        for variant in variants:
            optimizer = GradientDescentOptimizer(
                learning_rate=0.01 if variant != 'adam' else 0.001,
                variant=variant
            )
            result = optimizer.optimize(problem, initial_point)
            gd_results[variant] = result
        
        return gd_results
    
    def _scipy_bfgs(self, problem: OptimizationProblem, 
                   initial_point: np.ndarray) -> OptimizationResult:
        """SciPy BFGS optimization"""
        start_time = time.time()
        
        result = minimize(
            fun=problem.objective_function,
            x0=initial_point,
            method='BFGS',
            jac=problem.gradient,
            options={'disp': False, 'maxiter': 1000}
        )
        
        execution_time = time.time() - start_time
        
        return OptimizationResult(
            optimal_parameters=result.x,
            optimal_value=result.fun,
            iterations=result.nit,
            convergence_history=[],
            execution_time=execution_time,
            gradient_norm=np.linalg.norm(problem.gradient(result.x)),
            success=result.success
        )
    
    def _scipy_nelder_mead(self, problem: OptimizationProblem, 
                          initial_point: np.ndarray) -> OptimizationResult:
        """SciPy Nelder-Mead optimization (derivative-free)"""
        start_time = time.time()
        
        result = minimize(
            fun=problem.objective_function,
            x0=initial_point,
            method='Nelder-Mead',
            options={'disp': False, 'maxiter': 1000}
        )
        
        execution_time = time.time() - start_time
        
        return OptimizationResult(
            optimal_parameters=result.x,
            optimal_value=result.fun,
            iterations=result.nit,
            convergence_history=[],
            execution_time=execution_time,
            gradient_norm=np.linalg.norm(problem.gradient(result.x)),
            success=result.success
        )
    
    def _scipy_lbfgs(self, problem: OptimizationProblem, 
                    initial_point: np.ndarray) -> OptimizationResult:
        """SciPy L-BFGS-B optimization"""
        start_time = time.time()
        
        result = minimize(
            fun=problem.objective_function,
            x0=initial_point,
            method='L-BFGS-B',
            jac=problem.gradient,
            options={'disp': False, 'maxiter': 1000}
        )
        
        execution_time = time.time() - start_time
        
        return OptimizationResult(
            optimal_parameters=result.x,
            optimal_value=result.fun,
            iterations=result.nit,
            convergence_history=[],
            execution_time=execution_time,
            gradient_norm=np.linalg.norm(problem.gradient(result.x)),
            success=result.success
        )
    
    def _differential_evolution(self, problem: OptimizationProblem, 
                              initial_point: np.ndarray) -> OptimizationResult:
        """Differential Evolution (global optimization)"""
        start_time = time.time()
        
        # Define bounds for differential evolution
        bounds = [(-10, 10) for _ in range(problem.dimension)]
        
        result = differential_evolution(
            func=problem.objective_function,
            bounds=bounds,
            maxiter=1000,
            disp=False
        )
        
        execution_time = time.time() - start_time
        
        return OptimizationResult(
            optimal_parameters=result.x,
            optimal_value=result.fun,
            iterations=result.nit,
            convergence_history=[],
            execution_time=execution_time,
            gradient_norm=np.linalg.norm(problem.gradient(result.x)),
            success=result.success
        )

## Advanced Applications in Machine Learning

The optimization framework directly applies to machine learning problems where we seek to minimize prediction errors. Consider a linear regression model where we want to find parameters θ that minimize the mean squared error:

**Loss Function**: L(θ) = (1/2n) Σ(h_θ(x_i) - y_i)²

**Gradient**: ∇L(θ) = (1/n) X^T(Xθ - y)

**Update Rule**: θ_{t+1} = θ_t - α∇L(θ_t)

This mathematical foundation extends to all machine learning algorithms, from logistic regression and neural networks to support vector machines and ensemble methods.
