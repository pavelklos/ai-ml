# 10. Time Series: Predicting the Future

## Key Terms

**Time Series**: A sequence of data points collected at consecutive time intervals, characterized by temporal dependencies where past observations influence future values, making traditional machine learning assumptions of independent observations invalid.

**Stationarity**: A statistical property where time series mean, variance, and autocorrelation structure remain constant over time, essential for many forecasting models as non-stationary data can lead to spurious predictions.

**Seasonality**: Regular, predictable patterns that repeat over fixed periods (daily, weekly, monthly, yearly), representing cyclical behavior in time series data that must be identified and modeled separately.

**Trend**: The long-term directional movement in time series data, representing underlying growth or decline patterns that persist beyond short-term fluctuations and seasonal variations.

**Autocorrelation**: The correlation between time series values and their lagged versions, measuring how past values influence current observations and forming the foundation for autoregressive models.

**Feature Engineering for Time Series**: The process of creating predictive variables from temporal data including lag features, rolling statistics, seasonal decompositions, and time-based features like day-of-week or month.

**Walk-Forward Validation**: A time series-specific cross-validation technique that respects temporal order by training on past data and testing on future data, preventing data leakage that would occur with random splits.

**ARIMA (AutoRegressive Integrated Moving Average)**: A classical statistical model that combines autoregression, differencing, and moving averages to model time series data with trends and seasonality.

**Prophet**: Facebook's open-source forecasting tool designed for business time series with strong seasonal patterns and multiple seasons, handling missing data and outliers automatically.

## Theoretical Foundation of Time Series Forecasting

Time series forecasting presents unique challenges that distinguish it from traditional machine learning problems. The fundamental assumption of independent and identically distributed observations is violated, as temporal dependencies create autocorrelation structures that must be explicitly modeled.

The decomposition of time series into trend, seasonal, and residual components provides the foundation for most forecasting approaches. Classical methods like ARIMA model these components through mathematical formulations, while modern machine learning approaches use feature engineering to capture temporal patterns.

Stationarity requirements in classical models necessitate data transformations like differencing or logarithmic scaling to achieve constant statistical properties over time. However, modern approaches like neural networks can handle non-stationary data directly through appropriate architectures.

class TimeSeriesFeatureEngineering:
    """Advanced feature engineering for time series data"""
    
    def __init__(self):
        self.feature_names_ = []
        
    def create_time_features(self, df: pd.DataFrame, date_column: str) -> pd.DataFrame:
        """Create comprehensive time-based features"""
        
        df = df.copy()
        df[date_column] = pd.to_datetime(df[date_column])
        df = df.set_index(date_column)
        
        # Basic time features
        df['year'] = df.index.year
        df['month'] = df.index.month
        df['day'] = df.index.day
        df['dayofweek'] = df.index.dayofweek
        df['dayofyear'] = df.index.dayofyear
        df['week'] = df.index.isocalendar().week
        df['quarter'] = df.index.quarter
        
        # Cyclical encoding for better ML performance
        df['month_sin'] = np.sin(2 * np.pi * df['month'] / 12)
        df['month_cos'] = np.cos(2 * np.pi * df['month'] / 12)
        df['day_sin'] = np.sin(2 * np.pi * df['day'] / 31)
        df['day_cos'] = np.cos(2 * np.pi * df['day'] / 31)
        df['dayofweek_sin'] = np.sin(2 * np.pi * df['dayofweek'] / 7)
        df['dayofweek_cos'] = np.cos(2 * np.pi * df['dayofweek'] / 7)
        
        # Binary indicators
        df['is_weekend'] = (df['dayofweek'] >= 5).astype(int)
        df['is_month_start'] = df.index.is_month_start.astype(int)
        df['is_month_end'] = df.index.is_month_end.astype(int)
        df['is_quarter_start'] = df.index.is_quarter_start.astype(int)
        df['is_quarter_end'] = df.index.is_quarter_end.astype(int)
        
        return df
    
    def create_lag_features(self, df: pd.DataFrame, target_column: str, 
                           lags: List[int]) -> pd.DataFrame:
        """Create lag features for target variable"""
        
        df = df.copy()
        
        for lag in lags:
            df[f'{target_column}_lag_{lag}'] = df[target_column].shift(lag)
            
        return df
    
    def create_rolling_features(self, df: pd.DataFrame, target_column: str,
                               windows: List[int]) -> pd.DataFrame:
        """Create rolling window statistics"""
        
        df = df.copy()
        
        for window in windows:
            # Rolling statistics
            df[f'{target_column}_rolling_mean_{window}'] = (
                df[target_column].rolling(window=window).mean()
            )
            df[f'{target_column}_rolling_std_{window}'] = (
                df[target_column].rolling(window=window).std()
            )
            df[f'{target_column}_rolling_min_{window}'] = (
                df[target_column].rolling(window=window).min()
            )
            df[f'{target_column}_rolling_max_{window}'] = (
                df[target_column].rolling(window=window).max()
            )
            df[f'{target_column}_rolling_median_{window}'] = (
                df[target_column].rolling(window=window).median()
            )
            
            # Exponential weighted features
            df[f'{target_column}_ewm_{window}'] = (
                df[target_column].ewm(span=window).mean()
            )
            
        return df
    
    def create_seasonal_features(self, df: pd.DataFrame, target_column: str,
                                periods: List[int]) -> pd.DataFrame:
        """Create seasonal decomposition features"""
        
        df = df.copy()
        
        for period in periods:
            # Seasonal decomposition
            try:
                decomposition = seasonal_decompose(
                    df[target_column].dropna(), period=period, extrapolate_trend='freq'
                )
                
                df[f'{target_column}_trend_{period}'] = decomposition.trend
                df[f'{target_column}_seasonal_{period}'] = decomposition.seasonal
                df[f'{target_column}_residual_{period}'] = decomposition.resid
                
            except Exception as e:
                logger.warning(f"Failed to create seasonal features for period {period}: {e}")
                
        return df

class TimeSeriesValidator:
    """Time series specific cross-validation"""
    
    def __init__(self, n_splits: int = 5, test_size: Optional[int] = None):
        self.n_splits = n_splits
        self.test_size = test_size
        
    def walk_forward_validation(self, df: pd.DataFrame, target_column: str,
                               feature_columns: List[str], model,
                               min_train_size: int = 100) -> Dict[str, Any]:
        """Perform walk-forward validation for time series"""
        
        # Ensure data is sorted by index (time)
        df = df.sort_index()
        
        # Remove rows with NaN values
        df_clean = df.dropna()
        
        # Initialize results
        fold_results = []
        predictions = []
        actuals = []
        
        # Calculate fold sizes
        total_size = len(df_clean)
        if self.test_size is None:
            test_size = max(1, total_size // (self.n_splits + 1))
        else:
            test_size = self.test_size
            
        # Perform walk-forward validation
        for fold in range(self.n_splits):
            # Calculate train and test indices
            test_start = min_train_size + fold * test_size
            test_end = test_start + test_size
            
            if test_end > total_size:
                break
                
            train_data = df_clean.iloc[:test_start]
            test_data = df_clean.iloc[test_start:test_end]
            
            # Prepare features and target
            X_train = train_data[feature_columns]
            y_train = train_data[target_column]
            X_test = test_data[feature_columns]
            y_test = test_data[target_column]
            
            # Train model
            model_clone = self._clone_model(model)
            model_clone.fit(X_train, y_train)
            
            # Make predictions
            y_pred = model_clone.predict(X_test)
            
            # Calculate metrics
            mse = mean_squared_error(y_test, y_pred)
            mae = mean_absolute_error(y_test, y_pred)
            rmse = np.sqrt(mse)
            
            # Store results
            fold_results.append({
                'fold': fold + 1,
                'train_size': len(X_train),
                'test_size': len(X_test),
                'mse': mse,
                'mae': mae,
                'rmse': rmse,
                'train_start': train_data.index[0],
                'train_end': train_data.index[-1],
                'test_start': test_data.index[0],
                'test_end': test_data.index[-1]
            })
            
            predictions.extend(y_pred)
            actuals.extend(y_test)
            
        return {
            'fold_results': fold_results,
            'overall_mse': mean_squared_error(actuals, predictions),
            'overall_mae': mean_absolute_error(actuals, predictions),
            'overall_rmse': np.sqrt(mean_squared_error(actuals, predictions)),
            'predictions': predictions,
            'actuals': actuals
        }
    
    def _clone_model(self, model):
        """Clone model for cross-validation"""
        if hasattr(model, 'get_params'):
            # Sklearn-style model
            return type(model)(**model.get_params())
        else:
            # Create new instance
            return type(model)()

class TimeSeriesForecaster:
    """Comprehensive time series forecasting system"""
    
    def __init__(self):
        self.models_ = {}
        self.feature_engineering_ = TimeSeriesFeatureEngineering()
        self.validator_ = TimeSeriesValidator()
        self.results_ = {}
        
    def analyze_time_series(self, df: pd.DataFrame, target_column: str,
                           date_column: str) -> Dict[str, Any]:
        """Comprehensive time series analysis"""
        
        # Prepare data
        df = df.copy()
        df[date_column] = pd.to_datetime(df[date_column])
        df = df.set_index(date_column).sort_index()
        
        analysis_results = {}
        
        # Basic statistics
        analysis_results['basic_stats'] = {
            'start_date': df.index.min(),
            'end_date': df.index.max(),
            'frequency': self._infer_frequency(df),
            'missing_values': df[target_column].isna().sum(),
            'total_observations': len(df),
            'mean': df[target_column].mean(),
            'std': df[target_column].std(),
            'min': df[target_column].min(),
            'max': df[target_column].max()
        }
        
        # Stationarity tests
        analysis_results['stationarity'] = self._test_stationarity(df[target_column])
        
        # Seasonal decomposition
        try:
            analysis_results['decomposition'] = self._seasonal_decomposition(df[target_column])
        except Exception as e:
            logger.warning(f"Seasonal decomposition failed: {e}")
            analysis_results['decomposition'] = None
            
        # Autocorrelation analysis
        analysis_results['autocorrelation'] = self._analyze_autocorrelation(df[target_column])
        
        return analysis_results
    
    def prepare_features(self, df: pd.DataFrame, target_column: str,
                        date_column: str) -> pd.DataFrame:
        """Comprehensive feature preparation for time series"""
        
        # Create time features
        df_features = self.feature_engineering_.create_time_features(df, date_column)
        
        # Create lag features
        lags = [1, 2, 3, 7, 14, 30]  # Common lag periods
        df_features = self.feature_engineering_.create_lag_features(
            df_features, target_column, lags
        )
        
        # Create rolling features
        windows = [7, 14, 30]  # Common window sizes
        df_features = self.feature_engineering_.create_rolling_features(
            df_features, target_column, windows
        )
        
        # Create seasonal features
        periods = [7, 30, 365]  # Weekly, monthly, yearly patterns
        df_features = self.feature_engineering_.create_seasonal_features(
            df_features, target_column, periods
        )
        
        return df_features
    
    def fit_multiple_models(self, df: pd.DataFrame, target_column: str,
                           feature_columns: List[str]) -> Dict[str, Any]:
        """Train multiple forecasting models"""
        
        models = {
            'linear_regression': LinearRegression(),
            'ridge_regression': Ridge(alpha=1.0),
            'random_forest': RandomForestRegressor(n_estimators=100, random_state=42),
            'gradient_boosting': GradientBoostingRegressor(n_estimators=100, random_state=42),
            'xgboost': xgb.XGBRegressor(n_estimators=100, random_state=42)
        }
        
        results = {}
        
        for model_name, model in models.items():
            logger.info(f"Training {model_name}")
            
            try:
                # Perform walk-forward validation
                cv_results = self.validator_.walk_forward_validation(
                    df, target_column, feature_columns, model
                )
                
                # Train on full dataset for final model
                df_clean = df.dropna()
                X = df_clean[feature_columns]
                y = df_clean[target_column]
                
                model.fit(X, y)
                
                results[model_name] = {
                    'model': model,
                    'cv_results': cv_results,
                    'feature_importance': self._get_feature_importance(model, feature_columns)
                }
                
                self.models_[model_name] = model
                
            except Exception as e:
                logger.error(f"Error training {model_name}: {e}")
                continue
        
        self.results_ = results
        return results
    
    def forecast_prophet(self, df: pd.DataFrame, target_column: str,
                        date_column: str, periods: int = 30) -> Dict[str, Any]:
        """Create forecast using Facebook Prophet"""
        
        # Prepare data for Prophet
        prophet_df = df[[date_column, target_column]].copy()
        prophet_df.columns = ['ds', 'y']
        prophet_df = prophet_df.dropna()
        
        # Initialize and fit Prophet model
        model = Prophet(
            yearly_seasonality=True,
            weekly_seasonality=True,
            daily_seasonality=False,
            changepoint_prior_scale=0.05
        )
        
        model.fit(prophet_df)
        
        # Create future dataframe
        future = model.make_future_dataframe(periods=periods)
        forecast = model.predict(future)
        
        # Calculate performance on historical data
        historical_forecast = forecast[forecast['ds'].isin(prophet_df['ds'])]
        historical_actual = prophet_df['y'].values
        historical_predicted = historical_forecast['yhat'].values
        
        mse = mean_squared_error(historical_actual, historical_predicted)
        mae = mean_absolute_error(historical_actual, historical_predicted)
        rmse = np.sqrt(mse)
        
        return {
            'model': model,
            'forecast': forecast,
            'future_forecast': forecast.tail(periods),
            'performance': {
                'mse': mse,
                'mae': mae,
                'rmse': rmse
            }
        }
    
    def forecast_future(self, model_name: str, df: pd.DataFrame,
                       feature_columns: List[str], periods: int = 30) -> np.ndarray:
        """Generate future forecasts using trained model"""
        
        if model_name not in self.models_:
            raise ValueError(f"Model {model_name} not found")
            
        model = self.models_[model_name]
        df_clean = df.dropna()
        
        # Recursive forecasting for multi-step ahead prediction
        forecasts = []
        current_data = df_clean.copy()
        
        for step in range(periods):
            # Get latest features
            latest_features = current_data[feature_columns].iloc[-1:].values
            
            # Make prediction
            prediction = model.predict(latest_features)[0]
            forecasts.append(prediction)
            
            # Update data for next prediction (simplified approach)
            # In practice, you'd need to update all lag and rolling features
            next_index = current_data.index[-1] + pd.Timedelta(days=1)
            new_row = current_data.iloc[-1].copy()
            new_row.name = next_index
            new_row[current_data.columns[0]] = prediction  # Assume first column is target
            
            current_data = pd.concat([current_data, new_row.to_frame().T])
            
        return np.array(forecasts)
    
    def _infer_frequency(self, df: pd.DataFrame) -> str:
        """Infer time series frequency"""
        try:
            freq = pd.infer_freq(df.index)
            return freq if freq else 'Unknown'
        except:
            return 'Unknown'
    
    def _test_stationarity(self, series: pd.Series) -> Dict[str, Any]:
        """Test time series stationarity"""
        
        series_clean = series.dropna()
        
        # Augmented Dickey-Fuller test
        adf_result = adfuller(series_clean)
        
        # KPSS test
        try:
            kpss_result = kpss(series_clean)
            kpss_pvalue = kpss_result[1]
        except:
            kpss_pvalue = None
        
        return {
            'adf_statistic': adf_result[0],
            'adf_pvalue': adf_result[1],
            'adf_critical_values': adf_result[4],
            'is_stationary_adf': adf_result[1] < 0.05,
            'kpss_pvalue': kpss_pvalue,
            'is_stationary_kpss': kpss_pvalue > 0.05 if kpss_pvalue else None
        }
    
    def _seasonal_decomposition(self, series: pd.Series) -> Dict[str, Any]:
        """Perform seasonal decomposition"""
        
        series_clean = series.dropna()
        
        # Try different periods
        for period in [7, 30, 365]:
            if len(series_clean) >= 2 * period:
                try:
                    decomposition = seasonal_decompose(
                        series_clean, period=period, extrapolate_trend='freq'
                    )
                    
                    return {
                        'period': period,
                        'trend_strength': np.var(decomposition.trend.dropna()) / np.var(series_clean),
                        'seasonal_strength': np.var(decomposition.seasonal.dropna()) / np.var(series_clean),
                        'residual_strength': np.var(decomposition.resid.dropna()) / np.var(series_clean)
                    }
                except:
                    continue
                    
        return {'period': None, 'trend_strength': None, 'seasonal_strength': None}
    
    def _analyze_autocorrelation(self, series: pd.Series, max_lags: int = 40) -> Dict[str, Any]:
        """Analyze autocorrelation structure"""
        
        series_clean = series.dropna()
        autocorr_values = [series_clean.autocorr(lag=lag) for lag in range(1, min(max_lags, len(series_clean)))]
        
        # Find significant lags (simplified approach)
        significant_lags = [i+1 for i, corr in enumerate(autocorr_values) if abs(corr) > 0.1]
        
        return {
            'autocorrelations': autocorr_values[:10],  # First 10 lags
            'significant_lags': significant_lags[:5],  # Top 5 significant lags
            'max_autocorr': max(autocorr_values) if autocorr_values else 0
        }
    
    def _get_feature_importance(self, model, feature_columns: List[str]) -> Dict[str, float]:
        """Extract feature importance from model"""
        
        if hasattr(model, 'feature_importances_'):
            return dict(zip(feature_columns, model.feature_importances_))
        elif hasattr(model, 'coef_'):
            return dict(zip(feature_columns, np.abs(model.coef_)))
        else:
            return {}

## Conclusion

This comprehensive exploration of time series forecasting demonstrates the sophisticated techniques required to predict future values while accounting for temporal dependencies, seasonality, and trend patterns that distinguish time series from traditional machine learning problems.

**Advanced Feature Engineering** transforms raw temporal data into predictive variables through lag features, rolling statistics, seasonal decompositions, and cyclical encodings, creating rich feature sets that capture both short-term and long-term patterns essential for accurate forecasting.

**Walk-Forward Validation** ensures realistic performance estimation by respecting temporal order during model evaluation, preventing data leakage that would occur with traditional cross-validation methods and providing honest assessments of forecasting accuracy.

**Multi-Model Approaches** combining classical statistical methods like Prophet with modern machine learning algorithms enable comprehensive forecasting strategies that leverage the strengths of different methodological approaches for robust prediction systems.

**Stationarity Analysis and Decomposition** provide fundamental insights into time series structure, enabling appropriate model selection and preprocessing decisions that significantly impact forecasting performance and model reliability.

Time series forecasting represents a critical intersection of statistical modeling and machine learning, where understanding temporal patterns, implementing proper validation techniques, and selecting appropriate algorithms directly determine the success of predictive systems in real-world applications ranging from business planning to operational optimization.
