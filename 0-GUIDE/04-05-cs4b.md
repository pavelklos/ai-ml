## Key Terms

**Data Pipeline**: A systematic sequence of data processing operations that transforms raw input data through multiple stages into a format suitable for machine learning models, ensuring reproducibility, maintainability, and automated data flow from source to prediction.

**Feature Engineering**: The process of creating, transforming, and selecting input variables (features) from raw data to improve machine learning model performance, involving domain knowledge application, mathematical transformations, and data enrichment techniques.

**Transformer**: An object in scikit-learn that implements the fit-transform pattern, learning parameters from training data during the fit phase and applying transformations during the transform phase, enabling consistent data preprocessing across training and inference.

**Fit Method**: The training phase of a transformer where it learns necessary parameters from the input data, such as means and standard deviations for scaling, unique categories for encoding, or principal components for dimensionality reduction.

**Transform Method**: The application phase where a fitted transformer applies learned transformations to new data, ensuring consistency between training and inference data preprocessing without data leakage.

**Column Transformer**: A scikit-learn utility that applies different transformations to different subsets of features simultaneously, enabling heterogeneous data processing where numerical and categorical features require distinct preprocessing approaches.

**Feature Store**: A centralized repository for storing, managing, and serving machine learning features, providing consistent feature definitions, versioning, and monitoring across different models and teams.

**Pipeline Composition**: The practice of combining multiple data processing steps into a single, cohesive workflow that can be executed atomically, ensuring reproducibility and simplifying deployment.

## Theoretical Foundation of Data Pipelines and Feature Engineering

Data pipelines represent the backbone of modern machine learning systems, providing structured workflows that transform raw data into model-ready features through reproducible and maintainable processes. The pipeline paradigm encapsulates the entire data preprocessing workflow, ensuring that transformations applied during training are consistently replicated during inference.

Feature engineering constitutes both an art and science, requiring domain expertise combined with statistical knowledge to create meaningful representations that enhance model performance. The process involves understanding data distributions, identifying patterns, creating interactions, and applying mathematical transformations that expose hidden relationships within the data.

def performance_monitor(func):
    """Decorator to monitor function performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedFeatureEngineer(BaseEstimator, TransformerMixin):
    """Advanced feature engineering transformer with multiple techniques"""
    
    def __init__(self, numerical_features: List[str] = None,

    def fit(self, X: pd.DataFrame, y: pd.Series = None):

        # Calculate statistics for transformations
        self._calculate_statistics(X, y)
        
        # Prepare feature names
        self._prepare_feature_names(X)

    def transform(self, X: pd.DataFrame) -> pd.DataFrame:

        X_transformed = X.copy()
        
        # Apply various feature engineering techniques with warning suppression
        with warnings.catch_warnings():
            warnings.simplefilter("ignore")

            X_transformed = self._engineer_categorical_features(X_transformed)
            X_transformed = self._engineer_date_features(X_transformed)
            X_transformed = self._engineer_text_features(X_transformed)
            X_transformed = self._engineer_interaction_features(X_transformed)
            X_transformed = self._engineer_polynomial_features(X_transformed)

    def _auto_detect_feature_types(self, X: pd.DataFrame):
        """Automatically detect feature types"""
        
        for col in X.columns:
            if pd.api.types.is_numeric_dtype(X[col]):
                if X[col].nunique() < 10 and X[col].dtype in ['int64', 'int32']:
                    self.categorical_features.append(col)
                else:
                    self.numerical_features.append(col)
            elif pd.api.types.is_datetime64_any_dtype(X[col]):
                self.date_features.append(col)
            elif X[col].dtype == 'object':
                # Check if it's text or categorical
                avg_length = X[col].astype(str).str.len().mean()
                if avg_length > 50:  # Assume text if average length > 50
                    self.text_features.append(col)
                else:
                    self.categorical_features.append(col)
    
    def _calculate_statistics(self, X: pd.DataFrame, y: pd.Series = None):
        """Calculate statistics needed for transformations"""
        
        # Numerical statistics
        for col in self.numerical_features:
            if col in X.columns:
                self.statistics_[col] = {
                    'mean': X[col].mean(),
                    'std': X[col].std(),
                    'median': X[col].median(),
                    'q25': X[col].quantile(0.25),
                    'q75': X[col].quantile(0.75),
                    'skewness': stats.skew(X[col].dropna()) if len(X[col].dropna()) > 0 else 0,
                    'kurtosis': stats.kurtosis(X[col].dropna()) if len(X[col].dropna()) > 0 else 0
                }
        
        # Categorical statistics
        for col in self.categorical_features:
            if col in X.columns:
                self.statistics_[col] = {
                    'value_counts': X[col].value_counts().to_dict(),
                    'nunique': X[col].nunique(),
                    'mode': X[col].mode().iloc[0] if not X[col].mode().empty else None
                }
        
        # Target correlation (if available)
        if y is not None:
            self.statistics_['target_correlations'] = {}
            for col in self.numerical_features:
                if col in X.columns:
                    try:
                        corr = np.corrcoef(X[col].fillna(X[col].median()), y)[0, 1]
                        self.statistics_['target_correlations'][col] = corr if not np.isnan(corr) else 0
                    except:
                        self.statistics_['target_correlations'][col] = 0
    
    def _prepare_feature_names(self, X: pd.DataFrame):

        feature_names = list(X.columns)

                    f'{col}_reciprocal', f'{col}_zscore', f'{col}_robust_scale'
                ])
        
        for col in self.categorical_features:
            if col in X.columns:
                feature_names.extend([
                    f'{col}_frequency', f'{col}_target_encoded'
                ])
        
        for col in self.date_features:
            if col in X.columns:
                feature_names.extend([
                    f'{col}_year', f'{col}_month', f'{col}_day', f'{col}_dayofweek',
                    f'{col}_quarter', f'{col}_is_weekend', f'{col}_is_month_start',
                    f'{col}_days_since_epoch'
                ])
        
        if self.interaction_features and len(self.numerical_features) >= 2:
            for i, col1 in enumerate(self.numerical_features):
                for col2 in self.numerical_features[i+1:]:
                    feature_names.extend([
                        f'{col1}_{col2}_product', f'{col1}_{col2}_ratio',
                        f'{col1}_{col2}_difference', f'{col1}_{col2}_sum'
                    ])
        
        self.feature_names_out_ = feature_names
    
    def _engineer_numerical_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer numerical features"""
        
        new_features = {}
        
        for col in self.numerical_features:
            if col in X.columns:
                # Fill NaN values for calculations
                col_data = X[col].fillna(X[col].median())
                
                # Mathematical transformations
                new_features[f'{col}_squared'] = col_data ** 2
                new_features[f'{col}_cubed'] = col_data ** 3
                new_features[f'{col}_sqrt'] = np.sqrt(np.abs(col_data))
                new_features[f'{col}_log'] = np.log1p(np.abs(col_data))
                new_features[f'{col}_reciprocal'] = 1 / (col_data + 1e-8)
                
                # Statistical transformations
                stats = self.statistics_.get(col, {})
                if 'mean' in stats and 'std' in stats and stats['std'] > 0:
                    new_features[f'{col}_zscore'] = (col_data - stats['mean']) / stats['std']
                
                if 'median' in stats and 'q25' in stats and 'q75' in stats:
                    iqr = stats['q75'] - stats['q25']
                    if iqr > 0:
                        new_features[f'{col}_robust_scale'] = (col_data - stats['median']) / iqr
        
        # Use concat to add all new features at once
        if new_features:
            X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def _engineer_categorical_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer categorical features"""
        
        new_features = {}
        
        for col in self.categorical_features:
            if col in X.columns:
                # Frequency encoding
                value_counts = self.statistics_.get(col, {}).get('value_counts', {})
                new_features[f'{col}_frequency'] = X[col].map(value_counts).fillna(0)
                
                # Target encoding (simplified version)
                new_features[f'{col}_target_encoded'] = X[col].map(value_counts).fillna(0)
        
        # Use concat to add all new features at once
        if new_features:
            X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def _engineer_date_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer date/time features"""
        
        new_features = {}
        
        for col in self.date_features:
            if col in X.columns:
                # Convert to datetime if not already
                date_col = pd.to_datetime(X[col], errors='coerce')
                
                # Extract date components
                new_features[f'{col}_year'] = date_col.dt.year
                new_features[f'{col}_month'] = date_col.dt.month
                new_features[f'{col}_day'] = date_col.dt.day
                new_features[f'{col}_dayofweek'] = date_col.dt.dayofweek
                new_features[f'{col}_quarter'] = date_col.dt.quarter
                
                # Boolean features
                new_features[f'{col}_is_weekend'] = (date_col.dt.dayofweek >= 5).astype(int)
                new_features[f'{col}_is_month_start'] = date_col.dt.is_month_start.astype(int)
                
                # Cyclical features
                new_features[f'{col}_month_sin'] = np.sin(2 * np.pi * date_col.dt.month / 12)
                new_features[f'{col}_month_cos'] = np.cos(2 * np.pi * date_col.dt.month / 12)
                new_features[f'{col}_day_sin'] = np.sin(2 * np.pi * date_col.dt.day / 31)
                new_features[f'{col}_day_cos'] = np.cos(2 * np.pi * date_col.dt.day / 31)
                
                # Time since epoch
                epoch = pd.to_datetime('1970-01-01')
                new_features[f'{col}_days_since_epoch'] = (date_col - epoch).dt.days
        
        # Use concat to add all new features at once
        if new_features:
            X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def _engineer_text_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer text features"""
        
        new_features = {}
        
        for col in self.text_features:
            if col in X.columns:
                text_col = X[col].astype(str)
                
                # Text statistics
                new_features[f'{col}_length'] = text_col.str.len()
                new_features[f'{col}_word_count'] = text_col.str.split().str.len()
                new_features[f'{col}_unique_words'] = text_col.apply(lambda x: len(set(x.split())))
                new_features[f'{col}_avg_word_length'] = text_col.apply(
                    lambda x: np.mean([len(word) for word in x.split()]) if x.split() else 0
                )
                
                # Character features
                new_features[f'{col}_uppercase_ratio'] = text_col.apply(
                    lambda x: sum(1 for c in x if c.isupper()) / (len(x) + 1e-8)
                )
                new_features[f'{col}_digit_ratio'] = text_col.apply(
                    lambda x: sum(1 for c in x if c.isdigit()) / (len(x) + 1e-8)
                )
                new_features[f'{col}_special_char_ratio'] = text_col.apply(
                    lambda x: sum(1 for c in x if not c.isalnum() and not c.isspace()) / (len(x) + 1e-8)
                )
        
        # Use concat to add all new features at once
        if new_features:
            X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def _engineer_interaction_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer interaction features between numerical variables"""
        
        if not self.interaction_features or len(self.numerical_features) < 2:
            return X
        
        new_features = {}
        
        for i, col1 in enumerate(self.numerical_features):
            for col2 in self.numerical_features[i+1:]:
                if col1 in X.columns and col2 in X.columns:
                    col1_data = X[col1].fillna(X[col1].median())
                    col2_data = X[col2].fillna(X[col2].median())
                    
                    new_features[f'{col1}_{col2}_product'] = col1_data * col2_data
                    new_features[f'{col1}_{col2}_ratio'] = col1_data / (col2_data + 1e-8)
                    new_features[f'{col1}_{col2}_difference'] = col1_data - col2_data
                    new_features[f'{col1}_{col2}_sum'] = col1_data + col2_data
        
        # Use concat to add all new features at once
        if new_features:
            X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def _engineer_polynomial_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer polynomial features"""
        
        if self.polynomial_degree <= 1:
            return X
        
        from sklearn.preprocessing import PolynomialFeatures
        
        poly_features = self.numerical_features[:5]  # Limit to first 5 to avoid explosion
        if poly_features:
            # Filter features that exist in X
            available_features = [f for f in poly_features if f in X.columns]
            
            if available_features:
                poly = PolynomialFeatures(degree=self.polynomial_degree, include_bias=False)
                poly_data = poly.fit_transform(X[available_features].fillna(0))
                poly_names = poly.get_feature_names_out(available_features)
                
                # Create new features dictionary
                new_features = {}
                for i, name in enumerate(poly_names):
                    if name not in available_features:  # Don't duplicate original features
                        new_features[f'poly_{name}'] = poly_data[:, i]
                
                # Use concat to add all new features at once
                if new_features:
                    X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def _engineer_binning_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer binning features"""
        
        new_features = {}
        
        for col in self.binning_features:
            if col in X.columns:
                col_data = X[col].fillna(X[col].median())
                
                # Equal-width binning
                try:
                    new_features[f'{col}_binned_equal'] = pd.cut(col_data, bins=5, labels=False)
                except:
                    new_features[f'{col}_binned_equal'] = 0
                
                # Equal-frequency binning
                try:
                    new_features[f'{col}_binned_quantile'] = pd.qcut(col_data, q=5, labels=False, duplicates='drop')
                except:
                    new_features[f'{col}_binned_quantile'] = 0
        
        # Use concat to add all new features at once
        if new_features:
            X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def _engineer_mathematical_features(self, X: pd.DataFrame) -> pd.DataFrame:
        """Engineer mathematical transformation features"""
        
        new_features = {}
        
        for col in self.log_transform_features:
            if col in X.columns:
                col_data = X[col].fillna(X[col].median())
                
                # Only apply transformations if data is finite and valid
                if np.all(np.isfinite(col_data)) and len(col_data.dropna()) > 0:
                    # Box-Cox transformation
                    if (col_data > 0).all():
                        try:
                            new_features[f'{col}_boxcox'] = stats.boxcox(col_data + 1)[0]
                        except:
                            new_features[f'{col}_boxcox'] = col_data
                    
                    # Yeo-Johnson transformation
                    try:
                        new_features[f'{col}_yeojohnson'] = stats.yeojohnson(col_data)[0]
                    except:
                        new_features[f'{col}_yeojohnson'] = col_data
        
        # Use concat to add all new features at once
        if new_features:
            X = pd.concat([X, pd.DataFrame(new_features, index=X.index)], axis=1)
        
        return X
    
    def get_feature_names_out(self, input_features=None):
        """Get output feature names"""
        check_is_fitted(self, 'feature_names_out_')
        return self.feature_names_out_

class AutomatedPipelineBuilder:
    """Automated pipeline builder with intelligent feature engineering"""
    
    def __init__(self, task_type: str = 'auto', random_state: int = 42):
        self.task_type = task_type
        self.random_state = random_state
        self.pipelines = {}
        self.best_pipeline = None
        self.feature_importance_analysis = {}
        
    @performance_monitor
    def build_comprehensive_pipeline(self, X: pd.DataFrame, y: pd.Series,
                                   config: PipelineConfiguration = None) -> Dict[str, Pipeline]:
        """Build comprehensive data processing pipeline"""
        
        if config is None:
            config = PipelineConfiguration()
        
        # Auto-detect task type
        if self.task_type == 'auto':
            self.task_type = self._detect_task_type(y)
        
        # Identify feature types
        numerical_features = X.select_dtypes(include=[np.number]).columns.tolist()
        categorical_features = X.select_dtypes(include=['object', 'category']).columns.tolist()
        
        # Build multiple pipeline variants
        pipeline_configs = [
            ('basic', self._build_basic_pipeline(numerical_features, categorical_features, config)),
            ('advanced', self._build_advanced_pipeline(numerical_features, categorical_features, config)),
            ('feature_rich', self._build_feature_rich_pipeline(numerical_features, categorical_features, config)),
            ('ensemble_ready', self._build_ensemble_ready_pipeline(numerical_features, categorical_features, config))
        ]
        
        # Evaluate pipelines
        for name, pipeline in pipeline_configs:
            self.pipelines[name] = pipeline
            self._evaluate_pipeline(name, pipeline, X, y)
        
        # Select best pipeline
        self._select_best_pipeline(X, y)
        
        return self.pipelines
    
    def _detect_task_type(self, y: pd.Series) -> str:
        """Automatically detect if task is classification or regression"""
        
        if pd.api.types.is_numeric_dtype(y):
            unique_values = y.nunique()
            if unique_values <= 20 and y.dtype in ['int64', 'int32']:
                return 'classification'
            else:
                return 'regression'
        else:
            return 'classification'
    
    def _build_basic_pipeline(self, numerical_features: List[str], 
                            categorical_features: List[str],
                            config: PipelineConfiguration) -> Pipeline:
        """Build basic preprocessing pipeline"""
        
        # Numerical preprocessing
        numerical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy=config.missing_strategy)),
            ('scaler', self._get_scaler(config.numerical_strategy))
        ])
        
        # Categorical preprocessing
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
            ('encoder', self._get_encoder(config.categorical_strategy))
        ])
        
        # Combine preprocessing
        preprocessor = ColumnTransformer([
            ('num', numerical_pipeline, numerical_features),
            ('cat', categorical_pipeline, categorical_features)
        ])
        
        # Build full pipeline
        steps = [('preprocessor', preprocessor)]
        
        if config.feature_selection:
            steps.append(('feature_selection', self._get_feature_selector()))
        
        return Pipeline(steps)
    
    def _build_advanced_pipeline(self, numerical_features: List[str],
                               categorical_features: List[str],
                               config: PipelineConfiguration) -> Pipeline:
        """Build advanced preprocessing pipeline with feature engineering"""
        
        # Advanced numerical preprocessing
        numerical_pipeline = Pipeline([
            ('imputer', KNNImputer(n_neighbors=5)),
            ('outlier_clipper', FunctionTransformer(
                func=lambda X: np.clip(X, np.percentile(X, 1, axis=0), np.percentile(X, 99, axis=0)),
                validate=False
            )),
            ('scaler', RobustScaler()),
            ('power_transformer', PowerTransformer(method='yeo-johnson'))
        ])
        
        # Advanced categorical preprocessing
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
            ('target_encoder', ce.TargetEncoder(smoothing=1.0)),
            ('scaler', StandardScaler())
        ])
        
        # Combine preprocessing
        preprocessor = ColumnTransformer([
            ('num', numerical_pipeline, numerical_features),
            ('cat', categorical_pipeline, categorical_features)
        ])
        
        # Build full pipeline
        steps = [
            ('preprocessor', preprocessor),
            ('feature_selection', SelectKBest(k='all'))  # Use 'all' to avoid k > n_features warning
        ]
        
        if config.polynomial_features:
            steps.append(('poly_features', PolynomialFeatures(degree=2, interaction_only=True)))
        
        return Pipeline(steps)
    
    def _build_feature_rich_pipeline(self, numerical_features: List[str],
                                   categorical_features: List[str],
                                   config: PipelineConfiguration) -> Pipeline:
        """Build feature-rich pipeline with extensive feature engineering"""
        
        # Feature engineering transformer
        feature_engineer = AdvancedFeatureEngineer(
            numerical_features=numerical_features,
            categorical_features=categorical_features,
            polynomial_degree=2,
            interaction_features=True
        )
        
        # Robust preprocessing after feature engineering
        numerical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='median')),
            ('scaler', StandardScaler())
        ])
        
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
            ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
        ])
        
        # Separate numerical and categorical after feature engineering
        preprocessor = ColumnTransformer([
            ('num', numerical_pipeline, make_column_selector(dtype_include=[np.number])),
            ('cat', categorical_pipeline, make_column_selector(dtype_include=['object', 'category']))
        ], remainder='drop')
        
        # Advanced feature selection
        feature_selector = Pipeline([
            ('variance_threshold', VarianceThreshold(threshold=0.01)),
            ('univariate_selection', SelectKBest(k='all')),  # Use 'all' to avoid k > n_features warning
            ('model_selection', SelectFromModel(
                RandomForestRegressor(n_estimators=50, random_state=self.random_state)
                if self.task_type == 'regression'
                else RandomForestClassifier(n_estimators=50, random_state=self.random_state)
            ))
        ])
        
        return Pipeline([
            ('feature_engineering', feature_engineer),
            ('preprocessing', preprocessor),
            ('feature_selection', feature_selector)
        ])
    
    def _build_ensemble_ready_pipeline(self, numerical_features: List[str],
                                     categorical_features: List[str],
                                     config: PipelineConfiguration) -> Pipeline:
        """Build pipeline optimized for ensemble methods"""
        
        # Robust preprocessing for ensemble methods
        numerical_pipeline = Pipeline([
            ('imputer', IterativeImputer(random_state=self.random_state)),
            ('scaler', RobustScaler()),
            ('quantile_transformer', QuantileTransformer(output_distribution='normal'))
        ])
        
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='unknown')),
            ('encoder', ce.CatBoostEncoder()),
            ('scaler', StandardScaler())
        ])
        
        preprocessor = ColumnTransformer([
            ('num', numerical_pipeline, numerical_features),
            ('cat', categorical_pipeline, categorical_features)
        ])
        
        return Pipeline([
            ('preprocessor', preprocessor),
            ('feature_selection', SelectFromModel(
                RandomForestRegressor(n_estimators=100, random_state=self.random_state)
                if self.task_type == 'regression'
                else RandomForestClassifier(n_estimators=100, random_state=self.random_state),
                threshold='median'
            ))
        ])
    
    def _get_scaler(self, strategy: str):
        """Get scaler based on strategy"""
        scalers = {
            'standard': StandardScaler(),
            'minmax': MinMaxScaler(),
            'robust': RobustScaler(),
            'quantile': QuantileTransformer()
        }
        return scalers.get(strategy, StandardScaler())
    
    def _get_encoder(self, strategy: str):
        """Get encoder based on strategy"""
        encoders = {
            'onehot': OneHotEncoder(handle_unknown='ignore', sparse_output=False),
            'label': OrdinalEncoder(handle_unknown='use_encoded_value', unknown_value=-1),
            'target': ce.TargetEncoder()
        }
        return encoders.get(strategy, OneHotEncoder(handle_unknown='ignore', sparse_output=False))
    
    def _get_feature_selector(self):
        """Get feature selector based on task type"""
        if self.task_type == 'classification':
            return SelectKBest(f_classif, k='all')  # Use 'all' to avoid warnings
        else:
            return SelectKBest(f_regression, k='all')  # Use 'all' to avoid warnings

        """Evaluate pipeline performance with improved error handling"""

            # Fit and transform with better error handling
            with warnings.catch_warnings():
                warnings.simplefilter("ignore")
                X_transformed = pipeline.fit_transform(X, y)

                X_numeric = X_transformed.select_dtypes(include=[np.number])

                X_numeric = X_transformed

            if self.task_type == 'classification':
                model = LogisticRegression(random_state=self.random_state, max_iter=1000)
                scoring = accuracy_score
            else:
                model = LinearRegression()
                scoring = r2_score
            
            # Cross-validation with warning suppression
            with warnings.catch_warnings():

                scores = cross_val_score(model, X_numeric, y, cv=5)

                'mean_score': scores.mean(),
                'std_score': scores.std(),
                'n_features_out': X_numeric.shape[1],
                'transformation_ratio': X_numeric.shape[1] / X.shape[1]
            }
            
            logger.info(f"Pipeline {name}: Score = {scores.mean():.4f} ± {scores.std():.4f}, "

                'std_score': np.inf,
                'n_features_out': 0,
                'transformation_ratio': 0,
                'error': str(e)
            }
