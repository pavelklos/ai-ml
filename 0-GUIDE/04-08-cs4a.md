# 08. Cross-Validation and Model Selection Art

## Key Terms

**Cross-Validation**: A statistical resampling technique that divides the training dataset into multiple folds to evaluate model performance across different data subsets, providing robust estimates of model generalization capability and reducing overfitting risk.

**Hyperparameter Tuning**: The systematic process of optimizing model configuration parameters that are not learned during training, such as learning rates, regularization strength, or tree depth, to achieve optimal model performance.

**Train-Test Split**: The fundamental division of available data into separate training and testing sets, where the training set is used for model development and the testing set provides an unbiased evaluation of final model performance.

**Model Generalization**: The ability of a machine learning model to perform accurately on unseen data that was not used during training, representing the true measure of model effectiveness in real-world applications.

**Stratified Sampling**: A sampling technique that maintains the same proportion of samples for each target class across different data splits, ensuring representative distribution in imbalanced datasets.

**Grid Search**: An exhaustive hyperparameter optimization method that evaluates all possible combinations of specified parameter values to identify the optimal configuration through systematic exploration.

**Random Search**: A probabilistic hyperparameter optimization approach that randomly samples parameter combinations from specified distributions, often more efficient than grid search for high-dimensional parameter spaces.

**Nested Cross-Validation**: An advanced validation technique that uses separate cross-validation loops for hyperparameter tuning (inner loop) and model evaluation (outer loop), providing unbiased performance estimates.

**Bias-Variance Tradeoff**: The fundamental machine learning principle describing the relationship between model complexity, training error (bias), and sensitivity to training data variations (variance), crucial for optimal model selection.

## Theoretical Foundation of Cross-Validation and Model Selection

Cross-validation represents the cornerstone of robust model evaluation, addressing the fundamental challenge of estimating how well a model will generalize to independent datasets. The technique provides statistically sound methods for model comparison, hyperparameter optimization, and performance estimation while maximizing the utilization of available training data.

The mathematical foundation involves partitioning the training set into k folds, training on k-1 folds, and validating on the remaining fold, repeating this process k times. This provides k performance estimates that can be averaged to obtain a more stable and reliable measure of model performance than a single train-test split.

Model selection extends beyond simple algorithm comparison to encompass the entire machine learning pipeline optimization, including preprocessing steps, feature selection, hyperparameter tuning, and ensemble configuration. Proper cross-validation prevents data leakage and provides honest estimates of production performance.

def performance_monitor(func):
    """Decorator to monitor function performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedCrossValidator:
    """Advanced cross-validation system with multiple strategies"""
    
    def __init__(self, random_state: int = 42):
        self.random_state = random_state
        self.cv_results_ = {}
        self.best_cv_strategy_ = None
        
    @performance_monitor
    def evaluate_cv_strategies(self, X: pd.DataFrame, y: pd.Series,
                             estimator: BaseEstimator,
                             cv_strategies: List[str] = None,
                             scoring: str = None) -> Dict[str, CrossValidationResults]:
        """Evaluate different cross-validation strategies"""
        
        if cv_strategies is None:
            cv_strategies = ['kfold', 'stratified', 'repeated_kfold', 'leave_one_out']
        
        if scoring is None:
            scoring = 'accuracy' if self._is_classifier(estimator) else 'r2'
        
        cv_results = {}
        
        for strategy in cv_strategies:
            try:
                logger.info(f"Evaluating {strategy} cross-validation")
                
                cv_splitter = self._create_cv_splitter(strategy, X, y)
                results = self._perform_cross_validation(
                    X, y, estimator, cv_splitter, scoring, strategy
                )
                cv_results[strategy] = results
                
            except Exception as e:
                logger.error(f"Error in {strategy} cross-validation: {e}")
                continue
        
        # Select best strategy
        self._select_best_cv_strategy(cv_results)
        self.cv_results_ = cv_results
        
        return cv_results
    
    def _create_cv_splitter(self, strategy: str, X: pd.DataFrame, y: pd.Series):
        """Create appropriate cross-validation splitter"""
        
        n_samples = len(X)
        
        if strategy == 'kfold':
            return KFold(n_splits=min(10, n_samples // 10), shuffle=True, random_state=self.random_state)
        
        elif strategy == 'stratified':
            if self._is_classification_task(y):
                return StratifiedKFold(n_splits=min(10, n_samples // 10), shuffle=True, random_state=self.random_state)
            else:
                # For regression, use regular KFold
                return KFold(n_splits=min(10, n_samples // 10), shuffle=True, random_state=self.random_state)
        
        elif strategy == 'repeated_kfold':
            from sklearn.model_selection import RepeatedKFold, RepeatedStratifiedKFold
            if self._is_classification_task(y):
                return RepeatedStratifiedKFold(n_splits=5, n_repeats=2, random_state=self.random_state)
            else:
                return RepeatedKFold(n_splits=5, n_repeats=2, random_state=self.random_state)
        
        elif strategy == 'leave_one_out':
            if n_samples <= 100:  # Only for small datasets
                return LeaveOneOut()
            else:
                # Use LeavePOut for larger datasets
                return LeavePOut(p=min(5, n_samples // 20))
        
        elif strategy == 'time_series':
            return TimeSeriesSplit(n_splits=min(10, n_samples // 10))
        
        elif strategy == 'group_kfold':
            # Assume first column as group identifier
            groups = X.iloc[:, 0] if not X.empty else np.arange(n_samples) % 5
            return GroupKFold(n_splits=min(5, len(np.unique(groups))))
        
        else:
            raise ValueError(f"Unknown cross-validation strategy: {strategy}")
    
    def _perform_cross_validation(self, X: pd.DataFrame, y: pd.Series,
                                estimator: BaseEstimator, cv_splitter,
                                scoring: str, strategy: str) -> CrossValidationResults:
        """Perform cross-validation with detailed analysis"""
        
        # Perform cross-validation
        cv_results = cross_validate(
            estimator, X, y, cv=cv_splitter, scoring=scoring,
            return_train_score=True, return_estimator=True, n_jobs=-1
        )
        
        test_scores = cv_results['test_score']
        train_scores = cv_results['train_score']
        
        # Calculate statistics
        mean_score = np.mean(test_scores)
        std_score = np.std(test_scores)
        
        # Calculate confidence interval
        confidence_level = 0.95
        alpha = 1 - confidence_level
        degrees_freedom = len(test_scores) - 1
        t_critical = stats.t.ppf(1 - alpha/2, degrees_freedom)
        margin_error = t_critical * (std_score / np.sqrt(len(test_scores)))
        confidence_interval = (mean_score - margin_error, mean_score + margin_error)
        
        # Detailed fold analysis
        fold_details = []
        for i, (train_score, test_score, estimator_fold) in enumerate(
            zip(train_scores, test_scores, cv_results['estimator'])
        ):
            fold_details.append({
                'fold': i + 1,
                'train_score': train_score,
                'test_score': test_score,
                'overfitting': train_score - test_score,
                'estimator': estimator_fold
            })
        
        return CrossValidationResults(
            cv_scores=test_scores,
            mean_score=mean_score,
            std_score=std_score,
            confidence_interval=confidence_interval,
            fold_details=fold_details,
            cv_method=strategy,
            scoring_metric=scoring
        )
    
    def _select_best_cv_strategy(self, cv_results: Dict[str, CrossValidationResults]):
        """Select best cross-validation strategy based on stability and reliability"""
        
        strategy_scores = {}
        
        for strategy, results in cv_results.items():
            # Score based on mean performance and stability (low variance)
            stability_score = 1 / (1 + results.std_score)  # Higher score for lower variance
            performance_score = results.mean_score
            
            # Combined score (weighted)
            combined_score = 0.7 * performance_score + 0.3 * stability_score
            strategy_scores[strategy] = combined_score
        
        self.best_cv_strategy_ = max(strategy_scores.keys(), key=lambda x: strategy_scores[x])
        logger.info(f"Best cross-validation strategy: {self.best_cv_strategy_}")
    
    def _is_classifier(self, estimator: BaseEstimator) -> bool:
        """Check if estimator is a classifier"""
        return hasattr(estimator, 'predict_proba') or hasattr(estimator, 'decision_function')
    
    def _is_classification_task(self, y: pd.Series) -> bool:
        """Determine if task is classification based on target variable"""
        unique_ratio = y.nunique() / len(y)
        return unique_ratio < 0.05 or y.nunique() <= 20

class ComprehensiveHyperparameterOptimizer:
    """Advanced hyperparameter optimization with multiple search strategies"""
    
    def __init__(self, random_state: int = 42, n_jobs: int = -1):
        self.random_state = random_state
        self.n_jobs = n_jobs
        self.search_results_ = {}
        self.best_search_method_ = None
        
    @performance_monitor
    def optimize_hyperparameters(self, X: pd.DataFrame, y: pd.Series,
                                estimator: BaseEstimator,
                                param_space: Dict[str, Any],
                                search_methods: List[str] = None,
                                cv_strategy = None,
                                scoring: str = None,
                                max_iter: int = 100) -> Dict[str, HyperparameterSearchResults]:
        """Comprehensive hyperparameter optimization using multiple methods"""
        
        if search_methods is None:
            search_methods = ['grid_search', 'random_search', 'bayesian_search']
        
        if scoring is None:
            scoring = 'accuracy' if self._is_classifier(estimator) else 'r2'
        
        if cv_strategy is None:
            cv_strategy = StratifiedKFold(n_splits=5, shuffle=True, random_state=self.random_state)
        
        search_results = {}
        
        for method in search_methods:
            try:
                logger.info(f"Performing {method} hyperparameter optimization")
                
                start_time = time.time()
                result = self._perform_hyperparameter_search(
                    X, y, estimator, param_space, method, cv_strategy, scoring, max_iter
                )
                search_time = time.time() - start_time
                
                result.search_time = search_time
                search_results[method] = result
                
            except Exception as e:
                logger.error(f"Error in {method}: {e}")
                continue
        
        self.search_results_ = search_results
        self._select_best_search_method()
        
        return search_results
    
    def _perform_hyperparameter_search(self, X: pd.DataFrame, y: pd.Series,
                                     estimator: BaseEstimator, param_space: Dict[str, Any],
                                     method: str, cv_strategy, scoring: str,
                                     max_iter: int) -> HyperparameterSearchResults:
        """Perform specific hyperparameter search method"""
        
        if method == 'grid_search':
            search = GridSearchCV(
                estimator=estimator,
                param_grid=param_space,
                cv=cv_strategy,
                scoring=scoring,
                n_jobs=self.n_jobs,
                verbose=1
            )
            
        elif method == 'random_search':
            search = RandomizedSearchCV(
                estimator=estimator,
                param_distributions=param_space,
                n_iter=max_iter,
                cv=cv_strategy,
                scoring=scoring,
                n_jobs=self.n_jobs,
                random_state=self.random_state,
                verbose=1
            )
            
        elif method == 'bayesian_search':
            # Convert parameter space for scikit-optimize
            search_space = self._convert_param_space_for_skopt(param_space)
            search = BayesSearchCV(
                estimator=estimator,
                search_spaces=search_space,
                n_iter=max_iter,
                cv=cv_strategy,
                scoring=scoring,
                n_jobs=self.n_jobs,
                random_state=self.random_state,
                verbose=1
            )
            
        else:
            raise ValueError(f"Unknown search method: {method}")
        
        # Fit the search
        search.fit(X, y)
        
        return HyperparameterSearchResults(
            best_params=search.best_params_,
            best_score=search.best_score_,
            best_estimator=search.best_estimator_,
            cv_results=search.cv_results_,
            search_method=method,
            total_iterations=len(search.cv_results_['mean_test_score']),
            search_time=0.0  # Will be set by calling function
        )
    
    def _convert_param_space_for_skopt(self, param_space: Dict[str, Any]) -> Dict[str, Any]:
        """Convert parameter space for scikit-optimize format"""
        
        skopt_space = {}
        
        for param, values in param_space.items():
            if isinstance(values, list):
                if all(isinstance(v, (int, float)) for v in values):
                    # Numerical values - create range
                    if all(isinstance(v, int) for v in values):
                        skopt_space[param] = Integer(min(values), max(values))
                    else:
                        skopt_space[param] = Real(min(values), max(values))
                else:
                    # Categorical values
                    skopt_space[param] = Categorical(values)
            elif isinstance(values, tuple) and len(values) == 2:
                # Range specification
                if all(isinstance(v, int) for v in values):
                    skopt_space[param] = Integer(values[0], values[1])
                else:
                    skopt_space[param] = Real(values[0], values[1])
            else:
                # Single value or unknown format
                skopt_space[param] = Categorical([values] if not isinstance(values, list) else values)
        
        return skopt_space
    
    def _select_best_search_method(self):
        """Select best search method based on performance and efficiency"""
        
        if not self.search_results_:
            return
        
        method_scores = {}
        
        for method, results in self.search_results_.items():
            # Score based on performance and efficiency
            performance_score = results.best_score
            efficiency_score = 1 / (1 + results.search_time / 60)  # Preference for faster methods
            
            # Combined score
            combined_score = 0.8 * performance_score + 0.2 * efficiency_score
            method_scores[method] = combined_score
        
        self.best_search_method_ = max(method_scores.keys(), key=lambda x: method_scores[x])
        logger.info(f"Best search method: {self.best_search_method_}")
    
    def _is_classifier(self, estimator: BaseEstimator) -> bool:
        """Check if estimator is a classifier"""
        return hasattr(estimator, 'predict_proba') or hasattr(estimator, 'decision_function')

class AdvancedModelComparator:
    """Comprehensive model comparison and selection system"""
    
    def __init__(self, random_state: int = 42):
        self.random_state = random_state
        self.comparison_results_ = None
        self.model_library_ = {}
        
    @performance_monitor
    def compare_models(self, X: pd.DataFrame, y: pd.Series,
                      models: Dict[str, BaseEstimator] = None,
                      cv_strategy = None,
                      scoring: str = None,
                      include_preprocessing: bool = True) -> ModelComparisonResults:
        """Comprehensive model comparison with statistical significance testing"""
        
        if models is None:
            models = self._get_default_model_library(y)
        
        if cv_strategy is None:
            cv_strategy = StratifiedKFold(n_splits=5, shuffle=True, random_state=self.random_state)
        
        if scoring is None:
            scoring = 'accuracy' if self._is_classification_task(y) else 'r2'
        
        # Prepare data
        X_processed, y_processed = self._prepare_data(X, y, include_preprocessing)
        
        # Compare models
        model_scores = {}
        all_cv_scores = {}
        
        for model_name, model in models.items():
            try:
                logger.info(f"Evaluating model: {model_name}")
                
                # Perform cross-validation
                cv_scores = cross_val_score(
                    model, X_processed, y_processed, cv=cv_strategy,
                    scoring=scoring, n_jobs=-1
                )
                
                # Calculate statistics
                mean_score = np.mean(cv_scores)
                std_score = np.std(cv_scores)
                
                # Confidence interval
                confidence_level = 0.95
                alpha = 1 - confidence_level
                degrees_freedom = len(cv_scores) - 1
                t_critical = stats.t.ppf(1 - alpha/2, degrees_freedom)
                margin_error = t_critical * (std_score / np.sqrt(len(cv_scores)))
                confidence_interval = (mean_score - margin_error, mean_score + margin_error)
                
                model_scores[model_name] = CrossValidationResults(
                    cv_scores=cv_scores,
                    mean_score=mean_score,
                    std_score=std_score,
                    confidence_interval=confidence_interval,
                    fold_details=[],
                    cv_method='comparison',
                    scoring_metric=scoring
                )
                
                all_cv_scores[model_name] = cv_scores
                
            except Exception as e:
                logger.error(f"Error evaluating {model_name}: {e}")
                continue
        
        # Statistical significance testing
        significance_results = self._perform_significance_testing(all_cv_scores)
        
        # Performance ranking
        performance_ranking = sorted(
            [(name, results.mean_score) for name, results in model_scores.items()],
            key=lambda x: x[1], reverse=True
        )
        
        # Best model selection
        best_model = performance_ranking[0][0] if performance_ranking else None
        
        # Generate recommendation
        recommendation = self._generate_model_recommendation(
            model_scores, significance_results, performance_ranking
        )
        
        comparison_results = ModelComparisonResults(
            model_scores=model_scores,
            best_model=best_model,
            performance_ranking=performance_ranking,
            statistical_significance=significance_results,
            recommendation=recommendation
        )
        
        self.comparison_results_ = comparison_results
        return comparison_results
    
    def _get_default_model_library(self, y: pd.Series) -> Dict[str, BaseEstimator]:

        is_classification = self._is_classification_task(y)
        
        if is_classification:

                'random_forest': RandomForestClassifier(random_state=self.random_state),
                'gradient_boosting': GradientBoostingClassifier(random_state=self.random_state),
                'svm': SVC(random_state=self.random_state),
                'knn': KNeighborsClassifier(),
                'naive_bayes': GaussianNB(),
                'extra_trees': ExtraTreesClassifier(random_state=self.random_state)
            }
        else:
            return {
                'linear_regression': LinearRegression(),
                'ridge_regression': Ridge(random_state=self.random_state),
                'random_forest': RandomForestRegressor(random_state=self.random_state),
                'gradient_boosting': GradientBoostingRegressor(random_state=self.random_state),
                'svr': SVR(),
                'knn': KNeighborsRegressor(),
                'extra_trees': ExtraTreesRegressor(random_state=self.random_state)
            }
    
    def _prepare_data(self, X: pd.DataFrame, y: pd.Series, 
                     include_preprocessing: bool) -> Tuple[pd.DataFrame, pd.Series]:
        """Prepare data with optional preprocessing"""
        
        if not include_preprocessing:
            return X, y
        
        # Handle missing values
        if X.isnull().any().any():
            numeric_features = X.select_dtypes(include=[np.number]).columns
            categorical_features = X.select_dtypes(include=['object', 'category']).columns
            
            # Simple imputation
            for col in numeric_features:
                X[col] = X[col].fillna(X[col].median())
            
            for col in categorical_features:
                X[col] = X[col].fillna(X[col].mode().iloc[0] if not X[col].mode().empty else 'unknown')
        
        # Basic preprocessing
        preprocessor = ColumnTransformer([
            ('num', StandardScaler(), X.select_dtypes(include=[np.number]).columns.tolist()),
            ('cat', OneHotEncoder(handle_unknown='ignore', sparse=False), 
             X.select_dtypes(include=['object', 'category']).columns.tolist())
        ])
        
        X_processed = preprocessor.fit_transform(X)
        
        # Convert back to DataFrame for consistency
        feature_names = (
            X.select_dtypes(include=[np.number]).columns.tolist() +
            list(preprocessor.named_transformers_['cat'].get_feature_names_out(
                X.select_dtypes(include=['object', 'category']).columns
            ))
        )
        
        X_processed = pd.DataFrame(X_processed, columns=feature_names, index=X.index)
        
        return X_processed, y
    
    def _perform_significance_testing(self, all_cv_scores: Dict[str, np.ndarray]) -> Dict[str, Dict[str, float]]:
        """Perform statistical significance testing between models"""
        
        significance_results = {}
        model_names = list(all_cv_scores.keys())
        
        for i, model1 in enumerate(model_names):
            significance_results[model1] = {}
            
            for j, model2 in enumerate(model_names):
                if i != j:
                    # Paired t-test
                    scores1 = all_cv_scores[model1]
                    scores2 = all_cv_scores[model2]
                    
                    if len(scores1) == len(scores2):
                        t_stat, p_value = stats.ttest_rel(scores1, scores2)
                        significance_results[model1][model2] = p_value
                    else:
                        # Independent t-test if different lengths
                        t_stat, p_value = stats.ttest_ind(scores1, scores2)
                        significance_results[model1][model2] = p_value
        
        return significance_results
    
    def _generate_model_recommendation(self, model_scores: Dict[str, CrossValidationResults],
                                     significance_results: Dict[str, Dict[str, float]],
                                     performance_ranking: List[Tuple[str, float]]) -> str:
        """Generate intelligent model recommendation"""
        
        if not performance_ranking:
            return "No valid models found"
        
        best_model = performance_ranking[0][0]
        best_score = performance_ranking[0][1]
        
        # Check if best model is significantly better than others
        significant_improvements = 0
        if best_model in significance_results:
            for other_model, p_value in significance_results[best_model].items():
                if p_value < 0.05:  # Significant at 95% confidence
                    significant_improvements += 1
        
        # Generate recommendation
        if significant_improvements >= len(performance_ranking) // 2:
            return f"Strong recommendation: {best_model} (significantly outperforms {significant_improvements} other models)"
        elif model_scores[best_model].std_score < 0.05:
            return f"Moderate recommendation: {best_model} (stable performance, low variance)"
        else:
            return f"Weak recommendation: {best_model} (marginal performance advantage, consider ensemble methods)"
    
    def _is_classification_task(self, y: pd.Series) -> bool:
        """Determine if task is classification"""
        unique_ratio = y.nunique() / len(y)
        return unique_ratio < 0.05 or y.nunique() <= 20

class ComprehensiveMLPipeline:
    """Complete machine learning pipeline with cross-validation and model selection"""
    
    def __init__(self, random_state: int = 42):
        self.random_state = random_state
        self.cross_validator = AdvancedCrossValidator(random_state)
        self.hyperparameter_optimizer = ComprehensiveHyperparameterOptimizer(random_state)
        self.model_comparator = AdvancedModelComparator(random_state)
        self.final_pipeline_ = None
        self.pipeline_results_ = {}
        
    @performance_monitor
    def build_complete_pipeline(self, X: pd.DataFrame, y: pd.Series,
                              test_size: float = 0.2,
                              optimize_hyperparameters: bool = True,
                              compare_models: bool = True) -> Dict[str, Any]:
        """Build complete ML pipeline with cross-validation and model selection"""
        
        logger.info("Starting comprehensive ML pipeline construction")
        
        # Split data
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=test_size, random_state=self.random_state,
            stratify=y if self._is_classification_task(y) else None
        )
        
        logger.info(f"Data split: Train {X_train.shape}, Test {X_test.shape}")
        
        # 1. Model Comparison
        if compare_models:
            logger.info("Performing model comparison")
            comparison_results = self.model_comparator.compare_models(X_train, y_train)
            best_model_name = comparison_results.best_model
            
            # Get best model instance
            default_models = self.model_comparator._get_default_model_library(y_train)
            best_base_model = default_models[best_model_name]
        else:
            # Use default model
            if self._is_classification_task(y_train):
                best_base_model = RandomForestClassifier(random_state=self.random_state)
                best_model_name = 'random_forest'
            else:
                best_base_model = RandomForestRegressor(random_state=self.random_state)
                best_model_name = 'random_forest'
            
            comparison_results = None
        
        # 2. Cross-validation strategy evaluation
        logger.info("Evaluating cross-validation strategies")
        cv_results = self.cross_validator.evaluate_cv_strategies(
            X_train, y_train, best_base_model
        )
        best_cv_strategy = self.cross_validator.best_cv_strategy_
        
        # 3. Hyperparameter optimization
        if optimize_hyperparameters:
            logger.info("Optimizing hyperparameters")
            param_space = self._get_param_space(best_base_model, best_model_name)
            
            cv_splitter = self.cross_validator._create_cv_splitter(
                best_cv_strategy, X_train, y_train
            )
            
            hp_results = self.hyperparameter_optimizer.optimize_hyperparameters(
                X_train, y_train, best_base_model, param_space, cv_strategy=cv_splitter
            )
            
            best_search_method = self.hyperparameter_optimizer.best_search_method_
            optimized_model = hp_results[best_search_method].best_estimator
        else:
            hp_results = None
            optimized_model = best_base_model
        
        # 4. Build final pipeline
        logger.info("Building final pipeline")
        final_pipeline = self._build_final_pipeline(optimized_model, X_train)
        
        # 5. Final evaluation
        logger.info("Performing final evaluation")
        final_pipeline.fit(X_train, y_train)
        
        # Training performance
        train_score = final_pipeline.score(X_train, y_train)
        test_score = final_pipeline.score(X_test, y_test)
        
        # Cross-validation performance on full training set
        final_cv_scores = cross_val_score(
            final_pipeline, X_train, y_train,
            cv=self.cross_validator._create_cv_splitter(best_cv_strategy, X_train, y_train),
            scoring='accuracy' if self._is_classification_task(y_train) else 'r2'
        )
        
        # Store results
        self.pipeline_results_ = {
            'model_comparison': comparison_results,
            'cv_evaluation': cv_results,
            'hyperparameter_optimization': hp_results,
            'final_performance': {
                'train_score': train_score,
                'test_score': test_score,
                'cv_scores': final_cv_scores,
                'cv_mean': np.mean(final_cv_scores),
                'cv_std': np.std(final_cv_scores)
            },
            'best_model': best_model_name,
            'best_cv_strategy': best_cv_strategy,
            'pipeline_config': {
                'test_size': test_size,
                'optimize_hyperparameters': optimize_hyperparameters,
                'compare_models': compare_models
            }
        }
        
        self.final_pipeline_ = final_pipeline
        
        logger.info("Pipeline construction completed")
        return self.pipeline_results_
    
    def _get_param_space(self, model: BaseEstimator, model_name: str) -> Dict[str, Any]:
        """Get parameter space for hyperparameter optimization"""
        
        if 'random_forest' in model_name.lower():
            return {
                'n_estimators': [50, 100, 200, 300],
                'max_depth': [None, 10, 20, 30],
                'min_samples_split': [2, 5, 10],
                'min_samples_leaf': [1, 2, 4],
                'bootstrap': [True, False]
            }
        
        elif 'gradient_boosting' in model_name.lower():
            return {
                'n_estimators': [50, 100, 200],
                'learning_rate': [0.01, 0.1, 0.2],
                'max_depth': [3, 5, 7],
                'subsample': [0.8, 0.9, 1.0]
            }
        
        elif 'logistic' in model_name.lower():
            return {
                'C': [0.01, 0.1, 1, 10, 100],
                'penalty': ['l1', 'l2'],
                'solver': ['liblinear', 'saga']
            }
        
        elif 'svm' in model_name.lower() or 'svc' in model_name.lower():
            return {
                'C': [0.1, 1, 10, 100],
                'gamma': ['scale', 'auto', 0.001, 0.01, 0.1],
                'kernel': ['rbf', 'poly', 'sigmoid']
            }
        
        elif 'knn' in model_name.lower():
            return {
                'n_neighbors': [3, 5, 7, 9, 11],
                'weights': ['uniform', 'distance'],
                'metric': ['euclidean', 'manhattan', 'minkowski']
            }
        
        else:
            # Generic parameter space
            return {
                'random_state': [self.random_state]
            }
    
    def _build_final_pipeline(self, model: BaseEstimator, X_train: pd.DataFrame) -> Pipeline:
        """Build comprehensive preprocessing and modeling pipeline"""
        
        # Identify feature types
        numeric_features = X_train.select_dtypes(include=[np.number]).columns.tolist()
        categorical_features = X_train.select_dtypes(include=['object', 'category']).columns.tolist()
        
        # Preprocessing pipelines
        numeric_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='median')),
            ('scaler', StandardScaler())
        ])
        
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
            ('encoder', OneHotEncoder(handle_unknown='ignore', sparse=False))
        ])
        
        # Combine preprocessing
        preprocessor = ColumnTransformer([
            ('num', numeric_pipeline, numeric_features),
            ('cat', categorical_pipeline, categorical_features)
        ])
        
        # Final pipeline
        pipeline = Pipeline([
            ('preprocessor', preprocessor),
            ('feature_selection', VarianceThreshold(threshold=0.01)),
            ('model', model)
        ])
        
        return pipeline
    
    def _is_classification_task(self, y: pd.Series) -> bool:
        """Determine if task is classification"""
        unique_ratio = y.nunique() / len(y)
        return unique_ratio < 0.05 or y.nunique() <= 20
