## Key Terms

**Data Quality**: The measure of data's fitness for its intended use in machine learning, encompassing completeness, accuracy, consistency, validity, and timeliness of datasets, directly impacting model performance and reliability.

**Missing Values**: Absent or undefined data points in a dataset that can occur due to data collection failures, survey non-responses, sensor malfunctions, or data integration issues, requiring systematic handling to prevent model degradation.

**Outliers**: Data points that significantly deviate from the normal distribution or expected patterns in a dataset, potentially indicating measurement errors, data entry mistakes, or genuine rare events that may skew model training.

**Data Imputation**: The process of replacing missing values with substitute values estimated through statistical methods, machine learning algorithms, or domain knowledge to maintain dataset completeness.

**Anomaly Detection**: Statistical and machine learning techniques used to identify unusual patterns, outliers, or data points that deviate significantly from expected behavior in datasets.

**Data Scaling**: The process of transforming numerical features to a common scale or range to prevent features with larger magnitudes from dominating model training, essential for distance-based algorithms.

**Data Validation**: Systematic checking of data against predefined rules, constraints, and quality criteria to identify inconsistencies, errors, and quality issues before model training.

**Robust Statistics**: Statistical measures that are less sensitive to outliers and extreme values, providing more reliable estimates of central tendency and variability in the presence of anomalous data.

## Theoretical Foundation of Data Quality Management

Data quality represents the cornerstone of successful machine learning implementations, as poor quality data inevitably leads to unreliable models regardless of algorithm sophistication. The principle "garbage in, garbage out" emphasizes that even the most advanced machine learning techniques cannot compensate for fundamentally flawed input data.

Missing values present complex challenges beyond simple data loss, as the missingness mechanism itself may contain valuable information. Understanding whether data is Missing Completely At Random (MCAR), Missing At Random (MAR), or Missing Not At Random (MNAR) determines appropriate imputation strategies and potential model bias implications.

Outliers require nuanced treatment as they may represent critical edge cases, measurement errors, or fraudulent activities depending on the domain context. Effective outlier management balances robustness against information loss while preserving genuine anomalies that provide business value.

def performance_monitor(func):
    """Decorator to monitor data quality function performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedMissingValueAnalyzer:
    """Advanced analyzer for missing value patterns and imputation strategies"""
    
    def __init__(self):
        self.missing_patterns_ = {}
        self.correlation_analysis_ = {}
        self.imputation_strategies_ = {}
        
    @performance_monitor
    def analyze_missing_patterns(self, df: pd.DataFrame, target_col: str = None) -> Dict[str, MissingValueAnalysis]:
        """Comprehensive analysis of missing value patterns"""
        
        missing_analysis = {}
        
        for col in df.columns:
            if col == target_col:
                continue
                
            missing_count = df[col].isnull().sum()
            missing_percentage = (missing_count / len(df)) * 100
            
            # Analyze missing pattern
            missing_pattern = self._identify_missing_pattern(df, col)
            
            # Correlation with target (if available)
            target_correlation = 0.0
            if target_col and target_col in df.columns:
                target_correlation = self._calculate_missing_target_correlation(df, col, target_col)
            
            # Recommend strategy
            recommended_strategy = self._recommend_imputation_strategy(
                df, col, missing_percentage, missing_pattern, target_correlation
            )
            
            missing_analysis[col] = MissingValueAnalysis(
                column_name=col,
                missing_count=missing_count,
                missing_percentage=missing_percentage,
                missing_pattern=missing_pattern,
                correlation_with_target=target_correlation,
                recommended_strategy=recommended_strategy
            )
        
        return missing_analysis
    
    def _identify_missing_pattern(self, df: pd.DataFrame, col: str) -> str:
        """Identify the pattern of missing values"""
        
        missing_mask = df[col].isnull()
        
        # Check for systematic patterns
        if missing_mask.sum() == 0:
            return "no_missing"
        
        # Check for completely missing
        if missing_mask.sum() == len(df):
            return "completely_missing"
        
        # Check for consecutive missing values
        consecutive_groups = missing_mask.groupby((missing_mask != missing_mask.shift()).cumsum()).sum()
        max_consecutive = consecutive_groups.max()
        
        if max_consecutive > len(df) * 0.1:
            return "consecutive_blocks"
        
        # Check for periodic patterns
        if self._has_periodic_pattern(missing_mask):
            return "periodic"
        
        # Check for correlation with other columns
        if self._has_correlated_missing(df, col):
            return "correlated_missing"
        
        # Default to random
        return "random"
    
    def _has_periodic_pattern(self, missing_mask: pd.Series) -> bool:
        """Check if missing values follow a periodic pattern"""
        
        # Simple check for regular intervals
        missing_indices = missing_mask[missing_mask].index.tolist()
        
        if len(missing_indices) < 3:
            return False
        
        intervals = np.diff(missing_indices)
        
        # Check if intervals are roughly equal
        if len(set(intervals)) <= 2 and np.std(intervals) < np.mean(intervals) * 0.2:
            return True
        
        return False
    
    def _has_correlated_missing(self, df: pd.DataFrame, col: str) -> bool:
        """Check if missing values are correlated with other columns"""
        
        missing_mask = df[col].isnull()
        correlations = []
        
        for other_col in df.columns:
            if other_col != col and df[other_col].dtype in ['object', 'category']:
                # For categorical columns, check if certain categories have more missing values
                contingency = pd.crosstab(df[other_col].fillna('Missing'), missing_mask)
                if contingency.shape[0] > 1 and contingency.shape[1] > 1:
                    chi2, p_value = stats.chi2_contingency(contingency)[:2]
                    if p_value < 0.05:
                        return True
            elif other_col != col and pd.api.types.is_numeric_dtype(df[other_col]):
                # For numerical columns, check correlation
                other_missing = df[other_col].isnull()
                correlation = np.corrcoef(missing_mask.astype(int), other_missing.astype(int))[0, 1]
                if abs(correlation) > 0.3:
                    return True
        
        return False
    
    def _calculate_missing_target_correlation(self, df: pd.DataFrame, col: str, target_col: str) -> float:
        """Calculate correlation between missingness and target variable"""
        
        missing_mask = df[col].isnull()
        
        if pd.api.types.is_numeric_dtype(df[target_col]):
            # For numerical target, use point-biserial correlation
            present_values = df[target_col][~missing_mask]
            missing_values = df[target_col][missing_mask]
            
            if len(present_values) > 0 and len(missing_values) > 0:
                return abs(stats.pointbiserialr(missing_mask.astype(int), df[target_col])[0])
        else:
            # For categorical target, use chi-square test
            contingency = pd.crosstab(df[target_col].fillna('Missing'), missing_mask)
            if contingency.shape[0] > 1 and contingency.shape[1] > 1:
                chi2, p_value = stats.chi2_contingency(contingency)[:2]
                return 1 - p_value  # Convert p-value to correlation-like measure
        
        return 0.0
    
    def _recommend_imputation_strategy(self, df: pd.DataFrame, col: str, 
                                     missing_percentage: float, missing_pattern: str,
                                     target_correlation: float) -> str:
        """Recommend appropriate imputation strategy"""
        
        # High missing percentage - consider removal
        if missing_percentage > 50:
            return "remove_column"
        
        # Completely missing
        if missing_pattern == "completely_missing":
            return "remove_column"
        
        # High correlation with target - sophisticated imputation needed
        if target_correlation > 0.3:
            return "iterative_imputation"
        
        # Determine strategy based on data type and pattern
        if pd.api.types.is_numeric_dtype(df[col]):
            if missing_percentage < 5:
                return "median_imputation"
            elif missing_pattern == "random":
                return "knn_imputation"
            else:
                return "iterative_imputation"
        else:
            if missing_percentage < 5:
                return "mode_imputation"
            else:
                return "constant_imputation"

class ComprehensiveOutlierDetector:
    """Advanced outlier detection using multiple methods"""
    
    def __init__(self, contamination: float = 0.1):
        self.contamination = contamination
        self.detectors_ = {}
        self.outlier_scores_ = {}
        
    @performance_monitor
    def detect_outliers_comprehensive(self, df: pd.DataFrame, 
                                    methods: List[str] = None) -> Dict[str, OutlierAnalysis]:
        """Comprehensive outlier detection using multiple methods"""
        
        if methods is None:
            methods = ['statistical', 'isolation_forest', 'local_outlier_factor', 
                      'one_class_svm', 'dbscan', 'elliptic_envelope']
        
        numerical_columns = df.select_dtypes(include=[np.number]).columns
        outlier_analysis = {}
        
        for col in numerical_columns:
            column_data = df[col].dropna()
            
            if len(column_data) < 10:  # Skip columns with too few values
                continue
            
            outlier_results = {}
            
            for method in methods:
                try:
                    outliers = self._detect_outliers_single_method(column_data, method)
                    outlier_results[method] = outliers
                except Exception as e:
                    logger.warning(f"Error in {method} for column {col}: {e}")
                    continue
            
            # Combine results using ensemble approach
            combined_outliers = self._combine_outlier_results(outlier_results, column_data.index)
            
            # Calculate severity score
            severity_score = self._calculate_outlier_severity(column_data, combined_outliers)
            
            # Recommend action
            recommended_action = self._recommend_outlier_action(
                len(combined_outliers), len(column_data), severity_score
            )
            
            outlier_analysis[col] = OutlierAnalysis(
                column_name=col,
                outlier_indices=combined_outliers.tolist(),
                outlier_count=len(combined_outliers),
                outlier_percentage=(len(combined_outliers) / len(column_data)) * 100,
                detection_method="ensemble",
                severity_score=severity_score,
                recommended_action=recommended_action
            )
        
        return outlier_analysis
    
    def _detect_outliers_single_method(self, data: pd.Series, method: str) -> np.ndarray:
        """Detect outliers using a single method"""
        
        data_array = data.values.reshape(-1, 1)
        
        if method == 'statistical':
            # IQR method
            q1, q3 = np.percentile(data, [25, 75])
            iqr = q3 - q1
            lower_bound = q1 - 1.5 * iqr
            upper_bound = q3 + 1.5 * iqr
            outliers = data.index[(data < lower_bound) | (data > upper_bound)]
            
        elif method == 'zscore':
            # Z-score method
            z_scores = np.abs(zscore(data))
            outliers = data.index[z_scores > 3]
            
        elif method == 'modified_zscore':
            # Modified Z-score using median
            median = np.median(data)
            mad = median_abs_deviation(data)
            modified_z_scores = 0.6745 * (data - median) / mad
            outliers = data.index[np.abs(modified_z_scores) > 3.5]
            
        elif method == 'isolation_forest':
            detector = IsolationForest(contamination=self.contamination, random_state=42)
            outlier_labels = detector.fit_predict(data_array)
            outliers = data.index[outlier_labels == -1]
            
        elif method == 'local_outlier_factor':
            detector = LocalOutlierFactor(contamination=self.contamination)
            outlier_labels = detector.fit_predict(data_array)
            outliers = data.index[outlier_labels == -1]
            
        elif method == 'one_class_svm':
            detector = OneClassSVM(nu=self.contamination)
            outlier_labels = detector.fit_predict(data_array)
            outliers = data.index[outlier_labels == -1]
            
        elif method == 'elliptic_envelope':
            detector = EllipticEnvelope(contamination=self.contamination)
            outlier_labels = detector.fit_predict(data_array)
            outliers = data.index[outlier_labels == -1]
            
        elif method == 'dbscan':
            # DBSCAN clustering - outliers are noise points
            detector = DBSCAN(eps=0.5, min_samples=5)
            cluster_labels = detector.fit_predict(data_array)
            outliers = data.index[cluster_labels == -1]
            
        else:
            raise ValueError(f"Unknown outlier detection method: {method}")
        
        return outliers.values
    
    def _combine_outlier_results(self, outlier_results: Dict[str, np.ndarray], 
                               original_index: pd.Index) -> np.ndarray:
        """Combine outlier detection results using voting"""
        
        outlier_votes = defaultdict(int)
        
        for method, outliers in outlier_results.items():
            for outlier_idx in outliers:
                outlier_votes[outlier_idx] += 1
        
        # Require majority vote (more than half of methods)
        threshold = len(outlier_results) / 2
        consensus_outliers = [idx for idx, votes in outlier_votes.items() if votes > threshold]
        
        return np.array(consensus_outliers)
    
    def _calculate_outlier_severity(self, data: pd.Series, outlier_indices: np.ndarray) -> float:
        """Calculate severity score for outliers"""
        
        if len(outlier_indices) == 0:
            return 0.0
        
        # Calculate how far outliers are from the main distribution
        median = data.median()
        mad = median_abs_deviation(data)
        
        outlier_values = data.iloc[outlier_indices]
        distances = np.abs(outlier_values - median) / (mad + 1e-8)
        
        # Average distance as severity score
        return np.mean(distances)
    
    def _recommend_outlier_action(self, outlier_count: int, total_count: int, 
                                severity_score: float) -> str:
        """Recommend action for handling outliers"""
        
        outlier_percentage = (outlier_count / total_count) * 100
        
        if outlier_percentage > 25:
            return "investigate_data_collection"
        elif outlier_percentage > 10:
            return "winsorize"
        elif severity_score > 10:
            return "remove"
        elif severity_score > 5:
            return "cap"
        else:
            return "keep"

class AdvancedDataScaler:
    """Advanced data scaling with automatic method selection"""
    
    def __init__(self):
        self.scalers_ = {}
        self.scaling_recommendations_ = {}
        
    @performance_monitor
    def analyze_scaling_requirements(self, df: pd.DataFrame, 
                                   target_col: str = None) -> Dict[str, str]:
        """Analyze scaling requirements for each numerical column"""
        
        numerical_columns = df.select_dtypes(include=[np.number]).columns
        scaling_recommendations = {}
        
        for col in numerical_columns:
            if col == target_col:
                continue
                
            data = df[col].dropna()
            recommendation = self._recommend_scaling_method(data)
            scaling_recommendations[col] = recommendation
        
        self.scaling_recommendations_ = scaling_recommendations
        return scaling_recommendations
    
    def _recommend_scaling_method(self, data: pd.Series) -> str:
        """Recommend appropriate scaling method based on data characteristics"""
        
        # Calculate distribution characteristics
        skewness = stats.skew(data)
        kurtosis = stats.kurtosis(data)
        
        # Calculate outlier ratio
        q1, q3 = np.percentile(data, [25, 75])
        iqr = q3 - q1
        lower_bound = q1 - 1.5 * iqr
        upper_bound = q3 + 1.5 * iqr
        outlier_ratio = ((data < lower_bound) | (data > upper_bound)).sum() / len(data)
        
        # Calculate range
        data_range = data.max() - data.min()
        
        # Normality test
        _, p_value = normaltest(data)
        is_normal = p_value > 0.05
        
        # Decision logic
        if outlier_ratio > 0.1:
            return "robust"
        elif abs(skewness) > 2 or abs(kurtosis) > 3:
            return "quantile"
        elif not is_normal and (data > 0).all():
            return "power_transformer"
        elif data_range > 1000:
            return "standard"
        elif (data >= 0).all() and (data <= 1).all():
            return "none"  # Already normalized
        else:
            return "minmax"
    
    def fit_scalers(self, df: pd.DataFrame, target_col: str = None) -> Dict[str, Any]:
        """Fit appropriate scalers for each column"""
        
        if not self.scaling_recommendations_:
            self.analyze_scaling_requirements(df, target_col)
        
        fitted_scalers = {}
        
        for col, method in self.scaling_recommendations_.items():
            if method == "none":
                fitted_scalers[col] = None
                continue
            
            scaler = self._create_scaler(method)
            data = df[[col]].dropna()
            
            if len(data) > 0:
                scaler.fit(data)
                fitted_scalers[col] = scaler
            else:
                fitted_scalers[col] = None
        
        self.scalers_ = fitted_scalers
        return fitted_scalers
    
    def _create_scaler(self, method: str):
        """Create scaler instance based on method"""
        
        scalers = {
            "standard": StandardScaler(),
            "minmax": MinMaxScaler(),
            "robust": RobustScaler(),
            "quantile": QuantileTransformer(output_distribution='normal'),
            "power_transformer": PowerTransformer(method='yeo-johnson'),
            "maxabs": MaxAbsScaler(),
            "normalizer": Normalizer()
        }
        
        return scalers.get(method, StandardScaler())
    
    def transform_data(self, df: pd.DataFrame) -> pd.DataFrame:
        """Transform data using fitted scalers"""
        
        df_scaled = df.copy()
        
        for col, scaler in self.scalers_.items():
            if scaler is not None and col in df.columns:
                # Handle missing values before scaling
                mask = df[col].notna()
                if mask.sum() > 0:
                    df_scaled.loc[mask, col] = scaler.transform(df.loc[mask, [col]]).flatten()
        
        return df_scaled

    def _summarize_missing_analysis(self, missing_analysis: Dict[str, MissingValueAnalysis]) -> Dict[str, Any]:
        """Summarize missing value analysis results"""
        
        total_missing = sum(analysis.missing_count for analysis in missing_analysis.values())
        columns_with_missing = len([a for a in missing_analysis.values() if a.missing_count > 0])
        
        # Group by recommended strategy
        strategy_counts = defaultdict(int)
        for analysis in missing_analysis.values():
            strategy_counts[analysis.recommended_strategy] += 1
        
        return {
            'total_missing_values': total_missing,
            'columns_with_missing': columns_with_missing,
            'strategy_recommendations': dict(strategy_counts),
            'high_missing_columns': [
                analysis.column_name for analysis in missing_analysis.values()
                if analysis.missing_percentage > 20
            ]
        }
    
    def _summarize_outlier_analysis(self, outlier_analysis: Dict[str, OutlierAnalysis]) -> Dict[str, Any]:
        """Summarize outlier analysis results"""
        
        total_outliers = sum(analysis.outlier_count for analysis in outlier_analysis.values())
        columns_with_outliers = len([a for a in outlier_analysis.values() if a.outlier_count > 0])
        
        # Group by recommended action
        action_counts = defaultdict(int)
        for analysis in outlier_analysis.values():
            action_counts[analysis.recommended_action] += 1
        
        return {
            'total_outliers': total_outliers,
            'columns_with_outliers': columns_with_outliers,
            'action_recommendations': dict(action_counts),
            'severe_outlier_columns': [
                analysis.column_name for analysis in outlier_analysis.values()
                if analysis.severity_score > 5
            ]
        }
    
    def _analyze_data_type_issues(self, df: pd.DataFrame) -> Dict[str, Any]:
        """Analyze data type related issues"""
        
        issues = {
            'mixed_types': [],
            'potential_dates': [],
            'potential_categories': [],
            'high_cardinality_objects': []
        }
        
        for col in df.columns:
            # Check for mixed types in object columns
            if df[col].dtype == 'object':
                sample_types = set(type(x).__name__ for x in df[col].dropna().sample(min(100, len(df[col].dropna()))))
                if len(sample_types) > 1:
                    issues['mixed_types'].append(col)
                
                # Check for potential date columns
                if any(keyword in col.lower() for keyword in ['date', 'time', 'created', 'updated']):
                    issues['potential_dates'].append(col)
                
                # Check for high cardinality
                unique_ratio = df[col].nunique() / len(df)
                if unique_ratio > 0.5:
                    issues['high_cardinality_objects'].append(col)
                elif unique_ratio < 0.1:
                    issues['potential_categories'].append(col)
        
        return issues
    
    def _calculate_quality_score(self, df: pd.DataFrame, missing_summary: Dict[str, Any],
                               outlier_summary: Dict[str, Any], data_type_issues: Dict[str, Any],
                               duplicate_count: int) -> float:
        """Calculate overall data quality score (0-100)"""
        
        total_cells = df.shape[0] * df.shape[1]
        
        # Completeness score (40% of total)
        missing_ratio = missing_summary['total_missing_values'] / total_cells
        completeness_score = (1 - missing_ratio) * 40
        
        # Validity score (30% of total)
        outlier_ratio = outlier_summary['total_outliers'] / (df.select_dtypes(include=[np.number]).shape[0] * df.select_dtypes(include=[np.number]).shape[1])
        validity_score = (1 - outlier_ratio) * 30
        
        # Consistency score (20% of total)
        duplicate_ratio = duplicate_count / len(df)
        type_issue_ratio = sum(len(issues) for issues in data_type_issues.values()) / len(df.columns)
        consistency_score = (1 - duplicate_ratio - type_issue_ratio) * 20
        
        # Uniqueness score (10% of total)
        uniqueness_score = 10  # Simplified - would need more sophisticated analysis
        
        total_score = completeness_score + validity_score + consistency_score + uniqueness_score
        return max(0, min(100, total_score))
    
    def _generate_recommendations(self, missing_analysis: Dict[str, MissingValueAnalysis],
                                outlier_analysis: Dict[str, OutlierAnalysis],
                                data_type_issues: Dict[str, Any],
                                duplicate_count: int) -> List[str]:
        """Generate actionable recommendations for data quality improvement"""
        
        recommendations = []
        
        # Missing value recommendations
        high_missing_cols = [a for a in missing_analysis.values() if a.missing_percentage > 20]
        if high_missing_cols:
            recommendations.append(f"Consider removing {len(high_missing_cols)} columns with >20% missing values")
        
        iterative_imputation_cols = [a for a in missing_analysis.values() if a.recommended_strategy == 'iterative_imputation']
        if iterative_imputation_cols:
            recommendations.append(f"Use iterative imputation for {len(iterative_imputation_cols)} columns with complex missing patterns")
        
        # Outlier recommendations
        severe_outliers = [a for a in outlier_analysis.values() if a.severity_score > 5]
        if severe_outliers:
            recommendations.append(f"Investigate {len(severe_outliers)} columns with severe outliers")
        
        # Data type recommendations
        if data_type_issues['mixed_types']:
            recommendations.append(f"Fix mixed data types in {len(data_type_issues['mixed_types'])} columns")
        
        if data_type_issues['potential_dates']:
            recommendations.append(f"Convert {len(data_type_issues['potential_dates'])} potential date columns to datetime")
        
        # Duplicate recommendations
        if duplicate_count > 0:
            recommendations.append(f"Remove {duplicate_count} duplicate records")
        
        return recommendations

                     scaling_methods: Dict[str, str] = None):
            self.missing_strategies = missing_strategies or {}
            self.outlier_actions = outlier_actions or {}
            self.scaling_methods = scaling_methods or {}
            self.fitted_components_ = {}
            
        def fit(self, X: pd.DataFrame, y: pd.Series = None):
            """Fit the data quality pipeline"""
            
            # Fit missing value imputers
            for col, strategy in self.missing_strategies.items():
                if col in X.columns and strategy in ['knn', 'iterative']:

                        imputer = IterativeImputer(random_state=42)

                if col in X.columns and method != 'none':
                    scaler = quality_analyzer.scaler._create_scaler(method)
                    scaler.fit(X[[col]].dropna())
                    self.fitted_components_[f'{col}_scaler'] = scaler
            
            return self
        
        def transform(self, X: pd.DataFrame) -> pd.DataFrame:
            """Transform data using fitted pipeline"""
            
            X_transformed = X.copy()
            
            # Apply missing value treatments
            for col, strategy in self.missing_strategies.items():
                if col not in X_transformed.columns:
                    continue
                    
                if strategy == 'median':
                    X_transformed[col] = X_transformed[col].fillna(X_transformed[col].median())
                elif strategy == 'mode':
                    mode_val = X_transformed[col].mode().iloc[0] if not X_transformed[col].mode().empty else 'unknown'

                elif strategy in ['knn', 'iterative']:
                    imputer_key = f'{col}_imputer'
                    if imputer_key in self.fitted_components_:
                        X_transformed[col] = self.fitted_components_[imputer_key].transform(X_transformed[[col]]).flatten()
            
            # Apply outlier treatments
            for col, action in self.outlier_actions.items():
                if col not in X_transformed.columns:
                    continue
                    
                if action == 'cap':
                    lower_cap = X_transformed[col].quantile(0.01)
                    upper_cap = X_transformed[col].quantile(0.99)
                    X_transformed[col] = X_transformed[col].clip(lower=lower_cap, upper=upper_cap)
            
            # Apply scaling
            for col, method in self.scaling_methods.items():
                if col not in X_transformed.columns or method == 'none':
                    continue
                    
                scaler_key = f'{col}_scaler'
                if scaler_key in self.fitted_components_:
                    mask = X_transformed[col].notna()

            return X_transformed
