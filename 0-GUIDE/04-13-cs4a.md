## Key Terms

**Large Language Models (LLMs)**: Massive neural networks trained on extensive text corpora using transformer architectures, capable of understanding and generating human-like text through probabilistic token prediction, enabling complex natural language processing tasks including conversation, summarization, and reasoning.

**Transformer Architecture**: A neural network design utilizing self-attention mechanisms to process sequential data in parallel, enabling efficient training on large datasets and superior performance in natural language understanding through positional encoding and multi-head attention layers.

**LangChain Framework**: A comprehensive Python library designed for building applications with large language models, providing abstractions for prompts, chains, agents, and memory management, enabling complex AI workflows through modular components and integration capabilities.

**Retrieval-Augmented Generation (RAG)**: A hybrid approach combining parametric knowledge from pre-trained language models with non-parametric knowledge retrieved from external databases, enabling models to access up-to-date information and domain-specific knowledge beyond their training data.

**Prompt Engineering**: The systematic design and optimization of input prompts to elicit desired responses from language models, involving techniques like few-shot learning, chain-of-thought reasoning, and role-based prompting to maximize model performance on specific tasks.

**Vector Embeddings**: Dense numerical representations of text chunks stored in high-dimensional spaces where semantic similarity corresponds to geometric proximity, enabling efficient similarity search and retrieval operations in RAG systems.

**API Integration**: The process of connecting applications to language model services through standardized interfaces, enabling programmatic access to model capabilities while managing authentication, rate limiting, and response handling.

**Memory Management**: Techniques for maintaining conversation context and state across multiple interactions with language models, including conversation buffers, summary memories, and entity extraction for coherent long-term dialogues.

**Chain-of-Thought**: A prompting technique that encourages language models to break down complex problems into step-by-step reasoning processes, improving performance on tasks requiring logical thinking and multi-step problem solving.

**Agent Systems**: AI frameworks that combine language models with tools and external services, enabling autonomous task execution through planning, action selection, and iterative refinement based on environmental feedback.

## Theoretical Foundation of Large Language Models

Large Language Models represent a paradigm shift in natural language processing, leveraging transformer architectures trained on massive text corpora to develop sophisticated understanding of language patterns, context, and reasoning. The fundamental mechanism operates through next-token prediction, where models learn probability distributions over vocabulary given preceding context.

The transformer architecture's self-attention mechanism enables models to attend to relevant parts of input sequences regardless of distance, solving the long-range dependency problem that limited previous recurrent architectures. Multi-head attention allows parallel processing of different representation subspaces, capturing diverse linguistic relationships simultaneously.

Pre-training on diverse internet text followed by fine-tuning on specific tasks creates models with broad world knowledge and task-specific capabilities. The emergence of few-shot and zero-shot learning capabilities demonstrates that sufficiently large models develop meta-learning abilities, adapting to new tasks through prompt engineering rather than parameter updates.

RAG systems address the limitation of static knowledge by combining parametric model knowledge with dynamic retrieval from external sources, enabling access to current information and specialized domain knowledge while maintaining the model's reasoning capabilities.

def performance_monitor(func):
    """Decorator for performance monitoring"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.2f}s, "
                   f"Memory: {end_memory - start_memory:.1f}MB")
        return result
    return wrapper

        # Create dynamic Pydantic model
        class DynamicModel(BaseModel):
            pass
        
        # Add fields based on schema
        for field_name, field_info in output_schema.items():
            field_type = field_info.get('type', str)
            field_description = field_info.get('description', '')
            setattr(DynamicModel, field_name, Field(description=field_description))
        
        parser = PydanticOutputParser(pydantic_object=DynamicModel)
        
        # Create prompt with format instructions

                cost_estimate=cb.total_cost,

class DocumentProcessor:
    """Advanced document processing for RAG systems"""
    
    def __init__(self, config: RAGConfig):
        self.config = config
        self.text_splitter = RecursiveCharacterTextSplitter(
            chunk_size=config.chunk_size,
            chunk_overlap=config.chunk_overlap,
            separators=["\n\n", "\n", " ", ""]
        )
    
    @performance_monitor
    def load_documents(self, sources: List[str]) -> List[Document]:
        """Load documents from various sources"""
        documents = []
        
        for source in sources:
            try:
                if source.startswith('http'):
                    # Web content
                    docs = self._load_web_content(source)
                elif source.endswith('.pdf'):
                    # PDF file
                    loader = PyPDFLoader(source)
                    docs = loader.load()
                elif source.endswith('.txt'):
                    # Text file
                    loader = TextLoader(source)
                    docs = loader.load()
                else:
                    # Treat as text content
                    docs = [Document(page_content=source, metadata={"source": "direct_input"})]
                
                documents.extend(docs)
                logger.info(f"Loaded {len(docs)} documents from {source}")
                
            except Exception as e:
                logger.error(f"Failed to load {source}: {e}")
                continue
        
        return documents
    
    def _load_web_content(self, url: str) -> List[Document]:
        """Load content from web URL"""
        try:
            response = requests.get(url, timeout=10)
            response.raise_for_status()
            
            soup = BeautifulSoup(response.content, 'html.parser')
            
            # Remove script and style elements
            for script in soup(["script", "style"]):
                script.decompose()
            
            # Get text content
            text = soup.get_text()
            
            # Clean up text
            lines = (line.strip() for line in text.splitlines())
            chunks = (phrase.strip() for line in lines for phrase in line.split("  "))
            text = ' '.join(chunk for chunk in chunks if chunk)
            
            return [Document(page_content=text, metadata={"source": url})]
            
        except Exception as e:
            logger.error(f"Failed to load web content from {url}: {e}")
            return []
    
    @performance_monitor
    def process_documents(self, documents: List[Document]) -> List[Document]:
        """Process and split documents into chunks"""
        processed_docs = []
        
        for doc in documents:
            # Split document into chunks
            chunks = self.text_splitter.split_documents([doc])
            
            # Add chunk metadata
            for i, chunk in enumerate(chunks):
                chunk.metadata.update({
                    "chunk_id": i,
                    "total_chunks": len(chunks),
                    "chunk_size": len(chunk.page_content),
                    "processed_at": datetime.now().isoformat()
                })
            
            processed_docs.extend(chunks)
        
        logger.info(f"Processed {len(documents)} documents into {len(processed_docs)} chunks")
        return processed_docs
    
    def estimate_token_count(self, text: str, model: str = "gpt-3.5-turbo") -> int:
        """Estimate token count for text"""
        try:
            encoding = tiktoken.encoding_for_model(model)
            return len(encoding.encode(text))
        except:
            # Fallback estimation
            return len(text.split()) * 1.3

class VectorStoreManager:
    """Advanced vector store management for RAG"""
    
    def __init__(self, config: RAGConfig):
        self.config = config
        self.embeddings = None
        self.vector_store = None
        self.retriever = None
        self._initialize_embeddings()
    
    def _initialize_embeddings(self):
        """Initialize embedding model"""
        try:
            # Try OpenAI embeddings first
            if os.getenv("OPENAI_API_KEY"):
                self.embeddings = OpenAIEmbeddings(
                    model=self.config.embedding_model
                )
                logger.info(f"Initialized OpenAI embeddings: {self.config.embedding_model}")
            else:
                # Fallback to HuggingFace embeddings
                self.embeddings = HuggingFaceEmbeddings(
                    model_name="sentence-transformers/all-MiniLM-L6-v2"
                )
                logger.info("Initialized HuggingFace embeddings (fallback)")
                
        except Exception as e:
            logger.error(f"Failed to initialize embeddings: {e}")
            raise
    
    @performance_monitor
    def create_vector_store(self, documents: List[Document], store_type: str = "faiss") -> Any:
        """Create vector store from documents"""
        try:
            if store_type.lower() == "chroma":
                self.vector_store = Chroma.from_documents(
                    documents=documents,
                    embedding=self.embeddings,
                    persist_directory="./chroma_db"
                )
            elif store_type.lower() == "faiss":
                self.vector_store = FAISS.from_documents(
                    documents=documents,
                    embedding=self.embeddings
                )
            else:
                raise ValueError(f"Unsupported vector store type: {store_type}")
            
            # Create retriever
            self.retriever = self.vector_store.as_retriever(
                search_kwargs={"k": self.config.retriever_k}
            )
            
            logger.info(f"Created {store_type} vector store with {len(documents)} documents")
            return self.vector_store
            
        except Exception as e:
            logger.error(f"Failed to create vector store: {e}")
            raise
    
    @performance_monitor
    def similarity_search(self, query: str, k: int = None) -> List[Tuple[Document, float]]:
        """Perform similarity search with scores"""
        if not self.vector_store:
            raise ValueError("Vector store not initialized")
        
        k = k or self.config.retriever_k
        
        # Get documents with similarity scores
        docs_and_scores = self.vector_store.similarity_search_with_score(query, k=k)
        
        # Filter by similarity threshold
        filtered_results = [
            (doc, score) for doc, score in docs_and_scores
            if score >= self.config.similarity_threshold
        ]
        
        logger.info(f"Found {len(filtered_results)} relevant documents for query")
        return filtered_results
    
    @performance_monitor
    def hybrid_search(self, query: str, documents: List[Document]) -> List[Document]:
        """Combine vector and keyword search"""
        if not self.vector_store:
            raise ValueError("Vector store not initialized")
        
        # Vector search
        vector_retriever = self.vector_store.as_retriever(
            search_kwargs={"k": self.config.retriever_k}
        )
        
        # Keyword search (BM25)
        bm25_retriever = BM25Retriever.from_documents(documents)
        bm25_retriever.k = self.config.retriever_k
        
        # Ensemble retriever
        ensemble_retriever = EnsembleRetriever(
            retrievers=[vector_retriever, bm25_retriever],
            weights=[0.7, 0.3]  # Favor vector search
        )
        
        results = ensemble_retriever.get_relevant_documents(query)
        logger.info(f"Hybrid search returned {len(results)} documents")
        return results
    
    def save_vector_store(self, path: str):
        """Save vector store to disk"""
        if isinstance(self.vector_store, FAISS):
            self.vector_store.save_local(path)
        elif isinstance(self.vector_store, Chroma):
            # Chroma auto-persists if persist_directory is set
            pass
        logger.info(f"Vector store saved to {path}")
    
    def load_vector_store(self, path: str, store_type: str = "faiss"):
        """Load vector store from disk"""
        if store_type.lower() == "faiss":
            self.vector_store = FAISS.load_local(path, self.embeddings)
        elif store_type.lower() == "chroma":
            self.vector_store = Chroma(
                persist_directory=path,
                embedding_function=self.embeddings
            )
        
        self.retriever = self.vector_store.as_retriever(
            search_kwargs={"k": self.config.retriever_k}
        )
        logger.info(f"Vector store loaded from {path}")

class RAGSystem:
    """Complete Retrieval-Augmented Generation system"""
    
    def __init__(self, llm_config: LLMConfig, rag_config: RAGConfig):
        self.llm_config = llm_config
        self.rag_config = rag_config
        
        self.llm_manager = AdvancedLLMManager(llm_config)
        self.doc_processor = DocumentProcessor(rag_config)
        self.vector_manager = VectorStoreManager(rag_config)
        
        self.qa_chain = None
        self.memory = ConversationBufferMemory(
            memory_key="chat_history",
            return_messages=True
        )
    
    @performance_monitor
    def setup_knowledge_base(self, sources: List[str]) -> Dict[str, Any]:
        """Setup knowledge base from various sources"""
        
        # Load and process documents
        documents = self.doc_processor.load_documents(sources)
        processed_docs = self.doc_processor.process_documents(documents)
        
        # Create vector store
        self.vector_manager.create_vector_store(processed_docs)
        
        # Setup QA chain
        self._setup_qa_chain()
        
        # Calculate statistics
        total_tokens = sum(
            self.doc_processor.estimate_token_count(doc.page_content)
            for doc in processed_docs
        )
        
        return {
            "total_documents": len(documents),
            "total_chunks": len(processed_docs),
            "estimated_tokens": total_tokens,
            "average_chunk_size": np.mean([len(doc.page_content) for doc in processed_docs]),
            "sources": sources
        }
    
    def _setup_qa_chain(self):
        """Setup QA chain with custom prompt"""
        
        # Custom prompt template
        prompt_template = """
        Use the following pieces of context to answer the question at the end. 
        If you don't know the answer, just say that you don't know, don't try to make up an answer.
        Always provide citations by mentioning the source when possible.
        
        Context:
        {context}
        
        Question: {question}
        
        Answer (with citations):
        """
        
        prompt = PromptTemplate(
            template=prompt_template,
            input_variables=["context", "question"]
        )
        
        # Create QA chain
        self.qa_chain = RetrievalQA.from_chain_type(
            llm=self.llm_manager.chat_model,
            chain_type="stuff",
            retriever=self.vector_manager.retriever,
            chain_type_kwargs={"prompt": prompt},
            return_source_documents=True
        )
    
    @performance_monitor
    def ask_question(self, question: str, include_sources: bool = True) -> Dict[str, Any]:
        """Ask question using RAG system"""
        if not self.qa_chain:
            raise ValueError("Knowledge base not setup. Call setup_knowledge_base first.")
        
        start_time = time.time()
        
        with get_openai_callback() as cb:
            # Get answer from QA chain
            response = self.qa_chain({"query": question})
            
            # Prepare result
            result = {
                "question": question,
                "answer": response["result"],
                "response_time": time.time() - start_time,
                "tokens_used": cb.total_tokens,
                "cost_estimate": cb.total_cost
            }
            
            if include_sources and "source_documents" in response:
                sources = []
                for doc in response["source_documents"]:
                    sources.append({
                        "content": doc.page_content[:200] + "...",
                        "metadata": doc.metadata,
                        "relevance_score": getattr(doc, 'score', None)
                    })
                result["sources"] = sources
                result["source_count"] = len(sources)
        
        # Update memory
        self.memory.chat_memory.add_user_message(question)
        self.memory.chat_memory.add_ai_message(response["result"])
        
        return result
    
    @performance_monitor
    def conversational_qa(self, question: str) -> Dict[str, Any]:
        """Question answering with conversation memory"""
        
        # Get conversation history
        history = self.memory.chat_memory.messages
        
        # Create conversational prompt
        system_message = """You are a helpful AI assistant with access to a knowledge base. 
        Use the retrieved context to answer questions accurately and cite sources when possible.
        Consider the conversation history to provide contextually relevant responses."""
        
        # Format conversation history
        conversation_context = ""
        for msg in history[-6:]:  # Last 6 messages
            if hasattr(msg, 'content'):
                role = "Human" if isinstance(msg, HumanMessage) else "Assistant"
                conversation_context += f"{role}: {msg.content}\n"
        
        # Enhance question with context
        enhanced_question = f"""
        Conversation History:
        {conversation_context}
        
        Current Question: {question}
        
        Please answer the current question considering the conversation history and using the knowledge base.
        """
        
        return self.ask_question(enhanced_question)
    
    @performance_monitor
    def multi_step_reasoning(self, complex_question: str) -> Dict[str, Any]:
        """Handle complex questions requiring multi-step reasoning"""
        
        # Break down complex question
        breakdown_prompt = f"""
        Break down this complex question into simpler sub-questions that can be answered step by step:
        
        Question: {complex_question}
        
        Provide a numbered list of sub-questions:
        """
        
        # Get sub-questions
        breakdown_response, _ = self.llm_manager.simple_completion(breakdown_prompt)
        
        # Extract sub-questions (simple parsing)
        sub_questions = [
            line.strip() 
            for line in breakdown_response.split('\n') 
            if line.strip() and any(line.strip().startswith(str(i)) for i in range(1, 10))
        ]
        
        # Answer each sub-question
        sub_answers = []
        for sub_q in sub_questions[:5]:  # Limit to 5 sub-questions
            try:
                sub_answer = self.ask_question(sub_q, include_sources=False)
                sub_answers.append({
                    "question": sub_q,
                    "answer": sub_answer["answer"]
                })
            except Exception as e:
                logger.warning(f"Failed to answer sub-question: {sub_q}, Error: {e}")
        
        # Synthesize final answer
        synthesis_prompt = f"""
        Based on the following sub-questions and their answers, provide a comprehensive answer to the original question:
        
        Original Question: {complex_question}
        
        Sub-questions and Answers:
        """
        
        for sa in sub_answers:
            synthesis_prompt += f"\nQ: {sa['question']}\nA: {sa['answer']}\n"
        
        synthesis_prompt += f"\nFinal comprehensive answer to '{complex_question}':"
        
        final_answer, metrics = self.llm_manager.simple_completion(synthesis_prompt)
        
        return {
            "original_question": complex_question,
            "sub_questions": sub_questions,
            "sub_answers": sub_answers,
            "final_answer": final_answer,
            "reasoning_steps": len(sub_answers),
            "total_tokens": metrics.total_tokens,
            "response_time": metrics.response_time
        }
    
    def get_system_statistics(self) -> Dict[str, Any]:
        """Get comprehensive system statistics"""
        llm_stats = self.llm_manager.get_usage_statistics()
        
        return {
            "llm_usage": llm_stats,
            "memory_messages": len(self.memory.chat_memory.messages),
            "vector_store_setup": self.vector_manager.vector_store is not None,

class LangChainAgentSystem:
    """Advanced agent system using LangChain"""
    
    def __init__(self, llm_config: LLMConfig):
        self.llm = ChatOpenAI(
            model_name=llm_config.model_name,
            temperature=llm_config.temperature
        )
        self.tools = []
        self.agent = None
        self._setup_tools()
    
    def _setup_tools(self):
        """Setup tools for the agent"""
        
        def web_search_tool(query: str) -> str:
            """Search the web for information"""
            try:
                # Simplified web search (in practice, use real search API)
                search_url = f"https://api.duckduckgo.com/?q={query}&format=json&no_html=1"
                response = requests.get(search_url, timeout=10)
                
                if response.status_code == 200:
                    data = response.json()
                    if data.get('AbstractText'):
                        return data['AbstractText']
                    else:
                        return f"Search completed for '{query}' but no abstract found"
                else:
                    return f"Search failed for query: {query}"
                    
            except Exception as e:
                return f"Error searching for {query}: {str(e)}"
        
        def calculator_tool(expression: str) -> str:
            """Calculate mathematical expressions"""
            try:
                # Safe evaluation of mathematical expressions
                allowed_chars = set('0123456789+-*/.() ')
                if all(c in allowed_chars for c in expression):
                    result = eval(expression)
                    return f"Result: {result}"
                else:
                    return "Invalid mathematical expression"
            except Exception as e:
                return f"Calculation error: {str(e)}"
        
        def text_analyzer_tool(text: str) -> str:
            """Analyze text for basic statistics"""
            try:
                words = text.split()
                sentences = text.count('.') + text.count('!') + text.count('?')
                
                return f"""Text Analysis:
                - Words: {len(words)}
                - Characters: {len(text)}
                - Sentences: {sentences}
                - Average words per sentence: {len(words)/max(sentences, 1):.1f}
                """
            except Exception as e:
                return f"Analysis error: {str(e)}"
        
        # Create tool objects
        self.tools = [
            Tool(
                name="WebSearch",
                func=web_search_tool,
                description="Search the web for current information about any topic"
            ),
            Tool(
                name="Calculator",
                func=calculator_tool,
                description="Calculate mathematical expressions"
            ),
            Tool(
                name="TextAnalyzer",
                func=text_analyzer_tool,
                description="Analyze text for basic statistics and metrics"
            )
        ]
        
        # Initialize agent
        self.agent = initialize_agent(
            tools=self.tools,
            llm=self.llm,
            agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
            verbose=True,
            handle_parsing_errors=True
        )
    
    @performance_monitor
    def run_agent(self, task: str) -> Dict[str, Any]:
        """Run agent with specific task"""
        start_time = time.time()
        
        try:
            with get_openai_callback() as cb:
                response = self.agent.run(task)
                
                return {
                    "task": task,
                    "response": response,
                    "tokens_used": cb.total_tokens,
                    "cost_estimate": cb.total_cost,
                    "execution_time": time.time() - start_time,
                    "tools_available": [tool.name for tool in self.tools]
                }
        except Exception as e:
            return {
                "task": task,
                "error": str(e),
                "execution_time": time.time() - start_time
            }
