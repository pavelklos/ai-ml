# 12. Dimensionality Reduction and Embedding Techniques

## Key Terms and Concepts

**Dimensionality Reduction**: The process of reducing the number of features (dimensions) in a dataset while preserving the most important information. This technique addresses the "curse of dimensionality" where high-dimensional data becomes sparse and computationally expensive to process.

**Principal Component Analysis (PCA)**: A linear dimensionality reduction technique that transforms data to lower-dimensional space by finding principal components that capture maximum variance in the data. These components are orthogonal linear combinations of original features.

**t-SNE (t-Distributed Stochastic Neighbor Embedding)**: A non-linear dimensionality reduction technique primarily used for data visualization. It preserves local neighborhood structures and is particularly effective for visualizing high-dimensional data in 2D or 3D space.

**Embeddings**: Dense vector representations of discrete objects (words, sentences, images) in a continuous vector space where semantic similarity is captured by geometric proximity. These vectors encode meaningful relationships and properties of the original data.

**Curse of Dimensionality**: The phenomenon where the performance of machine learning algorithms degrades as the number of dimensions increases, due to data sparsity and increased computational complexity.

**Manifold Learning**: The assumption that high-dimensional data lies on or near a lower-dimensional manifold embedded in the high-dimensional space.

## Reasons for Dimensionality Reduction

### Computational Efficiency
High-dimensional datasets require exponentially more computational resources. Reducing dimensions significantly decreases training time and memory usage while maintaining model performance.

### Visualization and Interpretation
Human perception is limited to 2D and 3D visualizations. Dimensionality reduction enables visualization of complex, high-dimensional data patterns and relationships.

### Noise Reduction
Real-world data often contains noise and irrelevant features. Dimensionality reduction techniques can filter out noise while preserving signal, leading to better model performance.

### Storage Optimization
Lower-dimensional representations require less storage space, making data handling more efficient for large-scale applications.

### Avoiding Overfitting
High-dimensional spaces can lead to overfitting, especially with limited training data. Dimensionality reduction helps create more generalizable models.

## Principal Component Analysis (PCA)

PCA finds orthogonal components that capture maximum variance in the data. The first principal component explains the most variance, the second explains the most remaining variance, and so on.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import load_digits, fetch_openml
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, accuracy_score
import warnings
warnings.filterwarnings('ignore')

# Load high-dimensional dataset
digits = load_digits()
X, y = digits.data, digits.target

print(f"Original data shape: {X.shape}")
print(f"Number of classes: {len(np.unique(y))}")

# Standardize the data (important for PCA)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Apply PCA with different numbers of components
pca_full = PCA()
X_pca_full = pca_full.fit_transform(X_scaled)

# Calculate cumulative explained variance ratio
cumulative_variance = np.cumsum(pca_full.explained_variance_ratio_)

# Find number of components for 95% variance
n_components_95 = np.argmax(cumulative_variance >= 0.95) + 1
print(f"Components needed for 95% variance: {n_components_95}")

# Apply PCA with optimal number of components
pca_optimal = PCA(n_components=n_components_95)
X_pca_reduced = pca_optimal.fit_transform(X_scaled)

print(f"Reduced data shape: {X_pca_reduced.shape}")
print(f"Variance explained: {pca_optimal.explained_variance_ratio_.sum():.4f}")

# Visualize explained variance
plt.figure(figsize=(12, 4))

plt.subplot(1, 2, 1)
plt.plot(range(1, len(cumulative_variance) + 1), cumulative_variance)
plt.axhline(y=0.95, color='r', linestyle='--', label='95% Variance')
plt.axvline(x=n_components_95, color='r', linestyle='--')
plt.xlabel('Number of Components')
plt.ylabel('Cumulative Explained Variance')
plt.title('PCA Explained Variance')
plt.legend()
plt.grid(True)

plt.subplot(1, 2, 2)
plt.bar(range(1, 11), pca_optimal.explained_variance_ratio_[:10])
plt.xlabel('Principal Component')
plt.ylabel('Explained Variance Ratio')
plt.title('Individual Component Variance (First 10)')
plt.grid(True)

plt.tight_layout()
plt.show()

# Compare model performance: Original vs PCA-reduced
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.3, random_state=42)
X_train_pca, X_test_pca, _, _ = train_test_split(X_pca_reduced, y, test_size=0.3, random_state=42)

# Train models
rf_original = RandomForestClassifier(n_estimators=100, random_state=42)
rf_pca = RandomForestClassifier(n_estimators=100, random_state=42)

rf_original.fit(X_train, y_train)
rf_pca.fit(X_train_pca, y_train)

# Evaluate models
y_pred_original = rf_original.predict(X_test)
y_pred_pca = rf_pca.predict(X_test_pca)

print("Original Data Performance:")
print(f"Accuracy: {accuracy_score(y_test, y_pred_original):.4f}")

print("\nPCA-Reduced Data Performance:")
print(f"Accuracy: {accuracy_score(y_test, y_pred_pca):.4f}")
print(f"Dimensionality reduction: {X.shape[1]} -> {X_pca_reduced.shape[1]} ({(1 - X_pca_reduced.shape[1]/X.shape[1])*100:.1f}% reduction)")
```

## Text Processing with Embeddings

Modern embedding techniques transform text into dense vector representations that capture semantic meaning.

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from gensim.models import Word2Vec
from sentence_transformers import SentenceTransformer
import nltk
from nltk.tokenize import word_tokenize, sent_tokenize
from nltk.corpus import stopwords
import re

# Download required NLTK data
nltk.download('punkt', quiet=True)
nltk.download('stopwords', quiet=True)

# Sample text data
documents = [
    "Machine learning algorithms can automatically learn patterns from data without explicit programming.",
    "Deep learning uses neural networks with multiple layers to process complex information.",
    "Natural language processing enables computers to understand and generate human language.",
    "Computer vision allows machines to interpret and analyze visual information from images.",
    "Artificial intelligence encompasses various techniques for creating intelligent systems.",
    "Data science combines statistics, programming, and domain expertise to extract insights.",
    "Big data technologies handle massive volumes of structured and unstructured information.",
    "Cloud computing provides scalable infrastructure for modern applications and services.",
    "Cybersecurity protects digital assets from threats and unauthorized access attempts.",
    "Software engineering involves systematic approaches to designing and building applications."
]

# Text preprocessing
def preprocess_text(text):
    # Convert to lowercase and remove special characters
    text = re.sub(r'[^a-zA-Z\s]', '', text.lower())
    # Tokenize and remove stopwords
    tokens = word_tokenize(text)
    stop_words = set(stopwords.words('english'))
    tokens = [token for token in tokens if token not in stop_words and len(token) > 2]
    return tokens

# Preprocess documents
processed_docs = [preprocess_text(doc) for doc in documents]

# Traditional TF-IDF embeddings
tfidf = TfidfVectorizer(max_features=1000, stop_words='english')
tfidf_matrix = tfidf.fit_transform(documents)

print(f"TF-IDF matrix shape: {tfidf_matrix.shape}")
print(f"TF-IDF feature names (first 10): {tfidf.get_feature_names_out()[:10]}")

# Word2Vec embeddings
word2vec_model = Word2Vec(sentences=processed_docs, vector_size=100, 
                         window=5, min_count=1, workers=4, sg=1)

# Get word vectors
def get_document_vector(doc_tokens, model):
    vectors = []
    for token in doc_tokens:
        if token in model.wv:
            vectors.append(model.wv[token])
    if vectors:
        return np.mean(vectors, axis=0)
    else:
        return np.zeros(model.vector_size)

word2vec_embeddings = np.array([get_document_vector(doc, word2vec_model) 
                               for doc in processed_docs])

print(f"Word2Vec embeddings shape: {word2vec_embeddings.shape}")

# Modern Sentence Transformers
# Note: This requires internet connection to download the model
try:
    sentence_model = SentenceTransformer('all-MiniLM-L6-v2')
    sentence_embeddings = sentence_model.encode(documents)
    print(f"Sentence embeddings shape: {sentence_embeddings.shape}")
    
    # Compute similarity matrix
    from sklearn.metrics.pairwise import cosine_similarity
    
    similarity_matrix = cosine_similarity(sentence_embeddings)
    
    # Visualize similarity matrix
    plt.figure(figsize=(10, 8))
    sns.heatmap(similarity_matrix, annot=True, cmap='viridis', 
                xticklabels=range(len(documents)), 
                yticklabels=range(len(documents)))
    plt.title('Document Similarity Matrix (Sentence Embeddings)')
    plt.xlabel('Document Index')
    plt.ylabel('Document Index')
    plt.show()
    
except Exception as e:
    print(f"Sentence Transformers not available: {e}")
    print("Install with: pip install sentence-transformers")
```

## Building a Simple Neural Network for Embeddings

Creating custom embeddings using neural networks for specific tasks.

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential, Model
from tensorflow.keras.layers import Dense, Embedding, Flatten, Input
from tensorflow.keras.preprocessing.text import Tokenizer
from tensorflow.keras.preprocessing.sequence import pad_sequences
from tensorflow.keras.utils import to_categorical

# Set random seeds for reproducibility
tf.random.set_seed(42)
np.random.seed(42)

# Prepare text data for neural network
tokenizer = Tokenizer(num_words=1000, oov_token='<OOV>')
tokenizer.fit_on_texts(documents)

# Convert texts to sequences
sequences = tokenizer.texts_to_sequences(documents)
max_length = max(len(seq) for seq in sequences)
padded_sequences = pad_sequences(sequences, maxlen=max_length, padding='post')

print(f"Vocabulary size: {len(tokenizer.word_index)}")
print(f"Max sequence length: {max_length}")
print(f"Padded sequences shape: {padded_sequences.shape}")

# Create labels for classification (document categories)
# For demonstration, we'll create artificial categories
labels = np.array([0, 1, 2, 3, 1, 0, 0, 3, 3, 1])  # Tech categories
labels_categorical = to_categorical(labels, num_classes=4)

# Build neural network with embedding layer
vocab_size = len(tokenizer.word_index) + 1
embedding_dim = 50

model = Sequential([
    Embedding(vocab_size, embedding_dim, input_length=max_length),
    Flatten(),
    Dense(128, activation='relu'),
    Dense(64, activation='relu'),
    Dense(4, activation='softmax')  # 4 categories
])

model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
model.summary()

# Train the model
history = model.fit(padded_sequences, labels_categorical, 
                   epochs=50, batch_size=2, verbose=0)

# Extract learned embeddings
embedding_layer = model.layers[0]
embeddings = embedding_layer.get_weights()[0]

print(f"Learned embeddings shape: {embeddings.shape}")

# Visualize training history
plt.figure(figsize=(12, 4))

plt.subplot(1, 2, 1)
plt.plot(history.history['loss'])
plt.title('Model Loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.grid(True)

plt.subplot(1, 2, 2)
plt.plot(history.history['accuracy'])
plt.title('Model Accuracy')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.grid(True)

plt.tight_layout()
plt.show()

# Create embedding visualization using t-SNE
word_embeddings_sample = embeddings[1:101]  # Skip padding token, take first 100 words
tsne_embeddings = TSNE(n_components=2, random_state=42).fit_transform(word_embeddings_sample)

# Get words for visualization
word_list = list(tokenizer.word_index.keys())[:100]

plt.figure(figsize=(12, 8))
plt.scatter(tsne_embeddings[:, 0], tsne_embeddings[:, 1], alpha=0.7)
for i, word in enumerate(word_list):
    plt.annotate(word, (tsne_embeddings[i, 0], tsne_embeddings[i, 1]), 
                fontsize=8, alpha=0.7)
plt.title('Word Embeddings Visualization (t-SNE)')
plt.xlabel('t-SNE 1')
plt.ylabel('t-SNE 2')
plt.grid(True, alpha=0.3)
plt.show()
```

## Practical Implementation Tips

```python
# Best practices for dimensionality reduction
class DimensionalityReducer:
    def __init__(self, method='pca', n_components=None, **kwargs):
        self.method = method
        self.n_components = n_components
        self.kwargs = kwargs
        self.reducer = None
        self.scaler = StandardScaler()
        
    def fit(self, X, y=None):
        # Always scale data first
        X_scaled = self.scaler.fit_transform(X)
        
        if self.method == 'pca':
            if self.n_components is None:
                # Find optimal components for 95% variance
                pca_temp = PCA()
                pca_temp.fit(X_scaled)
                cumvar = np.cumsum(pca_temp.explained_variance_ratio_)
                self.n_components = np.argmax(cumvar >= 0.95) + 1
            
            self.reducer = PCA(n_components=self.n_components, **self.kwargs)
            
        elif self.method == 'tsne':
            self.reducer = TSNE(n_components=self.n_components or 2, **self.kwargs)
            
        self.reducer.fit(X_scaled)
        return self
    
    def transform(self, X):
        X_scaled = self.scaler.transform(X)
        return self.reducer.transform(X_scaled)
    
    def fit_transform(self, X, y=None):
        return self.fit(X, y).transform(X)
    
    def get_feature_importance(self):
        if hasattr(self.reducer, 'components_'):
            return np.abs(self.reducer.components_).mean(axis=0)
        return None

# Usage example
reducer = DimensionalityReducer(method='pca')
X_reduced = reducer.fit_transform(X)

print(f"Optimal components: {reducer.n_components}")
print(f"Explained variance: {reducer.reducer.explained_variance_ratio_.sum():.4f}")

# Feature importance from PCA
importance = reducer.get_feature_importance()
if importance is not None:
    top_features = np.argsort(importance)[-10:]
    plt.figure(figsize=(10, 6))
    plt.barh(range(len(top_features)), importance[top_features])
    plt.title('Top 10 Most Important Original Features (PCA)')
    plt.xlabel('Importance Score')
    plt.ylabel('Feature Index')
    plt.grid(True, alpha=0.3)
    plt.show()
```

## Conclusion

Dimensionality reduction and embedding techniques are fundamental tools in modern machine learning that address the challenges of high-dimensional data. This section covered both linear methods like PCA, which preserve global structure and maximize variance, and non-linear methods like t-SNE, which excel at preserving local neighborhoods for visualization.

Key takeaways include understanding when to apply different techniques: PCA for computational efficiency and interpretability, t-SNE for data exploration and visualization, and neural network-based approaches for learning task-specific representations. The practical implementations demonstrate how these methods can dramatically reduce computational requirements while maintaining or even improving model performance.

Modern embedding techniques, particularly for text processing, represent a paradigm shift from sparse, high-dimensional representations to dense, semantically meaningful vectors. These embeddings capture complex relationships that traditional methods often miss, making them essential for natural language processing and other domains dealing with discrete data.

The combination of classical statistical methods with modern deep learning approaches provides a comprehensive toolkit for handling high-dimensional data effectively. Understanding the theoretical foundations and practical limitations of each method enables informed decision-making in real-world applications where data efficiency and interpretability are crucial considerations.
