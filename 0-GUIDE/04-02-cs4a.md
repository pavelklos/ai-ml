## Key Terms

**Linear Regression**: A fundamental statistical learning method that models the relationship between a dependent variable and one or more independent variables by fitting a linear equation to observed data, enabling prediction of continuous target values based on input features.

**Ordinary Least Squares (OLS)**: The mathematical optimization method used to estimate linear regression parameters by minimizing the sum of squared residuals between observed and predicted values, providing the best linear unbiased estimator under specific assumptions.

**Coefficients Interpretation**: The slope parameters in linear regression that quantify the expected change in the dependent variable for a one-unit change in each independent variable, holding all other variables constant, providing insights into feature importance and relationship direction.

**Residuals**: The differences between observed and predicted values that capture the unexplained variance in the model, used for diagnostic analysis to validate regression assumptions and identify potential model improvements.

**R-squared (Coefficient of Determination)**: A statistical measure representing the proportion of variance in the dependent variable explained by the independent variables, ranging from 0 to 1, with higher values indicating better model fit.

**Multicollinearity**: A phenomenon where independent variables are highly correlated with each other, potentially causing instability in coefficient estimates and reducing the reliability of individual variable interpretations.

**Homoscedasticity**: The assumption that residuals have constant variance across all levels of predicted values, essential for valid statistical inference and confidence interval construction in linear regression.

**Feature Scaling**: The process of standardizing or normalizing input features to ensure they contribute equally to the model training process, particularly important when features have different units or scales.

## Theoretical Foundation of Linear Regression

Linear regression serves as the cornerstone of statistical learning, providing both interpretable insights and predictive capabilities through mathematical modeling of linear relationships. The method assumes a linear relationship between features and target variables, making it invaluable for understanding data patterns and establishing baseline performance benchmarks.

The mathematical foundation rests on the assumption that the relationship between features X and target y can be expressed as: y = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ + ε, where β coefficients represent the linear effects of each feature, and ε captures random noise. The ordinary least squares method finds optimal coefficients by minimizing the sum of squared residuals, providing both point estimates and uncertainty quantification.

def performance_monitor(func):
    """Decorator to monitor function performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024  # MB
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024  # MB
        
        logger.info(f"{func.__name__} - Execution time: {end_time - start_time:.4f}s, "
                   f"Memory change: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class BaseRegressor(ABC):
    """Abstract base class for regression models"""
    
    def __init__(self):
        self.model = None
        self.is_fitted = False
        self.feature_names = None
        self.training_metrics = None
        
    @abstractmethod
    def fit(self, X: np.ndarray, y: np.ndarray) -> 'BaseRegressor':
        """Fit the regression model"""
        pass
        
    @abstractmethod
    def predict(self, X: np.ndarray) -> np.ndarray:
        """Make predictions using the fitted model"""
        pass
        
    def get_coefficients(self) -> Dict[str, float]:
        """Get model coefficients with feature names"""
        if not self.is_fitted:
            raise ValueError("Model must be fitted before accessing coefficients")
        return dict(zip(self.feature_names, self.model.coef_))

class AdvancedLinearRegression(BaseRegressor):
    """Advanced linear regression with comprehensive diagnostics"""
    
    def __init__(self, regularization: str = 'none', alpha: float = 1.0,
                 l1_ratio: float = 0.5, robust: bool = False):
        super().__init__()
        self.regularization = regularization
        self.alpha = alpha
        self.l1_ratio = l1_ratio
        self.robust = robust
        self.scaler = None
        self.polynomial_features = None
        self._initialize_model()
        
    def _initialize_model(self):
        """Initialize the appropriate regression model"""
        if self.robust:
            self.model = HuberRegressor(alpha=self.alpha)
        elif self.regularization == 'ridge':
            self.model = Ridge(alpha=self.alpha)
        elif self.regularization == 'lasso':
            self.model = Lasso(alpha=self.alpha, max_iter=2000)
        elif self.regularization == 'elastic_net':
            self.model = ElasticNet(alpha=self.alpha, l1_ratio=self.l1_ratio, max_iter=2000)
        else:
            self.model = LinearRegression()
    
    @performance_monitor
    def fit(self, X: np.ndarray, y: np.ndarray, feature_names: List[str] = None,
            scale_features: bool = True, polynomial_degree: int = 1) -> 'AdvancedLinearRegression':
        """Fit the linear regression model with optional preprocessing"""
        
        # Store feature names
        if feature_names is not None:
            self.feature_names = feature_names
        else:
            self.feature_names = [f'feature_{i}' for i in range(X.shape[1])]
        
        # Create polynomial features if specified
        if polynomial_degree > 1:
            self.polynomial_features = PolynomialFeatures(
                degree=polynomial_degree, include_bias=False
            )
            X = self.polynomial_features.fit_transform(X)
            
            # Update feature names for polynomial features
            self.feature_names = self.polynomial_features.get_feature_names_out(self.feature_names)
        
        # Scale features if requested
        if scale_features:
            self.scaler = StandardScaler()
            X = self.scaler.fit_transform(X)
        
        # Fit the model
        self.model.fit(X, y)
        self.is_fitted = True
        
        # Calculate training metrics
        y_pred = self.model.predict(X)
        self.training_metrics = self._calculate_metrics(y, y_pred, X.shape[1])
        
        logger.info(f"Model fitted with R² = {self.training_metrics.r2:.4f}")
        return self
    
    def predict(self, X: np.ndarray) -> np.ndarray:
        """Make predictions using the fitted model"""
        if not self.is_fitted:
            raise ValueError("Model must be fitted before making predictions")
        
        # Apply polynomial transformation if used
        if self.polynomial_features is not None:
            X = self.polynomial_features.transform(X)
        
        # Apply scaling if used
        if self.scaler is not None:
            X = self.scaler.transform(X)
        
        return self.model.predict(X)
    
    def predict_with_intervals(self, X: np.ndarray, alpha: float = 0.05) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
        """Predict with confidence and prediction intervals"""
        predictions = self.predict(X)
        
        # For simplicity, using approximate intervals
        # In practice, you'd use more sophisticated methods
        residual_std = np.sqrt(self.training_metrics.mse)
        z_score = stats.norm.ppf(1 - alpha/2)
        
        # Approximate prediction intervals
        interval_width = z_score * residual_std
        lower_bound = predictions - interval_width
        upper_bound = predictions + interval_width
        
        return predictions, lower_bound, upper_bound
    
    def _calculate_metrics(self, y_true: np.ndarray, y_pred: np.ndarray, n_features: int) -> RegressionMetrics:
        """Calculate comprehensive regression metrics"""
        n_samples = len(y_true)
        
        mse = mean_squared_error(y_true, y_pred)
        rmse = np.sqrt(mse)
        mae = mean_absolute_error(y_true, y_pred)
        r2 = r2_score(y_true, y_pred)
        
        # Adjusted R-squared
        adjusted_r2 = 1 - (1 - r2) * (n_samples - 1) / (n_samples - n_features - 1)
        
        # MAPE (handle division by zero)
        mape = mean_absolute_percentage_error(y_true, y_pred) if np.all(y_true != 0) else np.inf
        
        explained_variance = explained_variance_score(y_true, y_pred)
        
        # AIC and BIC approximations
        aic = n_samples * np.log(mse) + 2 * n_features
        bic = n_samples * np.log(mse) + n_features * np.log(n_samples)
        
        return RegressionMetrics(
            mse=mse, rmse=rmse, mae=mae, r2=r2, adjusted_r2=adjusted_r2,
            mape=mape, explained_variance=explained_variance, aic=aic, bic=bic
        )

class RegressionDiagnostics:
    """Comprehensive regression diagnostics and assumption testing"""
    
    def __init__(self, model: AdvancedLinearRegression, X: np.ndarray, y: np.ndarray):
        self.model = model
        self.X = X
        self.y = y
        self.y_pred = model.predict(X)
        self.residuals = y - self.y_pred
        
    @performance_monitor
    def run_full_diagnostics(self) -> DiagnosticResults:
        """Run comprehensive regression diagnostics"""
        
        results = DiagnosticResults(
            normality_test=self._test_normality(),
            homoscedasticity_test=self._test_homoscedasticity(),
            autocorrelation_test=self._test_autocorrelation(),
            multicollinearity_vif=self._calculate_vif(),
            outlier_detection=self._detect_outliers(),
            residual_analysis=self._analyze_residuals()
        )
        
        self._print_diagnostic_summary(results)
        return results
    
    def _test_normality(self) -> Dict[str, float]:
        """Test normality of residuals using multiple tests"""
        
        # Jarque-Bera test
        jb_stat, jb_pvalue = jarque_bera(self.residuals)
        
        # Shapiro-Wilk test (for smaller samples)
        if len(self.residuals) <= 5000:
            sw_stat, sw_pvalue = stats.shapiro(self.residuals)
        else:
            sw_stat, sw_pvalue = np.nan, np.nan
        
        # Anderson-Darling test
        ad_result = stats.anderson(self.residuals, dist='norm')
        
        return {
            'jarque_bera_statistic': jb_stat,
            'jarque_bera_pvalue': jb_pvalue,
            'shapiro_wilk_statistic': sw_stat,
            'shapiro_wilk_pvalue': sw_pvalue,
            'anderson_darling_statistic': ad_result.statistic,
            'anderson_darling_critical_values': ad_result.critical_values.tolist()
        }
    
    def _test_homoscedasticity(self) -> Dict[str, float]:
        """Test homoscedasticity using multiple tests"""
        
        # Breusch-Pagan test
        try:
            X_with_const = sm.add_constant(self.X)
            bp_stat, bp_pvalue, _, _ = het_breuschpagan(self.residuals, X_with_const)
        except:
            bp_stat, bp_pvalue = np.nan, np.nan
        
        # White test
        try:
            white_stat, white_pvalue, _, _ = het_white(self.residuals, X_with_const)
        except:
            white_stat, white_pvalue = np.nan, np.nan
        
        return {
            'breusch_pagan_statistic': bp_stat,
            'breusch_pagan_pvalue': bp_pvalue,
            'white_statistic': white_stat,
            'white_pvalue': white_pvalue
        }
    
    def _test_autocorrelation(self) -> Dict[str, float]:
        """Test for autocorrelation in residuals"""
        
        # Durbin-Watson test
        dw_statistic = durbin_watson(self.residuals)
        
        # Ljung-Box test (approximation)
        from statsmodels.stats.diagnostic import acorr_ljungbox
        lb_result = acorr_ljungbox(self.residuals, lags=10, return_df=True)
        
        return {
            'durbin_watson_statistic': dw_statistic,
            'ljung_box_statistic': lb_result['lb_stat'].iloc[-1],
            'ljung_box_pvalue': lb_result['lb_pvalue'].iloc[-1]
        }
    
    def _calculate_vif(self) -> Dict[str, float]:
        """Calculate Variance Inflation Factor for multicollinearity detection"""
        
        if self.X.shape[1] == 1:
            return {self.model.feature_names[0]: 1.0}
        
        vif_data = {}
        try:
            for i in range(self.X.shape[1]):
                feature_name = self.model.feature_names[i] if i < len(self.model.feature_names) else f'feature_{i}'
                vif_value = variance_inflation_factor(self.X, i)
                vif_data[feature_name] = vif_value
        except:
            # Fallback for numerical issues
            for i, name in enumerate(self.model.feature_names):
                vif_data[name] = np.nan
        
        return vif_data
    
    def _detect_outliers(self) -> Dict[str, Any]:
        """Detect outliers using multiple methods"""
        
        # Standardized residuals
        residual_std = np.std(self.residuals)
        standardized_residuals = self.residuals / residual_std
        
        # Cook's distance approximation
        n, p = self.X.shape
        leverage = np.diagonal(self.X @ np.linalg.pinv(self.X.T @ self.X) @ self.X.T)
        cooks_distance = (standardized_residuals**2 / p) * (leverage / (1 - leverage)**2)
        
        # Outlier thresholds
        outlier_threshold_std = 2.5
        outlier_threshold_cooks = 4 / n
        
        outliers_std = np.where(np.abs(standardized_residuals) > outlier_threshold_std)[0]
        outliers_cooks = np.where(cooks_distance > outlier_threshold_cooks)[0]
        
        return {
            'standardized_residuals': standardized_residuals.tolist(),
            'cooks_distance': cooks_distance.tolist(),
            'outliers_standardized': outliers_std.tolist(),
            'outliers_cooks': outliers_cooks.tolist(),
            'outlier_threshold_std': outlier_threshold_std,
            'outlier_threshold_cooks': outlier_threshold_cooks
        }
    
    def _analyze_residuals(self) -> Dict[str, Any]:
        """Comprehensive residual analysis"""
        
        return {
            'mean': np.mean(self.residuals),
            'std': np.std(self.residuals),
            'skewness': stats.skew(self.residuals),
            'kurtosis': stats.kurtosis(self.residuals),
            'min': np.min(self.residuals),
            'max': np.max(self.residuals),
            'q25': np.percentile(self.residuals, 25),
            'median': np.median(self.residuals),
            'q75': np.percentile(self.residuals, 75)
        }
    
    def _print_diagnostic_summary(self, results: DiagnosticResults):
        """Print diagnostic summary"""
        
        print("\n" + "="*60)
        print("REGRESSION DIAGNOSTICS SUMMARY")
        print("="*60)
        
        # Normality
        print(f"\n1. NORMALITY OF RESIDUALS:")
        jb_pval = results.normality_test['jarque_bera_pvalue']
        print(f"   Jarque-Bera test p-value: {jb_pval:.4f}")
        print(f"   Normal distribution: {'✓' if jb_pval > 0.05 else '✗'}")
        
        # Homoscedasticity
        print(f"\n2. HOMOSCEDASTICITY:")
        bp_pval = results.homoscedasticity_test['breusch_pagan_pvalue']
        if not np.isnan(bp_pval):
            print(f"   Breusch-Pagan test p-value: {bp_pval:.4f}")
            print(f"   Constant variance: {'✓' if bp_pval > 0.05 else '✗'}")
        
        # Autocorrelation
        print(f"\n3. AUTOCORRELATION:")
        dw_stat = results.autocorrelation_test['durbin_watson_statistic']
        print(f"   Durbin-Watson statistic: {dw_stat:.4f}")
        print(f"   No autocorrelation: {'✓' if 1.5 < dw_stat < 2.5 else '✗'}")
        
        # Multicollinearity
        print(f"\n4. MULTICOLLINEARITY (VIF):")
        for feature, vif in results.multicollinearity_vif.items():
            if not np.isnan(vif):
                status = '✓' if vif < 5 else ('⚠' if vif < 10 else '✗')
                print(f"   {feature}: {vif:.2f} {status}")
        
        # Outliers
        print(f"\n5. OUTLIERS:")
        n_outliers_std = len(results.outlier_detection['outliers_standardized'])
        n_outliers_cooks = len(results.outlier_detection['outliers_cooks'])
        print(f"   Standardized residuals outliers: {n_outliers_std}")
        print(f"   Cook's distance outliers: {n_outliers_cooks}")

    def _plot_actual_vs_predicted(self):
        """Plot actual vs predicted values"""
        plt.scatter(self.y, self.y_pred, alpha=0.6, s=50)
        
        # Perfect prediction line
        min_val = min(self.y.min(), self.y_pred.min())
        max_val = max(self.y.max(), self.y_pred.max())
        plt.plot([min_val, max_val], [min_val, max_val], 'r--', lw=2, label='Perfect Prediction')
        
        # R² annotation
        r2 = r2_score(self.y, self.y_pred)
        plt.text(0.05, 0.95, f'R² = {r2:.4f}', transform=plt.gca().transAxes, 
                bbox=dict(boxstyle='round', facecolor='white', alpha=0.8))
        
        plt.xlabel('Actual Values')
        plt.ylabel('Predicted Values')
        plt.title('Actual vs Predicted Values')
        plt.legend()
        plt.grid(True, alpha=0.3)
    
    def _plot_residuals_vs_fitted(self):
        """Plot residuals vs fitted values"""
        plt.scatter(self.y_pred, self.residuals, alpha=0.6, s=50)
        plt.axhline(y=0, color='r', linestyle='--', lw=2)
        
        # Add lowess smooth line
        try:
            from statsmodels.nonparametric.smoothers_lowess import lowess
            smoothed = lowess(self.residuals, self.y_pred, frac=0.3)
            plt.plot(smoothed[:, 0], smoothed[:, 1], 'g-', lw=2, label='LOWESS')
            plt.legend()
        except:
            pass
        
        plt.xlabel('Fitted Values')
        plt.ylabel('Residuals')
        plt.title('Residuals vs Fitted Values')
        plt.grid(True, alpha=0.3)
    
    def _plot_qq_residuals(self):
        """Q-Q plot of residuals"""
        stats.probplot(self.residuals, dist="norm", plot=plt)
        plt.title('Q-Q Plot of Residuals')
        plt.grid(True, alpha=0.3)
    
    def _plot_residuals_histogram(self):
        """Histogram of residuals with normal overlay"""
        plt.hist(self.residuals, bins=30, density=True, alpha=0.7, color='skyblue', edgecolor='black')
        
        # Overlay normal distribution
        mu, sigma = np.mean(self.residuals), np.std(self.residuals)
        x = np.linspace(self.residuals.min(), self.residuals.max(), 100)
        plt.plot(x, stats.norm.pdf(x, mu, sigma), 'r-', lw=2, label='Normal Distribution')
        
        plt.xlabel('Residuals')
        plt.ylabel('Density')
        plt.title('Distribution of Residuals')
        plt.legend()
        plt.grid(True, alpha=0.3)
    
    def _plot_cooks_distance(self):
        """Plot Cook's distance"""
        n, p = self.X.shape
        leverage = np.diagonal(self.X @ np.linalg.pinv(self.X.T @ self.X) @ self.X.T)
        standardized_residuals = self.residuals / np.std(self.residuals)
        cooks_distance = (standardized_residuals**2 / p) * (leverage / (1 - leverage)**2)
        
        plt.stem(range(len(cooks_distance)), cooks_distance, basefmt=' ')
        plt.axhline(y=4/n, color='r', linestyle='--', lw=2, label=f'Threshold (4/n = {4/n:.4f})')
        
        plt.xlabel('Observation Index')
        plt.ylabel("Cook's Distance")
        plt.title("Cook's Distance")
        plt.legend()
        plt.grid(True, alpha=0.3)
    
    def _plot_leverage_residuals(self):
        """Plot leverage vs standardized residuals"""
        n, p = self.X.shape
        leverage = np.diagonal(self.X @ np.linalg.pinv(self.X.T @ self.X) @ self.X.T)
        standardized_residuals = self.residuals / np.std(self.residuals)
        
        plt.scatter(leverage, standardized_residuals, alpha=0.6, s=50)
        plt.axhline(y=0, color='gray', linestyle='-', alpha=0.5)
        plt.axhline(y=2, color='r', linestyle='--', alpha=0.7)
        plt.axhline(y=-2, color='r', linestyle='--', alpha=0.7)
        
        plt.xlabel('Leverage')
        plt.ylabel('Standardized Residuals')
        plt.title('Leverage vs Standardized Residuals')
        plt.grid(True, alpha=0.3)
    
    def _plot_feature_importance(self):
        """Plot feature importance (coefficients)"""
        if hasattr(self.model.model, 'coef_'):
            coefficients = self.model.model.coef_
            feature_names = self.model.feature_names
            
            # Sort by absolute value
            abs_coef = np.abs(coefficients)
            sorted_idx = np.argsort(abs_coef)[::-1]
            
            plt.barh(range(len(coefficients)), coefficients[sorted_idx])
            plt.yticks(range(len(coefficients)), [feature_names[i] for i in sorted_idx])
            plt.xlabel('Coefficient Value')
            plt.title('Feature Importance (Coefficients)')
            plt.grid(True, alpha=0.3)
    
    def _plot_learning_curve(self):
        """Plot learning curve"""
        try:
            train_sizes, train_scores, val_scores = learning_curve(
                self.model.model, self.X, self.y, cv=5, n_jobs=-1,
                train_sizes=np.linspace(0.1, 1.0, 10)
            )
            
            train_mean = np.mean(train_scores, axis=1)
            train_std = np.std(train_scores, axis=1)
            val_mean = np.mean(val_scores, axis=1)
            val_std = np.std(val_scores, axis=1)
            
            plt.plot(train_sizes, train_mean, 'o-', color='blue', label='Training Score')
            plt.fill_between(train_sizes, train_mean - train_std, train_mean + train_std, alpha=0.2, color='blue')
            
            plt.plot(train_sizes, val_mean, 'o-', color='red', label='Validation Score')
            plt.fill_between(train_sizes, val_mean - val_std, val_mean + val_std, alpha=0.2, color='red')
            
            plt.xlabel('Training Set Size')
            plt.ylabel('R² Score')
            plt.title('Learning Curve')
            plt.legend()
            plt.grid(True, alpha=0.3)
        except:
            plt.text(0.5, 0.5, 'Learning curve not available', 
                    transform=plt.gca().transAxes, ha='center', va='center')
            plt.title('Learning Curve')
    
    def _plot_residuals_vs_features(self):
        """Plot residuals vs first feature"""
        if self.X.shape[1] > 0:
            plt.scatter(self.X[:, 0], self.residuals, alpha=0.6, s=50)
            plt.axhline(y=0, color='r', linestyle='--', lw=2)
            
            feature_name = self.model.feature_names[0] if self.model.feature_names else 'Feature 1'
            plt.xlabel(feature_name)
            plt.ylabel('Residuals')
            plt.title(f'Residuals vs {feature_name}')
            plt.grid(True, alpha=0.3)
