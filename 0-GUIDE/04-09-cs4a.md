# 09. Ensemble Models: Power of Diversity

## Key Terms

**Ensemble Learning**: A meta-approach that combines multiple learning algorithms to improve predictive performance beyond what could be obtained from any individual constituent learning algorithm, leveraging the principle that diverse models can compensate for each other's weaknesses.

**Bagging (Bootstrap Aggregating)**: An ensemble technique that trains multiple models on different bootstrap samples of the training data and combines their predictions through averaging (regression) or voting (classification), reducing model variance and overfitting.

**Boosting**: A sequential ensemble method that builds models iteratively, where each subsequent model focuses on correcting the errors made by previous models, typically reducing both bias and variance through adaptive learning.

**Stacking (Stacked Generalization)**: An advanced ensemble technique that uses a meta-learner to combine predictions from multiple base models, learning optimal ways to blend different model outputs for superior performance.

**Bootstrap Sampling**: A statistical resampling technique that creates multiple datasets by randomly sampling with replacement from the original training data, enabling variance estimation and model diversity in bagging methods.

**Weak Learner**: A model that performs slightly better than random chance, typically used as base learners in boosting algorithms where multiple weak learners are combined to create a strong predictor.

**Gradient Boosting**: A machine learning technique that builds an additive model in a forward stage-wise fashion, optimizing arbitrary differentiable loss functions by fitting new models to residual errors of prior predictions.

**Feature Importance**: Measures that quantify the contribution of individual features to model predictions, particularly valuable in ensemble methods for understanding which variables drive model decisions.

**Out-of-Bag (OOB) Error**: An unbiased estimate of prediction error in bagging methods, calculated using predictions on samples not included in the bootstrap sample used to train each base model.

## Theoretical Foundation of Ensemble Methods

Ensemble learning leverages the statistical principle that combining multiple independent estimates typically yields more accurate results than individual predictions. The mathematical foundation rests on the bias-variance decomposition, where different ensemble techniques address different components of prediction error.

Bagging primarily reduces variance by training models on different data subsets and averaging their predictions, following the law of large numbers. For regression, if individual models have variance σ² and are uncorrelated, the ensemble variance becomes σ²/n where n is the number of models.

Boosting operates on the bias-variance tradeoff differently, sequentially building models that focus on previously misclassified examples. The AdaBoost algorithm provably reduces both training and generalization error under certain conditions, while gradient boosting optimizes arbitrary loss functions through functional gradient descent.

Stacking transcends simple averaging by learning optimal combination strategies through cross-validation, potentially capturing complex interactions between base model predictions and achieving superior performance when base models have complementary strengths.

def performance_monitor(func):
    """Decorator to monitor ensemble function performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedBaggingEnsemble:
    """Advanced bagging ensemble with multiple base learners and optimization"""
    
    def __init__(self, random_state: int = 42, n_jobs: int = -1):
        self.random_state = random_state
        self.n_jobs = n_jobs
        self.bagging_models_ = {}
        self.results_ = {}
        
    @performance_monitor
    def create_bagging_ensemble(self, X: pd.DataFrame, y: pd.Series,
                              base_estimators: Dict[str, BaseEstimator] = None,
                              n_estimators: int = 100,
                              max_samples: float = 0.8,
                              max_features: float = 0.8) -> Dict[str, EnsembleResults]:
        """Create comprehensive bagging ensemble with multiple base learners"""
        
        if base_estimators is None:
            base_estimators = self._get_default_base_estimators(y)
        
        is_classification = self._is_classification_task(y)
        bagging_results = {}
        
        for base_name, base_estimator in base_estimators.items():
            logger.info(f"Creating bagging ensemble with {base_name}")
            
            # Create bagging ensemble
            if is_classification:
                bagging_model = BaggingClassifier(
                    base_estimator=base_estimator,
                    n_estimators=n_estimators,
                    max_samples=max_samples,
                    max_features=max_features,
                    bootstrap=True,
                    bootstrap_features=False,
                    oob_score=True,
                    random_state=self.random_state,
                    n_jobs=self.n_jobs
                )
            else:
                bagging_model = BaggingRegressor(
                    base_estimator=base_estimator,
                    n_estimators=n_estimators,
                    max_samples=max_samples,
                    max_features=max_features,
                    bootstrap=True,
                    bootstrap_features=False,
                    oob_score=True,
                    random_state=self.random_state,
                    n_jobs=self.n_jobs
                )
            
            # Evaluate ensemble
            results = self._evaluate_ensemble(X, y, bagging_model, f"bagging_{base_name}")
            bagging_results[f"bagging_{base_name}"] = results
            self.bagging_models_[f"bagging_{base_name}"] = bagging_model
        
        self.results_.update(bagging_results)
        return bagging_results
    
    def create_random_forest_variants(self, X: pd.DataFrame, y: pd.Series) -> Dict[str, EnsembleResults]:
        """Create different Random Forest variants for comparison"""
        
        is_classification = self._is_classification_task(y)
        rf_variants = {}

        if is_classification:
            rf_standard = RandomForestClassifier(

            }
    
    def _evaluate_ensemble(self, X: pd.DataFrame, y: pd.Series,
                          ensemble: BaseEstimator, model_name: str) -> EnsembleResults:
        """Comprehensive ensemble evaluation"""
        
        # Cross-validation
        cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=self.random_state) \
            if self._is_classification_task(y) else KFold(n_splits=5, shuffle=True, random_state=self.random_state)
        
        # Performance evaluation
        start_time = time.time()
        cv_results = cross_validate(
            ensemble, X, y, cv=cv, scoring='accuracy' if self._is_classification_task(y) else 'r2',
            return_train_score=True, n_jobs=self.n_jobs
        )
        training_time = time.time() - start_time
        
        # Fit for additional metrics
        ensemble.fit(X, y)
        
        # Prediction time
        start_time = time.time()
        predictions = ensemble.predict(X)
        prediction_time = time.time() - start_time
        
        # Feature importance
        feature_importance = None
        if hasattr(ensemble, 'feature_importances_'):
            feature_importance = dict(zip(X.columns, ensemble.feature_importances_))
        
        # OOB Score
        oob_score = getattr(ensemble, 'oob_score_', None)
        
        return EnsembleResults(
            model_name=model_name,
            base_models=[str(type(ensemble).__name__)],
            ensemble_type="bagging",
            cv_scores=cv_results['test_score'],
            mean_score=np.mean(cv_results['test_score']),
            std_score=np.std(cv_results['test_score']),
            training_time=training_time,
            prediction_time=prediction_time,
            feature_importance=feature_importance,
            oob_score=oob_score
        )
    
    def _is_classification_task(self, y: pd.Series) -> bool:
        """Determine if task is classification"""
        unique_ratio = y.nunique() / len(y)
        return unique_ratio < 0.05 or y.nunique() <= 20

class AdvancedBoostingEnsemble:
    """Advanced boosting ensemble with multiple algorithms and optimization"""
    
    def __init__(self, random_state: int = 42, n_jobs: int = -1):
        self.random_state = random_state
        self.n_jobs = n_jobs
        self.boosting_models_ = {}
        self.results_ = {}
        
    @performance_monitor
    def create_boosting_ensemble(self, X: pd.DataFrame, y: pd.Series,
                               optimize_hyperparameters: bool = True) -> Dict[str, EnsembleResults]:
        """Create comprehensive boosting ensemble with multiple algorithms"""
        
        is_classification = self._is_classification_task(y)
        boosting_results = {}
        
        # AdaBoost
        ada_boost = self._create_adaboost(is_classification)
        boosting_results['adaboost'] = self._evaluate_ensemble(X, y, ada_boost, "adaboost")
        
        # Gradient Boosting
        gb_model = self._create_gradient_boosting(is_classification)
        boosting_results['gradient_boosting'] = self._evaluate_ensemble(X, y, gb_model, "gradient_boosting")
        
        # XGBoost
        xgb_model = self._create_xgboost(is_classification)
        boosting_results['xgboost'] = self._evaluate_ensemble(X, y, xgb_model, "xgboost")
        
        # LightGBM
        lgb_model = self._create_lightgbm(is_classification)
        boosting_results['lightgbm'] = self._evaluate_ensemble(X, y, lgb_model, "lightgbm")
        
        # CatBoost
        cat_model = self._create_catboost(is_classification)
        boosting_results['catboost'] = self._evaluate_ensemble(X, y, cat_model, "catboost")
        
        # Hyperparameter optimization for best performing model
        if optimize_hyperparameters:
            best_model_name = max(boosting_results.keys(), 
                                key=lambda x: boosting_results[x].mean_score)
            optimized_results = self._optimize_best_boosting_model(
                X, y, best_model_name, is_classification
            )
            boosting_results[f'{best_model_name}_optimized'] = optimized_results
        
        self.results_.update(boosting_results)
        return boosting_results
    
    def _create_adaboost(self, is_classification: bool) -> BaseEstimator:
        """Create AdaBoost model"""
        if is_classification:
            return AdaBoostClassifier(
                n_estimators=100, learning_rate=1.0, random_state=self.random_state
            )
        else:
            return AdaBoostRegressor(
                n_estimators=100, learning_rate=1.0, random_state=self.random_state
            )
    
    def _create_gradient_boosting(self, is_classification: bool) -> BaseEstimator:
        """Create Gradient Boosting model"""
        if is_classification:
            return GradientBoostingClassifier(
                n_estimators=100, learning_rate=0.1, max_depth=3,
                random_state=self.random_state
            )
        else:
            return GradientBoostingRegressor(
                n_estimators=100, learning_rate=0.1, max_depth=3,
                random_state=self.random_state
            )
    
    def _create_xgboost(self, is_classification: bool) -> BaseEstimator:
        """Create XGBoost model"""
        if is_classification:
            return xgb.XGBClassifier(
                n_estimators=100, learning_rate=0.1, max_depth=3,
                random_state=self.random_state, eval_metric='logloss'
            )
        else:
            return xgb.XGBRegressor(
                n_estimators=100, learning_rate=0.1, max_depth=3,
                random_state=self.random_state
            )
    
    def _create_lightgbm(self, is_classification: bool) -> BaseEstimator:
        """Create LightGBM model"""
        if is_classification:
            return lgb.LGBMClassifier(
                n_estimators=100, learning_rate=0.1, max_depth=3,
                random_state=self.random_state, verbosity=-1
            )
        else:
            return lgb.LGBMRegressor(
                n_estimators=100, learning_rate=0.1, max_depth=3,
                random_state=self.random_state, verbosity=-1
            )
    
    def _create_catboost(self, is_classification: bool) -> BaseEstimator:
        """Create CatBoost model"""
        if is_classification:
            return CatBoostClassifier(
                iterations=100, learning_rate=0.1, depth=3,
                random_seed=self.random_state, verbose=False
            )
        else:
            return CatBoostRegressor(
                iterations=100, learning_rate=0.1, depth=3,
                random_seed=self.random_state, verbose=False
            )
    
    def _optimize_best_boosting_model(self, X: pd.DataFrame, y: pd.Series,
                                    model_name: str, is_classification: bool) -> EnsembleResults:
        """Optimize hyperparameters for best performing boosting model"""
        
        logger.info(f"Optimizing hyperparameters for {model_name}")
        
        def objective(trial):
            if model_name == 'xgboost':
                params = {
                    'n_estimators': trial.suggest_int('n_estimators', 50, 300),
                    'learning_rate': trial.suggest_float('learning_rate', 0.01, 0.3),
                    'max_depth': trial.suggest_int('max_depth', 3, 10),
                    'subsample': trial.suggest_float('subsample', 0.6, 1.0),
                    'colsample_bytree': trial.suggest_float('colsample_bytree', 0.6, 1.0)
                }
                
                if is_classification:
                    model = xgb.XGBClassifier(random_state=self.random_state, eval_metric='logloss', **params)
                else:
                    model = xgb.XGBRegressor(random_state=self.random_state, **params)
                    
            elif model_name == 'lightgbm':
                params = {
                    'n_estimators': trial.suggest_int('n_estimators', 50, 300),
                    'learning_rate': trial.suggest_float('learning_rate', 0.01, 0.3),
                    'max_depth': trial.suggest_int('max_depth', 3, 10),
                    'subsample': trial.suggest_float('subsample', 0.6, 1.0),
                    'colsample_bytree': trial.suggest_float('colsample_bytree', 0.6, 1.0)
                }
                
                if is_classification:
                    model = lgb.LGBMClassifier(random_state=self.random_state, verbosity=-1, **params)
                else:
                    model = lgb.LGBMRegressor(random_state=self.random_state, verbosity=-1, **params)
            
            else:
                # Default to XGBoost if unknown model
                if is_classification:
                    model = xgb.XGBClassifier(random_state=self.random_state, eval_metric='logloss')
                else:
                    model = xgb.XGBRegressor(random_state=self.random_state)
            
            # Cross-validation score
            cv = StratifiedKFold(n_splits=3, shuffle=True, random_state=self.random_state) \
                if is_classification else KFold(n_splits=3, shuffle=True, random_state=self.random_state)
            
            scores = cross_val_score(
                model, X, y, cv=cv, 
                scoring='accuracy' if is_classification else 'r2'
            )
            return scores.mean()
        
        # Optuna optimization
        study = optuna.create_study(direction='maximize')
        study.optimize(objective, n_trials=50, show_progress_bar=False)
        
        # Create optimized model
        best_params = study.best_params
        
        if model_name == 'xgboost':
            if is_classification:
                optimized_model = xgb.XGBClassifier(
                    random_state=self.random_state, eval_metric='logloss', **best_params
                )
            else:
                optimized_model = xgb.XGBRegressor(
                    random_state=self.random_state, **best_params
                )
        elif model_name == 'lightgbm':
            if is_classification:
                optimized_model = lgb.LGBMClassifier(
                    random_state=self.random_state, verbosity=-1, **best_params
                )
            else:
                optimized_model = lgb.LGBMRegressor(
                    random_state=self.random_state, verbosity=-1, **best_params
                )
        
        return self._evaluate_ensemble(X, y, optimized_model, f"{model_name}_optimized")
    
    def _evaluate_ensemble(self, X: pd.DataFrame, y: pd.Series,

            if self._is_classification_task(y) else KFold(n_splits=5, shuffle=True, random_state=self.random_state)

        start_time = time.time()
        cv_results = cross_validate(
            ensemble, X, y, cv=cv, scoring='accuracy' if self._is_classification_task(y) else 'r2',
            return_train_score=True, n_jobs=self.n_jobs
        )
        training_time = time.time() - start_time
        
        # Fit for additional metrics
        ensemble.fit(X, y)
        
        # Prediction time
        start_time = time.time()
        predictions = ensemble.predict(X)
        prediction_time = time.time() - start_time
        
        # Feature importance
        feature_importance = None
        if hasattr(ensemble, 'feature_importances_'):
            feature_importance = dict(zip(X.columns, ensemble.feature_importances_))
        
        return EnsembleResults(
            model_name=model_name,
            base_models=[str(type(ensemble).__name__)],
            ensemble_type="boosting",
            cv_scores=cv_results['test_score'],
            mean_score=np.mean(cv_results['test_score']),
            std_score=np.std(cv_results['test_score']),
            training_time=training_time,
            prediction_time=prediction_time,
            feature_importance=feature_importance,
            oob_score=None
        )
    
    def _is_classification_task(self, y: pd.Series) -> bool:
        """Determine if task is classification"""
        unique_ratio = y.nunique() / len(y)
        return unique_ratio < 0.05 or y.nunique() <= 20

class AdvancedStackingEnsemble:
    """Advanced stacking ensemble with meta-learner optimization"""
    
    def __init__(self, random_state: int = 42, n_jobs: int = -1):
        self.random_state = random_state
        self.n_jobs = n_jobs
        self.stacking_models_ = {}
        self.results_ = {}
        
    @performance_monitor
    def create_stacking_ensemble(self, X: pd.DataFrame, y: pd.Series,
                               base_models: Dict[str, BaseEstimator] = None,
                               meta_learners: List[BaseEstimator] = None) -> Dict[str, EnsembleResults]:
        """Create advanced stacking ensemble with multiple meta-learners"""
        
        if base_models is None:
            base_models = self._get_default_base_models(y)
        
        if meta_learners is None:
            meta_learners = self._get_default_meta_learners(y)
        
        is_classification = self._is_classification_task(y)
        stacking_results = {}
        
        # Create base estimators list
        base_estimators = [(name, model) for name, model in base_models.items()]
        
        for i, meta_learner in enumerate(meta_learners):
            meta_name = f"meta_{type(meta_learner).__name__}_{i}"
            
            logger.info(f"Creating stacking ensemble with {meta_name}")
            
            if is_classification:
                stacking_model = StackingClassifier(
                    estimators=base_estimators,
                    final_estimator=meta_learner,
                    cv=5,
                    stack_method='auto',
                    n_jobs=self.n_jobs,
                    passthrough=False
                )
            else:
                stacking_model = StackingRegressor(
                    estimators=base_estimators,
                    final_estimator=meta_learner,
                    cv=5,
                    n_jobs=self.n_jobs,
                    passthrough=False
                )
            
            results = self._evaluate_stacking(X, y, stacking_model, meta_name, base_models.keys())
            stacking_results[meta_name] = results
            self.stacking_models_[meta_name] = stacking_model
        
        # Create voting ensemble for comparison
        if is_classification:
            voting_model = VotingClassifier(
                estimators=base_estimators,
                voting='soft',
                n_jobs=self.n_jobs
            )
        else:
            voting_model = VotingRegressor(
                estimators=base_estimators,
                n_jobs=self.n_jobs
            )
        
        voting_results = self._evaluate_stacking(X, y, voting_model, "voting", base_models.keys())
        stacking_results['voting'] = voting_results
        
        self.results_.update(stacking_results)
        return stacking_results
    
    def _get_default_base_models(self, y: pd.Series) -> Dict[str, BaseEstimator]:
        """Get diverse base models for stacking"""
        
        is_classification = self._is_classification_task(y)
        
        if is_classification:
            return {
                'rf': RandomForestClassifier(n_estimators=50, random_state=self.random_state),
                'gb': GradientBoostingClassifier(n_estimators=50, random_state=self.random_state),
                'svm': SVC(probability=True, random_state=self.random_state),
                'lr': LogisticRegression(random_state=self.random_state, max_iter=1000),
                'knn': KNeighborsClassifier(n_neighbors=5)
            }
        else:
            return {
                'rf': RandomForestRegressor(n_estimators=50, random_state=self.random_state),
                'gb': GradientBoostingRegressor(n_estimators=50, random_state=self.random_state),
                'svr': SVR(),
                'ridge': Ridge(random_state=self.random_state),
                'knn': KNeighborsRegressor(n_neighbors=5)
            }
    
    def _get_default_meta_learners(self, y: pd.Series) -> List[BaseEstimator]:
        """Get meta-learners for stacking"""
        
        is_classification = self._is_classification_task(y)
        
        if is_classification:
            return [
                LogisticRegression(random_state=self.random_state, max_iter=1000),
                RandomForestClassifier(n_estimators=50, random_state=self.random_state),
                xgb.XGBClassifier(n_estimators=50, random_state=self.random_state, eval_metric='logloss')
            ]
        else:
            return [
                Ridge(random_state=self.random_state),
                RandomForestRegressor(n_estimators=50, random_state=self.random_state),
                xgb.XGBRegressor(n_estimators=50, random_state=self.random_state)
            ]
    
    def _evaluate_stacking(self, X: pd.DataFrame, y: pd.Series,
                          ensemble: BaseEstimator, model_name: str,
                          base_model_names: List[str]) -> EnsembleResults:
        """Comprehensive stacking evaluation"""
        
        cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=self.random_state) \
            if self._is_classification_task(y) else KFold(n_splits=5, shuffle=True, random_state=self.random_state)
        
        # Performance evaluation
        start_time = time.time()
        cv_results = cross_validate(
            ensemble, X, y, cv=cv, scoring='accuracy' if self._is_classification_task(y) else 'r2',
            return_train_score=True, n_jobs=self.n_jobs
        )
        training_time = time.time() - start_time
        
        # Fit for additional metrics
        ensemble.fit(X, y)
        
        # Prediction time
        start_time = time.time()
        predictions = ensemble.predict(X)
        prediction_time = time.time() - start_time
        
        return EnsembleResults(
            model_name=model_name,
            base_models=list(base_model_names),
            ensemble_type="stacking",
            cv_scores=cv_results['test_score'],
            mean_score=np.mean(cv_results['test_score']),
            std_score=np.std(cv_results['test_score']),
            training_time=training_time,
            prediction_time=prediction_time,
            feature_importance=None,
            oob_score=None
        )
    
    def _is_classification_task(self, y: pd.Series) -> bool:
        """Determine if task is classification"""
        unique_ratio = y.nunique() / len(y)
        return unique_ratio < 0.05 or y.nunique() <= 20

class MultiClassClassificationAnalyzer:
    """Advanced multi-class classification analysis and optimization"""
    
    def __init__(self, random_state: int = 42):
        self.random_state = random_state
        self.multiclass_results_ = {}
        
    @performance_monitor
    def analyze_multiclass_performance(self, X: pd.DataFrame, y: pd.Series,
                                     models: Dict[str, BaseEstimator],
                                     strategies: List[str] = None) -> Dict[str, MultiClassResults]:
        """Comprehensive multi-class classification analysis"""
        
        if strategies is None:
            strategies = ['native', 'ovr', 'ovo']
        
        # Ensure we have multi-class problem
        n_classes = y.nunique()
        if n_classes <= 2:
            logger.warning("This appears to be a binary classification problem")
        
        multiclass_results = {}
        
        for model_name, model in models.items():
            for strategy in strategies:
                logger.info(f"Evaluating {model_name} with {strategy} strategy")
                
                # Apply multi-class strategy
                if strategy == 'native':
                    # Use model as-is (assumes native multi-class support)
                    ensemble_model = model
                    strategy_name = f"{model_name}_native"
                elif strategy == 'ovr':
                    # One-vs-Rest
                    ensemble_model = OneVsRestClassifier(model)
                    strategy_name = f"{model_name}_ovr"
                elif strategy == 'ovo':
                    # One-vs-One
                    ensemble_model = OneVsOneClassifier(model)
                    strategy_name = f"{model_name}_ovo"
                else:
                    continue
                
                # Evaluate model
                results = self._evaluate_multiclass_model(X, y, ensemble_model)
                multiclass_results[strategy_name] = results
        
        self.multiclass_results_ = multiclass_results
        return multiclass_results
    
    def _evaluate_multiclass_model(self, X: pd.DataFrame, y: pd.Series,
                                 model: BaseEstimator) -> MultiClassResults:
        """Evaluate multi-class classification model"""
        
        # Split data
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=0.2, random_state=self.random_state, stratify=y
        )
        
        # Train model
        model.fit(X_train, y_train)
        y_pred = model.predict(X_test)
        
        # Calculate metrics
        accuracy = accuracy_score(y_test, y_pred)
        precision_macro = precision_score(y_test, y_pred, average='macro')
        recall_macro = recall_score(y_test, y_pred, average='macro')
        f1_macro = f1_score(y_test, y_pred, average='macro')
        precision_weighted = precision_score(y_test, y_pred, average='weighted')
        recall_weighted = recall_score(y_test, y_pred, average='weighted')
        f1_weighted = f1_score(y_test, y_pred, average='weighted')
        
        # Confusion matrix
        cm = confusion_matrix(y_test, y_pred)
        
        # Classification report
        class_report = classification_report(y_test, y_pred, output_dict=True)
        
        # Per-class metrics
        per_class_metrics = {}
        for class_label in np.unique(y):
            if str(class_label) in class_report:
                per_class_metrics[f"class_{class_label}"] = class_report[str(class_label)]
        
        return MultiClassResults(
            accuracy=accuracy,
            precision_macro=precision_macro,
            recall_macro=recall_macro,
            f1_macro=f1_macro,
            precision_weighted=precision_weighted,
            recall_weighted=recall_weighted,
            f1_weighted=f1_weighted,
            confusion_matrix=cm,
            class_report=class_report,
            per_class_metrics=per_class_metrics
        )
