## Key Terms

**Binary Classification**: A supervised learning task where the goal is to classify instances into one of two mutually exclusive categories, such as spam/not spam, positive/negative sentiment, or fraud/legitimate transactions, using labeled training data to learn decision boundaries.

**Multi-class Classification**: An extension of binary classification where instances must be categorized into one of three or more distinct classes, requiring algorithms that can handle multiple decision boundaries and class probability distributions simultaneously.

**Logistic Regression**: A linear classification algorithm that uses the logistic function (sigmoid) to model the probability of class membership, transforming linear combinations of features into probability values between 0 and 1 for binary classification or using techniques like one-vs-rest for multi-class problems.

**K-Nearest Neighbors (KNN)**: A non-parametric, instance-based learning algorithm that classifies new instances based on the majority vote of their k nearest neighbors in the feature space, using distance metrics to determine similarity and making predictions without explicit model training.

**Class Imbalance**: A common problem in classification datasets where one or more classes are significantly underrepresented compared to others, leading to biased models that favor majority classes and poor performance on minority classes without proper handling techniques.

**Confusion Matrix**: A comprehensive evaluation tool that displays the counts of true positives, true negatives, false positives, and false negatives, providing detailed insights into classification performance across all classes and enabling calculation of various performance metrics.

**Precision and Recall**: Key performance metrics where precision measures the proportion of positive predictions that are actually correct, while recall measures the proportion of actual positive cases that were correctly identified, often requiring trade-offs in optimization.

**F1-Score**: The harmonic mean of precision and recall that provides a single metric balancing both measures, particularly useful for imbalanced datasets where accuracy alone may be misleading.

## Theoretical Foundation of Classification

Classification represents one of the most fundamental and widely applied machine learning paradigms, enabling automated decision-making across diverse domains from medical diagnosis to fraud detection. Unlike regression that predicts continuous values, classification assigns discrete labels to instances based on learned patterns from training data.

The mathematical foundation involves learning a decision function f(x) that maps input features to class labels, where the goal is to minimize classification error on unseen data. This requires understanding probability distributions, decision boundaries, and the bias-variance tradeoff specific to classification problems.

def performance_monitor(func):
    """Decorator to monitor function performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedClassificationFramework:
    """Comprehensive classification framework with advanced features"""
    
    def __init__(self, random_state: int = 42):

    @performance_monitor
    def run_comprehensive_evaluation(self, X: np.ndarray, y: np.ndarray,
                                   feature_names: List[str] = None,
                                   test_size: float = 0.2,
                                   handle_imbalance: str = 'none',
                                   cv_folds: int = 5) -> Dict[str, ClassificationExperiment]:
        """Run comprehensive classification evaluation"""
        
        self.feature_names = feature_names or [f'feature_{i}' for i in range(X.shape[1])]
        
        # Encode labels if necessary
        if isinstance(y[0], str):
            self.label_encoder = LabelEncoder()
            y = self.label_encoder.fit_transform(y)
        
        # Split data
        X_train, X_test, y_train, y_test = train_test_split(

        )
        
        # Handle class imbalance
        X_train_balanced, y_train_balanced = self._handle_imbalance(
            X_train, y_train, method=handle_imbalance
        )
        
        # Evaluate all models
        for model_name, model in self.models.items():
            logger.info(f"Evaluating {model_name}")
            
            experiment = self._evaluate_single_model(
                model, model_name, X_train_balanced, y_train_balanced,
                X_test, y_test, cv_folds
            )
            
            self.experiments[model_name] = experiment
        
        # Find best model
        self._select_best_model()
        
        return self.experiments
    
    def _handle_imbalance(self, X: np.ndarray, y: np.ndarray, 
                         method: str = 'none') -> Tuple[np.ndarray, np.ndarray]:
        """Handle class imbalance using various techniques"""
        
        if method == 'none':
            return X, y
        
        techniques = {
            'smote': SMOTE(random_state=self.random_state),
            'adasyn': ADASYN(random_state=self.random_state),
            'random_oversample': RandomOverSampler(random_state=self.random_state),
            'random_undersample': RandomUnderSampler(random_state=self.random_state),
            'tomek_links': TomekLinks(),
            'smote_tomek': SMOTETomek(random_state=self.random_state),
            'smote_enn': SMOTEENN(random_state=self.random_state)
        }
        
        if method in techniques:
            try:
                X_resampled, y_resampled = techniques[method].fit_resample(X, y)
                logger.info(f"Applied {method} resampling: {Counter(y)} -> {Counter(y_resampled)}")
                return X_resampled, y_resampled
            except Exception as e:
                logger.warning(f"Failed to apply {method}: {e}")
                return X, y
        
        return X, y
    
    @performance_monitor
    def _evaluate_single_model(self, model: Any, model_name: str,
                             X_train: np.ndarray, y_train: np.ndarray,
                             X_test: np.ndarray, y_test: np.ndarray,
                             cv_folds: int) -> ClassificationExperiment:
        """Evaluate a single classification model"""
        
        # Create pipeline with preprocessing
        pipeline = Pipeline([
            ('scaler', StandardScaler()),
            ('classifier', model)
        ])
        
        # Training
        start_time = time.time()
        pipeline.fit(X_train, y_train)
        training_time = time.time() - start_time
        
        # Prediction
        start_time = time.time()
        y_pred = pipeline.predict(X_test)
        y_pred_proba = None
        if hasattr(pipeline, 'predict_proba'):
            try:
                y_pred_proba = pipeline.predict_proba(X_test)
            except:
                pass
        prediction_time = time.time() - start_time
        
        # Calculate metrics
        metrics = self._calculate_comprehensive_metrics(y_test, y_pred, y_pred_proba)
        
        # Confusion matrix
        cm = confusion_matrix(y_test, y_pred)
        
        # Classification report
        class_names = self.label_encoder.classes_ if self.label_encoder else None
        report = classification_report(y_test, y_pred, target_names=class_names, output_dict=True)
        
        # Cross-validation
        cv_scores = cross_val_score(pipeline, X_train, y_train, cv=cv_folds, scoring='f1_macro')
        
        # Feature importance (if available)
        feature_importance = None
        if hasattr(model, 'feature_importances_'):
            feature_importance = model.feature_importances_
        elif hasattr(model, 'coef_'):
            feature_importance = np.abs(model.coef_).flatten()
        
        return ClassificationExperiment(
            model_name=model_name,
            model=pipeline,
            metrics=metrics,
            confusion_matrix=cm,
            classification_report=report,
            training_time=training_time,
            prediction_time=prediction_time,
            cross_val_scores=cv_scores,
            feature_importance=feature_importance
        )
    
    def _calculate_comprehensive_metrics(self, y_true: np.ndarray, 
                                       y_pred: np.ndarray,
                                       y_pred_proba: Optional[np.ndarray] = None) -> ClassificationMetrics:
        """Calculate comprehensive classification metrics"""
        
        # Basic metrics
        accuracy = accuracy_score(y_true, y_pred)
        balanced_accuracy = balanced_accuracy_score(y_true, y_pred)
        
        # Precision, Recall, F1
        precision_macro = precision_score(y_true, y_pred, average='macro', zero_division=0)
        precision_micro = precision_score(y_true, y_pred, average='micro', zero_division=0)
        precision_weighted = precision_score(y_true, y_pred, average='weighted', zero_division=0)
        
        recall_macro = recall_score(y_true, y_pred, average='macro', zero_division=0)
        recall_micro = recall_score(y_true, y_pred, average='micro', zero_division=0)
        recall_weighted = recall_score(y_true, y_pred, average='weighted', zero_division=0)
        
        f1_macro = f1_score(y_true, y_pred, average='macro', zero_division=0)
        f1_micro = f1_score(y_true, y_pred, average='micro', zero_division=0)
        f1_weighted = f1_score(y_true, y_pred, average='weighted', zero_division=0)
        
        # Agreement metrics
        cohen_kappa = cohen_kappa_score(y_true, y_pred)
        matthews_corrcoef_score = matthews_corrcoef(y_true, y_pred)
        
        # Probability-based metrics
        roc_auc = None
        average_precision = None
        log_loss_score = None
        top_k_accuracy = None
        
        if y_pred_proba is not None:
            try:
                n_classes = len(np.unique(y_true))
                if n_classes == 2:
                    roc_auc = roc_auc_score(y_true, y_pred_proba[:, 1])
                    average_precision = average_precision_score(y_true, y_pred_proba[:, 1])
                else:
                    roc_auc = roc_auc_score(y_true, y_pred_proba, multi_class='ovr', average='macro')
                
                log_loss_score = log_loss(y_true, y_pred_proba)
                
                if n_classes > 2:
                    k = min(3, n_classes)
                    top_k_accuracy = top_k_accuracy_score(y_true, y_pred_proba, k=k)
            except Exception as e:
                logger.warning(f"Error calculating probability-based metrics: {e}")
        
        return ClassificationMetrics(
            accuracy=accuracy,
            balanced_accuracy=balanced_accuracy,
            precision_macro=precision_macro,
            precision_micro=precision_micro,
            precision_weighted=precision_weighted,
            recall_macro=recall_macro,
            recall_micro=recall_micro,
            recall_weighted=recall_weighted,
            f1_macro=f1_macro,
            f1_micro=f1_micro,
            f1_weighted=f1_weighted,
            cohen_kappa=cohen_kappa,
            matthews_corrcoef=matthews_corrcoef_score,
            roc_auc=roc_auc,
            average_precision=average_precision,
            log_loss_score=log_loss_score,
            top_k_accuracy=top_k_accuracy
        )
    
    def _select_best_model(self):
        """Select the best model based on F1-macro score"""
        
        best_score = -1
        best_name = None
        
        for name, experiment in self.experiments.items():
            if experiment.metrics.f1_macro > best_score:
                best_score = experiment.metrics.f1_macro
                best_name = name
        
        self.best_model = self.experiments[best_name] if best_name else None
        logger.info(f"Best model: {best_name} with F1-macro: {best_score:.4f}")

class ImbalancedDatasetAnalyzer:
    """Analyze and handle imbalanced datasets"""
    
    def __init__(self):
        self.class_distribution = None
        self.imbalance_ratio = None
        self.majority_class = None
        self.minority_class = None
        
    @performance_monitor
    def analyze_imbalance(self, y: np.ndarray) -> Dict[str, Any]:
        """Comprehensive imbalance analysis"""
        
        # Class distribution
        unique_classes, counts = np.unique(y, return_counts=True)
        self.class_distribution = dict(zip(unique_classes, counts))
        
        # Imbalance metrics
        max_count = max(counts)
        min_count = min(counts)
        self.imbalance_ratio = max_count / min_count
        self.majority_class = unique_classes[np.argmax(counts)]
        self.minority_class = unique_classes[np.argmin(counts)]
        
        # Imbalance severity
        severity = self._classify_imbalance_severity(self.imbalance_ratio)
        
        # Recommendations
        recommendations = self._get_imbalance_recommendations(severity, len(unique_classes))
        
        analysis = {
            'class_distribution': self.class_distribution,
            'imbalance_ratio': self.imbalance_ratio,
            'majority_class': self.majority_class,
            'minority_class': self.minority_class,
            'severity': severity,
            'n_classes': len(unique_classes),
            'total_samples': len(y),
            'recommendations': recommendations
        }
        
        self._print_imbalance_analysis(analysis)
        return analysis
    
    def _classify_imbalance_severity(self, ratio: float) -> str:
        """Classify imbalance severity"""
        if ratio <= 1.5:
            return 'balanced'
        elif ratio <= 4:
            return 'mild_imbalance'
        elif ratio <= 9:
            return 'moderate_imbalance'
        elif ratio <= 99:
            return 'severe_imbalance'
        else:
            return 'extreme_imbalance'
    
    def _get_imbalance_recommendations(self, severity: str, n_classes: int) -> List[str]:
        """Get recommendations for handling imbalance"""
        
        recommendations = []
        
        if severity == 'balanced':
            recommendations.append("Dataset is well-balanced. No special handling needed.")
        elif severity == 'mild_imbalance':
            recommendations.extend([
                "Consider class weights in algorithms",
                "Use stratified sampling in cross-validation"
            ])
        elif severity == 'moderate_imbalance':
            recommendations.extend([
                "Apply SMOTE oversampling",
                "Use class weights in algorithms",
                "Consider cost-sensitive learning",
                "Focus on F1-score instead of accuracy"
            ])
        elif severity in ['severe_imbalance', 'extreme_imbalance']:
            recommendations.extend([
                "Apply advanced resampling (ADASYN, SMOTE variants)",
                "Use ensemble methods with resampling",
                "Consider anomaly detection approach",
                "Use precision-recall metrics",
                "Apply cost-sensitive learning with high penalties"
            ])
        
        if n_classes > 2:
            recommendations.append("Consider one-vs-rest or one-vs-one strategies")
        
        return recommendations
    
    def _print_imbalance_analysis(self, analysis: Dict[str, Any]):
        """Print imbalance analysis results"""
        
        print("\n" + "="*60)
        print("IMBALANCED DATASET ANALYSIS")
        print("="*60)
        
        print(f"\nClass Distribution:")
        for class_label, count in analysis['class_distribution'].items():
            percentage = (count / analysis['total_samples']) * 100
            print(f"  Class {class_label}: {count} samples ({percentage:.1f}%)")
        
        print(f"\nImbalance Metrics:")
        print(f"  Imbalance Ratio: {analysis['imbalance_ratio']:.2f}")
        print(f"  Majority Class: {analysis['majority_class']}")
        print(f"  Minority Class: {analysis['minority_class']}")
        print(f"  Severity: {analysis['severity'].replace('_', ' ').title()}")
        
        print(f"\nRecommendations:")
        for i, rec in enumerate(analysis['recommendations'], 1):
            print(f"  {i}. {rec}")
