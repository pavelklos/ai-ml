# 12. Dimensionality Reduction and Embedding Techniques

## Key Terms

**Dimensionality Reduction**: A computational technique that transforms high-dimensional data into lower-dimensional representations while preserving essential information, enabling visualization, reducing computational complexity, and mitigating the curse of dimensionality in machine learning applications.

**Principal Component Analysis (PCA)**: A linear dimensionality reduction method that identifies orthogonal directions of maximum variance in data, creating principal components that capture the most significant patterns while reducing feature space through eigenvalue decomposition of covariance matrices.

**t-Distributed Stochastic Neighbor Embedding (t-SNE)**: A non-linear dimensionality reduction technique optimized for data visualization that preserves local neighborhood structures by minimizing Kullback-Leibler divergence between probability distributions in high and low-dimensional spaces.

**Embeddings**: Dense vector representations of discrete objects (words, documents, categories) in continuous vector spaces where semantic relationships are encoded as geometric relationships, enabling mathematical operations on categorical data through learned representations.

**Word Embeddings**: Distributed representations of words in dense vector spaces where semantic similarity corresponds to vector proximity, learned through neural language models that capture syntactic and semantic relationships from large text corpora.

**Curse of Dimensionality**: The phenomenon where increasing feature dimensions exponentially expand data space volume, causing data sparsity, increased computational requirements, and degraded machine learning performance due to insufficient sample density in high-dimensional spaces.

**Manifold Learning**: The hypothesis that high-dimensional data often lies on or near lower-dimensional manifolds, enabling dimensionality reduction techniques to discover these intrinsic geometric structures for more efficient data representation.

**Feature Extraction**: The process of transforming original features into new representations that capture essential information while reducing dimensionality, often through mathematical transformations that combine multiple original features into composite variables.

**Latent Space**: A lower-dimensional representation space where data points are embedded, capturing underlying factors of variation that generate observed data patterns, commonly used in generative models and representation learning.

**Semantic Similarity**: The degree of meaning relatedness between concepts, often measured in embedding spaces through cosine similarity or Euclidean distance, enabling quantitative analysis of conceptual relationships.

## Theoretical Foundation of Dimensionality Reduction

Dimensionality reduction addresses fundamental challenges in high-dimensional data analysis where traditional machine learning algorithms suffer from computational inefficiency, visualization limitations, and the curse of dimensionality. The mathematical foundation rests on finding optimal lower-dimensional representations that preserve essential data characteristics.

Linear methods like PCA operate through eigenvalue decomposition of covariance matrices, identifying directions of maximum variance that capture the most significant data variation. The transformation projects data onto principal component subspaces defined by eigenvectors, enabling reconstruction with minimal information loss through rank approximation.

Non-linear techniques like t-SNE optimize probability distributions to preserve local neighborhood structures, using gradient descent to minimize divergence between high-dimensional and low-dimensional probability distributions. This approach excels at revealing cluster structures and non-linear relationships that linear methods cannot capture.

Embedding techniques transform discrete categorical data into continuous vector spaces through neural network training, where semantic relationships emerge as geometric properties. Modern transformer-based embeddings capture complex contextual relationships, enabling sophisticated natural language processing and recommendation systems.

def performance_monitor(func):
    """Decorator to monitor performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedDimensionalityReducer:
    """Comprehensive dimensionality reduction toolkit"""
    
    def __init__(self, random_state: int = 42):
        self.random_state = random_state
        self.reducers_ = {}
        self.results_ = {}
        self.scalers_ = {}
        
    @performance_monitor
    def apply_multiple_methods(self, X: np.ndarray, n_components: int = 2,
                              methods: List[str] = None) -> Dict[str, DimensionalityReductionResults]:
        """Apply multiple dimensionality reduction methods"""
        
        if methods is None:
            methods = ['pca', 'tsne', 'umap', 'ica', 'factor_analysis']
        
        # Standardize data
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        results = {}
        
        for method in methods:
            logger.info(f"Applying {method.upper()} dimensionality reduction")
            
            try:
                result = self._apply_single_method(X_scaled, method, n_components)
                results[method] = result
                
            except Exception as e:
                logger.error(f"Failed to apply {method}: {e}")
                continue
        
        self.results_ = results
        return results
    
    def _apply_single_method(self, X: np.ndarray, method: str, 
                           n_components: int) -> DimensionalityReductionResults:
        """Apply single dimensionality reduction method"""
        
        start_time = time.time()
        
        if method == 'pca':
            reducer = PCA(n_components=n_components, random_state=self.random_state)
            X_reduced = reducer.fit_transform(X)
            explained_variance = reducer.explained_variance_ratio_
            
            # Calculate reconstruction error
            X_reconstructed = reducer.inverse_transform(X_reduced)
            reconstruction_error = np.mean((X - X_reconstructed) ** 2)
            
        elif method == 'tsne':
            reducer = TSNE(n_components=n_components, random_state=self.random_state,
                          perplexity=min(30, X.shape[0] - 1))
            X_reduced = reducer.fit_transform(X)
            explained_variance = None
            reconstruction_error = None
            
        elif method == 'umap':
            try:
                reducer = UMAP(n_components=n_components, random_state=self.random_state)
                X_reduced = reducer.fit_transform(X)
                explained_variance = None
                reconstruction_error = None
            except ImportError:
                logger.warning("UMAP not available, using Isomap instead")
                reducer = Isomap(n_components=n_components)
                X_reduced = reducer.fit_transform(X)
                explained_variance = None
                reconstruction_error = reducer.reconstruction_error()
                
        elif method == 'ica':
            reducer = FastICA(n_components=n_components, random_state=self.random_state)
            X_reduced = reducer.fit_transform(X)
            explained_variance = None
            reconstruction_error = None
            
        elif method == 'factor_analysis':
            reducer = FactorAnalysis(n_components=n_components, random_state=self.random_state)
            X_reduced = reducer.fit_transform(X)
            explained_variance = None
            reconstruction_error = None
            
        elif method == 'truncated_svd':
            reducer = TruncatedSVD(n_components=n_components, random_state=self.random_state)
            X_reduced = reducer.fit_transform(X)
            explained_variance = reducer.explained_variance_ratio_
            reconstruction_error = None
            
        else:
            raise ValueError(f"Unknown method: {method}")
        
        transformation_time = time.time() - start_time
        
        # Calculate clustering quality metrics
        try:
            if X_reduced.shape[0] > 10:  # Ensure sufficient samples
                n_clusters = min(8, X_reduced.shape[0] // 2)
                kmeans = KMeans(n_clusters=n_clusters, random_state=self.random_state)
                cluster_labels = kmeans.fit_predict(X_reduced)
                silhouette = silhouette_score(X_reduced, cluster_labels)
            else:
                silhouette = None
        except:
            silhouette = None
        
        # Store reducer
        self.reducers_[method] = reducer
        
        return DimensionalityReductionResults(
            method=method,
            original_dimensions=X.shape[1],
            reduced_dimensions=n_components,
            explained_variance_ratio=explained_variance,
            transformation_time=transformation_time,
            reconstruction_error=reconstruction_error,
            silhouette_score=silhouette,
            embeddings=X_reduced
        )
    
    def compare_methods(self, results: Dict[str, DimensionalityReductionResults]) -> pd.DataFrame:
        """Compare dimensionality reduction methods"""
        
        comparison_data = []
        
        for method, result in results.items():
            comparison_data.append({
                'method': method.upper(),
                'transformation_time': result.transformation_time,
                'silhouette_score': result.silhouette_score,
                'reconstruction_error': result.reconstruction_error,
                'explained_variance_sum': (np.sum(result.explained_variance_ratio) 
                                        if result.explained_variance_ratio is not None else None)
            })
        
        return pd.DataFrame(comparison_data)
    
    def analyze_pca_components(self, X: np.ndarray, max_components: int = None) -> Dict[str, Any]:
        """Detailed PCA analysis with optimal component selection"""
        
        if max_components is None:
            max_components = min(X.shape[1], X.shape[0] - 1, 50)
        
        # Standardize data
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        # Fit PCA with maximum components
        pca = PCA(n_components=max_components, random_state=self.random_state)
        X_pca = pca.fit_transform(X_scaled)
        
        # Calculate cumulative explained variance
        cumulative_variance = np.cumsum(pca.explained_variance_ratio_)
        
        # Find optimal number of components (95% variance)
        optimal_components_95 = np.argmax(cumulative_variance >= 0.95) + 1
        optimal_components_90 = np.argmax(cumulative_variance >= 0.90) + 1
        
        # Elbow method for optimal components
        eigenvalues = pca.explained_variance_
        differences = np.diff(eigenvalues)
        second_differences = np.diff(differences)
        
        # Find elbow point
        if len(second_differences) > 0:
            elbow_point = np.argmax(second_differences) + 2
        else:
            elbow_point = optimal_components_90
        
        return {
            'pca_model': pca,
            'explained_variance_ratio': pca.explained_variance_ratio_,
            'cumulative_variance': cumulative_variance,
            'eigenvalues': eigenvalues,
            'optimal_components_95': optimal_components_95,
            'optimal_components_90': optimal_components_90,
            'elbow_point': elbow_point,
            'components_matrix': pca.components_,
            'transformed_data': X_pca
        }

class TextEmbeddingGenerator:
    """Advanced text embedding generation using multiple techniques"""
    
    def __init__(self, random_state: int = 42):
        self.random_state = random_state
        self.models_ = {}
        self.tokenizers_ = {}
        self.results_ = {}
        self.lemmatizer = WordNetLemmatizer()
        
    @performance_monitor
    def preprocess_text(self, texts: List[str]) -> List[List[str]]:
        """Advanced text preprocessing"""
        
        stop_words = set(stopwords.words('english'))
        processed_texts = []
        
        for text in texts:
            # Tokenize
            tokens = word_tokenize(text.lower())
            
            # Remove stopwords and non-alphabetic tokens
            tokens = [token for token in tokens if token.isalpha() and token not in stop_words]
            
            # Lemmatize
            tokens = [self.lemmatizer.lemmatize(token) for token in tokens]
            
            processed_texts.append(tokens)
        
        return processed_texts
    
    @performance_monitor
    def create_word2vec_embeddings(self, texts: List[str], 
                                  embedding_dim: int = 100,
                                  window: int = 5,
                                  min_count: int = 1) -> EmbeddingResults:
        """Create Word2Vec embeddings"""
        
        # Preprocess texts
        processed_texts = self.preprocess_text(texts)
        
        # Train Word2Vec model
        start_time = time.time()
        
        model = Word2Vec(
            sentences=processed_texts,
            vector_size=embedding_dim,
            window=window,
            min_count=min_count,
            workers=4,
            seed=self.random_state
        )
        
        training_time = time.time() - start_time
        
        # Get vocabulary
        vocabulary = list(model.wv.key_to_index.keys())
        
        # Create embeddings matrix
        embeddings_matrix = np.array([model.wv[word] for word in vocabulary])
        
        # Find similar words examples
        similarity_examples = {}
        for word in vocabulary[:10]:  # First 10 words
            try:
                similar_words = model.wv.most_similar(word, topn=3)
                similarity_examples[word] = similar_words
            except:
                similarity_examples[word] = []
        
        # Store model
        self.models_['word2vec'] = model
        
        return EmbeddingResults(
            method='word2vec',
            vocabulary_size=len(vocabulary),
            embedding_dimension=embedding_dim,
            training_time=training_time,
            loss_history=None,
            similarity_examples=similarity_examples,
            embeddings_matrix=embeddings_matrix
        )

    @performance_monitor
    def create_neural_embeddings(self, texts: List[str],
                                vocab_size: int = 10000,
                                embedding_dim: int = 100,
                                max_length: int = 100) -> EmbeddingResults:
        """Create neural network embeddings"""
        
        # Tokenize texts
        tokenizer = Tokenizer(num_words=vocab_size, oov_token='<OOV>')
        tokenizer.fit_on_texts(texts)
        sequences = tokenizer.texts_to_sequences(texts)
        
        # Pad sequences
        padded_sequences = pad_sequences(sequences, maxlen=max_length, truncating='post')
        
        # Create skip-gram training data
        X_train, y_train = self._create_skipgram_data(padded_sequences, window_size=2)
        
        # Build neural embedding model
        model = self._build_embedding_model(vocab_size, embedding_dim)
        
        # Train model
        start_time = time.time()
        
        history = model.fit(
            X_train, y_train,
            batch_size=128,
            epochs=10,
            validation_split=0.2,
            verbose=0
        )
        
        training_time = time.time() - start_time
        
        # Extract embeddings
        embeddings_layer = model.get_layer('embedding')
        embeddings_matrix = embeddings_layer.get_weights()[0]
        
        # Create similarity examples
        word_index = tokenizer.word_index
        index_word = {v: k for k, v in word_index.items()}
        
        similarity_examples = {}
        for i in range(1, min(11, len(index_word))):  # Skip 0 (padding)
            if i in index_word:
                word = index_word[i]
                # Find most similar words using cosine similarity
                word_embedding = embeddings_matrix[i]
                similarities = []
                
                for j in range(1, min(vocab_size, embeddings_matrix.shape[0])):
                    if j != i and j in index_word:
                        other_embedding = embeddings_matrix[j]
                        similarity = 1 - cosine(word_embedding, other_embedding)
                        similarities.append((index_word[j], similarity))
                
                similarities.sort(key=lambda x: x[1], reverse=True)
                similarity_examples[word] = similarities[:3]
        
        # Store models
        self.models_['neural'] = model
        self.tokenizers_['neural'] = tokenizer
        
        return EmbeddingResults(
            method='neural',
            vocabulary_size=vocab_size,
            embedding_dimension=embedding_dim,
            training_time=training_time,
            loss_history=history.history['loss'],
            similarity_examples=similarity_examples,
            embeddings_matrix=embeddings_matrix
        )
    
    def _create_skipgram_data(self, sequences: np.ndarray, window_size: int = 2) -> Tuple[np.ndarray, np.ndarray]:
        """Create skip-gram training data"""
        
        X, y = [], []
        
        for sequence in sequences:
            for i, target_word in enumerate(sequence):
                if target_word == 0:  # Skip padding
                    continue
                    
                # Context window
                start = max(0, i - window_size)
                end = min(len(sequence), i + window_size + 1)
                
                for j in range(start, end):
                    if j != i and sequence[j] != 0:
                        X.append(target_word)
                        y.append(sequence[j])
        
        return np.array(X), np.array(y)
    
    def _build_embedding_model(self, vocab_size: int, embedding_dim: int) -> keras.Model:
        """Build neural embedding model"""
        
        # Input layer
        target_input = layers.Input(shape=(), name='target')
        context_input = layers.Input(shape=(), name='context')
        
        # Embedding layers
        target_embedding = layers.Embedding(vocab_size, embedding_dim, name='embedding')(target_input)
        context_embedding = layers.Embedding(vocab_size, embedding_dim)(context_input)
        
        # Flatten embeddings
        target_flat = layers.Flatten()(target_embedding)
        context_flat = layers.Flatten()(context_embedding)
        
        # Compute similarity
        similarity = layers.Dot(axes=1)([target_flat, context_flat])
        output = layers.Dense(1, activation='sigmoid')(similarity)
        
        # Create model
        model = keras.Model(inputs=[target_input, context_input], outputs=output)
        model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
        
        return model
    
    @performance_monitor
    def create_transformer_embeddings(self, texts: List[str],
                                    model_name: str = 'all-MiniLM-L6-v2') -> EmbeddingResults:
        """Create transformer-based embeddings"""
        
        start_time = time.time()
        
        try:
            # Load pre-trained sentence transformer
            model = SentenceTransformer(model_name)
            
            # Generate embeddings
            embeddings_matrix = model.encode(texts)
            
            training_time = time.time() - start_time
            
            # Calculate similarities between first few texts
            similarity_examples = {}
            for i in range(min(5, len(texts))):
                similarities = []
                for j in range(len(texts)):
                    if i != j:
                        similarity = 1 - cosine(embeddings_matrix[i], embeddings_matrix[j])
                        similarities.append((f'text_{j}', similarity))
                
                similarities.sort(key=lambda x: x[1], reverse=True)
                similarity_examples[f'text_{i}'] = similarities[:3]
            
            self.models_['transformer'] = model
            
            return EmbeddingResults(
                method='transformer',
                vocabulary_size=len(texts),
                embedding_dimension=embeddings_matrix.shape[1],
                training_time=training_time,
                loss_history=None,
                similarity_examples=similarity_examples,
                embeddings_matrix=embeddings_matrix
            )
            
        except Exception as e:
            logger.error(f"Transformer embeddings failed: {e}")
            # Fallback to simple TF-IDF embeddings
            return self._create_tfidf_fallback(texts)
    
    def _create_tfidf_fallback(self, texts: List[str]) -> EmbeddingResults:
        """Fallback TF-IDF embeddings when transformers fail"""
        
        from sklearn.feature_extraction.text import TfidfVectorizer
        
        start_time = time.time()
        
        vectorizer = TfidfVectorizer(max_features=1000, stop_words='english')
        embeddings_matrix = vectorizer.fit_transform(texts).toarray()
        
        training_time = time.time() - start_time
        
        # Simple similarity calculation
        similarity_examples = {}
        for i in range(min(3, len(texts))):
            similarities = []
            for j in range(len(texts)):
                if i != j:
                    similarity = 1 - cosine(embeddings_matrix[i], embeddings_matrix[j])
                    similarities.append((f'text_{j}', similarity))
            
            similarities.sort(key=lambda x: x[1], reverse=True)
            similarity_examples[f'text_{i}'] = similarities[:2]
        
        return EmbeddingResults(
            method='tfidf_fallback',
            vocabulary_size=len(texts),
            embedding_dimension=embeddings_matrix.shape[1],
            training_time=training_time,
            loss_history=None,
            similarity_examples=similarity_examples,
            embeddings_matrix=embeddings_matrix
        )

class EmbeddingVisualizer:
    """Advanced visualization for embeddings and dimensionality reduction"""
    
    @staticmethod
    def plot_dimensionality_reduction_comparison(results: Dict[str, DimensionalityReductionResults],
                                               labels: Optional[np.ndarray] = None):
        """Plot comparison of dimensionality reduction methods"""
        
        n_methods = len(results)
        fig = make_subplots(
            rows=2, cols=(n_methods + 1) // 2,
            subplot_titles=[method.upper() for method in results.keys()],
            specs=[[{"type": "scatter"}] * ((n_methods + 1) // 2)] * 2
        )
        
        colors = px.colors.qualitative.Set1

    @staticmethod
    def plot_embedding_similarities(embedding_results: EmbeddingResults, top_n: int = 10):
        """Plot embedding similarity network"""
        
        similarities = embedding_results.similarity_examples
        
        # Create network graph
        G = nx.Graph()
        
        # Add nodes and edges
        for word, similar_words in list(similarities.items())[:top_n]:
            G.add_node(word)
            for similar_word, similarity in similar_words:
                if similarity > 0.5:  # Only add strong similarities
                    G.add_edge(word, similar_word, weight=similarity)
        
        # Calculate layout
        pos = nx.spring_layout(G, k=1, iterations=50)
        
        # Create edges trace
        edge_x, edge_y = [], []
        for edge in G.edges():
            x0, y0 = pos[edge[0]]
            x1, y1 = pos[edge[1]]
            edge_x.extend([x0, x1, None])
            edge_y.extend([y0, y1, None])
        
        edge_trace = go.Scatter(
            x=edge_x, y=edge_y,
            line=dict(width=0.5, color='#888'),
            hoverinfo='none',
            mode='lines'
        )
        
        # Create nodes trace
        node_x, node_y, node_text = [], [], []
        for node in G.nodes():
            x, y = pos[node]
            node_x.append(x)
            node_y.append(y)
            node_text.append(node)
        
        node_trace = go.Scatter(
            x=node_x, y=node_y,
            mode='markers+text',
            hoverinfo='text',
            text=node_text,
            textposition="middle center",
            marker=dict(
                size=20,
                color='lightblue',
                line=dict(width=2, color='darkblue')
            )
        )
        
        fig = go.Figure(data=[edge_trace, node_trace],
                       layout=go.Layout(
                           title=f'{embedding_results.method.title()} Embedding Similarity Network',
                           showlegend=False,
                           hovermode='closest',
                           margin=dict(b=20,l=5,r=5,t=40),
                           annotations=[ dict(
                               text="Word similarity network based on embeddings",
                               showarrow=False,
                               xref="paper", yref="paper",
                               x=0.005, y=-0.002 ) ],
                           xaxis=dict(showgrid=False, zeroline=False, showticklabels=False),
                           yaxis=dict(showgrid=False, zeroline=False, showticklabels=False)
                       ))
        
        return fig
