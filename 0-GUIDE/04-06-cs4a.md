## Key Terms

**Data Transformer**: A scikit-learn object that implements the fit-transform pattern to systematically convert raw data into machine learning-ready features, maintaining consistency between training and inference while enabling complex data preprocessing workflows.

**Categorical Encoding**: The process of converting categorical variables into numerical representations that machine learning algorithms can process, including techniques like one-hot encoding, label encoding, target encoding, and frequency encoding.

**Polynomial Features**: Mathematical transformations that create interaction terms and higher-order polynomial combinations of input features, capturing non-linear relationships and feature interactions that linear models can leverage.

**Numerical Transformation**: Advanced preprocessing techniques for continuous variables including scaling, normalization, power transformations, and binning to improve model convergence and handle skewed distributions.

**Column Transformer**: A scikit-learn utility that applies different transformation pipelines to different subsets of columns simultaneously, enabling heterogeneous data processing where different feature types require distinct preprocessing approaches.

**Custom Transformer**: User-defined transformation classes that inherit from BaseEstimator and TransformerMixin, implementing domain-specific feature engineering logic while maintaining compatibility with scikit-learn pipelines.

**Feature Engineering Pipeline**: A systematic workflow that chains multiple transformation steps together, ensuring reproducible and maintainable data preprocessing from raw input to model-ready features.

**Transformer Composition**: The practice of combining multiple transformers using FeatureUnion, ColumnTransformer, or Pipeline to create complex preprocessing workflows that handle diverse data types and transformation requirements.

## Theoretical Foundation of Data Transformers

Data transformers represent the cornerstone of effective machine learning preprocessing, providing systematic methods to convert raw data into formats that algorithms can efficiently process. The transformer pattern ensures consistency between training and inference phases while enabling complex feature engineering workflows that significantly impact model performance.

The mathematical foundation involves understanding how different transformations affect data distributions, feature relationships, and algorithm behavior. Categorical encoding techniques must preserve meaningful relationships while avoiding curse of dimensionality, polynomial features must balance expressiveness with overfitting risk, and numerical transformations must improve convergence without losing information.

def performance_monitor(func):
    """Decorator to monitor transformer performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedCategoricalEncoder(BaseEstimator, TransformerMixin):
    """Advanced categorical encoder with multiple encoding strategies"""
    
    def __init__(self, strategy: str = 'auto', target_col: str = None,
                 handle_unknown: str = 'ignore', min_frequency: int = 1,
                 max_categories: int = None):
        self.strategy = strategy
        self.target_col = target_col
        self.handle_unknown = handle_unknown
        self.min_frequency = min_frequency
        self.max_categories = max_categories
        
        # Internal state
        self.encoders_ = {}
        self.feature_names_out_ = []
        self.encoding_strategies_ = {}
        
    def fit(self, X: pd.DataFrame, y: pd.Series = None):
        """Fit encoders for each categorical column"""
        
        self.encoders_ = {}
        self.encoding_strategies_ = {}
        
        categorical_columns = X.select_dtypes(include=['object', 'category']).columns
        
        for col in categorical_columns:
            # Determine encoding strategy for each column
            strategy = self._determine_encoding_strategy(X[col], y, col)
            self.encoding_strategies_[col] = strategy
            
            # Create and fit encoder
            encoder = self._create_encoder(strategy, y)
            
            if strategy in ['target', 'woe', 'catboost'] and y is not None:
                encoder.fit(X[[col]], y)
            else:
                encoder.fit(X[[col]])
            
            self.encoders_[col] = encoder
        
        # Prepare output feature names
        self._prepare_feature_names(X)
        
        return self
    
    def transform(self, X: pd.DataFrame) -> pd.DataFrame:
        """Transform categorical columns using fitted encoders"""
        check_is_fitted(self, 'encoders_')
        
        X_transformed = X.copy()
        
        # Remove original categorical columns and add encoded versions
        categorical_columns = X.select_dtypes(include=['object', 'category']).columns
        
        for col in categorical_columns:
            if col in self.encoders_:
                # Transform using fitted encoder
                encoded = self.encoders_[col].transform(X[[col]])
                
                # Handle different encoder output formats
                if hasattr(encoded, 'toarray'):  # Sparse matrix
                    encoded = encoded.toarray()
                
                if isinstance(encoded, np.ndarray):
                    if encoded.shape[1] == 1:
                        X_transformed[f'{col}_encoded'] = encoded.flatten()
                    else:
                        # Multiple columns (one-hot encoding)
                        feature_names = self._get_encoder_feature_names(col)
                        for i, name in enumerate(feature_names):
                            X_transformed[name] = encoded[:, i]
                else:
                    X_transformed[f'{col}_encoded'] = encoded
                
                # Remove original column
                X_transformed = X_transformed.drop(columns=[col])
        
        return X_transformed
    
    def _determine_encoding_strategy(self, column: pd.Series, y: pd.Series = None, col_name: str = None) -> str:
        """Automatically determine the best encoding strategy for a column"""
        
        if self.strategy != 'auto':
            return self.strategy
        
        unique_count = column.nunique()
        total_count = len(column)
        cardinality_ratio = unique_count / total_count
        
        # High cardinality categorical variables
        if unique_count > 50 or cardinality_ratio > 0.1:
            if y is not None:
                return 'target'  # Target encoding for high cardinality
            else:
                return 'frequency'  # Frequency encoding
        
        # Medium cardinality
        elif unique_count > 10:
            if y is not None:
                return 'woe'  # Weight of Evidence
            else:
                return 'label'  # Label encoding
        
        # Low cardinality
        else:
            return 'onehot'  # One-hot encoding
    
    def _create_encoder(self, strategy: str, y: pd.Series = None):
        """Create encoder based on strategy"""
        
        encoders = {
            'onehot': OneHotEncoder(handle_unknown=self.handle_unknown, sparse=False),
            'label': OrdinalEncoder(handle_unknown='use_encoded_value', unknown_value=-1),
            'target': ce.TargetEncoder(smoothing=1.0, min_samples_leaf=1),
            'frequency': ce.CountEncoder(),
            'binary': ce.BinaryEncoder(),
            'helmert': ce.HelmertEncoder(),
            'sum': ce.SumEncoder(),
            'polynomial': ce.PolynomialEncoder(),
            'backward_difference': ce.BackwardDifferenceEncoder(),
            'woe': ce.WOEEncoder(),
            'catboost': ce.CatBoostEncoder(),
            'james_stein': ce.JamesSteinEncoder(),
            'leave_one_out': ce.LeaveOneOutEncoder()
        }
        
        if strategy in encoders:
            return encoders[strategy]
        else:
            return OrdinalEncoder(handle_unknown='use_encoded_value', unknown_value=-1)
    
    def _get_encoder_feature_names(self, col: str) -> List[str]:
        """Get feature names from encoder"""
        
        encoder = self.encoders_[col]
        
        if hasattr(encoder, 'get_feature_names_out'):
            try:
                return encoder.get_feature_names_out([col]).tolist()
            except:
                pass
        
        if hasattr(encoder, 'categories_'):
            return [f'{col}_{cat}' for cat in encoder.categories_[0]]
        
        return [f'{col}_encoded']
    
    def _prepare_feature_names(self, X: pd.DataFrame):
        """Prepare output feature names"""
        
        feature_names = []
        
        # Add non-categorical features
        non_categorical = X.select_dtypes(exclude=['object', 'category']).columns
        feature_names.extend(non_categorical.tolist())
        
        # Add encoded categorical features
        categorical_columns = X.select_dtypes(include=['object', 'category']).columns
        for col in categorical_columns:
            if col in self.encoders_:
                feature_names.extend(self._get_encoder_feature_names(col))
        
        self.feature_names_out_ = feature_names
    
    def get_feature_names_out(self, input_features=None):
        """Get output feature names"""
        check_is_fitted(self, 'feature_names_out_')
        return self.feature_names_out_

class AdvancedNumericalTransformer(BaseEstimator, TransformerMixin):
    """Advanced numerical transformer with multiple transformation strategies"""
    
    def __init__(self, scaling_strategy: str = 'auto', 
                 distribution_transform: bool = True,
                 outlier_treatment: str = 'clip',
                 create_interactions: bool = False,
                 polynomial_degree: int = 2,
                 binning_strategy: str = None):
        
        self.scaling_strategy = scaling_strategy
        self.distribution_transform = distribution_transform
        self.outlier_treatment = outlier_treatment
        self.create_interactions = create_interactions
        self.polynomial_degree = polynomial_degree
        self.binning_strategy = binning_strategy
        
        # Internal state
        self.scalers_ = {}
        self.transformers_ = {}
        self.feature_statistics_ = {}
        self.feature_names_out_ = []
        
    def fit(self, X: pd.DataFrame, y: pd.Series = None):
        """Fit transformers for numerical columns"""
        
        numerical_columns = X.select_dtypes(include=[np.number]).columns
        
        for col in numerical_columns:
            # Calculate statistics
            self.feature_statistics_[col] = self._calculate_statistics(X[col])
            
            # Determine scaling strategy
            scaling_strategy = self._determine_scaling_strategy(X[col])
            scaler = self._create_scaler(scaling_strategy)
            scaler.fit(X[[col]])
            self.scalers_[col] = scaler
            
            # Distribution transformation
            if self.distribution_transform:
                transformer = self._create_distribution_transformer(X[col])
                if transformer:
                    transformer.fit(X[[col]])
                    self.transformers_[col] = transformer
        
        # Prepare feature names
        self._prepare_feature_names(X)
        
        return self
    
    def transform(self, X: pd.DataFrame) -> pd.DataFrame:
        """Transform numerical columns"""
        check_is_fitted(self, 'scalers_')
        
        X_transformed = X.copy()
        numerical_columns = X.select_dtypes(include=[np.number]).columns
        
        for col in numerical_columns:
            if col in self.scalers_:
                # Outlier treatment
                if self.outlier_treatment == 'clip':
                    X_transformed[col] = self._clip_outliers(X_transformed[col], col)
                elif self.outlier_treatment == 'remove':
                    # Mark outliers for removal (handled externally)
                    pass
                
                # Distribution transformation
                if col in self.transformers_:
                    X_transformed[col] = self.transformers_[col].transform(X_transformed[[col]]).flatten()
                
                # Scaling
                X_transformed[col] = self.scalers_[col].transform(X_transformed[[col]]).flatten()
                
                # Additional engineered features
                self._create_engineered_features(X_transformed, col)
        
        # Create interaction features
        if self.create_interactions:
            X_transformed = self._create_interaction_features(X_transformed, numerical_columns)
        
        # Create polynomial features
        if self.polynomial_degree > 1:
            X_transformed = self._create_polynomial_features(X_transformed, numerical_columns)
        
        return X_transformed
    
    def _calculate_statistics(self, series: pd.Series) -> Dict[str, float]:
        """Calculate comprehensive statistics for a numerical series"""
        
        clean_series = series.dropna()
        
        return {
            'mean': clean_series.mean(),
            'std': clean_series.std(),
            'median': clean_series.median(),
            'q1': clean_series.quantile(0.25),
            'q3': clean_series.quantile(0.75),
            'iqr': clean_series.quantile(0.75) - clean_series.quantile(0.25),
            'skewness': stats.skew(clean_series),
            'kurtosis': stats.kurtosis(clean_series),
            'min': clean_series.min(),
            'max': clean_series.max(),
            'range': clean_series.max() - clean_series.min(),
            'cv': clean_series.std() / (clean_series.mean() + 1e-8),  # Coefficient of variation
            'outlier_ratio': self._calculate_outlier_ratio(clean_series)
        }
    
    def _calculate_outlier_ratio(self, series: pd.Series) -> float:
        """Calculate the ratio of outliers using IQR method"""
        
        q1, q3 = series.quantile([0.25, 0.75])
        iqr = q3 - q1
        lower_bound = q1 - 1.5 * iqr
        upper_bound = q3 + 1.5 * iqr
        
        outliers = (series < lower_bound) | (series > upper_bound)
        return outliers.sum() / len(series)
    
    def _determine_scaling_strategy(self, series: pd.Series) -> str:
        """Determine optimal scaling strategy based on data characteristics"""
        
        if self.scaling_strategy != 'auto':
            return self.scaling_strategy
        
        stats_dict = self.feature_statistics_[series.name]
        
        # High outlier ratio -> Robust scaling
        if stats_dict['outlier_ratio'] > 0.1:
            return 'robust'
        
        # High skewness -> Quantile transformation
        if abs(stats_dict['skewness']) > 2:
            return 'quantile'
        
        # High kurtosis -> Power transformation
        if abs(stats_dict['kurtosis']) > 3:
            return 'power'
        
        # Default to standard scaling
        return 'standard'
    
    def _create_scaler(self, strategy: str):
        """Create scaler based on strategy"""
        
        scalers = {
            'standard': StandardScaler(),
            'minmax': MinMaxScaler(),
            'robust': RobustScaler(),
            'quantile': QuantileTransformer(output_distribution='normal'),
            'power': PowerTransformer(method='yeo-johnson'),
            'maxabs': MaxAbsScaler(),
            'normalizer': Normalizer()
        }
        
        return scalers.get(strategy, StandardScaler())
    
    def _create_distribution_transformer(self, series: pd.Series):
        """Create distribution transformer if needed"""
        
        stats_dict = self.feature_statistics_[series.name]
        
        # Highly skewed data
        if abs(stats_dict['skewness']) > 2:
            if (series > 0).all():
                # Box-Cox for positive data
                return FunctionTransformer(
                    func=lambda x: stats.boxcox(x.flatten() + 1)[0].reshape(-1, 1),
                    inverse_func=None,
                    validate=False
                )
            else:
                # Yeo-Johnson for all data
                return PowerTransformer(method='yeo-johnson')
        
        return None
    
    def _clip_outliers(self, series: pd.Series, col: str) -> pd.Series:
        """Clip outliers using IQR method"""
        
        stats_dict = self.feature_statistics_[col]
        lower_bound = stats_dict['q1'] - 1.5 * stats_dict['iqr']
        upper_bound = stats_dict['q3'] + 1.5 * stats_dict['iqr']
        
        return series.clip(lower=lower_bound, upper=upper_bound)
    
    def _create_engineered_features(self, X: pd.DataFrame, col: str):
        """Create additional engineered features"""
        
        # Mathematical transformations
        if (X[col] >= 0).all():
            X[f'{col}_sqrt'] = np.sqrt(X[col])
            X[f'{col}_log1p'] = np.log1p(X[col])
        
        X[f'{col}_squared'] = X[col] ** 2
        X[f'{col}_cubed'] = X[col] ** 3
        
        # Statistical features
        stats_dict = self.feature_statistics_[col]
        X[f'{col}_zscore'] = (X[col] - stats_dict['mean']) / (stats_dict['std'] + 1e-8)
        X[f'{col}_robust_scale'] = (X[col] - stats_dict['median']) / (stats_dict['iqr'] + 1e-8)
        
        # Binning if requested
        if self.binning_strategy:
            if self.binning_strategy == 'equal_width':
                X[f'{col}_binned'] = pd.cut(X[col], bins=5, labels=False)
            elif self.binning_strategy == 'equal_frequency':
                X[f'{col}_binned'] = pd.qcut(X[col], q=5, labels=False, duplicates='drop')
    
    def _create_interaction_features(self, X: pd.DataFrame, numerical_columns: List[str]) -> pd.DataFrame:
        """Create interaction features between numerical columns"""
        
        for i, col1 in enumerate(numerical_columns):
            for col2 in numerical_columns[i+1:]:
                if col1 in X.columns and col2 in X.columns:
                    X[f'{col1}_{col2}_product'] = X[col1] * X[col2]
                    X[f'{col1}_{col2}_ratio'] = X[col1] / (X[col2] + 1e-8)
                    X[f'{col1}_{col2}_diff'] = X[col1] - X[col2]
                    X[f'{col1}_{col2}_sum'] = X[col1] + X[col2]
        
        return X
    
    def _create_polynomial_features(self, X: pd.DataFrame, numerical_columns: List[str]) -> pd.DataFrame:
        """Create polynomial features"""
        
        # Limit to first few columns to avoid feature explosion
        poly_columns = numerical_columns[:min(5, len(numerical_columns))]
        
        if poly_columns:
            poly = PolynomialFeatures(degree=self.polynomial_degree, include_bias=False)
            poly_data = poly.fit_transform(X[poly_columns].fillna(0))
            poly_names = poly.get_feature_names_out(poly_columns)
            
            for i, name in enumerate(poly_names):
                if name not in poly_columns:  # Don't duplicate original features
                    X[f'poly_{name}'] = poly_data[:, i]
        
        return X
    
    def _prepare_feature_names(self, X: pd.DataFrame):
        """Prepare output feature names"""
        
        feature_names = list(X.columns)
        numerical_columns = X.select_dtypes(include=[np.number]).columns
        
        # Add engineered feature names
        for col in numerical_columns:
            feature_names.extend([
                f'{col}_sqrt', f'{col}_log1p', f'{col}_squared', f'{col}_cubed',
                f'{col}_zscore', f'{col}_robust_scale'
            ])
            
            if self.binning_strategy:
                feature_names.append(f'{col}_binned')
        
        # Add interaction feature names
        if self.create_interactions:
            for i, col1 in enumerate(numerical_columns):
                for col2 in numerical_columns[i+1:]:
                    feature_names.extend([
                        f'{col1}_{col2}_product', f'{col1}_{col2}_ratio',
                        f'{col1}_{col2}_diff', f'{col1}_{col2}_sum'
                    ])
        
        self.feature_names_out_ = feature_names
    
    def get_feature_names_out(self, input_features=None):
        """Get output feature names"""
        check_is_fitted(self, 'feature_names_out_')
        return self.feature_names_out_

class ComprehensiveTransformerPipeline:
    """Comprehensive transformer pipeline with advanced capabilities"""
    
    def __init__(self, task_type: str = 'auto', random_state: int = 42):
        self.task_type = task_type
        self.random_state = random_state
        self.pipelines = {}
        self.best_pipeline = None
        self.transformer_analysis = {}
        
    @performance_monitor
    def build_transformer_pipeline(self, X: pd.DataFrame, y: pd.Series = None,
                                 test_size: float = 0.2) -> Dict[str, Pipeline]:
        """Build comprehensive transformer pipeline with multiple strategies"""
        
        # Auto-detect task type
        if self.task_type == 'auto':
            self.task_type = self._detect_task_type(y) if y is not None else 'unsupervised'
        
        # Split data for evaluation
        if y is not None:
            X_train, X_test, y_train, y_test = train_test_split(
                X, y, test_size=test_size, random_state=self.random_state
            )
        else:
            X_train, X_test = train_test_split(X, test_size=test_size, random_state=self.random_state)
            y_train, y_test = None, None
        
        # Build different pipeline configurations
        pipeline_configs = [
            ('basic_preprocessing', self._build_basic_pipeline()),
            ('advanced_encoding', self._build_advanced_encoding_pipeline()),
            ('feature_engineering', self._build_feature_engineering_pipeline()),
            ('comprehensive', self._build_comprehensive_pipeline())
        ]
        
        # Evaluate each pipeline
        for name, pipeline in pipeline_configs:
            logger.info(f"Building and evaluating {name} pipeline")
            
            try:
                # Fit pipeline
                pipeline.fit(X_train, y_train)
                
                # Transform data
                X_train_transformed = pipeline.transform(X_train)
                X_test_transformed = pipeline.transform(X_test)
                
                # Analyze transformation
                analysis = self._analyze_transformation(
                    name, X_train, X_train_transformed, y_train, y_test
                )
                
                self.pipelines[name] = pipeline
                self.transformer_analysis[name] = analysis
                
            except Exception as e:
                logger.error(f"Error building {name} pipeline: {e}")
                continue
        
        # Select best pipeline
        self._select_best_pipeline()
        
        return self.pipelines
    
    def _detect_task_type(self, y: pd.Series) -> str:
        """Detect if task is classification or regression"""
        
        if pd.api.types.is_numeric_dtype(y):
            unique_ratio = y.nunique() / len(y)
            if unique_ratio < 0.05 or y.nunique() <= 20:
                return 'classification'
            else:
                return 'regression'
        else:
            return 'classification'
    
    def _build_basic_pipeline(self) -> Pipeline:
        """Build basic preprocessing pipeline"""
        
        # Simple numerical and categorical preprocessing
        numerical_features = make_column_selector(dtype_include=np.number)
        categorical_features = make_column_selector(dtype_include=['object', 'category'])
        
        numerical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='median')),
            ('scaler', StandardScaler())
        ])
        
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
            ('encoder', OneHotEncoder(handle_unknown='ignore', sparse=False))
        ])
        
        preprocessor = ColumnTransformer([
            ('num', numerical_pipeline, numerical_features),
            ('cat', categorical_pipeline, categorical_features)
        ])
        
        return Pipeline([('preprocessor', preprocessor)])
    
    def _build_advanced_encoding_pipeline(self) -> Pipeline:
        """Build pipeline with advanced categorical encoding"""
        
        numerical_features = make_column_selector(dtype_include=np.number)
        categorical_features = make_column_selector(dtype_include=['object', 'category'])
        
        numerical_pipeline = Pipeline([
            ('imputer', KNNImputer(n_neighbors=5)),
            ('scaler', RobustScaler())
        ])
        
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
            ('encoder', AdvancedCategoricalEncoder(strategy='auto'))
        ])
        
        preprocessor = ColumnTransformer([
            ('num', numerical_pipeline, numerical_features),
            ('cat', categorical_pipeline, categorical_features)
        ])
        
        return Pipeline([('preprocessor', preprocessor)])
    
    def _build_feature_engineering_pipeline(self) -> Pipeline:
        """Build pipeline with extensive feature engineering"""
        
        numerical_features = make_column_selector(dtype_include=np.number)
        categorical_features = make_column_selector(dtype_include=['object', 'category'])
        
        numerical_pipeline = Pipeline([
            ('imputer', IterativeImputer(random_state=self.random_state)),
            ('transformer', AdvancedNumericalTransformer(
                scaling_strategy='auto',
                distribution_transform=True,
                create_interactions=True,
                polynomial_degree=2
            ))
        ])
        
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
            ('encoder', AdvancedCategoricalEncoder(strategy='auto'))
        ])
        
        preprocessor = ColumnTransformer([
            ('num', numerical_pipeline, numerical_features),
            ('cat', categorical_pipeline, categorical_features)
        ])
        
        return Pipeline([
            ('preprocessor', preprocessor),
            ('feature_selection', VarianceThreshold(threshold=0.01))

    def _build_comprehensive_pipeline(self) -> Pipeline:
        """Build comprehensive pipeline with all advanced features"""
        
        numerical_features = make_column_selector(dtype_include=np.number)
        categorical_features = make_column_selector(dtype_include=['object', 'category'])
        
        numerical_pipeline = Pipeline([
            ('imputer', IterativeImputer(random_state=self.random_state)),
            ('outlier_treatment', FunctionTransformer(
                func=lambda X: np.clip(X, np.percentile(X, 1, axis=0), np.percentile(X, 99, axis=0)),
                validate=False
            )),
            ('transformer', AdvancedNumericalTransformer(
                scaling_strategy='auto',
                distribution_transform=True,
                create_interactions=True,
                polynomial_degree=2,
                binning_strategy='equal_frequency'
            ))
        ])
        
        categorical_pipeline = Pipeline([
            ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),

        ])
        
        preprocessor = ColumnTransformer([

            ('cat', categorical_pipeline, categorical_features)
        ])
        
        return Pipeline([

    @performance_monitor
    def _analyze_transformation(self, name: str, X_original: pd.DataFrame,
                              X_transformed: np.ndarray, y_train: pd.Series = None,
                              y_test: pd.Series = None) -> TransformerAnalysis:
        """Analyze transformation results"""
        
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        # Basic transformation metrics
        input_shape = X_original.shape
        output_shape = X_transformed.shape
        transformation_time = time.time() - start_time
        memory_usage = psutil.Process().memory_info().rss / 1024 / 1024 - start_memory
        
        # Feature names (if available)
        feature_names = []
        if hasattr(X_transformed, 'columns'):
            feature_names = X_transformed.columns.tolist()
        else:
            feature_names = [f'feature_{i}' for i in range(output_shape[1])]
        
        # Data quality score (simplified)
        data_quality_score = self._calculate_data_quality_score(X_transformed)
        
        return TransformerAnalysis(
            transformer_name=name,
            input_shape=input_shape,
            output_shape=output_shape,
            transformation_time=transformation_time,
            memory_usage=memory_usage,
            feature_names=feature_names,
            data_quality_score=data_quality_score
        )
    
    def _calculate_data_quality_score(self, X: np.ndarray) -> float:
        """Calculate a simple data quality score"""
        
        if isinstance(X, pd.DataFrame):
            X = X.values
        
        # Check for missing values
        missing_ratio = np.isnan(X).sum() / X.size
        
        # Check for infinite values
        infinite_ratio = np.isinf(X).sum() / X.size
        
        # Check for constant features
        constant_features = np.var(X, axis=0) == 0
        constant_ratio = constant_features.sum() / X.shape[1]
        
        # Calculate quality score (higher is better)
        quality_score = 1.0 - (missing_ratio + infinite_ratio + constant_ratio * 0.5)
        
        return max(0.0, min(1.0, quality_score))
    
    def _select_best_pipeline(self):
        """Select best pipeline based on analysis"""
        
        if not self.transformer_analysis:
            return
        
        # Score pipelines based on multiple criteria
        pipeline_scores = {}
        
        for name, analysis in self.transformer_analysis.items():
            # Combine multiple factors
            feature_expansion = analysis.output_shape[1] / analysis.input_shape[1]
            quality_score = analysis.data_quality_score
            efficiency_score = 1.0 / (analysis.transformation_time + 1e-6)
            
            # Weighted combination
            total_score = (
                0.4 * quality_score +
                0.3 * min(feature_expansion / 5.0, 1.0) +  # Cap feature expansion benefit
                0.3 * min(efficiency_score / 10.0, 1.0)    # Cap efficiency benefit
            )
            
            pipeline_scores[name] = total_score
        
        # Select best pipeline
        best_name = max(pipeline_scores.keys(), key=lambda x: pipeline_scores[x])
        self.best_pipeline = self.pipelines[best_name]
        
        logger.info(f"Best pipeline selected: {best_name} with score {pipeline_scores[best_name]:.4f}")

                    X[numerical_cols].max(axis=1) - X[numerical_cols].min(axis=1)

                        stats = self.feature_stats_[col]
                        lower_bound = stats['q1'] - 1.5 * stats['iqr']

                            (X[col] < lower_bound) | (X[col] > upper_bound)

                        X_transformed[f'{col}_zscore_abs'] = np.abs(
                            (X[col] - stats['mean']) / (stats['std'] + 1e-8)
                        )
