# 09. Ensemble Models: Power of Diversity

## Key Terms and Concepts

- **Ensemble Learning**: A machine learning paradigm where multiple models (called "base learners") are trained to solve the same problem and combined to get better results.
- **Bagging (Bootstrap Aggregating)**: A technique that involves training multiple models on different random subsamples of the training dataset with replacement and combining their predictions.
- **Boosting**: A sequential ensemble technique where each model attempts to correct the errors made by the previous models.
- **Stacking**: An ensemble method that combines multiple classification or regression models via a meta-learner.
- **Weak Learner**: A model that performs slightly better than random guessing.
- **Strong Learner**: A model with high predictive performance.
- **Diversity**: The degree to which models make different errors on the same data points.
- **Voting**: A method for combining predictions from multiple classifiers.
- **Feature Importance**: Metrics that indicate the relative importance of each feature in making predictions.
- **Out-of-Bag (OOB) Estimation**: A method of measuring prediction error using bootstrap aggregation.

# Function to demonstrate the core concept of ensemble learning
def demonstrate_ensemble_concept(X, y, n_estimators=10, test_size=0.25, random_state=42):
    """
    Demonstrates how combining multiple weak models can create a stronger model.
    
    Parameters:
    -----------
    X : array-like
        Features
    y : array-like
        Target variable
    n_estimators : int
        Number of base models to create
    test_size : float
        Proportion of data to use for testing
    random_state : int
        Random seed for reproducibility
    
    Returns:
    --------
    dict : Dictionary with performance metrics for individual models and ensemble
    """
    # Split data
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=test_size, random_state=random_state, stratify=y
    )
    
    # Create and train multiple weak learners (shallow decision trees)
    weak_learners = []
    weak_predictions = []
    
    for i in range(n_estimators):
        # Create a weak learner (shallow decision tree)
        model = DecisionTreeClassifier(max_depth=2, random_state=random_state + i)
        model.fit(X_train, y_train)
        
        # Save model and its predictions
        weak_learners.append(model)
        weak_predictions.append(model.predict(X_test))
    
    # Calculate accuracy for each weak learner
    weak_accuracies = [accuracy_score(y_test, pred) for pred in weak_predictions]
    
    # Create ensemble prediction by majority voting
    ensemble_pred = np.array([1 if sum(predictions) > len(predictions)/2 else 0 
                              for predictions in zip(*weak_predictions)])
    
    # Calculate ensemble accuracy
    ensemble_accuracy = accuracy_score(y_test, ensemble_pred)
    
    # Compare with a stronger single model
    strong_model = DecisionTreeClassifier(max_depth=None, random_state=random_state)
    strong_model.fit(X_train, y_train)
    strong_pred = strong_model.predict(X_test)
    strong_accuracy = accuracy_score(y_test, strong_pred)
    
    # Return results
    return {
        'weak_accuracies': weak_accuracies,
        'mean_weak_accuracy': np.mean(weak_accuracies),
        'ensemble_accuracy': ensemble_accuracy,
        'strong_model_accuracy': strong_accuracy
    }

## Bagging: Bootstrap Aggregating

Bagging creates multiple versions of a predictor and combines them through averaging (regression) or voting (classification):

def explore_bagging(X, y, test_size=0.25, random_state=42):
    """

    -----------
    X : array-like
        Features
    y : array-like
        Target variable
    test_size : float
        Proportion of data to use for testing
    random_state : int
        Random seed for reproducibility

    --------
    dict : Dictionary with performance metrics for bagging models

        X, y, test_size=test_size, random_state=random_state, stratify=y
    )
    
    # 1. Basic Bagging with Decision Trees
    bagging_clf = BaggingClassifier(
        estimator=DecisionTreeClassifier(random_state=random_state),
        n_estimators=100,
        max_samples=0.8,  # Use 80% of samples for each estimator
        max_features=0.8,  # Use 80% of features for each estimator
        bootstrap=True,    # Sample with replacement
        bootstrap_features=True,  # Sample features with replacement
        random_state=random_state,
        n_jobs=-1
    )
    
    bagging_clf.fit(X_train, y_train)
    bagging_pred = bagging_clf.predict(X_test)
    bagging_accuracy = accuracy_score(y_test, bagging_pred)
    
    # 2. Random Forest (specialized bagging with feature selection)
    rf_clf = RandomForestClassifier(
        n_estimators=100,
        max_depth=None,
        min_samples_split=2,
        min_samples_leaf=1,
        max_features='sqrt',  # Key feature of Random Forest
        bootstrap=True,
        oob_score=True,  # Use out-of-bag samples to estimate accuracy
        random_state=random_state,
        n_jobs=-1
    )
    
    rf_clf.fit(X_train, y_train)
    rf_pred = rf_clf.predict(X_test)
    rf_accuracy = accuracy_score(y_test, rf_pred)
    
    # Out-of-bag score (estimate of generalization accuracy)
    oob_score = rf_clf.oob_score_
    
    # Feature importance
    feature_importances = pd.DataFrame({
        'Feature': range(X.shape[1]),
        'Importance': rf_clf.feature_importances_
    }).sort_values('Importance', ascending=False)
    
    # 3. Explore the effect of n_estimators
    n_estimators_range = [10, 50, 100, 200]
    n_estimators_scores = []
    
    for n_est in n_estimators_range:
        rf = RandomForestClassifier(
            n_estimators=n_est, 
            random_state=random_state,
            n_jobs=-1
        )
        rf.fit(X_train, y_train)
        score = accuracy_score(y_test, rf.predict(X_test))
        n_estimators_scores.append(score)
    
    return {
        'bagging_accuracy': bagging_accuracy,
        'rf_accuracy': rf_accuracy,
        'oob_score': oob_score,
        'feature_importances': feature_importances,
        'n_estimators_effect': {
            'n_estimators': n_estimators_range,
            'scores': n_estimators_scores
        }
    }

## Stacking: Meta-Learning Approach

Stacking combines multiple models via a meta-learner that takes the predictions of base models as input:

```python
def explore_stacking(X, y, test_size=0.25, random_state=42):
    """
    Demonstrates stacking ensemble techniques.
    
    Parameters:
    -----------
    X : array-like
        Features
    y : array-like
        Target variable
    test_size : float
        Proportion of data to use for testing
    random_state : int
        Random seed for reproducibility
    
    Returns:
    --------
    dict : Dictionary with performance metrics for stacking models
    """
    # Split data
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=test_size, random_state=random_state, stratify=y
    )
    
    # 1. Simple Voting Ensemble (not true stacking, but a simple ensemble)
    voting_clf = VotingClassifier(
        estimators=[
            ('rf', RandomForestClassifier(n_estimators=100, random_state=random_state)),
            ('gb', GradientBoostingClassifier(n_estimators=100, random_state=random_state)),
            ('xgb', xgb.XGBClassifier(n_estimators=100, random_state=random_state))
        ],
        voting='soft'  # Use predicted probabilities
    )
    
    voting_clf.fit(X_train, y_train)
    voting_pred = voting_clf.predict(X_test)
    voting_accuracy = accuracy_score(y_test, voting_pred)
    
    # 2. Stacking Ensemble
    # Define base models
    base_models = [
        ('rf', RandomForestClassifier(n_estimators=100, random_state=random_state)),
        ('gb', GradientBoostingClassifier(n_estimators=100, random_state=random_state)),
        ('xgb', xgb.XGBClassifier(n_estimators=100, random_state=random_state))
    ]
    
    # Define meta-learner
    meta_learner = LogisticRegression(random_state=random_state)
    
    # Create stacking classifier
    stacking_clf = StackingClassifier(
        estimators=base_models,
        final_estimator=meta_learner,
        cv=5,  # 5-fold cross-validation for base models
        stack_method='predict_proba'  # Use predicted probabilities
    )
    
    stacking_clf.fit(X_train, y_train)
    stacking_pred = stacking_clf.predict(X_test)
    stacking_accuracy = accuracy_score(y_test, stacking_pred)
    
    # 3. Custom implementation of stacking (for demonstration)
    def custom_stacking(X_train, y_train, X_test, base_models, meta_model, cv=5):
        """Custom implementation of stacking for clarity."""
        # Initialize arrays to store base models' predictions
        train_meta_features = np.zeros((X_train.shape[0], len(base_models)))
        test_meta_features = np.zeros((X_test.shape[0], len(base_models)))
        
        # Generate cross-validation predictions for training data
        kf = StratifiedKFold(n_splits=cv, shuffle=True, random_state=random_state)
        
        for i, (name, model) in enumerate(base_models):
            # Cross-validation predictions for training data
            for train_idx, val_idx in kf.split(X_train, y_train):
                # Split data for this fold
                fold_X_train, fold_X_val = X_train[train_idx], X_train[val_idx]
                fold_y_train = y_train[train_idx]
                
                # Train the model on training fold
                model.fit(fold_X_train, fold_y_train)
                
                # Predict on validation fold
                train_meta_features[val_idx, i] = model.predict(fold_X_val)
            
            # Train on full training data for test predictions
            model.fit(X_train, y_train)
            test_meta_features[:, i] = model.predict(X_test)
        
        # Train meta-learner on base model predictions
        meta_model.fit(train_meta_features, y_train)
        
        # Make final predictions
        final_predictions = meta_model.predict(test_meta_features)
        
        return final_predictions
    
    # Convert pandas DataFrames to numpy arrays if needed
    X_train_array = X_train.values if hasattr(X_train, 'values') else X_train
    X_test_array = X_test.values if hasattr(X_test, 'values') else X_test
    y_train_array = y_train.values if hasattr(y_train, 'values') else y_train
    
    # Define simplified base models for custom stacking
    simple_base_models = [
        ('rf', RandomForestClassifier(n_estimators=10, random_state=random_state)),
        ('gb', GradientBoostingClassifier(n_estimators=10, random_state=random_state)),
        ('dt', DecisionTreeClassifier(random_state=random_state))
    ]
    
    # Prepare models for custom stacking
    base_models_list = [(name, clone(model)) for name, model in simple_base_models]
    meta_model = LogisticRegression(random_state=random_state)
    
    # Apply custom stacking
    custom_stack_pred = custom_stacking(
        X_train_array, y_train_array, X_test_array, 
        base_models_list, meta_model
    )
    
    custom_stack_accuracy = accuracy_score(y_test, custom_stack_pred)
    
    return {
        'voting_accuracy': voting_accuracy,
        'stacking_accuracy': stacking_accuracy,
        'custom_stacking_accuracy': custom_stack_accuracy
    }
```

def advanced_boosting_frameworks(X, y, test_size=0.25, random_state=42):

    -----------

    )

    stacking_accuracy = accuracy_score(y_test, stacking_pred)
    
    # 6. Confusion matrices
    rf_cm = confusion_matrix(y_test, rf_pred)
    xgb_cm = confusion_matrix(y_test, xgb_pred)
    stacking_cm = confusion_matrix(y_test, stacking_pred)
    
    return {
        'rf_accuracy': rf_accuracy,
        'rf_report': rf_report,
        'xgb_accuracy': xgb_accuracy,
        'ovr_accuracy': ovr_accuracy,
        'ovo_accuracy': ovo_accuracy,
        'stacking_accuracy': stacking_accuracy,
        'confusion_matrices': {
            'random_forest': rf_cm,
            'xgboost': xgb_cm,
            'stacking': stacking_cm
        }
    }

    numeric_features = [col for col in X_df.columns if col.startswith('num')]

        ('onehot', OneHotEncoder(handle_unknown='ignore'))

        transformers=[
            ('num', numeric_transformer, numeric_features),
            ('cat', categorical_transformer, categorical_features)
        ]
    )

    rf_pipeline = Pipeline(steps=[
        ('preprocessor', preprocessor),
        ('classifier', RandomForestClassifier(

            random_state=random_state,
            n_jobs=-1

## Conclusion

Ensemble models represent one of the most powerful approaches in modern machine learning, leveraging the principle that combining diverse models often leads to superior performance. Through our exploration, we've covered the three main ensemble techniques:

1. **Bagging** techniques like Random Forest reduce variance by training models on different subsets of data and features, making them robust against overfitting.

2. **Boosting** algorithms like XGBoost and LightGBM create strong learners by sequentially correcting errors from previous models, leading to highly accurate predictions.

3. **Stacking** approaches combine predictions from multiple models through a meta-learner, capturing different patterns and relationships in the data.

We've also seen how these techniques extend naturally to multi-class classification problems, providing flexible frameworks for complex real-world applications.

The modern implementations like XGBoost and LightGBM offer significant advantages in terms of speed, memory efficiency, and handling of specialized data types. Their sophisticated regularization techniques and tree-growing strategies make them particularly effective for structured data problems.

When implementing ensemble models, remember these key takeaways:

- Diversity is crucial: ensure your base models capture different aspects of the data.
- Hyperparameter tuning is essential for optimal performance.
- Consider computational costs, especially with large datasets.
- Watch for overfitting, particularly with complex ensembles.
- For imbalanced datasets, incorporate appropriate class weighting or sampling techniques.

Ensemble learning has become the standard approach for tabular data problems in industry and competitions, consistently delivering state-of-the-art results when properly implemented. By understanding and applying these techniques, you can significantly improve the predictive power and robustness of your machine learning solutions.
