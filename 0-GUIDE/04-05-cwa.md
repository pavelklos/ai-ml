# 05. Data Pipelines and Feature Engineering Art

## Key Terms and Concepts

**Pipeline**: A sequential chain of data processing steps that transforms raw data into a format suitable for machine learning models. Each step in the pipeline receives input from the previous step and passes its output to the next step.

**Transformer**: An object that implements the `fit()` and `transform()` methods to modify data. Transformers learn parameters from training data during the fit phase and apply transformations during the transform phase.

**Feature Engineering**: The process of creating, modifying, or selecting features (input variables) to improve machine learning model performance. This includes creating new features from existing ones, encoding categorical variables, scaling numerical features, and removing irrelevant features.

**Fit-Transform Pattern**: A fundamental design pattern in scikit-learn where `fit()` learns parameters from training data, `transform()` applies the transformation, and `fit_transform()` combines both operations efficiently.

**Column Transformer**: A scikit-learn utility that applies different transformations to different subsets of columns in a dataset, enabling sophisticated preprocessing workflows.

## Understanding Data Pipelines

Data pipelines provide a systematic approach to data preprocessing and model training. They ensure reproducibility, prevent data leakage, and make code more maintainable by encapsulating the entire workflow from raw data to predictions.

The pipeline concept addresses several critical challenges in machine learning:
- **Consistency**: Ensures the same transformations are applied to training and test data
- **Reproducibility**: Makes experiments repeatable and results verifiable
- **Modularity**: Allows individual components to be tested and modified independently
- **Automation**: Reduces manual intervention and potential errors

### Basic Transformer Implementation

```python
class LogTransformer(BaseEstimator, TransformerMixin):
    """Custom transformer that applies logarithmic transformation to numerical features."""
    
    def __init__(self, columns=None):
        self.columns = columns
        
    def fit(self, X, y=None):
        """Fit the transformer - identify columns to transform if not specified."""
        if self.columns is None:
            # Automatically detect numerical columns
            self.columns = X.select_dtypes(include=[np.number]).columns.tolist()
        return self
    
    def transform(self, X):
        """Apply logarithmic transformation."""
        X_transformed = X.copy()
        for col in self.columns:
            # Add small constant to handle zero values
            X_transformed[col] = np.log1p(X_transformed[col])
        return X_transformed
    
    def get_feature_names_out(self, input_features=None):
        """Return feature names for output features."""
        if input_features is None:
            return [f"log_{col}" for col in self.columns]
        return input_features

class InteractionFeatureGenerator(BaseEstimator, TransformerMixin):
    """Generate interaction features between numerical columns."""
    
    def __init__(self, feature_pairs=None):
        self.feature_pairs = feature_pairs
        
    def fit(self, X, y=None):
        if self.feature_pairs is None:
            # Generate all possible pairs of numerical columns
            numeric_cols = X.select_dtypes(include=[np.number]).columns.tolist()
            self.feature_pairs = [(col1, col2) for i, col1 in enumerate(numeric_cols) 
                                for col2 in numeric_cols[i+1:]]
        return self
    
    def transform(self, X):
        X_transformed = X.copy()
        for col1, col2 in self.feature_pairs:
            interaction_name = f"{col1}_x_{col2}"
            X_transformed[interaction_name] = X_transformed[col1] * X_transformed[col2]
        return X_transformed
    
    def get_feature_names_out(self, input_features=None):
        interaction_names = [f"{col1}_x_{col2}" for col1, col2 in self.feature_pairs]
        base_features = input_features if input_features is not None else []
        return list(base_features) + interaction_names
```

### Advanced Feature Engineering Pipeline

```python
class PolynomialFeatureGenerator(BaseEstimator, TransformerMixin):
    """Generate polynomial features for numerical columns."""
    
    def __init__(self, degree=2, include_bias=False):
        self.degree = degree
        self.include_bias = include_bias
        
    def fit(self, X, y=None):
        self.numerical_columns_ = X.select_dtypes(include=[np.number]).columns.tolist()
        return self
    
    def transform(self, X):
        X_transformed = X.copy()
        
        for col in self.numerical_columns_:
            for deg in range(2, self.degree + 1):
                new_col_name = f"{col}_power_{deg}"
                X_transformed[new_col_name] = X_transformed[col] ** deg
                
        return X_transformed
    
    def get_feature_names_out(self, input_features=None):
        if input_features is None:
            input_features = []
        
        new_features = []
        for col in self.numerical_columns_:
            for deg in range(2, self.degree + 1):
                new_features.append(f"{col}_power_{deg}")
        
        return list(input_features) + new_features

class StatisticalFeatureExtractor(BaseEstimator, TransformerMixin):
    """Extract statistical features from numerical columns."""
    
    def __init__(self, features=['mean', 'std', 'skew']):
        self.features = features
        
    def fit(self, X, y=None):
        self.numerical_columns_ = X.select_dtypes(include=[np.number]).columns.tolist()
        
        # Calculate statistics on fit data
        self.statistics_ = {}
        for col in self.numerical_columns_:
            self.statistics_[col] = {
                'mean': X[col].mean(),
                'std': X[col].std(),
                'median': X[col].median(),
                'q25': X[col].quantile(0.25),
                'q75': X[col].quantile(0.75)
            }
        return self
    
    def transform(self, X):
        X_transformed = X.copy()
        
        for col in self.numerical_columns_:
            if 'mean' in self.features:
                X_transformed[f"{col}_vs_mean"] = X_transformed[col] - self.statistics_[col]['mean']
            if 'std' in self.features:
                X_transformed[f"{col}_standardized"] = (
                    (X_transformed[col] - self.statistics_[col]['mean']) / 
                    self.statistics_[col]['std']
                )
            if 'skew' in self.features:
                X_transformed[f"{col}_vs_median"] = X_transformed[col] - self.statistics_[col]['median']
                
        return X_transformed

# Enhanced preprocessing pipeline
enhanced_preprocessor = ColumnTransformer([
```

```python
# Get feature names after preprocessing
def get_feature_names_from_pipeline(pipeline, input_features):
    """Extract feature names from a fitted pipeline."""
    
    # Get the preprocessor step
    preprocessor = pipeline.named_steps['preprocessor']
    
    feature_names = []
    
    # Iterate through transformers in ColumnTransformer
    for name, transformer, columns in preprocessor.transformers_:
        if name == 'remainder':
            continue
            
        if hasattr(transformer, 'get_feature_names_out'):
            if isinstance(columns, slice):
                input_cols = input_features[columns]
            else:
                input_cols = columns
            transformer_features = transformer.get_feature_names_out(input_cols)
            feature_names.extend(transformer_features)
        else:
            # For transformers without get_feature_names_out
            if isinstance(columns, slice):
                feature_names.extend(input_features[columns])
            else:
                feature_names.extend(columns)
    
    return feature_names

# Get feature names

    feature_names = get_feature_names_from_pipeline(enhanced_pipeline, X.columns.tolist())
    print(f"Total features after preprocessing: {len(feature_names)}")

    # Alternative approach
    X_transformed = enhanced_pipeline.named_steps['preprocessor'].transform(X_train)
    print(f"Transformed feature shape: {X_transformed.shape}")
```

## Real-world Pipeline Example: End-to-End ML System

```python
class MLPipelineManager:
    """Comprehensive ML pipeline management system."""
    
    def __init__(self, config=None):
        self.config = config or {}
        self.pipeline = None
        self.feature_names = None
        self.training_metadata = {}
        
    def create_pipeline(self, numerical_features, categorical_features, binary_features):
        """Create a comprehensive ML pipeline."""
        
        # Numerical preprocessing
        numerical_pipeline = Pipeline([
            ('imputer', 'passthrough'),  # Could add SimpleImputer here
            ('scaler', StandardScaler()),
            ('feature_eng', StatisticalFeatureExtractor())
        ])
        
        # Categorical preprocessing
        categorical_pipeline = Pipeline([
            ('onehot', OneHotEncoder(drop='first', sparse_output=False, handle_unknown='ignore'))
        ])
        
        # Combine preprocessing
        preprocessor = ColumnTransformer([
            ('numerical', numerical_pipeline, numerical_features),
            ('categorical', categorical_pipeline, categorical_features),
            ('binary', 'passthrough', binary_features)
        ], remainder='drop')
        
        # Complete pipeline
        self.pipeline = Pipeline([
            ('preprocessor', preprocessor),
            ('classifier', RandomForestClassifier(
                n_estimators=self.config.get('n_estimators', 100),
                random_state=self.config.get('random_state', 42),
                n_jobs=-1
            ))
        ])
        
        return self.pipeline
    
    def train(self, X_train, y_train):
        """Train the pipeline and collect metadata."""
        if self.pipeline is None:
            raise ValueError("Pipeline not created. Call create_pipeline first.")
        
        start_time = datetime.now()
        self.pipeline.fit(X_train, y_train)
        training_time = datetime.now() - start_time
        
        self.training_metadata = {
            'training_time': training_time,
            'training_samples': len(X_train),
            'feature_count': X_train.shape[1],
            'target_classes': len(np.unique(y_train))
        }
        
        return self.pipeline
    
    def evaluate(self, X_test, y_test):
        """Comprehensive model evaluation."""
        if self.pipeline is None:
            raise ValueError("Pipeline not trained.")
        
        predictions = self.pipeline.predict(X_test)
        probabilities = self.pipeline.predict_proba(X_test)
        
        metrics = {
            'accuracy': accuracy_score(y_test, predictions),
            'f1_weighted': f1_score(y_test, predictions, average='weighted'),
            'classification_report': classification_report(y_test, predictions, output_dict=True)
        }
        
        return metrics, predictions, probabilities
    
    def get_pipeline_info(self):
        """Get comprehensive pipeline information."""
        if self.pipeline is None:
            return "Pipeline not created."
        
        info = {
            'pipeline_steps': [step for step, _ in self.pipeline.steps],
            'training_metadata': self.training_metadata,
            'pipeline_params': self.pipeline.get_params()
        }
        
        return info

# Usage example
pipeline_manager = MLPipelineManager(config={'n_estimators': 150, 'random_state': 42})
pipeline = pipeline_manager.create_pipeline(numerical_features, categorical_features, binary_features)
trained_pipeline = pipeline_manager.train(X_train, y_train)
metrics, predictions, probabilities = pipeline_manager.evaluate(X_test, y_test)

print("Pipeline Manager Results:")
print(f"Accuracy: {metrics['accuracy']:.4f}")
print(f"F1 Score (weighted): {metrics['f1_weighted']:.4f}")
print(f"Training metadata: {pipeline_manager.training_metadata}")
```

## Conclusion

Data pipelines and feature engineering form the backbone of successful machine learning projects. Through systematic preprocessing workflows, we ensure data consistency, reproducibility, and optimal model performance. The scikit-learn pipeline framework provides powerful abstractions for chaining transformations, while custom transformers enable domain-specific feature engineering.

Key takeaways from this comprehensive exploration:

**Pipeline Benefits**: Pipelines eliminate data leakage, ensure consistent preprocessing, and make code modular and maintainable. They encapsulate the entire workflow from raw data to predictions.

**Feature Engineering Impact**: Thoughtful feature engineering often provides greater performance improvements than algorithm optimization. Creating meaningful features through domain knowledge and statistical transformations can significantly boost model accuracy.

**Scalability Considerations**: Modern pipelines must handle large datasets efficiently. Using sparse matrices, memory-efficient transformations, and parallel processing ensures scalability.

**Production Readiness**: Well-designed pipelines are essential for deploying models to production. They handle new data consistently and can be easily versioned and updated.

The combination of robust preprocessing pipelines and intelligent feature engineering establishes a solid foundation for building reliable, high-performance machine learning systems that can adapt to real-world data complexities and scale with business needs.
