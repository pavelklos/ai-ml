## Key Terms

**Artificial Neuron**: A computational unit that mimics biological neurons by receiving multiple inputs, applying weights and biases, and producing an output through an activation function, forming the fundamental building block of neural networks.

**Activation Function**: A mathematical function applied to neuron outputs that introduces non-linearity into the network, enabling complex pattern recognition through functions like ReLU, sigmoid, tanh, and softmax that determine neuron firing behavior.

**Backpropagation Algorithm**: The core learning mechanism in neural networks that calculates gradients of the loss function with respect to network weights by propagating errors backward through layers, enabling efficient weight optimization via gradient descent.

**Weight Matrix**: Learnable parameters that determine the strength of connections between neurons in different layers, representing the knowledge stored in the network and adjusted during training to minimize prediction errors.

**Bias Term**: An additional learnable parameter added to each neuron that shifts the activation function, providing the network with flexibility to fit data that doesn't pass through the origin and improving model expressiveness.

**Loss Function**: A mathematical measure of the difference between predicted and actual outputs, such as mean squared error for regression or cross-entropy for classification, providing the optimization objective for network training.

**Gradient Descent**: An iterative optimization algorithm that adjusts network weights by moving in the direction of steepest descent of the loss function, with variants like SGD, Adam, and RMSprop offering different convergence properties.

**Deep Learning**: A subset of machine learning using neural networks with multiple hidden layers (typically 3 or more) that can automatically learn hierarchical feature representations from raw data without manual feature engineering.

**Feedforward Neural Network**: A basic network architecture where information flows in one direction from input to output layers without cycles, suitable for standard classification and regression tasks on structured data.

**Convolutional Neural Network (CNN)**: A specialized architecture using convolutional layers that apply filters to detect spatial patterns, particularly effective for image processing, computer vision, and spatial data analysis tasks.

## Theoretical Foundation of Neural Networks

Neural networks represent a paradigm shift from traditional machine learning by automatically learning feature representations through hierarchical layers of interconnected artificial neurons. The mathematical foundation rests on the universal approximation theorem, which proves that feedforward networks with sufficient neurons can approximate any continuous function.

The forward propagation process computes predictions by passing inputs through weighted connections and activation functions: z = Wx + b, where W represents weights, x inputs, and b biases. The activation function f(z) introduces essential non-linearity, enabling networks to model complex patterns beyond linear relationships.

Backpropagation implements the chain rule of calculus to efficiently compute gradients throughout the network hierarchy. For a loss function L and weight w, the gradient ∂L/∂w = ∂L/∂y × ∂y/∂z × ∂z/∂w flows backward through layers, enabling simultaneous optimization of thousands or millions of parameters.

Modern deep learning architectures leverage specialized components like convolutional layers for spatial invariance, recurrent layers for temporal dependencies, and attention mechanisms for selective focus, creating powerful models for diverse applications from computer vision to natural language processing.

class ActivationFunctions:
    """Collection of activation functions and their derivatives"""
    
    @staticmethod
    def relu(x: np.ndarray) -> np.ndarray:
        """Rectified Linear Unit activation"""
        return np.maximum(0, x)
    
    @staticmethod
    def relu_derivative(x: np.ndarray) -> np.ndarray:
        """Derivative of ReLU"""
        return (x > 0).astype(float)
    
    @staticmethod
    def sigmoid(x: np.ndarray) -> np.ndarray:
        """Sigmoid activation function"""
        # Clip to prevent overflow
        x_clipped = np.clip(x, -500, 500)
        return 1 / (1 + np.exp(-x_clipped))
    
    @staticmethod
    def sigmoid_derivative(x: np.ndarray) -> np.ndarray:
        """Derivative of sigmoid"""
        s = ActivationFunctions.sigmoid(x)
        return s * (1 - s)
    
    @staticmethod
    def tanh(x: np.ndarray) -> np.ndarray:
        """Hyperbolic tangent activation"""
        return np.tanh(x)
    
    @staticmethod
    def tanh_derivative(x: np.ndarray) -> np.ndarray:
        """Derivative of tanh"""
        return 1 - np.tanh(x) ** 2
    
    @staticmethod
    def leaky_relu(x: np.ndarray, alpha: float = 0.01) -> np.ndarray:
        """Leaky ReLU activation"""
        return np.where(x > 0, x, alpha * x)
    
    @staticmethod
    def leaky_relu_derivative(x: np.ndarray, alpha: float = 0.01) -> np.ndarray:
        """Derivative of Leaky ReLU"""
        return np.where(x > 0, 1, alpha)
    
    @staticmethod
    def softmax(x: np.ndarray) -> np.ndarray:
        """Softmax activation for multi-class classification"""
        x_shifted = x - np.max(x, axis=-1, keepdims=True)
        exp_x = np.exp(x_shifted)
        return exp_x / np.sum(exp_x, axis=-1, keepdims=True)

class NeuralNetworkFromScratch:
    """Complete neural network implementation from scratch"""
    
    def __init__(self, architecture: NetworkArchitecture):
        self.architecture = architecture
        self.weights = []
        self.biases = []
        self.activations = []
        self.z_values = []
        self.loss_history = []
        self.accuracy_history = []
        
        # Initialize network
        self._initialize_weights()
        
        # Set activation functions
        self.activation_func = getattr(ActivationFunctions, architecture.activation)
        self.activation_derivative = getattr(ActivationFunctions, f"{architecture.activation}_derivative")
        
        if architecture.output_activation == 'sigmoid':
            self.output_activation = ActivationFunctions.sigmoid
        elif architecture.output_activation == 'softmax':
            self.output_activation = ActivationFunctions.softmax
        else:
            self.output_activation = lambda x: x  # Linear activation
    
    def _initialize_weights(self):
        """Initialize weights using Xavier/Glorot initialization"""
        
        layer_sizes = [self.architecture.input_size] + self.architecture.hidden_layers + [self.architecture.output_size]
        
        for i in range(len(layer_sizes) - 1):
            # Xavier initialization
            fan_in = layer_sizes[i]
            fan_out = layer_sizes[i + 1]
            limit = np.sqrt(6 / (fan_in + fan_out))
            
            weight = np.random.uniform(-limit, limit, (fan_in, fan_out))
            bias = np.zeros((1, fan_out))
            
            self.weights.append(weight)
            self.biases.append(bias)
    
    def forward_propagation(self, X: np.ndarray) -> np.ndarray:
        """Forward propagation through the network"""
        
        self.activations = [X]
        self.z_values = []
        
        current_input = X
        
        # Forward pass through hidden layers
        for i in range(len(self.weights) - 1):
            z = np.dot(current_input, self.weights[i]) + self.biases[i]
            self.z_values.append(z)
            
            a = self.activation_func(z)
            
            # Apply dropout during training
            if self.architecture.dropout_rate > 0:
                dropout_mask = np.random.binomial(1, 1 - self.architecture.dropout_rate, a.shape)
                a = a * dropout_mask / (1 - self.architecture.dropout_rate)
            
            self.activations.append(a)
            current_input = a
        
        # Output layer
        z_output = np.dot(current_input, self.weights[-1]) + self.biases[-1]
        self.z_values.append(z_output)
        
        output = self.output_activation(z_output)
        self.activations.append(output)
        
        return output
    
    def backward_propagation(self, X: np.ndarray, y: np.ndarray, predictions: np.ndarray) -> List[np.ndarray]:
        """Backward propagation to compute gradients"""
        
        m = X.shape[0]  # Number of samples
        gradients_w = []
        gradients_b = []
        
        # Initialize error for output layer
        if self.architecture.output_activation == 'softmax':
            # For softmax with cross-entropy loss
            error = predictions - y
        else:
            # For other activations with MSE loss
            error = (predictions - y) * self.activation_derivative(self.z_values[-1])
        
        # Compute gradients for output layer
        dW = (1/m) * np.dot(self.activations[-2].T, error)
        db = (1/m) * np.sum(error, axis=0, keepdims=True)
        
        gradients_w.insert(0, dW)
        gradients_b.insert(0, db)
        
        # Propagate error backward through hidden layers
        for i in range(len(self.weights) - 2, -1, -1):
            error = np.dot(error, self.weights[i + 1].T) * self.activation_derivative(self.z_values[i])
            
            dW = (1/m) * np.dot(self.activations[i].T, error)
            db = (1/m) * np.sum(error, axis=0, keepdims=True)
            
            gradients_w.insert(0, dW)
            gradients_b.insert(0, db)
        
        return gradients_w, gradients_b
    
    def update_weights(self, gradients_w: List[np.ndarray], gradients_b: List[np.ndarray], 
                      learning_rate: float):
        """Update weights using gradient descent"""
        
        for i in range(len(self.weights)):
            self.weights[i] -= learning_rate * gradients_w[i]
            self.biases[i] -= learning_rate * gradients_b[i]
    
    def compute_loss(self, y_true: np.ndarray, y_pred: np.ndarray) -> float:
        """Compute loss function"""
        
        if self.architecture.output_activation == 'softmax':
            # Cross-entropy loss
            epsilon = 1e-15  # To prevent log(0)
            y_pred_clipped = np.clip(y_pred, epsilon, 1 - epsilon)
            return -np.mean(np.sum(y_true * np.log(y_pred_clipped), axis=1))
        else:
            # Mean squared error
            return np.mean((y_true - y_pred) ** 2)
    
    def train(self, X: np.ndarray, y: np.ndarray, config: TrainingConfig) -> Dict[str, List[float]]:
        """Train the neural network"""
        
        # Split data for validation
        X_train, X_val, y_train, y_val = train_test_split(
            X, y, test_size=config.validation_split, random_state=42
        )
        
        best_val_loss = float('inf')
        patience_counter = 0
        
        for epoch in range(config.epochs):
            # Forward pass
            predictions = self.forward_propagation(X_train)
            
            # Compute loss
            train_loss = self.compute_loss(y_train, predictions)
            
            # Backward pass
            gradients_w, gradients_b = self.backward_propagation(X_train, y_train, predictions)
            
            # Update weights
            self.update_weights(gradients_w, gradients_b, config.learning_rate)
            
            # Validation
            val_predictions = self.forward_propagation(X_val)
            val_loss = self.compute_loss(y_val, val_predictions)
            
            # Store history
            self.loss_history.append(train_loss)
            
            # Early stopping
            if config.early_stopping:
                if val_loss < best_val_loss:
                    best_val_loss = val_loss
                    patience_counter = 0
                else:
                    patience_counter += 1
                    
                if patience_counter >= config.patience:
                    logger.info(f"Early stopping at epoch {epoch + 1}")
                    break
            
            # Log progress
            if (epoch + 1) % 10 == 0:
                logger.info(f"Epoch {epoch + 1}/{config.epochs}, "
                           f"Train Loss: {train_loss:.6f}, Val Loss: {val_loss:.6f}")
        
        return {
            'loss_history': self.loss_history,
            'final_train_loss': train_loss,
            'final_val_loss': val_loss
        }
    
    def predict(self, X: np.ndarray) -> np.ndarray:
        """Make predictions"""
        return self.forward_propagation(X)

class TensorFlowNeuralNetwork:
    """Advanced neural network using TensorFlow/Keras"""
    
    def __init__(self, architecture: NetworkArchitecture):
        self.architecture = architecture
        self.model = None
        self.history = None
        
    def build_model(self) -> keras.Model:
        """Build TensorFlow model"""
        
        model = keras.Sequential()
        
        # Input layer
        model.add(layers.Dense(
            self.architecture.hidden_layers[0],
            activation=self.architecture.activation,
            input_shape=(self.architecture.input_size,),
            kernel_initializer='glorot_uniform'
        ))
        
        if self.architecture.batch_normalization:
            model.add(layers.BatchNormalization())
        
        if self.architecture.dropout_rate > 0:
            model.add(layers.Dropout(self.architecture.dropout_rate))
        
        # Hidden layers
        for hidden_size in self.architecture.hidden_layers[1:]:
            model.add(layers.Dense(
                hidden_size,
                activation=self.architecture.activation,
                kernel_initializer='glorot_uniform'
            ))
            
            if self.architecture.batch_normalization:
                model.add(layers.BatchNormalization())
            
            if self.architecture.dropout_rate > 0:
                model.add(layers.Dropout(self.architecture.dropout_rate))
        
        # Output layer
        model.add(layers.Dense(
            self.architecture.output_size,
            activation=self.architecture.output_activation,
            kernel_initializer='glorot_uniform'
        ))
        
        self.model = model
        return model
    
    def compile_model(self, config: TrainingConfig):
        """Compile the model"""
        
        # Select optimizer
        if config.optimizer == 'adam':
            optimizer = optimizers.Adam(learning_rate=config.learning_rate)
        elif config.optimizer == 'sgd':
            optimizer = optimizers.SGD(learning_rate=config.learning_rate)
        elif config.optimizer == 'rmsprop':
            optimizer = optimizers.RMSprop(learning_rate=config.learning_rate)
        else:
            optimizer = 'adam'
        
        # Select loss function
        if config.loss_function == 'categorical_crossentropy':
            loss = 'categorical_crossentropy'
            metrics = ['accuracy']
        elif config.loss_function == 'binary_crossentropy':
            loss = 'binary_crossentropy'
            metrics = ['accuracy']
        else:
            loss = 'mse'
            metrics = ['mae']
        
        self.model.compile(
            optimizer=optimizer,
            loss=loss,
            metrics=metrics
        )
    
    def train(self, X: np.ndarray, y: np.ndarray, config: TrainingConfig) -> keras.callbacks.History:
        """Train the model"""
        
        # Prepare callbacks
        callback_list = []
        
        if config.early_stopping:
            early_stopping = callbacks.EarlyStopping(
                monitor='val_loss',
                patience=config.patience,
                restore_best_weights=True,
                verbose=1
            )
            callback_list.append(early_stopping)
        
        # Reduce learning rate on plateau
        reduce_lr = callbacks.ReduceLROnPlateau(
            monitor='val_loss',
            factor=0.5,
            patience=config.patience // 2,
            min_lr=1e-7,
            verbose=1
        )
        callback_list.append(reduce_lr)
        
        # Train model
        self.history = self.model.fit(
            X, y,
            epochs=config.epochs,
            batch_size=config.batch_size,
            validation_split=config.validation_split,
            callbacks=callback_list,
            verbose=1
        )
        
        return self.history
    
    def predict(self, X: np.ndarray) -> np.ndarray:
        """Make predictions"""
        return self.model.predict(X)

class PyTorchNeuralNetwork(nn.Module):
    """Advanced neural network using PyTorch"""
    
    def __init__(self, architecture: NetworkArchitecture):
        super(PyTorchNeuralNetwork, self).__init__()
        self.architecture = architecture
        
        # Build layers
        layers_list = []
        input_size = architecture.input_size
        
        for hidden_size in architecture.hidden_layers:
            layers_list.append(nn.Linear(input_size, hidden_size))
            
            if architecture.batch_normalization:
                layers_list.append(nn.BatchNorm1d(hidden_size))
            
            # Add activation
            if architecture.activation == 'relu':
                layers_list.append(nn.ReLU())
            elif architecture.activation == 'tanh':
                layers_list.append(nn.Tanh())
            elif architecture.activation == 'sigmoid':
                layers_list.append(nn.Sigmoid())
            
            if architecture.dropout_rate > 0:
                layers_list.append(nn.Dropout(architecture.dropout_rate))
            
            input_size = hidden_size
        
        # Output layer
        layers_list.append(nn.Linear(input_size, architecture.output_size))
        
        # Add output activation if needed
        if architecture.output_activation == 'sigmoid':
            layers_list.append(nn.Sigmoid())
        elif architecture.output_activation == 'softmax':
            layers_list.append(nn.Softmax(dim=1))
        
        self.network = nn.Sequential(*layers_list)
        
        # Initialize weights
        self._initialize_weights()
    
    def _initialize_weights(self):
        """Initialize weights using Xavier initialization"""
        for module in self.modules():
            if isinstance(module, nn.Linear):
                nn.init.xavier_uniform_(module.weight)
                nn.init.zeros_(module.bias)
    
    def forward(self, x):
        """Forward pass"""
        return self.network(x)

class NeuralNetworkComparison:
    """Compare different neural network implementations"""
    
    def __init__(self):
        self.results = {}
    
    def compare_implementations(self, X: np.ndarray, y: np.ndarray, 
                              architecture: NetworkArchitecture,
                              config: TrainingConfig) -> Dict[str, Any]:
        """Compare different neural network implementations"""
        
        results = {}
        
        # 1. From Scratch Implementation
        logger.info("Training neural network from scratch...")
        start_time = time.time()
        
        try:
            nn_scratch = NeuralNetworkFromScratch(architecture)
            scratch_history = nn_scratch.train(X, y, config)
            scratch_predictions = nn_scratch.predict(X)
            
            results['from_scratch'] = {
                'model': nn_scratch,
                'training_time': time.time() - start_time,
                'history': scratch_history,
                'predictions': scratch_predictions
            }
        except Exception as e:
            logger.error(f"From scratch implementation failed: {e}")
            results['from_scratch'] = None
        
        # 2. TensorFlow/Keras Implementation
        logger.info("Training TensorFlow neural network...")
        start_time = time.time()
        
        try:
            nn_tf = TensorFlowNeuralNetwork(architecture)
            nn_tf.build_model()
            nn_tf.compile_model(config)
            tf_history = nn_tf.train(X, y, config)
            tf_predictions = nn_tf.predict(X)
            
            results['tensorflow'] = {
                'model': nn_tf,
                'training_time': time.time() - start_time,
                'history': tf_history,
                'predictions': tf_predictions
            }
        except Exception as e:
            logger.error(f"TensorFlow implementation failed: {e}")
            results['tensorflow'] = None
        
        # 3. Scikit-learn Implementation
        logger.info("Training scikit-learn neural network...")
        start_time = time.time()
        
        try:
            if architecture.output_activation == 'softmax':
                # Classification
                sklearn_nn = MLPClassifier(
                    hidden_layer_sizes=tuple(architecture.hidden_layers),
                    activation=architecture.activation,
                    solver='adam',
                    learning_rate_init=config.learning_rate,
                    max_iter=config.epochs,
                    random_state=42
                )
            else:
                # Regression
                sklearn_nn = MLPRegressor(
                    hidden_layer_sizes=tuple(architecture.hidden_layers),
                    activation=architecture.activation,
                    solver='adam',
                    learning_rate_init=config.learning_rate,
                    max_iter=config.epochs,
                    random_state=42
                )
            
            sklearn_nn.fit(X, y)
            sklearn_predictions = sklearn_nn.predict(X)
            
            results['sklearn'] = {
                'model': sklearn_nn,
                'training_time': time.time() - start_time,
                'predictions': sklearn_predictions,
                'loss_curve': sklearn_nn.loss_curve_
            }
        except Exception as e:
            logger.error(f"Scikit-learn implementation failed: {e}")
            results['sklearn'] = None
        
        self.results = results
        return results
    
    def evaluate_models(self, y_true: np.ndarray) -> Dict[str, Dict[str, float]]:
        """Evaluate all trained models"""
        
        evaluation_results = {}
        
        for name, result in self.results.items():
            if result is None:
                continue
                
            predictions = result['predictions']
            
            # Calculate metrics based on problem type
            if len(y_true.shape) > 1 and y_true.shape[1] > 1:
                # Multi-class classification
                y_pred_classes = np.argmax(predictions, axis=1)
                y_true_classes = np.argmax(y_true, axis=1)
                
                accuracy = accuracy_score(y_true_classes, y_pred_classes)
                
                evaluation_results[name] = {
                    'accuracy': accuracy,
                    'training_time': result['training_time']
                }
            else:
                # Regression or binary classification
                if np.all(np.isin(y_true, [0, 1])):
                    # Binary classification
                    y_pred_binary = (predictions > 0.5).astype(int)
                    accuracy = accuracy_score(y_true, y_pred_binary)
                    
                    evaluation_results[name] = {
                        'accuracy': accuracy,
                        'training_time': result['training_time']
                    }
                else:
                    # Regression
                    mse = np.mean((y_true - predictions) ** 2)
                    mae = np.mean(np.abs(y_true - predictions))
                    
                    evaluation_results[name] = {
                        'mse': mse,
                        'mae': mae,
                        'training_time': result['training_time']
                    }
        
        return evaluation_results

    y_true_final = np.argmax(y_class_onehot, axis=1)
    final_accuracy = accuracy_score(y_true_final, y_pred_final)
    
    print(f"Final model accuracy: {final_accuracy:.4f}")
    print(f"Final model architecture: {best_hidden_layers}")
    print(f"Total parameters: {final_nn.model.count_params():,}")
    
    # 9. Summary and Recommendations
    print(f"\n{'='*60}")
    print("9. SUMMARY AND RECOMMENDATIONS")

    print("Neural Networks Summary:")

    if reg_evaluation:

        print(f"  Regression: {best_reg_model} (MSE: {reg_evaluation[best_reg_model]['mse']:.4f})")

    if activation_results:

        'best_hyperparameters': study.best_params,

        'recommendations': {

            'learning_rate': 0.001,
            'use_batch_norm': True,
            'use_dropout': True,
            'use_early_stopping': True
        }
    }
    
    # Save to file
    with open('neural_networks_results.json', 'w') as f:
        json.dump(results_summary, f, indent=2, default=str)

    if final_nn.model:
