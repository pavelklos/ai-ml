## Key Terms and Concepts

**Linear Regression** is a fundamental statistical method that models the relationship between a dependent variable (target) and one or more independent variables (features) by fitting a linear equation to observed data. It assumes that the relationship between variables can be represented as a straight line (or hyperplane in higher dimensions).

**Least Squares Method** is the optimization technique used to find the best-fitting line by minimizing the sum of squared residuals (differences between observed and predicted values). This method provides the optimal coefficients that minimize prediction error.

**Simple Linear Regression** involves one independent variable predicting one dependent variable using the equation: y = β₀ + β₁x + ε, where β₀ is the intercept, β₁ is the slope coefficient, and ε represents the error term.

**Multiple Linear Regression** extends this concept to multiple independent variables: y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε, allowing for more complex relationships and better predictive power.

**Coefficients** represent the magnitude and direction of the relationship between each feature and the target variable. They indicate how much the target variable changes for a one-unit change in the corresponding feature, holding all other features constant.

**R-squared (R²)** measures the proportion of variance in the dependent variable explained by the independent variables, ranging from 0 to 1, where higher values indicate better model fit.

**Residuals** are the differences between actual and predicted values, used to assess model performance and validate assumptions.

## Theoretical Foundation

Linear regression operates on several key assumptions: linearity of relationships, independence of observations, homoscedasticity (constant variance of residuals), and normal distribution of residuals. The method finds the best-fitting line by minimizing the cost function J(β) = Σ(yᵢ - ŷᵢ)², where yᵢ represents actual values and ŷᵢ represents predicted values.

The mathematical solution involves solving the normal equation: β = (XᵀX)⁻¹Xᵀy, where X is the feature matrix and y is the target vector. This closed-form solution provides optimal coefficients directly without iterative optimization.

## Data Generation and Preparation

```python
# Generate synthetic dataset for demonstration
np.random.seed(42)
n_samples = 1000

# Create realistic housing price dataset
house_size = np.random.normal(2000, 800, n_samples)
bedrooms = np.random.poisson(3, n_samples)
age = np.random.exponential(15, n_samples)
location_score = np.random.beta(2, 5, n_samples) * 10

# Create realistic price relationship with noise
price = (
    150 * house_size +
    5000 * bedrooms +
    -800 * age +
    12000 * location_score +
    np.random.normal(0, 50000, n_samples) +
    200000  # base price
)

# Create DataFrame
data = pd.DataFrame({
    'house_size': house_size,
    'bedrooms': bedrooms,
    'age': age,
    'location_score': location_score,
    'price': price
})

# Remove outliers using IQR method
def remove_outliers(df, columns):
    df_clean = df.copy()
    for col in columns:
        Q1 = df_clean[col].quantile(0.25)
        Q3 = df_clean[col].quantile(0.75)
        IQR = Q3 - Q1
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR
        df_clean = df_clean[(df_clean[col] >= lower_bound) & (df_clean[col] <= upper_bound)]
    return df_clean

data_clean = remove_outliers(data, ['house_size', 'price'])

print("Dataset shape after cleaning:", data_clean.shape)
print("\nDataset statistics:")
print(data_clean.describe())
```

## Simple Linear Regression Implementation

```python
# Simple Linear Regression: House size predicting price
X_simple = data_clean[['house_size']]
y = data_clean['price']

# Split data
X_train_simple, X_test_simple, y_train, y_test = train_test_split(
    X_simple, y, test_size=0.2, random_state=42
)

# Create and train model
simple_model = LinearRegression()
simple_model.fit(X_train_simple, y_train)

# Generate predictions
y_pred_simple = simple_model.predict(X_test_simple)

# Model coefficients and interpretation
print("Simple Linear Regression Results:")
print(f"Intercept (β₀): ${simple_model.intercept_:,.2f}")
print(f"Coefficient (β₁): ${simple_model.coef_[0]:.2f} per sq ft")
print(f"Interpretation: Each additional square foot increases price by ${simple_model.coef_[0]:.2f}")

# Performance metrics
r2_simple = r2_score(y_test, y_pred_simple)
rmse_simple = np.sqrt(mean_squared_error(y_test, y_pred_simple))
mae_simple = mean_absolute_error(y_test, y_pred_simple)

print(f"\nModel Performance:")

print(f"MAE: ${mae_simple:,.2f}")
```

```python
# Normality test (Shapiro-Wilk for small samples, Anderson-Darling for larger)
if len(residuals) <= 5000:
    stat, p_value = stats.shapiro(residuals)
    test_name = "Shapiro-Wilk"
else:
    stat, critical_values, significance_levels = stats.anderson(residuals, dist='norm')
    test_name = "Anderson-Darling"
    p_value = 0.05 if stat > critical_values[2] else 0.1  # Approximate p-value
```

## Prediction Pipeline and Production-Ready Code

```python
class LinearRegressionPredictor:
    """
    Production-ready linear regression predictor with comprehensive validation
    """
    
    def __init__(self, model_type='linear', **kwargs):
        self.model_type = model_type
        self.scaler = StandardScaler()
        
        if model_type == 'linear':
            self.model = LinearRegression(**kwargs)
        elif model_type == 'ridge':
            self.model = Ridge(**kwargs)
        elif model_type == 'lasso':
            self.model = Lasso(**kwargs)
        elif model_type == 'elastic_net':
            self.model = ElasticNet(**kwargs)
        else:
            raise ValueError("Model type must be 'linear', 'ridge', 'lasso', or 'elastic_net'")
    
    def fit(self, X, y):
        """Fit the model with feature scaling"""
        X_scaled = self.scaler.fit_transform(X)
        self.model.fit(X_scaled, y)
        self.feature_names = X.columns.tolist()
        return self
    
    def predict(self, X):
        """Make predictions with input validation"""
        # Validate input features
        if not all(col in X.columns for col in self.feature_names):
            missing_cols = set(self.feature_names) - set(X.columns)
            raise ValueError(f"Missing features: {missing_cols}")
        
        X_scaled = self.scaler.transform(X[self.feature_names])
        return self.model.predict(X_scaled)
    
    def get_feature_importance(self):
        """Get feature importance based on coefficients"""
        if hasattr(self.model, 'coef_'):
            importance_df = pd.DataFrame({
                'feature': self.feature_names,
                'coefficient': self.model.coef_,
                'abs_coefficient': np.abs(self.model.coef_)
            }).sort_values('abs_coefficient', ascending=False)
            return importance_df
        else:
            return None
    
    def predict_with_confidence(self, X, confidence_level=0.95):
        """
        Predict with confidence intervals (simplified approach)
        Note: For true confidence intervals, use statsmodels
        """
        predictions = self.predict(X)
        
        # Simplified confidence interval based on residual standard error
        # In production, use proper statistical methods
        residual_std = np.std(self.model.predict(self.scaler.transform(X)) - 
                             self.predict(X)) if hasattr(self, 'residual_std') else 50000
        
        from scipy.stats import t
        alpha = 1 - confidence_level
        dof = len(X) - len(self.feature_names) - 1
        t_value = t.ppf(1 - alpha/2, dof)
        
        margin_error = t_value * residual_std
        
        return {
            'predictions': predictions,
            'lower_bound': predictions - margin_error,
            'upper_bound': predictions + margin_error
        }

# Initialize and train production model
predictor = LinearRegressionPredictor(model_type='ridge', alpha=best_alpha)
predictor.fit(X_train_multiple, y_train)

# Make predictions
sample_data = X_test_multiple.head(5)

results_table = pd.DataFrame({

    print(f"Sample {i+1}:")
```

```python
# Generate comprehensive model report
def generate_model_report(predictor, X_test, y_test):
    """Generate comprehensive model performance report"""
    
    predictions = predictor.predict(X_test)
    
    # Performance metrics
    r2 = r2_score(y_test, predictions)
    rmse = np.sqrt(mean_squared_error(y_test, predictions))
    mae = mean_absolute_error(y_test, predictions)
    
    # Feature importance
    feature_importance = predictor.get_feature_importance()
    
    print("="*60)
    print("COMPREHENSIVE MODEL PERFORMANCE REPORT")
    print("="*60)
    
    print(f"\nModel Type: {predictor.model_type.upper()}")
    print(f"Number of Features: {len(predictor.feature_names)}")
    print(f"Test Set Size: {len(X_test)}")
    
    print(f"\nPERFORMANCE METRICS:")
    print(f"R² Score: {r2:.4f} ({r2*100:.2f}% of variance explained)")
    print(f"RMSE: ${rmse:,.2f}")
    print(f"MAE: ${mae:,.2f}")
    
    print(f"\nFEATURE IMPORTANCE:")
    for _, row in feature_importance.head().iterrows():
        direction = "increases" if row['coefficient'] > 0 else "decreases"
        print(f"  {row['feature']}: {direction} price by ${abs(row['coefficient']):,.2f} per unit")

    error_percentiles = np.percentile(np.abs(errors), [50, 75, 90, 95])

    print(f"  75% of predictions within: ${error_percentiles[1]:,.0f}")
    print(f"  90% of predictions within: ${error_percentiles[2]:,.0f}")
    print(f"  95% of predictions within: ${error_percentiles[3]:,.0f}")
    
    return {
```
