## Key Terms and Concepts

- **Classification**: A supervised learning technique where the algorithm learns to categorize data into predefined classes.
- **Binary Classification**: Classification task with exactly two possible outcomes (e.g., spam/not spam).
- **Multi-class Classification**: Classification involving three or more classes (e.g., digit recognition).
- **Multi-label Classification**: Cases where each instance can belong to multiple classes simultaneously.
- **Decision Boundary**: The hypersurface that separates different classes in the feature space.
- **Logistic Regression**: A linear model for binary classification that uses a logistic function to model probability.
- **K-Nearest Neighbors (KNN)**: A non-parametric algorithm that classifies instances based on the majority class of their k nearest neighbors.
- **Confusion Matrix**: A table showing the performance of a classification model by counting true/false positives/negatives.
- **Precision**: The ratio of true positives to all predicted positives.
- **Recall**: The ratio of true positives to all actual positives (also called sensitivity).
- **F1-Score**: The harmonic mean of precision and recall.
- **ROC Curve**: A graphical plot illustrating a classifier's performance across various thresholds.
- **Class Imbalance**: When class distribution in the dataset is not uniform, typically when one class significantly outnumbers others.
- **Sampling Techniques**: Methods like oversampling, undersampling, and synthetic data generation to address class imbalance.

## Logistic Regression: The Foundation of Classification

Logistic regression is a linear model that uses the logistic function to transform linear predictions into probabilities:

```python
def sigmoid(z):
    """Logistic (sigmoid) function: transforms any real number into the range [0,1]"""
    return 1 / (1 + np.exp(-z))

def logistic_regression_from_scratch(X, y, learning_rate=0.01, iterations=10000, tol=1e-4):
    """
    Implementation of logistic regression from scratch using gradient descent.
    
    Parameters:
    -----------
    X : numpy array
        Features (n_samples, n_features)
    y : numpy array
        Target variable (n_samples,)
    learning_rate : float
        Step size for gradient descent
    iterations : int
        Maximum number of iterations
    tol : float
        Convergence tolerance
        
    Returns:
    --------
    weights : numpy array
        Learned coefficients
    bias : float
        Learned intercept
    costs : list
        Cost function values during iterations
    """
    m, n = X.shape
    weights = np.zeros(n)
    bias = 0
    costs = []
    
    for i in range(iterations):
        # Forward pass
        z = np.dot(X, weights) + bias
        y_pred = sigmoid(z)
        
        # Compute cost (binary cross-entropy)
        cost = (-1/m) * np.sum(y * np.log(y_pred + 1e-10) + (1 - y) * np.log(1 - y_pred + 1e-10))
        costs.append(cost)
        
        # Compute gradients
        dw = (1/m) * np.dot(X.T, (y_pred - y))
        db = (1/m) * np.sum(y_pred - y)
        
        # Update parameters
        weights = weights - learning_rate * dw
        bias = bias - learning_rate * db
        
        # Check for convergence
        if i > 0 and abs(costs[i] - costs[i-1]) < tol:
            break
    
    return weights, bias, costs
```

## K-Nearest Neighbors: A Non-Parametric Approach

KNN is a simple yet powerful non-parametric algorithm for classification:

```python
# KNN implementation from scratch
def knn_from_scratch(X_train, y_train, X_test, k=5, metric='euclidean'):
    """
    Implementation of K-Nearest Neighbors from scratch.
    
    Parameters:
    -----------
    X_train : numpy array
        Training features
    y_train : numpy array
        Training labels
    X_test : numpy array
        Test features
    k : int
        Number of neighbors to consider
    metric : str
        Distance metric ('euclidean' or 'manhattan')
        
    Returns:
    --------
    y_pred : numpy array
        Predicted labels for test data
    """
    m_test = X_test.shape[0]
    y_pred = np.zeros(m_test)
    
    for i in range(m_test):
        # Compute distances
        if metric == 'euclidean':
            distances = np.sqrt(np.sum((X_train - X_test[i])**2, axis=1))
        elif metric == 'manhattan':
            distances = np.sum(np.abs(X_train - X_test[i]), axis=1)
        else:
            raise ValueError("Metric must be 'euclidean' or 'manhattan'")
        
        # Find k nearest neighbors
        nearest_indices = np.argsort(distances)[:k]
        nearest_labels = y_train[nearest_indices]
        
        # Majority vote
        y_pred[i] = np.bincount(nearest_labels.astype(int)).argmax()
    
    return y_pred
```

## Classification Metrics: Measuring Model Performance

Proper evaluation metrics are crucial for classification tasks:

```python
def comprehensive_classification_metrics(y_true, y_pred, y_proba=None, average='binary'):
    """
    Calculate and display comprehensive classification metrics.
    
    Parameters:
    -----------
    y_true : array-like
        Ground truth labels
    y_pred : array-like
        Predicted labels
    y_proba : array-like, optional
        Predicted probabilities (for ROC and PR curves)
    average : str
        Averaging method for multi-class metrics ('binary', 'micro', 'macro', 'weighted')
    """
    # Basic metrics
    accuracy = accuracy_score(y_true, y_pred)
    
    # Precision, recall, F1 (with appropriate averaging for multi-class)
    precision = precision_score(y_true, y_pred, average=average, zero_division=0)
    recall = recall_score(y_true, y_pred, average=average, zero_division=0)
    f1 = f1_score(y_true, y_pred, average=average, zero_division=0)
    
    # Confusion matrix
    cm = confusion_matrix(y_true, y_pred)
    
    # Display results
    print("\nClassification Metrics:")
    print(f"Accuracy: {accuracy:.4f}")
    print(f"Precision: {precision:.4f}")
    print(f"Recall: {recall:.4f}")
    print(f"F1 Score: {f1:.4f}")
    
    print("\nConfusion Matrix:")
    print(cm)
    
    # Calculate and display ROC-AUC if probabilities are provided
    if y_proba is not None:
        if average == 'binary':
            # Binary classification
            roc_auc = roc_auc_score(y_true, y_proba[:, 1])
            print(f"\nROC-AUC: {roc_auc:.4f}")
            
            # Precision-Recall AUC
            pr_auc = average_precision_score(y_true, y_proba[:, 1])
            print(f"PR-AUC: {pr_auc:.4f}")
        else:
            # Multi-class classification - use one-vs-rest approach
            roc_auc = roc_auc_score(y_true, y_proba, multi_class='ovr', average=average)
            print(f"\nROC-AUC ({average}): {roc_auc:.4f}")
    
    return {
        'accuracy': accuracy,
        'precision': precision,
        'recall': recall,
        'f1': f1,
        'confusion_matrix': cm,
        'roc_auc': roc_auc if y_proba is not None else None
    }
```

```python
# Create an imbalanced dataset for demonstration
def create_imbalanced_dataset(imbalance_ratio=10):
    """Create an imbalanced version of the breast cancer dataset"""
    # Start with the original binary dataset
    X_imb = X_binary.copy()
    y_imb = y_binary.copy()
    
    # Identify the minority class
    class_counts = Counter(y_imb)
    minority_class = min(class_counts, key=class_counts.get)
    majority_class = 1 - minority_class
    
    # Indices of the minority class
    minority_indices = np.where(y_imb == minority_class)[0]
    
    # Randomly select a subset of the minority class to keep
    np.random.seed(42)
    keep_count = len(minority_indices) // imbalance_ratio
    keep_indices = np.random.choice(minority_indices, keep_count, replace=False)
    
    # Indices of the majority class
    majority_indices = np.where(y_imb == majority_class)[0]
    
    # Combine indices to keep
    indices_to_keep = np.concatenate([keep_indices, majority_indices])
    
    # Create the imbalanced dataset
    X_imbalanced = X_imb.iloc[indices_to_keep]
    y_imbalanced = y_imb[indices_to_keep]
    
    print(f"\nImbalanced Dataset Created:")
    print(f"Class distribution: {Counter(y_imbalanced)}")
    imbalance_ratio = Counter(y_imbalanced)[majority_class] / Counter(y_imbalanced)[minority_class]
    print(f"Imbalance ratio: {imbalance_ratio:.1f}:1")
    
    return X_imbalanced, y_imbalanced
```

```python
def build_advanced_classification_pipeline():
    """Build an advanced classification pipeline with proper handling of imbalanced data"""
    # Define preprocessing steps
    numeric_transformer = Pipeline(steps=[
        ('imputer', SimpleImputer(strategy='median')),
        ('scaler', StandardScaler())
    ])
    
    preprocessor = ColumnTransformer(
        transformers=[
            ('num', numeric_transformer, list(range(X_imbalanced.shape[1])))
        ]
    )

    classifiers = {
        'Logistic Regression': LogisticRegression(class_weight='balanced', max_iter=10000),
        'KNN': KNeighborsClassifier(n_neighbors=5)
    }
    
    # Create resampling strategies
    resampling_strategies = {
        'No Resampling': None,
        'SMOTE': SMOTE(random_state=42),
        'Random Oversampling': RandomOverSampler(random_state=42)
    }
    
    # Define cross-validation strategy
    cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
    
    # Compare all combinations
    results = {}
    
    for clf_name, classifier in classifiers.items():
        for rs_name, resampler in resampling_strategies.items():
            # Create pipeline
            if resampler is None:
                # Standard scikit-learn pipeline
                pipeline = Pipeline(steps=[
                    ('preprocessor', preprocessor),
                    ('classifier', classifier)
                ])
            else:
                # Imbalanced-learn pipeline with resampling
                pipeline = ImbPipeline(steps=[
                    ('preprocessor', preprocessor),
                    ('resampler', resampler),
                    ('classifier', classifier)
                ])
            
            # Cross-validate
            cv_scores = cross_val_score(
                pipeline, X_imbalanced, y_imbalanced, cv=cv, scoring='f1'
            )
            
            # Store results
            key = f"{clf_name} with {rs_name}"
            results[key] = {
                'mean_f1': cv_scores.mean(),
                'std_f1': cv_scores.std(),
                'pipeline': pipeline
            }
    
    # Print results
    print("\nCross-Validation Results (F1 Score):")
    for name, result in sorted(results.items(), key=lambda x: x[1]['mean_f1'], reverse=True):
        print(f"{name}: {result['mean_f1']:.4f} ± {result['std_f1']:.4f}")
    
    # Train the best pipeline on the full training set
    best_pipeline_name = max(results, key=lambda x: results[x]['mean_f1'])
    best_pipeline = results[best_pipeline_name]['pipeline']

        y_test_imb, y_pred_best, y_proba_best, average='binary'
```
