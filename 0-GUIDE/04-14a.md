## Key Terms and Concepts

- **Machine Learning Operations (MLOps)**: A set of practices that aims to deploy and maintain machine learning models in production reliably and efficiently.
- **AI/ML Production Lifecycle**: The end-to-end process of developing, deploying, monitoring, and updating AI/ML models in production environments.
- **Technical Debt**: The implied cost of additional rework caused by choosing an expedient solution now instead of a better approach that would take longer.
- **Model Drift**: The degradation of model performance due to changes in the statistical properties of target variables or features over time.
- **Continuous Integration/Continuous Deployment (CI/CD)**: Automated pipelines for testing and deploying code and machine learning models.
- **A/B Testing**: A method of comparing two versions of a model or feature to determine which performs better.
- **Model Registry**: A centralized repository for storing, managing, and tracking machine learning models and their metadata.
- **Data Versioning**: The practice of tracking changes to datasets over time, enabling reproducibility and rollbacks.
- **Skills Gap**: The difference between the skills required for a job and those possessed by the workforce.
- **T-shaped Skills**: Deep expertise in one area combined with broad knowledge across multiple domains.

class MLProjectIntegration:
    """

    def __init__(self, data_path=None, model_registry_path="models"):
        """Initialize the ML project with paths and configurations."""
        self.data_path = data_path
        self.model_registry_path = model_registry_path

    def load_data(self, data_path=None, target_column=None):

    def exploratory_data_analysis(self):

    def clean_data(self):
        """Clean the data by handling missing values and outliers."""
        if self.data is None:
            raise ValueError("No data loaded. Call load_data() first.")
        
        # Store original shape
        original_shape = self.data.shape
        
        # Handle missing values
        numeric_columns = self.data.select_dtypes(include=[np.number]).columns
        categorical_columns = self.data.select_dtypes(include=['object', 'category']).columns
        
        # Fill numeric missing values with median
        for col in numeric_columns:
            if self.data[col].isnull().sum() > 0:
                median_value = self.data[col].median()
                self.data[col].fillna(median_value, inplace=True)
                logger.info(f"Filled missing values in {col} with median value {median_value}")
        
        # Fill categorical missing values with mode
        for col in categorical_columns:
            if self.data[col].isnull().sum() > 0:
                mode_value = self.data[col].mode()[0]
                self.data[col].fillna(mode_value, inplace=True)
                logger.info(f"Filled missing values in {col} with mode value '{mode_value}'")
        
        # Handle outliers in numeric columns using IQR method
        for col in numeric_columns:
            Q1 = self.data[col].quantile(0.25)
            Q3 = self.data[col].quantile(0.75)
            IQR = Q3 - Q1
            lower_bound = Q1 - 1.5 * IQR
            upper_bound = Q3 + 1.5 * IQR
            
            # Cap outliers
            outliers_count = ((self.data[col] < lower_bound) | (self.data[col] > upper_bound)).sum()
            if outliers_count > 0:
                self.data[col] = self.data[col].clip(lower=lower_bound, upper=upper_bound)
                logger.info(f"Capped {outliers_count} outliers in {col}")
        
        # Update X and y if they were previously set
        if self.X is not None and self.y is not None:
            target_column = self.y.name
            self.X = self.data.drop(columns=[target_column])
            self.y = self.data[target_column]
        
        logger.info(f"Data cleaning complete. Original shape: {original_shape}, New shape: {self.data.shape}")
        return self.data
    
    def create_preprocessing_pipeline(self, numeric_features=None, categorical_features=None):
        """Create a preprocessing pipeline for feature engineering."""
        if self.X is None:
            raise ValueError("Features not defined. Load data and set target first.")
        
        # If features not specified, infer from data types
        if numeric_features is None:
            numeric_features = self.X.select_dtypes(include=[np.number]).columns.tolist()
        
        if categorical_features is None:
            categorical_features = self.X.select_dtypes(include=['object', 'category']).columns.tolist()
        
        # Define preprocessing for numeric features
        numeric_transformer = Pipeline(steps=[
            ('scaler', StandardScaler())
        ])
        
        # Define preprocessing for categorical features
        categorical_transformer = Pipeline(steps=[
            ('onehot', OneHotEncoder(handle_unknown='ignore'))
        ])
        
        # Combine preprocessing steps
        self.preprocessor = ColumnTransformer(
            transformers=[
                ('num', numeric_transformer, numeric_features),
                ('cat', categorical_transformer, categorical_features)
            ],
            remainder='passthrough'
        )
        
        logger.info(f"Created preprocessing pipeline with {len(numeric_features)} numeric features and {len(categorical_features)} categorical features")
        return self.preprocessor
    
    def reduce_dimensionality(self, n_components=0.95):
        """Apply PCA for dimensionality reduction."""
        if self.preprocessor is None:
            raise ValueError("Preprocessor not defined. Call create_preprocessing_pipeline() first.")
        
        # Add PCA to the preprocessing pipeline
        self.preprocessor = Pipeline(steps=[
            ('preprocessor', self.preprocessor),
            ('pca', PCA(n_components=n_components))
        ])
        
        logger.info(f"Added PCA to preprocessing pipeline with n_components={n_components}")
        return self.preprocessor
    
    def train_models(self, models_config=None):
        """Train multiple models and compare their performance."""
        if self.X is None or self.y is None:
            raise ValueError("Features and target not defined.")
        
        if self.preprocessor is None:
            logger.warning("No preprocessor defined. Creating default preprocessing pipeline.")
            self.create_preprocessing_pipeline()
        
        # Default models configuration if not provided
        if models_config is None:
            models_config = {
                'logistic_regression': {
                    'model': LogisticRegression(max_iter=1000),
                    'params': {
                        'C': [0.1, 1.0, 10.0],
                        'solver': ['liblinear', 'lbfgs']
                    }
                },
                'random_forest': {
                    'model': RandomForestClassifier(),
                    'params': {
                        'n_estimators': [100, 200],
                        'max_depth': [None, 10, 20],
                        'min_samples_split': [2, 5]
                    }
                },
                'gradient_boosting': {
                    'model': GradientBoostingClassifier(),
                    'params': {
                        'n_estimators': [100, 200],
                        'learning_rate': [0.01, 0.1],
                        'max_depth': [3, 5]
                    }
                }
            }
        
        # Split data into train and test sets
        X_train, X_test, y_train, y_test = train_test_split(
            self.X, self.y, test_size=0.2, random_state=42
        )
        
        results = {}
        
        # Train and evaluate each model
        for model_name, config in models_config.items():
            logger.info(f"Training {model_name}...")
            
            # Create a pipeline with preprocessing and the model
            model_pipeline = Pipeline(steps=[
                ('preprocessor', self.preprocessor),
                ('model', config['model'])
            ])
            
            # Set up grid search with cross-validation
            grid_search = GridSearchCV(
                model_pipeline,
                param_grid={'model__' + key: value for key, value in config['params'].items()},
                cv=5,
                scoring='accuracy',
                verbose=1
            )
            
            # Fit the grid search
            grid_search.fit(X_train, y_train)
            
            # Get best model and its performance
            best_model = grid_search.best_estimator_
            best_params = grid_search.best_params_
            cv_score = grid_search.best_score_
            
            # Evaluate on test set
            y_pred = best_model.predict(X_test)
            test_score = roc_auc_score(y_test, best_model.predict_proba(X_test)[:, 1])
            
            # Store results
            results[model_name] = {
                'model': best_model,
                'best_params': best_params,
                'cv_score': cv_score,
                'test_score': test_score,
                'classification_report': classification_report(y_test, y_pred, output_dict=True)
            }
            
            logger.info(f"{model_name} training complete.")
            logger.info(f"Best parameters: {best_params}")
            logger.info(f"CV Score: {cv_score:.4f}")
            logger.info(f"Test Score (ROC AUC): {test_score:.4f}")
        
        # Identify best model based on test score
        best_model_name = max(results, key=lambda x: results[x]['test_score'])
        self.best_model = results[best_model_name]['model']
        self.models = results
        
        logger.info(f"Best model: {best_model_name} with test score {results[best_model_name]['test_score']:.4f}")
        
        return results
    
    def train_neural_network(self, hidden_layers=[64, 32], dropout_rate=0.2, epochs=50, batch_size=32):
        """Train a neural network model."""
        if self.X is None or self.y is None:
            raise ValueError("Features and target not defined.")
        
        if self.preprocessor is None:
            logger.warning("No preprocessor defined. Creating default preprocessing pipeline.")
            self.create_preprocessing_pipeline()
        
        # Preprocess data
        X_processed = self.preprocessor.fit_transform(self.X)
        
        # Split data
        X_train, X_test, y_train, y_test = train_test_split(
            X_processed, self.y, test_size=0.2, random_state=42
        )
        
        # Determine input shape
        input_shape = X_processed.shape[1]
        
        # Create neural network model
        model = Sequential()
        
        # Add input layer
        model.add(Dense(hidden_layers[0], activation='relu', input_shape=(input_shape,)))
        model.add(Dropout(dropout_rate))
        
        # Add hidden layers
        for units in hidden_layers[1:]:
            model.add(Dense(units, activation='relu'))
            model.add(Dropout(dropout_rate))
        
        # Add output layer
        model.add(Dense(1, activation='sigmoid'))
        
        # Compile model
        model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
        
        # Train model
        history = model.fit(
            X_train, y_train,
            epochs=epochs,
            batch_size=batch_size,
            validation_split=0.2,
            verbose=1
        )
        
        # Evaluate model
        evaluation = model.evaluate(X_test, y_test)
        
        # Predictions
        y_pred_proba = model.predict(X_test)
        y_pred = (y_pred_proba > 0.5).astype(int)
        
        # Calculate metrics
        nn_results = {
            'model': model,
            'history': history,
            'evaluation': evaluation,
            'classification_report': classification_report(y_test, y_pred, output_dict=True),
            'test_score': roc_auc_score(y_test, y_pred_proba)
        }
        
        # Add to models
        self.models['neural_network'] = nn_results
        
        # Update best model if neural network performs better
        if nn_results['test_score'] > max([self.models[m]['test_score'] for m in self.models if m != 'neural_network']):
            logger.info("Neural network outperforms other models")
            self.best_model = {
                'type': 'neural_network',
                'model': model,
                'preprocessor': self.preprocessor
            }
        
        logger.info(f"Neural network training complete. Test score (ROC AUC): {nn_results['test_score']:.4f}")
        
        return nn_results
    
    def save_model(self, model_name=None):

        if model_name is None:

                metadata = {
                    'model_type': 'sklearn',
                    'created_at': datetime.datetime.now().isoformat(),

        logger.info(f"Model saved to {model_path}")
        return model_path
    
    def load_model(self, model_path):
        """Load a model from the model registry."""
        # Check if path exists
        if not os.path.exists(model_path):
            raise ValueError(f"Model path {model_path} does not exist")
        
        # Load metadata to determine model type
        try:
            with open(os.path.join(model_path, 'metadata.json'), 'r') as f:
                metadata = json.load(f)
                
            if metadata['model_type'] == 'neural_network':
                # Load neural network model
                nn_model = tf.keras.models.load_model(os.path.join(model_path, 'nn_model'))
                preprocessor = joblib.load(os.path.join(model_path, 'preprocessor.pkl'))
                
                self.best_model = {
                    'type': 'neural_network',
                    'model': nn_model,
                    'preprocessor': preprocessor
                }
            else:
                # Load sklearn model
                self.best_model = joblib.load(os.path.join(model_path, 'model.pkl'))
                
            logger.info(f"Model loaded from {model_path}")
            return self.best_model
            
        except Exception as e:
            logger.error(f"Error loading model: {str(e)}")
            raise
    
    def predict(self, data):
        """Make predictions using the best model."""
        if self.best_model is None:
            raise ValueError("No model available. Train or load a model first.")
        
        # Convert to DataFrame if not already
        if not isinstance(data, pd.DataFrame):
            try:
                data = pd.DataFrame(data)
            except:
                raise ValueError("Data must be convertible to a pandas DataFrame")
        
        # Make predictions
        try:
            if isinstance(self.best_model, dict) and self.best_model['type'] == 'neural_network':
                # Preprocess data
                X_processed = self.best_model['preprocessor'].transform(data)
                # Make predictions
                predictions = self.best_model['model'].predict(X_processed)
                # Convert to binary predictions
                binary_predictions = (predictions > 0.5).astype(int)
                return {
                    'probability': predictions.flatten(),
                    'class': binary_predictions.flatten()
                }
            else:
                # For sklearn models, the pipeline includes preprocessing
                return {
                    'probability': self.best_model.predict_proba(data)[:, 1],
                    'class': self.best_model.predict(data)
                }
        except Exception as e:
            logger.error(f"Error making predictions: {str(e)}")
            raise
    
    def create_rag_system(self, documents_folder):
        """
        Create a Retrieval-Augmented Generation system for answering
        questions about machine learning concepts.
        """
        # Load environment variables
        load_dotenv()
        
        # Check if OpenAI API key is available
        if not os.getenv("OPENAI_API_KEY"):
            logger.error("OpenAI API key not found in environment variables")
            raise ValueError("OpenAI API key not found. Add it to .env file.")
        
        try:
            # Load documents
            loader = DirectoryLoader(documents_folder, glob="**/*.md")
            documents = loader.load()
            logger.info(f"Loaded {len(documents)} documents")
            
            # Split documents into chunks
            text_splitter = RecursiveCharacterTextSplitter(
                chunk_size=1000,
                chunk_overlap=200
            )
            
            chunks = text_splitter.split_documents(documents)
            logger.info(f"Split into {len(chunks)} chunks")
            
            # Create embeddings
            embeddings = OpenAIEmbeddings()
            
            # Create vector store
            vector_store = FAISS.from_documents(chunks, embeddings)
            logger.info("Created vector store")
            
            # Create QA chain
            llm = OpenAI(temperature=0)
            qa_chain = RetrievalQA.from_chain_type(
                llm=llm,
                chain_type="stuff",
                retriever=vector_store.as_retriever()
            )
            
            logger.info("RAG system created successfully")
            
            return qa_chain
            
        except Exception as e:
            logger.error(f"Error creating RAG system: {str(e)}")
            raise

            qa_chain = self.create_rag_system(documents_folder)
        
        # Get answer

        return result

2. **Specialization vs. Generalization**: While the field demands some specialists with deep expertise, there's also growing value in "full-stack" ML practitioners who understand the entire lifecycle.

4. **Ethical AI Implementation**: Responsible AI practices are no longer optional but essential components of any serious AI initiative.

5. **Continuous Learning Requirement**: The rapid pace of innovation means that continuous learning is not just beneficial but necessary to remain competitive.

To succeed in this dynamic field:

- **Build a Strong Foundation**: Ensure you have solid understanding of the fundamentals before chasing the latest trends.

- **Focus on Real-world Applications**: Bridge the gap between theoretical knowledge and practical implementation through hands-on projects.
- **Embrace Collaboration**: The complexity of modern AI systems requires cross-functional collaboration across technical and domain specialties.
- **Prioritize Ethical Considerations**: Incorporate responsible AI principles into your work from the beginning, not as an afterthought.

The job market for ML and AI professionals remains strong, though increasingly competitive at entry levels. The greatest opportunities exist for those who can demonstrate both technical proficiency and the ability to translate technical capabilities into business value.
