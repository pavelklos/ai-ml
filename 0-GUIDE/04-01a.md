## Key Terms

- **Artificial Intelligence (AI)**: The simulation of human intelligence in machines programmed to think and learn like humans.
- **Machine Learning (ML)**: A subset of AI that enables systems to learn and improve from experience without being explicitly programmed.
- **Optimization Problem**: A mathematical problem of finding the best solution from all feasible solutions.
- **Cost/Loss Function**: A function that maps an event or values of variables onto a real number representing some "cost" associated with the event.
- **Gradient Descent**: An iterative optimization algorithm for finding the minimum of a function.
- **NumPy**: A Python library providing support for large, multi-dimensional arrays and matrices.
- **SciPy**: A Python library used for scientific and technical computing.

## Introduction to Machine Learning

Machine learning is a field of AI focused on developing systems that can learn from data. These systems improve their performance over time without being explicitly programmed. The core of machine learning involves:

1. **Supervised Learning**: Training on labeled data
2. **Unsupervised Learning**: Finding patterns in unlabeled data
3. **Reinforcement Learning**: Learning through trial and error with rewards/penalties

All these approaches fundamentally rely on optimization techniques.

## Optimization Problems in Machine Learning

In machine learning, optimization is the process of finding the best parameters for a model that minimizes error or maximizes performance. Mathematically, we can express this as:

```
min_θ f(θ)
```

Where:
- θ represents the model parameters
- f(θ) is the objective function (usually a loss function)

Common optimization problems in machine learning include:
- Finding weights in neural networks
- Finding coefficients in regression models
- Finding support vectors in support vector machines

## Using NumPy and SciPy for Optimization

Let's look at how to solve optimization problems using Python libraries:

```python
# Import necessary libraries
import numpy as np
from scipy import optimize
import matplotlib.pyplot as plt

# Define a function to minimize
def objective_function(x):
    return x[0]**2 + x[1]**2 + 2*x[0]*x[1]

# Define constraints
def constraint1(x):
    return x[0] + x[1] - 1  # Constraint: x[0] + x[1] >= 1

# Initial guess
x0 = [0, 0]

# Define bounds for variables
bounds = [(-10, 10), (-10, 10)]

# Define constraints dictionary
constraints = [{'type': 'ineq', 'fun': constraint1}]

# Perform optimization
result = optimize.minimize(
    objective_function, 
    x0, 
    method='SLSQP',  # Sequential Least SQuares Programming
    bounds=bounds,
    constraints=constraints
)

# Print results
print("Status:", result.success)
print("Termination message:", result.message)
print("Optimal solution:", result.x)
print("Objective function value:", result.fun)
```

## Optimization for Prediction Tasks

In prediction tasks, we aim to find model parameters that minimize the difference between predicted and actual values:

```python
import numpy as np
from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt

# Generate synthetic data
np.random.seed(42)
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X + np.random.randn(100, 1)

# Implement gradient descent manually
def compute_cost(X, y, theta):
    m = len(y)
    predictions = X.dot(theta)
    cost = (1/(2*m)) * np.sum(np.square(predictions - y))
    return cost

def gradient_descent(X, y, theta, alpha, iterations):
    m = len(y)
    cost_history = np.zeros(iterations)
    theta_history = np.zeros((iterations, 2))
    
    for i in range(iterations):
        prediction = X.dot(theta)
        theta = theta - (alpha/m) * (X.T.dot(prediction - y))
        theta_history[i,:] = theta.T
        cost_history[i] = compute_cost(X, y, theta)
    
    return theta, cost_history, theta_history

# Add a column of ones for the intercept term
X_b = np.c_[np.ones((100, 1)), X]
theta = np.random.randn(2, 1)

# Run gradient descent
iterations = 1000
alpha = 0.01
theta_final, cost_history, theta_history = gradient_descent(X_b, y, theta, alpha, iterations)

print("Final theta values:", theta_final)
print("Final cost value:", cost_history[-1])

# Compare with scikit-learn
model = LinearRegression()
model.fit(X, y)
print("scikit-learn coefficients:", model.intercept_[0], model.coef_[0][0])
```

## Gradient Descent Algorithm

Gradient descent is an iterative optimization algorithm for finding the minimum of a differentiable function. The basic idea is to take repeated steps in the direction of the steepest decrease of the function.

The algorithm updates parameters in the opposite direction of the gradient of the objective function:

```
θ_new = θ_old - α * ∇f(θ_old)
```

Where:
- θ_old is the current parameter value
- α is the learning rate (step size)
- ∇f(θ_old) is the gradient of the objective function at θ_old

Variants of gradient descent include:

1. **Batch Gradient Descent**: Computes the gradient using the entire dataset
2. **Stochastic Gradient Descent (SGD)**: Computes the gradient using a single sample
3. **Mini-batch Gradient Descent**: Computes the gradient using a small batch of samples

Here's an implementation of stochastic gradient descent:

```python
def stochastic_gradient_descent(X, y, theta, alpha, iterations, batch_size=10):
    m = len(y)
    cost_history = np.zeros(iterations)
    
    for i in range(iterations):
        cost = 0.0
        indices = np.random.permutation(m)
        X_shuffled = X[indices]
        y_shuffled = y[indices]
        
        for j in range(0, m, batch_size):
            X_batch = X_shuffled[j:j+batch_size]
            y_batch = y_shuffled[j:j+batch_size]
            
            prediction = X_batch.dot(theta)
            theta = theta - (alpha/len(X_batch)) * (X_batch.T.dot(prediction - y_batch))
            cost += compute_cost(X_batch, y_batch, theta)
        
        cost_history[i] = cost
    
    return theta, cost_history

# Use SGD
theta_sgd, cost_history_sgd = stochastic_gradient_descent(X_b, y, theta, alpha=0.01, iterations=50)
print("SGD final theta:", theta_sgd)
```
