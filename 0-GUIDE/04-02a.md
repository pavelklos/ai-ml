## Key Terms and Concepts

- **Linear Regression**: A statistical model that analyzes the relationship between a dependent variable and one or more independent variables.
- **Least Squares Method**: Mathematical approach to find the best-fitting line by minimizing the sum of squared residuals.
- **Simple Linear Regression**: Model with one independent variable.
- **Multiple Linear Regression**: Model with multiple independent variables.
- **Coefficients**: Parameters that describe the relationship between independent variables and the dependent variable.
- **Intercept**: The value of the dependent variable when all independent variables are zero.
- **Residuals**: Differences between observed and predicted values.
- **R-squared (R²)**: Statistical measure representing the proportion of variance explained by the model.
- **Adjusted R-squared**: Modified version of R² that adjusts for the number of predictors in the model.
- **Multicollinearity**: High correlation between independent variables that can affect coefficient interpretation.
- **Homoscedasticity**: Condition where residuals have constant variance across all levels of independent variables.

## Theoretical Foundation of Linear Regression

Linear regression is a fundamental supervised learning algorithm based on the linear relationship between variables. The mathematical representation of a linear regression model is:

For simple linear regression:
```
y = β₀ + β₁x + ε
```

For multiple linear regression:
```
y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε
```

Where:
- y is the dependent variable (target)
- x, x₁, x₂, etc. are independent variables (features)
- β₀ is the intercept
- β₁, β₂, etc. are coefficients
- ε is the error term

### Least Squares Method

The least squares method finds optimal values for the coefficients by minimizing the sum of squared residuals (SSR):

```
SSR = Σ(yᵢ - ŷᵢ)² = Σ(yᵢ - (β₀ + β₁x₁ᵢ + β₂x₂ᵢ + ... + βₙxₙᵢ))²
```

Let's implement a function to calculate the coefficients using the normal equation:

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import train_test_split, cross_val_score, KFold
from sklearn.linear_model import LinearRegression, Ridge, Lasso, ElasticNet
from sklearn.preprocessing import StandardScaler, PolynomialFeatures
from sklearn.pipeline import Pipeline
from sklearn.metrics import mean_squared_error, r2_score, mean_absolute_error
from sklearn.feature_selection import RFE
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor
import warnings
warnings.filterwarnings('ignore')

def least_squares_coefficients(X, y):
    """
    Calculate linear regression coefficients using the normal equation.
    
    Parameters:
    -----------
    X : numpy array
        Features (with a column of 1s for the intercept)
    y : numpy array
        Target variable
        
    Returns:
    --------
    coefficients : numpy array
        Regression coefficients including intercept
    """
    # Add a column of 1s for the intercept term
    X_with_intercept = np.column_stack((np.ones(X.shape[0]), X))
    
    # Calculate coefficients using the normal equation: β = (X^T X)^(-1) X^T y
    XTX = np.dot(X_with_intercept.T, X_with_intercept)
    XTX_inv = np.linalg.inv(XTX)
    XTy = np.dot(X_with_intercept.T, y)
    coefficients = np.dot(XTX_inv, XTy)
    
    return coefficients

# Example usage with synthetic data
np.random.seed(42)
n_samples = 100
X = np.random.normal(0, 1, (n_samples, 3))  # 3 features
true_coefficients = [2.5, 0.8, -1.2, 0.5]   # Intercept and 3 feature coefficients
y = true_coefficients[0] + np.dot(X, true_coefficients[1:]) + np.random.normal(0, 0.5, n_samples)

calculated_coefficients = least_squares_coefficients(X, y)
print("True coefficients:", true_coefficients)
print("Calculated coefficients:", calculated_coefficients)

# Implement gradient descent as an alternative method
def gradient_descent(X, y, learning_rate=0.01, iterations=10000, tol=1e-6):
    """
    Implement linear regression using gradient descent.
    
    Parameters:
    -----------
    X : numpy array
        Features
    y : numpy array
        Target variable
    learning_rate : float
        Step size for gradient descent
    iterations : int
        Maximum number of iterations
    tol : float
        Convergence tolerance
        
    Returns:
    --------
    coefficients : numpy array
        Regression coefficients including intercept
    cost_history : list
        Cost function values during iterations
    """
    m = X.shape[0]  # Number of samples
    
    # Add a column of 1s for the intercept term
    X_with_intercept = np.column_stack((np.ones(X.shape[0]), X))
    n_features = X_with_intercept.shape[1]
    
    # Initialize coefficients
    coefficients = np.zeros(n_features)
    
    # Initialize cost history
    cost_history = []
    
    # Previous cost for convergence check
    prev_cost = float('inf')
    
    for i in range(iterations):
        # Compute predictions
        y_pred = np.dot(X_with_intercept, coefficients)
        
        # Compute error
        error = y_pred - y
        
        # Compute gradient
        gradient = (1/m) * np.dot(X_with_intercept.T, error)
        
        # Update coefficients
        coefficients = coefficients - learning_rate * gradient
        
        # Compute cost
        cost = (1/(2*m)) * np.sum(error**2)
        cost_history.append(cost)
        
        # Check for convergence
        if abs(prev_cost - cost) < tol:
            break
        
        prev_cost = cost
    
    return coefficients, cost_history

# Run gradient descent
gd_coefficients, cost_history = gradient_descent(X, y)
print("\nGradient Descent coefficients:", gd_coefficients)
```

## Simple vs. Multiple Linear Regression

### Simple Linear Regression

Simple linear regression involves one independent variable predicting a dependent variable. It's represented by a straight line in a 2D space:

```python
# Generate data for simple linear regression
np.random.seed(42)
X_simple = np.random.uniform(0, 10, 100).reshape(-1, 1)
y_simple = 2 + 3 * X_simple.flatten() + np.random.normal(0, 1, 100)

# Split data into training and testing sets
X_train, X_test, y_train, y_test = train_test_split(X_simple, y_simple, test_size=0.2, random_state=42)

# Implement simple linear regression
def simple_linear_regression(X, y):
    """
    Manually implement simple linear regression.
    
    Parameters:
    -----------
    X : numpy array
        Single feature (one-dimensional)
    y : numpy array
        Target variable
        
    Returns:
    --------
    intercept : float
        Intercept (β₀)
    slope : float
        Slope (β₁)
    """
    X = X.flatten()
    n = len(X)
    
    # Calculate means
    x_mean = np.mean(X)
    y_mean = np.mean(y)
    
    # Calculate slope
    numerator = np.sum((X - x_mean) * (y - y_mean))
    denominator = np.sum((X - x_mean) ** 2)
    slope = numerator / denominator
    
    # Calculate intercept
    intercept = y_mean - slope * x_mean
    
    return intercept, slope

# Calculate coefficients manually

print(f"\nSimple Linear Regression (Manual):")
print(f"Intercept (β₀): {intercept:.4f}")
print(f"Slope (β₁): {slope:.4f}")

# Calculate predictions

# Calculate metrics

r2_manual = r2_score(y_test, y_pred_manual)
print(f"MSE: {mse_manual:.4f}")
print(f"R²: {r2_manual:.4f}")
```

```python
# Create a pipeline for preprocessing and model training
def create_regression_pipeline(alpha=1.0, l1_ratio=0.5, regression_type='linear'):
    """
    Create a pipeline for regression with preprocessing steps.
    
    Parameters:
    -----------
    alpha : float
        Regularization strength
    l1_ratio : float
        Ratio for ElasticNet (0 = Ridge, 1 = Lasso)
    regression_type : str
        Type of regression ('linear', 'ridge', 'lasso', 'elasticnet')
        
    Returns:
    --------
    pipeline : Pipeline
        Scikit-learn pipeline
    """
    steps = [
        ('scaler', StandardScaler())
    ]
    
    if regression_type == 'ridge':
        steps.append(('model', Ridge(alpha=alpha)))
    elif regression_type == 'lasso':
        steps.append(('model', Lasso(alpha=alpha)))
    elif regression_type == 'elasticnet':
        steps.append(('model', ElasticNet(alpha=alpha, l1_ratio=l1_ratio)))
    else:
        steps.append(('model', LinearRegression()))
    
    return Pipeline(steps)

# Compare different regression models
```

## Making Predictions with Linear Regression

Predictions are the primary goal of regression models:

```python
# Create a function to generate predictions with confidence intervals
def predict_with_confidence(model, X_test, y_test, conf_level=0.95):
    """
    Generate predictions with confidence intervals.
    
    Parameters:
    -----------
    model : fitted statsmodels OLS model
    X_test : test features
    y_test : test target
    conf_level : confidence level (default: 0.95)
    
    Returns:
    --------
    predictions_df : DataFrame with predictions and intervals
    """
    # Add constant if using statsmodels
    if isinstance(model, sm.regression.linear_model.RegressionResultsWrapper):
        X_test_const = sm.add_constant(X_test)
        # Get predictions
        y_pred = model.predict(X_test_const)
        # Get prediction intervals
        pred_ints = model.get_prediction(X_test_const).conf_int(alpha=1-conf_level)
    else:
        # For scikit-learn models
        y_pred = model.predict(X_test)
        # We'll need to approximate confidence intervals
        residuals = y_pred - y_test
        std_resid = np.std(residuals)
        z_critical = 1.96  # Approximately 95% confidence
        margin_error = z_critical * std_resid
        pred_ints = np.column_stack((y_pred - margin_error, y_pred + margin_error))
    
    # Create DataFrame with results
    predictions_df = pd.DataFrame({
        'Actual': y_test,
        'Predicted': y_pred,
        'Lower CI': pred_ints[:, 0],
        'Upper CI': pred_ints[:, 1]
    })
    
    return predictions_df

# Get predictions with confidence intervals
# For statsmodels
X_test_sm = sm.add_constant(X_test_multi)
predictions_sm = predict_with_confidence(model_sm, X_test_multi, y_test_multi)

# Display sample predictions
print("\nSample Predictions with Confidence Intervals:")
print(predictions_sm.head())

# Calculate prediction errors
predictions_sm['Error'] = predictions_sm['Actual'] - predictions_sm['Predicted']
predictions_sm['Absolute Error'] = abs(predictions_sm['Error'])
predictions_sm['Within CI'] = (predictions_sm['Actual'] >= predictions_sm['Lower CI']) & \
                              (predictions_sm['Actual'] <= predictions_sm['Upper CI'])

print("\nPrediction Error Statistics:")
print(f"Mean Absolute Error: {predictions_sm['Absolute Error'].mean():.4f}")
print(f"Percentage within 95% CI: {100 * predictions_sm['Within CI'].mean():.2f}%")
```

## Practical Exercise: Building a Comprehensive Linear Regression Model

Let's implement a complete workflow for linear regression:

```python
# Load a dataset with categorical and numerical features
from sklearn.datasets import fetch_openml

# Function to handle the entire regression workflow
def regression_workflow(dataset_name='boston', test_size=0.2, polynomial_degree=1):
    """
    Complete regression workflow from data loading to evaluation.
    
    Parameters:
    -----------
    dataset_name : str
        Name of the dataset to use
    test_size : float
        Proportion of data to use for testing
    polynomial_degree : int
        Degree of polynomial features to generate
        
    Returns:
    --------
    results : dict
        Dictionary containing models and evaluation metrics
    """
    # 1. Load data
    try:
        data = fetch_openml(name=dataset_name, as_frame=True)
        X = data.data
        y = data.target
        feature_names = X.columns
    except:
        # Fallback to California housing if Boston dataset is unavailable
        data = fetch_california_housing()
        X = pd.DataFrame(data.data, columns=data.feature_names)
        y = data.target
        feature_names = data.feature_names
    
    print(f"Dataset: {dataset_name}")
    print(f"Features: {feature_names.tolist()}")
    print(f"Target: {data.target_names if hasattr(data, 'target_names') else 'Housing price'}")
    print(f"Number of samples: {X.shape[0]}")
    
    # 2. Exploratory Data Analysis
    print("\nData Overview:")
    print(X.describe())
    
    # Check for missing values
    missing_values = X.isnull().sum()
    if missing_values.sum() > 0:
        print("\nMissing Values:")
        print(missing_values[missing_values > 0])
        
        # Impute missing values
        from sklearn.impute import SimpleImputer
        imputer = SimpleImputer(strategy='median')
        X = pd.DataFrame(imputer.fit_transform(X), columns=X.columns)
    
    # 3. Split data
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=test_size, random_state=42)
    
    # 4. Feature Engineering
    # Identify categorical columns
    categorical_cols = X.select_dtypes(include=['object', 'category']).columns
    numerical_cols = X.select_dtypes(include=['int64', 'float64']).columns
    
    # Create preprocessing pipeline
    from sklearn.compose import ColumnTransformer
    from sklearn.preprocessing import OneHotEncoder
    
    # Define preprocessing for numerical and categorical data
    numerical_transformer = Pipeline(steps=[
        ('scaler', StandardScaler())
    ])
    
    if len(categorical_cols) > 0:
        categorical_transformer = Pipeline(steps=[
            ('onehot', OneHotEncoder(handle_unknown='ignore'))
        ])
        
        preprocessor = ColumnTransformer(
            transformers=[
                ('num', numerical_transformer, numerical_cols),
                ('cat', categorical_transformer, categorical_cols)
            ])
    else:
        preprocessor = ColumnTransformer(
            transformers=[
                ('num', numerical_transformer, numerical_cols)
            ])
    
    # Add polynomial features if requested
    if polynomial_degree > 1:
        poly_features = PolynomialFeatures(degree=polynomial_degree, include_bias=False)
        X_train_poly = poly_features.fit_transform(X_train)
        X_test_poly = poly_features.transform(X_test)
        
        # Get feature names for polynomials
        if hasattr(poly_features, 'get_feature_names_out'):
            poly_feature_names = poly_features.get_feature_names_out(X.columns)
        else:
            poly_feature_names = [f'Poly_{i}' for i in range(X_train_poly.shape[1])]
        
        print(f"\nAdded polynomial features (degree {polynomial_degree}):")
        print(f"Number of features increased from {X.shape[1]} to {X_train_poly.shape[1]}")
        
        # Replace original features with polynomial features
        X_train = pd.DataFrame(X_train_poly, columns=poly_feature_names)
        X_test = pd.DataFrame(X_test_poly, columns=poly_feature_names)
    
    # 5. Create model pipelines
    models = {
        'Linear Regression': Pipeline(steps=[
            ('preprocessor', preprocessor),
            ('model', LinearRegression())
        ]),
        'Ridge Regression': Pipeline(steps=[
            ('preprocessor', preprocessor),
            ('model', Ridge(alpha=0.1))
        ]),
        'Lasso Regression': Pipeline(steps=[
            ('preprocessor', preprocessor),
            ('model', Lasso(alpha=0.1))
        ]),
        'ElasticNet': Pipeline(steps=[
            ('preprocessor', preprocessor),
            ('model', ElasticNet(alpha=0.1, l1_ratio=0.5))
        ])
    }
    
    # 6. Train and evaluate models
    results = {}
    
    for name, model in models.items():
        # Train the model
        model.fit(X_train, y_train)
        
        # Make predictions
        y_pred = model.predict(X_test)
        
        # Calculate metrics
        mse = mean_squared_error(y_test, y_pred)
        rmse = np.sqrt(mse)
        mae = mean_absolute_error(y_test, y_pred)
        r2 = r2_score(y_test, y_pred)
        
        # Store results
        results[name] = {
            'model': model,
            'predictions': y_pred,
            'MSE': mse,
            'RMSE': rmse,
            'MAE': mae,
            'R²': r2
        }
        
        print(f"\n{name} Results:")
        print(f"MSE: {mse:.4f}")
        print(f"RMSE: {rmse:.4f}")
        print(f"MAE: {mae:.4f}")
        print(f"R²: {r2:.4f}")
    
    # 7. Detailed analysis of the best model
    best_model_name = max(results, key=lambda x: results[x]['R²'])
    print(f"\nBest Model: {best_model_name} (R² = {results[best_model_name]['R²']:.4f})")
    
    # Get feature importances if possible
    if hasattr(models[best_model_name][-1], 'coef_'):
        # For linear models, get coefficients
        model_coefs = models[best_model_name][-1].coef_
        
        # Get feature names after preprocessing
        if polynomial_degree > 1:
            feature_names_after_preprocessing = poly_feature_names
        else:
            feature_names_after_preprocessing = feature_names
            
            # If we have categorical features, we need to get the transformed feature names
            if len(categorical_cols) > 0:
                # This is an approximation as getting exact feature names after one-hot encoding is complex
                cat_features_count = sum([X[col].nunique() for col in categorical_cols])
                num_features_count = len(numerical_cols)
                feature_names_after_preprocessing = list(numerical_cols) + [f'Cat_{i}' for i in range(cat_features_count)]
        
        # Create feature importance DataFrame
        if len(model_coefs) == len(feature_names_after_preprocessing):
            feature_importance = pd.DataFrame({
                'Feature': feature_names_after_preprocessing,
                'Importance': abs(model_coefs)
            }).sort_values(by='Importance', ascending=False)
            
            print("\nFeature Importances:")
            print(feature_importance.head(10))
    
    # 8. Visualize residuals
    y_pred_best = results[best_model_name]['predictions']
    residuals = y_test - y_pred_best
    
    # Calculate residual statistics
    print("\nResidual Statistics:")
    print(f"Mean of Residuals: {np.mean(residuals):.4f}")
    print(f"Standard Deviation of Residuals: {np.std(residuals):.4f}")
    
    # Test for normality of residuals
    from scipy import stats
    stat, p_value = stats.normaltest(residuals)
    print(f"Normality Test (D'Agostino-Pearson): stat={stat:.4f}, p-value={p_value:.4f}")
    if p_value < 0.05:
        print("Residuals are not normally distributed.")
    else:
        print("Residuals appear to be normally distributed.")
    
    return results

# Run the complete workflow
results = regression_workflow(dataset_name='boston', polynomial_degree=2)

# Get the best model
best_model_name = max(results, key=lambda x: results[x]['R²'])
best_model = results[best_model_name]['model']
```

```python
    Parameters:
    -----------
    y_true : array-like
        Actual target values
    y_pred : array-like
        Predicted target values
    X : DataFrame or array-like, optional
        Feature matrix used for predictions
        
    Returns:
    --------
    diagnostics : dict
        Dictionary with diagnostic results
    """
    diagnostics = {}
    
    # Calculate residuals
    residuals = y_true - y_pred
    
    # Basic metrics
    diagnostics['MSE'] = mean_squared_error(y_true, y_pred)
    diagnostics['RMSE'] = np.sqrt(diagnostics['MSE'])
    diagnostics['MAE'] = mean_absolute_error(y_true, y_pred)
    diagnostics['R²'] = r2_score(y_true, y_pred)
    
    # Adjusted R² if X is provided
    if X is not None:
        n = len(y_true)
        p = X.shape[1]
        diagnostics['Adjusted R²'] = 1 - (1 - diagnostics['R²']) * (n - 1) / (n - p - 1)
    
    # Residual statistics
    diagnostics['Mean of Residuals'] = np.mean(residuals)
    diagnostics['Std of Residuals'] = np.std(residuals)
    
    # Durbin-Watson test for autocorrelation
    # Value around 2 indicates no autocorrelation
    from statsmodels.stats.stattools import durbin_watson
    diagnostics['Durbin-Watson'] = durbin_watson(residuals)
    
    # Test for homoscedasticity (Breusch-Pagan test)
    # Null hypothesis: Homoscedasticity is present
    if X is not None:
        from statsmodels.stats.diagnostic import het_breuschpagan
        bp_test = het_breuschpagan(residuals, X)
        diagnostics['Breusch-Pagan p-value'] = bp_test[1]
        diagnostics['Homoscedasticity'] = bp_test[1] > 0.05
    
    # Test for normality of residuals
    from scipy import stats
    _, normality_p_value = stats.normaltest(residuals)
    diagnostics['Normality p-value'] = normality_p_value
    diagnostics['Residuals Normal'] = normality_p_value > 0.05
    
    return diagnostics

# Apply diagnostics to our best model
best_y_pred = results[best_model_name]['predictions']
diagnostics = regression_diagnostics(y_test, best_y_pred, X_test)

print("\nComprehensive Model Diagnostics:")
for key, value in diagnostics.items():
    print(f"{key}: {value:.4f}" if isinstance(value, (int, float)) else f"{key}: {value}")

# Check for outliers in predictions
def detect_prediction_outliers(y_true, y_pred, threshold=3):
    """
    Detect outliers in predictions using standardized residuals.
    
    Parameters:
    -----------
    y_true : array-like
        Actual target values
    y_pred : array-like
        Predicted target values
    threshold : float
        Z-score threshold for outlier detection
        
    Returns:
    --------
    outliers : DataFrame
        DataFrame with outlier information
    """
    # Calculate residuals
    residuals = y_true - y_pred
    
    # Standardize residuals
    std_residuals = (residuals - np.mean(residuals)) / np.std(residuals)
    
    # Identify outliers
    outlier_indices = np.where(abs(std_residuals) > threshold)[0]
    
    if len(outlier_indices) > 0:
        outliers = pd.DataFrame({
            'Index': outlier_indices,
            'Actual': y_true.iloc[outlier_indices] if hasattr(y_true, 'iloc') else y_true[outlier_indices],
            'Predicted': y_pred[outlier_indices],
            'Residual': residuals[outlier_indices],
            'Std Residual': std_residuals[outlier_indices]
        })
        return outliers
    else:
        return pd.DataFrame()

# Detect prediction outliers
outliers = detect_prediction_outliers(y_test, best_y_pred)

if not outliers.empty:
    print(f"\nDetected {len(outliers)} outliers in predictions:")
    print(outliers)
else:
    print("\nNo significant outliers detected in predictions.")
```
