# 10. Time Series: Predicting the Future

## Key Terms and Concepts

**Time Series**: A sequence of data points collected or recorded at successive, typically uniform time intervals. Examples include stock prices, weather data, sales figures, or sensor readings over time.

**Stationarity**: A statistical property where the mean, variance, and autocorrelation structure of a time series remain constant over time. Non-stationary series often require transformation before modeling.

**Seasonality**: Regular, predictable patterns that repeat over fixed periods (daily, weekly, monthly, yearly). For example, ice cream sales peaking in summer months.

**Trend**: The long-term direction or movement in data, showing whether values are generally increasing, decreasing, or remaining stable over time.

**Autocorrelation**: The correlation of a time series with a delayed copy of itself. This measures how much current values depend on previous values.

**Lag Features**: Previous time period values used as input features for prediction. A lag-1 feature uses the previous time step's value to predict the current one.

**Walk-Forward Validation**: A time series-specific cross-validation technique that respects temporal order by training on past data and testing on future data.

**ARIMA (AutoRegressive Integrated Moving Average)**: A classical statistical model that combines autoregression, differencing, and moving averages to model time series data.

**Prophet**: Facebook's robust forecasting procedure designed for business time series with strong seasonal effects and multiple seasons of historical data.

## Time Series Characteristics and Challenges

Time series data presents unique challenges that distinguish it from traditional machine learning problems:

### Temporal Dependencies
Unlike independent observations in typical ML datasets, time series observations are inherently dependent on previous values. This temporal structure must be preserved during modeling and validation.

### Non-Stationarity
Many real-world time series exhibit changing statistical properties over time. Stock prices may have increasing volatility, sales data may show growing trends, or sensor readings may drift due to equipment aging.

### Seasonal Patterns
Business data often contains multiple seasonal patterns - daily cycles in website traffic, weekly patterns in retail sales, monthly variations in energy consumption, and yearly trends in tourism.

### Irregular Observations
Missing data points, outliers, and irregular sampling intervals are common in time series, requiring specialized preprocessing techniques.

## Modern Time Series Forecasting Models

### Statistical Approaches

**ARIMA Models**: Combine autoregressive and moving average components with differencing to handle non-stationary data. Suitable for univariate series with clear patterns.

**Seasonal ARIMA (SARIMA)**: Extension of ARIMA that explicitly models seasonal patterns through additional seasonal autoregressive and moving average terms.

**Exponential Smoothing (ETS)**: Family of models that use weighted averages of past observations, with weights decreasing exponentially for older observations.

### Machine Learning Approaches

**Prophet**: Robust to missing data and trend changes, designed for business forecasting with interpretable parameters for trend, seasonality, and holidays.

**LightGBM/XGBoost for Time Series**: Gradient boosting models adapted for time series through careful feature engineering and validation strategies.

**LSTM/GRU Networks**: Deep learning models specifically designed to handle sequential data and long-term dependencies.

### Hybrid Approaches

**Neural Prophet**: Combines neural network flexibility with Prophet's interpretability, handling multiple seasonality patterns and external regressors.

**AutoML Solutions**: Automated model selection and hyperparameter tuning specifically designed for time series forecasting.

### Walk-Forward Validation
```python
def walk_forward_validation(data, model, window_size, forecast_horizon):
    predictions = []
    actuals = []
    
    for i in range(window_size, len(data) - forecast_horizon + 1):
        # Training window
        train_data = data[i-window_size:i]
        
        # Fit model
        model.fit(train_data)
        
        # Forecast
        forecast = model.predict(forecast_horizon)
        predictions.extend(forecast)
        
        # Actual values
        actual = data[i:i+forecast_horizon]
        actuals.extend(actual)
    
    return predictions, actuals
```

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from datetime import datetime, timedelta
import warnings
warnings.filterwarnings('ignore')

# Statistical and ML libraries
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.seasonal import seasonal_decompose
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
from prophet import Prophet
import lightgbm as lgb
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.model_selection import TimeSeriesSplit
from sklearn.preprocessing import StandardScaler

# Set random seed for reproducibility
np.random.seed(42)

class TimeSeriesAnalyzer:
    def __init__(self):
        self.models = {}
        self.predictions = {}
        self.metrics = {}
    
    def generate_sample_data(self, n_days=1000, start_date='2021-01-01'):
        """Generate realistic time series data with trend, seasonality, and noise"""
        dates = pd.date_range(start=start_date, periods=n_days, freq='D')
        
        # Base trend
        trend = np.linspace(100, 150, n_days)
        
        # Seasonal patterns
        yearly_season = 20 * np.sin(2 * np.pi * np.arange(n_days) / 365.25)
        weekly_season = 10 * np.sin(2 * np.pi * np.arange(n_days) / 7)
        
        # Random noise
        noise = np.random.normal(0, 5, n_days)
        
        # Weekend effect
        weekend_effect = np.where(pd.to_datetime(dates).dayofweek >= 5, -15, 0)
        
        # Combine components
        values = trend + yearly_season + weekly_season + weekend_effect + noise
        
        # Add some outliers
        outlier_indices = np.random.choice(n_days, size=int(n_days * 0.02), replace=False)
        values[outlier_indices] += np.random.normal(0, 30, len(outlier_indices))
        
        df = pd.DataFrame({
            'date': dates,
            'value': values
        })
        df.set_index('date', inplace=True)
        
        return df
    
    def create_features(self, df, target_col='value'):
        """Create comprehensive feature set for time series modeling"""
        df = df.copy()
        
        # Lag features
        for lag in [1, 2, 3, 7, 14, 30]:
            df[f'lag_{lag}'] = df[target_col].shift(lag)
        
        # Rolling statistics
        for window in [7, 14, 30]:
            df[f'rolling_mean_{window}'] = df[target_col].rolling(window=window).mean()
            df[f'rolling_std_{window}'] = df[target_col].rolling(window=window).std()
            df[f'rolling_min_{window}'] = df[target_col].rolling(window=window).min()
            df[f'rolling_max_{window}'] = df[target_col].rolling(window=window).max()
        
        # Expanding statistics
        df['expanding_mean'] = df[target_col].expanding().mean()
        df['expanding_std'] = df[target_col].expanding().std()
        
        # Temporal features
        df['year'] = df.index.year
        df['month'] = df.index.month
        df['day'] = df.index.day
        df['dayofweek'] = df.index.dayofweek
        df['dayofyear'] = df.index.dayofyear
        df['quarter'] = df.index.quarter
        df['is_weekend'] = (df.index.dayofweek >= 5).astype(int)
        df['is_month_start'] = df.index.is_month_start.astype(int)
        df['is_month_end'] = df.index.is_month_end.astype(int)
        
        # Cyclical features
        df['month_sin'] = np.sin(2 * np.pi * df['month'] / 12)
        df['month_cos'] = np.cos(2 * np.pi * df['month'] / 12)
        df['dayofweek_sin'] = np.sin(2 * np.pi * df['dayofweek'] / 7)
        df['dayofweek_cos'] = np.cos(2 * np.pi * df['dayofweek'] / 7)
        df['dayofyear_sin'] = np.sin(2 * np.pi * df['dayofyear'] / 365.25)
        df['dayofyear_cos'] = np.cos(2 * np.pi * df['dayofyear'] / 365.25)
        
        # Difference features
        df['diff_1'] = df[target_col].diff(1)
        df['diff_7'] = df[target_col].diff(7)
        df['diff_30'] = df[target_col].diff(30)
        
        # Percentage change
        df['pct_change_1'] = df[target_col].pct_change(1)
        df['pct_change_7'] = df[target_col].pct_change(7)
        
        return df
    
    def split_time_series(self, df, test_size=0.2, val_size=0.1):
        """Split time series data maintaining temporal order"""
        n = len(df)
        
        train_end = int(n * (1 - test_size - val_size))
        val_end = int(n * (1 - test_size))
        
        train_data = df.iloc[:train_end]
        val_data = df.iloc[train_end:val_end]
        test_data = df.iloc[val_end:]
        
        return train_data, val_data, test_data
    
    def train_arima_model(self, train_data, target_col='value', order=(2,1,2)):
        """Train ARIMA model"""
        model = ARIMA(train_data[target_col].dropna(), order=order)
        fitted_model = model.fit()
        self.models['ARIMA'] = fitted_model
        return fitted_model
    
    def train_prophet_model(self, train_data, target_col='value'):
        """Train Prophet model"""
        # Prepare data for Prophet
        prophet_data = train_data.reset_index()
        prophet_data = prophet_data.rename(columns={'date': 'ds', target_col: 'y'})
        
        # Initialize and fit Prophet model
        model = Prophet(
            daily_seasonality=True,
            weekly_seasonality=True,
            yearly_seasonality=True,
            seasonality_mode='additive',
            changepoint_prior_scale=0.05
        )
        
        model.fit(prophet_data)
        self.models['Prophet'] = model
        return model
    
    def train_lightgbm_model(self, train_data, val_data, target_col='value'):
        """Train LightGBM model for time series"""
        feature_cols = [col for col in train_data.columns if col != target_col]
        
        # Remove rows with NaN values
        train_clean = train_data.dropna()
        val_clean = val_data.dropna()
        
        X_train = train_clean[feature_cols]
        y_train = train_clean[target_col]
        X_val = val_clean[feature_cols]
        y_val = val_clean[target_col]
        
        # LightGBM parameters
        params = {
            'objective': 'regression',
            'metric': 'rmse',
            'boosting_type': 'gbdt',
            'num_leaves': 31,
            'learning_rate': 0.05,
            'feature_fraction': 0.9,
            'bagging_fraction': 0.8,
            'bagging_freq': 5,
            'verbose': -1,
            'random_state': 42
        }
        
        # Create datasets
        train_dataset = lgb.Dataset(X_train, label=y_train)
        val_dataset = lgb.Dataset(X_val, label=y_val, reference=train_dataset)
        
        # Train model
        model = lgb.train(
            params,
            train_dataset,
            valid_sets=[val_dataset],
            num_boost_round=1000,
            callbacks=[lgb.early_stopping(100), lgb.log_evaluation(0)]
        )
        
        self.models['LightGBM'] = model
        return model
    
    def make_predictions(self, test_data, target_col='value', forecast_periods=30):
        """Make predictions with all trained models"""
        predictions = {}
        
        # ARIMA predictions
        if 'ARIMA' in self.models:
            arima_pred = self.models['ARIMA'].forecast(steps=len(test_data))
            predictions['ARIMA'] = arima_pred
        
        # Prophet predictions
        if 'Prophet' in self.models:
            future_dates = pd.DataFrame({
                'ds': test_data.index
            })
            prophet_pred = self.models['Prophet'].predict(future_dates)
            predictions['Prophet'] = prophet_pred['yhat'].values
        
        # LightGBM predictions
        if 'LightGBM' in self.models:
            feature_cols = [col for col in test_data.columns if col != target_col]
            test_clean = test_data.dropna()
            X_test = test_clean[feature_cols]
            lgb_pred = self.models['LightGBM'].predict(X_test)
            
            # Align predictions with test data index
            predictions['LightGBM'] = pd.Series(lgb_pred, index=test_clean.index)
        
        self.predictions = predictions
        return predictions
    
    def evaluate_models(self, test_data, target_col='value'):
        """Evaluate model performance"""
        results = {}
        
        for model_name, pred in self.predictions.items():
            if model_name == 'LightGBM':
                # Handle LightGBM predictions (may have different index)
                common_idx = test_data.index.intersection(pred.index)
                y_true = test_data.loc[common_idx, target_col]
                y_pred = pred.loc[common_idx]
            else:
                y_true = test_data[target_col].values
                y_pred = pred
            
            # Calculate metrics
            mae = mean_absolute_error(y_true, y_pred)
            rmse = np.sqrt(mean_squared_error(y_true, y_pred))
            mape = np.mean(np.abs((y_true - y_pred) / y_true)) * 100
            
            results[model_name] = {
                'MAE': mae,
                'RMSE': rmse,
                'MAPE': mape
            }
        
        self.metrics = results
        return results
    
    def time_series_cv(self, data, target_col='value', n_splits=5, test_size=30):
        """Perform time series cross-validation"""
        tscv = TimeSeriesSplit(n_splits=n_splits, test_size=test_size)
        cv_scores = {'LightGBM': []}
        
        X = data.drop(columns=[target_col]).fillna(method='ffill').fillna(method='bfill')
        y = data[target_col]
        
        for fold, (train_idx, test_idx) in enumerate(tscv.split(X)):
            print(f"Processing fold {fold + 1}/{n_splits}")
            
            X_train, X_test = X.iloc[train_idx], X.iloc[test_idx]
            y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]
            
            # Train LightGBM
            params = {
                'objective': 'regression',
                'metric': 'rmse',
                'boosting_type': 'gbdt',
                'num_leaves': 31,
                'learning_rate': 0.1,
                'verbose': -1,
                'random_state': 42
            }
            
            train_dataset = lgb.Dataset(X_train, label=y_train)
            model = lgb.train(params, train_dataset, num_boost_round=100, verbose_eval=False)
            
            pred = model.predict(X_test)
            rmse = np.sqrt(mean_squared_error(y_test, pred))
            cv_scores['LightGBM'].append(rmse)
        
        return cv_scores
```

```python
from sklearn.model_selection import ParameterGrid
import optuna

class TimeSeriesOptimizer:
    def __init__(self):
        self.best_params = {}
        self.best_score = float('inf')
    
    def optimize_prophet(self, data, n_trials=50):
        """Optimize Prophet hyperparameters using Optuna"""
        def objective(trial):
            params = {
                'changepoint_prior_scale': trial.suggest_float('changepoint_prior_scale', 0.001, 0.5, log=True),
                'seasonality_prior_scale': trial.suggest_float('seasonality_prior_scale', 0.01, 10, log=True),
                'holidays_prior_scale': trial.suggest_float('holidays_prior_scale', 0.01, 10, log=True),
                'seasonality_mode': trial.suggest_categorical('seasonality_mode', ['additive', 'multiplicative']),
            }
            
            # Time series cross-validation
            tscv = TimeSeriesSplit(n_splits=3, test_size=30)
            scores = []
            
            for train_idx, val_idx in tscv.split(data):
                train_data = data.iloc[train_idx].reset_index()
                val_data = data.iloc[val_idx].reset_index()
                
                train_prophet = train_data.rename(columns={'date': 'ds', 'value': 'y'})
                
                model = Prophet(**params)
                model.fit(train_prophet)
                
                future = val_data[['date']].rename(columns={'date': 'ds'})
                forecast = model.predict(future)
                
                score = mean_squared_error(val_data['value'], forecast['yhat'])
                scores.append(score)
            
            return np.mean(scores)
        
        study = optuna.create_study(direction='minimize')
        study.optimize(objective, n_trials=n_trials)
        
        return study.best_params
    
    def optimize_lightgbm(self, X_train, y_train, X_val, y_val):
```
