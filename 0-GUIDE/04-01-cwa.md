# 01. Introduction to AI: From Theory to Practice

## Key Terms and Concepts

**Machine Learning (ML)**: A subset of artificial intelligence that enables computers to learn and make decisions from data without being explicitly programmed for each specific task.

**Optimization Problem**: A mathematical formulation that seeks to find the best solution (minimum or maximum) of an objective function, subject to certain constraints.

**Gradient Descent**: An iterative optimization algorithm used to minimize a function by moving in the direction of steepest descent as defined by the negative of the gradient.

**Objective Function**: The function that needs to be optimized (minimized or maximized) in a machine learning context, often representing the error or loss between predicted and actual values.

**Feature Space**: The multi-dimensional space where each dimension represents a feature or attribute of the data used for machine learning.

## Introduction to Machine Learning Tasks

Machine learning encompasses three primary categories of tasks:

**Supervised Learning** involves training models on labeled data where both input features and target outputs are known. Common applications include regression (predicting continuous values) and classification (predicting discrete categories).

**Unsupervised Learning** discovers hidden patterns in data without labeled examples. Typical tasks include clustering, dimensionality reduction, and anomaly detection.

**Reinforcement Learning** trains agents to make sequential decisions by learning from rewards and penalties in an environment, commonly used in game playing, robotics, and autonomous systems.

## Theoretical Foundation of Optimization Problems

At its core, machine learning is fundamentally an optimization problem. The goal is to find model parameters that minimize a loss function, which measures the difference between predicted and actual outcomes.

Mathematically, we can express this as:

```
minimize f(θ) = L(y_predicted, y_actual)
```

Where θ represents the model parameters, and L is the loss function. The optimization landscape can be complex, featuring multiple local minima, saddle points, and regions of varying curvature.

## Practical Implementation with NumPy and SciPy

Let's explore optimization through practical examples using modern Python libraries:

```python
import numpy as np
from scipy import optimize
import matplotlib.pyplot as plt
from typing import Tuple, Callable
import warnings
warnings.filterwarnings('ignore')

# Define a complex optimization problem: Rosenbrock function
def rosenbrock_function(x: np.ndarray) -> float:
    """
    The Rosenbrock function - a classic optimization test problem
    Global minimum at (1, 1) with value 0
    """
    return sum(100.0 * (x[1:] - x[:-1]**2.0)**2.0 + (1 - x[:-1])**2.0)

def rosenbrock_gradient(x: np.ndarray) -> np.ndarray:
    """Analytical gradient of the Rosenbrock function"""
    grad = np.zeros_like(x)
    grad[0] = -400 * x[0] * (x[1] - x[0]**2) - 2 * (1 - x[0])
    grad[1] = 200 * (x[1] - x[0]**2)
    return grad

# Solve using SciPy's advanced optimization methods
initial_guess = np.array([-1.0, 2.0])

# Method 1: BFGS (Quasi-Newton method)
result_bfgs = optimize.minimize(
    rosenbrock_function, 
    initial_guess, 
    method='BFGS',
    jac=rosenbrock_gradient,
    options={'disp': True, 'maxiter': 1000}
)

print(f"BFGS Result: {result_bfgs.x}, Function value: {result_bfgs.fun}")

# Method 2: Trust Region method (more robust for complex landscapes)
result_trust = optimize.minimize(
    rosenbrock_function,
    initial_guess,
    method='trust-ncg',
    jac=rosenbrock_gradient,
    hess=optimize.BFGS(),
    options={'disp': True}
)

print(f"Trust Region Result: {result_trust.x}, Function value: {result_trust.fun}")

# Advanced: Multi-start optimization for global solutions
def global_optimization_example():
    """Demonstrate global optimization techniques"""
    from scipy.optimize import differential_evolution
    
    bounds = [(-3, 3), (-3, 3)]
    result_global = differential_evolution(
        rosenbrock_function, 
        bounds, 
        seed=42,
        atol=1e-8,
        tol=1e-8
    )
    
    return result_global

global_result = global_optimization_example()
print(f"Global Optimization Result: {global_result.x}, Function value: {global_result.fun}")
```

## Optimization in Machine Learning Context

In machine learning, optimization problems typically involve minimizing a loss function. Here's a comprehensive example demonstrating how optimization applies to prediction tasks:

```python
import numpy as np
from sklearn.datasets import make_regression
from sklearn.preprocessing import StandardScaler
from typing import Tuple

class LinearRegressionOptimizer:
    """
    Custom implementation of linear regression using various optimization techniques
    """
    
    def __init__(self, learning_rate: float = 0.01, max_iterations: int = 1000):
        self.learning_rate = learning_rate
        self.max_iterations = max_iterations
        self.weights = None
        self.bias = None
        self.cost_history = []
        
    def _add_bias_term(self, X: np.ndarray) -> np.ndarray:
        """Add bias term to feature matrix"""
        return np.column_stack([np.ones(X.shape[0]), X])
    
    def _compute_cost(self, X: np.ndarray, y: np.ndarray, theta: np.ndarray) -> float:
        """Compute mean squared error cost function"""
        m = X.shape[0]
        predictions = X @ theta
        cost = (1 / (2 * m)) * np.sum((predictions - y) ** 2)
        return cost
    
    def _compute_gradient(self, X: np.ndarray, y: np.ndarray, theta: np.ndarray) -> np.ndarray:
        """Compute gradient of cost function"""
        m = X.shape[0]
        predictions = X @ theta
        gradient = (1 / m) * X.T @ (predictions - y)
        return gradient
    
    def fit_gradient_descent(self, X: np.ndarray, y: np.ndarray) -> 'LinearRegressionOptimizer':
        """Fit model using standard gradient descent"""
        X_with_bias = self._add_bias_term(X)
        m, n = X_with_bias.shape
        
        # Initialize parameters
        theta = np.random.normal(0, 0.01, n)
        
        for i in range(self.max_iterations):
            cost = self._compute_cost(X_with_bias, y, theta)
            self.cost_history.append(cost)
            
            gradient = self._compute_gradient(X_with_bias, y, theta)
            theta -= self.learning_rate * gradient
            
            # Early stopping condition
            if i > 0 and abs(self.cost_history[-2] - self.cost_history[-1]) < 1e-8:
                print(f"Converged at iteration {i}")
                break
        
        self.bias = theta[0]
        self.weights = theta[1:]
        return self
    
    def fit_stochastic_gradient_descent(self, X: np.ndarray, y: np.ndarray, batch_size: int = 32) -> 'LinearRegressionOptimizer':
        """Fit model using stochastic gradient descent with mini-batches"""
        X_with_bias = self._add_bias_term(X)
        m, n = X_with_bias.shape
        
        theta = np.random.normal(0, 0.01, n)
        
        for epoch in range(self.max_iterations):
            # Shuffle data
            indices = np.random.permutation(m)
            X_shuffled = X_with_bias[indices]
            y_shuffled = y[indices]
            
            epoch_cost = 0
            num_batches = 0
            
            # Process mini-batches
            for start_idx in range(0, m, batch_size):
                end_idx = min(start_idx + batch_size, m)
                X_batch = X_shuffled[start_idx:end_idx]
                y_batch = y_shuffled[start_idx:end_idx]
                
                batch_cost = self._compute_cost(X_batch, y_batch, theta)
                epoch_cost += batch_cost
                num_batches += 1
                
                gradient = self._compute_gradient(X_batch, y_batch, theta)
                theta -= self.learning_rate * gradient
            
            avg_cost = epoch_cost / num_batches
            self.cost_history.append(avg_cost)
            
            if epoch > 0 and abs(self.cost_history[-2] - self.cost_history[-1]) < 1e-8:
                print(f"SGD converged at epoch {epoch}")
                break
        
        self.bias = theta[0]
        self.weights = theta[1:]
        return self
    
    def predict(self, X: np.ndarray) -> np.ndarray:
        """Make predictions on new data"""
        if self.weights is None:
            raise ValueError("Model must be fitted before making predictions")
        return X @ self.weights + self.bias

# Advanced optimization using Adam optimizer
class AdamOptimizer:
    """
    Implementation of Adam optimization algorithm
    """
    
    def __init__(self, learning_rate: float = 0.001, beta1: float = 0.9, 
                 beta2: float = 0.999, epsilon: float = 1e-8):
        self.learning_rate = learning_rate
        self.beta1 = beta1
        self.beta2 = beta2
        self.epsilon = epsilon
        self.m = None  # First moment estimate
        self.v = None  # Second moment estimate
        self.t = 0     # Time step
    
    def update(self, params: np.ndarray, gradients: np.ndarray) -> np.ndarray:
        """Update parameters using Adam optimization"""
        if self.m is None:
            self.m = np.zeros_like(params)
            self.v = np.zeros_like(params)
        
        self.t += 1
        
        # Update biased first moment estimate
        self.m = self.beta1 * self.m + (1 - self.beta1) * gradients
        
        # Update biased second raw moment estimate
        self.v = self.beta2 * self.v + (1 - self.beta2) * (gradients ** 2)
        
        # Compute bias-corrected first moment estimate
        m_corrected = self.m / (1 - self.beta1 ** self.t)
        
        # Compute bias-corrected second raw moment estimate
        v_corrected = self.v / (1 - self.beta2 ** self.t)
        
        # Update parameters
        params -= self.learning_rate * m_corrected / (np.sqrt(v_corrected) + self.epsilon)
        
        return params

# Demonstrate optimization on a real dataset
def comprehensive_optimization_example():
    """Complete example showing different optimization approaches"""
    
    # Generate synthetic dataset
    X, y = make_regression(n_samples=1000, n_features=5, noise=10, random_state=42)
    
    # Standardize features
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)
    
    # Split data
    train_size = int(0.8 * len(X_scaled))
    X_train, X_test = X_scaled[:train_size], X_scaled[train_size:]
    y_train, y_test = y[:train_size], y[train_size:]
    
    # Method 1: Standard Gradient Descent
    print("Training with Standard Gradient Descent...")
    model_gd = LinearRegressionOptimizer(learning_rate=0.01, max_iterations=1000)
    model_gd.fit_gradient_descent(X_train, y_train)
    
    # Method 2: Stochastic Gradient Descent
    print("Training with Stochastic Gradient Descent...")
    model_sgd = LinearRegressionOptimizer(learning_rate=0.01, max_iterations=100)
    model_sgd.fit_stochastic_gradient_descent(X_train, y_train, batch_size=32)
    
    # Evaluate models
    pred_gd = model_gd.predict(X_test)
    pred_sgd = model_sgd.predict(X_test)
    
    mse_gd = np.mean((pred_gd - y_test) ** 2)
    mse_sgd = np.mean((pred_sgd - y_test) ** 2)
    
    print(f"Standard GD MSE: {mse_gd:.4f}")
    print(f"Stochastic GD MSE: {mse_sgd:.4f}")
    
    return model_gd, model_sgd
```

## Advanced Gradient Descent Implementation

Understanding the mathematical foundations and implementing modern variants of gradient descent:

```python
import numpy as np
from typing import Dict, List, Optional
from dataclasses import dataclass

@dataclass
class OptimizationResult:
    """Container for optimization results"""
    final_params: np.ndarray
    cost_history: List[float]
    gradient_norms: List[float]
    iterations: int
    converged: bool

class AdvancedGradientDescent:
    """
    Advanced gradient descent implementation with multiple variants
    """
    
    def __init__(self, learning_rate: float = 0.01, max_iterations: int = 1000,
                 tolerance: float = 1e-6, momentum: float = 0.9):
        self.learning_rate = learning_rate
        self.max_iterations = max_iterations
        self.tolerance = tolerance
        self.momentum = momentum
    
    def optimize_with_momentum(self, 
                             objective_func: Callable,
                             gradient_func: Callable,
                             initial_params: np.ndarray,
                             args: Tuple = ()) -> OptimizationResult:
        """
        Gradient descent with momentum
        """
        params = initial_params.copy()
        velocity = np.zeros_like(params)
        cost_history = []
        gradient_norms = []
        
        for i in range(self.max_iterations):
            cost = objective_func(params, *args)
            gradient = gradient_func(params, *args)
            
            cost_history.append(cost)
            gradient_norms.append(np.linalg.norm(gradient))
            
            # Momentum update
            velocity = self.momentum * velocity - self.learning_rate * gradient
            params += velocity
            
            # Check convergence
            if np.linalg.norm(gradient) < self.tolerance:
                return OptimizationResult(
                    final_params=params,
                    cost_history=cost_history,
                    gradient_norms=gradient_norms,
                    iterations=i + 1,
                    converged=True
                )
        
        return OptimizationResult(
            final_params=params,
            cost_history=cost_history,
            gradient_norms=gradient_norms,
            iterations=self.max_iterations,
            converged=False
        )
    
    def optimize_with_adaptive_learning_rate(self,
                                           objective_func: Callable,
                                           gradient_func: Callable,
                                           initial_params: np.ndarray,
                                           args: Tuple = ()) -> OptimizationResult:
        """
        Gradient descent with adaptive learning rate (AdaGrad-like)
        """
        params = initial_params.copy()
        accumulated_gradients = np.zeros_like(params)
        cost_history = []
        gradient_norms = []
        epsilon = 1e-8
        
        for i in range(self.max_iterations):
            cost = objective_func(params, *args)
            gradient = gradient_func(params, *args)
            
            cost_history.append(cost)
            gradient_norms.append(np.linalg.norm(gradient))
            
            # Accumulate squared gradients
            accumulated_gradients += gradient ** 2
            
            # Adaptive learning rate update
            adaptive_lr = self.learning_rate / (np.sqrt(accumulated_gradients) + epsilon)
            params -= adaptive_lr * gradient
            
            # Check convergence
            if np.linalg.norm(gradient) < self.tolerance:
                return OptimizationResult(
                    final_params=params,
                    cost_history=cost_history,
                    gradient_norms=gradient_norms,
                    iterations=i + 1,
                    converged=True
                )
        
        return OptimizationResult(
            final_params=params,
            cost_history=cost_history,
            gradient_norms=gradient_norms,
            iterations=self.max_iterations,
            converged=False
        )

# Real-world optimization example: Logistic Regression from scratch
class LogisticRegressionOptimizer:
    """
    Logistic regression implementation using gradient descent
    """
    
    def __init__(self, learning_rate: float = 0.01, max_iterations: int = 1000,
                 regularization_strength: float = 0.01):
        self.learning_rate = learning_rate
        self.max_iterations = max_iterations
        self.regularization_strength = regularization_strength
        self.weights = None
        self.bias = None
        
    def _sigmoid(self, z: np.ndarray) -> np.ndarray:
        """Sigmoid activation function with numerical stability"""
        z = np.clip(z, -500, 500)  # Prevent overflow
        return 1 / (1 + np.exp(-z))
    
    def _cost_function(self, X: np.ndarray, y: np.ndarray, 
                      weights: np.ndarray, bias: float) -> float:
        """Logistic regression cost function with L2 regularization"""
        m = X.shape[0]
        z = X @ weights + bias
        predictions = self._sigmoid(z)
        
        # Prevent log(0) by clipping
        predictions = np.clip(predictions, 1e-15, 1 - 1e-15)
        
        # Cross-entropy loss
        cost = -(1/m) * np.sum(y * np.log(predictions) + (1 - y) * np.log(1 - predictions))
        
        # L2 regularization
        regularization_cost = self.regularization_strength * np.sum(weights ** 2)
        
        return cost + regularization_cost
    
    def _compute_gradients(self, X: np.ndarray, y: np.ndarray,
                          weights: np.ndarray, bias: float) -> Tuple[np.ndarray, float]:
        """Compute gradients for weights and bias"""
        m = X.shape[0]
        z = X @ weights + bias
        predictions = self._sigmoid(z)
        
        # Gradients
        dw = (1/m) * X.T @ (predictions - y) + 2 * self.regularization_strength * weights
        db = (1/m) * np.sum(predictions - y)
        
        return dw, db
    
    def fit(self, X: np.ndarray, y: np.ndarray) -> 'LogisticRegressionOptimizer':
        """Fit logistic regression model using gradient descent"""
        m, n = X.shape
        
        # Initialize parameters
        self.weights = np.random.normal(0, 0.01, n)
        self.bias = 0.0
        
        cost_history = []
        
        for i in range(self.max_iterations):
            # Compute cost
            cost = self._cost_function(X, y, self.weights, self.bias)
            cost_history.append(cost)
            
            # Compute gradients
            dw, db = self._compute_gradients(X, y, self.weights, self.bias)
            
            # Update parameters
            self.weights -= self.learning_rate * dw
            self.bias -= self.learning_rate * db
            
            # Check for convergence
            if i > 0 and abs(cost_history[-2] - cost_history[-1]) < 1e-8:
                print(f"Logistic regression converged at iteration {i}")
                break
        
        return self
    
    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        """Predict class probabilities"""
        if self.weights is None:
            raise ValueError("Model must be fitted before making predictions")
        
        z = X @ self.weights + self.bias
        return self._sigmoid(z)
    
    def predict(self, X: np.ndarray, threshold: float = 0.5) -> np.ndarray:
        """Make binary predictions"""
        probabilities = self.predict_proba(X)
        return (probabilities >= threshold).astype(int)

def demonstrate_advanced_optimization():

    # Problem 1: Quadratic function optimization
    def quadratic_objective(params, A, b):

    def quadratic_gradient(params, A, b):
        return A @ params - b
    
    # Create a well-conditioned quadratic problem
    n = 10
    A = np.random.randn(n, n)
    A = A.T @ A + np.eye(n)  # Make positive definite
```
