## Key Terms

**Decision Tree**: A hierarchical model that uses a tree-like structure of decisions to predict target values by recursively splitting the dataset based on feature values, creating interpretable rules that mimic human decision-making processes while providing both classification and regression capabilities.

**Node**: A decision point in the tree structure where the algorithm evaluates a specific feature and creates a binary or multi-way split based on threshold values, with each node representing a test condition that determines the path data flows through the tree.

**Edge**: The connection between nodes that represents the outcome of a decision test, directing data samples to child nodes based on whether they satisfy the splitting condition, effectively creating the pathways through the decision-making process.

**Leaf (Terminal Node)**: The final node in a branch that contains the prediction outcome, storing either class labels for classification tasks or numerical values for regression tasks, representing the algorithm's final decision for samples reaching that node.

**Information Gain**: A measure used to evaluate the quality of splits by quantifying how much uncertainty (entropy) is reduced when dividing the dataset at a particular feature and threshold, guiding the tree construction process toward optimal decision boundaries.

**Gini Impurity**: An alternative splitting criterion that measures the probability of incorrectly classifying a randomly chosen element, with lower values indicating purer nodes and better splits for classification tasks.

**Pruning**: A regularization technique that removes branches from the tree to prevent overfitting by eliminating nodes that provide little improvement in prediction accuracy, balancing model complexity with generalization performance.

**Feature Importance**: A quantitative measure of how much each input feature contributes to decreasing node impurity across all splits in the tree, providing insights into which variables are most influential for making predictions.

## Theoretical Foundation of Decision Trees

Decision trees represent one of the most intuitive and interpretable machine learning algorithms, mimicking human decision-making processes through a series of hierarchical questions. The algorithm constructs a tree structure by recursively selecting the best features and thresholds to split the data, optimizing for maximum information gain or minimum impurity.

The mathematical foundation involves entropy and information theory, where the algorithm seeks to minimize uncertainty at each split. For classification, the goal is to create pure nodes containing samples from a single class, while regression trees aim to minimize variance within leaf nodes. The recursive partitioning process continues until stopping criteria are met, such as maximum depth, minimum samples per leaf, or minimum improvement threshold.

def performance_monitor(func):
    """Decorator to monitor function performance"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        start_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        result = func(*args, **kwargs)
        
        end_time = time.time()
        end_memory = psutil.Process().memory_info().rss / 1024 / 1024
        
        logger.info(f"{func.__name__} - Time: {end_time - start_time:.4f}s, "
                   f"Memory: {end_memory - start_memory:.2f}MB")
        return result
    return wrapper

class AdvancedDecisionTreeAnalyzer:

    @performance_monitor
    def analyze_tree_structure(self, tree_model: Union[DecisionTreeClassifier, DecisionTreeRegressor],
                             X: np.ndarray, y: np.ndarray,
                             feature_names: List[str] = None) -> TreeAnalysisResults:
        """Comprehensive analysis of decision tree structure"""
        
        if feature_names:
            self.feature_names = feature_names
        else:
            self.feature_names = [f'feature_{i}' for i in range(X.shape[1])]
        
        tree = tree_model.tree_
        
        # Basic tree metrics
        tree_depth = tree.max_depth
        n_nodes = tree.node_count
        n_leaves = tree.n_leaves
        
        # Feature importance
        feature_importance = tree_model.feature_importances_
        
        # Tree rules in text format
        tree_rules = export_text(tree_model, feature_names=self.feature_names)
        
        # Analyze tree paths
        prediction_paths = self._extract_prediction_paths(tree_model, X)
        
        # Node statistics
        node_samples = [tree.n_node_samples[i] for i in range(n_nodes)]
        node_impurity = [tree.impurity[i] for i in range(n_nodes)]
        
        # Performance metrics
        y_pred_train = tree_model.predict(X)
        if hasattr(tree_model, 'predict_proba'):  # Classification
            training_accuracy = accuracy_score(y, y_pred_train)
            test_accuracy = training_accuracy  # Will be updated with actual test data
        else:  # Regression
            training_accuracy = r2_score(y, y_pred_train)
            test_accuracy = training_accuracy
        
        # Cross-validation
        cv_scores = cross_val_score(tree_model, X, y, cv=5)
        
        return TreeAnalysisResults(
            tree_depth=tree_depth,
            n_nodes=n_nodes,
            n_leaves=n_leaves,
            feature_importance=feature_importance,
            tree_rules=tree_rules,
            prediction_paths=prediction_paths,
            node_samples=node_samples,
            node_impurity=node_impurity,
            training_accuracy=training_accuracy,
            test_accuracy=test_accuracy,
            cross_val_scores=cv_scores
        )
    
    def _extract_prediction_paths(self, tree_model: Union[DecisionTreeClassifier, DecisionTreeRegressor],
                                X: np.ndarray) -> List[List[int]]:
        """Extract prediction paths through the tree for sample data"""
        
        decision_path = tree_model.decision_path(X)
        paths = []
        
        for sample_id in range(min(10, X.shape[0])):  # Analyze first 10 samples
            path = decision_path[sample_id].indices.tolist()
            paths.append(path)
        
        return paths
    
    @performance_monitor
    def compare_tree_algorithms(self, X: np.ndarray, y: np.ndarray,
                              task_type: str = 'classification') -> TreeComparisonResults:
        """Compare different tree-based algorithms"""
        
        if task_type == 'classification':
            models = {
                'decision_tree': DecisionTreeClassifier(random_state=self.random_state),
                'random_forest': RandomForestClassifier(n_estimators=100, random_state=self.random_state),
                'extra_trees': ExtraTreesClassifier(n_estimators=100, random_state=self.random_state),
                'gradient_boosting': GradientBoostingClassifier(random_state=self.random_state)
            }
            scoring_metric = accuracy_score
        else:
            models = {
                'decision_tree': DecisionTreeRegressor(random_state=self.random_state),
                'random_forest': RandomForestRegressor(n_estimators=100, random_state=self.random_state),
                'extra_trees': ExtraTreesRegressor(n_estimators=100, random_state=self.random_state),
                'gradient_boosting': GradientBoostingRegressor(random_state=self.random_state)
            }
            scoring_metric = r2_score
        
        # Split data
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=0.2, random_state=self.random_state
        )
        
        model_performance = {}
        feature_importance_comparison = {}
        complexity_metrics = {}
        training_times = {}
        prediction_times = {}
        
        for name, model in models.items():
            logger.info(f"Evaluating {name}")
            
            # Training
            start_time = time.time()
            model.fit(X_train, y_train)
            training_times[name] = time.time() - start_time
            
            # Prediction
            start_time = time.time()
            y_pred = model.predict(X_test)
            prediction_times[name] = time.time() - start_time
            
            # Performance
            if task_type == 'classification':
                train_score = accuracy_score(y_train, model.predict(X_train))
                test_score = accuracy_score(y_test, y_pred)
            else:
                train_score = r2_score(y_train, model.predict(X_train))
                test_score = r2_score(y_test, y_pred)
            
            model_performance[name] = {
                'train_score': train_score,
                'test_score': test_score,
                'cv_score': np.mean(cross_val_score(model, X_train, y_train, cv=5))
            }
            
            # Feature importance
            feature_importance_comparison[name] = model.feature_importances_
            
            # Complexity metrics
            if hasattr(model, 'tree_'):  # Single tree
                complexity_metrics[name] = {
                    'depth': model.tree_.max_depth,
                    'nodes': model.tree_.node_count,
                    'leaves': model.tree_.n_leaves
                }
            elif hasattr(model, 'estimators_'):  # Ensemble
                depths = [est.tree_.max_depth for est in model.estimators_]
                nodes = [est.tree_.node_count for est in model.estimators_]
                complexity_metrics[name] = {
                    'avg_depth': np.mean(depths),
                    'avg_nodes': np.mean(nodes),
                    'n_estimators': len(model.estimators_)
                }
            
            # Store model for later use
            self.models[name] = model
        
        return TreeComparisonResults(
            model_performance=model_performance,
            feature_importance_comparison=feature_importance_comparison,
            complexity_metrics=complexity_metrics,
            training_times=training_times,
            prediction_times=prediction_times
        )
    
    @performance_monitor
    def optimize_tree_hyperparameters(self, X: np.ndarray, y: np.ndarray,
                                    task_type: str = 'classification') -> Dict[str, Any]:
        """Optimize decision tree hyperparameters using grid search"""
        
        if task_type == 'classification':
            base_model = DecisionTreeClassifier(random_state=self.random_state)
            scoring = 'accuracy'
        else:
            base_model = DecisionTreeRegressor(random_state=self.random_state)
            scoring = 'r2'
        
        # Define parameter grid
        param_grid = {
            'max_depth': [3, 5, 7, 10, 15, None],
            'min_samples_split': [2, 5, 10, 20],
            'min_samples_leaf': [1, 2, 5, 10],
            'max_features': ['auto', 'sqrt', 'log2', None],
            'criterion': ['gini', 'entropy'] if task_type == 'classification' else ['mse', 'mae']
        }
        
        # Grid search
        grid_search = GridSearchCV(
            base_model, param_grid, cv=5, scoring=scoring,
            n_jobs=-1, verbose=1
        )
        
        grid_search.fit(X, y)
        
        # Analyze hyperparameter importance
        results_df = pd.DataFrame(grid_search.cv_results_)
        
        return {
            'best_params': grid_search.best_params_,
            'best_score': grid_search.best_score_,
            'best_model': grid_search.best_estimator_,
            'cv_results': results_df,
            'hyperparameter_analysis': self._analyze_hyperparameter_effects(results_df)
        }
    
    def _analyze_hyperparameter_effects(self, results_df: pd.DataFrame) -> Dict[str, Any]:
        """Analyze the effects of different hyperparameters"""
        
        analysis = {}
        
        # Find parameters with highest impact on performance
        param_columns = [col for col in results_df.columns if col.startswith('param_')]
        
        for param_col in param_columns:
            param_name = param_col.replace('param_', '')
            grouped = results_df.groupby(param_col)['mean_test_score'].agg(['mean', 'std'])
            analysis[param_name] = {
                'best_value': grouped['mean'].idxmax(),
                'performance_range': grouped['mean'].max() - grouped['mean'].min(),
                'stability': grouped['std'].mean()
            }
        
        return analysis

    def _plot_feature_importance(self, model):
        """Plot feature importance"""
        if self.feature_names and hasattr(model, 'feature_importances_'):
            importance = model.feature_importances_
            indices = np.argsort(importance)[::-1]
            
            plt.bar(range(len(importance)), importance[indices])
            plt.title('Feature Importance')
            plt.xlabel('Features')
            plt.ylabel('Importance')
            if len(self.feature_names) <= 20:
                plt.xticks(range(len(importance)), 
                          [self.feature_names[i] for i in indices], rotation=45)
        else:
            plt.text(0.5, 0.5, 'Feature importance\nnot available', 
                    ha='center', va='center', transform=plt.gca().transAxes)
    
    def _plot_depth_vs_performance(self, X, y, model_class):
        """Plot tree depth vs performance"""
        depths = range(1, 21)
        train_scores = []
        val_scores = []
        
        for depth in depths:
            model = model_class(max_depth=depth, random_state=self.random_state)
            scores = cross_val_score(model, X, y, cv=5)
            val_scores.append(scores.mean())
            
            model.fit(X, y)
            if hasattr(model, 'predict_proba'):
                train_scores.append(accuracy_score(y, model.predict(X)))
            else:
                train_scores.append(r2_score(y, model.predict(X)))
        
        plt.plot(depths, train_scores, 'o-', label='Training', alpha=0.7)
        plt.plot(depths, val_scores, 'o-', label='Validation', alpha=0.7)
        plt.xlabel('Max Depth')
        plt.ylabel('Score')
        plt.title('Depth vs Performance')
        plt.legend()
        plt.grid(True, alpha=0.3)
    
    def _plot_learning_curve(self, model, X, y):
        """Plot learning curve"""
        train_sizes, train_scores, val_scores = learning_curve(
            model, X, y, cv=5, n_jobs=-1, train_sizes=np.linspace(0.1, 1.0, 10)
        )
        
        train_mean = np.mean(train_scores, axis=1)
        train_std = np.std(train_scores, axis=1)
        val_mean = np.mean(val_scores, axis=1)
        val_std = np.std(val_scores, axis=1)
        
        plt.fill_between(train_sizes, train_mean - train_std, train_mean + train_std, alpha=0.2)
        plt.fill_between(train_sizes, val_mean - val_std, val_mean + val_std, alpha=0.2)
        plt.plot(train_sizes, train_mean, 'o-', label='Training')
        plt.plot(train_sizes, val_mean, 'o-', label='Validation')
        
        plt.xlabel('Training Size')
        plt.ylabel('Score')
        plt.title('Learning Curve')
        plt.legend()
        plt.grid(True, alpha=0.3)
    
    def _plot_validation_curve(self, model, X, y, param_name, param_range):

        train_scores, val_scores = validation_curve(

        val_mean = np.mean(val_scores, axis=1)

        plt.ylabel('Score')
        plt.title(f'Validation Curve ({param_name})')
        plt.legend()
        plt.grid(True, alpha=0.3)

    def _plot_cv_scores(self, model, X, y):
        """Plot cross-validation scores"""
        cv_scores = cross_val_score(model, X, y, cv=5)
        
        plt.bar(range(len(cv_scores)), cv_scores, alpha=0.7)
        plt.axhline(y=cv_scores.mean(), color='red', linestyle='--', 
                   label=f'Mean: {cv_scores.mean():.3f}')
        plt.xlabel('CV Fold')
        plt.ylabel('Score')
        plt.title('Cross-Validation Scores')
        plt.legend()
        plt.grid(True, alpha=0.3)
    
    def _plot_overfitting_analysis(self, X, y, model_class):
        """Plot overfitting analysis"""
        depths = range(1, 21)
        train_scores = []
        test_scores = []
        
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=0.3, random_state=self.random_state
        )
        
        for depth in depths:
            model = model_class(max_depth=depth, random_state=self.random_state)
            model.fit(X_train, y_train)
            
            if hasattr(model, 'predict_proba'):
                train_score = accuracy_score(y_train, model.predict(X_train))
                test_score = accuracy_score(y_test, model.predict(X_test))
            else:
                train_score = r2_score(y_train, model.predict(X_train))
                test_score = r2_score(y_test, model.predict(X_test))
            
            train_scores.append(train_score)
            test_scores.append(test_score)
        
        plt.plot(depths, train_scores, 'o-', label='Training', alpha=0.7)
        plt.plot(depths, test_scores, 'o-', label='Test', alpha=0.7)
        plt.xlabel('Max Depth')
        plt.ylabel('Score')
        plt.title('Overfitting Analysis')
        plt.legend()
        plt.grid(True, alpha=0.3)

            x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
            y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
            xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                               np.arange(y_min, y_max, h))
            
            mesh_points = np.c_[xx.ravel(), yy.ravel()]
            
            if hasattr(model, 'predict_proba'):
                Z = model.predict_proba(mesh_points)[:, 1]
            else:
                Z = model.predict(mesh_points)
            
            Z = Z.reshape(xx.shape)
            plt.contourf(xx, yy, Z, alpha=0.4)
            scatter = plt.scatter(X[:, 0], X[:, 1], c=y, alpha=0.8)
            plt.colorbar(scatter)
            plt.title('2D Decision Boundary')
        else:
            plt.text(0.5, 0.5, f'Decision boundary visualization\nrequires 2D data\n(current: {X.shape[1]}D)', 
                    ha='center', va='center', transform=plt.gca().transAxes)

                left_rule = f"{parent_rule} {name} <= {threshold:.2f}"
                right_rule = f"{parent_rule} {name} > {threshold:.2f}"
                
                recurse(tree_.children_left[node], depth + 1, left_rule)
                recurse(tree_.children_right[node], depth + 1, right_rule)
            else:

                if class_names:

                    confidence = np.max(value) / np.sum(value)

                else:
                    prediction = value[0]
                    rule = f"IF{parent_rule} THEN {prediction:.3f}"
                
                rules.append(rule)
        
        recurse(0, 1)
        return rules
