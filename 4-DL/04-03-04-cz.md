## 1. Úvod do grafových neuronových sítí

Grafové neuronové sítě (GNN) jsou modely hlubokého učení navržené pro práci s daty ve formě grafů. Na rozdíl od tradičních neuronových sítí, které pracují s pravidelnými mřížkovými daty (obrázky, text), GNN mohou zpracovávat data reprezentovaná jako grafy s uzly a hranami.

```python

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GCNConv, GATConv
import networkx as nx
import matplotlib.pyplot as plt
```

Grafová data jsou všudypřítomná v reálných aplikacích: sociální sítě, molekulární struktury, znalostní grafy a doporučovací systémy jsou všechny přirozeně reprezentovány jako grafy. Tradiční architektury hlubokého učení mají potíže s takovými nepravidelnými strukturami, což je důvod, proč byly vyvinuty GNN.

## 2. Základy reprezentace grafů

Klíčové reprezentace grafů zahrnují:

1. **Matice sousednosti**: Matice n×n, kde n je počet uzlů a každý záznam (i,j) označuje, zda existuje hrana mezi uzly i a j.
2. **Seznam hran**: Seznam dvojic označujících propojené uzly.
3. **Příznaky uzlů**: Atributy nebo příznaky spojené s každým uzlem.
4. **Příznaky hran**: Atributy spojené s hranami.

## 3. Typy architektur GNN

Existuje několik klíčových architektur GNN, každá s různými přístupy ke zpracování grafových dat:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GCNConv, GATConv, SAGEConv

# Graph Convolutional Network (GCN)
class GCN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        return x

# Graph Attention Network (GAT)
class GAT(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, heads=8):
        super(GAT, self).__init__()
        self.conv1 = GATConv(in_channels, hidden_channels, heads=heads)
        self.conv2 = GATConv(hidden_channels*heads, out_channels)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.elu(x)
        x = F.dropout(x, p=0.6, training=self.training)
        x = self.conv2(x, edge_index)
        return x

# GraphSAGE
class GraphSAGE(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(GraphSAGE, self).__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = SAGEConv(hidden_channels, out_channels)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        return x
```

Hlavní typy architektur GNN zahrnují:

1. **Graph Convolutional Networks (GCN)**: Provádí konvoluce přes grafovou strukturu agregací informací z okolních uzlů.
2. **Graph Attention Networks (GAT)**: Využívají mechanismy pozornosti k vážení důležitosti různých sousedů.
3. **GraphSAGE**: Využívá vzorkování a agregaci pro efektivní zpracování velkých grafů.
4. **Graph Isomorphism Networks (GIN)**: Navrženy pro maximalizaci vyjadřovací síly GNN.
5. **Message Passing Neural Networks (MPNN)**: Obecný rámec, který zahrnuje mnoho variant GNN.

## 4. Implementace základní GNN pomocí PyTorch

Podívejme se na kompletní příklad tréninku GNN na jednoduchém datasetu:

```python
from torch_geometric.datasets import Planetoid
from torch_geometric.transforms import NormalizeFeatures
import torch_geometric.transforms as T

# Načtení datasetu citační sítě Cora
dataset = Planetoid(root='/tmp/Cora', name='Cora', transform=NormalizeFeatures())
data = dataset[0]

# Prozkoumání dat
print(f"Počet uzlů: {data.num_nodes}")
print(f"Počet hran: {data.num_edges}")
print(f"Počet příznaků uzlů: {data.num_features}")
print(f"Počet tříd: {dataset.num_classes}")
print(f"Trénovací uzly: {data.train_mask.sum().item()}")
print(f"Validační uzly: {data.val_mask.sum().item()}")
print(f"Testovací uzly: {data.test_mask.sum().item()}")

# Definice modelu GCN
class GCN(torch.nn.Module):
    def __init__(self, num_features, hidden_channels, num_classes):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(num_features, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, num_classes)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)

# Inicializace modelu
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCN(dataset.num_features, 16, dataset.num_classes).to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

# Trénovací funkce
def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    return loss

# Hodnotící funkce
def test():
    model.eval()
    with torch.no_grad():
        out = model(data.x, data.edge_index)
        pred = out.argmax(dim=1)
        
        # Výpočet přesnosti
        train_acc = pred[data.train_mask].eq(data.y[data.train_mask]).sum().item() / data.train_mask.sum().item()
        val_acc = pred[data.val_mask].eq(data.y[data.val_mask]).sum().item() / data.val_mask.sum().item()
        test_acc = pred[data.test_mask].eq(data.y[data.test_mask]).sum().item() / data.test_mask.sum().item()
        
        return train_acc, val_acc, test_acc

# Trénovací smyčka
best_val_acc = 0
for epoch in range(200):
    loss = train()
    train_acc, val_acc, test_acc = test()
    
    if val_acc > best_val_acc:
        best_val_acc = val_acc
        best_test_acc = test_acc
    
    if epoch % 20 == 0:
        print(f'Epocha: {epoch:03d}, Ztráta: {loss:.4f}, Trénování: {train_acc:.4f}, '
              f'Validace: {val_acc:.4f}, Test: {test_acc:.4f}')

print(f'Nejlepší validační přesnost: {best_val_acc:.4f}')
print(f'Nejlepší testovací přesnost: {best_test_acc:.4f}')
```

Tento příklad implementuje GCN pro klasifikaci uzlů na datasetu citační sítě Cora, kde každý uzel je vědecký článek, hrany představují citace a úlohou je klasifikovat články do různých oblastí výzkumu.

## 5. Klasifikace uzlů

Klasifikace uzlů je jednou z nejběžnějších úloh pro GNN, kde předpovídáme štítky pro uzly v grafu.

```python
# Pokročilejší klasifikace uzlů s inženýrstvím příznaků

from torch_geometric.datasets import Planetoid
from torch_geometric.transforms import NormalizeFeatures
import torch.nn.functional as F

# Načtení datasetu s dalšími transformacemi
dataset = Planetoid(
    root='/tmp/Cora',
    name='Cora',
    transform=T.Compose([
        NormalizeFeatures(),
        T.RandomNodeSplit(num_val=0.1, num_test=0.1),
    ])
)
data = dataset[0]

# Přidání stupně uzlu jako příznaku
from torch_geometric.utils import degree
node_degrees = degree(data.edge_index[0], data.num_nodes).unsqueeze(1)
data.x = torch.cat([data.x, node_degrees/node_degrees.max()], dim=1)

# Vytvoření složitějšího modelu s reziduálními spojeními
class ResGCN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, num_layers=3):
        super(ResGCN, self).__init__()
        
        self.convs = torch.nn.ModuleList()
        self.convs.append(GCNConv(in_channels, hidden_channels))
        
        for _ in range(num_layers - 2):
            self.convs.append(GCNConv(hidden_channels, hidden_channels))
            
        self.convs.append(GCNConv(hidden_channels, out_channels))
        
        # Lineární transformace pro reziduální spojení
        self.skips = torch.nn.ModuleList()
        self.skips.append(torch.nn.Linear(in_channels, hidden_channels))
        for _ in range(num_layers - 2):
            self.skips.append(torch.nn.Linear(hidden_channels, hidden_channels))
        self.skips.append(torch.nn.Linear(hidden_channels, out_channels))
        
    def forward(self, x, edge_index):
        for i, conv in enumerate(self.convs[:-1]):
            # Reziduální spojení
            res = self.skips[i](x)
            x = conv(x, edge_index)
            x = F.relu(x + res)  # Přidání rezidua
            x = F.dropout(x, p=0.5, training=self.training)
            
        # Poslední vrstva
        res = self.skips[-1](x)
        x = self.convs[-1](x, edge_index)
        x = x + res  # Přidání rezidua
        
        return F.log_softmax(x, dim=1)

# Inicializace modelu
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = ResGCN(data.num_features, 64, dataset.num_classes, num_layers=3).to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.005, weight_decay=5e-4)

# Trénování a vyhodnocení (podobné jako v předchozím příkladu)
# ...
```

Klasifikace uzlů je užitečná pro:
- Detekci podvodů ve finančních sítích
- Doporučování obsahu v sociálních sítích
- Identifikaci funkcí proteinů v biologických sítích
- Klasifikaci výzkumných článků podle tématu

## 6. Klasifikace grafů

U klasifikace grafů je cílem klasifikovat celé grafy spíše než jednotlivé uzly.

```python
from torch_geometric.datasets import TUDataset
from torch_geometric.data import DataLoader
from torch_geometric.nn import GCNConv, global_mean_pool

# Načtení datasetu pro klasifikaci grafů (molekulární grafy)
dataset = TUDataset(root='/tmp/PROTEINS', name='PROTEINS')
dataset = dataset.shuffle()

# Rozdělení datasetu
train_dataset = dataset[:int(len(dataset) * 0.8)]
test_dataset = dataset[int(len(dataset) * 0.8):]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

print(f"Počet grafů: {len(dataset)}")
print(f"Počet příznaků: {dataset.num_features}")
print(f"Počet tříd: {dataset.num_classes}")

# Definice modelu pro klasifikaci grafů
class GCNGraphClassifier(torch.nn.Module):
    def __init__(self, num_features, hidden_channels, num_classes):
        super(GCNGraphClassifier, self).__init__()
        self.conv1 = GCNConv(num_features, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, hidden_channels)
        self.conv3 = GCNConv(hidden_channels, hidden_channels)
        self.lin = torch.nn.Linear(hidden_channels, num_classes)
        
    def forward(self, x, edge_index, batch):
        # Vložení uzlů
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        
        x = self.conv2(x, edge_index)
        x = F.relu(x)
        
        x = self.conv3(x, edge_index)
        
        # Čtení na úrovni grafu
        x = global_mean_pool(x, batch)  # [batch_size, hidden_channels]
        
        # Finální klasifikátor
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.lin(x)
        
        return F.log_softmax(x, dim=-1)

# Inicializace modelu
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCNGraphClassifier(dataset.num_features, 64, dataset.num_classes).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

    model.train()
    total_loss = 0
    
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = F.nll_loss(out, data.y)
        loss.backward()
        optimizer.step()
        total_loss += float(loss) * data.num_graphs
    
    return total_loss / len(train_dataset)

# Testovací funkce

# Trénovací smyčka
```

## 7. Predikce spojení

Predikce spojení má za cíl předpovídat chybějící nebo budoucí spojení mezi uzly v grafu.

```python
from torch_geometric.nn import GCNConv
from torch_geometric.utils import train_test_split_edges, negative_sampling
from torch_geometric.datasets import Planetoid

# Načtení datasetu
dataset = Planetoid(root='/tmp/Cora', name='Cora')
data = dataset[0]

# Příprava dat pro predikci spojení
data = train_test_split_edges(data)

class LinkPredictionGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(LinkPredictionGNN, self).__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
        
    def encode(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        return self.conv2(x, edge_index)
    
    def decode(self, z, edge_index):
        # Výpočet skalárního součinu mezi vloženými uzly spojenými hranou
        return (z[edge_index[0]] * z[edge_index[1]]).sum(dim=1)
    
    def decode_all(self, z):
        # Výpočet párových skalárních součinů pro všechny možné páry uzlů
        return torch.matmul(z, z.t())
    
    def forward(self, x, edge_index):
        z = self.encode(x, edge_index)
        return z

# Inicializace modelu
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = LinkPredictionGNN(data.num_features, 128, 64).to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# Trénovací funkce
def train():
    model.train()
    optimizer.zero_grad()
    
    # Výpočet vložení uzlů
    z = model.encode(data.x, data.train_pos_edge_index)
    
    # Vzorkování pozitivních a negativních hran
    pos_edge_index = data.train_pos_edge_index
    neg_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=pos_edge_index.size(1)
    )
    
    # Predikce skóre hran pro pozitivní a negativní příklady
    pos_score = model.decode(z, pos_edge_index)
    neg_score = model.decode(z, neg_edge_index)
    
    # Výpočet ztráty pomocí binární křížové entropie
    pos_loss = F.binary_cross_entropy_with_logits(pos_score, torch.ones_like(pos_score))
    neg_loss = F.binary_cross_entropy_with_logits(neg_score, torch.zeros_like(neg_score))
    loss = pos_loss + neg_loss
    
    loss.backward()
    optimizer.step()
    
    return loss.item()

# Hodnotící funkce
@torch.no_grad()
def test():
    model.eval()
    
    z = model.encode(data.x, data.train_pos_edge_index)
    
    def get_auc(pos_edge_index, neg_edge_index):
        pos_score = model.decode(z, pos_edge_index)
        neg_score = model.decode(z, neg_edge_index)
        
        scores = torch.cat([pos_score, neg_score], dim=0)
        labels = torch.cat([torch.ones(pos_score.size(0)), 
                            torch.zeros(neg_score.size(0))], dim=0)
        
        from sklearn.metrics import roc_auc_score
        return roc_auc_score(labels.cpu().numpy(), scores.cpu().numpy())
    
    # Vzorkování negativních testovacích/validačních hran
    neg_val_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=data.val_pos_edge_index.size(1)
    )
    
    neg_test_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=data.test_pos_edge_index.size(1)
    )
    
    # Výpočet AUC
    val_auc = get_auc(data.val_pos_edge_index, neg_val_edge_index)
    test_auc = get_auc(data.test_pos_edge_index, neg_test_edge_index)
    
    return val_auc, test_auc

# Trénovací smyčka
best_val_auc = 0
best_test_auc = 0

for epoch in range(100):
    loss = train()
    val_auc, test_auc = test()
    
    if val_auc > best_val_auc:
        best_val_auc = val_auc
        best_test_auc = test_auc
    
    if epoch % 10 == 0:
        print(f'Epocha: {epoch:03d}, Ztráta: {loss:.4f}, Validační AUC: {val_auc:.4f}, '
              f'Testovací AUC: {test_auc:.4f}')

print(f'Nejlepší validační AUC: {best_val_auc:.4f}')
print(f'Nejlepší testovací AUC: {best_test_auc:.4f}')
```

Predikce spojení je cenná pro:
- Doporučování přátelství v sociálních sítích
- Doplňování znalostních grafů
- Předpověď interakcí mezi proteiny
- Doporučování položek v e-commerce

```python
# Příklad: Použití GNN pro předpověď vlastností molekul (QSAR)
from torch_geometric.datasets import MoleculeNet
from torch_geometric.nn import GCNConv, global_add_pool
from torch_geometric.data import DataLoader

# Načtení datasetu
dataset = MoleculeNet(root='/tmp/ESOL', name='ESOL')  # Předpověď rozpustnosti
dataset = dataset.shuffle()

# Rozdělení datasetu
train_dataset = dataset[:int(len(dataset) * 0.8)]
val_dataset = dataset[int(len(dataset) * 0.8):int(len(dataset) * 0.9)]
test_dataset = dataset[int(len(dataset) * 0.9):]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

print(f"Velikost datasetu: {len(dataset)}")
print(f"Počet příznaků uzlů: {dataset.num_node_features}")
print(f"Počet příznaků hran: {dataset.num_edge_features}")
print(f"Počet úloh: {dataset.num_tasks}")

# Definice modelu pro regresi
class MoleculeGNN(torch.nn.Module):
    def __init__(self, node_features, edge_features, hidden_channels, num_tasks):
        super(MoleculeGNN, self).__init__()
        
        # Vložení uzlů
        self.node_encoder = torch.nn.Linear(node_features, hidden_channels)
        
        # Vložení hran
        self.edge_encoder = torch.nn.Linear(edge_features, hidden_channels)
        
        # Grafové konvoluce
        self.conv1 = GCNConv(hidden_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, hidden_channels)
        self.conv3 = GCNConv(hidden_channels, hidden_channels)
        
        # Výstupní vrstvy
        self.lin1 = torch.nn.Linear(hidden_channels, hidden_channels)
        self.lin2 = torch.nn.Linear(hidden_channels, num_tasks)
        
    def forward(self, x, edge_index, edge_attr, batch):
        # Počáteční vložení uzlů a hran
        x = self.node_encoder(x)
        edge_attr = self.edge_encoder(edge_attr)
        
        # Grafové konvoluce
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        
        x = self.conv2(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        
        x = self.conv3(x, edge_index)
        
        # Globální pooling
        x = global_add_pool(x, batch)
        
        # Finální predikce
        x = self.lin1(x)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        x = self.lin2(x)
        
        return x
```

## 9. Nedávné pokroky v GNN

Oblast GNN se rychle vyvíjí s několika nedávnými pokroky:

```python
# Příklad implementace novější architektury GNN

import torch
from torch_geometric.nn import MessagePassing, global_mean_pool
import torch.nn.functional as F

# Implementace GraphNorm - nedávné normalizační techniky pro GNN
class GraphNorm(torch.nn.Module):
    def __init__(self, num_features, eps=1e-5, affine=True):
        super(GraphNorm, self).__init__()
        self.eps = eps
        self.num_features = num_features
        
        if affine:
            self.gamma = torch.nn.Parameter(torch.ones(num_features))
            self.beta = torch.nn.Parameter(torch.zeros(num_features))
        else:
            self.register_parameter('gamma', None)
            self.register_parameter('beta', None)
            
    def forward(self, x, batch):
        batch_size = batch.max().item() + 1
        
        # Výpočet statistik dávky
        batch_mean = global_mean_pool(x, batch)
        batch_mean = torch.repeat_interleave(batch_mean, torch.bincount(batch), dim=0)
        
        # Výpočet rozptylu pro každou dávku
        batch_var = global_mean_pool((x - batch_mean)**2, batch)
        batch_var = torch.repeat_interleave(batch_var, torch.bincount(batch), dim=0)
        
        # Normalizace
        x_norm = (x - batch_mean) / (torch.sqrt(batch_var + self.eps))
        
        # Škálování a posun
        if self.gamma is not None and self.beta is not None:
            x_norm = self.gamma * x_norm + self.beta
            
        return x_norm

# Příklad Jumping Knowledge sítě
class JumpingKnowledge(torch.nn.Module):
    def __init__(self, in_channels, out_channels, num_layers=3, mode='cat'):
        super(JumpingKnowledge, self).__init__()
        self.convs = torch.nn.ModuleList()
        self.norms = torch.nn.ModuleList()
        self.mode = mode
        
        for i in range(num_layers):
            if i == 0:
                self.convs.append(GCNConv(in_channels, out_channels))
            else:
                self.convs.append(GCNConv(out_channels, out_channels))
            self.norms.append(GraphNorm(out_channels))
            
        if mode == 'cat':
            self.jump = torch.nn.Linear(out_channels * num_layers, out_channels)
        elif mode == 'max':
            self.jump = torch.nn.Identity()
        else:  # LSTM mód
            self.jump = torch.nn.LSTM(out_channels, out_channels, batch_first=True)
            
    def forward(self, x, edge_index, batch):
        xs = []
        for i, conv in enumerate(self.convs):
            x = conv(x, edge_index)
            x = self.norms[i](x, batch)
            x = F.relu(x)
            x = F.dropout(x, p=0.2, training=self.training)
            xs.append(x)
            
        if self.mode == 'cat':
            return self.jump(torch.cat(xs, dim=1))
        elif self.mode == 'max':
            return torch.stack(xs, dim=1).max(dim=1)[0]
        else:  # LSTM mód
            x = torch.stack(xs, dim=1)  # [num_nodes, num_layers, out_channels]
            x, _ = self.jump(x)
            return x[:, -1]  # Vrácení posledního výstupu LSTM

# Příklad použití
```
