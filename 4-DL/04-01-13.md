# Implementace jednoduchých dopředných neuronových sítí

## Hlavní body

Tento dokument shrnuje implementaci dopředných neuronových sítí (Feedforward Neural Networks), které tvoří základní architekturu pro mnoho aplikací hlubokého učení.

### 1. Porozumění dopředným neuronovým sítím
- **Základní struktura**: Vstupní vrstva, skryté vrstvy, výstupní vrstva
- **Klíčové komponenty**: Neurony, váhy, aktivační funkce
- **Informační tok**: Informace prochází jednosměrně - dopředně
- **Matematická reprezentace**: y = f(Wx + b)

### 2. Aktivační funkce
- **Sigmoid**: Pro binární klasifikaci (výstup 0-1)
- **Tanh**: Hyperbolic tangent (výstup -1 až 1)
- **ReLU**: Rectified Linear Unit, nejpoužívanější pro skryté vrstvy
- **Leaky ReLU**: Modifikace ReLU s malým sklonem pro záporné hodnoty

### 3. Implementace od základů
- Manuální implementace pomocí NumPy
- Inicializace vah a biasů
- Dopředný průchod (forward propagation)
- Výpočet chyby (loss)
- Zpětný průchod (backpropagation)
- Aktualizace parametrů pomocí gradientního sestupu

### 4. Implementace s TensorFlow/Keras
- Sequential API pro lineární architektury
- Funkcionální API pro komplexnější topologie
- Použití vrstev: Dense, Dropout, BatchNormalization
- Kompilace a training modelu
- Vyhodnocení výkonnosti

### 5. Implementace s PyTorch
- Definice modelu pomocí nn.Module
- DataLoader pro zpracování dat
- Tréninkový cyklus
- Vyhodnocení modelu

### 6. Vizualizace neuronových sítí
- Vizualizace vah a biasů
- Zobrazení architektury sítě
- Sledování aktivací neuronu

### 7. Tréninkový proces a evaluace
- Přehled tréninkového procesu
- Ztrátové funkce pro různé typy problémů
- Optimalizační algoritmy (SGD, Adam, RMSprop)
- Plánování learning rate
- Validační strategie
- Metriky výkonnosti
- Early stopping

### 8. Ladění hyperparametrů
- Klíčové hyperparametry:
  - Architektura (počet vrstev, počet neuronů)
  - Tréninkové parametry (learning rate, batch size)
  - Regularizační parametry (dropout rate, L1/L2)
- Metody ladění:
  - Manuální ladění
  - Grid Search
  - Random Search
  - Bayesovská optimalizace

### 9. Pokročilé techniky
- Pokročilé aktivační funkce (Leaky ReLU, ELU, SELU, Swish)
- Pokročilé techniky normalizace (Batch Normalization, Layer Normalization)
- Pokročilé inicializace vah (He, Xavier/Glorot, Orthogonal)
- Skip connections
- Pokročilé regularizační techniky
- Transfer learning
- Model distillation

## Závěr

Přestože byly vyvinuty složitější architektury jako CNN, RNN a Transformery, dopředné neuronové sítě zůstávají základním pilířem hlubokého učení:

1. **Základ hlubokého učení**: Dopředné sítě poskytují základní architekturu, na které jsou postaveny složitější modely.
2. **Všestrannost**: Jednoduché dopředné sítě mohou řešit širokou škálu problémů při správném nastavení.
3. **Efektivita**: Pro mnoho tabulkových dat často překonávají složitější architektury.
4. **Interpretovatelnost**: Jednodušší architektury jsou obecně snazší pro interpretaci a ladění.

### Osvědčené postupy
- Začněte s jednoduchým modelem
- Správně předzpracujte data
- Pečlivě navrhněte architekturu
- Systematicky laďte hyperparametry
- Používejte správné metriky pro evaluaci
- Aplikujte regularizaci proti přetrénování
- Kombinujte více modelů pro lepší výkon (ensembling)

### Budoucí směry
- Integrace s mechanismy pozornosti (attention)
- Automatické hledání optimální architektury
- Hybridní modely kombinující symbolické AI a doménové znalosti
- Adaptace na prostředí s omezenými zdroji dat a výpočetní kapacitou

Dopředné neuronové sítě budou i nadále cenné jak samostatně, tak jako komponenty složitějších architektur, zejména s pokračujícím vývojem technik trénování, regularizace a designu architektur.
