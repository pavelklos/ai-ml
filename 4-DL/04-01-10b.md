# Práce s datasety a Data Loadery v Deep Learningu

## Hlavní body

1. **Koncept datasetů**
   - Rozdělení dat na trénovací, validační a testovací množiny
   - Features (vstupy) a labels (výstupy)
   - Velikost dávek (batch size) a její vliv na trénink
   - Různé formáty datasetů (strukturovaná data, obrázky, text, audio, video)

2. **Vytváření vlastních datasetů**
   - PyTorch: rozšíření třídy `torch.utils.data.Dataset` s metodami `__init__`, `__len__` a `__getitem__`
   - TensorFlow: použití API `tf.data.Dataset` pro vytváření datasetů

3. **Vestavěné datasety**
   - PyTorch: torchvision.datasets (MNIST, CIFAR-10, ImageNet, atd.)
   - TensorFlow: keras.datasets (MNIST, CIFAR-10, atd.)
   - Načítání a transformace předpřipravených datasetů

4. **Data Loadery**
   - PyTorch DataLoader: batching, shuffling, paralelní načítání dat
   - TensorFlow Data API: metody batch(), shuffle(), map(), cache(), prefetch()

5. **Předzpracování dat**
   - Normalizace a standardizace
   - One-hot encoding kategorických proměnných
   - Řešení chybějících hodnot

6. **Datová augmentace**
   - Augmentace obrázků: otáčení, změna velikosti, převrácení, úprava jasu a kontrastu
   - Augmentace textu: nahrazování synonym, náhodné vkládání a prohazování

7. **Řešení nevyvážených datasetů**
   - Undersampling: snížení počtu vzorků většinové třídy
   - Oversampling: zvýšení počtu vzorků menšinové třídy
   - Vážené vzorkování v data loaderech

8. **Práce s velkými datasety**
   - Generator-based datasety v PyTorch
   - TensorFlow's `tf.data.Dataset.from_generator`
   - Memory-mapped soubory pomocí NumPy

9. **Vytváření datových pipeline**
   - Kompletní datové pipeline v PyTorch a TensorFlow
   - Načítání, předzpracování, augmentace a dávkování dat

10. **Optimalizace výkonu načítání dat**
    - Měření rychlosti načítání dat
    - Optimalizace PyTorch DataLoaderu: num_workers, pin_memory
    - Optimalizace TensorFlow Datasetu: cache(), shuffle(), prefetch()

## Klíčové koncepty

### Dataset v PyTorch
```python
class SyntheticDataset(Dataset):
    def __init__(self, num_samples=1000, feature_dim=10, transform=None):
        self.features = torch.randn(num_samples, feature_dim)
        self.labels = torch.randint(0, 2, (num_samples,))
        self.transform = transform
        
    def __len__(self):
        return len(self.features)
    
    def __getitem__(self, idx):
        x = self.features[idx]
        y = self.labels[idx]
        
        if self.transform:
            x = self.transform(x)
            
        return x, y
```

### Dataset v TensorFlow
```python
# Vytvoření syntetického datasetu v TensorFlow
def create_tf_synthetic_dataset(num_samples=1000, feature_dim=10, batch_size=32):
    # Generování náhodných features a labels
    features = tf.random.normal((num_samples, feature_dim))
    labels = tf.random.uniform((num_samples,), 0, 2, dtype=tf.int32)
    
    # Vytvoření TensorFlow datasetu
    dataset = tf.data.Dataset.from_tensor_slices((features, labels))
    
    # Shuffle a batch datasetu
    dataset = dataset.shuffle(buffer_size=num_samples)
    dataset = dataset.batch(batch_size)
    
    return dataset
```
