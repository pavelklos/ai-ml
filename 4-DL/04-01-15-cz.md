# Základy dávkové normalizace

## 1. Úvod do dávkové normalizace

Dávková normalizace (BatchNorm) je technika představená Sergeyem Ioffe a Christianem Szegedy v roce 2015, která dramaticky zlepšuje rychlost, výkon a stabilitu neuronových sítí. Funguje normalizací vstupů každé vrstvy, čímž redukuje tzv. "interní kovariantní posun" - změnu v distribuci aktivací sítě způsobenou aktualizacemi parametrů sítě během tréninku.

BatchNorm se stal standardní součástí mnoha architektur hlubokého učení, zejména v hlubokých neuronových sítích, CNN a některých variantách RNN.

## 2. Problém: Interní kovariantní posun

Při trénování hlubokých sítí se s měnícími se parametry počátečních vrstev mění také distribuce vstupů do hlubších vrstev. Tento fenomén, nazývaný interní kovariantní posun, může zpomalit trénink, protože každá vrstva se musí přizpůsobovat neustále se měnící vstupní distribuci.

Uvažte jednoduchý příklad: pokud mají vstupy do vrstvy velmi rozdílné škály, gradienty parametrů mohou mít také velmi rozdílné škály, což ztěžuje optimalizaci.

## 3. Jak dávková normalizace funguje

Dávková normalizace řeší tento problém normalizací vstupů každé vrstvy tak, aby měly střední hodnotu nula a rozptyl jedna, podobně jako normalizujeme počáteční vstupy do sítě.

### Matematická formulace

Pro mini-dávku vstupů $x$:

1. Výpočet střední hodnoty mini-dávky: $\mu_B = \frac{1}{m} \sum_{i=1}^{m} x_i$
2. Výpočet rozptylu mini-dávky: $\sigma_B^2 = \frac{1}{m} \sum_{i=1}^{m} (x_i - \mu_B)^2$
3. Normalizace: $\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$ (kde $\epsilon$ je malá konstanta pro numerickou stabilitu)
4. Škálování a posun: $y_i = \gamma \hat{x}_i + \beta$ (kde $\gamma$ a $\beta$ jsou naučitelné parametry)

Během tréninku používá BatchNorm statistiky aktuální mini-dávky. Během inference typicky používá klouzavé průměry těchto statistik vypočtené během tréninku.

### V TensorFlow/Keras

```python
import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras import layers, models
from tensorflow.keras.datasets import mnist

# Načtení a předzpracování dat
(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train = x_train.reshape(-1, 28, 28, 1).astype('float32') / 255.0
x_test = x_test.reshape(-1, 28, 28, 1).astype('float32') / 255.0

# Model bez BatchNorm
def create_model_without_bn():
    model = models.Sequential([
        layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
        layers.MaxPooling2D((2, 2)),
        layers.Conv2D(64, (3, 3), activation='relu'),
        layers.MaxPooling2D((2, 2)),
        layers.Conv2D(64, (3, 3), activation='relu'),
        layers.Flatten(),
        layers.Dense(64, activation='relu'),
        layers.Dense(10, activation='softmax')
    ])
    return model

# Model s BatchNorm
def create_model_with_bn():
    model = models.Sequential([
        layers.Conv2D(32, (3, 3), input_shape=(28, 28, 1)),
        layers.BatchNormalization(),
        layers.Activation('relu'),
        layers.MaxPooling2D((2, 2)),
        
        layers.Conv2D(64, (3, 3)),
        layers.BatchNormalization(),
        layers.Activation('relu'),
        layers.MaxPooling2D((2, 2)),
        
        layers.Conv2D(64, (3, 3)),
        layers.BatchNormalization(),
        layers.Activation('relu'),
        layers.Flatten(),
        
        layers.Dense(64),
        layers.BatchNormalization(),
        layers.Activation('relu'),
        
        layers.Dense(10, activation='softmax')
    ])
    return model

# Vytvoření modelů
model_without_bn = create_model_without_bn()
model_with_bn = create_model_with_bn()

# Kompilace modelů
model_without_bn.compile(optimizer='adam',
                loss='sparse_categorical_crossentropy',
                metrics=['accuracy'])

model_with_bn.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# Trénování modelů
history_without_bn = model_without_bn.fit(x_train, y_train, epochs=10, 
                                          batch_size=64, validation_split=0.2)

history_with_bn = model_with_bn.fit(x_train, y_train, epochs=10, 
                                    batch_size=64, validation_split=0.2)

# Vykreslení trénovacích křivek
plt.figure(figsize=(12, 4))

plt.subplot(1, 2, 1)
plt.plot(history_without_bn.history['accuracy'], label='Bez BN')
plt.plot(history_with_bn.history['accuracy'], label='S BN')
plt.xlabel('Epocha')
plt.ylabel('Trénovací přesnost')
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(history_without_bn.history['val_accuracy'], label='Bez BN')
plt.plot(history_with_bn.history['val_accuracy'], label='S BN')
plt.xlabel('Epocha')
plt.ylabel('Validační přesnost')
plt.legend()

plt.tight_layout()
plt.show()
```

### V PyTorch

```python
import torch
import torch.nn as nn
import torch.optim as optim
import torchvision
import torchvision.transforms as transforms
import matplotlib.pyplot as plt

# Konfigurace zařízení
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Načtení a předzpracování dat
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

train_dataset = torchvision.datasets.MNIST(root='./data', 
                                           train=True, 
                                           transform=transform, 
                                           download=True)

test_dataset = torchvision.datasets.MNIST(root='./data', 
                                          train=False, 
                                          transform=transform)

train_loader = torch.utils.data.DataLoader(dataset=train_dataset, 
                                           batch_size=100, 
                                           shuffle=True)

test_loader = torch.utils.data.DataLoader(dataset=test_dataset, 
                                          batch_size=100, 
                                          shuffle=False)

# Model bez BatchNorm
class ConvNetWithoutBN(nn.Module):
    def __init__(self):
        super(ConvNetWithoutBN, self).__init__()
        self.layer1 = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=5, padding=2),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        self.layer2 = nn.Sequential(
            nn.Conv2d(16, 32, kernel_size=5, padding=2),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        self.fc = nn.Linear(7*7*32, 10)
    
    def forward(self, x):
        out = self.layer1(x)
        out = self.layer2(out)
        out = out.view(out.size(0), -1)
        out = self.fc(out)
        return out

# Model s BatchNorm
class ConvNetWithBN(nn.Module):
    def __init__(self):
        super(ConvNetWithBN, self).__init__()
        self.layer1 = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=5, padding=2),
            nn.BatchNorm2d(16),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        self.layer2 = nn.Sequential(
            nn.Conv2d(16, 32, kernel_size=5, padding=2),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2)
        )
        self.fc = nn.Linear(7*7*32, 10)
    
    def forward(self, x):
        out = self.layer1(x)
        out = self.layer2(out)
        out = out.view(out.size(0), -1)
        out = self.fc(out)
        return out

# Trénovací funkce
def train_model(model, train_loader, num_epochs=5):
    model.to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.001)
    
    train_losses = []
    
    for epoch in range(num_epochs):
        running_loss = 0.0
        for i, (images, labels) in enumerate(train_loader):
            images = images.to(device)
            labels = labels.to(device)
            
            # Dopředný průchod
            outputs = model(images)
            loss = criterion(outputs, labels)
            
            # Zpětný průchod a optimalizace
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            running_loss += loss.item()
            
        epoch_loss = running_loss / len(train_loader)
        train_losses.append(epoch_loss)
        print(f'Epocha [{epoch+1}/{num_epochs}], Ztráta: {epoch_loss:.4f}')
    
    return train_losses

# Vytvoření a trénování modelů
model_without_bn = ConvNetWithoutBN()
model_with_bn = ConvNetWithBN()

losses_without_bn = train_model(model_without_bn, train_loader)
losses_with_bn = train_model(model_with_bn, train_loader)

# Vykreslení trénovacích ztrát
plt.figure(figsize=(10, 6))
plt.plot(losses_without_bn, label='Bez BatchNorm')
plt.plot(losses_with_bn, label='S BatchNorm')
plt.xlabel('Epocha')
plt.ylabel('Trénovací ztráta')
plt.legend()
plt.title('Vliv dávkové normalizace na trénovací ztrátu')
plt.grid(True)
plt.show()
```

## 5. Výhody dávkové normalizace

1. **Rychlejší trénink**: BatchNorm často umožňuje použití vyšších rychlostí učení, což urychluje trénink.
2. **Regularizace**: Působí jako mírná forma regularizace, snižuje potřebu dalších regularizačních technik jako je dropout.
3. **Snižuje citlivost na inicializaci**: Činí sítě méně citlivé na počáteční váhy.
4. **Stabilizuje učení**: Snižuje riziko exploze/vymizení gradientu ve velmi hlubokých sítích.
5. **Redukuje interní kovariantní posun**: Jak bylo zmíněno dříve, toto je primární účel.

## 6. Praktické úvahy

### Kam přidat dávkovou normalizaci

1. **Po aktivaci**: Původně bylo doporučeno aplikovat ji před aktivační funkcí (pre-aktivace), ale výzkum a praxe ukázaly, že v některých případech může fungovat lépe po aktivaci.

```python
# BatchNorm před aktivací (běžnější)
layers.Dense(64)
layers.BatchNormalization()
layers.Activation('relu')

# BatchNorm po aktivaci
layers.Dense(64)
layers.Activation('relu')
layers.BatchNormalization()
```

2. **Interakce s biasem**: Při použití BatchNorm se bias term v předchozí vrstvě stává redundantním, protože BatchNorm zahrnuje naučitelný parametr posunu (β).

### Úvahy o velikosti dávky

Dávková normalizace je vysoce závislá na velikosti dávky. Velmi malé velikosti dávek mohou vést k zašuměným statistikám, což ovlivňuje výkon modelu. Pro extrémně malé dávky zvažte použití alternativ jako Layer Normalization.

## 7. Pokročilá témata v dávkové normalizaci

### Chování při tréninku vs. inferenci

Během tréninku používá BatchNorm střední hodnotu a rozptyl aktuální mini-dávky. Během inference používá exponenciální klouzavý průměr středních hodnot a rozptylů vypočtených během tréninku.

### Dávková normalizace v rekurentních neuronových sítích

Aplikace BatchNorm v RNN vyžaduje speciální pozornost kvůli rekurentní povaze těchto sítí. Pro řešení této výzvy byly vyvinuty techniky dávkové normalizace závislé na čase.

### Podmíněná dávková normalizace

V některých modelech, jako jsou ty používané pro přenos stylu nebo doménovou adaptaci, mohou být parametry BatchNorm (γ a β) podmíněny jinými vstupy.

## 8. Alternativy k dávkové normalizaci

1. **Layer Normalization**: Normalizuje napříč příznaky místo dimenze dávky, což ji činí nezávislou na velikosti dávky.
2. **Instance Normalization**: Normalizuje každý vzorek nezávisle, užitečné pro úlohy přenosu stylu.
3. **Group Normalization**: Kompromis mezi Layer a Instance normalizací, kde jsou kanály rozděleny do skupin pro normalizaci.

```python
# Implementace alternativ k BatchNorm v TensorFlow/Keras
import tensorflow as tf
from tensorflow.keras import layers

# Layer Normalization
layer_norm_model = tf.keras.Sequential([
    layers.Dense(64),
    layers.LayerNormalization(),
    layers.Activation('relu'),
    # Zbytek modelu...
])

# Instance Normalization (běžně používaná v CNN)
class InstanceNormalization(layers.Layer):
    def __init__(self, epsilon=1e-5):
        super(InstanceNormalization, self).__init__()
        self.epsilon = epsilon
        self.gamma = None
        self.beta = None
        
    def build(self, input_shape):
        self.gamma = self.add_weight(
            name='gamma',
            shape=input_shape[-1:],
            initializer='ones',
            trainable=True)
        self.beta = self.add_weight(
            name='beta',
            shape=input_shape[-1:],
            initializer='zeros',
            trainable=True)
        
    def call(self, x):
        mean, variance = tf.nn.moments(x, axes=[1, 2], keepdims=True)
        normalized = (x - mean) / tf.sqrt(variance + self.epsilon)
        return self.gamma * normalized + self.beta

# Group Normalization
# TensorFlow obsahuje implementaci v tf.keras.layers.experimental
from tensorflow.keras.layers.experimental import GroupNormalization

group_norm_model = tf.keras.Sequential([
    layers.Conv2D(32, 3, padding='same'),
    GroupNormalization(groups=4),
    layers.Activation('relu'),
    # Zbytek modelu...
])
```

## 9. Kdy používat dávkovou normalizaci

- **Hluboké sítě**: Obzvláště užitečné ve velmi hlubokých sítích, kde je interní kovariantní posun významným problémem
- **CNN**: Extrémně efektivní v konvolučních sítích
- **Vyšší rychlosti učení**: Když chcete použít vyšší rychlosti učení pro zrychlení tréninku
- **Nestabilní trénink**: Pokud váš trénovací proces vykazuje nestabilitu nebo pomalou konvergenci

BatchNorm nemusí být tak přínosný v:
- Velmi malých velikostech dávek
- RNN (bez speciálních adaptací)
- Sítích, kde je kritické zachování přesných hodnot aktivací

Klíčovou výhodou BatchNorm je udržování stabilních distribucí aktivací. Vizualizujme to:

import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras import layers, models

# Vytvoření modelů pro extrakci aktivací
def create_model_with_bn():
    inputs = tf.keras.Input(shape=(28, 28, 1))
    x = layers.Conv2D(32, 3, activation=None)(inputs)
    bn = layers.BatchNormalization()(x)
    act = layers.Activation('relu')(bn)
    
    return models.Model(inputs=inputs, outputs=[x, bn, act])

def create_model_without_bn():
    inputs = tf.keras.Input(shape=(28, 28, 1))
    x = layers.Conv2D(32, 3, activation=None)(inputs)
    act = layers.Activation('relu')(x)
    
    return models.Model(inputs=inputs, outputs=[x, act])
