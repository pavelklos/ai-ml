# Úvod do TensorFlow/Keras API - Shrnutí

## Hlavní body

1. **Nastavení a instalace**
   - Instalace TensorFlow pomocí pip nebo conda
   - Kontrola verze a dostupnosti GPU
   - Nastavení náhodných seedů pro reprodukovatelnost

2. **Porozumění vztahu mezi TensorFlow a Keras**
   - TensorFlow jako komplexní platforma strojového učení
   - Keras jako vysokoúrovňové API integrované do TensorFlow
   - Tři úrovně API v TensorFlow: nízkoúrovňové (základní operace), středněúrovňové (vrstvy) a vysokoúrovňové (modely)

3. **Základy TensorFlow**
   - Tenzory: vícerozměrná pole jednotného typu (skaláry, vektory, matice, atd.)
   - Proměnné: speciální tenzory, které udržují stav napříč operacemi
   - Operace: matematické výpočty prováděné s tenzory
   - Výpočetní graf: série operací uspořádaných do grafu
   - Eager Execution: okamžité vyhodnocování operací (výchozí v TF 2.x)

4. **Úvod do Keras API**
   - Modely: Sequential API vs Functional API
   - Vrstvy: Dense, Conv2D, LSTM, Dropout, atd.
   - Optimalizační algoritmy: SGD, Adam, RMSprop
   - Ztrátové funkce: MSE, binary_crossentropy, categorical_crossentropy
   - Metriky: přesnost, precision, recall

5. **Vytváření modelů pomocí Keras**
   - Sequential API pro jednoduché lineární modely
   - Functional API pro složitější architektury s více vstupy/výstupy
   - Vlastní vrstvy a modely pomocí dědičnosti z tf.keras.layers.Layer a tf.keras.Model

6. **Trénink a evaluace modelů**
   - model.fit() pro trénování
   - model.evaluate() pro hodnocení na testovacích datech
   - model.predict() pro generování predikcí
   - Vizualizace průběhu tréninku pomocí history objektu
   - Využití callbacků: ModelCheckpoint, EarlyStopping, ReduceLROnPlateau, TensorBoard

7. **Ukládání a načítání modelů**
   - HDF5 formát pro uložení celého modelu
   - SavedModel formát (doporučený TensorFlow)
   - Ukládání pouze vah modelu
   - Ukládání pouze architektury modelu jako JSON nebo YAML

8. **TensorFlow Datasets**
   - tf.data API pro efektivní zpracování dat
   - TensorFlow Datasets (TFDS) pro přístup k veřejným datasetům
   - Vestavěné datasety v Keras (MNIST, CIFAR-10)
   - Techniky augmentace dat pro lepší generalizaci modelů

9. **Využití předtrénovaných modelů**
   - Extrakce příznaků pomocí předtrénovaných modelů
   - Transfer learning a fine-tuning
   - Zmrazení vrstev pro zachování naučených reprezentací
   - Úprava architektury pro specifické úlohy

10. **Praktické příklady**
    - Implementace jednoduchých klasifikačních a regresních modelů
    - Zpracování obrazových dat s MNIST
    - Vytvoření efektivních datových pipeline
    - Transfer learning s MobileNetV2

## Závěrečné shrnutí v češtině

TensorFlow s Keras API představuje komplexní ekosystém pro vývoj a nasazení modelů strojového učení. TensorFlow poskytuje nízkoúrovňové operace pro manipulaci s tenzory a definování výpočetních grafů, zatímco Keras nabízí uživatelsky přívětivé rozhraní zaměřené na zjednodušení procesu vytváření a trénování modelů.

Základem TensorFlow jsou tenzory - vícerozměrná pole dat, která mohou reprezentovat různé typy informací, od jednoduchých skalárů až po komplexní vícerozměrné matice. S těmito tenzory lze provádět různé matematické operace, které jsou kombinovány do výpočetních grafů definujících tok dat v modelu.

Keras API poskytuje elegantní způsob vytváření neuronových sítí prostřednictvím dvou hlavních přístupů: Sequential API pro jednoduché lineární modely a Functional API pro složitější architektury. Pro maximální flexibilitu lze vytvářet vlastní vrstvy a modely pomocí objektově orientovaného přístupu, což umožňuje implementaci specializovaných architektur a algoritmů.

Proces trénování a evaluace modelů je v Keras zjednodušen díky intuitivním metodám jako fit(), evaluate() a predict(). Pro lepší kontrolu nad tréninkovým procesem jsou k dispozici callbacky, které umožňují ukládání checkpointů, předčasné zastavení tréninku při přetrénování, dynamickou úpravu learning rate a mnoho dalšího.

TensorFlow nabízí různé možnosti pro ukládání a načítání modelů, od kompletního uložení architektury a vah až po separátní ukládání jednotlivých částí. Pro produkční nasazení je doporučen formát SavedModel, který zachovává celý výpočetní graf.

Pro efektivní práci s daty TensorFlow poskytuje tf.data API, které umožňuje vytvářet optimalizované datové pipeline s operacemi jako načítání, transformace, dávkování a prefetching. Pro standardní datasety lze využít vestavěné zdroje nebo knihovnu TensorFlow Datasets.

Transfer learning prostřednictvím předtrénovaných modelů představuje mocnou techniku, která umožňuje využít znalosti získané na velkých datasetech a aplikovat je na menší, specifické úlohy. Tento přístup výrazně zkracuje čas potřebný k trénování a často vede k lepším výsledkům, zejména když je k dispozici omezené množství trénovacích dat.

Zvládnutí TensorFlow a Keras API otevírá cestu k implementaci široké škály modelů strojového učení - od jednoduchých lineárních regresí až po komplexní architektury hlubokého učení pro počítačové vidění, zpracování přirozeného jazyka a další domény. S rostoucí zkušeností lze využívat pokročilé techniky jako vlastní trénovací smyčky, distribuované trénování nebo kvantizaci modelů pro efektivní nasazení.
