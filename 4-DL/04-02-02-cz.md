## Úvod do rekurentních neuronových sítí

Rekurentní neuronové sítě (RNN) jsou třídou neuronových sítí navržených pro práci se sekvenčními daty prostřednictvím udržování vnitřní paměti. Na rozdíl od tradičních dopředných neuronových sítí, RNN mají spojení, která vytvářejí cykly, což umožňuje přetrvání informací napříč časovými kroky.

Klíčovou vlastností RNN je jejich schopnost zpracovávat sekvence proměnné délky sdílením parametrů napříč různými časovými kroky. To je činí obzvláště vhodnými pro úlohy jako:

- Zpracování přirozeného jazyka (generování textu, překlad, analýza sentimentu)
- Předpovídání časových řad (ceny akcií, předpověď počasí)
- Rozpoznávání řeči
- Generování hudby

### Základní architektura RNN

V každém časovém kroku RNN přijímá vstupní vektor a kombinuje jej s předchozím skrytým stavem k produkci nového skrytého stavu a výstupu:

```python
import numpy as np

# Jednoduchá implementace základní buňky RNN
class SimpleRNNCell:
    def __init__(self, input_dim, hidden_dim, output_dim):
        # Inicializace vah a biasů
        self.Wxh = np.random.randn(hidden_dim, input_dim) * 0.01  # Vstup do skryté vrstvy
        self.Whh = np.random.randn(hidden_dim, hidden_dim) * 0.01  # Skrytá vrstva do skryté vrstvy
        self.Why = np.random.randn(output_dim, hidden_dim) * 0.01  # Skrytá vrstva do výstupu
        self.bh = np.zeros((hidden_dim, 1))  # Bias skryté vrstvy
        self.by = np.zeros((output_dim, 1))  # Bias výstupu
        
    def forward(self, x, h_prev):
        # Dopředný průchod
        h = np.tanh(np.dot(self.Wxh, x) + np.dot(self.Whh, h_prev) + self.bh)  # Skrytý stav
        y = np.dot(self.Why, h) + self.by  # Výstup
        return h, y
    
    def process_sequence(self, x_sequence):
        # Zpracování sekvence vstupů
        h = np.zeros((self.Whh.shape[0], 1))  # Inicializace skrytého stavu nulami
        outputs = []
        hidden_states = []
        
        for x in x_sequence:
            h, y = self.forward(x, h)
            outputs.append(y)
            hidden_states.append(h)
            
        return outputs, hidden_states

# Příklad použití
input_dim = 3
hidden_dim = 4
output_dim = 2

# Vytvoření buňky RNN
rnn_cell = SimpleRNNCell(input_dim, hidden_dim, output_dim)

# Vytvoření vzorové sekvence (3 časové kroky)
x_sequence = [np.random.randn(input_dim, 1) for _ in range(3)]

# Zpracování sekvence
outputs, hidden_states = rnn_cell.process_sequence(x_sequence)

print(f"Počet časových kroků: {len(outputs)}")
print(f"Tvar výstupu: {outputs[0].shape}")
print(f"Tvar skrytého stavu: {hidden_states[0].shape}")
```

Výpočet v každém časovém kroku lze matematicky vyjádřit jako:

- $h_t = \tanh(W_{xh} \cdot x_t + W_{hh} \cdot h_{t-1} + b_h)$
- $y_t = W_{hy} \cdot h_t + b_y$

Kde:
- $h_t$ je skrytý stav v časovém kroku t
- $x_t$ je vstup v časovém kroku t
- $W_{xh}$, $W_{hh}$, $W_{hy}$ jsou váhové matice
- $b_h$, $b_y$ jsou biasové vektory

## Problém mizejícího gradientu

Zatímco standardní RNN jsou teoreticky schopny učit se dlouhodobé závislosti v sekvenčních datech, v praxi trpí problémem mizejícího gradientu. Během zpětného šíření chyby v čase (backpropagation through time) jsou gradienty mnohokrát násobeny rekurentní váhovou maticí, což způsobuje, že buď:

1. **Mizí**: Gradienty se stávají extrémně malými, což ztěžuje učení dlouhodobých závislostí.
2. **Explodují**: Gradienty se stávají extrémně velkými, což způsobuje nestabilní trénink.

Problém mizejícího gradientu je obzvláště závažný pro delší sekvence, kde informace z mnoha kroků zpět nemůže efektivně ovlivnit aktuální predikci.

```python
import matplotlib.pyplot as plt

# Demonstrace mizejícího gradientu v RNN
def simulate_gradient_flow(weight_value, sequence_length):
    # Simulace toku gradientu přes jednoduchou RNN s fixními vahami
    gradient = 1.0
    gradients = [gradient]
    
    for t in range(1, sequence_length):
        # Při zpětném šíření v čase jsou gradienty opakovaně násobeny vahami
        gradient *= weight_value
        gradients.append(gradient)
    
    return gradients

# Vykreslení toku gradientu pro různé hodnoty vah
plt.figure(figsize=(10, 6))

sequence_length = 100
weight_values = [0.9, 1.0, 1.1]
colors = ['r', 'g', 'b']
labels = ['Váha = 0.9 (Mizející)', 'Váha = 1.0 (Stabilní)', 'Váha = 1.1 (Explodující)']

for i, w in enumerate(weight_values):
    gradients = simulate_gradient_flow(w, sequence_length)
    plt.plot(range(sequence_length), gradients, color=colors[i], label=labels[i])

plt.xlabel('Časové kroky')
plt.ylabel('Hodnota gradientu')
plt.title('Tok gradientu v rekurentních sítích')
plt.legend()
plt.grid(True)
plt.yscale('log')  # Logaritmická škála pro lepší zobrazení mizejícího/explodujícího chování
plt.show()
```

## Long Short-Term Memory (LSTM) sítě

Long Short-Term Memory (LSTM) sítě byly speciálně navrženy pro řešení problému mizejícího gradientu ve standardních RNN. Uvedeny Hochreiterem a Schmidhuberem v roce 1997, LSTM mají složitější strukturu se specializovanými komponentami nazývanými "brány", které regulují tok informací.

Klíčovou inovací LSTM je jejich schopnost selektivně si pamatovat nebo zapomínat informace po dlouhá období, což jim umožňuje zachytit dlouhodobé závislosti v sekvenčních datech.

### Klíčové výhody LSTM

1. **Dlouhodobá paměť**: LSTM mohou udržovat informace po stovky časových kroků.
2. **Selektivní paměť**: Mohou se naučit, které informace zachovat a které zahodit.
3. **Stabilita gradientu**: Architektura významně snižuje problém mizejícího gradientu.

## Architektura a komponenty LSTM

Buňka LSTM obsahuje tři hlavní brány, které řídí tok informací:

1. **Zapomínající brána (Forget gate)**: Rozhoduje, které informace zahodit ze stavu buňky.
2. **Vstupní brána (Input gate)**: Rozhoduje, které nové informace uložit do stavu buňky.
3. **Výstupní brána (Output gate)**: Řídí, které části stavu buňky jsou předány do dalšího skrytého stavu.

Kromě toho LSTM udržují dva typy stavů:
- **Stav buňky (Cell state)**: Komponenta dlouhodobé paměti.
- **Skrytý stav (Hidden state)**: Komponenta pracovní paměti (podobná skrytému stavu RNN).

```python
# Zjednodušená implementace LSTM buňky
class SimpleLSTMCell:
    def __init__(self, input_dim, hidden_dim):
        # Inicializace vah pro zapomínající bránu, vstupní bránu, stav buňky a výstupní bránu
        # (Detaily inicializace vah vynechány pro přehlednost)
        self.hidden_dim = hidden_dim
        self.input_dim = input_dim
        
        # Pro demonstraci vytvoříme pouze slovník náhodných vah
        self.weights = {}
        gates = ['forget', 'input', 'cell', 'output']
        
        for gate in gates:
            self.weights[f'W_{gate}'] = np.random.randn(hidden_dim, input_dim + hidden_dim) * 0.01
            self.weights[f'b_{gate}'] = np.zeros((hidden_dim, 1))
    
    def forward(self, x, h_prev, c_prev):
        # Spojení vstupu a předchozího skrytého stavu
        combined = np.vstack((x, h_prev))
        
        # Zapomínající brána
        f_gate = self.sigmoid(np.dot(self.weights['W_forget'], combined) + self.weights['b_forget'])
        
        # Vstupní brána
        i_gate = self.sigmoid(np.dot(self.weights['W_input'], combined) + self.weights['b_input'])
        
        # Kandidát stavu buňky
        c_candidate = np.tanh(np.dot(self.weights['W_cell'], combined) + self.weights['b_cell'])
        
        # Aktualizace stavu buňky
        c = f_gate * c_prev + i_gate * c_candidate
        
        # Výstupní brána
        o_gate = self.sigmoid(np.dot(self.weights['W_output'], combined) + self.weights['b_output'])
        
        # Aktualizace skrytého stavu
        h = o_gate * np.tanh(c)
        
        return h, c
    
    def sigmoid(self, x):
        return 1 / (1 + np.exp(-x))
    
    def process_sequence(self, x_sequence):
        h = np.zeros((self.hidden_dim, 1))  # Počáteční skrytý stav
        c = np.zeros((self.hidden_dim, 1))  # Počáteční stav buňky
        hidden_states = []
        
        for x in x_sequence:
            h, c = self.forward(x, h, c)
            hidden_states.append(h)
            
        return hidden_states

# Příklad použití
lstm = SimpleLSTMCell(input_dim=3, hidden_dim=5)
x_sequence = [np.random.randn(3, 1) for _ in range(4)]  # Sekvence 4 časových kroků
hidden_states = lstm.process_sequence(x_sequence)
```

## Implementace RNN pomocí TensorFlow/Keras

Pojďme implementovat jednoduchý model RNN pomocí TensorFlow/Keras pro úlohu klasifikace sekvencí:

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense
from tensorflow.keras.utils import to_categorical
from sklearn.model_selection import train_test_split
import numpy as np

# Nastavení náhodných seedů pro reprodukovatelnost
np.random.seed(42)
tf.random.set_seed(42)

# Generování syntetických sekvenčních dat
def generate_sequence_data(n_samples=1000, seq_length=20, n_features=1):
    X = np.random.randn(n_samples, seq_length, n_features)
    # Vytvoření štítků: součet sekvence > 0 je třída 1, jinak třída 0
    y = (np.sum(X, axis=1) > 0).astype(int).flatten()
    return X, y

# Generování dat
X, y = generate_sequence_data()
y_categorical = to_categorical(y)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y_categorical, test_size=0.2, random_state=42)

# Vytvoření modelu RNN
model = Sequential([
    SimpleRNN(units=32, activation='tanh', input_shape=(X.shape[1], X.shape[2]), return_sequences=False),
    Dense(units=2, activation='softmax')
])

# Kompilace modelu
model.compile(
    optimizer='adam',
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# Zobrazení shrnutí modelu
model.summary()

# Trénování modelu
history = model.fit(
    X_train, y_train,
    batch_size=32,
    epochs=10,
    validation_split=0.2,
    verbose=1
)

# Vyhodnocení modelu
test_loss, test_accuracy = model.evaluate(X_test, y_test)
print(f"Testovací přesnost: {test_accuracy:.4f}")

# Vykreslení historie tréninku
import matplotlib.pyplot as plt

plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(history.history['accuracy'])
plt.plot(history.history['val_accuracy'])
plt.title('Přesnost modelu')
plt.ylabel('Přesnost')
plt.xlabel('Epocha')
plt.legend(['Trénování', 'Validace'], loc='lower right')

plt.subplot(1, 2, 2)
plt.plot(history.history['loss'])
plt.plot(history.history['val_loss'])
plt.title('Ztráta modelu')
plt.ylabel('Ztráta')
plt.xlabel('Epocha')
plt.legend(['Trénování', 'Validace'], loc='upper right')
plt.tight_layout()
plt.show()
```

## Předpovídání časových řad s RNN a LSTM

RNN a LSTM jsou obzvláště vhodné pro úlohy předpovídání časových řad. Pojďme implementovat model pro předpovídání budoucích hodnot v časové řadě:

```python
import pandas as pd
import numpy as np
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense
from sklearn.preprocessing import MinMaxScaler
import matplotlib.pyplot as plt

# Generování syntetických dat časové řady
np.random.seed(42)
time_steps = 500
series = np.sin(0.1 * np.arange(time_steps)) + np.random.randn(time_steps) * 0.1

# Vykreslení časové řady
plt.figure(figsize=(12, 6))
plt.plot(series)
plt.title('Syntetická časová řada')
plt.xlabel('Časový krok')
plt.ylabel('Hodnota')
plt.grid(True)
plt.show()

# Příprava dat pro LSTM
def create_sequences(data, seq_length):
    xs, ys = [], []
    for i in range(len(data) - seq_length):
        x = data[i:i+seq_length]
        y = data[i+seq_length]
        xs.append(x)
        ys.append(y)
    return np.array(xs), np.array(ys)

# Nastavení délky sekvence
seq_length = 50

# Škálování dat
scaler = MinMaxScaler()
series_scaled = scaler.fit_transform(series.reshape(-1, 1))

# Vytvoření sekvencí
X, y = create_sequences(series_scaled, seq_length)

# Přetvarování X pro LSTM [vzorky, časové kroky, příznaky]
X = X.reshape(X.shape[0], X.shape[1], 1)

# Rozdělení na trénovací a testovací sadu
train_size = int(0.8 * len(X))
X_train, X_test = X[:train_size], X[train_size:]
y_train, y_test = y[:train_size], y[train_size:]

# Vytvoření modelu LSTM pro předpovídání časových řad
model = Sequential([
    LSTM(units=50, activation='relu', input_shape=(seq_length, 1)),
    Dense(units=1)
])

# Kompilace modelu
model.compile(optimizer='adam', loss='mse')

# Trénování modelu
history = model.fit(
    X_train, y_train,
    epochs=50,
    batch_size=32,
    validation_data=(X_test, y_test),
    verbose=1
)

# Vykreslení ztráty
plt.figure(figsize=(10, 6))
plt.plot(history.history['loss'], label='Trénovací ztráta')
plt.plot(history.history['val_loss'], label='Validační ztráta')
plt.title('Ztráta modelu')
plt.ylabel('Ztráta')
plt.xlabel('Epocha')
plt.legend()
plt.grid(True)
plt.show()

# Generování předpovědí
predictions = model.predict(X_test)

# Inverzní transformace předpovědí a skutečných hodnot
predictions = scaler.inverse_transform(predictions)
y_test_inv = scaler.inverse_transform(y_test.reshape(-1, 1))

# Vykreslení předpovědí vs. skutečné hodnoty
plt.figure(figsize=(12, 6))
plt.plot(y_test_inv, label='Skutečné hodnoty')
plt.plot(predictions, label='Předpovědi')
plt.title('LSTM předpověď časové řady')
plt.xlabel('Časový krok')
plt.ylabel('Hodnota')
plt.legend()
plt.grid(True)
plt.show()
```

## Generování textu s RNN a LSTM

RNN a LSTM se také běžně používají pro generování textu. Pojďme vytvořit jednoduchý jazykový model na úrovni znaků:

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Embedding
from tensorflow.keras.preprocessing.text import Tokenizer
from tensorflow.keras.preprocessing.sequence import pad_sequences
import re

# Vzorový text (malý korpus pro demonstraci)
text = """
The quick brown fox jumps over the lazy dog.
Pack my box with five dozen liquor jugs.
How vexingly quick daft zebras jump!
Bright vixens jump; dozy fowl quack.
Sphinx of black quartz, judge my vow.
"""

# Vyčištění textu - odstranění interpunkce a převod na malá písmena
text = re.sub(r'[^\w\s]', '', text.lower())

# Vytvoření mapování znaků
chars = sorted(list(set(text)))
char_to_idx = {c: i for i, c in enumerate(chars)}
idx_to_char = {i: c for i, c in enumerate(chars)}

# Vytvoření trénovacích sekvencí
seq_length = 10
step = 1

sequences = []
next_chars = []

for i in range(0, len(text) - seq_length, step):
    sequences.append(text[i:i + seq_length])
    next_chars.append(text[i + seq_length])

# Vektorizace sekvencí
X = np.zeros((len(sequences), seq_length, len(chars)), dtype=np.bool_)
y = np.zeros((len(sequences), len(chars)), dtype=np.bool_)

for i, sequence in enumerate(sequences):
    for t, char in enumerate(sequence):
        X[i, t, char_to_idx[char]] = 1
    y[i, char_to_idx[next_chars[i]]] = 1

# Vytvoření LSTM modelu pro generování textu
model = Sequential([
    LSTM(128, input_shape=(seq_length, len(chars))),
    Dense(len(chars), activation='softmax')
])

# Kompilace modelu
model.compile(loss='categorical_crossentropy', optimizer='adam')

# Trénování modelu (několik epoch pro demonstraci)
model.fit(X, y, batch_size=128, epochs=20)

# Funkce pro generování textu
def generate_text(seed_text, length=100, temperature=0.5):
    generated_text = seed_text
    
    # Generování znaků
    for i in range(length):
        # Vektorizace aktuálního vstupního textu
        x_pred = np.zeros((1, seq_length, len(chars)))
        for t, char in enumerate(seed_text[-seq_length:]):
            x_pred[0, t, char_to_idx[char]] = 1
            
        # Predikce dalšího znaku
        preds = model.predict(x_pred, verbose=0)[0]
        
        # Aplikace teploty pro náhodnost
        preds = np.log(preds + 1e-10) / temperature
        exp_preds = np.exp(preds)
        preds = exp_preds / np.sum(exp_preds)
        
        # Výběr z distribuce
        next_index = np.random.choice(len(chars), p=preds)
        next_char = idx_to_char[next_index]
        
        # Přidání k vygenerovanému textu
        generated_text += next_char
        seed_text = seed_text[1:] + next_char
    
    return generated_text

# Generování textu s různým nastavením teploty
seed = "the quick"
print("Vygenerovaný text s teplotou = 0.5:")
print(generate_text(seed, length=200, temperature=0.5))
```

## Tipy pro trénink a osvědčené postupy

### 1. Správa délky sekvence

Velmi dlouhé sekvence mohou způsobovat problémy při tréninku. Běžné přístupy zahrnují:

- **Zkrácené zpětné šíření v čase (TBPTT)**: Aktualizace vah po zpracování menších podsekvencí.
- **Stavové RNN**: Udržování stavu mezi dávkami souvisejících sekvencí.

```python
# Příklad stavového LSTM
from tensorflow.keras.layers import LSTM, Dense
from tensorflow.keras.models import Sequential

# Předpokládejme, že máme data X s tvarem [vzorky, časové_kroky, příznaky]
batch_size = 32
stateful_model = Sequential([
    LSTM(50, 
         batch_input_shape=(batch_size, None, X.shape[2]),  # Pevná velikost dávky
         stateful=True,
         return_sequences=True),
    LSTM(50, stateful=True),
    Dense(1)
])

stateful_model.compile(optimizer='adam', loss='mse')

# Při tréninku musíme resetovat stavy mezi epochami
for epoch in range(10):  # 10 epoch
    stateful_model.fit(X_train, y_train, 
                      batch_size=batch_size, 
                      shuffle=False,  # Důležité pro stavové LSTM
                      epochs=1,
                      verbose=1)
    stateful_model.reset_states()  # Reset stavů po každé epoše
```

### 2. Ořezávání gradientu

Ořezávání gradientů může pomoci zabránit problému explodujícího gradientu:

```python
from tensorflow.keras.optimizers import Adam

# Vytvoření optimalizátoru s ořezáváním gradientu
optimizer = Adam(learning_rate=0.001, clipnorm=1.0)  # Oříznutí gradientů na normu 1.0

model = Sequential([
    LSTM(50, input_shape=(seq_length, n_features), return_sequences=True),
    LSTM(50),
    Dense(1)
])

model.compile(optimizer=optimizer, loss='mse')
```

### 3. Dropout pro regularizaci

Specifické techniky dropoutu pro rekurentní sítě:

```python
from tensorflow.keras.layers import LSTM, Dropout

model = Sequential([
    LSTM(100, input_shape=(seq_length, n_features), 
         return_sequences=True,
         dropout=0.2,          # Dropout aplikovaný na vstupy
         recurrent_dropout=0.2  # Dropout aplikovaný na rekurentní spojení
        ),
    LSTM(100, dropout=0.2, recurrent_dropout=0.2),
    Dense(1)
])
```

### 4. Obousměrné LSTM

Pro úlohy, kde záleží na kontextu z minulosti i budoucnosti:

```python
from tensorflow.keras.layers import Bidirectional, LSTM, Dense

model = Sequential([
    Bidirectional(LSTM(50, return_sequences=True), input_shape=(seq_length, n_features)),
    Bidirectional(LSTM(50)),
    Dense(1)
])
```

### 5. Plánování učební rychlosti

Adaptivní rychlosti učení často fungují dobře:

```python
from tensorflow.keras.callbacks import LearningRateScheduler

def lr_schedule(epoch):
    if epoch < 10:
        return 0.001
    else:
        return 0.001 * tf.math.exp(0.1 * (10 - epoch))

lr_scheduler = LearningRateScheduler(lr_schedule)

model.fit(
    X_train, y_train,
    epochs=30,
    callbacks=[lr_scheduler]
)
```

## Shrnutí

Rekurentní neuronové sítě (RNN) a Long Short-Term Memory (LSTM) sítě jsou výkonné architektury pro zpracování sekvenčních dat. Klíčové body probrané v tomto přehledu:

1. **Základy RNN**: RNN zpracovávají sekvence udržováním skrytých stavů, které přenášejí informace napříč časovými kroky.

2. **Problém mizejícího gradientu**: Standardní RNN mají potíže s dlouhodobými závislostmi kvůli mizejícím nebo explodujícím gradientům.

3. **Řešení pomocí LSTM**: LSTM řeší problém mizejícího gradientu pomocí specializovaných bránových struktur (zapomínající, vstupní a výstupní brány), které řídí tok informací.

4. **Architektura LSTM**: LSTM udržují dva stavové vektory - stav buňky pro dlouhodobou paměť a skrytý stav pro výstup a zpracování dalšího kroku.

5. **Implementace**: Jak RNN, tak LSTM lze snadno implementovat pomocí moderních frameworků pro hluboké učení jako TensorFlow/Keras.

6. **Aplikace**:
   - Předpovídání časových řad
   - Generování textu a zpracování přirozeného jazyka
   - Klasifikace sekvencí
   - Rozpoznávání řeči

7. **Osvědčené postupy**:
   - Vhodná správa délky sekvencí
   - Aplikace ořezávání gradientu pro prevenci explodujících gradientů
   - Použití dropoutu pro regularizaci
   - Zvážení obousměrných modelů pro úlohy, které těží z budoucího kontextu
   - Implementace plánování učební rychlosti

RNN a LSTM zůstávají základními architekturami v hlubokém učení pro sekvenční data, ačkoli jsou stále častěji doplňovány nebo nahrazovány modely založenými na pozornosti (attention) v některých aplikacích, zejména ve zpracování přirozeného jazyka.
