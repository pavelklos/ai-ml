# Optimalizace metodou gradientního sestupu v hlubokém učení

## Úvod

Gradientní sestup je základní optimalizační algoritmus používaný k trénování modelů strojového učení, zejména hlubokých neuronových sítí. Minimalizuje nákladovou funkci iterativním pohybem ve směru nejstrmějšího sestupu, který je definován záporným gradientem. ## Základy gradientního sestupu

Gradientní sestup používá gradient nákladové funkce k určení směru aktualizace parametrů. Pravidlo aktualizace je:

$$\theta = \theta - \alpha \nabla J(\theta)$$

Kde:
- $\theta$ představuje parametry modelu
- $\alpha$ je rychlost učení (learning rate)
- $\nabla J(\theta)$ je gradient nákladové funkce vzhledem k parametrům

### Základní implementace

```python
import numpy as np

def gradient_descent(X, y, theta, alpha, num_iterations):
    """
    Jednoduchá implementace gradientního sestupu pro lineární regresi
    
    Parametry:
    X -- vstupní příznaky, tvar (m, n)
    y -- cílové hodnoty, tvar (m, 1)
    theta -- parametry, tvar (n, 1)
    alpha -- rychlost učení
    num_iterations -- počet iterací
    
    Vrací:
    theta -- optimalizované parametry
    cost_history -- hodnoty nákladů v průběhu iterací
    """
    m = len(y)
    cost_history = []
    
    for i in range(num_iterations):
        # Výpočet predikce
        predictions = X.dot(theta)
        
        # Výpočet chyb
        errors = predictions - y
        
        # Výpočet gradientů
        gradients = (1/m) * X.T.dot(errors)
        
        # Aktualizace parametrů
        theta = theta - alpha * gradients
        
        # Výpočet nákladů
        cost = (1/(2*m)) * np.sum(np.square(errors))
        cost_history.append(cost)
        
        if i % 100 == 0:
            print(f"Iterace {i}: Náklady = {cost}")
    
    return theta, cost_history
```

### 2. Stochastický gradientní sestup (Stochastic Gradient Descent, SGD)

Aktualizuje parametry pomocí jednoho trénovacího příkladu v čase. Rychlejší, ale výsledkem je hlučnější konvergence.

```python
def stochastic_gradient_descent(X, y, theta, alpha, num_iterations):
    m = len(y)
    cost_history = []
    
    for i in range(num_iterations):
        cost = 0
        
        # Iterace přes každý trénovací příklad
        for j in range(m):
            # Výběr náhodného příkladu
            random_index = np.random.randint(0, m)
            
            # Získání jednoho trénovacího příkladu
            xi = X[random_index:random_index+1]
            yi = y[random_index:random_index+1]
            
            # Výpočet predikce a chyby pro tento příklad
            prediction = xi.dot(theta)
            error = prediction - yi
            
            # Aktualizace parametrů pomocí tohoto jednoho příkladu
            theta = theta - alpha * xi.T.dot(error)
            
            # Přidání k nákladům
            cost += (1/2) * np.sum(np.square(error))
        
        # Zaznamenání průměrných nákladů
        cost_history.append(cost / m)
        
        if i % 100 == 0:
            print(f"Iterace {i}: Náklady = {cost/m}")
    
    return theta, cost_history
```

### 3. Mini-dávkový gradientní sestup (Mini-batch Gradient Descent)

Kombinuje výhody dávkového a stochastického přístupu použitím malých dávek trénovacích příkladů.

```python
def mini_batch_gradient_descent(X, y, theta, alpha, num_iterations, batch_size=32):
    m = len(y)
    cost_history = []
    
    for i in range(num_iterations):
        # Zamíchání dat
        indices = np.random.permutation(m)
        X_shuffled = X[indices]
        y_shuffled = y[indices]
        
        # Zpracování mini-dávek
        for j in range(0, m, batch_size):
            # Získání mini-dávky
            X_batch = X_shuffled[j:j+batch_size]
            y_batch = y_shuffled[j:j+batch_size]
            
            # Výpočet gradientů na mini-dávce
            predictions = X_batch.dot(theta)
            errors = predictions - y_batch
            gradients = (1/len(X_batch)) * X_batch.T.dot(errors)
            
            # Aktualizace parametrů
            theta = theta - alpha * gradients
        
        # Výpočet nákladů na celém datasetu (pro monitorování)
        predictions = X.dot(theta)
        cost = (1/(2*m)) * np.sum(np.square(predictions - y))
        cost_history.append(cost)
        
        if i % 10 == 0:
            print(f"Iterace {i}: Náklady = {cost}")
    
    return theta, cost_history
```

## Pokročilé optimalizační algoritmy

### 1. Gradientní sestup s momentem (Momentum)

Přidává term momentu pro urychlení konvergence a snížení oscilací.

```python
def momentum_gradient_descent(X, y, theta, alpha, num_iterations, beta=0.9):
    m = len(y)
    cost_history = []
    velocity = np.zeros_like(theta)
    
    for i in range(num_iterations):
        # Výpočet gradientů
        predictions = X.dot(theta)
        errors = predictions - y
        gradients = (1/m) * X.T.dot(errors)
        
        # Aktualizace rychlosti
        velocity = beta * velocity + (1 - beta) * gradients
        
        # Aktualizace parametrů pomocí rychlosti
        theta = theta - alpha * velocity
        
        # Výpočet nákladů
        cost = (1/(2*m)) * np.sum(np.square(errors))
        cost_history.append(cost)
        
        if i % 100 == 0:
            print(f"Iterace {i}: Náklady = {cost}")
    
    return theta, cost_history
```

### 2. RMSprop

Adaptuje učicí rychlost každého parametru na základě historie gradientů.

```python
def rmsprop(X, y, theta, alpha, num_iterations, beta=0.9, epsilon=1e-8):
    m = len(y)
    cost_history = []
    squared_gradients = np.zeros_like(theta)
    
    for i in range(num_iterations):
        # Výpočet gradientů
        predictions = X.dot(theta)
        errors = predictions - y
        gradients = (1/m) * X.T.dot(errors)
        
        # Aktualizace akumulátoru čtverců gradientů
        squared_gradients = beta * squared_gradients + (1 - beta) * np.square(gradients)
        
        # Aktualizace parametrů
        theta = theta - alpha * gradients / (np.sqrt(squared_gradients) + epsilon)
        
        # Výpočet nákladů
        cost = (1/(2*m)) * np.sum(np.square(errors))
        cost_history.append(cost)
        
        if i % 100 == 0:
            print(f"Iterace {i}: Náklady = {cost}")
    
    return theta, cost_history
```

### 3. Adam optimalizace

Kombinuje myšlenky momentu a RMSprop pro efektivní optimalizaci.

```python
def adam_optimization(X, y, theta, alpha, num_iterations, beta1=0.9, beta2=0.999, epsilon=1e-8):
    m = len(y)
    cost_history = []
    
    # Inicializace vektorů prvního a druhého momentu
    m_t = np.zeros_like(theta)
    v_t = np.zeros_like(theta)
    
    for i in range(1, num_iterations + 1):
        # Výpočet gradientů
        predictions = X.dot(theta)
        errors = predictions - y
        gradients = (1/m) * X.T.dot(errors)
        
        # Aktualizace odhadů prvního momentu s posunem
        m_t = beta1 * m_t + (1 - beta1) * gradients
        
        # Aktualizace odhadů druhého momentu s posunem
        v_t = beta2 * v_t + (1 - beta2) * np.square(gradients)
        
        # Výpočet korigovaného odhadu prvního momentu
        m_t_corrected = m_t / (1 - beta1**i)
        
        # Výpočet korigovaného odhadu druhého momentu
        v_t_corrected = v_t / (1 - beta2**i)
        
        # Aktualizace parametrů
        theta = theta - alpha * m_t_corrected / (np.sqrt(v_t_corrected) + epsilon)
        
        # Výpočet nákladů
        cost = (1/(2*m)) * np.sum(np.square(errors))
        cost_history.append(cost)
        
        if i % 100 == 0:
            print(f"Iterace {i}: Náklady = {cost}")
    
    return theta, cost_history
```

## Strategie učící rychlosti

### 1. Fixní učící rychlost

Nejjednodušší přístup s konstantní rychlostí učení během celého tréninku.

### 2. Snižování učící rychlosti (Learning Rate Decay)

Postupně snižuje rychlost učení v průběhu času pro doladění optimalizace.

```python
def learning_rate_decay(initial_alpha, epoch, decay_rate):
    """
    Implementuje jednoduché snížení učící rychlosti
    
    Parametry:
    initial_alpha -- počáteční učící rychlost
    epoch -- číslo aktuální epochy
    decay_rate -- rychlost poklesu
    
    Vrací:
    alpha -- aktualizovanou učící rychlost
    """
    return initial_alpha / (1 + decay_rate * epoch)
```

### 3. Kroková redukce (Step Decay)

Snižuje učící rychlost o faktor po určitém počtu epoch.

```python
def step_decay(initial_alpha, epoch, drop_rate=0.5, epochs_drop=10):
    """
    Implementuje krokové snížení učící rychlosti
    
    Parametry:
    initial_alpha -- počáteční učící rychlost
    epoch -- číslo aktuální epochy
    drop_rate -- faktor, o který se sníží učící rychlost
    epochs_drop -- počet epoch, po kterých se sníží učící rychlost
    
    Vrací:
    alpha -- aktualizovanou učící rychlost
    """
    return initial_alpha * drop_rate ** np.floor(epoch / epochs_drop)
```

### Použití PyTorch

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
import matplotlib.pyplot as plt

# Nastavení náhodného seedu pro reprodukovatelnost
torch.manual_seed(42)
np.random.seed(42)

# Generování syntetických dat
X = np.random.rand(1000, 20).astype(np.float32)
y = 5 * X[:, 0] + 3 * X[:, 1] - 2 * X[:, 2] + np.random.randn(1000) * 0.5
y = y.astype(np.float32)

# Rozdělení dat na trénovací a testovací sady
X_train, X_test = X[:800], X[800:]
y_train, y_test = y[:800], y[800:]

# Konverze na PyTorch tenzory
X_train_tensor = torch.tensor(X_train)
y_train_tensor = torch.tensor(y_train).view(-1, 1)
X_test_tensor = torch.tensor(X_test)
y_test_tensor = torch.tensor(y_test).view(-1, 1)

# Definice jednoduché neuronové sítě
class SimpleNet(nn.Module):
    def __init__(self):
        super(SimpleNet, self).__init__()
        self.fc1 = nn.Linear(20, 16)
        self.relu1 = nn.ReLU()
        self.fc2 = nn.Linear(16, 8)
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(8, 1)
        
    def forward(self, x):
        x = self.relu1(self.fc1(x))
        x = self.relu2(self.fc2(x))
        x = self.fc3(x)
        return x

def train_model(model, optimizer_name, learning_rate=0.01, momentum=0.9):
    # Inicializace modelu a ztrátové funkce
    model = model()
    criterion = nn.MSELoss()
    
    # Výběr optimalizátoru
    if optimizer_name == 'sgd':
        optimizer = optim.SGD(model.parameters(), lr=learning_rate)
    elif optimizer_name == 'momentum':
        optimizer = optim.SGD(model.parameters(), lr=learning_rate, momentum=momentum)
    elif optimizer_name == 'adam':
        optimizer = optim.Adam(model.parameters(), lr=learning_rate)
    else:
        raise ValueError("Optimizátor není podporován")
    
    # Trénovací cyklus
    epochs = 100
    train_losses = []
    test_losses = []
    
    for epoch in range(epochs):
        # Fáze tréninku
        model.train()
        optimizer.zero_grad()
        outputs = model(X_train_tensor)
        loss = criterion(outputs, y_train_tensor)
        loss.backward()
        optimizer.step()
        
        # Zaznamenání trénovací ztráty
        train_losses.append(loss.item())
        
        # Fáze evaluace
        model.eval()
        with torch.no_grad():
            test_outputs = model(X_test_tensor)
            test_loss = criterion(test_outputs, y_test_tensor)
            test_losses.append(test_loss.item())
    
    return train_losses, test_losses

# Trénink s různými optimalizátory
results = {}
optimizers = ['sgd', 'momentum', 'adam']
for optimizer_name in optimizers:
    train_losses, test_losses = train_model(SimpleNet, optimizer_name)
    results[optimizer_name] = {'train': train_losses, 'test': test_losses}

# Vizualizace výsledků
plt.figure(figsize=(12, 4))

plt.subplot(1, 2, 1)
for optimizer_name in optimizers:
    plt.plot(results[optimizer_name]['train'], label=optimizer_name)
plt.title('Trénovací ztráta')
plt.xlabel('Epochy')
plt.ylabel('Ztráta')
plt.legend()

plt.subplot(1, 2, 2)
for optimizer_name in optimizers:
    plt.plot(results[optimizer_name]['test'], label=optimizer_name)
plt.title('Validační ztráta')
plt.xlabel('Epochy')
plt.ylabel('Ztráta')
plt.legend()

plt.tight_layout()
plt.show()
```

## Výzvy a řešení

### 1. Mizející/Explodující gradienty

**Problém**: Gradienty se během zpětné propagace stávají příliš malými (mizí) nebo příliš velkými (explodují).

**Řešení**:
- Použití omezení gradientů (gradient clipping)
- Správná inicializace vah
- Dávková normalizace (batch normalization)
- Přeskočené spojení (skip connections, jako v ResNet)

```python
# Příklad omezení gradientů v PyTorch
optimizer.zero_grad()
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
```

### 2. Sedlové body a lokální minima

**Problém**: Optimalizace uvízne v sedlových bodech nebo lokálních minimech.

**Řešení**:
- Optimalizátory založené na momentu
- Stochastické metody (SGD)
- Plánování učící rychlosti

### 3. Volba učící rychlosti

**Problém**: Příliš vysoká učící rychlost způsobuje divergenci; příliš nízká zpomaluje trénink.

**Řešení**:
- Techniky hledání učící rychlosti
- Plánování učící rychlosti

```python
# Příklad hledače učící rychlosti s Keras
from tensorflow.keras.callbacks import LearningRateScheduler

def lr_schedule(epoch):
    return 0.01 * (0.1 ** (epoch // 30))

model.fit(X_train, y_train, epochs=100, 
          callbacks=[LearningRateScheduler(lr_schedule)])
```

import numpy as np

from mpl_toolkits.mplot3d import Axes3D

def cost_function(x, y):
    return x**2 + 3*y**2

def gradient(x, y):
    return np.array([2*x, 6*y])

# Vytvoření mřížky bodů pro vizualizaci
x = np.linspace(-5, 5, 100)
y = np.linspace(-5, 5, 100)

# Implementace gradientního sestupu
def gradient_descent_path(start_x, start_y, learning_rate, num_iterations):
    path = np.zeros((num_iterations+1, 2))
    path[0] = np.array([start_x, start_y])
    
    for i in range(num_iterations):
        grad = gradient(path[i, 0], path[i, 1])
        path[i+1] = path[i] - learning_rate * grad
    
    return path
