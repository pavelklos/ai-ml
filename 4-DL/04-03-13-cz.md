## 1. Úvod do hlubokého zpětnovazebního učení

Hluboké zpětnovazební učení (Deep Reinforcement Learning, DRL) kombinuje principy zpětnovazebního učení s hlubokými neuronovými sítěmi k učení optimálního chování ve složitých prostředích. Na rozdíl od učení s učitelem, agenti DRL se učí interakcí s prostředím a přijímáním zpětné vazby prostřednictvím odměn.

Klíčové komponenty systému zpětnovazebního učení:

1. **Agent**: Činí rozhodnutí a interaguje s prostředím
2. **Prostředí**: Svět, se kterým agent interaguje
3. **Stav**: Aktuální situace agenta
4. **Akce**: Možné pohyby, které může agent provést
5. **Odměna**: Zpětná vazba z prostředí
6. **Strategie**: Přístup používaný agentem k rozhodování o akcích

## 2. Přehled metod gradientu strategie

Metody gradientu strategie jsou třídou algoritmů zpětnovazebního učení, které optimalizují strategii přímo odhadováním gradientu očekávaného výnosu vzhledem k parametrům strategie.

Klíčové charakteristiky:
- Učí se parametrizované strategie přímo
- Optimalizují parametry strategie pomocí gradientního výstupu
- Přirozeně zvládají spojité akční prostory
- Mohou se učit stochastické strategie

```python
class SimplePolicyNetwork(torch.nn.Module):
    def __init__(self, input_dim, output_dim):
        super(SimplePolicyNetwork, self).__init__()
        self.network = torch.nn.Sequential(
            torch.nn.Linear(input_dim, 128),
            torch.nn.ReLU(),
            torch.nn.Linear(128, 128),
            torch.nn.ReLU(),
            torch.nn.Linear(128, output_dim),
            torch.nn.Softmax(dim=-1)
        )
    
    def forward(self, x):
        return self.network(x)
    
    def select_action(self, state):
        probs = self.forward(torch.FloatTensor(state))
        action = torch.multinomial(probs, 1).item()
        return action, probs
```

## 3. Proximální optimalizace strategie (PPO)

Proximální optimalizace strategie (PPO) je metoda gradientu strategie představená společností OpenAI v roce 2017. Řeší problém příliš velkých aktualizací strategie omezením změny strategie na "oblast důvěry".

Klíčové vlastnosti:
- Ořezaná cílová funkce k omezení aktualizací strategie
- Dobrá efektivita využití vzorků
- Relativně jednoduchá implementace
- Silný výkon v různých oblastech

Cílová funkce PPO:

```python
def ppo_loss(old_probs, new_probs, advantages, epsilon=0.2):
    ratio = new_probs / old_probs
    clipped_ratio = torch.clamp(ratio, 1-epsilon, 1+epsilon)
    loss = -torch.min(ratio * advantages, clipped_ratio * advantages).mean()
    return loss
```

## 4. Soft Actor-Critic (SAC)

Soft Actor-Critic je off-policy algoritmus actor-critic, který zahrnuje formu entropické regularizace. Usiluje o maximalizaci jak očekávané odměny, tak entropie strategie.

Klíčové vlastnosti:
- Entropická regularizace pro průzkum
- Off-policy učení pro efektivitu vzorků
- Oddělené sítě actor a critic
- Automatické ladění teploty
- Vynikající výkon na úlohách se spojitým řízením

## 5. Implementace v Pythonu

Zde je zjednodušená implementace PPO od základů pomocí PyTorch:

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
import gymnasium as gym

# Síť Actor-Critic
class ActorCritic(nn.Module):
    def __init__(self, state_dim, action_dim):
        super(ActorCritic, self).__init__()
        # Sdílené vrstvy
        self.fc1 = nn.Linear(state_dim, 64)
        self.fc2 = nn.Linear(64, 64)
        
        # Vrstvy pro Actor (strategie)
        self.actor_fc = nn.Linear(64, action_dim)
        
        # Vrstvy pro Critic (hodnota)
        self.critic_fc = nn.Linear(64, 1)
        
    def actor(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        return torch.softmax(self.actor_fc(x), dim=-1)
    
    def critic(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        return self.critic_fc(x)

class PPOAgent:
    def __init__(self, state_dim, action_dim, lr=0.002, gamma=0.99, epsilon=0.2, epochs=10):
        self.gamma = gamma
        self.epsilon = epsilon
        self.epochs = epochs
        
        self.policy = ActorCritic(state_dim, action_dim)
        self.optimizer = optim.Adam(self.policy.parameters(), lr=lr)
        
        self.states = []
        self.actions = []
        self.rewards = []
        self.next_states = []
        self.dones = []
        self.action_probs = []
    
    def select_action(self, state):
        with torch.no_grad():
            state = torch.FloatTensor(state)
            action_probs = self.policy.actor(state)
            action = torch.multinomial(action_probs, 1).item()
        return action, action_probs[action].item()
    
    def store_transition(self, state, action, reward, next_state, done, action_prob):
        self.states.append(state)
        self.actions.append(action)
        self.rewards.append(reward)
        self.next_states.append(next_state)
        self.dones.append(done)
        self.action_probs.append(action_prob)
    
    def update(self):
        # Převod seznamů na tensory
        states = torch.FloatTensor(np.array(self.states))
        actions = torch.LongTensor(self.actions)
        rewards = torch.FloatTensor(self.rewards)
        next_states = torch.FloatTensor(np.array(self.next_states))
        dones = torch.FloatTensor(self.dones)
        old_probs = torch.FloatTensor(self.action_probs)
        
        # Výpočet výnosů (diskontované odměny)
        returns = []
        discounted_reward = 0
        for reward, done in zip(reversed(rewards), reversed(dones)):
            if done:
                discounted_reward = 0
            discounted_reward = reward + self.gamma * discounted_reward
            returns.insert(0, discounted_reward)
        
        returns = torch.FloatTensor(returns)
        returns = (returns - returns.mean()) / (returns.std() + 1e-8)
        
        # Aktualizace pro více epoch
        for _ in range(self.epochs):
            # Získání nových pravděpodobností akcí a hodnot stavů
            action_probs = self.policy.actor(states)
            current_probs = action_probs.gather(1, actions.unsqueeze(1)).squeeze(1)
            state_values = self.policy.critic(states).squeeze(1)
            
            # Výpočet výhody
            advantage = returns - state_values.detach()
            
            # Výpočet ztráty
            ratio = current_probs / old_probs
            surr1 = ratio * advantage
            surr2 = torch.clamp(ratio, 1 - self.epsilon, 1 + self.epsilon) * advantage
            policy_loss = -torch.min(surr1, surr2).mean()
            value_loss = 0.5 * ((returns - state_values) ** 2).mean()
            
            total_loss = policy_loss + value_loss
            
            # Aktualizace strategie
            self.optimizer.zero_grad()
            total_loss.backward()
            self.optimizer.step()
        
        # Vyčištění paměti
        self.states = []
        self.actions = []
        self.rewards = []
        self.next_states = []
        self.dones = []
        self.action_probs = []
```

## 6. Ladění hyperparametrů

Ladění hyperparametrů je klíčové jak pro PPO, tak pro SAC. Zde je způsob, jak k tomu přistupovat systematicky:

```python
from stable_baselines3.common.callbacks import EvalCallback
from stable_baselines3.common.env_util import make_vec_env
import optuna

def objective(trial):
    # Hyperparametry k ladění
    learning_rate = trial.suggest_float("learning_rate", 1e-5, 1e-3, log=True)
    n_steps = trial.suggest_int("n_steps", 16, 2048, log=True)
    batch_size = trial.suggest_int("batch_size", 8, 256, log=True)
    gamma = trial.suggest_float("gamma", 0.9, 0.9999)
    clip_range = trial.suggest_float("clip_range", 0.1, 0.4)
    
    # Vytvoření vektorizovaného prostředí
    env = make_vec_env("CartPole-v1", n_envs=4)
    
    # Vytvoření PPO modelu s hyperparametry z trial
    model = PPO(
        policy="MlpPolicy",
        env=env,
        learning_rate=learning_rate,
        n_steps=n_steps,
        batch_size=batch_size,
        gamma=gamma,
        clip_range=clip_range,
        verbose=0
    )
    
    # Callback pro vyhodnocení
    eval_env = gym.make("CartPole-v1")
    eval_callback = EvalCallback(
        eval_env,
        best_model_save_path="./best_model",
        log_path="./logs/",
        eval_freq=5000,
        deterministic=True,
        render=False
    )
    
    try:
        # Trénování modelu
        model.learn(total_timesteps=50000, callback=eval_callback)
        
        # Vyhodnocení modelu
        mean_reward, _ = evaluate_policy(model, eval_env, n_eval_episodes=10)
        
        return mean_reward
    
    except Exception as e:
        print(e)
        return -1000  # Návrat špatného skóre při chybě

# Spuštění optimalizace hyperparametrů
study = optuna.create_study(direction="maximize")
study.optimize(objective, n_trials=50)

print("Nejlepší hyperparametry:", study.best_params)
```

## 7. Porovnání algoritmů

PPO a SAC mají různé přednosti a hodí se pro různé typy úloh:

```python
import pandas as pd

# Funkce pro vyhodnocení výkonu algoritmu
def evaluate_algorithm(algo_name, env_name, num_trials=5):
    results = []
    env = gym.make(env_name)
    
    for i in range(num_trials):
        if algo_name == "PPO":
            model = PPO("MlpPolicy", env, verbose=0)
            train_steps = 100000
        else:  # SAC
            model = SAC("MlpPolicy", env, verbose=0)
            train_steps = 100000
        
        model.learn(total_timesteps=train_steps)
        mean_reward, std_reward = evaluate_policy(model, env, n_eval_episodes=10)
        results.append(mean_reward)
    
    return np.mean(results), np.std(results)

# Porovnání algoritmů na různých prostředích
environments = ["CartPole-v1", "Pendulum-v1", "BipedalWalker-v3"]
algorithms = ["PPO", "SAC"]

comparison_results = []
for env_name in environments:
    for algo_name in algorithms:
        try:
            mean, std = evaluate_algorithm(algo_name, env_name)
            comparison_results.append({
                "Prostředí": env_name,
                "Algoritmus": algo_name,
                "Průměrná odměna": mean,
                "Std odměna": std
            })
        except Exception as e:
            print(f"Chyba s {algo_name} na {env_name}: {e}")

# Zobrazení výsledků jako tabulky
results_df = pd.DataFrame(comparison_results)
print(results_df)

# Vykreslení výsledků
plt.figure(figsize=(10, 6))
for algo in algorithms:
    data = results_df[results_df["Algoritmus"] == algo]
    plt.bar(data["Prostředí"], data["Průměrná odměna"], yerr=data["Std odměna"], label=algo, alpha=0.7)

plt.xlabel("Prostředí")
plt.ylabel("Průměrná odměna")
plt.title("Porovnání výkonu algoritmů")
plt.legend()
plt.tight_layout()
plt.show()
```

Klíčové rozdíly mezi PPO a SAC:

| Vlastnost | PPO | SAC |
|---------|-----|-----|
| Typ algoritmu | On-policy | Off-policy |
| Efektivita vzorků | Střední | Vysoká |
| Akční prostor | Diskrétní & Spojitý | Funguje nejlépe se Spojitým |
| Složitost implementace | Střední | Vyšší |
| Stabilita | Vysoká | Vysoká |
| Strategie průzkumu | Pomocí stochastické strategie | Maximalizace entropie |

## 10. Shrnutí

Algoritmy hlubokého zpětnovazebního učení jako PPO a SAC představují výkonné přístupy k trénování agentů pro provádění komplexních sekvenčních rozhodovacích úloh. Řeší mnoho výzev tradičních metod zpětnovazebního učení využitím hlubokých neuronových sítí a inovativních algoritmických vylepšení.

PPO nabízí jednoduchost, stabilitu a všestrannost napříč různými typy prostředí, což z něj činí skvělý výchozí bod pro mnoho problémů zpětnovazebního učení. Jeho ořezaná cílová funkce zabraňuje nadměrným aktualizacím strategie, což vede ke stabilnějšímu učení.

SAC vyniká v úlohách spojitého řízení díky svému off-policy přístupu a maximalizaci entropie, nabízejícímu vynikající efektivitu vzorků a schopnosti průzkumu. Jeho schopnost učit se z minulých zkušeností jej činí obzvláště silným pro složité úlohy robotického řízení.

Oba algoritmy tvoří nezbytné nástroje v moderním arzenálu hlubokého zpětnovazebního učení, přičemž implementační knihovny jako Stable Baselines3 je činí přístupnými pro širokou škálu aplikací od robotiky po hraní her a další oblasti.

Toto odvětví se nadále rychle vyvíjí, přičemž probíhající výzkum řeší současná omezení týkající se efektivity vzorků, zobecňování a potřeby pečlivě navržených funkcí odměn.

```python
# Shrnutí: Kompletní trénovací pipeline pro RL
def train_and_visualize(env_name, algorithm="PPO", timesteps=100000, render=True):
    """Trénování agenta a vizualizace jeho výkonu"""
    
    # Vytvoření prostředí
    env = gym.make(env_name)
    eval_env = gym.make(env_name, render_mode="human" if render else None)
    
    # Vytvoření modelu
    if algorithm == "PPO":
        model = PPO("MlpPolicy", env, verbose=1)
    else:  # SAC
        model = SAC("MlpPolicy", env, verbose=1)
    
    # Trénování modelu
    model.learn(total_timesteps=timesteps)
    
    # Vyhodnocení a vizualizace
    print(f"\nVyhodnocení {algorithm} na {env_name}...\n")
    obs, info = eval_env.reset()
    total_reward = 0
    
    for _ in range(1000):
        action, _ = model.predict(obs, deterministic=True)
        obs, reward, terminated, truncated, info = eval_env.step(action)
        total_reward += reward
        
        if terminated or truncated:
            print(f"Epizoda dokončena! Celková odměna: {total_reward}")
            break
    
    env.close()
    eval_env.close()
```
