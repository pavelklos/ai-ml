## Introduction

Deep learning frameworks provide the essential building blocks for designing, training, and validating deep neural networks. The two most popular frameworks today are TensorFlow (developed by Google) and PyTorch (developed by Facebook's AI Research lab). Each has its own strengths, ecosystem, and syntax.

- **TensorFlow** offers a comprehensive ecosystem for machine learning, with tools like TensorBoard for visualization and TensorFlow Extended (TFX) for production pipelines.

- **PyTorch** is known for its dynamic computational graph, intuitive design, and pythonic approach, making it popular among researchers.

This guide will help you set up both frameworks and prepare your environment for deep learning development.

## System Requirements

Before installation, ensure your system meets these requirements:

- **Python**: Both frameworks require Python 3.7+ (as of 2023)
- **CPU**: Any modern multi-core processor (Intel or AMD)
- **RAM**: Minimum 8GB (16GB+ recommended for larger models)
- **Storage**: 5GB+ free space for framework installations and dependencies
- **GPU** (optional but recommended): NVIDIA GPU with CUDA support

## Basic Examples

### TensorFlow Example: Training a Simple Neural Network

```python
import tensorflow as tf
from tensorflow.keras import layers, models
import numpy as np

# Create a simple dataset
X_train = np.random.random((1000, 20))
y_train = np.random.randint(2, size=(1000, 1))
X_test = np.random.random((300, 20))
y_test = np.random.randint(2, size=(300, 1))

# Create a simple model
model = models.Sequential([
    layers.Dense(64, activation='relu', input_shape=(20,)),
    layers.Dropout(0.2),
    layers.Dense(32, activation='relu'),
    layers.Dropout(0.2),
    layers.Dense(1, activation='sigmoid')
])

# Compile the model
model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy'])

# Display model architecture
model.summary()

# Train the model
history = model.fit(X_train, y_train, epochs=10, 
                    batch_size=32, validation_split=0.2)

# Evaluate the model
test_loss, test_acc = model.evaluate(X_test, y_test)
print(f"Test accuracy: {test_acc:.3f}")
```

### PyTorch Example: Training a Simple Neural Network

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# Check if GPU is available
device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")
print(f"Using device: {device}")

# Create a simple dataset
X_train = torch.FloatTensor(np.random.random((1000, 20))).to(device)
y_train = torch.FloatTensor(np.random.randint(2, size=(1000, 1))).to(device)
X_test = torch.FloatTensor(np.random.random((300, 20))).to(device)
y_test = torch.FloatTensor(np.random.randint(2, size=(300, 1))).to(device)

# Define model
class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.layers = nn.Sequential(
            nn.Linear(20, 64),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, 1),
            nn.Sigmoid()
        )
        
    def forward(self, x):
        return self.layers(x)

# Create model instance
model = SimpleNN().to(device)

# Define loss function and optimizer
criterion = nn.BCELoss()
optimizer = optim.Adam(model.parameters())

# Train the model
num_epochs = 10
batch_size = 32
num_samples = X_train.shape[0]
num_batches = num_samples // batch_size

for epoch in range(num_epochs):
    model.train()
    running_loss = 0.0
    
    for i in range(num_batches):
        # Get mini-batch
        indices = torch.randperm(num_samples)[:batch_size]
        X_batch, y_batch = X_train[indices], y_train[indices]
        
        # Forward pass
        optimizer.zero_grad()
        outputs = model(X_batch)
        loss = criterion(outputs, y_batch)
        
        # Backward pass and optimize
        loss.backward()
        optimizer.step()
        
        running_loss += loss.item()
    
    # Print statistics
    print(f'Epoch {epoch+1}/{num_epochs}, Loss: {running_loss/num_batches:.4f}')

# Evaluate the model
model.eval()
with torch.no_grad():
    y_pred = model(X_test)
    test_loss = criterion(y_pred, y_test).item()
    correct = ((y_pred > 0.5).float() == y_test).float().sum()
    accuracy = correct / y_test.shape[0]
    print(f'Test Loss: {test_loss:.4f}, Accuracy: {accuracy:.4f}')
```

## Troubleshooting Common Issues

### TensorFlow Issues

1. **GPU Not Detected**:
   - Verify CUDA and cuDNN installation
   - Check compatibility between TensorFlow, CUDA, and cuDNN versions
   - Install the exact versions specified in TensorFlow documentation

2. **Out of Memory Errors**:
   - Reduce batch size
   - Use gradient accumulation
   - Enable memory growth:
   ```python
   physical_devices = tf.config.list_physical_devices('GPU') 
   tf.config.experimental.set_memory_growth(physical_devices[0], True)
   ```

### PyTorch Issues

1. **CUDA Unavailable**:
   - Check CUDA installation with `nvcc --version`
   - Verify that PyTorch was installed with CUDA support
   - Check PyTorch and CUDA version compatibility

2. **Out of Memory Errors**:
   - Reduce batch size
   - Free up memory manually:
   ```python
   torch.cuda.empty_cache()
   ```
   - Move unused tensors to CPU or delete them

### General Issues

1. **Dependency Conflicts**:
   - Use separate environments for different projects
   - Specify versions precisely when installing packages
   - Use `pip freeze > requirements.txt` to document working environments

2. **Performance Problems**:
   - Check GPU utilization with `nvidia-smi`
   - Monitor memory usage with system tools or framework utilities
   - Optimize data loading pipelines
