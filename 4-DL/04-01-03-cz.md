## Úvod

Frameworky pro hluboké učení poskytují základní stavební bloky pro návrh, trénování a validaci hlubokých neuronových sítí. Dva nejpopulárnější frameworky v současnosti jsou TensorFlow (vyvinutý společností Google) a PyTorch (vyvinutý výzkumnou laboratoří Facebook AI Research). Každý z nich má své vlastní přednosti, ekosystém a syntaxi.

- **TensorFlow** nabízí komplexní ekosystém pro strojové učení s nástroji jako TensorBoard pro vizualizaci a TensorFlow Extended (TFX) pro produkční pipeline.

- **PyTorch** je známý svým dynamickým výpočetním grafem, intuitivním designem a přístupem ve stylu Pythonu, což ho činí oblíbeným mezi výzkumníky.

Tento průvodce vám pomůže nastavit oba frameworky a připravit vaše prostředí pro vývoj hlubokého učení.

## Systémové požadavky

Před instalací se ujistěte, že váš systém splňuje tyto požadavky:

- **Python**: Oba frameworky vyžadují Python 3.7+ (aktuální k roku 2023)
- **CPU**: Jakýkoli moderní vícejádrový procesor (Intel nebo AMD)
- **RAM**: Minimálně 8 GB (doporučeno 16 GB+ pro větší modely)
- **Úložiště**: 5 GB+ volného místa pro instalace frameworků a závislosti
- **GPU** (volitelné, ale doporučené): NVIDIA GPU s podporou CUDA

## Ověření instalace

Vytvořte komplexní testovací skript pro ověření TensorFlow i PyTorch:

```python
# test_dl_setup.py

import sys
print(f"Verze Pythonu: {sys.version}")

# Test TensorFlow
try:
    import tensorflow as tf
    print(f"\nVerze TensorFlow: {tf.__version__}")
    
    # Kontrola dostupnosti GPU
    gpus = tf.config.list_physical_devices('GPU')
    if gpus:
        print(f"TensorFlow má přístup k {len(gpus)} GPU:")
        for gpu in gpus:
            print(f"  - {gpu}")
        
        # Test GPU s jednoduchým výpočtem
        with tf.device('/GPU:0'):
            a = tf.constant([[1.0, 2.0], [3.0, 4.0]])
            b = tf.constant([[5.0, 6.0], [7.0, 8.0]])
            c = tf.matmul(a, b)
        print(f"Výsledek násobení matic: \n{c}")
    else:
        print("TensorFlow nemá přístup k žádnému GPU. Používá CPU.")
except ImportError:
    print("TensorFlow není nainstalován.")

# Test PyTorch
try:
    import torch
    print(f"\nVerze PyTorch: {torch.__version__}")
    
    # Kontrola dostupnosti GPU
    if torch.cuda.is_available():
        device_count = torch.cuda.device_count()
        print(f"PyTorch má přístup k {device_count} GPU:")
        for i in range(device_count):
            print(f"  - {torch.cuda.get_device_name(i)}")
        
        # Test GPU s jednoduchým výpočtem
        device = torch.device("cuda:0")
        a = torch.tensor([[1.0, 2.0], [3.0, 4.0]], device=device)
        b = torch.tensor([[5.0, 6.0], [7.0, 8.0]], device=device)
        c = torch.matmul(a, b)
        print(f"Výsledek násobení matic: \n{c}")
    else:
        print("PyTorch nemá přístup k žádnému GPU. Používá CPU.")
except ImportError:
    print("PyTorch není nainstalován.")
```

## Základní příklady

### Příklad TensorFlow: Trénování jednoduché neuronové sítě

```python
import tensorflow as tf
from tensorflow.keras import layers, models
import numpy as np

# Vytvoření jednoduchého datasetu
X_train = np.random.random((1000, 20))
y_train = np.random.randint(2, size=(1000, 1))
X_test = np.random.random((300, 20))
y_test = np.random.randint(2, size=(300, 1))

# Vytvoření jednoduchého modelu
model = models.Sequential([
    layers.Dense(64, activation='relu', input_shape=(20,)),
    layers.Dropout(0.2),
    layers.Dense(32, activation='relu'),
    layers.Dropout(0.2),
    layers.Dense(1, activation='sigmoid')
])

# Kompilace modelu
model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy'])

# Zobrazení architektury modelu
model.summary()

# Trénování modelu
history = model.fit(X_train, y_train, epochs=10, 
                    batch_size=32, validation_split=0.2)

# Evaluace modelu
test_loss, test_acc = model.evaluate(X_test, y_test)
print(f"Testovací přesnost: {test_acc:.3f}")
```

### Příklad PyTorch: Trénování jednoduché neuronové sítě

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# Kontrola dostupnosti GPU
device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")
print(f"Používané zařízení: {device}")

# Vytvoření jednoduchého datasetu
X_train = torch.FloatTensor(np.random.random((1000, 20))).to(device)
y_train = torch.FloatTensor(np.random.randint(2, size=(1000, 1))).to(device)
X_test = torch.FloatTensor(np.random.random((300, 20))).to(device)
y_test = torch.FloatTensor(np.random.randint(2, size=(300, 1))).to(device)

# Definice modelu
class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.layers = nn.Sequential(
            nn.Linear(20, 64),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, 1),
            nn.Sigmoid()
        )
        
    def forward(self, x):
        return self.layers(x)

# Vytvoření instance modelu
model = SimpleNN().to(device)

# Definice ztrátové funkce a optimalizátoru
criterion = nn.BCELoss()
optimizer = optim.Adam(model.parameters())

# Trénování modelu
num_epochs = 10
batch_size = 32
num_samples = X_train.shape[0]
num_batches = num_samples // batch_size

for epoch in range(num_epochs):
    model.train()
    running_loss = 0.0
    
    for i in range(num_batches):
        # Získání mini-batch
        indices = torch.randperm(num_samples)[:batch_size]
        X_batch, y_batch = X_train[indices], y_train[indices]
        
        # Dopředný průchod
        optimizer.zero_grad()
        outputs = model(X_batch)
        loss = criterion(outputs, y_batch)
        
        # Zpětný průchod a optimalizace
        loss.backward()
        optimizer.step()
        
        running_loss += loss.item()
    
    # Výpis statistik
    print(f'Epocha {epoch+1}/{num_epochs}, Ztráta: {running_loss/num_batches:.4f}')

# Evaluace modelu
model.eval()
with torch.no_grad():
    y_pred = model(X_test)
    test_loss = criterion(y_pred, y_test).item()
    correct = ((y_pred > 0.5).float() == y_test).float().sum()
    accuracy = correct / y_test.shape[0]
    print(f'Testovací ztráta: {test_loss:.4f}, Přesnost: {accuracy:.4f}')
```

## Řešení běžných problémů

### Problémy s TensorFlow

1. **GPU není detekováno**:
   - Ověřte instalaci CUDA a cuDNN
   - Zkontrolujte kompatibilitu mezi verzemi TensorFlow, CUDA a cuDNN
   - Nainstalujte přesné verze uvedené v dokumentaci TensorFlow

2. **Chyby nedostatku paměti**:
   - Snižte velikost dávky (batch size)
   - Použijte akumulaci gradientů
   - Povolte růst paměti:
   ```python
   physical_devices = tf.config.list_physical_devices('GPU') 
   tf.config.experimental.set_memory_growth(physical_devices[0], True)
   ```

### Problémy s PyTorch

1. **CUDA není dostupná**:
   - Zkontrolujte instalaci CUDA pomocí `nvcc --version`
   - Ověřte, že PyTorch byl nainstalován s podporou CUDA
   - Zkontrolujte kompatibilitu verzí PyTorch a CUDA

2. **Chyby nedostatku paměti**:
   - Snižte velikost dávky
   - Uvolněte paměť ručně:
   ```python
   torch.cuda.empty_cache()
   ```
   - Přesuňte nepoužívané tenzory na CPU nebo je odstraňte

### Obecné problémy

1. **Konflikty závislostí**:
   - Používejte oddělená prostředí pro různé projekty
   - Specifikujte verze přesně při instalaci balíčků
   - Použijte `pip freeze > requirements.txt` pro dokumentaci fungujících prostředí

2. **Problémy s výkonem**:
   - Kontrolujte využití GPU s `nvidia-smi`
   - Monitorujte využití paměti systémovými nástroji nebo nástroji frameworku
   - Optimalizujte datové pipelines
