## Úvod do slovních embeddingů

Slovní embeddingy jsou husté vektorové reprezentace slov v kontinuálním vektorovém prostoru, kde jsou sémanticky podobná slova mapována do blízkých bodů. Na rozdíl od tradičního one-hot kódování, které reprezentuje slova jako řídké vektory, slovní embeddingy zachycují smysluplné sémantické vztahy mezi slovy.

**Klíčové výhody slovních embeddingů:**
- Zachycují sémantické vztahy mezi slovy
- Umožňují matematické operace se slovy (např. král - muž + žena = královna)
- Snižují dimenzionalitu ve srovnání s one-hot kódováním
- Umožňují transfer learning v úlohách zpracování přirozeného jazyka

### Od One-Hot kódování k embeddingům

## Modely Word2Vec a GloVe

Dva nejpopulárnější algoritmy pro slovní embeddingy jsou Word2Vec (vyvinutý Googlem) a GloVe (Globální vektory pro reprezentaci slov, vyvinuté na Stanfordu).

### Word2Vec

Word2Vec používá dvě hlavní architektury:
- **CBOW (Continuous Bag of Words)**: Předpovídá aktuální slovo na základě okolních kontextových slov
- **Skip-gram**: Předpovídá okolní kontextová slova na základě aktuálního slova

```python
import gensim.downloader as api

# Příprava korpusu

# Trénování Word2Vec modelu
model = Word2Vec(sentences=sentences, vector_size=100, window=5, min_count=5, workers=4)

print("Slova nejpodobnější slovu 'happy':")
for word, score in similar_words:
    print(f"{word}: {score:.4f}")

    print(f"{word}: {score:.4f}")
```

### Model GloVe

GloVe se učí slovní embeddingy využitím globálních statistik společného výskytu slov.

```python
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity
import requests
import zipfile
import io
import os

def download_glove_embeddings(dimension=50):
    """Stáhnutí předtrénovaných GloVe embeddingů"""
    url = f"https://nlp.stanford.edu/data/glove.6B.{dimension}d.zip"
    r = requests.get(url)
    z = zipfile.ZipFile(io.BytesIO(r.content))
    z.extractall()
    return f"glove.6B.{dimension}d.txt"

def load_glove_embeddings(filename, vocab_size=100000):
    """Načtení GloVe embeddingů ze souboru"""
    embeddings = {}
    with open(filename, 'r', encoding='utf-8') as f:
        for i, line in enumerate(f):
            if i >= vocab_size:
                break
            values = line.split()
            word = values[0]
            vector = np.asarray(values[1:], dtype='float32')
            embeddings[word] = vector
    return embeddings

# Stažení a načtení embeddingů (odkomentujte pro spuštění)
# glove_file = download_glove_embeddings(50)
# embeddings = load_glove_embeddings(glove_file, vocab_size=10000)

# Pro demonstraci vytvoříme ukázkový slovník embeddingů
embeddings = {
    "king": np.random.rand(50),
    "queen": np.random.rand(50),
    "man": np.random.rand(50),
    "woman": np.random.rand(50),
    "paris": np.random.rand(50),
    "france": np.random.rand(50),
    "rome": np.random.rand(50),
    "italy": np.random.rand(50)
}

# Funkce pro hledání nejbližších slov
def find_closest_words(embeddings, word_vector, n=3):
    similarities = {}
    for word, vector in embeddings.items():
        similarity = cosine_similarity([word_vector], [vector])[0][0]
        similarities[word] = similarity
    return sorted(similarities.items(), key=lambda x: x[1], reverse=True)[:n]

# Test analogií
def analogy(embeddings, a, b, c, n=3):
    # a je pro b jako c je pro ?
    a_vec = embeddings.get(a)
    b_vec = embeddings.get(b)
    c_vec = embeddings.get(c)
    
    if a_vec is None or b_vec is None or c_vec is None:
        return f"Jedno nebo více slov není ve slovníku: {a}, {b}, {c}"
    
    # d = b - a + c
    d_vec = b_vec - a_vec + c_vec
    
    result = find_closest_words(embeddings, d_vec, n+3)
    # Filtrování vstupních slov
    result = [r for r in result if r[0] not in [a, b, c]][:n]
    return result

# Test některých analogií
print("king : queen :: man : ?")
result = analogy(embeddings, "king", "queen", "man")
for word, score in result:
    print(f"{word}: {score:.4f}")

print("\nparis : france :: rome : ?")
result = analogy(embeddings, "paris", "france", "rome")
for word, score in result:
    print(f"{word}: {score:.4f}")
```

## Použití předtrénovaných slovních embeddingů

Předtrénované slovní embeddingy umožňují využít embeddingy natrénované na velkých textových korpusech bez nutnosti trénovat vlastní.

```python

import tensorflow as tf
import torch
import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import PCA

# Získání vektorů slov
words = ['king', 'queen', 'man', 'woman', 'doctor', 'nurse', 'computer', 'keyboard']
word_vectors = {word: nlp(word).vector for word in words if word in nlp.vocab}

# Použití PCA pro redukci na 2 dimenze pro vizualizaci
pca = PCA(n_components=2)
vectors_2d = pca.fit_transform(np.array(list(word_vectors.values())))

# Vykreslení vektorů
plt.figure(figsize=(10, 8))
for i, word in enumerate(word_vectors.keys()):
    plt.scatter(vectors_2d[i, 0], vectors_2d[i, 1], s=100)
    plt.annotate(word, (vectors_2d[i, 0] + 0.01, vectors_2d[i, 1] + 0.01), fontsize=12)

plt.title('2D PCA projekce slovních embeddingů')
plt.grid(True)
plt.show()

# 2. Použití předtrénovaných embeddingů v TensorFlow/Keras
def load_glove_embeddings_for_keras(embedding_dim=100, vocab_size=10000):
    # Toto je zástupný kód - v reálném případě byste načítali skutečné embeddingy
    # embeddings_index = {...}  # slovník mapování slovo -> embedding
    
    # Pro tento příklad vytvoříme náhodné embeddingy
    words = ['<PAD>', '<UNK>'] + [f'word{i}' for i in range(vocab_size-2)]
    embeddings_index = {word: np.random.randn(embedding_dim) for word in words}
    
    return embeddings_index, words

# Vytvoření Embedding vrstvy s předtrénovanými váhami
embedding_dim = 100
vocab_size = 1000
embeddings_index, words = load_glove_embeddings_for_keras(embedding_dim, vocab_size)

# Vytvoření slovníku slov (mapování slovo -> index)
word_index = {word: i for i, word in enumerate(words)}

# Vytvoření embedding matice
embedding_matrix = np.zeros((vocab_size, embedding_dim))
for word, i in word_index.items():
    embedding_vector = embeddings_index.get(word)
    if embedding_vector is not None:
        embedding_matrix[i] = embedding_vector

# Vytvoření embedding vrstvy s předtrénovanými váhami
embedding_layer = tf.keras.layers.Embedding(
    input_dim=vocab_size,
    output_dim=embedding_dim,
    weights=[embedding_matrix],
    trainable=False  # Ponechat předtrénované embeddingy fixní
)

# 3. Použití předtrénovaných embeddingů v PyTorch
embedding_layer_torch = torch.nn.Embedding.from_pretrained(
    torch.FloatTensor(embedding_matrix),
    freeze=True  # Ponechat předtrénované embeddingy fixní
)
```

## Úvod do jazykových modelů

Jazykové modely jsou statistické modely, které předpovídají pravděpodobnost sekvencí slov. Jsou základem mnoha úloh zpracování přirozeného jazyka, jako je strojový překlad, rozpoznávání řeči, generování textu a další.

```python
import numpy as np
import re
import random
from collections import defaultdict, Counter

# Jednoduchý ukázkový text pro demonstraci
text = """
Natural language processing is a field of artificial intelligence. 
Artificial intelligence is changing the world.
The world is becoming more connected through technology.
Technology helps humans solve complex problems.
Humans develop new artificial intelligence systems.
"""

# Čištění a tokenizace textu
def preprocess(text):
    text = text.lower()
    text = re.sub(r'\s+', ' ', text)
    sentences = re.split(r'[.!?]', text)
    sentences = [s.strip() for s in sentences if s.strip()]
    tokens_list = [sentence.split() for sentence in sentences]
    return tokens_list

tokenized_sentences = preprocess(text)

# Podívejme se na naše zpracovaná data
print("Ukázka tokenizovaných vět:")
for i, sentence in enumerate(tokenized_sentences[:3]):
    print(f"{i+1}. {' '.join(sentence)}")

print("\nCelkový počet vět:", len(tokenized_sentences))

# Vytvoření slovníku
vocabulary = set()
for sentence in tokenized_sentences:
    vocabulary.update(sentence)

print(f"\nVelikost slovníku: {len(vocabulary)}")
print(f"Slovník: {', '.join(sorted(list(vocabulary)))}")
```

## N-gramové jazykové modely

N-gramové jazykové modely předpovídají následující slovo na základě předchozích N-1 slov.

```python
from collections import defaultdict
import random
import numpy as np

# Vytvoření n-gramových jazykových modelů
def build_ngram_model(sentences, n=2):
    # Inicializace počítadel
    ngram_counts = defaultdict(Counter)
    context_counts = defaultdict(int)
    
    # Přidání počátečních a koncových tokenů
    padded_sentences = []
    for sentence in sentences:
        padded_sentence = ['<s>'] * (n-1) + sentence + ['</s>']
        padded_sentences.append(padded_sentence)
    
    # Počítání n-gramů
    for sentence in padded_sentences:
        for i in range(len(sentence) - n + 1):
            ngram = tuple(sentence[i:i+n])
            context = tuple(sentence[i:i+n-1])
            next_word = sentence[i+n-1]
            
            ngram_counts[context][next_word] += 1
            context_counts[context] += 1
    
    # Převod na pravděpodobnosti
    ngram_probs = defaultdict(dict)
    for context, next_word_counts in ngram_counts.items():
        for next_word, count in next_word_counts.items():
            ngram_probs[context][next_word] = count / context_counts[context]
    
    return ngram_probs

# Generování textu pomocí n-gramového modelu
def generate_text(model, n=2, max_length=20, seed=None):
    # Začneme s n-1 počátečními tokeny
    if seed:
        text = seed.lower().split()
        # Ujistíme se, že seed má n-1 tokenů
        if len(text) < n-1:
            text = ['<s>'] * (n-1)
        else:
            text = text[-(n-1):]
    else:
        text = ['<s>'] * (n-1)
    
    # Generování textu
    for _ in range(max_length):
        context = tuple(text[-(n-1):])
        
        if context not in model:
            break
            
        next_word_probs = model[context]
        next_word_candidates = list(next_word_probs.keys())
        next_word_probabilities = list(next_word_probs.values())
        
        next_word = np.random.choice(next_word_candidates, p=next_word_probabilities)
        
        if next_word == '</s>':
            break
            
        text.append(next_word)
    
    return ' '.join(text[n-1:])  # Odstranění počátečních tokenů

# Vytvoření bigramových a trigramových modelů
bigram_model = build_ngram_model(tokenized_sentences, n=2)
trigram_model = build_ngram_model(tokenized_sentences, n=3)

# Generování textu pomocí modelů
print("Text generovaný bigramovým modelem:")
for _ in range(3):
    print(generate_text(bigram_model, n=2, max_length=10))

print("\nText generovaný trigramovým modelem:")
for _ in range(3):
    print(generate_text(trigram_model, n=3, max_length=10))

# Hodnocení pravděpodobností pro konkrétní sekvence
def evaluate_sequence_probability(model, sequence, n=2):
    words = ['<s>'] * (n-1) + sequence.lower().split() + ['</s>']
    log_prob = 0
    
    for i in range(len(words) - n + 1):
        context = tuple(words[i:i+n-1])
        next_word = words[i+n-1]
        
        if context in model and next_word in model[context]:
            probability = model[context][next_word]
            log_prob += np.log(probability)
        else:
            return float('-inf')  # Neviděný n-gram
    
    return log_prob

test_sequences = [
    "artificial intelligence is changing",
    "intelligence artificial changing is",
    "technology helps humans"
]

print("\nHodnocení pravděpodobností sekvencí trigramovým modelem:")
for sequence in test_sequences:
    log_prob = evaluate_sequence_probability(trigram_model, sequence, n=3)
    if log_prob == float('-inf'):
        print(f"'{sequence}' obsahuje neviděné trigramy")
    else:
        print(f"'{sequence}' pravděpodobnost (log): {log_prob:.4f}")
```

## Neuronové jazykové modely

Neuronové jazykové modely používají neuronové sítě pro modelování pravděpodobnosti sekvencí slov, čímž překonávají mnohá omezení n-gramových modelů.

```python
import tensorflow as tf
from tensorflow.keras.preprocessing.text import Tokenizer
from tensorflow.keras.preprocessing.sequence import pad_sequences
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Embedding, LSTM, Dense, Dropout

# Vzorová textová data (v reálné aplikaci byste použili mnohem více dat)
text = """
Natural language processing is a field of artificial intelligence.
Artificial intelligence is changing the world.
The world is becoming more connected through technology.
Technology helps humans solve complex problems.
Humans develop new artificial intelligence systems.
Language models are fundamental to natural language processing.
Deep learning has revolutionized artificial intelligence.
Machine learning is a subset of artificial intelligence.
"""

# Předzpracování textu pro neuronový jazykový model
def preprocess_for_neural_lm(text):
    # Rozdělení na věty
    sentences = re.split(r'[.!?]', text)
    sentences = [s.strip() for s in sentences if s.strip()]
    
    # Tokenizace (v reálné aplikaci byste použili sofistikovanější tokenizátor)
    tokenized_sentences = [sentence.lower().split() for sentence in sentences]
    
    return tokenized_sentences

sentences = preprocess_for_neural_lm(text)

# Vytvoření trénovacích dat: pro každé slovo předpovíme následující slovo
input_sequences = []
for sentence in sentences:
    # Vytvoření trigramů (x0, x1) -> x2, (x1, x2) -> x3, atd.
    for i in range(2, len(sentence)):
        input_sequences.append(sentence[i-2:i+1])

# Tokenizace slov
tokenizer = Tokenizer()
tokenizer.fit_on_texts([word for sentence in sentences for word in sentence])
total_words = len(tokenizer.word_index) + 1

# Převod sekvencí na indexy tokenů
tokenized_sequences = []
for seq in input_sequences:
    tokenized_seq = tokenizer.texts_to_sequences([seq])[0]
    tokenized_sequences.append(tokenized_seq)

# Definice vstupu (x) a výstupu (y)
X = []
y = []
for seq in tokenized_sequences:
    X.append(seq[:-1])  # Všechna slova kromě posledního
    y.append(seq[-1])   # Pouze poslední slovo

# Převod na numpy pole a doplnění sekvencí
max_sequence_len = max(len(seq) for seq in X)
X = pad_sequences(X, maxlen=max_sequence_len)
y = tf.keras.utils.to_categorical(y, num_classes=total_words)

# Vytvoření jednoduchého neuronového jazykového modelu
embedding_dim = 50
model = Sequential([
    Embedding(total_words, embedding_dim, input_length=max_sequence_len),
    LSTM(100),
    Dropout(0.2),
    Dense(total_words, activation='softmax')
])

model.compile(
    loss='categorical_crossentropy',
    optimizer='adam',
    metrics=['accuracy']
)

# Zobrazení architektury modelu
model.summary()

# V reálné aplikaci byste model natrénovali
# model.fit(X, y, epochs=100, batch_size=4, verbose=1)

# Funkce pro generování textu pomocí neuronového jazykového modelu
def generate_text_neural_lm(seed_text, next_words, model, tokenizer, max_sequence_len):
    # Poznámka: V reálné aplikaci s natrénovaným modelem by toto fungovalo
    # Pouze pro demonstraci
    input_text = seed_text.lower().split()
    
    for _ in range(next_words):
        # Tokenizace a doplnění vstupní sekvence
        token_list = tokenizer.texts_to_sequences([input_text[-max_sequence_len:]])[0]
        token_list = pad_sequences([token_list], maxlen=max_sequence_len)
        
        # Předpověď dalšího slova
        predicted = model.predict(token_list, verbose=0)
        predicted_word_index = tf.argmax(predicted, axis=1).numpy()[0]
        
        # Převod indexu slova zpět na slovo
        output_word = ""
        for word, index in tokenizer.word_index.items():
            if index == predicted_word_index:
                output_word = word
                break
        
        # Přidání předpovězeného slova ke vstupnímu textu
        input_text.append(output_word)
    
    return ' '.join(input_text)
```

## Metriky pro hodnocení jazykových modelů

Mezi běžné metriky pro hodnocení jazykových modelů patří perplexita, BLEU skóre a další úlohově specifické metriky.

```python
import numpy as np
from nltk.translate.bleu_score import sentence_bleu, SmoothingFunction
import math

# Výpočet perplexity jazykového modelu
def calculate_perplexity(model, test_sentences, n=2):
    total_log_prob = 0
    total_words = 0
    
    for sentence in test_sentences:
        padded_sentence = ['<s>'] * (n-1) + sentence + ['</s>']
        
        for i in range(n-1, len(padded_sentence)):
            context = tuple(padded_sentence[i-(n-1):i])
            word = padded_sentence[i]
            
            # Výpočet pravděpodobnosti tohoto slova v daném kontextu
            if context in model and word in model[context]:
                probability = model[context][word]
                total_log_prob += math.log2(probability)
            else:
                # Vyhlazení pro neviděné n-gramy (jednoduché add-1 vyhlazení pro demonstraci)
                # V praxi byste použili sofistikovanější vyhlazení
                probability = 1 / (len(model) + 1)  # Neviděný n-gram
                total_log_prob += math.log2(probability)
            
            total_words += 1
    
    # Výpočet perplexity
    perplexity = 2 ** (-total_log_prob / total_words)
    return perplexity

# Výpočet BLEU skóre pro generovaný text
def calculate_bleu(reference, candidate):
    # Aplikace vyhlazení pro krátké sekvence
    smoothie = SmoothingFunction().method1
    return sentence_bleu([reference], candidate, smoothing_function=smoothie)

# Test výpočtu perplexity

    ['artificial', 'intelligence', 'is', 'changing', 'the', 'world'],
    ['technology', 'helps', 'humans', 'solve', 'problems']
]
```

```python
def generate_text_with_seed(model, tokenizer, seed_text, max_length=20):
    # Poznámka: Toto vyžaduje natrénovaný model pro správné fungování
    # Pouze pro demonstrační účely
```

## Shrnutí

Slovní embeddingy a jazykové modely jsou základními komponenty moderního zpracování přirozeného jazyka:

1. **Slovní embeddingy** zachycují sémantické vztahy mezi slovy jejich reprezentací jako husté vektory v kontinuálním prostoru, což nabízí významné výhody oproti tradičnímu one-hot kódování.

2. **Word2Vec** a **GloVe** jsou populární algoritmy pro vytváření slovních embeddingů, přičemž Word2Vec používá prediktivní metody (CBOW a Skip-gram) a GloVe využívá globální statistiky společných výskytů slov.

3. **Předtrénované embeddingy** umožňují transfer learning v NLP poskytnutím hotových slovních reprezentací natrénovaných na velkých textových korpusech, které lze použít přímo nebo doladit pro specifické úlohy.

4. **Vlastní embeddingy** lze trénovat pro doménově specifické aplikace k zachycení specializovaných sémantických vztahů, které nejsou reflektovány v obecných embeddingách.

5. **Jazykové modely** předpovídají pravděpodobnost sekvencí slov a slouží jako základ mnoha NLP úloh, od generování textu po strojový překlad.

6. **N-gramové modely** používají jednoduché statistiky četnosti k předpovědi dalšího slova na základě předchozích N-1 slov, ale potýkají se s řídkostí dat a omezeními při zachycení dlouhodobých závislostí.

7. **Neuronové jazykové modely** překonávají mnohá omezení n-gramových modelů použitím neuronových sítí k učení distribuovaných reprezentací a zachycení složitějších vzorů.

8. **Metriky hodnocení** jako perplexita a BLEU skóre pomáhají posoudit kvalitu jazykových modelů pro různé aplikace.

9. **Aplikace** slovních embeddingů a jazykových modelů zahrnují mnoho NLP úloh, včetně analýzy sentimentu, generování textu, klasifikace dokumentů a rozpoznávání pojmenovaných entit.

Slovní embeddingy a jazykové modely způsobily revoluci v NLP tím, že umožnily strojům vyvinout jemnější porozumění lidskému jazyku a tvoří stavební bloky pro stále sofistikovanější jazykové technologie. Nedávné pokroky v modelech založených na transformerech (jako BERT a GPT) staví na těchto základech a posouvají hranice možností v porozumění a generování přirozeného jazyka.
