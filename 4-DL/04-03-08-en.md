## 1. Introduction to Model Compression

Model compression is essential for deploying deep learning models on resource-constrained devices like mobile phones, embedded systems, and edge devices. Without compression, modern deep learning models can be too large and computationally intensive for practical deployment.

Key benefits of model compression include:

- Reduced model size for easier distribution and storage
- Decreased memory footprint during inference
- Lower computational requirements and faster inference
- Reduced energy consumption
- Enabling deployment on resource-limited hardware

## 2. Fundamentals of Quantization

Quantization reduces the precision of numerical representations in a neural network, typically from 32-bit floating-point to lower bit-width formats like 16-bit, 8-bit, or even 4-bit and 1-bit (binary) values. This significantly reduces memory requirements and can accelerate computation.

### Types of Quantization

1. **Weight Quantization**: Reduces only the model parameters
2. **Activation Quantization**: Reduces the intermediate activations
3. **Full Quantization**: Reduces both weights and activations

```python
# Example of manual quantization implementation
def simple_quantization(tensor, num_bits=8):
    """Quantize a tensor to specified number of bits"""
    # Calculate the range of the tensor
    tensor_min = tf.reduce_min(tensor)
    tensor_max = tf.reduce_max(tensor)
    
    # Calculate step size (scale)
    step = (tensor_max - tensor_min) / (2**num_bits - 1)
    
    # Quantize the tensor
    quantized_tensor = tf.round((tensor - tensor_min) / step)
    
    # Convert back to original range (dequantization for storage)
    dequantized_tensor = quantized_tensor * step + tensor_min
    
    return quantized_tensor, dequantized_tensor, step, tensor_min

# Create a sample tensor
original_tensor = tf.random.normal([5, 5])
print("Original tensor:")
print(original_tensor.numpy())

# Quantize to 8 bits
quantized, dequantized, step, min_val = simple_quantization(original_tensor, 8)
print("\nQuantized tensor (8-bit):")
print(quantized.numpy())

print("\nDequantized tensor (reconstructed from 8-bit):")
print(dequantized.numpy())

# Calculate quantization error
error = tf.reduce_mean(tf.abs(original_tensor - dequantized))
print(f"\nAverage quantization error: {error.numpy():.6f}")
```

## 3. Post-Training Quantization

Post-training quantization (PTQ) applies quantization to an already trained model without retraining. It's the simplest approach to model compression and works well for many applications.

### TensorFlow Example

```python
# TensorFlow post-training quantization example
import tensorflow as tf

# Load a pre-trained model (using MobileNetV2 as an example)
base_model = tf.keras.applications.MobileNetV2(
    input_shape=(224, 224, 3),
    include_top=True,
    weights='imagenet'
)

# Convert to a TensorFlow Lite model
converter = tf.lite.TFLiteConverter.from_keras_model(base_model)

# Apply default post-training quantization
converter.optimizations = [tf.lite.Optimize.DEFAULT]

# Define a representative dataset for calibration
def representative_dataset():
    for _ in range(100):
        data = np.random.rand(1, 224, 224, 3) * 255
        yield [data.astype(np.float32)]

# Apply full integer quantization
converter.representative_dataset = representative_dataset
converter.target_spec.supported_ops = [tf.lite.OpsSet.TFLITE_BUILTINS_INT8]
converter.inference_input_type = tf.int8
converter.inference_output_type = tf.int8

# Convert the model
quantized_model = converter.convert()

# Save the model
with open('mobilenet_v2_quantized.tflite', 'wb') as f:
    f.write(quantized_model)

# Show model size comparison
original_size = os.path.getsize('mobilenet_v2_original.tflite') / (1024 * 1024)
quantized_size = os.path.getsize('mobilenet_v2_quantized.tflite') / (1024 * 1024)

print(f"Original model size: {original_size:.2f} MB")
print(f"Quantized model size: {quantized_size:.2f} MB")
print(f"Compression ratio: {original_size / quantized_size:.2f}x")
```

## 4. Quantization-Aware Training

Quantization-aware training (QAT) simulates the effects of quantization during training, allowing the model to adapt to the reduced precision. This typically produces better results than post-training quantization, especially for lower bit-widths.

```python
# TensorFlow Quantization-Aware Training
import tensorflow as tf
import tensorflow_model_optimization as tfmot

# Create a simple model
def create_model():
    model = tf.keras.Sequential([
        tf.keras.layers.Conv2D(32, 3, activation='relu', input_shape=(28, 28, 1)),
        tf.keras.layers.MaxPooling2D(),
        tf.keras.layers.Conv2D(64, 3, activation='relu'),
        tf.keras.layers.MaxPooling2D(),
        tf.keras.layers.Flatten(),
        tf.keras.layers.Dense(128, activation='relu'),
        tf.keras.layers.Dense(10)
    ])
    return model

# Load MNIST dataset
mnist = tf.keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0
x_train = x_train[..., tf.newaxis]
x_test = x_test[..., tf.newaxis]

# Create and compile base model
base_model = create_model()
base_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

# Apply quantization aware training
quantize_model = tfmot.quantization.keras.quantize_model

# Create quantization aware model
q_aware_model = quantize_model(base_model)

# Compile and train quantization aware model
q_aware_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

q_aware_model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=2,
    validation_data=(x_test, y_test)
)

# Convert to TensorFlow Lite model
converter = tf.lite.TFLiteConverter.from_keras_model(q_aware_model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
quantized_tflite_model = converter.convert()

# Save the model
with open('mnist_quantized.tflite', 'wb') as f:
    f.write(quantized_tflite_model)
```

## 5. Model Pruning Techniques

Pruning removes unnecessary parameters from deep learning models by setting weights that contribute little to the output to zero. This reduces model size and can improve computational efficiency.

### Weight Magnitude Pruning

```python
# TensorFlow Pruning Example
import tensorflow as tf
import tensorflow_model_optimization as tfmot

# Create a simple model
def create_model():
    model = tf.keras.Sequential([
        tf.keras.layers.Dense(128, activation='relu', input_shape=(784,)),
        tf.keras.layers.Dense(64, activation='relu'),
        tf.keras.layers.Dense(10)
    ])
    return model

# Load MNIST dataset
mnist = tf.keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0
x_train = x_train.reshape(-1, 784).astype('float32')
x_test = x_test.reshape(-1, 784).astype('float32')

# Define pruning parameters
pruning_params = {
    'pruning_schedule': tfmot.sparsity.keras.PolynomialDecay(
        initial_sparsity=0.0,
        final_sparsity=0.50,
        begin_step=0,
        end_step=1000
    )
}

# Create and compile base model
model = create_model()

# Apply pruning
pruned_model = tfmot.sparsity.keras.prune_low_magnitude(model, **pruning_params)

# Compile pruned model
pruned_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

# Create pruning callbacks
callbacks = [
    tfmot.sparsity.keras.UpdatePruningStep(),
    tfmot.sparsity.keras.PruningSummaries(log_dir='logs'),
]

# Train pruned model
pruned_model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=2,
    validation_data=(x_test, y_test),
    callbacks=callbacks
)

# Convert to a fully-quantized TF Lite model
converter = tf.lite.TFLiteConverter.from_keras_model(pruned_model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
pruned_quantized_tflite_model = converter.convert()

# Save the model
with open('mnist_pruned_quantized.tflite', 'wb') as f:
    f.write(pruned_quantized_tflite_model)

# Evaluate the models
original_model = create_model()
original_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

original_model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=2,
    validation_data=(x_test, y_test)
)

print("Original Model Accuracy:", original_model.evaluate(x_test, y_test)[1])
print("Pruned Model Accuracy:", pruned_model.evaluate(x_test, y_test)[1])
```

### PyTorch Pruning Example

```python
# PyTorch pruning example
import torch
import torch.nn as nn
import torch.optim as optim
import torchvision
import torchvision.transforms as transforms

# Define a simple model
class SimpleNet(nn.Module):
    def __init__(self):
        super(SimpleNet, self).__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        
    def forward(self, x):
        x = x.view(-1, 784)
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        x = self.fc3(x)
        return x

# Create the model
model = SimpleNet()

# Function to apply weight pruning based on magnitude
def prune_model(model, pruning_percent):
    # Get all weights
    weights = []
    for name, param in model.named_parameters():
        if 'weight' in name:
            tensor = param.data.cpu().numpy()
            weights.extend(np.abs(tensor.flatten()))
    
    # Determine pruning threshold
    threshold = np.percentile(weights, pruning_percent)
    
    # Apply pruning
    for name, param in model.named_parameters():
        if 'weight' in name:
            mask = torch.abs(param.data) > threshold
            param.data = param.data * mask
    
    return model

# Apply 50% pruning
pruned_model = prune_model(model, 50)

# Count non-zero parameters before and after pruning
def count_parameters(model):
    total_params = 0
    non_zero_params = 0
    for param in model.parameters():
        total_params += param.numel()
        non_zero_params += (param != 0).sum().item()
    return total_params, non_zero_params

total, non_zero = count_parameters(pruned_model)
print(f"Total parameters: {total}")
print(f"Non-zero parameters: {non_zero}")
print(f"Compression ratio: {total/max(1, non_zero):.2f}x")
print(f"Sparsity: {(total-non_zero)/total*100:.2f}%")
```

## 6. Knowledge Distillation

Knowledge distillation transfers knowledge from a large "teacher" model to a smaller "student" model. The student model learns to mimic the output distribution of the teacher, not just the predicted class.

```python
# Knowledge distillation with TensorFlow
import tensorflow as tf
import numpy as np

# Temperature parameter for softening probability distributions
temperature = 3.0

# Define loss function for knowledge distillation
def knowledge_distillation_loss(y_true, y_pred, teacher_logits, temperature, alpha=0.1):
    # Standard cross-entropy loss
    student_loss = tf.keras.losses.sparse_categorical_crossentropy(
        y_true, y_pred, from_logits=True)
    
    # Soft targets from teacher (with temperature scaling)
    teacher_probs = tf.nn.softmax(teacher_logits / temperature)
    student_probs = tf.nn.softmax(y_pred / temperature)
    
    # KL divergence loss
    distillation_loss = tf.keras.losses.kullback_leibler_divergence(
        teacher_probs, student_probs) * (temperature ** 2)
    
    # Combine losses
    return alpha * student_loss + (1 - alpha) * distillation_loss

# Create teacher model (large model)
teacher_model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(32, 3, activation='relu', input_shape=(28, 28, 1)),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Conv2D(64, 3, activation='relu'),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(256, activation='relu'),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10)
])

# Create student model (smaller model)
student_model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(16, 3, activation='relu', input_shape=(28, 28, 1)),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(10)
])

# Load MNIST dataset
mnist = tf.keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0
x_train = x_train[..., tf.newaxis]
x_test = x_test[..., tf.newaxis]

# Compile and train teacher model
teacher_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

teacher_model.fit(x_train, y_train, epochs=2, validation_data=(x_test, y_test))

# Get teacher predictions on training data
teacher_logits = teacher_model.predict(x_train)

# Custom training loop for student model with knowledge distillation
student_optimizer = tf.keras.optimizers.Adam()

# Custom training step
@tf.function
def train_step(images, labels, teacher_preds):
    with tf.GradientTape() as tape:
        # Forward pass
        student_logits = student_model(images, training=True)
        
        # Calculate loss
        loss = knowledge_distillation_loss(
            labels, student_logits, teacher_preds, temperature)
    
    # Compute gradients
    gradients = tape.gradient(loss, student_model.trainable_variables)
    
    # Apply gradients
    student_optimizer.apply_gradients(zip(gradients, student_model.trainable_variables))
    return loss

# Training loop with distillation
batch_size = 128
train_dataset = tf.data.Dataset.from_tensor_slices(
    (x_train, y_train, teacher_logits)).shuffle(10000).batch(batch_size)

for epoch in range(2):
    epoch_loss_avg = tf.keras.metrics.Mean()
    
    for images, labels, teacher_preds in train_dataset:
        loss = train_step(images, labels, teacher_preds)
        epoch_loss_avg.update_state(loss)
    
    print(f"Epoch {epoch+1}, Loss: {epoch_loss_avg.result().numpy():.4f}")

# Evaluate the models
teacher_accuracy = teacher_model.evaluate(x_test, y_test)[1]
student_model.compile(metrics=['accuracy'])
student_accuracy = student_model.evaluate(x_test, y_test)[1]

print(f"Teacher model accuracy: {teacher_accuracy:.4f}")
print(f"Student model accuracy: {student_accuracy:.4f}")
print(f"Teacher model size: {teacher_model.count_params()} parameters")
print(f"Student model size: {student_model.count_params()} parameters")
print(f"Size reduction: {teacher_model.count_params() / student_model.count_params():.2f}x")
```

## 7. Low-Rank Factorization

Low-rank factorization decomposes weight matrices into products of smaller matrices, reducing the total number of parameters.

```python
# PyTorch low-rank factorization example
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# Define a large fully connected layer
class LargeLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super(LargeLayer, self).__init__()
        self.fc = nn.Linear(in_features, out_features)
    
    def forward(self, x):
        return self.fc(x)

# Define a low-rank factorized version of the layer
class FactorizedLayer(nn.Module):
    def __init__(self, in_features, out_features, rank):
        super(FactorizedLayer, self).__init__()
        self.fc1 = nn.Linear(in_features, rank, bias=False)
        self.fc2 = nn.Linear(rank, out_features)
    
    def forward(self, x):
        x = self.fc1(x)
        x = self.fc2(x)
        return x

# Create example models
in_features, out_features = 1000, 1000
rank = 100

large_model = LargeLayer(in_features, out_features)
factorized_model = FactorizedLayer(in_features, out_features, rank)

# Count parameters
large_params = sum(p.numel() for p in large_model.parameters())
factorized_params = sum(p.numel() for p in factorized_model.parameters())

print(f"Original model parameters: {large_params}")
print(f"Factorized model parameters: {factorized_params}")
print(f"Compression ratio: {large_params / factorized_params:.2f}x")

# Create a random input
x = torch.randn(1, in_features)

# Apply SVD to approximate the original weight matrix
with torch.no_grad():
    W = large_model.fc.weight.data
    U, S, V = torch.svd(W)
    
    # Keep only top-rank singular values
    U_reduced = U[:, :rank]
    S_reduced = torch.diag(S[:rank])
    V_reduced = V[:, :rank]
    
    # Set weights of factorized layers
    factorized_model.fc1.weight.data = torch.matmul(V_reduced, torch.sqrt(S_reduced)).t()
    factorized_model.fc2.weight.data = torch.matmul(U_reduced, torch.sqrt(S_reduced))
    factorized_model.fc2.bias.data = large_model.fc.bias.data.clone()

# Compare outputs
with torch.no_grad():
    out_original = large_model(x)
    out_factorized = factorized_model(x)
    
    # Calculate approximation error
    error = torch.norm(out_original - out_factorized) / torch.norm(out_original)
    print(f"Approximation relative error: {error.item():.6f}")
```

class SimpleModel(nn.Module):

        self.relu1 = nn.ReLU()

        self.fc1 = nn.Linear(64 * 14 * 14, 128)
        self.relu3 = nn.ReLU()
        self.fc2 = nn.Linear(128, 10)
        
    def forward(self, x):
        x = self.relu1(self.conv1(x))
        x = self.maxpool(x)
        x = self.relu2(self.conv2(x))
        x = self.flatten(x)
        x = self.relu3(self.fc1(x))
        x = self.fc2(x)
        return x

def fuse_model(model):

                    torch.quantization.fuse_modules(m, [str(i), str(i + 1)], inplace=True)

## 10. Summary and Best Practices

Model compression is crucial for deploying deep learning models in resource-constrained environments. We've covered:

1. **Quantization**:
   - Post-training quantization is easiest but less accurate
   - Quantization-aware training provides better accuracy but requires more effort
   - INT8 quantization typically offers a good balance between accuracy and size

2. **Pruning**:
   - Reduces model size by removing unimportant connections
   - Can be structured (removing entire filters) or unstructured (zeroing individual weights)
   - Often works well with quantization for combined benefits

3. **Knowledge Distillation**:
   - Transfers knowledge from larger to smaller models
   - Useful when designing compact architectures from scratch
   - Can be combined with other compression techniques

4. **Low-rank Factorization**:
   - Decomposes weight matrices to reduce parameters
   - Good for fully-connected layers with many parameters
   - Matrix factorization techniques like SVD are commonly used

### Best Practices

1. **Choose the right technique for your constraints**: Consider your target device's memory, compute, and energy constraints.

2. **Benchmark extensively**: Always measure accuracy, size, and inference speed on your target hardware.

3. **Consider combining techniques**: Often, using pruning + quantization + distillation can yield better results than any single approach.

4. **Start with model architectures designed for efficiency**: MobileNet, EfficientNet, and SqueezeNet are already optimized for mobile/edge devices.

5. **Use framework-specific tools**: TensorFlow Lite, PyTorch Mobile, and ONNX Runtime provide optimized runtimes.

6. **Profile before compressing**: Identify bottlenecks in your model to target specific layers for compression.

7. **Use hardware-specific optimizations**: Different hardware platforms (CPUs, GPUs, TPUs, NPUs) benefit from different optimizations.

8. **Test on real data**: Ensure the compressed model performs well on real-world inputs, not just benchmark datasets.
