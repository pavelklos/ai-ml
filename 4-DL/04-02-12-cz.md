## 1. Úvod do ztrátových funkcí

Ztrátové funkce (nazývané také nákladové nebo cílové funkce) jsou jádrem tréninku neuronových sítí. Kvantifikují rozdíl mezi predikcemi modelu a skutečnými hodnotami, poskytují signál optimalizátoru pro úpravu parametrů modelu.

```python

```

Běžné ztrátové funkce zahrnují:
- **Střední kvadratická chyba (MSE)**: Pro regresní problémy
- **Binární křížová entropie**: Pro binární klasifikaci
- **Kategorická křížová entropie**: Pro víceúrovňovou klasifikaci

## 2. Standardní vs. vlastní ztrátové funkce

Zatímco standardní ztrátové funkce fungují dobře pro mnoho problémů, vlastní ztrátové funkce jsou nezbytné v případech, kdy:

1. Řešíme specifické požadavky domény
2. Pracujeme s nevyváženými daty
3. Potřebujeme začlenit doménové znalosti
4. Optimalizujeme pro hodnotící metriky, které se liší od standardních ztrát
5. Kombinujeme více cílů

```python
# Příklad: Vizualizace různých ztrátových funkcí
def plot_loss_functions():
    # Vytvoření datových bodů
    y_true = np.array([1, 1, 1, 0, 0])
    predictions = np.linspace(0, 1, 100)
    
    # Výpočet ztrát
    mse_losses = [np.mean((y_true - pred)**2) for pred in predictions]
    log_losses = [-np.mean(y_true * np.log(pred + 1e-7) + 
                           (1-y_true) * np.log(1-pred + 1e-7)) for pred in predictions]
    
    # Vlastní ztráta: Vážená binární křížová entropie (vyšší váha na pozitivech)
    def weighted_bce(y_true, pred, pos_weight=2.0):
        return -np.mean(pos_weight * y_true * np.log(pred + 1e-7) + 
                        (1-y_true) * np.log(1-pred + 1e-7))
    
    custom_losses = [weighted_bce(y_true, pred) for pred in predictions]
    
    # Vykreslení
    plt.figure(figsize=(12, 6))
    plt.plot(predictions, mse_losses, label='MSE ztráta')
    plt.plot(predictions, log_losses, label='Binární křížová entropie')
    plt.plot(predictions, custom_losses, label='Vlastní vážená BCE (pos_weight=2.0)')
    plt.xlabel('Predikce')
    plt.ylabel('Hodnota ztráty')
    plt.title('Porovnání ztrátových funkcí')
    plt.legend()
    plt.grid(True)
    plt.show()
```

## 3. Implementace vlastních ztrátových funkcí v TensorFlow/Keras

TensorFlow/Keras nabízí více způsobů, jak implementovat vlastní ztrátové funkce:

### Přístup založený na funkcích

```python
# Jednoduchá vlastní ztrátová funkce
def custom_mse_with_regularization(y_true, y_pred, beta=0.1):
    mse = tf.reduce_mean(tf.square(y_true - y_pred))
    # Přidání L1 regularizace na predikce (podporuje řídké predikce)
    regularization = beta * tf.reduce_mean(tf.abs(y_pred))
    return mse + regularization

# Použití vlastní ztráty v modelu

    keras.layers.Dense(64, activation='relu', input_shape=(10,)),
    keras.layers.Dense(32, activation='relu'),

# Možnost 1: Přímo předat funkci
```

### Implementace Focal Loss (pro nevyváženou klasifikaci)

```python
def focal_loss(y_true, y_pred, gamma=2.0, alpha=0.25):
    """
    Focal loss pro binární klasifikaci s nevyváženými daty.
    Zaměřuje se více na těžké příklady snížením váhy snadných příkladů.
    
    Argumenty:
        y_true: Skutečné hodnoty
        y_pred: Předpovězené pravděpodobnosti
        gamma: Parametr zaostření (vyšší hodnoty se více zaměřují na těžké příklady)
        alpha: Parametr vážení tříd
    """
    # Oříznutí predikcí pro zabránění numerické nestability
    y_pred = tf.clip_by_value(y_pred, tf.keras.backend.epsilon(), 1 - tf.keras.backend.epsilon())
    
    # Výpočet křížové entropie
    cross_entropy = -y_true * tf.math.log(y_pred)
    
    # Výpočet focal term
    focal_weight = alpha * tf.math.pow(1 - y_pred, gamma) * y_true + \
                  (1 - alpha) * tf.math.pow(y_pred, gamma) * (1 - y_true)
    
    # Aplikace focal term na křížovou entropii
    loss = focal_weight * cross_entropy
    
    return tf.reduce_mean(loss)
```

### Implementace Dice Loss (pro segmentaci obrazu)

```python
class DiceLoss(nn.Module):
    def __init__(self, smooth=1.0):
        super(DiceLoss, self).__init__()
        self.smooth = smooth
        
    def forward(self, y_pred, y_true):
        """
        Dice loss pro úlohy segmentace obrazu.
        
        Argumenty:
            y_pred: Predikované masky (po sigmoid)
            y_true: Skutečné masky
            smooth: Vyhlazovací faktor k zabránění dělení nulou
        """
        # Zploštění predikcí a skutečných hodnot
        y_pred_flat = y_pred.view(-1)
        y_true_flat = y_true.view(-1)
        
        # Výpočet průniku a sjednocení
        intersection = torch.sum(y_pred_flat * y_true_flat)
        union = torch.sum(y_pred_flat) + torch.sum(y_true_flat)
        
        # Výpočet Dice koeficientu
        dice = (2. * intersection + self.smooth) / (union + self.smooth)
        
        # Vrácení Dice ztráty
        return 1 - dice
```

### Segmentace obrazu: Soft Dice Loss v TensorFlow

```python
def dice_loss(y_true, y_pred, smooth=1.0):
    """
    Dice loss pro segmentaci obrazu v TensorFlow/Keras.
    
    Argumenty:
        y_true: Skutečné masky
        y_pred: Predikované masky (po sigmoid)
        smooth: Vyhlazovací faktor k zabránění dělení nulou
    """
    # Zploštění predikcí a skutečných hodnot
    y_true_flat = tf.reshape(y_true, [-1])
    y_pred_flat = tf.reshape(y_pred, [-1])
    
    # Výpočet průniku a sjednocení
    intersection = tf.reduce_sum(y_true_flat * y_pred_flat)
    union = tf.reduce_sum(y_true_flat) + tf.reduce_sum(y_pred_flat)
    
    # Výpočet Dice koeficientu
    dice = (2. * intersection + smooth) / (union + smooth)
    
    # Vrácení Dice ztráty
    return 1. - dice

# Kombinace s binární křížovou entropií pro lepší výsledky
def bce_dice_loss(y_true, y_pred):
    bce = tf.keras.losses.BinaryCrossentropy(from_logits=False)(y_true, y_pred)
    dice = dice_loss(y_true, y_pred)
    return bce + dice
```

### Detekce objektů: IoU Loss

```python
def iou_loss(y_true, y_pred):
    """
    IoU (Intersection over Union) ztráta pro predikci ohraničovacích rámečků.
    
    Argumenty:
        y_true: Skutečné ohraničovací rámečky [x1, y1, x2, y2]
        y_pred: Predikované ohraničovací rámečky [x1, y1, x2, y2]
    """
    # Výpočet souřadnic průniku
    intersect_x1 = tf.maximum(y_true[:, 0], y_pred[:, 0])
    intersect_y1 = tf.maximum(y_true[:, 1], y_pred[:, 1])
    intersect_x2 = tf.minimum(y_true[:, 2], y_pred[:, 2])
    intersect_y2 = tf.minimum(y_true[:, 3], y_pred[:, 3])
    
    # Výpočet plochy průniku
    width = tf.maximum(0.0, intersect_x2 - intersect_x1)
    height = tf.maximum(0.0, intersect_y2 - intersect_y1)
    intersection_area = width * height
    
    # Výpočet plochy skutečných a predikovaných rámečků
    true_area = (y_true[:, 2] - y_true[:, 0]) * (y_true[:, 3] - y_true[:, 1])
    pred_area = (y_pred[:, 2] - y_pred[:, 0]) * (y_pred[:, 3] - y_pred[:, 1])
    
    # Výpočet plochy sjednocení
    union_area = true_area + pred_area - intersection_area
    
    # Výpočet IoU
    iou = intersection_area / (union_area + tf.keras.backend.epsilon())
    
    # Vrácení IoU ztráty
    return 1.0 - tf.reduce_mean(iou)
```

### Metrické učení: Triplet Loss

```python
def triplet_loss(y_true, y_pred, margin=1.0):
    """
    Triplet loss pro metrické učení a prostory embedingů.
    
    Argumenty:
        y_true: Nepoužívá se (může být None)
        y_pred: Zřetězené embeddiny [kotva, pozitivní, negativní]
        margin: Minimální požadovaná vzdálenost mezi kotvou-negativní vs kotvou-pozitivní
    """
    # Rozdělení dávky na kotvu, pozitivní a negativní příklady
    embedding_dim = y_pred.shape[1] // 3
    anchor = y_pred[:, :embedding_dim]
    positive = y_pred[:, embedding_dim:2*embedding_dim]
    negative = y_pred[:, 2*embedding_dim:]
    
    # Výpočet vzdáleností
    pos_dist = tf.reduce_sum(tf.square(anchor - positive), axis=1)
    neg_dist = tf.reduce_sum(tf.square(anchor - negative), axis=1)
    
    # Výpočet ztráty
    basic_loss = pos_dist - neg_dist + margin
    loss = tf.maximum(basic_loss, 0.0)
    
    return tf.reduce_mean(loss)
```

## 6. Vícesložkové ztrátové funkce

Složité úlohy často těží z kombinování více ztrátových termů pro vedení optimalizace:

### Ztráta pro učení s více úlohami

```python
class MultiTaskLoss(keras.losses.Loss):
    def __init__(self, task_weights=None):
        """
        Ztráta pro učení s více úlohami, která kombinuje více ztrátových funkcí.
        
        Argumenty:
            task_weights: Slovník mapující názvy úloh na jejich váhy
        """
        super().__init__()
        self.task_weights = task_weights or {"classification": 1.0, "regression": 1.0}
        self.classification_loss = keras.losses.BinaryCrossentropy()
        self.regression_loss = keras.losses.MeanSquaredError()
        
    def call(self, y_true, y_pred):
        # Rozbalení skutečných a predikovaných hodnot pro každou úlohu
        y_true_cls, y_true_reg = y_true["classification"], y_true["regression"]
        y_pred_cls, y_pred_reg = y_pred["classification"], y_pred["regression"]
        
        # Výpočet jednotlivých ztrát
        cls_loss = self.classification_loss(y_true_cls, y_pred_cls)
        reg_loss = self.regression_loss(y_true_reg, y_pred_reg)
        
        # Kombinace ztrát s váhami
        total_loss = (self.task_weights["classification"] * cls_loss + 
                      self.task_weights["regression"] * reg_loss)
        
        return total_loss
```

### Ztráta pro přenos neuronového stylu

```python
def style_transfer_loss(style_outputs, content_outputs, style_targets, content_targets, 
                        style_weight=1e-2, content_weight=1e4):
    """
    Kombinovaná ztráta pro přenos neuronového stylu.
    
    Argumenty:
        style_outputs: Výstupy stylu ze sítě
        content_outputs: Výstupy obsahu ze sítě
        style_targets: Cílové vlastnosti stylu
        content_targets: Cílové vlastnosti obsahu
        style_weight: Váha pro ztrátu stylu
        content_weight: Váha pro ztrátu obsahu
    """
    # Výpočet ztráty obsahu
    content_loss = tf.reduce_mean(tf.square(content_outputs - content_targets))
    
    # Výpočet ztráty stylu (pomocí Gramových matic)
    style_loss = 0
    for style_output, style_target in zip(style_outputs, style_targets):
        # Výpočet Gramových matic
        style_output_gram = gram_matrix(style_output)
        style_target_gram = gram_matrix(style_target)
        
        # Přidání do ztráty stylu
        style_loss += tf.reduce_mean(tf.square(style_output_gram - style_target_gram))
    
    style_loss *= style_weight / len(style_outputs)
    content_loss *= content_weight
    
    # Celková ztráta
    total_loss = style_loss + content_loss
    
    return total_loss

def gram_matrix(input_tensor):
    """Výpočet Gramovy matice pro reprezentaci stylu."""
    result = tf.linalg.einsum('bijc,bijd->bcd', input_tensor, input_tensor)
    input_shape = tf.shape(input_tensor)
    num_locations = tf.cast(input_shape[1] * input_shape[2], tf.float32)
    return result / num_locations
```

### Kombinace ztráty pro GAN

```python
class GANLoss:
    def __init__(self, disc_loss_fn=None, gen_loss_fn=None):
        """
        Kombinace ztrát pro GAN pro trénink generátoru a diskriminátoru.
        
        Argumenty:
            disc_loss_fn: Ztrátová funkce pro diskriminátor (výchozí: binární křížová entropie)
            gen_loss_fn: Ztrátová funkce pro generátor (výchozí: binární křížová entropie)
        """
        self.disc_loss_fn = disc_loss_fn or tf.keras.losses.BinaryCrossentropy(from_logits=True)
        self.gen_loss_fn = gen_loss_fn or tf.keras.losses.BinaryCrossentropy(from_logits=True)
    
    def discriminator_loss(self, real_output, fake_output):
        # Skutečné vzorky by měly být klasifikovány jako 1
        real_loss = self.disc_loss_fn(tf.ones_like(real_output), real_output)
        # Falešné vzorky by měly být klasifikovány jako 0
        fake_loss = self.disc_loss_fn(tf.zeros_like(fake_output), fake_output)
        return real_loss + fake_loss
    
    def generator_loss(self, fake_output):
        # Generátor se snaží přimět diskriminátor, aby klasifikoval falešné vzorky jako 1
        return self.gen_loss_fn(tf.ones_like(fake_output), fake_output)
```

## 7. Vážené a adaptivní ztrátové funkce

### Třídně vážená ztráta pro nevyvážená data

```python
def weighted_categorical_crossentropy(y_true, y_pred, class_weights):
    """
    Vážená kategorická křížová entropie pro nevyváženou klasifikaci.
    
    Argumenty:
        y_true: One-hot kódované skutečné hodnoty
        y_pred: Předpovězené pravděpodobnosti tříd
        class_weights: Seznam nebo pole vah pro každou třídu
    """
    # Převod class_weights na tenzor
    class_weights = tf.convert_to_tensor(class_weights, dtype=tf.float32)
    
    # Aplikace vah tříd na one-hot kódované popisky
    weights = tf.reduce_sum(y_true * class_weights, axis=-1)
    
    # Výpočet běžné kategorické křížové entropie
    unweighted_loss = tf.keras.losses.categorical_crossentropy(y_true, y_pred)
    
    # Aplikace vah
    weighted_loss = unweighted_loss * weights
    
    return tf.reduce_mean(weighted_loss)

# Příklad použití pro 3-třídní problém s nevyvážeností tříd
class_weights = [1.0, 2.5, 10.0]  # Vyšší váhy pro nedostatečně zastoupené třídy

# Při kompilaci modelu
model.compile(
    optimizer='adam',
    loss=lambda y_true, y_pred: weighted_categorical_crossentropy(y_true, y_pred, class_weights)
)
```

### Adaptive Wing Loss pro detekci orientačních bodů

```python
def adaptive_wing_loss(y_true, y_pred, omega=14, alpha=2.1, epsilon=1, theta=0.5):
    """
    Adaptive Wing Loss pro detekci obličejových orientačních bodů.
    Zaměřuje se na těžké vzorky a aplikuje různé formulace ztráty
    na základě velikosti chyby.
    
    Argumenty:
        y_true: Skutečné orientační body
        y_pred: Predikované orientační body
        omega, alpha, epsilon, theta: Hyperparametry ovlivňující chování ztráty
    """
    # Výpočet chyby
    error = tf.abs(y_true - y_pred)
    
    # Definice podmínek na základě velikosti chyby
    condition = tf.less(error, theta)
    
    # Pro chyby < theta: Použití modifikované logaritmické funkce
    A = omega * (1 / (1 + tf.pow(theta / epsilon, alpha-y_true))) * (alpha-y_true) * \
        tf.pow(theta/epsilon, alpha-y_true-1) * (1/epsilon)
    C = theta * A - omega * tf.math.log(1 + tf.pow(theta/epsilon, alpha-y_true))
    
    # Aplikace různých formulací na základě velikosti chyby
    losses = tf.where(
        condition,
        # Malé chyby: Aplikace modifikované logaritmické funkce
        omega * tf.math.log(1 + tf.pow(error/epsilon, alpha-y_true)),
        # Velké chyby: Aplikace lineární funkce
        A * error - C
    )
    
    return tf.reduce_mean(losses)
```

## 8. Ladění vlastních ztrátových funkcí

Při implementaci vlastních ztrátových funkcí je klíčové ladění, aby fungovaly podle očekávání:

```python
def debug_loss_function(loss_fn, num_samples=5):
    """
    Pomocná funkce pro ladění vlastních ztrátových funkcí.
    
    Argumenty:
        loss_fn: Ztrátová funkce k ladění (bere y_true, y_pred jako argumenty)
        num_samples: Počet vzorových případů k testování
    """
    # Vytvoření vzorových dat různých tvarů
    shapes = [(1,), (1, 1), (2, 3), (5, 10)]
    
    for shape in shapes:
        print(f"\nTestování s tvarem: {shape}")
```

```python
def numerically_stable_bce(y_true, y_pred, epsilon=1e-7):
    # Oříznutí predikcí k vyvarování se log(0) nebo log(1)
    y_pred = tf.clip_by_value(y_pred, epsilon, 1 - epsilon)
    
    # Výpočet binární křížové entropie
    loss = -tf.reduce_mean(
        y_true * tf.math.log(y_pred) + (1 - y_true) * tf.math.log(1 - y_pred)
    )
    return loss
```

```python
def test_loss_gradients(loss_fn, input_shape=(5, 1)):
    """Test, zda ztrátová funkce vytváří smysluplné gradienty."""
    # Vytvoření náhodných vstupů
    y_true = tf.random.uniform(input_shape)
    y_pred = tf.random.uniform(input_shape)
    y_pred = tf.Variable(y_pred)
    
    # Výpočet gradientu pomocí GradientTape
    with tf.GradientTape() as tape:
        loss = loss_fn(y_true, y_pred)
    
    gradients = tape.gradient(loss, y_pred)
    
    # Kontrola, zda gradienty nejsou None nebo neobsahují NaNy
    if gradients is None:
        print("Varování: Gradienty jsou None! Ztrátová funkce nemusí být diferencovatelná.")
        return False
    
    if tf.reduce_any(tf.math.is_nan(gradients)):
        print("Varování: Gradienty obsahují hodnoty NaN!")
        return False
    
    # Kontrola, zda jsou všechny gradienty nulové
    if tf.reduce_all(tf.equal(gradients, 0)):
        print("Varování: Všechny gradienty jsou nulové! Ztrátová funkce může být plochá.")
        return False
    
    print("Kontrola gradientů prošla! Průměrná velikost gradientu:", 
          tf.reduce_mean(tf.abs(gradients)).numpy())
    return True
```
