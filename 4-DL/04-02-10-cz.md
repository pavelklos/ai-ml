## Úvod do plánování učící rychlosti

Plánování učící rychlosti je technika pro dynamickou úpravu učící rychlosti během tréninku ke zlepšení výkonu a konvergence modelu. Učící rychlost, jeden z nejdůležitějších hyperparametrů v hlubokém učení, určuje, jak moc aktualizovat váhy modelu v reakci na odhadnutou chybu pokaždé, když jsou váhy modelu aktualizovány.

## Proč je plánování učící rychlosti důležité

Učící rychlost významně ovlivňuje dynamiku tréninku:

1. **Příliš velká**: Trénink může divergovat nebo oscilovat kolem minima
2. **Příliš malá**: Trénink může být pomalý nebo se zaseknout v nevhodných lokálních minimech
3. **Právě správná**: Ale co je "správné" se během tréninku mění

Plánování učící rychlosti řeší tyto výzvy adaptivním nastavením učící rychlosti během tréninku.

## Běžné techniky plánování učící rychlosti

Bylo vyvinuto několik efektivních technik plánování učící rychlosti:

### 1. Step Decay (Stupňovitý pokles)

Snižuje učící rychlost o faktor po pevném počtu epoch.

### 2. Exponential Decay (Exponenciální pokles)

Kontinuálně snižuje učící rychlost exponenciálně.

### 3. Cosine Annealing (Kosinové žíhání)

Snižuje učící rychlost podle kosinové křivky, postupně klesající na minimální hodnotu.

### 4. Cyclical Learning Rates (Cyklické učící rychlosti)

Cyklicky mění učící rychlost mezi rozumnými hraničními hodnotami.

### 5. Warm-Up + Decay (Zahřívání + pokles)

Začíná s malou učící rychlostí, postupně ji zvyšuje (zahřívání) a poté ji snižuje.

```python
def visualize_lr_schedules():
    epochs = 100
    initial_lr = 0.1
    
    # Stupňovitý pokles
    step_decay = [initial_lr * 0.1**(np.floor(i / 30)) for i in range(epochs)]
    
    # Exponenciální pokles
    exp_decay = [initial_lr * np.exp(-0.03 * i) for i in range(epochs)]
    
    # Kosinové žíhání
    cosine = [initial_lr * 0.5 * (1 + np.cos(np.pi * i / epochs)) for i in range(epochs)]
    
    # Cyklická učící rychlost
    def triangular_lr(i, base_lr=0.001, max_lr=0.1, step_size=20):
        cycle = np.floor(1 + i / (2 * step_size))
        x = np.abs(i / step_size - 2 * cycle + 1)
        return base_lr + (max_lr - base_lr) * np.maximum(0, (1 - x))
    
    cyclical = [triangular_lr(i) for i in range(epochs)]
    
    # Zahřívání + pokles
    warmup_epochs = 10
    warmup = [initial_lr * i / warmup_epochs if i < warmup_epochs else 
              initial_lr * np.exp(-0.03 * (i - warmup_epochs)) for i in range(epochs)]
    
    plt.figure(figsize=(15, 10))
    
    plt.subplot(2, 3, 1)
    plt.plot(step_decay)
    plt.title('Stupňovitý pokles')
    plt.xlabel('Epochy')
    plt.ylabel('Učící rychlost')
```

```python
def create_model_with_lr_callback():
    model = keras.Sequential([
        keras.layers.Dense(128, activation='relu', input_shape=(784,)),
        keras.layers.Dropout(0.2),
        keras.layers.Dense(10, activation='softmax')
    ])
    
    model.compile(
        optimizer='adam',
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Definice funkce plánu
    def step_decay(epoch):
        initial_lr = 0.1
        drop_factor = 0.5
        epochs_drop = 10.0
        return initial_lr * (drop_factor ** np.floor(epoch / epochs_drop))
    
    # Vytvoření callbacku LearningRateScheduler
    lr_scheduler = keras.callbacks.LearningRateScheduler(step_decay)
    
    # ReduceLROnPlateau: snižuje LR, když se metrika přestane zlepšovat
    reduce_lr = keras.callbacks.ReduceLROnPlateau(
        monitor='val_loss',
        factor=0.2,     # Faktor, kterým se sníží učící rychlost
        patience=5,     # Počet epoch bez zlepšení, po kterých bude LR snížena
        min_lr=0.0001   # Dolní hranice učící rychlosti
    )
    
    return model, [lr_scheduler, reduce_lr]
```

## Vlastní plánovače učící rychlosti

Někdy můžete chtít implementovat vlastní plán učící rychlosti:

```python
# Vlastní plánovač v TensorFlow/Keras
class WarmupCosineDecayScheduler(keras.callbacks.Callback):
    def __init__(self, total_epochs, warmup_epochs=5, base_lr=0.01, min_lr=1e-5):
        super(WarmupCosineDecayScheduler, self).__init__()
        self.total_epochs = total_epochs
        self.warmup_epochs = warmup_epochs
        self.base_lr = base_lr
        self.min_lr = min_lr

    def on_epoch_begin(self, epoch, logs=None):
        if epoch < self.warmup_epochs:
            # Lineární zahřívání
            lr = self.base_lr * (epoch + 1) / self.warmup_epochs
        else:
            # Kosinový pokles
            progress = (epoch - self.warmup_epochs) / (self.total_epochs - self.warmup_epochs)
            cosine_decay = 0.5 * (1 + np.cos(np.pi * progress))
            lr = self.min_lr + (self.base_lr - self.min_lr) * cosine_decay

        keras.backend.set_value(self.model.optimizer.lr, lr)
        print(f"\nEpocha {epoch+1}: Učící rychlost nastavena na {lr:.6f}")

# Vlastní plánovač v PyTorch
class WarmupCosineDecay:
    def __init__(self, optimizer, warmup_epochs, total_epochs, base_lr, min_lr=1e-5):
        self.optimizer = optimizer
        self.warmup_epochs = warmup_epochs
        self.total_epochs = total_epochs
        self.base_lr = base_lr
        self.min_lr = min_lr
        self.last_epoch = -1
        self.step()
    
    def get_lr(self):
        epoch = self.last_epoch + 1
        
        if epoch < self.warmup_epochs:
            # Lineární zahřívání
            return self.base_lr * (epoch + 1) / self.warmup_epochs
        else:
            # Kosinový pokles
            progress = (epoch - self.warmup_epochs) / (self.total_epochs - self.warmup_epochs)
            cosine_decay = 0.5 * (1 + np.cos(np.pi * progress))
            return self.min_lr + (self.base_lr - self.min_lr) * cosine_decay
    
    def step(self):
        self.last_epoch += 1
        lr = self.get_lr()
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = lr
```

## Hledání učící rychlosti

Technika hledání učící rychlosti pomáhá určit optimální počáteční učící rychlost:

```python
def lr_finder(model, train_data, start_lr=1e-7, end_lr=10, num_iters=100):
    """
    Hledá optimální učící rychlost tréninkem s exponenciálně rostoucí LR.
    Inspirováno hledáním učící rychlosti z fast.ai.
    """
    # Vytvoření kopie vah modelu
    initial_weights = [w.numpy().copy() for w in model.weights]
    
    # Vytvoření optimalizátoru a ztrátové funkce
    optimizer = keras.optimizers.SGD()
    loss_fn = keras.losses.SparseCategoricalCrossentropy()
    
    # Vytvoření logaritmicky rozmístěných učících rychlostí
    learning_rates = np.logspace(np.log10(start_lr), np.log10(end_lr), num_iters)
    
    losses = []
    
    for i, lr in enumerate(learning_rates):
        # Nastavení učící rychlosti
        keras.backend.set_value(optimizer.lr, lr)
        
        # Získání dávky dat
        # V praxi byste iterovali přes své data
        x_batch, y_batch = next(iter(train_data))
        
        # Dopředný a zpětný průchod
        with tf.GradientTape() as tape:
            y_pred = model(x_batch, training=True)
            loss = loss_fn(y_batch, y_pred)
        
        # Výpočet gradientů a aktualizace vah
        grads = tape.gradient(loss, model.trainable_variables)
        optimizer.apply_gradients(zip(grads, model.trainable_variables))
        
        # Zaznamenání ztráty
        losses.append(loss.numpy())
        
        # Zastavení, pokud ztráta exploduje
        if i > 0 and losses[-1] > 4 * losses[0]:
            break
    
    # Obnovení původních vah
    for i, w in enumerate(initial_weights):
        model.weights[i].assign(w)
    
    # Vykreslení výsledků
    plt.figure(figsize=(12, 6))
    plt.plot(learning_rates[:len(losses)], losses)
    plt.xscale('log')
    plt.xlabel('Učící rychlost (logaritmická škála)')
    plt.ylabel('Ztráta')
    plt.title('Hledání učící rychlosti')
    plt.grid(True)
    
    # Nalezení bodu nejstrmějšího poklesu ztráty
    smoothed_losses = np.array(losses)
    min_grad_idx = np.gradient(smoothed_losses).argmin()
    
    # Označení navrhované učící rychlosti
    suggested_lr = learning_rates[min_grad_idx]
    plt.axvline(x=suggested_lr, color='r', linestyle='--')
    plt.text(suggested_lr, min(losses), f"Navrhovaná LR: {suggested_lr:.2e}", 
             horizontalalignment='center', color='red')
    
    return suggested_lr

# Implementace PyTorch verze hledače LR
def pytorch_lr_finder(model, train_loader, criterion, optimizer, device,
                      start_lr=1e-7, end_lr=10, num_iters=100):
    """PyTorch implementace hledání učící rychlosti"""
    # Uložení kopie modelu
    model_state = {k: v.clone().detach() for k, v in model.state_dict().items()}
    optimizer_state = optimizer.state_dict()
    
    # Nastavení počáteční učící rychlosti
    for param_group in optimizer.param_groups:
        param_group['lr'] = start_lr
    
    # Příprava iterátoru dat
    data_iter = iter(train_loader)
    
    # Výpočet multiplikativního faktoru pro každou aktualizaci
    mult_factor = (end_lr / start_lr) ** (1 / num_iters)
    
    losses = []
    lrs = []
    
    model.train()
    for i in range(num_iters):
        try:
            inputs, targets = next(data_iter)
        except StopIteration:
            data_iter = iter(train_loader)
            inputs, targets = next(data_iter)
            
        inputs, targets = inputs.to(device), targets.to(device)
        
        # Zaznamenání aktuální učící rychlosti
        current_lr = optimizer.param_groups[0]['lr']
        lrs.append(current_lr)
        
        # Dopředný průchod
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, targets)
        
        # Zpětný průchod
        loss.backward()
        optimizer.step()
        
        # Zaznamenání ztráty
        losses.append(loss.item())
        
        # Zvýšení učící rychlosti
        for param_group in optimizer.param_groups:
            param_group['lr'] = param_group['lr'] * mult_factor
        
        # Zastavení, pokud ztráta exploduje
        if i > 0 and losses[-1] > 4 * losses[0]:
            break
    
    # Obnovení modelu a optimalizátoru do jejich původních stavů
    model.load_state_dict(model_state)
    optimizer.load_state_dict(optimizer_state)
    
    # Vykreslení výsledků
    plt.figure(figsize=(10, 6))
    plt.plot(lrs, losses)
    plt.xscale('log')
    plt.xlabel('Učící rychlost (logaritmická škála)')
    plt.ylabel('Ztráta')
    plt.title('Hledání učící rychlosti')
    plt.grid(True)
    
    # Nalezení učící rychlosti s nejstrmějším gradientem
    log_lrs = np.log10(lrs)
    loss_grad = np.gradient(losses) / np.gradient(log_lrs)
    
    # Vyhlazení gradientů
    from scipy.signal import savgol_filter
    if len(loss_grad) > 7:  # Potřebuji dostatečný počet bodů pro vyhlazení
        loss_grad_smooth = savgol_filter(loss_grad, min(7, len(loss_grad)//2*2-1), 1)
    else:
        loss_grad_smooth = loss_grad
        
    # Nalezení bodu nejstrmějšího poklesu
    min_grad_idx = np.argmin(loss_grad_smooth)
    suggested_lr = lrs[min_grad_idx]
    
    plt.axvline(x=suggested_lr, color='r', linestyle='--')
    plt.text(suggested_lr, losses[min_grad_idx], f"Navrhovaná LR: {suggested_lr:.2e}", 
             horizontalalignment='center', color='red')
    
    return suggested_lr
```

## Osvědčené postupy a tipy

Zde jsou některé osvědčené postupy pro používání plánovačů učící rychlosti:

4. **Kombinujte s předčasným zastavením**: Plány učící rychlosti mohou dobře fungovat s předčasným zastavením pro prevenci přetrénování.

5. **Experimentujte a vizualizujte**: Vizualizujte svůj plán učící rychlosti a jeho vliv na trénovací metriky.

```python
# Příklad kombinace plánování učící rychlosti a předčasného zastavení
def train_model_with_lr_schedule_and_early_stopping():
    # Vytvoření modelu
    model = keras.Sequential([
        keras.layers.Conv2D(32, (3, 3), activation='relu', input_shape=(32, 32, 3)),
        keras.layers.MaxPooling2D((2, 2)),
        keras.layers.Conv2D(64, (3, 3), activation='relu'),
        keras.layers.MaxPooling2D((2, 2)),
        keras.layers.Flatten(),
        keras.layers.Dense(64, activation='relu'),
        keras.layers.Dense(10, activation='softmax')
    ])
    
    # Kompilace modelu
    model.compile(
        optimizer='adam',
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Definice plánu učící rychlosti
    def cosine_decay_with_warmup(epoch):
        total_epochs = 100
        warmup_epochs = 5
        
        if epoch < warmup_epochs:
            # Lineární zahřívání
            return 0.0001 + (0.001 - 0.0001) * epoch / warmup_epochs
        else:
            # Kosinový pokles
            progress = (epoch - warmup_epochs) / (total_epochs - warmup_epochs)
            cosine_decay = 0.5 * (1 + np.cos(np.pi * progress))
            return 0.0001 + (0.001 - 0.0001) * cosine_decay
    
    # Vytvoření callbacků
    callbacks = [
        keras.callbacks.LearningRateScheduler(cosine_decay_with_warmup),
        keras.callbacks.EarlyStopping(
            monitor='val_accuracy',
            patience=10,
            restore_best_weights=True
        ),
        keras.callbacks.ModelCheckpoint(
            filepath='best_model.h5',
            monitor='val_accuracy',
            save_best_only=True
        ),
        keras.callbacks.TensorBoard(log_dir='./logs')
    ]
    
    # Trénování modelu (ukázková data pro demonstraci)
    x_train = np.random.random((1000, 32, 32, 3))
    y_train = np.random.randint(0, 10, size=1000)
    x_val = np.random.random((200, 32, 32, 3))
    y_val = np.random.randint(0, 10, size=200)
    
    history = model.fit(
        x_train, y_train,
        epochs=100,
        batch_size=32,
        validation_data=(x_val, y_val),
        callbacks=callbacks,
        verbose=0  # Nastavte na 1 pro zobrazení průběhu
    )
    
    # Vykreslení historie tréninku
    plt.figure(figsize=(12, 5))
    
    plt.subplot(1, 2, 1)
    plt.plot(history.history['accuracy'], label='Trénovací')
    plt.plot(history.history['val_accuracy'], label='Validační')
    plt.title('Přesnost modelu')
    plt.xlabel('Epocha')
    plt.ylabel('Přesnost')
    plt.legend()
    plt.grid(True)
    
    plt.subplot(1, 2, 2)
    plt.plot(history.history['loss'], label='Trénovací')
    plt.plot(history.history['val_loss'], label='Validační')
    plt.title('Ztráta modelu')
    plt.xlabel('Epocha')
    plt.ylabel('Ztráta')
    plt.legend()
    plt.grid(True)
    
    plt.tight_layout()
    plt.show()
    
    return model, history
```

## Shrnutí

Plánování učící rychlosti je klíčová technika v hlubokém učení, která dynamicky upravuje učící rychlost během tréninku pro zlepšení výkonu modelu. Klíčové poznatky zahrnují:

1. **Důležitost**: Učící rychlost je jedním z nejkritičtějších hyperparametrů ovlivňujících dynamiku tréninku a výkon modelu.

2. **Běžné techniky**: Populární strategie plánování zahrnují stupňovitý pokles, exponenciální pokles, kosinové žíhání, cyklické učící rychlosti a zahřívání následované poklesem.

3. **Podpora frameworků**: Jak TensorFlow/Keras, tak PyTorch poskytují vestavěné plánovače pro běžné techniky plánování učící rychlosti.

4. **Vlastní plánovače**: Vlastní plány učící rychlosti lze implementovat pro splnění specifických požadavků.

5. **Hledání učící rychlosti**: Použití hledače učící rychlosti může pomoci určit optimální počáteční učící rychlost.

6. **Vizualizace**: Vizualizace plánů učící rychlosti a jejich efektů pomáhá pochopit a optimalizovat trénink.

7. **Osvědčené postupy**: Kombinujte plánování učící rychlosti s technikami jako předčasné zastavení a období zahřívání pro nejlepší výsledky.

8. **Adaptabilita**: Různé plány učící rychlosti fungují lépe pro různé architektury a úlohy; experimentování je klíčové.

Správně implementované plánování učící rychlosti může významně zlepšit stabilitu tréninku, rychlost konvergence a konečný výkon modelu. Je to základní nástroj v sadě nástrojů odborníka na hluboké učení pro trénování vysoce výkonných neuronových sítí.
