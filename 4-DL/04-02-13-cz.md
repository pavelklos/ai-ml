## 1. Úvod do dolaďování modelů

Dolaďování modelů je proces, kdy se vezme předtrénovaný model vyvinutý pro jeden úkol a adaptuje se pro jiný, ale související úkol. Tento přístup využívá znalosti obsažené v existujících modelech, šetří čas a výpočetní prostředky a často zlepšuje výkon.

```python
import tensorflow as tf
from tensorflow import keras
import torch
import torch.nn as nn
import torchvision.models as models
import matplotlib.pyplot as plt
import numpy as np
from sklearn.metrics import accuracy_score, classification_report
```

Hlavní výhody dolaďování modelů zahrnují:
- Zkrácení doby tréninku
- Nižší výpočetní nároky
- Lepší výkon s omezeným množstvím dat
- Přenos znalostí mezi doménami

## 2. Základy přenosového učení

Přenosové učení zahrnuje použití znalostí získaných při řešení jednoho problému a jejich aplikaci na jiný, ale související problém. V hlubokém učení to typicky znamená opětovné použití vah z předtrénovaného modelu.

def feature_extraction(base_model, new_dataset):

def fine_tuning(base_model, new_dataset, unfreeze_layers=5):
    """
    Dolaďování: Zmrazit počáteční vrstvy, trénovat pozdější vrstvy a novou hlavičku
    """

Konvoluční neuronové sítě (CNN) jsou běžně dolaďovány pro úlohy počítačového vidění. Modely jako ResNet, VGG a EfficientNet lze adaptovat na nové úlohy klasifikace obrázků.

### Dolaďování pomocí TensorFlow/Keras

```python
# Dolaďování předtrénovaného modelu ResNet50 pro novou klasifikační úlohu
def fine_tune_resnet_keras(train_data, validation_data, num_classes, epochs=10):
    # Načtení předtrénovaného modelu
    base_model = keras.applications.ResNet50(
        weights='imagenet',  # Načíst předtrénované váhy ImageNet
        include_top=False,   # Nezahrnovat původní klasifikační hlavičku
        input_shape=(224, 224, 3)
    )
    
    # Zmrazit konvoluční základ
    base_model.trainable = False
    
    # Vytvořit nový model s naší klasifikační hlavičkou
    model = keras.Sequential([
        base_model,
        keras.layers.GlobalAveragePooling2D(),
        keras.layers.Dense(256, activation='relu'),
        keras.layers.Dropout(0.5),
        keras.layers.Dense(num_classes, activation='softmax')
    ])
    
    # Kompilace modelu
    model.compile(
        optimizer=keras.optimizers.Adam(1e-4),  # Nízká rychlost učení pro dolaďování
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Nejprve trénovat horní vrstvy (fáze 1)
    print("Fáze 1: Trénování pouze klasifikační hlavičky...")
    history_phase1 = model.fit(
        train_data,
        validation_data=validation_data,
        epochs=5
    )
    
    # Odmrazit některé vrstvy pro doladění (fáze 2)
    print("Fáze 2: Dolaďování vrstev ResNet...")
    # Odmrazit posledních 30 vrstev
    for layer in base_model.layers[-30:]:
        layer.trainable = True
    
    # Rekompilace s nižší rychlostí učení
    model.compile(
        optimizer=keras.optimizers.Adam(1e-5),  # Ještě nižší rychlost učení
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Pokračování v tréninku
    history_phase2 = model.fit(
        train_data,
        validation_data=validation_data,
        epochs=epochs
    )
    
    return model, history_phase1, history_phase2
```

### Dolaďování pomocí PyTorch

```python
# Doladění předtrénovaného modelu ResNet v PyTorch
def fine_tune_resnet_pytorch(train_loader, val_loader, num_classes, epochs=10, device='cuda'):
    # Načtení předtrénovaného modelu
    model = models.resnet50(pretrained=True)
    
    # Zmrazení všech vrstev
    for param in model.parameters():
        param.requires_grad = False
    
    # Nahrazení poslední plně propojené vrstvy
    num_features = model.fc.in_features
    model.fc = nn.Sequential(
        nn.Linear(num_features, 256),
        nn.ReLU(),
        nn.Dropout(0.5),
        nn.Linear(256, num_classes)
    )
    
    # Přesunutí modelu na příslušné zařízení
    model = model.to(device)
    
    # Ztrátová funkce a optimalizátor
    criterion = nn.CrossEntropyLoss()
    
    # Optimalizovat pouze parametry nových vrstev
    optimizer = torch.optim.Adam(model.fc.parameters(), lr=1e-4)
    
    # Fáze 1: Trénovat pouze nové vrstvy
    print("Fáze 1: Trénování pouze klasifikační hlavičky...")
    train_model(model, train_loader, val_loader, criterion, optimizer, epochs=5, device=device)
    
    # Fáze 2: Doladit některé vrstvy
    print("Fáze 2: Dolaďování vrstev ResNet...")
    # Odmrazit poslední blok vrstev
    for param in model.layer4.parameters():  # Odmrazit poslední hlavní blok
        param.requires_grad = True
    
    # Optimalizátor nyní zahrnuje všechny trénovatelné parametry
    optimizer = torch.optim.Adam([
        {'params': model.fc.parameters()},
        {'params': model.layer4.parameters(), 'lr': 1e-5}  # Nižší rychlost učení pro předtrénované vrstvy
    ], lr=1e-4)
    
    # Pokračování v tréninku
    train_model(model, train_loader, val_loader, criterion, optimizer, epochs=epochs, device=device)
    
    return model

def train_model(model, train_loader, val_loader, criterion, optimizer, epochs, device):
    for epoch in range(epochs):
        # Fáze tréninku
        model.train()
        running_loss = 0.0
        
        for inputs, labels in train_loader:
            inputs, labels = inputs.to(device), labels.to(device)
            
            # Vynulování gradientů
            optimizer.zero_grad()
            
            # Dopředný průchod
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            
            # Zpětný průchod a optimalizace
            loss.backward()
            optimizer.step()
            
            running_loss += loss.item()
        
        # Fáze validace
        model.eval()
        val_loss = 0.0
        correct = 0
        total = 0
        
        with torch.no_grad():
            for inputs, labels in val_loader:
                inputs, labels = inputs.to(device), labels.to(device)
                outputs = model(inputs)
                loss = criterion(outputs, labels)
                val_loss += loss.item()
                
                _, predicted = torch.max(outputs, 1)
                total += labels.size(0)
                correct += (predicted == labels).sum().item()
        
        val_accuracy = correct / total
        print(f'Epoch {epoch+1}/{epochs}, Tréninková ztráta: {running_loss/len(train_loader):.4f}, '
              f'Validační ztráta: {val_loss/len(val_loader):.4f}, Validační přesnost: {val_accuracy:.4f}')
```

## 4. Dolaďování NLP modelů

Modely zpracování přirozeného jazyka (NLP) jako BERT, GPT a RoBERTa lze doladit pro specifické textové úlohy jako je analýza sentimentu, klasifikace textu a odpovídání na otázky.

### Dolaďování BERT pomocí Hugging Face Transformers

```python
import torch
from transformers import BertTokenizer, BertForSequenceClassification
from transformers import AdamW, get_linear_schedule_with_warmup
from torch.utils.data import TensorDataset, DataLoader, RandomSampler, SequentialSampler

def fine_tune_bert(train_texts, train_labels, validation_texts, validation_labels, epochs=3):
    # Načtení předtrénovaného tokenizátoru a modelu
    tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
    model = BertForSequenceClassification.from_pretrained(
        'bert-base-uncased',
        num_labels=2,  # Binární klasifikace (např. pozitivní/negativní)
        output_attentions=False,
        output_hidden_states=False,
    )
    
    # Tokenizace textů a příprava vstupních tenzorů
    train_encodings = tokenizer(
        train_texts,
        truncation=True,
        padding=True,
        max_length=128,
        return_tensors='pt'
    )
    
    val_encodings = tokenizer(
        validation_texts,
        truncation=True,
        padding=True,
        max_length=128,
        return_tensors='pt'
    )
    
    # Vytvoření tenzorových datasetů
    train_dataset = TensorDataset(
        train_encodings['input_ids'],
        train_encodings['attention_mask'],
        torch.tensor(train_labels)
    )
    
    val_dataset = TensorDataset(
        val_encodings['input_ids'],
        val_encodings['attention_mask'],
        torch.tensor(validation_labels)
    )
    
    # Vytvoření dataloaderů
    batch_size = 16
    train_dataloader = DataLoader(
        train_dataset,
        sampler=RandomSampler(train_dataset),
        batch_size=batch_size
    )
    
    val_dataloader = DataLoader(
        val_dataset,
        sampler=SequentialSampler(val_dataset),
        batch_size=batch_size
    )
    
    # Nastavení optimalizátoru a plánovače
    optimizer = AdamW(model.parameters(), lr=5e-5)
    
    # Celkové kroky pro plánovač
    total_steps = len(train_dataloader) * epochs
    
    # Vytvoření plánovače rychlosti učení
    scheduler = get_linear_schedule_with_warmup(
        optimizer,
        num_warmup_steps=0,
        num_training_steps=total_steps
    )
    
    # Kontrola dostupnosti GPU
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model.to(device)
    
    # Trénovací smyčka
    for epoch in range(epochs):
        print(f'======== Epoch {epoch+1} / {epochs} ========')
        
        # Trénování
        model.train()
        total_train_loss = 0
        
        for batch in train_dataloader:
            # Přidání dávky na zařízení
            input_ids = batch[0].to(device)
            attention_mask = batch[1].to(device)
            labels = batch[2].to(device)
            
            # Vynulování gradientů
            optimizer.zero_grad()
            
            # Dopředný průchod
            outputs = model(
                input_ids=input_ids,
                attention_mask=attention_mask,
                labels=labels
            )
            
            loss = outputs.loss
            total_train_loss += loss.item()
            
            # Zpětný průchod
            loss.backward()
            
            # Oříznutí gradientů pro prevenci explodujících gradientů
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            
            # Aktualizace parametrů
            optimizer.step()
            
            # Aktualizace rychlosti učení
            scheduler.step()
        
        avg_train_loss = total_train_loss / len(train_dataloader)
        print(f"Průměrná tréninková ztráta: {avg_train_loss:.4f}")
        
        # Validace
        model.eval()
        total_val_loss = 0
        predictions, true_labels = [], []
        
        for batch in val_dataloader:
            input_ids = batch[0].to(device)
            attention_mask = batch[1].to(device)
            labels = batch[2].to(device)
            
            with torch.no_grad():
                outputs = model(
                    input_ids=input_ids,
                    attention_mask=attention_mask,
                    labels=labels
                )
            
            loss = outputs.loss
            total_val_loss += loss.item()
            
            # Získání predikcí a skutečných štítků
            logits = outputs.logits
            predictions.extend(torch.argmax(logits, dim=1).cpu().numpy())
            true_labels.extend(labels.cpu().numpy())
        
        avg_val_loss = total_val_loss / len(val_dataloader)
        val_accuracy = accuracy_score(true_labels, predictions)
        
        print(f"Validační ztráta: {avg_val_loss:.4f}")
        print(f"Validační přesnost: {val_accuracy:.4f}")
    
    return model, tokenizer
```

## 5. Strategie adaptace domény

Adaptace domény řeší výzvu přizpůsobení modelů trénovaných na jedné datové distribuci tak, aby dobře fungovaly na jiné, ale související distribuci.

```python
# Implementace adaptace domény s vrstvou obráceného gradientu (GRL)
import torch.autograd as autograd

class GradientReversalLayer(autograd.Function):
    @staticmethod
    def forward(ctx, x, alpha):
        ctx.alpha = alpha
        return x.clone()
    
    @staticmethod
    def backward(ctx, grad_output):
        return grad_output.neg() * ctx.alpha, None

def gradient_reverse(x, alpha=1.0):
    return GradientReversalLayer.apply(x, alpha)

class DomainAdaptationModel(nn.Module):
    def __init__(self, feature_extractor, num_classes):
        super(DomainAdaptationModel, self).__init__()
        self.feature_extractor = feature_extractor
        
        # Klasifikátor úlohy (např. klasifikace obrázků)
        self.task_classifier = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes)
        )
        
        # Klasifikátor domény (zdrojová vs. cílová)
        self.domain_classifier = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, 2)  # binární klasifikace: zdrojová nebo cílová
        )
        
    def forward(self, x, alpha=1.0):
        features = self.feature_extractor(x)
        
        # Predikce úlohy
        task_output = self.task_classifier(features)
        
        # Obrácení gradientu pro adaptaci domény
        reversed_features = gradient_reverse(features, alpha)
        domain_output = self.domain_classifier(reversed_features)
        
        return task_output, domain_output
```

### Implementace doménově-adversariálního tréninku

```python
def train_domain_adaptation(source_loader, target_loader, model, epochs=10, device='cuda'):
    model = model.to(device)
    
    # Ztrátové funkce
    task_criterion = nn.CrossEntropyLoss()
    domain_criterion = nn.CrossEntropyLoss()
    
    # Optimalizátor
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)
    
    for epoch in range(epochs):
        model.train()
        running_task_loss = 0.0
        running_domain_loss = 0.0
        total_samples = 0
        correct_task = 0
        correct_domain = 0
        
        # Průchod dávkami zdrojových a cílových dat
        for (source_inputs, source_labels), (target_inputs, _) in zip(source_loader, target_loader):
            source_inputs, source_labels = source_inputs.to(device), source_labels.to(device)
            target_inputs = target_inputs.to(device)
            
            # Vytvoření štítků domény: source=0, target=1
            source_domain_labels = torch.zeros(source_inputs.size(0), dtype=torch.long).to(device)
            target_domain_labels = torch.ones(target_inputs.size(0), dtype=torch.long).to(device)
            
            # Vynulování gradientů
            optimizer.zero_grad()
            
            # Výpočet adaptačního faktoru
            p = float(epoch) / epochs
            alpha = 2. / (1. + np.exp(-10 * p)) - 1  # postupně zvyšovat alpha
            
            # Dopředný průchod na zdrojových datech
            task_output_source, domain_output_source = model(source_inputs, alpha)
            
            # Dopředný průchod na cílových datech
            _, domain_output_target = model(target_inputs, alpha)
            
            # Výpočet ztráty úlohy (pouze na zdrojových datech)
            task_loss = task_criterion(task_output_source, source_labels)
            
            # Výpočet ztráty domény (na zdrojových i cílových datech)
            domain_loss_source = domain_criterion(domain_output_source, source_domain_labels)
            domain_loss_target = domain_criterion(domain_output_target, target_domain_labels)
            domain_loss = domain_loss_source + domain_loss_target
            
            # Kombinovaná ztráta
            loss = task_loss + domain_loss
            
            # Zpětný průchod a optimalizace
            loss.backward()
            optimizer.step()
            
            # Statistiky
            running_task_loss += task_loss.item() * source_inputs.size(0)
            running_domain_loss += domain_loss.item() * (source_inputs.size(0) + target_inputs.size(0))
            total_samples += source_inputs.size(0)
            
            # Přesnost úlohy (na zdrojových datech)
            _, predicted = torch.max(task_output_source, 1)
            correct_task += (predicted == source_labels).sum().item()
            
            # Přesnost domény
            _, domain_pred_source = torch.max(domain_output_source, 1)
            _, domain_pred_target = torch.max(domain_output_target, 1)
            correct_domain += (domain_pred_source == source_domain_labels).sum().item()
            correct_domain += (domain_pred_target == target_domain_labels).sum().item()
        
        # Statistiky za epochu
        task_loss = running_task_loss / total_samples
        task_acc = correct_task / total_samples
        domain_loss = running_domain_loss / (total_samples * 2)  # zdrojová + cílová
        domain_acc = correct_domain / (total_samples * 2)  # zdrojová + cílová
        
        print(f'Epocha {epoch+1}/{epochs}: '
              f'Ztráta úlohy: {task_loss:.4f}, Přesnost úlohy: {task_acc:.4f}, '
              f'Ztráta domény: {domain_loss:.4f}, Přesnost domény: {domain_acc:.4f}')
    
    return model
```

## 6. Progresivní a postupné dolaďování

Progresivní dolaďování zahrnuje postupné odmrazování a dolaďování vrstev modelu, počínaje výstupními vrstvami a postupným přechodem zpět.

```python
def progressive_fine_tuning(base_model, train_data, val_data, epochs_per_stage=3):
    """
    Progresivně doladit model postupným odmrazováním vrstev
    """
    # Fáze 1: Trénovat pouze nově přidanou klasifikační hlavičku
    for layer in base_model.layers:
        layer.trainable = False
    
    # Přidat klasifikační hlavičku
    model = keras.Sequential([
        base_model,
        keras.layers.GlobalAveragePooling2D(),
        keras.layers.Dense(256, activation='relu'),
        keras.layers.Dense(num_classes, activation='softmax')
    ])
    
    model.compile(
        optimizer=keras.optimizers.Adam(1e-4),
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    print("Fáze 1: Trénování pouze klasifikační hlavičky")
    model.fit(train_data, validation_data=val_data, epochs=epochs_per_stage)
    
    # Získat všechny vrstvy, které lze odmrazit (typicky konvoluční bloky)
    trainable_layers = [layer for layer in base_model.layers 
                        if isinstance(layer, keras.layers.Conv2D)]
    
    # Počet fází = počet bloků k odmrazení + 1 (pro trénink hlavičky)
    num_blocks = len(trainable_layers) // 3  # Předpoklad ~3 konv. vrstvy na blok
    
    # Začít posledním blokem a postupovat zpět
    for stage in range(2, num_blocks + 2):
        print(f"Fáze {stage}: Odmrazování dalších vrstev")
        
        # Vypočítat, kolik vrstev odmrazit v této fázi
        layers_to_unfreeze = len(trainable_layers) // (num_blocks + 1 - stage)
        
        # Odmrazit podmnožinu vrstev od konce
        for layer in trainable_layers[-layers_to_unfreeze:]:
            layer.trainable = True
        
        # Rekompilovat s nižší rychlostí učení
        model.compile(
            optimizer=keras.optimizers.Adam(1e-5 / stage),  # Postupně nižší rychlost učení
            loss='categorical_crossentropy',
            metrics=['accuracy']
        )
        
        # Trénovat pro tuto fázi
        model.fit(train_data, validation_data=val_data, epochs=epochs_per_stage)
    
    return model
```

## 8. Prevence katastrofického zapomínání

Katastrofické zapomínání nastává, když model ztrácí dříve získané znalosti po doladění na nové úloze. Existuje několik technik, které pomáhají tento problém zmírnit.

```python
# Implementace Elastic Weight Consolidation (EWC)
class ElasticWeightConsolidation:
    def __init__(self, model, old_tasks_data, importance=1000):
        self.model = model
        self.old_tasks_data = old_tasks_data
        self.importance = importance
        self.fisher_matrix = None
        self.old_params = None
        
    def compute_fisher_matrix(self):
        # Uložení kopie aktuálních parametrů
        self.old_params = {name: param.clone().detach()
                          for name, param in self.model.named_parameters() if param.requires_grad}
        
        # Inicializace Fisher matrix nulami
        self.fisher_matrix = {name: torch.zeros_like(param)
                             for name, param in self.old_params.items()}
        
        # Nastavení modelu do evaluačního režimu
        self.model.eval()
        
        # Výpočet Fisher information matrix
        for inputs, targets in self.old_tasks_data:
            self.model.zero_grad()
            
            # Dopředný průchod
            outputs = self.model(inputs)
            
            # Výpočet ztráty
            loss = F.cross_entropy(outputs, targets)
            
            # Zpětný průchod
            loss.backward()
            
            # Akumulace kvadrátů gradientů v Fisher matrix
            for name, param in self.model.named_parameters():
                if param.requires_grad and param.grad is not None:
                    self.fisher_matrix[name] += param.grad.pow(2).detach()
        
        # Normalizace počtem vzorků
        for name in self.fisher_matrix:
            self.fisher_matrix[name] /= len(self.old_tasks_data)
    
    def ewc_loss(self):
        loss = 0
        for name, param in self.model.named_parameters():
            if name in self.fisher_matrix and param.requires_grad:
                # Výpočet penalizace: importance * Fisher * (current_params - old_params)^2
                loss += (self.importance * self.fisher_matrix[name] * 
                         (param - self.old_params[name]).pow(2)).sum()
        return loss
    
    def train_with_ewc(self, train_loader, val_loader, criterion, optimizer, epochs=10):
        # Výpočet Fisher matrix před trénováním na nové úloze
        self.compute_fisher_matrix()
        
        for epoch in range(epochs):
            self.model.train()
            running_loss = 0.0
            
            for inputs, targets in train_loader:
                # Dopředný průchod
                outputs = self.model(inputs)
                
                # Výpočet ztráty úlohy
                task_loss = criterion(outputs, targets)
                
                # Přidání EWC regularizační ztráty
                ewc_reg_loss = self.ewc_loss()
                
                # Celková ztráta
                loss = task_loss + ewc_reg_loss
                
                # Zpětný průchod a optimalizace
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
                
                running_loss += loss.item()
            
            print(f'Epocha {epoch+1}/{epochs}, Ztráta: {running_loss/len(train_loader):.4f}')
            
            # Vyhodnocení na validační sadě
            self.model.eval()
            correct = 0
            total = 0
            with torch.no_grad():
                for inputs, targets in val_loader:
                    outputs = self.model(inputs)
                    _, predicted = torch.max(outputs.data, 1)
                    total += targets.size(0)
                    correct += (predicted == targets).sum().item()
            
            print(f'Validační přesnost: {100 * correct / total:.2f}%')
```

## 10. Shrnutí

Dolaďování a adaptace modelů je nezbytná technika v oblasti hlubokého učení, která umožňuje využít předtrénované modely pro nové úlohy s omezenými daty. Klíčové poznatky zahrnují:

1. **Přenosové učení** umožňuje znovu využít znalosti z modelů trénovaných na velkých datových sadách, šetří čas a výpočetní zdroje.

2. **Přístupy k dolaďování**:
   - Extrakce příznaků: Zmrazit předtrénovaný model, trénovat pouze novou klasifikační hlavičku
   - Částečné dolaďování: Zmrazit počáteční vrstvy, doladit pozdější vrstvy
   - Úplné dolaďování: Přetrénovat celou síť s opatrným nastavením parametrů

3. **Adaptace domény** pomáhá modelům generalizovat napříč různými, ale souvisejícími datovými distribucemi.

4. **Progresivní dolaďování** postupně odmrazuje vrstvy od shora dolů, což často vede k lepším výsledkům.

5. **Optimalizace hyperparametrů** je při dolaďování zásadní, zejména pro rychlosti učení a regularizaci.

6. **Katastrofickému zapomínání** lze předejít pomocí technik jako je Elastic Weight Consolidation.

7. **Důkladné vyhodnocení** je nezbytné k ověření, že doladěné modely dobře generalizují na nové úlohy.

8. **Osvědčené postupy**:
   - Používat menší rychlosti učení pro dolaďování předtrénovaných vrstev
   - Aplikovat vhodnou regularizaci k prevenci přeučení
   - Sledovat validační výkon, aby nedošlo k degradaci předtrénovaných znalostí

Ovládnutím těchto technik můžete efektivně adaptovat state-of-the-art modely pro vaše specifické případy použití a dosáhnout vysokého výkonu i s omezenými trénovacími daty.
