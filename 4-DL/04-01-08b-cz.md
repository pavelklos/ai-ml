## Vztah mezi TensorFlow a Keras

TensorFlow je open-source framework pro strojové učení vyvinutý Googlem, zatímco Keras je vysokoúrovňové API pro neuronové sítě, které může běžet na TensorFlow. Od verze TensorFlow 2.0 je Keras integrován jako oficiální vysokoúrovňové API TensorFlow.

### Úrovně API v TensorFlow:
1. **Nízkoúrovňové API**: Základní operace TensorFlow (tenzory, proměnné, gradienty)
2. **Středněúrovňové API**: Vrstvy, metriky, optimalizátory, callbacky
3. **Vysokoúrovňové API**: Keras (vytváření modelů, trénování, evaluace)

## Základy TensorFlow

Základním konceptem v TensorFlow je tenzor - vícerozměrné pole. Porozumění práce s tenzory je základem pro efektivní používání TensorFlow.

### Klíčové koncepty TensorFlow:
1. **Tenzory**: Vícerozměrná pole s jednotným typem
2. **Proměnné**: Speciální tenzory, které uchovávají stav napříč operacemi
3. **Operace**: Matematické výpočty prováděné na tenzorech
4. **Výpočetní graf**: Série operací TensorFlow uspořádaných do grafu
5. **Eager Execution**: Okamžité vyhodnocování operací (výchozí v TF 2.x)

```python
# Vytvoření tenzorů různých dimenzí
scalar = tf.constant(5)  # 0D tenzor (skalár)
vector = tf.constant([1, 2, 3])  # 1D tenzor (vektor)
matrix = tf.constant([[1, 2], [3, 4]])  # 2D tenzor (matice)
tensor_3d = tf.constant([[[1, 2], [3, 4]], [[5, 6], [7, 8]]])  # 3D tenzor

# Operace s tenzory
a = tf.constant([[1, 2], [3, 4]])
b = tf.constant([[5, 6], [7, 8]])
print(f"Součet: \n{a + b}")
print(f"Násobení (prvek po prvku): \n{a * b}")
print(f"Maticové násobení: \n{tf.matmul(a, b)}")
```

## Úvod do Keras API

Keras je vysokoúrovňové API TensorFlow navržené pro zjednodušení procesu vytváření a trénování modelů. Poskytuje intuitivní abstrakce pro práci s neuronovými sítěmi.

### Klíčové komponenty Keras API:
1. **Modely**: Definují strukturu neuronové sítě
2. **Vrstvy**: Stavební bloky neuronových sítí
3. **Optimalizátory**: Algoritmy pro aktualizaci vah modelu
4. **Ztrátové funkce**: Měří výkon modelu během trénování
5. **Metriky**: Sledují výkon během trénování a testování

## Vytváření modelů s Keras

Keras nabízí dva hlavní způsoby vytváření modelů:
1. **Sequential API**: Jednoduchý lineární zásobník vrstev
2. **Functional API**: Flexibilnější přístup umožňující modely s více vstupy/výstupy nebo sdílenými vrstvami

```python
# Vytvoření modelu pomocí Sequential API
sequential_model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(10,)),
    tf.keras.layers.Dense(32, activation='relu'),
    tf.keras.layers.Dense(16, activation='relu'),
    tf.keras.layers.Dense(1, activation='sigmoid')
])

# Kompilace modelu
sequential_model.compile(
    optimizer='adam',
    loss='binary_crossentropy',
    metrics=['accuracy']
)
```

### Vlastní vrstvy a modely

Keras umožňuje vytvářet vlastní vrstvy a modely pomocí dědění z tříd `tf.keras.layers.Layer` a `tf.keras.Model`.

```python
# Vytvoření vlastní vrstvy
class CustomDense(tf.keras.layers.Layer):
    def __init__(self, units, activation=None):
        super(CustomDense, self).__init__()
        self.units = units
        self.activation = tf.keras.activations.get(activation)
        
    def build(self, input_shape):
        # Vytvoření trénovatelných vah
        self.w = self.add_weight(
            shape=(input_shape[-1], self.units),
            initializer='random_normal',
            trainable=True,
        )
        self.b = self.add_weight(
            shape=(self.units,),
            initializer='zeros',
            trainable=True,
        )
        
    def call(self, inputs):
        # Definice výpočtu
        output = tf.matmul(inputs, self.w) + self.b
        if self.activation is not None:
            output = self.activation(output)
        return output
```

## Trénování a evaluace

Po vytvoření a kompilaci modelu následuje trénování a evaluace:
1. **Trénování**: `model.fit()` pro dávkové trénování
2. **Evaluace**: `model.evaluate()` pro měření výkonu na testovacích datech
3. **Predikce**: `model.predict()` pro generování predikcí na nových datech

```python
# Trénování modelu
history = sequential_model.fit(
    x_train, y_train,
    epochs=10,
    batch_size=32,
    validation_data=(x_val, y_val),
    verbose=1
)

# Evaluace modelu
test_results = sequential_model.evaluate(x_test, y_test, verbose=1)
print(f"Testovací ztráta: {test_results[0]:.4f}, Testovací přesnost: {test_results[1]:.4f}")
```

### Použití callbacks

Callbacks v Keras umožňují provádět akce během trénování, jako je:
- Ukládání checkpointů
- Předčasné zastavení (early stopping) pro prevenci přetrénování
- Úprava learning rate
- Logování metrik do TensorBoard

## Ukládání a načítání modelů

TensorFlow/Keras poskytuje několik způsobů ukládání a načítání modelů:
1. **HDF5 formát**: Uložení celého modelu (architektura, váhy, stav optimizéru)
2. **SavedModel formát**: Doporučený formát TensorFlow pro ukládání modelů
3. **Váhy modelu**: Uložení pouze vah modelu
4. **Architektura modelu**: Uložení pouze architektury modelu jako JSON nebo YAML

## TensorFlow Datasety

TensorFlow poskytuje vestavěné datasety a nástroje pro efektivní práci s daty:
1. **tf.data API**: Vytváření datových pipeline pro efektivní načítání a předzpracování dat
2. **TensorFlow Datasets (TFDS)**: Knihovna předpřipravených datasetů
3. **Vestavěné datasety v Keras**: Populární datasety jako MNIST, CIFAR-10, atd.

```python
# Použití tf.data API pro vytvoření efektivních datových pipeline
train_dataset = tf.data.Dataset.from_tensor_slices((x_mnist_train, y_mnist_train))
train_dataset = train_dataset.shuffle(10000)  # Promíchání dat
train_dataset = train_dataset.batch(32)       # Vytvoření dávek po 32 vzorcích
train_dataset = train_dataset.prefetch(tf.data.AUTOTUNE)  # Předběžné načítání pro efektivitu
```

## Použití předtrénovaných modelů

TensorFlow/Keras poskytuje přístup k mnoha předtrénovaným modelům, které lze použít pro:
1. **Extrakci příznaků**: Použití předtrénovaného modelu jako extraktoru příznaků
2. **Transfer learning**: Dotrénování předtrénovaného modelu na specifickou úlohu
3. **Úpravu modelu**: Modifikace částí předtrénovaných architektur

```python
# Načtení předtrénovaného modelu (MobileNetV2)
base_model = tf.keras.applications.MobileNetV2(
    input_shape=(224, 224, 3),
    include_top=False,  # Nezahrnout klasifikační hlavičku
    weights='imagenet'  # Předtrénováno na ImageNet
)

# Zmrazení vrstev základního modelu
base_model.trainable = False

# Vytvoření nového modelu s předtrénovaným modelem jako extraktorem příznaků
inputs = tf.keras.Input(shape=(224, 224, 3))
x = base_model(inputs, training=False)
x = tf.keras.layers.GlobalAveragePooling2D()(x)
x = tf.keras.layers.Dense(256, activation='relu')(x)
outputs = tf.keras.layers.Dense(10, activation='softmax')(x)

transfer_model = tf.keras.Model(inputs, outputs)
```
