## Úvod do augmentace dat

Augmentace dat je technika používaná k umělému zvětšení velikosti trénovacího datasetu vytvořením modifikovaných verzí existujících dat. Tyto modifikace zachovávají základní charakteristiky dat a zároveň zavádějí variace, které pomáhají modelům naučit se robustnější vlastnosti a lépe generalizovat na neviděné příklady.

## Proč je augmentace dat důležitá

Augmentace dat řeší několik kritických výzev v hlubokém učení:

1. **Omezená data**: Když je trénovacích dat málo, augmentace efektivně násobí velikost datasetu
2. **Prevence přetrénování**: Vytváření různých variant trénovacích příkladů snižuje memorování
3. **Robustnost**: Modely se učí invarianci vůči specifickým transformacím, což zlepšuje generalizaci
4. **Nevyváženost tříd**: Minoritní třídy lze augmentovat pro vyvážení datasetu

```python
# Porovnání výkonnosti modelu s a bez augmentace dat
def compare_with_without_augmentation():
    # Načtení malého datasetu (např. CIFAR-10 podmnožina)
    (x_train, y_train), (x_test, y_test) = tf.keras.datasets.cifar10.load_data()
    # Použití pouze 20 % trénovacích dat pro simulaci nedostatku dat
    x_train = x_train[:10000]
    y_train = y_train[:10000]
    
    # Normalizace hodnot pixelů
    x_train = x_train.astype('float32') / 255.0
    x_test = x_test.astype('float32') / 255.0
    
    # Vytvoření jednoduchého CNN modelu
    def create_model():
        model = models.Sequential([
            layers.Conv2D(32, (3, 3), activation='relu', input_shape=(32, 32, 3)),
            layers.MaxPooling2D((2, 2)),
            layers.Conv2D(64, (3, 3), activation='relu'),
            layers.MaxPooling2D((2, 2)),
            layers.Conv2D(64, (3, 3), activation='relu'),
            layers.Flatten(),
            layers.Dense(64, activation='relu'),
            layers.Dense(10)
        ])
        model.compile(optimizer='adam',
                      loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
                      metrics=['accuracy'])
        return model
    
    # Model bez augmentace
    model_without_aug = create_model()
    history_without_aug = model_without_aug.fit(
        x_train, y_train, epochs=10, validation_data=(x_test, y_test), verbose=0
    )
    
    # Model s augmentací
    datagen = ImageDataGenerator(
        rotation_range=15,
        width_shift_range=0.1,
        height_shift_range=0.1,
        horizontal_flip=True,
        zoom_range=0.1
    )
    
    model_with_aug = create_model()
    history_with_aug = model_with_aug.fit(
        datagen.flow(x_train, y_train, batch_size=32),
        epochs=10, validation_data=(x_test, y_test),
        steps_per_epoch=len(x_train) // 32, verbose=0
    )
    
    # Vykreslení výsledků
    plt.figure(figsize=(12, 4))
    
    plt.subplot(1, 2, 1)
    plt.plot(history_without_aug.history['val_accuracy'], label='Bez augmentace')
    plt.plot(history_with_aug.history['val_accuracy'], label='S augmentací')
    plt.xlabel('Epocha')
    plt.ylabel('Validační přesnost')
    plt.legend()
    
    plt.subplot(1, 2, 2)
    plt.plot(history_without_aug.history['val_loss'], label='Bez augmentace')
    plt.plot(history_with_aug.history['val_loss'], label='S augmentací')
    plt.xlabel('Epocha')
    plt.ylabel('Validační ztráta')
    plt.legend()
    
    plt.tight_layout()
    plt.show()
    
    return history_without_aug, history_with_aug
```

- Rotace, překlopení, posuny, změna měřítka a zkosení
- Ořezávání a doplňování
- Perspektivní transformace

- Úpravy jasu, kontrastu a sytosti
- Posuny barevných kanálů
- Převod na stupně šedi

### Šum a filtrování
- Přidání Gaussova či šumu typu "sůl a pepř"
- Rozmazání a zaostření

```python
# Příklad implementace vlastní funkce pro augmentaci textu
def custom_text_augmenter(text, p_swap=0.1, p_delete=0.1):
    """Jednoduchý vlastní augmentátor textu, který náhodně prohazuje nebo odstraňuje slova"""
    words = text.split()
    result = words.copy()
    
    # Náhodné prohazování sousedních slov
    for i in range(len(result)-1):
        if np.random.random() < p_swap:
            result[i], result[i+1] = result[i+1], result[i]
    
    # Náhodné odstraňování slov
    result = [word for word in result if np.random.random() > p_delete]
    
    return ' '.join(result)
```

```python
# Vytvoření pipeline pro augmentaci zvuku
class AudioAugmenter:
    def __init__(self, sample_rate=22050):
        self.sr = sample_rate
        
    def time_stretch(self, audio, rate_range=(0.8, 1.2)):
        """Roztáhne zvukový signál v čase o náhodný faktor v rozmezí rate_range"""
        rate = np.random.uniform(*rate_range)
        return librosa.effects.time_stretch(audio, rate=rate)
    
    def pitch_shift(self, audio, n_steps_range=(-4, 4)):
        """Posune výšku tónu o n_steps půltónů"""
        n_steps = np.random.uniform(*n_steps_range)
        return librosa.effects.pitch_shift(audio, sr=self.sr, n_steps=n_steps)
    
    def add_noise(self, audio, noise_factor_range=(0.001, 0.01)):
        """Přidá bílý šum do zvuku"""
        noise_factor = np.random.uniform(*noise_factor_range)
        noise = np.random.randn(len(audio))
        return audio + noise_factor * noise
    
    def time_shift(self, audio, shift_range=(-0.5, 0.5)):
        """Posune zvuk v čase o náhodnou velikost v sekundách"""
        shift_sec = np.random.uniform(*shift_range)
        shift_samples = int(self.sr * shift_sec)
        shifted = np.roll(audio, shift_samples)
        # Vynulování přetočených vzorků
        if shift_samples > 0:
            shifted[:shift_samples] = 0
        elif shift_samples < 0:
            shifted[shift_samples:] = 0
        return shifted
    
    def apply_random_augmentations(self, audio, num_augmentations=2):
        """Aplikuje náhodné augmentace na zvuk"""
        augmentation_functions = [
            self.time_stretch,
            self.pitch_shift,
            self.add_noise,
            self.time_shift
        ]
        
        # Vybere náhodnou podmnožinu augmentací
        selected_functions = np.random.choice(
            augmentation_functions, 
            size=min(num_augmentations, len(augmentation_functions)), 
            replace=False
        )
        
        augmented = audio
        for func in selected_functions:
            augmented = func(augmented)
        return augmented
```

## Pokročilé strategie augmentace

Kromě základních technik mohou pokročilé strategie dále zlepšit robustnost modelu:

### Naučené augmentace
- AutoAugment a RandAugment
- Augmentace založená na populaci
- Adversariální trénink

### Techniky míchání vzorků
- Mixup: Mísení obrázků a popisků
- CutMix: Vystřihování a vkládání částí mezi obrázky
- SamplePairing: Průměrování párů obrázků

```python
# Implementace Mixup augmentace v TensorFlow
def mixup_data(x, y, alpha=0.2):
    """Provádí mixup augmentaci na dávkách obrázků"""
    batch_size = tf.shape(x)[0]
    
    # Vzorkování z beta distribuce
    lam = np.random.beta(alpha, alpha, batch_size)
    lam = np.maximum(lam, 1 - lam)
    lam_reshaped = tf.reshape(lam, [batch_size] + [1] * (len(x.shape) - 1))
    
    # Získání zamíchaných indexů
    indices = tf.random.shuffle(tf.range(batch_size))
    
    # Vytvoření smíchaných vzorků
    mixed_x = lam_reshaped * x + (1 - lam_reshaped) * tf.gather(x, indices)
    mixed_y = lam * y + (1 - lam) * tf.gather(y, indices)
    
    return mixed_x, mixed_y

# CutMix implementace pro augmentaci obrázků
def cutmix_data(x, y, alpha=1.0):
    """Provádí CutMix augmentaci na dávkách obrázků"""
    batch_size = tf.shape(x)[0]
    image_h, image_w = x.shape[1], x.shape[2]
    
    # Vzorkování z beta distribuce
    lam = np.random.beta(alpha, alpha)
    
    # Získání náhodných rozměrů boxu
    cut_ratio = np.sqrt(1.0 - lam)
    cut_h = np.int32(image_h * cut_ratio)
    cut_w = np.int32(image_w * cut_ratio)
    
    # Získání náhodného středového bodu
    cx = np.random.randint(image_w)
    cy = np.random.randint(image_h)
    
    # Získání rohů bbox
    x1 = np.clip(cx - cut_w // 2, 0, image_w)
    y1 = np.clip(cy - cut_h // 2, 0, image_h)
    x2 = np.clip(cx + cut_w // 2, 0, image_w)
    y2 = np.clip(cy + cut_h // 2, 0, image_h)
    
    # Získání náhodného vzorku
    indices = tf.random.shuffle(tf.range(batch_size))
    
    # Vytvoření masek pro box
    mask = np.ones((batch_size, image_h, image_w, x.shape[3]))
    mask[:, y1:y2, x1:x2, :] = 0
    
    # Vytvoření cutmix obrázku a popisků
    cutmix_x = x * mask + tf.gather(x, indices) * (1 - mask)
    
    # Upravená lambda založená na skutečné ploše
    area_ratio = ((y2 - y1) * (x2 - x1)) / (image_h * image_w)
    lam = 1 - area_ratio
    
    cutmix_y = lam * y + (1 - lam) * tf.gather(y, indices)
    
    return cutmix_x, cutmix_y

# Vizualizace příkladů mixup a cutmix

    # Vizualizace

        plt.title(f"Původní {i+1}\nPopisek: {np.argmax(batch_y[i])}")
        plt.axis('off')
    
    # Mixup obrázky

        plt.subplot(3, 4, i + 5)
        plt.imshow(mixup_x[i])
        plt.title(f"Mixup {i+1}\nPopisky: {mixup_y[i].numpy().round(2)}")
```

## Osvědčené postupy a běžné chyby

### Osvědčené postupy
1. **Vybírejte augmentace vhodné pro doménu**: Vybírejte techniky, které dávají smysl pro váš specifický typ dat

## Shrnutí

Augmentace dat je mocná technika ke zlepšení generalizace modelu, řešení nedostatku dat a zvýšení robustnosti modelu. Klíčové poznatky:

1. **Zvětšení trénovacích dat**: Augmentace dat uměle rozšiřuje váš trénovací set bez sbírání nových dat.

2. **Techniky specifické pro doménu**: Různé typy dat (obrázky, text, zvuk) vyžadují různé přístupy k augmentaci.

3. **Přístupy k implementaci**: Moderní frameworky hlubokého učení poskytují efektivní nástroje pro integraci augmentace do trénovacích pipeline.

4. **Pokročilé strategie**: Kromě základních transformací nabízejí techniky jako Mixup a CutMix další zvýšení výkonu.

5. **Zlepšení výkonu**: Dobře implementovaná augmentace typicky snižuje přetrénování a zlepšuje generalizaci.

6. **Online vs. offline**: Online augmentace během tréninku je obvykle paměťově efektivnější než předgenerování augmentovaných datasetů.

7. **Osvědčené postupy**: Vybírejte transformace vhodné pro doménu, aplikujte je pouze na trénovací data a laďte jejich parametry.

8. **Multi-modální augmentace**: Pro modely s více typy vstupů může být kombinace různých strategií augmentace obzvláště efektivní.

9. **Zohlednění zdrojů**: Efektivní implementace je důležitá, aby augmentace nepředstavovala úzké místo tréninku.

Při správné implementaci slouží augmentace dat jako základní technika v sadě nástrojů pro hluboké učení, často poskytující významné přínosy za relativně nízkou cenu.
