## 1. Úvod do modelů sekvence-na-sekvenci

Modely sekvence-na-sekvenci (Seq2Seq) jsou rodina architektur neuronových sítí navržených k převodu sekvencí z jedné domény na sekvence v jiné doméně. Vynikají v úlohách, kde vstup i výstup jsou sekvence proměnlivé délky.

```python
import tensorflow as tf
import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.layers import LSTM, Dense, Input, Embedding
from tensorflow.keras.models import Model
```

Běžné aplikace modelů sekvence-na-sekvenci zahrnují:
- Strojový překlad
- Sumarizaci textu
- Rozpoznávání řeči
- Zodpovídání otázek
- Konverzační agenty
- Generování kódu
- Generování hudby

Klíčovou silou těchto modelů je jejich schopnost zpracovat vstupy proměnlivé délky a produkovat výstupy proměnlivé délky, což je činí vysoce flexibilními pro širokou škálu úloh transformace sekvencí.

## 2. Architektura enkodér-dekodér

Základní struktura modelů Seq2Seq se skládá ze dvou hlavních komponent: enkodéru a dekodéru.

```python
# Základní architektura enkodér-dekodér (konceptuální)
def encoder_decoder_concept():
    # Enkodér: Zpracovává vstupní sekvenci do kontextového vektoru
    def encoder(input_sequence):
        # Zpracování vstupní sekvence
        # Vrácení zakódované reprezentace (kontextu)
        context = process_sequence(input_sequence)
        return context
    
    # Dekodér: Generuje výstupní sekvenci na základě kontextu
    def decoder(context, start_token):
        # Inicializace počátečním tokenem
        current_token = start_token
        output_sequence = [current_token]
        
        # Generování sekvence, dokud není dosaženo koncového tokenu nebo max. délky
        while current_token != end_token and len(output_sequence) < max_length:
            # Predikce dalšího tokenu na základě kontextu a předchozích tokenů
            current_token = predict_next_token(context, output_sequence)
            output_sequence.append(current_token)
            
        return output_sequence
    
    # Kompletní model sekvence-na-sekvenci
    def seq2seq(input_sequence):
        context = encoder(input_sequence)
        output_sequence = decoder(context, start_token)
        return output_sequence
```

### Klíčové komponenty:

1. **Enkodér**: Zpracovává vstupní sekvenci a komprimuje ji do kontextového vektoru (nebo sady vektorů), který zachycuje význam vstupu.

2. **Dekodér**: Přebírá kontext od enkodéru a generuje výstupní sekvenci prvek po prvku.

3. **Kontextový vektor**: Mezilehlá reprezentace, která spojuje enkodér a dekodér. V základních modelech jde o vektor pevné velikosti, zatímco v modelech s mechanismy pozornosti je dynamicky vypočítáván pro každý krok dekódování.

## 3. Modely Seq2Seq založené na RNN

Původní modely sekvence-na-sekvenci používaly rekurentní neuronové sítě (RNN), zejména LSTM nebo GRU, jak pro enkodér, tak pro dekodér.

```python
# Implementace modelu Seq2Seq založeného na RNN v TensorFlow/Keras
def create_rnn_seq2seq_model(input_vocab_size, output_vocab_size, 
                            hidden_size=256, embedding_dim=100):
    # Enkodér
    encoder_inputs = Input(shape=(None,))
    encoder_embedding = Embedding(input_vocab_size, embedding_dim)(encoder_inputs)
    encoder_lstm = LSTM(hidden_size, return_state=True)
    _, state_h, state_c = encoder_lstm(encoder_embedding)
    encoder_states = [state_h, state_c]
    
    # Dekodér
    decoder_inputs = Input(shape=(None,))
    decoder_embedding = Embedding(output_vocab_size, embedding_dim)
    decoder_lstm = LSTM(hidden_size, return_sequences=True, return_state=True)
    
    # Propojení enkodéru a dekodéru
    x = decoder_embedding(decoder_inputs)
    decoder_outputs, _, _ = decoder_lstm(x, initial_state=encoder_states)
    decoder_dense = Dense(output_vocab_size, activation='softmax')
    decoder_outputs = decoder_dense(decoder_outputs)
    
    # Vytvoření modelu
    model = Model([encoder_inputs, decoder_inputs], decoder_outputs)
    
    # Vytvoření modelu enkodéru pro vyvozování
    encoder_model = Model(encoder_inputs, encoder_states)
    
    # Vytvoření modelu dekodéru pro vyvozování
    decoder_state_input_h = Input(shape=(hidden_size,))
    decoder_state_input_c = Input(shape=(hidden_size,))
    decoder_states_inputs = [decoder_state_input_h, decoder_state_input_c]
    
    x = decoder_embedding(decoder_inputs)
    decoder_outputs, state_h, state_c = decoder_lstm(
        x, initial_state=decoder_states_inputs)
    decoder_states = [state_h, state_c]
    decoder_outputs = decoder_dense(decoder_outputs)
    
    decoder_model = Model(
        [decoder_inputs] + decoder_states_inputs,
        [decoder_outputs] + decoder_states)
    
    return model, encoder_model, decoder_model
```

```python
# Implementace modelu Seq2Seq založeného na RNN v PyTorch
class EncoderRNN(nn.Module):
    def __init__(self, input_size, hidden_size, embedding_size):
        super(EncoderRNN, self).__init__()
        self.hidden_size = hidden_size
        self.embedding = nn.Embedding(input_size, embedding_size)
        self.gru = nn.GRU(embedding_size, hidden_size)
        
    def forward(self, input, hidden):
        embedded = self.embedding(input).view(1, 1, -1)
        output, hidden = self.gru(embedded, hidden)
        return output, hidden
    
    def init_hidden(self, device):
        return torch.zeros(1, 1, self.hidden_size, device=device)

class DecoderRNN(nn.Module):
    def __init__(self, hidden_size, output_size, embedding_size):
        super(DecoderRNN, self).__init__()
        self.hidden_size = hidden_size
        self.embedding = nn.Embedding(output_size, embedding_size)
        self.gru = nn.GRU(embedding_size, hidden_size)
        self.out = nn.Linear(hidden_size, output_size)
        self.softmax = nn.LogSoftmax(dim=1)
        
    def forward(self, input, hidden):
        embedded = self.embedding(input).view(1, 1, -1)
        output, hidden = self.gru(embedded, hidden)
        output = self.softmax(self.out(output[0]))
        return output, hidden
```

### Problémy se základními modely Seq2Seq založenými na RNN:
1. **Informační úzké hrdlo**: Enkodér komprimuje všechny informace do vektoru pevné velikosti
2. **Dlouhodobé závislosti**: Obtížné zachování informací z počátečních částí dlouhých sekvencí
3. **Mizející gradienty**: Problémy při trénování hlubokých RNN kvůli mizejícím gradientům

## 4. Mechanismy pozornosti (attention)

Mechanismy pozornosti (attention) způsobily revoluci v modelech Seq2Seq tím, že umožnily dekodéru zaměřit se na různé části vstupní sekvence v každém kroku dekódování.

```python
# PyTorch Seq2Seq s mechanismem pozornosti 
class AttnDecoderRNN(nn.Module):
    def __init__(self, hidden_size, output_size, embedding_size, max_length, dropout_p=0.1):
        super(AttnDecoderRNN, self).__init__()
        self.hidden_size = hidden_size
        self.output_size = output_size
        self.embedding_size = embedding_size
        self.max_length = max_length
        self.dropout_p = dropout_p
        
        self.embedding = nn.Embedding(self.output_size, self.embedding_size)
        self.attn = nn.Linear(self.hidden_size * 2, self.max_length)
        self.attn_combine = nn.Linear(self.hidden_size * 2, self.hidden_size)
        self.dropout = nn.Dropout(self.dropout_p)
        self.gru = nn.GRU(self.hidden_size, self.hidden_size)
        self.out = nn.Linear(self.hidden_size, self.output_size)
        
    def forward(self, input, hidden, encoder_outputs):
        embedded = self.embedding(input).view(1, 1, -1)
        embedded = self.dropout(embedded)
        
        # Výpočet vah pozornosti
        attn_weights = torch.softmax(
            self.attn(torch.cat((embedded[0], hidden[0]), 1)), dim=1)
        attn_applied = torch.bmm(attn_weights.unsqueeze(0),
                               encoder_outputs.unsqueeze(0))
        
        # Kombinace vloženého vstupu a pozornosti
        output = torch.cat((embedded[0], attn_applied[0]), 1)
        output = self.attn_combine(output).unsqueeze(0)
        
        output = torch.relu(output)
        output, hidden = self.gru(output, hidden)
        
        output = torch.log_softmax(self.out(output[0]), dim=1)
        return output, hidden, attn_weights
```

### Implementace s mechanismem pozornosti v Tensorflow/Keras:

```python
from tensorflow.keras.layers import Attention, Concatenate

def create_attention_seq2seq_model(input_vocab_size, output_vocab_size, 
                                   hidden_size=256, embedding_dim=100):
    # Enkodér
    encoder_inputs = Input(shape=(None,))
    encoder_embedding = Embedding(input_vocab_size, embedding_dim)(encoder_inputs)
    encoder_lstm = LSTM(hidden_size, return_sequences=True, return_state=True)
    encoder_outputs, state_h, state_c = encoder_lstm(encoder_embedding)
    encoder_states = [state_h, state_c]
    
    # Dekodér
    decoder_inputs = Input(shape=(None,))
    decoder_embedding = Embedding(output_vocab_size, embedding_dim)
    decoder_lstm = LSTM(hidden_size, return_sequences=True, return_state=True)
    
    # Propojení enkodéru a dekodéru
    x = decoder_embedding(decoder_inputs)
    decoder_outputs, _, _ = decoder_lstm(x, initial_state=encoder_states)
    
    # Mechanismus pozornosti
    attention = Attention()([decoder_outputs, encoder_outputs])
    
    # Spojení pozornosti s výstupy dekodéru
    concat = Concatenate()([decoder_outputs, attention])
    
    # Výstupní vrstva
    decoder_dense = Dense(output_vocab_size, activation='softmax')
    decoder_outputs = decoder_dense(concat)
    
    # Vytvoření modelu
    model = Model([encoder_inputs, decoder_inputs], decoder_outputs)
    
    return model
```

### Výhody mechanismu pozornosti:
1. **Překonání informačního úzkého hrdla**: Není nutné komprimovat všechny informace do kontextového vektoru pevné velikosti
2. **Lepší zpracování dlouhých sekvencí**: Přímý přístup ke všem stavům enkodéru
3. **Interpretovatelnost**: Vizualizace vah pozornosti ukazuje, které části vstupu jsou relevantní pro každý výstupní token
4. **Zlepšený výkon**: Výrazná zlepšení v kvalitě překladu a dalších sekvenčních úlohách

## 5. Seq2Seq založené na transformerech

Architektura Transformer, představená v článku "Attention is All You Need" (Vaswani a kol., 2017), způsobila revoluci v modelování sekvence-na-sekvenci nahrazením rekurentních vrstev mechanismy sebepoznání (self-attention).

```python
# Vytvoření modelu Seq2Seq založeného na Transformeru pomocí TensorFlow
import tensorflow as tf
from tensorflow.keras import layers

def transformer_encoder(inputs, head_size, num_heads, ff_dim, dropout=0):
    # Vícevrstvá sebepoznávací vrstva
    attention_output = layers.MultiHeadAttention(
        key_dim=head_size, num_heads=num_heads, dropout=dropout
    )(inputs, inputs)
    attention_output = layers.Dropout(dropout)(attention_output)
    attention_output = layers.LayerNormalization(epsilon=1e-6)(
        inputs + attention_output
    )
    
    # Dopředná neuronová síť
    ffn_output = layers.Dense(ff_dim, activation="relu")(attention_output)
    ffn_output = layers.Dense(inputs.shape[-1])(ffn_output)
    ffn_output = layers.Dropout(dropout)(ffn_output)
    return layers.LayerNormalization(epsilon=1e-6)(
        attention_output + ffn_output
    )

def transformer_decoder(inputs, encoder_outputs, head_size, num_heads, ff_dim, dropout=0):
    # Sebepoznání
    attention_output = layers.MultiHeadAttention(
        key_dim=head_size, num_heads=num_heads, dropout=dropout
    )(inputs, inputs)
    attention_output = layers.LayerNormalization(epsilon=1e-6)(
        inputs + attention_output
    )
    
    # Křížová pozornost
    cross_attention_output = layers.MultiHeadAttention(
        key_dim=head_size, num_heads=num_heads, dropout=dropout
    )(attention_output, encoder_outputs)
    cross_attention_output = layers.LayerNormalization(epsilon=1e-6)(
        attention_output + cross_attention_output
    )
    
    # Dopředná neuronová síť
    ffn_output = layers.Dense(ff_dim, activation="relu")(cross_attention_output)
    ffn_output = layers.Dense(inputs.shape[-1])(ffn_output)
    ffn_output = layers.Dropout(dropout)(ffn_output)
    return layers.LayerNormalization(epsilon=1e-6)(
        cross_attention_output + ffn_output
    )

def build_transformer_model(
    input_vocab_size,
    target_vocab_size,
    encoder_seq_length, 
    decoder_seq_length,
    embed_dim=512, 
    num_heads=8,
    feed_forward_dim=2048,
    num_encoder_blocks=6,
    num_decoder_blocks=6,
    dropout=0.1,
):
    # Vstupy
    encoder_inputs = layers.Input(shape=(None,), name="encoder_inputs")
    decoder_inputs = layers.Input(shape=(None,), name="decoder_inputs")
    
    # Embedding vrstvy
    encoder_embedding = layers.Embedding(input_vocab_size, embed_dim)(encoder_inputs)
    encoder_positional_encoding = positional_encoding(encoder_seq_length, embed_dim)
    encoder_embedding += encoder_positional_encoding[:, :tf.shape(encoder_inputs)[1], :]
    encoder_embedding = layers.Dropout(dropout)(encoder_embedding)
    
    decoder_embedding = layers.Embedding(target_vocab_size, embed_dim)(decoder_inputs)
    decoder_positional_encoding = positional_encoding(decoder_seq_length, embed_dim)
    decoder_embedding += decoder_positional_encoding[:, :tf.shape(decoder_inputs)[1], :]
    decoder_embedding = layers.Dropout(dropout)(decoder_embedding)
    
    # Enkodér
    encoder_outputs = encoder_embedding
    for _ in range(num_encoder_blocks):
        encoder_outputs = transformer_encoder(
            encoder_outputs, embed_dim // num_heads, num_heads, feed_forward_dim, dropout
        )
    
    # Dekodér
    decoder_outputs = decoder_embedding
    for _ in range(num_decoder_blocks):
        decoder_outputs = transformer_decoder(
            decoder_outputs, encoder_outputs, embed_dim // num_heads, 
            num_heads, feed_forward_dim, dropout
        )
    
    # Výstupní vrstva
    outputs = layers.Dense(target_vocab_size, activation="softmax")(decoder_outputs)
    
    return tf.keras.Model([encoder_inputs, decoder_inputs], outputs)

def positional_encoding(sequence_length, embed_dim):
    # Vytvoření poziční kódování, jak je popsáno v článku Transformer
    positions = np.arange(sequence_length)[:, np.newaxis]
    depths = np.arange(embed_dim)[np.newaxis, :] // 2 * 2  # Celočíselné dělení
    
    angle_rates = 1 / np.power(10000, depths / embed_dim)
    angle_rads = positions * angle_rates
    
    # Aplikace sinu na sudé indexy a kosinu na liché indexy
    pos_encoding = np.zeros_like(angle_rads)
    pos_encoding[:, 0::2] = np.sin(angle_rads[:, 0::2])  # Sudé indexy
    pos_encoding[:, 1::2] = np.cos(angle_rads[:, 1::2])  # Liché indexy
    
    return tf.cast(pos_encoding[np.newaxis, ...], dtype=tf.float32)
```

### Příklad Transformer v PyTorch:

```python
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super(PositionalEncoding, self).__init__()
        
        # Vytvoření tabulky pozičního kódování
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        pe = pe.unsqueeze(0)
        
        # Registrace bufferu (není parametr modelu, ale měl by být součástí modulu)
        self.register_buffer('pe', pe)
        
    def forward(self, x):
        # Přidání pozičního kódování ke vstupním embedingům
        return x + self.pe[:, :x.size(1)]

class TransformerSeq2Seq(nn.Module):
    def __init__(self, src_vocab_size, tgt_vocab_size, d_model=512, nhead=8, 
                 num_encoder_layers=6, num_decoder_layers=6, dim_feedforward=2048, dropout=0.1):
        super(TransformerSeq2Seq, self).__init__()
        
        # Embedding vrstvy
        self.src_embedding = nn.Embedding(src_vocab_size, d_model)
        self.tgt_embedding = nn.Embedding(tgt_vocab_size, d_model)
        self.positional_encoding = PositionalEncoding(d_model)
        
        # Transformer vrstvy
        self.transformer = nn.Transformer(
            d_model=d_model, 
            nhead=nhead, 
            num_encoder_layers=num_encoder_layers,
            num_decoder_layers=num_decoder_layers,
            dim_feedforward=dim_feedforward,
            dropout=dropout
        )
        
        # Výstupní vrstva
        self.output_layer = nn.Linear(d_model, tgt_vocab_size)
        
        # Inicializace parametrů
        self._init_parameters()
        
    def _init_parameters(self):
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)
    
    def forward(self, src, tgt, src_mask=None, tgt_mask=None, 
                src_padding_mask=None, tgt_padding_mask=None, memory_key_padding_mask=None):
        
        # Embedding a přidání pozičního kódování
        src = self.positional_encoding(self.src_embedding(src) * math.sqrt(self.src_embedding.embedding_dim))
        tgt = self.positional_encoding(self.tgt_embedding(tgt) * math.sqrt(self.tgt_embedding.embedding_dim))
        
        # Transformer očekává vstupy ve formátu (délka_sekvence, velikost_dávky, dimenze_příznaku)
        src = src.permute(1, 0, 2)
        tgt = tgt.permute(1, 0, 2)
        
        # Dopředný průchod transformerem
        output = self.transformer(src, tgt, src_mask, tgt_mask, None,
                                 src_padding_mask, tgt_padding_mask, memory_key_padding_mask)
        
        # Převedení zpět na (velikost_dávky, délka_sekvence, dimenze_příznaku)
        output = output.permute(1, 0, 2)
        
        # Projekce na velikost slovníku
        return self.output_layer(output)

# Generování čtvercové masky pro dekodér (zabraňuje pozornosti na budoucí pozice)
def generate_square_subsequent_mask(sz, device):
    mask = (torch.triu(torch.ones((sz, sz), device=device)) == 1).transpose(0, 1)
    mask = mask.float().masked_fill(mask == 0, float('-inf')).masked_fill(mask == 1, float(0.0))
    return mask
```

### Hlavní výhody transformerů:
1. **Paralelizace**: Na rozdíl od RNN mohou transformery zpracovávat všechny tokeny paralelně
2. **Globální závislosti**: Self-attention přímo modeluje vztahy mezi všemi pozicemi
3. **Škálovatelnost**: Lépe škáluje na velké datasety a hluboké architektury
4. **State-of-the-art výkon**: Transformery posunuly state-of-the-art ve většině sekvenčních úloh

## 6. Dekódování pomocí beam search

Během odvozování se často používá beam search k generování lepších sekvencí ve srovnání s hladovým dekódováním.

```python
def beam_search_decode(model, encoder_input, start_token, end_token, 
                      max_length=50, beam_width=3):
    """
    Provádí dekódování pomocí beam search pro modely seq2seq
    
    Args:
        model: Model enkodér-dekodér
        encoder_input: Vstupní sekvence k zakódování
        start_token: Token pro začátek dekódované sekvence
        end_token: Token indikující konec sekvence
        max_length: Maximální délka generované sekvence
        beam_width: Počet kandidátů, které je třeba udržovat v každém kroku
    
    Returns:
        best_sequence: Sekvence s nejvyšší pravděpodobností
    """
    # Zakódování vstupní sekvence
    encoder_output = model.encode(encoder_input)
    
    # Inicializace paprsku počátečním tokenem
    beam = [(0.0, [start_token], None)]  # (skóre, sekvence, stav_dekodéru)
    finished_beams = []
    
    # Generování sekvence
    for _ in range(max_length):
        candidates = []
        
        # Pro každou sekvenci v paprsku
        for score, sequence, decoder_state in beam:
            # Pokud sekvence končí end_tokenem
            if sequence[-1] == end_token:
                finished_beams.append((score, sequence))
                continue
                
            # Předpověď dalších tokenů
            logits, new_decoder_state = model.decode_step(
                sequence[-1], decoder_state, encoder_output)
            
            # Získání top-k tokenů
            top_k_logits, top_k_indices = tf.math.top_k(logits, k=beam_width)
            
            # Přidání kandidátů do seznamu
            for i in range(beam_width):
                token = top_k_indices[0, i].numpy()
                log_prob = top_k_logits[0, i].numpy()
                new_score = score + log_prob
                new_sequence = sequence + [token]
                candidates.append((new_score, new_sequence, new_decoder_state))
        
        # Pokud nejsou žádní kandidáti (všechny paprsky dokončeny), přeruš
        if len(candidates) == 0:
            break
            
        # Seřaď kandidáty podle skóre a ponech top beam_width
        candidates.sort(reverse=True, key=lambda x: x[0])
        beam = candidates[:beam_width]
    
    # Přidej všechny zbývající paprsky do dokončeného seznamu
    finished_beams.extend(beam)
    
    # Vrať nejlepší dokončenou sekvenci
    if finished_beams:
        # Seřaď podle skóre
        finished_beams.sort(reverse=True, key=lambda x: x[0])
        best_score, best_sequence = finished_beams[0]
        return best_sequence
    else:
        # Žádná sekvence nebyla dokončena, vrať sekvenci s nejvyšším skóre
        best_score, best_sequence, _ = beam[0]
        return best_sequence
```

### Výhody beam search:
1. **Lepší kvalita**: Udržuje více hypotéz, což vede k produkci lepších sekvencí
2. **Redukovaný vyhledávací prostor**: Efektivnější než vyčerpávající vyhledávání
3. **Laditelný**: Parametr šířky paprsku vyvažuje kvalitu a výpočetní náročnost

## 7. Techniky tréninku a optimalizace

Modely Seq2Seq vyžadují specifické přístupy k tréninku a optimalizaci pro dosažení nejlepších výsledků.

```python
def train_seq2seq(model, train_loader, val_loader, epochs=10, learning_rate=0.001):
    # Definice optimalizátoru
    optimizer = torch.optim.Adam(model.parameters(), lr=learning_rate)
    
    # Definice ztrátové funkce (ignoruje padding token)
    criterion = nn.CrossEntropyLoss(ignore_index=PAD_TOKEN)
    
    # Plánovač rychlosti učení
    scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
        optimizer, mode='min', factor=0.5, patience=2, verbose=True)
    
    # Poměr teacher forcing (začíná vysoko a postupně klesá)
    teacher_forcing_ratio = 0.9
    
    for epoch in range(epochs):
        model.train()
        total_loss = 0
        
        for batch_idx, (src, tgt) in enumerate(train_loader):
            # Vynulování gradientů
            optimizer.zero_grad()
            
            # Získej vstupní a cílové sekvence
            input_seq, target_seq = src, tgt[:, :-1]  # Odstranění EOS z cílového vstupu
            target_output = tgt[:, 1:]  # Odstranění SOS z cílového výstupu
            
            # Aplikuj teacher forcing na základě poměru
            use_teacher_forcing = random.random() < teacher_forcing_ratio
            
            if use_teacher_forcing:
                # Teacher forcing: Použij cíl jako další vstup
                output = model(input_seq, target_seq)
            else:
                # Bez teacher forcing: Použij vlastní predikce modelu
                output = []
                decoder_input = target_seq[:, 0].unsqueeze(1)  # Začni s SOS
                
                for i in range(target_seq.size(1)):
                    # Dopředný průchod
                    prediction = model(input_seq, decoder_input)
                    # Získej poslední predikci
                    last_prediction = prediction[:, -1:, :]
                    output.append(last_prediction)
                    
                    # Získej další vstup (buď z předpovědi nebo cíle)
                    _, next_tokens = last_prediction.max(dim=2)
                    decoder_input = torch.cat([decoder_input, next_tokens], dim=1)
                
                # Spoj výstupy
                output = torch.cat(output, dim=1)
            
            # Přetvaruj výstupy a cíle pro výpočet ztráty
            output = output.reshape(-1, output.size(-1))
            target_output = target_output.reshape(-1)
            
            # Výpočet ztráty
            loss = criterion(output, target_output)
            
            # Zpětná propagace
            loss.backward()
            
            # Oříznutí gradientů pro prevenci explodujících gradientů
            torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
            
            # Aktualizace vah
            optimizer.step()
            
            # Sledování ztráty
            total_loss += loss.item()
            
            # Zobrazení průběhu
            if batch_idx % 100 == 0:
                print(f'Epocha: {epoch+1}, Dávka: {batch_idx}, Ztráta: {loss.item():.4f}')
        
        # Validace
        val_loss = validate_seq2seq(model, val_loader, criterion)
        
        # Aktualizace rychlosti učení na základě validační ztráty
        scheduler.step(val_loss)
        
        # Snížení poměru teacher forcing
        teacher_forcing_ratio = max(0.1, teacher_forcing_ratio * 0.9)
        
        print(f'Epocha: {epoch+1}, Tréninková ztráta: {total_loss/len(train_loader):.4f}, '
              f'Validační ztráta: {val_loss:.4f}')

def validate_seq2seq(model, val_loader, criterion):
    model.eval()
    total_loss = 0
    
    with torch.no_grad():
        for src, tgt in val_loader:
            # Získej vstupní a cílové sekvence
            input_seq, target_seq = src, tgt[:, :-1]
            target_output = tgt[:, 1:]
            
            # Dopředný průchod
            output = model(input_seq, target_seq)
            
            # Přetvaruj výstupy a cíle
            output = output.reshape(-1, output.size(-1))
            target_output = target_output.reshape(-1)
            
            # Výpočet ztráty
            loss = criterion(output, target_output)
            total_loss += loss.item()
    
    return total_loss / len(val_loader)
```

### Klíčové techniky tréninku:
1. **Teacher forcing**: Použití skutečných hodnot jako vstupů dekodéru během tréninku
2. **Scheduled sampling**: Postupný přechod z teacher forcing na používání vlastních predikcí modelu
3. **Label smoothing**: Prevence přílišné sebedůvěry modelu změkčením cílové distribuce
4. **Ořezávání gradientu**: Prevence explodujících gradientů během zpětné propagace
5. **Plánování rychlosti učení**: Úprava rychlosti učení během tréninku

```python
# Příklad: Jednoduchý strojový překlad s TensorFlow/Keras
def build_machine_translation_model(source_vocab_size, target_vocab_size, hidden_units=256):
    # Enkodér
    encoder_inputs = tf.keras.layers.Input(shape=(None,))
    enc_emb = tf.keras.layers.Embedding(source_vocab_size, hidden_units)(encoder_inputs)
    
    encoder = tf.keras.layers.Bidirectional(
        tf.keras.layers.LSTM(hidden_units, return_state=True, return_sequences=True)
    )
    encoder_outputs, forward_h, forward_c, backward_h, backward_c = encoder(enc_emb)
    
    # Spojení dopředných a zpětných stavů
    state_h = tf.keras.layers.Concatenate()([forward_h, backward_h])
    state_c = tf.keras.layers.Concatenate()([forward_c, backward_c])
    encoder_states = [state_h, state_c]
    
    # Dekodér
    decoder_inputs = tf.keras.layers.Input(shape=(None,))
    dec_emb = tf.keras.layers.Embedding(target_vocab_size, hidden_units*2)(decoder_inputs)
    
    # Nastavení dekodéru se stavy enkodéru jako počátečním stavem
    decoder_lstm = tf.keras.layers.LSTM(hidden_units*2, return_sequences=True, return_state=True)
    decoder_outputs, _, _ = decoder_lstm(dec_emb, initial_state=encoder_states)
    
    # Mechanismus pozornosti
    attention = tf.keras.layers.Attention()([decoder_outputs, encoder_outputs])
    
    # Spojení výstupu pozornosti s výstupem dekodéru
    concat = tf.keras.layers.Concatenate()([decoder_outputs, attention])
    
    # Výstupní vrstva
    decoder_dense = tf.keras.layers.Dense(target_vocab_size, activation='softmax')
    output = decoder_dense(concat)
    
    # Vytvoření modelu
    model = tf.keras.Model([encoder_inputs, decoder_inputs], output)
    
    # Kompilace modelu
    model.compile(
        optimizer='adam',
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
    
    return model
```

Zde je kompletní příklad vytvoření jednoduchého modelu Seq2Seq pro překlad z angličtiny do španělštiny.

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras.layers import Input, LSTM, Embedding, Dense, Attention, Concatenate
from tensorflow.keras.models import Model
from tensorflow.keras.preprocessing.text import Tokenizer
from tensorflow.keras.preprocessing.sequence import pad_sequences

# Vzorová data (velmi malá pro demonstraci)
english_sentences = [
    'hello how are you',
    'thank you very much',
    'I love machine learning',
    'what is your name',
    'where are you going'
]

spanish_sentences = [
    'hola como estas',
    'muchas gracias',
    'me encanta el aprendizaje automatico',
    'cual es tu nombre',
    'a donde vas'
]

# Tokenizace vstupů
english_tokenizer = Tokenizer()
english_tokenizer.fit_on_texts(english_sentences)
english_vocab_size = len(english_tokenizer.word_index) + 1

spanish_tokenizer = Tokenizer()
spanish_tokenizer.fit_on_texts(spanish_sentences)
spanish_vocab_size = len(spanish_tokenizer.word_index) + 1

# Převedení textu na sekvence
english_sequences = english_tokenizer.texts_to_sequences(english_sentences)
spanish_sequences = spanish_tokenizer.texts_to_sequences(spanish_sentences)

# Přidání start a end tokenů k cílovým sekvencím
# Použití indexu 0 pro padding, 1 pro start a 2 pro end
decoder_input_data = [[1] + seq for seq in spanish_sequences]
decoder_target_data = [seq + [2] for seq in spanish_sequences]

# Padding sekvencí
max_english_len = max(len(seq) for seq in english_sequences)
max_spanish_len = max(len(seq) for seq in spanish_sequences) + 1  # +1 pro start/end token

encoder_input_data = pad_sequences(english_sequences, maxlen=max_english_len, padding='post')
decoder_input_data = pad_sequences(decoder_input_data, maxlen=max_spanish_len, padding='post')
decoder_target_data = pad_sequences(decoder_target_data, maxlen=max_spanish_len, padding='post')

# Vytvoření modelu
def build_translation_model(input_vocab_size, output_vocab_size, input_maxlen, output_maxlen, units=128):
    # Enkodér
    encoder_inputs = Input(shape=(input_maxlen,))
    encoder_embedding = Embedding(input_vocab_size, units, mask_zero=True)(encoder_inputs)
    encoder_outputs, state_h, state_c = LSTM(units, return_state=True, return_sequences=True)(encoder_embedding)
    encoder_states = [state_h, state_c]
    
    # Dekodér
    decoder_inputs = Input(shape=(output_maxlen,))
    decoder_embedding = Embedding(output_vocab_size, units, mask_zero=True)(decoder_inputs)
    decoder_lstm = LSTM(units, return_sequences=True, return_state=True)
    decoder_outputs, _, _ = decoder_lstm(decoder_embedding, initial_state=encoder_states)
    
    # Pozornost
    attention_layer = Attention()
    attention_output = attention_layer([decoder_outputs, encoder_outputs])
    concat = Concatenate()([decoder_outputs, attention_output])
    
    # Výstupní vrstva
    decoder_dense = Dense(output_vocab_size, activation='softmax')
    decoder_outputs = decoder_dense(concat)
    
    # Definice modelu
    model = Model([encoder_inputs, decoder_inputs], decoder_outputs)
    
    return model

# Vytvoření a kompilace modelu
model = build_translation_model(
    english_vocab_size, 
    spanish_vocab_size, 
    max_english_len, 
    max_spanish_len
)

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')

# Trénování modelu (jen pár epoch pro ukázku)
model.fit(
    [encoder_input_data, decoder_input_data],
    np.expand_dims(decoder_target_data, -1),
    batch_size=2,
    epochs=50
)

# Funkce pro překlad vět
def translate(input_text):
    # Tokenizace a padding vstupu
    input_seq = english_tokenizer.texts_to_sequences([input_text])
    input_seq = pad_sequences(input_seq, maxlen=max_english_len, padding='post')
    
    # Inicializace cílové sekvence start tokenem
    target_seq = np.zeros((1, max_spanish_len))
    target_seq[0, 0] = 1  # Start token
    
    # Generování překladu
    output_text = []
    
    for i in range(max_spanish_len - 1):
        predictions = model.predict([input_seq, target_seq], verbose=0)
        predicted_token = np.argmax(predictions[0, i, :])
        
        if predicted_token == 2:  # End token
            break
            
        if predicted_token > 0:
            output_text.append(predicted_token)
        
        # Aktualizace cílové sekvence pro další predikci
        target_seq[0, i+1] = predicted_token
    
    # Převod tokenů na slova
    output_words = []
    
    for token in output_text:
        for word, index in spanish_tokenizer.word_index.items():
            if index == token:
                output_words.append(word)
                break
    
    return ' '.join(output_words)

# Otestuj překlad
test_sentences = [
    'hello how are you',
    'I love machine learning'
]

for sentence in test_sentences:
    translation = translate(sentence)
    print(f"Angličtina: {sentence}")
    print(f"Španělština: {translation}")
    print()
```

## 10. Shrnutí

Modely sekvence-na-sekvenci poskytují výkonný rámec pro konverzi jedné sekvence na jinou. Klíčové body zahrnují:

1. **Architektura**: Modely Seq2Seq se obvykle skládají z enkodéru, který zpracovává vstup, a dekodéru, který generuje výstup.

2. **Evoluce**: Oblast se vyvinula od základních modelů založených na RNN přes architektury vylepšené pozorností až po modely založené na transformerech.

3. **Mechanismy pozornosti**: Pozornost umožňuje dekodéru zaměřit se na relevantní části vstupu, což výrazně zlepšuje výkon na dlouhých sekvencích.

4. **Transformery**: Architektura transformer se stala dominantní díky své paralelizovatelnosti a schopnosti zachytit dlouhodobé závislosti.

5. **Techniky tréninku**: Specializované metody tréninku jako teacher forcing, scheduled sampling a beam search dekódování jsou nezbytné pro efektivní modely seq2seq.

6. **Aplikace**: Modely seq2seq pohání širokou škálu aplikací včetně překladu, sumarizace, rozpoznávání řeči a dialogových systémů.

7. **Výzvy**: Navzdory svému úspěchu modely seq2seq stále čelí výzvám s velmi dlouhými sekvencemi, výpočetní efektivitou a adaptací na různé domény.

8. **Budoucí směry**: Výzkum pokračuje v oblastech jako efektivní mechanismy pozornosti, lepší dekódovací algoritmy a vylepšené metody předtrénování.

Modely sekvence-na-sekvenci způsobily revoluci v přístupu k úlohám transformace sekvencí, což umožnilo strojům překládat jazyky, sumarizovat dokumenty, generovat lidské odpovědi a mnoho dalšího.
