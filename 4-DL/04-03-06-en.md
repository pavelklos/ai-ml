## 1. Introduction to Self-supervised Learning

Self-supervised learning is a subset of unsupervised learning where the data provides the supervision. Instead of using human-annotated labels, self-supervised methods automatically generate supervision signals from the data itself, creating "pseudo-labels." This approach allows models to learn useful representations from unlabeled data, making it particularly valuable when labeled data is scarce.

The key idea is to create a pretext task that requires understanding the data's structure to solve, leading to meaningful representations that can be transferred to downstream tasks.

## 2. Contrastive Learning

Contrastive learning is a popular self-supervised approach that learns representations by comparing similar and dissimilar pairs of samples. The core idea is to push representations of similar samples closer together while pushing dissimilar ones further apart in the embedding space.

```python
# Simplified contrastive loss implementation
class ContrastiveLoss(nn.Module):
    def __init__(self, temperature=0.5):
        super(ContrastiveLoss, self).__init__()
        self.temperature = temperature
        
    def forward(self, features):
        # features: [2*batch_size, feature_dim]
        # The first half and second half are positive pairs
        
        batch_size = features.shape[0] // 2
        labels = torch.cat([torch.arange(batch_size) for i in range(2)], dim=0)
        labels = (labels.unsqueeze(0) == labels.unsqueeze(1)).float()
        labels = labels.to(features.device)
        
        features = F.normalize(features, dim=1)
        
        # Calculate similarity matrix
        similarity_matrix = torch.matmul(features, features.T) / self.temperature
        
        # Mask out the diagonal (self-similarity)
        mask = torch.eye(labels.shape[0], dtype=torch.bool).to(features.device)
        labels = labels[~mask].view(labels.shape[0], -1)
        similarity_matrix = similarity_matrix[~mask].view(similarity_matrix.shape[0], -1)
        
        # Calculate the positive and negatives
        positives = similarity_matrix[labels.bool()].view(labels.shape[0], -1)
        negatives = similarity_matrix[~labels.bool()].view(similarity_matrix.shape[0], -1)
        
        # Calculate InfoNCE loss
        logits = torch.cat([positives, negatives], dim=1)
        labels = torch.zeros(logits.shape[0], dtype=torch.long).to(features.device)
        
        return F.cross_entropy(logits, labels)

# Usage example
contrastive_loss = ContrastiveLoss()
```

Key contrastive learning methods include:

1. **SimCLR**: Uses data augmentation to create positive pairs from the same image
2. **MoCo**: Maintains a momentum-updated queue of negative samples
3. **BYOL**: Doesn't require negative samples, using a teacher-student paradigm
4. **SwAV**: Combines contrastive learning with clustering

## 3. Masked Prediction Tasks

Masked prediction involves hiding parts of the input and training a model to predict those hidden parts. This forces the model to understand the full context and structure of the data.

```python
# Simple masked image modeling example
class MaskedImageModeling(nn.Module):
    def __init__(self, encoder, decoder):
        super(MaskedImageModeling, self).__init__()
        self.encoder = encoder
        self.decoder = decoder
        
    def forward(self, x, mask):
        # x: [batch_size, channels, height, width]
        # mask: [batch_size, height, width] - boolean mask (True = masked)
        
        # Create masked input (replace masked tokens with zeros or a learnable token)
        masked_x = x.clone()
        for i in range(x.size(0)):
            masked_x[i, :, mask[i]] = 0  # Zero out masked positions
        
        # Encode the masked input
        features = self.encoder(masked_x)
        
        # Decode to reconstruct the original
        reconstructed = self.decoder(features)
        
        # Compute loss only on masked positions
        loss = F.mse_loss(reconstructed[mask], x[mask])
        
        return loss, reconstructed

# Example usage with random data
def mask_generator(batch_size, h, w, mask_ratio=0.75):
    """Generate random masks for images with specified ratio"""
    mask = torch.zeros(batch_size, h, w, dtype=torch.bool)
    for i in range(batch_size):
        num_patches = h * w
        num_mask = int(mask_ratio * num_patches)
        mask_idx = torch.randperm(num_patches)[:num_mask]
        mask[i].view(-1)[mask_idx] = True
    return mask
```

Popular masked prediction approaches:

1. **BERT**: Masks random tokens in text for language understanding
2. **MAE (Masked Autoencoders)**: Masks random patches in images
3. **Data2vec**: Applies masked prediction across multiple modalities

## 4. Auto-regressive Learning

Auto-regressive learning involves predicting the next element in a sequence given the previous elements, creating a self-supervised task from sequential data.

```python
# Simple auto-regressive model for text
class SimpleAutoregressive(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim):
        super(SimpleAutoregressive, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)
        
    def forward(self, x):
        # x: [batch_size, seq_len]
        embedded = self.embedding(x)
        lstm_out, _ = self.lstm(embedded)
        logits = self.fc(lstm_out)
        return logits
    
    def generate(self, start_tokens, max_len, temperature=1.0):
        self.eval()
        current_tokens = start_tokens.clone()
        
        with torch.no_grad():
            for _ in range(max_len):
                logits = self.forward(current_tokens)
                next_token_logits = logits[:, -1, :] / temperature
                next_token = torch.multinomial(F.softmax(next_token_logits, dim=-1), 1)
                current_tokens = torch.cat([current_tokens, next_token], dim=1)
                
        return current_tokens

# Example usage
vocab_size = 10000
embed_dim = 256
hidden_dim = 512
model = SimpleAutoregressive(vocab_size, embed_dim, hidden_dim)

# Training loop example
def train_step(model, optimizer, data, target):
    optimizer.zero_grad()
    output = model(data)
    # Shift targets by one to predict next token
    loss = F.cross_entropy(output[:, :-1, :].reshape(-1, vocab_size), 
                          target[:, 1:].reshape(-1))
    loss.backward()
    optimizer.step()
    return loss.item()
```

Auto-regressive models like GPT learn powerful representations through next-token prediction, which has proven effective for language tasks.

## 5. Auto-encoding Methods

Auto-encoding methods learn useful representations by encoding the input into a latent space and then reconstructing the original input from this representation.

```python
class SimpleAutoencoder(nn.Module):
    def __init__(self, input_dim, latent_dim):
        super(SimpleAutoencoder, self).__init__()
        
        # Encoder
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.ReLU(),
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, latent_dim)
        )
        
        # Decoder
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 512),
            nn.ReLU(),
            nn.Linear(512, input_dim),
            nn.Sigmoid()  # For normalized inputs
        )
    
    def forward(self, x):
        # Encode
        z = self.encoder(x)
        # Decode
        reconstructed = self.decoder(z)
        return reconstructed, z
    
# Training example
def train_autoencoder(model, dataloader, epochs=10):
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    criterion = nn.MSELoss()
    
    for epoch in range(epochs):
        total_loss = 0
        for batch in dataloader:
            # Flatten the images
            x = batch[0].view(batch[0].size(0), -1)
            
            # Forward pass
            reconstructed, _ = model(x)
            
            # Compute loss
            loss = criterion(reconstructed, x)
            
            # Backward pass
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
            
        print(f"Epoch {epoch+1}, Loss: {total_loss/len(dataloader):.6f}")
```

Variations include:
- **Denoising Autoencoders**: Learn to remove noise from corrupted inputs
- **Variational Autoencoders (VAEs)**: Learn probabilistic representations
- **Sparse Autoencoders**: Enforce sparsity in the latent space

## 6. Implementing SimCLR

SimCLR (Simple Framework for Contrastive Learning of Representations) is one of the most influential contrastive learning methods. Let's implement a simplified version:

```python
# Data augmentation functions for SimCLR
from torchvision import transforms

class SimCLRDataTransform:
    def __init__(self, base_transform):
        self.base_transform = base_transform
        
    def __call__(self, x):
        # Generate two differently augmented views of the same image
        return self.base_transform(x), self.base_transform(x)

# Setup data augmentation for SimCLR
color_jitter = transforms.ColorJitter(0.8, 0.8, 0.8, 0.2)
data_transforms = transforms.Compose([
    transforms.RandomResizedCrop(96),
    transforms.RandomHorizontalFlip(),
    transforms.RandomApply([color_jitter], p=0.8),
    transforms.RandomGrayscale(p=0.2),
    transforms.ToTensor(),
    transforms.Normalize([0.5, 0.5, 0.5], [0.5, 0.5, 0.5])
])

# SimCLR model
class SimCLR(nn.Module):
    def __init__(self, backbone, projection_dim=128):
        super(SimCLR, self).__init__()
        # Encoder network (e.g., ResNet)
        self.backbone = backbone
        # Get the output dimension of the backbone
        out_dim = self.backbone.fc.in_features
        # Replace the final fully connected layer
        self.backbone.fc = nn.Identity()
        # Projection head
        self.projection_head = nn.Sequential(
            nn.Linear(out_dim, 512),
            nn.ReLU(),
            nn.Linear(512, projection_dim)
        )
    
    def forward(self, x):
        # Get representations from the backbone
        h = self.backbone(x)
        # Project to the contrastive space
        z = self.projection_head(h)
        return z

# Training loop
def train_simclr(model, train_loader, optimizer, temperature=0.5, epochs=100):
    criterion = ContrastiveLoss(temperature=temperature)
    
    for epoch in range(epochs):
        total_loss = 0
        for images, _ in train_loader:
            # Get the two augmented views
            x_i = images[0].cuda()
            x_j = images[1].cuda()
            
            # Forward pass through the model
            z_i = model(x_i)
            z_j = model(x_j)
            
            # Concatenate representations
            representations = torch.cat([z_i, z_j], dim=0)
            
            # Compute loss
            loss = criterion(representations)
            
            # Backward and optimize
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
        
        print(f"Epoch {epoch+1}/{epochs}, Loss: {total_loss/len(train_loader):.6f}")
```

SimCLR has been shown to achieve strong performance on various downstream tasks, demonstrating the power of contrastive learning in self-supervised settings.

## 7. BERT and Masked Language Modeling

BERT (Bidirectional Encoder Representations from Transformers) uses masked language modeling as its primary self-supervised task. Here's a simplified implementation:

```python
# Import libraries
from transformers import BertTokenizer, BertForMaskedLM, AdamW
import torch

# Load pre-trained tokenizer
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

# Define masked language modeling function
def create_masked_input(text, mask_probability=0.15):
    # Tokenize the input text
    tokens = tokenizer.tokenize(text)
    token_ids = tokenizer.convert_tokens_to_ids(tokens)
    
    # Create a copy of token_ids to store masked ids for targets
    masked_token_ids = token_ids.copy()
    
    # Loop through tokens and mask with probability
    for i in range(len(token_ids)):
        if np.random.rand() < mask_probability:
            # 80% of the time, replace with [MASK]
            if np.random.rand() < 0.8:
                token_ids[i] = tokenizer.mask_token_id
            # 10% of the time, replace with random word
            elif np.random.rand() < 0.5:
                token_ids[i] = np.random.randint(0, tokenizer.vocab_size)
            # 10% of the time, keep the original word
    
    # Convert to tensors
    input_ids = torch.tensor([token_ids])
    labels = torch.tensor([masked_token_ids])
    
    # Create attention mask
    attention_mask = torch.ones_like(input_ids)
    
    return {
        'input_ids': input_ids,
        'attention_mask': attention_mask,
        'labels': labels
    }

# Load pre-trained BERT model for masked language modeling
model = BertForMaskedLM.from_pretrained('bert-base-uncased')

# Example text
text = "The quick brown fox jumps over the lazy dog."
inputs = create_masked_input(text)

# Fine-tuning loop (simplified)
optimizer = AdamW(model.parameters(), lr=5e-5)

def train_step(model, inputs, optimizer):
    model.train()
    optimizer.zero_grad()
    outputs = model(**inputs)
    loss = outputs.loss
    loss.backward()
    optimizer.step()
    return loss.item()

# Example usage
loss = train_step(model, inputs, optimizer)
print(f"Loss: {loss}")

# Using BERT for inference
def predict_masked_tokens(text):
    # Tokenize input, replacing some words with [MASK]
    inputs = tokenizer(text, return_tensors="pt")
    
    # Get model predictions
    with torch.no_grad():
        outputs = model(**inputs)
    
    # Get predicted tokens
    predictions = torch.argmax(outputs.logits, dim=-1)
    predicted_tokens = tokenizer.convert_ids_to_tokens(predictions[0].tolist())
    
    return predicted_tokens

# Example with masked input
masked_text = "The [MASK] brown fox [MASK] over the lazy dog."
predictions = predict_masked_tokens(masked_text)
print(predictions)
```

BERT's bidirectional representation learning has been revolutionary for NLP tasks, allowing models to understand context from both directions.

## 8. Self-supervision in Computer Vision

Computer vision has many creative self-supervised tasks. Let's implement a simple rotation prediction task as an example:

```python
# Rotation prediction task
class RotationPrediction(nn.Module):
    def __init__(self, backbone):
        super(RotationPrediction, self).__init__()
        self.backbone = backbone
        # Modify the last layer to predict 4 rotation angles (0, 90, 180, 270 degrees)
        out_features = backbone.fc.in_features
        self.backbone.fc = nn.Identity()
        self.rotation_classifier = nn.Linear(out_features, 4)
    
    def forward(self, x):
        features = self.backbone(x)
        rotation_logits = self.rotation_classifier(features)
        return rotation_logits

# Create rotated images
def rotate_images(images):
    batch_size = images.shape[0]
    rotated_images = []
    rotation_labels = []
    
    for i in range(batch_size):
        for rotation in range(4):  # 0, 1, 2, 3 (0°, 90°, 180°, 270°)
            rotated_img = torch.rot90(images[i], rotation, dims=[1, 2])
            rotated_images.append(rotated_img)
            rotation_labels.append(rotation)
    
    rotated_images = torch.stack(rotated_images)
    rotation_labels = torch.tensor(rotation_labels)
    
    return rotated_images, rotation_labels

# Training function
def train_rotation_prediction(model, train_loader, optimizer, epochs=100):
    criterion = nn.CrossEntropyLoss()
    
    for epoch in range(epochs):
        total_loss = 0
        correct = 0
        total = 0
        
        for images, _ in train_loader:
            images = images.cuda()
            
            # Create rotated versions
            rotated_images, rotation_labels = rotate_images(images)
            rotated_images = rotated_images.cuda()
            rotation_labels = rotation_labels.cuda()
            
            # Forward pass
            outputs = model(rotated_images)
            
            # Compute loss
            loss = criterion(outputs, rotation_labels)
            
            # Backward pass and optimize
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            # Calculate accuracy
            _, predicted = torch.max(outputs.data, 1)
            total += rotation_labels.size(0)
            correct += (predicted == rotation_labels).sum().item()
            
            total_loss += loss.item()
        
        accuracy = 100 * correct / total
        print(f"Epoch {epoch+1}/{epochs}, Loss: {total_loss/len(train_loader):.4f}, "
              f"Accuracy: {accuracy:.2f}%")
```

## 10. Summary

Self-supervised learning represents a powerful paradigm in deep learning that leverages the structure of unlabeled data to create supervised tasks. Key advantages include:

1. **Reducing label dependency**: Decreases reliance on expensive manual annotations
2. **Scaling with data**: Can effectively utilize massive unlabeled datasets
3. **Transfer learning**: Creates robust representations that transfer well to downstream tasks
4. **Versatility**: Applicable across domains (vision, language, audio, etc.)

Major approaches in self-supervised learning:

- **Contrastive learning**: SimCLR, MoCo, BYOL - learns by comparing similar and dissimilar examples
- **Masked prediction**: BERT, MAE - learns by predicting masked content
- **Auto-regressive modeling**: GPT - predicts next elements in sequences
- **Auto-encoding**: Reconstructs inputs from compressed representations
- **Pretext tasks**: Rotation prediction, jigsaw puzzles - learns by solving artificially created tasks

Self-supervised learning continues to push the state-of-the-art in many domains, reducing the gap between supervised and unsupervised approaches while offering more data-efficient solutions.

As research progresses, we're seeing increasing convergence of techniques across modalities, with frameworks like data2vec showing that similar self-supervised approaches can work across vision, speech, and text domains.
