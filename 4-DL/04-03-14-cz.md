## 1. Úvod do neuro-symbolické umělé inteligence

Neuro-symbolická umělá inteligence představuje paradigma, které kombinuje silné stránky neuronových sítí (učení z dat) se symbolickou umělou inteligencí (logické odvozování a reprezentace znalostí). Tato integrace si klade za cíl překonat omezení každého přístupu a současně využít jejich komplementární výhody.

Základní myšlenkou je vytvořit systémy, které se mohou učit z dat a zároveň odvozovat strukturovanými znalostmi, což poskytuje:
- Lepší interpretovatelnost než čistě neuronové přístupy
- Větší flexibilitu než systémy založené na pravidlech
- Schopnost začlenit předchozí znalosti do učení
- Efektivnější učení z menšího množství vzorků díky integraci znalostí

```python
# Konceptuální ukázka neuro-symbolické integrace
import torch
import torch.nn as nn
import numpy as np

# Jednoduchá neuronová komponenta
class NeuralComponent(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(NeuralComponent, self).__init__()
        self.network = nn.Sequential(
            nn.Linear(input_size, hidden_size),
            nn.ReLU(),
            nn.Linear(hidden_size, output_size)
        )
    
    def forward(self, x):
        return self.network(x)

# Symbolická komponenta pro odvozování (zjednodušená)
class SymbolicReasoner:
    def __init__(self, rules):
        self.rules = rules
    
    def apply_rules(self, inputs):
        # Aplikace symbolických pravidel na vstupy
        results = []
        for input_data in inputs:
            for rule in self.rules:
                if rule["condition"](input_data):
                    results.append(rule["action"](input_data))
                    break
        return results

# Neuro-symbolický systém
class NeuroSymbolicSystem:
    def __init__(self, neural_component, symbolic_component):
        self.neural = neural_component
        self.symbolic = symbolic_component
    
    def process(self, inputs):
        # Neuronové zpracování
        neural_outputs = self.neural(inputs)
        
        # Symbolické odvozování na neuronových výstupech
        final_outputs = self.symbolic.apply_rules(neural_outputs)
        
        return final_outputs
```

## 2. Porozumění znalostním grafům

Znalostní grafy jsou strukturované reprezentace informací, které zachycují entity, jejich atributy a vztahy mezi entitami. Poskytují silný způsob organizace znalostí a odvozování z nich.

Klíčové komponenty znalostních grafů:
- **Entity**: Objekty nebo koncepty (např. lidé, místa, události)
- **Vztahy**: Spojení mezi entitami (např. "pracuje v", "žije v")
- **Atributy**: Vlastnosti entit (např. věk, barva)
- **Trojice**: Základní jednotky informací ve formě (subjekt, predikát, objekt)

## 3. Vkládání znalostních grafů

Vkládání znalostních grafů (knowledge graph embeddings) učí spojité vektorové reprezentace entit a vztahů v znalostním grafu. Tyto vložení (embeddings) zachycují sémantické informace a umožňují neuronovým sítím pracovat se strukturovanými znalostmi.

Populární modely vkládání znalostních grafů zahrnují:
- TransE: Modeluje vztahy jako translace ve vektorovém prostoru
- ComplEx: Používá komplexní vkládání k modelování asymetrických vztahů
- RotatE: Reprezentuje vztahy jako rotace v komplexním prostoru
- RESCAL: Používá faktorizaci tenzoru pro vkládání vztahů

```python
# Implementace TransE pomocí PyTorch
!pip install torch numpy tqdm

import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
from tqdm import tqdm

class TransE(nn.Module):
    def __init__(self, entity_count, relation_count, embedding_dim=100, margin=1.0):
        super(TransE, self).__init__()
        self.entity_embeddings = nn.Embedding(entity_count, embedding_dim)
        self.relation_embeddings = nn.Embedding(relation_count, embedding_dim)
        self.embedding_dim = embedding_dim
        self.margin = margin
        
        # Inicializace vložení
        nn.init.xavier_uniform_(self.entity_embeddings.weight.data)
        nn.init.xavier_uniform_(self.relation_embeddings.weight.data)
        
        # Normalizace vložení entit
        self.entity_embeddings.weight.data = nn.functional.normalize(
            self.entity_embeddings.weight.data, p=2, dim=1
        )
    
    def forward(self, pos_triples, neg_triples):
        # Pozitivní trojice
        pos_heads = self.entity_embeddings(pos_triples[:, 0])
        pos_relations = self.relation_embeddings(pos_triples[:, 1])
        pos_tails = self.entity_embeddings(pos_triples[:, 2])
        
        # Negativní trojice
        neg_heads = self.entity_embeddings(neg_triples[:, 0])
        neg_relations = self.relation_embeddings(neg_triples[:, 1])
        neg_tails = self.entity_embeddings(neg_triples[:, 2])
        
        # Výpočet skóre
        pos_scores = torch.norm(pos_heads + pos_relations - pos_tails, p=2, dim=1)
        neg_scores = torch.norm(neg_heads + neg_relations - neg_tails, p=2, dim=1)
        
        # Výpočet ztráty
        loss = torch.relu(self.margin + pos_scores - neg_scores).mean()
        return loss
    
    def predict(self, triples):
        heads = self.entity_embeddings(triples[:, 0])
        relations = self.relation_embeddings(triples[:, 1])
        tails = self.entity_embeddings(triples[:, 2])
        
        scores = torch.norm(heads + relations - tails, p=2, dim=1)
        return scores

# Příklad použití
def train_transe(model, train_triples, entity_count, batch_size=128, epochs=100, lr=0.001):
    optimizer = optim.Adam(model.parameters(), lr=lr)
    
    for epoch in range(epochs):
        model.train()
        total_loss = 0
        batch_count = 0
        
        # Generování dávek a negativních vzorků
        np.random.shuffle(train_triples)
        for i in range(0, len(train_triples), batch_size):
            batch = train_triples[i:i+batch_size]
            if len(batch) < batch_size:
                continue
                
            # Vytvoření náhodných negativních vzorků
            neg_batch = batch.copy()
            for j in range(len(neg_batch)):
                if np.random.random() < 0.5:  # Poškození hlavy
                    neg_batch[j, 0] = np.random.randint(0, entity_count)
                else:  # Poškození ocasu
                    neg_batch[j, 2] = np.random.randint(0, entity_count)
            
            pos_batch = torch.LongTensor(batch)
            neg_batch = torch.LongTensor(neg_batch)
            
            # Dopředný průchod
            optimizer.zero_grad()
            loss = model(pos_batch, neg_batch)
            loss.backward()
            optimizer.step()
            
            # Normalizace vložení entit po aktualizaci gradientu
            with torch.no_grad():
                model.entity_embeddings.weight.data = nn.functional.normalize(
                    model.entity_embeddings.weight.data, p=2, dim=1
                )
            
            total_loss += loss.item()
            batch_count += 1
        
        if epoch % 10 == 0:
            print(f"Epocha {epoch}, Ztráta: {total_loss / batch_count:.4f}")
```

## 4. Přístupy k neuro-symbolické integraci

Existuje několik přístupů k integraci neuronových sítí se symbolickými znalostmi:

1. **Symbolické znalosti jako omezení**: Použití logických pravidel k omezení tréninku neuronových sítí
2. **Neuronové sítě pro indukci symbolických pravidel**: Učení logických pravidel z dat
3. **Metody založené na vkládání**: Mapování symbolických struktur do vektorových prostorů
4. **Neuralizace symbolických algoritmů**: Implementace symbolických algoritmů jako diferencovatelných operací

```python
# Příklad použití logických omezení při tréninku neuronové sítě
!pip install torch

import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# Definice neuronové sítě s omezením
class ConstrainedNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(ConstrainedNN, self).__init__()
        self.layer1 = nn.Linear(input_size, hidden_size)
        self.layer2 = nn.Linear(hidden_size, output_size)
        self.relu = nn.ReLU()
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x):
        x = self.relu(self.layer1(x))
        x = self.sigmoid(self.layer2(x))
        return x

# Logické omezení: pokud x1 > 0.5 a x2 > 0.5, pak y = 1
def logical_constraint(inputs, outputs):
    constraint = torch.zeros_like(outputs)
    mask = (inputs[:, 0] > 0.5) & (inputs[:, 1] > 0.5)
    constraint[mask] = 1.0
    
    # Výpočet ztráty dodržení omezení
    constraint_loss = torch.mean(torch.abs(outputs[mask] - constraint[mask]))
    return constraint_loss

# Trénovací smyčka s omezením
def train_with_constraints(model, X, y, epochs=1000, lr=0.01, constraint_weight=0.5):
    optimizer = optim.SGD(model.parameters(), lr=lr)
    criterion = nn.BCELoss()
    
    for epoch in range(epochs):
        # Dopředný průchod
        outputs = model(X)
        
        # Standardní ztráta
        loss = criterion(outputs, y)
        
        # Ztráta omezení
        constraint_loss = logical_constraint(X, outputs)
        
        # Kombinovaná ztráta
        total_loss = loss + constraint_weight * constraint_loss
        
        # Zpětný průchod a optimalizace
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        if epoch % 100 == 0:
            print(f'Epocha {epoch}, Ztráta: {loss.item():.4f}, Ztráta omezení: {constraint_loss.item():.4f}')

# Vygenerování syntetických dat
np.random.seed(42)
X = torch.FloatTensor(np.random.rand(100, 2))
y = torch.FloatTensor((X[:, 0] > 0.5) & (X[:, 1] > 0.5)).view(-1, 1).float()

# Vytvoření a trénování modelu
model = ConstrainedNN(input_size=2, hidden_size=5, output_size=1)
train_with_constraints(model, X, y)
```

## 5. Odvozování se znalostními grafy a neuronovými sítěmi

Integrace schopností odvozování do neuronových sítí je jednou z klíčových výzev v neuro-symbolické umělé inteligenci. Několik přístupů umožňuje neuronovým sítím provádět logické odvozování nad znalostními grafy:

1. **Grafové neuronové sítě (GNN)**: Učí se reprezentace uzlů a hran prostřednictvím předávání zpráv
2. **Neuronové dokazovače teorémů**: Diferencovatelné verze symbolických algoritmů pro odvozování
3. **Odvozování založené na pozornosti**: Použití mechanismů pozornosti k simulaci cest odvozování

```python
# Grafová neuronová síť pro odvozování nad znalostním grafem
!pip install torch torch_geometric

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GATConv, GCNConv

class KGReasoningGNN(torch.nn.Module):
    def __init__(self, num_entities, num_relations, embedding_dim=100):
        super(KGReasoningGNN, self).__init__()
        
        # Vložení entit a vztahů
        self.entity_embedding = nn.Embedding(num_entities, embedding_dim)
        self.relation_embedding = nn.Embedding(num_relations, embedding_dim)
        
        # Vrstvy grafové konvoluce
        self.conv1 = GCNConv(embedding_dim, embedding_dim)
        self.conv2 = GCNConv(embedding_dim, embedding_dim)
        
        # Skórovací funkce
        self.score_function = nn.Sequential(
            nn.Linear(embedding_dim * 3, embedding_dim),
            nn.ReLU(),
            nn.Linear(embedding_dim, 1)
        )
        
    def forward(self, edge_index, edge_type, query_entities, query_relations):
        # Získání počátečních vložení entit
        x = self.entity_embedding.weight
        
        # Zpracování grafu vrstvami GCN
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        x = self.conv2(x, edge_index)
        
        # Získání vložení pro dotazované entity a vztahy
        head_emb = torch.index_select(x, 0, query_entities)
        rel_emb = self.relation_embedding(query_relations)
        
        # Skórování všech možných cílových entit pro každou dvojici (hlava, vztah)
        all_entities = x.unsqueeze(0).repeat(head_emb.size(0), 1, 1)
        head_emb = head_emb.unsqueeze(1).repeat(1, all_entities.size(1), 1)
        rel_emb = rel_emb.unsqueeze(1).repeat(1, all_entities.size(1), 1)
        
        # Zřetězení a skórování
        triplet_emb = torch.cat([head_emb, rel_emb, all_entities], dim=2)
        scores = self.score_function(triplet_emb).squeeze(-1)
        
        return scores
```

## 6. Implementace neuro-symbolických systémů

Vytvoření praktického neuro-symbolického systému zahrnuje integraci neuronových komponent s reprezentací znalostí a odvozování. Zde implementujeme jednoduchý neuro-symbolický systém, který dokáže odpovídat na otázky s využitím jak naučených vzorů, tak logického odvozování.

```python
# Jednoduchý neuro-symbolický systém pro zodpovídání otázek
!pip install torch networkx rdflib transformers

import torch
import torch.nn as nn
import networkx as nx
import rdflib
from rdflib import Graph, Literal, Namespace, RDF, URIRef
from transformers import BertModel, BertTokenizer

class NeuroSymbolicQA:
    def __init__(self, knowledge_graph_path=None):
        # Inicializace znalostního grafu
        self.kg = Graph()
        if knowledge_graph_path:
            self.kg.parse(knowledge_graph_path)
        else:
            self.create_sample_kg()
        
        # Inicializace neuronových komponent
        self.tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
        self.encoder = BertModel.from_pretrained('bert-base-uncased')
        
        # Klasifikátor vztahů
        self.relation_classifier = nn.Linear(768, len(self.get_relation_types()))
        
        # Spojovač entit (zjednodušený)
        self.entity_linker = self.create_entity_linker()
    
    def create_sample_kg(self):
        # Vytvoření jednoduchého znalostního grafu
        ex = Namespace("http://example.org/")
        
        # Přidání trojic o lidech a místech
        self.kg.add((ex.Jan, RDF.type, ex.Osoba))
        self.kg.add((ex.Jan, ex.zijeV, ex.Praha))
        self.kg.add((ex.Jan, ex.pracujeV, ex.TechFirma))
        self.kg.add((ex.Marie, RDF.type, ex.Osoba))
        self.kg.add((ex.Marie, ex.zijeV, ex.Brno))
        self.kg.add((ex.Marie, ex.pracujeV, ex.Univerzita))
        self.kg.add((ex.Marie, ex.zna, ex.Jan))
        self.kg.add((ex.Praha, RDF.type, ex.Mesto))
        self.kg.add((ex.Brno, RDF.type, ex.Mesto))
        self.kg.add((ex.TechFirma, RDF.type, ex.Firma))
        self.kg.add((ex.Univerzita, RDF.type, ex.Organizace))
    
    def get_relation_types(self):
        # Extrakce typů vztahů ze znalostního grafu
        relations = set()
        for _, p, _ in self.kg:
            relations.add(p)
        return list(relations)
    
    def create_entity_linker(self):
        # Vytvoření jednoduchého spojovače entit založeného na porovnávání řetězců
        entity_dict = {}
        for s, _, _ in self.kg:
            if isinstance(s, URIRef):
                entity_dict[s.split('/')[-1].lower()] = s
        return entity_dict
    
    def link_entity(self, entity_mention):
        # Propojení zmínky entity s entitou KG
        mention = entity_mention.lower()
        return self.entity_linker.get(mention, None)
    
    def detect_entities(self, question):
        # Jednoduchá detekce entit - v praxi by byla sofistikovanější
        entities = []
        for entity_name in self.entity_linker:
            if entity_name in question.lower():
                entities.append((entity_name, self.entity_linker[entity_name]))
        return entities
    
    def encode_question(self, question):
        # Kódování otázky pomocí BERT
        inputs = self.tokenizer(question, return_tensors="pt")
        with torch.no_grad():
            outputs = self.encoder(**inputs)
        
        # Použití reprezentace tokenu CLS
        return outputs.last_hidden_state[:, 0, :]
    
    def predict_relation(self, question_embedding):
        # Předpověď typu vztahu na základě vložení otázky
        logits = self.relation_classifier(question_embedding)
        relation_idx = torch.argmax(logits, dim=1).item()
        return self.get_relation_types()[relation_idx]
    
    def query_knowledge_graph(self, entity, relation):
        # Dotazování znalostního grafu na odpovědi
        ex = Namespace("http://example.org/")
        query = f"""
            SELECT ?answer
            WHERE {{
                {entity.n3()} {relation.n3()} ?answer .
            }}
        """
        results = list(self.kg.query(query))
        return [result[0] for result in results]
    
    def answer_question(self, question):
        # Detekce entit v otázce
        detected_entities = self.detect_entities(question)
        if not detected_entities:
            return "V otázce nebyly detekovány žádné entity."
        
        # Kódování otázky
        question_embedding = self.encode_question(question)
        
        # Předpověď vztahu
        predicted_relation = self.predict_relation(question_embedding)
        
        # Dotaz na znalostní graf
        main_entity = detected_entities[0][1]  # Použití první detekované entity
        answers = self.query_knowledge_graph(main_entity, predicted_relation)
        
        if answers:
            return f"Odpověď je: {', '.join(str(a).split('/')[-1] for a in answers)}"
        else:
            # Návrat k neuronové inferenci, pokud není nalezena přímá odpověď
            return "Nemám dostatek informací k zodpovězení této otázky."
```

## 7. Aplikace a případy použití

Neuro-symbolická umělá inteligence a integrace znalostních grafů mají řadu aplikací v různých oblastech:

1. **Systémy pro zodpovídání otázek**: Kombinování faktických znalostí s neuronovým jazykovým porozuměním
2. **Objevování léčiv**: Používání znalostních grafů biologických interakcí s neuronovými prediktivními modely
3. **Lékařská diagnostika**: Integrace lékařských znalostních bází s naučenými vzory z pacientských dat
4. **Konverzační umělá inteligence**: Přidání faktických znalostí a schopností odvozování do chatbotů
5. **Extrakce informací**: Použití doménových znalostí k řízení extrakce informací z textu

```python
        else:

            nn.Linear(256, num_classes)
        )
    
    def create_sample_domain_kg(self):
        # Vytvoření zjednodušeného oborového znalostního grafu (např. pro klasifikaci filmů)
        ex = Namespace("http://example.org/")
        
        # Filmové žánry
        self.kg.add((ex.Akce, RDF.type, ex.FilmovyZanr))
        self.kg.add((ex.Komedie, RDF.type, ex.FilmovyZanr))
        self.kg.add((ex.Drama, RDF.type, ex.FilmovyZanr))
        
        # Filmové atributy
        self.kg.add((ex.Nasili, RDF.type, ex.FilmovyAtribut))
        self.kg.add((ex.Romance, RDF.type, ex.FilmovyAtribut))
        self.kg.add((ex.Humor, RDF.type, ex.FilmovyAtribut))
        
        # Vztahy mezi atributy a žánry
        self.kg.add((ex.Akce, ex.maBeznyAtribut, ex.Nasili))
        self.kg.add((ex.Komedie, ex.maBeznyAtribut, ex.Humor))
        self.kg.add((ex.Drama, ex.maBeznyAtribut, ex.Romance))
    
    def get_kg_entities(self):
        # Extrakce všech entit ze znalostního grafu
        entities = set()
        for s, _, o in self.kg:
            if isinstance(s, URIRef):
                entities.add(s)
            if isinstance(o, URIRef):
                entities.add(o)
        return list(entities)
    
    def create_entity_linker(self):
        # Vytvoření jednoduchého spojovače entit založeného na porovnávání řetězců
        entity_dict = {}
        for entity in self.kg_entities:
            entity_name = entity.split('/')[-1].lower()
            entity_dict[entity_name] = self.kg_entities.index(entity)
        return entity_dict
    
    def extract_entities_from_text(self, text):
        # Jednoduchá extrakce entit založená na porovnávání řetězců
        entities = []
        text_lower = text.lower()
        for entity_name, entity_idx in self.entity_linker.items():
            if entity_name in text_lower:
                entities.append(entity_idx)
        return entities
    
    def forward(self, text):
        # Zpracování textu pomocí BERT
        inputs = self.tokenizer(text, return_tensors="pt", padding=True, truncation=True)
        bert_output = self.bert(**inputs)
        text_embedding = bert_output.last_hidden_state[:, 0, :]
        
        # Extrakce entit znalostního grafu
        batch_entity_embeddings = []
        for t in text:
            entity_indices = self.extract_entities_from_text(t)
            if entity_indices:
                # Průměrování vložení entit
                entity_vectors = self.entity_embeddings(torch.tensor(entity_indices))
                entity_vector = torch.mean(entity_vectors, dim=0)
            else:
                # Pokud nejsou nalezeny entity, použijte nuly
                entity_vector = torch.zeros(100)
            batch_entity_embeddings.append(entity_vector)
        
        kg_embedding = torch.stack(batch_entity_embeddings)
        
        # Kombinace textových a znalostních vložení
        combined = torch.cat([text_embedding, kg_embedding], dim=1)
        
        # Klasifikace
        return self.classifier(combined)
```

```python
import time

def measure_reasoning_time(kg_sizes, reasoning_methods):
    """Měření času odvozování pro různé velikosti znalostních grafů."""
    results = {method: [] for method in reasoning_methods}
    
    for size in kg_sizes:
        # Vytvoření syntetického znalostního grafu dané velikosti
        print(f"Testování se znalostním grafem velikosti {size}")

            if method == "symbolic":
                # Simulace symbolického odvozování (např. logická inference)
                start_time = time.time()
                # Složitost O(n²) pro jednoduché symbolické odvozování
                _ = [i*j for i in range(size) for j in range(min(100, size))]
                elapsed = time.time() - start_time
                
            elif method == "neural":
                # Simulace neuronového odvozování (např. grafová neuronová síť)
                start_time = time.time()
                # Složitost O(n) pro dopředný průchod GNN

                # Kombinovaná složitost
                _ = [i*2 for i in range(size*100)]  # Neuronová část
                _ = [i*j for i in range(int(size/10)) for j in range(min(100, int(size/10)))]  # Symbolická část
                elapsed = time.time() - start_time
                
            results[method].append(elapsed)
```

```python
# Příklad systému pro automatickou konstrukci znalostních grafů
import torch
import torch.nn as nn
from transformers import BertTokenizer, BertModel
import networkx as nx

class NeuralKnowledgeGraphBuilder:
    def __init__(self):
        # Inicializace jazykového modelu
        self.tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
        self.model = BertModel.from_pretrained('bert-base-uncased')
        
        # Hlava pro extrakci vztahů
        self.relation_classifier = nn.Linear(768, 10)  # 10 typů vztahů
        
        # Model rozpoznávání entit (zjednodušený)
        self.entity_classifier = nn.Linear(768, 5)  # 5 typů entit
        
        # Znalostní graf
        self.knowledge_graph = nx.DiGraph()
        self.relation_map = {
            0: "je", 
            1: "je_součástí", 
            2: "nachází_se_v", 
            3: "pracuje_v", 
            4: "zná",
            5: "vytvořeno_kým",
            6: "má_vlastnost",
            7: "patří_do",
            8: "způsobuje",
            9: "používá_se_pro"
        }
        
        self.entity_type_map = {
            0: "osoba",
            1: "organizace",
            2: "místo",
            3: "koncept",
            4: "objekt"
        }
    
    def extract_entities(self, text):
        # Tokenizace a získání vložení
        tokens = self.tokenizer(text, return_tensors="pt", return_offsets_mapping=True)
        with torch.no_grad():
            outputs = self.model(**{k: v for k, v in tokens.items() if k != 'offset_mapping'})
        
        # Získání vložení tokenů
        token_embeddings = outputs.last_hidden_state
        
        # Klasifikace každého tokenu
        entity_logits = self.entity_classifier(token_embeddings)
        entity_predictions = torch.argmax(entity_logits, dim=-1)
        
        # Extrakce rozsahů entit (zjednodušeno)
        entities = []
        current_entity = None
        current_type = None
        
        for i, (token_id, entity_type) in enumerate(zip(tokens.input_ids[0], entity_predictions[0])):
            if entity_type > 0:  # Nenulová hodnota znamená, že je to entita
                entity_text = self.tokenizer.decode([token_id])
                entity_type_name = self.entity_type_map[entity_type.item()]
                
                if current_entity and current_type == entity_type_name:
                    current_entity += " " + entity_text
                else:
                    if current_entity:
                        entities.append((current_entity, current_type))
                    current_entity = entity_text
                    current_type = entity_type_name
            else:
                if current_entity:
                    entities.append((current_entity, current_type))
                    current_entity = None
                    current_type = None
        
        if current_entity:
            entities.append((current_entity, current_type))
            
        return entities
    
    def extract_relations(self, text, entities):
        # Jednoduchá extrakce vztahů založená na vložení věty
        with torch.no_grad():
            inputs = self.tokenizer(text, return_tensors="pt")
            outputs = self.model(**inputs)
            sentence_embedding = outputs.last_hidden_state[:, 0, :]
        
        # Pro každou dvojici entit predikujte vztah
        relations = []
        for i, (entity1, type1) in enumerate(entities):
            for j, (entity2, type2) in enumerate(entities):
                if i != j:
                    # Kombinace vložení věty s informacemi o entitách
                    # (V praxi byste použili sofistikovanější přístup)
                    relation_logits = self.relation_classifier(sentence_embedding)
                    relation_id = torch.argmax(relation_logits, dim=-1).item()
                    relation_type = self.relation_map[relation_id]
                    
                    relations.append((entity1, relation_type, entity2))
        
        return relations
    
    def update_knowledge_graph(self, relations):
        # Přidání vztahů do znalostního grafu
        for subj, rel, obj in relations:
            if subj not in self.knowledge_graph:
                self.knowledge_graph.add_node(subj)
            if obj not in self.knowledge_graph:
                self.knowledge_graph.add_node(obj)
            self.knowledge_graph.add_edge(subj, obj, relation=rel)
    
    def process_text(self, text):
        # Extrakce entit a vztahů z textu
        entities = self.extract_entities(text)
        relations = self.extract_relations(text, entities)
        
        # Aktualizace znalostního grafu
        self.update_knowledge_graph(relations)
        
        return entities, relations
    
    def visualize_knowledge_graph(self):
        plt.figure(figsize=(12, 10))
        pos = nx.spring_layout(self.knowledge_graph)
        nx.draw(self.knowledge_graph, pos, with_labels=True, node_size=3000, 
                node_color="skyblue", font_size=10)
        
        edge_labels = {(u, v): d["relation"] for u, v, d in self.knowledge_graph.edges(data=True)}
        nx.draw_networkx_edge_labels(self.knowledge_graph, pos, edge_labels=edge_labels)
        
        plt.title("Automaticky vytvořený znalostní graf")
        plt.axis('off')
        plt.tight_layout()
        plt.show()
```
