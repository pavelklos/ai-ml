## Introduction to Neural Networks

Neural networks are computational systems inspired by the structure and function of biological neural networks. They consist of interconnected "neurons" that process and transmit information. These networks form the foundation of deep learning and have revolutionized how we approach complex problems in areas such as computer vision, natural language processing, and reinforcement learning.

A neural network typically consists of:
- An input layer that receives data
- One or more hidden layers that process the data
- An output layer that produces the final result

```python
# Conceptual representation of a simple neural network
"""
Input Layer    Hidden Layer    Output Layer
   (x₁)           (h₁)          
    ↓              ↑↓             ↑
   (x₂) --------→ (h₂) --------→ (y)
    ↓              ↑↓             ↑
   (x₃)           (h₃)          
"""
```

## Biological Inspiration

Artificial neural networks take inspiration from the biological neurons in the brain. In the human brain, neurons receive signals through dendrites, process these signals in the cell body, and transmit them through axons to other neurons. The strength of these connections can change over time, which is the basis for learning.

Similarly, artificial neural networks consist of interconnected nodes (neurons) that:
1. Receive inputs from other neurons
2. Apply weights to these inputs
3. Sum the weighted inputs
4. Apply an activation function to determine the output
5. Transmit this output to other neurons

## The Artificial Neuron

The artificial neuron, also known as a perceptron in its simplest form, is the basic computational unit of a neural network. It takes multiple inputs, processes them, and produces an output.

Key components of an artificial neuron:
- **Inputs** (x₁, x₂, ..., xₙ): Data values entering the neuron
- **Weights** (w₁, w₂, ..., wₙ): Parameters that determine the importance of each input
- **Bias** (b): An additional parameter that allows the activation function to be shifted
- **Net Input/Weighted Sum** (z): The sum of weighted inputs plus the bias
- **Activation Function** (φ): A function that transforms the weighted sum into the output
- **Output** (a): The value produced by the activation function

## Mathematical Representation

The operation of a neuron can be represented mathematically as:

1. Calculate the weighted sum of inputs:
   z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

2. Apply the activation function:
   a = φ(z)

In vector notation:
   z = W·X + b
   a = φ(z)

Where:
- X is the input vector [x₁, x₂, ..., xₙ]
- W is the weight vector [w₁, w₂, ..., wₙ]
- b is the bias term
- φ is the activation function

```python
import numpy as np

def neuron(inputs, weights, bias, activation_function):
    """Basic implementation of an artificial neuron"""
    # Calculate the weighted sum
    z = np.dot(weights, inputs) + bias
    # Apply the activation function
    output = activation_function(z)
    return output
```

## Activation Functions

Activation functions introduce non-linearity into neural networks, enabling them to learn complex patterns and relationships in data. Without activation functions, neural networks would be limited to learning only linear relationships, regardless of their depth.

### Linear Activation

The simplest activation function is the linear or identity function: f(x) = x.

```python
def linear(x):
    return x
```

**Pros:**
- Simple to compute
- Suitable for regression problems in the output layer

**Cons:**
- Cannot solve non-linear problems
- Derivatives are constant, which causes issues during backpropagation

### Sigmoid

The sigmoid function (logistic function) maps any input to a value between 0 and 1:
f(x) = 1 / (1 + e^(-x))

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```

**Pros:**
- Smooth gradient, preventing jumps in output values
- Output range bounded between 0 and 1, useful for binary classification

**Cons:**
- Prone to vanishing gradient problem
- Outputs not centered around zero
- Computationally expensive

### Hyperbolic Tangent (tanh)

The hyperbolic tangent function is similar to sigmoid but maps inputs to values between -1 and 1:
f(x) = (e^x - e^(-x)) / (e^x + e^(-x))

```python
def tanh(x):
    return np.tanh(x)
```

**Pros:**
- Output is zero-centered, making optimization easier
- Stronger gradients than sigmoid

**Cons:**
- Still suffers from the vanishing gradient problem
- Computationally expensive

### ReLU and Variants

#### ReLU (Rectified Linear Unit)

ReLU is one of the most widely used activation functions in modern neural networks:
f(x) = max(0, x)

```python
def relu(x):
    return np.maximum(0, x)
```

**Pros:**
- Computationally efficient
- Helps mitigate the vanishing gradient problem
- Biologically inspired (sparsity)

**Cons:**
- "Dying ReLU" problem: neurons can become permanently inactive
- Not zero-centered

#### Leaky ReLU

A variant of ReLU that allows a small negative value when x < 0:
f(x) = max(αx, x), where α is a small constant (e.g., 0.01)

```python
def leaky_relu(x, alpha=0.01):
    return np.maximum(alpha * x, x)
```

**Pros:**
- Prevents the dying ReLU problem
- All other benefits of ReLU

**Cons:**
- The optimal value of α may vary across problems

#### Parametric ReLU (PReLU)

Similar to Leaky ReLU, but the slope parameter α is learned during training:

```python
class PReLU:
    def __init__(self, alpha=0.01):
        self.alpha = alpha  # Learnable parameter in actual implementations
        
    def __call__(self, x):
        return np.maximum(self.alpha * x, x)
```

#### ELU (Exponential Linear Unit)

ELU combines the benefits of ReLU while addressing some of its limitations:
f(x) = x if x > 0 else α(e^x - 1)

```python
def elu(x, alpha=1.0):
    return np.where(x > 0, x, alpha * (np.exp(x) - 1))
```

**Pros:**
- Smooth function including negative values
- Reduces the "dead neuron" problem
- Mean activations closer to zero

**Cons:**
- Computationally more expensive than ReLU
- Alpha requires tuning

### Softmax

The softmax function is commonly used in the output layer for multi-class classification problems. It converts a vector of values to a probability distribution:

f(x_i) = e^(x_i) / Σ(e^(x_j))

```python
def softmax(x):
    exp_x = np.exp(x - np.max(x))  # Subtract max for numerical stability
    return exp_x / exp_x.sum()
```

**Pros:**
- Outputs sum to 1, representing a probability distribution
- Emphasizes the largest values while suppressing the smaller ones

**Cons:**
- Computationally expensive
- Can cause numerical instability due to exponentials

### Modern Activation Functions

Several newer activation functions have been developed to address limitations of the traditional ones.

#### GELU (Gaussian Error Linear Unit)

Used in state-of-the-art models like BERT and GPT:
f(x) = x * Φ(x), where Φ is the cumulative distribution function of the standard normal distribution

```python
def gelu(x):
    return 0.5 * x * (1 + np.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * x**3)))
```

#### Swish

Developed by Google:
f(x) = x * sigmoid(x)

```python
def swish(x):
    return x * sigmoid(x)
```

**Pros:**
- Smooth, non-monotonic function
- Good performance on deep networks

**Cons:**
- Computationally more expensive than ReLU

## Implementing Neurons in Python

Let's implement a simple neuron from scratch and see how it processes input:

```python
import numpy as np
import matplotlib.pyplot as plt

class Neuron:
    def __init__(self, n_inputs, activation_function):
        # Initialize weights with small random values
        self.weights = np.random.randn(n_inputs) * 0.1
        self.bias = np.random.randn() * 0.1
        self.activation_function = activation_function
    
    def forward(self, inputs):
        # Calculate the weighted sum
        z = np.dot(self.weights, inputs) + self.bias
        # Apply the activation function
        output = self.activation_function(z)
        return output

# Create a neuron with 3 inputs and ReLU activation
relu_neuron = Neuron(3, relu)

# Test with sample input
sample_input = np.array([0.5, 0.2, -0.1])
output = relu_neuron.forward(sample_input)

print(f"Weights: {relu_neuron.weights}")
print(f"Bias: {relu_neuron.bias}")
print(f"Input: {sample_input}")
print(f"Output: {output}")
```

## Building Simple Neural Networks

Now let's build a simple neural network with a hidden layer using our neuron implementation:

```python
class SimpleNeuralNetwork:
    def __init__(self, n_inputs, n_hidden, n_outputs, hidden_activation, output_activation):
        self.hidden_layer = [Neuron(n_inputs, hidden_activation) for _ in range(n_hidden)]
        self.output_layer = [Neuron(n_hidden, output_activation) for _ in range(n_outputs)]
    
    def forward(self, inputs):
        # Process inputs through hidden layer
        hidden_outputs = [neuron.forward(inputs) for neuron in self.hidden_layer]
        hidden_outputs = np.array(hidden_outputs)
        
        # Process hidden layer outputs through output layer
        final_outputs = [neuron.forward(hidden_outputs) for neuron in self.output_layer]
        return np.array(final_outputs)

# Create a simple network: 3 inputs, 4 hidden neurons, 2 outputs
network = SimpleNeuralNetwork(3, 4, 2, relu, sigmoid)

# Test with sample input
sample_input = np.array([0.5, 0.2, -0.1])
output = network.forward(sample_input)

print(f"Network input: {sample_input}")
print(f"Network output: {output}")
```

## Choosing the Right Activation Function

The choice of activation function is crucial for the performance of your neural network. Here are some guidelines:

1. **Hidden Layers**:
   - ReLU is a good default choice due to its simplicity and effectiveness
   - For very deep networks, consider Leaky ReLU, ELU, or GELU to avoid dead neurons

2. **Output Layer**:
   - Binary classification: Sigmoid
   - Multi-class classification: Softmax
   - Regression: Linear
   - Bounded regression (e.g., values between 0 and 1): Sigmoid or Tanh

3. **Special Cases**:
   - RNNs and LSTMs: Tanh is often used for internal state updates
   - Modern transformers: GELU is commonly used
   - Autoencoder middle layers: Linear or ReLU depending on the application

## Common Issues and Solutions

### Vanishing Gradients

**Problem**: Gradients become extremely small as they are backpropagated through many layers, especially with sigmoid and tanh.

**Solutions**:
- Use ReLU or its variants
- Use batch normalization
- Implement residual connections
- Use proper weight initialization techniques

### Exploding Gradients

**Problem**: Gradients become extremely large, causing unstable training.

**Solutions**:
- Use gradient clipping
- Implement proper weight initialization
- Apply batch normalization

### Dead Neurons (with ReLU)

**Problem**: Neurons can get stuck in a state where they always output zero.

**Solutions**:
- Use Leaky ReLU, PReLU, or ELU instead
- Use proper learning rate
- Apply batch normalization

## Building a Neuron Layer with NumPy

Let's implement a complete layer of neurons using NumPy for vectorized operations:

```python
import numpy as np

class DenseLayer:
    def __init__(self, n_inputs, n_neurons, activation_function):
        # Initialize weights and biases
        self.weights = np.random.randn(n_inputs, n_neurons) * 0.1
        self.biases = np.zeros((1, n_neurons))
        self.activation_function = activation_function
    
    def forward(self, inputs):
        # Calculate the weighted sum
        self.inputs = inputs
        self.z = np.dot(inputs, self.weights) + self.biases
        # Apply the activation function
        self.output = self.activation_function(self.z)
        return self.output

# Example of using the layer
np.random.seed(42)  # For reproducibility

# Create a layer with 3 inputs and 4 neurons
layer = DenseLayer(3, 4, relu)

# Sample batch of data (5 samples, each with 3 features)
X = np.random.randn(5, 3)

# Forward pass
output = layer.forward(X)
print("Layer input shape:", X.shape)
print("Layer output shape:", output.shape)
print("Layer output:")
print(output)
```

## Training a Single Neuron with Gradient Descent

To understand how neurons learn, let's implement a simple binary classification neuron with gradient descent:

```python
import numpy as np
import matplotlib.pyplot as plt

class PerceptronNeuron:
    def __init__(self, n_inputs):
        # Initialize weights and bias
        self.weights = np.random.randn(n_inputs) * 0.01
        self.bias = 0
    
    def sigmoid(self, x):
        return 1 / (1 + np.exp(-x))
    
    def forward(self, x):
        # Calculate weighted sum
        z = np.dot(x, self.weights) + self.bias
        # Apply sigmoid activation
        return self.sigmoid(z)
    
    def train(self, X, y, learning_rate=0.1, epochs=100):
        losses = []
        
        for epoch in range(epochs):
            total_loss = 0
            
            for i in range(len(X)):
                # Forward pass
                prediction = self.forward(X[i])
                
                # Calculate loss (binary cross-entropy)
                loss = -y[i] * np.log(prediction) - (1 - y[i]) * np.log(1 - prediction)
                total_loss += loss
                
                # Calculate gradients
                d_prediction = (prediction - y[i])  # Derivative of binary cross-entropy
                
                # Update weights and bias using gradient descent
                self.weights -= learning_rate * d_prediction * X[i]
                self.bias -= learning_rate * d_prediction
            
            # Record average loss for this epoch
            avg_loss = total_loss / len(X)
            losses.append(avg_loss)
            
            if epoch % 10 == 0:
                print(f"Epoch {epoch}, Loss: {avg_loss:.4f}")
        
        return losses

# Create a dataset for binary classification
np.random.seed(42)

# Generate 100 points with 2 features each
X = np.random.randn(100, 2)

# Create labels: 1 if x₁ + x₂ > 0, else 0
y = (X[:, 0] + X[:, 1] > 0).astype(int)

# Visualize the data
plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='viridis', marker='o', edgecolors='k')
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.title('Binary Classification Dataset')
plt.colorbar(label='Class')
plt.grid(True)
plt.show()

# Train the neuron
neuron = PerceptronNeuron(2)
losses = neuron.train(X, y, learning_rate=0.1, epochs=100)

# Plot the loss curve
plt.figure(figsize=(10, 6))
plt.plot(losses)
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('Training Loss')
plt.grid(True)
plt.show()

# Visualize decision boundary
plt.figure(figsize=(8, 6))

# Create a grid of points
x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100),
                     np.linspace(y_min, y_max, 100))
grid = np.c_[xx.ravel(), yy.ravel()]

# Make predictions on the grid
Z = np.array([neuron.forward(point) for point in grid])
Z = Z.reshape(xx.shape)

# Plot the decision boundary
plt.contourf(xx, yy, Z, alpha=0.3, cmap='viridis')

# Plot the original data
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='viridis', marker='o', edgecolors='k')
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.title('Decision Boundary Learned by the Neuron')
plt.colorbar(label='Probability of Class 1')
plt.grid(True)
plt.show()
```
