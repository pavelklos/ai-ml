## Úvod do GANs

Generativní adversariální sítě (GANs) jsou revoluční třídou modelů hlubokého učení, které představil Ian Goodfellow a jeho kolegové v roce 2014. Skládají se ze dvou neuronových sítí—generátoru a diskriminátoru—které jsou trénovány současně pomocí adversariálního tréninku.

GANs vynikají v generování nových, syntetických dat, která se podobají trénovacímu datasetu. Jejich inovativní přístup vedl k průlomům v generování obrazů, rozšiřování dat a kreativních aplikacích, jako je generování umění a převod obrazu na obraz.

## Základní architektura GANs

GAN se skládá ze dvou hlavních komponent:

1. **Generátor (G)**: Vytváří syntetické vzorky dat z náhodného šumu
2. **Diskriminátor (D)**: Rozlišuje mezi reálnými daty a generovanými falešnými daty

Tyto dvě sítě soutěží proti sobě v minimax hře, kde:
- Generátor se snaží vytvářet stále realističtější data, aby oklamal diskriminátor
- Diskriminátor se snaží přesně identifikovat reálné vs. falešné vzorky

![Architektura GAN](https://i.imgur.com/OzQP5G6.png)

```python
# Jednoduchá architektura generátoru
def build_generator(latent_dim, output_shape):
    model = models.Sequential([
        # Základ pro obraz 7x7
        layers.Dense(7*7*256, use_bias=False, input_shape=(latent_dim,)),
        layers.BatchNormalization(),
        layers.LeakyReLU(),
        
        layers.Reshape((7, 7, 256)),
        
        # Zvětšení na 14x14
        layers.Conv2DTranspose(128, (5, 5), strides=(1, 1), padding='same', use_bias=False),
        layers.BatchNormalization(),
        layers.LeakyReLU(),
        
        # Zvětšení na 28x28
        layers.Conv2DTranspose(64, (5, 5), strides=(2, 2), padding='same', use_bias=False),
        layers.BatchNormalization(),
        layers.LeakyReLU(),
        
        # Výstupní vrstva s tanh aktivací
        layers.Conv2DTranspose(1, (5, 5), strides=(2, 2), padding='same', use_bias=False, activation='tanh')
    ])
    
    return model

# Jednoduchá architektura diskriminátoru
def build_discriminator(input_shape):
    model = models.Sequential([
        layers.Conv2D(64, (5, 5), strides=(2, 2), padding='same', input_shape=input_shape),
        layers.LeakyReLU(),
        layers.Dropout(0.3),
        
        layers.Conv2D(128, (5, 5), strides=(2, 2), padding='same'),
        layers.LeakyReLU(),
        layers.Dropout(0.3),
        
        layers.Flatten(),
        layers.Dense(1)  # Binární klasifikace: pravý nebo falešný
    ])
    
    return model
```

## Jak GANs fungují

GANs fungují prostřednictvím adversariálního tréninku, kde generátor a diskriminátor sítě soutěží:

1. **Generátor**: Přijímá náhodný šum (latentní vektor) jako vstup a vytváří syntetické vzorky
2. **Diskriminátor**: Přijímá reálná data i generovaná falešná data jako vstup a výstupem je pravděpodobnost, že vstup je reálný

Proces trénování zahrnuje:
- Trénování diskriminátoru pro správnou klasifikaci reálných a falešných vzorků
- Trénování generátoru pro vytváření vzorků, které oklamou diskriminátor

Toto lze matematicky vyjádřit jako minimax hru s následující účelovou funkcí:

$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_z(z)}[\log(1 - D(G(z)))]$

```python
# Definice ztrátových funkcí pro GAN
cross_entropy = tf.keras.losses.BinaryCrossentropy(from_logits=True)

def discriminator_loss(real_output, fake_output):
    # Reálné vzorky by měly být klasifikovány jako 1
    real_loss = cross_entropy(tf.ones_like(real_output), real_output)
    # Falešné vzorky by měly být klasifikovány jako 0
    fake_loss = cross_entropy(tf.zeros_like(fake_output), fake_output)
    # Celková ztráta je součtem
    total_loss = real_loss + fake_loss
    return total_loss

def generator_loss(fake_output):
    # Generátor chce, aby byly falešné vzorky klasifikovány jako 1 (reálné)
    return cross_entropy(tf.ones_like(fake_output), fake_output)
```

## Proces trénování a výzvy

Trénování GANs je notoricky obtížné kvůli několika výzvám:

1. **Nashova rovnováha**: Nalezení rovnovážného bodu, kde obě sítě pracují optimálně
2. **Kolaps módu**: Generátor produkuje omezené varianty vzorků
3. **Mizející gradienty**: Diskriminátor se stává příliš dobrým, což vede ke slabým gradientům pro generátor
4. **Nestabilita trénování**: Oscilace a selhání konvergence

Běžné techniky pro zlepšení trénování GANs:

- **Porovnávání příznaků**: Porovnávání statistik reálných a generovaných dat
- **Wassersteinova vzdálenost**: Alternativa k JS divergenci (WGAN)
- **Penalizace gradientu**: Vynucení Lipschitzovy podmínky (WGAN-GP)
- **Spektrální normalizace**: Stabilizace trénování diskriminátoru
- **Progresivní růst**: Postupně zvyšující se rozlišení

```python
# Trénovací smyčka GAN
def train_gan(generator, discriminator, dataset, latent_dim, epochs=50, batch_size=256):
    # Optimalizátory
    generator_optimizer = tf.keras.optimizers.Adam(1e-4)
    discriminator_optimizer = tf.keras.optimizers.Adam(1e-4)
    
    # Trénovací krok
    @tf.function
    def train_step(images):
        # Generování náhodného šumu pro generátor
        noise = tf.random.normal([batch_size, latent_dim])
        
        with tf.GradientTape() as gen_tape, tf.GradientTape() as disc_tape:
            # Generování falešných obrázků
            generated_images = generator(noise, training=True)
            
            # Získání výstupů diskriminátoru pro reálné a falešné obrázky
            real_output = discriminator(images, training=True)
            fake_output = discriminator(generated_images, training=True)
            
            # Výpočet ztrát
            gen_loss = generator_loss(fake_output)
            disc_loss = discriminator_loss(real_output, fake_output)
        
        # Výpočet gradientů
        gradients_of_generator = gen_tape.gradient(gen_loss, generator.trainable_variables)
        gradients_of_discriminator = disc_tape.gradient(disc_loss, discriminator.trainable_variables)
        
        # Aplikace gradientů
        generator_optimizer.apply_gradients(zip(gradients_of_generator, generator.trainable_variables))
        discriminator_optimizer.apply_gradients(zip(gradients_of_discriminator, discriminator.trainable_variables))
        
        return gen_loss, disc_loss
    
    # Trénovací smyčka
    for epoch in range(epochs):
        for batch in dataset:
            gen_loss, disc_loss = train_step(batch)
            
        # Občasný výpis ztrát
        if (epoch + 1) % 10 == 0:
            print(f"Epocha {epoch+1}, Ztráta gen.: {gen_loss:.4f}, Ztráta diskr.: {disc_loss:.4f}")
            
        # Generování a uložení vzorových obrázků
        if (epoch + 1) % 10 == 0:
            generate_and_save_images(generator, epoch + 1, latent_dim)
            
    return generator, discriminator

# Funkce pro generování a vizualizaci obrázků
def generate_and_save_images(model, epoch, latent_dim, n=16):
    # Generování obrázků z náhodného šumu
    noise = tf.random.normal([n, latent_dim])
    generated_images = model(noise, training=False)
    
    # Přeškálování obrázků na [0, 1]
    generated_images = (generated_images + 1) / 2.0
    
    # Vykreslení obrázků
    fig = plt.figure(figsize=(4, 4))
    for i in range(n):
        plt.subplot(4, 4, i+1)
        plt.imshow(generated_images[i, :, :, 0], cmap='gray')
        plt.axis('off')
    
    plt.savefig(f'obrazek_v_epose_{epoch}.png')
    plt.close()
```

## Typy GANs

Od jejich zavedení bylo vyvinuto mnoho variant GANs pro řešení specifických výzev nebo úloh:

1. **DCGAN (Deep Convolutional GAN)**: Používá konvoluční vrstvy pro lepší generování obrazů
2. **WGAN (Wasserstein GAN)**: Používá Wassersteinovu vzdálenost pro zlepšení stability tréninku
3. **CGAN (Conditional GAN)**: Začleňuje podmíněné informace pro řízení generování
4. **CycleGAN**: Učí se mapování mezi doménami bez párovaných příkladů
5. **StyleGAN**: Umožňuje přenos stylu a jemné ovládání generovaných obrázků
6. **Progressive GAN**: Postupně zvyšuje rozlišení během tréninku
7. **BigGAN**: Škálované GANs pro generování obrázků vysoké kvality
8. **InfoGAN**: Učí se disentangled reprezentace bez učitele

```python
# Příklad generátoru Conditional GAN (CGAN)
def build_cgan_generator(latent_dim, n_classes, output_shape):
    # Vstup šumu
    noise = layers.Input(shape=(latent_dim,))
    
    # Vstup štítku
    label = layers.Input(shape=(1,), dtype='int32')
    label_embedding = layers.Embedding(n_classes, 50)(label)
    label_embedding = layers.Flatten()(label_embedding)
    
    # Kombinování šumu a štítku
    combined_input = layers.Concatenate()([noise, label_embedding])
    
    # Síť generátoru
    x = layers.Dense(7*7*256)(combined_input)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU()(x)
    
    x = layers.Reshape((7, 7, 256))(x)
    
    x = layers.Conv2DTranspose(128, (5, 5), strides=(1, 1), padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU()(x)
    
    x = layers.Conv2DTranspose(64, (5, 5), strides=(2, 2), padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU()(x)
    
    output = layers.Conv2DTranspose(1, (5, 5), strides=(2, 2), padding='same', activation='tanh')(x)
    
    # Definice modelu
    model = models.Model([noise, label], output)
    return model
```

## Evaluační metriky pro GANs

Hodnocení GANs je náročné, protože neexistuje jediná objektivní metrika. Běžné hodnotící metody zahrnují:

1. **Inception Score (IS)**: Měří kvalitu a rozmanitost generovaných obrázků
2. **Fréchet Inception Distance (FID)**: Měří podobnost mezi distribucemi reálných a generovaných obrázků
3. **Precision a Recall**: Hodnotí kvalitu a rozmanitost samostatně
4. **Perceptual Path Length (PPL)**: Měří hladkost latentního prostoru
5. **Hodnocení lidmi**: Přímé posouzení lidskými hodnotiteli


## Pokročilé techniky GANs

Pro zlepšení tréninku a výkonu GANs bylo vyvinuto několik technik:

1. **Spektrální normalizace**: Stabilizuje trénink diskriminátoru omezením jeho Lipschitzovy konstanty
2. **Mechanismy self-attention**: Umožňují generování obrázků s globální koherencí
3. **Progresivní růst**: Začíná s obrázky nízkého rozlišení a postupně přidává vrstvy pro vyšší rozlišení
4. **Míchání stylů**: Umožňuje kontrolu nad různými aspekty generovaných obrázků
5. **Adaptivní instance normalizace**: Lepší přenos stylu v architekturách StyleGAN
6. **Trik zkrácení**: Vyvážení mezi rozmanitostí a kvalitou v latentním prostoru

```python
# Příklad implementace spektrální normalizace pro stabilizaci diskriminátoru
class SpectralNormalization(tf.keras.layers.Wrapper):
    def __init__(self, layer, iteration=1, **kwargs):
        super(SpectralNormalization, self).__init__(layer, **kwargs)
        self.iteration = iteration

    def build(self, input_shape):
        if not self.layer.built:
            self.layer.build(input_shape)

        self.w = self.layer.kernel
        self.w_shape = self.w.shape.as_list()
        
        # Zploštění váhové matice
        self.u = self.add_weight(
            shape=(1, self.w_shape[-1]),
            initializer=tf.initializers.TruncatedNormal(),
            trainable=False,
            name='sn_u')

    def call(self, inputs, training=None):
        # Spektrální normalizace
        w_reshaped = tf.reshape(self.w, [-1, self.w_shape[-1]])
        
        # Mocninná iterace
        for _ in range(self.iteration):
            v = tf.matmul(self.u, w_reshaped, transpose_b=True)
            v = v / tf.norm(v)
            self.u.assign(tf.matmul(v, w_reshaped))
        
        sigma = tf.matmul(tf.matmul(self.u, w_reshaped), v, transpose_b=True)
        self.layer.kernel = self.w / sigma
        
        return self.layer(inputs)

# Příklad použití v diskriminátoru
def build_sn_discriminator(input_shape):
    model = models.Sequential([
        SpectralNormalization(layers.Conv2D(64, (5, 5), strides=(2, 2), 
                                          padding='same', input_shape=input_shape)),
        layers.LeakyReLU(0.2),
        
        SpectralNormalization(layers.Conv2D(128, (5, 5), strides=(2, 2), 
                                          padding='same')),
        layers.LeakyReLU(0.2),
        
        layers.Flatten(),
        SpectralNormalization(layers.Dense(1))
    ])
    
    return model
```

## Aplikace GANs

GANs našly uplatnění v mnoha oblastech:

1. **Generování obrazů**: Vytváření realistických obrázků od základu
2. **Převod obrazu na obraz**: Převádění jednoho typu obrazu na jiný (např. náčrty na fotografie)
3. **Super-resolution**: Vylepšování obrázků s nízkým rozlišením
4. **Rozšiřování dat**: Generování syntetických trénovacích dat pro jiné modely
5. **Syntéza textu na obraz**: Generování obrázků z textových popisů
6. **Úprava a manipulace s obličeji**: Úprava atributů obličeje
7. **Přenos stylu**: Aplikace uměleckých stylů na fotografie
8. **Detekce anomálií**: Identifikace neobvyklých vzorů v datech
9. **Objevování léčiv**: Generování nových molekulárních struktur
10. **Tvorba syntetických médií**: Včetně deepfakes a digitálních avatarů

```python
# Příklad použití GAN pro převod obrazu na obraz (zjednodušený koncept CycleGAN)
def build_generator_unet(input_shape):
    """Generátor stylu U-Net pro převod obrazu na obraz"""
    
    # Enkodér
    inputs = layers.Input(shape=input_shape)
    
    # Downsampling
    e1 = layers.Conv2D(64, (4, 4), strides=(2, 2), padding='same')(inputs)
    e1 = layers.LeakyReLU(0.2)(e1)
    
    e2 = layers.Conv2D(128, (4, 4), strides=(2, 2), padding='same')(e1)
    e2 = layers.BatchNormalization()(e2)
    e2 = layers.LeakyReLU(0.2)(e2)
    
    e3 = layers.Conv2D(256, (4, 4), strides=(2, 2), padding='same')(e2)
    e3 = layers.BatchNormalization()(e3)
    e3 = layers.LeakyReLU(0.2)(e3)
    
    # Bottleneck
    b = layers.Conv2D(512, (4, 4), strides=(2, 2), padding='same')(e3)
    b = layers.BatchNormalization()(b)
    b = layers.LeakyReLU(0.2)(b)
    
    # Upsampling s přeskočenými spojeními
    d1 = layers.Conv2DTranspose(256, (4, 4), strides=(2, 2), padding='same')(b)
    d1 = layers.BatchNormalization()(d1)
    d1 = layers.Dropout(0.5)(d1)
    d1 = layers.concatenate([d1, e3])
    d1 = layers.LeakyReLU(0.2)(d1)
    
    d2 = layers.Conv2DTranspose(128, (4, 4), strides=(2, 2), padding='same')(d1)
    d2 = layers.BatchNormalization()(d2)
    d2 = layers.Dropout(0.5)(d2)
    d2 = layers.concatenate([d2, e2])
    d2 = layers.LeakyReLU(0.2)(d2)
    
    d3 = layers.Conv2DTranspose(64, (4, 4), strides=(2, 2), padding='same')(d2)
    d3 = layers.BatchNormalization()(d3)
    d3 = layers.Dropout(0.5)(d3)
    d3 = layers.concatenate([d3, e1])
    d3 = layers.LeakyReLU(0.2)(d3)
    
    # Výstup
    outputs = layers.Conv2DTranspose(3, (4, 4), strides=(2, 2), padding='same', activation='tanh')(d3)
    
    # Definice modelu
    model = models.Model(inputs, outputs)
    return model
```

## Shrnutí

Generativní adversariální sítě (GANs) představují průlomové paradigma v hlubokém učení zaměřené na generativní modelování prostřednictvím adversariálního tréninku. Klíčové poznatky zahrnují:

1. **Unikátní architektura**: GANs se skládají ze dvou soupeřících sítí—generátoru, který vytváří syntetická data, a diskriminátoru, který rozlišuje reálná data od falešných.

2. **Adversariální trénink**: Sítě se zlepšují prostřednictvím soutěže, přičemž generátor se snaží oklamat diskriminátor a diskriminátor se stává lepším v detekci falešných dat.

3. **Výzvy trénování**: GANs jsou notoricky obtížné na trénování, čelí problémům jako kolaps módu, nestabilita tréninku a mizející gradienty.

4. **Různé varianty**: Existuje mnoho variant GANs, včetně DCGAN, WGAN, conditional GAN, CycleGAN a StyleGAN, z nichž každá řeší specifické výzvy nebo aplikace.

5. **Komplexnost hodnocení**: Hodnocení GANs vyžaduje více metrik, jako je Inception Score, FID, precision/recall a často i lidský úsudek.

6. **Široké aplikace**: GANs revolucionizovaly generování obrazů, překlady, vylepšení a našly uplatnění ve zdravotnictví, zábavě a vědeckém výzkumu.

7. **Pokračující výzkum**: Oblast se nadále rychle vyvíjí s pokroky v architektuře, trénovacích technikách a aplikacích.

Navzdory svým výzvám se GANs ukázaly být jedním z nejzajímavějších vývoj v oblasti hlubokého učení, umožňují kreativní aplikace, které byly dříve považovány za nemožné, a otevírají nové cesty pro umělou inteligenci k pochopení a generování realistického obsahu.
