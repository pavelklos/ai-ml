## 1. Úvod do posilovaného učení

Posilované učení (Reinforcement Learning, RL) je paradigma strojového učení zaměřené na rozhodování a optimální chování v interaktivních prostředích. Na rozdíl od učení s učitelem agent nemá přístup ke správným odpovědím, ale učí se z interakce s prostředím pomocí zpětné vazby.

```python
# Základní koncepty posilovaného učení
import numpy as np
import gym

# Vytvoření jednoduchého prostředí
env = gym.make('CartPole-v1')

# Základní komponenty posilovaného učení
observation_space = env.observation_space  # Stavový prostor
action_space = env.action_space            # Akční prostor
rewards = []                               # Odměny

# Jednoduchý průchod prostředím s náhodnými akcemi
observation = env.reset()
done = False
total_reward = 0

while not done:
    action = env.action_space.sample()  # Náhodná akce
    observation, reward, done, info = env.step(action)
    total_reward += reward

print(f"Celková odměna při náhodném chování: {total_reward}")
```

### Klíčové komponenty posilovaného učení:

1. **Agent**: Entita, která se učí a rozhoduje
2. **Prostředí**: Svět, se kterým agent interaguje
3. **Stav**: Informace o aktuální situaci
4. **Akce**: Možná rozhodnutí agenta
5. **Odměna**: Zpětná vazba z prostředí
6. **Strategie (Policy)**: Způsob, jakým agent vybírá akce
7. **Hodnotová funkce**: Odhad budoucích odměn

## 2. Základy hlubokých neuronových sítí pro RL

Hluboké neuronové sítě slouží v posilovaném učení jako funkční aproximátory pro odhad hodnotových funkcí nebo strategií, zvláště při práci s vysokodimenzionálními stavovými prostory jako jsou například obrázky.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleDQN(nn.Module):
    """Jednoduchá deep Q-network"""
    def __init__(self, input_size, output_size):
        super(SimpleDQN, self).__init__()
        self.fc1 = nn.Linear(input_size, 128)
        self.fc2 = nn.Linear(128, 128)
        self.fc3 = nn.Linear(128, output_size)
        
    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        return self.fc3(x)  # Q-hodnoty pro každou akci

# Příklad použití
state_size = 4    # Pro prostředí CartPole
action_size = 2   # Pro prostředí CartPole
model = SimpleDQN(state_size, action_size)

# Zpracování ukázkového stavu
sample_state = torch.FloatTensor(np.random.rand(1, state_size))
q_values = model(sample_state)
print(f"Q-hodnoty pro ukázkový stav: {q_values}")
```

Klíčové úvahy při používání neuronových sítí pro RL:

- **Nestacionarita**: Distribuce trénovacích dat se mění, jak se agent učí
- **Efektivita vzorkování**: Maximalizace učení z omezených interakcí s prostředím
- **Přiřazení kreditu**: Určení, které akce vedly k zpožděným odměnám
- **Kompromis mezi průzkumem a využitím**: Vyvažování objevování a využívání známých odměn

## 3. Q-Learning a Deep Q-Networks (DQN)

Q-Learning je algoritmus RL založený na hodnotách, který se učí hodnotu akcí v různých stavech. Deep Q-Networks tuto myšlenku rozšiřují použitím neuronových sítí pro aproximaci Q-funkce.

```python
import torch.optim as optim
from collections import deque
import random

class DQNAgent:
    def __init__(self, state_size, action_size):
        self.state_size = state_size
        self.action_size = action_size
        self.memory = deque(maxlen=10000)  # Buffer pro experience replay
        
        self.gamma = 0.99    # Diskontní faktor
        self.epsilon = 1.0   # Míra průzkumu
        self.epsilon_min = 0.01
        self.epsilon_decay = 0.995
        
        # Q-sítě
        self.model = SimpleDQN(state_size, action_size)
        self.target_model = SimpleDQN(state_size, action_size)
        self.optimizer = optim.Adam(self.model.parameters(), lr=0.001)
        
        # Aktualizace cílové sítě
        self.update_target_model()
        
    def update_target_model(self):
        """Zkopíruje váhy z modelu do target_modelu"""
        self.target_model.load_state_dict(self.model.state_dict())
        
    def remember(self, state, action, reward, next_state, done):
        """Uloží zkušenost do replay paměti"""
        self.memory.append((state, action, reward, next_state, done))
        
    def act(self, state):
        """Vybere akci pomocí epsilon-greedy strategie"""
        if np.random.rand() <= self.epsilon:
            return random.randrange(self.action_size)  # Průzkum
            
        # Využití: výběr nejlepší akce založené na Q-hodnotách
        state_tensor = torch.FloatTensor(state).unsqueeze(0)
        with torch.no_grad():
            q_values = self.model(state_tensor)
        return q_values.argmax().item()
    
    def replay(self, batch_size):
        """Trénování na náhodné mini-dávce z replay paměti"""
        if len(self.memory) < batch_size:
            return
            
        # Výběr náhodné mini-dávky
        minibatch = random.sample(self.memory, batch_size)
        
        for state, action, reward, next_state, done in minibatch:
            target = reward
            state_tensor = torch.FloatTensor(state).unsqueeze(0)
            next_state_tensor = torch.FloatTensor(next_state).unsqueeze(0)
            
            if not done:
                # Výpočet cílové Q-hodnoty pomocí cílové sítě (Double DQN)
                with torch.no_grad():
                    next_q_values = self.target_model(next_state_tensor)
                target = reward + self.gamma * next_q_values.max().item()
                
            # Aktualizace Q-hodnoty pro provedenou akci
            current_q = self.model(state_tensor)
            target_q = current_q.clone().detach()
            target_q[0][action] = target
            
            # Trénování modelu
            self.optimizer.zero_grad()
            loss = F.mse_loss(current_q, target_q)
            loss.backward()
            self.optimizer.step()
            
        # Snížení míry průzkumu
        if self.epsilon > self.epsilon_min:
            self.epsilon *= self.epsilon_decay
```

### Klíčové inovace DQN:

1. **Experience Replay**: Ukládání a náhodné vzorkování minulých zkušeností pro narušení korelací v sekvenčních datech
2. **Cílová síť**: Použití samostatné sítě pro výpočet cílových hodnot ke zlepšení stability tréninku
3. **Double DQN**: Oddělení výběru akce od jejího hodnocení pro snížení nadhodnocení
4. **Dueling DQN**: Oddělený odhad hodnoty stavu a výhod akcí

## 4. Policy Gradient metody

Policy Gradient metody optimalizují strategii přímo, bez učení hodnotové funkce. Fungují aktualizací parametrů strategie ve směru větší očekávané odměny.

```python
class PolicyNetwork(nn.Module):
    """Jednoduchá síť pro strategii u policy gradient metod"""
    def __init__(self, input_size, output_size):
        super(PolicyNetwork, self).__init__()
        self.fc1 = nn.Linear(input_size, 128)
        self.fc2 = nn.Linear(128, output_size)
        
    def forward(self, x):
        x = F.relu(self.fc1(x))
        # Výstup pravděpodobnostní distribuce pro akce
        return F.softmax(self.fc2(x), dim=1)

class REINFORCE:
    """REINFORCE (Monte Carlo Policy Gradient) algoritmus"""
    def __init__(self, state_size, action_size):
        self.policy = PolicyNetwork(state_size, action_size)
        self.optimizer = optim.Adam(self.policy.parameters(), lr=0.01)
        self.gamma = 0.99
        
    def select_action(self, state):
        """Výběr akce ze strategie"""
        state_tensor = torch.FloatTensor(state).unsqueeze(0)
        action_probs = self.policy(state_tensor)
        action_distribution = torch.distributions.Categorical(action_probs)
        action = action_distribution.sample()
        log_prob = action_distribution.log_prob(action)
        return action.item(), log_prob
    
    def update_policy(self, rewards, log_probs):
        """Aktualizace parametrů strategie pomocí policy gradient"""
        # Výpočet diskontovaných návratů
        returns = []
        discounted_return = 0
        
        # Výpočet návratů v obráceném pořadí
        for reward in reversed(rewards):
            discounted_return = reward + self.gamma * discounted_return
            returns.insert(0, discounted_return)
            
        returns = torch.FloatTensor(returns)
        
        # Normalizace návratů pro stabilitu tréninku
        returns = (returns - returns.mean()) / (returns.std() + 1e-9)
        
        # Výpočet ztráty strategie
        policy_loss = []
        for log_prob, R in zip(log_probs, returns):
            # Záporné znaménko, protože provádíme gradient ascent
            policy_loss.append(-log_prob * R)
        
        # Zpětná propagace
        self.optimizer.zero_grad()
        policy_loss = torch.cat(policy_loss).sum()
        policy_loss.backward()
        self.optimizer.step()
```

### Výhody Policy Gradient metod:

1. **Přímá optimalizace**: Přímo optimalizují strategii pro daný cíl
2. **Stochastické strategie**: Přirozeně pracují se stochastickými strategiemi, což je důležité pro průzkum
3. **Spojité akce**: Dobře fungují se spojitými akčními prostory
4. **Jednoduchá aktualizační pravidla**: Konceptuálně přímočaré aktualizace gradientu

## 5. Actor-Critic architektury

Actor-Critic metody kombinují přístupy založené na hodnotách a strategiích. Herec (actor - síť strategie) rozhoduje, jaké akce provést, zatímco kritik (critic - síť hodnot) tyto akce hodnotí.

```python
class ActorCritic(nn.Module):
    """Kombinovaná actor-critic síť"""
    def __init__(self, state_size, action_size):
        super(ActorCritic, self).__init__()
        
        # Společné vrstvy pro extrakci příznaků
        self.fc1 = nn.Linear(state_size, 128)
        
        # Actor výstupy (strategie)
        self.actor = nn.Linear(128, action_size)
        
        # Critic výstupy (hodnotová funkce)
        self.critic = nn.Linear(128, 1)
    
    def forward(self, x):
        """Průchod sítí"""
        features = F.relu(self.fc1(x))
        
        # Actor: Pravděpodobnostní distribuce akcí
        action_probs = F.softmax(self.actor(features), dim=-1)
        
        # Critic: Odhad hodnoty stavu
        state_value = self.critic(features)
        
        return action_probs, state_value
    
    def act(self, state):
        """Výběr akce ze současné strategie"""
        state_tensor = torch.FloatTensor(state).unsqueeze(0)
        action_probs, _ = self(state_tensor)
        
        # Vytvoření distribuce a výběr
        dist = torch.distributions.Categorical(action_probs)
        action = dist.sample()
        
        return action.item(), dist.log_prob(action), action_probs

class A2CAgent:
    """Advantage Actor-Critic (A2C) agent"""
    def __init__(self, state_size, action_size):
        self.model = ActorCritic(state_size, action_size)
        self.optimizer = optim.Adam(self.model.parameters(), lr=0.001)
        self.gamma = 0.99
        
    def update(self, states, actions, rewards, next_states, dones):
        """Aktualizace actor a critic sítí"""
        # Převod seznamů na tensory
        states = torch.FloatTensor(states)
        actions = torch.LongTensor(actions)
        rewards = torch.FloatTensor(rewards)
        next_states = torch.FloatTensor(next_states)
        dones = torch.FloatTensor(dones)
        
        # Získání pravděpodobností akcí a hodnot stavů
        _, next_state_values = self.model(next_states)
        action_probs, state_values = self.model(states)
        
        # Indexace vybraných akcí
        dist = torch.distributions.Categorical(action_probs)
        log_probs = dist.log_prob(actions)
        entropy = dist.entropy()  # Pro bonus průzkumu
        
        # Výpočet výhod
        next_state_values[dones] = 0  # Terminální stavy nemají budoucí odměny
        advantages = rewards + self.gamma * next_state_values.detach() - state_values
        
        # Výpočet ztrát
        critic_loss = advantages.pow(2).mean()  # MSE
        actor_loss = -(log_probs * advantages.detach()).mean()  # Policy gradient
        entropy_loss = -0.01 * entropy.mean()  # Bonus průzkumu
        
        # Kombinovaná ztráta
        loss = actor_loss + critic_loss + entropy_loss
        
        # Aktualizace sítí
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()
        
        return loss.item()
```

### Výhody Actor-Critic metod:

1. **Snížená variance**: Použití kritika snižuje varianci aktualizací policy gradientu
2. **Efektivita vzorků**: Efektivnější využití dat ze zkušeností
3. **Online učení**: Lze se učit z jednotlivých přechodů bez celých epizod
4. **Kombinované výhody**: Využívá výhody metod založených na hodnotách i strategiích

## 6. Implementace DQN v Pythonu

Zde je kompletní implementace agenta Deep Q-Network trénujícího se v prostředí CartPole:

```python
import gym
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
import torch.nn.functional as F
from collections import deque
import random
import matplotlib.pyplot as plt

# Model Deep Q-Network
class DQN(nn.Module):
    def __init__(self, state_size, action_size):
        super(DQN, self).__init__()
        self.fc1 = nn.Linear(state_size, 64)
        self.fc2 = nn.Linear(64, 64)
        self.fc3 = nn.Linear(64, action_size)
        
    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        return self.fc3(x)

# DQN agent s experience replay a cílovou sítí
class DQNAgent:
    def __init__(self, state_size, action_size):
        self.state_size = state_size
        self.action_size = action_size
        self.memory = deque(maxlen=2000)
        self.batch_size = 64
        
        # Hyperparametry
        self.gamma = 0.99        # Diskontní faktor
        self.epsilon = 1.0       # Míra průzkumu
        self.epsilon_min = 0.01
        self.epsilon_decay = 0.995
        self.tau = 0.001         # Parametr pro soft update
        
        # Sítě
        self.policy_net = DQN(state_size, action_size)
        self.target_net = DQN(state_size, action_size)
        self.target_net.load_state_dict(self.policy_net.state_dict())
        self.target_net.eval()  # Nastavení cílové sítě do režimu vyhodnocení
        
        self.optimizer = optim.Adam(self.policy_net.parameters(), lr=0.001)
        
    def remember(self, state, action, reward, next_state, done):
        """Uložení přechodu do replay paměti"""
        self.memory.append((state, action, reward, next_state, done))
        
    def act(self, state):
        """Výběr akce pomocí epsilon-greedy strategie"""
        if random.random() <= self.epsilon:
            return random.randrange(self.action_size)
        else:
            state_tensor = torch.FloatTensor(state).unsqueeze(0)
            with torch.no_grad():
                q_values = self.policy_net(state_tensor)
            return q_values.argmax().item()
        
    def replay(self):
        """Trénování na dávce z replay paměti"""
        if len(self.memory) < self.batch_size:
            return
            
        # Výběr náhodné dávky
        minibatch = random.sample(self.memory, self.batch_size)
        
        # Příprava dat pro dávku
        states, actions, rewards, next_states, dones = zip(*minibatch)
        
        states = torch.FloatTensor(np.array(states))
        actions = torch.LongTensor(actions).unsqueeze(1)
        rewards = torch.FloatTensor(rewards).unsqueeze(1)
        next_states = torch.FloatTensor(np.array(next_states))
        dones = torch.FloatTensor(dones).unsqueeze(1)
        
        # Výpočet současných Q hodnot
        current_q = self.policy_net(states).gather(1, actions)
        
        # Výpočet cílových Q hodnot (Double DQN)
        with torch.no_grad():
            # Výběr akcí pomocí policy sítě
            policy_argmax = self.policy_net(next_states).argmax(dim=1, keepdim=True)
            # Vyhodnocení pomocí target sítě
            next_q = self.target_net(next_states).gather(1, policy_argmax)
            target_q = rewards + (1 - dones) * self.gamma * next_q
        
        # Výpočet ztráty a aktualizace
        loss = F.smooth_l1_loss(current_q, target_q)
        self.optimizer.zero_grad()
        loss.backward()
        # Oříznutí gradientů pro prevenci explodujícího gradientu
        for param in self.policy_net.parameters():
            param.grad.data.clamp_(-1, 1)
        self.optimizer.step()
        
        # Soft update cílové sítě
        for target_param, policy_param in zip(self.target_net.parameters(), 
                                              self.policy_net.parameters()):
            target_param.data.copy_(
                self.tau * policy_param.data + (1 - self.tau) * target_param.data
            )
        
        # Snížení epsilon
        if self.epsilon > self.epsilon_min:
            self.epsilon *= self.epsilon_decay
            
# Trénovací funkce
def train_dqn(env_name='CartPole-v1', episodes=500):
    env = gym.make(env_name)
    state_size = env.observation_space.shape[0]
    action_size = env.action_space.n
    
    agent = DQNAgent(state_size, action_size)
    scores = []
    
    for episode in range(episodes):
        state = env.reset()
        score = 0
        done = False
        
        while not done:
            # Výběr a provedení akce
            action = agent.act(state)
            next_state, reward, done, _ = env.step(action)
            
            # Uložení přechodu a učení
            agent.remember(state, action, reward, next_state, done)
            agent.replay()
            
            state = next_state
            score += reward
            
        scores.append(score)
        
        print(f"Epizoda: {episode+1}, Skóre: {score}, Epsilon: {agent.epsilon:.2f}")
        
        # Pokud je CartPole vyřešen (průměrné skóre >= 195 přes 100 epizod)
        if len(scores) > 100 and np.mean(scores[-100:]) >= 195:
            print(f"CartPole vyřešen v {episode+1} epizodách!")
            break
            
    return scores

# Spuštění tréninku
if __name__ == "__main__":
    scores = train_dqn()
    
    # Vykreslení výsledků
    plt.figure(figsize=(10, 6))
    plt.plot(scores)
    plt.title('DQN trénink na CartPole')
    plt.xlabel('Epizoda')
    plt.ylabel('Skóre')
    plt.show()
```

Tato implementace zahrnuje klíčové funkce DQN:
- Buffer pro experience replay
- Cílovou síť s soft updates
- Double DQN algoritmus
- Epsilon-greedy průzkum

## 7. Implementace Policy Gradient v Pythonu

Nyní implementujme algoritmus REINFORCE (Monte Carlo Policy Gradient):

```python
import gym
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
import torch.nn.functional as F
import matplotlib.pyplot as plt
from torch.distributions import Categorical

# Síť pro strategii
class PolicyNetwork(nn.Module):
    def __init__(self, state_size, action_size):
        super(PolicyNetwork, self).__init__()
        self.fc1 = nn.Linear(state_size, 128)
        self.fc2 = nn.Linear(128, action_size)
        
    def forward(self, x):
        x = F.relu(self.fc1(x))
        return F.softmax(self.fc2(x), dim=1)
    
    def act(self, state):
        """Výběr akce ze strategie"""
        state_tensor = torch.FloatTensor(state).unsqueeze(0)
        probs = self.forward(state_tensor)
        m = Categorical(probs)
        action = m.sample()
        return action.item(), m.log_prob(action)

# REINFORCE Agent
class REINFORCEAgent:
    def __init__(self, state_size, action_size):
        self.policy = PolicyNetwork(state_size, action_size)
        self.optimizer = optim.Adam(self.policy.parameters(), lr=0.001)
        self.gamma = 0.99
        
    def update_policy(self, rewards, log_probs):
        """Aktualizace strategie pomocí policy gradientu"""
        # Výpočet diskontovaných odměn
        discounted_rewards = []
        R = 0
        for r in reversed(rewards):
            R = r + self.gamma * R
            discounted_rewards.insert(0, R)
            
        # Převod na tensor a normalizace
        discounted_rewards = torch.FloatTensor(discounted_rewards)
        discounted_rewards = (discounted_rewards - discounted_rewards.mean()) / \
                             (discounted_rewards.std() + 1e-9)
        
        # Výpočet ztráty strategie
        policy_loss = []
        for log_prob, R in zip(log_probs, discounted_rewards):
            policy_loss.append(-log_prob * R)
            
        # Zpětná propagace
        self.optimizer.zero_grad()
        policy_loss = torch.cat(policy_loss).sum()
        policy_loss.backward()
        self.optimizer.step()
        
        return policy_loss.item()

# Trénovací funkce
def train_reinforce(env_name='CartPole-v1', episodes=1000):
    env = gym.make(env_name)
    state_size = env.observation_space.shape[0]
    action_size = env.action_space.n
    
    agent = REINFORCEAgent(state_size, action_size)
    scores = []
    
    for episode in range(episodes):
        state = env.reset()
        log_probs = []
        rewards = []
        score = 0
        done = False
        
        # Sběr trajektorie
        while not done:
            # Výběr akce
            action, log_prob = agent.policy.act(state)
            
            # Provedení akce
            next_state, reward, done, _ = env.step(action)
            
            # Uložení zkušenosti
            log_probs.append(log_prob)
            rewards.append(reward)
            
            state = next_state
            score += reward
        
        # Aktualizace strategie po dokončení epizody
        loss = agent.update_policy(rewards, log_probs)
        scores.append(score)
        
        print(f"Epizoda: {episode+1}, Skóre: {score}, Ztráta: {loss:.4f}")
        
        # Pokud je CartPole vyřešen
        if len(scores) > 100 and np.mean(scores[-100:]) >= 195:
            print(f"CartPole vyřešen v {episode+1} epizodách!")
            break
```

```python
# Příklad: Obchodní strategie s RL
import pandas as pd
import numpy as np
import yfinance as yf
import matplotlib.pyplot as plt

class TradingEnvironment:
    """Jednoduché obchodní prostředí pro RL"""
    def __init__(self, data, initial_balance=10000):
        self.data = data
        self.initial_balance = initial_balance
        self.reset()
        
    def reset(self):
        self.balance = self.initial_balance
        self.position = 0  # Počet akcií
        self.current_step = 0
        self.done = False
        state = self._get_state()
        return state
        
    def _get_state(self):
        """Vytvoření reprezentace stavu pro agenta"""
        # Jednoduchý stav: cenové příznaky, současný zůstatek, současná pozice
        if self.current_step >= len(self.data) - 1:
            return None
            
        # Použití ceny, 5denní návratnosti, 10denní návratnosti jako příznaků
        price = self.data.iloc[self.current_step]['Close']
        if self.current_step >= 5:
            return_5d = price / self.data.iloc[self.current_step-5]['Close'] - 1
        else:
            return_5d = 0
            
        if self.current_step >= 10:
            return_10d = price / self.data.iloc[self.current_step-10]['Close'] - 1
        else:
            return_10d = 0
        
        state = np.array([
            return_5d, return_10d,
            self.balance / self.initial_balance,
            self.position * price / self.initial_balance  # Hodnota portfolia
        ])
        
        return state
        
    def step(self, action):
        """Provedení akce a vrácení nového stavu, odměny, done"""
        # Akce: 0=prodej, 1=držení, 2=nákup
        if self.done:
            return self._get_state(), 0, self.done, {}
            
        # Získání současné ceny
        current_price = self.data.iloc[self.current_step]['Close']
        
        # Provedení akce
        if action == 0:  # Prodej
            if self.position > 0:
                self.balance += self.position * current_price
                self.position = 0
        elif action == 2:  # Nákup
            if self.balance > 0:
                shares_to_buy = self.balance / current_price
                self.position += shares_to_buy
                self.balance = 0
                
        # Posun na další krok
        self.current_step += 1
        
        # Výpočet odměny (změna hodnoty portfolia)
        old_portfolio_value = self.balance + self.position * current_price
        
        if self.current_step >= len(self.data) - 1:
            self.done = True
        
        if not self.done:
            new_price = self.data.iloc[self.current_step]['Close']
            new_portfolio_value = self.balance + self.position * new_price
            reward = (new_portfolio_value / old_portfolio_value) - 1
        else:
            reward = 0
            
        return self._get_state(), reward, self.done, {}

# Stažení vzorových dat akcií

        action = np.random.choice([0, 1, 2])  # Náhodná akce
```
