## Úvod do transformerů

Transformery jsou revoluční architektura neuronových sítí představená v článku ["Attention Is All You Need"](https://arxiv.org/abs/1706.03762) od Vaswani a kol. v roce 2017. Na rozdíl od předchozích modelů založených na sekvencích, které spoléhaly na rekurentní nebo konvoluční vrstvy, jsou transformery postaveny výhradně na mechanismech attention (pozornosti), konkrétně self-attention.

Transformery mají oproti předchozím architekturám několik výhod:

1. **Paralelizace**: Na rozdíl od RNN zpracovávají transformery celou sekvenci současně
2. **Dlouhodobé závislosti**: Mechanismus attention přímo propojuje libovolné pozice v sekvenci
3. **Škálovatelnost**: Transformery efektivně škálují na velké datasety a velikosti modelů

## Mechanismus self-attention

Mechanismus self-attention (vlastní pozornosti) je klíčovou inovací transformerů. Umožňuje modelu vážit důležitost různých slov v sekvenci při kódování každého slova. Například ve větě "Zvíře nepřešlo silnici, protože byla příliš široká," mechanismus self-attention pomáhá modelu pochopit, že "byla" se týká "silnice" a ne "zvířete".

Self-attention funguje prostřednictvím tří hlavních komponent:
1. **Query (Q)**: Co aktuální token hledá
2. **Key (K)**: Co nabízejí ostatní tokeny
3. **Value (V)**: Skutečná informace, kterou každý token nese

Attention skóre se vypočítá jako: $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$

```python
def scaled_dot_product_attention(q, k, v, mask=None):
    """Vypočítá váhy pozornosti.
    q, k, v musí mít shodné úvodní dimenze.
    k, v musí mít shodné předposlední dimenze, tj.: seq_len_k = seq_len_v.
    Maska má různé tvary v závislosti na typu (padding nebo look ahead),
    ale musí být broadcastovatelná pro součet.
    
    Argumenty:
      q: query, tvar == (..., seq_len_q, depth)
      k: key, tvar == (..., seq_len_k, depth)
      v: value, tvar == (..., seq_len_v, depth_v)
      mask: Float tensor s tvarem broadcastovatelným 
            na (..., seq_len_q, seq_len_k). Výchozí hodnota je None.
      
    Vrací:
      výstup, váhy pozornosti
    """

    # Výpočet skalárního součinu query a key
    matmul_qk = tf.matmul(q, k, transpose_b=True)  # (..., seq_len_q, seq_len_k)
    
    # Škálování matmul_qk
    dk = tf.cast(tf.shape(k)[-1], tf.float32)
    scaled_attention_logits = matmul_qk / tf.math.sqrt(dk)
    
    # Přidání masky k škálovanému tensoru (pokud je poskytnuta)
    if mask is not None:
        scaled_attention_logits += (mask * -1e9)  
    
    # Softmax je normalizován na poslední ose (seq_len_k), takže součet vah je 1
    attention_weights = tf.nn.softmax(scaled_attention_logits, axis=-1)  # (..., seq_len_q, seq_len_k)
    
    # Výpočet výstupu
    output = tf.matmul(attention_weights, v)  # (..., seq_len_q, depth_v)
    
    return output, attention_weights

# Příklad použití mechanismu attention
def attention_example():
    # Vytvoření vstupů příkladu
```

## Multi-head attention

Namísto provádění jediné operace attention, transformery používají multi-head attention (vícehlavou pozornost), která umožňuje modelu současně se zaměřit na informace z různých reprezentačních podprostorů. To pomáhá modelu zachytit různé typy vztahů mezi slovy.

Multi-head attention rozděluje dotazy, klíče a hodnoty do více hlav, aplikuje self-attention na každou hlavu nezávisle a poté výsledky spojí.

```python
class MultiHeadAttention(tf.keras.layers.Layer):
    def __init__(self, d_model, num_heads):
        super(MultiHeadAttention, self).__init__()
        self.num_heads = num_heads
        self.d_model = d_model
        
        assert d_model % self.num_heads == 0
        
        self.depth = d_model // self.num_heads
        
        self.wq = tf.keras.layers.Dense(d_model)
        self.wk = tf.keras.layers.Dense(d_model)
        self.wv = tf.keras.layers.Dense(d_model)
        
        self.dense = tf.keras.layers.Dense(d_model)
        
    def split_heads(self, x, batch_size):
        """Rozdělí poslední dimenzi na (num_heads, depth).
        Transponuje výsledek tak, že tvar je (batch_size, num_heads, seq_len, depth)
        """
        x = tf.reshape(x, (batch_size, -1, self.num_heads, self.depth))
        return tf.transpose(x, perm=[0, 2, 1, 3])
        
    def call(self, v, k, q, mask=None):
        batch_size = tf.shape(q)[0]
        
        q = self.wq(q)  # (batch_size, seq_len, d_model)
        k = self.wk(k)  # (batch_size, seq_len, d_model)
        v = self.wv(v)  # (batch_size, seq_len, d_model)
        
        q = self.split_heads(q, batch_size)  # (batch_size, num_heads, seq_len_q, depth)
        k = self.split_heads(k, batch_size)  # (batch_size, num_heads, seq_len_k, depth)
        v = self.split_heads(v, batch_size)  # (batch_size, num_heads, seq_len_v, depth)
        
        # Škálovaná dot-product attention
        scaled_attention, attention_weights = scaled_dot_product_attention(
            q, k, v, mask)
        
        # (batch_size, num_heads, seq_len_q, depth)
        scaled_attention = tf.transpose(scaled_attention, perm=[0, 2, 1, 3])  

        # (batch_size, seq_len_q, num_heads, depth)
        concat_attention = tf.reshape(scaled_attention, 
                                      (batch_size, -1, self.d_model))  # (batch_size, seq_len_q, d_model)
        
        output = self.dense(concat_attention)  # (batch_size, seq_len_q, d_model)
            
        return output, attention_weights

# Příklad použití
def multi_head_attention_example():
    # Vytvoření vzorového vstupu

    print(f"Tvar vstupu: {x.shape}")
    print(f"Tvar výstupu: {output.shape}")
    print(f"Tvar vah pozornosti: {attention_weights.shape}")
```

## Poziční kódování

Protože transformery zpracovávají všechny tokeny paralelně a nemají přirozenou představu o pořadí tokenů, jsou přidána poziční kódování, aby model získal informace o pozicích tokenů v sekvenci.

Typicky se používají funkce sinus a cosinus různých frekvencí k vytvoření jedinečných pozičních kódování:

```python
def get_positional_encoding(position, d_model):
    """
    Vypočítá poziční kódování pro pozici pomocí funkcí sinus a cosinus.
    
    Argumenty:
        position: Index pozice
        d_model: Dimenze modelu
    
    Vrací:
        Poziční kódování pro danou pozici
    """
    # Vytvoření pole úhlů pro funkce sinus a cosinus
    angle_rates = 1 / np.power(10000, (2 * (np.arange(d_model) // 2)) / np.float32(d_model))
    angle_rads = position * angle_rates

    # Aplikace sinu na sudé indexy v poli
    angle_rads[0::2] = np.sin(angle_rads[0::2])

    # Aplikace cosinu na liché indexy v poli
    angle_rads[1::2] = np.cos(angle_rads[1::2])

    return angle_rads

def positional_encoding(max_position, d_model):
    """
    Vytváří poziční kódování pro celou sekvenci.
    
    Argumenty:
        max_position: Maximální délka sekvence
        d_model: Dimenze modelu
    
    Vrací:
        Poziční kódování pro všechny pozice
    """
    pos_encoding = np.zeros((max_position, d_model))
    
    for pos in range(max_position):
        pos_encoding[pos] = get_positional_encoding(pos, d_model)
    
    # Přidání dimenze dávky
    pos_encoding = pos_encoding[np.newaxis, ...]
    
    return tf.cast(pos_encoding, dtype=tf.float32)

# Vizualizace pozičního kódování
```

## Architektura enkodér-dekodér

Architektura transformeru se skládá z enkodéru a dekodéru, z nichž každý obsahuje několik identických vrstev:

1. **Enkodér**: Zpracovává vstupní sekvenci a generuje reprezentace
2. **Dekodér**: Používá reprezentace enkodéru a dříve generované tokeny k vytvoření výstupní sekvence

Každá vrstva enkodéru obsahuje mechanismus multi-head self-attention a dopřednou neuronovou síť. Dekodér má navíc cross-attention vrstvu, která se zaměřuje na výstup enkodéru.

```python
def point_wise_feed_forward_network(d_model, dff):
    return tf.keras.Sequential([
        tf.keras.layers.Dense(dff, activation='relu'),  # (batch_size, seq_len, dff)
        tf.keras.layers.Dense(d_model)  # (batch_size, seq_len, d_model)
    ])

class EncoderLayer(tf.keras.layers.Layer):
    def __init__(self, d_model, num_heads, dff, rate=0.1):
        super(EncoderLayer, self).__init__()

        self.mha = MultiHeadAttention(d_model, num_heads)
        self.ffn = point_wise_feed_forward_network(d_model, dff)

        self.layernorm1 = tf.keras.layers.LayerNormalization(epsilon=1e-6)
        self.layernorm2 = tf.keras.layers.LayerNormalization(epsilon=1e-6)
        
        self.dropout1 = tf.keras.layers.Dropout(rate)
        self.dropout2 = tf.keras.layers.Dropout(rate)
    
    def call(self, x, training, mask=None):
        # Multi-head attention
        attn_output, _ = self.mha(x, x, x, mask)  # (batch_size, input_seq_len, d_model)
        attn_output = self.dropout1(attn_output, training=training)
        out1 = self.layernorm1(x + attn_output)  # (batch_size, input_seq_len, d_model)
        
        # Feed forward síť
        ffn_output = self.ffn(out1)  # (batch_size, input_seq_len, d_model)
        ffn_output = self.dropout2(ffn_output, training=training)
        out2 = self.layernorm2(out1 + ffn_output)  # (batch_size, input_seq_len, d_model)
        
        return out2

class DecoderLayer(tf.keras.layers.Layer):
    def __init__(self, d_model, num_heads, dff, rate=0.1):
        super(DecoderLayer, self).__init__()

        self.mha1 = MultiHeadAttention(d_model, num_heads)
        self.mha2 = MultiHeadAttention(d_model, num_heads)

        self.ffn = point_wise_feed_forward_network(d_model, dff)
 
        self.layernorm1 = tf.keras.layers.LayerNormalization(epsilon=1e-6)
        self.layernorm2 = tf.keras.layers.LayerNormalization(epsilon=1e-6)
        self.layernorm3 = tf.keras.layers.LayerNormalization(epsilon=1e-6)
        
        self.dropout1 = tf.keras.layers.Dropout(rate)
        self.dropout2 = tf.keras.layers.Dropout(rate)
        self.dropout3 = tf.keras.layers.Dropout(rate)
    
    def call(self, x, enc_output, training, 
             look_ahead_mask=None, padding_mask=None):
        # Self attention
        attn1, attn_weights_block1 = self.mha1(x, x, x, look_ahead_mask)  # (batch_size, target_seq_len, d_model)
        attn1 = self.dropout1(attn1, training=training)
        out1 = self.layernorm1(attn1 + x)
        
        # Cross attention s výstupem enkodéru
        attn2, attn_weights_block2 = self.mha2(
            enc_output, enc_output, out1, padding_mask)  # (batch_size, target_seq_len, d_model)
        attn2 = self.dropout2(attn2, training=training)
        out2 = self.layernorm2(attn2 + out1)  # (batch_size, target_seq_len, d_model)
        
        # Feed forward síť
        ffn_output = self.ffn(out2)  # (batch_size, target_seq_len, d_model)
        ffn_output = self.dropout3(ffn_output, training=training)
        out3 = self.layernorm3(ffn_output + out2)  # (batch_size, target_seq_len, d_model)
        
        return out3, attn_weights_block1, attn_weights_block2
```

## Implementace základního transformeru

Nyní implementujme základní model transformeru kombinací všech komponent:

```python
class Encoder(tf.keras.layers.Layer):
    def __init__(self, num_layers, d_model, num_heads, dff, input_vocab_size,
                 maximum_position_encoding, rate=0.1):
        super(Encoder, self).__init__()

        self.d_model = d_model
        self.num_layers = num_layers
        
        self.embedding = tf.keras.layers.Embedding(input_vocab_size, d_model)
        self.pos_encoding = positional_encoding(maximum_position_encoding, d_model)
        
        self.enc_layers = [
            EncoderLayer(d_model, num_heads, dff, rate) 
            for _ in range(num_layers)]
        
        self.dropout = tf.keras.layers.Dropout(rate)
        
    def call(self, x, training, mask=None):
        seq_len = tf.shape(x)[1]
        
        # Přidání embeddingu a pozičního kódování
        x = self.embedding(x)  # (batch_size, input_seq_len, d_model)
        x *= tf.math.sqrt(tf.cast(self.d_model, tf.float32))
        x += self.pos_encoding[:, :seq_len, :]
        
        x = self.dropout(x, training=training)
        
        # Zpracování enkodérovými vrstvami
        for i in range(self.num_layers):
            x = self.enc_layers[i](x, training, mask)
            
        return x  # (batch_size, input_seq_len, d_model)

class Decoder(tf.keras.layers.Layer):
    def __init__(self, num_layers, d_model, num_heads, dff, target_vocab_size,
                 maximum_position_encoding, rate=0.1):
        super(Decoder, self).__init__()

        self.d_model = d_model
        self.num_layers = num_layers
        
        self.embedding = tf.keras.layers.Embedding(target_vocab_size, d_model)
        self.pos_encoding = positional_encoding(maximum_position_encoding, d_model)
        
        self.dec_layers = [
            DecoderLayer(d_model, num_heads, dff, rate) 
            for _ in range(num_layers)]
        self.dropout = tf.keras.layers.Dropout(rate)
        
    def call(self, x, enc_output, training, 
             look_ahead_mask=None, padding_mask=None):
        seq_len = tf.shape(x)[1]
        attention_weights = {}
        
        # Přidání embeddingu a pozičního kódování
        x = self.embedding(x)  # (batch_size, target_seq_len, d_model)
        x *= tf.math.sqrt(tf.cast(self.d_model, tf.float32))
        x += self.pos_encoding[:, :seq_len, :]
        
        x = self.dropout(x, training=training)

        # Zpracování dekodérovými vrstvami
        for i in range(self.num_layers):
            x, block1, block2 = self.dec_layers[i](x, enc_output, training,
                                                 look_ahead_mask, padding_mask)
            
            attention_weights[f'decoder_layer{i+1}_block1'] = block1
            attention_weights[f'decoder_layer{i+1}_block2'] = block2
            
        return x, attention_weights  # (batch_size, target_seq_len, d_model)

class Transformer(tf.keras.Model):
    def __init__(self, num_layers, d_model, num_heads, dff, input_vocab_size, 
                 target_vocab_size, pe_input, pe_target, rate=0.1):
        super(Transformer, self).__init__()

        self.encoder = Encoder(num_layers, d_model, num_heads, dff, 
                               input_vocab_size, pe_input, rate)

        self.decoder = Decoder(num_layers, d_model, num_heads, dff, 
                               target_vocab_size, pe_target, rate)

        self.final_layer = tf.keras.layers.Dense(target_vocab_size)
        
    def call(self, inp, tar, training, enc_padding_mask=None, 
             look_ahead_mask=None, dec_padding_mask=None):
        # Výstup enkodéru
        enc_output = self.encoder(inp, training, enc_padding_mask)  # (batch_size, inp_seq_len, d_model)
        
        # Výstup dekodéru
        dec_output, attention_weights = self.decoder(
            tar, enc_output, training, look_ahead_mask, dec_padding_mask)
        
        # Konečný výstup
        final_output = self.final_layer(dec_output)  # (batch_size, tar_seq_len, target_vocab_size)
        
        return final_output, attention_weights

# Vytvoření jednoduchého příkladu transformeru
def create_transformer_example():
    # Parametry modelu
    num_layers = 2
    d_model = 128
    num_heads = 8
    dff = 512
    input_vocab_size = 8000
    target_vocab_size = 8000
    pe_input = 100
    pe_target = 100
    
    # Vytvoření modelu transformeru
    transformer = Transformer(num_layers, d_model, num_heads, dff,
                              input_vocab_size, target_vocab_size, 
                              pe_input, pe_target, rate=0.1)
    
    # Vytvoření vzorových vstupů
    inp = tf.random.uniform((2, 20), dtype=tf.int64, minval=0, maxval=200)
    tar = tf.random.uniform((2, 15), dtype=tf.int64, minval=0, maxval=200)
    
    # Dopředný průchod
    output, attention_weights = transformer(inp, tar, training=False)
    
    print(f"Tvar vstupu: {inp.shape}")
    print(f"Tvar cíle: {tar.shape}")
    print(f"Tvar výstupu: {output.shape}")
    print(f"Počet matic vah pozornosti: {len(attention_weights)}")
    
    # Výpis shrnutí modelu
    print("\nShrnutí modelu transformeru:")
    transformer.summary()
```

## Předtrénované modely transformerů

Jednou z klíčových výhod architektury transformerů je schopnost předtrénování na velkých datasetech a následného doladění pro konkrétní úlohy. Populární předtrénované modely transformerů zahrnují:

1. **BERT** (Bidirectional Encoder Representations from Transformers)
2. **GPT** (Generative Pre-trained Transformer)
3. **RoBERTa** (Robustly Optimized BERT Approach)
4. **T5** (Text-to-Text Transfer Transformer)

Implementujme jednoduchý příklad použití předtrénovaného modelu BERT pro klasifikaci textu:

```python
# Import potřebných knihoven
from transformers import BertTokenizer, TFBertForSequenceClassification
import tensorflow as tf
import numpy as np

def bert_example():
    # Načtení předtrénovaného tokenizeru a modelu
    tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
    model = TFBertForSequenceClassification.from_pretrained('bert-base-uncased')
    
    # Vzorové texty
    texts = [
        "Tento film se mi opravdu líbil!",
        "Služby byly hrozné a už se nevrátím.",
        "Toto je neutrální tvrzení o počasí."
    ]
    
    # Tokenizace textů
    encoded_inputs = tokenizer(texts, padding=True, truncation=True, 
                               return_tensors="tf", max_length=128)
    
    # Provedení predikce
    outputs = model(encoded_inputs)
    logits = outputs.logits
    
    # Převod logitů na pravděpodobnosti
    probabilities = tf.nn.softmax(logits, axis=1)
    
    # Výpis výsledků
    for i, text in enumerate(texts):
        print(f"Text: {text}")
        print(f"Pravděpodobnosti: {probabilities[i].numpy()}")
        print("---")
```

## Omezení a výzvy

Navzdory svým pozoruhodným úspěchům čelí transformery několika výzvám:

1. **Výpočetní složitost**: Výpočet pozornosti má kvadratickou složitost (O(n²)) s délkou sekvence, což omezuje jejich použití s dlouhými sekvencemi
2. **Požadavky na trénovací data**: Typicky potřebují velké množství dat
3. **Interpretovatelnost**: Porozumění tomu, co se děje uvnitř transformerů, může být náročné
4. **Využití paměti**: Transformery mohou být paměťově náročné, zejména pro dlouhé sekvence
5. **Omezení pozičního kódování**: Základní poziční kódování nemusí být dostatečné pro velmi dlouhé sekvence

Výzkumníci nadále pracují na řešení těchto omezení pomocí technik jako:
- Řídké mechanismy pozornosti
- Efektivní varianty transformerů (Linformer, Reformer, BigBird)
- Vylepšené metody pozičního kódování

```python
# Příklad toho, jak se výpočetní složitost zvyšuje s délkou sekvence
def compute_attention_complexity(seq_lengths):
```

## Shrnutí

Transformery zásadně změnily prostředí hlubokého učení, zvláště v oblasti zpracování přirozeného jazyka, zavedením výkonné architektury založené na self-attention:

1. **Architektura**: Transformery používají strukturu enkodér-dekodér postavenou na mechanismech self-attention místo rekurence nebo konvoluce.

2. **Self-Attention**: Klíčová inovace umožňující transformerům modelovat vztahy mezi všemi pozicemi v sekvenci přímo, bez ohledu na jejich vzdálenost.

3. **Multi-Head Attention**: Umožňuje modelu zaměřit se na informace z různých reprezentačních podprostorů, zachycující různé aspekty vstupu.

4. **Poziční kódování**: Protože transformery zpracovávají všechny tokeny současně, poziční kódování poskytuje klíčové informace o pozicích tokenů.

5. **Paralelizace**: Na rozdíl od RNN mohou transformery zpracovávat sekvence paralelně, což zrychluje a zefektivňuje trénink.

6. **Transfer learning**: Předtrénované modely transformerů mohou být doladěny pro různé navazující úlohy s relativně malým množstvím úlohově specifických dat.

7. **Aplikace**: Transformery vynikají v mnoha úlohách zpracování přirozeného jazyka a byly rozšířeny do oblastí počítačového vidění, multimodálního učení a posilovaného učení.

8. **Omezení**: Navzdory své síle čelí transformery výzvám s výpočetní složitostí, využitím paměti a zpracováním velmi dlouhých sekvencí.

Architektura transformerů vedla k pozoruhodným pokrokům ve schopnostech umělé inteligence a nadále se vyvíjí s novými variantami a optimalizacemi. Pochopení tohoto základu je klíčové pro práci s moderními systémy hlubokého učení.
