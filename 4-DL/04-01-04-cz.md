## Úvod

Trénovací proces je srdcem hlubokého učení. Je to způsob, jakým se neuronové sítě učí z dat, upravují své parametry a nakonec vytvářejí přesné předpovědi. Toto umožňují dvě klíčové komponenty:

1. **Dopředné šíření**: Proces předávání vstupních dat sítí pro generování předpovědí
2. **Zpětné šíření**: Proces výpočtu gradientů a aktualizace vah pro zlepšení předpovědí

Tento dokument podrobně zkoumá tyto procesy s praktickými příklady v Pythonu pro upevnění porozumění.

## Trénovací cyklus neuronové sítě

Na vysoké úrovni zahrnuje trénink neuronové sítě tyto kroky:

1. Inicializace sítě s náhodnými váhami
2. Pro určený počet epoch:
   - Provedení dopředného šíření pro získání předpovědí
   - Výpočet ztráty (chyby) mezi předpověďmi a skutečnými cíli
   - Provedení zpětného šíření pro výpočet gradientů
   - Aktualizace vah pomocí optimalizačního algoritmu
   - Vyhodnocení výkonu na validačních datech

```python
# Pseudokód pro trénovací cyklus neuronové sítě
def train_network(model, train_data, train_targets, epochs, learning_rate):
    for epoch in range(epochs):
        # Dopředné šíření
        predictions = model.forward(train_data)
        
        # Výpočet ztráty
        loss = calculate_loss(predictions, train_targets)
        
        # Zpětné šíření
        gradients = model.backward(train_targets)
        
        # Aktualizace vah
        model.update_weights(gradients, learning_rate)
        
        # Zobrazení postupu
        print(f"Epocha {epoch+1}/{epochs}, Ztráta: {loss}")
```

Nyní se podíváme hlouběji na jednotlivé komponenty.

## Dopředné šíření

Dopředné šíření (nebo dopředný průchod) je proces předávání vstupních dat přes neuronovou síť k získání výstupních předpovědí. Data tečou od vstupní vrstvy přes skryté vrstvy až do výstupní vrstvy.

### Matematická reprezentace

Pro jednoduchou dopřednou neuronovou síť:

1. Pro každou vrstvu *l* (začínáme od vstupní vrstvy):
   - Výpočet váženého součtu: z^(l) = w^(l) * a^(l-1) + b^(l)
   - Aplikace aktivační funkce: a^(l) = f(z^(l))

Kde:
- z^(l) je vážený součet pro vrstvu l
- w^(l) je matice vah pro vrstvu l
- a^(l-1) je aktivace z předchozí vrstvy
- b^(l) je vektor biasů pro vrstvu l
- f je aktivační funkce

### Implementace dopředného šíření

Zde je implementace dopředného šíření v Pythonu pro jednoduchou neuronovou síť:

```python
import numpy as np

class SimpleNeuralNetwork:
    def __init__(self, input_size, hidden_size, output_size):
        # Inicializace vah a biasů malými náhodnými hodnotami
        self.W1 = np.random.randn(input_size, hidden_size) * 0.01
        self.b1 = np.zeros((1, hidden_size))
        self.W2 = np.random.randn(hidden_size, output_size) * 0.01
        self.b2 = np.zeros((1, output_size))
        
    def sigmoid(self, x):
        return 1 / (1 + np.exp(-x))
    
    def relu(self, x):
        return np.maximum(0, x)
        
    def forward(self, X):
        # Uložení hodnot pro zpětné šíření
        self.X = X
        
        # První vrstva
        self.Z1 = np.dot(X, self.W1) + self.b1
        self.A1 = self.relu(self.Z1)
        
        # Výstupní vrstva
        self.Z2 = np.dot(self.A1, self.W2) + self.b2
        self.A2 = self.sigmoid(self.Z2)
        
        return self.A2
```

## Výpočet ztráty

Po dopředném šíření potřebujeme kvantifikovat, jak daleko jsou naše předpovědi od skutečných cílů. K tomu slouží ztrátová funkce.

### Běžné ztrátové funkce

1. **Střední kvadratická chyba (MSE)**: Používá se pro regresní problémy
   - MSE = (1/n) * Σ(y_pred - y_true)²

2. **Binární křížová entropie**: Používá se pro binární klasifikaci
   - BCE = -(1/n) * Σ[y_true * log(y_pred) + (1 - y_true) * log(1 - y_pred)]

3. **Kategorická křížová entropie**: Používá se pro multi-třídní klasifikaci
   - CCE = -(1/n) * Σ[Σ(y_true * log(y_pred))]

### Implementace ztrátových funkcí

```python
def mean_squared_error(y_pred, y_true):
    return np.mean(np.square(y_pred - y_true))

def binary_cross_entropy(y_pred, y_true):
    epsilon = 1e-15  # Malá konstanta pro prevenci log(0)
    y_pred = np.clip(y_pred, epsilon, 1 - epsilon)  # Oříznutí hodnot pro prevenci numerických problémů
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

def categorical_cross_entropy(y_pred, y_true):
    epsilon = 1e-15
    y_pred = np.clip(y_pred, epsilon, 1 - epsilon)
    return -np.mean(np.sum(y_true * np.log(y_pred), axis=1))
```

## Zpětné šíření

Zpětné šíření (nebo backpropagation) je algoritmus používaný k výpočtu gradientů ztrátové funkce vzhledem k vahám a biasům sítě. Tyto informace jsou pak použity k aktualizaci parametrů pro minimalizaci ztráty.

### Řetězové pravidlo v neuronových sítích

Zpětné šíření silně spoléhá na řetězové pravidlo z kalkulu, které nám umožňuje vypočítat derivaci vnořených funkcí. V neuronové síti potřebujeme najít:

∂Loss/∂W = (∂Loss/∂A) * (∂A/∂Z) * (∂Z/∂W)

Kde:
- ∂Loss/∂W je gradient ztráty vzhledem k vahám
- ∂Loss/∂A je gradient ztráty vzhledem k aktivacím
- ∂A/∂Z je derivace aktivační funkce
- ∂Z/∂W je gradient váženého součtu vzhledem k vahám

### Výpočet gradientů

Pro každou vrstvu, začínáme od výstupní vrstvy a pohybujeme se zpět:

1. Výpočet chyby na výstupní vrstvě:
   - δ^(L) = ∂Loss/∂A^(L) * f'(Z^(L))

2. Šíření chyby zpět pro každou předchozí vrstvu:
   - δ^(l) = (δ^(l+1) * W^(l+1)) * f'(Z^(l))

3. Výpočet gradientů pro váhy a biasy:
   - ∂Loss/∂W^(l) = A^(l-1) * δ^(l)
   - ∂Loss/∂b^(l) = δ^(l)

### Implementace zpětného šíření

Pokračujeme s naší třídou SimpleNeuralNetwork:

```python
def backward(self, y_true):
    m = y_true.shape[0]  # Počet vzorků
    
    # Gradient ztráty vzhledem k výstupu
    dZ2 = self.A2 - y_true
    
    # Gradienty pro druhou vrstvu
    dW2 = (1/m) * np.dot(self.A1.T, dZ2)
    db2 = (1/m) * np.sum(dZ2, axis=0, keepdims=True)
    
    # Gradient pro první vrstvu
    dZ1 = np.dot(dZ2, self.W2.T) * (self.A1 > 0)  # Derivace ReLU
    
    # Gradienty pro první vrstvu
    dW1 = (1/m) * np.dot(self.X.T, dZ1)
    db1 = (1/m) * np.sum(dZ1, axis=0, keepdims=True)
    
    # Uložení gradientů
    self.gradients = {
        'dW1': dW1, 'db1': db1,
        'dW2': dW2, 'db2': db2
    }
    
    return self.gradients
```

## Gradientní sestup

Jakmile máme gradienty, použijeme optimalizační algoritmus k aktualizaci vah a biasů. Nejzákladnějším algoritmem je gradientní sestup.

```python
def update_params(self, learning_rate):
    # Aktualizace vah a biasů pomocí vypočítaných gradientů
    self.W1 -= learning_rate * self.gradients['dW1']
    self.b1 -= learning_rate * self.gradients['db1']
    self.W2 -= learning_rate * self.gradients['dW2']
    self.b2 -= learning_rate * self.gradients['db2']
```

### Varianty gradientního sestupu

1. **Dávkový gradientní sestup**: Používá všechny trénovací vzorky k aktualizaci parametrů
2. **Stochastický gradientní sestup (SGD)**: Používá jeden náhodný vzorek najednou
3. **Mini-dávkový gradientní sestup**: Používá malé náhodné dávky vzorků

### Rychlost učení

Rychlost učení (learning rate) řídí, jak moc upravujeme váhy v každé iteraci:
- Příliš vysoká: Může přestřelit minimum
- Příliš nízká: Může trvat příliš dlouho k dosažení konvergence nebo uvíznout v lokálních minimech

```python
# Implementace decay rychlosti učení
initial_learning_rate = 0.1
decay_rate = 0.01

def learning_rate_schedule(epoch, initial_lr):
    return initial_lr * (1 / (1 + decay_rate * epoch))
```

## Implementace kompletního trénovacího cyklu

### Od základů

Zkombinujme vše a vytvořme kompletní trénovací cyklus:

```python
def train(self, X, y, learning_rate=0.01, epochs=1000, batch_size=32, print_interval=100):
    m = X.shape[0]
    losses = []
    
    for epoch in range(epochs):
        # Implementace mini-dávek
        permutation = np.random.permutation(m)
        X_shuffled = X[permutation]
        y_shuffled = y[permutation]
        
        for i in range(0, m, batch_size):
            X_batch = X_shuffled[i:i+batch_size]
            y_batch = y_shuffled[i:i+batch_size]
            
            # Dopředný průchod
            y_pred = self.forward(X_batch)
            
            # Výpočet ztráty
            loss = binary_cross_entropy(y_pred, y_batch)
            
            # Zpětný průchod
            self.backward(y_batch)
            
            # Aktualizace parametrů
            self.update_params(learning_rate)
        
        # Periodický výpočet ztráty na celém datasetu
        if epoch % print_interval == 0:
            y_pred_full = self.forward(X)
            loss = binary_cross_entropy(y_pred_full, y)
            losses.append(loss)
            print(f"Epocha {epoch}/{epochs}, Ztráta: {loss:.4f}")
    
    return losses
```

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset

# Definice modelu
class SimpleNN(nn.Module):
    def __init__(self, input_size):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(input_size, 64)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(64, 1)
        self.sigmoid = nn.Sigmoid()

        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        x = self.sigmoid(x)
        return x

# Konverze dat do PyTorch tenzorů
X_tensor = torch.FloatTensor(X_train)
y_tensor = torch.FloatTensor(y_train)
dataset = TensorDataset(X_tensor, y_tensor)
dataloader = DataLoader(dataset, batch_size=32, shuffle=True)

# Inicializace modelu, ztrátové funkce, optimalizéru
model = SimpleNN(input_size)
criterion = nn.BCELoss()
optimizer = optim.Adam(model.parameters(), lr=0.01)

# Trénovací cyklus
for epoch in range(100):
    for X_batch, y_batch in dataloader:
        # Dopředný průchod
        y_pred = model(X_batch)
        
        # Výpočet ztráty
        loss = criterion(y_pred, y_batch)
        
        # Zpětný průchod a optimalizace
        optimizer.zero_grad()  # Vynulování gradientů
        loss.backward()        # Výpočet gradientů
        optimizer.step()       # Aktualizace vah
    
    print(f"Epocha {epoch+1}/100, Ztráta: {loss.item():.4f}")
```

## Výzvy při trénování

### Mizející a explodující gradienty

Jak se gradienty šíří zpět přes mnoho vrstev, mohou se stát extrémně malými (mizejícími) nebo extrémně velkými (explodujícími).

Řešení:
- Správná inicializace vah
- Dávková normalizace (batch normalization)
- Přeskakované spojení (skip connections, jako v ResNet)
- Ořezávání gradientů (gradient clipping)
- Používání aktivačních funkcí jako ReLU

```python
# Příklad ořezávání gradientů v PyTorch
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

# Příklad dávkové normalizace v TensorFlow
model = keras.Sequential([
    keras.layers.Dense(64),
    keras.layers.BatchNormalization(),
    keras.layers.Activation('relu')
])
```

### Lokální minima a sedlové body

Gradientní sestup může uvíznout v lokálních minimech nebo sedlových bodech.

Řešení:
- Použití optimalizérů založených na momentu
- Plány rychlosti učení
- Stochastické přístupy jako přidání šumu

## Kompletní příklad: Trénování neuronové sítě od základů

Pojďme dát vše dohromady v kompletním příkladu:

```python
import numpy as np
import matplotlib.pyplot as plt

class NeuralNetwork:
    def __init__(self, layers_dims):
        """
        Inicializace neuronové sítě s určenými dimenzemi vrstev.
        
        Args:
            layers_dims: Seznam obsahující dimenze každé vrstvy
        """
        self.parameters = {}
        self.L = len(layers_dims) - 1  # Počet vrstev (kromě vstupní)
        
        # Inicializace vah a biasů
        for l in range(1, len(layers_dims)):
            self.parameters[f"W{l}"] = np.random.randn(layers_dims[l], layers_dims[l-1]) * 0.01
            self.parameters[f"b{l}"] = np.zeros((layers_dims[l], 1))
            
    def sigmoid(self, Z):
        return 1 / (1 + np.exp(-Z))
    
    def relu(self, Z):
        return np.maximum(0, Z)
    
    def sigmoid_backward(self, dA, Z):
        s = self.sigmoid(Z)
        return dA * s * (1 - s)
    
    def relu_backward(self, dA, Z):
        dZ = np.array(dA, copy=True)
        dZ[Z <= 0] = 0
        return dZ
    
    def forward_propagation(self, X):
        """
        Implementace dopředného šíření
        
        Args:
            X: Vstupní data, tvar (příznaky, m_vzorků)
        
        Returns:
            AL: Výstupní aktivace
            caches: Seznam cache pro zpětné šíření
        """
        caches = []
        A = X
        
        # Pro L-1 vrstev použijeme ReLU
        for l in range(1, self.L):
            A_prev = A
            W = self.parameters[f"W{l}"]
            b = self.parameters[f"b{l}"]
            
            Z = np.dot(W, A_prev) + b
            A = self.relu(Z)
            
            cache = (A_prev, W, b, Z)
            caches.append(cache)
        
        # Pro výstupní vrstvu použijeme sigmoid
        W = self.parameters[f"W{self.L}"]
        b = self.parameters[f"b{self.L}"]
        Z = np.dot(W, A) + b
        A = self.sigmoid(Z)
        
        cache = (A, W, b, Z)
        caches.append(cache)
        
        return A, caches
    
    def compute_cost(self, AL, Y):
        """
        Výpočet ztráty binární křížové entropie
        
        Args:
            AL: Výstup dopředného šíření
            Y: Skutečné štítky
            
        Returns:
            cost: Ztráta binární křížové entropie
        """
        m = Y.shape[1]
        
        # Prevence numerických problémů s malými hodnotami
        epsilon = 1e-15
        AL = np.clip(AL, epsilon, 1 - epsilon)
        
        # Ztráta binární křížové entropie
        cost = -(1/m) * np.sum(Y * np.log(AL) + (1 - Y) * np.log(1 - AL))
        return cost
    
    def backward_propagation(self, AL, Y, caches):
        """
        Implementace zpětného šíření
        
        Args:
            AL: Výstupní aktivace
            Y: Skutečné štítky
            caches: Cache z dopředného šíření
            
        Returns:
            grads: Slovník s gradienty
        """
        grads = {}
        m = Y.shape[1]
        Y = Y.reshape(AL.shape)
        
        # Inicializace zpětného šíření
        dAL = - (np.divide(Y, AL) - np.divide(1 - Y, 1 - AL))
        
        # Získání cache pro poslední vrstvu
        current_cache = caches[self.L - 1]
        A_prev, W, b, Z = current_cache
        
        # Gradienty pro výstupní vrstvu (sigmoid)
        dZ = self.sigmoid_backward(dAL, Z)
        grads[f"dW{self.L}"] = (1/m) * np.dot(dZ, A_prev.T)
        grads[f"db{self.L}"] = (1/m) * np.sum(dZ, axis=1, keepdims=True)
        dA_prev = np.dot(W.T, dZ)
        
        # Zpětné šíření přes skryté vrstvy
        for l in reversed(range(1, self.L)):
            current_cache = caches[l-1]
            A_prev, W, b, Z = current_cache
            
            # Gradienty pro ReLU vrstvy
            dZ = self.relu_backward(dA_prev, Z)
            grads[f"dW{l}"] = (1/m) * np.dot(dZ, A_prev.T)
            grads[f"db{l}"] = (1/m) * np.sum(dZ, axis=1, keepdims=True)
            dA_prev = np.dot(W.T, dZ)
        
        return grads
    
    def update_parameters(self, grads, learning_rate):
        """
        Aktualizace parametrů pomocí gradientního sestupu
        
        Args:
            grads: Slovník s gradienty
            learning_rate: Rychlost učení
        """
        for l in range(1, self.L + 1):
            self.parameters[f"W{l}"] -= learning_rate * grads[f"dW{l}"]
            self.parameters[f"b{l}"] -= learning_rate * grads[f"db{l}"]
    
    def train(self, X, Y, learning_rate=0.01, num_iterations=3000, print_cost=True, print_interval=100):
        """
        Trénování neuronové sítě
        
        Args:
            X: Vstupní data (příznaky, m_vzorků)
            Y: Skutečné štítky (1, m_vzorků)
            learning_rate: Rychlost učení
            num_iterations: Počet iterací
            print_cost: Zda tisknout ztrátu během trénování
            
        Returns:
            costs: Seznam ztrát během trénování
        """
        costs = []
        
        for i in range(num_iterations):
            # Dopředné šíření
            AL, caches = self.forward_propagation(X)
            
            # Výpočet ztráty
            cost = self.compute_cost(AL, Y)
            
            # Zpětné šíření
            grads = self.backward_propagation(AL, Y, caches)
            
            # Aktualizace parametrů
            self.update_parameters(grads, learning_rate)
            
            # Tisk ztráty a uložení
            if print_cost and i % print_interval == 0:
                print(f"Cena po iteraci {i}: {cost}")
                costs.append(cost)
        
        return costs
    
    def predict(self, X):
        """
        Použití natrénovaného modelu k předpovědi
        
        Args:
            X: Vstupní data
            
        Returns:
            predictions: Předpovědi modelu (0 nebo 1)
        """
        # Dopředné šíření
        A, _ = self.forward_propagation(X)
        
        # Převod pravděpodobností na předpovědi
        predictions = np.round(A)
        return predictions

# Generování umělých dat pro binární klasifikaci
def generate_data(n_samples=1000):
    np.random.seed(42)
    
    # Generování dvou shluků bodů
    X1 = np.random.randn(2, int(n_samples/2)) * 0.5 + np.array([[-2], [2]])
    X2 = np.random.randn(2, int(n_samples/2)) * 0.5 + np.array([[2], [-2]])
    X = np.concatenate((X1, X2), axis=1)
    
    # Vytvoření štítků
    Y = np.zeros((1, n_samples))
    Y[0, :int(n_samples/2)] = 1
    
    # Zamíchání dat
    permutation = np.random.permutation(n_samples)
    X = X[:, permutation]
    Y = Y[:, permutation]
    
    return X, Y

def plot_decision_boundary(model, X, Y):

    x_min, x_max = X[0, :].min() - 1, X[0, :].max() + 1
    y_min, y_max = X[1, :].min() - 1, X[1, :].max() + 1
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                         np.arange(y_min, y_max, h))
    
    # Vytvoření předpovědí pro každý bod v mřížce
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()].T)
    Z = Z.reshape(xx.shape)
    
    # Vykreslení rozhodovací hranice
    plt.figure(figsize=(10, 8))
    plt.contourf(xx, yy, Z, alpha=0.8, cmap=plt.cm.RdBu)
    
    # Vykreslení trénovacích bodů
    plt.scatter(X[0, :], X[1, :], c=Y.ravel(), edgecolors='k', cmap=plt.cm.RdBu)
    plt.title('Rozhodovací hranice')
    plt.xlabel('Příznak 1')
    plt.ylabel('Příznak 2')

# Vykreslení rozhodovací hranice
```
