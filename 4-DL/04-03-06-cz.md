## 1. Úvod do učení bez učitele

Učení bez učitele (self-supervised learning) je podmnožinou učení bez dozoru, kde data sama poskytují dohled. Namísto použití člověkem anotovaných štítků self-supervised metody automaticky generují signály dohledu ze samotných dat, čímž vytvářejí "pseudo-štítky". Tento přístup umožňuje modelům naučit se užitečné reprezentace z neoznačených dat, což je zvláště cenné, když jsou označená data vzácná.

Klíčovou myšlenkou je vytvoření pomocné úlohy, která vyžaduje pochopení struktury dat k jejímu vyřešení, což vede k smysluplným reprezentacím, které lze přenést do následných úloh.

- Slouží jako vynikající předtrénování před doladěním na konkrétních úlohách

## 2. Kontrastivní učení

Kontrastivní učení je populární přístup učení bez učitele, který se učí reprezentace porovnáváním podobných a nepodobných párů vzorků. Základní myšlenkou je přibližovat reprezentace podobných vzorků k sobě, zatímco oddalovat nepodobné vzorky od sebe v prostoru embedingů.

```python
# Zjednodušená implementace kontrastivní ztráty
class ContrastiveLoss(nn.Module):
    def __init__(self, temperature=0.5):
        super(ContrastiveLoss, self).__init__()
        self.temperature = temperature
        
    def forward(self, features):
        # features: [2*batch_size, feature_dim]
        # První polovina a druhá polovina jsou pozitivní páry
        
        batch_size = features.shape[0] // 2
        labels = torch.cat([torch.arange(batch_size) for i in range(2)], dim=0)
        labels = (labels.unsqueeze(0) == labels.unsqueeze(1)).float()
        labels = labels.to(features.device)
        
        features = F.normalize(features, dim=1)
        
        # Výpočet matice podobnosti
        similarity_matrix = torch.matmul(features, features.T) / self.temperature
        
        # Maskování diagonály (podobnost se sebou samým)
        mask = torch.eye(labels.shape[0], dtype=torch.bool).to(features.device)
        labels = labels[~mask].view(labels.shape[0], -1)
        similarity_matrix = similarity_matrix[~mask].view(similarity_matrix.shape[0], -1)
        
        # Výpočet pozitivních a negativních párů
        positives = similarity_matrix[labels.bool()].view(labels.shape[0], -1)
        negatives = similarity_matrix[~labels.bool()].view(similarity_matrix.shape[0], -1)
        
        # Výpočet InfoNCE ztráty
        logits = torch.cat([positives, negatives], dim=1)
        labels = torch.zeros(logits.shape[0], dtype=torch.long).to(features.device)
        
        return F.cross_entropy(logits, labels)

# Příklad použití
contrastive_loss = ContrastiveLoss()
```

Klíčové metody kontrastivního učení zahrnují:

1. **SimCLR**: Používá augmentaci dat k vytvoření pozitivních párů ze stejného obrázku
2. **MoCo**: Udržuje frontu negativních vzorků aktualizovanou pomocí momentových aktualizací
3. **BYOL**: Nevyžaduje negativní vzorky, používá paradigma učitel-žák
4. **SwAV**: Kombinuje kontrastivní učení s klastrováním

## 3. Úlohy maskovaných predikcí

Maskované predikce zahrnují skrytí částí vstupu a trénování modelu k předpovědi těchto skrytých částí. To nutí model pochopit úplný kontext a strukturu dat.

```python
# Jednoduchý příklad maskovaného modelování obrazu
class MaskedImageModeling(nn.Module):
    def __init__(self, encoder, decoder):
        super(MaskedImageModeling, self).__init__()
        self.encoder = encoder
        self.decoder = decoder
        
    def forward(self, x, mask):
        # x: [batch_size, channels, height, width]
        # mask: [batch_size, height, width] - booleovská maska (True = maskováno)
        
        # Vytvoření maskovaného vstupu (nahrazení maskovaných tokenů nulami nebo naučitelným tokenem)
        masked_x = x.clone()
        for i in range(x.size(0)):
            masked_x[i, :, mask[i]] = 0  # Vynulování maskovaných pozic
        
        # Kódování maskovaného vstupu
        features = self.encoder(masked_x)
        
        # Dekódování pro rekonstrukci originálu
        reconstructed = self.decoder(features)
        
        # Výpočet ztráty pouze na maskovaných pozicích
        loss = F.mse_loss(reconstructed[mask], x[mask])
        
        return loss, reconstructed

# Příklad použití s náhodnými daty
def mask_generator(batch_size, h, w, mask_ratio=0.75):
    """Generování náhodných masek pro obrázky s daným poměrem"""
    mask = torch.zeros(batch_size, h, w, dtype=torch.bool)
    for i in range(batch_size):
        num_patches = h * w
        num_mask = int(mask_ratio * num_patches)
        mask_idx = torch.randperm(num_patches)[:num_mask]
        mask[i].view(-1)[mask_idx] = True
    return mask
```

Populární přístupy maskovaných predikcí:

1. **BERT**: Maskuje náhodné tokeny v textu pro porozumění jazyku
2. **MAE (Masked Autoencoders)**: Maskuje náhodné oblasti v obrázcích
3. **Data2vec**: Aplikuje maskované predikce napříč různými modalitami

## 4. Auto-regresivní učení

Auto-regresivní učení zahrnuje predikci dalšího prvku v sekvenci na základě předchozích prvků, čímž vytváří úlohu učení bez učitele ze sekvenčních dat.

```python
# Jednoduchý auto-regresivní model pro text
class SimpleAutoregressive(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim):
        super(SimpleAutoregressive, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)
        
    def forward(self, x):
        # x: [batch_size, seq_len]
        embedded = self.embedding(x)
        lstm_out, _ = self.lstm(embedded)
        logits = self.fc(lstm_out)
        return logits
    
    def generate(self, start_tokens, max_len, temperature=1.0):
        self.eval()
        current_tokens = start_tokens.clone()
        
        with torch.no_grad():
            for _ in range(max_len):
                logits = self.forward(current_tokens)
                next_token_logits = logits[:, -1, :] / temperature
                next_token = torch.multinomial(F.softmax(next_token_logits, dim=-1), 1)
                current_tokens = torch.cat([current_tokens, next_token], dim=1)
                
        return current_tokens

# Příklad použití
vocab_size = 10000
embed_dim = 256
hidden_dim = 512
model = SimpleAutoregressive(vocab_size, embed_dim, hidden_dim)

# Příklad trénovací smyčky
def train_step(model, optimizer, data, target):
    optimizer.zero_grad()
    output = model(data)
    # Posun cílů o jeden pro predikci dalšího tokenu
    loss = F.cross_entropy(output[:, :-1, :].reshape(-1, vocab_size), 
                          target[:, 1:].reshape(-1))
    loss.backward()
    optimizer.step()
    return loss.item()
```

Auto-regresivní modely jako GPT se učí silné reprezentace prostřednictvím predikce následujícího tokenu, což se ukázalo jako efektivní pro jazykové úlohy.

## 5. Metody auto-enkódování

Metody auto-enkódování se učí užitečné reprezentace kódováním vstupu do latentního prostoru a následnou rekonstrukcí původního vstupu z této reprezentace.

```python
class SimpleAutoencoder(nn.Module):
    def __init__(self, input_dim, latent_dim):
        super(SimpleAutoencoder, self).__init__()
        
        # Enkodér
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.ReLU(),
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, latent_dim)
        )
        
        # Dekodér
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 512),
            nn.ReLU(),
            nn.Linear(512, input_dim),
            nn.Sigmoid()  # Pro normalizované vstupy
        )
    
    def forward(self, x):
        # Kódování
        z = self.encoder(x)
        # Dekódování
        reconstructed = self.decoder(z)
        return reconstructed, z
    
# Příklad tréninku
def train_autoencoder(model, dataloader, epochs=10):
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    criterion = nn.MSELoss()
    
    for epoch in range(epochs):
        total_loss = 0
        for batch in dataloader:
            # Zploštění obrázků
            x = batch[0].view(batch[0].size(0), -1)
            
            # Dopředný průchod
            reconstructed, _ = model(x)
            
            # Výpočet ztráty
            loss = criterion(reconstructed, x)
            
            # Zpětný průchod
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
            
        print(f"Epocha {epoch+1}, Ztráta: {total_loss/len(dataloader):.6f}")
```

Varianty zahrnují:
- **Denoising Autoencoders**: Učí se odstranit šum z poškozených vstupů
- **Variační Autoenkodéry (VAEs)**: Učí se pravděpodobnostní reprezentace
- **Sparse Autoencoders**: Vynucují řídkost v latentním prostoru

## 6. Implementace SimCLR

SimCLR (Simple Framework for Contrastive Learning of Representations) je jednou z nejvlivnějších metod kontrastivního učení. Implementujme zjednodušenou verzi:

```python
# Funkce augmentace dat pro SimCLR
from torchvision import transforms

class SimCLRDataTransform:
    def __init__(self, base_transform):
        self.base_transform = base_transform
        
    def __call__(self, x):
        # Generování dvou různě augmentovaných pohledů stejného obrázku
        return self.base_transform(x), self.base_transform(x)

# Nastavení augmentace dat pro SimCLR
color_jitter = transforms.ColorJitter(0.8, 0.8, 0.8, 0.2)
data_transforms = transforms.Compose([
    transforms.RandomResizedCrop(96),
    transforms.RandomHorizontalFlip(),
    transforms.RandomApply([color_jitter], p=0.8),
    transforms.RandomGrayscale(p=0.2),
    transforms.ToTensor(),
    transforms.Normalize([0.5, 0.5, 0.5], [0.5, 0.5, 0.5])
])

# SimCLR model
class SimCLR(nn.Module):
    def __init__(self, backbone, projection_dim=128):
        super(SimCLR, self).__init__()
        # Enkodérová síť (např. ResNet)
        self.backbone = backbone
        # Získání výstupní dimenze páteřní sítě
        out_dim = self.backbone.fc.in_features
        # Nahrazení poslední plně propojené vrstvy
        self.backbone.fc = nn.Identity()
        # Projekční hlava
        self.projection_head = nn.Sequential(
            nn.Linear(out_dim, 512),
            nn.ReLU(),
            nn.Linear(512, projection_dim)
        )
    
    def forward(self, x):
        # Získání reprezentací z páteřní sítě
        h = self.backbone(x)
        # Projekce do kontrastivního prostoru
        z = self.projection_head(h)
        return z

# Trénovací smyčka
def train_simclr(model, train_loader, optimizer, temperature=0.5, epochs=100):
    criterion = ContrastiveLoss(temperature=temperature)
    
    for epoch in range(epochs):
        total_loss = 0
        for images, _ in train_loader:
            # Získání dvou augmentovaných pohledů
            x_i = images[0].cuda()
            x_j = images[1].cuda()
            
            # Dopředný průchod modelem
            z_i = model(x_i)
            z_j = model(x_j)
            
            # Spojení reprezentací
            representations = torch.cat([z_i, z_j], dim=0)
            
            # Výpočet ztráty
            loss = criterion(representations)
            
            # Zpětný průchod a optimalizace
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
        
        print(f"Epocha {epoch+1}/{epochs}, Ztráta: {total_loss/len(train_loader):.6f}")
```

SimCLR dosahuje silného výkonu na různých následných úlohách, což demonstruje sílu kontrastivního učení v nastavení učení bez učitele.

## 7. BERT a maskované jazykové modelování

BERT (Bidirectional Encoder Representations from Transformers) používá maskované jazykové modelování jako svou primární úlohu učení bez učitele. Zde je zjednodušená implementace:

```python
# Import knihoven
from transformers import BertTokenizer, BertForMaskedLM, AdamW
import torch

# Načtení předtrénovaného tokenizátoru
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

# Definice funkce maskovaného jazykového modelování
def create_masked_input(text, mask_probability=0.15):
    # Tokenizace vstupního textu
    tokens = tokenizer.tokenize(text)
    token_ids = tokenizer.convert_tokens_to_ids(tokens)
    
    # Vytvoření kopie token_ids pro uložení maskovaných ID pro cíle
    masked_token_ids = token_ids.copy()
    
    # Procházení tokenů a maskování s pravděpodobností
    for i in range(len(token_ids)):
        if np.random.rand() < mask_probability:
            # 80 % času nahradit [MASK]
            if np.random.rand() < 0.8:
                token_ids[i] = tokenizer.mask_token_id
            # 10 % času nahradit náhodným slovem
            elif np.random.rand() < 0.5:
                token_ids[i] = np.random.randint(0, tokenizer.vocab_size)
            # 10 % času ponechat původní slovo
    
    # Převod na tenzory
    input_ids = torch.tensor([token_ids])
    labels = torch.tensor([masked_token_ids])
    
    # Vytvoření masky pozornosti
    attention_mask = torch.ones_like(input_ids)
    
    return {
        'input_ids': input_ids,
        'attention_mask': attention_mask,
        'labels': labels
    }

# Načtení předtrénovaného BERT modelu pro maskované jazykové modelování
model = BertForMaskedLM.from_pretrained('bert-base-uncased')

# Příklad textu
text = "Rychlá hnědá liška skáče přes líného psa."
inputs = create_masked_input(text)

# Smyčka pro dolaďování (zjednodušená)
optimizer = AdamW(model.parameters(), lr=5e-5)

def train_step(model, inputs, optimizer):
    model.train()
    optimizer.zero_grad()
    outputs = model(**inputs)
    loss = outputs.loss
    loss.backward()
    optimizer.step()
    return loss.item()

# Příklad použití
loss = train_step(model, inputs, optimizer)
print(f"Ztráta: {loss}")

# Použití BERT pro inference
def predict_masked_tokens(text):
    # Tokenizace vstupu, nahrazení některých slov [MASK]
    inputs = tokenizer(text, return_tensors="pt")
    
    # Získání predikcí modelu
    with torch.no_grad():
        outputs = model(**inputs)
    
    # Získání předpovězených tokenů
    predictions = torch.argmax(outputs.logits, dim=-1)
    predicted_tokens = tokenizer.convert_ids_to_tokens(predictions[0].tolist())
    
    return predicted_tokens

# Příklad s maskovaným vstupem
masked_text = "Rychlá [MASK] liška [MASK] přes líného psa."
predictions = predict_masked_tokens(masked_text)
print(predictions)
```

Obousměrné učení reprezentací v BERT bylo revoluční pro NLP úlohy, protože umožňuje modelům chápat kontext z obou směrů.

## 8. Učení bez učitele v počítačovém vidění

Počítačové vidění má mnoho kreativních úloh učení bez učitele. Implementujme jednoduchou úlohu predikce rotace jako příklad:

```python
# Úloha predikce rotace
class RotationPrediction(nn.Module):
    def __init__(self, backbone):
        super(RotationPrediction, self).__init__()
        self.backbone = backbone
        # Modifikace poslední vrstvy pro předpověď 4 úhlů rotace (0, 90, 180, 270 stupňů)
        out_features = backbone.fc.in_features
        self.backbone.fc = nn.Identity()
        self.rotation_classifier = nn.Linear(out_features, 4)
    
    def forward(self, x):
        features = self.backbone(x)
        rotation_logits = self.rotation_classifier(features)
        return rotation_logits

# Vytvoření rotovaných obrázků
def rotate_images(images):
    batch_size = images.shape[0]
    rotated_images = []
    rotation_labels = []
    
    for i in range(batch_size):
        for rotation in range(4):  # 0, 1, 2, 3 (0°, 90°, 180°, 270°)
            rotated_img = torch.rot90(images[i], rotation, dims=[1, 2])
            rotated_images.append(rotated_img)
            rotation_labels.append(rotation)
    
    rotated_images = torch.stack(rotated_images)
    rotation_labels = torch.tensor(rotation_labels)
    
    return rotated_images, rotation_labels

# Trénovací funkce
def train_rotation_prediction(model, train_loader, optimizer, epochs=100):
    criterion = nn.CrossEntropyLoss()
    
    for epoch in range(epochs):
        total_loss = 0
        correct = 0
        total = 0
        
        for images, _ in train_loader:
            images = images.cuda()
            
            # Vytvoření rotovaných verzí
            rotated_images, rotation_labels = rotate_images(images)
            rotated_images = rotated_images.cuda()
            rotation_labels = rotation_labels.cuda()
            
            # Dopředný průchod
            outputs = model(rotated_images)
            
            # Výpočet ztráty
            loss = criterion(outputs, rotation_labels)
            
            # Zpětný průchod a optimalizace
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            # Výpočet přesnosti
            _, predicted = torch.max(outputs.data, 1)
            total += rotation_labels.size(0)
            correct += (predicted == rotation_labels).sum().item()
            
            total_loss += loss.item()
        
        accuracy = 100 * correct / total
        print(f"Epocha {epoch+1}/{epochs}, Ztráta: {total_loss/len(train_loader):.4f}, "
              f"Přesnost: {accuracy:.2f}%")
```

## 9. Učení bez učitele při zpracování zvuku

Zvuková data jsou další oblastí, kde učení bez učitele ukázalo slibné výsledky:

```python
# Jednoduché učení zvukových reprezentací s kontrastivním učením
import torchaudio

class AudioEncoder(nn.Module):
    def __init__(self):
        super(AudioEncoder, self).__init__()
        # CNN pro zpracování zvuku
        self.conv1 = nn.Conv1d(1, 64, kernel_size=10, stride=5)
        self.conv2 = nn.Conv1d(64, 128, kernel_size=8, stride=4)
        self.conv3 = nn.Conv1d(128, 256, kernel_size=4, stride=2)
        self.conv4 = nn.Conv1d(256, 512, kernel_size=4, stride=2)
        self.flatten = nn.Flatten()
        self.projection = nn.Linear(512, 128)
    
    def forward(self, x):
        # x: [batch_size, 1, time]
        x = F.relu(self.conv1(x))
        x = F.relu(self.conv2(x))
        x = F.relu(self.conv3(x))
        x = F.relu(self.conv4(x))
        # Globální pooling
        x = torch.mean(x, dim=2)
        # Projekce do prostoru embedingů
        embedding = self.projection(x)
        return F.normalize(embedding, dim=1)

# Techniky augmentace zvuku
class AudioAugmentation:
    def __init__(self):
        self.time_mask = torchaudio.transforms.TimeMasking(time_mask_param=100)
        self.freq_mask = torchaudio.transforms.FrequencyMasking(freq_mask_param=27)
    
    def __call__(self, audio):
        # Nejprve převod na mel spektrogram
        mel_spec = torchaudio.transforms.MelSpectrogram()(audio)
        
        # Aplikace náhodných augmentací
        if np.random.random() > 0.5:
            mel_spec = self.time_mask(mel_spec)
        if np.random.random() > 0.5:
            mel_spec = self.freq_mask(mel_spec)
            
        # Převod zpět na vlnovou formu (aproximace)
        inverse_mel = torchaudio.transforms.InverseMelScale()(mel_spec)
        waveform = torchaudio.transforms.GriffinLim()(inverse_mel)
        
        return waveform

# Příklad použití zvukového enkodéru
def train_audio_encoder():
    # Definice modelu a optimalizátoru
    encoder = AudioEncoder().cuda()
    optimizer = torch.optim.Adam(encoder.parameters(), lr=3e-4)
    
    # Definice kontrastivní ztráty
    contrastive_loss = ContrastiveLoss(temperature=0.1)
    
    # Augmentace zvuku
    augmentation = AudioAugmentation()
    
    # Načtení příkladových zvukových dat (zástupný kód)
```

## 10. Shrnutí

Učení bez učitele představuje mocné paradigma v hlubokém učení, které využívá strukturu neoznačených dat k vytvoření úloh s učitelem. Klíčové výhody zahrnují:

1. **Snížení závislosti na štítcích**: Snižuje závislost na nákladných ručních anotacích
2. **Škálování s daty**: Může efektivně využít masivní neoznačené datasety
3. **Transfer learning**: Vytváří robustní reprezentace, které se dobře přenášejí do následných úloh
4. **Všestrannost**: Aplikovatelné napříč doménami (vidění, jazyk, zvuk atd.)

Hlavní přístupy v učení bez učitele:

- **Kontrastivní učení**: SimCLR, MoCo, BYOL - učí se porovnáváním podobných a nepodobných příkladů
- **Maskované predikce**: BERT, MAE - učí se předpovídáním maskovaného obsahu
- **Auto-regresivní modelování**: GPT - předpovídá další prvky v sekvencích
- **Auto-enkódování**: Rekonstruuje vstupy z komprimovaných reprezentací
- **Pomocné úlohy**: Predikce rotace, skládačky - učí se řešením uměle vytvořených úloh

Učení bez učitele nadále posouvá stav techniky v mnoha doménách, zmenšuje mezeru mezi učením s učitelem a bez učitele a nabízí datově efektivnější řešení.

S postupem výzkumu vidíme rostoucí konvergenci technik napříč modalitami, přičemž rámce jako data2vec ukazují, že podobné přístupy učení bez učitele mohou fungovat napříč doménami vidění, řeči a textu.
