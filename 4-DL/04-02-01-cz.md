## Úvod do konvolučních neuronových sítí

Konvoluční neuronové sítě (CNN) jsou specializované modely hlubokého učení navržené pro zpracování dat s mřížkovou topologií, jako jsou například obrázky. Způsobily revoluci v počítačovém vidění dosažením špičkových výsledků v úlohách jako je klasifikace obrazů, detekce objektů a rozpoznávání obličejů.

Na rozdíl od tradičních neuronových sítí, CNN efektivně zpracovávají vysokou dimenzionalitu obrazových dat pomocí:

- **Sdílení parametrů**: Stejný filtr je aplikován na celý obrázek
- **Lokální konektivita**: Neurony se spojují pouze s malou oblastí vstupu
- **Invariance vůči posunu**: Schopnost rozpoznat vzory bez ohledu na jejich pozici

Tyto vlastnosti činí CNN obzvláště vhodnými pro zpracování vizuálních dat, protože mohou automaticky a adaptivně učit prostorové hierarchie příznaků.

## Základní komponenty architektury CNN

Typická architektura CNN se skládá z několika klíčových komponent uspořádaných sekvenčně:

1. **Vstupní vrstva**: Přijímá surové pixely obrazu
2. **Konvoluční vrstvy**: Aplikují filtry pro detekci příznaků
3. **Aktivační vrstvy**: Zavádějí nelinearitu (typicky ReLU)
4. **Pooling vrstvy**: Redukují prostorové dimenze a počet parametrů
5. **Plně propojené vrstvy**: Propojují všechny neurony s předchozí vrstvou
6. **Výstupní vrstva**: Produkuje finální predikci

Každá komponenta hraje klíčovou roli ve schopnosti sítě učit se a efektivně extrahovat příznaky z obrazů.


## Konvoluční vrstvy

Konvoluční vrstvy tvoří jádro CNN. Provádějí operaci konvoluce, která zahrnuje posun filtru (jádra) přes vstupní obraz za účelem vytvoření mapy příznaků. Tento proces umožňuje síti detekovat lokální vzory jako hrany, textury a složitější příznaky.

Klíčové parametry konvolučních vrstev zahrnují:

- **Filtry (jádra)**: Malé matice, které detekují specifické příznaky
- **Velikost jádra**: Rozměry filtru (např. 3×3, 5×5)
- **Krok (stride)**: Velikost kroku při posunu filtru
- **Padding**: Přidání pixelů kolem vstupu pro kontrolu rozměrů výstupu
- **Aktivační funkce**: Typicky ReLU, zavádí nelinearitu

```python
# Ukázka fungování konvoluce
def visualize_convolution():
    # Vytvoření vzorového 6x6 obrázku (stupně šedi)
    image = np.zeros((6, 6))
    image[1:5, 1:5] = 1  # Vytvoření bílého čtverce uprostřed
    
    # Definice jednoduchého 3x3 jádra pro detekci hran
    kernel = np.array([[-1, -1, -1],
                       [-1,  8, -1],
                       [-1, -1, -1]])
    
    # Ruční provedení konvoluce
    output = np.zeros((4, 4))
    for i in range(4):
        for j in range(4):
            # Extrakce aktuálního okna z obrázku
            window = image[i:i+3, j:j+3]
            # Aplikace jádra
            output[i, j] = np.sum(window * kernel)
    
    # Vizualizace procesu
    fig, axes = plt.subplots(1, 3, figsize=(12, 4))
    
    axes[0].imshow(image, cmap='gray')
    axes[0].set_title('Původní obrázek')
    axes[0].axis('off')
    
    axes[1].imshow(kernel, cmap='gray')
    axes[1].set_title('Jádro (detekce hran)')
    axes[1].axis('off')
    
    axes[2].imshow(output, cmap='gray')
    axes[2].set_title('Výsledek konvoluce')
    axes[2].axis('off')
    
    plt.tight_layout()
    plt.show()
    
    # Nyní s TensorFlow
    tf_image = tf.constant(image.reshape(1, 6, 6, 1), dtype=tf.float32)
    tf_kernel = tf.constant(kernel.reshape(3, 3, 1, 1), dtype=tf.float32)
    tf_output = tf.nn.conv2d(tf_image, tf_kernel, strides=1, padding='VALID')
    
    print("Výsledek konvoluce v TensorFlow:")
    print(tf_output.numpy().reshape(4, 4))

visualize_convolution()

# Vytvoření konvoluční vrstvy v Keras
conv_layer = layers.Conv2D(
    filters=32,           # Počet filtrů
    kernel_size=(3, 3),   # Velikost každého filtru
    strides=(1, 1),       # Velikost kroku při posunu filtru
    padding='same',       # 'same' zachovává dimenze, 'valid' redukuje dimenze
    activation='relu',    # Aktivační funkce aplikovaná po konvoluci
    input_shape=(28, 28, 1)  # Vstupní tvar: výška, šířka, kanály
)

# Vytvoření konvoluční vrstvy v PyTorch
import torch
import torch.nn as nn

torch_conv_layer = nn.Conv2d(
    in_channels=1,        # Počet vstupních kanálů
    out_channels=32,      # Počet filtrů
    kernel_size=3,        # Velikost každého filtru
    stride=1,             # Velikost kroku při posunu filtru
    padding=1             # Padding (1 znamená 'same' v tomto případě)
)
```

## Pooling vrstvy

Pooling vrstvy redukují prostorové dimenze (šířku a výšku) vstupního objemu, čímž snižují počet parametrů a výpočetní zatížení sítě. Také pomáhají síti být robustnější vůči variacím v pozici příznaků.

Běžné typy poolingu zahrnují:

- **Max Pooling**: Bere maximální hodnotu v každém okně
- **Average Pooling**: Bere průměrnou hodnotu v každém okně
- **Global Pooling**: Redukuje každou mapu příznaků na jednu hodnotu

```python
# Ukázka fungování max poolingu
def visualize_pooling():
    # Vytvoření vzorové 4x4 mapy příznaků
    feature_map = np.array([
        [1, 2, 5, 6],
        [3, 4, 7, 8],
        [9, 10, 13, 14],
        [11, 12, 15, 16]
    ])
    
    # Ruční provedení 2x2 max poolingu
    pooled = np.zeros((2, 2))
    for i in range(0, 4, 2):
        for j in range(0, 4, 2):
            pooled[i//2, j//2] = np.max(feature_map[i:i+2, j:j+2])
    
    # Vizualizace procesu
    fig, axes = plt.subplots(1, 2, figsize=(10, 5))
    
    axes[0].imshow(feature_map, cmap='viridis')
    axes[0].set_title('Původní mapa příznaků')
    # Přidání mřížky
    for i in range(5):
        axes[0].axhline(i - 0.5, color='black', linestyle='-', linewidth=1)
        axes[0].axvline(i - 0.5, color='black', linestyle='-', linewidth=1)
    # Přidání textových popisků
    for i in range(4):
        for j in range(4):
            axes[0].text(j, i, str(feature_map[i, j]), ha='center', va='center', color='white')
    
    axes[1].imshow(pooled, cmap='viridis')
    axes[1].set_title('Po max poolingu (2x2)')
    # Přidání mřížky
    for i in range(3):
        axes[1].axhline(i - 0.5, color='black', linestyle='-', linewidth=1)
        axes[1].axvline(i - 0.5, color='black', linestyle='-', linewidth=1)
    # Přidání textových popisků
    for i in range(2):
        for j in range(2):
            axes[1].text(j, i, str(int(pooled[i, j])), ha='center', va='center', color='white')
    
    # Nakreslení šipek mezi odpovídajícími oblastmi
    plt.tight_layout()
    plt.show()
    
    # Nyní s TensorFlow
    tf_feature_map = tf.constant(feature_map.reshape(1, 4, 4, 1), dtype=tf.float32)
    tf_pooled = tf.nn.max_pool2d(tf_feature_map, ksize=2, strides=2, padding='VALID')
    
    print("Výsledek max poolingu v TensorFlow:")
    print(tf_pooled.numpy().reshape(2, 2))

visualize_pooling()

# Vytvoření pooling vrstev v Keras
max_pool_layer = layers.MaxPooling2D(pool_size=(2, 2), strides=2)
avg_pool_layer = layers.AveragePooling2D(pool_size=(2, 2), strides=2)
global_avg_pool_layer = layers.GlobalAveragePooling2D()

# Vytvoření pooling vrstev v PyTorch
torch_max_pool = nn.MaxPool2d(kernel_size=2, stride=2)
torch_avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)
torch_global_avg_pool = nn.AdaptiveAvgPool2d(1)  # Globální average pooling
```

## Plně propojené vrstvy

Poté, co několik konvolučních a pooling vrstev extrahovalo příznaky ze vstupu, jsou typicky přidány plně propojené (dense) vrstvy pro provedení uvažování na vysoké úrovni. Tyto vrstvy propojují každý neuron v jedné vrstvě s každým neuronem v následující vrstvě.

Plně propojené vrstvy:
- Zplošťují prostorové příznaky do 1D vektoru
- Učí se nelineární kombinace extrahovaných příznaků
- Mapují příznaky na výstupní třídy

```python
# Zploštění a plně propojené vrstvy v CNN
def illustrate_fc_layers():
    # Vytvoření jednoduchého příkladu
    feature_map = np.random.rand(1, 4, 4, 3)  # Velikost dávky, výška, šířka, kanály
    print(f"Tvar mapy příznaků: {feature_map.shape}")
    
    # Zploštění v TensorFlow/Keras
    flatten_layer = layers.Flatten()
    flattened = flatten_layer(feature_map)
    print(f"Po zploštění: {flattened.shape}")
    
    # Přidání plně propojených vrstev
    dense1 = layers.Dense(32, activation='relu')
    dense_output = dense1(flattened)
    print(f"Po dense vrstvě: {dense_output.shape}")
    
    # Výstupní vrstva
    output_layer = layers.Dense(10, activation='softmax')
    final_output = output_layer(dense_output)
    print(f"Tvar finálního výstupu: {final_output.shape}")
    
    # Vizualizace transformace
    plt.figure(figsize=(10, 4))
    plt.subplot(1, 5, 1)
    plt.imshow(feature_map[0, :, :, 0], cmap='viridis')
    plt.title('Mapa příznaků\n(Kanál 1)')
    plt.axis('off')
    
    plt.subplot(1, 5, 2)
    plt.imshow(feature_map[0, :, :, 1], cmap='viridis')
    plt.title('Mapa příznaků\n(Kanál 2)')
    plt.axis('off')
    
    plt.subplot(1, 5, 3)
    plt.imshow(feature_map[0, :, :, 2], cmap='viridis')
    plt.title('Mapa příznaků\n(Kanál 3)')
    plt.axis('off')
    
    plt.subplot(1, 5, 4)
    plt.bar(range(flattened.shape[1]), flattened.numpy().flatten())
    plt.title('Zploštěné\npříznaky')
    plt.axis('off')
    
    plt.subplot(1, 5, 5)
    plt.bar(range(final_output.shape[1]), final_output.numpy().flatten())
    plt.title('Výstupní\npravděpodobnosti')
    plt.axis('off')
    
    plt.tight_layout()
    plt.show()

illustrate_fc_layers()
```

## Vytvoření jednoduché CNN v Pythonu

Pojďme vytvořit kompletní CNN pro klasifikaci obrazu pomocí datasetu MNIST ručně psaných číslic:

```python
# Načtení a předzpracování MNIST datasetu
(train_images, train_labels), (test_images, test_labels) = mnist.load_data()

# Normalizace hodnot pixelů do rozsahu 0 až 1
train_images = train_images.reshape((60000, 28, 28, 1)).astype('float32') / 255
test_images = test_images.reshape((10000, 28, 28, 1)).astype('float32') / 255

# Převedení štítků na one-hot kódované vektory
train_labels = to_categorical(train_labels)
test_labels = to_categorical(test_labels)

# Vytvoření CNN modelu
def build_cnn_model():
    model = models.Sequential()
    
    # První konvoluční vrstva
    model.add(layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)))
    model.add(layers.MaxPooling2D((2, 2)))
    
    # Druhá konvoluční vrstva
    model.add(layers.Conv2D(64, (3, 3), activation='relu'))
    model.add(layers.MaxPooling2D((2, 2)))
    
    # Třetí konvoluční vrstva
    model.add(layers.Conv2D(64, (3, 3), activation='relu'))
    
    # Zploštění a přidání plně propojených vrstev
    model.add(layers.Flatten())
    model.add(layers.Dense(64, activation='relu'))
    model.add(layers.Dense(10, activation='softmax'))
    
    return model

# Vytvoření a kompilace modelu
model = build_cnn_model()
model.compile(optimizer='adam',
              loss='categorical_crossentropy',
              metrics=['accuracy'])

# Zobrazení shrnutí modelu
model.summary()

# Trénování modelu
history = model.fit(train_images, train_labels, 
                    epochs=5, 
                    batch_size=64,
                    validation_split=0.2)

# Vyhodnocení modelu
test_loss, test_acc = model.evaluate(test_images, test_labels)
print(f"Testovací přesnost: {test_acc:.4f}")

# Vizualizace historie trénování
def plot_history(history):
    plt.figure(figsize=(12, 5))
    
    # Vykreslení přesnosti
    plt.subplot(1, 2, 1)
    plt.plot(history.history['accuracy'], label='Trénovací přesnost')
    plt.plot(history.history['val_accuracy'], label='Validační přesnost')
    plt.xlabel('Epocha')
    plt.ylabel('Přesnost')
    plt.title('Trénovací a validační přesnost')
    plt.legend()
    
    # Vykreslení ztráty
    plt.subplot(1, 2, 2)
    plt.plot(history.history['loss'], label='Trénovací ztráta')
    plt.plot(history.history['val_loss'], label='Validační ztráta')
    plt.xlabel('Epocha')
    plt.ylabel('Ztráta')
    plt.title('Trénovací a validační ztráta')
    plt.legend()
    
    plt.tight_layout()
    plt.show()

plot_history(history)

# Provedení predikcí
predictions = model.predict(test_images)

# Zobrazení některých predikcí
def show_predictions(images, true_labels, predictions, n=5):
    plt.figure(figsize=(12, 4))
    for i in range(n):
        plt.subplot(1, n, i+1)
        plt.imshow(images[i].reshape(28, 28), cmap='gray')
        predicted_label = np.argmax(predictions[i])
        true_label = np.argmax(true_labels[i])
        plt.title(f"Pravé: {true_label}\nPred: {predicted_label}")
        plt.axis('off')
    plt.tight_layout()
    plt.show()

show_predictions(test_images, test_labels, predictions)
```

## Běžné architektury CNN

Během let bylo vyvinuto mnoho vlivných architektur CNN, z nichž každá přinesla inovace, které posunuly tuto oblast vpřed:

1. **LeNet-5** (1998): Průkopnická architektura CNN od Yanna LeCuna, používaná pro rozpoznávání číslic.
2. **AlexNet** (2012): Hlubší než LeNet, vyhrála soutěž ImageNet s významným náskokem, znamenala začátek éry hlubokého učení.
3. **VGG** (2014): Používala velmi malé filtry (3×3) s mnoha vrstvami, demonstrující důležitost hloubky.
4. **GoogLeNet/Inception** (2014): Zavedla inception moduly, používala 1×1 konvoluce ke snížení počtu parametrů.
5. **ResNet** (2015): Zavedla reziduální (skip) spojení umožňující trénování velmi hlubokých sítí (až 152 vrstev).
6. **MobileNet** (2017): Navržena pro mobilní zařízení, používá hloubkově oddělitelné konvoluce.
7. **EfficientNet** (2019): Využívá hledání neuronové architektury a škálování k optimalizaci hloubky, šířky a rozlišení.

Podívejme se, jak používat předtrénované modely z těchto architektur:

```python
# Použití předtrénovaných architektur CNN s Keras
from tensorflow.keras.applications import VGG16, ResNet50, MobileNetV2

# Načtení předtrénovaných modelů (bez top vrstev)
vgg_model = VGG16(weights='imagenet', include_top=False, input_shape=(224, 224, 3))
resnet_model = ResNet50(weights='imagenet', include_top=False, input_shape=(224, 224, 3))
mobilenet_model = MobileNetV2(weights='imagenet', include_top=False, input_shape=(224, 224, 3))

# Porovnání velikostí modelů
def compare_models(models):
    for name, model in models:
        # Počítání parametrů
        total_params = model.count_params()
        trainable_params = sum([K.count_params(w) for w in model.trainable_weights])
        
        print(f"{name}:")
        print(f"  Celkový počet parametrů: {total_params:,}")
        print(f"  Počet trénovatelných parametrů: {trainable_params:,}")
        print(f"  Počet vrstev: {len(model.layers)}")
        print()

# Import K
from tensorflow.keras import backend as K

compare_models([
    ('VGG16', vgg_model),
    ('ResNet50', resnet_model),
    ('MobileNetV2', mobilenet_model)
])

# Příklad transfer learningu s ResNet50
def create_transfer_learning_model():
    # Načtení předtrénovaného ResNet50 bez top vrstev
    base_model = ResNet50(weights='imagenet', include_top=False, input_shape=(224, 224, 3))
    
    # Zmrazení základního modelu
    base_model.trainable = False
    
    # Přidání vlastních top vrstev
    model = models.Sequential([
        base_model,
        layers.GlobalAveragePooling2D(),
        layers.Dense(256, activation='relu'),
        layers.Dropout(0.5),
        layers.Dense(10, activation='softmax')  # 10 tříd
    ])
    
    model.compile(
        optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    return model

# Vytvoření modelu s transfer learningem
transfer_model = create_transfer_learning_model()
print("Shrnutí modelu s transfer learningem:")
transfer_model.summary()
```

## Vizualizace příznaků CNN

Porozumění tomu, jaké příznaky se CNN učí, je klíčové pro interpretovatelnost. Můžeme vizualizovat:

1. **Filtry/jádra**: Vzory, které každý filtr hledá
2. **Mapy příznaků**: Výstup každé konvoluční vrstvy
3. **Mapy aktivace tříd**: Oblasti v obraze, které ovlivňují predikci
4. **Vizualizace založené na gradientu**: Které části vstupu maximalizují určité aktivace

```python
# Vizualizace naučených filtrů a map příznaků
def visualize_filters_and_maps():

    plt.suptitle('Prvních 16 filtrů v první konvoluční vrstvě')
    plt.tight_layout()
    plt.subplots_adjust(top=0.9)
    plt.show()
    
    # Načtení a předzpracování ukázkového obrázku
    from tensorflow.keras.preprocessing import image
    from tensorflow.keras.applications.vgg16 import preprocess_input

def generate_class_activation_map(img_array, model, last_conv_layer_name, pred_index=None):
    # Vytvoření modelu, který mapuje vstupní obrázek na aktivace poslední konvoluční vrstvy
    last_conv_layer = model.get_layer(last_conv_layer_name)
    last_conv_output = last_conv_layer.output
    
    # Získání výstupu predikce modelu
    classifier_output = model.output
    
    # Pokud je pred_index zadán, použijte ho, jinak použijte předpovězenou třídu
    if pred_index is None:
        pred_index = tf.argmax(classifier_output[0])
    
    # Toto je gradient předpovězené třídy s ohledem na výstupní mapu příznaků
    grads = K.gradients(classifier_output[:, pred_index], last_conv_output)[0]
    
    # Toto je vektor, kde každá položka je střední intenzita gradientu přes kanál
    pooled_grads = K.mean(grads, axis=(0, 1, 2))
    
    # Vytvoření funkce pro přístup k těmto hodnotám
    iterate = K.function([model.input], [pooled_grads, last_conv_output[0]])
    
    # Volání funkce s naším obrázkem
    pooled_grads_value, conv_layer_output_value = iterate([img_array])
    
    # Vynásobení každého kanálu jeho důležitostí
    for i in range(pooled_grads_value.shape[0]):
        conv_layer_output_value[:, :, i] *= pooled_grads_value[i]
    
    # Kanálový průměr výsledné mapy příznaků je naše tepelná mapa
    heatmap = np.mean(conv_layer_output_value, axis=-1)
    
    # Normalizace tepelné mapy
    heatmap = np.maximum(heatmap, 0)
    heatmap /= np.max(heatmap) + 1e-10
    
    return heatmap
```

## Osvědčené postupy při návrhu CNN

Při návrhu architektur CNN zvažte tyto osvědčené postupy:

1. **Začněte jednoduše**: Začněte jednoduchou architekturou a postupně zvyšujte složitost.
2. **Používejte osvědčené architektury**: Pro mnoho úloh funguje lépe adaptace existujících architektur než vytváření nových.
3. **Datová augmentace**: Zvyšte efektivní velikost trénovací sady aplikací transformací.
4. **Batch normalizace**: Přidejte batch normalizaci po konvolučních vrstvách pro stabilizaci tréninku.
5. **Dropout**: Používejte dropout v plně propojených vrstvách pro prevenci přeučení.
6. **Globální pooling**: Používejte global average pooling před plně propojenými vrstvami pro snížení počtu parametrů.
7. **Plánování učební rychlosti**: Upravujte rychlost učení v průběhu tréninku.
8. **Regularizace vah**: Aplikujte L1/L2 regularizaci pro prevenci přeučení.

```python
# Osvědčené postupy implementované v modelu CNN
def build_best_practice_cnn(input_shape=(224, 224, 3), num_classes=10):
    model = models.Sequential()
    
    # První konvoluční blok s batch normalizací
    model.add(layers.Conv2D(32, (3, 3), padding='same', input_shape=input_shape))
    model.add(layers.BatchNormalization())
    model.add(layers.Activation('relu'))
    model.add(layers.MaxPooling2D((2, 2)))
    
    # Druhý konvoluční blok
    model.add(layers.Conv2D(64, (3, 3), padding='same'))
    model.add(layers.BatchNormalization())
    model.add(layers.Activation('relu'))
    model.add(layers.MaxPooling2D((2, 2)))
    
    # Třetí konvoluční blok
    model.add(layers.Conv2D(128, (3, 3), padding='same'))
    model.add(layers.BatchNormalization())
    model.add(layers.Activation('relu'))
    model.add(layers.MaxPooling2D((2, 2)))
    
    # Globální average pooling a plně propojené vrstvy
    model.add(layers.GlobalAveragePooling2D())
    model.add(layers.Dense(256, kernel_regularizer=tf.keras.regularizers.l2(0.001)))
    model.add(layers.BatchNormalization())
    model.add(layers.Activation('relu'))
    model.add(layers.Dropout(0.5))
    model.add(layers.Dense(num_classes, activation='softmax'))
    
    # Použití optimalizovaného optimalizéru s plánováním učební rychlosti
    lr_schedule = tf.keras.optimizers.schedules.ExponentialDecay(
        initial_learning_rate=0.001,
        decay_steps=10000,
        decay_rate=0.9)
    optimizer = tf.keras.optimizers.Adam(learning_rate=lr_schedule)
    
    model.compile(
        optimizer=optimizer,
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    return model
```

## Shrnutí

Konvoluční neuronové sítě (CNN) způsobily revoluci v počítačovém vidění využitím specializovaných architektonických komponent navržených pro zpracování obrazu:

- **Konvoluční vrstvy** detekují příznaky pomocí filtrů posunujících se přes vstupy
- **Pooling vrstvy** redukují prostorové dimenze při zachování důležitých příznaků
- **Plně propojené vrstvy** provádějí uvažování na vysoké úrovni pro finální klasifikace

Klíčové silné stránky CNN zahrnují:
- Sdílení parametrů a lokální konektivitu, které drasticky snižují počet parametrů ve srovnání s plně propojenými sítěmi
- Hierarchické učení příznaků, od jednoduchých nízkoúrovňových příznaků až po složité vysokoúrovňové příznaky
- Invarianci vůči posunu, umožňující rozpoznávání vzorů bez ohledu na jejich pozici v obraze

Osvědčené postupy pro návrh efektivních CNN zahrnují:
- Začínat s osvědčenými architekturami a přizpůsobovat je vašim potřebám
- Používání technik jako datová augmentace, batch normalizace a dropout
- Pečlivé řízení hloubky, velikostí filtrů a celkové architektury sítě

Díky správnému návrhu a tréninku mohou CNN dosáhnout pozoruhodných výkonů v široké škále úloh vizuálního vnímání, od jednoduché klasifikace obrazů až po složité úlohy jako detekce objektů, segmentace a generování.

Tato oblast se neustále vyvíjí s inovacemi v návrhu architektur, trénovacích technikách a aplikacích napříč různými doménami mimo počítačové vidění, jako je rozpoznávání řeči, zpracování přirozeného jazyka a posilované učení.
