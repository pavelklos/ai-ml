## Úvod do autoenkodérů

Autoenkodéry jsou typem neuronové sítě, která se učí efektivně komprimovat a kódovat data, a poté rekonstruovat původní data z kódované reprezentace. Jedná se o modely učení bez učitele, které se snaží naučit reprezentaci (kódování) pro sadu dat, typicky za účelem snížení dimenzionality nebo učení příznaků.

Základním principem autoenkodérů je přinutit síť k učení komprimované reprezentace omezením počtu neuronů ve skrytých vrstvách. To vytváří úzké hrdlo, které nutí síť stanovit priority, které aspekty vstupních dat jsou nejdůležitější pro rekonstrukci.

## Základní architektura autoenkodérů

Autoenkodér se skládá ze dvou hlavních částí:
1. **Enkodér**: Komprimuje vstup do reprezentace v latentním prostoru
2. **Dekodér**: Rekonstruuje vstup z reprezentace v latentním prostoru

Nejjednodušší forma má tři vrstvy:
- Vstupní vrstva
- Skrytá vrstva (úzké hrdlo)
- Výstupní vrstva (se stejnými dimenzemi jako vstup)

Síť je trénována tak, aby minimalizovala rozdíl mezi vstupem a rekonstruovaným výstupem, čímž se efektivně učí kopírovat svůj vstup na výstup s omezením v podobě průchodu úzkým hrdlem.

## Typy autoenkodérů

Autoenkodéry existují v různých formách, každá je navržena pro specifické účely:

1. **Základní autoenkodér**: Základní architektura s plně propojenými vrstvami.
2. **Denoising autoenkodér**: Trénovaný na rekonstrukci čistých dat z zašuměného vstupu.
3. **Sparse autoenkodér**: Používá penalizaci řídkosti pro omezení skrytých reprezentací.
4. **Variační autoenkodér (VAE)**: Učí se pravděpodobnostní reprezentaci latentního prostoru.
5. **Konvoluční autoenkodér**: Používá konvoluční vrstvy pro úlohy zpracování obrazů.
6. **Kontraktivní autoenkodér**: Přidává penalizaci, aby byl model robustní vůči malým variacím.

Výběr typu závisí na řešeném problému a charakteristikách dat.

## Implementace jednoduchého autoenkodéru

Implementujme jednoduchý autoenkodér pomocí TensorFlow/Keras s datovou sadou MNIST:

```python
# Načtení MNIST datové sady
from tensorflow.keras.datasets import mnist

(x_train, _), (x_test, _) = mnist.load_data()

# Normalizace dat
x_train = x_train.astype('float32') / 255.0
x_test = x_test.astype('float32') / 255.0

# Zploštění obrázků
x_train = x_train.reshape((len(x_train), np.prod(x_train.shape[1:])))
x_test = x_test.reshape((len(x_test), np.prod(x_test.shape[1:])))

# Definice dimenzí
input_dim = x_train.shape[1]  # 784 pro MNIST
encoding_dim = 32  # Velikost úzkého hrdla

# Sestavení modelu autoenkodéru
def build_simple_autoencoder(input_dim, encoding_dim):
    # Definice enkodéru
    encoder = tf.keras.Sequential([
        layers.Dense(128, activation='relu', input_shape=(input_dim,)),
        layers.Dense(encoding_dim, activation='relu')
    ])
    
    # Definice dekodéru
    decoder = tf.keras.Sequential([
        layers.Dense(128, activation='relu', input_shape=(encoding_dim,)),
        layers.Dense(input_dim, activation='sigmoid')
    ])
    
    # Definice autoenkodéru
    autoencoder = tf.keras.Sequential([
        encoder,
        decoder
    ])
    
    # Kompilace autoenkodéru
    autoencoder.compile(optimizer='adam', loss='binary_crossentropy')
    
    return autoencoder, encoder, decoder

# Vytvoření a trénování modelu
```

## Denoising autoenkodéry

Denoising autoenkodéry jsou trénovány k rekonstrukci čistých dat ze zašuměných vstupů. Tím se naučené reprezentace stávají robustnějšími a pomáhají modelu naučit se smysluplné příznaky spíše než jen kopírování vstupu.

```python
# Přidání šumu do obrázků
def add_noise(x, noise_factor=0.5):
    x_noisy = x + noise_factor * np.random.normal(loc=0.0, scale=1.0, size=x.shape)
    # Oříznutí obrázků, aby byly mezi 0 a 1
    x_noisy = np.clip(x_noisy, 0.0, 1.0)
    return x_noisy

# Vytvoření zašuměných verzí dat
x_train_noisy = add_noise(x_train)
x_test_noisy = add_noise(x_test)

# Sestavení denoising autoenkodéru
def build_denoising_autoencoder(input_dim, encoding_dim):
    # Definice enkodéru
    encoder = tf.keras.Sequential([
        layers.Dense(128, activation='relu', input_shape=(input_dim,)),
        layers.Dense(encoding_dim, activation='relu')
    ])
    
    # Definice dekodéru
    decoder = tf.keras.Sequential([
        layers.Dense(128, activation='relu', input_shape=(encoding_dim,)),
        layers.Dense(input_dim, activation='sigmoid')
    ])
    
    # Definice autoenkodéru
    autoencoder = tf.keras.Sequential([
        encoder,
        decoder
    ])
    
    # Kompilace autoenkodéru

    return autoencoder
```

## Variační autoenkodéry (VAEs)

Variační autoenkodéry jsou pravděpodobnostní verzí autoenkodérů. Namísto kódování vstupu jako jediného bodu v latentním prostoru, VAE ho kóduje jako distribuci nad latentním prostorem. To umožňuje generovat nová data vzorkováním z naučených distribucí.

```python
# Sestavení variačního autoenkodéru (VAE)
from tensorflow.keras import backend as K
from tensorflow.keras.losses import binary_crossentropy

# Definice architektury VAE
def build_vae(input_dim, latent_dim):
    # Enkodér
    inputs = layers.Input(shape=(input_dim,))
    x = layers.Dense(512, activation='relu')(inputs)
    x = layers.Dense(256, activation='relu')(x)
    
    # Střední hodnota a logaritmus rozptylu pro latentní distribuci
    z_mean = layers.Dense(latent_dim)(x)
    z_log_var = layers.Dense(latent_dim)(x)
    
    # Vzorkovací vrstva
    def sampling(args):
        z_mean, z_log_var = args
        batch = K.shape(z_mean)[0]
        dim = K.int_shape(z_mean)[1]
        # Reparametrizační trik
        epsilon = K.random_normal(shape=(batch, dim))
        return z_mean + K.exp(0.5 * z_log_var) * epsilon
    
    z = layers.Lambda(sampling)([z_mean, z_log_var])
    
    # Dekodér
    decoder_h = layers.Dense(256, activation='relu')
    decoder_h2 = layers.Dense(512, activation='relu')
    decoder_output = layers.Dense(input_dim, activation='sigmoid')
    
    h_decoded = decoder_h(z)
    h2_decoded = decoder_h2(h_decoded)
    outputs = decoder_output(h2_decoded)
    
    # Definice VAE modelu
    vae = models.Model(inputs, outputs)
    
    # Definice enkodérového modelu
    encoder = models.Model(inputs, [z_mean, z_log_var, z])
    
    # Definice dekodérového modelu
    decoder_input = layers.Input(shape=(latent_dim,))
    h_decoded_decoder = decoder_h(decoder_input)
    h2_decoded_decoder = decoder_h2(h_decoded_decoder)
    outputs_decoder = decoder_output(h2_decoded_decoder)
    decoder = models.Model(decoder_input, outputs_decoder)
    
    # Ztráta VAE
    reconstruction_loss = binary_crossentropy(inputs, outputs) * input_dim
    kl_loss = 1 + z_log_var - K.square(z_mean) - K.exp(z_log_var)
    kl_loss = K.sum(kl_loss, axis=-1)
    kl_loss *= -0.5
    vae_loss = K.mean(reconstruction_loss + kl_loss)
    vae.add_loss(vae_loss)
    
    vae.compile(optimizer='adam')
    
    return vae, encoder, decoder

# Vytvoření VAE modelu
latent_dim = 2  # Použití 2 dimenzí pro vizualizaci
vae, encoder, decoder = build_vae(input_dim, latent_dim)
print(vae.summary())

# Trénování VAE

    x_train, None,
    epochs=20,
    batch_size=128,
    validation_data=(x_test, None)
)

# Generování nových obrázků z latentního prostoru

            figure[i * digit_size: (i + 1) * digit_size,
                   j * digit_size: (j + 1) * digit_size] = digit
    
    plt.figure(figsize=(10, 10))
    plt.imshow(figure, cmap='gray')
    plt.title("VAE generované obrázky z latentního prostoru")
    plt.axis('off')
    plt.show()
```

## Konvoluční autoenkodéry

Konvoluční autoenkodéry aplikují konvoluční vrstvy na architekturu autoenkodéru, což je činí obzvláště efektivními pro obrazová data.

```python
# Načtení a přetvarování MNIST pro konvoluční zpracování
(x_train, _), (x_test, _) = mnist.load_data()
x_train = x_train.astype('float32') / 255.0
x_test = x_test.astype('float32') / 255.0
x_train = x_train.reshape(x_train.shape[0], 28, 28, 1)
x_test = x_test.reshape(x_test.shape[0], 28, 28, 1)

# Sestavení konvolučního autoenkodéru
def build_conv_autoencoder():
    # Enkodér
    encoder = models.Sequential([
        layers.Input(shape=(28, 28, 1)),
        layers.Conv2D(16, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2), padding='same'),
        layers.Conv2D(8, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2), padding='same'),
        layers.Conv2D(8, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2), padding='same')
    ])
    
    # Dekodér
    decoder = models.Sequential([
        layers.Conv2D(8, (3, 3), activation='relu', padding='same'),
        layers.UpSampling2D((2, 2)),
        layers.Conv2D(8, (3, 3), activation='relu', padding='same'),
        layers.UpSampling2D((2, 2)),
        layers.Conv2D(16, (3, 3), activation='relu', padding='same'),
        layers.UpSampling2D((2, 2)),
        layers.Conv2D(1, (3, 3), activation='sigmoid', padding='same')
    ])
    
    # Autoenkodér
    autoencoder = models.Sequential([
        encoder,
        decoder
    ])
    
    autoencoder.compile(optimizer='adam', loss='binary_crossentropy')
    return autoencoder, encoder, decoder

# Vytvoření a trénování konvolučního autoenkodéru
conv_autoencoder, conv_encoder, conv_decoder = build_conv_autoencoder()
print(conv_autoencoder.summary())

# Trénování modelu

    x_train, x_train,
    epochs=10,
    batch_size=256,
    shuffle=True,
    validation_data=(x_test, x_test)
)

# Kódování a dekódování testovacích obrázků
encoded_imgs = conv_encoder.predict(x_test)
decoded_imgs = conv_autoencoder.predict(x_test)

# Zobrazení původních a rekonstruovaných obrázků
```

## Aplikace autoenkodérů

Autoenkodéry mají různé reálné aplikace:

1. **Redukce dimenzionality**: Autoenkodéry se mohou naučit efektivnější kompresi než tradiční metody jako PCA.

2. **Odšumování obrazů**: Denoising autoenkodéry jsou efektivní při odstraňování šumu z obrázků.

3. **Detekce anomálií**: Díky naučení normální distribuce dat mohou autoenkodéry identifikovat anomálie jako vstupy s vysokou chybou rekonstrukce.

4. **Generování obrazů**: VAE a generativní adversariální sítě (GAN) mohou vytvářet nové, realistické obrázky.

5. **Učení příznaků**: Autoenkodéry se mohou naučit smysluplné příznaky z neoznačených dat.

Implementujme příklad aplikace pro detekci anomálií:

```python
# Detekce anomálií pomocí autoenkodérů
from sklearn.metrics import roc_curve, auc

# Trénujme autoenkodér pouze na jedné číslici (např. číslici 8)
(x_train, y_train), (x_test, y_test) = mnist.load_data()

# Normalizace a přetvarování
x_train = x_train.astype('float32') / 255.0
x_test = x_test.astype('float32') / 255.0
x_train = x_train.reshape((len(x_train), np.prod(x_train.shape[1:])))
x_test = x_test.reshape((len(x_test), np.prod(x_test.shape[1:])))

# Filtrujeme, abychom získali pouze číslici 8 pro trénování (ostatní považujeme za anomálie)
normal_digit = 8
x_train_normal = x_train[y_train == normal_digit]
x_test_normal = x_test[y_test == normal_digit]
x_test_anomaly = x_test[y_test != normal_digit]

# Vytvoření a trénování autoenkodéru na normálních datech
autoencoder, _, _ = build_simple_autoencoder(input_dim, encoding_dim)
autoencoder.fit(
    x_train_normal, x_train_normal,
    epochs=20,
    batch_size=128,
    shuffle=True,
    validation_data=(x_test_normal, x_test_normal),
    verbose=0
)

# Výpočet chyby rekonstrukce na testovacích datech
normal_reconstruction = autoencoder.predict(x_test_normal)
anomaly_reconstruction = autoencoder.predict(x_test_anomaly)

# Výpočet MSE pro každý testovací příklad
normal_errors = np.mean(np.square(x_test_normal - normal_reconstruction), axis=1)
anomaly_errors = np.mean(np.square(x_test_anomaly - anomaly_reconstruction), axis=1)

# Vykreslení distribuce chyb
plt.figure(figsize=(10, 6))
plt.hist(normal_errors, bins=50, alpha=0.5, label='Normální (číslice 8)')
plt.hist(anomaly_errors, bins=50, alpha=0.5, label='Anomálie (ostatní číslice)')
plt.title('Chyba rekonstrukce pro normální vs anomální data')
plt.xlabel('Chyba rekonstrukce (MSE)')
plt.ylabel('Počet')
plt.legend()
plt.grid(True)
plt.show()

# Vytvoření popisků a kombinace chyb pro ROC křivku
true_labels = np.concatenate([np.zeros(len(normal_errors)), np.ones(len(anomaly_errors))])
reconstruction_errors = np.concatenate([normal_errors, anomaly_errors])

# Výpočet ROC křivky
fpr, tpr, thresholds = roc_curve(true_labels, reconstruction_errors)
roc_auc = auc(fpr, tpr)

# Vykreslení ROC křivky
plt.figure(figsize=(8, 6))
plt.plot(fpr, tpr, color='darkorange', lw=2, label=f'ROC křivka (plocha = {roc_auc:.2f})')
plt.plot([0, 1], [0, 1], color='navy', lw=2, linestyle='--')
plt.xlim([0.0, 1.0])
plt.ylim([0.0, 1.05])
plt.xlabel('False Positive Rate')
plt.ylabel('True Positive Rate')
plt.title('ROC křivka pro detekci anomálií autoenkodérem')
plt.legend(loc="lower right")
plt.grid(True)
plt.show()

# Nalezení optimálního prahu a provedení predikce
optimal_threshold_idx = np.argmax(tpr - fpr)
optimal_threshold = thresholds[optimal_threshold_idx]
print(f"Optimální práh: {optimal_threshold:.4f}")

# Příklad použití prahu pro detekci anomálií
predictions = (reconstruction_errors > optimal_threshold).astype(int)
accuracy = np.mean(predictions == true_labels)
print(f"Přesnost s optimálním prahem: {accuracy:.4f}")
```

### 2. Sparse autoenkodéry

Tyto autoenkodéry přidávají omezení řídkosti do skrytých vrstev, nutí model naučit se efektivnější reprezentace.

```python
# Sparse autoenkodér s L1 regularizací aktivity
def build_sparse_autoencoder(input_dim, encoding_dim, sparsity_reg=0.001):
    # Enkodér
    inputs = layers.Input(shape=(input_dim,))
    encoded = layers.Dense(128, activation='relu')(inputs)
    encoded = layers.Dense(
        encoding_dim, 
        activation='relu',
        activity_regularizer=tf.keras.regularizers.l1(sparsity_reg)
    )(encoded)
    
    # Dekodér
    decoded = layers.Dense(128, activation='relu')(encoded)
    decoded = layers.Dense(input_dim, activation='sigmoid')(decoded)
    
    # Model autoenkodéru
    autoencoder = models.Model(inputs, decoded)
    
    # Model enkodéru
    encoder = models.Model(inputs, encoded)
    
    # Kompilace
    autoencoder.compile(optimizer='adam', loss='binary_crossentropy')
    
    return autoencoder, encoder

# Vytvoření a trénování sparse autoenkodéru
sparse_autoencoder, sparse_encoder = build_sparse_autoencoder(input_dim, encoding_dim)
```

```python
# Doplňování obrazů pomocí autoenkodérů
def add_block_mask(images, block_size=10):
    # Přidání náhodné masky bloku k obrázkům
    masked_images = images.copy()
    for i in range(len(masked_images)):
        x_start = np.random.randint(0, 28 - block_size)
        y_start = np.random.randint(0, 28 - block_size)
        
        for x in range(x_start, x_start + block_size):
            for y in range(y_start, y_start + block_size):
                masked_images[i, x, y] = 0
                
    return masked_images

# Načtení a přetvarování dat MNIST

x_train = x_train.astype('float32') / 255.0

x_test_masked = add_block_mask(x_test)

# Přetvarování pro síť
```

## Shrnutí

Autoenkodéry jsou všestranné architektury neuronových sítí, které se učí efektivní reprezentace dat prostřednictvím učení bez učitele. Skládají se z enkodéru, který komprimuje vstupní data do reprezentace v latentním prostoru, a dekodéru, který rekonstruuje původní data z této reprezentace.

Klíčové body o autoenkodérech:

1. **Všestranná architektura**: Autoenkodéry existují v mnoha variantách, od jednoduchých plně propojených variant až po složité konvoluční a variační návrhy, každý vhodný pro jiné úlohy.

2. **Učení bez učitele**: Učí se bez explicitních popisků, což je činí cennými pro scénáře s omezenými označenými daty.

3. **Redukce dimenzionality**: Autoenkodéry mohou snížit dimenze dat při zachování důležitých informací, často s lepšími výsledky než tradiční metody jako PCA.

4. **Učení příznaků**: Dokáží automaticky objevit užitečné příznaky ze surových dat, což může zlepšit výkon v následných úlohách.

5. **Mnoho aplikací**: Od odšumování obrazů a detekce anomálií po generování dat a kompresi, autoenkodéry mají různorodé aplikace napříč odvětvími.

6. **Variační autoenkodéry**: VAE rozšiřují autoenkodéry na generativní modely tím, že se učí pravděpodobnostní mapování, což umožňuje kontrolované generování dat.

7. **Omezení**: Mohou mít problémy s vysoce komplexními daty a někdy se mohou naučit spíše identitní funkce než smysluplné reprezentace, pokud nejsou správně omezeny.

Autoenkodéry tvoří zásadní součást moderních nástrojů hlubokého učení, zejména při práci s neoznačenými daty nebo když je vyžadována redukce dimenzionality. Jejich schopnost učit se kompaktní reprezentace je činí cennými pro různé úlohy napříč počítačovým viděním, zpracováním přirozeného jazyka a detekci anomálií v mnoha oborech.
