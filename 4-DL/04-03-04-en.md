## 1. Introduction to Graph Neural Networks

Graph Neural Networks (GNNs) are deep learning models designed to work with graph-structured data. Unlike traditional neural networks which operate on regular grid-like data (images, text), GNNs can process data represented as graphs with nodes and edges.

Graph data is ubiquitous in real-world applications: social networks, molecular structures, knowledge graphs, and recommendation systems are all naturally represented as graphs. Traditional deep learning architectures struggle with such irregular structures, which is why GNNs were developed.

## 3. Types of GNN Architectures

There are several key GNN architectures, each with different approaches to handling graph data:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GCNConv, GATConv, SAGEConv

# Graph Convolutional Network (GCN)
class GCN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        return x

# Graph Attention Network (GAT)
class GAT(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, heads=8):
        super(GAT, self).__init__()
        self.conv1 = GATConv(in_channels, hidden_channels, heads=heads)
        self.conv2 = GATConv(hidden_channels*heads, out_channels)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.elu(x)
        x = F.dropout(x, p=0.6, training=self.training)
        x = self.conv2(x, edge_index)
        return x

# GraphSAGE
class GraphSAGE(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(GraphSAGE, self).__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = SAGEConv(hidden_channels, out_channels)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        return x
```

The main types of GNN architectures include:

1. **Graph Convolutional Networks (GCNs)**: Perform convolutions over the graph structure by aggregating information from neighboring nodes.
2. **Graph Attention Networks (GATs)**: Apply attention mechanisms to weight the importance of different neighbors.
3. **GraphSAGE**: Uses sampling and aggregation to efficiently handle large graphs.
4. **Graph Isomorphism Networks (GINs)**: Designed for maximizing the expressive power of GNNs.
5. **Message Passing Neural Networks (MPNNs)**: A general framework that encompasses many GNN variants.

## 4. Implementing a Basic GNN with PyTorch

Let's implement a complete example of training a GNN on a simple dataset:

```python
from torch_geometric.datasets import Planetoid
from torch_geometric.transforms import NormalizeFeatures
import torch_geometric.transforms as T

# Load the Cora citation network dataset
dataset = Planetoid(root='/tmp/Cora', name='Cora', transform=NormalizeFeatures())
data = dataset[0]

# Examine the data
print(f"Number of nodes: {data.num_nodes}")
print(f"Number of edges: {data.num_edges}")
print(f"Number of node features: {data.num_features}")
print(f"Number of classes: {dataset.num_classes}")
print(f"Training nodes: {data.train_mask.sum().item()}")
print(f"Validation nodes: {data.val_mask.sum().item()}")
print(f"Test nodes: {data.test_mask.sum().item()}")

# Define GCN model
class GCN(torch.nn.Module):
    def __init__(self, num_features, hidden_channels, num_classes):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(num_features, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, num_classes)
        
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)

# Initialize model
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCN(dataset.num_features, 16, dataset.num_classes).to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

# Training function
def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    return loss

# Evaluation function
def test():
    model.eval()
    with torch.no_grad():
        out = model(data.x, data.edge_index)
        pred = out.argmax(dim=1)
        
        # Calculate accuracies
        train_acc = pred[data.train_mask].eq(data.y[data.train_mask]).sum().item() / data.train_mask.sum().item()
        val_acc = pred[data.val_mask].eq(data.y[data.val_mask]).sum().item() / data.val_mask.sum().item()
        test_acc = pred[data.test_mask].eq(data.y[data.test_mask]).sum().item() / data.test_mask.sum().item()
        
        return train_acc, val_acc, test_acc

# Training loop
best_val_acc = 0
for epoch in range(200):
    loss = train()
    train_acc, val_acc, test_acc = test()
    
    if val_acc > best_val_acc:
        best_val_acc = val_acc
        best_test_acc = test_acc
    
    if epoch % 20 == 0:
        print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, Train: {train_acc:.4f}, '
              f'Val: {val_acc:.4f}, Test: {test_acc:.4f}')

print(f'Best validation accuracy: {best_val_acc:.4f}')
print(f'Best test accuracy: {best_test_acc:.4f}')
```

This example implements a GCN for node classification on the Cora citation network dataset, where each node is a scientific paper, edges represent citations, and the task is to classify papers into different research areas.

```python
# Create a more complex model with residual connections
class ResGCN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, num_layers=3):
        super(ResGCN, self).__init__()
        
        self.convs = torch.nn.ModuleList()
        self.convs.append(GCNConv(in_channels, hidden_channels))
        
        for _ in range(num_layers - 2):
            self.convs.append(GCNConv(hidden_channels, hidden_channels))
            
        self.convs.append(GCNConv(hidden_channels, out_channels))
        
        # Linear transformations for residual connections
        self.skips = torch.nn.ModuleList()
        self.skips.append(torch.nn.Linear(in_channels, hidden_channels))
        for _ in range(num_layers - 2):
            self.skips.append(torch.nn.Linear(hidden_channels, hidden_channels))
        self.skips.append(torch.nn.Linear(hidden_channels, out_channels))
        
    def forward(self, x, edge_index):
        for i, conv in enumerate(self.convs[:-1]):
            # Residual connection
            res = self.skips[i](x)
            x = conv(x, edge_index)
            x = F.relu(x + res)  # Add residual
            x = F.dropout(x, p=0.5, training=self.training)
            
        # Final layer
        res = self.skips[-1](x)
        x = self.convs[-1](x, edge_index)
        x = x + res  # Add residual
        
        return F.log_softmax(x, dim=1)
```

## 6. Graph Classification Tasks

In graph classification, the goal is to classify entire graphs rather than individual nodes.

```python
from torch_geometric.datasets import TUDataset
from torch_geometric.data import DataLoader
from torch_geometric.nn import GCNConv, global_mean_pool

# Load a graph classification dataset (molecular graphs)
dataset = TUDataset(root='/tmp/PROTEINS', name='PROTEINS')
dataset = dataset.shuffle()

# Split dataset
train_dataset = dataset[:int(len(dataset) * 0.8)]
test_dataset = dataset[int(len(dataset) * 0.8):]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

print(f"Number of graphs: {len(dataset)}")
print(f"Number of features: {dataset.num_features}")
print(f"Number of classes: {dataset.num_classes}")

# Define graph classification model
class GCNGraphClassifier(torch.nn.Module):
    def __init__(self, num_features, hidden_channels, num_classes):
        super(GCNGraphClassifier, self).__init__()
        self.conv1 = GCNConv(num_features, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, hidden_channels)
        self.conv3 = GCNConv(hidden_channels, hidden_channels)
        self.lin = torch.nn.Linear(hidden_channels, num_classes)
        
    def forward(self, x, edge_index, batch):
        # Node embedding
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        
        x = self.conv2(x, edge_index)
        x = F.relu(x)
        
        x = self.conv3(x, edge_index)
        
        # Graph-level readout
        x = global_mean_pool(x, batch)  # [batch_size, hidden_channels]
        
        # Final classifier
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.lin(x)
        
        return F.log_softmax(x, dim=-1)

# Initialize model
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCNGraphClassifier(dataset.num_features, 64, dataset.num_classes).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# Training function
def train():
    model.train()
    total_loss = 0
    
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = F.nll_loss(out, data.y)
        loss.backward()
        optimizer.step()
        total_loss += float(loss) * data.num_graphs
    
    return total_loss / len(train_dataset)

# Testing function
def test(loader):
    model.eval()
    correct = 0
    
    for data in loader:
        data = data.to(device)
        with torch.no_grad():
            pred = model(data.x, data.edge_index, data.batch).argmax(dim=1)
            correct += int((pred == data.y).sum())
            
    return correct / len(loader.dataset)

# Training loop
for epoch in range(100):
    loss = train()
    train_acc = test(train_loader)
    test_acc = test(test_loader)
    
    if epoch % 10 == 0:
        print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, Train Acc: {train_acc:.4f}, Test Acc: {test_acc:.4f}')
```

## 7. Link Prediction

Link prediction aims to predict missing or future connections between nodes in a graph.

```python
from torch_geometric.nn import GCNConv
from torch_geometric.utils import train_test_split_edges, negative_sampling
from torch_geometric.datasets import Planetoid

# Load dataset
dataset = Planetoid(root='/tmp/Cora', name='Cora')
data = dataset[0]

# Prepare data for link prediction
data = train_test_split_edges(data)

class LinkPredictionGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(LinkPredictionGNN, self).__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
        
    def encode(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        return self.conv2(x, edge_index)
    
    def decode(self, z, edge_index):
        # Compute dot product between connected node embeddings
        return (z[edge_index[0]] * z[edge_index[1]]).sum(dim=1)
    
    def decode_all(self, z):
        # Compute pairwise dot products for all possible node pairs
        return torch.matmul(z, z.t())
    
    def forward(self, x, edge_index):
        z = self.encode(x, edge_index)
        return z

# Initialize model
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = LinkPredictionGNN(data.num_features, 128, 64).to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# Training function
def train():
    model.train()
    optimizer.zero_grad()
    
    # Compute node embeddings
    z = model.encode(data.x, data.train_pos_edge_index)
    
    # Sample positive and negative edges
    pos_edge_index = data.train_pos_edge_index
    neg_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=pos_edge_index.size(1)
    )
    
    # Predict edge scores for positive and negative examples
    pos_score = model.decode(z, pos_edge_index)
    neg_score = model.decode(z, neg_edge_index)
    
    # Compute loss using binary cross entropy
    pos_loss = F.binary_cross_entropy_with_logits(pos_score, torch.ones_like(pos_score))
    neg_loss = F.binary_cross_entropy_with_logits(neg_score, torch.zeros_like(neg_score))
    loss = pos_loss + neg_loss
    
    loss.backward()
    optimizer.step()
    
    return loss.item()

# Evaluation function
@torch.no_grad()
def test():
    model.eval()
    
    z = model.encode(data.x, data.train_pos_edge_index)
    
    def get_auc(pos_edge_index, neg_edge_index):
        pos_score = model.decode(z, pos_edge_index)
        neg_score = model.decode(z, neg_edge_index)
        
        scores = torch.cat([pos_score, neg_score], dim=0)
        labels = torch.cat([torch.ones(pos_score.size(0)), 
                            torch.zeros(neg_score.size(0))], dim=0)
        
        from sklearn.metrics import roc_auc_score
        return roc_auc_score(labels.cpu().numpy(), scores.cpu().numpy())
    
    # Sample negative test/validation edges
    neg_val_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=data.val_pos_edge_index.size(1)
    )
    
    neg_test_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=data.test_pos_edge_index.size(1)
    )
    
    # Calculate AUC
    val_auc = get_auc(data.val_pos_edge_index, neg_val_edge_index)
    test_auc = get_auc(data.test_pos_edge_index, neg_test_edge_index)
    
    return val_auc, test_auc

# Training loop
best_val_auc = 0
best_test_auc = 0

for epoch in range(100):
    loss = train()
    val_auc, test_auc = test()
    
    if val_auc > best_val_auc:
        best_val_auc = val_auc
        best_test_auc = test_auc
    
    if epoch % 10 == 0:
        print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, Val AUC: {val_auc:.4f}, '
              f'Test AUC: {test_auc:.4f}')

print(f'Best validation AUC: {best_val_auc:.4f}')
print(f'Best test AUC: {best_test_auc:.4f}')
```

## 8. GNN Applications

GNNs have been successfully applied across many domains:

```python
# Example: Using GNNs for molecular property prediction (QSAR)
from torch_geometric.datasets import MoleculeNet
from torch_geometric.nn import GCNConv, global_add_pool
from torch_geometric.data import DataLoader

# Load dataset
dataset = MoleculeNet(root='/tmp/ESOL', name='ESOL')  # Solubility prediction
dataset = dataset.shuffle()

# Split dataset
train_dataset = dataset[:int(len(dataset) * 0.8)]
val_dataset = dataset[int(len(dataset) * 0.8):int(len(dataset) * 0.9)]
test_dataset = dataset[int(len(dataset) * 0.9):]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

print(f"Dataset size: {len(dataset)}")
print(f"Number of node features: {dataset.num_node_features}")
print(f"Number of edge features: {dataset.num_edge_features}")
print(f"Number of tasks: {dataset.num_tasks}")

# Define model for regression
class MoleculeGNN(torch.nn.Module):
    def __init__(self, node_features, edge_features, hidden_channels, num_tasks):
        super(MoleculeGNN, self).__init__()
        
        # Node embedding
        self.node_encoder = torch.nn.Linear(node_features, hidden_channels)
        
        # Edge embedding
        self.edge_encoder = torch.nn.Linear(edge_features, hidden_channels)
        
        # Graph convolutions
        self.conv1 = GCNConv(hidden_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, hidden_channels)
        self.conv3 = GCNConv(hidden_channels, hidden_channels)
        
        # Output layers
        self.lin1 = torch.nn.Linear(hidden_channels, hidden_channels)
        self.lin2 = torch.nn.Linear(hidden_channels, num_tasks)
        
    def forward(self, x, edge_index, edge_attr, batch):
        # Initial node and edge embedding
        x = self.node_encoder(x)
        edge_attr = self.edge_encoder(edge_attr)
        
        # Graph convolutions
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        
        x = self.conv2(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        
        x = self.conv3(x, edge_index)
        
        # Global pooling
        x = global_add_pool(x, batch)
        
        # Final prediction
        x = self.lin1(x)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        x = self.lin2(x)
        
        return x

# Initialize model
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = MoleculeGNN(
    node_features=dataset.num_node_features, 
    edge_features=dataset.num_edge_features,
    hidden_channels=64, 
    num_tasks=dataset.num_tasks
).to(device)

optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
criterion = torch.nn.MSELoss()

# Training function
def train():
    model.train()
    total_loss = 0
    
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.edge_attr, data.batch)
        loss = criterion(out, data.y)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * data.num_graphs
    
    return total_loss / len(train_dataset)

# Evaluation function
@torch.no_grad()
def evaluate(loader):
    model.eval()
    mse = 0
    
    for data in loader:
        data = data.to(device)
        out = model(data.x, data.edge_index, data.edge_attr, data.batch)
        mse += F.mse_loss(out, data.y, reduction='sum').item()
    
    return mse / len(loader.dataset)

# Training loop
best_val_mse = float('inf')
for epoch in range(100):
    train_loss = train()
    val_mse = evaluate(val_loader)
    test_mse = evaluate(test_loader)
    
    if val_mse < best_val_mse:
        best_val_mse = val_mse
        best_test_mse = test_mse
    
    if epoch % 10 == 0:
        print(f'Epoch: {epoch:03d}, Train Loss: {train_loss:.4f}, '
              f'Val MSE: {val_mse:.4f}, Test MSE: {test_mse:.4f}')

print(f'Best validation MSE: {best_val_mse:.4f}')
print(f'Best test MSE: {best_test_mse:.4f}')
```

## 9. Recent Advances in GNNs

The field of GNNs is rapidly evolving with several recent advances:

```python
# Example of implementing a more recent GNN architecture

import torch
from torch_geometric.nn import MessagePassing, global_mean_pool
import torch.nn.functional as F

# Implementation of GraphNorm - a recent normalization technique for GNNs
class GraphNorm(torch.nn.Module):
    def __init__(self, num_features, eps=1e-5, affine=True):
        super(GraphNorm, self).__init__()
        self.eps = eps
        self.num_features = num_features
        
        if affine:
            self.gamma = torch.nn.Parameter(torch.ones(num_features))
            self.beta = torch.nn.Parameter(torch.zeros(num_features))
        else:
            self.register_parameter('gamma', None)
            self.register_parameter('beta', None)
            
    def forward(self, x, batch):
        batch_size = batch.max().item() + 1
        
        # Calculate batch statistics
        batch_mean = global_mean_pool(x, batch)
        batch_mean = torch.repeat_interleave(batch_mean, torch.bincount(batch), dim=0)
        
        # Compute variance per batch
        batch_var = global_mean_pool((x - batch_mean)**2, batch)
        batch_var = torch.repeat_interleave(batch_var, torch.bincount(batch), dim=0)
        
        # Normalize
        x_norm = (x - batch_mean) / (torch.sqrt(batch_var + self.eps))
        
        # Scale and shift
        if self.gamma is not None and self.beta is not None:
            x_norm = self.gamma * x_norm + self.beta
            
        return x_norm

class JumpingKnowledge(torch.nn.Module):
    def __init__(self, in_channels, out_channels, num_layers=3, mode='cat'):
        super(JumpingKnowledge, self).__init__()
        self.convs = torch.nn.ModuleList()
        self.norms = torch.nn.ModuleList()
        self.mode = mode
        
        for i in range(num_layers):
            if i == 0:
                self.convs.append(GCNConv(in_channels, out_channels))
            else:
                self.convs.append(GCNConv(out_channels, out_channels))
            self.norms.append(GraphNorm(out_channels))
            
        if mode == 'cat':
            self.jump = torch.nn.Linear(out_channels * num_layers, out_channels)
        elif mode == 'max':
            self.jump = torch.nn.Identity()
        else:  # LSTM mode
            self.jump = torch.nn.LSTM(out_channels, out_channels, batch_first=True)
            
    def forward(self, x, edge_index, batch):
        xs = []
        for i, conv in enumerate(self.convs):
            x = conv(x, edge_index)
            x = self.norms[i](x, batch)
            x = F.relu(x)
            x = F.dropout(x, p=0.2, training=self.training)
            xs.append(x)
            
        if self.mode == 'cat':
            return self.jump(torch.cat(xs, dim=1))
        elif self.mode == 'max':
            return torch.stack(xs, dim=1).max(dim=1)[0]
        else:  # LSTM mode
            x = torch.stack(xs, dim=1)  # [num_nodes, num_layers, out_channels]
            x, _ = self.jump(x)
            return x[:, -1]  # Return the last LSTM output
```

## 10. Summary

Graph Neural Networks have emerged as a powerful paradigm for deep learning on graph-structured data. Key takeaways from this introduction include:

1. **Graph Data Representation**: Graphs provide a natural representation for many real-world data types, capturing relationships between entities.

2. **GNN Architectures**: Various architectures have been developed, including GCN, GAT, GraphSAGE, and more recent advances, each with different approaches to aggregating and updating node information.

3. **Message Passing Framework**: Most GNNs follow a message passing paradigm, where nodes update their representations by aggregating information from neighbors.

4. **Tasks**: GNNs excel at node classification, graph classification, link prediction, and other graph-related tasks.

5. **Applications**: GNNs have found applications across diverse domains including chemistry, social networks, computer vision, NLP, and recommendation systems.

6. **Challenges**: GNNs face challenges related to scalability, expressiveness, heterogeneity, and dealing with dynamic graphs.

7. **Implementation**: Libraries like PyTorch Geometric and Deep Graph Library make it easier to implement GNNs for various applications.

8. **Recent Advances**: The field is rapidly evolving with new architectures and techniques addressing limitations of traditional GNN approaches.

As graph data continues to grow in importance across domains, GNNs provide a powerful toolset for extracting insights and making predictions based on relational information. Their ability to handle irregular data structures makes them a crucial component of the modern deep learning toolkit.
