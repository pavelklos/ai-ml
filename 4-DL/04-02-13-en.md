## 1. Introduction to Model Fine-tuning

Model fine-tuning is the process of taking a pre-trained model developed for one task and adapting it for a different but related task. This approach leverages the knowledge embedded in existing models, saving time and computational resources while often improving performance.

```python
import tensorflow as tf

import matplotlib.pyplot as plt

```

Key benefits of model fine-tuning include:
- Reduced training time
- Lower computational requirements
- Better performance with limited data
- Knowledge transfer across domains

## 2. Transfer Learning Fundamentals

Transfer learning involves using knowledge gained while solving one problem and applying it to a different but related problem. In deep learning, this typically means reusing weights from a pre-trained model.

### Types of Transfer Learning

```python
# Fine-tune a pre-trained ResNet50 model for a new classification task
def fine_tune_resnet_keras(train_data, validation_data, num_classes, epochs=10):
    # Load pre-trained model
    base_model = keras.applications.ResNet50(
        weights='imagenet',  # Load pre-trained ImageNet weights
        include_top=False,   # Don't include the original classification head
        input_shape=(224, 224, 3)
    )
    
    # Freeze convolutional base
    base_model.trainable = False
    
    # Create new model with our classification head
    model = keras.Sequential([
        base_model,
        keras.layers.GlobalAveragePooling2D(),
        keras.layers.Dense(256, activation='relu'),
        keras.layers.Dropout(0.5),
        keras.layers.Dense(num_classes, activation='softmax')
    ])
    
    # Compile model
    model.compile(
        optimizer=keras.optimizers.Adam(1e-4),  # Low learning rate for fine-tuning
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Train the top layers first (phase 1)
    print("Phase 1: Training classification head only...")
    history_phase1 = model.fit(
        train_data,
        validation_data=validation_data,
        epochs=5
    )
    
    # Unfreeze some layers for fine-tuning (phase 2)
    print("Phase 2: Fine-tuning ResNet layers...")
    # Unfreeze the last 30 layers
    for layer in base_model.layers[-30:]:
        layer.trainable = True
    
    # Recompile with lower learning rate
    model.compile(
        optimizer=keras.optimizers.Adam(1e-5),  # Even lower learning rate
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Continue training
    history_phase2 = model.fit(
        train_data,
        validation_data=validation_data,
        epochs=epochs
    )
    
    return model, history_phase1, history_phase2
```

```python
def fine_tune_resnet_pytorch(train_loader, val_loader, num_classes, epochs=10, device='cuda'):
    # Load pre-trained model
    model = models.resnet50(pretrained=True)
    
    # Freeze all layers
    for param in model.parameters():
        param.requires_grad = False
    
    # Replace final fully connected layer
    num_features = model.fc.in_features
    model.fc = nn.Sequential(
        nn.Linear(num_features, 256),
        nn.ReLU(),
        nn.Dropout(0.5),
        nn.Linear(256, num_classes)
    )
    
    # Move model to appropriate device
    model = model.to(device)
    
    # Loss function and optimizer
    criterion = nn.CrossEntropyLoss()
    
    # Only optimize parameters of the new layers
    optimizer = torch.optim.Adam(model.fc.parameters(), lr=1e-4)
    
    # Phase 1: Train only the new layers
    print("Phase 1: Training classification head only...")
    train_model(model, train_loader, val_loader, criterion, optimizer, epochs=5, device=device)
    
    # Phase 2: Fine-tune some layers
    print("Phase 2: Fine-tuning ResNet layers...")
    # Unfreeze the last few layers
    for param in model.layer4.parameters():  # Unfreeze last major block
        param.requires_grad = True
    
    # Optimizer now includes all trainable parameters
    optimizer = torch.optim.Adam([
        {'params': model.fc.parameters()},
        {'params': model.layer4.parameters(), 'lr': 1e-5}  # Lower LR for pre-trained layers
    ], lr=1e-4)
    
    # Continue training
    train_model(model, train_loader, val_loader, criterion, optimizer, epochs=epochs, device=device)
    
    return model

def train_model(model, train_loader, val_loader, criterion, optimizer, epochs, device):
    for epoch in range(epochs):
        # Training phase
        model.train()
        running_loss = 0.0
        
        for inputs, labels in train_loader:
            inputs, labels = inputs.to(device), labels.to(device)
            
            # Zero the gradients
            optimizer.zero_grad()
            
            # Forward pass
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            
            # Backward pass and optimize
            loss.backward()
            optimizer.step()
            
            running_loss += loss.item()
        
        # Validation phase
        model.eval()
        val_loss = 0.0
        correct = 0
        total = 0
        
        with torch.no_grad():
            for inputs, labels in val_loader:
                inputs, labels = inputs.to(device), labels.to(device)
                outputs = model(inputs)
                loss = criterion(outputs, labels)
                val_loss += loss.item()
                
                _, predicted = torch.max(outputs, 1)
                total += labels.size(0)
                correct += (predicted == labels).sum().item()
        
        val_accuracy = correct / total
        print(f'Epoch {epoch+1}/{epochs}, Train Loss: {running_loss/len(train_loader):.4f}, '
              f'Val Loss: {val_loss/len(val_loader):.4f}, Val Accuracy: {val_accuracy:.4f}')
```

```python
import torch
from transformers import BertTokenizer, BertForSequenceClassification
from transformers import AdamW, get_linear_schedule_with_warmup
from torch.utils.data import TensorDataset, DataLoader, RandomSampler, SequentialSampler

def fine_tune_bert(train_texts, train_labels, validation_texts, validation_labels, epochs=3):
    # Load pre-trained tokenizer and model
    tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
    model = BertForSequenceClassification.from_pretrained(
        'bert-base-uncased',
        num_labels=2,  # Binary classification (e.g., positive/negative)
        output_attentions=False,
        output_hidden_states=False,
    )
    
    # Tokenize texts and prepare input tensors
    train_encodings = tokenizer(
        train_texts,
        truncation=True,
        padding=True,
        max_length=128,
        return_tensors='pt'
    )
    
    val_encodings = tokenizer(
        validation_texts,
        truncation=True,
        padding=True,
        max_length=128,
        return_tensors='pt'
    )
    
    # Create tensor datasets
    train_dataset = TensorDataset(
        train_encodings['input_ids'],
        train_encodings['attention_mask'],
        torch.tensor(train_labels)
    )
    
    val_dataset = TensorDataset(
        val_encodings['input_ids'],
        val_encodings['attention_mask'],
        torch.tensor(validation_labels)
    )
    
    # Create data loaders
    batch_size = 16
    train_dataloader = DataLoader(
        train_dataset,
        sampler=RandomSampler(train_dataset),
        batch_size=batch_size
    )
    
    val_dataloader = DataLoader(
        val_dataset,
        sampler=SequentialSampler(val_dataset),
        batch_size=batch_size
    )
    
    # Set up optimizer and scheduler
    optimizer = AdamW(model.parameters(), lr=5e-5)
    
    # Total steps for scheduler
    total_steps = len(train_dataloader) * epochs
    
    # Create learning rate scheduler
    scheduler = get_linear_schedule_with_warmup(
        optimizer,
        num_warmup_steps=0,
        num_training_steps=total_steps
    )
    
    # Check for GPU
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model.to(device)
    
    # Training loop
    for epoch in range(epochs):
        print(f'======== Epoch {epoch+1} / {epochs} ========')
        
        # Training
        model.train()
        total_train_loss = 0
        
        for batch in train_dataloader:
            # Add batch to device
            input_ids = batch[0].to(device)
            attention_mask = batch[1].to(device)
            labels = batch[2].to(device)
            
            # Clear gradients
            optimizer.zero_grad()
            
            # Forward pass
            outputs = model(
                input_ids=input_ids,
                attention_mask=attention_mask,
                labels=labels
            )
            
            loss = outputs.loss
            total_train_loss += loss.item()
            
            # Backward pass
            loss.backward()
            
            # Clip gradients to prevent exploding gradients
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            
            # Update parameters
            optimizer.step()
            
            # Update learning rate
            scheduler.step()
        
        avg_train_loss = total_train_loss / len(train_dataloader)
        print(f"Average training loss: {avg_train_loss:.4f}")
        
        # Validation
        model.eval()
        total_val_loss = 0
        predictions, true_labels = [], []
        
        for batch in val_dataloader:
            input_ids = batch[0].to(device)
            attention_mask = batch[1].to(device)
            labels = batch[2].to(device)
            
            with torch.no_grad():
                outputs = model(
                    input_ids=input_ids,
                    attention_mask=attention_mask,
                    labels=labels
                )
            
            loss = outputs.loss
            total_val_loss += loss.item()
            
            # Get predictions and true labels
            logits = outputs.logits
            predictions.extend(torch.argmax(logits, dim=1).cpu().numpy())
            true_labels.extend(labels.cpu().numpy())
        
        avg_val_loss = total_val_loss / len(val_dataloader)
        val_accuracy = accuracy_score(true_labels, predictions)
        
        print(f"Validation loss: {avg_val_loss:.4f}")
        print(f"Validation accuracy: {val_accuracy:.4f}")
    
    return model, tokenizer
```

## 5. Domain Adaptation Strategies

Domain adaptation addresses the challenge of adapting models trained on one data distribution to perform well on a different but related distribution.

```python
# Implement domain adaptation with Gradient Reversal Layer (GRL)
import torch.autograd as autograd

class GradientReversalLayer(autograd.Function):
    @staticmethod
    def forward(ctx, x, alpha):
        ctx.alpha = alpha
        return x.clone()
    
    @staticmethod
    def backward(ctx, grad_output):
        return grad_output.neg() * ctx.alpha, None

def gradient_reverse(x, alpha=1.0):
    return GradientReversalLayer.apply(x, alpha)

class DomainAdaptationModel(nn.Module):
    def __init__(self, feature_extractor, num_classes):
        super(DomainAdaptationModel, self).__init__()
        self.feature_extractor = feature_extractor
        
        # Task classifier (e.g., image classification)
        self.task_classifier = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes)
        )
        
        # Domain classifier (source vs target)
        self.domain_classifier = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, 2)  # binary classification: source or target
        )
        
    def forward(self, x, alpha=1.0):
        features = self.feature_extractor(x)
        
        # Task prediction
        task_output = self.task_classifier(features)
        
        # Reverse gradient for domain adaptation
        reversed_features = gradient_reverse(features, alpha)
        domain_output = self.domain_classifier(reversed_features)
        
        return task_output, domain_output
```

### Implementing Domain-Adversarial Training

```python
def train_domain_adaptation(source_loader, target_loader, model, epochs=10, device='cuda'):
    model = model.to(device)
    
    # Loss functions
    task_criterion = nn.CrossEntropyLoss()
    domain_criterion = nn.CrossEntropyLoss()
    
    # Optimizer
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)
    
    for epoch in range(epochs):
        model.train()
        running_task_loss = 0.0
        running_domain_loss = 0.0
        total_samples = 0
        correct_task = 0
        correct_domain = 0
        
        # Progress through batches of source and target
        for (source_inputs, source_labels), (target_inputs, _) in zip(source_loader, target_loader):
            source_inputs, source_labels = source_inputs.to(device), source_labels.to(device)
            target_inputs = target_inputs.to(device)
            
            # Create domain labels: source=0, target=1
            source_domain_labels = torch.zeros(source_inputs.size(0), dtype=torch.long).to(device)
            target_domain_labels = torch.ones(target_inputs.size(0), dtype=torch.long).to(device)
            
            # Clear gradients
            optimizer.zero_grad()
            
            # Calculate adaptation factor
            p = float(epoch) / epochs
            alpha = 2. / (1. + np.exp(-10 * p)) - 1  # gradually increase alpha
            
            # Forward pass on source data
            task_output_source, domain_output_source = model(source_inputs, alpha)
            
            # Forward pass on target data
            _, domain_output_target = model(target_inputs, alpha)
            
            # Calculate task loss (only on source)
            task_loss = task_criterion(task_output_source, source_labels)
            
            # Calculate domain loss (on both source and target)
            domain_loss_source = domain_criterion(domain_output_source, source_domain_labels)
            domain_loss_target = domain_criterion(domain_output_target, target_domain_labels)
            domain_loss = domain_loss_source + domain_loss_target
            
            # Combined loss
            loss = task_loss + domain_loss
            
            # Backward and optimize
            loss.backward()
            optimizer.step()
            
            # Statistics
            running_task_loss += task_loss.item() * source_inputs.size(0)
            running_domain_loss += domain_loss.item() * (source_inputs.size(0) + target_inputs.size(0))
            total_samples += source_inputs.size(0)
            
            # Task accuracy (on source)
            _, predicted = torch.max(task_output_source, 1)
            correct_task += (predicted == source_labels).sum().item()
            
            # Domain accuracy
            _, domain_pred_source = torch.max(domain_output_source, 1)
            _, domain_pred_target = torch.max(domain_output_target, 1)
            correct_domain += (domain_pred_source == source_domain_labels).sum().item()
            correct_domain += (domain_pred_target == target_domain_labels).sum().item()
        
        # Epoch statistics
        task_loss = running_task_loss / total_samples
        task_acc = correct_task / total_samples
        domain_loss = running_domain_loss / (total_samples * 2)  # source + target
        domain_acc = correct_domain / (total_samples * 2)  # source + target
        
        print(f'Epoch {epoch+1}/{epochs}: '
              f'Task Loss: {task_loss:.4f}, Task Acc: {task_acc:.4f}, '
              f'Domain Loss: {domain_loss:.4f}, Domain Acc: {domain_acc:.4f}')
    
    return model
```

## 6. Progressive and Gradual Fine-tuning

Progressive fine-tuning involves gradually unfreezing and fine-tuning layers of a model, starting from the output layers and working backwards.

```python
def progressive_fine_tuning(base_model, train_data, val_data, epochs_per_stage=3):
    """
    Progressively fine-tune a model by gradually unfreezing layers
    """
    # Stage 1: Train only the newly added classification head
    for layer in base_model.layers:
        layer.trainable = False
    
    # Add classification head
    model = keras.Sequential([
        base_model,
        keras.layers.GlobalAveragePooling2D(),
        keras.layers.Dense(256, activation='relu'),
        keras.layers.Dense(num_classes, activation='softmax')
    ])
    
    model.compile(
        optimizer=keras.optimizers.Adam(1e-4),
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    print("Stage 1: Training classification head only")
    model.fit(train_data, validation_data=val_data, epochs=epochs_per_stage)
    
    # Get all layers that can be unfrozen (typically convolutional blocks)
    trainable_layers = [layer for layer in base_model.layers 
                        if isinstance(layer, keras.layers.Conv2D)]
    
    # Number of stages = number of blocks to unfreeze + 1 (for head training)
    num_blocks = len(trainable_layers) // 3  # Assuming ~3 conv layers per block
    
    # Start with last block and move backwards
    for stage in range(2, num_blocks + 2):
        print(f"Stage {stage}: Unfreezing more layers")
        
        # Calculate how many layers to unfreeze in this stage
        layers_to_unfreeze = len(trainable_layers) // (num_blocks + 1 - stage)
        
        # Unfreeze a subset of layers from the end
        for layer in trainable_layers[-layers_to_unfreeze:]:
            layer.trainable = True
        
        # Recompile with lower learning rate
        model.compile(
            optimizer=keras.optimizers.Adam(1e-5 / stage),  # Progressively lower LR
            loss='categorical_crossentropy',
            metrics=['accuracy']
        )
        
        # Train for this stage
        model.fit(train_data, validation_data=val_data, epochs=epochs_per_stage)
    
    return model
```

## 8. Preventing Catastrophic Forgetting

Catastrophic forgetting occurs when a model loses its previously learned knowledge after being fine-tuned on a new task. Several techniques help mitigate this issue.

```python
# Elastic Weight Consolidation (EWC) implementation
class ElasticWeightConsolidation:
    def __init__(self, model, old_tasks_data, importance=1000):
        self.model = model
        self.old_tasks_data = old_tasks_data
        self.importance = importance
        self.fisher_matrix = None
        self.old_params = None
        
    def compute_fisher_matrix(self):
        # Store a copy of current parameters
        self.old_params = {name: param.clone().detach()
                          for name, param in self.model.named_parameters() if param.requires_grad}
        
        # Initialize Fisher matrix with zeros
        self.fisher_matrix = {name: torch.zeros_like(param)
                             for name, param in self.old_params.items()}
        
        # Set model to evaluation mode
        self.model.eval()
        
        # Compute Fisher information matrix
        for inputs, targets in self.old_tasks_data:
            self.model.zero_grad()
            
            # Forward pass
            outputs = self.model(inputs)
            
            # Compute loss
            loss = F.cross_entropy(outputs, targets)
            
            # Backward pass
            loss.backward()
            
            # Accumulate squared gradients in Fisher matrix
            for name, param in self.model.named_parameters():
                if param.requires_grad and param.grad is not None:
                    self.fisher_matrix[name] += param.grad.pow(2).detach()
        
        # Normalize by number of samples
        for name in self.fisher_matrix:
            self.fisher_matrix[name] /= len(self.old_tasks_data)
    
    def ewc_loss(self):
        loss = 0
        for name, param in self.model.named_parameters():
            if name in self.fisher_matrix and param.requires_grad:
                # Compute penalty: importance * Fisher * (current_params - old_params)^2
                loss += (self.importance * self.fisher_matrix[name] * 
                         (param - self.old_params[name]).pow(2)).sum()
        return loss
    
    def train_with_ewc(self, train_loader, val_loader, criterion, optimizer, epochs=10):
        # Compute Fisher matrix before training on new task
        self.compute_fisher_matrix()
        
        for epoch in range(epochs):
            self.model.train()
            running_loss = 0.0
            
            for inputs, targets in train_loader:
                # Forward pass
                outputs = self.model(inputs)
                
                # Compute task loss
                task_loss = criterion(outputs, targets)
                
                # Add EWC regularization loss
                ewc_reg_loss = self.ewc_loss()
                
                # Total loss
                loss = task_loss + ewc_reg_loss
                
                # Backward and optimize
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
                
                running_loss += loss.item()
            
            print(f'Epoch {epoch+1}/{epochs}, Loss: {running_loss/len(train_loader):.4f}')
            
            # Evaluate on validation set
            self.model.eval()
            correct = 0
            total = 0
            with torch.no_grad():
                for inputs, targets in val_loader:
                    outputs = self.model(inputs)
                    _, predicted = torch.max(outputs.data, 1)
                    total += targets.size(0)
                    correct += (predicted == targets).sum().item()
            
            print(f'Validation Accuracy: {100 * correct / total:.2f}%')
```

## 9. Evaluating Fine-tuned Models

Proper evaluation helps determine if fine-tuning has been successful and whether the model generalizes well to the new task.

```python
def evaluate_fine_tuned_model(model, test_data, batch_size=32):
    """Evaluate a fine-tuned model on test data"""
    # Prepare data
    if isinstance(test_data, tuple):
        # If test_data is (x_test, y_test)
        x_test, y_test = test_data
        test_dataset = tf.data.Dataset.from_tensor_slices((x_test, y_test)).batch(batch_size)
    else:
        # If test_data is already a dataset or dataloader
        test_dataset = test_data
    
    # Evaluate model
    results = model.evaluate(test_dataset)
    
    if isinstance(results, list):
        # If multiple metrics were returned
        metrics = model.metrics_names
        results_dict = dict(zip(metrics, results))
        
        print("\nTest Results:")
        for metric, value in results_dict.items():
            print(f"{metric}: {value:.4f}")
    else:
        # If only loss was returned
        print(f"\nTest Loss: {results:.4f}")
    
    # Get predictions for more detailed analysis
    y_pred_list = []
    y_true_list = []
    
    for x_batch, y_batch in test_dataset:
        y_pred = model.predict(x_batch)
        y_pred_list.append(y_pred)
        y_true_list.append(y_batch)
    
    # Concatenate batch predictions
    y_pred_array = np.vstack(y_pred_list)
    y_true_array = np.vstack(y_true_list) if len(y_true_list[0].shape) > 1 else np.concatenate(y_true_list)
    
    # Convert predictions to class indices for classification tasks
    if y_pred_array.shape[1] > 1:  # Multi-class classification
        y_pred_classes = np.argmax(y_pred_array, axis=1)
        if len(y_true_array.shape) > 1 and y_true_array.shape[1] > 1:  # One-hot encoded
            y_true_classes = np.argmax(y_true_array, axis=1)
        else:  # Class indices
            y_true_classes = y_true_array
        
        # Print classification report
        print("\nClassification Report:")
        print(classification_report(y_true_classes, y_pred_classes))
    
    # Plot confusion matrix for classification tasks
    if y_pred_array.shape[1] > 1:  # Multi-class classification
        from sklearn.metrics import confusion_matrix
        import seaborn as sns
        
        cm = confusion_matrix(y_true_classes, y_pred_classes)
        plt.figure(figsize=(10, 8))
        sns.heatmap(cm, annot=True, fmt='d', cmap='Blues')
        plt.title('Confusion Matrix')
        plt.xlabel('Predicted Labels')
        plt.ylabel('True Labels')
        plt.show()
    
    return y_pred_array, y_true_array
```

## 10. Summary

Model fine-tuning and adaptation is an essential technique in deep learning that allows practitioners to leverage pre-trained models for new tasks with limited data. Key takeaways include:

1. **Transfer Learning** enables knowledge reuse from models trained on large datasets, saving time and computational resources.

2. **Fine-tuning Approaches**:
   - Feature extraction: Freeze the pre-trained model, only train a new classification head
   - Partial fine-tuning: Freeze early layers, fine-tune later layers
   - Full fine-tuning: Retrain the entire network with careful parameter settings

3. **Domain Adaptation** techniques help models generalize across different but related data distributions.

4. **Progressive Fine-tuning** gradually unfreezes layers from top to bottom, often yielding better results.

5. **Hyperparameter Optimization** is crucial during fine-tuning, especially for learning rates and regularization.

6. **Catastrophic Forgetting** can be mitigated using techniques like Elastic Weight Consolidation.

7. **Thorough Evaluation** is needed to verify that fine-tuned models generalize well to new tasks.

8. **Best Practices**:
   - Use smaller learning rates for fine-tuning pre-trained layers
   - Apply appropriate regularization to prevent overfitting
   - Monitor validation performance to avoid degrading the pre-trained knowledge

By mastering these techniques, you can effectively adapt state-of-the-art models to your specific use cases, achieving high performance even with limited training data.
