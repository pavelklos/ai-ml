## 1. Introduction to Time Series Forecasting with Deep Learning

Time series forecasting is the process of predicting future values based on previously observed values. Deep learning has revolutionized this field by capturing complex temporal patterns and dependencies that traditional statistical methods often miss.

Time series data has unique characteristics that make it challenging for standard machine learning approaches:

1. **Temporal dependencies**: Values depend on previous observations
2. **Seasonality**: Regular patterns that repeat at fixed intervals
3. **Trends**: Long-term increase or decrease in data values
4. **Non-stationarity**: Statistical properties change over time

## 2. Time Series Data Preprocessing

Proper preprocessing is crucial for effective time series forecasting with deep learning. Common techniques include:

1. **Resampling**: Changing the frequency of the time series 
2. **Scaling**: Normalizing or standardizing values
3. **Windowing**: Creating input-output sequences
4. **Feature engineering**: Extracting relevant features like lag variables or date-based features

```python
# Data preprocessing for deep learning time series forecasting

# Scaling the data
scaler = MinMaxScaler(feature_range=(0, 1))
scaled_data = scaler.fit_transform(df['Passengers'].values.reshape(-1, 1))

# Create sequences (windows) for supervised learning
def create_sequences(data, seq_length):
    """Create sequences for supervised learning from time series data."""
    xs, ys = [], []
    for i in range(len(data) - seq_length):
        x = data[i:i+seq_length]
        y = data[i+seq_length]
        xs.append(x)
        ys.append(y)
    return np.array(xs), np.array(ys)

# Define sequence length (lookback period)
seq_length = 12  # Using 12 months to predict the next month
X, y = create_sequences(scaled_data, seq_length)
```

## 3. Recurrent Neural Networks (RNNs) for Time Series

Recurrent Neural Networks (RNNs) are designed to work with sequential data by maintaining a memory of previous inputs. Simple RNNs can capture short-term dependencies but struggle with longer sequences due to the vanishing gradient problem.

## 5. Temporal Convolutional Networks (TCNs)

Temporal Convolutional Networks (TCNs) use dilated causal convolutions to process sequential data. They offer advantages over RNNs including parallelizable training, flexible receptive field size, and stable gradients.

```python
# Implementing a TCN for time series forecasting
from tensorflow.keras.layers import Conv1D, BatchNormalization, Activation, Add, Input, Dense
from tensorflow.keras.models import Model

def residual_block(x, filters, kernel_size, dilation_rate):
    """TCN residual block with dilated causal convolution."""
    # Skip connection
    residual = x
    
    # First dilated causal convolution
    conv1 = Conv1D(filters, kernel_size, padding='causal', dilation_rate=dilation_rate)(x)
    norm1 = BatchNormalization()(conv1)
    act1 = Activation('relu')(norm1)
    
    # Second dilated causal convolution
    conv2 = Conv1D(filters, kernel_size, padding='causal', dilation_rate=dilation_rate)(act1)
    norm2 = BatchNormalization()(conv2)
    act2 = Activation('relu')(norm2)
    
    # Skip connection handling (match dimensions)
    if x.shape[-1] != filters:
        residual = Conv1D(filters, 1, padding='same')(x)
    
    # Add skip connection
    output = Add()([residual, act2])
    return Activation('relu')(output)

def build_tcn_model(input_shape, filters=64, kernel_size=3, num_layers=3):
    """Build a TCN model with multiple residual blocks."""
    inputs = Input(shape=input_shape)
    x = inputs
    
    # Create TCN blocks with increasing dilation rates
    for i in range(num_layers):
        dilation_rate = 2 ** i
        x = residual_block(x, filters, kernel_size, dilation_rate)
    
    # Global average pooling and output layer
    x = keras.layers.GlobalAveragePooling1D()(x)
    outputs = Dense(1)(x)
    
    model = Model(inputs, outputs)
    model.compile(optimizer='adam', loss='mse')
    return model

# Create and train the TCN model
tcn_model = build_tcn_model((X_train.shape[1], X_train.shape[2]))
print(tcn_model.summary())

# Training with early stopping

    X_train, y_train,

    batch_size=16,
    validation_split=0.2,
    callbacks=[early_stopping],
    verbose=1
)

# Evaluate the TCN model

y_pred_tcn_inv = scaler.inverse_transform(y_pred_tcn)
```

## 6. Attention Mechanisms for Time Series

Attention mechanisms allow models to focus on relevant parts of the input sequence when making predictions. This is particularly useful for time series with important patterns at various time points.

## 7. Transformer Models for Time Series Data

Transformer models, originally designed for natural language processing, have become increasingly popular for time series forecasting due to their ability to capture global dependencies and efficiently process sequences in parallel.

```python
# Implementing a Transformer model for time series forecasting
import tensorflow as tf
from tensorflow.keras import layers

def transformer_encoder(inputs, head_size, num_heads, ff_dim, dropout=0):
    """Transformer encoder block with multi-head self-attention."""
    # Normalization and Multi-Head Attention
    x = layers.LayerNormalization(epsilon=1e-6)(inputs)
    x = layers.MultiHeadAttention(
        key_dim=head_size, num_heads=num_heads, dropout=dropout
    )(x, x)
    res = x + inputs
    
    # Feed Forward Network
    x = layers.LayerNormalization(epsilon=1e-6)(res)
    x = layers.Conv1D(filters=ff_dim, kernel_size=1, activation="relu")(x)
    x = layers.Dropout(dropout)(x)
    x = layers.Conv1D(filters=inputs.shape[-1], kernel_size=1)(x)
    return x + res

def build_transformer_model(input_shape, head_size=256, num_heads=4, ff_dim=4, num_transformer_blocks=4, mlp_units=[128], dropout=0.1):
    """Build a Transformer model for time series forecasting."""
    inputs = layers.Input(shape=input_shape)
    x = inputs
    
    # Add positional encoding
    positional_encoding = PositionalEncoding(input_shape[0], input_shape[1])(x)
    x = layers.Add()([x, positional_encoding])
    
    # Transformer blocks
    for _ in range(num_transformer_blocks):
        x = transformer_encoder(x, head_size, num_heads, ff_dim, dropout)
    
    # Final processing
    x = layers.GlobalAveragePooling1D(data_format="channels_first")(x)
    for dim in mlp_units:
        x = layers.Dense(dim, activation="relu")(x)
        x = layers.Dropout(dropout)(x)
    
    outputs = layers.Dense(1)(x)
    
    model = keras.Model(inputs, outputs)
    model.compile(optimizer='adam', loss='mse')
    return model

# Positional encoding layer for Transformer
class PositionalEncoding(layers.Layer):
    def __init__(self, max_len, d_model):
        super(PositionalEncoding, self).__init__()
        self.max_len = max_len
        self.d_model = d_model
    
    def build(self, input_shape):
        pe = np.zeros((self.max_len, self.d_model))
        position = np.arange(0, self.max_len)[:, np.newaxis]
        div_term = np.exp(np.arange(0, self.d_model, 2) * -(np.log(10000.0) / self.d_model))
        
        pe[:, 0::2] = np.sin(position * div_term)
        pe[:, 1::2] = np.cos(position * div_term)
        
        self.pe = tf.cast(pe[np.newaxis, ...], dtype=tf.float32)
        
    def call(self, inputs):
        return self.pe[:, :inputs.shape[1], :]

# Create and train the Transformer model
transformer_model = build_transformer_model((X_train.shape[1], X_train.shape[2]))
print(transformer_model.summary())

# Training with early stopping

    X_train, y_train,
    epochs=100,
    batch_size=16,
    validation_split=0.2,
    callbacks=[early_stopping],
    verbose=1
)

# Evaluate the Transformer model
y_pred_transformer = transformer_model.predict(X_test)
y_pred_transformer_inv = scaler.inverse_transform(y_pred_transformer)

transformer_rmse = np.sqrt(mean_squared_error(y_test_inv, y_pred_transformer_inv))
print(f"Transformer Model RMSE: {transformer_rmse:.2f}")

# Plot Transformer model predictions
```

```python
    """Create sequences for multivariate time series with multiple forecast steps."""

        X.append(data[i:i+seq_length])
        y.append(data[i+seq_length:i+seq_length+horizon, 0])  # Predicting the first variable (pollution)
    return np.array(X), np.array(y)
```

## 9. Hyperparameter Tuning and Model Evaluation

Effective hyperparameter tuning and proper model evaluation are essential for developing accurate time series forecasting models. Techniques like cross-validation must be adapted for time series to avoid data leakage.

```python
# Hyperparameter tuning for time series models
import keras_tuner as kt
from sklearn.model_selection import TimeSeriesSplit

# Define a function to build a model with tunable hyperparameters
def build_tunable_lstm(hp):
    model = keras.Sequential()
    
    # Tune the number of units in the LSTM layer
    lstm_units = hp.Int('lstm_units', min_value=32, max_value=128, step=32)
    
    # Tune dropout rate
    dropout_rate = hp.Float('dropout_rate', min_value=0.0, max_value=0.5, step=0.1)
    
    # Tune number of layers
    num_layers = hp.Int('num_layers', 1, 3)
    
    # First LSTM layer
    model.add(keras.layers.LSTM(
        units=lstm_units,
        return_sequences=num_layers > 1,
        input_shape=(X_train.shape[1], X_train.shape[2])
    ))
    model.add(keras.layers.Dropout(dropout_rate))
    
    # Additional LSTM layers
    for i in range(num_layers - 1):
        return_sequences = i < num_layers - 2
        model.add(keras.layers.LSTM(units=lstm_units, return_sequences=return_sequences))

    learning_rate = hp.Float('learning_rate', min_value=1e-4, max_value=1e-2, sampling='log')
    
    # Compile the model
    model.compile(
        optimizer=keras.optimizers.Adam(learning_rate=learning_rate),
        loss='mse'
    )
    
    return model

# Advanced evaluation metrics for time series
def evaluate_forecast(y_true, y_pred):
    """Calculate various evaluation metrics for time series forecasting."""
    # Root Mean Squared Error
    rmse = np.sqrt(mean_squared_error(y_true, y_pred))
    
    # Mean Absolute Error
    mae = mean_absolute_error(y_true, y_pred)
    
    # Mean Absolute Percentage Error
    mape = np.mean(np.abs((y_true - y_pred) / y_true)) * 100
    
    # Symmetric Mean Absolute Percentage Error
    smape = np.mean(200 * np.abs(y_pred - y_true) / (np.abs(y_pred) + np.abs(y_true)))
    
    # Coefficient of Determination (R²)
    r2 = 1 - (np.sum((y_true - y_pred) ** 2) / np.sum((y_true - np.mean(y_true)) ** 2))
    
    return {
        'RMSE': rmse,
        'MAE': mae,
        'MAPE': mape,
        'SMAPE': smape,
        'R²': r2
    }
```

## 10. Summary and Best Practices

Deep learning has significantly advanced time series forecasting capabilities, offering powerful tools to capture complex temporal patterns. Here's a summary of key points and best practices:

1. **Data Preprocessing** is crucial for time series forecasting:
   - Ensure stationarity or handle non-stationarity appropriately
   - Scale data to improve model training
   - Create appropriate sequence windows for supervised learning
   - Engineer useful features like lag variables and date-based features

2. **Model Selection** depends on your specific time series characteristics:
   - **Simple RNNs**: For very short sequences with limited temporal dependencies
   - **LSTM/GRU**: For capturing longer-term dependencies
   - **TCNs**: For efficient parallel processing and precise control of receptive field size
   - **Attention/Transformers**: For very long sequences and capturing complex relationships

3. **Training Strategies**:
   - Use proper time series cross-validation to prevent data leakage
   - Apply early stopping to prevent overfitting
   - Experiment with learning rate scheduling for better convergence
   - Adjust batch size according to your dataset size

4. **Handling Complex Forecasting Tasks**:
   - For multivariate data, ensure proper feature scaling
   - For multistep forecasting, choose between direct and recursive strategies
   - Consider ensemble methods to combine predictions from multiple models

5. **Evaluation Considerations**:
   - Use multiple metrics (RMSE, MAE, MAPE) for comprehensive evaluation
   - Consider domain-specific evaluation criteria
   - Visualize predictions alongside actual values for intuitive assessment

```python
def time_series_forecasting_pipeline(data, target_column=None, sequence_length=10,

        data: DataFrame containing time series data
        target_column: Column to forecast (None for univariate series)
        sequence_length: Number of time steps to use for prediction
        forecast_horizon: Number of steps to forecast
        test_size: Proportion of data to use for testing

    X, y = create_sequences(scaled_data, sequence_length, forecast_horizon)

    if forecast_horizon == 1:

    else:
```
