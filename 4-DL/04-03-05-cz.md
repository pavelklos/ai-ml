## 1. Úvod do Zero-shot a Few-shot learningu

Zero-shot a few-shot learning představují pokročilá paradigmata ve strojovém učení, která řeší problém učení s omezeným množstvím označených dat. Umožňují modelům provádět úlohy s minimálním nebo dokonce žádným výslovným tréninkem na konkrétních třídách či úlohách.

- **Zero-shot Learning**: Schopnost klasifikovat objekty bez zhlédnutí jakýchkoli trénovacích příkladů dané třídy
- **Few-shot Learning**: Schopnost učit se pouze z několika příkladů (typicky 1-5) pro každou třídu

Tyto přístupy jsou stále důležitější, protože snižují potřebu masivních označených datových sad a umožňují modelům efektivněji zobecňovat na nové scénáře.

## 2. Tradiční vs Few-shot/Zero-shot learning paradigmata

### Tradiční učení

V tradičním učení s učitelem modely vyžadují velké množství označených dat pro každou třídu, kterou mají klasifikovat:

```python
# Tradiční přístup učení s učitelem
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# Načtení standardního datasetu (např. MNIST)
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
train_loader = DataLoader(train_dataset, batch_size=64)

# Definice jednoduché neuronové sítě
class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.fc1 = nn.Linear(28 * 28, 128)
        self.fc2 = nn.Linear(128, 10)  # 10 tříd
        
    def forward(self, x):
        x = x.view(-1, 28 * 28)
        x = torch.relu(self.fc1(x))
        return self.fc2(x)

# Trénování na mnoha příkladech každé třídy
model = SimpleNN()
optimizer = torch.optim.Adam(model.parameters())
criterion = nn.CrossEntropyLoss()

def train(epochs=1):
    for epoch in range(epochs):
        for batch_idx, (data, target) in enumerate(train_loader):
            optimizer.zero_grad()
            output = model(data)
            loss = criterion(output, target)
            loss.backward()
            optimizer.step()
            if batch_idx % 100 == 0:
                print(f'Epocha: {epoch}, Dávka: {batch_idx}, Ztráta: {loss.item():.4f}')
```

### Zero-shot/Few-shot Learning

Naproti tomu zero-shot a few-shot přístupy využívají:

1. **Přenesené znalosti**: Využití znalostí z příbuzných úloh nebo domén
2. **Sémantické embeddingy**: Využití doplňkových sémantických informací o třídách
3. **Meta-učení**: Učení se, jak se učit z několika málo příkladů

## 3. Přístupy k Zero-shot learningu

Zero-shot learning umožňuje modelům zobecňovat na nové, neviděné třídy využitím pomocných informací a sémantických vztahů.

### Hlavní přístupy k Zero-shot learningu:

1. **Metody založené na atributech**: Učení mapování mezi vizuálními rysy a sémantickými atributy
2. **Metody založené na embeddingu**: Projekce obrázků a popisů tříd do sdíleného sémantického prostoru
3. **Generativní metody**: Generování syntetických příkladů pro neviděné třídy
4. **Metody založené na promptech**: Využití jazykových modelů s pečlivě vytvořenými prompty

```python
# Implementace jednoduchého zero-shot klasifikátoru pomocí předtrénovaných obrazových a textových enkodérů
import torch
from PIL import Image
import requests
from io import BytesIO
from transformers import CLIPProcessor, CLIPModel

# Načtení předtrénovaného CLIP modelu (propojuje obrázky a text ve sdíleném embeddingovém prostoru)
model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

# Příklad URL obrázku
image_url = "https://farm1.staticflickr.com/6/9606553_ccc7518589_z.jpg"  # Obrázek ptáka
response = requests.get(image_url)
image = Image.open(BytesIO(response.content))

# Kandidáti štítků tříd, na kterých jsme nikdy explicitně netrénovali
candidate_labels = ["fotografie ptáka", "fotografie psa", "fotografie auta"]

# Zpracování vstupů
inputs = processor(text=candidate_labels, images=image, return_tensors="pt", padding=True)

# Získání predikce
with torch.no_grad():
    outputs = model(**inputs)
    logits_per_image = outputs.logits_per_image  # Skóre podobnosti mezi obrázkem a textem
    probs = logits_per_image.softmax(dim=1)  # Převod na pravděpodobnosti

# Zobrazení výsledků
print("Pravděpodobnosti štítků:", probs)
print(f"Nejlepší shoda: {candidate_labels[probs.argmax().item()]}")
```

## 4. Metody Few-shot learningu

Metody few-shot learningu se snaží efektivně učit z malého počtu označených příkladů pro každou třídu. Hlavní přístupy zahrnují:

1. **Metody založené na metrikách**: Učení metrik podobnosti mezi příklady (např. Siamské sítě, Prototypové sítě)
2. **Metody založené na modelech**: Návrh modelů, které se dokáží rychle přizpůsobit novým úlohám (např. Memory-Augmented Neural Networks)
3. **Metody založené na optimalizaci**: Učení optimalizačních algoritmů, které dokáží rychle adaptovat modely na nové úlohy (např. MAML)
4. **Transfer learning s dolaďováním**: Adaptace předtrénovaných modelů pomocí omezeného počtu příkladů

```python
# Jednoduchá implementace Prototypových sítí pro Few-Shot Learning
import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np

class EmbeddingNetwork(nn.Module):
    def __init__(self, input_dim=28*28, hidden_dim=64, output_dim=64):
        super(EmbeddingNetwork, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)
        
    def forward(self, x):
        x = x.view(x.size(0), -1)  # Zploštění vstupu
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x

class PrototypicalNetwork:
    def __init__(self, embedding_network):
        self.embedding_network = embedding_network
        
    def calculate_prototypes(self, support_set, support_labels):
        # Převod štítků na one-hot kódování
        unique_labels = torch.unique(support_labels)
        prototypes = []
        
        for label in unique_labels:
            # Získání embeddingů pro tuto třídu
            mask = support_labels == label
            class_embeddings = self.embedding_network(support_set[mask])
            # Výpočet prototypu (průměrný embedding)
            prototype = torch.mean(class_embeddings, dim=0)
            prototypes.append(prototype)
            
        return torch.stack(prototypes)
    
    def classify(self, query_set, support_set, support_labels):
        # Ujistíme se, že model je v režimu vyhodnocování
        self.embedding_network.eval()
        
        # Výpočet prototypů tříd
        prototypes = self.calculate_prototypes(support_set, support_labels)
        
        # Získání embeddingů pro dotazovací sadu
        query_embeddings = self.embedding_network(query_set)
        
        # Výpočet vzdáleností k prototypům
        distances = torch.cdist(query_embeddings, prototypes)
        
        # Vrácení predikované třídy (nejmenší vzdálenost)
        return torch.argmin(distances, dim=1)
```

## 5. Základní modely a promptování

Moderní základní modely (jako GPT-4, CLIP nebo BERT) vynikají v zero-shot a few-shot learningu díky efektivnímu předtrénování a návrhu promptů.

### Techniky promptování:

1. **Zero-shot promptování**: Přímé požádání modelu o provedení úlohy bez příkladů
2. **Few-shot promptování**: Zahrnutí několika příkladů do promptu
3. **Chain-of-thought promptování**: Vedení rozhodovacího procesu modelu
4. **In-context learning**: Poskytnutí příkladů v kontextovém okně

```python

model = GPT2LMHeadModel.from_pretrained("gpt2-large")

# Zero-shot promptování
def zero_shot_prompt(instruction, input_text):
    prompt = f"{instruction}\nVstup: {input_text}\nVýstup:"
    input_ids = tokenizer(prompt, return_tensors="pt").input_ids
    
    # Generování odpovědi
    output = model.generate(
        input_ids, 
        max_length=100, 
        num_return_sequences=1, 
        temperature=0.7,
        pad_token_id=tokenizer.eos_token_id
    )
    
    response = tokenizer.decode(output[0], skip_special_tokens=True)
    return response.split("Výstup:")[1].strip()

# Few-shot promptování
def few_shot_prompt(instruction, examples, input_text):
    # Formátování příkladů
    formatted_examples = ""
```

```python
from transformers import CLIPProcessor, CLIPModel
import requests
from PIL import Image

def zero_shot_image_classification(image_url, candidate_labels):
    # Načtení modelu a procesoru
    model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32")
    processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")
    
    # Formátování kandidátních štítků pro CLIP
    text_inputs = [f"fotografie {label}" for label in candidate_labels]
    
    # Načtení a zpracování obrázku
    image = Image.open(requests.get(image_url, stream=True).raw)
    inputs = processor(text=text_inputs, images=image, return_tensors="pt", padding=True)
    
    # Získání predikce
    outputs = model(**inputs)
    probs = outputs.logits_per_image.softmax(dim=1)[0]
    
    # Vrácení výsledků jako slovník
    results = [{"label": label, "score": score.item()} 
              for label, score in zip(candidate_labels, probs)]
    return sorted(results, key=lambda x: x["score"], reverse=True)
```

## 7. Implementace Few-shot learningu s PyTorch

Níže je implementace přístupu few-shot learningu využívající Prototypové sítě:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torchvision import transforms, datasets

# Definice siamské sítě pro few-shot learning
class SiameseNetwork(nn.Module):
    def __init__(self):
        super(SiameseNetwork, self).__init__()
        self.conv1 = nn.Conv2d(1, 64, 10)  # Předpokládáme obrázky ve stylu MNIST (černobílé)
        self.conv2 = nn.Conv2d(64, 128, 7)
        self.conv3 = nn.Conv2d(128, 128, 4)
        self.conv4 = nn.Conv2d(128, 256, 4)
        self.fc1 = nn.Linear(256 * 6 * 6, 4096)
        self.fc2 = nn.Linear(4096, 128)
        
        # Pooling a aktivace
        self.pool = nn.MaxPool2d(2, 2)
        
    def forward_one(self, x):
        x = F.relu(self.conv1(x))
        x = self.pool(x)
        x = F.relu(self.conv2(x))
        x = self.pool(x)
        x = F.relu(self.conv3(x))
        x = F.relu(self.conv4(x))
        x = x.view(x.size()[0], -1)
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x
    
    def forward(self, input1, input2):
        output1 = self.forward_one(input1)
        output2 = self.forward_one(input2)
        return output1, output2

# Kontrastivní ztrátová funkce
class ContrastiveLoss(nn.Module):
    def __init__(self, margin=1.0):
        super(ContrastiveLoss, self).__init__()
        self.margin = margin
    
    def forward(self, output1, output2, label):
        # Euklidovská vzdálenost
        euclidean_distance = F.pairwise_distance(output1, output2)
        
        # Kontrastivní ztráta
        loss_contrastive = torch.mean(
            (1-label) * torch.pow(euclidean_distance, 2) +  # Podobné páry: tlačit k sobě
            (label) * torch.pow(torch.clamp(self.margin - euclidean_distance, min=0.0), 2)  # Nepodobné páry: odtáhnout od sebe
        )
        
        return loss_contrastive

# Funkce pro provedení few-shot learningu
def few_shot_learning_demo():
    # Nastavení
    model = SiameseNetwork()
    criterion = ContrastiveLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.0005)
    
    print("Model a optimalizátor inicializovány")
    print("Poznámka: Toto je zjednodušený příklad. Skutečná implementace by zahrnovala:")
    print("1. Vytvoření datasetu s podpůrnými a dotazovacími sadami")
    print("2. Trénovací smyčku pro siamskou síť")
    print("3. Few-shot vyhodnocení na nových třídách")
    
    # V praxi byste:
    # 1. Natrénovali siamskou síť na základním datasetu
    # 2. Použili natrénovanou síť pro výpočet embeddingů pro podpůrné a dotazovací obrázky
    # 3. Provedli klasifikaci pomocí nejbližších sousedů v prostoru embeddingů
    
    return model, criterion, optimizer
```

## 9. Výzvy a budoucí směry

Navzdory svému potenciálu čelí zero-shot a few-shot learning několika výzvám:

1. **Doménová mezera**: Výkon klesá, když se testovací domény výrazně liší od trénovacích domén
2. **Zesilování předpojatosti**: Modely mohou zesilovat předpojatosti přítomné v předtrénovaných datech
3. **Složitost vyhodnocení**: Obtížnost spravedlivého hodnocení zero/few-shot schopností
4. **Inženýrství promptů**: Nalezení optimálních promptů často vyžaduje odbornost a metodu pokus-omyl
5. **Požadavky na zdroje**: Současné přístupy často spoléhají na velmi velké modely

Budoucí směry výzkumu zahrnují:
- Efektivnější architektury, které vyžadují méně výpočetních zdrojů
- Lepší metody pro zobecňování napříč doménami
- Lepší teoretické porozumění few-shot zobecnění
- Kombinace zero-shot přístupů s aktivním učením

## 10. Shrnutí

Zero-shot a few-shot learning představují výkonná paradigmata v moderním hlubokém učení:

- **Zero-shot learning** umožňuje modelům rozpoznávat nebo provádět úlohy s třídami/koncepty, které nikdy nebyly součástí tréninku
- **Few-shot learning** umožňuje modelům rychle se přizpůsobit novým úlohám s minimem příkladů
- **Klíčové přístupy** zahrnují metody založené na metrikách, embeddingové prostory, meta-učení a základní modely s promptováním
- **Základní modely** jako GPT, CLIP a T5 prokázaly pozoruhodné zero-shot a few-shot schopnosti
- **Implementace** je stále dostupnější prostřednictvím knihoven jako Hugging Face Transformers
- **Aplikace** sahají od počítačového vidění a NLP až po objevování léků a moderování obsahu
- **Výzvy přetrvávají** v adaptaci domén, zmírnění předpojatosti a efektivitě zdrojů

Tyto přístupy jsou zásadní pro budoucnost umělé inteligence, protože nás přibližují k lidské schopnosti učit se koncepty z minimálního počtu příkladů a aplikovat znalosti napříč doménami.
