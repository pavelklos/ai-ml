## Introduction to Word Embeddings

Word embeddings are dense vector representations of words in a continuous vector space where semantically similar words are mapped to nearby points. Unlike traditional one-hot encoding which represents words as sparse vectors, word embeddings capture meaningful semantic relationships between words.

**Key benefits of word embeddings:**
- Capture semantic relationships between words
- Allow mathematical operations on words (e.g., king - man + woman = queen)
- Reduce dimensionality compared to one-hot encoding
- Enable transfer learning in NLP tasks

## Word2Vec and GloVe Models

Two of the most popular word embedding algorithms are Word2Vec (proposed by Google) and GloVe (Global Vectors for Word Representation, developed at Stanford).

### Word2Vec

Word2Vec uses two primary architectures:
- **CBOW (Continuous Bag of Words)**: Predicts the current word based on surrounding context words
- **Skip-gram**: Predicts surrounding context words given the current word


### GloVe Model

GloVe learns word embeddings by leveraging global word-word co-occurrence statistics.

```python
def load_glove_embeddings(filename, vocab_size=100000):
    """Load GloVe embeddings from file"""

                break
            values = line.split()
            word = values[0]
            vector = np.asarray(values[1:], dtype='float32')
            embeddings[word] = vector
    return embeddings

def find_closest_words(embeddings, word_vector, n=3):
    similarities = {}
    for word, vector in embeddings.items():
        similarity = cosine_similarity([word_vector], [vector])[0][0]
        similarities[word] = similarity
    return sorted(similarities.items(), key=lambda x: x[1], reverse=True)[:n]

# Test analogies
def analogy(embeddings, a, b, c, n=3):
    # a is to b as c is to ?
    a_vec = embeddings.get(a)
    b_vec = embeddings.get(b)
    c_vec = embeddings.get(c)
    
    if a_vec is None or b_vec is None or c_vec is None:
        return f"One or more words not in vocabulary: {a}, {b}, {c}"
    
    # d = b - a + c
    d_vec = b_vec - a_vec + c_vec
    
    result = find_closest_words(embeddings, d_vec, n+3)
    # Filter out input words
    result = [r for r in result if r[0] not in [a, b, c]][:n]
    return result
```

## Introduction to Language Models

Language models are statistical models that predict the probability of sequences of words. They are fundamental to many NLP tasks like machine translation, speech recognition, text generation, and more.

## N-gram Language Models

N-gram language models predict the next word based on the previous N-1 words.

```python
from collections import defaultdict
import random
import numpy as np

# Build n-gram language models
def build_ngram_model(sentences, n=2):
    # Initialize counters
    ngram_counts = defaultdict(Counter)
    context_counts = defaultdict(int)
    
    # Add start and end tokens
    padded_sentences = []
    for sentence in sentences:
        padded_sentence = ['<s>'] * (n-1) + sentence + ['</s>']
        padded_sentences.append(padded_sentence)
    
    # Count n-grams
    for sentence in padded_sentences:
        for i in range(len(sentence) - n + 1):
            ngram = tuple(sentence[i:i+n])
            context = tuple(sentence[i:i+n-1])
            next_word = sentence[i+n-1]
            
            ngram_counts[context][next_word] += 1
            context_counts[context] += 1
    
    # Convert to probabilities
    ngram_probs = defaultdict(dict)
    for context, next_word_counts in ngram_counts.items():
        for next_word, count in next_word_counts.items():
            ngram_probs[context][next_word] = count / context_counts[context]
    
    return ngram_probs

# Generate text using n-gram model
def generate_text(model, n=2, max_length=20, seed=None):
    # Start with n-1 start tokens
    if seed:
        text = seed.lower().split()
        # Ensure seed has n-1 tokens
        if len(text) < n-1:
            text = ['<s>'] * (n-1)
        else:
            text = text[-(n-1):]
    else:
        text = ['<s>'] * (n-1)
    
    # Generate text
    for _ in range(max_length):
        context = tuple(text[-(n-1):])
        
        if context not in model:
            break
            
        next_word_probs = model[context]
        next_word_candidates = list(next_word_probs.keys())
        next_word_probabilities = list(next_word_probs.values())
        
        next_word = np.random.choice(next_word_candidates, p=next_word_probabilities)
        
        if next_word == '</s>':
            break
            
        text.append(next_word)
    
    return ' '.join(text[n-1:])  # Remove start tokens

# Build bigram and trigram models
bigram_model = build_ngram_model(tokenized_sentences, n=2)
trigram_model = build_ngram_model(tokenized_sentences, n=3)

# Generate text with the models
print("Text generated with bigram model:")
for _ in range(3):
    print(generate_text(bigram_model, n=2, max_length=10))

print("\nText generated with trigram model:")
for _ in range(3):
    print(generate_text(trigram_model, n=3, max_length=10))

# Evaluate probabilities for specific sequences
def evaluate_sequence_probability(model, sequence, n=2):
    words = ['<s>'] * (n-1) + sequence.lower().split() + ['</s>']
    log_prob = 0
    
    for i in range(len(words) - n + 1):
        context = tuple(words[i:i+n-1])
        next_word = words[i+n-1]
        
        if context in model and next_word in model[context]:
            probability = model[context][next_word]
            log_prob += np.log(probability)
        else:
            return float('-inf')  # Unseen n-gram
    
    return log_prob

test_sequences = [
    "artificial intelligence is changing",
    "intelligence artificial changing is",
    "technology helps humans"
]

print("\nEvaluating sequence probabilities with trigram model:")
for sequence in test_sequences:
    log_prob = evaluate_sequence_probability(trigram_model, sequence, n=3)
    if log_prob == float('-inf'):
        print(f"'{sequence}' contains unseen trigrams")
    else:
        print(f"'{sequence}' log probability: {log_prob:.4f}")
```

## Evaluation Metrics for Language Models

Common metrics for evaluating language models include perplexity, BLEU score, and more task-specific metrics.

```python
import numpy as np
from nltk.translate.bleu_score import sentence_bleu, SmoothingFunction
import math

# Calculate perplexity of a language model
def calculate_perplexity(model, test_sentences, n=2):
    total_log_prob = 0
    total_words = 0
    
    for sentence in test_sentences:
        padded_sentence = ['<s>'] * (n-1) + sentence + ['</s>']
        
        for i in range(n-1, len(padded_sentence)):
            context = tuple(padded_sentence[i-(n-1):i])
            word = padded_sentence[i]
            
            # Calculate probability of this word given context
            if context in model and word in model[context]:
                probability = model[context][word]
                total_log_prob += math.log2(probability)
            else:
                # Smooth for unseen n-grams (simple add-1 smoothing for demonstration)
                # In practice, you'd use more sophisticated smoothing
                probability = 1 / (len(model) + 1)  # Unseen n-gram
                total_log_prob += math.log2(probability)
            
            total_words += 1
    
    # Calculate perplexity
    perplexity = 2 ** (-total_log_prob / total_words)
    return perplexity

# Calculate BLEU score for generated text
def calculate_bleu(reference, candidate):
    # Apply smoothing for short sequences
    smoothie = SmoothingFunction().method1
    return sentence_bleu([reference], candidate, smoothing_function=smoothie)

# Test perplexity calculation
```

## Summary

Word embeddings and language models are foundational components of modern natural language processing:

1. **Word Embeddings** capture semantic relationships between words by representing them as dense vectors in a continuous space, offering significant advantages over traditional one-hot encoding.

2. **Word2Vec** and **GloVe** are popular algorithms for creating word embeddings, with Word2Vec using predictive methods (CBOW and Skip-gram) and GloVe leveraging global word co-occurrence statistics.

3. **Pre-trained Embeddings** enable transfer learning in NLP by providing ready-to-use word representations trained on large text corpora, which can be used directly or fine-tuned for specific tasks.

4. **Custom Embeddings** can be trained for domain-specific applications to capture specialized semantic relationships not reflected in general-purpose embeddings.

5. **Language Models** predict the probability of sequences of words and serve as the foundation for many NLP tasks, from text generation to machine translation.

6. **N-gram Models** use simple counting statistics to predict the next word based on the previous N-1 words, but struggle with data sparsity and long-range dependencies.

7. **Neural Language Models** overcome many limitations of n-gram models by using neural networks to learn distributed representations and capture more complex patterns.

8. **Evaluation Metrics** like perplexity and BLEU score help assess the quality of language models for different applications.

9. **Applications** of word embeddings and language models span many NLP tasks, including sentiment analysis, text generation, document classification, and named entity recognition.

Word embeddings and language models have revolutionized NLP by enabling machines to develop a more nuanced understanding of human language, forming the building blocks for increasingly sophisticated language technologies. Recent advances in transformer-based models (like BERT and GPT) build upon these foundations, pushing the boundaries of what's possible in natural language understanding and generation.
