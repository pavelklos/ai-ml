## Introduction

Loss functions are fundamental components in deep learning that quantify the difference between predicted outputs and actual target values. They serve as optimization targets during model training, with the goal of minimizing this difference to improve model performance.

The choice of loss function significantly impacts:
- Model convergence speed
- Final model accuracy
- Ability to handle specific data characteristics (e.g., outliers, imbalanced classes)
- Problem-specific objectives

This guide explores various loss functions, their mathematical formulations, implementation in popular frameworks, and appropriate applications for different deep learning tasks.

## Regression Loss Functions

Regression loss functions are used when predicting continuous values, such as price, temperature, or any other numerical value.

### Mean Squared Error (MSE)

**Definition**: MSE is the average of squared differences between predicted and actual values.

**Mathematical formula**:
```
MSE = (1/n) * Σ(y_true - y_pred)²
```

**When to use**:
- Standard loss function for regression problems
- When larger errors should be penalized more heavily
- When the data has relatively few outliers

**Implementation**:

```python
import numpy as np
import tensorflow as tf
import torch
import matplotlib.pyplot as plt

# Manual implementation
def mse_manual(y_true, y_pred):
    return np.mean(np.square(y_true - y_pred))

# TensorFlow/Keras implementation
y_true = tf.constant([[1.0, 2.0], [3.0, 4.0]])
y_pred = tf.constant([[1.1, 1.8], [2.8, 3.9]])

mse_tf = tf.keras.losses.MeanSquaredError()
mse_tf_result = mse_tf(y_true, y_pred)
print(f"TensorFlow MSE: {mse_tf_result.numpy()}")

# PyTorch implementation
y_true_pt = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
y_pred_pt = torch.tensor([[1.1, 1.8], [2.8, 3.9]])

mse_pt = torch.nn.MSELoss()
mse_pt_result = mse_pt(y_pred_pt, y_true_pt)
print(f"PyTorch MSE: {mse_pt_result.item()}")
```

### Mean Absolute Error (MAE)

**Definition**: MAE is the average of absolute differences between predicted and actual values.

**Mathematical formula**:
```
MAE = (1/n) * Σ|y_true - y_pred|
```

**When to use**:
- When you want errors to scale linearly (not quadratically as in MSE)
- When your data contains outliers
- When the exact precision is not as important as general trend

**Implementation**:

```python
# Manual implementation
def mae_manual(y_true, y_pred):
    return np.mean(np.abs(y_true - y_pred))

# TensorFlow/Keras implementation
mae_tf = tf.keras.losses.MeanAbsoluteError()
mae_tf_result = mae_tf(y_true, y_pred)
print(f"TensorFlow MAE: {mae_tf_result.numpy()}")

# PyTorch implementation
mae_pt = torch.nn.L1Loss()
mae_pt_result = mae_pt(y_pred_pt, y_true_pt)
print(f"PyTorch MAE: {mae_pt_result.item()}")
```

### Huber Loss

**Definition**: Huber loss combines the best properties of MSE and MAE by being quadratic for small errors and linear for large errors, making it less sensitive to outliers than MSE.

**Mathematical formula**:
```
Huber(y, f(x)) = 0.5(y - f(x))² if |y - f(x)| ≤ δ
                  δ|y - f(x)| - 0.5δ² otherwise
```
where δ is a hyperparameter that controls the transition point.

**When to use**:
- When your data contains outliers but you still want to benefit from MSE for small errors
- When you need a differentiable loss function that is less sensitive to outliers

**Implementation**:

```python
# Manual implementation
def huber_manual(y_true, y_pred, delta=1.0):
    error = y_true - y_pred
    is_small_error = np.abs(error) <= delta
    squared_loss = 0.5 * np.square(error)
    linear_loss = delta * (np.abs(error) - 0.5 * delta)
    return np.mean(np.where(is_small_error, squared_loss, linear_loss))

# TensorFlow/Keras implementation
huber_tf = tf.keras.losses.Huber(delta=1.0)
huber_tf_result = huber_tf(y_true, y_pred)
print(f"TensorFlow Huber Loss: {huber_tf_result.numpy()}")

# PyTorch implementation
huber_pt = torch.nn.HuberLoss(delta=1.0)
huber_pt_result = huber_pt(y_pred_pt, y_true_pt)
print(f"PyTorch Huber Loss: {huber_pt_result.item()}")

# Visualize the different regression losses
x = np.linspace(-3, 3, 1000)
plt.figure(figsize=(10, 6))
plt.plot(x, x**2, label='MSE')
plt.plot(x, np.abs(x), label='MAE')
plt.plot(x, np.where(np.abs(x) <= 1, 0.5*x**2, np.abs(x)-0.5), label='Huber (δ=1)')
plt.grid(True)
plt.legend()
plt.title('Comparison of Regression Loss Functions')
plt.xlabel('Error (y_true - y_pred)')
plt.ylabel('Loss')
plt.show()
```

### Log-cosh Loss

**Definition**: Log-cosh loss is the logarithm of the hyperbolic cosine of the prediction error.

**Mathematical formula**:
```
Log-cosh = Σ log(cosh(y_pred - y_true))
```

**When to use**:
- When you need a loss function that is smooth everywhere
- As an alternative to Huber loss with twice differentiability
- For regression tasks where MSE is too sensitive to outliers

**Implementation**:

```python
# Manual implementation
def log_cosh_manual(y_true, y_pred):
    return np.mean(np.log(np.cosh(y_pred - y_true)))

# TensorFlow/Keras implementation
def log_cosh_tf(y_true, y_pred):
    return tf.reduce_mean(tf.math.log(tf.math.cosh(y_pred - y_true)))

log_cosh_tf_result = log_cosh_tf(y_true, y_pred)
print(f"TensorFlow Log-cosh Loss: {log_cosh_tf_result.numpy()}")

# PyTorch implementation
def log_cosh_pt(y_pred, y_true):
    return torch.mean(torch.log(torch.cosh(y_pred - y_true)))

log_cosh_pt_result = log_cosh_pt(y_pred_pt, y_true_pt)
print(f"PyTorch Log-cosh Loss: {log_cosh_pt_result.item()}")
```

## Classification Loss Functions

Classification loss functions are used when predicting categorical outputs, such as class membership.

### Binary Cross-Entropy

**Definition**: Binary cross-entropy measures the performance of a classification model whose output is a probability value between 0 and 1.

**Mathematical formula**:
```
BCE = -Σ(y_true * log(y_pred) + (1 - y_true) * log(1 - y_pred))
```

**When to use**:
- For binary classification problems
- When your model outputs probabilities (through a sigmoid activation)

**Implementation**:

```python
# Create sample data
binary_y_true = tf.constant([[0], [1], [1], [0]])
binary_y_pred = tf.constant([[0.1], [0.7], [0.8], [0.2]])  # Predicted probabilities

# Manual implementation
def binary_crossentropy_manual(y_true, y_pred, epsilon=1e-7):
    # Clip predictions to avoid log(0)
    y_pred = np.clip(y_pred, epsilon, 1 - epsilon)
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

# TensorFlow/Keras implementation
bce_tf = tf.keras.losses.BinaryCrossentropy()
bce_tf_result = bce_tf(binary_y_true, binary_y_pred)
print(f"TensorFlow Binary Cross-Entropy: {bce_tf_result.numpy()}")

# PyTorch implementation
binary_y_true_pt = torch.tensor([[0.0], [1.0], [1.0], [0.0]])
binary_y_pred_pt = torch.tensor([[0.1], [0.7], [0.8], [0.2]])

bce_pt = torch.nn.BCELoss()
bce_pt_result = bce_pt(binary_y_pred_pt, binary_y_true_pt)
print(f"PyTorch Binary Cross-Entropy: {bce_pt_result.item()}")
```

### Categorical Cross-Entropy

**Definition**: Categorical cross-entropy is used for multi-class classification when targets are one-hot encoded.

**Mathematical formula**:
```
CCE = -Σ Σ(y_true_ij * log(y_pred_ij))
```
where i indexes examples and j indexes classes.

**When to use**:
- For multi-class classification problems
- When class labels are one-hot encoded
- When model outputs a probability distribution (softmax)

**Implementation**:

```python
# Create sample data
cat_y_true = tf.constant([[0, 1, 0], [0, 0, 1], [1, 0, 0]])  # One-hot encoded
cat_y_pred = tf.constant([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]])  # Class probabilities

# TensorFlow/Keras implementation
cce_tf = tf.keras.losses.CategoricalCrossentropy()
cce_tf_result = cce_tf(cat_y_true, cat_y_pred)
print(f"TensorFlow Categorical Cross-Entropy: {cce_tf_result.numpy()}")

# PyTorch implementation
cat_y_true_pt = torch.tensor([[0, 1, 0], [0, 0, 1], [1, 0, 0]], dtype=torch.float32)
cat_y_pred_pt = torch.tensor([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]], dtype=torch.float32)

cce_pt = torch.nn.CrossEntropyLoss()
# PyTorch expects logits, not probabilities, so we need to adjust or use log_softmax
# Here we'll use the direct loss function for simplicity
cce_pt_result = -torch.sum(cat_y_true_pt * torch.log(cat_y_pred_pt)) / cat_y_true_pt.size(0)
print(f"PyTorch Categorical Cross-Entropy: {cce_pt_result.item()}")
```

### Sparse Categorical Cross-Entropy

**Definition**: Similar to categorical cross-entropy, but targets are provided as integer indices rather than one-hot encoded vectors.

**When to use**:
- For multi-class classification problems
- When class labels are integers (not one-hot encoded)
- To save memory when dealing with many classes

**Implementation**:

```python
# Create sample data - sparse labels
sparse_y_true = tf.constant([1, 2, 0])  # Integer class indices
sparse_y_pred = tf.constant([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]])  # Class probabilities

# TensorFlow/Keras implementation
scce_tf = tf.keras.losses.SparseCategoricalCrossentropy()
scce_tf_result = scce_tf(sparse_y_true, sparse_y_pred)
print(f"TensorFlow Sparse Categorical Cross-Entropy: {scce_tf_result.numpy()}")

# PyTorch implementation
sparse_y_true_pt = torch.tensor([1, 2, 0])  # Integer class indices
sparse_y_pred_pt = torch.tensor([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]], dtype=torch.float32)

# PyTorch CrossEntropyLoss combines log_softmax and NLLLoss, expects logits not probabilities
scce_pt = torch.nn.CrossEntropyLoss()
# We'll use log probabilities instead of logits for simplicity
scce_pt_result = scce_pt(torch.log(sparse_y_pred_pt), sparse_y_true_pt)
print(f"PyTorch Sparse Categorical Cross-Entropy: {scce_pt_result.item()}")
```

### Focal Loss

**Definition**: Focal loss is designed to address class imbalance by down-weighting easy examples and focusing training on hard negatives.

**Mathematical formula**:
```
FL(pt) = -α(1-pt)ᵧ * log(pt)
```
where pt is the predicted probability for the true class, α is a balancing parameter, and γ is a focusing parameter.

**When to use**:
- For classification problems with severe class imbalance
- In object detection tasks (originated from RetinaNet)
- When false positives/negatives have different importance

**Implementation**:

```python
# TensorFlow/Keras implementation
def focal_loss_tf(y_true, y_pred, gamma=2.0, alpha=0.25):
    """
    Implementation of Focal Loss for binary classification
    """
    # Clip values to prevent division by zero
    epsilon = 1e-7
    y_pred = tf.clip_by_value(y_pred, epsilon, 1 - epsilon)
    
    # Calculate focal loss
    pt = tf.where(tf.equal(y_true, 1), y_pred, 1 - y_pred)
    focal_loss = -alpha * tf.pow(1 - pt, gamma) * tf.math.log(pt)
    return tf.reduce_mean(focal_loss)

focal_loss_result = focal_loss_tf(binary_y_true, binary_y_pred)
print(f"TensorFlow Focal Loss: {focal_loss_result.numpy()}")

# PyTorch implementation
def focal_loss_pt(y_pred, y_true, gamma=2.0, alpha=0.25):
    """
    Implementation of Focal Loss for binary classification in PyTorch
    """
    # Clip values to prevent division by zero
    epsilon = 1e-7
    y_pred = torch.clamp(y_pred, epsilon, 1 - epsilon)
    
    # Calculate focal loss
    pt = torch.where(y_true == 1, y_pred, 1 - y_pred)
    focal_loss = -alpha * (1 - pt).pow(gamma) * torch.log(pt)
    return torch.mean(focal_loss)

focal_loss_pt_result = focal_loss_pt(binary_y_pred_pt, binary_y_true_pt)
print(f"PyTorch Focal Loss: {focal_loss_pt_result.item()}")
```

## Probabilistic Loss Functions

Probabilistic loss functions are used when dealing with distributions rather than point estimates.

### Kullback-Leibler Divergence

**Definition**: KL divergence measures how one probability distribution diverges from a second expected distribution.

**Mathematical formula**:
```
KL(P||Q) = Σ P(x) * log(P(x)/Q(x))
```

**When to use**:
- For training variational autoencoders (VAEs)
- When comparing probability distributions
- In reinforcement learning for policy optimization

**Implementation**:

```python
# Create sample probability distributions
p = tf.constant([[0.1, 0.7, 0.2], [0.3, 0.2, 0.5]])
q = tf.constant([[0.2, 0.6, 0.2], [0.25, 0.25, 0.5]])

# TensorFlow implementation
kl_tf = tf.keras.losses.KLDivergence()
kl_tf_result = kl_tf(p, q)
print(f"TensorFlow KL Divergence: {kl_tf_result.numpy()}")

# PyTorch implementation
p_pt = torch.tensor([[0.1, 0.7, 0.2], [0.3, 0.2, 0.5]], dtype=torch.float32)
q_pt = torch.tensor([[0.2, 0.6, 0.2], [0.25, 0.25, 0.5]], dtype=torch.float32)

kl_pt = torch.nn.KLDivLoss(reduction='batchmean')
# PyTorch's KLDivLoss expects log-probabilities for q
kl_pt_result = kl_pt(torch.log(q_pt), p_pt)
print(f"PyTorch KL Divergence: {kl_pt_result.item()}")
```

### Jensen-Shannon Divergence

**Definition**: JS divergence is a symmetrized and smoothed version of KL divergence.

**Mathematical formula**:
```
JS(P||Q) = 0.5 * KL(P||M) + 0.5 * KL(Q||M)
```
where M = 0.5 * (P + Q)

**When to use**:
- When you need a symmetric divergence measure
- In GANs (Generative Adversarial Networks)
- When distributions may not share support

**Implementation**:

```python
def jensen_shannon_divergence_tf(p, q):
    m = 0.5 * (p + q)
    return 0.5 * tf.keras.losses.KLDivergence()(p, m) + 0.5 * tf.keras.losses.KLDivergence()(q, m)

js_tf_result = jensen_shannon_divergence_tf(p, q)
print(f"TensorFlow Jensen-Shannon Divergence: {js_tf_result.numpy()}")

def jensen_shannon_divergence_pt(p, q):
    m = 0.5 * (p + q)
    kl = torch.nn.KLDivLoss(reduction='batchmean')
    return 0.5 * kl(torch.log(m), p) + 0.5 * kl(torch.log(m), q)

js_pt_result = jensen_shannon_divergence_pt(p_pt, q_pt)
print(f"PyTorch Jensen-Shannon Divergence: {js_pt_result.item()}")
```

## Specialized Loss Functions

### Dice Loss for Segmentation

**Definition**: Dice loss is based on the Dice coefficient, which measures the overlap between two samples. It's commonly used for image segmentation tasks.

**Mathematical formula**:
```
Dice Loss = 1 - (2 * |X ∩ Y| / (|X| + |Y|))
```

**When to use**:
- For image segmentation tasks
- Especially with imbalanced classes (e.g., small objects in large images)
- When you want to directly optimize for IoU (Intersection over Union)

**Implementation**:

```python
def dice_loss_tf(y_true, y_pred, smooth=1):
    """Dice loss for binary segmentation"""
    y_true_flat = tf.reshape(y_true, [-1])
    y_pred_flat = tf.reshape(y_pred, [-1])
    intersection = tf.reduce_sum(y_true_flat * y_pred_flat)
    return 1 - ((2. * intersection + smooth) / 
                (tf.reduce_sum(y_true_flat) + tf.reduce_sum(y_pred_flat) + smooth))

# Create sample segmentation data
seg_true = tf.random.uniform((4, 16, 16, 1), 0, 2, dtype=tf.int32)
seg_pred = tf.random.uniform((4, 16, 16, 1), 0, 1, dtype=tf.float32)

# Calculate Dice loss
dice_loss_val = dice_loss_tf(tf.cast(seg_true, tf.float32), seg_pred)
print(f"Dice Loss: {dice_loss_val.numpy()}")

def dice_loss_pt(y_true, y_pred, smooth=1):
    """Dice loss for binary segmentation in PyTorch"""
    y_true_flat = y_true.reshape(-1)
    y_pred_flat = y_pred.reshape(-1)
    intersection = (y_true_flat * y_pred_flat).sum()
    return 1 - ((2. * intersection + smooth) / 
                (y_true_flat.sum() + y_pred_flat.sum() + smooth))
```

### Contrastive Loss

**Definition**: Contrastive loss is used in siamese networks to learn embeddings where similar samples are close and dissimilar samples are far apart.

**Mathematical formula**:
```
L = (1-Y) * 0.5 * D² + Y * 0.5 * max(0, margin - D)²
```
where D is the distance between embeddings, Y is 1 if samples are similar and 0 otherwise.

**When to use**:
- For metric learning and similarity learning
- Face recognition/verification
- When you want to learn embeddings for clustering

**Implementation**:

```python
def contrastive_loss_tf(y_true, pair_distances, margin=1.0):
    """
    Contrastive loss for siamese networks in TensorFlow
    y_true: Binary tensor indicating similar pairs (1) or dissimilar pairs (0)
    pair_distances: Tensor of L2 distances between pairs of embeddings
    """
    # Loss for similar pairs: encourage embeddings to be close
    similar_loss = y_true * tf.square(pair_distances)
    
    # Loss for dissimilar pairs: encourage embeddings to be at least margin apart
    dissimilar_loss = (1 - y_true) * tf.square(tf.maximum(margin - pair_distances, 0))
    
    return tf.reduce_mean(0.5 * (similar_loss + dissimilar_loss))

# Create sample data
pairs_y_true = tf.constant([1, 0, 1, 0])  # Similar/dissimilar pairs
pair_distances = tf.constant([0.2, 0.8, 0.3, 0.5])  # Distances between embeddings

cl_result = contrastive_loss_tf(pairs_y_true, pair_distances)
print(f"Contrastive Loss: {cl_result.numpy()}")

def contrastive_loss_pt(y_true, pair_distances, margin=1.0):
    """
    Contrastive loss for siamese networks in PyTorch
    """
    similar_loss = y_true * torch.pow(pair_distances, 2)
    dissimilar_loss = (1 - y_true) * torch.pow(torch.clamp(margin - pair_distances, min=0.0), 2)
    return torch.mean(0.5 * (similar_loss + dissimilar_loss))
```

### Triplet Loss

**Definition**: Triplet loss works by minimizing the distance between an anchor and a positive (both from the same class) while maximizing the distance between the anchor and a negative (from different classes).

**Mathematical formula**:
```
L = max(d(a, p) - d(a, n) + margin, 0)
```
where a is the anchor, p is the positive and n is the negative.

**When to use**:
- Face recognition
- Image retrieval
- When you have clear notions of similar/dissimilar examples
- When contrastive loss isn't providing enough context

**Implementation**:

```python
def triplet_loss_tf(anchor, positive, negative, margin=0.2):
    """
    Triplet loss in TensorFlow
    anchor, positive, negative: embeddings of anchor, positive, and negative examples
    """
    # Calculate distances
    pos_dist = tf.reduce_sum(tf.square(anchor - positive), axis=1)
    neg_dist = tf.reduce_sum(tf.square(anchor - negative), axis=1)
    
    # Compute triplet loss with margin
    basic_loss = pos_dist - neg_dist + margin
    loss = tf.maximum(basic_loss, 0.0)
    
    return tf.reduce_mean(loss)

# Create sample embeddings
anchor = tf.random.normal((4, 128))
positive = tf.random.normal((4, 128), mean=0.1)
negative = tf.random.normal((4, 128), mean=2.0)

tl_result = triplet_loss_tf(anchor, positive, negative)
print(f"Triplet Loss: {tl_result.numpy()}")

def triplet_loss_pt(anchor, positive, negative, margin=0.2):
    """
    Triplet loss in PyTorch
    """
    pos_dist = torch.sum(torch.pow(anchor - positive, 2), dim=1)
    neg_dist = torch.sum(torch.pow(anchor - negative, 2), dim=1)
    
    basic_loss = pos_dist - neg_dist + margin
    loss = torch.clamp(basic_loss, min=0.0)
    
    return torch.mean(loss)
```

## Custom Loss Functions

Sometimes predefined loss functions are not adequate for specific tasks. Both TensorFlow/Keras and PyTorch allow the creation of custom loss functions.

### Creating Custom Losses in TensorFlow/Keras

```python
@tf.keras.utils.register_keras_serializable()
class CustomLoss(tf.keras.losses.Loss):
    def __init__(self, alpha=0.4, **kwargs):
        super().__init__(**kwargs)
        self.alpha = alpha

    def call(self, y_true, y_pred):
        mae_loss = tf.keras.losses.MeanAbsoluteError()(y_true, y_pred)
        mse_loss = tf.keras.losses.MeanSquaredError()(y_true, y_pred)
        return self.alpha * mae_loss + (1 - self.alpha) * mse_loss
    
    def get_config(self):
        base_config = super().get_config()
        return {**base_config, "alpha": self.alpha}

# Simple function-based custom loss
def custom_loss_fn(y_true, y_pred, alpha=0.4):
    mae_loss = tf.keras.losses.MeanAbsoluteError()(y_true, y_pred)
    mse_loss = tf.keras.losses.MeanSquaredError()(y_true, y_pred)
    return alpha * mae_loss + (1 - alpha) * mse_loss

# Usage
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(10,)),
    tf.keras.layers.Dense(1)
])

# Using class-based custom loss
model.compile(optimizer='adam', loss=CustomLoss(alpha=0.3))

# Using function-based custom loss
model.compile(optimizer='adam', 
              loss=lambda y_true, y_pred: custom_loss_fn(y_true, y_pred, alpha=0.3))
```

### Creating Custom Losses in PyTorch

```python
class CustomLoss(torch.nn.Module):
    def __init__(self, alpha=0.4):
        super().__init__()
        self.alpha = alpha
        self.mae_loss = torch.nn.L1Loss()
        self.mse_loss = torch.nn.MSELoss()
        
    def forward(self, y_pred, y_true):
        mae = self.mae_loss(y_pred, y_true)
        mse = self.mse_loss(y_pred, y_true)
        return self.alpha * mae + (1 - self.alpha) * mse

# Function-based custom loss
def custom_loss_fn_pt(y_pred, y_true, alpha=0.4):
    mae_loss = torch.nn.functional.l1_loss(y_pred, y_true)
    mse_loss = torch.nn.functional.mse_loss(y_pred, y_true)
    return alpha * mae_loss + (1 - alpha) * mse_loss

# Usage
model = torch.nn.Sequential(
    torch.nn.Linear(10, 64),
    torch.nn.ReLU(),
    torch.nn.Linear(64, 1)
)

# Using class-based custom loss
criterion = CustomLoss(alpha=0.3)
optimizer = torch.optim.Adam(model.parameters())

# During training
def train(model, inputs, targets):
    model.train()
    optimizer.zero_grad()
    outputs = model(inputs)
    loss = criterion(outputs, targets)
    loss.backward()
    optimizer.step()
    return loss.item()
```

## Combining Multiple Loss Functions

Complex deep learning tasks often benefit from combining multiple loss functions. Here's how to create weighted combinations of losses:

```python
# TensorFlow/Keras example: Multi-task learning with multiple losses
inputs = tf.keras.Input(shape=(128,))
shared = tf.keras.layers.Dense(64, activation='relu')(inputs)

# Output branch for classification
classification_output = tf.keras.layers.Dense(10, activation='softmax', name='classification')(shared)

# Output branch for regression
regression_output = tf.keras.layers.Dense(1, name='regression')(shared)

model = tf.keras.Model(inputs=inputs, outputs=[classification_output, regression_output])

model.compile(
    optimizer='adam',
    loss={
        'classification': 'categorical_crossentropy',
        'regression': 'mse'
    },
    loss_weights={
        'classification': 1.0,
        'regression': 0.5
    },
    metrics={
        'classification': 'accuracy',
        'regression': 'mae'
    }
)

# PyTorch example
class MultiTaskModel(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.shared = torch.nn.Sequential(
            torch.nn.Linear(128, 64),
            torch.nn.ReLU()
        )
        self.classification_head = torch.nn.Linear(64, 10)
        self.regression_head = torch.nn.Linear(64, 1)
        
    def forward(self, x):
        shared_features = self.shared(x)
        classification_output = self.classification_head(shared_features)
        regression_output = self.regression_head(shared_features)
        return classification_output, regression_output

# Loss functions
classification_loss = torch.nn.CrossEntropyLoss()
regression_loss = torch.nn.MSELoss()

# Training loop with combined losses
def train_multi_task(model, inputs, class_targets, reg_targets):
    model.train()
    optimizer.zero_grad()
    class_outputs, reg_outputs = model(inputs)
    
    # Calculate individual losses
    c_loss = classification_loss(class_outputs, class_targets)
    r_loss = regression_loss(reg_outputs, reg_targets)
    
    # Combine losses with weights
    combined_loss = c_loss + 0.5 * r_loss
    
    combined_loss.backward()
    optimizer.step()
    
    return c_loss.item(), r_loss.item(), combined_loss.item()
```

## Loss Function Selection Guidelines

Choosing the right loss function is critical for model performance. Here are some guidelines:

1. **For regression tasks**:
   - MSE: When errors should be penalized quadratically
   - MAE: When outliers are present or errors should scale linearly
   - Huber/Log-cosh: For robust regression, balancing MSE and MAE properties

2. **For binary classification**:
   - Binary Cross-Entropy: Standard choice
   - Focal Loss: When class imbalance is severe

3. **For multi-class classification**:
   - Categorical Cross-Entropy: When classes are one-hot encoded
   - Sparse Categorical Cross-Entropy: When class labels are integers

4. **For image segmentation**:
   - Dice Loss: For balancing precision and recall
   - Weighted Cross-Entropy: For class imbalance

5. **For similarity learning**:
   - Contrastive Loss: For pairs of examples
   - Triplet Loss: For anchor-positive-negative triplets

6. **For sequence prediction**:
   - CTC Loss: When alignment is unknown
   - Custom sequence losses: For specific domain needs

### Object Detection

```python
# Simplified example of a custom loss for object detection inspired by YOLO
def yolo_custom_loss(y_true, y_pred, lambda_coord=5.0, lambda_noobj=0.5):
    """
    Simplified YOLO-style loss function
    
    Args:
        y_true: Ground truth boxes and classes
        y_pred: Predicted boxes and classes
        lambda_coord: Weight for coordinate predictions
        lambda_noobj: Weight for no-object predictions
        
    Returns:
        Combined loss for bounding boxes and classifications
    """
    # Extract components - in real YOLO this would be more complex
    # [batch, cell, cell, (x, y, w, h, confidence, classes)]
    
    # Presence of objects in each grid cell (1 if object center is in cell, 0 otherwise)
    object_mask = y_true[..., 4:5]
    
    # Coordinate loss (x, y, w, h) - only where objects exist
    coord_true = y_true[..., 0:4]
    coord_pred = y_pred[..., 0:4]
    
    # Scale coordinate losses by lambda_coord
    coord_loss = lambda_coord * object_mask * tf.reduce_sum(
        tf.square(coord_true - coord_pred), axis=-1, keepdims=True)
    
    # Confidence loss (objectness)
    conf_true = y_true[..., 4:5]
    conf_pred = y_pred[..., 4:5]
    
    # Object confidence loss
    obj_conf_loss = object_mask * tf.square(conf_true - conf_pred)
    
    # No-object confidence loss
    noobj_conf_loss = lambda_noobj * (1 - object_mask) * tf.square(conf_true - conf_pred)
    
    # Class probabilities loss - only where objects exist
    class_true = y_true[..., 5:]
    class_pred = y_pred[..., 5:]
    class_loss = object_mask * tf.reduce_sum(
        tf.square(class_true - class_pred), axis=-1, keepdims=True)
    
    # Sum all losses
    total_loss = tf.reduce_mean(coord_loss + obj_conf_loss + noobj_conf_loss + class_loss)
    
    return total_loss
```

```python
def cross_entropy_with_label_smoothing(y_true, y_pred, label_smoothing=0.1):
    confidence = 1.0 - label_smoothing
    y_true_smooth = y_true * confidence + (1 - y_true) * label_smoothing / (y_true.shape[-1] - 1)

# PyTorch example with nn.CrossEntropyLoss and label smoothing
class LabelSmoothingLoss(torch.nn.Module):
    def __init__(self, classes, smoothing=0.1, dim=-1):
        super(LabelSmoothingLoss, self).__init__()
        self.confidence = 1.0 - smoothing
        self.smoothing = smoothing
        self.cls = classes
        self.dim = dim

    def forward(self, pred, target):
        pred = pred.log_softmax(dim=self.dim)
        with torch.no_grad():
            # Create smooth target distribution
            true_dist = torch.zeros_like(pred)
            true_dist.fill_(self.smoothing / (self.cls - 1))
            true_dist.scatter_(1, target.data.unsqueeze(1), self.confidence)
        return torch.mean(torch.sum(-true_dist * pred, dim=self.dim))

# Usage
```

## Common Issues and Troubleshooting

1. **Vanishing or exploding gradients**:
   - Solution: Try different loss functions, gradient clipping, or loss scaling
   - Example: Replace sigmoid with ReLU for hidden layers

2. **Class imbalance**:
   - Solution: Use weighted cross-entropy, focal loss, or oversampling techniques

3. **Unstable training**:
   - Solution: Use label smoothing, batch normalization, or adjust learning rates

4. **Slow convergence**:
   - Solution: Choose an appropriate loss function for your data distribution

5. **Overfitting**:
   - Solution: Add regularization terms to your loss function (L1/L2)

```python
# Adding L2 regularization to custom loss function
def custom_loss_with_reg(y_true, y_pred, l2_reg=0.01):
    # Main loss term
    mse_loss = tf.reduce_mean(tf.square(y_true - y_pred))
    
    # L2 regularization term - collecting all model weights
    l2_loss = tf.add_n([tf.nn.l2_loss(v) for v in model.trainable_variables 
                        if 'bias' not in v.name]) * l2_reg
    
    return mse_loss + l2_loss
```
