# Úvod do Transfer Learningu

## 1. Co je Transfer Learning?

Transfer learning je technika strojového učení, která využívá znalosti získané při řešení jednoho problému k řešení jiného, ale příbuzného problému. V hlubokém učení to typicky znamená použití předtrénovaného modelu (natrénovaného na velkém datasetu) jako výchozího bodu pro model na novou úlohu. Tento přístup je obzvláště silný, když máte pro váš specifický problém omezené množství trénovacích dat.

Základní myšlenka je jednoduchá, ale hluboká: neuronové sítě se učí hierarchické příznaky, kde časné vrstvy zachycují základní vzory (hrany, textury), zatímco hlubší vrstvy zachycují složitější koncepty. Tyto základní vzory jsou často přenositelné napříč různými úlohami.

## 2. Proč používat Transfer Learning?

Transfer learning nabízí několik významných výhod:

- **Zkrácená doba tréninku**: Začátek s předtrénovanými váhami dramaticky zrychluje konvergenci
- **Menší potřeba dat**: Můžete dosáhnout dobrých výsledků s mnohem menšími datasety
- **Lepší výkon**: Často vede k vyšší přesnosti než trénování od nuly
- **Nižší výpočetní nároky**: Vyžaduje méně výpočetního výkonu než trénování kompletních modelů

## 3. Kdy používat Transfer Learning

Transfer learning je obzvláště efektivní, když:

- Vaše úloha má omezené množství trénovacích dat
- Předtrénovaný model byl natrénován na datech podobných vaší cílové úloze
- Chcete urychlit proces trénování
- Nemáte dostatečné výpočetní zdroje pro plné trénování

## 4. Typy Transfer Learningu

### 4.1 Extrakce příznaků

V tomto přístupu používáte předtrénovanou síť jako pevný extraktor příznaků. Vy:
1. Odstraníte finální klasifikační vrstvy
2. Zmrazíte všechny zbývající vrstvy (takže jejich váhy se nebudou aktualizovat)
3. Přidáte nové klasifikační vrstvy pro vaši specifickou úlohu
4. Trénujete pouze tyto nové vrstvy

### 4.2 Dolaďování (Fine-Tuning)

Při dolaďování nejen nahradíte a trénujete klasifikační vrstvy, ale také aktualizujete některé nebo všechny váhy v předtrénované síti, aby se lépe přizpůsobily nové úloze:

1. Začnete s předtrénovaným modelem
2. Nahradíte finální klasifikační vrstvy
3. Volitelně zmrazíte rané vrstvy (které zachycují obecnější příznaky)
4. Trénujete model s malou rychlostí učení pro doladění vah

## 5. Populární předtrénované modely

Mnoho modelů předtrénovaných na velkých datasetech jako ImageNet je dostupných:

- Rodina **ResNet** (ResNet-50, ResNet-101, atd.)
- Modely **VGG** (VGG16, VGG19)
- Modely **Inception**
- Rodina **EfficientNet**
- **MobileNet** pro mobilní aplikace
- **BERT**, série **GPT** pro NLP úlohy

## 6. Transfer Learning s TensorFlow/Keras

Podívejme se, jak implementovat transfer learning pomocí TensorFlow/Keras s předtrénovaným modelem ResNet50.

### 6.1 Příklad extrakce příznaků

```python
import tensorflow as tf
from tensorflow.keras.applications import ResNet50
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D
from tensorflow.keras.models import Model

# Načtení předtrénovaného modelu bez klasifikační hlavy
base_model = ResNet50(weights='imagenet', include_top=False, input_shape=(224, 224, 3))

# Zmrazení všech vrstev v základním modelu
for layer in base_model.layers:
    layer.trainable = False

# Přidání vlastní klasifikační hlavy
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(1024, activation='relu')(x)
predictions = Dense(10, activation='softmax')(x)  # 10 tříd v tomto příkladu

# Vytvoření nového modelu
model = Model(inputs=base_model.input, outputs=predictions)

# Kompilace modelu
model.compile(optimizer='adam', 
              loss='categorical_crossentropy', 
              metrics=['accuracy'])

# Vytvoření generátorů dat pro trénování a validaci
train_datagen = ImageDataGenerator(
    rescale=1./255,
    rotation_range=20,
    width_shift_range=0.2,
    height_shift_range=0.2,
    horizontal_flip=True)

test_datagen = ImageDataGenerator(rescale=1./255)

train_generator = train_datagen.flow_from_directory(
    'train_directory',
    target_size=(224, 224),
    batch_size=32,
    class_mode='categorical')

validation_generator = test_datagen.flow_from_directory(
    'validation_directory',
    target_size=(224, 224),
    batch_size=32,
    class_mode='categorical')

# Trénování modelu
history = model.fit(
    train_generator,
    steps_per_epoch=train_generator.samples // 32,
    epochs=10,
    validation_data=validation_generator,
    validation_steps=validation_generator.samples // 32)

# Uložení modelu
model.save('transfer_learning_model.h5')
```

## 7. Transfer Learning s PyTorch

Podívejme se, jak implementovat transfer learning v PyTorch s využitím předtrénovaného modelu ResNet.

### 7.1 Příklad extrakce příznaků

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, models, transforms
import matplotlib.pyplot as plt
import time
import copy

# Transformace dat
data_transforms = {
    'train': transforms.Compose([
        transforms.RandomResizedCrop(224),
        transforms.RandomHorizontalFlip(),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
    ]),
    'val': transforms.Compose([
        transforms.Resize(256),
        transforms.CenterCrop(224),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
    ]),
}

# Načtení dat
data_dir = 'data'
image_datasets = {x: datasets.ImageFolder(f'{data_dir}/{x}', data_transforms[x])
                  for x in ['train', 'val']}
dataloaders = {x: torch.utils.data.DataLoader(image_datasets[x], batch_size=32, shuffle=True, num_workers=4)
              for x in ['train', 'val']}
dataset_sizes = {x: len(image_datasets[x]) for x in ['train', 'val']}
class_names = image_datasets['train'].classes

device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")

def train_model(model, criterion, optimizer, num_epochs=25):
    since = time.time()
    best_model_wts = copy.deepcopy(model.state_dict())
    best_acc = 0.0

    for epoch in range(num_epochs):
        print(f'Epocha {epoch}/{num_epochs - 1}')
        print('-' * 10)

        # Každá epocha má trénovací a validační fázi
        for phase in ['train', 'val']:
            if phase == 'train':
                model.train()  # Nastavení modelu do režimu tréninku
            else:
                model.eval()   # Nastavení modelu do režimu vyhodnocování

            running_loss = 0.0
            running_corrects = 0

            # Iterace přes data
            for inputs, labels in dataloaders[phase]:
                inputs = inputs.to(device)
                labels = labels.to(device)

                # Vynulování gradientů parametrů
                optimizer.zero_grad()

                # Dopředný průchod
                with torch.set_grad_enabled(phase == 'train'):
                    outputs = model(inputs)
                    _, preds = torch.max(outputs, 1)
                    loss = criterion(outputs, labels)

                    # Zpětný průchod + optimalizace pouze v trénovací fázi
                    if phase == 'train':
                        loss.backward()
                        optimizer.step()

                # Statistiky
                running_loss += loss.item() * inputs.size(0)
                running_corrects += torch.sum(preds == labels.data)

            epoch_loss = running_loss / dataset_sizes[phase]
            epoch_acc = running_corrects.double() / dataset_sizes[phase]

            print(f'{phase} Ztráta: {epoch_loss:.4f} Přesnost: {epoch_acc:.4f}')

            # Hluboká kopie modelu
            if phase == 'val' and epoch_acc > best_acc:
                best_acc = epoch_acc
                best_model_wts = copy.deepcopy(model.state_dict())

        print()

    time_elapsed = time.time() - since
    print(f'Trénink dokončen za {time_elapsed // 60:.0f}m {time_elapsed % 60:.0f}s')
    print(f'Nejlepší validační přesnost: {best_acc:.4f}')

    # Načtení vah nejlepšího modelu
    model.load_state_dict(best_model_wts)
    return model

# Načtení předtrénovaného modelu
model_ft = models.resnet50(pretrained=True)

# Zmrazení celé sítě kromě poslední vrstvy
for param in model_ft.parameters():
    param.requires_grad = False

# Nahrazení finální plně propojené vrstvy
num_ftrs = model_ft.fc.in_features
model_ft.fc = nn.Linear(num_ftrs, len(class_names))

model_ft = model_ft.to(device)

criterion = nn.CrossEntropyLoss()

# Optimalizovány jsou pouze parametry poslední vrstvy
optimizer_ft = optim.SGD(model_ft.fc.parameters(), lr=0.001, momentum=0.9)

# Trénování a vyhodnocení
model_ft = train_model(model_ft, criterion, optimizer_ft, num_epochs=10)

# Uložení modelu
torch.save(model_ft.state_dict(), 'transfer_learning_model.pth')
```

### 7.2 Příklad dolaďování

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, models, transforms

# Načtení předtrénovaného modelu
model_ft = models.resnet50(pretrained=True)

# Nejprve zmrazíme všechny vrstvy
for param in model_ft.parameters():
    param.requires_grad = False

# Nahrazení finální plně propojené vrstvy
num_ftrs = model_ft.fc.in_features
model_ft.fc = nn.Linear(num_ftrs, len(class_names))

model_ft = model_ft.to(device)

# První fáze: trénování pouze klasifikátoru
criterion = nn.CrossEntropyLoss()
optimizer_ft = optim.SGD(model_ft.fc.parameters(), lr=0.001, momentum=0.9)

print("Fáze 1: Trénování pouze klasifikátoru...")
model_ft = train_model(model_ft, criterion, optimizer_ft, num_epochs=5)

# Druhá fáze: Doladění vybraných vrstev
# Rozmrazení některých vrstev pro doladění
ct = 0
for child in model_ft.children():
    ct += 1
    if ct > 7:  # Doladění několika posledních vrstev (upravte podle potřeby)
        for param in child.parameters():
            param.requires_grad = True

# Rekompilace s nižší rychlostí učení
optimizer_ft = optim.SGD(filter(lambda p: p.requires_grad, model_ft.parameters()),
                          lr=0.0001, momentum=0.9)

print("Fáze 2: Dolaďování modelu...")
model_ft = train_model(model_ft, criterion, optimizer_ft, num_epochs=10)

# Uložení doladěného modelu
torch.save(model_ft.state_dict(), 'fine_tuned_model.pth')
```

## 8. Praktický příklad: Transfer Learning pro vlastní klasifikaci květin

Implementujme kompletní řešení transfer learningu pro úlohu klasifikace květin:

```python
import tensorflow as tf
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras import layers, models
import matplotlib.pyplot as plt
import os
import numpy as np

# Stažení datasetu květin (TensorFlow Datasets)
import tensorflow_datasets as tfds
tfds.disable_progress_bar()

# Ruční rozdělení datasetu na trénovací, validační a testovací sady
split_weights = (8, 1, 1)
splits = tfds.Split.TRAIN.subsplit(weighted=split_weights)

# Načtení datasetu
(train_ds, validation_ds, test_ds), dataset_info = tfds.load(
    'tf_flowers', 
    split=splits,
    with_info=True,
    as_supervised=True)

# Získání názvů tříd
num_classes = dataset_info.features['label'].num_classes
class_names = dataset_info.features['label'].names

print(f"Počet tříd: {num_classes}")
print(f"Názvy tříd: {class_names}")

# Funkce pro předzpracování obrázků
def preprocess_image(image, label):
    image = tf.cast(image, tf.float32)
    image = tf.image.resize(image, (224, 224))
    image = image / 255.0  # Normalizace na [0,1]
    return image, label

# Aplikace předzpracování na datasety
batch_size = 32
train_ds = train_ds.map(preprocess_image).batch(batch_size).prefetch(buffer_size=tf.data.AUTOTUNE)
validation_ds = validation_ds.map(preprocess_image).batch(batch_size).prefetch(buffer_size=tf.data.AUTOTUNE)
test_ds = test_ds.map(preprocess_image).batch(batch_size).prefetch(buffer_size=tf.data.AUTOTUNE)

# Zobrazení několika vzorových obrázků
plt.figure(figsize=(10, 10))
for images, labels in train_ds.take(1):
    for i in range(9):
        plt.subplot(3, 3, i + 1)
        plt.imshow(images[i])
        plt.title(class_names[labels[i].numpy()])
        plt.axis('off')
plt.show()

# Vytvoření základního modelu z předtrénovaného modelu MobileNetV2
base_model = MobileNetV2(input_shape=(224, 224, 3),
                          include_top=False,
                          weights='imagenet')

# Zmrazení základního modelu
base_model.trainable = False

# Vytvoření nového modelu na vrcholu
model = models.Sequential([
    base_model,
    layers.GlobalAveragePooling2D(),
    layers.Dense(128, activation='relu'),
    layers.Dropout(0.2),
    layers.Dense(num_classes, activation='softmax')
])

model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

print(model.summary())

# Trénování modelu (fáze extrakce příznaků)
history = model.fit(
    train_ds,
    validation_data=validation_ds,
    epochs=10
)

# Vykreslení výsledků tréninku
acc = history.history['accuracy']
val_acc = history.history['val_accuracy']

loss = history.history['loss']
val_loss = history.history['val_loss']

plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(acc, label='Trénovací přesnost')
plt.plot(val_acc, label='Validační přesnost')
plt.legend(loc='lower right')
plt.title('Trénovací a validační přesnost')

plt.subplot(1, 2, 2)
plt.plot(loss, label='Trénovací ztráta')
plt.plot(val_loss, label='Validační ztráta')
plt.legend(loc='upper right')
plt.title('Trénovací a validační ztráta')
plt.show()

# Dolaďování
print("Dolaďování modelu...")

# Rozmrazení některých horních vrstev základního modelu
base_model.trainable = True
for layer in base_model.layers[:-20]:
    layer.trainable = False

# Kompilace s nižší rychlostí učení
model.compile(optimizer=tf.keras.optimizers.Adam(1e-5),
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# Pokračování v trénování s dolaďováním
history_fine = model.fit(
    train_ds,
    validation_data=validation_ds,
    epochs=10,
    initial_epoch=10  # Začít od poslední epochy předchozího tréninku
)

# Vyhodnocení modelu
loss, accuracy = model.evaluate(test_ds)
print(f"Testovací přesnost: {accuracy:.4f}")

# Funkce pro vytváření predikcí
def predict_image(model, img_path):
    img = tf.keras.preprocessing.image.load_img(
        img_path, target_size=(224, 224)
    )
    img_array = tf.keras.preprocessing.image.img_to_array(img)
    img_array = tf.expand_dims(img_array, 0) / 255.0
    
    predictions = model.predict(img_array)
    predicted_class = np.argmax(predictions[0])
    confidence = np.max(predictions[0])
    
    return predicted_class, confidence, class_names[predicted_class]

# Uložení modelu
model.save('flower_classifier.h5')
```

## 9. Vizualizace příznaků a Transfer Learning

Podívejme se, jak vizualizovat, co se model naučil během transfer learningu:

```python
import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.preprocessing import image
from tensorflow.keras.models import Model

# Načtení vašeho natrénovaného modelu
model = tf.keras.models.load_model('flower_classifier.h5')

# Vytvoření modelu pro extrakci příznaků
layer_outputs = [layer.output for layer in model.layers[0].layers[1:6]]
activation_model = Model(inputs=model.layers[0].input, outputs=layer_outputs)

# Načtení obrázku
img_path = 'cesta_k_obrazku_kvetiny.jpg'
img = image.load_img(img_path, target_size=(224, 224))
x = image.img_to_array(img)
x = np.expand_dims(x, axis=0)
x = x / 255.0

# Získání aktivací
activations = activation_model.predict(x)

# Vizualizace map příznaků z jedné z vrstev
layer_names = [layer.name for layer in model.layers[0].layers[1:6]]
images_per_row = 16

for layer_name, layer_activation in zip(layer_names, activations):
    n_features = layer_activation.shape[-1]
    size = layer_activation.shape[1]
    
    n_cols = n_features // images_per_row
    display_grid = np.zeros((size * n_cols, images_per_row * size))
    
    for col in range(n_cols):
        for row in range(images_per_row):
            channel_index = col * images_per_row + row
            if channel_index < n_features:
                channel_image = layer_activation[0, :, :, channel_index]
                channel_image -= channel_image.mean()
                channel_image /= channel_image.std() + 1e-5
                channel_image *= 64
                channel_image += 128
                channel_image = np.clip(channel_image, 0, 255).astype('uint8')
                display_grid[col * size : (col + 1) * size,
                             row * size : (row + 1) * size] = channel_image
    
    scale = 1. / size
    plt.figure(figsize=(scale * display_grid.shape[1],
                       scale * display_grid.shape[0]))
    plt.title(layer_name)
    plt.grid(False)
    plt.imshow(display_grid, aspect='auto', cmap='viridis')
    
plt.show()
```

## 10. Osvědčené postupy pro Transfer Learning

Zde jsou některé tipy pro efektivní transfer learning:

1. **Vyberte relevantní předtrénovaný model**: Vyberte model trénovaný na datech, která jsou podobná vašim cílovým datům
2. **Předzpracování obrázků**: Slaďte předzpracování s tím, které bylo použito během původního trénování modelu
3. **Postupné rozmrazování**: Místo rozmrazení všech vrstev najednou postupně rozmrazujte od shora dolů
4. **Použijte nižší rychlost učení pro dolaďování**: Typicky 10x menší než počáteční rychlost učení
5. **Augmentace dat**: Zvláště důležitá, když máte malý dataset
6. **Předčasné zastavení**: Sledujte validační metriky, abyste zabránili přeučení během dolaďování
7. **Vyzkoušejte různé strategie zmrazování**: Experimentujte se zmrazením různého počtu vrstev
8. **Použijte různé rychlosti učení pro různé vrstvy**: Nižší rychlosti pro předtrénované vrstvy, vyšší pro nové vrstvy

## 11. Výzvy v Transfer Learningu

Některé běžné výzvy a jak je řešit:

1. **Nesoulad domén**: Když jsou zdrojové a cílové domény příliš odlišné
   - Řešení: Použijte techniky adaptace domén nebo najděte vhodnější předtrénovaný model

2. **Katastrofální zapomínání**: Když dolaďování vymaže užitečné předtrénované znalosti
   - Řešení: Použijte postupné rozmrazování, vhodné rychlosti učení a regularizaci

3. **Přeučení**: Zvláště s malými datasety
   - Řešení: Silná regularizace, augmentace dat a předčasné zastavení

4. **Vstupní tvary**: Když mají vaše data jiné rozměry než předtrénovaný model
   - Řešení: Změňte velikost vstupů nebo upravte architekturu sítě

5. **Výpočetní zdroje**: Dolaďování velkých modelů může být náročné
   - Řešení: Začněte s extrakcí příznaků, použijte trénink se smíšenou přesností nebo vyzkoušejte menší modely

### 12.2 Destilace znalostí

Přenos znalostí z velkého předtrénovaného modelu do menšího:

```python
import tensorflow as tf
from tensorflow.keras.layers import Dense, Input
from tensorflow.keras.models import Model

# Učitelský model (předtrénovaný)
teacher = tf.keras.applications.ResNet50(weights='imagenet')

# Žákovský model (menší)
input_tensor = Input(shape=(224, 224, 3))
x = tf.keras.applications.MobileNetV2(include_top=False, weights='imagenet',
                                      input_tensor=input_tensor).output
x = tf.keras.layers.GlobalAveragePooling2D()(x)
x = Dense(1024, activation='relu')(x)
student_outputs = Dense(1000, activation='softmax')(x)
student = Model(inputs=input_tensor, outputs=student_outputs)

# Definice funkce ztráty pro destilaci
def distillation_loss(y_true, y_pred, teacher_logits, T=2.0, alpha=0.1):
    """
    Kombinovaná funkce ztráty pro destilaci znalostí
    y_true: pravdivé štítky
    y_pred: predikce žáka
    teacher_logits: predikce učitelského modelu
    T: teplota pro změkčení rozdělení pravděpodobnosti
    alpha: váha pro vyvážení tvrdých/měkkých cílů
    """
    hard_loss = tf.keras.losses.categorical_crossentropy(
        y_true, y_pred)
    
    soft_targets = tf.nn.softmax(teacher_logits / T)
    soft_prob = tf.nn.softmax(y_pred / T)
    soft_loss = tf.keras.losses.kullback_leibler_divergence(
        soft_targets, soft_prob) * (T**2)
    
    return alpha * hard_loss + (1 - alpha) * soft_loss

# Nastavení tréninku
student.compile(
    optimizer=tf.keras.optimizers.Adam(1e-4),
    loss=lambda y_true, y_pred: distillation_loss(
        y_true, y_pred, teacher.predict(x_input)),
    metrics=['accuracy']
)
```
