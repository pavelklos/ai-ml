## 1. Úvod do distribuovaného tréninku

Distribuovaný trénink je technika, která umožňuje trénovat modely hlubokého učení napříč více výpočetními zařízeními nebo počítači. S růstem velikosti modelů a datasetů se distribuovaný trénink stává nezbytným pro rychlejší trénování a zpracování modelů, které jsou příliš velké pro jedno zařízení.

```python
import tensorflow as tf
import torch
import torch.distributed as dist
import torch.multiprocessing as mp
import numpy as np
import os
import time
```

Hlavní výhody distribuovaného tréninku zahrnují:
- Zkrácení doby tréninku
- Možnost trénovat větší modely
- Schopnost zpracovat větší datasety
- Lepší využití zdrojů

## 2. Přístupy k paralelismu v hlubokém učení

Existují dva hlavní přístupy k distribuci pracovních zátěží hlubokého učení:

### Datový paralelismus
V datovém paralelismu je model replikován napříč více zařízeními, ale každé zařízení zpracovává různé dávky dat. Gradienty jsou následně synchronizovány pro aktualizaci modelu.

### Modelový paralelismus
V modelovém paralelismu jsou různé části modelu umístěny na různých zařízeních. To je užitečné, když je model příliš velký na to, aby se vešel na jedno zařízení.

Datový paralelismus je nejběžnějším přístupem pro distribuovaný trénink. Zde je způsob implementace v TensorFlow a PyTorch:

### TensorFlow datový paralelismus

```python
# TensorFlow datový paralelismus pomocí tf.distribute.Strategy

def tensorflow_data_parallelism():
    # Definice distribuční strategie (pro více GPU na jednom počítači)
    strategy = tf.distribute.MirroredStrategy()
    print(f"Počet zařízení: {strategy.num_replicas_in_sync}")
    
    # Definice modelu v rámci scope strategie
    with strategy.scope():
        model = tf.keras.Sequential([
            tf.keras.layers.Dense(256, activation='relu', input_shape=(784,)),
            tf.keras.layers.Dense(128, activation='relu'),
            tf.keras.layers.Dense(10, activation='softmax')
        ])
        
        model.compile(
            optimizer='adam',
            loss='sparse_categorical_crossentropy',
            metrics=['accuracy']
        )
    
    # Načtení dat (příklad MNIST)
    (x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()
    x_train = x_train.reshape(-1, 784).astype('float32') / 255.0
    x_test = x_test.reshape(-1, 784).astype('float32') / 255.0
    
    # Vytvoření datasetů
    train_dataset = tf.data.Dataset.from_tensor_slices((x_train, y_train)).batch(64)
    test_dataset = tf.data.Dataset.from_tensor_slices((x_test, y_test)).batch(64)
    
    # Trénování (automaticky využívá všechna dostupná zařízení)
    model.fit(train_dataset, epochs=5, validation_data=test_dataset)
    
    return model
```

### PyTorch datový paralelismus

```python
# PyTorch datový paralelismus pomocí DistributedDataParallel (DDP)

def setup(rank, world_size):
    """
    Inicializace distribuovaného prostředí.
    """
    os.environ['MASTER_ADDR'] = 'localhost'
    os.environ['MASTER_PORT'] = '12355'
    
    # Inicializace skupiny procesů
    dist.init_process_group("nccl" if torch.cuda.is_available() else "gloo", 
                           rank=rank, world_size=world_size)

def cleanup():
    """
    Ukončení distribuovaného prostředí.
    """
    dist.destroy_process_group()

class SimpleModel(torch.nn.Module):
    def __init__(self):
        super(SimpleModel, self).__init__()
        self.fc1 = torch.nn.Linear(784, 256)
        self.fc2 = torch.nn.Linear(256, 128)
        self.fc3 = torch.nn.Linear(128, 10)
        
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        return torch.log_softmax(self.fc3(x), dim=1)

def train(rank, world_size):
    # Inicializace distribuovaného prostředí
    setup(rank, world_size)
    
    # Nastavení zařízení pro tento proces
    device = torch.device(f"cuda:{rank}" if torch.cuda.is_available() else "cpu")
    
    # Vytvoření modelu a přesun na zařízení
    model = SimpleModel().to(device)
    
    # Zabalení modelu pro distribuované trénování
    ddp_model = torch.nn.parallel.DistributedDataParallel(model, 
                                                         device_ids=[rank] if torch.cuda.is_available() else None)
    
    # Definice ztrátové funkce a optimalizátoru
    loss_fn = torch.nn.CrossEntropyLoss()
    optimizer = torch.optim.Adam(ddp_model.parameters(), lr=0.001)
    
    # Vytvoření vzorových dat (skutečná implementace by použila DistributedSampler)
    # Pouze pro demonstrační účely
    x = torch.randn(100, 784).to(device)
    y = torch.randint(0, 10, (100,)).to(device)
    
    # Trénovací smyčka
    for epoch in range(5):
        ddp_model.train()
        outputs = ddp_model(x)
        loss = loss_fn(outputs, y)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        if rank == 0:
            print(f"Epocha {epoch}, Ztráta: {loss.item()}")
    
    # Ukončení
    cleanup()

def run_distributed_training():
    world_size = torch.cuda.device_count() if torch.cuda.is_available() else 1
    print(f"Používá se {world_size} zařízení pro distribuované trénování")
    
    # Spuštění více procesů (jeden na GPU)
    mp.spawn(
        train,
        args=(world_size,),
        nprocs=world_size,
        join=True
    )
```

## 4. Implementace modelového paralelismu

Modelový paralelismus je užitečný, když jsou modely příliš velké na to, aby se vešly na jedno zařízení.

```python
# Příklad modelového paralelismu v TensorFlow

def tensorflow_model_parallelism():
    # Jednoduchý příklad modelového paralelismu s TensorFlow
    gpus = tf.config.list_physical_devices('GPU')
    if len(gpus) < 2:
        print("Tento příklad vyžaduje alespoň 2 GPU")
        return
    
    # Omezení růstu paměti GPU
    for gpu in gpus:
        tf.config.experimental.set_memory_growth(gpu, True)
    
    # Vytvoření modelu rozděleného mezi dvě GPU
    with tf.device('/GPU:0'):
        inputs = tf.keras.layers.Input(shape=(784,))
        x = tf.keras.layers.Dense(2048, activation='relu')(inputs)
        x = tf.keras.layers.Dense(2048, activation='relu')(x)
    
    with tf.device('/GPU:1'):
        x = tf.keras.layers.Dense(1024, activation='relu')(x)
        outputs = tf.keras.layers.Dense(10, activation='softmax')(x)
    
    model = tf.keras.Model(inputs=inputs, outputs=outputs)
    model.compile(
        optimizer='adam',
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Generování umělých dat pro ukázku
    x_train = np.random.random((1000, 784))
    y_train = np.random.randint(0, 10, (1000,))
    
    # Trénování (model je rozdělen mezi dvě GPU)
    model.fit(x_train, y_train, epochs=3, batch_size=64)
    
    return model

# Příklad modelového paralelismu v PyTorch s paralelismem pipeline
def pytorch_pipeline_parallelism():
    # Toto je zjednodušená implementace
    # Skutečný pipeline paralelismus je složitější a obvykle používá knihovny
    
    class PipelineParallelModel(torch.nn.Module):
        def __init__(self):
            super(PipelineParallelModel, self).__init__()
            # První část modelu je na GPU:0
            self.part1 = torch.nn.Sequential(
                torch.nn.Linear(784, 1024),
                torch.nn.ReLU(),
                torch.nn.Linear(1024, 512),
                torch.nn.ReLU()
            ).to('cuda:0')
            
            # Druhá část modelu je na GPU:1
            self.part2 = torch.nn.Sequential(
                torch.nn.Linear(512, 256),
                torch.nn.ReLU(),
                torch.nn.Linear(256, 10)
            ).to('cuda:1')
        
        def forward(self, x):
            # Vstup je na GPU:0
            x = x.to('cuda:0')
            # Zpracování na GPU:0
            x = self.part1(x)
            # Přenos na GPU:1
            x = x.to('cuda:1')
            # Zpracování na GPU:1
            x = self.part2(x)
            return x
    
    # Kontrola, zda máme alespoň 2 GPU
    if torch.cuda.device_count() < 2:
        print("Tento příklad vyžaduje alespoň 2 GPU")
        return
    
    # Vytvoření modelu
    model = PipelineParallelModel()
    
    # Generování umělých dat pro ukázku
    x_train = torch.randn(100, 784)
    y_train = torch.randint(0, 10, (100,))
    
    loss_fn = torch.nn.CrossEntropyLoss()
    optimizer = torch.optim.Adam([
        {'params': model.part1.parameters()},
        {'params': model.part2.parameters()}
    ], lr=0.001)
    
    # Trénovací smyčka
    for epoch in range(3):
        outputs = model(x_train)
        loss = loss_fn(outputs, y_train.to('cuda:1'))  # Ztráta počítána na GPU:1
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        print(f"Epocha {epoch}, Ztráta: {loss.item()}")
    
    return model
```

## 7. Distribuované trénování pomocí PyTorch

PyTorch nabízí flexibilní možnosti distribuovaného tréninku:

```python
# PyTorch distribuované trénování s DistributedDataParallel

def pytorch_distributed_training():
    def train_worker(rank, world_size):
        # Inicializace distribuované skupiny procesů
        dist.init_process_group("nccl", rank=rank, world_size=world_size)
        
        # Konfigurace zařízení
        device = torch.device(f'cuda:{rank}')
        
        # Vytvoření modelu a přesun na zařízení
        model = torch.nn.Sequential(
            torch.nn.Linear(784, 256),
            torch.nn.ReLU(),
            torch.nn.Linear(256, 128),
            torch.nn.ReLU(),
            torch.nn.Linear(128, 10)
        ).to(device)
        
        # Zabalení modelu pomocí DistributedDataParallel
        ddp_model = torch.nn.parallel.DistributedDataParallel(
            model, device_ids=[rank])
        
        # Ztrátová funkce a optimalizátor
        criterion = torch.nn.CrossEntropyLoss()
        optimizer = torch.optim.Adam(ddp_model.parameters(), lr=0.001)
        
        # Distribuovaný sampler pro trénovací data
        train_dataset = torch.utils.data.TensorDataset(
            torch.randn(1000, 784),
            torch.randint(0, 10, (1000,))
        )
        train_sampler = torch.utils.data.distributed.DistributedSampler(
            train_dataset,
            num_replicas=world_size,
            rank=rank
        )
        train_loader = torch.utils.data.DataLoader(
            dataset=train_dataset,
            batch_size=32,
            shuffle=False,
            sampler=train_sampler
        )
        
        # Trénování modelu
        for epoch in range(3):
            train_sampler.set_epoch(epoch)
            
            for data, target in train_loader:
                data, target = data.to(device), target.to(device)
                
                # Dopředný průchod
                outputs = ddp_model(data)
                loss = criterion(outputs, target)
                
                # Zpětný průchod a optimalizace
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
                
            if rank == 0:
                print(f'Epocha {epoch}, Ztráta: {loss.item()}')
        
        # Ukončení
        dist.destroy_process_group()
    
    # Spuštění více procesů (jeden na GPU)
    world_size = torch.cuda.device_count()
    mp.spawn(
        train_worker,
        args=(world_size,),
        nprocs=world_size,
        join=True
    )
    
# PyTorch s Horovod pro distribuované trénování
def pytorch_horovod_example():
    """
    Horovod poskytuje jednodušší API pro distribuované trénování
    """
    import horovod.torch as hvd
    
    # Inicializace Horovod
    hvd.init()
    
    # Nastavení zařízení na lokální rank
    torch.cuda.set_device(hvd.local_rank())
    device = torch.device('cuda')
    
    # Vytvoření modelu
    model = torch.nn.Sequential(
        torch.nn.Linear(784, 256),
        torch.nn.ReLU(),
        torch.nn.Linear(256, 10)
    ).to(device)
    
    # Škálování rychlosti učení podle počtu GPU
    optimizer = torch.optim.Adam(model.parameters(), lr=0.001 * hvd.size())
    
    # Broadcast parametrů z ranku 0 do všech ostatních procesů
    hvd.broadcast_parameters(model.state_dict(), root_rank=0)
    hvd.broadcast_optimizer_state(optimizer, root_rank=0)
    
    # Zabalení optimalizátoru pomocí Horovod Distributed Optimizer
    optimizer = hvd.DistributedOptimizer(
        optimizer, named_parameters=model.named_parameters()
    )
    
    # Vytvoření datasetu a distribuovaného sampleru
    train_dataset = torch.utils.data.TensorDataset(
        torch.randn(1000, 784),
        torch.randint(0, 10, (1000,))
    )
    train_sampler = torch.utils.data.distributed.DistributedSampler(
        train_dataset, num_replicas=hvd.size(), rank=hvd.rank()
    )
    train_loader = torch.utils.data.DataLoader(
        train_dataset, batch_size=32, sampler=train_sampler
    )
    
    # Trénovací smyčka
    for epoch in range(3):
        for data, target in train_loader:
            data, target = data.to(device), target.to(device)
            
            optimizer.zero_grad()
            output = model(data)
            loss = torch.nn.functional.cross_entropy(output, target)
            loss.backward()
            optimizer.step()
            
        # Tisk metrik na ranku 0
        if hvd.rank() == 0:
            print(f'Epocha {epoch}, Ztráta: {loss.item()}')
```

## 8. Řešení komunikační režie

Komunikace mezi zařízeními se může stát úzkým hrdlem při distribuovaném trénování:

```python
def communication_overhead_strategies():
    """
    Strategie pro řízení komunikační režie při distribuovaném trénování:
    
    1. Akumulace gradientů
    2. Komprese gradientů
    3. Trénování s velkými dávkami
    4. Optimalizovaná kolektivní komunikace
    """
    
    # Příklad akumulace gradientů s PyTorch
    def gradient_accumulation_example():
        model = torch.nn.Linear(10, 2)
        optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
        
        # Hyperparametry
        accumulation_steps = 4  # Akumulace gradientů přes 4 dávky
        
        # Trénovací smyčka
        for i in range(100):  # 100 dávek
            # Dopředný průchod s malou dávkou
            inputs = torch.randn(8, 10)  # Malá velikost dávky 8
            targets = torch.randint(0, 2, (8,))
            outputs = model(inputs)
            loss = torch.nn.functional.cross_entropy(outputs, targets)
            
            # Škálování ztráty pro zohlednění akumulace
            loss = loss / accumulation_steps
            
            # Zpětný průchod (akumulace gradientů)
            loss.backward()
            
            # Aktualizace vah pouze jednou za accumulation_steps dávek
            if (i + 1) % accumulation_steps == 0:
                optimizer.step()
                optimizer.zero_grad()
    
    # Příklad konceptu komprese gradientů
    def gradient_compression_concept():
        """
        Techniky komprese gradientů:
        1. Kvantizace: Snížení přesnosti (např. float32 na float16)
        2. Sparsifikace: Komunikace pouze významných gradientů
        3. Error-feedback: Sledování akumulovaných chyb z komprese
        """
        # Toto je konceptuální příklad - skutečná implementace by použila
        # knihovny jako DeepSpeed, Horovod s kompresí atd.
        
        def sparsify_gradients(gradients, sparsity=0.001):
            # Ponechá pouze horních 0,1 % gradientů dle velikosti
            flattened = torch.cat([g.flatten() for g in gradients])
            k = max(1, int(sparsity * flattened.numel()))
            _, indices = torch.topk(flattened.abs(), k)
            
            # Vytvoření řídkého tenzoru pouze s horními k gradienty
            sparse_flattened = torch.zeros_like(flattened)
            sparse_flattened[indices] = flattened[indices]
            
            # Přetvarování zpět do původních tvarů gradientů
            sparse_gradients = []
            offset = 0
            for g in gradients:
                numel = g.numel()
                sparse_gradients.append(
                    sparse_flattened[offset:offset+numel].view(g.shape)
                )
                offset += numel
            
            return sparse_gradients
    
    # Příklad trénování s velkými dávkami s lineárním škálováním rychlosti učení
    def large_batch_training():
        base_lr = 0.1
        base_batch_size = 256
        actual_batch_size = 4096
        
        # Lineární škálování rychlosti učení s velikostí dávky
        scaled_lr = base_lr * (actual_batch_size / base_batch_size)
        
        # Použití škálované rychlosti učení
        optimizer = torch.optim.SGD(model.parameters(), lr=scaled_lr)
        
        # Volitelné: Použití zahřívací fáze pro stabilizaci počátečního tréninku
        def lr_warmup(epoch, warmup_epochs=5):
            if epoch < warmup_epochs:
                # Lineární zahřívání
                return scaled_lr * (epoch + 1) / warmup_epochs
            return scaled_lr
```

```python
       - Omezení šířky pásma sítě

    # Příklad nastavení deterministického chování pro reprodukovatelnost
    def set_reproducible_environment(seed=42):
        # TensorFlow
        tf.random.set_seed(seed)
        
        # PyTorch
        torch.manual_seed(seed)
        torch.cuda.manual_seed_all(seed)
        torch.backends.cudnn.deterministic = True
        torch.backends.cudnn.benchmark = False
        
        # NumPy
        np.random.seed(seed)
        
        # Python
        import random
        random.seed(seed)

        os.environ['PYTHONHASHSEED'] = str(seed)
    
    # Příklad checkpointingu v distribuovaném tréninku
    def checkpointing_example():
        # TensorFlow příklad
        checkpoint_dir = './checkpoints'
        checkpoint_callback = tf.keras.callbacks.ModelCheckpoint(
            filepath=checkpoint_dir,
            save_weights_only=True,
            monitor='val_accuracy',
            mode='max',
            save_best_only=True
        )

        def save_checkpoint(model, optimizer, epoch, rank):
            if rank == 0:  # Uložení pouze na hlavním procesu
                checkpoint = {
                    'model_state_dict': model.state_dict(),
                    'optimizer_state_dict': optimizer.state_dict(),
                    'epoch': epoch,
                }
                torch.save(checkpoint, f'checkpoint_epoch_{epoch}.pt')
                
        def load_checkpoint(model, optimizer, filename):
            checkpoint = torch.load(filename)
            model.load_state_dict(checkpoint['model_state_dict'])
            optimizer.load_state_dict(checkpoint['optimizer_state_dict'])
            epoch = checkpoint['epoch']
```

## 10. Shrnutí

Distribuované trénování umožňuje odborníkům na hluboké učení pracovat s většími modely a datasety tím, že rozloží výpočty mezi více zařízení nebo počítače. Klíčové poznatky zahrnují:

1. **Distribuční strategie**: Vyberte mezi datovým paralelismem (nejběžnější), modelovým paralelismem nebo hybridními přístupy podle velikosti vašeho modelu a dostupného hardwaru.

2. **Podpora frameworků**: Jak TensorFlow, tak PyTorch nabízejí robustní možnosti distribuovaného tréninku prostřednictvím vysokoúrovňových API jako `tf.distribute.Strategy` a `DistributedDataParallel`.

3. **Komunikační režie**: Řešte hlavní úzké hrdlo distribuovaného tréninku pomocí technik jako akumulace gradientů, komprese a optimalizované kolektivní operace.

4. **Aspekty škálování**: Věnujte pozornost velikosti dávek, škálování rychlosti učení a využití zdrojů při škálování na více zařízení.

5. **Osvědčené postupy**:
   - Profilujte před distribucí
   - Zajistěte reprodukovatelnost nastavením náhodných seedů

   - Monitorujte využití zdrojů během tréninku

S růstem modelů v jejich velikosti a složitosti zůstane distribuovaný trénink nezbytným nástrojem v sadě nástrojů odborníka na hluboké učení, umožňující trénování state-of-the-art modelů, které by na jediném zařízení nebyly možné.
