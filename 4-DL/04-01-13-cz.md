# Implementace jednoduchých dopředných sítí

## 1. Úvod do dopředných sítí

Dopředné neuronové sítě, též známé jako vícevrstvé perceptrony (MLP), jsou nejzákladnějším typem architektury neuronových sítí. Skládají se z vrstev neuronů, kde informace proudí jedním směrem, od vstupní vrstvy přes skryté vrstvy k výstupní vrstvě, bez jakýchkoli smyček nebo zpětných vazeb.

Dopředné sítě jsou základními stavebními bloky v hlubokém učení a slouží jako vynikající výchozí bod pro pochopení složitějších architektur. Tyto sítě mohou aproximovat jakoukoli spojitou funkci, pokud mají dostatečný počet skrytých jednotek, což je činí všestrannými pro různé úlohy.

## 2. Architektura dopředných sítí

Typická architektura dopředné sítě zahrnuje:

- **Vstupní vrstva**: Přijímá počáteční data
- **Skrytá vrstva (vrstvy)**: Zpracovává informace prostřednictvím vážených spojení
- **Výstupní vrstva**: Produkuje konečnou predikci nebo klasifikaci

Každá vrstva se skládá z neuronů (nebo uzlů), které provádějí jednoduché výpočty:
1. Přijímají vážené vstupy z předchozí vrstvy
2. Sčítají tyto vstupy
3. Aplikují aktivační funkci
4. Předávají výstup do další vrstvy

## 3. Matematický základ

Operace každého neuronu lze vyjádřit jako:

$$y = f(\sum_{i=1}^{n} w_i x_i + b)$$

Kde:
- $x_i$ jsou vstupy
- $w_i$ jsou váhy
- $b$ je bias (posun)
- $f$ je aktivační funkce
- $y$ je výstup

## 5. Implementace dopředných sítí pomocí TensorFlow/Keras

Keras poskytuje vysokoúrovňové API pro vytváření dopředných sítí:

```python
import tensorflow as tf

from tensorflow.keras import layers
import numpy as np

# Generování syntetických dat
np.random.seed(42)
X_train = np.random.rand(1000, 20)  # 1000 vzorků, každý s 20 příznaky
```

## 6. Implementace dopředných sítí pomocí PyTorch

PyTorch nabízí flexibilnější přístup k vytváření neuronových sítí:

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset
import numpy as np

# Nastavení náhodného semínka pro reprodukovatelnost
torch.manual_seed(42)

# Generování syntetických dat
X_train = np.random.rand(1000, 20).astype(np.float32)
y_train = (X_train.sum(axis=1) > 10).astype(np.float32).reshape(-1, 1)

X_test = np.random.rand(200, 20).astype(np.float32)
y_test = (X_test.sum(axis=1) > 10).astype(np.float32).reshape(-1, 1)

# Převod na PyTorch tenzory
X_train_tensor = torch.from_numpy(X_train)
y_train_tensor = torch.from_numpy(y_train)
X_test_tensor = torch.from_numpy(X_test)
y_test_tensor = torch.from_numpy(y_test)

# Vytvoření datasetu a dataloaderu
train_dataset = TensorDataset(X_train_tensor, y_train_tensor)
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)

# Definice dopředné sítě
class FeedforwardNN(nn.Module):
    def __init__(self, input_size, hidden_size1, hidden_size2, output_size):
        super(FeedforwardNN, self).__init__()
        self.fc1 = nn.Linear(input_size, hidden_size1)
        self.relu1 = nn.ReLU()
        self.fc2 = nn.Linear(hidden_size1, hidden_size2)
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(hidden_size2, output_size)
        self.sigmoid = nn.Sigmoid()
        
    def forward(self, x):
        out = self.fc1(x)
        out = self.relu1(out)
        out = self.fc2(out)
        out = self.relu2(out)
        out = self.fc3(out)
        out = self.sigmoid(out)
        return out

# Inicializace sítě
input_size = 20
hidden_size1 = 64
hidden_size2 = 32
output_size = 1

model = FeedforwardNN(input_size, hidden_size1, hidden_size2, output_size)
print(model)

# Definice ztrátové funkce a optimalizátoru
criterion = nn.BCELoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# Trénování
num_epochs = 20
losses = []

for epoch in range(num_epochs):
    for batch_idx, (data, targets) in enumerate(train_loader):
        # Dopředný průchod
        outputs = model(data)
        loss = criterion(outputs, targets)
        
        # Zpětný průchod a optimalizace
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    # Sledování ztráty každou epochu
    losses.append(loss.item())
    print(f'Epocha [{epoch+1}/{num_epochs}], Ztráta: {loss.item():.4f}')

# Vyhodnocení modelu
with torch.no_grad():
    model.eval()
    test_outputs = model(X_test_tensor)
    predicted = (test_outputs > 0.5).float()
    accuracy = (predicted == y_test_tensor).sum().item() / y_test_tensor.size(0)
    print(f'Přesnost na testovacích datech: {accuracy:.4f}')

# Vykreslení trénovací ztráty
plt.figure(figsize=(10, 5))
plt.plot(range(1, num_epochs+1), losses)
plt.title('Trénovací ztráta')
plt.xlabel('Epocha')
plt.ylabel('Ztráta')
plt.grid(True)
plt.show()
```

## 7. Vytvoření dopředné sítě od základů

Pro lepší pochopení mechanismů, zde je implementace jednoduché dopředné sítě bez použití frameworků hlubokého učení:

```python
import numpy as np
import matplotlib.pyplot as plt

class NeuralNetwork:
    def __init__(self, input_size, hidden_size, output_size):
        # Inicializace vah a biasů
        self.W1 = np.random.randn(input_size, hidden_size) * 0.01
        self.b1 = np.zeros((1, hidden_size))
        self.W2 = np.random.randn(hidden_size, output_size) * 0.01
        self.b2 = np.zeros((1, output_size))
        
    def sigmoid(self, x):
        return 1 / (1 + np.exp(-x))
    
    def sigmoid_derivative(self, x):
        return x * (1 - x)
    
    def forward(self, X):
        # Dopředný průchod
        self.z1 = np.dot(X, self.W1) + self.b1
        self.a1 = self.sigmoid(self.z1)
        self.z2 = np.dot(self.a1, self.W2) + self.b2
        self.a2 = self.sigmoid(self.z2)
        return self.a2
    
    def backward(self, X, y, output, learning_rate):
        # Zpětný průchod
        self.error = y - output
        self.delta_output = self.error * self.sigmoid_derivative(output)
        
        self.error_hidden = self.delta_output.dot(self.W2.T)
        self.delta_hidden = self.error_hidden * self.sigmoid_derivative(self.a1)
        
        # Aktualizace vah a biasů
        self.W2 += self.a1.T.dot(self.delta_output) * learning_rate
        self.b2 += np.sum(self.delta_output, axis=0, keepdims=True) * learning_rate
        self.W1 += X.T.dot(self.delta_hidden) * learning_rate
        self.b1 += np.sum(self.delta_hidden, axis=0, keepdims=True) * learning_rate
    
    def train(self, X, y, epochs, learning_rate):
        losses = []
        for epoch in range(epochs):
            output = self.forward(X)
            self.backward(X, y, output, learning_rate)
            
            # Výpočet ztráty
            loss = np.mean(np.square(y - output))
            losses.append(loss)
            
            if epoch % 100 == 0:
                print(f"Epocha {epoch}, Ztráta: {loss:.4f}")
        
        return losses

# Generování dat pro XOR problém
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
y = np.array([[0], [1], [1], [0]])

# Vytvoření a trénování sítě
nn = NeuralNetwork(input_size=2, hidden_size=4, output_size=1)
losses = nn.train(X, y, epochs=10000, learning_rate=0.1)

# Testování sítě
predictions = nn.forward(X)
print("\nPredikce po tréninku:")
for i in range(len(X)):
    print(f"Vstup: {X[i]}, Cíl: {y[i][0]}, Predikce: {predictions[i][0]:.4f}")

# Vykreslení ztráty během trénování
plt.figure(figsize=(10, 5))
plt.plot(losses[10:])  # Přeskočení prvních několika epoch pro lepší vizualizaci
plt.title('Ztráta během tréninku')
plt.xlabel('Epocha')
plt.ylabel('Ztráta')
plt.grid(True)
plt.show()
```

## 10. Vylepšení dopředných sítí

Prozkoumejme některé techniky pro vylepšení dopředných sítí:

```python
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers, regularizers
import numpy as np

# Generování syntetických dat
np.random.seed(42)
X_train = np.random.rand(1000, 20)
y_train = (X_train.sum(axis=1) > 10).astype(int)
X_test = np.random.rand(200, 20)
y_test = (X_test.sum(axis=1) > 10).astype(int)

# Model s regularizací, batch normalizací a dropout
model_improved = keras.Sequential([
    # Vstupní vrstva
    layers.Dense(64, 
                 kernel_regularizer=regularizers.l2(0.001),  # L2 regularizace
                 input_shape=(20,)),
    layers.BatchNormalization(),  # Batch normalizace
    layers.Activation('relu'),
    layers.Dropout(0.3),  # Dropout pro regularizaci
    
    # Skrytá vrstva
    layers.Dense(32, 
                 kernel_regularizer=regularizers.l2(0.001)),
    layers.BatchNormalization(),
    layers.Activation('relu'),
    layers.Dropout(0.3),
    
    # Výstupní vrstva
    layers.Dense(1, activation='sigmoid')
])

# Kompilace s adaptivní rychlostí učení
initial_learning_rate = 0.01
lr_schedule = keras.optimizers.schedules.ExponentialDecay(
    initial_learning_rate,
    decay_steps=1000,
    decay_rate=0.96,
    staircase=True)

optimizer = keras.optimizers.Adam(learning_rate=lr_schedule)

model_improved.compile(
    optimizer=optimizer,
    loss='binary_crossentropy',
    metrics=['accuracy']
)

# Přidání předčasného ukončení
early_stopping = keras.callbacks.EarlyStopping(
    monitor='val_loss',
    patience=10,
    restore_best_weights=True
)

# Trénování modelu
history = model_improved.fit(
    X_train, y_train,
    epochs=100,
    batch_size=32,
    validation_split=0.2,
    callbacks=[early_stopping],
    verbose=1
)

# Vyhodnocení
test_loss, test_acc = model_improved.evaluate(X_test, y_test)
print(f"Přesnost na testovacích datech: {test_acc:.4f}")
```

## 12. Osvědčené postupy pro dopředné sítě

1. **Návrh architektury**:
   - Začněte s 1-2 skrytými vrstvami a zvyšujte podle potřeby
   - Použijte více neuronů v prvních vrstvách, méně v pozdějších vrstvách
   
2. **Aktivační funkce**:
   - Používejte ReLU (nebo varianty jako Leaky ReLU) pro skryté vrstvy
   - Vyberte výstupní aktivaci podle úlohy (sigmoid pro binární, softmax pro vícetřídní)
   
3. **Regularizace**:
   - Aplikujte dropout a/nebo L1/L2 regularizaci pro prevenci přeučení
   - Používejte batch normalizaci ke stabilizaci a urychlení trénování
   
4. **Trénování**:
   - Používejte optimalizátory s adaptivní rychlostí učení (Adam je často dobrá výchozí volba)
   - Monitorujte validační metriky a používejte předčasné zastavení
   - Zvažte plány rychlosti učení
   
5. **Předzpracování dat**:
   - Normalizujte/standardizujte vstupy
   - Řešte chybějící hodnoty
   - V případě potřeby vyvažte třídy

## 14. Závěr

Dopředné neuronové sítě poskytují solidní základ pro pochopení konceptů hlubokého učení. Navzdory své jednoduchosti ve srovnání s pokročilými architekturami jako CNN, RNN nebo transformery zůstávají užitečné pro mnoho praktických aplikací a slouží jako stavební bloky pro složitější modely.

Zvládnutím dopředných sítí získáte intuici o chování neuronových sítí, dynamice trénování a optimalizačních výzvách, které platí pro všechny typy neuronových sítí.
