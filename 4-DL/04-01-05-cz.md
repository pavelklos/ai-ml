## Úvod

Ztrátové funkce jsou základní komponenty v hlubokém učení, které kvantifikují rozdíl mezi předpovídanými výstupy a skutečnými cílovými hodnotami. Slouží jako optimalizační cíle během trénování modelu s cílem minimalizovat tento rozdíl pro zlepšení výkonu modelu.

Volba ztrátové funkce významně ovlivňuje:
- Rychlost konvergence modelu
- Konečnou přesnost modelu
- Schopnost zpracovávat specifické charakteristiky dat (např. odlehlé hodnoty, nevyvážené třídy)
- Cíle specifické pro daný problém

Tento průvodce zkoumá různé ztrátové funkce, jejich matematické formulace, implementaci v populárních frameworcích a vhodné aplikace pro různé úlohy hlubokého učení.

## Regresní ztrátové funkce

Regresní ztrátové funkce se používají při předpovídání spojitých hodnot, jako je cena, teplota nebo jakákoliv jiná číselná hodnota.

### Střední kvadratická chyba (MSE)

**Definice**: MSE je průměr čtverců rozdílů mezi předpovídanými a skutečnými hodnotami.

**Matematický vzorec**:
```
MSE = (1/n) * Σ(y_true - y_pred)²
```

**Kdy použít**:
- Standardní ztrátová funkce pro regresní problémy
- Když mají být větší chyby penalizovány více
- Když data obsahují relativně málo odlehlých hodnot

**Implementace**:

```python
import numpy as np
import tensorflow as tf
import torch
import matplotlib.pyplot as plt

# Ruční implementace
def mse_manual(y_true, y_pred):
    return np.mean(np.square(y_true - y_pred))

# TensorFlow/Keras implementace
y_true = tf.constant([[1.0, 2.0], [3.0, 4.0]])
y_pred = tf.constant([[1.1, 1.8], [2.8, 3.9]])

mse_tf = tf.keras.losses.MeanSquaredError()
mse_tf_result = mse_tf(y_true, y_pred)
print(f"TensorFlow MSE: {mse_tf_result.numpy()}")

# PyTorch implementace
y_true_pt = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
y_pred_pt = torch.tensor([[1.1, 1.8], [2.8, 3.9]])

mse_pt = torch.nn.MSELoss()
mse_pt_result = mse_pt(y_pred_pt, y_true_pt)
print(f"PyTorch MSE: {mse_pt_result.item()}")
```

### Střední absolutní chyba (MAE)

**Definice**: MAE je průměr absolutních rozdílů mezi předpovídanými a skutečnými hodnotami.

**Matematický vzorec**:
```
MAE = (1/n) * Σ|y_true - y_pred|
```

**Kdy použít**:
- Když chcete, aby chyby rostly lineárně (ne kvadraticky jako u MSE)
- Když vaše data obsahují odlehlé hodnoty
- Když přesná přesnost není tak důležitá jako obecný trend

**Implementace**:

```python
# Ruční implementace
def mae_manual(y_true, y_pred):
    return np.mean(np.abs(y_true - y_pred))

# TensorFlow/Keras implementace
mae_tf = tf.keras.losses.MeanAbsoluteError()
mae_tf_result = mae_tf(y_true, y_pred)
print(f"TensorFlow MAE: {mae_tf_result.numpy()}")

# PyTorch implementace
mae_pt = torch.nn.L1Loss()
mae_pt_result = mae_pt(y_pred_pt, y_true_pt)
print(f"PyTorch MAE: {mae_pt_result.item()}")
```

### Huberova ztráta

**Definice**: Huberova ztráta kombinuje nejlepší vlastnosti MSE a MAE tím, že je kvadratická pro malé chyby a lineární pro velké chyby, což ji činí méně citlivou na odlehlé hodnoty než MSE.

**Matematický vzorec**:
```
Huber(y, f(x)) = 0.5(y - f(x))² pokud |y - f(x)| ≤ δ
                  δ|y - f(x)| - 0.5δ² jinak
```
kde δ je hyperparametr, který určuje bod přechodu.

**Kdy použít**:
- Když vaše data obsahují odlehlé hodnoty, ale stále chcete těžit z MSE pro malé chyby
- Když potřebujete diferencovatelnou ztrátovou funkci, která je méně citlivá na odlehlé hodnoty

**Implementace**:

```python
# Ruční implementace
def huber_manual(y_true, y_pred, delta=1.0):
    error = y_true - y_pred
    is_small_error = np.abs(error) <= delta
    squared_loss = 0.5 * np.square(error)
    linear_loss = delta * (np.abs(error) - 0.5 * delta)
    return np.mean(np.where(is_small_error, squared_loss, linear_loss))

# TensorFlow/Keras implementace
huber_tf = tf.keras.losses.Huber(delta=1.0)
huber_tf_result = huber_tf(y_true, y_pred)
print(f"TensorFlow Huber Loss: {huber_tf_result.numpy()}")

# PyTorch implementace
huber_pt = torch.nn.HuberLoss(delta=1.0)
huber_pt_result = huber_pt(y_pred_pt, y_true_pt)
print(f"PyTorch Huber Loss: {huber_pt_result.item()}")

# Vizualizace různých regresních ztrát
x = np.linspace(-3, 3, 1000)
plt.figure(figsize=(10, 6))
plt.plot(x, x**2, label='MSE')
plt.plot(x, np.abs(x), label='MAE')
plt.plot(x, np.where(np.abs(x) <= 1, 0.5*x**2, np.abs(x)-0.5), label='Huber (δ=1)')
plt.grid(True)
plt.legend()
plt.title('Porovnání regresních ztrátových funkcí')
plt.xlabel('Chyba (y_true - y_pred)')
plt.ylabel('Ztráta')
plt.show()
```

### Log-cosh ztráta

**Definice**: Log-cosh ztráta je logaritmus hyperbolického kosinu chyby predikce.

**Matematický vzorec**:
```
Log-cosh = Σ log(cosh(y_pred - y_true))
```

**Kdy použít**:
- Když potřebujete ztrátovou funkci, která je hladká všude
- Jako alternativu k Huberově ztrátě s dvojitou diferencovatelností
- Pro regresní úlohy, kde je MSE příliš citlivá na odlehlé hodnoty

**Implementace**:

```python
# Ruční implementace
def log_cosh_manual(y_true, y_pred):
    return np.mean(np.log(np.cosh(y_pred - y_true)))

# TensorFlow/Keras implementace
def log_cosh_tf(y_true, y_pred):
    return tf.reduce_mean(tf.math.log(tf.math.cosh(y_pred - y_true)))

log_cosh_tf_result = log_cosh_tf(y_true, y_pred)
print(f"TensorFlow Log-cosh ztráta: {log_cosh_tf_result.numpy()}")

# PyTorch implementace
def log_cosh_pt(y_pred, y_true):
    return torch.mean(torch.log(torch.cosh(y_pred - y_true)))

log_cosh_pt_result = log_cosh_pt(y_pred_pt, y_true_pt)
print(f"PyTorch Log-cosh ztráta: {log_cosh_pt_result.item()}")
```

## Klasifikační ztrátové funkce

Klasifikační ztrátové funkce se používají při předpovídání kategorických výstupů, jako je příslušnost ke třídě.

### Binární křížová entropie

**Definice**: Binární křížová entropie měří výkon klasifikačního modelu, jehož výstup je pravděpodobnost mezi 0 a 1.

**Matematický vzorec**:
```
BCE = -Σ(y_true * log(y_pred) + (1 - y_true) * log(1 - y_pred))
```

**Kdy použít**:
- Pro binární klasifikační problémy
- Když váš model dává na výstupu pravděpodobnosti (pomocí sigmoidální aktivace)

**Implementace**:

```python
# Vytvoření vzorových dat
binary_y_true = tf.constant([[0], [1], [1], [0]])
binary_y_pred = tf.constant([[0.1], [0.7], [0.8], [0.2]])  # Předpovězené pravděpodobnosti

# Ruční implementace
def binary_crossentropy_manual(y_true, y_pred, epsilon=1e-7):
    # Oříznutí předpovědí, aby se předešlo log(0)
    y_pred = np.clip(y_pred, epsilon, 1 - epsilon)
    return -np.mean(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))

# TensorFlow/Keras implementace
bce_tf = tf.keras.losses.BinaryCrossentropy()
bce_tf_result = bce_tf(binary_y_true, binary_y_pred)
print(f"TensorFlow binární křížová entropie: {bce_tf_result.numpy()}")

# PyTorch implementace
binary_y_true_pt = torch.tensor([[0.0], [1.0], [1.0], [0.0]])
binary_y_pred_pt = torch.tensor([[0.1], [0.7], [0.8], [0.2]])

bce_pt = torch.nn.BCELoss()
bce_pt_result = bce_pt(binary_y_pred_pt, binary_y_true_pt)
print(f"PyTorch binární křížová entropie: {bce_pt_result.item()}")
```

### Kategorická křížová entropie

**Definice**: Kategorická křížová entropie se používá pro vícevrstvou klasifikaci, když jsou cíle kódovány ve formátu one-hot.

**Matematický vzorec**:
```
CCE = -Σ Σ(y_true_ij * log(y_pred_ij))
```
kde i indexuje příklady a j indexuje třídy.

**Kdy použít**:
- Pro vícevrstvé klasifikační problémy
- Když jsou štítky tříd kódovány ve formátu one-hot
- Když model dává na výstupu pravděpodobnostní distribuci (softmax)

**Implementace**:

```python
# Vytvoření vzorových dat
cat_y_true = tf.constant([[0, 1, 0], [0, 0, 1], [1, 0, 0]])  # Kódováno ve formátu one-hot
cat_y_pred = tf.constant([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]])  # Pravděpodobnosti tříd

# TensorFlow/Keras implementace
cce_tf = tf.keras.losses.CategoricalCrossentropy()
cce_tf_result = cce_tf(cat_y_true, cat_y_pred)
print(f"TensorFlow kategorická křížová entropie: {cce_tf_result.numpy()}")

# PyTorch implementace
cat_y_true_pt = torch.tensor([[0, 1, 0], [0, 0, 1], [1, 0, 0]], dtype=torch.float32)
cat_y_pred_pt = torch.tensor([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]], dtype=torch.float32)

cce_pt = torch.nn.CrossEntropyLoss()
# PyTorch očekává logity, ne pravděpodobnosti, takže musíme upravit nebo použít log_softmax
# Zde použijeme přímou ztrátovou funkci pro jednoduchost
cce_pt_result = -torch.sum(cat_y_true_pt * torch.log(cat_y_pred_pt)) / cat_y_true_pt.size(0)
print(f"PyTorch kategorická křížová entropie: {cce_pt_result.item()}")
```

### Řídká kategorická křížová entropie

**Definice**: Podobná kategorické křížové entropii, ale cíle jsou poskytovány jako celočíselné indexy spíše než jako vektory kódované ve formátu one-hot.

**Kdy použít**:
- Pro vícevrstvé klasifikační problémy
- Když jsou štítky tříd celá čísla (ne ve formátu one-hot)
- Pro úsporu paměti při práci s mnoha třídami

**Implementace**:

```python
# Vytvoření vzorových dat - řídké štítky
sparse_y_true = tf.constant([1, 2, 0])  # Celočíselné indexy tříd
sparse_y_pred = tf.constant([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]])  # Pravděpodobnosti tříd

# TensorFlow/Keras implementace
scce_tf = tf.keras.losses.SparseCategoricalCrossentropy()
scce_tf_result = scce_tf(sparse_y_true, sparse_y_pred)
print(f"TensorFlow řídká kategorická křížová entropie: {scce_tf_result.numpy()}")

# PyTorch implementace
sparse_y_true_pt = torch.tensor([1, 2, 0])  # Celočíselné indexy tříd
sparse_y_pred_pt = torch.tensor([[0.1, 0.8, 0.1], [0.2, 0.3, 0.5], [0.7, 0.2, 0.1]], dtype=torch.float32)

# PyTorch CrossEntropyLoss kombinuje log_softmax a NLLLoss, očekává logity, ne pravděpodobnosti
scce_pt = torch.nn.CrossEntropyLoss()
# Použijeme logaritmy pravděpodobností místo logitů pro jednoduchost
scce_pt_result = scce_pt(torch.log(sparse_y_pred_pt), sparse_y_true_pt)
print(f"PyTorch řídká kategorická křížová entropie: {scce_pt_result.item()}")
```

### Fokální ztráta

**Definice**: Fokální ztráta je navržena pro řešení nevyváženosti tříd tím, že snižuje váhu jednoduchých příkladů a zaměřuje trénink na těžké negativní příklady.

**Matematický vzorec**:
```
FL(pt) = -α(1-pt)ᵧ * log(pt)
```
kde pt je předpovídaná pravděpodobnost pro skutečnou třídu, α je vyvažovací parametr a γ je fokusovací parametr.

**Kdy použít**:
- Pro klasifikační problémy se závažnou nevyvážeností tříd
- V úlohách detekce objektů (pochází z RetinaNet)
- Když mají false positives/negatives různou důležitost

**Implementace**:

```python
# TensorFlow/Keras implementace
def focal_loss_tf(y_true, y_pred, gamma=2.0, alpha=0.25):
    """
    Implementace fokální ztráty pro binární klasifikaci
    """
    # Oříznutí hodnot pro prevenci dělení nulou
    epsilon = 1e-7
    y_pred = tf.clip_by_value(y_pred, epsilon, 1 - epsilon)
    
    # Výpočet fokální ztráty
    pt = tf.where(tf.equal(y_true, 1), y_pred, 1 - y_pred)
    focal_loss = -alpha * tf.pow(1 - pt, gamma) * tf.math.log(pt)
    return tf.reduce_mean(focal_loss)

focal_loss_result = focal_loss_tf(binary_y_true, binary_y_pred)
print(f"TensorFlow fokální ztráta: {focal_loss_result.numpy()}")

# PyTorch implementace
def focal_loss_pt(y_pred, y_true, gamma=2.0, alpha=0.25):
    """
    Implementace fokální ztráty pro binární klasifikaci v PyTorch
    """
    # Oříznutí hodnot pro prevenci dělení nulou
    epsilon = 1e-7
    y_pred = torch.clamp(y_pred, epsilon, 1 - epsilon)
    
    # Výpočet fokální ztráty
    pt = torch.where(y_true == 1, y_pred, 1 - y_pred)
    focal_loss = -alpha * (1 - pt).pow(gamma) * torch.log(pt)
    return torch.mean(focal_loss)

focal_loss_pt_result = focal_loss_pt(binary_y_pred_pt, binary_y_true_pt)
print(f"PyTorch fokální ztráta: {focal_loss_pt_result.item()}")
```

## Pravděpodobnostní ztrátové funkce

Pravděpodobnostní ztrátové funkce se používají při práci s distribucemi spíše než s bodovými odhady.

### Kullback-Leiblerova divergence

**Definice**: KL divergence měří, jak jedna pravděpodobnostní distribuce diverguje od druhé očekávané distribuce.

**Matematický vzorec**:
```
KL(P||Q) = Σ P(x) * log(P(x)/Q(x))
```

**Kdy použít**:
- Pro trénování variačních autoenkodérů (VAEs)
- Při porovnávání pravděpodobnostních distribucí
- V posilovaném učení pro optimalizaci politik

**Implementace**:

```python
# Vytvoření vzorových pravděpodobnostních distribucí
p = tf.constant([[0.1, 0.7, 0.2], [0.3, 0.2, 0.5]])
q = tf.constant([[0.2, 0.6, 0.2], [0.25, 0.25, 0.5]])

# TensorFlow implementace
kl_tf = tf.keras.losses.KLDivergence()
kl_tf_result = kl_tf(p, q)
print(f"TensorFlow KL divergence: {kl_tf_result.numpy()}")

# PyTorch implementace
p_pt = torch.tensor([[0.1, 0.7, 0.2], [0.3, 0.2, 0.5]], dtype=torch.float32)
q_pt = torch.tensor([[0.2, 0.6, 0.2], [0.25, 0.25, 0.5]], dtype=torch.float32)

kl_pt = torch.nn.KLDivLoss(reduction='batchmean')
# PyTorch KLDivLoss očekává log-pravděpodobnosti pro q
kl_pt_result = kl_pt(torch.log(q_pt), p_pt)
print(f"PyTorch KL divergence: {kl_pt_result.item()}")
```

### Jensen-Shannonova divergence

**Definice**: JS divergence je symetrizovaná a vyhlazená verze KL divergence.

**Matematický vzorec**:
```
JS(P||Q) = 0.5 * KL(P||M) + 0.5 * KL(Q||M)
```
kde M = 0.5 * (P + Q)

**Kdy použít**:
- Když potřebujete symetrickou míru divergence
- V GAN (generative adversarial networks)
- Když distribuce nemusí sdílet podporu

**Implementace**:

```python
def jensen_shannon_divergence_tf(p, q):
    m = 0.5 * (p + q)
    return 0.5 * tf.keras.losses.KLDivergence()(p, m) + 0.5 * tf.keras.losses.KLDivergence()(q, m)

js_tf_result = jensen_shannon_divergence_tf(p, q)
print(f"TensorFlow Jensen-Shannonova divergence: {js_tf_result.numpy()}")

def jensen_shannon_divergence_pt(p, q):
    m = 0.5 * (p + q)
    kl = torch.nn.KLDivLoss(reduction='batchmean')
    return 0.5 * kl(torch.log(m), p) + 0.5 * kl(torch.log(m), q)

js_pt_result = jensen_shannon_divergence_pt(p_pt, q_pt)
print(f"PyTorch Jensen-Shannonova divergence: {js_pt_result.item()}")
```

## Specializované ztrátové funkce

### Dice ztráta pro segmentaci

**Definice**: Dice ztráta je založena na koeficientu Dice, který měří překryv mezi dvěma vzorky. Běžně se používá pro úlohy segmentace obrazu.

**Matematický vzorec**:
```
Dice ztráta = 1 - (2 * |X ∩ Y| / (|X| + |Y|))
```

**Kdy použít**:
- Pro úlohy segmentace obrazu
- Zvláště s nevyváženými třídami (např. malé objekty na velkých obrázcích)
- Když chcete přímo optimalizovat pro IoU (průnik nad sjednocením)

**Implementace**:

```python
def dice_loss_tf(y_true, y_pred, smooth=1):
    """Dice ztráta pro binární segmentaci"""
    y_true_flat = tf.reshape(y_true, [-1])
    y_pred_flat = tf.reshape(y_pred, [-1])
    intersection = tf.reduce_sum(y_true_flat * y_pred_flat)
    return 1 - ((2. * intersection + smooth) / 
                (tf.reduce_sum(y_true_flat) + tf.reduce_sum(y_pred_flat) + smooth))

# Vytvoření vzorových segmentačních dat
seg_true = tf.random.uniform((4, 16, 16, 1), 0, 2, dtype=tf.int32)
seg_pred = tf.random.uniform((4, 16, 16, 1), 0, 1, dtype=tf.float32)

# Výpočet Dice ztráty
dice_loss_val = dice_loss_tf(tf.cast(seg_true, tf.float32), seg_pred)
print(f"Dice ztráta: {dice_loss_val.numpy()}")

def dice_loss_pt(y_true, y_pred, smooth=1):
    """Dice ztráta pro binární segmentaci v PyTorch"""
    y_true_flat = y_true.reshape(-1)
    y_pred_flat = y_pred.reshape(-1)
    intersection = (y_true_flat * y_pred_flat).sum()
    return 1 - ((2. * intersection + smooth) / 
                (y_true_flat.sum() + y_pred_flat.sum() + smooth))
```

### Kontrastivní ztráta

**Definice**: Kontrastivní ztráta se používá v siamských sítích pro učení vložení, kde jsou podobné vzorky blízko u sebe a nepodobné vzorky jsou daleko od sebe.

**Matematický vzorec**:
```
L = (1-Y) * 0.5 * D² + Y * 0.5 * max(0, margin - D)²
```
kde D je vzdálenost mezi vloženími, Y je 1, pokud jsou vzorky podobné a 0 v opačném případě.

**Kdy použít**:
- Pro metrické učení a učení podobnosti
- Rozpoznávání/verifikace obličeje
- Když chcete naučit vložení pro shlukování

**Implementace**:

```python
def contrastive_loss_tf(y_true, pair_distances, margin=1.0):
    """
    Kontrastivní ztráta pro siamské sítě v TensorFlow
    y_true: Binární tenzor označující podobné páry (1) nebo nepodobné páry (0)
    pair_distances: Tenzor L2 vzdáleností mezi páry vložení
    """
    # Ztráta pro podobné páry: podporuje blízkost vložení
    similar_loss = y_true * tf.square(pair_distances)
    
    # Ztráta pro nepodobné páry: podporuje, aby vložení byla alespoň margin vzdálená
    dissimilar_loss = (1 - y_true) * tf.square(tf.maximum(margin - pair_distances, 0))
    
    return tf.reduce_mean(0.5 * (similar_loss + dissimilar_loss))

# Vytvoření vzorových dat
pairs_y_true = tf.constant([1, 0, 1, 0])  # Podobné/nepodobné páry
pair_distances = tf.constant([0.2, 0.8, 0.3, 0.5])  # Vzdálenosti mezi vloženími

cl_result = contrastive_loss_tf(pairs_y_true, pair_distances)
print(f"Kontrastivní ztráta: {cl_result.numpy()}")

def contrastive_loss_pt(y_true, pair_distances, margin=1.0):
    """
    Kontrastivní ztráta pro siamské sítě v PyTorch
    """
    similar_loss = y_true * torch.pow(pair_distances, 2)
    dissimilar_loss = (1 - y_true) * torch.pow(torch.clamp(margin - pair_distances, min=0.0), 2)
    return torch.mean(0.5 * (similar_loss + dissimilar_loss))
```

### Triplet ztráta

**Definice**: Triplet ztráta funguje minimalizací vzdálenosti mezi kotvou a pozitivním vzorkem (oba ze stejné třídy) a zároveň maximalizací vzdálenosti mezi kotvou a negativním vzorkem (z různých tříd).

**Matematický vzorec**:
```
L = max(d(a, p) - d(a, n) + margin, 0)
```
kde a je kotva, p je pozitivní a n je negativní.

**Kdy použít**:
- Rozpoznávání obličejů
- Vyhledávání obrazů
- Když máte jasné pojmy podobných/nepodobných příkladů
- Když kontrastivní ztráta neposkytuje dostatek kontextu

**Implementace**:

```python
def triplet_loss_tf(anchor, positive, negative, margin=0.2):
    """
    Triplet ztráta v TensorFlow
    anchor, positive, negative: vložení kotvy, pozitivního a negativního příkladu
    """
    # Výpočet vzdáleností
    pos_dist = tf.reduce_sum(tf.square(anchor - positive), axis=1)
    neg_dist = tf.reduce_sum(tf.square(anchor - negative), axis=1)
    
    # Výpočet triplet ztráty s margin
    basic_loss = pos_dist - neg_dist + margin
    loss = tf.maximum(basic_loss, 0.0)
    
    return tf.reduce_mean(loss)

# Vytvoření vzorových vložení
anchor = tf.random.normal((4, 128))
positive = tf.random.normal((4, 128), mean=0.1)
negative = tf.random.normal((4, 128), mean=2.0)

tl_result = triplet_loss_tf(anchor, positive, negative)
print(f"Triplet ztráta: {tl_result.numpy()}")

def triplet_loss_pt(anchor, positive, negative, margin=0.2):
    """
    Triplet ztráta v PyTorch
    """
    pos_dist = torch.sum(torch.pow(anchor - positive, 2), dim=1)
    neg_dist = torch.sum(torch.pow(anchor - negative, 2), dim=1)
    
    basic_loss = pos_dist - neg_dist + margin
    loss = torch.clamp(basic_loss, min=0.0)
    
    return torch.mean(loss)
```

## Vlastní ztrátové funkce

Někdy předefinované ztrátové funkce nejsou adekvátní pro specifické úlohy. Jak TensorFlow/Keras, tak PyTorch umožňují vytváření vlastních ztrátových funkcí.

### Vytváření vlastních ztrát v TensorFlow/Keras

```python
@tf.keras.utils.register_keras_serializable()
class CustomLoss(tf.keras.losses.Loss):
    def __init__(self, alpha=0.4, **kwargs):
        super().__init__(**kwargs)
        self.alpha = alpha

    def call(self, y_true, y_pred):
        mae_loss = tf.keras.losses.MeanAbsoluteError()(y_true, y_pred)
        mse_loss = tf.keras.losses.MeanSquaredError()(y_true, y_pred)
        return self.alpha * mae_loss + (1 - self.alpha) * mse_loss
    
    def get_config(self):
        base_config = super().get_config()
        return {**base_config, "alpha": self.alpha}

# Jednoduchá funkční vlastní ztráta
def custom_loss_fn(y_true, y_pred, alpha=0.4):
    mae_loss = tf.keras.losses.MeanAbsoluteError()(y_true, y_pred)
    mse_loss = tf.keras.losses.MeanSquaredError()(y_true, y_pred)
    return alpha * mae_loss + (1 - alpha) * mse_loss

# Použití
model = tf.keras.Sequential([
    tf.keras.layers.Dense(64, activation='relu', input_shape=(10,)),
    tf.keras.layers.Dense(1)
])

# Použití vlastní ztráty založené na třídě
model.compile(optimizer='adam', loss=CustomLoss(alpha=0.3))

# Použití vlastní ztráty založené na funkci
model.compile(optimizer='adam', 
              loss=lambda y_true, y_pred: custom_loss_fn(y_true, y_pred, alpha=0.3))
```

### Vytváření vlastních ztrát v PyTorch

```python
class CustomLoss(torch.nn.Module):
    def __init__(self, alpha=0.4):
        super().__init__()
        self.alpha = alpha
        self.mae_loss = torch.nn.L1Loss()
        self.mse_loss = torch.nn.MSELoss()
        
    def forward(self, y_pred, y_true):
        mae = self.mae_loss(y_pred, y_true)
        mse = self.mse_loss(y_pred, y_true)
        return self.alpha * mae + (1 - self.alpha) * mse

# Funkční vlastní ztráta
def custom_loss_fn_pt(y_pred, y_true, alpha=0.4):
    mae_loss = torch.nn.functional.l1_loss(y_pred, y_true)
    mse_loss = torch.nn.functional.mse_loss(y_pred, y_true)
    return alpha * mae_loss + (1 - alpha) * mse_loss

# Použití
model = torch.nn.Sequential(
    torch.nn.Linear(10, 64),
    torch.nn.ReLU(),
    torch.nn.Linear(64, 1)
)

# Použití vlastní ztráty založené na třídě
criterion = CustomLoss(alpha=0.3)
optimizer = torch.optim.Adam(model.parameters())

# Během tréninku
def train(model, inputs, targets):
    model.train()
    optimizer.zero_grad()
    outputs = model(inputs)
    loss = criterion(outputs, targets)
    loss.backward()
    optimizer.step()
    return loss.item()
```

## Kombinování více ztrátových funkcí

Komplexní úlohy hlubokého učení často těží z kombinace více ztrátových funkcí. Zde je způsob, jak vytvořit vážené kombinace ztrát:

```python
# TensorFlow/Keras příklad: Multi-task learning s více ztrátami
inputs = tf.keras.Input(shape=(128,))
shared = tf.keras.layers.Dense(64, activation='relu')(inputs)

# Výstupní větev pro klasifikaci
classification_output = tf.keras.layers.Dense(10, activation='softmax', name='classification')(shared)

# Výstupní větev pro regresi
regression_output = tf.keras.layers.Dense(1, name='regression')(shared)

model = tf.keras.Model(inputs=inputs, outputs=[classification_output, regression_output])

model.compile(
    optimizer='adam',
    loss={
        'classification': 'categorical_crossentropy',
        'regression': 'mse'
    },
    loss_weights={
        'classification': 1.0,
        'regression': 0.5
    },
    metrics={
        'classification': 'accuracy',
        'regression': 'mae'
    }
)

# PyTorch příklad
class MultiTaskModel(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.shared = torch.nn.Sequential(
            torch.nn.Linear(128, 64),
            torch.nn.ReLU()
        )
        self.classification_head = torch.nn.Linear(64, 10)
        self.regression_head = torch.nn.Linear(64, 1)
        
    def forward(self, x):
        shared_features = self.shared(x)
        classification_output = self.classification_head(shared_features)
        regression_output = self.regression_head(shared_features)
        return classification_output, regression_output

# Ztrátové funkce
classification_loss = torch.nn.CrossEntropyLoss()
regression_loss = torch.nn.MSELoss()

# Trénovací smyčka s kombinovanými ztrátami
def train_multi_task(model, inputs, class_targets, reg_targets):
    model.train()
    optimizer.zero_grad()
    class_outputs, reg_outputs = model(inputs)
    
    # Výpočet jednotlivých ztrát
    c_loss = classification_loss(class_outputs, class_targets)
    r_loss = regression_loss(reg_outputs, reg_targets)
    
    # Kombinace ztrát s váhami
    combined_loss = c_loss + 0.5 * r_loss
    
    combined_loss.backward()
    optimizer.step()
    
    return c_loss.item(), r_loss.item(), combined_loss.item()
```

## Pokyny pro výběr ztrátové funkce

Výběr správné ztrátové funkce je klíčový pro výkon modelu. Zde jsou některé pokyny:

1. **Pro regresní úlohy**:
   - MSE: Když mají být chyby penalizovány kvadraticky
   - MAE: Když jsou přítomny odlehlé hodnoty nebo chyby by měly růst lineárně
   - Huber/Log-cosh: Pro robustní regresi, vyvažující vlastnosti MSE a MAE

2. **Pro binární klasifikaci**:
   - Binární křížová entropie: Standardní volba
   - Fokální ztráta: Když je nevyváženost tříd vážná

3. **Pro vícevrstvou klasifikaci**:
   - Kategorická křížová entropie: Když jsou třídy kódovány ve formátu one-hot
   - Řídká kategorická křížová entropie: Když jsou štítky tříd celá čísla

4. **Pro segmentaci obrazu**:
   - Dice ztráta: Pro vyvážení přesnosti a úplnosti
   - Vážená křížová entropie: Pro nevyváženost tříd

5. **Pro učení podobnosti**:
   - Kontrastivní ztráta: Pro páry příkladů
   - Triplet ztráta: Pro trojice kotva-pozitivní-negativní

6. **Pro predikci sekvencí**:
   - CTC ztráta: Když je zarovnání neznámé
   - Vlastní sekvenční ztráty: Pro specifické potřeby domény

### Detekce objektů

```python
# Zjednodušený příklad vlastní ztráty pro detekci objektů inspirovaný YOLO
def yolo_custom_loss(y_true, y_pred, lambda_coord=5.0, lambda_noobj=0.5):
    """
    Zjednodušená YOLO-style ztrátová funkce
    
    Args:
        y_true: Groundtruth boxy a třídy
        y_pred: Předpovězené boxy a třídy
        lambda_coord: Váha pro predikce souřadnic
        lambda_noobj: Váha pro predikce bez-objektu
        
    Returns:
        Kombinovaná ztráta pro ohraničující rámečky a klasifikace
    """
    # Extrakce komponent - v reálném YOLO by to bylo složitější
    # [batch, cell, cell, (x, y, w, h, confidence, classes)]
    
    # Přítomnost objektů v každé buňce mřížky (1 pokud střed objektu je v buňce, jinak 0)
    object_mask = y_true[..., 4:5]
    
    # Ztráta souřadnic (x, y, w, h) - pouze kde existují objekty
    coord_true = y_true[..., 0:4]
    coord_pred = y_pred[..., 0:4]
    
    # Škálování ztrát souřadnic podle lambda_coord
    coord_loss = lambda_coord * object_mask * tf.reduce_sum(
        tf.square(coord_true - coord_pred), axis=-1, keepdims=True)
    
    # Ztráta jistoty (objektovost)
    conf_true = y_true[..., 4:5]
    conf_pred = y_pred[..., 4:5]
    
    # Ztráta jistoty objektu
    obj_conf_loss = object_mask * tf.square(conf_true - conf_pred)
    
    # Ztráta jistoty bez-objektu
    noobj_conf_loss = lambda_noobj * (1 - object_mask) * tf.square(conf_true - conf_pred)
    
    # Ztráta pravděpodobností tříd - pouze kde existují objekty
    class_true = y_true[..., 5:]
    class_pred = y_pred[..., 5:]
    class_loss = object_mask * tf.reduce_sum(
        tf.square(class_true - class_pred), axis=-1, keepdims=True)
    
    # Součet všech ztrát
    total_loss = tf.reduce_mean(coord_loss + obj_conf_loss + noobj_conf_loss + class_loss)
    
    return total_loss
```

# Křížová entropie s vyhlazováním štítků v TensorFlow
def cross_entropy_with_label_smoothing(y_true, y_pred, label_smoothing=0.1):
    confidence = 1.0 - label_smoothing
    y_true_smooth = y_true * confidence + (1 - y_true) * label_smoothing / (y_true.shape[-1] - 1)
    return tf.keras.losses.categorical_crossentropy(y_true_smooth, y_pred)

# PyTorch příklad s nn.CrossEntropyLoss a vyhlazováním štítků
class LabelSmoothingLoss(torch.nn.Module):
    def __init__(self, classes, smoothing=0.1, dim=-1):
        super(LabelSmoothingLoss, self).__init__()
        self.confidence = 1.0 - smoothing
        self.smoothing = smoothing
        self.cls = classes
        self.dim = dim

    def forward(self, pred, target):
        pred = pred.log_softmax(dim=self.dim)
        with torch.no_grad():
            # Vytvoření vyhlazené cílové distribuce
            true_dist = torch.zeros_like(pred)
            true_dist.fill_(self.smoothing / (self.cls - 1))
            true_dist.scatter_(1, target.data.unsqueeze(1), self.confidence)
        return torch.mean(torch.sum(-true_dist * pred, dim=self.dim))

# Použití
criterion = LabelSmoothingLoss(classes=vocab_size, smoothing=0.1)

3. **Nestabilní trénování**:
   - Řešení: Použijte vyhlazování štítků, batch normalizaci nebo upravte rychlost učení

4. **Pomalá konvergence**:
   - Řešení: Zvolte vhodnou ztrátovou funkci pro vaši distribuci dat

5. **Přeučení**:
   - Řešení: Přidejte regularizační členy do vaší ztrátové funkce (L1/L2)

# Přidání L2 regularizace do vlastní ztrátové funkce
def custom_loss_with_reg(y_true, y_pred, l2_reg=0.01):
    # Hlavní člen ztráty
    mse_loss = tf.reduce_mean(tf.square(y_true - y_pred))
    
    # L2 regularizační člen - sběr všech vah modelu
    l2_loss = tf.add_n([tf.nn.l2_loss(v) for v in model.trainable_variables 
                        if 'bias' not in v.name]) * l2_reg
    
    return mse_loss + l2_loss
