## 1. Introduction to Advanced Transformer Architectures

Advanced transformer architectures have revolutionized natural language processing by applying the self-attention mechanism introduced in the original Transformer paper ("Attention is All You Need"). These models use pre-training on large text corpora followed by fine-tuning for specific tasks.

The three major transformer architectures we'll explore:
- **BERT**: Bidirectional context for understanding language
- **GPT**: Unidirectional (left-to-right) for text generation
- **T5**: Text-to-text framework for unified NLP tasks

## 2. BERT: Bidirectional Encoder Representations from Transformers

BERT utilizes a bidirectional approach to understand context from both directions in text. It was developed by Google and introduced in 2018.

### Key Features:
- Bidirectional context understanding
- Masked Language Model (MLM) pre-training
- Next Sentence Prediction (NSP) pre-training
- Encoder-only architecture

```python
from transformers import BertModel, BertTokenizer

# Load pre-trained BERT model and tokenizer
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

# Example text
text = "The Transformer architecture revolutionized natural language processing."

# Tokenize input
inputs = tokenizer(text, return_tensors="pt", padding=True, truncation=True, max_length=512)

# Get embeddings from BERT
with torch.no_grad():
    outputs = model(**inputs)

# Extract the last hidden states (contextual embeddings)
last_hidden_states = outputs.last_hidden_state
print(f"Shape of embeddings: {last_hidden_states.shape}")  # [batch_size, seq_length, hidden_size]

# Extract the [CLS] token representation (often used for classification tasks)
cls_embedding = last_hidden_states[:, 0, :]
print(f"Shape of [CLS] embedding: {cls_embedding.shape}")  # [batch_size, hidden_size]
```

### Fine-tuning BERT for Sentiment Classification:

```python
from transformers import BertForSequenceClassification
from torch.optim import AdamW
from torch.utils.data import DataLoader, TensorDataset

# Load pre-trained model for sequence classification (e.g., 2 classes for sentiment)
model = BertForSequenceClassification.from_pretrained('bert-base-uncased', num_labels=2)

# Example data (in practice, you would load a real dataset)
texts = ["I love this product!", "This movie was terrible", "Great service, highly recommend"]
labels = [1, 0, 1]  # 1 for positive, 0 for negative

# Tokenize all texts
encoded_data = tokenizer(texts, padding=True, truncation=True, return_tensors="pt")
input_ids = encoded_data['input_ids']
attention_mask = encoded_data['attention_mask']
labels_tensor = torch.tensor(labels)

# Create dataset and dataloader
dataset = TensorDataset(input_ids, attention_mask, labels_tensor)
dataloader = DataLoader(dataset, batch_size=2)

# Set up optimizer
optimizer = AdamW(model.parameters(), lr=5e-5)

# Training loop (simplified)
model.train()
for epoch in range(3):  # 3 epochs
    for batch in dataloader:
        batch_input_ids, batch_attention_mask, batch_labels = batch
        
        # Clear gradients
        optimizer.zero_grad()
        
        # Forward pass
        outputs = model(
            input_ids=batch_input_ids, 
            attention_mask=batch_attention_mask, 
            labels=batch_labels
        )
        
        loss = outputs.loss
        
        # Backward pass
        loss.backward()
        
        # Update weights
        optimizer.step()
    
    print(f"Epoch {epoch+1}, Loss: {loss.item()}")
```

## 3. GPT: Generative Pre-trained Transformers

GPT models are designed for text generation and use a unidirectional approach (left-to-right). OpenAI's GPT models have progressed from GPT to GPT-2, GPT-3, and beyond, with increasing parameter sizes.

### Key Features:
- Unidirectional (left-to-right) context
- Autoregressive language modeling for pre-training
- Decoder-only architecture
- Optimized for generation tasks

```python
from transformers import GPT2Model, GPT2Tokenizer, GPT2LMHeadModel

# Load pre-trained GPT-2 model and tokenizer
tokenizer = GPT2Tokenizer.from_pretrained('gpt2')
model = GPT2LMHeadModel.from_pretrained('gpt2')

# Add padding token (not included by default in GPT-2)
tokenizer.pad_token = tokenizer.eos_token

# Example text for generation
prompt = "Artificial intelligence will"

# Encode prompt
inputs = tokenizer(prompt, return_tensors="pt", padding=True)

# Generate text
output = model.generate(
    inputs.input_ids,
    max_length=50,
    num_return_sequences=1,
    temperature=0.7,
    top_k=50,
    top_p=0.95,
    do_sample=True
)

# Decode and print the generated text
generated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Generated text:\n{generated_text}")
```

## 4. T5: Text-to-Text Transfer Transformer

T5 (Text-to-Text Transfer Transformer) frames all NLP tasks as text-to-text problems, providing a unified approach. Developed by Google Research, it uses both encoder and decoder components.

### Key Features:
- Unified text-to-text framework for all NLP tasks
- Encoder-decoder architecture
- Task-specific prefixes (e.g., "translate English to French:", "summarize:")
- Single model for multiple NLP tasks

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

# Load pre-trained T5 model and tokenizer
tokenizer = T5Tokenizer.from_pretrained('t5-small')
model = T5ForConditionalGeneration.from_pretrained('t5-small')

# Example for translation
translation_input = "translate English to German: The house is wonderful."
inputs = tokenizer(translation_input, return_tensors="pt", padding=True)

# Generate translation
output = model.generate(
    inputs.input_ids,
    max_length=40,
    num_beams=4,
    early_stopping=True
)
translated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Translation: {translated_text}")

# Example for summarization
summarization_input = "summarize: " + """
    Transformers have revolutionized natural language processing. 
    They use self-attention mechanisms to process sequential data in parallel.
    This allows for more efficient training and better modeling of long-range dependencies.
    BERT, GPT, and T5 are popular transformer-based architectures that have achieved
    state-of-the-art results on various NLP tasks.
"""
inputs = tokenizer(summarization_input, return_tensors="pt", padding=True)

# Generate summary
output = model.generate(
    inputs.input_ids,
    max_length=30,
    num_beams=4,
    early_stopping=True
)
summary = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Summary: {summary}")
```

## 6. Fine-tuning Pre-trained Models

All three architectures support fine-tuning for specific downstream tasks, but with different approaches:

            # Example structure:
            optimizer.zero_grad()
            outputs = model(**batch)
            loss = outputs.loss
            loss.backward()
            optimizer.step()
            scheduler.step()

### Fine-tuning differences:
- **BERT**: Often fine-tuned for classification, NER, QA by adding task-specific heads
- **GPT**: Fine-tuned through language modeling with task description in the prompt
- **T5**: Fine-tuned by converting all tasks to a text-to-text format with task-specific prefixes

## 7. Implementation Examples and Use Cases

Let's explore common use cases for each architecture:

### BERT for Named Entity Recognition (NER):

```python
from transformers import BertForTokenClassification, BertTokenizer
import torch

# Load pre-trained model for token classification
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertForTokenClassification.from_pretrained('bert-base-cased', num_labels=9)

# Example input
text = "Apple Inc. is headquartered in Cupertino, California and was founded by Steve Jobs."
tokens = tokenizer.tokenize(tokenizer.decode(tokenizer.encode(text)))
inputs = tokenizer(text, return_tensors="pt")

# Get predictions
with torch.no_grad():
    outputs = model(**inputs)

# Get predicted labels
predictions = torch.argmax(outputs.logits, dim=2)
predicted_labels = [model.config.id2label[t.item()] for t in predictions[0]]

# Print tokens and their predicted labels
print("NER Results:")
for token, label in zip(tokens, predicted_labels[:len(tokens)]):
    print(f"{token}: {label}")
```

## 8. Performance Optimization Techniques

Advanced transformer models require significant computing resources. Here are techniques to optimize their performance:

```python
# Several optimization techniques for transformer models

# 1. Quantization example with PyTorch
def quantize_model(model):
    """Quantize a model from FP32 to INT8"""
    # Requires PyTorch 1.8.0 or later
    import torch.quantization
    
    # Define quantization configuration
    model.qconfig = torch.quantization.get_default_qconfig('fbgemm')
    
    # Prepare model for quantization
    model_prepared = torch.quantization.prepare(model)
    
    # Calibrate with some data (dummy example)
    dummy_input = torch.randn(1, 512)
    model_prepared(dummy_input)
    
    # Convert to quantized model
    quantized_model = torch.quantization.convert(model_prepared)
    
    return quantized_model

# 2. Gradient Checkpointing example
def apply_gradient_checkpointing(model):
    """Apply gradient checkpointing to save memory during training"""
    if hasattr(model, 'gradient_checkpointing_enable'):
        model.gradient_checkpointing_enable()
    return model

# 3. Mixed precision training with PyTorch
def setup_mixed_precision():
    """Set up mixed precision training"""
    from torch.cuda.amp import autocast, GradScaler
    
    # Create gradient scaler
    scaler = GradScaler()
    
    # Training step with mixed precision (to be included in training loop)
    def training_step(model, inputs, optimizer):
        optimizer.zero_grad()
        
        # Use autocast for forward pass with reduced precision
        with autocast():
            outputs = model(**inputs)
            loss = outputs.loss
        
        # Scale gradients and perform backward pass
        scaler.scale(loss).backward()
        
        # Unscale gradients for possible gradient clipping
        scaler.unscale_(optimizer)
        
        # Update weights
        scaler.step(optimizer)
        
        # Update scaler for next iteration
        scaler.update()
        
        return loss
    
    return training_step

# 4. Model parallelism (conceptual example)
def setup_model_parallelism(model):
    """Distribute model across multiple GPUs"""
    import torch.nn as nn
    
    # Check if multiple GPUs are available
    if torch.cuda.device_count() > 1:
        print(f"Using {torch.cuda.device_count()} GPUs for model parallelism")
        model = nn.DataParallel(model)
    
    return model
```

## 9. Recent Advancements and Variants

The transformer architecture has evolved significantly with many specialized variants:

    text = "DistilBERT is a smaller, faster version of BERT."

from transformers import RobertaModel, RobertaTokenizer

    tokenizer = RobertaTokenizer.from_pretrained('roberta-base')

## 10. Summary

Advanced transformer architectures have fundamentally transformed NLP with their attention-based mechanisms:

- **BERT** excels in language understanding through bidirectional context modeling, making it ideal for classification, NER, and text understanding tasks.

- **GPT** models focus on text generation with their unidirectional approach, enabling powerful applications in creative writing, chatbots, and code generation.

- **T5** provides a versatile text-to-text framework that unifies NLP tasks, handling translation, summarization, QA, and classification with a single model architecture.

These models share a common foundation in the transformer architecture but differ in their approaches to context processing, pre-training objectives, and application domains. Their development represents a significant leap in machine learning capabilities, enabling more human-like text understanding and generation.

The journey from BERT to GPT to T5 showcases the rapid innovation in deep learning for NLP, with each architecture bringing unique strengths while addressing limitations of previous approaches. As these models continue to evolve, they promise even more powerful and efficient solutions for language processing tasks.
