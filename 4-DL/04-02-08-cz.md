## Úvod do mechanismů pozornosti

Mechanismy pozornosti (attention) způsobily revoluci v hlubokém učení tím, že umožnily modelům soustředit se na relevantní části vstupních dat při zpracování informací. Původně byly zavedeny k řešení omezení modelů typu sequence-to-sequence a nyní jsou základními komponenty moderních architektur neuronových sítí.

Před zavedením attention musely modely jako RNN a LSTM pracovat s dlouhými sekvencemi tak, že komprimovaly všechny informace do vektorů pevné délky. Mechanismus attention tento problém vyřešil tím, že umožnil modelu "podívat se zpět" na vstupní sekvenci a zaměřit se na nejrelevantnější části při generování každého výstupu.

## Typy mechanismů pozornosti

Existuje několik typů mechanismů pozornosti, každý se specifickými případy použití:

1. **Základní pozornost**: Počítá zarovnání mezi dotazem (query) a páry klíč-hodnota (key-value)
2. **Globální pozornost**: Zaměřuje se na všechny zdrojové pozice pro každou cílovou pozici
3. **Lokální pozornost**: Zaměřuje se pouze na podmnožinu pozic v blízkosti konkrétní pozice
4. **Self-attention**: Vztahuje různé pozice jedné sekvence
5. **Cross-attention**: Vztahuje pozice ze dvou různých sekvencí

```python
# Jednoduchý výpočet vah pozornosti
def simple_attention(query, key, value):
    """
    Výpočet vah pozornosti a jejich aplikace na hodnoty
    
    Argumenty:
        query: tensor tvaru [batch_size, query_len, query_dim]
        key: tensor tvaru [batch_size, key_len, key_dim]
        value: tensor tvaru [batch_size, value_len, value_dim]
        
    Vrací:
        output: tensor tvaru [batch_size, query_len, value_dim]
        attention_weights: tensor tvaru [batch_size, query_len, key_len]
    """
    # Výpočet skóre pozornosti
    scores = tf.matmul(query, key, transpose_b=True)
    
    # Škálování skóre (zabraňuje tomu, aby softmax měl extrémně malé gradienty)
    key_dim = tf.cast(tf.shape(key)[-1], tf.float32)
    scaled_scores = scores / tf.math.sqrt(key_dim)
    
    # Aplikace softmax pro získání vah pozornosti
    attention_weights = tf.nn.softmax(scaled_scores, axis=-1)
    
    # Aplikace vah pozornosti na hodnoty
    output = tf.matmul(attention_weights, value)
    
    return output, attention_weights
```

## Self-attention

Self-attention, známý také jako intra-attention, vztahuje různé pozice v rámci jedné sekvence. To umožňuje modelu zachytit závislosti na dlouhé vzdálenosti bez ohledu na jejich vzdálenost ve vstupních nebo výstupních sekvencích. Self-attention je klíčovou součástí architektury Transformer.

Mechanismus self-attention počítá skóre pozornosti pro všechna slova v sekvenci vzhledem k sobě navzájem. Výpočet probíhá ve třech krocích:
1. Transformace každého word embedingu na vektory query, key a value
2. Výpočet skóre pozornosti mezi všemi dotazy a klíči
3. Aplikace těchto vah na hodnoty pro získání reprezentace zohledňující kontext

```python
def self_attention_layer(x, hidden_size=64):
    """
    Jednoduchá vrstva self-attention
    
    Argumenty:
        x: vstupní tensor tvaru [batch_size, seq_len, input_dim]
        hidden_size: dimenze projekcí query, key a value
        
    Vrací:
        output: tensor s aplikovanou self-attention
    """
    # Lineární projekce
    q = layers.Dense(hidden_size)(x)  # Query
    k = layers.Dense(hidden_size)(x)  # Key
    v = layers.Dense(hidden_size)(x)  # Value
    
    # Výpočet pozornosti
    scores = tf.matmul(q, k, transpose_b=True)
    
    # Škálování skóre
    dk = tf.cast(tf.shape(k)[-1], tf.float32)
    scaled_scores = scores / tf.sqrt(dk)
    
    # Softmax pro získání vah pozornosti
    attention_weights = tf.nn.softmax(scaled_scores, axis=-1)
    
    # Aplikace vah pozornosti na hodnoty
    output = tf.matmul(attention_weights, v)
    
    return output, attention_weights
```

## Multi-head attention

Multi-head attention rozšiřuje mechanismus self-attention tím, že provádí více operací pozornosti paralelně. To umožňuje modelu zaměřit se na informace z různých reprezentačních podprostorů a zachytit různé typy vztahů v rámci stejných dat.

Každá "hlava" provádí svou vlastní kalkulaci pozornosti s různými naučenými projekcemi a jejich výstupy jsou spojeny a lineárně transformovány pro vytvoření konečného výsledku.

```python
class MultiHeadAttention(layers.Layer):
    def __init__(self, d_model, num_heads):
        super(MultiHeadAttention, self).__init__()
        self.num_heads = num_heads
        self.d_model = d_model
        
        assert d_model % self.num_heads == 0
        
        self.depth = d_model // self.num_heads
        
        self.wq = layers.Dense(d_model)
        self.wk = layers.Dense(d_model)
        self.wv = layers.Dense(d_model)
        
        self.dense = layers.Dense(d_model)
    
    def split_heads(self, x, batch_size):
        """Rozdělí poslední dimenzi na (num_heads, depth)."""
        x = tf.reshape(x, (batch_size, -1, self.num_heads, self.depth))
        return tf.transpose(x, perm=[0, 2, 1, 3])
    
    def call(self, v, k, q, mask=None):
        batch_size = tf.shape(q)[0]
        
        q = self.wq(q)  # (batch_size, seq_len, d_model)
        k = self.wk(k)  # (batch_size, seq_len, d_model)
        v = self.wv(v)  # (batch_size, seq_len, d_model)
        
        q = self.split_heads(q, batch_size)  # (batch_size, num_heads, seq_len_q, depth)
        k = self.split_heads(k, batch_size)  # (batch_size, num_heads, seq_len_k, depth)
        v = self.split_heads(v, batch_size)  # (batch_size, num_heads, seq_len_v, depth)
        
        # Škálovaná dot-product pozornost
        scaled_attention, attention_weights = self.scaled_dot_product_attention(
            q, k, v, mask)
        
        scaled_attention = tf.transpose(scaled_attention, perm=[0, 2, 1, 3])  # (batch_size, seq_len_q, num_heads, depth)
        
        concat_attention = tf.reshape(scaled_attention, 
                                      (batch_size, -1, self.d_model))  # (batch_size, seq_len_q, d_model)
        
        output = self.dense(concat_attention)  # (batch_size, seq_len_q, d_model)
        
        return output, attention_weights
    
    def scaled_dot_product_attention(self, q, k, v, mask=None):
        """Výpočet vah pozornosti."""
        matmul_qk = tf.matmul(q, k, transpose_b=True)  # (..., seq_len_q, seq_len_k)
        
        # Škálování matmul_qk
        dk = tf.cast(tf.shape(k)[-1], tf.float32)
        scaled_attention_logits = matmul_qk / tf.sqrt(dk)
        
        # Přidání masky k škálovanému tenzoru (pokud je poskytnuta)
        if mask is not None:
            scaled_attention_logits += (mask * -1e9)
        
        # Softmax se aplikuje na poslední osu (seq_len_k)
        attention_weights = tf.nn.softmax(scaled_attention_logits, axis=-1)  # (..., seq_len_q, seq_len_k)
        
        output = tf.matmul(attention_weights, v)  # (..., seq_len_q, depth_v)
        
        return output, attention_weights
```

## Pozornost v sekvenčních modelech

Pozornost byla původně navržena pro zlepšení modelů sequence-to-sequence, jako jsou modely používané ve strojovém překladu. V sekvenčních úlohách pozornost umožňuje dekodéru zaměřit se na relevantní části vstupní sekvence při generování každého slova výstupu.

Klasický enkodér-dekodér s pozorností postupuje následovně:
1. Enkodér zpracuje vstupní sekvenci a vytvoří skryté stavy
2. Pro každý krok dekodéru jsou vypočteny váhy pozornosti mezi aktuálním stavem dekodéru a všemi stavy enkodéru
3. Kontextový vektor je vypočítán jako vážený součet stavů enkodéru
4. Dekodér používá jak svůj stav, tak kontextový vektor k predikci dalšího výstupu

```python
# Základní model seq2seq s pozorností
class Seq2SeqWithAttention(tf.keras.Model):
    def __init__(self, vocab_size, embedding_dim, encoder_units, decoder_units):
        super(Seq2SeqWithAttention, self).__init__()
        self.encoder = Encoder(vocab_size, embedding_dim, encoder_units)
        self.attention = BahdanauAttention(decoder_units)
        self.decoder = Decoder(vocab_size, embedding_dim, decoder_units)
        
    def call(self, inputs, training=False):
        input_seq, target_seq = inputs
        
        # Kódování vstupní sekvence
        encoder_output, encoder_hidden = self.encoder(input_seq)
        
        # Inicializace stavu dekodéru konečným stavem enkodéru
        decoder_hidden = encoder_hidden
        decoder_input = tf.expand_dims(target_seq[:, 0], 1)
        
        outputs = []
        
        # Teacher forcing - použití cíle jako dalšího vstupu
        for t in range(1, target_seq.shape[1]):
            # Použití pozornosti k výpočtu kontextového vektoru
            context_vector, attention_weights = self.attention(decoder_hidden, encoder_output)
            
            # Předání výstupu enkodéru (kontextu) dekodéru
            decoder_output, decoder_hidden = self.decoder(
                decoder_input, decoder_hidden, context_vector)
            
            outputs.append(decoder_output)
            
            # Použití teacher forcingu
            decoder_input = tf.expand_dims(target_seq[:, t], 1)
        
        return tf.stack(outputs, axis=1)

class BahdanauAttention(tf.keras.layers.Layer):
    def __init__(self, units):
        super(BahdanauAttention, self).__init__()
        self.W1 = tf.keras.layers.Dense(units)
        self.W2 = tf.keras.layers.Dense(units)
        self.V = tf.keras.layers.Dense(1)
        
    def call(self, query, values):
        # query: skrytý stav dekodéru, tvar == (batch_size, hidden size)
        # values: výstup enkodéru, tvar == (batch_size, max_len, hidden size)
        
        # Rozšíření dimenzí query pro shodování s dimenzemi values
        query_with_time_axis = tf.expand_dims(query, 1)
        
        # Funkce skóre: tanh(W1(query) + W2(values))
        score = self.V(tf.nn.tanh(
            self.W1(query_with_time_axis) + self.W2(values)))
        
        # Váhy pozornosti, tvar == (batch_size, max_length, 1)
        attention_weights = tf.nn.softmax(score, axis=1)
        
        # Kontextový vektor, tvar == (batch_size, hidden_size)
        context_vector = attention_weights * values
        context_vector = tf.reduce_sum(context_vector, axis=1)
        
        return context_vector, attention_weights
```

## Implementace pozornosti v Pythonu

Zde je implementace modelu založeného na pozornosti pro úlohu klasifikace textu pomocí TensorFlow/Keras:

```python
import tensorflow as tf
from tensorflow.keras import layers, Model

# Ukázkový model klasifikace textu s pozorností
def build_attention_classification_model(vocab_size, embedding_dim, maxlen, num_classes):
    """
    Sestavení modelu klasifikace textu s pozorností
    
    Argumenty:
        vocab_size: velikost slovníku
        embedding_dim: dimenze embeddings
        maxlen: maximální délka vstupních sekvencí
        num_classes: počet výstupních tříd
        
    Vrací:
        Keras model s mechanismem pozornosti
    """
    # Vstupní vrstva
    inputs = layers.Input(shape=(maxlen,))
    
    # Vrstva embedding
    embedding = layers.Embedding(input_dim=vocab_size, 
                                output_dim=embedding_dim,
                                input_length=maxlen)(inputs)
    
    # Bidirectional LSTM pro zpracování sekvence
    lstm = layers.Bidirectional(
        layers.LSTM(128, return_sequences=True))(embedding)
    
    # Mechanismus pozornosti
    attention = layers.Dense(1, activation='tanh')(lstm)
    attention = layers.Flatten()(attention)
    attention_weights = layers.Activation('softmax')(attention)
    
    # Změna tvaru vah pozornosti pro aplikaci na výstupy LSTM
    attention_weights = layers.RepeatVector(256)(attention_weights)
    attention_weights = layers.Permute([2, 1])(attention_weights)
    
    # Aplikace vah pozornosti na výstupy LSTM
    weighted_lstm = layers.Multiply()([lstm, attention_weights])
    context_vector = layers.Lambda(lambda x: tf.reduce_sum(x, axis=1))(weighted_lstm)
    
    # Výstupní vrstva
    outputs = layers.Dense(num_classes, activation='softmax')(context_vector)
    
    # Vytvoření a kompilace modelu
    model = Model(inputs=inputs, outputs=outputs)
    model.compile(optimizer='adam',
                 loss='categorical_crossentropy',
                 metrics=['accuracy'])
    
    return model
```

## Vizualizace pozornosti

Vizualizace vah pozornosti pomáhá porozumět tomu, na co se model zaměřuje, což může poskytnout informace o chování modelu. Zde je způsob, jak vizualizovat váhy pozornosti pro textová data:

```python
def plot_attention(input_text, attention_weights, tokenizer):
    """
    Vizualizace vah pozornosti pro textová data
    
    Argumenty:
        input_text: původní vstupní text
        attention_weights: váhy pozornosti z modelu
        tokenizer: tokenizer použitý ke zpracování textu
    """
    # Tokenizace vstupního textu
    tokens = tokenizer.texts_to_sequences([input_text])[0]
    token_words = [tokenizer.index_word[token] for token in tokens]
    
    # Získání vah pozornosti pro sekvenci
    weights = attention_weights[0][:len(tokens)]
    
    # Vytvoření heatmap vizualizace
    plt.figure(figsize=(12, 6))
    plt.imshow(weights.reshape(1, -1), cmap='viridis')
    plt.yticks([])
    plt.xticks(range(len(token_words)), token_words, rotation=45)
    plt.colorbar()
    plt.title('Váhy pozornosti')
    plt.tight_layout()
    plt.show()
    
    # Vizualizace sloupcovým grafem
    plt.figure(figsize=(12, 4))
    plt.bar(range(len(token_words)), weights, alpha=0.6)
    plt.xticks(range(len(token_words)), token_words, rotation=45)
    plt.title('Distribuce vah pozornosti')
    plt.tight_layout()
    plt.show()
```

## Aplikace mechanismů pozornosti

Mechanismy pozornosti byly úspěšně aplikovány v mnoha doménách a aplikacích:

1. **Strojový překlad**: Zvyšuje kvalitu překladů, zejména pro delší věty
2. **Popisování obrázků**: Umožňuje modelu zaměřit se na specifické části obrázku při generování slov popisu
3. **Rozpoznávání řeči**: Zlepšuje rozpoznávání zaměřením se na relevantní zvukové segmenty
4. **Zdravotnictví**: Identifikuje důležité rysy v lékařských záznamech nebo obrazových datech
5. **Sumarizace dokumentů**: Pomáhá identifikovat nejdůležitější věty pro zahrnutí do souhrnu

```python
# Příklad attention pro popisování obrázků
def build_image_caption_model(vocab_size, max_length, embedding_dim=256, units=512):
    """
    Sestavení modelu pro popisování obrázků s pozorností
    
    Argumenty:
        vocab_size: velikost slovníku
        max_length: maximální délka popisků
        embedding_dim: dimenze slovních embeddingů
        units: počet jednotek LSTM
        
    Vrací:
        encoder model, decoder model
    """
    # Extraktor příznaků (např. CNN předtrénovaný na ImageNet)
    image_model = tf.keras.applications.InceptionV3(
        include_top=False,
        weights='imagenet'
    )
    
    # Extrakce příznaků na specifické vrstvě
    image_model.trainable = False
    output_layer = image_model.get_layer('mixed7')
    
    # Encoder
    inputs = image_model.input
    features = output_layer.output
    features = layers.Reshape((-1, features.shape[-1]))(features)
    encoder = Model(inputs=inputs, outputs=features)
    
    # Decoder s pozorností
    decoder_inputs = layers.Input(shape=(max_length,))
    decoder_lstm = layers.LSTM(units, return_sequences=True, return_state=True)
    decoder_embedding = layers.Embedding(vocab_size, embedding_dim)
    
    # Mechanismus pozornosti
    attention = BahdanauAttention(units)  # Použití třídy pozornosti definované výše
    
    # Dense vrstvy pro predikci
    dense1 = layers.Dense(units)
    dense2 = layers.Dense(vocab_size)
    
    def decode_sequence(features, caption):
        embedded = decoder_embedding(caption)
        
        # Inicializace stavů decoderu nulami
        hidden = tf.zeros((tf.shape(caption)[0], units))
        cell = tf.zeros((tf.shape(caption)[0], units))
        
        outputs = []
        
        for i in range(1, max_length):
            context_vector, attention_weights = attention(hidden, features)
            
            # Kombinace vloženého vstupu a kontextového vektoru
            x = tf.concat([tf.expand_dims(context_vector, 1), 
                           tf.expand_dims(embedded[:, i-1], 1)], axis=-1)
            
            # Spuštění kroku LSTM
            output, hidden, cell = decoder_lstm(x, initial_state=[hidden, cell])
            
            # Generování predikce
            output = dense1(output)
            output = dense2(output)
            
            outputs.append(output)
        
        return tf.concat(outputs, axis=1)
    
    # Propojení decoderu s encoderem
    decoder_outputs = decode_sequence(encoder.output, decoder_inputs)
    decoder = Model([image_model.input, decoder_inputs], decoder_outputs)
    
    return encoder, decoder

# Poznámka: Toto je zjednodušený příklad. Kompletní implementace by vyžadovala
# správnou trénovací logiku, beam search pro inference atd.
```

## Běžné výzvy a řešení

Práce s mechanismy pozornosti přináší několik výzev:

1. **Výpočetní složitost**: Operace pozornosti rostou kvadraticky s délkou sekvence (O(n²))
   - **Řešení**: Implementace efektivních algoritmů pozornosti jako Linformer, Reformer nebo Longformer

2. **Paměťové nároky**: Ukládání vah pozornosti pro dlouhé sekvence může být náročné na paměť
   - **Řešení**: Použití gradient checkpointing nebo paměťově efektivních implementací

3. **Mizející gradienty**: Ve velmi hlubokých sítích s pozorností
   - **Řešení**: Implementace reziduálních spojení a normalizace vrstev

4. **Interpretace pozornosti**: Porozumění tomu, co váhy pozornosti skutečně reprezentují
   - **Řešení**: Použití vizualizačních technik a provádění ablačních studií

```python
# Příklad řídké pozornosti pro snížení výpočetní složitosti
def sparse_attention(q, k, v, sparsity_factor=2):
    """
    Výpočet řídké pozornosti pro snížení výpočetní složitosti
    
    Argumenty:
        q: query tensor
        k: key tensor
        v: value tensor
        sparsity_factor: faktor pro redukci výpočtu pozornosti
        
    Vrací:
        výstup s aplikovanou pozorností
    """
    batch_size, num_heads, seq_len, depth = q.shape
    
    # Pozornost pouze na každé n-té pozici
    sparse_indices = tf.range(0, seq_len, sparsity_factor)
    
    # Výběr řídkých keys a values
    sparse_k = tf.gather(k, sparse_indices, axis=2)
    sparse_v = tf.gather(v, sparse_indices, axis=2)
    
    # Výpočet pozornosti s redukovanou sadou klíčů
    scores = tf.matmul(q, sparse_k, transpose_b=True)
    
    # Škálování skóre
    dk = tf.cast(tf.shape(sparse_k)[-1], tf.float32)
    scaled_scores = scores / tf.sqrt(dk)
    
    # Aplikace softmax
    attention_weights = tf.nn.softmax(scaled_scores, axis=-1)
    
    # Aplikace vah pozornosti na řídké hodnoty
    output = tf.matmul(attention_weights, sparse_v)
    
    return output

# Poznámka: Toto je zjednodušený příklad řídké pozornosti.
# Sofistikovanější implementace jako lokální vzory pozornosti nebo
# naučené vzory řídkosti by byly použity v produkčních systémech.
```

## Shrnutí

Mechanismy pozornosti transformovaly hluboké učení tím, že poskytly modelům schopnost soustředit se na relevantní části vstupu při generování výstupu. Klíčové poznatky zahrnují:

1. **Základy**: Pozornost počítá skóre relevance mezi prvky v sekvencích, což umožňuje modelům vážit důležitost různých vstupů.

2. **Typy pozornosti**: Existují různé mechanismy pozornosti, včetně základní pozornosti, self-attention a multi-head attention, z nichž každý slouží specifickým účelům.

3. **Self-Attention**: Umožňuje vztahovat různé pozice jedné sekvence, což tvoří základ moderních architektur jako jsou Transformery.

4. **Multi-Head Attention**: Rozšiřuje self-attention tím, že umožňuje modelům zaměřit se současně na různé reprezentační podprostory.

5. **Aplikace**: Pozornost způsobila revoluci v NLP úlohách jako strojový překlad a byla úspěšně aplikována i v jiných doménách včetně počítačového vidění a zdravotnictví.

6. **Vizualizace**: Váhy pozornosti lze vizualizovat pro interpretaci chování modelu a získání vhledu do rozhodovacího procesu.

7. **Výzvy**: Navzdory svým výhodám čelí mechanismy pozornosti problémům jako výpočetní složitost a paměťové nároky, zejména pro dlouhé sekvence.

8. **Budoucí směry**: Výzkum pokračuje ve vývoji efektivnějších mechanismů pozornosti a rozšiřování jejich aplikací do nových domén.

Mechanismy pozornosti představují jeden z nejvýznamnějších nedávných pokroků v hlubokém učení, umožňující silnější, interpretovatelné a flexibilní modely napříč širokou škálou aplikací.
