## 1. Úvod do difuzních modelů

Difuzní modely jsou třída generativních modelů, které způsobily revoluci v obsahu vytvářeném pomocí umělé inteligence, zejména v generování obrazů. Fungují na principu postupného přidávání šumu do dat a následného učení, jak tento proces obrátit a generovat nové vzorky.


Základní myšlenka difuzních modelů spočívá v transformaci složité distribuce dat na jednoduchou (jako je Gaussův šum) prostřednictvím postupného procesu "difuze" a následném učení, jak tuto transformaci obrátit a generovat nová data.

## 2. Matematické základy difuzních procesů

Difuzní modely jsou založeny na nerovnovážné termodynamice. Proces zahrnuje dvě hlavní komponenty:

1. **Dopředný proces (difuze)**: Postupné přidávání šumu do dat
2. **Zpětný proces (odšumění)**: Učení, jak obrátit přidávání šumu

```python
def forward_diffusion(x_0, t, beta_schedule):
    """
    Přidání šumu do vstupních dat podle difuzního plánu
    
    Args:
        x_0: Původní obrázek
        t: Časový krok
        beta_schedule: Plán rozptylu šumu
        
    Returns:
        Zašuměný obrázek v časovém kroku t a přidaný šum
    """
    # Extrahování úrovně šumu v časovém kroku t
    beta_t = beta_schedule[t]
    
    # Výpočet kumulativního součinu (1 - beta) od 0 do t
    alpha_t = torch.prod(1 - beta_schedule[:t+1])
    
    # Vzorkování šumu ze standardního normálního rozdělení
    epsilon = torch.randn_like(x_0)
    
    # Přidání šumu podle difuzní rovnice
    x_t = torch.sqrt(alpha_t) * x_0 + torch.sqrt(1 - alpha_t) * epsilon
    
    return x_t, epsilon
```

Matematický model zahrnuje Markovův řetězec difuzních kroků, kde každý krok přidává malé množství Gaussova šumu podle předem definovaného plánu.

## 3. Dopředná a zpětná difuze

**Dopředná difuze**: Tento proces postupně přidává Gaussův šum do obrázku, dokud se nestane čistým šumem.

**Zpětná difuze**: Cílem je naučit se obrátit tento proces, začít od čistého šumu a postupně odstraňovat šum až k čistému vzorku.

```python
class SimpleDiffusionModel(nn.Module):
    def __init__(self, n_steps=1000):
        super().__init__()
        # Definování plánu beta (úroveň šumu v každém časovém kroku)
        self.n_steps = n_steps
        self.beta_start = 1e-4
        self.beta_end = 2e-2
        self.beta_schedule = torch.linspace(self.beta_start, self.beta_end, n_steps)
        self.alpha_schedule = 1 - self.beta_schedule
        self.alpha_bar_schedule = torch.cumprod(self.alpha_schedule, dim=0)
        
        # Jednoduchá U-Net pro predikci šumu
        self.model = self._build_unet()
        
    def _build_unet(self):
        # Zástupný kód pro architekturu U-Net
        # V praxi by se jednalo o řádnou U-Net s vrstvami attention
        return nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(64, 64, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(64, 3, 3, padding=1)
        )
    
    def forward(self, x_t, t):
        """Předpověď šumu v zašuměném obrázku v časovém kroku t"""
        # Ve skutečném modelu by t bylo embedováno a použito k podmínění U-Net
        return self.model(x_t)
    
    def sample(self, n_samples, img_size, device):
        """Generování vzorků pomocí zpětného difuzního procesu"""
        # Začínáme s čistým šumem
        x_t = torch.randn(n_samples, 3, img_size, img_size, device=device)
        
        # Postupné odšumění obrazů
        for t in tqdm(range(self.n_steps-1, 0, -1)):
            # Předpověď šumu
            predicted_noise = self.forward(x_t, t)
            
            # Výpočet parametrů pro odšumovací krok
            alpha_t = self.alpha_schedule[t]
            alpha_t_prev = self.alpha_schedule[t-1] if t > 0 else torch.tensor(1.0)
            beta_t = 1 - alpha_t/alpha_t_prev
            
            # Přidání šumu pro stochasticitu (pouze pokud t > 0)
            if t > 0:
                noise = torch.randn_like(x_t)
            else:
                noise = 0
            
            # Aktualizace x_t pomocí odšumovací rovnice
            x_t = 1/torch.sqrt(alpha_t) * (x_t - (beta_t/torch.sqrt(1-self.alpha_bar_schedule[t])) * predicted_noise) + torch.sqrt(beta_t) * noise
            
        return x_t
```

Toto představuje zjednodušenou implementaci. V praxi difuzní modely používají složitější architektury a strategie pro predikci šumu.

## 4. Architektura difuzních modelů

Jádrem difuzního modelu je typicky architektura U-Net, která predikuje složku šumu v zašuměném obrazu. U-Net je podmíněn časovým krokem difuze, který říká modelu, kolik šumu je přítomno.

```python
class TimeEmbedding(nn.Module):
    """Vrstva pro embedding časových kroků"""
    def __init__(self, time_dim):
        super().__init__()
        self.time_dim = time_dim
        self.time_mlp = nn.Sequential(
            nn.Linear(1, time_dim),
            nn.SiLU(),
            nn.Linear(time_dim, time_dim)
        )
        
    def forward(self, t):
        # Vytvoření sinusoidálních poziční embeddingů (podobně jako Transformer)
        embeddings = self.time_mlp(t.unsqueeze(-1).float())
        return embeddings

class UNetBlock(nn.Module):
    """Základní stavební blok U-Net s časovým podmíněním"""
    def __init__(self, in_channels, out_channels, time_dim):
        super().__init__()
        self.time_mlp = nn.Sequential(
            nn.SiLU(),
            nn.Linear(time_dim, out_channels)
        )
        
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, padding=1)
        self.norm1 = nn.GroupNorm(8, out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, padding=1)
        self.norm2 = nn.GroupNorm(8, out_channels)
        self.act = nn.SiLU()
        
    def forward(self, x, t):
        # První konvoluční blok
        h = self.act(self.norm1(self.conv1(x)))
        
        # Časové podmínění
        time_emb = self.time_mlp(t)[:, :, None, None]  # Změna tvaru pro broadcast
        h = h + time_emb
        
        # Druhý konvoluční blok
        h = self.act(self.norm2(self.conv2(h)))
        return h
```

Kompletní architektura U-Net by zahrnovala:
- Enkodérové bloky, které podvzorkovávají obraz
- Střední blok s vrstvami attention
- Dekodérové bloky, které nadvzorkovávají s přeskočenými spojeními z enkodéru
- Časové embeddování pro podmínění na difuzním časovém kroku

## 5. Trénování difuzních modelů

Trénování zahrnuje učení modelu předpovídat šum přidaný během dopředného procesu. Ztrátová funkce je typicky jednoduchá střední kvadratická chyba mezi predikovaným a skutečným šumem.

```python
def train_diffusion_model(model, dataloader, optimizer, device, epochs=10):
    """Trénování difuzního modelu"""
    model.train()
    
    for epoch in range(epochs):
        epoch_loss = 0.0
        for batch in tqdm(dataloader):
            # Přesun obrázků na zařízení
            real_images = batch[0].to(device)
            batch_size = real_images.shape[0]
            
            # Vzorkování náhodných časových kroků
            t = torch.randint(0, model.n_steps, (batch_size,), device=device)
            
            # Přidání šumu podle t
            noise = torch.randn_like(real_images)
            alpha_bar_t = model.alpha_bar_schedule[t].view(-1, 1, 1, 1)
            noisy_images = torch.sqrt(alpha_bar_t) * real_images + torch.sqrt(1 - alpha_bar_t) * noise
            
            # Predikce šumu
            optimizer.zero_grad()
            noise_pred = model(noisy_images, t)
            
            # Výpočet ztráty
            loss = torch.nn.functional.mse_loss(noise_pred, noise)
            loss.backward()
            optimizer.step()
            
            epoch_loss += loss.item()
        
        print(f"Epocha {epoch+1}, Ztráta: {epoch_loss/len(dataloader):.6f}")
    
    return model
```

Cílem tréninku je minimalizovat rozdíl mezi predikovaným šumem a skutečným šumem, který byl přidán během dopředného difuzního procesu.

## 6. Model Stable Diffusion

Stable Diffusion je konkrétní implementace difuzních modelů, která byla vyvinuta společností Stability AI a vydána v roce 2022. Pracuje v komprimovaném latentním prostoru místo prostoru pixelů, což ji činí efektivnější.

```python
# Instalace knihoven pro stable diffusion
# pip install diffusers transformers accelerate

from diffusers import StableDiffusionPipeline
import torch

def generate_image_with_stable_diffusion(prompt, model_id="runwayml/stable-diffusion-v1-5"):
    """Generování obrázku pomocí Stable Diffusion na základě textového promptu"""
    # Načtení pipeline
    pipe = StableDiffusionPipeline.from_pretrained(
        model_id,
        torch_dtype=torch.float16
    )
    
    # Přesun na GPU, pokud je k dispozici
    device = "cuda" if torch.cuda.is_available() else "cpu"
    pipe = pipe.to(device)
    
    # Generování obrázku
    with torch.autocast(device):
        image = pipe(prompt).images[0]
    
    return image

# Příklad použití
prompt = "Krásná horská krajina při západu slunce, digitální umění"
image = generate_image_with_stable_diffusion(prompt)
image.save("stable_diffusion_output.png")
```

Klíčové vlastnosti Stable Diffusion:
- Pracuje v latentním prostoru autoenkodéru (VAE)
- Používá podmíněný U-Net jako odšumovací síť
- Zahrnuje textové podmínění pomocí textového enkodéru (jako CLIP)
- Umožňuje různá nastavení jako guidance scale pro přilnavost k promptu

## 7. Implementace difuzních modelů v Pythonu

Zde je praktičtější příklad využívající knihovnu diffusers k implementaci vlastní trénovací smyčky pro difuzní model:

```python
from diffusers import UNet2DModel, DDPMScheduler
from datasets import load_dataset
from torchvision import transforms

# Načtení datasetu
dataset = load_dataset("huggan/flowers-102-categories", split="train")

# Definice transformací
image_transforms = transforms.Compose([
    transforms.Resize((128, 128)),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize([0.5], [0.5]),
])

def transform_images(examples):
    examples["pixel_values"] = [image_transforms(image.convert("RGB")) for image in examples["image"]]
    return examples

transformed_dataset = dataset.with_transform(transform_images)
train_dataloader = torch.utils.data.DataLoader(transformed_dataset, batch_size=8, shuffle=True)

# Inicializace modelu
model = UNet2DModel(
    sample_size=128,           # Velikost obrázku
    in_channels=3,             # RGB obrázky
    out_channels=3,            # RGB predikce
    layers_per_block=2,        # Vrstvy na blok U-Net
    block_out_channels=(64, 128, 256, 512),  # Dimenze kanálů
    down_block_types=(
        "DownBlock2D",
        "DownBlock2D",
        "DownBlock2D",
        "AttnDownBlock2D",
    ),
    up_block_types=(
        "AttnUpBlock2D",
        "UpBlock2D",
        "UpBlock2D",
        "UpBlock2D",
    ),
)

# Inicializace plánovače šumu
noise_scheduler = DDPMScheduler(num_train_timesteps=1000)

# Nastavení tréninku
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-4)
device = "cuda" if torch.cuda.is_available() else "cpu"
model.to(device)

# Trénovací smyčka (zjednodušená)
def train():
    for epoch in range(30):
        model.train()
        progress_bar = tqdm(total=len(train_dataloader))
        for batch in train_dataloader:
            clean_images = batch["pixel_values"].to(device)
            batch_size = clean_images.shape[0]
            
            # Vzorkování šumu a časových kroků
            noise = torch.randn(clean_images.shape).to(device)
            timesteps = torch.randint(
                0, noise_scheduler.num_train_timesteps, (batch_size,), device=device
            ).long()
            
            # Přidání šumu podle plánu
            noisy_images = noise_scheduler.add_noise(clean_images, noise, timesteps)
            
            # Predikce šumu
            noise_pred = model(noisy_images, timesteps).sample
            
            # Výpočet ztráty
            loss = torch.nn.functional.mse_loss(noise_pred, noise)
            
            # Optimalizace
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            progress_bar.update(1)
            progress_bar.set_postfix(loss=loss.item())
            
        # Uložení checkpointu
        if epoch % 5 == 0:
            torch.save(model.state_dict(), f"diffusion_model_epoch_{epoch}.pt")
```

## 8. Aplikace difuzních modelů

Difuzní modely našly řadu aplikací:

```python
# Generování obrazu s textovým podmíněním
def conditional_image_generation(text_prompt, model, text_encoder, device):
    """Generování obrázku podmíněného textem pomocí difuzního modelu"""
    # Kódování textového promptu
    text_embedding = text_encoder(text_prompt).to(device)
    
    # Začínáme od náhodného šumu
    image_size = 64  # Příkladová velikost
    channels = 3     # RGB
    batch_size = 1
    
    # Inicializace náhodným šumem
    image = torch.randn(batch_size, channels, image_size, image_size).to(device)
    
    # Proces zpětné difuze
    for t in tqdm(range(model.n_steps-1, -1, -1)):
        # Předání časového kroku a textového embeddingu do modelu
        with torch.no_grad():
            predicted_noise = model(image, torch.tensor([t]).to(device), text_embedding)
            
        # Aktualizace obrázku pomocí predikovaného šumu
        # (Zjednodušeno - skutečná rovnice by závisela na konkrétním plánovači)
        alpha = model.alpha_schedule[t]
        alpha_prev = model.alpha_schedule[t-1] if t > 0 else torch.tensor(1.0)
        sigma = torch.sqrt((1 - alpha_prev) / (1 - alpha)) * torch.sqrt(1 - alpha / alpha_prev)
        
        # Přidání šumu pouze pro t > 0
        z = torch.randn_like(image) if t > 0 else 0
        image = (1 / torch.sqrt(alpha)) * (image - (1 - alpha) / torch.sqrt(1 - alpha) * predicted_noise) + sigma * z
    
    # Převod na formát obrázku
    image = (image.clamp(-1, 1) + 1) / 2
    image = (image * 255).type(torch.uint8)
    return image
```

Další aplikace zahrnují:
1. **Doplňování obrázků (inpainting)**: Vyplnění chybějících částí obrázků
2. **Zvýšení rozlišení (super-resolution)**: Vylepšení rozlišení obrázku
3. **Převod mezi doménami obrázků (image-to-image translation)**: Převod mezi doménami obrázků
4. **Generování videa**: Vytváření videa z promptů
5. **Generování 3D modelů**: Generování 3D objektů

## 9. Srovnání s jinými generativními modely

Difuzní modely mají několik výhod a nevýhod ve srovnání s jinými generativními přístupy:

```python
import matplotlib.pyplot as plt
import numpy as np

# Vizualizace vzorků z různých generativních modelů
def compare_generative_models(samples_dict):
    """Porovnání vzorků z různých generativních modelů"""
    fig, axes = plt.subplots(1, len(samples_dict), figsize=(15, 5))
    
    for i, (model_name, sample) in enumerate(samples_dict.items()):
        axes[i].imshow(sample)
        axes[i].set_title(model_name)
        axes[i].axis('off')
    
    plt.tight_layout()
    plt.show()

# Vytvoření jednoduchého porovnání vlastností modelů
def plot_model_comparison():
    models = ['GAN', 'VAE', 'Diffusion', 'Flow-based']
    metrics = {
        'Kvalita vzorků': [0.7, 0.5, 0.9, 0.6],
        'Stabilita tréninku': [0.3, 0.8, 0.7, 0.75],
        'Rychlost inference': [0.9, 0.8, 0.2, 0.7],
        'Pokrytí módů': [0.4, 0.7, 0.85, 0.75],
    }
    
    fig, ax = plt.subplots(figsize=(10, 6))
    x = np.arange(len(models))
    width = 0.2
    multiplier = 0
    
    for attribute, score in metrics.items():
        offset = width * multiplier
        ax.bar(x + offset, score, width, label=attribute)
        multiplier += 1
    
    ax.set_xlabel('Generativní modely')
    ax.set_ylabel('Skóre (vyšší je lepší)')
    ax.set_title('Porovnání generativních modelů')
    ax.set_xticks(x + width, models)
    ax.legend(loc='upper left', bbox_to_anchor=(1, 1))
    ax.set_ylim(0, 1)
    
    plt.tight_layout()
    plt.show()
```

Klíčová srovnání:
- **GANy**: Rychlejší inference, ale méně stabilní trénink; často problémy s kolapsem módů
- **VAE**: Stabilní trénink, ale rozmazanější vzorky
- **Flow-based modely**: Přesná věrohodnost, ale omezující architektury
- **Difuzní modely**: Vysoce kvalitní vzorky, stabilní trénink, ale pomalá inference

## 10. Shrnutí

Difuzní modely představují významný pokrok v generativní umělé inteligenci, zejména pro syntézu obrazů. Fungují na principu učení se obrácení postupného procesu přidávání šumu a poskytují vysoce kvalitní a rozmanité výstupy.

3. Stable Diffusion je populární implementace, která pracuje v latentním prostoru

```python
def create_image_variation(input_image_path, prompt, strength=0.75):
```
