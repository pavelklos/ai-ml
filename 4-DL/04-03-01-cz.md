## 2. BERT: Bidirectional Encoder Representations from Transformers

BERT využívá obousměrný přístup pro pochopení kontextu z obou směrů v textu. Byl vyvinut společností Google a představen v roce 2018.

### Klíčové vlastnosti:
- Obousměrné porozumění kontextu
- Předtrénování pomocí Masked Language Model (MLM)
- Předtrénování Next Sentence Prediction (NSP)
- Architektura založená pouze na enkodéru

```python
from transformers import BertModel, BertTokenizer

# Načtení předtrénovaného modelu BERT a tokenizéru
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

# Příklad textu
text = "The Transformer architecture revolutionized natural language processing."

# Tokenizace vstupu
inputs = tokenizer(text, return_tensors="pt", padding=True, truncation=True, max_length=512)

# Získání embeddingů z BERTu
with torch.no_grad():
    outputs = model(**inputs)

# Extrahování posledních skrytých stavů (kontextové embeddingy)
last_hidden_states = outputs.last_hidden_state
print(f"Tvar embeddingů: {last_hidden_states.shape}")  # [batch_size, seq_length, hidden_size]

# Extrahování reprezentace tokenu [CLS] (často používaná pro klasifikační úlohy)
cls_embedding = last_hidden_states[:, 0, :]
print(f"Tvar [CLS] embeddingu: {cls_embedding.shape}")  # [batch_size, hidden_size]
```

### Dolaďování BERTu pro klasifikaci sentimentu:

```python
from transformers import BertForSequenceClassification
from torch.optim import AdamW
from torch.utils.data import DataLoader, TensorDataset

# Načtení předtrénovaného modelu pro klasifikaci sekvencí (např. 2 třídy pro sentiment)
model = BertForSequenceClassification.from_pretrained('bert-base-uncased', num_labels=2)

# Příklad dat (v praxi byste načetli skutečný dataset)
texts = ["I love this product!", "This movie was terrible", "Great service, highly recommend"]
labels = [1, 0, 1]  # 1 pro pozitivní, 0 pro negativní

# Tokenizace všech textů
encoded_data = tokenizer(texts, padding=True, truncation=True, return_tensors="pt")
input_ids = encoded_data['input_ids']
attention_mask = encoded_data['attention_mask']
labels_tensor = torch.tensor(labels)

# Vytvoření datasetu a dataloaderu
dataset = TensorDataset(input_ids, attention_mask, labels_tensor)
dataloader = DataLoader(dataset, batch_size=2)

# Nastavení optimalizátoru
optimizer = AdamW(model.parameters(), lr=5e-5)

# Tréninková smyčka (zjednodušená)
model.train()
for epoch in range(3):  # 3 epochy
    for batch in dataloader:
        batch_input_ids, batch_attention_mask, batch_labels = batch
        
        # Vynulování gradientů
        optimizer.zero_grad()
        
        # Dopředný průchod
        outputs = model(
            input_ids=batch_input_ids, 
            attention_mask=batch_attention_mask, 
            labels=batch_labels
        )
        
        loss = outputs.loss
        
        # Zpětný průchod
        loss.backward()
        
        # Aktualizace vah
        optimizer.step()
    
    print(f"Epocha {epoch+1}, Ztráta: {loss.item()}")
```

## 4. T5: Text-to-Text Transfer Transformer

T5 (Text-to-Text Transfer Transformer) rámuje všechny NLP úlohy jako text-to-text problémy, čímž poskytuje jednotný přístup. Vyvinutý výzkumným týmem Google, využívá jak enkodérové, tak dekodérové komponenty.

### Klíčové vlastnosti:
- Jednotný text-to-text framework pro všechny NLP úlohy
- Architektura enkodér-dekodér
- Úlohově specifické prefixy (např. "translate English to French:", "summarize:")
- Jeden model pro více NLP úloh

```python
from transformers import T5Tokenizer, T5ForConditionalGeneration

# Načtení předtrénovaného modelu T5 a tokenizéru
tokenizer = T5Tokenizer.from_pretrained('t5-small')
model = T5ForConditionalGeneration.from_pretrained('t5-small')

# Příklad pro překlad
translation_input = "translate English to German: The house is wonderful."
inputs = tokenizer(translation_input, return_tensors="pt", padding=True)

# Generování překladu
output = model.generate(
    inputs.input_ids,
    max_length=40,
    num_beams=4,
    early_stopping=True
)
translated_text = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Překlad: {translated_text}")

# Příklad pro sumarizaci
summarization_input = "summarize: " + """
    Transformers have revolutionized natural language processing. 
    They use self-attention mechanisms to process sequential data in parallel.
    This allows for more efficient training and better modeling of long-range dependencies.
    BERT, GPT, and T5 are popular transformer-based architectures that have achieved
    state-of-the-art results on various NLP tasks.
"""
inputs = tokenizer(summarization_input, return_tensors="pt", padding=True)

# Generování shrnutí
output = model.generate(
    inputs.input_ids,
    max_length=30,
    num_beams=4,
    early_stopping=True
)
summary = tokenizer.decode(output[0], skip_special_tokens=True)
print(f"Shrnutí: {summary}")
```

## 6. Fine-tuning předtrénovaných modelů

Všechny tři architektury podporují dolaďování pro konkrétní následné úlohy, ale s různými přístupy:

```python
from transformers import (
    BertForSequenceClassification, 
    GPT2LMHeadModel,
    T5ForConditionalGeneration,
    AdamW,
    get_linear_schedule_with_warmup
)

# Společná funkce pro dolaďování (konceptuální, není určena k přímému spuštění)
def finetune_transformer_model(model_type, model_name, task, train_dataset, val_dataset, num_epochs=3):
    """
    Fine-tune transformerového modelu pro konkrétní úlohu
    
    Args:
        model_type: "bert", "gpt2", nebo "t5"
        model_name: konkrétní checkpoint modelu
        task: klasifikace, generování, atd.
        train_dataset, val_dataset: PyTorch datasety
        num_epochs: Počet trénovacích epoch
    """
    # Načtení vhodného modelu podle typu a úlohy
    if model_type == "bert":
        if task == "classification":
            model = BertForSequenceClassification.from_pretrained(model_name, num_labels=2)
            tokenizer = BertTokenizer.from_pretrained(model_name)
        elif task == "token_classification":
            model = BertForTokenClassification.from_pretrained(model_name)
            tokenizer = BertTokenizer.from_pretrained(model_name)
    elif model_type == "gpt2":
        model = GPT2LMHeadModel.from_pretrained(model_name)
        tokenizer = GPT2Tokenizer.from_pretrained(model_name)
        tokenizer.pad_token = tokenizer.eos_token
    elif model_type == "t5":
        model = T5ForConditionalGeneration.from_pretrained(model_name)
        tokenizer = T5Tokenizer.from_pretrained(model_name)
    
    # Vytvoření dataloaderů
    train_loader = DataLoader(train_dataset, batch_size=8, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=8)
    
    # Nastavení optimalizátoru a plánovače
    optimizer = AdamW(model.parameters(), lr=5e-5)
    total_steps = len(train_loader) * num_epochs
    scheduler = get_linear_schedule_with_warmup(
        optimizer, 
        num_warmup_steps=0, 
        num_training_steps=total_steps
    )
    
    # Tréninková smyčka
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model.to(device)
    
    for epoch in range(num_epochs):
        model.train()
        total_loss = 0
        
        for batch in train_loader:
            # Zpracování dávky podle typu modelu a úlohy
            # (Implementace by se lišila podle modelu)
            
            # Příklad struktury:
            optimizer.zero_grad()
            outputs = model(**batch)
            loss = outputs.loss
            loss.backward()
            optimizer.step()
            scheduler.step()
            total_loss += loss.item()
        
        # Validace
        model.eval()
        # Vyhodnocení modelu
        # ...
        
        print(f"Epocha {epoch+1}, Ztráta: {total_loss/len(train_loader)}")
    
    return model, tokenizer
```

### Rozdíly v dolaďování:
- **BERT**: Často dolaďován pro klasifikaci, NER, QA přidáním úlohově specifických hlaviček
- **GPT**: Dolaďován pomocí jazykového modelování s popisem úlohy v promptu
- **T5**: Dolaďován převodem všech úloh do formátu text-to-text s úlohově specifickými prefixy

## 8. Techniky optimalizace výkonu

Pokročilé modely transformerů vyžadují významné výpočetní zdroje. Zde jsou techniky pro optimalizaci jejich výkonu:

```python
# Několik optimalizačních technik pro modely transformerů

# 1. Kvantizace s PyTorch
def quantize_model(model):
    """Kvantizace modelu z FP32 na INT8"""
    # Vyžaduje PyTorch 1.8.0 nebo novější
    import torch.quantization
    
    # Definice konfigurace kvantizace
    model.qconfig = torch.quantization.get_default_qconfig('fbgemm')
    
    # Příprava modelu na kvantizaci
    model_prepared = torch.quantization.prepare(model)
    
    # Kalibrace s nějakými daty (umělý příklad)
    dummy_input = torch.randn(1, 512)
    model_prepared(dummy_input)
    
    # Převod na kvantizovaný model
    quantized_model = torch.quantization.convert(model_prepared)
    
    return quantized_model

# 2. Gradient Checkpointing
def apply_gradient_checkpointing(model):
    """Aplikace gradient checkpointingu pro úsporu paměti během tréninku"""
    if hasattr(model, 'gradient_checkpointing_enable'):
        model.gradient_checkpointing_enable()
    return model

# 3. Trénování s mixovanou přesností v PyTorch
def setup_mixed_precision():
    """Nastavení tréninku s mixovanou přesností"""
    from torch.cuda.amp import autocast, GradScaler
    
    # Vytvoření scale faktoru pro gradienty
    scaler = GradScaler()
    
    # Tréninková iterace s mixovanou přesností (pro zahrnutí do tréninkové smyčky)
    def training_step(model, inputs, optimizer):
        optimizer.zero_grad()
        
        # Použití autocast pro dopředný průchod s redukovanou přesností
        with autocast():
            outputs = model(**inputs)
            loss = outputs.loss
        
        # Škálování gradientů a provedení zpětného průchodu
        scaler.scale(loss).backward()
        
        # Odstranění škálování gradientů pro případné oříznutí
        scaler.unscale_(optimizer)
        
        # Aktualizace vah
        scaler.step(optimizer)
        
        # Aktualizace scale faktoru pro další iteraci
        scaler.update()
        
        return loss
    
    return training_step

# 4. Paralelizace modelu (konceptuální příklad)
def setup_model_parallelism(model):
    """Distribuce modelu na více GPU"""
    import torch.nn as nn
    
    # Kontrola, zda je dostupných více GPU
    if torch.cuda.device_count() > 1:
        print(f"Používám {torch.cuda.device_count()} GPU pro paralelizaci modelu")
        model = nn.DataParallel(model)
    
    return model
```

from transformers import AlbertModel, AlbertTokenizer

def use_albert():

## 10. Shrnutí

Pokročilé architektury transformerů zásadně změnily zpracování přirozeného jazyka díky svým mechanismům založeným na pozornosti:

- **BERT** vyniká v porozumění jazyku díky obousměrnému modelování kontextu, což ho činí ideálním pro klasifikaci, NER a úlohy porozumění textu.

- **GPT** modely se zaměřují na generování textu díky jejich jednosměrnému přístupu, což umožňuje výkonné aplikace v kreativním psaní, chatbotech a generování kódu.

- **T5** poskytuje všestranný text-to-text framework, který sjednocuje NLP úlohy, umožňující zvládnutí překladu, sumarizace, zodpovídání otázek a klasifikace jediným modelovým přístupem.

Tyto modely sdílejí společný základ v architektuře transformeru, ale liší se přístupy ke zpracování kontextu, cíli předtrénování a oblastmi aplikací. Jejich vývoj představuje významný pokrok v schopnostech strojového učení, umožňující porozumění a generování textu více podobné lidskému.

Cesta od BERTu přes GPT k T5 ukazuje rychlé inovace v hlubokém učení pro NLP, přičemž každá architektura přináší jedinečné silné stránky a zároveň řeší omezení předchozích přístupů. S pokračujícím vývojem těchto modelů slibují ještě výkonnější a efektivnější řešení pro úlohy zpracování přirozeného jazyka.
