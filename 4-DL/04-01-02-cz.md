## Úvod do neuronových sítí

Neuronové sítě jsou výpočetní systémy inspirované strukturou a funkcí biologických neuronových sítí. Skládají se z propojených "neuronů", které zpracovávají a přenášejí informace. Tyto sítě tvoří základ hlubokého učení a způsobily revoluci v přístupu k řešení složitých problémů v oblastech jako počítačové vidění, zpracování přirozeného jazyka a posilované učení.

Neuronová síť se obvykle skládá z:
- Vstupní vrstvy, která přijímá data
- Jedné nebo více skrytých vrstev, které data zpracovávají
- Výstupní vrstvy, která produkuje konečný výsledek

```python
# Konceptuální reprezentace jednoduché neuronové sítě
"""
Vstupní vrstva   Skrytá vrstva   Výstupní vrstva
   (x₁)           (h₁)          
    ↓              ↑↓             ↑
   (x₂) --------→ (h₂) --------→ (y)
    ↓              ↑↓             ↑
   (x₃)           (h₃)          
"""
```

## Biologická inspirace

Umělé neuronové sítě se inspirují biologickými neurony v mozku. V lidském mozku neurony přijímají signály přes dendrity, zpracovávají tyto signály v buněčném těle a přenášejí je přes axony k dalším neuronům. Síla těchto spojení se může časem měnit, což je základ učení.

Podobně se umělé neuronové sítě skládají z propojených uzlů (neuronů), které:
1. Přijímají vstupy od jiných neuronů
2. Aplikují váhy na tyto vstupy
3. Sčítají vážené vstupy
4. Aplikují aktivační funkci k určení výstupu
5. Přenášejí tento výstup dalším neuronům

## Umělý neuron

Umělý neuron, známý ve své nejjednodušší formě jako perceptron, je základní výpočetní jednotka neuronové sítě. Přijímá více vstupů, zpracovává je a vytváří výstup.

Klíčové komponenty umělého neuronu:
- **Vstupy** (x₁, x₂, ..., xₙ): Datové hodnoty vstupující do neuronu
- **Váhy** (w₁, w₂, ..., wₙ): Parametry, které určují důležitost každého vstupu
- **Bias** (b): Dodatečný parametr, který umožňuje posun aktivační funkce
- **Čistý vstup/Vážený součet** (z): Součet vážených vstupů plus bias
- **Aktivační funkce** (φ): Funkce, která transformuje vážený součet na výstup
- **Výstup** (a): Hodnota produkovaná aktivační funkcí

## Matematická reprezentace

Operaci neuronu lze matematicky vyjádřit jako:

1. Výpočet váženého součtu vstupů:
   z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

2. Aplikace aktivační funkce:
   a = φ(z)

Ve vektorové notaci:
   z = W·X + b
   a = φ(z)

Kde:
- X je vstupní vektor [x₁, x₂, ..., xₙ]
- W je vektor vah [w₁, w₂, ..., wₙ]
- b je bias
- φ je aktivační funkce

```python
import numpy as np

def neuron(inputs, weights, bias, activation_function):
    """Základní implementace umělého neuronu"""
    # Výpočet váženého součtu
    z = np.dot(weights, inputs) + bias
    # Aplikace aktivační funkce
    output = activation_function(z)
    return output
```

## Aktivační funkce

Aktivační funkce zavádějí do neuronových sítí nelinearitu, což jim umožňuje učit se složité vzory a vztahy v datech. Bez aktivačních funkcí by neuronové sítě byly omezeny na učení pouze lineárních vztahů, bez ohledu na jejich hloubku.

### Lineární aktivace

Nejjednodušší aktivační funkcí je lineární nebo identická funkce: f(x) = x.

```python
def linear(x):
    return x
```

**Výhody:**
- Jednoduchý výpočet
- Vhodná pro regresní problémy ve výstupní vrstvě

**Nevýhody:**
- Nemůže řešit nelineární problémy
- Derivace jsou konstantní, což způsobuje problémy během zpětného šíření

### Sigmoid

Sigmoidní funkce (logistická funkce) mapuje jakýkoli vstup na hodnotu mezi 0 a 1:
f(x) = 1 / (1 + e^(-x))

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```

**Výhody:**
- Plynulý gradient, zabraňující skokům ve výstupních hodnotách
- Rozsah výstupu omezen mezi 0 a 1, užitečný pro binární klasifikaci

**Nevýhody:**
- Náchylná k problému mizejícího gradientu
- Výstupy nejsou centrované kolem nuly
- Výpočetně náročná

### Hyperbolický tangens (tanh)

Funkce hyperbolického tangens je podobná sigmoidu, ale mapuje vstupy na hodnoty mezi -1 a 1:
f(x) = (e^x - e^(-x)) / (e^x + e^(-x))

```python
def tanh(x):
    return np.tanh(x)
```

**Výhody:**
- Výstup je centrovaný kolem nuly, což usnadňuje optimalizaci
- Silnější gradienty než sigmoid

**Nevýhody:**
- Stále trpí problémem mizejícího gradientu
- Výpočetně náročná

### ReLU a jeho varianty

#### ReLU (Rectified Linear Unit)

ReLU je jednou z nejpoužívanějších aktivačních funkcí v moderních neuronových sítích:
f(x) = max(0, x)

```python
def relu(x):
    return np.maximum(0, x)
```

**Výhody:**
- Výpočetně efektivní
- Pomáhá zmírnit problém mizejícího gradientu
- Biologicky inspirovaná (řídkost aktivací)

**Nevýhody:**
- Problém "umírajícího ReLU": neurony mohou být trvale neaktivní
- Není centrovaná kolem nuly

#### Leaky ReLU

Varianta ReLU, která umožňuje malou zápornou hodnotu, když x < 0:
f(x) = max(αx, x), kde α je malá konstanta (např. 0,01)

```python
def leaky_relu(x, alpha=0.01):
    return np.maximum(alpha * x, x)
```

**Výhody:**
- Zabraňuje problému umírajícího ReLU
- Všechny ostatní výhody funkce ReLU

**Nevýhody:**
- Optimální hodnota α se může lišit mezi různými problémy

#### Parametric ReLU (PReLU)

Podobná jako Leaky ReLU, ale parametr sklonu α je učen během tréninku:

```python
class PReLU:
    def __init__(self, alpha=0.01):
        self.alpha = alpha  # Parametr, který se učí během tréninku v reálných implementacích
        
    def __call__(self, x):
        return np.maximum(self.alpha * x, x)
```

#### ELU (Exponential Linear Unit)

ELU kombinuje výhody ReLU a zároveň řeší některé její nedostatky:
f(x) = x když x > 0, jinak α(e^x - 1)

```python
def elu(x, alpha=1.0):
    return np.where(x > 0, x, alpha * (np.exp(x) - 1))
```

**Výhody:**
- Hladká funkce včetně záporných hodnot
- Redukuje problém "mrtvých neuronů"
- Střední aktivace blíže nule

**Nevýhody:**
- Výpočetně náročnější než ReLU
- Alfa vyžaduje ladění

### Softmax

Funkce softmax se běžně používá ve výstupní vrstvě pro problémy s vícerozměrnou klasifikací. Převádí vektor hodnot na pravděpodobnostní rozdělení:

f(x_i) = e^(x_i) / Σ(e^(x_j))

```python
def softmax(x):
    exp_x = np.exp(x - np.max(x))  # Odečtení maxima pro numerickou stabilitu
    return exp_x / exp_x.sum()
```

**Výhody:**
- Výstupy se sčítají na 1, což představuje pravděpodobnostní rozdělení
- Zdůrazňuje největší hodnoty a potlačuje menší hodnoty

**Nevýhody:**
- Výpočetně náročná
- Může způsobit numerickou nestabilitu kvůli exponenciálním funkcím

### Moderní aktivační funkce

Bylo vyvinuto několik novějších aktivačních funkcí, které řeší omezení tradičních aktivačních funkcí.

#### GELU (Gaussian Error Linear Unit)

Používá se ve špičkových modelech jako BERT a GPT:
f(x) = x * Φ(x), kde Φ je kumulativní distribuční funkce standardního normálního rozdělení

```python
def gelu(x):
    return 0.5 * x * (1 + np.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * x**3)))
```

#### Swish

Vyvinuto společností Google:
f(x) = x * sigmoid(x)

```python
def swish(x):
    return x * sigmoid(x)
```

**Výhody:**
- Hladká, nemonotónní funkce
- Dobrý výkon na hlubokých sítích

**Nevýhody:**
- Výpočetně náročnější než ReLU

## Implementace neuronů v Pythonu

Pojďme implementovat jednoduchý neuron od základů a podívejme se, jak zpracovává vstup:

```python
import numpy as np
import matplotlib.pyplot as plt

class Neuron:
    def __init__(self, n_inputs, activation_function):
        # Inicializace vah malými náhodnými hodnotami
        self.weights = np.random.randn(n_inputs) * 0.1
        self.bias = np.random.randn() * 0.1
        self.activation_function = activation_function
    
    def forward(self, inputs):
        # Výpočet váženého součtu
        z = np.dot(self.weights, inputs) + self.bias
        # Aplikace aktivační funkce
        output = self.activation_function(z)
        return output

# Vytvoření neuronu s 3 vstupy a ReLU aktivací
relu_neuron = Neuron(3, relu)

# Test se vzorovým vstupem
sample_input = np.array([0.5, 0.2, -0.1])
output = relu_neuron.forward(sample_input)

print(f"Váhy: {relu_neuron.weights}")
print(f"Bias: {relu_neuron.bias}")
print(f"Vstup: {sample_input}")
print(f"Výstup: {output}")
```

## Vytváření jednoduchých neuronových sítí

Nyní vytvořme jednoduchou neuronovou síť se skrytou vrstvou pomocí naší implementace neuronu:

```python
class SimpleNeuralNetwork:
    def __init__(self, n_inputs, n_hidden, n_outputs, hidden_activation, output_activation):
        self.hidden_layer = [Neuron(n_inputs, hidden_activation) for _ in range(n_hidden)]
        self.output_layer = [Neuron(n_hidden, output_activation) for _ in range(n_outputs)]
    
    def forward(self, inputs):
        # Zpracování vstupů skrytou vrstvou
        hidden_outputs = [neuron.forward(inputs) for neuron in self.hidden_layer]
        hidden_outputs = np.array(hidden_outputs)
        
        # Zpracování výstupů skryté vrstvy výstupní vrstvou
        final_outputs = [neuron.forward(hidden_outputs) for neuron in self.output_layer]
        return np.array(final_outputs)

# Vytvoření jednoduché sítě: 3 vstupy, 4 skryté neurony, 2 výstupy
network = SimpleNeuralNetwork(3, 4, 2, relu, sigmoid)

# Test se vzorovým vstupem
sample_input = np.array([0.5, 0.2, -0.1])
output = network.forward(sample_input)

print(f"Vstup sítě: {sample_input}")
print(f"Výstup sítě: {output}")
```

## Výběr správné aktivační funkce

Volba aktivační funkce je klíčová pro výkon vaší neuronové sítě. Zde jsou některé pokyny:

1. **Skryté vrstvy**:
   - ReLU je dobrá výchozí volba díky své jednoduchosti a efektivnosti
   - Pro velmi hluboké sítě zvažte Leaky ReLU, ELU nebo GELU, abyste se vyhnuli mrtvým neuronům

2. **Výstupní vrstva**:
   - Binární klasifikace: Sigmoid
   - Vícerozměrná klasifikace: Softmax
   - Regrese: Lineární
   - Omezená regrese (např. hodnoty mezi 0 a 1): Sigmoid nebo Tanh

3. **Speciální případy**:
   - RNN a LSTM: Tanh se často používá pro aktualizace vnitřního stavu
   - Moderní transformery: Běžně se používá GELU
   - Střední vrstvy autoenkodérů: Lineární nebo ReLU podle aplikace

## Běžné problémy a jejich řešení

### Mizející gradient

**Problém**: Gradienty se stávají extrémně malými, když jsou zpětně šířeny přes mnoho vrstev, zejména se sigmoidem a tanh.

**Řešení**:
- Použijte ReLU nebo jeho varianty
- Použijte dávkovou normalizaci
- Implementujte reziduální spojení
- Použijte správné techniky inicializace vah

### Explodující gradient

**Problém**: Gradienty se stávají extrémně velkými, což způsobuje nestabilní trénink.

**Řešení**:
- Použijte ořezávání gradientu
- Implementujte správnou inicializaci vah
- Aplikujte dávkovou normalizaci

### Mrtvé neurony (s ReLU)

**Problém**: Neurony mohou uvíznout ve stavu, kdy vždy produkují nulový výstup.

**Řešení**:
- Místo toho použijte Leaky ReLU, PReLU nebo ELU
- Použijte správnou míru učení
- Aplikujte dávkovou normalizaci

## Implementace vrstvy neuronů s NumPy

Pojďme implementovat kompletní vrstvu neuronů pomocí NumPy pro vektorizované operace:

```python
import numpy as np

class DenseLayer:
    def __init__(self, n_inputs, n_neurons, activation_function):
        # Inicializace vah a biasů
        self.weights = np.random.randn(n_inputs, n_neurons) * 0.1
        self.biases = np.zeros((1, n_neurons))
        self.activation_function = activation_function
    
    def forward(self, inputs):
        # Výpočet váženého součtu
        self.inputs = inputs
        self.z = np.dot(inputs, self.weights) + self.biases
        # Aplikace aktivační funkce
        self.output = self.activation_function(self.z)
        return self.output

# Příklad použití vrstvy
np.random.seed(42)  # Pro reprodukovatelnost

# Vytvoření vrstvy se 3 vstupy a 4 neurony
layer = DenseLayer(3, 4, relu)

# Vzorková dávka dat (5 vzorků, každý se 3 příznaky)
X = np.random.randn(5, 3)

# Dopředný průchod
output = layer.forward(X)
print("Tvar vstupu vrstvy:", X.shape)
print("Tvar výstupu vrstvy:", output.shape)
print("Výstup vrstvy:")
print(output)
```

## Trénování jednoduchého neuronu pomocí gradientního sestupu

Pro pochopení, jak se neurony učí, implementujme jednoduchý neuron pro binární klasifikaci s gradientním sestupem:

```python
import numpy as np
import matplotlib.pyplot as plt

class PerceptronNeuron:
    def __init__(self, n_inputs):
        # Inicializace vah a biasu
        self.weights = np.random.randn(n_inputs) * 0.01
        self.bias = 0
    
    def sigmoid(self, x):
        return 1 / (1 + np.exp(-x))
    
    def forward(self, x):
        # Výpočet váženého součtu
        z = np.dot(x, self.weights) + self.bias
        # Aplikace sigmoidní aktivace
        return self.sigmoid(z)
    
    def train(self, X, y, learning_rate=0.1, epochs=100):
        losses = []
        
        for epoch in range(epochs):
            total_loss = 0
            
            for i in range(len(X)):
                # Dopředný průchod
                prediction = self.forward(X[i])
                
                # Výpočet ztráty (binární cross-entropy)
                loss = -y[i] * np.log(prediction) - (1 - y[i]) * np.log(1 - prediction)
                total_loss += loss
                
                # Výpočet gradientů
                d_prediction = (prediction - y[i])  # Derivát binární cross-entropy
                
                # Aktualizace vah a biasu pomocí gradientního sestupu
                self.weights -= learning_rate * d_prediction * X[i]
                self.bias -= learning_rate * d_prediction
            
            # Záznam průměrné ztráty pro tuto epochu
            avg_loss = total_loss / len(X)
            losses.append(avg_loss)
            
            if epoch % 10 == 0:
                print(f"Epocha {epoch}, Ztráta: {avg_loss:.4f}")
        
        return losses

# Vytvoření datasetu pro binární klasifikaci
np.random.seed(42)

# Generování 100 bodů se 2 příznaky
X = np.random.randn(100, 2)

# Vytvoření štítků: 1 pokud x₁ + x₂ > 0, jinak 0
y = (X[:, 0] + X[:, 1] > 0).astype(int)

# Vizualizace dat
plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='viridis', marker='o', edgecolors='k')
plt.xlabel('Příznak 1')
plt.ylabel('Příznak 2')
plt.title('Dataset pro binární klasifikaci')
plt.colorbar(label='Třída')
plt.grid(True)
plt.show()

# Trénování neuronu
neuron = PerceptronNeuron(2)
losses = neuron.train(X, y, learning_rate=0.1, epochs=100)

# Vykreslení křivky ztráty
plt.figure(figsize=(10, 6))
plt.plot(losses)
plt.xlabel('Epocha')
plt.ylabel('Ztráta')
plt.title('Trénovací ztráta')
plt.grid(True)
plt.show()

# Vizualizace rozhodovací hranice
plt.figure(figsize=(8, 6))

# Vytvoření mřížky bodů
x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100),
                     np.linspace(y_min, y_max, 100))
grid = np.c_[xx.ravel(), yy.ravel()]

# Vytvoření předpovědí na mřížce
Z = np.array([neuron.forward(point) for point in grid])
Z = Z.reshape(xx.shape)

# Vykreslení rozhodovací hranice
plt.contourf(xx, yy, Z, alpha=0.3, cmap='viridis')

# Vykreslení původních dat
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='viridis', marker='o', edgecolors='k')
plt.xlabel('Příznak 1')
plt.ylabel('Příznak 2')
plt.title('Rozhodovací hranice naučená neuronem')
plt.colorbar(label='Pravděpodobnost třídy 1')
plt.grid(True)
plt.show()
```
