## 1. Úvod do útočných technik

Útočné techniky (adversarial attacks) jsou pečlivě vytvořené perturbace vstupních dat navržené tak, aby oklamaly modely hlubokého učení a přinutily je k nesprávným predikcím, zatímco zůstávají pro lidské pozorovatele nepostřehnutelné. Tyto útoky odhalují základní zranitelnosti v hlubokých neuronových sítích, navzdory jejich působivému výkonu na mnoha úlohách.

## 2. Typy útočných technik

Útočné techniky lze kategorizovat podle různých faktorů:

1. **Úroveň znalostí**:
   - **White-box útoky**: Útočník má úplnou znalost modelu
   - **Black-box útoky**: Útočník má omezenou nebo žádnou znalost modelu
   - **Gray-box útoky**: Útočník má částečnou znalost modelu

2. **Rozsah útoku**:
   - **Cílené útoky**: Cílem je chybná klasifikace vstupu jako konkrétní třídy
   - **Necílené útoky**: Cílem je chybná klasifikace vstupu jako jakékoli nesprávné třídy

3. **Rozsah perturbace**:
   - **Útoky specifické pro obrázek**: Perturbace vypočítané pro konkrétní obrázky
   - **Univerzální útoky**: Jedna perturbace funguje pro více obrázků

```python
# Ukázková funkce pro klasifikaci typu útoku
def classify_attack_type(is_whitebox, is_targeted, is_universal):

    attack_perturbation = "Univerzální" if is_universal else "Specifický pro obrázek"

    print(f"- Úroveň znalostí: {attack_knowledge}")

    print(f"- Rozsah perturbace: {attack_perturbation}")
```

## 3. Generování nepřátelských příkladů

Jednou z nejběžnějších metod útoku je Fast Gradient Sign Method (FGSM), která vytváří nepřátelské příklady přidáním perturbací ve směru gradientu ztrátové funkce.

```python
# Implementace útoku FGSM
def fgsm_attack(image, epsilon, data_grad):
    # Získání znaménka gradientu dat pro každý element
    sign_data_grad = data_grad.sign()
    
    # Vytvoření perturbovaného obrázku úpravou každého pixelu vstupního obrázku
    perturbed_image = image + epsilon * sign_data_grad
    
    # Oříznutí pro zachování rozsahu [0,1]
    perturbed_image = torch.clamp(perturbed_image, 0, 1)
    
    return perturbed_image

# Příklad procesu útoku
def attack_example(model, original_image, target_class=None, epsilon=0.01):
    # Vytvoření kopie vstupního obrázku a požadovaných gradientů
    image = original_image.clone().detach().requires_grad_(True)
    
    # Dopředný průchod
    output = model(image.unsqueeze(0))
    
    # Počáteční predikce
    init_pred = output.max(1, keepdim=True)[1]
    
    # Pokud není cílený, minimalizujeme důvěru pro pravou třídu
    if target_class is None:
        # Výpočet ztráty
        loss = F.nll_loss(F.log_softmax(output, dim=1), init_pred.flatten())
    else:
        # Pokud je cílený, maximalizujeme důvěru pro cílovou třídu
        target = torch.tensor([target_class], device='cpu')
        loss = -F.nll_loss(F.log_softmax(output, dim=1), target)
    
    # Nulování gradientů
    model.zero_grad()
    
    # Výpočet gradientů
    loss.backward()
    
    # Shromáždění gradientů dat
    data_grad = image.grad.data
    
    # Volání útoku FGSM
    perturbed_image = fgsm_attack(image, epsilon, data_grad)
    
    # Dopředný průchod s perturbovaným obrázkem
    output = model(perturbed_image.unsqueeze(0))
    
    # Kontrola úspěšnosti
    final_pred = output.max(1, keepdim=True)[1]
    
    return perturbed_image.detach(), init_pred, final_pred

# Vizualizace původního a nepřátelského obrázku
def visualize_attack(original_image, adversarial_image, original_label, adversarial_label):

```

Další mocnou metodou útoku je Projected Gradient Descent (PGD):

```python
def pgd_attack(model, images, labels, epsilon=0.3, alpha=0.01, num_iter=40):
    """
    Implementace útoku PGD
    
    Argumenty:
        model: cílový model
        images: vstupní obrázky
        labels: pravdivé štítky
        epsilon: maximální perturbace
        alpha: velikost kroku
        num_iter: počet iterací
        
    Vrací:
        perturbované obrázky
    """
    images = images.clone().detach().to(device)
    labels = labels.clone().detach().to(device)
    
    loss = nn.CrossEntropyLoss()
    
    adv_images = images.clone().detach()
    
    for i in range(num_iter):
        adv_images.requires_grad = True
        outputs = model(adv_images)
        
        # Výpočet ztráty
        cost = loss(outputs, labels)
        
        # Výpočet gradientů
        grad = torch.autograd.grad(cost, adv_images, 
                                  retain_graph=False, create_graph=False)[0]
        
        # Vytvoření nepřátelských příkladů
        adv_images = adv_images.detach() + alpha * grad.sign()
        delta = torch.clamp(adv_images - images, min=-epsilon, max=epsilon)
        adv_images = torch.clamp(images + delta, min=0, max=1).detach()
    
    return adv_images
```

## 4. Přenositelnost útočných technik

Nepřátelské příklady jsou často přenositelné mezi různými modely, což znamená, že příklad vytvořený k oklamání jednoho modelu může oklamat i jiný model. Tato vlastnost umožňuje black-box útoky, kde útočníci nepotřebují přístup k cílovému modelu.

```python
# Demonstrace přenositelnosti útočných technik
def demonstrate_transferability():
    # Načtení dvou různých modelů
    model_A = torchvision.models.resnet18(pretrained=True).eval()
    model_B = torchvision.models.vgg16(pretrained=True).eval()
    
    # Načtení a předzpracování obrázku
    transform = transforms.Compose([
        transforms.Resize(256),
        transforms.CenterCrop(224),
        transforms.ToTensor(),
    ])
    img = transform(Image.open('sample_image.jpg'))
    
    # Vytvoření nepřátelského příkladu pomocí modelu A
    epsilon = 0.05
    img_tensor = img.clone().detach().requires_grad_(True)
    
    # Dopředný průchod přes model A
    output = model_A(img_tensor.unsqueeze(0))
    
    # Získání původní predikce
    orig_pred_A = output.max(1, keepdim=True)[1].item()
    
    # Výpočet ztráty vzhledem k původní predikci
    loss = F.cross_entropy(output, torch.tensor([orig_pred_A]))
    
    # Zpětný průchod
    model_A.zero_grad()
    loss.backward()
    
    # Generování nepřátelského příkladu pomocí FGSM
    adv_img = img_tensor + epsilon * img_tensor.grad.sign()
    adv_img = torch.clamp(adv_img, 0, 1)
    
    # Test na modelu A
    with torch.no_grad():
        output_A = model_A(adv_img.unsqueeze(0))
        adv_pred_A = output_A.max(1, keepdim=True)[1].item()
    
    # Test na modelu B (přenositelnost)
    with torch.no_grad():
        output_B_orig = model_B(img.unsqueeze(0))
        orig_pred_B = output_B_orig.max(1, keepdim=True)[1].item()
        
        output_B_adv = model_B(adv_img.unsqueeze(0))
        adv_pred_B = output_B_adv.max(1, keepdim=True)[1].item()
    
    # Kontrola, zda se útok přenesl
    print(f"Model A - Původní predikce: {orig_pred_A}, Nepřátelská predikce: {adv_pred_A}")
    print(f"Model B - Původní predikce: {orig_pred_B}, Nepřátelská predikce: {adv_pred_B}")
    print(f"Útok se přenesl: {orig_pred_B != adv_pred_B}")
    
    return img, adv_img
```

## 5. Obranné techniky

Pro obranu proti útokům bylo vyvinuto několik přístupů:

1. **Předzpracování vstupů**: Transformace vstupů k odstranění nepřátelských perturbací
2. **Změny architektury modelů**: Úprava architektur sítí pro zvýšení robustnosti
3. **Detekce za běhu**: Identifikace potenciálních nepřátelských příkladů během inference
4. **Maskování/obfuskace gradientů**: Skrytí informací o gradientech, aby byly útoky obtížnější

```python
# Příklad obranné techniky předzpracování vstupů
def input_preprocessing_defense(image, preprocess_type='jpeg_compression'):
    """Aplikace technik předzpracování pro obranu proti útočným technikám"""
    if preprocess_type == 'jpeg_compression':
        # Převod na PIL Image
        pil_img = transforms.ToPILImage()(image.squeeze(0))
        
        # Aplikace JPEG komprese
        buffer = BytesIO()
        pil_img.save(buffer, format='JPEG', quality=75)
        buffer.seek(0)
        
        # Načtení zpět komprimovaného obrázku
        compressed_img = Image.open(buffer)
        
        # Převod zpět na tenzor
        tensor_img = transforms.ToTensor()(compressed_img)
        return tensor_img
    
    elif preprocess_type == 'gaussian_blur':
        # Aplikace Gaussovského rozostření
        from torchvision.transforms import GaussianBlur
        blur = GaussianBlur(kernel_size=5, sigma=1.0)
        return blur(image)
    
    elif preprocess_type == 'bit_depth_reduction':
        # Redukce bitové hloubky (kvantizace barev)
        num_bits = 5
        max_val = 2**num_bits - 1
        img_reduced = torch.round(image * max_val) / max_val
        return img_reduced
    
    return image  # Vrácení originálu, pokud není specifikováno předzpracování
```

## 6. Nepřátelský trénink

Nepřátelský trénink (adversarial training) je jednou z nejefektivnějších obranných technik, při kterém je model explicitně trénován na nepřátelských příkladech:

```python
def adversarial_training(model, train_loader, optimizer, epochs=10, epsilon=0.1):
    """Trénink modelu s nepřátelskými příklady smíchanými do trénovacích dat"""
    model.train()
    criterion = nn.CrossEntropyLoss()
    
    for epoch in range(epochs):
        running_loss = 0.0
        correct, total = 0, 0
        
        for i, (inputs, labels) in enumerate(train_loader):
            inputs, labels = inputs.to(device), labels.to(device)
            
            # Generování nepřátelských příkladů
            inputs.requires_grad = True
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            model.zero_grad()
            loss.backward()
            
            # Vytvoření FGSM perturbací
            data_grad = inputs.grad.data
            perturbed_inputs = fgsm_attack(inputs, epsilon, data_grad)
            
            # Kombinace čistých a nepřátelských příkladů (50/50 rozdělení)
            combined_inputs = torch.cat([inputs[:len(inputs)//2], 
                                         perturbed_inputs[len(inputs)//2:]])
            combined_labels = torch.cat([labels[:len(labels)//2], 
                                         labels[len(labels)//2:]])
            
            # Trénování na smíšené dávce
            optimizer.zero_grad()
            outputs = model(combined_inputs)
            loss = criterion(outputs, combined_labels)
            loss.backward()
            optimizer.step()
            
            running_loss += loss.item()
            
            # Výpočet přesnosti tréninku
            _, predicted = torch.max(outputs, 1)
            total += combined_labels.size(0)
            correct += (predicted == combined_labels).sum().item()
            
        # Výpis statistik
        print(f'Epocha {epoch+1}: Ztráta = {running_loss/len(train_loader):.4f}, ' +
              f'Přesnost = {100 * correct/total:.2f}%')
    
    return model

# Ukázka použití
def train_robust_model():
    # Načtení modelu a datasetu
    model = torchvision.models.resnet18(pretrained=False, num_classes=10)
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.5,), (0.5,))
    ])
    trainset = torchvision.datasets.CIFAR10(root='./data', train=True,
                                           download=True, transform=transform)
    trainloader = torch.utils.data.DataLoader(trainset, batch_size=128,
                                             shuffle=True, num_workers=2)
    
    # Definice optimalizátoru
    optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
    
    # Provedení nepřátelského tréninku
    robust_model = adversarial_training(model, trainloader, optimizer, 
                                       epochs=5, epsilon=0.03)
    
    return robust_model
```

## 7. Certifikované obrany

Certifikované obrany poskytují matematické záruky ohledně robustnosti modelu v rámci určitých hranic perturbací.

```python
# Implementace randomizovaného vyhlazování (technika certifikované obrany)
def randomized_smoothing(model, x, sigma, n_samples=100, batch_size=32):
    """
    Aplikace randomizovaného vyhlazování pro zvýšení robustnosti
    
    Argumenty:
        model: klasifikátor, který má být vyhlazen
        x: vstupní tenzor obrázku
        sigma: směrodatná odchylka Gaussovského šumu
        n_samples: počet vzorků šumu
        batch_size: velikost dávky pro vzorkování šumu
        
    Vrací:
        predikovanou třídu a certifikační rádius
    """
    with torch.no_grad():
        # Inicializace čítačů pro každou třídu
        counts = torch.zeros(1000, dtype=torch.int32)
        
        # Zpracování po dávkách
        num_batches = int(np.ceil(n_samples / batch_size))
        
        for i in range(num_batches):
            batch_size_actual = min(batch_size, n_samples - i * batch_size)
            
            # Vytvoření dávky zašuměných vzorků
            noise = torch.randn(batch_size_actual, *x.shape[1:]) * sigma
            noisy_x = x.repeat(batch_size_actual, 1, 1, 1) + noise
            noisy_x = torch.clamp(noisy_x, 0, 1)
            
            # Získání predikcí pro zašuměné vzorky
            outputs = model(noisy_x)
            predictions = outputs.argmax(dim=1)
            
            # Počítání predikcí
            for j in range(batch_size_actual):
                counts[predictions[j]] += 1
        
        # Nalezení nejvyšší třídy
        top_class = counts.argmax().item()
        
        # Výpočet certifikačního rádia pomocí Neyman-Pearsonova lemmatu
        top_counts = counts[top_class].item()
        p_hat = top_counts / n_samples
        
        # Pokud majoritní třída nemá alespoň 50% hlasů, 
        # nemůžeme certifikovat robustnost
        if p_hat < 0.5:
            radius = 0.0
        else:
            radius = sigma * norm.ppf(p_hat)
        
        return top_class, radius
```

## 8. Hodnocení robustnosti

Pro vyhodnocení robustnosti modelu je třeba jej otestovat proti různým útočným technikám:

```python
def evaluate_robustness(model, test_loader, epsilon_range=None):
    """
    Vyhodnocení robustnosti modelu proti FGSM útokům při různých silách
    
    Argumenty:
        model: model k vyhodnocení
        test_loader: DataLoader pro testovací data
        epsilon_range: seznam sil útoku k otestování
    """
    if epsilon_range is None:
        epsilon_range = [0, 0.01, 0.02, 0.05, 0.1, 0.2]
    
    results = []
    
    model.eval()
    
    # Pro každé epsilon (sílu útoku)
    for epsilon in epsilon_range:
        correct = 0
        total = 0
        
        for images, labels in test_loader:
            images, labels = images.to(device), labels.to(device)
            
            if epsilon == 0:
                # Čistá přesnost
                outputs = model(images)
                _, predicted = torch.max(outputs.data, 1)
            else:
                # Vytvoření nepřátelských příkladů
                images.requires_grad = True
                outputs = model(images)
                loss = F.cross_entropy(outputs, labels)
                model.zero_grad()
                loss.backward()
                
                # FGSM útok
                perturbed_images = fgsm_attack(images.detach(), epsilon, images.grad.data)
                
                # Vyhodnocení na nepřátelských příkladech
                with torch.no_grad():
                    outputs = model(perturbed_images)
                    _, predicted = torch.max(outputs.data, 1)
            
            total += labels.size(0)
            correct += (predicted == labels).sum().item()
        
        # Výpočet přesnosti
        accuracy = 100 * correct / total
        results.append((epsilon, accuracy))
        print(f"Epsilon = {epsilon:.3f}, Přesnost = {accuracy:.2f}%")
    
    return results

# Vizualizace výsledků robustnosti
def plot_robustness(results):
    """Vykreslení přesnosti vs síly útoku"""
    epsilons = [r[0] for r in results]
    accuracies = [r[1] for r in results]
    
    plt.figure(figsize=(10, 6))
    plt.plot(epsilons, accuracies, marker='o', linestyle='-', linewidth=2)
    plt.title("Robustnost modelu proti FGSM útoku", fontsize=15)
    plt.xlabel("Epsilon (síla útoku)", fontsize=12)
    plt.ylabel("Přesnost (%)", fontsize=12)
    plt.grid(True)
    plt.show()
```

```python
# Příklad útoku v reálném scénáři (rozpoznávání obličejů)
def face_recognition_attack_demo():
    """Demo ukazující, jak nepřátelské náplasti mohou oklamat systémy rozpoznávání obličejů"""
    # Načtení předtrénovaného modelu pro rozpoznávání obličejů
    # (V reálné implementaci byste použili knihovnu jako face_recognition nebo deepface)
    face_model = torchvision.models.resnet50(pretrained=True)
    face_model.eval()
    
    # Načtení a předzpracování obrázku obličeje
    transform = transforms.Compose([
        transforms.Resize((224, 224)),
        transforms.ToTensor(),
    ])
    face_img = transform(Image.open('face_sample.jpg'))
    
    # Vytvoření minimální nepřátelské náplasti
    # V reálných útocích by toto bylo pečlivě optimalizováno
    patch_size = 40
    patch_location = (100, 140)  # Umístění na obličeji
    
    # Generování nepřátelské náplasti (zjednodušená verze)
    patch = torch.rand(3, patch_size, patch_size)
    patch.requires_grad = True
    
    # Optimalizační smyčka (zjednodušená)
    optimizer = torch.optim.Adam([patch], lr=0.1)
    
    for i in range(100):
        # Aplikace náplasti na obličej
        patched_face = face_img.clone()
        patched_face[:, 
                    patch_location[0]:patch_location[0]+patch_size, 
                    patch_location[1]:patch_location[1]+patch_size] = patch
        
        # Získání predikce modelu
        output = face_model(patched_face.unsqueeze(0))
        
        # Ztráta pro maximalizaci chybné klasifikace
        target_class = 999  # Libovolný cíl rozdílný od správné třídy
        loss = -F.cross_entropy(output, torch.tensor([target_class]))
        
        # Aktualizace náplasti
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # Oříznutí hodnot náplasti na platný rozsah
        with torch.no_grad():
            patch.clamp_(0, 1)
    
    # Aplikace finální náplasti
    patched_face = face_img.clone()
    patched_face[:, 
                patch_location[0]:patch_location[0]+patch_size, 
                patch_location[1]:patch_location[1]+patch_size] = patch
    
    # Porovnání výsledků
    with torch.no_grad():
        orig_output = face_model(face_img.unsqueeze(0))
        patched_output = face_model(patched_face.unsqueeze(0))
        
        orig_class = orig_output.argmax(1).item()
        patched_class = patched_output.argmax(1).item()
    
    # Zobrazení výsledků
    plt.figure(figsize=(12, 5))
    
    plt.subplot(1, 2, 1)
    plt.imshow(face_img.permute(1, 2, 0))
    plt.title(f"Původní obličej (Třída: {orig_class})")
    plt.axis('off')
    
    plt.subplot(1, 2, 2)
    plt.imshow(patched_face.permute(1, 2, 0))
    plt.title(f"Obličej s nepřátelskou náplastí (Třída: {patched_class})")
    plt.axis('off')
    
    plt.tight_layout()
    plt.show()
```

## 10. Shrnutí

Útočné techniky a obranné mechanismy představují kritickou oblast v bezpečnosti hlubokého učení:

1. **Zranitelnost**: Hluboké neuronové sítě jsou ze své podstaty zranitelné vůči pečlivě vytvořeným perturbacím, které mohou způsobit chybnou klasifikaci, přestože zůstávají pro lidi nepostřehnutelné.

2. **Metody útoku**: Existují různé metody útoku, od jednoduchých přístupů založených na gradientech jako FGSM až po sofistikovanější techniky jako PGD a CW útoky.

3. **Strategie obrany**: Obrany zahrnují nepřátelský trénink, předzpracování vstupů, certifikovanou robustnost a architektonické modifikace.

4. **Kompromisy**: Obvykle existuje kompromis mezi přesností modelu na čistých datech a robustností vůči nepřátelským příkladům.

5. **Směry výzkumu**: Aktivní výzkum se zaměřuje na vývoj silnějších útoků, efektivnějších obran a teoretické pochopení nepřátelských jevů.

6. **Dopad v reálném světě**: Nepřátelské zranitelnosti mají významné důsledky pro AI systémy v bezpečnostně kritických aplikacích jako autonomní vozidla, biometrická autentizace a lékařská diagnostika.

Pochopení a řešení těchto zranitelností je klíčové pro nasazení bezpečných a spolehlivých systémů hlubokého učení. S tím, jak se modely stávají rozšířenější v kritických aplikacích, robustnost vůči útočným technikám se stává stále důležitější pro zajištění důvěryhodných AI systémů.
