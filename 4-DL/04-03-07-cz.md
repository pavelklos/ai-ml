## 1. Úvod do prohledávání neuronových architektur

Prohledávání neuronových architektur (Neural Architecture Search, NAS) je automatizovaný proces, který se snaží objevit optimální architektury neuronových sítí pro konkrétní úlohy, čímž snižuje potřebu manuálního návrhu a expertních znalostí. NAS způsobil revoluci v hlubokém učení tím, že automatizuje jeden z jeho nejnáročnějších aspektů: navrhování správné architektury sítě.

NAS typicky sestává ze tří klíčových komponent:
1. **Prostor prohledávání**: Definuje, které architektury mohou být reprezentovány
2. **Strategie prohledávání**: Jak prozkoumat prostor prohledávání
3. **Strategie odhadu výkonnosti**: Jak efektivně vyhodnotit kandidátské architektury

## 2. Návrh prostoru prohledávání

Prostor prohledávání definuje množinu možných architektur, které může algoritmus NAS prozkoumat. Běžné prostory prohledávání zahrnují:

1. **Sítě s řetězovou strukturou**: Lineárně poskládané vrstvy s různými operacemi
2. **Prostory založené na buňkách**: Hledání opakovatelných motivů/buněk
3. **Hierarchické prostory prohledávání**: Více úrovní architektonických rozhodnutí

```python
# Příklad definice jednoduchého prostoru prohledávání s řetězovou strukturou
def create_search_space(max_layers=10):
    """Vytvoření jednoduchého prostoru prohledávání pro síť s řetězovou strukturou."""
    
    # Dostupné operace vrstev
    conv_ops = [
        {'type': 'conv', 'kernel_size': 3, 'filters': 16},
        {'type': 'conv', 'kernel_size': 5, 'filters': 16},
        {'type': 'conv', 'kernel_size': 3, 'filters': 32},
        {'type': 'conv', 'kernel_size': 5, 'filters': 32},
    ]
    
    # Operace sdružování (pooling)
    pool_ops = [
        {'type': 'max_pool', 'size': 2},
        {'type': 'avg_pool', 'size': 2},
    ]
    
    # Dostupné operace
    operations = conv_ops + pool_ops
    
    # Prostor prohledávání jako seznam možných operací na každé vrstvě
    search_space = [operations for _ in range(max_layers)]
    
    return search_space

# Příklad vzorkování architektury z prostoru prohledávání
def sample_architecture(search_space):
    """Vzorkování náhodné architektury z prostoru prohledávání."""
    architecture = []
    for layer_ops in search_space:
        op = random.choice(layer_ops)
        architecture.append(op)
    return architecture

# Vytvoření prostoru prohledávání a vzorkování architektury
search_space = create_search_space(max_layers=5)
sampled_arch = sample_architecture(search_space)
print("Vzorkovaná architektura:")
for i, op in enumerate(sampled_arch):
    print(f"Vrstva {i}: {op}")
```

Dobře navržené prostory prohledávání jsou klíčové pro úspěch NAS. Měly by být:
- **Vyjadřující**: Schopné reprezentovat širokou škálu architektur
- **Omezené**: Ne příliš velké, aby bylo prohledávání zvládnutelné
- **Doménově specifické**: Přizpůsobené cílové úloze, pokud je to možné

## 3. Strategie prohledávání

Strategie prohledávání určují, jak algoritmus NAS prozkoumává prostor prohledávání. Běžné přístupy zahrnují:

1. **Náhodné prohledávání**: Náhodně vzorkuje architektury
2. **Mřížkové prohledávání**: Systematicky vyhodnocuje předem definované architektury
3. **Evoluční algoritmy**: Používají genetické operace jako mutace a křížení
4. **Posilované učení (RL)**: Trénuje kontrolér, který navrhuje architektury
5. **Gradientní metody**: Převádí diskrétní prohledávání na spojité pro umožnění gradientního sestupu
6. **Bayesovská optimalizace**: Modeluje výkonnost architektur pro vedení prohledávání

```python
# Jednoduchá implementace náhodného prohledávání pro NAS
def random_search(search_space, num_samples=10, evaluate_fn=None):
    """Provést náhodné prohledávání prostoru prohledávání."""
    best_arch = None
    best_performance = float('-inf')
    results = []
    
    for i in range(num_samples):
        # Vzorkování architektury
        arch = sample_architecture(search_space)
        
        # Vyhodnocení architektury
        performance = evaluate_fn(arch) if evaluate_fn else random.random()
        results.append((arch, performance))
        
        # Sledování nejlepší architektury
        if performance > best_performance:
            best_performance = performance
            best_arch = arch
            
        print(f"Vzorek {i+1}/{num_samples}: Výkon = {performance:.4f}")
    
    return best_arch, best_performance, results

    return random.random()  # Vrátí náhodné skóre mezi 0 a 1

# Spuštění náhodného prohledávání
```

## 4. Strategie odhadu výkonnosti

Odhad výkonnosti je kritickou výzvou v NAS, protože trénování a vyhodnocování každé kandidátské architektury od začátku může být extrémně časově náročné. Vzniklo několik strategií, které tento proces zefektivňují:

1. **Odhady s nízkou věrností**: Trénování na méně epochách, menších datasetech nebo nižším rozlišení
2. **Extrapolace křivky učení**: Předpověď konečného výkonu z částečného tréninku
3. **Sdílení/dědičnost vah**: Opětovné použití vah mezi podobnými architekturami
4. **Náhradní modely**: Trénování modelu pro předpověď výkonu architektury
5. **One-shot modely**: Trénování jedné super-sítě obsahující všechny architektury

## 5. Implementace náhodného prohledávání NAS

Implementujme kompletnější příklad náhodného prohledávání NAS pro klasifikaci obrázků:

```python
import torch
import torch.nn as nn
import torch.optim as optim
import torchvision
import torchvision.transforms as transforms
from torch.utils.data import DataLoader, random_split
import time
import random

# Definice prostoru prohledávání operací ve vrstvách
OPERATIONS = {
    'conv3x3': lambda in_channels, out_channels: nn.Sequential(
        nn.Conv2d(in_channels, out_channels, 3, padding=1, bias=False),
        nn.BatchNorm2d(out_channels),
        nn.ReLU()
    ),
    'conv5x5': lambda in_channels, out_channels: nn.Sequential(
        nn.Conv2d(in_channels, out_channels, 5, padding=2, bias=False),
        nn.BatchNorm2d(out_channels),
        nn.ReLU()
    ),
    'max_pool': lambda in_channels, out_channels: nn.Sequential(
        nn.MaxPool2d(3, stride=1, padding=1),
        nn.Conv2d(in_channels, out_channels, 1, bias=False),
        nn.BatchNorm2d(out_channels),
        nn.ReLU()
    ),
    'avg_pool': lambda in_channels, out_channels: nn.Sequential(
        nn.AvgPool2d(3, stride=1, padding=1),
        nn.Conv2d(in_channels, out_channels, 1, bias=False),
        nn.BatchNorm2d(out_channels),
        nn.ReLU()
    ),
}

# Definice jednoduchého modelového rámce
class SimpleCNN(nn.Module):
    def __init__(self, architecture, num_classes=10):
        super(SimpleCNN, self).__init__()
        self.architecture = architecture
        
        # Úvodní konvoluční vrstva
        in_channels = 3  # RGB vstup
        out_channels = 16
        layers = [nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1),
                 nn.BatchNorm2d(out_channels),
                 nn.ReLU()]
        
        # Přidání vrstev z architektury
        for op_name, channels in architecture:
            layers.append(OPERATIONS[op_name](out_channels, channels))
            out_channels = channels
        
        # Přidání závěrečných vrstev
        layers.append(nn.AdaptiveAvgPool2d(1))
        self.features = nn.Sequential(*layers)
        self.classifier = nn.Linear(out_channels, num_classes)
        
    def forward(self, x):
        x = self.features(x)
        x = torch.flatten(x, 1)
        x = self.classifier(x)
        return x

# Funkce pro generování náhodné architektury
def generate_random_architecture(num_layers=4, min_channels=16, max_channels=128):
    architecture = []
    for _ in range(num_layers):
        op_name = random.choice(list(OPERATIONS.keys()))
        channels = 2 ** random.randint(int(np.log2(min_channels)), int(np.log2(max_channels)))
        architecture.append((op_name, channels))
    return architecture

# Funkce pro vyhodnocení architektury
def evaluate_architecture(architecture, train_loader, val_loader, epochs=1, device='cuda'):
    model = SimpleCNN(architecture).to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.001)
    
    # Trénování modelu
    model.train()
    for epoch in range(epochs):
        for inputs, targets in train_loader:
            inputs, targets = inputs.to(device), targets.to(device)
            optimizer.zero_grad()
            outputs = model(inputs)
            loss = criterion(outputs, targets)
            loss.backward()
            optimizer.step()
    
    # Vyhodnocení modelu
    model.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for inputs, targets in val_loader:
            inputs, targets = inputs.to(device), targets.to(device)
            outputs = model(inputs)
            _, predicted = outputs.max(1)
            total += targets.size(0)
            correct += predicted.eq(targets).sum().item()
    
    accuracy = correct / total
    return accuracy

# Hlavní funkce náhodného prohledávání
def random_search_nas(num_samples=10, num_layers=4, epochs=1):
    # Načtení a příprava dat
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))
    ])
    
    # Použití CIFAR-10 datasetu
    full_dataset = torchvision.datasets.CIFAR10(root='./data', train=True, 
                                               download=True, transform=transform)
    train_size = int(0.8 * len(full_dataset))
    val_size = len(full_dataset) - train_size
    train_dataset, val_dataset = random_split(full_dataset, [train_size, val_size])
    
    train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=64)
    
    # Určení zařízení
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    
    # Provedení náhodného prohledávání
    best_arch = None
    best_accuracy = 0.0
    results = []
    
    for i in range(num_samples):
        start_time = time.time()
        
        # Generování náhodné architektury
        architecture = generate_random_architecture(num_layers)
        
        # Vyhodnocení architektury
        try:
            accuracy = evaluate_architecture(
                architecture, train_loader, val_loader, epochs, device)
            
            # Sledování výsledků
            results.append((architecture, accuracy))
            print(f"Architektura {i+1}/{num_samples}: Přesnost = {accuracy:.4f}")
            
            # Aktualizace nejlepší architektury
            if accuracy > best_accuracy:
                best_accuracy = accuracy
                best_arch = architecture
        except Exception as e:
            print(f"Chyba při vyhodnocování architektury {i+1}: {e}")
        
        elapsed_time = time.time() - start_time
        print(f"Doba trvání: {elapsed_time:.2f} sekund\n")
    
    return best_arch, best_accuracy, results
```

## 7. Gradientní NAS: DARTS

DARTS (Differentiable Architecture Search) je gradientní metoda NAS, která převádí diskrétní prostor prohledávání architektur na spojitý, což umožňuje použití gradientního sestupu:

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# Definice jednoduché verze smíšené operace DARTS
class MixedOp(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(MixedOp, self).__init__()
        self.ops = nn.ModuleList([
            # Definice kandidátských operací
            nn.Conv2d(in_channels, out_channels, 3, padding=1),  # 3x3 konvoluce
            nn.Conv2d(in_channels, out_channels, 5, padding=2),  # 5x5 konvoluce
            nn.MaxPool2d(3, stride=1, padding=1),  # Max pooling
            nn.AvgPool2d(3, stride=1, padding=1),  # Avg pooling
            nn.Identity()  # Přeskočení spojení
        ])
        # Parametry architektury (naučitelné váhy pro každou operaci)
        self.alpha = nn.Parameter(torch.zeros(len(self.ops)))
    
    def forward(self, x):
        # Aplikace softmax pro získání vah operací
        weights = F.softmax(self.alpha, dim=0)
        
        # Vážený součet všech operací
        return sum(w * op(x) for w, op in zip(weights, self.ops))

# Definice jednoduché sítě používající buňky DARTS
class SimpleDARTSNetwork(nn.Module):
    def __init__(self, in_channels, num_classes, num_cells=3):
        super(SimpleDARTSNetwork, self).__init__()
        
        self.stem = nn.Sequential(
            nn.Conv2d(in_channels, 16, 3, padding=1),
            nn.BatchNorm2d(16),
            nn.ReLU()
        )
        
        # Vytvoření buněk se smíšenými operacemi
        self.cells = nn.ModuleList()
        in_channels = 16
        out_channels = 16
        
        for i in range(num_cells):
            cell = MixedOp(in_channels, out_channels)
            self.cells.append(cell)
            in_channels = out_channels
            out_channels *= 2  # Zdvojnásobení počtu kanálů v každé buňce
        
        # Klasifikační hlava
        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(in_channels, num_classes)
        )
    
    def forward(self, x):
        x = self.stem(x)
        for cell in self.cells:
            x = cell(x)
        x = self.classifier(x)
        return x

# Funkce pro trénování DARTS
def train_darts(model, train_loader, val_loader, epochs=50):
    # Rozdělení parametrů: parametry architektury a parametry vah
    arch_params = [p for name, p in model.named_parameters() if 'alpha' in name]
    weight_params = [p for name, p in model.named_parameters() if 'alpha' not in name]
    
    # Nastavení optimalizátorů
    arch_optimizer = torch.optim.Adam(arch_params, lr=3e-4)
    weight_optimizer = torch.optim.SGD(weight_params, lr=0.01, momentum=0.9, weight_decay=3e-4)
    
    criterion = nn.CrossEntropyLoss()
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model = model.to(device)
    
    for epoch in range(epochs):
        # Trénovací fáze - aktualizace vah
        model.train()
        for images, labels in train_loader:
            images, labels = images.to(device), labels.to(device)
            
            # Aktualizace vah
            weight_optimizer.zero_grad()
            outputs = model(images)
            loss = criterion(outputs, labels)
            loss.backward()
            weight_optimizer.step()
        
        # Validační fáze - aktualizace parametrů architektury
        model.train()  # Zůstat v trénovacím režimu pro aktualizaci architektury
        for images, labels in val_loader:
            images, labels = images.to(device), labels.to(device)
            
            # Aktualizace parametrů architektury
            arch_optimizer.zero_grad()
            outputs = model(images)
            loss = criterion(outputs, labels)
            loss.backward()
            arch_optimizer.step()
        
        # Vyhodnocení aktuálního modelu
        model.eval()
        correct = 0
        total = 0
        with torch.no_grad():
            for images, labels in val_loader:
                images, labels = images.to(device), labels.to(device)
                outputs = model(images)
                _, predicted = outputs.max(1)
                total += labels.size(0)
                correct += predicted.eq(labels).sum().item()
        
        accuracy = correct / total
        print(f"Epocha {epoch+1}/{epochs}: Přesnost = {accuracy:.4f}")
    
    # Vrácení konečné architektury
    return get_final_architecture(model)

# Funkce pro extrakci konečné architektury z DARTS
def get_final_architecture(model):
    architecture = []
    for i, cell in enumerate(model.cells):
        # Získání operace s nejvyšší váhou pro každou buňku
        weights = F.softmax(cell.alpha, dim=0).detach().cpu().numpy()
        best_op_idx = weights.argmax()
        architecture.append((f"cell_{i}", best_op_idx))
    return architecture
```

## 8. NAS s posilovaným učením

Posilované učení (RL) je další populární přístup k NAS. Zde agent (kontrolér) generuje architektury a výkon těchto architektur slouží jako signál odměny:

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
from collections import namedtuple

# Definice prostoru prohledávání
NUM_LAYERS = 4
OPERATIONS = ['conv3x3', 'conv5x5', 'max_pool', 'avg_pool']
CHANNELS = [16, 32, 64]

# RNN kontrolér pro NAS
class Controller(nn.Module):
    def __init__(self, lstm_size=100, lstm_num_layers=1):
        super(Controller, self).__init__()
        
        # Pro výběr operací
        self.lstm = nn.LSTM(
            input_size=len(OPERATIONS) + len(CHANNELS),
            hidden_size=lstm_size,
            num_layers=lstm_num_layers
        )
        self.op_embedding = nn.Embedding(len(OPERATIONS), len(OPERATIONS))
        self.channel_embedding = nn.Embedding(len(CHANNELS), len(CHANNELS))
        
        # Výstupní vrstvy
        self.op_fc = nn.Linear(lstm_size, len(OPERATIONS))
        self.channel_fc = nn.Linear(lstm_size, len(CHANNELS))
        
        self.saved_log_probs = []
        self.rewards = []
    
    def forward(self, x, hidden=None):
        output, hidden = self.lstm(x, hidden)
        return output, hidden
    
    def sample_architecture(self):
        """Vzorkování architektury neuronové sítě."""
        architecture = []
        
        # Inicializace vstupů nulami
        inputs = torch.zeros(1, 1, len(OPERATIONS) + len(CHANNELS))
        hidden = None
        
        # Vzorkování pro každou vrstvu
        for _ in range(NUM_LAYERS):
            output, hidden = self.forward(inputs, hidden)
            
            # Vzorkování operace
            op_logits = self.op_fc(output.squeeze(0))
            op_probs = torch.softmax(op_logits, dim=-1)
            op_dist = torch.distributions.Categorical(op_probs)
            op_id = op_dist.sample()
            self.saved_log_probs.append(op_dist.log_prob(op_id))
            
            # Vzorkování počtu kanálů
            ch_logits = self.channel_fc(output.squeeze(0))
            ch_probs = torch.softmax(ch_logits, dim=-1)
            ch_dist = torch.distributions.Categorical(ch_probs)
            ch_id = ch_dist.sample()
            self.saved_log_probs.append(ch_dist.log_prob(ch_id))
            
            # Vytvoření vstupů pro další vrstvu
            op_one_hot = torch.zeros(1, 1, len(OPERATIONS))
            op_one_hot[0, 0, op_id] = 1
            ch_one_hot = torch.zeros(1, 1, len(CHANNELS))
            ch_one_hot[0, 0, ch_id] = 1
            inputs = torch.cat([op_one_hot, ch_one_hot], dim=-1)
            
            # Přidání do architektury
            architecture.append((OPERATIONS[op_id.item()], CHANNELS[ch_id.item()]))
            
        return architecture
    
    def update_policy(self, optimizer, gamma=0.99):
        """Aktualizace politiky pomocí algoritmu REINFORCE."""
        R = 0
        policy_loss = []
        returns = []
        
        # Výpočet návratů
        for r in self.rewards[::-1]:
            R = r + gamma * R
            returns.insert(0, R)
        returns = torch.tensor(returns)
        
        # Normalizace návratů
        returns = (returns - returns.mean()) / (returns.std() + 1e-8)
        
        # Výpočet ztráty
        for log_prob, R in zip(self.saved_log_probs, returns):
            policy_loss.append(-log_prob * R)
        
        # Provedení aktualizace
        optimizer.zero_grad()
        policy_loss = torch.cat(policy_loss).sum()
        policy_loss.backward()
        optimizer.step()
        
        # Resetování odměn a log pravděpodobností
        self.rewards = []
        self.saved_log_probs = []

# Jednoduchý konstruktor modelů pro vyhodnocení architektur
def build_and_evaluate_model(architecture):
    """Fiktivní funkce pro sestavení a vyhodnocení modelu z architektury.
    V praxi by toto sestavilo PyTorch model a vyhodnotilo ho na datasetu."""
    
    # Toto je zástupce - ve skutečném použití byste:
    # 1. Sestavili CNN na základě architektury
    # 2. Natrénovali ji na nějakých datech
    # 3. Vrátili přesnost validace
    
    # Pro demonstraci vraťte náhodnou přesnost s vyšší pravděpodobností 
    # pro architektury s více kanály
    total_channels = sum(ch for _, ch in architecture)
    base_accuracy = 0.5 + 0.3 * np.random.random()
    channel_bonus = min(0.1, 0.001 * total_channels)
    return base_accuracy + channel_bonus

# Trénovací smyčka pro NAS založený na RL
def train_controller(controller, optimizer, n_episodes=100):
    for episode in range(n_episodes):
        # Vzorkování architektury
        architecture = controller.sample_architecture()
        
        # Vyhodnocení architektury
        accuracy = build_and_evaluate_model(architecture)
        
        # Použití přesnosti jako odměny
        controller.rewards.append(accuracy)
        
        # Aktualizace politiky
        if (episode + 1) % 10 == 0:
            controller.update_policy(optimizer)
            print(f"Epizoda {episode+1}/{n_episodes}, Poslední přesnost: {accuracy:.4f}")
    
    # Vzorkování konečné architektury
    return controller.sample_architecture()

# Spuštění NAS založeného na RL
def run_rl_nas():
    controller = Controller()
    optimizer = optim.Adam(controller.parameters(), lr=0.01)
    
    final_architecture = train_controller(controller, optimizer, n_episodes=50)
    print(f"Nalezena konečná architektura: {final_architecture}")
    return final_architecture
```

## 9. Efektivní metody NAS

Mnoho nedávných pokroků v NAS se zaměřuje na zlepšení efektivity. Podíváme se na přístupy sdílení vah jako je One-Shot NAS:

```python
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# Definice supersítě se sdílením vah pro one-shot NAS
class OneShot(nn.Module):
    def __init__(self, in_channels, num_classes):
        super(OneShot, self).__init__()
        
        # Počáteční vrstvy
        self.stem = nn.Sequential(
            nn.Conv2d(in_channels, 16, 3, padding=1),
            nn.BatchNorm2d(16),
            nn.ReLU()
        )
        
        # Definice operací pro každý blok volby
        self.ops = nn.ModuleList([
            nn.ModuleList([
                nn.Conv2d(16, 16, 3, padding=1),
                nn.Conv2d(16, 16, 5, padding=2),
                nn.MaxPool2d(3, stride=1, padding=1),
                nn.AvgPool2d(3, stride=1, padding=1)
            ]),
            nn.ModuleList([
                nn.Conv2d(16, 32, 3, padding=1),
                nn.Conv2d(16, 32, 5, padding=2),
                nn.MaxPool2d(3, stride=1, padding=1),
                nn.AvgPool2d(3, stride=1, padding=1)
            ]),
            nn.ModuleList([
                nn.Conv2d(32, 64, 3, padding=1),
                nn.Conv2d(32, 64, 5, padding=2),
                nn.MaxPool2d(3, stride=1, padding=1),
                nn.AvgPool2d(3, stride=1, padding=1)
            ])
        ])
        
        # Závěrečný klasifikátor
        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d(1),
            nn.Flatten(),
            nn.Linear(64, num_classes)
        )
        
        # Inicializace indexů cesty
        self.selected_ops = None
    
    def forward(self, x):
        x = self.stem(x)
        
        # Pokud je architektura specifikována, použij ji; jinak vyber náhodně
        if self.selected_ops is None:
            # Náhodná cesta pro trénink
            for layer in self.ops:
                op_idx = np.random.randint(0, len(layer))
                x = layer[op_idx](x)
        else:
            # Vybraná cesta pro vyhodnocení
            for layer_idx, op_idx in enumerate(self.selected_ops):
                x = self.ops[layer_idx][op_idx](x)
        
        x = self.classifier(x)
        return x
    
    def set_architecture(self, architecture):
        """Nastavení konkrétní architektury pro vyhodnocení."""
        self.selected_ops = architecture
```

## 10. Shrnutí

Hledání neuronových architektur (NAS) představuje významný krok směrem k automatizaci hlubokého učení. Systematickým prozkoumáváním možných architektur neuronových sítí mohou metody NAS objevit návrhy, které překonávají ty vytvořené lidskými experty.

Klíčové poznatky z tohoto průzkumu NAS:

1. **Komponenty NAS**: Návrh prohledávacího prostoru, strategie prohledávání a odhad výkonu jsou tři klíčové komponenty každé metody NAS.

2. **Strategie prohledávání**: Existuje více přístupů, včetně náhodného vyhledávání, evolučních algoritmů, posilovaného učení a metod založených na gradientech.

3. **Výzvy efektivity**: Tradiční metody NAS jsou výpočetně náročné, ale novější techniky jako sdílení vah, jednorázové metody a diferenciální vyhledávání dramaticky snížily výpočetní nároky.

4. **Praktická implementace**: Knihovny jako PyTorch a TensorFlow umožňují implementovat různé metody NAS, ačkoli produkční NAS stále vyžaduje významné prostředky.

5. **Příběhy úspěchu**: NAS vytvořil state-of-the-art architektury pro klasifikaci obrazu (NASNet, EfficientNet), detekci objektů a úlohy zpracování přirozeného jazyka.

6. **Budoucí směry**: Obor se posouvá směrem k efektivnějším metodám, širším prohledávacím prostorům, které zahrnují hyperparametry a tréninkové strategie, a specializovanému hardwarovému urychlení pro vyhledávání architektur.

S tím, jak techniky NAS nadále dozrávají a stávají se efektivnějšími, můžeme očekávat, že automatizovaný návrh architektury se stane standardní součástí workflow hlubokého učení, což potenciálně povede k novým architekturám, které by lidé nemuseli vymyslet.
