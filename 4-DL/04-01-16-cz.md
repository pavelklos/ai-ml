# Regularizační techniky v hlubokém učení (Dropout, L1/L2)

## 1. Úvod do regularizace

Regularizační techniky jsou nezbytné nástroje v hlubokém učení, které pomáhají předcházet přeučení a zlepšují generalizaci modelu. Bez regularizace mohou hluboké neuronové sítě s mnoha parametry v podstatě "zapamatovat" trénovací data, místo aby se naučily užitečné vzory, což vede k špatným výsledkům na neviděných datech.

Regularizace přidává omezení nebo penalizace do procesu učení, což podporuje model v učení jednodušších vzorů a zabraňuje přizpůsobení se šumu v trénovacích datech.

## 2. Porozumění přeučení (overfitting)

Než se ponoříme do regularizačních technik, pojďme pochopit problém, který řeší:

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

# Generování syntetických dat
np.random.seed(42)
X = np.linspace(-3, 3, 100).reshape(-1, 1)
y = np.sin(X) + np.random.normal(0, 0.2, X.shape)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Škálování dat
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# Vytvoření jednoduchého vs. složitého modelu
simple_model = Sequential([
    Dense(4, activation='relu', input_shape=(1,)),
    Dense(1)
])

complex_model = Sequential([
    Dense(32, activation='relu', input_shape=(1,)),
    Dense(64, activation='relu'),
    Dense(64, activation='relu'),
    Dense(1)
])

# Kompilace modelů
simple_model.compile(optimizer='adam', loss='mse')
complex_model.compile(optimizer='adam', loss='mse')

# Trénování modelů
simple_model.fit(X_train, y_train, epochs=100, verbose=0)
complex_model.fit(X_train, y_train, epochs=100, verbose=0)

# Vykreslení výsledků
X_plot = np.linspace(-3, 3, 1000).reshape(-1, 1)
X_plot_scaled = scaler.transform(X_plot)

plt.figure(figsize=(12, 5))
plt.subplot(1, 2, 1)
plt.scatter(X, y, alpha=0.5, label='Původní data')
plt.plot(X_plot, simple_model.predict(X_plot_scaled), 'r-', label='Jednoduchý model')
plt.title('Jednoduchý model (dobrá generalizace)')
plt.legend()

plt.subplot(1, 2, 2)
plt.scatter(X, y, alpha=0.5, label='Původní data')
plt.plot(X_plot, complex_model.predict(X_plot_scaled), 'g-', label='Složitý model')
plt.title('Složitý model (přeučení)')
plt.legend()
plt.tight_layout()
plt.show()

# Vyhodnocení modelů
simple_train_loss = simple_model.evaluate(X_train, y_train, verbose=0)
simple_test_loss = simple_model.evaluate(X_test, y_test, verbose=0)
complex_train_loss = complex_model.evaluate(X_train, y_train, verbose=0)
complex_test_loss = complex_model.evaluate(X_test, y_test, verbose=0)

print(f"Jednoduchý model - Trénovací ztráta: {simple_train_loss:.4f}, Testovací ztráta: {simple_test_loss:.4f}")
print(f"Složitý model - Trénovací ztráta: {complex_train_loss:.4f}, Testovací ztráta: {complex_test_loss:.4f}")
```

Složitý model pravděpodobně dosahuje nižší trénovací chyby, ale vyšší testovací chyby - klasický znak přeučení. Nyní prozkoumejme, jak mohou regularizační techniky pomoci.

## 3. L2 regularizace (Weight Decay)

L2 regularizace, známá také jako weight decay nebo Ridge regularizace, přidává do ztrátové funkce penalizační člen úměrný součtu čtverců vah.

### Matematická formulace

Upravená ztrátová funkce s L2 regularizací je:

$$L_{regularized} = L_{original} + \lambda \sum_{i} w_i^2$$

Kde:
- $L_{original}$ je původní ztrátová funkce (např. MSE, cross-entropy)
- $\lambda$ je síla regularizace (hyperparametr)
- $w_i$ jsou váhy modelu (bez biasů)

### Implementace v TensorFlow/Keras

```python
from tensorflow.keras.regularizers import l2
from tensorflow.keras.layers import Dense

# Vytvoření modelu s L2 regularizací
l2_lambda = 0.001  # Síla regularizace

model_with_l2 = Sequential([
    Dense(32, activation='relu', input_shape=(1,), 
          kernel_regularizer=l2(l2_lambda)),
    Dense(64, activation='relu', 
          kernel_regularizer=l2(l2_lambda)),
    Dense(64, activation='relu', 
          kernel_regularizer=l2(l2_lambda)),
    Dense(1)
])

model_with_l2.compile(optimizer='adam', loss='mse')
model_with_l2.fit(X_train, y_train, epochs=100, verbose=0)

# Vyhodnocení modelu
l2_train_loss = model_with_l2.evaluate(X_train, y_train, verbose=0)
l2_test_loss = model_with_l2.evaluate(X_test, y_test, verbose=0)
print(f"L2 model - Trénovací ztráta: {l2_train_loss:.4f}, Testovací ztráta: {l2_test_loss:.4f}")

# Vizualizace predikcí
plt.figure(figsize=(10, 6))
plt.scatter(X, y, alpha=0.5, label='Původní data')
plt.plot(X_plot, complex_model.predict(X_plot_scaled), 'g-', label='Bez regularizace')
plt.plot(X_plot, model_with_l2.predict(X_plot_scaled), 'b-', label='S L2 regularizací')
plt.title('Efekt L2 regularizace')
plt.legend()
plt.show()
```

### Efekt L2 regularizace

L2 regularizace zmenšuje váhy směrem k nule, ale zřídka je dělá přesně nulovými. Má tyto účinky:
- Penalizuje velké váhy a podporuje malé, rozprostřené váhy
- Činí model méně citlivý na malé změny vstupu
- Preferuje využití všech příznaků trochu, spíše než některých příznaků hodně

### Výběr správné hodnoty λ

```python
# Testování různých hodnot lambda
lambda_values = [0, 0.0001, 0.001, 0.01, 0.1]
test_losses = []

for l_val in lambda_values:
    model = Sequential([
        Dense(32, activation='relu', input_shape=(1,), 
              kernel_regularizer=l2(l_val)),
        Dense(64, activation='relu', 
              kernel_regularizer=l2(l_val)),
        Dense(64, activation='relu', 
              kernel_regularizer=l2(l_val)),
        Dense(1)
    ])
    model.compile(optimizer='adam', loss='mse')
    history = model.fit(X_train, y_train, epochs=100, 
                        validation_split=0.2, verbose=0)
    
    test_loss = model.evaluate(X_test, y_test, verbose=0)
    test_losses.append(test_loss)

# Vykreslení vlivu lambdy na testovací ztrátu
plt.figure(figsize=(10, 6))
plt.semilogx(lambda_values, test_losses, '-o')
plt.xlabel('Síla L2 regularizace (λ)')
plt.ylabel('Testovací ztráta')
plt.title('Hledání optimální síly L2 regularizace')
plt.grid(True)
plt.show()
```

## 4. L1 regularizace

L1 regularizace, známá také jako Lasso regularizace, přidává penalizační člen úměrný absolutním hodnotám vah.

### Matematická formulace

$$L_{regularized} = L_{original} + \lambda \sum_{i} |w_i|$$

### Implementace v TensorFlow/Keras

```python
from tensorflow.keras.regularizers import l1

# Vytvoření modelu s L1 regularizací
l1_lambda = 0.0001  # L1 typicky potřebuje menší hodnoty než L2

model_with_l1 = Sequential([
    Dense(32, activation='relu', input_shape=(1,), 
          kernel_regularizer=l1(l1_lambda)),
    Dense(64, activation='relu', 
          kernel_regularizer=l1(l1_lambda)),
    Dense(64, activation='relu', 
          kernel_regularizer=l1(l1_lambda)),
    Dense(1)
])

model_with_l1.compile(optimizer='adam', loss='mse')
model_with_l1.fit(X_train, y_train, epochs=100, verbose=0)

# Vyhodnocení modelu
l1_train_loss = model_with_l1.evaluate(X_train, y_train, verbose=0)
l1_test_loss = model_with_l1.evaluate(X_test, y_test, verbose=0)
print(f"L1 model - Trénovací ztráta: {l1_train_loss:.4f}, Testovací ztráta: {l1_test_loss:.4f}")
```

### Efekt L1 regularizace

L1 regularizace má tendenci vytvářet řídké modely, tlačí některé váhy přesně na nulu:
- Provádí implicitní výběr příznaků
- Vytváří jednodušší, interpretovatelné modely
- Funguje dobře, když je mnoho příznaků irelevantních

## 5. Elastic Net (Kombinace L1 a L2)

Elastic Net kombinuje L1 a L2 regularizaci, nabízí výhody obou.

### Matematická formulace

$$L_{regularized} = L_{original} + \lambda_1 \sum_{i} |w_i| + \lambda_2 \sum_{i} w_i^2$$

### Implementace v TensorFlow/Keras

```python
from tensorflow.keras.regularizers import l1_l2

# Vytvoření modelu s Elastic Net regularizací
l1_lambda = 0.0001
l2_lambda = 0.001

model_with_elastic_net = Sequential([
    Dense(32, activation='relu', input_shape=(1,), 
          kernel_regularizer=l1_l2(l1=l1_lambda, l2=l2_lambda)),
    Dense(64, activation='relu', 
          kernel_regularizer=l1_l2(l1=l1_lambda, l2=l2_lambda)),
    Dense(64, activation='relu', 
          kernel_regularizer=l1_l2(l1=l1_lambda, l2=l2_lambda)),
    Dense(1)
])

model_with_elastic_net.compile(optimizer='adam', loss='mse')
model_with_elastic_net.fit(X_train, y_train, epochs=100, verbose=0)

# Vyhodnocení modelu
elastic_net_train_loss = model_with_elastic_net.evaluate(X_train, y_train, verbose=0)
elastic_net_test_loss = model_with_elastic_net.evaluate(X_test, y_test, verbose=0)
print(f"Elastic Net model - Trénovací ztráta: {elastic_net_train_loss:.4f}, Testovací ztráta: {elastic_net_test_loss:.4f}")
```

## 6. Dropout regularizace

Dropout je silná regularizační technika, která dočasně odstraňuje náhodné neurony během tréninku, což nutí síť k redundanci a robustnosti.

### Jak Dropout funguje

1. Během tréninku náhodně nastaví zlomek neuronů na 0 (vyřadí je)
2. Upraví měřítko zbývajících neuronů jako kompenzaci
3. Během testování/inference používá všechny neurony se sníženými vahami

### Implementace v TensorFlow/Keras

```python
from tensorflow.keras.layers import Dropout

# Vytvoření modelu s Dropout
dropout_rate = 0.3  # 30% neuronů bude během tréninku vyřazeno

model_with_dropout = Sequential([
    Dense(32, activation='relu', input_shape=(1,)),
    Dropout(dropout_rate),
    Dense(64, activation='relu'),
    Dropout(dropout_rate),
    Dense(64, activation='relu'),
    Dropout(dropout_rate),
    Dense(1)
])

model_with_dropout.compile(optimizer='adam', loss='mse')
model_with_dropout.fit(X_train, y_train, epochs=100, verbose=0)

# Vyhodnocení modelu
dropout_train_loss = model_with_dropout.evaluate(X_train, y_train, verbose=0)
dropout_test_loss = model_with_dropout.evaluate(X_test, y_test, verbose=0)
print(f"Dropout model - Trénovací ztráta: {dropout_train_loss:.4f}, Testovací ztráta: {dropout_test_loss:.4f}")
```

## 7. Implementace regularizace v PyTorch

```python
import torch
import torch.nn as nn
import torch.optim as optim

# Převod dat na PyTorch tenzory
X_train_tensor = torch.FloatTensor(X_train)
y_train_tensor = torch.FloatTensor(y_train.reshape(-1, 1))
X_test_tensor = torch.FloatTensor(X_test)
y_test_tensor = torch.FloatTensor(y_test.reshape(-1, 1))

# Definice modelu s L2 regularizací
class L2RegularizedModel(nn.Module):
    def __init__(self):
        super(L2RegularizedModel, self).__init__()
        self.fc1 = nn.Linear(1, 32)
        self.relu1 = nn.ReLU()
        self.fc2 = nn.Linear(32, 64)
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(64, 64)
        self.relu3 = nn.ReLU()
        self.fc4 = nn.Linear(64, 1)
        
    def forward(self, x):
        x = self.relu1(self.fc1(x))
        x = self.relu2(self.fc2(x))
        x = self.relu3(self.fc3(x))
        x = self.fc4(x)
        return x

# Definice modelu s dropoutem
class DropoutModel(nn.Module):
    def __init__(self, dropout_rate=0.3):
        super(DropoutModel, self).__init__()
        self.fc1 = nn.Linear(1, 32)
        self.relu1 = nn.ReLU()
        self.dropout1 = nn.Dropout(dropout_rate)
        self.fc2 = nn.Linear(32, 64)
        self.relu2 = nn.ReLU()
        self.dropout2 = nn.Dropout(dropout_rate)
        self.fc3 = nn.Linear(64, 64)
        self.relu3 = nn.ReLU()
        self.dropout3 = nn.Dropout(dropout_rate)
        self.fc4 = nn.Linear(64, 1)
        
    def forward(self, x):
        x = self.dropout1(self.relu1(self.fc1(x)))
        x = self.dropout2(self.relu2(self.fc2(x)))
        x = self.dropout3(self.relu3(self.fc3(x)))
        x = self.fc4(x)
        return x

# Trénování s L2 regularizací v PyTorch
l2_model = L2RegularizedModel()
criterion = nn.MSELoss()
weight_decay = 0.001  # Síla L2 regularizace
optimizer = optim.Adam(l2_model.parameters(), lr=0.01, weight_decay=weight_decay)

# Trénovací cyklus
epochs = 100
for epoch in range(epochs):
    # Dopředný průchod
    outputs = l2_model(X_train_tensor)
    loss = criterion(outputs, y_train_tensor)
    
    # Zpětný průchod a optimalizace
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    
    if (epoch+1) % 20 == 0:
        print(f'L2 Model - Epocha [{epoch+1}/{epochs}], Ztráta: {loss.item():.4f}')

# Trénování s dropoutem v PyTorch
dropout_model = DropoutModel(dropout_rate=0.3)
optimizer_dropout = optim.Adam(dropout_model.parameters(), lr=0.01)

# Trénovací cyklus
for epoch in range(epochs):
    # Nastavení trénovacího režimu
    dropout_model.train()
    
    # Dopředný průchod
    outputs = dropout_model(X_train_tensor)
    loss = criterion(outputs, y_train_tensor)
    
    # Zpětný průchod a optimalizace
    optimizer_dropout.zero_grad()
    loss.backward()
    optimizer_dropout.step()
    
    if (epoch+1) % 20 == 0:
        # Nastavení evaluačního režimu
        dropout_model.eval()
        test_outputs = dropout_model(X_test_tensor)
        test_loss = criterion(test_outputs, y_test_tensor)
        print(f'Dropout Model - Epocha [{epoch+1}/{epochs}], '
              f'Trénovací ztráta: {loss.item():.4f}, Testovací ztráta: {test_loss.item():.4f}')
```

## 8. Porovnání regularizačních technik na reálném datasetu

Pojďme porovnat tyto metody na datasetu MNIST:

```python
from tensorflow.keras.datasets import mnist
from tensorflow.keras.utils import to_categorical

# Načtení a předzpracování MNIST dat
(X_train, y_train), (X_test, y_test) = mnist.load_data()
X_train = X_train.reshape(-1, 28*28).astype('float32') / 255
X_test = X_test.reshape(-1, 28*28).astype('float32') / 255
y_train = to_categorical(y_train, 10)
y_test = to_categorical(y_test, 10)

# Základní model (náchylný k přeučení)
def create_base_model():
    model = Sequential([
        Dense(512, activation='relu', input_shape=(784,)),
        Dense(256, activation='relu'),
        Dense(128, activation='relu'),
        Dense(10, activation='softmax')
    ])
    model.compile(optimizer='adam', 
                  loss='categorical_crossentropy', 
                  metrics=['accuracy'])
    return model

# Model s L2 regularizací
def create_l2_model(l2_lambda=0.001):
    model = Sequential([
        Dense(512, activation='relu', input_shape=(784,), 
              kernel_regularizer=l2(l2_lambda)),
        Dense(256, activation='relu', 
              kernel_regularizer=l2(l2_lambda)),
        Dense(128, activation='relu', 
              kernel_regularizer=l2(l2_lambda)),
        Dense(10, activation='softmax')
    ])
    model.compile(optimizer='adam', 
                  loss='categorical_crossentropy', 
                  metrics=['accuracy'])
    return model

# Model s L1 regularizací
def create_l1_model(l1_lambda=0.0001):
    model = Sequential([
        Dense(512, activation='relu', input_shape=(784,), 
              kernel_regularizer=l1(l1_lambda)),
        Dense(256, activation='relu', 
              kernel_regularizer=l1(l1_lambda)),
        Dense(128, activation='relu', 
              kernel_regularizer=l1(l1_lambda)),
        Dense(10, activation='softmax')
    ])
    model.compile(optimizer='adam', 
                  loss='categorical_crossentropy', 
                  metrics=['accuracy'])
    return model

# Model s Dropout
def create_dropout_model(dropout_rate=0.3):
    model = Sequential([
        Dense(512, activation='relu', input_shape=(784,)),
        Dropout(dropout_rate),
        Dense(256, activation='relu'),
        Dropout(dropout_rate),
        Dense(128, activation='relu'),
        Dropout(dropout_rate),
        Dense(10, activation='softmax')
    ])
    model.compile(optimizer='adam', 
                  loss='categorical_crossentropy', 
                  metrics=['accuracy'])
    return model

# Model s kombinovanou regularizací
def create_combined_model(l2_lambda=0.001, dropout_rate=0.3):
    model = Sequential([
        Dense(512, activation='relu', input_shape=(784,), 
              kernel_regularizer=l2(l2_lambda)),
        Dropout(dropout_rate),
        Dense(256, activation='relu', 
              kernel_regularizer=l2(l2_lambda)),
        Dropout(dropout_rate),
        Dense(128, activation='relu', 
              kernel_regularizer=l2(l2_lambda)),
        Dropout(dropout_rate),
        Dense(10, activation='softmax')
    ])
    model.compile(optimizer='adam', 
                  loss='categorical_crossentropy', 
                  metrics=['accuracy'])
    return model

# Trénování a vyhodnocení modelů
def train_and_evaluate(model, name):
    print(f"Trénování modelu {name}...")
    history = model.fit(
        X_train, y_train,
        batch_size=128,
        epochs=5,
        validation_split=0.1,
        verbose=1
    )
    
    test_loss, test_acc = model.evaluate(X_test, y_test)
    print(f"{name} - Testovací přesnost: {test_acc:.4f}")
    return history

# Vytvoření všech modelů
base_model = create_base_model()
l1_model = create_l1_model()
l2_model = create_l2_model()
dropout_model = create_dropout_model()
combined_model = create_combined_model()

# Trénování a vyhodnocení
base_history = train_and_evaluate(base_model, "Základní")
l1_history = train_and_evaluate(l1_model, "L1 regularizace")
l2_history = train_and_evaluate(l2_model, "L2 regularizace")
dropout_history = train_and_evaluate(dropout_model, "Dropout")
combined_history = train_and_evaluate(combined_model, "Kombinovaný (L2 + Dropout)")

# Vykreslení porovnání validační přesnosti
plt.figure(figsize=(12, 6))
plt.plot(base_history.history['val_accuracy'], label='Základní model')
plt.plot(l1_history.history['val_accuracy'], label='L1 regularizace')
plt.plot(l2_history.history['val_accuracy'], label='L2 regularizace')
plt.plot(dropout_history.history['val_accuracy'], label='Dropout')
plt.plot(combined_history.history['val_accuracy'], label='Kombinovaný (L2 + Dropout)')
plt.title('Porovnání validační přesnosti')
plt.xlabel('Epocha')
plt.ylabel('Validační přesnost')
plt.legend()
plt.grid(True)
plt.show()
```

## 9. Pokročilé regularizační techniky

Kromě základních technik, které jsme probrali, existuje několik pokročilých regularizačních metod:

### Předčasné zastavení (Early Stopping)

Technicky nejde o regularizační člen, ale zabraňuje přeučení zastavením tréninku, když se validační výkon přestane zlepšovat.

```python
from tensorflow.keras.callbacks import EarlyStopping

early_stopping = EarlyStopping(
    monitor='val_loss',
    patience=5,
    restore_best_weights=True
)

model = create_base_model()
history = model.fit(
    X_train, y_train,
    epochs=100,
    batch_size=128,
    validation_split=0.1,
    callbacks=[early_stopping],
    verbose=1
)

print(f"Trénink zastaven v epoše {len(history.history['loss'])}")
```

### Rozšíření dat (Data Augmentation)

Umělé rozšíření trénovací sady aplikací náhodných transformací na existující data.

```python
from tensorflow.keras.preprocessing.image import ImageDataGenerator

# Změna tvaru zpět na 2D pro rozšíření obrazu
X_train_img = X_train.reshape(-1, 28, 28, 1)

# Vytvoření generátoru dat
datagen = ImageDataGenerator(
    rotation_range=10,
    width_shift_range=0.1,
    height_shift_range=0.1,
    zoom_range=0.1
)

# Konfigurace velikosti dávky a příprava generátoru dat
batch_size = 128
train_generator = datagen.flow(X_train_img, y_train, batch_size=batch_size)

# Vytvoření modelu
model = Sequential([
    # Použití 2D konvolučních vrstev pro obrazová data
    tf.keras.layers.Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
    tf.keras.layers.MaxPooling2D(2, 2),
    tf.keras.layers.Conv2D(64, (3, 3), activation='relu'),
    tf.keras.layers.MaxPooling2D(2, 2),
    tf.keras.layers.Flatten(),
    Dense(128, activation='relu'),
    Dropout(0.3),
    Dense(10, activation='softmax')
])

model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])

# Trénování s využitím rozšíření dat
history = model.fit(
    train_generator,
    steps_per_epoch=X_train.shape[0] // batch_size,
    epochs=10,
    validation_data=(X_test.reshape(-1, 28, 28, 1), y_test)
)
```

### Vyhlazení labelů (Label Smoothing)

Regularizuje model tím, že mu zabraňuje být příliš jistý ve svých predikcích.

```python
from tensorflow.keras.losses import CategoricalCrossentropy

# Vytvoření modelu s vyhlazením labelů
model = create_base_model()

# Aktualizace ztrátové funkce pro použití vyhlazení labelů
model.compile(
    optimizer='adam',
    loss=CategoricalCrossentropy(label_smoothing=0.1),  # Faktor vyhlazení
    metrics=['accuracy']
)

# Trénování modelu
history = model.fit(
    X_train, y_train,
    batch_size=128,
    epochs=5,
    validation_split=0.1,
    verbose=1
)
```

5. **Zvažte velikost dat** - S více daty můžete použít méně regularizace
