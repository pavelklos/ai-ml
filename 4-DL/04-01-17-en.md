# Transfer Learning Introduction

## 1. What is Transfer Learning?

Transfer learning is a machine learning technique that leverages knowledge gained from solving one problem to help solve a different but related problem. In deep learning, this typically means using a pre-trained model (trained on a large dataset) as a starting point for a model on a new task. This approach is especially powerful when you have limited training data for your specific problem.

The core idea is simple but profound: neural networks learn hierarchical features, where early layers capture basic patterns (edges, textures) while deeper layers capture more complex concepts. These basic patterns are often transferable across different tasks.

## 2. Why Use Transfer Learning?

Transfer learning offers several significant benefits:

- **Reduced training time**: Starting with pre-trained weights dramatically speeds up convergence
- **Less data required**: You can achieve good results with much smaller datasets
- **Better performance**: Often leads to higher accuracy than training from scratch
- **Lower computational resources**: Requires less computing power than training full models

## 3. When to Use Transfer Learning

Transfer learning is especially effective when:

- Your task has limited training data
- The pre-trained model was trained on data similar to your target task
- You want to accelerate the training process
- You lack computational resources for full training

## 4. Types of Transfer Learning

### 4.1 Feature Extraction

In this approach, you use a pre-trained network as a fixed feature extractor. You:
1. Remove the final classification layers
2. Freeze all remaining layers (so their weights won't update)
3. Add new classification layers for your specific task
4. Train only these new layers

### 4.2 Fine-Tuning

In fine-tuning, you not only replace and train the classification layers but also update some or all of the weights in the pre-trained network to better adapt to the new task:

1. Start with a pre-trained model
2. Replace the final classification layers
3. Optionally freeze early layers (which capture more generic features)
4. Train the model with a small learning rate to fine-tune the weights

## 5. Popular Pre-trained Models

Many models pre-trained on large datasets like ImageNet are available:

- **ResNet** family (ResNet-50, ResNet-101, etc.)
- **VGG** models (VGG16, VGG19)
- **Inception** models
- **EfficientNet** family
- **MobileNet** for mobile applications
- **BERT**, **GPT** series for NLP tasks

## 6. Transfer Learning with TensorFlow/Keras

Let's implement transfer learning using TensorFlow/Keras with a pre-trained ResNet50 model.

### 6.1 Feature Extraction Example

```python
import tensorflow as tf
from tensorflow.keras.applications import ResNet50
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D
from tensorflow.keras.models import Model

# Load pre-trained model without the classification head
base_model = ResNet50(weights='imagenet', include_top=False, input_shape=(224, 224, 3))

# Freeze all the layers in the base model
for layer in base_model.layers:
    layer.trainable = False

# Add custom classification head
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(1024, activation='relu')(x)
predictions = Dense(10, activation='softmax')(x)  # 10 classes in this example

# Create the new model
model = Model(inputs=base_model.input, outputs=predictions)

# Compile the model
model.compile(optimizer='adam', 
              loss='categorical_crossentropy', 
              metrics=['accuracy'])

# Create data generators for training and validation
train_datagen = ImageDataGenerator(
    rescale=1./255,
    rotation_range=20,
    width_shift_range=0.2,
    height_shift_range=0.2,
    horizontal_flip=True)

test_datagen = ImageDataGenerator(rescale=1./255)

train_generator = train_datagen.flow_from_directory(
    'train_directory',
    target_size=(224, 224),
    batch_size=32,
    class_mode='categorical')

validation_generator = test_datagen.flow_from_directory(
    'validation_directory',
    target_size=(224, 224),
    batch_size=32,
    class_mode='categorical')

# Train the model
history = model.fit(
    train_generator,
    steps_per_epoch=train_generator.samples // 32,
    epochs=10,
    validation_data=validation_generator,
    validation_steps=validation_generator.samples // 32)

# Save the model
model.save('transfer_learning_model.h5')
```

## 7. Transfer Learning with PyTorch

Let's see how to implement transfer learning in PyTorch using a pre-trained ResNet model.

### 7.1 Feature Extraction Example

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, models, transforms
import matplotlib.pyplot as plt
import time
import copy

# Data transformations
data_transforms = {
    'train': transforms.Compose([
        transforms.RandomResizedCrop(224),
        transforms.RandomHorizontalFlip(),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
    ]),
    'val': transforms.Compose([
        transforms.Resize(256),
        transforms.CenterCrop(224),
        transforms.ToTensor(),
        transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
    ]),
}

# Load data
data_dir = 'data'
image_datasets = {x: datasets.ImageFolder(f'{data_dir}/{x}', data_transforms[x])
                  for x in ['train', 'val']}
dataloaders = {x: torch.utils.data.DataLoader(image_datasets[x], batch_size=32, shuffle=True, num_workers=4)
              for x in ['train', 'val']}
dataset_sizes = {x: len(image_datasets[x]) for x in ['train', 'val']}
class_names = image_datasets['train'].classes

device = torch.device("cuda:0" if torch.cuda.is_available() else "cpu")

def train_model(model, criterion, optimizer, num_epochs=25):
    since = time.time()
    best_model_wts = copy.deepcopy(model.state_dict())
    best_acc = 0.0

    for epoch in range(num_epochs):
        print(f'Epoch {epoch}/{num_epochs - 1}')
        print('-' * 10)

        # Each epoch has a training and validation phase
        for phase in ['train', 'val']:
            if phase == 'train':
                model.train()  # Set model to training mode
            else:
                model.eval()   # Set model to evaluate mode

            running_loss = 0.0
            running_corrects = 0

            # Iterate over data
            for inputs, labels in dataloaders[phase]:
                inputs = inputs.to(device)
                labels = labels.to(device)

                # Zero the parameter gradients
                optimizer.zero_grad()

                # Forward pass
                with torch.set_grad_enabled(phase == 'train'):
                    outputs = model(inputs)
                    _, preds = torch.max(outputs, 1)
                    loss = criterion(outputs, labels)

                    # Backward + optimize only if in training phase
                    if phase == 'train':
                        loss.backward()
                        optimizer.step()

                # Statistics
                running_loss += loss.item() * inputs.size(0)
                running_corrects += torch.sum(preds == labels.data)

            epoch_loss = running_loss / dataset_sizes[phase]
            epoch_acc = running_corrects.double() / dataset_sizes[phase]

            print(f'{phase} Loss: {epoch_loss:.4f} Acc: {epoch_acc:.4f}')

            # Deep copy the model
            if phase == 'val' and epoch_acc > best_acc:
                best_acc = epoch_acc
                best_model_wts = copy.deepcopy(model.state_dict())

        print()

    time_elapsed = time.time() - since
    print(f'Training complete in {time_elapsed // 60:.0f}m {time_elapsed % 60:.0f}s')
    print(f'Best val Acc: {best_acc:.4f}')

    # Load best model weights
    model.load_state_dict(best_model_wts)
    return model

# Load a pretrained model
model_ft = models.resnet50(pretrained=True)

# Freeze all the network except the final layer
for param in model_ft.parameters():
    param.requires_grad = False

# Replace the final fully connected layer
num_ftrs = model_ft.fc.in_features
model_ft.fc = nn.Linear(num_ftrs, len(class_names))

model_ft = model_ft.to(device)

criterion = nn.CrossEntropyLoss()

# Only parameters of final layer are being optimized
optimizer_ft = optim.SGD(model_ft.fc.parameters(), lr=0.001, momentum=0.9)

# Train and evaluate
model_ft = train_model(model_ft, criterion, optimizer_ft, num_epochs=10)

# Save the model
torch.save(model_ft.state_dict(), 'transfer_learning_model.pth')
```

### 7.2 Fine-Tuning Example

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, models, transforms

# Load pretrained model
model_ft = models.resnet50(pretrained=True)

# First freeze all layers
for param in model_ft.parameters():
    param.requires_grad = False

# Replace the final fully connected layer
num_ftrs = model_ft.fc.in_features
model_ft.fc = nn.Linear(num_ftrs, len(class_names))

model_ft = model_ft.to(device)

# First phase: train only the classifier
criterion = nn.CrossEntropyLoss()
optimizer_ft = optim.SGD(model_ft.fc.parameters(), lr=0.001, momentum=0.9)

print("Phase 1: Training only the classifier...")
model_ft = train_model(model_ft, criterion, optimizer_ft, num_epochs=5)

# Second phase: Fine-tune selected layers
# Unfreeze some layers for fine-tuning
ct = 0
for child in model_ft.children():
    ct += 1
    if ct > 7:  # Fine-tune the last few layers (adjust based on your needs)
        for param in child.parameters():
            param.requires_grad = True

# Recompile with a lower learning rate
optimizer_ft = optim.SGD(filter(lambda p: p.requires_grad, model_ft.parameters()),
                          lr=0.0001, momentum=0.9)

print("Phase 2: Fine-tuning the model...")
model_ft = train_model(model_ft, criterion, optimizer_ft, num_epochs=10)

# Save the fine-tuned model
torch.save(model_ft.state_dict(), 'fine_tuned_model.pth')
```

## 8. Practical Example: Transfer Learning for Custom Image Classification

Let's implement a complete transfer learning solution for a flower classification task:

```python
import tensorflow as tf
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras import layers, models
import matplotlib.pyplot as plt
import os
import numpy as np

# Download the flower dataset (TensorFlow Datasets)
import tensorflow_datasets as tfds
tfds.disable_progress_bar()

# Split the dataset manually into train, validation, and test sets
split_weights = (8, 1, 1)
splits = tfds.Split.TRAIN.subsplit(weighted=split_weights)

# Loading the dataset
(train_ds, validation_ds, test_ds), dataset_info = tfds.load(
    'tf_flowers', 
    split=splits,
    with_info=True,
    as_supervised=True)

# Get class names
num_classes = dataset_info.features['label'].num_classes
class_names = dataset_info.features['label'].names

print(f"Number of classes: {num_classes}")
print(f"Class names: {class_names}")

# Function to preprocess images
def preprocess_image(image, label):
    image = tf.cast(image, tf.float32)
    image = tf.image.resize(image, (224, 224))
    image = image / 255.0  # Normalize to [0,1]
    return image, label

# Apply preprocessing to datasets
batch_size = 32
train_ds = train_ds.map(preprocess_image).batch(batch_size).prefetch(buffer_size=tf.data.AUTOTUNE)
validation_ds = validation_ds.map(preprocess_image).batch(batch_size).prefetch(buffer_size=tf.data.AUTOTUNE)
test_ds = test_ds.map(preprocess_image).batch(batch_size).prefetch(buffer_size=tf.data.AUTOTUNE)

# Display some sample images
plt.figure(figsize=(10, 10))
for images, labels in train_ds.take(1):
    for i in range(9):
        plt.subplot(3, 3, i + 1)
        plt.imshow(images[i])
        plt.title(class_names[labels[i].numpy()])
        plt.axis('off')
plt.show()

# Create a base model from the pre-trained model MobileNetV2
base_model = MobileNetV2(input_shape=(224, 224, 3),
                          include_top=False,
                          weights='imagenet')

# Freeze the base model
base_model.trainable = False

# Create the new model on top
model = models.Sequential([
    base_model,
    layers.GlobalAveragePooling2D(),
    layers.Dense(128, activation='relu'),
    layers.Dropout(0.2),
    layers.Dense(num_classes, activation='softmax')
])

model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

print(model.summary())

# Train the model (feature extraction phase)
history = model.fit(
    train_ds,
    validation_data=validation_ds,
    epochs=10
)

# Plot training results
acc = history.history['accuracy']
val_acc = history.history['val_accuracy']

loss = history.history['loss']
val_loss = history.history['val_loss']

plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(acc, label='Training Accuracy')
plt.plot(val_acc, label='Validation Accuracy')
plt.legend(loc='lower right')
plt.title('Training and Validation Accuracy')

plt.subplot(1, 2, 2)
plt.plot(loss, label='Training Loss')
plt.plot(val_loss, label='Validation Loss')
plt.legend(loc='upper right')
plt.title('Training and Validation Loss')
plt.show()

# Fine-tuning
print("Fine-tuning the model...")

# Unfreeze some of the top layers of the base model
base_model.trainable = True
for layer in base_model.layers[:-20]:
    layer.trainable = False

# Compile with a lower learning rate
model.compile(optimizer=tf.keras.optimizers.Adam(1e-5),
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# Continue training with fine-tuning
history_fine = model.fit(
    train_ds,
    validation_data=validation_ds,
    epochs=10,
    initial_epoch=10  # Start from the last epoch of the previous training
)

# Evaluate the model
loss, accuracy = model.evaluate(test_ds)
print(f"Test accuracy: {accuracy:.4f}")

# Function to make predictions
def predict_image(model, img_path):
    img = tf.keras.preprocessing.image.load_img(
        img_path, target_size=(224, 224)
    )
    img_array = tf.keras.preprocessing.image.img_to_array(img)
    img_array = tf.expand_dims(img_array, 0) / 255.0
    
    predictions = model.predict(img_array)
    predicted_class = np.argmax(predictions[0])
    confidence = np.max(predictions[0])
    
    return predicted_class, confidence, class_names[predicted_class]

# Save the model
model.save('flower_classifier.h5')
```

## 9. Visualizing Features and Transfer Learning

Let's visualize what the model has learned during transfer learning:

import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.keras.preprocessing import image
from tensorflow.keras.models import Model

# Load your trained model
model = tf.keras.models.load_model('flower_classifier.h5')

x = np.expand_dims(x, axis=0)

# Get activations
activations = activation_model.predict(x)

# Visualize feature maps from one of the layers
layer_names = [layer.name for layer in model.layers[0].layers[1:6]]
images_per_row = 16

for layer_name, layer_activation in zip(layer_names, activations):
    n_features = layer_activation.shape[-1]
    size = layer_activation.shape[1]
    
    n_cols = n_features // images_per_row
    display_grid = np.zeros((size * n_cols, images_per_row * size))
    
    for col in range(n_cols):
        for row in range(images_per_row):
            channel_index = col * images_per_row + row
            if channel_index < n_features:
                channel_image = layer_activation[0, :, :, channel_index]
                channel_image -= channel_image.mean()
                channel_image /= channel_image.std() + 1e-5
                channel_image *= 64
                channel_image += 128
                channel_image = np.clip(channel_image, 0, 255).astype('uint8')
                display_grid[col * size : (col + 1) * size,
                             row * size : (row + 1) * size] = channel_image

    plt.figure(figsize=(scale * display_grid.shape[1],
                       scale * display_grid.shape[0]))

## 10. Best Practices for Transfer Learning

Here are some tips for effective transfer learning:

1. **Choose a relevant pre-trained model**: Select a model trained on data that's similar to your target data
2. **Image preprocessing**: Match the preprocessing used during the original model training
3. **Gradual unfreezing**: Instead of unfreezing all layers at once, gradually unfreeze from top to bottom
4. **Use a lower learning rate for fine-tuning**: Typically 10x smaller than the initial learning rate
5. **Data augmentation**: Especially important when you have a small dataset
6. **Early stopping**: Monitor validation metrics to prevent overfitting during fine-tuning
7. **Try different freezing strategies**: Experiment with freezing different numbers of layers
8. **Use different learning rates for different layers**: Lower rates for pre-trained layers, higher for new layers

## 11. Challenges in Transfer Learning

Some common challenges and how to address them:

1. **Domain mismatch**: When source and target domains are too different
   - Solution: Use domain adaptation techniques or find a more suitable pre-trained model

2. **Catastrophic forgetting**: When fine-tuning erases useful pre-trained knowledge
   - Solution: Use gradual unfreezing, proper learning rates, and regularization

3. **Overfitting**: Especially with small datasets
   - Solution: Strong regularization, data augmentation, and early stopping

4. **Input shapes**: When your data has different dimensions than the pre-trained model
   - Solution: Resize inputs or modify the network architecture

5. **Computational resources**: Fine-tuning large models can be expensive
   - Solution: Start with feature extraction, use mixed-precision training, or try smaller models

### 12.2 Knowledge Distillation

Transfer knowledge from a large pre-trained model to a smaller one:

```python
import tensorflow as tf
from tensorflow.keras.layers import Dense, Input
from tensorflow.keras.models import Model

# Teacher model (pre-trained)
teacher = tf.keras.applications.ResNet50(weights='imagenet')

# Student model (smaller)
input_tensor = Input(shape=(224, 224, 3))
x = tf.keras.applications.MobileNetV2(include_top=False, weights='imagenet',
                                      input_tensor=input_tensor).output
x = tf.keras.layers.GlobalAveragePooling2D()(x)
x = Dense(1024, activation='relu')(x)
student_outputs = Dense(1000, activation='softmax')(x)
student = Model(inputs=input_tensor, outputs=student_outputs)

# Define distillation loss function
def distillation_loss(y_true, y_pred, teacher_logits, T=2.0, alpha=0.1):
    """
    Combined loss function for knowledge distillation
    y_true: true labels
    y_pred: student predictions
    teacher_logits: teacher model predictions
    T: temperature for softening probability distributions
    alpha: weight for balancing hard/soft targets
    """
    hard_loss = tf.keras.losses.categorical_crossentropy(
        y_true, y_pred)
    
    soft_targets = tf.nn.softmax(teacher_logits / T)
    soft_prob = tf.nn.softmax(y_pred / T)
    soft_loss = tf.keras.losses.kullback_leibler_divergence(
        soft_targets, soft_prob) * (T**2)
    
    return alpha * hard_loss + (1 - alpha) * soft_loss

# Set up training
student.compile(
    optimizer=tf.keras.optimizers.Adam(1e-4),
    loss=lambda y_true, y_pred: distillation_loss(
        y_true, y_pred, teacher.predict(x_input)),
    metrics=['accuracy']
)
```

## 13. Conclusion and Next Steps

Transfer learning is a powerful technique that significantly speeds up the training of deep learning models and improves performance, especially when dealing with limited data. As you've seen, implementing transfer learning in both TensorFlow/Keras and PyTorch is relatively straightforward, and the benefits are substantial.

As you continue exploring transfer learning, consider:

- Experimenting with different pre-trained models
- Trying different freezing/unfreezing strategies
- Applying transfer learning to non-image domains (NLP, audio)
- Exploring domain adaptation techniques
- Combining transfer learning with other techniques like semi-supervised learning
