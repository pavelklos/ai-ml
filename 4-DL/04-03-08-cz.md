## 1. Úvod do komprese modelů

Komprese modelů je zásadní pro nasazování modelů hlubokého učení na zařízeních s omezenými zdroji, jako jsou mobilní telefony, vestavěné systémy a okrajová zařízení. Bez komprese mohou být moderní modely hlubokého učení příliš velké a výpočetně náročné pro praktické nasazení.

Klíčové výhody komprese modelů zahrnují:

- Snížená velikost modelu pro snazší distribuci a ukládání
- Snížená paměťová náročnost během inference
- Nižší výpočetní nároky a rychlejší inference
- Snížená spotřeba energie
- Umožnění nasazení na hardwaru s omezenými zdroji

## 2. Základy kvantizace

Kvantizace snižuje přesnost numerických reprezentací v neuronové síti, typicky z 32-bitových čísel s plovoucí desetinnou čárkou na formáty s nižším počtem bitů jako 16-bit, 8-bit, nebo dokonce 4-bit a 1-bit (binární) hodnoty. To výrazně snižuje paměťové nároky a může urychlit výpočty.

### Typy kvantizace

1. **Kvantizace vah**: Snižuje pouze parametry modelu
2. **Kvantizace aktivací**: Snižuje mezivýsledky aktivací
3. **Plná kvantizace**: Snižuje jak váhy, tak aktivace

```python
# Příklad manuální implementace kvantizace
def simple_quantization(tensor, num_bits=8):
    """Kvantizace tenzoru na určený počet bitů"""
    # Výpočet rozsahu tenzoru
    tensor_min = tf.reduce_min(tensor)
    tensor_max = tf.reduce_max(tensor)
    
    # Výpočet velikosti kroku (měřítka)
    step = (tensor_max - tensor_min) / (2**num_bits - 1)
    
    # Kvantizace tenzoru
    quantized_tensor = tf.round((tensor - tensor_min) / step)
    
    # Převod zpět na původní rozsah (dekvantizace pro uložení)
    dequantized_tensor = quantized_tensor * step + tensor_min
    
    return quantized_tensor, dequantized_tensor, step, tensor_min

# Vytvoření vzorového tenzoru
original_tensor = tf.random.normal([5, 5])
print("Původní tenzor:")
print(original_tensor.numpy())

# Kvantizace na 8 bitů
quantized, dequantized, step, min_val = simple_quantization(original_tensor, 8)
print("\nKvantizovaný tenzor (8-bit):")
print(quantized.numpy())

print("\nDekvantizovaný tenzor (rekonstruovaný z 8-bit):")
print(dequantized.numpy())

# Výpočet chyby kvantizace
error = tf.reduce_mean(tf.abs(original_tensor - dequantized))
print(f"\nPrůměrná chyba kvantizace: {error.numpy():.6f}")
```

## 3. Kvantizace po tréninku

Kvantizace po tréninku (PTQ) aplikuje kvantizaci na již natrénovaný model bez přetrénování. Je to nejjednodušší přístup ke kompresi modelu a funguje dobře pro mnoho aplikací.

### Příklad v TensorFlow

```python
# Příklad kvantizace po tréninku v TensorFlow
import tensorflow as tf

# Načtení předtrénovaného modelu (použití MobileNetV2 jako příkladu)
base_model = tf.keras.applications.MobileNetV2(
    input_shape=(224, 224, 3),
    include_top=True,
    weights='imagenet'
)

# Konverze na model TensorFlow Lite
converter = tf.lite.TFLiteConverter.from_keras_model(base_model)

# Aplikace výchozí kvantizace po tréninku
converter.optimizations = [tf.lite.Optimize.DEFAULT]

# Definice reprezentativního datasetu pro kalibraci
def representative_dataset():
    for _ in range(100):
        data = np.random.rand(1, 224, 224, 3) * 255
        yield [data.astype(np.float32)]

# Aplikace plné integer kvantizace
converter.representative_dataset = representative_dataset
converter.target_spec.supported_ops = [tf.lite.OpsSet.TFLITE_BUILTINS_INT8]
converter.inference_input_type = tf.int8
converter.inference_output_type = tf.int8

# Konverze modelu
quantized_model = converter.convert()

# Uložení modelu
with open('mobilenet_v2_quantized.tflite', 'wb') as f:
    f.write(quantized_model)

# Porovnání velikosti modelu
original_size = os.path.getsize('mobilenet_v2_original.tflite') / (1024 * 1024)
quantized_size = os.path.getsize('mobilenet_v2_quantized.tflite') / (1024 * 1024)

print(f"Velikost původního modelu: {original_size:.2f} MB")
print(f"Velikost kvantizovaného modelu: {quantized_size:.2f} MB")
print(f"Kompresní poměr: {original_size / quantized_size:.2f}x")
```

### Příklad v PyTorch

```python
# Příklad kvantizace po tréninku v PyTorch
import torch
import torch.quantization

# Načtení předtrénovaného modelu
model = torch.hub.load('pytorch/vision:v0.10.0', 'mobilenet_v2', pretrained=True)
model.eval()

# Sloučení konvolucí, batch normalizace a ReLU pro lepší kvantizaci
model_fused = torch.quantization.fuse_modules(model, [['Conv2d', 'BatchNorm2d', 'ReLU']])

# Nastavení konfigurace kvantizace
model_fused.qconfig = torch.quantization.get_default_qconfig('fbgemm')
model_fused = torch.quantization.prepare(model_fused)

# Kalibrace s vzorkovými daty
with torch.no_grad():
    for _ in range(100):
        inputs = torch.randn(1, 3, 224, 224)
        outputs = model_fused(inputs)

# Konverze na kvantizovaný model
model_quantized = torch.quantization.convert(model_fused)

# Uložení modelů pro porovnání velikosti
torch.save(model.state_dict(), 'mobilenet_v2_original.pth')
torch.save(model_quantized.state_dict(), 'mobilenet_v2_quantized.pth')

# Porovnání velikosti modelů
original_size = os.path.getsize('mobilenet_v2_original.pth') / (1024 * 1024)
quantized_size = os.path.getsize('mobilenet_v2_quantized.pth') / (1024 * 1024)

print(f"Velikost původního modelu: {original_size:.2f} MB")
print(f"Velikost kvantizovaného modelu: {quantized_size:.2f} MB")
print(f"Kompresní poměr: {original_size / quantized_size:.2f}x")
```

## 4. Trénování s vědomím kvantizace

Trénování s vědomím kvantizace (QAT) simuluje efekty kvantizace během tréninku, což umožňuje modelu přizpůsobit se snížené přesnosti. To typicky poskytuje lepší výsledky než kvantizace po tréninku, zejména pro nižší bitové šířky.

```python
# Trénování s vědomím kvantizace v TensorFlow
import tensorflow as tf
import tensorflow_model_optimization as tfmot

# Vytvoření jednoduchého modelu
def create_model():
    model = tf.keras.Sequential([
        tf.keras.layers.Conv2D(32, 3, activation='relu', input_shape=(28, 28, 1)),
        tf.keras.layers.MaxPooling2D(),
        tf.keras.layers.Conv2D(64, 3, activation='relu'),
        tf.keras.layers.MaxPooling2D(),
        tf.keras.layers.Flatten(),
        tf.keras.layers.Dense(128, activation='relu'),
        tf.keras.layers.Dense(10)
    ])
    return model

# Načtení datasetu MNIST
mnist = tf.keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0
x_train = x_train[..., tf.newaxis]
x_test = x_test[..., tf.newaxis]

# Vytvoření a kompilace základního modelu
base_model = create_model()
base_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

# Aplikace trénování s vědomím kvantizace
quantize_model = tfmot.quantization.keras.quantize_model

# Vytvoření modelu s vědomím kvantizace
q_aware_model = quantize_model(base_model)

# Kompilace a trénink modelu s vědomím kvantizace
q_aware_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

q_aware_model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=2,
    validation_data=(x_test, y_test)
)

# Konverze na model TensorFlow Lite
converter = tf.lite.TFLiteConverter.from_keras_model(q_aware_model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
quantized_tflite_model = converter.convert()

# Uložení modelu
with open('mnist_quantized.tflite', 'wb') as f:
    f.write(quantized_tflite_model)
```

## 5. Techniky prořezávání modelů

Prořezávání odstraňuje nepotřebné parametry z modelů hlubokého učení nastavením vah, které málo přispívají k výstupu, na nulu. To snižuje velikost modelu a může zlepšit výpočetní efektivitu.

### Prořezávání dle velikosti vah

```python
# Příklad prořezávání v TensorFlow
import tensorflow as tf
import tensorflow_model_optimization as tfmot

# Vytvoření jednoduchého modelu
def create_model():
    model = tf.keras.Sequential([
        tf.keras.layers.Dense(128, activation='relu', input_shape=(784,)),
        tf.keras.layers.Dense(64, activation='relu'),
        tf.keras.layers.Dense(10)
    ])
    return model

# Načtení datasetu MNIST
mnist = tf.keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0
x_train = x_train.reshape(-1, 784).astype('float32')
x_test = x_test.reshape(-1, 784).astype('float32')

# Definice parametrů prořezávání
pruning_params = {
    'pruning_schedule': tfmot.sparsity.keras.PolynomialDecay(
        initial_sparsity=0.0,
        final_sparsity=0.50,
        begin_step=0,
        end_step=1000
    )
}

# Vytvoření a kompilace základního modelu
model = create_model()

# Aplikace prořezávání
pruned_model = tfmot.sparsity.keras.prune_low_magnitude(model, **pruning_params)

# Kompilace prořezaného modelu
pruned_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

# Vytvoření callbacků pro prořezávání
callbacks = [
    tfmot.sparsity.keras.UpdatePruningStep(),
    tfmot.sparsity.keras.PruningSummaries(log_dir='logs'),
]

# Trénink prořezaného modelu
pruned_model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=2,
    validation_data=(x_test, y_test),
    callbacks=callbacks
)

# Konverze na plně kvantizovaný model TF Lite
converter = tf.lite.TFLiteConverter.from_keras_model(pruned_model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
pruned_quantized_tflite_model = converter.convert()

# Uložení modelu
with open('mnist_pruned_quantized.tflite', 'wb') as f:
    f.write(pruned_quantized_tflite_model)

# Vyhodnocení modelů
original_model = create_model()
original_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

original_model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=2,
    validation_data=(x_test, y_test)
)

print("Přesnost původního modelu:", original_model.evaluate(x_test, y_test)[1])
print("Přesnost prořezaného modelu:", pruned_model.evaluate(x_test, y_test)[1])
```

### Příklad prořezávání v PyTorch

```python
# Příklad prořezávání v PyTorch
import torch
import torch.nn as nn
import torch.optim as optim
import torchvision
import torchvision.transforms as transforms

# Definice jednoduchého modelu
class SimpleNet(nn.Module):
    def __init__(self):
        super(SimpleNet, self).__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        
    def forward(self, x):
        x = x.view(-1, 784)
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        x = self.fc3(x)
        return x

# Vytvoření modelu
model = SimpleNet()

# Funkce pro aplikaci prořezávání dle velikosti vah
def prune_model(model, pruning_percent):
    # Získání všech vah
    weights = []
    for name, param in model.named_parameters():
        if 'weight' in name:
            tensor = param.data.cpu().numpy()
            weights.extend(np.abs(tensor.flatten()))
    
    # Určení prahu prořezávání
    threshold = np.percentile(weights, pruning_percent)
    
    # Aplikace prořezávání
    for name, param in model.named_parameters():
        if 'weight' in name:
            mask = torch.abs(param.data) > threshold
            param.data = param.data * mask
    
    return model

# Aplikace 50% prořezávání
pruned_model = prune_model(model, 50)

# Počet nenulových parametrů před a po prořezávání
def count_parameters(model):
    total_params = 0
    non_zero_params = 0
    for param in model.parameters():
        total_params += param.numel()
        non_zero_params += (param != 0).sum().item()
    return total_params, non_zero_params

total, non_zero = count_parameters(pruned_model)
print(f"Celkový počet parametrů: {total}")
print(f"Počet nenulových parametrů: {non_zero}")
print(f"Kompresní poměr: {total/max(1, non_zero):.2f}x")
print(f"Řídkost: {(total-non_zero)/total*100:.2f}%")
```

## 6. Destilace znalostí

Destilace znalostí přenáší znalosti z velkého "učitelského" modelu do menšího "žákovského" modelu. Žákovský model se učí napodobovat výstupní rozdělení učitele, nejen předpovídanou třídu.

```python
# Destilace znalostí s TensorFlow
import tensorflow as tf
import numpy as np

# Parametr teploty pro změkčení pravděpodobnostních rozdělení
temperature = 3.0

# Definice ztrátové funkce pro destilaci znalostí
def knowledge_distillation_loss(y_true, y_pred, teacher_logits, temperature, alpha=0.1):
    # Standardní cross-entropy ztráta
    student_loss = tf.keras.losses.sparse_categorical_crossentropy(
        y_true, y_pred, from_logits=True)
    
    # Měkké cíle od učitele (se škálováním teploty)
    teacher_probs = tf.nn.softmax(teacher_logits / temperature)
    student_probs = tf.nn.softmax(y_pred / temperature)
    
    # KL divergence ztráta
    distillation_loss = tf.keras.losses.kullback_leibler_divergence(
        teacher_probs, student_probs) * (temperature ** 2)
    
    # Kombinace ztrát
    return alpha * student_loss + (1 - alpha) * distillation_loss

# Vytvoření učitelského modelu (velký model)
teacher_model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(32, 3, activation='relu', input_shape=(28, 28, 1)),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Conv2D(64, 3, activation='relu'),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(256, activation='relu'),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10)
])

# Vytvoření žákovského modelu (menší model)
student_model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(16, 3, activation='relu', input_shape=(28, 28, 1)),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(10)
])

# Načtení MNIST datasetu
mnist = tf.keras.datasets.mnist
(x_train, y_train), (x_test, y_test) = mnist.load_data()
x_train, x_test = x_train / 255.0, x_test / 255.0
x_train = x_train[..., tf.newaxis]
x_test = x_test[..., tf.newaxis]

# Kompilace a trénink učitelského modelu
teacher_model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy']
)

teacher_model.fit(x_train, y_train, epochs=2, validation_data=(x_test, y_test))

# Získání predikcí učitele na trénovacích datech
teacher_logits = teacher_model.predict(x_train)

# Vlastní trénovací smyčka pro žákovský model s destilací znalostí
student_optimizer = tf.keras.optimizers.Adam()

# Vlastní trénovací krok
@tf.function
def train_step(images, labels, teacher_preds):
    with tf.GradientTape() as tape:
        # Dopředný průchod
        student_logits = student_model(images, training=True)
        
        # Výpočet ztráty
        loss = knowledge_distillation_loss(
            labels, student_logits, teacher_preds, temperature)
    
    # Výpočet gradientů
    gradients = tape.gradient(loss, student_model.trainable_variables)
    
    # Aplikace gradientů
    student_optimizer.apply_gradients(zip(gradients, student_model.trainable_variables))
    return loss

# Trénovací smyčka s destilací
batch_size = 128
train_dataset = tf.data.Dataset.from_tensor_slices(
    (x_train, y_train, teacher_logits)).shuffle(10000).batch(batch_size)

for epoch in range(2):
    epoch_loss_avg = tf.keras.metrics.Mean()
    
    for images, labels, teacher_preds in train_dataset:
        loss = train_step(images, labels, teacher_preds)
        epoch_loss_avg.update_state(loss)
    
    print(f"Epocha {epoch+1}, Ztráta: {epoch_loss_avg.result().numpy():.4f}")

# Vyhodnocení modelů
teacher_accuracy = teacher_model.evaluate(x_test, y_test)[1]
student_model.compile(metrics=['accuracy'])
student_accuracy = student_model.evaluate(x_test, y_test)[1]

print(f"Přesnost učitelského modelu: {teacher_accuracy:.4f}")
print(f"Přesnost žákovského modelu: {student_accuracy:.4f}")
print(f"Velikost učitelského modelu: {teacher_model.count_params()} parametrů")
print(f"Velikost žákovského modelu: {student_model.count_params()} parametrů")
print(f"Zmenšení velikosti: {teacher_model.count_params() / student_model.count_params():.2f}x")
```

## 7. Faktorizace s nízkým rankem

Faktorizace s nízkým rankem rozkládá váhové matice na součiny menších matic, čímž snižuje celkový počet parametrů.

```python
# Příklad faktorizace s nízkým rankem v PyTorch
import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np

# Definice velké plně propojené vrstvy
class LargeLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super(LargeLayer, self).__init__()
        self.fc = nn.Linear(in_features, out_features)
    
    def forward(self, x):
        return self.fc(x)

# Definice faktorizované verze vrstvy s nízkým rankem
class FactorizedLayer(nn.Module):
    def __init__(self, in_features, out_features, rank):
        super(FactorizedLayer, self).__init__()
        self.fc1 = nn.Linear(in_features, rank, bias=False)
        self.fc2 = nn.Linear(rank, out_features)
    
    def forward(self, x):
        x = self.fc1(x)
        x = self.fc2(x)
        return x

# Vytvoření ukázkových modelů
in_features, out_features = 1000, 1000
rank = 100

large_model = LargeLayer(in_features, out_features)
factorized_model = FactorizedLayer(in_features, out_features, rank)

# Počet parametrů
large_params = sum(p.numel() for p in large_model.parameters())
factorized_params = sum(p.numel() for p in factorized_model.parameters())

print(f"Parametry původního modelu: {large_params}")
print(f"Parametry faktorizovaného modelu: {factorized_params}")
print(f"Kompresní poměr: {large_params / factorized_params:.2f}x")

# Vytvoření náhodného vstupu
x = torch.randn(1, in_features)

# Aplikace SVD pro aproximaci původní váhové matice
with torch.no_grad():
    W = large_model.fc.weight.data
    U, S, V = torch.svd(W)
    
    # Ponechání pouze rank největších singulárních hodnot
    U_reduced = U[:, :rank]
    S_reduced = torch.diag(S[:rank])
    V_reduced = V[:, :rank]
    
    # Nastavení vah faktorizovaných vrstev
    factorized_model.fc1.weight.data = torch.matmul(V_reduced, torch.sqrt(S_reduced)).t()
    factorized_model.fc2.weight.data = torch.matmul(U_reduced, torch.sqrt(S_reduced))
    factorized_model.fc2.bias.data = large_model.fc.bias.data.clone()

# Porovnání výstupů
with torch.no_grad():
    out_original = large_model(x)
    out_factorized = factorized_model(x)
    
    # Výpočet chyby aproximace
    error = torch.norm(out_original - out_factorized) / torch.norm(out_original)
    print(f"Relativní chyba aproximace: {error.item():.6f}")
```

## 8. Hardwarově specifické optimalizace

Různé hardwarové platformy mají specifické optimalizace pro modely hlubokého učení. Přizpůsobení vaší strategie komprese cílovému hardwaru může přinést významná zlepšení.

```python
# TensorFlow Lite pro mobilní zařízení
import tensorflow as tf

# Načtení předtrénovaného modelu
model = tf.keras.applications.MobileNetV2(
    input_shape=(224, 224, 3),
    include_top=True,
    weights='imagenet'
)

# Konverze do TensorFlow Lite s různými nastaveními optimalizace

# 1. Výchozí optimalizace
```

### PyTorch kvantizace a prořezávání

```python
# PyTorch kombinované techniky komprese
import torch
import torch.nn as nn
import torch.quantization

# Definice jednoduchého modelu
class SimpleModel(nn.Module):
    def __init__(self):
        super(SimpleModel, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, padding=1)
        self.relu1 = nn.ReLU()
        self.maxpool = nn.MaxPool2d(2)
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)
        self.relu2 = nn.ReLU()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(64 * 14 * 14, 128)
        self.relu3 = nn.ReLU()
        self.fc2 = nn.Linear(128, 10)
        
    def forward(self, x):
        x = self.relu1(self.conv1(x))
        x = self.maxpool(x)
        x = self.relu2(self.conv2(x))
        x = self.flatten(x)
        x = self.relu3(self.fc1(x))
        x = self.fc2(x)
        return x

# Vytvoření instance modelu
model = SimpleModel()

# Aplikace prořezávání
import torch.nn.utils.prune as prune

# Aplikace L1 nestrukturovaného prořezávání na všechny konvoluční a lineární vrstvy
for name, module in model.named_modules():
    if isinstance(module, torch.nn.Conv2d) or isinstance(module, torch.nn.Linear):
        prune.l1_unstructured(module, name='weight', amount=0.3)

# Permanentní aplikace prořezávání
for name, module in model.named_modules():
    if isinstance(module, torch.nn.Conv2d) or isinstance(module, torch.nn.Linear):
        prune.remove(module, 'weight')

# Příprava modelu pro kvantizaci
class QuantizedModel(nn.Module):
    def __init__(self, model):
        super(QuantizedModel, self).__init__()
        self.quant = torch.quantization.QuantStub()
        self.model = model
        self.dequant = torch.quantization.DeQuantStub()
        
    def forward(self, x):
        x = self.quant(x)
        x = self.model(x)
        x = self.dequant(x)
        return x

# Sloučení vrstev pro lepší kvantizaci
def fuse_model(model):
    for m in model.modules():
        if type(m) == nn.Sequential:
            for i, module in enumerate(m):
                if type(module) == nn.Conv2d and i < len(m) - 1 and type(m[i + 1]) == nn.ReLU:
                    torch.quantization.fuse_modules(m, [str(i), str(i + 1)], inplace=True)
    return model

# Aplikace konfigurace kvantizace
quantized_model = QuantizedModel(model)
quantized_model.qconfig = torch.quantization.get_default_qconfig('fbgemm')
torch.quantization.prepare(quantized_model, inplace=True)

# Kalibrace se vzorkovými daty
with torch.no_grad():
    for _ in range(100):
        x = torch.randn(1, 1, 28, 28)
        quantized_model(x)

# Konverze na kvantizovaný model
torch.quantization.convert(quantized_model, inplace=True)

# Uložení obou modelů
torch.save(model.state_dict(), 'original_model.pth')
torch.save(quantized_model.state_dict(), 'compressed_model.pth')

# Porovnání velikostí modelů
orig_size = os.path.getsize('original_model.pth') / (1024 * 1024)
comp_size = os.path.getsize('compressed_model.pth') / (1024 * 1024)

print(f"Velikost původního modelu: {orig_size:.2f} MB")
print(f"Velikost komprimovaného modelu: {comp_size:.2f} MB")
print(f"Kompresní poměr: {orig_size / comp_size:.2f}x")
```

## 10. Shrnutí a osvědčené postupy

Komprese modelů je klíčová pro nasazování modelů hlubokého učení v prostředích s omezenými zdroji. Probrali jsme:

1. **Kvantizace**:
   - Kvantizace po tréninku je nejjednodušší, ale méně přesná
   - Trénování s vědomím kvantizace poskytuje lepší přesnost, ale vyžaduje více úsilí
   - INT8 kvantizace typicky nabízí dobrou rovnováhu mezi přesností a velikostí

2. **Prořezávání**:
   - Snižuje velikost modelu odstraněním nepodstatných spojení
   - Může být strukturované (odstraňování celých filtrů) nebo nestrukturované (nulování jednotlivých vah)
   - Často funguje dobře s kvantizací pro kombinované přínosy

3. **Destilace znalostí**:
   - Přenáší znalosti z větších na menší modely
   - Užitečná při návrhu kompaktních architektur od základu
   - Lze kombinovat s dalšími technikami komprese

4. **Faktorizace s nízkým rankem**:
   - Rozkládá váhové matice pro snížení počtu parametrů
   - Vhodná pro plně propojené vrstvy s mnoha parametry
   - Často se používají techniky faktorizace matic jako SVD

### Osvědčené postupy

1. **Zvolte správnou techniku pro vaše omezení**: Zvažte paměť, výpočetní výkon a energetická omezení cílového zařízení.

2. **Důkladně testujte**: Vždy měřte přesnost, velikost a rychlost inference na vašem cílovém hardwaru.

3. **Zvažte kombinaci technik**: Často použití prořezávání + kvantizace + destilace může přinést lepší výsledky než jakýkoli jednotlivý přístup.

4. **Začněte s architekturami navrženými pro efektivitu**: MobileNet, EfficientNet a SqueezeNet jsou již optimalizované pro mobilní/okrajová zařízení.

5. **Použijte nástroje specifické pro framework**: TensorFlow Lite, PyTorch Mobile a ONNX Runtime poskytují optimalizované runtime.

6. **Profilujte před kompresí**: Identifikujte úzká místa ve vašem modelu pro cílení konkrétních vrstev ke kompresi.

7. **Použijte hardwarově specifické optimalizace**: Různé hardwarové platformy (CPU, GPU, TPU, NPU) těží z různých optimalizací.

8. **Testujte na reálných datech**: Ujistěte se, že komprimovaný model dobře funguje na reálných vstupech, nejen na benchmarkových datasetech.
