## Co je hluboké učení?

Hluboké učení (Deep Learning, DL) je podmnožina strojového učení, která využívá neuronové sítě s mnoha vrstvami (hluboké neuronové sítě) k analýze různých forem dat. Algoritmy hlubokého učení se učí reprezentace dat na různých úrovních abstrakce, čímž vytvářejí hierarchii konceptů.

Hluboké učení způsobilo revoluci v mnoha oblastech včetně:
- Počítačového vidění
- Zpracování přirozeného jazyka
- Rozpoznávání řeči
- Autonomních vozidel
- Lékařské diagnostiky
- Umělé inteligence pro hraní her

## Klíčová terminologie

### Neuronové sítě
**Neuronové sítě** jsou výpočetní systémy inspirované biologickými neuronovými sítěmi v mozcích živočichů. Skládají se z propojených uzlů (neuronů), které se mohou učit z dat.

### Neuron/uzel
**Neuron** je základní výpočetní jednotka neuronové sítě. Přijímá vstupy, aplikuje váhy, přidává bias a předává výsledek přes aktivační funkci.

### Vrstvy
**Vrstvy** jsou skupiny neuronů, které zpracovávají informace v jednotlivých fázích:
- **Vstupní vrstva**: Přijímá surová data
- **Skryté vrstvy**: Zpracovávají data prostřednictvím vážených spojení
- **Výstupní vrstva**: Produkuje konečný výsledek

### Váhy a biasy
**Váhy** určují sílu spojení mezi neurony, zatímco **biasy** jsou dodatečné parametry, které pomáhají modelu lépe se přizpůsobit datům.

### Aktivační funkce
**Aktivační funkce** zavádějí do sítě nelinearitu, což umožňuje učit se složité vzory. Běžné příklady zahrnují ReLU, Sigmoid a Tanh.

### Dopředné šíření
**Dopředné šíření** (Forward Propagation) je proces průchodu dat sítí od vstupu k výstupu za účelem vytvoření předpovědi.

### Zpětné šíření
**Zpětné šíření** (Backpropagation) je algoritmus používaný k výpočtu gradientů a aktualizaci vah během tréninku, na základě chyby v předpovědích.

### Ztrátová funkce
**Ztrátová funkce** měří, jak daleko jsou předpovědi modelu od skutečných hodnot, a tak usměrňuje proces učení.

### Epocha
**Epocha** je jeden úplný průchod celým tréninkovým datasetem.

### Dávka
**Dávka** (Batch) je podmnožina tréninkových dat použitá v jedné iteraci trénování modelu.

```python
# Vizualizace klíčových komponent hlubokého učení
import numpy as np
import matplotlib.pyplot as plt

# Jednoduchá reprezentace neuronu
def neuron(x, weights, bias, activation_function):
    """Základní výpočet neuronu"""
    z = np.dot(weights, x) + bias
    return activation_function(z)

# Běžné aktivační funkce
def relu(x):
    """ReLU aktivační funkce"""
    return np.maximum(0, x)

def sigmoid(x):
    """Sigmoid aktivační funkce"""
    return 1 / (1 + np.exp(-x))

def tanh(x):
    """Tanh aktivační funkce"""
    return np.tanh(x)

# Vykreslení aktivačních funkcí
x = np.linspace(-5, 5, 100)
plt.figure(figsize=(10, 6))
plt.plot(x, relu(x), label='ReLU')
plt.plot(x, sigmoid(x), label='Sigmoid')
plt.plot(x, tanh(x), label='Tanh')
plt.grid(True)
plt.legend()
plt.title('Běžné aktivační funkce')
plt.xlabel('Vstup')
plt.ylabel('Výstup')
plt.axhline(y=0, color='k', linestyle='-', alpha=0.3)
plt.axvline(x=0, color='k', linestyle='-', alpha=0.3)
plt.show()
```

## Základy neuronových sítí

Neuronová síť transformuje vstupní data na smysluplný výstup prostřednictvím vrstev propojených neuronů. Každé spojení má váhu a každý neuron má bias. Síť se "učí" úpravou těchto vah a biasů během tréninku.

### Matematika za neuronem

1. Neuron přijímá vstupy (x₁, x₂, ..., xₙ)
2. Každý vstup je násoben váhou (w₁, w₂, ..., wₙ)
3. Vážené vstupy jsou sečteny spolu s biasem: z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
4. Tento součet prochází aktivační funkcí: a = f(z)

```python
import numpy as np

# Příklad výpočtu jednoduchého neuronu
def simple_neuron(x, w, b, activation_function):
    """
    x: vstupní pole
    w: pole vah
    b: bias
    activation_function: aplikovaná funkce
    """
    z = np.dot(w, x) + b
    return activation_function(z)

# Příklad použití
inputs = np.array([1.0, 2.0, 3.0])
weights = np.array([0.2, 0.8, -0.5])
bias = 2.0

# Výpočet výstupu pomocí ReLU aktivace
output = simple_neuron(inputs, weights, bias, relu)
print(f"Výstup neuronu: {output}")
```

## Hluboké učení vs. strojové učení

Ačkoliv každé hluboké učení je strojovým učením, ne každé strojové učení je hlubokým učením:

| Strojové učení | Hluboké učení |
|----------------|---------------|
| Často vyžaduje ruční extrakci příznaků | Automaticky se učí příznaky |
| Funguje dobře s malými až středními daty | Typicky vyžaduje velké množství dat |
| Obecně lépe interpretovatelné | Často považováno za "černou skříňku" |
| Rychlejší trénink | Výpočetně náročné |
| Zahrnuje algoritmy jako náhodné lesy, SVM | Založeno na neuronových sítích s mnoha vrstvami |

```python
# Konceptuální srovnání přístupu strojového a hlubokého učení
"""
# Tradiční pipeline strojového učení
vstupní_data -> [Extrakce příznaků] -> příznaky -> [ML algoritmus] -> předpověď

# Pipeline hlubokého učení
vstupní_data -> [Hluboká neuronová síť] -> předpověď
"""
```

## Typy neuronových sítí

### Dopředné neuronové sítě (FNN)
Nejjednodušší typ neuronové sítě, kde spojení mezi uzly nevytváří cykly. Informace se pohybuje pouze jedním směrem, od vstupu k výstupu.

### Konvoluční neuronové sítě (CNN)
Specializovány na zpracování dat podobných mřížce, jako jsou obrázky. Používají konvoluční operace k hierarchické extrakci příznaků.

### Rekurentní neuronové sítě (RNN)
Navrženy pro sekvenční data zachováváním paměti předchozích vstupů. Mají spojení, která tvoří cykly.

### Sítě s dlouhou krátkodobou pamětí (LSTM)
Speciální druh RNN navržený pro zapamatování dlouhodobých závislostí v sekvenčních datech.

### Generativní adversariální sítě (GAN)
Skládají se ze dvou sítí (generátor a diskriminátor), které soutěží proti sobě, což vede k generování nového obsahu.

### Transformery
Architektura využívající mechanismy sebepoznornosti (self-attention), způsobila revoluci v úlohách NLP.

```python
# Konceptuální reprezentace různých typů neuronových sítí
"""
FNN: x -> [Vrstva 1] -> [Vrstva 2] -> ... -> [Vrstva n] -> výstup

CNN: obrázek -> [Konvoluce] -> [Pooling] -> [Plně propojená] -> klasifikace

RNN: x₁ -> [RNN buňka] -> y₁
      ↑        ↓
     x₂ -> [RNN buňka] -> y₂
              ↓
            ...
"""
```

# PyTorch příklad
import torch
import torch.nn as nn

class SimpleNN(nn.Module):
    def __init__(self):
        super(SimpleNN, self).__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(64, 10)
        )
    
    def forward(self, x):
        x = self.flatten(x)
        logits = self.linear_relu_stack(x)
        return logits

## Vaše první neuronová síť

Pojďme sestavit jednoduchou neuronovou síť pro klasickou úlohu rozpoznávání číslic MNIST:

```python
# Kompletní příklad trénování neuronové sítě na datasetu MNIST
import tensorflow as tf

# Načtení datasetu MNIST
(x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()

# Předzpracování dat
x_train = x_train.reshape(-1, 28*28).astype('float32') / 255.0
x_test = x_test.reshape(-1, 28*28).astype('float32') / 255.0

# Vytvoření modelu
model = tf.keras.Sequential([
    tf.keras.layers.Dense(128, activation='relu', input_shape=(784,)),
    tf.keras.layers.Dropout(0.2),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dropout(0.2),
    tf.keras.layers.Dense(10, activation='softmax')
])

# Kompilace modelu
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# Přehled modelu
model.summary()

# Trénování modelu
history = model.fit(
    x_train, y_train,
    batch_size=32,
    epochs=5,
    validation_split=0.2
)

# Vyhodnocení modelu
test_loss, test_acc = model.evaluate(x_test, y_test)
print(f"Testovací přesnost: {test_acc:.3f}")

# Vizualizace historie trénování
import matplotlib.pyplot as plt

plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(history.history['accuracy'], label='Trénovací přesnost')
plt.plot(history.history['val_accuracy'], label='Validační přesnost')
plt.xlabel('Epocha')
plt.ylabel('Přesnost')
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(history.history['loss'], label='Trénovací ztráta')
plt.plot(history.history['val_loss'], label='Validační ztráta')
plt.xlabel('Epocha')
plt.ylabel('Ztráta')
plt.legend()
plt.show()
```

## Výzvy v hlubokém učení

Navzdory své síle čelí hluboké učení několika výzvám:

### Požadavky na data
Modely hlubokého učení typicky vyžadují velké množství označených dat, aby fungovaly dobře.

### Výpočetní zdroje
Trénování hlubokých sítí vyžaduje významný výpočetní výkon, často je nutné použití GPU nebo TPU.

### Přeučení
Komplexní modely si mohou zapamatovat trénovací data místo učení zobecnitelných vzorů.

### Interpretovatelnost
Modely hlubokého učení jsou často považovány za "černé skříňky" s omezenou vysvětlitelností.

### Ladění hyperparametrů
Hledání optimálních hyperparametrů může být časově náročné a nákladné na zdroje.

```python
# Příklad řešení přeučení pomocí regularizačních technik
from tensorflow.keras import layers, regularizers

def create_regularized_model():
    model = tf.keras.Sequential([
        layers.Dense(128, activation='relu', input_shape=(784,),
                   kernel_regularizer=regularizers.l2(0.001)),  # L2 regularizace
        layers.Dropout(0.3),  # Dropout pro regularizaci
        layers.Dense(64, activation='relu',
                   kernel_regularizer=regularizers.l2(0.001)),
        layers.Dropout(0.3),
        layers.Dense(10, activation='softmax')
    ])
    model.compile(optimizer='adam',
                  loss='sparse_categorical_crossentropy',
                  metrics=['accuracy'])
    return model
```
