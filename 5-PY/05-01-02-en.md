## 1. Introduction to Variables

Variables in Python are containers for storing data values. Unlike other programming languages, Python has no command for declaring a variable - a variable is created the moment you first assign a value to it.

```python
# Creating variables
name = "John"
age = 25
height = 1.75
is_student = True

# Printing variables
print(name)        # Output: John
print(age)         # Output: 25
print(height)      # Output: 1.75
print(is_student)  # Output: True

# Checking variable types
print(type(name))        # Output: <class 'str'>
print(type(age))         # Output: <class 'int'>
print(type(height))      # Output: <class 'float'>
print(type(is_student))  # Output: <class 'bool'>
```

### Variable Naming Rules

- Variable names can contain letters, numbers, and underscores
- Variable names must start with a letter or underscore
- Variable names are case-sensitive
- Variable names cannot be Python keywords

```python
# Valid variable names
my_var = 10
_my_var = 20
myVar = 30
MYVAR = 40
my_var_2 = 50

# Invalid variable names
# 2my_var = 60    # Cannot start with a number
# my-var = 70     # Cannot use hyphens
# my var = 80     # Cannot use spaces
# class = 90      # Cannot use reserved keywords
```

## 2. Numeric Data Types

Python has three main numeric data types:

### Integers (int)

Integers are whole numbers, positive or negative, without decimals.

```python
x = 10
y = -5
big_number = 12345678901234567890

print(x)           # Output: 10
print(y)           # Output: -5
print(big_number)  # Output: 12345678901234567890

# Integer operations
print(x + y)       # Output: 5
print(x * y)       # Output: -50
```

### Floating-point numbers (float)

Floats are numbers with decimal points.

```python
a = 3.14
b = -0.5
c = 2e3  # Scientific notation (2 × 10³)

print(a)      # Output: 3.14
print(b)      # Output: -0.5
print(c)      # Output: 2000.0

# Float operations
print(a + b)  # Output: 2.64
print(a * c)  # Output: 6280.0
```

### Complex numbers (complex)

Complex numbers have a real and imaginary part, represented as `a + bj`.

```python
z = 2 + 3j
w = 1 - 2j

print(z)         # Output: (2+3j)
print(z.real)    # Output: 2.0
print(z.imag)    # Output: 3.0
print(z + w)     # Output: (3+1j)
print(z * w)     # Output: (8-1j)
```

## 3. String Data Type

Strings in Python are sequences of characters enclosed in single quotes (`'`), double quotes (`"`), or triple quotes (`'''` or `"""`).

```python
# String creation
name = "Alice"
message = 'Hello, World!'
multi_line = """This is a
multi-line
string."""

print(name)       # Output: Alice
print(message)    # Output: Hello, World!
print(multi_line) # Output: This is a
                  #         multi-line
                  #         string.

# String indexing (0-based)
print(name[0])    # Output: A
print(name[-1])   # Output: e

# String slicing
print(name[1:3])  # Output: li
print(name[:2])   # Output: Al
print(name[2:])   # Output: ice

# String methods
print(name.upper())             # Output: ALICE
print(message.lower())          # Output: hello, world!
print(message.replace('H', 'J')) # Output: Jello, World!
print(len(name))                # Output: 5
```

## 4. Boolean Data Type

Booleans represent one of two values: `True` or `False`. They are often used in conditional testing.

```python
# Boolean variables
is_student = True
is_working = False

print(is_student)  # Output: True
print(is_working)  # Output: False

# Boolean operations
print(is_student and is_working)  # Output: False (logical AND)
print(is_student or is_working)   # Output: True (logical OR)
print(not is_student)             # Output: False (logical NOT)

# Boolean evaluation
print(bool(0))     # Output: False
print(bool(1))     # Output: True
print(bool(""))    # Output: False
print(bool("Hi"))  # Output: True
print(bool([]))    # Output: False
```

## 5. Type Conversion

Python allows you to convert between different data types.

```python
# Integer to other types
num = 10
print(float(num))  # Output: 10.0
print(str(num))    # Output: "10"
print(bool(num))   # Output: True

# Float to other types
pi = 3.14
print(int(pi))     # Output: 3 (truncates, doesn't round)
print(str(pi))     # Output: "3.14"

# String to numeric types
num_str = "25"
print(int(num_str))     # Output: 25
print(float(num_str))   # Output: 25.0

# Be careful with conversions!
# print(int("hello"))  # This would raise a ValueError
```

## 6. Basic Arithmetic Operations

Python supports the standard arithmetic operations.

```python
a = 10
b = 3

# Basic operations
print(a + b)    # Output: 13 (addition)
print(a - b)    # Output: 7 (subtraction)
print(a * b)    # Output: 30 (multiplication)
print(a / b)    # Output: 3.3333... (division, always returns float)
print(a // b)   # Output: 3 (floor division, integer result)
print(a % b)    # Output: 1 (modulus, remainder)
print(a ** b)   # Output: 1000 (exponentiation: 10³)

# Augmented assignment
c = 5
c += 2   # Equivalent to c = c + 2
print(c)  # Output: 7

c -= 1   # Equivalent to c = c - 1
print(c)  # Output: 6

c *= 3   # Equivalent to c = c * 3
print(c)  # Output: 18

c /= 6   # Equivalent to c = c / 6
print(c)  # Output: 3.0
```

## 7. Comparison and Logical Operations

Comparison operators are used to compare values, while logical operators combine boolean expressions.

```python
x = 5
y = 10

# Comparison operators
print(x == y)   # Output: False (equal to)
print(x != y)   # Output: True (not equal to)
print(x < y)    # Output: True (less than)
print(x > y)    # Output: False (greater than)
print(x <= y)   # Output: True (less than or equal to)
print(x >= y)   # Output: False (greater than or equal to)

# Logical operators
a = True
b = False

print(a and b)  # Output: False (True if both are True)
print(a or b)   # Output: True (True if at least one is True)
print(not a)    # Output: False (inverts the value)

# Combining comparisons
age = 25
has_id = True
print(age >= 21 and has_id)  # Output: True (can buy alcohol in the US)
```

## 8. Variable Assignment Techniques

Python offers several ways to assign values to variables.

```python
# Multiple assignment
a, b, c = 1, 2, 3
print(a, b, c)  # Output: 1 2 3

# Swapping variables
x = 5
y = 10
x, y = y, x
print(x, y)     # Output: 10 5

# Unpacking sequences
coordinates = (3, 4)
x, y = coordinates
print(x, y)     # Output: 3 4

# Unpacking with * (for lists/tuples)
first, *middle, last = [1, 2, 3, 4, 5]
print(first)    # Output: 1
print(middle)   # Output: [2, 3, 4]
print(last)     # Output: 5
```

## 9. Built-in Functions for Data Types

Python provides many built-in functions to work with data types.

```python
# Numeric functions
print(abs(-5))        # Output: 5 (absolute value)
print(max(1, 3, 5))   # Output: 5 (maximum value)
print(min(1, 3, 5))   # Output: 1 (minimum value)
print(pow(2, 3))      # Output: 8 (power: 2³)
print(round(3.75, 1)) # Output: 3.8 (round to 1 decimal place)

# Type checking
print(isinstance(5, int))        # Output: True
print(isinstance("hello", str))  # Output: True
print(isinstance(3.14, float))   # Output: True

# String functions
greeting = "hello world"
print(greeting.capitalize())  # Output: Hello world
print(greeting.title())       # Output: Hello World
print(greeting.count('l'))    # Output: 3 (count occurrences)
print(greeting.find('o'))     # Output: 4 (find first occurrence)
```
