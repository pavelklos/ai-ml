## 1. Introduction to Object-Oriented Programming

Object-Oriented Programming (OOP) is a programming paradigm based on the concept of "objects", which can contain data (attributes) and code (methods). OOP allows for organizing code into reusable patterns, making it easier to maintain and extend large programs. Python is a multi-paradigm language that fully supports OOP principles.

Core concepts in OOP include:
- **Classes**: Blueprints for creating objects
- **Objects**: Instances of classes
- **Attributes**: Data stored inside objects
- **Methods**: Functions that define object behaviors
- **Inheritance**: Mechanism for code reuse
- **Encapsulation**: Hiding implementation details
- **Polymorphism**: Objects of different types responding to the same method

```python
# OOP allows us to model real-world concepts in code
# For example, we might represent a car as:

class Car:
    # Attributes (data)
    color = "red"
    brand = "Toyota"
    
    # Methods (behavior)
    def drive(self):
        print("The car is moving!")
    
    def honk(self):
        print("Beep beep!")

# Creating an object from the Car class
my_car = Car()

# Using the object
print(f"My {my_car.color} {my_car.brand} is nice!")  # Output: My red Toyota is nice!
my_car.drive()  # Output: The car is moving!
my_car.honk()   # Output: Beep beep!
```

## 2. Creating Classes and Objects

A class is defined using the `class` keyword, followed by the class name (conventionally using CamelCase) and a colon. The class body contains attributes and methods. Objects (instances) are created by calling the class name as if it were a function.

```python
# Defining a simple class
class Person:
    # Class body - define attributes and methods here
    pass  # 'pass' is a placeholder that does nothing

# Creating objects (instances) of the class
person1 = Person()  # First instance
person2 = Person()  # Second instance

# Each instance is a separate object
print(person1)  # Output: <__main__.Person object at 0x...>
print(person2)  # Output: <__main__.Person object at 0x...>
print(person1 is person2)  # Output: False

# Adding attributes to individual objects
person1.name = "Alice"
person1.age = 30

person2.name = "Bob"
person2.age = 25

# Accessing attributes
print(f"{person1.name} is {person1.age} years old.")  # Output: Alice is 30 years old.
print(f"{person2.name} is {person2.age} years old.")  # Output: Bob is 25 years old.
```

## 3. Attributes and Instance Variables

Attributes are variables that store data within a class or object. There are two main types:
- **Class attributes**: Defined within the class but outside any methods, shared by all instances
- **Instance attributes**: Specific to each instance, typically defined in the `__init__` method

```python
class Student:
    # Class attribute - shared by all instances
    school_name = "Python High School"
    
    def __init__(self, name, grade):
        # Instance attributes - unique to each instance
        self.name = name
        self.grade = grade

# Creating student objects
student1 = Student("Alice", 10)
student2 = Student("Bob", 9)

# Access instance attributes
print(f"{student1.name} is in grade {student1.grade}")  # Output: Alice is in grade 10
print(f"{student2.name} is in grade {student2.grade}")  # Output: Bob is in grade 9

# Access class attribute (shared)
print(f"Both students attend {Student.school_name}")  # Output: Both students attend Python High School
print(f"{student1.name} attends {student1.school_name}")  # Output: Alice attends Python High School
print(f"{student2.name} attends {student2.school_name}")  # Output: Bob attends Python High School

# Modifying class attribute affects all instances
Student.school_name = "Python Advanced Academy"
print(f"School name changed to {Student.school_name}")
print(f"{student1.name} now attends {student1.school_name}")  # Output: Alice now attends Python Advanced Academy
print(f"{student2.name} now attends {student2.school_name}")  # Output: Bob now attends Python Advanced Academy

# Modifying instance attribute affects only that instance
student1.school_name = "Special Program"
print(f"{student1.name} attends {student1.school_name}")  # Output: Alice attends Special Program
print(f"{student2.name} attends {student2.school_name}")  # Output: Bob attends Python Advanced Academy
```

## 4. Methods and Behaviors

Methods are functions defined within a class that describe the behaviors of the objects. The first parameter of a method is always `self`, which refers to the instance the method is called on.

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
    
    # Instance method
    def deposit(self, amount):
        if amount > 0:
            self.balance += amount
            print(f"Deposited ${amount}. New balance: ${self.balance}")
        else:
            print("Deposit amount must be positive")
    
    # Instance method
    def withdraw(self, amount):
        if 0 < amount <= self.balance:
            self.balance -= amount
            print(f"Withdrew ${amount}. Remaining balance: ${self.balance}")
        elif amount > self.balance:
            print("Insufficient funds!")
        else:
            print("Withdrawal amount must be positive")
    
    # Instance method
    def check_balance(self):
        print(f"{self.owner}'s account balance: ${self.balance}")

# Create an account
account = BankAccount("Alice", 1000)

# Use methods to interact with the object
account.check_balance()  # Output: Alice's account balance: $1000
account.deposit(500)     # Output: Deposited $500. New balance: $1500
account.withdraw(200)    # Output: Withdrew $200. Remaining balance: $1300
account.withdraw(2000)   # Output: Insufficient funds!
account.check_balance()  # Output: Alice's account balance: $1300
```

## 5. Constructors and Initialization

The `__init__` method is a special method called when a new object is created. It's used to initialize the object's attributes. It's not strictly a constructor (Python actually uses `__new__` for that), but it's commonly referred to as a constructor because it serves a similar purpose.

```python
class Rectangle:
    def __init__(self, width, height):
        print("Creating a new Rectangle object...")
        # Initialize instance attributes
        self.width = width
        self.height = height
        self.area = width * height
    
    def describe(self):
        print(f"Rectangle: width={self.width}, height={self.height}, area={self.area}")
    
    def scale(self, factor):
        self.width *= factor
        self.height *= factor
        self.area = self.width * self.height
        print(f"Scaled by {factor}. New dimensions: {self.width}x{self.height}")

# Create rectangles
rect1 = Rectangle(5, 10)  # Output: Creating a new Rectangle object...
rect2 = Rectangle(3, 4)   # Output: Creating a new Rectangle object...

rect1.describe()  # Output: Rectangle: width=5, height=10, area=50
rect2.describe()  # Output: Rectangle: width=3, height=4, area=12

rect1.scale(2)    # Output: Scaled by 2. New dimensions: 10x20
rect1.describe()  # Output: Rectangle: width=10, height=20, area=200
```

## 6. Inheritance Basics

Inheritance allows a class to inherit attributes and methods from another class. The new class (subclass) can override or extend the functionality of the parent class (superclass).

```python
# Base class (parent class)
class Animal:
    def __init__(self, name, species):
        self.name = name
        self.species = species
    
    def make_sound(self):
        print("Some generic animal sound")
    
    def describe(self):
        print(f"{self.name} is a {self.species}")

# Derived class (child class)
class Dog(Animal):
    def __init__(self, name, breed):
        # Call the parent class's __init__ method
        super().__init__(name, species="Dog")
        self.breed = breed
    
    # Override parent method
    def make_sound(self):
        print("Woof!")
    
    # Add new method
    def wag_tail(self):
        print(f"{self.name} wags tail happily")

# Derived class (another child class)
class Cat(Animal):
    def __init__(self, name, color):
        super().__init__(name, species="Cat")
        self.color = color
    
    def make_sound(self):
        print("Meow!")
    
    def purr(self):
        print(f"{self.name} purrs contentedly")

# Create instances
generic_animal = Animal("Generic", "Unknown")
dog = Dog("Buddy", "Golden Retriever")
cat = Cat("Whiskers", "Tabby")

# Call methods
generic_animal.describe()  # Output: Generic is a Unknown
generic_animal.make_sound()  # Output: Some generic animal sound

dog.describe()  # Output: Buddy is a Dog
print(f"Breed: {dog.breed}")  # Output: Breed: Golden Retriever
dog.make_sound()  # Output: Woof!
dog.wag_tail()  # Output: Buddy wags tail happily

cat.describe()  # Output: Whiskers is a Cat
print(f"Color: {cat.color}")  # Output: Color: Tabby
cat.make_sound()  # Output: Meow!
cat.purr()  # Output: Whiskers purrs contentedly
```

## 7. Encapsulation in Python

Encapsulation is the bundling of data and methods that operate on that data within a single unit (class). It also involves restricting direct access to some of an object's components. Python uses naming conventions for this purpose:

- `attribute`: Public (accessible from anywhere)
- `_attribute`: Protected (shouldn't be accessed outside the class, but it's just a convention)
- `__attribute`: Private (name mangling is applied, making it harder to access from outside)

```python
class Employee:
    def __init__(self, name, salary):
        self.name = name          # Public attribute
        self._salary = salary      # Protected attribute (convention)
        self.__bonus = 1000        # Private attribute (name mangling)
    
    def display_info(self):
        print(f"Name: {self.name}")
        print(f"Salary: ${self._salary}")
        print(f"Total compensation: ${self._salary + self.__bonus}")
    
    def _protected_method(self):
        print("This is a protected method")
    
    def __private_method(self):
        print("This is a private method")
    
    def call_private(self):
        # Private methods can be called from within the class
        self.__private_method()

# Create an employee
emp = Employee("Alice", 50000)

# Access public attribute
print(emp.name)  # Output: Alice

# Access protected attribute (possible, but not recommended)
print(emp._salary)  # Output: 50000

# Try to access private attribute (won't work as expected)
try:
    print(emp.__bonus)
except AttributeError as e:
    print(f"Error: {e}")  # Output: Error: 'Employee' object has no attribute '__bonus'

# Name mangling: Private attributes are stored with modified names
print(emp._Employee__bonus)  # Output: 1000 (not recommended, but possible)

emp.display_info()  # Output: Name: Alice, Salary: $50000, Total compensation: $51000

# Call protected method (possible, but not recommended)
emp._protected_method()  # Output: This is a protected method

# Try to call private method (won't work)
try:
    emp.__private_method()
except AttributeError as e:
    print(f"Error: {e}")  # Output: Error: 'Employee' object has no attribute '__private_method'

# Call private method through public interface
emp.call_private()  # Output: This is a private method
```

## 8. Special Methods (Magic Methods)

Python classes have special methods, also called "magic methods" or "dunder methods" (double underscore), that allow you to define how objects of your class behave with built-in functions and operators.

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    # String representation
    def __str__(self):
        return f"Vector({self.x}, {self.y})"
    
    # Developer-friendly representation
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"
    
    # Addition
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    
    # Subtraction
    def __sub__(self, other):
        return Vector(self.x - other.x, self.y - other.y)
    
    # Equality
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y
    
    # Length (magnitude)
    def __abs__(self):
        return (self.x**2 + self.y**2) ** 0.5
    
    # Make class iterable
    def __iter__(self):
        yield self.x
        yield self.y
    
    # Use object like a function
    def __call__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)

# Create vectors
v1 = Vector(2, 3)
v2 = Vector(5, 7)

# String representation
print(v1)  # Output: Vector(2, 3)
print(repr(v2))  # Output: Vector(5, 7)

# Addition
v3 = v1 + v2
print(v3)  # Output: Vector(7, 10)

# Subtraction
v4 = v2 - v1
print(v4)  # Output: Vector(3, 4)

# Equality
print(v1 == v2)  # Output: False
print(v1 == Vector(2, 3))  # Output: True

# Magnitude
print(abs(v1))  # Output: 3.605551275463989

# Iteration
x, y = v1
print(f"x: {x}, y: {y}")  # Output: x: 2, y: 3

# Calling object like a function
v5 = v1(3)  # Multiply by scalar
print(v5)  # Output: Vector(6, 9)
```
