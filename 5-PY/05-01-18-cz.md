## 1. Úvod do PEP 8

PEP 8 je příručka stylu pro Python kód, vytvořená Guidem van Rossumem, tvůrcem Pythonu. Poskytuje konvence kódování pro zajištění čitelnosti a konzistence napříč projekty v Pythonu. Dodržování PEP 8 činí váš kód více udržovatelným a srozumitelnějším pro ostatní.

```python
# Kód nevyhovující PEP 8
x=5;y=10
z=x+y
print('Součet je:'+str(z))

# Kód vyhovující PEP 8
x = 5
y = 10
z = x + y
print(f"Součet je: {z}")
```

## 3. Konvence pojmenování

PEP 8 poskytuje specifické konvence pojmenování pro různé typy identifikátorů, aby byl kód čitelnější a konzistentnější.

```python
# Názvy modulů: krátké, malá písmena s podtržítky v případě potřeby
import muj_modul

# Názvy tříd: CapWords (CamelCase)
class MojeTrida:
    pass

# Názvy funkcí a proměnných: malá písmena s podtržítky
def spocitej_prumer(prvni_cislo, druhe_cislo):
    return (prvni_cislo + druhe_cislo) / 2

# Konstanty: velká písmena s podtržítky
MAXIMALNI_ITERACE = 1000
HODNOTA_PI = 3.14159

# Chráněné členy: jedno úvodní podtržítko
_interni_promenna = "Není určeno pro přímý přístup"

# Soukromé členy: dvě úvodní podtržítka
__velmi_soukrome = "Jméno změněno Pythonem"

# Speciální metody: obklopeny dvojitými podtržítky
class SpecialniTrida:
    def __init__(self):
        self.hodnota = 42
        
    def __str__(self):
        return f"SpeciálníTřída s hodnotou: {self.hodnota}"
```

## 4. Komentáře a dokumentace

PEP 8 má pokyny pro komentáře a dokumentaci, aby byl kód srozumitelnější.

```python
# Toto je jednořádkový komentář - měl by být úplnými větami

"""Toto je dokumentační řetězec modulu.

Měl by začínat jednořádkovým shrnutím, pak prázdným řádkem,
následovaným podrobnějším popisem.
"""

def slozita_funkce(param1, param2):
    """Vypočítá něco důležitého.
    
    Args:
        param1: Popis prvního parametru
        param2: Popis druhého parametru
        
    Returns:
        Popis návratové hodnoty
    
    Raises:
        ValueError: Když jsou parametry neplatné
    """
    # Řádkové komentáře by měly být odděleny od kódu alespoň dvěma mezerami
    x = param1 + param2  # Sečti parametry
    
    # Blokové komentáře vysvětlují složité části kódu
    # Měly by mít stejné odsazení jako kód, který popisují
    # a každý řádek by měl začínat # a jednou mezerou
    if x < 0:
        raise ValueError("Parametry musí vést k kladné hodnotě")
        
    return x ** 2
```

## 7. Importy

PEP 8 specifikuje, jak by importy měly být organizovány a formátovány pro zlepšení čitelnosti a prevenci problémů.

```python
# Importy by měly být na samostatných řádcích
import os
import sys

# Ne: import os, sys

# Seskupte importy v následujícím pořadí s prázdným řádkem mezi skupinami:
# 1. Importy standardní knihovny
import os
import sys

# 2. Importy souvisejících knihoven třetích stran
import numpy as np
import pandas as pd

# 3. Importy specifické pro lokální aplikaci/knihovnu
from muj_balicek import modul1
from muj_balicek.podmodul import funkce2

# Absolutní importy jsou preferovány před relativními
from muj_balicek.modul import Trida  # Dobré
from .modul import Trida             # Méně preferované

# Hromadným importům by se mělo vyhnout
# Špatně: from math import *
# Dobře:
from math import sqrt, sin, cos

# Pro velmi dlouhé importy používejte závorky
from velmi_dlouhy_nazev_modulu import (
    funkce1, funkce2, funkce3,
    Trida1, Trida2, Trida3
)
```

## 8. Nástroje pro dodržování PEP 8

Různé nástroje vám mohou pomoci udržovat soulad s PEP 8 ve vašem kódu.

```python
# pycodestyle (dříve pep8) - nástroj příkazového řádku pro kontrolu vašeho kódu
# Instalace pomocí: pip install pycodestyle
# Použití z příkazového řádku:
# $ pycodestyle muj_soubor.py

# Příklad Python kódu pro programové spuštění pycodestyle
import pycodestyle

def zkontroluj_soulad_s_pep8(cesta_k_souboru):
    """Zkontroluje, zda soubor odpovídá PEP 8."""
    pruvodce_stylem = pycodestyle.StyleGuide()
    vysledek = pruvodce_stylem.check_files([cesta_k_souboru])
    
    if vysledek.total_errors == 0:
        print(f"{cesta_k_souboru} je v souladu s PEP 8!")
    else:
        print(f"{cesta_k_souboru} má {vysledek.total_errors} porušení PEP 8.")
    
    return vysledek.total_errors == 0

# Black - Nekompromisní formátovač kódu
# Instalace pomocí: pip install black
# Použití z příkazového řádku:
# $ black muj_soubor.py

# Flake8 - Kombinuje pycodestyle s dalšími kontrolami
# Instalace pomocí: pip install flake8
# Použití z příkazového řádku:
# $ flake8 muj_soubor.py
```

## 10. Shrnutí

Dodržování směrnic PEP 8 pomáhá vytvářet čistý, čitelný a konzistentní kód v Pythonu. Klíčové body zahrnují:

- Používejte 4 mezery pro odsazení (ne tabulátory)
- Omezte řádky na 79 znaků
- Používejte prázdné řádky k oddělení funkcí, tříd a logických sekcí
- Dodržujte konvence pojmenování: `mala_pismena_s_podtrzitky` pro proměnné a funkce, `CapWords` pro třídy
- Pište dokumentační řetězce a smysluplné komentáře
- Konzistentně používejte bílé znaky pro zlepšení čitelnosti
- Správně organizujte importy
- Používejte nástroje jako pycodestyle, black nebo flake8 pro kontrolu a vynucení souladu

Pamatujte, že čitelnost kódu je prvořadá. I když PEP 8 poskytuje vynikající směrnice, specifické potřeby projektu mohou někdy vyžadovat odchylky od těchto standardů. V takových případech je konzistence v rámci projektu důležitější než striktní dodržování PEP 8. Zen Pythonu říká: "Čitelnost se počítá."

```python
# Zen Pythonu
import this
```

PEP 8 by měl být vnímán jako průvodce, který pomáhá psát lepší Python kód, spíše než jako neměnná sada pravidel. Dodržování těchto konvencí učiní váš kód udržovatelnějším a přístupnějším pro Python komunitu.
