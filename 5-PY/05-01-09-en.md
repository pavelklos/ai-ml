## 1. Introduction to Functions

Functions are reusable blocks of code that perform specific tasks. They help organize code, improve readability, and reduce duplication. In Python, functions are first-class objects, which means they can be assigned to variables, passed as arguments, and returned from other functions.

```python
# Functions allow you to organize and reuse code
def greet():
    print("Hello, world!")

# Using a function multiple times
greet()  # Output: Hello, world!
greet()  # Output: Hello, world!

# Functions as objects
message_function = greet  # Assigning a function to a variable
message_function()  # Output: Hello, world!
```

## 2. Defining and Calling Functions

In Python, functions are defined using the `def` keyword, followed by the function name, parentheses, and a colon. The function body is indented below the definition line.

```python
# Basic function definition
def display_message():
    """This is a docstring that explains what the function does."""
    print("Learning about Python functions!")

# Calling the function
display_message()  # Output: Learning about Python functions!

# Functions with logic
def check_even(number):
    if number % 2 == 0:
        print(f"{number} is even.")
    else:
        print(f"{number} is odd.")

check_even(4)  # Output: 4 is even.
check_even(7)  # Output: 7 is odd.
```

## 3. Parameters and Arguments

Parameters are variables listed in the function definition, while arguments are the values passed to the function when it's called. Parameters serve as placeholders for the data that will be passed in.

```python
# Function with parameters
def greet_person(name, greeting="Hello"):
    """Greet a person with a customizable message."""
    print(f"{greeting}, {name}!")

# Passing arguments to parameters
greet_person("Alice")  # Output: Hello, Alice!
greet_person("Bob", "Hi")  # Output: Hi, Bob!

# Positional parameters must come before default parameters
def create_profile(name, age, occupation="Student"):
    profile = {
        "name": name,
        "age": age,
        "occupation": occupation
    }
    return profile

profile1 = create_profile("Carol", 25)
profile2 = create_profile("Dave", 30, "Engineer")
print(profile1)  # Output: {'name': 'Carol', 'age': 25, 'occupation': 'Student'}
print(profile2)  # Output: {'name': 'Dave', 'age': 30, 'occupation': 'Engineer'}
```

## 4. Return Values

Functions can send data back to the caller using the `return` statement. A function can return single values, multiple values, or no value at all (which implicitly returns `None`).

```python
# Function returning a single value
def square(number):
    """Return the square of a number."""
    return number ** 2

result = square(5)
print(result)  # Output: 25

# Function returning multiple values (as a tuple)
def get_dimensions():
    """Return width and height."""
    width = 100
    height = 50
    return width, height

dimensions = get_dimensions()
print(dimensions)  # Output: (100, 50)
print(type(dimensions))  # Output: <class 'tuple'>

# Unpacking returned values
width, height = get_dimensions()
print(f"Width: {width}, Height: {height}")  # Output: Width: 100, Height: 50

# Function with conditional returns
def absolute_value(number):
    """Return the absolute value of a number."""
    if number >= 0:
        return number
    else:
        return -number

print(absolute_value(5))   # Output: 5
print(absolute_value(-3))  # Output: 3
```

## 5. Default Parameter Values

Python allows you to specify default values for parameters. These values are used when the function is called without the corresponding argument.

```python
# Function with default parameter values
def power(base, exponent=2):
    """Return base raised to the given exponent."""
    return base ** exponent

# Using the default parameter
print(power(5))      # Output: 25 (5^2, using default exponent=2)
print(power(5, 3))   # Output: 125 (5^3, overriding the default)

# Multiple default parameters
def create_person(name, age=30, city="New York", job=None):
    """Create a dictionary representing a person."""
    person = {
        "name": name,
        "age": age,
        "city": city
    }
    if job:
        person["job"] = job
    return person

# Using different combinations of defaults
print(create_person("Eve"))
print(create_person("Frank", 25))
print(create_person("Grace", 28, "Boston"))
print(create_person("Hank", 35, "Chicago", "Developer"))

# Warning: Default values are created only once!
def add_to_list(item, my_list=[]):
    my_list.append(item)
    return my_list

print(add_to_list("apple"))  # Output: ['apple']
print(add_to_list("banana"))  # Output: ['apple', 'banana'] - careful!

# Better way: use None as default
def add_to_list_safe(item, my_list=None):
    if my_list is None:
        my_list = []
    my_list.append(item)
    return my_list

print(add_to_list_safe("apple"))    # Output: ['apple']
print(add_to_list_safe("banana"))   # Output: ['banana']
```

## 6. Keyword Arguments

Keyword arguments allow you to pass arguments to a function by parameter name rather than just by position. This makes function calls more readable and flexible.

```python
# Function with multiple parameters
def display_info(name, age, city):
    """Display personal information."""
    print(f"Name: {name}")
    print(f"Age: {age}")
    print(f"City: {city}")

# Using positional arguments
display_info("John", 25, "Boston")

# Using keyword arguments (can be in any order)
display_info(city="New York", name="Alice", age=30)

# Mixing positional and keyword arguments
# Positional arguments must come before keyword arguments
display_info("Bob", city="Chicago", age=35)

# This would cause an error:
# display_info(name="Charlie", 40, city="Denver")  # SyntaxError

# Function that forces keyword arguments with *
def calculate_total(*, price, tax_rate, discount=0):
    """Calculate total price after tax and discount."""
    subtotal = price * (1 - discount)
    total = subtotal * (1 + tax_rate)
    return total

# This must be called with keyword arguments
# calculate_total(100, 0.07)  # TypeError
print(calculate_total(price=100, tax_rate=0.07))  # Works
print(calculate_total(price=100, tax_rate=0.07, discount=0.1))  # Works
```

## 7. Variable-Length Arguments

Python provides special syntax for accepting variable numbers of arguments, allowing functions to be more flexible.

```python
# *args for variable number of positional arguments
def sum_all(*args):
    """Sum all arguments passed to the function."""
    total = 0
    for num in args:
        total += num
    return total

print(sum_all(1, 2))           # Output: 3
print(sum_all(1, 2, 3, 4, 5))  # Output: 15

# **kwargs for variable number of keyword arguments
def display_person_info(**kwargs):
    """Display all information provided about a person."""
    print("Person Information:")
    for key, value in kwargs.items():
        print(f"{key}: {value}")

display_person_info(name="Alice", age=30, job="Engineer", city="Boston")

# Combining all types of parameters
def create_report(title, *args, author="Unknown", **kwargs):
    """Create a report with variable content and metadata."""
    print(f"Report: {title}")
    print(f"By: {author}")
    print("Contents:")
    for i, item in enumerate(args, 1):
        print(f"  {i}. {item}")
    print("Additional Information:")
    for key, value in kwargs.items():
        print(f"  {key}: {value}")

create_report("Quarterly Results", 
              "Revenue increased by 10%", 
              "New product line launched",
              author="Finance Team",
              date="2023-04-15",
              confidentiality="High")

# Unpacking lists and dictionaries into function arguments
numbers = [1, 2, 3, 4, 5]
print(sum_all(*numbers))  # Unpacks list into separate arguments

person_data = {"name": "David", "age": 42, "job": "Scientist"}
display_person_info(**person_data)  # Unpacks dictionary into keyword arguments
```

## 8. Lambda Functions

Lambda functions (also called anonymous functions) are small, one-line functions defined with the `lambda` keyword. They're useful for short operations and can be used in places where a function object is expected.

```python
# Basic lambda function
square = lambda x: x ** 2
print(square(5))  # Output: 25

# Lambda with multiple parameters
add = lambda x, y: x + y
print(add(3, 4))  # Output: 7

# Lambda functions are commonly used with built-in functions like map, filter, and sorted
numbers = [1, 5, 3, 9, 2, 6]

# Using map with lambda to square all numbers
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # Output: [1, 25, 9, 81, 4, 36]

# Using filter with lambda to get only even numbers
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(even_numbers)  # Output: [2, 6]

# Using sorted with lambda as a key function
pairs = [(1, 'one'), (3, 'three'), (2, 'two')]
sorted_pairs = sorted(pairs, key=lambda pair: pair[1])  # Sort by the string
print(sorted_pairs)  # Output: [(1, 'one'), (3, 'three'), (2, 'two')]

# Quick conditional expression with lambda
get_status = lambda status: "Active" if status else "Inactive"
print(get_status(True))   # Output: Active
print(get_status(False))  # Output: Inactive
```

## 9. Function Scope

Variables defined inside a function are only accessible within that function (local scope), while variables defined outside functions are accessible from within functions (global scope).

```python
# Global and local scope
message = "Global message"  # Global variable

def show_message():
    message = "Local message"  # Local variable
    print("Inside function:", message)

show_message()  # Output: Inside function: Local message
print("Outside function:", message)  # Output: Outside function: Global message

# Using global variables inside functions
counter = 0

def increment():
    global counter  # Declare that we want to use the global variable
    counter += 1
    print(f"Counter: {counter}")

increment()  # Output: Counter: 1
increment()  # Output: Counter: 2

# Nested functions and enclosing scope
def outer_function(x):
    """Demonstrate nested functions and closures."""
    
    def inner_function(y):
        # inner_function can access variables from outer_function
        return x + y
    
    return inner_function  # Returns the inner function

# Creating a closure
add_five = outer_function(5)
print(add_five(3))  # Output: 8
print(add_five(7))  # Output: 12

# Use nonlocal to modify enclosing scope variables
def counter_function():
    count = 0
    
    def increment():
        nonlocal count  # Allows modifying count from the enclosing scope
        count += 1
        return count
    
    return increment

counter = counter_function()
print(counter())  # Output: 1
print(counter())  # Output: 2
print(counter())  # Output: 3
```
