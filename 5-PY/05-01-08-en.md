## 1. Introduction to Tuples

Tuples are ordered, immutable sequences in Python that can store multiple items of different data types. Unlike lists, once tuples are created, they cannot be modified. This immutability makes tuples useful for representing fixed collections of items where the order matters but the values shouldn't change.

```python
# Tuple example - an (x, y) coordinate
point = (10, 20)
print(point)  # Output: (10, 20)

# Tuple containing different data types
mixed_tuple = (1, "hello", 3.14, True)
print(mixed_tuple)  # Output: (1, 'hello', 3.14, True)

# Attempting to modify a tuple will raise an error
# point[0] = 5  # TypeError: 'tuple' object does not support item assignment
```

## 2. Creating and Accessing Tuples

Tuples can be created in several ways, with or without parentheses. You can access tuple elements using indexing, just like with lists.

```python
# Creating tuples
empty_tuple = ()
print(empty_tuple)  # Output: ()

# Tuple with one element needs a trailing comma
singleton = (42,)  # Without the comma, Python treats it as an integer in parentheses
print(singleton)    # Output: (42,)
print(type((42)))   # Output: <class 'int'>
print(type((42,)))  # Output: <class 'tuple'>

# Creating a tuple without parentheses
coordinates = 10, 20, 30
print(coordinates)  # Output: (10, 20, 30)

# Using the tuple() constructor
tuple_from_list = tuple([1, 2, 3])
tuple_from_string = tuple("Python")
print(tuple_from_list)    # Output: (1, 2, 3)
print(tuple_from_string)  # Output: ('P', 'y', 't', 'h', 'o', 'n')

# Accessing tuple elements
point = (10, 20, 30, 40)
print(point[0])    # Output: 10
print(point[2])    # Output: 30
print(point[-1])   # Output: 40 (last element)

# Slicing tuples
print(point[1:3])  # Output: (20, 30)
print(point[:2])   # Output: (10, 20)
print(point[2:])   # Output: (30, 40)
```

## 3. Tuple Operations and Methods

While tuples are immutable, you can still perform several operations and use built-in methods with them.

```python
# Concatenating tuples
tuple1 = (1, 2, 3)
tuple2 = (4, 5, 6)
combined = tuple1 + tuple2
print(combined)  # Output: (1, 2, 3, 4, 5, 6)

# Repeating tuples
repeated = tuple1 * 3
print(repeated)  # Output: (1, 2, 3, 1, 2, 3, 1, 2, 3)

# Checking membership
print(2 in tuple1)       # Output: True
print(5 not in tuple1)   # Output: True

# Tuple methods
numbers = (1, 2, 3, 2, 4, 2, 5)
print(numbers.count(2))  # Output: 3 (counts occurrences of 2)
print(numbers.index(4))  # Output: 4 (returns first index of 4)

# Finding length of a tuple
print(len(numbers))  # Output: 7

# Min and max values
print(min(numbers))  # Output: 1
print(max(numbers))  # Output: 5

# Converting between tuples and lists
my_list = list(numbers)
print(my_list)      # Output: [1, 2, 3, 2, 4, 2, 5]
back_to_tuple = tuple(my_list)
print(back_to_tuple)  # Output: (1, 2, 3, 2, 4, 2, 5)
```

## 4. Tuples vs Lists

Understanding when to use tuples versus lists is important for efficient Python programming.

```python
# Comparing tuples and lists

# Size comparison
import sys
my_list = [1, 2, 3, 4, 5]
my_tuple = (1, 2, 3, 4, 5)
print(f"List size: {sys.getsizeof(my_list)} bytes")
print(f"Tuple size: {sys.getsizeof(my_tuple)} bytes")
# Tuples typically use less memory

# Performance comparison
import timeit

# Creation speed
list_creation = timeit.timeit(stmt="[1, 2, 3, 4, 5]", number=1000000)
tuple_creation = timeit.timeit(stmt="(1, 2, 3, 4, 5)", number=1000000)
print(f"List creation time: {list_creation}")
print(f"Tuple creation time: {tuple_creation}")
# Tuples are typically faster to create

# When to use lists:
# - When you need a mutable sequence
mutable_collection = [1, 2, 3]
mutable_collection.append(4)  # Can modify lists

# When to use tuples:
# - For immutable data (values that shouldn't change)
# - For heterogeneous data (different types)
# - As dictionary keys (lists cannot be used as keys)
# - When you want to ensure data integrity
```

## 5. Tuple Packing and Unpacking

Tuple packing and unpacking are powerful features in Python that allow you to work with multiple values efficiently.

```python
# Tuple packing - combining values into a tuple
packed_tuple = 1, 2, 3
print(packed_tuple)  # Output: (1, 2, 3)

# Tuple unpacking - extracting values from a tuple
x, y, z = packed_tuple
print(x)  # Output: 1
print(y)  # Output: 2
print(z)  # Output: 3

# Unpacking specific values
person = ("John", "Doe", 30, "Software Engineer")
first_name, last_name, *other = person
print(first_name)  # Output: John
print(last_name)   # Output: Doe
print(other)       # Output: [30, 'Software Engineer']

# Using * to collect remaining items
*names, age, profession = person
print(names)       # Output: ['John', 'Doe']
print(age)         # Output: 30
print(profession)  # Output: Software Engineer

# Swapping variables using tuple unpacking
a, b = 10, 20
print(f"Before swap: a={a}, b={b}")
a, b = b, a  # Swapping using tuple packing and unpacking
print(f"After swap: a={a}, b={b}")
# Output: 
# Before swap: a=10, b=20
# After swap: a=20, b=10
```

## 6. Tuples as Dictionary Keys

One important feature of tuples is that they can be used as dictionary keys, unlike lists which are mutable.

```python
# Using tuples as dictionary keys
# This works because tuples are immutable and hashable
locations = {
    (40.7128, -74.0060): "New York",
    (34.0522, -118.2437): "Los Angeles",
    (51.5074, -0.1278): "London"
}

# Accessing values by tuple keys
print(locations[(40.7128, -74.0060)])  # Output: New York

# Adding a new location
locations[(48.8566, 2.3522)] = "Paris"

# Iterating through the dictionary
for coordinates, city in locations.items():
    print(f"{city}: {coordinates}")

# This would cause an error because lists cannot be used as dictionary keys
# error_dict = {[1, 2]: "This won't work"}  # TypeError: unhashable type: 'list'
```

## 7. Returning Multiple Values from Functions

Tuples provide a clean way to return multiple values from a function.

```python
# Returning multiple values from a function
def get_user_info():
    name = "Alice"
    age = 30
    email = "alice@example.com"
    return name, age, email  # Implicitly returns a tuple

# Collecting returned values
user = get_user_info()
print(user)  # Output: ('Alice', 30, 'alice@example.com')
print(type(user))  # Output: <class 'tuple'>

# Unpacking returned values directly
name, age, email = get_user_info()
print(f"Name: {name}")   # Output: Name: Alice
print(f"Age: {age}")     # Output: Age: 30
print(f"Email: {email}") # Output: Email: alice@example.com

# Function that performs calculations and returns multiple results
def calculate_statistics(numbers):
    total = sum(numbers)
    average = total / len(numbers)
    minimum = min(numbers)
    maximum = max(numbers)
    return total, average, minimum, maximum

# Using the returned statistics
data = [10, 15, 20, 25, 30]
stats = calculate_statistics(data)
print(f"Statistics: {stats}")

# Unpacking immediately
total, avg, min_val, max_val = calculate_statistics(data)
print(f"Total: {total}, Average: {avg}, Min: {min_val}, Max: {max_val}")
```

## 8. Named Tuples

Named tuples are an extension of regular tuples that allow you to access elements by name as well as by position.

```python
from collections import namedtuple

# Creating a named tuple type
Person = namedtuple('Person', ['name', 'age', 'job'])

# Creating instances of the named tuple
alice = Person(name="Alice", age=30, job="Engineer")
bob = Person("Bob", 25, "Designer")  # Positional arguments also work

# Accessing elements by name
print(alice.name)  # Output: Alice
print(alice.age)   # Output: 30
print(alice.job)   # Output: Engineer

# Accessing elements by index (like regular tuples)
print(alice[0])    # Output: Alice
print(alice[1])    # Output: 30

# Unpacking named tuples
name, age, job = bob
print(f"{name} is {age} years old and works as a {job}")
# Output: Bob is 25 years old and works as a Designer

# Named tuples are immutable
# alice.age = 31  # This would raise an AttributeError

# Converting to dictionary
alice_dict = alice._asdict()
print(alice_dict)  # Output: {'name': 'Alice', 'age': 30, 'job': 'Engineer'}

# Creating a new instance with updated fields
alice_updated = alice._replace(age=31, job="Senior Engineer")
print(alice_updated)  # Output: Person(name='Alice', age=31, job='Senior Engineer')

# Named tuples for structured data
Point = namedtuple('Point', ['x', 'y', 'z'])
origin = Point(0, 0, 0)
print(f"Origin: {origin}")  # Output: Origin: Point(x=0, y=0, z=0)
```
