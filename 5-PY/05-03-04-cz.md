## 1. Úvod do správy paměti v Pythonu

Python zajišťuje správu paměti automaticky pomocí kombinace počítání referencí, garbage collection a dalších strategií přidělování paměti. Na rozdíl od jazyků jako C nebo C++ nemusí programátoři v Pythonu explicitně alokovat nebo uvolňovat paměť, ale pochopení principů správy paměti v Pythonu je klíčové pro optimalizaci výkonu.

```python
# Jednoduchá ukázka Python objektů a alokace paměti
import sys

# Vytvoření různých proměnných a kontrola jejich využití paměti
x = 42               # Celé číslo
y = "Hello, World!"  # Řetězec
z = [1, 2, 3, 4, 5]  # Seznam

# Zobrazení velikosti paměti každého objektu v bajtech
print(f"Velikost celého čísla: {sys.getsizeof(x)} bajtů")
print(f"Velikost řetězce: {sys.getsizeof(y)} bajtů")
print(f"Velikost seznamu: {sys.getsizeof(z)} bajtů")

# Poznámka: sys.getsizeof() poskytuje pouze přímé využití paměti
# a nezahrnuje paměť obsaženou v objektech
```

## 2. Porozumění architektuře paměti

Architektura paměti v Pythonu se skládá ze zásobníkové paměti pro ukládání referencí a primitivních dat a haldy pro ukládání objektů. Správce paměti Pythonu se stará o alokaci a dealokaci paměti haldy.

```python
# Ukázka alokace na zásobníku vs na haldě v Pythonu
import tracemalloc

# Začátek sledování alokací paměti
tracemalloc.start()

# Vytvoření některých proměnných
x = 42                    # Primitivní typ (hodnota na zásobníku, objekt na haldě)
large_list = list(range(100000))  # Komplexní objekt (reference na zásobníku, objekt na haldě)

# Získání aktuálního snímku paměti
snapshot = tracemalloc.take_snapshot()
top_stats = snapshot.statistics('lineno')

# Zobrazení statistik využití paměti
print("[ Největší využití paměti ]")
for stat in top_stats[:3]:
    print(stat)

# Zastavení sledování
tracemalloc.stop()
```

## 3. Počítání referencí a garbage collection

Python používá počítání referencí jako svůj primární mechanismus správy paměti. Každý objekt sleduje počet referencí na sebe. Když počet klesne na nulu, paměť je uvolněna. Kromě toho Python používá garbage collector k detekci a vyčištění cyklických referencí.

```python
import sys
import gc

# Příklad počítání referencí
class MujObjekt:
    def __init__(self, jmeno):
        self.jmeno = jmeno
    
    def __del__(self):
        print(f"{self.jmeno} je destruován")

# Vytvoření objektu
obj1 = MujObjekt("Objekt 1")
print(f"Počet referencí: {sys.getrefcount(obj1) - 1}")  # -1 protože getrefcount() vytváří dočasnou referenci

# Vytvoření další reference na stejný objekt
obj2 = obj1
print(f"Počet referencí: {sys.getrefcount(obj1) - 1}")

# Odstranění jedné reference
obj2 = None
print(f"Počet referencí: {sys.getrefcount(obj1) - 1}")

# Odstranění poslední reference
obj1 = None
# "Objekt 1 je destruován" by měl být vytištěn, když je obj1 uvolněn garbage collectorem

# Příklad cyklické reference
print("\nPříklad cyklické reference:")
class Uzel:
    def __init__(self, jmeno):
        self.jmeno = jmeno
        self.dalsi = None
    
    def __del__(self):
        print(f"Uzel {self.jmeno} je destruován")

# Vytvoření cyklických referencí
uzel1 = Uzel("A")
uzel2 = Uzel("B")
uzel1.dalsi = uzel2
uzel2.dalsi = uzel1

# Odstranění externích referencí
uzel1 = None
uzel2 = None
# Uzly zatím nebudou zničeny kvůli cyklickým referencím

# Vynucení garbage collection
print("Spouštím garbage collection...")
gc.collect()  # Toto by mělo detekovat a vyčistit cyklus
```

## 4. Nástroje pro profilování paměti

Python nabízí různé nástroje pro profilování využití paměti. Pochopení, jak tyto nástroje používat, je zásadní pro identifikaci paměťových úzkých míst ve vašich aplikacích.

```python
# Příklad profilování paměti
import random
import time
from memory_profiler import profile

# Funkce dekorovaná s @profile pro sledování využití paměti
@profile
def vytvorit_velky_seznam(velikost):
    vysledek = []
    for i in range(velikost):
        vysledek.append(random.random())
        time.sleep(0.01)  # Zpomalení vykonávání, aby byl vidět nárůst paměti
    return vysledek

@profile
def zpracovat_s_list_comprehension(velikost):
    # Paměťově efektivnější přístup pomocí list comprehension
    vysledek = [random.random() for _ in range(velikost)]
    time.sleep(0.5)  # Jen pro srovnání
    return vysledek

if __name__ == "__main__":
    print("Vytváření seznamu pomocí append:")
    vytvorit_velky_seznam(1000)
    
    print("\nVytváření seznamu pomocí comprehension:")
    zpracovat_s_list_comprehension(1000)

# Pro spuštění s řádkovým profilerem paměti:
# python -m memory_profiler nazev_souboru.py
```

## 5. Paměťově efektivní datové struktury

Výběr správné datové struktury může významně ovlivnit využití paměti. Python poskytuje několik paměťově efektivních alternativ ke standardním datovým strukturám.

```python
import sys
import array
import numpy as np
from collections import namedtuple

# Srovnání využití paměti u různých datových struktur
n = 10000
numbers = list(range(n))  # Běžný seznam celých čísel
array_nums = array.array('i', numbers)  # Pole celých čísel (efektivnější)
np_nums = np.array(numbers)  # NumPy pole (ještě efektivnější pro numerické operace)

print(f"Velikost seznamu: {sys.getsizeof(numbers)} bajtů")
print(f"Velikost pole: {sys.getsizeof(array_nums)} bajtů")
print(f"Velikost NumPy pole: {sys.getsizeof(np_nums)} bajtů")

# Použití namedtuple namísto třídy pro jednoduché datové struktury
print("\nNamed tuple vs. třída:")

# Běžná třída
class Bod:
    def __init__(self, x, y):
        self.x = x
        self.y = y

# Ekvivalent pomocí named tuple
BodTuple = namedtuple('BodTuple', ['x', 'y'])

# Vytvoření 1000 instancí každého typu
body_trida = [Bod(i, i) for i in range(1000)]
body_tuple = [BodTuple(i, i) for i in range(1000)]

print(f"Paměť pro 1000 instancí třídy: {sys.getsizeof(body_trida) + sum(sys.getsizeof(p) for p in body_trida)} bajtů")
print(f"Paměť pro 1000 named tuples: {sys.getsizeof(body_tuple) + sum(sys.getsizeof(p) for p in body_tuple)} bajtů")
```

## 6. Techniky optimalizace paměti

Existuje několik technik, které můžete použít k optimalizaci využití paměti v Pythonu, včetně použití generátorů, líného vyhodnocování a vhodných datových typů.

```python
# Techniky optimalizace paměti

# 1. Použití generátorů místo seznamů pro velké sekvence
print("Generátor vs Seznam:")

def generovat_velky_rozsah(n):
    # Vrací generátor
    for i in range(n):
        yield i

# Generátor (líné vyhodnocování, mnohem efektivnější z hlediska paměti)
generator = generovat_velky_rozsah(10**6)
print(f"Velikost generátoru: {sys.getsizeof(generator)} bajtů")

# Seznam (vytváří všechny položky najednou)
velky_seznam = list(range(10**6))
print(f"Velikost seznamu: {sys.getsizeof(velky_seznam)} bajtů")

# 2. Použití slotů ke snížení režie paměti u instancí tříd
print("\nPoužití __slots__:")

class BeznaTrida:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z

class TridaSeSloty:
    __slots__ = ['x', 'y', 'z']  # Omezuje atributy a využívá méně paměti
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z

bezny_obj = BeznaTrida(1, 2, 3)
sloty_obj = TridaSeSloty(1, 2, 3)

print(f"Velikost instance běžné třídy: {sys.getsizeof(bezny_obj)} bajtů")
print(f"Velikost instance třídy se sloty: {sys.getsizeof(sloty_obj)} bajtů")

# 3. Interning řetězců pro opakované řetězce
print("\nInterning řetězců:")
# Python automaticky internuje malé řetězce
s1 = "hello"
s2 = "hello"
print(f"Jsou s1 a s2 stejný objekt? {s1 is s2}")

# Pro větší řetězce zvažte manuální interning
import sys
slovnik_retezcu = {}
def internovat_retezec(s):
    if s not in slovnik_retezcu:
        slovnik_retezcu[s] = s
    return slovnik_retezcu[s]

velky_retezec = "Toto je větší řetězec, který by mohl být opakován mnohokrát"
internovane_retezce = [internovat_retezec(velky_retezec) for _ in range(1000)]
bezne_retezce = [velky_retezec] * 1000

print(f"Paměť pro 1000 běžných řetězců: ~{sys.getsizeof(velky_retezec) * 1000} bajtů")
print(f"Paměť s interningem: ~{sys.getsizeof(velky_retezec) + sys.getsizeof(internovane_retezce)} bajtů")
```

## 7. Práce s velkými datovými sadami

Při práci s velkými datovými sadami, které přesahují dostupnou paměť, je potřeba použít speciální techniky jako rozdělení na části, paměťově mapované soubory nebo streamové zpracování.

```python
import pandas as pd
import numpy as np
import os

# Příklad: Zpracování velkého CSV souboru po částech
def zpracovat_velky_csv_po_castech(nazev_souboru, velikost_casti=10000):
    # Zpracování souboru po částech, aby se celý soubor nenahrával do paměti
    citac_casti = pd.read_csv(nazev_souboru, chunksize=velikost_casti)
    
    celkem_radku = 0
    soucet_hodnot = 0
    
    for i, cast in enumerate(citac_casti):
        # Zpracování každé části
        celkem_radku += len(cast)
        soucet_hodnot += cast['hodnota_sloupce'].sum()
        
        print(f"Zpracována část {i+1}, řádků dosud: {celkem_radku}")
    
    return soucet_hodnot / celkem_radku if celkem_radku > 0 else 0

# Ukázkový soubor pro demonstraci (použili byste svůj skutečný soubor)
# Vytvoření ukázkového velkého CSV souboru
csv_nazev_souboru = "velky_vzorek.csv"
with open(csv_nazev_souboru, 'w') as f:
    f.write("id,hodnota_sloupce\n")
    for i in range(50000):
        f.write(f"{i},{np.random.rand()}\n")

# Zpracování souboru po částech
prumer = zpracovat_velky_csv_po_castech(csv_nazev_souboru)
print(f"Průměrná hodnota: {prumer}")

# Vyčištění
os.remove(csv_nazev_souboru)

# Příklad paměťově mapovaného souboru
import mmap
import contextlib

def nacist_velky_soubor_s_mmap(nazev_souboru):
    with open(nazev_souboru, 'r+b') as f:
        # Paměťově mapovaný soubor
        with contextlib.closing(mmap.mmap(f.fileno(), 0)) as m:
            # Zpracování paměťově mapovaného souboru
            print(f"Velikost souboru: {len(m)} bajtů")
            
            # Načtení prvních 50 bajtů
            print(f"Prvních 50 bajtů: {m[:50]}")
            
            # Nalezení vzoru
            pozice = m.find(b'hodnota')
            if pozice >= 0:
                print(f"Nalezeno 'hodnota' na pozici: {pozice}")

# Použití funkce paměťově mapovaného souboru s naším vzorkovým souborem
with open(csv_nazev_souboru, 'w') as f:
    f.write("id,hodnota_sloupce\n")
    for i in range(100):
        f.write(f"{i},{np.random.rand()}\n")

nacist_velky_soubor_s_mmap(csv_nazev_souboru)

# Vyčištění
os.remove(csv_nazev_souboru)
```

## 8. Úniky paměti v Pythonu

Přestože Python má automatickou správu paměti, úniky paměti se mohou stále objevit, zejména kvůli cyklickým referencím, cachovaným objektům nebo nesprávnému uvolňování zdrojů.

```python
import gc
import weakref

# Běžné příčiny úniků paměti a jak se jim vyhnout

# 1. Cyklické reference bez slabých referencí
class Rodic:
    def __init__(self, jmeno):
        self.jmeno = jmeno
        self.deti = []
    
    def pridat_dite(self, dite):
        self.deti.append(dite)
    
    def __repr__(self):
        return f"Rodic({self.jmeno})"

class Dite:
    def __init__(self, jmeno, rodic):
        self.jmeno = jmeno
        self.rodic = rodic  # Silná reference vytváří cyklus
        rodic.pridat_dite(self)
    
    def __repr__(self):
        return f"Dite({self.jmeno}, {self.rodic.jmeno})"

# Vytvoření objektů s cyklickými referencemi
rodic = Rodic("Alice")
dite = Dite("Bob", rodic)

# Odstranění externích referencí
jmeno_rodice = rodic.jmeno
jmeno_ditete = dite.jmeno
rodic = None
dite = None

# I po odstranění proměnných objekty zůstávají v paměti kvůli cyklickým referencím
print("Spouštím garbage collection...")
vysbíráno = gc.collect()
print(f"Vysbíráno {vysbíráno} objektů.")

print("\nŘešení pomocí slabých referencí:")

class LepsiDite:
    def __init__(self, jmeno, rodic):
        self.jmeno = jmeno
        # Použití slabé reference k zabránění cyklické reference
        self.rodic = weakref.ref(rodic)  # Vytváří slabou referenci
        rodic.pridat_dite(self)
    
    def __repr__(self):
        rodic = self.rodic()  # Získání referencovaného objektu nebo None, pokud je pryč
        jmeno_rodice = rodic.jmeno if rodic else "Neznámý"
        return f"LepsiDite({self.jmeno}, {jmeno_rodice})"

# Vytvoření objektů se slabými referencemi
lepsi_rodic = Rodic("Carol")
lepsi_dite = LepsiDite("Dave", lepsi_rodic)

# Odstranění externích referencí
jmeno_lepsiho_rodice = lepsi_rodic.jmeno
jmeno_lepsiho_ditete = lepsi_dite.jmeno
lepsi_rodic = None  # Toto by mělo umožnit garbage collection

# Nyní je reference rodiče dítěte slabá reference ukazující na nic
print("Spouštím garbage collection znovu...")
vysbíráno = gc.collect()
print(f"Vysbíráno {vysbíráno} objektů.")
```

## 9. Osvědčené postupy

Zde jsou některé osvědčené postupy pro efektivní správu paměti v Pythonu:

```python
# Osvědčené postupy pro správu paměti

# 1. Explicitní uvolňování zdrojů, kdykoli je to možné
import tempfile
import os

def spatna_prace_se_souborem():
    # Špatně: Držadlo souboru není explicitně uzavřeno
    temp = tempfile.NamedTemporaryFile(delete=False)
    temp.write(b"Nějaká data")
    # Držadlo souboru zůstává otevřené až do garbage collection
    return temp.name

def dobra_prace_se_souborem():
    # Dobře: Použití správce kontextu k zajištění řádného vyčištění
    with tempfile.NamedTemporaryFile(delete=False) as temp:
        temp.write(b"Nějaká data")
        return temp.name

# 2. Použití generátorů pro velké iterace
def cist_radky_velkeho_souboru(nazev_souboru):
    # Paměťově efektivní způsob zpracování souboru řádek po řádku
    with open(nazev_souboru, 'r') as f:
        for radek in f:  # Čte jeden řádek najednou
            yield radek.strip()

# 3. Vyhýbání se zbytečným kopiím velkých dat
import copy

# Špatně: Vytváří zbytečné kopie
def zpracovat_data_neefektivne(data):
    # Toto vytváří úplnou kopii dat
    kopie_dat = copy.deepcopy(data)
    vysledek = kopie_dat[:]  # Další kopie
    return vysledek

# Dobře: Vyhýbání se zbytečným kopiím
def zpracovat_data_efektivne(data):
    # Zpracování přímo bez kopírování, pokud je to možné
    return data

# 4. Použití vhodných datových struktur
# Množiny (sets) pro testy členství
def test_clenstvi_neefektivni(polozka, kolekce):
    return polozka in kolekce  # O(n) pro seznamy

def test_clenstvi_efektivni(polozka, kolekce_mnozina):
    return polozka in kolekce_mnozina  # O(1) pro množiny

# 5. Upřednostnění lokálních proměnných před globálními
globalni_var = "Jsem globální"

def spatna_funkce():
    # Špatně: Používá globální proměnnou
    return globalni_var + " a upravená"

def dobra_funkce(lokalni_var):
    # Dobře: Používá lokální proměnnou
    return lokalni_var + " a upravená"
```

## 10. Shrnutí

Efektivní správa paměti v Pythonu vyžaduje pochopení, jak Python alokuje a spravuje paměť, používání vhodných nástrojů pro profilování, výběr efektivních datových struktur a dodržování osvědčených postupů v organizaci kódu. Klíčové poznatky zahrnují:

1. **Pochopení modelu paměti Pythonu**: Počítání referencí a garbage collection jsou klíčovými složkami.
2. **Používání nástrojů pro profilování paměti**: Nástroje jako `memory_profiler`, `tracemalloc` a `sys.getsizeof()` pomáhají identifikovat vzorce využití paměti.
3. **Volba vhodných datových struktur**: Používání paměťově efektivních struktur jako jsou NumPy pole, `collections.namedtuple` nebo specializované knihovny pro velké datové sady.
4. **Aplikace optimalizačních technik**: Generátory, `__slots__`, slabé reference a řádné uvolňování zdrojů mohou výrazně snížit využití paměti.
5. **Správné zpracování velkých datových sad**: Použití segmentace, paměťového mapování nebo streamovaných přístupů pro data, která se nevejdou do paměti.
6. **Vyhýbání se únikům paměti**: Obezřetnost s cyklickými referencemi a cache, a používání slabých referencí, kdy je to vhodné.
7. **Dodržování osvědčených postupů**: Explicitní čištění zdrojů, minimalizace kopií a používání lokálních proměnných, když je to možné.

Aplikací těchto principů můžete psát Python kód, který je jak paměťově efektivní, tak výkonný, a to i při práci s velkými datovými sadami nebo v prostředích s omezenou pamětí.
