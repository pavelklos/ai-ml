## 1. Úvod do profilování výkonu

Profilování výkonu je proces měření a analýzy provádění vašeho kódu za účelem identifikace úzkých míst a neefektivností. Optimalizace je aplikace technik k urychlení běhu vašeho kódu nebo ke snížení využití zdrojů.

Před optimalizací kódu je zásadní:
1. Ujistit se, že funguje správně
2. Stanovit základní úroveň výkonu
3. Identifikovat skutečná úzká místa
4. Dodržovat princip: "Předčasná optimalizace je kořenem veškerého zla"

```python
# Neoptimalizujte naslepo - vždy nejdříve měřte!
# Běžné oblasti ke zkoumání:
# - Úzká místa omezená CPU (pomalé výpočty)
# - Úzká místa omezená pamětí (nadměrné využití paměti)
# - Úzká místa omezená I/O (operace s diskem nebo sítí)
```

## 2. Základní techniky měření času a porovnávací testy

Nejjednodušším způsobem měření výkonu je použití vestavěného modulu `time` v Pythonu nebo modulu `timeit` pro přesnější porovnávací testy.

```python
import time

# Jednoduché měření času pomocí time.time()
def jednoduche_mereni():
    cas_zacatku = time.time()
    
    # Kód, jehož čas se má měřit
    celkem = 0
    for i in range(1000000):
        celkem += i
    
    cas_konce = time.time()
    doba_provadeni = cas_konce - cas_zacatku
    print(f"Doba provádění: {doba_provadeni:.6f} sekund")

jednoduche_mereni()

# Přesnější porovnávací testy s timeit
import timeit

def funkce_k_porovnani():
    celkem = 0
    for i in range(10000):
        celkem += i
    return celkem

# Spustí funkci 1000krát a vypočítá průměrný čas provádění
doba_provadeni = timeit.timeit(funkce_k_porovnani, number=1000)
print(f"Průměrná doba provádění: {doba_provadeni/1000:.8f} sekund")

# Měření času úseků kódu pomocí timeit
cas_vytvoreni_seznamu = timeit.timeit('[i for i in range(10000)]', number=1000)
print(f"Seznamová komprehence: {cas_vytvoreni_seznamu/1000:.8f} sekund")

cas_generatoru = timeit.timeit('list(i for i in range(10000))', number=1000)
print(f"Výraz generátoru: {cas_generatoru/1000:.8f} sekund")
```

## 3. Profilování pomocí cProfile a pstats

Standardní knihovna Pythonu obsahuje výkonný modul `cProfile`, který poskytuje podrobné informace o volání funkcí.

```python
import cProfile
import pstats
import io

def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

def vypocet_fibonacciho_posloupnosti(delka):
    return [fibonacci(i) for i in range(delka)]

# Spuštění profileru
profil = cProfile.Profile()
profil.enable()

# Spuštění funkce, kterou chceme profilovat
vypocet_fibonacciho_posloupnosti(30)

profil.disable()

# Přímý výpis jednoduchých statistik
profil.print_stats(sort='cumulative')

# Pro větší kontrolu použijte pstats
s = io.StringIO()
ps = pstats.Stats(profil, stream=s).sort_stats('cumulative')
ps.print_stats(10)  # Výpis 10 nejdůležitějších funkcí
print(s.getvalue())

# Uložení výsledků profilování do souboru pro pozdější analýzu
ps.dump_stats('fibonacci_profile.prof')

# Výsledky můžete vizualizovat pomocí nástrojů jako snakeviz:
# pip install snakeviz
# snakeviz fibonacci_profile.prof
```

## 5. Profilování paměti

Využití paměti je stejně důležité jako doba provádění. Balíček `memory_profiler` pomáhá sledovat spotřebu paměti.

```python
# Nainstalujte memory_profiler:
# pip install memory_profiler

from memory_profiler import profile as memory_profile

@memory_profile
def pamet_neefektivni():
    # Vytvoření velkého seznamu
    velky_seznam = [i for i in range(10000000)]
    return sum(velky_seznam)

@memory_profile
def pamet_efektivni():
    # Použití generátoru místo toho
    return sum(i for i in range(10000000))

print("Neefektivní přístup k paměti:")
pamet_neefektivni()

print("\nEfektivní přístup k paměti:")
pamet_efektivni()

# V Jupyter notebooku můžete také použít:
# %load_ext memory_profiler
# %memit velky_seznam = [i for i in range(10000000)]
# %memit sum(i for i in range(10000000))
```

## 6. Algoritmická optimalizace

Často největší zlepšení výkonu přicházejí z výběru lepších algoritmů s nižší výpočetní složitostí.

```python
import time
import random

# Přístup O(n²) k nalezení duplikátů
def najdi_duplikaty_kvadraticky(cisla):
    duplikaty = []
    n = len(cisla)
    for i in range(n):
        for j in range(i+1, n):
            if cisla[i] == cisla[j] and cisla[i] not in duplikaty:
                duplikaty.append(cisla[i])
    return duplikaty

# Přístup O(n) s použitím množiny
def najdi_duplikaty_linearne(cisla):
    videne = set()
    duplikaty = set()
    for cislo in cisla:
        if cislo in videne:
            duplikaty.add(cislo)
        else:
            videne.add(cislo)
    return list(duplikaty)

# Test s velkým seznamem
testovaci_data = [random.randint(1, 1000) for _ in range(10000)]

# Měření času kvadratického přístupu
start = time.time()
najdi_duplikaty_kvadraticky(testovaci_data)
konec = time.time()
print(f"Kvadratický přístup: {konec - start:.4f} sekund")

# Měření času lineárního přístupu
start = time.time()
najdi_duplikaty_linearne(testovaci_data)
konec = time.time()
print(f"Lineární přístup: {konec - start:.4f} sekund")
```

## 7. Techniky optimalizace kódu

I bez změny algoritmů můžete aplikovat mnoho optimalizací specifických pro Python.

```python
# 1. Použití vhodných datových struktur
import timeit

# Vyhledávání v seznamu je O(n)
def vyhledavani_v_seznamu():
    muj_seznam = list(range(10000))
    return 9999 in muj_seznam

# Vyhledávání v množině je O(1)
def vyhledavani_v_mnozine():
    moje_mnozina = set(range(10000))
    return 9999 in moje_mnozina

print(f"Vyhledávání v seznamu: {timeit.timeit(vyhledavani_v_seznamu, number=1000):.6f} sekund")
print(f"Vyhledávání v množině: {timeit.timeit(vyhledavani_v_mnozine, number=1000):.6f} sekund")

# 2. Vyhněte se vytváření zbytečných proměnných
def zbytecne_promenne(n):
    vysledek = []
    for i in range(n):
        docasna = i * 2  # Zbytečná proměnná
        vysledek.append(docasna)
    return vysledek

def primy_vypocet(n):
    vysledek = []
    for i in range(n):
        vysledek.append(i * 2)
    return vysledek

# 3. Použijte vestavěné funkce a metody
def manualni_soucet(cisla):
    celkem = 0
    for cislo in cisla:
        celkem += cislo
    return celkem

def vestaveny_soucet(cisla):
    return sum(cisla)

# 4. Přístup k lokální proměnné je rychlejší než ke globální
globalni_var = 100

def pouzij_globalni():
    for i in range(10000):
        vysledek = globalni_var * i

def pouzij_lokalni():
    lokalni_var = 100
    for i in range(10000):
        vysledek = lokalni_var * i
```

## 8. Vektorizace pomocí NumPy

Pro numerické operace jsou vektorizované operace NumPy mnohem rychlejší než smyčky v Pythonu.

```python
import numpy as np
import time

# Smyčky v Pythonu (pomalé)
def python_soucet_ctvercu(n):
    vysledek = 0
    for i in range(n):
        vysledek += i ** 2
    return vysledek

# Vektorizace NumPy (rychlé)
def numpy_soucet_ctvercu(n):
    return np.sum(np.arange(n) ** 2)

n = 10000000
# Měření verze v Pythonu
start = time.time()
python_vysledek = python_soucet_ctvercu(n)
python_cas = time.time() - start

# Měření verze NumPy
start = time.time()
numpy_vysledek = numpy_soucet_ctvercu(n)
numpy_cas = time.time() - start

print(f"Čas Pythonu: {python_cas:.4f} sekund")
print(f"Čas NumPy: {numpy_cas:.4f} sekund")
print(f"Zlepšení rychlosti: {python_cas/numpy_cas:.1f}x")
```

## 9. Paralelní zpracování pro zvýšení výkonu

Při práci s operacemi náročnými na CPU můžete použít `multiprocessing` nebo `concurrent.futures` v Pythonu k využití více jader.

```python
import time
from concurrent.futures import ProcessPoolExecutor
import multiprocessing as mp

def narocny_ukol_pro_cpu(n):
    """Funkce náročná na CPU pro výpočet součtu čtverců."""
    return sum(i*i for i in range(n))

# Sériové provádění
def spustit_seriove(cisla):
    start = time.time()
    vysledky = [narocny_ukol_pro_cpu(n) for n in cisla]
    konec = time.time()
    print(f"Doba sériového provádění: {konec - start:.2f} sekund")
    return vysledky

# Paralelní provádění s concurrent.futures
def spustit_paralelne_futures(cisla):
    start = time.time()
    with ProcessPoolExecutor() as executor:
        vysledky = list(executor.map(narocny_ukol_pro_cpu, cisla))
    konec = time.time()
    print(f"Doba paralelního provádění (concurrent.futures): {konec - start:.2f} sekund")
    return vysledky

# Paralelní provádění s multiprocessing
def spustit_paralelne_mp(cisla):
    start = time.time()
    with mp.Pool() as pool:
        vysledky = pool.map(narocny_ukol_pro_cpu, cisla)
    konec = time.time()
    print(f"Doba paralelního provádění (multiprocessing): {konec - start:.2f} sekund")
    return vysledky

if __name__ == "__main__":
    # Vygenerování úkolů ke spuštění
    ukoly = [20000000 + i * 1000 for i in range(8)]
    
    # Spuštění sériově
    seriove_vysledky = spustit_seriove(ukoly)
    
    # Spuštění s concurrent.futures
    futures_vysledky = spustit_paralelne_futures(ukoly)
    
    # Spuštění s multiprocessing
    mp_vysledky = spustit_paralelne_mp(ukoly)
    
    # Ověření, že všechny přístupy dávají stejné výsledky
    print(f"Výsledky se shodují: {seriove_vysledky == futures_vysledky == list(mp_vysledky)}")
```

## 10. Shrnutí

Profilování výkonu a optimalizace v Pythonu zahrnuje:

1. **Nejprve měření**: Vždy stanovte výchozí úroveň a identifikujte skutečná úzká místa před optimalizací.

2. **Nástroje profilování**: Používejte vestavěné nástroje jako `timeit` a `cProfile` nebo nástroje třetích stran jako `line_profiler` a `memory_profiler` k identifikaci problémů.

3. **Algoritmická vylepšení**: Vybírejte efektivní algoritmy s nižší výpočetní složitostí (O(n) vs O(n²)).

4. **Optimalizace na úrovni kódu**: Používejte vhodné datové struktury, vyhněte se zbytečným operacím, využívejte vestavěné funkce a optimalizujte přístup k proměnným.

5. **Vektorizace**: Používejte NumPy pro numerické operace k dosažení významného zrychlení.

6. **Paralelizace**: Používejte `multiprocessing` nebo `concurrent.futures` k distribuci práce napříč více jádry pro úlohy náročné na CPU.

Pamatujte na mantru optimalizace:
1. Udělejte to funkční
2. Udělejte to správně
3. Udělejte to rychlé - ale až po profilování

Nejúčinnější optimalizace řeší specifická úzká místa ve vaší aplikaci, spíše než předčasná optimalizace kódu, který není kritický z hlediska výkonu. Vždy zajistěte, že vaše optimalizace neohrozí čitelnost a udržitelnost kódu bez významných výkonnostních přínosů.
