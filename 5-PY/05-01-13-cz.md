## 1. Úvod do objektově orientovaného programování

Objektově orientované programování (OOP) je programovací paradigma založené na konceptu "objektů", které mohou obsahovat data (atributy) a kód (metody). OOP umožňuje organizovat kód do znovupoužitelných vzorů, což usnadňuje údržbu a rozšiřování velkých programů. Python je víceúčelový jazyk, který plně podporuje principy OOP.

Základní koncepty v OOP zahrnují:
- **Třídy**: Šablony pro vytváření objektů
- **Objekty**: Instance tříd
- **Atributy**: Data uložená uvnitř objektů
- **Metody**: Funkce, které definují chování objektů
- **Dědičnost**: Mechanismus pro opětovné použití kódu
- **Zapouzdření**: Skrývání detailů implementace
- **Polymorfismus**: Objekty různých typů reagující na stejnou metodu

```python
# OOP nám umožňuje modelovat koncepty reálného světa v kódu
# Například bychom mohli reprezentovat auto jako:

class Auto:
    # Atributy (data)
    barva = "červená"
    značka = "Toyota"
    
    # Metody (chování)
    def jed(self):
        print("Auto se pohybuje!")
    
    def troubení(self):
        print("Tút tút!")

# Vytvoření objektu z třídy Auto
moje_auto = Auto()

# Použití objektu
print(f"Moje {moje_auto.barva} {moje_auto.značka} je pěkná!")  # Výstup: Moje červená Toyota je pěkná!
moje_auto.jed()  # Výstup: Auto se pohybuje!
moje_auto.troubení()   # Výstup: Tút tút!
```

## 2. Vytváření tříd a objektů

Třída je definována pomocí klíčového slova `class`, následovaného názvem třídy (obvykle používající CamelCase) a dvojtečkou. Tělo třídy obsahuje atributy a metody. Objekty (instance) jsou vytvářeny voláním názvu třídy, jako by to byla funkce.

```python
# Definování jednoduché třídy
class Osoba:
    # Tělo třídy - zde definujeme atributy a metody
    pass  # 'pass' je zástupný symbol, který nedělá nic

# Vytvoření objektů (instancí) třídy
osoba1 = Osoba()  # První instance
osoba2 = Osoba()  # Druhá instance

# Každá instance je samostatný objekt
print(osoba1)  # Výstup: <__main__.Osoba object at 0x...>
print(osoba2)  # Výstup: <__main__.Osoba object at 0x...>
print(osoba1 is osoba2)  # Výstup: False

# Přidání atributů jednotlivým objektům
osoba1.jmeno = "Alice"
osoba1.vek = 30

osoba2.jmeno = "Bob"
osoba2.vek = 25

# Přístup k atributům
print(f"{osoba1.jmeno} je {osoba1.vek} let.")  # Výstup: Alice je 30 let.
print(f"{osoba2.jmeno} je {osoba2.vek} let.")  # Výstup: Bob je 25 let.
```

## 3. Atributy a instanční proměnné

Atributy jsou proměnné, které ukládají data v rámci třídy nebo objektu. Existují dva hlavní typy:
- **Třídní atributy**: Definované v třídě, ale mimo jakékoli metody, sdílené všemi instancemi
- **Instanční atributy**: Specifické pro každou instanci, typicky definované v metodě `__init__`

```python
class Student:
    # Třídní atribut - sdílený všemi instancemi
    nazev_skoly = "Střední škola Python"
    
    def __init__(self, jmeno, rocnik):
        # Instanční atributy - jedinečné pro každou instanci
        self.jmeno = jmeno
        self.rocnik = rocnik

# Vytvoření objektů studentů
student1 = Student("Alice", 10)
student2 = Student("Bob", 9)

# Přístup k instančním atributům
print(f"{student1.jmeno} je v {student1.rocnik}. ročníku")  # Výstup: Alice je v 10. ročníku
print(f"{student2.jmeno} je v {student2.rocnik}. ročníku")  # Výstup: Bob je v 9. ročníku

# Přístup k třídnímu atributu (sdílený)
print(f"Oba studenti navštěvují {Student.nazev_skoly}")  # Výstup: Oba studenti navštěvují Střední škola Python
print(f"{student1.jmeno} navštěvuje {student1.nazev_skoly}")  # Výstup: Alice navštěvuje Střední škola Python
print(f"{student2.jmeno} navštěvuje {student2.nazev_skoly}")  # Výstup: Bob navštěvuje Střední škola Python

# Úprava třídního atributu ovlivní všechny instance
Student.nazev_skoly = "Pokročilá akademie Pythonu"
print(f"Název školy byl změněn na {Student.nazev_skoly}")
print(f"{student1.jmeno} nyní navštěvuje {student1.nazev_skoly}")  # Výstup: Alice nyní navštěvuje Pokročilá akademie Pythonu
print(f"{student2.jmeno} nyní navštěvuje {student2.nazev_skoly}")  # Výstup: Bob nyní navštěvuje Pokročilá akademie Pythonu

# Úprava instančního atributu ovlivní pouze danou instanci
student1.nazev_skoly = "Speciální program"
print(f"{student1.jmeno} navštěvuje {student1.nazev_skoly}")  # Výstup: Alice navštěvuje Speciální program
print(f"{student2.jmeno} navštěvuje {student2.nazev_skoly}")  # Výstup: Bob navštěvuje Pokročilá akademie Pythonu
```

## 4. Metody a chování

Metody jsou funkce definované uvnitř třídy, které popisují chování objektů. Prvním parametrem metody je vždy `self`, což odkazuje na instanci, na které je metoda volána.

```python
class BankovniUcet:
    def __init__(self, vlastnik, zustatek=0):
        self.vlastnik = vlastnik
        self.zustatek = zustatek
    
    # Instanční metoda
    def vklad(self, castka):
        if castka > 0:
            self.zustatek += castka
            print(f"Vloženo {castka} Kč. Nový zůstatek: {self.zustatek} Kč")
        else:
            print("Částka vkladu musí být kladná")
    
    # Instanční metoda
    def vyber(self, castka):
        if 0 < castka <= self.zustatek:
            self.zustatek -= castka
            print(f"Vybráno {castka} Kč. Zbývající zůstatek: {self.zustatek} Kč")
        elif castka > self.zustatek:
            print("Nedostatek prostředků!")
        else:
            print("Částka výběru musí být kladná")
    
    # Instanční metoda
    def kontrola_zustatku(self):
        print(f"Zůstatek účtu {self.vlastnik}: {self.zustatek} Kč")

# Vytvoření účtu
ucet = BankovniUcet("Alice", 1000)

# Použití metod pro interakci s objektem
ucet.kontrola_zustatku()  # Výstup: Zůstatek účtu Alice: 1000 Kč
ucet.vklad(500)           # Výstup: Vloženo 500 Kč. Nový zůstatek: 1500 Kč
ucet.vyber(200)           # Výstup: Vybráno 200 Kč. Zbývající zůstatek: 1300 Kč
ucet.vyber(2000)          # Výstup: Nedostatek prostředků!
ucet.kontrola_zustatku()  # Výstup: Zůstatek účtu Alice: 1300 Kč
```

## 5. Konstruktory a inicializace

Metoda `__init__` je speciální metoda, která je volána při vytváření nového objektu. Používá se k inicializaci atributů objektu. Není to přísně vzato konstruktor (Python ve skutečnosti používá `__new__` pro tento účel), ale běžně se označuje jako konstruktor, protože slouží podobnému účelu.

```python
class Obdelnik:
    def __init__(self, sirka, vyska):
        print("Vytváření nového objektu Obdelnik...")
        # Inicializace instančních atributů
        self.sirka = sirka
        self.vyska = vyska
        self.plocha = sirka * vyska
    
    def popis(self):
        print(f"Obdélník: šířka={self.sirka}, výška={self.vyska}, plocha={self.plocha}")
    
    def zmenit_meritko(self, faktor):
        self.sirka *= faktor
        self.vyska *= faktor
        self.plocha = self.sirka * self.vyska
        print(f"Změněno měřítko {faktor}x. Nové rozměry: {self.sirka}x{self.vyska}")

# Vytvoření obdélníků
obdelnik1 = Obdelnik(5, 10)  # Výstup: Vytváření nového objektu Obdelnik...
obdelnik2 = Obdelnik(3, 4)   # Výstup: Vytváření nového objektu Obdelnik...

obdelnik1.popis()  # Výstup: Obdélník: šířka=5, výška=10, plocha=50
obdelnik2.popis()  # Výstup: Obdélník: šířka=3, výška=4, plocha=12

obdelnik1.zmenit_meritko(2)    # Výstup: Změněno měřítko 2x. Nové rozměry: 10x20
obdelnik1.popis()  # Výstup: Obdélník: šířka=10, výška=20, plocha=200
```

## 6. Základy dědičnosti

Dědičnost umožňuje třídě zdědit atributy a metody od jiné třídy. Nová třída (podtřída) může přepsat nebo rozšířit funkčnost rodičovské třídy (nadtřídy).

```python
# Základní třída (rodičovská třída)
class Zvire:
    def __init__(self, jmeno, druh):
        self.jmeno = jmeno
        self.druh = druh
    
    def vydej_zvuk(self):
        print("Nějaký obecný zvířecí zvuk")
    
    def popis(self):
        print(f"{self.jmeno} je {self.druh}")

# Odvozená třída (potomek)
class Pes(Zvire):
    def __init__(self, jmeno, plemeno):
        # Volání metody __init__ rodičovské třídy
        super().__init__(jmeno, druh="Pes")
        self.plemeno = plemeno
    
    # Přepsání metody rodiče
    def vydej_zvuk(self):
        print("Haf!")
    
    # Přidání nové metody
    def vrteni_ocasem(self):
        print(f"{self.jmeno} vesele vrtí ocasem")

# Odvozená třída (další potomek)
class Kocka(Zvire):
    def __init__(self, jmeno, barva):
        super().__init__(jmeno, druh="Kočka")
        self.barva = barva
    
    def vydej_zvuk(self):
        print("Mňau!")
    
    def predeni(self):
        print(f"{self.jmeno} spokojeně přede")

# Vytvoření instancí
obecne_zvire = Zvire("Obecné", "Neznámé")
pes = Pes("Buddy", "Zlatý retrívr")
kocka = Kocka("Micka", "Mourovatá")

# Volání metod
obecne_zvire.popis()  # Výstup: Obecné je Neznámé
obecne_zvire.vydej_zvuk()  # Výstup: Nějaký obecný zvířecí zvuk

pes.popis()  # Výstup: Buddy je Pes
print(f"Plemeno: {pes.plemeno}")  # Výstup: Plemeno: Zlatý retrívr
pes.vydej_zvuk()  # Výstup: Haf!
pes.vrteni_ocasem()  # Výstup: Buddy vesele vrtí ocasem

kocka.popis()  # Výstup: Micka je Kočka
print(f"Barva: {kocka.barva}")  # Výstup: Barva: Mourovatá
kocka.vydej_zvuk()  # Výstup: Mňau!
kocka.predeni()  # Výstup: Micka spokojeně přede
```

## 7. Zapouzdření v Pythonu

Zapouzdření je svázání dat a metod, které s těmito daty pracují, v rámci jedné jednotky (třídy). Zahrnuje také omezení přímého přístupu k některým komponentám objektu. Python pro tento účel používá konvence pojmenování:

- `atribut`: Veřejný (přístupný odkudkoli)
- `_atribut`: Chráněný (neměl by být přístupný mimo třídu, ale je to jen konvence)
- `__atribut`: Soukromý (dochází k tzv. name mangling, což ztěžuje přístup zvenčí)

```python
class Zamestnanec:
    def __init__(self, jmeno, plat):
        self.jmeno = jmeno          # Veřejný atribut
        self._plat = plat           # Chráněný atribut (konvence)
        self.__bonus = 1000         # Soukromý atribut (name mangling)
    
    def zobraz_info(self):
        print(f"Jméno: {self.jmeno}")
        print(f"Plat: {self._plat} Kč")
        print(f"Celková odměna: {self._plat + self.__bonus} Kč")
    
    def _chranena_metoda(self):
        print("Toto je chráněná metoda")
    
    def __soukroma_metoda(self):
        print("Toto je soukromá metoda")
    
    def volej_soukromou(self):
        # Soukromé metody lze volat z rámci třídy
        self.__soukroma_metoda()

# Vytvoření zaměstnance
zam = Zamestnanec("Alice", 50000)

# Přístup k veřejnému atributu
print(zam.jmeno)  # Výstup: Alice

# Přístup k chráněnému atributu (možné, ale nedoporučené)
print(zam._plat)  # Výstup: 50000

# Pokus o přístup k soukromému atributu (nebude fungovat podle očekávání)
try:
    print(zam.__bonus)
except AttributeError as e:
    print(f"Chyba: {e}")  # Výstup: Chyba: 'Zamestnanec' object has no attribute '__bonus'

# Name mangling: Soukromé atributy jsou uloženy s upravenými názvy
print(zam._Zamestnanec__bonus)  # Výstup: 1000 (nedoporučeno, ale možné)

zam.zobraz_info()  # Výstup: Jméno: Alice, Plat: 50000 Kč, Celková odměna: 51000 Kč

# Volání chráněné metody (možné, ale nedoporučené)
zam._chranena_metoda()  # Výstup: Toto je chráněná metoda

# Pokus o volání soukromé metody (nebude fungovat)
try:
    zam.__soukroma_metoda()
except AttributeError as e:
    print(f"Chyba: {e}")  # Výstup: Chyba: 'Zamestnanec' object has no attribute '__soukroma_metoda'

# Volání soukromé metody přes veřejné rozhraní
zam.volej_soukromou()  # Výstup: Toto je soukromá metoda
```

## 8. Speciální metody (magické metody)

Třídy v Pythonu mají speciální metody, také nazývané "magické metody" nebo "dunder metody" (double underscore), které umožňují definovat, jak se objekty vaší třídy chovají s vestavěnými funkcemi a operátory.

```python
class Vektor:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    # Řetězcová reprezentace
    def __str__(self):
        return f"Vektor({self.x}, {self.y})"
    
    # Reprezentace pro vývojáře
    def __repr__(self):
        return f"Vektor({self.x}, {self.y})"
    
    # Sčítání
    def __add__(self, other):
        return Vektor(self.x + other.x, self.y + other.y)
    
    # Odčítání
    def __sub__(self, other):
        return Vektor(self.x - other.x, self.y - other.y)
    
    # Rovnost
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y
    
    # Délka (velikost)
    def __abs__(self):
        return (self.x**2 + self.y**2) ** 0.5
    
    # Udělat třídu iterovatelnou
    def __iter__(self):
        yield self.x
        yield self.y
    
    # Používání objektu jako funkce
    def __call__(self, skalar):
        return Vektor(self.x * skalar, self.y * skalar)

# Vytvoření vektorů
v1 = Vektor(2, 3)
v2 = Vektor(5, 7)

# Řetězcová reprezentace
print(v1)  # Výstup: Vektor(2, 3)
print(repr(v2))  # Výstup: Vektor(5, 7)

# Sčítání
v3 = v1 + v2
print(v3)  # Výstup: Vektor(7, 10)

# Odčítání
v4 = v2 - v1
print(v4)  # Výstup: Vektor(3, 4)

# Rovnost
print(v1 == v2)  # Výstup: False
print(v1 == Vektor(2, 3))  # Výstup: True

# Velikost
print(abs(v1))  # Výstup: 3.605551275463989

# Iterace
x, y = v1
print(f"x: {x}, y: {y}")  # Výstup: x: 2, y: 3

# Volání objektu jako funkce
v5 = v1(3)  # Vynásobení skalárem
print(v5)  # Výstup: Vektor(6, 9)
```

## 9. Shrnutí

V tomto modulu jsme se zabývali:

- **Objektově orientovaným programováním** a jeho principy implementovanými v Pythonu
- **Třídami a objekty**: Jak definovat třídy a vytvářet instance
- **Atributy**: Třídní proměnné a instanční proměnné pro ukládání dat
- **Metodami**: Definování chování objektů
- **Konstruktory**: Používání `__init__` k inicializaci nových objektů
- **Dědičností**: Vytváření specializovaných tříd z bázových tříd
- **Zapouzdřením**: Řízení přístupu k datům pomocí konvencí pojmenování
- **Speciálními metodami**: Přizpůsobení chování objektů pomocí magických metod

Objektově orientované programování poskytuje výkonný způsob, jak strukturovat kód pro komplexní aplikace. Implementace OOP v Pythonu je flexibilní a intuitivní, což usnadňuje vytváření dobře organizovaného, znovupoužitelného kódu. Principy, které jsme se zde naučili, tvoří základ pro pokročilejší koncepty OOP, jako je vícenásobná dědičnost, abstraktní bázové třídy a návrhové vzory.

Porozumění základním konceptům OOP je zásadní pro každého programátora v Pythonu, jelikož velká část standardní knihovny Pythonu a balíčků třetích stran využívá objektově orientovaný design. Při dalším vzdělávání zjistíte, že tyto principy vám pomohou psát čistší, udržitelnější a škálovatelnější kód.
