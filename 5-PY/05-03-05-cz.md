## 1. Úvod do návrhových vzorů

Návrhové vzory jsou znovu použitelná řešení běžných problémů v softwarovém návrhu. Představují osvědčené postupy, které byly vyvinuty zkušenými softwarovými vývojáři v průběhu času. V Pythonu mohou být návrhové vzory implementovány s jedinečnou flexibilitou díky dynamické povaze jazyka a podpoře více programovacích paradigmat.

```python
# Návrhové vzory nejsou jen šablony kódu, ale konceptuální modely
# Zde je jednoduchý příklad ukazující, jak flexibilita Pythonu umožňuje elegantní implementaci vzorů

# Tradiční OOP přístup k jednoduchému vzoru Singleton
class SingletonOOP:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

# Přístup specifický pro Python využívající modul (moduly jsou v Pythonu singletony)
# singleton_module.py
single_value = "Jsem hodnota singletonu"

def get_value():
    return single_value

def set_value(new_value):
    global single_value
    single_value = new_value
```

## 2. Vytvářející vzory

Vytvářející vzory se zaměřují na mechanismy vytváření objektů, abstrahují proces instanciace. Pomáhají systému být nezávislý na způsobu, jakým jsou jeho objekty vytvářeny, skládány a reprezentovány.

### Vzor Singleton

Zajišťuje, že třída má pouze jednu instanci a poskytuje globální přístupový bod k této instanci.

```python
class Singleton:
    _instance = None
    
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            # Sem umístěte inicializační kód
        return cls._instance

# Použití
s1 = Singleton()
s2 = Singleton()
print(s1 is s2)  # True - obě proměnné odkazují na stejnou instanci
```

### Tovární vzor (Factory Pattern)

Definuje rozhraní pro vytváření objektu, ale ponechává výběr jeho typu na podtřídách, vytváří instance více souvisejících tříd.

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return "Haf!"

class Cat(Animal):
    def speak(self):
        return "Mňau!"

class AnimalFactory:
    def create_animal(self, animal_type):
        if animal_type == "dog":
            return Dog()
        elif animal_type == "cat":
            return Cat()
        else:
            raise ValueError(f"Neznámý typ zvířete: {animal_type}")

# Použití
factory = AnimalFactory()
dog = factory.create_animal("dog")
cat = factory.create_animal("cat")
print(dog.speak())  # Výstup: Haf!
print(cat.speak())  # Výstup: Mňau!
```

### Vzor Stavitel (Builder Pattern)

Odděluje konstrukci složitého objektu od jeho reprezentace, umožňuje stejný konstrukční proces vytvářet různé reprezentace.

```python
class Computer:
    def __init__(self):
        self.cpu = None
        self.ram = None
        self.storage = None
        self.gpu = None
    
    def __str__(self):
        return f"Specifikace počítače: CPU={self.cpu}, RAM={self.ram}GB, Úložiště={self.storage}GB, GPU={self.gpu}"

class ComputerBuilder:
    def __init__(self):
        self.computer = Computer()
    
    def configure_cpu(self, cpu):
        self.computer.cpu = cpu
        return self
    
    def configure_ram(self, ram):
        self.computer.ram = ram
        return self
        
    def configure_storage(self, storage):
        self.computer.storage = storage
        return self
        
    def configure_gpu(self, gpu):
        self.computer.gpu = gpu
        return self
    
    def build(self):
        return self.computer

# Použití
builder = ComputerBuilder()
gaming_pc = builder.configure_cpu("Intel i9") \
                  .configure_ram(32) \
                  .configure_storage(1000) \
                  .configure_gpu("NVIDIA RTX 3080") \
                  .build()

print(gaming_pc)
```

## 3. Strukturální vzory

Strukturální vzory se zabývají kompozicí objektů k vytvoření větších struktur a poskytnutí nových funkcionalit.

### Vzor Adaptér (Adapter Pattern)

Umožňuje spolupráci nekompatibilních rozhraní vytvořením střední vrstvy adaptéru.

```python
# Existující třída s nekompatibilním rozhraním
class OldSystem:
    def original_request(self):
        return "Odpověď starého systému"

# Cílové rozhraní, které klient očekává
class NewInterface:
    def new_request(self):
        pass

# Adaptér činí OldSystem kompatibilní s NewInterface
class Adapter(NewInterface):
    def __init__(self, old_system):
        self.old_system = old_system
    
    def new_request(self):
        # Překládá new_request na original_request
        return f"Adaptér: {self.old_system.original_request()}"

# Použití
old_system = OldSystem()
adapter = Adapter(old_system)
print(adapter.new_request())  # Výstup: Adaptér: Odpověď starého systému
```

### Vzor Dekorátor (Decorator Pattern)

Dynamicky přidává odpovědnosti objektům bez úpravy jejich struktury.

```python
# Základní komponenta s metodou, kterou chceme rozšířit
class TextComponent:
    def render(self):
        return "Základní text"

# Základní třída dekorátoru
class TextDecorator:
    def __init__(self, component):
        self._component = component
    
    def render(self):
        return self._component.render()

# Konkrétní dekorátory
class BoldDecorator(TextDecorator):
    def render(self):
        return f"<b>{self._component.render()}</b>"

class ItalicDecorator(TextDecorator):
    def render(self):
        return f"<i>{self._component.render()}</i>"

# Použití
text = TextComponent()
bold_text = BoldDecorator(text)
italic_bold_text = ItalicDecorator(bold_text)

print(text.render())           # Výstup: Základní text
print(bold_text.render())      # Výstup: <b>Základní text</b>
print(italic_bold_text.render())  # Výstup: <i><b>Základní text</b></i>
```

## 4. Behaviorální vzory

Behaviorální vzory se zaměřují na komunikaci mezi objekty, jak objekty interagují a distribuují odpovědnost.

### Vzor Pozorovatel (Observer Pattern)

Definuje vztah jeden-k-mnoha mezi objekty, takže když jeden objekt změní stav, všechny jeho závislosti jsou upozorněny.

```python
class Subject:
    def __init__(self):
        self._observers = []
        self._state = None
    
    def attach(self, observer):
        if observer not in self._observers:
            self._observers.append(observer)
    
    def detach(self, observer):
        self._observers.remove(observer)
    
    def notify(self):
        for observer in self._observers:
            observer.update(self)
    
    @property
    def state(self):
        return self._state
    
    @state.setter
    def state(self, value):
        self._state = value
        self.notify()

class Observer:
    def update(self, subject):
        pass

class ConcreteObserver(Observer):
    def __init__(self, name):
        self.name = name
    
    def update(self, subject):
        print(f"{self.name} obdržel aktualizaci. Nový stav: {subject.state}")

# Použití
subject = Subject()

observer1 = ConcreteObserver("Pozorovatel 1")
observer2 = ConcreteObserver("Pozorovatel 2")

subject.attach(observer1)
subject.attach(observer2)

subject.state = "Nový stav"
# Výstup:
# Pozorovatel 1 obdržel aktualizaci. Nový stav: Nový stav
# Pozorovatel 2 obdržel aktualizaci. Nový stav: Nový stav
```

### Vzor Strategie (Strategy Pattern)

Definuje rodinu algoritmů, zapouzdří každý z nich a umožňuje jejich zaměnitelnost.

```python
from abc import ABC, abstractmethod

# Rozhraní strategie
class SortStrategy(ABC):
    @abstractmethod
    def sort(self, data):
        pass

# Konkrétní strategie
class QuickSortStrategy(SortStrategy):
    def sort(self, data):
        print("Řazení pomocí rychlého řazení")
        # Implementace quicksortu by byla zde
        return sorted(data)  # Používáme Python řazení pro jednoduchost

class MergeSortStrategy(SortStrategy):
    def sort(self, data):
        print("Řazení pomocí merge sort")
        # Implementace merge sortu by byla zde
        return sorted(data)  # Používáme Python řazení pro jednoduchost

# Kontext, který používá strategii
class Sorter:
    def __init__(self, strategy=None):
        self._strategy = strategy
    
    @property
    def strategy(self):
        return self._strategy
    
    @strategy.setter
    def strategy(self, strategy):
        self._strategy = strategy
    
    def sort(self, data):
        if self._strategy is None:
            raise ValueError("Strategie řazení není nastavena")
        return self._strategy.sort(data)

# Použití
data = [5, 3, 1, 4, 2]

sorter = Sorter()
sorter.strategy = QuickSortStrategy()
print(sorter.sort(data))  # Používá strategii rychlého řazení

sorter.strategy = MergeSortStrategy()
print(sorter.sort(data))  # Používá strategii merge sortu
```

## 5. Adaptace vzorů specifické pro Python

Dynamická povaha Pythonu umožňuje jedinečné adaptace tradičních návrhových vzorů.

### Mixin vzor

Umožňuje kompozici chování prostřednictvím vícenásobné dědičnosti bez hlubokých hierarchií dědičnosti.

```python
class LoggerMixin:
    def log(self, message):
        print(f"Log: {message}")

class DBOperationsMixin:
    def save_to_db(self, data):
        self.log(f"Ukládám data do databáze: {data}")  # Používá metodu log z LoggerMixin
        # Operace s databází by byly zde
        print(f"Data uložena: {data}")

class User(LoggerMixin, DBOperationsMixin):
    def __init__(self, name):
        self.name = name
    
    def save(self):
        self.save_to_db({"name": self.name})

# Použití
user = User("Alice")
user.log("Instance uživatele vytvořena")  # Z LoggerMixin
user.save()  # Spouští save_to_db z DBOperationsMixin, který používá log z LoggerMixin
```

### Vzor Descriptor

Umožňuje přidávat spravované atributy objektům pomocí speciálních metod jako `__get__`, `__set__` a `__delete__`.

```python
class Validator:
    def __init__(self, min_value=None, max_value=None):
        self.min_value = min_value
        self.max_value = max_value
        
    def __set_name__(self, owner, name):
        self.name = name
        
    def __get__(self, instance, owner):
        if instance is None:
            return self
        return instance.__dict__.get(self.name, None)
        
    def __set__(self, instance, value):
        if self.min_value is not None and value < self.min_value:
            raise ValueError(f"{self.name} nemůže být menší než {self.min_value}")
        if self.max_value is not None and value > self.max_value:
            raise ValueError(f"{self.name} nemůže být větší než {self.max_value}")
        instance.__dict__[self.name] = value

class Product:
    price = Validator(min_value=0)
    quantity = Validator(min_value=0, max_value=100)
    
    def __init__(self, name, price, quantity):
        self.name = name
        self.price = price
        self.quantity = quantity
        
    def total_value(self):
        return self.price * self.quantity

# Použití
try:
    product = Product("Widget", 19.99, 5)
    print(f"Hodnota produktu: ${product.total_value():.2f}")
    
    # Toto vyvolá ValueError
    product.quantity = 101
except ValueError as e:
    print(f"Chyba: {e}")
```

## 6. Anti-vzory, kterým se vyhnout

Pochopení toho, kterým vzorům se vyhnout, je stejně důležité jako vědět, které vzory použít.

```python
# Singleton jako globální stav (anti-vzor)
class BadSingleton:
    # Třídní proměnné přístupné všem instancím
    shared_data = {}
    
    @classmethod
    def set_data(cls, key, value):
        cls.shared_data[key] = value
    
    @classmethod
    def get_data(cls, key):
        return cls.shared_data.get(key)

# Lepší přístup: Dependency injection (Vkládání závislostí)
class Configuration:
    def __init__(self, config_dict=None):
        self._config = config_dict or {}
        
    def set(self, key, value):
        self._config[key] = value
        
    def get(self, key, default=None):
        return self._config.get(key, default)

class Service:
    def __init__(self, configuration):
        self.configuration = configuration
    
    def process(self):
        value = self.configuration.get('key', 'default')
        return f"Zpracováno s {value}"

# Použití
config = Configuration({'key': 'vlastní hodnota'})
service = Service(config)
print(service.process())  # Jasné závislosti, snazší testování a údržba
```

## 7. Strategie testování návrhových vzorů

Efektivní přístupy k testování kódu implementujícího návrhové vzory.

```python
import unittest
from unittest.mock import Mock

# Testovaná třída používající vzor Strategie
class PaymentProcessor:
    def __init__(self, strategy):
        self.strategy = strategy
    
    def process_payment(self, amount):
        return self.strategy.process(amount)

# Test používající mocky
class TestPaymentProcessor(unittest.TestCase):
    def test_payment_processing(self):
        # Vytvoření mock strategie
        mock_strategy = Mock()
        mock_strategy.process.return_value = "Platba zpracována"
        
        # Inicializace procesoru s mockem
        processor = PaymentProcessor(mock_strategy)
        
        # Testování zpracování
        result = processor.process_payment(100)
        
        # Ověření výsledku a že strategie byla správně zavolána
        self.assertEqual(result, "Platba zpracována")
        mock_strategy.process.assert_called_once_with(100)

# Spuštění testu
if __name__ == "__main__":
    unittest.main()
```

## 8. Využití v praxi

Příklady návrhových vzorů používaných v reálných Python knihovnách a frameworcích.

```python
# Django ORM: Vzor Active Record (zjednodušený příklad)
class Model:
    objects = Manager()  # V Django by to byla továrna na QuerySet
    
    def save(self):
        """Uloží aktuální instanci do databáze"""
        # Logika pro uložení do databáze
        print(f"Ukládám instanci {self.__class__.__name__} do databáze")

class User(Model):
    def __init__(self, username, email):
        self.username = username
        self.email = email
    
    def __str__(self):
        return f"Uživatel: {self.username}"

# Flask route dekorátory: Vzor Dekorátor
from functools import wraps

def route(path):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            print(f"Požadavek na cestu: {path}")
            return func(*args, **kwargs)
        wrapper.path = path  # Registrace cesty s funkcí
        return wrapper
    return decorator

@route('/home')
def home():
    return "Vítejte na domovské stránce"

@route('/about')
def about():
    return "O nás"

# Volání route funkce
print(home())  # Simuluje požadavek na /home
```

## 10. Shrnutí

4. Dynamická povaha Pythonu umožňuje jedinečné adaptace tradičních vzorů, jako jsou Mixiny a Descriptory.

7. Mnoho populárních Python knihoven a frameworků intenzivně využívá návrhové vzory.
8. Dodržujte osvědčené postupy: upřednostňujte kompozici před dědičností, udržujte implementace jednoduché a zajistěte, aby vzory řešily skutečné problémy, a ne přidávaly zbytečnou komplexitu.
9. Návrhové vzory by měly být považovány za nástroje ve vašem arzenálu, ne za řešení, která se musí vtěsnat do každého problému.
