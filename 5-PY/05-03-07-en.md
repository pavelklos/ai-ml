## 1. Introduction to Metaprogramming

Metaprogramming is the practice of writing code that manipulates code. In Python, this means writing programs that can treat other programs as their data, examining, generating, or transforming them. Python's dynamic nature makes it particularly well-suited for metaprogramming.

```python
# Basic example of metaprogramming - function that creates functions
def create_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

double = create_multiplier(2)
triple = create_multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15

# Another simple example - assigning functions dynamically
def greet(name):
    return f"Hello, {name}!"

def farewell(name):
    return f"Goodbye, {name}!"

# Choose function at runtime
greeting_type = "farewell" if input("Are you leaving? (y/n): ").lower() == 'y' else "greet"
greeting_func = locals()[greeting_type]  # Dynamically select which function to use

print(greeting_func("Alice"))  # Will call either greet or farewell based on input
```

## 2. Introspection Techniques

Introspection is the ability to examine objects at runtime. Python provides numerous tools for introspection, such as `dir()`, `type()`, `id()`, `getattr()`, `hasattr()`, `isinstance()`, and many more.

```python
import inspect

# Basic introspection
class Example:
    """A sample class for demonstration"""
    
    def __init__(self, x=1, y=2):
        self.x = x
        self.y = y
    
    def method(self, a, b=None):
        """Example method"""
        return a + b if b else a

# Get object type
obj = Example()
print(type(obj))  # <class '__main__.Example'>

# List all attributes and methods
print(dir(obj))

# Get class documentation
print(Example.__doc__)  # A sample class for demonstration

# Get method signature
print(inspect.signature(Example.method))  # (self, a, b=None)

# Get method documentation
print(inspect.getdoc(Example.method))  # Example method

# Inspect class source code
print(inspect.getsource(Example))

# Get method arguments
def some_function(a, b, c=10, *args, **kwargs):
    pass

print(inspect.getfullargspec(some_function))
# FullArgSpec(args=['a', 'b', 'c'], varargs='args', varkw='kwargs', defaults=(10,), kwonlyargs=[], kwonlydefaults=None, annotations={})
```

## 3. Dynamic Attribute Access and Modification

Python allows dynamic manipulation of object attributes at runtime, which is a powerful metaprogramming technique.

```python
# Dynamic attribute management
class DynamicObject:
    def __getattr__(self, name):
        """Called when an attribute lookup fails"""
        print(f"Attribute {name} not found")
        # Create the attribute on the fly
        self.__dict__[name] = 0
        return 0
    
    def __setattr__(self, name, value):
        """Called when an attribute is set"""
        print(f"Setting {name} to {value}")
        self.__dict__[name] = value
    
    def __delattr__(self, name):
        """Called when an attribute is deleted"""
        print(f"Deleting {name}")
        del self.__dict__[name]

# Usage
obj = DynamicObject()
print(obj.non_existent)  # Will create 'non_existent' attribute with value 0
obj.name = "Dynamic"     # Will call __setattr__
print(obj.name)          # Dynamic
del obj.name             # Will call __delattr__

# Dictionary-style attribute access
class AttrDict:
    def __init__(self, **kwargs):
        for key, value in kwargs.items():
            setattr(self, key, value)

user = AttrDict(name="John", age=30, email="john@example.com")
print(user.name)  # John

# Dynamic attribute access with getattr/setattr
class Config:
    pass

config = Config()

# Set attributes dynamically
for key, value in {'debug': True, 'log_level': 'INFO', 'max_connections': 100}.items():
    setattr(config, key, value)

# Access attributes dynamically
for attr in ['debug', 'log_level', 'max_connections', 'non_existent']:
    print(f"{attr}: {getattr(config, attr, 'Not found')}")
```

## 4. Code Generation and Execution

Python provides tools to generate, compile, and execute code at runtime, allowing for truly dynamic programming.

```python
# Simple eval example - evaluating expressions
x = 10
result = eval("x * 2 + 5")
print(result)  # 25

# Using exec to execute dynamic code blocks
code = """
def dynamic_function(x, y):
    return x * y + 10

result = dynamic_function(5, 3)
print(f"The result is {result}")
"""
exec(code)  # Will print "The result is 25"

# Creating a function dynamically
function_code = """
def greeting(name):
    return f"Hello, {name}!"
"""
namespace = {}
exec(function_code, namespace)
greet = namespace['greeting']
print(greet("World"))  # "Hello, World!"

# Compile and exec - more efficient for reusing code
compiled_code = compile("result = [i**2 for i in range(10)]", "<string>", "exec")
namespace = {}
exec(compiled_code, namespace)
print(namespace['result'])  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# Creating a function with dynamic behavior based on parameters
def make_function(operation):
    if operation == "add":
        return lambda x, y: x + y
    elif operation == "multiply":
        return lambda x, y: x * y
    else:
        return lambda x, y: None

add = make_function("add")
multiply = make_function("multiply")
print(add(5, 3))       # 8
print(multiply(5, 3))  # 15
```

## 5. Decorators as Metaprogramming Tools

Decorators are a syntactic feature that allows modifying functions or classes. They are a powerful metaprogramming tool.

```python
import functools
import time

# Basic decorator
def timer(func):
    @functools.wraps(func)  # Preserves the original function metadata
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"Function {func.__name__} took {end - start:.6f} seconds to run")
        return result
    return wrapper

@timer
def slow_function(delay=1):
    """This is a slow function"""
    time.sleep(delay)
    return "Function completed"

print(slow_function(0.5))  # Will time the execution

# Decorator with arguments
def repeat(n=3):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            results = []
            for _ in range(n):
                results.append(func(*args, **kwargs))
            return results
        return wrapper
    return decorator

@repeat(n=5)
def greet(name):
    return f"Hello, {name}!"

print(greet("World"))  # Will return a list with 5 greetings

# Class decorator
def add_properties(cls):
    cls.property1 = "value1"
    cls.property2 = "value2"
    return cls

@add_properties
class MyClass:
    def __init__(self):
        self.x = 10

obj = MyClass()
print(obj.property1)  # value1
print(MyClass.property2)  # value2

# Method decorator for class methods
def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__} with args: {args[1:]} and kwargs: {kwargs}")
        return func(*args, **kwargs)
    return wrapper

class Calculator:
    @log_calls
    def add(self, a, b):
        return a + b

calc = Calculator()
print(calc.add(5, 3))  # Will log the call and return 8
```

## 6. Metaclasses and Dynamic Class Creation

Metaclasses are classes whose instances are classes. They allow customizing class creation and behavior.

```python
# Basic metaclass
class Meta(type):
    def __new__(mcs, name, bases, attrs):
        # Add a new method to the class
        attrs['added_method'] = lambda self: f"I was added to {name}"
        # Modify existing methods
        if 'existing_method' in attrs:
            original_method = attrs['existing_method']
            attrs['existing_method'] = lambda self: f"Modified: {original_method(self)}"
        
        print(f"Creating class: {name}")
        return super().__new__(mcs, name, bases, attrs)

    def __init__(cls, name, bases, attrs):
        print(f"Initializing class: {name}")
        super().__init__(name, bases, attrs)

# Using the metaclass
class MyClass(metaclass=Meta):
    def existing_method(self):
        return "Original method"

# The metaclass will run during class creation
obj = MyClass()
print(obj.added_method())      # I was added to MyClass
print(obj.existing_method())   # Modified: Original method

# Dynamic class creation using type
def method(self):
    return "Hello from dynamic method"

DynamicClass = type('DynamicClass', (object,), {
    'x': 10,
    'y': 20,
    'method': method
})

obj = DynamicClass()
print(obj.x)          # 10
print(obj.method())   # Hello from dynamic method

# Registry metaclass pattern
class RegistryMeta(type):
    _registry = {}
    
    def __new__(mcs, name, bases, attrs):
        cls = super().__new__(mcs, name, bases, attrs)
        if name != 'BaseClass':  # Don't register the base class
            mcs._registry[name] = cls
        return cls
    
    @classmethod
    def get_registry(mcs):
        return dict(mcs._registry)

class BaseClass(metaclass=RegistryMeta):
    pass

class ClassA(BaseClass):
    pass

class ClassB(BaseClass):
    pass

print(RegistryMeta.get_registry())  # {'ClassA': <class '__main__.ClassA'>, 'ClassB': <class '__main__.ClassB'>}
```

## 7. Abstract Syntax Tree Manipulation

Python can manipulate its own abstract syntax trees (AST), allowing for code inspection, transformation, and generation.

```python
import ast

# Parse Python code to AST
code = """
def add(a, b):
    return a + b

result = add(5, 3)
"""

tree = ast.parse(code)
print(ast.dump(tree, indent=4))  # Print the AST structure

# A simple AST visitor
class FunctionVisitor(ast.NodeVisitor):
    def __init__(self):
        self.functions = []
    
    def visit_FunctionDef(self, node):
        self.functions.append(node.name)
        self.generic_visit(node)  # Visit children

visitor = FunctionVisitor()
visitor.visit(tree)
print(f"Found functions: {visitor.functions}")  # Found functions: ['add']

# AST transformation - adding debug print statements
class DebugTransformer(ast.NodeTransformer):
    def visit_FunctionDef(self, node):
        # Create print statement: print(f"Calling {func_name} with args: {args}")
        debug_print = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[
                    ast.JoinedStr(values=[
                        ast.Constant(value=f"Calling {node.name} with args: "),
                        ast.FormattedValue(
                            value=ast.Tuple(
                                elts=[ast.Name(id=arg.arg, ctx=ast.Load()) for arg in node.args.args],
                                ctx=ast.Load()
                            ),
                            conversion=-1
                        )
                    ])
                ],
                keywords=[]
            )
        )
        
        # Add the print statement at the beginning of the function body
        node.body.insert(0, debug_print)
        return node

# Apply transformation
transformed_tree = ast.fix_missing_locations(DebugTransformer().visit(tree))

# Compile and execute the transformed AST
code_object = compile(transformed_tree, "<ast>", "exec")
namespace = {}
exec(code_object, namespace)

# Call the function from the transformed AST
namespace['add'](10, 20)  # Will print "Calling add with args: (10, 20)" and return 30
```

## 8. Practical Applications

Let's explore some practical applications of metaprogramming techniques in real-world scenarios.

```python
# 1. Creating an ORM-like system
class Field:
    def __init__(self, field_type, required=False):
        self.field_type = field_type
        self.required = required

class ModelMeta(type):
    def __new__(mcs, name, bases, attrs):
        # Extract fields from class attributes
        fields = {}
        for key, value in list(attrs.items()):
            if isinstance(value, Field):
                fields[key] = value
                del attrs[key]  # Remove field from class attrs
        
        attrs['_fields'] = fields
        
        # Add validation method
        def validate(self, data):
            errors = {}
            for field_name, field in self._fields.items():
                if field_name not in data:
                    if field.required:
                        errors[field_name] = "This field is required"
                elif not isinstance(data[field_name], field.field_type):
                    errors[field_name] = f"Must be of type {field.field_type.__name__}"
            return errors
        
        attrs['validate'] = validate
        
        return super().__new__(mcs, name, bases, attrs)

class Model(metaclass=ModelMeta):
    pass

# Using our ORM-like system
class User(Model):
    name = Field(str, required=True)
    age = Field(int, required=True)
    email = Field(str, required=True)

# Validate user data
user_data = {
    "name": "John",
    "age": 30,
    # Missing email
}

user = User()
validation_errors = user.validate(user_data)
print(validation_errors)  # {'email': 'This field is required'}

# 2. Plugin system
class PluginManager:
    def __init__(self):
        self.plugins = {}
    
    def register(self, plugin_name):
        def decorator(cls):
            self.plugins[plugin_name] = cls
            return cls
        return decorator
    
    def get_plugin(self, plugin_name):
        return self.plugins.get(plugin_name)

# Create plugin manager
manager = PluginManager()

# Register plugins
@manager.register("text_processor")
class TextProcessor:
    def process(self, text):
        return text.upper()

@manager.register("number_processor")
class NumberProcessor:
    def process(self, number):
        return number * 2

# Use plugins dynamically
data = ["hello", 10, "world", 20]
processors = {
    str: manager.get_plugin("text_processor"),
    int: manager.get_plugin("number_processor")
}

for item in data:
    processor_class = processors.get(type(item))
    if processor_class:
        processor = processor_class()
        print(f"Processed {item}: {processor.process(item)}")
```

## 9. Best Practices and Limitations

Metaprogramming is powerful but should be used judiciously. Here are some best practices and limitations to consider.

```python
# BEST PRACTICE 1: Document metaprogramming clearly
class AutoProperty(type):
    """
    Metaclass that automatically creates getter and setter methods
    for attributes prefixed with '_' in the class definition.
    
    Example:
        class Person(metaclass=AutoProperty):
            _name = "Default"  # Creates name property
    """
    def __new__(mcs, name, bases, attrs):
        # Generate properties for attributes starting with '_'
        for key, value in list(attrs.items()):
            if key.startswith('_') and not key.startswith('__'):
                prop_name = key[1:]  # Remove leading underscore
                
                # Create getter
                getter_name = f"get_{prop_name}"
                if getter_name not in attrs:
                    attrs[getter_name] = lambda self, key=key: getattr(self, key)
                
                # Create setter
                setter_name = f"set_{prop_name}"
                if setter_name not in attrs:
                    attrs[setter_name] = lambda self, value, key=key: setattr(self, key, value)
                
                # Create property
                attrs[prop_name] = property(attrs[getter_name], attrs[setter_name])
        
        return super().__new__(mcs, name, bases, attrs)

# BEST PRACTICE 2: Avoid overly complex metaprogramming
# Bad example - unnecessary complexity
def create_class_with_methods(*method_names):
    attrs = {}
    for name in method_names:
        # Dynamically creating methods - hard to debug and understand
        attrs[name] = eval(f"lambda self, x: f'Called {name} with {{x}}'")
    return type('DynamicClass', (object,), attrs)

# Better approach - more explicit and readable
def create_class_with_methods_better(*method_names):
    attrs = {}
    
    def make_method(name):
        def method(self, x):
            return f"Called {name} with {x}"
        return method
    
    for name in method_names:
        attrs[name] = make_method(name)
    
    return type('DynamicClass', (object,), attrs)

# LIMITATION: Debugging can be difficult
# Example showing stack trace complexity with metaprogramming
def debug_example():
    try:
        # Create a function dynamically
        func_code = "def problematic(): return 1/0"
        namespace = {}
        exec(func_code, namespace)
        
        # Call the function
        namespace['problematic']()
    except Exception as e:
        import traceback
        print("Error occurred in dynamically created code:")
        traceback.print_exc()

debug_example()

# LIMITATION: Performance overhead
import time

# Measure performance difference between direct and dynamic invocation
def direct_function(x):
    return x * 2

def measure_performance():
    # Direct call
    start = time.time()
    for _ in range(1000000):
        direct_function(10)
    direct_time = time.time() - start
    
    # Dynamic call using getattr
    functions = {'func': direct_function}
    start = time.time()
    for _ in range(1000000):
        getattr(functions['func'], '__call__')(10)
    dynamic_time = time.time() - start
    
    print(f"Direct call time: {direct_time:.6f} seconds")
    print(f"Dynamic call time: {dynamic_time:.6f} seconds")
    print(f"Dynamic calls are {dynamic_time/direct_time:.2f}x slower")

measure_performance()
```

## 10. Summary

Metaprogramming in Python leverages the language's dynamic nature to inspect, generate, and modify code at runtime, enabling powerful programming techniques:

1. **Introspection** allows examining objects at runtime, exposing information about types, methods, and attributes.
2. **Dynamic attribute access and modification** enables creating flexible APIs and adaptable objects.
3. **Code generation and execution** permits creating and running code on the fly, adapting to changing requirements.
4. **Decorators** provide a syntax-friendly way to modify functions and classes, implementing cross-cutting concerns.
5. **Metaclasses** enable customizing class creation, enforcing constraints, or adding functionality to classes automatically.
6. **Abstract Syntax Tree manipulation** offers low-level control over code structure and execution.

These techniques enable powerful applications like ORMs, plugin systems, DSLs, and framework development. However, metaprogramming should be used judiciously as it can make code harder to understand, debug, and maintain. Always prioritize readability and provide thorough documentation when employing these advanced techniques.
