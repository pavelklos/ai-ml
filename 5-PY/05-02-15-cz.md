## 1. Úvod do oborů platnosti proměnných

V Pythonu obor platnosti proměnné určuje, kde ve vašem programu je proměnná přístupná. Python má čtyři hlavní úrovně oborů platnosti:

- **Lokální**: Proměnné definované uvnitř funkce
- **Uzavírající**: Proměnné definované ve vnějších funkcích
- **Globální**: Proměnné definované na nejvyšší úrovni modulu
- **Vestavěné**: Předdefinované názvy Pythonu (jako `print`, `len`, atd.)

Tato hierarchie se někdy označuje jako pravidlo LEGB.

```python
# Příklad různých oborů platnosti v Pythonu

x = 100  # Globální obor platnosti

def vnejsi_funkce():
    y = 200  # Uzavírající obor platnosti
    
    def vnitrni_funkce():
        z = 300  # Lokální obor platnosti
        print(f"Lokální: z = {z}")
        print(f"Uzavírající: y = {y}")
        print(f"Globální: x = {x}")
        print(f"Vestavěné: {len}")
        
    vnitrni_funkce()

vnejsi_funkce()
```

## 2. Pochopení uzávěrů

Uzávěr je funkční objekt, který si pamatuje hodnoty v uzavírajícím oboru platnosti, i když tyto hodnoty nejsou přítomny v paměti. Jednodušeji řečeno, uzávěr je funkce, která "zachycuje" a nese některé části prostředí, ve kterém byla definována.

Aby uzávěr existoval:
1. Musí existovat vnořená funkce
2. Vnořená funkce musí odkazovat na hodnotu z vnější funkce
3. Vnější funkce musí vracet vnořenou funkci

```python
def vnejsi_funkce(zprava):
    # Toto je uzavírající funkce
    
    def vnitrni_funkce():
        # Toto je vnořená funkce, která tvoří uzávěr
        print(zprava)  # Použití proměnné z vnějšího oboru platnosti
        
    return vnitrni_funkce  # Vrácení vnořené funkce

# Vytváření uzávěrů
uzaver_ahoj = vnejsi_funkce("Ahoj, světe!")
uzaver_sbohem = vnejsi_funkce("Sbohem, světe!")

# Spouštění uzávěrů
uzaver_ahoj()    # Výstup: Ahoj, světe!
uzaver_sbohem()  # Výstup: Sbohem, světe!
```

## 3. Vytváření a používání uzávěrů

Prozkoumejme více příkladů uzávěrů pro hlubší pochopení:

```python
def nasobitel(faktor):
    def nasob(cislo):
        return cislo * faktor
    return nasob

# Vytvoření uzávěrů s různými zachycenými hodnotami
zdvojnasobit = nasobitel(2)
ztrojnasobit = nasobitel(3)
zctvernasobit = nasobitel(4)

# Použití uzávěrů
print(zdvojnasobit(5))    # 10
print(ztrojnasobit(5))    # 15
print(zctvernasobit(5))   # 20

# Prozkoumání uzávěru
print(zdvojnasobit.__closure__[0].cell_contents)  # Výstup: 2
```

Uzávěry umožňují funkcím "pamatovat si" prostředí, ve kterém byly vytvořeny, a nést tento kontext s sebou kdekoli jsou použity.

## 4. Klíčová slova `nonlocal` a `global`

Při práci s vnořenými funkcemi a uzávěry může být potřeba upravit proměnné z vnějších oborů platnosti. Zde přicházejí na řadu klíčová slova `nonlocal` a `global`:

```python
# Příklad klíčového slova nonlocal
def pocitadlo():
    pocet = 0
    
    def zvys():
        nonlocal pocet  # Deklarace proměnné pocet jako nonlocal
        pocet += 1      # Úprava proměnné z vnější funkce
        return pocet
    
    return zvys

moje_pocitadlo = pocitadlo()
print(moje_pocitadlo())  # 1
print(moje_pocitadlo())  # 2
print(moje_pocitadlo())  # 3

# Příklad klíčového slova global
celkem = 0

def aktualizuj_globalni():
    global celkem  # Deklarace proměnné celkem jako global
    celkem += 1    # Úprava globální proměnné
    return celkem

print(aktualizuj_globalni())  # 1
print(aktualizuj_globalni())  # 2
print(celkem)                # 2
```

Bez klíčového slova `nonlocal` by se pokus o úpravu uzavřené proměnné mohl považovat za vytvoření nové lokální proměnné.

## 5. Běžné případy použití uzávěrů

Uzávěry jsou zvláště užitečné pro:

### Skrývání dat a zapouzdření
```python
def vytvor_ucet(pocatecni_zustatek):
    zustatek = pocatecni_zustatek
    
    def vlozit(castka):
        nonlocal zustatek
        zustatek += castka
        return zustatek
    
    def vybrat(castka):
        nonlocal zustatek
        if castka > zustatek:
            return "Nedostatek prostředků"
        zustatek -= castka
        return zustatek
    
    def zjisti_zustatek():
        return zustatek
    
    # Vrácení slovníku funkcí
    return {
        "vlozit": vlozit,
        "vybrat": vybrat,
        "zjisti_zustatek": zjisti_zustatek
    }

# Vytvoření účtu s počátečním zůstatkem 1000
ucet = vytvor_ucet(1000)

# Použití funkcí účtu
print(ucet["zjisti_zustatek"]())  # 1000
print(ucet["vlozit"](500))        # 1500
print(ucet["vybrat"](200))        # 1300
print(ucet["vybrat"](2000))       # Nedostatek prostředků
```

### Udržování stavu
```python
def vytvor_kalkulacku_prumeru():
    celkem = 0
    pocet = 0
    
    def pridat_hodnotu(hodnota):
        nonlocal celkem, pocet
        celkem += hodnota
        pocet += 1
        return celkem / pocet
    
    return pridat_hodnotu

prumer = vytvor_kalkulacku_prumeru()
print(prumer(10))  # 10.0
print(prumer(20))  # 15.0
print(prumer(30))  # 20.0
```

## 6. Továrny na funkce

Uzávěry jsou výborné pro vytváření továren na funkce - funkcí, které generují a vracejí jiné funkce:

```python
def tovarna_mocnin(exponent):
    def funkce_mocniny(zaklad):
        return zaklad ** exponent
    return funkce_mocniny

# Vytvoření specifických funkcí pro mocniny
druha_mocnina = tovarna_mocnin(2)
treti_mocnina = tovarna_mocnin(3)
odmocnina = tovarna_mocnin(0.5)

# Použití funkcí
print(druha_mocnina(4))  # 16
print(treti_mocnina(3))  # 27
print(odmocnina(16))     # 4.0

# Další příklad: Vytváření vlastních formátovacích funkcí
def tovarna_formatovace(formatovaci_retezec):
    def formatovac(hodnota):
        return formatovaci_retezec.format(hodnota)
    return formatovac

format_meny = tovarna_formatovace("${:.2f}")
format_procent = tovarna_formatovace("{:.2%}")

print(format_meny(123.456))     # $123.46
print(format_procent(0.789))    # 78.90%
```

## 7. Uzávěry vs. třídy

Jak uzávěry, tak třídy lze použít k udržování stavu, ale mají různé případy použití:

```python
# Použití uzávěru pro jednoduché počítadlo
def vytvor_pocitadlo():
    pocet = 0
    
    def zvysit():
        nonlocal pocet
        pocet += 1
        return pocet
    
    return zvysit

# Použití třídy pro počítadlo
class Pocitadlo:
    def __init__(self):
        self.pocet = 0
    
    def zvysit(self):
        self.pocet += 1
        return self.pocet

# Použití obou přístupů
pocitadlo_uzaver = vytvor_pocitadlo()
pocitadlo_trida = Pocitadlo()

print(pocitadlo_uzaver())  # 1
print(pocitadlo_uzaver())  # 2

print(pocitadlo_trida.zvysit())  # 1
print(pocitadlo_trida.zvysit())  # 2

# Kdy použít který přístup:
# - Uzávěry jsou lehčí a dobré pro jednoduchou funkcionalitu
# - Třídy jsou lepší pro složitější data a chování
```

## 8. Ladění uzávěrů

Ladění uzávěrů může být náročné, protože uzavřené proměnné nejsou snadno přístupné. Zde jsou některé techniky pro ladění:

```python
def vytvor_nasobitel(faktor):
    # Přidání ladicích informací
    print(f"Vytvářím násobitel s faktorem: {faktor}")
    
    def nasob(cislo):
        vysledek = cislo * faktor
        print(f"Násobení {cislo} faktorem {faktor}: {vysledek}")
        return vysledek
    
    # Prozkoumání uzávěru
    print(f"Funkce vytvořena. Obsah uzávěru: {nasob.__closure__}")
    return nasob

# Vytvoření a testování násobiče
zdvojnasobit = vytvor_nasobitel(2)
vysledek = zdvojnasobit(5)
print(f"Konečný výsledek: {vysledek}")

# Použití atributů pro ladění
def laditelne_pocitadlo():
    counter = laditelne_pocitadlo
    counter.pocet = 0
    
    def zvysit():
        counter.pocet += 1
        return counter.pocet
    
    return zvysit

pocet = laditelne_pocitadlo()
print(pocet())  # 1
print(pocet())  # 2
print(pocet.pocet)  # 2 - přístupné pro ladění
```

```python
def lepsi_pristup(polozky=None):
    if polozky is None:
        polozky = []
    polozky.append(1)
    return polozky

# 3. Dokumentujte chování uzávěrů
def dokumentovany_uzaver(faktor):
    """
    Vytvoří funkci násobení s daným faktorem.
    
    Args:
        faktor: Číslo, kterým se bude násobit
        
    Returns:
        Funkce, která násobí svůj argument faktorem
    """
    def nasob(cislo):
        """
        Násobí vstup uloženým faktorem.
        
        Args:
            cislo: Číslo, které má být násobeno
            
        Returns:
            Součin čísla a faktoru
        """
        return cislo * faktor
    
    return nasob

# 4. Vyhněte se nadměrnému zachytávání proměnných
def efektivni_uzaver(x):
    # Zachyťte pouze to, co potřebujete
    y = draha_vypocetni_operace(x)
    
    def vnitrni(z):
        # Používá pouze y, nezachytává celý obor platnosti
        return y * z
    
    return vnitrni
```
