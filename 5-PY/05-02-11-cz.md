## 1. Úvod do formátů souborů

Python poskytuje vynikající podporu pro práci s různými formáty souborů, což je nezbytné pro zpracování, ukládání a výměnu dat. V tomto průvodci se zaměříme na tři nejčastěji používané formáty:

- **CSV** (Comma Separated Values): Jednoduchý textový formát pro tabulková data
- **JSON** (JavaScript Object Notation): Všestranný formát pro strukturovaná data
- **Pickle**: Binární formát specifický pro Python určený k serializaci Python objektů

Každý formát má své silné stránky a vhodné případy použití. Pojďme prozkoumat, jak s nimi efektivně pracovat v Pythonu.

```python
# Základní operace se soubory v Pythonu (opakování)
# Otevření textového souboru
with open('example.txt', 'w') as file:
    file.write('Ahoj, práce se soubory v Pythonu!')

# Čtení z textového souboru
with open('example.txt', 'r') as file:
    obsah = file.read()
    print(obsah)  # Výstup: Ahoj, práce se soubory v Pythonu!
```

## 2. Práce s CSV soubory

CSV (Comma Separated Values) je jedním z nejběžnějších formátů pro ukládání a výměnu tabulkových dat. Vestavěný modul `csv` v Pythonu poskytuje funkcionalitu pro čtení a zápis do CSV souborů.

```python
import csv

# Vzorová data
data = [
    ['Jméno', 'Věk', 'Země'],
    ['Alice', 28, 'USA'],
    ['Bob', 35, 'Kanada'],
    ['Charlie', 42, 'UK'],
    ['David', 31, 'Austrálie']
]

# Zápis dat do CSV souboru
with open('lide.csv', 'w', newline='') as file:
    writer = csv.writer(file)
    writer.writerows(data)
    
print("Data byla úspěšně zapsána do CSV souboru!")

# Čtení dat z CSV souboru
with open('lide.csv', 'r') as file:
    reader = csv.reader(file)
    print("CSV data:")
    for radek in reader:
        print(radek)
```

### Použití Pandas s CSV

## 3. Práce s JSON soubory

JSON (JavaScript Object Notation) je lehký formát pro výměnu dat, který je snadno čitelný a zapisovatelný pro lidi a snadno analyzovatelný a generovatelný pro stroje. Modul `json` v Pythonu poskytuje metody pro práci s JSON daty.

```python
import json

# Vzorová data
uzivatelska_data = {
    'jmeno': 'Jan Novák',
    'vek': 30,
    'aktivni': True,
    'zajmy': ['programování', 'datová věda', 'strojové učení'],
    'kontakt': {
        'email': 'jan@example.com',
        'telefon': '+420-555-1234'
    }
}

# Zápis JSON do souboru
with open('uzivatel.json', 'w') as file:
    json.dump(uzivatelska_data, file, indent=4)
    
print("Data byla úspěšně zapsána do JSON souboru!")

# Čtení JSON ze souboru
with open('uzivatel.json', 'r') as file:
    nactena_data = json.load(file)
    
print("Načteno z JSON souboru:")
print(nactena_data)

# Převod Python objektů na JSON řetězce
json_retezec = json.dumps(uzivatelska_data, indent=4)
print("\nJSON řetězcová reprezentace:")
print(json_retezec)

# Parsování JSON řetězců do Python objektů
rozparsovana_data = json.loads(json_retezec)
print("\nRozparsované zájmy:", rozparsovana_data['zajmy'])
```

## 4. Práce s Pickle soubory

Pickle je binární protokol specifický pro Python určený k serializaci a deserializaci Python objektů. Umožňuje ukládat a načítat složité Python objekty jako seznamy, slovníky, instance tříd a další.

```python
import pickle

# Vzorová data - může být jakýkoli Python objekt
class Osoba:
    def __init__(self, jmeno, vek, zajmy):
        self.jmeno = jmeno
        self.vek = vek
        self.zajmy = zajmy
        
    def __str__(self):
        return f"{self.jmeno}, {self.vek} let, zájmy: {', '.join(self.zajmy)}"

# Vytvoření několika objektů
alice = Osoba("Alice Nováková", 28, ["AI", "robotika", "turistika"])
bob = Osoba("Bob Svoboda", 35, ["fotografie", "cestování"])

lide = [alice, bob]
datovy_slovnik = {
    "lide": lide,
    "nazev_projektu": "Demo Projekt",
    "aktivni": True
}

# Serializace (uložení) objektů do souboru
with open('data.pickle', 'wb') as file:  # Poznámka: 'wb' pro binární zápis
    pickle.dump(datovy_slovnik, file)
    
print("Data byla úspěšně serializována do pickle souboru!")

# Deserializace (načtení) objektů ze souboru
with open('data.pickle', 'rb') as file:  # Poznámka: 'rb' pro binární čtení
    nactena_data = pickle.load(file)
    
print("Načteno z pickle souboru:")
print(f"Projekt: {nactena_data['nazev_projektu']}")
print("Lidé:")
for osoba in nactena_data['lide']:
    print(f"- {osoba}")
```

## 5. Porovnání formátů souborů

Každý formát souboru má své silné a slabé stránky:

```python
import csv
import json
import pickle
import pandas as pd
import time
import os

# Vzorová data - seznam slovníků
data = [
    {"id": i, "nazev": f"Položka {i}", "hodnota": i * 10} for i in range(1, 1001)
]

# Funkce pro měření velikosti souboru
def zjisti_velikost_souboru(nazev_souboru):
    return os.path.getsize(nazev_souboru) / 1024  # Velikost v KB

# Porovnání času a velikosti souboru
vysledky = {}

# CSV
start = time.time()
with open('porovnani.csv', 'w', newline='') as file:
    writer = csv.DictWriter(file, fieldnames=["id", "nazev", "hodnota"])
    writer.writeheader()
    writer.writerows(data)
vysledky['CSV'] = {
    'cas_zapisu': time.time() - start,
    'velikost_souboru': zjisti_velikost_souboru('porovnani.csv')
}

# JSON
start = time.time()
with open('porovnani.json', 'w') as file:
    json.dump(data, file)
vysledky['JSON'] = {
    'cas_zapisu': time.time() - start,
    'velikost_souboru': zjisti_velikost_souboru('porovnani.json')
}

# Pickle
start = time.time()
with open('porovnani.pickle', 'wb') as file:
    pickle.dump(data, file)
vysledky['Pickle'] = {
    'cas_zapisu': time.time() - start,
    'velikost_souboru': zjisti_velikost_souboru('porovnani.pickle')
}

# Tisk výsledků
print("Porovnání formátů:")
print(f"{'Formát':<10} {'Čas zápisu (s)':<15} {'Velikost souboru (KB)':<15}")
print("-" * 40)
for fmt, vysledek in vysledky.items():
    print(f"{fmt:<10} {vysledek['cas_zapisu']:<15.5f} {vysledek['velikost_souboru']:<15.2f}")

print("\nShrnutí porovnání formátů:")
print("- CSV: Čitelné pro člověka, široce kompatibilní, ale omezené na tabulková data")
print("- JSON: Čitelné pro člověka, široce kompatibilní, podporuje vnořené struktury")
print("- Pickle: Specifický pro Python, podporuje všechny Python objekty, binární formát")
```

## 6. Zpracování chyb při práci se soubory

Správné zpracování chyb je při práci se soubory zásadní:

```python
import csv
import json
import pickle
import os

# Příklad zpracování chyb při operacích se soubory

def bezpecne_cteni_csv(nazev_souboru):
    try:
        with open(nazev_souboru, 'r', newline='') as file:
            reader = csv.reader(file)
            return list(reader)
    except FileNotFoundError:
        print(f"Chyba: Soubor '{nazev_souboru}' nebyl nalezen.")
        return None
    except csv.Error as e:
        print(f"CSV chyba: {e}")
        return None
    except Exception as e:
        print(f"Neočekávaná chyba: {e}")
        return None
    
def bezpecne_cteni_json(nazev_souboru):
    try:
        with open(nazev_souboru, 'r') as file:
            return json.load(file)
    except FileNotFoundError:
        print(f"Chyba: Soubor '{nazev_souboru}' nebyl nalezen.")
        return None
    except json.JSONDecodeError as e:
        print(f"JSON chyba: {e}")
        return None
    except Exception as e:
        print(f"Neočekávaná chyba: {e}")
        return None

def bezpecne_cteni_pickle(nazev_souboru):
    try:
        with open(nazev_souboru, 'rb') as file:
            return pickle.load(file)
    except FileNotFoundError:
        print(f"Chyba: Soubor '{nazev_souboru}' nebyl nalezen.")
        return None
    except pickle.UnpicklingError as e:
        print(f"Pickle chyba: {e}")
        return None
    except Exception as e:
        print(f"Neočekávaná chyba: {e}")
        return None

# Testování zpracování chyb
print("Testování zpracování chyb:")
print("1. Neexistující CSV:", bezpecne_cteni_csv("neexistujici.csv"))
print("2. Platné CSV:", bezpecne_cteni_csv("lide.csv") is not None)

# Vytvoření neplatného JSON souboru
with open('neplatny.json', 'w') as f:
    f.write('{"nazev": "Neplatný JSON s chybějící zavírací závorkou"')

print("3. Neplatný JSON:", bezpecne_cteni_json("neplatny.json"))

# Vyčištění neplatného souboru
os.remove('neplatny.json')
```

## 7. Praktické příklady a případy použití

Podívejme se na některé praktické příklady, jak se tyto formáty souborů používají:

### Správa konfigurací

```python
import json
import os

# Příklad: Správa konfigurace aplikace

# Výchozí konfigurace
vychozi_konfigurace = {
    "databaze": {
        "host": "localhost",
        "port": 5432,
        "uzivatel": "admin",
        "heslo": "vychozi_heslo"
    },
    "aplikace": {
        "ladeni": False,
        "uroven_logu": "INFO",
        "tema": "vychozi"
    },
    "cesty": {
        "data": "./data",
        "logy": "./logy"
    }
}

# Funkce pro načtení nebo vytvoření konfigurace
def nacti_konfiguraci(cesta_konfigurace="konfigurace.json"):
    if os.path.exists(cesta_konfigurace):
        try:
            with open(cesta_konfigurace, 'r') as file:
                return json.load(file)
        except Exception as e:
            print(f"Chyba při načítání konfigurace: {e}")
            print("Používám výchozí konfiguraci")
            return vychozi_konfigurace
    else:
        print(f"Konfigurační soubor nebyl nalezen. Vytvářím {cesta_konfigurace} s výchozím nastavením.")
        with open(cesta_konfigurace, 'w') as file:
            json.dump(vychozi_konfigurace, file, indent=4)
        return vychozi_konfigurace

# Použití
konfigurace = nacti_konfiguraci()
print("Aktivní konfigurace:")
import pprint
pprint.pprint(konfigurace)

# Aktualizace konfigurace
konfigurace["aplikace"]["ladeni"] = True
konfigurace["databaze"]["heslo"] = "nove_bezpecne_heslo"

# Uložení aktualizované konfigurace
with open("konfigurace.json", 'w') as file:
    json.dump(konfigurace, file, indent=4)
print("\nKonfigurace byla aktualizována a uložena!")
```

### Workflow datové analýzy

```python
import pandas as pd
import pickle
import os

# Příklad: Workflow datové analýzy

# Generování vzorových dat
if not os.path.exists("prodejni_data.csv"):
    # Vytvoření vzorových prodejních dat
    data = {
        'datum': pd.date_range(start='2023-01-01', periods=100),
        'produkt': ['Produkt A', 'Produkt B', 'Produkt C', 'Produkt D'] * 25,
        'region': ['Sever', 'Jih', 'Východ', 'Západ', 'Střed'] * 20,
        'prodeje': [round(100 * (0.5 + 0.5 * pd.np.random.random())) for _ in range(100)],
        'jednotky': [int(10 * pd.np.random.random()) + 1 for _ in range(100)]
    }
    prodeje_df = pd.DataFrame(data)
    prodeje_df.to_csv("prodejni_data.csv", index=False)
    print("Vygenerovány vzorová prodejní data")
else:
    print("Používám existující prodejní data")

# Workflow datové analýzy
def analyzuj_prodejni_data():
    # 1. Načtení CSV dat
    print("\nKrok 1: Načítání CSV dat")
    prodeje = pd.read_csv("prodejni_data.csv")
    print(f"Načteno {len(prodeje)} záznamů")
    print(prodeje.head())
    
    # 2. Provedení analýzy
    print("\nKrok 2: Analýza dat")
    analyza = {
        'celkove_prodeje': prodeje['prodeje'].sum(),
        'prumerne_prodeje': prodeje['prodeje'].mean(),
        'prodeje_podle_produktu': prodeje.groupby('produkt')['prodeje'].sum().to_dict(),
        'prodeje_podle_regionu': prodeje.groupby('region')['prodeje'].sum().to_dict(),
        'nejprodavanejsi_produkt': prodeje.groupby('produkt')['prodeje'].sum().idxmax()
    }
    print("Výsledky analýzy:")
    pprint.pprint(analyza)
    
    # 3. Uložení výsledků analýzy do JSON
    print("\nKrok 3: Ukládání výsledků do JSON")
    with open("analyza_prodeje.json", 'w') as f:
        json.dump(analyza, f, indent=4)
    
    # 4. Vytvoření a uložení modelu (pomocí pickle)
    print("\nKrok 4: Vytvoření jednoduchého predikčního modelu")
    from sklearn.model_selection import train_test_split
    from sklearn.linear_model import LinearRegression
    
    # Jednoduchý model predikce prodejů založený na jednotkách
    X = prodeje[['jednotky']]
    y = prodeje['prodeje']
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
    
    model = LinearRegression()
    model.fit(X_train, y_train)
    
    # Uložení natrénovaného modelu
    with open("prodejni_model.pickle", 'wb') as f:
        pickle.dump(model, f)
    
    # 5. Načtení a otestování modelu
    print("\nKrok 5: Testování uloženého modelu")
    with open("prodejni_model.pickle", 'rb') as f:
        nacteny_model = pickle.load(f)
    
    score = nacteny_model.score(X_test, y_test)
    print(f"R² skóre modelu: {score:.4f}")
    
    # Predikce prodejů pro 5, 10 a 15 jednotek
    testovaci_jednotky = pd.DataFrame({'jednotky': [5, 10, 15]})
    predikce = nacteny_model.predict(testovaci_jednotky)
    
    print("\nPredikce prodejů:")
    for jednotky, predikce in zip(testovaci_jednotky['jednotky'], predikce):
        print(f"{jednotky} jednotek -> {predikce:.2f} Kč prodejů")

# Spuštění workflow
try:
    analyzuj_prodejni_data()
except Exception as e:
    print(f"Chyba ve workflow: {e}")
```

## 8. Shrnutí

V tomto průvodci jsme prozkoumali tři základní formáty souborů pro programování v Pythonu a práci s daty:

- **CSV** soubory jsou vynikající pro tabulková data a jsou široce kompatibilní mezi různými systémy a aplikacemi. Modul `csv` a pandas poskytují nástroje pro práci s CSV daty.

- **JSON** soubory nabízejí flexibilní formát pro strukturovaná data s podporou vnořených objektů a polí. Modul `json` usnadňuje konverzi mezi JSON a datovými strukturami Pythonu.

- **Pickle** poskytuje serializační formát specifický pro Python, který dokáže zpracovat téměř jakýkoli Python objekt, ale měl by být používán pouze s důvěryhodnými daty kvůli bezpečnostním obavám.

Klíčové body k zapamatování:

1. Vyberte správný formát pro vaše potřeby:
   - **CSV** pro jednoduchá tabulková data a kompatibilitu
   - **JSON** pro strukturovaná data a webové aplikace
   - **Pickle** pro data specifická pro Python a složité objekty

2. Vždy používejte správné zpracování chyb při práci se soubory, abyste zajistili robustnost vašeho kódu.

3. Zvažte bezpečnostní důsledky, zejména u pickle souborů z nedůvěryhodných zdrojů.

4. Pro workflow datové analýzy zvažte použití pandas, který poskytuje vynikající integraci s těmito formáty souborů.

5. Vždy správně zavírejte soubory, nejlépe pomocí správců kontextu (`with` příkazů), abyste zajistili uvolnění zdrojů.

Zvládnutím těchto formátů souborů budete dobře vybaveni zvládat většinu požadavků na ukládání a výměnu dat ve vašich Python aplikacích.
