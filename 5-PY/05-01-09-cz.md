## 1. Úvod do funkcí

Funkce jsou znovupoužitelné bloky kódu, které provádějí konkrétní úkoly. Pomáhají organizovat kód, zlepšují čitelnost a snižují duplicitu. V Pythonu jsou funkce objekty první třídy, což znamená, že mohou být přiřazeny proměnným, předávány jako argumenty a vraceny z jiných funkcí.

```python
# Funkce umožňují organizovat a znovu používat kód
def pozdrav():
    print("Ahoj, světe!")

# Použití funkce vícekrát
pozdrav()  # Výstup: Ahoj, světe!
pozdrav()  # Výstup: Ahoj, světe!

# Funkce jako objekty
pozdrav_funkce = pozdrav  # Přiřazení funkce proměnné
pozdrav_funkce()  # Výstup: Ahoj, světe!
```

## 2. Definování a volání funkcí

V Pythonu jsou funkce definovány pomocí klíčového slova `def`, následovaného názvem funkce, závorkami a dvojtečkou. Tělo funkce je odsazeno pod definičním řádkem.

```python
# Základní definice funkce
def zobraz_zpravu():
    """Toto je dokumentační řetězec, který vysvětluje, co funkce dělá."""
    print("Učíme se o funkcích v Pythonu!")

# Volání funkce
zobraz_zpravu()  # Výstup: Učíme se o funkcích v Pythonu!

# Funkce s logikou
def zkontroluj_sude(cislo):
    if cislo % 2 == 0:
        print(f"{cislo} je sudé.")
    else:
        print(f"{cislo} je liché.")

zkontroluj_sude(4)  # Výstup: 4 je sudé.
zkontroluj_sude(7)  # Výstup: 7 je liché.
```

## 3. Parametry a argumenty

Parametry jsou proměnné uvedené v definici funkce, zatímco argumenty jsou hodnoty předané funkci při jejím volání. Parametry slouží jako zástupné symboly pro data, která budou předána.

```python
# Funkce s parametry
def pozdrav_osobu(jmeno, pozdrav="Ahoj"):
    """Pozdrav osobu s přizpůsobitelnou zprávou."""
    print(f"{pozdrav}, {jmeno}!")

# Předávání argumentů parametrům
pozdrav_osobu("Alice")  # Výstup: Ahoj, Alice!
pozdrav_osobu("Bob", "Zdravím")  # Výstup: Zdravím, Bob!

# Poziční parametry musí být před výchozími parametry
def vytvor_profil(jmeno, vek, povolani="Student"):
    profil = {
        "jmeno": jmeno,
        "vek": vek,
        "povolani": povolani
    }
    return profil

profil1 = vytvor_profil("Karolína", 25)
profil2 = vytvor_profil("David", 30, "Inženýr")
print(profil1)  # Výstup: {'jmeno': 'Karolína', 'vek': 25, 'povolani': 'Student'}
print(profil2)  # Výstup: {'jmeno': 'David', 'vek': 30, 'povolani': 'Inženýr'}
```

## 4. Návratové hodnoty

Funkce mohou odesílat data zpět volajícímu pomocí příkazu `return`. Funkce může vracet jednu hodnotu, více hodnot nebo žádnou hodnotu (což implicitně vrací `None`).

```python
# Funkce vracející jednu hodnotu
def umocni(cislo):
    """Vrátí druhou mocninu čísla."""
    return cislo ** 2

vysledek = umocni(5)
print(vysledek)  # Výstup: 25

# Funkce vracející více hodnot (jako n-tici)
def ziskej_rozmery():
    """Vrátí šířku a výšku."""
    sirka = 100
    vyska = 50
    return sirka, vyska

rozmery = ziskej_rozmery()
print(rozmery)  # Výstup: (100, 50)
print(type(rozmery))  # Výstup: <class 'tuple'>

# Rozbalení vrácených hodnot
sirka, vyska = ziskej_rozmery()
print(f"Šířka: {sirka}, Výška: {vyska}")  # Výstup: Šířka: 100, Výška: 50

# Funkce s podmíněnými návraty
def absolutni_hodnota(cislo):
    """Vrátí absolutní hodnotu čísla."""
    if cislo >= 0:
        return cislo
    else:
        return -cislo

print(absolutni_hodnota(5))   # Výstup: 5
print(absolutni_hodnota(-3))  # Výstup: 3
```

## 5. Výchozí hodnoty parametrů

Python umožňuje specifikovat výchozí hodnoty pro parametry. Tyto hodnoty jsou použity, když je funkce volána bez odpovídajícího argumentu.

```python
# Funkce s výchozími hodnotami parametrů
def mocnina(zaklad, exponent=2):
    """Vrátí základ umocněný na daný exponent."""
    return zaklad ** exponent

# Použití výchozího parametru
print(mocnina(5))      # Výstup: 25 (5^2, použití výchozí hodnoty exponent=2)
print(mocnina(5, 3))   # Výstup: 125 (5^3, přepsání výchozí hodnoty)

# Více výchozích parametrů
def vytvor_osobu(jmeno, vek=30, mesto="Praha", prace=None):
    """Vytvoří slovník představující osobu."""
    osoba = {
        "jmeno": jmeno,
        "vek": vek,
        "mesto": mesto
    }
    if prace:
        osoba["prace"] = prace
    return osoba

# Použití různých kombinací výchozích hodnot
print(vytvor_osobu("Eva"))
print(vytvor_osobu("František", 25))
print(vytvor_osobu("Gabriela", 28, "Brno"))
print(vytvor_osobu("Honza", 35, "Ostrava", "Vývojář"))

# Varování: Výchozí hodnoty jsou vytvořeny pouze jednou!
def pridej_do_seznamu(polozka, muj_seznam=[]):
    muj_seznam.append(polozka)
    return muj_seznam

print(pridej_do_seznamu("jablko"))  # Výstup: ['jablko']
print(pridej_do_seznamu("banán"))   # Výstup: ['jablko', 'banán'] - pozor!

# Lepší způsob: použít None jako výchozí hodnotu
def pridej_do_seznamu_bezpecne(polozka, muj_seznam=None):
    if muj_seznam is None:
        muj_seznam = []
    muj_seznam.append(polozka)
    return muj_seznam

print(pridej_do_seznamu_bezpecne("jablko"))    # Výstup: ['jablko']
print(pridej_do_seznamu_bezpecne("banán"))     # Výstup: ['banán']
```

## 6. Klíčové argumenty

Klíčové argumenty umožňují předávat argumenty funkci podle názvu parametru, nikoli pouze podle pozice. To činí volání funkcí čitelnějším a flexibilnějším.

```python
# Funkce s více parametry
def zobraz_info(jmeno, vek, mesto):
    """Zobrazí osobní informace."""
    print(f"Jméno: {jmeno}")
    print(f"Věk: {vek}")
    print(f"Město: {mesto}")

# Použití pozičních argumentů
zobraz_info("Jan", 25, "Brno")

# Použití klíčových argumentů (mohou být v libovolném pořadí)
zobraz_info(mesto="Praha", jmeno="Alice", vek=30)

# Kombinace pozičních a klíčových argumentů
# Poziční argumenty musí být před klíčovými argumenty
zobraz_info("Bob", mesto="Plzeň", vek=35)

# Toto by způsobilo chybu:
# zobraz_info(jmeno="Charlie", 40, mesto="Olomouc")  # SyntaxError

# Funkce, která vynucuje klíčové argumenty pomocí *
def vypocitej_celkem(*, cena, sazba_dane, sleva=0):
    """Vypočítá celkovou cenu po dani a slevě."""
    mezisoučet = cena * (1 - sleva)
    celkem = mezisoučet * (1 + sazba_dane)
    return celkem

# Toto musí být voláno s klíčovými argumenty
# vypocitej_celkem(100, 0.07)  # TypeError
print(vypocitej_celkem(cena=100, sazba_dane=0.07))  # Funguje
print(vypocitej_celkem(cena=100, sazba_dane=0.07, sleva=0.1))  # Funguje
```

## 7. Argumenty s proměnnou délkou

Python poskytuje speciální syntaxi pro přijímání proměnného počtu argumentů, což umožňuje funkcím být flexibilnější.

```python
# *args pro proměnný počet pozičních argumentů
def secti_vse(*args):
    """Sečte všechny argumenty předané funkci."""
    celkem = 0
    for cislo in args:
        celkem += cislo
    return celkem

print(secti_vse(1, 2))           # Výstup: 3
print(secti_vse(1, 2, 3, 4, 5))  # Výstup: 15

# **kwargs pro proměnný počet klíčových argumentů
def zobraz_info_osoby(**kwargs):
    """Zobrazí všechny poskytnuté informace o osobě."""
    print("Informace o osobě:")
    for klic, hodnota in kwargs.items():
        print(f"{klic}: {hodnota}")

zobraz_info_osoby(jmeno="Alice", vek=30, prace="Inženýr", mesto="Praha")

# Kombinace všech typů parametrů
def vytvor_zpravu(titulek, *args, autor="Neznámý", **kwargs):
    """Vytvoří zprávu s proměnným obsahem a metadaty."""
    print(f"Zpráva: {titulek}")
    print(f"Autor: {autor}")
    print("Obsah:")
    for i, polozka in enumerate(args, 1):
        print(f"  {i}. {polozka}")
    print("Další informace:")
    for klic, hodnota in kwargs.items():
        print(f"  {klic}: {hodnota}")

vytvor_zpravu("Čtvrtletní výsledky", 
              "Tržby vzrostly o 10 %", 
              "Zahájena nová produktová řada",
              autor="Finanční tým",
              datum="2023-04-15",
              důvěrnost="Vysoká")

# Rozbalování seznamů a slovníků do argumentů funkce
cisla = [1, 2, 3, 4, 5]
print(secti_vse(*cisla))  # Rozbalí seznam do samostatných argumentů

data_osoby = {"jmeno": "David", "vek": 42, "prace": "Vědec"}
zobraz_info_osoby(**data_osoby)  # Rozbalí slovník do klíčových argumentů
```

## 8. Lambda funkce

Lambda funkce (také nazývané anonymní funkce) jsou malé, jednořádkové funkce definované klíčovým slovem `lambda`. Jsou užitečné pro krátké operace a mohou být použity tam, kde je očekáván objekt funkce.

```python
# Základní lambda funkce
ctverec = lambda x: x ** 2
print(ctverec(5))  # Výstup: 25

# Lambda s více parametry
secti = lambda x, y: x + y
print(secti(3, 4))  # Výstup: 7

# Lambda funkce se běžně používají s vestavěnými funkcemi jako map, filter a sorted
cisla = [1, 5, 3, 9, 2, 6]

# Použití map s lambda funkcí pro umocnění všech čísel
umocnena = list(map(lambda x: x ** 2, cisla))
print(umocnena)  # Výstup: [1, 25, 9, 81, 4, 36]

# Použití filter s lambda funkcí pro získání pouze sudých čísel
suda_cisla = list(filter(lambda x: x % 2 == 0, cisla))
print(suda_cisla)  # Výstup: [2, 6]

# Použití sorted s lambda funkcí jako klíčovou funkcí
pary = [(1, 'jedna'), (3, 'tři'), (2, 'dva')]
serazene_pary = sorted(pary, key=lambda par: par[1])  # Seřazení podle řetězce
print(serazene_pary)  # Výstup: [(1, 'jedna'), (3, 'tři'), (2, 'dva')]

# Rychlý podmíněný výraz s lambda funkcí
ziskej_stav = lambda stav: "Aktivní" if stav else "Neaktivní"
print(ziskej_stav(True))   # Výstup: Aktivní
print(ziskej_stav(False))  # Výstup: Neaktivní
```

## 9. Rozsah platnosti funkcí

Proměnné definované uvnitř funkce jsou přístupné pouze v rámci této funkce (lokální rozsah), zatímco proměnné definované mimo funkce jsou přístupné i z funkcí (globální rozsah).

```python
# Globální a lokální rozsah
zprava = "Globální zpráva"  # Globální proměnná

def ukaz_zpravu():
    zprava = "Lokální zpráva"  # Lokální proměnná
    print("Uvnitř funkce:", zprava)

ukaz_zpravu()  # Výstup: Uvnitř funkce: Lokální zpráva
print("Mimo funkci:", zprava)  # Výstup: Mimo funkci: Globální zpráva

# Použití globálních proměnných uvnitř funkcí
pocitadlo = 0

def zvys():
    global pocitadlo  # Deklarace, že chceme použít globální proměnnou
    pocitadlo += 1
    print(f"Počítadlo: {pocitadlo}")

zvys()  # Výstup: Počítadlo: 1
zvys()  # Výstup: Počítadlo: 2

# Vnořené funkce a uzavírající rozsah
def vnejsi_funkce(x):
    """Demonstrace vnořených funkcí a uzávěrů."""
    
    def vnitrni_funkce(y):
        # vnitrni_funkce má přístup k proměnným z vnejsi_funkce
        return x + y
    
    return vnitrni_funkce  # Vrací vnitřní funkci

# Vytvoření uzávěru
pricti_pet = vnejsi_funkce(5)
print(pricti_pet(3))  # Výstup: 8
print(pricti_pet(7))  # Výstup: 12

# Použití nonlocal pro úpravu proměnných z uzavírajícího rozsahu
def funkce_pocitadla():
    pocet = 0
    
    def zvys():
        nonlocal pocet  # Umožňuje upravovat proměnnou pocet z uzavírajícího rozsahu
        pocet += 1
        return pocet
    
    return zvys

pocitadlo = funkce_pocitadla()
print(pocitadlo())  # Výstup: 1
print(pocitadlo())  # Výstup: 2
print(pocitadlo())  # Výstup: 3
```
