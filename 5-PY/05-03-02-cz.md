## 1. Úvod do souběžnosti

Souběžnost umožňuje více operacím postupovat v překrývajících se časových obdobích. V Pythonu existují dva hlavní přístupy k dosažení souběžnosti:

1. **Vlákna**: Více vláken běží v rámci stejného procesu a sdílejí paměťový prostor
2. **Multiprocesové zpracování**: Více procesů běží nezávisle, každý s vlastním paměťovým prostorem

Oba přístupy pomáhají efektivněji využívat systémové zdroje a zlepšit výkon aplikace pro určité typy úloh.

```python
# Jednoduchý příklad ukazující rozdíl v mentálním modelu
import threading
import multiprocessing
import time

def worker():
    print(f"Pracovník se spouští...")
    time.sleep(1)
    print(f"Pracovník dokončen")

# Přístup pomocí vláken
thread = threading.Thread(target=worker)
thread.start()
print("Hlavní vlákno pokračuje ve vykonávání")
thread.join()

# Přístup pomocí multiprocessingu
process = multiprocessing.Process(target=worker)
process.start()
print("Hlavní proces pokračuje ve vykonávání")
process.join()
```

## 2. Pochopení vláken v Pythonu

Vlákna jsou lehčí než procesy a sdílejí stejný paměťový prostor, což umožňuje efektivní komunikaci mezi vlákny. Nicméně, Globální zámek interpretu (GIL) v Pythonu omezuje skutečný paralelismus pro úlohy náročné na CPU.

Kdy používat vlákna:
- Úlohy vázané na I/O (operace se soubory, síťové požadavky, dotazy na databáze)
- Úlohy, které tráví čas čekáním na externí zdroje
- Když je vyžadován sdílený přístup do paměti

```python
import threading
import time

def odpocet(jmeno, zpozdeni):
    print(f"Vlákno {jmeno} začíná")
    citac = 5
    while citac > 0:
        time.sleep(zpozdeni)
        print(f"Vlákno {jmeno}: {citac}")
        citac -= 1
    print(f"Vlákno {jmeno} dokončeno")

# Vytvoření dvou vláken
thread1 = threading.Thread(target=odpocet, args=("A", 0.5))
thread2 = threading.Thread(target=odpocet, args=("B", 1))

# Spuštění vláken
thread1.start()
thread2.start()

# Čekání na dokončení obou vláken
print("Hlavní vlákno čeká na ostatní vlákna...")
thread1.join()
thread2.join()
print("Všechna vlákna byla dokončena")
```

## 3. Práce s modulem threading

Pythonův modul `threading` poskytuje vysokoúrovňové rozhraní pro správu vláken. Zde jsou některé z klíčových komponent:

```python
import threading
import time
import random

# Dědění od třídy Thread
class MojeVlakno(threading.Thread):
    def __init__(self, jmeno, zpozdeni):
        threading.Thread.__init__(self)
        self.jmeno = jmeno
        self.zpozdeni = zpozdeni
        
    def run(self):
        print(f"Spouštím vlákno {self.jmeno}")
        vlakno_odpocet(self.jmeno, self.zpozdeni)
        print(f"Dokončuji vlákno {self.jmeno}")
        
def vlakno_odpocet(jmeno, zpozdeni):
    citac = 3
    while citac > 0:
        time.sleep(zpozdeni)
        print(f"{jmeno}: {citac}")
        citac -= 1

# Vytvoření instancí vláken
thread1 = MojeVlakno("Vlákno-1", random.random())
thread2 = MojeVlakno("Vlákno-2", random.random())
thread3 = MojeVlakno("Vlákno-3", random.random())

# Spuštění vláken
thread1.start()
thread2.start()
thread3.start()

# Čekání na dokončení vláken
thread1.join()
thread2.join()
thread3.join()

print("Hlavní vlákno končí")
```

Další užitečné funkce pro práci s vlákny:

- `threading.active_count()`: Vrací počet aktivních objektů typu Thread
- `threading.current_thread()`: Vrací aktuální objekt typu Thread
- `threading.enumerate()`: Vrací seznam všech aktivních objektů typu Thread
- `threading.main_thread()`: Vrací hlavní objekt typu Thread

## 4. Synchronizace vláken

Když více vláken přistupuje ke sdíleným zdrojům, je synchronizace nezbytná k prevenci podmínek souběhu a zajištění integrity dat. Python poskytuje několik synchronizačních primitiv:

```python
import threading
import time

# Sdílený zdroj
citac = 0

# Zámek pro synchronizaci
citac_zamek = threading.Lock()

def zvys_citac(jmeno, zpozdeni):
    global citac
    
    for _ in range(5):
        # Pokus o získání zámku
        citac_zamek.acquire()
        try:
            aktualni_hodnota = citac
            time.sleep(zpozdeni)  # Simulace času zpracování
            citac = aktualni_hodnota + 1
            print(f"{jmeno} zvýšil čítač na {citac}")
        finally:
            # Vždy uvolnit zámek
            citac_zamek.release()

# Vytvoření vláken
thread1 = threading.Thread(target=zvys_citac, args=("Vlákno-1", 0.1))
thread2 = threading.Thread(target=zvys_citac, args=("Vlákno-2", 0.1))

# Spuštění vláken
thread1.start()
thread2.start()

# Čekání na dokončení vláken
thread1.join()
thread2.join()

print(f"Konečná hodnota čítače: {citac}")
```

Použití správce kontextu pro zámky (doporučený přístup):

```python
import threading
import time

citac = 0
citac_zamek = threading.Lock()

def zvysit_pomocí_spravce_kontextu(jmeno):
    global citac
    
    for _ in range(3):
        with citac_zamek:  # Automaticky získá a uvolní zámek
            aktualni = citac
            time.sleep(0.1)
            citac = aktualni + 1
            print(f"{jmeno} zvýšil čítač na {citac}")

# Vytvoření a spuštění vláken
vlakna = [
    threading.Thread(target=zvysit_pomocí_spravce_kontextu, args=(f"Vlákno-{i}",))
    for i in range(3)
]

for vlakno in vlakna:
    vlakno.start()
    
for vlakno in vlakna:
    vlakno.join()
    
print(f"Konečná hodnota čítače: {citac}")
```

## 5. Globální zámek interpretu (GIL)

Globální zámek interpretu (GIL) v Pythonu je mutex, který chrání přístup k objektům Pythonu a zabraňuje více vláknům současně vykonávat bytecode Pythonu. To znamená, že i s více vlákny může Python vykonávat pouze jedno vlákno současně v interpretru.

Důsledky GIL:

- Vlákna v Pythonu neposkytují skutečný paralelismus pro úlohy náročné na CPU
- Pro I/O vázané úlohy mohou vlákna stále zlepšit výkon
- Pro úlohy náročné na CPU vyžadující paralelismus je obvykle lepší multiprocesové zpracování

```python
import threading
import time

def cpu_vazana_uloha(cislo):
    # Toto je úloha náročná na CPU (výpočet Fibonacciho čísel)
    vysledek = 0
    for i in range(cislo):
        vysledek = vypocitat_fibonacci(i)
    return vysledek

def vypocitat_fibonacci(n):
    if n <= 1:
        return n
    return vypocitat_fibonacci(n-1) + vypocitat_fibonacci(n-2)

def io_vazana_uloha(cislo):
    # Toto je I/O vázaná úloha (spánek)
    time.sleep(cislo)
    return cislo

# Porovnání výkonu vláken
def spustit_ulohy_ve_vlaknech(uloha, cisla):
    cas_zacatek = time.time()
    
    vlakna = []
    for n in cisla:
        vlakno = threading.Thread(target=uloha, args=(n,))
        vlakna.append(vlakno)
        vlakno.start()
    
    for vlakno in vlakna:
        vlakno.join()
    
    cas_konec = time.time()
    return cas_konec - cas_zacatek

# Sekvenční vykonávání
def spustit_ulohy_sekvencne(uloha, cisla):
    cas_zacatek = time.time()
    
    for n in cisla:
        uloha(n)
    
    cas_konec = time.time()
    return cas_konec - cas_zacatek

# Porovnání výkonu pro I/O vázané úlohy
io_cisla = [0.5, 0.5, 0.5, 0.5]
sekvencni_io_cas = spustit_ulohy_sekvencne(io_vazana_uloha, io_cisla)
vlaknovy_io_cas = spustit_ulohy_ve_vlaknech(io_vazana_uloha, io_cisla)

print(f"I/O-vázaný sekvenční čas: {sekvencni_io_cas:.2f}s")
print(f"I/O-vázaný čas s vlákny: {vlaknovy_io_cas:.2f}s")
print(f"Zrychlení pro I/O úlohy: {sekvencni_io_cas / vlaknovy_io_cas:.2f}x")

# Porovnání výkonu pro CPU vázané úlohy
# Použijte menší čísla, abyste se vyhnuli nadměrnému času běhu
cpu_cisla = [20, 20, 20, 20]
sekvencni_cpu_cas = spustit_ulohy_sekvencne(cpu_vazana_uloha, cpu_cisla)
vlaknovy_cpu_cas = spustit_ulohy_ve_vlaknech(cpu_vazana_uloha, cpu_cisla)

print(f"CPU-vázaný sekvenční čas: {sekvencni_cpu_cas:.2f}s")
print(f"CPU-vázaný čas s vlákny: {vlaknovy_cpu_cas:.2f}s")
print(f"Zrychlení pro CPU úlohy: {sekvencni_cpu_cas / vlaknovy_cpu_cas:.2f}x")
```

## 6. Modul multiprocessing

Modul `multiprocessing` v Pythonu umožňuje vytvářet více procesů, obcházet GIL a dosahovat skutečného paralelismu. Každý proces má svůj vlastní interpret Pythonu a paměťový prostor.

```python
import multiprocessing
import time

def proces_pracovnik(jmeno, zpozdeni):
    print(f"Proces {jmeno} začíná")
    citac = 5
    while citac > 0:
        time.sleep(zpozdeni)
        print(f"Proces {jmeno}: {citac}")
        citac -= 1
    print(f"Proces {jmeno} dokončen")

if __name__ == "__main__":
    # Vždy chraňte vstupní bod při použití multiprocesingu
    
    # Vytvoření procesů
    proces1 = multiprocessing.Process(target=proces_pracovnik, args=("Alfa", 0.5))
    proces2 = multiprocessing.Process(target=proces_pracovnik, args=("Beta", 1))
    
    # Spuštění procesů
    proces1.start()
    proces2.start()
    
    # Čekání na dokončení procesů
    print("Hlavní proces čeká na ostatní procesy...")
    proces1.join()
    proces2.join()
    print("Všechny procesy byly dokončeny")
```

Ochrana `if __name__ == "__main__":` je nezbytná při používání multiprocesingu, aby se zabránilo rekurzivnímu vytváření dětských procesů.

## 7. Komunikace mezi procesy

Protože procesy nesdílejí paměť, Python poskytuje několik mechanismů pro meziprocesovou komunikaci (IPC):

```python
import multiprocessing
import time

def producent(fronta):
    """Produkuje data a vkládá je do fronty"""
    for i in range(5):
        položka = f"Položka {i}"
        fronta.put(položka)
        print(f"Vyprodukováno {položka}")
        time.sleep(1)

def konzument(fronta):
    """Spotřebovává data z fronty"""
    while True:
        položka = fronta.get()
        if položka is None:  # Kontrolní hodnota označující konec
            break
        print(f"Spotřebováno {položka}")
        time.sleep(2)

if __name__ == "__main__":
    # Vytvoření sdílené fronty
    fronta = multiprocessing.Queue()
    
    # Vytvoření procesů producenta a konzumenta
    proces_producent = multiprocessing.Process(target=producent, args=(fronta,))
    proces_konzument = multiprocessing.Process(target=konzument, args=(fronta,))
    
    # Spuštění procesů
    proces_producent.start()
    proces_konzument.start()
    
    # Čekání na dokončení producenta
    proces_producent.join()
    
    # Odeslání kontrolní hodnoty pro signalizaci konzumentovi k ukončení
    fronta.put(None)
    
    # Čekání na dokončení konzumenta
    proces_konzument.join()
    
    print("Všechny procesy byly dokončeny")
```

## 8. Fondy vláken a procesů

Objekty fond nabízejí pohodlný způsob paralelizace vykonávání funkce napříč více vstupními hodnotami a distribuují práci mezi daný počet pracovníků.

```python
import multiprocessing
import concurrent.futures
import time
import math

# CPU-intenzivní úloha
def vypocitat_prvociselne_faktory(n):
    """Výpočet prvočíselných faktorů čísla"""
    faktory = []
    d = 2
    while n > 1:
        while n % d == 0:
            faktory.append(d)
            n //= d
        d += 1
        if d*d > n and n > 1:
            faktory.append(n)
            break
    return faktory

# Příklad čísel k faktorizaci
cisla = [112272535095293, 112582705942171, 112272535095293,
         115280095190773, 115797848077099, 1099726899285419]

# Sekvenční zpracování
def spustit_sekvencne():
    start = time.time()
    vysledky = [vypocitat_prvociselne_faktory(n) for n in cisla]
    konec = time.time()
    return vysledky, konec - start

# Fond procesů
def spustit_fond_procesu():
    start = time.time()
    with concurrent.futures.ProcessPoolExecutor() as executor:
        vysledky = list(executor.map(vypocitat_prvociselne_faktory, cisla))
    konec = time.time()
    return vysledky, konec - start

# Fond vláken (nebude rychlejší pro CPU-vázané úlohy)
def spustit_fond_vlaken():
    start = time.time()
    with concurrent.futures.ThreadPoolExecutor() as executor:
        vysledky = list(executor.map(vypocitat_prvociselne_faktory, cisla))
    konec = time.time()
    return vysledky, konec - start

if __name__ == "__main__":
    print("Spouštím výpočty...")
    
    sek_vysledky, sek_cas = spustit_sekvencne()
    proc_vysledky, proc_cas = spustit_fond_procesu()
    thrd_vysledky, thrd_cas = spustit_fond_vlaken()
    
    print(f"Čas sekvenčního vykonávání: {sek_cas:.2f}s")
    print(f"Čas vykonávání fondu procesů: {proc_cas:.2f}s")
    print(f"Čas vykonávání fondu vláken: {thrd_cas:.2f}s")
    
    print(f"Zrychlení fondu procesů: {sek_cas / proc_cas:.2f}x")
    print(f"Zrychlení fondu vláken: {sek_cas / thrd_cas:.2f}x")
    
    # Ověření, že výsledky jsou stejné
    print(f"Všechny výsledky se shodují: {sek_vysledky == proc_vysledky == thrd_vysledky}")
```

Použití `concurrent.futures` pro větší kontrolu nad vykonáváním:

```python
import concurrent.futures
import time
import random

def uloha(jmeno):
    cas_spanku = random.uniform(0.5, 2)
    print(f"Úloha {jmeno} začíná (spí po dobu {cas_spanku:.2f}s)")
    time.sleep(cas_spanku)
    print(f"Úloha {jmeno} dokončena")
    return jmeno, cas_spanku

if __name__ == "__main__":
    # Použití as_completed pro získání výsledků, jakmile jsou dokončeny
    with concurrent.futures.ProcessPoolExecutor(max_workers=3) as executor:
        futures = [executor.submit(uloha, f"Úloha-{i}") for i in range(5)]
        
        print("Čekám na dokončení úloh...")
        
        for future in concurrent.futures.as_completed(futures):
            jmeno, cas_spanku = future.result()
            print(f"Získán výsledek z {jmeno} (spal po dobu {cas_spanku:.2f}s)")
```

## 9. Praktické případy použití

Podívejme se na některé reálné scénáře, kde je souběžnost užitečná:

### Webové stahování s vlákny

```python
import threading
import requests
import time

class WebovyStahovac:
    def __init__(self, url_adresy):
        self.url_adresy = url_adresy
        self.vysledky = {}
        self.zamek = threading.Lock()
        
    def stahnout_url(self, url):
        try:
            print(f"Stahuji {url}...")
            cas_zacatek = time.time()
            
            odpoved = requests.get(url, timeout=10)
            delka_obsahu = len(odpoved.text)
            
            cas_konec = time.time()
            trvani = cas_konec - cas_zacatek
            
            with self.zamek:
                self.vysledky[url] = {
                    "stavovy_kod": odpoved.status_code,
                    "delka_obsahu": delka_obsahu,
                    "cas_trvani": trvani
                }
                
            print(f"Dokončeno {url} za {trvani:.2f}s")
            
        except Exception as e:
            print(f"Chyba při stahování {url}: {e}")
            with self.zamek:
                self.vysledky[url] = {"chyba": str(e)}
    
    def stahnout_vse(self):
        vlakna = []
        
        for url in self.url_adresy:
            vlakno = threading.Thread(target=self.stahnout_url, args=(url,))
            vlakna.append(vlakno)
            vlakno.start()
        
        for vlakno in vlakna:
            vlakno.join()
        
        return self.vysledky

# Příklad použití
if __name__ == "__main__":
    url_adresy = [
        "https://www.python.org",
        "https://www.github.com",
        "https://www.wikipedia.org",
        "https://www.stackoverflow.com",
        "https://www.reddit.com"
    ]
    
    stahovac = WebovyStahovac(url_adresy)
    cas_zacatek = time.time()
    vysledky = stahovac.stahnout_vse()
    cas_konec = time.time()
    
    print("\nVýsledky stahování:")
    for url, data in vysledky.items():
        if "chyba" in data:
            print(f"{url}: Chyba - {data['chyba']}")
        else:
            print(f"{url}: Stav {data['stavovy_kod']}, "
                  f"Délka {data['delka_obsahu']} bajtů, "
                  f"Čas {data['cas_trvani']:.2f}s")
    
    print(f"\nCelkový čas: {cas_konec - cas_zacatek:.2f}s")
```

def zpracovat_obrazek(cesta_obrazku, vystupni_adresar, typ_filtru):
    """Zpracování jednoho obrázku aplikováním filtru"""
    try:
        nazev_obrazku = os.path.basename(cesta_obrazku)
        vystupni_cesta = os.path.join(vystupni_adresar, f"zpracovany_{nazev_obrazku}")
        
        # Otevření obrázku
        with Image.open(cesta_obrazku) as obrazek:
            # Aplikace filtru
            if typ_filtru == "blur":
                zpracovany = obrazek.filter(ImageFilter.BLUR)
            elif typ_filtru == "contour":
                zpracovany = obrazek.filter(ImageFilter.CONTOUR)
            elif typ_filtru == "sharpen":
                zpracovany = obrazek.filter(ImageFilter.SHARPEN)
            else:
                zpracovany = obrazek.filter(ImageFilter.DETAIL)
            
            # Uložení zpracovaného obrázku
            zpracovany.save(vystupni_cesta)
        
        return f"Zpracován {nazev_obrazku}"
    
    except Exception as e:
        return f"Chyba při zpracování {cesta_obrazku}: {str(e)}"

def zpracovat_obrazky_paralelne(cesty_obrazku, vystupni_adresar, typ_filtru, max_pracovniku=None):
    """Zpracování více obrázků paralelně pomocí fondu procesů"""
    if not os.path.exists(vystupni_adresar):
        os.makedirs(vystupni_adresar)
    
    with multiprocessing.Pool(processes=max_pracovniku) as fond:
        # Vytvoření argumentů pro každý obrázek
        argumenty = [(cesta, vystupni_adresar, typ_filtru) for cesta in cesty_obrazku]
        
        # Zpracování obrázků paralelně
        vysledky = fond.starmap(zpracovat_obrazek, argumenty)
    
    return vysledky

## 10. Shrnutí

Python nabízí dva hlavní přístupy k souběžnosti: vlákna a multiprocesové zpracování. Zde jsou hlavní poznatky:

1. **Vlákna** jsou užitečná pro I/O vázané úlohy, kde operace čekají na externí zdroje:
   - Sdílejí paměťový prostor mezi vlákny
   - Jsou omezena Globálním zámkem interpretu (GIL)
   - Vhodná pro I/O vázané operace (vstup/výstup souborů, síťové požadavky)
   - Vyžadují synchronizační mechanismy (zámky, události, semafory)

2. **Multiprocesové zpracování** je užitečné pro CPU vázané úlohy, které potřebují skutečný paralelismus:
   - Každý proces má svůj vlastní interpret Pythonu a paměťový prostor
   - Obchází omezení GIL
   - Vyžaduje meziprocesovou komunikaci (fronty, roury, sdílenou paměť)
   - Více náročné na zdroje než vlákna

3. **Kdy použít jednotlivé přístupy**:
   - Použijte vlákna pro I/O vázané úlohy s požadavky na sdílenou paměť
   - Použijte multiprocesové zpracování pro CPU vázané úlohy vyžadující paralelismus
   - Zvažte `concurrent.futures` pro jednotné API k oběma přístupům

4. **Osvědčené postupy**:
   - Vždy chraňte vstupní bod pomocí `if __name__ == "__main__"` při používání multiprocesingu
   - Používejte správce kontextu pro synchronizační primitivy
   - Používejte fondy vláken/procesů pro efektivní správu zdrojů
   - Mějte na paměti důsledky sdílených zdrojů a podmínek souběhu
   - Důkladně testujte souběžný kód pro hraniční případy

Nástroje pro souběžnost v Pythonu poskytují výkonné možnosti pro zlepšení výkonu aplikací, zvláště při práci s I/O operacemi nebo úlohami náročnými na CPU na vícejádrových systémech.
