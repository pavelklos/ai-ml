## 1. Úvod do správy balíčků

Síla Pythonu spočívá v jeho rozsáhlém ekosystému balíčků třetích stran. Nástroje pro správu balíčků vám pomáhají efektivně instalovat, aktualizovat a spravovat tyto balíčky. Zajišťují správné řešení závislostí a usnadňují sdílení požadavků vašeho projektu s ostatními.

```python
# Ekosystém balíčků Pythonu poskytuje knihovny téměř pro cokoli
# Zde jsou některé běžné případy použití:
# - Analýza dat: pandas, numpy, scipy
# - Strojové učení: scikit-learn, tensorflow, pytorch
# - Webový vývoj: flask, django, fastapi
# - Vizualizace dat: matplotlib, seaborn, plotly
# - Zpracování přirozeného jazyka: nltk, spacy
# - Zpracování obrazu: pillow, opencv
# - Web scraping: beautifulsoup4, scrapy, requests
```

## 2. Porozumění nástroji pip

pip je oficiální instalátor balíčků pro Python. Připojuje se k Python Package Index (PyPI), který hostí více než 400 000 balíčků. pip je předinstalován s Pythonem 3.4+ a stará se o stahování, instalaci a správu závislostí balíčků.

```python
# Pro kontrolu, zda je pip nainstalován, a zjištění jeho verze
# Spusťte toto v terminálu nebo příkazovém řádku:
# python -m pip --version

# Ukázkový výstup:
# pip 23.1.2 from C:\Users\username\AppData\Local\Programs\Python\Python311\Lib\site-packages\pip (python 3.11)

# Pokud pip není nainstalován, můžete jej nainstalovat pomocí:
# curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
# python get-pip.py
```

## 4. Instalace balíčků pomocí pip

Balíčky můžete instalovat z PyPI, ze systémů správy verzí nebo z lokálních souborů. pip také umožňuje specifikovat omezení verzí.

```python
# Instalace nejnovější verze balíčku
# pip install requests

# Instalace konkrétní verze
# pip install requests==2.28.1

# Instalace s omezením verzí
# pip install "requests>=2.28.0,<2.29.0"

# Instalace z GitHubu
# pip install git+https://github.com/uzivatel/repozitar.git

# Instalace z lokálního souboru
# pip install ./downloads/nejaky-balicek-1.0.0.tar.gz

# Instalace více balíčků najednou
# pip install requests matplotlib pandas

# Ukázkový kód Pythonu používající nainstalovaný balíček
import requests

response = requests.get('https://api.github.com')
if response.status_code == 200:
    print("Úspěšné připojení k GitHub API")
    print(f"Hlavičky odpovědi: {response.headers}")
else:
    print(f"Selhalo se stavovým kódem: {response.status_code}")
```

## 6. Používání souborů requirements

Soubory requirements umožňují specifikovat závislosti projektu v souboru, což usnadňuje opětovné vytvoření prostředí a sdílení s ostatními.

```python
# Vytvoření souboru requirements.txt se všemi nainstalovanými balíčky
# pip freeze > requirements.txt

# Ruční vytvoření minimálního souboru requirements:
# Příklad obsahu souboru requirements.txt:
# requests==2.28.1
# pandas>=1.5.0
# matplotlib
# numpy>=1.23.0,<2.0.0

# Instalace všech balíčků ze souboru requirements
# pip install -r requirements.txt

# Ukázkový skript Pythonu pro kontrolu, zda jsou splněny všechny požadavky:
def zkontroluj_pozadavky(nazev_souboru='requirements.txt'):
    import pkg_resources
    import re
    
    with open(nazev_souboru, 'r') as f:
        pozadavky = f.readlines()
    
    for poz in pozadavky:
        poz = poz.strip()
        if not poz or poz.startswith('#'):
            continue
        
        try:
            # Odstranění specifikátorů verzí pro jednoduchou kontrolu
            nazev_balicku = re.split(r'[<>=]', poz)[0].strip()
            pkg_resources.require(nazev_balicku)
            print(f"✓ {nazev_balicku} je nainstalován")
        except pkg_resources.DistributionNotFound:
            print(f"✗ {nazev_balicku} NENÍ nainstalován")

# Použití
# zkontroluj_pozadavky()
```

## 7. Práce s virtuálními prostředími

Virtuální prostředí vám umožňují vytvářet izolovaná prostředí Pythonu pro vaše projekty, což zabraňuje konfliktům závislostí mezi projekty.

```python
# Vytvoření virtuálního prostředí (spustit v terminálu/příkazovém řádku)
# Metoda 1: Použití venv (součást Pythonu 3.3+)
# python -m venv mojeprostredi

# Metoda 2: Použití virtualenv (musí být nejprve nainstalováno)
# pip install virtualenv
# virtualenv mojeprostredi

# Aktivace virtuálního prostředí
# Na Windows:
# mojeprostredi\Scripts\activate
# Na macOS/Linux:
# source mojeprostredi/bin/activate

# Po aktivaci by se měla změnit vaše výzva, zobrazující název prostředí
# Instalujte balíčky ve virtuálním prostředí
# pip install requests pandas

# Deaktivace virtuálního prostředí
# deactivate

# Ukázkový skript Pythonu pro kontrolu, zda běží ve virtuálním prostředí:
import sys

def zkontroluj_virtualni_prostredi():
    """Kontrola, zda běží ve virtuálním prostředí"""
    # Kontrola, zda se base_prefix liší od prefix nebo zda existuje real_prefix
    je_venv = (hasattr(sys, 'base_prefix') and sys.base_prefix != sys.prefix) or \
              hasattr(sys, 'real_prefix')
    
    if je_venv:
        print(f"Běží ve virtuálním prostředí: {sys.prefix}")
    else:
        print("Neběží ve virtuálním prostředí")
    
    return je_venv

zkontroluj_virtualni_prostredi()
```

## 8. Hledání a prozkoumávání balíčků

Před instalací balíčků je užitečné je prozkoumat, abyste se ujistili, že splňují vaše potřeby.

```python
# Pro prozkoumání balíčků můžete:
# 1. Navštívit webovou stránku PyPI: https://pypi.org
# 2. Použít pip search (když je dostupné)
# 3. Použít nástroje třetích stran jako pip-search

# Příklad: Instalace a použití pip-search
# pip install pip-search
# pip-search "vizualizace dat"

# Prozkoumání nainstalovaných balíčků
import pkg_resources

def seznam_balicku():
    """Seznam všech nainstalovaných balíčků a jejich verzí"""
    nainstalovane_balicky = [(d.project_name, d.version) for d in pkg_resources.working_set]
    for balicek, verze in sorted(nainstalovane_balicky):
        print(f"{balicek} {verze}")

def ziskej_detaily_balicku(nazev_balicku):
    """Získat podrobnosti o konkrétním balíčku"""
    try:
        balicek = pkg_resources.get_distribution(nazev_balicku)
        print(f"Balíček: {balicek.project_name}")
        print(f"Verze: {balicek.version}")
        print(f"Umístění: {balicek.location}")
        if hasattr(balicek, 'requires'):
            print("Závislosti:")
            for pozadavek in balicek.requires():
                print(f"  {pozadavek}")
    except pkg_resources.DistributionNotFound:
        print(f"Balíček '{nazev_balicku}' není nainstalován")

# Použití
# seznam_balicku()
# ziskej_detaily_balicku("requests")
```

## 9. Shrnutí

Systém správy balíčků Pythonu, s pip jako jádrem, poskytuje robustní způsob instalace, správy a sdílení knihoven třetích stran. Mezi klíčové poznatky patří:

- **pip** je oficiální instalátor balíčků pro Python, který pracuje s Python Package Index (PyPI)
- Můžete instalovat balíčky s přesnými specifikacemi verzí, aby byla zajištěna kompatibilita
- **Soubory requirements** pomáhají dokumentovat a sdílet závislosti vašeho projektu
- **Virtuální prostředí** poskytují izolované prostory pro závislosti projektů, což zabraňuje konfliktům
- Pravidelná údržba balíčků (aktualizace, audit závislostí) je nezbytná pro bezpečnost a výkon
- Porozumění základním příkazům pip pomáhá zefektivnit váš vývojový pracovní postup
- Nástroje pro prozkoumávání balíčků vám pomáhají najít správné knihovny pro vaše projekty

Efektivní správa balíčků je zásadní pro vývoj v Pythonu, umožňuje vám využívat rozsáhlý ekosystém knihoven a zároveň udržovat stabilní a reprodukovatelné prostředí. S tím, jak se vaše projekty stávají složitějšími, tyto dovednosti se stávají stále důležitějšími pro efektivní správu závislostí.
