## 1. Úvod do slovníků a množin

V Pythonu jsou slovníky a množiny dvě výkonné vestavěné datové struktury. Slovníky jsou kolekce párů klíč-hodnota, zatímco množiny jsou neuspořádané kolekce unikátních prvků. Obě poskytují rychlý přístup k datům a mají specifické případy použití v programování.

```python
# Příklad slovníku - páry klíč-hodnota
osoba = {
    "jmeno": "Alice",
    "vek": 30,
    "mesto": "Praha"
}

# Příklad množiny - kolekce unikátních prvků
prvocisla = {2, 3, 5, 7, 11, 13}
```

## 2. Vytváření a přístup ke slovníkům

Slovníky v Pythonu jsou vytvářeny pomocí složených závorek `{}` nebo konstruktorem `dict()`. Klíče musí být neměnitelné typy (řetězce, čísla, n-tice), zatímco hodnoty mohou být jakéhokoli datového typu.

```python
# Vytváření slovníků
prazdny_slovnik = {}                         # Prázdný slovník
uzivatelske_info = {"uzivatel": "jan_novak", "email": "jan@priklad.cz", "aktivni": True}
znamky = dict(matematika=95, prirodoveda=88, dejepis=82)  # Použití konstruktoru dict()

# Přístup k hodnotám slovníku pomocí klíče
print(uzivatelske_info["uzivatel"])    # Výstup: jan_novak

# Použití metody get() (vrátí None nebo výchozí hodnotu, pokud klíč neexistuje)
print(uzivatelske_info.get("email"))   # Výstup: jan@priklad.cz
print(uzivatelske_info.get("telefon", "Není k dispozici"))  # Výstup: Není k dispozici

# Úprava hodnot
uzivatelske_info["aktivni"] = False
print(uzivatelske_info)  # Výstup: {'uzivatel': 'jan_novak', 'email': 'jan@priklad.cz', 'aktivni': False}

# Přidání nových párů klíč-hodnota
uzivatelske_info["datum_registrace"] = "2023-04-15"
print(uzivatelske_info)

# Kontrola, zda klíč existuje
if "email" in uzivatelske_info:
    print("Email je:", uzivatelske_info["email"])
```

## 3. Metody a operace se slovníky

Python slovníky přicházejí s mnoha užitečnými metodami pro manipulaci a přístup k datům.

```python
student = {
    "jmeno": "Emma",
    "vek": 22,
    "predmety": ["Matematika", "Informatika", "Fyzika"],
    "znamky": {"Matematika": "A", "Informatika": "B+", "Fyzika": "A-"}
}

# Získání všech klíčů a hodnot
print(student.keys())    # Výstup: dict_keys(['jmeno', 'vek', 'predmety', 'znamky'])
print(student.values())  # Výstup: dict_values(['Emma', 22, ['Matematika', 'Informatika', 'Fyzika'], {'Matematika': 'A', 'Informatika': 'B+', 'Fyzika': 'A-'}])

# Získání párů klíč-hodnota jako n-tice
print(student.items())   # Výstup: dict_items([('jmeno', 'Emma'), ('vek', 22), ...])

# Odstraňování položek
odstraneny_vek = student.pop("vek")  # Odstraní a vrátí hodnotu
print(odstraneny_vek)       # Výstup: 22
print(student)              # 'vek' již není ve slovníku

# Odstraní a vrátí libovolný pár klíč-hodnota
posledni_polozka = student.popitem()
print(posledni_polozka)     # Vrací n-tici (klíč, hodnota)

# Vyčištění všech položek
student.clear()
print(student)              # Výstup: {}

# Aktualizace slovníku pomocí jiného slovníku
student = {"jmeno": "Emma", "vek": 22}
dalsi_info = {"obor": "Informatika", "rocnik": "Třetí"}
student.update(dalsi_info)
print(student)  # Výstup: {'jmeno': 'Emma', 'vek': 22, 'obor': 'Informatika', 'rocnik': 'Třetí'}

# Získání výchozí hodnoty, pokud klíč neexistuje (a přidání do slovníku)
pocty = {}
pocty.setdefault("jablka", 0)
pocty["jablka"] += 1
print(pocty)  # Výstup: {'jablka': 1}
```

## 4. Slovníková porozumění

Podobně jako seznamová porozumění, slovníková porozumění poskytují stručný způsob vytváření slovníků.

```python
# Vytvoření slovníku pomocí slovníkového porozumění
ctverce = {x: x**2 for x in range(1, 6)}
print(ctverce)  # Výstup: {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Slovníkové porozumění s podmínkami
sude_ctverce = {x: x**2 for x in range(1, 11) if x % 2 == 0}
print(sude_ctverce)  # Výstup: {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}

# Převod dvou seznamů do slovníku
jmena = ["Alice", "Bob", "Charlie"]
veky = [25, 30, 35]
jmeno_k_veku = {jmeno: vek for jmeno, vek in zip(jmena, veky)}
print(jmeno_k_veku)  # Výstup: {'Alice': 25, 'Bob': 30, 'Charlie': 35}

# Transformace existujícího slovníku
puvodni = {"a": 1, "b": 2, "c": 3}
umocnene = {k: v**2 for k, v in puvodni.items()}
print(umocnene)  # Výstup: {'a': 1, 'b': 4, 'c': 9}
```

## 5. Vnořené slovníky

Slovníky mohou obsahovat jiné slovníky jako hodnoty, čímž vytvářejí vnořené struktury, které jsou užitečné pro reprezentaci komplexních hierarchických dat.

```python
# Příklad vnořeného slovníku
firma = {
    "oddeleni1": {
        "nazev": "Vývoj",
        "manažer": "Alice",
        "zamestnanci": {
            "zam1": {"jmeno": "Bob", "pozice": "Vývojář"},
            "zam2": {"jmeno": "Charlie", "pozice": "QA Inženýr"}
        }
    },
    "oddeleni2": {
        "nazev": "Marketing",
        "manažer": "David",
        "zamestnanci": {
            "zam3": {"jmeno": "Eva", "pozice": "Copywriter"},
            "zam4": {"jmeno": "František", "pozice": "SEO specialista"}
        }
    }
}

# Přístup k vnořeným hodnotám
print(firma["oddeleni1"]["nazev"])  # Výstup: Vývoj
print(firma["oddeleni1"]["zamestnanci"]["zam1"]["pozice"])  # Výstup: Vývojář

# Úprava vnořených hodnot
firma["oddeleni2"]["zamestnanci"]["zam3"]["pozice"] = "Senior copywriter"

# Přidávání do vnořených slovníků
firma["oddeleni1"]["zamestnanci"]["zam5"] = {"jmeno": "Gabriela", "pozice": "DevOps"}

# Iterace vnořenými slovníky
for odd_id, odd_info in firma.items():
    print(f"Oddělení: {odd_info['nazev']}")
    print(f"Manažer: {odd_info['manažer']}")
    print("Zaměstnanci:")
    for zam_id, zam_info in odd_info['zamestnanci'].items():
        print(f"  - {zam_info['jmeno']}: {zam_info['pozice']}")
    print()
```

## 6. Úvod do množin

Množiny jsou neuspořádané kolekce unikátních prvků. Jsou užitečné pro testování členství, odstranění duplicit a matematické operace s množinami.

```python
# Vytváření množin
prazdna_mnozina = set()  # Poznámka: {} vytváří prázdný slovník, ne množinu
barvy = {"červená", "zelená", "modrá"}
cisla = set([1, 2, 3, 2, 1])  # Duplicity jsou automaticky odstraněny
print(cisla)  # Výstup: {1, 2, 3}

# Přidávání prvků do množiny
barvy.add("žlutá")
print(barvy)  # Výstup: {'modrá', 'zelená', 'žlutá', 'červená'} (pořadí se může lišit)

# Odebírání prvků z množiny
barvy.remove("zelená")  # Vyvolá KeyError, pokud prvek neexistuje
print(barvy)

barvy.discard("fialová")  # Nevyvolává chybu, pokud prvek neexistuje
print(barvy)

# Vyjmutí libovolného prvku
vyjmuty = barvy.pop()
print(vyjmuty)
print(barvy)

# Vyčištění množiny
barvy.clear()
print(barvy)  # Výstup: set()

# Testování členství (velmi rychlá operace)
ovoce = {"jablko", "banán", "třešeň"}
print("banán" in ovoce)  # Výstup: True
print("pomeranč" in ovoce)  # Výstup: False
```

## 7. Vytváření množin a operace s nimi

Množiny poskytují operace pro přidávání, odstraňování a manipulaci s prvky.

```python
# Různé způsoby vytváření množin
mnozina1 = {1, 2, 3}
mnozina2 = set([3, 4, 5])
mnozina3 = set("ahoj")  # Vytvoří množinu z písmen řetězce
print(mnozina3)  # Výstup: {'a', 'h', 'o', 'j'}

# Nalezení unikátních prvků v seznamu
seznam_s_duplicitami = [1, 2, 3, 1, 2, 5, 6, 7, 8, 5, 2]
unikatni_prvky = set(seznam_s_duplicitami)
print(unikatni_prvky)  # Výstup: {1, 2, 3, 5, 6, 7, 8}

# Množinové porozumění
suda_cisla = {x for x in range(10) if x % 2 == 0}
print(suda_cisla)  # Výstup: {0, 2, 4, 6, 8}

# Frozenset (neměnitelné množiny)
nemenna_mnozina = frozenset([1, 2, 3])
# nemenna_mnozina.add(4)  # Toto by vyvolalo AttributeError

# Převod zpět na seznam
barvy = {"červená", "zelená", "modrá"}
seznam_barev = list(barvy)
print(seznam_barev)  # Výstup: ['červená', 'zelená', 'modrá'] (pořadí se může lišit)
```

## 8. Matematické operace s množinami

Množiny v Pythonu podporují matematické operace s množinami, což umožňuje provádět operace jako sjednocení, průnik, rozdíl a symetrický rozdíl.

```python
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

# Sjednocení: prvky v A nebo B (nebo obou)
print(A.union(B))           # Výstup: {1, 2, 3, 4, 5, 6, 7, 8}
print(A | B)                # Stejná operace pomocí operátoru

# Průnik: prvky v A i B
print(A.intersection(B))    # Výstup: {4, 5}
print(A & B)                # Stejná operace pomocí operátoru

# Rozdíl: prvky v A, ale ne v B
print(A.difference(B))      # Výstup: {1, 2, 3}
print(A - B)                # Stejná operace pomocí operátoru

# Symetrický rozdíl: prvky v A nebo B, ale ne v obou
print(A.symmetric_difference(B))  # Výstup: {1, 2, 3, 6, 7, 8}
print(A ^ B)                      # Stejná operace pomocí operátoru

# Testy pro podmnožinu, nadmnožinu a disjunktní množiny
C = {1, 2}
print(C.issubset(A))        # Výstup: True (C je podmnožinou A)
print(A.issuperset(C))      # Výstup: True (A je nadmnožinou C)
print(A.isdisjoint(C))      # Výstup: False (A a C mají společné prvky)
print({9, 10}.isdisjoint(A))  # Výstup: True (žádné společné prvky)

# Aktualizační operace (modifikují původní množinu)
D = {1, 2, 3}
E = {3, 4, 5}
D.update(E)                 # Sjednocení na místě
print(D)                    # Výstup: {1, 2, 3, 4, 5}

F = {1, 2, 3, 4}
G = {3, 4, 5, 6}
F.intersection_update(G)    # Průnik na místě
print(F)                    # Výstup: {3, 4}

H = {1, 2, 3, 4, 5}
I = {4, 5, 6}
H.difference_update(I)      # Rozdíl na místě
print(H)                    # Výstup: {1, 2, 3}
```

## 9. Shrnutí

V této sekci jsme se zabývali:

- **Slovníky**: Kolekce klíč-hodnota, které poskytují rychlé vyhledávání založené na klíčích
  - Vytváření a přístup ke slovníkům
  - Metody slovníků jako `keys()`, `values()`, `items()`, `pop()` a `update()`
  - Slovníková porozumění pro stručné vytváření slovníků
  - Vnořené slovníky pro reprezentaci hierarchických dat

- **Množiny**: Neuspořádané kolekce unikátních prvků
  - Vytváření množin a základní operace s množinami
  - Přidávání a odebírání prvků
  - Množinová porozumění
  - Matematické operace s množinami (sjednocení, průnik, rozdíl)
  - Frozen množiny pro neměnné kolekce množin

Slovníky a množiny jsou základní datové struktury Pythonu s výraznými výhodami:

- Slovníky jsou ideální, když potřebujete přiřadit hodnoty ke klíčům a efektivně je načítat.
- Množiny vynikají při testování členství, eliminaci duplicit a provádění matematických operací s množinami.

Obě struktury mají průměrnou časovou složitost vyhledávání O(1), což je činí mnohem efektivnější než seznamy pro tyto operace při práci s velkým množstvím dat.
