## 1. Úvod do objektově orientovaného programování

Objektově orientované programování (OOP) je programovací paradigma, které používá "objekty" – instance tříd – ke strukturování kódu. Python je multi-paradigmatický jazyk, který plně podporuje OOP. Základní koncepty v OOP zahrnují:

- **Třídy**: Šablony pro vytváření objektů
- **Objekty**: Instance tříd
- **Atributy**: Data uložená v objektu
- **Metody**: Funkce, které definují, co objekt může dělat
- **Dědičnost**: Vytváření nových tříd z existujících
- **Polymorfismus**: Různé třídy implementující stejné rozhraní

```python
# Základní příklad třídy a objektu
class Pes:
    # Třídní atribut
    druh = "Canis familiaris"
    
    # Inicializátor / Konstruktor
    def __init__(self, jmeno, vek):
        # Instanční atributy
        self.jmeno = jmeno
        self.vek = vek
    
    # Instanční metoda
    def popis(self):
        return f"{self.jmeno} je {self.vek} let starý"
    
    # Další instanční metoda
    def mluvi(self, zvuk):
        return f"{self.jmeno} říká {zvuk}"

# Vytváření instancí třídy Pes
buddy = Pes("Buddy", 9)
miles = Pes("Miles", 4)

# Přístup k atributům a metodám
print(buddy.jmeno)                # Výstup: Buddy
print(buddy.popis())              # Výstup: Buddy je 9 let starý
print(miles.mluvi("Haf Haf"))     # Výstup: Miles říká Haf Haf
```

## 2. Základy dědičnosti tříd

Dědičnost nám umožňuje definovat třídu, která dědí všechny metody a vlastnosti z jiné třídy. Rodičovská třída se nazývá základní třída a potomek je odvozená třída.

```python
# Základní třída
class Zvire:
    def __init__(self, jmeno, druh):
        self.jmeno = jmeno
        self.druh = druh
        
    def vydej_zvuk(self):
        print("Nějaký obecný zvuk zvířete")
        
    def __str__(self):
        return f"{self.jmeno} je {self.druh}"

# Odvozená třída
class Pes(Zvire):
    def __init__(self, jmeno, plemeno):
        # Volání konstruktoru základní třídy
        super().__init__(jmeno, "Pes")
        self.plemeno = plemeno
        
    def vydej_zvuk(self):
        print("Haf!")

# Další odvozená třída
class Kocka(Zvire):
    def __init__(self, jmeno, barva):
        super().__init__(jmeno, "Kočka")
        self.barva = barva
        
    def vydej_zvuk(self):
        print("Mňau!")

# Vytvoření objektů každé třídy
obecne_zvire = Zvire("Obecné", "Zvíře")
pes = Pes("Buddy", "Zlatý retrívr")
kocka = Kocka("Mourek", "Mourovatá")

# Přístup k atributům a metodám
print(obecne_zvire)  # Výstup: Obecné je Zvíře
obecne_zvire.vydej_zvuk()  # Výstup: Nějaký obecný zvuk zvířete

print(pes)  # Výstup: Buddy je Pes
print(f"{pes.jmeno} je {pes.plemeno} {pes.druh}")  # Výstup: Buddy je Zlatý retrívr Pes
pes.vydej_zvuk()  # Výstup: Haf!

print(kocka)  # Výstup: Mourek je Kočka
kocka.vydej_zvuk()  # Výstup: Mňau!
```

## 3. Typy dědičnosti

Python podporuje různé typy dědičnosti:

1. **Jednoduchá dědičnost**: Třída dědí z jediné rodičovské třídy
2. **Vícenásobná dědičnost**: Třída dědí z více rodičovských tříd
3. **Víceúrovňová dědičnost**: Třída dědí z odvozené třídy
4. **Hierarchická dědičnost**: Více tříd dědí z jediného rodiče
5. **Hybridní dědičnost**: Kombinace různých typů dědičnosti

```python
# Jednoduchá dědičnost (již ukázáno výše s třídou Pes a Zvire)

# Vícenásobná dědičnost
class Letajici:
    def letej(self):
        print("Létám vysoko!")

class Plavajici:
    def plavej(self):
        print("Plavu rychle!")

class LetajiciRyba(Letajici, Plavajici):
    pass

# Víceúrovňová dědičnost
class Vozidlo:
    def __init__(self, nazev):
        self.nazev = nazev
    
    def get_nazev(self):
        return self.nazev

class Auto(Vozidlo):
    def __init__(self, nazev, model):
        super().__init__(nazev)
        self.model = model
    
    def get_detaily(self):
        return f"{self.get_nazev()} {self.model}"

class ElektrickeAuto(Auto):
    def __init__(self, nazev, model, kapacita_baterie):
        super().__init__(nazev, model)
        self.kapacita_baterie = kapacita_baterie
    
    def get_info_o_baterii(self):
        return f"Kapacita baterie: {self.kapacita_baterie} kWh"

# Příklady
letajici_ryba = LetajiciRyba()
letajici_ryba.letej()   # Výstup: Létám vysoko!
letajici_ryba.plavej()  # Výstup: Plavu rychle!

tesla = ElektrickeAuto("Tesla", "Model S", 100)
print(tesla.get_nazev())         # Výstup: Tesla
print(tesla.get_detaily())       # Výstup: Tesla Model S
print(tesla.get_info_o_baterii()) # Výstup: Kapacita baterie: 100 kWh
```

## 4. Přepisování metod a funkce super()

K přepisování metod dochází, když odvozená třída poskytuje specifickou implementaci pro metodu, která je již definována v její základní třídě. Funkce `super()` umožňuje volat metody z rodičovské třídy.

```python
class Tvar:
    def __init__(self, barva):
        self.barva = barva
        
    def plocha(self):
        # Základní implementace
        return 0
    
    def popis(self):
        return f"{self.barva} tvar s plochou: {self.plocha()}"

class Kruh(Tvar):
    def __init__(self, barva, polomer):
        super().__init__(barva)
        self.polomer = polomer
        
    def plocha(self):
        # Přepis metody plocha
        return 3.14159 * (self.polomer ** 2)

class Obdelnik(Tvar):
    def __init__(self, barva, sirka, vyska):
        super().__init__(barva)
        self.sirka = sirka
        self.vyska = vyska
        
    def plocha(self):
        # Přepis metody plocha
        return self.sirka * self.vyska
    
    def popis(self):
        # Přepis s dodatečnými informacemi
        zakladni_popis = super().popis()
        return f"{zakladni_popis} (šířka: {self.sirka}, výška: {self.vyska})"

# Vytvoření objektů
kruh = Kruh("červený", 5)
obdelnik = Obdelnik("modrý", 4, 6)

# Volání metod
print(kruh.popis())     # Výstup: červený tvar s plochou: 78.53975
print(obdelnik.popis()) # Výstup: modrý tvar s plochou: 24 (šířka: 4, výška: 6)
```

## 5. Polymorfismus v Pythonu

Polymorfismus umožňuje různým třídám mít metody se stejným názvem, ale různými implementacemi. Podporuje flexibilitu a znovu použitelnost kódu.

```python
# Polymorfismus s funkcí
def popis_tvaru(tvar):
    # Toto funguje pro jakýkoli objekt s metodou popis
    return tvar.popis()

# Polymorfismus s iterací
tvary = [Kruh("červený", 5), Obdelnik("modrý", 4, 6), Kruh("zelený", 8)]

# Volání stejné metody na různých objektech
for tvar in tvary:
    print(tvar.popis())
    print(f"Plocha: {tvar.plocha()}")
    print("---")

# Duck typing - forma polymorfismu
class Kachna:
    def mluv(self):
        return "Kvák!"
    
    def chodeni(self):
        return "Chodím jako kachna."

class Osoba:
    def mluv(self):
        return "Ahoj!"
    
    def chodeni(self):
        return "Chodím jako člověk."

def nech_mluvit_a_chodit(entita):
    # Žádná kontrola typu - dokud má objekt tyto metody, funguje to
    print(entita.mluv())
    print(entita.chodeni())

nech_mluvit_a_chodit(Kachna())
# Výstup:
# Kvák!
# Chodím jako kachna.

nech_mluvit_a_chodit(Osoba())
# Výstup:
# Ahoj!
# Chodím jako člověk.
```

## 6. Abstraktní základní třídy

Abstraktní základní třídy (ABCs) jsou třídy, které nemohou být inicializovány a vyžadují, aby odvozené třídy implementovaly specifické metody. Fungují jako šablona pro jiné třídy.

```python
from abc import ABC, abstractmethod

class Zvire(ABC):
    def __init__(self, jmeno):
        self.jmeno = jmeno
    
    @abstractmethod
    def vydej_zvuk(self):
        """Každé zvíře musí implementovat tuto metodu"""
        pass
    
    def predstav_se(self):
        return f"Jsem {self.jmeno} a zním takto: {self.vydej_zvuk()}"

# Toto by vyvolalo chybu, kdybychom se pokusili inicializovat Zvire přímo:
# TypeError: Can't instantiate abstract class Zvire with abstract method vydej_zvuk

class Pes(Zvire):
    def vydej_zvuk(self):
        return "Haf!"

class Kocka(Zvire):
    def vydej_zvuk(self):
        return "Mňau!"

# Vytvoření objektů
pes = Pes("Buddy")
kocka = Kocka("Mourek")

print(pes.predstav_se())  # Výstup: Jsem Buddy a zním takto: Haf!
print(kocka.predstav_se())  # Výstup: Jsem Mourek a zním takto: Mňau!

# Použití isinstance() s abstraktními základními třídami
print(isinstance(pes, Zvire))  # Výstup: True
print(isinstance(kocka, Zvire))  # Výstup: True
```

## 7. Vícenásobná dědičnost a pořadí řešení metod

Když třída dědí z více rodičovských tříd, Python používá pořadí řešení metod (Method Resolution Order, MRO) k určení, kterou metodu zavolat, pokud existují metody se stejným názvem v různých rodičovských třídách.

```python
class A:
    def proces(self):
        print("Proces třídy A")

class B:
    def proces(self):
        print("Proces třídy B")

class C(A, B):
    pass

class D(B, A):
    pass

# Vytvoření objektů
c = C()
d = D()

# Pořadí řešení metod sleduje pořadí specifikované v dědičnosti
c.proces()  # Výstup: Proces třídy A (A je před B v dědičnosti C)
d.proces()  # Výstup: Proces třídy B (B je před A v dědičnosti D)

# Prohlédnutí MRO
print(C.__mro__)  
# Výstup: (<class '__main__.C'>, <class '__main__.A'>, <class '__main__.B'>, <class 'object'>)

print(D.__mro__)
# Výstup: (<class '__main__.D'>, <class '__main__.B'>, <class '__main__.A'>, <class 'object'>)

# Příklad s super() ve vícenásobné dědičnosti
class A:
    def proces(self):
        print("Proces třídy A")
        return "A"

class B:
    def proces(self):
        print("Proces třídy B")
        return "B"

class E(A, B):
    def proces(self):
        vysledek_a = super().proces()  # Volá proces třídy A na základě MRO
        print(f"Proces třídy E, získal {vysledek_a} od rodiče")
        return "E"

e = E()
vysledek = e.proces()
# Výstup:
# Proces třídy A
# Proces třídy E, získal A od rodiče
```

## 8. Principy objektově orientovaného návrhu

Při navrhování tříd je důležité dodržovat určité principy:

1. **Zapouzdření**: Sbalení dat a metod pracujících s těmito daty do třídy a omezení přístupu k internímu stavu
2. **Dědičnost**: Modelování vztahu "je" mezi objekty
3. **Polymorfismus**: Poskytnutí jednotného rozhraní pro objekty různých typů
4. **Abstrakce**: Skrytí implementačních detailů a zobrazení pouze funkcionality
5. **Kompozice**: Vytváření složitých objektů z jednodušších objektů (upřednostnit kompozici před dědičností)

```python
# Příklad zapouzdření s privátními atributy
class BankovniUcet:
    def __init__(self, vlastnik, pocatecni_zustatek=0):
        self.vlastnik = vlastnik
        self._zustatek = pocatecni_zustatek  # Chráněný atribut (konvence)
        self.__historie_transakci = []       # Privátní atribut (name mangling)
    
    def vlozit(self, castka):
        if castka > 0:
            self._zustatek += castka
            self.__zaznamenat_transakci("vklad", castka)
            return True
        return False
    
    def vybrat(self, castka):
        if 0 < castka <= self._zustatek:
            self._zustatek -= castka
            self.__zaznamenat_transakci("výběr", castka)
            return True
        return False
    
    def get_zustatek(self):
        return self._zustatek
    
    def __zaznamenat_transakci(self, typ_transakce, castka):
        # Privátní metoda
        import datetime
        self.__historie_transakci.append({
            "typ": typ_transakce,
            "castka": castka,
            "cas": datetime.datetime.now()
        })

# Příklad kompozice
class Motor:
    def nastartovat(self):
        return "Motor nastartován"
    
    def zastavit(self):
        return "Motor zastaven"

class Auto:
    def __init__(self, znacka, model):
        self.znacka = znacka
        self.model = model
        # Kompozice: Auto má Motor
        self.motor = Motor()
    
    def nastartovat(self):
        return f"{self.znacka} {self.model}: {self.motor.nastartovat()}"
    
    def zastavit(self):
        return f"{self.znacka} {self.model}: {self.motor.zastavit()}"

# Příklady
ucet = BankovniUcet("Jan Novák", 1000)
print(ucet.get_zustatek())  # Výstup: 1000
ucet.vlozit(500)
print(ucet.get_zustatek())  # Výstup: 1500
ucet.vybrat(200)
print(ucet.get_zustatek())  # Výstup: 1300

# Ochrana přístupu
print(ucet._zustatek)      # Přístupné, ale nedoporučuje se
# print(ucet.__historie_transakci)  # Toto by vyvolalo AttributeError

moje_auto = Auto("Toyota", "Corolla")
print(moje_auto.nastartovat())  # Výstup: Toyota Corolla: Motor nastartován
print(moje_auto.zastavit())     # Výstup: Toyota Corolla: Motor zastaven
```

## 9. Praktické aplikace

Podívejme se, jak lze dědičnost a polymorfismus aplikovat v reálných scénářích:

```python
# Příklad: Systém správy zaměstnanců
class Zamestnanec:
    def __init__(self, jmeno, id_cislo):
        self.jmeno = jmeno
        self.id_cislo = id_cislo
        
    def get_plat(self):
        # Abstraktní metoda, kterou musí implementovat potomci
        raise NotImplementedError("Potomci musí implementovat get_plat()")
    
    def zobraz_info(self):
        return f"Zaměstnanec {self.jmeno} (ID: {self.id_cislo})"

class HodinovyZamestnanec(Zamestnanec):
    def __init__(self, jmeno, id_cislo, hodinova_sazba, odpracovane_hodiny):
        super().__init__(jmeno, id_cislo)
        self.hodinova_sazba = hodinova_sazba
        self.odpracovane_hodiny = odpracovane_hodiny
        
    def get_plat(self):
        return self.hodinova_sazba * self.odpracovane_hodiny
    
    def zobraz_info(self):
        zakladni_info = super().zobraz_info()
        return f"{zakladni_info}, Hodinová sazba: {self.hodinova_sazba:.2f} Kč/hod"

class ZamestnanecNaPlnyUvazek(Zamestnanec):
    def __init__(self, jmeno, id_cislo, rocni_plat):
        super().__init__(jmeno, id_cislo)
        self.rocni_plat = rocni_plat
        
    def get_plat(self):
        return self.rocni_plat / 12  # Měsíční plat
    
    def zobraz_info(self):
        zakladni_info = super().zobraz_info()
        return f"{zakladni_info}, Roční plat: {self.rocni_plat:.2f} Kč"

class ZamestnanecSProvizi(ZamestnanecNaPlnyUvazek):
    def __init__(self, jmeno, id_cislo, rocni_plat, sazba_provize, prodeje):
        super().__init__(jmeno, id_cislo, rocni_plat)
        self.sazba_provize = sazba_provize
        self.prodeje = prodeje
        
    def get_plat(self):
        zakladni_plat = super().get_plat()
        provize = self.sazba_provize * self.prodeje
        return zakladni_plat + provize
    
    def zobraz_info(self):
        zakladni_info = super().zobraz_info()
        return f"{zakladni_info}, Sazba provize: {self.sazba_provize:.1%}"

# Systém výplatních listin, který pracuje s jakýmkoli typem zaměstnance
def zpracuj_vyplatni_listiny(zamestnanci):
    print("Zpracování výplatních listin...")
    for zam in zamestnanci:
        print(f"{zam.zobraz_info()}")
        print(f"Měsíční plat: {zam.get_plat():.2f} Kč")
        print("---")

# Vytvoření zaměstnanců
zamestnanci = [
    HodinovyZamestnanec("Jan Novák", "H001", 200.0, 160),
    ZamestnanecNaPlnyUvazek("Jana Nováková", "S001", 600000.0),
    ZamestnanecSProvizi("Alice Procházková", "C001", 500000.0, 0.05, 300000.0)
]

# Zpracování výplatních listin pro všechny zaměstnance
zpracuj_vyplatni_listiny(zamestnanci)
```

## 10. Shrnutí

Objektově orientované programování v Pythonu poskytuje výkonné nástroje pro strukturování a navrhování kódu:

1. **Třídy a objekty** tvoří základ OOP, umožňují modelovat reálné entity jako softwarové objekty s atributy a chováním.

2. **Dědičnost** umožňuje znovupoužití kódu vytvářením nových tříd, které dědí atributy a metody z existujících tříd. Python podporuje jednoduchou, vícenásobnou a víceúrovňovou dědičnost.

3. **Přepisování metod** umožňuje definovat specifické implementace metod v odvozených třídách při zachování stejného rozhraní.

4. **Polymorfismus** umožňuje zacházet s objekty různých tříd, které implementují stejné rozhraní, podobným způsobem, což podporuje flexibilitu a rozšiřitelnost.

5. **Abstraktní základní třídy** pomáhají definovat rozhraní, která musí odvozené třídy implementovat, čímž zajišťují konzistenci napříč hierarchií tříd.

6. **Vícenásobná dědičnost** a pořadí řešení metod (MRO) poskytují flexibilitu, ale vyžadují pečlivý návrh, aby se předešlo složitosti.

7. **Principy návrhu OOP** jako zapouzdření, dědičnost, polymorfismus, abstrakce a kompozice vás vedou k vytváření udržovatelného a rozšiřitelného kódu.

Ovládnutím těchto konceptů můžete vytvářet dobře strukturované, udržovatelné a rozšiřitelné aplikace v Pythonu. OOP pomáhá zvládat složitost velkých systémů organizováním kódu kolem objektů, které modelují koncepty reálného světa, což činí váš kód intuitivnějším a snadněji pochopitelným.
