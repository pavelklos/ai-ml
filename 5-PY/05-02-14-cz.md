## 1. Úvod do protokolování a ladění

Efektivní protokolování a ladění jsou základními dovednostmi pro vývojáře v Pythonu. Protokolování pomáhá sledovat chování aplikace a diagnostikovat problémy, zatímco ladění umožňuje zkoumat a opravovat problémy během vývoje. Společně tvoří silný nástroj pro udržování spolehlivého softwaru.

```python
# Běžné přístupy k řešení problémů v kódu

# Přístup 1: Příkazy print (nedoporučuje se pro produkci)
def vypocitej_soucet(polozky):
    print(f"Začínám výpočet s {len(polozky)} položkami")
    celkem = 0
    for polozka in polozky:
        print(f"Přidávám položku: {polozka}")
        celkem += polozka
    print(f"Konečný součet: {celkem}")
    return celkem

# Přístup 2: Použití tvrzení pro zachycení logických chyb
def vypocitej_prumer(cisla):
    assert len(cisla) > 0, "Nelze vypočítat průměr prázdného seznamu"
    celkem = sum(cisla)
    return celkem / len(cisla)

# Přístup 3: Strukturované protokolování (lepší přístup)
import logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

def zpracuj_objednavku(objednavka):
    logger.info(f"Zpracovávám objednávku #{objednavka['id']}")
    if objednavka['status'] == 'zaplaceno':
        logger.debug(f"Detaily objednávky: {objednavka}")
        # Zpracování objednávky
        return True
    else:
        logger.warning(f"Objednávka #{objednavka['id']} není zaplacena")
        return False
```

## 2. Základní protokolování s modulem logging

Vestavěný modul `logging` v Pythonu poskytuje flexibilní framework pro emitování protokolovacích zpráv z vašich programů. Nabízí více funkcí než jednoduché příkazy print, včetně úrovní protokolování, možností formátování a schopnosti výstupu do různých cílů.

```python
import logging

# Základní konfigurace
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    filename='aplikace.log'
)

# Použití různých úrovní protokolování
logging.debug("Toto je ladící zpráva")    # Nezobrazí se (pod úrovní INFO)
logging.info("Aplikace spuštěna")
logging.warning("Konfigurační soubor nenalezen, používám výchozí hodnoty")
logging.error("Nelze zpracovat požadavek")
logging.critical("Selhalo připojení k databázi")

# Vytvoření pojmenovaného loggeru
logger = logging.getLogger("moje_aplikace")
logger.info("Tato zpráva pochází z loggeru mé aplikace")

# Úrovně protokolování podle závažnosti:
# DEBUG < INFO < WARNING < ERROR < CRITICAL
```

Úrovně protokolování poskytují způsob, jak kategorizovat zprávy podle důležitosti:
- DEBUG: Podrobné informace, obvykle cenné pouze při diagnostice problémů
- INFO: Potvrzení, že věci fungují podle očekávání
- WARNING: Indikace, že se stalo něco neočekávaného, nebo že se může v budoucnu stát
- ERROR: Kvůli závažnějšímu problému software nemohl provést nějakou funkci
- CRITICAL: Vážná chyba, indikující, že program sám může být neschopen pokračovat v běhu

## 3. Konfigurace loggerů

Protokolování lze konfigurovat několika způsoby, od jednoduchých po složité, v závislosti na potřebách vaší aplikace.

```python
import logging
import logging.config
import json
import yaml
import os

# Základní konfigurace s konzolovým a souborovým handlerem
def nastavit_zakladni_protokolovani():
    logger = logging.getLogger("moje_app")
    logger.setLevel(logging.DEBUG)
    
    # Konzolový handler
    konzole = logging.StreamHandler()
    konzole.setLevel(logging.INFO)
    konzole_format = logging.Formatter('%(name)s - %(levelname)s - %(message)s')
    konzole.setFormatter(konzole_format)
    
    # Souborový handler
    soubor_handler = logging.FileHandler("app_debug.log")
    soubor_handler.setLevel(logging.DEBUG)
    soubor_format = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')
    soubor_handler.setFormatter(soubor_format)
    
    # Přidání handlerů k loggeru
    logger.addHandler(konzole)
    logger.addHandler(soubor_handler)
    
    return logger

# Konfigurace pomocí slovníku
def nastavit_slovnikovou_konfiguraci():
    konfigurace = {
        'version': 1,
        'formatters': {
            'standard': {
                'format': '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
            },
        },
        'handlers': {
            'console': {
                'class': 'logging.StreamHandler',
                'level': 'INFO',
                'formatter': 'standard',
                'stream': 'ext://sys.stdout'
            },
            'file': {
                'class': 'logging.FileHandler',
                'level': 'DEBUG',
                'formatter': 'standard',
                'filename': 'aplikace.log',
                'mode': 'a',
            }
        },
        'loggers': {
            'moje_app': {
                'handlers': ['console', 'file'],
                'level': 'DEBUG',
                'propagate': False
            }
        }
    }
    logging.config.dictConfig(konfigurace)
    return logging.getLogger('moje_app')

# Konfigurace pomocí souboru (příklad YAML)
def nastavit_yaml_konfiguraci(konfiguracni_soubor='logging.yaml'):
    if os.path.exists(konfiguracni_soubor):
        with open(konfiguracni_soubor, 'rt') as f:
            konfigurace = yaml.safe_load(f.read())
        logging.config.dictConfig(konfigurace)
    else:
        logging.basicConfig(level=logging.INFO)
    return logging.getLogger('moje_app')

# Příklad použití
logger = nastavit_zakladni_protokolovani()
logger.debug("Ladící zpráva")
logger.info("Informační zpráva")
logger.warning("Varovná zpráva")
```

## 4. Pokročilé funkce protokolování

Modul logging nabízí mnoho pokročilých funkcí, které vám pomohou zvládnout složité požadavky na protokolování.

```python
import logging
import logging.handlers
import sys
import traceback

# Rotující soubor handler (omezuje velikost souboru)
def nastavit_rotujici_protokoly():
    logger = logging.getLogger("rotujici_priklad")
    logger.setLevel(logging.DEBUG)
    
    # 5 MB na soubor, uchovat 5 záložních souborů
    handler = logging.handlers.RotatingFileHandler(
        "aplikace.log", maxBytes=5*1024*1024, backupCount=5
    )
    formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')
    handler.setFormatter(formatter)
    logger.addHandler(handler)
    return logger

# Rotace na základě času
def nastavit_casove_protokoly():
    logger = logging.getLogger("casovy_priklad")
    logger.setLevel(logging.DEBUG)
    
    # Vytvoří nový log soubor o půlnoci
    handler = logging.handlers.TimedRotatingFileHandler(
        "aplikace.log", when="midnight", interval=1, backupCount=7
    )
    formatter = logging.Formatter('%(asctime)s - %(name)s - %(levelname)s - %(message)s')
    handler.setFormatter(formatter)
    logger.addHandler(handler)
    return logger

# Zachycení zásobníků volání s výjimkami
def protokolovat_vyjimku(logger):
    try:
        1 / 0  # Vygeneruje ZeroDivisionError
    except Exception as e:
        # Metoda 1: Jednoduše použít informace o výjimce
        logger.error("Došlo k chybě: %s", str(e), exc_info=True)
        
        # Metoda 2: Manuálně formátovat výjimku
        logger.error("Došlo k chybě: %s\n%s", str(e), traceback.format_exc())

# Vlastní třída loggeru
class VlastniAdapter(logging.LoggerAdapter):
    def process(self, msg, kwargs):
        # Přidání ID uživatele do všech protokolovacích zpráv
        user_id = kwargs.pop('user_id', 'neznámý')
        return f"[Uživatel: {user_id}] {msg}", kwargs

# Příklad použití
logger = nastavit_rotujici_protokoly()
adapter = VlastniAdapter(logger, {})

adapter.info("Uživatel se přihlásil", user_id="12345")
protokolovat_vyjimku(logger)
```

## 5. Používání Python debuggeru (pdb)

Python Debugger (pdb) je výkonný nástroj, který vám umožňuje krokovat váš kód, kontrolovat proměnné a pochopit tok programu.

```python
import pdb

def slozita_funkce(data):
    vysledek = []
    for polozka in data:
        # Nastavení breakpointu programově
        if polozka < 0:
            pdb.set_trace()  # Debugger se spustí zde, když je položka < 0
        
        zpracovana = polozka * 2
        vysledek.append(zpracovana)
    
    return vysledek

# V Pythonu 3.7+ můžete také použít vestavěnou funkci breakpoint()
def dalsi_funkce():
    x = 10
    y = 20
    breakpoint()  # Debugger se spustí zde
    z = x + y
    return z

# Příklad spuštění
data = [1, 5, -3, 10]
vysledek = slozita_funkce(data)

# pdb příkazy (k použití, když je debugger aktivní):
# n (next) - Provede aktuální řádek a přesune se na další řádek
# s (step) - Krokuje do volání funkce
# c (continue) - Pokračuje v provádění až do dalšího breakpointu
# q (quit) - Ukončí debugger
# l (list) - Zobrazí aktuální umístění v kódu
# p výraz - Vypíše hodnotu výrazu
# pp výraz - Formátovaný výpis hodnoty výrazu
# h (help) - Zobrazí nápovědu
# b číslo_řádku - Nastaví breakpoint na daném čísle řádku
```

### Použití pdb s post-mortem laděním

```python
import pdb

def deleni(a, b):
    return a / b

def vypocet():
    try:
        vysledek = deleni(10, 0)
    except Exception:
        # Vstoupit do post-mortem debuggingu, když dojde k výjimce
        pdb.post_mortem()
        # nebo: pdb.pm()  

# Spusťte toto ve skriptu
# vypocet()

# Pro ladění traceback z výjimky, která již nastala:
def demonstrovat_pm():
    import sys
    import traceback
    
    try:
        deleni(1, 0)
    except Exception:
        # Uložení informací o traceback
        typ, hodnota, tb = sys.exc_info()
        traceback.print_exc()
        pdb.pm()  # Spustit post-mortem ladění
```

## 6. Pomocníci pro ladění a osvědčené postupy

Kromě základního protokolování a pdb nabízí Python další nástroje a techniky, které pomáhají při ladění.

```python
# Použití tvrzení pro ladění
def vypocitej_slevu(cena, sazba_slevy):
    assert 0 <= sazba_slevy <= 1, f"Sazba slevy musí být mezi 0 a 1, dostali jsme {sazba_slevy}"
    return cena * (1 - sazba_slevy)

# Příklad vlastního ladícího dekorátoru
import functools
import time

def ladeni_volani_funkci(funkce):
    """Dekorátor, který protokoluje volání funkcí s argumenty a návratovými hodnotami"""
    @functools.wraps(funkce)
    def obal(*args, **kwargs):
        repr_args = [repr(a) for a in args]
        repr_kwargs = [f"{k}={v!r}" for k, v in kwargs.items()]
        podpis = ", ".join(repr_args + repr_kwargs)
        
        print(f"Volám {funkce.__name__}({podpis})")
        cas_zacatku = time.time()
        
        try:
            vysledek = funkce(*args, **kwargs)
            print(f"{funkce.__name__} vrátil {vysledek!r}")
        except Exception as e:
            print(f"{funkce.__name__} vyvolal {type(e).__name__}: {e}")
            raise
        finally:
            cas_konce = time.time()
            print(f"{funkce.__name__} zabral {(cas_konce - cas_zacatku)*1000:.2f}ms k vykonání")
        
        return vysledek
    return obal

@ladeni_volani_funkci
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Příklad použití
vysledek = fibonacci(5)

# Osvědčené postupy pro ladění:
# 1. Používejte smysluplné názvy proměnných
# 2. Přidejte komentáře ke složitým částem
# 3. Rozdělte složité funkce na menší
# 4. Používejte typové nápovědy pro zachycení typových chyb brzy
```

## 7. Ladění v produkčním prostředí

V produkčním prostředí musí být strategie ladění odlišné kvůli výkonnostním úvahám a bezpečnostním obavám.

```python
import logging
import sys
import traceback
from logging.handlers import SMTPHandler, RotatingFileHandler

# Nastavení produkčního protokolování
def nastavit_produkcni_protokolovani():
    # Logger aplikace
    logger = logging.getLogger('moje_app')
    logger.setLevel(logging.INFO)
    
    # Běžné protokoly aplikace
    soubor_handler = RotatingFileHandler(
        'aplikace.log', maxBytes=10*1024*1024, backupCount=10
    )
    soubor_handler.setFormatter(logging.Formatter(
        '%(asctime)s %(levelname)s: %(message)s [v %(pathname)s:%(lineno)d]'
    ))
    soubor_handler.setLevel(logging.INFO)
    logger.addHandler(soubor_handler)
    
    # Protokoly chyb s e-mailovými upozorněními pro kritické chyby
    if not sys.debug:  # Pouze v produkci
        mail_handler = SMTPHandler(
            mailhost=('smtp.example.com', 587),
            fromaddr='server@example.com',
            toaddrs=['admin@example.com'],
            subject='Chyba aplikace',
            credentials=('username', 'password'),
            secure=()
        )
        mail_handler.setLevel(logging.ERROR)
        logger.addHandler(mail_handler)
        
    return logger

# Globální obsluha výjimek
def nakonfiguruj_globalni_obsluhu_vyjimek(logger):
    def zpracuj_vyjimku(typ_exc, hodnota_exc, traceback_exc):
        if issubclass(typ_exc, KeyboardInterrupt):
            # Neprotokolujte přerušení klávesou (Ctrl+C)
            sys.__excepthook__(typ_exc, hodnota_exc, traceback_exc)
            return
            
        logger.critical("Nezachycená výjimka", 
                      exc_info=(typ_exc, hodnota_exc, traceback_exc))
    
    sys.excepthook = zpracuj_vyjimku

# Strukturované kontextové protokolování pro sledování požadavků/uživatelů
class AdapterKontextuPozadavku(logging.LoggerAdapter):
    def process(self, msg, kwargs):
        id_pozadavku = self.extra.get('id_pozadavku', 'neznámý')
        id_uzivatele = self.extra.get('id_uzivatele', 'anonymní')
        return f"[Požadavek: {id_pozadavku}][Uživatel: {id_uzivatele}] {msg}", kwargs

# Příklad protokolování v kontextu webové aplikace
def zpracuj_pozadavek(pozadavek, logger):
    kontext = {
        'id_pozadavku': pozadavek.get('id', 'neznámý'),
        'id_uzivatele': pozadavek.get('id_uzivatele', 'anonymní')
    }
    pozadavek_logger = AdapterKontextuPozadavku(logger, kontext)
    
    try:
        pozadavek_logger.info("Zpracovávám požadavek")
        # Zpracování požadavku...
        if 'chyba' in pozadavek:
            raise ValueError("Neplatný parametr požadavku")
        pozadavek_logger.info("Požadavek úspěšně zpracován")
        return {"status": "úspěch"}
    except Exception as e:
        pozadavek_logger.error(f"Chyba při zpracování požadavku: {str(e)}", exc_info=True)
        return {"status": "chyba", "zpráva": str(e)}

# Příklad použití
logger = nastavit_produkcni_protokolovani()
nakonfiguruj_globalni_obsluhu_vyjimek(logger)

falesny_pozadavek = {
    'id': '12345',
    'id_uzivatele': 'uzivatel789',
    'chyba': True
}

odpoved = zpracuj_pozadavek(falesny_pozadavek, logger)
```

## 8. Shrnutí

Efektivní protokolování a ladění jsou základními dovednostmi pro vývoj v Pythonu. Klíčové body, které je třeba si zapamatovat, jsou:

1. **Používejte modul logging** namísto příkazů print pro řádnou správu protokolů.

2. **Nakonfigurujte protokolování vhodně** pro potřeby vaší aplikace, se správnými úrovněmi protokolů, handlery a formáty.

3. **Vyberte správnou úroveň protokolování**, abyste zajistili, že zachytíte nezbytné informace bez zahlcení vašich protokolů.

4. **Python debugger (pdb)** poskytuje výkonné nástroje pro interaktivní ladění během vývoje.

5. **Pokročilé techniky protokolování** jako rotace protokolů, vlastní formáty a kontextové adaptéry pomáhají spravovat protokoly ve složitých aplikacích.

6. **Osvědčené postupy ladění** zahrnují používání tvrzení, vlastních dekorátorů a udržování jasného, testovatelného kódu.

7. **Produkční ladění** vyžaduje zvláštní pozornost pro bezpečnost, výkon a zachycení dostatečného kontextu k diagnostice problémů.

Zvládnutím těchto technik budete lépe vybaveni pro vývoj, údržbu a řešení problémů s Python aplikacemi během celého jejich životního cyklu.
