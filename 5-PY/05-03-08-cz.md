## 1. Úvod do vnitřních mechanismů Pythonu

Vnitřní mechanismy Pythonu odkazují na mechanismy a struktury, které pohánějí jazyk v zákulisí. Pochopení těchto interních mechanismů vám umožní získat hlubší vhled do fungování Pythonu, optimalizovat váš kód a řešit složité problémy při ladění.

```python
# Exekuční model Pythonu ve zkratce
def simple_function():
    x = 10
    y = 20
    return x + y

# Když zavoláte tuto funkci, Python:
# 1. Zkompiluje ji do bajtkódu
# 2. Vytvoří objektový rámec pro provedení funkce
# 3. Provede bajtkód v interpreteru
# 4. Vrátí výsledek a uklidí
```

## 2. Přehled modulu sys

Modul `sys` poskytuje přístup k proměnným a funkcím, které silně interagují s interpreterem Pythonu. Umožňuje přístup k systémově specifickým parametrům a funkcím.

```python
import sys

# Informace o verzi Pythonu
print(f"Verze Pythonu: {sys.version}")
print(f"Informace o verzi: {sys.version_info}")

# Argumenty příkazové řádky
print(f"Argumenty příkazové řádky: {sys.argv}")

# Cesty pro vyhledávání modulů
print(f"Cesty pro vyhledávání modulů:")
for path in sys.path:
    print(f"  {path}")

# Informace o platformě
print(f"Platforma: {sys.platform}")

# Vestavěné moduly
print(f"Počet vestavěných modulů: {len(sys.builtin_module_names)}")
print(f"Ukázka vestavěných modulů: {list(sys.builtin_module_names)[:5]}")
```

## 3. Introspekce za běhu pomocí modulu sys

Modul `sys` umožňuje zkoumat a manipulovat s běhovým prostředím Pythonu.

```python
import sys

# Získání aktuálního počtu referencí pro objekt
x = "Hello, World!"
print(f"Počet referencí pro x: {sys.getrefcount(x)}")

# Aktuální informace o výjimce
try:
    1/0
except Exception:
    exc_type, exc_value, exc_traceback = sys.exc_info()
    print(f"Typ výjimky: {exc_type}")
    print(f"Hodnota výjimky: {exc_value}")

# Získání aktuálních rámců
def inspect_frames():
    frame = sys._current_frames()
    for thread_id, current_frame in frame.items():
        print(f"ID vlákna: {thread_id}")
        print(f"Název souboru rámce: {current_frame.f_code.co_filename}")
        print(f"Název rámce: {current_frame.f_code.co_name}")

inspect_frames()

# Limit rekurze
print(f"Aktuální limit rekurze: {sys.getrecursionlimit()}")
sys.setrecursionlimit(2000)  # Zvýšení limitu (buďte opatrní!)
print(f"Nový limit rekurze: {sys.getrecursionlimit()}")
```

## 4. Správa paměti a zdrojů

Modul `sys` poskytuje nástroje pro monitorování a správu využití paměti a systémových zdrojů.

```python
import sys
import gc

# Získání velikosti objektu v bajtech
sample_list = [1, 2, 3, 4, 5]
print(f"Velikost seznamu: {sys.getsizeof(sample_list)} bajtů")
print(f"Velikost celého čísla: {sys.getsizeof(42)} bajtů")
print(f"Velikost řetězce: {sys.getsizeof('Hello World')} bajtů")

# Složitější příklad - porovnání velikostí datových struktur
empty_list = []
empty_dict = {}
empty_set = set()
empty_tuple = ()

print(f"Prázdný seznam: {sys.getsizeof(empty_list)} bajtů")
print(f"Prázdný slovník: {sys.getsizeof(empty_dict)} bajtů")
print(f"Prázdná množina: {sys.getsizeof(empty_set)} bajtů")
print(f"Prázdná n-tice: {sys.getsizeof(empty_tuple)} bajtů")

# Správa paměti s interakcí garbage collectoru
gc.collect()  # Vynucené uvolnění paměti
print(f"Prahy garbage collectoru: {gc.get_threshold()}")
print(f"Počet garbage collection: {gc.get_count()}")
```

## 5. Modul inspect

Modul `inspect` poskytuje funkce pro získání informací o živých objektech, jako jsou moduly, třídy, metody a funkce. Může zkoumat zdrojový kód a získávat informace o objektech.

```python
import inspect

# Definice ukázkové funkce a třídy pro inspekci
def sample_function(arg1, arg2="default", *args, **kwargs):
    """Toto je ukázková funkce pro demonstraci."""
    return arg1 + arg2

class SampleClass:
    """Ukázková třída pro demonstraci."""
    
    def __init__(self, value):
        self.value = value
    
    def method(self, x):
        """Ukázková metoda."""
        return self.value * x

# Získání zdrojového kódu
print(inspect.getsource(sample_function))
print(inspect.getsource(SampleClass))

# Získání signatury funkce
print(inspect.signature(sample_function))

# Získání dokumentace
print(inspect.getdoc(SampleClass))
print(inspect.getdoc(SampleClass.method))

# Kontrola, zda je objekt funkce, metoda, třída atd.
print(f"Je funkcí: {inspect.isfunction(sample_function)}")
print(f"Je třídou: {inspect.isclass(SampleClass)}")
print(f"Je metodou: {inspect.ismethod(SampleClass.method)}")  # False, protože není vázána na instanci
instance = SampleClass(10)
print(f"Je metodou (instance): {inspect.ismethod(instance.method)}")  # True
```

## 6. Techniky inspekce kódu

Prozkoumejme pokročilejší techniky inspekce kódu pomocí modulu `inspect`.

```python
import inspect

# Získání informací o zásobníku rámců
def function1():
    function2()

def function2():
    function3()

def function3():
    frame_info = inspect.stack()
    for frame in frame_info:
        print(f"Rámec: {frame.function} v {frame.filename}:{frame.lineno}")

function1()

# Inspekce modulu
import random
print("\nInspekce modulu random:")
for name, obj in inspect.getmembers(random):
    if inspect.isfunction(obj):
        print(f"Funkce: {name}, {obj.__doc__?.split('.')[0] or 'Bez dokumentace'}")

# Zkoumání parametrů funkce
def complex_function(a, b=1, *args, c=None, **kwargs):
    pass

signature = inspect.signature(complex_function)
for param_name, param in signature.parameters.items():
    print(f"Parametr: {param_name}, typ: {param.kind}, výchozí hodnota: {param.default if param.default is not param.empty else 'Bez výchozí hodnoty'}")

# Získání zdrojových řádků funkce
lines, start_line = inspect.getsourcelines(complex_function)
print(f"Funkce začíná na řádku {start_line} a má {len(lines)} řádků kódu")
```

## 7. Modul dis a bajtkód

Modul `dis` rozkládá bajtkód Pythonu do čitelnějšího formátu, což umožňuje pochopit, co se děje uvnitř provádění Pythonu.

```python
import dis

# Disassemblování jednoduché funkce
def add(a, b):
    return a + b

print("Disassemblování funkce add:")
dis.dis(add)

# Složitější příklad
def complex_example(x, y):
    if x > y:
        return x - y
    else:
        z = x + y
        return z * 2

print("\nDisassemblování složité funkce:")
dis.dis(complex_example)

# Disassemblování list comprehension
list_comp = compile('[i*2 for i in range(10)]', '<string>', 'eval')
print("\nDisassemblování list comprehension:")
dis.dis(list_comp)

# Přímé zobrazení bajtkódu
print("\nBajtkód funkce add:")
for instruction in dis.get_instructions(add):
    print(f"{instruction.offset}: {instruction.opname} {instruction.argval if instruction.argval is not None else ''}")
```

## 8. Analýza bajtkódu v praxi

Porovnejme různé konstrukce Pythonu zkoumáním jejich bajtkódu, abychom pochopili dopady na výkon.

```python
import dis
import time

# Porovnání list comprehension vs. for cyklus
def with_list_comprehension():
    return [i*i for i in range(1000)]

def with_for_loop():
    result = []
    for i in range(1000):
        result.append(i*i)
    return result

print("Bajtkód list comprehension:")
dis.dis(with_list_comprehension)

print("\nBajtkód for cyklu:")
dis.dis(with_for_loop)

# Měření doby provádění
def measure_execution(func, iterations=1000):
    start = time.time()
    for _ in range(iterations):
        func()
    end = time.time()
    return end - start

comp_time = measure_execution(with_list_comprehension)
loop_time = measure_execution(with_for_loop)

print(f"\nList comprehension trvalo: {comp_time:.6f} sekund")
print(f"For cyklus trval: {loop_time:.6f} sekund")
print(f"Rozdíl: List comprehension je {loop_time/comp_time:.2f}x rychlejší")

# Porovnání různých způsobů přístupu ke globálním vs. lokálním proměnným
x = 100  # Globální proměnná

def global_access():
    for _ in range(1000):
        y = x  # Přístup ke globální proměnné

def local_access():
    x_local = x  # Uložení globální proměnné do lokální
    for _ in range(1000):
        y = x_local  # Přístup k lokální proměnné

print("\nBajtkód přístupu ke globální proměnné:")
dis.dis(global_access)

print("\nBajtkód přístupu k lokální proměnné:")
dis.dis(local_access)
```

## 9. Praktické aplikace

Nyní se podívejme na některé praktické aplikace použití vnitřních mechanismů Pythonu pro reálné problémy.

```python
import sys
import inspect
import dis
import tracemalloc
import time

# Nástroj pro dynamické ladění
def debug_function(func):
    """Dekorátor, který poskytuje rozsáhlé ladicí informace o funkci."""
    def wrapper(*args, **kwargs):
        print(f"\n{'='*50}")
        print(f"Volání funkce: {func.__name__}")
        print(f"Dokumentace: {func.__doc__ or 'Žádná dokumentace'}")
        print(f"Signatura: {inspect.signature(func)}")
        print(f"Argumenty: {args}, {kwargs}")
        
        # Zobrazení zdrojového kódu
        source_lines, _ = inspect.getsourcelines(func)
        print("\nZdrojový kód:")
        for line in source_lines:
            print(f"    {line.rstrip()}")
        
        # Zobrazení bajtkódu
        print("\nBajtkód:")
        dis.dis(func)
        
        # Sledování paměti
        tracemalloc.start()
        start_time = time.time()
        
        # Provedení funkce
        result = func(*args, **kwargs)
        
        # Měření výkonu
        execution_time = time.time() - start_time
        current, peak = tracemalloc.get_traced_memory()
        tracemalloc.stop()
        
        print(f"\nDoba provádění: {execution_time:.6f} sekund")
        print(f"Aktuální využití paměti: {current / 1024:.2f} KB")
        print(f"Špičkové využití paměti: {peak / 1024:.2f} KB")
        print(f"Výsledek: {result}")
        print(f"{'='*50}\n")
        
        return result
    
    return wrapper

# Příklad použití
@debug_function
def fibonacci(n):
    """Vypočítá Fibonacciho číslo pro n."""
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Spustíme s malým vstupem, abychom se vyhnuli přílišnému výstupu
result = fibonacci(5)

# Nástroj pro inspekci vlastních objektů
def inspect_object(obj):
    """Podrobně prozkoumá libovolný objekt Pythonu."""
    obj_type = type(obj)
    print(f"Objekt: {obj}")
    print(f"Typ: {obj_type}")
    print(f"ID: {id(obj)}")
    print(f"Velikost paměti: {sys.getsizeof(obj)} bajtů")
    
    if inspect.isfunction(obj) or inspect.ismethod(obj):
        print(f"Signatura: {inspect.signature(obj)}")
        print(f"Dokumentace: {obj.__doc__ or 'Žádná dokumentace'}")
    
    if inspect.isclass(obj):
        print("Metody:")
        for name, method in inspect.getmembers(obj, inspect.isfunction):
            print(f"  {name}: {method.__doc__ or 'Žádná dokumentace'}")
            
        print("Atributy:")
        for name, value in inspect.getmembers(obj, lambda x: not inspect.isroutine(x)):
            if not name.startswith('__'):
                print(f"  {name}: {value}")
    
    # Pro vestavěné objekty zobrazíme jejich strukturu
    if hasattr(obj, '__dict__') and obj.__dict__:
        print("Atributy objektu:")
        for key, value in obj.__dict__.items():
            print(f"  {key}: {value}")

# Příklad použití
class Person:
    """Jednoduchá třída osoby."""
    
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def greet(self):
        """Vrátí pozdrav."""
        return f"Ahoj, jmenuji se {self.name}"

inspect_object(Person)
print("\n")
inspect_object(Person("Alice", 30))
```

## 10. Shrnutí

Porozumění vnitřním mechanismům Pythonu prostřednictvím modulů jako `sys`, `inspect` a `dis` poskytuje vývojářům Pythonu řadu výhod:

1. **Modul `sys`** poskytuje přístup ke stavu interpretu Pythonu, včetně argumentů příkazové řádky, modulů a informací o platformě. Je nezbytný pro pochopení prostředí, ve kterém váš kód běží, a pro úkoly jako je správa paměti.

2. **Modul `inspect`** umožňuje introspekci živých objektů, díky které můžete zkoumat třídy, funkce a kód za běhu. To je neocenitelné pro ladění, generování dokumentace a vytváření adaptivního kódu.

3. **Modul `dis`** odhaluje bajtkód Pythonu, což vám umožňuje vidět, jak je váš kód překládán pro interpret. Tento vhled může pomoci optimalizovat výkon a pochopit, proč jsou některé konstrukce rychlejší než jiné.

Tyto moduly vám pomáhají:
- Ladit složité problémy zkoumáním exekučního prostředí
- Optimalizovat kód pochopením využití paměti a efektivity bajtkódu
- Vytvářet dynamické nástroje a rámce, které se přizpůsobují různým strukturám kódu
- Vyvíjet řešení metaprogramování, která mohou zkoumat a upravovat chování kódu za běhu

Ponořením se do vnitřních mechanismů Pythonu získáte nejen praktické nástroje pro řešení bezprostředních problémů, ale také hlubší pochopení samotného jazyka, což z vás činí efektivnějšího vývojáře Pythonu.
