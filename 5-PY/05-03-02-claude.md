# Python Concurrency: Threading and Multiprocessing

## Introduction

Concurrency is a programming paradigm that allows multiple sequences of operations to progress simultaneously. In Python, there are several approaches to implementing concurrency, with threading and multiprocessing being the most common ones. This notebook explores these concepts in depth, providing code examples and practical applications.

## 1. Understanding Concurrency Concepts

Concurrency involves managing multiple operations that appear to run simultaneously. It's important to distinguish between:

- **Concurrency**: Managing multiple operations at once (not necessarily executing them simultaneously)
- **Parallelism**: Executing multiple operations simultaneously (requires multiple CPU cores)

### Key Concepts

```python
# Core concurrency concepts in Python
"""
1. Tasks: Units of work to be executed concurrently
2. Threads: Lightweight execution units that share memory space
3. Processes: Independent execution units with separate memory spaces
4. Synchronization: Coordinating access to shared resources
5. Race conditions: Issues arising from uncoordinated access to shared data
6. Deadlocks: Situations where two or more operations are waiting for each other
"""
```

### When to Use Concurrency

```python
# Use cases for concurrency
"""
- I/O-bound tasks: Network requests, file operations, database queries
- CPU-bound tasks: Complex calculations, data processing
- User interface responsiveness: Keeping UI responsive while performing background work
- Service scalability: Handling multiple clients or requests simultaneously
"""
```

## 2. Threading in Python

Threads are lightweight processes that share the same memory space. Python's `threading` module provides a high-level interface for thread-based parallelism.

### Basic Threading Example

```python
import threading
import time

def worker(name):
    """Function executed in a thread"""
    print(f"Worker {name} starting")
    time.sleep(2)  # Simulate work
    print(f"Worker {name} finished")

# Create and start multiple threads
threads = []
for i in range(5):
    t = threading.Thread(target=worker, args=(i,))
    threads.append(t)
    t.start()

# Wait for all threads to complete
for t in threads:
    t.join()

print("All workers completed their tasks")
```

## 3. Thread Synchronization

When multiple threads access shared resources, synchronization mechanisms are required to prevent race conditions.

### Race Condition Example

```python
import threading

# Shared resource
counter = 0

def increment_counter(iterations):
    global counter
    for _ in range(iterations):
        current = counter
        # Simulating a context switch that might happen in real scenarios
        # by breaking the increment into read-modify-write steps
        counter = current + 1

# Create threads
threads = []
for _ in range(5):
    thread = threading.Thread(target=increment_counter, args=(10000,))
    threads.append(thread)
    thread.start()

# Wait for all threads to complete
for thread in threads:
    thread.join()

print(f"Expected count: {5 * 10000}")
print(f"Actual count: {counter}")
print("The difference is due to race conditions!")
```

### Locks

```python
import threading

counter = 0
counter_lock = threading.Lock()

def increment_counter_safe(iterations):
    global counter
    for _ in range(iterations):
        with counter_lock:  # Acquire the lock
            counter += 1    # Critical section
        # Lock is released automatically here

# Create threads
threads = []
for _ in range(5):
    thread = threading.Thread(target=increment_counter_safe, args=(10000,))
    threads.append(thread)
    thread.start()

# Wait for all threads to complete
for thread in threads:
    thread.join()

print(f"Expected count: {5 * 10000}")
print(f"Actual count: {counter}")
print("With locks, the count is correct!")
```

### RLock (Reentrant Lock)

```python
import threading

class ReentrantExample:
    def __init__(self):
        self.lock = threading.RLock()  # Reentrant lock
        self.value = 0
        
    def outer_method(self):
        with self.lock:
            print("Outer method acquired lock")
            self.inner_method()  # This works because RLock is reentrant
            
    def inner_method(self):
        with self.lock:
            print("Inner method also acquired lock")
            self.value += 1

# Demonstrate reentrant locking
example = ReentrantExample()
thread = threading.Thread(target=example.outer_method)
thread.start()
thread.join()

print(f"Final value: {example.value}")
```

### Conditions

```python
import threading
import time
import random

# Shared resources
item = None
condition = threading.Condition()

def producer():
    global item
    for i in range(5):
        time.sleep(random.uniform(1, 3))  # Simulate production time
        
        with condition:
            item = f"Item {i}"
            print(f"Producer created {item}")
            condition.notify()  # Notify consumer that an item is available
            
    with condition:
        item = "DONE"
        condition.notify()

def consumer():
    global item
    while True:
        with condition:
            while item is None:  # Guard against spurious wakeups
                condition.wait()
            
            if item == "DONE":
                print("Consumer received termination signal")
                break
                
            print(f"Consumer consumed {item}")
            item = None  # Reset the item

# Create and start threads
producer_thread = threading.Thread(target=producer)
consumer_thread = threading.Thread(target=consumer)

producer_thread.start()
consumer_thread.start()

producer_thread.join()
consumer_thread.join()
```

## 4. The Global Interpreter Lock (GIL)

The Global Interpreter Lock (GIL) is a mutex that protects access to Python objects, preventing multiple threads from executing Python bytecode at once.

### Impact of GIL

```python
import threading
import time

def cpu_bound_task(n):
    """A CPU-bound task that calculates the sum of squares"""
    result = 0
    for i in range(n):
        result += i * i
    return result

def run_sequential(n):
    start = time.time()
    
    cpu_bound_task(n)
    cpu_bound_task(n)
    
    end = time.time()
    return end - start

def run_threaded(n):
    start = time.time()
    
    t1 = threading.Thread(target=cpu_bound_task, args=(n,))
    t2 = threading.Thread(target=cpu_bound_task, args=(n,))
    
    t1.start()
    t2.start()
    
    t1.join()
    t2.join()
    
    end = time.time()
    return end - start

# Compare performance
n = 10000000
sequential_time = run_sequential(n)
threaded_time = run_threaded(n)

print(f"Sequential time: {sequential_time:.4f} seconds")
print(f"Threaded time: {threaded_time:.4f} seconds")
print(f"Speedup: {sequential_time/threaded_time:.4f}x")
print("Due to the GIL, CPU-bound tasks may not see significant speedup with threading")
```

## 5. Multiprocessing in Python

The `multiprocessing` module allows you to bypass the GIL by using separate processes instead of threads.

### Basic Multiprocessing Example

```python
import multiprocessing
import time

def worker(name):
    """Function executed in a separate process"""
    print(f"Worker {name} starting (Process ID: {multiprocessing.current_process().pid})")
    time.sleep(2)  # Simulate work
    print(f"Worker {name} finished")

if __name__ == '__main__':
    # Create and start multiple processes
    processes = []
    for i in range(5):
        p = multiprocessing.Process(target=worker, args=(i,))
        processes.append(p)
        p.start()

    # Wait for all processes to complete
    for p in processes:
        p.join()

    print("All workers completed their tasks")
```

## 6. Process Communication

Since processes don't share memory, special mechanisms are needed for inter-process communication.

### Queues

```python
import multiprocessing
import time
import random

def producer(queue):
    """Produce items and put them in the queue"""
    for i in range(5):
        item = f"Item {i}"
        queue.put(item)
        print(f"Producer added {item} to queue")
        time.sleep(random.uniform(0.5, 1.5))
    
    # Signal end of production
    queue.put(None)
    print("Producer finished")

def consumer(queue):
    """Consume items from the queue"""
    while True:
        item = queue.get()
        if item is None:
            break
        print(f"Consumer got {item} from queue")
        time.sleep(random.uniform(0.5, 1.5))
    
    print("Consumer finished")

if __name__ == '__main__':
    # Create a shared queue
    queue = multiprocessing.Queue()
    
    # Create producer and consumer processes
    p = multiprocessing.Process(target=producer, args=(queue,))
    c = multiprocessing.Process(target=consumer, args=(queue,))
    
    # Start processes
    p.start()
    c.start()
    
    # Wait for processes to finish
    p.join()
    c.join()
    
    print("Both processes completed")
```

### Pipes

```python
import multiprocessing
import time

def sender(conn):
    """Send messages through the pipe"""
    print("Sender: starting")
    for i in range(5):
        message = f"Message {i}"
        conn.send(message)
        print(f"Sender: sent {message}")
        time.sleep(1)
    
    conn.send("END")
    conn.close()
    print("Sender: finished")

def receiver(conn):
    """Receive messages from the pipe"""
    print("Receiver: starting")
    while True:
        if conn.poll():  # Check if there's data in the pipe
            message = conn.recv()
            if message == "END":
                break
            print(f"Receiver: got {message}")
        time.sleep(0.5)
    
    conn.close()
    print("Receiver: finished")

if __name__ == '__main__':
    # Create a pipe
    parent_conn, child_conn = multiprocessing.Pipe()
    
    # Create sender and receiver processes
    s = multiprocessing.Process(target=sender, args=(parent_conn,))
    r = multiprocessing.Process(target=receiver, args=(child_conn,))
    
    # Start processes
    s.start()
    r.start()
    
    # Wait for processes to finish
    s.join()
    r.join()
    
    print("Both processes completed")
```

### Shared Memory

```python
import multiprocessing
import time
import numpy as np

def modify_array(shared_array, shape, index, value):
    """Modify a specific element in the shared array"""
    # Create a numpy array that uses the shared memory
    array = np.frombuffer(shared_array.get_obj()).reshape(shape)
    
    # Modify the array
    array[index] = value
    print(f"Process {multiprocessing.current_process().name} set array[{index}] = {value}")

if __name__ == '__main__':
    # Create a shared array
    shape = (3, 3)
    size = np.prod(shape)
    shared_array = multiprocessing.Array('d', size)
    
    # Initialize the array with zeros
    array = np.frombuffer(shared_array.get_obj()).reshape(shape)
    array.fill(0)
    print(f"Initial array:\n{array}")
    
    # Create processes to modify different elements
    processes = []
    for i in range(3):
        for j in range(3):
            p = multiprocessing.Process(
                target=modify_array,
                args=(shared_array, shape, (i, j), i*3+j+1)
            )
            processes.append(p)
    
    # Start all processes
    for p in processes:
        p.start()
    
    # Wait for all processes to finish
    for p in processes:
        p.join()
    
    # Print the final array
    array = np.frombuffer(shared_array.get_obj()).reshape(shape)
    print(f"Final array:\n{array}")
```

## 7. Thread Pools and Process Pools

Thread and process pools manage a fixed number of workers for executing tasks.

### ThreadPoolExecutor

```python
import concurrent.futures
import requests
import time

# List of URLs to fetch
urls = [
    'https://www.python.org/',
    'https://docs.python.org/',
    'https://pypi.org/',
    'https://github.com/python/cpython',

    'https://www.python.org/about/',
    'https://www.python.org/events/',
    'https://www.python.org/blogs/',
    'https://wiki.python.org/moin/',
]

def fetch_url(url):

    print(f"Fetching {url}")
    try:
        response = requests.get(url, timeout=10)
        return f"{url}: {len(response.text)} bytes"
    except Exception as e:
        return f"{url}: Error ({str(e)})"

# Using ThreadPoolExecutor
def fetch_with_threadpool():
    start = time.time()
    
    with concurrent.futures.ThreadPoolExecutor(max_workers=5) as executor:
        # Submit tasks and get futures
        future_to_url = {executor.submit(fetch_url, url): url for url in urls}
        
        # Process results as they complete
        for future in concurrent.futures.as_completed(future_to_url):
            url = future_to_url[future]
            try:
                result = future.result()
                print(result)
            except Exception as e:
                print(f"{url}: Error - {str(e)}")
    
    end = time.time()
    return end - start

if __name__ == '__main__':
    print("Fetching URLs with ThreadPoolExecutor...")
    elapsed_time = fetch_with_threadpool()
    print(f"Total time: {elapsed_time:.4f} seconds")
```

### Custom Thread Pool Implementation

```python
import threading
import queue
import time
import random

class ThreadPool:
    """A simple thread pool implementation"""
    
    def __init__(self, num_threads):
        self.task_queue = queue.Queue()
        self.threads = []
        self.shutdown_event = threading.Event()
        
        # Create worker threads
        for _ in range(num_threads):
            thread = threading.Thread(target=self._worker)
            thread.daemon = True
            thread.start()
            self.threads.append(thread)
    
    def _worker(self):
        """Worker thread that processes tasks from the queue"""
        while not self.shutdown_event.is_set():
            try:
                # Get task from queue with timeout
                func, args, kwargs, result_holder = self.task_queue.get(timeout=0.5)
                
                # Execute the task
                try:
                    result = func(*args, **kwargs)
                    result_holder['result'] = result
                except Exception as e:
                    result_holder['error'] = e
                
                # Mark task as done
                self.task_queue.task_done()
                
            except queue.Empty:
                continue
    
    def submit(self, func, *args, **kwargs):
        """Submit a task to the thread pool"""
        result_holder = {}
        self.task_queue.put((func, args, kwargs, result_holder))
        return result_holder
    
    def shutdown(self):
        """Shutdown the thread pool"""
        self.shutdown_event.set()
        for thread in self.threads:
            thread.join()

# Example task
def process_item(item):
    """Process an item with random delay"""
    print(f"Processing item {item}")
    # Simulate varying processing time
    time.sleep(random.uniform(0.5, 2.0))
    return f"Result for item {item}"

if __name__ == '__main__':
    # Create a thread pool with 3 worker threads
    pool = ThreadPool(3)
    
    # Submit tasks
    result_holders = []
    for i in range(10):
        result_holder = pool.submit(process_item, i)
        result_holders.append((i, result_holder))
    
    # Wait and get results
    time.sleep(5)  # Give some time for tasks to complete
    
    for i, result_holder in result_holders:
        if 'result' in result_holder:
            print(f"Task {i} completed: {result_holder['result']}")
        elif 'error' in result_holder:
            print(f"Task {i} failed: {result_holder['error']}")
        else:
            print(f"Task {i} is still running")
    
    # Shutdown the pool
    pool.shutdown()
```

```python
def process_images_in_directory(input_dir, output_dir, max_workers=4):
    """Process all images in a directory using ProcessPoolExecutor"""
    # Ensure output directory exists
    os.makedirs(output_dir, exist_ok=True)

    image_files = []
    for file in os.listdir(input_dir):
        if file.lower().endswith(('.png', '.jpg', '.jpeg', '.bmp', '.gif')):
            image_files.append(os.path.join(input_dir, file))
    
    if not image_files:
        print("No image files found")
        return
    
    start_time = time.time()
    
    # Process images concurrently
    with concurrent.futures.ProcessPoolExecutor(max_workers=max_workers) as executor:
        # Submit tasks
        future_to_image = {
            executor.submit(process_image, img_path, output_dir): img_path 
            for img_path in image_files
        }
        
        # Process results as they complete
        for future in concurrent.futures.as_completed(future_to_image):
            img_path = future_to_image[future]
            try:
                path, success = future.result()
                if success:
                    print(f"Successfully processed {os.path.basename(path)}")
                else:
                    print(f"Failed to process {os.path.basename(path)}")
            except Exception as e:
                print(f"{os.path.basename(img_path)}: Error - {str(e)}")
    
    elapsed_time = time.time() - start_time
    print(f"Processed {len(image_files)} images in {elapsed_time:.2f} seconds")
```

```python
import concurrent.futures
import pandas as pd
import numpy as np
import time
import os

# Function to generate a sample DataFrame
def generate_sample_data(size=1000000):
    """Generate a sample DataFrame with random data"""
    np.random.seed(42)
    data = {
        'id': range(size),
        'value1': np.random.rand(size),
        'value2': np.random.rand(size),
        'category': np.random.choice(['A', 'B', 'C', 'D'], size)
    }
    return pd.DataFrame(data)

def process_chunk(chunk):
    """Process a chunk of data"""
    # Perform some data transformations
    result = chunk.copy()
    
    # Add new calculated columns
    result['value_sum'] = result['value1'] + result['value2']
    result['value_product'] = result['value1'] * result['value2']
    result['value_ratio'] = result['value1'] / (result['value2'] + 0.001)  # Avoid division by zero
    
    # Group by category and calculate statistics
    grouped = result.groupby('category').agg({
        'value1': ['mean', 'std', 'min', 'max'],
        'value2': ['mean', 'std', 'min', 'max'],
        'value_sum': ['mean', 'min', 'max'],
        'value_product': ['mean', 'min', 'max']
    })
    
    # Return both the transformed data and the statistics
    return {
        'transformed_data': result,
        'statistics': grouped
    }

def parallel_process_dataframe(df, num_processes=4):
    """Process a DataFrame in parallel using ProcessPoolExecutor"""
    # Split DataFrame into chunks
    chunk_size = len(df) // num_processes
    chunks = [df[i:i+chunk_size] for i in range(0, len(df), chunk_size)]
    
    start_time = time.time()
    
    all_transformed_data = []
    all_statistics = []
    
    # Process chunks in parallel
    with concurrent.futures.ProcessPoolExecutor(max_workers=num_processes) as executor:
        # Submit tasks and get results
        results = list(executor.map(process_chunk, chunks))
        
        # Collect results
        for result in results:
            all_transformed_data.append(result['transformed_data'])
            all_statistics.append(result['statistics'])
    
    # Combine results
    combined_data = pd.concat(all_transformed_data)
    
    # Combine statistics (taking mean of means, etc.)
    combined_stats = pd.concat(all_statistics)
    final_stats = combined_stats.groupby(level=0).mean()
    
    elapsed_time = time.time() - start_time
    
    return {
        'data': combined_data,
        'statistics': final_stats,
        'processing_time': elapsed_time
    }
```

## 10. Best Practices and Summary

### Best Practices for Threading and Multiprocessing

```python
"""
Best Practices for Concurrency in Python:

1. Choose the right concurrency approach:
   - For I/O-bound tasks: Use threading or asyncio
   - For CPU-bound tasks: Use multiprocessing
   
2. Avoid race conditions:
   - Use proper synchronization primitives (locks, semaphores, events)
   - Minimize shared state between threads
   - Make operations atomic when possible
   
3. Prevent deadlocks:
   - Acquire locks in a consistent order
   - Use timeouts when acquiring locks
   - Use context managers for lock acquisition and release
   
4. Pool management:
   - Use ThreadPoolExecutor and ProcessPoolExecutor when appropriate
   - Set appropriate number of workers based on the task type
   - For CPU-bound tasks, use processes equal to the number of cores
   - For I/O-bound tasks, use more threads than cores
   
5. Communication best practices:
   - Prefer message passing over shared memory
   - Use Queue objects for thread-safe communication
   - Avoid complex synchronization schemes when possible
   
6. GIL considerations:
   - Be aware of GIL limitations for CPU-bound threading
   - Release the GIL in C extensions for CPU-intensive operations
   - Use multiprocessing to bypass the GIL for compute-heavy tasks
   
7. Error handling:
   - Always join threads and processes
   - Use proper exception handling in worker functions
   - Consider using futures for better error propagation

8. Performance monitoring:
   - Measure and compare different concurrency approaches
   - Profile your code to identify bottlenecks
   - Adjust the concurrency strategy based on performance metrics
"""
```
