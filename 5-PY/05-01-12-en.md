## 1. Understanding Python Modules

Modules in Python are files containing Python code that can be imported and used in other Python programs. They help organize code into reusable components, making it more maintainable and scalable. A module can contain functions, classes, variables, and even executable code.

```python
# Example of what a module is conceptually
# This would be in a file named "my_module.py"

# Variables in the module
pi = 3.14159
greeting = "Hello, world!"

# Functions in the module
def square(x):
    """Return the square of a number."""
    return x * x

def cube(x):
    """Return the cube of a number."""
    return x * x * x

# A class in the module
class Circle:
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        return pi * self.radius ** 2
    
    def circumference(self):
        return 2 * pi * self.radius

# This will run when the module is executed directly
if __name__ == "__main__":
    print("This module is being run directly.")
else:
    print("This module has been imported.")
```

## 2. Importing Modules

Python provides several ways to import modules into your code. You can import an entire module, specific attributes from a module, or rename modules during import.

```python
# Importing an entire module
import math
print(math.sqrt(16))  # Output: 4.0

# Importing specific functions from a module
from math import sqrt, pi
print(sqrt(16))       # Output: 4.0
print(pi)             # Output: 3.141592653589793

# Importing with an alias
import math as m
print(m.sqrt(16))     # Output: 4.0

# Importing all names from a module (not recommended in practice)
from math import *
print(sqrt(16))       # Output: 4.0
print(cos(0))         # Output: 1.0
```

## 3. Module Search Path

When you import a module, Python searches for it in several locations. Understanding this search path is crucial when working with modules across different directories.

```python
# Viewing the module search path
import sys
print(sys.path)  # Shows the list of directories Python searches for modules

# Adding a directory to the search path
import sys
sys.path.append('/path/to/my/modules')

# You can now import modules from the added directory
import my_custom_module

# Checking if a module is available
try:
    import non_existent_module
except ImportError:
    print("Module not found!")

# Finding where a module is located
import os
print(os.__file__)  # Shows the file path of the os module
```

## 4. Creating Custom Modules

Creating your own modules allows you to organize code and share functionality between different scripts and projects.

```python
# Example: Creating a custom module
# Save this in a file named "calculator.py"

def add(a, b):
    """Add two numbers and return the result."""
    return a + b

def subtract(a, b):
    """Subtract b from a and return the result."""
    return a - b

def multiply(a, b):
    """Multiply two numbers and return the result."""
    return a * b

def divide(a, b):
    """Divide a by b and return the result."""
    if b == 0:
        raise ValueError("Cannot divide by zero!")
    return a / b
```

```python
# In another script, import and use the custom module
import calculator

result1 = calculator.add(10, 5)
result2 = calculator.subtract(10, 5)
result3 = calculator.multiply(10, 5)
result4 = calculator.divide(10, 5)

print(f"Addition: {result1}")      # Output: Addition: 15
print(f"Subtraction: {result2}")   # Output: Subtraction: 5
print(f"Multiplication: {result3}")  # Output: Multiplication: 50
print(f"Division: {result4}")      # Output: Division: 2.0
```

## 5. Working with Packages

Packages are collections of modules organized in directories. They provide a way to organize related modules into a hierarchical structure.

```python
# Example package structure
# my_package/
# ├── __init__.py
# ├── module1.py
# ├── module2.py
# └── subpackage/
#     ├── __init__.py
#     └── module3.py

# The __init__.py file marks a directory as a package
# It can be empty or contain initialization code

# Importing from a package
import my_package.module1
my_package.module1.some_function()

# Importing a specific function from a module in a package
from my_package.module1 import some_function
some_function()

# Importing from a subpackage
from my_package.subpackage import module3
module3.another_function()

# Relative imports within a package (in module2.py)
# from . import module1  # Import from the same directory
# from .subpackage import module3  # Import from a subdirectory
# from .. import other_package  # Import from a parent directory
```

## 6. Import Variations

Python offers several ways to control what happens during imports and how names are made available in your code.

```python
# Basic import
import math
print(math.pi)  # Need to use the module name as prefix

# Import with renaming
import math as m
print(m.pi)  # Use the shorter alias

# Import specific items
from math import pi, sqrt
print(pi)    # Use directly without module prefix
print(sqrt(16))

# Import with local renaming
from math import pi as PI, sqrt as square_root
print(PI)
print(square_root(16))

# Import all names (not recommended in most cases)
from math import *
print(pi)
print(sqrt(16))

# Conditional imports
try:
    import matplotlib.pyplot as plt
    HAS_MATPLOTLIB = True
except ImportError:
    HAS_MATPLOTLIB = False
    print("Matplotlib not installed, visualizations disabled.")

# Lazy imports (import only when needed)
def plot_data(data):
    if not 'plt' in globals():  # Check if already imported
        import matplotlib.pyplot as plt
    plt.plot(data)
    plt.show()
```

## 7. Standard Library Modules

Python comes with a rich standard library of modules that provide various functionalities. These modules are available without installing additional packages.

```python
# Working with operating system
import os
current_dir = os.getcwd()
print(f"Current directory: {current_dir}")
os.makedirs("new_folder", exist_ok=True)  # Create directory

# File paths
import os.path
file_exists = os.path.isfile("data.txt")
print(f"File exists: {file_exists}")

# Date and time operations
import datetime
now = datetime.datetime.now()
print(f"Current date and time: {now}")
print(f"Year: {now.year}, Month: {now.month}, Day: {now.day}")

# Random numbers
import random
print(f"Random number: {random.random()}")
print(f"Random integer between 1 and 10: {random.randint(1, 10)}")
print(f"Random choice from list: {random.choice(['apple', 'banana', 'cherry'])}")

# Mathematical operations
import math
print(f"Square root of 16: {math.sqrt(16)}")
print(f"Value of pi: {math.pi}")
print(f"Sine of 0: {math.sin(0)}")

# JSON data handling
import json
data = {"name": "John", "age": 30, "city": "New York"}
json_string = json.dumps(data)
print(f"JSON string: {json_string}")
parsed_data = json.loads(json_string)
print(f"Parsed data: {parsed_data}")
```

## 8. Working with Third-Party Modules

Python's ecosystem includes thousands of third-party modules that can be installed using package managers like pip. These modules extend Python's functionality for various specialized tasks.

```python
# First, install the module using pip (run in terminal/command prompt)
# pip install requests

# Using a third-party module for HTTP requests
import requests

# Make a GET request to a website
response = requests.get('https://api.github.com')

# Check if the request was successful
if response.status_code == 200:
    print("Request successful!")
    # Parse the JSON response
    data = response.json()
    print(f"GitHub API version: {data.get('current_user_url', 'Not found')}")
else:
    print(f"Request failed with status code: {response.status_code}")

# Example with NumPy (need to install with: pip install numpy)
try:
    import numpy as np
    
    # Create a NumPy array
    arr = np.array([1, 2, 3, 4, 5])
    print(f"NumPy array: {arr}")
    print(f"Array mean: {np.mean(arr)}")
    print(f"Array standard deviation: {np.std(arr)}")
except ImportError:
    print("NumPy is not installed. Install with: pip install numpy")
```
