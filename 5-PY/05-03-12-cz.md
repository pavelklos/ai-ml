## 1. Úvod do abstraktních bázových tříd a protokolů

Abstraktní bázové třídy (ABC) a protokoly jsou dva silné mechanismy v Pythonu pro definování rozhraní a zajištění toho, že odvozené třídy implementují konkrétní metody nebo vlastnosti. I když oba slouží podobným účelům, představují různé přístupy k definici rozhraní:

- **Abstraktní bázové třídy** sledují tradičnější objektově orientovaný přístup, kde třídy explicitně dědí z bázové třídy, která definuje požadované rozhraní.
- **Protokoly** sledují přístup více zaměřený na "duck typing", kde shoda je určena tím, zda třída implementuje požadované metody, nikoliv děděním.

```python
# Přístup s abstraktní bázovou třídou (explicitní dědičnost)
from abc import ABC, abstractmethod

class DatabaseConnector(ABC):
    @abstractmethod
    def connect(self):
        pass
        
    @abstractmethod
    def execute_query(self, query):
        pass

# Přístup s protokolem (strukturální typování)
from typing import Protocol

class DatabaseInterface(Protocol):
    def connect(self) -> None:
        ...
        
    def execute_query(self, query: str) -> list:
        ...
```

Oba přístupy pomáhají definovat jasná rozhraní, ale liší se v tom, jak třídy dodržují tato rozhraní a jak je ověřována jejich shoda.

## 2. Modul ABC a vytváření abstraktních bázových tříd

Modul `abc` v Pythonu poskytuje infrastrukturu pro definování abstraktních bázových tříd. Hlavními komponentami jsou třída `ABC` a dekorátor `abstractmethod`:

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    """Abstraktní bázová třída reprezentující geometrický tvar."""
    
    @abstractmethod
    def area(self):
        """Vypočítat plochu tvaru."""
        pass
    
    @abstractmethod
    def perimeter(self):
        """Vypočítat obvod tvaru."""
        pass
    
    def describe(self):
        """Vrátí popis tvaru."""
        return f"Tvar s plochou {self.area()} a obvodem {self.perimeter()}"
```

Klíčové body o ABC:

1. Třída se stává abstraktní bázovou třídou děděním z `ABC`.
2. Abstraktní metody jsou označeny dekorátorem `@abstractmethod`.
3. Třída může mít jak abstraktní, tak konkrétní (implementované) metody.
4. Abstraktní třídu nelze přímo instantizovat.

```python
# Toto vyvolá TypeError
# shape = Shape()  # TypeError: Can't instantiate abstract class Shape with abstract methods area, perimeter
```

## 3. Abstraktní metody a vlastnosti

Abstraktní bázové třídy mohou definovat různé druhy abstraktních členů:

1. Abstraktní metody pomocí `@abstractmethod`
2. Abstraktní vlastnosti pomocí `@property` kombinované s `@abstractmethod`
3. Abstraktní třídní metody pomocí `@classmethod` s `@abstractmethod`
4. Abstraktní statické metody pomocí `@staticmethod` s `@abstractmethod`

```python
from abc import ABC, abstractmethod

class DataProcessor(ABC):
    @abstractmethod
    def process(self, data):
        """Zpracovat vstupní data."""
        pass
    
    @property
    @abstractmethod
    def is_ready(self):
        """Zkontrolovat, zda je procesor připraven."""
        pass
    
    @classmethod
    @abstractmethod
    def from_file(cls, filepath):
        """Vytvořit procesor ze souboru."""
        pass
    
    @staticmethod
    @abstractmethod
    def supported_formats():
        """Vrátit seznam podporovaných formátů."""
        pass
```

Pořadí dekorátorů je důležité: u abstraktních vlastností by měl být `@property` před `@abstractmethod`.

## 4. Implementace abstraktních bázových tříd

Pro použití abstraktní bázové třídy musíme vytvořit konkrétní podtřídy, které implementují všechny abstraktní metody:

```python
class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        import math
        return math.pi * self.radius ** 2
    
    def perimeter(self):
        import math
        return 2 * math.pi * self.radius

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)

# Nyní můžeme vytvářet instance těchto konkrétních tříd
circle = Circle(5)
print(circle.area())  # 78.53981633974483
print(circle.describe())  # Tvar s plochou 78.53981633974483 a obvodem 31.41592653589793

rectangle = Rectangle(4, 6)
print(rectangle.area())  # 24
print(rectangle.perimeter())  # 20
```

Abstraktní bázové třídy také poskytují kontroly za běhu pomocí funkcí `isinstance()` a `issubclass()`:

```python
print(isinstance(circle, Shape))  # True
print(isinstance(rectangle, Shape))  # True
print(issubclass(Circle, Shape))  # True

# I objekty, které explicitně nedědí od třídy Shape, mohou být zaregistrovány
class Triangle:
    def __init__(self, base, height, side1, side2, side3):
        self.base = base
        self.height = height
        self.side1 = side1
        self.side2 = side2
        self.side3 = side3
    
    def area(self):
        return 0.5 * self.base * self.height
    
    def perimeter(self):
        return self.side1 + self.side2 + self.side3

# Zaregistrujeme Triangle jako virtuální podtřídu Shape
Shape.register(Triangle)

triangle = Triangle(3, 4, 3, 4, 5)
print(isinstance(triangle, Shape))  # True, i když Triangle nedědí od Shape
```

## 5. Úvod do protokolů v Pythonu

Protokoly představují alternativní přístup k definování rozhraní v Pythonu, založený na strukturálním typování (známém také jako "duck typing"). Byly formálně představeny v Pythonu 3.8 s PEP 544.

Na rozdíl od ABC, které vynucují shodu rozhraní pomocí dědičnosti, se protokoly zaměřují na to, jaké metody objekt implementuje, bez ohledu na jeho hierarchii dědičnosti.

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Drawable(Protocol):
    def draw(self) -> None:
        ...

# Není potřeba explicitní dědičnost
class Circle:
    def __init__(self, radius):
        self.radius = radius
    
    def draw(self):
        print(f"Kreslím kruh s poloměrem {self.radius}")

# Circle splňuje protokol Drawable
circle = Circle(10)
print(isinstance(circle, Drawable))  # True, protože Circle implementuje draw()
```

Tři tečky `...` (elipsa) v definicích metod protokolu naznačují, že tělo metody není v protokolu samotném definováno.

## 6. Vytváření a používání protokolů

Protokoly mohou definovat jak metody, tak atributy:

```python
from typing import Protocol, runtime_checkable

@runtime_checkable
class Employee(Protocol):
    name: str
    
    def calculate_salary(self) -> float:
        ...
    
    def get_department(self) -> str:
        ...

class Developer:
    def __init__(self, name: str, base_salary: float, bonus: float):
        self.name = name
        self.base_salary = base_salary
        self.bonus = bonus
    
    def calculate_salary(self) -> float:
        return self.base_salary + self.bonus
    
    def get_department(self) -> str:
        return "Vývoj"

# Developer splňuje protokol Employee
dev = Developer("Alice", 70000, 10000)
print(isinstance(dev, Employee))  # True
```

Klíčové body o protokolech:

1. Protokoly definují rozhraní bez požadavku na dědičnost.
2. Dekorátor `@runtime_checkable` umožňuje kontroly za běhu pomocí `isinstance()`.
3. Protokoly mohou zahrnovat definice metod i atributů.
4. Objekty splňují protokol, pokud strukturálně odpovídají jeho požadavkům.

## 7. Strukturální vs nominální typování

Typový systém Pythonu podporuje jak strukturální typování, tak nominální typování:

- **Nominální typování** (používané ABC): Kompatibilita typů je určena explicitními deklaracemi a hierarchií dědičnosti. Třídy musí explicitně dědit nebo být registrovány u ABC, aby byly považovány za podtyp.

- **Strukturální typování** (používané Protokoly): Kompatibilita typů je určena strukturou objektů—jaké metody a atributy mají—spíše než hierarchií dědičnosti.

```python
# Nominální typování s ABC
from abc import ABC, abstractmethod

class Serializable(ABC):
    @abstractmethod
    def serialize(self):
        pass

class JSONData(Serializable):
    def serialize(self):
        return "{}"

# Musí dědit od Serializable, aby byla považována za kompatibilní
json_data = JSONData()
print(isinstance(json_data, Serializable))  # True

class XMLData:
    def serialize(self):
        return "<data></data>"

xml_data = XMLData()
print(isinstance(xml_data, Serializable))  # False, navzdory tomu, že má kompatibilní rozhraní

# Strukturální typování s protokoly
from typing import Protocol, runtime_checkable

@runtime_checkable
class CanSerialize(Protocol):
    def serialize(self) -> str:
        ...

# Není potřeba dědičnost, pouze odpovídající signatury metod
print(isinstance(json_data, CanSerialize))  # True
print(isinstance(xml_data, CanSerialize))  # True, protože má metodu serialize
```

Strukturální typování je přirozeněji v souladu s pythonskou filozofií duck typingu, kde "pokud to chodí jako kachna a kvákají jako kachna, je to kachna."

## 8. Praktické aplikace

Abstraktní bázové třídy a protokoly jsou široce používány ve standardní knihovně Pythonu a balíčcích třetích stran:

### Collections ABC

Modul `collections.abc` poskytuje abstraktní bázové třídy pro definování vlastních kontejnerových typů:

```python
from collections.abc import Sequence

class MyCustomList(Sequence):
    def __init__(self, data):
        self._data = list(data)
    
    def __len__(self):
        return len(self._data)
    
    def __getitem__(self, index):
        return self._data[index]

# Potřebujeme implementovat pouze __len__ a __getitem__ k splnění ABC Sequence
custom_list = MyCustomList([1, 2, 3, 4])
print(isinstance(custom_list, Sequence))  # True
print(list(custom_list))  # [1, 2, 3, 4]
print(custom_list[2])  # 3
```

### Objekty podobné souborům

Mnoho funkcí v Pythonu přijímá "objekty podobné souborům", které podporují společné rozhraní:

```python
from io import StringIO
from typing import Protocol, runtime_checkable

@runtime_checkable
class ReadableFile(Protocol):
    def read(self, size: int = -1) -> str:
        ...
    
    def readline(self) -> str:
        ...

# StringIO implementuje rozhraní souboru
file_like = StringIO("Řádek 1\nŘádek 2\nŘádek 3")
print(isinstance(file_like, ReadableFile))  # True

# Funkce, která pracuje s jakýmkoliv objektem podobným souboru
def count_lines(file):
    if not isinstance(file, ReadableFile):
        raise TypeError("Očekáván čitelný soubor")
    
    count = 0
    while file.readline():
        count += 1
    
    # Resetovat pozici souboru pro další čtení
    if hasattr(file, "seek"):
        file.seek(0)
    
    return count

print(count_lines(file_like))  # 3
```

### Systémy zásuvných modulů (plugins)

ABC a protokoly jsou užitečné pro vývoj systémů zásuvných modulů:

```python
# Použití ABC pro systém zásuvných modulů
from abc import ABC, abstractmethod
import pkgutil
import importlib
import sys

class Plugin(ABC):
    @abstractmethod
    def process(self, data):
        pass

# Implementace zásuvných modulů
class CsvPlugin(Plugin):
    def process(self, data):
        return f"Zpracovávám CSV: {data}"

class JsonPlugin(Plugin):
    def process(self, data):
        return f"Zpracovávám JSON: {data}"

# Správce zásuvných modulů
class PluginManager:
    def __init__(self):
        self.plugins = {}
    
    def register_plugin(self, name, plugin):
        if not issubclass(plugin, Plugin):
            raise TypeError("Zásuvný modul musí být podtřídou ABC Plugin")
        self.plugins[name] = plugin()
    
    def process_data(self, plugin_name, data):
        if plugin_name not in self.plugins:
            raise ValueError(f"Zásuvný modul {plugin_name} nebyl nalezen")
        return self.plugins[plugin_name].process(data)

# Použití
manager = PluginManager()
manager.register_plugin("csv", CsvPlugin)
manager.register_plugin("json", JsonPlugin)

print(manager.process_data("csv", "data.csv"))  # Zpracovávám CSV: data.csv
print(manager.process_data("json", "data.json"))  # Zpracovávám JSON: data.json
```

## 9. Shrnutí

Abstraktní bázové třídy a protokoly poskytují dva přístupy k definování rozhraní v Pythonu:

**Abstraktní bázové třídy:**
- Vynucují rozhraní pomocí dědičnosti (nominální typování)
- Používají modul `abc` a bázovou třídu `ABC`
- Označují požadované metody pomocí `@abstractmethod`
- Umožňují kontrolu typu za běhu pomocí `isinstance()` a `issubclass()`
- Umožňují registraci virtuálních podtříd
- Zabraňují instancím neúplných implementací

**Protokoly:**
- Definují rozhraní pomocí struktury (strukturální typování)
- Používají bázovou třídu `typing.Protocol`
- Definují signatury metod pomocí `...` (elipsy)
- Podporují kontroly za běhu s `@runtime_checkable`
- Přirozeněji se přizpůsobují pythonské filozofii duck typingu
- Nevyžadují explicitní dědičnost

**Kdy použít které:**

- **Použijte ABC,** když chcete vynutit přísné rozhraní, zabránit vytvoření instancí neúplných implementací nebo chcete poskytnout základní implementace některých metod.

- **Použijte protokoly,** když chcete pracovat s existujícími třídami bez jejich modifikace, preferujete duck typing nebo potřebujete definovat rozhraní, která mohou být splněna mnoha různými typy objektů.

Oba přístupy pomáhají vytvářet udržitelnější a typově bezpečný kód jasným definováním rozhraní a zajištěním správné implementace. Protokoly jsou novější a obecně více pythonické, ale ABC jsou již dlouho součástí Pythonu a jsou stále široce používány ve standardní knihovně a mnoha balíčcích třetích stran.
