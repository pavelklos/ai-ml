## 1. Úvod k řízení toku programu

Řízení toku programu umožňuje vašemu programu činit rozhodnutí na základě podmínek, přičemž provádí různé bloky kódu v závislosti na tom, zda jsou určité podmínky pravdivé nebo nepravdivé. V Pythonu je řízení toku primárně spravováno pomocí příkazů if, elif (else if) a else.

```python
# Základní struktura řízení toku
if podminka:
    # Kód provedený, pokud je podmínka True
    pass
elif jina_podminka:
    # Kód provedený, pokud je podmínka False a jina_podminka je True
    pass
else:
    # Kód provedený, pokud všechny výše uvedené podmínky jsou False
    pass
```

## 2. Jednoduché příkazy if

Nejjednodušší formou řízení toku je příkaz if, který provede blok kódu pouze v případě, že podmínka je vyhodnocena jako True.

```python
# Jednoduchý příkaz if
vek = 18

if vek >= 18:
    print("Jste dospělý.")

# Výstup: Jste dospělý.

# Více podmínek
teplota = 28
je_slunecno = True

if teplota > 25:
    print("Je teplý den.")
    
if je_slunecno:
    print("Nezapomeňte na opalovací krém!")

# Výstup:
# Je teplý den.
# Nezapomeňte na opalovací krém!
```

Pokud je podmínka v příkazu if vyhodnocena jako False, blok kódu je přeskočen:

```python
vek = 15

if vek >= 18:
    print("Jste dospělý.")  # Toto se neprovede
    
print("Program pokračuje...")

# Výstup: Program pokračuje...
```

## 3. Příkazy if-else

Příkaz if-else poskytuje alternativní cesty provedení pro případ, kdy je podmínka False.

```python
# Příkaz if-else
vek = 15

if vek >= 18:
    print("Můžete volit.")
else:
    print("Zatím nemůžete volit.")
    
# Výstup: Zatím nemůžete volit.

# Praktický příklad
skore = 75

if skore >= 60:
    print("Prošli jste!")
else:
    print("Neprošli jste.")
    
# Výstup: Prošli jste!
```

## 4. Řetězce if-elif-else

Když potřebujete zkontrolovat více podmínek, můžete použít if následovaný jedním nebo více elif (else if) klauzulemi, s volitelnou else klauzulí na konci.

```python
# Řetězec if-elif-else
skore = 85

if skore >= 90:
    znamka = "A"
elif skore >= 80:
    znamka = "B"
elif skore >= 70:
    znamka = "C"
elif skore >= 60:
    znamka = "D"
else:
    znamka = "F"
    
print(f"Vaše známka je: {znamka}")
# Výstup: Vaše známka je: B

# Příklad s více podmínkami
pocasi = "zataženo"
teplota = 15

if pocasi == "deštivo":
    print("Vezměte si deštník.")
elif pocasi == "slunečno" and teplota > 25:
    print("Vezměte si sluneční brýle a opalovací krém.")
elif pocasi == "slunečno":
    print("Vezměte si sluneční brýle.")
elif pocasi == "zataženo" and teplota < 10:
    print("Vezměte si bundu.")
else:
    print("Nejsou potřeba žádné speciální věci.")
    
# Výstup: Nejsou potřeba žádné speciální věci.
```

Důležité: Python kontroluje podmínky v pořadí a provede první blok, jehož podmínka je True.

## 5. Vnořené podmínkové příkazy

Můžete vnořit příkazy if do jiných příkazů if pro vytvoření složitějších rozhodovacích stromů.

```python
# Vnořené příkazy if
vek = 25
ma_ridicak = True

if vek >= 18:
    print("Věkový požadavek splněn.")
    
    if ma_ridicak:
        print("Můžete řídit.")
    else:
        print("Nejprve si musíte udělat řidičák.")
else:
    print("Jste příliš mladý na řízení.")
    
# Výstup:
# Věkový požadavek splněn.
# Můžete řídit.

# Další příklad
prijem = 60000
roky_zamestnani = 2
kreditni_skore = 720

if prijem >= 50000:
    if roky_zamestnani >= 3:
        print("Půjčka schválena na základě příjmu a zaměstnání.")
    elif kreditni_skore >= 700:
        print("Půjčka schválena na základě příjmu a kreditního skóre.")
    else:
        print("Příjem dostatečný, ale potřebujete lepší historii zaměstnání nebo kreditní skóre.")
else:
    print("Nesplňujete požadavky na příjem.")
    
# Výstup: Půjčka schválena na základě příjmu a kreditního skóre.
```

## 6. Logické operátory v podmínkách

Python poskytuje logické operátory (`and`, `or`, `not`) pro kombinaci nebo inverzi podmínek.

```python
# Použití logického AND
vek = 25
prijem = 50000

if vek >= 18 and prijem >= 30000:
    print("Máte nárok na kreditní kartu.")
else:
    print("Nemáte nárok na kreditní kartu.")
    
# Výstup: Máte nárok na kreditní kartu.

# Použití logického OR
ma_hotovost = False
ma_kreditni_kartu = True

if ma_hotovost or ma_kreditni_kartu:
    print("Můžete provést nákup.")
else:
    print("Nemůžete provést nákup.")
    
# Výstup: Můžete provést nákup.

# Použití logického NOT
je_vikend = False

if not je_vikend:
    print("Je pracovní den.")
else:
    print("Je víkend.")
    
# Výstup: Je pracovní den.

# Kombinace více logických operátorů
vek = 22
je_student = True
ma_slevovou_kartu = False

if (vek < 25 and je_student) or ma_slevovou_kartu:
    print("Sleva uplatněna!")
else:
    print("Sleva není k dispozici.")
    
# Výstup: Sleva uplatněna!
```

## 7. Podmínkové výrazy (ternární operátor)

Python nabízí kompaktní způsob, jak zapsat jednoduché příkazy if-else pomocí podmínkových výrazů, známých také jako ternární operátor.

```python
# Standardní if-else
vek = 20

if vek >= 18:
    status = "dospělý"
else:
    status = "nezletilý"
    
print(status)  # Výstup: dospělý

# Ekvivalentní ternární operátor
vek = 20
status = "dospělý" if vek >= 18 else "nezletilý"
print(status)  # Výstup: dospělý

# Další příklad
skore = 75
vysledek = "prošel" if skore >= 60 else "neprošel"
print(vysledek)  # Výstup: prošel

# Lze použít ve výrazech
cena = 100
sleva = 15
finalni_cena = cena - (sleva if cena > 50 else 0)
print(finalni_cena)  # Výstup: 85
```

## 8. Běžné vzory a osvědčené postupy

Zde jsou některé běžné vzory a osvědčené postupy pro řízení toku v Pythonu:

```python
# Testování pravdivostní hodnoty - prázdné sekvence jsou vyhodnoceny jako False
jmena = []

if jmena:
    print("Seznam obsahuje nějaká jména.")
else:
    print("Seznam je prázdný.")
    
# Výstup: Seznam je prázdný.

# Neporovnávejte explicitně s True/False
je_platny = True

# Nedoporučeno
if je_platny == True:
    print("Platný")
    
# Doporučeno
if je_platny:
    print("Platný")
    
# Testování členství pomocí 'in'
ovoce = ["jablko", "banán", "třešeň"]
if "banán" in ovoce:
    print("Máme banány!")
    
# Výstup: Máme banány!

# Práce s více podmínkami pomocí seznamu
role_uzivatele = "editor"
povolene_role = ["admin", "editor", "manažer"]

if role_uzivatele in povolene_role:
    print("Přístup povolen.")
else:
    print("Přístup odepřen.")
    
# Výstup: Přístup povolen.

# Strážní klauzule pro včasné návraty (lepší než hluboké vnoření)
def zpracovat_platbu(castka, zustatek_na_uctu, je_overeny):
    # Včasný návrat pro chybové podmínky
    if castka <= 0:
        return "Neplatná částka"
    
    if castka > zustatek_na_uctu:
        return "Nedostatek prostředků"
        
    if not je_overeny:
        return "Účet není ověřený"
    
    # Zpracování platby
    return "Platba úspěšně zpracována"

print(zpracovat_platbu(100, 500, True))  # Výstup: Platba úspěšně zpracována
print(zpracovat_platbu(-50, 500, True))  # Výstup: Neplatná částka
```
