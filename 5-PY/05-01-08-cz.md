## 1. Úvod do n-tic

N-tice (tuples) jsou uspořádané, neměnné sekvence v Pythonu, které mohou ukládat více položek různých datových typů. Na rozdíl od seznamů, jakmile jsou n-tice vytvořeny, nemohou být upraveny. Tato neměnnost činí n-tice užitečnými pro reprezentaci pevných kolekcí položek, kde záleží na pořadí, ale hodnoty by se neměly měnit.

```python
# Příklad n-tice - souřadnice (x, y)
bod = (10, 20)
print(bod)  # Výstup: (10, 20)

# N-tice obsahující různé datové typy
smisena_ntice = (1, "ahoj", 3.14, True)
print(smisena_ntice)  # Výstup: (1, 'ahoj', 3.14, True)

# Pokus o úpravu n-tice vyvolá chybu
# bod[0] = 5  # TypeError: 'tuple' object does not support item assignment
```

## 2. Vytváření a přístup k n-ticím

N-tice lze vytvářet několika způsoby, s nebo bez závorek. K prvkům n-tice můžete přistupovat pomocí indexování, stejně jako u seznamů.

```python
# Vytváření n-tic
prazdna_ntice = ()
print(prazdna_ntice)  # Výstup: ()

# N-tice s jedním prvkem potřebuje čárku na konci
jedinecna = (42,)  # Bez čárky by Python považoval hodnotu za celé číslo v závorkách
print(jedinecna)    # Výstup: (42,)
print(type((42)))   # Výstup: <class 'int'>
print(type((42,)))  # Výstup: <class 'tuple'>

# Vytvoření n-tice bez závorek
souradnice = 10, 20, 30
print(souradnice)  # Výstup: (10, 20, 30)

# Použití konstruktoru tuple()
ntice_ze_seznamu = tuple([1, 2, 3])
ntice_z_retezce = tuple("Python")
print(ntice_ze_seznamu)    # Výstup: (1, 2, 3)
print(ntice_z_retezce)  # Výstup: ('P', 'y', 't', 'h', 'o', 'n')

# Přístup k prvkům n-tice
bod = (10, 20, 30, 40)
print(bod[0])    # Výstup: 10
print(bod[2])    # Výstup: 30
print(bod[-1])   # Výstup: 40 (poslední prvek)

# Řezání n-tic
print(bod[1:3])  # Výstup: (20, 30)
print(bod[:2])   # Výstup: (10, 20)
print(bod[2:])   # Výstup: (30, 40)
```

## 3. Operace a metody n-tic

I když jsou n-tice neměnné, stále s nimi můžete provádět několik operací a používat vestavěné metody.

```python
# Spojování n-tic
ntice1 = (1, 2, 3)
ntice2 = (4, 5, 6)
spojene = ntice1 + ntice2
print(spojene)  # Výstup: (1, 2, 3, 4, 5, 6)

# Opakování n-tic
opakovane = ntice1 * 3
print(opakovane)  # Výstup: (1, 2, 3, 1, 2, 3, 1, 2, 3)

# Kontrola členství
print(2 in ntice1)       # Výstup: True
print(5 not in ntice1)   # Výstup: True

# Metody n-tic
cisla = (1, 2, 3, 2, 4, 2, 5)
print(cisla.count(2))  # Výstup: 3 (počítá výskyty 2)
print(cisla.index(4))  # Výstup: 4 (vrací první index 4)

# Zjištění délky n-tice
print(len(cisla))  # Výstup: 7

# Minimální a maximální hodnoty
print(min(cisla))  # Výstup: 1
print(max(cisla))  # Výstup: 5

# Převod mezi n-ticemi a seznamy
muj_seznam = list(cisla)
print(muj_seznam)      # Výstup: [1, 2, 3, 2, 4, 2, 5]
zpet_na_ntici = tuple(muj_seznam)
print(zpet_na_ntici)  # Výstup: (1, 2, 3, 2, 4, 2, 5)
```

## 4. N-tice versus seznamy

Porozumění tomu, kdy používat n-tice versus seznamy, je důležité pro efektivní programování v Pythonu.

```python
# Porovnání n-tic a seznamů

# Porovnání velikosti
import sys
muj_seznam = [1, 2, 3, 4, 5]
moje_ntice = (1, 2, 3, 4, 5)
print(f"Velikost seznamu: {sys.getsizeof(muj_seznam)} bajtů")
print(f"Velikost n-tice: {sys.getsizeof(moje_ntice)} bajtů")
# N-tice obvykle zabírají méně paměti

# Porovnání výkonu
import timeit

# Rychlost vytváření
vytvoreni_seznamu = timeit.timeit(stmt="[1, 2, 3, 4, 5]", number=1000000)
vytvoreni_ntice = timeit.timeit(stmt="(1, 2, 3, 4, 5)", number=1000000)
print(f"Doba vytvoření seznamu: {vytvoreni_seznamu}")
print(f"Doba vytvoření n-tice: {vytvoreni_ntice}")
# N-tice jsou obvykle rychlejší při vytváření

# Kdy používat seznamy:
# - Když potřebujete měnitelnou sekvenci
menitelna_kolekce = [1, 2, 3]
menitelna_kolekce.append(4)  # Seznamy lze upravovat

# Kdy používat n-tice:
# - Pro neměnná data (hodnoty, které by se neměly měnit)
# - Pro heterogenní data (různé typy)
# - Jako klíče slovníků (seznamy nelze použít jako klíče)
# - Když chcete zajistit integritu dat
```

## 5. Balení a rozbalování n-tic

Balení a rozbalování n-tic jsou výkonné funkce Pythonu, které vám umožňují efektivně pracovat s více hodnotami.

```python
# Balení n-tice - kombinace hodnot do n-tice
zabalena_ntice = 1, 2, 3
print(zabalena_ntice)  # Výstup: (1, 2, 3)

# Rozbalování n-tice - extrakce hodnot z n-tice
x, y, z = zabalena_ntice
print(x)  # Výstup: 1
print(y)  # Výstup: 2
print(z)  # Výstup: 3

# Rozbalování konkrétních hodnot
osoba = ("Jan", "Novák", 30, "Softwarový inženýr")
jmeno, prijmeni, *ostatni = osoba
print(jmeno)     # Výstup: Jan
print(prijmeni)  # Výstup: Novák
print(ostatni)   # Výstup: [30, 'Softwarový inženýr']

# Použití * pro sběr zbývajících položek
*jmena, vek, profese = osoba
print(jmena)     # Výstup: ['Jan', 'Novák']
print(vek)       # Výstup: 30
print(profese)   # Výstup: Softwarový inženýr

# Výměna proměnných pomocí rozbalování n-tic
a, b = 10, 20
print(f"Před výměnou: a={a}, b={b}")
a, b = b, a  # Výměna pomocí balení a rozbalování n-tic
print(f"Po výměně: a={a}, b={b}")
# Výstup: 
# Před výměnou: a=10, b=20
# Po výměně: a=20, b=10
```

## 6. N-tice jako klíče slovníků

Důležitou vlastností n-tic je, že mohou být použity jako klíče slovníků, na rozdíl od seznamů, které jsou měnitelné.

```python
# Použití n-tic jako klíčů slovníků
# Toto funguje, protože n-tice jsou neměnné a hashovatelné
lokace = {
    (50.0755, 14.4378): "Praha",
    (40.7128, -74.0060): "New York",
    (34.0522, -118.2437): "Los Angeles"
}

# Přístup k hodnotám pomocí klíčů n-tic
print(lokace[(50.0755, 14.4378)])  # Výstup: Praha

# Přidání nové lokace
lokace[(48.8566, 2.3522)] = "Paříž"

# Procházení slovníku
for souradnice, mesto in lokace.items():
    print(f"{mesto}: {souradnice}")

# Toto by způsobilo chybu, protože seznamy nelze použít jako klíče slovníků
# chybny_slovnik = {[1, 2]: "Toto nebude fungovat"}  # TypeError: unhashable type: 'list'
```

## 7. Vracení více hodnot z funkcí

N-tice poskytují čistý způsob, jak vracet více hodnot z funkce.

```python
# Vracení více hodnot z funkce
def ziskej_informace_uzivatele():
    jmeno = "Alice"
    vek = 30
    email = "alice@example.com"
    return jmeno, vek, email  # Implicitně vrací n-tici

# Sběr vrácených hodnot
uzivatel = ziskej_informace_uzivatele()
print(uzivatel)  # Výstup: ('Alice', 30, 'alice@example.com')
print(type(uzivatel))  # Výstup: <class 'tuple'>

# Přímé rozbalení vrácených hodnot
jmeno, vek, email = ziskej_informace_uzivatele()
print(f"Jméno: {jmeno}")   # Výstup: Jméno: Alice
print(f"Věk: {vek}")       # Výstup: Věk: 30
print(f"Email: {email}")   # Výstup: Email: alice@example.com

# Funkce, která provádí výpočty a vrací více výsledků
def vypocitej_statistiky(cisla):
    soucet = sum(cisla)
    prumer = soucet / len(cisla)
    minimum = min(cisla)
    maximum = max(cisla)
    return soucet, prumer, minimum, maximum

# Použití vrácených statistik
data = [10, 15, 20, 25, 30]
statistiky = vypocitej_statistiky(data)
print(f"Statistiky: {statistiky}")

# Okamžité rozbalení
soucet, prumer, min_hodnota, max_hodnota = vypocitej_statistiky(data)
print(f"Součet: {soucet}, Průměr: {prumer}, Min: {min_hodnota}, Max: {max_hodnota}")
```

## 8. Pojmenované n-tice

Pojmenované n-tice jsou rozšířením běžných n-tic, které umožňují přístup k prvkům pomocí jména i pozice.

```python
from collections import namedtuple

# Vytvoření typu pojmenované n-tice
Osoba = namedtuple('Osoba', ['jmeno', 'vek', 'prace'])

# Vytvoření instancí pojmenované n-tice
alice = Osoba(jmeno="Alice", vek=30, prace="Inženýr")
bob = Osoba("Bob", 25, "Designer")  # Fungují i poziční argumenty

# Přístup k prvkům podle názvu
print(alice.jmeno)  # Výstup: Alice
print(alice.vek)    # Výstup: 30
print(alice.prace)  # Výstup: Inženýr

# Přístup k prvkům podle indexu (jako u běžných n-tic)
print(alice[0])     # Výstup: Alice
print(alice[1])     # Výstup: 30

# Rozbalování pojmenovaných n-tic
jmeno, vek, prace = bob
print(f"{jmeno} je {vek} let starý a pracuje jako {prace}")
# Výstup: Bob je 25 let starý a pracuje jako Designer

# Pojmenované n-tice jsou neměnné
# alice.vek = 31  # Toto by vyvolalo AttributeError

# Převod na slovník
alice_slovnik = alice._asdict()
print(alice_slovnik)  # Výstup: {'jmeno': 'Alice', 'vek': 30, 'prace': 'Inženýr'}

# Vytvoření nové instance s aktualizovanými poli
alice_aktualizovana = alice._replace(vek=31, prace="Senior inženýr")
print(alice_aktualizovana)  # Výstup: Osoba(jmeno='Alice', vek=31, prace='Senior inženýr')

# Pojmenované n-tice pro strukturovaná data
Bod = namedtuple('Bod', ['x', 'y', 'z'])
pocatek = Bod(0, 0, 0)
print(f"Počátek: {pocatek}")  # Výstup: Počátek: Bod(x=0, y=0, z=0)
```
