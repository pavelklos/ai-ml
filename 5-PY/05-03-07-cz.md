## 1. Úvod do metaprogramování

Metaprogramování je praxe psaní kódu, který manipuluje s kódem. V Pythonu to znamená psaní programů, které mohou zacházet s jinými programy jako se svými daty, zkoumat je, generovat je nebo transformovat. Dynamická povaha Pythonu jej činí obzvláště vhodným pro metaprogramování.

```python
# Základní příklad metaprogramování - funkce, která vytváří funkce
def create_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

double = create_multiplier(2)
triple = create_multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15

# Další jednoduchý příklad - dynamické přiřazování funkcí
def greet(name):
    return f"Ahoj, {name}!"

def farewell(name):
    return f"Nashledanou, {name}!"

# Výběr funkce za běhu
greeting_type = "farewell" if input("Odcházíte? (a/n): ").lower() == 'a' else "greet"
greeting_func = locals()[greeting_type]  # Dynamický výběr funkce

print(greeting_func("Alice"))  # Zavolá buď greet nebo farewell na základě vstupu
```

## 2. Techniky introspekce

Introspekce je schopnost zkoumat objekty za běhu. Python poskytuje řadu nástrojů pro introspekci, jako jsou `dir()`, `type()`, `id()`, `getattr()`, `hasattr()`, `isinstance()` a mnoho dalších.

```python
import inspect

# Základní introspekce
class Example:
    """Ukázková třída pro demonstraci"""
    
    def __init__(self, x=1, y=2):
        self.x = x
        self.y = y
    
    def method(self, a, b=None):
        """Ukázková metoda"""
        return a + b if b else a

# Získání typu objektu
obj = Example()
print(type(obj))  # <class '__main__.Example'>

# Seznam všech atributů a metod
print(dir(obj))

# Získání dokumentace třídy
print(Example.__doc__)  # Ukázková třída pro demonstraci

# Získání signatury metody
print(inspect.signature(Example.method))  # (self, a, b=None)

# Získání dokumentace metody
print(inspect.getdoc(Example.method))  # Ukázková metoda

# Kontrola zdrojového kódu třídy
print(inspect.getsource(Example))

# Získání argumentů metody
def some_function(a, b, c=10, *args, **kwargs):
    pass

print(inspect.getfullargspec(some_function))
# FullArgSpec(args=['a', 'b', 'c'], varargs='args', varkw='kwargs', defaults=(10,), kwonlyargs=[], kwonlydefaults=None, annotations={})
```

## 3. Dynamický přístup k atributům a jejich modifikace

Python umožňuje dynamickou manipulaci s atributy objektů za běhu, což je silná technika metaprogramování.

```python
# Dynamická správa atributů
class DynamicObject:
    def __getattr__(self, name):
        """Volá se, když vyhledávání atributu selže"""
        print(f"Atribut {name} nebyl nalezen")
        # Vytvoření atributu za běhu
        self.__dict__[name] = 0
        return 0
    
    def __setattr__(self, name, value):
        """Volá se, když je nastaven atribut"""
        print(f"Nastavuji {name} na {value}")
        self.__dict__[name] = value
    
    def __delattr__(self, name):
        """Volá se, když je atribut smazán"""
        print(f"Mažu {name}")
        del self.__dict__[name]

# Použití
obj = DynamicObject()
print(obj.non_existent)  # Vytvoří atribut 'non_existent' s hodnotou 0
obj.name = "Dynamic"     # Zavolá __setattr__
print(obj.name)          # Dynamic
del obj.name             # Zavolá __delattr__

# Přístup k atributům ve stylu slovníku
class AttrDict:
    def __init__(self, **kwargs):
        for key, value in kwargs.items():
            setattr(self, key, value)

user = AttrDict(name="Jan", age=30, email="jan@example.com")
print(user.name)  # Jan

# Dynamický přístup k atributům s getattr/setattr
class Config:
    pass

config = Config()

# Dynamické nastavení atributů
for key, value in {'debug': True, 'log_level': 'INFO', 'max_connections': 100}.items():
    setattr(config, key, value)

# Dynamický přístup k atributům
for attr in ['debug', 'log_level', 'max_connections', 'non_existent']:
    print(f"{attr}: {getattr(config, attr, 'Nenalezeno')}")
```

## 4. Generování a provádění kódu

Python poskytuje nástroje pro generování, kompilaci a provádění kódu za běhu, což umožňuje skutečně dynamické programování.

```python
# Jednoduchý příklad eval - vyhodnocení výrazů
x = 10
result = eval("x * 2 + 5")
print(result)  # 25

# Použití exec k provedení dynamických bloků kódu
code = """
def dynamic_function(x, y):
    return x * y + 10

result = dynamic_function(5, 3)
print(f"Výsledek je {result}")
"""
exec(code)  # Vypíše "Výsledek je 25"

# Dynamické vytvoření funkce
function_code = """
def greeting(name):
    return f"Ahoj, {name}!"
"""
namespace = {}
exec(function_code, namespace)
greet = namespace['greeting']
print(greet("světe"))  # "Ahoj, světe!"

# Kompilace a exec - efektivnější pro opakované použití kódu
compiled_code = compile("result = [i**2 for i in range(10)]", "<string>", "exec")
namespace = {}
exec(compiled_code, namespace)
print(namespace['result'])  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# Vytvoření funkce s dynamickým chováním na základě parametrů
def make_function(operation):
    if operation == "add":
        return lambda x, y: x + y
    elif operation == "multiply":
        return lambda x, y: x * y
    else:
        return lambda x, y: None

add = make_function("add")
multiply = make_function("multiply")
print(add(5, 3))       # 8
print(multiply(5, 3))  # 15
```

## 5. Dekorátory jako nástroje metaprogramování

Dekorátory jsou syntaktická funkce, která umožňuje upravovat funkce nebo třídy. Jsou to silné nástroje metaprogramování.

```python
import functools
import time

# Základní dekorátor
def timer(func):
    @functools.wraps(func)  # Zachovává původní metadata funkce
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"Funkce {func.__name__} trvala {end - start:.6f} sekund")
        return result
    return wrapper

@timer
def slow_function(delay=1):
    """Toto je pomalá funkce"""
    time.sleep(delay)
    return "Funkce dokončena"

print(slow_function(0.5))  # Změří čas provádění

# Dekorátor s argumenty
def repeat(n=3):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            results = []
            for _ in range(n):
                results.append(func(*args, **kwargs))
            return results
        return wrapper
    return decorator

@repeat(n=5)
def greet(name):
    return f"Ahoj, {name}!"

print(greet("světe"))  # Vrátí seznam s 5 pozdravy

# Dekorátor třídy
def add_properties(cls):
    cls.property1 = "hodnota1"
    cls.property2 = "hodnota2"
    return cls

@add_properties
class MyClass:
    def __init__(self):
        self.x = 10

obj = MyClass()
print(obj.property1)  # hodnota1
print(MyClass.property2)  # hodnota2

# Dekorátor metod pro metody tříd
def log_calls(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Volám {func.__name__} s args: {args[1:]} a kwargs: {kwargs}")
        return func(*args, **kwargs)
    return wrapper

class Calculator:
    @log_calls
    def add(self, a, b):
        return a + b

calc = Calculator()
print(calc.add(5, 3))  # Zaznamená volání a vrátí 8
```

## 6. Metatřídy a dynamické vytváření tříd

Metatřídy jsou třídy, jejichž instance jsou třídy. Umožňují přizpůsobit vytváření a chování tříd.

```python
# Základní metatřída
class Meta(type):
    def __new__(mcs, name, bases, attrs):
        # Přidání nové metody do třídy
        attrs['added_method'] = lambda self: f"Byl jsem přidán do {name}"
        # Úprava existujících metod
        if 'existing_method' in attrs:
            original_method = attrs['existing_method']
            attrs['existing_method'] = lambda self: f"Upraveno: {original_method(self)}"
        
        print(f"Vytvářím třídu: {name}")
        return super().__new__(mcs, name, bases, attrs)

    def __init__(cls, name, bases, attrs):
        print(f"Inicializuji třídu: {name}")
        super().__init__(name, bases, attrs)

# Použití metatřídy
class MyClass(metaclass=Meta):
    def existing_method(self):
        return "Původní metoda"

# Metatřída se spustí během vytváření třídy
obj = MyClass()
print(obj.added_method())      # Byl jsem přidán do MyClass
print(obj.existing_method())   # Upraveno: Původní metoda

# Dynamické vytváření tříd pomocí type
def method(self):
    return "Ahoj z dynamické metody"

DynamicClass = type('DynamicClass', (object,), {
    'x': 10,
    'y': 20,
    'method': method
})

obj = DynamicClass()
print(obj.x)          # 10
print(obj.method())   # Ahoj z dynamické metody

# Vzor metatřídy registru
class RegistryMeta(type):
    _registry = {}
    
    def __new__(mcs, name, bases, attrs):
        cls = super().__new__(mcs, name, bases, attrs)
        if name != 'BaseClass':  # Neregistrujeme základní třídu
            mcs._registry[name] = cls
        return cls
    
    @classmethod
    def get_registry(mcs):
        return dict(mcs._registry)

class BaseClass(metaclass=RegistryMeta):
    pass

class ClassA(BaseClass):
    pass

class ClassB(BaseClass):
    pass

print(RegistryMeta.get_registry())  # {'ClassA': <class '__main__.ClassA'>, 'ClassB': <class '__main__.ClassB'>}
```

## 7. Manipulace s abstraktním syntaktickým stromem

Python umožňuje manipulovat s vlastními abstraktními syntaktickými stromy (AST), což dovoluje inspekci kódu, transformaci a generování.

```python
import ast

# Parsing Python kódu do AST
code = """
def add(a, b):
    return a + b

result = add(5, 3)
"""

tree = ast.parse(code)
print(ast.dump(tree, indent=4))  # Vypíše strukturu AST

# Jednoduchý AST návštěvník
class FunctionVisitor(ast.NodeVisitor):
    def __init__(self):
        self.functions = []
    
    def visit_FunctionDef(self, node):
        self.functions.append(node.name)
        self.generic_visit(node)  # Navštíví potomky

visitor = FunctionVisitor()
visitor.visit(tree)
print(f"Nalezené funkce: {visitor.functions}")  # Nalezené funkce: ['add']

# AST transformace - přidání ladicích výpisů
class DebugTransformer(ast.NodeTransformer):
    def visit_FunctionDef(self, node):
        # Vytvoření výpisu: print(f"Volám {func_name} s argumenty: {args}")
        debug_print = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[
                    ast.JoinedStr(values=[
                        ast.Constant(value=f"Volám {node.name} s argumenty: "),
                        ast.FormattedValue(
                            value=ast.Tuple(
                                elts=[ast.Name(id=arg.arg, ctx=ast.Load()) for arg in node.args.args],
                                ctx=ast.Load()
                            ),
                            conversion=-1
                        )
                    ])
                ],
                keywords=[]
            )
        )
        
        # Přidání výpisu na začátek těla funkce
        node.body.insert(0, debug_print)
        return node

# Aplikace transformace
transformed_tree = ast.fix_missing_locations(DebugTransformer().visit(tree))

# Kompilace a provedení transformovaného AST
code_object = compile(transformed_tree, "<ast>", "exec")
namespace = {}
exec(code_object, namespace)

# Volání funkce z transformovaného AST
namespace['add'](10, 20)  # Vypíše "Volám add s argumenty: (10, 20)" a vrátí 30
```

## 8. Praktické aplikace

Prozkoumejme některé praktické aplikace technik metaprogramování v reálných scénářích.

```python
# 1. Vytvoření systému podobného ORM
class Field:
    def __init__(self, field_type, required=False):
        self.field_type = field_type
        self.required = required

class ModelMeta(type):
    def __new__(mcs, name, bases, attrs):
        # Extrakce polí z atributů třídy
        fields = {}
        for key, value in list(attrs.items()):
            if isinstance(value, Field):
                fields[key] = value
                del attrs[key]  # Odstranění pole z atributů třídy
        
        attrs['_fields'] = fields
        
        # Přidání metody validace
        def validate(self, data):
            errors = {}
            for field_name, field in self._fields.items():
                if field_name not in data:
                    if field.required:
                        errors[field_name] = "Toto pole je povinné"
                elif not isinstance(data[field_name], field.field_type):
                    errors[field_name] = f"Musí být typu {field.field_type.__name__}"
            return errors
        
        attrs['validate'] = validate
        
        return super().__new__(mcs, name, bases, attrs)

class Model(metaclass=ModelMeta):
    pass

# Použití našeho systému podobného ORM
class User(Model):
    name = Field(str, required=True)
    age = Field(int, required=True)
    email = Field(str, required=True)

# Validace uživatelských dat
user_data = {
    "name": "Jan",
    "age": 30,
    # Chybí email
}

user = User()
validation_errors = user.validate(user_data)
print(validation_errors)  # {'email': 'Toto pole je povinné'}

# 2. Systém pluginů
class PluginManager:
    def __init__(self):
        self.plugins = {}
    
    def register(self, plugin_name):
        def decorator(cls):
            self.plugins[plugin_name] = cls
            return cls
        return decorator
    
    def get_plugin(self, plugin_name):
        return self.plugins.get(plugin_name)

# Vytvoření správce pluginů
manager = PluginManager()

# Registrace pluginů
@manager.register("text_processor")
class TextProcessor:
    def process(self, text):
        return text.upper()

@manager.register("number_processor")
class NumberProcessor:
    def process(self, number):
        return number * 2

# Dynamické využití pluginů
data = ["ahoj", 10, "svět", 20]
processors = {
    str: manager.get_plugin("text_processor"),
    int: manager.get_plugin("number_processor")
}

for item in data:
    processor_class = processors.get(type(item))
    if processor_class:
        processor = processor_class()
        print(f"Zpracováno {item}: {processor.process(item)}")
```

## 9. Osvědčené postupy a omezení

Metaprogramování je mocné, ale mělo by být používáno s rozvahou. Zde jsou některé osvědčené postupy a omezení, která je třeba zvážit.

```python
# OSVĚDČENÝ POSTUP 1: Jasně dokumentujte metaprogramování
class AutoProperty(type):
    """
    Metatřída, která automaticky vytváří metody getter a setter
    pro atributy s prefixem '_' v definici třídy.
    
    Příklad:
        class Person(metaclass=AutoProperty):
            _name = "Default"  # Vytvoří vlastnost name
    """
    def __new__(mcs, name, bases, attrs):
        # Generování vlastností pro atributy začínající '_'
        for key, value in list(attrs.items()):
            if key.startswith('_') and not key.startswith('__'):
                prop_name = key[1:]  # Odstranění počátečního podtržítka
                
                # Vytvoření getteru
                getter_name = f"get_{prop_name}"
                if getter_name not in attrs:
                    attrs[getter_name] = lambda self, key=key: getattr(self, key)
                
                # Vytvoření setteru
                setter_name = f"set_{prop_name}"
                if setter_name not in attrs:
                    attrs[setter_name] = lambda self, value, key=key: setattr(self, key, value)
                
                # Vytvoření vlastnosti
                attrs[prop_name] = property(attrs[getter_name], attrs[setter_name])
        
        return super().__new__(mcs, name, bases, attrs)

# OSVĚDČENÝ POSTUP 2: Vyhněte se příliš složitému metaprogramování
# Špatný příklad - zbytečná složitost
def create_class_with_methods(*method_names):
    attrs = {}
    for name in method_names:
        # Dynamické vytváření metod - těžko se ladí a chápe
        attrs[name] = eval(f"lambda self, x: f'Volána metoda {name} s {{x}}'")
    return type('DynamicClass', (object,), attrs)

# Lepší přístup - explicitnější a čitelnější
def create_class_with_methods_better(*method_names):
    attrs = {}
    
    def make_method(name):
        def method(self, x):
            return f"Volána metoda {name} s {x}"
        return method
    
    for name in method_names:
        attrs[name] = make_method(name)
    
    return type('DynamicClass', (object,), attrs)

# OMEZENÍ: Ladění může být obtížné
# Příklad ukazující složitost trasování zásobníku s metaprogramováním
def debug_example():
    try:
        # Dynamické vytvoření funkce
        func_code = "def problematic(): return 1/0"
        namespace = {}
        exec(func_code, namespace)
        
        # Volání funkce
        namespace['problematic']()
    except Exception as e:
        import traceback
        print("Došlo k chybě v dynamicky vytvořeném kódu:")
        traceback.print_exc()

debug_example()

# OMEZENÍ: Režie výkonu
import time

# Měření rozdílu výkonu mezi přímým a dynamickým voláním
def direct_function(x):
    return x * 2

def measure_performance():
    # Přímé volání
    start = time.time()
    for _ in range(1000000):
        direct_function(10)
    direct_time = time.time() - start
    
    # Dynamické volání pomocí getattr
    functions = {'func': direct_function}
    start = time.time()
    for _ in range(1000000):
        getattr(functions['func'], '__call__')(10)
    dynamic_time = time.time() - start
    
    print(f"Čas přímého volání: {direct_time:.6f} sekund")
    print(f"Čas dynamického volání: {dynamic_time:.6f} sekund")
    print(f"Dynamická volání jsou {dynamic_time/direct_time:.2f}x pomalejší")

measure_performance()
```

## 10. Shrnutí

Metaprogramování v Pythonu využívá dynamickou povahu jazyka k zkoumání, generování a modifikaci kódu za běhu, což umožňuje použití výkonných programovacích technik:

1. **Introspekce** umožňuje zkoumat objekty za běhu, odhalujíc informace o typech, metodách a atributech.
2. **Dynamický přístup k atributům a jejich modifikace** umožňuje vytvářet flexibilní API a adaptabilní objekty.
3. **Generování a provádění kódu** umožňuje vytvářet a spouštět kód za běhu, přizpůsobovat se měnícím se požadavkům.
4. **Dekorátory** poskytují syntakticky příjemný způsob, jak upravovat funkce a třídy, implementovat průřezové zájmy.
5. **Metatřídy** umožňují přizpůsobit vytváření tříd, vynucovat omezení nebo automaticky přidávat funkcionalitu do tříd.
6. **Manipulace s abstraktním syntaktickým stromem** nabízí nízkoúrovňovou kontrolu nad strukturou kódu a jeho prováděním.

Tyto techniky umožňují výkonné aplikace jako ORM, systémy pluginů, DSL a vývoj frameworků. Metaprogramování by však mělo být používáno s rozvahou, protože může vést k tomu, že kód bude obtížnější pochopit, ladit a udržovat.
