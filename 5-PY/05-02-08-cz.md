## 1. Úvod do argumentů s proměnnou délkou

Python nabízí flexibilní způsoby, jak definovat funkce, které mohou přijímat různý počet argumentů. Tato flexibilita je dosažena pomocí speciální syntaxe s použitím hvězdiček:

- `*args`: Umožňuje funkci přijmout libovolný počet pozičních argumentů
- `**kwargs`: Umožňuje funkci přijmout libovolný počet klíčových argumentů

Tyto funkce činí funkce v Pythonu vysoce adaptabilní a znovupoužitelné, což vám umožňuje psát obecnější a flexibilnější kód.

```python
# Běžná funkce s pevnými parametry
def pevna_funkce(a, b, c):
    return a + b + c

# Funkce s proměnným počtem argumentů
def flexibilni_funkce(*args, **kwargs):
    print(f"Poziční argumenty (args): {args}")
    print(f"Klíčové argumenty (kwargs): {kwargs}")
    
# Příklady volání těchto funkcí
print(pevna_funkce(1, 2, 3))  # Výstup: 6

flexibilni_funkce(1, 2, 3, name="Python", version=3.9)
# Výstup:
# Poziční argumenty (args): (1, 2, 3)
# Klíčové argumenty (kwargs): {'name': 'Python', 'version': 3.9}
```

## 2. Pochopení `*args` (poziční argumenty s proměnnou délkou)

Syntaxe `*args` umožňuje funkci přijmout libovolný počet pozičních argumentů. Uvnitř funkce je `args` n-tice (tuple) obsahující všechny poziční argumenty, které byly předány.

```python
def secti_vse(*args):
    """Vypočítá součet všech argumentů."""
    vysledek = 0
    for cislo in args:
        vysledek += cislo
    return vysledek

# Použití funkce s různým počtem argumentů
print(secti_vse(1, 2))            # Výstup: 3
print(secti_vse(1, 2, 3, 4, 5))   # Výstup: 15
print(secti_vse())                # Výstup: 0

# Můžete také kombinovat *args s běžnými parametry
def predstav(pozdrav, *jmena):
    """Představí lidi s pozdravem."""
    for jmeno in jmena:
        print(f"{pozdrav}, {jmeno}!")

predstav("Ahoj", "Alice", "Bob", "Charlie")
# Výstup:
# Ahoj, Alice!
# Ahoj, Bob!
# Ahoj, Charlie!

# Běžné parametry musí být před *args
def vypocitej_celkem(sazba_dane, *ceny):
    """Vypočítá celkovou cenu včetně daně."""
    mezisoučet = sum(ceny)
    celkem = mezisoučet * (1 + sazba_dane)
    return celkem

print(vypocitej_celkem(0.1, 10, 20, 30))  # Výstup: 66.0 (60 + 10% daň)
```

Všimněte si, že parametr s prefixem `*` může mít jakýkoliv název, ale `args` je konvenční volba:

```python
def priklad(*pozicni_args):
    print(pozicni_args)

priklad(1, 2, 3)  # Výstup: (1, 2, 3)
```

## 3. Pochopení `**kwargs` (klíčové argumenty s proměnnou délkou)

Syntaxe `**kwargs` umožňuje funkci přijmout libovolný počet klíčových argumentů (argumentů předaných se jmény). Uvnitř funkce je `kwargs` slovník, kde klíče jsou názvy argumentů a hodnoty jsou hodnoty argumentů.

```python
def zobraz_info(**kwargs):
    """Zobrazí informace z klíčových argumentů."""
    for klic, hodnota in kwargs.items():
        print(f"{klic}: {hodnota}")

# Volání s různými klíčovými argumenty
zobraz_info(jmeno="Alice", vek=30, zeme="USA")
# Výstup:
# jmeno: Alice
# vek: 30
# zeme: USA

# Další příklad s konfigurací uživatele
def vytvor_profil(**uzivatelska_data):
    """Vytvoří uživatelský profil s poskytnutými daty."""
    vychozi = {
        "jazyk": "Čeština",
        "tema": "Světlé",
        "oznameni": True
    }
    
    # Aktualizace výchozích hodnot uživatelem poskytnutými hodnotami
    profil = {**vychozi, **uzivatelska_data}
    return profil

profil = vytvor_profil(jmeno="Bob", tema="Tmavé")
print(profil)
# Výstup: {'jazyk': 'Čeština', 'tema': 'Tmavé', 'oznameni': True, 'jmeno': 'Bob'}
```

Podobně jako u `*args` můžete použít jakýkoli název po prefixu `**`, ale `kwargs` (zkratka pro klíčové argumenty) je konvence:

```python
def priklad(**pojmenovane_parametry):
    print(pojmenovane_parametry)

priklad(a=1, b=2, c=3)  # Výstup: {'a': 1, 'b': 2, 'c': 3}
```

## 4. Kombinace `*args` a `**kwargs`

Ve stejné definici funkce můžete použít jak `*args`, tak `**kwargs`, abyste mohli přijmout libovolnou kombinaci pozičních a klíčových argumentů. Při tom musí `*args` předcházet `**kwargs`.

```python
def univerzalni_funkce(*args, **kwargs):
    """Přijme libovolnou kombinaci argumentů."""
    print(f"Poziční argumenty: {args}")
    print(f"Klíčové argumenty: {kwargs}")

univerzalni_funkce(1, 2, 3, a="jablko", b="banán")
# Výstup:
# Poziční argumenty: (1, 2, 3)
# Klíčové argumenty: {'a': 'jablko', 'b': 'banán'}

# Praktičtější příklad: vytvoření konfigurovatelného formátovače
def formatuj_zpravu(sablona, *hodnoty, **nahrazeni):
    """Formátuje zprávu s pozičními hodnotami a klíčovými nahrazeními."""
    # Nejprve nahraďte všechny poziční zástupné symboly (např. {0}, {1})
    formatovano = sablona.format(*hodnoty)
    
    # Poté nahraďte pojmenované zástupné symboly
    for klic, hodnota in nahrazeni.items():
        formatovano = formatovano.replace(f"{{{klic}}}", str(hodnota))
    
    return formatovano

zprava = formatuj_zpravu(
    "Ahoj {0}, tvoje {polozka} je připravena v {misto}!",
    "Alice",
    polozka="objednávka",
    misto="recepce"
)
print(zprava)  # Výstup: Ahoj Alice, tvoje objednávka je připravena v recepce!
```

Při definování funkce, která kombinuje běžné parametry s `*args` a `**kwargs`, by se měly objevit v tomto pořadí:

1. Běžné poziční parametry
2. `*args` pro proměnné poziční argumenty
3. Běžné klíčové parametry (s výchozími hodnotami)
4. `**kwargs` pro proměnné klíčové argumenty

```python
def komplexni_funkce(a, b, *args, volba=True, **kwargs):
    print(f"a: {a}")
    print(f"b: {b}")
    print(f"args: {args}")
    print(f"volba: {volba}")
    print(f"kwargs: {kwargs}")

komplexni_funkce(1, 2, 3, 4, 5, volba=False, x="extra", y="více")
# Výstup:
# a: 1
# b: 2
# args: (3, 4, 5)
# volba: False
# kwargs: {'x': 'extra', 'y': 'více'}
```

## 5. Rozbalování pomocí operátorů `*` a `**`

Operátory `*` a `**` lze také použít při volání funkcí k rozbalení sekvencí a slovníků:

```python
# Rozbalení seznamu na poziční argumenty
cisla = [1, 2, 3]
print(secti_vse(*cisla))  # Ekvivalent k secti_vse(1, 2, 3)

# Rozbalení slovníku na klíčové argumenty
osoba = {"jmeno": "David", "vek": 35, "zeme": "Kanada"}
zobraz_info(**osoba)  # Ekvivalent k zobraz_info(jmeno="David", vek=35, zeme="Kanada")

# Praktický příklad: Sloučení slovníků (Python 3.5+)
vychozi = {"tema": "světlé", "jazyk": "cs", "timeout": 30}
uzivatelske_nastaveni = {"tema": "tmavé", "velikost_pisma": 14}

# Sloučení slovníků s rozbalením
nastaveni = {**vychozi, **uzivatelske_nastaveni}
print(nastaveni)
# Výstup: {'tema': 'tmavé', 'jazyk': 'cs', 'timeout': 30, 'velikost_pisma': 14}

# Rozbalování při volání funkcí s dodatečnými argumenty
def vytvor_uzivatele(uzivatelske_jmeno, email, **detaily):
    uzivatel = {
        "uzivatelske_jmeno": uzivatelske_jmeno,
        "email": email,
        **detaily  # Rozbalení dodatečných detailů do slovníku
    }
    return uzivatel

zakladni_detaily = {"aktivni": True, "registrovan": "2023-01-15"}
uzivatel = vytvor_uzivatele("jannovak", "jan@example.com", **zakladni_detaily, role="admin")
print(uzivatel)
# Výstup: {'uzivatelske_jmeno': 'jannovak', 'email': 'jan@example.com', 'aktivni': True, 'registrovan': '2023-01-15', 'role': 'admin'}
```

Můžete také rozbalit více sekvencí:

```python
# Kombinování prvků z více seznamů
seznam1 = [1, 2, 3]
seznam2 = [4, 5, 6]
kombinovane = [*seznam1, *seznam2]
print(kombinovane)  # Výstup: [1, 2, 3, 4, 5, 6]

# Funguje s jakýmkoliv iterovatelným objektem
n_tice1 = (7, 8)
mnozina1 = {9, 10}
vice_kombinovanych = [*seznam1, *n_tice1, *mnozina1]
print(vice_kombinovanych)  # Výstup může být: [1, 2, 3, 7, 8, 9, 10] (pořadí prvků množiny se může lišit)
```

## 6. Předávání funkcí a dekorátory

Jednou z nejsilnějších aplikací `*args` a `**kwargs` je v obalovačích funkcí a dekorátorech, kde umožňují předávat všechny argumenty z jedné funkce do druhé:

```python
import time
import functools

def casovaci_dekorator(funkce):
    """Dekorátor, který hlásí dobu provedení."""
    @functools.wraps(funkce)
    def wrapper(*args, **kwargs):
        cas_zacatku = time.time()
        vysledek = funkce(*args, **kwargs)  # Předává všechny argumenty původní funkci
        cas_konce = time.time()
        print(f"{funkce.__name__} trvala {cas_konce - cas_zacatku:.4f} sekund")
        return vysledek
    return wrapper

@casovaci_dekorator
def zpracuj_data(data, faktor=2, **moznosti):
    """Zpracuje data s daným faktorem a možnostmi."""
    time.sleep(1)  # Simulace doby zpracování
    return [polozka * faktor for polozka in data]

# Dekorátor funguje s libovolnými argumenty, které předáme
vysledek = zpracuj_data([1, 2, 3, 4, 5], faktor=3, podrobne=True)
print(vysledek)
# Výstup:
# zpracuj_data trvala 1.0012 sekund
# [3, 6, 9, 12, 15]
```

Dalším běžným případem použití je vytváření obalů API:

```python
def api_pozadavek(endpoint, metoda="GET", *args, **kwargs):
    """Zjednodušená funkce API požadavku."""
    print(f"Provádím {metoda} požadavek na {endpoint}")
    
    # Zaznamenání všech dodatečných argumentů
    if args:
        print(f"Dodatečné poziční argumenty: {args}")
    if kwargs:
        print(f"Dodatečné klíčové argumenty: {kwargs}")
    
    # Ve skutečnosti by to používalo requests nebo jinou HTTP knihovnu
    return {"stav": "úspěch", "endpoint": endpoint}

# Základní použití
api_pozadavek("/uzivatele")

# S dodatečnými možnostmi
api_pozadavek("/prispevky", "POST", 
            json={"titulek": "Nový příspěvek", "obsah": "Obsah"}, 
            headers={"Authorization": "Bearer token"})
# Výstup:
# Provádím POST požadavek na /prispevky
# Dodatečné klíčové argumenty: {'json': {'titulek': 'Nový příspěvek', 'obsah': 'Obsah'}, 'headers': {'Authorization': 'Bearer token'}}
```

### Systémy pluginů

```python
class SpravcePluginu:
    def __init__(self):
        self.pluginy = {}
    
    def zaregistruj_plugin(self, nazev, plugin_funkce):
        """Zaregistruje plugin funkci."""
        self.pluginy[nazev] = plugin_funkce
        print(f"Zaregistrován plugin: {nazev}")
    
    def spust_plugin(self, nazev, *args, **kwargs):
        """Spustí plugin s dynamickými argumenty."""
        if nazev in self.pluginy:
            return self.pluginy[nazev](*args, **kwargs)
        else:
            raise ValueError(f"Plugin '{nazev}' nenalezen")

# Vytvoření správce pluginů
spravce = SpravcePluginu()

# Definice a registrace některých pluginů
def zpracovatel_textu(text, velka_pismena=False, obratit=False):
    """Plugin, který zpracovává text."""
    vysledek = text
    if velka_pismena:
        vysledek = vysledek.upper()
    if obratit:
        vysledek = vysledek[::-1]
    return vysledek

spravce.zaregistruj_plugin("text", zpracovatel_textu)

# Spuštění pluginu s různými parametry
print(spravce.spust_plugin("text", "Ahoj světe"))
print(spravce.spust_plugin("text", "Ahoj světe", velka_pismena=True))
print(spravce.spust_plugin("text", "Ahoj světe", obratit=True))
print(spravce.spust_plugin("text", "Ahoj světe", velka_pismena=True, obratit=True))
# Výstup:
# Zaregistrován plugin: text
# Ahoj světe
# AHOJ SVĚTE
# etěvs johA
# ETĚVS JOHA
```

### Časté chyby

1. **Konflikty v pořadí parametrů**: Nezapomeňte, že poziční argumenty musí předcházet klíčovým argumentům.

```python
# Toto funguje
def dobra_funkce(a, b, *args, c=10, **kwargs):
    pass

# Toto vyvolá SyntaxError - poziční argument po klíčovém argumentu
def spatna_funkce(a, b=5, *args, c, **kwargs):
    pass
```

2. **Chyby při rozbalování**: Ujistěte se, že objekt, který rozbalujete s `*`, je iterovatelný, a objekt, který rozbalujete s `**`, je mapování.

```python
def secti(a, b):
    return a + b

# Toto funguje
hodnoty = (1, 2)
print(secti(*hodnoty))

# Toto vyvolá TypeError - 5 není iterovatelné
cislo = 5
try:
    print(secti(*cislo))
except TypeError as e:
    print(f"Chyba: {e}")
```

3. **Neúmyslná modifikace měnitelných výchozích argumentů**:

```python
# Problematická funkce
def pridat_k(prvek, cilovy=[]):
    cilovy.append(prvek)
    return cilovy

print(pridat_k(1))  # Výstup: [1]
print(pridat_k(2))  # Výstup: [1, 2] - ne nový seznam!

# Lepší přístup s použitím kwargs
def lepsi_pridat_k(prvek, **kwargs):
    cilovy = kwargs.get('cilovy', [])
    if 'cilovy' not in kwargs:  # Pokud cilovy nebyl poskytnut, vytvoř nový seznam
        cilovy = []
    cilovy.append(prvek)
    return cilovy

print(lepsi_pridat_k(1))  # Výstup: [1]
print(lepsi_pridat_k(2))  # Výstup: [2] - nový seznam
```

4. **Úvahy o výkonu**: Používání `*args` a `**kwargs` může být mírně pomalejší než použití pevných parametrů.

```python
import timeit

def pevna(a, b, c):
    return a + b + c

def flexibilni(*args):
    return sum(args)

# Porovnání výkonu
cas_pevny = timeit.timeit("pevna(1, 2, 3)", globals={"pevna": pevna}, number=1000000)
cas_flexibilni = timeit.timeit("flexibilni(1, 2, 3)", globals={"flexibilni": flexibilni}, number=1000000)

print(f"Pevné parametry: {cas_pevny:.6f} sekund")
print(f"*args: {cas_flexibilni:.6f} sekund")
# *args je obvykle mírně pomalejší, ale rozdíl je zanedbatelný pro většinu aplikací
```

## 9. Shrnutí

Argumenty s proměnnou délkou v Pythonu poskytují mocnou flexibilitu pro definice funkcí:

- **`*args`** umožňuje přijímat libovolný počet pozičních argumentů, shromážděných jako n-tice
- **`**kwargs`** umožňuje přijímat libovolný počet klíčových argumentů, shromážděných jako slovník
- Tyto funkce lze kombinovat k vytvoření vysoce flexibilních funkcí
- Operátory rozbalování (`*` a `**`) lze také použít při volání funkcí k předání více argumentů ze sekvencí a mapování
- Běžné aplikace zahrnují obalovače funkcí, dekorátory a návrh API
- Osvědčené postupy zahrnují používání smysluplných názvů parametrů a dokumentování očekávaných argumentů

Pochopení, jak pracovat s `*args` a `**kwargs`, je nezbytné pro psaní adaptabilního, znovupoužitelného kódu v Pythonu, zejména při navrhování frameworků a knihoven, které musí vyhovět široké škále případů použití.
