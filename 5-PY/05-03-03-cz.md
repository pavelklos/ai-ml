## 1. Úvod do asynchronního programování

Asynchronní programování umožňuje psát souběžný kód bez použití vláken nebo multiprocesingu. Je obzvláště efektivní pro I/O vázané operace, kde program tráví značný čas čekáním na externí zdroje jako sítě, soubory nebo databáze.

Pythonova knihovna `asyncio` poskytuje nástroje pro psaní asynchronního kódu pomocí syntaxe `async`/`await`, což činí souběžný kód čitelnějším a udržovatelnějším.

Tradiční synchronní versus asynchronní přístup:

```python
# Synchronní přístup - blokující
import time

def stahnout_stranku(url):
    print(f"Stahuji {url}")
    # Simulace síťového zpoždění
    time.sleep(1)
    print(f"Dokončeno stahování {url}")

def stahnout_vsechny_stranky(stranky):
    for stranka in stranky:
        stahnout_stranku(stranka)

stranky = ["stranka1.cz", "stranka2.cz", "stranka3.cz"]
cas_zacatku = time.time()
stahnout_vsechny_stranky(stranky)
cas_konce = time.time()
print(f"Staženo {len(stranky)} stránek za {cas_konce - cas_zacatku:.2f} sekund")
# Výstup: Staženo 3 stránek za 3.00 sekund
```

```python
# Asynchronní přístup - neblokující
import asyncio

async def stahnout_stranku_async(url):
    print(f"Začínám stahovat {url}")
    # Simulace síťového zpoždění bez blokování
    await asyncio.sleep(1)
    print(f"Dokončeno stahování {url}")

async def stahnout_vsechny_stranky_async(stranky):
    ulohy = [stahnout_stranku_async(stranka) for stranka in stranky]
    # Spustit všechny úlohy souběžně
    await asyncio.gather(*ulohy)

async def main():
    stranky = ["stranka1.cz", "stranka2.cz", "stranka3.cz"]
    cas_zacatku = time.time()
    await stahnout_vsechny_stranky_async(stranky)
    cas_konce = time.time()
    print(f"Staženo {len(stranky)} stránek za {cas_konce - cas_zacatku:.2f} sekund")
    # Výstup: Staženo 3 stránek za 1.01 sekund

# Spuštění hlavní funkce
asyncio.run(main())
```

Klíčové výhody asynchronního programování s `asyncio`:
1. Zlepšený výkon pro I/O vázané operace
2. Jednovláknová souběžnost (vyhýbá se komplikacím synchronizace vláken)
3. Čitelnější kód se syntaxí `async`/`await`
4. Lepší využití zdrojů

## 2. Pochopení korutin a syntaxe async/await

Korutiny jsou speciální funkce, které mohou být pozastaveny a obnoveny, což umožňuje mezitím spuštění jiného kódu. V Pythonu definujeme korutiny pomocí klíčového slova `async` a voláme je pomocí `await`.

```python
import asyncio

# Jednoduchá korutina
async def hello_world():
    print("Ahoj...")
    await asyncio.sleep(1)  # Neblokující uspání
    print("...světe!")
    return "Dokončeno"

# Další korutina, která volá první
async def main():
    print("Spouštím hlavní funkci")
    vysledek = await hello_world()  # Pozastaví main, dokud se hello_world nedokončí
    print(f"Výsledek: {vysledek}")

# Spuštění event loopu
asyncio.run(main())
```

Klíčové koncepty:

- `async def` - Definuje funkci korutiny
- `await` - Pozastaví aktuální korutinu, dokud se očekávaná operace nedokončí
- Pouze korutiny mohou používat klíčové slovo `await`
- Volání funkce korutiny ji nespouští; vrací objekt korutiny

```python
# Pochopení korutin
async def priklad_korutiny():
    print("Toto je korutina")
    return "Výsledek"

# Pouhé volání funkce ji nespouští
koro = priklad_korutiny()
print(f"Typ koro: {type(koro)}")  # <class 'coroutine'>

# Musíme ji očekávat (await) nebo naplánovat pomocí asyncio
async def spustit():
    vysledek = await koro
    print(f"Získáno: {vysledek}")

asyncio.run(spustit())
```

## 3. Práce s event loopy

Event loop je jádrem každé asyncio aplikace. Spouští asynchronní úlohy, zpracovává události síťového I/O a spouští podprocesy.

```python
import asyncio

async def uloha_jedna():
    print("Úloha jedna: Začala")
    await asyncio.sleep(2)
    print("Úloha jedna: Dokončena")
    return "Výsledek z úlohy jedna"

async def uloha_dva():
    print("Úloha dva: Začala")
    await asyncio.sleep(1)
    print("Úloha dva: Dokončena")
    return "Výsledek z úlohy dva"

async def main():
    # Získat běžící event loop
    loop = asyncio.get_running_loop()
    
    # Vytvořit a naplánovat úlohy
    print("Vytvářím úlohy...")
    uloha_1 = loop.create_task(uloha_jedna())
    uloha_2 = loop.create_task(uloha_dva())
    
    # Čekat na dokončení obou úloh
    print("Čekám na dokončení úloh...")
    vysledky = await asyncio.gather(uloha_1, uloha_2)
    
    print(f"Výsledky: {vysledky}")

# Spustit hlavní korutinu
asyncio.run(main())
```

Různé způsoby spouštění korutin:

```python
import asyncio

async def pozdrav():
    await asyncio.sleep(1)
    return "Ahoj"

# Metoda 1: asyncio.run() (Python 3.7+)
vysledek = asyncio.run(pozdrav())

# Metoda 2: Přímé použití event loopu (starší verze Pythonu)
loop = asyncio.get_event_loop()
vysledek = loop.run_until_complete(pozdrav())

# Metoda 3: Vytvoření nového event loopu
novy_loop = asyncio.new_event_loop()
asyncio.set_event_loop(novy_loop)
vysledek = novy_loop.run_until_complete(pozdrav())
novy_loop.close()
```

## 4. Úlohy a Future objekty

Úlohy se používají k plánování korutin souběžně. Úloha je podtřída třídy Future, která obaluje korutinu a umožňuje sledovat její provádění.

```python
import asyncio
import time

async def zpracovavajici_uloha(nazev, doba_trvani):
    print(f"Úloha {nazev} začala, zabere {doba_trvani} sekund")
    await asyncio.sleep(doba_trvani)  # Simulace práce
    print(f"Úloha {nazev} dokončena")
    return f"Výsledek z {nazev}"

async def main():
    # Explicitní vytvoření úloh
    uloha1 = asyncio.create_task(zpracovavajici_uloha("A", 3))
    uloha2 = asyncio.create_task(zpracovavajici_uloha("B", 2))
    uloha3 = asyncio.create_task(zpracovavajici_uloha("C", 1))
    
    # Čekání na konkrétní úlohu
    print("Čekám na úlohu C...")
    vysledek_c = await uloha3
    print(f"Získán dřívější výsledek: {vysledek_c}")
    
    # Čekání na zbývající úlohy
    print("Čekám na zbývající úlohy...")
    vysledky = await asyncio.gather(uloha1, uloha2)
    print(f"Všechny výsledky: {[vysledek_c] + vysledky}")

asyncio.run(main())
```

Práce s future objekty:

```python
import asyncio
import concurrent.futures
import time

def vypocetne_narocna_prace(cislo):
    """Výpočetně náročná operace, která počítá Fibonacciho čísla"""
    print(f"Počítám fibonacci({cislo})...")
    if cislo <= 1:
        return cislo
    vysledek = vypocetne_narocna_prace(cislo - 1) + vypocetne_narocna_prace(cislo - 2)
    return vysledek

async def main():
    print("Spouštím hlavní funkci")
    
    # Vytvoření ThreadPoolExecutor pro výpočetně náročnou práci
    with concurrent.futures.ThreadPoolExecutor() as pool:
        # Naplánování výpočetně náročné práce v poolu vláken
        cisla = [30, 28, 26]
        
        # Převod vláken na očekávatelné future
        futures = [
            asyncio.get_running_loop().run_in_executor(pool, vypocetne_narocna_prace, cislo)
            for cislo in cisla
        ]
        
        print("Provádění jiné asynchronní práce, zatímco výpočet běží...")
        await asyncio.sleep(0.5)
        print("Stále čekám na výsledky výpočtu...")
        
        # Čekání na dokončení všech futures
        vysledky = await asyncio.gather(*futures)
        print(f"Výsledky: {vysledky}")

asyncio.run(main())
```

## 5. Asynchronní I/O operace

Knihovna `asyncio` poskytuje asynchronní verze běžných I/O operací:

```python
import asyncio
import aiohttp
import aiofiles

async def nacist_url(url, session):
    """Asynchronně načíst URL"""
    print(f"Načítám {url}")
    async with session.get(url) as response:
        return await response.text()

async def ulozit_obsah(nazev_souboru, obsah):
    """Asynchronně uložit obsah do souboru"""
    print(f"Ukládám obsah do {nazev_souboru}")
    async with aiofiles.open(nazev_souboru, 'w') as soubor:
        await soubor.write(obsah)
    print(f"Uloženo {nazev_souboru}")

async def stahnout_a_ulozit(url, nazev_souboru):
    """Stáhnout URL a uložit do souboru"""
    async with aiohttp.ClientSession() as session:
        obsah = await nacist_url(url, session)
        await ulozit_obsah(nazev_souboru, obsah)
        return len(obsah)

async def main():
    url_adresy = [
        ('https://python.org', 'python.html'),
        ('https://github.com', 'github.html'),
        ('https://stackoverflow.com', 'stackoverflow.html')
    ]
    
    # Zpracovat všechna stahování souběžně
    ulohy = [stahnout_a_ulozit(url, nazev_souboru) for url, nazev_souboru in url_adresy]
    velikosti = await asyncio.gather(*ulohy)
    
    for (url, nazev_souboru), velikost in zip(url_adresy, velikosti):
        print(f"Staženo {url} do {nazev_souboru} ({velikost} bajtů)")

# Pro spuštění tohoto příkladu potřebujete:
# pip install aiohttp aiofiles
# asyncio.run(main())
```

Práce s asynchronními iterátory:

```python
import asyncio
from aiohttp import ClientSession

async def nacist_radky(url, session):
    """Načíst URL a poskytovat řádky z odpovědi"""
    async with session.get(url) as response:
        # Čtení řádek po řádce
        async for radek in response.content:
            yield radek.decode('utf-8').strip()

async def zpracovat_url(url):
    async with ClientSession() as session:
        pocet_radku = 0
        async for radek in nacist_radky(url, session):
            if radek:
                pocet_radku += 1
                if pocet_radku <= 3:  # Zobrazit pouze první 3 řádky
                    print(f"Řádek {pocet_radku}: {radek[:50]}...")
        
        print(f"Celkem řádků: {pocet_radku}")

async def main():
    await zpracovat_url('https://python.org')

# asyncio.run(main())
```

## 6. Synchronizační primitivy

Asyncio poskytuje synchronizační primitivy podobné těm v modulu `threading`:

```python
import asyncio
import random

# Použití zámku (Lock)
async def pracovnik(zamek, id_pracovnika):
    print(f"Pracovník {id_pracovnika} čeká na získání zámku")
    async with zamek:
        print(f"Pracovník {id_pracovnika} získal zámek")
        # Simulace práce
        await asyncio.sleep(random.uniform(0.5, 1.5))
    print(f"Pracovník {id_pracovnika} uvolnil zámek")

async def priklad_zamku():
    zamek = asyncio.Lock()
    pracovnici = [pracovnik(zamek, i) for i in range(3)]
    await asyncio.gather(*pracovnici)

# Použití semaforu k omezení souběžnosti
async def pracovnik_s_limitem(semafor, id_pracovnika):
    print(f"Pracovník {id_pracovnika} čeká na semafor")
    async with semafor:
        print(f"Pracovník {id_pracovnika} získal semafor")
        # Simulace práce
        await asyncio.sleep(random.uniform(1, 2))
    print(f"Pracovník {id_pracovnika} uvolnil semafor")

async def priklad_semaforu():
    # Povolit pouze 2 souběžné operace
    semafor = asyncio.Semaphore(2)
    pracovnici = [pracovnik_s_limitem(semafor, i) for i in range(5)]
    await asyncio.gather(*pracovnici)

# Použití události pro signalizaci
async def cekal(udalost, id_cekatele):
    print(f"Čekatel {id_cekatele} čeká na událost")
    await udalost.wait()
    print(f"Čekatel {id_cekatele} obdržel událost, pokračuje")

async def nastavovac(udalost):
    print("Nastavovač: vykonávám nějakou práci před nastavením události")
    await asyncio.sleep(2)
    print("Nastavovač: nastavuji událost")
    udalost.set()

async def priklad_udalosti():
    udalost = asyncio.Event()
    cekatele = [cekal(udalost, i) for i in range(3)]
    await asyncio.gather(*cekatele, nastavovac(udalost))

async def main():
    print("Příklad zámku:")
    await priklad_zamku()
    print("\nPříklad semaforu:")
    await priklad_semaforu()
    print("\nPříklad události:")
    await priklad_udalosti()

# asyncio.run(main())
```

## 7. Zpracování chyb v asynchronním kódu

Zpracování chyb v asynchronním kódu vyžaduje zvláštní pozornost:

```python
import asyncio

async def muze_selhat(uspech=True):
    print("Spouštím úlohu...")
    await asyncio.sleep(1)
    if not uspech:
        raise ValueError("Ups, něco se pokazilo!")
    return "Úspěšný výsledek"

async def zpracovat_ulohu_individualne():
    try:
        vysledek = await muze_selhat(uspech=False)
        print(f"Získán výsledek: {vysledek}")
    except ValueError as e:
        print(f"Zachycena chyba v úloze: {e}")

async def zpracovat_shromazdene_ulohy():
    # Při použití gather s return_exceptions=False (výchozí)
    try:
        vysledky = await asyncio.gather(
            muze_selhat(uspech=True),
            muze_selhat(uspech=False)
        )
        print(f"Všechny úlohy uspěly: {vysledky}")
    except ValueError as e:
        print(f"Alespoň jedna úloha selhala: {e}")
    
    # Při použití gather s return_exceptions=True
    vysledky = await asyncio.gather(
        muze_selhat(uspech=True),
        muze_selhat(uspech=False),
        return_exceptions=True
    )
    
    for i, vysledek in enumerate(vysledky):
        if isinstance(vysledek, Exception):
            print(f"Úloha {i} selhala s: {vysledek}")
        else:
            print(f"Úloha {i} uspěla: {vysledek}")

async def zpracovani_timeoutu():
    try:
        # Provedení s časovým limitem
        vysledek = await asyncio.wait_for(muze_selhat(uspech=True), timeout=0.5)
        print(f"Úloha dokončena včas: {vysledek}")
    except asyncio.TimeoutError:
        print("Úloha trvala příliš dlouho, vypršel časový limit")

async def main():
    print("Individuální zpracování chyb úlohy:")
    await zpracovat_ulohu_individualne()
    
    print("\nZpracování chyb shromážděných úloh:")
    await zpracovat_shromazdene_ulohy()
    
    print("\nZpracování timeoutu:")
    await zpracovani_timeoutu()

# asyncio.run(main())
```

## 8. Praktické aplikace

Implementujme praktickou aplikaci: asynchronní webový crawler, který respektuje omezení datového toku.

```python
import asyncio
import aiohttp
from urllib.parse import urljoin
import re
import time

# Semafor pro omezení datového toku - povolit 5 souběžných požadavků
DATOVY_LIMIT = 5
semafor = asyncio.Semaphore(DATOVY_LIMIT)

# Sledování navštívených URL
navstivene_url = set()
nalezene_url = set()

async def nacist_url(session, url):
    """Načíst URL s omezením datového toku"""
    async with semafor:  # Omezení souběžných požadavků
        try:
            print(f"Načítám: {url}")
            async with session.get(url, timeout=10) as response:
                if response.status == 200:
                    obsah = await response.text()
                    print(f"Načteno: {url}, délka: {len(obsah)}")
                    return obsah
                else:
                    print(f"Chyba při načítání {url}: Status {response.status}")
                    return None
        except Exception as e:
            print(f"Chyba při načítání {url}: {e}")
            return None

async def extrahovat_odkazy(zakladni_url, html_obsah):
    """Extrahovat odkazy z HTML obsahu"""
    if not html_obsah:
        return set()
    
    # Jednoduchý regex pro hledání odkazů - skutečný crawler by použil řádný HTML parser
    url_vzor = re.compile(r'href=["\'](https?://[^"\'>]+|/[^"\'>]+)["\']')
    shody = url_vzor.findall(html_obsah)
    
    # Normalizace URL
    url_adresy = set()
    for shoda in shody:
        # Zpracování relativních URL
        if shoda.startswith('/'):
            url = urljoin(zakladni_url, shoda)
        else:
            url = shoda
        url_adresy.add(url)
    
    return url_adresy

async def crawler(pocatecni_url, max_url=10, stejny_domen=True):
    """Procházet stránky začínající od počáteční URL"""
    async with aiohttp.ClientSession() as session:
        # Získat doménu z počáteční URL, pokud procházíme pouze stejnou doménu
        domena = re.search(r'https?://([^/]+)', pocatecni_url).group(1) if stejny_domen else None
        
        # Přidat počáteční URL do naší fronty
        fronta = asyncio.Queue()
        await fronta.put(pocatecni_url)
        nalezene_url.add(pocatecni_url)
        
        # Procházet URL do šířky
        while len(navstivene_url) < max_url:
            if fronta.empty():
                print("Fronta prázdná, procházení dokončeno")
                break
                
            aktualni_url = await fronta.get()
            
            # Přeskočit, pokud jsme již navštívili
            if aktualni_url in navstivene_url:
                continue
                
            # Zpracovávat pouze URL ze stejné domény, pokud je to požadováno
            if stejny_domen and domena not in aktualni_url:
                continue
                
            # Načíst a zpracovat URL
            html_obsah = await nacist_url(session, aktualni_url)
            navstivene_url.add(aktualni_url)
            
            if html_obsah:
                # Extrahovat nové URL
                nove_url = await extrahovat_odkazy(aktualni_url, html_obsah)
                
                # Přidat nové URL do fronty
                for url in nove_url:
                    if url not in nalezene_url:
                        await fronta.put(url)
                        nalezene_url.add(url)
                        
            print(f"Navštíveno: {len(navstivene_url)}/{max_url} URL, Fronta: {fronta.qsize()}, Nalezeno: {len(nalezene_url)}")

async def main():
    cas_zacatku = time.time()
    pocatecni_url = "https://python.org"
    await crawler(pocatecni_url, max_url=15)
    cas_konce = time.time()
    
    print(f"\nProcházení dokončeno. Navštíveno {len(navstivene_url)} URL za {cas_konce - cas_zacatku:.2f} sekund")
    print(f"Navštívené URL: {navstivene_url}")

# Pro spuštění tohoto příkladu:
# pip install aiohttp
# asyncio.run(main())
```

## 9. Osvědčené postupy

Zde jsou některé osvědčené postupy pro práci s asyncio:

```python
import asyncio
import time
import functools

# 1. Použijte asyncio.create_task pro operace typu "spusť a zapomeň"
async def osvedceny_postup_create_task():
    async def uloha_na_pozadi():
        print("Úloha na pozadí spuštěna")
        await asyncio.sleep(2)
        print("Úloha na pozadí dokončena")
    
    # Vytvořit a zapomenout (neočekávat výsledek)
    uloha = asyncio.create_task(uloha_na_pozadi())
    
    print("Hlavní funkce pokračuje ve vykonávání")
    await asyncio.sleep(1)
    print("Hlavní funkce stále běží, zatímco úloha na pozadí pracuje")
    
    # Volitelné: zajistit dokončení všech úloh před ukončením
    await uloha

# 2. Použijte řádnou obsluhu zrušení
async def osvedceny_postup_zruseni():
    async def prerusitelna_operace():
        try:
            print("Spouštím dlouhou operaci")
            for i in range(5):
                await asyncio.sleep(1)
                print(f"Operace krok {i+1}")
        except asyncio.CancelledError:
            print("Operace byla zrušena, čistím...")
            # Zde proveďte nezbytné čištění
            raise  # Znovu vyhodit pro správné šíření zrušení
    
    # Spustit operaci
    uloha = asyncio.create_task(prerusitelna_operace())
    
    # Nechat ji chvíli běžet
    await asyncio.sleep(2.5)
    
    # Pak ji zrušit
    uloha.cancel()
    
    try:
        await uloha
    except asyncio.CancelledError:
        print("Zrušení úlohy potvrzeno")
```

## 10. Shrnutí

Asynchronní programování s `asyncio` nabízí výkonný způsob, jak psát souběžný kód v Pythonu:

1. **Základy**:
   - Asynchronní funkce jsou definovány pomocí `async def` a vytvářejí korutiny
   - Klíčové slovo `await` pozastavuje provádění, dokud se očekávaný objekt nedokončí
   - Event loopy řídí vykonávání asynchronních úloh

2. **Základní komponenty**:
   - **Korutiny** - Asynchronní funkce, které mohou být pozastaveny a obnoveny
   - **Úlohy** - Obaly kolem korutin pro plánování a sledování
   - **Future** - Nízkoúrovňové očekávatelné objekty, které představují budoucí výsledky
   - **Event loops** - Řídí provádění úloh a zpracovává I/O operace

3. **Klíčové funkce**:
   - Souběžné provádění bez vláken nebo procesů
   - Efektivní I/O operace bez blokování
   - Strukturovaná souběžnost pro lepší řízení toku
   - Synchronizační primitivy pro koordinaci

4. **Vhodné pro**:
   - I/O vázané aplikace (webové požadavky, databázové dotazy, operace se soubory)
   - Síťové servery a klienty
   - Web scraping a interakce s API

5. **Omezení**:
   - Nevhodné pro CPU vázané úlohy bez dodatečných opatření
   - Vyžaduje knihovny kompatibilní s asyncio pro plný přínos
   - Míchání synchronního a asynchronního kódu vyžaduje pečlivé zacházení

6. **Klíčové poznatky**:
   - `asyncio.run()` je vstupním bodem pro asyncio aplikace
   - `asyncio.gather()` spouští více korutin souběžně
   - `asyncio.create_task()` naplánuje korutinu ke spuštění brzy
   - Vždy správně zpracovávejte zrušení úloh a výjimky
   - CPU vázané operace by měly běžet v poolu vláken nebo procesů

Asynchronní programování s `asyncio` může významně zlepšit výkon a odezvu I/O vázaných aplikací a poskytuje elegantní způsoby zpracování souběžnosti bez komplikací tradičního multithreadingu.
