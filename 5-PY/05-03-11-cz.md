## 1. Úvod do Python C rozšíření a FFI

Python C rozšíření a Foreign Function Interface (FFI) umožňují Python programům interagovat s kódem napsaným v C a dalších jazycích. Tato schopnost je klíčová pro:

- Zlepšení výkonu výpočetně náročných operací
- Přístup k systémovým knihovnám a ovladačům hardware
- Znovupoužití existujícího C/C++ kódu v Python aplikacích
- Implementaci kritických sekcí v kompilovaných jazycích pro zvýšení rychlosti

```python
# Jednoduchá Python funkce, která by mohla být pomalá
def calculate_sum(numbers):
    total = 0
    for num in numbers:
        total += num
    return total

# Stejná operace v C by byla mnohem rychlejší pro velká pole
# Naučíme se, jak ji vytvořit jako C rozšíření
```

## 2. Porozumění Python C API

Python C API poskytuje sadu funkcí a maker, které umožňují C kódu interagovat s Python objekty, vytvářet nové typy a integrovat se s interpreterem. API je definováno v hlavičkovém souboru `Python.h` a poskytuje přístup k vnitřním mechanismům Pythonu.

```c
// Jednoduché C rozšíření používající Python C API
#include <Python.h>

static PyObject *
example_add(PyObject *self, PyObject *args)
{
    int a, b;
    
    // Zpracování argumentů z Pythonu
    if (!PyArg_ParseTuple(args, "ii", &a, &b))
        return NULL;
    
    // Vrácení výsledku jako Python objekt
    return PyLong_FromLong(a + b);
}

// Definice metody
static PyMethodDef ExampleMethods[] = {
    {"add", example_add, METH_VARARGS, "Sečti dvě celá čísla."},
    {NULL, NULL, 0, NULL}  // Ukončovací záznam
};

// Definice modulu
static struct PyModuleDef examplemodule = {
    PyModuleDef_HEAD_INIT,
    "example",   // Název modulu
    "Ukázkový modul, který sčítá čísla", // Dokumentační řetězec modulu
    -1,          // Velikost stavu interpreteru nebo -1
    ExampleMethods
};

// Inicializační funkce modulu
PyMODINIT_FUNC
PyInit_example(void)
{
    return PyModule_Create(&examplemodule);
}
```

## 3. Vytváření základních C rozšíření

Vytváření C rozšíření zahrnuje vytváření C souborů, setupovacího skriptu a kompilaci rozšíření jako sdílené knihovny, kterou může Python importovat.

```python
# setup.py - Používá se k sestavení C rozšíření
from setuptools import setup, Extension

module = Extension('example',
                  sources=['example.c'])

setup(name='Example',
      version='1.0',
      description='Ukázkové C rozšíření',
      ext_modules=[module])
```

Pro sestavení a instalaci rozšíření:

```bash
# Pro sestavení v režimu vývoje:
python setup.py build_ext --inplace

# Pro instalaci:
pip install .
```

Použití rozšíření v Pythonu:

```python
# Použití našeho C rozšíření v Pythonu
import example

result = example.add(5, 3)
print(result)  # Výstup: 8
```

## 4. Práce s ctypes

Modul `ctypes` poskytuje datové typy kompatibilní s C a umožňuje volání funkcí v DLL nebo sdílených knihovnách bez nutnosti psát jakýkoliv C kód.

```python
# Použití ctypes pro volání funkce z C knihovny
import ctypes
from ctypes import c_int, c_double

# Načtení standardní C knihovny
libc = ctypes.cdll.LoadLibrary("libc.so.6")  # Na Linuxu
# libc = ctypes.cdll.msvcrt  # Na Windows

# Volání C funkce pow ze standardní knihovny
libc.pow.argtypes = [c_double, c_double]
libc.pow.restype = c_double

result = libc.pow(2.0, 10.0)
print(result)  # Výstup: 1024.0

# Vytvoření vlastní funkce pomocí ctypes
# Předpokládejme, že máme kompilovanou sdílenou knihovnu "mylib.so" s funkcí "multiply"
mylib = ctypes.CDLL("./mylib.so")
mylib.multiply.argtypes = [c_int, c_int]
mylib.multiply.restype = c_int

result = mylib.multiply(5, 7)
print(result)  # Výstup: 35
```

## 5. Použití CFFI (C Foreign Function Interface)

CFFI poskytuje modernější a pythoničtější způsob, jak volat C kód. Umožňuje přímo interagovat s C kódem z Pythonu pomocí známé C-podobné syntaxe.

```python
# Nainstalování CFFI: pip install cffi

import cffi

# Inicializace CFFI
ffi = cffi.FFI()

# Deklarace C funkce, kterou chceme použít
ffi.cdef("""
    int multiply(int a, int b);
""")

# Načtení sdílené knihovny
lib = ffi.dlopen("./mylib.so")  # Na Linuxu
# lib = ffi.dlopen("mylib.dll")  # Na Windows

# Volání funkce
result = lib.multiply(6, 7)
print(result)  # Výstup: 42

# Složitější příklad s CFFI - inline C kód
ffi.cdef("""
    typedef struct {
        char* name;
        int age;
    } Person;
    
    Person* create_person(const char* name, int age);
    void free_person(Person* p);
    void print_person(Person* p);
""")

# Definice implementace
lib = ffi.verify("""
    #include <stdlib.h>
    #include <stdio.h>
    #include <string.h>
    
    typedef struct {
        char* name;
        int age;
    } Person;
    
    Person* create_person(const char* name, int age) {
        Person* p = (Person*)malloc(sizeof(Person));
        p->name = strdup(name);
        p->age = age;
        return p;
    }
    
    void free_person(Person* p) {
        free(p->name);
        free(p);
    }
    
    void print_person(Person* p) {
        printf("Osoba: %s, %d let\\n", p->name, p->age);
    }
""")

# Použití našich C struktur a funkcí z Pythonu
person = lib.create_person(b"Jan Novák", 30)
lib.print_person(person)
lib.free_person(person)
```

## 6. Úvod do Cythonu

Cython je programovací jazyk, který usnadňuje psaní C rozšíření pro Python stejně snadno jako samotný Python. Je to nadmnožina Pythonu, která se kompiluje do C.

```python
# Nainstalování Cythonu: pip install cython

# example.pyx - Cython soubor
def fibonacci_cy(int n):
    cdef int a = 0
    cdef int b = 1
    cdef int i
    cdef int temp
    
    if n <= 0:
        return a
    for i in range(n - 1):
        temp = a + b
        a = b
        b = temp
    return b
```

Pro kompilaci tohoto Cython kódu vytvoříme setup soubor:

```python
# setup.py pro Cython
from setuptools import setup
from Cython.Build import cythonize

setup(
    ext_modules = cythonize("example.pyx")
)
```

Sestavení a použití Cython modulu:

```bash
python setup.py build_ext --inplace
```

```python
# Použití zkompilované Cython funkce
import example
result = example.fibonacci_cy(20)
print(result)  # Výstup: 6765

# Porovnání s čistou Python verzí
def fibonacci_py(n):
    a, b = 0, 1
    if n <= 0:
        return a
    for i in range(n - 1):
        a, b = b, a + b
    return b

import time

# Benchmark
start = time.time()
fibonacci_py(30)
py_time = time.time() - start

start = time.time()
example.fibonacci_cy(30)
cy_time = time.time() - start

print(f"Python: {py_time:.6f}s, Cython: {cy_time:.6f}s")
print(f"Cython je {py_time/cy_time:.1f}x rychlejší")
```

## 7. Porovnání výkonu

Porovnejme výkon různých přístupů pro jednoduchý úkol:

```python
import time
import array
import ctypes
import numpy as np
from cffi import FFI

# C kód pro ctypes a CFFI
C_SUM_CODE = """
int sum_array(int *arr, int size) {
    int sum = 0;
    for (int i = 0; i < size; i++) {
        sum += arr[i];
    }
    return sum;
}
"""

# Čistá Python implementace
def sum_pure_python(arr):
    return sum(arr)

# NumPy implementace
def sum_numpy(arr):
    return np.sum(arr)

# Příprava dat
size = 10000000
data = list(range(size))
data_array = array.array('i', data)
data_np = np.array(data, dtype=np.int32)

# Benchmark Python
start = time.time()
result_py = sum_pure_python(data)
python_time = time.time() - start
print(f"Čistý Python: {python_time:.4f}s - Výsledek: {result_py}")

# Benchmark NumPy
start = time.time()
result_np = sum_numpy(data_np)
numpy_time = time.time() - start
print(f"NumPy: {numpy_time:.4f}s - Výsledek: {result_np}")

# Kompilace a benchmark CFFI
ffi = FFI()
ffi.cdef("int sum_array(int *arr, int size);")
lib = ffi.verify(C_SUM_CODE)

start = time.time()
ptr = ffi.cast("int *", ffi.from_buffer(data_array))
result_cffi = lib.sum_array(ptr, size)
cffi_time = time.time() - start
print(f"CFFI: {cffi_time:.4f}s - Výsledek: {result_cffi}")

# Výpis zrychlení
print(f"NumPy je {python_time/numpy_time:.1f}x rychlejší než Python")
print(f"CFFI je {python_time/cffi_time:.1f}x rychlejší než Python")
```

## 8. Osvědčené postupy a běžné problémy

### Osvědčené postupy

1. **Používejte C rozšíření jen když je to nutné**: Nejprve optimalizujte váš Python kód, než se uchýlíte k C rozšířením.
2. **Počítání referencí**: Správně spravujte reference na Python objekty, abyste předešli únikům paměti.
3. **Zpracování chyb**: Vždy kontrolujte návratové hodnoty a správně propagujte chyby.
4. **Povědomí o GIL**: Uvolněte Global Interpreter Lock pro operace náročné na CPU, abyste umožnili vícevláknové zpracování.
5. **Kontrola typů**: Validujte vstupní typy, abyste předešli pádům.

### Běžné problémy

```python
# Běžný problém: Úniky paměti v C rozšířeních
# V C kódu:
static PyObject *
leaky_function(PyObject *self, PyObject *args)
{
    PyObject *result = PyLong_FromLong(42);
    // Zapomenutí dekrementovat reference při vyvolávání výjimek
    if (error_condition) {
        PyErr_SetString(PyExc_ValueError, "Došlo k chybě");
        return NULL;  # Únik paměti: reference na výsledek je ztracena
    }
    return result;
}

# Lepší verze:
static PyObject *
better_function(PyObject *self, PyObject *args)
{
    PyObject *result = PyLong_FromLong(42);
    if (error_condition) {
        Py_DECREF(result);  # Správně dekrementovat referenci
        PyErr_SetString(PyExc_ValueError, "Došlo k chybě");
        return NULL;
    }
    return result;
}
```

Správa paměti s CFFI:

```python
# Použití CFFI pro správu paměti
import cffi

ffi = cffi.FFI()
ffi.cdef("""
    void* malloc(size_t size);
    void free(void* ptr);
""")
C = ffi.dlopen(None)  # Načtení standardní C knihovny

# Alokace paměti
ptr = C.malloc(100)
if ptr == ffi.NULL:
    raise MemoryError("Nepodařilo se alokovat paměť")

# Zápis do paměti
buffer = ffi.buffer(ptr, 100)
buffer[0:4] = b"ABCD"

# Použití paměti...

# Vždy uvolněte paměť po dokončení
C.free(ptr)
```

## 9. Shrnutí

Python C rozšíření a FFI poskytují výkonné způsoby integrace Pythonu s C kódem:

- **Python C API** nabízí přímý přístup k vnitřním funkcím Pythonu, ale vyžaduje nejvíce základního kódu
- **ctypes** poskytuje vestavěný způsob volání funkcí ve sdílených knihovnách bez nutnosti psát C
- **CFFI** nabízí více pythoničtější rozhraní pro práci s C a je doporučen pro nové projekty
- **Cython** zjednodušuje proces tím, že umožňuje psát kód podobný Pythonu, který se kompiluje do C

Každý přístup má své silné stránky:

- Použijte **Python C API** pro hlubokou integraci s objektovým systémem Pythonu
- Použijte **ctypes** pro jednoduché volání existujících C knihoven
- Použijte **CFFI** pro složitější interakce s C knihovnami
- Použijte **Cython** pro optimalizaci Python kódu nebo vytváření rozšíření s minimální znalostí C

Zlepšení výkonu může být podstatné, zejména pro výpočetně náročné operace. S těmito výhodami však přicházejí další odpovědnosti za správu paměti, typovou bezpečnost a zpracování chyb.

Při výběru přístupu zvažte kompromisy mezi složitostí vývoje, údržbou a výkonnostními požadavky pro váš konkrétní případ použití.
