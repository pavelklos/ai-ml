## 1. Úvod do metařád

Metařídy jsou často popisovány jako "třídy tříd" v Pythonu. Definují, jak jsou samotné třídy vytvářeny, inicializovány a jak se chovají. Přestože většina vývojářů v Pythonu metařídy zřídka potřebuje, jejich pochopení poskytuje hlubší vhled do objektového systému Pythonu.

```python
# V Pythonu je vše objektem, včetně tříd
class MojeTrida:
    pass

# Třídy jsou instancemi typu 'type'
print(type(MojeTrida))  # <class 'type'>

# A 'type' je svou vlastní metařídou
print(type(type))     # <class 'type'>

# Objekty jsou instancemi svých tříd
obj = MojeTrida()
print(type(obj))      # <class '__main__.MojeTrida'>
```

Tato hierarchie ukazuje, že:
1. Běžné objekty jsou instancemi tříd
2. Třídy jsou instancemi metařád (obvykle `type`)
3. Metařída `type` je instancí sebe sama

## 2. Proces vytváření tříd v Pythonu

Když v Pythonu definujete třídu, dochází ke složitému procesu vytvoření této třídy:

```python
# Když napíšete tento kód:
class MojeTrida:
    tridni_promenna = 42
    
    def __init__(self, hodnota):
        self.hodnota = hodnota
        
    def metoda(self):
        return self.hodnota * 2

# Python vykoná tělo třídy a shromáždí:
# - Atributy (tridni_promenna)
# - Metody (__init__, metoda)
# - Název třídy ("MojeTrida")
# - Základní třídy (žádné nejsou zadány, takže výchozí je object)
# - Jmenný prostor, kde je třída definována

# Poté Python zavolá:
# type("MojeTrida", (object,), jmenný_prostor)
# Kde jmenný_prostor obsahuje tridni_promenna, __init__ a metoda
```

Pochopení tohoto procesu je klíčem k efektivní práci s metařídami.

## 3. Funkce `type` pro dynamické vytváření tříd

Funkci `type` lze použít k dynamickému vytváření tříd za běhu programu:

```python
# Dynamické vytvoření třídy pomocí type
def metoda(self):
    return self.hodnota * 2

# Signature: type(název, základní_třídy, atributy)
DynamickaTrida = type(
    "DynamickaTrida",           # Název třídy
    (object,),                # Základní třídy (jako tuple)
    {
        "tridni_promenna": 42,      # Atributy třídy
        "__init__": lambda self, hodnota: setattr(self, "hodnota", hodnota),
        "metoda": metoda      # Metody
    }
)

# Použití dynamicky vytvořené třídy
obj = DynamickaTrida(10)
print(obj.metoda())  # Výstup: 20
print(DynamickaTrida.tridni_promenna)  # Výstup: 42

# Ověření, že je stejná jako normální třída
print(type(DynamickaTrida))  # Výstup: <class 'type'>
```

Dynamické vytváření tříd je užitečné, když potřebujete generovat třídy programově na základě konfigurace, datových schémat nebo jiných faktorů za běhu programu.

## 4. Vytváření základních metařád

Metařída se vytváří odvozením od třídy `type`:

```python
# Definice jednoduché metařídy
class MojeMetatrida(type):
    def __new__(mcs, nazev, zakladni_tridy, jmenny_prostor):
        print(f"Vytvářím třídu: {nazev}")
        
        # Vypsat všechny atributy přidávané do třídy
        for klic, hodnota in jmenny_prostor.items():
            if not klic.startswith('__'):
                print(f"  Atribut: {klic} = {hodnota}")
                
        # Upravit jmenný prostor před vytvořením třídy
        jmenny_prostor['pridano_metaridou'] = 'Byl jsem přidán metařídou'
        
        # Vytvořit a vrátit třídu
        return super().__new__(mcs, nazev, zakladni_tridy, jmenny_prostor)

# Použití metařídy k vytvoření třídy
class MojeTrida(metaclass=MojeMetatrida):
    tridni_promenna = 100
    
    def metoda(self):
        return "Ahoj z metody"

# Metařída přidala atribut
print(MojeTrida.pridano_metaridou)  # Výstup: Byl jsem přidán metařídou

# Vytvoření instance třídy
instance = MojeTrida()
print(instance.pridano_metaridou)  # Atribut je dostupný i pro instance
```

Tento příklad ukazuje, jak metařída může:
1. Monitorovat vytváření třídy
2. Zkoumat atributy třídy
3. Upravit třídu před jejím dokončením

## 5. Metody a háčky metařád

Metařídy nabízejí několik háčků do procesu vytváření třídy:

```python
class PokrocileMetaridy(type):
    # Volá se pro vytvoření objektu třídy
    def __new__(mcs, nazev, zakladni_tridy, jmenny_prostor):
        print(f"__new__ zavolán pro {nazev}")
        return super().__new__(mcs, nazev, zakladni_tridy, jmenny_prostor)
    
    # Volá se pro inicializaci třídy po vytvoření
    def __init__(cls, nazev, zakladni_tridy, jmenny_prostor):
        print(f"__init__ zavolán pro {nazev}")
        super().__init__(nazev, zakladni_tridy, jmenny_prostor)
    
    # Volá se, když vytvoříte instanci třídy
    def __call__(cls, *args, **kwargs):
        print(f"__call__ zavolán pro {cls.__name__} s {args}, {kwargs}")
        instance = super().__call__(*args, **kwargs)
        print(f"Vytvořena instance: {instance}")
        return instance

class MojeTrida(metaclass=PokrocileMetaridy):
    def __init__(self, hodnota):
        self.hodnota = hodnota
    
    def __str__(self):
        return f"Instance MojeTrida s hodnotou {self.hodnota}"

# Vytvoření třídy spouští __new__ a __init__ na metařídě
print("Vytvářím instanci...")
instance = MojeTrida(42)  # Toto spouští __call__ na metařídě
```

Klíčové háčky metařád jsou:
- `__new__`: Řídí vytvoření třídy
- `__init__`: Inicializuje nově vytvořenou třídu
- `__call__`: Je vyvolán při vytváření instancí třídy

## 6. Přizpůsobení vytváření tříd

Metařídy mohou vynucovat standardy nebo aplikovat transformace na třídy:

```python
class VyzadujDocstringMeta(type):
    def __new__(mcs, nazev, zakladni_tridy, jmenny_prostor):
        # Zajištění, že třída má docstring
        if '__doc__' not in jmenny_prostor or not jmenny_prostor['__doc__']:
            raise TypeError(f"Třída {nazev} musí mít docstring")
        
        # Zajištění, že všechny metody mají docstring
        for klic, hodnota in jmenny_prostor.items():
            if callable(hodnota) and not klic.startswith('__'):
                if not hodnota.__doc__:
                    raise TypeError(f"Metoda {klic} ve třídě {nazev} musí mít docstring")
        
        return super().__new__(mcs, nazev, zakladni_tridy, jmenny_prostor)

class PlatnaTrida(metaclass=VyzadujDocstringMeta):
    """Tato třída má požadovaný docstring."""
    
    def platna_metoda(self):
        """Tato metoda má požadovaný docstring."""
        return True

try:
    # Toto vyvolá chybu, protože chybí docstring
    class NeplatnaTrida(metaclass=VyzadujDocstringMeta):
        def neplatna_metoda(self):
            return False
except TypeError as e:
    print(f"Chyba: {e}")
```

Další praktický příklad je automatická registrace podtříd:

```python
class RegistracniMeta(type):
    registr = {}
    
    def __new__(mcs, nazev, zakladni_tridy, jmenny_prostor):
        trida = super().__new__(mcs, nazev, zakladni_tridy, jmenny_prostor)
        
        # Neregistrovat abstraktní základní třídy
        if not jmenny_prostor.get('__abstract__', False):
            # Registrovat třídu podle atributu format_nazev nebo názvu třídy
            klic = jmenny_prostor.get('format_nazev', nazev.lower())
            mcs.registr[klic] = trida
            print(f"Registrováno: {klic} -> {trida}")
        
        return trida
    
    @classmethod
    def ziskat_tridu(mcs, format_nazev):
        return mcs.registr.get(format_nazev)

class Dokument(metaclass=RegistracniMeta):
    __abstract__ = True  # Neregistrovat tuto třídu

class XMLDokument(Dokument):
    format_nazev = 'xml'
    
    def parsovat(self, obsah):
        return f"Parsuji XML: {obsah[:10]}..."

class JSONDokument(Dokument):
    format_nazev = 'json'
    
    def parsovat(self, obsah):
        return f"Parsuji JSON: {obsah[:10]}..."

# Vytvoření handleru dokumentu podle formátu
def vytvorit_handler_dokumentu(format_nazev):
    trida_dokumentu = RegistracniMeta.ziskat_tridu(format_nazev)
    if trida_dokumentu:
        return trida_dokumentu()
    raise ValueError(f"Nepodporovaný formát: {format_nazev}")

# Použití
xml_handler = vytvorit_handler_dokumentu('xml')
print(xml_handler.parsovat("<root><item>data</item></root>"))

json_handler = vytvorit_handler_dokumentu('json')
print(json_handler.parsovat('{"klic": "hodnota"}'))
```

## 7. Praktické aplikace

Zde jsou některé praktické aplikace metařád:

### Vzor Singleton

```python
class SingletonMeta(type):
    _instance = {}
    
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instance:
            instance = super().__call__(*args, **kwargs)
            cls._instance[cls] = instance
        return cls._instance[cls]

class Databaze(metaclass=SingletonMeta):
    def __init__(self, pripojovaci_retezec):
        self.pripojovaci_retezec = pripojovaci_retezec
        print(f"Připojuji se k databázi s {pripojovaci_retezec}")
        # V reálném kódu byste zde navázali připojení

# Obě proměnné odkazují na stejnou instanci
db1 = Databaze("postgresql://localhost/db")
db2 = Databaze("postgresql://localhost/db")  # Nevytvoří se nové připojení

print(db1 is db2)  # Výstup: True
```

### ORM (Object-Relational Mapping)

```python
class ModelMeta(type):
    def __new__(mcs, nazev, zakladni_tridy, jmenny_prostor):
        # Přeskočit zpracování pro základní třídu
        if nazev == 'Model':
            return super().__new__(mcs, nazev, zakladni_tridy, jmenny_prostor)
        
        # Vytvořit slovník polí
        pole = {}
        for klic, hodnota in jmenny_prostor.items():
            if isinstance(hodnota, Pole):
                pole[klic] = hodnota
                hodnota.nazev = klic  # Nastavit název pole
        
        # Uložit pole do třídy
        jmenny_prostor['_pole'] = pole
        
        # Generovat SQL pro vytvoření tabulky
        nazev_tabulky = jmenny_prostor.get('__nazev_tabulky__', nazev.lower())
        definice_poli = [f"{pole.nazev} {pole.sql_typ}" for pole in pole.values()]
        create_sql = f"CREATE TABLE {nazev_tabulky} (\n  " + ",\n  ".join(definice_poli) + "\n);"
        jmenny_prostor['_create_sql'] = create_sql
        
        return super().__new__(mcs, nazev, zakladni_tridy, jmenny_prostor)

class Pole:
    def __init__(self, sql_typ):
        self.nazev = None
        self.sql_typ = sql_typ

class Model(metaclass=ModelMeta):
    @classmethod
    def vytvorit_tabulku(cls):
        print(f"Provádím SQL:\n{cls._create_sql}")
        # V reálném kódu byste toto SQL vykonali proti databázi

class Uzivatel(Model):
    __nazev_tabulky__ = 'uzivatele'
    id = Pole('INTEGER PRIMARY KEY')
    jmeno = Pole('TEXT NOT NULL')
    email = Pole('TEXT UNIQUE')
    vek = Pole('INTEGER')

# Vytvoření tabulky
Uzivatel.vytvorit_tabulku()
```

## 8. Osvědčené postupy a běžné nástrahy

### Osvědčené postupy

1. **Používejte střídmě**: Metařídy jsou mocné, ale složité a mohou učinit kód obtížněji pochopitelným.
2. **Důkladně dokumentujte**: Při používání metařád poskytněte jasnou dokumentaci o tom, co dělají.
3. **Zvažte alternativy**: Dekorátory tříd nebo mixin třídy mohou poskytnout jednodušší řešení.

### Běžné nástrahy

```python
# Nástraha 1: Konflikty metařád
class Meta1(type): pass
class Meta2(type): pass

# Toto vyvolá TypeError kvůli konfliktu metařád
try:
    class Konflikt(metaclass=Meta1):
        pass
    
    class Odvozena(Konflikt, metaclass=Meta2):
        pass
except TypeError as e:
    print(f"Chyba: {e}")

# Řešení: Dědičnost metařád
class KombinovanaMetarida(Meta1, Meta2): pass

class BezKonfliktu(metaclass=KombinovanaMetarida):
    pass

# Nástraha 2: Přílišné používání metařád
# Pro jednoduché případy jsou dekorátory tříd často jasnější:

def pridej_vlastnost(cls):
    cls.dynamicka_vlastnost = "Přidáno dekorátorem"
    return cls

@pridej_vlastnost
class JednoduchaTrida:
    pass

print(JednoduchaTrida.dynamicka_vlastnost)  # Výstup: Přidáno dekorátorem
```

## 9. Shrnutí

Metařídy v Pythonu poskytují mocný mechanismus pro přizpůsobení vytváření a chování tříd. Klíčové body k zapamatování:

1. Metařídy jsou "třídy tříd", které řídí vytváření tříd.
2. Funkce `type` může vytvářet třídy dynamicky za běhu programu.
3. Vlastní metařídy se vytvářejí odvozením od třídy `type`.
4. Háčky metařád zahrnují `__new__`, `__init__` a `__call__`, z nichž každý slouží k jinému účelu v procesu vytváření třídy.
5. Praktické aplikace zahrnují vynucování standardů kódování, implementaci návrhových vzorů jako je Singleton a budování frameworků jako ORM.
6. Přestože jsou mocné, měly by být metařídy používány střídmě kvůli jejich složitosti.
7. Alternativní přístupy jako dekorátory tříd a mixiny jsou často jednodušší pro méně složité případy použití.

Metařídy jsou nejvhodnější, když potřebujete hluboce přizpůsobit, jak fungují samotné třídy, zejména při vývoji frameworků nebo při implementaci složitých návrhových vzorů. Pro každodenní programovací úkoly jsou obvykle vhodnější jednodušší přístupy.
