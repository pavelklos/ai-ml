## 1. Introduction to Asynchronous Programming

Asynchronous programming allows you to write concurrent code without using threads or multiprocessing. It's particularly effective for I/O-bound operations where your program spends significant time waiting for external resources like networks, files, or databases.

Python's `asyncio` library provides tools for writing asynchronous code using the `async`/`await` syntax, making concurrent code more readable and maintainable.

Traditional synchronous vs asynchronous approaches:

```python
# Synchronous approach - blocking
import time

def download_site(url):
    print(f"Downloading {url}")
    # Simulate network delay
    time.sleep(1)
    print(f"Finished downloading {url}")

def download_all_sites(sites):
    for site in sites:
        download_site(site)

sites = ["site1.com", "site2.com", "site3.com"]
start_time = time.time()
download_all_sites(sites)
end_time = time.time()
print(f"Downloaded {len(sites)} sites in {end_time - start_time:.2f} seconds")
# Output: Downloaded 3 sites in 3.00 seconds
```

```python
# Asynchronous approach - non-blocking
import asyncio

async def download_site_async(url):
    print(f"Starting download of {url}")
    # Simulate network delay without blocking
    await asyncio.sleep(1)
    print(f"Finished downloading {url}")

async def download_all_sites_async(sites):
    tasks = [download_site_async(site) for site in sites]
    # Run all tasks concurrently
    await asyncio.gather(*tasks)

async def main():
    sites = ["site1.com", "site2.com", "site3.com"]
    start_time = time.time()
    await download_all_sites_async(sites)
    end_time = time.time()
    print(f"Downloaded {len(sites)} sites in {end_time - start_time:.2f} seconds")
    # Output: Downloaded 3 sites in 1.01 seconds

# Run the main function
asyncio.run(main())
```

The key benefits of asynchronous programming with `asyncio`:
1. Improved performance for I/O-bound operations
2. Single-threaded concurrency (avoids complications of thread synchronization)
3. More readable code with `async`/`await` syntax
4. Better resource utilization

## 2. Understanding Coroutines and Async/Await Syntax

Coroutines are special functions that can be paused and resumed, allowing other code to run in the meantime. In Python, we define coroutines using the `async` keyword and call them with `await`.

```python
import asyncio

# A simple coroutine
async def hello_world():
    print("Hello...")
    await asyncio.sleep(1)  # Non-blocking sleep
    print("...World!")
    return "Completed"

# Another coroutine that calls the first one
async def main():
    print("Starting main function")
    result = await hello_world()  # Pause main until hello_world completes
    print(f"Result: {result}")

# Run the event loop
asyncio.run(main())
```

Key concepts:

- `async def` - Defines a coroutine function
- `await` - Pauses the current coroutine until the awaited operation completes
- Only coroutines can use the `await` keyword
- Calling a coroutine function does not execute it; it returns a coroutine object

```python
# Understanding coroutines
async def example_coroutine():
    print("This is a coroutine")
    return "Result"

# Just calling the function doesn't run it
coro = example_coroutine()
print(f"Type of coro: {type(coro)}")  # <class 'coroutine'>

# We need to await it or schedule it with asyncio
async def run_it():
    result = await coro
    print(f"Got: {result}")

asyncio.run(run_it())
```

## 3. Working with Event Loops

The event loop is the core of every asyncio application. It runs asynchronous tasks, handles network I/O events, and runs subprocesses.

```python
import asyncio

async def task_one():
    print("Task One: Started")
    await asyncio.sleep(2)
    print("Task One: Completed")
    return "Result from Task One"

async def task_two():
    print("Task Two: Started")
    await asyncio.sleep(1)
    print("Task Two: Completed")
    return "Result from Task Two"

async def main():
    # Get the running event loop
    loop = asyncio.get_running_loop()
    
    # Create and schedule tasks
    print("Creating tasks...")
    task_1 = loop.create_task(task_one())
    task_2 = loop.create_task(task_two())
    
    # Wait for both tasks to complete
    print("Waiting for tasks to complete...")
    results = await asyncio.gather(task_1, task_2)
    
    print(f"Results: {results}")

# Run the main coroutine
asyncio.run(main())
```

Different ways to run coroutines:

```python
import asyncio

async def say_hello():
    await asyncio.sleep(1)
    return "Hello"

# Method 1: asyncio.run() (Python 3.7+)
result = asyncio.run(say_hello())

# Method 2: Using event loop directly (older Python versions)
loop = asyncio.get_event_loop()
result = loop.run_until_complete(say_hello())

# Method 3: Creating a new event loop
new_loop = asyncio.new_event_loop()
asyncio.set_event_loop(new_loop)
result = new_loop.run_until_complete(say_hello())
new_loop.close()
```

## 4. Tasks and Futures

Tasks are used to schedule coroutines concurrently. A Task is a subclass of Future that wraps a coroutine and allows you to track its execution.

```python
import asyncio
import time

async def processing_task(name, duration):
    print(f"Task {name} started, will take {duration} seconds")
    await asyncio.sleep(duration)  # Simulate work
    print(f"Task {name} completed")
    return f"Result from {name}"

async def main():
    # Create tasks explicitly
    task1 = asyncio.create_task(processing_task("A", 3))
    task2 = asyncio.create_task(processing_task("B", 2))
    task3 = asyncio.create_task(processing_task("C", 1))
    
    # Wait for a specific task
    print("Waiting for task C...")
    result_c = await task3
    print(f"Got early result: {result_c}")
    
    # Wait for remaining tasks
    print("Waiting for remaining tasks...")
    results = await asyncio.gather(task1, task2)
    print(f"All results: {[result_c] + results}")

asyncio.run(main())
```

Working with futures:

```python
import asyncio
import concurrent.futures
import time

def cpu_bound_work(number):
    """A CPU-bound operation that computes fibonacci numbers"""
    print(f"Computing fibonacci({number})...")
    if number <= 1:
        return number
    result = cpu_bound_work(number - 1) + cpu_bound_work(number - 2)
    return result

async def main():
    print("Starting main function")
    
    # Create a ThreadPoolExecutor for CPU-bound work
    with concurrent.futures.ThreadPoolExecutor() as pool:
        # Schedule CPU-bound work in the thread pool
        numbers = [30, 28, 26]
        
        # Convert the threads to awaitable futures
        futures = [
            asyncio.get_running_loop().run_in_executor(pool, cpu_bound_work, num)
            for num in numbers
        ]
        
        print("Doing other async work while CPU work runs...")
        await asyncio.sleep(0.5)
        print("Still waiting for CPU results...")
        
        # Wait for all futures to complete
        results = await asyncio.gather(*futures)
        print(f"Results: {results}")

asyncio.run(main())
```

## 5. Asynchronous I/O Operations

The `asyncio` library provides asynchronous versions of common I/O operations:

```python
import asyncio
import aiohttp
import aiofiles

async def fetch_url(url, session):
    """Fetch a URL asynchronously"""
    print(f"Fetching {url}")
    async with session.get(url) as response:
        return await response.text()

async def save_content(filename, content):
    """Save content to a file asynchronously"""
    print(f"Saving content to {filename}")
    async with aiofiles.open(filename, 'w') as file:
        await file.write(content)
    print(f"Saved {filename}")

async def download_and_save(url, filename):
    """Download a URL and save it to a file"""
    async with aiohttp.ClientSession() as session:
        content = await fetch_url(url, session)
        await save_content(filename, content)
        return len(content)

async def main():
    urls = [
        ('https://python.org', 'python.html'),
        ('https://github.com', 'github.html'),
        ('https://stackoverflow.com', 'stackoverflow.html')
    ]
    
    # Process all downloads concurrently
    tasks = [download_and_save(url, filename) for url, filename in urls]
    sizes = await asyncio.gather(*tasks)
    
    for (url, filename), size in zip(urls, sizes):
        print(f"Downloaded {url} to {filename} ({size} bytes)")

# To run this example, you need:
# pip install aiohttp aiofiles
# asyncio.run(main())
```

## 6. Synchronization Primitives

Asyncio provides synchronization primitives similar to those in the `threading` module:

```python
import asyncio
import random

# Using a Lock
async def worker(lock, worker_id):
    print(f"Worker {worker_id} waiting to acquire lock")
    async with lock:
        print(f"Worker {worker_id} acquired lock")
        # Simulate work
        await asyncio.sleep(random.uniform(0.5, 1.5))
    print(f"Worker {worker_id} released lock")

async def lock_example():
    lock = asyncio.Lock()
    workers = [worker(lock, i) for i in range(3)]
    await asyncio.gather(*workers)

# Using a Semaphore to limit concurrency
async def worker_with_limit(semaphore, worker_id):
    print(f"Worker {worker_id} waiting for semaphore")
    async with semaphore:
        print(f"Worker {worker_id} acquired semaphore")
        # Simulate work
        await asyncio.sleep(random.uniform(1, 2))
    print(f"Worker {worker_id} released semaphore")

async def semaphore_example():
    # Allow only 2 concurrent operations
    semaphore = asyncio.Semaphore(2)
    workers = [worker_with_limit(semaphore, i) for i in range(5)]
    await asyncio.gather(*workers)

# Using an Event for signaling
async def waiter(event, waiter_id):
    print(f"Waiter {waiter_id} waiting for event")
    await event.wait()
    print(f"Waiter {waiter_id} received event, proceeding")

async def setter(event):
    print("Setter: doing some work before setting event")
    await asyncio.sleep(2)
    print("Setter: setting event")
    event.set()

async def event_example():
    event = asyncio.Event()
    waiters = [waiter(event, i) for i in range(3)]
    await asyncio.gather(*waiters, setter(event))

async def main():
    print("Lock example:")
    await lock_example()
    print("\nSemaphore example:")
    await semaphore_example()
    print("\nEvent example:")
    await event_example()

# asyncio.run(main())
```

## 7. Error Handling in Asynchronous Code

Error handling in asynchronous code requires special attention:

```python
import asyncio

async def might_fail(success=True):
    print("Starting task...")
    await asyncio.sleep(1)
    if not success:
        raise ValueError("Oops, something went wrong!")
    return "Success result"

async def handle_task_individually():
    try:
        result = await might_fail(success=False)
        print(f"Got result: {result}")
    except ValueError as e:
        print(f"Caught error in task: {e}")

async def handle_gathered_tasks():
    # When using gather with return_exceptions=False (default)
    try:
        results = await asyncio.gather(
            might_fail(success=True),
            might_fail(success=False)
        )
        print(f"All tasks succeeded: {results}")
    except ValueError as e:
        print(f"At least one task failed: {e}")
    
    # When using gather with return_exceptions=True
    results = await asyncio.gather(
        might_fail(success=True),
        might_fail(success=False),
        return_exceptions=True
    )
    
    for i, result in enumerate(results):
        if isinstance(result, Exception):
            print(f"Task {i} failed with: {result}")
        else:
            print(f"Task {i} succeeded: {result}")

async def timeout_handling():
    try:
        # Execute with timeout
        result = await asyncio.wait_for(might_fail(success=True), timeout=0.5)
        print(f"Task completed in time: {result}")
    except asyncio.TimeoutError:
        print("Task took too long, timed out")

async def main():
    print("Individual task error handling:")
    await handle_task_individually()
    
    print("\nGathered tasks error handling:")
    await handle_gathered_tasks()
    
    print("\nTimeout handling:")
    await timeout_handling()

# asyncio.run(main())
```

## 8. Practical Applications

Let's implement a practical application: an asynchronous web crawler that respects a rate limit.

```python
import asyncio
import aiohttp
from urllib.parse import urljoin
import re
import time

# Rate limiting semaphore - allow 5 concurrent requests
RATE_LIMIT = 5
semaphore = asyncio.Semaphore(RATE_LIMIT)

# Keep track of visited URLs
visited_urls = set()
found_urls = set()

async def fetch_url(session, url):
    """Fetch a URL with rate limiting"""
    async with semaphore:  # Limit concurrent requests
        try:
            print(f"Fetching: {url}")
            async with session.get(url, timeout=10) as response:
                if response.status == 200:
                    content = await response.text()
                    print(f"Fetched: {url}, length: {len(content)}")
                    return content
                else:
                    print(f"Error fetching {url}: Status {response.status}")
                    return None
        except Exception as e:
            print(f"Error fetching {url}: {e}")
            return None

async def extract_links(base_url, html_content):
    """Extract links from HTML content"""
    if not html_content:
        return set()
    
    # Simple regex for finding links - a real crawler would use a proper HTML parser
    url_pattern = re.compile(r'href=["\'](https?://[^"\'>]+|/[^"\'>]+)["\']')
    matches = url_pattern.findall(html_content)
    
    # Normalize URLs
    urls = set()
    for match in matches:
        # Handle relative URLs
        if match.startswith('/'):
            url = urljoin(base_url, match)
        else:
            url = match
        urls.add(url)
    
    return urls

async def crawler(start_url, max_urls=10, same_domain=True):
    """Crawl pages starting from start_url"""
    async with aiohttp.ClientSession() as session:
        # Get the domain of the starting URL if we're only crawling the same domain
        domain = re.search(r'https?://([^/]+)', start_url).group(1) if same_domain else None
        
        # Add the starting URL to our queue
        queue = asyncio.Queue()
        await queue.put(start_url)
        found_urls.add(start_url)
        
        # Crawl URLs breadth-first
        while len(visited_urls) < max_urls:
            if queue.empty():
                print("Queue empty, crawling complete")
                break
                
            current_url = await queue.get()
            
            # Skip if we've already visited
            if current_url in visited_urls:
                continue
                
            # Only process URLs from the same domain if required
            if same_domain and domain not in current_url:
                continue
                
            # Fetch and process the URL
            html_content = await fetch_url(session, current_url)
            visited_urls.add(current_url)
            
            if html_content:
                # Extract new URLs
                new_urls = await extract_links(current_url, html_content)
                
                # Add new URLs to the queue
                for url in new_urls:
                    if url not in found_urls:
                        await queue.put(url)
                        found_urls.add(url)
                        
            print(f"Visited: {len(visited_urls)}/{max_urls} URLs, Queue: {queue.qsize()}, Found: {len(found_urls)}")

async def main():
    start_time = time.time()
    start_url = "https://python.org"
    await crawler(start_url, max_urls=15)
    end_time = time.time()
    
    print(f"\nCrawling complete. Visited {len(visited_urls)} URLs in {end_time - start_time:.2f} seconds")
    print(f"Visited URLs: {visited_urls}")

# To run this example:
# pip install aiohttp
# asyncio.run(main())
```

## 9. Best Practices

Here are some best practices for working with asyncio:

```python
import asyncio
import time
import functools

# 1. Use asyncio.create_task for fire-and-forget operations
async def best_practice_create_task():
    async def background_task():
        print("Background task started")
        await asyncio.sleep(2)
        print("Background task completed")
    
    # Create and forget (not awaiting the result)
    task = asyncio.create_task(background_task())
    
    print("Main function continues executing")
    await asyncio.sleep(1)
    print("Main function still running while background task works")
    
    # Optional: ensure all tasks complete before exiting
    await task

# 2. Use proper cancellation handling
async def best_practice_cancellation():
    async def cancellable_operation():
        try:
            print("Starting long operation")
            for i in range(5):
                await asyncio.sleep(1)
                print(f"Operation step {i+1}")
        except asyncio.CancelledError:
            print("Operation was cancelled, cleaning up...")
            # Do any necessary cleanup here
            raise  # Re-raise to properly propagate cancellation
    
    # Start the operation
    task = asyncio.create_task(cancellable_operation())
    
    # Let it run for a bit
    await asyncio.sleep(2.5)
    
    # Then cancel it
    task.cancel()
    
    try:
        await task
    except asyncio.CancelledError:
        print("Task cancellation confirmed")

# 3. Use asyncio.shield to protect critical operations from cancellation
async def best_practice_shield():
    async def critical_operation():
        print("Starting critical operation")
        await asyncio.sleep(1)
        print("Critical operation complete")
        return "Important result"
    
    task = asyncio.create_task(asyncio.shield(critical_operation()))
    
    # Try to cancel the task
    task.cancel()
    
    try:
        result = await task
        print(f"Got result despite cancellation: {result}")
    except asyncio.CancelledError:
        print("Task was cancelled anyway")

# 4. Use wrapper functions to run CPU-bound operations in a thread pool
def cpu_intensive(seconds):
    """A CPU-intensive function that blocks the event loop"""
    print(f"CPU-intensive operation started")
    start = time.time()
    # Simulate CPU-bound operation
    while time.time() - start < seconds:
        pass
    print(f"CPU-intensive operation completed")
    return "CPU result"

async def best_practice_run_in_executor():
    loop = asyncio.get_running_loop()
    
    # Wrong way - blocks the event loop
    # result = cpu_intensive(2)
    
    # Right way - run in thread pool
    result = await loop.run_in_executor(None, cpu_intensive, 2)
    print(f"Got result: {result}")

# 5. Create utility functions for common patterns
async def best_practice_utilities():
    # Utility to retry an async operation
    async def retry_async(func, attempts=3, delay=1):
        for attempt in range(1, attempts + 1):
            try:
                return await func()
            except Exception as e:
                if attempt == attempts:
                    raise
                print(f"Attempt {attempt} failed: {e}. Retrying in {delay}s...")
                await asyncio.sleep(delay)
    
    # Example function that might fail
    async def unreliable_operation():
        if time.time() % 3 < 2:  # Fail ~66% of the time
            raise ConnectionError("Simulated connection failure")
        return "Success!"
    
    try:
        result = await retry_async(unreliable_operation)
        print(f"Operation eventually succeeded: {result}")
    except Exception as e:
        print(f"All retry attempts failed: {e}")

async def main():
    print("Best practice: Using create_task")
    await best_practice_create_task()
    
    print("\nBest practice: Proper cancellation handling")
    await best_practice_cancellation()
    
    print("\nBest practice: Using shield for critical operations")
    await best_practice_shield()
    
    print("\nBest practice: Running CPU-bound operations in executor")
    await best_practice_run_in_executor()
    
    print("\nBest practice: Creating utilities for common patterns")
    await best_practice_utilities()

# asyncio.run(main())
```

## 10. Summary

Asynchronous programming with `asyncio` offers a powerful way to write concurrent code in Python:

1. **Fundamentals**:
   - Async functions are defined with `async def` and create coroutines
   - The `await` keyword pauses execution until an awaitable completes
   - Event loops manage the execution of asynchronous tasks

2. **Core Components**:
   - **Coroutines** - Asynchronous functions that can be paused and resumed
   - **Tasks** - Wrappers around coroutines for scheduling and tracking
   - **Futures** - Low-level awaitable objects that represent eventual results
   - **Event Loops** - Manages execution of tasks and handles I/O operations

3. **Key Features**:
   - Concurrent execution without threads or processes
   - Efficient I/O operations without blocking
   - Structured concurrency for better control flow
   - Synchronization primitives for coordination

4. **Best Suited For**:
   - I/O-bound applications (web requests, database queries, file operations)
   - Network servers and clients
   - Web scraping and API interactions

5. **Limitations**:
   - Not suitable for CPU-bound tasks without additional measures
   - Requires asyncio-compatible libraries for full benefit
   - Mixing synchronous and asynchronous code requires careful handling

6. **Key Takeaways**:
   - `asyncio.run()` is the entry point for asyncio applications
   - `asyncio.gather()` runs multiple coroutines concurrently
   - `asyncio.create_task()` schedules a coroutine to run soon
   - Always handle task cancellation and exceptions properly
   - CPU-bound operations should run in thread or process pools

Asynchronous programming with `asyncio` can significantly improve the performance and responsiveness of I/O-bound applications, providing elegant ways to handle concurrency without the complications of traditional multithreading.
