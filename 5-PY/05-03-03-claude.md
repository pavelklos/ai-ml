# Asynchronous Programming with asyncio in Python

## 1. Import Required Libraries

The `asyncio` module is included in the Python standard library since Python 3.4, with significant improvements in 3.5, 3.6, and 3.7. Here's how to import it:

```python
import asyncio
import time  # Used for comparison with synchronous code
import aiohttp  # Popular async HTTP client (install with: pip install aiohttp)
import aiofiles  # For async file operations (install with: pip install aiofiles)
from concurrent.futures import ThreadPoolExecutor  # For running blocking code
```

## 2. Understanding Asynchronous Programming

### What is Asynchronous Programming?

Asynchronous programming allows tasks to run concurrently without blocking the main thread. This is particularly useful for I/O-bound operations such as network requests, file operations, and database queries.

### Synchronous vs. Asynchronous Code

Let's compare synchronous and asynchronous approaches:

```python
# Synchronous example
def sync_example():
    start = time.time()
    
    # Sequential execution
    for i in range(5):
        print(f"Task {i} starting")
        time.sleep(1)  # Simulates I/O operation
        print(f"Task {i} completed")
    
    elapsed = time.time() - start
    print(f"Synchronous execution took: {elapsed:.2f} seconds")

# Asynchronous equivalent
async def async_example():
    start = time.time()
    
    # Create tasks to run concurrently
    tasks = []
    for i in range(5):
        tasks.append(asyncio.create_task(async_task(i)))
    
    # Wait for all tasks to complete
    await asyncio.gather(*tasks)
    
    elapsed = time.time() - start
    print(f"Asynchronous execution took: {elapsed:.2f} seconds")

async def async_task(i):
    print(f"Task {i} starting")
    await asyncio.sleep(1)  # Non-blocking sleep
    print(f"Task {i} completed")

# Run synchronous version
sync_example()  # Takes ~5 seconds

# Run asynchronous version
asyncio.run(async_example())  # Takes ~1 second
```

### Benefits of Asynchronous Programming

- **Improved Performance**: Handle many operations concurrently
- **Better Resource Utilization**: Don't block while waiting for I/O
- **Scalability**: Handle more concurrent connections with fewer resources
- **Responsiveness**: Keep the application responsive while processing

## 3. Coroutines and Async/Await Syntax

### Coroutines

Coroutines are special functions that can pause execution and yield control to other coroutines. They are defined using the `async def` syntax.

```python
# This is a coroutine
async def my_coroutine():
    print("Coroutine started")
    await asyncio.sleep(1)  # This is a suspension point
    print("Coroutine resumed after 1 second")
    return "Completed"

# This will NOT execute the coroutine
result = my_coroutine()  # Returns a coroutine object, doesn't run the code

# To actually run a coroutine, you need an event loop
# This is the proper way to run a top-level coroutine:
result = asyncio.run(my_coroutine())
```

### Async/Await Syntax

- `async def` defines a coroutine function
- `await` pauses the execution of the coroutine until the awaited task completes
- You can only use `await` inside an `async def` function

```python
async def outer_coroutine():
    print("Outer coroutine started")
    
    # Await inner coroutine
    result = await inner_coroutine()
    print(f"Inner coroutine returned: {result}")
    
    return "Outer completed"

async def inner_coroutine():
    print("Inner coroutine executing")
    await asyncio.sleep(0.5)
    return "Inner completed"

# Run the outer coroutine
asyncio.run(outer_coroutine())
```

## 4. Event Loops

The event loop is the core of every asyncio application. It manages all the asynchronous tasks and handles callbacks.

```python
# Getting and working with the event loop

async def main():
    # Get the running event loop
    loop = asyncio.get_running_loop()
    
    # Schedule a callback
    loop.call_soon(lambda: print("This runs soon"))
    
    # Schedule a callback with a delay (in seconds)
    loop.call_later(1.0, lambda: print("This runs after 1 second"))
    
    # Create a Future on the loop
    future = loop.create_future()
    
    # Schedule a task to set the future's result
    loop.call_later(2.0, lambda: future.set_result("Future is done!"))
    
    # Wait for the future to complete
    result = await future
    print(result)

# Run the main coroutine with the event loop
asyncio.run(main())
```

### Custom Event Loop Policy

You can customize the event loop policy if needed:

```python
import sys

if sys.platform == 'win32':
    # Windows-specific policy for better performance
    asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())

# Or with uvloop for better performance on Unix systems
# First: pip install uvloop
if sys.platform != 'win32':
    import uvloop
    asyncio.set_event_loop_policy(uvloop.EventLoopPolicy())
```

## 5. Creating and Running Tasks

Tasks are used to schedule coroutines to run on the event loop.

```python
async def main():
    # Create a task from a coroutine
    task1 = asyncio.create_task(
        worker("Task 1", 2)
    )
    
    task2 = asyncio.create_task(
        worker("Task 2", 1)
    )
    
    # Wait for both tasks to complete
    print("Waiting for tasks to complete...")
    await task1
    await task2
    
    print("All tasks completed")

async def worker(name, seconds):
    print(f"{name} is starting")
    await asyncio.sleep(seconds)
    print(f"{name} is done after {seconds} seconds")
    return f"{name} result"

# Alternative: using gather
async def main_with_gather():
    # Run multiple coroutines concurrently
    results = await asyncio.gather(
        worker("Task 1", 2),
        worker("Task 2", 1),
        worker("Task 3", 3)
    )
    
    print(f"All tasks completed with results: {results}")

# Run with asyncio.run
asyncio.run(main())
asyncio.run(main_with_gather())
```

## 6. Working with Futures

Futures represent the eventual result of an asynchronous operation.

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor

async def main():
    # Create a future
    future = asyncio.get_running_loop().create_future()
    
    # Schedule a callback to set the future's result
    asyncio.get_running_loop().call_later(
        1.0, 
        lambda: future.set_result("Future is complete")
    )
    
    # Wait for the future to complete
    result = await future
    print(f"Future result: {result}")
    
    # Using ThreadPoolExecutor with futures
    with ThreadPoolExecutor() as pool:
        # Schedule a function to run in a thread pool
        loop = asyncio.get_running_loop()
        
        # Run a CPU-bound function in a thread
        future = loop.run_in_executor(
            pool, 
            cpu_bound_task,  # Function to run
            10  # Arguments to the function
        )
        
        print("Waiting for CPU-bound task to complete...")
        result = await future
        print(f"CPU-bound task result: {result}")

def cpu_bound_task(number):
    """A CPU-bound task that will run in a thread."""
    result = 0
    for i in range(number * 1000000):
        result += i
    return result

asyncio.run(main())
```

## 7. Handling Timeouts and Cancellations

### Timeouts

```python
async def main():
    try:
        # Run with a timeout
        result = await asyncio.wait_for(
            slow_operation(), 
            timeout=1.0  # 1 second timeout
        )
        print(f"Operation completed with result: {result}")
    except asyncio.TimeoutError:
        print("Operation timed out!")

async def slow_operation():
    print("Slow operation started")
    await asyncio.sleep(2)  # This takes too long
    return "Slow operation result"

# Using shield to prevent cancellation of the underlying coroutine
async def main_with_shield():
    task = asyncio.create_task(slow_operation())
    
    try:
        # Shield prevents the slow_operation from being cancelled
        # when the timeout occurs
        await asyncio.wait_for(
            asyncio.shield(task), 
            timeout=1.0
        )
    except asyncio.TimeoutError:
        print("The wait timed out, but the operation continues running")
        # We can still await the original task
        result = await task
        print(f"Operation eventually completed with: {result}")

asyncio.run(main())
asyncio.run(main_with_shield())
```

## 8. Asynchronous Context Managers

Asynchronous context managers use `async with` and are perfect for resource management.

```python
import aiohttp
import aiofiles

# Define an async context manager
class AsyncResource:
    async def __aenter__(self):
        print("Acquiring the resource asynchronously")
        await asyncio.sleep(0.1)  # Simulate async acquisition
        return self
    
    async def __aexit__(self, exc_type, exc_val, exc_tb):
        print("Releasing the resource asynchronously")
        await asyncio.sleep(0.1)  # Simulate async release
        # Return False to propagate exceptions, True to suppress
        return False
    
    async def use_resource(self):
        print("Using the resource")
        await asyncio.sleep(0.2)

async def main():
    # Using a custom async context manager
    async with AsyncResource() as resource:
        await resource.use_resource()
    
    # Using aiohttp's ClientSession (a built-in async context manager)
    async with aiohttp.ClientSession() as session:
        async with session.get('https://python.org') as response:
            html = await response.text()
            print(f"Got response with {len(html)} bytes")
    
    # Using aiofiles for async file operations
    async with aiofiles.open('example.txt', 'w') as file:
        await file.write("Hello, async world!")
    
    async with aiofiles.open('example.txt', 'r') as file:
        content = await file.read()
        print(f"File content: {content}")

asyncio.run(main())
```

## 9. Asynchronous Generators

Asynchronous generators combine generator and coroutine features.

```python
# Define an async generator
async def async_range(start, stop):
    for i in range(start, stop):
        await asyncio.sleep(0.1)  # Simulate async work

async def main():

    print("Starting async iteration")
    async for number in async_range(1, 5):

asyncio.run(main())
```

## 10. Synchronization Primitives

Asyncio provides several synchronization primitives.

```python
async def main():
    # Lock: ensures exclusive access to a shared resource
    lock = asyncio.Lock()
    
    async def worker(name, lock):
        print(f"{name} is waiting for the lock")
        async with lock:
            print(f"{name} acquired the lock")
            await asyncio.sleep(0.5)  # Simulate work with the resource
            print(f"{name} releasing the lock")
    
    # Start workers that will compete for the lock
    await asyncio.gather(
        worker("Worker 1", lock),
        worker("Worker 2", lock),
        worker("Worker 3", lock)
    )
    
    # Event: signals that something has happened
    event = asyncio.Event()
    
    async def waiter(name):
        print(f"{name} is waiting for the event")
        await event.wait()
        print(f"{name} received the event, continuing")
    
    async def setter():
        print("Setter: working before setting the event")
        await asyncio.sleep(1)
        print("Setter: setting the event")
        event.set()
    
    # Run waiters and setter
    await asyncio.gather(
        waiter("Waiter 1"),
        waiter("Waiter 2"),
        setter()
    )
    
    # Semaphore: limits concurrent access to a resource
    semaphore = asyncio.Semaphore(2)  # Allow 2 concurrent access
    
    async def limited_worker(name):
        print(f"{name} is waiting for the semaphore")
        async with semaphore:
            print(f"{name} acquired the semaphore")
            await asyncio.sleep(1)
            print(f"{name} releasing the semaphore")
    
    # Start workers that will be limited by the semaphore
    await asyncio.gather(
        limited_worker("Worker 1"),
        limited_worker("Worker 2"),
        limited_worker("Worker 3"),
        limited_worker("Worker 4")
    )
    
    # Condition: a combination of a lock and an event
    condition = asyncio.Condition()
    
    # Shared state
    queue = []
    
    async def producer():
        async with condition:
            print("Producer: adding items to queue")
            queue.extend([1, 2, 3])
            print("Producer: notifying consumers")
            condition.notify_all()
    
    async def consumer(name):
        async with condition:
            print(f"{name}: waiting for items")
            await condition.wait()
            print(f"{name}: consumed items {queue}")
    
    # Run producers and consumers
    await asyncio.gather(
        consumer("Consumer 1"),
        consumer("Consumer 2"),
        asyncio.sleep(0.1),  # Ensure consumers are waiting
        producer()
    )

asyncio.run(main())
```

## 11. Handling Blocking Operations

Handling CPU-bound or blocking I/O operations with `run_in_executor`.

```python
import time
import requests
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor

async def main():
    loop = asyncio.get_running_loop()
    
    # Thread pool for I/O-bound blocking operations
    with ThreadPoolExecutor() as thread_pool:
        # Run a blocking I/O operation in a thread
        print("Running blocking HTTP request in thread")
        response = await loop.run_in_executor(
            thread_pool,
            make_http_request,  # Blocking function
            "https://python.org"
        )
        print(f"HTTP response size: {len(response)} bytes")
        
        # Run a blocking file I/O operation in a thread
        content = await loop.run_in_executor(
            thread_pool,
            read_large_file,  # Blocking function
            "example.txt"
        )
        print(f"File content: {content[:50]}...")
    
    # Process pool for CPU-bound operations
    with ProcessPoolExecutor() as process_pool:
        # Run a CPU-intensive operation in a separate process
        print("Running CPU-intensive calculation in process")
        result = await loop.run_in_executor(
            process_pool,
            cpu_intensive_calculation,  # CPU-bound function
            10000000
        )
        print(f"Calculation result: {result}")

def make_http_request(url):
    """A blocking function that makes an HTTP request."""
    print(f"Making HTTP request to {url}")
    response = requests.get(url)
    return response.text

def read_large_file(filename):
    """A blocking function that reads a file."""
    print(f"Reading file {filename}")
    try:
        with open(filename, 'r') as f:
            return f.read()
    except FileNotFoundError:
        return "File not found"

def cpu_intensive_calculation(n):
    """A CPU-intensive calculation."""
    print(f"Starting calculation with n={n}")
    result = sum(i * i for i in range(n))
    return result

asyncio.run(main())
```

### Concurrent File Processing Example

```python
import aiofiles
import os
import asyncio
from hashlib import md5

async def hash_file(filename):
    async with aiofiles.open(filename, 'rb') as f:
        contents = await f.read()
        file_hash = md5(contents).hexdigest()
        return filename, file_hash

async def process_directory(directory):
    tasks = []
    
    # Walk through directory and create tasks
    for root, _, files in os.walk(directory):
        for filename in files:
            filepath = os.path.join(root, filename)
            tasks.append(hash_file(filepath))
            
    # Process files concurrently
    results = await asyncio.gather(*tasks, return_exceptions=True)
    
    # Filter out exceptions and process results
    file_hashes = {}
    for result in results:
        if isinstance(result, Exception):
            print(f"Error processing a file: {result}")
        else:
            filename, file_hash = result
            file_hashes[filename] = file_hash
    
    return file_hashes

async def find_duplicates(file_hashes):
    # Group files by hash
    hash_to_files = {}
    for filename, file_hash in file_hashes.items():
        if file_hash not in hash_to_files:
            hash_to_files[file_hash] = []
        hash_to_files[file_hash].append(filename)
    
    # Find duplicates (files with the same hash)
    duplicates = {h: files for h, files in hash_to_files.items() if len(files) > 1}
    return duplicates

async def main():
    directory = "."  # Current directory
    
    print(f"Processing files in {directory}...")
    file_hashes = await process_directory(directory)
    
    print(f"Processed {len(file_hashes)} files")
    
    duplicates = await find_duplicates(file_hashes)
    if duplicates:
        print("\nFound duplicate files:")
        for file_hash, files in duplicates.items():
            print(f"\nHash: {file_hash}")
            for filename in files:
                print(f"  {filename}")
    else:
        print("\nNo duplicate files found")
```

## 13. Best Practices and Common Pitfalls

### Best Practices

#### 1. Use `asyncio.run()` for the Main Entry Point

```python
# Good practice
async def main():
    # Your async code here
    pass

# Entry point
if __name__ == "__main__":
    asyncio.run(main())
```

#### 2. Avoid Blocking Calls in Coroutines

```python
# Bad practice
async def bad_coroutine():
    # This blocks the event loop!
    time.sleep(1)
    
# Good practice
async def good_coroutine():
    # This allows other coroutines to run
    await asyncio.sleep(1)
    
# Good practice for unavoidable blocking calls
async def better_coroutine():
    loop = asyncio.get_running_loop()
    with ThreadPoolExecutor() as pool:
        # Run blocking code in a thread
        await loop.run_in_executor(pool, time.sleep, 1)
```

#### 3. Handle Exceptions Properly

```python
async def main():
    try:
        await risky_coroutine()
    except Exception as e:
        print(f"Caught an exception: {e}")
    
    # With multiple tasks
    tasks = [
        asyncio.create_task(risky_coroutine()),
        asyncio.create_task(another_coroutine())
    ]
    
    # Wait for all tasks, collecting exceptions
    results = await asyncio.gather(*tasks, return_exceptions=True)
    
    for i, result in enumerate(results):
        if isinstance(result, Exception):
            print(f"Task {i} raised exception: {result}")
        else:
            print(f"Task {i} succeeded with: {result}")
```

#### 4. Use Timeout for Operations That Might Hang

```python
async def main():
    try:
        # Set a reasonable timeout
        result = await asyncio.wait_for(
            potentially_slow_operation(), 
            timeout=5.0
        )
    except asyncio.TimeoutError:
        print("Operation timed out")
```

#### 5. Properly Close Resources

```python
async def main():
    # Always use context managers for resources
    async with aiohttp.ClientSession() as session:
        # Use the session
        pass
    # Session is automatically closed when the block exits
    
    # If you can't use a context manager:
    try:
        resource = await open_resource()
        # Use resource
    finally:
        await resource.close()
```

### Common Pitfalls

#### 1. Forgetting to Await Coroutines

```python
async def main():
    # Bad: This doesn't actually run the coroutine!
    process_data()  # This just creates a coroutine object
    
    # Good: Use await to execute the coroutine
    await process_data()
    
    # Also good: Create a task to run it concurrently
    task = asyncio.create_task(process_data())
    # ... do other things ...
    await task  # Eventually wait for it
```

#### 2. Mixing Blocking and Non-blocking Code

```python
async def main():
    # Bad: This blocks the event loop for all coroutines
    with open('large_file.txt', 'r') as f:
        data = f.read()  # Blocking I/O
    
    # Good: Use async libraries
    async with aiofiles.open('large_file.txt', 'r') as f:
        data = await f.read()
    
    # Good: Run blocking code in a thread
    loop = asyncio.get_running_loop()
    with ThreadPoolExecutor() as pool:
        data = await loop.run_in_executor(
            pool,
            lambda: open('large_file.txt', 'r').read()
        )
```

#### 3. Creating Tasks Without Tracking Them

```python
async def main():
    # Bad: Task is created but never awaited
    asyncio.create_task(background_job())
    # If an exception occurs in background_job, it's never handled!
    
    # Good: Keep track of tasks
    background_tasks = set()
    
    task = asyncio.create_task(background_job())
    background_tasks.add(task)
    
    # Remove the task when it's done
    task.add_done_callback(background_tasks.discard)
    
    # Later, you can wait for all background tasks
    await asyncio.gather(*background_tasks)
```

#### 4. Ignoring Task Cancellation

```python
async def cancellable_task():
    try:
        while True:
            await asyncio.sleep(1)
            print("Working...")
    except asyncio.CancelledError:
        # Handle cancellation gracefully
        print("Task was cancelled, cleaning up...")
        # Clean up resources
        raise  # Re-raise to signal task was cancelled
```

#### 5. Synchronization Issues with Shared State

```python
# Bad: Two coroutines modifying shared state without synchronization
shared_counter = 0

async def increment_bad():
    global shared_counter
    # This operation is not atomic in a multi-coroutine context
    temp = shared_counter
    await asyncio.sleep(0.1)  # Context switch possible here
    shared_counter = temp + 1

# Good: Use a lock to protect shared state
shared_counter = 0
counter_lock = asyncio.Lock()

async def increment_good():
    global shared_counter
    async with counter_lock:
        # This whole block is now atomic
        temp = shared_counter
        await asyncio.sleep(0.1)  # Other coroutines wait for the lock
        shared_counter = temp + 1
```

```python
# Condition: Advanced example with multiple producers and consumers
async def condition_demo():
    condition = asyncio.Condition()
    queue = []
    max_queue_size = 5
    
    async def producer(name, items_to_produce):
        for i in range(items_to_produce):
            item = f"{name}-{i}"
            
            async with condition:
                # Wait until there's space in the queue
                while len(queue) >= max_queue_size:
                    print(f"{name} waiting for space in queue")
                    await condition.wait()
                
                # Add item to queue
                queue.append(item)
                print(f"{name} added {item} to queue (size: {len(queue)})")
                
                # Notify consumers that a new item is available
                condition.notify()
            
            # Simulate production time
            await asyncio.sleep(random.random())
    
    async def consumer(name, items_to_consume):
        items_consumed = 0
        
        while items_consumed < items_to_consume:
            async with condition:
                # Wait until there's an item in the queue
                while not queue:
                    print(f"{name} waiting for items")
                    await condition.wait()
                
                # Get item from queue
                item = queue.pop(0)
                items_consumed += 1
                print(f"{name} got {item} from queue (size: {len(queue)})")
                
                # Notify producers that there's space in the queue
                condition.notify()
            
            # Simulate consumption time
            await asyncio.sleep(random.random() * 2)
    
    # Create producers and consumers
    producers = [
        producer("Producer-1", 8),
        producer("Producer-2", 6)
    ]
    
    consumers = [
        consumer("Consumer-1", 7),
        consumer("Consumer-2", 7)
    ]
    
    # Run all producers and consumers
    await asyncio.gather(*producers, *consumers)
```

```python

import asyncio
import aiosqlite
import json
import logging

# Configure logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

# Database initialization
async def init_db():
    # Connect to SQLite database (will create if not exists)
    db = await aiosqlite.connect("users.db")
    
    # Create tables if they don't exist
    await db.execute("""
    CREATE TABLE IF NOT EXISTS users (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        email TEXT UNIQUE NOT NULL,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    )
    """)
    
    await db.commit()
    return db

# Database operations
async def get_all_users(db):
    async with db.execute("SELECT id, name, email, created_at FROM users") as cursor:
        rows = await cursor.fetchall()
        # Convert to list of dictionaries
        users = [
            {"id": row[0], "name": row[1], "email": row[2], "created_at": row[3]}
            for row in rows
        ]
        return users

async def get_user_by_id(db, user_id):
    async with db.execute(
        "SELECT id, name, email, created_at FROM users WHERE id = ?", 
        (user_id,)
    ) as cursor:
        row = await cursor.fetchone()
        if row:
            return {
                "id": row[0], 
                "name": row[1], 
                "email": row[2], 
                "created_at": row[3]
            }
        return None

async def create_user(db, name, email):
    try:
        cursor = await db.execute(
            "INSERT INTO users (name, email) VALUES (?, ?)",
            (name, email)
        )
        await db.commit()
        
        # Get the user ID of the newly inserted row
        user_id = cursor.lastrowid
        
        # Return the complete user object
        return await get_user_by_id(db, user_id)
    except Exception as e:
        logger.error(f"Error creating user: {e}")
        raise

async def delete_user(db, user_id):
    await db.execute("DELETE FROM users WHERE id = ?", (user_id,))
    await db.commit()
    return True

# Request handlers
async def handle_get_users(request):
    db = request.app['db']
    users = await get_all_users(db)
    return web.json_response(users)

async def handle_get_user(request):
    db = request.app['db']
    user_id = int(request.match_info['id'])
    
    user = await get_user_by_id(db, user_id)
    if user is None:
        return web.json_response(
            {"error": "User not found"}, 
            status=404
        )
    
    return web.json_response(user)

async def handle_create_user(request):
    db = request.app['db']
    
    try:
        data = await request.json()
    except json.JSONDecodeError:
        return web.json_response(
            {"error": "Invalid JSON"}, 
            status=400
        )
    
    # Validate required fields
    if not all(key in data for key in ["name", "email"]):
        return web.json_response(
            {"error": "Missing required fields"}, 
            status=400
        )
    
    try:
        user = await create_user(db, data["name"], data["email"])
        return web.json_response(user, status=201)
    except Exception as e:
        # Handle unique constraint error
        if "UNIQUE constraint failed" in str(e):
            return web.json_response(
                {"error": "Email already exists"}, 
                status=409
            )
        return web.json_response(
            {"error": "Failed to create user"}, 
            status=500
        )

async def handle_delete_user(request):
    db = request.app['db']
    user_id = int(request.match_info['id'])
    
    # Check if user exists
    user = await get_user_by_id(db, user_id)
    if user is None:
        return web.json_response(
            {"error": "User not found"}, 
            status=404
        )
    
    # Delete the user
    await delete_user(db, user_id)
    return web.json_response({"message": "User deleted"})

# Application setup
async def create_app():
    app = web.Application()
    
    # Connect to database
    app['db'] = await init_db()
    
    # Add routes
    app.add_routes([
        web.get('/api/users', handle_get_users),
        web.get('/api/users/{id}', handle_get_user),
        web.post('/api/users', handle_create_user),
        web.delete('/api/users/{id}', handle_delete_user),
    ])
    
    # Cleanup on shutdown
    async def close_db(app):
        await app['db'].close()
    
    app.on_cleanup.append(close_db)
    
    return app

# Run the application
if __name__ == "__main__":
    asyncio.run(web.run_app(create_app()))

# The server will start on http://localhost:8080
```

```python
import asyncio
import time
import random
from functools import wraps
import uvloop  # pip install uvloop (for Unix systems)

# Decorator to measure execution time
def timing_decorator(func):
    @wraps(func)
    async def wrapper(*args, **kwargs):
        start_time = time.time()
        result = await func(*args, **kwargs)
        end_time = time.time()
        print(f"{func.__name__} completed in {end_time - start_time:.4f} seconds")
        return result
    return wrapper

# Inefficient implementation
@timing_decorator
async def inefficient_download_all(urls):
    results = []
    # Sequential processing
    for url in urls:
        result = await download_url(url)
        results.append(result)
    return results

# More efficient implementation
@timing_decorator
async def efficient_download_all(urls):
    # Concurrent processing
    tasks = [download_url(url) for url in urls]

async def efficient_limited_download_all(urls, limit=10):

            return await download_url(url)
    
    tasks = [limited_download(url) for url in urls]
    return await asyncio.gather(*tasks)
```

## 20. Managing Application Lifecycle

Managing the lifecycle of an asyncio application:

```python
import asyncio
import signal
import functools
import logging

# Configure logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

class AsyncioApp:
    def __init__(self):
        self.running = False
        self.tasks = set()
        self.shutdown_event = asyncio.Event()
    
    async def startup(self):
        """Initialize resources when the application starts."""
        logger.info("Application starting up")
        self.running = True
        
        # Create initial tasks
        self.tasks.add(asyncio.create_task(self.periodic_task()))
        self.tasks.add(asyncio.create_task(self.another_task()))
        
        logger.info("Application startup completed")
    
    async def shutdown(self):
        """Clean up resources when the application shuts down."""
        logger.info("Application shutting down")
        
        # Signal tasks to stop
        self.running = False
        self.shutdown_event.set()
        
        # Cancel all running tasks
        for task in self.tasks:
            if not task.done():
                task.cancel()
        
        # Wait for tasks to complete with a timeout
        if self.tasks:
            await asyncio.wait(self.tasks, timeout=5.0)
        
        logger.info("Application shutdown completed")
    
    async def periodic_task(self):
        """A task that runs periodically."""
        try:
            while self.running:
                logger.info("Periodic task running")
                
                # Perform some work
                await asyncio.sleep(1.0)
                
                # Use wait_for to make the sleep interruptible
                try:
                    await asyncio.wait_for(
                        self.shutdown_event.wait(), 
                        timeout=2.0
                    )
                    # If we get here, shutdown was signaled
                    break
                except asyncio.TimeoutError:
                    # Timeout means continue with the next iteration
                    pass
                
            logger.info("Periodic task stopped")
        except asyncio.CancelledError:
            logger.info("Periodic task cancelled")
            raise
        except Exception:
            logger.exception("Error in periodic task")
    
    async def another_task(self):
        """Another background task."""
        try:
            while self.running:
                logger.info("Another task running")
                
                # Check shutdown event with timeout
                try:
                    await asyncio.wait_for(
                        self.shutdown_event.wait(), 
                        timeout=3.0
                    )
                    # If we get here, shutdown was signaled
                    break
                except asyncio.TimeoutError:
                    # Timeout means continue
                    pass
            
            logger.info("Another task stopped")
        except asyncio.CancelledError:
            logger.info("Another task cancelled")
            raise
        except Exception:
            logger.exception("Error in another task")

async def main():
    app = AsyncioApp()
    
    # Register signal handlers
    loop = asyncio.get_running_loop()
    
    # Handle SIGINT (Ctrl+C) and SIGTERM
    for sig in (signal.SIGINT, signal.SIGTERM):
        loop.add_signal_handler(
            sig,
            functools.partial(asyncio.create_task, app.shutdown())
        )
    
    # Start the application
    await app.startup()
    
    try:
        # Keep the application running
        logger.info("Application running, press Ctrl+C to exit")
        # Wait indefinitely (until shutdown is called)
        await app.shutdown_event.wait()
    finally:
        # Ensure shutdown happens
        await app.shutdown()

# Run the application
if __name__ == "__main__":
    asyncio.run(main())
```

## 21. Conclusion and Further Resources

### Key Takeaways

1. **Async is not always faster**: It's best for I/O-bound operations, not CPU-bound tasks
2. **Asyncio shines with many concurrent operations**: Network requests, disk I/O
3. **Proper error handling is critical**: Unhandled exceptions can silently crash background tasks
4. **Use the right tools**: `asyncio.gather`, `TaskGroup`, timeouts, etc.
5. **Resource management**: Always clean up resources using context managers or try/finally

### Recommended Practices

1. Organize code into clear, focused coroutines
2. Use context managers for resource management
3. Implement proper error handling and cancellation
4. Set timeouts for operations that might hang
5. Limit concurrency for external services
6. Name your tasks for easier debugging
7. Consider asyncio alternatives like Trio for different concurrency models
