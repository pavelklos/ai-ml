## 1. Úvod do proměnných

Proměnné v Pythonu slouží jako kontejnery pro ukládání hodnot. Na rozdíl od jiných programovacích jazyků Python nevyžaduje deklaraci proměnných – proměnná je vytvořena při prvním přiřazení hodnoty.

```python
# Vytvoření proměnných
jmeno = "Jan"
vek = 25
vyska = 1.75
je_student = True

# Výpis proměnných
print(jmeno)        # Výstup: Jan
print(vek)          # Výstup: 25
print(vyska)        # Výstup: 1.75
print(je_student)   # Výstup: True

# Kontrola typů proměnných
print(type(jmeno))        # Výstup: <class 'str'>
print(type(vek))          # Výstup: <class 'int'>
print(type(vyska))        # Výstup: <class 'float'>
print(type(je_student))   # Výstup: <class 'bool'>
```

### Pravidla pro pojmenování proměnných

- Názvy proměnných mohou obsahovat písmena, číslice a podtržítka.
- Názvy proměnných musí začínat písmenem nebo podtržítkem.
- Názvy proměnných jsou citlivé na velikost písmen.
- Názvy proměnných nesmí být klíčová slova Pythonu.

```python
# Platné názvy proměnných
moje_promenna = 10
_moje_promenna = 20
mojePromenna = 30
MOJEPROMENNA = 40
moje_promenna_2 = 50

# Neplatné názvy proměnných
# 2moje_promenna = 60    # Nemůže začínat číslem
# moje-promenna = 70     # Nemůže obsahovat pomlčky
# moje promenna = 80     # Nemůže obsahovat mezery
# class = 90             # Nemůže být klíčové slovo
```

## 2. Číselné datové typy

Python má tři hlavní číselné datové typy:

### Celá čísla (int)

Celá čísla jsou kladná nebo záporná čísla bez desetinné části.

```python
x = 10
y = -5
velke_cislo = 12345678901234567890

print(x)           # Výstup: 10
print(y)           # Výstup: -5
print(velke_cislo) # Výstup: 12345678901234567890

# Operace s celými čísly
print(x + y)       # Výstup: 5
print(x * y)       # Výstup: -50
```

### Desetinná čísla (float)

Desetinná čísla obsahují desetinnou část.

```python
a = 3.14
b = -0.5
c = 2e3  # Vědecký zápis (2 × 10³)

print(a)      # Výstup: 3.14
print(b)      # Výstup: -0.5
print(c)      # Výstup: 2000.0

# Operace s desetinnými čísly
print(a + b)  # Výstup: 2.64
print(a * c)  # Výstup: 6280.0
```

### Komplexní čísla (complex)

Komplexní čísla mají reálnou a imaginární část, reprezentovanou jako `a + bj`.

```python
z = 2 + 3j
w = 1 - 2j

print(z)         # Výstup: (2+3j)
print(z.real)    # Výstup: 2.0
print(z.imag)    # Výstup: 3.0
print(z + w)     # Výstup: (3+1j)
print(z * w)     # Výstup: (8-1j)
```

## 3. Datový typ řetězec (string)

Řetězce v Pythonu jsou sekvence znaků uzavřené v jednoduchých (`'`), dvojitých (`"`) nebo trojitých uvozovkách (`'''` nebo `"""`).

```python
# Vytvoření řetězců
jmeno = "Alice"
zprava = 'Ahoj, světe!'
vice_radku = """Toto je
víceřádkový
řetězec."""

print(jmeno)       # Výstup: Alice
print(zprava)      # Výstup: Ahoj, světe!
print(vice_radku)  # Výstup: Toto je
                   #         víceřádkový
                   #         řetězec.

# Indexování řetězců (0-based)
print(jmeno[0])    # Výstup: A
print(jmeno[-1])   # Výstup: e

# Řezání řetězců
print(jmeno[1:3])  # Výstup: li
print(jmeno[:2])   # Výstup: Al
print(jmeno[2:])   # Výstup: ice

# Metody řetězců
print(jmeno.upper())             # Výstup: ALICE
print(zprava.lower())            # Výstup: ahoj, světe!
print(zprava.replace('A', 'J'))  # Výstup: Jhoj, světe!
print(len(jmeno))                # Výstup: 5
```

## 4. Datový typ boolean

Boolean hodnoty reprezentují `True` nebo `False`. Často se používají v podmínkách.

```python
# Boolean proměnné
je_student = True
pracuje = False

print(je_student)  # Výstup: True
print(pracuje)     # Výstup: False

# Boolean operace
print(je_student and pracuje)  # Výstup: False (logické AND)
print(je_student or pracuje)   # Výstup: True (logické OR)
print(not je_student)          # Výstup: False (logické NOT)

# Vyhodnocení boolean hodnot
print(bool(0))     # Výstup: False
print(bool(1))     # Výstup: True
print(bool(""))    # Výstup: False
print(bool("Ahoj"))# Výstup: True
print(bool([]))    # Výstup: False
```

## 5. Převod datových typů

Python umožňuje převod mezi různými datovými typy.

```python
# Celé číslo na jiné typy
cislo = 10
print(float(cislo))  # Výstup: 10.0
print(str(cislo))    # Výstup: "10"
print(bool(cislo))   # Výstup: True

# Desetinné číslo na jiné typy
pi = 3.14
print(int(pi))       # Výstup: 3 (odstraní desetinnou část)
print(str(pi))       # Výstup: "3.14"

# Řetězec na číselné typy
cislo_str = "25"
print(int(cislo_str))     # Výstup: 25
print(float(cislo_str))   # Výstup: 25.0

# Pozor na chyby při převodu!
# print(int("ahoj"))  # Vyvolá ValueError
```

## 6. Základní aritmetické operace

Python podporuje standardní aritmetické operace.

```python
a = 10
b = 3

# Základní operace
print(a + b)    # Výstup: 13 (sčítání)
print(a - b)    # Výstup: 7 (odčítání)
print(a * b)    # Výstup: 30 (násobení)
print(a / b)    # Výstup: 3.3333... (dělení, vždy vrací float)
print(a // b)   # Výstup: 3 (celé dělení)
print(a % b)    # Výstup: 1 (zbytek po dělení)
print(a ** b)   # Výstup: 1000 (mocnina: 10³)

# Zkrácené přiřazení
c = 5
c += 2   # Ekvivalentní c = c + 2
print(c)  # Výstup: 7

c -= 1   # Ekvivalentní c = c - 1
print(c)  # Výstup: 6

c *= 3   # Ekvivalentní c = c * 3
print(c)  # Výstup: 18

c /= 6   # Ekvivalentní c = c / 6
print(c)  # Výstup: 3.0
```

## 7. Porovnávací a logické operace

Porovnávací operátory slouží k porovnání hodnot, zatímco logické operátory kombinují boolean výrazy.

```python
x = 5
y = 10

# Porovnávací operátory
print(x == y)   # Výstup: False (rovná se)
print(x != y)   # Výstup: True (nerovná se)
print(x < y)    # Výstup: True (menší než)
print(x > y)    # Výstup: False (větší než)
print(x <= y)   # Výstup: True (menší nebo rovno)
print(x >= y)   # Výstup: False (větší nebo rovno)

# Logické operátory
a = True
b = False

print(a and b)  # Výstup: False (True, pokud jsou oba True)
print(a or b)   # Výstup: True (True, pokud je alespoň jeden True)
print(not a)    # Výstup: False (negace)

# Kombinace porovnání
vek = 25
ma_prukaz = True
print(vek >= 21 and ma_prukaz)  # Výstup: True (může koupit alkohol v USA)
```

## 8. Techniky přiřazení proměnných

Python nabízí několik způsobů přiřazení hodnot proměnným.

```python
# Vícenásobné přiřazení
a, b, c = 1, 2, 3
print(a, b, c)  # Výstup: 1 2 3

# Prohození proměnných
x = 5
y = 10
x, y = y, x
print(x, y)     # Výstup: 10 5

# Rozbalení sekvencí
souradnice = (3, 4)
x, y = souradnice
print(x, y)     # Výstup: 3 4

# Rozbalení s * (pro seznamy/tuples)
prvni, *stred, posledni = [1, 2, 3, 4, 5]
print(prvni)    # Výstup: 1
print(stred)    # Výstup: [2, 3, 4]
print(posledni) # Výstup: 5
```

## 9. Vestavěné funkce pro práci s datovými typy

Python poskytuje mnoho vestavěných funkcí pro práci s datovými typy.

```python
# Číselné funkce
print(abs(-5))        # Výstup: 5 (absolutní hodnota)
print(max(1, 3, 5))   # Výstup: 5 (maximální hodnota)
print(min(1, 3, 5))   # Výstup: 1 (minimální hodnota)
print(pow(2, 3))      # Výstup: 8 (mocnina: 2³)
print(round(3.75, 1)) # Výstup: 3.8 (zaokrouhlení na 1 desetinné místo)

# Kontrola typů
print(isinstance(5, int))        # Výstup: True
print(isinstance("ahoj", str))   # Výstup: True
print(isinstance(3.14, float))   # Výstup: True

# Funkce pro řetězce
pozdrav = "ahoj svet"
print(pozdrav.capitalize())  # Výstup: Ahoj svet
print(pozdrav.title())       # Výstup: Ahoj Svet
print(pozdrav.count('a'))    # Výstup: 1 (počet výskytů)
print(pozdrav.find('o'))     # Výstup: 1 (první výskyt)
```
