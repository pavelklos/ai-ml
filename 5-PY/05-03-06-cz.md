## 1. Úvod do typových nápověd

Typové nápovědy byly zavedeny v Pythonu 3.5 prostřednictvím PEP 484, což umožňuje vývojářům označit očekávané typy proměnných, parametrů funkcí a návratových hodnot. Přestože Python zůstává dynamicky typovaným jazykem, typové nápovědy přinášejí několik výhod:

- Lepší čitelnost kódu a samodokumentace
- Lepší podpora v IDE (automatické dokončování, detekce chyb)
- Statická kontrola typů pro odhalení chyb souvisejících s typy před spuštěním
- Vylepšené možnosti refaktoringu

Typové nápovědy standardně neovlivňují chování Pythonu za běhu - jsou to jen nápovědy pro nástroje, IDE a vývojáře.

```python
# Bez typových nápověd
def calculate_total(price, quantity):
    return price * quantity

# S typovými nápovědami
def calculate_total(price: float, quantity: int) -> float:
    return price * quantity
```

## 2. Základní typové anotace

Nejzákladnější typové nápovědy jsou aplikovány na proměnné pomocí syntaxe s dvojtečkou:

```python
# Základní typové anotace
name: str = "John Doe"
age: int = 30
height: float = 1.75
is_active: bool = True

# Anotace může být přidána bez inicializace
employee_id: int  # Zatím není přiřazena žádná hodnota
employee_id = 12345

# Typové nápovědy pro konstanty (podle konvence použijte Final)
from typing import Final
MAX_CONNECTIONS: Final[int] = 100
```

Vestavěné typy Pythonu mohou být přímo použity jako anotace, včetně `str`, `int`, `float`, `bool`, `bytes` a `complex`.

## 3. Typové nápovědy pro kolekce

Pro kolekce používáme typy z modulu `typing` k určení, jaké typy bude kolekce obsahovat:

```python
from typing import List, Dict, Set, Tuple, Sequence

# Seznamy
numbers: List[int] = [1, 2, 3, 4, 5]
names: List[str] = ["Alice", "Bob", "Charlie"]

# Slovníky
user_ages: Dict[str, int] = {"Alice": 30, "Bob": 25}
config: Dict[str, str] = {"host": "localhost", "port": "8000"}

# Množiny
unique_ids: Set[int] = {1, 2, 3, 4, 5}

# Ntice s pevnou velikostí
point: Tuple[float, float] = (10.5, 20.5)

# Ntice s proměnnou velikostí
numbers: Tuple[int, ...] = (1, 2, 3, 4, 5)

# Sekvence (objekty podobné seznamu)
items: Sequence[str] = ["apple", "banana", "cherry"]

# V Pythonu 3.9+ můžete použít přímo vestavěné typy kolekcí
modern_numbers: list[int] = [1, 2, 3, 4, 5]  # Python 3.9+
modern_ages: dict[str, int] = {"Alice": 30, "Bob": 25}  # Python 3.9+
```

## 4. Typové anotace funkcí a návratových hodnot

Typové nápovědy jsou zvláště užitečné pro dokumentování parametrů funkcí a návratových hodnot:

```python
from typing import List, Dict, Optional

def greet(name: str) -> str:
    return f"Hello, {name}!"

def calculate_average(numbers: List[float]) -> float:
    if not numbers:
        return 0.0
    return sum(numbers) / len(numbers)

def process_data(data: Dict[str, int], scale: float = 1.0) -> Dict[str, float]:
    result: Dict[str, float] = {}
    for key, value in data.items():
        result[key] = value * scale
    return result

# Funkce, které nevrací hodnotu
def log_message(message: str) -> None:
    print(f"LOG: {message}")

# Více parametrů s různými typy
def register_user(username: str, age: int, active: bool = True) -> Dict[str, object]:
    return {"username": username, "age": age, "active": active}
```

## 5. Unijní typy a volitelné hodnoty

Někdy může proměnná nebo parametr přijímat více typů. Pro to používáme `Union` nebo zkrácený operátor `|` (Python 3.10+):

```python
from typing import Union, Optional

# Proměnná, která může být buď int nebo string
user_id: Union[int, str] = 123
user_id = "ABC123"  # Také platné

# V Pythonu 3.10+ můžete použít operátor |
price: int | float = 19.99

# Optional je zkratka pro Union[X, None]
# Tyto dva zápisy jsou ekvivalentní:
def get_user(user_id: Optional[int] = None) -> Dict[str, object]:
    if user_id is None:
        return {"id": 0, "name": "Host"}
    # Vyhledání uživatele podle ID
    return {"id": user_id, "name": f"Uživatel {user_id}"}

def get_config(path: Union[str, None] = None) -> Dict[str, str]:
    if path is None:
        path = "default_config.json"
    # Načtení konfigurace z cesty
    return {"setting": "value"}

# V Pythonu 3.10+ můžete jednoduše psát:
def get_items(category: str | None = None) -> list[str]:
    if category is None:
        return ["item1", "item2"]
    # Vrátit položky filtrované podle kategorie
    return [f"{category}_item1", f"{category}_item2"]
```

## 6. Typové aliasy a vlastní typy

Typové aliasy vám umožňují vytvářet vlastní názvy pro komplexní typy, což zlepšuje čitelnost:

```python
from typing import Dict, List, Tuple, TypedDict, NewType

# Jednoduché typové aliasy
UserId = int
Point = Tuple[float, float]
Points = List[Point]

def plot_points(points: Points) -> None:
    for point in points:
        x, y = point
        print(f"Vykreslení bodu ({x}, {y})")

# Tyto aliasy můžete použít kdekoli
user_id: UserId = 42
coordinates: Point = (10.5, 20.5)
path: Points = [(0.0, 0.0), (1.0, 1.0), (2.0, 0.5)]

# Pro strukturované slovníky můžete použít TypedDict
class UserDict(TypedDict):
    id: int
    name: str
    email: str
    active: bool

def process_user(user: UserDict) -> None:
    print(f"Zpracování {user['name']}, ID: {user['id']}")

valid_user: UserDict = {
    "id": 123,
    "name": "John Doe",
    "email": "john@example.com",
    "active": True
}

# NewType vytváří odlišné typy
EmployeeId = NewType("EmployeeId", int)

def get_employee_details(employee_id: EmployeeId) -> Dict[str, object]:
    # Získání detailů zaměstnance
    return {"name": "Jméno zaměstnance"}

regular_id = 123
employee_id = EmployeeId(regular_id)  # Konverze na EmployeeId
get_employee_details(employee_id)  # Platné
# get_employee_details(regular_id)  # Kontrolory typů označí toto jako chybu
```

## 7. Generické typy

Generika vám umožňují definovat znovupoužitelné komponenty, které fungují s více typy:

```python
from typing import TypeVar, Generic, List, Dict

# Definujte proměnnou typu
T = TypeVar('T')
K = TypeVar('K')
V = TypeVar('V')

# Příklad generické funkce
def first_element(collection: List[T]) -> T:
    if not collection:
        raise IndexError("Prázdná kolekce")
    return collection[0]

# Použití
first_int = first_element([1, 2, 3])  # Typ: int
first_str = first_element(["a", "b", "c"])  # Typ: str

# Příklad generické třídy
class Stack(Generic[T]):
    def __init__(self) -> None:
        self.items: List[T] = []
        
    def push(self, item: T) -> None:
        self.items.append(item)
        
    def pop(self) -> T:
        if not self.items:
            raise IndexError("Pop z prázdného zásobníku")
        return self.items.pop()
    
    def peek(self) -> T:
        if not self.items:
            raise IndexError("Peek z prázdného zásobníku")
        return self.items[-1]
    
    def is_empty(self) -> bool:
        return len(self.items) == 0

# Použití
int_stack = Stack[int]()
int_stack.push(1)
int_stack.push(2)
print(int_stack.pop())  # 2

str_stack = Stack[str]()
str_stack.push("hello")
print(str_stack.peek())  # "hello"

# Generická třída slovníku
class KeyValueStore(Generic[K, V]):
    def __init__(self) -> None:
        self.store: Dict[K, V] = {}
    
    def set(self, key: K, value: V) -> None:
        self.store[key] = value
    
    def get(self, key: K) -> V:
        return self.store[key]

# Použití
str_to_int = KeyValueStore[str, int]()
str_to_int.set("one", 1)
str_to_int.set("two", 2)
print(str_to_int.get("one"))  # 1
```

## 8. Statická kontrola typů pomocí mypy

Mypy je statický kontrolor typů pro Python, který může odhalit chyby související s typy před spuštěním:

```python
# example.py
def add(a: int, b: int) -> int:
    return a + b

# Toto by způsobilo typovou chybu při kontrole s mypy
result = add("hello", "world")
```

Pro kontrolu vašeho kódu s mypy:

```bash
pip install mypy
mypy example.py
```

Výstup:
```
example.py:5: error: Argument 1 to "add" has incompatible type "str"; expected "int"
example.py:5: error: Argument 2 to "add" has incompatible type "str"; expected "int"
```

Konfigurace může být přidána do souboru `mypy.ini`:

```ini
# mypy.ini
[mypy]
python_version = 3.10
warn_return_any = True
warn_unused_configs = True
disallow_untyped_defs = True
disallow_incomplete_defs = True

[mypy.plugins.numpy.*]
follow_imports = silent
```

Běžné příznaky mypy pro vynucení přísnější kontroly:

```python
# Použití přísného režimu s @mypy.stubgen
from typing import Any, List

# Bez tohoto příznaku by mypy povolilo tuto funkci bez typových anotací
def untyped_func(a, b):  # chyba mypy s disallow_untyped_defs
    return a + b

# Neúplné typové anotace
def incomplete_func(a: int, b):  # chyba mypy s disallow_incomplete_defs
    return a + b

# Typ Any umožňuje méně přísnou kontrolu
def process_data(data: Any) -> None:  # varování mypy s warn_return_any
    print(data)
```

## 9. Kontrola typů za běhu

Někdy můžete chtít vynutit kontrolu typů za běhu:

```python
from typing import List, Dict, Any, cast, TypeGuard
import inspect

# Jednoduchá kontrola typů za běhu
def enforce_types(func):
    signature = inspect.signature(func)
    parameters = signature.parameters
    
    def wrapper(*args, **kwargs):
        bound_arguments = signature.bind(*args, **kwargs)
        bound_arguments.apply_defaults()
        
        for param_name, param_value in bound_arguments.arguments.items():
            if param_name in parameters:
                param_type = parameters[param_name].annotation
                if param_type is not inspect.Parameter.empty and not isinstance(param_value, param_type):
                    raise TypeError(f"Parametr '{param_name}' musí být typu {param_type.__name__}")
        
        result = func(*args, **kwargs)
        return_type = signature.return_annotation
        
        if return_type is not inspect.Signature.empty and not isinstance(result, return_type):
            raise TypeError(f"Návratová hodnota musí být typu {return_type.__name__}")
        
        return result
    
    return wrapper

# Použití kontrolora typů za běhu
@enforce_types
def add_numbers(a: int, b: int) -> int:
    return a + b

# Toto vyvolá TypeError za běhu
try:
    add_numbers(1, "2")
except TypeError as e:
    print(e)  # Parametr 'b' musí být typu int

# Pro robustnější kontrolu typů za běhu zvažte knihovny jako:
# - pydantic
# - typeguard
# - beartype
```

Pro produkční použití zvažte knihovny speciálně navržené pro kontrolu typů za běhu:

```python
# Použití typeguard pro kontrolu typů za běhu
from typeguard import typechecked

@typechecked
def process_user_data(user_id: int, settings: Dict[str, bool]) -> List[str]:
    return [f"Nastavení: {k}" for k, v in settings.items() if v]

# Toto vyvolá chybu za běhu
# process_user_data("123", {"notify": True})  # TypeError: type of argument "user_id" must be int; got str instead
```

## 10. Osvědčené postupy a omezení

### Osvědčené postupy

```python
# 1. Buďte konzistentní s typovými anotacemi
def inconsistent(a: int, b):  # Špatně: mix anotovaných a neanotovaných
    return a + b

def consistent(a: int, b: int) -> int:  # Dobře: všechny parametry jsou anotované
    return a + b

# 2. Používejte None místo Optional pro výchozí parametry
# Špatně
def bad_optional(value: Optional[int] = None) -> int:
    return value if value is not None else 0

# Dobře
def good_optional(value: int | None = None) -> int:
    return value if value is not None else 0

# 3. Používejte Protocol pro duck typing
from typing import Protocol, Iterable

class Drawable(Protocol):
    def draw(self) -> None: ...

def draw_all(items: Iterable[Drawable]) -> None:
    for item in items:
        item.draw()

class Circle:
    def draw(self) -> None:
        print("Kreslím kruh")

class Square:
    def draw(self) -> None:
        print("Kreslím čtverec")

draw_all([Circle(), Square()])  # Funguje bez dědičnosti

# 4. Používejte Literal pro omezené možnosti řetězců/čísel
from typing import Literal

def align_text(alignment: Literal["left", "center", "right"]) -> str:
    return f"Text zarovnaný {alignment}"

align_text("left")     # OK
align_text("center")   # OK
# align_text("top")    # Typová chyba
```

### Omezení

Typové nápovědy mají některá omezení, kterých byste si měli být vědomi:

```python
# 1. Režie za běhu - typové nápovědy neovlivňují chování za běhu
def calculate(a: int, b: int) -> int:
    return a + b

calculate("hello", "world")  # Funguje za běhu: "helloworld"

# 2. Dynamické prvky může být těžké správně typovat
def dynamic_attributes(obj: object) -> None:
    # Těžké typově napovědět při použití dynamických atributů
    obj.dynamic_attr = "value"  # Kontrolory typů mohou nahlásit chybu

# 3. Komplexní typové vztahy
from typing import TypeVar, cast

T = TypeVar('T')
def complex_relationship(x: T) -> T:
    # Nějaká komplexní logika, kde je typový vztah
    # těžké vyjádřit pomocí typového systému Pythonu
    result = do_something_with(x)
    return cast(T, result)  # Někdy musíme použít cast

# 4. Knihovny třetích stran bez typových nápověd
import some_library  # Pokud tato knihovna nemá typové nápovědy

result = some_library.function()  # Typ bude Any
```

## Shrnutí

Typové nápovědy v Pythonu poskytují výkonný způsob, jak dokumentovat kód a odhalit chyby před spuštěním:

1. **Typové anotace** přidávají jasnost a zlepšují podporu IDE bez ovlivnění chování za běhu
2. **Typy kolekcí** umožňují specifikovat typy prvků v datových strukturách
3. **Anotace funkcí** dokumentují očekávané vstupy a výstupy funkcí
4. **Typy Union a Optional** umožňují flexibilní zpracování různých možných typů
5. **Typové aliasy a vlastní typy** zlepšují čitelnost a organizaci kódu
6. **Generické typy** umožňují typově bezpečné znovupoužitelné komponenty
7. **Statická kontrola typů s mypy** odhaluje typové chyby před spuštěním
8. **Kontrola typů za běhu** může ověřit typy během provádění programu
9. **Osvědčené postupy** zahrnují konzistentnost a používání vhodných typových konstruktů
10. **Omezení** zahrnují režii za běhu a výzvy s dynamickými prvky

Začleněním typových nápověd do vašeho Python kódu můžete vytvořit lépe udržovatelný, samodokumentující se kód, který je méně náchylný k chybám a snazší k refaktoringu.
