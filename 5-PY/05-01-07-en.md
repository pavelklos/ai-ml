## 1. Introduction to Dictionaries and Sets

In Python, dictionaries and sets are two powerful built-in data structures. Dictionaries are collections of key-value pairs, while sets are unordered collections of unique elements. Both provide fast access to data and have specific use cases in programming.

```python
# Dictionary example - key-value pairs
person = {
    "name": "Alice",
    "age": 30,
    "city": "New York"
}

# Set example - collection of unique elements
prime_numbers = {2, 3, 5, 7, 11, 13}
```

## 2. Creating and Accessing Dictionaries

Dictionaries in Python are created with curly braces `{}` or the `dict()` constructor. Keys must be immutable types (strings, numbers, tuples), while values can be any data type.

```python
# Creating dictionaries
empty_dict = {}                          # Empty dictionary
user_info = {"username": "john_doe", "email": "john@example.com", "active": True}
grades = dict(math=95, science=88, history=82)  # Using dict() constructor

# Accessing dictionary values by key
print(user_info["username"])    # Output: john_doe

# Using get() method (returns None or default value if key doesn't exist)
print(user_info.get("email"))   # Output: john@example.com
print(user_info.get("phone", "Not available"))  # Output: Not available

# Modifying values
user_info["active"] = False
print(user_info)  # Output: {'username': 'john_doe', 'email': 'john@example.com', 'active': False}

# Adding new key-value pairs
user_info["signup_date"] = "2023-04-15"
print(user_info)

# Checking if a key exists
if "email" in user_info:
    print("Email is:", user_info["email"])
```

## 3. Dictionary Methods and Operations

Python dictionaries come with many useful methods to manipulate and access data.

```python
student = {
    "name": "Emma",
    "age": 22,
    "courses": ["Math", "Computer Science", "Physics"],
    "grades": {"Math": "A", "CS": "B+", "Physics": "A-"}
}

# Getting all keys and values
print(student.keys())    # Output: dict_keys(['name', 'age', 'courses', 'grades'])
print(student.values())  # Output: dict_values(['Emma', 22, ['Math', 'Computer Science', 'Physics'], {'Math': 'A', 'CS': 'B+', 'Physics': 'A-'}])

# Getting key-value pairs as tuples
print(student.items())   # Output: dict_items([('name', 'Emma'), ('age', 22), ...])

# Removing items
removed_age = student.pop("age")  # Removes and returns the value
print(removed_age)       # Output: 22
print(student)           # 'age' is no longer in the dictionary

# Remove and return an arbitrary key-value pair
last_item = student.popitem()
print(last_item)         # Returns a tuple of (key, value)

# Clearing all items
student.clear()
print(student)           # Output: {}

# Updating a dictionary with another dictionary
student = {"name": "Emma", "age": 22}
more_info = {"major": "Computer Science", "year": "Junior"}
student.update(more_info)
print(student)  # Output: {'name': 'Emma', 'age': 22, 'major': 'Computer Science', 'year': 'Junior'}

# Get default value if key doesn't exist (and add it to the dictionary)
counts = {}
counts.setdefault("apples", 0)
counts["apples"] += 1
print(counts)  # Output: {'apples': 1}
```

## 4. Dictionary Comprehensions

Similar to list comprehensions, dictionary comprehensions provide a concise way to create dictionaries.

```python
# Creating a dictionary with dictionary comprehension
squares = {x: x**2 for x in range(1, 6)}
print(squares)  # Output: {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Dictionary comprehension with conditions
even_squares = {x: x**2 for x in range(1, 11) if x % 2 == 0}
print(even_squares)  # Output: {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}

# Converting two lists into a dictionary
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
name_to_age = {name: age for name, age in zip(names, ages)}
print(name_to_age)  # Output: {'Alice': 25, 'Bob': 30, 'Charlie': 35}

# Transforming an existing dictionary
original = {"a": 1, "b": 2, "c": 3}
squared = {k: v**2 for k, v in original.items()}
print(squared)  # Output: {'a': 1, 'b': 4, 'c': 9}
```

## 5. Nested Dictionaries

Dictionaries can contain other dictionaries as values, creating nested structures that are useful for representing complex hierarchical data.

```python
# Nested dictionary example
company = {
    "department1": {
        "name": "Engineering",
        "manager": "Alice",
        "employees": {
            "emp1": {"name": "Bob", "role": "Developer"},
            "emp2": {"name": "Charlie", "role": "QA Engineer"}
        }
    },
    "department2": {
        "name": "Marketing",
        "manager": "David",
        "employees": {
            "emp3": {"name": "Eve", "role": "Content Writer"},
            "emp4": {"name": "Frank", "role": "SEO Specialist"}
        }
    }
}

# Accessing nested values
print(company["department1"]["name"])  # Output: Engineering
print(company["department1"]["employees"]["emp1"]["role"])  # Output: Developer

# Modifying nested values
company["department2"]["employees"]["emp3"]["role"] = "Senior Content Writer"

# Adding to nested dictionaries
company["department1"]["employees"]["emp5"] = {"name": "Grace", "role": "DevOps"}

# Iterating through nested dictionaries
for dept_id, dept_info in company.items():
    print(f"Department: {dept_info['name']}")
    print(f"Manager: {dept_info['manager']}")
    print("Employees:")
    for emp_id, emp_info in dept_info['employees'].items():
        print(f"  - {emp_info['name']}: {emp_info['role']}")
    print()
```

## 6. Introduction to Sets

Sets are unordered collections of unique elements. They are useful for membership testing, removing duplicates, and mathematical set operations.

```python
# Creating sets
empty_set = set()  # Note: {} creates an empty dictionary, not a set
colors = {"red", "green", "blue"}
numbers = set([1, 2, 3, 2, 1])  # Duplicates are automatically removed
print(numbers)  # Output: {1, 2, 3}

# Adding elements to a set
colors.add("yellow")
print(colors)  # Output: {'blue', 'green', 'yellow', 'red'} (order may vary)

# Removing elements from a set
colors.remove("green")  # Raises KeyError if element doesn't exist
print(colors)

colors.discard("purple")  # No error if element doesn't exist
print(colors)

# Pop an arbitrary element
popped = colors.pop()
print(popped)
print(colors)

# Clearing a set
colors.clear()
print(colors)  # Output: set()

# Membership testing (very fast operation)
fruits = {"apple", "banana", "cherry"}
print("banana" in fruits)  # Output: True
print("orange" in fruits)  # Output: False
```

## 7. Set Creation and Operations

Sets provide operations for adding, removing, and manipulating items.

```python
# Different ways to create sets
set1 = {1, 2, 3}
set2 = set([3, 4, 5])
set3 = set("hello")  # Creates a set from string characters
print(set3)  # Output: {'h', 'e', 'l', 'o'}

# Finding unique elements in a list
duplicated_list = [1, 2, 3, 1, 2, 5, 6, 7, 8, 5, 2]
unique_items = set(duplicated_list)
print(unique_items)  # Output: {1, 2, 3, 5, 6, 7, 8}

# Set comprehension
even_numbers = {x for x in range(10) if x % 2 == 0}
print(even_numbers)  # Output: {0, 2, 4, 6, 8}

# Frozen sets (immutable sets)
immutable_set = frozenset([1, 2, 3])
# immutable_set.add(4)  # This would raise an AttributeError

# Converting back to list
colors = {"red", "green", "blue"}
colors_list = list(colors)
print(colors_list)  # Output: ['red', 'green', 'blue'] (order may vary)
```

## 8. Mathematical Set Operations

Sets in Python support mathematical set operations, allowing you to perform operations like union, intersection, difference, and symmetric difference.

```python
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

# Union: elements in either A or B (or both)
print(A.union(B))           # Output: {1, 2, 3, 4, 5, 6, 7, 8}
print(A | B)                # Same operation using operator

# Intersection: elements in both A and B
print(A.intersection(B))    # Output: {4, 5}
print(A & B)                # Same operation using operator

# Difference: elements in A but not in B
print(A.difference(B))      # Output: {1, 2, 3}
print(A - B)                # Same operation using operator

# Symmetric difference: elements in either A or B but not in both
print(A.symmetric_difference(B))  # Output: {1, 2, 3, 6, 7, 8}
print(A ^ B)                      # Same operation using operator

# Subset, superset, and disjoint tests
C = {1, 2}
print(C.issubset(A))        # Output: True (C is a subset of A)
print(A.issuperset(C))      # Output: True (A is a superset of C)
print(A.isdisjoint(C))      # Output: False (A and C have elements in common)
print({9, 10}.isdisjoint(A))  # Output: True (no common elements)

# Update operations (modify the original set)
D = {1, 2, 3}
E = {3, 4, 5}
D.update(E)                 # Union in-place
print(D)                    # Output: {1, 2, 3, 4, 5}

F = {1, 2, 3, 4}
G = {3, 4, 5, 6}
F.intersection_update(G)    # Intersection in-place
print(F)                    # Output: {3, 4}

H = {1, 2, 3, 4, 5}
I = {4, 5, 6}
H.difference_update(I)      # Difference in-place
print(H)                    # Output: {1, 2, 3}
```
