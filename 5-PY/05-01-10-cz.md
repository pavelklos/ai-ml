## 1. Úvod do souborových operací

Operace vstup/výstup (I/O) souborů umožňují programům v Pythonu pracovat se soubory na vašem počítači. Tyto operace jsou nezbytné pro úkoly jako čtení konfiguračních souborů, ukládání dat programu, zpracování velkých datových sad a mnoho dalšího. Python poskytuje vestavěné funkce a metody, které usnadňují práci se soubory.

```python
# Souborové operace vám umožňují:
# - Číst data ze souborů
# - Zapisovat data do souborů
# - Přidávat do existujících souborů
# - Zpracovávat soubory řádek po řádku
# - Pracovat s různými formáty souborů

# Python používá objekty souborů pro interakci se soubory
# Základní operace se soubory sledují tento vzor:
# 1. Otevřít soubor
# 2. Provést operace (čtení nebo zápis)
# 3. Zavřít soubor
```

## 2. Otevírání a zavírání souborů

Než můžete číst ze souboru nebo do něj zapisovat, musíte jej otevřít pomocí vestavěné funkce `open()`. Po dokončení je důležité soubor zavřít, aby se uvolnily systémové prostředky.

```python
# Základní syntaxe pro otevření souboru
soubor = open('priklad.txt', 'r')  # 'r' znamená režim čtení

# Vždy zavřete soubory, když s nimi skončíte
soubor.close()

# Kontrola, zda soubor existuje, než ho otevřeme
import os

cesta_k_souboru = 'data.txt'
if os.path.exists(cesta_k_souboru):
    soubor = open(cesta_k_souboru, 'r')
    # Udělej něco se souborem
    soubor.close()
else:
    print(f"Soubor {cesta_k_souboru} neexistuje")

# Získání informací o souboru
if os.path.exists(cesta_k_souboru):
    velikost_souboru = os.path.getsize(cesta_k_souboru)  # Velikost v bajtech
    print(f"Velikost souboru: {velikost_souboru} bajtů")
    
    # Kontrola, zda jde o soubor nebo adresář
    if os.path.isfile(cesta_k_souboru):
        print(f"{cesta_k_souboru} je soubor")
    elif os.path.isdir(cesta_k_souboru):
        print(f"{cesta_k_souboru} je adresář")
```

## 3. Čtení ze souborů

Python nabízí několik metod pro čtení obsahu souborů, které vám umožňují číst celý soubor najednou nebo řádek po řádku.

```python
# Čtení celého souboru najednou
soubor = open('priklad.txt', 'r')
obsah = soubor.read()
print(obsah)
soubor.close()

# Čtení konkrétního počtu znaků
soubor = open('priklad.txt', 'r')
prvnich_10_znaku = soubor.read(10)  # Přečte prvních 10 znaků
print(prvnich_10_znaku)
soubor.close()

# Čtení řádek po řádku
soubor = open('priklad.txt', 'r')
radek = soubor.readline()  # Přečte první řádek
print(radek)
soubor.close()

# Čtení všech řádků do seznamu
soubor = open('priklad.txt', 'r')
radky = soubor.readlines()  # Vrátí seznam řádků
for radek in radky:
    print(radek.strip())  # strip() odstraní koncové znaky nového řádku
soubor.close()

# Efektivnější způsob iterace přes řádky
soubor = open('priklad.txt', 'r')
for radek in soubor:  # Objekty souborů jsou iterovatelné
    print(radek.strip())
soubor.close()
```

## 4. Zápis do souborů

Python poskytuje metody pro zápis dat do souborů. Můžete vytvářet nové soubory, přepisovat existující nebo do nich přidávat.

```python
# Zápis do souboru (vytvoří nebo přepíše soubor)
soubor = open('vystup.txt', 'w')
soubor.write("Ahoj, světe!\n")
soubor.write("Toto je nový řádek.")
soubor.close()

# Zápis více řádků najednou
radky = ["První řádek\n", "Druhý řádek\n", "Třetí řádek\n"]
soubor = open('vystup.txt', 'w')
soubor.writelines(radky)  # Zapíše všechny řádky najednou
soubor.close()

# Přidávání do existujícího souboru
soubor = open('vystup.txt', 'a')  # 'a' je pro režim append (přidávání)
soubor.write("\nTento text je přidán na konec.")
soubor.close()
```

## 5. Režimy souborů

Při otevírání souboru určujete režim, který určuje, jak bude soubor používán. Python nabízí několik režimů souborů pro různé operace.

```python
# Běžné režimy souborů:
# 'r' - Čtení (výchozí). Otevře soubor pro čtení.
# 'w' - Zápis. Vytvoří nový soubor nebo ořízne existující.
# 'a' - Append (přidávání). Otevře pro zápis, přidává na konec, pokud soubor existuje.
# 'x' - Exkluzivní vytvoření. Selže, pokud soubor již existuje.
# 'b' - Binární režim.
# 't' - Textový režim (výchozí).
# '+' - Otevře pro aktualizaci (čtení i zápis)

# Příklady různých režimů

# Binární režim pro netextové soubory
with open('obrazek.jpg', 'rb') as soubor:
    obrazek_data = soubor.read()
    # Zpracování binárních dat

# Režim čtení a zápisu
with open('data.txt', 'r+') as soubor:
    obsah = soubor.read()
    soubor.seek(0)  # Přesun na začátek souboru
    soubor.write("Nový obsah\n" + obsah)

# Binární režim zápisu (užitečný pro vytváření obrázkových/binárních souborů)
with open('novysoubor.bin', 'wb') as soubor:
    soubor.write(b'\x00\x01\x02\x03')  # Zápis surových bajtů
```

## 6. Práce s kontextovými manažery

Použití příkazu `with` (kontextový manažer) je doporučený způsob, jak zacházet se soubory v Pythonu. Automaticky se postará o zavření souboru, když skončíte, a to i v případě, že dojde k výjimce.

```python
# Použití kontextového manažeru pro práci se soubory
with open('priklad.txt', 'r') as soubor:
    obsah = soubor.read()
    print(obsah)
# Není třeba volat soubor.close() - je to provedeno automaticky

# Čtení a zápis s kontextovými manažery
with open('vstup.txt', 'r') as vstupni_soubor:
    with open('vystup.txt', 'w') as vystupni_soubor:
        for radek in vstupni_soubor:
            # Zpracování řádku a zápis do výstupního souboru
            vystupni_soubor.write(radek.upper())

# Kombinace více kontextových manažerů
with open('vstup.txt', 'r') as vstupni_soubor, open('vystup.txt', 'w') as vystupni_soubor:
    obsah = vstupni_soubor.read()
    vystupni_soubor.write(obsah.upper())
```

## 7. Pozice v souboru a navigace

Python poskytuje metody pro navigaci v souboru, což vám umožňuje kontrolovat, odkud čtete nebo kam zapisujete.

```python
# Získání aktuální pozice v souboru
with open('priklad.txt', 'r') as soubor:
    print(f"Aktuální pozice: {soubor.tell()}")  # Mělo by být 0
    data = soubor.read(10)
    print(f"Po přečtení 10 znaků: {soubor.tell()}")  # Mělo by být 10

# Přesun na konkrétní pozici v souboru
with open('priklad.txt', 'r') as soubor:
    soubor.seek(5)  # Přesun na 6. bajt (indexováno od 0)
    data = soubor.read(10)
    print(data)  # 10 znaků začínajících od pozice 5
    
    # seek(offset, whence) kde whence je:
    # 0: od začátku (výchozí)
    # 1: od aktuální pozice
    # 2: od konce
    
    soubor.seek(0)  # Zpět na začátek
    soubor.seek(0, 2)  # Přesun na konec souboru
    
    # Získání velikosti souboru přesunem na konec a zjištěním pozice
    soubor.seek(0, 2)
    velikost = soubor.tell()
    print(f"Velikost souboru: {velikost} bajtů")
```

## 8. Práce s různými formáty souborů

Python umí pracovat s různými formáty souborů kromě čistě textových souborů, včetně CSV, JSON a dalších.

```python
# Práce s CSV soubory
import csv

# Čtení CSV souborů
with open('data.csv', 'r', newline='') as csvfile:
    csv_reader = csv.reader(csvfile)
    for radek in csv_reader:
        print(', '.join(radek))

# Zápis CSV souborů
with open('vystup.csv', 'w', newline='') as csvfile:
    csv_writer = csv.writer(csvfile)
    csv_writer.writerow(['Jméno', 'Věk', 'Město'])
    csv_writer.writerow(['Alice', '25', 'Praha'])
    csv_writer.writerow(['Bob', '30', 'Brno'])

# Práce s JSON soubory
import json

# Čtení JSON
with open('data.json', 'r') as jsonfile:
    data = json.load(jsonfile)
    print(data)

# Zápis JSON
osoba = {
    'jmeno': 'Jan',
    'vek': 30,
    'mesto': 'Praha',
    'jazyky': ['Python', 'JavaScript', 'C++']
}

with open('osoba.json', 'w') as jsonfile:
    json.dump(osoba, jsonfile, indent=4)  # Formátování s odsazením

# Práce s pickle (pro objekty Pythonu)
import pickle

# Serializace objektů Pythonu do souboru
data = {'a': [1, 2.0, 3, 4+6j],
        'b': ('řetězec', u'Unicode řetězec'),
        'c': None}

with open('data.pickle', 'wb') as f:
    pickle.dump(data, f)

# Čtení objektů Pythonu ze souboru
with open('data.pickle', 'rb') as f:
    nactena_data = pickle.load(f)
    print(nactena_data)
```
