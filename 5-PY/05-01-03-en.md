## 1. Introduction to Strings

In Python, strings are sequences of characters enclosed in quotes. They are immutable, meaning once created, their content cannot be changed. Strings are one of the most commonly used data types for storing and manipulating text data.

```python
# A simple string
message = "Hello, Python!"
print(message)  # Output: Hello, Python!

# Check the type
print(type(message))  # Output: <class 'str'>

# Strings are immutable - this will create a new string, not modify the original
original = "Hello"
modified = original + " World"
print(original)  # Output: Hello
print(modified)  # Output: Hello World
```

## 2. String Creation and Notation

Python offers multiple ways to create strings using single quotes (`'`), double quotes (`"`), or triple quotes (`'''` or `"""`) for multi-line strings.

```python
# Different ways to create strings
single_quotes = 'Python Programming'
double_quotes = "Python Programming"

# Both are exactly the same
print(single_quotes == double_quotes)  # Output: True

# Multi-line strings using triple quotes
multi_line = """This is a multi-line string.
It spans across multiple lines.
Very useful for documentation."""
print(multi_line)

# Escape characters
with_quotes = "She said, \"Python is fun!\""
print(with_quotes)  # Output: She said, "Python is fun!"

# Raw strings (ignore escape characters)
raw_string = r"C:\Users\name\Documents"
print(raw_string)  # Output: C:\Users\name\Documents
```

## 3. String Indexing and Slicing

Python strings can be accessed by index (starting from 0), and slices allow you to extract portions of strings.

```python
text = "Python Programming"

# Indexing (accessing individual characters)
print(text[0])   # Output: P
print(text[7])   # Output: P
print(text[-1])  # Output: g (negative indices count from the end)

# Slicing (extracting portions of strings)
print(text[0:6])    # Output: Python
print(text[7:])     # Output: Programming
print(text[:6])     # Output: Python
print(text[-11:])   # Output: Programming

# Stride (step)
print(text[::2])    # Output: Pto rgamn (every 2nd character)
print(text[::-1])   # Output: gnimmargorP nohtyP (reverse the string)
```

## 4. Common String Methods

Python provides numerous built-in methods for string manipulation:

```python
text = "Python Programming"

# Case conversion
print(text.upper())      # Output: PYTHON PROGRAMMING
print(text.lower())      # Output: python programming
print(text.title())      # Output: Python Programming
print(text.capitalize()) # Output: Python programming

# Searching
print(text.find("Pro"))        # Output: 7 (index of first occurrence)
print(text.count("m"))         # Output: 2 (count occurrences)
print("Pro" in text)           # Output: True (membership test)

# Replacing
print(text.replace("Python", "Java"))  # Output: Java Programming

# Splitting and joining
words = text.split()
print(words)                          # Output: ['Python', 'Programming']
print("-".join(words))                # Output: Python-Programming

# Stripping whitespace
spaces = "   Python   "
print(spaces.strip())                 # Output: Python
print(spaces.lstrip())                # Output: Python   
print(spaces.rstrip())                # Output:    Python

# Checking string properties
print("Python123".isalnum())          # Output: True (alphanumeric)
print("Python".isalpha())             # Output: True (alphabetic)
print("123".isdigit())                # Output: True (numeric)
print("PYTHON".isupper())             # Output: True (all uppercase)
print("python".islower())             # Output: True (all lowercase)
```

## 5. String Formatting Techniques

Python provides multiple ways to format strings:

```python
name = "Alice"
age = 30

# 1. String concatenation
message = "My name is " + name + " and I am " + str(age) + " years old."
print(message)

# 2. % operator (old style)
message = "My name is %s and I am %d years old." % (name, age)
print(message)

# 3. str.format() method
message = "My name is {} and I am {} years old.".format(name, age)
print(message)
message = "My name is {0} and I am {1} years old. {0} is my name.".format(name, age)
print(message)
message = "My name is {name} and I am {age} years old.".format(name=name, age=age)
print(message)

# 4. f-strings (Python 3.6+, recommended)
message = f"My name is {name} and I am {age} years old."
print(message)
message = f"My name is {name} and I am {age * 12} months old."
print(message)

# Formatting numbers
pi = 3.14159
print(f"Pi rounded to 2 decimal places: {pi:.2f}")  # Output: Pi rounded to 2 decimal places: 3.14
```

## 6. String Concatenation and Operations

Strings can be combined and manipulated using various operators:

```python
# String concatenation with +
first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name
print(full_name)  # Output: John Doe

# String repetition with *
separator = "-" * 20
print(separator)  # Output: --------------------

# String comparison
print("apple" < "banana")  # Output: True (lexicographical comparison)
print("Apple" < "apple")   # Output: True (uppercase comes before lowercase)

# Membership operators
sentence = "Python is amazing"
print("Python" in sentence)  # Output: True
print("Java" not in sentence)  # Output: True

# String length
print(len(sentence))  # Output: 17
```

## 7. Regular Expressions for Advanced String Processing

For more complex string processing tasks, Python's `re` module provides powerful pattern matching and manipulation:

```python
import re

text = "Contact us at info@example.com or support@company.org"

# Find all email addresses
emails = re.findall(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', text)
print(emails)  # Output: ['info@example.com', 'support@company.org']

# Replace pattern
new_text = re.sub(r'(\w+)@(\w+)\.org', r'\1@\2.com', text)
print(new_text)  # Output: Contact us at info@example.com or support@company.com

# Split string by multiple delimiters
line = "name,age:30;city-New York"
parts = re.split(r'[,;:-]', line)
print(parts)  # Output: ['name', 'age', '30', 'city', 'New York']

# Check if string matches a pattern
phone = "123-456-7890"
if re.match(r'\d{3}-\d{3}-\d{4}', phone):
    print("Valid phone number format")
```

## 8. Practical String Manipulation Examples

Let's look at some real-world examples of string manipulation:

```python
# Example 1: Cleaning user input
user_input = "   John DOE  "
cleaned = user_input.strip().title()
print(cleaned)  # Output: John Doe

# Example 2: Extracting domain from email
email = "user@example.com"
domain = email.split('@')[1]
print(domain)  # Output: example.com

# Example 3: Converting snake_case to camelCase
variable_name = "user_first_name"
parts = variable_name.split('_')
camel_case = parts[0] + ''.join(part.title() for part in parts[1:])
print(camel_case)  # Output: userFirstName

# Example 4: Password validation
def validate_password(password):
    has_upper = any(c.isupper() for c in password)
    has_lower = any(c.islower() for c in password)
    has_digit = any(c.isdigit() for c in password)
    has_special = any(not c.isalnum() for c in password)
    is_long_enough = len(password) >= 8
    
    return has_upper and has_lower and has_digit and has_special and is_long_enough

print(validate_password("Abc123!@"))  # Output: True
print(validate_password("password"))  # Output: False

# Example 5: Creating a simple text analyzer
def analyze_text(text):
    character_count = len(text)
    word_count = len(text.split())
    line_count = len(text.split('\n'))
    
    return {
        "characters": character_count,
        "words": word_count,
        "lines": line_count
    }

sample = """Python is a programming language.
It is easy to learn and use.
Python is widely used in data science."""

analysis = analyze_text(sample)
print(analysis)
# Output: {'characters': 94, 'words': 18, 'lines': 3}
```
