## 1. Úvod do jednotkového testování

Jednotkové testování je praxe testování jednotlivých komponent nebo jednotek kódu izolovaně, aby se zajistilo, že fungují podle očekávání. V Pythonu jednotkové testy pomáhají ověřit, že funkce, třídy a moduly se chovají správně, což činí údržbu a refaktorování bezpečnějším.

Výhody jednotkového testování zahrnují:
- Včasné odhalení chyb
- Dokumentace chování kódu
- Bezpečnější refaktorování
- Zlepšení návrhu kódu
- Ochrana proti regresi

Vytvořme jednoduchou funkci k otestování:

```python
# sample_code.py
def add(a, b):
    """Sečte dvě čísla a vrátí výsledek."""
    return a + b

def subtract(a, b):
    """Odečte b od a a vrátí výsledek."""
    return a - b

def multiply(a, b):
    """Vynásobí dvě čísla a vrátí výsledek."""
    return a * b

def divide(a, b):
    """Vydělí a číslem b a vrátí výsledek.
    
    Raises:
        ValueError: Pokud je b rovno 0.
    """
    if b == 0:
        raise ValueError("Nelze dělit nulou")
    return a / b
```

## 2. Testování s unittest

Vestavěný modul `unittest` v Pythonu poskytuje framework pro organizaci a spouštění testů. Je inspirován Javovským JUnit a používá objektově orientovaný přístup.

### Základní struktura unittest

```python
# test_calculator_unittest.py
import unittest
from sample_code import add, subtract, multiply, divide

class TestCalculator(unittest.TestCase):
    
    def test_add(self):
        self.assertEqual(add(3, 5), 8)
        self.assertEqual(add(-1, 1), 0)
        self.assertEqual(add(-1, -1), -2)
        
    def test_subtract(self):
        self.assertEqual(subtract(5, 3), 2)
        self.assertEqual(subtract(1, 1), 0)
        self.assertEqual(subtract(-1, -1), 0)
        
    def test_multiply(self):
        self.assertEqual(multiply(3, 5), 15)
        self.assertEqual(multiply(-1, 1), -1)
        self.assertEqual(multiply(-1, -1), 1)
        
    def test_divide(self):
        self.assertEqual(divide(10, 2), 5)
        self.assertEqual(divide(-10, 2), -5)
        self.assertEqual(divide(5, 2), 2.5)
        
    def test_divide_by_zero(self):
        with self.assertRaises(ValueError):
            divide(10, 0)
            
if __name__ == "__main__":
    unittest.main()
```

### Spouštění unittest

Unittest lze spouštět několika způsoby:

```bash
# Přímé spuštění
python test_calculator_unittest.py

# Spuštění s modulem unittest
python -m unittest test_calculator_unittest.py

# Spuštění s vyhledáváním testů
python -m unittest discover
```

### Běžné unittest tvrzení (assertions)

```python
# Běžná tvrzení
self.assertEqual(a, b)       # a == b
self.assertNotEqual(a, b)    # a != b
self.assertTrue(x)           # bool(x) je True
self.assertFalse(x)          # bool(x) je False
self.assertIs(a, b)          # a is b
self.assertIsNot(a, b)       # a is not b
self.assertIsNone(x)         # x is None
self.assertIsNotNone(x)      # x is not None
self.assertIn(a, b)          # a in b
self.assertNotIn(a, b)       # a not in b
self.assertIsInstance(a, b)  # isinstance(a, b)
self.assertRaises(exc, func, *args, **kwargs)  # func(*args, **kwargs) vyvolá exc
```

## 3. Testování s pytest

`pytest` je modernější testovací framework, který nabízí jednodušší syntaxi, silné přípravky (fixtures) a rozsáhlé pluginy.

### Instalace

```bash
pip install pytest
```

### Základní struktura pytest

```python
# test_calculator_pytest.py
import pytest
from sample_code import add, subtract, multiply, divide

def test_add():
    assert add(3, 5) == 8
    assert add(-1, 1) == 0
    assert add(-1, -1) == -2
    
def test_subtract():
    assert subtract(5, 3) == 2
    assert subtract(1, 1) == 0
    assert subtract(-1, -1) == 0
    
def test_multiply():
    assert multiply(3, 5) == 15
    assert multiply(-1, 1) == -1
    assert multiply(-1, -1) == 1
    
def test_divide():
    assert divide(10, 2) == 5
    assert divide(-10, 2) == -5
    assert divide(5, 2) == 2.5
    
def test_divide_by_zero():
    with pytest.raises(ValueError):
        divide(10, 0)
```

### Spouštění pytest

```bash
# Spuštění všech testů v aktuálním adresáři
pytest

# Spuštění konkrétního testovacího souboru
pytest test_calculator_pytest.py

# Spuštění s podrobným výstupem
pytest -v

# Spuštění testů odpovídajících vzoru
pytest -k "add or divide"
```

## 4. Testovací přípravky a nastavení

Testovací přípravky (fixtures) poskytují způsob, jak nastavit a uklidit zdroje potřebné pro testy.

### unittest přípravky

```python
# unittest přípravky
import unittest
from sample_code import add, subtract

class TestWithFixtures(unittest.TestCase):
    
    def setUp(self):
        # Volá se před každým testem
        print("Nastavuji testovací data")
        self.values = [1, 2, 3]
        self.expected_sum = 6
        
    def tearDown(self):
        # Volá se po každém testu
        print("Úklid")
        self.values = None
        
    def test_sum(self):
        result = 0
        for val in self.values:
            result = add(result, val)
        self.assertEqual(result, self.expected_sum)
        
    @classmethod
    def setUpClass(cls):
        # Volá se jednou před všemi testy
        print("Nastavuji třídu")
        
    @classmethod
    def tearDownClass(cls):
        # Volá se jednou po všech testech
        print("Ukončuji třídu")
```

### pytest přípravky

```python
# pytest přípravky
import pytest

@pytest.fixture
def values():
    print("Nastavuji testovací data")
    values = [1, 2, 3]
    yield values
    print("Úklid")
    
def test_sum_with_fixture(values):
    from sample_code import add
    result = 0
    for val in values:
        result = add(result, val)
    assert result == 6
    
# Sdílení přípravků mezi více testy
@pytest.fixture(scope="module")
def complex_data():
    print("Nastavuji komplexní data")
    data = {"numbers": [1, 2, 3, 4, 5], "expected_sum": 15}
    yield data
    print("Ukončuji komplexní data")
    
def test_complex_sum(complex_data):
    from sample_code import add
    result = 0
    for val in complex_data["numbers"]:
        result = add(result, val)
    assert result == complex_data["expected_sum"]
```

## 5. Mockování a patchování

Mockování umožňuje nahradit části vašeho systému mockovanými objekty, aby byl testovaný kód izolován.

### unittest.mock

```python
# service.py
import requests

def get_user_data(user_id):
    response = requests.get(f"https://api.example.com/users/{user_id}")
    if response.status_code == 200:
        return response.json()
    else:
        return None

def get_user_name(user_id):
    data = get_user_data(user_id)
    if data:
        return data.get("name")
    return "Unknown"
```

```python
# test_service_unittest.py
import unittest
from unittest.mock import patch, MagicMock
from service import get_user_name, get_user_data

class TestService(unittest.TestCase):
    
    @patch('service.requests.get')
    def test_get_user_data(self, mock_get):
        # Konfigurování mocku
        mock_response = MagicMock()
        mock_response.status_code = 200
        mock_response.json.return_value = {"id": 1, "name": "Jan Novák"}
        mock_get.return_value = mock_response
        
        # Volání funkce
        result = get_user_data(1)
        
        # Tvrzení
        mock_get.assert_called_once_with("https://api.example.com/users/1")
        self.assertEqual(result, {"id": 1, "name": "Jan Novák"})
        
    @patch('service.get_user_data')
    def test_get_user_name(self, mock_get_user_data):
        # Konfigurování mocku
        mock_get_user_data.return_value = {"id": 1, "name": "Jan Novák"}
        
        # Volání funkce
        result = get_user_name(1)
        
        # Tvrzení
        self.assertEqual(result, "Jan Novák")
        mock_get_user_data.assert_called_once_with(1)
        
    @patch('service.get_user_data')
    def test_get_user_name_unknown(self, mock_get_user_data):
        # Konfigurování mocku
        mock_get_user_data.return_value = None
        
        # Volání funkce
        result = get_user_name(1)
        
        # Tvrzení
        self.assertEqual(result, "Unknown")
```

### pytest mockování

```python
# test_service_pytest.py
import pytest
from unittest.mock import patch, MagicMock
from service import get_user_name, get_user_data

def test_get_user_data():
    with patch('service.requests.get') as mock_get:
        # Konfigurování mocku
        mock_response = MagicMock()
        mock_response.status_code = 200
        mock_response.json.return_value = {"id": 1, "name": "Jan Novák"}
        mock_get.return_value = mock_response
        
        # Volání funkce
        result = get_user_data(1)
        
        # Tvrzení
        mock_get.assert_called_once_with("https://api.example.com/users/1")
        assert result == {"id": 1, "name": "Jan Novák"}

def test_get_user_name(mocker):
    # Použití pytest-mock pluginu
    mock_get_user_data = mocker.patch('service.get_user_data')
    mock_get_user_data.return_value = {"id": 1, "name": "Jan Novák"}
    
    result = get_user_name(1)
    
    assert result == "Jan Novák"
    mock_get_user_data.assert_called_once_with(1)
```

## 6. Parametrizované testování

Parametrizované testování umožňuje spustit stejný test s různými vstupy.

### unittest parametrizované testy

```python
# test_parameterized_unittest.py
import unittest
from sample_code import add

class TestParameterized(unittest.TestCase):
    
    def test_add(self):
        test_cases = [
            (1, 2, 3),
            (5, 3, 8),
            (-1, 1, 0),
            (0, 0, 0)
        ]
        
        for a, b, expected in test_cases:
            with self.subTest(a=a, b=b, expected=expected):
                self.assertEqual(add(a, b), expected)
```

### pytest parametrizované testy

```python
# test_parameterized_pytest.py
import pytest
from sample_code import add, divide

@pytest.mark.parametrize("a, b, expected", [
    (1, 2, 3),
    (5, 3, 8),
    (-1, 1, 0),
    (0, 0, 0)
])
def test_add_parameterized(a, b, expected):
    assert add(a, b) == expected

# Více parametrů
@pytest.mark.parametrize("a", [1, 2, 3])
@pytest.mark.parametrize("b", [10, 20])
def test_multiply_combinations(a, b):
    from sample_code import multiply
    result = multiply(a, b)
    assert result == a * b
    
# Parametrizovaný přípravek
@pytest.fixture(params=[1, 2, 3, 4, 5])
def input_value(request):
    return request.param

def test_with_parameterized_fixture(input_value):
    assert input_value < 10
```

## 8. Nejlepší praktiky

Zde jsou některé nejlepší praktiky pro psaní efektivních jednotkových testů:

### Struktura testu

```python
# Dodržujte vzor AAA: Arrange (Příprava), Act (Akce), Assert (Tvrzení)
def test_add_follows_aaa_pattern():
    # Příprava
    a, b = 3, 5
    expected = 8
    
    # Akce
    result = add(a, b)
    
    # Tvrzení
    assert result == expected
```

### Testovací zásady

1. **Udržujte testy jednoduché a zaměřené**: Testujte jednu věc v každé testovací funkci
2. **Používejte popisné názvy testů**: Ujasněte, co každý test kontroluje
3. **Izolujte testy**: Testy by neměly záviset jeden na druhém
4. **Používejte přípravky pro běžné nastavení**: Vyhněte se duplikaci nastavovacího kódu
5. **Testujte chybové případy**: Zajistěte, aby byly chyby správně zpracovány
6. **Efektivně používejte tvrzení**: Vyberte správné tvrzení pro každý případ
7. **Vyhněte se testování implementačních detailů**: Zaměřte se na chování, ne na interní implementaci
8. **Udržujte vysoké pokrytí**: Snažte se o vysoké testovací pokrytí
9. **Nezávislost testů**: Testy by měly běžet v jakémkoli pořadí
10. **Pište deterministické testy**: Testy by měly vždy dávat stejný výsledek

## 9. Shrnutí

Jednotkové testování je klíčovou praktikou ve vývoji softwaru, která pomáhá zajistit kvalitu a spolehlivost kódu. Python poskytuje dva hlavní frameworky pro jednotkové testování:

1. **unittest** - Vestavěný testovací framework s objektově orientovaným přístupem:
   - Používá testovací třídy, které dědí z `unittest.TestCase`
   - Poskytuje různé metody pro tvrzení
   - Zahrnuje vyhledávání testů a testovací spouštěče

2. **pytest** - Modernější a funkcemi bohatší testovací framework:
   - Jednodušší syntaxe s běžnými funkcemi a tvrzeními
   - Silné přípravky pro nastavení a úklid
   - Rozsáhlý ekosystém pluginů
   - Podpora parametrizovaného testování
   - Lepší reportování a výstup

Klíčové testovací koncepty:
- Testovací přípravky pro nastavení a úklid
- Mockování k izolaci testovaného kódu
- Parametrizované testy pro testování více scénářů
- Testovací pokrytí pro zajištění důkladného testování
- Nejlepší praktiky pro psaní udržovatelných testů

Začleněním jednotkového testování do vašeho vývojového procesu můžete včas odhalit chyby, dokumentovat očekávané chování a budovat spolehlivější software. Ať už si vyberete unittest nebo pytest (nebo kombinaci obou), důležité je psát testy důsledně a učinit testování nedílnou součástí vašeho vývojového procesu.
