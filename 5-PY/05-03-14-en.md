## 1. Introduction to Performance Profiling

Performance profiling is the process of measuring and analyzing your code's execution to identify bottlenecks and inefficiencies. Optimization is the application of techniques to make your code run faster or use fewer resources.

Before optimizing code, it's crucial to:
1. Make sure it works correctly
2. Establish a baseline performance
3. Identify the actual bottlenecks
4. Follow the principle: "Premature optimization is the root of all evil"

```python
# Don't optimize blindly - always measure first!
# Common areas to investigate:
# - CPU-bound bottlenecks (slow computations)
# - Memory-bound bottlenecks (excessive memory usage)
# - I/O-bound bottlenecks (disk or network operations)
```

## 2. Basic Timing and Benchmarking Techniques

The simplest way to measure performance is using Python's built-in `time` module or the `timeit` module for more accurate benchmarking.

```python
import time

# Simple timing with time.time()
def simple_timing():
    start_time = time.time()
    
    # Code to be timed
    total = 0
    for i in range(1000000):
        total += i
    
    end_time = time.time()
    execution_time = end_time - start_time
    print(f"Execution time: {execution_time:.6f} seconds")

simple_timing()

# More accurate benchmarking with timeit
import timeit

def function_to_benchmark():
    total = 0
    for i in range(10000):
        total += i
    return total

# Run the function 1000 times and calculate the average execution time
execution_time = timeit.timeit(function_to_benchmark, number=1000)
print(f"Average execution time: {execution_time/1000:.8f} seconds")

# Timing code snippets with timeit
list_creation_time = timeit.timeit('[i for i in range(10000)]', number=1000)
print(f"List comprehension: {list_creation_time/1000:.8f} seconds")

generator_time = timeit.timeit('list(i for i in range(10000))', number=1000)
print(f"Generator expression: {generator_time/1000:.8f} seconds")
```

## 3. Profiling with cProfile and pstats

Python's standard library includes the powerful `cProfile` module which provides detailed information about function calls.

```python
import cProfile
import pstats
import io

def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

def calculate_fibonacci_sequence(length):
    return [fibonacci(i) for i in range(length)]

# Run the profiler
profile = cProfile.Profile()
profile.enable()

# Run the function you want to profile
calculate_fibonacci_sequence(30)

profile.disable()

# Print simple stats directly
profile.print_stats(sort='cumulative')

# For more control, use pstats
s = io.StringIO()
ps = pstats.Stats(profile, stream=s).sort_stats('cumulative')
ps.print_stats(10)  # Print top 10 functions
print(s.getvalue())

# Save profiling results to a file for later analysis
ps.dump_stats('fibonacci_profile.prof')

# You can visualize the results with tools like snakeviz:
# pip install snakeviz
# snakeviz fibonacci_profile.prof
```

## 5. Memory Profiling

Memory usage is as important as execution time. The `memory_profiler` package helps track memory consumption.

```python
# Install memory_profiler:
# pip install memory_profiler

from memory_profiler import profile as memory_profile

@memory_profile
def memory_inefficient():
    # Creating a large list
    large_list = [i for i in range(10000000)]
    return sum(large_list)

@memory_profile
def memory_efficient():
    # Using a generator instead
    return sum(i for i in range(10000000))

print("Memory inefficient approach:")
memory_inefficient()

print("\nMemory efficient approach:")
memory_efficient()
```

## 6. Algorithmic Optimization

Often the biggest performance gains come from choosing better algorithms with lower computational complexity.

```python
import time
import random

# O(n²) approach to find duplicates
def find_duplicates_quadratic(nums):
    duplicates = []
    n = len(nums)
    for i in range(n):
        for j in range(i+1, n):
            if nums[i] == nums[j] and nums[i] not in duplicates:
                duplicates.append(nums[i])
    return duplicates

# O(n) approach using a set
def find_duplicates_linear(nums):
    seen = set()
    duplicates = set()
    for num in nums:
        if num in seen:
            duplicates.add(num)
        else:
            seen.add(num)
    return list(duplicates)

# Test with a large list
test_data = [random.randint(1, 1000) for _ in range(10000)]

# Time the quadratic approach
start = time.time()
find_duplicates_quadratic(test_data)
end = time.time()
print(f"Quadratic approach: {end - start:.4f} seconds")

# Time the linear approach
start = time.time()
find_duplicates_linear(test_data)
end = time.time()
print(f"Linear approach: {end - start:.4f} seconds")
```

## 7. Code Optimization Techniques

Even without changing algorithms, there are many Python-specific optimizations you can apply.

```python
# 1. Use appropriate data structures
import timeit

# List lookup is O(n)
def list_lookup():
    my_list = list(range(10000))
    return 9999 in my_list

# Set lookup is O(1)
def set_lookup():
    my_set = set(range(10000))
    return 9999 in my_set

print(f"List lookup: {timeit.timeit(list_lookup, number=1000):.6f} seconds")
print(f"Set lookup: {timeit.timeit(set_lookup, number=1000):.6f} seconds")

# 2. Avoid creating unnecessary variables
def unnecessary_vars(n):
    result = []
    for i in range(n):
        temp = i * 2  # Unnecessary variable
        result.append(temp)
    return result

def direct_calculation(n):
    result = []
    for i in range(n):
        result.append(i * 2)
    return result

# 3. Use built-in functions and methods
def manual_sum(numbers):
    total = 0
    for num in numbers:
        total += num
    return total

def builtin_sum(numbers):
    return sum(numbers)

# 4. Local variable access is faster than global
global_var = 100

def use_global():
    for i in range(10000):
        result = global_var * i

def use_local():
    local_var = 100
    for i in range(10000):
        result = local_var * i
```

## 8. Vectorization with NumPy

For numerical operations, NumPy's vectorized operations are much faster than Python loops.

```python
import numpy as np
import time

# Python loops (slow)
def python_sum_of_squares(n):
    result = 0
    for i in range(n):
        result += i ** 2
    return result

# NumPy vectorization (fast)
def numpy_sum_of_squares(n):
    return np.sum(np.arange(n) ** 2)

n = 10000000
# Measure Python version
start = time.time()
python_result = python_sum_of_squares(n)
python_time = time.time() - start

# Measure NumPy version
start = time.time()
numpy_result = numpy_sum_of_squares(n)
numpy_time = time.time() - start

print(f"Python time: {python_time:.4f} seconds")
print(f"NumPy time: {numpy_time:.4f} seconds")
print(f"Speed improvement: {python_time/numpy_time:.1f}x")
```

## 9. Parallel Processing for Performance

When dealing with CPU-bound operations, you can use Python's `multiprocessing` or `concurrent.futures` to leverage multiple cores.

```python
import time
from concurrent.futures import ProcessPoolExecutor
import multiprocessing as mp

def cpu_heavy_task(n):
    """A CPU-intensive function to calculate sum of squares."""
    return sum(i*i for i in range(n))

# Serial execution
def run_serial(numbers):
    start = time.time()
    results = [cpu_heavy_task(n) for n in numbers]
    end = time.time()
    print(f"Serial execution time: {end - start:.2f} seconds")
    return results

# Parallel execution with concurrent.futures
def run_parallel_futures(numbers):
    start = time.time()
    with ProcessPoolExecutor() as executor:
        results = list(executor.map(cpu_heavy_task, numbers))
    end = time.time()
    print(f"Parallel execution time (concurrent.futures): {end - start:.2f} seconds")
    return results

# Parallel execution with multiprocessing
def run_parallel_mp(numbers):
    start = time.time()
    with mp.Pool() as pool:
        results = pool.map(cpu_heavy_task, numbers)
    end = time.time()
    print(f"Parallel execution time (multiprocessing): {end - start:.2f} seconds")
    return results

if __name__ == "__main__":
    # Generate some tasks to run
    tasks = [20000000 + i * 1000 for i in range(8)]
    
    # Run serially
    serial_results = run_serial(tasks)
    
    # Run with concurrent.futures
    futures_results = run_parallel_futures(tasks)
    
    # Run with multiprocessing
    mp_results = run_parallel_mp(tasks)
    
    # Verify all approaches give the same results
    print(f"Results match: {serial_results == futures_results == list(mp_results)}")
```

## 10. Summary

Performance profiling and optimization in Python involves:

1. **Measuring First**: Always establish a baseline and identify actual bottlenecks before optimizing.

2. **Profiling Tools**: Use built-in tools like `timeit` and `cProfile` or third-party tools like `line_profiler` and `memory_profiler` to identify issues.

3. **Algorithmic Improvements**: Choose efficient algorithms with lower computational complexity (O(n) vs O(n²)).

4. **Code-Level Optimizations**: Use appropriate data structures, avoid unnecessary operations, leverage built-in functions, and optimize variable access.

5. **Vectorization**: Use NumPy for numerical operations to achieve significant speedups.

6. **Parallelization**: Use `multiprocessing` or `concurrent.futures` to distribute work across multiple cores for CPU-bound tasks.

Remember the optimization mantra:
1. Make it work
2. Make it right
3. Make it fast - but only after profiling

The most effective optimizations address the specific bottlenecks in your application, rather than prematurely optimizing code that isn't performance-critical. Always ensure that your optimizations don't compromise code readability and maintainability without significant performance benefits.
