## 1. Introduction to Control Flow

Control flow allows your program to make decisions based on conditions, executing different code blocks depending on whether certain conditions are true or false. In Python, control flow is primarily managed with if, elif (else if), and else statements.

```python
# Basic structure of control flow
if condition:
    # Code executed if condition is True
    pass
elif another_condition:
    # Code executed if condition is False and another_condition is True
    pass
else:
    # Code executed if all conditions above are False
    pass
```

## 2. Simple if Statements

The simplest form of control flow is the if statement, which executes a block of code only if a condition evaluates to True.

```python
# Simple if statement
age = 18

if age >= 18:
    print("You are an adult.")

# Output: You are an adult.

# Multiple conditions
temperature = 28
is_sunny = True

if temperature > 25:
    print("It's a warm day.")
    
if is_sunny:
    print("Don't forget sunscreen!")

# Output:
# It's a warm day.
# Don't forget sunscreen!
```

When an if statement condition is False, its code block is skipped:

```python
age = 15

if age >= 18:
    print("You are an adult.")  # This won't execute
    
print("Program continues...")

# Output: Program continues...
```

## 3. If-else Statements

The if-else statement provides alternative execution paths for when a condition is False.

```python
# If-else statement
age = 15

if age >= 18:
    print("You can vote.")
else:
    print("You cannot vote yet.")
    
# Output: You cannot vote yet.

# Practical example
score = 75

if score >= 60:
    print("Passed!")
else:
    print("Failed.")
    
# Output: Passed!
```

## 4. If-elif-else Chains

When you need to check multiple conditions, you can use if followed by one or more elif (else if) clauses, with an optional else clause at the end.

```python
# If-elif-else chain
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
    
print(f"Your grade is: {grade}")
# Output: Your grade is: B

# Example with multiple conditions
weather = "cloudy"
temperature = 15

if weather == "rainy":
    print("Bring an umbrella.")
elif weather == "sunny" and temperature > 25:
    print("Bring sunglasses and sunscreen.")
elif weather == "sunny":
    print("Bring sunglasses.")
elif weather == "cloudy" and temperature < 10:
    print("Bring a jacket.")
else:
    print("No special items needed.")
    
# Output: No special items needed.
```

Important: Python checks conditions in order and executes the first block whose condition is True.

## 5. Nested Conditional Statements

You can nest if statements inside other if statements to create more complex decision trees.

```python
# Nested if statements
age = 25
has_license = True

if age >= 18:
    print("Age requirement met.")
    
    if has_license:
        print("You can drive.")
    else:
        print("You need to get a license first.")
else:
    print("You are too young to drive.")
    
# Output:
# Age requirement met.
# You can drive.

# Another example
income = 60000
years_employed = 2
credit_score = 720

if income >= 50000:
    if years_employed >= 3:
        print("Loan approved based on income and employment.")
    elif credit_score >= 700:
        print("Loan approved based on income and credit score.")
    else:
        print("Income sufficient, but need better employment history or credit score.")
else:
    print("Income requirements not met.")
    
# Output: Loan approved based on income and credit score.
```

## 6. Logical Operators in Conditions

Python provides logical operators (`and`, `or`, `not`) to combine or invert conditions.

```python
# Using logical AND
age = 25
income = 50000

if age >= 18 and income >= 30000:
    print("Eligible for credit card.")
else:
    print("Not eligible for credit card.")
    
# Output: Eligible for credit card.

# Using logical OR
has_cash = False
has_credit_card = True

if has_cash or has_credit_card:
    print("You can make the purchase.")
else:
    print("You cannot make the purchase.")
    
# Output: You can make the purchase.

# Using logical NOT
is_weekend = False

if not is_weekend:
    print("It's a workday.")
else:
    print("It's the weekend.")
    
# Output: It's a workday.

# Combining multiple logical operators
age = 22
is_student = True
has_discount_card = False

if (age < 25 and is_student) or has_discount_card:
    print("Discount applied!")
else:
    print("No discount available.")
    
# Output: Discount applied!
```

## 7. Conditional Expressions (Ternary Operator)

Python offers a compact way to write simple if-else statements using conditional expressions, also known as the ternary operator.

```python
# Standard if-else
age = 20

if age >= 18:
    status = "adult"
else:
    status = "minor"
    
print(status)  # Output: adult

# Equivalent ternary operator
age = 20
status = "adult" if age >= 18 else "minor"
print(status)  # Output: adult

# Another example
score = 75
result = "pass" if score >= 60 else "fail"
print(result)  # Output: pass

# Can be used in expressions
price = 100
discount = 15
final_price = price - (discount if price > 50 else 0)
print(final_price)  # Output: 85
```

## 8. Common Patterns and Best Practices

Here are some common patterns and best practices for control flow in Python:

```python
# Truth value testing - empty sequences evaluate to False
names = []

if names:
    print("The list has some names.")
else:
    print("The list is empty.")
    
# Output: The list is empty.

# Don't compare explicitly with True/False
is_valid = True

# Not recommended
if is_valid == True:
    print("Valid")
    
# Recommended
if is_valid:
    print("Valid")
    
# Membership testing with 'in'
fruits = ["apple", "banana", "cherry"]
if "banana" in fruits:
    print("We have bananas!")
    
# Output: We have bananas!

# Handling multiple conditions with a list
user_role = "editor"
allowed_roles = ["admin", "editor", "manager"]

if user_role in allowed_roles:
    print("Access granted.")
else:
    print("Access denied.")
    
# Output: Access granted.

# Guard clauses for early returns (better than deep nesting)
def process_payment(amount, account_balance, is_verified):
    # Return early for error conditions
    if amount <= 0:
        return "Invalid amount"
    
    if amount > account_balance:
        return "Insufficient funds"
        
    if not is_verified:
        return "Account not verified"
    
    # Process the payment
    return "Payment processed successfully"

print(process_payment(100, 500, True))  # Output: Payment processed successfully
print(process_payment(-50, 500, True))  # Output: Invalid amount
```
