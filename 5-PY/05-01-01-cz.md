## 1. Úvod do instalace Pythonu

Python je všestranný programovací jazyk známý svou jednoduchostí a čitelností. Instalace Pythonu je prvním krokem na vaší programovací cestě. Tato příručka pokrývá vše, co potřebujete vědět pro nastavení kompletního vývojového prostředí Python.

Před instalací Pythonu je důležité porozumět těmto faktům:
- Python je dostupný pro všechny hlavní operační systémy (Windows, macOS, Linux)
- Existuje více verzí Pythonu (2.x a 3.x)
- Python 3 je aktuálně doporučovaná verze (Python 2 dosáhl konce životnosti v roce 2020)

## 2. Instalace Pythonu na různých operačních systémech

### Windows

1. Stáhněte instalační program z [python.org](https://www.python.org/downloads/)
2. Spusťte instalační program a zaškrtněte "Add Python to PATH"
3. Klikněte na "Install Now" pro standardní instalaci

```bash
# Ověření instalace v příkazovém řádku
python --version
```

### macOS

macOS přichází s předinstalovaným Pythonem, ale obvykle jde o starší verzi. Pro instalaci nejnovější verze:

1. Použijte Homebrew (doporučeno):

```bash
# Instalace Homebrew, pokud ještě není nainstalován
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Instalace Pythonu
brew install python
```

2. Nebo stáhněte instalační program z Python.org

```bash
# Ověření instalace
python3 --version
```

### Linux

Většina distribucí Linuxu přichází s předinstalovaným Pythonem. Pro instalaci nejnovější verze:

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# Fedora
sudo dnf install python3 python3-pip

# Arch Linux
sudo pacman -S python python-pip
```

## 3. Porozumění verzím Pythonu

Python má dvě hlavní verze: Python 2 a Python 3. Python 3 je aktuální verze a je doporučován pro všechny nové projekty.

Pro kontrolu vaší verze Pythonu:

```python
import sys
print(sys.version)
```

Klíčové rozdíly:
- Python 3 opravuje mnoho nekonzistencí v Pythonu 2
- Print je funkce v Pythonu 3: `print("Hello")` vs `print "Hello"` v Pythonu 2
- Unicode řetězce jsou výchozí v Pythonu 3
- Celočíselné dělení vrací float v Pythonu 3: `1/2` vrací `0.5` v Pythonu 3, ale `0` v Pythonu 2

## 4. Nastavení proměnných prostředí PATH

Proměnná prostředí PATH umožňuje spouštět Python z jakéhokoliv umístění v příkazovém řádku nebo terminálu.

### Windows

Pokud jste během instalace zaškrtli "Add Python to PATH", je to již nastaveno. Jinak:

1. Vyhledejte "Environment Variables" ve vyhledávání Windows
2. Klikněte na "Edit the system environment variables"
3. Klikněte na "Environment Variables"
4. V "System variables" najděte "Path" a klikněte na "Edit"
5. Klikněte na "New" a přidejte instalační cesty Pythonu:
   - `C:\Python39\`
   - `C:\Python39\Scripts\`

### macOS/Linux

Přidejte do souboru `.bashrc`, `.zshrc` nebo ekvivalentního:

```bash
# Pro macOS při instalaci přes Homebrew
export PATH="/usr/local/opt/python/libexec/bin:$PATH"

# Pro Linux nebo přímou instalaci
export PATH="$HOME/.local/bin:$PATH"
```

## 5. Správa balíčků pomocí pip

`pip` je instalační program balíčků pro Python, který vám umožňuje instalovat a spravovat další knihovny.

```bash
# Instalace balíčku
pip install numpy

# Instalace konkrétní verze
pip install numpy==1.21.0

# Aktualizace balíčku
pip install --upgrade numpy

# Seznam nainstalovaných balíčků
pip list

# Instalace balíčků z requirements.txt
pip install -r requirements.txt
```

Vytvoření souboru requirements.txt:

```bash
# Vygenerování souboru požadavků z aktuálního prostředí
pip freeze > requirements.txt
```

Příklad souboru requirements.txt:
```
numpy==1.21.0
pandas==1.3.0
matplotlib==3.4.2
```

## 6. Virtuální prostředí

Virtuální prostředí vám umožňují vytvářet izolovaná prostředí Pythonu pro různé projekty, čímž se vyhnete konfliktům balíčků.

### Použití venv (vestavěný)

```bash
# Vytvoření virtuálního prostředí
python -m venv myenv

# Aktivace prostředí
# Windows
myenv\Scripts\activate

# macOS/Linux
source myenv/bin/activate

# Instalace balíčků v aktivovaném prostředí
pip install numpy pandas

# Deaktivace po dokončení
deactivate
```

### Použití conda (Anaconda/Miniconda)

```bash
# Nejprve nainstalujte Anaconda nebo Miniconda

# Vytvoření prostředí conda
conda create --name myenv python=3.9

# Aktivace prostředí
conda activate myenv

# Instalace balíčků
conda install numpy pandas

# Deaktivace
conda deactivate
```

## 7. Integrovaná vývojová prostředí (IDE)

Populární Python IDE a editory kódu:

1. **Visual Studio Code**
   - Zdarma, lehký, rozsáhlá podpora pluginů
   - Nainstalujte rozšíření Python pro plnou funkčnost

2. **PyCharm**
   - Profesionální IDE s komplexními funkcemi
   - Dostupné verze Community (zdarma) a Professional (placená)

3. **Jupyter Notebook/Lab**
   - Interaktivní prostředí založené na prohlížeči
   - Skvělé pro datovou vědu a explorační práci

```bash
# Instalace Jupyter
pip install jupyter

# Spuštění Jupyter Notebook
jupyter notebook
```

4. **IDLE**
   - Dodáváno s Pythonem
   - Jednoduché rozhraní pro začátečníky

## 8. Hello World: Váš první Python program

Nyní, když je vaše prostředí nastaveno, vytvořme váš první Python program:

1. Otevřete váš oblíbený editor
2. Vytvořte soubor s názvem `hello.py`
3. Přidejte následující kód:

```python
# Toto je komentář
print("Hello, World!")

# Proměnné
name = "Python Programmer"
print(f"Hello, {name}!")

# Jednoduchá funkce
def greet(name):
    return f"Vítej v Pythonu, {name}!"
    
# Volání funkce
message = greet("Nový student")
print(message)
```

4. Spusťte program:

```bash
# V terminálu/příkazovém řádku
python hello.py
```

Výstup:
```
Hello, World!
Hello, Python Programmer!
Vítej v Pythonu, Nový student!
```

## 9. Shrnutí

Nastavení vašeho Python prostředí zahrnuje:

- Instalaci Pythonu vhodného pro váš operační systém
- Porozumění rozdílům mezi verzemi Pythonu
- Konfiguraci proměnných prostředí PATH pro přístup z příkazové řádky
- Používání pip pro správu balíčků a závislostí
- Vytváření virtuálních prostředí pro izolaci projektů
- Výběr IDE nebo editoru kódu, který vyhovuje vašim potřebám
- Psaní a spouštění základního Python kódu

S řádně nastaveným prostředím jste připraveni ponořit se hlouběji do programování v Pythonu. Další kroky jsou naučit se o proměnných, datových typech a základních operacích, které tvoří základ vaší cesty s Pythonem.
