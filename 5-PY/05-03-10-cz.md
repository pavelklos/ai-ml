## 1. Úvod do pokročilých dekorátorů

Dekorátory jsou mocnou funkcí v Pythonu, která umožňuje upravit nebo rozšířit chování funkcí nebo metod bez změny jejich zdrojového kódu. Základní dekorátory jsou funkce, které přijímají jinou funkci jako argument a vracejí novou funkci, která obvykle rozšiřuje chování původní funkce.

```python
# Přehled základního dekorátoru
def simple_decorator(func):
    def wrapper(*args, **kwargs):
        print("Něco se děje před voláním funkce.")
        result = func(*args, **kwargs)
        print("Něco se děje po volání funkce.")
        return result
    return wrapper

@simple_decorator
def say_hello(name):
    print(f"Ahoj, {name}!")

# Použití dekorované funkce
say_hello("Alice")
# Výstup:
# Něco se děje před voláním funkce.
# Ahoj, Alice!
# Něco se děje po volání funkce.
```

Pokročilé dekorátory rozšiřují tento koncept přidáním parametrů k samotným dekorátorům nebo jejich implementací jako tříd místo funkcí, což umožňuje složitější a znovupoužitelné modifikace chování.

## 2. Parametrizované dekorátory

Parametrizované dekorátory jsou dekorátory, které mohou přijímat argumenty, což umožňuje přizpůsobit jejich chování. Implementace vyžaduje další úroveň vnořování: funkci, která přebírá parametry a vrací dekorátor.

```python
# Parametrizovaný dekorátor
def repeat(n=3):
    """Dekorátor, který opakuje provedení funkce n-krát"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            results = []
            for _ in range(n):
                results.append(func(*args, **kwargs))
            return results
        return wrapper
    return decorator

# Použití parametrizovaného dekorátoru
@repeat(n=5)
def greet(name):
    return f"Ahoj, {name}!"

# Volání dekorované funkce
print(greet("Bob"))
# Výstup: ['Ahoj, Bob!', 'Ahoj, Bob!', 'Ahoj, Bob!', 'Ahoj, Bob!', 'Ahoj, Bob!']

# Použití výchozího parametru
@repeat()  # nebo jednoduše @repeat
def double(x):
    return x * 2

print(double(10))  # Výstup: [20, 20, 20]
```

Parametrizované dekorátory umožňují flexibilnější a konfigurovatelnou modifikaci chování funkcí.

## 3. Dekorátory založené na třídách

Dekorátory založené na třídách využívají objektově orientované funkce Pythonu k vytvoření udržitelnějších a stavových dekorátorů. Dekorátor třídy musí implementovat metodu `__call__`, aby byly instance volatelné.

```python
class CountCalls:
    """Dekorátor, který počítá, kolikrát byla funkce volána"""
    
    def __init__(self, func):
        self.func = func
        self.count = 0
    
    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"Volání {self.count} funkce {self.func.__name__}")
        return self.func(*args, **kwargs)

@CountCalls
def say_hello(name):
    return f"Ahoj, {name}!"

# Vícenásobné volání dekorované funkce
print(say_hello("Alice"))  # Volání 1 funkce say_hello
print(say_hello("Bob"))    # Volání 2 funkce say_hello
print(say_hello("Carol"))  # Volání 3 funkce say_hello

# Můžete přistupovat ke stavu dekorátoru
print(f"Funkce byla volána {say_hello.count} krát")  # Funkce byla volána 3 krát
```

Dekorátory založené na třídách s parametry kombinují přístupy z předchozích příkladů. Potřebujete třídu, která přijímá parametry a vrací dekorátor:

```python
class RepeatCalls:
    """Třídní dekorátor s parametry"""
    
    def __init__(self, n=3):
        self.n = n
    
    def __call__(self, func):
        def wrapper(*args, **kwargs):
            results = []
            for _ in range(self.n):
                results.append(func(*args, **kwargs))
            return results
        return wrapper

# Použití dekorátoru založeného na třídě s parametry
@RepeatCalls(n=4)
def greet(name):
    return f"Ahoj, {name}!"

print(greet("Dave"))  # Výstup: ['Ahoj, Dave!', 'Ahoj, Dave!', 'Ahoj, Dave!', 'Ahoj, Dave!']
```

## 4. Zachování metadat funkcí

Jedním z problémů dekorátorů je, že skrývají metadata původní funkce (jako například jméno, dokumentační řetězec atd.). Dekorátor `functools.wraps` pomáhá zachovat tato metadata:

```python
import functools
import time

def timing_decorator(func):
    @functools.wraps(func)  # Zachovává metadata dekorované funkce
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"Funkce {func.__name__} trvala {end_time - start_time:.6f} sekund")
        return result
    return wrapper

@timing_decorator
def slow_function():
    """Tato funkce simuluje pomalou operaci"""
    time.sleep(1)
    return "Funkce dokončena"

# Jméno funkce a dokumentační řetězec jsou zachovány
print(slow_function.__name__)  # Výstup: slow_function
print(slow_function.__doc__)   # Výstup: Tato funkce simuluje pomalou operaci

# Volání funkce
print(slow_function())
# Výstup:
# Funkce slow_function trvala 1.001234 sekund
# Funkce dokončena
```

## 5. Skládání více dekorátorů

Dekorátory lze skládat, přičemž každý dekorátor přidává své vlastní chování. Dekorátory se aplikují zdola nahoru (dekorátor nejblíže k funkci se aplikuje jako první).

```python
def bold(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        return f"<b>{func(*args, **kwargs)}</b>"
    return wrapper

def italic(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        return f"<i>{func(*args, **kwargs)}</i>"
    return wrapper

def underline(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        return f"<u>{func(*args, **kwargs)}</u>"
    return wrapper

# Skládání dekorátorů
@bold
@italic
@underline
def greet(name):
    return f"Ahoj, {name}!"

print(greet("světe"))
# Výstup: <b><i><u>Ahoj, světe!</u></i></b>
```

## 6. Pokročilé vzory dekorátorů

Pokročilé dekorátory mohou implementovat složitější vzory, jako je ukládání výsledků do mezipaměti (memoizace), logika opakování nebo ověřování.

### Dekorátor pro memoizaci

```python
def memoize(func):
    cache = {}
    
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        # Vytvoření klíče z argumentů
        key = str(args) + str(kwargs)
        
        if key not in cache:
            cache[key] = func(*args, **kwargs)
            print(f"Vypočtený výsledek pro {key}")
        else:
            print(f"Použití výsledku z mezipaměti pro {key}")
            
        return cache[key]
    
    return wrapper

# Použití dekorátoru pro memoizaci
@memoize
def fibonacci(n):
    """Rekurzivní výpočet Fibonacciho čísla"""
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(5))  # Vypočítá pro 0, 1, 2, 3, 4, 5
print(fibonacci(5))  # Použije výsledek z mezipaměti
```

### Dekorátor pro opakované pokusy

```python
import random
import time

def retry(max_attempts=3, delay_seconds=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            attempts = 0
            while attempts < max_attempts:
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    attempts += 1
                    if attempts == max_attempts:
                        raise
                    print(f"Pokus {attempts} selhal s chybou {e}. Opakuji za {delay_seconds} sekund...")
                    time.sleep(delay_seconds)
            return None  # Sem by se nikdy nemělo dojít
        return wrapper
    return decorator

# Použití dekorátoru pro opakované pokusy
@retry(max_attempts=5, delay_seconds=0.5)
def unstable_function():
    """Tato funkce selhává náhodně"""
    if random.random() < 0.7:  # 70% pravděpodobnost selhání
        raise ConnectionError("Náhodná chyba připojení")
    return "Úspěch!"

try:
    print(unstable_function())
except Exception as e:
    print(f"Funkce nakonec selhala s chybou: {e}")
```

## 7. Praktické aplikace

Dekorátory jsou široce používány ve webových frameworcích, testování a dalších knihovnách. Zde jsou některé příklady, jak jsou dekorátory používány v reálných aplikacích:

### Ověřování ve webových frameworcích

```python
def login_required(func):
    @functools.wraps(func)
    def wrapper(request, *args, **kwargs):
        if not request.user.is_authenticated:
            return redirect('/login/')
        return func(request, *args, **kwargs)
    return wrapper

# V aplikaci podobné Flask nebo Django
@login_required
def protected_view(request):
    return "Vítejte, ověřený uživateli!"
```

### Omezení přenosové rychlosti

```python
import time
from collections import deque

class RateLimiter:
    """Dekorátor třídy, který omezuje rychlost volání funkce"""
    
    def __init__(self, max_calls=5, period=60):
        self.max_calls = max_calls
        self.period = period
        self.calls_history = {}  # Slovník pro sledování historie pro různé funkce
    
    def __call__(self, func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            # Získání nebo vytvoření historie pro tuto funkci
            if func not in self.calls_history:
                self.calls_history[func] = deque()
            
            # Odstranění starých volání
            current_time = time.time()
            history = self.calls_history[func]
            
            while history and history[0] < current_time - self.period:
                history.popleft()
            
            # Kontrola, zda můžeme provést nové volání
            if len(history) < self.max_calls:
                history.append(current_time)
                return func(*args, **kwargs)
            else:
                oldest_call = history[0]
                wait_time = oldest_call + self.period - current_time
                raise Exception(f"Překročen limit rychlosti. Zkuste to znovu za {wait_time:.2f} sekund.")
                
        return wrapper

# Použití omezovače rychlosti
@RateLimiter(max_calls=3, period=10)
def api_request(endpoint):
    print(f"Provádím API požadavek na {endpoint}")
    return f"Odpověď z {endpoint}"

# Testování omezovače rychlosti
for i in range(5):
    try:
        print(api_request(f"/api/endpoint-{i}"))
    except Exception as e:
        print(f"Chyba: {e}")
    time.sleep(1)  # Počkej 1 sekundu mezi pokusy
```

### Běžné chyby

```python
# Chyba 1: Zapomenutí, že dekorátory se provádějí během importu
def print_on_import(func):
    print(f"Importuji {func.__name__}")  # Toto se spustí během importu!
    return func

@print_on_import
def greet():
    return "Ahoj!"

# Chyba 2: Nesprávná dekorace metod
class WrongDecorator:
    def __init__(self, func):
        self.func = func
    
    def __call__(self, *args, **kwargs):
        # Neřeší správně 'self' pro metody
        return self.func(*args, **kwargs)

class CorrectDecorator:
    def __init__(self, func):
        self.func = func
    
    def __call__(self, *args, **kwargs):
        return self.func(*args, **kwargs)
    
    def __get__(self, instance, owner):
        # Správné ošetření metod
        if instance is None:
            return self
        return functools.partial(self, instance)

# Chyba 3: Nesprávné zachycení argumentů v parametrizovaných dekorátorech
def buggy_repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                # n je správně zachyceno díky closure
                pass
            
            for i in range(n):
                # Ale pokud předefinujete nebo upravíte zachycenou proměnnou,
                # vytvoří se nová lokální proměnná
                # i = n  # Toto by narušilo closure
                pass
            
            return func(*args, **kwargs)
        return wrapper
    return decorator
```

## 9. Shrnutí

Pokročilé dekorátory rozšiřují možnosti metaprogramování v Pythonu tím, že umožňují sofistikovaným způsobem upravovat chování funkcí nebo metod:

1. **Parametrizované dekorátory** umožňují konfigurovatelné chování prostřednictvím argumentů předaných samotnému dekorátoru.
2. **Dekorátory založené na třídách** poskytují mechanismy pro udržování stavu mezi voláními dekorátorů a využívají objektově orientované funkce Pythonu.
3. **Správné zachování metadat** pomocí `functools.wraps` zajišťuje, že dekorované funkce zachovají svou identitu.
4. **Skládání dekorátorů** umožňuje kombinovat více modifikací chování přehledným, vrstveným přístupem.
5. **Praktické aplikace** zahrnují ověřování, omezování rychlosti, memoizaci a logiku opakovaných pokusů, mimo jiné.

Zvládnutí pokročilých dekorátorů odemyká mocné programovací vzory, které činí váš kód modulárnějším, znovu použitelnějším a expresivnějším. Díky pochopení implementace založené na funkcích i na třídách získáváte flexibilitu v tom, jak přistupovat k různým výzvám metaprogramování.

Při rozumném použití mohou dekorátory výrazně zlepšit organizaci kódu a snížit redundanci. Měly by však být používány s rozmyslem, s pečlivou pozorností věnovanou čitelnosti, dokumentaci a dopadům na výkon.
