## 1. Úvod do modulů a balíčků

Moduly a balíčky jsou klíčovými komponenty Pythonu, které pomáhají efektivně organizovat a znovu používat kód. Modul je soubor obsahující definice a příkazy Pythonu, zatímco balíček je adresář souvisejících modulů.

- **Modul**: Jediný soubor Pythonu (`.py`) obsahující funkce, třídy a proměnné
- **Balíček**: Adresář obsahující více modulů a speciální soubor `__init__.py`

Moduly a balíčky pomáhají rozdělit velké programy na malé, zvládnutelné a organizované komponenty, podporují znovupoužitelnost kódu a zamezují konfliktům názvů.

```python
# Základní použití modulu
import math  # Import vestavěného modulu

# Použití funkcí z importovaného modulu
radius = 5
area = math.pi * radius ** 2
print(f"Plocha kruhu s poloměrem {radius} je {area:.2f}")

# Alternativní syntaxe importu
from math import pi, sqrt
area = pi * radius ** 2
diagonal = sqrt(10)
print(f"Upravený výpočet: {area:.2f}, úhlopříčka: {diagonal:.2f}")
```

## 2. Práce s vestavěnými a externími moduly

Python přichází s bohatou standardní knihovnou vestavěných modulů. Kromě toho externí moduly rozšiřují funkčnost Pythonu pro specializované úlohy.

```python
# Příklady

# Informace o systému
print(f"Verze Pythonu: {sys.version}")

# Aktuální datum a čas
now = datetime.datetime.now()
print(f"Aktuální datum a čas: {now}")

# Práce s JSON
data = {
    "name": "Jan",
    "age": 30,
    "city": "Praha"

json_string = json.dumps(data, indent=2)
```

## 3. Vytváření vlastních modulů

Vytvoření vlastních modulů vám umožňuje efektivně organizovat a znovu používat váš kód.

### Základy vytváření modulů

Pojďme vytvořit jednoduchý vlastní modul nazvaný `calculator.py`:

```python
# Soubor: calculator.py
"""
Jednoduchý kalkulační modul se základními aritmetickými operacemi.
"""

def add(a, b):
    """Sečte dvě čísla."""
    return a + b

def subtract(a, b):
    """Odečte b od a."""
    return a - b

def multiply(a, b):
    """Vynásobí dvě čísla."""
    return a * b

def divide(a, b):
    """Vydělí a číslem b."""
    if b == 0:
        raise ValueError("Nelze dělit nulou")
    return a / b

# Konstanty
PI = 3.14159

# Tento kód se spustí pouze při přímém spuštění modulu
if __name__ == "__main__":
    print("Test kalkulačního modulu")
    print(f"5 + 3 = {add(5, 3)}")
    print(f"5 - 3 = {subtract(5, 3)}")
```

Nyní můžeme použít náš vlastní modul v jiném skriptu:

```python
# Soubor: main.py
import calculator

# Použití funkcí z našeho vlastního modulu
result1 = calculator.add(10, 5)
result2 = calculator.multiply(10, 5)

print(f"Výsledek sčítání: {result1}")
print(f"Výsledek násobení: {result2}")
print(f"Hodnota PI z modulu: {calculator.PI}")

# Můžeme také importovat konkrétní funkce
from calculator import divide, subtract

result3 = divide(20, 4)
result4 = subtract(20, 4)

print(f"Výsledek dělení: {result3}")
print(f"Výsledek odčítání: {result4}")
```

## 4. Struktura a organizace balíčků

Balíček je způsob, jak organizovat související moduly do hierarchie adresářů. Vytvoření balíčku zahrnuje strukturování adresářů a použití speciálního souboru `__init__.py`.

### Základní struktura balíčku

```
my_package/
│
├── __init__.py
├── module1.py
├── module2.py
│
└── subpackage/
    ├── __init__.py
    └── module3.py
```

Takto bychom implementovali tuto strukturu:

```python
# Soubor: my_package/__init__.py
"""
Inicializační soubor mého balíčku.
"""
print("Inicializace balíčku my_package")

# Můžeme definovat, co se importuje, když někdo provede "from my_package import *"
__all__ = ['module1', 'module2']

# Můžeme také importovat submoduly pro zjednodušení přístupu
from . import module1
from . import module2
```

```python
# Soubor: my_package/module1.py
"""Funkcionalita modulu 1."""

def function1():
    return "Funkce 1 z module1"

class Class1:
    def method1(self):
        return "Metoda 1 z Class1"
```

```python
# Soubor: my_package/module2.py
"""Funkcionalita modulu 2."""

def function2():
    return "Funkce 2 z module2"
```

```python
# Soubor: my_package/subpackage/__init__.py
"""Inicializace podbalíčku."""
print("Inicializace podbalíčku")
```

```python
# Soubor: my_package/subpackage/module3.py
"""Funkcionalita modulu 3 v podbalíčku."""

def function3():
    return "Funkce 3 z subpackage.module3"
```

### Použití balíčku

```python
# Import a použití modulů z našeho balíčku
import my_package
from my_package import module1
from my_package.subpackage import module3

# Použití funkcí z modulů
print(module1.function1())
result = module3.function3()
print(result)

# Vytvoření instance třídy
obj = module1.Class1()
print(obj.method1())
```

## 5. Mechanismy importu a osvědčené postupy

Python nabízí několik způsobů importu modulů a balíčků, každý s různými důsledky pro čitelnost a správu jmenných prostorů.

### Metody importu

```python
# Metoda 1: Import celého modulu
import math
result = math.sqrt(16)  # Jmenný prostor je zachován

# Metoda 2: Import konkrétních položek z modulu
from math import sqrt, pi
result = sqrt(16)  # Přímý přístup, bez jmenného prostoru

# Metoda 3: Import s aliasem
import numpy as np
array = np.array([1, 2, 3])

# Metoda 4: Import všeho (obecně nedoporučováno)
from math import *
result = sqrt(16) + pi  # Riziko znečištění jmenného prostoru
```

### Cesta vyhledávání modulů

Python hledá moduly v umístěních specifikovaných v `sys.path`:

```python
import sys
print("Cesty pro vyhledávání modulů Pythonu:")
for path in sys.path:
    print(f"- {path}")

# Přidání nové cesty programově
import os
custom_path = os.path.join(os.getcwd(), "custom_modules")
sys.path.append(custom_path)
print(f"Přidána vlastní cesta: {custom_path}")
```

### Osvědčené postupy

```python
# 1. Organizujte importy ve skupinách s prázdným řádkem mezi nimi
# Importy ze standardní knihovny
import os
import sys
import json

# Importy externích knihoven
import numpy as np
import pandas as pd

# Importy z lokální aplikace/knihovny
from my_package import module1
from my_package.subpackage import module3

# 2. Používejte raději absolutní importy než relativní
# Dobré:
from my_package import module1

# 3. Použijte explicitní relativní importy, když je to nutné
# V my_package/subpackage/module3.py:
from .. import module1  # Import z rodičovského balíčku

# 4. Vyhýbejte se importům s hvězdičkou
# Nedoporučuje se:
# from math import *

# 5. Používejte smysluplné aliasy
import matplotlib.pyplot as plt
import pandas as pd
```

## 6. Správa balíčků pomocí pip

`pip` je instalátor balíčků pro Python, který umožňuje instalovat a spravovat externí balíčky z Python Package Index (PyPI) a dalších zdrojů.

### Základní příkazy pip

```bash
# Instalace balíčků
pip install numpy
pip install pandas matplotlib seaborn

# Instalace konkrétní verze
pip install requests==2.25.1

# Instalace s omezením verze
pip install "django>=3.0,<4.0"

# Aktualizace balíčku
pip install --upgrade requests

# Odinstalování balíčku
pip uninstall requests

# Seznam nainstalovaných balíčků
pip list

# Zobrazení detailů o balíčku
pip show numpy

# Export závislostí do souboru requirements
pip freeze > requirements.txt

# Instalace ze souboru requirements
pip install -r requirements.txt
```

### Použití souborů requirements

Soubor requirements.txt pomáhá spravovat závislosti projektu:

```
# requirements.txt
numpy==1.20.3
pandas>=1.3.0
matplotlib==3.4.2
scikit-learn>=0.24.2
```

### Práce s Pythonovým kódem

```python
# Programově můžete zkontrolovat nainstalované balíčky
import pkg_resources

# Seznam všech nainstalovaných balíčků
print("Nainstalované balíčky:")
for package in pkg_resources.working_set:
    print(f"{package.key} {package.version}")

# Kontrola, zda je balíček nainstalován
def je_balik_nainstalovan(nazev_baliku):
    try:
        pkg_resources.get_distribution(nazev_baliku)
        return True
    except pkg_resources.DistributionNotFound:
        return False

print(f"NumPy nainstalován: {je_balik_nainstalovan('numpy')}")
print(f"NeexistujiciBalik nainstalován: {je_balik_nainstalovan('neexistujicibalik')}")
```

## 7. Virtuální prostředí

Virtuální prostředí umožňují vytvářet izolovaná prostředí Pythonu pro různé projekty, čímž se předchází konfliktům závislostí.

### Vytváření a používání virtuálních prostředí

```bash
# Vytvoření virtuálního prostředí
python -m venv mojeprostredi

# Aktivace virtuálního prostředí
# Ve Windows
mojeprostredi\Scripts\activate
# V macOS/Linux
source mojeprostredi/bin/activate

# Deaktivace virtuálního prostředí
deactivate
```

### Práce s virtualenv a virtualenvwrapper

```bash
# Instalace virtualenv
pip install virtualenv

# Vytvoření virtuálního prostředí
virtualenv mojeprostredi

# S virtualenvwrapper (po instalaci)
# Vytvoření nového prostředí
mkvirtualenv mujprojekt

# Seznam prostředí
workon

# Přepnutí do prostředí
workon mujprojekt

# Opuštění aktuálního prostředí
deactivate

# Smazání prostředí
rmvirtualenv mujprojekt
```

### Programová správa prostředí

```python
import subprocess
import os
import sys

def vytvor_virtualni_prostredi(nazev_prostredi):
    """Vytvoření nového virtuálního prostředí."""
    subprocess.run([sys.executable, "-m", "venv", nazev_prostredi], check=True)
    print(f"Virtuální prostředí '{nazev_prostredi}' bylo úspěšně vytvořeno")

def instaluj_requirements(nazev_prostredi, soubor_requirements):
    """Instalace balíčků ze souboru requirements ve virtuálním prostředí."""
    # Určení cesty k pip ve virtuálním prostředí
    if os.name == "nt":  # Windows
        pip_cesta = os.path.join(nazev_prostredi, "Scripts", "pip")
    else:  # Unix/Linux/MacOS
        pip_cesta = os.path.join(nazev_prostredi, "bin", "pip")
    
    # Instalace požadavků
    subprocess.run([pip_cesta, "install", "-r", soubor_requirements], check=True)
    print(f"Balíčky ze souboru {soubor_requirements} byly nainstalovány v prostředí '{nazev_prostredi}'")

# Příklad použití
if __name__ == "__main__":
    nazev_prostredi = "mujprojekt_prostredi"
    vytvor_virtualni_prostredi(nazev_prostredi)
    
    # Vytvoření vzorového souboru requirements
    with open("requirements.txt", "w") as f:
        f.write("requests==2.28.1\nnumpy==1.24.0\npandas==1.5.2\n")
    
    instaluj_requirements(nazev_prostredi, "requirements.txt")
```

## 8. Distribuce a publikování balíčků

Vytváření distribuovatelných balíčků vám umožňuje sdílet váš kód s ostatními prostřednictvím PyPI nebo jiných repozitářů.

### Struktura balíčku pro distribuci

```
my_project/
├── LICENSE
├── README.md
├── pyproject.toml  # Moderní konfigurační soubor pro sestavení
├── setup.py        # Tradiční instalační skript
├── setup.cfg       # Dodatečná konfigurace
├── src/
│   └── mypackage/
│       ├── __init__.py
│       ├── module1.py
│       └── module2.py
└── tests/
    ├── __init__.py
    └── test_mypackage.py
```

### Vytvoření setup.py

```python
# Soubor: setup.py
from setuptools import setup, find_packages

setup(
    name="mypackage",
    version="0.1.0",
    author="Vaše Jméno",
    author_email="vas.email@example.com",
    description="Krátký popis vašeho balíčku",
    long_description=open("README.md").read(),
    long_description_content_type="text/markdown",
    url="https://github.com/vaseuzivatelsekjmeno/mypackage",
    packages=find_packages(where="src"),
    package_dir={"": "src"},
    classifiers=[
        "Programming Language :: Python :: 3",
        "License :: OSI Approved :: MIT License",
        "Operating System :: OS Independent",
    ],
    python_requires=">=3.6",
    install_requires=[
        "numpy>=1.19.0",
        "requests>=2.25.0",
    ],
)
```

### Použití pyproject.toml (moderní přístup)


### Sestavení a publikování

```bash
# Instalace nástrojů pro sestavení
pip install build twine

# Nahrání na PyPI (nejprve testovací server)

```

### Programový příklad pro distribuci

```python
import os
import subprocess

def vytvor_adresar_balicku():
    """Vytvoření základní struktury pro distribuovatelný balíček."""
    # Vytvoření struktury adresářů
    os.makedirs("my_project/src/mypackage", exist_ok=True)
    os.makedirs("my_project/tests", exist_ok=True)
    
    # Vytvoření souborů __init__.py
    with open("my_project/src/mypackage/__init__.py", "w") as f:
        f.write('"""Můj balíček pro demonstraci."""\n\n__version__ = "0.1.0"\n')
    
    with open("my_project/tests/__init__.py", "w") as f:
        f.write("# Testovací balíček\n")
    
    # Vytvoření jednoduchého modulu
    with open("my_project/src/mypackage/core.py", "w") as f:
        f.write('"""Základní funkcionalita."""\n\ndef hello():\n    return "Ahoj z mypackage!"\n')
    
    # Vytvoření setup.py
    with open("my_project/setup.py", "w") as f:
        f.write('''from setuptools import setup, find_packages

setup(
    name="mypackage-demo",
    version="0.1.0",
    author="Demo Author",
    author_email="demo@example.com",
    description="Balíček pro demonstraci",
    packages=find_packages(where="src"),
    package_dir={"": "src"},
    python_requires=">=3.6",
)
''')
    
    # Vytvoření README.md
    with open("my_project/README.md", "w") as f:
        f.write("# Můj balíček\n\nJednoduchý balíček Pythonu pro demonstraci.\n")
    
    print("Struktura adresáře balíčku vytvořena v my_project/")

# Vytvoření struktury balíčku
vytvor_adresar_balicku()

# Zobrazení příkazu pro sestavení (ale bez spuštění)
print("\nPro sestavení balíčku byste spustili:")
print("cd my_project && python -m build")
```

## 9. Shrnutí

Systém modulů a balíčků v Pythonu je mocná funkce, která umožňuje organizaci kódu, znovupoužitelnost a distribuci:

1. **Moduly** jsou jednotlivé soubory Pythonu obsahující znovupoužitelný kód, zatímco **balíčky** jsou adresáře modulů se souborem `__init__.py`.

2. Python přichází s rozsáhlou **standardní knihovnou** vestavěných modulů a ekosystém je rozšířen o mnoho **externích balíčků**.

3. **Vytváření vlastních modulů a balíčků** pomáhá efektivně strukturovat váš kód a podporuje jeho znovupoužití v různých projektech.

4. Python nabízí různé **mechanismy importu** s různými dopady na jmenné prostory a čitelnost kódu.

5. **pip** je instalátor balíčků pro Python, který zjednodušuje instalaci a správu externích balíčků.

6. **Virtuální prostředí** umožňují vytvářet izolovaná prostředí Pythonu pro různé projekty, čímž předcházejí konfliktům závislostí.

7. Můžete **distribuovat vlastní balíčky** přes PyPI pomocí setuptools, což umožňuje ostatním instalovat váš kód pomocí pip.

Abyste se stali zdatnými ve správě modulů a balíčků v Pythonu:
- Organizujte svůj kód do logických modulů a balíčků
- Používejte virtuální prostředí pro všechny projekty
- Udržujte jasné soubory požadavků
- Dodržujte osvědčené postupy pro import
- Používejte vhodné nástroje pro správu balíčků

Zvládnutím těchto konceptů budete schopni psát lépe udržovatelný a znovupoužitelný kód v Pythonu, snadno sdílet svou práci s ostatními a efektivně využívat rozsáhlý ekosystém balíčků Pythonu.
