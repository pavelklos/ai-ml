## 2. Understanding pip

pip is Python's official package installer. It connects to the Python Package Index (PyPI), which hosts over 400,000 packages. pip comes pre-installed with Python 3.4+ and handles downloading, installing, and managing package dependencies.


## 4. Installing Packages with pip

You can install packages from PyPI, from version control systems, or from local files. pip also allows you to specify version constraints.

```python
# Installing the latest version of a package
# pip install requests

# Installing a specific version
# pip install requests==2.28.1

# Installing with version constraints
# pip install "requests>=2.28.0,<2.29.0"

# Installing from GitHub
# pip install git+https://github.com/user/repository.git

# Installing from a local file
# pip install ./downloads/some-package-1.0.0.tar.gz

# Installing multiple packages at once
# pip install requests matplotlib pandas

# Example Python code using an installed package
import requests

response = requests.get('https://api.github.com')
if response.status_code == 200:
    print("Successfully connected to GitHub API")
    print(f"Response headers: {response.headers}")
else:
    print(f"Failed with status code: {response.status_code}")
```

## 6. Using Requirements Files

Requirements files allow you to specify project dependencies in a file, making it easy to recreate environments and share with others.

```python
# Creating a requirements.txt file with all installed packages
# pip freeze > requirements.txt

# Creating a minimal requirements file manually:
# Example requirements.txt content:
# requests==2.28.1
# pandas>=1.5.0
# matplotlib
# numpy>=1.23.0,<2.0.0

# Installing all packages from a requirements file
# pip install -r requirements.txt

# Example Python script to check if all requirements are met:
def check_requirements(filename='requirements.txt'):
    import pkg_resources
    import re
    
    with open(filename, 'r') as f:
        requirements = f.readlines()
    
    for req in requirements:
        req = req.strip()
        if not req or req.startswith('#'):
            continue
        
        try:
            # Remove version specifiers for simple check
            package_name = re.split(r'[<>=]', req)[0].strip()
            pkg_resources.require(package_name)
            print(f"✓ {package_name} is installed")
        except pkg_resources.DistributionNotFound:
            print(f"✗ {package_name} is NOT installed")

# Usage
# check_requirements()
```

## 7. Working with Virtual Environments

Virtual environments allow you to create isolated Python environments for your projects, preventing dependency conflicts between projects.

```python
# Creating a virtual environment (run in terminal/command prompt)
# Method 1: Using venv (included with Python 3.3+)
# python -m venv myenv

# Method 2: Using virtualenv (needs to be installed first)
# pip install virtualenv
# virtualenv myenv

# Activating the virtual environment
# On Windows:
# myenv\Scripts\activate
# On macOS/Linux:
# source myenv/bin/activate

# Once activated, your prompt should change, showing the environment name
# Install packages in the virtual environment
# pip install requests pandas

# Deactivating the virtual environment
# deactivate

# Example Python script to check if running in a virtual environment:
import sys

def check_virtual_env():
    """Check if running in a virtual environment"""
    # Check if base_prefix differs from prefix or if there's a real_prefix
    is_venv = (hasattr(sys, 'base_prefix') and sys.base_prefix != sys.prefix) or \
              hasattr(sys, 'real_prefix')
    
    if is_venv:
        print(f"Running in virtual environment: {sys.prefix}")
    else:
        print("Not running in a virtual environment")
    
    return is_venv

check_virtual_env()
```

## 8. Finding and Exploring Packages

Before installing packages, it's useful to research them to ensure they meet your needs.

```python
# To explore packages, you can:
# 1. Visit PyPI website: https://pypi.org
# 2. Use pip search (when available)
# 3. Use third-party tools like pip-search

# Example: Installing and using pip-search
# pip install pip-search
# pip-search "data visualization"

# Exploring installed packages
import pkg_resources

def list_packages():
    """List all installed packages and their versions"""
    installed_packages = [(d.project_name, d.version) for d in pkg_resources.working_set]
    for package, version in sorted(installed_packages):
        print(f"{package} {version}")

def get_package_details(package_name):
    """Get details about a specific package"""
    try:
        package = pkg_resources.get_distribution(package_name)
        print(f"Package: {package.project_name}")
        print(f"Version: {package.version}")
        print(f"Location: {package.location}")
        if hasattr(package, 'requires'):
            print("Dependencies:")
            for requirement in package.requires():
                print(f"  {requirement}")
    except pkg_resources.DistributionNotFound:
        print(f"Package '{package_name}' is not installed")

# Usage
# list_packages()
# get_package_details("requests")
```
