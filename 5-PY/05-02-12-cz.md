## 1. Úvod do modulu Collections

Modul `collections` v Pythonu poskytuje specializované typy kontejnerových datových struktur, které rozšiřují funkcionalitu vestavěných kontejnerů Pythonu jako jsou slovníky, seznamy a n-tice. Tyto specializované kontejnery jsou navrženy tak, aby umožnily efektivnější, výstižnější a méně chybové řešení běžných úkolů.

```python
import collections

# Přehled modulu collections
print("Dostupné kolekce:")
for name in dir(collections):
    if not name.startswith('_'):  # Filtruje privátní metody
        print(f"- {name}")
```

Nejčastěji používané kolekce jsou `defaultdict`, `Counter` a `namedtuple`, které si podrobně probereme.

## 2. Práce s defaultdict

`defaultdict` je podtřída vestavěné třídy `dict`, která poskytuje výchozí hodnotu pro neexistující klíče. To odstraňuje potřebu kontrolovat existenci klíče před jeho použitím.

```python
from collections import defaultdict

# Běžný slovník vyžaduje kontrolu existence klíče
obyčejný_slovník = {}
slovo = "ahoj"
for znak in slovo:
    if znak not in obyčejný_slovník:
        obyčejný_slovník[znak] = 0
    obyčejný_slovník[znak] += 1
print("Obyčejný slovník:", obyčejný_slovník)

# S defaultdict není potřeba kontrolovat, zda klíč existuje
# Funkce int při volání bez argumentů vrací 0
počet_znaků = defaultdict(int)
for znak in slovo:
    počet_znaků[znak] += 1
print("defaultdict:", dict(počet_znaků))

# Vytvoření defaultdict s jinými výchozími typy
seznam_slovník = defaultdict(list)
for i in range(5):
    seznam_slovník[i % 2].append(i)
print("defaultdict se seznamy:", dict(seznam_slovník))

# Použití lambda funkce pro vytvoření složitějších výchozích hodnot
továrna_výchozích = defaultdict(lambda: {"počet": 0, "indexy": []})
for i, znak in enumerate(slovo):
    továrna_výchozích[znak]["počet"] += 1
    továrna_výchozích[znak]["indexy"].append(i)
print("Složitý defaultdict:")
for k, v in továrna_výchozích.items():
    print(f"  {k}: {v}")
```

### Běžné použití defaultdict

```python
# Seskupování položek
zvířata = [('kočka', 'Mourek'), ('pes', 'Rex'), ('kočka', 'Micka'), ('králík', 'Ušáček'), ('pes', 'Fido')]

# Bez defaultdict
skupiny_zvířat = {}
for typ_zvířete, jméno in zvířata:
    if typ_zvířete not in skupiny_zvířat:
        skupiny_zvířat[typ_zvířete] = []
    skupiny_zvířat[typ_zvířete].append(jméno)
print("Bez defaultdict:", skupiny_zvířat)

# S defaultdict
skupiny_zvířat = defaultdict(list)
for typ_zvířete, jméno in zvířata:
    skupiny_zvířat[typ_zvířete].append(jméno)
print("S defaultdict:", dict(skupiny_zvířat))

# Vytvoření grafu
graf = defaultdict(list)
hrany = [('A', 'B'), ('B', 'C'), ('A', 'C'), ('C', 'D')]
for zdroj, cíl in hrany:
    graf[zdroj].append(cíl)
print("Reprezentace grafu:", dict(graf))
```

## 3. Použití Counter pro počítání

`Counter` je specializovaný slovník pro počítání hashovatelných objektů. Je zvláště užitečný pro sčítání položek, hledání nejčastějších prvků a další operace počítání.

```python
from collections import Counter

# Základní počítání
text = "mississippi"
čítač = Counter(text)
print("Počet znaků:", čítač)

# Nejčastější prvky
print("Nejčastější znaky:", čítač.most_common(2))  # Top 2

# Počítání ze seznamu
ovoce = ['jablko', 'pomeranč', 'banán', 'jablko', 'hruška', 'pomeranč', 'jablko', 'hruška']
čítač_ovoce = Counter(ovoce)
print("Počet ovoce:", čítač_ovoce)

# Aktualizace čítačů
čítač.update("missouri")
print("Aktualizovaný čítač:", čítač)

# Matematické operace s čítači
čítač1 = Counter(a=3, b=1, c=5)
čítač2 = Counter(a=1, b=2, d=3)

print("Čítač1:", čítač1)
print("Čítač2:", čítač2)
print("Součet:", čítač1 + čítač2)  # Sčítá počty
print("Rozdíl:", čítač1 - čítač2)  # Odčítá (uchovává pouze kladné počty)
print("Průnik:", čítač1 & čítač2)  # Minimum z počtů
print("Sjednocení:", čítač1 | čítač2)  # Maximum z počtů

# Převod na seznam párů (prvek, počet)
print("Položky:", list(čítač.items()))

# Získání seznamu prvků
print("Prvky:", list(čítač.elements()))
```

## 4. Vytváření datových struktur s namedtuple

Tovární funkce `namedtuple` vytváří podtřídy n-tic s pojmenovanými poli, což činí n-tice více samopopisnými a poskytuje přístup k polím podle názvu, nejen podle pozice.

```python
from collections import namedtuple

# Vytvoření třídy namedtuple
Osoba = namedtuple('Osoba', ['jméno', 'věk', 'profese'])

# Vytvoření instancí
alice = Osoba('Alice', 30, 'Inženýrka')
bob = Osoba('Bob', 25, 'Designér')

print("Alice:", alice)
print("Bobova profese:", bob.profese)  # Přístup podle názvu
print("Alicin věk:", alice[1])  # Stále lze použít index

# Převod na slovník
alice_dict = alice._asdict()
print("Alice jako slovník:", alice_dict)

# Vytvoření nové instance pomocí _replace
starší_alice = alice._replace(věk=31)
print("Starší Alice:", starší_alice)

# Názvy polí
print("Názvy polí:", Osoba._fields)

# Vytvoření z iterable
data = ['Charlie', 22, 'Student']
charlie = Osoba._make(data)
print("Charlie:", charlie)

# Výchozí hodnoty
# Od Pythonu 3.7 můžete použít parametr defaults
Zaměstnanec = namedtuple('Zaměstnanec', ['jméno', 'id', 'oddělení', 'plat'], defaults=[0, 'Neznámé'])
jan = Zaměstnanec('Jan', 1001, 'IT')  # plat bude 'Neznámé'
print("Jan:", jan)

# Použití namedtuple ve funkci
def získej_statistiky_kruhu(poloměr):
    Kruh = namedtuple('Kruh', ['poloměr', 'průměr', 'obvod', 'plocha'])
    import math
    return Kruh(
        poloměr=poloměr,
        průměr=poloměr * 2,
        obvod=2 * math.pi * poloměr,
        plocha=math.pi * poloměr ** 2
    )

kruh = získej_statistiky_kruhu(5)
print(f"Statistiky kruhu: poloměr={kruh.poloměr}, plocha={kruh.plocha:.2f}")
```

## 5. Další užitečné kolekce

Modul collections také poskytuje další užitečné typy kontejnerů, které mohou být nápomocné v různých situacích.

```python
from collections import deque, OrderedDict, ChainMap

# deque: Oboustranná fronta s rychlým přidáváním/odebíráním z obou konců
fronta = deque(['a', 'b', 'c'])
fronta.append('d')  # Přidání vpravo
fronta.appendleft('e')  # Přidání vlevo
print("Deque po přidání:", fronta)
print("Pop vpravo:", fronta.pop())  # Odstranění zprava
print("Pop vlevo:", fronta.popleft())  # Odstranění zleva
print("Deque po odebrání:", fronta)

# Rotace
fronta.rotate(1)  # Rotace vpravo o 1
print("Po rotate(1):", fronta)
fronta.rotate(-1)  # Rotace vlevo o 1
print("Po rotate(-1):", fronta)

# OrderedDict: Udržuje pořadí vložení (méně důležité od Pythonu 3.7)
# Ale stále užitečné pro své specializované metody
seřazený = OrderedDict()
seřazený['a'] = 1
seřazený['b'] = 2
seřazený['c'] = 3
print("OrderedDict:", seřazený)

# Přesun položky na konec
seřazený.move_to_end('a')
print("Po přesunutí 'a' na konec:", seřazený)

# ChainMap: Prohledávání více slovníků jako jedné jednotky
slovník1 = {'a': 1, 'b': 2}
slovník2 = {'b': 3, 'c': 4}
řetěz = ChainMap(slovník1, slovník2)  # slovník1 má přednost při překrývání klíčů
print("ChainMap:", dict(řetěz))
print("Hodnota 'b':", řetěz['b'])  # Získá ze slovník1
print("Hodnota 'c':", řetěz['c'])  # Získá ze slovník2
```

## 6. Praktické aplikace

Prozkoumejme některé praktické aplikace modulu collections v reálných scénářích.

```python
from collections import defaultdict, Counter, namedtuple
import csv
import json

# Příklad 1: Analýza textových dat
def analyzuj_text(text):
    # Počet slov
    slova = text.lower().split()
    počet_slov = Counter(slova)
    
    # Seskupení podle prvního písmene
    podle_prvního_písmene = defaultdict(list)
    for slovo in set(slova):
        podle_prvního_písmene[slovo[0]].append(slovo)
    
    return {
        'celkem_slov': len(slova),
        'unikátních_slov': len(počet_slov),
        'nejčastější': počet_slov.most_common(3),
        'podle_prvního_písmene': dict(podle_prvního_písmene)
    }

ukázkový_text = """
Python je vysokoúrovňový, interpretovaný programovací jazyk. 
Filozofie návrhu Pythonu zdůrazňuje čitelnost kódu prostřednictvím významných mezer.
Jeho jazykové konstrukce a objektově orientovaný přístup mají za cíl pomoci programátorům psát jasný, logický kód.
Python je dynamicky typovaný a s automatickou správou paměti.
"""

analýza = analyzuj_text(ukázkový_text)
print("Analýza textu:")
print(f"Celkem slov: {analýza['celkem_slov']}")
print(f"Unikátních slov: {analýza['unikátních_slov']}")
print(f"Nejčastější slova: {analýza['nejčastější']}")
print("Slova začínající na 'p':", analýza['podle_prvního_písmene'].get('p', []))

# Příklad 2: Zpracování strukturovaných dat
DataBod = namedtuple('DataBod', ['datum', 'hodnota', 'kategorie'])

data = [
    DataBod('2023-01-01', 10, 'A'),
    DataBod('2023-01-02', 15, 'B'),
    DataBod('2023-01-01', 20, 'A'),
    DataBod('2023-01-03', 30, 'B'),
    DataBod('2023-01-02', 25, 'A')
]

# Agregace podle data a kategorie
součty_podle_data = defaultdict(int)
součty_podle_kategorie = defaultdict(int)

for bod in data:
    součty_podle_data[bod.datum] += bod.hodnota
    součty_podle_kategorie[bod.kategorie] += bod.hodnota

print("\nAgregace dat:")
print("Součty podle data:", dict(součty_podle_data))
print("Součty podle kategorie:", dict(součty_podle_kategorie))
```

## 7. Výkonnostní aspekty

Specializované kontejnery v modulu collections jsou navrženy pro efektivitu v konkrétních případech použití. Porovnejme jejich výkon se standardními kontejnery Pythonu.

```python
import time
import random
from collections import defaultdict, Counter

def čas_provedení(func, *args, **kwargs):
    start = time.time()
    výsledek = func(*args, **kwargs)
    konec = time.time()
    return výsledek, konec - start

# Generování náhodných dat
random.seed(42)  # Pro reprodukovatelnost
data = [random.randint(1, 100) for _ in range(1000000)]

# Počítání frekvencí pomocí standardního slovníku
def počítej_slovníkem(položky):
    počty = {}
    for položka in položky:
        if položka not in počty:
            počty[položka] = 0
        počty[položka] += 1
    return počty

# Počítání frekvencí pomocí defaultdict
def počítej_defaultdictem(položky):
    počty = defaultdict(int)
    for položka in položky:
        počty[položka] += 1
    return počty

# Počítání frekvencí pomocí Counter
def počítej_counterem(položky):
    return Counter(položky)

# Provedení a změření času každého přístupu
slovník_výsledek, slovník_čas = čas_provedení(počítej_slovníkem, data)
defaultdict_výsledek, defaultdict_čas = čas_provedení(počítej_defaultdictem, data)
counter_výsledek, counter_čas = čas_provedení(počítej_counterem, data)

print("Porovnání výkonu:")
print(f"Standardní slovník: {slovník_čas:.4f} sekund")
print(f"defaultdict: {defaultdict_čas:.4f} sekund")
print(f"Counter: {counter_čas:.4f} sekund")
```

## 8. Shrnutí

Modul `collections` poskytuje specializované typy datových kontejnerů, které rozšiřují vestavěné kontejnery Pythonu, což činí kód efektivnějším a čitelnějším:

1. **defaultdict**: Podtřída slovníku, která poskytuje výchozí hodnoty pro chybějící klíče, což odstraňuje potřebu kontrol existence klíče.

2. **Counter**: Specializovaný slovník pro počítání hashovatelných objektů, s užitečnými metodami pro sčítání a hledání nejčastějších prvků.

3. **namedtuple**: Vytváří podtřídy n-tic s pojmenovanými poli, což činí n-tice více samopopisnými a umožňuje přístup k polím podle názvu.

4. **Další kolekce** jako `deque`, `OrderedDict` a `ChainMap` poskytují dodatečnou funkcionalitu pro specifické scénáře.

Používání těchto specializovaných kontejnerů může vést k:
- Přehlednějšímu a čitelnějšímu kódu
- Lepšímu výkonu pro konkrétní případy použití
- Výstižnějším datovým strukturám
- Menšímu počtu chyb souvisejících s chybami klíčů nebo složitým zpracováním dat

Modul collections je součástí Pythonovy filozofie "batteries included" (vše potřebné je součástí), poskytující elegantní řešení pro běžné programovací úkoly. Využíváním těchto specializovaných kontejnerů můžete psát efektivnější a udržitelnější kód.
