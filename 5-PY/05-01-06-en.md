## 1. Introduction to Lists

Lists in Python are ordered, mutable collections that can store multiple items of different data types. They are one of Python's most versatile and commonly used data structures. Lists are denoted by square brackets `[]` and elements are separated by commas.

```python
# A list can contain different data types
mixed_list = [1, "hello", 3.14, True, None]
print(mixed_list)  # Output: [1, 'hello', 3.14, True, None]

# Lists are mutable (can be changed after creation)
numbers = [1, 2, 3]
numbers[0] = 10
print(numbers)  # Output: [10, 2, 3]

# Lists preserve order
colors = ["red", "green", "blue"]
print(colors[0])  # Output: red
print(colors[2])  # Output: blue
```

## 2. Creating and Accessing Lists

There are multiple ways to create lists in Python. You can access list elements through indexing, which starts from 0 for the first element.

```python
# Creating lists
empty_list = []                      # Empty list
numbers = [1, 2, 3, 4, 5]            # List of integers
fruits = ["apple", "banana", "cherry"]  # List of strings
mixed = [1, "hello", 3.14]           # Mixed types

# Creating a list using the list() constructor
letters = list("abcde")      # Converts string to list of characters
print(letters)               # Output: ['a', 'b', 'c', 'd', 'e']

# Creating a list using range()
numbers = list(range(1, 6))  # Creates [1, 2, 3, 4, 5]
print(numbers)

# Accessing list elements by index
fruits = ["apple", "banana", "cherry", "date"]
print(fruits[0])    # Output: apple
print(fruits[2])    # Output: cherry

# Negative indexing (counts from the end)
print(fruits[-1])   # Output: date (last element)
print(fruits[-2])   # Output: cherry (second last element)

# Slicing lists [start:stop:step]
print(fruits[1:3])    # Output: ['banana', 'cherry']
print(fruits[:2])     # Output: ['apple', 'banana']
print(fruits[2:])     # Output: ['cherry', 'date']
print(fruits[::2])    # Output: ['apple', 'cherry'] (every second element)
print(fruits[::-1])   # Output: ['date', 'cherry', 'banana', 'apple'] (reversed)
```

## 3. Basic List Operations

Python provides various operations that can be performed on lists:

```python
# List length
fruits = ["apple", "banana", "cherry"]
print(len(fruits))  # Output: 3

# Concatenation
list1 = [1, 2, 3]
list2 = [4, 5, 6]
combined = list1 + list2
print(combined)  # Output: [1, 2, 3, 4, 5, 6]

# Repetition
zeros = [0] * 5
print(zeros)  # Output: [0, 0, 0, 0, 0]

# Checking membership
fruits = ["apple", "banana", "cherry"]
print("banana" in fruits)  # Output: True
print("orange" in fruits)  # Output: False

# Iterating through a list
for fruit in fruits:
    print(fruit)

# Iterating with index
for i, fruit in enumerate(fruits):
    print(f"Index {i}: {fruit}")

# Comparing lists
list1 = [1, 2, 3]
list2 = [1, 2, 3]
list3 = [3, 2, 1]
print(list1 == list2)  # Output: True
print(list1 == list3)  # Output: False
```

## 4. List Methods

Python lists provide many built-in methods for manipulation:

```python
# Add elements
fruits = ["apple", "banana"]
fruits.append("cherry")           # Add to end
print(fruits)  # Output: ['apple', 'banana', 'cherry']

fruits.insert(1, "orange")        # Insert at position
print(fruits)  # Output: ['apple', 'orange', 'banana', 'cherry']

fruits.extend(["grape", "kiwi"])  # Add multiple items
print(fruits)  # Output: ['apple', 'orange', 'banana', 'cherry', 'grape', 'kiwi']

# Remove elements
fruits.remove("banana")      # Remove by value
print(fruits)  # Output: ['apple', 'orange', 'cherry', 'grape', 'kiwi']

popped = fruits.pop()        # Remove and return last item
print(popped)   # Output: kiwi
print(fruits)   # Output: ['apple', 'orange', 'cherry', 'grape']

popped = fruits.pop(1)       # Remove item at index
print(popped)   # Output: orange
print(fruits)   # Output: ['apple', 'cherry', 'grape']

fruits.clear()               # Remove all items
print(fruits)   # Output: []

# Ordering
numbers = [3, 1, 4, 1, 5, 9, 2, 6]
numbers.sort()               # Sort in-place (ascending)
print(numbers)  # Output: [1, 1, 2, 3, 4, 5, 6, 9]

numbers.sort(reverse=True)   # Sort in descending order
print(numbers)  # Output: [9, 6, 5, 4, 3, 2, 1, 1]

numbers.reverse()            # Reverse the list
print(numbers)  # Output: [1, 1, 2, 3, 4, 5, 6, 9]

# Finding elements
fruits = ["apple", "banana", "cherry", "banana"]
print(fruits.index("banana"))        # Output: 1 (first occurrence)
print(fruits.count("banana"))        # Output: 2 (number of occurrences)

# Copying lists
original = [1, 2, 3]
copy1 = original.copy()      # Method 1: using copy()
copy2 = list(original)       # Method 2: using list()
copy3 = original[:]          # Method 3: using slicing

original[0] = 100
print(original)  # Output: [100, 2, 3]
print(copy1)     # Output: [1, 2, 3] (unchanged)
```

## 5. List Comprehensions

List comprehensions provide a concise way to create lists. They consist of brackets containing an expression followed by a for clause and optional if clauses.

```python
# Basic list comprehension
squares = [x**2 for x in range(1, 6)]
print(squares)  # Output: [1, 4, 9, 16, 25]

# With conditional logic
even_squares = [x**2 for x in range(1, 11) if x % 2 == 0]
print(even_squares)  # Output: [4, 16, 36, 64, 100]

# Multiple conditions
numbers = [x for x in range(1, 20) if x % 2 == 0 if x % 3 == 0]
print(numbers)  # Output: [6, 12, 18]

# If-else in list comprehension
results = ["Even" if x % 2 == 0 else "Odd" for x in range(5)]
print(results)  # Output: ['Even', 'Odd', 'Even', 'Odd', 'Even']

# Working with strings
words = ["hello", "world", "python"]
upper_words = [word.upper() for word in words]
print(upper_words)  # Output: ['HELLO', 'WORLD', 'PYTHON']

# Flattening a 2D list
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flattened = [num for row in matrix for num in row]
print(flattened)  # Output: [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 6. Working with Nested Lists

Nested lists (lists of lists) are used to represent multi-dimensional structures like matrices:

```python
# Creating a nested list
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Accessing elements in nested lists
print(matrix[0])      # Output: [1, 2, 3]
print(matrix[1][2])   # Output: 6

# Modifying elements
matrix[0][1] = 20
print(matrix)  # Output: [[1, 20, 3], [4, 5, 6], [7, 8, 9]]

# Iterating through a nested list
for row in matrix:
    for element in row:
        print(element, end=" ")
    print()  # New line after each row

# Creating a 3x3 identity matrix using list comprehension
size = 3
identity = [[1 if i == j else 0 for j in range(size)] for i in range(size)]
print(identity)  # Output: [[1, 0, 0], [0, 1, 0], [0, 0, 1]]

# Transpose a matrix
transpose = [[row[i] for row in matrix] for i in range(3)]
print(transpose)  # Output: [[1, 4, 7], [20, 5, 8], [3, 6, 9]]
```

## 7. Common List Patterns and Algorithms

Here are some common patterns and algorithms used with Python lists:

```python
# Finding the maximum/minimum value
numbers = [3, 1, 4, 1, 5, 9, 2, 6]
print(max(numbers))  # Output: 9
print(min(numbers))  # Output: 1

# Summing values
print(sum(numbers))  # Output: 31

# Filtering a list
even_numbers = [x for x in numbers if x % 2 == 0]
print(even_numbers)  # Output: [4, 2, 6]

# Custom filtering
def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

primes = list(filter(is_prime, range(20)))
print(primes)  # Output: [2, 3, 5, 7, 11, 13, 17, 19]

# Mapping operations
squared = list(map(lambda x: x**2, numbers))
print(squared)  # Output: [9, 1, 16, 1, 25, 81, 4, 36]

# Remove duplicates while preserving order
def remove_duplicates(lst):
    result = []
    for item in lst:
        if item not in result:
            result.append(item)
    return result

duplicated = [1, 2, 2, 3, 4, 3, 5]
print(remove_duplicates(duplicated))  # Output: [1, 2, 3, 4, 5]

# Alternative way to remove duplicates (using dict.fromkeys)
print(list(dict.fromkeys(duplicated)))  # Output: [1, 2, 3, 4, 5]

# Counting occurrences
from collections import Counter
counts = Counter(duplicated)
print(counts)  # Output: Counter({2: 2, 3: 2, 1: 1, 4: 1, 5: 1})
```

## 8. List Performance Considerations

Lists are versatile but come with certain performance characteristics:

```python
import time
import sys

# Memory usage
empty_list = []
print(sys.getsizeof(empty_list))  # Base size of an empty list (typically 56 bytes)

# Memory usage grows as list grows
for i in range(5):
    empty_list.append(i)
    print(f"{len(empty_list)} items: {sys.getsizeof(empty_list)} bytes")

# Performance comparison: append vs. concatenation
def test_append():
    lst = []
    for i in range(10000):
        lst.append(i)
    return lst

def test_concatenation():
    lst = []
    for i in range(10000):
        lst = lst + [i]  # Creates a new list each time
    return lst

start = time.time()
test_append()
print(f"Append time: {time.time() - start:.6f} seconds")

start = time.time()
test_concatenation()
print(f"Concatenation time: {time.time() - start:.6f} seconds")

# Performance of list operations
# O(1) operations: append, pop from end, get/set by index
# O(n) operations: insert, remove, pop from beginning, in (search)

# When to use other data structures:
# - Use sets for fast membership testing
# - Use deque for efficient additions/removals from both ends
# - Use numpy arrays for numerical operations
```
