## 1. Introduction to Abstract Syntax Trees

Abstract Syntax Trees (ASTs) are tree representations of the abstract syntactic structure of source code. In Python, ASTs play a crucial role in understanding, analyzing, and transforming code. Rather than dealing with raw text, ASTs provide a structured way to work with code's logical components.

Key concepts:
- AST represents code as a hierarchical tree structure
- Each node in the tree corresponds to a language construct
- Syntax details like whitespace and comments are stripped away
- ASTs allow programmatic analysis and modification of code

```python
"""
This is a high-level overview of how Python code translates to AST concepts:

Source code:
    x = 1 + 2

AST structure (conceptual):
    Assignment
    ├── Target: Name(id='x')
    └── Value: BinOp
        ├── Left: Num(value=1)
        ├── Op: Add()
        └── Right: Num(value=2)
"""
```

## 2. Getting Started with Python's AST Module

Python's built-in `ast` module provides tools for working with Abstract Syntax Trees. This module allows you to parse code, explore the resulting AST, and create or modify ASTs programmatically.

```python
import ast

# A simple example to get started
code = "x = 1 + 2"
parsed_ast = ast.parse(code)

# Basic information about the AST
print(f"AST type: {type(parsed_ast)}")
print(f"AST fields: {parsed_ast._fields}")

# Print a basic representation of the AST
print(ast.dump(parsed_ast))
```

When executed, this will output:
```
AST type: <class 'ast.Module'>
AST fields: ('body', 'type_ignores')
Module(body=[Assign(targets=[Name(id='x', ctx=Store())], value=BinOp(left=Constant(value=1), op=Add(), right=Constant(value=2)))], type_ignores=[])
```

## 3. Parsing Python Code into AST

The `ast.parse()` function converts Python code into an AST. You can parse strings, files, or any other text containing valid Python code.

```python
import ast

# Parse code from a string
code_str = """
def add(a, b):
    return a + b

result = add(5, 7)
"""
tree = ast.parse(code_str)

# Parse code from a file
with open('example.py', 'r') as file:
    file_code = file.read()
file_tree = ast.parse(file_code)

# You can specify the source filename for better error messages
tree_with_filename = ast.parse(code_str, filename='<string>')

# Parse an expression (returns an Expression node instead of Module)
expr_tree = ast.parse('1 + 2', mode='eval')
print(type(expr_tree))  # <class 'ast.Expression'>

# Parse a single statement
stmt_tree = ast.parse('if True: print("Hello")', mode='single')
```

## 4. Exploring AST Structures

Understanding the structure of ASTs is essential for working with them effectively. Let's explore common node types and their attributes.

```python
import ast

def explore_node(node, indent=0):
    """Recursively explore an AST node and its children."""
    prefix = ' ' * indent
    # Print the node class name
    print(f"{prefix}{node.__class__.__name__}")
    
    # Print the node fields and their values
    for field, value in ast.iter_fields(node):
        if isinstance(value, list):
            print(f"{prefix}  {field}:")
            for item in value:
                if isinstance(item, ast.AST):
                    explore_node(item, indent + 4)
                else:
                    print(f"{prefix}    {item}")
        elif isinstance(value, ast.AST):
            print(f"{prefix}  {field}:")
            explore_node(value, indent + 4)
        else:
            print(f"{prefix}  {field}: {value}")

# Example code to explore
code = """
def factorial(n):
    if n <= 1:
        return 1
    else:
        return n * factorial(n - 1)
"""

# Parse and explore the AST
tree = ast.parse(code)
explore_node(tree)
```

Common AST node types:
- `Module`: Top-level node for a file or code block
- `Assign`: Variable assignment (x = y)
- `Name`: Variable reference 
- `Call`: Function call (func())
- `BinOp`: Binary operation (a + b)
- `If`: Conditional statement
- `FunctionDef`: Function definition

## 5. Traversing and Transforming ASTs

Python's `ast` module provides tools for traversing and transforming ASTs through visitor classes. The two main base classes are:
- `ast.NodeVisitor`: For traversing and analyzing AST nodes
- `ast.NodeTransformer`: For modifying ASTs

### Using NodeVisitor

```python
import ast

class FunctionVisitor(ast.NodeVisitor):
    """Visit and print information about function definitions."""
    
    def visit_FunctionDef(self, node):
        args = [arg.arg for arg in node.args.args]
        print(f"Found function: {node.name}")
        print(f"Arguments: {', '.join(args)}")
        
        # Continue traversing the function body
        self.generic_visit(node)

# Example code with functions
code = """
def greet(name):
    return f"Hello, {name}!"

def add(a, b):
    return a + b
"""

# Parse and visit the AST
tree = ast.parse(code)
visitor = FunctionVisitor()
visitor.visit(tree)
```

### Using NodeTransformer

```python
import ast
import astor  # Install with: pip install astor

class DoubleConstantsTransformer(ast.NodeTransformer):
    """Double all numeric constants in the code."""
    
    def visit_Constant(self, node):
        # Check if the constant is a number
        if isinstance(node.value, (int, float)):
            # Return a new node with doubled value
            return ast.Constant(value=node.value * 2)
        # Return unchanged for non-numeric constants
        return node

# Example code with numeric constants
code = """
x = 10
y = 3.14
z = "This is a string"
result = x + y
"""

# Parse, transform, and compile the AST
tree = ast.parse(code)
transformer = DoubleConstantsTransformer()
transformed_tree = transformer.visit(tree)
ast.fix_missing_locations(transformed_tree)  # Fix line numbers and offsets

# Convert back to code and execute
compiled_code = compile(transformed_tree, '<string>', 'exec')
namespace = {}
exec(compiled_code, namespace)
print(f"x: {namespace['x']}")  # 20
print(f"y: {namespace['y']}")  # 6.28
print(f"z: {namespace['z']}")  # This is a string
print(f"result: {namespace['result']}")  # 26.28
```

## 6. Code Analysis with AST

ASTs are powerful tools for static code analysis. With them, you can detect patterns, enforce style guidelines, find bugs, and more.

```python
import ast
import symtable

class CodeAnalyzer(ast.NodeVisitor):
    def __init__(self):
        self.stats = {
            'function_count': 0,
            'class_count': 0,
            'import_count': 0,
            'lines_of_code': 0,
            'for_loops': 0,
            'while_loops': 0,
            'if_statements': 0,
            'assignments': 0,
            'function_calls': 0,
        }
    
    def visit_FunctionDef(self, node):
        self.stats['function_count'] += 1
        self.generic_visit(node)
    
    def visit_ClassDef(self, node):
        self.stats['class_count'] += 1
        self.generic_visit(node)
    
    def visit_Import(self, node):
        self.stats['import_count'] += len(node.names)
        self.generic_visit(node)
    
    def visit_ImportFrom(self, node):
        self.stats['import_count'] += len(node.names)
        self.generic_visit(node)
    
    def visit_For(self, node):
        self.stats['for_loops'] += 1
        self.generic_visit(node)
    
    def visit_While(self, node):
        self.stats['while_loops'] += 1
        self.generic_visit(node)
    
    def visit_If(self, node):
        self.stats['if_statements'] += 1
        self.generic_visit(node)
    
    def visit_Assign(self, node):
        self.stats['assignments'] += 1
        self.generic_visit(node)
    
    def visit_Call(self, node):
        self.stats['function_calls'] += 1
        self.generic_visit(node)

def analyze_code(code):
    tree = ast.parse(code)
    analyzer = CodeAnalyzer()
    analyzer.visit(tree)
    
    # Count lines (approximation)
    analyzer.stats['lines_of_code'] = len(code.splitlines())
    
    return analyzer.stats

# Example usage
test_code = """
import math
import numpy as np
from datetime import datetime

def calculate_stats(numbers):
    total = sum(numbers)
    average = total / len(numbers)
    variance = sum((x - average) ** 2 for x in numbers) / len(numbers)
    return {
        'total': total,
        'average': average,
        'variance': variance,
        'std_dev': math.sqrt(variance)
    }

class DataAnalyzer:
    def __init__(self, data):
        self.data = data
    
    def process(self):
        if len(self.data) > 0:
            for item in self.data:
                print(item)
        else:
            print("No data to process")

# Main code
data = [1, 2, 3, 4, 5]
stats = calculate_stats(data)
analyzer = DataAnalyzer(data)
analyzer.process()
"""

analysis = analyze_code(test_code)
for metric, value in analysis.items():
    print(f"{metric}: {value}")
```

## 7. AST Modification Techniques

Modifying ASTs allows you to transform code in powerful ways. Here are some techniques for AST modification.

```python
import ast
import astor

# Example: Add logging to function entries and exits
class LoggingTransformer(ast.NodeTransformer):
    """Add logging statements at the beginning and end of functions."""
    
    def visit_FunctionDef(self, node):
        # Create a log statement for function entry
        entry_log = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[ast.Constant(value=f"Entering function {node.name}")],
                keywords=[]
            )
        )
        
        # Create a log statement for function exit
        exit_log = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[ast.Constant(value=f"Exiting function {node.name}")],
                keywords=[]
            )
        )
        
        # Add entry log at the beginning of the function
        node.body.insert(0, entry_log)
        
        # Add exit log before each return statement
        return_transformer = ReturnVisitor(node.name)
        node = return_transformer.visit(node)
        
        # Also add exit log at the end for functions that might not return explicitly
        node.body.append(exit_log)
        
        return node

class ReturnVisitor(ast.NodeTransformer):
    """Add logging before return statements."""
    
    def __init__(self, function_name):
        self.function_name = function_name
    
    def visit_Return(self, node):
        # Create exit log before return
        exit_log = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[ast.Constant(value=f"Exiting function {self.function_name}")],
                keywords=[]
            )
        )
        
        # Create a list of statements (log + return)
        return [exit_log, node]

# Test code
code = """
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

def greet(name):
    message = f"Hello, {name}!"
    return message
"""

# Parse, transform, and compile
tree = ast.parse(code)
transformer = LoggingTransformer()
transformed = transformer.visit(tree)
ast.fix_missing_locations(transformed)

# Convert back to source code
modified_code = astor.to_source(transformed)
print("Modified code:")
print(modified_code)

# Execute the modified code
exec(compile(transformed, '<string>', 'exec'))
print("\nTesting factorial(3):")
result = eval('factorial(3)')
print(f"Result: {result}")
```

## 8. Converting AST Back to Code

After modifying an AST, you need to convert it back to source code. There are a few approaches:

```python
import ast
import astunparse  # pip install astunparse
import astor      # pip install astor

code = """
def add(a, b):
    return a + b

result = add(5, 7)
"""

# Parse the code to AST
tree = ast.parse(code)

# Approach 1: Using astunparse
print("=== Using astunparse ===")
unparsed_code = astunparse.unparse(tree)
print(unparsed_code)

# Approach 2: Using astor (often produces cleaner code)
print("\n=== Using astor ===")
astor_code = astor.to_source(tree)
print(astor_code)

# Approach 3: Compile and execute the AST directly
# (not converting back to source, but executing the AST)
print("\n=== Compiling and executing ===")
namespace = {}
compiled = compile(tree, '<string>', 'exec')
exec(compiled, namespace)
print(f"Result: {namespace['result']}")
```

## 9. Practical Applications

Let's look at some practical applications of AST manipulation:

### Finding Security Vulnerabilities

```python
import ast

class InsecureCodeDetector(ast.NodeVisitor):
    def __init__(self):
        self.issues = []
    
    def visit_Call(self, node):
        # Check for potentially dangerous function calls
        if isinstance(node.func, ast.Name):
            if node.func.id == 'eval':
                self.issues.append({
                    'type': 'security',
                    'name': 'eval_usage',
                    'message': 'Potentially dangerous eval() call found',
                    'lineno': node.lineno
                })
            elif node.func.id == 'exec':
                self.issues.append({
                    'type': 'security',
                    'name': 'exec_usage',
                    'message': 'Potentially dangerous exec() call found',
                    'lineno': node.lineno
                })
        
        # Check for SQL injection vulnerabilities
        if isinstance(node.func, ast.Attribute):
            if node.func.attr in ['execute', 'executemany']:
                # Check for string concatenation in arguments
                for arg in node.args:
                    if isinstance(arg, ast.BinOp) and isinstance(arg.op, ast.Add):
                        if any(isinstance(n, ast.Name) for n in [arg.left, arg.right]):
                            self.issues.append({
                                'type': 'security',
                                'name': 'sql_injection',
                                'message': 'Possible SQL injection vulnerability',
                                'lineno': node.lineno
                            })
        
        self.generic_visit(node)

# Test code with security issues
code_to_check = """
def process_user_input(user_input):
    # Dangerous: executing user input
    result = eval(user_input)
    return result

def fetch_user(username):
    # Dangerous: SQL injection vulnerability
    cursor.execute("SELECT * FROM users WHERE username = '" + username + "'")
    return cursor.fetchone()

def safe_fetch_user(username):
    # Safe: using parameterized queries
    cursor.execute("SELECT * FROM users WHERE username = ?", (username,))
    return cursor.fetchone()
"""

tree = ast.parse(code_to_check)
detector = InsecureCodeDetector()
detector.visit(tree)

for issue in detector.issues:
    print(f"Line {issue['lineno']}: {issue['message']}")
```

### Creating a Simple Code Formatter

```python
import ast
import astor

class SimpleFormatter(ast.NodeVisitor):
    def __init__(self):
        self.import_statements = []
        self.class_definitions = []
        self.function_definitions = []
        self.other_statements = []
    
    def visit_Import(self, node):
        self.import_statements.append(node)
    
    def visit_ImportFrom(self, node):
        self.import_statements.append(node)
    
    def visit_ClassDef(self, node):
        self.class_definitions.append(node)
        # Skip visiting children since we've captured the node
    
    def visit_FunctionDef(self, node):
        if not isinstance(node.parent, ast.ClassDef):  # Only top-level functions
            self.function_definitions.append(node)
        # Skip visiting children since we've captured the node
    
    def visit_Module(self, node):
        # Add parent references to all nodes
        for parent in ast.walk(node):
            for child in ast.iter_child_nodes(parent):
                child.parent = parent
        
        # Visit all children to categorize them
        self.generic_visit(node)
        
        # Process remaining statements
        for stmt in node.body:
            if (stmt not in self.import_statements and
                stmt not in self.class_definitions and
                stmt not in self.function_definitions):
                self.other_statements.append(stmt)

def format_code(code):
    tree = ast.parse(code)
    formatter = SimpleFormatter()
    formatter.visit(tree)
    
    # Create a new AST with organized statements
    new_tree = ast.Module(
        body=(
            formatter.import_statements +
            [ast.Expr(value=ast.Constant(value=""))] +  # Empty line
            formatter.class_definitions +
            [ast.Expr(value=ast.Constant(value=""))] +  # Empty line
            formatter.function_definitions +
            [ast.Expr(value=ast.Constant(value=""))] +  # Empty line
            formatter.other_statements
        ),
        type_ignores=[]
    )
    
    # Fix line numbers and locations
    ast.fix_missing_locations(new_tree)
    
    # Convert back to source
    return astor.to_source(new_tree)

# Test with messy code
messy_code = """
def some_function():
    return "Hello world"

import random
from datetime import datetime
import os

class TestClass:
    def __init__(self):
        self.value = 42

result = some_function()
import sys

print(result)
"""

formatted = format_code(messy_code)
print(formatted)
```

## 10. Summary

Working with Python's Abstract Syntax Tree (AST) provides powerful capabilities for code analysis, transformation, and generation:

1. **AST Fundamentals**: ASTs represent code as tree structures with nodes corresponding to language constructs, enabling programmatic code analysis.

2. **Built-in Tools**: Python's `ast` module provides functionality to parse code into ASTs, traverse and modify them, and compile them back to executable code.

3. **AST Traversal**: The `NodeVisitor` and `NodeTransformer` classes enable visiting and modifying nodes in an AST, allowing for code analysis and transformation.

4. **Code Analysis**: ASTs facilitate static code analysis for detecting bugs, security vulnerabilities, enforcing style guidelines, and collecting metrics.

5. **Code Transformation**: With AST manipulation, you can implement sophisticated code transformations like adding logging, instrumentation, or optimizations.

6. **Code Generation**: ASTs can be used to generate code programmatically, which is useful for metaprogramming, domain-specific languages, and code synthesis.

7. **Real-world Applications**:
   - Static analysis tools
   - Linters and code formatters
   - Automated refactoring
   - Security vulnerability scanning
   - Code instrumentation and profiling
   - Domain-specific language processing

AST manipulation is a powerful technique that opens up advanced Python metaprogramming possibilities, helping you create tools that understand and transform code at a structural level rather than just as text.
