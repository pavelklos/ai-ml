## 1. Úvod do řetězců

V Pythonu jsou řetězce sekvence znaků uzavřené v uvozovkách. Jsou neměnné (immutable), což znamená, že jakmile jsou vytvořeny, jejich obsah nelze změnit. Řetězce jsou jedním z nejčastěji používaných datových typů pro ukládání a manipulaci s textovými daty.

```python
# Jednoduchý řetězec
zprava = "Ahoj, Pythone!"
print(zprava)  # Výstup: Ahoj, Pythone!

# Kontrola typu
print(type(zprava))  # Výstup: <class 'str'>

# Řetězce jsou neměnné - toto vytvoří nový řetězec, nezmění původní
puvodni = "Ahoj"
upraveny = puvodni + " světe"
print(puvodni)  # Výstup: Ahoj
print(upraveny)  # Výstup: Ahoj světe
```

## 2. Vytváření a zápis řetězců

Python nabízí několik způsobů vytváření řetězců pomocí jednoduchých uvozovek (`'`), dvojitých uvozovek (`"`) nebo trojitých uvozovek (`'''` nebo `"""`) pro víceřádkové řetězce.

```python
# Různé způsoby vytváření řetězců
jednoduche_uvozovky = 'Python Programování'
dvojite_uvozovky = "Python Programování"

# Oboje je naprosto stejné
print(jednoduche_uvozovky == dvojite_uvozovky)  # Výstup: True

# Víceřádkové řetězce pomocí trojitých uvozovek
vice_radkovy = """Toto je víceřádkový řetězec.
Rozprostírá se přes více řádků.
Velmi užitečné pro dokumentaci."""
print(vice_radkovy)

# Escape znaky
s_uvozovkami = "Řekla, \"Python je zábavný!\""
print(s_uvozovkami)  # Výstup: Řekla, "Python je zábavný!"

# Surové řetězce (ignorují escape znaky)
surovy_retezec = r"C:\Users\jmeno\Dokumenty"
print(surovy_retezec)  # Výstup: C:\Users\jmeno\Dokumenty
```

## 3. Indexování a řezání řetězců

K řetězcům v Pythonu lze přistupovat pomocí indexů (začínají od 0) a řezy umožňují extrahovat části řetězců.

```python
text = "Python Programování"

# Indexování (přístup k jednotlivým znakům)
print(text[0])   # Výstup: P
print(text[7])   # Výstup: P
print(text[-1])  # Výstup: í (záporné indexy počítají od konce)

# Řezání (extrakce částí řetězců)
print(text[0:6])    # Výstup: Python
print(text[7:])     # Výstup: Programování
print(text[:6])     # Výstup: Python
print(text[-13:])   # Výstup: Programování

# Krok (stride)
print(text[::2])    # Výstup: Pto rgaoáí (každý druhý znak)
print(text[::-1])   # Výstup: ínávomargorP nohtyP (otočení řetězce)
```

## 4. Běžné metody řetězců

Python poskytuje mnoho vestavěných metod pro manipulaci s řetězci:

```python
text = "Python Programování"

# Převod velikosti písmen
print(text.upper())      # Výstup: PYTHON PROGRAMOVÁNÍ
print(text.lower())      # Výstup: python programování
print(text.title())      # Výstup: Python Programování
print(text.capitalize()) # Výstup: Python programování

# Vyhledávání
print(text.find("Pro"))        # Výstup: 7 (index prvního výskytu)
print(text.count("m"))         # Výstup: 1 (počet výskytů)
print("Pro" in text)           # Výstup: True (test členství)

# Nahrazování
print(text.replace("Python", "Java"))  # Výstup: Java Programování

# Rozdělování a spojování
slova = text.split()
print(slova)                          # Výstup: ['Python', 'Programování']
print("-".join(slova))                # Výstup: Python-Programování

# Odstranění bílých znaků
mezery = "   Python   "
print(mezery.strip())                 # Výstup: Python
print(mezery.lstrip())                # Výstup: Python   
print(mezery.rstrip())                # Výstup:    Python

# Kontrola vlastností řetězce
print("Python123".isalnum())          # Výstup: True (alfanumerické)
print("Python".isalpha())             # Výstup: True (pouze písmena)
print("123".isdigit())                # Výstup: True (číslice)
print("PYTHON".isupper())             # Výstup: True (vše velkými písmeny)
print("python".islower())             # Výstup: True (vše malými písmeny)
```

## 5. Techniky formátování řetězců

Python poskytuje několik způsobů, jak formátovat řetězce:

```python
jmeno = "Alice"
vek = 30

# 1. Spojování řetězců
zprava = "Jmenuji se " + jmeno + " a je mi " + str(vek) + " let."
print(zprava)

# 2. Operátor % (starý styl)
zprava = "Jmenuji se %s a je mi %d let." % (jmeno, vek)
print(zprava)

# 3. Metoda str.format()
zprava = "Jmenuji se {} a je mi {} let.".format(jmeno, vek)
print(zprava)
zprava = "Jmenuji se {0} a je mi {1} let. {0} je moje jméno.".format(jmeno, vek)
print(zprava)
zprava = "Jmenuji se {jmeno} a je mi {vek} let.".format(jmeno=jmeno, vek=vek)
print(zprava)

# 4. f-řetězce (Python 3.6+, doporučeno)
zprava = f"Jmenuji se {jmeno} a je mi {vek} let."
print(zprava)
zprava = f"Jmenuji se {jmeno} a je mi {vek * 12} měsíců."
print(zprava)

# Formátování čísel
pi = 3.14159
print(f"Pí zaokrouhlené na 2 desetinná místa: {pi:.2f}")  # Výstup: Pí zaokrouhlené na 2 desetinná místa: 3.14
```

## 6. Spojování řetězců a operace

Řetězce lze kombinovat a manipulovat s nimi pomocí různých operátorů:

```python
# Spojování řetězců pomocí +
jmeno = "Jan"
prijmeni = "Novák"
cele_jmeno = jmeno + " " + prijmeni
print(cele_jmeno)  # Výstup: Jan Novák

# Opakování řetězců pomocí *
oddelovac = "-" * 20
print(oddelovac)  # Výstup: --------------------

# Porovnávání řetězců
print("jablko" < "banán")  # Výstup: False (lexikografické porovnání)
print("Jablko" < "jablko")   # Výstup: True (velká písmena předcházejí malým)

# Operátory členství
veta = "Python je úžasný"
print("Python" in veta)  # Výstup: True
print("Java" not in veta)  # Výstup: True

# Délka řetězce
print(len(veta))  # Výstup: 16
```

## 7. Regulární výrazy pro pokročilé zpracování řetězců

Pro složitější úlohy zpracování řetězců poskytuje modul `re` v Pythonu výkonné nástroje pro hledání a manipulaci se vzory:

```python
import re

text = "Kontaktujte nás na info@priklad.cz nebo podpora@firma.org"

# Nalezení všech e-mailových adres
emaily = re.findall(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', text)
print(emaily)  # Výstup: ['info@priklad.cz', 'podpora@firma.org']

# Nahrazení vzoru
novy_text = re.sub(r'(\w+)@(\w+)\.org', r'\1@\2.cz', text)
print(novy_text)  # Výstup: Kontaktujte nás na info@priklad.cz nebo podpora@firma.cz

# Rozdělení řetězce podle více oddělovačů
radek = "jmeno,vek:30;mesto-Praha"
casti = re.split(r'[,;:-]', radek)
print(casti)  # Výstup: ['jmeno', 'vek', '30', 'mesto', 'Praha']

# Kontrola, zda řetězec odpovídá vzoru
telefon = "123-456-7890"
if re.match(r'\d{3}-\d{3}-\d{4}', telefon):
    print("Platný formát telefonního čísla")
```

## 8. Praktické příklady manipulace s řetězci

Podívejme se na několik praktických příkladů manipulace s řetězci:

```python
# Příklad 1: Čištění uživatelského vstupu
uzivatelsky_vstup = "   Jan NOVÁK  "
vycisteny = uzivatelsky_vstup.strip().title()
print(vycisteny)  # Výstup: Jan Novák

# Příklad 2: Extrakce domény z e-mailu
email = "uzivatel@priklad.cz"
domena = email.split('@')[1]
print(domena)  # Výstup: priklad.cz

# Příklad 3: Převod z snake_case na camelCase
nazev_promenne = "jmeno_uzivatele"
casti = nazev_promenne.split('_')
camel_case = casti[0] + ''.join(cast.title() for cast in casti[1:])
print(camel_case)  # Výstup: jmenoUzivatele

# Příklad 4: Validace hesla
def overheslo(heslo):
    ma_velka = any(c.isupper() for c in heslo)
    ma_mala = any(c.islower() for c in heslo)
    ma_cislo = any(c.isdigit() for c in heslo)
    ma_specialni = any(not c.isalnum() for c in heslo)
    dostatecna_delka = len(heslo) >= 8
    
    return ma_velka and ma_mala and ma_cislo and ma_specialni and dostatecna_delka

print(overheslo("Abc123!@"))  # Výstup: True
print(overheslo("heslo"))    # Výstup: False

# Příklad 5: Vytvoření jednoduchého textového analyzátoru
def analyzuj_text(text):
    pocet_znaku = len(text)
    pocet_slov = len(text.split())
    pocet_radku = len(text.split('\n'))
    
    return {
        "znaky": pocet_znaku,
        "slova": pocet_slov,
        "řádky": pocet_radku
    }

ukazka = """Python je programovací jazyk.
Je snadné se ho naučit a používat.
Python je široce používán v datové vědě."""

analyza = analyzuj_text(ukazka)
print(analyza)
# Výstup: {'znaky': 103, 'slova': 18, 'řádky': 3}
```
