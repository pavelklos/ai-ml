## 1. Introduction to File I/O

File Input/Output (I/O) operations allow Python programs to interact with files on your computer. These operations are essential for tasks like reading configuration files, saving program data, processing large datasets, and more. Python provides built-in functions and methods to make file operations straightforward.

```python
# File operations allow you to:
# - Read data from files
# - Write data to files
# - Append to existing files
# - Process files line by line
# - Work with different file formats

# Python uses file objects to interact with files
# Basic file operations follow this pattern:
# 1. Open the file
# 2. Perform operations (read or write)
# 3. Close the file
```

## 2. Opening and Closing Files

Before you can read from or write to a file, you need to open it using the built-in `open()` function. After you're done, it's important to close the file to free up system resources.

```python
# Basic syntax for opening a file
file = open('example.txt', 'r')  # 'r' means read mode

# Always close files after you're done
file.close()

# Checking if a file exists before opening
import os

file_path = 'data.txt'
if os.path.exists(file_path):
    file = open(file_path, 'r')
    # Do something with the file
    file.close()
else:
    print(f"The file {file_path} does not exist")

# Getting information about a file
if os.path.exists(file_path):
    file_size = os.path.getsize(file_path)  # Size in bytes
    print(f"File size: {file_size} bytes")
    
    # Check if it's a file or directory
    if os.path.isfile(file_path):
        print(f"{file_path} is a file")
    elif os.path.isdir(file_path):
        print(f"{file_path} is a directory")
```

## 3. Reading from Files

Python offers several methods to read file contents, allowing you to read the entire file at once or line by line.

```python
# Reading the entire file at once
file = open('example.txt', 'r')
content = file.read()
print(content)
file.close()

# Reading a specific number of characters
file = open('example.txt', 'r')
first_10_chars = file.read(10)  # Read first 10 characters
print(first_10_chars)
file.close()

# Reading line by line
file = open('example.txt', 'r')
line = file.readline()  # Read first line
print(line)
file.close()

# Reading all lines into a list
file = open('example.txt', 'r')
lines = file.readlines()  # Returns a list of lines
for line in lines:
    print(line.strip())  # strip() removes trailing newline characters
file.close()

# More efficient way to iterate through lines
file = open('example.txt', 'r')
for line in file:  # File objects are iterable
    print(line.strip())
file.close()
```

## 4. Writing to Files

Python provides methods to write data to files. You can create new files, overwrite existing ones, or append to them.

```python
# Writing to a file (creates or overwrites the file)
file = open('output.txt', 'w')
file.write("Hello, World!\n")
file.write("This is a new line.")
file.close()

# Writing multiple lines at once
lines = ["First line\n", "Second line\n", "Third line\n"]
file = open('output.txt', 'w')
file.writelines(lines)  # Writes all lines at once
file.close()

# Appending to an existing file
file = open('output.txt', 'a')  # 'a' is for append mode
file.write("\nThis text is appended at the end.")
file.close()
```

## 5. File Modes

When opening a file, you specify a mode that determines how the file will be used. Python offers several file modes for different operations.

```python
# Common file modes:
# 'r' - Read (default). Opens file for reading.
# 'w' - Write. Creates a new file or truncates an existing one.
# 'a' - Append. Opens for writing, appending to the end if file exists.
# 'x' - Exclusive creation. Fails if file already exists.
# 'b' - Binary mode.
# 't' - Text mode (default).
# '+' - Open for updating (reading and writing)

# Examples of different modes

# Binary mode for non-text files
with open('image.jpg', 'rb') as file:
    image_data = file.read()
    # Process binary data

# Read and write mode
with open('data.txt', 'r+') as file:
    content = file.read()
    file.seek(0)  # Move to beginning of file
    file.write("New content\n" + content)

# Write binary mode (useful for creating image/binary files)
with open('newfile.bin', 'wb') as file:
    file.write(b'\x00\x01\x02\x03')  # Write raw bytes
```

## 6. Working with Context Managers

Using the `with` statement (context manager) is the recommended way to handle files in Python. It automatically takes care of closing the file when you're done, even if an exception occurs.

```python
# Using a context manager to handle files
with open('example.txt', 'r') as file:
    content = file.read()
    print(content)
# No need to call file.close() - it's done automatically

# Reading and writing with context managers
with open('input.txt', 'r') as input_file:
    with open('output.txt', 'w') as output_file:
        for line in input_file:
            # Process line and write to output file
            output_file.write(line.upper())

# Combining multiple context managers
with open('input.txt', 'r') as input_file, open('output.txt', 'w') as output_file:
    content = input_file.read()
    output_file.write(content.upper())
```

## 7. File Position and Navigation

Python provides methods to navigate within a file, allowing you to control where you read from or write to.

```python
# Getting the current position in a file
with open('example.txt', 'r') as file:
    print(f"Current position: {file.tell()}")  # Should be 0
    data = file.read(10)
    print(f"After reading 10 chars: {file.tell()}")  # Should be 10

# Moving to a specific position in a file
with open('example.txt', 'r') as file:
    file.seek(5)  # Move to the 6th byte (0-indexed)
    data = file.read(10)
    print(data)  # 10 characters starting from position 5
    
    # seek(offset, whence) where whence is:
    # 0: from start (default)
    # 1: from current position
    # 2: from end
    
    file.seek(0)  # Back to start
    file.seek(0, 2)  # Seek to end of file
    
    # Get file size by seeking to end and checking position
    file.seek(0, 2)
    size = file.tell()
    print(f"File size: {size} bytes")
```

## 8. Working with Different File Formats

Python can handle various file formats beyond plain text files, including CSV, JSON, and more.

```python
# Working with CSV files
import csv

# Reading CSV files
with open('data.csv', 'r', newline='') as csvfile:
    csv_reader = csv.reader(csvfile)
    for row in csv_reader:
        print(', '.join(row))

# Writing CSV files
with open('output.csv', 'w', newline='') as csvfile:
    csv_writer = csv.writer(csvfile)
    csv_writer.writerow(['Name', 'Age', 'City'])
    csv_writer.writerow(['Alice', '25', 'New York'])
    csv_writer.writerow(['Bob', '30', 'Boston'])

# Working with JSON files
import json

# Reading JSON
with open('data.json', 'r') as jsonfile:
    data = json.load(jsonfile)
    print(data)

# Writing JSON
person = {
    'name': 'John',
    'age': 30,
    'city': 'New York',
    'languages': ['Python', 'JavaScript', 'C++']
}

with open('person.json', 'w') as jsonfile:
    json.dump(person, jsonfile, indent=4)  # Pretty-print with indentation

# Working with pickle (for Python objects)
import pickle

# Serializing Python objects to a file
data = {'a': [1, 2.0, 3, 4+6j],
        'b': ('string', u'Unicode string'),
        'c': None}

with open('data.pickle', 'wb') as f:
    pickle.dump(data, f)

# Reading Python objects from a file
with open('data.pickle', 'rb') as f:
    loaded_data = pickle.load(f)
    print(loaded_data)
```
