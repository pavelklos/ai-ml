## 1. Úvod do seznamů

Seznamy v Pythonu jsou uspořádané, měnitelné kolekce, které mohou uchovávat více položek různých datových typů. Jsou jednou z nejvšestrannějších a nejpoužívanějších datových struktur v Pythonu. Seznamy jsou označeny hranatými závorkami `[]` a prvky jsou odděleny čárkami.

```python
# Seznam může obsahovat různé datové typy
smiseny_seznam = [1, "ahoj", 3.14, True, None]
print(smiseny_seznam)  # Výstup: [1, 'ahoj', 3.14, True, None]

# Seznamy jsou měnitelné (lze je měnit po vytvoření)
cisla = [1, 2, 3]
cisla[0] = 10
print(cisla)  # Výstup: [10, 2, 3]

# Seznamy zachovávají pořadí
barvy = ["červená", "zelená", "modrá"]
print(barvy[0])  # Výstup: červená
print(barvy[2])  # Výstup: modrá
```

## 2. Vytváření seznamů a přístup k nim

Existuje několik způsobů, jak vytvářet seznamy v Pythonu. K prvkům seznamu můžete přistupovat pomocí indexování, které začíná od 0 pro první prvek.

```python
# Vytváření seznamů
prazdny_seznam = []                    # Prázdný seznam
cisla = [1, 2, 3, 4, 5]                # Seznam celých čísel
ovoce = ["jablko", "banán", "třešeň"]  # Seznam řetězců
smiseny = [1, "ahoj", 3.14]            # Smíšené typy

# Vytvoření seznamu pomocí konstruktoru list()
pismena = list("abcde")      # Převede řetězec na seznam znaků
print(pismena)               # Výstup: ['a', 'b', 'c', 'd', 'e']

# Vytvoření seznamu pomocí range()
cisla = list(range(1, 6))    # Vytvoří [1, 2, 3, 4, 5]
print(cisla)

# Přístup k prvkům seznamu pomocí indexu
ovoce = ["jablko", "banán", "třešeň", "datle"]
print(ovoce[0])    # Výstup: jablko
print(ovoce[2])    # Výstup: třešeň

# Negativní indexování (počítá od konce)
print(ovoce[-1])   # Výstup: datle (poslední prvek)
print(ovoce[-2])   # Výstup: třešeň (předposlední prvek)

# Řezání seznamů [začátek:konec:krok]
print(ovoce[1:3])    # Výstup: ['banán', 'třešeň']
print(ovoce[:2])     # Výstup: ['jablko', 'banán']
print(ovoce[2:])     # Výstup: ['třešeň', 'datle']
print(ovoce[::2])    # Výstup: ['jablko', 'třešeň'] (každý druhý prvek)
print(ovoce[::-1])   # Výstup: ['datle', 'třešeň', 'banán', 'jablko'] (obrácený seznam)
```

## 3. Základní operace se seznamy

Python poskytuje různé operace, které lze provádět se seznamy:

```python
# Délka seznamu
ovoce = ["jablko", "banán", "třešeň"]
print(len(ovoce))  # Výstup: 3

# Spojování
seznam1 = [1, 2, 3]
seznam2 = [4, 5, 6]
spojeny = seznam1 + seznam2
print(spojeny)  # Výstup: [1, 2, 3, 4, 5, 6]

# Opakování
nuly = [0] * 5
print(nuly)  # Výstup: [0, 0, 0, 0, 0]

# Kontrola členství
ovoce = ["jablko", "banán", "třešeň"]
print("banán" in ovoce)  # Výstup: True
print("pomeranč" in ovoce)  # Výstup: False

# Iterace přes seznam
for ovoce_polozka in ovoce:
    print(ovoce_polozka)

# Iterace s indexem
for i, ovoce_polozka in enumerate(ovoce):
    print(f"Index {i}: {ovoce_polozka}")

# Porovnávání seznamů
seznam1 = [1, 2, 3]
seznam2 = [1, 2, 3]
seznam3 = [3, 2, 1]
print(seznam1 == seznam2)  # Výstup: True
print(seznam1 == seznam3)  # Výstup: False
```

## 4. Metody seznamů

Python poskytuje mnoho vestavěných metod pro manipulaci se seznamy:

```python
# Přidání prvků
ovoce = ["jablko", "banán"]
ovoce.append("třešeň")           # Přidání na konec
print(ovoce)  # Výstup: ['jablko', 'banán', 'třešeň']

ovoce.insert(1, "pomeranč")      # Vložení na pozici
print(ovoce)  # Výstup: ['jablko', 'pomeranč', 'banán', 'třešeň']

ovoce.extend(["hrozny", "kiwi"])  # Přidání více položek
print(ovoce)  # Výstup: ['jablko', 'pomeranč', 'banán', 'třešeň', 'hrozny', 'kiwi']

# Odstranění prvků
ovoce.remove("banán")       # Odstranění podle hodnoty
print(ovoce)  # Výstup: ['jablko', 'pomeranč', 'třešeň', 'hrozny', 'kiwi']

vyjmuty = ovoce.pop()       # Odstranění a vrácení posledního prvku
print(vyjmuty)   # Výstup: kiwi
print(ovoce)     # Výstup: ['jablko', 'pomeranč', 'třešeň', 'hrozny']

vyjmuty = ovoce.pop(1)      # Odstranění prvku na indexu
print(vyjmuty)   # Výstup: pomeranč
print(ovoce)     # Výstup: ['jablko', 'třešeň', 'hrozny']

ovoce.clear()               # Odstranění všech položek
print(ovoce)     # Výstup: []

# Řazení
cisla = [3, 1, 4, 1, 5, 9, 2, 6]
cisla.sort()                # Seřazení na místě (vzestupně)
print(cisla)  # Výstup: [1, 1, 2, 3, 4, 5, 6, 9]

cisla.sort(reverse=True)    # Seřazení sestupně
print(cisla)  # Výstup: [9, 6, 5, 4, 3, 2, 1, 1]

cisla.reverse()             # Obrácení seznamu
print(cisla)  # Výstup: [1, 1, 2, 3, 4, 5, 6, 9]

# Hledání prvků
ovoce = ["jablko", "banán", "třešeň", "banán"]
print(ovoce.index("banán"))        # Výstup: 1 (první výskyt)
print(ovoce.count("banán"))        # Výstup: 2 (počet výskytů)

# Kopírování seznamů
original = [1, 2, 3]
kopie1 = original.copy()      # Metoda 1: použití copy()
kopie2 = list(original)       # Metoda 2: použití list()
kopie3 = original[:]          # Metoda 3: použití řezání

original[0] = 100
print(original)  # Výstup: [100, 2, 3]
print(kopie1)    # Výstup: [1, 2, 3] (nezměněno)
```

## 5. Seznamová porozumění (list comprehensions)

Seznamová porozumění poskytují stručný způsob vytváření seznamů. Skládají se z hranatých závorek obsahujících výraz následovaný klauzulí for a volitelnými klauzulemi if.

```python
# Základní seznamové porozumění
ctverce = [x**2 for x in range(1, 6)]
print(ctverce)  # Výstup: [1, 4, 9, 16, 25]

# S podmínkovou logikou
sude_ctverce = [x**2 for x in range(1, 11) if x % 2 == 0]
print(sude_ctverce)  # Výstup: [4, 16, 36, 64, 100]

# Více podmínek
cisla = [x for x in range(1, 20) if x % 2 == 0 if x % 3 == 0]
print(cisla)  # Výstup: [6, 12, 18]

# If-else v seznamovém porozumění
vysledky = ["Sudé" if x % 2 == 0 else "Liché" for x in range(5)]
print(vysledky)  # Výstup: ['Sudé', 'Liché', 'Sudé', 'Liché', 'Sudé']

# Práce s řetězci
slova = ["ahoj", "svět", "python"]
velka_slova = [slovo.upper() for slovo in slova]
print(velka_slova)  # Výstup: ['AHOJ', 'SVĚT', 'PYTHON']

# Zploštění 2D seznamu
matice = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
zplošteno = [cislo for radek in matice for cislo in radek]
print(zplošteno)  # Výstup: [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 6. Práce s vnořenými seznamy

Vnořené seznamy (seznamy seznamů) se používají k reprezentaci vícerozměrných struktur jako jsou matice:

```python
# Vytvoření vnořeného seznamu
matice = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Přístup k prvkům ve vnořených seznamech
print(matice[0])      # Výstup: [1, 2, 3]
print(matice[1][2])   # Výstup: 6

# Úprava prvků
matice[0][1] = 20
print(matice)  # Výstup: [[1, 20, 3], [4, 5, 6], [7, 8, 9]]

# Iterace přes vnořený seznam
for radek in matice:
    for prvek in radek:
        print(prvek, end=" ")
    print()  # Nový řádek po každém řádku

# Vytvoření 3x3 jednotkové matice pomocí seznamového porozumění
velikost = 3
jednotkova = [[1 if i == j else 0 for j in range(velikost)] for i in range(velikost)]
print(jednotkova)  # Výstup: [[1, 0, 0], [0, 1, 0], [0, 0, 1]]

# Transpozice matice
transpozice = [[radek[i] for radek in matice] for i in range(3)]
print(transpozice)  # Výstup: [[1, 4, 7], [20, 5, 8], [3, 6, 9]]
```

## 7. Běžné vzory a algoritmy pro seznamy

Zde jsou některé běžné vzory a algoritmy používané s Python seznamy:

```python
# Nalezení maximální/minimální hodnoty
cisla = [3, 1, 4, 1, 5, 9, 2, 6]
print(max(cisla))  # Výstup: 9
print(min(cisla))  # Výstup: 1

# Sčítání hodnot
print(sum(cisla))  # Výstup: 31

# Filtrování seznamu
suda_cisla = [x for x in cisla if x % 2 == 0]
print(suda_cisla)  # Výstup: [4, 2, 6]

# Vlastní filtrování
def je_prvocislo(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

prvocisla = list(filter(je_prvocislo, range(20)))
print(prvocisla)  # Výstup: [2, 3, 5, 7, 11, 13, 17, 19]

# Mapování operací
umocneno = list(map(lambda x: x**2, cisla))
print(umocneno)  # Výstup: [9, 1, 16, 1, 25, 81, 4, 36]

# Odstranění duplicit se zachováním pořadí
def odstran_duplicity(lst):
    vysledek = []
    for polozka in lst:
        if polozka not in vysledek:
            vysledek.append(polozka)
    return vysledek

duplikovane = [1, 2, 2, 3, 4, 3, 5]
print(odstran_duplicity(duplikovane))  # Výstup: [1, 2, 3, 4, 5]

# Alternativní způsob odstranění duplicit (pomocí dict.fromkeys)
print(list(dict.fromkeys(duplikovane)))  # Výstup: [1, 2, 3, 4, 5]

# Počítání výskytů
from collections import Counter
pocty = Counter(duplikovane)
print(pocty)  # Výstup: Counter({2: 2, 3: 2, 1: 1, 4: 1, 5: 1})
```

## 8. Výkonnostní aspekty seznamů

Seznamy jsou všestranné, ale mají určité výkonnostní charakteristiky:

```python
import time
import sys

# Využití paměti
prazdny_seznam = []
print(sys.getsizeof(prazdny_seznam))  # Základní velikost prázdného seznamu (typicky 56 bajtů)

# Využití paměti roste s velikostí seznamu
for i in range(5):
    prazdny_seznam.append(i)
    print(f"{len(prazdny_seznam)} položek: {sys.getsizeof(prazdny_seznam)} bajtů")

# Porovnání výkonu: append vs. spojování
def test_append():
    lst = []
    for i in range(10000):
        lst.append(i)
    return lst

def test_spojovani():
    lst = []
    for i in range(10000):
        lst = lst + [i]  # Vytvoří nový seznam pokaždé
    return lst

start = time.time()
test_append()
print(f"Čas append: {time.time() - start:.6f} sekund")

start = time.time()
test_spojovani()
print(f"Čas spojování: {time.time() - start:.6f} sekund")

# Výkon operací se seznamy
# O(1) operace: append, pop z konce, get/set podle indexu
```

## 9. Shrnutí

V této sekci jsme se zabývali:

- **Základy seznamů**: Seznamy v Pythonu jsou měnitelné, uspořádané kontejnery, které mohou uchovávat položky jakéhokoli datového typu.
- **Vytváření a přístup**: Vytváření seznamů pomocí hranatých závorek, konstruktoru `list()` a přístup k prvkům pomocí indexování a řezání.
- **Základní operace**: Spojování, opakování, testování členství a iterace.
- **Metody seznamů**: Vestavěné funkce pro úpravu seznamů jako `append()`, `insert()`, `remove()`, `sort()` a `reverse()`.
- **Seznamová porozumění**: Stručný způsob vytváření seznamů pomocí jediného řádku kódu.
- **Vnořené seznamy**: Práce s vícerozměrnými datovými strukturami.
- **Běžné vzory**: Filtrování, mapování, hledání maxim/minim a odstranění duplicit.
- **Výkonnostní aspekty**: Porozumění výkonnostním charakteristikám různých operací se seznamy.

Seznamy jsou jednou z nejvšestrannějších datových struktur v Pythonu a jsou nezbytné pro ukládání kolekcí dat. Poskytují širokou škálu operací, které usnadňují manipulaci s daty intuitivním způsobem. Pro konkrétní případy použití však mohou být vhodnější jiné datové struktury, jako jsou množiny, n-tice nebo slovníky.
