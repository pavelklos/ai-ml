## 1. Úvod do dekorátorů

Dekorátory jsou mocnou funkcí v Pythonu, která umožňuje upravovat nebo rozšiřovat funkce a metody bez změny jejich zdrojového kódu. Jsou založeny na konceptu funkcí jako objektů první třídy v Pythonu, což znamená, že funkce lze předávat jako argumenty, vracet z jiných funkcí a přiřazovat proměnným.

```python
# V Pythonu jsou funkce objekty první třídy
def pozdrav(jmeno):
    return f"Ahoj, {jmeno}!"

# Funkce lze přiřadit proměnným
rekni_ahoj = pozdrav
print(rekni_ahoj("Alice"))  # Výstup: Ahoj, Alice!

# Funkce lze předat jako argumenty
def aplikuj_funkci(funkce, hodnota):
    return funkce(hodnota)

print(aplikuj_funkci(pozdrav, "Bob"))  # Výstup: Ahoj, Bob!

# Funkce mohou vracet jiné funkce
def vytvor_pozdravnou_funkci(pozdrav):
    def pozdrav_osobu(jmeno):
        return f"{pozdrav}, {jmeno}!"
    return pozdrav_osobu

rekni_dobre_rano = vytvor_pozdravnou_funkci("Dobré ráno")
print(rekni_dobre_rano("Charlie"))  # Výstup: Dobré ráno, Charlie!
```

Dekorátory využívají těchto konceptů k obalení funkce jinou funkcí, čímž modifikují její chování nebo přidávají další funkcionalitu.

## 2. Základní syntaxe dekorátorů

Dekorátor je funkce, která přijímá jinou funkci jako argument, rozšiřuje její chování a vrací upravenou funkci. Základní syntaxe používá symbol `@` umístěný nad definicí funkce.

```python
# Jednoduchý dekorátor
def muj_dekorator(funkce):
    def wrapper():
        print("Něco se děje před voláním funkce.")
        funkce()
        print("Něco se děje po volání funkce.")
    return wrapper

# Použití dekorátoru se syntaxí @
@muj_dekorator
def rekni_ahoj():
    print("Ahoj!")

# Toto je ekvivalentní:
# rekni_ahoj = muj_dekorator(rekni_ahoj)

# Volání dekorované funkce
rekni_ahoj()
```

Výstup:
```
Něco se děje před voláním funkce.
Ahoj!
Něco se děje po volání funkce.
```

Dekorátory, které přijímají funkce s argumenty:

```python
def muj_dekorator(funkce):
    def wrapper(*args, **kwargs):
        print(f"Funkce {funkce.__name__} je volána s {args} a {kwargs}")
        vysledek = funkce(*args, **kwargs)
        print(f"Funkce {funkce.__name__} dokončila provedení")
        return vysledek
    return wrapper

@muj_dekorator
def secti(a, b):
    return a + b

vysledek = secti(5, 3)
print(f"Výsledek: {vysledek}")
```

Výstup:
```
Funkce secti je volána s (5, 3) a {}
Funkce secti dokončila provedení
Výsledek: 8
```

## 3. Funkční wrappery s functools.wraps

Při vytváření dekorátorů wrapper funkce nahrazuje původní funkci. To může způsobit problémy s introspekci, protože metadata původní funkce (jako jméno, docstring) jsou ztracena. Dekorátor `functools.wraps` pomáhá zachovat tato metadata.

```python
import functools

def muj_dekorator(funkce):
    @functools.wraps(funkce)  # Zachovává metadata původní funkce
    def wrapper(*args, **kwargs):
        print(f"Volám {funkce.__name__}")
        return funkce(*args, **kwargs)
    return wrapper

@muj_dekorator
def zobraz_info(jmeno, vek):
    """Zobrazí informace o osobě."""
    print(f"{jmeno} je {vek} let starý")

# Bez functools.wraps by tyto příkazy zobrazily informace o wrapperu
print(zobraz_info.__name__)  # Výstup: zobraz_info (ne "wrapper")
print(zobraz_info.__doc__)   # Výstup: Zobrazí informace o osobě.

# Volání funkce
zobraz_info("David", 30)
```

Výstup:
```
zobraz_info
Zobrazí informace o osobě.
Volám zobraz_info
David je 30 let starý
```

## 4. Dekorátory s argumenty

Můžete vytvářet dekorátory, které přijímají argumenty, přidáním další úrovně vnořování funkcí:

```python
def opakuj(n=1):
    def dekorator(funkce):
        @functools.wraps(funkce)
        def wrapper(*args, **kwargs):
            vysledky = []
            for _ in range(n):
                vysledky.append(funkce(*args, **kwargs))
            return vysledky
        return wrapper
    return dekorator

@opakuj(n=3)
def pozdrav(jmeno):
    return f"Ahoj, {jmeno}!"

print(pozdrav("Emily"))
```

Výstup:
```
['Ahoj, Emily!', 'Ahoj, Emily!', 'Ahoj, Emily!']
```

## 5. Dekorátory založené na třídách

Dekorátory lze také implementovat jako třídy pomocí metody `__call__`, která umožňuje volat objekt jako funkci:

```python
class PocitejVolani:
    def __init__(self, funkce):
        functools.update_wrapper(self, funkce)
        self.funkce = funkce
        self.pocet = 0
        
    def __call__(self, *args, **kwargs):
        self.pocet += 1
        print(f"Volání {self.pocet} funkce {self.funkce.__name__}")
        return self.funkce(*args, **kwargs)

@PocitejVolani
def rekni_ahoj(jmeno):
    return f"Ahoj, {jmeno}!"

print(rekni_ahoj("Frank"))
print(rekni_ahoj("Grace"))
print(rekni_ahoj("Helen"))
```

Výstup:
```
Volání 1 funkce rekni_ahoj
Ahoj, Frank!
Volání 2 funkce rekni_ahoj
Ahoj, Grace!
Volání 3 funkce rekni_ahoj
Ahoj, Helen!
```

## 6. Více dekorátorů

Na jednu funkci můžete aplikovat více dekorátorů. Aplikují se zdola nahoru (dekorátor nejblíže k funkci se aplikuje jako první):

```python
def tucne(funkce):
    @functools.wraps(funkce)
    def wrapper(*args, **kwargs):
        return f"<b>{funkce(*args, **kwargs)}</b>"
    return wrapper

def kurziva(funkce):
    @functools.wraps(funkce)
    def wrapper(*args, **kwargs):
        return f"<i>{funkce(*args, **kwargs)}</i>"
    return wrapper

@tucne
@kurziva
def formatovat_text(text):
    return text

# Toto je ekvivalentní:
# formatovat_text = tucne(kurziva(formatovat_text))

print(formatovat_text("Ahoj, světe!"))
```

Výstup:
```
<b><i>Ahoj, světe!</i></b>
```

## 7. Praktické aplikace

Dekorátory mají mnoho praktických využití v reálném programování v Pythonu:

### Měření času funkcí

```python
import time

def casovac(funkce):
    @functools.wraps(funkce)
    def wrapper(*args, **kwargs):
        cas_zacatku = time.time()
        vysledek = funkce(*args, **kwargs)
        cas_konce = time.time()
        print(f"Funkce {funkce.__name__} trvala {cas_konce - cas_zacatku:.4f} sekund")
        return vysledek
    return wrapper

@casovac
def pomala_funkce():
    time.sleep(1)
    return "Zpracování dokončeno"

pomala_funkce()
```

### Autentizace a autorizace

```python
def vyzadovat_autentizaci(funkce):
    @functools.wraps(funkce)
    def wrapper(uzivatel, *args, **kwargs):
        if not uzivatel.je_autentizovan:
            raise PermissionError("Vyžadována autentizace")
        return funkce(uzivatel, *args, **kwargs)
    return wrapper

class Uzivatel:
    def __init__(self, jmeno, je_autentizovan=False):
        self.jmeno = jmeno
        self.je_autentizovan = je_autentizovan

@vyzadovat_autentizaci
def zobrazit_chraneny_zdroj(uzivatel):
    return f"Vítej, {uzivatel.jmeno}! Zde jsou tvá chráněná data."

# Test s neautentizovaným uživatelem
try:
    uzivatel = Uzivatel("Jan", je_autentizovan=False)
    print(zobrazit_chraneny_zdroj(uzivatel))
except PermissionError as e:
    print(f"Chyba: {e}")

# Test s autentizovaným uživatelem
uzivatel = Uzivatel("Jan", je_autentizovan=True)
print(zobrazit_chraneny_zdroj(uzivatel))
```

### Ukládání výsledků do mezipaměti (Memoizace)

```python
def memoizace(funkce):
    cache = {}
    
    @functools.wraps(funkce)
    def wrapper(*args):
        if args not in cache:
            cache[args] = funkce(*args)
            print(f"Vypočítán výsledek pro {args}")
        else:
            print(f"Použit výsledek z mezipaměti pro {args}")
        return cache[args]
    
    return wrapper

@memoizace
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))  # Vypočítá všechny hodnoty
print(fibonacci(10))  # Použije výsledek z mezipaměti
```

## 8. Běžné vzory a osvědčené postupy

### Šablonové dekorátory

Vytvoření šablony pro sestavení podobných dekorátorů:

```python
def vytvor_dekorator(zprava_pred, zprava_po):
    def dekorator(funkce):
        @functools.wraps(funkce)
        def wrapper(*args, **kwargs):
            print(zprava_pred)
            vysledek = funkce(*args, **kwargs)
            print(zprava_po)
            return vysledek
        return wrapper
    return dekorator

# Vytvoření konkrétních dekorátorů
log_vstup_vystup = vytvor_dekorator("Vstupuji do funkce", "Vystupuji z funkce")
ladici_vypis = vytvor_dekorator("Ladění: volání funkce", "Ladění: funkce dokončena")

@log_vstup_vystup
def zpracovat_data(data):
    print(f"Zpracovávám {data}...")
    return f"Zpracováno: {data}"

@ladici_vypis
def analyzovat(data):
    print(f"Analyzuji {data}...")
    return f"Výsledky analýzy pro {data}"

print(zpracovat_data("záznamy zákazníků"))
print()
print(analyzovat("prodejní údaje"))
```

### Osvědčené postupy

1. **Vždy používejte `functools.wraps`** pro zachování metadat dekorované funkce.
2. **Udržujte dekorátory jednoduché** - měly by dodržovat princip jediné odpovědnosti.
3. **Správně zpracovávejte výjimky** - nenechte své dekorátory pohltit výjimky.
4. **Dokumentujte, jak dekorátory upravují chování funkce** v docstrinzích.

```python
def log_vyjimky(funkce):
    """
    Dekorátor, který zaznamenává výjimky vyvolané dekorovanou funkcí.
    
    Args:
        funkce: Funkce k dekorování
        
    Returns:
        Wrapper funkce, která zaznamenává výjimky
    """
    @functools.wraps(funkce)
    def wrapper(*args, **kwargs):
        try:
            return funkce(*args, **kwargs)
        except Exception as e:
            print(f"Výjimka v {funkce.__name__}: {e}")
            raise  # Znovu vyvolá výjimku po zaznamenání
    return wrapper

@log_vyjimky
def deleni(a, b):
    """Vydělí a číslem b a vrátí výsledek."""
    return a / b

try:
    print(deleni(10, 0))
except ZeroDivisionError:
    print("Zachycena chyba dělení v hlavním kódu")
```

## 9. Ladění dekorovaných funkcí

Ladění dekorovaných funkcí může být náročné, protože přidáváte vrstvy nepřímého volání. Zde jsou některé techniky:

```python
def ladici_dekorator(funkce):
    @functools.wraps(funkce)
    def wrapper(*args, **kwargs):
        args_repr = [repr(a) for a in args]
        kwargs_repr = [f"{k}={v!r}" for k, v in kwargs.items()]
        podpis = ", ".join(args_repr + kwargs_repr)
        print(f"Volám {funkce.__name__}({podpis})")
        
        vysledek = funkce(*args, **kwargs)
        
        print(f"{funkce.__name__} vrátila {vysledek!r}")
        return vysledek
    return wrapper

@ladici_dekorator
def vypocet_celkem(polozky, sazba_dane=0.1):
    celkem = sum(polozky)
    return celkem * (1 + sazba_dane)

vypocet_celkem([10, 20, 30], sazba_dane=0.05)
```

Další technikou je poskytnutí způsobu, jak deaktivovat dekorátory během ladění:

```python
def ladici_dekorator(aktivni=True):
    def dekorator(funkce):
        @functools.wraps(funkce)
        def wrapper(*args, **kwargs):
            if aktivni:
                print(f"Volám {funkce.__name__}")
                vysledek = funkce(*args, **kwargs)
                print(f"{funkce.__name__} vrátila {vysledek}")
                return vysledek
            else:
                # Přeskočit dekoraci, pokud není aktivní
                return funkce(*args, **kwargs)
        return wrapper
    return dekorator

# Ladění lze přepínat
DEBUG = False  # Nastavení na True pro povolení ladění

@ladici_dekorator(aktivni=DEBUG)
def nasobit(a, b):
    return a * b

print(nasobit(4, 5))  # Žádný ladící výstup, když je DEBUG False
```

## 10. Shrnutí

Dekorátory jsou mocnou funkcí v Pythonu, která umožňuje:

1. **Opakované použití kódu** - Aplikace běžného chování na více funkcí
2. **Oddělení zájmů** - Udržení základní funkcionality odděleně od pomocného chování
3. **Čistý, čitelný kód** - Aplikace průřezové funkcionality bez přeplnění těla funkcí

Klíčové koncepty, které je třeba si zapamatovat:

- Dekorátor je funkce, která přijímá funkci a vrací vylepšenou funkci
- Syntaxe `@dekorator` je syntaktický cukr pro `funkce = dekorator(funkce)`
- Používejte `functools.wraps` pro zachování metadat funkce
- Dekorátory mohou přijímat argumenty přidáním další úrovně vnořování funkcí
- Dekorátory založené na třídách implementují metodu `__call__`
- Více dekorátorů se aplikuje zdola nahoru
- Běžné případy použití zahrnují časování, autentizaci, protokolování a ukládání do mezipaměti

Dekorátory představují flexibilitu Pythonu a filozofii čistého, znovupoužitelného kódu. Pochopením a efektivním používáním dekorátorů můžete psát udržovatelnější a elegantnější Python programy.
