## 1. Introduction to File Formats

Python provides excellent support for handling various file formats, which is essential for data processing, storage, and exchange. In this guide, we'll focus on three of the most commonly used formats:

- **CSV** (Comma Separated Values): Simple text format for tabular data
- **JSON** (JavaScript Object Notation): Versatile format for structured data
- **Pickle**: Python-specific binary format for serializing Python objects

Each format has its strengths and appropriate use cases. Let's explore how to work with them effectively in Python.

```python
# Basic file operations in Python (review)
# Opening a text file
with open('example.txt', 'w') as file:
    file.write('Hello, file handling in Python!')

# Reading from a text file
with open('example.txt', 'r') as file:
    content = file.read()
    print(content)  # Output: Hello, file handling in Python!
```

## 2. Working with CSV Files

CSV (Comma Separated Values) is one of the most common formats for storing and exchanging tabular data. Python's built-in `csv` module provides functionality to read from and write to CSV files.

```python
import csv

# Sample data
data = [
    ['Name', 'Age', 'Country'],
    ['Alice', 28, 'USA'],
    ['Bob', 35, 'Canada'],
    ['Charlie', 42, 'UK'],
    ['David', 31, 'Australia']
]

# Writing data to a CSV file
with open('people.csv', 'w', newline='') as file:
    writer = csv.writer(file)
    writer.writerows(data)
    
print("Data written to CSV file successfully!")

# Reading data from a CSV file
with open('people.csv', 'r') as file:
    reader = csv.reader(file)
    print("CSV data:")
    for row in reader:
        print(row)
```

### Using Pandas with CSV

For more complex operations, pandas provides powerful functionality:


## 3. Working with JSON Files

JSON (JavaScript Object Notation) is a lightweight data interchange format that's easy for humans to read and write and easy for machines to parse and generate. Python's `json` module provides methods to work with JSON data.

```python
import json

# Sample data
user_data = {
    'name': 'John Doe',
    'age': 30,
    'is_active': True,
    'interests': ['programming', 'data science', 'machine learning'],
    'contact': {
        'email': 'john@example.com',
        'phone': '+1-555-1234'
    }
}

# Writing JSON to a file
with open('user.json', 'w') as file:
    json.dump(user_data, file, indent=4)
    
print("Data written to JSON file successfully!")

# Reading JSON from a file
with open('user.json', 'r') as file:
    loaded_data = json.load(file)
    
print("Loaded from JSON file:")
print(loaded_data)

# Converting Python objects to JSON strings
json_string = json.dumps(user_data, indent=4)
print("\nJSON string representation:")
print(json_string)

# Parsing JSON strings into Python objects
parsed_data = json.loads(json_string)
print("\nParsed interests:", parsed_data['interests'])
```

## 4. Working with Pickle Files

Pickle is a Python-specific binary protocol for serializing and deserializing Python objects. It allows you to save and load complex Python objects like lists, dictionaries, class instances, and more.

```python
import pickle

# Sample data - can be any Python object
class Person:
    def __init__(self, name, age, interests):
        self.name = name
        self.age = age
        self.interests = interests
        
    def __str__(self):
        return f"{self.name}, {self.age} years old, interests: {', '.join(self.interests)}"

# Creating some objects
alice = Person("Alice Smith", 28, ["AI", "robotics", "hiking"])
bob = Person("Bob Johnson", 35, ["photography", "travel"])

people = [alice, bob]
data_dict = {
    "people": people,
    "project_name": "Demo Project",
    "active": True
}

# Serializing (saving) objects to a file
with open('data.pickle', 'wb') as file:  # Note: 'wb' for binary writing
    pickle.dump(data_dict, file)
    
print("Data serialized to pickle file successfully!")

# Deserializing (loading) objects from a file
with open('data.pickle', 'rb') as file:  # Note: 'rb' for binary reading
    loaded_data = pickle.load(file)
    
print("Loaded from pickle file:")
print(f"Project: {loaded_data['project_name']}")
print("People:")
for person in loaded_data['people']:
    print(f"- {person}")
```

### Pickle Protocols and Security

```python
import pickle

# Using different pickle protocols
data = {"name": "Advanced example", "values": [1, 2, 3, 4, 5]}

# Default protocol
with open('data_default.pickle', 'wb') as file:
    pickle.dump(data, file)

# Highest protocol (more efficient)
with open('data_highest.pickle', 'wb') as file:
    pickle.dump(data, file, protocol=pickle.HIGHEST_PROTOCOL)

# Security warning
print("\n⚠️ IMPORTANT SECURITY NOTE:")
print("Only unpickle data from trusted sources! Pickle can execute arbitrary code.")
print("For untrusted data, use safer formats like JSON.")
```

## 5. Comparing File Formats

Each file format has its strengths and weaknesses:

```python
import csv
import json
import pickle
import pandas as pd
import time
import os

# Sample data - a list of dictionaries
data = [
    {"id": i, "name": f"Item {i}", "value": i * 10} for i in range(1, 1001)
]

# Function to measure file size
def get_file_size(filename):
    return os.path.getsize(filename) / 1024  # Size in KB

# Timing and file size comparison
results = {}

# CSV
start = time.time()
with open('comparison.csv', 'w', newline='') as file:
    writer = csv.DictWriter(file, fieldnames=["id", "name", "value"])
    writer.writeheader()
    writer.writerows(data)
results['CSV'] = {
    'write_time': time.time() - start,
    'file_size': get_file_size('comparison.csv')
}

# JSON
start = time.time()
with open('comparison.json', 'w') as file:
    json.dump(data, file)
results['JSON'] = {
    'write_time': time.time() - start,
    'file_size': get_file_size('comparison.json')
}

# Pickle
start = time.time()
with open('comparison.pickle', 'wb') as file:
    pickle.dump(data, file)
results['Pickle'] = {
    'write_time': time.time() - start,
    'file_size': get_file_size('comparison.pickle')
}

# Print results
print("Format comparison:")
print(f"{'Format':<10} {'Write Time (s)':<15} {'File Size (KB)':<15}")
print("-" * 40)
for fmt, result in results.items():
    print(f"{fmt:<10} {result['write_time']:<15.5f} {result['file_size']:<15.2f}")

print("\nFormat comparison summary:")
print("- CSV: Human-readable, widely compatible, but limited to tabular data")
print("- JSON: Human-readable, widely compatible, supports nested structures")
print("- Pickle: Python-specific, supports all Python objects, binary format")
```

## 6. Error Handling in File Operations

Proper error handling is crucial when working with files:

```python
import csv
import json
import pickle
import os

# Example of error handling for file operations

def safe_read_csv(filename):
    try:
        with open(filename, 'r', newline='') as file:
            reader = csv.reader(file)
            return list(reader)
    except FileNotFoundError:
        print(f"Error: File '{filename}' not found.")
        return None
    except csv.Error as e:
        print(f"CSV Error: {e}")
        return None
    except Exception as e:
        print(f"Unexpected error: {e}")
        return None
    
def safe_read_json(filename):
    try:
        with open(filename, 'r') as file:
            return json.load(file)
    except FileNotFoundError:
        print(f"Error: File '{filename}' not found.")
        return None
    except json.JSONDecodeError as e:
        print(f"JSON Error: {e}")
        return None
    except Exception as e:
        print(f"Unexpected error: {e}")
        return None

def safe_read_pickle(filename):
    try:
        with open(filename, 'rb') as file:
            return pickle.load(file)
    except FileNotFoundError:
        print(f"Error: File '{filename}' not found.")
        return None
    except pickle.UnpicklingError as e:
        print(f"Pickle Error: {e}")
        return None
    except Exception as e:
        print(f"Unexpected error: {e}")
        return None

# Testing error handling
print("Testing error handling:")
print("1. Non-existent CSV:", safe_read_csv("nonexistent.csv"))
print("2. Valid CSV:", safe_read_csv("people.csv") is not None)

# Create an invalid JSON file
with open('invalid.json', 'w') as f:
    f.write('{"name": "Invalid JSON missing closing bracket"')

print("3. Invalid JSON:", safe_read_json("invalid.json"))

# Clean up the invalid file
os.remove('invalid.json')
```

## 7. Practical Examples and Use Cases

Let's look at some real-world examples of how these file formats are used:

### Configuration Management

```python
import json
import os

# Example: Application configuration management

# Default configuration
default_config = {
    "database": {
        "host": "localhost",
        "port": 5432,
        "user": "admin",
        "password": "default_password"
    },
    "app": {
        "debug": False,
        "log_level": "INFO",
        "theme": "default"
    },
    "paths": {
        "data": "./data",
        "logs": "./logs"
    }
}

# Function to load or create configuration
def load_config(config_path="config.json"):
    if os.path.exists(config_path):
        try:
            with open(config_path, 'r') as file:
                return json.load(file)
        except Exception as e:
            print(f"Error loading configuration: {e}")
            print("Using default configuration")
            return default_config
    else:
        print(f"Configuration file not found. Creating {config_path} with defaults.")
        with open(config_path, 'w') as file:
            json.dump(default_config, file, indent=4)
        return default_config

# Usage
config = load_config()
print("Active configuration:")
import pprint
pprint.pprint(config)

# Update configuration
config["app"]["debug"] = True
config["database"]["password"] = "new_secure_password"

# Save updated configuration
with open("config.json", 'w') as file:
    json.dump(config, file, indent=4)
print("\nConfiguration updated and saved!")
```

### Data Analysis Workflow

```python
import pandas as pd
import pickle
import os

# Example: Data analysis workflow

# Generate sample data
if not os.path.exists("sales_data.csv"):
    # Create sample sales data
    data = {
        'date': pd.date_range(start='2023-01-01', periods=100),
        'product': ['Product A', 'Product B', 'Product C', 'Product D'] * 25,
        'region': ['North', 'South', 'East', 'West', 'Central'] * 20,
        'sales': [round(100 * (0.5 + 0.5 * pd.np.random.random())) for _ in range(100)],
        'units': [int(10 * pd.np.random.random()) + 1 for _ in range(100)]
    }
    sales_df = pd.DataFrame(data)
    sales_df.to_csv("sales_data.csv", index=False)
    print("Generated sample sales data")
else:
    print("Using existing sales data")

# Data analysis workflow
def analyze_sales_data():
    # 1. Load the CSV data
    print("\nStep 1: Loading CSV data")
    sales = pd.read_csv("sales_data.csv")
    print(f"Loaded {len(sales)} records")
    print(sales.head())
    
    # 2. Perform analysis
    print("\nStep 2: Analyzing data")
    analysis = {
        'total_sales': sales['sales'].sum(),
        'avg_sales': sales['sales'].mean(),
        'sales_by_product': sales.groupby('product')['sales'].sum().to_dict(),
        'sales_by_region': sales.groupby('region')['sales'].sum().to_dict(),
        'best_selling_product': sales.groupby('product')['sales'].sum().idxmax()
    }
    print("Analysis results:")
    pprint.pprint(analysis)
    
    # 3. Save analysis results to JSON
    print("\nStep 3: Saving results to JSON")
    with open("sales_analysis.json", 'w') as f:
        json.dump(analysis, f, indent=4)
    
    # 4. Create and save a model (using pickle)
    print("\nStep 4: Creating a simple prediction model")
    from sklearn.model_selection import train_test_split
    from sklearn.linear_model import LinearRegression
    
    # Simple sales prediction model based on units
    X = sales[['units']]
    y = sales['sales']
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
    
    model = LinearRegression()
    model.fit(X_train, y_train)
    
    # Save the trained model
    with open("sales_model.pickle", 'wb') as f:
        pickle.dump(model, f)
    
    # 5. Load and test the model
    print("\nStep 5: Testing the saved model")
    with open("sales_model.pickle", 'rb') as f:
        loaded_model = pickle.load(f)
    
    score = loaded_model.score(X_test, y_test)
    print(f"Model R² score: {score:.4f}")
    
    # Predict sales for 5, 10, and 15 units
    test_units = pd.DataFrame({'units': [5, 10, 15]})
    predictions = loaded_model.predict(test_units)
    
    print("\nSales predictions:")
    for units, prediction in zip(test_units['units'], predictions):
        print(f"{units} units -> ${prediction:.2f} sales")

# Run the workflow
try:
    analyze_sales_data()
except Exception as e:
    print(f"Error in workflow: {e}")
```

## 8. Summary

In this guide, we've explored three essential file formats for Python programming and data handling:

- **CSV** files are excellent for tabular data and are widely compatible across different systems and applications. The `csv` module and pandas provide tools for working with CSV data.

- **JSON** files offer a flexible format for structured data with support for nested objects and arrays. The `json` module makes it easy to convert between JSON and Python data structures.

- **Pickle** provides a Python-specific serialization format that can handle almost any Python object, but should only be used with trusted data due to security concerns.

Key points to remember:

1. Choose the right format for your needs:
   - **CSV** for simple tabular data and compatibility
   - **JSON** for structured data and web applications
   - **Pickle** for Python-specific data and complex objects

2. Always use proper error handling when working with files to make your code robust.

3. Consider security implications, especially with pickle files from untrusted sources.

4. For data analysis workflows, consider using pandas which provides excellent integration with these file formats.

5. Always close files properly, preferably using context managers (`with` statements) to ensure resources are released.

By mastering these file formats, you'll be well-equipped to handle most data storage and exchange requirements in your Python applications.
