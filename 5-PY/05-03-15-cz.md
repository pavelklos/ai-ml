## 1. Úvod do abstraktních syntaktických stromů

Abstraktní syntaktické stromy (AST) jsou stromové reprezentace abstraktní syntaktické struktury zdrojového kódu. V Pythonu hrají AST klíčovou roli při pochopení, analýze a transformaci kódu. Místo práce se surovým textem poskytují AST strukturovaný způsob práce s logickými komponentami kódu.

Klíčové koncepty:
- AST reprezentuje kód jako hierarchickou stromovou strukturu
- Každý uzel ve stromě odpovídá jazykovému konstruktu
- Syntaktické detaily jako mezery a komentáře jsou odstraněny
- AST umožňuje programovou analýzu a modifikaci kódu

```python
"""
Toto je základní přehled, jak se Python kód překládá do AST konceptů:

Zdrojový kód:
    x = 1 + 2

Struktura AST (konceptuálně):
    Assignment
    ├── Target: Name(id='x')
    └── Value: BinOp
        ├── Left: Num(value=1)
        ├── Op: Add()
        └── Right: Num(value=2)
"""
```

## 2. Začínáme s modulem AST v Pythonu

Vestavěný modul `ast` v Pythonu poskytuje nástroje pro práci s abstraktními syntaktickými stromy. Tento modul umožňuje parsovat kód, zkoumat výsledný AST a programově vytvářet nebo upravovat AST.

```python
import ast

# Jednoduchý příklad pro začátek
kod = "x = 1 + 2"
parsovany_ast = ast.parse(kod)

# Základní informace o AST
print(f"Typ AST: {type(parsovany_ast)}")
print(f"Pole AST: {parsovany_ast._fields}")

# Vytiskne základní reprezentaci AST
print(ast.dump(parsovany_ast))
```

Po spuštění bude výstup:
```
Typ AST: <class 'ast.Module'>
Pole AST: ('body', 'type_ignores')
Module(body=[Assign(targets=[Name(id='x', ctx=Store())], value=BinOp(left=Constant(value=1), op=Add(), right=Constant(value=2)))], type_ignores=[])
```

## 3. Parsování Python kódu do AST

Funkce `ast.parse()` převádí Python kód do AST. Můžete parsovat řetězce, soubory nebo jakýkoli jiný text obsahující platný Python kód.

```python
import ast

# Parsování kódu z řetězce
kod_retezec = """
def secti(a, b):
    return a + b

vysledek = secti(5, 7)
"""
strom = ast.parse(kod_retezec)

# Parsování kódu ze souboru
with open('priklad.py', 'r') as soubor:
    kod_soubor = soubor.read()
soubor_strom = ast.parse(kod_soubor)

# Můžete zadat název zdrojového souboru pro lepší chybové zprávy
strom_s_nazvem = ast.parse(kod_retezec, filename='<retezec>')

# Parsování výrazu (vrací uzel Expression místo Module)
vyraz_strom = ast.parse('1 + 2', mode='eval')
print(type(vyraz_strom))  # <class 'ast.Expression'>

# Parsování jednoho příkazu
prikaz_strom = ast.parse('if True: print("Ahoj")', mode='single')
```

## 4. Zkoumání struktury AST

Pochopení struktury AST je nezbytné pro efektivní práci s nimi. Prozkoumejme běžné typy uzlů a jejich atributy.

```python
import ast

def prozkoumej_uzel(uzel, odsazeni=0):
    """Rekurzivně prozkoumá AST uzel a jeho potomky."""
    predpona = ' ' * odsazeni
    # Vypíše název třídy uzlu
    print(f"{predpona}{uzel.__class__.__name__}")
    
    # Vypíše pole uzlu a jejich hodnoty
    for pole, hodnota in ast.iter_fields(uzel):
        if isinstance(hodnota, list):
            print(f"{predpona}  {pole}:")
            for polozka in hodnota:
                if isinstance(polozka, ast.AST):
                    prozkoumej_uzel(polozka, odsazeni + 4)
                else:
                    print(f"{predpona}    {polozka}")
        elif isinstance(hodnota, ast.AST):
            print(f"{predpona}  {pole}:")
            prozkoumej_uzel(hodnota, odsazeni + 4)
        else:
            print(f"{predpona}  {pole}: {hodnota}")

# Vzorový kód k prozkoumání
kod = """
def faktorial(n):
    if n <= 1:
        return 1
    else:
        return n * faktorial(n - 1)
"""

# Parsování a prozkoumání AST
strom = ast.parse(kod)
prozkoumej_uzel(strom)
```

Běžné typy AST uzlů:
- `Module`: Uzel nejvyšší úrovně pro soubor nebo blok kódu
- `Assign`: Přiřazení proměnné (x = y)
- `Name`: Reference na proměnnou 
- `Call`: Volání funkce (func())
- `BinOp`: Binární operace (a + b)
- `If`: Podmíněný příkaz
- `FunctionDef`: Definice funkce

## 5. Procházení a transformace AST

Modul `ast` v Pythonu poskytuje nástroje pro procházení a transformaci AST pomocí tříd návštěvníků. Dvě hlavní základní třídy jsou:
- `ast.NodeVisitor`: Pro procházení a analýzu AST uzlů
- `ast.NodeTransformer`: Pro úpravu AST

### Použití NodeVisitor

```python
import ast

class FunkceNavstevnik(ast.NodeVisitor):
    """Navštíví a vytiskne informace o definicích funkcí."""
    
    def visit_FunctionDef(self, uzel):
        argumenty = [arg.arg for arg in uzel.args.args]
        print(f"Nalezena funkce: {uzel.name}")
        print(f"Argumenty: {', '.join(argumenty)}")
        
        # Pokračování v procházení těla funkce
        self.generic_visit(uzel)

# Vzorový kód s funkcemi
kod = """
def pozdrav(jmeno):
    return f"Ahoj, {jmeno}!"

def secti(a, b):
    return a + b
"""

# Parsování a návštěva AST
strom = ast.parse(kod)
navstevnik = FunkceNavstevnik()
navstevnik.visit(strom)
```

### Použití NodeTransformer

```python
import ast
import astor  # Instalace: pip install astor

class ZdvojnasobKonstantyTransformer(ast.NodeTransformer):
    """Zdvojnásobí všechny číselné konstanty v kódu."""
    
    def visit_Constant(self, uzel):
        # Kontrola, zda je konstanta číslo
        if isinstance(uzel.value, (int, float)):
            # Vrátí nový uzel se zdvojnásobenou hodnotou
            return ast.Constant(value=uzel.value * 2)
        # Vrátí beze změny pro nečíselné konstanty
        return uzel

# Vzorový kód s číselnými konstantami
kod = """
x = 10
y = 3.14
z = "Toto je řetězec"
vysledek = x + y
"""

# Parsování, transformace a kompilace AST
strom = ast.parse(kod)
transformer = ZdvojnasobKonstantyTransformer()
transformovany_strom = transformer.visit(strom)
ast.fix_missing_locations(transformovany_strom)  # Oprava čísel řádků a offsetů

# Převod zpět na kód a spuštění
kompilovany_kod = compile(transformovany_strom, '<retezec>', 'exec')
jmenny_prostor = {}
exec(kompilovany_kod, jmenny_prostor)
print(f"x: {jmenny_prostor['x']}")  # 20
print(f"y: {jmenny_prostor['y']}")  # 6.28
print(f"z: {jmenny_prostor['z']}")  # Toto je řetězec
print(f"vysledek: {jmenny_prostor['vysledek']}")  # 26.28
```

## 6. Analýza kódu pomocí AST

AST jsou mocné nástroje pro statickou analýzu kódu. S jejich pomocí můžete detekovat vzory, vynucovat stylistické pokyny, hledat chyby a mnohem více.

```python
import ast
import symtable

class KodAnalyzator(ast.NodeVisitor):
    def __init__(self):
        self.statistiky = {
            'pocet_funkci': 0,
            'pocet_trid': 0,
            'pocet_importu': 0,
            'radky_kodu': 0,
            'for_cykly': 0,
            'while_cykly': 0,
            'if_prikazy': 0,
            'prirazeni': 0,
            'volani_funkci': 0,
        }
    
    def visit_FunctionDef(self, uzel):
        self.statistiky['pocet_funkci'] += 1
        self.generic_visit(uzel)
    
    def visit_ClassDef(self, uzel):
        self.statistiky['pocet_trid'] += 1
        self.generic_visit(uzel)
    
    def visit_Import(self, uzel):
        self.statistiky['pocet_importu'] += len(uzel.names)
        self.generic_visit(uzel)
    
    def visit_ImportFrom(self, uzel):
        self.statistiky['pocet_importu'] += len(uzel.names)
        self.generic_visit(uzel)
    
    def visit_For(self, uzel):
        self.statistiky['for_cykly'] += 1
        self.generic_visit(uzel)
    
    def visit_While(self, uzel):
        self.statistiky['while_cykly'] += 1
        self.generic_visit(uzel)
    
    def visit_If(self, uzel):
        self.statistiky['if_prikazy'] += 1
        self.generic_visit(uzel)
    
    def visit_Assign(self, uzel):
        self.statistiky['prirazeni'] += 1
        self.generic_visit(uzel)
    
    def visit_Call(self, uzel):
        self.statistiky['volani_funkci'] += 1
        self.generic_visit(uzel)

def analyzuj_kod(kod):
    strom = ast.parse(kod)
    analyzator = KodAnalyzator()
    analyzator.visit(strom)
    
    # Počítání řádků (přibližné)
    analyzator.statistiky['radky_kodu'] = len(kod.splitlines())
    
    return analyzator.statistiky

# Příklad použití
testovaci_kod = """
import math
import numpy as np
from datetime import datetime

def vypocitej_statistiky(cisla):
    celkem = sum(cisla)
    prumer = celkem / len(cisla)
    rozptyl = sum((x - prumer) ** 2 for x in cisla) / len(cisla)
    return {
        'celkem': celkem,
        'prumer': prumer,
        'rozptyl': rozptyl,
        'smerodatna_odchylka': math.sqrt(rozptyl)
    }

class AnalyzatorDat:
    def __init__(self, data):
        self.data = data
    
    def zpracuj(self):
        if len(self.data) > 0:
            for polozka in self.data:
                print(polozka)
        else:
            print("Žádná data ke zpracování")

# Hlavní kód
data = [1, 2, 3, 4, 5]
statistiky = vypocitej_statistiky(data)
analyzator = AnalyzatorDat(data)
analyzator.zpracuj()
"""

analyza = analyzuj_kod(testovaci_kod)
for metrika, hodnota in analyza.items():
    print(f"{metrika}: {hodnota}")
```

## 7. Techniky modifikace AST

Modifikace AST vám umožňuje výkonně transformovat kód. Zde jsou některé techniky pro modifikaci AST.

```python
import ast
import astor

# Příklad: Přidání logování na začátek a konec funkcí
class LogovaniTransformer(ast.NodeTransformer):
    """Přidá logovací příkazy na začátek a konec funkcí."""
    
    def visit_FunctionDef(self, uzel):
        # Vytvoření logovacího příkazu pro vstup do funkce
        vstupni_log = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[ast.Constant(value=f"Vstup do funkce {uzel.name}")],
                keywords=[]
            )
        )
        
        # Vytvoření logovacího příkazu pro výstup z funkce
        vystupni_log = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[ast.Constant(value=f"Výstup z funkce {uzel.name}")],
                keywords=[]
            )
        )
        
        # Přidání vstupního logu na začátek funkce
        uzel.body.insert(0, vstupni_log)
        
        # Přidání výstupního logu před každý return příkaz
        return_transformer = ReturnNavstevnik(uzel.name)
        uzel = return_transformer.visit(uzel)
        
        # Také přidání výstupního logu na konec pro funkce, které nemusí explicitně vracet hodnotu
        uzel.body.append(vystupni_log)
        
        return uzel

class ReturnNavstevnik(ast.NodeTransformer):
    """Přidání logování před return příkazy."""
    
    def __init__(self, nazev_funkce):
        self.nazev_funkce = nazev_funkce
    
    def visit_Return(self, uzel):
        # Vytvoření výstupního logu před return
        vystupni_log = ast.Expr(
            value=ast.Call(
                func=ast.Name(id='print', ctx=ast.Load()),
                args=[ast.Constant(value=f"Výstup z funkce {self.nazev_funkce}")],
                keywords=[]
            )
        )
        
        # Vytvoření seznamu příkazů (log + return)
        return [vystupni_log, uzel]

# Testovací kód
kod = """
def faktorial(n):
    if n <= 1:
        return 1
    return n * faktorial(n - 1)

def pozdrav(jmeno):
    zprava = f"Ahoj, {jmeno}!"
    return zprava
"""

# Parsování, transformace a kompilace
strom = ast.parse(kod)
transformer = LogovaniTransformer()
transformovany = transformer.visit(strom)
ast.fix_missing_locations(transformovany)

# Převod zpět na zdrojový kód
upraveny_kod = astor.to_source(transformovany)
print("Upravený kód:")
print(upraveny_kod)

# Spuštění upraveného kódu
exec(compile(transformovany, '<retezec>', 'exec'))
print("\nTestování faktorial(3):")
vysledek = eval('faktorial(3)')
print(f"Výsledek: {vysledek}")
```

## 8. Převod AST zpět na kód

Po úpravě AST je potřeba jej převést zpět na zdrojový kód. Existuje několik přístupů:

```python
import ast
import astunparse  # pip install astunparse
import astor      # pip install astor

kod = """
def secti(a, b):
    return a + b

vysledek = secti(5, 7)
"""

# Parsování kódu do AST
strom = ast.parse(kod)

# Přístup 1: Použití astunparse
print("=== Použití astunparse ===")
rozparsovany_kod = astunparse.unparse(strom)
print(rozparsovany_kod)

# Přístup 2: Použití astor (často produkuje čistší kód)
print("\n=== Použití astor ===")
astor_kod = astor.to_source(strom)
print(astor_kod)

# Přístup 3: Kompilace a přímé spuštění AST
# (bez převodu zpět na zdrojový kód, ale spuštění AST)
print("\n=== Kompilace a spuštění ===")
jmenny_prostor = {}
kompilovany = compile(strom, '<retezec>', 'exec')
exec(kompilovany, jmenny_prostor)
print(f"Výsledek: {jmenny_prostor['vysledek']}")
```

## 9. Praktické aplikace

Podívejme se na některé praktické aplikace manipulace s AST:

### Hledání bezpečnostních zranitelností

```python
import ast

class DetektorNebezpecnehoKodu(ast.NodeVisitor):
    def __init__(self):
        self.problemy = []
    
    def visit_Call(self, uzel):
        # Kontrola potenciálně nebezpečných volání funkcí
        if isinstance(uzel.func, ast.Name):
            if uzel.func.id == 'eval':
                self.problemy.append({
                    'typ': 'bezpecnost',
                    'nazev': 'eval_pouziti',
                    'zprava': 'Nalezeno potenciálně nebezpečné volání eval()',
                    'radek': uzel.lineno
                })
            elif uzel.func.id == 'exec':
                self.problemy.append({
                    'typ': 'bezpecnost',
                    'nazev': 'exec_pouziti',
                    'zprava': 'Nalezeno potenciálně nebezpečné volání exec()',
                    'radek': uzel.lineno
                })
        
        # Kontrola zranitelností SQL injection
        if isinstance(uzel.func, ast.Attribute):
            if uzel.func.attr in ['execute', 'executemany']:
                # Kontrola zřetězení řetězců v argumentech
                for arg in uzel.args:
                    if isinstance(arg, ast.BinOp) and isinstance(arg.op, ast.Add):
                        if any(isinstance(n, ast.Name) for n in [arg.left, arg.right]):
                            self.problemy.append({
                                'typ': 'bezpecnost',
                                'nazev': 'sql_injection',
                                'zprava': 'Možná zranitelnost SQL injection',
                                'radek': uzel.lineno
                            })
        
        self.generic_visit(uzel)

# Testovací kód s bezpečnostními problémy
kod_ke_kontrole = """
def zpracuj_vstup_uzivatele(uzivatelsky_vstup):
    # Nebezpečné: provádění uživatelského vstupu
    vysledek = eval(uzivatelsky_vstup)
    return vysledek

def najdi_uzivatele(uzivatelske_jmeno):
    # Nebezpečné: zranitelnost SQL injection
    kurzor.execute("SELECT * FROM uzivatele WHERE uzivatelske_jmeno = '" + uzivatelske_jmeno + "'")
    return kurzor.fetchone()

def bezpecne_najdi_uzivatele(uzivatelske_jmeno):
    # Bezpečné: použití parametrizovaných dotazů
    kurzor.execute("SELECT * FROM uzivatele WHERE uzivatelske_jmeno = ?", (uzivatelske_jmeno,))
    return kurzor.fetchone()
"""

strom = ast.parse(kod_ke_kontrole)
detektor = DetektorNebezpecnehoKodu()
detektor.visit(strom)

for problem in detektor.problemy:
    print(f"Řádek {problem['radek']}: {problem['zprava']}")
```

### Vytvoření jednoduchého formátovače kódu

```python
import ast
import astor

class JednoduchyFormatter(ast.NodeVisitor):
    def __init__(self):
        self.import_prikazy = []
        self.definice_trid = []
        self.definice_funkci = []
        self.ostatni_prikazy = []
    
    def visit_Import(self, uzel):
        self.import_prikazy.append(uzel)
    
    def visit_ImportFrom(self, uzel):
        self.import_prikazy.append(uzel)
    
    def visit_ClassDef(self, uzel):
        self.definice_trid.append(uzel)
        # Přeskočení návštěvy potomků, protože jsme zachytili uzel
    
    def visit_FunctionDef(self, uzel):
        if not isinstance(uzel.parent, ast.ClassDef):  # Pouze funkce nejvyšší úrovně
            self.definice_funkci.append(uzel)
        # Přeskočení návštěvy potomků, protože jsme zachytili uzel
    
    def visit_Module(self, uzel):
        # Přidání referencí na rodiče ke všem uzlům
        for rodic in ast.walk(uzel):
            for potomek in ast.iter_child_nodes(rodic):
                potomek.parent = rodic
        
        # Návštěva všech potomků pro jejich kategorizaci
        self.generic_visit(uzel)
        
        # Zpracování zbývajících příkazů
        for prikaz in uzel.body:
            if (prikaz not in self.import_prikazy and
                prikaz not in self.definice_trid and
                prikaz not in self.definice_funkci):
                self.ostatni_prikazy.append(prikaz)

def formatuj_kod(kod):
    strom = ast.parse(kod)
    formatter = JednoduchyFormatter()
    formatter.visit(strom)
    
    # Vytvoření nového AST s uspořádanými příkazy
    novy_strom = ast.Module(
        body=(
            formatter.import_prikazy +
            [ast.Expr(value=ast.Constant(value=""))] +  # Prázdný řádek
            formatter.definice_trid +
            [ast.Expr(value=ast.Constant(value=""))] +  # Prázdný řádek
            formatter.definice_funkci +
            [ast.Expr(value=ast.Constant(value=""))] +  # Prázdný řádek
            formatter.ostatni_prikazy
        ),
        type_ignores=[]
    )
    
    # Oprava čísel řádků a umístění
    ast.fix_missing_locations(novy_strom)
    
    # Převod zpět na zdrojový kód
    return astor.to_source(novy_strom)

# Test s neuspořádaným kódem
neuspořádaný_kod = """
```

## 10. Shrnutí

Práce s abstraktními syntaktickými stromy (AST) v Pythonu poskytuje mocné možnosti pro analýzu kódu, transformaci a generování:

1. **Základy AST**: AST reprezentují kód jako stromové struktury s uzly odpovídajícími jazykovým konstruktům, což umožňuje programovou analýzu kódu.

2. **Vestavěné nástroje**: Modul `ast` v Pythonu poskytuje funkce pro parsování kódu do AST, procházení a úpravu a kompilaci zpět do spustitelného kódu.

3. **Procházení AST**: Třídy `NodeVisitor` a `NodeTransformer` umožňují navštěvovat a upravovat uzly v AST, což umožňuje analýzu a transformaci kódu.

4. **Analýza kódu**: AST usnadňují statickou analýzu kódu pro detekci chyb, bezpečnostních zranitelností, vynucování stylistických pokynů a sběr metrik.

5. **Transformace kódu**: S manipulací AST můžete implementovat sofistikované transformace kódu, jako je přidání logování, instrumentace nebo optimalizace.

6. **Generování kódu**: AST lze použít k programovému generování kódu, což je užitečné pro metaprogramování, doménově specifické jazyky a syntézu kódu.

7. **Reálné aplikace**:
   - Nástroje pro statickou analýzu
   - Lintery a formátovače kódu
   - Automatické refaktorování
