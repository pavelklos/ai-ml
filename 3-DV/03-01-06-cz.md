## 1. Úvod do Seabornu a jeho účel

Seaborn je knihovna pro vizualizaci dat v Pythonu založená na matplotlib, která poskytuje rozhraní vyšší úrovně pro vytváření atraktivních a informativních statistických grafů. Je speciálně navržena pro usnadnění a estetické vylepšení statistických vizualizací.

Klíčové vlastnosti Seabornu:
- Postavený na Matplotlib s těsnou integrací s pandas
- Zaměřený na statistickou exploraci a vizualizaci
- Poskytuje krásné výchozí styly a barevné palety
- Specializovaný na vizualizaci vztahů v datových sadách
- Zjednodušuje vytváření komplexních vizualizací s méně řádky kódu

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Kontrola verze Seabornu
print(f"Verze Seabornu: {sns.__version__}")

# Nastavení seed pro reprodukovatelnost
np.random.seed(42)

# Vytvoření vzorových dat
data = pd.DataFrame({
    'x': np.random.normal(0, 1, 100),
    'y': np.random.normal(0, 1, 100),
    'kategorie': np.random.choice(['A', 'B', 'C', 'D'], 100)
})

# Zobrazení prvních několika řádků našich dat
print(data.head())
```

## 3. Porovnání s Matplotlib

Zatímco Matplotlib nabízí vysoce přizpůsobitelné možnosti vykreslování, Seaborn poskytuje abstrakci vyšší úrovně, která usnadňuje vytváření běžných statistických grafů.

```python
# Vytvoření vzorových dat
x = np.linspace(0, 10, 100)
y = np.sin(x)
data = pd.DataFrame({'x': x, 'y': y, 
                    'kategorie': ['A' if i < 50 else 'B' for i in range(100)]})

# Vytvoření dvou podgrafů
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(15, 5))

# Přístup Matplotlib
ax1.scatter(data['x'][:50], data['y'][:50], color='blue', label='A')
ax1.scatter(data['x'][50:], data['y'][50:], color='red', label='B')
ax1.set_title('Bodový graf v Matplotlib')
ax1.set_xlabel('Hodnota X')
ax1.set_ylabel('Hodnota Y')
ax1.legend()
ax1.grid(True, alpha=0.3)

# Přístup Seaborn
sns.scatterplot(data=data, x='x', y='y', hue='kategorie', ax=ax2)
ax2.set_title('Bodový graf v Seabornu')
plt.tight_layout()
plt.show()

# Další porovnání: Vytváření histogramů
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(15, 5))

# Histogram v Matplotlib
ax1.hist(data['y'], bins=20, alpha=0.7)
ax1.set_title('Histogram v Matplotlib')
ax1.set_xlabel('Hodnota')
ax1.set_ylabel('Četnost')

# Histogram v Seabornu
sns.histplot(data['y'], bins=20, kde=True, ax=ax2)
ax2.set_title('Histogram s KDE v Seabornu')
plt.tight_layout()
plt.show()
```

Klíčové rozdíly:
- **Seaborn**: Stručnější syntaxe, integrované statistické povědomí, esteticky příjemnější výchozí nastavení
- **Matplotlib**: Větší flexibilita, kontrola na nižší úrovni, strmější křivka učení

## 4. Základní vykreslování se Seabornem

Seaborn nabízí různé typy grafů pro různé potřeby vizualizace:

```python
# Vytvoření datasetu s více proměnnými
tips = sns.load_dataset('tips')
print(tips.head())

# Vytvoření obrázku s podgrafy
fig, axes = plt.subplots(2, 2, figsize=(16, 12))

# 1. Bodový graf
sns.scatterplot(
    data=tips,
    x='total_bill',
    y='tip',
    hue='sex',
    size='size',
    sizes=(20, 200),
    ax=axes[0, 0]
)
axes[0, 0].set_title('Bodový graf: Spropitné vs. Celková útrata')

# 2. Čarový graf
# Generování časových dat
dates = pd.date_range('2023-01-01', periods=30)
time_data = pd.DataFrame({
    'date': dates,
    'value': np.cumsum(np.random.randn(30)),
    'type': ['A' if i < 15 else 'B' for i in range(30)]
})

sns.lineplot(
    data=time_data,
    x='date',
    y='value',
    hue='type',
    markers=True,
    ax=axes[0, 1]
)
axes[0, 1].set_title('Čarový graf: Časová řada')
axes[0, 1].tick_params(axis='x', rotation=45)

# 3. Sloupcový graf
sns.barplot(
    data=tips,
    x='day',
    y='total_bill',
    hue='sex',
    errorbar=('ci', 95),
    ax=axes[1, 0]
)
axes[1, 0].set_title('Sloupcový graf: Průměrná útrata podle dne')

# 4. Graf počtu
sns.countplot(
    data=tips,
    x='day',
    hue='time',
    ax=axes[1, 1]
)
axes[1, 1].set_title('Graf počtu: Počet návštěv podle dne')

plt.tight_layout()
plt.show()
```

Základní typy grafů v Seabornu:
- **scatterplot()**: Zobrazení vztahu mezi dvěma proměnnými
- **lineplot()**: Zobrazení trendů na spojité proměnné
- **barplot()**: Zobrazení bodových odhadů a intervalů spolehlivosti
- **countplot()**: Zobrazení počtu pozorování v kategoriálních třídách

## 5. Statistické vizualizace

Seaborn vyniká v tvorbě statistických vizualizací, které pomáhají porozumět distribucím dat a vztahům:

```python
# Vytvoření vzorových datasetů
np.random.seed(42)
df = pd.DataFrame({
    'skupina': np.repeat(['A', 'B', 'C', 'D'], 50),
    'hodnota1': np.random.normal(0, 1, 200),
    'hodnota2': np.random.normal(5, 1.5, 200)
})
df.loc[df['skupina'] == 'B', 'hodnota1'] += 2
df.loc[df['skupina'] == 'C', 'hodnota1'] += 4
df.loc[df['skupina'] == 'D', 'hodnota1'] += 6

# Vytvoření obrázku s podgrafy
fig, axes = plt.subplots(2, 2, figsize=(16, 12))

# 1. Distribuční graf (KDE a histogram)
sns.histplot(
    data=df,
    x='hodnota1',
    hue='skupina',
    kde=True,
    ax=axes[0, 0]
)
axes[0, 0].set_title('Distribuční graf s KDE')

# 2. Krabicový graf
sns.boxplot(
    data=df,
    x='skupina',
    y='hodnota1',
    ax=axes[0, 1]
)
axes[0, 1].set_title('Krabicový graf podle skupiny')

# 3. Houslový graf
sns.violinplot(
    data=df,
    x='skupina',
    y='hodnota1',
    ax=axes[1, 0]
)
axes[1, 0].set_title('Houslový graf podle skupiny')

# 4. Spojený graf (v samostatném obrázku)
plt.figure(figsize=(8, 8))
g = sns.jointplot(
    data=df,
    x='hodnota1',
    y='hodnota2',
    kind='scatter',
    hue='skupina',
    height=8
)
g.fig.suptitle('Spojený graf hodnoty1 vs hodnoty2', y=1.02)

plt.tight_layout()
plt.show()

# 5. Párový graf (v samostatném obrázku)
sns.pairplot(
    data=df,
    hue='skupina',
    vars=['hodnota1', 'hodnota2']
)
plt.suptitle('Párový graf všech numerických proměnných', y=1.02)
plt.show()
```

Klíčové statistické grafy:
- **histplot()**: Histogram a KDE pro jednorozměrné distribuce
- **boxplot()**: Zobrazení distribuce s kvartily a odlehlými hodnotami
- **violinplot()**: Kombinuje krabicový graf s KDE
- **jointplot()**: Zobrazení dvourozměrného vztahu s marginálními distribucemi
- **pairplot()**: Vykreslení párových vztahů v datasetu

## 6. Přizpůsobení grafů v Seabornu

Grafy v Seabornu lze přizpůsobit, aby vyhovovaly specifickým potřebám vizualizace:

```python
# Vytvoření vzorových dat
np.random.seed(42)
data = pd.DataFrame({
    'x': np.random.normal(0, 1, 100),
    'y': np.random.normal(0, 1, 100),
    'kategorie': np.random.choice(['Skupina A', 'Skupina B', 'Skupina C'], 100)
})

# Základní graf
plt.figure(figsize=(12, 6))
basic = sns.scatterplot(
    data=data,
    x='x',
    y='y',
    hue='kategorie'
)
basic.set_title('Základní bodový graf')
plt.tight_layout()
plt.show()

# Přizpůsobený graf s různými možnostmi
plt.figure(figsize=(12, 6))
custom = sns.scatterplot(
    data=data,
    x='x',
    y='y',
    hue='kategorie',
    s=100,  # Velikost značek
    alpha=0.7,  # Průhlednost
    palette='viridis',  # Barevná paleta
    style='kategorie',  # Různé styly značek
    edgecolor='black',  # Barva okraje značek
    linewidth=0.5  # Šířka okraje značek
)

# Přizpůsobení dalších aspektů
custom.set_title('Přizpůsobený bodový graf', fontsize=16, fontweight='bold')
custom.set_xlabel('Proměnná X', fontsize=12)
custom.set_ylabel('Proměnná Y', fontsize=12)
custom.grid(True, linestyle='--', alpha=0.7)
custom.legend(title='Skupiny', title_fontsize=12, fontsize=10, frameon=True, loc='best')

# Odstranění horních a pravých os pro čistější vzhled
sns.despine()

plt.tight_layout()
plt.show()
```

Klíčové možnosti přizpůsobení:
- **Barvy a palety**: Změna barevných schémat pomocí parametru `palette`
- **Styly značek**: Řízení vzhledu bodů pomocí `style`, `s`, `edgecolor`
- **Průhlednost**: Úprava pomocí parametru `alpha`
- **Titulky a popisky**: Použití metod matplotlibu jako `set_title()`
- **Mřížky a osy**: Přizpůsobení pomocí `grid()` a `despine()`
- **Legendy**: Úprava pomocí parametrů jako `legend_out` nebo metod matplotlibu

## 7. Témata a styly Seabornu

Témata a styly Seabornu umožňují rychle změnit celkový vzhled grafů:

```python
# Dostupné styly
styles = ['darkgrid', 'whitegrid', 'dark', 'white', 'ticks']

# Vytvoření jednoduchého datasetu
x = np.linspace(0, 10, 100)
y = np.sin(x)
data = pd.DataFrame({'x': x, 'y': y})

# Vytvoření podgrafů pro demonstraci stylů
fig, axes = plt.subplots(len(styles), 1, figsize=(10, 15))

# Vykreslení s různými styly
for i, style in enumerate(styles):
    sns.set_style(style)
    sns.lineplot(data=data, x='x', y='y', ax=axes[i])
    axes[i].set_title(f"Styl: {style}")
    axes[i].set_ylabel('sin(x)')

plt.tight_layout()
plt.show()

# Reset na výchozí styl
sns.set_style('whitegrid')

# Předvolby kontextu (paper, notebook, talk, poster)
contexts = ['paper', 'notebook', 'talk', 'poster']
fig, axes = plt.subplots(len(contexts), 1, figsize=(10, 15))

for i, context in enumerate(contexts):
    sns.set_context(context)
    sns.lineplot(data=data, x='x', y='y', ax=axes[i])
    axes[i].set_title(f"Kontext: {context}")

plt.tight_layout()
plt.show()

# Vlastní téma s set_theme()
sns.set_theme(
    style="darkgrid",
    context="notebook",
    palette="muted",
    font_scale=1.2,
    rc={"lines.linewidth": 2.5}
)

plt.figure(figsize=(10, 6))
sns.lineplot(data=data, x='x', y='y')
plt.title('Vlastní téma')
plt.show()
```

Klíčové aspekty témat a stylů Seabornu:
- **Styly**: Řízení pozadí, mřížky a os ('darkgrid', 'whitegrid', 'dark', 'white', 'ticks')
- **Kontexty**: Řízení měřítka prvků grafu pro různé výstupy ('paper', 'notebook', 'talk', 'poster')
- **Palety**: Vestavěná barevná schémata ('deep', 'muted', 'pastel', 'bright', 'dark', 'colorblind')
- **Měřítko písma**: Úprava všech textových prvků najednou pomocí `font_scale`
- **RC parametry**: Jemné doladění specifických parametrů matplotlibu pomocí `rc`

## 8. Práce s DataFrame objekty

Seaborn je navržen tak, aby bezproblémově pracoval s pandas DataFrame:

```python
# Načtení reálného datasetu
flights = sns.load_dataset('flights')
print("Ukázka datasetu flights:")
print(flights.head())

# Vytvoření pivotní tabulky pro snadnější vizualizaci
flights_pivot = flights.pivot(index='month', columns='year', values='passengers')
print("\nPivotovaná data:")
print(flights_pivot.head())

# Vytvoření různých vizualizací ze stejného DataFrame
plt.figure(figsize=(14, 10))

# 1. Teplotní mapa počtu cestujících podle měsíce a roku
plt.subplot(2, 1, 1)
sns.heatmap(
    flights_pivot,
    cmap='YlGnBu',
    annot=True,
    fmt='d',
    linewidths=.5
)
plt.title('Počet cestujících podle měsíce a roku')

# 2. Čárový graf ukazující trendy cestujících v čase
plt.subplot(2, 1, 2)
sns.lineplot(
    data=flights,
    x='year',
    y='passengers',
    hue='month',
    palette='viridis'
)
plt.title('Trendy cestujících podle měsíce v průběhu let')
plt.tight_layout()
plt.show()

# FacetGrid pro vytvoření více grafů na základě kategorií
g = sns.FacetGrid(flights, col="year", col_wrap=4, height=2.5, aspect=1.5)
g.map_dataframe(sns.lineplot, x="month", y="passengers")
g.set_titles(col_template="{col_name}")
g.set_axis_labels("Měsíc", "Cestující")
g.add_legend()
plt.tight_layout()
plt.show()
```

Klíčové výhody použití Seabornu s DataFrame:
- **Automatické mapování proměnných**: Seaborn rozumí struktuře DataFrame
- **Zpracování kategorií**: Správné zacházení s kategoriálními proměnnými a jejich řazením
- **Statistické povědomí**: Vestavěné statistické výpočty založené na datech
- **Facetování s FacetGrid**: Vytvoření více grafů rozdělených podle kategorií
- **Long-form vs Wide-form data**: Flexibilita při zpracování různých datových formátů

## 9. Komplexní vizualizace se Seabornem

Seaborn umožňuje vytvářet komplexní statistické vizualizace s minimálním kódem:

```python
# Načtení vzorových datasetů
tips = sns.load_dataset('tips')
iris = sns.load_dataset('iris')
titanic = sns.load_dataset('titanic')

# 1. Párový graf s diagonálními KDE grafy
sns.pairplot(
    iris, 
    hue='species', 
    diag_kind='kde',
    corner=True,
    plot_kws={'alpha': 0.6}
)
plt.suptitle('Párové vztahy v datasetu Iris', y=1.02)
plt.show()

# 2. Komplexní kategoriální graf
plt.figure(figsize=(12, 8))
sns.catplot(
    data=titanic, 
    kind='bar',
    x='class', 
    y='survived',
    hue='sex',
    col='deck',
    height=4,
    aspect=.7
)
plt.suptitle('Míra přežití podle třídy, pohlaví a paluby', y=1.02)
plt.tight_layout()
plt.show()

# 3. Teplotní mapa s anotacemi a shlukováním
# Vytvoření korelační matice
corr = iris.drop('species', axis=1).corr()

plt.figure(figsize=(10, 8))
sns.clustermap(
    corr,
    annot=True,
    cmap='RdBu_r',
    vmin=-1, vmax=1,
    linewidths=.5,
    figsize=(8, 8)
)
plt.title('Shlukovaná korelační teplotní mapa', y=1.02)
plt.show()

# 4. Komplexní spojený distribuční graf
sns.jointplot(
    data=tips,
    x='total_bill',
    y='tip',
    kind='reg',
    truncate=False,
    xlim=(0, None),
    color='m',
    height=8
).plot_joint(
    sns.kdeplot, 
    levels=5, 
    color="r"
)
plt.suptitle('Spropitné vs celková útrata s regresí a KDE', y=1.02)
plt.show()

# 5. Vícenásobné regresní přímky s lmplot
sns.lmplot(
    data=tips,
    x='total_bill',
    y='tip',
    hue='smoker',
    col='time',
    row='sex',
    height=4,
    aspect=1.2
)
plt.suptitle('Regrese spropitného podle kuřáků, času a pohlaví', y=1.05)
plt.tight_layout()
plt.show()
```

Klíčové komplexní vizualizace:
- **pairplot()**: Matice párových vztahů
- **catplot()**: Flexibilní kategoriální grafy s facetováním
- **clustermap()**: Hierarchicky shlukovaná teplotní mapa
- **jointplot()**: Dvourozměrný graf s marginálními distribucemi
- **lmplot()**: Regresní graf s facetováním
