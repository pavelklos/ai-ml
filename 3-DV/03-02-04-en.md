# Geographic Visualizations with Folium

## Introduction

Geographic data visualization brings a spatial dimension to your data analysis, allowing you to uncover patterns, relationships, and insights based on location. Folium is a powerful Python library that bridges the gap between data manipulation and map visualization by leveraging the Leaflet.js JavaScript library. It enables the creation of interactive maps that can be displayed in web browsers, Jupyter notebooks, or web applications.

This guide will explore how to create various types of geographic visualizations using Folium, from basic maps to complex data overlays and interactive features.

## Creating Basic Maps

Creating a basic map with Folium is straightforward. You specify the center coordinates and zoom level:

```python
# Creating a basic map centered on a specific location
m = folium.Map(location=[48.85, 2.35], zoom_start=12)

# Display the map in a Jupyter notebook
m
```

You can also customize the map's appearance by choosing different tile providers:


## Markers and Popups

Markers are used to pinpoint specific locations on maps:

```python
# Create a map centered on New York City
nyc_map = folium.Map(location=[40.7128, -74.0060], zoom_start=12)

# Add a simple marker
folium.Marker(
    location=[40.7128, -74.0060],
    popup='New York City',
    tooltip='Click for info',
    icon=folium.Icon(color='blue', icon='info-sign')

# Add a custom icon marker
folium.Marker(
    location=[40.7831, -73.9712],
    popup='<b>Central Park</b><br>A famous urban park',
    tooltip='Central Park',
    icon=folium.Icon(color='green', icon='tree', prefix='fa')

folium.CircleMarker(
    location=[40.7484, -73.9857],
    radius=50,
    popup='<i>Empire State Building</i>',
    tooltip='Empire State Building',
    color='red',
    fill=True,
    fill_color='red',
    fill_opacity=0.3

nyc_map
```

For datasets with many points, you can use marker clusters:

## Heatmaps

Heatmaps are useful for visualizing density and intensity of point data:

```python
# Generate some random data points around San Francisco
np.random.seed(42)
num_points = 500
data = np.random.normal(loc=[37.76, -122.45], scale=[0.1, 0.1], size=(num_points, 2))

# Create a map centered on San Francisco
sf_map = folium.Map(location=[37.76, -122.45], zoom_start=12)

# Add a heatmap layer
HeatMap(data).add_to(sf_map)

# Add a title
title_html = '''
             <h3 align="center" style="font-size:16px"><b>San Francisco Activity Heatmap</b></h3>
             '''
sf_map.get_root().html.add_child(folium.Element(title_html))

sf_map
```

You can also create more advanced heatmaps with weighted data:

```python
# Create weighted data points (e.g., representing crime intensity)
weighted_data = []
for i in range(num_points):
    # Each point has a location and a weight
    lat, lon = data[i]
    weight = np.random.uniform(0.1, 1.0)  # Random weight between 0.1 and 1.0
    weighted_data.append([lat, lon, weight])

# Create a map for weighted heatmap
weighted_map = folium.Map(location=[37.76, -122.45], zoom_start=12)

# Add a weighted heatmap layer
HeatMap(weighted_data, radius=15, blur=10, max_zoom=13, gradient={0.4: 'blue', 0.65: 'lime', 1: 'red'}).add_to(weighted_map)

weighted_map
```

### Weather Data Visualization

```python
# Create a map showing weather data for major cities
weather_data = {
    'City': ['New York', 'Los Angeles', 'Chicago', 'Miami', 'Denver'],
    'Latitude': [40.7128, 34.0522, 41.8781, 25.7617, 39.7392],
    'Longitude': [-74.0060, -118.2437, -87.6298, -80.1918, -104.9903],
    'Temperature': [45, 75, 32, 82, 50],  # in Fahrenheit
    'Weather': ['Cloudy', 'Sunny', 'Snow', 'Sunny', 'Partly Cloudy']
}

weather_df = pd.DataFrame(weather_data)

# Create a weather map
weather_map = folium.Map(location=[39.8283, -98.5795], zoom_start=4)

# Function to determine weather icon
def get_weather_icon(weather):
    icons = {
        'Sunny': 'sun',
        'Cloudy': 'cloud',
        'Snow': 'snowflake',
        'Partly Cloudy': 'cloud-sun'
    }
    return icons.get(weather, 'question')

# Function to determine color based on temperature
def get_temp_color(temp):
    if temp < 32:
        return 'blue'
    elif temp < 50:
        return 'lightblue'
    elif temp < 70:
        return 'green'
    elif temp < 85:
        return 'orange'
    else:
        return 'red'

# Add weather markers
for idx, row in weather_df.iterrows():
    html = f"""
        <h4>{row['City']}</h4>
        <p>Temperature: {row['Temperature']}°F</p>
        <p>Conditions: {row['Weather']}</p>
    """
    
    folium.Marker(
        location=[row['Latitude'], row['Longitude']],
        popup=folium.Popup(html=html, max_width=200),
        tooltip=f"{row['City']}: {row['Temperature']}°F",
        icon=folium.Icon(
            color=get_temp_color(row['Temperature']),
            icon=get_weather_icon(row['Weather']),
            prefix='fa'
        )
    ).add_to(weather_map)

weather_map
```
