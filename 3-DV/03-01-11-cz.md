## 1. Úvod do ukládání vizualizací

Ukládání vizualizací do souborů je zásadní dovedností pro každého datového vědce nebo analytika. Zatímco interaktivní vizualizace v notebookách jsou skvělé pro průzkum, existuje mnoho scénářů, kdy potřebujete exportovat své grafy:

- Zahrnutí vizualizací do zpráv a prezentací
- Sdílení poznatků se zainteresovanými stranami, které nemají Python
- Vytváření dokumentace a publikací
- Archivace výsledků pro budoucí použití
- Tvorba webových aplikací, které zobrazují statické vizualizace

Python nabízí více způsobů, jak ukládat vizualizace do souborů, s různými možnostmi formátů, nastavení kvality a technik automatizace.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import plotly.express as px
from pathlib import Path

# Nastavení konzistentního stylu pro lepší vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Vytvoření adresáře pro ukládání vizualizací, pokud neexistuje
output_dir = Path("visualization_output")
output_dir.mkdir(exist_ok=True)

print(f"Vizualizace budou uloženy do: {output_dir.absolute()}")
```

## 2. Porozumění formátům souborů pro vizualizace

Různé formáty souborů slouží různým účelům při ukládání vizualizací. Formát, který zvolíte, závisí na vašich specifických potřebách:

- **PNG (Portable Network Graphics)**: Bezeztrátová komprese, podporuje průhlednost, ideální pro web a prezentace
- **JPEG/JPG**: Ztrátová komprese, menší velikost souboru, vhodná pro fotografie, ale ne ideální pro grafy s textem
- **SVG (Scalable Vector Graphics)**: Vektorový formát, zachovává kvalitu v jakékoli velikosti, upravitelný, ideální pro publikace
- **PDF (Portable Document Format)**: Vektorový formát, zachovává kvalitu, podpora více stránek, vhodný pro publikace
- **EPS (Encapsulated PostScript)**: Vektorový formát běžně používaný v akademických publikacích
- **TIFF**: Vysoce kvalitní formát často používaný pro tisk

Každý formát má své vlastní výhody a případy použití:

```python
# Vytvoření jednoduché vizualizace pro demonstraci různých formátů
np.random.seed(42)
data = np.random.normal(0, 1, 1000)

plt.figure(figsize=(10, 6))
plt.hist(data, bins=30, alpha=0.7, color='blue', edgecolor='black')
plt.title('Normální rozdělení', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Četnost', fontsize=12)
plt.grid(True, alpha=0.3)

# Uložení v různých formátech
formats = ['png', 'jpg', 'svg', 'pdf', 'eps', 'tiff']
for fmt in formats:
    plt.savefig(output_dir / f"histogram.{fmt}")
    print(f"Uloženo histogram.{fmt}")

plt.close()

# Zobrazení velikostí souborů pro porovnání
import os
file_sizes = [(fmt, os.path.getsize(output_dir / f"histogram.{fmt}") / 1024) 
              for fmt in formats]
for fmt, size in file_sizes:
    print(f"{fmt.upper()} velikost: {size:.2f} KB")
```

## 3. Ukládání Matplotlib grafů do souborů

Funkce `savefig()` knihovny Matplotlib je hlavní metodou pro ukládání vizualizací do souborů. Nabízí mnoho parametrů pro kontrolu výstupu:

```python
# Vytvoření složitější vizualizace
plt.figure(figsize=(12, 8))

# Generování dat
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

# Vytvoření grafu
plt.plot(x, y1, 'b-', linewidth=2, label='Sinus')
plt.plot(x, y2, 'r--', linewidth=2, label='Kosinus')
plt.title('Funkce Sinus a Kosinus', fontsize=16)
plt.xlabel('x', fontsize=14)
plt.ylabel('y', fontsize=14)
plt.legend(fontsize=12)
plt.grid(True, alpha=0.3)

# Přidání anotací
plt.annotate('Maximum', xy=(1.5, 1.0), xytext=(3, 1.5),
             arrowprops=dict(facecolor='black', shrink=0.05),
             fontsize=12)

# Základní ukládání
plt.savefig(output_dir / 'trig_functions.png')

# Ukládání s větší kontrolou - průhledné pozadí
plt.savefig(output_dir / 'trig_functions_transparent.png', 
            transparent=True)

# Těsné rozložení pro odstranění přebytečného bílého prostoru
plt.savefig(output_dir / 'trig_functions_tight.png', 
            bbox_inches='tight')

# Kombinace možností
plt.savefig(output_dir / 'trig_functions_optimized.png',
            bbox_inches='tight', 
            transparent=True,
            pad_inches=0.1)

plt.close()
```

## 4. Nastavení rozlišení a kvality

Rozlišení a kvalita uložených vizualizací jsou klíčové, zejména pro publikace nebo velkoformátový tisk. Matplotlib umožňuje kontrolovat tyto aspekty:

```python
# Vytvoření vizualizace s více prvky
plt.figure(figsize=(10, 6))

# Generování dat pro bodový graf
np.random.seed(42)
x = np.random.normal(0, 1, 100)
y = x * 0.8 + np.random.normal(0, 0.5, 100)
colors = np.random.rand(100)
sizes = np.random.randint(50, 200, 100)

plt.scatter(x, y, c=colors, s=sizes, alpha=0.7, cmap='viridis')
plt.colorbar(label='Hodnota barvy')
plt.title('Bodový graf s více prvky', fontsize=16)
plt.xlabel('Hodnota X', fontsize=12)
plt.ylabel('Hodnota Y', fontsize=12)
plt.grid(True, alpha=0.3)

# Uložení s různými nastaveními DPI
dpi_settings = [72, 150, 300, 600]
for dpi in dpi_settings:
    plt.savefig(output_dir / f'scatter_dpi_{dpi}.png', dpi=dpi)
    print(f"Uloženo s {dpi} DPI")

# Kontrola kvality JPEG (0-100, vyšší je lepší)
for quality in [30, 60, 90]:
    plt.savefig(output_dir / f'scatter_quality_{quality}.jpg', 
                dpi=300, quality=quality)
    print(f"Uloženo JPEG s kvalitou {quality}")

# Vektorové formáty nepotřebují nastavení DPI pro jasnost,
# ale ovlivňují velikost textu a dalších prvků
plt.savefig(output_dir / 'scatter_vector.svg')
plt.savefig(output_dir / 'scatter_vector.pdf')

plt.close()
```

## 6. Ukládání interaktivních vizualizací

## 7. Dávkové ukládání více vizualizací

Při práci s mnoha vizualizacemi je užitečné automatizovat proces ukládání:

```python
# Vytvoření funkce pro generování a ukládání více vizualizací
def create_and_save_plots(data, output_directory):
    """
    Generování a ukládání více grafů z datasetu
    
    Parametry:
    -----------
    data : pandas.DataFrame
        Dataset k vizualizaci
    output_directory : str nebo Path
        Adresář, kam budou grafy uloženy
    """
    output_dir = Path(output_directory)
    output_dir.mkdir(exist_ok=True)
    
    # Graf 1: Histogram
    plt.figure(figsize=(10, 6))
    plt.hist(data['total_bill'], bins=20, color='skyblue', edgecolor='black')
    plt.title('Rozdělení celkové útraty')
    plt.xlabel('Celková útrata ($)')
    plt.ylabel('Četnost')
    plt.savefig(output_dir / 'histogram_bill.png', dpi=300, bbox_inches='tight')
    plt.close()
    
    # Graf 2: Bodový graf
    plt.figure(figsize=(10, 6))
    plt.scatter(data['total_bill'], data['tip'], alpha=0.7)
    plt.title('Spropitné vs. celková útrata')
    plt.xlabel('Celková útrata ($)')
    plt.ylabel('Spropitné ($)')
    plt.savefig(output_dir / 'scatter_tip_bill.png', dpi=300, bbox_inches='tight')
    plt.close()
    
    # Graf 3: Krabicový graf
    plt.figure(figsize=(12, 6))
    sns.boxplot(x='day', y='total_bill', data=data)
    plt.title('Celková útrata podle dne')
    plt.savefig(output_dir / 'boxplot_day.png', dpi=300, bbox_inches='tight')
    plt.close()
    
    # Graf 4: Sloupcový graf
    day_avg = data.groupby('day')['total_bill'].mean().reset_index()
    plt.figure(figsize=(10, 6))
    sns.barplot(x='day', y='total_bill', data=day_avg)
    plt.title('Průměrná útrata podle dne')
    plt.xlabel('Den')
    plt.ylabel('Průměrná útrata ($)')
    plt.savefig(output_dir / 'barplot_day_avg.png', dpi=300, bbox_inches='tight')
    plt.close()
    
    print(f"Vytvořeno a uloženo 4 grafů do {output_dir}")

# Použití naší funkce pro vytvoření a uložení více grafů
batch_output_dir = output_dir / 'batch_plots'
create_and_save_plots(tips, batch_output_dir)
```

## 8. Automatizace procesu ukládání

Můžete dále automatizovat ukládání vizualizací integrací do datových zpracovatelských pipeline:

```python
# Vytvoření jednoduché vizualizační pipeline
def analysis_pipeline(data_path, output_dir, formats=['png', 'pdf']):
    """
    Spustit analytickou pipeline, která zpracovává data a ukládá vizualizace
    
    Parametry:
    -----------
    data_path : str
        Cesta k datovému souboru
    output_dir : str nebo Path
        Adresář, kam budou vizualizace uloženy
    formats : list
        Seznam formátů souborů pro uložení
    """
    output_dir = Path(output_dir)
    output_dir.mkdir(exist_ok=True)
    
    # Krok 1: Načtení a příprava dat
    if isinstance(data_path, str) and data_path.endswith('.csv'):
        data = pd.read_csv(data_path)
    else:
        # Použití vzorových dat, pokud soubor neexistuje
        data = sns.load_dataset('tips')
    
    print(f"Načtena data s {len(data)} řádky")
    
    # Krok 2: Vytvoření vizualizace pro každý numerický sloupec
    numeric_cols = data.select_dtypes(include=['float64', 'int64']).columns
    
    for col in numeric_cols:
        plt.figure(figsize=(10, 6))
        
        # Vytvoření histogramu s KDE
        sns.histplot(data[col], kde=True)
        plt.title(f'Rozdělení {col}')
        
        # Uložení ve všech požadovaných formátech
        for fmt in formats:
            filename = f"{col.lower().replace(' ', '_')}_dist.{fmt}"
            plt.savefig(output_dir / filename, dpi=300, bbox_inches='tight')
        
        plt.close()
    
    # Krok 3: Vytvoření korelační teplotní mapy
    plt.figure(figsize=(12, 10))
    corr = data.select_dtypes(include=['float64', 'int64']).corr()
    sns.heatmap(corr, annot=True, cmap='coolwarm', vmin=-1, vmax=1)
    plt.title('Korelační matice')
    
    # Uložení ve všech požadovaných formátech
    for fmt in formats:
        filename = f"correlation_heatmap.{fmt}"
        plt.savefig(output_dir / filename, dpi=300, bbox_inches='tight')
    
    plt.close()
    
    print(f"Pipeline dokončena. Vizualizace uloženy do {output_dir}")

# Spuštění pipeline s našimi vzorovými daty
pipeline_output_dir = output_dir / 'pipeline_visualizations'
analysis_pipeline('tips.csv', pipeline_output_dir, formats=['png', 'svg', 'pdf'])
```

## 9. Osvědčené postupy pro správu souborů

Následování osvědčených postupů při správě vizualizačních souborů pomáhá udržet organizaci a reprodukovatelnost:

```python
import datetime
import os

class VisualizationManager:
    """Třída pro správu vytváření a organizaci vizualizačních souborů"""
    
    def __init__(self, base_directory='visualization_output'):
        """
        Inicializace správce vizualizací
        
        Parametry:
        -----------
        base_directory : str
            Základní adresář pro veškerý vizualizační výstup
        """
        self.base_dir = Path(base_directory)
        self.base_dir.mkdir(exist_ok=True)
        
        # Vytvoření časově označené složky pro tuto relaci
        timestamp = datetime.datetime.now().strftime('%Y%m%d_%H%M%S')
        self.session_dir = self.base_dir / f"viz_session_{timestamp}"
        self.session_dir.mkdir(exist_ok=True)
        
        # Sledování uložených vizualizací
        self.saved_files = []
        
        print(f"Správce vizualizací inicializován. Výstupní adresář: {self.session_dir}")
    
    def save_figure(self, fig, name, formats=['png'], dpi=300, **kwargs):
        """
        Uložení obrázku v různých formátech s řádnou organizací
        
        Parametry:
        -----------
        fig : matplotlib.figure.Figure
            Obrázek k uložení
        name : str
            Základní název pro soubor (bez přípony)
        formats : list
            Seznam formátů k uložení (např. ['png', 'pdf'])
        dpi : int
            Rozlišení pro rastrové formáty
        **kwargs : dict
            Další argumenty k předání savefig
        """
        for fmt in formats:
            filename = f"{name}.{fmt}"
            filepath = self.session_dir / filename
            fig.savefig(filepath, dpi=dpi, **kwargs)
            self.saved_files.append(filepath)
            
        return [self.session_dir / f"{name}.{fmt}" for fmt in formats]
    
    def create_catalog(self):
        """Vytvoření katalogu všech vizualizací v této relaci"""
        catalog_path = self.session_dir / "visualization_catalog.html"
        
        html_content = [
            "<!DOCTYPE html>",
            "<html>",
            "<head>",
            "    <title>Katalog vizualizací</title>",
            "    <style>",
            "        body { font-family: Arial, sans-serif; margin: 20px; }",
            "        .viz-item { margin-bottom: 30px; border-bottom: 1px solid #ccc; padding-bottom: 20px; }",
            "        img { max-width: 800px; box-shadow: 0 2px 5px rgba(0,0,0,0.2); }",
            "    </style>",
            "</head>",
            "<body>",
            "    <h1>Katalog vizualizací</h1>",
            f"    <p>Vytvořeno: {datetime.datetime.now().strftime('%Y-%m-%d %H:%M:%S')}</p>"
        ]
        
        # Přidání pouze obrázkových souborů do katalogu
        image_files = [f for f in self.saved_files if f.suffix.lower() in ['.png', '.jpg', '.jpeg', '.svg']]
        
        for img_path in image_files:
            rel_path = os.path.relpath(img_path, self.session_dir)
            name = img_path.stem
            
            html_content.extend([
                "    <div class='viz-item'>",
                f"        <h2>{name}</h2>",
                f"        <img src='{rel_path}' alt='{name}'>",
                f"        <p>Soubor: {rel_path}</p>",
                "    </div>"
            ])
        
        html_content.extend([
            "</body>",
            "</html>"
        ])
        
        with open(catalog_path, 'w') as f:
            f.write('\n'.join(html_content))
            
        return catalog_path

# Příklad použití VisualizationManager
viz_manager = VisualizationManager()

# Vytvoření a uložení grafu
plt.figure(figsize=(10, 6))
plt.scatter(tips['total_bill'], tips['tip'], c=tips['size'], cmap='viridis', alpha=0.7)
plt.colorbar(label='Velikost skupiny')
plt.title('Spropitné vs. celková útrata', fontsize=16)
plt.xlabel('Celková útrata ($)', fontsize=12)
plt.ylabel('Spropitné ($)', fontsize=12)

# Uložení pomocí správce
viz_manager.save_figure(plt.gcf(), 'tips_scatter', 
                       formats=['png', 'pdf', 'svg'], 
                       bbox_inches='tight')
plt.close()

# Vytvoření a uložení dalšího grafu
plt.figure(figsize=(12, 6))
sns.boxplot(x='day', y='tip', hue='time', data=tips)
plt.title('Spropitné podle dne a času', fontsize=16)

# Uložení pomocí správce
viz_manager.save_figure(plt.gcf(), 'tips_boxplot', 
                       formats=['png', 'pdf'], 
                       bbox_inches='tight')
plt.close()

# Vytvoření katalogu všech vizualizací
catalog_file = viz_manager.create_catalog()
print(f"Katalog vizualizací vytvořen: {catalog_file}")
```

## 10. Shrnutí

Ukládání vizualizací do souborů je základní dovedností v pracovních postupech vizualizace dat. Klíčové body k zapamatování:

1. **Vyberte správný formát** pro vaše potřeby:
   - PNG nebo JPEG pro web/prezentace
   - SVG nebo PDF pro publikace nebo když je potřeba škálovatelnost
   - Zvažte velikost souboru, kvalitu a účel

2. **Kontrolujte nastavení kvality**:
   - Použijte vyšší DPI (300+) pro obrázky publikační kvality
   - Upravte kvalitu JPEG podle potřeby
   - Používejte vektorové formáty (SVG, PDF) pro škálovatelnou grafiku

3. **Používejte správné velikosti**:
   - Nastavte velikost obrázku před vytvořením grafu
   - Používejte možnosti těsného rozložení pro odstranění přebytečného bílého prostoru
   - Zvažte, jak bude vizualizace zobrazena

4. **Organizujte své soubory**:
   - Používejte konzistentní konvence pojmenování
   - Vytvářejte struktury adresářů, které dávají smysl
   - Zvažte zahrnutí časových razítek nebo informací o verzi
   - Vytvářejte katalogy pro lepší organizaci

5. **Automatizujte, když je to možné**:
   - Vytvářejte funkce pro dávkové zpracování
   - Integrujte ukládání vizualizací do analytických pipeline
   - Používejte třídy nebo utility pro správu vizualizačních výstupů

# Kompletní příklad spojující vše dohromady

def save_visualization_suite(data, title, output_dir):
    """
    Vytvoření a uložení komplexní sady vizualizací z dat
    
    Parametry:
    -----------
    data : pandas.DataFrame
        Dataset k vizualizaci
    title : str
        Předpona titulu pro všechny vizualizace
    output_dir : str nebo Path
        Adresář, kam budou vizualizace uloženy
    
    Vrací:
    --------
    dict
        Cesty ke všem uloženým vizualizacím
    """
    output_dir = Path(output_dir)
    output_dir.mkdir(exist_ok=True, parents=True)
    saved_files = {}
    
    # 1. Očištění titulku pro názvy souborů
    clean_title = title.lower().replace(' ', '_')
    
    # 2. Rozdělení numerických sloupců
    numeric_cols = data.select_dtypes(include=['float64', 'int64']).columns
    for col in numeric_cols:
        plt.figure(figsize=(10, 6))
        sns.histplot(data[col], kde=True, color='skyblue')
        plt.title(f'{title}: Rozdělení {col}', fontsize=14)
        plt.xlabel(col, fontsize=12)
        plt.ylabel('Četnost', fontsize=12)
        
        # Uložení v několika formátech s různými možnostmi
        file_path = output_dir / f"{clean_title}_{col.lower()}_dist"
        plt.savefig(f"{file_path}.png", dpi=300, bbox_inches='tight')
        plt.savefig(f"{file_path}.pdf", bbox_inches='tight')
        
        saved_files[f"{col}_dist"] = file_path
        plt.close()
    
    # 3. Korelační matice
    if len(numeric_cols) > 1:
        plt.figure(figsize=(10, 8))
        corr = data[numeric_cols].corr()
        sns.heatmap(corr, annot=True, cmap='coolwarm', vmin=-1, vmax=1)
        plt.title(f'{title}: Korelační matice', fontsize=14)
        
        file_path = output_dir / f"{clean_title}_correlation"
        plt.savefig(f"{file_path}.png", dpi=300, bbox_inches='tight')
        plt.savefig(f"{file_path}.pdf", bbox_inches='tight')
        
        saved_files["correlation"] = file_path
        plt.close()
    
    # 4. Vytvoření README s informacemi o vizualizacích
    readme_content = [
        f"# Sada vizualizací: {title}",
        f"Vytvořeno: {datetime.datetime.now().strftime('%Y-%m-%d %H:%M:%S')}",
        "",
        "## Soubory:",
    ]
    
    for key, path in saved_files.items():
        readme_content.append(f"- {key}: {path.name}.png, {path.name}.pdf")
    
    with open(output_dir / "README.md", "w") as f:
        f.write("\n".join(readme_content))
    
    print(f"Sada vizualizací pro '{title}' uložena do {output_dir}")
    return saved_files
