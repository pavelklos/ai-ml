## 1. Úvod do velikosti a rozlišení obrázků

Velikost a rozlišení vašich vizualizací výrazně ovlivňují jejich efektivitu a vzhled. Správně zvolená velikost obrázků zajišťuje, že vaše data jsou zobrazena jasně a proporčně, zatímco správné nastavení rozlišení zaručuje, že vaše vizualizace vypadají ostře jak na obrazovce, tak v tisku.

Pojďme nastavit naše prostředí s potřebnými knihovnami:

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from matplotlib.figure import Figure
from matplotlib import rcParams

# Nastavení výchozích stylů
plt.style.use('seaborn-v0_8-whitegrid')

# Pro reprodukovatelnost
np.random.seed(42)

x = np.linspace(0, 10, 100)
y = np.sin(x) * np.exp(-0.1 * x)
data = pd.DataFrame({
    'x': x,
    'y': y,
    'category': np.random.choice(['A', 'B', 'C'], size=100)
})

# Zobrazení aktuálních výchozích nastavení matplotlib
print(f"Výchozí velikost obrázku: {plt.rcParams['figure.figsize']}")
print(f"Výchozí DPI: {plt.rcParams['figure.dpi']}")
print(f"Výchozí DPI při ukládání: {plt.rcParams['savefig.dpi']}")
```

## 2. Ovládání rozměrů obrázků v Matplotlib

Rozměry obrázků v matplotlib jsou obvykle zadávány v palcích. Tyto rozměry v kombinaci s rozlišením (DPI) určují konečnou velikost vaší vizualizace v pixelech.

```python

plt.ylabel('Osa Y')
plt.show()

plt.scatter(data['x'], data['y'], c=data['y'], cmap='viridis', s=50)
plt.title('Čtvercový obrázek (6 × 6 palců)')
plt.colorbar(label='hodnota y')
plt.tight_layout()
plt.show()

plt.tight_layout()

# Funkce pro ukázku různých velikostí obrázků
def compare_figure_sizes():
    sizes = [(4, 3), (6, 4), (10, 6)]
    fig, axes = plt.subplots(len(sizes), 1, figsize=(8, 10))
    
    for ax, size in zip(axes, sizes):
        # Vytvoření menšího obrázku se zadanou velikostí
        inner_fig = Figure(figsize=size)
        inner_ax = inner_fig.add_subplot(111)
        inner_ax.plot(x, y)
        inner_ax.set_title(f'Velikost obrázku: {size[0]} × {size[1]} palců')
        
        # Zobrazení velikosti obrázku v hlavním grafu
        ax.axis('off')
        # Převod vnitřního obrázku na obrázek
        buf = io.BytesIO()
        inner_fig.savefig(buf, format='png')
        buf.seek(0)
        img = Image.open(buf)
        # Zobrazení obrázku
        ax.imshow(np.asarray(img))
        ax.set_title(f'Velikost obrázku: {size[0]} × {size[1]} palců')
    
    plt.tight_layout()
    plt.show()
```

## 3. Porozumění konceptům DPI a rozlišení

DPI (dots per inch, bodů na palec) určuje, kolik pixelů je použito na jeden palec obrázku. Vyšší hodnoty DPI vedou k větším a detailnějším obrázkům.

```python
# Ukázka nastavení DPI
def show_dpi_comparison():
    dpi_values = [50, 100, 200]
    sample_size = (4, 3)  # 4×3 palce
    
    plt.figure(figsize=(10, 8))
    
    for i, dpi in enumerate(dpi_values):
        plt.subplot(len(dpi_values), 1, i+1)
        
        # Zobrazení rozměrů obrázku, které by vznikly
        width_px = sample_size[0] * dpi
        height_px = sample_size[1] * dpi
        
        plt.text(0.5, 0.5, f"DPI: {dpi}\nVelikost: {sample_size} palců\n"
                           f"Rozlišení: {width_px:.0f} × {height_px:.0f} pixelů",
                 ha='center', va='center', fontsize=12)
        plt.title(f'DPI = {dpi}')
        plt.xlim(0, 1)
        plt.ylim(0, 1)
        plt.axis('off')
    
    plt.tight_layout()
    plt.show()

# Odkomentujte pro spuštění porovnání DPI
# show_dpi_comparison()

plt.title('Obrázek s DPI=100')

# Výpočet výsledné velikosti obrázku v pixelech
def calculate_image_size(fig_size_inches, dpi):
    width_px = fig_size_inches[0] * dpi
    height_px = fig_size_inches[1] * dpi
    return width_px, height_px

sizes = [(6, 4), (8, 6), (10, 8)]
dpi_values = [72, 100, 150, 300]

print("Očekávané rozměry obrázků v pixelech:")

        width_px, height_px = calculate_image_size(size, dpi)
        print(f"Velikost: {size} palců, DPI: {dpi} → {width_px:.0f}×{height_px:.0f} pixelů")
```

## 7. Dynamické a responzivní určování velikosti obrázků

V interaktivních prostředích nebo při programovém vytváření vizualizací může být nutné dynamicky upravovat velikosti obrázků:

```python
# Dynamické určování velikosti na základě charakteristik dat
def dynamic_figure_size(data, base_size=(6, 4), max_size=(15, 10)):
    """Určení velikosti obrázku na základě charakteristik dat"""
    n_points = len(data)
    n_features = data.shape[1] if hasattr(data, 'shape') and len(data.shape) > 1 else 1
    
    # Škálování šířky podle počtu vlastností/kategorií
    width = min(base_size[0] * (1 + n_features * 0.2), max_size[0])
    
    # Škálování výšky podle logaritmu počtu datových bodů
    height = min(base_size[1] * (1 + np.log10(n_points) * 0.3), max_size[1])
    
    return (width, height)

# Vytvoření datasetů různých velikostí
small_data = pd.DataFrame(np.random.randn(10, 2), columns=['A', 'B'])
medium_data = pd.DataFrame(np.random.randn(100, 4), columns=['A', 'B', 'C', 'D'])
large_data = pd.DataFrame(np.random.randn(1000, 6), 
                         columns=['A', 'B', 'C', 'D', 'E', 'F'])

# Výpočet dynamických velikostí
small_size = dynamic_figure_size(small_data)
medium_size = dynamic_figure_size(medium_data)
large_size = dynamic_figure_size(large_data)

print(f"Dynamické velikosti na základě dat:")
print(f"Malá data ({small_data.shape}): {small_size}")
print(f"Střední data ({medium_data.shape}): {medium_size}")
print(f"Velká data ({large_data.shape}): {large_size}")

# Responzivní velikost pro Jupyter notebooky / interaktivní prostředí
from IPython.display import display

def responsive_figure(fig_function, size_px=(800, 500)):
    """Vytvoření obrázku, který se přizpůsobuje velikosti displeje"""
    # Převod požadované velikosti v pixelech na palce na základě aktuálního DPI
    current_dpi = plt.rcParams['figure.dpi']
    size_inches = (size_px[0] / current_dpi, size_px[1] / current_dpi)
    
    fig = plt.figure(figsize=size_inches)
    fig_function(fig)
    plt.tight_layout()
    display(fig)
    plt.close(fig)
```

```python
def two_column_figure(width_pt=246.0):
    """
    Vytvoření obrázku o velikosti pro dvousloupcový formát časopisu.
    
    Args:
        width_pt (float): Šířka sloupce v bodech (liší se podle časopisu)
                          Běžné hodnoty: 246pt (IEEE), 240pt (Elsevier)
    
    Returns:
        tuple: Velikost obrázku v palcích
    """
    # Převod bodů na palce (1pt = 1/72 palce)
    width_in = width_pt / 72.0
    # Zlatý poměr pro esteticky příjemné obrázky
    golden_ratio = (5**0.5 - 1) / 2  # ~= 0.618
    # Výpočet výšky na základě zlatého poměru
    height_in = width_in * golden_ratio
    
    return (width_in, height_in)

# Příklad pro časopis IEEE (dvousloupcový formát)

plt.figure(figsize=ieee_figsize, dpi=300)
```

## 10. Shrnutí

Správná velikost a nastavení rozlišení jsou základními aspekty vytváření efektivních datových vizualizací. Zde je shrnutí klíčových bodů:

1. **Základy velikosti obrázku**:
   - Velikost se v matplotlib určuje v palcích (parametr figsize)
   - Velikost by měla být zvolena na základě složitosti dat a účelu vizualizace
   - Různé typy grafů mají různé optimální poměry stran

2. **Koncepty rozlišení**:
   - DPI (bodů na palec) určuje hustotu pixelů vašich obrázků
   - Vyšší DPI vede k větším velikostem souborů, ale ostřejším obrázkům
   - Běžné hodnoty: 72-96 DPI pro obrazovku, 150-200 DPI pro standardní tisk, 300+ DPI pro publikaci

3. **Výstupní aspekty**:
   - Pro web/obrazovku: nižší DPI (72-96), formáty PNG/SVG
   - Pro tisk/publikace: vyšší DPI (300+), formáty PDF/TIFF
   - Vektorové formáty (PDF, SVG, EPS) jsou nezávislé na rozlišení a preferované pro publikace

4. **Osvědčené postupy**:
   - Používejte `tight_layout()` nebo `constrained_layout=True` pro zabránění oříznutí
   - Nastavte velikosti fontů úměrně k velikosti obrázku
   - Udržujte konzistentní velikosti v celém dokumentu nebo prezentaci
   - Při volbě velikosti a rozlišení zvažte konečné médium
   - Testujte obrázky v jejich zamýšleném kontextu zobrazení

5. **Běžné chyby**:
   - Příliš malý text a prvky ve velkých obrázcích
   - Pixelizace kvůli nedostatečnému rozlišení
   - Plýtvání místem nebo přeplnění kvůli nevhodné velikosti obrázku
   - Nekonzistentní velikosti vytvářející nesouvislou prezentaci

Zvládnutí nastavení velikosti a rozlišení vám pomůže vytvářet vizualizace profesionální kvality, které efektivně komunikují vaše datové poznatky napříč různými médii a kontexty. Dodržováním postupů uvedených v této příručce zajistíte, že vaše vizualizace budou vypadat co nejlépe, ať už jsou zobrazeny na obrazovce, v prezentacích nebo v publikacích.
