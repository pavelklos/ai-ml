## 1. Introduction to Numerical Data Visualization

Numerical data visualization is essential for understanding distributions, relationships, and trends in quantitative data. Effective visualization helps reveal patterns that might not be apparent from summary statistics alone. Python offers powerful libraries for creating informative and visually appealing representations of numerical data.

```python
# Import essential libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set a consistent style for better visuals
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Generate sample data for our examples
np.random.seed(42)  # For reproducibility

# Create different datasets for various types of visualizations
# Normal distribution data
normal_data = np.random.normal(loc=0, scale=1, size=1000)

# Bimodal data
bimodal_data = np.concatenate([
    np.random.normal(loc=-2, scale=0.5, size=500),
    np.random.normal(loc=2, scale=0.5, size=500)
])

# Time series data
x = np.linspace(0, 10, 100)
time_series_data = np.sin(x) * np.exp(-0.1 * x) + np.random.normal(0, 0.1, 100)

# Display basic information about our datasets
print("Normal data shape:", normal_data.shape)
print("Bimodal data shape:", bimodal_data.shape)
print("Time series data shape:", time_series_data.shape)

print("\nSummary statistics for normal data:")
print(pd.Series(normal_data).describe())

# Preview the first few data points from each dataset
pd.DataFrame({
    'Normal': normal_data[:5],
    'Bimodal': bimodal_data[:5],
    'Time Series': time_series_data[:5]
})
```

When working with numerical data, the key is to choose visualizations that best represent the specific characteristics you want to highlight:

- **Distributions**: Histograms, density plots, box plots
- **Relationships**: Scatter plots, bubble charts, line plots
- **Patterns across categories**: Grouped bar charts, violin plots
- **High-dimensional data**: Heat maps, contour plots, 3D surface plots

## 2. Histograms and Density Plots

Histograms and density plots are fundamental tools for visualizing the distribution of a single numerical variable. They allow you to see the shape, central tendency, and spread of your data.

```python
# Create a figure with multiple plots
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Simple histogram of normal distribution
axes[0, 0].hist(normal_data, bins=30, alpha=0.7, color='blue')
axes[0, 0].set_title('Histogram of Normal Distribution')
axes[0, 0].set_xlabel('Value')
axes[0, 0].set_ylabel('Frequency')

# Histogram with density normalization and KDE
sns.histplot(normal_data, bins=30, kde=True, ax=axes[0, 1], color='darkblue')
axes[0, 1].set_title('Histogram with KDE')
axes[0, 1].set_xlabel('Value')
axes[0, 1].set_ylabel('Density')

# Comparing distributions with KDE
sns.kdeplot(normal_data, ax=axes[1, 0], label='Normal', fill=True, alpha=0.3)
sns.kdeplot(bimodal_data, ax=axes[1, 0], label='Bimodal', fill=True, alpha=0.3)
axes[1, 0].set_title('KDE Comparison of Distributions')
axes[1, 0].set_xlabel('Value')
axes[1, 0].set_ylabel('Density')
axes[1, 0].legend()

# 2D density plot (hexbin) for two variables
x = np.random.normal(size=1000)
y = x * 0.5 + np.random.normal(size=1000, scale=0.5)
axes[1, 1].hexbin(x, y, gridsize=30, cmap='Blues')
axes[1, 1].set_title('2D Histogram (Hexbin Plot)')
axes[1, 1].set_xlabel('X Value')
axes[1, 1].set_ylabel('Y Value')

plt.tight_layout()
plt.show()

# Distplot with matplotlib and seaborn combined
plt.figure(figsize=(10, 6))
# Histogram
plt.hist(bimodal_data, bins=50, density=True, alpha=0.5, color='teal', 
        label='Histogram')
# Kernel Density Estimation
sns.kdeplot(bimodal_data, color='darkblue', linewidth=2, label='KDE')
# Add a rug plot at the bottom
plt.plot(bimodal_data, np.zeros_like(bimodal_data), '|', color='darkred', 
        alpha=0.5, markeredgewidth=1)

plt.title('Bimodal Distribution: Histogram, KDE, and Rug Plot')
plt.xlabel('Value')
plt.ylabel('Density')
plt.legend()
plt.tight_layout()
plt.show()
```

Key considerations for histograms and density plots:

1. **Bin width/number**: Too few bins can hide important features; too many can create noise
2. **Normalization**: For comparing distributions of different sizes, using density normalization is important
3. **Kernel Density Estimation (KDE)**: Smooths the histogram to emphasize the distribution shape
4. **Multiple distributions**: Overlaying multiple histograms or density plots helps in comparing distributions
5. **2D histograms**: For showing the distribution of two numerical variables together

## 3. Scatter Plots for Exploring Relationships

Scatter plots are powerful tools for visualizing relationships between two numerical variables. They can be enhanced with additional dimensions through color, size, and shape.

```python
# Generate data for scatter plot examples
np.random.seed(42)
n_points = 100

# Create correlated data
x = np.random.normal(size=n_points)
y_linear = x + np.random.normal(size=n_points, scale=0.5)  # Linear relationship
y_quad = x**2 + np.random.normal(size=n_points, scale=0.5)  # Quadratic relationship
y_none = np.random.normal(size=n_points)  # No relationship

# Create a categorical variable for grouping
categories = np.random.choice(['A', 'B', 'C'], size=n_points)
sizes = np.random.uniform(10, 100, size=n_points)

# Create a figure with multiple scatter plots
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Basic scatter plot
axes[0, 0].scatter(x, y_linear, alpha=0.7)
axes[0, 0].set_title('Basic Scatter Plot (Linear Relationship)')
axes[0, 0].set_xlabel('X Variable')
axes[0, 0].set_ylabel('Y Variable')

# Scatter plot with color groups
for category, color in zip(['A', 'B', 'C'], ['blue', 'red', 'green']):
    mask = categories == category
    axes[0, 1].scatter(x[mask], y_quad[mask], color=color, alpha=0.7, label=category)
axes[0, 1].set_title('Scatter Plot with Color Groups (Quadratic Relationship)')
axes[0, 1].set_xlabel('X Variable')
axes[0, 1].set_ylabel('Y Variable')
axes[0, 1].legend()

# Scatter plot with size variation
scatter = axes[1, 0].scatter(x, y_none, c=y_quad, s=sizes, alpha=0.7, cmap='viridis')
axes[1, 0].set_title('Scatter Plot with Size and Color Dimensions')
axes[1, 0].set_xlabel('X Variable')
axes[1, 0].set_ylabel('Y Variable')
plt.colorbar(scatter, ax=axes[1, 0], label='Y Quadratic Value')

# Scatter plot with regression line using seaborn
sns.regplot(x=x, y=y_linear, ax=axes[1, 1], scatter_kws={'alpha': 0.5})
axes[1, 1].set_title('Scatter Plot with Regression Line')
axes[1, 1].set_xlabel('X Variable')
axes[1, 1].set_ylabel('Y Variable')

plt.tight_layout()
plt.show()

# Scatter plot matrix with seaborn
data = pd.DataFrame({
    'x': x,
    'y_linear': y_linear,
    'y_quad': y_quad,
    'y_none': y_none,
    'category': categories
})

plt.figure(figsize=(10, 8))
sns.pairplot(data, hue='category', vars=['x', 'y_linear', 'y_quad', 'y_none'])
plt.suptitle('Scatter Plot Matrix (Pairplot)', y=1.02)
plt.show()
```

Key techniques for effective scatter plots:

1. **Simple scatter**: Shows basic relationship between two variables
2. **Color grouping**: Adds a categorical dimension to identify patterns by group
3. **Size variation**: Adds another numerical dimension (bubble chart)
4. **Regression lines**: Helps visualize the trend and strength of relationships
5. **Scatter plot matrix**: Shows relationships between multiple numerical variables at once
6. **Alpha transparency**: Essential when plotting many points to see density of overlapping points

## 4. Box Plots and Violin Plots for Distributions

Box plots and violin plots provide a concise way to visualize the distribution of numerical data, especially when comparing across categories or groups.

```python
# Generate data for box plot and violin plot examples
np.random.seed(42)

# Create data from different distributions
data = {
    'Group A': np.random.normal(0, 1, 200),
    'Group B': np.random.normal(2, 0.5, 200),
    'Group C': np.random.exponential(1, 200),
    'Group D': np.random.lognormal(0, 0.5, 200)
}

# Convert to DataFrame for easier plotting
df = pd.DataFrame({k: pd.Series(v) for k, v in data.items()})

# Create a figure with box plots and violin plots
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Basic box plot
sns.boxplot(data=df, ax=axes[0, 0])
axes[0, 0].set_title('Basic Box Plot Comparison')
axes[0, 0].set_xlabel('Group')
axes[0, 0].set_ylabel('Value')

# Box plot with individual points
sns.boxplot(data=df, ax=axes[0, 1], width=0.5)
sns.stripplot(data=df, ax=axes[0, 1], color='black', alpha=0.5, jitter=True)
axes[0, 1].set_title('Box Plot with Individual Points')
axes[0, 1].set_xlabel('Group')
axes[0, 1].set_ylabel('Value')

# Basic violin plot
sns.violinplot(data=df, ax=axes[1, 0])
axes[1, 0].set_title('Basic Violin Plot Comparison')
axes[1, 0].set_xlabel('Group')
axes[1, 0].set_ylabel('Value')

# Split violin plot with additional information
sns.violinplot(data=df, inner='quartile', cut=0, ax=axes[1, 1])
axes[1, 1].set_title('Violin Plot with Quartiles')
axes[1, 1].set_xlabel('Group')
axes[1, 1].set_ylabel('Value')

plt.tight_layout()
plt.show()

# Create a dataset with multiple groups for paired comparison
group_data = pd.DataFrame({
    'value': np.concatenate([data['Group A'], data['Group B'], data['Group C']]),
    'group': np.repeat(['A', 'B', 'C'], 200),
    'subgroup': np.concatenate([np.repeat(['X', 'Y'], 100) for _ in range(3)])
})

# Plot box plot with grouped data
plt.figure(figsize=(12, 6))
sns.boxplot(x='group', y='value', hue='subgroup', data=group_data, palette='Set3')
plt.title('Grouped Box Plot Comparison')
plt.xlabel('Main Group')
plt.ylabel('Value')
plt.legend(title='Subgroup')
plt.tight_layout()
plt.show()
```

Box plots and violin plots offer these advantages:

1. **Compact summary**: Show median, quartiles, range, and outliers in a compact form
2. **Group comparison**: Easily compare distributions across multiple categories
3. **Violin plots**: Add density information to better visualize the distribution shape
4. **Outlier detection**: Clearly identify outliers beyond the whiskers
5. **Layering individual points**: Adding individual data points helps show the actual data distribution

## 5. Line Plots for Trends and Time Series

Line plots are ideal for visualizing trends over time or across a continuous sequence. They emphasize the continuity and rate of change between data points.

```python
# Generate time series data
np.random.seed(42)
dates = pd.date_range(start='2023-01-01', periods=100, freq='D')
linear_trend = np.linspace(0, 10, 100)
seasonal = 2 * np.sin(np.linspace(0, 4*np.pi, 100))
noise = np.random.normal(0, 0.5, 100)

# Create different time series
ts1 = linear_trend + seasonal + noise
ts2 = linear_trend * 0.5 + seasonal * 1.5 + noise
ts3 = linear_trend * 0.3 + np.roll(seasonal, 25) + noise

# Create DataFrame
ts_df = pd.DataFrame({
    'date': dates,
    'Series 1': ts1,
    'Series 2': ts2,
    'Series 3': ts3
})

# Create a figure with line plots
fig, axes = plt.subplots(3, 1, figsize=(12, 12))

# Basic line plot
axes[0].plot(ts_df['date'], ts_df['Series 1'], linewidth=2)
axes[0].set_title('Basic Line Plot of Time Series')
axes[0].set_xlabel('Date')
axes[0].set_ylabel('Value')
axes[0].grid(True)

# Multiple series comparison
axes[1].plot(ts_df['date'], ts_df['Series 1'], label='Series 1')
axes[1].plot(ts_df['date'], ts_df['Series 2'], label='Series 2')
axes[1].plot(ts_df['date'], ts_df['Series 3'], label='Series 3')
axes[1].set_title('Multiple Time Series Comparison')
axes[1].set_xlabel('Date')
axes[1].set_ylabel('Value')
axes[1].legend()
axes[1].grid(True)

# Line plot with area fill
axes[2].plot(ts_df['date'], ts_df['Series 1'], linewidth=2, color='blue')
axes[2].fill_between(ts_df['date'], ts_df['Series 1'], alpha=0.3, color='blue')
axes[2].set_title('Line Plot with Area Fill')
axes[2].set_xlabel('Date')
axes[2].set_ylabel('Value')
axes[2].grid(True)

plt.tight_layout()
plt.show()

# Line plot with subplot for zoomed section
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8), 
                             gridspec_kw={'height_ratios': [3, 1]})

# Main plot with all data
for col, color in zip(['Series 1', 'Series 2', 'Series 3'], ['blue', 'red', 'green']):
    ax1.plot(ts_df['date'], ts_df[col], label=col, color=color)
ax1.set_title('Time Series with Zoomed Section')
ax1.legend()
ax1.grid(True)

# Highlight the region to zoom
zoom_start = 30
zoom_end = 50
ax1.axvspan(dates[zoom_start], dates[zoom_end], color='gray', alpha=0.2)

# Zoomed plot
for col, color in zip(['Series 1', 'Series 2', 'Series 3'], ['blue', 'red', 'green']):
    ax2.plot(ts_df['date'][zoom_start:zoom_end+1], ts_df[col][zoom_start:zoom_end+1], 
            color=color)
ax2.set_title('Zoomed Section')
ax2.grid(True)

plt.tight_layout()
plt.show()
```

Effective techniques for line plots:

1. **Multiple series**: Compare different datasets over the same sequence
2. **Area fills**: Emphasize the magnitude of values or show confidence intervals
3. **Markers**: Add points to highlight individual observations
4. **Zoomed sections**: Focus on important details while maintaining context
5. **Trend lines**: Add smoothed curves to show underlying trends beneath noisy data
6. **Dual axes**: Show variables with different scales on the same plot (use cautiously)

## 6. Heat Maps for Numerical Matrices

Heat maps are excellent for visualizing numerical matrices, correlation matrices, or data with two categorical dimensions and a numerical value.

```python
# Generate data for heatmap examples
np.random.seed(42)

# Create correlation matrix from random data
data = np.random.randn(100, 5)
columns = ['Variable A', 'Variable B', 'Variable C', 'Variable D', 'Variable E']
df = pd.DataFrame(data, columns=columns)
correlation_matrix = df.corr()

# Create a 2D matrix with a pattern
x = np.linspace(-3, 3, 30)
y = np.linspace(-3, 3, 30)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y)

# Create a figure with heatmaps
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Basic correlation matrix heatmap
sns.heatmap(correlation_matrix, annot=True, cmap='coolwarm', vmin=-1, vmax=1, ax=axes[0, 0])
axes[0, 0].set_title('Correlation Matrix Heatmap')

# 2D function visualization with heatmap
im = axes[0, 1].imshow(Z, cmap='viridis', extent=[-3, 3, -3, 3], origin='lower')
axes[0, 1].set_title('2D Function Visualization')
axes[0, 1].set_xlabel('X axis')
axes[0, 1].set_ylabel('Y axis')
fig.colorbar(im, ax=axes[0, 1])

# Generate categorical heatmap data
categories1 = ['Cat A', 'Cat B', 'Cat C', 'Cat D', 'Cat E']
categories2 = ['Group 1', 'Group 2', 'Group 3', 'Group 4']
cat_data = np.random.randint(0, 100, size=(5, 4))
cat_df = pd.DataFrame(cat_data, index=categories1, columns=categories2)

# Categorical heatmap
sns.heatmap(cat_df, annot=True, fmt='d', cmap='YlGnBu', ax=axes[1, 0])
axes[1, 0].set_title('Categorical Heatmap')
axes[1, 0].set_xlabel('Category 2')
axes[1, 0].set_ylabel('Category 1')

# Create time-based heatmap data
dates = pd.date_range('2023-01-01', periods=12, freq='M')
times = [f'{hour}:00' for hour in range(24)]
time_data = np.random.randint(0, 100, size=(12, 24))
time_df = pd.DataFrame(time_data, index=dates, columns=times)

# Time-based heatmap
sns.heatmap(time_df, cmap='rocket_r', ax=axes[1, 1])
axes[1, 1].set_title('Time-Based Heatmap (Monthly x Hourly)')
axes[1, 1].set_xlabel('Hour of Day')
axes[1, 1].set_ylabel('Month')
axes[1, 1].set_yticks(np.arange(len(dates)))
axes[1, 1].set_yticklabels([d.strftime('%b %Y') for d in dates])
axes[1, 1].set_xticks(np.arange(0, 24, 3))
axes[1, 1].set_xticklabels([f'{h}:00' for h in range(0, 24, 3)])

plt.tight_layout()
plt.show()

# Seaborn clustermap for reordered correlation matrix
plt.figure(figsize=(10, 8))
sns.clustermap(correlation_matrix, cmap='coolwarm', vmin=-1, vmax=1, 
              annot=True, standard_scale=1)
plt.title('Clustered Correlation Matrix', pad=50)
plt.show()
```

Key applications for heatmaps:

1. **Correlation matrices**: Visualize relationships between many variables at once
2. **Categorical cross-tabulations**: Show counts or metrics across two categorical dimensions
3. **Time-based patterns**: Visualize patterns across time dimensions (e.g., day of week × hour of day)
4. **Spatial data**: Show intensity across geographical regions
5. **Clustered heatmaps**: Reorder rows and columns to reveal patterns and groupings
6. **Distance matrices**: Visualize similarity or distance between pairs of observations

## 7. Contour and Surface Plots for 3D Data

When working with three-dimensional numerical data, contour plots and surface plots help visualize relationships between three variables.

```python
# Import 3D plotting tools
from mpl_toolkits.mplot3d import Axes3D
from matplotlib import cm

# Create data for 3D visualization
x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)

# Create different 3D surfaces
Z1 = np.sin(X) * np.cos(Y)
Z2 = X**2 + Y**2
Z3 = np.sin(np.sqrt(X**2 + Y**2))

# Create a figure with 3D plots
fig = plt.figure(figsize=(16, 12))

# 1. Basic contour plot
ax1 = fig.add_subplot(221)
cp = ax1.contour(X, Y, Z1, levels=15, cmap='viridis')
ax1.clabel(cp, inline=True, fontsize=8)
ax1.set_title('Contour Plot')
ax1.set_xlabel('X')
ax1.set_ylabel('Y')

# 2. Filled contour plot
ax2 = fig.add_subplot(222)
cf = ax2.contourf(X, Y, Z2, levels=20, cmap='plasma')
plt.colorbar(cf, ax=ax2)
ax2.set_title('Filled Contour Plot')
ax2.set_xlabel('X')
ax2.set_ylabel('Y')

# 3. 3D surface plot
ax3 = fig.add_subplot(223, projection='3d')
surf = ax3.plot_surface(X, Y, Z3, cmap='coolwarm', 
                       linewidth=0, antialiased=True)
ax3.set_title('3D Surface Plot')
ax3.set_xlabel('X')
ax3.set_ylabel('Y')
ax3.set_zlabel('Z')

# 4. 3D wire frame plot
ax4 = fig.add_subplot(224, projection='3d')
wire = ax4.plot_wireframe(X, Y, Z1, rstride=5, cstride=5, color='darkblue')
ax4.set_title('3D Wire Frame Plot')
ax4.set_xlabel('X')
ax4.set_ylabel('Y')
ax4.set_zlabel('Z')

plt.tight_layout()
plt.show()

# Create 3D scatter plot
fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')

# Generate 3D scatter data
n_points = 500
x_scatter = np.random.normal(0, 1, n_points)
y_scatter = np.random.normal(0, 1, n_points)
z_scatter = np.random.normal(0, 1, n_points)
colors = np.sqrt(x_scatter**2 + y_scatter**2 + z_scatter**2)

scatter = ax.scatter(x_scatter, y_scatter, z_scatter, c=colors, s=30, cmap='viridis', alpha=0.8)
plt.colorbar(scatter, ax=ax, label='Distance from Origin')
ax.set_title('3D Scatter Plot')
ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')

plt.tight_layout()
plt.show()
```

Contour and 3D plots are useful for:

1. **Multivariate functions**: Visualizing functions of two variables
2. **Geographical data**: Showing elevation or other metrics across a landscape
3. **Statistical surfaces**: Displaying probability densities or likelihood functions
4. **Scientific data**: Visualizing physical phenomena like temperature gradients or pressure fields
5. **Optimization landscapes**: Understanding the shape of objective functions in optimization problems

## 8. Combining Multiple Visualization Types

Often, the most insightful visualizations combine multiple types to show different aspects of the same data.

```python
# Generate data for combined visualizations
np.random.seed(42)
data = np.random.normal(loc=0, scale=1, size=1000)

# Create a figure combining a histogram with a boxplot
fig, axes = plt.subplots(2, 1, figsize=(10, 8), 
                        gridspec_kw={'height_ratios': [3, 1]})

# Histogram with KDE on top
sns.histplot(data, kde=True, bins=30, ax=axes[0])
axes[0].set_title('Distribution of Data')
axes[0].set_xlabel('')  # Remove x-label from top plot
axes[0].set_xlim(-4, 4)  # Set consistent x-axis limits

# Boxplot below
sns.boxplot(x=data, ax=axes[1])
axes[1].set_title('')
axes[1].set_xlabel('Value')
axes[1].set_xlim(-4, 4)  # Same x-axis limits as histogram

plt.tight_layout()
plt.show()

# Create a scatter plot with marginal distributions
# (Similar to what you'd see in seaborn's jointplot)
fig = plt.figure(figsize=(10, 8))

# Create a gridspec layout
gs = fig.add_gridspec(2, 2,  width_ratios=(4, 1), height_ratios=(1, 4),
                     left=0.1, right=0.9, bottom=0.1, top=0.9,
                     wspace=0.05, hspace=0.05)

# Create the scatter plot
ax_scatter = fig.add_subplot(gs[1, 0])
# Create top histogram
ax_histx = fig.add_subplot(gs[0, 0], sharex=ax_scatter)
# Create right histogram
ax_histy = fig.add_subplot(gs[1, 1], sharey=ax_scatter)

# Turn off tick labels on marginal plots
ax_histx.tick_params(axis="x", labelbottom=False)
ax_histy.tick_params(axis="y", labelleft=False)

# Generate correlated data
x = np.random.normal(0, 1, 1000)
y = x * 0.7 + np.random.normal(0, 0.5, 1000)

# Scatter plot
ax_scatter.scatter(x, y, alpha=0.6)
ax_scatter.set_xlabel('X Value')
ax_scatter.set_ylabel('Y Value')
ax_scatter.grid(True, alpha=0.3)

# X histogram on top
ax_histx.hist(x, bins=30, alpha=0.7)
ax_histx.grid(True, alpha=0.3)

# Y histogram on right
ax_histy.hist(y, bins=30, orientation='horizontal', alpha=0.7)
ax_histy.grid(True, alpha=0.3)

plt.suptitle('Scatter Plot with Marginal Distributions', y=0.98)
plt.show()

# Combine scatter and line plot to show regression
plt.figure(figsize=(10, 6))

# Generate data with a clear trend
x = np.linspace(0, 10, 100)
y = 2 * x + 1 + np.random.normal(0, 2, 100)

# Create scatter plot of raw data
plt.scatter(x, y, alpha=0.6, label='Data points')

# Add regression line
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(x.reshape(-1, 1), y)
y_pred = model.predict(x.reshape(-1, 1))
plt.plot(x, y_pred, color='red', linewidth=2, label=f'Regression line (slope={model.coef_[0]:.2f})')

# Add confidence interval
from scipy import stats
# Calculate confidence interval
pred = model.predict(x.reshape(-1, 1))
# Get mean squared error
n = len(x)
y_err = y - pred
mse = np.sum(y_err**2) / (n-2)
std_err = np.sqrt(mse * (1/n + (x - np.mean(x))**2 / np.sum((x - np.mean(x))**2)))
t = stats.t.ppf(0.975, n-2)
ci = t * std_err

# Plot confidence interval
plt.fill_between(x, pred - ci, pred + ci, color='gray', alpha=0.2, label='95% Confidence Interval')

plt.title('Scatter Plot with Regression Line and Confidence Interval')
plt.xlabel('X Value')
plt.ylabel('Y Value')
plt.legend()
```

## 10. Summary and Best Practices

Visualizing numerical data effectively is crucial for exploratory data analysis, identifying patterns, and communicating insights. Here are key best practices to follow:

1. **Choose the right visualization type:**
   - Use histograms and density plots for distributions
   - Use scatter plots for relationships between variables
   - Use line plots for trends over time or sequences
   - Use box plots and violin plots for comparing distributions
   - Use heatmaps for correlation matrices or 2D patterns
   - Use contour and surface plots for 3D relationships

2. **Ensure clarity and accuracy:**
   - Label axes clearly with units
   - Use appropriate scales (linear, logarithmic)
   - Include titles and legends
   - Consider the aspect ratio and size
   - Avoid distorting data with improper scales

3. **Enhance with statistical information:**
   - Add trend lines or curves to show patterns
   - Include confidence intervals where appropriate
   - Show summary statistics (mean, median, etc.)
   - Use statistical transformations when needed

4. **Consider the audience:**
   - Adjust complexity based on the viewer's expertise
   - Use color effectively but be mindful of colorblindness
   - Balance between aesthetics and information density
   - Consider interactive visualizations for complex data exploration

5. **Iterate and refine:**
   - Start with simple visualizations
   - Add complexity as needed to reveal patterns
   - Remove elements that don't contribute to understanding
   - Get feedback and refine your approach

By following these guidelines and using the Python visualization tools shown in this guide, you'll be able to create effective, informative, and visually appealing representations of numerical data that help you and others gain valuable insights.
