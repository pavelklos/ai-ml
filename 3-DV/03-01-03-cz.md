## 1. Úvod do histogramů a distribučních grafů

Histogramy a distribuční grafy jsou základními nástroji pro pochopení distribuce dat. Histogramy zobrazují četnost nebo počet hodnot v rámci intervalů (binů), zatímco hustotní grafy (jako KDE grafy) ukazují vyhlazenou verzi distribuce.

Tyto vizualizace vám pomáhají:
- Identifikovat tvar distribuce dat (normální, zešikmená, bimodální)
- Odhalit odlehlé hodnoty a anomálie
- Porovnávat distribuce napříč různými skupinami
- Pochopit centrální tendenci a rozptyl dat

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení stylu vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_palette('muted')

# Generování vzorových dat
np.random.seed(42)  # Pro reprodukovatelnost
normal_data = np.random.normal(0, 1, 1000)  # Průměr=0, SD=1, 1000 bodů
skewed_data = np.random.exponential(2, 1000)  # Exponenciální s lambda=2
bimodal_data = np.concatenate([
    np.random.normal(-3, 1, 500),  # První vrchol
    np.random.normal(3, 1, 500)     # Druhý vrchol
])

# Vytvoření obrázku s ukázkovými distribucemi
fig, ax = plt.subplots(3, 1, figsize=(10, 8))

# Vykreslení tří různých distribucí
ax[0].hist(normal_data, bins=30, alpha=0.7, color='steelblue')
ax[0].set_title('Normální distribuce')

ax[1].hist(skewed_data, bins=30, alpha=0.7, color='green')
ax[1].set_title('Zešikmená (Exponenciální) distribuce')

ax[2].hist(bimodal_data, bins=30, alpha=0.7, color='purple')
ax[2].set_title('Bimodální distribuce')

plt.tight_layout()
plt.show()
```

## 2. Základní histogramy s Matplotlib

Matplotlib poskytuje funkci `hist()` pro vytváření histogramů, která je jednoduchá, ale výkonná. Počet intervalů (binů) je klíčovým parametrem, který ovlivňuje, jak se distribuce vizualizuje.

```python
# Vytvoření vzorových dat
data = np.random.normal(0, 1, 1000)

# Vytvoření základního histogramu
plt.figure(figsize=(10, 6))
plt.hist(data, bins=30, color='steelblue', alpha=0.7, edgecolor='black')
plt.title('Základní histogram', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Četnost', fontsize=12)
plt.grid(axis='y', alpha=0.75)
plt.show()

# Vliv velikosti binů
fig, axs = plt.subplots(1, 3, figsize=(15, 5))

# Málo binů (příliš hrubé)
axs[0].hist(data, bins=5, color='steelblue', alpha=0.7, edgecolor='black')
axs[0].set_title('Příliš málo binů (5)')

# Vhodný počet binů
axs[1].hist(data, bins=30, color='steelblue', alpha=0.7, edgecolor='black')
axs[1].set_title('Vhodný počet binů (30)')

# Příliš mnoho binů (příliš zašuměné)
axs[2].hist(data, bins=100, color='steelblue', alpha=0.7, edgecolor='black')
axs[2].set_title('Příliš mnoho binů (100)')

plt.tight_layout()
plt.show()
```

## 3. Pokročilé úpravy histogramů

Histogramy lze rozšířit o další funkce, jako je normalizace, kumulativní počty a možnosti stylizace.

```python
# Vytvoření vzorových dat
np.random.seed(42)
data = np.random.normal(0, 1, 1000)

# Obrázek s více typy histogramů
fig, axs = plt.subplots(2, 2, figsize=(12, 8))

# Standardní histogram
axs[0, 0].hist(data, bins=30, color='steelblue', alpha=0.7, edgecolor='black')
axs[0, 0].set_title('Standardní histogram')
axs[0, 0].set_ylabel('Četnost')

# Normalizovaný histogram (hustota pravděpodobnosti)
axs[0, 1].hist(data, bins=30, density=True, color='green', alpha=0.7, edgecolor='black')
axs[0, 1].set_title('Normalizovaný histogram (PDF)')
axs[0, 1].set_ylabel('Hustota pravděpodobnosti')

# Kumulativní histogram
axs[1, 0].hist(data, bins=30, cumulative=True, color='purple', alpha=0.7, edgecolor='black')
axs[1, 0].set_title('Kumulativní histogram')
axs[1, 0].set_ylabel('Kumulativní četnost')

# Kumulativní normalizovaný (CDF)
axs[1, 1].hist(data, bins=30, density=True, cumulative=True, 
             color='orange', alpha=0.7, edgecolor='black')
axs[1, 1].set_title('Kumulativní normalizovaný (CDF)')
axs[1, 1].set_ylabel('Kumulativní pravděpodobnost')

for ax in axs.flat:
    ax.set_xlabel('Hodnota')
    ax.grid(True, linestyle='--', alpha=0.7)

plt.tight_layout()
plt.show()

# Stylizovaný histogram se svislými čarami pro statistiky
plt.figure(figsize=(10, 6))
n, bins, patches = plt.hist(data, bins=30, color='skyblue', 
                           alpha=0.7, edgecolor='black')

# Přidání svislých čar pro průměr a medián
plt.axvline(np.mean(data), color='red', linestyle='dashed', linewidth=2, label=f'Průměr: {np.mean(data):.2f}')
plt.axvline(np.median(data), color='green', linestyle='dotted', linewidth=2, label=f'Medián: {np.median(data):.2f}')

# Přidání rozsahu jedné směrodatné odchylky
plt.axvspan(np.mean(data) - np.std(data), np.mean(data) + np.std(data), 
           alpha=0.2, color='red', label=f'±1 Směr. odch.: {np.std(data):.2f}')

plt.title('Histogram se statistickými ukazateli', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Četnost', fontsize=12)
plt.legend()
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()
```

## 4. Hustotní grafy a KDE

Grafy jádrového odhadu hustoty (KDE) poskytují vyhlazenou verzi histogramu, která ukazuje funkci hustoty pravděpodobnosti dat.

```python
# Vytvoření vzorových dat
np.random.seed(42)
data = np.random.normal(0, 1, 1000)
skewed_data = np.random.exponential(2, 1000)

# Histogram s překrytím KDE
plt.figure(figsize=(10, 6))

# Vykreslení histogramu
plt.hist(data, bins=30, density=True, alpha=0.6, color='steelblue', edgecolor='black', label='Histogram')

# Vykreslení KDE navrch
sns.kdeplot(data, color='red', linewidth=2, label='KDE')

plt.title('Histogram s překryvem KDE', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Hustota', fontsize=12)
plt.legend()
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Porovnání hustoty histogramu s různými šířkami pásma KDE
plt.figure(figsize=(12, 6))

plt.hist(skewed_data, bins=30, density=True, alpha=0.4, color='gray', edgecolor='black', label='Histogram')

# KDE s různými šířkami pásma
sns.kdeplot(skewed_data, bw_adjust=0.2, color='red', linewidth=2, label='KDE (úzké pásmo)')
sns.kdeplot(skewed_data, bw_adjust=1.0, color='green', linewidth=2, label='KDE (výchozí pásmo)')
sns.kdeplot(skewed_data, bw_adjust=2.0, color='blue', linewidth=2, label='KDE (široké pásmo)')

plt.title('Vliv šířky pásma KDE na vyhlazení', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Hustota', fontsize=12)
plt.legend()
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()
```

## 5. Porovnání více distribucí

Porovnání více distribucí je běžným úkolem při analýze dat. Můžeme překrývat histogramy nebo používat specializované grafy.

```python
# Vytvoření více datových sad
np.random.seed(42)
group_a = np.random.normal(0, 1, 1000)
group_b = np.random.normal(0.5, 1.5, 1000)
group_c = np.random.normal(-0.5, 0.8, 1000)

# Přístup 1: Překryté histogramy s průhledností
plt.figure(figsize=(10, 6))

plt.hist(group_a, bins=30, alpha=0.5, label='Skupina A')
plt.hist(group_b, bins=30, alpha=0.5, label='Skupina B')
plt.hist(group_c, bins=30, alpha=0.5, label='Skupina C')

plt.title('Porovnání více distribucí: Překryté histogramy', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Počet', fontsize=12)
plt.legend()
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Přístup 2: KDE grafy pro hladší porovnání
plt.figure(figsize=(10, 6))

sns.kdeplot(group_a, label='Skupina A')
sns.kdeplot(group_b, label='Skupina B')
sns.kdeplot(group_c, label='Skupina C')

plt.title('Porovnání více distribucí: KDE grafy', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Hustota', fontsize=12)
plt.legend()
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Přístup 3: Krabicové grafy vedle sebe
plt.figure(figsize=(10, 6))

data_to_plot = [group_a, group_b, group_c]
labels = ['Skupina A', 'Skupina B', 'Skupina C']

plt.boxplot(data_to_plot, labels=labels, patch_artist=True)
plt.title('Porovnání více distribucí: Krabicové grafy', fontsize=16)
plt.xlabel('Skupina', fontsize=12)
plt.ylabel('Hodnota', fontsize=12)
plt.grid(True, linestyle='--', axis='y', alpha=0.7)
plt.show()
```

## 6. Distribuční grafy pomocí Seaborn

Knihovna Seaborn poskytuje specializované funkce pro vizualizaci distribucí, které kombinují více prvků pro komplexní vizualizaci.

```python
# Import požadovaných knihoven
import seaborn as sns
import numpy as np
import matplotlib.pyplot as plt

# Generování vzorových dat
np.random.seed(42)
data = np.random.normal(0, 1, 1000)

# Seaborn distplot (kombinuje histogram a KDE)
plt.figure(figsize=(10, 6))
sns.histplot(data, kde=True, bins=30, color='steelblue')
plt.title('Seaborn histogram s KDE', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Počet', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Seaborn displot (funkce na úrovni obrázku)
sns.displot(data, kde=True, bins=30, height=6, aspect=1.5)
plt.title('Seaborn displot', fontsize=16)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Seaborn kdeplot 
plt.figure(figsize=(10, 6))
sns.kdeplot(data, fill=True)
plt.title('Seaborn KDE graf', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Hustota', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Vytvoření dataframe s kategorickou proměnnou
df = pd.DataFrame({
    'value': np.concatenate([np.random.normal(0, 1, 500), 
                            np.random.normal(2, 1, 500)]),
    'group': ['A'] * 500 + ['B'] * 500
})

# Histogram podle kategorie
plt.figure(figsize=(10, 6))
sns.histplot(data=df, x='value', hue='group', element='step', common_norm=False, bins=30)
plt.title('Seaborn histogram podle kategorie', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Počet', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()
```

## 7. Statistické překryvy

Přidání statistických informací do distribučních grafů může zvýšit jejich interpretační hodnotu.

```python
# Generování vzorových dat
np.random.seed(42)
data = np.random.normal(0, 1, 1000)

# Vytvoření obrázku
plt.figure(figsize=(10, 6))

# Vytvoření histogramu
sns.histplot(data, kde=True, bins=30, stat='density', color='skyblue', edgecolor='black', alpha=0.7)

# Přidání křivky normálního rozdělení pro porovnání
x = np.linspace(min(data), max(data), 100)
y = 1/(1 * np.sqrt(2 * np.pi)) * np.exp( - (x - 0)**2 / (2 * 1**2))
plt.plot(x, y, 'r-', linewidth=2, label='Normální rozdělení (μ=0, σ=1)')

# Přidání svislých čar pro statistiky
plt.axvline(np.mean(data), color='green', linestyle='dashed', linewidth=2, label=f'Průměr: {np.mean(data):.2f}')
plt.axvline(np.median(data), color='orange', linestyle='dotted', linewidth=2, label=f'Medián: {np.median(data):.2f}')

# Přidání percentilů
percentiles = [25, 75]
for p in percentiles:
    value = np.percentile(data, p)
    plt.axvline(value, color='purple', linestyle=':', linewidth=1, alpha=0.7,
               label=f'{p}. percentil: {value:.2f}')

# Výpočet a zobrazení souhrnných statistik v textovém poli
mean = np.mean(data)
median = np.median(data)
std = np.std(data)
q1 = np.percentile(data, 25)
q3 = np.percentile(data, 75)
iqr = q3 - q1

stats_text = (
    f"Průměr: {mean:.2f}\n"
    f"Medián: {median:.2f}\n"
    f"Směr. odch.: {std:.2f}\n"
    f"IQR: {iqr:.2f}\n"
    f"Šikmost: {pd.Series(data).skew():.2f}\n"
    f"Špičatost: {pd.Series(data).kurtosis():.2f}"
)

# Přidání textového pole se statistikami
plt.text(0.02, 0.95, stats_text, transform=plt.gca().transAxes, 
         bbox=dict(facecolor='white', alpha=0.8, boxstyle='round,pad=0.5'),
         verticalalignment='top', fontsize=10)

plt.title('Histogram se statistickými překryvy', fontsize=16)
plt.xlabel('Hodnota', fontsize=12)
plt.ylabel('Hustota', fontsize=12)
plt.legend(loc='upper right')
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()
```

## 8. Vícerozměrné distribuce

Při práci s více proměnnými můžeme použít specializované grafy k vizualizaci jejich společné distribuce.

```python
# Generování vícerozměrných dat
np.random.seed(42)
mean = [0, 0]
cov = [[1, 0.7], [0.7, 1]]  # Kovarianční matice s pozitivní korelací
x, y = np.random.multivariate_normal(mean, cov, 1000).T

# Vytvoření dataframe pro snadné vykreslování
df = pd.DataFrame({
    'x': x,
    'y': y
})

# Joint plot (kombinuje bodový graf s okrajovými histogramy)
sns.jointplot(data=df, x='x', y='y', kind='scatter', height=8, 
              marginal_kws=dict(bins=30, fill=True))
plt.suptitle('Joint distribuční graf', y=1.02, fontsize=16)
plt.tight_layout()
plt.show()

# Joint plot s KDE
sns.jointplot(data=df, x='x', y='y', kind='kde', height=8, fill=True, cmap='Blues')
plt.suptitle('Joint KDE graf', y=1.02, fontsize=16)
plt.tight_layout()
plt.show()

# 2D histogram (hexbin)
plt.figure(figsize=(10, 8))
plt.hexbin(x, y, gridsize=30, cmap='Blues', mincnt=1)
plt.colorbar(label='Počet')
plt.title('2D histogram (Hexbin)', fontsize=16)
plt.xlabel('Hodnota X', fontsize=12)
plt.ylabel('Hodnota Y', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# 2D KDE graf
plt.figure(figsize=(10, 8))
sns.kdeplot(x=x, y=y, cmap='Reds', fill=True, thresh=0.05, levels=15)
plt.title('2D KDE graf', fontsize=16)
plt.xlabel('Hodnota X', fontsize=12)
plt.ylabel('Hodnota Y', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()
```

## 9. Běžné případy použití a příklady

Nyní prozkoumejme některé případy použití histogramů a distribučních grafů z reálného světa.

```python
# Příklad 1: Analýza reálného datasetu
from sklearn.datasets import load_diabetes

# Načtení datasetu diabetes
diabetes = load_diabetes()
X = diabetes.data
y = diabetes.target

# Převod na DataFrame pro snazší manipulaci
diabetes_df = pd.DataFrame(X, columns=diabetes.feature_names)
diabetes_df['target'] = y

# Vizualizace distribuce cílové proměnné
plt.figure(figsize=(10, 6))
sns.histplot(diabetes_df['target'], kde=True, bins=30)
plt.title('Distribuce progrese diabetu', fontsize=16)
plt.xlabel('Progrese nemoci', fontsize=12)
plt.ylabel('Počet', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Příklad 2: Porovnání distribucí příznaků
plt.figure(figsize=(12, 10))

features = diabetes.feature_names[:4]  # Použití prvních 4 příznaků
for i, feature in enumerate(features, 1):
    plt.subplot(2, 2, i)
    sns.histplot(diabetes_df[feature], kde=True)
    plt.title(f'Distribuce příznaku {feature}')
    plt.grid(True, linestyle='--', alpha=0.7)

plt.tight_layout()
plt.show()

# Příklad 3: Vizualizace distribuce podle skupin
from sklearn.datasets import load_iris

# Načtení datasetu iris
iris = load_iris()
iris_df = pd.DataFrame(iris.data, columns=iris.feature_names)
iris_df['species'] = [iris.target_names[i] for i in iris.target]

# Vizualizace délky kalichu podle druhu
plt.figure(figsize=(12, 6))
sns.histplot(data=iris_df, x='sepal length (cm)', hue='species', 
            element='step', common_norm=False, bins=20)
plt.title('Distribuce délky kalichu podle druhu', fontsize=16)
plt.xlabel('Délka kalichu (cm)', fontsize=12)
plt.ylabel('Počet', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.show()

# Distribuční mřížka pro všechny příznaky podle druhu
sns.displot(
    data=iris_df,
    x='sepal length (cm)', col='species',
    kde=True, height=4, aspect=1
)
plt.suptitle('Délka kalichu podle druhu', y=1.05)
plt.tight_layout()
plt.show()
```

## 10. Shrnutí

Histogramy a distribuční grafy jsou základními nástroji pro pochopení charakteristik vašich dat:

- **Histogramy** představují četnost dat v rámci binů, poskytující náhled na tvar distribuce dat
- **KDE grafy** nabízejí hladkou spojitou verzi histogramu
- **Statistické překryvy** vylepšují grafy klíčovými metrikami jako průměr, medián a percentily
- **Seaborn** poskytuje specializované nástroje pro vizualizaci distribucí jako `histplot`, `kdeplot` a `displot`
- **Vícerozměrné distribuce** lze vizualizovat pomocí joint plotů, 2D histogramů a 2D KDE grafů

Klíčové úvahy při vytváření těchto vizualizací zahrnují:

1. Výběr vhodné velikosti binu pro histogramy
2. Použití hustotních grafů (KDE) pro hladší vizualizaci základní distribuce
3. Přidání statistických informací pro poskytnutí kontextu
4. Porovnávání distribucí pomocí překryvů nebo grafů vedle sebe
5. Pro vícerozměrnou analýzu použití joint plotů nebo 2D vizualizací

Při interpretaci distribučních grafů hledejte vzory jako:
- Centrální tendence a rozptyl
- Šikmost a asymetrie
- Více vrcholů (bimodální nebo multimodální distribuce)
- Odlehlé hodnoty a neobvyklé vzory

Zvládnutí těchto vizualizačních technik vám pomůže získat hlubší vhled do vašich dat a efektivněji komunikovat vaše zjištění.
