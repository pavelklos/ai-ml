## 1. Úvod do vizualizace numerických dat

Vizualizace numerických dat je nezbytná pro pochopení distribucí, vztahů a trendů v kvantitativních datech. Efektivní vizualizace pomáhá odhalit vzory, které nemusí být zřejmé pouze ze souhrnných statistik. Python nabízí výkonné knihovny pro vytváření informativních a vizuálně přitažlivých reprezentací numerických dat.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení konzistentního stylu pro lepší vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Generování vzorových dat pro naše příklady
np.random.seed(42)  # Pro reprodukovatelnost

# Vytvoření různých datových sad pro různé typy vizualizací
# Normální rozdělení
normal_data = np.random.normal(loc=0, scale=1, size=1000)

# Bimodální data
bimodal_data = np.concatenate([
    np.random.normal(loc=-2, scale=0.5, size=500),
    np.random.normal(loc=2, scale=0.5, size=500)
])

# Časová řada
x = np.linspace(0, 10, 100)
time_series_data = np.sin(x) * np.exp(-0.1 * x) + np.random.normal(0, 0.1, 100)

# Zobrazení základních informací o našich datových sadách
print("Tvar normálních dat:", normal_data.shape)
print("Tvar bimodálních dat:", bimodal_data.shape)
print("Tvar dat časové řady:", time_series_data.shape)

print("\nSouhrnné statistiky normálních dat:")
print(pd.Series(normal_data).describe())

# Náhled na prvních několik datových bodů z každé datové sady
pd.DataFrame({
    'Normální': normal_data[:5],
    'Bimodální': bimodal_data[:5],
    'Časová řada': time_series_data[:5]
})
```

Při práci s numerickými daty je klíčové vybrat vizualizace, které nejlépe reprezentují konkrétní charakteristiky, které chcete zdůraznit:

- **Distribuce**: Histogramy, grafy hustoty, krabicové grafy
- **Vztahy**: Bodové grafy, bublinové grafy, čárové grafy
- **Vzory napříč kategoriemi**: Seskupené sloupcové grafy, houslové grafy
- **Vícerozměrná data**: Teplotní mapy, vrstevnicové grafy, 3D povrchové grafy

## 2. Histogramy a grafy hustoty

Histogramy a grafy hustoty jsou základními nástroji pro vizualizaci distribuce jednotlivé numerické proměnné. Umožňují zobrazit tvar, centrální tendenci a rozptyl vašich dat.

```python
# Vytvoření obrázku s více grafy
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Jednoduchý histogram normálního rozdělení
axes[0, 0].hist(normal_data, bins=30, alpha=0.7, color='blue')
axes[0, 0].set_title('Histogram normálního rozdělení')
axes[0, 0].set_xlabel('Hodnota')
axes[0, 0].set_ylabel('Četnost')

# Histogram s normalizací hustoty a KDE
sns.histplot(normal_data, bins=30, kde=True, ax=axes[0, 1], color='darkblue')
axes[0, 1].set_title('Histogram s KDE')
axes[0, 1].set_xlabel('Hodnota')
axes[0, 1].set_ylabel('Hustota')

# Porovnání distribucí pomocí KDE
sns.kdeplot(normal_data, ax=axes[1, 0], label='Normální', fill=True, alpha=0.3)
sns.kdeplot(bimodal_data, ax=axes[1, 0], label='Bimodální', fill=True, alpha=0.3)
axes[1, 0].set_title('KDE porovnání distribucí')
axes[1, 0].set_xlabel('Hodnota')
axes[1, 0].set_ylabel('Hustota')
axes[1, 0].legend()

# 2D histogram (hexbin) pro dvě proměnné
x = np.random.normal(size=1000)
y = x * 0.5 + np.random.normal(size=1000, scale=0.5)
axes[1, 1].hexbin(x, y, gridsize=30, cmap='Blues')
axes[1, 1].set_title('2D Histogram (Hexbin graf)')
axes[1, 1].set_xlabel('Hodnota X')
axes[1, 1].set_ylabel('Hodnota Y')

plt.tight_layout()
plt.show()

# Distplot s kombinací matplotlib a seaborn
plt.figure(figsize=(10, 6))
# Histogram
plt.hist(bimodal_data, bins=50, density=True, alpha=0.5, color='teal', 
        label='Histogram')
# Jádrový odhad hustoty (KDE)
sns.kdeplot(bimodal_data, color='darkblue', linewidth=2, label='KDE')
# Přidání rug plotu ve spodní části
plt.plot(bimodal_data, np.zeros_like(bimodal_data), '|', color='darkred', 
        alpha=0.5, markeredgewidth=1)

plt.title('Bimodální rozdělení: Histogram, KDE a Rug Plot')
plt.xlabel('Hodnota')
plt.ylabel('Hustota')
plt.legend()
plt.tight_layout()
plt.show()
```

Klíčové úvahy pro histogramy a grafy hustoty:

1. **Šířka/počet binů**: Příliš málo binů může skrýt důležité vlastnosti; příliš mnoho může vytvořit šum
2. **Normalizace**: Pro porovnání distribucí různých velikostí je důležité použít normalizaci hustoty
3. **Jádrový odhad hustoty (KDE)**: Vyhlazuje histogram pro zdůraznění tvaru distribuce
4. **Více distribucí**: Překrývání více histogramů nebo grafů hustoty pomáhá při porovnávání distribucí
5. **2D histogramy**: Pro zobrazení distribuce dvou numerických proměnných současně

## 3. Bodové grafy pro zkoumání vztahů

Bodové grafy jsou výkonné nástroje pro vizualizaci vztahů mezi dvěma numerickými proměnnými. Lze je rozšířit o další dimenze pomocí barvy, velikosti a tvaru.

```python
# Generování dat pro příklady bodových grafů
np.random.seed(42)
n_points = 100

# Vytvoření korelovaných dat
x = np.random.normal(size=n_points)
y_linear = x + np.random.normal(size=n_points, scale=0.5)  # Lineární vztah
y_quad = x**2 + np.random.normal(size=n_points, scale=0.5)  # Kvadratický vztah
y_none = np.random.normal(size=n_points)  # Žádný vztah

# Vytvoření kategoriální proměnné pro seskupení
categories = np.random.choice(['A', 'B', 'C'], size=n_points)
sizes = np.random.uniform(10, 100, size=n_points)

# Vytvoření obrázku s více bodovými grafy
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Základní bodový graf
axes[0, 0].scatter(x, y_linear, alpha=0.7)
axes[0, 0].set_title('Základní bodový graf (lineární vztah)')
axes[0, 0].set_xlabel('Proměnná X')
axes[0, 0].set_ylabel('Proměnná Y')

# Bodový graf s barevnými skupinami
for category, color in zip(['A', 'B', 'C'], ['blue', 'red', 'green']):
    mask = categories == category
    axes[0, 1].scatter(x[mask], y_quad[mask], color=color, alpha=0.7, label=category)
axes[0, 1].set_title('Bodový graf s barevnými skupinami (kvadratický vztah)')
axes[0, 1].set_xlabel('Proměnná X')
axes[0, 1].set_ylabel('Proměnná Y')
axes[0, 1].legend()

# Bodový graf s variací velikosti
scatter = axes[1, 0].scatter(x, y_none, c=y_quad, s=sizes, alpha=0.7, cmap='viridis')
axes[1, 0].set_title('Bodový graf s dimenzemi velikosti a barvy')
axes[1, 0].set_xlabel('Proměnná X')
axes[1, 0].set_ylabel('Proměnná Y')
plt.colorbar(scatter, ax=axes[1, 0], label='Hodnota Y Kvadratická')

# Bodový graf s regresní přímkou pomocí seaborn
sns.regplot(x=x, y=y_linear, ax=axes[1, 1], scatter_kws={'alpha': 0.5})
axes[1, 1].set_title('Bodový graf s regresní přímkou')
axes[1, 1].set_xlabel('Proměnná X')
axes[1, 1].set_ylabel('Proměnná Y')

plt.tight_layout()
plt.show()

# Matice bodových grafů se seaborn
data = pd.DataFrame({
    'x': x,
    'y_linear': y_linear,
    'y_quad': y_quad,
    'y_none': y_none,
    'category': categories
})

plt.figure(figsize=(10, 8))
sns.pairplot(data, hue='category', vars=['x', 'y_linear', 'y_quad', 'y_none'])
plt.suptitle('Matice bodových grafů (Pairplot)', y=1.02)
plt.show()
```

Klíčové techniky pro efektivní bodové grafy:

1. **Jednoduchý rozptyl**: Zobrazuje základní vztah mezi dvěma proměnnými
2. **Barevné seskupení**: Přidává kategoriální dimenzi pro identifikaci vzorců podle skupin
3. **Variace velikosti**: Přidává další numerickou dimenzi (bublinový graf)
4. **Regresní přímky**: Pomáhají vizualizovat trend a sílu vztahů
5. **Matice bodových grafů**: Zobrazuje vztahy mezi více numerickými proměnnými najednou
6. **Alfa průhlednost**: Nezbytná při vykreslování mnoha bodů pro zobrazení hustoty překrývajících se bodů

## 4. Krabicové a houslové grafy pro zobrazení distribucí

Krabicové a houslové grafy poskytují stručný způsob vizualizace distribuce numerických dat, zvláště při porovnávání napříč kategoriemi nebo skupinami.

```python
# Generování dat pro příklady krabicových a houslových grafů
np.random.seed(42)

# Vytvoření dat z různých distribucí
data = {
    'Skupina A': np.random.normal(0, 1, 200),
    'Skupina B': np.random.normal(2, 0.5, 200),
    'Skupina C': np.random.exponential(1, 200),
    'Skupina D': np.random.lognormal(0, 0.5, 200)
}

# Převod na DataFrame pro jednodušší vykreslování
df = pd.DataFrame({k: pd.Series(v) for k, v in data.items()})

# Vytvoření obrázku s krabicovými a houslovými grafy
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Základní krabicový graf
sns.boxplot(data=df, ax=axes[0, 0])
axes[0, 0].set_title('Základní krabicové porovnání')
axes[0, 0].set_xlabel('Skupina')
axes[0, 0].set_ylabel('Hodnota')

# Krabicový graf s jednotlivými body
sns.boxplot(data=df, ax=axes[0, 1], width=0.5)
sns.stripplot(data=df, ax=axes[0, 1], color='black', alpha=0.5, jitter=True)
axes[0, 1].set_title('Krabicový graf s jednotlivými body')
axes[0, 1].set_xlabel('Skupina')
axes[0, 1].set_ylabel('Hodnota')

# Základní houslový graf
sns.violinplot(data=df, ax=axes[1, 0])
axes[1, 0].set_title('Základní houslové porovnání')
axes[1, 0].set_xlabel('Skupina')
axes[1, 0].set_ylabel('Hodnota')

# Rozdělený houslový graf s dodatečnými informacemi
sns.violinplot(data=df, inner='quartile', cut=0, ax=axes[1, 1])
axes[1, 1].set_title('Houslový graf s kvartily')
axes[1, 1].set_xlabel('Skupina')
axes[1, 1].set_ylabel('Hodnota')

plt.tight_layout()
plt.show()

# Vytvoření datasetu s více skupinami pro párové porovnání
group_data = pd.DataFrame({
    'hodnota': np.concatenate([data['Skupina A'], data['Skupina B'], data['Skupina C']]),
    'skupina': np.repeat(['A', 'B', 'C'], 200),
    'podskupina': np.concatenate([np.repeat(['X', 'Y'], 100) for _ in range(3)])
})

# Vykreslení krabicového grafu se seskupenými daty
plt.figure(figsize=(12, 6))
sns.boxplot(x='skupina', y='hodnota', hue='podskupina', data=group_data, palette='Set3')
plt.title('Seskupené krabicové porovnání')
plt.xlabel('Hlavní skupina')
plt.ylabel('Hodnota')
plt.legend(title='Podskupina')
plt.tight_layout()
plt.show()
```

Krabicové a houslové grafy nabízejí tyto výhody:

1. **Kompaktní shrnutí**: Zobrazují medián, kvartily, rozsah a odlehlé hodnoty v kompaktní formě
2. **Porovnání skupin**: Snadné porovnání distribucí napříč více kategoriemi
3. **Houslové grafy**: Přidávají informaci o hustotě pro lepší vizualizaci tvaru distribuce
4. **Detekce odlehlých hodnot**: Jasně identifikují odlehlé hodnoty za hranicemi vousů
5. **Vrstvení jednotlivých bodů**: Přidání jednotlivých datových bodů pomáhá ukázat skutečnou distribuci dat

## 5. Čárové grafy pro trendy a časové řady

Čárové grafy jsou ideální pro vizualizaci trendů v čase nebo napříč spojitou sekvencí. Zdůrazňují kontinuitu a míru změny mezi datovými body.

```python
# Generování dat časových řad
np.random.seed(42)
dates = pd.date_range(start='2023-01-01', periods=100, freq='D')
linear_trend = np.linspace(0, 10, 100)
seasonal = 2 * np.sin(np.linspace(0, 4*np.pi, 100))
noise = np.random.normal(0, 0.5, 100)

# Vytvoření různých časových řad
ts1 = linear_trend + seasonal + noise
ts2 = linear_trend * 0.5 + seasonal * 1.5 + noise
ts3 = linear_trend * 0.3 + np.roll(seasonal, 25) + noise

# Vytvoření DataFrame
ts_df = pd.DataFrame({
    'datum': dates,
    'Řada 1': ts1,
    'Řada 2': ts2,
    'Řada 3': ts3
})

# Vytvoření obrázku s čárovými grafy
fig, axes = plt.subplots(3, 1, figsize=(12, 12))

# Základní čárový graf
axes[0].plot(ts_df['datum'], ts_df['Řada 1'], linewidth=2)
axes[0].set_title('Základní čárový graf časové řady')
axes[0].set_xlabel('Datum')
axes[0].set_ylabel('Hodnota')
axes[0].grid(True)

# Porovnání více řad
axes[1].plot(ts_df['datum'], ts_df['Řada 1'], label='Řada 1')
axes[1].plot(ts_df['datum'], ts_df['Řada 2'], label='Řada 2')
axes[1].plot(ts_df['datum'], ts_df['Řada 3'], label='Řada 3')
axes[1].set_title('Porovnání více časových řad')
axes[1].set_xlabel('Datum')
axes[1].set_ylabel('Hodnota')
axes[1].legend()
axes[1].grid(True)

# Čárový graf s vyplněnou oblastí
axes[2].plot(ts_df['datum'], ts_df['Řada 1'], linewidth=2, color='blue')
axes[2].fill_between(ts_df['datum'], ts_df['Řada 1'], alpha=0.3, color='blue')
axes[2].set_title('Čárový graf s vyplněnou oblastí')
axes[2].set_xlabel('Datum')
axes[2].set_ylabel('Hodnota')
axes[2].grid(True)

plt.tight_layout()
plt.show()

# Čárový graf s podgrafem pro přiblíženou sekci
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(12, 8), 
                             gridspec_kw={'height_ratios': [3, 1]})

# Hlavní graf se všemi daty
for col, color in zip(['Řada 1', 'Řada 2', 'Řada 3'], ['blue', 'red', 'green']):
    ax1.plot(ts_df['datum'], ts_df[col], label=col, color=color)
ax1.set_title('Časová řada s přiblíženou sekcí')
ax1.legend()
ax1.grid(True)

# Zvýraznění oblasti k přiblížení
zoom_start = 30
zoom_end = 50
ax1.axvspan(dates[zoom_start], dates[zoom_end], color='gray', alpha=0.2)

# Přiblížený graf
for col, color in zip(['Řada 1', 'Řada 2', 'Řada 3'], ['blue', 'red', 'green']):
    ax2.plot(ts_df['datum'][zoom_start:zoom_end+1], ts_df[col][zoom_start:zoom_end+1], 
            color=color)
ax2.set_title('Přiblížená sekce')
ax2.grid(True)

plt.tight_layout()
plt.show()
```

Efektivní techniky pro čárové grafy:

1. **Více řad**: Porovnání různých datových sad přes stejnou sekvenci
2. **Výplně oblastí**: Zdůraznění velikosti hodnot nebo zobrazení intervalů spolehlivosti
3. **Značky**: Přidání bodů pro zvýraznění jednotlivých pozorování
4. **Přiblížené sekce**: Zaměření na důležité detaily při současném zachování kontextu
5. **Trendové čáry**: Přidání vyhlazených křivek pro zobrazení základních trendů pod zašuměnými daty
6. **Dvojité osy**: Zobrazení proměnných s různými měřítky na stejném grafu (používat opatrně)

## 6. Teplotní mapy pro numerické matice

Teplotní mapy jsou vynikající pro vizualizaci numerických matic, korelačních matic nebo dat s dvěma kategoriálními dimenzemi a numerickou hodnotou.

```python
# Generování dat pro příklady teplotních map
np.random.seed(42)

# Vytvoření korelační matice z náhodných dat
data = np.random.randn(100, 5)
columns = ['Proměnná A', 'Proměnná B', 'Proměnná C', 'Proměnná D', 'Proměnná E']
df = pd.DataFrame(data, columns=columns)
correlation_matrix = df.corr()

# Vytvoření 2D matice se vzorem
x = np.linspace(-3, 3, 30)
y = np.linspace(-3, 3, 30)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y)

# Vytvoření obrázku s teplotními mapami
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Základní teplotní mapa korelační matice
sns.heatmap(correlation_matrix, annot=True, cmap='coolwarm', vmin=-1, vmax=1, ax=axes[0, 0])
axes[0, 0].set_title('Teplotní mapa korelační matice')

# Vizualizace 2D funkce pomocí teplotní mapy
im = axes[0, 1].imshow(Z, cmap='viridis', extent=[-3, 3, -3, 3], origin='lower')
axes[0, 1].set_title('Vizualizace 2D funkce')
axes[0, 1].set_xlabel('Osa X')
axes[0, 1].set_ylabel('Osa Y')
fig.colorbar(im, ax=axes[0, 1])

# Generování dat pro kategoriální teplotní mapu
categories1 = ['Kat A', 'Kat B', 'Kat C', 'Kat D', 'Kat E']
categories2 = ['Skupina 1', 'Skupina 2', 'Skupina 3', 'Skupina 4']
cat_data = np.random.randint(0, 100, size=(5, 4))
cat_df = pd.DataFrame(cat_data, index=categories1, columns=categories2)

# Kategoriální teplotní mapa
sns.heatmap(cat_df, annot=True, fmt='d', cmap='YlGnBu', ax=axes[1, 0])
axes[1, 0].set_title('Kategoriální teplotní mapa')
axes[1, 0].set_xlabel('Kategorie 2')
axes[1, 0].set_ylabel('Kategorie 1')

# Vytvoření časově založených dat pro teplotní mapu
dates = pd.date_range('2023-01-01', periods=12, freq='M')
times = [f'{hour}:00' for hour in range(24)]
time_data = np.random.randint(0, 100, size=(12, 24))
time_df = pd.DataFrame(time_data, index=dates, columns=times)

# Časově založená teplotní mapa
sns.heatmap(time_df, cmap='rocket_r', ax=axes[1, 1])
axes[1, 1].set_title('Časově založená teplotní mapa (Měsíce × Hodiny)')
axes[1, 1].set_xlabel('Hodina dne')
axes[1, 1].set_ylabel('Měsíc')
axes[1, 1].set_yticks(np.arange(len(dates)))
axes[1, 1].set_yticklabels([d.strftime('%b %Y') for d in dates])
axes[1, 1].set_xticks(np.arange(0, 24, 3))
axes[1, 1].set_xticklabels([f'{h}:00' for h in range(0, 24, 3)])

plt.tight_layout()
plt.show()

# Seaborn clustermap pro přeuspořádanou korelační matici
plt.figure(figsize=(10, 8))
sns.clustermap(correlation_matrix, cmap='coolwarm', vmin=-1, vmax=1, 
              annot=True, standard_scale=1)
plt.title('Shlukovaná korelační matice', pad=50)
plt.show()
```

Klíčové aplikace pro teplotní mapy:

1. **Korelační matice**: Vizualizují vztahy mezi mnoha proměnnými najednou
2. **Kategoriální křížové tabulky**: Zobrazují počty nebo metriky napříč dvěma kategoriálními dimenzemi
3. **Časově založené vzory**: Vizualizují vzory napříč časovými dimenzemi (např. den v týdnu × hodina dne)
4. **Prostorová data**: Zobrazují intenzitu napříč geografickými regiony
5. **Shlukované teplotní mapy**: Přeuspořádávají řádky a sloupce pro odhalení vzorů a seskupení
6. **Matice vzdáleností**: Vizualizují podobnost nebo vzdálenost mezi páry pozorování

## 7. Vrstevnicové a povrchové grafy pro 3D data

Při práci s trojrozměrnými numerickými daty vrstevnicové a povrchové grafy pomáhají vizualizovat vztahy mezi třemi proměnnými.

```python
# Import nástrojů pro 3D vykreslování
from mpl_toolkits.mplot3d import Axes3D
from matplotlib import cm

# Vytvoření dat pro 3D vizualizaci

np.random.seed(42)

# Kombinace bodového a čárového grafu pro zobrazení regrese

# Generování dat s jasným trendem
x = np.linspace(0, 10, 100)
y = 2 * x + 1 + np.random.normal(0, 2, 100)

# Vytvoření bodového grafu surových dat
plt.scatter(x, y, alpha=0.6, label='Datové body')

# Přidání regresní přímky
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(x.reshape(-1, 1), y)
y_pred = model.predict(x.reshape(-1, 1))
plt.plot(x, y_pred, color='red', linewidth=2, label=f'Regresní přímka (sklon={model.coef_[0]:.2f})')

# Přidání intervalu spolehlivosti
from scipy import stats
# Výpočet intervalu spolehlivosti
pred = model.predict(x.reshape(-1, 1))
# Získání střední kvadratické chyby
n = len(x)
y_err = y - pred
mse = np.sum(y_err**2) / (n-2)
std_err = np.sqrt(mse * (1/n + (x - np.mean(x))**2 / np.sum((x - np.mean(x))**2)))
t = stats.t.ppf(0.975, n-2)
ci = t * std_err

# Vykreslení intervalu spolehlivosti
plt.fill_between(x, pred - ci, pred + ci, color='gray', alpha=0.2, label='95% interval spolehlivosti')

plt.title('Bodový graf s regresní přímkou a intervalem spolehlivosti')
plt.xlabel('Hodnota X')
plt.ylabel('Hodnota Y')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

1. **Komplementární vhledy**: Různé grafy zdůrazňují různé aspekty dat
2. **Kontext**: Marginální distribuce poskytují kontext pro bodové grafy
3. **Efektivita**: Více vizualizací v jednom obrázku šetří prostor a pomáhá vyprávět ucelený příběh
4. **Detail a souhrn**: Kombinace přehledových vizualizací s detailními pohledy
5. **Statistický vhled**: Přidání statistických prvků jako regresních přímek nebo intervalů spolehlivosti k surovým datům

## 10. Shrnutí a osvědčené postupy

Efektivní vizualizace numerických dat je klíčová pro průzkumnou analýzu dat, identifikaci vzorů a komunikaci poznatků. Zde jsou klíčové osvědčené postupy, které je třeba dodržovat:

1. **Výběr správného typu vizualizace:**
   - Použití histogramů a grafů hustoty pro distribuce
   - Použití bodových grafů pro vztahy mezi proměnnými
   - Použití čárových grafů pro trendy v čase nebo sekvencích
   - Použití krabicových a houslových grafů pro porovnání distribucí
   - Použití teplotních map pro korelační matice nebo 2D vzory
   - Použití vrstevnicových a povrchových grafů pro 3D vztahy

2. **Zajištění jasnosti a přesnosti:**
   - Jasné označení os s jednotkami
   - Použití vhodných měřítek (lineární, logaritmická)
   - Zahrnutí titulků a legend
   - Zvážení poměru stran a velikosti
   - Vyhnutí se zkreslení dat nesprávnými měřítky

3. **Vylepšení o statistické informace:**
   - Přidání trendových čar nebo křivek pro zobrazení vzorů
   - Zahrnutí intervalů spolehlivosti, kde je to vhodné
   - Zobrazení souhrnných statistik (průměr, medián atd.)
   - Použití statistických transformací v případě potřeby

4. **Zohlednění publika:**
   - Úprava složitosti na základě zkušeností diváka
   - Efektivní používání barev s ohledem na barvoslepost
   - Vyvážení mezi estetikou a hustotou informací
   - Zvážení interaktivních vizualizací pro komplexní průzkum dat

5. **Iterace a vylepšování:**
   - Začínání s jednoduchými vizualizacemi
   - Přidávání složitosti podle potřeby pro odhalení vzorů
   - Odstranění prvků, které nepřispívají k pochopení
   - Získání zpětné vazby a vylepšení přístupu

Dodržováním těchto pokynů a použitím nástrojů pro vizualizaci v Pythonu ukázaných v tomto průvodci budete schopni vytvářet efektivní, informativní a vizuálně přitažlivé reprezentace numerických dat, které pomohou vám i ostatním získat cenné poznatky.

```python
# Komplexní příklad spojující více konceptů
np.random.seed(42)

# Vytvoření vzorového datasetu s více numerickými proměnnými
n = 1000
df = pd.DataFrame({
    'x': np.random.normal(0, 1, n),
    'y': np.random.normal(0, 1, n),
    'skupina': np.random.choice(['Skupina A', 'Skupina B', 'Skupina C'], n),
    'velikost': np.random.uniform(10, 100, n),
    'hodnota': np.random.normal(0, 1, n)
})

# Vytvoření korelace mezi x a y pro každou skupinu jinak
mask = df['skupina'] == 'Skupina A'
df.loc[mask, 'y'] = df.loc[mask, 'x'] * 0.8 + np.random.normal(0, 0.5, sum(mask))

mask = df['skupina'] == 'Skupina B'
df.loc[mask, 'y'] = df.loc[mask, 'x'] * -0.5 + np.random.normal(0, 0.5, sum(mask))

mask = df['skupina'] == 'Skupina C'
df.loc[mask, 'y'] = df.loc[mask, 'x'] ** 2 + np.random.normal(0, 0.5, sum(mask))

# Vytvoření obrázku s více podgrafy zobrazujícími různé aspekty dat
fig = plt.figure(figsize=(16, 12))
gs = fig.add_gridspec(3, 3)

# 1. Bodový graf s barevnými skupinami
ax1 = fig.add_subplot(gs[0, 0:2])
for skupina, color in zip(['Skupina A', 'Skupina B', 'Skupina C'], ['#3498db', '#e74c3c', '#2ecc71']):
    mask = df['skupina'] == skupina
    ax1.scatter(df.loc[mask, 'x'], df.loc[mask, 'y'], alpha=0.7, color=color, label=skupina)
ax1.set_title('Bodový graf podle skupiny', fontsize=14, fontweight='bold')
ax1.set_xlabel('Hodnota X')
ax1.set_ylabel('Hodnota Y')
ax1.legend()
ax1.grid(True, alpha=0.3)

# 2. Graf hustoty proměnné x
ax2 = fig.add_subplot(gs[0, 2])
for skupina, color in zip(['Skupina A', 'Skupina B', 'Skupina C'], ['#3498db', '#e74c3c', '#2ecc71']):
    sns.kdeplot(df.loc[df['skupina'] == skupina, 'x'], label=skupina, fill=True, alpha=0.3, ax=ax2)
ax2.set_title('Distribuce X podle skupiny', fontsize=14, fontweight='bold')
ax2.set_xlabel('Hodnota X')
ax2.set_ylabel('Hustota')
ax2.grid(True, alpha=0.3)

# 3. Krabicové porovnání
ax3 = fig.add_subplot(gs[1, 0:2])
sns.boxplot(x='skupina', y='y', data=df, ax=ax3, palette=['#3498db', '#e74c3c', '#2ecc71'])
sns.stripplot(x='skupina', y='y', data=df, ax=ax3, size=3, alpha=0.3, jitter=True, color='black')
ax3.set_title('Distribuce Y podle skupiny', fontsize=14, fontweight='bold')
ax3.set_xlabel('Skupina')
ax3.set_ylabel('Hodnota Y')
ax3.grid(True, alpha=0.3)

# 4. Teplotní mapa korelační matice
ax4 = fig.add_subplot(gs[1, 2])
corr = df[['x', 'y', 'velikost', 'hodnota']].corr()
sns.heatmap(corr, annot=True, cmap='coolwarm', vmin=-1, vmax=1, ax=ax4)
ax4.set_title('Korelační matice', fontsize=14, fontweight='bold')

# 5. Histogram s KDE
ax5 = fig.add_subplot(gs[2, 0])
sns.histplot(df['y'], kde=True, bins=30, ax=ax5)
ax5.axvline(df['y'].mean(), color='red', linestyle='--', 
           label=f'Průměr: {df["y"].mean():.2f}')
ax5.axvline(df['y'].median(), color='green', linestyle='--', 
           label=f'Medián: {df["y"].median():.2f}')
ax5.set_title('Distribuce Y', fontsize=14, fontweight='bold')
ax5.set_xlabel('Hodnota Y')
ax5.set_ylabel('Počet')
ax5.legend()
ax5.grid(True, alpha=0.3)

# 6. Bodový graf s regresní přímkou pro každou skupinu
ax6 = fig.add_subplot(gs[2, 1:3])
sns.regplot(x='x', y='y', data=df[df['skupina'] == 'Skupina A'], 
           scatter_kws={'alpha': 0.3, 's': 10}, line_kws={'color': '#3498db'}, 
           label='Skupina A', ax=ax6)
sns.regplot(x='x', y='y', data=df[df['skupina'] == 'Skupina B'], 
           scatter_kws={'alpha': 0.3, 's': 10}, line_kws={'color': '#e74c3c'}, 
           label='Skupina B', ax=ax6)
sns.regplot(x='x', y='y', data=df[df['skupina'] == 'Skupina C'], 
           scatter_kws={'alpha': 0.3, 's': 10}, line_kws={'color': '#2ecc71'}, 
           label='Skupina C', ax=ax6)
ax6.set_title('Regrese podle skupiny', fontsize=14, fontweight='bold')
ax6.set_xlabel('Hodnota X')
ax6.set_ylabel('Hodnota Y')
ax6.legend()
ax6.grid(True, alpha=0.3)

# Přidání celkového titulku
fig.suptitle('Komplexní příklad vizualizace numerických dat', 
           fontsize=20, fontweight='bold', y=0.98)

plt.tight_layout()
plt.subplots_adjust(top=0.92)
plt.show()
```

Tento komplexní průvodce pokrývá základní techniky vizualizace numerických dat v Pythonu, od základních histogramů po pokročilé 3D grafy, se zaměřením na získávání smysluplných poznatků prostřednictvím efektivní vizuální reprezentace.
