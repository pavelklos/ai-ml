## 1. Úvod do koláčových grafů

Koláčové grafy jsou kruhové statistické grafiky, které rozdělují kruh na sektory, přičemž každý sektor představuje určitou část celku. Plocha a středový úhel každého sektoru jsou úměrné množství, které reprezentuje.

Koláčové grafy se používají především k zobrazení:
- Vztahů části k celku
- Proporcí kategorií v rámci jedné datové řady
- Jednoduchých kompozic, kde je důraz na významné rozdíly

```python
# Import základních knihoven pro koláčové grafy
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení vizuálního stylu
plt.style.use('seaborn-v0_8-whitegrid')

# Vzorová data pro naše příklady
categories = ['Kategorie A', 'Kategorie B', 'Kategorie C', 'Kategorie D', 'Kategorie E']
values = [25, 30, 15, 10, 20]

# Jednoduchá vizualizace koláčového grafu se vzorovými daty
plt.figure(figsize=(8, 8))
plt.pie(values, labels=categories)
plt.title('Základní koláčový graf')
plt.show()
```

Navzdory jejich běžnému použití jsou koláčové grafy v komunitě datové vizualizace často kritizovány z několika důvodů, které prozkoumáme později v tomto dokumentu. Porozumění, kdy je použít—a co je důležitější, kdy ne—je nezbytné pro efektivní komunikaci dat.

## 2. Základní koláčové grafy v Matplotlib

Matplotlib usnadňuje vytváření koláčových grafů pomocí funkce `pie()`. Zde se budeme zabývat základní implementací a základními parametry.

```python
# Import knihoven
import matplotlib.pyplot as plt
import numpy as np

# Vzorová data
categories = ['Produkt A', 'Produkt B', 'Produkt C', 'Produkt D']
sales = [38, 27, 19, 16]

# Vytvoření jednoduchého koláčového grafu
plt.figure(figsize=(10, 6))
plt.pie(sales, labels=categories, autopct='%1.1f%%', startangle=90)
plt.title('Distribuce prodeje produktů')
plt.axis('equal')  # Stejný poměr stran zajišťuje, že koláčový graf je kruhový
plt.show()

# Další příklad s více možnostmi formátování
departments = ['Marketing', 'Provoz', 'Finance', 'HR', 'IT']
budget = [25000, 30000, 22000, 15000, 18000]
colors = ['#ff9999', '#66b3ff', '#99ff99', '#ffcc99', '#c2c2f0']
explode = (0.05, 0, 0, 0, 0)  # Zvýraznění 1. výseče (Marketing)

plt.figure(figsize=(10, 6))
plt.pie(budget, 
        labels=departments, 
        colors=colors,
        explode=explode,
        autopct='%1.1f%%', 
        shadow=True, 
        startangle=90)
plt.title('Alokace rozpočtu společnosti podle oddělení')
plt.axis('equal')
plt.show()
```

Klíčové parametry `plt.pie()`:
- `x`: Datové hodnoty pro vykreslení
- `labels`: Seznam popisků pro každou výseč
- `autopct`: Formát řetězce pro procenta výsečí (např. '%1.1f%%')
- `explode`: Pole pro odsazení výsečí od středu
- `shadow`: Boolovská hodnota pro přidání efektu stínu
- `startangle`: Úhel začátku kreslení výsečí (proti směru hodinových ručiček od osy x)
- `colors`: Pole barev pro každou výseč

## 3. Přizpůsobení koláčových grafů

Přizpůsobení je důležité pro vytvoření jasných, efektivních koláčových grafů, které odpovídají vašim potřebám vizualizace a stylu.

```python
# Import knihoven
import matplotlib.pyplot as plt
import numpy as np

# Vzorová data
categories = ['Online', 'Kamenné obchody', 'Distributoři', 'Přímý prodej']
revenue = [45, 30, 15, 10]

# Vlastní barvy a stylizace
colors = ['#2C3E50', '#E74C3C', '#3498DB', '#1ABC9C']


plt.figure(figsize=(10, 8))

# Přizpůsobený koláčový graf
wedges, texts, autotexts = plt.pie(
    revenue,
    labels=categories,
    autopct='%1.1f%%',
    startangle=90,
    colors=colors,
    shadow=True,
    explode=(0.05, 0, 0, 0),
    wedgeprops={'edgecolor': 'white', 'linewidth': 2}
)

# Stylizace textových prvků
for text in texts:
    text.set_fontsize(12)
    text.set_fontweight('bold')
    
for autotext in autotexts:
    autotext.set_fontsize(12)
    autotext.set_fontweight('bold')
    autotext.set_color('white')

plt.title('Distribuce příjmů podle kanálu', fontsize=16, fontweight='bold', pad=20)

# Přidání legendy s procenty
plt.legend(wedges, [f'{c} ({r}%)' for c, r in zip(categories, revenue)], 
           title='Kanály',
           loc='center left',
           bbox_to_anchor=(1, 0, 0.5, 1))

plt.axis('equal')
plt.tight_layout()
plt.show()
```

Další tipy pro přizpůsobení:
- Použijte parametr `wedgeprops` pro přizpůsobení vzhledu výsečí
- Stylizujte textové prvky pro lepší čitelnost
- Přidejte legendu pro poskytnutí dodatečného kontextu
- Používejte promyšlené barevné volby pro efektivní odlišení kategorií

## 4. Kdy používat koláčové grafy (a kdy ne)

Koláčové grafy jsou užitečné v konkrétních scénářích, ale často jsou nesprávně používány. Porozumění tomu, kdy jsou vhodné, je klíčové pro efektivní vizualizaci dat.

### Kdy používat koláčové grafy:

1. **Málo kategorií**: Při zobrazení 2-5 kategorií (zřídka více než 7)
2. **Vztah části k celku**: Při zobrazení toho, jak části přispívají k celku
3. **Významné rozdíly**: Když jsou rozdíly mezi segmenty podstatné
4. **Jednoduché porovnání**: Pro základní, jednoduché porovnání proporcí
5. **Očekávání publika**: Když vaše publikum očekává nebo je zvyklé na koláčové grafy

### Kdy NEpoužívat koláčové grafy:

1. **Mnoho kategorií**: S více než 5-7 kategoriemi se koláčové grafy stávají nepřehlednými
2. **Podobné proporce**: Když mají segmenty podobné velikosti, rozdíly jsou těžko vnímatelné
3. **Porovnávání napříč více datasety**: Porovnávání více koláčových grafů je neefektivní
4. **Časové řady**: Koláčové grafy nemohou efektivně zobrazit změny v čase
5. **Přesná porovnání**: Když jsou potřeba přesná porovnání mezi kategoriemi

```python
# Příklad: Porovnání efektivních a neefektivních případů použití koláčových grafů
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Nastavení obrázku se dvěma řadami podgrafů
fig, axs = plt.subplots(2, 2, figsize=(16, 12))

# Dobrý případ použití: Málo kategorií s významnými rozdíly
good_case = {'Kategorie A': 45, 'Kategorie B': 30, 'Kategorie C': 25}
axs[0, 0].pie(good_case.values(), labels=good_case.keys(), autopct='%1.1f%%')
axs[0, 0].set_title('Dobrý případ použití: Málo kategorií s jasnými rozdíly', fontsize=14)

# Špatný případ 1: Příliš mnoho kategorií
bad_case1 = {f'Kategorie {chr(65+i)}': np.random.randint(3, 10) for i in range(15)}
axs[0, 1].pie(bad_case1.values(), labels=bad_case1.keys(), autopct='%1.1f%%')
axs[0, 1].set_title('Špatný případ použití: Příliš mnoho kategorií', fontsize=14)

# Špatný případ 2: Podobné proporce
bad_case2 = {'A': 19, 'B': 18, 'C': 21, 'D': 20, 'E': 22}
axs[1, 0].pie(bad_case2.values(), labels=bad_case2.keys(), autopct='%1.1f%%')
axs[1, 0].set_title('Špatný případ použití: Podobné proporce', fontsize=14)

# Lepší alternativa: Sloupcový graf pro porovnání
axs[1, 1].bar(bad_case2.keys(), bad_case2.values(), color='steelblue')
axs[1, 1].set_title('Lepší alternativa: Sloupcový graf pro porovnání', fontsize=14)
axs[1, 1].set_ylabel('Hodnota')
axs[1, 1].grid(axis='y', alpha=0.3)

# Zajistit, aby koláčové grafy byly kruhové
for i in range(2):
    for j in range(2):
        if i != 1 or j != 1:  # Přeskočit sloupcový graf
            axs[i, j].axis('equal')

plt.tight_layout()
plt.show()
```

## 5. Prstencové grafy: Alternativa

Prstencové grafy jsou variantou koláčových grafů s otvorem ve středu. Někteří tvrdí, že jsou mírně lepší než koláčové grafy, protože méně zdůrazňují středový úhel a více se zaměřují na délku oblouku.

```python
# Vytvoření prstencového grafu
import matplotlib.pyplot as plt

# Vzorová data
categories = ['Dojíždění', 'Zábava', 'Jídlo', 'Služby', 'Nájem']
expenses = [12, 15, 25, 18, 30]
colors = ['#ff9999', '#66b3ff', '#99ff99', '#ffcc99', '#c2c2f0']

# Vytvoření prstencového grafu
plt.figure(figsize=(10, 8))
wedges, texts, autotexts = plt.pie(
    expenses,
    labels=categories,
    colors=colors,
    autopct='%1.1f%%',
    startangle=90,
    wedgeprops={'width': 0.4}  # Toto vytváří otvor prstence
)

# Stylizace textových prvků
for text in texts:
    text.set_fontsize(12)
for autotext in autotexts:
    autotext.set_fontsize(10)
    autotext.set_color('black')

plt.title('Měsíční rozdělení výdajů', fontsize=16)

# Přidání centrálního textu
plt.annotate('Výdaje', xy=(0, 0), ha='center', va='center', fontsize=20)

plt.axis('equal')
plt.tight_layout()
plt.show()

# Porovnání koláčových a prstencových grafů
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 8))

# Koláčový graf
ax1.pie(expenses, labels=categories, colors=colors, autopct='%1.1f%%', startangle=90)
ax1.set_title('Standardní koláčový graf', fontsize=14)
ax1.axis('equal')

# Prstencový graf
ax2.pie(expenses, labels=categories, colors=colors, autopct='%1.1f%%', 
        startangle=90, wedgeprops={'width': 0.4})
ax2.set_title('Prstencový graf', fontsize=14)
ax2.axis('equal')

plt.tight_layout()
plt.show()
```

Výhody prstencových grafů:
- Středová oblast může být použita pro dodatečné informace nebo souhrnné statistiky
- Někteří tvrdí, že mohou být čitelnější než standardní koláčové grafy
- Poskytují mírně modernější estetický vzhled

## 6. Explodované koláčové grafy pro zvýraznění

Explodované koláčové grafy oddělují jednu nebo více výsečí od hlavního koláče pro zdůraznění konkrétních segmentů.

```python
# Vytvoření explodovaného koláčového grafu
import matplotlib.pyplot as plt

# Vzorová data
categories = ['Elektronika', 'Oblečení', 'Potraviny', 'Knihy', 'Ostatní']
sales = [35, 25, 20, 15, 5]

# Definice explodování (efekt vytažení)
# Výseč s nejvyšší hodnotou bude vytažena
explode = [0.2 if x == max(sales) else 0 for x in sales]

plt.figure(figsize=(10, 8))
plt.pie(
    sales,
    labels=categories,
    autopct='%1.1f%%',
    startangle=90,
    explode=explode,
    shadow=True,
    colors=plt.cm.Pastel1.colors
)

plt.title('Distribuce prodejů podle oddělení', fontsize=16)
plt.axis('equal')
plt.tight_layout()
plt.show()

# Explodování více výsečí
categories = ['Produkt A', 'Produkt B', 'Produkt C', 'Produkt D', 'Produkt E']
values = [30, 25, 20, 15, 10]
explode = (0.1, 0, 0.1, 0, 0.1)  # Explodování každé druhé výseče

plt.figure(figsize=(10, 8))
plt.pie(
    values,
    labels=categories,
    explode=explode,
    autopct='%1.1f%%',
    shadow=True,
    colors=plt.cm.tab10.colors,
    startangle=140
)
plt.title('Střídavě explodovaný koláčový graf', fontsize=16)
plt.axis('equal')
plt.tight_layout()
plt.show()
```

Použijte explodované koláčové grafy:
- Pro zvýraznění jedné nebo několika kritických segmentů
- Když potřebujete vizuálně zdůraznit nejdůležitější kategorii
- Pro prezentace, kde chcete upoutat pozornost na konkrétní datové body

## 7. Vnořené a dílčí koláčové grafy

Pro složitější vztahy části k celku lze použít vnořené (hierarchické) koláčové grafy nebo více koláčových grafů v podgrafech.

```python
# Vytvoření vnořeného koláčového grafu (také nazývaného sluneční graf)
import matplotlib.pyplot as plt
import numpy as np

# Data pro vnější prstenec
outer_labels = ['Elektronika', 'Oblečení', 'Potraviny', 'Domácnost']
outer_values = [35, 25, 25, 15]
outer_colors = plt.cm.tab10(np.arange(4)/10.)

# Data pro vnitřní prstenec (podkategorie)
# Elektronika - rozdělení
electronics = [20, 15]
electronics_labels = ['Počítače', 'Telefony']
electronics_colors = plt.cm.Reds([0.5, 0.8])

# Oblečení - rozdělení
clothing = [15, 10]
clothing_labels = ['Pánské', 'Dámské']
clothing_colors = plt.cm.Blues([0.5, 0.8])

# Potraviny - rozdělení
food = [10, 8, 7]
food_labels = ['Potraviny', 'Restaurace', 'Svačiny']
food_colors = plt.cm.Greens([0.3, 0.6, 0.8])

# Domácnost - rozdělení
home = [8, 7]
home_labels = ['Nábytek', 'Dekorace']
home_colors = plt.cm.Purples([0.5, 0.8])

# Vytvoření obrázku
plt.figure(figsize=(12, 10))

# Vytvoření vnějšího koláčového grafu
outer_circle, outer_texts, outer_autotexts = plt.pie(
    outer_values,
    labels=outer_labels,
    colors=outer_colors,
    autopct='%1.1f%%',
    startangle=90,
    radius=1.2,
    wedgeprops=dict(width=0.3, edgecolor='w')
)

# Vytvoření vnitřního koláčového grafu (použití samostatných prstencových segmentů pro každou vnější kategorii)
plt.pie(
    electronics + clothing + food + home,
    labels=electronics_labels + clothing_labels + food_labels + home_labels,
    colors=np.concatenate([electronics_colors, clothing_colors, food_colors, home_colors]),
    radius=0.9,
    startangle=90,
    wedgeprops=dict(width=0.3, edgecolor='w')
)

# Prázdný střed pro estetiku
plt.pie(
    [1], 
    colors=['white'],
    radius=0.6
)

plt.title('Vnořený koláčový graf: Rozdělení prodejů podle oddělení a kategorie', fontsize=16)
plt.axis('equal')
plt.tight_layout()
plt.show()

# Více koláčových grafů v podgrafech
fig, axes = plt.subplots(1, 3, figsize=(18, 6))

# Prodeje podle regionu
regions = ['Sever', 'Jih', 'Východ', 'Západ']
region_sales = [30, 25, 20, 25]
axes[0].pie(region_sales, labels=regions, autopct='%1.1f%%', colors=plt.cm.Paired(np.arange(4)/8.))
axes[0].set_title('Prodeje podle regionu', fontsize=14)
axes[0].axis('equal')

# Prodeje podle kategorie produktů
products = ['Elektronika', 'Oblečení', 'Potraviny', 'Ostatní']
product_sales = [40, 30, 20, 10]
axes[1].pie(product_sales, labels=products, autopct='%1.1f%%', colors=plt.cm.Set2(np.arange(4)/8.))
axes[1].set_title('Prodeje podle kategorie produktů', fontsize=14)
axes[1].axis('equal')

# Prodeje podle typu zákazníků
customers = ['Noví', 'Vracející se', 'Věrní']
customer_sales = [25, 35, 40]
axes[2].pie(customer_sales, labels=customers, autopct='%1.1f%%', colors=plt.cm.Set3(np.arange(3)/8.))
axes[2].set_title('Prodeje podle typu zákazníků', fontsize=14)
axes[2].axis('equal')

plt.tight_layout()
plt.show()
```

Vnořené koláčové grafy a podgrafy jsou užitečné pro:
- Zobrazení hierarchických vztahů v datech
- Porovnávání různých rozdělení napříč více kategoriemi
- Prezentaci více aspektů vztahů k celku současně

Tyto složité typy koláčových grafů však používejte střídmě, protože se mohou rychle stát obtížně interpretovatelnými.

## 8. Interaktivní koláčové grafy s Plotly

Interaktivní koláčové grafy mohou zlepšit zapojení uživatelů a poskytnout podrobnější informace prostřednictvím efektů při přejetí myší a interaktivity.

```python
# Vytvoření interaktivního koláčového grafu s Plotly
# pip install plotly
import plotly.express as px
import plotly.graph_objects as go
import pandas as pd

# Vzorová data
data = pd.DataFrame({
    'Kategorie': ['Technologie', 'Zdravotnictví', 'Finance', 'Spotřební zboží', 'Energie'],
    'Tržní podíl': [28, 22, 18, 16, 16],
    'Tempo růstu': [12.3, 9.8, 7.5, 5.2, 4.1]
})

# Jednoduchý interaktivní koláčový graf s Plotly Express
fig = px.pie(
    data,
    values='Tržní podíl',
    names='Kategorie',
    title='Tržní podíl podle průmyslového sektoru',
    hover_data=['Tempo růstu'],
    labels={'Tempo růstu': 'Roční tempo růstu (%)'}
)

fig.update_traces(
    textposition='inside',
    textinfo='percent+label',
    marker=dict(line=dict(color='#FFFFFF', width=2))
)

fig.update_layout(
    title_font_size=22,
    legend_title_font_size=16,
    legend_font_size=14,
    hoverlabel=dict(bgcolor="white", font_size=14),
    width=800,
    height=600
)

fig.show()  # Zobrazí se v notebooku nebo může být uloženo jako HTML

# Více přizpůsobený interaktivní prstencový graf s Plotly Graph Objects
fig = go.Figure(data=[go.Pie(
    labels=data['Kategorie'],
    values=data['Tržní podíl'],
    hole=.4,
    hovertemplate='<b>%{label}</b><br>Tržní podíl: %{percent}<br>Tempo růstu: %{customdata}%<extra></extra>',
    customdata=data['Tempo růstu'],
    texttemplate='%{label}<br>%{percent}',
    marker=dict(
        colors=px.colors.qualitative.Pastel,
        line=dict(color='#FFFFFF', width=2)
    )
)])

fig.update_layout(
    title={
        'text': "Interaktivní prstencový graf: Tržní podíl podle průmyslu",
        'y': 0.95,
        'x': 0.5,
        'xanchor': 'center',
        'yanchor': 'top',
        'font': {'size': 22}
    },
    annotations=[dict(
        text='2023<br>Přehled<br>trhu',
        showarrow=False,
        font_size=16,
        x=0.5,
        y=0.5
    )],
    width=800,
    height=600
)

fig.show()  # Zobrazí se v notebooku nebo může být uloženo pomocí fig.write_html("pie_chart.html")
```

Výhody interaktivních koláčových grafů:
- Umožňují uživatelům prozkoumat podrobné informace pomocí najetí myší
- Mohou zobrazovat dodatečné metriky nad rámec primárních procentuálních hodnot
- Umožňují přepínatelnou legendu pro výběr/odznačení kategorií
- Poskytují možnost animace pro změny dat v průběhu času

## 9. Osvědčené postupy pro efektivní koláčové grafy

Když se rozhodnete, že koláčový graf je vhodný pro vaše data, dodržujte tyto osvědčené postupy, které zajistí jasnost a efektivnost:

```python
# Demonstrace osvědčených postupů pro koláčové grafy
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Vzorová data
categories = ['Kategorie A', 'Kategorie B', 'Kategorie C', 'Kategorie D']
values = [40, 30, 20, 10]

# Nastavení obrázku se dvěma podgrafy
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 8))

# Špatné postupy u koláčových grafů
ax1.pie(
    values + [2, 1.5, 1, 0.8, 0.7],  # Příliš mnoho malých výsečí
    labels=['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I'],  # Zkrácené, nejasné popisky
    colors=plt.cm.rainbow(np.linspace(0, 1, 9)),  # Duhové barvy (těžko rozlišitelné)
    startangle=0
)
```

Klíčové osvědčené postupy pro koláčové grafy:
1. **Omezte počet kategorií** na nejvýše 5-7
2. **Použijte jasné, seřazené řazení** (typicky od největšího k nejmenšímu)
3. **Zahrňte procenta nebo hodnoty** přímo v grafu
4. **Používejte výrazné, ale ne přehnané barvy**
5. **Přidejte jasné popisky**, které vysvětlují, co každá výseč představuje
6. **Přidejte titulek**, který vysvětluje, co celý koláč představuje
7. **Začněte v pozici 12 hodin** (úhel 90°) pro lepší čitelnost
8. **Zvažte přidání legendy**, pokud by popisky výsečí byly přeplněné
9. **Používejte přímé označení** místo nutnosti porovnávat barvy s legendou
10. **Zajistěte dobrý kontrast** mezi výsečemi pomocí okrajů nebo rozestupů

## 10. Shrnutí

Koláčové grafy jsou vizualizace pro zobrazení vztahů části k celku prostřednictvím proporcionálních segmentů kruhu. Přestože jsou široce používány v obchodě a médiích, měly by být používány opatrně a pouze v konkrétních situacích.

**Kdy používat koláčové grafy:**
- Pro znázornění jednoduchých proporcí s málo kategoriemi (ideálně 2-5)
- Při zobrazení toho, jak se části vztahují k celku
- Když existují podstatné rozdíly mezi segmenty
- Když je vaše publikum obeznámeno s koláčovými grafy a očekává je

**Kdy se vyhnout koláčovým grafům:**
- S více než 5-7 kategoriemi
- Když jsou hodnoty podobné velikosti
- Pro přesná porovnání mezi hodnotami
- Při zobrazení změn v čase
- Pro složité vztahy dat

**Alternativy k zvážení:**
- Sloupcové grafy pro přesnější porovnání
- Skládané sloupcové grafy pro vztahy části k celku
- Treemap grafy pro hierarchické vztahy části k celku
- Prstencové grafy jako mírně vylepšená verze koláčových grafů
- Waffle grafy pro diskrétní proporce

Koláčové grafy, pokud jsou použity vhodně a dobře navrženy, mohou být efektivní pro rychlé pochopení proporcionálních vztahů v datech u publika. Měly by však být vždy voleny uvážlivě, s ohledem na charakteristiky dat i zamýšlené sdělení.
