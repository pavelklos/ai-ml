## 1. Úvod do dashboardů

Dashboardy jsou vizuální zobrazení, která organizují a prezentují data přehledným a srozumitelným způsobem. Umožňují uživatelům sledovat klíčové metriky, pochopit trendy a činit rozhodnutí na základě dat. Na rozdíl od statických vizualizací jsou dashboardy často interaktivní a mohou se aktualizovat v reálném čase.

Klíčové komponenty dashboardů obvykle zahrnují:
- Grafy a diagramy
- Datové tabulky
- Interaktivní ovládací prvky (filtry, posuvníky, rozbalovací nabídky)
- Textové prvky a zobrazení KPI

Nastavme si prostředí pro tvorbu dashboardů:

## 3. Vytváření dashboardu s Plotly Dash

Plotly Dash je výkonný framework pro vytváření analytických webových aplikací. Kombinuje Flask, React.js a Plotly.js pro vytváření interaktivních dashboardů pomocí Pythonu.

```python
# Základní Dash aplikace
import dash
from dash import dcc, html
from dash.dependencies import Input, Output
import plotly.express as px

# Inicializace Dash aplikace
app = dash.Dash(__name__)

# Vytvoření filtrovaného dataframe
df_monthly = df.copy()
df_monthly['Měsíc'] = df_monthly['Datum'].dt.strftime('%Y-%m')
monthly_data = df_monthly.groupby(['Měsíc', 'Region']).agg({'Prodeje': 'sum'}).reset_index()

# Definice rozložení
app.layout = html.Div([
    html.H1("Prodejní Dashboard"),
    
    html.Div([
        html.Div([
            html.H3("Filtrovat podle regionu:"),
            dcc.Dropdown(
                id='region-dropdown',
                options=[{'label': region, 'value': region} for region in df['Region'].unique()],
                value=df['Region'].unique(),  # Výchozí hodnota - vše vybráno
                multi=True
            ),
        ], style={'width': '30%', 'display': 'inline-block'}),
    ]),
    
    html.Div([
        dcc.Graph(id='sales-time-series'),
    ]),
    
    html.Div([
        dcc.Graph(id='product-performance'),
    ]),
])

# Definice callbacku pro aktualizaci časové řady
@app.callback(
    Output('sales-time-series', 'figure'),
    [Input('region-dropdown', 'value')]
)
def update_time_series(selected_regions):
    filtered_df = df_monthly[df_monthly['Region'].isin(selected_regions)]
    time_data = filtered_df.groupby('Měsíc').agg({'Prodeje': 'sum'}).reset_index()
    
    fig = px.line(time_data, x='Měsíc', y='Prodeje', title='Měsíční trend prodejů')
    return fig

# Definice callbacku pro aktualizaci grafu produktů
@app.callback(
    Output('product-performance', 'figure'),
    [Input('region-dropdown', 'value')]
)
def update_product_chart(selected_regions):
    filtered_df = df[df['Region'].isin(selected_regions)]
    product_data = filtered_df.groupby('Produkt').agg({'Prodeje': 'sum'}).reset_index()
    
    fig = px.bar(product_data, x='Produkt', y='Prodeje', title='Výkonnost produktů')
    return fig

# Spuštění aplikace
if __name__ == '__main__':
    app.run_server(debug=True)
```

## 4. Tvorba interaktivních dashboardů pomocí Streamlit

Streamlit je známý pro svou jednoduchost použití a rychlý vývoj. Je skvělou volbou pro datové vědce, kteří chtějí rychle převést své analýzy do sdílitelných webových aplikací.

```python
# Uložte toto jako streamlit_dashboard.py
import streamlit as st
import pandas as pd
import plotly.express as px
import matplotlib.pyplot as plt
import seaborn as sns

# Načtení předem vytvořeného dataframe (v reálné aplikaci byste zde načítali data)
# df = pd.read_csv('sales_data.csv')

# Funkce pro vytvoření příkladových dat (pro demo účely)
@st.cache_data
def create_example_data():
    np.random.seed(42)
    dates = pd.date_range(start='2022-01-01', periods=365, freq='D')
    regions = ['Sever', 'Jih', 'Východ', 'Západ']
    products = ['Produkt A', 'Produkt B', 'Produkt C']
    
    data = []
    for date in dates:
        for region in regions:
            for product in products:
                sales = np.random.randint(10, 100)
                profit = sales * np.random.uniform(0.1, 0.4)
                data.append([date, region, product, sales, profit])
    
    return pd.DataFrame(data, columns=['Datum', 'Region', 'Produkt', 'Prodeje', 'Zisk'])

df = create_example_data()

# Nadpis aplikace
st.title('Prodejní Dashboard')
st.markdown('Interaktivní dashboard zobrazující výkonnost prodejů')

# Postranní panel pro filtrování
st.sidebar.header('Filtry')
regions = st.sidebar.multiselect('Vyberte regiony', df['Region'].unique(), default=df['Region'].unique())
products = st.sidebar.multiselect('Vyberte produkty', df['Produkt'].unique(), default=df['Produkt'].unique())
date_range = st.sidebar.date_input('Časový rozsah', [df['Datum'].min(), df['Datum'].max()])

# Filtrování dat
filtered_df = df[
    (df['Region'].isin(regions)) &
    (df['Produkt'].isin(products)) &
    (df['Datum'] >= pd.Timestamp(date_range[0])) &
    (df['Datum'] <= pd.Timestamp(date_range[1]))
]

# Klíčové metriky
st.header('Klíčové metriky')
col1, col2, col3 = st.columns(3)
col1.metric(label="Celkové prodeje", value=f"{filtered_df['Prodeje'].sum():,.0f} Kč")
col2.metric(label="Celkový zisk", value=f"{filtered_df['Zisk'].sum():,.0f} Kč")
col3.metric(label="Zisková marže", value=f"{(filtered_df['Zisk'].sum() / filtered_df['Prodeje'].sum()) * 100:.1f}%")

# Časová řada
st.header('Trend prodejů')
monthly_data = filtered_df.copy()
monthly_data['Měsíc'] = monthly_data['Datum'].dt.strftime('%Y-%m')
time_data = monthly_data.groupby('Měsíc').agg({'Prodeje': 'sum'}).reset_index()

fig = px.line(time_data, x='Měsíc', y='Prodeje', title='Měsíční prodeje')
st.plotly_chart(fig, use_container_width=True)

# Výkonnost produktů
st.header('Výkonnost produktů')
product_data = filtered_df.groupby('Produkt').agg({'Prodeje': 'sum'}).reset_index()
fig = px.bar(product_data, x='Produkt', y='Prodeje')
st.plotly_chart(fig, use_container_width=True)

# Regionální rozdělení
st.header('Regionální prodeje')
region_data = filtered_df.groupby('Region').agg({'Prodeje': 'sum'}).reset_index()
fig = px.pie(region_data, values='Prodeje', names='Region')
st.plotly_chart(fig, use_container_width=True)

# Datová tabulka
st.header('Datová tabulka')
st.dataframe(filtered_df.pivot_table(
    values='Prodeje',
    index=['Region', 'Produkt'],
    aggfunc='sum'
).reset_index())
```

## 5. Rozvržení a komponenty dashboardu

Dobře navržené rozvržení dashboardu je klíčové pro porozumění a interakci uživatele. Většina dashboard knihoven nabízí komponenty pro rozvržení k organizaci obsahu.

Zde je příklad vytvoření rozvržení pomocí knihovny Panel:

```python
# Příklad rozvržení v knihovně Panel
import panel as pn
import holoviews as hv
pn.extension('plotly')
hv.extension('plotly')

# Vytvoření vzorových vizualizací
def create_charts(data):
    # Graf časové řady
    time_data = data.groupby(data['Datum'].dt.strftime('%Y-%m')).agg({'Prodeje': 'sum'}).reset_index()
    time_chart = px.line(time_data, x='Datum', y='Prodeje', title='Měsíční prodeje')
    
    # Sloupcový graf produktů
    product_data = data.groupby('Produkt').agg({'Prodeje': 'sum'}).reset_index()
    product_chart = px.bar(product_data, x='Produkt', y='Prodeje', title='Výkonnost produktů')
    
    # Koláčový graf regionů
    region_data = data.groupby('Region').agg({'Prodeje': 'sum'}).reset_index()
    region_chart = px.pie(region_data, values='Prodeje', names='Region', title='Regionální rozdělení')
    
    return time_chart, product_chart, region_chart

time_chart, product_chart, region_chart = create_charts(df)

# Vytvoření rozvržení
dashboard = pn.Column(
    pn.pane.Markdown("# Prodejní Dashboard", style={'font-size': '24pt'}),
    
    # Ovládací prvky filtrů v řádku
    pn.Row(
        pn.widgets.Select(name='Region', options=list(df['Region'].unique()) + ['Vše']),
        pn.widgets.Select(name='Produkt', options=list(df['Produkt'].unique()) + ['Vše']),
        pn.widgets.DateRangeSlider(
            name='Časový rozsah',
            start=df['Datum'].min().timestamp() * 1000,
            end=df['Datum'].max().timestamp() * 1000,
            value=(df['Datum'].min().timestamp() * 1000, df['Datum'].max().timestamp() * 1000)
        )
    ),
    
    # Grafy v mřížkovém rozvržení
    pn.GridSpec(
        height=800,
        ncols=2,
        nrows=2,
        sizing_mode='stretch_width'
    )[0, 0:2] = pn.pane.Plotly(time_chart)  # Horní řádek: časový graf
    
    # Umístění grafu produktů vlevo dole
    dashboard.gridspec[1, 0] = pn.pane.Plotly(product_chart)
    
    # Umístění grafu regionů vpravo dole
    dashboard.gridspec[1, 1] = pn.pane.Plotly(region_chart)
)

# Zobrazení dashboardu
dashboard.servable()
```

Běžné vzory rozvržení zahrnují:
1. **Hlavička-Obsah-Patička**: Tradiční webové rozvržení s navigací nahoře
2. **Mřížkové rozvržení**: Dashboard rozdělený do rovnoměrných nebo proporčních buněk mřížky
3. **Karty**: Jednotlivé komponenty zapouzdřené v samostatných kartách
4. **Postranní panel + Hlavní obsah**: Ovládací prvky v postranním panelu s vizualizacemi v hlavním prostoru

## 7. Aktualizace dat a callbacky

Dashboardy obvykle potřebují aktualizovat vizualizace, když uživatelé interagují s ovládacími prvky. To se řeší prostřednictvím callbacků.

```python
# Příklad callbacku v Dash
from dash.dependencies import Input, Output

@app.callback(
    [Output('sales-chart', 'figure'),
     Output('performance-table', 'data')],
    [Input('date-picker-range', 'start_date'),
     Input('date-picker-range', 'end_date'),
     Input('region-dropdown', 'value'),
     Input('product-dropdown', 'value'),
     Input('chart-type', 'value'),
     Input('aggregation-method', 'value')]
)
def update_dashboard(start_date, end_date, regions, products, chart_type, agg_method):
    # Filtrování dat na základě vstupů
    filtered_df = df[
        (df['Datum'] >= start_date) &
        (df['Datum'] <= end_date) &
        (df['Region'].isin(regions)) &
        (df['Produkt'].isin(products))
    ]
    
    # Vytvoření agregovaných dat
    agg_data = filtered_df.groupby('Datum').agg({'Prodeje': agg_method}).reset_index()
    
    # Vytvoření grafu na základě vybraného typu
    if chart_type == 'bar':
        fig = px.bar(agg_data, x='Datum', y='Prodeje')
    elif chart_type == 'line':
        fig = px.line(agg_data, x='Datum', y='Prodeje')
    else:  # area
        fig = px.area(agg_data, x='Datum', y='Prodeje')
    
    # Vytvoření dat pro tabulku
    table_data = filtered_df.groupby(['Region', 'Produkt']).agg({'Prodeje': agg_method}).reset_index().to_dict('records')
    
    return fig, table_data
```

Streamlit zpracovává aktualizace dat automaticky, když se změní vstupy:

```python
# Automatické aktualizace dat ve Streamlit
import streamlit as st
import pandas as pd
import plotly.express as px

# Příklad toho, jak Streamlit zpracovává aktualizace automaticky
def load_data():
    # Vytvoření vzorových dat
    np.random.seed(42)
    dates = pd.date_range(start='2022-01-01', periods=365, freq='D')
    regions = ['Sever', 'Jih', 'Východ', 'Západ']
    products = ['Produkt A', 'Produkt B', 'Produkt C']
    
    data = []
    for date in dates:
        for region in regions:
            for product in products:
                sales = np.random.randint(10, 100)
                profit = sales * np.random.uniform(0.1, 0.4)
                data.append([date, region, product, sales, profit])
    
    return pd.DataFrame(data, columns=['Datum', 'Region', 'Produkt', 'Prodeje', 'Zisk'])

# Načtení dat
df = load_data()

# Uživatelské rozhraní ovládacích prvků
st.sidebar.header("Filtry")
regions = st.sidebar.multiselect("Vyberte regiony", df['Region'].unique(), default=df['Region'].unique())
chart_type = st.sidebar.selectbox("Typ grafu", ["Sloupcový", "Čárový", "Plošný"])

# Filtrování dat na základě výběru uživatele
filtered_df = df[df['Region'].isin(regions)]

# Vytvoření vizualizace na základě výběru
st.header("Prodeje podle regionu")
if chart_type == "Sloupcový":
    fig = px.bar(filtered_df.groupby('Region').sum().reset_index(), x='Region', y='Prodeje')
elif chart_type == "Čárový":
    fig = px.line(filtered_df.groupby(['Datum', 'Region']).sum().reset_index(), 
                 x='Datum', y='Prodeje', color='Region')
else:  # Plošný
    fig = px.area(filtered_df.groupby(['Datum', 'Region']).sum().reset_index(), 
                 x='Datum', y='Prodeje', color='Region')

# Zobrazení grafu
st.plotly_chart(fig, use_container_width=True)

# Pokaždé, když uživatel změní výběr, Streamlit automaticky znovu spustí skript
```

## 9. Možnosti nasazení

Jakmile je váš dashboard připraven, potřebujete ho nasadit, aby k němu uživatelé měli přístup:

### Možnosti nasazení Dash:
```python
# Pro jednoduché nasazení během vývoje
if __name__ == '__main__':
    app.run_server(debug=True, port=8050)

# Pro produkci pomocí gunicorn (instalujte pomocí pip)
# Uložte toto jako app.py, poté spusťte:
# gunicorn app:server -b :8000
```

### Nasazení Streamlit:
```bash
# Lokální nasazení
streamlit run vase_aplikace.py

# Cloudové nasazení pomocí Streamlit Cloud
# 1. Nahrajte svůj kód na GitHub
# 2. Zaregistrujte se na Streamlit Cloud
# 3. Propojte svůj GitHub repositář
# 4. Nasaďte svou aplikaci
```

### Další možnosti nasazení:

1. **Heroku**:
```bash
# Vytvořte requirements.txt a Procfile
# Procfile pro Dash:
web: gunicorn app:server
# Procfile pro Streamlit:
web: streamlit run app.py --server.port $PORT
```

2. **Docker**:
```dockerfile
# Dockerfile příklad pro Dash
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt ./
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8050

CMD ["python", "app.py"]
```

3. **AWS, Google Cloud nebo Azure**:
   - Nasazení jako kontejnery
   - Využití bezserverových možností
   - Nastavení s load balancingem pro aplikace s vysokou návštěvností

## 10. Shrnutí

Vytváření interaktivních dashboardů v Pythonu se stalo dostupným díky moderním knihovnám jako Plotly Dash a Streamlit. Klíčové body k zapamatování:

1. **Vyberte správný nástroj** podle svých potřeb:
   - Streamlit pro rychlý vývoj a jednodušší rozhraní
   - Dash pro vysoce přizpůsobené, podnikové aplikace
   - Panel pro integraci s více vizualizačními knihovnami

2. **Naplánujte rozvržení dashboardu** s ohledem na uživatelskou zkušenost:
   - Seskupte související informace
   - Použijte hierarchii pro vedení pozornosti
   - Poskytněte jasné filtry a ovládací prvky

3. **Optimalizujte výkon** při práci s většími datasety:
   - Předem agregujte data, kde je to možné
   - Zvažte strategie ukládání do mezipaměti
   - Načítejte data postupně

4. **Vytvořte interaktivitu** pro zvýšení zapojení uživatelů:
   - Přidejte filtry a ovládací prvky, které aktualizují vizualizace
   - Zahrňte možnosti podrobného zkoumání
   - Poskytněte kontext a vysvětlení

5. **Navrhujte pro své publikum**:
   - Zvažte technickou zdatnost uživatelů
   - Zaměřte se na metriky, které jsou důležité
   - Poskytněte odpovídající úroveň detailu

6. **Testujte se skutečnými uživateli** pro zajištění:
   - Intuitivní navigace
   - Přiměřené doby načítání
   - Jasné pochopení dat

Dodržováním těchto principů a využitím dashboard knihoven Pythonu můžete vytvářet výkonné, interaktivní datové prostředky, které pomohou uživatelům získat vhled a činit rozhodnutí na základě vašich dat.
