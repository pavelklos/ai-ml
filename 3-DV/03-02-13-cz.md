# Vizualizace sítí a grafů v Pythonu

## Úvod

Vizualizace sítí a grafů je mocný nástroj pro pochopení vztahů a spojení v komplexních datech. V mnoha oborech—od sociálních sítí a dopravních systémů po biologické interakce a odkazy mezi webovými stránkami—data přirozeně nabývají formy sítí. Efektivní vizualizace těchto sítí může odhalit skryté vzory, identifikovat klíčové uzly a pomoci komunikovat složité strukturální informace.

Tento průvodce zkoumá techniky a knihovny pro vizualizaci síťových dat v Pythonu, od základního vykreslování grafů až po interaktivní a dynamické vizualizace sítí.

## Pochopení grafových dat

Sítě se skládají z uzlů (vrcholů) propojených hranami (spojeními). Před ponořením se do vizualizace je důležité pochopit typy grafových dat:

- **Orientované vs. neorientované**: V orientovaných grafech mají hrany směr; v neorientovaných grafech jsou spojení obousměrná.
- **Vážené vs. nevážené**: Ve vážených grafech mají hrany přiřazené hodnoty (např. vzdálenosti, síly).
- **Jednoduché vs. multigrafy**: Multigrafy umožňují více hran mezi stejnými páry uzlů.
- **Cyklické vs. acyklické**: Acyklické grafy nemají cykly (cesty, které začínají a končí ve stejném uzlu).

## Základní vizualizace grafů pomocí NetworkX

NetworkX je základní knihovna pro vytváření, manipulaci a studium struktury a dynamiky sítí v Pythonu.

### Vytvoření jednoduchého grafu

```python
# Vytvoření neorientovaného grafu
G = nx.Graph()

# Přidání uzlů
G.add_nodes_from([1, 2, 3, 4, 5, 6, 7, 8])

# Přidání hran
G.add_edges_from([
    (1, 2), (1, 3), (2, 3), (2, 4), (3, 4), (3, 5),
    (4, 5), (4, 6), (5, 6), (5, 7), (6, 7), (6, 8), (7, 8)
])

# Základní vizualizace
plt.figure(figsize=(10, 8))
pos = nx.spring_layout(G, seed=42)  # Umístění uzlů pomocí pružinového rozvržení
nx.draw(G, pos, with_labels=True, node_color='skyblue', 
        node_size=700, edge_color='gray', linewidths=1, 
        font_size=15, font_weight='bold')
plt.title("Jednoduchý neorientovaný graf", fontsize=15)
plt.show()
```

### Přizpůsobení vzhledu hran podle váhy

```python
# Vytvoření váženého grafu
G = nx.Graph()
weighted_edges = [
    (1, 2, 0.7), (1, 3, 1.0), (2, 3, 0.8), (3, 4, 1.2),

# Přidání barevné stupnice pro váhy hran
```

## Rozvržení grafů řízené silou

Různé algoritmy rozvržení umisťují uzly způsoby, které zdůrazňují různé aspekty struktury grafu.

```python
# Vytvoření grafu malého světa
G = nx.watts_strogatz_graph(25, 4, 0.1, seed=42)

# Definice různých rozvržení
pos_spring = nx.spring_layout(G, seed=42)
pos_circular = nx.circular_layout(G)
pos_kamada = nx.kamada_kawai_layout(G)
pos_spectral = nx.spectral_layout(G)
pos_shell = nx.shell_layout(G)

# Vykreslení grafu s různými rozvrženími
fig, axes = plt.subplots(2, 3, figsize=(18, 12))
axes = axes.flatten()

layouts = [
    ('Pružinové rozvržení', pos_spring),
    ('Kruhové rozvržení', pos_circular),
    ('Kamada-Kawai rozvržení', pos_kamada),
    ('Spektrální rozvržení', pos_spectral),
    ('Skořápkové rozvržení', pos_shell)
]

for i, (layout_name, pos) in enumerate(layouts):
    if i < len(axes):
        ax = axes[i]
        nx.draw(G, pos=pos, ax=ax, with_labels=True, 
                node_color='lightblue', node_size=300, 
                font_size=10, font_weight='bold')
        ax.set_title(layout_name)
        ax.axis('off')

plt.tight_layout()
plt.show()
```

## Interaktivní vizualizace sítí

Interaktivní vizualizace umožňují uživatelům efektivněji prozkoumat sítě.

### Použití Plotly pro interaktivní sítě

```python
# Vytvoření grafu pro vizualizaci s Plotly
G = nx.karate_club_graph()
pos = nx.spring_layout(G, seed=42)

# Vytvoření stop hran
edge_x = []
edge_y = []
for edge in G.edges():
    x0, y0 = pos[edge[0]]
    x1, y1 = pos[edge[1]]
    edge_x.extend([x0, x1, None])
    edge_y.extend([y0, y1, None])

edge_trace = go.Scatter(
    x=edge_x, y=edge_y,
    line=dict(width=0.5, color='#888'),
    hoverinfo='none',
    mode='lines')

# Vytvoření stop uzlů
node_x = []
node_y = []
for node in G.nodes():
    x, y = pos[node]
    node_x.append(x)
    node_y.append(y)

node_trace = go.Scatter(
    x=node_x, y=node_y,
    mode='markers',
    hoverinfo='text',
    marker=dict(
        showscale=True,
        colorscale='YlGnBu',
        size=10,
        colorbar=dict(
            thickness=15,
            title='Spojení uzlů',
            xanchor='left',
            titleside='right'
        )
    )
)

# Obarvení uzlů podle jejich spojení
node_adjacencies = []
node_text = []
for node, adjacencies in enumerate(G.adjacency()):
    node_adjacencies.append(len(adjacencies[1]))
    node_text.append(f'Uzel #{node}: {len(adjacencies[1])} spojení')

node_trace.marker.color = node_adjacencies
node_trace.text = node_text

# Vytvoření grafu
fig = go.Figure(data=[edge_trace, node_trace],
             layout=go.Layout(
                title='<br>Síť karate klubu',
                titlefont_size=16,
                showlegend=False,
                hovermode='closest',
                margin=dict(b=20, l=5, r=5, t=40),
                xaxis=dict(showgrid=False, zeroline=False, showticklabels=False),
                yaxis=dict(showgrid=False, zeroline=False, showticklabels=False))
                )

fig.show()
```

## Vizualizace velkých sítí

Vizualizace velkých sítí vyžaduje speciální techniky, aby se předešlo vizuálnímu přeplnění.

```python
# Generování většího náhodného grafu
large_G = nx.barabasi_albert_graph(200, 2, seed=42)

# Výpočet metrik uzlů
betweenness = nx.betweenness_centrality(large_G)
degree = nx.degree_centrality(large_G)

# Filtrování méně důležitých uzlů pro vizualizaci
threshold = 0.05
important_nodes = [n for n in large_G.nodes() if betweenness[n] > threshold]
sub_G = large_G.subgraph(important_nodes)

plt.figure(figsize=(14, 10))

# Umístění všech uzlů pomocí původního grafu
pos = nx.spring_layout(large_G, seed=42)

# Vykreslení celé sítě s nízkou průhledností
nx.draw_networkx_edges(large_G, pos, edge_color='gray', alpha=0.1, width=0.5)
nx.draw_networkx_nodes(large_G, pos, node_color='gray', alpha=0.1, node_size=30)

# Vykreslení důležité podsítě
node_sizes = [betweenness[n]*10000 for n in sub_G]
node_colors = [degree[n] for n in sub_G]

nx.draw_networkx_edges(sub_G, pos, alpha=0.8, width=1.0)
nodes = nx.draw_networkx_nodes(sub_G, pos, node_color=node_colors, 
                              node_size=node_sizes,
                              cmap=plt.cm.viridis, alpha=0.8)

plt.colorbar(nodes, label='Stupeň centrality')
plt.title("Vizualizace velké sítě se zvýrazněnými důležitými uzly", fontsize=15)
plt.axis('off')
plt.tight_layout()
plt.show()
```

## Bipartitní a multipartitní grafy

Bipartitní grafy mají uzly rozdělené do dvou skupin, s hranami pouze mezi různými skupinami.

```python
# Vytvoření bipartitního grafu (produkty zakoupené zákazníky)
B = nx.Graph()

# Přidání uzlů různých typů
customers = ['Z1', 'Z2', 'Z3', 'Z4', 'Z5']
products = ['P1', 'P2', 'P3', 'P4', 'P5', 'P6']

B.add_nodes_from(customers, bipartite=0)  # Zákazníci jsou typ 0
B.add_nodes_from(products, bipartite=1)   # Produkty jsou typ 1

# Přidání hran (nákupy)
B.add_edges_from([
    ('Z1', 'P1'), ('Z1', 'P2'), ('Z1', 'P3'),
    ('Z2', 'P2'), ('Z2', 'P4'),
    ('Z3', 'P3'), ('Z3', 'P5'), ('Z3', 'P6'),
    ('Z4', 'P1'), ('Z4', 'P3'), ('Z4', 'P5'),
    ('Z5', 'P2'), ('Z5', 'P4'), ('Z5', 'P6')
])

# Vytvoření vlastního rozvržení
pos = {}
# Umístění zákazníků vlevo
for i, node in enumerate(customers):
    pos[node] = np.array([0, i])
# Umístění produktů vpravo
for i, node in enumerate(products):
    pos[node] = np.array([1, i])

plt.figure(figsize=(10, 8))
# Vykreslení uzlů
node_colors = ['skyblue' if B.nodes[n]['bipartite'] == 0 else 'lightgreen' for n in B.nodes()]
nx.draw_networkx_nodes(B, pos, node_color=node_colors, node_size=500, alpha=0.8)
# Vykreslení hran
nx.draw_networkx_edges(B, pos, alpha=0.5)
# Vykreslení popisků
nx.draw_networkx_labels(B, pos, font_size=12, font_weight='bold')

plt.title("Bipartitní graf: Zákazníci a produkty", fontsize=15)
plt.axis('off')
plt.tight_layout()
plt.show()
```

## Dynamická vizualizace sítí

Sítě, které se v průběhu času mění, vyžadují specializované techniky vizualizace.

```python
# Vytvoření seznamu grafů představujících vývoj sítě v čase
T = 5  # Počet časových kroků
dynamic_graphs = []

# Vytvoření základního grafu
G_base = nx.watts_strogatz_graph(15, 3, 0.1, seed=42)
dynamic_graphs.append(G_base.copy())

# Vývoj grafu v čase přidáváním/odstraňováním hran
for t in range(1, T):
    G_t = dynamic_graphs[-1].copy()
    
    # Přidání náhodných hran
    for _ in range(3):
        u, v = np.random.choice(G_t.nodes(), 2, replace=False)
        if not G_t.has_edge(u, v):
            G_t.add_edge(u, v)
    
    # Odstranění náhodných hran
    if G_t.number_of_edges() > 5:  # Zajištění, že neodstraníme všechny hrany
        edges_to_remove = np.random.choice(list(G_t.edges()), 
                                          min(2, G_t.number_of_edges() - 5), 
                                          replace=False)
        G_t.remove_edges_from(edges_to_remove)
    
    dynamic_graphs.append(G_t)

# Vizualizace vývoje sítě
fig, axes = plt.subplots(1, T, figsize=(20, 4))

pos = nx.spring_layout(G_base, seed=42)  # Použití stejného rozložení pro všechny časové kroky

for t, G_t in enumerate(dynamic_graphs):
    ax = axes[t]
    
    # Výpočet barev hran podle toho, kdy se objevily
    edge_colors = []
    for u, v in G_t.edges():
        # Kontrola, kdy se tato hrana poprvé objevila
        for ti, G_ti in enumerate(dynamic_graphs[:t+1]):
            if G_ti.has_edge(u, v):
                edge_colors.append(plt.cm.viridis(ti/T))
                break
    
    nx.draw(G_t, pos, ax=ax, with_labels=True, node_color='lightblue', 
            edge_color=edge_colors, width=2, node_size=300, 
            font_weight='bold', font_size=10)
    ax.set_title(f"Časový krok {t}")
    ax.axis('off')

plt.tight_layout()
plt.show()
```

## Detekce a vizualizace komunit

Mnoho reálných sítí má komunitní struktury, které lze detekovat a vizualizovat.

```python
# Vytvoření grafu s komunitní strukturou
G = nx.barbell_graph(10, 2)

# Aplikace algoritmu pro detekci komunit (metoda Louvain)
partition = community_louvain.best_partition(G)

# Vizualizace komunit
plt.figure(figsize=(12, 10))
pos = nx.spring_layout(G, seed=42)

# Zjištění počtu komunit
num_communities = max(partition.values()) + 1
color_map = get_cmap('tab10', num_communities)

# Vykreslení uzlů zbarvených podle komunity
for comm in range(num_communities):
    node_list = [node for node in G.nodes() if partition[node] == comm]
    nx.draw_networkx_nodes(G, pos, nodelist=node_list, 
                          node_color=[color_map(comm)], 
                          node_size=500, alpha=0.8)

nx.draw_networkx_edges(G, pos, alpha=0.5)
nx.draw_networkx_labels(G, pos, font_size=10, font_weight='bold')

plt.title("Detekce komunit v síti", fontsize=15)
plt.axis('off')
plt.tight_layout()
plt.show()
```

## Vizualizace atributů uzlů a hran

```python
# Vytvoření grafu s atributy uzlů a hran
G = nx.Graph()

# Přidání uzlů s atributy
nodes_with_attrs = [
    (1, {'role': 'manažer', 'dept': 'prodej', 'experience': 7}),
    (2, {'role': 'vývojář', 'dept': 'it', 'experience': 3}),
    (3, {'role': 'vývojář', 'dept': 'it', 'experience': 5}),
    (4, {'role': 'analytik', 'dept': 'marketing', 'experience': 2}),
    (5, {'role': 'manažer', 'dept': 'marketing', 'experience': 8}),
    (6, {'role': 'analytik', 'dept': 'prodej', 'experience': 4})
]
G.add_nodes_from(nodes_with_attrs)

# Přidání hran s atributy
edges_with_attrs = [
    (1, 2, {'weight': 3, 'relationship': 'dohlíží'}),
    (1, 6, {'weight': 5, 'relationship': 'dohlíží'}),
    (2, 3, {'weight': 2, 'relationship': 'spolupracuje'}),
    (3, 4, {'weight': 4, 'relationship': 'spolupracuje'}),
    (4, 5, {'weight': 3, 'relationship': 'hlásí_se'}),
    (5, 6, {'weight': 1, 'relationship': 'dohlíží'})
]
G.add_edges_from(edges_with_attrs)

plt.figure(figsize=(12, 10))
pos = nx.spring_layout(G, seed=42)

# Velikosti uzlů podle zkušeností
node_sizes = [300 + G.nodes[n]['experience'] * 50 for n in G.nodes()]

# Barvy uzlů podle oddělení
dept_colors = {'prodej': 'royalblue', 'it': 'limegreen', 'marketing': 'crimson'}
node_colors = [dept_colors[G.nodes[n]['dept']] for n in G.nodes()]

# Šířky hran podle váhy
edge_widths = [G[u][v]['weight'] for u, v in G.edges()]

# Styly hran podle vztahu
edge_styles = {'dohlíží': 'solid', 'spolupracuje': 'dashed', 'hlásí_se': 'dotted'}
edge_linestyles = [edge_styles[G[u][v]['relationship']] for u, v in G.edges()]

# Vykreslení grafu
nx.draw_networkx_nodes(G, pos, node_size=node_sizes, node_color=node_colors, alpha=0.8)

for i, (u, v) in enumerate(G.edges()):
    nx.draw_networkx_edges(G, pos, edgelist=[(u, v)], width=edge_widths[i], 
                          style=edge_linestyles[i], alpha=0.7)

nx.draw_networkx_labels(G, pos, font_size=12, font_weight='bold')

# Vytvoření legendy pro oddělení
dept_patches = [plt.Line2D([0], [0], marker='o', color='w', markerfacecolor=color, 
                          markersize=15, label=dept) 
               for dept, color in dept_colors.items()]
# Vytvoření legendy pro vztahy
rel_patches = [plt.Line2D([0], [0], color='black', linestyle=style, 
                         label=rel) 
              for rel, style in edge_styles.items()]

plt.legend(handles=dept_patches + rel_patches, loc='upper right')
plt.title("Síť s atributy uzlů a hran", fontsize=15)
```

## 3D vizualizace sítí

Pro komplexní sítě může 3D vizualizace poskytnout dodatečnou přehlednost.

```python
# Tento příklad používá Plotly pro 3D vizualizaci sítě

import plotly.graph_objects as go
import numpy as np

# Vytvoření náhodného 3D grafu
G_3d = nx.random_geometric_graph(50, 0.125, dim=3)

# Získání 3D pozic
pos_3d = nx.get_node_attributes(G_3d, 'pos')

# Vytvoření stopy hran
edge_x = []
edge_y = []
edge_z = []
for edge in G_3d.edges():
    x0, y0, z0 = pos_3d[edge[0]]
    x1, y1, z1 = pos_3d[edge[1]]
    edge_x.extend([x0, x1, None])
    edge_y.extend([y0, y1, None])
    edge_z.extend([z0, z1, None])

edge_trace = go.Scatter3d(
    x=edge_x,
    y=edge_y,
    z=edge_z,
    mode='lines',
    line=dict(color='black', width=2),
    hoverinfo='none'
)

# Vytvoření stopy uzlů
node_x = []
node_y = []
node_z = []
for node in G_3d.nodes():
    x, y, z = pos_3d[node]
    node_x.append(x)
    node_y.append(y)
    node_z.append(z)

# Výpočet stupně uzlů pro barvy
node_adjacencies = []
for node, adjacencies in enumerate(G_3d.adjacency()):
    node_adjacencies.append(len(adjacencies[1]))

node_trace = go.Scatter3d(
    x=node_x,
    y=node_y,
    z=node_z,
    mode='markers',
    marker=dict(
        showscale=True,
        colorscale='YlGnBu',
        size=10,
        color=node_adjacencies,
        colorbar=dict(
            thickness=20,
            title='Spojení uzlů'
        )
    ),
    text=[f'Uzel {i}: {adj} spojení' for i, adj in enumerate(node_adjacencies)],
    hoverinfo='text'
)

# Vytvoření grafu
fig = go.Figure(data=[edge_trace, node_trace])
fig.update_layout(
    title='3D vizualizace sítě',
    showlegend=False,
    scene=dict(
        xaxis=dict(showticklabels=False),
        yaxis=dict(showticklabels=False),
        zaxis=dict(showticklabels=False)
    ),
    margin=dict(l=0, r=0, b=0, t=40)
)
```

## Shrnutí

Vizualizace sítí a grafů je nezbytným nástrojem pro pochopení a komunikaci vztahů v komplexních datech. Klíčové poznatky z tohoto průvodce zahrnují:

1. **Základy grafů**: Pochopení základních komponentů sítí (uzlů a hran) a jejich různých typů (orientované, neorientované, vážené atd.) je nezbytné pro efektivní vizualizaci.

2. **Možnosti knihoven**: Python nabízí více knihoven pro vizualizaci sítí, každá se svými silnými stránkami:
   - NetworkX pro vytváření, analýzu a základní vizualizaci grafů
   - Matplotlib pro přizpůsobení statických vizualizací sítí
   - Plotly pro interaktivní vizualizace sítí
   - PyVis a Cytoscape pro vysoce interaktivní webové vizualizace

3. **Algoritmy rozvržení**: Volba správného algoritmu rozvržení (pružinové, kruhové, spektrální atd.) výrazně ovlivňuje, jak jsou struktury sítí vnímány ve vizualizacích.

4. **Vizuální kódování**: Efektivní vizualizace sítí využívají vizuální vlastnosti jako velikost uzlů, barvu a šířku hran k zakódování dalších dimenzí dat.

5. **Detekce komunit**: Identifikace a vizualizace komunitních struktur pomáhá odhalit základní vzory v sítích.

6. **Práce s velkými sítěmi**: Pro velké sítě se stávají nezbytné techniky jako filtrování, agregace a zaměření se na klíčové uzly pro zajištění přehlednosti.

7. **Specializované vizualizace**: Různé typy sítí (bipartitní, geografické, dynamické) vyžadují specializované přístupy k vizualizaci.

8. **Interaktivní průzkum**: Komplexní sítě těží z interaktivních nástrojů, které umožňují přiblížení, filtrování a prozkoumání detailů uzlů.

Využitím těchto technik mohou dataloví vědci vytvářet smysluplné vizualizace, které odhalují skryté vzory a struktury v síťových datech, což činí složité vztahy přístupnějšími a srozumitelnějšími.
