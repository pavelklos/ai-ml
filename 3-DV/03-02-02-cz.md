# Interaktivní vizualizace pomocí Plotly

## Úvod

Plotly je výkonná knihovna pro vizualizaci dat, která umožňuje vytvářet interaktivní, publikačně kvalitní grafy v Pythonu. Na rozdíl od statických vizualizačních knihoven jako Matplotlib, Plotly generuje interaktivní webové vizualizace, které uživatelům umožňují zobrazovat detaily při najetí myší, přibližovat, posouvat a interagovat s daty. Tato interaktivita činí Plotly vynikajícím nástrojem pro průzkumnou analýzu dat, dashboardy a prezentace.

Tento průvodce vás provede vytvořením různých interaktivních vizualizací pomocí Plotly, od základních grafů až po pokročilé interaktivní funkce.

## Nastavení Plotly

Začneme instalací a nastavením Plotly:

```python
# Instalace Plotly (spusťte v terminálu nebo v buňce notebooku)
# pip install plotly

# Import potřebných knihoven
import plotly.express as px  # Vysokoúrovňové rozhraní
import plotly.graph_objects as go  # Nízkoúrovňové rozhraní
import plotly.io as pio
import numpy as np
import pandas as pd

# Nastavení výchozího rendereru
pio.renderers.default = "notebook"  # Pro Jupyter notebook
# Alternativní renderery: "browser", "colab", "kaggle", atd.

# Ukázková data pro příklady
np.random.seed(42)
random_x = np.random.randint(1, 101, 100)
random_y = np.random.randint(1, 101, 100)
categories = np.random.choice(['A', 'B', 'C', 'D'], 100)
```

## Základní interaktivní grafy

### Jednoduchý bodový graf

Nejjednodušší způsob, jak vytvořit interaktivní grafy, je pomocí Plotly Express:

```python
# Vytvoření jednoduchého bodového grafu
fig = px.scatter(x=random_x, y=random_y, color=categories, 
                 title="Základní interaktivní bodový graf",
                 labels={"x": "X-osa", "y": "Y-osa", "color": "Kategorie"},
                 opacity=0.7)

# Zobrazení grafu
fig.show()
```

### Čárový graf

```python
# Generování časové řady
dates = pd.date_range('2022-01-01', periods=30)

# Vytvoření čárového grafu
fig = px.line(x=dates, y=values, 
              title="Interaktivní čárový graf",
              labels={"x": "Datum", "y": "Hodnota"})

# Zobrazení grafu
fig.show()
```

### Sloupcový graf

```python
# Ukázková data pro sloupcový graf

# Vytvoření sloupcového grafu
fig = px.bar(x=categories, y=values,
             title="Interaktivní sloupcový graf",
             labels={"x": "Kategorie", "y": "Hodnota"},
```

## Přizpůsobení grafů

Plotly nabízí rozsáhlé možnosti přizpůsobení vašich vizualizací:

```python
# Vytvoření bodového grafu s přizpůsobením
fig = px.scatter(x=random_x, y=random_y, color=categories)

# Přizpůsobení rozložení grafu
fig.update_layout(
    title="Přizpůsobený interaktivní bodový graf",
    title_font=dict(size=24, family="Arial", color="darkblue"),
    xaxis=dict(
        title="X-osa",
        title_font=dict(size=18),
        tickfont=dict(size=14),
        showgrid=True,
        gridwidth=1,
        gridcolor='lightgray'
    ),
    yaxis=dict(
        title="Y-osa",
        title_font=dict(size=18),
        tickfont=dict(size=14),
        showgrid=True,
        gridwidth=1,
        gridcolor='lightgray'
    ),
    legend=dict(
        title="Kategorie",
        orientation="h",  # horizontální
        yanchor="bottom",
        y=1.02,
        xanchor="right",
        x=1
    ),
    plot_bgcolor='white'
)

# Aktualizace stop
fig.update_traces(
    marker=dict(size=12, line=dict(width=2, color='DarkSlateGrey')),
    selector=dict(mode='markers')
)

# Přidání anotací
fig.add_annotation(
    x=50, y=90,
    text="Oblast vysokých hodnot",
    showarrow=True,
    arrowhead=1,
    arrowsize=1,
    arrowwidth=2,
    arrowcolor="#636363"
)

# Zobrazení grafu
fig.show()
```

## Přidání pokročilé interaktivity

Plotly umožňuje přidat interaktivní prvky jako posuvníky, rozbalovací nabídky a tlačítka:

### Animovaný bodový graf s posuvníkem

```python
# Vytvoření dataframe s časovou proměnnou
df = pd.DataFrame({
    'time': np.tile(range(1, 11), 10),
    'x': np.random.rand(100) * 100,
    'y': np.random.rand(100) * 100,
    'size': np.random.rand(100) * 30 + 5,
    'category': np.random.choice(['A', 'B', 'C', 'D'], 100)
})

# Vytvoření animovaného bodového grafu
fig = px.scatter(df, x='x', y='y', 
                animation_frame='time',  # Toto vytvoří posuvník
                size='size', color='category',
                title="Animovaný bodový graf s posuvníkem",
                labels={'x': 'X-osa', 'y': 'Y-osa', 'size': 'Velikost', 'category': 'Kategorie'},
                range_x=[0, 100], range_y=[0, 100])

# Přizpůsobení animace
fig.layout.updatemenus[0].buttons[0].args[1]['frame']['duration'] = 800
fig.layout.updatemenus[0].buttons[0].args[1]['transition']['duration'] = 500

# Zobrazení grafu
fig.show()
```

### Rozbalovací nabídka pro výběr

```python
# Vytvoření grafu s rozbalovací nabídkou
fig = go.Figure()

# Přidání stop pro každou kategorii
for category in ['A', 'B', 'C', 'D']:
    df_cat = pd.DataFrame({
        'x': np.random.rand(20) * 100,
        'y': np.random.rand(20) * 100,
        'category': [category] * 20
    })
    fig.add_trace(
        go.Scatter(
            x=df_cat['x'],
            y=df_cat['y'],
            mode='markers',
            name=category,
            visible=(category == 'A')  # Pouze první kategorie je zpočátku viditelná
        )
    )

# Vytvoření a přidání rozbalovací nabídky
buttons = []
for i, category in enumerate(['A', 'B', 'C', 'D']):
    visibility = [False] * 4  # Začínáme se všemi False
    visibility[i] = True      # Nastavíme vybranou na True
    buttons.append(
        dict(
            method="update",
            label=f"Kategorie {category}",
            args=[{"visible": visibility},
                  {"title": f"Data pro kategorii {category}"}]
        )
    )

fig.update_layout(
    updatemenus=[
        dict(
            active=0,
            buttons=buttons,
            direction="down",
            pad={"r": 10, "t": 10},
            showactive=True,
            x=0.1,
            xanchor="left",
            y=1.15,
            yanchor="top"
        ),
    ],
    title="Interaktivní graf s rozbalovací nabídkou",
    xaxis_title="X-osa",
    yaxis_title="Y-osa"
)

# Zobrazení grafu
fig.show()
```

### Interaktivní tlačítka

```python
# Vytvoření grafu s tlačítky
fig = go.Figure()

# Generování ukázkových dat
x = np.linspace(0, 10, 100)
y_sin = np.sin(x)
y_cos = np.cos(x)
y_tan = np.tan(x)

# Přidání všech stop (zpočátku visible=False pro cos a tan)
fig.add_trace(go.Scatter(x=x, y=y_sin, mode='lines', name='sin(x)', visible=True))
fig.add_trace(go.Scatter(x=x, y=y_cos, mode='lines', name='cos(x)', visible=False))
fig.add_trace(go.Scatter(x=x, y=y_tan, mode='lines', name='tan(x)', visible=False))

# Vytvoření a přidání tlačítek
fig.update_layout(
    updatemenus=[
        dict(
            type="buttons",
            direction="right",
            active=0,
            x=0.1,
            y=1.15,
            buttons=list([
                dict(label="sin(x)",
                     method="update",
                     args=[{"visible": [True, False, False]},
                           {"title": "Funkce sin(x)"}]),
                dict(label="cos(x)",
                     method="update",
                     args=[{"visible": [False, True, False]},
                           {"title": "Funkce cos(x)"}]),
                dict(label="tan(x)",
                     method="update",
                     args=[{"visible": [False, False, True]},
                           {"title": "Funkce tan(x)"}]),
                dict(label="Všechny funkce",
                     method="update",
                     args=[{"visible": [True, True, True]},
                           {"title": "Všechny trigonometrické funkce"}]),
            ]),
        )
    ],
    title="Interaktivní graf s tlačítky",
    xaxis_title="X-osa",
    yaxis_title="Y-osa"
)

# Zobrazení grafu
fig.show()
```

## Vytváření podgrafů

Funkce podgrafů v Plotly umožňuje vytvářet komplexní rozložení s více grafy:

```python
from plotly.subplots import make_subplots

# Vytvoření grafu s podgrafy
fig = make_subplots(
    rows=2, cols=2,
    subplot_titles=("Bodový graf", "Čárový graf", "Sloupcový graf", "Koláčový graf"),
    specs=[[{"type": "scatter"}, {"type": "scatter"}],
           [{"type": "bar"}, {"type": "pie"}]]
)

# Přidání bodového grafu
fig.add_trace(
    go.Scatter(x=random_x[:20], y=random_y[:20], mode="markers"),
    row=1, col=1
)

# Přidání čárového grafu
fig.add_trace(
    go.Scatter(x=np.arange(10), y=np.cumsum(np.random.randn(10)), mode="lines"),
    row=1, col=2
)

# Přidání sloupcového grafu
fig.add_trace(
    go.Bar(x=['A', 'B', 'C', 'D'], y=[14, 18, 12, 9]),
    row=2, col=1
)

# Přidání koláčového grafu
fig.add_trace(
    go.Pie(values=[15, 25, 30, 30], labels=['A', 'B', 'C', 'D']),
    row=2, col=2
)

# Aktualizace rozložení
fig.update_layout(
    title_text="Příklad interaktivních podgrafů",
    height=800,
    showlegend=False
)

# Zobrazení grafu
fig.show()
```

## Osvědčené postupy

Při vytváření interaktivních vizualizací pomocí Plotly dodržujte tyto osvědčené postupy:

1. **Držte se tématu**: Zahrnujte pouze nezbytné interaktivní prvky, které přidávají hodnotu vaší vizualizaci.

2. **Přidejte užitečné informace při najetí myší**: Přizpůsobte šablony pro najetí myší, abyste poskytli hodnotný kontext:

```python
# Přizpůsobení šablon pro najetí myší
fig = px.scatter(x=random_x[:30], y=random_y[:30], color=categories[:30])

# Aktualizace šablony pro najetí myší
fig.update_traces(
    hovertemplate="<b>Hodnota X</b>: %{x}<br>" +
                  "<b>Hodnota Y</b>: %{y}<br>" +
                  "<b>Kategorie</b>: %{marker.color}<br>" +
                  "<extra></extra>"  # Odstraňuje název stopy z najetí myší
)

fig.show()
```

3. **Udržujte konzistentní barevné schéma**: Používejte konzistentní barvy pro stejné proměnné napříč vizualizacemi.

4. **Zahrňte dostatečný kontext**: Přidejte názvy, popisky os a legendy, aby byla vaše vizualizace samoexplanační:

```python
# Přidání správného kontextu
fig = px.scatter(x=random_x[:30], y=random_y[:30], color=categories[:30])

# Přidání komplexního kontextu
fig.update_layout(
    title={
        'text': 'Distribuce hodnot podle kategorie',
        'y':0.95,
        'x':0.5,
        'xanchor': 'center',
        'yanchor': 'top'
    },
    xaxis_title="Proměnná X (jednotky)",
    yaxis_title="Proměnná Y (jednotky)",
    legend_title="Skupiny kategorií",
    font=dict(
        family="Arial, sans-serif",
        size=12,
    )
)

fig.show()
```

5. **Uvažujte o výkonu**: Pro velké datové sady používejte vzorkování nebo agregaci pro zachování rychlosti odezvy:

```python
# Příklad práce s velkými datovými sadami
# Generování velké datové sady
large_df = pd.DataFrame({
    'x': np.random.randn(10000),
    'y': np.random.randn(10000),
    'kategorie': np.random.choice(['A', 'B', 'C', 'D', 'E'], 10000)
})

# Metoda 1: Vzorkování
sampled_df = large_df.sample(n=1000)  # Vzorkování 1000 bodů
fig1 = px.scatter(sampled_df, x='x', y='y', color='kategorie', title="Přístup vzorkování")

# Metoda 2: Agregace
aggregated_df = large_df.groupby('kategorie').agg({'x': 'mean', 'y': 'mean'}).reset_index()
fig2 = px.scatter(aggregated_df, x='x', y='y', color='kategorie', title="Přístup agregace")

fig1.show()
fig2.show()
```

## Praktické aplikace

Podívejme se na některé praktické aplikace interaktivních vizualizací s Plotly:

### Vizualizace ceny akcií

```python
# Generování falešných dat o akciích
dates = pd.date_range('2022-01-01', '2022-12-31', freq='B')  # Pracovní dny
price = 100 + np.cumsum(np.random.randn(len(dates)) * 2)
volume = np.random.randint(1000, 10000, size=len(dates))

stock_df = pd.DataFrame({
    'Datum': dates,
    'Cena': price,
    'Objem': volume
})

# Vytvoření interaktivního grafu akcií
fig = make_subplots(
    rows=2, cols=1,
    shared_xaxes=True,
    vertical_spacing=0.1,
    subplot_titles=("Cena akcie", "Objem obchodování"),
    row_heights=[0.7, 0.3]
)

# Přidání dat o ceně
fig.add_trace(
    go.Scatter(x=stock_df['Datum'], y=stock_df['Cena'], mode='lines', name='Cena akcie'),
    row=1, col=1
)

# Přidání dat o objemu
fig.add_trace(
    go.Bar(x=stock_df['Datum'], y=stock_df['Objem'], name='Objem'),
    row=2, col=1
)

# Přidání posuvníku rozsahu
fig.update_layout(
    xaxis=dict(
        rangeselector=dict(
            buttons=list([
                dict(count=1, label="1m", step="month", stepmode="backward"),
                dict(count=6, label="6m", step="month", stepmode="backward"),
                dict(count=1, label="YTD", step="year", stepmode="todate"),
                dict(count=1, label="1r", step="year", stepmode="backward"),
                dict(step="all")
            ])
        ),
        rangeslider=dict(visible=True),
        type="date"
    ),
    title="Interaktivní graf ceny a objemu akcií"
)

fig.show()
```

## Shrnutí

Interaktivní vizualizace s Plotly nabízejí výkonný způsob průzkumu a prezentace dat. Klíčové poznatky z tohoto průvodce zahrnují:

1. **Všestrannost Plotly**: Plotly poskytuje širokou škálu interaktivních typů grafů, od základních bodových a čárových grafů až po komplexní 3D vizualizace a mapy.

2. **Interaktivní funkce**: Vizualizace Plotly obsahují vestavěné informace při najetí myší, přiblížení, posouvání a další interaktivní funkce, které zlepšují průzkum dat.

3. **Možnosti přizpůsobení**: Rozsáhlé možnosti přizpůsobení vám umožňují vytvářet profesionální, publikačně kvalitní vizualizace s plnou kontrolou nad vzhledem.

4. **Pokročilá interaktivita**: Kromě základní interaktivity Plotly podporuje přidávání posuvníků, rozbalovacích nabídek a tlačítek pro vytváření dynamických, interaktivních dashboardů.

5. **Možnosti integrace**: Plotly pracuje bezproblémově s Pandas DataFrames a lze jej integrovat do různých aplikací, včetně Dash pro webové dashboardy.

6. **Sdílení a export**: Vizualizace Plotly lze exportovat jako interaktivní HTML soubory nebo statické obrázky, což usnadňuje jejich sdílení napříč různými platformami.

Interaktivní vizualizace jsou zvláště cenné pro průzkumnou analýzu dat, umožňující uživatelům objevovat vzory a poznatky, které by mohly být v statických vizualizacích přehlédnuty. Využitím možností Plotly můžete vytvářet poutavé, informativní vizualizace, které efektivně komunikují příběh vašich dat.
