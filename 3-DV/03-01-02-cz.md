## 1. Úvod do Matplotlib

Matplotlib je základní knihovna pro vizualizaci dat v Pythonu. Poskytuje komplexní sadu nástrojů pro vytváření statických, interaktivních a animovaných vizualizací. Knihovna nabízí jak jednoduché rozhraní podobné MATLABu prostřednictvím modulu pyplot, tak objektově orientované API pro složitější aplikace.

```python
# Import základních knihoven, které budeme používat
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Povolení zobrazení grafů přímo v Jupyter notebooku
# %matplotlib inline

# Nastavení stylu pro konzistentní vzhled
plt.style.use('seaborn-v0_8-whitegrid')
```

Matplotlib pracuje s číselnými daty poskytovanými prostřednictvím Python seznamů, NumPy polí nebo Pandas DataFrames. Jeho flexibilita jej činí vhodným pro vytváření široké škály vizualizací dat, od jednoduchých čárových grafů až po složité víceúrovňové obrázky.

## 2. Nastavení prostředí

Před vytvářením grafů se ujistěte, že máte nainstalované a správně importované potřebné balíčky:

```python
# Instalace matplotlib, pokud jej ještě nemáte
# pip install matplotlib numpy pandas

# Import knihoven
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Vytvoření vzorových dat pro naše příklady
x = np.linspace(0, 10, 100)  # 100 bodů od 0 do 10
sin_y = np.sin(x)
cos_y = np.cos(x)

# Kategorie a hodnoty pro příklady sloupcových grafů
categories = ['Kategorie A', 'Kategorie B', 'Kategorie C', 'Kategorie D', 'Kategorie E']
values = [23, 45, 56, 78, 32]

# Náhodná data pro příklady bodových grafů
np.random.seed(42)  # Pro reprodukovatelnost
x_scatter = np.random.rand(50)
y_scatter = np.random.rand(50)
colors = np.random.rand(50)
sizes = 1000 * np.random.rand(50)
```

## 3. Čárové grafy

Čárové grafy jsou ideální pro zobrazení trendů v čase nebo spojitých funkcí. Spojují datové body přímkami, což usnadňuje vizualizaci vzorů a vztahů.

```python
# Základní čárový graf
plt.figure(figsize=(10, 6))
plt.plot(x, sin_y)
plt.title('Základní funkce sinus')
plt.xlabel('hodnoty x')
plt.ylabel('sin(x)')
plt.grid(True)
plt.show()

# Více čar s popisky a legendou
plt.figure(figsize=(10, 6))
plt.plot(x, sin_y, label='sin(x)', color='blue', linestyle='-')
plt.plot(x, cos_y, label='cos(x)', color='red', linestyle='--')
plt.title('Funkce sinus a kosinus')
plt.xlabel('hodnoty x')
plt.ylabel('hodnoty y')
plt.legend()
plt.grid(True)
plt.show()

# Možnosti stylizace čárových grafů
plt.figure(figsize=(10, 6))
plt.plot(x, sin_y, color='green', linestyle='-', linewidth=2, marker='o', 
         markersize=4, markerfacecolor='yellow', markeredgecolor='green', 
         markeredgewidth=1, alpha=0.7)
plt.title('Stylizovaný čárový graf')
plt.xlabel('hodnoty x')
plt.ylabel('sin(x)')
plt.grid(True)
plt.show()
```

Běžné parametry čárových grafů:
- `color`: Nastavení barvy čáry
- `linestyle`: '-' (plná), '--' (čárkovaná), '-.' (čerchovaná), ':' (tečkovaná)
- `linewidth`: Šířka čáry
- `marker`: Styl značek (např. 'o', 's', '^', 'x')
- `markersize`: Velikost značek
- `alpha`: Průhlednost (0 až 1)

## 4. Sloupcové grafy

Sloupcové grafy jsou ideální pro porovnávání množství v různých kategoriích. Představují kategorická data pomocí obdélníkových sloupců úměrných hodnotám, které reprezentují.

```python
# Základní vertikální sloupcový graf
plt.figure(figsize=(10, 6))
plt.bar(categories, values)
plt.title('Základní sloupcový graf')
plt.xlabel('Kategorie')
plt.ylabel('Hodnoty')
plt.show()

# Horizontální sloupcový graf
plt.figure(figsize=(10, 6))
plt.barh(categories, values)
plt.title('Horizontální sloupcový graf')
plt.xlabel('Hodnoty')
plt.ylabel('Kategorie')
plt.show()

# Stylizovaný sloupcový graf s vlastními barvami
plt.figure(figsize=(10, 6))
plt.bar(categories, values, color='skyblue', edgecolor='navy', linewidth=2, alpha=0.7)
plt.title('Stylizovaný sloupcový graf')
plt.xlabel('Kategorie')
plt.ylabel('Hodnoty')

# Přidání hodnot nad každý sloupec
for i, v in enumerate(values):
    plt.text(i, v + 1, str(v), ha='center')
    
plt.show()

# Skupinový sloupcový graf
group_data = pd.DataFrame({
    'Skupina 1': [20, 35, 30, 35, 27],
    'Skupina 2': [25, 32, 34, 20, 25],
    'Skupina 3': [15, 28, 20, 25, 30]
}, index=categories)

group_data.plot(kind='bar', figsize=(12, 6))
plt.title('Skupinový sloupcový graf')
plt.xlabel('Kategorie')
plt.ylabel('Hodnoty')
plt.legend(title='Skupiny')
plt.grid(True, axis='y')
plt.show()
```

Klíčové parametry sloupcových grafů:
- `width`: Šířka sloupců
- `color`: Barva sloupců
- `edgecolor`: Barva okrajů sloupců
- `alpha`: Průhlednost
- `align`: 'center' nebo 'edge'
- `bottom`: Hodnoty, kde sloupce začínají (pro stohování)

## 5. Bodové grafy

Bodové grafy zobrazují vztah mezi dvěma číselnými proměnnými. Každý bod představuje pozorování, jehož pozice je určena hodnotami na dvou osách.

```python
# Základní bodový graf
plt.figure(figsize=(10, 6))
plt.scatter(x_scatter, y_scatter)
plt.title('Základní bodový graf')
plt.xlabel('Hodnoty X')
plt.ylabel('Hodnoty Y')
plt.grid(True)
plt.show()

# Bodový graf s různými barvami a velikostmi
plt.figure(figsize=(10, 6))
plt.scatter(x_scatter, y_scatter, c=colors, s=sizes, alpha=0.7, cmap='viridis')
plt.colorbar(label='Hodnota barvy')
plt.title('Bodový graf s variací barev a velikostí')
plt.xlabel('Hodnoty X')
plt.ylabel('Hodnoty Y')
plt.grid(True)
plt.show()

# Bodový graf s kategorickými daty
categories_for_scatter = ['Kategorie A', 'Kategorie B', 'Kategorie C']
category_indices = np.random.choice(range(len(categories_for_scatter)), 50)
category_colors = {0: 'red', 1: 'green', 2: 'blue'}

plt.figure(figsize=(10, 6))
for i in range(len(categories_for_scatter)):
    indices = category_indices == i
    plt.scatter(x_scatter[indices], y_scatter[indices], 
               color=category_colors[i], label=categories_for_scatter[i], alpha=0.7)
    
plt.title('Bodový graf s kategoriemi')
plt.xlabel('Hodnoty X')
plt.ylabel('Hodnoty Y')
plt.legend()
plt.grid(True)
plt.show()
```

Důležité parametry bodových grafů:
- `s`: Velikost značek
- `c`: Barva nebo sekvence barev
- `marker`: Styl značek
- `alpha`: Průhlednost
- `cmap`: Barevná mapa pro mapování barev
- `edgecolors`: Barvy okrajů značek

## 6. Přizpůsobení vzhledu grafů

Matplotlib nabízí rozsáhlé možnosti přizpůsobení pro vylepšení vzhledu a čitelnosti vašich grafů:

```python
# Nastavení konzistentního stylu
plt.style.use('ggplot')  # Další možnosti: 'seaborn', 'fivethirtyeight', 'dark_background'

# Vytvoření vysoce přizpůsobeného grafu
plt.figure(figsize=(12, 7))

# Vytvoření hlavního grafu
plt.plot(x, sin_y, label='sin(x)', color='#1f77b4', linewidth=2)
plt.plot(x, cos_y, label='cos(x)', color='#ff7f0e', linewidth=2)

# Přizpůsobení titulku a popisků
plt.title('Funkce sinus a kosinus', fontsize=16, fontweight='bold')
plt.xlabel('Popisek osy X', fontsize=12)
plt.ylabel('Popisek osy Y', fontsize=12)

# Přizpůsobení mřížky
plt.grid(True, linestyle='--', alpha=0.7)

# Přizpůsobení limitů os a značek
plt.xlim(0, 10)
plt.ylim(-1.5, 1.5)
plt.xticks(np.arange(0, 11, 2))
plt.yticks(np.arange(-1, 1.1, 0.5))

# Přidání legendy
plt.legend(fontsize=12, loc='upper right', framealpha=0.9)

# Přidání anotací
plt.annotate('Maximum', xy=(1.5, 1), xytext=(2, 1.3),
             arrowprops=dict(facecolor='black', shrink=0.05, width=1.5))

# Přidání textu
plt.text(7, -1, 'Příklad vlastního textu', fontsize=12)

# Zobrazení grafu
plt.tight_layout()  # Automaticky upraví parametry podgrafu pro lepší přizpůsobení
plt.show()
```

Klíčové prvky přizpůsobení:
- `plt.style.use()`: Aplikace předdefinovaných stylových listů
- `figsize`: Nastavení velikosti obrázku v palcích
- `fontsize` a `fontweight`: Řízení vzhledu textu
- `xlim()`, `ylim()`: Nastavení limitů os
- `xticks()`, `yticks()`: Řízení značek na osách
- `tight_layout()`: Úprava rozestupů pro lepší vzhled
- `annotate()` a `text()`: Přidání vysvětlujícího textu a anotací

## 7. Kombinování různých typů grafů

Často budete chtít kombinovat různé typy grafů, abyste vyprávěli komplexnější příběh dat:

```python
# Vytvoření obrázku s více typy grafů
np.random.seed(42)
data = np.random.normal(0, 1, 1000)
x_trend = np.arange(20)
y_trend = np.cumsum(np.random.randn(20))
categories_small = ['A', 'B', 'C', 'D']
values_small = [15, 30, 45, 10]

# Vytvoření obrázku s mřížkou podgrafů
fig, axs = plt.subplots(2, 2, figsize=(14, 10))

# Histogram vlevo nahoře
axs[0, 0].hist(data, bins=30, color='skyblue', edgecolor='black')
axs[0, 0].set_title('Histogram')
axs[0, 0].set_xlabel('Hodnota')
axs[0, 0].set_ylabel('Četnost')

# Čárový graf vpravo nahoře
axs[0, 1].plot(x_trend, y_trend, marker='o', color='green')
axs[0, 1].set_title('Čárový graf')
axs[0, 1].set_xlabel('Čas')
axs[0, 1].set_ylabel('Kumulativní součet')
axs[0, 1].grid(True)

# Sloupcový graf vlevo dole
axs[1, 0].bar(categories_small, values_small, color='salmon')
axs[1, 0].set_title('Sloupcový graf')
axs[1, 0].set_xlabel('Kategorie')
axs[1, 0].set_ylabel('Hodnota')

# Bodový graf vpravo dole
x_scatter_small = np.random.rand(30)
y_scatter_small = x_scatter_small * 2 + np.random.randn(30) * 0.5
axs[1, 1].scatter(x_scatter_small, y_scatter_small, color='purple', alpha=0.7)
axs[1, 1].set_title('Bodový graf')
axs[1, 1].set_xlabel('Hodnota X')
axs[1, 1].set_ylabel('Hodnota Y')
axs[1, 1].grid(True)

# Úprava rozvržení
plt.tight_layout()
plt.show()
```

## 8. Ukládání grafů

Po vytvoření vizualizací je často budete chtít uložit pro zprávy, prezentace nebo webové publikace:

```python
# Vytvoření jednoduchého grafu pro uložení
plt.figure(figsize=(10, 6))
plt.plot(x, sin_y, label='sin(x)')
plt.title('Funkce sinus')
plt.xlabel('hodnoty x')
plt.ylabel('sin(x)')
plt.legend()
plt.grid(True)

# Uložení v různých formátech
plt.savefig('sinus_graf.png', dpi=300)  # PNG formát s rozlišením 300 dpi
plt.savefig('sinus_graf.jpg', quality=90)  # JPG formát s 90% kvalitou
plt.savefig('sinus_graf.pdf')  # PDF formát pro vektorovou grafiku
plt.savefig('sinus_graf.svg')  # SVG formát pro vektorovou grafiku

# Uložení s průhledným pozadím
plt.savefig('sinus_graf_pruhledny.png', dpi=300, transparent=True)

plt.show()
```

Důležité parametry pro `savefig()`:
- `dpi`: Rozlišení v bodech na palec
- `transparent`: Zda použít průhledné pozadí
- `bbox_inches='tight'`: Automatická úprava velikosti obrázku pro zahrnutí všech prvků
- `facecolor`: Barva pozadí obrázku
- `edgecolor`: Barva okraje obrázku

## 9. Praktické příklady

Pojďme aplikovat naše znalosti na několik praktických příkladů s daty podobnými reálnému světu:

```python
# Příklad 1: Vizualizace měsíčních prodejů
months = ['Led', 'Úno', 'Bře', 'Dub', 'Kvě', 'Čer', 
          'Čvc', 'Srp', 'Zář', 'Říj', 'Lis', 'Pro']
sales_2021 = [12000, 13500, 14200, 15100, 16300, 17500, 
              18200, 19100, 20500, 19800, 21200, 22500]
sales_2022 = [13000, 14300, 15600, 16800, 17900, 19200, 
              20100, 21400, 22800, 21900, 23400, 25100]

plt.figure(figsize=(12, 6))

# Čárový graf pro trendy
plt.plot(months, sales_2021, marker='o', linestyle='-', color='blue', label='Prodeje 2021')
plt.plot(months, sales_2022, marker='s', linestyle='--', color='red', label='Prodeje 2022')

# Přidání titulků a popisků
plt.title('Porovnání měsíčních prodejů: 2021 vs 2022', fontsize=16)
plt.xlabel('Měsíc', fontsize=12)
plt.ylabel('Prodeje (Kč)', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.legend()

# Anotace procentuálního meziročního nárůstu
annual_increase = ((sum(sales_2022) - sum(sales_2021)) / sum(sales_2021)) * 100
plt.annotate(f'Roční nárůst: {annual_increase:.1f}%', 
             xy=(6, max(sales_2022)), 
             xytext=(6, max(sales_2022) + 1500),
             fontsize=12,
             bbox=dict(boxstyle="round,pad=0.5", fc="yellow", alpha=0.7))

plt.tight_layout()
plt.show()

# Příklad 2: Porovnání výkonnosti produktů
products = ['Produkt A', 'Produkt B', 'Produkt C', 'Produkt D', 'Produkt E']
sales = [850, 730, 1200, 590, 920]
profits = [320, 290, 410, 240, 350]
returns = [23, 18, 35, 12, 25]

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))

# Sloupcový graf pro prodeje a zisky
x = np.arange(len(products))
width = 0.35

ax1.bar(x - width/2, sales, width, label='Prodeje', color='skyblue')
ax1.bar(x + width/2, profits, width, label='Zisk', color='lightgreen')
ax1.set_title('Prodeje a zisky podle produktu')
ax1.set_xlabel('Produkt')
ax1.set_ylabel('Částka (Kč)')
ax1.set_xticks(x)
ax1.set_xticklabels(products, rotation=45, ha='right')
ax1.legend()
ax1.grid(axis='y', linestyle='--', alpha=0.7)

# Bodový graf ukazující vztah mezi prodeji a vracením zboží
sizes = [p * 3 for p in profits]  # Velikost založená na zisku
ax2.scatter(sales, returns, s=sizes, alpha=0.7, c=profits, cmap='viridis')
ax2.set_title('Prodeje vs. Vrácení (Velikost = Zisk)')
ax2.set_xlabel('Prodeje (Kč)')
ax2.set_ylabel('Vrácení (ks)')
ax2.grid(True)

# Přidání popisků produktů k bodům
for i, product in enumerate(products):
    ax2.annotate(product, (sales[i], returns[i]), 
                 xytext=(5, 5), textcoords='offset points')

plt.colorbar(ax2.collections[0], ax=ax2, label='Zisk (Kč)')
plt.tight_layout()
plt.show()
```
