# Dashboardy s knihovnami Dash nebo Panel

## Úvod

Dashboardy jsou mocné nástroje pro prezentaci dat interaktivním a vizuálně přitažlivým způsobem. Umožňují uživatelům zkoumat data prostřednictvím více vizualizací, filtrů a ovládacích prvků v rámci jediného rozhraní. Python nabízí několik vynikajících knihoven pro tvorbu dashboardů, přičemž Dash a Panel patří mezi dvě nejpopulárnější volby.

Dash, vyvinutý společností Plotly, je produktivní Python framework pro vytváření webových aplikací s vysoce přizpůsobeným uživatelským rozhraním v čistém Pythonu. Panel je naopak součástí ekosystému HoloViz a umožňuje vytvářet vlastní interaktivní webové aplikace a dashboardy propojením uživatelsky definovaných widgetů s grafy, obrázky, tabulkami nebo textem.

V tomto průvodci prozkoumáme oba frameworky, naučíme se budovat interaktivní dashboardy a pochopíme, kdy který z nich používat.

## Úvod do Dash

Dash je produktivní Python framework pro tvorbu webových aplikací. Je napsaný nad frameworky Flask, Plotly.js a React.js. Dash je ideální pro vytváření aplikací pro vizualizaci dat s vysoce přizpůsobenými uživatelskými rozhraními v čistém Pythonu.

### Základní komponenty Dash

Dash poskytuje HTML komponenty a interaktivní komponenty prostřednictvím modulů `html` a `dcc` (Dash Core Components):

```python
# HTML komponenty: Pro vytváření HTML tagů
# Dash Core Components: Pro vytváření interaktivních prvků
from dash import html, dcc

# Příklady základních komponent
html_div = html.Div("Toto je div element")
h1_title = html.H1("Toto je nadpis")
paragraph = html.P("Toto je odstavec textu")

# Interaktivní komponenty
dropdown = dcc.Dropdown(
    options=['New York City', 'Montreal', 'San Francisco'],
    value='Montreal'
)
slider = dcc.Slider(
    min=0,
    max=10,
    step=1,
    value=5
)
graph = dcc.Graph(id='example-graph')
```

## Vytvoření jednoduchého Dash dashboardu

Pojďme vytvořit jednoduchý dashboard, který vizualizuje nějaká data:

```python
import dash
from dash import dcc, html
import plotly.express as px
import pandas as pd

# Vytvoření vzorových dat
df = pd.DataFrame({
    "Fruit": ["Jablka", "Pomeranče", "Banány", "Jablka", "Pomeranče", "Banány"],
    "Amount": [4, 1, 2, 2, 4, 5],
    "City": ["SF", "SF", "SF", "NYC", "MTL", "NYC"]
})

# Inicializace aplikace
app = dash.Dash(__name__)

# Vytvoření sloupcového grafu
fig = px.bar(df, x="Fruit", y="Amount", color="City", barmode="group")

# Definice rozložení
app.layout = html.Div([
    html.H1('Jednoduchý dashboard ovoce'),
    html.Div([
        html.Label('Vyberte město:'),
        dcc.Dropdown(
            id='city-dropdown',
            options=[{'label': city, 'value': city} for city in df['City'].unique()],
            value='All',
            clearable=False
        ),
    ]),
    dcc.Graph(id='fruit-graph', figure=fig)
])

# Spuštění aplikace
if __name__ == '__main__':
    app.run_server(debug=True)
```

## Dash callbacky pro interaktivitu

Callbacky v Dash umožňují interaktivitu propojením komponent:

```python
from dash import Dash, dcc, html, Input, Output, callback
import plotly.express as px
import pandas as pd

# Vytvoření vzorových dat
df = pd.DataFrame({
    "Fruit": ["Jablka", "Pomeranče", "Banány", "Jablka", "Pomeranče", "Banány"],
    "Amount": [4, 1, 2, 2, 4, 5],
    "City": ["SF", "SF", "SF", "NYC", "MTL", "NYC"]
})

# Inicializace aplikace
app = Dash(__name__)

# Definice rozložení
app.layout = html.Div([
    html.H1('Interaktivní dashboard ovoce'),
    html.Div([
        html.Label('Vyberte město:'),
        dcc.Dropdown(
            id='city-dropdown',
            options=[{'label': 'Všechna', 'value': 'All'}] + 
                    [{'label': city, 'value': city} for city in df['City'].unique()],
            value='All',
            clearable=False
        ),
    ]),
    dcc.Graph(id='fruit-graph')
])

# Definice callbacku pro aktualizaci grafu na základě výběru v dropdownu
@callback(
    Output('fruit-graph', 'figure'),
    Input('city-dropdown', 'value')
)
def update_graph(selected_city):
    if selected_city == 'All':
        filtered_df = df
    else:
        filtered_df = df[df['City'] == selected_city]
    
    fig = px.bar(filtered_df, x="Fruit", y="Amount", color="City", barmode="group")
    return fig

# Spuštění aplikace
if __name__ == '__main__':
    app.run_server(debug=True)
```

## Úvod do Panel

Panel je vysokoúrovňové řešení pro tvorbu aplikací a dashboardů v Pythonu, které vám umožňuje propojit widgety s grafy, tabulkami nebo textem. Funguje s více knihovnami pro vizualizaci a lze jej nasadit jako samostatné aplikace nebo integrovat do Jupyter notebooků.

### Panel komponenty a widgety

```python
    '# Ukázka Panel widgetů',
    text_input,
    slider,
    select,
    checkbox,
    date_picker
)
```

## Budování Panel dashboardu

Pojďme vytvořit jednoduchý Panel dashboard:

```python
import panel as pn
import hvplot.pandas
import pandas as pd
import numpy as np

# Povolení rozšíření
pn.extension()

# Generování vzorových dat
dates = pd.date_range('2020-01-01', periods=100)
df = pd.DataFrame({
    'date': dates,
    'value1': np.random.randn(100).cumsum(),
    'value2': np.random.randn(100).cumsum(),
    'category': np.random.choice(['A', 'B', 'C'], 100)
})

# Vytvoření widgetů
category_select = pn.widgets.MultiSelect(
    name='Kategorie',
    options=list(df['category'].unique()),
    value=['A', 'B'],
    size=3
)

date_range = pn.widgets.DateRangeSlider(
    name='Rozsah dat',
    start=dates.min(),
    end=dates.max(),
    value=(dates.min(), dates.max())
)

# Definice funkce pro vytvoření grafů na základě hodnot widgetů
def create_plots(categories, date_range):
    filtered_df = df[
        (df['category'].isin(categories)) & 
        (df['date'] >= date_range[0]) & 
        (df['date'] <= date_range[1])
    ]
    
    line_plot = filtered_df.hvplot.line(
        x='date', y=['value1', 'value2'], 
        title='Čárový graf', height=300, width=700
    )
    
    scatter_plot = filtered_df.hvplot.scatter(
        x='value1', y='value2', by='category',
        title='Bodový graf', height=300, width=700
    )
    
    return pn.Column(line_plot, scatter_plot)

# Propojení widgetů s grafy
dashboard = pn.Column(
    '# Interaktivní datový dashboard',
    pn.Row(
        pn.Column('## Filtry', category_select, date_range),
        pn.panel(
            pn.bind(create_plots, categories=category_select, date_range=date_range)
        )
    )
)

# Zobrazení dashboardu
dashboard
```

## Interaktivita v Panel

Panel umožňuje vytvářet interaktivní aplikace pomocí reaktivních funkcí a widgetů:

```python
import panel as pn
import numpy as np
import holoviews as hv
import hvplot.pandas
import pandas as pd

pn.extension()

# Vytvoření vzorových dat
x = np.linspace(0, 10, 200)
y = np.sin(x)
df = pd.DataFrame({'x': x, 'y': y})

# Vytvoření interaktivních widgetů
amplitude = pn.widgets.FloatSlider(name='Amplituda', start=0.1, end=2, step=0.1, value=1)
frequency = pn.widgets.FloatSlider(name='Frekvence', start=0.1, end=2, step=0.1, value=1)
phase = pn.widgets.FloatSlider(name='Fázový posun', start=0, end=np.pi*2, step=0.1, value=0)

# Definice funkce, která aktualizuje graf na základě hodnot widgetů
@pn.depends(amplitude=amplitude, frequency=frequency, phase=phase)
def sine_plot(amplitude, frequency, phase):
    y_values = amplitude * np.sin(frequency * x + phase)
    df = pd.DataFrame({'x': x, 'y': y_values})
    return df.hvplot.line(x='x', y='y', height=400, width=700, 
                          title='Interaktivní sinusová vlna')

# Vytvoření dashboardu
dashboard = pn.Column(
    '# Interaktivní průzkumník sinusových vln',
    pn.Row(
        pn.Column('## Parametry', amplitude, frequency, phase),
        sine_plot
    )
)

dashboard
```

## Srovnání: Dash vs Panel

### Výhody Dash:
- Postavený na React.js, nabízí rozsáhlý ekosystém komponent
- Detailní dokumentace a rozsáhlá komunita
- Silná integrace s vizualizačními knihovnami Plotly
- Vhodnější pro komplexní webové aplikace

### Výhody Panel:
- Jednodušší na naučení a používání pro datové vědce
- Bezproblémová integrace s Jupyter notebooky
- Dobře funguje s mnoha vizualizačními knihovnami (Matplotlib, Plotly, Bokeh, HoloViews)
- Lepší pro rychlé prototypování

## Příklad dashboardu z reálného světa

Pojďme vytvořit komplexnější dashboard, který analyzuje a vizualizuje data akcií:

```python
import dash
from dash import dcc, html
from dash.dependencies import Input, Output
import plotly.express as px
import plotly.graph_objects as go
import pandas as pd
import numpy as np
import yfinance as yf
from datetime import datetime, timedelta

# Inicializace aplikace
app = dash.Dash(__name__, external_stylesheets=['https://codepen.io/chriddyp/pen/bWLwgP.css'])

# Definice rozložení aplikace
app.layout = html.Div([
    html.H1("Dashboard akcií"),
    
    html.Div([
        html.Div([
            html.Label("Vyberte akcii:"),
            dcc.Dropdown(
                id='stock-picker',
                options=[
                    {'label': 'Apple (AAPL)', 'value': 'AAPL'},
                    {'label': 'Microsoft (MSFT)', 'value': 'MSFT'},
                    {'label': 'Google (GOOGL)', 'value': 'GOOGL'},
                    {'label': 'Amazon (AMZN)', 'value': 'AMZN'},
                    {'label': 'Tesla (TSLA)', 'value': 'TSLA'}
                ],
                value='AAPL'
            )
        ], className="six columns"),
        
        html.Div([
            html.Label("Vyberte časové období:"),
            dcc.Dropdown(
                id='time-period',
                options=[
                    {'label': '1 Měsíc', 'value': '1mo'},
                    {'label': '3 Měsíce', 'value': '3mo'},
                    {'label': '6 Měsíců', 'value': '6mo'},
                    {'label': '1 Rok', 'value': '1y'},
                    {'label': '5 Let', 'value': '5y'}
                ],
                value='6mo'
            )
        ], className="six columns"),
    ], className="row"),
    
    html.Div([
        html.Div([
            dcc.Graph(id='stock-graph')
        ], className="eight columns"),
        
        html.Div([
            html.H4("Informace o akcii"),
            html.Div(id='stock-info')
        ], className="four columns"),
    ], className="row"),
    
    html.Div([
        html.Div([
            html.H4("Klouzavé průměry"),
            dcc.Graph(id='ma-graph')
        ], className="six columns"),
        
        html.Div([
            html.H4("Obchodní objem"),
            dcc.Graph(id='volume-graph')
        ], className="six columns"),
    ], className="row"),
])

@app.callback(
    [Output('stock-graph', 'figure'),
     Output('stock-info', 'children'),
     Output('ma-graph', 'figure'),
     Output('volume-graph', 'figure')],
    [Input('stock-picker', 'value'),
     Input('time-period', 'value')]
)
def update_dashboard(ticker, period):
    # Získání dat akcií
    end_date = datetime.now()
    
    if period == '1mo':
        start_date = end_date - timedelta(days=30)
    elif period == '3mo':
        start_date = end_date - timedelta(days=90)
    elif period == '6mo':
        start_date = end_date - timedelta(days=180)
    elif period == '1y':
        start_date = end_date - timedelta(days=365)
    else:  # 5y
        start_date = end_date - timedelta(days=1825)
    
    # Použití yfinance k získání dat
    stock_data = yf.download(ticker, start=start_date, end=end_date)
    
    # Výpočet klouzavých průměrů
    stock_data['MA20'] = stock_data['Close'].rolling(window=20).mean()
    stock_data['MA50'] = stock_data['Close'].rolling(window=50).mean()
    
    # Vytvoření hlavního grafu akcií
    fig1 = go.Figure()
    fig1.add_trace(go.Candlestick(
        x=stock_data.index,
        open=stock_data['Open'],
        high=stock_data['High'],
        low=stock_data['Low'],
        close=stock_data['Close'],
        name='Svíčkový graf'
    ))
    fig1.update_layout(
        title=f'{ticker} Cena akcie',
        xaxis_title='Datum',
        yaxis_title='Cena (Kč)',
        height=500
    )
    
    # Vytvoření grafu klouzavých průměrů
    fig2 = go.Figure()
    fig2.add_trace(go.Scatter(
        x=stock_data.index, 
        y=stock_data['Close'],
        mode='lines',
        name='Závěrečná cena'
    ))
    fig2.add_trace(go.Scatter(
        x=stock_data.index, 
        y=stock_data['MA20'],
        mode='lines',
        name='20denní KP',
        line=dict(color='orange')
    ))
    fig2.add_trace(go.Scatter(
        x=stock_data.index, 
        y=stock_data['MA50'],
        mode='lines',
        name='50denní KP',
        line=dict(color='green')
    ))
    fig2.update_layout(
        title='Klouzavé průměry',
        xaxis_title='Datum',
        yaxis_title='Cena (Kč)',
        height=400
    )
    
    # Vytvoření grafu objemů
    fig3 = go.Figure()
    fig3.add_trace(go.Bar(
        x=stock_data.index,
        y=stock_data['Volume'],
        name='Objem'
    ))
    fig3.update_layout(
        title='Obchodní objem',
        xaxis_title='Datum',
        yaxis_title='Objem',
        height=400
    )
    
    # Získání aktuálních informací o akcii
    try:
        stock_info = yf.Ticker(ticker).info
        current_price = stock_info.get('currentPrice', stock_data['Close'].iloc[-1])
        previous_close = stock_info.get('previousClose', stock_data['Close'].iloc[-2])
        market_cap = stock_info.get('marketCap', 'N/A')
        if isinstance(market_cap, (int, float)):
            market_cap = f"{market_cap/1000000000:.2f} mld. Kč"
        
        price_change = current_price - previous_close
        price_change_percent = (price_change / previous_close) * 100
        
        stock_info_div = html.Div([
            html.P(f"Aktuální cena: {current_price:.2f} Kč"),
            html.P([
                "Změna: ",
                html.Span(
                    f"{price_change:.2f} ({price_change_percent:.2f}%)",
                    style={'color': 'green' if price_change >= 0 else 'red'}
                )
            ]),
            html.P(f"Tržní kapitalizace: {market_cap}"),
            html.P(f"52týdenní maximum: {stock_info.get('fiftyTwoWeekHigh', 'N/A')} Kč"),
            html.P(f"52týdenní minimum: {stock_info.get('fiftyTwoWeekLow', 'N/A')} Kč")
        ])
    except:
        stock_info_div = html.P("Nelze načíst detailní informace o akcii")
    
    return fig1, stock_info_div, fig2, fig3

# Spuštění aplikace
if __name__ == '__main__':
    app.run_server(debug=True)
```

```python
import panel as pn
import hvplot.pandas
import pandas as pd
import numpy as np
import yfinance as yf
from datetime import datetime, timedelta

# Povolení rozšíření
pn.extension()

# Vytvoření widgetů
stock_picker = pn.widgets.Select(

time_period = pn.widgets.Select(

    },

)

# Funkce pro získání dat o akciích
def get_stock_data(ticker, period):
    end_date = datetime.now()
    
    if period == '1mo':
        start_date = end_date - timedelta(days=30)
    elif period == '3mo':
        start_date = end_date - timedelta(days=90)
    elif period == '6mo':
        start_date = end_date - timedelta(days=180)
    elif period == '1y':
        start_date = end_date - timedelta(days=365)
    else:  # 5y
        start_date = end_date - timedelta(days=1825)
    
    # Použití yfinance k získání dat
    stock_data = yf.download(ticker, start=start_date, end=end_date)
    
    # Výpočet klouzavých průměrů
    stock_data['MA20'] = stock_data['Close'].rolling(window=20).mean()
    stock_data['MA50'] = stock_data['Close'].rolling(window=50).mean()
    
    return stock_data

# Vytvoření interaktivních grafů
@pn.depends(stock_picker, time_period)
def create_stock_plot(ticker, period):
    stock_data = get_stock_data(ticker, period)
    
    return stock_data.hvplot.line(
        y='Close',
        title=f'{ticker} Cena akcie',
        height=400,
        width=700
    ).opts(
        ylabel='Cena (Kč)',
        xlabel='Datum',
        legend_position='top_left'
    )

@pn.depends(stock_picker, time_period)
def create_ma_plot(ticker, period):
    stock_data = get_stock_data(ticker, period)
    
    return stock_data.hvplot.line(
        y=['Close', 'MA20', 'MA50'],
        title='Klouzavé průměry',
        height=300,
        width=600,
        legend='top_left'
    ).opts(
        ylabel='Cena (Kč)',
        xlabel='Datum'
    )

@pn.depends(stock_picker, time_period)
def create_volume_plot(ticker, period):
    stock_data = get_stock_data(ticker, period)
    
    return stock_data.hvplot.bar(
        y='Volume',
        title='Obchodní objem',
        height=300,
        width=600
    ).opts(
        ylabel='Objem',
        xlabel='Datum'
    )

@pn.depends(stock_picker)
def get_stock_info(ticker):
    try:
        stock_info = yf.Ticker(ticker).info
        current_price = stock_info.get('currentPrice', 'N/A')
        previous_close = stock_info.get('previousClose', 'N/A')
        
        if isinstance(current_price, (int, float)) and isinstance(previous_close, (int, float)):
            price_change = current_price - previous_close
            price_change_percent = (price_change / previous_close) * 100
            change_text = f"{price_change:.2f} ({price_change_percent:.2f}%)"
            change_color = 'green' if price_change >= 0 else 'red'
        else:
            change_text = "N/A"
            change_color = 'black'
            
        market_cap = stock_info.get('marketCap', 'N/A')
        if isinstance(market_cap, (int, float)):
            market_cap = f"{market_cap/1000000000:.2f} mld. Kč"
            
        return pn.Column(
            pn.pane.Markdown(f"## Informace o {ticker}"),
            pn.pane.Markdown(f"**Aktuální cena:** {current_price} Kč"),
            pn.pane.Markdown(f"**Změna:** <span style='color:{change_color}'>{change_text}</span>", allow_markup=True),
            pn.pane.Markdown(f"**Tržní kapitalizace:** {market_cap}"),
            pn.pane.Markdown(f"**52týdenní maximum:** {stock_info.get('fiftyTwoWeekHigh', 'N/A')} Kč"),
            pn.pane.Markdown(f"**52týdenní minimum:** {stock_info.get('fiftyTwoWeekLow', 'N/A')} Kč")
        )
    except:
        return pn.pane.Markdown("Nelze načíst detailní informace o akcii")

# Vytvoření dashboardu
dashboard = pn.Column(
    pn.pane.Markdown('# Dashboard akcií'),
    pn.Row(stock_picker, time_period),
    pn.Row(
        pn.Column(create_stock_plot),
        pn.Column(get_stock_info)
    ),
    pn.Row(
        pn.Column(create_ma_plot),
        pn.Column(create_volume_plot)
    )
)

# Zobrazení dashboardu
dashboard.servable()
```

## Shrnutí

Dashboardy jsou mocnými nástroji pro interaktivní vizualizaci dat a Python nabízí výborné knihovny jako Dash a Panel pro jejich vytváření. Zde je shrnutí toho, co jsme probrali:

- **Dash** je komplexní framework postavený na Reactu, Flasku a Plotly, ideální pro vytváření složitých webových aplikací s rozsáhlými možnostmi přizpůsobení. Používá systém callbacků pro interaktivitu a dobře spolupracuje s vizualizačními nástroji Plotly.

- **Panel** je vysokoúrovňová knihovna, která se zaměřuje na jednoduchost a integraci s ekosystémem datové vědy v Pythonu. Bezproblémově funguje s různými vizualizačními knihovnami a je obzvláště užitečný pro vytváření dashboardů v Jupyter noteboocích.

- Oba frameworky vám umožňují vytvářet interaktivní komponenty jako posuvníky, rozbalovací seznamy a tlačítka, které mohou v reálném čase aktualizovat vizualizace na základě vstupů uživatele.

- Při výběru mezi nimi zvažte své specifické potřeby: Dash nabízí více funkcí pro webový vývoj a detailnější kontrolu, zatímco Panel poskytuje více pythonický přístup s rychlejším vývojovým časem.

- Mezi osvědčené postupy pro návrh dashboardů patří pochopení vašeho publika, optimalizace výkonu, implementace správného zpracování chyb a udržování čistého, intuitivního rozhraní.

Zvládnutím těchto nástrojů můžete přeměnit statické vizualizace dat na dynamické, interaktivní zážitky, které uživatelům umožňují efektivněji prozkoumávat data a objevovat poznatky.

Ať už vytváříte dashboardy pro business intelligence, datovou analýzu nebo vědecký výzkum, Dash i Panel nabízejí mocné schopnosti, které vaše data oživí.
