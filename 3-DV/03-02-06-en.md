# Dashboards with Dash or Panel

## Introduction

Dashboards are powerful tools for presenting data in an interactive and visually appealing way. They allow users to explore data through multiple visualizations, filters, and controls within a single interface. Python offers several excellent libraries for creating dashboards, with Dash and Panel being two of the most popular choices.

Dash, developed by Plotly, is a productive Python framework for building web applications with highly customized user interfaces in pure Python. Panel, on the other hand, is part of the HoloViz ecosystem and allows you to create custom interactive web apps and dashboards by connecting user-defined widgets to plots, images, tables, or text.

In this guide, we'll explore both frameworks, learn how to build interactive dashboards, and understand when to use each one.

## Creating a Simple Dash Dashboard

Let's build a simple dashboard that visualizes some data:

```python
import dash
from dash import dcc, html
import plotly.express as px
import pandas as pd

# Create sample data
df = pd.DataFrame({
    "Fruit": ["Apples", "Oranges", "Bananas", "Apples", "Oranges", "Bananas"],
    "Amount": [4, 1, 2, 2, 4, 5],
    "City": ["SF", "SF", "SF", "NYC", "MTL", "NYC"]
})

# Initialize the app
app = dash.Dash(__name__)

# Create a bar chart
fig = px.bar(df, x="Fruit", y="Amount", color="City", barmode="group")

# Define the layout
app.layout = html.Div([
    html.H1('Simple Fruit Dashboard'),
    html.Div([
        html.Label('Select a City:'),
        dcc.Dropdown(
            id='city-dropdown',
            options=[{'label': city, 'value': city} for city in df['City'].unique()],
            value='All',
            clearable=False
        ),
    ]),
    dcc.Graph(id='fruit-graph', figure=fig)
])

# Run the app
if __name__ == '__main__':
    app.run_server(debug=True)
```

## Dash Callbacks for Interactivity

Callbacks in Dash enable interactivity by connecting components together:

```python
from dash import Dash, dcc, html, Input, Output, callback
import plotly.express as px
import pandas as pd

# Create sample data
df = pd.DataFrame({
    "Fruit": ["Apples", "Oranges", "Bananas", "Apples", "Oranges", "Bananas"],
    "Amount": [4, 1, 2, 2, 4, 5],
    "City": ["SF", "SF", "SF", "NYC", "MTL", "NYC"]
})

# Initialize the app
app = Dash(__name__)

# Define the layout
app.layout = html.Div([
    html.H1('Interactive Fruit Dashboard'),
    html.Div([
        html.Label('Select a City:'),
        dcc.Dropdown(
            id='city-dropdown',
            options=[{'label': 'All', 'value': 'All'}] + 
                    [{'label': city, 'value': city} for city in df['City'].unique()],
            value='All',
            clearable=False
        ),
    ]),
    dcc.Graph(id='fruit-graph')
])

# Define callback to update graph based on dropdown selection
@callback(
    Output('fruit-graph', 'figure'),
    Input('city-dropdown', 'value')
)
def update_graph(selected_city):
    if selected_city == 'All':
        filtered_df = df
    else:
        filtered_df = df[df['City'] == selected_city]
    
    fig = px.bar(filtered_df, x="Fruit", y="Amount", color="City", barmode="group")
    return fig

# Run the app
if __name__ == '__main__':
    app.run_server(debug=True)
```

## Introduction to Panel

Panel is a high-level app and dashboarding solution for Python that lets you connect widgets to plots, tables, or text. It works with multiple visualization libraries and can be deployed as standalone apps or embedded in Jupyter notebooks.

### Panel Components and Widgets

Panel provides a wide range of widgets and components:

```python
import panel as pn
import numpy as np
import hvplot.pandas

    '# Panel Widgets Demo',

    select,

    date_picker
)
```

## Building a Panel Dashboard

Let's create a simple Panel dashboard:

```python
import panel as pn
import hvplot.pandas
import pandas as pd
import numpy as np

# Enable extension
pn.extension()

# Generate sample data
dates = pd.date_range('2020-01-01', periods=100)
df = pd.DataFrame({
    'date': dates,
    'value1': np.random.randn(100).cumsum(),
    'value2': np.random.randn(100).cumsum(),
    'category': np.random.choice(['A', 'B', 'C'], 100)
})

# Create widgets
category_select = pn.widgets.MultiSelect(
    name='Category',
    options=list(df['category'].unique()),
    value=['A', 'B'],
    size=3
)

date_range = pn.widgets.DateRangeSlider(
    name='Date Range',
    start=dates.min(),
    end=dates.max(),
    value=(dates.min(), dates.max())
)

# Define a function to create plots based on widget values
def create_plots(categories, date_range):
    filtered_df = df[
        (df['category'].isin(categories)) & 
        (df['date'] >= date_range[0]) & 
        (df['date'] <= date_range[1])
    ]
    
    line_plot = filtered_df.hvplot.line(
        x='date', y=['value1', 'value2'], 
        title='Line Plot', height=300, width=700
    )
    
    scatter_plot = filtered_df.hvplot.scatter(
        x='value1', y='value2', by='category',
        title='Scatter Plot', height=300, width=700
    )
    
    return pn.Column(line_plot, scatter_plot)

# Link the widgets to the plots
dashboard = pn.Column(
    '# Interactive Data Dashboard',
    pn.Row(
        pn.Column('## Filters', category_select, date_range),
        pn.panel(
            pn.bind(create_plots, categories=category_select, date_range=date_range)
        )
    )
)

# Show the dashboard
dashboard
```

## Panel Interactivity

Panel allows you to create interactive applications using reactive functions and widgets:

```python
import panel as pn
import numpy as np
import holoviews as hv
import hvplot.pandas
import pandas as pd

pn.extension()

# Create sample data
x = np.linspace(0, 10, 200)
y = np.sin(x)
df = pd.DataFrame({'x': x, 'y': y})

# Create interactive widgets
amplitude = pn.widgets.FloatSlider(name='Amplitude', start=0.1, end=2, step=0.1, value=1)
frequency = pn.widgets.FloatSlider(name='Frequency', start=0.1, end=2, step=0.1, value=1)
phase = pn.widgets.FloatSlider(name='Phase Shift', start=0, end=np.pi*2, step=0.1, value=0)

# Define a function that updates the plot based on widget values
@pn.depends(amplitude=amplitude, frequency=frequency, phase=phase)
def sine_plot(amplitude, frequency, phase):
    y_values = amplitude * np.sin(frequency * x + phase)
    df = pd.DataFrame({'x': x, 'y': y_values})
    return df.hvplot.line(x='x', y='y', height=400, width=700, 
                          title='Interactive Sine Wave')

# Create the dashboard
dashboard = pn.Column(
    '# Interactive Sine Wave Explorer',
    pn.Row(
        pn.Column('## Parameters', amplitude, frequency, phase),
        sine_plot
    )
)

dashboard
```

## Comparison: Dash vs Panel

### Dash Advantages:
- Built on top of React.js, offering a large ecosystem of components
- Detailed documentation and extensive community
- Strong integration with Plotly's visualization libraries
- More suitable for complex web applications

### Panel Advantages:
- Easier to learn and use for data scientists
- Seamless integration with Jupyter notebooks
- Works well with many visualization libraries (Matplotlib, Plotly, Bokeh, HoloViews)
- Better for rapid prototyping

## Real-World Dashboard Example

Let's create a more complex dashboard that analyzes and visualizes stock data:

```python
import dash
from dash import dcc, html
from dash.dependencies import Input, Output
import plotly.express as px
import plotly.graph_objects as go
import pandas as pd
import numpy as np
import yfinance as yf
from datetime import datetime, timedelta

# Initialize the app
app = dash.Dash(__name__, external_stylesheets=['https://codepen.io/chriddyp/pen/bWLwgP.css'])

# Define the app layout
app.layout = html.Div([
    html.H1("Stock Dashboard"),
    
    html.Div([
        html.Div([
            html.Label("Select Stock:"),
            dcc.Dropdown(
                id='stock-picker',
                options=[
                    {'label': 'Apple (AAPL)', 'value': 'AAPL'},
                    {'label': 'Microsoft (MSFT)', 'value': 'MSFT'},
                    {'label': 'Google (GOOGL)', 'value': 'GOOGL'},
                    {'label': 'Amazon (AMZN)', 'value': 'AMZN'},
                    {'label': 'Tesla (TSLA)', 'value': 'TSLA'}
                ],
                value='AAPL'
            )
        ], className="six columns"),
        
        html.Div([
            html.Label("Select Time Period:"),
            dcc.Dropdown(
                id='time-period',
                options=[
                    {'label': '1 Month', 'value': '1mo'},
                    {'label': '3 Months', 'value': '3mo'},
                    {'label': '6 Months', 'value': '6mo'},
                    {'label': '1 Year', 'value': '1y'},
                    {'label': '5 Years', 'value': '5y'}
                ],
                value='6mo'
            )
        ], className="six columns"),
    ], className="row"),
    
    html.Div([
        html.Div([
            dcc.Graph(id='stock-graph')
        ], className="eight columns"),
        
        html.Div([
            html.H4("Stock Information"),
            html.Div(id='stock-info')
        ], className="four columns"),
    ], className="row"),
    
    html.Div([
        html.Div([
            html.H4("Moving Averages"),
            dcc.Graph(id='ma-graph')
        ], className="six columns"),
        
        html.Div([
            html.H4("Trading Volume"),
            dcc.Graph(id='volume-graph')
        ], className="six columns"),
    ], className="row"),
])

@app.callback(
    [Output('stock-graph', 'figure'),
     Output('stock-info', 'children'),
     Output('ma-graph', 'figure'),
     Output('volume-graph', 'figure')],
    [Input('stock-picker', 'value'),
     Input('time-period', 'value')]
)
def update_dashboard(ticker, period):
    # Get stock data
    end_date = datetime.now()
    
    if period == '1mo':
        start_date = end_date - timedelta(days=30)
    elif period == '3mo':
        start_date = end_date - timedelta(days=90)
    elif period == '6mo':
        start_date = end_date - timedelta(days=180)
    elif period == '1y':
        start_date = end_date - timedelta(days=365)
    else:  # 5y
        start_date = end_date - timedelta(days=1825)
    
    # Use yfinance to get data
    stock_data = yf.download(ticker, start=start_date, end=end_date)
    
    # Calculate moving averages
    stock_data['MA20'] = stock_data['Close'].rolling(window=20).mean()
    stock_data['MA50'] = stock_data['Close'].rolling(window=50).mean()
    
    # Create main stock graph
    fig1 = go.Figure()
    fig1.add_trace(go.Candlestick(
        x=stock_data.index,
        open=stock_data['Open'],
        high=stock_data['High'],
        low=stock_data['Low'],
        close=stock_data['Close'],
        name='Candlestick'
    ))
    fig1.update_layout(
        title=f'{ticker} Stock Price',
        xaxis_title='Date',
        yaxis_title='Price ($)',
        height=500
    )
    
    # Create moving averages graph
    fig2 = go.Figure()
    fig2.add_trace(go.Scatter(
        x=stock_data.index, 
        y=stock_data['Close'],
        mode='lines',
        name='Close'
    ))
    fig2.add_trace(go.Scatter(
        x=stock_data.index, 
        y=stock_data['MA20'],
        mode='lines',
        name='20-day MA',
        line=dict(color='orange')
    ))
    fig2.add_trace(go.Scatter(
        x=stock_data.index, 
        y=stock_data['MA50'],
        mode='lines',
        name='50-day MA',
        line=dict(color='green')
    ))
    fig2.update_layout(
        title='Moving Averages',
        xaxis_title='Date',
        yaxis_title='Price ($)',
        height=400
    )
    
    # Create volume graph
    fig3 = go.Figure()
    fig3.add_trace(go.Bar(
        x=stock_data.index,
        y=stock_data['Volume'],
        name='Volume'
    ))
    fig3.update_layout(
        title='Trading Volume',
        xaxis_title='Date',
        yaxis_title='Volume',
        height=400
    )
    
    # Get current stock info
    try:
        stock_info = yf.Ticker(ticker).info
        current_price = stock_info.get('currentPrice', stock_data['Close'].iloc[-1])
        previous_close = stock_info.get('previousClose', stock_data['Close'].iloc[-2])
        market_cap = stock_info.get('marketCap', 'N/A')
        if isinstance(market_cap, (int, float)):
            market_cap = f"${market_cap/1000000000:.2f}B"
        
        price_change = current_price - previous_close
        price_change_percent = (price_change / previous_close) * 100
        
        stock_info_div = html.Div([
            html.P(f"Current Price: ${current_price:.2f}"),
            html.P([
                "Change: ",
                html.Span(
                    f"{price_change:.2f} ({price_change_percent:.2f}%)",
                    style={'color': 'green' if price_change >= 0 else 'red'}
                )
            ]),
            html.P(f"Market Cap: {market_cap}"),
            html.P(f"52-Week High: ${stock_info.get('fiftyTwoWeekHigh', 'N/A')}"),
            html.P(f"52-Week Low: ${stock_info.get('fiftyTwoWeekLow', 'N/A')}")
        ])
    except:
        stock_info_div = html.P("Unable to fetch detailed stock information")
    
    return fig1, stock_info_div, fig2, fig3

# Run the app
if __name__ == '__main__':
    app.run_server(debug=True)
```

Let's see the equivalent in Panel:

```python
import panel as pn
import hvplot.pandas
import pandas as pd
import numpy as np
import yfinance as yf
from datetime import datetime, timedelta

# Enable the extension
pn.extension()

# Create widgets
stock_picker = pn.widgets.Select(
    name='Select Stock',
    options={
        'Apple (AAPL)': 'AAPL',
        'Microsoft (MSFT)': 'MSFT',
        'Google (GOOGL)': 'GOOGL',
        'Amazon (AMZN)': 'AMZN',
        'Tesla (TSLA)': 'TSLA'
    },
    value='AAPL'
)

time_period = pn.widgets.Select(
    name='Select Time Period',
    options={
        '1 Month': '1mo',
        '3 Months': '3mo',
        '6 Months': '6mo',
        '1 Year': '1y',
        '5 Years': '5y'
    },
    value='6mo'
)

# Function to get stock data
def get_stock_data(ticker, period):
    end_date = datetime.now()
    
    if period == '1mo':
        start_date = end_date - timedelta(days=30)
    elif period == '3mo':
        start_date = end_date - timedelta(days=90)
    elif period == '6mo':
        start_date = end_date - timedelta(days=180)
    elif period == '1y':
        start_date = end_date - timedelta(days=365)
    else:  # 5y
        start_date = end_date - timedelta(days=1825)
    
    # Use yfinance to get data
    stock_data = yf.download(ticker, start=start_date, end=end_date)
    
    # Calculate moving averages
    stock_data['MA20'] = stock_data['Close'].rolling(window=20).mean()
    stock_data['MA50'] = stock_data['Close'].rolling(window=50).mean()
    
    return stock_data

# Create interactive plots
@pn.depends(stock_picker, time_period)
def create_stock_plot(ticker, period):
    stock_data = get_stock_data(ticker, period)
    
    return stock_data.hvplot.line(
        y='Close',
        title=f'{ticker} Stock Price',
        height=400,
        width=700
    ).opts(
        ylabel='Price ($)',
        xlabel='Date',
        legend_position='top_left'
    )

@pn.depends(stock_picker, time_period)
def create_ma_plot(ticker, period):
    stock_data = get_stock_data(ticker, period)
    
    return stock_data.hvplot.line(
        y=['Close', 'MA20', 'MA50'],
        title='Moving Averages',
        height=300,
        width=600,
        legend='top_left'
    ).opts(
        ylabel='Price ($)',
        xlabel='Date'
    )

@pn.depends(stock_picker, time_period)
def create_volume_plot(ticker, period):
    stock_data = get_stock_data(ticker, period)
    
    return stock_data.hvplot.bar(
        y='Volume',
        title='Trading Volume',
        height=300,
        width=600
    ).opts(
        ylabel='Volume',
        xlabel='Date'
    )

@pn.depends(stock_picker)
def get_stock_info(ticker):
    try:
        stock_info = yf.Ticker(ticker).info
        current_price = stock_info.get('currentPrice', 'N/A')
        previous_close = stock_info.get('previousClose', 'N/A')
        
        if isinstance(current_price, (int, float)) and isinstance(previous_close, (int, float)):
            price_change = current_price - previous_close
            price_change_percent = (price_change / previous_close) * 100
            change_text = f"{price_change:.2f} ({price_change_percent:.2f}%)"
            change_color = 'green' if price_change >= 0 else 'red'
        else:
            change_text = "N/A"
            change_color = 'black'
            
        market_cap = stock_info.get('marketCap', 'N/A')
        if isinstance(market_cap, (int, float)):
            market_cap = f"${market_cap/1000000000:.2f}B"
            
        return pn.Column(
            pn.pane.Markdown(f"## {ticker} Information"),
            pn.pane.Markdown(f"**Current Price:** ${current_price}"),
            pn.pane.Markdown(f"**Change:** <span style='color:{change_color}'>{change_text}</span>", allow_markup=True),
            pn.pane.Markdown(f"**Market Cap:** {market_cap}"),
            pn.pane.Markdown(f"**52-Week High:** ${stock_info.get('fiftyTwoWeekHigh', 'N/A')}"),
            pn.pane.Markdown(f"**52-Week Low:** ${stock_info.get('fiftyTwoWeekLow', 'N/A')}")
        )
    except:
        return pn.pane.Markdown("Unable to fetch detailed stock information")

# Create the dashboard
dashboard = pn.Column(
    pn.pane.Markdown('# Stock Dashboard'),
    pn.Row(stock_picker, time_period),
    pn.Row(
        pn.Column(create_stock_plot),
        pn.Column(get_stock_info)
    ),
    pn.Row(
        pn.Column(create_ma_plot),
        pn.Column(create_volume_plot)
    )
)

# Show the dashboard
dashboard.servable()
```

## Best Practices

1. **Understand Your Audience**: Design dashboards with the end user in mind.
2. **Focus on User Experience**: Make interactions intuitive and responsive.
3. **Prioritize Performance**: Optimize data processing and rendering to reduce load times.
4. **Create Mobile-Responsive Layouts**: Ensure dashboards work well on various screen sizes.
5. **Use Consistent Styling**: Maintain a coherent design language across components.
6. **Implement Proper Error Handling**: Provide helpful feedback when things go wrong.
7. **Document Your Code**: Write clear documentation for maintenance and collaboration.
8. **Use Caching When Appropriate**: Cache expensive computations to improve performance.
9. **Test Thoroughly**: Ensure the dashboard functions correctly in different scenarios.
10. **Keep It Simple**: Avoid cluttering the interface with too many elements.

## Summary

Dashboards are powerful tools for interactive data visualization, and Python offers excellent libraries like Dash and Panel to create them. Here's a summary of what we've covered:

- **Dash** is a comprehensive framework built on React, Flask, and Plotly, ideal for creating complex web applications with extensive customization options. It uses a callback system for interactivity and works well with Plotly's visualization tools.

- **Panel** is a high-level library that focuses on simplicity and integration with the Python data science ecosystem. It seamlessly works with various visualization libraries and is particularly useful for creating dashboards in Jupyter notebooks.

- Both frameworks allow you to create interactive components like sliders, dropdowns, and buttons that can update visualizations in real-time based on user input.

- When choosing between them, consider your specific needs: Dash offers more web development features and fine-grained control, while Panel provides a more Pythonic approach with faster development time.

- Dashboard design best practices include understanding your audience, optimizing performance, implementing proper error handling, and maintaining a clean, intuitive interface.

By mastering these tools, you can transform static data visualizations into dynamic, interactive experiences that allow users to explore data and discover insights more effectively.

Whether you're building dashboards for business intelligence, data analysis, or scientific research, both Dash and Panel offer powerful capabilities to bring your data to life.
