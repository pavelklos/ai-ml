# Tree Maps and Sunburst Charts

## Introduction

Hierarchical data appears in many domains - from file systems and organizational structures to taxonomies and nested categories. Effectively visualizing such data requires specialized chart types that can represent both the hierarchical relationships and quantitative values simultaneously. Two powerful techniques for this purpose are tree maps and sunburst charts, both of which transform hierarchical data into intuitive, space-efficient visualizations.

This guide explores how to create, customize, and implement tree maps and sunburst charts in Python, helping you unlock new ways to visualize complex nested data structures.

## Understanding Hierarchical Data Visualization

Hierarchical data consists of items that are organized in a tree-like structure with parent-child relationships. Examples include:

- File systems (folders and subfolders)
- Organizational charts
- Taxonomic classifications
- Website navigation structures
- Budget allocations

Visualizing hierarchical data needs to address two key challenges:
1. Representing the parent-child relationships clearly
2. Displaying quantitative values associated with each element

Tree maps and sunburst charts solve these challenges through different approaches, each with its own strengths.

## Tree Maps

Tree maps display hierarchical data as nested rectangles. Each branch of the hierarchy is represented by a rectangle, which is then tiled with smaller rectangles representing sub-branches.

### Key Concepts

- **Size**: The area of each rectangle typically represents a quantitative value
- **Color**: Often used to represent another data dimension or category
- **Nesting**: Parent-child relationships are shown through rectangle containment
- **Space efficiency**: Utilizes nearly 100% of the available space

### When to Use Tree Maps

Tree maps are particularly effective when:
- Space is limited and you need to display many categories
- The primary focus is comparing sizes across the hierarchy
- The data has multiple levels of hierarchy but not too deep (2-3 levels work best)
- You want to emphasize the largest categories at a glance

## Sunburst Charts

Sunburst charts (also known as ring charts or multi-level pie charts) display hierarchical data in a radial layout. The hierarchy starts from the center with the root node and extends outward with deeper levels.

### Key Concepts

- **Rings**: Each ring represents a level in the hierarchy
- **Segments**: Slices within each ring represent items at that level
- **Size**: The arc length (or angle) represents the value proportion
- **Color**: Often used to distinguish categories or represent a data dimension
- **Radial layout**: Emphasizes the hierarchical structure from center outward

### When to Use Sunburst Charts

Sunburst charts are particularly effective when:
- Showing the hierarchical structure is the primary goal
- The data has multiple levels (they can handle more depth than tree maps)
- You want to emphasize the path from root to leaf nodes
- The circular layout fits your design aesthetic

## Comparing Tree Maps and Sunburst Charts

| Feature | Tree Maps | Sunburst Charts |
|---------|----------|-----------------|
| Space efficiency | Very high | Medium |
| Depth representation | Limited (2-3 levels work best) | Better for deeper hierarchies |
| Size comparison | Easier to compare rectangles | Harder to compare segments across levels |
| Path visualization | Less intuitive | More intuitive from center outward |
| Layout | Rectangular | Radial |
| Learning curve | Moderate | Moderate to high |

## Creating Tree Maps in Python

There are several libraries for creating tree maps in Python. We'll explore three popular options: Squarify with Matplotlib, Plotly, and Seaborn.


### Interactive Tree Map with Drilling Down

```python

# Create sample data for sales across regions
regions = {

            'Monterrey': 290000
        }
    },
    'Europe': {
        'Germany': {
            'Berlin': 720000,
            'Munich': 680000,
            'Frankfurt': 490000
        },
        'UK': {
            'London': 1120000,
            'Manchester': 480000
        },
        'France': {
            'Paris': 980000,
            'Lyon': 420000
        }
    },
    'Asia': {
        'China': {
            'Beijing': 1450000,
            'Shanghai': 1650000,
            'Shenzhen': 980000
        },
        'Japan': {
            'Tokyo': 1380000,
            'Osaka': 820000
        },
        'India': {
            'Mumbai': 780000,
            'Delhi': 690000
        }
    }
}

# Function to flatten the hierarchical data
def flatten_dict(d, parent_key='', sep='.'):
    items = []
    for k, v in d.items():
        new_key = f"{parent_key}{sep}{k}" if parent_key else k
        if isinstance(v, dict):
            items.extend(flatten_dict(v, new_key, sep=sep).items())
        else:
            items.append((new_key, v))
    return dict(items)

# Flatten the data
flat_data = flatten_dict(regions)

# Create lists for labels, parents, values
labels = []
parents = []
values = []

for path, value in flat_data.items():
    parts = path.split('.')
    label = parts[-1]
    parent = parts[-2] if len(parts) > 1 else ""
    
    labels.append(label)
    parents.append(parent)
    values.append(value)

# Add the top-level categories with empty parents
for region in regions.keys():
    if region not in labels:
        labels.append(region)
        parents.append("")
        values.append(sum(regions[region].values()))

# Create the treemap
fig = go.Figure(go.Treemap(
    labels=labels,
    parents=parents,
    values=values,
    branchvalues="total",
    marker=dict(
        colorscale='Viridis',
        showscale=True
    ),
    hovertemplate='<b>%{label}</b><br>Sales: $%{value:,.0f}<extra></extra>',
    texttemplate='%{label}<br>$%{value:,.0f}',
))

fig.update_layout(
    title='Global Sales by Region',
    margin=dict(t=50, l=25, r=25, b=25),
    font=dict(size=14),
)

fig.show()
```

## Best Practices

When creating tree maps and sunburst charts, consider these best practices:

1. **Keep hierarchies manageable**: 
   - Tree maps work best with 2-3 levels
   - Sunburst charts can handle more levels but become harder to interpret beyond 4-5 levels

2. **Use color effectively**:
   - Use color to represent a meaningful dimension, not just for aesthetics
   - Ensure sufficient contrast between adjacent segments
   - Consider colorblind-friendly palettes

3. **Size appropriately**:
   - Ensure the smallest segments are still visible and interpretable
   - Consider filtering out very small values or grouping them into an "Other" category

4. **Add interactivity for exploration**:
   - Enable drilling down into segments
   - Provide tooltips with detailed information
   - Add filters or controls to show different aspects of the data

5. **Clear labeling**:
   - Ensure labels are readable and not overcrowded
   - Consider showing labels only for larger segments
   - Use hover information for detailed data

6. **Choose the right chart type**:
   - Tree maps are better for comparing sizes across categories
   - Sunburst charts better highlight the hierarchical structure
   - Consider showing both for complex datasets

7. **Create consistent visual hierarchies**:
   - Use consistent color schemes across hierarchy levels
   - Make parent-child relationships visually obvious

8. **Add context**:
   - Include titles, descriptions, and legends
   - Add annotations for important insights

## Summary

Tree maps and sunburst charts are powerful visualization tools for hierarchical data, each with unique strengths and applications:

**Tree Maps:**
- Transform hierarchical data into nested rectangles where area represents quantity
- Excel at efficient space utilization and size comparisons
- Work best for visualizing 2-3 levels of hierarchy
- Particularly effective for financial data, portfolio analysis, and space allocation

**Sunburst Charts:**
- Display hierarchical data in a radial layout with concentric rings representing hierarchy levels
- Clearly visualize the hierarchical structure and parent-child relationships
- Can effectively show deeper hierarchies (4-5 levels)
- Excellent for file systems, organizational structures, and navigation paths

Both visualization types can be enhanced through:
- Interactive features like drilling down and tooltips
- Strategic use of color to represent additional data dimensions
- Thoughtful labeling and annotation
- Appropriate filtering to maintain clarity

Python offers excellent libraries for creating these visualizations, with Plotly providing the most comprehensive and interactive implementation for both chart types. For simpler static tree maps, the squarify package with Matplotlib offers a lightweight alternative.

When deciding between tree maps and sunburst charts, consider whether quantitative comparison (favoring tree maps) or hierarchical structure visualization (favoring sunburst charts) is your primary goal. For complex data storytelling, combining both visualization types can provide complementary perspectives on your hierarchical data.
