## 1. Introduction to Seaborn and Its Purpose

Seaborn is a Python data visualization library based on matplotlib that provides a high-level interface for drawing attractive and informative statistical graphics. It's specifically designed to make statistical visualization easier and more aesthetically pleasing.

Key features of Seaborn:
- Built on top of Matplotlib with tight integration to pandas
- Focused on statistical exploration and visualization
- Provides beautiful default styles and color palettes
- Specialized for visualizing relationships in datasets
- Simplifies creating complex visualizations with fewer lines of code

```python
# Import essential libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Check Seaborn version
print(f"Seaborn version: {sns.__version__}")

# Set a seed for reproducibility
np.random.seed(42)

# Create sample data
data = pd.DataFrame({
    'x': np.random.normal(0, 1, 100),
    'y': np.random.normal(0, 1, 100),
    'category': np.random.choice(['A', 'B', 'C', 'D'], 100)
})

# Display the first few rows of our data
print(data.head())
```

## 3. Comparison with Matplotlib

While Matplotlib offers highly customizable plotting capabilities, Seaborn provides a higher-level abstraction that makes it easier to create common statistical plots.

```python
# Create sample data
x = np.linspace(0, 10, 100)
y = np.sin(x)
data = pd.DataFrame({'x': x, 'y': y, 
                     'category': ['A' if i < 50 else 'B' for i in range(100)]})

# Create two subplots
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(15, 5))

# Matplotlib approach
ax1.scatter(data['x'][:50], data['y'][:50], color='blue', label='A')
ax1.scatter(data['x'][50:], data['y'][50:], color='red', label='B')
ax1.set_title('Matplotlib Scatter Plot')
ax1.set_xlabel('X Value')
ax1.set_ylabel('Y Value')
ax1.legend()
ax1.grid(True, alpha=0.3)

# Seaborn approach
sns.scatterplot(data=data, x='x', y='y', hue='category', ax=ax2)
ax2.set_title('Seaborn Scatter Plot')
plt.tight_layout()
plt.show()

# Another comparison: Creating histograms
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(15, 5))

# Matplotlib histogram
ax1.hist(data['y'], bins=20, alpha=0.7)
ax1.set_title('Matplotlib Histogram')
ax1.set_xlabel('Value')
ax1.set_ylabel('Frequency')

# Seaborn histogram
sns.histplot(data['y'], bins=20, kde=True, ax=ax2)
ax2.set_title('Seaborn Histogram with KDE')
plt.tight_layout()
plt.show()
```

Key differences:
- **Seaborn**: More concise syntax, built-in statistical awareness, aesthetically pleasing defaults
- **Matplotlib**: More flexibility, lower-level control, steeper learning curve

## 4. Basic Plotting with Seaborn

Seaborn offers a variety of plot types for different visualization needs:

```python
# Create a dataset with multiple variables
tips = sns.load_dataset('tips')
print(tips.head())

# Create a figure with subplots
fig, axes = plt.subplots(2, 2, figsize=(16, 12))

# 1. Scatter plot
sns.scatterplot(
    data=tips,
    x='total_bill',
    y='tip',
    hue='sex',
    size='size',
    sizes=(20, 200),
    ax=axes[0, 0]
)
axes[0, 0].set_title('Scatter Plot: Tips vs. Total Bill')

# 2. Line plot
# Generate some time series data
dates = pd.date_range('2023-01-01', periods=30)
time_data = pd.DataFrame({
    'date': dates,
    'value': np.cumsum(np.random.randn(30)),
    'type': ['A' if i < 15 else 'B' for i in range(30)]
})

sns.lineplot(
    data=time_data,
    x='date',
    y='value',
    hue='type',
    markers=True,
    ax=axes[0, 1]
)
axes[0, 1].set_title('Line Plot: Time Series Data')
axes[0, 1].tick_params(axis='x', rotation=45)

# 3. Bar plot
sns.barplot(
    data=tips,
    x='day',
    y='total_bill',
    hue='sex',
    errorbar=('ci', 95),
    ax=axes[1, 0]
)
axes[1, 0].set_title('Bar Plot: Average Bill by Day')

# 4. Count plot
sns.countplot(
    data=tips,
    x='day',
    hue='time',
    ax=axes[1, 1]
)
axes[1, 1].set_title('Count Plot: Number of Visits by Day')

plt.tight_layout()
plt.show()
```

Basic plot types in Seaborn:
- **scatterplot()**: Show relationship between two variables
- **lineplot()**: Show trends over a continuous variable
- **barplot()**: Show point estimates and confidence intervals
- **countplot()**: Show counts of observations in categorical bins

## 5. Statistical Visualizations

Seaborn excels at creating statistical visualizations that help understand data distributions and relationships:

```python
# Create sample datasets
np.random.seed(42)
df = pd.DataFrame({
    'group': np.repeat(['A', 'B', 'C', 'D'], 50),
    'value1': np.random.normal(0, 1, 200),
    'value2': np.random.normal(5, 1.5, 200)
})
df.loc[df['group'] == 'B', 'value1'] += 2
df.loc[df['group'] == 'C', 'value1'] += 4
df.loc[df['group'] == 'D', 'value1'] += 6

# Create a figure with subplots
fig, axes = plt.subplots(2, 2, figsize=(16, 12))

# 1. Distribution Plot (KDE and Histogram)
sns.histplot(
    data=df,
    x='value1',
    hue='group',
    kde=True,
    ax=axes[0, 0]
)
axes[0, 0].set_title('Distribution Plot with KDE')

# 2. Box Plot
sns.boxplot(
    data=df,
    x='group',
    y='value1',
    ax=axes[0, 1]
)
axes[0, 1].set_title('Box Plot by Group')

# 3. Violin Plot
sns.violinplot(
    data=df,
    x='group',
    y='value1',
    ax=axes[1, 0]
)
axes[1, 0].set_title('Violin Plot by Group')

# 4. Joint Plot (in a separate figure)
plt.figure(figsize=(8, 8))
g = sns.jointplot(
    data=df,
    x='value1',
    y='value2',
    kind='scatter',
    hue='group',
    height=8
)
g.fig.suptitle('Joint Plot of Value1 vs Value2', y=1.02)

plt.tight_layout()
plt.show()

# 5. Pair Plot (in a separate figure)
sns.pairplot(
    data=df,
    hue='group',
    vars=['value1', 'value2']
)
plt.suptitle('Pair Plot of All Numeric Variables', y=1.02)
plt.show()
```

Key statistical plots:
- **histplot()**: Histogram and KDE for univariate distributions
- **boxplot()**: Show distribution with quartiles and outliers
- **violinplot()**: Combines box plot with KDE
- **jointplot()**: Show bivariate relationship with marginal distributions
- **pairplot()**: Plot pairwise relationships in a dataset

## 6. Customizing Seaborn Plots

Seaborn plots can be customized to meet specific visualization needs:

```python
# Create sample data
np.random.seed(42)
data = pd.DataFrame({
    'x': np.random.normal(0, 1, 100),
    'y': np.random.normal(0, 1, 100),
    'category': np.random.choice(['Group A', 'Group B', 'Group C'], 100)
})

# Basic plot
plt.figure(figsize=(12, 6))
basic = sns.scatterplot(
    data=data,
    x='x',
    y='y',
    hue='category'
)
basic.set_title('Basic Scatter Plot')
plt.tight_layout()
plt.show()

# Customized plot with various options
plt.figure(figsize=(12, 6))
custom = sns.scatterplot(
    data=data,
    x='x',
    y='y',
    hue='category',
    s=100,  # Marker size
    alpha=0.7,  # Transparency
    palette='viridis',  # Color palette
    style='category',  # Different marker styles
    edgecolor='black',  # Marker edge color
    linewidth=0.5  # Marker edge width
)

# Customize other aspects
custom.set_title('Customized Scatter Plot', fontsize=16, fontweight='bold')
custom.set_xlabel('X Variable', fontsize=12)
custom.set_ylabel('Y Variable', fontsize=12)
custom.grid(True, linestyle='--', alpha=0.7)
custom.legend(title='Groups', title_fontsize=12, fontsize=10, frameon=True, loc='best')

# Remove top and right spines for cleaner look
sns.despine()

plt.tight_layout()
plt.show()
```

Key customization options:
- **Colors and palettes**: Change color schemes with `palette` parameter
- **Marker styles**: Control point appearance with `style`, `s`, `edgecolor`
- **Transparency**: Adjust with `alpha` parameter
- **Titles and labels**: Use matplotlib's methods like `set_title()`
- **Grids and spines**: Customize with `grid()` and `despine()`
- **Legends**: Modify with parameters like `legend_out` or matplotlib methods

## 7. Seaborn Themes and Styles

Seaborn's themes and styles allow you to quickly change the overall appearance of plots:

```python
# Available styles
styles = ['darkgrid', 'whitegrid', 'dark', 'white', 'ticks']

# Create a simple dataset
x = np.linspace(0, 10, 100)
y = np.sin(x)
data = pd.DataFrame({'x': x, 'y': y})

# Create subplots to demonstrate styles
fig, axes = plt.subplots(len(styles), 1, figsize=(10, 15))

# Plot with different styles
for i, style in enumerate(styles):
    sns.set_style(style)
    sns.lineplot(data=data, x='x', y='y', ax=axes[i])
    axes[i].set_title(f"Style: {style}")
    axes[i].set_ylabel('sin(x)')

plt.tight_layout()
plt.show()

# Reset to default style
sns.set_style('whitegrid')

# Context presets (paper, notebook, talk, poster)
contexts = ['paper', 'notebook', 'talk', 'poster']
fig, axes = plt.subplots(len(contexts), 1, figsize=(10, 15))

for i, context in enumerate(contexts):
    sns.set_context(context)
    sns.lineplot(data=data, x='x', y='y', ax=axes[i])
    axes[i].set_title(f"Context: {context}")

plt.tight_layout()
plt.show()

# Custom theme with set_theme()
sns.set_theme(
    style="darkgrid",
    context="notebook",
    palette="muted",
    font_scale=1.2,
    rc={"lines.linewidth": 2.5}
)

plt.figure(figsize=(10, 6))
sns.lineplot(data=data, x='x', y='y')
plt.title('Custom Theme')
plt.show()
```

Key aspects of Seaborn themes and styles:
- **Styles**: Control background, grid, and spines ('darkgrid', 'whitegrid', 'dark', 'white', 'ticks')
- **Contexts**: Control scaling of plot elements for different outputs ('paper', 'notebook', 'talk', 'poster')
- **Palettes**: Built-in color schemes ('deep', 'muted', 'pastel', 'bright', 'dark', 'colorblind')
- **Font scaling**: Adjust all text elements at once with `font_scale`
- **RC Parameters**: Fine-tune specific matplotlib parameters with `rc`

## 8. Working with DataFrames

Seaborn is designed to work seamlessly with pandas DataFrames:

```python
# Load a real dataset
flights = sns.load_dataset('flights')
print("Sample of flights dataset:")
print(flights.head())

# Create a pivot table for easier visualization
flights_pivot = flights.pivot(index='month', columns='year', values='passengers')
print("\nPivoted data:")
print(flights_pivot.head())

# Create different visualizations from the same DataFrame
plt.figure(figsize=(14, 10))

# 1. Heatmap of passenger numbers by month and year
plt.subplot(2, 1, 1)
sns.heatmap(
    flights_pivot,
    cmap='YlGnBu',
    annot=True,
    fmt='d',
    linewidths=.5
)
plt.title('Passenger Numbers by Month and Year')

# 2. Line plot showing passenger trends over time
plt.subplot(2, 1, 2)
sns.lineplot(
    data=flights,
    x='year',
    y='passengers',
    hue='month',
    palette='viridis'
)
plt.title('Passenger Trends by Month Over Years')
plt.tight_layout()
plt.show()

# FacetGrid for creating multiple plots based on categories
g = sns.FacetGrid(flights, col="year", col_wrap=4, height=2.5, aspect=1.5)
g.map_dataframe(sns.lineplot, x="month", y="passengers")
g.set_titles(col_template="{col_name}")
g.set_axis_labels("Month", "Passengers")
g.add_legend()
plt.tight_layout()
plt.show()
```

Key benefits of using Seaborn with DataFrames:
- **Automatic variable mapping**: Seaborn understands DataFrame structure
- **Categorical handling**: Proper handling of categorical variables and ordering
- **Statistical awareness**: Built-in statistical calculations based on data
- **Faceting with FacetGrid**: Create multiple plots split by categories
- **Long-form vs Wide-form data**: Flexibility in handling different data formats

## 9. Complex Visualizations with Seaborn

Seaborn enables creating complex statistical visualizations with minimal code:

```python
# Load sample datasets
tips = sns.load_dataset('tips')
iris = sns.load_dataset('iris')
titanic = sns.load_dataset('titanic')

# 1. Pair Plot with diagonal KDE plots
sns.pairplot(
    iris, 
    hue='species', 
    diag_kind='kde',
    corner=True,
    plot_kws={'alpha': 0.6}
)
plt.suptitle('Iris Dataset Pairwise Relationships', y=1.02)
plt.show()

# 2. Complex Categorical Plot
plt.figure(figsize=(12, 8))
sns.catplot(
    data=titanic, 
    kind='bar',
    x='class', 
    y='survived',
    hue='sex',
    col='deck',
    height=4,
    aspect=.7
)
plt.suptitle('Survival Rates by Class, Sex, and Deck', y=1.02)
plt.tight_layout()
plt.show()

# 3. Heatmap with Annotations and Clustering
# Create a correlation matrix
corr = iris.drop('species', axis=1).corr()

plt.figure(figsize=(10, 8))
sns.clustermap(
    corr,
    annot=True,
    cmap='RdBu_r',
    vmin=-1, vmax=1,
    linewidths=.5,
    figsize=(8, 8)
)
plt.title('Clustered Correlation Heatmap', y=1.02)
plt.show()

# 4. Complex Joint Distribution Plot
sns.jointplot(
    data=tips,
    x='total_bill',
    y='tip',
    kind='reg',
    truncate=False,
    xlim=(0, None),
    color='m',
    height=8
).plot_joint(
    sns.kdeplot, 
    levels=5, 
    color="r"
)
plt.suptitle('Tips vs Total Bill with Regression and KDE', y=1.02)
plt.show()

# 5. Multiple Regression Lines with lmplot
sns.lmplot(
    data=tips,
    x='total_bill',
    y='tip',
    hue='smoker',
    col='time',
    row='sex',
    height=4,
    aspect=1.2
)
plt.suptitle('Tips Regression by Smoker, Time, and Sex', y=1.05)
plt.tight_layout()
plt.show()
```

Key complex visualizations:
- **pairplot()**: Matrix of pairwise relationships
- **catplot()**: Flexible categorical plots with faceting
- **clustermap()**: Hierarchically clustered heatmap
- **jointplot()**: Bivariate plot with marginal distributions
- **lmplot()**: Regression plot with faceting
