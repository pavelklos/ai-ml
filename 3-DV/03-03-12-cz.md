## Úvod

Přístupnost v datové vizualizaci se týká navrhování vizuálních reprezentací dat, které mohou být vnímány, pochopeny a používány lidmi s různými schopnostmi a potřebami. Vytváření přístupných vizualizací není jen právním nebo etickým požadavkem—je to zásadní pro efektivní komunikaci s celým vaším publikem. Když vizualizace vylučují určité uživatele, dochází ke ztrátě kritických informací a rozhodnutí mohou být činěna bez úplného kontextu.

Tato příručka se zaměřuje na to, jak vytvářet přístupné datové vizualizace pomocí Pythonu, poskytuje praktické techniky, ukázky kódu a osvědčené postupy pro zajištění inkluzivity vašich vizualizací pro všechny uživatele.

## Porozumění potřebám přístupnosti

Různí uživatelé se setkávají s různými překážkami při konzumaci datových vizualizací:

- **Zrakové postižení**: Zahrnuje slepotu, slabý zrak a poruchy barvocitu
- **Kognitivní omezení**: Ovlivňující zpracování informací, paměť nebo pozornost
- **Motorické postižení**: Omezující schopnost interakce s vizualizacemi
- **Neurologické rozdíly**: Jako je fotosenzitivita nebo citlivost na pohyb

### Použití nástrojů pro simulaci barvosleposti

```python
from matplotlib.colors import LinearSegmentedColormap
import matplotlib.colors as mcolors
from matplotlib import cm
import numpy as np

# Funkce pro simulaci různých typů barvosleposti
def simulate_colorblindness(data, cmap, type='deuteranopia'):
    """
    Simuluje barvoslepost pro danou barevnou mapu
    Typy: 'deuteranopia', 'protanopia', 'tritanopia'
    """
    from colorspacious import cspace_converter
    
    cmaps = {
        'original': cmap,
        'deuteranopia': None,
        'protanopia': None,
        'tritanopia': None
    }
    
    # Generování vzorových dat
    x = np.linspace(0, 1, 256)
    y = np.linspace(0, 1, 2)
    X, Y = np.meshgrid(x, y)
    
    # Zobrazení v různých barevných prostorech
    for name, cm_type in cmaps.items():
        if name == 'original':
            rgb = cm.get_cmap(cmap)(x)[np.newaxis, :, :3]
        else:
            rgb = cm.get_cmap(cmap)(x)[np.newaxis, :, :3]
            convert = cspace_converter("sRGB1", f"sRGB1+{name}")
            rgb = convert(rgb)
            
        cmaps[name] = rgb
    
    return cmaps

# Příklad použití funkce
data = np.random.rand(10, 10)
colorblind_simulation = simulate_colorblindness(data, 'viridis')

# Zobrazení výsledků
fig, axes = plt.subplots(4, 1, figsize=(10, 8))
labels = ['Originál', 'Deuteranopie', 'Protanopie', 'Tritanopie']
cmaps = ['original', 'deuteranopia', 'protanopia', 'tritanopia']

for i, (label, cmap_name) in enumerate(zip(labels, cmaps)):
    if i == 0:
        axes[i].imshow(colorblind_simulation[cmap_name], aspect='auto')
    else:
        # Pro simulaci, zobrazujeme jen originál
        axes[i].imshow(colorblind_simulation['original'], aspect='auto')
        axes[i].set_title(f"Simulace {label}")
    axes[i].set_yticks([])
    
plt.tight_layout()
plt.show()
```

### Datové tabulky vedle vizualizací

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.gridspec import GridSpec

# Vytvoření vzorových dat
np.random.seed(42)
years = range(2018, 2023)
sales_data = {
    'Rok': list(years),
    'Příjmy': np.random.randint(100, 200, len(years)),
    'Výdaje': np.random.randint(50, 100, len(years)),
    'Zisk': []
}

# Výpočet zisku
for i in range(len(years)):
    sales_data['Zisk'].append(sales_data['Příjmy'][i] - sales_data['Výdaje'][i])

# Převod na DataFrame
df = pd.DataFrame(sales_data)

# Vytvoření obrázku s vizualizací i tabulkou
fig = plt.figure(figsize=(12, 8))
gs = GridSpec(2, 1, height_ratios=[2, 1])

# Vykreslení dat
ax0 = fig.add_subplot(gs[0])
ax0.plot(df['Rok'], df['Příjmy'], 'o-', label='Příjmy', linewidth=2)
ax0.plot(df['Rok'], df['Výdaje'], 's-', label='Výdaje', linewidth=2)
ax0.plot(df['Rok'], df['Zisk'], '^-', label='Zisk', linewidth=2)
ax0.set_title('Finanční výkonnost (2018-2022)', fontsize=16)
ax0.set_xlabel('Rok', fontsize=14)
ax0.set_ylabel('Částka (v tisících Kč)', fontsize=14)
ax0.grid(True, linestyle='--', alpha=0.7)
ax0.legend(fontsize=12)

# Vytvoření tabulky
ax1 = fig.add_subplot(gs[1])
ax1.axis('tight')
ax1.axis('off')
table = ax1.table(cellText=df.values, colLabels=df.columns, loc='center',
                 cellLoc='center', colColours=['#f2f2f2']*4)
table.auto_set_font_size(False)
table.set_fontsize(12)
table.scale(1, 1.5)

plt.tight_layout()
plt.show()
```

### Textová shrnutí a postřehy

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Generování vzorových dat
np.random.seed(42)
months = ['Led', 'Únor', 'Břez', 'Dub', 'Květ', 'Čer']
sales = np.random.randint(50, 100, len(months))
costs = np.random.randint(30, 70, len(months))
profit = sales - costs

# Vytvoření vizualizace
fig, ax = plt.subplots(figsize=(10, 8))
width = 0.35
x = np.arange(len(months))
ax.bar(x - width/2, sales, width, label='Prodeje')
ax.bar(x + width/2, costs, width, label='Náklady')
ax.plot(x, profit, 'ro-', linewidth=2, label='Zisk')

# Přidání popisků a legendy
ax.set_title('Měsíční prodeje, náklady a zisk', fontsize=16)
ax.set_xlabel('Měsíc', fontsize=14)
ax.set_ylabel('Částka (tisíce Kč)', fontsize=14)
ax.set_xticks(x)
ax.set_xticklabels(months)
ax.legend()

# Přidání textového shrnutí
total_sales = np.sum(sales)
total_costs = np.sum(costs)
total_profit = np.sum(profit)
best_month = months[np.argmax(profit)]
worst_month = months[np.argmin(profit)]

summary = f"""
Klíčové poznatky:
- Celkové prodeje: {total_sales} tis. Kč
- Celkové náklady: {total_costs} tis. Kč
- Celkový zisk: {total_profit} tis. Kč
- Nejlepší měsíc: {best_month} ({np.max(profit)} tis. Kč zisku)
- Nejhorší měsíc: {worst_month} ({np.min(profit)} tis. Kč zisku)
- Trend: Zisky {'rostou' if profit[-1] > profit[0] else 'klesají'} od začátku do konce období
"""

plt.figtext(0.5, -0.05, summary, ha='center', fontsize=12, 
           bbox={'facecolor':'lightgrey', 'alpha':0.5, 'pad':10})

plt.tight_layout()
plt.subplots_adjust(bottom=0.25)  # Vytvoření prostoru pro text
plt.show()
```

```python
import plotly.express as px
```

```python
df = pd.DataFrame({

        'xanchor': 'center'
    }

# Převod na HTML s atributy ARIA
chart_html = fig.to_html()

# Obalení dalšími prvky přístupnosti
accessible_html = f'''
<div role="figure" aria-labelledby="chart-title" aria-describedby="chart-desc">
  {chart_html}
  <p id="chart-title" class="visually-hidden">Ukázkový sloupcový graf</p>
  <p id="chart-desc" class="visually-hidden">
    Tento sloupcový graf zobrazuje hodnoty pro pět kategorií A až E.
    Kategorie A má hodnotu 23, B má 45, C má 56, D má 78 (nejvyšší) a E má 42.
  </p>
</div>
<style>
  .visually-hidden {{
    position: absolute;
    width: 1px;
    height: 1px;
    padding: 0;
    margin: -1px;
    overflow: hidden;
    clip: rect(0, 0, 0, 0);
    white-space: nowrap;
    border: 0;
  }}
</style>
'''

# Zobrazení přístupného HTML
HTML(accessible_html)

# Kód pro uložení HTML do souboru
```

```python
import matplotlib.pyplot as plt
import numpy as np
```

```python
from matplotlib.colors import LinearSegmentedColormap

# Funkce pro simulaci poruchy barvocitu
def simulate_cvd(rgb, cvd_type="deuteranomaly", severity=1.0):
    """
    Simulace poruchy barvocitu
    
    Parametry:
    -----------
    rgb : ndarray, tvar (n, 3)
        RGB hodnoty barev, které mají být převedeny
    cvd_type : string
        Typ poruchy barvocitu pro simulaci.
        Jeden z "protanomaly", "deuteranomaly", nebo "tritanomaly"
    severity : float
        Závažnost poruchy barvocitu, od 0.0 do 1.0
    
    Vrací:
    --------
    cvd_rgb : ndarray, tvar (n, 3)
        RGB hodnoty barev, jak by je vnímal
        pozorovatel se specifikovanou poruchou barvocitu
    """
    cvd_space = f"sRGB1+{cvd_type}({severity})"
    convert = cspace_converter("sRGB1", cvd_space)
    return convert(rgb)
```

```python
def evaluate_visualization_accessibility(fig=None):
    """
    Funkce pro hodnocení přístupnosti matplotlib figury
    Vrací kontrolní seznam s detekovanými problémy
    """
    if fig is None:
        fig = plt.gcf()
        
    issues = []
    recommendations = []
    
    # Kontrola titulku
    if not fig._suptitle:
        issues.append("Chybí titulek")
        recommendations.append("Přidejte popisný titulek k vaší vizualizaci")
    
    # Kontrola popisků os pro všechny dílčí grafy
    for ax in fig.axes:
        if not ax.get_xlabel():
            issues.append("Chybí popisek osy X")
            recommendations.append("Přidejte popisky osy X ke všem grafům")
        if not ax.get_ylabel():
            issues.append("Chybí popisek osy Y")
            recommendations.append("Přidejte popisky osy Y ke všem grafům")
    
    # Kontrola legendy, pokud existuje více datových řad
    for ax in fig.axes:
        lines = ax.get_lines()
        if len(lines) > 1:
            if not ax.get_legend():
                issues.append("Více datových řad bez legendy")
                recommendations.append("Přidejte legendu při zobrazení více datových řad")
    
    # Kontrola problémů s barevnou mapou
    for ax in fig.axes:
        for collection in ax.collections:
            if hasattr(collection, 'get_cmap'):
                cmap = collection.get_cmap()
                if cmap is not None:
                    cmap_name = cmap.name if hasattr(cmap, 'name') else str(cmap)
                    problematic_cmaps = ['jet', 'rainbow', 'spectral', 'RdYlGn', 'RdYlBu']
                    if any(p_cmap in cmap_name for p_cmap in problematic_cmaps):
                        issues.append(f"Používání problematické barevné mapy: {cmap_name}")
                        recommendations.append("Nahraďte percepčně jednotnou barevnou mapou jako 'viridis', 'cividis', nebo 'plasma'")
    
    # Kontrola velikosti písma
    small_font = False
    for ax in fig.axes:
        if ax.title.get_fontsize() < 12:
            small_font = True
        for label in ax.get_xticklabels() + ax.get_yticklabels():
            if label.get_fontsize() < 10:
                small_font = True
    
    if small_font:
        issues.append("Zjištěna malá velikost písma")
        recommendations.append("Použijte větší velikost písma (12+ pro titulky, 10+ pro popisky)")
    
    # Vrácení výsledků
    if not issues:
        print("✅ Nebyly nalezeny žádné problémy s přístupností!")
    else:
        print(f"⚠️ Nalezeno {len(issues)} potenciálních problémů s přístupností:")
        for i, (issue, rec) in enumerate(zip(issues, recommendations)):
            print(f"{i+1}. {issue}")
            print(f"   Doporučení: {rec}")
    
    return {
        'issues': issues,
        'recommendations': recommendations,
        'passed': len(issues) == 0
    }

# Ukázka použití
plt.figure(figsize=(10, 6))
# Vytvoření grafu s problémy přístupnosti
plt.plot([1, 2, 3], [4, 5, 6], 'r-')
plt.plot([1, 2, 3], [6, 5, 4], 'b-')
# Bez titulku, bez popisků, bez legendy
plt.xticks(fontsize=8)  # Malé písmo
plt.yticks(fontsize=8)  # Malé písmo

# Vyhodnocení vizualizace
results = evaluate_visualization_accessibility()

# Oprava problémů
if not results['passed']:
    plt.title('Opravená vizualizace', fontsize=16)
    plt.xlabel('Popisek osy X', fontsize=14)
    plt.ylabel('Popisek osy Y', fontsize=14)
    plt.legend(['Řada 1', 'Řada 2'], fontsize=12)
    plt.xticks(fontsize=12)
    plt.yticks(fontsize=12)
    
    # Kontrola znovu
    print("\nPo opravách:")
    evaluate_visualization_accessibility()

plt.tight_layout()
plt.show()
```

## Shrnutí a kontrolní seznam

Vytváření přístupných datových vizualizací je nezbytné pro efektivní komunikaci informací všem uživatelům bez ohledu na jejich schopnosti. Dodržováním technik a principů uvedených v této příručce můžete zajistit, že vaše vizualizace budou inkluzivní a použitelné pro každého.

### Kontrolní seznam klíčových aspektů přístupnosti

- **Použití barev**
  - [ ] Používejte palety přátelské k barvoslepým (viridis, cividis atd.)
  - [ ] Vyhněte se kombinacím červené a zelené barvy
  - [ ] Udržujte dostatečný kontrast mezi prvky
  - [ ] Nespoléhejte pouze na barvy pro přenos informací

- **Text a popisky**
  - [ ] Používejte adekvátní velikosti písma (12 bodů+ pro hlavní text, 16 bodů+ pro nadpisy)
  - [ ] Přidávejte jasné popisky os a titulky
  - [ ] Přidávejte popisné legendy, kde je potřeba
  - [ ] Zajistěte vysoký kontrast pro všechny textové prvky

- **Alternativní reprezentace**
  - [ ] Přidávejte datové tabulky vedle vizualizací
  - [ ] Poskytujte textová shrnutí klíčových poznatků
  - [ ] Používejte více vizuálních kódování (tvary, velikosti, vzory)
  - [ ] Zpřístupněte data v alternativních formátech

- **Struktura a organizace**
  - [ ] Udržujte čistý a nepřeplněný design
  - [ ] Používejte konzistentní rozvržení a vzory
  - [ ] Logicky seskupujte související informace
  - [ ] Poskytněte jasnou hierarchii informací

- **Interaktivní přístupnost**
  - [ ] Zajistěte funkční navigaci klávesnicí pro interaktivní prvky
  - [ ] Přidávejte ARIA popisky a popisy
  - [ ] Podporujte čtečky obrazovky správnou strukturou HTML
  - [ ] Poskytujte popisky a informace při najetí myší

Dodržováním těchto principů zpřístupníte své vizualizace širšímu publiku, zlepšíte obecnou použitelnost pro všechny uživatele a zajistíte, že vaše datové poznatky budou sdíleny spravedlivě. Pamatujte, že přístupnost není dodatečnou funkcí nebo speciální vlastností – měla by být integrována do procesu tvorby vizualizací od samého začátku.
