## 1. Úvod do etiky vizualizace dat

Etika v datové vizualizaci se týká odpovědné tvorby a prezentace vizuálních reprezentací dat. S rostoucím významem datových vizualizací v rozhodovacích procesech, zpravodajství a veřejné diskuzi roste také důležitost etických dopadů způsobu, jakým tyto vizualizace vytváříme a sdílíme. Etika vizualizace zahrnuje poctivost, transparentnost, spravedlnost a přístupnost ve způsobu, jakým data vizuálně reprezentujeme.

Nastavme si prostředí s nezbytnými knihovnami:

```python
# Import nezbytných knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from matplotlib.colors import LinearSegmentedColormap
import matplotlib.ticker as ticker

# Nastavení vizuálního stylu
plt.style.use('seaborn-v0_8-whitegrid')

# Pro reprodukovatelnost
np.random.seed(42)
```

## 2. Síla a odpovědnost datové vizualizace

Datové vizualizace jsou mocnými komunikačními nástroji. Mohou zjednodušit složité informace, zvýraznit vzory a ovlivnit rozhodnutí. Tato síla však přináší i odpovědnost. Vizualizace mohou stejně snadno zavádět jako informovat, ať už úmyslně nebo neúmyslně.

```python
# Příklad: Stejná data, různé vizuální interpretace

# Vygenerování vzorových prodejních dat
months = pd.date_range(start='2022-01-01', periods=12, freq='M')
sales = np.array([45, 47, 52, 51, 48, 55, 59, 62, 65, 63, 68, 72])
data = pd.DataFrame({'date': months, 'sales': sales})

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Vizualizace 1: Plný rozsah osy y od 0
axes[0].plot(data['date'], data['sales'], marker='o', linewidth=2, color='blue')
axes[0].set_ylim(0, 100)
axes[0].set_title('Trend prodejů (Plná škála)', fontsize=14)
axes[0].set_ylabel('Prodeje (jednotky)', fontsize=12)
axes[0].set_xlabel('Měsíc', fontsize=12)
axes[0].grid(True, alpha=0.3)

# Vizualizace 2: Oříznutá osa y
axes[1].plot(data['date'], data['sales'], marker='o', linewidth=2, color='red')
axes[1].set_ylim(40, 75)  # Oříznutá osa y
axes[1].set_title('Trend prodejů (Oříznutá škála)', fontsize=14)
axes[1].set_ylabel('Prodeje (jednotky)', fontsize=12)
axes[1].set_xlabel('Měsíc', fontsize=12)
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

print("Povšimněte si, jak oříznutá stupnice dělá nárůst prodejů dramatičtějším,")
print("přestože obě vizualizace ukazují přesně stejná data.")
```

## 3. Běžné etické problémy v datové vizualizaci

Několik běžných praktik může vést k etickým problémům v datové vizualizaci:

1. **Zavádějící škály a osy**: Ořezávání os nebo používání nevhodných měřítek
2. **Selektivní výběr dat**: Selektivní prezentování dat podporujících předem určený narativ
3. **Nevhodné použití vizuálních prvků**: Používání 3D, plošných nebo jiných efektů, které zkreslují vnímání
4. **Nedostatek kontextu**: Prezentování dat bez nezbytného kontextu pro interpretaci
5. **Nepřístupné volby designu**: Používání barev nebo designu, které vylučují určité publikum

```python
# Příklad potenciálně zavádějících typů grafů
# 3D koláčový graf - často kritizovaný za zkreslování proporcí

data = [35, 25, 20, 20]
labels = ['Kategorie A', 'Kategorie B', 'Kategorie C', 'Kategorie D']

fig = plt.figure(figsize=(12, 5))

# Standardní koláčový graf
ax1 = fig.add_subplot(121)
ax1.pie(data, labels=labels, autopct='%1.1f%%', startangle=90)
ax1.set_title('Standardní koláčový graf', fontsize=14)

# 3D koláčový graf
ax2 = fig.add_subplot(122, projection='3d')
# Výpočet pozic a velikostí výsečí
theta = np.linspace(0, 2*np.pi, len(data), endpoint=False)
width = np.pi / 4 * np.ones(len(data))
colors = plt.cm.viridis(np.linspace(0, 1, len(data)))

# Vytvoření výsečí
for th, w, d, c, l in zip(theta, width, data, colors, labels):
    size = d / sum(data)
    ax2.bar(x=[th], height=[size], width=w, zs=0, zdir='y', color=c, alpha=0.8)

ax2.set_title('3D koláčový graf (Může být zavádějící)', fontsize=14)
ax2.set_xticks([])
ax2.set_yticks([])
ax2.set_zticks([])

plt.tight_layout()
plt.show()

print("3D koláčové grafy mohou zkreslit vnímání proporcí a ztížit")
print("přesné porovnávání. Standardní koláčový graf je jasnější.")
```

## 4. Zavádějící osy a měřítka

Jedním z nejběžnějších etických problémů v datové vizualizaci je manipulace s osami a měřítky. Ořezávání osy y nebo používání nevhodných měřítek může dramaticky změnit to, jak diváci vnímají trendy, rozdíly a vzorce.

```python
# Příklad: Ukázka různých voleb osy y

# Vygenerování příkladu dat cen akcií
dates = pd.date_range(start='2023-01-01', periods=30, freq='D')
price = 100 + np.cumsum(np.random.normal(0.1, 1, 30))
stock_data = pd.DataFrame({'date': dates, 'price': price})

fig, axes = plt.subplots(2, 1, figsize=(10, 8))

# Standardní měřítko s nulovou základnou (vhodnější pro ceny akcií)
axes[0].plot(stock_data['date'], stock_data['price'], 'g-', linewidth=2)
axes[0].set_ylabel('Cena akcie (Kč)', fontsize=12)
axes[0].set_title('Cena akcie s plným rozsahem osy Y', fontsize=14)
axes[0].set_ylim(0, max(stock_data['price']) * 1.1)
axes[0].grid(True, alpha=0.3)

# Oříznutá osa y (může přehánět změny)
axes[1].plot(stock_data['date'], stock_data['price'], 'r-', linewidth=2)
axes[1].set_ylabel('Cena akcie (Kč)', fontsize=12)
axes[1].set_title('Cena akcie s oříznutou osou Y (Může být zavádějící)', fontsize=14)
min_price = min(stock_data['price']) * 0.95
max_price = max(stock_data['price']) * 1.05
axes[1].set_ylim(min_price, max_price)
axes[1].grid(True, alpha=0.3)

# Přidání kontextové anotace
for ax in axes:
    # Výpočet procentuální změny
    pct_change = (stock_data['price'].iloc[-1] - stock_data['price'].iloc[0]) / stock_data['price'].iloc[0] * 100
    ax.annotate(f'Celková změna: {pct_change:.1f}%', 
                xy=(0.02, 0.95), xycoords='axes fraction',
                fontsize=12, ha='left', va='top',
                bbox=dict(boxstyle='round,pad=0.5', fc='yellow', alpha=0.3))

plt.tight_layout()
plt.show()

# Etičtější přístup: Ukázat oba pohledy, ale s jasnými popisky
fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(stock_data['date'], stock_data['price'], 'b-', linewidth=2)
ax.set_ylabel('Cena akcie (Kč)', fontsize=12)
ax.set_title('Cena akcie s kontextovými informacemi', fontsize=14)

# Zvolit vhodné měřítko založené na kontextu dat
# Pro akcie je často důležité ukázat variace, ale měly by být označeny
ax.set_ylim(min_price, max_price)

# Přidání jasně viditelné poznámky o oříznuté ose
ax.text(0.5, 0.01, 
        "Poznámka: Osa Y nezačíná nulou, aby byly vidět cenové variace",
        transform=ax.transAxes, ha='center', va='bottom',
        bbox=dict(boxstyle='round,pad=0.5', fc='white', ec='gray', alpha=0.8),
        fontsize=10)

ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

## 5. Selektivní výběr a vyloučení dat

Selektivní prezentace dat, známá také jako "cherry-picking", zahrnuje zvýrazňování pouze částí dat, které podporují určitý narativ, a zároveň vynechávání relevantních protikladů nebo kontextu.

```python
# Příklad: Selektivní výběr časových období pro zobrazení různých trendů

# Vygenerování příkladu dat teplot s sezónními vzory
years = np.arange(1970, 2023)
# Základní trend oteplování
baseline_temp = 14.0
warming_trend = 0.03 * (years - 1970)
# Přidání náhodných variací
noise = np.random.normal(0, 0.3, len(years))
# Vytvoření dat o teplotě s trendem oteplování a šumem
temperatures = baseline_temp + warming_trend + noise

climate_data = pd.DataFrame({
    'year': years,
    'temperature': temperatures
})

fig, axes = plt.subplots(2, 1, figsize=(12, 8))

# Selektivně vybraný krátký časový úsek (2015-2018) ukazující ochlazování
cherry_picked = climate_data[(climate_data['year'] >= 2015) & (climate_data['year'] <= 2018)]
axes[0].plot(cherry_picked['year'], cherry_picked['temperature'], 'b-o', linewidth=2)
axes[0].set_title('Selektivně vybraná data: "Globální ochlazování" (2015-2018)', fontsize=14)
axes[0].set_ylabel('Teplota (°C)', fontsize=12)
axes[0].grid(True, alpha=0.3)

# Přidání trendové čáry pro vybraná data
z = np.polyfit(cherry_picked['year'], cherry_picked['temperature'], 1)
p = np.poly1d(z)
axes[0].plot(cherry_picked['year'], p(cherry_picked['year']), "r--", alpha=0.7)
axes[0].annotate(f'Trend: {z[0]:.3f}°C/rok', xy=(2016, p(2016)+0.1), 
                fontsize=10, color='r')

# Kompletní datový soubor ukazující skutečný trend oteplování
axes[1].plot(climate_data['year'], climate_data['temperature'], 'g-', linewidth=2, alpha=0.7)
axes[1].scatter(climate_data['year'], climate_data['temperature'], s=20, alpha=0.7)
axes[1].set_title('Kompletní data: Dlouhodobý trend oteplování (1970-2022)', fontsize=14)
axes[1].set_ylabel('Teplota (°C)', fontsize=12)
axes[1].set_xlabel('Rok', fontsize=12)
axes[1].grid(True, alpha=0.3)

# Přidání trendové čáry pro celý datový soubor
z_full = np.polyfit(climate_data['year'], climate_data['temperature'], 1)
p_full = np.poly1d(z_full)
axes[1].plot(climate_data['year'], p_full(climate_data['year']), "r--", alpha=0.7)
axes[1].annotate(f'Trend: {z_full[0]:.3f}°C/rok', xy=(1990, p_full(1990)+0.2), 
                fontsize=10, color='r')

# Zvýraznění selektivně vybraného období v celém datovém souboru
axes[1].axvspan(2015, 2018, alpha=0.2, color='blue')
axes[1].annotate('Selektivně\nvybrané období', xy=(2016.5, min(climate_data['temperature'])),
                ha='center', fontsize=10, color='blue')

plt.tight_layout()
plt.show()

print("Všimněte si, jak výběr pouze krátkého časového období může zkreslit celkový trend.")
print(f"Selektivně vybraný trend (2015-2018): {z[0]:.3f}°C/rok")
print(f"Skutečný dlouhodobý trend (1970-2022): {z_full[0]:.3f}°C/rok")
```

## 6. Volba barev a přístupnost

Volby barev v datové vizualizaci mohou významně ovlivnit interpretaci a přístupnost. Etická vizualizace zahrnuje výběr barev, které jsou:

1. Perceptuálně přesné pro daný typ dat
2. Přístupné pro lidi s poruchami barevného vidění
3. Kulturně neutrální, kde je to vhodné

```python
# Příklad: Ukázka problémů s přístupností barev

# Vygenerování vzorových dat
categories = ['A', 'B', 'C', 'D', 'E']
values = [23, 45, 56, 78, 91]

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 1. Problematické: Červeno-zelené barevné schéma (obtížné pro barvoslepé diváky)
axes[0, 0].bar(categories, values, color=['darkgreen', 'forestgreen', 'limegreen', 'red', 'darkred'])
axes[0, 0].set_title('Problematické: Červeno-zelené barevné schéma', fontsize=14)
axes[0, 0].set_ylabel('Hodnota', fontsize=12)
axes[0, 0].grid(True, alpha=0.3, axis='y')

# 2. Lepší: Barevná paleta přívětivá pro barvoslepé
axes[0, 1].bar(categories, values, color=sns.color_palette("colorblind", 5))
axes[0, 1].set_title('Lepší: Paleta přívětivá pro barvoslepé', fontsize=14)
axes[0, 1].set_ylabel('Hodnota', fontsize=12)
axes[0, 1].grid(True, alpha=0.3, axis='y')

# 3. Problematické: Duhová barevná mapa (perceptuálně nejednotná)
rainbow = plt.cm.rainbow(np.linspace(0, 1, len(categories)))
axes[1, 0].bar(categories, values, color=rainbow)
axes[1, 0].set_title('Problematické: Duhová barevná mapa', fontsize=14)
axes[1, 0].set_ylabel('Hodnota', fontsize=12)
axes[1, 0].grid(True, alpha=0.3, axis='y')

# 4. Lepší: Perceptuálně jednotná barevná mapa
viridis = plt.cm.viridis(np.linspace(0, 1, len(categories)))
axes[1, 1].bar(categories, values, color=viridis)

axes[1, 1].set_ylabel('Hodnota', fontsize=12)

plt.show()
```

## 7. Zobrazení korelace versus kauzality

Běžným etickým problémem v datové vizualizaci je naznačování kauzality, když existuje pouze korelace. Vizualizace mohou jemně naznačovat příčinné vztahy, i když data podporují pouze korelaci.

```python
# Příklad: Korelace versus kauzalita

# Vygenerování korelovaných, ale příčinně nesouvisejících dat
np.random.seed(42)
years = np.arange(2000, 2020)
internet_users = 20 + 3.5 * (years - 2000) + np.random.normal(0, 2, len(years))
stork_population = 100 + 2 * (years - 2000) + np.random.normal(0, 5, len(years))
birth_rate = 12 - 0.15 * (years - 2000) + 0.01 * internet_users + np.random.normal(0, 0.4, len(years))

data = pd.DataFrame({
    'Year': years,
    'Internet_Users_Millions': internet_users,
    'Stork_Population_Thousands': stork_population,
    'Birth_Rate_Per_1000': birth_rate
})

# Graf, který by mohl naznačovat kauzalitu
fig, axes = plt.subplots(1, 2, figsize=(15, 6))

# Potenciálně zavádějící vizualizace naznačující kauzalitu
axes[0].scatter(data['Stork_Population_Thousands'], data['Birth_Rate_Per_1000'], 
              s=80, alpha=0.7, c=data['Year'], cmap='viridis')
axes[0].set_title('Zavádějící: "Čápi a porodnost"', fontsize=14)
axes[0].set_xlabel('Populace čápů (tisíce)', fontsize=12)
axes[0].set_ylabel('Porodnost (na 1000 obyvatel)', fontsize=12)
m, b = np.polyfit(data['Stork_Population_Thousands'], data['Birth_Rate_Per_1000'], 1)
axes[0].plot(data['Stork_Population_Thousands'], 
           m * data['Stork_Population_Thousands'] + b, 'r--')
r = np.corrcoef(data['Stork_Population_Thousands'], data['Birth_Rate_Per_1000'])[0, 1]
axes[0].text(0.05, 0.95, f"Korelace: {r:.2f}", transform=axes[0].transAxes,
           fontsize=12, va='top', 
           bbox=dict(boxstyle='round', facecolor='white', alpha=0.8))
axes[0].grid(True, alpha=0.3)

# Etičtější vizualizace ukazující zavádějící proměnnou
sns.scatterplot(
    x='Year', 
    y='value', 
    hue='variable',
    data=pd.melt(
        data[['Year', 'Stork_Population_Thousands', 'Birth_Rate_Per_1000']], 
        id_vars=['Year'],
        value_vars=['Stork_Population_Thousands', 'Birth_Rate_Per_1000']
    ),
    ax=axes[1],
    palette=['green', 'blue'],
    s=80
)
axes[1].set_title('Lepší: "Trendy v čase (zavádějící proměnná)"', fontsize=14)
axes[1].set_xlabel('Rok', fontsize=12)
axes[1].set_ylabel('Hodnota (škálovaná)', fontsize=12)
axes[1].text(0.05, 0.95, 
           "Obě proměnné se mění s časem\nale nejsou v příčinném vztahu", 
           transform=axes[1].transAxes,
           fontsize=12, va='top',
           bbox=dict(boxstyle='round', facecolor='white', alpha=0.8))
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

print("První graf by mohl vést diváky k domněnce, že čápi ovlivňují porodnost.")
print(f"Mají korelaci {r:.2f}, ale jde o falešnou korelaci.")
print("Druhý graf odhaluje, že obě proměnné se prostě mění v čase.")
```

## 8. Transparentnost v procesu vizualizace

Etická datová vizualizace vyžaduje transparentnost ohledně celého procesu vizualizace, včetně zdrojů dat, transformací a analytických rozhodnutí.

```python
# Příklad: Ukázka transparentnosti ve vizualizaci

# Vygenerování vzorových průzkumných dat s různými velikostmi vzorků
np.random.seed(42)

# Vytvoření dvou průzkumů s různými velikostmi vzorků a odchylkami
survey1_sample = 100
survey2_sample = 1000

# Vygenerování odpovědí (1 pro ano, 0 pro ne)
survey1_responses = np.random.binomial(1, 0.55, survey1_sample)
survey2_responses = np.random.binomial(1, 0.51, survey2_sample)

# Výpočet výsledků a standardních chyb
survey1_result = np.mean(survey1_responses) * 100  # převod na procenta
survey2_result = np.mean(survey2_responses) * 100

survey1_se = np.sqrt(survey1_result * (100 - survey1_result) / survey1_sample)
survey2_se = np.sqrt(survey2_result * (100 - survey2_result) / survey2_sample)

# 95% interval spolehlivosti (přibližně 2 standardní chyby)
survey1_margin = 1.96 * survey1_se
survey2_margin = 1.96 * survey2_se

# Vytvoření srovnávacích grafů
fig, axes = plt.subplots(1, 2, figsize=(15, 6))

# Méně transparentní vizualizace (vynechává velikost vzorku a chybovou marži)
surveys = ['Průzkum A', 'Průzkum B']
results = [survey1_result, survey2_result]

axes[0].bar(surveys, results, color=['blue', 'red'])
axes[0].set_ylim(40, 70)
axes[0].set_title('Méně transparentní: "Podpora návrhu X"', fontsize=14)
axes[0].set_ylabel('Podpora (%)', fontsize=12)
axes[0].grid(True, alpha=0.3, axis='y')

for i, v in enumerate(results):
    axes[0].text(i, v + 1, f"{v:.1f}%", ha='center', fontsize=12)

# Transparentnější vizualizace (zahrnuje velikost vzorku a odchylku)
axes[1].bar(surveys, results, color=['blue', 'red'], yerr=[survey1_margin, survey2_margin],
          capsize=10, alpha=0.7)
axes[1].set_ylim(40, 70)
axes[1].set_title('Transparentnější: "Podpora návrhu X s odchylkami"', fontsize=14)
axes[1].set_ylabel('Podpora (%)', fontsize=12)
axes[1].grid(True, alpha=0.3, axis='y')

# Přidání anotací pro velikosti vzorků a odchylky
for i, (v, m, n) in enumerate(zip(results, [survey1_margin, survey2_margin], 
                                [survey1_sample, survey2_sample])):
    axes[1].text(i, v - 10, f"n = {n}", ha='center', fontsize=11)
    axes[1].text(i, v + 3, f"{v:.1f}% ± {m:.1f}%", ha='center', fontsize=11)

plt.tight_layout()
plt.show()

print("Druhá vizualizace je etičtější, protože zahrnuje důležitý kontext:")
print(f"Průzkum A: {survey1_result:.1f}% ± {survey1_margin:.1f}% (n={survey1_sample})")
print(f"Průzkum B: {survey2_result:.1f}% ± {survey2_margin:.1f}% (n={survey2_sample})")
print("To ukazuje, že výsledky jsou v rámci odchylek a nemusí být významně odlišné.")
```

## 9. Osvědčené postupy etické vizualizace

Na základě etických principů, které jsme probrali, zde jsou některé osvědčené postupy pro vytváření etických vizualizací:

```python
# Příklad: Ukázka etických osvědčených postupů

# Vygenerování vzorových dat pro vizualizaci
np.random.seed(42)
years = np.arange(2010, 2023)
baseline = 100
values = baseline + np.cumsum(np.random.normal(2, 4, len(years)))
lower_ci = values - np.random.uniform(5, 10, len(years))
upper_ci = values + np.random.uniform(5, 10, len(years))

# Vytvoření komplexní etické vizualizace
fig, ax = plt.subplots(figsize=(12, 7))

# Vykreslení hlavní trendové čáry
ax.plot(years, values, 'b-', linewidth=2, label='Primární metrika')

# Přidání intervalů spolehlivosti pro nejistotu
ax.fill_between(years, lower_ci, upper_ci, color='blue', alpha=0.2, label='Interval spolehlivosti')

# Přidání datových bodů pro zobrazení skutečných měření
ax.scatter(years, values, s=60, color='blue', zorder=5)

# Zahrnutí kompletních os s nulovou základnou, kde je to vhodné
ax.set_ylim(0, max(upper_ci) * 1.1)
ax.grid(True, alpha=0.3)

# Poskytnutí jasných a informativních popisků
ax.set_title('Příklad etické vizualizace: Růst metriky v čase', fontsize=16)
ax.set_xlabel('Rok', fontsize=14)
ax.set_ylabel('Hodnota', fontsize=14)

# Přidání kontextu o zdrojích dat a metodologii
source_text = "Zdroj: Vzorová data (pro ukázku)\nMetodologie: Hodnoty zahrnují odhadované 95% intervaly spolehlivosti"
ax.text(0.01, 0.01, source_text, transform=ax.transAxes, fontsize=10, va='bottom',
       bbox=dict(boxstyle='round', facecolor='white', alpha=0.9))

# Přidání anotací pro důležité události nebo změny v metodologii
ax.annotate('Změna\nmetody', xy=(2015, values[years == 2015]), xytext=(2015, values[years == 2015]+20),
          arrowprops=dict(arrowstyle='->'), ha='center')

ax.annotate('Mezera v datech\n(Odhadnuto)', xy=(2019.5, np.mean([values[years == 2019], values[years == 2020]])),
          xytext=(2019.5, max(upper_ci) * 0.8),
          arrowprops=dict(arrowstyle='->'), ha='center')

# Přidání jasné legendy
ax.legend(loc='upper left', frameon=True)

# Použití barev přívětivých pro barvoslepé (již používáme modrou s různými průhlednostmi)

plt.tight_layout()
plt.show()

# Shrnutí etických osvědčených postupů
practices = [
    "1. Použití vhodných měřítek (zobrazení nulové základny pro sloupcové grafy)",
    "2. Reprezentování nejistoty (intervaly spolehlivosti, chybové úsečky)",
    "3. Poskytnutí kontextu (metodologie, zdroje dat)",
    "4. Volba přístupných barev (přívětivé pro barvoslepé)",
    "5. Jasné a úplné označení",
    "6. Označení mezer v datech nebo změn metodologie",
    "7. Vyhýbání se zavádějícím srovnáním",
    "8. Zahrnutí všech relevantních datových bodů",
    "9. Jasné a informativní legendy",
    "10. Zohlednění publika a jeho potřeb"
]

for practice in practices:
    print(practice)
```

## 10. Shrnutí

Etika v datové vizualizaci se týká poctivosti, jasnosti a odpovědnosti v tom, jak vizuálně reprezentujeme data. Hlavní poznatky zahrnují:

1. **Síla a odpovědnost**: Datové vizualizace významně ovlivňují vnímání a rozhodování, což vytváří etický závazek pro tvůrce vizualizací.

2. **Běžné etické problémy**:
   - Zavádějící měřítka a osy
   - Selektivní výběr dat
   - Naznačování kauzality z korelace
   - Problémy s přístupností barevných voleb
   - Nedostatek transparentnosti

3. **Osvědčené postupy**:
   - Používání vhodných měřítek a základních hodnot
   - Zobrazování nejistoty a kontextu
   - Zajištění přístupnosti prostřednictvím volby barev
   - Poskytování transparentnosti ohledně zdrojů dat a metod
   - Prezentování úplných dat bez selektivního výběru
   - Vyhýbání se naznačování kauzality, když existuje pouze korelace

4. **Praktická implementace**:
   - Zahrnutí nulových základen, kde je to vhodné
   - Zobrazení chybových úseček a intervalů spolehlivosti
   - Poskytnutí informací o zdrojích a poznámek k metodologii
   - Používání barevných palet přívětivých pro barvoslepé
   - Navrhování pro specifické potřeby vašeho publika

Vytváření etických vizualizací není jen o vyhýbání se klamání - jde o aktivní snahu zajistit, aby vaše publikum mohlo správně interpretovat a porozumět datům. Dodržováním etických postupů se datová vizualizace stává mocnějším a důvěryhodnějším nástrojem pro komunikaci, vhled a rozhodování.

Pamatujte, že etika vizualizace existuje na spektru - mnoho rozhodnutí zahrnuje kompromisy mezi různými principy. Cílem je činit záměrná, informovaná rozhodnutí, která upřednostňují poctivou a jasnou komunikaci skutečného příběhu dat.
