## 1. Introduction to Figure Size and Resolution

The size and resolution of your visualizations significantly impact their effectiveness and appearance. Well-sized figures ensure that your data is displayed clearly and proportionally, while proper resolution settings guarantee that your visualizations look crisp whether viewed on screen or in print.

Let's set up our environment with the necessary libraries:


## 3. Understanding DPI and Resolution Concepts

DPI (dots per inch) determines how many pixels are used per inch of the figure. Higher DPI values result in larger and more detailed images.

```python
# Demonstrating DPI settings
def show_dpi_comparison():
    dpi_values = [50, 100, 200]
    sample_size = (4, 3)  # 4×3 inches
    
    plt.figure(figsize=(10, 8))
    
    for i, dpi in enumerate(dpi_values):
        plt.subplot(len(dpi_values), 1, i+1)
        
        # Display image dimensions that would result
        width_px = sample_size[0] * dpi
        height_px = sample_size[1] * dpi
        
        plt.text(0.5, 0.5, f"DPI: {dpi}\nSize: {sample_size} inches\n"
                           f"Resolution: {width_px:.0f} × {height_px:.0f} pixels",
                 ha='center', va='center', fontsize=12)
        plt.title(f'DPI = {dpi}')
        plt.xlim(0, 1)
        plt.ylim(0, 1)
        plt.axis('off')
    
    plt.tight_layout()
    plt.show()

# Uncomment to run DPI comparison
# show_dpi_comparison()

# Setting DPI for display
plt.figure(figsize=(6, 4), dpi=100)  # Default dpi is usually 100

plt.show()

# Creating a high-DPI figure

plt.tight_layout()
plt.show()

# Calculating resulting image size in pixels
def calculate_image_size(fig_size_inches, dpi):
    width_px = fig_size_inches[0] * dpi
    height_px = fig_size_inches[1] * dpi
    return width_px, height_px

sizes = [(6, 4), (8, 6), (10, 8)]
dpi_values = [72, 100, 150, 300]

print("Expected image dimensions in pixels:")
for size in sizes:
    for dpi in dpi_values:
        width_px, height_px = calculate_image_size(size, dpi)
        print(f"Size: {size} inches, DPI: {dpi} → {width_px:.0f}×{height_px:.0f} pixels")
```

## 7. Dynamic and Responsive Figure Sizing

In interactive environments or when creating visualizations programmatically, you may need to adjust figure sizes dynamically:

```python
# Dynamic sizing based on data characteristics
def dynamic_figure_size(data, base_size=(6, 4), max_size=(15, 10)):
    """Determine figure size based on data characteristics"""
    n_points = len(data)
    n_features = data.shape[1] if hasattr(data, 'shape') and len(data.shape) > 1 else 1
    
    # Scale width by number of features/categories
    width = min(base_size[0] * (1 + n_features * 0.2), max_size[0])
    
    # Scale height by log of number of data points
    height = min(base_size[1] * (1 + np.log10(n_points) * 0.3), max_size[1])
    
    return (width, height)

# Create datasets of different sizes
small_data = pd.DataFrame(np.random.randn(10, 2), columns=['A', 'B'])
medium_data = pd.DataFrame(np.random.randn(100, 4), columns=['A', 'B', 'C', 'D'])
large_data = pd.DataFrame(np.random.randn(1000, 6), 
                         columns=['A', 'B', 'C', 'D', 'E', 'F'])

# Calculate dynamic sizes
small_size = dynamic_figure_size(small_data)
medium_size = dynamic_figure_size(medium_data)
large_size = dynamic_figure_size(large_data)

print(f"Dynamic sizes based on data:")
print(f"Small data ({small_data.shape}): {small_size}")
print(f"Medium data ({medium_data.shape}): {medium_size}")
print(f"Large data ({large_data.shape}): {large_size}")

# Responsive sizing for Jupyter notebooks/interactive environments
from IPython.display import display

def responsive_figure(fig_function, size_px=(800, 500)):
    """Create a figure that adapts to display size"""
    # Convert desired pixel size to inches based on current DPI
    current_dpi = plt.rcParams['figure.dpi']
    size_inches = (size_px[0] / current_dpi, size_px[1] / current_dpi)
    
    fig = plt.figure(figsize=size_inches)
    fig_function(fig)
    plt.tight_layout()
    display(fig)
    plt.close(fig)
```

```python
# Two-column journal format (common in scientific publications)
def two_column_figure(width_pt=246.0):
    """
    Create a figure sized for a two-column journal format.
    
    Args:
        width_pt (float): Width of the column in points (varies by journal)
                          Common values: 246pt (IEEE), 240pt (Elsevier)
    
    Returns:
        tuple: Figure size in inches
    """
    # Convert points to inches (1pt = 1/72 inch)
    width_in = width_pt / 72.0
    # Golden ratio for aesthetically pleasing figures
    golden_ratio = (5**0.5 - 1) / 2  # ~= 0.618
    # Calculate height based on golden ratio
    height_in = width_in * golden_ratio
    
    return (width_in, height_in)
```

```python
# Best practice: Creating a figure size utility function
def get_figure_size(width_pt=483.69687, fraction=1.0, ratio=(5**0.5-1)/2):
    """
    Get appropriate figure size for different contexts
    
    Args:
        width_pt (float): Document width in points (default for LaTeX article is 483.69687pt)
        fraction (float): Fraction of the width to use
        ratio (float): Height to width ratio (default is golden ratio)
    
    Returns:
        tuple: Figure size in inches
    """
    # Convert from pt to inches
    width_in = width_pt * fraction / 72
    height_in = width_in * ratio
    return (width_in, height_in)
```

## 10. Summary

Proper figure sizing and resolution are essential aspects of creating effective data visualizations. Here's a summary of key points:

1. **Figure Size Basics**:
   - Size is specified in inches in matplotlib (figsize parameter)
   - Size should be chosen based on the complexity of your data and visualization purpose
   - Different plot types have different optimal aspect ratios

2. **Resolution Concepts**:
   - DPI (dots per inch) determines the pixel density of your images
   - Higher DPI results in larger file sizes but sharper images
   - Common values: 72-96 DPI for screen, 150-200 DPI for standard print, 300+ DPI for publication

3. **Output Considerations**:
   - For web/screen: Lower DPI (72-96), PNG/SVG formats
   - For print/publications: Higher DPI (300+), PDF/TIFF formats
   - Vector formats (PDF, SVG, EPS) are resolution-independent and preferred for publication

4. **Best Practices**:
   - Use `tight_layout()` or `constrained_layout=True` to avoid clipping
   - Set font sizes proportional to figure size
   - Maintain consistent sizing throughout a document or presentation
   - Consider the final medium when choosing size and resolution
   - Test figures in their intended display context

5. **Common Pitfalls**:
   - Too small text and elements in large figures
   - Pixelation from insufficient resolution
   - Wasted space or overcrowding due to inappropriate figure size
   - Inconsistent sizing creating a disjointed presentation

Mastering figure size and resolution settings will help you create professional-quality visualizations that effectively communicate your data insights across different mediums and contexts. By following the practices outlined in this guide, you can ensure your visualizations look their best whether viewed on screen, in presentations, or in publications.
