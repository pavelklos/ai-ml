# Heatmaps and Correlation Matrices

## Introduction

Heatmaps are powerful visualization tools that represent data values as colors in a two-dimensional grid. They excel at showing patterns, variations, and correlations in complex datasets at a glance. Correlation matrices, a common application of heatmaps, display the correlation coefficients between multiple variables, making them invaluable for exploratory data analysis, feature selection in machine learning, and identifying relationships in multivariate data.

This guide explores how to create effective heatmaps and correlation matrices in Python using various libraries, from basic implementations to advanced customizations and interactive visualizations.

## Basic Heatmaps with Matplotlib and Seaborn

### Creating a Simple Heatmap

Heatmaps can be created easily with both Matplotlib and Seaborn. Let's start with a basic example:

```python
# Generate sample data
np.random.seed(42)
data = np.random.rand(10, 12)

# Create a simple heatmap with Matplotlib
plt.figure(figsize=(10, 8))
plt.imshow(data, cmap='viridis')
plt.colorbar(label='Value')
plt.title('Basic Heatmap with Matplotlib')
plt.tight_layout()
plt.show()

# Create a heatmap with Seaborn
plt.figure(figsize=(10, 8))
sns.heatmap(data, cmap='viridis', annot=False)
plt.title('Basic Heatmap with Seaborn')
plt.tight_layout()
plt.show()
```

### Adding Annotations

Adding value annotations to heatmaps can make them more informative:

```python
# Create a smaller dataset for annotations
small_data = np.round(np.random.rand(5, 6) * 100)

# Create an annotated heatmap with Seaborn
plt.figure(figsize=(10, 8))
sns.heatmap(small_data, 
            annot=True,           # Show values
            fmt='g',             # Format as general (remove decimals if none)
            cmap='YlGnBu',       # Yellow-Green-Blue color map
            linewidths=0.5,      # Add grid lines
            cbar_kws={'label': 'Value'})
plt.title('Heatmap with Annotations')
plt.tight_layout()
plt.show()
```

## Correlation Matrices

Correlation matrices show the correlation coefficients between variables in a dataset, helping to identify relationships.

### Creating a Basic Correlation Matrix

```python
# Load the Iris dataset
iris = load_iris()
iris_df = pd.DataFrame(iris.data, columns=iris.feature_names)

# Calculate correlation matrix
corr_matrix = iris_df.corr()

# Plot the correlation matrix
plt.figure(figsize=(10, 8))
sns.heatmap(corr_matrix, 
            annot=True,           # Show correlation values
            cmap='coolwarm',      # Blue-red diverging colormap
            vmin=-1, vmax=1,      # Set the range for correlation values
            linewidths=0.5,
            square=True)          # Make the heatmap cells square
plt.title('Correlation Matrix of Iris Dataset Features')
plt.tight_layout()
plt.show()
```

### Using Real-World Data

Let's create a correlation matrix with a more complex dataset:

```python
# Load the California housing dataset
housing = fetch_california_housing()
housing_df = pd.DataFrame(housing.data, columns=housing.feature_names)

# Calculate correlation matrix
housing_corr = housing_df.corr()

# Create a mask to only show the lower triangle (avoid redundancy)
mask = np.triu(np.ones_like(housing_corr, dtype=bool))

# Plot the correlation matrix with a mask
plt.figure(figsize=(12, 10))
sns.heatmap(housing_corr, 
            annot=True,           # Show correlation values
            mask=mask,            # Apply the mask
            cmap='coolwarm',      # Blue-red diverging colormap
            vmin=-1, vmax=1,      # Set the range for correlation values
            center=0,             # Center the colormap at 0
            linewidths=0.5,
            square=True)          # Make the heatmap cells square
plt.title('Correlation Matrix of California Housing Features', fontsize=16)
plt.tight_layout()
plt.show()
```

## Advanced Heatmap Customization

### Custom Color Mapping

You can customize color maps based on specific thresholds or conditions:

```python
# Generate some example data with both positive and negative values
np.random.seed(42)
data = np.random.randn(10, 10)

# Create a custom diverging colormap
from matplotlib.colors import LinearSegmentedColormap

# Define custom colors (purple to green)
colors = ["darkpurple", "white", "forestgreen"]
custom_cmap = LinearSegmentedColormap.from_list("custom_diverging", colors, N=256)

# Plot the heatmap with custom colormap
plt.figure(figsize=(10, 8))
sns.heatmap(data,
            cmap=custom_cmap,
            center=0,             # Center the colormap at 0
            annot=True,           # Show values
            fmt=".2f",            # Format with 2 decimal places
            linewidths=0.5)
plt.title('Heatmap with Custom Diverging Colormap')
plt.tight_layout()
plt.show()
```

### Formatting Annotations

You can create custom formatting for annotations:

```python
# Function to format annotations differently based on value
def fmt_func(val):
    color = 'red' if val < 0 else 'black'
    return f'${val:.2f}' if abs(val) > 0.5 else ''

# Create a masked array for selective display
data_masked = np.ma.masked_where(abs(data) <= 0.5, data)

# Plot with custom formatting
plt.figure(figsize=(12, 10))
ax = sns.heatmap(data, 
                annot=np.abs(data) > 0.5,  # Only annotate values > 0.5
                fmt="",                   # Empty format since we use custom formatter
                cmap='PuOr',              # Purple-Orange colormap
                center=0,
                linewidths=0.5)

# Apply custom text formatting
for i in range(data.shape[0]):
    for j in range(data.shape[1]):
        value = data[i, j]
        if abs(value) > 0.5:  # Only add text for values we want to show
            text_color = 'white' if abs(value) > 1.5 else 'black'
            ax.text(j + 0.5, i + 0.5, f'{value:.2f}', 
                   ha='center', va='center', color=text_color)

plt.title('Heatmap with Custom Formatted Annotations')
plt.tight_layout()
plt.show()
```

## Hierarchical Clustering with Heatmaps

Hierarchical clustering can organize rows and columns in heatmaps to reveal patterns:

```python
# Load the Iris dataset again
iris = load_iris()
iris_df = pd.DataFrame(iris.data, columns=iris.feature_names)

# Add species information
iris_df['species'] = [iris.target_names[i] for i in iris.target]

# Select a subset of the data for clearer visualization
subset = iris_df.sample(40, random_state=42)
features = subset.iloc[:, :-1]  # All columns except species
row_labels = subset['species']

# Create a clustered heatmap
plt.figure(figsize=(14, 10))
sns.clustermap(features, 
               cmap='viridis',
               row_colors=pd.Series(row_labels).map({'setosa': 'red', 
                                                    'versicolor': 'green', 
                                                    'virginica': 'blue'}),
               standard_scale=1,  # Standardize data along columns
               linewidths=0.01,
               figsize=(14, 10))
plt.title('Hierarchically Clustered Heatmap of Iris Data', fontsize=16)
plt.tight_layout()
plt.show()
```

## Interactive Heatmaps with Plotly

Plotly allows for the creation of interactive heatmaps:

```python
# Create an interactive correlation heatmap
corr_matrix = iris_df.iloc[:, :-1].corr()

# Basic interactive heatmap
fig = px.imshow(corr_matrix,
                labels=dict(x="Features", y="Features", color="Correlation"),
                x=corr_matrix.columns,
                y=corr_matrix.columns,
                color_continuous_scale='RdBu_r',
                title='Interactive Correlation Matrix of Iris Dataset')
fig.update_layout(
    width=700, 
    height=600,
    title_font_size=20
)
fig.show()

# Advanced interactive heatmap with custom hover info
fig = go.Figure(data=go.Heatmap(
        z=corr_matrix.values,
        x=corr_matrix.columns,
        y=corr_matrix.columns,
        hoverongaps=False,
        colorscale='RdBu_r',
        zmid=0,  # Center the color scale at 0
        text=np.around(corr_matrix.values, decimals=2),  # Display rounded values in hover
        hovertemplate='%{y} & %{x}<br>Correlation: %{z:.3f}<extra></extra>'
))

fig.update_layout(
    title='Interactive Heatmap with Custom Hover Information',
    width=800,
    height=700,
    title_font_size=20
)
fig.show()
```

## Specialized Heatmaps

### Calendar Heatmaps

Calendar heatmaps display data values across dates:

```python
# Generate some date-based data
import datetime as dt

# Create a date range for 2022
dates = pd.date_range(start='2022-01-01', end='2022-12-31')
values = np.sin(np.linspace(0, 12*np.pi, len(dates))) + np.random.normal(0, 0.3, len(dates))

# Create a dataframe
date_df = pd.DataFrame({
    'date': dates,
    'value': values
})
date_df['year'] = date_df['date'].dt.year
date_df['month'] = date_df['date'].dt.month
date_df['day'] = date_df['date'].dt.day
date_df['weekday'] = date_df['date'].dt.weekday

# Create a pivot table suitable for a calendar heatmap
pivot_data = date_df.pivot_table(index='weekday', columns='date', values='value')

# Plot calendar heatmap (simplified version)
plt.figure(figsize=(20, 4))
sns.heatmap(pivot_data, 
            cmap='YlGnBu', 
            cbar_kws={'label': 'Value'})
plt.title('Calendar Heatmap (Weekdays vs Dates)')
plt.ylabel('Day of Week')
plt.tight_layout()
plt.show()
```

### Seaborn's Complex Heatmaps

Seaborn provides advanced heatmap capabilities with `clustermap`:

```python
# Create a more complex clustered heatmap using titanic dataset
titanic = sns.load_dataset('titanic')

# Create a pivot table of survival rate by age and fare
pivot_titanic = titanic.pivot_table(
    values='survived', 
    index=pd.qcut(titanic['age'].fillna(titanic['age'].median()), 5),  # Age quintiles
    columns=pd.qcut(titanic['fare'].fillna(titanic['fare'].median()), 5),  # Fare quintiles
    aggfunc='mean'
)

# Plot the clustermap with dendrogram
plt.figure(figsize=(14, 10))
cluster = sns.clustermap(
    pivot_titanic,
    cmap="YlGnBu",
    annot=True,
    fmt=".2f",
    linewidths=0.5,
    figsize=(10, 8),
    vmin=0, vmax=1,
    cbar_kws={"label": "Survival Rate"}
)
plt.title('Survival Rate by Age and Fare Quintiles (Clustered)', fontsize=16)
plt.tight_layout()
plt.show()
```

## Best Practices

1. **Choose appropriate color maps**:
   - Use sequential colormaps (e.g., 'viridis', 'YlGnBu') for data that ranges from low to high
   - Use diverging colormaps (e.g., 'coolwarm', 'RdBu') for data centered around a meaningful value (like 0 for correlations)

2. **Optimize readability**:
   - Add annotations when the number of cells is manageable
   - Use masks to avoid redundancy in symmetric matrices
   - Apply proper formatting for values
   - Choose appropriate cell sizes based on the data dimension

3. **Enhance interpretability**:
   - Apply clustering to reveal patterns
   - Add row/column labels
   - Include descriptive titles and colorbar labels
   - Consider sorting or reordering the matrix based on values or categories

4. **Handle large datasets**:
   - Use subsampling or aggregation for large datasets
   - Consider interactive plots for large matrices
   - Adjust the figure size appropriately

5. **Color considerations**:
   - Ensure colorblind-friendly colormaps when possible (viridis, cividis, etc.)
   - Set appropriate vmin and vmax for consistent scaling
   - Consider using center parameter for diverging data
