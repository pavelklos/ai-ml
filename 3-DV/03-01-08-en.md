## 1. Introduction to Multiple Plots and Subplots

Multiple plots and subplots allow you to display several visualizations within a single figure, enabling side-by-side comparisons, multi-dimensional data exploration, and comprehensive data storytelling. Subplots help in organizing related visualizations together while saving space and making it easier for the viewer to draw connections between different aspects of the data.

```python
# Import essential libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set a design theme for visual consistency
plt.style.use('seaborn-v0_8-whitegrid')

# Check matplotlib version
print(f"Matplotlib version: {plt.__version__}")

# Generate sample data
np.random.seed(42)  # For reproducibility
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)
y3 = np.sin(x) * np.exp(-x/5)
y4 = x**2 / 30
```

Key benefits of using subplots:
- Compare multiple datasets or views of the same data
- Show relationships between different variables
- Present analysis progression or different aspects of results
- Conserve space while presenting comprehensive information
- Create dashboard-like views of your data

## 2. Basic Subplot Creation with Matplotlib

Matplotlib offers several ways to create subplots. The most common methods are `plt.subplot()` and `plt.subplots()`. The former creates a single subplot at a time, while the latter creates a grid of subplots at once.

```python
# Method 1: Using plt.subplot()
plt.figure(figsize=(12, 4))

# Create first subplot (1 row, 3 columns, first position)
plt.subplot(1, 3, 1)
plt.plot(x, y1, 'b-')
plt.title('Sine Wave')
plt.xlabel('x')
plt.ylabel('sin(x)')

# Create second subplot (1 row, 3 columns, second position)
plt.subplot(1, 3, 2)
plt.plot(x, y2, 'r-')
plt.title('Cosine Wave')
plt.xlabel('x')
plt.ylabel('cos(x)')

# Create third subplot (1 row, 3 columns, third position)
plt.subplot(1, 3, 3)
plt.plot(x, y3, 'g-')
plt.title('Damped Sine Wave')
plt.xlabel('x')
plt.ylabel('sin(x) * exp(-x/5)')

plt.tight_layout()  # Adjust spacing between subplots
plt.show()

# Method 2: Using plt.subplots() - creates all subplots at once
fig, axes = plt.subplots(nrows=1, ncols=3, figsize=(12, 4))

# Plot on each axes
axes[0].plot(x, y1, 'b-')
axes[0].set_title('Sine Wave')
axes[0].set_xlabel('x')
axes[0].set_ylabel('sin(x)')

axes[1].plot(x, y2, 'r-')
axes[1].set_title('Cosine Wave')
axes[1].set_xlabel('x')
axes[1].set_ylabel('cos(x)')

axes[2].plot(x, y3, 'g-')
axes[2].set_title('Damped Sine Wave')
axes[2].set_xlabel('x')
axes[2].set_ylabel('sin(x) * exp(-x/5)')

plt.tight_layout()
plt.show()
```

Key differences between the two methods:
- `plt.subplot()`: Stateful API, creates one subplot at a time
- `plt.subplots()`: Object-oriented API, returns figure and axes objects
- The object-oriented approach (second method) offers more flexibility and is generally recommended for complex visualizations

## 3. Working with Figure and Axes Objects

Understanding the relationship between Figure and Axes objects is crucial for creating effective subplots. A Figure is the overall container for all plots, while each Axes represents an individual subplot within the Figure.

```python
# Creating Figure and Axes objects explicitly
fig = plt.figure(figsize=(15, 5))

# Add three Axes objects to the figure at specific positions
# Arguments are: [left, bottom, width, height] in figure coordinates (0-1)
ax1 = fig.add_axes([0.1, 0.1, 0.25, 0.8])  # Left subplot
ax2 = fig.add_axes([0.4, 0.1, 0.25, 0.8])  # Middle subplot
ax3 = fig.add_axes([0.7, 0.1, 0.25, 0.8])  # Right subplot

# Plot data on each axes
ax1.plot(x, y1, 'b-')
ax1.set_title('Sine Wave')
ax1.set_xlabel('x')
ax1.set_ylabel('sin(x)')

ax2.plot(x, y2, 'r-')
ax2.set_title('Cosine Wave')
ax2.set_xlabel('x')
ax2.set_ylabel('cos(x)')

ax3.plot(x, y3, 'g-')
ax3.set_title('Damped Sine Wave')
ax3.set_xlabel('x')
ax3.set_ylabel('sin(x) * exp(-x/5)')

plt.show()

# Create figure with main plot and an inset
fig = plt.figure(figsize=(8, 6))
ax_main = fig.add_axes([0.1, 0.1, 0.8, 0.8])  # Main axes
ax_inset = fig.add_axes([0.55, 0.55, 0.3, 0.3])  # Inset axes

# Plot on main axes
ax_main.plot(x, y3, 'g-')
ax_main.set_title('Damped Sine Wave with Zoomed Section')
ax_main.set_xlabel('x')
ax_main.set_ylabel('sin(x) * exp(-x/5)')

# Plot zoomed section in inset
ax_inset.plot(x[:30], y3[:30], 'r-')
ax_inset.set_title('Zoomed', fontsize=9)
ax_inset.tick_params(labelsize=8)

plt.show()
```

Working with Figure and Axes objects gives you:
- Precise control over subplot placement
- Ability to create nested plots (plots within plots)
- More flexibility for customizing individual plots
- Better control over shared properties between plots

## 4. Grid Layouts for Subplot Arrangement

Subplots can be arranged in various grid layouts to accommodate different visualization needs. Matplotlib provides flexible ways to create both regular and irregular grid patterns.

```python
# Regular grid with plt.subplots()
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8))

# Plot on each axes using indexing
axes[0, 0].plot(x, y1)
axes[0, 0].set_title('Sine Wave')

axes[0, 1].plot(x, y2)
axes[0, 1].set_title('Cosine Wave')

axes[1, 0].plot(x, y3)
axes[1, 0].set_title('Damped Sine Wave')

axes[1, 1].plot(x, y4)
axes[1, 1].set_title('Quadratic Function')

plt.tight_layout()
plt.show()

# Complex grid layout with GridSpec
import matplotlib.gridspec as gridspec

fig = plt.figure(figsize=(12, 8))
gs = gridspec.GridSpec(2, 3)  # 2 rows, 3 columns

# Create subplots with different spans
ax1 = fig.add_subplot(gs[0, :])  # First row, all columns
ax2 = fig.add_subplot(gs[1, 0])  # Second row, first column
ax3 = fig.add_subplot(gs[1, 1])  # Second row, second column
ax4 = fig.add_subplot(gs[1, 2])  # Second row, third column

# Plot data
ax1.plot(x, y1, 'b-')
ax1.set_title('Top Row: Sine Wave (Spans All Columns)')

ax2.plot(x, y2, 'r-')
ax2.set_title('Cosine Wave')

ax3.plot(x, y3, 'g-')
ax3.set_title('Damped Sine')

ax4.plot(x, y4, 'y-')
ax4.set_title('Quadratic')

plt.tight_layout()
plt.show()
```

Additional grid layout techniques:
- `plt.subplot2grid()`: Create irregular grid layouts
- `gridspec.GridSpecFromSubplotSpec()`: Create nested grid specifications
- `fig.add_gridspec()`: Modern way to create grid specifications directly from a figure

## 5. Shared Axes and Scales

Sharing axes between subplots helps maintain consistent scales and reduces redundant information, making it easier to compare data across multiple plots.

```python
# Creating subplots with shared axes
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8), 
                         sharex=True, sharey=True)

# Generate some data with similar ranges but different patterns
data1 = np.random.normal(0, 1, 100).cumsum()
data2 = np.random.normal(0, 1, 100).cumsum()
data3 = np.random.normal(0, 1, 100).cumsum()
data4 = np.random.normal(0, 1, 100).cumsum()

# Plot data on subplots
axes[0, 0].plot(data1, 'r-')
axes[0, 0].set_title('Dataset 1')

axes[0, 1].plot(data2, 'g-')
axes[0, 1].set_title('Dataset 2')

axes[1, 0].plot(data3, 'b-')
axes[1, 0].set_title('Dataset 3')

axes[1, 1].plot(data4, 'k-')
axes[1, 1].set_title('Dataset 4')

# Only bottom subplots need x-labels (because of shared x-axis)
axes[1, 0].set_xlabel('X values')
axes[1, 1].set_xlabel('X values')

# Only left subplots need y-labels (because of shared y-axis)
axes[0, 0].set_ylabel('Y values')
axes[1, 0].set_ylabel('Y values')

plt.tight_layout()
plt.show()

# Subplots with different sharing configurations
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Manually share x-axis between plots in the same column
axes[0, 0].get_shared_x_axes().join(axes[0, 0], axes[1, 0])
axes[0, 1].get_shared_x_axes().join(axes[0, 1], axes[1, 1])

# Manually share y-axis between plots in the same row
axes[0, 0].get_shared_y_axes().join(axes[0, 0], axes[0, 1])
axes[1, 0].get_shared_y_axes().join(axes[1, 0], axes[1, 1])

# Plot with deliberately different ranges
axes[0, 0].plot(np.sin(x))
axes[0, 0].set_title('Sin - Shared X with below, Shared Y with right')

axes[0, 1].plot(2 * np.sin(x))
axes[0, 1].set_title('2×Sin - Shared X with below, Shared Y with left')

axes[1, 0].plot(np.cos(x))
axes[1, 0].set_title('Cos - Shared X with above, Shared Y with right')

axes[1, 1].plot(2 * np.cos(x))
axes[1, 1].set_title('2×Cos - Shared X with above, Shared Y with left')

plt.tight_layout()
plt.show()
```

Benefits of shared axes:
- Ensures direct visual comparison between plots
- Reduces redundant axis labels and ticks
- Saves space and creates cleaner visualizations
- Helps viewers identify patterns and differences more easily

## 6. Combining Different Plot Types

One of the strengths of using subplots is the ability to combine different types of visualizations to provide complementary views of the same or related data.

```python
# Create data for different plot types
np.random.seed(42)
data = pd.DataFrame({
    'x': np.random.normal(0, 1, 1000),
    'y': np.random.normal(0, 1, 1000),
    'category': np.random.choice(['A', 'B', 'C', 'D'], 1000)
})

# Create a figure with different plot types
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# 1. Scatter plot
axes[0, 0].scatter(data['x'], data['y'], alpha=0.5)
axes[0, 0].set_title('Scatter Plot')
axes[0, 0].set_xlabel('X values')
axes[0, 0].set_ylabel('Y values')

# 2. Histogram
axes[0, 1].hist(data['x'], bins=30, alpha=0.7, color='green')
axes[0, 1].set_title('Histogram of X')
axes[0, 1].set_xlabel('Value')
axes[0, 1].set_ylabel('Frequency')

# 3. Bar chart
category_counts = data['category'].value_counts()
axes[1, 0].bar(category_counts.index, category_counts.values, color='orange')
axes[1, 0].set_title('Bar Chart of Categories')
axes[1, 0].set_xlabel('Category')
axes[1, 0].set_ylabel('Count')

# 4. Box plot with Seaborn
sns.boxplot(x='category', y='x', data=data, ax=axes[1, 1])
axes[1, 1].set_title('Box Plot by Category')
axes[1, 1].set_xlabel('Category')
axes[1, 1].set_ylabel('X Value Distribution')

plt.tight_layout()
plt.show()

# Combine related visualizations for better insights
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Create correlated data
n = 100
t = np.linspace(0, 2*np.pi, n)
x1 = np.sin(t) + np.random.normal(0, 0.2, n)
x2 = np.cos(t) + np.random.normal(0, 0.2, n)

# 1. Time series plot
axes[0, 0].plot(t, x1, 'b-', label='sin(t)')
axes[0, 0].plot(t, x2, 'r-', label='cos(t)')
axes[0, 0].set_title('Time Series')
axes[0, 0].set_xlabel('Time')
axes[0, 0].set_ylabel('Value')
axes[0, 0].legend()

# 2. Scatter plot of the two series
axes[0, 1].scatter(x1, x2, alpha=0.7)
axes[0, 1].set_title('X1 vs X2')
axes[0, 1].set_xlabel('X1 (sin)')
axes[0, 1].set_ylabel('X2 (cos)')

# 3 & 4. Histograms of each series
axes[1, 0].hist(x1, bins=20, alpha=0.7, color='blue')
axes[1, 0].set_title('Histogram of X1')
axes[1, 0].set_xlabel('Value')
axes[1, 0].set_ylabel('Frequency')

axes[1, 1].hist(x2, bins=20, alpha=0.7, color='red')
axes[1, 1].set_title('Histogram of X2')
axes[1, 1].set_xlabel('Value')
axes[1, 1].set_ylabel('Frequency')

plt.tight_layout()
plt.show()
```

Tips for combining different plot types:
- Choose complementary visualizations that highlight different aspects of the data
- Keep a consistent color scheme across related plots
- Arrange plots in a logical sequence or relationship
- Consider using shared axes when appropriate
- Include clear titles and axis labels to guide the viewer

## 7. Sizing and Spacing of Subplots

Properly sizing and spacing your subplots is crucial for creating clear, readable visualizations. Matplotlib provides several tools to control these aspects.

```python
# Control figure size and subplot spacing
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Plot simple data on all subplots
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))
        axes[i, j].set_title(f'Subplot [{i}, {j}]')

# Default spacing - often too tight
plt.suptitle('Default Subplot Spacing', fontsize=16)
plt.show()

# Using tight_layout() to improve spacing
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Plot simple data on all subplots
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))
        axes[i, j].set_title(f'Subplot [{i}, {j}]')

plt.tight_layout()
plt.suptitle('With tight_layout()', fontsize=16, y=1.05)  # Adjust y to prevent overlap
plt.show()

# Using subplots_adjust for fine control
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Plot simple data on all subplots
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))
        axes[i, j].set_title(f'Subplot [{i}, {j}]')

plt.subplots_adjust(left=0.1,    # Left margin
                   right=0.9,    # Right margin
                   bottom=0.1,   # Bottom margin
                   top=0.9,      # Top margin
                   wspace=0.4,   # Width spacing between subplots
                   hspace=0.4)   # Height spacing between subplots

plt.suptitle('Custom Spacing with subplots_adjust()', fontsize=16)
plt.show()

# GridSpec with width and height ratios
fig = plt.figure(figsize=(12, 8))
gs = gridspec.GridSpec(2, 2, width_ratios=[2, 1], height_ratios=[1, 2])

# Create subplots with custom sizes
ax1 = fig.add_subplot(gs[0, 0])  # Top-left, wide
ax2 = fig.add_subplot(gs[0, 1])  # Top-right, narrow
ax3 = fig.add_subplot(gs[1, 0])  # Bottom-left, wide and tall
ax4 = fig.add_subplot(gs[1, 1])  # Bottom-right, narrow and tall

ax1.plot(np.random.rand(10))
ax1.set_title('Wide Plot')

ax2.plot(np.random.rand(10))
ax2.set_title('Narrow Plot')

ax3.plot(np.random.rand(10))
ax3.set_title('Wide and Tall Plot')

ax4.plot(np.random.rand(10))
ax4.set_title('Narrow and Tall Plot')

plt.tight_layout()
plt.show()
```

Key techniques for controlling subplot size and spacing:
- `figsize`: Set the overall figure dimensions
- `plt.tight_layout()`: Automatically adjust subplot parameters for optimal spacing
- `plt.subplots_adjust()`: Fine-tune spacing with explicit parameters
- `width_ratios` and `height_ratios` in `GridSpec`: Control relative sizes of subplots
- Constrained layout: `plt.figure(constrained_layout=True)`: Alternative to tight_layout

## 8. Adding Titles and Labels to Multiple Subplots

Clear titles and labels help viewers understand what they're looking at. For multiple subplots, both individual titles and an overall figure title are often needed.

```python
# Creating a figure with subplots and comprehensive labeling
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Sample data
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)
y3 = np.sin(x) * np.exp(-x/5)
y4 = np.cos(x) * np.exp(-x/5)

# Plot 1
axes[0, 0].plot(x, y1, 'b-')
axes[0, 0].set_title('Sine Wave', fontsize=14)
axes[0, 0].set_xlabel('X values')
axes[0, 0].set_ylabel('Amplitude')

# Plot 2
axes[0, 1].plot(x, y2, 'r-')
axes[0, 1].set_title('Cosine Wave', fontsize=14)
axes[0, 1].set_xlabel('X values')
axes[0, 1].set_ylabel('Amplitude')

# Plot 3
axes[1, 0].plot(x, y3, 'g-')
axes[1, 0].set_title('Damped Sine Wave', fontsize=14)
axes[1, 0].set_xlabel('X values')
axes[1, 0].set_ylabel('Amplitude')

# Plot 4
axes[1, 1].plot(x, y4, 'm-')
axes[1, 1].set_title('Damped Cosine Wave', fontsize=14)
axes[1, 1].set_xlabel('X values')
axes[1, 1].set_ylabel('Amplitude')

# Add overall figure title and subtitle
fig.suptitle('Trigonometric Functions', fontsize=20, fontweight='bold', y=0.98)
plt.figtext(0.5, 0.92, 'Showing basic and damped trigonometric functions', 
           ha='center', fontsize=14, fontstyle='italic')

# Add figure-wide annotations or explanations
plt.figtext(0.5, 0.01, 
           'Note: The damped functions decay exponentially with exp(-x/5)', 
           ha='center', fontsize=12)

# Add legend for all subplots in a custom location
legend_elements = [
    plt.Line2D([0], [0], color='b', label='sin(x)'),
    plt.Line2D([0], [0], color='r', label='cos(x)'),
    plt.Line2D([0], [0], color='g', label='sin(x) * exp(-x/5)'),
    plt.Line2D([0], [0], color='m', label='cos(x) * exp(-x/5)')
]
fig.legend(handles=legend_elements, loc='upper center', bbox_to_anchor=(0.5, 0.05), 
          frameon=True, ncol=4, fontsize=12)

plt.subplots_adjust(top=0.85, bottom=0.15)  # Make room for titles
plt.show()

# Adding subplot labels (a), (b), etc. for publication
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Plot data in each subplot
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))
        
# Add subplot labels
subplot_labels = ['(a)', '(b)', '(c)', '(d)']
label_idx = 0

for i in range(2):
    for j in range(2):
        # Add label in the upper left corner of each subplot
        axes[i, j].text(0.05, 0.95, subplot_labels[label_idx], 
                      transform=axes[i, j].transAxes,
                      fontsize=16, fontweight='bold', va='top')
        
        axes[i, j].set_title(f'Subplot {subplot_labels[label_idx]}')
        label_idx += 1

plt.tight_layout()
plt.suptitle('Publication-Style Subplot Labeling', fontsize=16, y=1.05)
plt.show()
```

Effective titling practices:
- Use `fig.suptitle()` for overall figure titles
- Use `ax.set_title()` for individual subplot titles
- Use `plt.figtext()` for additional explanations or annotations
- Consider adding subplot labels ((a), (b), etc.) for reference in publications
- Use `plt.annotate()` to highlight specific features within plots
- Ensure titles are descriptive yet concise

## 9. Advanced Subplot Techniques

Beyond basic subplots, matplotlib offers advanced techniques for more complex visualization scenarios.

```python
# 1. Inset plots: plots within plots
fig, ax = plt.subplots(figsize=(10, 6))

# Main plot
x = np.linspace(0, 10, 1000)
y = np.sin(x) * np.exp(-x/5)
ax.plot(x, y, 'b-')
ax.set_title('Damped Sine Wave with Zoomed Inset', fontsize=14)
ax.set_xlabel('X values')
ax.set_ylabel('Amplitude')

# Create an inset plot
axins = ax.inset_axes([0.55, 0.55, 0.3, 0.3])  # [x, y, width, height] in relative coordinates
axins.plot(x[:200], y[:200], 'r-')
axins.set_title('Zoomed First Peak', fontsize=10)
axins.tick_params(labelsize=8)

# Draw a box around the zoomed region
ax.indicate_inset_zoom(axins, edgecolor='gray')

plt.tight_layout()
plt.show()

# 2. Secondary Y-axis for different scales
fig, ax1 = plt.subplots(figsize=(10, 6))

# Data with different scales
x = np.linspace(0, 10, 100)
y1 = np.sin(x)           # Range: -1 to 1
y2 = 100 * np.cos(x)     # Range: -100 to 100

# Primary y-axis
color = 'tab:blue'
ax1.plot(x, y1, color=color)
ax1.set_xlabel('X values')
ax1.set_ylabel('sin(x)', color=color)
ax1.tick_params(axis='y', labelcolor=color)

# Secondary y-axis
ax2 = ax1.twinx()
color = 'tab:red'
ax2.plot(x, y2, color=color)
ax2.set_ylabel('cos(x) × 100', color=color)
ax2.tick_params(axis='y', labelcolor=color)

fig.tight_layout()
plt.title('Plot with Two Scales')
plt.show()

# 3. Nested GridSpecs
fig = plt.figure(figsize=(12, 8))
outer_grid = fig.add_gridspec(2, 2)

# Top left: Single plot
ax_top_left = fig.add_subplot(outer_grid[0, 0])
ax_top_left.plot(np.random.rand(10))
ax_top_left.set_title('Single Plot')

# Top right: 2 subplots in a column
inner_top_right = gridspec.GridSpecFromSubplotSpec(2, 1, subplot_spec=outer_grid[0, 1])
ax_tr1 = fig.add_subplot(inner_top_right[0])
ax_tr2 = fig.add_subplot(inner_top_right[1])
ax_tr1.plot(np.random.rand(10), 'r-')
ax_tr2.plot(np.random.rand(10), 'g-')
ax_tr1.set_title('Top Right - Upper')
ax_tr2.set_title('Top Right - Lower')

# Bottom left: 2 subplots in a row
inner_bottom_left = gridspec.GridSpecFromSubplotSpec(1, 2, subplot_spec=outer_grid[1, 0])
ax_bl1 = fig.add_subplot(inner_bottom_left[0])
ax_bl2 = fig.add_subplot(inner_bottom_left[1])
ax_bl1.plot(np.random.rand(10), 'm-')
ax_bl2.plot(np.random.rand(10), 'y-')
ax_bl1.set_title('Bottom Left - Left')
ax_bl2.set_title('Bottom Left - Right')

# Bottom right: 2×2 grid
inner_bottom_right = gridspec.GridSpecFromSubplotSpec(2, 2, subplot_spec=outer_grid[1, 1])
for i in range(2):
    for j in range(2):
        ax = fig.add_subplot(inner_bottom_right[i, j])
        ax.plot(np.random.rand(10), 'k-')
        ax.set_title(f'BR [{i},{j}]')

plt.tight_layout()
plt.show()

# 4. Combining Seaborn and Matplotlib
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Create a sample dataset
titanic = sns.load_dataset('titanic')

# Matplotlib scatter plot
axes[0, 0].scatter(titanic['age'], titanic['fare'], 
                 c=titanic['survived'], cmap='viridis', alpha=0.7)
axes[0, 0].set_title('Matplotlib Scatter: Age vs Fare')
axes[0, 0].set_xlabel('Age')
axes[0, 0].set_ylabel('Fare')

# Seaborn boxplot
sns.boxplot(x='class', y='age', data=titanic, ax=axes[0, 1])
axes[0, 1].set_title('Seaborn Boxplot: Age by Class')

# Seaborn countplot
sns.countplot(x='class', hue='survived', data=titanic, ax=axes[1, 0])
axes[1, 0].set_title('Seaborn Countplot: Survival by Class')

# Seaborn heatmap of correlation matrix
correlation = titanic.select_dtypes(include=[np.number]).corr()
sns.heatmap(correlation, annot=True, fmt='.2f', cmap='coolwarm', 
          square=True, linewidths=0.5, ax=axes[1, 1])
axes[1, 1].set_title('Correlation Heatmap')
```

## 10. Summary and Best Practices

Multiple plots and subplots are powerful tools for comprehensive data visualization. They allow you to display related information together, enabling comparisons and providing context that might be lost in separate figures.

Key takeaways:
1. **Choose the right approach**: Use `plt.subplots()` for most cases due to its flexibility and object-oriented nature.
2. **Plan your layout**: Decide on the number and arrangement of subplots based on your data's story.
3. **Share axes when appropriate**: Use shared axes to maintain consistent scales across related plots.
4. **Mind the spacing**: Use `tight_layout()` or `subplots_adjust()` to ensure proper spacing between subplots.
5. **Label comprehensively**: Include clear titles, axis labels, and legends for each subplot.
6. **Consider different plot types**: Combine complementary visualizations to highlight different aspects of your data.
7. **Create visual hierarchy**: Use size and position to emphasize important plots.
8. **Maintain consistency**: Use consistent color schemes, scales, and styling across related subplots.
9. **Add context**: Include an overall figure title and annotations to guide the viewer.
10. **Optimize for your medium**: Consider where your visualization will be viewed (paper, screen, presentation) when determining layout and sizing.

```python
# A complete example bringing together best practices
np.random.seed(42)

# Create sample data
n_points = 100
x = np.linspace(0, 10, n_points)
y1 = np.sin(x) + np.random.normal(0, 0.2, n_points)
y2 = np.cos(x) + np.random.normal(0, 0.2, n_points)

# Create a comprehensive figure with multiple plot types
fig = plt.figure(figsize=(15, 10))
gs = gridspec.GridSpec(2, 3, width_ratios=[1, 1, 1.2])

# 1. Time series plot (top left)
ax1 = fig.add_subplot(gs[0, 0])
ax1.plot(x, y1, 'b-', label='sin(x)')
ax1.plot(x, y2, 'r-', label='cos(x)')
ax1.set_title('Time Series', fontweight='bold')
ax1.set_xlabel('X values')
ax1.set_ylabel('Value')
ax1.legend()
ax1.grid(True, alpha=0.3)

# 2. Scatter plot (top middle)
ax2 = fig.add_subplot(gs[0, 1])
ax2.scatter(y1, y2, alpha=0.7, c=x, cmap='viridis')
ax2.set_title('Y1 vs Y2 Relationship', fontweight='bold')
ax2.set_xlabel('sin(x) + noise')
ax2.set_ylabel('cos(x) + noise')
ax2.grid(True, alpha=0.3)

# 3. Histograms (top right, with subplots)
ax3 = fig.add_subplot(gs[0, 2])
ax3.hist(y1, bins=20, alpha=0.5, label='sin(x)', color='blue')
ax3.hist(y2, bins=20, alpha=0.5, label='cos(x)', color='red')
ax3.set_title('Value Distributions', fontweight='bold')
ax3.set_xlabel('Value')
ax3.set_ylabel('Frequency')
ax3.legend()
ax3.grid(True, alpha=0.3)

# 4. Heatmap (bottom left)
ax4 = fig.add_subplot(gs[1, 0])
# Create 2D data for heatmap
xx, yy = np.meshgrid(np.linspace(-2, 2, 30), np.linspace(-2, 2, 30))
zz = np.sin(xx) * np.cos(yy)
im = ax4.imshow(zz, cmap='coolwarm', origin='lower', extent=[-2, 2, -2, 2])
ax4.set_title('2D Function: sin(x)cos(y)', fontweight='bold')
ax4.set_xlabel('X axis')
ax4.set_ylabel('Y axis')
plt.colorbar(im, ax=ax4, label='Value')

# 5. Box plot (bottom middle)
ax5 = fig.add_subplot(gs[1, 1])
data = [y1, y2]
ax5.boxplot(data, labels=['sin(x)', 'cos(x)'])
ax5.set_title('Value Ranges', fontweight='bold')
ax5.set_ylabel('Value')
ax5.grid(True, alpha=0.3)

# 6. Moving average plot with shaded confidence (bottom right)
ax6 = fig.add_subplot(gs[1, 2])
from scipy.ndimage import gaussian_filter1d

# Calculate moving average and std dev
smoothed1 = gaussian_filter1d(y1, sigma=3)
smoothed2 = gaussian_filter1d(y2, sigma=3)
std1 = np.std(y1 - smoothed1)
std2 = np.std(y2 - smoothed2)

ax6.plot(x, smoothed1, 'b-', linewidth=2, label='sin(x) trend')
ax6.fill_between(x, smoothed1 - std1, smoothed1 + std1, color='blue', alpha=0.2)
ax6.plot(x, smoothed2, 'r-', linewidth=2, label='cos(x) trend')
ax6.fill_between(x, smoothed2 - std2, smoothed2 + std2, color='red', alpha=0.2)
ax6.set_title('Smoothed Trends with Confidence', fontweight='bold')
ax6.set_xlabel('X values')
ax6.set_ylabel('Smoothed value')
ax6.legend()
ax6.grid(True, alpha=0.3)

# Add overall title and description
fig.suptitle('Comprehensive Data Analysis Example', fontsize=20, fontweight='bold', y=0.98)
plt.figtext(0.5, 0.92, 'Multiple visualization techniques applied to noisy sine and cosine data', 
           ha='center', fontsize=14, fontstyle='italic')

plt.tight_layout()
plt.subplots_adjust(top=0.88)  # Make room for title
plt.show()
```
