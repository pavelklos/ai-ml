## 1. Introduction to Categorical Data Visualization

Categorical data represents variables that can be divided into distinct groups or categories. Unlike numerical data, categorical variables don't have a natural ordering or meaningful mathematical operations between them. Visualizing categorical data effectively helps reveal patterns, distributions, and relationships that might not be apparent in tabular form.

```python
# Import essential libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set styling for better visuals
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Load sample dataset
titanic = sns.load_dataset('titanic')
print(titanic.head())

# Check categorical columns
cat_columns = titanic.select_dtypes(include=['object', 'category']).columns
print("Categorical columns:", list(cat_columns))

# Display basic information about categorical variables
for col in cat_columns:
    print(f"\n{col} value counts:")
    print(titanic[col].value_counts())
    print(f"Number of unique values: {titanic[col].nunique()}")
```

Categorical data can be:
- **Nominal**: Categories with no inherent order (e.g., gender, country, color)
- **Ordinal**: Categories with a natural order (e.g., education level, satisfaction rating)

When visualizing categorical data, the goal is to show:
- Frequency distribution of categories
- Relationships between categorical variables
- Relationships between categorical and numerical variables
- Patterns and trends within categories

## 2. Bar Charts and Count Plots

Bar charts and count plots are the most common and intuitive ways to visualize categorical data. They display the frequency or count of observations in each category.

```python
# Create a figure with subplots
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# Simple bar chart with matplotlib
gender_counts = titanic['sex'].value_counts()
axes[0].bar(gender_counts.index, gender_counts.values, color=['#3498db', '#e74c3c'])
axes[0].set_title('Passenger Count by Gender (Matplotlib)')
axes[0].set_ylabel('Count')
axes[0].set_xlabel('Gender')

# Count plot with seaborn
sns.countplot(data=titanic, x='class', hue='survived', ax=axes[1], palette='viridis')
axes[1].set_title('Passenger Count by Class and Survival')
axes[1].set_xlabel('Passenger Class')
axes[1].set_ylabel('Count')
axes[1].legend(title='Survived', labels=['No', 'Yes'])

plt.tight_layout()
plt.show()

# Horizontal bar chart for longer category names
plt.figure(figsize=(10, 6))
sns.countplot(data=titanic, y='embark_town', palette='Set2')
plt.title('Passenger Count by Embarkation Town')
plt.xlabel('Count')
plt.ylabel('Embarkation Town')
plt.tight_layout()
plt.show()

# Normalized bar chart (percentage)
plt.figure(figsize=(10, 6))
# Calculate percentages
class_survival = pd.crosstab(titanic['class'], titanic['survived'], normalize='index') * 100
class_survival.plot(kind='bar', stacked=True, color=['#e74c3c', '#2ecc71'])
plt.title('Survival Rate by Passenger Class')
plt.xlabel('Passenger Class')
plt.ylabel('Percentage (%)')
plt.legend(title='Survived', labels=['No', 'Yes'])
plt.xticks(rotation=0)
plt.tight_layout()
plt.show()
```

Key considerations for bar charts:
- Always start the y-axis at zero to avoid misleading visuals
- Use consistent colors for the same categories across multiple charts
- For many categories, consider using horizontal bar charts
- Consider sorting bars by frequency for better readability
- Use normalized bars (percentages) when comparing proportions across groups

## 3. Box Plots for Categorical vs. Numerical Data

Box plots are excellent for showing the distribution of numerical data across different categories. They display the median, quartiles, and potential outliers in each category.

```python
# Create a figure with subplots
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# Simple box plot comparing age distribution by gender
sns.boxplot(data=titanic, x='sex', y='age', ax=axes[0])
axes[0].set_title('Age Distribution by Gender')
axes[0].set_xlabel('Gender')
axes[0].set_ylabel('Age (years)')

# Box plot with multiple categories
sns.boxplot(data=titanic, x='class', y='age', hue='survived', ax=axes[1], palette='Set2')
axes[1].set_title('Age Distribution by Class and Survival')
axes[1].set_xlabel('Passenger Class')
axes[1].set_ylabel('Age (years)')
axes[1].legend(title='Survived', labels=['No', 'Yes'])

plt.tight_layout()
plt.show()

# Advanced box plot with ordered categories and custom colors
# Create a new categorical variable based on age groups
titanic['age_group'] = pd.cut(titanic['age'], bins=[0, 12, 18, 35, 60, 100], 
                             labels=['Child', 'Teen', 'Young Adult', 'Adult', 'Senior'])

plt.figure(figsize=(10, 6))
sns.boxplot(data=titanic, x='age_group', y='fare', order=['Child', 'Teen', 'Young Adult', 'Adult', 'Senior'])
plt.title('Fare Distribution by Age Group')
plt.xlabel('Age Group')
plt.ylabel('Fare ($)')
plt.tight_layout()
plt.show()
```

Box plots help to answer questions like:
- How does a numeric variable (like age or fare) vary across different categories?
- Which category has the highest/lowest median value?
- Which category has the most/least variability?
- Are there outliers in specific categories?

## 4. Categorical Heatmaps

Heatmaps are powerful for visualizing relationships between two categorical variables, with color representing frequency, correlation, or another metric.

```python
# Create a cross-tabulation of two categorical variables
survival_class_sex = pd.crosstab(titanic['sex'], [titanic['class'], titanic['survived']])
print(survival_class_sex)

# Reshape for better heatmap visualization
survival_by_class_sex = pd.crosstab([titanic['sex']], [titanic['class'], titanic['survived']])
survival_pivot = survival_by_class_sex.unstack().reset_index()
survival_pivot.columns = ['Class', 'Survived', 'Gender', 'Count']
survival_pivot_table = survival_pivot.pivot_table(index=['Gender'], 
                                                 columns=['Class', 'Survived'], 
                                                 values='Count')

# Create a heatmap
plt.figure(figsize=(12, 6))
sns.heatmap(survival_pivot_table, annot=True, cmap='YlGnBu', fmt='d', linewidths=0.5)
plt.title('Survival Count by Gender, Class, and Survival Status')
plt.tight_layout()
plt.show()

# Simple categorical correlation heatmap
# Convert categorical variables to numeric for correlation
cat_encoded = pd.get_dummies(titanic[['sex', 'class', 'embarked', 'survived']])
correlation = cat_encoded.corr()

plt.figure(figsize=(10, 8))
sns.heatmap(correlation, annot=True, cmap='coolwarm', vmin=-1, vmax=1, linewidths=0.5)
plt.title('Correlation Between Categorical Variables (One-Hot Encoded)')
plt.tight_layout()
plt.show()
```

Heatmaps are particularly useful for:
- Showing the distribution of observations across combinations of categories
- Identifying patterns and relationships between categorical variables
- Visualizing contingency tables or cross-tabulations
- Displaying correlations between categorical variables when properly encoded

## 5. Violin and Strip Plots

Violin plots combine aspects of box plots with kernel density plots to show the distribution shape of numerical data across categories. Strip plots show individual data points, which can be helpful for smaller datasets.

```python
# Create a figure with violin plots
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# Violin plot
sns.violinplot(data=titanic, x='class', y='age', hue='survived', split=True, ax=axes[0])
axes[0].set_title('Age Distribution by Class and Survival')
axes[0].set_xlabel('Passenger Class')
axes[0].set_ylabel('Age (years)')

# Strip plot with jitter
sns.stripplot(data=titanic, x='class', y='age', hue='survived', dodge=True, 
             alpha=0.5, jitter=True, ax=axes[1])
axes[1].set_title('Individual Age Distribution by Class and Survival')
axes[1].set_xlabel('Passenger Class')
axes[1].set_ylabel('Age (years)')

plt.tight_layout()
plt.show()

# Combining violin and strip plots
plt.figure(figsize=(12, 6))
sns.violinplot(data=titanic, x='class', y='fare', inner=None, palette='pastel')
sns.stripplot(data=titanic, x='class', y='fare', color='black', alpha=0.5, jitter=True)
plt.title('Fare Distribution by Passenger Class')
plt.xlabel('Passenger Class')
plt.ylabel('Fare ($)')
plt.tight_layout()
plt.show()
```

Violin and strip plots help to:
- Show the full distribution shape of data across categories
- Compare distributions between multiple categories
- Identify multi-modal distributions within categories
- View individual data points while still showing overall patterns

## 6. Categorical Scatter Plots

For visualizing relationships between categorical and numerical variables, or between two categorical variables with a numerical metric, categorical scatter plots offer insights that regular scatter plots cannot.

```python
# Create a figure for categorical scatter plots
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# Categorical scatter plot: survival by age and class
sns.stripplot(data=titanic, x='age', y='class', hue='survived', dodge=True, 
             jitter=0.25, alpha=0.7, ax=axes[0])
axes[0].set_title('Survival by Age and Class')
axes[0].set_xlabel('Age (years)')
axes[0].set_ylabel('Passenger Class')
axes[0].legend(title='Survived', labels=['No', 'Yes'])

# Categorical point plot: survival rate by class and sex
sns.pointplot(data=titanic, x='class', y='survived', hue='sex', dodge=0.5, 
             markers=['o', 's'], linestyles=['-', '--'], ax=axes[1])
axes[1].set_title('Survival Rate by Class and Gender')
axes[1].set_xlabel('Passenger Class')
axes[1].set_ylabel('Survival Rate')
axes[1].set_ylim(0, 1)

plt.tight_layout()
plt.show()

# Categorical scatter plot with size representing another variable
plt.figure(figsize=(10, 6))

# Group data to get average fare by class, sex, and survival status
grouped_data = titanic.groupby(['class', 'sex', 'survived'])['fare'].mean().reset_index()

# Create bubble chart with size representing average fare
sns.scatterplot(data=grouped_data, x='class', y='sex', hue='survived', 
               size='fare', sizes=(50, 500), alpha=0.7, palette='deep')
plt.title('Average Fare by Class, Gender, and Survival')
plt.xlabel('Passenger Class')
plt.ylabel('Gender')
plt.legend(title='Survived', labels=['No', 'Yes'])
plt.tight_layout()
plt.show()
```

Categorical scatter plots are useful for:
- Showing the distribution of individual points across categories
- Identifying patterns and clusters within categorical groups
- Visualizing how a numerical variable relates to categorical groups
- Adding an additional dimension through color, size, or shape

## 7. Swarm Plots for Distribution Visualization

Swarm plots are similar to strip plots but avoid overlapping points by arranging them in a cluster along the categorical axis. This makes them excellent for showing the exact distribution of data within each category.

```python
# Create swarm plots
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# Simple swarm plot
sns.swarmplot(data=titanic, x='class', y='age', ax=axes[0])
axes[0].set_title('Age Distribution by Passenger Class')
axes[0].set_xlabel('Passenger Class')
axes[0].set_ylabel('Age (years)')

# Swarm plot with additional categorical variable
sns.swarmplot(data=titanic, x='class', y='age', hue='survived', dodge=True, ax=axes[1])
axes[1].set_title('Age Distribution by Class and Survival')
axes[1].set_xlabel('Passenger Class')
axes[1].set_ylabel('Age (years)')
axes[1].legend(title='Survived', labels=['No', 'Yes'])

plt.tight_layout()
plt.show()

# Combining box plot with swarm plot
plt.figure(figsize=(12, 6))
sns.boxplot(data=titanic[titanic['age'].notna()], x='class', y='age', color='lightgray')
sns.swarmplot(data=titanic[titanic['age'].notna()], x='class', y='age', hue='sex', dodge=True)
plt.title('Age Distribution by Passenger Class and Gender')
plt.xlabel('Passenger Class')
plt.ylabel('Age (years)')
plt.tight_layout()
plt.show()
```

Swarm plots are particularly effective when:
- The dataset is relatively small to medium sized
- You want to see every individual data point without overlap
- You need to reveal the exact distribution shape within categories
- You're combining with box plots to show both statistics and raw data

## 8. Advanced Categorical Visualization Techniques

Beyond the basic techniques, there are several advanced methods for visualizing categorical data that can reveal more complex patterns and relationships.

```python
# Create facet grid for multi-dimensional categorical visualization
g = sns.FacetGrid(titanic, col='class', row='sex', height=4, aspect=1.2)
g.map_dataframe(sns.histplot, x='age', bins=20, kde=True)
g.set_axis_labels("Age (years)", "Count")
g.set_titles("Class: {col_name} | Gender: {row_name}")
g.fig.subplots_adjust(top=0.9)
g.fig.suptitle('Age Distribution by Class and Gender', fontsize=16)
plt.tight_layout()
plt.show()

# Mosaic plot using statsmodels
from statsmodels.graphics.mosaicplot import mosaic

plt.figure(figsize=(10, 6))
mosaic(titanic, ['sex', 'survived', 'class'], title='Survival by Gender and Class')
plt.tight_layout()
plt.show()

# Parallel categories diagram using plotly
import plotly.express as px

# Create a smaller sample for clarity
titanic_sample = titanic.dropna(subset=['age', 'fare']).sample(n=200, random_state=42)

fig = px.parallel_categories(titanic_sample, 
                            dimensions=['sex', 'class', 'survived', 'embark_town'],
                            color='fare', color_continuous_scale='Viridis',
                            labels={'sex': 'Gender', 'class': 'Class', 
                                   'survived': 'Survived', 'embark_town': 'Embarkation'})
fig.update_layout(title='Parallel Categories Diagram: Relationships between Categories')
fig.show()
```

Advanced visualization techniques offer:
- Multidimensional views of categorical relationships
- Interactive exploration of categorical data
- More intuitive visualization of complex categorical patterns
- Integration of numerical variables with categorical structure

## 9. Best Practices for Categorical Data Visualization

Creating effective visualizations for categorical data requires careful consideration of various factors:

```python
# Example: Improving a basic categorical plot
# BAD: Too many categories with long names and poor orientation
plt.figure(figsize=(10, 6))
bad_data = pd.DataFrame({
    'very_long_category_name': ['Category A With Very Long Name', 
                              'Category B With Even Longer Name',
                              'Category C With Extremely Long Name',
                              'Category D With Unnecessarily Long Name',
                              'Category E With Ridiculously Long Name'],
    'values': [23, 45, 12, 78, 34]
})
plt.bar(bad_data['very_long_category_name'], bad_data['values'])
plt.title('A Poor Categorical Plot')
plt.xlabel('Categories')
plt.ylabel('Values')
plt.xticks(rotation=15)  # Not enough rotation
plt.tight_layout()
plt.show()

# GOOD: Proper orientation, sorted, with clear labels
plt.figure(figsize=(10, 6))
# Sort by values and use horizontal orientation
bad_data = bad_data.sort_values('values')
plt.barh(bad_data['very_long_category_name'], bad_data['values'], color='teal')
plt.title('Improved Categorical Plot')
plt.xlabel('Values')
plt.ylabel('Categories')
# Add value labels
for i, v in enumerate(bad_data['values']):
    plt.text(v + 1, i, str(v), va='center')
plt.tight_layout()
plt.show()

# Example: Using appropriate color schemes
plt.figure(figsize=(12, 6))
ax = plt.subplot(121)
# BAD: Rainbow colors for unordered categories
sns.countplot(data=titanic, x='class', ax=ax, palette='rainbow')
ax.set_title('Poor Color Choice for Categories')

ax = plt.subplot(122)
# GOOD: Distinct but harmonious colors for nominal categories
sns.countplot(data=titanic, x='class', ax=ax, palette='Set2')
ax.set_title('Better Color Choice for Categories')

plt.tight_layout()
plt.show()
```

Best practices include:
- **Order categories meaningfully**: Alphabetical, by frequency, or by a natural ordering
- **Handle long category names**: Use horizontal bar charts or abbreviate names
- **Choose appropriate color schemes**: Use qualitative schemes for nominal data, sequential or diverging schemes for ordinal data
- **Consider the audience**: Choose visualizations and colors that are accessible to all, including those with color vision deficiencies
- **Simplify when necessary**: Group small categories into "Other" if there are too many categories
- **Add context**: Include totals, percentages, or relevant statistics
- **Use interactive elements**: For complex categorical data, consider interactive visualizations
- **Be consistent**: Use the same colors for the same categories across multiple charts

## 10. Summary

Visualizing categorical data effectively is crucial for understanding patterns and relationships in data that doesn't have a natural numeric representation. The key points to remember are:

1. **Choose the right visualization** based on your data and what you want to communicate:
   - Bar charts and count plots for frequencies
   - Box plots and violin plots to relate categorical and numerical data
   - Heatmaps for relationships between categories
   - Strip and swarm plots for detailed distributions

2. **Consider the structure of your categorical data**:
   - Are categories nominal (unordered) or ordinal (ordered)?
   - How many unique categories do you have?
   - Are you comparing across multiple categorical variables?

3. **Enhance your visualizations** with appropriate:
   - Colors that distinguish categories clearly
   - Labels that provide context
   - Ordering that highlights important patterns
   - Combinations of techniques for complex data

4. **Follow best practices** for clarity and accessibility:
   - Avoid clutter and overloading with too many categories
   - Use consistent colors and styles
   - Consider accessibility for color-blind viewers
   - Choose interactive visualizations for complex categorical relationships

With these techniques and principles, you can create informative and compelling visualizations that effectively communicate patterns and insights in categorical data, making your analysis more accessible and impactful.
