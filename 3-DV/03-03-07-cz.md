## Úvod

Vizualizace velkých datových sad představuje jedinečné výzvy, které přesahují techniky používané pro malé až střední datové soubory. Moderní datové sady mohou snadno dosáhnout miliard záznamů, což činí tradiční přístupy k vizualizaci nepraktickými nebo dokonce nemožnými. Tento dokument zkoumá strategie, techniky a nástroje pro efektivní vizualizaci rozsáhlých dat pomocí Pythonu.

Vizualizace velkých datových sad vyžaduje řešení několika klíčových omezení:
- Omezení paměti
- Výpočetní výkon
- Vizuální škálovatelnost (vyhnutí se překreslování)
- Interaktivní odezva
- Smysluplná reprezentace komplexních vzorů

Probereme, jak překonat tato omezení pomocí pečlivého zpracování dat, specializovaných nástrojů a optimalizačních technik.

## Výzvy při vizualizaci velkých datových sad

Než se ponoříme do řešení, pojďme pochopit základní výzvy:

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import time
import psutil

# Funkce pro kontrolu využití paměti
def check_memory():
    process = psutil.Process()
    memory_info = process.memory_info()
    memory_mb = memory_info.rss / (1024 * 1024)
    return memory_mb

# Vygenerovat datové sady různých velikostí
sizes = [10_000, 100_000, 1_000_000, 10_000_000]
timings = []
memory_usage = []

plt.figure(figsize=(15, 10))

for i, size in enumerate(sizes):
    # Zaznamenat počáteční paměť
    start_mem = check_memory()
    
    # Generovat data
    df = pd.DataFrame({
        'x': np.random.randn(size),
        'y': np.random.randn(size)
    })
    
    # Zaznamenat paměť po vytvoření dat
    after_data_mem = check_memory()
    
    # Změřit čas vykreslování
    start_time = time.time()
    
    # Vytvořit subplot
    plt.subplot(2, 2, i+1)
    
    # Jednoduchý bodový graf
    plt.scatter(df['x'], df['y'], s=1, alpha=0.1)
    plt.title(f'{size:,} Bodů')
    plt.tight_layout()
    
    end_time = time.time()
    
    # Zaznamenat konečnou paměť
    end_mem = check_memory()
    
    # Uložit metriky
    timings.append(end_time - start_time)
    memory_usage.append(end_mem - start_mem)
    
    print(f"Velikost: {size:,} bodů")
    print(f"  Čas vykreslení: {timings[-1]:.2f} sekund")
    print(f"  Použitá paměť: {memory_usage[-1]:.2f} MB")
    print(f"  Paměť pro DataFrame: {after_data_mem - start_mem:.2f} MB")
    print()

plt.tight_layout()
# plt.savefig('scaling_challenge.png', dpi=300, bbox_inches='tight')  # Uložit v případě potřeby
plt.show()
```

Hlavní výzvy zahrnují:

1. **Paměťová omezení**: Velké datové sady mohou přesáhnout dostupnou RAM.
2. **Výpočetní škálovatelnost**: Vykreslování milionů bodů může být bolestně pomalé.
3. **Vizuální škálovatelnost**: Překreslování činí vzory nerozeznatelné.
4. **Interaktivní výkon**: Uživatelské interakce se při velkém objemu dat stávají neresponzivní.
5. **Šířka pásma sítě**: Přenos velkých datových sad do prohlížeče je nepraktický.

## Techniky redukce dat

### Vzorkování

Vzorkování je jedním z nejjednodušších přístupů ke zpracování velkých dat - vizualizuje se reprezentativní podmnožina místo celé datové sady.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs

# Vygenerovat syntetická data s klastry
n_samples = 1_000_000
X, y = make_blobs(n_samples=n_samples, centers=5, random_state=42)
df = pd.DataFrame(X, columns=['x', 'y'])
df['cluster'] = y

# Vytvořit graf s různými míry vzorkování
plt.figure(figsize=(16, 4))

# Původní data (může být pomalé pro velmi velké datové sady)
plt.subplot(141)
plt.scatter(df['x'][:10000], df['y'][:10000], c=df['cluster'][:10000], 
           s=3, alpha=0.5, cmap='viridis')
plt.title('Prvních 10 000 bodů')

# Náhodné vzorkování
sample_sizes = [0.001, 0.01, 0.1]
for i, sample_size in enumerate(sample_sizes):
    plt.subplot(142 + i)
    
    # Vzít náhodný vzorek
    sample_df = df.sample(frac=sample_size, random_state=42)
    
    plt.scatter(sample_df['x'], sample_df['y'], c=sample_df['cluster'], 
               s=3, alpha=0.5, cmap='viridis')
    plt.title(f'Náhodný {sample_size*100:.1f}% vzorek\n({len(sample_df):,} bodů)')

plt.tight_layout()
plt.show()

# Stratifikované vzorkování pro zachování distribuce tříd
plt.figure(figsize=(14, 5))

plt.subplot(121)
# Náhodné vzorkování
random_sample = df.sample(n=5000, random_state=42)
plt.scatter(random_sample['x'], random_sample['y'], c=random_sample['cluster'], 
           s=3, alpha=0.7, cmap='viridis')
plt.title('Náhodné vzorkování (5 000 bodů)')

plt.subplot(122)
# Stratifikované vzorkování
stratified_sample = df.groupby('cluster', group_keys=False).apply(
    lambda x: x.sample(n=1000, random_state=42))
plt.scatter(stratified_sample['x'], stratified_sample['y'], c=stratified_sample['cluster'], 
           s=3, alpha=0.7, cmap='viridis')
plt.title('Stratifikované vzorkování (5 000 bodů)')

plt.tight_layout()
plt.show()
```

### Agregace

Agregování dat do souhrnných statistik před vizualizací může dramaticky zmenšit velikost dat při zachování vzorů.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Vygenerovat velkou datovou sadu (10 milionů bodů)
np.random.seed(42)
n_points = 10_000_000

# Vytvořit DataFrame s x, y souřadnicemi a hodnotou
df = pd.DataFrame({
    'x': np.random.normal(0, 10, n_points),
    'y': np.random.normal(0, 10, n_points),
    'value': np.random.uniform(0, 100, n_points)
})

# Zaokrouhlit souřadnice k vytvoření binů (efektivně agregace)
df['x_bin'] = np.round(df['x'], 0)  # Zaokrouhlit na nejbližší celé číslo
df['y_bin'] = np.round(df['y'], 0)

# Agregovat podle binů, výpočet průměru, počtu a součtu hodnot
agg_df = df.groupby(['x_bin', 'y_bin']).agg(
    mean_value=('value', 'mean'),
    count=('value', 'count'),
    sum_value=('value', 'sum')
).reset_index()

print(f"Původní data: {len(df):,} bodů")
print(f"Agregovaná data: {len(agg_df):,} bodů")
print(f"Kompresní poměr: {len(df) / len(agg_df):.1f}x")

# Vizualizovat agregovaná data
plt.figure(figsize=(15, 5))

# Graf 1: Velikost bodu představuje počet
plt.subplot(131)
plt.scatter(agg_df['x_bin'], agg_df['y_bin'], s=agg_df['count']/50, 
           alpha=0.5, c=agg_df['mean_value'], cmap='viridis')
plt.colorbar(label='Průměrná hodnota')
plt.title('Velikost = počet')

# Graf 2: Barva představuje počet
plt.subplot(132)
plt.scatter(agg_df['x_bin'], agg_df['y_bin'], s=10, 
           c=agg_df['count'], cmap='plasma')
plt.colorbar(label='Počet')
plt.title('Barva = počet')

# Graf 3: Teplotní mapa počtů
plt.subplot(133)
# Převést na 2D mřížku
heatmap_data = agg_df.pivot_table(index='y_bin', columns='x_bin', values='count')
sns.heatmap(heatmap_data, cmap='YlOrRd')
plt.title('Teplotní mapa počtů')

plt.tight_layout()
plt.show()
```

### Binning

Binning je obzvláště užitečný pro vytváření histogramů, teplotních map a grafů hustoty.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.colors import LogNorm

# Vygenerovat 5 milionů bodů se zajímavou distribucí
np.random.seed(42)
n = 5_000_000

# Vytvořit několik klastrů
centers = [(-5, -5), (0, 0), (5, 5), (-5, 5), (5, -5)]
points = []

for cx, cy in centers:
    cluster_points = np.random.normal(loc=[cx, cy], scale=[1, 1], size=(n // 5, 2))
    points.append(cluster_points)
    
# Kombinovat všechny body
points = np.vstack(points)
df = pd.DataFrame(points, columns=['x', 'y'])

# Vytvořit 2D histogram (binning)
plt.figure(figsize=(15, 5))

plt.subplot(131)
# Základní 2D histogram
hist = plt.hist2d(df['x'], df['y'], bins=50, cmap='viridis')
plt.colorbar(label='Počet')
plt.title('2D histogram')

plt.subplot(132)
# 2D histogram s logaritmickým měřítkem pro lepší vizualizaci rozdílů v hustotě
hist = plt.hist2d(df['x'], df['y'], bins=100, cmap='inferno', norm=LogNorm())
plt.colorbar(label='Log(počet)')
plt.title('2D histogram s logaritmickým měřítkem')

plt.subplot(133)
# Hexbin graf - další přístup k binningu
plt.hexbin(df['x'], df['y'], gridsize=50, cmap='cividis', bins='log')
plt.colorbar(label='Log(počet)')
plt.title('Hexbin graf')

plt.tight_layout()
plt.show()
```

### Filtrování

Filtrování umožňuje odstranit méně důležité datové body a zaměřit se na ty nejvýznamnější.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Vygenerovat syntetická data
np.random.seed(42)
n = 1_000_000

# Vytvořit DataFrame s x, y souřadnicemi a hodnotou
df = pd.DataFrame({
    'x': np.random.normal(0, 1, n),
    'y': np.random.normal(0, 1, n),
    'importance': np.random.exponential(1, n)  # Nějaká míra důležitosti
})

plt.figure(figsize=(15, 5))

# Původní bodový graf (zobrazení pouze vzorku pro rychlost)
plt.subplot(131)
sample = df.sample(10000)  # Jen pro ukázku
plt.scatter(sample['x'], sample['y'], s=1, alpha=0.5)
plt.title('Vzorek původních dat\n(10 000 bodů)')

# Filtrování podle prahu
threshold = np.percentile(df['importance'], 90)  # Ponechat horních 10 % nejdůležitějších bodů
filtered_df = df[df['importance'] > threshold]

plt.subplot(132)
plt.scatter(filtered_df['x'], filtered_df['y'], s=1, alpha=0.5)
plt.title(f'Horních 10 % důležitých bodů\n({len(filtered_df):,} bodů)')

# Filtrování podle hustoty - ponechat body v méně hustých oblastech
from scipy.spatial import cKDTree

# Použít podmnožinu pro vytvoření KD-stromu (pro výkon)
subset = df.sample(100000)
tree = cKDTree(subset[['x', 'y']])

# Dotaz na strom pro 10 nejbližších sousedů každého bodu
dists, _ = tree.query(subset[['x', 'y']], k=10)

# Vypočítat průměrnou vzdálenost k sousedům (vyšší = méně husté oblasti)
subset['density_measure'] = dists.mean(axis=1)

# Ponechat body v méně hustých oblastech
sparse_points = subset.nlargest(10000, 'density_measure')

plt.subplot(133)
plt.scatter(sparse_points['x'], sparse_points['y'], s=1, alpha=0.5)
plt.title('Body v řídkých oblastech\n(10 000 bodů)')

plt.tight_layout()
plt.show()
```

## Specializované knihovny pro velká data

### Datashader

Datashader je systém grafického zpracování, který transformuje velká data do smysluplných vizualizací renderováním dat do agregačních polí a následnou transformací těchto polí na obrázky.

```python
import pandas as pd
import numpy as np
import datashader as ds
import datashader.transfer_functions as tf
import datashader.colors as dc
from datashader.utils import export_image
import matplotlib.pyplot as plt
from matplotlib.colors import LinearSegmentedColormap
from PIL import Image

# Vygenerovat velkou datovou sadu (10 milionů bodů)
np.random.seed(42)
n = 10_000_000

# Vytvořit několik propletených spirál
def spiral(n_points, start, end, a, b):
    t = np.linspace(start, end, n_points)
    x = a * t * np.cos(t)
    y = b * t * np.sin(t)
    return x, y

# Vytvořit více spirál s šumem
spirals = []
for i in range(5):
    x, y = spiral(n//5, i, 10*np.pi + i, 1, 1)
    # Přidat šum
    x += np.random.normal(0, 0.3, size=len(x))
    y += np.random.normal(0, 0.3, size=len(y))
    spirals.append(np.column_stack([x, y]))

# Kombinovat všechny body
points = np.vstack(spirals)

# Přidat sloupec kategorie pro barvení
category = np.repeat(np.arange(5), n//5)

# Vytvořit DataFrame
df = pd.DataFrame({
    'x': points[:, 0],
    'y': points[:, 1],
    'category': category
})

# Vytvořit objekt Canvas
canvas = ds.Canvas(plot_width=800, plot_height=800)

# Standardní přístup k vykreslování (velmi náročný na prostředky, jen pro srovnání)
def standard_plot(df_sample):
    plt.figure(figsize=(10, 10))
    categories = df_sample['category'].unique()
    colors = plt.cm.viridis(np.linspace(0, 1, len(categories)))
    
    for i, category in enumerate(categories):
        subset = df_sample[df_sample['category'] == category]
        plt.scatter(subset['x'], subset['y'], s=0.5, alpha=0.5, color=colors[i], label=f'Kategorie {category}')
    
    plt.legend()
    plt.title(f'Standardní bodový graf ({len(df_sample):,} bodů)')
    plt.tight_layout()
    plt.show()

# Zkusit s velmi malým vzorkem
standard_plot(df.sample(10000))

# Přístup Datashader pro všechny body
# Vykreslit body
agg = canvas.points(df, 'x', 'y')

# Převést na obrázek
img = tf.shade(agg, cmap=['navy', 'darkblue', 'blue', 'cyan', 'yellow', 'red', 'darkred'])

# Zobrazit obrázek
plt.figure(figsize=(10, 10))
plt.imshow(img.to_pil())
plt.axis('off')
plt.title(f'Datashader vizualizace ({n:,} bodů)')
plt.show()

# Obarvení podle kategorie
agg = canvas.points(df, 'x', 'y', ds.count_cat('category'))
img = tf.shade(agg, color_key=dc.Spectral10, how='eq_hist')

plt.figure(figsize=(10, 10))
plt.imshow(img.to_pil())
plt.axis('off')
plt.title(f'Datashader s kategoriemi ({n:,} bodů)')
plt.show()

# Vytvořit pipeline datashader s pokročilejším barvením
cvs = ds.Canvas(plot_width=800, plot_height=800)
agg = cvs.points(df, 'x', 'y')
img = tf.shade(agg, cmap=dc.inferno)
img = tf.set_background(img, 'black')

plt.figure(figsize=(10, 10))
plt.imshow(img.to_pil())
plt.axis('off')
plt.title('Vizualizace hustoty s Datashader')
plt.show()
```

### Vaex

Vaex je vysoce výkonná knihovna DataFrame navržená speciálně pro práci s velkými tabulkovými datovými sadami, které přesahují velikost paměti.

```python
# Instalace vaex v případě potřeby
# !pip install vaex

import numpy as np
import pandas as pd
import vaex
import matplotlib.pyplot as plt

# Vygenerovat velkou datovou sadu (20 milionů bodů)
np.random.seed(42)
n = 20_000_000

# Vytvořit data - 2D distribuce s více klastry
centers = [(-5, -5), (0, 0), (5, 5), (-5, 5), (5, -5)]
points = []

for cx, cy in centers:
    cluster_points = np.random.normal(loc=[cx, cy], scale=[1, 1], size=(n // 5, 2))
    points.append(cluster_points)
    
# Kombinovat všechny body
points = np.vstack(points)

# Vytvořit Vaex DataFrame
df_vaex = vaex.from_arrays(x=points[:, 0], y=points[:, 1])

print(f"Velikost Vaex DataFrame: {len(df_vaex):,} řádků")
print(f"Využití paměti: {df_vaex.memory_usage_total / (1024**3):.2f} GB (virtuální)")

# Vytvoření vizualizací
plt.figure(figsize=(15, 5))

# 1. Standardní histogram

counts, edges = df_vaex.count(binby=['x', 'y'],

plt.subplot(133)
hexbin_agg = df_vaex.count(binby=['x', 'y'], 
                         limits=[(-10, 10), (-10, 10)],

plt.hexbin(points[:10000, 0], points[:10000, 1], 
          gridsize=50, cmap='cividis', bins='log')
plt.colorbar(label='log(Počet)')
plt.title('Hexbin graf (vzorek)')

plt.tight_layout()
plt.show()

# Mapa hustoty s využitím schopností Vaexu
fig, ax = plt.subplots(figsize=(10, 8))
df_vaex.plot(ax, 'x', 'y', limits=[[-10, 10], [-10, 10]], f='log1p', colormap='viridis')
plt.title(f'Vaex graf hustoty ({n:,} bodů)')
plt.show()
```

### HoloViews

HoloViews kombinovaný s Datashaderem poskytuje vysokoúrovňové rozhraní pro interaktivní vizualizaci velkých datových sad.

```python
# Instalace potřebných balíčků v případě potřeby
# !pip install holoviews datashader bokeh

import holoviews as hv
import datashader as ds
from holoviews.operation.datashader import datashade, shade, dynspread, spread
import pandas as pd
import numpy as np

# Inicializace HoloViews s Bokeh backendem
hv.extension('bokeh')

# Vygenerovat velkou datovou sadu (5 milionů bodů)
np.random.seed(42)
n = 5_000_000

# Vytvořit spirálový vzor
theta = np.linspace(0, 8*np.pi, n)
radius = np.linspace(0, 1, n) + np.random.normal(0, 0.1, n)
x = radius * np.cos(theta)
y = radius * np.sin(theta)

# Vytvořit DataFrame
df = pd.DataFrame({'x': x, 'y': y})

# Vytvořit HoloViews Points objekt
points = hv.Points(df)

# Aplikovat datashader na body
datashaded = datashade(points, cmap='inferno', dynamic=False)

# Přidat rozptyl pro lepší viditelnost
spread_points = dynspread(datashaded, threshold=0.5)

# Zobrazit vizualizaci
# To by bylo zobrazeno v notebooku
# spread_points

# Pro statické zobrazení v Markdown:
print("HoloViews s Datashaderem vytváří interaktivní vizualizace.")
print("V prostředí notebooku by výše uvedená vizualizace byla dynamická a interaktivní.")
print("Dokáže efektivně vykreslovat miliony bodů při zachování interaktivity.")

# Vytvořit složitější příklad s vrstvami

# Vygenerovat více distribucí
points_list = []

# Vytvořit několik gaussových klastrů
for i in range(5):
    x = np.random.normal(i*2, 0.5, n//5)
    y = np.random.normal(i, 0.5, n//5)
    points_list.append(hv.Points((x, y), label=f'Klastr {i+1}'))

# Kombinovat do HoloViews překrytí
points_overlay = hv.Overlay(points_list)

# Aplikovat datashader
datashaded_overlay = datashade(points_overlay, aggregator=ds.count_cat('label'), cmap='Category10')

# Pro zobrazení v notebooku:
# datashaded_overlay

print("\nHoloViews může také vytvářet komplexní, vrstvené vizualizace s kategoriálním barvením.")
print("Každou vrstvu lze interaktivně zapínat a vypínat v prostředí notebooku.")
```

## Strategie vizualizace v prohlížeči

### Vykreslování založené na WebGL

Použití WebGL může výrazně urychlit vykreslování velkých datových sad v prohlížeči.

```python
import pandas as pd
import numpy as np
import plotly.express as px
import plotly.graph_objects as go

# Vygenerovat velkou datovou sadu (1 milión bodů)
np.random.seed(42)
n = 1_000_000

# Vytvořit klastry dat
x = np.concatenate([
```

```python
# 2. Vytvořit histogram pro každý oddíl
def partition_histogram(df):
    """Vytvořit histogram pro jeden oddíl"""
    hist, edges = np.histogram(df['x'], bins=20, range=(-5, 15))
    return pd.Series(hist, index=edges[:-1])

# Aplikovat na každý oddíl paralelně
histograms = dask_df.map_partitions(partition_histogram).compute()

# Vykreslit kombinovaný výsledek
plt.figure(figsize=(12, 6))
plt.bar(histograms.index, histograms, width=1, alpha=0.7)
plt.title('Distribuovaný výpočet histogramu')
plt.xlabel('hodnota x')
plt.ylabel('Počet')
plt.tight_layout()
plt.show()

# 3. Vytvořit 2D histogram pomocí distribuovaného výpočtu
# Ve skutečnosti bychom použili vestavěný histogram2d Dasku, ale ukážeme přístup

# Definovat globální biny
x_range = (-5, 15)  
y_range = (-10, 10)
bins = 100

# Vytvořit dask pole pro histogram
hist_array = da.zeros((bins, bins), chunks=(25, 25))  # Rozdělit i výstup

# Vypočítat hrany binů
x_edges = np.linspace(x_range[0], x_range[1], bins+1)
y_edges = np.linspace(y_range[0], y_range[1], bins+1)

# Funkce pro aktualizaci histogramu pro oddíl
def update_hist(df):
    """Vypočítat 2D histogram pro oddíl"""
    H, _, _ = np.histogram2d(df['x'], df['y'], bins=[x_edges, y_edges], 
                           range=[x_range, y_range])
    return H

# Vypočítat histogram přes všechny oddíly (paralelně)
result = dask_df.map_partitions(update_hist).sum().compute()

# Vykreslit výsledek
plt.figure(figsize=(10, 8))
plt.imshow(result.T, origin='lower', extent=[x_range[0], x_range[1], y_range[0], y_range[1]],
          aspect='auto', cmap='viridis')

plt.title('2D histogram s využitím distribuovaného výpočtu')
plt.tight_layout()
```

```python
# Tento příklad by typicky využíval dataset NYC Taxi, který má >10GB
# Pro tuto ukázku v Markdownu vygenerujeme syntetická data inspirovaná reálným datasetem

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import datashader as ds
import datashader.transfer_functions as tf
import datashader.colors as dc
import colorcet as cc

# Vygenerování syntetických dat NYC taxi
np.random.seed(42)
n_records = 1_000_000  # Ve skutečnosti by to bylo >150 milionů záznamů

# Vytvoření lokací výchozích a cílových bodů soustředěných kolem Manhattanu
def generate_nyc_locations(n, center_lat=40.76, center_lon=-73.98, scale=0.1):
    """Vygenerování syntetických NYC souřadnic s vyšší hustotou na Manhattanu"""
    # Vytvoření základu s normálním rozdělením
    lat = np.random.normal(center_lat, scale, n)
    lon = np.random.normal(center_lon, scale, n)
    
    # Přidání struktury pro simulaci ulic
    street_effect = np.random.choice([-0.01, 0, 0.01, 0.02], size=n)
    avenue_effect = np.random.choice([-0.01, 0, 0.01, 0.02], size=n)
    
    lat += street_effect
    lon += avenue_effect
    
    # Přidání několika hotspotů (např. letiště, vlakové stanice)
    hotspots = [
        (40.73, -73.99, 0.02),  # Downtown
        (40.71, -74.01, 0.02),  # Finanční čtvrť
        (40.78, -73.96, 0.02),  # Upper East Side
        (40.75, -73.97, 0.02),  # Midtown
        (40.64, -73.78, 0.05),  # JFK letiště
        (40.77, -73.87, 0.05),  # LGA letiště
    ]
    
    # Přidání vlivu hotspotů
    for h_lat, h_lon, radius in hotspots:
        # Náhodný výběr bodů, které budou ovlivněny každým hotspotem
        mask = np.random.random(n) < 0.1
        n_affected = mask.sum()
        
        # Vygenerování bodů kolem hotspotu
        lat[mask] = np.random.normal(h_lat, radius, n_affected)
        lon[mask] = np.random.normal(h_lon, radius, n_affected)
    
    return lat, lon

# Vygenerování výchozích a cílových lokací
pickup_lat, pickup_lon = generate_nyc_locations(n_records)
dropoff_lat, dropoff_lon = generate_nyc_locations(n_records)

    'pickup_datetime': pd.date_range('2019-01-01', periods=n_records, freq='30s'),
    'pickup_latitude': pickup_lat,
    'pickup_longitude': pickup_lon,
    'dropoff_latitude': dropoff_lat,
    'dropoff_longitude': dropoff_lon,
    'passenger_count': np.random.choice([1, 1, 1, 2, 2, 3, 4, 5, 6], n_records),
    'trip_distance': np.random.exponential(2.5, n_records),
    'fare_amount': np.random.exponential(15, n_records),
    'tip_amount': np.random.exponential(2, n_records),
})

# Přidání vlastností založených na čase
df['hour'] = df['pickup_datetime'].dt.hour
df['day_of_week'] = df['pickup_datetime'].dt.dayofweek
df['month'] = df['pickup_datetime'].dt.month

print(f"Syntetický dataset NYC Taxi vytvořen s {len(df):,} záznamy")
print("\nUkázkové údaje:")
print(df.head())

print("\nVizualizace rozsáhlého taxi datasetu pomocí pokročilých technik:")

dropoff_agg = canvas.points(df, 'dropoff_longitude', 'dropoff_latitude')

# Vytvoření kompozitního obrazu s různými barvami
pickup_img = tf.shade(pickup_agg, cmap=dc.blues)
dropoff_img = tf.shade(dropoff_agg, cmap=dc.reds)

composite = tf.stack(dropoff_img, pickup_img)

plt.figure(figsize=(12, 10))
plt.imshow(composite.to_pil())
plt.title('Vzorce výchozích bodů taxi (modrá) vs. cílových bodů (červená)')
plt.axis('off')
plt.tight_layout()
plt.show()

# 3. Vytvoření časové vizualizace (hodinové vzorce)
# Nejprve agregace podle hodin
hourly_counts = df.groupby('hour').size()

plt.figure(figsize=(12, 6))
plt.bar(hourly_counts.index, hourly_counts, color='steelblue')
plt.title('Objem taxi jízd podle hodiny dne')
plt.xlabel('Hodina')
plt.ylabel('Počet jízd')
plt.xticks(range(0, 24))
plt.grid(axis='y', alpha=0.3)

# 4. Agregace podle okrsků/oblastí
# Ve skutečnosti bychom použili skutečné NYC okrsky; zde vytvoříme syntetické regiony
df['precinct'] = (
```

## Osvědčené postupy

Na základě prozkoumaných technik zde jsou některé osvědčené postupy pro vizualizaci velkých datových sad:

1. **Začněte s otázkou**: Definujte, jaké poznatky hledáte, než se rozhodnete pro techniky vizualizace.

2. **Aplikujte strategicky redukci dat**:
   - Používejte vzorkování pro průzkum, ale mějte na paměti možné vychýlení vzorku.
   - Agregujte data, když detailní jednotlivé body nejsou nezbytné.
   - Zvažte redukci dimenzionality pro vysokodimenzionální data.

3. **Vyberte správné nástroje**:
   - Pro >1M bodů použijte specializované nástroje jako Datashader nebo Vaex.
   - Pro interaktivní práci použijte nástroje s podporou WebGL jako Plotly nebo Three.js.
   - Pro geografická data použijte specializované geo knihovny s podporou dlaždic.

4. **Optimalizujte vizualizační pipeline**:
   - Předpočítejte agregáty, když je to možné.
   - Používejte strategie ukládání do mezipaměti pro interaktivní vizualizace.
   - Zvažte out-of-core zpracování pro datasety větší než dostupná paměť.

5. **Navrhujte pro výkon a přehlednost**:
   - Používejte progresivní vykreslování pro okamžitou zpětnou vazbu.
   - Implementujte vzory přehled+detail pro průzkum.
   - Aplikujte vizuální hierarchie pro nasměrování pozornosti k důležitým vzorům.

6. **Řešte extrémní případy**:
   - Buďte připraveni řešit odlehlé hodnoty, které mohou zkreslit vizualizace.
   - Používejte vhodné barevné škály (často logaritmické) pro silně zešikmená data.
   - Zvažte vlastní strategie binningu pro nerovnoměrné distribuce.

7. **Vyvažujte detail a výkon**:
   - Na úrovni přehledu se zaměřte spíše na vzorce než na jednotlivé body.
   - Poskytněte mechanismy pro podrobné zkoumání zajímavých oblastí.
   - Zvažte použití adaptivního rozlišení na základě úrovně přiblížení.
