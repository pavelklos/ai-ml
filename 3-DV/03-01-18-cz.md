## 1. Úvod ke krabicovým a houslovým grafům

Krabicové a houslové grafy jsou silné vizualizační nástroje pro zobrazení distribuce numerických dat. Poskytují kompaktní způsob, jak zkoumat distribuce dat, identifikovat odlehlé hodnoty a porovnávat více distribucí vedle sebe.

Nastavme si prostředí s potřebnými knihovnami:

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení stylu pro lepší estetiku
plt.style.use('seaborn-v0_8-whitegrid')

# Nastavení seedu pro reprodukovatelnost
np.random.seed(42)

# Vytvoření vzorových dat
# Generování několika datových sad s různými distribucemi
normal_data = np.random.normal(0, 1, 1000)
skewed_data = np.random.exponential(2, 1000)
bimodal_data = np.concatenate([np.random.normal(-2, 0.5, 500), 
                              np.random.normal(2, 0.5, 500)])
uniform_data = np.random.uniform(-3, 3, 1000)

# Kombinace dat do jednoho DataFrame pro snazší vykreslování
df = pd.DataFrame({
    'Normální': normal_data,
    'Zešikmené': skewed_data,
    'Bimodální': bimodal_data,
    'Rovnoměrné': uniform_data
})

# Rychlý přehled dat
print(df.describe().round(2))
```

## 2. Porozumění komponentám krabicového grafu

Krabicový graf (také známý jako box-and-whisker plot) shrnuje distribuci dat pomocí pěti klíčových statistik:

1. **Minimum**: Nejmenší hodnota (s výjimkou odlehlých hodnot)
2. **První kvartil (Q1)**: 25. percentil
3. **Medián (Q2)**: 50. percentil
4. **Třetí kvartil (Q3)**: 75. percentil
5. **Maximum**: Největší hodnota (s výjimkou odlehlých hodnot)

Navíc mohou krabicové grafy zobrazovat **odlehlé hodnoty** jako jednotlivé body a poskytují vhled do:
- **Centrální tendence** (pomocí mediánu)
- **Variability** (pomocí mezikvartilového rozpětí)
- **Zešikmení** (porovnáním kvartilů a mediánu)
- **Odlehlých hodnot** (jako jednotlivých bodů za vousy)

```python
# Vytvoření obrázku pro vysvětlení komponent krabicového grafu
plt.figure(figsize=(10, 6))

# Generování vzorových dat pro ukázku
data = np.random.normal(0, 1, 100)
data = np.append(data, [3.5, 3.8, -3.6])  # Přidání několika odlehlých hodnot

# Vytvoření krabicového grafu pomocí matplotlib
bp = plt.boxplot(data, vert=False, patch_artist=True)

# Přizpůsobení krabicového grafu
plt.setp(bp['boxes'], facecolor='lightblue', alpha=0.7)
plt.setp(bp['medians'], color='red', linewidth=2)
plt.setp(bp['fliers'], marker='o', markersize=8, markerfacecolor='red', alpha=0.7)

# Přidání anotací pro vysvětlení komponent
plt.annotate('Minimum', xy=(bp['caps'][0].get_xdata()[0], 1.1), xytext=(bp['caps'][0].get_xdata()[0], 1.3), 
             arrowprops=dict(arrowstyle='->'), ha='center')
plt.annotate('Maximum', xy=(bp['caps'][1].get_xdata()[0], 1.1), xytext=(bp['caps'][1].get_xdata()[0], 1.3), 
             arrowprops=dict(arrowstyle='->'), ha='center')
plt.annotate('Medián (Q2)', xy=(bp['medians'][0].get_xdata().mean(), 1), xytext=(bp['medians'][0].get_xdata().mean(), 1.3), 
             arrowprops=dict(arrowstyle='->'), ha='center')
plt.annotate('První kvartil (Q1)', xy=(bp['boxes'][0].get_xdata()[0], 0.9), xytext=(bp['boxes'][0].get_xdata()[0], 0.7), 
             arrowprops=dict(arrowstyle='->'), ha='center')
plt.annotate('Třetí kvartil (Q3)', xy=(bp['boxes'][0].get_xdata()[2], 0.9), xytext=(bp['boxes'][0].get_xdata()[2], 0.7), 
             arrowprops=dict(arrowstyle='->'), ha='center')
plt.annotate('Odlehlé hodnoty', xy=(data.min(), 1), xytext=(data.min() - 0.5, 1.3), 
             arrowprops=dict(arrowstyle='->'), ha='center')

plt.yticks([])  # Skrytí značek na ose y
plt.title('Anatomie krabicového grafu', fontsize=14)
plt.xlabel('Hodnota', fontsize=12)
plt.tight_layout()
plt.show()

# Vysvětlení mezikvartilového rozpětí (IQR)
q1 = np.percentile(data, 25)
q3 = np.percentile(data, 75)
iqr = q3 - q1
print(f"Mezikvartilové rozpětí (IQR) = Q3 - Q1 = {q3:.2f} - {q1:.2f} = {iqr:.2f}")
print(f"Hranice vousů:")
print(f"Dolní hranice = Q1 - 1.5*IQR = {q1:.2f} - 1.5*{iqr:.2f} = {q1 - 1.5*iqr:.2f}")
print(f"Horní hranice = Q3 + 1.5*IQR = {q3:.2f} + 1.5*{iqr:.2f} = {q3 + 1.5*iqr:.2f}")
```

## 3. Vytváření základních krabicových grafů pomocí Matplotlib

Matplotlib poskytuje vestavěnou funkcionalitu pro vytváření krabicových grafů pomocí funkce `boxplot()`. Zde je ukázka, jak vytvořit základní krabicové grafy:

```python
# Vytvoření obrázku pro krabicové grafy matplotlib
plt.figure(figsize=(12, 6))

# Vytvoření krabicového grafu pro každou distribuci
plt.boxplot(
    [df['Normální'], df['Zešikmené'], df['Bimodální'], df['Rovnoměrné']],
    labels=['Normální', 'Zešikmené', 'Bimodální', 'Rovnoměrné'],
    vert=True,  # Vertikální krabicový graf
    patch_artist=True,  # Vyplnění krabic barvou
    medianprops={'color': 'black', 'linewidth': 2},  # Přizpůsobení čáry mediánu
    boxprops={'facecolor': 'lightblue', 'alpha': 0.8}  # Přizpůsobení výplně krabice
)

# Přidání nadpisu a popisků
plt.title('Krabicové grafy různých distribucí pomocí Matplotlib', fontsize=14)
plt.ylabel('Hodnota', fontsize=12)
plt.grid(True, alpha=0.3, axis='y')
plt.tight_layout()
plt.show()

# Horizontální krabicový graf s různými barvami
plt.figure(figsize=(10, 8))

# Vytvoření horizontálního krabicového grafu s různými barvami
colors = ['lightblue', 'lightgreen', 'salmon', 'wheat']
box_plot = plt.boxplot(
    [df['Normální'], df['Zešikmené'], df['Bimodální'], df['Rovnoměrné']], 
    labels=['Normální', 'Zešikmené', 'Bimodální', 'Rovnoměrné'],
    vert=False,
    patch_artist=True
)

# Obarvení každé krabice jinak
for box, color in zip(box_plot['boxes'], colors):
    box.set(facecolor=color, alpha=0.8)

# Přidání nadpisu a popisků
plt.title('Horizontální krabicové grafy s vlastními barvami', fontsize=14)
plt.xlabel('Hodnota', fontsize=12)
plt.grid(True, alpha=0.3, axis='x')
plt.tight_layout()
plt.show()

# Vytvoření krabicového grafu se zářezy
plt.figure(figsize=(10, 6))

plt.boxplot(
    [df['Normální'], df['Zešikmené'], df['Bimodální'], df['Rovnoměrné']],
    labels=['Normální', 'Zešikmené', 'Bimodální', 'Rovnoměrné'],
    notch=True,  # Přidání zářezů do krabic
    patch_artist=True,
    boxprops={'facecolor': 'lightblue', 'alpha': 0.8},
    medianprops={'color': 'red'}
)

plt.title('Krabicové grafy se zářezy (95% interval spolehlivosti mediánu)', fontsize=14)
plt.ylabel('Hodnota', fontsize=12)
plt.grid(True, alpha=0.3, axis='y')
plt.tight_layout()
plt.show()

print("Zářezy v krabicovém grafu představují 95% interval spolehlivosti kolem mediánu.")
print("Pokud se zářezy dvou krabic nepřekrývají, naznačuje to statisticky významný rozdíl mezi mediány.")
```

## 4. Krabicové grafy pomocí Seaborn

Seaborn staví na matplotlib a poskytuje vyšší úroveň rozhraní pro vytváření statistických vizualizací, včetně krabicových grafů. Jeho funkce nabízejí vylepšenou estetiku a dodatečné funkce:

```python
# Vytvoření obrázku pro krabicové grafy seaborn
plt.figure(figsize=(12, 6))

# Vytvoření krabicového grafu pomocí seaborn
sns.boxplot(data=df)

# Přidání nadpisu a popisků
plt.title('Krabicové grafy různých distribucí pomocí Seaborn', fontsize=14)
plt.ylabel('Hodnota', fontsize=12)
plt.grid(True, alpha=0.3, axis='y')
plt.tight_layout()
plt.show()

# Přetavení DataFrame pro složitější grafy
df_melted = df.melt(var_name='Distribuce', value_name='Hodnota')

# Vytvoření krabicových grafů s kategorickou proměnnou
plt.figure(figsize=(12, 6))

# Krabicový graf s kategorickou proměnnou
sns.boxplot(
    x='Distribuce',
    y='Hodnota',
    data=df_melted,
    palette='Set3'
)

plt.title('Krabicové grafy seskupené podle typu distribuce', fontsize=14)
plt.grid(True, alpha=0.3, axis='y')
plt.tight_layout()
plt.show()

# Vytvoření krabicového grafu s dodatečným kategorickým seskupením
# Generování nových dat s kategoriemi
np.random.seed(42)
categories = ['Skupina A', 'Skupina B', 'Skupina C']
distributions = ['Normální', 'Zešikmené']

# Generování dat pro každou kombinaci
data = []
for dist in distributions:
    for cat in categories:
        if dist == 'Normální':
            values = np.random.normal(0, 1, 100)
        else:
            values = np.random.exponential(2, 100)
        
        for value in values:
            data.append([dist, cat, value])

# Vytvoření DataFrame
grouped_df = pd.DataFrame(data, columns=['Distribuce', 'Kategorie', 'Hodnota'])

# Graf
plt.figure(figsize=(12, 6))
sns.boxplot(
    x='Distribuce', 
    y='Hodnota', 
    hue='Kategorie',
    data=grouped_df,
    palette='pastel'
)
plt.title('Krabicové grafy s více seskupujícími proměnnými', fontsize=14)
plt.grid(True, alpha=0.3, axis='y')
plt.tight_layout()
plt.show()
```

## 5. Porozumění komponentám houslového grafu

Houslové grafy kombinují vlastnosti krabicových grafů s odhadem jádrové hustoty (KDE) pro poskytnutí více informací o distribuci dat. Klíčové komponenty zahrnují:

1. **Centrální krabicový graf**: Zobrazuje medián a kvartilové informace
2. **Křivka hustoty**: Zobrazuje úplnou distribuci pravděpodobnosti dat
3. **Šířka**: Reprezentuje hustotu/frekvenci u konkrétní hodnoty
4. **Symetrie**: Ukazuje symetrii nebo zešikmení distribuce

```python
# Vytvoření obrázku pro vysvětlení komponent houslového grafu
plt.figure(figsize=(10, 6))

# Vytvoření houslového grafu pro normální distribuci
ax = sns.violinplot(x=df['Normální'], inner='box', color='lightblue')

# Přidání anotací pro vysvětlení komponent
plt.annotate('Medián', xy=(0, df['Normální'].median()), 
             xytext=(0.5, df['Normální'].median()), 
             arrowprops=dict(arrowstyle='->'))

plt.annotate('Mezikvartilové\nrozpětí (krabice)', xy=(0, df['Normální'].quantile(0.5)),
             xytext=(0.5, df['Normální'].quantile(0.75)), 
             arrowprops=dict(arrowstyle='->'))

plt.annotate('Odhad jádrové\nhustoty (KDE)', xy=(0, 2),
             xytext=(0.5, 2), 
             arrowprops=dict(arrowstyle='->'))

plt.annotate('Šířka = hustota\nv tomto bodě', xy=(0.05, 0),
             xytext=(0.5, 0.5), 
             arrowprops=dict(arrowstyle='->'))

# Odstranění popisku osy x a značek
plt.xlabel('')
plt.xticks([])

plt.title('Anatomie houslového grafu', fontsize=14)
plt.ylabel('Hodnota', fontsize=12)
plt.grid(True, alpha=0.3, axis='y')
plt.tight_layout()
plt.show()

print("Houslový graf kombinuje prvky krabicového grafu s odhadem jádrové hustoty (KDE).")
print("Zobrazuje úplný tvar distribuce, medián, IQR a může odhalit vlastnosti jako:")
print("- Multimodalitu (více vrcholů)")
print("- Zešikmení (asymetrii)")
print("- Variace hustoty, které krabicové grafy nemohou ukázat")
```

Funkce `violinplot()` v knihovně Seaborn usnadňuje vytváření houslových grafů s různými možnostmi:

```python

fig, axes = plt.subplots(1, 3, figsize=(18, 6))

    inner='quartile'

plt.grid(True, alpha=0.3, axis='y')

plt.figure(figsize=(12, 6))

    x='Distribuce',

    scale='width',   # Škálování podle šířky

    linewidth=1.5,   # Šířka obrysu
    cut=0,           # Nerozšiřovat za rozsah dat

plt.grid(True, alpha=0.3, axis='y')
plt.tight_layout()
plt.show()
```

## 7. Porovnání krabicových a houslových grafů

Krabicové a houslové grafy mají různé přednosti. Pojďme je porovnat vedle sebe, abychom pochopili, kdy použít který:

```python
# Vytvoření porovnání vedle sebe
fig, axes = plt.subplots(2, 4, figsize=(16, 8))

# Vytvoření distribucí se specifickými vlastnostmi pro zvýraznění rozdílů
# 1. Normální distribuce
normal = np.random.normal(0, 1, 1000)

# 2. Bimodální distribuce
bimodal = np.concatenate([np.random.normal(-1.5, 0.5, 500), np.random.normal(1.5, 0.5, 500)])

# 3. Vysoce zešikmená distribuce
skewed = np.random.exponential(2, 1000)

# 4. Rovnoměrná distribuce
uniform = np.random.uniform(-3, 3, 1000)

distributions = [normal, bimodal, skewed, uniform]
titles = ['Normální', 'Bimodální', 'Zešikmená', 'Rovnoměrná']

# Vykreslení krabicových grafů v prvním řádku
for i, (data, title) in enumerate(zip(distributions, titles)):
    sns.boxplot(y=data, ax=axes[0, i])
    axes[0, i].set_title(f'Krabicový graf: {title}', fontsize=12)
    axes[0, i].grid(True, alpha=0.3, axis='y')
    if i > 0:
        axes[0, i].set_ylabel('')

axes[0, 0].set_ylabel('Hodnota', fontsize=12)

# Vykreslení houslových grafů ve druhém řádku
for i, (data, title) in enumerate(zip(distributions, titles)):
    sns.violinplot(y=data, ax=axes[1, i], inner='box')
    axes[1, i].set_title(f'Houslový graf: {title}', fontsize=12)
    axes[1, i].grid(True, alpha=0.3, axis='y')
    if i > 0:
        axes[1, i].set_ylabel('')

axes[1, 0].set_ylabel('Hodnota', fontsize=12)

plt.tight_layout()
plt.show()

# Zobrazení porovnání výhod
comparison = pd.DataFrame({
    'Vlastnost': ['Zobrazuje medián', 'Zobrazuje kvartily (IQR)', 'Identifikuje odlehlé hodnoty', 
                'Zobrazuje úplný tvar distribuce', 'Zobrazuje multimodalitu', 
                'Zobrazuje lokální hustotu', 'Vizuální jednoduchost', 'Statistická jasnost'],
    'Krabicový graf': ['✓', '✓', '✓', '✗', '✗', '✗', '✓', '✓'],
    'Houslový graf': ['✓', '✓', '✓', '✓', '✓', '✓', '✗', '✗']
})

print("Porovnání krabicových grafů vs. houslových grafů:")
print(comparison.to_string(index=False))
```

## 8. Přizpůsobení krabicových a houslových grafů

Jak krabicové, tak houslové grafy lze přizpůsobit pro zvýšení jejich vizuální přitažlivosti a jasnosti:

```python
# Vytvoření obrázku pro přizpůsobení
plt.figure(figsize=(12, 8))

# Vlastní barevná paleta
custom_palette = ['#3498db', '#2ecc71', '#e74c3c', '#f39c12']

# Vytvoření vysoce přizpůsobeného krabicového grafu
ax = sns.boxplot(
    x='Distribuce',
    y='Hodnota',
    data=df_melted,
    palette=custom_palette,
    width=0.5,
    fliersize=5,
    linewidth=1.5
)

# Přizpůsobení vzhledu grafu
plt.title('Vysoce přizpůsobený krabicový graf', fontsize=16, fontweight='bold')
plt.ylabel('Hodnota', fontsize=14)
plt.xlabel('Typ distribuce', fontsize=14)
plt.grid(True, alpha=0.3, linestyle='--', axis='y')

# Změna barvy pozadí a přidání ohraničení
ax.set_facecolor('#f8f9fa')
for spine in ax.spines.values():
    spine.set_linewidth(1.5)
    spine.set_color('#333333')

plt.tight_layout()
plt.show()

# Vytvoření obrázku pro přizpůsobený houslový graf
plt.figure(figsize=(12, 8))

# Vytvoření vysoce přizpůsobeného houslového grafu
ax = sns.violinplot(
    x='Distribuce',
    y='Hodnota',
    data=df_melted,
    palette=custom_palette,
    scale='width',
    inner='box',
    linewidth=1.5,
    saturation=0.8
)

# Přidání jednotlivých datových bodů pomocí swarmplot
sns.swarmplot(
    x='Distribuce',
    y='Hodnota',
    data=df_melted,
    size=3,
    color='black',
    alpha=0.5
)

# Přizpůsobení vzhledu grafu
plt.title('Vysoce přizpůsobený houslový graf s datovými body', fontsize=16, fontweight='bold')
plt.ylabel('Hodnota', fontsize=14)
plt.xlabel('Typ distribuce', fontsize=14)
plt.grid(True, alpha=0.3, linestyle='--', axis='y')

# Změna barvy pozadí a přidání ohraničení
ax.set_facecolor('#f8f9fa')
for spine in ax.spines.values():
    spine.set_linewidth(1.5)
    spine.set_color('#333333')

plt.tight_layout()
plt.show()

# Kombinace krabicového a houslového grafu v jednom obrázku
plt.figure(figsize=(12, 6))

# Vytvoření houslového grafu
ax = sns.violinplot(
    x='Distribuce', 
    y='Hodnota', 
    data=df_melted,
    inner=None,
    color='lightgray'
)

# Přidání krabicového grafu na vrch
sns.boxplot(
    x='Distribuce', 
    y='Hodnota', 
    data=df_melted,
    width=0.3,
    palette=custom_palette,
    saturation=0.8,
    ax=ax
)

plt.title('Kombinovaný houslový a krabicový graf', fontsize=16)
plt.ylabel('Hodnota', fontsize=14)
plt.xlabel('Typ distribuce', fontsize=14)
plt.grid(True, alpha=0.3, axis='y')
```

## 10. Shrnutí

Krabicové a houslové grafy jsou univerzální nástroje pro vizualizaci distribucí dat a porovnávání mezi skupinami:

- **Krabicové grafy** poskytují jasné shrnutí centrální tendence a rozptylu dat, zvýrazňují odlehlé hodnoty a jsou vynikající pro statistická porovnání.

- **Houslové grafy** kombinují krabicové grafy s odhadem jádrové hustoty pro zobrazení úplného tvaru distribuce, což je ideální pro identifikaci vlastností jako bimodalita a zešikmení, které by krabicové grafy mohly přehlédnout.

Klíčové poznatky:

1. Krabicové grafy ukazují medián, kvartily, rozsah a odlehlé hodnoty efektivně
2. Houslové grafy rozšiřují krabicové grafy zobrazením hustoty pravděpodobnosti dat při různých hodnotách
3. Krabicové grafy jsou vhodnější pro čistší statistická porovnání
4. Houslové grafy vynikají, když záleží na tvaru distribuce
5. Oba typy lze rozsáhle přizpůsobit pro zvýšení jasnosti a vizuální přitažlivosti
6. Tyto grafy jsou obzvláště užitečné pro porovnávání distribucí napříč kategoriemi
7. Při výběru mezi nimi zvažte své publikum a případ použití
8. Pro malé datasety zvažte přidání jednotlivých datových bodů pro více kontextu
9. Seaborn poskytuje rozhraní vysoké úrovně pro vytváření obou typů grafů s minimálním kódem
10. Kombinované přístupy (krabicový graf v houslovém grafu) mohou poskytovat to nejlepší z obou světů

Pro efektivní vizualizaci dat vyberte typ grafu, který nejlépe zvýrazňuje aspekty vašich dat, které jsou nejrelevantnější pro vaši analýzu a publikum.
