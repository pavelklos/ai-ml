# Seaborn pro statistickou vizualizaci

## Úvod

Seaborn je výkonná knihovna pro vizualizaci dat v Pythonu, postavená na základech Matplotlib, která poskytuje vysokoúrovňové rozhraní pro vytváření informativních a atraktivních statistických grafů. Zatímco Matplotlib nabízí rozsáhlé možnosti přizpůsobení, Seaborn zjednodušuje proces vytváření běžně používaných statistických vizualizací s minimálním množstvím kódu a zároveň produkuje vizuálně přitažlivé výsledky.

Seaborn se specializuje na statistickou vizualizaci a vyniká v:
- Vizualizaci vztahů mezi proměnnými
- Porovnávání distribucí
- Vizualizaci kategorických dat
- Vytváření komplexních mřížek grafů
- Aplikaci atraktivních stylů s minimálním úsilím

Tento průvodce prozkoumá, jak využít Seaborn pro vytváření efektivních statistických vizualizací s praktickými příklady v Pythonu.

## Nastavení prostředí


## Maticové vizualizace

### Teplotní mapy

Vizualizace matic a korelačních dat:

```python
plt.figure(figsize=(14, 10))

# Vytvoření pivotní tabulky z datasetu letů
flights_pivot = flights.pivot_table(values='passengers', index='month', columns='year')

# Základní teplotní mapa
plt.subplot(2, 2, 1)

sns.heatmap(flights_pivot, annot=True, fmt='d', cmap='YlGnBu')
plt.title('Teplotní mapa s hodnotami')

# Korelační teplotní mapa
plt.subplot(2, 2, 3)
corr_matrix = iris.drop('species', axis=1).corr()
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm')
plt.title('Korelační teplotní mapa')

# Maskovaná teplotní mapa
plt.subplot(2, 2, 4)
mask = np.triu(np.ones_like(corr_matrix, dtype=bool))
sns.heatmap(corr_matrix, mask=mask, annot=True, cmap='viridis', vmax=.3, center=0)
plt.title('Maskovaná korelační teplotní mapa')

plt.tight_layout()
plt.show()
```

## Integrace s Matplotlib

Seaborn se hladce integruje s Matplotlib pro další přizpůsobení:

```python
# Vytvoření grafu pomocí seabornu
plt.figure(figsize=(10, 6))
sns.set_style("whitegrid")
ax = sns.barplot(x="day", y="total_bill", hue="sex", data=tips)

# Vylepšení pomocí matplotlib
plt.title("Sloupcový graf s přizpůsobením Matplotlib", fontsize=16, fontweight='bold')
plt.xlabel("Den v týdnu", fontsize=12)
plt.ylabel("Celkový účet (Kč)", fontsize=12)

# Přidání anotací
max_vals = tips.groupby(['day', 'sex'])['total_bill'].mean()
for i, day in enumerate(['Thur', 'Fri', 'Sat', 'Sun']):
    plt.text(i-0.2, max_vals[day, 'Female']+1, f"{max_vals[day, 'Female']:.2f} Kč", 
             ha='center', fontweight='bold')
    plt.text(i+0.2, max_vals[day, 'Male']+1, f"{max_vals[day, 'Male']:.2f} Kč", 
             ha='center', fontweight='bold')

# Přizpůsobení legendy a přidání mřížky
plt.legend(title="Pohlaví", frameon=True, fancybox=True, framealpha=0.8, shadow=True)
ax.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()
```

## Osvědčené postupy

Při používání Seaborn pro statistickou vizualizaci zvažte tyto osvědčené postupy:

```python
# Ukázková vizualizace podle osvědčených postupů
plt.figure(figsize=(12, 8))

# Nastavení čistého, profesionálního stylu
sns.set_style("whitegrid")
sns.set_context("notebook", font_scale=1.2)

# Použití palety přátelské pro barvoslepé
sns.set_palette("colorblind")

# Vytvoření smysluplné vizualizace
g = sns.catplot(
    data=tips, kind="bar",
    x="day", y="total_bill", hue="time",
    errorbar="sd", palette="dark", alpha=.8, height=6, aspect=1.4
)

# Přidání vhodných názvů a popisků
g.set_axis_labels("Den v týdnu", "Průměrný celkový účet (Kč)")
g.legend.set_title("Denní doba")
g.fig.suptitle("Denní výdajové vzorce podle denní doby", fontsize=16, y=1.02)

# Přidání popisných statistik jako textu
for i, day in enumerate(tips['day'].unique()):
    stats = tips[tips['day'] == day]['total_bill']
    plt.text(i, stats.mean() + stats.std() + 1, 
             f"n={stats.count()}\nσ={stats.std():.2f}", 
             ha='center', fontsize=9)

plt.tight_layout()
plt.show()
```

## Shrnutí

Seaborn je výkonná knihovna pro statistickou vizualizaci dat v Pythonu, která poskytuje:

1. **Vysokoúrovňové rozhraní**: Seaborn nabízí stručné API pro vytváření komplexních statistických vizualizací s minimálním kódem.

2. **Zaměření na statistickou vizualizaci**: Je specificky navržen pro průzkum a pochopení distribucí dat, vztahů a vzorců.

3. **Vestavěné datasety**: Seaborn zahrnuje ukázkové datasety, které jsou užitečné pro učení a prototypování.

4. **Atraktivní výchozí styly**: Výchozí estetika je navržena pro jasné, profesionálně vyhlížející vizualizace.

5. **Integrace s pandas**: Seaborn spolupracuje bezproblémově s pandas DataFrames.

6. **Specializované typy grafů**: Poskytuje specializované grafy pro distribuce (histogramy, KDE), kategorická data (krabicové grafy, houslové grafy), vztahy (bodové grafy, regresní grafy) a matice (teplotní mapy, clustermapy).

7. **Více-grafové mřížky**: FacetGrid a PairGrid usnadňují vytváření vizualizací s více panely.

8. **Možnosti přizpůsobení**: Kromě poskytování dobrých výchozích nastavení Seaborn stále nabízí rozsáhlé možnosti přizpůsobení pro barvy, styly a další vizuální prvky.

9. **Kompatibilita s Matplotlib**: Seaborn staví na Matplotlib, což vám umožňuje kombinovat silné stránky obou knihoven.

Využitím možností Seabornu můžete vytvářet informativní, statisticky správné a vizuálně přitažlivé grafy, které efektivně komunikují vzory a poznatky ve vašich datech.
