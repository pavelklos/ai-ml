# Vizualizace pro modely strojového učení

## Úvod

Vizualizace je klíčovou součástí pracovního postupu strojového učení. Pomáhá pochopit data, interpretovat chování modelu, vyhodnotit výkonnost, vysvětlit předpovědi a komunikovat výsledky zainteresovaným stranám. Efektivní vizualizace mohou odhalit poznatky, které samotná čísla a metriky nedokážou vyjádřit, čímž činí modely transparentnějšími a srozumitelnějšími.

Tento průvodce zkoumá různé techniky a nástroje pro vizualizaci různých aspektů modelů strojového učení, od průzkumné analýzy dat až po hodnocení a interpretaci modelu.

## Vizualizace metrik výkonnosti modelu

### Základní vizualizace přesnosti a metrik

Začněme jednoduchými vizualizacemi běžných metrik výkonnosti:

```python
# Načtení datasetu
iris = datasets.load_iris()
X = iris.data
y = iris.target

# Rozdělení dat
X_train, X_test, y_train, y_test = model_selection.train_test_split(
    X, y, test_size=0.3, random_state=42
)

# Trénování modelů
models = {
    "Random Forest": ensemble.RandomForestClassifier(random_state=42),
    "Decision Tree": tree.DecisionTreeClassifier(random_state=42),
    "SVM": svm.SVC(probability=True, random_state=42),
    "KNN": neighbors.KNeighborsClassifier()
}

# Výpočet přesnosti pro každý model
accuracy_scores = {}

for name, model in models.items():
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)
    accuracy_scores[name] = metrics.accuracy_score(y_test, y_pred)

# Vytvoření sloupcového grafu přesností
plt.figure(figsize=(10, 6))
bars = plt.bar(accuracy_scores.keys(), accuracy_scores.values(), color='skyblue')

# Přidání hodnot nad sloupce
for bar in bars:
    height = bar.get_height()
    plt.text(bar.get_x() + bar.get_width()/2., height + 0.01,
             f'{height:.2f}', ha='center', va='bottom')

plt.ylim(0, 1.1)
plt.title('Porovnání přesnosti modelů')
plt.ylabel('Skóre přesnosti')
plt.xticks(rotation=45)
plt.tight_layout()
```

## Vizualizace matice záměn

Matice záměn jsou nezbytné pro pochopení výkonnosti klasifikačních modelů:

```python
# Vytvoření a zobrazení matice záměn pomocí seabornu
def plot_confusion_matrix(y_true, y_pred, class_names=None):
    cm = metrics.confusion_matrix(y_true, y_pred)
    plt.figure(figsize=(8, 6))
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
                xticklabels=class_names, yticklabels=class_names)
    plt.xlabel('Predikovaná třída')
    plt.ylabel('Skutečná třída')
    plt.title('Matice záměn')
    plt.tight_layout()
    plt.show()

# Fit modelu
rf_model = ensemble.RandomForestClassifier(random_state=42)
rf_model.fit(X_train, y_train)
y_pred = rf_model.predict(X_test)

# Zobrazení matice záměn
plot_confusion_matrix(y_test, y_pred, iris.target_names)

# Pokročilejší vizualizace pomocí yellowbrick
cm = ConfusionMatrix(
    rf_model, classes=iris.target_names, 
    cmap='Blues', fontsize=12
)
cm.fit(X_train, y_train)
cm.score(X_test, y_test)
cm.show()
```

## ROC a PR křivky

ROC (Receiver Operating Characteristic) a Precision-Recall křivky jsou důležité pro hodnocení binárních a vícehodnotových klasifikačních modelů:

```python

X_train, X_test, y_train, y_test = model_selection.train_test_split(
    X, binary_y, test_size=0.3, random_state=42

rf_model.fit(X_train, y_train)
y_pred_proba = rf_model.predict_proba(X_test)[:, 1]

plt.figure(figsize=(10, 6))
plt.plot(fpr, tpr, color='darkorange', lw=2, label=f'ROC křivka (plocha = {roc_auc:.2f})')

plt.xlim([0.0, 1.0])
plt.ylim([0.0, 1.05])
plt.xlabel('Míra falešně pozitivních')

plt.show()

plt.title('Křivka Precision-Recall')
```

## Křivky učení

Křivky učení pomáhají diagnostikovat, zda model trpí přeučením nebo nedostatečným učením:

```python
# Vytvoření a vizualizace křivek učení
def plot_learning_curve(estimator, X, y, cv=5, n_jobs=-1):
    train_sizes = np.linspace(0.1, 1.0, 10)
    train_sizes, train_scores, test_scores = model_selection.learning_curve(
        estimator, X, y, train_sizes=train_sizes, cv=cv, n_jobs=n_jobs, scoring='accuracy'
    )
    
    train_mean = np.mean(train_scores, axis=1)
    train_std = np.std(train_scores, axis=1)
    test_mean = np.mean(test_scores, axis=1)
    test_std = np.std(test_scores, axis=1)
    
    plt.figure(figsize=(10, 6))
    plt.title('Křivka učení')
    plt.xlabel('Počet trénovacích příkladů')
    plt.ylabel('Skóre')
    plt.grid(True)
    
    plt.fill_between(train_sizes, train_mean - train_std, train_mean + train_std, 
                     alpha=0.1, color='blue')
    plt.fill_between(train_sizes, test_mean - test_std, test_mean + test_std, 
                     alpha=0.1, color='orange')
    plt.plot(train_sizes, train_mean, 'o-', color='blue', label='Trénovací skóre')
    plt.plot(train_sizes, test_mean, 'o-', color='orange', label='Validační skóre')
    plt.legend(loc='best')
    plt.show()

# Zobrazení křivky učení pro Random Forest
rf_model = ensemble.RandomForestClassifier(random_state=42)
plot_learning_curve(rf_model, X, y)

# Pokročilá vizualizace pomocí yellowbrick
visualizer = LearningCurve(
    rf_model, cv=5, scoring='accuracy', 
    train_sizes=np.linspace(0.1, 1.0, 10),
    n_jobs=-1
)
visualizer.fit(X, y)
visualizer.show()
```

## Vizualizace hranice rozhodování

Vizualizace hranice rozhodování pomáhá pochopit, jak modely oddělují různé třídy:

```python
# Vytvoření funkce pro zobrazení hranice rozhodování
def plot_decision_boundaries(X, y, model, feature_indices=[0, 1]):
    # Použití pouze vybraných příznaků
    X_subset = X[:, feature_indices]
    
    # Vytvoření mřížky
    h = 0.02  # velikost kroku
    x_min, x_max = X_subset[:, 0].min() - 1, X_subset[:, 0].max() + 1
    y_min, y_max = X_subset[:, 1].min() - 1, X_subset[:, 1].max() + 1
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h), np.arange(y_min, y_max, h))
    
    # Vytvoření nového modelu pouze s vybranými příznaky
    X_train_subset, X_test_subset, y_train, y_test = model_selection.train_test_split(
        X_subset, y, test_size=0.3, random_state=42
    )
    model.fit(X_train_subset, y_train)
    
    # Predikce pomocí mřížky
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
    Z = Z.reshape(xx.shape)
    
    # Zobrazení
    plt.figure(figsize=(10, 8))
    plt.contourf(xx, yy, Z, alpha=0.3, cmap='viridis')
    plt.scatter(X_subset[:, 0], X_subset[:, 1], c=y, cmap='viridis', edgecolors='k')
    plt.xlabel(f'Příznak {feature_indices[0]} ({iris.feature_names[feature_indices[0]]})')
    plt.ylabel(f'Příznak {feature_indices[1]} ({iris.feature_names[feature_indices[1]]})')
    plt.title(f'Hranice rozhodování pro {type(model).__name__}')
    plt.colorbar()
    plt.show()

# Zobrazení hranice rozhodování pro různé modely
models = {
    "Random Forest": ensemble.RandomForestClassifier(random_state=42),
    "Decision Tree": tree.DecisionTreeClassifier(random_state=42),
    "SVM": svm.SVC(gamma='scale', random_state=42),
    "KNN": neighbors.KNeighborsClassifier(n_neighbors=7)
}

for name, model in models.items():
    print(f"\nHranice rozhodování pro {name}:")
    plot_decision_boundaries(X, y, model, [0, 1])  # Použití délky a šířky kalichu
```

```python
# Trénování více modelů a sběr metrik výkonnosti
models = {
    "Random Forest": ensemble.RandomForestClassifier(random_state=42),
    "Decision Tree": tree.DecisionTreeClassifier(random_state=42),
    "SVM": svm.SVC(probability=True, random_state=42),

metrics_results = {

# Vytvoření DataFrame pro snadnější zobrazení
metrics_df = pd.DataFrame(metrics_results, index=model_names)

fig = go.Figure()
```

## Analýza reziduí

Pro regresní modely vizualizace reziduí pomáhá pochopit vhodnost modelu:

```python
# Analýza reziduí pro regresní problémy
boston = datasets.load_boston()
X_reg = boston.data
y_reg = boston.target

X_train_reg, X_test_reg, y_train_reg, y_test_reg = model_selection.train_test_split(
    X_reg, y_reg, test_size=0.3, random_state=42

plt.axhline(y=0, color='r', linestyle='-')
plt.title('Graf reziduí')
plt.xlabel('Predikované hodnoty')
plt.ylabel('Rezidua')

plt.subplot(1, 2, 2)
plt.hist(residuals, bins=20)
plt.title('Distribuce reziduí')
plt.xlabel('Hodnota rezidua')
plt.ylabel('Četnost')

plt.tight_layout()
plt.show()

# QQ graf pro kontrolu normality reziduí
import scipy.stats as stats

plt.figure(figsize=(10, 6))
stats.probplot(residuals, plot=plt)
plt.title('Q-Q graf reziduí')
plt.tight_layout()
plt.show()
```

## Shrnutí

Vizualizace modelů strojového učení je nezbytná pro porozumění, ladění, hodnocení a komunikaci chování modelu. Tento průvodce pokryl širokou škálu vizualizačních technik:

1. **Vizualizace metrik výkonnosti** pomáhá rychle porovnávat modely pomocí metrik jako přesnost, preciznost, úplnost a F1 skóre.

2. **Matice záměn** poskytují detailní pohled na to, kde modely dělají správné a nesprávné predikce napříč třídami.

3. **ROC a PR křivky** hodnotí klasifikační modely při různých nastaveních prahu, což je zvláště užitečné pro nevyvážené datasety.

4. **Křivky učení** diagnostikují přeučení a nedostatečné učení sledováním výkonnosti modelu s rostoucí velikostí trénovacích dat.

5. **Hranice rozhodování** ilustrují, jak modely oddělují třídy v prostoru příznaků, což pomáhá pochopit chování modelu.

6. **Důležitost příznaků** identifikuje, které proměnné mají největší vliv na predikce modelu.

7. **Rozhodovací stromy** lze vizualizovat pro pochopení přesných pravidel rozhodování, která jsou používána.

8. **Architektura neuronové sítě** vizualizace pomáhá porozumět struktuře a složitosti modelu.

9. **Ladění hyperparametrů** vizualizace pomáhá vybrat nejlepší parametry modelu.

10. **Analýza reziduí** pro regresní modely pomáhá identifikovat vzory v chybách predikce.

11. **Interaktivní vizualizace** umožňují hlubší průzkum a lepší komunikaci výsledků.

Klíčové knihovny pro vizualizaci modelů zahrnují:
- **Matplotlib a Seaborn** pro statické vizualizace
- **Plotly** pro interaktivní vizualizace
- **Yellowbrick** pro specializované vizualizace strojového učení
- **SHAP** pro interpretovatelnost modelů
- **Graphviz** pro vizualizaci stromových modelů
- **TensorBoard** pro vizualizaci neuronových sítí

Efektivní vizualizace modelu je mocným nástrojem pro budování důvěry, zlepšování výkonnosti modelu a komunikaci výsledků zainteresovaným stranám. Zahrnutím těchto vizualizačních technik do vašeho pracovního postupu strojového učení můžete vyvíjet transparentnější, interpretovatelné a spolehlivější modely.
