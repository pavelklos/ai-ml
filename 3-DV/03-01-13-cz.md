## 1. Úvod do vizualizace časových řad

Vizualizace časových řad je základní technikou pro pochopení dat, která se mění v čase. Ať už analyzujete ceny akcií, meteorologické vzorce, návštěvnost webových stránek nebo prodejní data, efektivní vizualizace může odhalit trendy, sezónnost, cyklické vzorce a anomálie, které by mohly být skryty v surových číslech.

Vizualizace časových řad vám pomůže:
- Identifikovat trendy a vzorce
- Detekovat sezónnost a cyklické chování
- Odhalit anomálie a odlehlé hodnoty
- Porovnávat různá časová období
- Efektivně komunikovat poznatky

Nastavme prostředí s potřebnými knihovnami pro vizualizaci časových řad:

## 2. Porozumění datům časových řad

Data časových řad mají některé jedinečné charakteristiky, které ovlivňují způsob jejich vizualizace a analýzy:

- **Časové uspořádání**: Posloupnost pozorování je důležitá
- **Časový index**: Typicky používá časová razítka jako indexy
- **Frekvence**: Data mohou být zaznamenávána v různých intervalech (denní, hodinové atd.)
- **Komponenty**: Často obsahují trend, sezónnost a reziduální složky

Vytvořme jednoduchý dataset časových řad, se kterým budeme pracovat v průběhu tohoto návodu:

```python
# Vytvoření vzorového datasetu časových řad
def create_sample_time_series(start_date='2022-01-01', periods=365, freq='D'):
    """
    Vytvoří vzorovou časovou řadu s trendem, sezónností a náhodným šumem
    
    Parametry:
    -----------
    start_date : str
        Počáteční datum časové řady
    periods : int
        Počet období k vygenerování
    freq : str
        Řetězec frekvence (např. 'D' pro denní, 'H' pro hodinové)
    
    Vrací:
    --------
    pandas.DataFrame
        DataFrame obsahující data časové řady
    """
    # Vytvoření rozsahu dat
    date_rng = pd.date_range(start=start_date, periods=periods, freq=freq)
    
    # Vytvoření složky trendu (lineární růst)
    trend = np.linspace(10, 30, periods)
    
    # Vytvoření sezónní složky (pomocí funkce sinus)
    seasons = 4  # Počet kompletních sezón
    seasonal = 5 * np.sin(2 * np.pi * np.arange(periods) * seasons / periods)
    
    # Přidání šumu
    noise = np.random.normal(0, 1, periods)
    
    # Kombinace složek
    values = trend + seasonal + noise
    
    # Vytvoření DataFrame
    df = pd.DataFrame({
        'date': date_rng,
        'value': values
    })
    
    # Nastavení data jako indexu
    df.set_index('date', inplace=True)
    
    return df

# Vygenerování naší vzorové časové řady
ts_data = create_sample_time_series()

# Zobrazení prvních několika řádků
print("Vzorová data časové řady:")
print(ts_data.head())

# Rychlá statistika
print("\nZákladní statistika:")
print(ts_data.describe())
```

## 4. Přizpůsobení grafů časových řad

Pro zajímavější a vizuálně přitažlivější vizualizace časových řad můžete přizpůsobit různé aspekty, jako jsou barvy, styly čar, značky a formátování dat.

```python
# Vytvoření více přizpůsobeného grafu s anotacemi

ax.plot(ts_data.index, ts_data['value'], linewidth=2, color='steelblue')

# Přidání trendové čáry (použití jednoduchého klouzavého průměru)
rolling_mean = ts_data['value'].rolling(window=30).mean()
ax.plot(ts_data.index, rolling_mean, linewidth=2, color='crimson', 
        linestyle='--', label='30denní klouzavý průměr')

# Přidání popisků os a titulku
ax.set_xlabel('Datum', fontsize=12)
ax.set_ylabel('Hodnota', fontsize=12)
ax.set_title('Přizpůsobený graf časové řady', fontsize=16, pad=20)

# Přizpůsobení mřížky
ax.grid(True, linestyle='--', alpha=0.7)

# Přizpůsobení datových značek
ax.tick_params(axis='both', which='major', labelsize=10)

# Otočení popisků data
plt.setp(ax.get_xticklabels(), rotation=45, ha='right')

# Zvýraznění specifických oblastí
start_highlight = pd.to_datetime('2022-06-01')
end_highlight = pd.to_datetime('2022-08-31')
ax.axvspan(start_highlight, end_highlight, alpha=0.2, color='yellow', 
           label='Letní období')

# Přidání anotací pro klíčové body
max_point = ts_data['value'].idxmax()
max_value = ts_data['value'].max()
ax.annotate(f'Maximum: {max_value:.2f}', 
            xy=(max_point, max_value),
            xytext=(max_point - pd.Timedelta(days=30), max_value + 2),
            arrowprops=dict(arrowstyle='->', connectionstyle='arc3,rad=0.2'))

# Přidání legendy
ax.legend(loc='upper left')

# Těsné rozvržení
plt.tight_layout()
plt.show()
```

## 6. Sezónní dekompozice a vizualizace

Jednou z nejsilnějších technik pro analýzu časových řad je rozklad dat na jejich trendové, sezónní a reziduální složky. To pomáhá pochopit základní vzorce v datech.

```python
# Převzorkování na měsíční frekvenci pro jasnější sezónnost
monthly_data = ts_data['value'].resample('M').mean()

# Provedení sezónní dekompozice
decomposition = seasonal_decompose(monthly_data, model='additive', period=12)

# Vykreslení dekompozice
fig, axes = plt.subplots(4, 1, figsize=(12, 12), sharex=True)

decomposition.observed.plot(ax=axes[0], legend=False)
axes[0].set_title('Pozorované')
axes[0].set_ylabel('Hodnota')

decomposition.trend.plot(ax=axes[1], legend=False)
axes[1].set_title('Trend')
axes[1].set_ylabel('Hodnota')

decomposition.seasonal.plot(ax=axes[2], legend=False)
axes[2].set_title('Sezónní')
axes[2].set_ylabel('Hodnota')

decomposition.resid.plot(ax=axes[3], legend=False)
axes[3].set_title('Reziduální')
axes[3].set_ylabel('Hodnota')
axes[3].set_xlabel('Datum')

plt.tight_layout()
plt.show()

# Vytvoření teplotní mapy pro vizualizaci sezónnosti podle měsíce a roku
# Nejprve připravíme data pro teplotní mapu
monthly_pivot = ts_data['value'].groupby([ts_data.index.year, ts_data.index.month]).mean().unstack()

# Vytvoření teplotní mapy
plt.figure(figsize=(12, 8))
sns.heatmap(monthly_pivot, annot=True, fmt=".1f", cmap='viridis', 
            linewidths=.5, cbar_kws={'label': 'Průměrná hodnota'})
plt.title('Měsíční sezónní vzorce')
plt.xlabel('Měsíc')
plt.ylabel('Rok')
plt.tight_layout()
plt.show()
```

## 7. Vizualizace klouzavých statistik

Klouzavé statistiky (také známé jako klouzavé průměry nebo posuvná okna) jsou užitečné pro vyhlazování dat časových řad a identifikaci trendů.

```python
# Výpočet různých klouzavých statistik
ts_data['7d_mean'] = ts_data['value'].rolling(window=7).mean()
ts_data['30d_mean'] = ts_data['value'].rolling(window=30).mean()
ts_data['7d_std'] = ts_data['value'].rolling(window=7).std()

# Vykreslení klouzavého průměru
plt.figure(figsize=(12, 6))
plt.plot(ts_data.index, ts_data['value'], alpha=0.5, label='Původní')
plt.plot(ts_data.index, ts_data['7d_mean'], linewidth=2, label='7denní klouzavý průměr')
plt.plot(ts_data.index, ts_data['30d_mean'], linewidth=2, label='30denní klouzavý průměr')
plt.title('Analýza klouzavého průměru')
plt.xlabel('Datum')
plt.ylabel('Hodnota')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Vykreslení klouzavé směrodatné odchylky
plt.figure(figsize=(12, 6))
plt.plot(ts_data.index, ts_data['7d_std'], linewidth=2, color='purple')
plt.title('7denní klouzavá směrodatná odchylka')
plt.xlabel('Datum')
plt.ylabel('Směrodatná odchylka')
plt.grid(True, alpha=0.3)
plt.show()

# Vykreslení s intervaly spolehlivosti (průměr ± 2*směrodatná odchylka)
plt.figure(figsize=(12, 6))
plt.plot(ts_data.index, ts_data['30d_mean'], linewidth=2, color='blue', label='30denní průměr')
plt.fill_between(ts_data.index, 
                ts_data['30d_mean'] - 2*ts_data['7d_std'],
                ts_data['30d_mean'] + 2*ts_data['7d_std'],
                color='lightblue', alpha=0.5, label='95% interval spolehlivosti')
plt.title('Klouzavý průměr s intervaly spolehlivosti')
plt.xlabel('Datum')
plt.ylabel('Hodnota')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

## 8. Interaktivní vizualizace časových řad

Zatímco statické grafy jsou užitečné, interaktivní vizualizace mohou poskytnout poutavější a průzkumnější zážitek, zejména s velkými datasety časových řad.

```python
# Vytvoření interaktivního grafu pomocí Plotly
import plotly.express as px
import plotly.graph_objects as go
from plotly.subplots import make_subplots

# Základní interaktivní čárový graf
fig = px.line(ts_data, y=['value', '7d_mean', '30d_mean'], 
              title='Interaktivní vizualizace časové řady',
              labels={'value': 'Původní', '7d_mean': '7denní prům.', '30d_mean': '30denní prům.'})

fig.update_layout(
    xaxis_title='Datum',
    yaxis_title='Hodnota',
    legend_title='Řada',
    hovermode='x unified'
)

# Přidání posuvníku rozsahu
fig.update_layout(
    xaxis=dict(
        rangeselector=dict(
            buttons=list([
                dict(count=1, label="1m", step="month", stepmode="backward"),
                dict(count=6, label="6m", step="month", stepmode="backward"),
                dict(count=1, label="YTD", step="year", stepmode="todate"),
                dict(count=1, label="1r", step="year", stepmode="backward"),
                dict(step="all")
            ])
        ),
        rangeslider=dict(visible=True),
        type="date"
    )
)

fig.show()

# Vytvoření komplexnějšího interaktivního dashboardu s podgrafy
fig = make_subplots(
    rows=2, cols=2,
    subplot_titles=('Původní časová řada', 'Klouzavé průměry', 
                    'Klouzavá směrodatná odchylka', 'Meziroční srovnání'),
    shared_xaxes=True,
    vertical_spacing=0.1
)

# Přidání grafů do podgrafů
fig.add_trace(
    go.Scatter(x=ts_data.index, y=ts_data['value'], mode='lines', name='Původní'),
    row=1, col=1
)

fig.add_trace(
    go.Scatter(x=ts_data.index, y=ts_data['7d_mean'], mode='lines', name='7denní prům.'),
    row=1, col=2
)

fig.add_trace(
    go.Scatter(x=ts_data.index, y=ts_data['30d_mean'], mode='lines', name='30denní prům.'),
    row=1, col=2
)

fig.add_trace(
    go.Scatter(x=ts_data.index, y=ts_data['7d_std'], mode='lines', 
               name='7denní StdOdch', line=dict(color='purple')),
    row=2, col=1
)

# Meziroční srovnání (použití stejného dne v roce)
# Pro jednoduchost vykreslíme prvních 180 dní oproti dalším 180 dnům
first_half = ts_data['value'][:180].reset_index(drop=True)
second_half = ts_data['value'][180:360].reset_index(drop=True)
days = np.arange(len(first_half))

fig.add_trace(
    go.Scatter(x=days, y=first_half, mode='lines', name='První polovina'),
    row=2, col=2
)

fig.add_trace(
    go.Scatter(x=days, y=second_half, mode='lines', name='Druhá polovina'),
    row=2, col=2
)

# Aktualizace rozvržení a zobrazení
fig.update_layout(
    height=700,
    width=1000,
    title_text='Interaktivní dashboard časové řady',
    hovermode='x unified'
)

fig.show()
```

## 10. Shrnutí

Vizualizace časových řad je kritickou dovedností pro datovou analýzu, protože pomáhá pochopit vzorce a vztahy v časových datech. V tomto průvodci jsme pokryli:

1. **Základní grafy časových řad** pomocí čárových grafů pro zobrazení změn dat v čase
2. **Přizpůsobení vizualizací** s anotacemi, formátováním a styly
3. **Porovnání více časových řad** na stejném grafu nebo pomocí podgrafů
4. **Rozklad časových řad** pro pochopení trendových, sezónních a reziduálních složek
5. **Vizualizace klouzavých statistik** pro identifikaci vzorů a redukci šumu
6. **Vytváření interaktivních vizualizací** pro průzkum a prezentaci
7. **Dodržování osvědčených postupů** pro jasnou a efektivní komunikaci časových řad

Vizualizace časových řad je jen začátkem analýzy časových řad. S postupem můžete prozkoumat metody předpovídání, detekci anomálií a složitější modely časových řad.

Pro pokročilejší vizualizace časových řad zvažte prozkoumání specializovaných knihoven jako:
- `plotly` pro interaktivní vizualizace
- `statsmodels` pro pokročilou analýzu a vizualizaci časových řad
- `prophet` pro předpovědi a vizualizaci dekompozice
- `altair` pro deklarativní statistické vizualizace

Pamatujte, že cílem vizualizace je vhled, nikoli jen pěkné obrázky. Vybírejte vizualizační techniky, které zdůrazňují vzorce a vztahy ve vašich datech, které jsou nejrelevantnější pro vaše analytické cíle.
