# Geografické vizualizace s Folium

## Úvod

Geografická vizualizace dat přináší prostorový rozměr do vaší datové analýzy a umožňuje odhalit vzory, vztahy a poznatky založené na geografické poloze. Folium je výkonná knihovna v Pythonu, která propojuje manipulaci s daty a mapovou vizualizaci prostřednictvím JavaScriptové knihovny Leaflet.js. Umožňuje vytvářet interaktivní mapy, které lze zobrazit ve webových prohlížečích, Jupyter notebookcích nebo webových aplikacích.

Tento průvodce prozkoumá, jak vytvářet různé typy geografických vizualizací pomocí knihovny Folium, od základních map až po komplexní překryvné vrstvy a interaktivní funkce.

## Práce s polygony a čarami

Folium umožňuje kreslit různé tvary na mapy:

```python
# Vytvoření mapy se středem v Central Parku, NY
central_park_map = folium.Map(location=[40.7829, -73.9654], zoom_start=14)

# Nakreslení polygonu (obrys Central Parku - zjednodušený)
central_park_coords = [
    [40.7682, -73.9818],
    [40.7682, -73.9493],
    [40.8006, -73.9493],
    [40.8006, -73.9818]
]

folium.Polygon(
    locations=central_park_coords,
    color='green',
    fill=True,
    fill_color='green',
    fill_opacity=0.4,
    popup='Central Park'
).add_to(central_park_map)

# Přidání lomené čáry (5. Avenue)
fifth_avenue = [
    [40.7392, -73.9903],
    [40.8130, -73.9654]
]

folium.PolyLine(
    locations=fifth_avenue,
    color='red',
    weight=5,
    opacity=0.8,
    popup='5. Avenue'
).add_to(central_park_map)

# Přidání obdélníku
folium.Rectangle(
    bounds=[[40.7728, -73.9718], [40.7800, -73.9630]],
    color='blue',
    fill=True,
    fill_opacity=0.3,
    popup='The Lake'
).add_to(central_park_map)

central_park_map
```

## Teplotní mapy

Teplotní mapy jsou užitečné pro vizualizaci hustoty a intenzity bodových dat:

```python
# Generování náhodných bodových dat v okolí San Francisca
np.random.seed(42)
num_points = 500
data = np.random.normal(loc=[37.76, -122.45], scale=[0.1, 0.1], size=(num_points, 2))

# Vytvoření mapy se středem v San Franciscu
sf_map = folium.Map(location=[37.76, -122.45], zoom_start=12)

# Přidání vrstvy teplotní mapy
HeatMap(data).add_to(sf_map)

# Přidání titulku
title_html = '''
             <h3 align="center" style="font-size:16px"><b>Teplotní mapa aktivit v San Franciscu</b></h3>
             '''
sf_map.get_root().html.add_child(folium.Element(title_html))

sf_map
```

Můžete také vytvářet pokročilejší teplotní mapy s váženými daty:

```python
# Vytvoření vážených bodových dat (např. znázorňující intenzitu kriminality)
weighted_data = []
for i in range(num_points):
    # Každý bod má lokaci a váhu
    lat, lon = data[i]
    weight = np.random.uniform(0.1, 1.0)  # Náhodná váha mezi 0.1 a 1.0
    weighted_data.append([lat, lon, weight])

# Vytvoření mapy pro váženou teplotní mapu
weighted_map = folium.Map(location=[37.76, -122.45], zoom_start=12)

# Přidání vrstvy vážené teplotní mapy
```

## Reálné aplikace

### Vizualizace dat o počasí

```python
# Vytvoření mapy zobrazující data o počasí pro hlavní města
weather_data = {
    'City': ['New York', 'Los Angeles', 'Chicago', 'Miami', 'Denver'],
    'Latitude': [40.7128, 34.0522, 41.8781, 25.7617, 39.7392],
    'Longitude': [-74.0060, -118.2437, -87.6298, -80.1918, -104.9903],
    'Temperature': [45, 75, 32, 82, 50],  # ve stupních Fahrenheita
    'Weather': ['Zataženo', 'Slunečno', 'Sněžení', 'Slunečno', 'Polojasno']
}

weather_df = pd.DataFrame(weather_data)

# Vytvoření mapy počasí
weather_map = folium.Map(location=[39.8283, -98.5795], zoom_start=4)

# Funkce pro určení ikony počasí
def get_weather_icon(weather):
    icons = {
        'Slunečno': 'sun',
        'Zataženo': 'cloud',
        'Sněžení': 'snowflake',
        'Polojasno': 'cloud-sun'
    }
    return icons.get(weather, 'question')

# Funkce pro určení barvy podle teploty
def get_temp_color(temp):
    if temp < 32:
        return 'blue'
    elif temp < 50:
        return 'lightblue'
    elif temp < 70:
        return 'green'
    elif temp < 85:
        return 'orange'
    else:
        return 'red'

# Přidání značek počasí
for idx, row in weather_df.iterrows():
    html = f"""
        <h4>{row['City']}</h4>
        <p>Teplota: {row['Temperature']}°F</p>
        <p>Podmínky: {row['Weather']}</p>
    """
    
    folium.Marker(
        location=[row['Latitude'], row['Longitude']],
        popup=folium.Popup(html=html, max_width=200),
        tooltip=f"{row['City']}: {row['Temperature']}°F",
        icon=folium.Icon(
            color=get_temp_color(row['Temperature']),
            icon=get_weather_icon(row['Weather']),
            prefix='fa'
        )
    ).add_to(weather_map)

weather_map
```

### Analýza trhu s nemovitostmi

```python
# Ukázková data o nemovitostech
properties = {
    'Address': [
        '123 Main St, Portland, OR',
        '456 Oak Ave, Portland, OR',
        '789 Pine St, Portland, OR',
        '101 Maple Dr, Portland, OR',
        '202 Cedar Ln, Portland, OR'
    ],
    'Price': [450000, 625000, 375000, 550000, 825000],
    'Type': ['Dům', 'Byt', 'Dům', 'Řadový dům', 'Dům'],
    'Bedrooms': [3, 2, 2, 3, 4],
    'Latitude': [45.5260, 45.5312, 45.5190, 45.5153, 45.5368],
    'Longitude': [-122.6850, -122.6795, -122.6730, -122.6608, -122.6550]
}

real_estate_df = pd.DataFrame(properties)

# Vytvoření mapy nemovitostí
real_estate_map = folium.Map(location=[45.5236, -122.6750], zoom_start=14)

# Funkce pro určení ikony podle typu nemovitosti
def get_property_icon(prop_type):
    icons = {
        'Dům': {'icon': 'home', 'color': 'blue'},
        'Byt': {'icon': 'building', 'color': 'red'},
        'Řadový dům': {'icon': 'city', 'color': 'purple'}
    }
    return icons.get(prop_type, {'icon': 'question', 'color': 'gray'})

# Přidání značek nemovitostí
for idx, row in real_estate_df.iterrows():
    icon_info = get_property_icon(row['Type'])
    
    html = f"""
        <h4>{row['Address']}</h4>
        <p>Cena: ${row['Price']:,}</p>
        <p>Typ: {row['Type']}</p>
        <p>Ložnice: {row['Bedrooms']}</p>
    """
    
    folium.Marker(
        location=[row['Latitude'], row['Longitude']],
        popup=folium.Popup(html=html, max_width=300),
        tooltip=f"${row['Price']:,}",
        icon=folium.Icon(
            color=icon_info['color'],
            icon=icon_info['icon'],
            prefix='fa'
        )
    ).add_to(real_estate_map)

# Přidání teplotní mapy cen
price_data = [[row['Latitude'], row['Longitude'], row['Price']/100000] for _, row in real_estate_df.iterrows()]
HeatMap(price_data, radius=25, gradient={0.4: 'blue', 0.65: 'lime', 1: 'red'}).add_to(real_estate_map)

# Přidání legendy
legend_html = '''
<div style="position: fixed; 
     bottom: 50px; right: 50px; width: 170px; height: 120px; 
     border:2px solid grey; z-index:9999; font-size:14px;
     background-color:white; padding: 10px;
     opacity: 0.8;">
     <b>Typy nemovitostí</b><br>
     <i class="fa fa-home fa-lg" style="color:blue"></i> Dům<br>
     <i class="fa fa-building fa-lg" style="color:red"></i> Byt<br>
     <i class="fa fa-city fa-lg" style="color:purple"></i> Řadový dům
</div>
'''

real_estate_map.get_root().html.add_child(folium.Element(legend_html))

real_estate_map
```

## Shrnutí

Geografická vizualizace s Folium poskytuje výkonný způsob vizualizace a analýzy prostorových dat. Zde jsou klíčové poznatky:

1. **Interaktivní mapy**: Folium vytváří webové interaktivní mapy, které lze přibližovat, posouvat a prozkoumávat.

2. **Všestranné možnosti vizualizace**: Od základních značek až po složité choroplethové mapy a teplotní mapy, Folium podporuje různé techniky vizualizace geografických dat.

3. **Integrace s ekosystémem Pythonu**: Folium bezproblémově spolupracuje s populárními knihovnami pro datovou vědu jako Pandas, což usnadňuje jeho začlenění do vašeho pracovního postupu analýzy dat.

4. **Přizpůsobení**: Mapy lze rozsáhle přizpůsobit pomocí různých mapových podkladů, ikon, barev a interaktivních prvků.

5. **Dostupnost**: Mapy Folium lze exportovat jako HTML soubory a sdílet s kýmkoli, kdo má webový prohlížeč, aniž by vyžadovaly znalost Pythonu.

6. **Reálné aplikace**: Geografické vizualizace jsou cenné pro širokou škálu aplikací včetně obchodní inteligence, epidemiologie, městského plánování, analýzy nemovitostí a environmentální vědy.

7. **Open Source a podpora komunity**: Folium je open-source projekt s dobrou podporou komunity a dokumentací.

Zvládnutím Folium můžete přidat prostorový rozměr k vaší analýze dat a vytvořit přesvědčivé interaktivní vizualizace, které odhalují vzory a poznatky, které by mohly být přehlédnuty v tradičních grafech a tabulkách.
