## 1. Úvod do vícenásobných grafů a podgrafů

Vícenásobné grafy a podgrafy umožňují zobrazit několik vizualizací v rámci jednoho obrázku, což umožňuje porovnání dat vedle sebe, vícerozměrné zkoumání dat a komplexní prezentaci příběhu dat. Podgrafy pomáhají uspořádat související vizualizace, šetří místo a usnadňují divákům vytvářet souvislosti mezi různými aspekty dat.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení tématu pro vizuální konzistenci
plt.style.use('seaborn-v0_8-whitegrid')

# Zjištění verze matplotlib
print(f"Verze Matplotlib: {plt.__version__}")

# Generování vzorových dat
np.random.seed(42)  # Pro reprodukovatelnost
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)
y3 = np.sin(x) * np.exp(-x/5)
y4 = x**2 / 30
```

Klíčové výhody použití podgrafů:
- Porovnávání více datových souborů nebo pohledů na stejná data
- Zobrazení vztahů mezi různými proměnnými
- Prezentace postupu analýzy nebo různých aspektů výsledků
- Úspora místa při prezentaci komplexních informací
- Vytváření pohledů podobných dashboardům na vaše data

## 2. Základní vytváření podgrafů s knihovnou Matplotlib

Matplotlib nabízí několik způsobů, jak vytvářet podgrafy. Nejběžnější metody jsou `plt.subplot()` a `plt.subplots()`. První vytváří jeden podgraf v danou chvíli, zatímco druhá vytváří mřížku podgrafů najednou.

```python
# Metoda 1: Použití plt.subplot()
plt.figure(figsize=(12, 4))

# Vytvoření prvního podgrafu (1 řádek, 3 sloupce, první pozice)
plt.subplot(1, 3, 1)
plt.plot(x, y1, 'b-')
plt.title('Sinusová vlna')
plt.xlabel('x')
plt.ylabel('sin(x)')

# Vytvoření druhého podgrafu (1 řádek, 3 sloupce, druhá pozice)
plt.subplot(1, 3, 2)
plt.plot(x, y2, 'r-')
plt.title('Kosinusová vlna')
plt.xlabel('x')
plt.ylabel('cos(x)')

# Vytvoření třetího podgrafu (1 řádek, 3 sloupce, třetí pozice)
plt.subplot(1, 3, 3)
plt.plot(x, y3, 'g-')
plt.title('Tlumená sinusová vlna')
plt.xlabel('x')
plt.ylabel('sin(x) * exp(-x/5)')

plt.tight_layout()  # Úprava mezer mezi podgrafy
plt.show()

# Metoda 2: Použití plt.subplots() - vytváří všechny podgrafy najednou
fig, axes = plt.subplots(nrows=1, ncols=3, figsize=(12, 4))

# Vykreslení na každé ose
axes[0].plot(x, y1, 'b-')
axes[0].set_title('Sinusová vlna')
axes[0].set_xlabel('x')
axes[0].set_ylabel('sin(x)')

axes[1].plot(x, y2, 'r-')
axes[1].set_title('Kosinusová vlna')
axes[1].set_xlabel('x')
axes[1].set_ylabel('cos(x)')

axes[2].plot(x, y3, 'g-')
axes[2].set_title('Tlumená sinusová vlna')
axes[2].set_xlabel('x')
axes[2].set_ylabel('sin(x) * exp(-x/5)')

plt.tight_layout()
plt.show()
```

Klíčové rozdíly mezi oběma metodami:
- `plt.subplot()`: Stavové API, vytváří jeden podgraf v danou chvíli
- `plt.subplots()`: Objektově orientované API, vrací objekty figure a axes
- Objektově orientovaný přístup (druhá metoda) nabízí větší flexibilitu a je obecně doporučován pro složité vizualizace

## 3. Práce s objekty Figure a Axes

Pochopení vztahu mezi objekty Figure a Axes je klíčové pro vytváření efektivních podgrafů. Figure je celkový kontejner pro všechny grafy, zatímco každý Axes představuje jednotlivý podgraf v rámci Figure.

```python
# Explicitní vytvoření objektů Figure a Axes
fig = plt.figure(figsize=(15, 5))

# Přidání tří objektů Axes do figure na konkrétní pozice
# Parametry jsou: [levý, dolní, šířka, výška] v souřadnicích figure (0-1)
ax1 = fig.add_axes([0.1, 0.1, 0.25, 0.8])  # Levý podgraf
ax2 = fig.add_axes([0.4, 0.1, 0.25, 0.8])  # Prostřední podgraf
ax3 = fig.add_axes([0.7, 0.1, 0.25, 0.8])  # Pravý podgraf

# Vykreslení dat na každé ose
ax1.plot(x, y1, 'b-')
ax1.set_title('Sinusová vlna')
ax1.set_xlabel('x')
ax1.set_ylabel('sin(x)')

ax2.plot(x, y2, 'r-')
ax2.set_title('Kosinusová vlna')
ax2.set_xlabel('x')
ax2.set_ylabel('cos(x)')

ax3.plot(x, y3, 'g-')
ax3.set_title('Tlumená sinusová vlna')
ax3.set_xlabel('x')
ax3.set_ylabel('sin(x) * exp(-x/5)')

plt.show()

# Vytvoření figure s hlavním grafem a vloženým grafem
fig = plt.figure(figsize=(8, 6))
ax_main = fig.add_axes([0.1, 0.1, 0.8, 0.8])  # Hlavní osa
ax_inset = fig.add_axes([0.55, 0.55, 0.3, 0.3])  # Vložená osa

# Vykreslení na hlavní ose
ax_main.plot(x, y3, 'g-')
ax_main.set_title('Tlumená sinusová vlna s přiblíženou částí')
ax_main.set_xlabel('x')
ax_main.set_ylabel('sin(x) * exp(-x/5)')

# Vykreslení přiblížené části ve vloženém grafu
ax_inset.plot(x[:30], y3[:30], 'r-')
ax_inset.set_title('Přiblížení', fontsize=9)
ax_inset.tick_params(labelsize=8)

plt.show()
```

Práce s objekty Figure a Axes poskytuje:
- Přesnou kontrolu nad umístěním podgrafů
- Možnost vytvářet vnořené grafy (grafy v grafech)
- Větší flexibilitu pro přizpůsobení jednotlivých grafů
- Lepší kontrolu nad sdílenými vlastnostmi mezi grafy

## 4. Rozložení mřížky pro uspořádání podgrafů

Podgrafy lze uspořádat v různých mřížkových rozloženích podle potřeb vizualizace. Matplotlib poskytuje flexibilní způsoby pro vytváření pravidelných i nepravidelných mřížkových vzorů.

```python
# Pravidelná mřížka s plt.subplots()
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8))

# Vykreslení na každé ose pomocí indexování
axes[0, 0].plot(x, y1)
axes[0, 0].set_title('Sinusová vlna')

axes[0, 1].plot(x, y2)
axes[0, 1].set_title('Kosinusová vlna')

axes[1, 0].plot(x, y3)
axes[1, 0].set_title('Tlumená sinusová vlna')

axes[1, 1].plot(x, y4)
axes[1, 1].set_title('Kvadratická funkce')

plt.tight_layout()
plt.show()

# Komplexní rozložení mřížky s GridSpec
import matplotlib.gridspec as gridspec

fig = plt.figure(figsize=(12, 8))
gs = gridspec.GridSpec(2, 3)  # 2 řádky, 3 sloupce

# Vytvoření podgrafů s různým rozpětím
ax1 = fig.add_subplot(gs[0, :])  # První řádek, všechny sloupce
ax2 = fig.add_subplot(gs[1, 0])  # Druhý řádek, první sloupec
ax3 = fig.add_subplot(gs[1, 1])  # Druhý řádek, druhý sloupec
ax4 = fig.add_subplot(gs[1, 2])  # Druhý řádek, třetí sloupec

# Vykreslení dat
ax1.plot(x, y1, 'b-')
ax1.set_title('Horní řádek: Sinusová vlna (přes všechny sloupce)')

ax2.plot(x, y2, 'r-')
ax2.set_title('Kosinusová vlna')

ax3.plot(x, y3, 'g-')
ax3.set_title('Tlumená sinusová')

ax4.plot(x, y4, 'y-')
ax4.set_title('Kvadratická')

plt.tight_layout()
plt.show()
```

Další techniky pro rozložení mřížky:
- `plt.subplot2grid()`: Vytváření nepravidelných rozložení mřížky
- `gridspec.GridSpecFromSubplotSpec()`: Vytváření vnořených specifikací mřížky
- `fig.add_gridspec()`: Moderní způsob vytváření specifikací mřížky přímo z objektu figure

## 5. Sdílené osy a měřítka

Sdílení os mezi podgrafy pomáhá zachovat konzistentní měřítka a redukuje redundantní informace, což usnadňuje porovnávání dat napříč více grafy.

```python
# Vytváření podgrafů se sdílenými osami
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8), 
                         sharex=True, sharey=True)

# Generování dat s podobnými rozsahy, ale různými vzory
data1 = np.random.normal(0, 1, 100).cumsum()
data2 = np.random.normal(0, 1, 100).cumsum()
data3 = np.random.normal(0, 1, 100).cumsum()
data4 = np.random.normal(0, 1, 100).cumsum()

# Vykreslení dat na podgrafech
axes[0, 0].plot(data1, 'r-')
axes[0, 0].set_title('Dataset 1')

axes[0, 1].plot(data2, 'g-')
axes[0, 1].set_title('Dataset 2')

axes[1, 0].plot(data3, 'b-')
axes[1, 0].set_title('Dataset 3')

axes[1, 1].plot(data4, 'k-')
axes[1, 1].set_title('Dataset 4')

# Pouze spodní podgrafy potřebují x-popisky (kvůli sdílené ose x)
axes[1, 0].set_xlabel('Hodnoty X')
axes[1, 1].set_xlabel('Hodnoty X')

# Pouze levé podgrafy potřebují y-popisky (kvůli sdílené ose y)
axes[0, 0].set_ylabel('Hodnoty Y')
axes[1, 0].set_ylabel('Hodnoty Y')

plt.tight_layout()
plt.show()

# Podgrafy s různými konfiguracemi sdílení
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Ručně sdílíme osu x mezi grafy ve stejném sloupci
axes[0, 0].get_shared_x_axes().join(axes[0, 0], axes[1, 0])
axes[0, 1].get_shared_x_axes().join(axes[0, 1], axes[1, 1])

# Ručně sdílíme osu y mezi grafy ve stejném řádku
axes[0, 0].get_shared_y_axes().join(axes[0, 0], axes[0, 1])
axes[1, 0].get_shared_y_axes().join(axes[1, 0], axes[1, 1])

# Vykreslení s úmyslně různými rozsahy
axes[0, 0].plot(np.sin(x))
axes[0, 0].set_title('Sin - Sdílený X s grafem níže, sdílený Y s grafem vpravo')

axes[0, 1].plot(2 * np.sin(x))
axes[0, 1].set_title('2×Sin - Sdílený X s grafem níže, sdílený Y s grafem vlevo')

axes[1, 0].plot(np.cos(x))
axes[1, 0].set_title('Cos - Sdílený X s grafem nahoře, sdílený Y s grafem vpravo')

axes[1, 1].plot(2 * np.cos(x))
axes[1, 1].set_title('2×Cos - Sdílený X s grafem nahoře, sdílený Y s grafem vlevo')

plt.tight_layout()
plt.show()
```

Výhody sdílených os:
- Zajišťují přímé vizuální porovnání mezi grafy
- Redukují redundantní popisky os a značky
- Šetří prostor a vytvářejí čistší vizualizace
- Pomáhají divákům snadněji identifikovat vzory a rozdíly

## 6. Kombinování různých typů grafů

Jednou z předností použití podgrafů je možnost kombinovat různé typy vizualizací pro poskytnutí doplňujících pohledů na stejná nebo související data.

```python
# Vytvoření dat pro různé typy grafů
np.random.seed(42)
data = pd.DataFrame({
    'x': np.random.normal(0, 1, 1000),
    'y': np.random.normal(0, 1, 1000),
    'category': np.random.choice(['A', 'B', 'C', 'D'], 1000)
})

# Vytvoření figure s různými typy grafů
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# 1. Bodový graf
axes[0, 0].scatter(data['x'], data['y'], alpha=0.5)
axes[0, 0].set_title('Bodový graf')
axes[0, 0].set_xlabel('Hodnoty X')
axes[0, 0].set_ylabel('Hodnoty Y')

# 2. Histogram
axes[0, 1].hist(data['x'], bins=30, alpha=0.7, color='green')
axes[0, 1].set_title('Histogram X')
axes[0, 1].set_xlabel('Hodnota')
axes[0, 1].set_ylabel('Četnost')

# 3. Sloupcový graf
category_counts = data['category'].value_counts()
axes[1, 0].bar(category_counts.index, category_counts.values, color='orange')
axes[1, 0].set_title('Sloupcový graf kategorií')
axes[1, 0].set_xlabel('Kategorie')
axes[1, 0].set_ylabel('Počet')

# 4. Krabicový graf s knihovnou Seaborn
sns.boxplot(x='category', y='x', data=data, ax=axes[1, 1])
axes[1, 1].set_title('Krabicový graf podle kategorie')
axes[1, 1].set_xlabel('Kategorie')
axes[1, 1].set_ylabel('Distribuce hodnot X')

plt.tight_layout()
plt.show()

# Kombinace souvisejících vizualizací pro lepší vhled
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Vytvoření korelovaných dat
n = 100
t = np.linspace(0, 2*np.pi, n)
x1 = np.sin(t) + np.random.normal(0, 0.2, n)
x2 = np.cos(t) + np.random.normal(0, 0.2, n)

# 1. Graf časových řad
axes[0, 0].plot(t, x1, 'b-', label='sin(t)')
axes[0, 0].plot(t, x2, 'r-', label='cos(t)')
axes[0, 0].set_title('Časová řada')
axes[0, 0].set_xlabel('Čas')
axes[0, 0].set_ylabel('Hodnota')
axes[0, 0].legend()

# 2. Bodový graf obou řad
axes[0, 1].scatter(x1, x2, alpha=0.7)
axes[0, 1].set_title('X1 vs X2')
axes[0, 1].set_xlabel('X1 (sin)')
axes[0, 1].set_ylabel('X2 (cos)')

# 3 & 4. Histogramy každé řady
axes[1, 0].hist(x1, bins=20, alpha=0.7, color='blue')
axes[1, 0].set_title('Histogram X1')
axes[1, 0].set_xlabel('Hodnota')
axes[1, 0].set_ylabel('Četnost')

axes[1, 1].hist(x2, bins=20, alpha=0.7, color='red')
axes[1, 1].set_title('Histogram X2')
axes[1, 1].set_xlabel('Hodnota')
axes[1, 1].set_ylabel('Četnost')

plt.tight_layout()
plt.show()
```

Tipy pro kombinování různých typů grafů:
- Vybírejte doplňující vizualizace, které zdůrazňují různé aspekty dat
- Udržujte konzistentní barevné schéma napříč souvisejícími grafy
- Uspořádejte grafy v logické sekvenci nebo vztahu
- Zvažte použití sdílených os, kde je to vhodné
- Zahrňte jasné nadpisy a popisky os pro vedení diváka

## 7. Velikost a rozestupy podgrafů

Správné nastavení velikosti a rozestupů podgrafů je zásadní pro vytvoření jasných, čitelných vizualizací. Matplotlib poskytuje několik nástrojů pro kontrolu těchto aspektů.

```python
# Kontrola velikosti figure a rozestupů podgrafů
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Vykreslení jednoduchých dat na všech podgrafech
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))
        axes[i, j].set_title(f'Podgraf [{i}, {j}]')

# Výchozí rozestupy - často příliš těsné
plt.suptitle('Výchozí rozestupy podgrafů', fontsize=16)
plt.show()

# Použití tight_layout() pro zlepšení rozestupů
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Vykreslení jednoduchých dat na všech podgrafech
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))
        axes[i, j].set_title(f'Podgraf [{i}, {j}]')

plt.tight_layout()
plt.suptitle('S funkcí tight_layout()', fontsize=16, y=1.05)  # Úprava y pro zabránění překrytí
plt.show()

# Použití subplots_adjust pro jemnou kontrolu
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Vykreslení jednoduchých dat na všech podgrafech
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))
        axes[i, j].set_title(f'Podgraf [{i}, {j}]')

plt.subplots_adjust(left=0.1,    # Levý okraj
                   right=0.9,    # Pravý okraj
                   bottom=0.1,   # Dolní okraj
                   top=0.9,      # Horní okraj
                   wspace=0.4,   # Šířka mezery mezi podgrafy
                   hspace=0.4)   # Výška mezery mezi podgrafy

plt.suptitle('Vlastní rozestupy s funkcí subplots_adjust()', fontsize=16)
plt.show()

# GridSpec s poměry šířky a výšky
fig = plt.figure(figsize=(12, 8))
gs = gridspec.GridSpec(2, 2, width_ratios=[2, 1], height_ratios=[1, 2])

# Vytvoření podgrafů s vlastními velikostmi
ax1 = fig.add_subplot(gs[0, 0])  # Nahoře vlevo, široký
ax2 = fig.add_subplot(gs[0, 1])  # Nahoře vpravo, úzký
ax3 = fig.add_subplot(gs[1, 0])  # Dole vlevo, široký a vysoký
ax4 = fig.add_subplot(gs[1, 1])  # Dole vpravo, úzký a vysoký

ax1.plot(np.random.rand(10))
ax1.set_title('Široký graf')

ax2.plot(np.random.rand(10))
ax2.set_title('Úzký graf')

ax3.plot(np.random.rand(10))
ax3.set_title('Široký a vysoký graf')

ax4.plot(np.random.rand(10))
ax4.set_title('Úzký a vysoký graf')

plt.tight_layout()
plt.show()
```

Klíčové techniky pro kontrolu velikosti a rozestupů podgrafů:
- `figsize`: Nastavení celkových rozměrů figure
- `plt.tight_layout()`: Automatické nastavení parametrů podgrafů pro optimální rozestupy
- `plt.subplots_adjust()`: Jemné doladění rozestupů s explicitními parametry
- `width_ratios` a `height_ratios` v `GridSpec`: Kontrola relativních velikostí podgrafů
- Omezené rozložení: `plt.figure(constrained_layout=True)`: Alternativa k tight_layout

## 8. Přidávání titulků a popisků k více podgrafům

Jasné titulky a popisky pomáhají divákům pochopit, co sledují. U více podgrafů jsou často potřeba jak jednotlivé titulky, tak celkový titulek obrázku.

```python
# Vytvoření figure s podgrafy a komplexním popisem
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Vzorová data
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)
y3 = np.sin(x) * np.exp(-x/5)
y4 = np.cos(x) * np.exp(-x/5)

# Graf 1
axes[0, 0].plot(x, y1, 'b-')
axes[0, 0].set_title('Sinusová vlna', fontsize=14)
axes[0, 0].set_xlabel('Hodnoty X')
axes[0, 0].set_ylabel('Amplituda')

# Graf 2
axes[0, 1].plot(x, y2, 'r-')
axes[0, 1].set_title('Kosinusová vlna', fontsize=14)
axes[0, 1].set_xlabel('Hodnoty X')
axes[0, 1].set_ylabel('Amplituda')

# Graf 3
axes[1, 0].plot(x, y3, 'g-')
axes[1, 0].set_title('Tlumená sinusová vlna', fontsize=14)
axes[1, 0].set_xlabel('Hodnoty X')
axes[1, 0].set_ylabel('Amplituda')

# Graf 4
axes[1, 1].plot(x, y4, 'm-')
axes[1, 1].set_title('Tlumená kosinusová vlna', fontsize=14)
axes[1, 1].set_xlabel('Hodnoty X')
axes[1, 1].set_ylabel('Amplituda')

# Přidání celkového titulku a podtitulku figure
fig.suptitle('Trigonometrické funkce', fontsize=20, fontweight='bold', y=0.98)
plt.figtext(0.5, 0.92, 'Zobrazení základních a tlumených trigonometrických funkcí', 
           ha='center', fontsize=14, fontstyle='italic')

# Přidání anotací nebo vysvětlivek pro celý obrázek
plt.figtext(0.5, 0.01, 
           'Poznámka: Tlumené funkce klesají exponenciálně s exp(-x/5)', 
           ha='center', fontsize=12)

# Přidání legendy pro všechny podgrafy na vlastní pozici
legend_elements = [
    plt.Line2D([0], [0], color='b', label='sin(x)'),
    plt.Line2D([0], [0], color='r', label='cos(x)'),

# Přidání označení podgrafů (a), (b), atd. pro publikaci
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Vykreslení dat v každém podgrafu
for i in range(2):
    for j in range(2):
        axes[i, j].plot(np.random.rand(10))

subplot_labels = ['(a)', '(b)', '(c)', '(d)']
label_idx = 0

for i in range(2):
    for j in range(2):
        # Přidání označení v levém horním rohu každého podgrafu
        axes[i, j].text(0.05, 0.95, subplot_labels[label_idx], 
                      transform=axes[i, j].transAxes,
                      fontsize=16, fontweight='bold', va='top')
        
        axes[i, j].set_title(f'Podgraf {subplot_labels[label_idx]}')
        label_idx += 1

plt.tight_layout()
plt.suptitle('Označování podgrafů ve stylu publikací', fontsize=16, y=1.05)
plt.show()
```

Efektivní postupy pro titulkování:
- Použití `fig.suptitle()` pro celkové titulky figure
- Použití `ax.set_title()` pro titulky jednotlivých podgrafů
- Použití `plt.figtext()` pro další vysvětlivky nebo anotace
- Zvážení přidání označení podgrafů ((a), (b), atd.) pro reference v publikacích
- Použití `plt.annotate()` pro zvýraznění konkrétních funkcí v grafech
- Ujištění se, že titulky jsou popisné, ale stručné

## 9. Pokročilé techniky práce s podgrafy

Kromě základních podgrafů nabízí matplotlib pokročilé techniky pro složitější scénáře vizualizace.

```python
# 1. Vložené grafy: grafy v grafech
fig, ax = plt.subplots(figsize=(10, 6))

# Hlavní graf
x = np.linspace(0, 10, 1000)
y = np.sin(x) * np.exp(-x/5)
ax.plot(x, y, 'b-')
ax.set_title('Tlumená sinusová vlna s přiblíženým vloženým grafem', fontsize=14)
ax.set_xlabel('Hodnoty X')
ax.set_ylabel('Amplituda')

# Vytvoření vloženého grafu
axins = ax.inset_axes([0.55, 0.55, 0.3, 0.3])  # [x, y, šířka, výška] v relativních souřadnicích
axins.plot(x[:200], y[:200], 'r-')
axins.set_title('Přiblížení první vlny', fontsize=10)
axins.tick_params(labelsize=8)

# Vykreslení rámečku kolem přiblížené oblasti
ax.indicate_inset_zoom(axins, edgecolor='gray')

plt.tight_layout()
plt.show()

# 2. Sekundární osa Y pro různá měřítka
fig, ax1 = plt.subplots(figsize=(10, 6))

# Data s různými měřítky
x = np.linspace(0, 10, 100)
y1 = np.sin(x)           # Rozsah: -1 až 1
y2 = 100 * np.cos(x)     # Rozsah: -100 až 100

# Primární osa y
color = 'tab:blue'
ax1.plot(x, y1, color=color)
ax1.set_xlabel('Hodnoty X')
ax1.set_ylabel('sin(x)', color=color)
ax1.tick_params(axis='y', labelcolor=color)

# Sekundární osa y
ax2 = ax1.twinx()
color = 'tab:red'
ax2.plot(x, y2, color=color)
ax2.set_ylabel('cos(x) × 100', color=color)
ax2.tick_params(axis='y', labelcolor=color)

fig.tight_layout()
plt.title('Graf se dvěma měřítky')
plt.show()

# 3. Vnořené GridSpecs
fig = plt.figure(figsize=(12, 8))
outer_grid = fig.add_gridspec(2, 2)

# Vlevo nahoře: Jeden graf
ax_top_left = fig.add_subplot(outer_grid[0, 0])
ax_top_left.plot(np.random.rand(10))
ax_top_left.set_title('Samostatný graf')

# Vpravo nahoře: 2 podgrafy ve sloupci
inner_top_right = gridspec.GridSpecFromSubplotSpec(2, 1, subplot_spec=outer_grid[0, 1])
ax_tr1 = fig.add_subplot(inner_top_right[0])
ax_tr2 = fig.add_subplot(inner_top_right[1])
ax_tr1.plot(np.random.rand(10), 'r-')
ax_tr2.plot(np.random.rand(10), 'g-')
ax_tr1.set_title('Vpravo nahoře - Horní')
ax_tr2.set_title('Vpravo nahoře - Dolní')

# Vlevo dole: 2 podgrafy v řadě
inner_bottom_left = gridspec.GridSpecFromSubplotSpec(1, 2, subplot_spec=outer_grid[1, 0])
ax_bl1 = fig.add_subplot(inner_bottom_left[0])
ax_bl2 = fig.add_subplot(inner_bottom_left[1])
ax_bl1.plot(np.random.rand(10), 'm-')
ax_bl2.plot(np.random.rand(10), 'y-')
ax_bl1.set_title('Vlevo dole - Levý')
ax_bl2.set_title('Vlevo dole - Pravý')

# Vpravo dole: Mřížka 2×2
inner_bottom_right = gridspec.GridSpecFromSubplotSpec(2, 2, subplot_spec=outer_grid[1, 1])
for i in range(2):
    for j in range(2):
        ax = fig.add_subplot(inner_bottom_right[i, j])
        ax.plot(np.random.rand(10), 'k-')
        ax.set_title(f'VD [{i},{j}]')

plt.tight_layout()
plt.show()

# 4. Kombinování Seaborn a Matplotlib
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Vytvoření vzorového datasetu
titanic = sns.load_dataset('titanic')

# Matplotlib bodový graf
axes[0, 0].scatter(titanic['age'], titanic['fare'], 
                 c=titanic['survived'], cmap='viridis', alpha=0.7)
axes[0, 0].set_title('Matplotlib bodový graf: Věk vs. Jízdné')
axes[0, 0].set_xlabel('Věk')
axes[0, 0].set_ylabel('Jízdné')

# Seaborn krabicový graf
sns.boxplot(x='class', y='age', data=titanic, ax=axes[0, 1])
axes[0, 1].set_title('Seaborn krabicový graf: Věk podle třídy')

# Seaborn počítací graf
sns.countplot(x='class', hue='survived', data=titanic, ax=axes[1, 0])
axes[1, 0].set_title('Seaborn počítací graf: Přežití podle třídy')

# Seaborn teplotní mapa korelační matice
correlation = titanic.select_dtypes(include=[np.number]).corr()
sns.heatmap(correlation, annot=True, fmt='.2f', cmap='coolwarm', 
          square=True, linewidths=0.5, ax=axes[1, 1])
axes[1, 1].set_title('Korelační teplotní mapa')

plt.tight_layout()
plt.show()
```

Pokročilé techniky:
- Vložené grafy: Zobrazení přiblíženého detailu konkrétní oblasti
- Sekundární osy: Zobrazení dat s různými měřítky na stejném grafu
- Vnořené specifikace mřížek: Vytváření komplexních rozložení s hierarchickou organizací
- Míchání knihoven pro vykreslování: Kombinace matplotlib se seaborn nebo jinými knihovnami
- Vlastní umístění podgrafů: Umístění podgrafů přesně tam, kde je potřeba

## 10. Shrnutí a osvědčené postupy

Vícenásobné grafy a podgrafy jsou mocnými nástroji pro komplexní vizualizaci dat. Umožňují zobrazit související informace společně, což umožňuje porovnávání a poskytuje kontext, který by mohl být ztracen v oddělených obrázcích.

Klíčové poznatky:
1. **Zvolte správný přístup**: Použijte `plt.subplots()` pro většinu případů díky jeho flexibilitě a objektově orientované povaze.
2. **Plánujte své rozložení**: Rozhodněte se o počtu a uspořádání podgrafů na základě příběhu vašich dat.
3. **Sdílejte osy, když je to vhodné**: Používejte sdílené osy k zachování konzistentních měřítek napříč souvisejícími grafy.
4. **Dbejte na rozestupy**: Používejte `tight_layout()` nebo `subplots_adjust()` pro zajištění správných rozestupů mezi podgrafy.
5. **Komplexně popisujte**: Doplňte jasné titulky, popisky os a legendy pro každý podgraf.
6. **Zvažte různé typy grafů**: Kombinujte doplňující vizualizace pro zdůraznění různých aspektů vašich dat.
7. **Vytvořte vizuální hierarchii**: Použijte velikost a pozici pro zdůraznění důležitých grafů.
8. **Zachovávejte konzistenci**: Používejte konzistentní barevná schémata, měřítka a styly napříč souvisejícími podgrafy.
9. **Přidávejte kontext**: Doplňte celkový titulek obrázku a anotace pro vedení diváka.
10. **Optimalizujte pro médium**: Zvažte, kde bude vaše vizualizace prohlížena (papír, obrazovka, prezentace) při určování rozložení a velikosti.

```python
# Kompletní příklad spojující osvědčené postupy
np.random.seed(42)

# Vytvoření vzorových dat
n_points = 100
x = np.linspace(0, 10, n_points)
y1 = np.sin(x) + np.random.normal(0, 0.2, n_points)
y2 = np.cos(x) + np.random.normal(0, 0.2, n_points)

# Vytvoření komplexního obrázku s více typy grafů
fig = plt.figure(figsize=(15, 10))
gs = gridspec.GridSpec(2, 3, width_ratios=[1, 1, 1.2])

# 1. Graf časové řady (vlevo nahoře)
ax1 = fig.add_subplot(gs[0, 0])
ax1.plot(x, y1, 'b-', label='sin(x)')
ax1.plot(x, y2, 'r-', label='cos(x)')
ax1.set_title('Časová řada', fontweight='bold')
ax1.set_xlabel('Hodnoty X')
ax1.set_ylabel('Hodnota')
ax1.legend()
ax1.grid(True, alpha=0.3)

# 2. Bodový graf (uprostřed nahoře)
ax2 = fig.add_subplot(gs[0, 1])
ax2.scatter(y1, y2, alpha=0.7, c=x, cmap='viridis')
ax2.set_title('Vztah Y1 vs Y2', fontweight='bold')
ax2.set_xlabel('sin(x) + šum')
ax2.set_ylabel('cos(x) + šum')
ax2.grid(True, alpha=0.3)

# 3. Histogramy (vpravo nahoře, s podgrafy)
ax3 = fig.add_subplot(gs[0, 2])
ax3.hist(y1, bins=20, alpha=0.5, label='sin(x)', color='blue')
ax3.hist(y2, bins=20, alpha=0.5, label='cos(x)', color='red')
ax3.set_title('Distribuce hodnot', fontweight='bold')
ax3.set_xlabel('Hodnota')
ax3.set_ylabel('Četnost')
ax3.legend()
ax3.grid(True, alpha=0.3)

# 4. Teplotní mapa (vlevo dole)
ax4 = fig.add_subplot(gs[1, 0])
# Vytvoření 2D dat pro teplotní mapu
xx, yy = np.meshgrid(np.linspace(-2, 2, 30), np.linspace(-2, 2, 30))
zz = np.sin(xx) * np.cos(yy)
im = ax4.imshow(zz, cmap='coolwarm', origin='lower', extent=[-2, 2, -2, 2])
ax4.set_title('2D funkce: sin(x)cos(y)', fontweight='bold')
ax4.set_xlabel('Osa X')
ax4.set_ylabel('Osa Y')
plt.colorbar(im, ax=ax4, label='Hodnota')

# 5. Krabicový graf (uprostřed dole)
ax5 = fig.add_subplot(gs[1, 1])
data = [y1, y2]
ax5.boxplot(data, labels=['sin(x)', 'cos(x)'])
ax5.set_title('Rozsahy hodnot', fontweight='bold')
ax5.set_ylabel('Hodnota')
ax5.grid(True, alpha=0.3)

# 6. Graf klouzavého průměru se stínovaným intervalem spolehlivosti (vpravo dole)
ax6 = fig.add_subplot(gs[1, 2])
from scipy.ndimage import gaussian_filter1d

# Výpočet klouzavého průměru a směrodatné odchylky
smoothed1 = gaussian_filter1d(y1, sigma=3)
smoothed2 = gaussian_filter1d(y2, sigma=3)
std1 = np.std(y1 - smoothed1)
std2 = np.std(y2 - smoothed2)

ax6.plot(x, smoothed1, 'b-', linewidth=2, label='sin(x) trend')
ax6.fill_between(x, smoothed1 - std1, smoothed1 + std1, color='blue', alpha=0.2)
ax6.plot(x, smoothed2, 'r-', linewidth=2, label='cos(x) trend')
ax6.fill_between(x, smoothed2 - std2, smoothed2 + std2, color='red', alpha=0.2)
ax6.set_title('Vyhlazené trendy s intervalem spolehlivosti', fontweight='bold')
ax6.set_xlabel('Hodnoty X')
ax6.set_ylabel('Vyhlazená hodnota')
ax6.legend()
ax6.grid(True, alpha=0.3)

# Přidání celkového titulku a popisu
fig.suptitle('Komplexní příklad analýzy dat', fontsize=20, fontweight='bold', y=0.98)
plt.figtext(0.5, 0.92, 'Několik vizualizačních technik aplikovaných na zašuměná data sinus a kosinus', 
           ha='center', fontsize=14, fontstyle='italic')

plt.tight_layout()
plt.subplots_adjust(top=0.88)  # Vytvoření prostoru pro titulek
plt.show()
```

Zvládnutím podgrafů a vícenásobných grafů budete schopni vytvářet komplexnější a informativnější vizualizace, které efektivně komunikují příběh vašich dat.
