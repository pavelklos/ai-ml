## 1. Úvod do výběru grafů

Výběr správného typu grafu je klíčový pro efektivní vizualizaci dat. Špatný graf může zakrýt důležité poznatky nebo dokonce zavádět publikum, zatímco správná volba okamžitě zvýrazní vzory a vztahy. Výběr grafu závisí na:

- Typu dat, se kterými pracujete
- Sdělení, které chcete komunikovat
- Vztahu, který chcete zdůraznit
- Obeznámenosti vašeho publika s typy grafů

Začněme nastavením našeho prostředí s potřebnými knihovnami:

```python
# Import základních knihoven pro různé typy grafů
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import plotly.express as px
from matplotlib.colors import LinearSegmentedColormap
from sklearn.datasets import load_iris

# Nastavení stylů pro konzistentní vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_theme(style="whitegrid")
sns.set_context("notebook", font_scale=1.2)

# Pro reprodukovatelnost
np.random.seed(42)

# Vytvoření vzorových datových sad pro naše příklady
# Vzorová kategoriální data
categories = ['Kategorie A', 'Kategorie B', 'Kategorie C', 'Kategorie D', 'Kategorie E']
values = [23, 35, 12, 27, 18]

# Vzorová data časové řady
dates = pd.date_range('2023-01-01', periods=100, freq='D')
time_series = pd.Series(np.cumsum(np.random.randn(100)) + 10, index=dates)

# Vzorová vztahová data
x = np.random.normal(0, 1, 100)
y = x * 0.5 + np.random.normal(0, 1, 100)
categories_small = np.random.choice(['Skupina A', 'Skupina B', 'Skupina C'], 100)
sizes = np.random.randint(10, 100, 100)

# Vzorová multivariační data
iris = load_iris()
iris_df = pd.DataFrame(iris.data, columns=iris.feature_names)
iris_df['species'] = iris.target_names[iris.target]

print("Příprava dat dokončena. Připraveno k průzkumu grafů.")
```

## 2. Porozumění typům dat a vztahům grafů

Před rozhodnutím o typu grafu je důležité pochopit povahu vašich dat a jaké vztahy se snažíte vizualizovat:

- **Nominální data**: Kategorie bez přirozeného pořadí (např. produkty, země)
- **Ordinální data**: Kategorie s konkrétním pořadím (např. hodnocení, úrovně vzdělání)
- **Intervalová data**: Číselná data, kde rozdíly mají význam (např. teplota)
- **Poměrová data**: Číselná data s pravou nulou a smysluplnými poměry (např. výška, váha)

Rámec výběru grafu také závisí na tom, co se snažíte ukázat:


## 3. Srovnávací grafy: Pruhové, sloupcové a bodové grafy

Používejte srovnávací grafy, když chcete ukázat rozdíly mezi kategoriemi nebo položkami:

- **Pruhové grafy**: Pro srovnání hodnot napříč kategoriemi
- **Sloupcové grafy**: Podobné pruhovým grafům, ale s vertikální orientací
- **Bodové grafy**: Pro přesné srovnání s menší vizuální váhou

```python
# Vytvoření obrázku s podgrafy pro různé srovnávací grafy
fig, axes = plt.subplots(3, 1, figsize=(10, 12))

# Horizontální pruhový graf

axes[0].set_title('Horizontální pruhový graf', fontsize=14)
axes[0].set_xlabel('Hodnota')
axes[0].set_ylabel('Kategorie')

# Vertikální sloupcový graf

axes[1].set_xlabel('Kategorie')
axes[1].set_ylabel('Hodnota')
axes[1].tick_params(axis='x', rotation=45)

# Bodový graf
sns.scatterplot(x=values, y=categories, s=100, ax=axes[2], color='darkblue')
axes[2].set_title('Bodový graf', fontsize=14)
axes[2].set_xlabel('Hodnota')
```

## 4. Distribuční grafy: Histogramy a grafy hustoty

Distribuční grafy ukazují, jak jsou hodnoty distribuovány v rámci rozsahu:

- **Histogramy**: Pro zobrazení frekvenční distribuce číselných dat
- **Grafy hustoty**: Pro vyhlazené distribuce, zvláště užitečné pro porovnání více distribucí
- **Krabicové grafy**: Pro zobrazení statistik distribuce (medián, kvartily, odlehlé hodnoty)

```python
# Generování náhodných dat z různých distribucí
data1 = np.random.normal(0, 1, 1000)  # Normální distribuce
data2 = np.random.exponential(2, 1000)  # Exponenciální distribuce
data3 = np.concatenate([np.random.normal(-3, 1, 500), np.random.normal(3, 1, 500)])  # Bimodální

# Vytvoření obrázku s podgrafy
fig, axes = plt.subplots(3, 1, figsize=(10, 12))

# Histogram
sns.histplot(data1, bins=30, kde=True, ax=axes[0], color='skyblue')
axes[0].set_title('Histogram s KDE', fontsize=14)
axes[0].set_xlabel('Hodnota')
axes[0].set_ylabel('Četnost')

# Graf hustoty srovnávající distribuce
sns.kdeplot(data1, ax=axes[1], label='Normální')
sns.kdeplot(data2, ax=axes[1], label='Exponenciální')
sns.kdeplot(data3, ax=axes[1], label='Bimodální')
sns[1].set_title('Grafy hustoty pro porovnání distribucí', fontsize=14)
axes[1].set_xlabel('Hodnota')
axes[1].set_ylabel('Hustota')
axes[1].legend()

# Krabicový graf s houslovým grafem
plot_data = pd.DataFrame({
    'Normální': data1,
    'Exponenciální': data2,
    'Bimodální': data3
})
plot_data = plot_data.melt(var_name='Distribuce', value_name='Hodnota')
sns.violinplot(x='Distribuce', y='Hodnota', data=plot_data, inner='box', ax=axes[2])
axes[2].set_title('Houslový graf s krabicovým grafem uvnitř', fontsize=14)
axes[2].set_ylabel('Hodnota')

plt.tight_layout()
plt.show()

print("Použijte histogramy, když:")
print("- Chcete ukázat frekvenční distribuci jedné proměnné")
print("- Potřebujete pochopit tvar distribuce")
print("\nPoužijte grafy hustoty, když:")
print("- Porovnáváte více distribucí")

print("- Potřebujete ukázat klíčové statistiky o distribucích")

```

## 5. Vztahové grafy: Bodové grafy a bublinové grafy

Vztahové grafy odhalují spojení mezi dvěma nebo více proměnnými:

- **Bodové grafy**: Pro zobrazení korelace mezi dvěma proměnnými
- **Bublinové grafy**: Pro zobrazení vztahů mezi třemi proměnnými
- **Teplotní mapy**: Pro zobrazení vztahů mezi mnoha proměnnými

```python
# Vytvoření obrázku s podgrafy
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Základní bodový graf
sns.scatterplot(x=x, y=y, ax=axes[0, 0])
axes[0, 0].set_title('Základní bodový graf', fontsize=14)
axes[0, 0].set_xlabel('Proměnná X')
axes[0, 0].set_ylabel('Proměnná Y')

# Bodový graf s kategoriálními barvami
sns.scatterplot(x=x, y=y, hue=categories_small, ax=axes[0, 1])
axes[0, 1].set_title('Bodový graf s kategoriemi', fontsize=14)
axes[0, 1].set_xlabel('Proměnná X')
axes[0, 1].set_ylabel('Proměnná Y')
axes[0, 1].legend(title='Skupina')

# Bublinový graf (bodový graf s velikostí)
sns.scatterplot(x=x, y=y, size=sizes, hue=categories_small, 
               sizes=(20, 200), ax=axes[1, 0])
axes[1, 0].set_title('Bublinový graf', fontsize=14)
axes[1, 0].set_xlabel('Proměnná X')
axes[1, 0].set_ylabel('Proměnná Y')
axes[1, 0].legend(title='Skupina')

# Korelační teplotní mapa použitím dat iris
correlation = iris_df.iloc[:, :4].corr()
sns.heatmap(correlation, annot=True, cmap='coolwarm', 
           vmin=-1, vmax=1, ax=axes[1, 1])
axes[1, 1].set_title('Korelační teplotní mapa', fontsize=14)

plt.tight_layout()
plt.show()

print("Použijte bodové grafy, když:")
print("- Zkoumáte vztah mezi dvěma spojitými proměnnými")
print("- Hledáte korelace nebo vzory")
```

## 6. Grafy časových řad

Grafy časových řad ukazují, jak se data mění v průběhu času:

- **Čárové grafy**: Pro zobrazení trendů v čase
- **Plošné grafy**: Pro zdůraznění rozsahu trendů
- **Svíčkové grafy**: Pro finanční data s hodnotami open, high, low, close


## 7. Grafy části a celku: Koláčové, prstencové grafy a stromové mapy

Grafy části a celku ukazují, jak jednotlivé komponenty přispívají k celku:

- **Koláčové grafy**: Pro zobrazení proporcí celku, když je málo kategorií
- **Prstencové grafy**: Variace koláčových grafů s lepším využitím prostoru
- **Stromové mapy**: Pro hierarchické vztahy části a celku s mnoha kategoriemi

```python
# Vytvoření obrázku s podgrafy
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Koláčový graf
axes[0, 0].pie(values, labels=categories, autopct='%1.1f%%', 
              startangle=90, shadow=True)
axes[0, 0].set_title('Koláčový graf', fontsize=14)
axes[0, 0].axis('equal')  # Rovnoměrný poměr stran zajišťuje, že koláč je vykreslen jako kruh

# Prstencový graf
axes[0, 1].pie(values, labels=categories, autopct='%1.1f%%', 
              startangle=90, wedgeprops=dict(width=0.5))
axes[0, 1].set_title('Prstencový graf', fontsize=14)
axes[0, 1].axis('equal')

# Skládaný sloupcový graf
categories_df = pd.DataFrame({
    'Kategorie': categories,
    'Hodnota': values,
    'Skupina': ['Skupina 1', 'Skupina 1', 'Skupina 2', 'Skupina 2', 'Skupina 3']
})
grouped = categories_df.groupby('Skupina')['Hodnota'].sum()
axes[1, 0].bar(grouped.index, grouped.values)
axes[1, 0].set_title('Skupinový sloupcový graf', fontsize=14)
axes[1, 0].set_xlabel('Skupina')
axes[1, 0].set_ylabel('Celková hodnota')

# Stromová mapa s plotly (pro čtvrtý podgraf ukážeme kód, ale neprovedeme ho in-line)

axes[1, 1].set_title('Zástupce stromové mapy', fontsize=14)
axes[1, 1].axis('off')

plt.tight_layout()
plt.show()
```

## 8. Grafy pro hierarchická a kategoriální data

Tyto grafy pomáhají vizualizovat data s vnořenými kategoriemi nebo hierarchiemi:

- **Skupinové sloupcové grafy**: Pro srovnání napříč kategoriemi a podkategoriemi
- **Teplotní mapy**: Pro zobrazení vztahů mezi dvěma kategoriálními proměnnými
- **Paralelní souřadnice**: Pro multivariační data s mnoha dimenzemi

```python
# Vytvoření vzorových dat pro hierarchickou vizualizaci
categories_nested = pd.DataFrame({
    'HlavníKategorie': ['A', 'A', 'A', 'B', 'B', 'B', 'C', 'C', 'C'],

axes[0].set_ylabel('Hodnota')
axes[0].legend(title='Podkategorie')
```

## 10. Shrnutí a osvědčené postupy

Výběr správného typu grafu je jak umění, tak věda. Zde jsou klíčové principy, které by měly vést váš výběr:

1. **Přizpůsobte graf svému sdělení**: Začněte identifikací toho, co má vaše publikum pochopit.

2. **Zohledněte typ vašich dat**:
   - Kategoriální srovnání → Pruhové/sloupcové grafy
   - Distribuce → Histogramy, krabicové grafy
   - Vztahy → Bodové grafy, teplotní mapy
   - Časové řady → Čárové grafy
   - Části a celek → Koláčové grafy (střídmě), stromové mapy

3. **Udržujte jednoduchost**: Jednodušší grafy jsou často efektivnější. Přidávejte složitost pouze tehdy, když přináší hodnotu.

4. **Respektujte osvědčené postupy vizualizace**:
   - Začínejte osy pruhových grafů na nule
   - Používejte koláčové grafy pouze pro malý počet kategorií
   - Vybírejte vhodné barevné schéma
   - Popisujte přímo, když je to možné, spíše než použitím legend

5. **Poznejte své publikum**: Zvažte jejich obeznámenost s typy grafů a datovou gramotností.

6. **Testujte svou vizualizaci**: Ptejte se ostatních, zda rychle pochopí vaš hlavní sdělení.
