## Úvod

Rozšířená realita (AR) a virtuální realita (VR) představují transformativní přístup k vizualizaci dat, který překračuje tradiční 2D rozhraní a vytváří imerzivní, prostorová prostředí. AR překrývá digitální informace přes fyzický svět, zatímco VR vytváří zcela imerzivní digitální prostředí. Tyto technologie umožňují analytikům zkoumat komplexní datové soubory způsoby, které využívají lidské prostorové vnímání, a potenciálně odhalují vzory a vztahy neviditelné v tradičních vizualizacích.

AR/VR vizualizace nabízejí několik unikátních výhod:
- Přirozené prostorové chápání vícerozměrných dat
- Fyzická navigace a interakce s daty
- Spolupráce při zkoumání dat ve sdílených prostorech
- Imerzivní vyprávění datových příběhů a prezentace

Tato příručka zkoumá, jak mohou vývojáři v Pythonu využít AR/VR technologie pro intuitivnější a silnější vizualizační zážitky při práci s daty.

## Základy vizualizace v AR/VR

### Porozumění imerzivním vizualizacím

AR/VR datové vizualizace se liší od tradičních přístupů v několika klíčových ohledech:

- **Prostorové dimenze**: Skutečný 3D prostor namísto simulovaného 3D na 2D obrazovce
- **Vtělené poznání**: Využití fyzické interakce a pohybu

import plotly.graph_objects as go
import numpy as np

# Generování shlukovaných 3D dat
np.random.seed(42)

bodu_na_shluk = 100
data = []

for i in range(shluky):
    stred = np.random.uniform(-5, 5, 3)

## Techniky vizualizace dat v AR

Vizualizace dat v AR překrývá digitální informace přes fyzický svět. Python může generovat data pro AR platformy.

### Příprava dat pro AR

```python
import pandas as pd
import numpy as np
import json

def priprava_dat_pro_ar(df, sloupce_pozice, sloupec_hodnot, sloupec_nazvu=None):
    """
    Připraví dataframe pro export AR vizualizace
    
    Parametry:
    -----------
    df : pandas DataFrame
        Vstupní data
    sloupce_pozice : list
        Názvy sloupců pro souřadnice [x, y, z] nebo [lat, lon]
    sloupec_hodnot : str
        Název sloupce pro vizualizovanou hodnotu
    sloupec_nazvu : str, volitelné
        Název sloupce pro označení bodů
    
    Vrací:
    --------
    str
        JSON formátovaná data připravená pro AR aplikace
    """
    ar_data = []
    
    for _, row in df.iterrows():
        bod = {
            "pozice": [float(row[col]) for col in sloupce_pozice],
            "hodnota": float(row[sloupec_hodnot])
        }
        
        if sloupec_nazvu:
            bod["popisek"] = str(row[sloupec_nazvu])
            
        ar_data.append(bod)
    
    return json.dumps({"body": ar_data})

# Příklad: Příprava geoprostorových dat pro AR
df_geo = pd.DataFrame({
    'zemepisna_sirka': [50.0755, 49.1951, 49.8175, 50.2331, 49.7384],
    'zemepisna_delka': [14.4378, 16.6068, 15.4730, 12.8747, 13.3929],
    'mesto': ['Praha', 'Brno', 'Olomouc', 'Ústí nad Labem', 'Plzeň'],
    'hodnota': [1.3, 0.38, 0.1, 0.09, 0.17]  # Populace v milionech
})

ar_ready_geo = priprava_dat_pro_ar(
    df_geo,
    ['zemepisna_sirka', 'zemepisna_delka'],
    'hodnota',
    'mesto'
)

print(ar_ready_geo)
```

## Interaktivní průzkum dat ve VR

Interaktivita je klíčová pro efektivní průzkum dat ve VR prostředích. Tato část ukazuje, jak strukturovat interaktivní funkce pro vizualizaci dat ve VR.

### Interaktivní funkce pro průzkum dat ve VR

```python
# Konceptuální Python kód pro model interakce ve VR

class VRModelInterakce:
    """
    Definuje možnosti interakce pro vizualizaci dat ve VR
    """
    def __init__(self, zdroj_dat):
        self.data = zdroj_dat
        self.vyber = set()
        self.filtry = {}
        self.zvyraznena_dimenze = None
        
    def vybrat_bod(self, id_bodu):
        """Vybere datový bod ve VR"""
        self.vyber.add(id_bodu)
        return self.ziskat_detaily_bodu(id_bodu)
    
    def filtrovat_podle_rozsahu(self, dimenze, min_hodnota, max_hodnota):
        """Filtruje data podle dimenzionálního rozsahu"""
        self.filtry[dimenze] = (min_hodnota, max_hodnota)
        return self.ziskat_filtrovana_data()
    
    def zvyraznit_dimenzi(self, dimenze):
        """Zvýrazní specifickou datovou dimenzi"""
        self.zvyraznena_dimenze = dimenze
        return {
            "dimenze": dimenze,
            "statistiky": {
                "min": self.data[dimenze].min(),
                "max": self.data[dimenze].max(),
                "prumer": self.data[dimenze].mean()
            }
        }
    
    def ziskat_filtrovana_data(self):
        """Vrátí data po aplikaci všech filtrů"""
        vysledek = self.data.copy()
        for dim, (min_val, max_val) in self.filtry.items():
            vysledek = vysledek[(vysledek[dim] >= min_val) & (vysledek[dim] <= max_val)]
        return vysledek
    
    def ziskat_detaily_bodu(self, id_bodu):
        """Získá detailní informace o datovém bodu"""
        return self.data.iloc[id_bodu].to_dict()
```

## Optimalizace výkonu

AR/VR aplikace vyžadují efektivní vykreslování pro dobrý uživatelský zážitek. Zde jsou techniky pro optimalizaci výkonu:

```python
import numpy as np
import pandas as pd

def optimalizovat_data_pro_vr(df, max_bodu=1000):
    """
    Optimalizuje dataset pro VR vykreslování snížením počtu bodů
    při zachování distribuce dat
    """
    n_rows = len(df)
    
    if n_rows <= max_bodu:
        return df  # Optimalizace není potřeba
    
    # Metoda 1: Jednoduché náhodné vzorkování
    if n_rows <= max_bodu * 10:
        return df.sample(max_bodu)
        
    # Metoda 2: Stratifikované vzorkování, pokud existují kategorické sloupce
    kategorialni_sloupce = df.select_dtypes(include=['object', 'category']).columns
    if len(kategorialni_sloupce) > 0:
        strat_sloupec = kategorialni_sloupce[0]
        try:
            return df.groupby(strat_sloupec).apply(
                lambda x: x.sample(min(len(x), max(1, int(max_bodu * len(x) / n_rows))))
            ).reset_index(drop=True)
        except:
            pass  # Fallback na shlukování, pokud stratifikované vzorkování selže
    
    # Metoda 3: Shlukování na základě centroidů pro velké datasety
    from sklearn.cluster import MiniBatchKMeans
    
    # Vyberte pouze numerické sloupce pro shlukování
    num_sloupce = df.select_dtypes(include=np.number).columns
    if len(num_sloupce) < 3:
        return df.sample(max_bodu)  # Nedostatek dimenzí pro smysluplné shlukování
    
    # Normalizace numerických dat pro shlukování
    from sklearn.preprocessing import StandardScaler
    X = StandardScaler().fit_transform(df[num_sloupce])
    
    # Výpočet optimálního počtu shluků 
    k = min(max_bodu, n_rows // 10)
    
    # Provedení shlukování
    kmeans = MiniBatchKMeans(n_clusters=k, random_state=42)
    df['shluk'] = kmeans.fit_predict(X)
    
    # Vzorkování z každého shluku
    vysledek = df.groupby('shluk').apply(
        lambda x: x.sample(min(len(x), max(1, int(max_bodu * len(x) / n_rows))))
    ).reset_index(drop=True)
    
    return vysledek.drop(columns=['shluk'])
```

## Případová studie: Imerzivní analytický dashboard

Tato případová studie ukazuje, jak vytvořit komplexní imerzivní analytický dashboard pro finanční data.

```python
import pandas as pd
import numpy as np
import plotly.graph_objects as go
from flask import Flask, render_template, jsonify

# Generování finančního datasetu pro vizualizaci
def generovat_financni_dataset():
    """Generování syntetických finančních dat pro imerzivní vizualizaci"""
    np.random.seed(42)
    
    # Generování časových řad
    datumy = pd.date_range(start='2020-01-01', end='2022-12-31', freq='B')
    n_akcii = 50
    
    # Vytvoření cen akcií s realistickými korelacemi
    zakladni_cena = 100
    ceny = {}
    
    # Tržní faktor (ovlivňuje všechny akcie)
    trh = np.cumsum(np.random.normal(0.0005, 0.01, len(datumy)))
    
    # Sektorové faktory (5 sektorů)
    sektory = {
        f"Sektor_{i}": np.cumsum(np.random.normal(0.0002, 0.008, len(datumy)))
        for i in range(5)
    }
    
    # Přiřazení akcií k sektorům
    akcie_sektory = np.random.choice(list(sektory.keys()), n_akcii)
    
    # Generování cen akcií
    for i in range(n_akcii):
        nazev_akcie = f"Akcie_{i:02d}"
        sektor = akcie_sektory[i]
        
        # Kombinace tržních, sektorových a individuálních faktorů
        pohyb_akcie = (
            0.5 * trh +  # Tržní efekt
            0.3 * sektory[sektor] +  # Sektorový efekt
            0.2 * np.cumsum(np.random.normal(0.0001, 0.015, len(datumy)))  # Individuální efekt
        )
        
        # Vytvoření cenové řady
        pocatecni_cena = zakladni_cena * np.random.uniform(0.5, 2.0)
        ceny[nazev_akcie] = pocatecni_cena * np.exp(pohyb_akcie)
    
    # Vytvoření DataFrame
    df = pd.DataFrame(ceny, index=datumy)
    
    # Přidání informací o sektoru
    mapovani_sektoru = {f"Akcie_{i:02d}": akcie_sektory[i] for i in range(n_akcii)}
    
    return df, mapovani_sektoru

# Generování dat
akcie_df, sektory = generovat_financni_dataset()

# Vytvoření Flask aplikace pro poskytování VR dashboardu
app = Flask(__name__)

@app.route('/')
def index():
    return render_template('financni_vr_dashboard.html')

@app.route('/api/akcie')
def get_stocks():
    # Vrácení seznamu akcií s jejich sektory
    akcie = [{"nazev": akcie, "sektor": sektor} 
              for akcie, sektor in sektory.items()]
    return jsonify(akcie)

@app.route('/api/ceny')
def get_prices():
    # Převod časových řad na 3D souřadnice pro VR
    # X: čas, Y: cena, Z: volatilita (klouzavá směrodatná odchylka)
    
    vysledek = []
    
    for sloupec in akcie_df.columns:
        cenova_rada = akcie_df[sloupec]
        volatilita = cenova_rada.pct_change().rolling(20).std().fillna(0)
        
        body = []
        for i, (datum, cena) in enumerate(cenova_rada.items()):
            # Přeskočení některých bodů pro výkon
            if i % 5 == 0:
                body.append({
                    "datum": datum.strftime("%Y-%m-%d"),
                    "x": i / len(cenova_rada) * 10,  # Škálování na 0-10
                    "y": float(cena / cenova_rada.iloc[0]),  # Normalizace k počáteční ceně
                    "z": float(volatilita.iloc[i] * 50),  # Škálování volatility
                    "cena": float(cena),
                    "volatilita": float(volatilita.iloc[i])
                })
        
        vysledek.append({
            "akcie": sloupec,
            "sektor": sektory[sloupec],
            "body": body
        })
    
    return jsonify(vysledek)

if __name__ == '__main__':
    app.run(debug=True)
```
