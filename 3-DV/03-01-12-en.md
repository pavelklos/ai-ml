## 1. Introduction to Chart Selection

Selecting the right chart type is crucial for effective data visualization. The wrong chart can obscure insights or even mislead your audience, while the right choice makes patterns and relationships immediately apparent. Chart selection depends on:

- The type of data you're working with
- The message you want to communicate
- The relationship you want to highlight
- Your audience's familiarity with chart types

Let's begin by setting up our environment with necessary libraries:


## 2. Understanding Data Types and Chart Relationships

Before deciding on a chart type, it's essential to understand the nature of your data and what relationships you're trying to visualize:

- **Nominal data**: Categories without inherent order (e.g., products, countries)
- **Ordinal data**: Categories with a specific order (e.g., ratings, education levels)
- **Interval data**: Numeric data where differences are meaningful (e.g., temperature)
- **Ratio data**: Numeric data with a true zero and meaningful ratios (e.g., height, weight)

The chart selection framework also depends on what you're trying to show:

## 3. Comparative Charts: Bar, Column, and Dot Plots

Use comparative charts when you want to show differences between categories or items:

- **Bar Charts**: For comparing values across categories
- **Column Charts**: Similar to bar charts but with vertical orientation
- **Dot Plots**: For precise comparisons with less visual weight

```python
# Create a figure with subplots for different comparative charts
fig, axes = plt.subplots(3, 1, figsize=(10, 12))

# Horizontal bar chart
sns.barplot(x=values, y=categories, ax=axes[0], palette='viridis')
axes[0].set_title('Horizontal Bar Chart', fontsize=14)
axes[0].set_xlabel('Value')
axes[0].set_ylabel('Category')

# Vertical column chart
sns.barplot(x=categories, y=values, ax=axes[1], palette='viridis')
axes[1].set_title('Vertical Column Chart', fontsize=14)
axes[1].set_xlabel('Category')
axes[1].set_ylabel('Value')
axes[1].tick_params(axis='x', rotation=45)

# Dot plot
sns.scatterplot(x=values, y=categories, s=100, ax=axes[2], color='darkblue')
axes[2].set_title('Dot Plot', fontsize=14)
axes[2].set_xlabel('Value')
axes[2].set_ylabel('Category')
axes[2].grid(True, axis='x')

plt.tight_layout()
plt.show()

# When to use each type:
print("Use bar/column charts when:")
print("- Comparing values across categories")
print("- You have distinct categories with single values")
print("- Showing ranks or comparisons")
print("\nUse dot plots when:")
print("- You need a more minimalist comparison")
print("- Precise value comparisons are important")
print("- You want to reduce chart ink for cleaner visualization")
```

## 4. Distribution Charts: Histograms and Density Plots

Distribution charts show how values are distributed across a range:

- **Histograms**: For showing frequency distribution of numerical data
- **Density Plots**: For smooth distributions, especially useful for comparing multiple distributions
- **Box Plots**: For showing the distribution's statistics (median, quartiles, outliers)

```python
# Generate some random data from different distributions
data1 = np.random.normal(0, 1, 1000)  # Normal distribution
data2 = np.random.exponential(2, 1000)  # Exponential distribution
data3 = np.concatenate([np.random.normal(-3, 1, 500), np.random.normal(3, 1, 500)])  # Bimodal

# Create a figure with subplots
fig, axes = plt.subplots(3, 1, figsize=(10, 12))

# Histogram
sns.histplot(data1, bins=30, kde=True, ax=axes[0], color='skyblue')
axes[0].set_title('Histogram with KDE', fontsize=14)
axes[0].set_xlabel('Value')
axes[0].set_ylabel('Frequency')

# Density plot comparing distributions
sns.kdeplot(data1, ax=axes[1], label='Normal')
sns.kdeplot(data2, ax=axes[1], label='Exponential')
sns.kdeplot(data3, ax=axes[1], label='Bimodal')
axes[1].set_title('Density Plots for Comparing Distributions', fontsize=14)
axes[1].set_xlabel('Value')
axes[1].set_ylabel('Density')
axes[1].legend()

# Box plot with violin plot
plot_data = pd.DataFrame({
    'Normal': data1,
    'Exponential': data2,
    'Bimodal': data3
})
plot_data = plot_data.melt(var_name='Distribution', value_name='Value')
sns.violinplot(x='Distribution', y='Value', data=plot_data, inner='box', ax=axes[2])
axes[2].set_title('Violin Plot with Box Plot Inside', fontsize=14)
axes[2].set_ylabel('Value')

plt.tight_layout()
plt.show()

print("Use histograms when:")
print("- You want to show the frequency distribution of a single variable")
print("- You need to understand the shape of a distribution")
print("\nUse density plots when:")
print("- Comparing multiple distributions")
print("- You want a smoother representation of the distribution")
print("\nUse box/violin plots when:")
print("- You need to show key statistics about distributions")
print("- Comparing distributions across categories")
```

## 5. Relationship Charts: Scatter Plots and Bubble Charts

Relationship charts reveal connections between two or more variables:

- **Scatter Plots**: For showing correlation between two variables
- **Bubble Charts**: For showing relationships between three variables
- **Heatmaps**: For showing relationships between many variables

```python
# Create a figure with subplots
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Basic scatter plot
sns.scatterplot(x=x, y=y, ax=axes[0, 0])
axes[0, 0].set_title('Basic Scatter Plot', fontsize=14)
axes[0, 0].set_xlabel('Variable X')
axes[0, 0].set_ylabel('Variable Y')

# Scatter plot with categorical colors
sns.scatterplot(x=x, y=y, hue=categories_small, ax=axes[0, 1])
axes[0, 1].set_title('Scatter Plot with Categories', fontsize=14)
axes[0, 1].set_xlabel('Variable X')
axes[0, 1].set_ylabel('Variable Y')
axes[0, 1].legend(title='Group')

# Bubble chart (scatter plot with size)
sns.scatterplot(x=x, y=y, size=sizes, hue=categories_small, 
               sizes=(20, 200), ax=axes[1, 0])
axes[1, 0].set_title('Bubble Chart', fontsize=14)
axes[1, 0].set_xlabel('Variable X')
axes[1, 0].set_ylabel('Variable Y')
axes[1, 0].legend(title='Group')

# Correlation heatmap using iris data
correlation = iris_df.iloc[:, :4].corr()
sns.heatmap(correlation, annot=True, cmap='coolwarm', 
           vmin=-1, vmax=1, ax=axes[1, 1])
axes[1, 1].set_title('Correlation Heatmap', fontsize=14)

plt.tight_layout()
plt.show()

print("Use scatter plots when:")
print("- Examining the relationship between two continuous variables")
print("- Looking for correlations or patterns")
print("- Identifying clusters or outliers")
print("\nUse bubble charts when:")
print("- You have three variables to visualize")
print("- The third variable can be represented by size")
print("\nUse heatmaps when:")
print("- Showing correlations between many variables")
print("- Visualizing matrices or tabular data")
```

## 7. Part-to-Whole Charts: Pie, Donut, and Treemaps

Part-to-whole charts show how individual components contribute to a total:

- **Pie Charts**: For showing proportions of a whole when there are few categories
- **Donut Charts**: A variation of pie charts with better space utilization
- **Treemaps**: For hierarchical part-to-whole relationships with many categories

```python
# Create a figure with subplots
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# Pie chart
axes[0, 0].pie(values, labels=categories, autopct='%1.1f%%', 
              startangle=90, shadow=True)
axes[0, 0].set_title('Pie Chart', fontsize=14)
axes[0, 0].axis('equal')  # Equal aspect ratio ensures that pie is drawn as a circle

# Donut chart
axes[0, 1].pie(values, labels=categories, autopct='%1.1f%%', 
              startangle=90, wedgeprops=dict(width=0.5))
axes[0, 1].set_title('Donut Chart', fontsize=14)
axes[0, 1].axis('equal')

# Stacked bar chart
categories_df = pd.DataFrame({
    'Category': categories,
    'Value': values,
    'Group': ['Group 1', 'Group 1', 'Group 2', 'Group 2', 'Group 3']
})
grouped = categories_df.groupby('Group')['Value'].sum()
axes[1, 0].bar(grouped.index, grouped.values)
axes[1, 0].set_title('Grouped Bar Chart', fontsize=14)
axes[1, 0].set_xlabel('Group')
axes[1, 0].set_ylabel('Total Value')

# Treemap with plotly (for the fourth subplot, we'll show the code but not execute it in-line)
axes[1, 1].text(0.5, 0.5, "Treemap would be shown here\n(Using Plotly in separate cell)", 
                ha='center', va='center', fontsize=12)
axes[1, 1].set_title('Treemap Placeholder', fontsize=14)
axes[1, 1].axis('off')

plt.tight_layout()
plt.show()

# Now create the treemap using plotly
import plotly.express as px

# Create hierarchical data for the treemap
treemap_data = pd.DataFrame({
    'Category': categories * 3,
    'Value': values * 3,
    'Group': ['Group 1', 'Group 1', 'Group 2', 'Group 2', 'Group 3'] * 3,
    'Subgroup': np.repeat(['A', 'B', 'C'], 5)
})

fig = px.treemap(
    treemap_data, 
    path=['Group', 'Subgroup', 'Category'],
    values='Value',
    title='Hierarchical Treemap'
)
fig.show()

print("Use pie/donut charts when:")
print("- Showing parts of a whole")
print("- You have a small number of categories (ideally less than 7)")
print("- The parts sum to a meaningful whole")
print("\nUse treemaps when:")
print("- Showing hierarchical part-to-whole relationships")
print("- You have many categories")
print("- Comparing proportions across different levels")
print("\nUse stacked bars when:")
print("- You need more accurate comparison than a pie chart allows")
print("- Showing part-to-whole relationships over time or categories")
```

## 8. Hierarchical and Categorical Data Charts

These charts help visualize data with nested categories or hierarchies:

- **Grouped Bar Charts**: For comparing across categories and subcategories
- **Heatmaps**: For showing relationships between two categorical variables
- **Parallel Coordinates**: For multivariate data with many dimensions

```python
# Create sample data for hierarchical visualization
categories_nested = pd.DataFrame({
    'MainCategory': ['A', 'A', 'A', 'B', 'B', 'B', 'C', 'C', 'C'],
    'SubCategory': ['X', 'Y', 'Z', 'X', 'Y', 'Z', 'X', 'Y', 'Z'],
    'Value': [15, 25, 10, 30, 20, 8, 12, 18, 22]
})

# Create a figure with subplots
fig, axes = plt.subplots(2, 1, figsize=(12, 12))

# Grouped bar chart
sns.barplot(x='MainCategory', y='Value', hue='SubCategory', 
           data=categories_nested, ax=axes[0])
axes[0].set_title('Grouped Bar Chart for Hierarchical Data', fontsize=14)
axes[0].set_xlabel('Main Category')
axes[0].set_ylabel('Value')
axes[0].legend(title='Sub Category')

# Create a pivot table for the heatmap
heatmap_data = categories_nested.pivot(
    index='MainCategory', 
    columns='SubCategory', 
    values='Value'
)

# Categorical heatmap
sns.heatmap(heatmap_data, annot=True, cmap='YlGnBu', fmt='d', ax=axes[1])
axes[1].set_title('Heatmap for Categorical Data', fontsize=14)

plt.tight_layout()
plt.show()

# Parallel Coordinates Plot (using Plotly)
import plotly.express as px

# Using the iris dataset for parallel coordinates
fig = px.parallel_coordinates(
    iris_df, 
    color="species",
    labels={col: col.replace("_", " ") for col in iris_df.columns},
    title="Parallel Coordinates Plot for Multivariate Data"
)
fig.show()

print("Use grouped bar charts when:")
print("- Comparing values across categories and subcategories")
print("- Showing hierarchical relationships")
print("\nUse categorical heatmaps when:")
print("- Showing relationships between two categorical variables")
print("- Displaying a matrix of values across categories")
print("\nUse parallel coordinates when:")
print("- Visualizing multivariate data with many dimensions")
print("- Identifying patterns across multiple variables")
```

## 10. Summary and Best Practices

Choosing the right chart type is both an art and a science. Here are key principles to guide your selection:

1. **Match the chart to your message**: Start by identifying what you want your audience to understand.

2. **Consider your data type**:
   - Categorical comparisons → Bar/column charts
   - Distributions → Histograms, box plots
   - Relationships → Scatter plots, heatmaps
   - Time series → Line charts
   - Part-to-whole → Pie charts (sparingly), treemaps

3. **Keep it simple**: Simpler charts are often more effective. Only add complexity when it adds value.

4. **Respect visualization best practices**:
   - Start bar chart axes at zero
   - Use pie charts only for small numbers of categories
   - Choose appropriate color schemes
   - Label directly when possible rather than using legends

5. **Know your audience**: Consider their familiarity with chart types and data literacy.

6. **Test your visualization**: Ask others if they can understand your main point quickly.

```python
# Create a decision tree chart for chart selection
import matplotlib.pyplot as plt
import matplotlib.patches as mpatches
from matplotlib.path import Path

fig, ax = plt.subplots(figsize=(12, 8))
ax.set_xlim(0, 10)
ax.set_ylim(0, 10)
ax.axis('off')

# Create boxes with decision points
boxes = {
    'start': (5, 9, 'What do you want to show?'),
    'compare': (3, 7, 'Comparing values?'),
    'distribute': (5, 7, 'Showing distribution?'),
    'relate': (7, 7, 'Showing relationship?'),
    'time': (3, 5, 'Over time?'),
    'parts': (7, 5, 'Parts of a whole?'),
    'bar': (2, 3, 'Bar/Column Chart'),
    'line': (4, 3, 'Line Chart'),
    'scatter': (6, 3, 'Scatter Plot'),
    'pie': (8, 3, 'Treemap/Pie Chart'),
    'hist': (5, 5, 'Histogram/Box Plot')
}

# Draw boxes
for key, (x, y, text) in boxes.items():
    if key in ['bar', 'line', 'scatter', 'pie', 'hist']:
        color = 'lightblue'
        font_weight = 'bold'
    else:
        color = 'lightgray'
        font_weight = 'normal'
    rect = mpatches.Rectangle((x-1, y-0.5), 2, 1, ec="black", fc=color, alpha=0.7)
    ax.add_patch(rect)
    ax.text(x, y, text, ha='center', va='center', fontweight=font_weight)

# Draw arrows
arrows = [
    ('start', 'compare'),
    ('start', 'distribute'),
    ('start', 'relate'),
    ('compare', 'time'),
    ('compare', 'parts'),
    ('time', 'bar'),
    ('time', 'line'),
    ('distribute', 'hist'),
    ('relate', 'scatter'),
    ('parts', 'pie')
]

for start, end in arrows:
    start_x, start_y, _ = boxes[start]
    end_x, end_y, _ = boxes[end]
    ax.annotate('', xy=(end_x, end_y+0.5), xytext=(start_x, start_y-0.5),
                arrowprops=dict(facecolor='black', shrink=0.05, width=1))

plt.title('Chart Selection Decision Guide', fontsize=16)
plt.tight_layout()
plt.show()

print("Final Chart Selection Checklist:")
print("1. Identify your message - what do you want to communicate?")
print("2. Understand your data - what type is it?")
print("3. Consider your audience - what will they understand?")
print("4. Choose the simplest chart that conveys your message")
print("5. Use appropriate scales and axes")
print("6. Add proper titles, labels and legends")
print("7. Test your visualization with others")
print("8. Iterate and improve based on feedback")
```

Choosing the right chart type is fundamental to effective data visualization. By matching your chart to your data type and communication goals, you'll create visualizations that quickly convey insights and drive understanding. Remember that the best chart is one that makes your data's story clear and compelling to your audience.
