# Interaktivní widgety s ipywidgets

## Úvod

Interaktivní widgety přetvářejí statické vizualizace na dynamické, prozkoumatelné datové zkušenosti. Knihovna ipywidgets v Jupyter poskytuje výkonný soubor nástrojů pro vytváření prvků grafického uživatelského rozhraní, které umožňují uživatelům manipulovat s daty, upravovat parametry a prozkoumávat různé scénáře vizualizace bez psaní kódu. Tento tutoriál zkoumá, jak využít ipywidgets k vytvoření poutavých, interaktivních datových vizualizací, které mohou pomoci zúčastněným stranám lépe porozumět komplexním datovým sadám a přijímat rozhodnutí založená na datech.

Ať už vytváříte dashboardy, vzdělávací nástroje nebo aplikace pro průzkumnou analýzu dat, ipywidgets nabízí přímočarou cestu k přidání interaktivity do vašich Python vizualizací. Tato mocná kombinace umožňuje datovým vědcům a analytikům vytvářet intuitivnější, poutavější a informativnější datové produkty.

## Propojení widgetů s vizualizacemi

Skutečná síla widgetů se projeví, když je propojíme s vizualizacemi. Pojďme vytvořit nějaké interaktivní grafy:

### Jednoduchý interaktivní graf

```python
# Vytvoření funkce, která aktualizuje graf při změně widgetu
def plot_sine(frequency, amplitude, phase):
    plt.figure(figsize=(10, 6))
    x = np.linspace(0, 10, 1000)
    y = amplitude * np.sin(frequency * x + phase)
    plt.plot(x, y)
    plt.grid(True)
    plt.title(f'Sinusová vlna: Amplituda={amplitude}, Frekvence={frequency}, Fáze={phase}')
    plt.ylim(-10, 10)
    plt.show()

# Vytvoření interaktivních widgetů
freq_slider = widgets.FloatSlider(value=1.0, min=0.1, max=5.0, step=0.1, description='Frekvence:')
amp_slider = widgets.FloatSlider(value=1.0, min=0.1, max=10.0, step=0.1, description='Amplituda:')
phase_slider = widgets.FloatSlider(value=0.0, min=0.0, max=2*np.pi, step=0.1, description='Fáze:')

# Použití interactive pro automatické propojení widgetů s funkcí
interactive_plot = widgets.interactive(plot_sine, frequency=freq_slider, amplitude=amp_slider, phase=phase_slider)
display(interactive_plot)
```

```python
# Načtení vzorové datové sady
tips = sns.load_dataset('tips')

def filter_tips(day, time):
    if day == 'Vše':
        filtered_data = tips[tips['time'] == time] if time != 'Vše' else tips
    elif time == 'Vše':
        filtered_data = tips[tips['day'] == day]
    else:
        filtered_data = tips[(tips['day'] == day) & (tips['time'] == time)]
    
    plt.figure(figsize=(10, 6))
    sns.barplot(x='day', y='total_bill', hue='sex', data=filtered_data, ci=None)
    plt.title(f'Průměrný účet podle dne (Den: {day}, Čas: {time})')
    plt.show()
    
    print(f"Počet záznamů: {len(filtered_data)}")

# Vytvoření rozbalovacích nabídek pro filtrování
day_dropdown = widgets.Dropdown(
    options=['Vše', 'Thur', 'Fri', 'Sat', 'Sun'],
```

### Interaktivní s Output widgetem

Někdy je užitečné mít větší kontrolu nad výstupem. K tomu můžeme použít widget `Output`:

```python
# Vytvoření Output widgetu
output = widgets.Output()

# Vytvoření interaktivních ovládacích prvků
x_data = widgets.Dropdown(
    options=['sepal_length', 'sepal_width', 'petal_length', 'petal_width'],
    value='sepal_length',
    description='Data X:',
)

y_data = widgets.Dropdown(
    options=['sepal_length', 'sepal_width', 'petal_length', 'petal_width'],
    value='sepal_width',
    description='Data Y:',
)

# Funkce pro aktualizaci grafu
def update_plot(*args):
    # Vymazání předchozího výstupu
    with output:
        clear_output(wait=True)
        # Načtení datové sady iris
        iris = sns.load_dataset('iris')
        # Vytvoření nového grafu
        plt.figure(figsize=(8, 6))
        sns.scatterplot(x=x_data.value, y=y_data.value, hue='species', data=iris)
        plt.title(f'{x_data.value} vs {y_data.value}')
        plt.show()

# Propojení ovládacích prvků s funkcí aktualizace
x_data.observe(update_plot, names='value')
y_data.observe(update_plot, names='value')

# Zobrazení ovládacích prvků a výstupu
display(widgets.VBox([x_data, y_data, output]))

# Inicializace grafu
update_plot()
```

## Události widgetů a zpětná volání

Programování řízené událostmi umožňuje složitější interakce:

### Použití observe

```python
# Vytvoření posuvníku a output widgetu
slider = widgets.IntSlider(min=1, max=10, value=5)
output = widgets.Output()

# Definice funkce zpětného volání
def on_value_change(change):
    with output:
        clear_output(wait=True)
        print(f"Nová hodnota: {change['new']}")
        print(f"Předchozí hodnota: {change['old']}")
        
# Registrace zpětného volání k hodnotě posuvníku
slider.observe(on_value_change, names='value')

# Zobrazení posuvníku a výstupu
display(widgets.VBox([slider, output]))
```

### Kliknutí na tlačítko

```python
# Vytvoření tlačítka
button = widgets.Button(
    description='Klikni na mě!',
    disabled=False,
    button_style='', # 'success', 'info', 'warning', 'danger' nebo ''
    tooltip='Klikni na mě',
    icon='check'
)

output = widgets.Output()

# Definice co se stane při kliknutí na tlačítko
def on_button_clicked(b):
    with output:
        clear_output(wait=True)
        print("Tlačítko bylo stisknuto!")
        plt.figure()
        plt.plot(np.random.rand(10))
        plt.title('Náhodný graf')
        plt.show()
        
# Registrace zpětného volání k tlačítku
button.on_click(on_button_clicked)

# Zobrazení tlačítka a výstupu
display(widgets.VBox([button, output]))
```

## Pokročilé interakce

Pojďme vytvořit složitější interaktivní vizualizace:

### Interaktivní bodový graf s více ovládacími prvky

```python
# Načtení datové sady iris
iris = sns.load_dataset('iris')

# Vytvoření output widgetu
output = widgets.Output()

# Vytvoření widgetů pro ovládání grafu
x_dropdown = widgets.Dropdown(
    options=['sepal_length', 'sepal_width', 'petal_length', 'petal_width'],
    value='sepal_length',
    description='Proměnná X:',
)

y_dropdown = widgets.Dropdown(
    options=['sepal_length', 'sepal_width', 'petal_length', 'petal_width'],
    value='sepal_width',
    description='Proměnná Y:',
)

species_checkbox = widgets.SelectMultiple(
    options=list(iris['species'].unique()),
    value=list(iris['species'].unique()),
    description='Druhy:',
    disabled=False
)

marker_size = widgets.IntSlider(
    value=50,
    min=10,
    max=200,
    step=10,
    description='Velikost:',
)

alpha_slider = widgets.FloatSlider(
    value=0.5,
    min=0.1,
    max=1.0,
    step=0.1,
    description='Průhlednost:',
)

# Funkce pro aktualizaci grafu
def update_scatter(*args):
    with output:
        clear_output(wait=True)
        
        # Filtrování dat podle vybraných druhů
        selected_species = list(species_checkbox.value)
        filtered_data = iris[iris['species'].isin(selected_species)]
        
        # Vytvoření bodového grafu
        plt.figure(figsize=(10, 7))
        plt.scatter(
            filtered_data[x_dropdown.value], 
            filtered_data[y_dropdown.value],
            c=filtered_data['species'].map({'setosa': 'red', 'versicolor': 'green', 'virginica': 'blue'}),
            s=marker_size.value,
            alpha=alpha_slider.value
        )
        
        plt.xlabel(x_dropdown.value.replace('_', ' ').title())
        plt.ylabel(y_dropdown.value.replace('_', ' ').title())
        plt.title('Datová sada Iris: Interaktivní bodový graf')
        
        # Přidání legendy
        from matplotlib.lines import Line2D
        legend_elements = [
            Line2D([0], [0], marker='o', color='w', markerfacecolor='red', markersize=10, label='Setosa'),
            Line2D([0], [0], marker='o', color='w', markerfacecolor='green', markersize=10, label='Versicolor'),
            Line2D([0], [0], marker='o', color='w', markerfacecolor='blue', markersize=10, label='Virginica')
        ]
        plt.legend(handles=[le for le in legend_elements if le.get_label() in selected_species])
        
        plt.grid(True, alpha=0.3)
        plt.tight_layout()
        plt.show()

# Propojení všech widgetů s funkcí aktualizace
x_dropdown.observe(update_scatter, names='value')
y_dropdown.observe(update_scatter, names='value')
species_checkbox.observe(update_scatter, names='value')
marker_size.observe(update_scatter, names='value')
alpha_slider.observe(update_scatter, names='value')

# Vytvoření rozložení s ovládacími prvky nahoře a grafem dole
controls = widgets.VBox([
    widgets.HBox([x_dropdown, y_dropdown]),
    widgets.HBox([species_checkbox, marker_size, alpha_slider])
])

# Zobrazení kompletního UI
display(widgets.VBox([controls, output]))

# Inicializace grafu
update_scatter()
```

### Interaktivní časová řada s ovládáním přehrávání

```python
# Vytvoření syntetických dat časových řad
np.random.seed(42)
dates = pd.date_range(start='1/1/2020', periods=100)
data = pd.DataFrame({
    'Date': dates,
    'Series1': np.random.normal(0, 1, 100).cumsum(),
    'Series2': np.random.normal(0, 1, 100).cumsum() + 5,
    'Series3': np.random.normal(0, 1, 100).cumsum() - 5
})

# Vytvoření widgetů
output = widgets.Output()

# Vytvoření tlačítka přehrávání pro animaci
play_button = widgets.Play(
    value=0,
    min=0,
    max=len(dates)-1,
    step=1,
    description="Stiskni play",
    disabled=False
)

# Vytvoření posuvníku propojeného s tlačítkem přehrávání
time_slider = widgets.IntSlider(
    value=0,
    min=0,
    max=len(dates)-1,
    step=1,
    description='Čas:',
    readout_format='d'
)

# Propojení tlačítka přehrávání a posuvníku
widgets.jslink((play_button, 'value'), (time_slider, 'value'))

# Zaškrtávací políčka pro přepínání viditelnosti řad
series1_checkbox = widgets.Checkbox(value=True, description='Řada 1')
series2_checkbox = widgets.Checkbox(value=True, description='Řada 2')
series3_checkbox = widgets.Checkbox(value=True, description='Řada 3')

# Funkce pro aktualizaci grafu
def update_timeseries(*args):
    with output:
        clear_output(wait=True)
        
        # Získání aktuálního časového indexu
        time_idx = time_slider.value
        
        # Vytvoření grafu
        plt.figure(figsize=(12, 6))
        
        # Vykreslení každé vybrané řady až po aktuální čas
        if series1_checkbox.value:
            plt.plot(data['Date'][:time_idx+1], data['Series1'][:time_idx+1], 'b-', label='Řada 1')
        
        if series2_checkbox.value:
            plt.plot(data['Date'][:time_idx+1], data['Series2'][:time_idx+1], 'r-', label='Řada 2')
            
        if series3_checkbox.value:
            plt.plot(data['Date'][:time_idx+1], data['Series3'][:time_idx+1], 'g-', label='Řada 3')
        
        # Zvýraznění aktuálního bodu
        plt.scatter(data['Date'][time_idx], data['Series1'][time_idx], color='blue', s=100, alpha=0.7 if series1_checkbox.value else 0)
        plt.scatter(data['Date'][time_idx], data['Series2'][time_idx], color='red', s=100, alpha=0.7 if series2_checkbox.value else 0)
        plt.scatter(data['Date'][time_idx], data['Series3'][time_idx], color='green', s=100, alpha=0.7 if series3_checkbox.value else 0)
        
        # Nastavení osy x na zobrazení celého časového rozsahu
        plt.xlim(data['Date'].min(), data['Date'].max())
        
        # Výpočet limitů osy y na základě viditelných řad
        visible_series = []
        if series1_checkbox.value: visible_series.append('Series1')
        if series2_checkbox.value: visible_series.append('Series2')
        if series3_checkbox.value: visible_series.append('Series3')
        
        if visible_series:
            min_val = data[visible_series].min().min() - 1
            max_val = data[visible_series].max().max() + 1
            plt.ylim(min_val, max_val)
        
        plt.title(f'Data časových řad - Datum: {data["Date"][time_idx].strftime("%Y-%m-%d")}')
        plt.xlabel('Datum')
        plt.ylabel('Hodnota')
        plt.grid(True, alpha=0.3)
        plt.legend()
        plt.tight_layout()
        plt.show()

# Připojení widgetů k funkci aktualizace
time_slider.observe(update_timeseries, names='value')
series1_checkbox.observe(update_timeseries, names='value')
series2_checkbox.observe(update_timeseries, names='value')
series3_checkbox.observe(update_timeseries, names='value')

# Vytvoření rozložení
controls = widgets.HBox([play_button, time_slider])
series_toggles = widgets.HBox([series1_checkbox, series2_checkbox, series3_checkbox])
ui = widgets.VBox([controls, series_toggles, output])

# Zobrazení UI
display(ui)

# Inicializace grafu
update_timeseries()
```

```python
    'MSFT': np.random.normal(0, 1, 100).cumsum() + 150,
    'GOOG': np.random.normal(0, 1, 100).cumsum() + 200,
    'AMZN': np.random.normal(0, 1, 100).cumsum() + 250,
})

# Vytvoření output widgetů pro různé sekce
chart_output = widgets.Output()
stats_output = widgets.Output()
table_output = widgets.Output()

# Vytvoření widgetů pro ovládání
stock_selector = widgets.SelectMultiple(
    options=['AAPL', 'MSFT', 'GOOG', 'AMZN'],
    value=['AAPL', 'MSFT'],
    description='Akcie:',
    layout=widgets.Layout(width='200px')
)

date_range = widgets.IntRangeSlider(
    value=[0, len(stocks)-1],
    min=0,
    max=len(stocks)-1,
    step=1,
    description='Období:',
    layout=widgets.Layout(width='400px')
)

chart_type = widgets.RadioButtons(
    options=['Čára', 'Oblast', 'Sloupec'],
    value='Čára',
    description='Graf:',
    layout=widgets.Layout(width='200px')
)

normalize = widgets.Checkbox(
    value=False,
    description='Normalizovat',
    layout=widgets.Layout(width='150px')
)

# Funkce pro aktualizaci dashboardu
def update_dashboard(*args):
    # Získání vybraných dat
    selected_stocks = list(stock_selector.value)
    start_idx, end_idx = date_range.value
    selected_dates = stocks['Date'][start_idx:end_idx+1]
    
    if not selected_stocks:
        return
    
    # Filtrování dat
    filtered_data = stocks.iloc[start_idx:end_idx+1].copy()
    
    # Normalizace dat, pokud je požadována
    if normalize.value:
        for stock in selected_stocks:
            filtered_data[stock] = filtered_data[stock] / filtered_data[stock].iloc[0] * 100
    
    # Aktualizace grafu
    with chart_output:
        clear_output(wait=True)
        plt.figure(figsize=(10, 6))
        
        if chart_type.value == 'Čára':
            for stock in selected_stocks:
                plt.plot(filtered_data['Date'], filtered_data[stock], label=stock)
        
        elif chart_type.value == 'Oblast':
            for stock in selected_stocks:
                plt.fill_between(filtered_data['Date'], filtered_data[stock], alpha=0.3, label=stock)
                plt.plot(filtered_data['Date'], filtered_data[stock], alpha=0.7)
        
        elif chart_type.value == 'Sloupec':
            # Pro sloupcový graf použijte podmnožinu, aby se předešlo přeplnění
            step = max(1, len(filtered_data) // 20)
            bar_data = filtered_data.iloc[::step].copy()
            
            width = 0.8 / len(selected_stocks)
            for i, stock in enumerate(selected_stocks):
                offset = i * width - (len(selected_stocks) - 1) * width / 2
                plt.bar(np.arange(len(bar_data)) + offset, bar_data[stock], 
                       width=width, label=stock, alpha=0.7)
            plt.xticks(np.arange(len(bar_data)), 
                      [d.strftime('%m/%d') for d in bar_data['Date']], rotation=45)
        
        plt.title('Ceny akcií' + (' (Normalizované)' if normalize.value else ''))
        plt.xlabel('Datum')
        plt.ylabel('Cena' if not normalize.value else 'Normalizovaná cena (Základna=100)')
        plt.grid(True, alpha=0.3)
        plt.legend()
        plt.tight_layout()
        plt.show()
    
    # Aktualizace statistik
    with stats_output:
        clear_output(wait=True)
        stats_df = pd.DataFrame()
        
        for stock in selected_stocks:
            stock_data = filtered_data[stock]
            stats_df[stock] = [
                stock_data.mean(),
                stock_data.std(),
                stock_data.min(),
                stock_data.max(),
                stock_data.iloc[-1] - stock_data.iloc[0],
                (stock_data.iloc[-1] / stock_data.iloc[0] - 1) * 100
            ]
        
        stats_df.index = ['Průměr', 'Směr. odchylka', 'Min', 'Max', 'Změna', 'Změna %']
        display(stats_df)
    
    # Aktualizace tabulky
    with table_output:
        clear_output(wait=True)
        columns_to_show = ['Date'] + selected_stocks
        display(filtered_data[columns_to_show].head())
        if len(filtered_data) > 5:
            print("...")
            display(filtered_data[columns_to_show].tail())

# Připojení widgetů k funkci aktualizace
stock_selector.observe(update_dashboard, names='value')
date_range.observe(update_dashboard, names='value')
chart_type.observe(update_dashboard, names='value')
normalize.observe(update_dashboard, names='value')

# Vytvoření rozložení dashboardu
controls = widgets.VBox([
    widgets.HBox([stock_selector, chart_type, normalize]),
    date_range
])

tab = widgets.Tab()
tab.children = [chart_output, stats_output, table_output]
tab.set_title(0, 'Graf')
tab.set_title(1, 'Statistiky')
tab.set_title(2, 'Data')

dashboard = widgets.VBox([controls, tab])
display(dashboard)

# Inicializace dashboardu
update_dashboard()
```

## Osvědčené postupy

Při práci s ipywidgets zvažte tyto osvědčené postupy:

1. **Udržujte jednoduchost**: Začněte s jednoduchými widgety a postupně zvyšujte složitost
2. **Organizujte logicky**: Seskupujte související widgety pomocí HBox a VBox
3. **Poskytujte zpětnou vazbu**: Ukažte uživatelům efekt jejich interakcí okamžitě
4. **Používejte popisné štítky**: Zajistěte, aby popisky widgetů jasně popisovaly jejich funkci
5. **Elegantně zpracovávejte chyby**: Předvídejte možné chyby a řádně je zpracujte
6. **Zvažujte výkon**: U složitých vizualizací optimalizujte svůj kód, abyste předešli zpoždění
7. **Přidávejte nápovědy**: Pomozte uživatelům pochopit, co každý widget dělá
8. **Dělejte to přístupné**: Zvažujte volby barev a poskytujte textové alternativy
9. **Testujte**: Vyzkoušejte své interaktivní vizualizace s různými vstupy a velikostmi obrazovek
10. **Dokumentujte**: V případě potřeby zahrňte instrukce nebo vysvětlení

### Případová studie 1: Interaktivní průzkumník dat

Pojďme vytvořit obecný průzkumník dat, který funguje s různými datovými sadami:

```python
# Získání dostupných datových sad ze seabornu
import seaborn as sns
dataset_names = ['iris', 'tips', 'diamonds', 'planets', 'titanic']

def load_dataset(name):
    return sns.load_dataset(name)

# Vytvoření widgetů
dataset_dropdown = widgets.Dropdown(
    options=dataset_names,
    value='iris',
    description='Datová sada:',
)

output = widgets.Output()
info_output = widgets.Output()
plot_output = widgets.Output()

# Proměnné pro ovládací prvky grafů (vytvoříme je po výběru datové sady)
plot_controls = widgets.HBox([widgets.HTML("Nejprve vyberte datovou sadu")])

# Funkce pro aktualizaci informací o datové sadě
def update_dataset_info():
    with info_output:
        clear_output(wait=True)
        df = load_dataset(dataset_dropdown.value)
        print(f"Datová sada: {dataset_dropdown.value}")
        print(f"Tvar: {df.shape}")
        print("\nInformace o sloupcích:")
        for col in df.columns:
            print(f"- {col}: {df[col].dtype}")
        
        print("\nUkázková data:")
        display(df.head())

# Funkce pro vytvoření ovládacích prvků grafu podle vybrané datové sady
def create_plot_controls():
    df = load_dataset(dataset_dropdown.value)
    
    # Vytvoření ovládacích prvků na základě datových typů
    numeric_cols = df.select_dtypes(include=['number']).columns.tolist()
    categorical_cols = df.select_dtypes(include=['object', 'category']).columns.tolist()
    
    # Výběr typu grafu
    plot_type = widgets.Dropdown(
        options=['Bodový', 'Sloupcový', 'Krabicový', 'Histogram', 'Teplotní mapa'],
        value='Bodový',
        description='Typ grafu:',
    )
    
    # Výběr os X a Y (závisí na typu grafu)
    x_dropdown = widgets.Dropdown(
        options=df.columns.tolist(),
        value=df.columns[0],
        description='Osa X:',
    )
    
    y_dropdown = widgets.Dropdown(
        options=['Žádný'] + numeric_cols,
        value=numeric_cols[0] if numeric_cols else 'Žádný',
        description='Osa Y:',
    )
    
    # Výběr proměnné pro barvu
    hue_dropdown = widgets.Dropdown(
        options=['Žádný'] + categorical_cols,
        value=categorical_cols[0] if categorical_cols else 'Žádný',
        description='Barva podle:',
    )
    
    # Další ovládací prvky
    size_slider = widgets.IntSlider(
        value=50,
        min=10,
        max=200,
        step=10,
        description='Velikost:',
    )
    
    # Funkce pro vytvoření grafů
    def create_plot(*args):
        with plot_output:
            clear_output(wait=True)
            
            try:
                plt.figure(figsize=(10, 6))
                
                plot_kind = plot_type.value
                x = x_dropdown.value
                y = y_dropdown.value if y_dropdown.value != 'Žádný' else None
                hue = hue_dropdown.value if hue_dropdown.value != 'Žádný' else None
                
                if plot_kind == 'Bodový':
                    if not y:
                        print("Bodové grafy vyžadují výběr osy Y")
                        return
                    sns.scatterplot(x=x, y=y, hue=hue, data=df, s=size_slider.value)
                
                elif plot_kind == 'Sloupcový':
                    sns.barplot(x=x, y=y, hue=hue, data=df)
                
                elif plot_kind == 'Krabicový':
                    sns.boxplot(x=x, y=y, hue=hue, data=df)
                
                elif plot_kind == 'Histogram':
                    sns.histplot(df[x], kde=True)
                    plt.xlabel(x)
                
                elif plot_kind == 'Teplotní mapa':
                    if len(numeric_cols) < 2:
                        print("Teplotní mapa vyžaduje alespoň 2 číselné sloupce")
                        return
                    
                    corr = df[numeric_cols].corr()
                    sns.heatmap(corr, annot=True, cmap='coolwarm', linewidths=0.5)
                
                plt.title(f"{plot_kind} graf datové sady {dataset_dropdown.value}")
                plt.tight_layout()
                plt.show()
            
            except Exception as e:
                print(f"Chyba při vytváření grafu: {e}")
    
    # Propojení ovládacích prvků s vytvářením grafu
    plot_type.observe(create_plot, names='value')
    x_dropdown.observe(create_plot, names='value')
    y_dropdown.observe(create_plot, names='value')
    hue_dropdown.observe(create_plot, names='value')
    size_slider.observe(create_plot, names='value')
    
    # Vytvoření rozložení pro ovládací prvky
    controls_layout = widgets.VBox([
        widgets.HBox([plot_type, x_dropdown]),
        widgets.HBox([y_dropdown, hue_dropdown, size_slider])
    ])
    
    return controls_layout, create_plot

# Funkce pro zpracování změny datové sady
def on_dataset_change(change):
    # Aktualizace informací o datové sadě
    update_dataset_info()
    
    # Vytvoření nových ovládacích prvků grafu
    global plot_controls
    new_controls, plot_function = create_plot_controls()
    
    # Nahrazení starých ovládacích prvků novými
    plot_controls.children = [new_controls]
    
    # Inicializace grafu
    plot_function()

# Připojení rozbalovací nabídky datových sad k funkci aktualizace
dataset_dropdown.observe(on_dataset_change, names='value')

# Vytvoření záložek pro různé pohledy
tab = widgets.Tab()
tab.children = [info_output, plot_output]
tab.set_title(0, 'Informace o datech')
tab.set_title(1, 'Graf')

# Rozložení celého UI
ui = widgets.VBox([
    dataset_dropdown,
    plot_controls,
    tab
])

# Zobrazení UI
display(ui)

# Inicializace s výchozí datovou sadou
on_dataset_change({'new': dataset_dropdown.value})
```

### Případová studie 2: Experimentování s parametry modelu

```python
# Import dalších knihoven pro strojové učení
from sklearn import datasets
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

# Načtení datové sady
X, y = datasets.load_wine(return_X_y=True)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Škálování příznaků
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# Vytvoření widgetů
output = widgets.Output()

# Výběr modelu
model_selector = widgets.RadioButtons(
    options=['K-Nejbližších sousedů', 'Support Vector Machine'],
    value='K-Nejbližších sousedů',
    description='Model:',
    layout=widgets.Layout(width='300px')
)

# Parametry KNN
knn_n_neighbors = widgets.IntSlider(
    value=5,
    min=1,
    max=20,
    step=1,
    description='Sousedů:',
    disabled=False
)

knn_weights = widgets.RadioButtons(
    options=['uniform', 'distance'],
    value='uniform',
    description='Váhy:',
    disabled=False
)

# Parametry SVM
svm_C = widgets.FloatLogSlider(
    value=1.0,
    base=10,
    min=-3,  # 10^(-3) = 0.001
    max=3,   # 10^3 = 1000
    step=0.2,
    description='C:',
    disabled=True
)

svm_kernel = widgets.Dropdown(
    options=['linear', 'poly', 'rbf', 'sigmoid'],
    value='rbf',
    description='Jádro:',
    disabled=True
)

svm_gamma = widgets.FloatLogSlider(
    value=0.1,
    base=10,
    min=-5,  # 10^(-5) = 0.00001
    max=0,   # 10^0 = 1
    step=0.2,
    description='Gamma:',
    disabled=True
)

# Funkce pro povolení/zakázání parametrů specifických pro model
def toggle_model_params(change):
    if change['new'] == 'K-Nejbližších sousedů':
        knn_n_neighbors.disabled = False
        knn_weights.disabled = False
        svm_C.disabled = True
        svm_kernel.disabled = True
        svm_gamma.disabled = True
    else:  # SVM
        knn_n_neighbors.disabled = True
        knn_weights.disabled = True
        svm_C.disabled = False
        svm_kernel.disabled = False
        svm_gamma.disabled = False
    
    # Aktualizace modelu s novými parametry
    update_model()

# Připojení výběru modelu k přepínání parametrů
model_selector.observe(toggle_model_params, names='value')

# Funkce pro aktualizaci modelu a výsledků
def update_model(*args):
    with output:
        clear_output(wait=True)
        
        try:
            # Získání aktuálního modelu a parametrů
            model_name = model_selector.value
            
            if model_name == 'K-Nejbližších sousedů':
                model = KNeighborsClassifier(
                    n_neighbors=knn_n_neighbors.value,
                    weights=knn_weights.value
                )
            else:  # SVM
                model = SVC(
                    C=svm_C.value,
                    kernel=svm_kernel.value,
                    gamma=svm_gamma.value if svm_kernel.value in ['rbf', 'poly', 'sigmoid'] else 'auto'
                )
            
            # Trénování modelu
            model.fit(X_train_scaled, y_train)
            
            # Vytváření predikcí
            y_pred = model.predict(X_test_scaled)
            
            # Výpočet přesnosti a dalších metrik
            accuracy = accuracy_score(y_test, y_pred)
            conf_matrix = confusion_matrix(y_test, y_pred)
            class_report = classification_report(y_test, y_pred)
            
            # Zobrazení výsledků
            print(f"Model: {model_name}")
            print(f"Parametry modelu: {model.get_params()}")
            print(f"\nPřesnost: {accuracy:.4f}")
            
            print("\nMatice záměn:")
            print(conf_matrix)
            
            print("\nKlasifikační zpráva:")
            print(class_report)
            
            # Vizualizace matice záměn
            plt.figure(figsize=(8, 6))
            sns.heatmap(conf_matrix, annot=True, fmt='d', cmap='Blues')
            plt.title(f'Matice záměn - {model_name}')
            plt.xlabel('Predikovaná třída')
            plt.ylabel('Skutečná třída')
            plt.show()
            
        except Exception as e:
            print(f"Chyba při trénování modelu: {e}")

# Připojení všech widgetů parametrů k aktualizaci modelu
knn_n_neighbors.observe(update_model, names='value')
knn_weights.observe(update_model, names='value')
svm_C.observe(update_model, names='value')
svm_kernel.observe(update_model, names='value')
svm_gamma.observe(update_model, names='value')

# Vytvoření rozložení pro parametry KNN
knn_params = widgets.VBox([knn_n_neighbors, knn_weights])

# Vytvoření rozložení pro parametry SVM
svm_params = widgets.VBox([svm_C, svm_kernel, svm_gamma])

# Vytvoření záložek pro skupiny parametrů
params_tab = widgets.Tab()
params_tab.children = [knn_params, svm_params]
params_tab.set_title(0, 'Parametry KNN')
params_tab.set_title(1, 'Parametry SVM')

# Vytvoření celého UI
ui = widgets.VBox([
    widgets.HTML("<h2>Průzkumník parametrů modelu</h2>"),
    model_selector,
    params_tab,
    output
])

# Zobrazení UI
display(ui)

# Inicializace zobrazení modelu
update_model()
```

## Shrnutí

Interaktivní widgety s ipywidgets přidávají výkonnou dimenzi k vizualizaci dat v Pythonu. Přeměňují statické grafy na dynamické nástroje pro průzkum dat, které umožňují uživatelům interagovat s daty v reálném čase bez potřeby znalosti programování. Klíčové poznatky z tohoto průvodce zahrnují:

1. **Vylepšený průzkum dat**: Interaktivní widgety umožňují uživatelům filtrovat, transformovat a vizualizovat data dynamicky, což usnadňuje objevování vzorů a poznatků.

2. **Rozmanitost widgetů**: ipywidgets nabízí bohatou kolekci ovládacích prvků UI včetně posuvníků, rozbalovacích nabídek, zaškrtávacích políček a dalších, vhodných pro vytváření různých interaktivních rozhraní.

3. **Programování řízené událostmi**: Připojením widgetů k funkcím zpětného volání prostřednictvím událostí můžete vytvářet responzivní vizualizace, které se aktualizují, když uživatelé interagují s ovládacími prvky.

4. **Integrace s vizualizačními knihovnami**: ipywidgets spolupracuje bezproblémově s populárními vizualizačními knihovnami jako jsou Matplotlib, Seaborn a Plotly a vytváří interaktivní grafy.

5. **Organizace widgetů**: Kontejnery rozložení jako HBox, VBox, Tab a Accordion pomáhají organizovat widgety jasným, uživatelsky přívětivým způsobem.

6. **Možnosti stylování**: Knihovna poskytuje více způsobů, jak stylovat a přizpůsobit widgety tak, aby odpovídaly vzhledu vaší aplikace.

7. **Tvorba dashboardů**: Kombinací více widgetů a vizualizací můžete vytvářet komplexní dashboardy pro analýzu a prezentaci dat.

8. **Reálné aplikace**: Interaktivní widgety jsou cenné pro vzdělávací nástroje, dashboardy pro průzkum dat, ladění parametrů ve strojovém učení a vytváření přesvědčivých datových příběhů.

9. **Úvahy o výkonu**: Pro složité aplikace je důležité optimalizovat kód, aby zůstal responzivní, zejména s velkými datovými sadami.

10. **Přístupnost a uživatelský zážitek**: Dobře navržené interaktivní vizualizace zlepšují přístupnost a vylepšují celkový uživatelský zážitek tím, že data zpřístupňují.

Zvládnutím ipywidgets mohou datoví vědci a analytici vytvářet výkonné interaktivní nástroje, které zapojí publikum a usnadní hlubší průzkum dat, což mění způsob, jakým uživatelé interagují s komplexními informacemi a chápou je.
