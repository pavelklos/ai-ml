## Úvod

Vizualizace vysokodimenzionálních dat představuje jednu z nejnáročnějších úloh v oblasti datové vizualizace. S rostoucím počtem dimenzí nad tři se přímá vizualizace stává nemožnou a musíme se spoléhat na techniky redukce dimenzionality pro vytvoření smysluplných 2D nebo 3D reprezentací, které zachovávají důležité vztahy v datech.

Tento dokument zkoumá dvě výkonné techniky pro vizualizaci vysokodimenzionálních dat:
- **t-SNE** (t-Distributed Stochastic Neighbor Embedding)
- **UMAP** (Uniform Manifold Approximation and Projection)

Obě metody způsobily revoluci v tom, jak vizualizujeme a interpretujeme vysokodimenzionální datasety díky tomu, že poskytují intuitivní a hodnotné projekce, které zachovávají lokální a v některých případech i globální strukturu.

## Výzvy vysokodimenzionálních dat

Vysokodimenzionální data přinášejí několik jedinečných výzev:

1. **Prokletí dimenzionality**: S rostoucím počtem dimenzí se data stávají stále řidšími a vzdálenosti ztrácejí svůj význam.
2. **Výpočetní složitost**: Zpracování a vizualizace vysokodimenzionálních dat jsou výpočetně náročné.
3. **Ztráta interpretovatelnosti**: Lidé dokáží přirozeně vnímat maximálně 3 dimenze.
4. **Koncentrace vzdáleností**: Ve vysokých dimenzích mají párové vzdálenosti tendenci stávat se uniformnějšími, což ztěžuje shlukování.

Ilustrujme si prokletí dimenzionality na jednoduchém příkladu:

```python
import numpy as np
import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns

# Nastavení random seed pro reprodukovatelnost
np.random.seed(42)

# Generování datasetů různých dimenzí
dims = [2, 10, 50, 100, 500]
num_points = 1000
distance_distributions = []

for dim in dims:
    # Generování bodů v n-dimenzionálním prostoru
    points = np.random.normal(0, 1, (num_points, dim))
    
    # Výpočet párových Euklidovských vzdáleností
    distances = []
    for i in range(num_points):
        for j in range(i+1, num_points):
            distance = np.linalg.norm(points[i] - points[j])
            distances.append(distance)
    
    distance_distributions.append(distances)

# Vizualizace distribuce vzdáleností
plt.figure(figsize=(12, 6))
for i, dim in enumerate(dims):
    sns.kdeplot(distance_distributions[i], label=f'{dim} dimenzí')

plt.title('Distribuce vzdáleností vs. dimenzionalita')
plt.xlabel('Euklidovská vzdálenost')
plt.ylabel('Hustota')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Výpočet koeficientu variace (relativní směrodatné odchylky)
cv_values = [np.std(dist)/np.mean(dist) for dist in distance_distributions]

plt.figure(figsize=(10, 5))
plt.plot(dims, cv_values, marker='o')
plt.title('Fenomén koncentrace vzdáleností')
plt.xlabel('Počet dimenzí')
plt.ylabel('Koeficient variace vzdáleností')
plt.xscale('log')
plt.grid(True, alpha=0.3)
plt.show()
```

S rostoucí dimenzionalitou se vzdálenosti mezi body stávají uniformnějšími, což ztěžuje identifikaci smysluplných shluků nebo vzorů v nezpracovaných datech.

## Přehled technik redukce dimenzionality

Techniky redukce dimenzionality lze obecně rozdělit do kategorií:

1. **Lineární metody**:
   - Principal Component Analysis (PCA)
   - Linear Discriminant Analysis (LDA)
   - Multidimensional Scaling (MDS)

2. **Nelineární metody**:
   - t-SNE
   - UMAP
   - Isomap
   - Locally Linear Embedding (LLE)
   - Autoenkodéry

Začněme jednoduchým porovnáním PCA (lineární) vs. t-SNE a UMAP (nelineární) na standardním datasetu:

```python
# Instalace potřebných balíčků, pokud je nemáte

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
import umap
import time

# Načtení datasetu digits

X_tsne = tsne.fit_transform(X)

plt.subplot(132)

plt.colorbar()

# UMAP

X_umap = reducer.fit_transform(X)
umap_time = time.time() - start_time

plt.subplot(133)
plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='tab10', s=5)
plt.title(f'UMAP (Čas: {umap_time:.2f}s)')
plt.colorbar()

plt.tight_layout()
plt.show()

print(f"PCA trval {pca_time:.2f} sekund")
print(f"t-SNE trval {tsne_time:.2f} sekund")
print(f"UMAP trval {umap_time:.2f} sekund")
```

## t-SNE: t-Distributed Stochastic Neighbor Embedding

### t-SNE teorie a koncepty

t-SNE byl vyvinut Laurensem van der Maatenem a Geoffreyem Hintonem v roce 2008 jako vylepšení původního SNE algoritmu. Zaměřuje se na zachování lokální struktury pomocí modelování pravděpodobnostních distribucí párových podobností mezi body.

Algoritmus pracuje ve dvou hlavních krocích:

1. **Konstrukce pravděpodobnostních distribucí**: Pro každý pár bodů t-SNE vypočítá podmíněnou pravděpodobnost, že bod j by byl vybrán jako soused bodu i, proporčně k jejich podobnosti (typicky na základě Gaussovské distribuce ve vysokodimenzionálním prostoru).

2. **Redukce dimenzionality**: t-SNE hledá nízkodimenzionální reprezentaci, kde jsou body umístěny tak, aby minimalizovaly Kullback-Leiblerovu divergenci mezi vysokodimenzionální a nízkodimenzionální pravděpodobnostní distribucí (s použitím t-distribuce v nízkodimenzionálním prostoru).

Klíčové vlastnosti t-SNE:
- Dobře zachovává lokální strukturu
- Nelineární redukce dimenzionality
- Stochastický algoritmus (výsledky se liší mezi běhy)
- Výpočetně náročný pro velké datasety
- Není navržen pro zachování globální struktury

### t-SNE implementace v Pythonu

Zde je jak implementovat t-SNE pomocí scikit-learn:

```python
from sklearn.manifold import TSNE
from sklearn.datasets import load_digits
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
import pandas as pd
import time

# Načtení datasetu digits
digits = load_digits()
X = digits.data
y = digits.target

# Aplikace t-SNE s různými hodnotami perplexity
perplexities = [5, 30, 50, 100]
plt.figure(figsize=(15, 10))

for i, perplexity in enumerate(perplexities):
    start_time = time.time()
    
    # Aplikace t-SNE
    tsne = TSNE(
        n_components=2,
        perplexity=perplexity,
        n_iter=1000,
        random_state=42
    )
    X_tsne = tsne.fit_transform(X)
    
    end_time = time.time()
    
    # Vytvoření DataFrame pro snadné vykreslení
    df = pd.DataFrame({
        'x': X_tsne[:, 0],
        'y': X_tsne[:, 1],
        'digit': y
    })
    
    # Vykreslení výsledku
    plt.subplot(2, 2, i+1)
    sns.scatterplot(x='x', y='y', hue='digit', palette='tab10', data=df, s=10, legend='full')
    plt.title(f't-SNE s Perplexity={perplexity} (Čas: {end_time-start_time:.2f}s)')
    plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()
```

### t-SNE ladění hyperparametrů

t-SNE má několik důležitých parametrů, které ovlivňují kvalitu vizualizace:

1. **Perplexita**: Řídí rovnováhu mezi zachováním lokální a globální struktury (typicky mezi 5 a 50)
2. **Learning rate**: Řídí velikost kroku v gradientním sestupu
3. **Počet iterací**: Více iterací často vede k lepší konvergenci
4. **Early exaggeration**: Zdůrazňuje shluky v prvních fázích optimalizace

Podívejme se, jak různé parametry ovlivňují výsledky t-SNE:

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.manifold import TSNE
from sklearn.datasets import load_digits
import time

# Načtení datasetu digits
digits = load_digits()
X = digits.data[:500]  # Použijeme podmnožinu pro rychlejší výpočet
y = digits.target[:500]

# Definice kombinací parametrů
params = [
    {'perplexity': 30, 'learning_rate': 200, 'n_iter': 1000, 'early_exaggeration': 12},
    {'perplexity': 5, 'learning_rate': 200, 'n_iter': 1000, 'early_exaggeration': 12},
    {'perplexity': 50, 'learning_rate': 200, 'n_iter': 1000, 'early_exaggeration': 12},
    {'perplexity': 30, 'learning_rate': 50, 'n_iter': 1000, 'early_exaggeration': 12},
    {'perplexity': 30, 'learning_rate': 200, 'n_iter': 250, 'early_exaggeration': 12},
    {'perplexity': 30, 'learning_rate': 200, 'n_iter': 1000, 'early_exaggeration': 4}
]

# Vytvoření figury
plt.figure(figsize=(18, 12))

for i, param in enumerate(params):
    start_time = time.time()
    
    tsne = TSNE(
        n_components=2,
        perplexity=param['perplexity'],
        learning_rate=param['learning_rate'],
        n_iter=param['n_iter'],
        early_exaggeration=param['early_exaggeration'],
        random_state=42
    )
    
    X_tsne = tsne.fit_transform(X)
    
    end_time = time.time()
    
    # Vykreslení
    plt.subplot(2, 3, i+1)
    plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='tab10', s=10)
    plt.title(
        f"Perplexity: {param['perplexity']}, LR: {param['learning_rate']},\n"
        f"Iterace: {param['n_iter']}, Early Exag: {param['early_exaggeration']}\n"
        f"Čas: {end_time-start_time:.2f}s"
    )
    plt.colorbar()
    plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()
```

## UMAP: Uniform Manifold Approximation and Projection

### UMAP teorie a koncepty

UMAP, vyvinutý Lelandem McInnesem, Johnem Healym a Jamesem Melvillem v roce 2018, je novější technikou redukce dimenzionality. Je založen na technikách učení manifoldů a Riemannovy geometrie.

Algoritmus UMAP:

1. Vytváří fuzzy topologickou reprezentaci vysokodimenzionálních dat
2. Vytváří podobnou reprezentaci v nízkodimenzionálním prostoru
3. Optimalizuje nízkodimenzionální reprezentaci tak, aby byla co nejpodobnější vysokodimenzionální reprezentaci

Klíčové vlastnosti UMAP:
- Lepší zachování jak lokální, tak globální struktury než t-SNE
- Obecně rychlejší než t-SNE, zejména pro velké datasety
- Lze použít pro redukci dimenzionality, nejen pro vizualizaci
- Stabilnější vzhledem k různým inicializacím
- Podporuje přístupy řízeného, částečně řízeného a metrického učení

### UMAP implementace v Pythonu

Zde je jak implementovat UMAP vizualizace:

```python
# Instalace umap-learn, pokud ho ještě nemáte
# !pip install umap-learn

import umap
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
import time

# Načtení datasetu digits
digits = load_digits()
X = digits.data
y = digits.target

# Aplikace UMAP s různými hodnotami n_neighbors
n_neighbors_values = [5, 15, 30, 50]
plt.figure(figsize=(15, 10))

for i, n_neighbors in enumerate(n_neighbors_values):
    start_time = time.time()
    
    # Aplikace UMAP
    reducer = umap.UMAP(
        n_neighbors=n_neighbors,
        min_dist=0.1,
        n_components=2,
        random_state=42
    )
    
    X_umap = reducer.fit_transform(X)
    
    end_time = time.time()
    
    # Vykreslení výsledku
    plt.subplot(2, 2, i+1)
    plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='tab10', s=10)
    plt.colorbar()
    plt.title(f'UMAP s n_neighbors={n_neighbors} (Čas: {end_time-start_time:.2f}s)')
    plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()
```

### UMAP ladění hyperparametrů

UMAP má také několik důležitých parametrů, které ovlivňují vizualizaci:

1. **n_neighbors**: Řídí rovnováhu mezi lokální a globální strukturou
2. **min_dist**: Řídí, jak těsně jsou body zabaleny k sobě
3. **metric**: Metrika vzdálenosti, kterou použít (např. 'euclidean', 'cosine', atd.)
4. **n_components**: Počet dimenzí ve výstupu (typicky 2 nebo 3 pro vizualizaci)

## Porovnání t-SNE a UMAP

Porovnejme t-SNE a UMAP na různých typech datasetů pro zvýraznění jejich předností a slabin:

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits, fetch_openml, make_swiss_roll
from sklearn.manifold import TSNE
import umap
import time
import warnings
warnings.filterwarnings('ignore')

# Funkce pro vytvoření srovnávacích grafů
def compare_methods(X, y, title):
    plt.figure(figsize=(18, 5))
    
    # PCA
    start_time = time.time()
    pca = PCA(n_components=2)
    X_pca = pca.fit_transform(X)
    pca_time = time.time() - start_time
    
    plt.subplot(131)
    plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap='tab10', s=10)
    plt.title(f'PCA (Čas: {pca_time:.2f}s)')
    plt.colorbar()
    plt.grid(alpha=0.3)
    
    # t-SNE
    start_time = time.time()
    tsne = TSNE(n_components=2, random_state=42)
    X_tsne = tsne.fit_transform(X)
    tsne_time = time.time() - start_time
    
    plt.subplot(132)
    plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='tab10', s=10)
    plt.title(f't-SNE (Čas: {tsne_time:.2f}s)')
    plt.colorbar()
    plt.grid(alpha=0.3)
    
    # UMAP
    start_time = time.time()
    reducer = umap.UMAP(random_state=42)
    X_umap = reducer.fit_transform(X)
    umap_time = time.time() - start_time
    
    plt.subplot(133)
    plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='tab10', s=10)
    plt.title(f'UMAP (Čas: {umap_time:.2f}s)')
    plt.colorbar()
    plt.grid(alpha=0.3)
    
    plt.suptitle(title, fontsize=16)
    plt.tight_layout()
    plt.show()

# 1. Dataset digits
digits = load_digits()
compare_methods(digits.data, digits.target, 'Ručně psané číslice (64 dimenzí)')

# 2. Swiss Roll (nelineární manifold)
X_swiss, y_swiss = make_swiss_roll(n_samples=1000, random_state=42)
# Použití první komponenty pro obarvení
compare_methods(X_swiss, y_swiss[:, 0], 'Swiss Roll (3 dimenze)')

# 3. Fashion MNIST (podmnožina)
try:
    # Načtení podmnožiny Fashion MNIST
    fashion = fetch_openml('Fashion-MNIST', version=1, parser='auto')
    X_fashion = fashion.data[:5000].astype('float32') / 255.0
    y_fashion = fashion.target[:5000].astype('int')
    compare_methods(X_fashion, y_fashion, 'Fashion MNIST Podmnožina (784 dimenzí)')
except:
    print("Nemohu načíst dataset Fashion-MNIST. Přeskakuji toto srovnání.")
```

Klíčové rozdíly mezi t-SNE a UMAP:

| Aspekt | t-SNE | UMAP |
|--------|-------|------|
| Rychlost | Pomalejší (O(n²)) | Rychlejší (O(n log n)) |
| Škálovatelnost | Omezeno na tisíce datových bodů | Zvládne stovky tisíc |
| Globální struktura | Často zkresluje globální strukturu | Lepší zachování globální struktury |
| Stabilita | Výsledky se liší mezi běhy | Konzistentnější výsledky |
| Teoretický základ | Pravděpodobnostní | Topologický a geometrický |
| Hyperparametry | Klíčová je perplexita | Klíčové jsou n_neighbors a min_dist |
| Implementace | Široce dostupná | Novější, ale dobře podporovaná |

## Pokročilé techniky vizualizace

### Vizualizace hierarchické struktury s UMAP

UMAP může být obzvlášť účinný při odhalování hierarchické struktury v datech:

```python
import umap
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_20newsgroups_vectorized
from sklearn.decomposition import TruncatedSVD
import time

# Načtení datasetu 20 newsgroups
newsgroups = fetch_20newsgroups_vectorized()
X = newsgroups.data
y = newsgroups.target

# Použití TruncatedSVD pro počáteční redukci dimenzionality (zrychluje UMAP)
svd = TruncatedSVD(n_components=50)
X_svd = svd.fit_transform(X)

# Aplikace hierarchického UMAP s různým nastavením parametrů
settings = [
    # Globální struktura
    {'n_neighbors': 50, 'min_dist': 0.5},
    # Rovnováha
    {'n_neighbors': 15, 'min_dist': 0.1},
    # Lokální struktura
    {'n_neighbors': 5, 'min_dist': 0.01}
]

plt.figure(figsize=(18, 6))

for i, params in enumerate(settings):
    start_time = time.time()
    
    reducer = umap.UMAP(
        n_neighbors=params['n_neighbors'],
        min_dist=params['min_dist'],
        random_state=42
    )
    
    X_umap = reducer.fit_transform(X_svd)
    
    end_time = time.time()
    
    plt.subplot(1, 3, i+1)
    plt.scatter(X_umap[:, 0], X_umap[:, 1], c=y, cmap='tab20', s=5, alpha=0.8)
    plt.title(
        f"n_neighbors: {params['n_neighbors']}, min_dist: {params['min_dist']}\n"
        f"Čas: {end_time-start_time:.2f}s"
    )
    plt.colorbar()
    
plt.tight_layout()
plt.show()
```

tsne = TSNE(n_components=2, random_state=42)
X_tsne = tsne.fit_transform(X)

# Získání 4 nejdůležitějších příznaků (na základě jednoduchého měření rozptylu)
feature_vars = np.var(X, axis=0)
top_features_idx = np.argsort(feature_vars)[-4:]
feature_names = [cancer.feature_names[i] for i in top_features_idx]

# Vykreslení t-SNE obarvené podle důležitých příznaků a podle cíle
plt.figure(figsize=(15, 12))

# Vykreslení podle cíle
plt.subplot(2, 3, 1)
plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='viridis', s=10)
plt.title('t-SNE obarvené podle cíle (Maligní/Benigní)')
plt.colorbar(label='Cíl')
plt.grid(alpha=0.3)

# Vykreslení podle důležitých příznaků
for i, (idx, name) in enumerate(zip(top_features_idx, feature_names)):
    plt.subplot(2, 3, i+2)
    plt.scatter(X_tsne[:, 0], X_tsne[:, 1], c=X[:, idx], cmap='plasma', s=10)
    plt.title(f't-SNE obarvené podle {name}')
    plt.colorbar(label=name)
    plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()

```python
# Toto je zjednodušený příklad analýzy jednobuněčných dat
# V praxi byste použili specializované knihovny jako scanpy

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import umap

# Simulace jednobuněčných RNA-seq dat (tisíce genů napříč buňkami)
np.random.seed(42)
n_cells = 1000
n_genes = 2000

# Vytvoření syntetických buněčných typů
cell_types = np.repeat(['T-buňka', 'B-buňka', 'NK-buňka', 'Monocyt'], n_cells // 4)

# Vytvoření matice genové exprese s různými vzory pro každý buněčný typ
expression = np.zeros((n_cells, n_genes))

# T-buňky exprimují geny 0-499 silněji
expression[:n_cells//4, :500] = np.random.normal(8, 2, (n_cells//4, 500))

# B-buňky exprimují geny 500-999 silněji
expression[n_cells//4:n_cells//2, 500:1000] = np.random.normal(8, 2, (n_cells//4, 500))

# NK-buňky exprimují geny 1000-1499 silněji
expression[n_cells//2:3*n_cells//4, 1000:1500] = np.random.normal(8, 2, (n_cells//4, 500))

# Monocyty exprimují geny 1500-1999 silněji
expression[3*n_cells//4:, 1500:] = np.random.normal(8, 2, (n_cells//4, 500))

# Přidání šumu na pozadí
expression += np.random.normal(1, 0.5, expression.shape)

# Aplikace UMAP
reducer = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=42)
embedding = reducer.fit_transform(expression)

# Vykreslení výsledku
plt.figure(figsize=(10, 8))
colors = {'T-buňka': 'red', 'B-buňka': 'blue', 'NK-buňka': 'green', 'Monocyt': 'purple'}
for cell_type in np.unique(cell_types):
    mask = cell_types == cell_type
    plt.scatter(embedding[mask, 0], embedding[mask, 1], c=colors[cell_type], 
                label=cell_type, alpha=0.7, s=10)

plt.legend()
plt.title('UMAP vizualizace jednobuněčných RNA-seq dat')
plt.grid(alpha=0.3)
plt.show()
```

### 2. Embeddingy obrazových příznaků s hlubokým učením

```python
# Tento příklad by normálně využíval předtrénované modely a reálná obrazová data
# Budeme simulovat embeddingy příznaků pro demonstrační účely

import numpy as np
import matplotlib.pyplot as plt
from sklearn.manifold import TSNE

# Simulace vysokodimenzionálních embeddingů obrazových příznaků z CNN
# V praxi by tyto pocházely z modelů jako ResNet, VGG, atd.
np.random.seed(42)
n_images = 500
embedding_dim = 512  # Typický rozměr CNN příznaku

# Vytvoření syntetických embeddingů obrazů pro různé kategorie
categories = ['kočka', 'pes', 'auto', 'letadlo', 'loď']
n_per_category = n_images // len(categories)

# Vytvoření embeddingů s odlišnými vzory pro každou kategorii
embeddings = []
labels = []

for i, category in enumerate(categories):
    # Vytvoření embeddingů pro tuto kategorii s konkrétním směrem
    category_center = np.random.normal(0, 1, embedding_dim)
    category_embeddings = category_center + np.random.normal(0, 0.5, (n_per_category, embedding_dim))
    embeddings.append(category_embeddings)
    labels.extend([category] * n_per_category)

# Kombinace všech embeddingů
embeddings = np.vstack(embeddings)

# Aplikace t-SNE pro vizualizaci vysokodimenzionálních embeddingů
tsne = TSNE(n_components=2, random_state=42)
embeddings_2d = tsne.fit_transform(embeddings)

# Vykreslení výsledku
plt.figure(figsize=(10, 8))
colors = {'kočka': 'red', 'pes': 'blue', 'auto': 'green', 'letadlo': 'purple', 'loď': 'orange'}

for category in categories:
    mask = np.array(labels) == category
    plt.scatter(embeddings_2d[mask, 0], embeddings_2d[mask, 1], c=colors[category], 
                label=category, alpha=0.7, s=30)

plt.legend()
plt.title('t-SNE vizualizace embeddingů obrazových příznaků')
plt.grid(alpha=0.3)
plt.show()
```

### 3. Zpracování přirozeného jazyka

```python
# Tento příklad demonstruje vizualizaci word embeddingů
# V praxi byste použili předtrénované word embeddingy jako Word2Vec, GloVe, atd.

import numpy as np
import matplotlib.pyplot as plt
import umap
from sklearn.manifold import TSNE

# Načtení malé sady předtrénovaných word embeddingů (simulováno pro tento příklad)
np.random.seed(42)
n_words = 200
embedding_dim = 300  # Běžná dimenze word embeddingu

# Vytvoření syntetických word embeddingů
word_vectors = np.random.normal(0, 1, (n_words, embedding_dim))

# Přiřazení kategorií slovům
word_categories = {
    'zvířata': ['pes', 'kočka', 'kůň', 'kráva', 'lev', 'tygr', 'slon', 'zebra', 'žirafa', 'opice'],
    'barvy': ['červená', 'modrá', 'zelená', 'žlutá', 'oranžová', 'fialová', 'černá', 'bílá', 'šedá', 'hnědá'],
    'země': ['usa', 'kanada', 'francie', 'německo', 'japonsko', 'čína', 'indie', 'brazílie', 'austrálie', 'rusko'],
    'čísla': ['jedna', 'dva', 'tři', 'čtyři', 'pět', 'šest', 'sedm', 'osm', 'devět', 'deset']
}

# Vytvoření seznamu slov a jejich kategorií
words = []
categories = []
for category, word_list in word_categories.items():
    words.extend(word_list)
    categories.extend([category] * len(word_list))

# Přiřazení různých vzorů různým kategoriím
for i, category in enumerate(word_categories.keys()):
    category_indices = [j for j, cat in enumerate(categories) if cat == category]
    direction = np.random.normal(0, 1, embedding_dim)
    for idx in category_indices:
        word_vectors[idx] = direction + np.random.normal(0, 0.2, embedding_dim)

# Aplikace technik redukce dimenzionality
tsne = TSNE(n_components=2, random_state=42, perplexity=5)
word_tsne = tsne.fit_transform(word_vectors[:len(words)])

reducer = umap.UMAP(n_components=2, random_state=42, n_neighbors=5)
word_umap = reducer.fit_transform(word_vectors[:len(words)])

# Vykreslení výsledků
plt.figure(figsize=(18, 8))

# t-SNE graf
plt.subplot(121)
colors = {'zvířata': 'red', 'barvy': 'blue', 'země': 'green', 'čísla': 'purple'}
for category in word_categories.keys():
    indices = [i for i, cat in enumerate(categories) if cat == category]
    plt.scatter(word_tsne[indices, 0], word_tsne[indices, 1], c=colors[category], label=category, alpha=0.7)
    
    # Přidání popisků slov
    for idx in indices:
        plt.annotate(words[idx], (word_tsne[idx, 0], word_tsne[idx, 1]), fontsize=8)

plt.title('t-SNE vizualizace word embeddingů')
plt.legend()
plt.grid(alpha=0.3)

# UMAP graf
plt.subplot(122)
for category in word_categories.keys():
    indices = [i for i, cat in enumerate(categories) if cat == category]
    plt.scatter(word_umap[indices, 0], word_umap[indices, 1], c=colors[category], label=category, alpha=0.7)
    
    # Přidání popisků slov
    for idx in indices:
        plt.annotate(words[idx], (word_umap[idx, 0], word_umap[idx, 1]), fontsize=8)

plt.title('UMAP vizualizace word embeddingů')
plt.legend()
plt.grid(alpha=0.3)

plt.tight_layout()
plt.show()
```

## Osvědčené postupy a časté chyby

### Osvědčené postupy

1. **Předzpracování**:
   - Škálujte data před aplikací t-SNE nebo UMAP
   - Zvažte nejprve redukci dimenzionality pomocí PCA pro velmi vysokodimenzionální data
   - Odstraňte nebo imputujte chybějící hodnoty

2. **Výběr parametrů**:
   - Pro t-SNE: Vyzkoušejte hodnoty perplexity mezi 5-50
   - Pro UMAP: Začněte s n_neighbors okolo 15, min_dist okolo 0.1
   - Otestujte více kombinací parametrů

3. **Interpretace**:
   - Pamatujte, že vzdálenosti v t-SNE/UMAP grafech mohou být zavádějící
   - Zaměřte se na shluky a lokální sousedství, ne na absolutní pozice
   - Použijte barvy a další vizuální atributy pro přidání kontextu

4. **Validace**:
   - Porovnejte s jinými technikami redukce dimenzionality
   - Ověřte vzory pomocí doménových znalostí
   - Zvažte kvantitativní evaluační metriky

### Časté chyby

1. **Nadinterpretace**:
   - t-SNE a UMAP mohou vytvářet zdánlivé shluky i v náhodných datech
   - Algoritmy optimalizují pro jiné cíle než lidské vnímání

2. **Citlivost na parametry**:
   - Výsledky se mohou dramaticky změnit s různým nastavením parametrů
   - Vždy prozkoumejte více konfigurací parametrů

3. **Nepochopení globální struktury**:
   - t-SNE často zkresluje globální vztahy
   - Vzdálenosti mezi shluky v t-SNE nemusí být smysluplné

4. **Výpočetní omezení**:
   - Standardní implementace mohou být pomalé pro velké datasety
   - Zvažte vzorkování nebo aproximační metody pro velmi velké datasety

## Shrnutí

Techniky vizualizace vysokodimenzionálních dat jako t-SNE a UMAP poskytují výkonné nástroje pro průzkum a porozumění komplexním datasetům, které by jinak bylo obtížné vizualizovat. Tyto metody nám umožňují promítat vysokodimenzionální data do 2D nebo 3D prostorů při zachování důležitých strukturálních vztahů.

Klíčové poznatky:

1. **t-SNE** vyniká v zachování lokální struktury a odhalování shluků, ale má tendenci zkreslovat globální vztahy a je výpočetně náročný pro velké datasety.

2. **UMAP** nabízí rychlejší výkon při lepším zachování lokální i globální struktury, což jej činí vhodným pro širší spektrum aplikací.

3. Obě techniky vyžadují pečlivé **ladění parametrů** pro dosažení smysluplných vizualizací. Kritické parametry zahrnují perplexitu pro t-SNE a n_neighbors pro UMAP.

4. Správná **interpretace** t-SNE a UMAP grafů je klíčová. Zaměřte se na shluky a relativní blízkosti spíše než na absolutní vzdálenosti.

5. Tyto techniky jsou cennými nástroji pro **průzkumnou analýzu dat** v oborech jako genomika, zpracování obrazu, NLP a mnoha dalších oblastech zabývajících se vysokodimenzionálními daty.
