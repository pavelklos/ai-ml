# Teplotní mapy a korelační matice

## Úvod

Teplotní mapy (heatmapy) jsou mocné vizualizační nástroje, které znázorňují hodnoty dat jako barvy ve dvourozměrné mřížce. Vynikají v zobrazování vzorů, variací a korelací v komplexních datových sadách na první pohled. Korelační matice, běžná aplikace teplotních map, zobrazují korelační koeficienty mezi více proměnnými, což je neocenitelné pro průzkumnou analýzu dat, výběr příznaků ve strojovém učení a identifikaci vztahů v multivariačních datech.

Tento průvodce zkoumá, jak v Pythonu vytvářet efektivní teplotní mapy a korelační matice pomocí různých knihoven, od základních implementací po pokročilé úpravy a interaktivní vizualizace.

## Základní teplotní mapy s Matplotlib a Seaborn

### Vytvoření jednoduché teplotní mapy

Teplotní mapy lze snadno vytvořit jak pomocí Matplotlib, tak i Seaborn. Začněme jednoduchým příkladem:

```python
# Generování vzorových dat
np.random.seed(42)
data = np.random.rand(10, 12)

# Vytvoření jednoduché teplotní mapy s Matplotlib
plt.figure(figsize=(10, 8))
plt.imshow(data, cmap='viridis')
plt.colorbar(label='Hodnota')
plt.title('Základní teplotní mapa s Matplotlib')
plt.tight_layout()
plt.show()

# Vytvoření teplotní mapy se Seaborn
plt.figure(figsize=(10, 8))
sns.heatmap(data, cmap='viridis', annot=False)
plt.title('Základní teplotní mapa se Seaborn')
plt.tight_layout()
plt.show()
```

### Přidání anotací

Přidání anotací hodnot do teplotních map může být přínosnější:

```python
# Vytvoření menšího datasetu pro anotace
small_data = np.round(np.random.rand(5, 6) * 100)

# Vytvoření anotované teplotní mapy se Seaborn
plt.figure(figsize=(10, 8))
sns.heatmap(small_data, 
            annot=True,           # Zobrazit hodnoty
            fmt='g',              # Formát jako obecný (odstranit desetinná místa, pokud nejsou)
            cmap='YlGnBu',        # Žluto-zeleno-modrá barevná mapa
            linewidths=0.5,       # Přidat mřížku
            cbar_kws={'label': 'Hodnota'})
plt.title('Teplotní mapa s anotacemi')
plt.tight_layout()
plt.show()
```

## Korelační matice

Korelační matice zobrazují korelační koeficienty mezi proměnnými v datové sadě, což pomáhá identifikovat vztahy.

### Vytvoření základní korelační matice

```python
# Načtení datasetu Iris
iris = load_iris()
iris_df = pd.DataFrame(iris.data, columns=iris.feature_names)

# Výpočet korelační matice
corr_matrix = iris_df.corr()

# Vykreslení korelační matice
plt.figure(figsize=(10, 8))
sns.heatmap(corr_matrix, 
            annot=True,           # Zobrazit korelační hodnoty
            cmap='coolwarm',      # Modro-červená divergentní barevná mapa
            vmin=-1, vmax=1,      # Nastavit rozsah pro korelační hodnoty
            linewidths=0.5,
            square=True)          # Udělat buňky teplotní mapy čtvercové
plt.title('Korelační matice příznaků datasetu Iris')
plt.tight_layout()
plt.show()
```

### Použití dat z reálného světa

Pojďme vytvořit korelační matici s komplexnějším datasetem:

```python
# Načtení datasetu California housing
housing = fetch_california_housing()
housing_df = pd.DataFrame(housing.data, columns=housing.feature_names)

# Výpočet korelační matice
housing_corr = housing_df.corr()

# Vytvoření masky pro zobrazení pouze dolního trojúhelníku (vyhnout se redundanci)
mask = np.triu(np.ones_like(housing_corr, dtype=bool))

# Vykreslení korelační matice s maskou
plt.figure(figsize=(12, 10))
sns.heatmap(housing_corr, 
            annot=True,           # Zobrazit korelační hodnoty
            mask=mask,            # Použít masku
            cmap='coolwarm',      # Modro-červená divergentní barevná mapa
            vmin=-1, vmax=1,      # Nastavit rozsah pro korelační hodnoty
            center=0,             # Centrovat barevnou mapu na 0
            linewidths=0.5,
            square=True)          # Udělat buňky teplotní mapy čtvercové
plt.title('Korelační matice příznaků California Housing', fontsize=16)
plt.tight_layout()
plt.show()
```

## Pokročilé přizpůsobení teplotních map

### Vlastní barevné mapování

Barevné mapy můžete přizpůsobit na základě konkrétních prahových hodnot nebo podmínek:

```python
# Generování ukázkových dat s kladnými i zápornými hodnotami
np.random.seed(42)
data = np.random.randn(10, 10)

# Vytvoření vlastní divergentní barevné mapy
from matplotlib.colors import LinearSegmentedColormap

# Definice vlastních barev (fialová až zelená)
colors = ["darkpurple", "white", "forestgreen"]
custom_cmap = LinearSegmentedColormap.from_list("custom_diverging", colors, N=256)

# Vykreslení teplotní mapy s vlastní barevnou mapou
plt.figure(figsize=(10, 8))
sns.heatmap(data,
            cmap=custom_cmap,
            center=0,             # Centrovat barevnou mapu na 0
            annot=True,           # Zobrazit hodnoty
            fmt=".2f",            # Formátovat na 2 desetinná místa
            linewidths=0.5)
plt.title('Teplotní mapa s vlastní divergentní barevnou mapou')
plt.tight_layout()
plt.show()
```

### Formátování anotací

Můžete vytvořit vlastní formátování pro anotace:

```python
# Funkce pro formátování anotací různě na základě hodnoty
def fmt_func(val):
    color = 'red' if val < 0 else 'black'
    return f'${val:.2f}' if abs(val) > 0.5 else ''

# Vytvoření maskovaného pole pro selektivní zobrazení
data_masked = np.ma.masked_where(abs(data) <= 0.5, data)

# Vykreslení s vlastním formátováním
plt.figure(figsize=(12, 10))
ax = sns.heatmap(data, 
                annot=np.abs(data) > 0.5,  # Anotovat pouze hodnoty > 0.5
                fmt="",                   # Prázdný formát, protože používáme vlastní formátovač
                cmap='PuOr',              # Fialovo-oranžová barevná mapa
                center=0,
                linewidths=0.5)

# Použití vlastního textového formátování
for i in range(data.shape[0]):
    for j in range(data.shape[1]):
        value = data[i, j]
        if abs(value) > 0.5:  # Přidat text pouze pro hodnoty, které chceme zobrazit
            text_color = 'white' if abs(value) > 1.5 else 'black'
            ax.text(j + 0.5, i + 0.5, f'{value:.2f}', 
                   ha='center', va='center', color=text_color)

plt.title('Teplotní mapa s vlastně formátovanými anotacemi')
plt.tight_layout()
plt.show()
```

## Hierarchické shlukování s teplotními mapami

Hierarchické shlukování může uspořádat řádky a sloupce v teplotních mapách, aby odhalilo vzory:

```python
# Znovu načtení datasetu Iris
iris = load_iris()
iris_df = pd.DataFrame(iris.data, columns=iris.feature_names)

# Přidání informací o druhu
iris_df['species'] = [iris.target_names[i] for i in iris.target]

# Výběr podmnožiny dat pro jasnější vizualizaci
subset = iris_df.sample(40, random_state=42)
features = subset.iloc[:, :-1]  # Všechny sloupce kromě species
row_labels = subset['species']

# Vytvoření shlukované teplotní mapy
plt.figure(figsize=(14, 10))
sns.clustermap(features, 
               cmap='viridis',
               row_colors=pd.Series(row_labels).map({'setosa': 'red', 
                                                    'versicolor': 'green', 
                                                    'virginica': 'blue'}),
               standard_scale=1,  # Standardizace dat podle sloupců
               linewidths=0.01,
               figsize=(14, 10))
plt.title('Hierarchicky shlukovaná teplotní mapa dat Iris', fontsize=16)
plt.tight_layout()
plt.show()
```

## Interaktivní teplotní mapy s Plotly

Plotly umožňuje vytvářet interaktivní teplotní mapy:

```python
# Vytvoření interaktivní korelační teplotní mapy
corr_matrix = iris_df.iloc[:, :-1].corr()

# Základní interaktivní teplotní mapa
fig = px.imshow(corr_matrix,
                labels=dict(x="Příznaky", y="Příznaky", color="Korelace"),
                x=corr_matrix.columns,
                y=corr_matrix.columns,
                color_continuous_scale='RdBu_r',
                title='Interaktivní korelační matice datasetu Iris')
fig.update_layout(
    width=700, 
    height=600,
    title_font_size=20
)
fig.show()

# Pokročilá interaktivní teplotní mapa s vlastními informacemi při najetí myší
fig = go.Figure(data=go.Heatmap(
        z=corr_matrix.values,
        x=corr_matrix.columns,
        y=corr_matrix.columns,
        hoverongaps=False,
        colorscale='RdBu_r',
        zmid=0,  # Centrovat barevnou škálu na 0
        text=np.around(corr_matrix.values, decimals=2),  # Zobrazit zaokrouhlené hodnoty při najetí myší
        hovertemplate='%{y} & %{x}<br>Korelace: %{z:.3f}<extra></extra>'
))

fig.update_layout(
    title='Interaktivní teplotní mapa s vlastními informacemi při najetí myší',
    width=800,
    height=700,
    title_font_size=20
)
fig.show()
```

## Specializované teplotní mapy

### Kalendářové teplotní mapy

Kalendářové teplotní mapy zobrazují hodnoty dat napříč daty:

```python
# Generování dat založených na datech
import datetime as dt

# Vytvoření datového rozsahu pro rok 2022
dates = pd.date_range(start='2022-01-01', end='2022-12-31')
values = np.sin(np.linspace(0, 12*np.pi, len(dates))) + np.random.normal(0, 0.3, len(dates))

# Vytvoření dataframe
date_df = pd.DataFrame({
    'date': dates,
    'value': values
})
date_df['year'] = date_df['date'].dt.year
date_df['month'] = date_df['date'].dt.month
date_df['day'] = date_df['date'].dt.day
date_df['weekday'] = date_df['date'].dt.weekday

# Vytvoření pivot tabulky vhodné pro kalendářovou teplotní mapu
pivot_data = date_df.pivot_table(index='weekday', columns='date', values='value')

# Vykreslení kalendářové teplotní mapy (zjednodušená verze)
plt.figure(figsize=(20, 4))
sns.heatmap(pivot_data, 
            cmap='YlGnBu', 
            cbar_kws={'label': 'Hodnota'})
plt.title('Kalendářová teplotní mapa (dny v týdnu vs. data)')
plt.ylabel('Den v týdnu')
plt.tight_layout()
plt.show()
```

### Komplexní teplotní mapy v Seabornu

Seaborn poskytuje pokročilé možnosti teplotních map s funkcí `clustermap`:

```python
# Vytvoření složitější shlukové teplotní mapy pomocí datasetu Titanic
titanic = sns.load_dataset('titanic')

# Vytvoření pivot tabulky míry přežití podle věku a jízdného
pivot_titanic = titanic.pivot_table(
    values='survived', 
    index=pd.qcut(titanic['age'].fillna(titanic['age'].median()), 5),  # Kvintily věku
    columns=pd.qcut(titanic['fare'].fillna(titanic['fare'].median()), 5),  # Kvintily jízdného
    aggfunc='mean'
)

# Vykreslení clustermap s dendrogramem
plt.figure(figsize=(14, 10))
cluster = sns.clustermap(
    pivot_titanic,
    cmap="YlGnBu",
    annot=True,
    fmt=".2f",
    linewidths=0.5,
    figsize=(10, 8),
    vmin=0, vmax=1,
    cbar_kws={"label": "Míra přežití"}
)
plt.title('Míra přežití podle věkových a cenových kvintilů (shlukovaná)', fontsize=16)
plt.tight_layout()
plt.show()
```

## Osvědčené postupy

1. **Výběr vhodných barevných map**:
   - Pro data, která se pohybují od nízkých po vysoké hodnoty, používejte sekvenční barevné mapy (např. 'viridis', 'YlGnBu')
   - Pro data centrovaná kolem významné hodnoty (jako je 0 pro korelace) používejte divergentní barevné mapy (např. 'coolwarm', 'RdBu')

2. **Optimalizace čitelnosti**:
   - Přidejte anotace, pokud je počet buněk zvládnutelný
   - Použijte masky, abyste se vyhnuli redundanci v symetrických maticích
   - Použijte správné formátování hodnot
   - Zvolte vhodnou velikost buněk na základě dimenze dat

3. **Zlepšení interpretovatelnosti**:
   - Aplikujte shlukování, abyste odhalili vzory
   - Přidejte popisky řádků a sloupců
   - Zahrňte popisné titulky a popisky barevné škály
   - Zvažte řazení nebo přeuspořádání matice na základě hodnot nebo kategorií

4. **Práce s velkými datovými sadami**:
   - Pro velké datové sady použijte podvzorkování nebo agregaci
   - Pro velké matice zvažte interaktivní grafy
   - Přizpůsobte velikost obrázku

5. **Barevné aspekty**:
   - Pokud možno použijte barevné mapy přátelské pro barvoslepé (viridis, cividis atd.)
   - Nastavte příslušné vmin a vmax pro konzistentní škálování
   - Pro divergentní data zvažte použití parametru center
