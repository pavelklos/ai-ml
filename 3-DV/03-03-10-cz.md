## Úvod

Vizualizace akcelerovaná GPU využívá paralelní výpočetní schopnosti grafických procesorů (GPU) k efektivnějšímu vykreslování komplexních vizualizací než tradiční přístupy založené na CPU. S rostoucí velikostí datových sad a složitostí vizualizací se akcelerace pomocí GPU stala nezbytnou pro udržení interaktivního výkonu a umožnění analýzy masivních datových sad v reálném čase.

Tato příručka zkoumá, jak využít schopnosti GPU pro datovou vizualizaci v Pythonu, od základních implementací až po pokročilé techniky pro zpracování miliard datových bodů.

## Základy akcelerace pomocí GPU

### Proč používat GPU pro vizualizaci?

GPU jsou navrženy ke zpracování tisíců paralelních operací současně, což je činí ideálními pro vizualizační úlohy zahrnující:

- Zpracování milionů nebo miliard datových bodů
- Vykreslování v reálném čase s interaktivitou
- Komplexní vizuální výpočty
- Transformace vysokodimenzionálních dat

### Základy architektury GPU

GPU se od CPU liší v několika důležitých aspektech:

- **Paralelní zpracování**: GPU obsahují tisíce menších jader (vs. několik výkonných jader v CPU)
- **Architektura paměti**: Specializovaná na vysokou propustnost spíše než nízkou latenci
- **Výpočetní shadery**: Umožňují obecné výpočty na GPU
- **Vykreslovací pipeline**: Optimalizovaná pro grafické transformace

### Vizualizační pipeline na GPU

```
Data → GPU paměť → Zpracování dat → Vykreslování → Zobrazení
```

Klíčovým úzkým místem je často přenos dat mezi pamětí CPU a GPU, takže efektivní implementace tyto přenosy minimalizují.

### Datashader se streamovanými daty

Pro vizualizaci streamovaných dat s akcelerací GPU:

```python
import pandas as pd
import numpy as np
import holoviews as hv
import datashader as ds
from holoviews.streams import Pipe, Buffer
from holoviews.operation.datashader import datashade
import time

hv.extension('bokeh')

# Vytvoření streamovacího bufferu pro data v reálném čase
buffer = Buffer(pd.DataFrame({'x': [], 'y': [], 'color': []}), length=5_000_000)

# Funkce pro přidání nových dat
def add_data(n=100_000):
    new_data = pd.DataFrame({
        'x': np.random.normal(0, 1, n),
        'y': np.random.normal(0, 1, n),
        'color': np.random.choice(['red', 'blue', 'green'], n)
    })
    buffer.send(new_data)

# Vytvoření dynamického grafu s backendem datashader
points = hv.DynamicMap(hv.Points, streams=[buffer])
datashaded = datashade(points, width=800, height=600, aggregator=ds.count_cat('color'))

# Zobrazení grafu (v Jupyter notebooku)
plot = datashaded.opts(title="Data v reálném čase s akcelerací GPU")

# Simulace streamovaných dat (v Jupyteru by to běželo v samostatném vlákně)
for i in range(10):
    add_data(100_000)
    time.sleep(1)  # V reálné aplikaci by data přicházela z externího zdroje
```

## Porovnání výkonu: CPU vs GPU

Porovnejme výkon vizualizace mezi CPU a GPU:

```python
import time
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import datashader as ds

# Testování různých velikostí datových sad
sizes = [1e5, 1e6, 1e7, 1e8]
cpu_times = []
gpu_times = []

for size in sizes:
    n = int(size)
    print(f"Testování s {n} body...")
    
    # Generování dat
    df = pd.DataFrame({
        'x': np.random.normal(0, 1, size=n),
        'y': np.random.normal(0, 1, size=n)
    })
    
    # Měření času CPU (matplotlib)
    start = time.time()
    if n <= 1e6:  # Matplotlib pouze pro rozumné velikosti
        plt.figure(figsize=(10, 8))
        plt.scatter(df['x'][:min(n, 100000)], df['y'][:min(n, 100000)], s=1, alpha=0.1)
        plt.close()
    cpu_time = time.time() - start
    cpu_times.append(cpu_time)
    
    # Měření času GPU (datashader)
    canvas = ds.Canvas(plot_width=800, plot_height=800)
    start = time.time()
    agg = canvas.points(df, 'x', 'y')
    img = ds.transfer_functions.shade(agg)
    gpu_time = time.time() - start
    gpu_times.append(gpu_time)
    
    print(f"  CPU čas: {cpu_time:.4f}s, GPU čas: {gpu_time:.4f}s")
    print(f"  Zrychlení: {cpu_time/max(gpu_time, 0.001):.1f}x")

# Vykreslení porovnání
plt.figure(figsize=(10, 6))
plt.plot(sizes, cpu_times, 'o-', label='CPU (Matplotlib)')
plt.plot(sizes, gpu_times, 'o-', label='GPU (Datashader)')
plt.xscale('log')
plt.yscale('log')
plt.xlabel('Velikost datové sady (bodů)')
plt.ylabel('Čas vykreslování (sekund)')
plt.title('Výkon vizualizace: CPU vs GPU')
plt.grid(True, alpha=0.3)
plt.legend()
plt.show()

print("Poznámka: Pro největší datové sady bylo vykreslování na CPU omezeno na podmnožinu bodů")
```

### Vizualizace strojového učení s akcelerací GPU

Vizualizace modelů strojového učení s akcelerací GPU:

```python
import numpy as np
import pandas as pd
import plotly.graph_objects as go
from sklearn.datasets import make_classification

# Generování syntetických klasifikačních dat
n_samples = 500_000
n_features = 2
X, y = make_classification(
    n_samples=n_samples, 
    n_features=n_features,
    n_redundant=0, 
    n_informative=2, 
    n_clusters_per_class=2,
    random_state=42
)

df = pd.DataFrame(X, columns=['feature1', 'feature2'])
df['target'] = y

# Vytvoření husté mřížky pro vizualizaci rozhodovací hranice
resolution = 500
x_min, x_max = df['feature1'].min() - 0.5, df['feature1'].max() + 0.5
y_min, y_max = df['feature2'].min() - 0.5, df['feature2'].max() + 0.5
xx, yy = np.meshgrid(np.linspace(x_min, x_max, resolution),
                     np.linspace(y_min, y_max, resolution))

# Trénování jednoduchého modelu s využitím GPU, pokud je dostupné
try:
    from cuml.ensemble import RandomForestClassifier
    import cupy as cp
    import cudf
    
    # Převod na GPU objekty
    X_gpu = cudf.DataFrame(X)
    y_gpu = cudf.Series(y)
    
    # Trénování RF modelu na GPU
    rf = RandomForestClassifier(max_depth=5, n_estimators=100)
    rf.fit(X_gpu, y_gpu)
    
    # Vytvoření predikcí přes mřížku
    grid_points = cudf.DataFrame({
        'feature1': cudf.Series(xx.ravel()),
        'feature2': cudf.Series(yy.ravel())
    })
    
    Z = rf.predict_proba(grid_points)[:, 1].values
    Z = Z.reshape(xx.shape)
    
    print("Použito trénování a predikce modelu s akcelerací GPU")
    
except ImportError:
    # Přechod na CPU
    from sklearn.ensemble import RandomForestClassifier
    
    rf = RandomForestClassifier(max_depth=5, n_estimators=100)
    rf.fit(X, y)
    
    grid_points = np.c_[xx.ravel(), yy.ravel()]
    Z = rf.predict_proba(grid_points)[:, 1]
    Z = Z.reshape(xx.shape)
    
    print("Použito trénování a predikce modelu na CPU (RAPIDS není dostupný)")

# Vytvoření vizualizace modelu s akcelerací WebGL
fig = go.Figure()

# Přidání teplotní mapy rozhodovací hranice
fig.add_trace(
    go.Heatmap(
        x=np.linspace(x_min, x_max, resolution),
        y=np.linspace(y_min, y_max, resolution),
        z=Z,
        colorscale='RdBu_r',
        opacity=0.7,
        showscale=False,
    )
)

# Přidání datových bodů s akcelerací WebGL
fig.add_trace(
    go.Scattergl(
        x=df['feature1'], 
        y=df['feature2'],
        mode='markers',
        marker=dict(
            color=df['target'],
            colorscale='RdBu',
            size=5,
            opacity=0.6,
            line=dict(width=1, color='white'),
        ),
        name='Datové body'
    )
)

fig.update_layout(
    title=f"Vizualizace rozhodovací hranice modelu ML s akcelerací GPU ({n_samples:,} bodů)",
    width=900,
    height=800,
    xaxis_title="Feature 1",
    yaxis_title="Feature 2",
)

fig.show()
```

## Osvědčené postupy a tipy pro optimalizaci

### Optimalizace přenosu dat

```python
import cudf
import numpy as np
import pandas as pd
import time

# Demonstrace technik efektivního přenosu dat

# Metoda 1: Přímý přenos velkého pole NumPy (neefektivní)
def inefficient_transfer(n_rows):
    # Vytvoření velkých dat na CPU
    cpu_data = np.random.random((n_rows, 10))
    
    start = time.time()
    # Přenos na GPU
    gpu_data = cudf.DataFrame(cpu_data)
    transfer_time = time.time() - start
    
    return transfer_time

# Metoda 2: Přenos po částech (efektivnější pro velmi velká data)
def chunked_transfer(n_rows, chunk_size=1_000_000):
    # Vytvoření velkých dat na CPU
    cpu_data = np.random.random((n_rows, 10))
    df_cpu = pd.DataFrame(cpu_data)
    
    start = time.time()
    
    # Zpracování po částech
    chunks = []
```

### Strategie správy paměti

```python
# Správná správa paměti GPU s explicitním uvolňováním
import numpy as np
import time

try:
    import cupy as cp
    import cudf
    
    # Funkce pro zobrazení využití paměti GPU
    def show_gpu_memory():
        # Získání informací o paměti
        meminfo = cp.cuda.runtime.memGetInfo()
        free = meminfo[0]
        total = meminfo[1]
        used = total - free
        
        print(f"Paměť GPU: {used/1e9:.2f} GB použito / {total/1e9:.2f} GB celkem ({used/total*100:.1f}%)")
    
    # Vytvoření velkých polí a jejich správné uvolnění
    show_gpu_memory()
    
    # Vytvoření velkého pole
    print("\nVytváření 1GB pole na GPU...")
    x = cp.random.random((int(1e8), 10)).astype(np.float32)  # Přibližně 4GB
    show_gpu_memory()
    
    # Zpracování pole
    print("\nZpracování pole...")
    y = cp.sin(x) + cp.cos(x) * 2  # Vytvoří další pole
    show_gpu_memory()
    
    # Explicitní uvolnění
    print("\nExplicitní úklid...")
    del x
    cp.cuda.runtime.deviceSynchronize()  # Zajištění dokončení operací
    show_gpu_memory()
    
    del y
    cp.cuda.runtime.deviceSynchronize()
    show_gpu_memory()
    
    # Vyčištění paměťového poolu
    print("\nVyčištění paměťového poolu...")
    cp.get_default_memory_pool().free_all_blocks()
    show_gpu_memory()
    
except ImportError:
    print("Příklady správy paměti přeskočeny - CuPy není dostupný")
```

### Tipy pro výkon vizualizace

1. **Redukce dat**: Použití downsamplingu nebo binování pro počáteční pohledy
2. **Progresivní vykreslování**: Přidávání detailů při přiblížení uživatelem
3. **Efektivní datové struktury**: Využití sloupcových formátů jako Apache Arrow
4. **Výpočty na vyžádání**: Počítejte pouze to, co je viditelné
5. **Kešování**: Ukládání mezivýsledků, které se nemění
6. **Více rozlišení**: Použití různých úrovní detailu v závislosti na úrovni přiblížení
