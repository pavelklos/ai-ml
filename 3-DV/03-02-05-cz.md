# Techniky vizualizace časových řad

## Úvod

Časové řady jsou sekvence datových bodů shromážděných nebo zaznamenaných v určitých časových intervalech. Efektivní vizualizace časových řad může odhalit vzory, trendy, sezónnost a anomálie, které by jinak zůstaly skryty v tabulkových formátech. Tento průvodce zkoumá různé techniky vizualizace časových řad v Pythonu, od základních čárových grafů až po pokročilé interaktivní dashboardy.

Vizualizace časových řad je klíčová v mnoha oborech, včetně:

- Finance (ceny akcií, ekonomické ukazatele)
- Meteorologie a klimatická věda
- Obchodní analytika (prodeje, návštěvnost webových stránek)
- IoT a monitorování senzorů
- Analýza spotřeby energie
- Sledování zdraví a fitness

Zvládnutím těchto vizualizačních technik budete schopni extrahovat smysluplné poznatky z časových dat a efektivně je komunikovat zainteresovaným stranám.

## Základní vizualizace časových řad

Základním způsobem vizualizace časových řad je čárový graf, kde čas je na ose x a měřená hodnota na ose y.

### Jednoduchý čárový graf s Matplotlib

```python
# Generování ukázkových dat časových řad
np.random.seed(42)
dates = pd.date_range(start='2022-01-01', end='2022-12-31', freq='D')
values = np.cumsum(np.random.randn(len(dates)))
ts_data = pd.Series(values, index=dates)

# Vytvoření základního čárového grafu
plt.figure(figsize=(12, 6))
plt.plot(ts_data.index, ts_data.values, linewidth=1.5)
plt.title('Základní čárový graf časové řady', fontsize=16)
plt.xlabel('Datum', fontsize=12)
plt.ylabel('Hodnota', fontsize=12)
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Grafy sezónního rozkladu

Statistický rozklad časových řad pomáhá oddělit časovou řadu na trendovou, sezónní a reziduální složku.

```python
# Generování časové řady s trendem a sezónností
np.random.seed(42)
dates = pd.date_range(start='2018-01-01', end='2022-12-31', freq='M')
trend = np.arange(len(dates)) * 0.1
seasonal = 5 * np.sin(np.linspace(0, 4*np.pi, len(dates)))
noise = np.random.normal(0, 1, len(dates))
data = trend + seasonal + noise

ts = pd.Series(data, index=dates)

# Provedení sezónního rozkladu
decomposition = seasonal_decompose(ts, model='additive', period=12)

# Vykreslení složek rozkladu
fig, axes = plt.subplots(4, 1, figsize=(14, 12))

# Původní řada
decomposition.observed.plot(ax=axes[0], legend=False)
axes[0].set_title('Původní časová řada', fontsize=14)
axes[0].set_ylabel('Hodnota', fontsize=12)

# Trendová složka
decomposition.trend.plot(ax=axes[1], legend=False)
axes[1].set_title('Trend', fontsize=14)
axes[1].set_ylabel('Hodnota', fontsize=12)

# Sezónní složka
decomposition.seasonal.plot(ax=axes[2], legend=False)
axes[2].set_title('Sezónnost', fontsize=14)
axes[2].set_ylabel('Hodnota', fontsize=12)

# Reziduální složka
decomposition.resid.plot(ax=axes[3], legend=False)
axes[3].set_title('Rezidua', fontsize=14)
axes[3].set_ylabel('Hodnota', fontsize=12)

plt.tight_layout()
plt.show()
```

## Teplotní mapy pro časové vzory

Teplotní mapy jsou skvělé pro vizualizaci vzorů napříč více časovými dimenzemi (např. hodina dne vs. den v týdnu).

```python
# Vytvoření hodinových dat pro jeden měsíc
hours = 24
days = 30
dates = pd.date_range(start='2022-01-01', periods=hours*days, freq='H')

# Generování dat s denními a týdenními vzory
hour_effect = np.sin(np.linspace(0, 2*np.pi, hours)) * 5 + 5  # Denní cyklus
day_of_week_effect = np.array([0, 1, 1, 1, 1, 1, 0.5])  # Týdenní vzor (nižší o víkendech)

# Kombinace efektů pro vytvoření datasetu
values = []
for i in range(len(dates)):
    hour = dates[i].hour
    day_of_week = dates[i].dayofweek
    value = hour_effect[hour] * day_of_week_effect[day_of_week] + np.random.normal(0, 0.5)
    values.append(value)

hourly_data = pd.Series(values, index=dates)

# Přeformátování dat pro teplotní mapu
data_for_heatmap = hourly_data.groupby([hourly_data.index.dayofweek, hourly_data.index.hour]).mean().unstack()

# Vytvoření teplotní mapy
plt.figure(figsize=(12, 8))
sns.heatmap(data_for_heatmap, cmap='viridis', annot=False, fmt=".1f")

# Nastavení vlastních popisků
plt.xlabel('Hodina dne', fontsize=12)
plt.ylabel('Den v týdnu', fontsize=12)
day_labels = ['Pondělí', 'Úterý', 'Středa', 'Čtvrtek', 'Pátek', 'Sobota', 'Neděle']
plt.yticks(np.arange(7) + 0.5, day_labels)

plt.title('Hodinové vzory podle dnů v týdnu', fontsize=16)
plt.tight_layout()
plt.show()
```

## Finanční grafy časových řad

Finanční časové řady mají specializované metody vizualizace jako svíčkové grafy.

```python
# Generování ukázkových dat akcií
np.random.seed(42)
dates = pd.date_range(start='2022-01-01', end='2022-12-31', freq='B')  # Obchodní dny
n_periods = len(dates)

# Generování OHLC dat
opens = np.random.normal(100, 1, n_periods)
changes = np.random.normal(0, 2, n_periods)
closes = opens + changes
highs = np.maximum(opens, closes) + np.random.uniform(0, 1, n_periods)
lows = np.minimum(opens, closes) - np.random.uniform(0, 1, n_periods)
volumes = np.random.normal(1000000, 200000, n_periods)

# Vytvoření DataFrame
stock_data = pd.DataFrame({
    'Open': opens,
    'High': highs,
    'Low': lows,
    'Close': closes,
    'Volume': volumes
}, index=dates)

# Výpočet klouzavých průměrů
stock_data['MA20'] = stock_data['Close'].rolling(window=20).mean()
stock_data['MA50'] = stock_data['Close'].rolling(window=50).mean()

# Vytvoření svíčkového grafu pomocí Plotly
fig = go.Figure()

# Přidání svíčkového grafu
fig.add_trace(go.Candlestick(
    x=stock_data.index,
    open=stock_data['Open'],
    high=stock_data['High'],
    low=stock_data['Low'],
    close=stock_data['Close'],
    name='OHLC'
))

# Přidání klouzavých průměrů
fig.add_trace(go.Scatter(
    x=stock_data.index,
    y=stock_data['MA20'],
    line=dict(color='blue', width=1),
    name='20denní KP'
))

fig.add_trace(go.Scatter(
    x=stock_data.index,
    y=stock_data['MA50'],
    line=dict(color='red', width=1),
    name='50denní KP'
))

# Přidání objemu jako sloupcového grafu
fig.add_trace(go.Bar(
    x=stock_data.index,
    y=stock_data['Volume'],
    marker_color='rgba(0, 0, 150, 0.3)',
    name='Objem',
    yaxis='y2'
))

# Aktualizace rozložení s dvěma osami y
fig.update_layout(
    title='Svíčkový graf ceny akcií s objemem',
    xaxis_title='Datum',
    yaxis_title='Cena (Kč)',
    yaxis2=dict(
        title='Objem',
        overlaying='y',
        side='right',
        showgrid=False
    ),
    xaxis_rangeslider_visible=False,  # Skrytí posuvníku rozsahu
    width=1000,
    height=600,
    legend=dict(orientation="h", yanchor="bottom", y=1.02, xanchor="center", x=0.5)
)

fig.show()
```

## Vizualizace anomálií v časových řadách

Vizualizace anomálií pomáhá identifikovat neobvyklé vzory v časových řadách.

```python
# Generování časové řady s anomáliemi
np.random.seed(42)
dates = pd.date_range(start='2022-01-01', end='2022-12-31', freq='D')
values = np.sin(np.linspace(0, 8*np.pi, len(dates))) * 3 + 10
noise = np.random.normal(0, 0.5, len(dates))
values += noise

# Přidání několika anomálií
anomaly_indices = [50, 150, 180, 250, 300]
for idx in anomaly_indices:
    values[idx] = values[idx] + np.random.choice([-1, 1]) * np.random.uniform(4, 6)

ts_data = pd.Series(values, index=dates)

# Výpočet průměru a směrodatné odchylky pro detekci anomálií
mean = ts_data.rolling(window=30, center=True).mean()
std = ts_data.rolling(window=30, center=True).std()

# Definice anomálií jako hodnoty mimo 3 směrodatné odchylky
anomalies = ts_data[(ts_data > mean + 3*std) | (ts_data < mean - 3*std)]

# Vykreslení časové řady se zvýrazněnými anomáliemi
plt.figure(figsize=(14, 7))
plt.plot(ts_data.index, ts_data.values, label='Časová řada', color='blue', alpha=0.7)
plt.plot(mean.index, mean.values, label='Klouzavý průměr (30d)', color='green', linestyle='--')
plt.fill_between(
    mean.index, 
    mean - 3*std, 
    mean + 3*std, 
    color='green', 
    alpha=0.2, 
    label='±3σ Rozsah'
)
plt.scatter(
    anomalies.index, 
    anomalies.values, 
    color='red', 
    label='Anomálie', 
    s=80, 
    zorder=5
)

plt.title('Časová řada s detekcí anomálií', fontsize=16)
plt.xlabel('Datum', fontsize=12)
plt.ylabel('Hodnota', fontsize=12)
plt.legend(fontsize=12)
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Vizualizace předpovědí časových řad

Předpovědi časových řad lze vizualizovat pro zobrazení předpovídaných hodnot spolu s historickými daty.

```python
# Generování historických dat
np.random.seed(42)
dates = pd.date_range(start='2020-01-01', end='2022-12-31', freq='M')
historical_values = np.cumsum(np.random.normal(0.5, 1, len(dates)))
historical = pd.Series(historical_values, index=dates)

# Generování dat "předpovědi"
forecast_dates = pd.date_range(start='2023-01-01', end='2023-12-31', freq='M')
forecast_values = historical_values[-1] + np.cumsum(np.random.normal(0.3, 1.2, len(forecast_dates)))
forecast = pd.Series(forecast_values, index=forecast_dates)

# Výpočet intervalů spolehlivosti (pouze pro ilustraci)
forecast_lower = forecast - 2 * np.arange(1, len(forecast) + 1) ** 0.5
forecast_upper = forecast + 2 * np.arange(1, len(forecast) + 1) ** 0.5

# Vykreslení historických dat a předpovědi
plt.figure(figsize=(14, 7))

# Vykreslení historických dat
plt.plot(historical.index, historical.values, label='Historická data', color='blue', linewidth=2)

# Vykreslení předpovědi s intervaly spolehlivosti
plt.plot(forecast.index, forecast.values, label='Předpověď', color='red', linewidth=2)
plt.fill_between(
    forecast.index, 
    forecast_lower, 
    forecast_upper, 
    color='red', 
    alpha=0.2, 
    label='Interval spolehlivosti'
)

# Přidání svislé čáry pro oddělení historických a předpovědních období
plt.axvline(x=historical.index[-1], color='gray', linestyle='--', linewidth=1.5)
plt.text(historical.index[-1], plt.ylim()[1]*0.9, ' Historie | Předpověď ', 
         horizontalalignment='center', backgroundcolor='white')

plt.title('Vizualizace předpovědi časové řady', fontsize=16)
plt.xlabel('Datum', fontsize=12)
plt.ylabel('Hodnota', fontsize=12)
plt.legend(fontsize=12)
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Korelace mezi časovými řadami

Vizualizace korelací mezi více časovými řadami může odhalit zajímavé vztahy.

```python
# Generování korelovaných časových řad
np.random.seed(42)
dates = pd.date_range(start='2022-01-01', end='2022-12-31', freq='D')
n_series = 4
n_points = len(dates)

# Základní řada s trendem a sezónností
base_series = np.arange(n_points) * 0.05 + np.sin(np.linspace(0, 8*np.pi, n_points)) * 3

# Vytvoření více řad s různými korelacemi k základní řadě
series_data = {}
series_names = ['Series_A', 'Series_B', 'Series_C', 'Series_D']

for i, name in enumerate(series_names):
    # Úprava korelace změnou úrovně šumu
    correlation_noise = np.random.normal(0, i*0.5 + 0.5, n_points)
    series_data[name] = base_series + correlation_noise

# Vytvoření DataFrame
df = pd.DataFrame(series_data, index=dates)

# Vytvoření matice bodových grafů
plt.figure(figsize=(12, 10))
sns.pairplot(df, height=2.5)
plt.suptitle('Matice bodových grafů více časových řad', y=1.02, fontsize=16)
plt.tight_layout()
plt.show()

# Výpočet korelační matice
corr_matrix = df.corr()

# Vytvoření korelační teplotní mapy
plt.figure(figsize=(10, 8))
sns.heatmap(
    corr_matrix, 
    annot=True, 
    cmap='coolwarm', 
    vmin=-1, 
    vmax=1, 
    center=0,
    square=True,
    fmt='.2f'
)
plt.title('Korelační matice mezi časovými řadami', fontsize=16)
plt.tight_layout()
plt.show()
```

## Shrnutí

Vizualizace časových řad je zásadní dovednost pro datové analytiky a vědce pracující s časovými daty. Tento průvodce pokryl širokou škálu technik, od základních čárových grafů až po pokročilé interaktivní vizualizace. Zde jsou hlavní poznatky:

1. **Základní techniky**: Čárové grafy jsou základem vizualizace časových řad, přičemž přizpůsobení, jako je správné formátování časové osy, je nezbytné pro přehlednost.

2. **Více řad**: Při práci s více časovými řadami zvažte použití podgrafů, barevného kódování nebo různých stylů čar pro rozlišení mezi řadami.

3. **Rozklad**: Statistický rozklad může pomoci vizualizovat trendové, sezónní a reziduální složky časové řady.

4. **Vyhlazování**: Klouzavé průměry a další techniky vyhlazování pomáhají identifikovat základní vzory snížením šumu.

5. **Vizualizace vzorů**: Teplotní mapy a kalendářové vizualizace jsou vynikající pro odhalení opakujících se vzorů napříč různými časovými dimenzemi.

6. **Interaktivní nástroje**: Knihovny jako Plotly umožňují interaktivní průzkum dat časových řad se zoomováním, posouváním a tooltipy.

7. **Specializované grafy**: Pro specifické domény, jako jsou finance, poskytují specializované vizualizace jako svíčkové grafy standardizované způsoby zobrazení dat.

8. **Anomálie a předpovědi**: Vizualizace anomálií a předpovědí vyžaduje pečlivou pozornost nejistotě a jasné rozlišení mezi historickými a projektovanými daty.

9. **Korelace**: Pochopení vztahů mezi více časovými řadami je usnadněno bodovými grafy, korelačními teplotními mapami a dalšími vícerozměrnými vizualizacemi.

Při výběru techniky vizualizace pro data časových řad zvažte:
- Konkrétní poznatky, které chcete zdůraznit
- Povahu vašich dat (frekvence, sezónnost, trend)
- Obeznámenost vašeho publika s různými typy grafů
- Požadovanou úroveň interaktivity
- Potřebu zobrazení nejistoty, anomálií nebo projekcí

Zvládnutím těchto vizualizačních technik budete lépe vybaveni k analýze časových vzorů a efektivní komunikaci poznatků založených na čase.
