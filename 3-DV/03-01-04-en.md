## 1. Introduction to Pie Charts

Pie charts are circular statistical graphics that divide a circle into sectors, with each sector representing a proportion of the whole. The area and central angle of each sector are proportional to the quantity it represents.

Pie charts are primarily used to show:
- Part-to-whole relationships
- Proportions of categories within a single data series
- Simple compositions where the focus is on significant differences

```python
# Import essential libraries for pie charts
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set visual style
plt.style.use('seaborn-v0_8-whitegrid')

# Sample data for our examples
categories = ['Category A', 'Category B', 'Category C', 'Category D', 'Category E']
values = [25, 30, 15, 10, 20]

# Simple pie chart visualization with sample data
plt.figure(figsize=(8, 8))
plt.pie(values, labels=categories)
plt.title('Basic Pie Chart')
plt.show()
```

Despite their common usage, pie charts are often criticized in the data visualization community for several reasons we'll explore later in this document. Understanding when to use them—and more importantly, when not to—is essential for effective data communication.

## 2. Basic Pie Charts with Matplotlib

Matplotlib makes it easy to create pie charts with the `pie()` function. Here, we'll cover the basic implementation and essential parameters.

```python
# Import libraries
import matplotlib.pyplot as plt
import numpy as np

# Sample data
categories = ['Product A', 'Product B', 'Product C', 'Product D']
sales = [38, 27, 19, 16]

# Create a simple pie chart
plt.figure(figsize=(10, 6))
plt.pie(sales, labels=categories, autopct='%1.1f%%', startangle=90)
plt.title('Product Sales Distribution')
plt.axis('equal')  # Equal aspect ratio ensures the pie chart is circular
plt.show()

# Additional example with more formatting options
departments = ['Marketing', 'Operations', 'Finance', 'HR', 'IT']
budget = [25000, 30000, 22000, 15000, 18000]
colors = ['#ff9999', '#66b3ff', '#99ff99', '#ffcc99', '#c2c2f0']
explode = (0.05, 0, 0, 0, 0)  # Explode the 1st slice (Marketing)

plt.figure(figsize=(10, 6))
plt.pie(budget, 
        labels=departments, 
        colors=colors,
        explode=explode,
        autopct='%1.1f%%', 
        shadow=True, 
        startangle=90)
plt.title('Company Budget Allocation by Department')
plt.axis('equal')
plt.show()
```

Key parameters of `plt.pie()`:
- `x`: The data values to plot
- `labels`: List of labels for each wedge
- `autopct`: String format for wedge percentages (e.g., '%1.1f%%')
- `explode`: Array to offset wedges from center
- `shadow`: Boolean to add a shadow effect
- `startangle`: Angle to start drawing wedges (counterclockwise from x-axis)
- `colors`: Array of colors for each wedge

## 3. Customizing Pie Charts

Customization is important for creating clear, effective pie charts that align with your visualization needs and style.

```python
# Import libraries
import matplotlib.pyplot as plt
import numpy as np

# Sample data
categories = ['Online', 'Retail Stores', 'Distributors', 'Direct Sales']
revenue = [45, 30, 15, 10]

# Custom colors and styling
colors = ['#2C3E50', '#E74C3C', '#3498DB', '#1ABC9C']


plt.figure(figsize=(10, 8))

# Customized pie chart
wedges, texts, autotexts = plt.pie(
    revenue,
    labels=categories,
    autopct='%1.1f%%',
    startangle=90,
    colors=colors,
    shadow=True,
    explode=(0.05, 0, 0, 0),
    wedgeprops={'edgecolor': 'white', 'linewidth': 2}
)

# Styling the text elements
for text in texts:
    text.set_fontsize(12)
    text.set_fontweight('bold')
    
for autotext in autotexts:
    autotext.set_fontsize(12)
    autotext.set_fontweight('bold')
    autotext.set_color('white')

plt.title('Revenue Distribution by Channel', fontsize=16, fontweight='bold', pad=20)

# Add a legend with percentages
plt.legend(wedges, [f'{c} ({r}%)' for c, r in zip(categories, revenue)], 
           title='Channels',
           loc='center left',
           bbox_to_anchor=(1, 0, 0.5, 1))

plt.axis('equal')
plt.tight_layout()
plt.show()
```

Additional customization tips:
- Use the `wedgeprops` parameter to customize the appearance of wedges
- Style text elements to enhance readability
- Add a legend to provide additional context
- Use thoughtful color choices to differentiate categories effectively

## 4. When to Use Pie Charts (and When Not To)

Pie charts are useful in specific scenarios but are often misused. Understanding when they are appropriate is crucial for effective data visualization.

### When to use pie charts:

1. **Few categories**: When displaying 2-5 categories (rarely more than 7)
2. **Part-to-whole relationship**: When showing how parts contribute to a total
3. **Significant differences**: When differences between segments are substantial
4. **Simple comparison**: For high-level, simple proportion comparisons
5. **Audience familiarity**: When your audience expects or is comfortable with pie charts

### When NOT to use pie charts:

1. **Many categories**: With more than 5-7 categories, pie charts become cluttered
2. **Similar proportions**: When segments have similar sizes, differences are hard to perceive
3. **Comparing across multiple datasets**: Comparing multiple pie charts is ineffective
4. **Time series data**: Pie charts cannot effectively show changes over time
5. **Precise comparisons**: When exact comparisons between categories are needed

```python
# Example: Comparing effective and ineffective use cases for pie charts
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Set up the figure with two rows of subplots
fig, axs = plt.subplots(2, 2, figsize=(16, 12))

# Good use case: Few categories with significant differences
good_case = {'Category A': 45, 'Category B': 30, 'Category C': 25}
axs[0, 0].pie(good_case.values(), labels=good_case.keys(), autopct='%1.1f%%')
axs[0, 0].set_title('Good Use Case: Few Categories with Clear Differences', fontsize=14)

# Bad use case 1: Too many categories
bad_case1 = {f'Category {chr(65+i)}': np.random.randint(3, 10) for i in range(15)}
axs[0, 1].pie(bad_case1.values(), labels=bad_case1.keys(), autopct='%1.1f%%')
axs[0, 1].set_title('Bad Use Case: Too Many Categories', fontsize=14)

# Bad use case 2: Similar proportions
bad_case2 = {'A': 19, 'B': 18, 'C': 21, 'D': 20, 'E': 22}
axs[1, 0].pie(bad_case2.values(), labels=bad_case2.keys(), autopct='%1.1f%%')
axs[1, 0].set_title('Bad Use Case: Similar Proportions', fontsize=14)

# Better alternative: Bar chart for comparison
axs[1, 1].bar(bad_case2.keys(), bad_case2.values(), color='steelblue')
axs[1, 1].set_title('Better Alternative: Bar Chart for Comparison', fontsize=14)
axs[1, 1].set_ylabel('Value')
axs[1, 1].grid(axis='y', alpha=0.3)

# Ensure pie charts are circular
for i in range(2):
    for j in range(2):
        if i != 1 or j != 1:  # Skip the bar chart
            axs[i, j].axis('equal')

plt.tight_layout()
plt.show()
```

## 5. Donut Charts: An Alternative

Donut charts are a variation of pie charts with a hole in the center. Some argue they're slightly better than pie charts as they de-emphasize the central angle and focus more on arc length.

```python
# Creating a donut chart
import matplotlib.pyplot as plt

# Sample data
categories = ['Commuting', 'Entertainment', 'Food', 'Utilities', 'Rent']
expenses = [12, 15, 25, 18, 30]
colors = ['#ff9999', '#66b3ff', '#99ff99', '#ffcc99', '#c2c2f0']

# Create a donut chart
plt.figure(figsize=(10, 8))
wedges, texts, autotexts = plt.pie(
    expenses,
    labels=categories,
    colors=colors,
    autopct='%1.1f%%',
    startangle=90,
    wedgeprops={'width': 0.4}  # This creates the donut hole
)

# Style text elements
for text in texts:
    text.set_fontsize(12)
for autotext in autotexts:
    autotext.set_fontsize(10)
    autotext.set_color('black')

plt.title('Monthly Expense Breakdown', fontsize=16)

# Add a central text
plt.annotate('Expenses', xy=(0, 0), ha='center', va='center', fontsize=20)

plt.axis('equal')
plt.tight_layout()
plt.show()

# Comparing pie and donut charts
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 8))

# Pie chart
ax1.pie(expenses, labels=categories, colors=colors, autopct='%1.1f%%', startangle=90)
ax1.set_title('Standard Pie Chart', fontsize=14)
ax1.axis('equal')

# Donut chart
ax2.pie(expenses, labels=categories, colors=colors, autopct='%1.1f%%', 
        startangle=90, wedgeprops={'width': 0.4})
ax2.set_title('Donut Chart', fontsize=14)
ax2.axis('equal')

plt.tight_layout()
plt.show()
```

Benefits of donut charts:
- The center area can be used for additional information or summary statistics
- Some argue they can be easier to read than standard pie charts
- They provide a slightly more modern aesthetic

## 6. Exploded Pie Charts for Emphasis

Exploded pie charts separate one or more slices from the main pie to emphasize particular segments.

```python
# Creating an exploded pie chart
import matplotlib.pyplot as plt

# Sample data
categories = ['Electronics', 'Clothing', 'Food', 'Books', 'Other']
sales = [35, 25, 20, 15, 5]

# Define explosion (pulled-out effect)
# The slice with the highest value will be pulled out
explode = [0.2 if x == max(sales) else 0 for x in sales]

plt.figure(figsize=(10, 8))
plt.pie(
    sales,
    labels=categories,
    autopct='%1.1f%%',
    startangle=90,
    explode=explode,
    shadow=True,
    colors=plt.cm.Pastel1.colors
)

plt.title('Sales Distribution by Department', fontsize=16)
plt.axis('equal')
plt.tight_layout()
plt.show()

# Exploding multiple slices
categories = ['Product A', 'Product B', 'Product C', 'Product D', 'Product E']
values = [30, 25, 20, 15, 10]
explode = (0.1, 0, 0.1, 0, 0.1)  # Explode every other slice

plt.figure(figsize=(10, 8))
plt.pie(
    values,
    labels=categories,
    explode=explode,
    autopct='%1.1f%%',
    shadow=True,
    colors=plt.cm.tab10.colors,
    startangle=140
)
plt.title('Alternating Exploded Pie Chart', fontsize=16)
plt.axis('equal')
plt.tight_layout()
plt.show()
```

Use exploded pie charts:
- To highlight one or a few critical segments
- When you need to visually emphasize the most important category
- For presentations where you want to draw attention to specific data points

## 7. Nested and Subplotted Pie Charts

For more complex part-to-whole relationships, nested (hierarchical) pie charts or multiple pie charts in subplots can be used.

```python
# Creating a nested pie chart (also called a sunburst chart)
import matplotlib.pyplot as plt
import numpy as np

# Data for the outer ring
outer_labels = ['Electronics', 'Clothing', 'Food', 'Home']
outer_values = [35, 25, 25, 15]
outer_colors = plt.cm.tab10(np.arange(4)/10.)

# Data for the inner ring (subdivisions)
# Electronics breakdown
electronics = [20, 15]
electronics_labels = ['Computers', 'Phones']
electronics_colors = plt.cm.Reds([0.5, 0.8])

# Clothing breakdown
clothing = [15, 10]
clothing_labels = ['Men', 'Women']
clothing_colors = plt.cm.Blues([0.5, 0.8])

# Food breakdown
food = [10, 8, 7]
food_labels = ['Groceries', 'Restaurants', 'Snacks']
food_colors = plt.cm.Greens([0.3, 0.6, 0.8])

# Home breakdown
home = [8, 7]
home_labels = ['Furniture', 'Decor']
home_colors = plt.cm.Purples([0.5, 0.8])

# Create a figure
plt.figure(figsize=(12, 10))

# Create outer pie chart
outer_circle, outer_texts, outer_autotexts = plt.pie(
    outer_values,
    labels=outer_labels,
    colors=outer_colors,
    autopct='%1.1f%%',
    startangle=90,
    radius=1.2,
    wedgeprops=dict(width=0.3, edgecolor='w')
)

# Create inner pie chart (using separate ring segments for each outer category)
plt.pie(
    electronics + clothing + food + home,
    labels=electronics_labels + clothing_labels + food_labels + home_labels,
    colors=np.concatenate([electronics_colors, clothing_colors, food_colors, home_colors]),
    radius=0.9,
    startangle=90,
    wedgeprops=dict(width=0.3, edgecolor='w')
)

# Hollow center for aesthetics
plt.pie(
    [1], 
    colors=['white'],
    radius=0.6
)

plt.title('Nested Pie Chart: Sales Breakdown by Department and Category', fontsize=16)
plt.axis('equal')
plt.tight_layout()
plt.show()

# Multiple pie charts in subplots
fig, axes = plt.subplots(1, 3, figsize=(18, 6))

# Sales by region
regions = ['North', 'South', 'East', 'West']
region_sales = [30, 25, 20, 25]
axes[0].pie(region_sales, labels=regions, autopct='%1.1f%%', colors=plt.cm.Paired(np.arange(4)/8.))
axes[0].set_title('Sales by Region', fontsize=14)
axes[0].axis('equal')

# Sales by product category
products = ['Electronics', 'Clothing', 'Food', 'Other']
product_sales = [40, 30, 20, 10]
axes[1].pie(product_sales, labels=products, autopct='%1.1f%%', colors=plt.cm.Set2(np.arange(4)/8.))
axes[1].set_title('Sales by Product Category', fontsize=14)
axes[1].axis('equal')

# Sales by customer type
customers = ['New', 'Returning', 'Loyal']
customer_sales = [25, 35, 40]
axes[2].pie(customer_sales, labels=customers, autopct='%1.1f%%', colors=plt.cm.Set3(np.arange(3)/8.))
axes[2].set_title('Sales by Customer Type', fontsize=14)
axes[2].axis('equal')

plt.tight_layout()
plt.show()
```

Nested pie charts and subplots are useful for:
- Showing hierarchical relationships in data
- Comparing different breakdowns across multiple categories
- Presenting multiple aspect-to-whole relationships simultaneously

However, use these complex pie chart types sparingly, as they can quickly become difficult to interpret.

## 8. Interactive Pie Charts with Plotly

Interactive pie charts can enhance user engagement and provide more detailed information through hover effects and interactivity.

```python
# Creating an interactive pie chart with Plotly
# pip install plotly
import plotly.express as px
import plotly.graph_objects as go
import pandas as pd

# Sample data
data = pd.DataFrame({
    'Category': ['Technology', 'Healthcare', 'Finance', 'Consumer Goods', 'Energy'],
    'Market Share': [28, 22, 18, 16, 16],
    'Growth Rate': [12.3, 9.8, 7.5, 5.2, 4.1]
})

# Simple interactive pie chart with Plotly Express
fig = px.pie(
    data,
    values='Market Share',
    names='Category',
    title='Market Share by Industry Sector',
    hover_data=['Growth Rate'],
    labels={'Growth Rate': 'Annual Growth Rate (%)'}
)

fig.update_traces(
    textposition='inside',
    textinfo='percent+label',
    marker=dict(line=dict(color='#FFFFFF', width=2))
)

fig.update_layout(
    title_font_size=22,
    legend_title_font_size=16,
    legend_font_size=14,
    hoverlabel=dict(bgcolor="white", font_size=14),
    width=800,
    height=600
)

fig.show()  # Will display in notebook or can be saved as HTML

# More customized interactive donut chart with Plotly Graph Objects
fig = go.Figure(data=[go.Pie(
    labels=data['Category'],
    values=data['Market Share'],
    hole=.4,
    hovertemplate='<b>%{label}</b><br>Market Share: %{percent}<br>Growth Rate: %{customdata}%<extra></extra>',
    customdata=data['Growth Rate'],
    texttemplate='%{label}<br>%{percent}',
    marker=dict(
        colors=px.colors.qualitative.Pastel,
        line=dict(color='#FFFFFF', width=2)
    )
)])

fig.update_layout(
    title={
        'text': "Interactive Donut Chart: Market Share by Industry",
        'y': 0.95,
        'x': 0.5,
        'xanchor': 'center',
        'yanchor': 'top',
        'font': {'size': 22}
    },
    annotations=[dict(
        text='2023<br>Market<br>Overview',
        showarrow=False,
        font_size=16,
        x=0.5,
        y=0.5
    )],
    width=800,
    height=600
)

fig.show()  # Will display in notebook or can be saved with fig.write_html("pie_chart.html")
```

Benefits of interactive pie charts:
- Allow users to explore detailed information through hovering
- Can display additional metrics beyond the primary percentages
- Enable toggleable legend for selecting/deselecting categories
- Provide animation capabilities for data changes over time

## 9. Best Practices for Effective Pie Charts

When you decide a pie chart is appropriate for your data, follow these best practices to ensure clarity and effectiveness:

```python
# Demonstrating pie chart best practices
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Sample data
categories = ['Category A', 'Category B', 'Category C', 'Category D']
values = [40, 30, 20, 10]

# Set up figure with two subplots
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 8))

# Poor pie chart practices
ax1.pie(
    values + [2, 1.5, 1, 0.8, 0.7],  # Too many small slices
    labels=['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I'],  # Abbreviated, unclear labels
    colors=plt.cm.rainbow(np.linspace(0, 1, 9)),  # Rainbow colors (hard to distinguish)
    startangle=0
)
ax1.set_title('Poor Practices: Too Many Slices, Rainbow Colors, No Percentages', fontsize=14)

# Best practices demonstration
ax2.pie(
    values,
    labels=categories,
    colors=plt.cm.Pastel1(np.arange(4)/4),  # Limited, distinct color palette
    autopct='%1.1f%%',  # Show percentages
    startangle=90,  # Start at top
    counterclock=False,  # Clockwise direction
    wedgeprops={'linewidth': 1, 'edgecolor': 'white'}  # Contrast edges
)
ax2.set_title('Best Practices: Few Categories, Clear Labels, Percentages Shown', fontsize=14)

# Add a clear legend to the second chart
ax2.legend(
    categories,
    title="Categories",
    loc="center left",
    bbox_to_anchor=(1, 0, 0.5, 1)
)

for ax in [ax1, ax2]:
    ax.axis('equal')

plt.tight_layout()
plt.show()

# Sorting segments for better readability
# Sample data (unsorted)
departments = ['IT', 'Marketing', 'Operations', 'Sales', 'HR']
budget_allocation = [18, 25, 22, 30, 5]

# Create a figure with two subplots
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 8))

# Unsorted pie chart
ax1.pie(
    budget_allocation,
    labels=departments,
    autopct='%1.1f%%',
    startangle=90,
    colors=plt.cm.Set2(np.arange(len(departments))/8.)
)
ax1.set_title('Unsorted: Harder to Compare', fontsize=14)
ax1.axis('equal')

# Sort data for better visualization
sorted_indices = np.argsort(budget_allocation)[::-1]  # Sort in descending order
sorted_values = [budget_allocation[i] for i in sorted_indices]
sorted_labels = [departments[i] for i in sorted_indices]

# Sorted pie chart
ax2.pie(
    sorted_values,
    labels=sorted_labels,
    autopct='%1.1f%%',
    startangle=90,
    colors=plt.cm.Set2(np.arange(len(departments))/8.)
)
ax2.set_title('Sorted (Descending): Easier to Interpret', fontsize=14)
ax2.axis('equal')

plt.tight_layout()
plt.show()
```

Key best practices for pie charts:
1. **Limit the number of categories** to 5-7 at most
2. **Use clear, sorted ordering** (typically largest to smallest)
3. **Include percentages or values** directly on the chart
4. **Use distinct but not overwhelming colors**
5. **Add clear labels** that explain what each slice represents
6. **Include a title** that explains what the whole pie represents
7. **Start at 12 o'clock position** (90° angle) for better readability
8. **Consider adding a legend** if slice labels would be cluttered
9. **Use direct labeling** when possible instead of forcing users to match colors to a legend
10. **Ensure good contrast** between slices with borders or spacing

## 10. Summary

Pie charts are visualizations for showing part-to-whole relationships through proportional segments of a circle. While they're widely used in business and media, they should be employed carefully and only in specific situations.

**When to use pie charts:**
- For depicting simple proportions with few categories (ideally 2-5)
- When showing how parts relate to a whole
- When substantial differences exist between segments
- When your audience is familiar with and expects pie charts

**When to avoid pie charts:**
- With more than 5-7 categories
- When values are similar in size
- For precise comparisons between values
- When showing changes over time
- For complex data relationships

**Alternatives to consider:**
- Bar charts for more precise comparisons
- Stacked bar charts for part-to-whole relationships
- Treemaps for hierarchical part-to-whole relationships
- Donut charts for a slightly improved version of pie charts
- Waffle charts for discrete proportions

Pie charts, when used appropriately and designed well, can be effective for giving audiences a quick understanding of proportional relationships in data. However, they should always be chosen thoughtfully, with consideration for both the data characteristics and the intended message.
