# Vizualizace vícerozměrných dat

## Úvod

Vizualizace vícerozměrných dat je jedním z nejnáročnějších aspektů datové vizualizace. Zatímco lidé snadno interpretují 2D a 3D vizualizace, většina reálných datových sad obsahuje mnohem více dimenzí, což představuje jedinečnou výzvu: jak efektivně vizualizovat data se 4, 10 nebo dokonce stovkami dimenzí?

Techniky vizualizace vícerozměrných dat nám pomáhají překonat toto omezení projekcí vysokodimenzionálních dat do prostorů s nižší dimenzí, kódováním dimenzí jako vizuálních atributů nebo použitím specializovaných typů grafů určených ke zpracování více proměnných současně. Zvládnutí těchto technik je zásadní pro průzkumnou analýzu dat, feature engineering a komunikaci komplexních vztahů v datech.

Tento průvodce zkoumá různé techniky vizualizace vícerozměrných dat v Pythonu, od tradičních přístupů až po pokročilé metody redukce dimenzionality a interaktivní vizualizace.


## Paralelní souřadnice

Grafy s paralelními souřadnicemi představují každou dimenzi jako vertikální osu a každý datový bod jako čáru spojující jeho hodnoty napříč všemi dimenzemi. Tato technika je obzvláště užitečná pro identifikaci vzorů napříč mnoha dimenzemi.

```python
# Vytvoření grafu paralelních souřadnic pro datovou sadu Iris

fig = px.parallel_coordinates(
```

## Radarové grafy

Radarové grafy (známé také jako paprskové grafy nebo hvězdicové grafy) zobrazují multivariační data na osách vycházejících ze stejného bodu. Každá osa představuje jednu dimenzi.

```python
# Příprava dat pro radarový graf - použití průměrů skupin
grouped = iris_df.groupby('species').mean().reset_index()
features = iris_df.columns[:-1].tolist()

# Vytvoření radarového grafu pomocí Plotly
fig = go.Figure()

for i, species in enumerate(grouped['species']):
    fig.add_trace(go.Scatterpolar(
        r=grouped.loc[i, features].values.tolist(),
        theta=features,
        fill='toself',
        name=species
    ))

fig.update_layout(
    polar=dict(
        radialaxis=dict(
            visible=True,
        )
    ),
    showlegend=True,
    title="Radarový graf příznaků druhů Iris"
)
fig.show()

# Matplotlib verze pro radarové grafy
from matplotlib.path import Path
from matplotlib.spines import Spine
from matplotlib.transforms import Affine2D

def radar_chart(df, group_col, value_cols):
    # Počet proměnných
    N = len(value_cols)
    
    # Vytvoření úhlů pro každou proměnnou
    angles = [n / float(N) * 2 * np.pi for n in range(N)]
    angles += angles[:1]  # Uzavření smyčky
    
    # Inicializace obrázku
    fig, ax = plt.subplots(figsize=(8, 8), subplot_kw=dict(polar=True))
    
    # Získání názvů skupin
    groups = df[group_col].unique()
    
    # Nastavení barevného cyklu
    colors = plt.cm.viridis(np.linspace(0, 1, len(groups)))
    
    # Vykreslení jedné čáry na skupinu
    for i, group in enumerate(groups):
        values = df[df[group_col] == group][value_cols].mean().values.flatten().tolist()
        values += values[:1]  # Uzavření smyčky
        
        # Vykreslení čáry
        ax.plot(angles, values, color=colors[i], linewidth=2, label=group)
        ax.fill(angles, values, color=colors[i], alpha=0.25)
    
    # Nastavení popisků a názvu
    ax.set_xticks(angles[:-1])
    ax.set_xticklabels(value_cols)
    ax.set_title('Radarový graf příznaků druhů Iris')
    plt.legend(loc='upper right', bbox_to_anchor=(0.1, 0.1))
    
    plt.tight_layout()
    
# Volání funkce s našimi daty
radar_chart(iris_df, 'species', iris_df.columns[:-1])
plt.show()
```

## Techniky redukce dimenzionality

Techniky redukce dimenzionality transformují vysokodimenzionální data do nízkorozměrné reprezentace, kterou lze snáze vizualizovat.

### Analýza hlavních komponent (PCA)

PCA je lineární technika redukce dimenzionality, která identifikuje směry (hlavní komponenty), podél kterých data vykazují největší variabilitu.

```python
# Standardizace dat
X = iris_df.drop('species', axis=1)
features = X.columns
X_scaled = StandardScaler().fit_transform(X)

# Aplikace PCA
pca = PCA(n_components=2)  # Redukce na 2 dimenze
X_pca = pca.fit_transform(X_scaled)

# Vytvoření dataframe s výsledky PCA
pca_df = pd.DataFrame(data=X_pca, columns=['PC1', 'PC2'])
pca_df['species'] = iris_df['species']

# Vykreslení výsledků PCA
plt.figure(figsize=(10, 8))
sns.scatterplot(x='PC1', y='PC2', hue='species', data=pca_df, s=100, alpha=0.8)
plt.title('PCA datové sady Iris')
plt.xlabel(f'Hlavní komponenta 1 ({pca.explained_variance_ratio_[0]:.2%} variance)')
plt.ylabel(f'Hlavní komponenta 2 ({pca.explained_variance_ratio_[1]:.2%} variance)')
plt.grid(linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Vizualizace zatížení příznaků
loadings = pd.DataFrame(
    pca.components_.T, 
    columns=['PC1', 'PC2'], 
    index=features
)

plt.figure(figsize=(10, 8))
loading_plot = sns.heatmap(loadings, annot=True, cmap='coolwarm', center=0)
plt.title('Zatížení příznaků v PCA')
plt.tight_layout()
plt.show()

# Vytvoření biplotu
def biplot(score, coeff, labels=None):
    xs = score[:,0]
    ys = score[:,1]
    n = coeff.shape[0]
    scalex = 1.0/(xs.max() - xs.min())
    scaley = 1.0/(ys.max() - ys.min())
    
    plt.figure(figsize=(10, 8))
    plt.scatter(xs * scalex, ys * scaley, c=iris.target, cmap='viridis')
    
    for i in range(n):
        plt.arrow(0, 0, coeff[i,0], coeff[i,1], color='r', alpha=0.5)
        if labels is not None:
            plt.text(coeff[i,0]* 1.15, coeff[i,1] * 1.15, labels[i], color='g', ha='center', va='center')
    
    plt.xlabel(f"PC1 ({pca.explained_variance_ratio_[0]:.2%})")
    plt.ylabel(f"PC2 ({pca.explained_variance_ratio_[1]:.2%})")
    plt.grid()
    plt.title("PCA Biplot")
    
biplot(X_pca, np.transpose(pca.components_), iris_df.columns[:-1])
plt.tight_layout()
plt.show()
```

### t-SNE

t-SNE (t-Distributed Stochastic Neighbor Embedding) je nelineární technika, která je obzvláště dobrá v zachování lokálních struktur v datech.

```python
# Aplikace t-SNE
tsne = TSNE(n_components=2, random_state=42)
X_tsne = tsne.fit_transform(X_scaled)

# Vytvoření dataframe s výsledky t-SNE
tsne_df = pd.DataFrame(data=X_tsne, columns=['t-SNE1', 't-SNE2'])
tsne_df['species'] = iris_df['species']

# Vykreslení výsledků t-SNE
plt.figure(figsize=(10, 8))
sns.scatterplot(x='t-SNE1', y='t-SNE2', hue='species', data=tsne_df, s=100, alpha=0.8)
plt.title('t-SNE datové sady Iris')
plt.grid(linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Aplikace t-SNE na složitější datový soubor (Wine)
X_wine = wine_df.drop('target', axis=1)
X_wine_scaled = StandardScaler().fit_transform(X_wine)

tsne_wine = TSNE(n_components=2, random_state=42)
X_wine_tsne = tsne_wine.fit_transform(X_wine_scaled)

# Vytvoření dataframe s výsledky t-SNE pro Wine
tsne_wine_df = pd.DataFrame(data=X_wine_tsne, columns=['t-SNE1', 't-SNE2'])
tsne_wine_df['target'] = wine_df['target']

# Vykreslení výsledků t-SNE pro Wine
plt.figure(figsize=(10, 8))
sns.scatterplot(x='t-SNE1', y='t-SNE2', hue='target', data=tsne_wine_df, s=100, alpha=0.8)
plt.title('t-SNE datové sady Wine')
plt.grid(linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()
```

### UMAP

Uniform Manifold Approximation and Projection (UMAP) je technika redukce dimenzionality, která dokáže zachovat více globální struktury než t-SNE a zároveň zachovává lokální vztahy mezi sousedy.

```python
# Aplikace UMAP
reducer = umap.UMAP(random_state=42)
X_umap = reducer.fit_transform(X_scaled)

# Vytvoření dataframe s výsledky UMAP
umap_df = pd.DataFrame(data=X_umap, columns=['UMAP1', 'UMAP2'])
umap_df['species'] = iris_df['species']

# Vykreslení výsledků UMAP
plt.figure(figsize=(10, 8))
sns.scatterplot(x='UMAP1', y='UMAP2', hue='species', data=umap_df, s=100, alpha=0.8)
plt.title('UMAP datové sady Iris')
plt.grid(linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Aplikace UMAP na datovou sadu Wine
umap_wine = umap.UMAP(random_state=42)
X_wine_umap = umap_wine.fit_transform(X_wine_scaled)

# Vytvoření dataframe s výsledky UMAP pro Wine
umap_wine_df = pd.DataFrame(data=X_wine_umap, columns=['UMAP1', 'UMAP2'])
umap_wine_df['target'] = wine_df['target']

# Vykreslení výsledků UMAP pro Wine
plt.figure(figsize=(10, 8))
sns.scatterplot(x='UMAP1', y='UMAP2', hue='target', data=umap_wine_df, s=100, alpha=0.8)
plt.title('UMAP datové sady Wine')
plt.grid(linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()
```

## Více dimenzí s vizuálním kódováním

Můžete zakódovat další dimenze v bodových grafech pomocí vizuálních atributů, jako jsou barva, velikost, tvar a průhlednost.

```python
# Načtení datové sady California housing (má více příznaků)
california = fetch_california_housing()
cal_df = pd.DataFrame(california.data, columns=california.feature_names)
cal_df['MedHouseVal'] = california.target

# Vzorkování menší podmnožiny pro přehlednost
cal_sample = cal_df.sample(1000, random_state=42)

# Vytvoření bodového grafu s vícenásobným vizuálním kódováním
plt.figure(figsize=(12, 9))
scatter = plt.scatter(
    cal_sample['MedInc'], 
    cal_sample['HouseAge'], 
    c=cal_sample['MedHouseVal'],  # Barva podle hodnoty domu
    s=cal_sample['Population']/50,  # Velikost podle populace
    alpha=0.6,
    cmap='viridis',
)

plt.colorbar(label='Střední hodnota domu')
plt.xlabel('Střední příjem')
plt.ylabel('Stáří domu')
plt.title('California Housing: Více dimenzí zakódovaných v 2D grafu')
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

# Interaktivní verze s Plotly
fig = px.scatter(
    cal_sample, 
    x='MedInc', 
    y='HouseAge', 
    color='MedHouseVal',
    size='Population',
    hover_data=['AveRooms', 'AveBedrms', 'AveOccup'],
    title='Interaktivní vícerozměrná vizualizace California Housing',
    color_continuous_scale='Viridis',
)
fig.update_layout(
    width=900,
    height=700,
)
fig.show()
```

## 3D vizualizace

3D bodové grafy mohou pomoci vizualizovat tři kontinuální dimenze najednou.


## Pokročilé techniky

### Andrews křivky

Andrews křivky reprezentují každé pozorování jako funkci nad intervalem [0, 2π] a mohou odhalit strukturu ve vysokodimenzionálních datech.

```python
# Vytvoření Andrews křivek pro datovou sadu Iris
plt.figure(figsize=(12, 6))
andrews_curves(iris_df, 'species', colormap='viridis')
plt.title('Andrews křivky datové sady Iris')
plt.legend(loc='best')
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()
```

### Radviz

Radviz umisťuje dimenzionální kotvy kolem kruhu a reprezentuje každý datový bod jako bod uvnitř kruhu táhnutý "pružinami" připojenými k dimenzionálním kotvám.

```python
from pandas.plotting import radviz

plt.figure(figsize=(10, 10))
radviz(iris_df, 'species', color=['blue', 'green', 'red'])
plt.title('Radviz graf datové sady Iris')
plt.tight_layout()
plt.show()
```

## Osvědčené postupy

1. **Vyberte správnou techniku pro vaše data a otázku**:
   - Matice bodových grafů fungují dobře pro méně dimenzí (do ~10)
   - Redukce dimenzionality (PCA, t-SNE, UMAP) funguje pro data s velmi vysokou dimenzionalitou
   - Paralelní souřadnice zvládají mnoho proměnných, ale mohou být nepřehledné

2. **Zpracujte správně předzpracování dat**:
   - Škálujte nebo normalizujte data před aplikací redukce dimenzionality
   - Vhodně ošetřete chybějící hodnoty
   - Zvažte transformace pro zešikmené proměnné

3. **Vyhýbejte se překrývání bodů**:
   - Použijte průhlednost (alpha) pro zobrazení překrývajících se bodů
   - Zvažte přidání šumu (jittering), binning nebo odhady jádrové hustoty
   - Pro přehlednost vzorkujte velké datové sady

4. **Přidejte kontext k vizualizacím**:
   - Vždy označujte osy a uvádějte jednotky
   - Přidejte popisné titulky a legendy
   - Zahrňte barevné škály pro numerická kódování

5. **Zvažte interaktivitu pro průzkum**:
   - Interaktivní grafy umožňují uživatelům přiblížení, filtrování a zobrazení detailů po najetí myší
   - Více propojených pohledů může poskytnout různé perspektivy na stejná data

6. **Ověřujte vzory pomocí statistiky**:
   - Vizuální vzory by měly být potvrzeny statistickými testy
   - Buďte opatrní při interpretaci shluků v grafech s redukovanou dimenzionalitou
   - Pamatujte, že techniky redukce dimenzionality mohou zkreslit vztahy

## Shrnutí

Vizualizace vícerozměrných dat je nezbytná pro porozumění komplexním datovým sadám, ale přináší s sebou přirozené výzvy kvůli naší omezené schopnosti vnímat vyšší dimenze. Tento průvodce pokryl několik přístupů k řešení této výzvy:

- **Přímé vícerozměrné vizualizace** jako matice bodových grafů, paralelní souřadnice a radarové grafy zobrazují surová vícerozměrná data uspořádáním proměnných chytrým způsobem.

- **Techniky redukce dimenzionality** včetně PCA, t-SNE a UMAP promítají vysokodimenzionální data do prostorů s nižší dimenzí při zachování důležitých struktur.

- **Strategie vizuálního kódování** využívají atributy grafu jako barva, velikost, tvar a pozice k zabalení více dimenzí do tradičních grafů.

- **Interaktivní vizualizace** umožňují dynamické prozkoumávání vícerozměrných prostorů prostřednictvím filtrování, zvýrazňování a více propojených pohledů.

Každá technika má své silné stránky a omezení. Matice bodových grafů vynikají v zobrazení párových vztahů, ale stávají se nepraktickými s mnoha proměnnými. Techniky redukce dimenzionality dobře zvládají vysokodimenzionální data, ale mohou zkreslit vztahy. Paralelní souřadnice zobrazují mnoho dimenzí, ale mohou být obtížně interpretovatelné u velkých datových sad.

Nejúčinnější přístup často kombinuje více technik a přizpůsobuje se specifickým charakteristikám vašich dat a otázkám, které se snažíte zodpovědět. Zvládnutím těchto vizualizačních nástrojů můžete získat hlubší vhled do komplexních vícerozměrných datových sad a efektivněji komunikovat tyto poznatky.
