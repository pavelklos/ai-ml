## 1. Úvod do vizualizace kategorických dat

Kategorická data představují proměnné, které lze rozdělit do různých skupin nebo kategorií. Na rozdíl od numerických dat nemají kategorické proměnné přirozené řazení ani mezi nimi nelze provádět smysluplné matematické operace. Efektivní vizualizace kategorických dat pomáhá odhalit vzory, distribuce a vztahy, které nemusí být zřejmé v tabulkové formě.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení stylu pro lepší vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Načtení vzorového datasetu
titanic = sns.load_dataset('titanic')
print(titanic.head())

# Kontrola kategorických sloupců
cat_columns = titanic.select_dtypes(include=['object', 'category']).columns
print("Kategorické sloupce:", list(cat_columns))

# Zobrazení základních informací o kategorických proměnných
for col in cat_columns:
    print(f"\n{col} počty hodnot:")
    print(titanic[col].value_counts())
    print(f"Počet unikátních hodnot: {titanic[col].nunique()}")
```

Kategorická data mohou být:
- **Nominální**: Kategorie bez přirozeného pořadí (např. pohlaví, země, barva)
- **Ordinální**: Kategorie s přirozeným pořadím (např. úroveň vzdělání, hodnocení spokojenosti)

Při vizualizaci kategorických dat je cílem ukázat:
- Frekvenční distribuci kategorií
- Vztahy mezi kategorickými proměnnými
- Vztahy mezi kategorickými a numerickými proměnnými
- Vzory a trendy v rámci kategorií

## 2. Sloupcové grafy a grafy četností

Sloupcové grafy a grafy četností jsou nejběžnějším a nejintuitivnějším způsobem vizualizace kategorických dat. Zobrazují frekvenci nebo počet pozorování v každé kategorii.

```python
# Vytvoření obrázku s podgrafy
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# Jednoduchý sloupcový graf pomocí matplotlib
gender_counts = titanic['sex'].value_counts()
axes[0].bar(gender_counts.index, gender_counts.values, color=['#3498db', '#e74c3c'])
axes[0].set_title('Počet pasažérů podle pohlaví (Matplotlib)')
axes[0].set_ylabel('Počet')
axes[0].set_xlabel('Pohlaví')

# Graf četností s knihovnou seaborn
sns.countplot(data=titanic, x='class', hue='survived', ax=axes[1], palette='viridis')
axes[1].set_title('Počet pasažérů podle třídy a přežití')
axes[1].set_xlabel('Třída cestujícího')
axes[1].set_ylabel('Počet')
axes[1].legend(title='Přežil', labels=['Ne', 'Ano'])

plt.tight_layout()
plt.show()

# Horizontální sloupcový graf pro delší názvy kategorií
plt.figure(figsize=(10, 6))
sns.countplot(data=titanic, y='embark_town', palette='Set2')
plt.title('Počet pasažérů podle města nalodění')
plt.xlabel('Počet')
plt.ylabel('Město nalodění')
plt.tight_layout()
plt.show()

# Normalizovaný sloupcový graf (procenta)
plt.figure(figsize=(10, 6))
# Výpočet procent
class_survival = pd.crosstab(titanic['class'], titanic['survived'], normalize='index') * 100
class_survival.plot(kind='bar', stacked=True, color=['#e74c3c', '#2ecc71'])
plt.title('Míra přežití podle třídy cestujícího')
plt.xlabel('Třída cestujícího')
plt.ylabel('Procenta (%)')
plt.legend(title='Přežil', labels=['Ne', 'Ano'])
plt.xticks(rotation=0)
plt.tight_layout()
plt.show()
```

Klíčové faktory pro sloupcové grafy:
- Vždy začněte osu y od nuly, abyste se vyhnuli zavádějícím vizualizacím
- Používejte konzistentní barvy pro stejné kategorie ve všech grafech
- Pro velký počet kategorií zvažte použití horizontálních sloupcových grafů
- Zvažte seřazení sloupců podle četnosti pro lepší čitelnost
- Používejte normalizované sloupce (procenta) při porovnávání proporcí mezi skupinami

## 3. Krabicové grafy pro kategorická vs. numerická data

Krabicové grafy jsou výborné pro zobrazení distribuce numerických dat napříč různými kategoriemi. Zobrazují medián, kvartily a potenciální odlehlé hodnoty v každé kategorii.

```python
# Vytvoření obrázku s podgrafy
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# Jednoduchý krabicový graf porovnávající distribuci věku podle pohlaví
sns.boxplot(data=titanic, x='sex', y='age', ax=axes[0])
axes[0].set_title('Distribuce věku podle pohlaví')
axes[0].set_xlabel('Pohlaví')
axes[0].set_ylabel('Věk (roky)')

# Krabicový graf s více kategoriemi
sns.boxplot(data=titanic, x='class', y='age', hue='survived', ax=axes[1], palette='Set2')
axes[1].set_title('Distribuce věku podle třídy a přežití')
axes[1].set_xlabel('Třída cestujícího')
axes[1].set_ylabel('Věk (roky)')
axes[1].legend(title='Přežil', labels=['Ne', 'Ano'])

plt.tight_layout()
plt.show()

# Pokročilý krabicový graf s uspořádanými kategoriemi a vlastními barvami
# Vytvoření nové kategorické proměnné na základě věkových skupin
titanic['age_group'] = pd.cut(titanic['age'], bins=[0, 12, 18, 35, 60, 100], 
                             labels=['Dítě', 'Teenager', 'Mladý dospělý', 'Dospělý', 'Senior'])

plt.figure(figsize=(10, 6))
sns.boxplot(data=titanic, x='age_group', y='fare', order=['Dítě', 'Teenager', 'Mladý dospělý', 'Dospělý', 'Senior'])
plt.title('Distribuce jízdného podle věkové skupiny')
plt.xlabel('Věková skupina')
plt.ylabel('Jízdné ($)')
plt.tight_layout()
plt.show()
```

Krabicové grafy pomáhají odpovědět na otázky jako:
- Jak se numerická proměnná (jako věk nebo jízdné) liší napříč různými kategoriemi?
- Která kategorie má nejvyšší/nejnižší medián hodnoty?
- Která kategorie má největší/nejmenší variabilitu?
- Jsou v konkrétních kategoriích odlehlé hodnoty?

## 4. Teplotní mapy pro kategorická data

Teplotní mapy jsou mocným nástrojem pro vizualizaci vztahů mezi dvěma kategorickými proměnnými, přičemž barva reprezentuje četnost, korelaci nebo jinou metriku.

```python
# Vytvoření křížové tabulky dvou kategorických proměnných
survival_class_sex = pd.crosstab(titanic['sex'], [titanic['class'], titanic['survived']])
print(survival_class_sex)

# Přeskupení pro lepší vizualizaci teplotní mapou
survival_by_class_sex = pd.crosstab([titanic['sex']], [titanic['class'], titanic['survived']])
survival_pivot = survival_by_class_sex.unstack().reset_index()
survival_pivot.columns = ['Třída', 'Přežil', 'Pohlaví', 'Počet']
survival_pivot_table = survival_pivot.pivot_table(index=['Pohlaví'], 
                                                 columns=['Třída', 'Přežil'], 
                                                 values='Počet')

# Vytvoření teplotní mapy
plt.figure(figsize=(12, 6))
sns.heatmap(survival_pivot_table, annot=True, cmap='YlGnBu', fmt='d', linewidths=0.5)
plt.title('Počet přežití podle pohlaví, třídy a stavu přežití')
plt.tight_layout()
plt.show()

# Jednoduchá kategoriální korelační teplotní mapa
# Konverze kategorických proměnných na číselné pro korelaci
cat_encoded = pd.get_dummies(titanic[['sex', 'class', 'embarked', 'survived']])
correlation = cat_encoded.corr()

plt.figure(figsize=(10, 8))
sns.heatmap(correlation, annot=True, cmap='coolwarm', vmin=-1, vmax=1, linewidths=0.5)
plt.title('Korelace mezi kategorickými proměnnými (kódování One-Hot)')
plt.tight_layout()
plt.show()
```

Teplotní mapy jsou zvláště užitečné pro:
- Zobrazení distribuce pozorování napříč kombinacemi kategorií
- Identifikaci vzorů a vztahů mezi kategorickými proměnnými
- Vizualizaci kontingenčních tabulek nebo křížových tabulací
- Zobrazení korelací mezi kategorickými proměnnými při správném kódování

## 5. Houslové a bodové grafy

Houslové grafy kombinují aspekty krabicových grafů s grafy jádrových hustot pro zobrazení tvaru distribuce numerických dat napříč kategoriemi. Bodové grafy zobrazují jednotlivé datové body, což může být užitečné pro menší datové soubory.

```python
# Vytvoření obrázku s houslovými grafy
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# Houslový graf
sns.violinplot(data=titanic, x='class', y='age', hue='survived', split=True, ax=axes[0])
axes[0].set_title('Distribuce věku podle třídy a přežití')
axes[0].set_xlabel('Třída cestujícího')
axes[0].set_ylabel('Věk (roky)')

# Bodový graf s rozptýlením
sns.stripplot(data=titanic, x='class', y='age', hue='survived', dodge=True, 
             alpha=0.5, jitter=True, ax=axes[1])
axes[1].set_title('Individuální distribuce věku podle třídy a přežití')
axes[1].set_xlabel('Třída cestujícího')
axes[1].set_ylabel('Věk (roky)')

plt.tight_layout()
plt.show()

# Kombinace houslových a bodových grafů
plt.figure(figsize=(12, 6))
sns.violinplot(data=titanic, x='class', y='fare', inner=None, palette='pastel')
sns.stripplot(data=titanic, x='class', y='fare', color='black', alpha=0.5, jitter=True)
plt.title('Distribuce jízdného podle třídy cestujícího')
plt.xlabel('Třída cestujícího')
plt.ylabel('Jízdné ($)')
plt.tight_layout()
plt.show()
```

Houslové a bodové grafy pomáhají:
- Ukázat celkový tvar distribuce dat napříč kategoriemi
- Porovnat distribuce mezi více kategoriemi
- Identifikovat multimodální distribuce v rámci kategorií
- Zobrazit jednotlivé datové body při současném zobrazení celkových vzorů

## 6. Kategorické bodové grafy

Pro vizualizaci vztahů mezi kategorickými a numerickými proměnnými nebo mezi dvěma kategorickými proměnnými s numerickou metrikou nabízejí kategorické bodové grafy poznatky, které běžné bodové grafy nemohou poskytnout.

```python
# Vytvoření obrázku pro kategorické bodové grafy
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# Kategorický bodový graf: přežití podle věku a třídy
sns.stripplot(data=titanic, x='age', y='class', hue='survived', dodge=True, 
             jitter=0.25, alpha=0.7, ax=axes[0])
axes[0].set_title('Přežití podle věku a třídy')
axes[0].set_xlabel('Věk (roky)')
axes[0].set_ylabel('Třída cestujícího')
axes[0].legend(title='Přežil', labels=['Ne', 'Ano'])

# Kategorický bodový graf: míra přežití podle třídy a pohlaví
sns.pointplot(data=titanic, x='class', y='survived', hue='sex', dodge=0.5, 
             markers=['o', 's'], linestyles=['-', '--'], ax=axes[1])
axes[1].set_title('Míra přežití podle třídy a pohlaví')
axes[1].set_xlabel('Třída cestujícího')
axes[1].set_ylabel('Míra přežití')
axes[1].set_ylim(0, 1)

plt.tight_layout()
plt.show()

# Kategorický bodový graf s velikostí reprezentující další proměnnou
plt.figure(figsize=(10, 6))

# Seskupení dat pro získání průměrného jízdného podle třídy, pohlaví a stavu přežití
grouped_data = titanic.groupby(['class', 'sex', 'survived'])['fare'].mean().reset_index()

# Vytvoření bublinového grafu s velikostí reprezentující průměrné jízdné
sns.scatterplot(data=grouped_data, x='class', y='sex', hue='survived', 
               size='fare', sizes=(50, 500), alpha=0.7, palette='deep')
plt.title('Průměrné jízdné podle třídy, pohlaví a přežití')
plt.xlabel('Třída cestujícího')
plt.ylabel('Pohlaví')
plt.legend(title='Přežil', labels=['Ne', 'Ano'])
plt.tight_layout()
plt.show()
```

Kategorické bodové grafy jsou užitečné pro:
- Zobrazení distribuce jednotlivých bodů napříč kategoriemi
- Identifikaci vzorů a shluků v rámci kategorických skupin
- Vizualizaci toho, jak se numerická proměnná vztahuje ke kategorickým skupinám
- Přidání další dimenze prostřednictvím barvy, velikosti nebo tvaru

## 7. Rojové grafy pro vizualizaci distribuce

Rojové grafy jsou podobné bodovým grafům, ale vyhýbají se překrývání bodů jejich uspořádáním do shluku podél kategorické osy. To z nich činí vynikající nástroj pro zobrazení přesné distribuce dat v rámci každé kategorie.

```python
# Vytvoření rojových grafů
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# Jednoduchý rojový graf
sns.swarmplot(data=titanic, x='class', y='age', ax=axes[0])
axes[0].set_title('Distribuce věku podle třídy cestujícího')
axes[0].set_xlabel('Třída cestujícího')
axes[0].set_ylabel('Věk (roky)')

# Rojový graf s další kategorickou proměnnou
sns.swarmplot(data=titanic, x='class', y='age', hue='survived', dodge=True, ax=axes[1])
axes[1].set_title('Distribuce věku podle třídy a přežití')
axes[1].set_xlabel('Třída cestujícího')
axes[1].set_ylabel('Věk (roky)')
axes[1].legend(title='Přežil', labels=['Ne', 'Ano'])

plt.tight_layout()
plt.show()

# Kombinace krabicového grafu s rojovým grafem
plt.figure(figsize=(12, 6))
sns.boxplot(data=titanic[titanic['age'].notna()], x='class', y='age', color='lightgray')
sns.swarmplot(data=titanic[titanic['age'].notna()], x='class', y='age', hue='sex', dodge=True)
plt.title('Distribuce věku podle třídy cestujícího a pohlaví')
plt.xlabel('Třída cestujícího')
plt.ylabel('Věk (roky)')
plt.tight_layout()
plt.show()
```

Rojové grafy jsou zvláště efektivní, když:
- Je datový soubor relativně malý až střední
- Chcete vidět každý jednotlivý datový bod bez překrývání
- Potřebujete ukázat přesný tvar distribuce v rámci kategorií
- Kombinujete je s krabicovými grafy pro zobrazení jak statistik, tak surových dat

## 8. Pokročilé techniky vizualizace kategorických dat

Kromě základních technik existuje několik pokročilých metod pro vizualizaci kategorických dat, které mohou odhalit složitější vzory a vztahy.

```python
# Vytvoření mřížky faset pro vícerozměrnou kategorickou vizualizaci
g = sns.FacetGrid(titanic, col='class', row='sex', height=4, aspect=1.2)
g.map_dataframe(sns.histplot, x='age', bins=20, kde=True)
g.set_axis_labels("Věk (roky)", "Počet")
g.set_titles("Třída: {col_name} | Pohlaví: {row_name}")
g.fig.subplots_adjust(top=0.9)
g.fig.suptitle('Distribuce věku podle třídy a pohlaví', fontsize=16)
plt.tight_layout()
plt.show()

# Mozaikový graf pomocí statsmodels
from statsmodels.graphics.mosaicplot import mosaic

plt.figure(figsize=(10, 6))
mosaic(titanic, ['sex', 'survived', 'class'], title='Přežití podle pohlaví a třídy')
plt.tight_layout()
plt.show()

# Diagram paralelních kategorií pomocí plotly
import plotly.express as px

# Vytvoření menšího vzorku pro přehlednost
titanic_sample = titanic.dropna(subset=['age', 'fare']).sample(n=200, random_state=42)

fig = px.parallel_categories(titanic_sample, 
                            dimensions=['sex', 'class', 'survived', 'embark_town'],
                            color='fare', color_continuous_scale='Viridis',
                            labels={'sex': 'Pohlaví', 'class': 'Třída', 
                                   'survived': 'Přežil', 'embark_town': 'Místo nalodění'})
fig.update_layout(title='Diagram paralelních kategorií: Vztahy mezi kategoriemi')
fig.show()
```

Pokročilé vizualizační techniky nabízejí:
- Vícerozměrné pohledy na kategorické vztahy
- Interaktivní průzkum kategorických dat
- Intuitivnější vizualizaci složitých kategorických vzorů
- Integraci numerických proměnných s kategorickou strukturou

## 9. Osvědčené postupy pro vizualizaci kategorických dat

Vytvoření efektivních vizualizací pro kategorická data vyžaduje pečlivé zvážení různých faktorů:

```python
# Příklad: Vylepšení základního kategorického grafu
# ŠPATNĚ: Příliš mnoho kategorií s dlouhými názvy a špatnou orientací
plt.figure(figsize=(10, 6))
bad_data = pd.DataFrame({
    'very_long_category_name': ['Kategorie A s velmi dlouhým názvem', 
                              'Kategorie B s ještě delším názvem',
                              'Kategorie C s extrémně dlouhým názvem',
                              'Kategorie D se zbytečně dlouhým názvem',
                              'Kategorie E se směšně dlouhým názvem'],
    'values': [23, 45, 12, 78, 34]
})
plt.bar(bad_data['very_long_category_name'], bad_data['values'])
plt.title('Špatný kategorický graf')
plt.xlabel('Kategorie')
plt.ylabel('Hodnoty')
plt.xticks(rotation=15)  # Nedostatečná rotace
plt.tight_layout()
plt.show()

# DOBŘE: Správná orientace, seřazení a jasné popisky
plt.figure(figsize=(10, 6))
# Seřazení podle hodnot a použití horizontální orientace
bad_data = bad_data.sort_values('values')
plt.barh(bad_data['very_long_category_name'], bad_data['values'], color='teal')
plt.title('Vylepšený kategorický graf')
plt.xlabel('Hodnoty')
plt.ylabel('Kategorie')
# Přidání popisků hodnot
for i, v in enumerate(bad_data['values']):
    plt.text(v + 1, i, str(v), va='center')
plt.tight_layout()
plt.show()

# Příklad: Použití vhodných barevných schémat
plt.figure(figsize=(12, 6))
ax = plt.subplot(121)
# ŠPATNĚ: Duhové barvy pro neseřazené kategorie
sns.countplot(data=titanic, x='class', ax=ax, palette='rainbow')
ax.set_title('Špatná volba barev pro kategorie')

ax = plt.subplot(122)
# DOBŘE: Odlišné, ale harmonické barvy pro nominální kategorie
sns.countplot(data=titanic, x='class', ax=ax, palette='Set2')
ax.set_title('Lepší volba barev pro kategorie')

plt.tight_layout()
plt.show()
```

Osvědčené postupy zahrnují:
- **Smysluplné řazení kategorií**: Abecedně, podle četnosti nebo přirozeného pořadí
- **Řešení dlouhých názvů kategorií**: Použití horizontálních sloupcových grafů nebo zkrácení názvů
- **Volba vhodných barevných schémat**: Použití kvalitativních schémat pro nominální data, sekvenčních nebo divergentních schémat pro ordinální data
- **Zohlednění publika**: Volba vizualizací a barev, které jsou přístupné všem, včetně osob s poruchami barvocitu
- **Zjednodušení v případě potřeby**: Seskupení malých kategorií do kategorie "Ostatní", pokud je příliš mnoho kategorií
- **Přidání kontextu**: Zahrnutí součtů, procent nebo relevantních statistik
- **Použití interaktivních prvků**: Pro komplexní kategorická data zvažte interaktivní vizualizace
- **Konzistence**: Použití stejných barev pro stejné kategorie napříč více grafy

## 10. Shrnutí

Efektivní vizualizace kategorických dat je klíčová pro pochopení vzorů a vztahů v datech, která nemají přirozené numerické vyjádření. Klíčové body, které je třeba si zapamatovat, jsou:

1. **Vyberte správnou vizualizaci** na základě vašich dat a toho, co chcete sdělit:
   - Sloupcové grafy a grafy četností pro frekvence
   - Krabicové a houslové grafy pro vztah mezi kategorickými a numerickými daty
   - Teplotní mapy pro vztahy mezi kategoriemi
