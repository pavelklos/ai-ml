## 1. Úvod do přizpůsobení grafů

Přizpůsobení grafů je nezbytné pro vytváření efektivních, profesionálně vypadajících datových vizualizací. Matplotlib nabízí rozsáhlé možnosti přizpůsobení, které vám umožňují vylepšit vaše grafy informativními titulky, jasnými popisky a užitečnými legendami. Dobře přizpůsobené grafy efektivněji komunikují informace a mohou učinit složitá data přístupnější vašemu publiku.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení motivu pro konzistentní stylizaci
plt.style.use('seaborn-v0_8-whitegrid')

# Vytvoření vzorových dat
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

# Vytvoření základního grafu
plt.figure(figsize=(10, 6))
plt.plot(x, y1)
plt.plot(x, y2)
plt.show()

# Nyní budeme na tomto základě vytvářet plně přizpůsobený graf
```

Základní graf výše zobrazuje data, ale postrádá důležitý kontext. V průběhu tohoto průvodce jej budeme transformovat na informativnější a vizuálně přitažlivější vizualizaci.

## 2. Přizpůsobení titulků a podtitulků

Titulky a podtitulky poskytují důležitý kontext pro vaše vizualizace. Dobrý titulek jasně sděluje, co graf představuje, zatímco podtitulky mohou přidat dodatečný kontext nebo vysvětlení.

```python
plt.figure(figsize=(10, 6))
plt.plot(x, y1)
plt.plot(x, y2)

# Přidání hlavního titulku
plt.title('Funkce sinus a kosinus', 
          fontsize=16, 
          fontweight='bold', 
          pad=20)

# Přidání podtitulku
plt.suptitle('Trigonometrické funkce od 0 do 10', 
             fontsize=12, 
             fontfamily='serif',
             y=0.95)

# Zobrazení grafu
plt.show()

# Přidání titulku s formátováním LaTeX
plt.figure(figsize=(10, 6))
plt.plot(x, y1)
plt.plot(x, y2)
plt.title(r'Funkce $\sin(x)$ a $\cos(x)$', fontsize=16)
plt.show()
```

Klíčové parametry přizpůsobení titulku:
- `fontsize`: Určuje velikost textu titulku
- `fontweight`: Může být nastaveno na 'normal', 'bold', atd.
- `fontfamily`: Rodina písma ('serif', 'sans-serif', atd.)
- `color`: Barva textu titulku
- `loc`: Umístění ('center', 'left', 'right')
- `pad`: Odsazení mezi titulkem a grafem

## 3. Přidávání a formátování popisků os

Jasné popisky os jsou klíčové pro pochopení významu dat a jejich jednotek. Matplotlib poskytuje několik možností pro přizpůsobení vzhledu těchto popisků.

```python
plt.figure(figsize=(10, 6))
plt.plot(x, y1)
plt.plot(x, y2)

# Přidání a přizpůsobení popisků os
plt.xlabel('Osa X (radiány)', 
           fontsize=12, 
           color='darkblue', 
           labelpad=10)

plt.ylabel('Osa Y (amplituda)', 
           fontsize=12, 
           color='darkblue',
           labelpad=10)

# Přizpůsobení titulku
plt.title('Funkce sinus a kosinus', fontsize=16)

plt.show()

# Použití formátování LaTeX pro matematické výrazy v popiscích
plt.figure(figsize=(10, 6))
plt.plot(x, y1)
plt.plot(x, y2)
plt.xlabel(r'$\theta$ (radiány)', fontsize=12)
plt.ylabel(r'$f(\theta)$', fontsize=12)
plt.title('Trigonometrické funkce', fontsize=16)
plt.show()
```

Klíčové parametry přizpůsobení popisků:
- `fontsize`: Určuje velikost písma
- `color`: Nastavuje barvu popisku
- `labelpad`: Určuje odsazení mezi osou a jejím popiskem
- `rotation`: Otáčí popisek (užitečné pro dlouhé popisky)
- `loc`: Pozice popisku ('center', 'left', 'right')

## 4. Práce s legendami

Legendy pomáhají divákům identifikovat, které vizuální prvky odpovídají kterým datovým řadám. Matplotlib nabízí rozsáhlé možnosti přizpůsobení legend tak, aby byly informativní a vizuálně přitažlivé.

```python
plt.figure(figsize=(10, 6))

# Graf s popisky pro legendu
plt.plot(x, y1, label='Sinus')
plt.plot(x, y2, label='Kosinus')

# Základní legenda
plt.legend()
plt.title('Základní příklad legendy')
plt.show()

# Přizpůsobená legenda
plt.figure(figsize=(10, 6))
plt.plot(x, y1, label='Sinus', color='royalblue', linestyle='-')
plt.plot(x, y2, label='Kosinus', color='forestgreen', linestyle='--')

plt.legend(
    loc='upper right',           # Pozice legendy
    frameon=True,                # Zobrazení rámečku legendy
    framealpha=0.9,              # Průhlednost rámečku
    shadow=True,                 # Přidání stínu k rámečku
    borderpad=1,                 # Odsazení uvnitř okraje legendy
    title='Funkce',              # Titulek pro legendu
    title_fontsize=12,           # Velikost písma titulku
    fontsize=10,                 # Velikost písma položek
    ncol=2                       # Počet sloupců
)

plt.title('Příklad přizpůsobené legendy')
plt.xlabel('Osa X (radiány)')
plt.ylabel('Osa Y (amplituda)')
plt.show()

# Umístění legendy mimo oblast grafu
plt.figure(figsize=(10, 6))
plt.plot(x, y1, label='Sinus')
plt.plot(x, y2, label='Kosinus')

plt.legend(bbox_to_anchor=(1.05, 1), loc='upper left', borderaxespad=0.)
plt.tight_layout()
plt.title('Legenda mimo oblast grafu')
plt.show()
```

Klíčové parametry přizpůsobení legendy:
- `loc`: Pozice ('upper right', 'lower left', 'center', atd.)
- `bbox_to_anchor`: Jemnější kontrola nad pozicí (dvojice (x, y))
- `ncol`: Počet sloupců v legendě
- `frameon`: Zda kreslit rámeček kolem legendy
- `framealpha`: Průhlednost rámečku legendy
- `title`: Přidání titulku k legendě
- `fontsize`: Řízení velikosti písma položek legendy
- `markerscale`: Úprava velikosti značek v legendě

## 5. Přizpůsobení popisků značek a mřížkových čar

Značky na osách a mřížkové čáry pomáhají čtenářům přesně interpretovat hodnoty. Přizpůsobení těchto prvků může výrazně zlepšit čitelnost vašich grafů.

```python
plt.figure(figsize=(10, 6))
plt.plot(x, y1, label='Sinus')
plt.plot(x, y2, label='Kosinus')

# Přizpůsobení značek na osách
plt.xticks(
    ticks=np.arange(0, 11, 2),                  # Pozice značek
    labels=['0', '2π/5', '4π/5', '6π/5', '8π/5', '2π'],  # Vlastní popisky
    fontsize=10,
    rotation=45
)
plt.yticks(np.arange(-1, 1.5, 0.5), fontsize=10)

# Přizpůsobení mřížky
plt.grid(True, linestyle='--', alpha=0.7)

# Přidání hlavních a vedlejších mřížkových čar
plt.minorticks_on()
plt.grid(which='major', color='#DDDDDD', linewidth=1.2)
plt.grid(which='minor', color='#EEEEEE', linestyle=':', linewidth=0.8)

plt.title('Přizpůsobené popisky značek a mřížkové čáry')
plt.xlabel('Osa X')
plt.ylabel('Osa Y')
plt.legend()
plt.tight_layout()
plt.show()

# Objektově orientovaný přístup s explicitními osami
fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(x, y1, label='Sinus')
ax.plot(x, y2, label='Kosinus')

# Konfigurace vlastností značek
ax.tick_params(
    axis='x',                # Změny se aplikují na osu x
    which='both',            # Ovlivněny jsou hlavní i vedlejší značky
    direction='out',         # Směr ('in', 'out' nebo 'inout')
    length=6,                # Délka značek
    width=1,                 # Šířka značek
    color='darkblue',        # Barva značek
    pad=10,                  # Vzdálenost od značky k popisku
    labelsize=10,            # Velikost popisků značek
    labelcolor='darkblue',   # Barva popisků značek
    bottom=True,             # Zobrazení značek dole
    top=False,               # Nezobrazení značek nahoře
    labelbottom=True         # Zobrazení popisků značek dole
)

ax.set_title('Přizpůsobené vlastnosti značek')
ax.set_xlabel('Osa X')
ax.set_ylabel('Osa Y')
ax.legend()
plt.tight_layout()
plt.show()
```

Klíčové možnosti přizpůsobení značek a mřížky:
- `plt.xticks()/plt.yticks()`: Nastavení vlastních pozic značek a popisků
- `tick_params()`: Řízení detailních aspektů značek
- `plt.grid()`: Konfigurace mřížkových čar
- `plt.minorticks_on()`: Povolení vedlejších značek
- `which`: Určení, které mřížkové čáry upravit ('major', 'minor', 'both')

## 6. Přidávání textových anotací a šipek

Anotace přidávají důležitý kontext k specifickým prvkům nebo datovým bodům ve vaší vizualizaci. Pomáhají upozornit na klíčové poznatky nebo vysvětlit anomálie.

```python
plt.figure(figsize=(10, 6))
plt.plot(x, y1, label='Sinus')
plt.plot(x, y2, label='Kosinus')

# Přidání jednoduché textové anotace
plt.text(7, 0.8, 'Lokální maximum', fontsize=12)

# Přidání šipky ukazující na specifický bod
plt.annotate(
    'Bod průsečíku',        # Text
    xy=(π/2, 0),            # Pozice, na kterou ukazovat
    xytext=(π/2 - 1, -0.5), # Pozice textu
    fontsize=12,
    arrowprops=dict(
        facecolor='black',
        shrink=0.05,
        width=1.5,
        headwidth=8
    )
)

# Přidání textového pole s pozadím
plt.text(7, -0.6, 'sin(x) a cos(x) mají\nfázový rozdíl π/2', 
         bbox=dict(facecolor='wheat', alpha=0.5),
         fontsize=12,
         ha='center')

plt.title('Textové anotace a šipky')
plt.xlabel('Osa X')
plt.ylabel('Osa Y')
plt.legend()
plt.grid(True, linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Pokročilé anotace s různými styly šipek
fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(x, y1, label='Sinus')

# Anotace s elegantní šipkou
ax.annotate(
    'Maximum',
    xy=(π/2, 1),            # Bod k anotaci
    xytext=(π/2, 0.5),      # Pozice textu
    fontsize=12,
    arrowprops=dict(
        arrowstyle='->',     # Styl šipky
        connectionstyle='arc3,rad=0.2',  # Zakřivená šipka
        color='red'
    )
)

# Anotace s ohraničenou šipkou
ax.annotate(
    'Minimum',
    xy=(3*π/2, -1),         # Bod k anotaci
    xytext=(3*π/2, -0.5),   # Pozice textu
    fontsize=12,
    bbox=dict(boxstyle='round,pad=0.5', fc='yellow', alpha=0.7),
    arrowprops=dict(
        arrowstyle='fancy',
        connectionstyle='angle3,angleA=0,angleB=90',
        fc='orange', 
        ec='black'
    )
)

ax.set_title('Pokročilé styly anotací')
ax.set_xlabel('Osa X')
ax.set_ylabel('Osa Y')
ax.legend()
ax.grid(True, alpha=0.7)
plt.tight_layout()
plt.show()
```

Klíčové parametry anotací:
- `text()`: Jednoduchý text bez šipky
- `annotate()`: Text se šipkou ukazující na specifickou pozici
- `xy`: Souřadnice bodu k anotaci
- `xytext`: Souřadnice umístění textu
- `arrowprops`: Slovník řídící vzhled šipky
- `bbox`: Slovník řídící vzhled textového pole
- `ha/va`: Horizontální/vertikální zarovnání textu

## 7. Úprava stylů čar a značek

Styly čar a značek pomáhají rozlišit mezi více datovými řadami a mohou být použity k přenosu dodatečných informací prostřednictvím vizuálního kódování.

```python
# Vytvoření vzorových dat pro více čar
t = np.linspace(0, 10, 100)
data = {
    'Lineární': 0.5 * t,
    'Kvadratická': 0.05 * t**2,
    'Exponenciální': np.exp(t/5) / 100,
    'Sinusoidní': np.sin(t) + 2
}

# Styly čar a značky
plt.figure(figsize=(12, 7))

# Vykreslení každé čáry s odlišným stylem
plt.plot(t, data['Lineární'], 
         linestyle='-',          # plná čára
         linewidth=2,            # tloušťka čáry
         color='blue',           # barva čáry
         marker='o',             # styl značky
         markersize=6,           # velikost značky
         markerfacecolor='white',# barva výplně značky
         markeredgecolor='blue', # barva okraje značky
         markeredgewidth=1.5,    # tloušťka okraje značky
         label='Lineární')

plt.plot(t, data['Kvadratická'], 
         linestyle='--',         # čárkovaná čára
         linewidth=2, 
         color='red',
         marker='s',             # čtvercová značka
         markersize=6,
         markerfacecolor='white',
         markeredgecolor='red',
         markeredgewidth=1.5,
         label='Kvadratická')

plt.plot(t, data['Exponenciální'], 
         linestyle='-.',         # čerchovaná čára
         linewidth=2, 
         color='green',
         marker='^',             # trojúhelníková značka
         markersize=6,
         markerfacecolor='white',
         markeredgecolor='green',
         markeredgewidth=1.5,
         label='Exponenciální')

plt.plot(t, data['Sinusoidní'], 
         linestyle=':',          # tečkovaná čára
         linewidth=2, 
         color='purple',
         marker='D',             # kosočtvercová značka
         markersize=6,
         markerfacecolor='white',
         markeredgecolor='purple',
         markeredgewidth=1.5,
         label='Sinusoidní')

plt.title('Různé styly čar a značek', fontsize=16)
plt.xlabel('Čas', fontsize=12)
plt.ylabel('Hodnota', fontsize=12)
plt.grid(True, linestyle='--', alpha=0.7)
plt.legend(fontsize=12)
plt.tight_layout()
plt.show()

# Přehled běžných stylů čar a značek
line_styles = ['-', '--', '-.', ':']
markers = ['o', 's', '^', 'D', 'v', '<', '>', 'p', '*', '+', 'x', '1', '2', '3', '4']

fig, axes = plt.subplots(2, 1, figsize=(10, 8))

# Vykreslení stylů čar
for i, ls in enumerate(line_styles):
    axes[0].plot(np.arange(5), np.ones(5) * i, linestyle=ls, linewidth=2, label=f"'{ls}'")
axes[0].set_title('Styly čar')
axes[0].legend(loc='upper right')
axes[0].set_yticks([])

# Vykreslení značek
for i, marker in enumerate(markers):
    row = i // 5
    col = i % 5
    axes[1].plot(col, row, marker=marker, markersize=10, 
                 markerfacecolor='white', markeredgecolor='blue',
                 markeredgewidth=1.5, linestyle='none',
                 label=f"'{marker}'")

axes[1].set_title('Styly značek')
axes[1].set_xlim(-0.5, 4.5)
axes[1].set_ylim(-0.5, 2.5)
axes[1].set_xticks([])
axes[1].set_yticks([])
axes[1].legend(ncol=5, loc='upper center', bbox_to_anchor=(0.5, -0.05))

plt.tight_layout()
plt.show()
```

Klíčové parametry přizpůsobení čar a značek:
- `linestyle`: Styl čáry ('-', '--', '-.', ':')
- `linewidth`: Šířka čáry
- `color`: Barva čáry
- `marker`: Styl značek ('o', 's', '^', atd.)
- `markersize`: Velikost značek
- `markerfacecolor`: Barva výplně značek
- `markeredgecolor`: Barva okraje značek
- `markeredgewidth`: Šířka okrajů značek
- `alpha`: Průhlednost čáry a značek

## 8. Nastavení barev a barevných map

Barvy jsou mocným nástrojem pro kódování dodatečných informací ve vašich vizualizacích. Matplotlib nabízí široký rozsah barevných možností a barevných map pro různé typy dat.

```python
# Příklad s vlastními barvami a barevnou mapou pro bodový graf
plt.figure(figsize=(14, 8))

# Vytvoření mřížky podgrafů
gs = plt.GridSpec(2, 2, width_ratios=[3, 1])

# 1. Jednoduchý čárový graf s pojmenovanými barvami
plt.subplot(gs[0, 0])
colors = ['royalblue', 'tomato', 'forestgreen', 'goldenrod', 'purple']
for i, color in enumerate(colors):
    plt.plot(x, y1 - 0.2*i, color=color, linewidth=2, label=color)

plt.title('Pojmenované barvy')
plt.xlabel('Osa X')
plt.ylabel('Osa Y')
plt.legend()
plt.grid(True, alpha=0.3)

# 2. Barevné spektrum pomocí RGB a RGBA
plt.subplot(gs[0, 1])
rgb_colors = [
    (1, 0, 0),          # Červená (RGB)
    (0, 0.8, 0),        # Zelená (RGB)
    (0, 0, 1),          # Modrá (RGB)
    (0.9, 0.7, 0.1),    # Oranžová (RGB)
    (0.5, 0, 0.5, 0.5)  # Fialová s průhledností (RGBA)
]

for i, color in enumerate(rgb_colors):
    plt.bar(i, i+1, color=color, edgecolor='black', width=0.7)
    
plt.title('RGB & RGBA barvy')
plt.xticks([])
plt.grid(axis='y', alpha=0.3)

# 3. Bodový graf s barevnou mapou
plt.subplot(gs[1, :])
N = 100
x = np.random.rand(N)
y = np.random.rand(N)
sizes = 1000 * np.random.rand(N)
colors = np.random.rand(N)

scatter = plt.scatter(x, y, 
                     s=sizes,           # Velikost bodů
                     c=colors,          # Hodnoty barev
                     cmap='viridis',    # Název barevné mapy
                     alpha=0.7,         # Průhlednost
                     edgecolors='black')# Barva okrajů

plt.title('Bodový graf s barevnou mapou')
plt.xlabel('Osa X')
plt.ylabel('Osa Y')
plt.colorbar(scatter, label='Hodnota barvy')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Porovnání různých barevných map
# Generování vzorových dat pro teplotní mapu
data = np.random.rand(20, 20)

# Vytvoření seznamu barevných map pro porovnání
colormaps = ['viridis', 'plasma', 'inferno', 'magma', 'cividis', 
             'Blues', 'Greens', 'Reds', 'YlOrBr', 'RdYlBu']

fig, axes = plt.subplots(2, 5, figsize=(15, 6))
axes = axes.flatten()

for i, cmap in enumerate(colormaps):
    im = axes[i].imshow(data, cmap=cmap)
    axes[i].set_title(cmap)
    axes[i].set_xticks([])
    axes[i].set_yticks([])
    plt.colorbar(im, ax=axes[i], fraction=0.046, pad=0.04)

plt.tight_layout()
plt.suptitle('Porovnání různých barevných map', fontsize=16, y=1.05)
plt.show()
```

Klíčové možnosti přizpůsobení barev:
- Pojmenované barvy: 'red', 'blue', 'green', 'tomato', atd.
- RGB n-tice: (r, g, b) s hodnotami od 0 do 1
- RGBA n-tice: (r, g, b, a) přidávající alfa průhlednost
- Hex kódy: '#FF0000' (červená), '#0000FF' (modrá), atd.
- Barevné mapy: 'viridis', 'plasma', 'Blues', 'RdYlBu', atd.
- `cmap`: Parametr pro určení barevné mapy
- `colorbar()`: Funkce pro přidání barevné stupnice ke grafu

## 9. Praktické příklady přizpůsobení

Aplikujme různé techniky přizpůsobení k vytvoření kompletních, publikovatelných grafů.

```python
# Příklad 1: Plně přizpůsobený čárový graf
plt.figure(figsize=(12, 8))

# Vytvoření grafu s vlastní stylizací
plt.plot(x, y1, 
         linewidth=3, 
         color='#1f77b4', 
         label='Sinus',
         linestyle='-',
         marker='o',
         markersize=8,
         markerfacecolor='white',
         markeredgewidth=2,
         markeredgecolor='#1f77b4',
         markevery=10)

plt.plot(x, y2, 
         linewidth=3, 
         color='#ff7f0e', 
         label='Kosinus',
         linestyle='--',
         marker='s',
         markersize=8,
         markerfacecolor='white',
         markeredgewidth=2,
         markeredgecolor='#ff7f0e',
         markevery=10)

# Nastavení barvy pozadí a mřížky
plt.grid(True, linestyle='--', alpha=0.7)
plt.gca().set_facecolor('#f8f9fa')

# Přidání a přizpůsobení titulku a popisků os
plt.title('Trigonometrické funkce', fontsize=20, fontweight='bold', pad=20)
plt.xlabel('Úhel (radiány)', fontsize=14, labelpad=10)
plt.ylabel('Hodnota', fontsize=14, labelpad=10)
```

## 10. Shrnutí

Efektivní přizpůsobení grafů je klíčovou dovedností pro vytváření jasných, informativních a vizuálně přitažlivých datových vizualizací. V tomto průvodci jsme pokryli:

1. **Titulky a popisky** poskytují zásadní kontext a význam vizualizacím
2. **Legendy** pomáhají divákům identifikovat různé datové řady
3. **Značky na osách a mřížkové čáry** usnadňují čtení konkrétních hodnot
4. **Textové anotace a šipky** mohou zvýraznit důležité poznatky nebo přehledy
5. **Styly čar a značek** pomáhají rozlišovat mezi více datovými řadami
6. **Barvy a barevné mapy** mohou kódovat dodatečné informace a zlepšit estetiku

Klíčové osvědčené postupy pro přizpůsobení grafů zahrnují:
- Zajistit, aby všechny textové prvky (titulky, popisky, legendy) byly jasné a vhodně veliké
- Používat konzistentní stylizaci napříč souvisejícími vizualizacemi
- Volit barvy, které jsou přístupné všem divákům, včetně těch s poruchami barevného vidění
- Přidávat anotace ke zvýraznění klíčových poznatků nebo neobvyklých prvků
- Udržovat přizpůsobení účelné spíše než ozdobné
- Používat vhodné styly čar a značek k odlišení datových řad
- Věnovat pozornost rozložení, zarovnání a celkové kompozici

Ovládnutím těchto technik přizpůsobení grafů v matplotlib můžete transformovat základní vizualizace na profesionální, publikovatelnou grafiku, která efektivně komunikuje vaše datové poznatky.
