## Úvod

Teorie percepčních barev v datové vizualizaci se zabývá pochopením toho, jak lidé vnímají a interpretují barvy, a využitím těchto znalostí k vytváření efektivnějších a přesnějších vizualizací. Barva není pouze estetickou volbou, ale mocným nástrojem, který ovlivňuje, jak diváci vnímají vztahy mezi daty, vzory a hodnoty. Při správném použití barvy zlepšují pochopení dat; při špatném použití mohou zavádět nebo zastírat důležité poznatky.

Tato příručka zkoumá vědecké poznatky o vnímání barev a poskytuje praktické techniky pro aplikaci teorie barev v datové vizualizaci v Pythonu.

## Barevné modely a prostory

Porozumění barevným modelům a prostorům je základem efektivní datové vizualizace. Různé barevné prostory reprezentují barvy různými způsoby, každý s konkrétními silnými a slabými stránkami.

### RGB a RGBA

RGB (červená, zelená, modrá) je aditivní barevný model běžně používaný v digitálních zobrazovacích zařízeních.

```python
# Demonstrace barevného modelu RGB
fig, ax = plt.subplots(figsize=(10, 6))

# Vytvoření gradientu RGB hodnot
n = 100
r = np.linspace(0, 1, n)
g = np.linspace(0, 1, n)
b = np.zeros(n)

# Vytvoření pole barev RGB
rgb_colors = np.vstack((r, g, b)).T.reshape(1, n, 3)

# Zobrazení RGB gradientu
ax.imshow(rgb_colors, aspect='auto')
ax.set_title('RGB barevný gradient (červená do žluté)', fontsize=14)
ax.set_xticks([])
ax.set_yticks([])

plt.show()
```

### HSL a HSV

HSL (odstín, sytost, světlost) a HSV (odstín, sytost, hodnota) reprezentují barvy více intuitivním způsobem z hlediska vnímání.

```python
# Demonstrace barevného prostoru HSV pomocí barevného kola
fig, ax = plt.subplots(figsize=(8, 8), subplot_kw=dict(polar=True))

# Vytvoření HSV barevného kola
n_angles = 100
angles = np.linspace(0, 2*np.pi, n_angles, endpoint=False)
radii = np.linspace(0.2, 0.9, 30)

# Mapování úhlů na odstín (0-1), poloměru na sytost (0-1) a hodnotu fixovanou na 1
hues = angles / (2*np.pi)
hsv_colors = []

for radius in radii:
    for hue in hues:
        hsv_colors.append([hue, radius, 1.0])

hsv_colors = np.array(hsv_colors)
rgb_colors = color.hsv2rgb(hsv_colors.reshape(len(radii), len(hues), 3))

# Vykreslení barevného kola
for i, radius in enumerate(radii):
    for j, angle in enumerate(angles):
        ax.scatter(angle, radius, color=rgb_colors[i, j], s=80)

ax.set_title('HSV barevné kolo', fontsize=14)
ax.set_xticks([])
ax.set_yticks([])
ax.grid(False)

plt.show()
```

### CIE LAB a percepční uniformita

CIE LAB je barevný prostor navržený tak, aby byl percepčně uniformní, což znamená, že stejné množství změny v barevné hodnotě vyvolá stejné množství vizuální změny.

```python
# Porovnání percepční uniformity mezi RGB a LAB
n = 256
gradient_rgb = np.linspace(0, 1, n)
rgb_colors = np.vstack([gradient_rgb, gradient_rgb, gradient_rgb]).T

# Konverze RGB na LAB
lab_converter = cspace_converter("sRGB1", "CAM02-UCS")
lab_colors = lab_converter(rgb_colors)

# Vytvoření obrázku pro porovnání
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 6))

# RGB gradient
ax1.imshow(rgb_colors.reshape(1, -1, 3), aspect='auto')
ax1.set_title('Lineární RGB gradient v odstínech šedé')
ax1.set_xticks([])
ax1.set_yticks([])

# LAB gradient (převedený zpět na RGB pro zobrazení)
rgb_back = cspace_converter("CAM02-UCS", "sRGB1")(lab_colors)
ax2.imshow(rgb_back.reshape(1, -1, 3), aspect='auto')
ax2.set_title('Percepčně uniformní gradient (LAB převedený na RGB)')
ax2.set_xticks([])
ax2.set_yticks([])

plt.tight_layout()
plt.show()
```

## Principy vnímání barev

Pochopení toho, jak lidé vnímají barvy, je klíčové pro vytváření efektivních vizualizací.

### Simultánní kontrast

Vnímání barvy je ovlivněno okolními barvami. To znamená, že stejná barva může vypadat odlišně v závislosti na jejím pozadí.

```python
# Demonstrace simultánního kontrastu
fig, ax = plt.subplots(figsize=(10, 6))

# Vytvoření dvou identických šedých čtverců na různých pozadích
background = np.zeros((100, 200, 3))
background[:, :100] = [0.1, 0.1, 0.1]  # Tmavé pozadí
background[:, 100:] = [0.9, 0.9, 0.9]  # Světlé pozadí

# Přidání identických šedých čtverců
square_color = [0.5, 0.5, 0.5]  # Střední šedá
square_size = 40
start_x = 30
start_y = 30

background[start_y:start_y+square_size, start_x:start_x+square_size] = square_color
background[start_y:start_y+square_size, start_x+100:start_x+100+square_size] = square_color

ax.imshow(background)
ax.set_title('Efekt simultánního kontrastu', fontsize=14)
ax.set_xticks([])
ax.set_yticks([])
ax.text(50, 90, 'Stejná šedá', color='white', ha='center')
ax.text(150, 90, 'Stejná šedá', color='black', ha='center')

plt.show()
```

### Zohlednění barvosleposti

Přibližně 8 % mužů a 0,5 % žen trpí barvoslepostí. Navrhování s ohledem na tuto skutečnost zajišťuje, že vaše vizualizace budou přístupné všem uživatelům.

```python
# Vytvoření simulace barvosleposti
from colorspacious import cspace_converter
from matplotlib.colors import LinearSegmentedColormap

# Generování duhové barevné mapy (často problematická pro barvoslepé)
rainbow_cm = plt.cm.rainbow
rainbow_colors = rainbow_cm(np.linspace(0, 1, 256))

# Vytvoření jednoduché teplotní mapy s duhovou barevnou mapou
data = np.random.rand(10, 10)
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# Původní vizualizace
axes[0, 0].imshow(data, cmap=rainbow_cm)
axes[0, 0].set_title('Originál (duhová barevná mapa)')
axes[0, 0].set_xticks([])
axes[0, 0].set_yticks([])

# Simulace různých typů barvosleposti
cvd_space = {"deuteranomaly": 50, "protanomaly": 50, "tritanomaly": 50}

for i, (name, severity) in enumerate([("Deuteranomálie", 80), ("Protanomálie", 80), ("Tritanomálie", 80)]):
    # Nastavení závažnosti barvosleposti
    cvd_space = {"name": name.lower(), "severity": severity}
    
    # Konverze barev
    cvd_converter = cspace_converter("sRGB1", {"name": "sRGB1+CVD", "cvd_type": cvd_space["name"], "severity": cvd_space["severity"]})
    cvd_colors = cvd_converter(rainbow_colors[:, :3])
    
    # Vytvoření nové barevné mapy
    cvd_cmap = ListedColormap(cvd_colors)
    
    # Vykreslení v příslušném podgrafu
    row, col = (i+1) // 2, (i+1) % 2
    axes[row, col].imshow(data, cmap=cvd_cmap)
    axes[row, col].set_title(f'Simulovaná {name}')
    axes[row, col].set_xticks([])
    axes[row, col].set_yticks([])

plt.tight_layout()
plt.show()
```

### Preattentivní zpracování

Určité vizuální vlastnosti jsou zpracovávány preattentivně, což znamená, že jsou zaznamenány okamžitě bez vědomého úsilí. Barva je jednou z těchto vlastností, ale nejlépe funguje v kombinaci s dalšími preattentivními atributy.

```python
# Demonstrace preattentivního zpracování s barvou
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# Generování náhodných datových bodů
n_points = 100
x = np.random.rand(n_points)
y = np.random.rand(n_points)
categories = np.random.choice(['A', 'B', 'C'], size=n_points)

# Bez efektivního barevného kódování (šedá škála)
axes[0].scatter(x, y, c='gray', s=50)
axes[0].set_title('Bez efektivního barevného kódování', fontsize=14)
axes[0].set_xticks([])
axes[0].set_yticks([])

# S barevným kódováním pro kategorie
color_map = {'A': 'blue', 'B': 'red', 'C': 'green'}
colors = [color_map[cat] for cat in categories]
axes[1].scatter(x, y, c=colors, s=50)
axes[1].set_title('S barevným kódováním pro kategorie', fontsize=14)
axes[1].set_xticks([])
axes[1].set_yticks([])

# Přidání legendy
from matplotlib.lines import Line2D
legend_elements = [Line2D([0], [0], marker='o', color='w', markerfacecolor=color, 
                         label=cat, markersize=10) for cat, color in color_map.items()]
axes[1].legend(handles=legend_elements, title="Kategorie")

plt.tight_layout()
plt.show()
```

## Vytváření efektivních barevných palet

Výběr správné barevné palety je zásadní pro efektivní datovou vizualizaci. Existují různé typy barevných palet vhodné pro různé typy dat.

## Sekvenční, divergentní a kategorické barevné mapy

Různé typy dat vyžadují různé přístupy k mapování barev.

### Sekvenční barevné mapy

Sekvenční barevné mapy používejte pro uspořádaná data, kde hodnoty postupují od nízkých k vysokým.

```python
# Demonstrace sekvenčních barevných map pomocí teplotní mapy
data = np.random.rand(10, 12)
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

sequential_maps = ['viridis', 'plasma', 'YlGnBu', 'Blues']

for i, cmap in enumerate(sequential_maps):
    row, col = i // 2, i % 2
    sns.heatmap(data, cmap=cmap, ax=axes[row, col], cbar=True)
    axes[row, col].set_title(f'Sekvenční: {cmap}', fontsize=14)
    axes[row, col].set_xticks([])
    axes[row, col].set_yticks([])

plt.tight_layout()
plt.show()
```

### Kategorické barevné mapy

Kategorické barevné mapy používejte pro neuspořádané, diskrétní kategorie dat.

```python
# Demonstrace kategorických barevných map pomocí sloupcového grafu
categories = ['Kategorie A', 'Kategorie B', 'Kategorie C', 'Kategorie D', 'Kategorie E', 
              'Kategorie F', 'Kategorie G', 'Kategorie H']
values = np.random.randint(10, 100, size=len(categories))

categorical_maps = ['Set1', 'Set3', 'tab10', 'Paired']

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

for i, cmap in enumerate(categorical_maps):
    row, col = i // 2, i % 2
    color_palette = plt.cm.get_cmap(cmap, len(categories))
    colors = [color_palette(i) for i in range(len(categories))]
    
    axes[row, col].bar(categories, values, color=colors)
    axes[row, col].set_title(f'Kategorická: {cmap}', fontsize=14)
    axes[row, col].set_xticklabels(categories, rotation=45, ha='right')
    
plt.tight_layout()
plt.show()
```

### Vestavěné barevné mapy v Matplotlib

```python
# Prozkoumání vestavěných barevných map v Matplotlib
from matplotlib import cm
from matplotlib.colors import ListedColormap, LinearSegmentedColormap

# Získání seznamu všech barevných map
cmaps = plt.colormaps()

# Kategorizace barevných map
sequential_cmaps = ['viridis', 'plasma', 'inferno', 'magma', 'cividis',
                    'Blues', 'BuGn', 'BuPu', 'GnBu', 'Greens', 'Greys',
                    'OrRd', 'Oranges', 'PuBu', 'PuBuGn', 'PuRd', 'Purples',
                    'RdPu', 'Reds', 'YlGn', 'YlGnBu', 'YlOrBr', 'YlOrRd']

diverging_cmaps = ['PiYG', 'PRGn', 'BrBG', 'PuOr', 'RdGy', 'RdBu',
                   'RdYlBu', 'RdYlGn', 'Spectral', 'coolwarm', 'bwr', 'seismic']

qualitative_cmaps = ['Pastel1', 'Pastel2', 'Paired', 'Accent', 'Dark2',
                     'Set1', 'Set2', 'Set3', 'tab10', 'tab20', 'tab20b', 'tab20c']

# Vykreslení výběru barevných map
def plot_colormap_category(category_name, cmaps_list, fig_height=1.5):
    n = len(cmaps_list)
    fig, axes = plt.subplots(n, 1, figsize=(12, n * fig_height))
    fig.subplots_adjust(top=0.95, bottom=0.01, left=0.2, right=0.99)
    
    axes[0].set_title(f'Barevné mapy typu {category_name}', fontsize=16, loc='left')
    
    for ax, name in zip(axes, cmaps_list):
        gradient = np.linspace(0, 1, 256).reshape(1, -1)
        ax.imshow(gradient, aspect='auto', cmap=plt.get_cmap(name))
        pos = list(ax.get_position().bounds)
        ax.set_axis_off()
        fig.text(pos[0] - 0.01, pos[1] + pos[3]/2, name, va='center', ha='right', fontsize=12)
        
    plt.show()

# Zobrazení příkladů z každé kategorie
plot_colormap_category('Sekvenční', sequential_cmaps[:10])
plot_colormap_category('Divergentní', diverging_cmaps[:6])
plot_colormap_category('Kvalitativní', qualitative_cmaps[:6])
```

### Pokročilé knihovny: ColorSpacious a ColorCET

```python
# Práce s colorspacious pro percepční uniformitu
import colorspacious as cs
import matplotlib.pyplot as plt
import numpy as np

# Vytvoření percepčně uniformního gradientu jasu
n = 256
gradient_linear = np.linspace(0, 1, n)
rgb_linear = np.vstack([gradient_linear, gradient_linear, gradient_linear]).T

# Konverze do prostoru JCh pro uniformní úpravu jasu
jch = cs.cspace_convert(rgb_linear, "sRGB1", "JCh")
jch[:, 0] = np.linspace(0, 100, n)  # Úprava J (jas) na percepčně lineární
rgb_uniform = cs.cspace_convert(jch, "JCh", "sRGB1")

# Oříznutí hodnot mimo rozsah
rgb_uniform = np.clip(rgb_uniform, 0, 1)

# Zobrazení porovnání
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 6))

ax1.imshow(rgb_linear.reshape(1, -1, 3), aspect='auto')
ax1.set_title('Standardní lineární RGB odstíny šedé', fontsize=14)
```

## Shrnutí

Teorie percepčních barev je kritickým aspektem vytváření efektivních a přístupných vizualizací dat. Pochopením toho, jak lidé vnímají barvy, a aplikací vědeckých principů můžeme vytvářet vizualizace, které přesně reprezentují data, zvýrazňují důležité vzory a komunikují poznatky všem divákům, včetně těch s poruchami barevného vidění.

Klíčové poznatky z této příručky:

1. **Barevné modely jsou důležité**: Různé barevné modely (RGB, HSL, LAB) slouží různým účelům, přičemž percepčně uniformní prostory jako LAB jsou obzvláště cenné pro vizualizaci dat.

2. **Přizpůsobte barvu typu dat**: 
   - Používejte sekvenční barevné mapy pro uspořádaná data (od nízkého k vysokému)
   - Používejte divergentní barevné mapy pro data s významným středovým bodem
   - Používejte kategorické barevné mapy pro neuspořádané, odlišné kategorie

3. **Zohledněte přístupnost**: Navrhujte s ohledem na barvoslepost pomocí palet přátelských k barvoslepým, vyhýbejte se problematickým barevným kombinacím (jako červená-zelená) a přidávejte redundantní kódování jako vzory nebo štítky.

4. **Vyhněte se duhovým barevným mapám**: Navzdory jejich popularitě mohou duhové barevné mapy zkreslit vnímání dat a vytvořit umělé hranice.

5. **Používejte percepční uniformitu**: Vybírejte barevné mapy, které reprezentují změny dat s proporcionálními percepčními změnami, abyste diváky neuváděli v omyl.

6. **Nástroje v Pythonu**: Knihovny jako Matplotlib, Seaborn, ColorCET a Colorspacious poskytují robustní nástroje pro implementaci principů teorie percepčního vnímání barev.

7. **Více kódovacích kanálů**: Pro komplexní data kombinujte barvu s jinými vizuálními atributy, jako jsou velikost, tvar nebo vzor, pro efektivnější komunikaci.

Aplikováním těchto principů teorie percepčních barev můžete vytvářet vizualizace, které nejen lépe vypadají, ale také efektivněji a přesněji komunikují příběh vašich dat všem divákům.
