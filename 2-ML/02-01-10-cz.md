## 1. Úvod do vyhodnocování modelů

Vyhodnocování modelů je kritickým krokem v pipeline strojového učení, který posuzuje, jak dobře váš model pracuje s daty. Správné vyhodnocení pomáhá určit, zda je model připraven pro produkční nasazení nebo potřebuje další vylepšení.

```python
# Import základních knihoven pro vyhodnocování modelů
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report
from sklearn.metrics import precision_score, recall_score, f1_score, roc_curve, auc
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import RandomForestClassifier

# Příprava jednoduchého datasetu pro ukázku
data = load_breast_cancer()
X = data.data
y = data.target

# Rozdělení datasetu
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)

# Vytvoření a trénování jednoduchého modelu
model = RandomForestClassifier(random_state=42)
model.fit(X_train, y_train)

# Vytvoření predikcí
y_pred = model.predict(X_test)
```

## 2. Pochopení přesnosti (accuracy)

Přesnost je jednou z nejjednodušších a nejintuitivnějších metrik vyhodnocení, reprezentující podíl správných predikcí ze všech provedených predikcí.

**Přesnost = (Správně pozitivní + Správně negativní) / Celkové predikce**

```python
# Výpočet přesnosti
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost: {accuracy:.4f}")

# Ruční výpočet přesnosti
correct_predictions = sum(y_test == y_pred)
total_predictions = len(y_test)
manual_accuracy = correct_predictions / total_predictions
print(f"Ručně vypočítaná přesnost: {manual_accuracy:.4f}")

# Ukázka omezení přesnosti
# Vytvoříme nevyvážený dataset
np.random.seed(42)
y_imbalanced = np.zeros(1000)  # 1000 negativních případů
y_imbalanced[0:50] = 1  # Pouze 50 pozitivních případů (5%)

# Jednoduchý klasifikátor, který vždy predikuje většinovou třídu
y_dummy_pred = np.zeros(1000)  # Vždy predikuje negativní

# Výpočet přesnosti pro jednoduchý klasifikátor
dummy_accuracy = sum(y_imbalanced == y_dummy_pred) / len(y_imbalanced)
print(f"Přesnost dummy klasifikátoru na nevyvážených datech: {dummy_accuracy:.4f}")
```

## 3. Vysvětlení matice záměn (confusion matrix)

Matice záměn poskytuje detailní rozpad výsledků predikcí, zobrazující správné a nesprávné klasifikace pro každou třídu.

```python
# Vytvoření matice záměn
cm = confusion_matrix(y_test, y_pred)
print("Matice záměn:")
print(cm)

# Vizualizace matice záměn
plt.figure(figsize=(8, 6))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
            xticklabels=['Maligní', 'Benigní'],
            yticklabels=['Maligní', 'Benigní'])
plt.xlabel('Predikovaný štítek')
plt.ylabel('Skutečný štítek')
plt.title('Matice záměn')
plt.show()

# Extrakce hodnot z matice záměn
tn, fp, fn, tp = confusion_matrix(y_test, y_pred).ravel()
print(f"Správně negativní (TN): {tn}")
print(f"Falešně pozitivní (FP): {fp}")
print(f"Falešně negativní (FN): {fn}")
print(f"Správně pozitivní (TP): {tp}")
```

Čtyři klíčové komponenty matice záměn jsou:
- **Správně pozitivní (True Positives, TP)**: Správně predikované pozitivní případy
- **Správně negativní (True Negatives, TN)**: Správně predikované negativní případy
- **Falešně pozitivní (False Positives, FP)**: Nesprávně predikované pozitivní případy (chyba I. typu)
- **Falešně negativní (False Negatives, FN)**: Nesprávně predikované negativní případy (chyba II. typu)

## 4. Více než přesnost: Preciznost, úplnost a F1 skóre

Pro komplexnější vyhodnocení, zejména u nevyvážených datasetů, potřebujeme metriky nad rámec přesnosti:

- **Preciznost (Precision)**: Podíl správných pozitivních predikcí ze všech pozitivních predikcí
  - Preciznost = TP / (TP + FP)
  
- **Úplnost (Recall, Senzitivita)**: Podíl správných pozitivních predikcí ze všech skutečně pozitivních případů
  - Úplnost = TP / (TP + FN)
  
- **F1 skóre**: Harmonický průměr preciznosti a úplnosti
  - F1 = 2 * (Preciznost * Úplnost) / (Preciznost + Úplnost)

```python
# Výpočet preciznosti, úplnosti a F1 skóre
precision = precision_score(y_test, y_pred)
recall = recall_score(y_test, y_pred)
f1 = f1_score(y_test, y_pred)

print(f"Preciznost: {precision:.4f}")
print(f"Úplnost: {recall:.4f}")
print(f"F1 skóre: {f1:.4f}")

# Použití classification_report pro souhrnný přehled
print("Klasifikační zpráva:")
print(classification_report(y_test, y_pred, target_names=['Maligní', 'Benigní']))

# Ruční výpočet
precision_manual = tp / (tp + fp)
recall_manual = tp / (tp + fn)
f1_manual = 2 * (precision_manual * recall_manual) / (precision_manual + recall_manual)
print(f"Ručně vypočítaná preciznost: {precision_manual:.4f}")
print(f"Ručně vypočítaná úplnost: {recall_manual:.4f}")
print(f"Ručně vypočítané F1: {f1_manual:.4f}")
```

## 5. ROC křivka a AUC

Křivka ROC (Receiver Operating Characteristic) a plocha pod křivkou (Area Under the Curve, AUC) jsou výkonné nástroje pro hodnocení výkonu klasifikátoru při různých nastaveních prahové hodnoty.

```python
# Získání predikovaných pravděpodobností pro pozitivní třídu
y_scores = model.predict_proba(X_test)[:, 1]

# Výpočet ROC křivky a AUC
fpr, tpr, thresholds = roc_curve(y_test, y_scores)
roc_auc = auc(fpr, tpr)

# Vykreslení ROC křivky
plt.figure(figsize=(8, 6))
plt.plot(fpr, tpr, color='blue', lw=2, label=f'ROC křivka (AUC = {roc_auc:.4f})')
plt.plot([0, 1], [0, 1], color='gray', linestyle='--')
plt.xlim([0.0, 1.0])
plt.ylim([0.0, 1.05])
plt.xlabel('Míra falešně pozitivních')
plt.ylabel('Míra správně pozitivních')
plt.title('ROC křivka (Receiver Operating Characteristic)')
plt.legend(loc="lower right")
plt.grid(True, alpha=0.3)
plt.show()

# Nalezení optimální prahové hodnoty
# Jeden přístup: Youdenův J index (maximalizace senzitivity + specificity - 1)
j_scores = tpr - fpr
optimal_idx = np.argmax(j_scores)
optimal_threshold = thresholds[optimal_idx]
print(f"Optimální prahová hodnota: {optimal_threshold:.4f}")
print(f"Při této prahové hodnotě, TPR: {tpr[optimal_idx]:.4f}, FPR: {fpr[optimal_idx]:.4f}")
```

## 6. Křížová validace pro vyhodnocení

Křížová validace poskytuje robustnější vyhodnocení testováním modelu na více datových rozděleních, čímž se snižuje vliv rozdělení dat.

```python
from sklearn.model_selection import cross_val_score, KFold

# K-násobná křížová validace
kf = KFold(n_splits=5, shuffle=True, random_state=42)
cv_scores = cross_val_score(model, X, y, cv=kf, scoring='accuracy')

print(f"Skóre křížové validace: {cv_scores}")
print(f"Průměrná přesnost CV: {cv_scores.mean():.4f}")
print(f"Směrodatná odchylka: {cv_scores.std():.4f}")

# Křížová validace s různými metrikami
metrics = ['accuracy', 'precision', 'recall', 'f1']
for metric in metrics:
    cv_scores = cross_val_score(model, X, y, cv=5, scoring=metric)
    print(f"Průměr {metric}: {cv_scores.mean():.4f}")

# Použití cross_validate pro více metrik najednou
from sklearn.model_selection import cross_validate

scoring = {'accuracy': 'accuracy', 'precision': 'precision', 
           'recall': 'recall', 'f1': 'f1'}
cv_results = cross_validate(model, X, y, cv=5, scoring=scoring)

for metric in scoring:
    print(f"Průměr {metric}: {cv_results[f'test_{metric}'].mean():.4f}")
```

## 7. Práce s nevyváženými datovými sadami

Při práci s nevyváženými datovými sadami mohou specializované metriky vyhodnocení poskytnout smysluplnější informace.

```python
from sklearn.metrics import balanced_accuracy_score, matthews_corrcoef
from sklearn.metrics import precision_recall_curve, average_precision_score
from imblearn.over_sampling import SMOTE
from imblearn.pipeline import Pipeline as ImbPipeline

# Vytvoření nevyváženého datasetu
from sklearn.datasets import make_classification
X_imb, y_imb = make_classification(n_samples=1000, n_classes=2, weights=[0.9, 0.1], 
                                  random_state=42)

# Rozdělení nevyváženého datasetu
X_train_imb, X_test_imb, y_train_imb, y_test_imb = train_test_split(
    X_imb, y_imb, test_size=0.25, random_state=42)

# Trénování a vyhodnocení modelu na nevyvážených datech
model_imb = RandomForestClassifier(random_state=42)
model_imb.fit(X_train_imb, y_train_imb)
y_pred_imb = model_imb.predict(X_test_imb)

# Běžná přesnost
print(f"Běžná přesnost: {accuracy_score(y_test_imb, y_pred_imb):.4f}")

# Vyvážená přesnost
print(f"Vyvážená přesnost: {balanced_accuracy_score(y_test_imb, y_pred_imb):.4f}")

# Matthewsův korelační koeficient (robustní vůči nevyváženosti)
print(f"Matthewsův korelační koeficient: {matthews_corrcoef(y_test_imb, y_pred_imb):.4f}")

# Rozložení tříd
print("Rozložení tříd:")
print(pd.Series(y_imb).value_counts(normalize=True))

# Precision-Recall křivka pro nevyvážená data
y_scores_imb = model_imb.predict_proba(X_test_imb)[:, 1]
precision_curve, recall_curve, _ = precision_recall_curve(y_test_imb, y_scores_imb)
ap = average_precision_score(y_test_imb, y_scores_imb)

plt.figure(figsize=(8, 6))
plt.plot(recall_curve, precision_curve, color='blue', lw=2, 
         label=f'Precision-Recall křivka (AP = {ap:.4f})')
plt.xlabel('Úplnost (Recall)')
plt.ylabel('Preciznost (Precision)')
plt.title('Precision-Recall křivka pro nevyvážená data')
plt.legend(loc="lower left")
plt.grid(True, alpha=0.3)
plt.show()
```

## 8. Případová studie: Vyhodnocení klasifikačního modelu

Pojďme vše spojit v komplexní případové studii pro vyhodnocení klasifikačního modelu na datasetu Iris.

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split, StratifiedKFold
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, classification_report
from sklearn.metrics import accuracy_score, precision_recall_fscore_support

# Načtení datasetu Iris
iris = load_iris()
X = iris.data
y = iris.target

# Převedení na problém binární klasifikace: Iris-Setosa vs. Ostatní
y_binary = (y == 0).astype(int)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(
    X, y_binary, test_size=0.3, random_state=42, stratify=y_binary)

# Trénování modelu
model = LogisticRegression(random_state=42)
model.fit(X_train, y_train)

# Vytvoření predikcí
y_pred = model.predict(X_test)
y_prob = model.predict_proba(X_test)[:, 1]

# 1. Základní přesnost
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost: {accuracy:.4f}")

# 2. Matice záměn
cm = confusion_matrix(y_test, y_pred)
plt.figure(figsize=(8, 6))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
           xticklabels=['Není Setosa', 'Setosa'],
           yticklabels=['Není Setosa', 'Setosa'])
plt.xlabel('Predikované')
plt.ylabel('Skutečné')
plt.title('Matice záměn')
plt.show()

# 3. Klasifikační zpráva
print("Klasifikační zpráva:")
print(classification_report(y_test, y_pred, target_names=['Není Setosa', 'Setosa']))

# 4. ROC křivka a AUC
fpr, tpr, _ = roc_curve(y_test, y_prob)
roc_auc = auc(fpr, tpr)

plt.figure(figsize=(8, 6))
plt.plot(fpr, tpr, color='blue', lw=2, label=f'ROC křivka (AUC = {roc_auc:.4f})')
plt.plot([0, 1], [0, 1], color='gray', linestyle='--')
plt.xlim([0.0, 1.0])
plt.ylim([0.0, 1.05])
plt.xlabel('Míra falešně pozitivních')
plt.ylabel('Míra správně pozitivních')
plt.title('ROC křivka')
plt.legend(loc="lower right")
plt.grid(True, alpha=0.3)
plt.show()

# 5. Křížová validace
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
cv_scores = cross_val_score(model, X, y_binary, cv=skf, scoring='accuracy')
print(f"Skóre přesnosti křížové validace: {cv_scores}")
print(f"Průměrná CV přesnost: {cv_scores.mean():.4f}")

# 6. Výpočet preciznosti, úplnosti a F1 pro každý fold
precision_list, recall_list, f1_list = [], [], []

for train_idx, test_idx in skf.split(X, y_binary):
    X_cv_train, X_cv_test = X[train_idx], X[test_idx]
    y_cv_train, y_cv_test = y_binary[train_idx], y_binary[test_idx]
    
    model.fit(X_cv_train, y_cv_train)
    y_cv_pred = model.predict(X_cv_test)
    
    precision, recall, f1, _ = precision_recall_fscore_support(y_cv_test, y_cv_pred, average='binary')
    precision_list.append(precision)
    recall_list.append(recall)
    f1_list.append(f1)

print(f"Křížová validace preciznost: {np.mean(precision_list):.4f}")
print(f"Křížová validace úplnost: {np.mean(recall_list):.4f}")
print(f"Křížová validace F1 skóre: {np.mean(f1_list):.4f}")
```

## 9. Shrnutí

Vyhodnocování modelů je zásadním krokem v pracovním postupu strojového učení, který určuje, zda je váš model připraven pro reálné aplikace. Klíčové body k zapamatování:

1. **Přesnost (Accuracy)** je jednoduchá a intuitivní metrika, ale může být zavádějící u nevyvážených datasetů.

2. **Matice záměn** poskytuje detailní rozpad správných a nesprávných predikcí napříč třídami.

3. **Preciznost, úplnost a F1 skóre** nabízejí propracovanější vyhodnocení, zejména pro nevyvážená data:
   - Preciznost se zaměřuje na přesnost pozitivních predikcí
   - Úplnost měří schopnost najít všechny pozitivní případy
   - F1 skóre vyvažuje preciznost a úplnost

4. **ROC křivky a AUC** hodnotí výkon modelu napříč různými nastaveními prahové hodnoty.

5. **Křížová validace** poskytuje robustnější vyhodnocení testováním na více rozdělení dat.

6. Pro **nevyvážené datasety** používejte specializované metriky jako vyvážená přesnost, Matthewsův korelační koeficient nebo precision-recall křivku.

7. Vždy vybírejte metriky vyhodnocení, které jsou v souladu s vaším konkrétním problémem a obchodními cíli.

8. Dobrý přístup k vyhodnocení kombinuje více metrik pro komplexní posouzení.
