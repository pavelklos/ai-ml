## 1. Úvod do paradigmat učení

Algoritmy strojového učení lze kategorizovat podle toho, jak se "učí" z dat. Dvě hlavní paradigmata učení jsou učení s učitelem a učení bez učitele. Pochopení rozdílů mezi těmito přístupy je zásadní pro výběr správného algoritmu pro váš konkrétní problém.

```python
# Běžné knihovny používané jak při učení s učitelem, tak při učení bez učitele
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn import datasets

# Nastavení stylu vykreslování
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_theme(style="whitegrid")

# Pro reprodukovatelnost
np.random.seed(42)
```

## 2. Učení s učitelem

Při učení s učitelem se algoritmy učí z označených dat. Každý trénovací příklad se skládá ze vstupních příznaků a odpovídajícího cílového výstupu. Cílem algoritmu je naučit se mapovací funkci, která dokáže předpovědět výstup pro nové, neviděné vstupy.

### Klíčové charakteristiky
- Vyžaduje označená data (vstupy mapované na známé výstupy)
- Cíl: Předpovědět výstupy pro nové vstupy
- Proces trénování zahrnuje minimalizaci chyb predikce
- Běžné úlohy: Klasifikace a regrese

```python
# Příklad datasetu pro učení s učitelem
from sklearn.datasets import load_iris

# Načtení datasetu Iris - klasický dataset pro učení s učitelem
iris = load_iris()
X = iris.data  # Příznaky: délka kališního lístku, šířka kališního lístku, délka okvětního lístku, šířka okvětního lístku
y = iris.target  # Cíl: druh rostliny (0, 1 nebo 2)

# Vytvoření DataFrame pro lepší vizualizaci
iris_df = pd.DataFrame(X, columns=iris.feature_names)
iris_df['species'] = [iris.target_names[i] for i in y]

print("Dataset pro učení s učitelem (Iris):")
print(iris_df.head())

# Vizualizace označených dat
plt.figure(figsize=(10, 6))
sns.scatterplot(x='sepal length (cm)', y='petal length (cm)', 
                hue='species', palette='viridis', data=iris_df)
plt.title('Dataset Iris - příklad učení s učitelem')
plt.show()
```

### Příklad klasifikace

```python
# Učení s učitelem - příklad klasifikace
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, classification_report

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření a trénování klasifikátoru
clf = DecisionTreeClassifier(random_state=42)
clf.fit(X_train, y_train)

# Vytvoření predikcí
y_pred = clf.predict(X_test)

# Vyhodnocení výkonu
print(f"Přesnost klasifikace: {accuracy_score(y_test, y_pred):.2f}")
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred, target_names=iris.target_names))
```

### Příklad regrese

```python
# Učení s učitelem - příklad regrese
from sklearn.datasets import load_diabetes
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# Načtení datasetu pro regresi
diabetes = load_diabetes()
X_diabetes = diabetes.data
y_diabetes = diabetes.target

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X_diabetes, y_diabetes, test_size=0.3, random_state=42)

# Vytvoření a trénování regresního modelu
regressor = LinearRegression()
regressor.fit(X_train, y_train)

# Vytvoření predikcí
y_pred = regressor.predict(X_test)

# Vyhodnocení výkonu
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print(f"Střední kvadratická chyba regrese: {mse:.2f}")
print(f"Koeficient determinace R²: {r2:.2f}")

# Vizualizace predikcí vs. skutečných hodnot
plt.figure(figsize=(8, 6))
plt.scatter(y_test, y_pred, alpha=0.7)
plt.xlabel('Skutečné hodnoty')
plt.ylabel('Predikované hodnoty')
plt.title('Regrese: Predikované vs. skutečné hodnoty')
plt.plot([min(y_test), max(y_test)], [min(y_test), max(y_test)], 'r--')
plt.show()
```

## 3. Učení bez učitele

Při učení bez učitele algoritmy pracují s neoznačenými daty a snaží se najít vzory, struktury nebo vztahy v datech bez předem definovaných výstupů.

### Klíčové charakteristiky
- Pracuje s neoznačenými daty (bez cílových výstupů)
- Cíl: Objevit skryté vzory nebo struktury
- Nemá "správné odpovědi" k porovnání
- Běžné úlohy: Shlukování, redukce dimenzionality, asociace

```python
# Příklad datasetu pro učení bez učitele
from sklearn.datasets import make_blobs

# Vygenerování syntetických dat se shluky
X_blobs, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.60, random_state=42)

# Vytvoření DataFrame
blobs_df = pd.DataFrame(X_blobs, columns=['Příznak 1', 'Příznak 2'])

print("Dataset pro učení bez učitele (syntetické shluky):")
print(blobs_df.head())

# Vizualizace neoznačených dat
plt.figure(figsize=(8, 6))
plt.scatter(X_blobs[:, 0], X_blobs[:, 1], alpha=0.7)
plt.title('Syntetický dataset - příklad učení bez učitele')
plt.xlabel('Příznak 1')
plt.ylabel('Příznak 2')
plt.show()
```

### Příklad shlukování

```python
# Učení bez učitele - příklad shlukování
from sklearn.cluster import KMeans

# Aplikace K-means shlukování
kmeans = KMeans(n_clusters=4, random_state=42)
cluster_labels = kmeans.fit_predict(X_blobs)

# Přidání označení shluků do DataFrame
blobs_df['Shluk'] = cluster_labels

# Vizualizace shluků
plt.figure(figsize=(10, 6))
sns.scatterplot(x='Příznak 1', y='Příznak 2', hue='Shluk', 
                palette='viridis', data=blobs_df)
plt.title('Výsledky K-means shlukování')
plt.scatter(kmeans.cluster_centers_[:, 0], kmeans.cluster_centers_[:, 1], 
            s=200, marker='X', c='red', label='Centroidy')
plt.legend()
plt.show()
```

### Příklad redukce dimenzionality

```python
# Učení bez učitele - příklad redukce dimenzionality
from sklearn.decomposition import PCA

# Aplikace PCA na dataset Iris
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

# Vytvoření DataFrame s hlavními komponentami
pca_df = pd.DataFrame(data=X_pca, columns=['PC1', 'PC2'])
pca_df['species'] = [iris.target_names[i] for i in y]

# Vizualizace redukovaných dat
plt.figure(figsize=(10, 6))
sns.scatterplot(x='PC1', y='PC2', hue='species', palette='viridis', data=pca_df)
plt.title('PCA: Redukce dimenzionality datasetu Iris')
plt.xlabel(f'Hlavní komponenta 1 ({pca.explained_variance_ratio_[0]:.2%} rozptylu)')
plt.ylabel(f'Hlavní komponenta 2 ({pca.explained_variance_ratio_[1]:.2%} rozptylu)')
plt.show()

print(f"Celkový vysvětlený rozptyl 2 komponentami: {sum(pca.explained_variance_ratio_):.2%}")
```

## 4. Klíčové rozdíly a kritéria výběru

Pochopení toho, kdy použít učení s učitelem versus učení bez učitele, je zásadní pro efektivní aplikaci strojového učení.

| Aspekt | Učení s učitelem | Učení bez učitele |
|--------|---------------------|------------------------|
| **Požadavky na data** | Označená data (vstupy a výstupy) | Neoznačená data (pouze vstupy) |
| **Cíl** | Předpovědět výsledky | Objevit vzory |
| **Běžné algoritmy** | Lineární/Logistická regrese, Rozhodovací stromy, Neuronové sítě, SVM | K-means, Hierarchické shlukování, PCA, Autoenkodéry |
| **Aplikace** | Detekce spamu, predikce cen, diagnostika nemocí | Segmentace zákazníků, detekce anomálií, extrakce příznaků |
| **Vyhodnocení** | Přímé metriky (přesnost, precize, MSE) | Nepřímé nebo interní metriky (silhouette skóre, inertia) |

## 5. Praktické příklady v Pythonu

Podívejme se na praktický příklad, kdy aplikujeme oba postupy - učení s učitelem i bez učitele - na stejný dataset.

```python
# Práce s reálným datasetem
from sklearn.datasets import fetch_california_housing
from sklearn.preprocessing import StandardScaler

# Načtení datasetu Kalifornských nemovitostí
housing = fetch_california_housing()
X_housing = pd.DataFrame(housing.data, columns=housing.feature_names)
y_housing = housing.target

print("Dataset Kalifornských nemovitostí:")
print(X_housing.head())
print(f"\nRozměry: {X_housing.shape}")

# Standardizace příznaků
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_housing)
X_scaled_df = pd.DataFrame(X_scaled, columns=housing.feature_names)

# 1. Učení bez učitele: Shlukování oblastí
kmeans_housing = KMeans(n_clusters=5, random_state=42)
clusters = kmeans_housing.fit_predict(X_scaled)
X_scaled_df['Shluk'] = clusters

# Vizualizace shluků v 2D prostoru pomocí PCA
pca_housing = PCA(n_components=2)
X_pca_housing = pca_housing.fit_transform(X_scaled)
pca_housing_df = pd.DataFrame(X_pca_housing, columns=['PC1', 'PC2'])
pca_housing_df['Shluk'] = clusters

plt.figure(figsize=(10, 6))
sns.scatterplot(x='PC1', y='PC2', hue='Shluk', data=pca_housing_df, palette='viridis')
plt.title('Data nemovitostí: Vizualizace shlukování pomocí PCA')
plt.show()

# 2. Učení s učitelem: Predikce cen domů
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y_housing, test_size=0.3, random_state=42)

# Použití Random Forest regresoru
from sklearn.ensemble import RandomForestRegressor
rf = RandomForestRegressor(n_estimators=100, random_state=42)
rf.fit(X_train, y_train)
y_pred_rf = rf.predict(X_test)

rf_mse = mean_squared_error(y_test, y_pred_rf)
rf_r2 = r2_score(y_test, y_pred_rf)

print("\nVýsledky učení s učitelem:")
print(f"Mean Squared Error náhodného lesa: {rf_mse:.4f}")
print(f"Koeficient determinace R² náhodného lesa: {rf_r2:.4f}")
```

## 6. Hybridní a polo-řízené přístupy

V praxi často používáme kombinace technik učení s učitelem a bez učitele nebo polo-řízené učení, když máme omezené množství označených dat.

```python
# Demonstrace konceptu polo-řízeného učení
from sklearn.semi_supervised import LabelSpreading

# Vytvoření syntetického datasetu
from sklearn.datasets import make_moons
X_moons, y_moons = make_moons(n_samples=300, noise=0.3, random_state=42)

# Simulace scénáře, kdy je označeno pouze 10 % dat
mask = np.zeros(len(X_moons), dtype=bool)
indices = np.random.choice(range(len(X_moons)), size=30, replace=False)
mask[indices] = True

# Vytvoření označení s -1 pro neoznačené body
y_partial = np.full(shape=len(X_moons), fill_value=-1)
y_partial[mask] = y_moons[mask]

# Vizualizace částečně označených dat
plt.figure(figsize=(10, 6))
plt.scatter(X_moons[~mask, 0], X_moons[~mask, 1], marker='.', c='gray', alpha=0.4, label='Neoznačené')
plt.scatter(X_moons[mask, 0], X_moons[mask, 1], marker='o', c=y_moons[mask], cmap='viridis', label='Označené')
plt.title('Polo-řízené učení: Částečně označený dataset')
plt.legend()
plt.show()

# Aplikace Label Spreading (algoritmus polo-řízeného učení)
model = LabelSpreading(kernel='knn', n_neighbors=10)
model.fit(X_moons, y_partial)
y_pred_semi = model.predict(X_moons)

# Vizualizace výsledků
plt.figure(figsize=(10, 6))
plt.scatter(X_moons[:, 0], X_moons[:, 1], marker='o', c=y_pred_semi, cmap='viridis', alpha=0.8)
plt.scatter(X_moons[mask, 0], X_moons[mask, 1], marker='*', s=100, c=y_moons[mask], 
            edgecolors='k', cmap='viridis', label='Původní označené body')
plt.title('Výsledky polo-řízeného učení')
plt.legend()
plt.show()

# Výpočet přesnosti na původně neoznačených bodech
accuracy_unlabeled = accuracy_score(y_moons[~mask], y_pred_semi[~mask])
print(f"Přesnost na původně neoznačených datech: {accuracy_unlabeled:.4f}")
```

## 7. Metody vyhodnocování

Vyhodnocení modelů učení s učitelem a bez učitele vyžaduje různé přístupy.

```python
# Metody vyhodnocení pro učení s učitelem
from sklearn.metrics import confusion_matrix, precision_recall_fscore_support

# Vyhodnocení klasifikace
def evaluate_classifier(y_true, y_pred, class_names=None):
    # Přesnost
    accuracy = accuracy_score(y_true, y_pred)
    
    # Matice záměn
    cm = confusion_matrix(y_true, y_pred)
    
    # Precision, recall, F1-score
    precision, recall, f1, _ = precision_recall_fscore_support(y_true, y_pred, average='weighted')
    
    print(f"Přesnost: {accuracy:.4f}")
    print(f"Precize: {precision:.4f}")
    print(f"Recall: {recall:.4f}")
    print(f"F1 skóre: {f1:.4f}")
    
    # Vizualizace matice záměn
    plt.figure(figsize=(8, 6))
    sns.heatmap(cm, annot=True, fmt="d", cmap="Blues", 
                xticklabels=class_names, yticklabels=class_names)
    plt.xlabel("Predikované třídy")
    plt.ylabel("Skutečné třídy")
    plt.title("Matice záměn")
    plt.show()

# Vyhodnocení regrese
def evaluate_regressor(y_true, y_pred):
    mse = mean_squared_error(y_true, y_pred)
    rmse = np.sqrt(mse)
    r2 = r2_score(y_true, y_pred)
    
    print(f"Střední kvadratická chyba: {mse:.4f}")
    print(f"Odmocnina střední kvadratické chyby: {rmse:.4f}")
    print(f"Koeficient determinace R²: {r2:.4f}")
    
    # Vykreslení skutečných vs. predikovaných hodnot
    plt.figure(figsize=(8, 6))
    plt.scatter(y_true, y_pred, alpha=0.6)
    plt.plot([y_true.min(), y_true.max()], [y_true.min(), y_true.max()], 'r--')
    plt.xlabel("Skutečné hodnoty")
    plt.ylabel("Predikované hodnoty")
    plt.title("Skutečné vs. predikované hodnoty")
    plt.show()

# Metody vyhodnocení pro učení bez učitele
from sklearn.metrics import silhouette_score, davies_bouldin_score

    davies_bouldin = davies_bouldin_score(X, labels)
    
    print(f"Silhouette skóre: {silhouette:.4f}")
    print(f"Davies-Bouldin index: {davies_bouldin:.4f}")
    
    # Poznámka: Pro silhouette skóre je lepší vyšší hodnota (rozsah: -1 až 1)
    # Pro Davies-Bouldin index je lepší nižší hodnota (minimum je 0)
```

## 8. Běžné výzvy

Každý přístup k učení přináší vlastní sadu výzev a problémů.

### Výzvy učení s učitelem
- Vyžaduje dostatečné množství označených dat, což může být nákladné nebo časově náročné
- Riziko přeučení, zvláště u složitých modelů a omezených dat
- Výběr a inženýrství příznaků jsou klíčové pro dobrý výkon
- Generalizace modelu na nová, neviděná data

### Výzvy učení bez učitele
- Obtížnost vyhodnocení výsledků (neexistuje referenční pravdivé označení)
- Určení optimálního počtu shluků nebo komponent
- Interpretace významu objevených vzorů
- Citlivost na škálování příznaků a odlehlé hodnoty

```python
# Demonstrace přeučení v učení s učitelem
from sklearn.datasets import make_regression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import Pipeline

# Vytvoření jednoduchého regresního datasetu
X_reg, y_reg = make_regression(n_samples=100, n_features=1, noise=20, random_state=42)
X_reg_train, X_reg_test, y_reg_train, y_reg_test = train_test_split(X_reg, y_reg, test_size=0.3)

# Vytvoření modelů s různou složitostí
degrees = [1, 5, 15]  # Stupně polynomu
plt.figure(figsize=(15, 5))

for i, degree in enumerate(degrees):
    # Vytvoření polynomu regresního modelu
    model = Pipeline([
        ("poly", PolynomialFeatures(degree=degree)),
        ("linear", LinearRegression())
    ])
    model.fit(X_reg_train, y_reg_train)
    
    # Generování predikcí pro vizualizaci
    X_plot = np.linspace(X_reg.min(), X_reg.max(), 100).reshape(-1, 1)
    y_plot = model.predict(X_plot)
    
    # Výpočet skóre pro trénovací a testovací data
    train_score = model.score(X_reg_train, y_reg_train)
    test_score = model.score(X_reg_test, y_reg_test)
    
    # Vizualizace
    plt.subplot(1, 3, i+1)
    plt.scatter(X_reg_train, y_reg_train, color='blue', alpha=0.7, label='Trénovací data')
    plt.scatter(X_reg_test, y_reg_test, color='red', alpha=0.7, label='Testovací data')
    plt.plot(X_plot, y_plot, color='green', label=f'Polynom stupně {degree}')
    plt.title(f"Polynom stupně {degree}\nTrénink R²: {train_score:.2f}, Test R²: {test_score:.2f}")
    plt.legend()

plt.tight_layout()
plt.show()
```

## 9. Využití v reálném světě

### Aplikace učení s učitelem
- Filtrování spamu v e-mailech
- Skóring úvěrů a schvalování půjček
- Lékařská diagnostika
- Rozpoznávání obrazu
- Rozpoznávání řeči
- Predikce cen akcií

### Aplikace učení bez učitele
- Segmentace zákazníků
- Detekce anomálií (detekce podvodů, síťové intruse)
- Doporučovací systémy
- Modelování témat v textových dokumentech
- Komprese obrazu
- Analýza sociálních sítí

```python
# Jednoduchý příklad: Klasifikace spamu v e-mailech (učení s učitelem)
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline

# Vzorová e-mailová data
emails = [
    "Zbohatněte rychle! Garantované výnosy z investic.",
    "Schůzka naplánována na zítřek v 10:00.",
    "Viagra na prodej, výhodné ceny!",
    "Prosím, prohlédněte si čtvrtletní zprávu.",
    "Vyhrajte dovolenou zdarma! Klikněte zde!",
    "Termín projektu prodloužen do pátku.",
    "Zhubněte rychle pomocí tohoto podivného triku!",
    "Telekonference je přeplánována na 14:00."
]

labels = [1, 0, 1, 0, 1, 0, 1, 0]  # 1 pro spam, 0 pro legitimní

# Vytvoření pipeline pro klasifikaci textu
text_clf = Pipeline([
    ('vectorizer', CountVectorizer()),
    ('classifier', MultinomialNB())
])

# Trénování modelu
text_clf.fit(emails, labels)

# Test na nových e-mailech
new_emails = [
    "Peníze zdarma pro vás!",
    "Schůzka týmu zítra v místnosti 305."
]

predictions = text_clf.predict(new_emails)
for email, prediction in zip(new_emails, predictions):
    print(f"E-mail: '{email}'")
```

## 10. Shrnutí

Pochopení rozdílů mezi učením s učitelem a učením bez učitele je klíčové pro efektivní aplikaci strojového učení:

- **Učení s učitelem** pracuje s označenými daty k predikci výsledků. Zahrnuje úlohy klasifikace a regrese, kde trénujeme modely mapování vstupů na známé výstupy. Vyhodnocení je přímočaré, protože máme referenční pravdivá označení, se kterými lze porovnávat.

- **Učení bez učitele** pracuje s neoznačenými daty k objevování vzorů a struktur. Zahrnuje shlukování a redukci dimenzionality, kde nacházíme přirozená seskupení nebo reprezentace bez předdefinovaných výstupů. Vyhodnocení je náročnější a často subjektivní.

- **Výběr mezi nimi** závisí na vašich datech (označená nebo neoznačená), vašem cíli (predikce nebo objevování vzorů) a dostupných zdrojích.

- **Hybridní přístupy** jako polo-řízené učení kombinují oba přístupy k využití omezeného množství označených dat s většími neoznačenými datasety.

Pochopení těchto základních paradigmat učení poskytuje základ pro pokročilejší koncepty a aplikace strojového učení.
