## Paradigmata strojového učení
Algoritmy strojového učení mohou být kategorizovány podle způsobu, jakým se učí z dat:

1. **Supervised learning (učení s učitelem)** - algoritmy se učí z označených dat, kde jsou známy požadované výstupy
2. **Unsupervised learning (učení bez učitele)** - algoritmy se učí z neoznačených dat, objevují vzory a vztahy bez vnějšího vedení
3. **Semi-supervised learning** - kombinuje označená i neoznačená data
4. **Reinforcement learning** - učí se prostřednictvím interakce s prostředím a zpětné vazby

## Supervised Learning (učení s učitelem)

### Klíčové charakteristiky
- **Trénovací data jsou označená**: Každý příklad má vstupní atributy a správný výstup
- **Přímá zpětná vazba**: Algoritmus může porovnávat své predikce se správnými odpověďmi
- **Zaměření na výstup**: Učí se předpovídat konkrétní výstupy na základě vstupních vzorů

### Typické algoritmy
- **Klasifikační algoritmy**: Logistická regrese, SVM, rozhodovací stromy, Random Forest, KNN, neuronové sítě
- **Regresní algoritmy**: Lineární regrese, Ridge regrese, Lasso regrese, regresní stromy

### Evaluační metriky
- **Klasifikace**: Přesnost (accuracy), precize, recall, F1 skóre, ROC-AUC
- **Regrese**: Střední kvadratická chyba (MSE), R-squared, střední absolutní chyba (MAE)

## Unsupervised Learning (učení bez učitele)

### Klíčové charakteristiky
- **Trénovací data jsou neoznačená**: K dispozici jsou pouze vstupní data bez odpovídajících výstupů
- **Žádná zpětná vazba**: Algoritmus nemá externí vodítko, zda nachází správné vzory
- **Zaměření na strukturu**: Soustředí se na hledání inherentních struktur v datech

### Typické algoritmy
- **Clustering (shlukování)**: K-Means, hierarchické shlukování, DBSCAN, Gaussian Mixture Models
- **Redukce dimenzí**: PCA, t-SNE, autoenkodéry, UMAP
- **Učení asociačních pravidel**: Apriori algoritmus, Eclat, FP-Growth

### Přístupy k hodnocení
- Silhouette skóre
- Calinski-Harabasz index
- Davies-Bouldin index
- Vizuální inspekce shluků

## Reálné aplikace

### Supervised Learning
- **Zdravotnictví**: Diagnostika nemocí, předpověď rizik opětovného přijetí, predikce reakce na léky
- **Finance**: Úvěrové skóre, detekce podvodů, předpověď cen akcií
- **Maloobchod**: Předpověď odchodu zákazníků, předpověď prodejů, personalizovaný marketing
- **Doprava**: Předpověď dopravy, autonomní řízení, odhad doby doručení

### Unsupervised Learning
- **Marketing**: Segmentace zákazníků, doporučovací systémy, analýza nákupního košíku
- **Kybernetická bezpečnost**: Detekce anomálií, profilování chování uživatelů
- **Biologie a medicína**: Shlukování genové exprese, segmentace medicínských obrazů
- **Analýza dokumentů**: Modelování témat, shlukování zpráv, doporučování obsahu

## Kdy použít který přístup

### Supervised Learning je vhodný když:
1. Máte označená data
2. Máte konkrétní úkol predikce
3. Potřebujete přesné výstupy
4. Váš problém je dobře definovaný
5. Máte zdroje pro označování dat

### Unsupervised Learning je vhodný když:
1. Nemáte označená data
2. Zkoumáte neznámé vzory
3. Potřebujete redukci dimenzí
4. Chcete identifikovat segmenty zákazníků
5. Hledáte anomálie

### Hybridní přístupy:
- Použití unsupervised learning pro objevení vzorů a vytvoření příznaků
- Následné použití supervised learning pro tvorbu predikcí s těmito novými příznaky

## Závěr

V tomto notebooku jsme prozkoumali základní rozdíly mezi supervised a unsupervised learningem:

- **Supervised learning** vyžaduje označená data a zaměřuje se na predikci konkrétních výsledků. Je ideální pro klasifikační a regresní problémy, kde je cílová proměnná známá.

- **Unsupervised learning** pracuje s neoznačenými daty a objevuje skryté vzory a struktury. Je vhodný pro shlukování, redukci dimenzí a detekci anomálií.

Demonstrovali jsme oba přístupy na datové sadě Iris:
- Pomocí supervised learning jsme vytvořili klasifikační modely s vysokou přesností pro predikci druhů květin.
- Pomocí unsupervised learning jsme objevili přirozené skupiny v datech, které z velké části odpovídaly skutečným druhům.

Volba mezi supervised a unsupervised learningem závisí na dostupnosti dat, definici problému a konečných cílech. V mnoha reálných aplikacích může kombinace obou přístupů přinést nejlepší výsledky.
