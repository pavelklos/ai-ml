## 1. Introduction to Clustering and K-means

Clustering is an unsupervised learning technique that groups similar data points together based on their characteristics. Unlike supervised learning, clustering doesn't rely on labeled outputs for training. K-means is one of the most popular clustering algorithms due to its simplicity and efficiency.

## 2. The K-means Algorithm

K-means is an iterative algorithm that partitions data into K distinct clusters by minimizing the sum of squared distances between data points and their assigned cluster centers.

The basic steps of the algorithm are:
1. Initialize K cluster centers (centroids) randomly
2. Assign each data point to the nearest centroid
3. Recalculate centroids as the mean of all points assigned to that cluster
4. Repeat steps 2-3 until convergence or maximum iterations

```python
# Simple implementation of K-means from scratch
def simple_kmeans(X, k, max_iters=100, tol=1e-4):
    # Randomly initialize centroids
    centroids = X[np.random.choice(X.shape[0], k, replace=False)]
    
    for _ in range(max_iters):
        # Assign points to nearest centroid
        distances = np.array([np.linalg.norm(X - centroid, axis=1) for centroid in centroids])
        labels = np.argmin(distances, axis=0)
        
        # Update centroids
        new_centroids = np.array([X[labels == i].mean(axis=0) for i in range(k)])
        
        # Check for convergence
        if np.all(np.linalg.norm(new_centroids - centroids, axis=1) < tol):
            break
            
        centroids = new_centroids
    
    return labels, centroids

# Generate sample data with 3 clusters
X, _ = make_blobs(n_samples=300, centers=3, cluster_std=0.60, random_state=0)

# Apply our simple K-means
labels, centroids = simple_kmeans(X, k=3)

# Plot results
plt.figure(figsize=(10, 6))
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis', alpha=0.7)
plt.scatter(centroids[:, 0], centroids[:, 1], c='red', s=200, marker='X')
plt.title('K-means Clustering (Simple Implementation)')
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.show()
```

## 3. Implementing K-means with Scikit-learn

Scikit-learn provides an efficient implementation of K-means with many built-in features:

```python
# Generate more complex sample data
X, y_true = make_blobs(n_samples=500, centers=4,
```

## 4. Choosing the Optimal Number of Clusters

One of the challenges in K-means is determining the optimal number of clusters. Two common methods are:

### The Elbow Method
This method looks at the percentage of variance explained as a function of the number of clusters. The "elbow" or inflection point in the curve suggests the optimal number.

```python
# Implement the elbow method
def plot_elbow_method(X, max_k=10):
    inertias = []
    for k in range(1, max_k+1):
        kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
        kmeans.fit(X)
        inertias.append(kmeans.inertia_)
    
    plt.figure(figsize=(10, 6))
    plt.plot(range(1, max_k+1), inertias, 'o-', color='blue')
    plt.xlabel('Number of Clusters (k)')
    plt.ylabel('Inertia (Sum of Squared Distances)')
    plt.title('Elbow Method for Optimal k')
    plt.grid(True, alpha=0.3)
    plt.show()

# Apply the elbow method
plot_elbow_method(X_scaled, max_k=10)
```

### Silhouette Analysis
The silhouette coefficient measures how similar a point is to its own cluster compared to other clusters.

```python
# Silhouette analysis
def plot_silhouette_scores(X, max_k=10):
    silhouette_scores = []
    for k in range(2, max_k+1):  # Silhouette requires at least 2 clusters
        kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
        labels = kmeans.fit_predict(X)
        score = silhouette_score(X, labels)
        silhouette_scores.append(score)
    
    plt.figure(figsize=(10, 6))
    plt.plot(range(2, max_k+1), silhouette_scores, 'o-', color='green')
    plt.xlabel('Number of Clusters (k)')
    plt.ylabel('Silhouette Score')
    plt.title('Silhouette Analysis for Optimal k')
    plt.grid(True, alpha=0.3)
    plt.show()

# Apply silhouette analysis
plot_silhouette_scores(X_scaled, max_k=10)
```

## 6. K-means Variations and Advanced Techniques

Several variations and extensions to K-means have been developed to address its limitations:

### K-means++
This is a smarter initialization method that chooses initial centroids that are distant from each other:

```python
# K-means++ is the default initialization in sklearn
kmeans_pp = KMeans(n_clusters=4, init='k-means++', random_state=42)
y_pred_pp = kmeans_pp.fit_predict(X_scaled)

# Compare with random initialization
kmeans_random = KMeans(n_clusters=4, init='random', random_state=42)
y_pred_random = kmeans_random.fit_predict(X_scaled)

print("K-means++ inertia:", kmeans_pp.inertia_)
print("Random init inertia:", kmeans_random.inertia_)
```

### Mini-Batch K-means
For large datasets, Mini-Batch K-means uses small random batches of data to update centroids, which is faster:

```python
from sklearn.cluster import MiniBatchKMeans

# Generate larger dataset
X_large, _ = make_blobs(n_samples=10000, centers=5, random_state=42)
X_large_scaled = StandardScaler().fit_transform(X_large)

# Compare execution time
import time

# Standard K-means
start_time = time.time()
kmeans = KMeans(n_clusters=5, random_state=42).fit(X_large_scaled)
std_time = time.time() - start_time
print(f"Standard K-means time: {std_time:.4f} seconds")

# Mini-batch K-means
start_time = time.time()
mbkmeans = MiniBatchKMeans(n_clusters=5, random_state=42, batch_size=256).fit(X_large_scaled)
mb_time = time.time() - start_time
print(f"Mini-Batch K-means time: {mb_time:.4f} seconds")
print(f"Speed improvement: {std_time/mb_time:.2f}x faster")
```

## 7. Evaluating Clustering Quality

Evaluating unsupervised learning algorithms like K-means can be challenging. Here are some metrics:

### Internal Evaluation
These metrics assess the clustering without external labels:

```python
# Inertia (sum of squared distances to centroids)
kmeans = KMeans(n_clusters=3, random_state=42).fit(X_iris_scaled)
print("Inertia:", kmeans.inertia_)

# Silhouette Score
silhouette_avg = silhouette_score(X_iris_scaled, kmeans.labels_)
print("Silhouette Score:", silhouette_avg)

# Visualize silhouette values for individual samples
from sklearn.metrics import silhouette_samples

# Compute silhouette scores for each sample
silhouette_vals = silhouette_samples(X_iris_scaled, kmeans.labels_)

plt.figure(figsize=(10, 6))
y_ticks = []
y_lower, y_upper = 0, 0

for i, cluster in enumerate(range(3)):
    # Aggregate silhouette scores for samples in cluster i
    cluster_silhouette_vals = silhouette_vals[kmeans.labels_ == cluster]
    cluster_silhouette_vals.sort()
    y_upper += len(cluster_silhouette_vals)
    
    color = plt.cm.viridis(i / 3)
    plt.barh(range(y_lower, y_upper), cluster_silhouette_vals, height=1.0, 
            edgecolor='none', color=color)
    
    y_ticks.append((y_lower + y_upper) / 2)
    y_lower += len(cluster_silhouette_vals)

plt.axvline(silhouette_avg, color="red", linestyle="--")
plt.yticks(y_ticks, [f"Cluster {i+1}" for i in range(3)])
plt.xlabel("Silhouette coefficient")
plt.ylabel("Cluster")
plt.title(f"Silhouette Plot (Avg Score: {silhouette_avg:.3f})")
plt.show()
```

### External Evaluation
If you have ground truth labels, you can use metrics like:

```python
from sklearn.metrics import adjusted_rand_score, normalized_mutual_info_score

# Adjusted Rand Index
ari = adjusted_rand_score(y_iris, kmeans.labels_)
print("Adjusted Rand Index:", ari)

# Normalized Mutual Information
nmi = normalized_mutual_info_score(y_iris, kmeans.labels_)
print("Normalized Mutual Information:", nmi)
```

## 8. Limitations and Considerations

K-means has several limitations to be aware of:

### 1. Assumes spherical clusters of similar size and density

```python
# Create data with non-spherical clusters
X_moons, _ = make_moons(n_samples=200, noise=0.05, random_state=42)

# Apply K-means
kmeans_moons = KMeans(n_clusters=2, random_state=42)
y_moons_pred = kmeans_moons.fit_predict(X_moons)

# Plot results
plt.figure(figsize=(10, 6))
plt.scatter(X_moons[:, 0], X_moons[:, 1], c=y_moons_pred, cmap='viridis', alpha=0.7)
plt.scatter(kmeans_moons.cluster_centers_[:, 0], kmeans_moons.cluster_centers_[:, 1], 
           c='red', s=200, alpha=0.75, marker='X')
plt.title('K-means with Non-Spherical Clusters')
plt.show()

# Try DBSCAN which can handle non-spherical clusters
from sklearn.cluster import DBSCAN
dbscan = DBSCAN(eps=0.2, min_samples=5)
y_dbscan = dbscan.fit_predict(X_moons)

plt.figure(figsize=(10, 6))
plt.scatter(X_moons[:, 0], X_moons[:, 1], c=y_dbscan, cmap='viridis', alpha=0.7)
plt.title('DBSCAN with Non-Spherical Clusters')
plt.show()
```

### 2. Sensitive to initialization and outliers

```python
# Demonstrate sensitivity to initialization
def run_kmeans_multiple_times(X, n_clusters=3, n_runs=10):
    inertias = []
    for i in range(n_runs):
        kmeans = KMeans(n_clusters=n_clusters, init='random', random_state=i)
        kmeans.fit(X)
        inertias.append(kmeans.inertia_)
    return inertias

# Run K-means multiple times
inertias = run_kmeans_multiple_times(X_iris_scaled)

plt.figure(figsize=(10, 6))
plt.bar(range(1, len(inertias) + 1), inertias)
plt.xlabel('Run')
plt.ylabel('Inertia')
plt.title('K-means Results with Different Initializations')
plt.grid(True, alpha=0.3)
plt.show()

print(f"Min inertia: {min(inertias):.2f}, Max inertia: {max(inertias):.2f}")
print(f"Variation: {(max(inertias) - min(inertias)) / min(inertias) * 100:.2f}%")
```

### 3. Requires specifying the number of clusters in advance

```python
# Use an ensemble approach to estimate the number of clusters
from sklearn.cluster import KMeans

def consensus_clustering(X, k_range=range(2, 11), n_runs=20):
    best_score = -1
    best_k = None
    
    for k in k_range:
        avg_silhouette = 0
        for i in range(n_runs):
            kmeans = KMeans(n_clusters=k, random_state=i*10)
            labels = kmeans.fit_predict(X)
            score = silhouette_score(X, labels)
            avg_silhouette += score
        
        avg_silhouette /= n_runs
        print(f"k={k}, Average Silhouette Score: {avg_silhouette:.4f}")
        
        if avg_silhouette > best_score:
            best_score = avg_silhouette
            best_k = k
    
    return best_k, best_score

best_k, best_score = consensus_clustering(X_iris_scaled, k_range=range(2, 6))
print(f"\nBest number of clusters: {best_k} with average silhouette score: {best_score:.4f}")
```

## 9. Summary

K-means clustering is a fundamental unsupervised learning algorithm that helps find structure in unlabeled data. Key points to remember:

- K-means partitions data into K clusters by minimizing the within-cluster sum of squares
- It works best for spherical clusters of similar size and density
- Determining the optimal number of clusters is a challenge that can be addressed with methods like elbow method or silhouette analysis
- Preprocessing, especially scaling features, is important for K-means to work properly
- K-means has several variations like K-means++ (for better initialization) and Mini-Batch K-means (for large datasets)
- Evaluation can be done using internal metrics (silhouette, inertia) or external metrics if ground truth is available
- K-means has limitations: assumes spherical clusters, sensitive to initialization, and requires specifying K

For the next topic, consider exploring more advanced clustering algorithms like DBSCAN, hierarchical clustering, or Gaussian Mixture Models, which address some of the limitations of K-means.
