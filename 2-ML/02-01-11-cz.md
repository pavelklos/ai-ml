## 1. Úvod do přeučení a nedoučení

Přeučení a nedoučení jsou základní koncepty ve strojovém učení, které popisují, jak dobře se model generalizuje na nová, neviděná data po tréninku.

- **Přeučení** nastává, když se model naučí trénovací data příliš dobře a zachycuje šum a náhodné fluktuace namísto základního vzoru. Tyto modely fungují výborně na trénovacích datech, ale špatně na nových datech.

- **Nedoučení** nastává, když je model příliš jednoduchý, aby zachytil základní strukturu dat. Tyto modely fungují špatně jak na trénovacích, tak na testovacích datech.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split, learning_curve
from sklearn.linear_model import LinearRegression, Lasso, Ridge
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.tree import DecisionTreeRegressor
from sklearn.metrics import mean_squared_error

# Nastavení náhodného semínka pro reprodukovatelnost
np.random.seed(42)
```

## 2. Pochopení kompromisu mezi zkreslením a rozptylem

Kompromis mezi zkreslením a rozptylem je centrálním konceptem spojeným s přeučením a nedoučením:

- **Vysoké zkreslení (Nedoučení)**: Model má silné předpoklady o datech, což vede k jednoduchému modelu, který přehlíží důležité vzory
- **Vysoký rozptyl (Přeučení)**: Model je vysoce citlivý na malé fluktuace v trénovacích datech

```python
# Generování syntetických dat pro demonstraci kompromisu mezi zkreslením a rozptylem
def generate_nonlinear_data(n_samples=100, noise=0.5):
    """Generování nelineárních dat s určitým šumem"""
    X = np.random.uniform(0, 10, size=n_samples).reshape(-1, 1)
    y = np.sin(X).ravel() + noise * np.random.randn(n_samples)
    return X, y

# Vytvoření datasetu
X, y = generate_nonlinear_data(200)

# Rozdělení dat na trénovací a testovací sady
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vykreslení dat
plt.figure(figsize=(10, 6))
plt.scatter(X_train, y_train, alpha=0.7, label='Trénovací data')
plt.scatter(X_test, y_test, alpha=0.7, label='Testovací data')
plt.title('Nelineární data')
plt.xlabel('X')
plt.ylabel('y')
plt.legend()
plt.show()
```

## 3. Identifikace přeučení a nedoučení

Přeučení a nedoučení můžete identifikovat porovnáním metrik výkonu na trénovacích a testovacích datasetech:

- **Nedoučení**: Vysoká trénovací chyba, vysoká testovací chyba
- **Dobrý fit**: Nízká trénovací chyba, nízká testovací chyba
- **Přeučení**: Nízká trénovací chyba, vysoká testovací chyba

```python
def evaluate_model(model, X_train, y_train, X_test, y_test):
    """Trénování modelu a vyhodnocení na trénovacích a testovacích datech"""
    model.fit(X_train, y_train)
    
    # Vytvoření predikcí
    train_preds = model.predict(X_train)
    test_preds = model.predict(X_test)
    
    # Výpočet MSE
    train_mse = mean_squared_error(y_train, train_preds)
    test_mse = mean_squared_error(y_test, test_preds)
    
    print(f"Trénovací MSE: {train_mse:.4f}")
    print(f"Testovací MSE: {test_mse:.4f}")
    
    return train_mse, test_mse, model

# Vytvoření modelů s různou složitostí
models = {
    "Nedoučení (Lineární)": LinearRegression(),
    "Dobrý fit (Polynom - stupeň 3)": make_pipeline(PolynomialFeatures(3), LinearRegression()),
    "Přeučení (Polynom - stupeň 15)": make_pipeline(PolynomialFeatures(15), LinearRegression()),
}

# Vyhodnocení každého modelu
results = {}
for name, model in models.items():
    print(f"\nVyhodnocení: {name}")
    train_mse, test_mse, fitted_model = evaluate_model(model, X_train, y_train, X_test, y_test)
    results[name] = {
        'model': fitted_model,
        'train_mse': train_mse,
        'test_mse': test_mse
    }
```

## 4. Vizualizace složitosti modelu

Vizualizace toho, jak modely s různou složitostí odpovídají vašim datům, vám může pomoci intuitivně porozumět přeučení a nedoučení.

```python
# Vytvoření rozsahu hodnot x pro hladké vykreslení
X_plot = np.linspace(0, 10, 1000).reshape(-1, 1)

# Vykreslení skutečného vztahu (sinusová funkce)
plt.figure(figsize=(15, 10))

for i, (name, result) in enumerate(results.items(), 1):
    model = result['model']
    
    # Vytvoření predikcí na hladkých hodnotách x
    y_pred = model.predict(X_plot)
    
    # Vytvoření subplotu
    plt.subplot(2, 2, i)
    plt.scatter(X_train, y_train, alpha=0.4, label='Trénovací data')
    plt.plot(X_plot, y_pred, 'r-', linewidth=3, label='Predikce modelu')
    plt.plot(X_plot, np.sin(X_plot), 'g--', linewidth=2, label='Skutečná funkce')
    plt.title(f"{name}\nTrénovací MSE: {result['train_mse']:.4f}, Testovací MSE: {result['test_mse']:.4f}")
    plt.xlabel('X')
    plt.ylabel('y')
    plt.legend()

plt.tight_layout()
plt.show()
```

## 5. Techniky prevence přeučení

Existuje několik technik, které mohou pomoci předcházet přeučení:

### Regularizace

```python
# Ukázka regularizace s Ridge a Lasso regresí
degree = 10  # Vysoký stupeň polynomu (náchylný k přeučení)

# Vytvoření modelů s různými silami regularizace
models = {
    "Bez regularizace": make_pipeline(PolynomialFeatures(degree), LinearRegression()),
    "Ridge (L2)": make_pipeline(PolynomialFeatures(degree), Ridge(alpha=1.0)),
    "Lasso (L1)": make_pipeline(PolynomialFeatures(degree), Lasso(alpha=0.01))
}

# Vyhodnocení regularizovaných modelů
reg_results = {}
for name, model in models.items():
    print(f"\nVyhodnocení: {name}")
    train_mse, test_mse, fitted_model = evaluate_model(model, X_train, y_train, X_test, y_test)
    reg_results[name] = {
        'model': fitted_model,
        'train_mse': train_mse,
        'test_mse': test_mse
    }
```

### Předčasné zastavení a prořezávání

```python
# Ukázka předčasného zastavení s rozhodovacími stromy
# Vytvoření a vyhodnocení neprořezaného stromu
deep_tree = DecisionTreeRegressor(max_depth=None)
deep_train_mse, deep_test_mse, _ = evaluate_model(deep_tree, X_train, y_train, X_test, y_test)

# Vytvoření a vyhodnocení prořezaného stromu
pruned_tree = DecisionTreeRegressor(max_depth=3)  # Omezení hloubky
pruned_train_mse, pruned_test_mse, _ = evaluate_model(pruned_tree, X_train, y_train, X_test, y_test)

print("\nNeprořezaný vs Prořezaný rozhodovací strom:")
print(f"Neprořezaný - Trénovací MSE: {deep_train_mse:.4f}, Testovací MSE: {deep_test_mse:.4f}")
print(f"Prořezaný  - Trénovací MSE: {pruned_train_mse:.4f}, Testovací MSE: {pruned_test_mse:.4f}")
```

### Dropout a ensemble metody

```python
from sklearn.ensemble import RandomForestRegressor

# Ukázka ensemble metod pro prevenci přeučení
forest = RandomForestRegressor(n_estimators=100, random_state=42)
forest_train_mse, forest_test_mse, _ = evaluate_model(forest, X_train, y_train, X_test, y_test)

print("\nRozhodovací strom vs Náhodný les:")
print(f"Rozhodovací strom - Trénovací MSE: {deep_train_mse:.4f}, Testovací MSE: {deep_test_mse:.4f}")
print(f"Náhodný les - Trénovací MSE: {forest_train_mse:.4f}, Testovací MSE: {forest_test_mse:.4f}")
```

## 6. Techniky řešení nedoučení

K řešení nedoučení obecně potřebujete zvýšit složitost modelu:

```python
# Ukázka řešení nedoučení
models = {
    "Lineární (Nedoučení)": LinearRegression(),
    "Polynom stupně 2": make_pipeline(PolynomialFeatures(2), LinearRegression()),
    "Polynom stupně 3": make_pipeline(PolynomialFeatures(3), LinearRegression()),
    "Komplexní model (Rozhodovací strom)": DecisionTreeRegressor(max_depth=5)
}

# Vyhodnocení modelů se zvyšující se složitostí
for name, model in models.items():
    print(f"\nVyhodnocení: {name}")
    train_mse, test_mse, _ = evaluate_model(model, X_train, y_train, X_test, y_test)
```

Strategie řešení nedoučení zahrnují:
- Přidání více relevantních příznaků
- Zvýšení složitosti modelu (např. polynomy vyššího stupně)
- Snížení síly regularizace
- Použití výkonnějších architektur modelů
- Feature engineering pro lepší zachycení vzorů

## 7. Křížová validace pro výběr modelu

Křížová validace pomáhá identifikovat optimální úroveň složitosti modelu, vyvážením kompromisu mezi přeučením a nedoučením.

```python
from sklearn.model_selection import cross_val_score

# Použití křížové validace pro výběr optimálního stupně polynomu
degrees = range(1, 15)
cv_scores = []

for degree in degrees:
    model = make_pipeline(PolynomialFeatures(degree), LinearRegression())
    scores = cross_val_score(model, X, y, cv=5, scoring='neg_mean_squared_error')
    cv_scores.append(-scores.mean())  # Převod na pozitivní MSE

# Nalezení optimálního stupně
optimal_degree = degrees[np.argmin(cv_scores)]
print(f"Optimální stupeň polynomu: {optimal_degree}")

# Vykreslení výsledků křížové validace
plt.figure(figsize=(10, 6))
plt.plot(degrees, cv_scores, marker='o')
plt.axvline(x=optimal_degree, color='r', linestyle='--', label=f'Optimální stupeň: {optimal_degree}')
plt.xlabel('Stupeň polynomu')
plt.ylabel('Křížová validace MSE')
plt.title('Křížová validace pro výběr modelu')
plt.grid(True, alpha=0.3)
plt.legend()
plt.show()
```

## 8. Praktické příklady s různými modely

Pojďme se podívat, jak se přeučení a nedoučení projevuje v různých modelech strojového učení:

```python
from sklearn.datasets import load_boston
from sklearn.model_selection import learning_curve
from sklearn.svm import SVR

# Načtení reálného datasetu
boston = load_boston()
X_boston, y_boston = boston.data, boston.target

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(
    X_boston, y_boston, test_size=0.2, random_state=42)

# Funkce pro vykreslení křivek učení
def plot_learning_curve(estimator, title, X, y, ylim=None, cv=5,
                        n_jobs=None, train_sizes=np.linspace(.1, 1.0, 5)):
    plt.figure(figsize=(10, 6))
    plt.title(title)
    if ylim is not None:
        plt.ylim(*ylim)
    plt.xlabel("Počet trénovacích příkladů")
    plt.ylabel("Skóre")
    
    train_sizes, train_scores, test_scores = learning_curve(
        estimator, X, y, cv=cv, n_jobs=n_jobs, train_sizes=train_sizes, scoring='neg_mean_squared_error')
    
    train_scores_mean = -np.mean(train_scores, axis=1)
    test_scores_mean = -np.mean(test_scores, axis=1)
    
    plt.grid()
    plt.plot(train_sizes, train_scores_mean, 'o-', color="r", label="Trénovací skóre")
    plt.plot(train_sizes, test_scores_mean, 'o-', color="g", label="Validační skóre")
    plt.legend(loc="best")
    
    return plt

# Modely pro ukázku přeučení a nedoučení
models = {
    "Lineární regrese (Nedoučení)": LinearRegression(),
    "Rozhodovací strom (Přeučení)": DecisionTreeRegressor(),
    "SVR s RBF jádrem (Dobrý fit)": SVR(kernel='rbf', C=1.0, gamma='scale')
}

for name, model in models.items():
    plot_learning_curve(model, f"Křivka učení - {name}", X_boston, y_boston)
    plt.show()
```

## 9. Shrnutí

Pochopení přeučení a nedoučení je nezbytné pro vytváření efektivních modelů strojového učení:

- **Přeučení** nastává, když jsou modely příliš složité pro data, zachycují šum místo skutečných vzorů
- **Nedoučení** nastává, když jsou modely příliš jednoduché pro zachycení základních vzorů v datech
- **Kompromis mezi zkreslením a rozptylem** je klíčový pro řešení těchto problémů:
  - Vysoké zkreslení vede k nedoučení
  - Vysoký rozptyl vede k přeučení

Klíčové strategie pro řešení těchto problémů:

- **Pro přeučení**: 
  - Regularizace (L1, L2)
  - Více trénovacích dat
  - Redukce příznaků
  - Předčasné zastavení
  - Ensemble metody
  - Dropout (pro neuronové sítě)

- **Pro nedoučení**:
  - Zvýšení složitosti modelu
  - Feature engineering
  - Snížení regularizace
  - Použití výkonnějších modelů

- **Pro nalezení správné rovnováhy**:
  - Křížová validace
  - Křivky učení
  - Monitorování trénovacích a validačních metrik

Pamatujte, že cílem není dokonale fitovat trénovací data, ale vytvořit model, který se dobře generalizuje na nová, neviděná data.

Pro další téma zvažte prozkoumání "Škálování a normalizace příznaků", což je zásadní pro přípravu dat pro mnoho algoritmů strojového učení a zajištění jejich optimálního výkonu.
