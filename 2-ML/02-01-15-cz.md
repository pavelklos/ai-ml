## 1. Úvod do kompromisu mezi systematickou a náhodnou chybou

Kompromis mezi systematickou a náhodnou chybou je základní koncept ve strojovém učení, který nám pomáhá pochopit zdroj chyb predikce v našich modelech. Představuje rovnováhu mezi dvěma konkurenčními faktory:

- **Systematická chyba (Bias)**: Chyba způsobená příliš zjednodušujícími předpoklady v algoritmu učení
- **Náhodná chyba (Variance)**: Chyba způsobená nadměrnou citlivostí na malé výkyvy v trénovacích datech

Pochopení tohoto kompromisu je klíčové pro vytváření modelů, které dobře generalizují na nová, neviděná data.

## 2. Pochopení systematické a náhodné chyby

### Systematická chyba (Bias)

Systematická chyba představuje, jak vzdálené jsou naše predikce od skutečných hodnot v průměru. Model s vysokou systematickou chybou je příliš zjednodušený a konzistentně přehlíží důležité vzory v datech.

- **Modely s vysokou systematickou chybou**: Lineární regrese, logistická regrese s minimem příznaků
- **Příznaky**: Podtrénování (underfitting), vysoká trénovací chyba, vysoká validační chyba
- **Příklad**: Použití lineární regrese pro modelování vysoce nelineárního vztahu

### Náhodná chyba (Variance)

Náhodná chyba představuje, jak moc naše predikce kolísají pro různé trénovací datové sady. Model s vysokou náhodnou chybou je příliš složitý a zachycuje náhodný šum v trénovacích datech.

- **Modely s vysokou náhodnou chybou**: Rozhodovací stromy s mnoha úrovněmi, polynomiální regrese vysokého stupně
- **Příznaky**: Přetrénování (overfitting), nízká trénovací chyba, vysoká validační chyba
- **Příklad**: Použití polynomu vysokého stupně pro modelování jednoduchých dat

```python
# Vygenerování syntetického datasetu s kvadratickým vztahem
np.random.seed(42)
n_samples = 100
X = np.linspace(0, 10, n_samples).reshape(-1, 1)
y_true = 1 + X.ravel() * 2 + X.ravel()**2 * 0.5
y = y_true + np.random.normal(0, 2, size=n_samples)  # Přidání šumu

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření modelů s různou složitostí
models = {
    "Lineární regrese (Vysoká systematická chyba)": LinearRegression(),
    "Kvadratická regrese (Vyvážená)": Pipeline([
        ("poly", PolynomialFeatures(degree=2)),
        ("linear", LinearRegression())
    ]),
    "Polynom 10. stupně (Vysoká náhodná chyba)": Pipeline([
        ("poly", PolynomialFeatures(degree=10)),
        ("linear", LinearRegression())
    ])
}

# Vykreslení výsledků
plt.figure(figsize=(12, 8))
X_plot = np.linspace(0, 10, 100).reshape(-1, 1)

plt.scatter(X_train, y_train, color='blue', alpha=0.5, label="Trénovací data")
plt.scatter(X_test, y_test, color='green', alpha=0.5, label="Testovací data")
plt.plot(X_plot, 1 + X_plot.ravel() * 2 + X_plot.ravel()**2 * 0.5, 'r-', label="Skutečná funkce")

for name, model in models.items():
    model.fit(X_train, y_train)
    y_pred = model.predict(X_plot)
    plt.plot(X_plot, y_pred, label=f"{name}, Test MSE: {mean_squared_error(y_test, model.predict(X_test)):.2f}")

plt.legend()
plt.title("Modely s různými charakteristikami systematické a náhodné chyby")
plt.xlabel("X")
plt.ylabel("y")
plt.show()
```

## 3. Matematický rámec

Očekávanou chybu predikce modelu lze rozložit na tři složky:

**Celková chyba = Systematická chyba² + Náhodná chyba + Neredukovatelná chyba**

Kde:
- **Systematická chyba²**: Kvadrát rozdílu mezi očekávanou predikcí a skutečnou hodnotou
- **Náhodná chyba**: Očekávaná kvadratická odchylka predikce kolem její střední hodnoty
- **Neredukovatelná chyba**: Šum v datech, který nelze redukovat žádným modelem

Tento rozklad nám pomáhá pochopit, že nemůžeme současně minimalizovat systematickou i náhodnou chybu - snížení jedné typicky zvyšuje druhou.

```python
# Funkce pro demonstraci kompromisu mezi systematickou a náhodnou chybou s polynomiální regresí
def bias_variance_demo(degrees, n_datasets=50, noise_level=1.0):
    # Vygenerování skutečné funkce (sinusoida)
    x = np.linspace(0, 1, 100)
    x_test = x.reshape(-1, 1)
    y_true = np.sin(4 * np.pi * x)
    
    # Inicializace polí pro predikce
    all_predictions = np.zeros((len(degrees), n_datasets, len(x)))
    
    # Simulace více datasetů se šumem
    for i in range(n_datasets):
        # Vygenerování trénovacích dat se šumem
        x_train = np.random.uniform(0, 1, size=20).reshape(-1, 1)
        y_train = np.sin(4 * np.pi * x_train.ravel()) + np.random.normal(0, noise_level, size=20)
        
        # Trénování modelů s různými stupni polynomu
        for j, degree in enumerate(degrees):
            model = Pipeline([
                ('poly', PolynomialFeatures(degree=degree)),
                ('linear', LinearRegression())
            ])
            model.fit(x_train, y_train)
            all_predictions[j, i] = model.predict(x_test).ravel()
    
    # Výpočet systematické chyby a náhodné chyby pro každý model
    mean_predictions = all_predictions.mean(axis=1)
    bias = np.array([np.mean((mean_pred - y_true)**2) for mean_pred in mean_predictions])
    variance = np.array([np.mean(np.var(all_predictions[j], axis=0)) for j in range(len(degrees))])
    error = bias + variance
    
    return x, y_true, all_predictions, mean_predictions, bias, variance, error

# Spuštění demonstrace
degrees = [1, 3, 5, 10, 15]
x, y_true, all_preds, mean_preds, biases, variances, errors = bias_variance_demo(degrees)

# Vykreslení výsledků
fig, axes = plt.subplots(2, 1, figsize=(10, 12))

# Vykreslení modelů různé složitosti
for i, degree in enumerate(degrees):
    axes[0].plot(x, mean_preds[i], label=f'Stupeň {degree}')
    # Vykreslení některých individuálních predikcí pro nejvyšší stupeň
    if degree == degrees[-1]:
        for j in range(10):  # Vykreslení 10 náhodných modelů nejvyššího stupně
            axes[0].plot(x, all_preds[i, j], 'k-', alpha=0.1)
            
axes[0].plot(x, y_true, 'r-', label='Skutečná funkce')
axes[0].scatter(np.linspace(0, 1, 20), 
                np.sin(4 * np.pi * np.linspace(0, 1, 20)) + np.random.normal(0, 1.0, size=20), 
                color='blue', alpha=0.4, label='Vzorové datové body')
axes[0].legend()
axes[0].set_title('Modely různé složitosti')

# Vykreslení kompromisu mezi systematickou a náhodnou chybou
axes[1].plot(degrees, biases, 'b-', label='Bias²')
axes[1].plot(degrees, variances, 'r-', label='Variance')
axes[1].plot(degrees, errors, 'g-', label='Celková chyba')
axes[1].legend()
axes[1].set_xlabel('Stupeň polynomu')
axes[1].set_ylabel('Chyba')
axes[1].set_title('Kompromis mezi systematickou a náhodnou chybou')

plt.tight_layout()
plt.show()
```

## 4. Vizualizace kompromisu mezi systematickou a náhodnou chybou

Klasickým způsobem vizualizace kompromisu mezi systematickou a náhodnou chybou jsou křivky učení, které ukazují, jak se trénovací a validační chyba mění s přidáváním více trénovacích příkladů.

```python
def plot_learning_curves(estimator, X, y, cv=5, n_jobs=-1, train_sizes=np.linspace(0.1, 1.0, 10)):
    train_sizes, train_scores, test_scores = learning_curve(
        estimator, X, y, cv=cv, n_jobs=n_jobs, train_sizes=train_sizes)
    
    # Výpočet průměru a směrodatné odchylky pro trénovací a testovací skóre
    train_mean = np.mean(train_scores, axis=1)
    train_std = np.std(train_scores, axis=1)
    test_mean = np.mean(test_scores, axis=1)
    test_std = np.std(test_scores, axis=1)
    
    # Vykreslení křivek učení
    plt.figure(figsize=(10, 6))
    plt.fill_between(train_sizes, train_mean - train_std, train_mean + train_std, alpha=0.1, color="blue")
    plt.fill_between(train_sizes, test_mean - test_std, test_mean + test_std, alpha=0.1, color="red")
    plt.plot(train_sizes, train_mean, 'o-', color="blue", label="Trénovací skóre")
    plt.plot(train_sizes, test_mean, 'o-', color="red", label="Validační skóre")
    
    plt.title("Křivky učení")
    plt.xlabel("Počet trénovacích příkladů")
    plt.ylabel("Skóre")
    plt.legend(loc="best")
    plt.grid(True)
    
    plt.tight_layout()
    plt.show()

# Vygenerování nové datové sady
np.random.seed(0)
X = np.random.rand(200, 1) * 5
y = np.sin(X.ravel()) + np.random.normal(0, 0.1, X.shape[0])

# Vykreslení křivek učení pro modely s různými charakteristikami systematické a náhodné chyby
print("Lineární model (Vysoká systematická chyba):")
plot_learning_curves(LinearRegression(), X, y)

print("Rozhodovací strom s max_depth=5 (Vyvážený):")
plot_learning_curves(DecisionTreeRegressor(max_depth=5, random_state=42), X, y)

print("Rozhodovací strom s max_depth=20 (Vysoká náhodná chyba):")
plot_learning_curves(DecisionTreeRegressor(max_depth=20, random_state=42), X, y)
```

## 5. Vliv na výběr modelu

Kompromis mezi systematickou a náhodnou chybou přímo ovlivňuje výběr modelu. Modely na škále od jednoduchých po složité nabízejí různé kompromisy:

1. **Velmi jednoduché modely** (vysoká systematická chyba, nízká náhodná chyba):
   - Lineární regrese
   - Jednoduché rozhodovací stromy
   - Naivní Bayes

2. **Modely střední složitosti** (střední systematická chyba, střední náhodná chyba):
   - Náhodné lesy
   - Boosting s omezenou hloubkou
   - Support vector machines s vhodnými jádry

3. **Složité modely** (nízká systematická chyba, vysoká náhodná chyba):
   - Hluboké neuronové sítě
   - Polynomiální regrese vysokého stupně
   - Hluboké rozhodovací stromy

```python
# Vygenerování složitější datové sady
np.random.seed(42)
n_samples = 200
X = np.random.rand(n_samples, 1) * 6 - 3
y = 0.5 * X.ravel() ** 3 + X.ravel() ** 2 - 2 * X.ravel() + 2 + np.random.normal(0, 2, n_samples)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

    "Kubická regrese": Pipeline([

        ("linear", LinearRegression())
    ]),
    "Polynom 10. stupně (Složitý)": Pipeline([
        ("poly", PolynomialFeatures(degree=10)),
        ("linear", LinearRegression())
    ]),
    "Rozhodovací strom (max_depth=2)": DecisionTreeRegressor(max_depth=2, random_state=42),
    "Rozhodovací strom (max_depth=10)": DecisionTreeRegressor(max_depth=10, random_state=42),

plt.title("Modely s různými charakteristikami systematické a náhodné chyby")

plt.bar([r['Model'] for r in results], [r['Train MSE'] for r in results], label='Train MSE', alpha=0.7)
```

## 6. Techniky pro vyvážení systematické a náhodné chyby

Existuje několik technik, které nám pomáhají zvládat kompromis mezi systematickou a náhodnou chybou:

### 1. Regularizace

Regularizace přidává penalizaci do ztrátové funkce ke snížení složitosti modelu.

```python
# Ukázka regularizace s Ridge a Lasso regresí
np.random.seed(42)
n_samples = 50
X = 3 * np.random.rand(n_samples, 10)
y = 5 + np.dot(X, [1, 0.1, 0.2, -0.3, 0, 0, 0, 0, 0, 0]) + np.random.randn(n_samples)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Porovnání různých sil regularizace
alphas = [0, 0.001, 0.01, 0.1, 1, 10, 100]
ridge_results = []
lasso_results = []

for alpha in alphas:
    # Ridge regrese
    ridge = Ridge(alpha=alpha, random_state=42)
    ridge.fit(X_train, y_train)
    ridge_train_mse = mean_squared_error(y_train, ridge.predict(X_train))
    ridge_test_mse = mean_squared_error(y_test, ridge.predict(X_test))
    ridge_results.append({
        'Alpha': alpha,
        'Train MSE': ridge_train_mse,
        'Test MSE': ridge_test_mse
    })
    
    # Lasso regrese
    lasso = Lasso(alpha=alpha, random_state=42)
    lasso.fit(X_train, y_train)
    lasso_train_mse = mean_squared_error(y_train, lasso.predict(X_train))
    lasso_test_mse = mean_squared_error(y_test, lasso.predict(X_test))
    lasso_results.append({
        'Alpha': alpha,
        'Train MSE': lasso_train_mse,
        'Test MSE': lasso_test_mse
    })

# Vykreslení efektu regularizace
plt.figure(figsize=(14, 6))

plt.subplot(1, 2, 1)
plt.semilogx([r['Alpha'] for r in ridge_results], [r['Train MSE'] for r in ridge_results], 'b-o', label='Train MSE')
plt.semilogx([r['Alpha'] for r in ridge_results], [r['Test MSE'] for r in ridge_results], 'r-o', label='Test MSE')
plt.xlabel('Ridge alpha (síla regularizace)')
plt.ylabel('Střední kvadratická chyba')
plt.title('Ridge regrese: Efekt regularizace')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.semilogx([r['Alpha'] for r in lasso_results], [r['Train MSE'] for r in lasso_results], 'b-o', label='Train MSE')
plt.semilogx([r['Alpha'] for r in lasso_results], [r['Test MSE'] for r in lasso_results], 'r-o', label='Test MSE')
plt.xlabel('Lasso alpha (síla regularizace)')
plt.ylabel('Střední kvadratická chyba')
plt.title('Lasso regrese: Efekt regularizace')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Zobrazení koeficientů pro různé síly regularizace
plt.figure(figsize=(14, 6))

plt.subplot(1, 2, 1)
for alpha in [0, 0.1, 1, 10]:
    ridge = Ridge(alpha=alpha)
    ridge.fit(X_train, y_train)
    plt.plot(range(10), ridge.coef_, 'o-', label=f'Ridge alpha={alpha}')
plt.xlabel('Index koeficientu')
plt.ylabel('Hodnota koeficientu')
plt.title('Koeficienty Ridge regrese')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
for alpha in [0, 0.1, 1, 10]:
    lasso = Lasso(alpha=alpha)
    lasso.fit(X_train, y_train)
    plt.plot(range(10), lasso.coef_, 'o-', label=f'Lasso alpha={alpha}')
plt.xlabel('Index koeficientu')
plt.ylabel('Hodnota koeficientu')
plt.title('Koeficienty Lasso regrese')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### 2. Ensemble metody

Ensemble metody jako náhodné lesy a gradient boosting kombinují více modelů ke snížení náhodné chyby při zachování nízké systematické chyby.

```python
# Ukázka ensemble metod pro vyvážení systematické a náhodné chyby
from sklearn.ensemble import RandomForestRegressor, GradientBoostingRegressor

# Vygenerování datové sady s nelineárním vzorem
np.random.seed(42)
X = np.random.rand(100, 1) * 10
y = np.sin(X.ravel()) + 0.1 * np.random.randn(100)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření různých estimátorů
estimators = {
    "Rozhodovací strom (max_depth=1)": DecisionTreeRegressor(max_depth=1, random_state=42),
    "Rozhodovací strom (max_depth=3)": DecisionTreeRegressor(max_depth=3, random_state=42),
    "Rozhodovací strom (max_depth=None)": DecisionTreeRegressor(random_state=42),
    "Náhodný les (10 stromů)": RandomForestRegressor(n_estimators=10, random_state=42),
    "Náhodný les (100 stromů)": RandomForestRegressor(n_estimators=100, random_state=42),
    "Gradient Boosting": GradientBoostingRegressor(random_state=42)
}

# Vyhodnocení modelů
X_plot = np.linspace(0, 10, 1000).reshape(-1, 1)
plt.figure(figsize=(14, 10))

for name, estimator in estimators.items():
    estimator.fit(X_train, y_train)
    train_mse = mean_squared_error(y_train, estimator.predict(X_train))
    test_mse = mean_squared_error(y_test, estimator.predict(X_test))
    
    # Vykreslení predikcí modelu
    plt.subplot(3, 2, list(estimators.keys()).index(name) + 1)
    plt.scatter(X_train, y_train, color='blue', s=20, alpha=0.5, label='Trénovací data')
    plt.scatter(X_test, y_test, color='green', s=20, alpha=0.5, label='Testovací data')
    plt.plot(X_plot, np.sin(X_plot.ravel()), 'r-', label='Skutečná funkce')
    plt.plot(X_plot, estimator.predict(X_plot), 'k-', label=f'{name}')
    plt.title(f"{name}\nTrain MSE: {train_mse:.4f}, Test MSE: {test_mse:.4f}")
    plt.legend()
    plt.ylim(-1.5, 1.5)

plt.tight_layout()
plt.show()
```

### 3. Křížová validace

Křížová validace pomáhá najít správnou složitost modelu tím, že vyhodnocuje na více datových rozděleních.

```python
from sklearn.model_selection import cross_val_score, KFold, validation_curve

# Vygenerování datové sady
np.random.seed(42)
X = np.random.rand(200, 1) * 10
y = np.sin(X.ravel()) + 0.2 * np.random.randn(200)

# Vykreslení validačních křivek pro nalezení optimálního hyperparametru
param_range = np.arange(1, 20)
train_scores, test_scores = validation_curve(
    DecisionTreeRegressor(random_state=42),
    X, y,
    param_name="max_depth",
    param_range=param_range,
    cv=5,
    scoring="neg_mean_squared_error"
)

# Vykreslení validační křivky
plt.figure(figsize=(10, 6))
train_scores_mean = -np.mean(train_scores, axis=1)
train_scores_std = np.std(train_scores, axis=1)
test_scores_mean = -np.mean(test_scores, axis=1)
test_scores_std = np.std(test_scores, axis=1)

plt.fill_between(param_range, train_scores_mean - train_scores_std,
                 train_scores_mean + train_scores_std, alpha=0.1, color="blue")
plt.fill_between(param_range, test_scores_mean - test_scores_std,
                 test_scores_mean + test_scores_std, alpha=0.1, color="red")
plt.plot(param_range, train_scores_mean, 'o-', color="blue", label="Trénovací skóre")
plt.plot(param_range, test_scores_mean, 'o-', color="red", label="Validační skóre")
plt.xlabel("max_depth")
plt.ylabel("Střední kvadratická chyba")
plt.title("Validační křivka pro rozhodovací strom")
plt.legend(loc="best")
plt.grid(True, alpha=0.3)
plt.show()

# Identifikace nejlepšího parametru
best_depth = param_range[np.argmin(test_scores_mean)]
print(f"Nejlepší max_depth: {best_depth}")
```

## 8. Detekce a řešení vysoké systematické nebo náhodné chyby

Identifikace, zda váš model trpí vysokou systematickou nebo náhodnou chybou, je prvním krokem k jeho zlepšení:

### Známky vysoké systematické chyby (Podtrénování):
- Vysoká trénovací chyba
- Validační chyba blízká trénovací chybě
- Špatný výkon na všech datových rozděleních

### Známky vysoké náhodné chyby (Přetrénování):
- Nízká trénovací chyba
- Mnohem vyšší validační chyba než trénovací chyba
- Velká variace výkonu napříč různými datovými rozděleními

```python
def diagnose_bias_variance(model, X_train, X_test, y_train, y_test):
    # Trénování modelu
    model.fit(X_train, y_train)
    
    # Získání predikcí
    y_train_pred = model.predict(X_train)
    y_test_pred = model.predict(X_test)
    
    # Výpočet chyb
    train_mse = mean_squared_error(y_train, y_train_pred)
    test_mse = mean_squared_error(y_test, y_test_pred)
    
    # Diagnóza modelu
    if train_mse > 0.8 * test_mse:  # Trénovací chyba je blízko testovací chybě
        if train_mse > 1.0:  # Obě chyby jsou vysoké
            diagnosis = "Vysoká systematická chyba (Podtrénování)"
            solution = [
                "Zkuste složitější model",
                "Přidejte více relevantních příznaků",
                "Snižte regularizaci",
                "Zkuste polynomiální příznaky"
            ]
        else:
            diagnosis = "Vyvážený (Dobrý fit)"
            solution = [
                "Model se zdá být dobře vyvážený",
                "Zvažte ensemble metody pro další zlepšení",
                "Dolaďte hyperparametry pomocí křížové validace"
            ]
    else:  # Trénovací chyba mnohem nižší než testovací chyba
        diagnosis = "Vysoká náhodná chyba (Přetrénování)"
        solution = [
            "Získejte více trénovacích dat",
            "Použijte regularizaci",
            "Zjednodušte model (snižte složitost)",
            "Zkuste redukci dimenzionality",
            "Použijte ensemble metody"
        ]
    
    return {
        'Train MSE': train_mse,
        'Test MSE': test_mse,
        'Diagnóza': diagnosis,
        'Doporučená řešení': solution
    }

# Vygenerování datové sady
np.random.seed(42)
X = np.random.rand(100, 10) * 5
y = X[:, 0]**2 + X[:, 1] + np.random.randn(100)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření různých modelů k diagnostice
models = {
    "Lineární regrese": LinearRegression(),
    "Rozhodovací strom (max_depth=None)": DecisionTreeRegressor(random_state=42),
    "Rozhodovací strom (max_depth=3)": DecisionTreeRegressor(max_depth=3, random_state=42),
    "Náhodný les": RandomForestRegressor(n_estimators=100, random_state=42),
    "Ridge (alpha=10)": Ridge(alpha=10, random_state=42)
}

# Diagnostika každého modelu
for name, model in models.items():
    diagnosis = diagnose_bias_variance(model, X_train, X_test, y_train, y_test)
    print(f"\n{name}:")
    print(f"Train MSE: {diagnosis['Train MSE']:.4f}")
    print(f"Test MSE: {diagnosis['Test MSE']:.4f}")
    print(f"Diagnóza: {diagnosis['Diagnóza']}")
    print("Doporučená řešení:")
    for solution in diagnosis['Doporučená řešení']:
        print(f"- {solution}")
```

## 9. Shrnutí

Kompromis mezi systematickou a náhodnou chybou je základním konceptem ve strojovém učení, který nám pomáhá pochopit výkon modelu:

- **Systematická chyba** se týká chyby způsobené zjednodušenými předpoklady v algoritmu učení
- **Náhodná chyba** se týká chyby způsobené citlivostí na malé výkyvy v trénovacích datech
- Každý model leží někde na spektru systematické a náhodné chyby
- Se zvyšující se složitostí modelu má systematická chyba tendenci klesat, zatímco náhodná chyba roste
- Optimální složitost modelu minimalizuje celkovou chybu (systematická chyba² + náhodná chyba + neredukovatelná chyba)

Praktické strategie pro zvládání kompromisu mezi systematickou a náhodnou chybou zahrnují:

1. **Pro vysokou systematickou chybu (podtrénování)**:
   - Zvýšení složitosti modelu
   - Přidání více příznaků
   - Snížení regularizace
   - Použití výkonnějších modelů

2. **Pro vysokou náhodnou chybu (přetrénování)**:
   - Zvýšení množství trénovacích dat
   - Snížení složitosti modelu
   - Aplikace regularizace
   - Použití ensemble metod
   - Výběr příznaků nebo redukce dimenzionality

Pochopení kompromisu mezi systematickou a náhodnou chybou vám pomáhá vybírat vhodné modely, diagnostikovat problémy s výkonem a systematicky zlepšovat vaše řešení strojového učení.

Dalším tématem k prozkoumání je "Základní výběr příznaků", který vám pomůže naučit se techniky identifikace a výběru nejrelevantnějších příznaků pro vaše modely, což dále zvýší výkon a interpretovatelnost.
