## Úvod do detekce anomálií

Detekce anomálií (také známá jako detekce odlehlých hodnot) je identifikace vzácných položek, událostí nebo pozorování, která se výrazně odchylují od většiny dat. Anomálie mohou indikovat kritické incidenty, jako je bankovní podvod, strukturální defekty, zdravotní problémy nebo chyby v textu.

Klíčové koncepty v detekci anomálií:
- **Bodové anomálie**: Jednotlivé instance, které jsou anomální
- **Kontextuální anomálie**: Instance anomální v konkrétním kontextu
- **Kolektivní anomálie**: Kolekce instancí, které jsou anomální dohromady

Běžné výzvy:
- Definování toho, co představuje "normální" chování
- Vypořádání se s vyvíjejícím se normálním chováním
- Různé typy anomálií v různých doménách
- Dostupnost označených dat pro trénink/validaci

## Statistické metody pro detekci anomálií

Statistické přístupy předpokládají, že normální datové instance se vyskytují v oblastech s vysokou pravděpodobností stochastického modelu, zatímco anomálie se vyskytují v oblastech s nízkou pravděpodobností. Tyto metody obvykle stanovují statistický model normality a následně označují jako anomálie jakákoli pozorování, která se od tohoto modelu odchylují.

### Z-Score metoda

Z-score měří, kolik směrodatných odchylek je prvek od průměru. Datové body se Z-score nad určitým prahem (často ±3) jsou považovány za anomálie.

```python
# Z-Score metoda pro detekci anomálií
from scipy import stats

def detect_anomalies_zscore(data, threshold=3):
    """
    Detekuje anomálie pomocí metody Z-score
    
    Parametry:
    -----------
    data : array-like
        Vstupní data
    threshold : float
        Z-score práh pro detekci anomálií
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    """
    mean = np.mean(data)
    std = np.std(data)
    z_scores = [(y - mean) / std for y in data]
    return np.abs(z_scores) > threshold

# Generování vzorových dat s anomáliemi
np.random.seed(42)
normal_data = np.random.normal(loc=0, scale=1, size=1000)
anomalies = np.random.uniform(low=5, high=10, size=20)
data = np.concatenate([normal_data, anomalies])

# Detekce anomálií pomocí Z-score
anomaly_indices = detect_anomalies_zscore(data, threshold=3)
print(f"Počet detekovaných anomálií: {np.sum(anomaly_indices)}")

# Vizualizace výsledků
plt.figure(figsize=(12, 6))
plt.scatter(range(len(data)), data, c=['blue' if not x else 'red' for x in anomaly_indices], alpha=0.6)
plt.axhspan(mean - 3*std, mean + 3*std, alpha=0.2, color='green', label='Normální rozsah')
plt.title('Detekce anomálií pomocí Z-Score', fontsize=15)
plt.xlabel('Index')
plt.ylabel('Hodnota')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### Modifikovaný Z-Score

Modifikovaný Z-score používá medián a mediánovou absolutní odchylku (MAD) namísto průměru a směrodatné odchylky, což ho činí robustnějším vůči přítomnosti odlehlých hodnot.

```python
def detect_anomalies_modified_zscore(data, threshold=3.5):
    """
    Detekuje anomálie pomocí metody modifikovaného Z-score
    
    Parametry:
    -----------
    data : array-like
        Vstupní data
    threshold : float
        Práh modifikovaného Z-score pro detekci anomálií
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    """
    median = np.median(data)
    # MAD = median(|x_i - median(x)|)
    mad = np.median(np.abs(data - median))
    
    # Pro srovnatelnost MAD se směrodatnou odchylkou 
    # pro normální distribuci vynásobíme 1.4826
    mad_factor = 1.4826
    
    modified_z_scores = mad_factor * np.abs(data - median) / mad if mad else np.zeros_like(data)
    return modified_z_scores > threshold

# Aplikace modifikovaného Z-score
anomaly_indices_mod = detect_anomalies_modified_zscore(data, threshold=3.5)
print(f"Počet detekovaných anomálií (Modifikovaný Z-score): {np.sum(anomaly_indices_mod)}")
```

### Tukeyova metoda (IQR metoda)

Tato metoda používá mezikvartilové rozpětí (IQR) k identifikaci odlehlých hodnot. Datové body spadající mimo 1,5×IQR za horním a dolním kvartilem jsou považovány za anomálie.

```python
def detect_anomalies_iqr(data, factor=1.5):
    """
    Detekuje anomálie pomocí metody IQR (Tukeyova metoda)
    
    Parametry:
    -----------
    data : array-like
        Vstupní data
    factor : float
        Násobitel pro rozsah IQR
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    """
    q1 = np.percentile(data, 25)
    q3 = np.percentile(data, 75)
    iqr = q3 - q1
    
    lower_bound = q1 - factor * iqr
    upper_bound = q3 + factor * iqr
    
    return (data < lower_bound) | (data > upper_bound)

# Aplikace metody IQR
anomaly_indices_iqr = detect_anomalies_iqr(data, factor=1.5)
print(f"Počet detekovaných anomálií (metoda IQR): {np.sum(anomaly_indices_iqr)}")

# Vizualizace výsledků metody IQR
plt.figure(figsize=(12, 6))
plt.boxplot(data, vert=False, widths=0.6)
plt.scatter(data, np.ones(len(data)), c=['blue' if not x else 'red' for x in anomaly_indices_iqr], alpha=0.6)
plt.title('Metoda IQR pro detekci anomálií', fontsize=15)
plt.yticks([])
plt.xlabel('Hodnota')
plt.grid(True, alpha=0.3)
plt.show()
```

## Metody založené na vzdálenosti

Metody založené na vzdálenosti detekují anomálie měřením vzdálenosti mezi datovými body. Body, které jsou daleko od svých nejbližších sousedů, jsou považovány za anomálie.

### K-Nearest Neighbors (KNN) pro detekci anomálií

```python
from sklearn.neighbors import NearestNeighbors

def knn_anomaly_detection(data, k=5, threshold=None, method='distance'):
    """
    Detekuje anomálie pomocí metody KNN
    
    Parametry:
    -----------
    data : array-like
        Vstupní data (n_samples, n_features)
    k : int
        Počet sousedů k uvažování
    threshold : float or None
        Práh pro detekci anomálií. Pokud None, použije se 95. percentil
    method : str
        'distance' nebo 'score', určuje způsob výpočtu anomálií
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    scores : array-like
        Skóre anomálií
    """
    # Přizpůsobení algoritmu nejbližších sousedů
    nbrs = NearestNeighbors(n_neighbors=k+1).fit(data)
    
    # Pro každý bod vypočítat vzdálenosti k jeho k nejbližším sousedům
    distances, _ = nbrs.kneighbors(data)
    
    # Vzdálenost k k-tému sousedovi je skóre anomálie
    # Vynecháme první vzdálenost (což je vzdálenost k sobě samému = 0)
    anomaly_scores = distances[:, 1:].mean(axis=1)
    
    # Nastavení prahu jako 95. percentil, pokud není zadán
    if threshold is None:
        threshold = np.percentile(anomaly_scores, 95)
    
    return anomaly_scores > threshold, anomaly_scores

# Vytvoření datasetu pro detekci anomálií pomocí KNN
X_normal, _ = make_blobs(n_samples=400, centers=3, cluster_std=0.7, random_state=42)
X_outliers = np.random.uniform(low=-7, high=7, size=(20, 2))
X_combined = np.vstack([X_normal, X_outliers])

# Aplikace detekce anomálií pomocí KNN
anomaly_indices, anomaly_scores = knn_anomaly_detection(X_combined, k=10)
print(f"Počet detekovaných anomálií (KNN): {np.sum(anomaly_indices)}")

# Vizualizace výsledků
plt.figure(figsize=(12, 8))

# Vykreslení datových bodů
plt.scatter(X_combined[:, 0], X_combined[:, 1], 
            c=['blue' if not x else 'red' for x in anomaly_indices],
            s=[30 if not x else 100 for x in anomaly_indices],
            alpha=0.7)

# Vykreslení kontury skóre anomálie
x_min, x_max = X_combined[:, 0].min() - 1, X_combined[:, 0].max() + 1
y_min, y_max = X_combined[:, 1].min() - 1, X_combined[:, 1].max() + 1
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100), np.linspace(y_min, y_max, 100))
grid_points = np.c_[xx.ravel(), yy.ravel()]

# Získání skóre anomálií pro body mřížky
nbrs = NearestNeighbors(n_neighbors=10).fit(X_combined)
distances, _ = nbrs.kneighbors(grid_points)
grid_scores = distances[:, 1:].mean(axis=1)

# Přeformátování pro vykreslení kontury
grid_scores = grid_scores.reshape(xx.shape)

# Vykreslení kontury
plt.contourf(xx, yy, grid_scores, cmap='Blues', alpha=0.3)
plt.colorbar(label='Skóre anomálie')

plt.title('Detekce anomálií pomocí KNN', fontsize=15)
plt.grid(True, alpha=0.3)
plt.show()
```

### Local Outlier Factor (LOF)

LOF porovnává lokální hustotu bodu s lokálními hustotami jeho sousedů. Body s mnohem nižší hustotou než jejich sousedé jsou považovány za anomálie.

```python
from sklearn.neighbors import LocalOutlierFactor

def lof_anomaly_detection(data, k=5):
    """
    Detekuje anomálie pomocí Local Outlier Factor (LOF)
    
    Parametry:
    -----------
    data : array-like
        Vstupní data (n_samples, n_features)
    k : int
        Počet sousedů k uvažování
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    scores : array-like
        LOF skóre (vyšší = více anomální)
    """
    # Inicializace a přizpůsobení LOF
    lof = LocalOutlierFactor(n_neighbors=k, contamination='auto')
    # fit_predict vrací 1 pro inliery a -1 pro outliery
    predictions = lof.fit_predict(data)
    # Záporné LOF skóre (vyšší = více anomální)
    scores = -lof.negative_outlier_factor_
    
    return predictions == -1, scores

# Aplikace detekce anomálií pomocí LOF
anomaly_indices_lof, lof_scores = lof_anomaly_detection(X_combined, k=10)
print(f"Počet detekovaných anomálií (LOF): {np.sum(anomaly_indices_lof)}")

# Vizualizace výsledků LOF
plt.figure(figsize=(12, 8))
scatter = plt.scatter(X_combined[:, 0], X_combined[:, 1], 
                     c=lof_scores, cmap='plasma', s=50, alpha=0.8)
plt.colorbar(scatter, label='LOF skóre')
plt.title('Detekce anomálií pomocí Local Outlier Factor (LOF)', fontsize=15)
plt.grid(True, alpha=0.3)
plt.show()
```

## Metody založené na hustotě

Metody založené na hustotě identifikují anomálie odhadem funkce hustoty pravděpodobnosti dat. Body v oblastech s nízkou hustotou jsou označeny jako anomálie.

### Gaussian Mixture Models (GMM)

GMM předpokládá, že data jsou generována směsí několika Gaussovských distribucí a může identifikovat body s nízkou pravděpodobností pod přizpůsobeným modelem.

```python
from sklearn.mixture import GaussianMixture

def gmm_anomaly_detection(data, n_components=3, threshold=None):
    """
    Detekuje anomálie pomocí Gaussian Mixture Model
    
    Parametry:
    -----------
    data : array-like
        Vstupní data (n_samples, n_features)
    n_components : int
        Počet Gaussovských komponent
    threshold : float or None
        Práh pravděpodobnosti pro detekci anomálií
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    scores : array-like
        Záporný logaritmus pravděpodobnostní hustoty (vyšší = více anomální)
    """
    # Inicializace a přizpůsobení GMM
    gmm = GaussianMixture(n_components=n_components, random_state=42)
    gmm.fit(data)
    
    # Výpočet logaritmu pravděpodobnostní hustoty pro každý bod
    log_probs = gmm.score_samples(data)
    # Záporný logaritmus pravděpodobnosti (vyšší = více anomální)
    scores = -log_probs
    
    # Nastavení prahu, pokud není zadán
    if threshold is None:
        threshold = np.percentile(scores, 95)
    
    return scores > threshold, scores

# Vytvoření datasetu pro detekci anomálií pomocí GMM
X_norm1, _ = make_blobs(n_samples=200, centers=[(0, 0)], cluster_std=0.5, random_state=42)
X_norm2, _ = make_blobs(n_samples=200, centers=[(4, 4)], cluster_std=0.5, random_state=42)
X_normal = np.vstack([X_norm1, X_norm2])
X_outliers = np.random.uniform(low=-2, high=6, size=(20, 2))
X_combined = np.vstack([X_normal, X_outliers])

# Aplikace detekce anomálií pomocí GMM
anomaly_indices_gmm, gmm_scores = gmm_anomaly_detection(X_combined, n_components=2)
print(f"Počet detekovaných anomálií (GMM): {np.sum(anomaly_indices_gmm)}")

# Vizualizace výsledků GMM
plt.figure(figsize=(12, 8))

# Datové body
plt.scatter(X_combined[:, 0], X_combined[:, 1], 
            c=['blue' if not x else 'red' for x in anomaly_indices_gmm],
            s=50, alpha=0.7)

# Kontury rozhodovací hranice
x_min, x_max = X_combined[:, 0].min() - 1, X_combined[:, 0].max() + 1
y_min, y_max = X_combined[:, 1].min() - 1, X_combined[:, 1].max() + 1
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100), np.linspace(y_min, y_max, 100))
grid_points = np.c_[xx.ravel(), yy.ravel()]

# Přizpůsobení GMM pro vizualizaci
gmm = GaussianMixture(n_components=2, random_state=42)
gmm.fit(X_combined)
log_probs = gmm.score_samples(grid_points)
grid_scores = -log_probs
grid_scores = grid_scores.reshape(xx.shape)

plt.contourf(xx, yy, grid_scores, levels=10, cmap='Blues', alpha=0.3)
plt.colorbar(label='Skóre anomálie (Záporný logaritmus pravděpodobnosti)')

plt.title('Detekce anomálií pomocí Gaussian Mixture Model', fontsize=15)
plt.grid(True, alpha=0.3)
plt.show()
```

### Kernel Density Estimation (KDE)

KDE odhaduje funkci hustoty pravděpodobnosti dat neparametrickým způsobem a může identifikovat body v oblastech s nízkou hustotou.

```python
from sklearn.neighbors import KernelDensity

def kde_anomaly_detection(data, bandwidth=0.5, threshold=None):
    """
    Detekuje anomálie pomocí Kernel Density Estimation
    
    Parametry:
    -----------
    data : array-like
        Vstupní data (n_samples, n_features)
    bandwidth : float
        Parametr šířky pásma pro KDE
    threshold : float or None
        Práh logaritmu hustoty pro detekci anomálií
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    scores : array-like
        Záporný logaritmus hustoty (vyšší = více anomální)
    """
    # Inicializace a přizpůsobení KDE
    kde = KernelDensity(bandwidth=bandwidth)
    kde.fit(data)
    
    # Výpočet logaritmu hustoty pro každý bod
    log_density = kde.score_samples(data)
    # Záporný logaritmus hustoty (vyšší = více anomální)
    scores = -log_density
    
    # Nastavení prahu, pokud není zadán
    if threshold is None:
        threshold = np.percentile(scores, 95)
    
    return scores > threshold, scores

# Aplikace detekce anomálií pomocí KDE
anomaly_indices_kde, kde_scores = kde_anomaly_detection(X_combined, bandwidth=0.5)
print(f"Počet detekovaných anomálií (KDE): {np.sum(anomaly_indices_kde)}")

# Vizualizace výsledků KDE
plt.figure(figsize=(12, 8))
scatter = plt.scatter(X_combined[:, 0], X_combined[:, 1], 
                     c=kde_scores, cmap='plasma', s=50, alpha=0.8)
plt.colorbar(scatter, label='Skóre anomálie KDE')
plt.title('Detekce anomálií pomocí Kernel Density Estimation', fontsize=15)
plt.grid(True, alpha=0.3)
plt.show()
```

## Přístupy založené na shlukování

Metody detekce anomálií založené na shlukování nejprve shlukují data a poté identifikují anomálie jako body, které buď nepatří do žádného shluku, nebo jsou daleko od centra svého shluku.

### DBSCAN pro detekci anomálií

Density-Based Spatial Clustering of Applications with Noise (DBSCAN) přirozeně identifikuje odlehlé hodnoty jako body, které nepatří do žádného shluku.

```python
from sklearn.cluster import DBSCAN

def dbscan_anomaly_detection(data, eps=0.5, min_samples=5):
    """
    Detekuje anomálie pomocí shlukovacího algoritmu DBSCAN
    
    Parametry:
    -----------
    data : array-like
        Vstupní data (n_samples, n_features)
    eps : float
        Maximální vzdálenost mezi dvěma vzorky, aby byly považovány za sousedy
    min_samples : int
        Počet vzorků v okolí pro bod, aby byl považován za jádrový bod
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie (-1 = anomálie)
    """
    # Inicializace a přizpůsobení DBSCAN
    dbscan = DBSCAN(eps=eps, min_samples=min_samples)
    clusters = dbscan.fit_predict(data)
    
    # Body označené jako -1 jsou považovány za odlehlé hodnoty/anomálie
    return clusters == -1, clusters

# Vytvoření datasetu pro DBSCAN
X_normal, _ = make_blobs(n_samples=400, centers=3, cluster_std=0.5, random_state=42)
X_outliers = np.random.uniform(low=-7, high=7, size=(20, 2))
X_combined = np.vstack([X_normal, X_outliers])

# Aplikace detekce anomálií pomocí DBSCAN
anomaly_indices_dbscan, cluster_labels = dbscan_anomaly_detection(X_combined, eps=0.7, min_samples=10)
print(f"Počet detekovaných anomálií (DBSCAN): {np.sum(anomaly_indices_dbscan)}")

# Vizualizace výsledků DBSCAN
plt.figure(figsize=(12, 8))

# Vytvoření mapování barev pro shluky (-1 = červená pro odlehlé hodnoty)
unique_labels = np.unique(cluster_labels)
colors = plt.cm.rainbow(np.linspace(0, 1, len(unique_labels) - 1))
cluster_colors = {}

# Přiřazení červené odlehlým hodnotám (-1) a duhových barev platným shlukům
for i, label in enumerate(unique_labels):
    if label == -1:  # Odlehlé hodnoty
        cluster_colors[label] = 'red'
    else:
        cluster_colors[label] = colors[i - (1 if -1 in unique_labels else 0)]

# Vykreslení bodů s barvami shluku
for label in unique_labels:
    mask = cluster_labels == label
    plt.scatter(
        X_combined[mask, 0], X_combined[mask, 1],
        color=cluster_colors[label],
        label=f"Shluk {label}" if label != -1 else "Anomálie",
        s=60 if label == -1 else 40,
        marker='x' if label == -1 else 'o',
        alpha=0.7
    )

plt.title('DBSCAN shlukování pro detekci anomálií', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### K-Means pro detekci anomálií

K-means shlukování lze použít pro detekci anomálií měřením vzdálenosti každého bodu k nejbližšímu centroidu shluku.

```python
from sklearn.cluster import KMeans

def kmeans_anomaly_detection(data, n_clusters=3, threshold=None):
    """
    Detekuje anomálie pomocí K-means shlukování
    
    Parametry:
    -----------
    data : array-like
        Vstupní data (n_samples, n_features)
    n_clusters : int
        Počet shluků
    threshold : float or None
        Práh vzdálenosti pro detekci anomálií

    scores : array-like
        Vzdálenost k nejbližšímu centroidu (vyšší = více anomální)
    """
    # Inicializace a přizpůsobení K-means
    kmeans = KMeans(n_clusters=n_clusters, random_state=42)
    kmeans.fit(data)
    
    # Predikce shluku pro každý bod
    cluster_labels = kmeans.predict(data)
    
    # Výpočet vzdálenosti k přiřazenému centru shluku
    distances = np.min(
        [np.linalg.norm(data - center, axis=1) for center in kmeans.cluster_centers_],
        axis=0
    )
    
    # Nastavení prahu, pokud není zadán
    if threshold is None:
        threshold = np.percentile(distances, 95)
    
    return distances > threshold, distances

# Aplikace detekce anomálií pomocí K-means
```

### Autoencodery pro detekci anomálií

Autoencodery jsou neuronové sítě, které se učí komprimovat a rekonstruovat data. Anomálie mají typicky vyšší chyby rekonstrukce.

```python
import tensorflow as tf
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense
from tensorflow.keras.optimizers import Adam
from sklearn.preprocessing import StandardScaler

def autoencoder_anomaly_detection(data, hidden_dim=8, epochs=50, threshold=None):
    """
    Detekuje anomálie pomocí autoencoder
    
    Parametry:
    -----------
    data : array-like
        Vstupní data (n_samples, n_features)
    hidden_dim : int
        Dimenze kódovací vrstvy
    epochs : int
        Počet trénovacích epoch
    threshold : float or None
        Práh chyby rekonstrukce pro detekci anomálií
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole označující anomálie
    scores : array-like
        Chyby rekonstrukce (vyšší = více anomální)
    model : object
        Trénovaný model autoencoder
    """
    # Škálování dat
    scaler = StandardScaler()
    scaled_data = scaler.fit_transform(data)
    
    # Definice vstupní dimenze
    input_dim = scaled_data.shape[1]
    
    # Definice architektury modelu
    input_layer = Input(shape=(input_dim,))
    # Encoder
    encoded = Dense(hidden_dim * 2, activation='relu')(input_layer)
    encoded = Dense(hidden_dim, activation='relu')(encoded)
    # Decoder
    decoded = Dense(hidden_dim * 2, activation='relu')(encoded)
    decoded = Dense(input_dim, activation='linear')(decoded)
    
    # Vytvoření a kompilace modelu
    autoencoder = Model(input_layer, decoded)
    autoencoder.compile(optimizer=Adam(learning_rate=0.001), loss='mse')
    
    # Trénování autoencoder
    autoencoder.fit(scaled_data, scaled_data, 
                   epochs=epochs, batch_size=32, 
                   verbose=0, shuffle=True)
    
    # Získání chyb rekonstrukce
    reconstructions = autoencoder.predict(scaled_data)
    reconstruction_errors = np.mean(np.square(scaled_data - reconstructions), axis=1)
    
    # Nastavení prahu, pokud není zadán
    if threshold is None:
        threshold = np.percentile(reconstruction_errors, 95)
    
    return reconstruction_errors > threshold, reconstruction_errors, autoencoder

# Vytvoření datasetu pro autoencoder
```

### Detekce anomálií založená na klouzavém průměru

Metody klouzavého průměru mohou identifikovat anomálie detekcí bodů, které se výrazně odchylují od lokálního trendu.

```python
def moving_average_anomaly_detection(time_series, window_size=10, n_sigma=3):
    """
    Detekce anomálií v časové řadě pomocí klouzavého průměru
    
    Parametry:
    -----------
    time_series : array-like
        Vstupní časová řada
    window_size : int
        Velikost okna pro klouzavý průměr
    n_sigma : float
        Počet směrodatných odchylek pro práh
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole indikující anomálie
    """
    # Výpočet klouzavého průměru a směrodatné odchylky
    rolling_mean = pd.Series(time_series).rolling(window=window_size).mean()
    rolling_std = pd.Series(time_series).rolling(window=window_size).std()
    
    # Vyplnění hodnot NaN (na začátku) prvními platnými hodnotami
    rolling_mean = rolling_mean.fillna(method='bfill')
    rolling_std = rolling_std.fillna(method='bfill')
    
    # Výpočet horní a dolní hranice
    upper_bound = rolling_mean + n_sigma * rolling_std
    lower_bound = rolling_mean - n_sigma * rolling_std
    
    # Detekce anomálií
    anomalies = (time_series > upper_bound) | (time_series < lower_bound)
    
    return anomalies, rolling_mean, upper_bound, lower_bound
```

### Sezónní dekompozice pro detekci anomálií

Pro časové řady se sezónními vzory může pomoci rozklad řady na trend, sezónní a reziduální složky při identifikaci anomálií.

```python
from statsmodels.tsa.seasonal import seasonal_decompose

def seasonal_decomposition_anomaly_detection(time_series, period=24, n_sigma=3):
    """
    Detekce anomálií pomocí sezónní dekompozice
    
    Parametry:
    -----------
    time_series : array-like
        Vstupní časová řada
    period : int
        Perioda sezónní složky
    n_sigma : float
        Počet směrodatných odchylek pro práh
        
    Vrací:
    --------
    anomalies : array-like
        Booleovské pole indikující anomálie
    """
    # Provedení sezónní dekompozice
    decomposition = seasonal_decompose(time_series, period=period, model='additive')
    residual = decomposition.resid
    
    # Výpočet průměru a směrodatné odchylky reziduálu
    residual_mean = np.nanmean(residual)
    residual_std = np.nanstd(residual)
    
    # Nastavení prahu
    threshold_high = residual_mean + n_sigma * residual_std
    threshold_low = residual_mean - n_sigma * residual_std
    
    # Detekce anomálií
    anomalies = (residual > threshold_high) | (residual < threshold_low)
    
    return anomalies, decomposition
```

## Metriky hodnocení detekce anomálií

Hodnocení algoritmů detekce anomálií vyžaduje specializované metriky kvůli typicky nevyváženému charakteru problému.

```python
from sklearn.metrics import precision_recall_curve, auc, roc_curve, confusion_matrix

def evaluate_anomaly_detection(y_true, anomaly_scores, threshold=None):
    """
    Vyhodnocení výkonu detekce anomálií
    
    Parametry:
    -----------
    y_true : array-like
        Skutečné označení anomálií (1 pro anomálii, 0 pro normální)
    anomaly_scores : array-like
        Skóre anomálií (vyšší = více anomální)
    threshold : float or None
        Práh pro detekci anomálií
        
    Vrací:
    --------
    metrics : dict
        Slovník hodnotících metrik
    """
    # Výpočet ROC křivky a AUC
    fpr, tpr, roc_thresholds = roc_curve(y_true, anomaly_scores)
    roc_auc = auc(fpr, tpr)
    
    # Výpočet křivky přesnost-úplnost a AUC
    precision, recall, pr_thresholds = precision_recall_curve(y_true, anomaly_scores)
    pr_auc = auc(recall, precision)
    
    # Použití výchozího prahu, pokud není poskytnut
    if threshold is None:
        # Nalezení prahu, který maximalizuje F1 skóre
        f1_scores = 2 * (precision * recall) / (precision + recall + 1e-10)
        best_idx = np.argmax(f1_scores)
        threshold = pr_thresholds[best_idx] if best_idx < len(pr_thresholds) else np.median(anomaly_scores)
    
    # Výpočet predikcí s použitím prahu
    y_pred = anomaly_scores >= threshold
    
    # Výpočet matice záměn
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred).ravel()
    
    # Výpočet metrik
    accuracy = (tp + tn) / (tp + tn + fp + fn)
    precision_val = tp / (tp + fp) if (tp + fp) > 0 else 0
    recall_val = tp / (tp + fn) if (tp + fn) > 0 else 0
    f1 = 2 * (precision_val * recall_val) / (precision_val + recall_val) if (precision_val + recall_val) > 0 else 0
    
    return {
        'accuracy': accuracy,
        'precision': precision_val,
        'recall': recall_val,
        'f1': f1,
        'roc_auc': roc_auc,
        'pr_auc': pr_auc,
        'confusion_matrix': {
            'tn': tn, 'fp': fp,
            'fn': fn, 'tp': tp
        }
    }

# Generování syntetického datasetu se známými anomáliemi
X_normal, _ = make_blobs(n_samples=400, centers=3, cluster_std=0.7, random_state=42)
X_anomalies, _ = make_blobs(n_samples=40, centers=[(5, 5), (-5, -5)], cluster_std=0.5, random_state=42)

y_true[-len(X_anomalies):] = 1

# Aplikace Isolation Forest pro detekci anomálií

iso_forest.fit(X_combined)
# Skóre Isolation Forest: negativní = více anomální
anomaly_scores = -iso_forest.decision_function(X_combined)

# Vyhodnocení výkonu
metrics = evaluate_anomaly_detection(y_true, anomaly_scores)
print("Výkon Isolation Forest:")
print(f"Přesnost: {metrics['accuracy']:.4f}")
print(f"Precision: {metrics['precision']:.4f}")
print(f"Recall: {metrics['recall']:.4f}")
print(f"F1 skóre: {metrics['f1']:.4f}")
print(f"ROC AUC: {metrics['roc_auc']:.4f}")
print(f"PR AUC: {metrics['pr_auc']:.4f}")
print(f"Skutečně pozitivní: {metrics['confusion_matrix']['tp']}")
print(f"Falešně pozitivní: {metrics['confusion_matrix']['fp']}")
print(f"Falešně negativní: {metrics['confusion_matrix']['fn']}")
print(f"Skutečně negativní: {metrics['confusion_matrix']['tn']}")

# Vizualizace ROC křivky
plt.figure(figsize=(10, 8))
plt.subplot(2, 1, 1)
plt.plot(fpr, tpr, label=f'ROC křivka (AUC = {metrics["roc_auc"]:.4f})')
plt.plot([0, 1], [0, 1], 'k--', label='Náhodná')
plt.xlabel('False Positive Rate')
plt.ylabel('True Positive Rate')
plt.title('ROC křivka')
plt.legend()
plt.grid(True, alpha=0.3)

# Vizualizace křivky přesnost-úplnost
plt.subplot(2, 1, 2)
plt.plot(recall, precision, label=f'PR křivka (AUC = {metrics["pr_auc"]:.4f})')
plt.xlabel('Recall')
plt.ylabel('Precision')
plt.title('Křivka přesnost-úplnost')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Shrnutí a nejlepší postupy

Detekce anomálií je klíčovou úlohou v mnoha oblastech, od detekce podvodů až po monitorování zdraví systému. Volba metody závisí na povaze dat a konkrétních požadavcích aplikace.

### Klíčové poznatky

1. **Statistické metody** (Z-skóre, IQR) jsou jednoduché a interpretovatelné, ale mohou mít potíže se složitými vzory.

2. **Metody založené na vzdálenosti** (KNN, LOF) vynikají při detekci lokálních anomálií, ale mohou být výpočetně náročné pro velké datasety.

3. **Metody založené na hustotě** (GMM, KDE) fungují dobře, když data sledují specifické distribuce, ale mohou mít potíže s vysokodimenzionálními daty.

4. **Přístupy založené na shlukování** (DBSCAN, K-means) přirozeně identifikují odlehlé hodnoty a jsou často intuitivní, ale vyžadují pečlivé ladění parametrů.

5. **Metody založené na strojovém učení** (One-Class SVM, Isolation Forest) dokážou modelovat složité vzory a jsou obecně robustnější, ale mohou být hůře interpretovatelné.

6. **Přístupy hlubokého učení** (Autoenkodéry) dobře zvládají vysokodimenzionální data, ale vyžadují značné množství dat a výpočetních zdrojů.

7. **Detekce anomálií v časových řadách** vyžaduje specializované techniky, které zohledňují časové závislosti, sezónnost a trendy.

### Nejlepší postupy

1. **Porozumění datům**: Různé typy anomálií (globální, kontextové, kolektivní) mohou vyžadovat různé přístupy k detekci.

2. **Vytvoření příznaků**: U složitých dat může vytvoření smysluplných příznaků výrazně zlepšit výkon detekce anomálií.

3. **Ensemble metody**: Kombinace více technik detekce anomálií často přináší lepší výsledky než jakákoli jednotlivá metoda.

4. **Správné hodnocení**: Používejte vhodné metriky (precision, recall, F1-skóre) a vizualizační techniky k posouzení výkonu.

5. **Ladění parametrů**: Většina metod vyžaduje pečlivý výběr parametrů (např. počet sousedů, míra kontaminace).

6. **Integrace doménových znalostí**: Začlenění znalostí specifických pro doménu může zlepšit detekci a snížit počet falešně pozitivních výsledků.

7. **Semi-supervised přístupy**: Když jsou k dispozici některé označené anomálie, jejich použití může výrazně zlepšit přesnost detekce.

8. **Úvahy o škálovatelnosti**: Pro velké datasety vybírejte metody s rozumnou časovou a prostorovou složitostí.

Detekce anomálií zůstává aktivní oblastí výzkumu, přičemž jsou neustále vyvíjeny nové techniky pro řešení specifických problémů a typů dat. Nejlepší přístup často zahrnuje experimenty s více metodami a jejich spojení pro využití jejich komplementárních silných stránek.
