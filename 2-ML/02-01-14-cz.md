## 1. Úvod do shlukování a K-means

Shlukování je technika učení bez učitele, která seskupuje podobné datové body na základě jejich charakteristik. Na rozdíl od učení s učitelem se shlukování nespoléhá na označené výstupy pro trénování. K-means je jedním z nejpopulárnějších shlukovacích algoritmů díky své jednoduchosti a efektivitě.

- Rozpoznávání vzorů ve vědeckých datech

## 2. Algoritmus K-means

K-means je iterativní algoritmus, který rozděluje data do K různých shluků minimalizací součtu čtverců vzdáleností mezi datovými body a jejich přiřazenými centry shluků.

Základní kroky algoritmu jsou:
1. Náhodně inicializovat K center shluků (centroidů)
2. Přiřadit každý datový bod k nejbližšímu centroidu
3. Přepočítat centroidy jako průměr všech bodů přiřazených k danému shluku
4. Opakovat kroky 2-3, dokud nedojde ke konvergenci nebo nedosáhneme maximálního počtu iterací

```python
# Jednoduchá implementace K-means od základu
def simple_kmeans(X, k, max_iters=100, tol=1e-4):
    # Náhodně inicializovat centroidy
    centroids = X[np.random.choice(X.shape[0], k, replace=False)]
    
    for _ in range(max_iters):
        # Přiřadit body k nejbližšímu centroidu
        distances = np.array([np.linalg.norm(X - centroid, axis=1) for centroid in centroids])
        labels = np.argmin(distances, axis=0)
        
        # Aktualizovat centroidy
        new_centroids = np.array([X[labels == i].mean(axis=0) for i in range(k)])
        
        # Kontrola konvergence
        if np.all(np.linalg.norm(new_centroids - centroids, axis=1) < tol):
            break
            
        centroids = new_centroids
    
    return labels, centroids

# Generování vzorových dat se 3 shluky
X, _ = make_blobs(n_samples=300, centers=3, cluster_std=0.60, random_state=0)

# Aplikace naší jednoduché implementace K-means
labels, centroids = simple_kmeans(X, k=3)

# Vykreslení výsledků
plt.figure(figsize=(10, 6))
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis', alpha=0.7)
plt.scatter(centroids[:, 0], centroids[:, 1], c='red', s=200, marker='X')
plt.title('K-means shlukování (Jednoduchá implementace)')
plt.xlabel('Příznak 1')
plt.ylabel('Příznak 2')
plt.show()
```

## 4. Výběr optimálního počtu shluků

Jednou z výzev při použití K-means je určení optimálního počtu shluků. Dvě běžné metody jsou:

### Metoda lokte (Elbow Method)
Tato metoda sleduje procento vysvětlené variance jako funkci počtu shluků. "Loket" nebo inflexní bod v křivce naznačuje optimální počet.

```python
# Implementace metody lokte
def plot_elbow_method(X, max_k=10):
    inertias = []
    for k in range(1, max_k+1):
        kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
        kmeans.fit(X)
        inertias.append(kmeans.inertia_)
    
    plt.figure(figsize=(10, 6))
    plt.plot(range(1, max_k+1), inertias, 'o-', color='blue')
    plt.xlabel('Počet shluků (k)')
    plt.ylabel('Inertia (Součet čtverců vzdáleností)')
    plt.title('Metoda lokte pro optimální k')
    plt.grid(True, alpha=0.3)
    plt.show()

# Aplikace metody lokte
plot_elbow_method(X_scaled, max_k=10)
```

### Siluetová analýza
Siluetový koeficient měří, jak podobný je bod svému vlastnímu shluku ve srovnání s ostatními shluky.

```python
# Siluetová analýza
def plot_silhouette_scores(X, max_k=10):
    silhouette_scores = []
    for k in range(2, max_k+1):  # Silhouette vyžaduje alespoň 2 shluky
        kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
        labels = kmeans.fit_predict(X)
        score = silhouette_score(X, labels)
        silhouette_scores.append(score)
    
    plt.figure(figsize=(10, 6))
    plt.plot(range(2, max_k+1), silhouette_scores, 'o-', color='green')
    plt.xlabel('Počet shluků (k)')
    plt.ylabel('Siluetové skóre')
    plt.title('Siluetová analýza pro optimální k')
    plt.grid(True, alpha=0.3)
    plt.show()

# Aplikace siluetové analýzy
plot_silhouette_scores(X_scaled, max_k=10)
```

## 6. Varianty K-means a pokročilé techniky

Pro řešení omezení K-means bylo vyvinuto několik variant a rozšíření:

### K-means++
Jedná se o chytřejší inicializační metodu, která vybírá počáteční centroidy, které jsou od sebe vzdálené:

```python
# K-means++ je výchozí inicializační metoda v sklearn
kmeans_pp = KMeans(n_clusters=4, init='k-means++', random_state=42)
y_pred_pp = kmeans_pp.fit_predict(X_scaled)

# Porovnání s náhodnou inicializací
kmeans_random = KMeans(n_clusters=4, init='random', random_state=42)
y_pred_random = kmeans_random.fit_predict(X_scaled)

print("K-means++ inertia:", kmeans_pp.inertia_)
print("Náhodná inicializace inertia:", kmeans_random.inertia_)
```

### Mini-Batch K-means
Pro velké datasety používá Mini-Batch K-means malé náhodné dávky dat pro aktualizaci centroidů, což je rychlejší:

```python
from sklearn.cluster import MiniBatchKMeans

# Generování většího datasetu
X_large, _ = make_blobs(n_samples=10000, centers=5, random_state=42)
X_large_scaled = StandardScaler().fit_transform(X_large)

# Porovnání doby provádění
import time

# Standardní K-means
start_time = time.time()
kmeans = KMeans(n_clusters=5, random_state=42).fit(X_large_scaled)
std_time = time.time() - start_time
print(f"Čas standardního K-means: {std_time:.4f} sekund")

# Mini-batch K-means
start_time = time.time()
mbkmeans = MiniBatchKMeans(n_clusters=5, random_state=42, batch_size=256).fit(X_large_scaled)
mb_time = time.time() - start_time
print(f"Čas Mini-Batch K-means: {mb_time:.4f} sekund")
print(f"Zlepšení rychlosti: {std_time/mb_time:.2f}x rychlejší")
```

## 7. Hodnocení kvality shlukování

Hodnocení algoritmů učení bez učitele, jako je K-means, může být náročné. Zde jsou některé metriky:

### Interní hodnocení
Tyto metriky hodnotí shlukování bez externích popisků:

```python
# Inertia (součet čtverců vzdáleností k centroidům)
kmeans = KMeans(n_clusters=3, random_state=42).fit(X_iris_scaled)
print("Inertia:", kmeans.inertia_)

# Siluetové skóre
silhouette_avg = silhouette_score(X_iris_scaled, kmeans.labels_)
print("Siluetové skóre:", silhouette_avg)

# Vizualizace siluetových hodnot pro jednotlivé vzorky
from sklearn.metrics import silhouette_samples

# Výpočet siluetových skóre pro každý vzorek
silhouette_vals = silhouette_samples(X_iris_scaled, kmeans.labels_)

plt.figure(figsize=(10, 6))
y_ticks = []
y_lower, y_upper = 0, 0

for i, cluster in enumerate(range(3)):
    # Agregace siluetových skóre pro vzorky v shluku i
    cluster_silhouette_vals = silhouette_vals[kmeans.labels_ == cluster]
    cluster_silhouette_vals.sort()
    y_upper += len(cluster_silhouette_vals)
    
    color = plt.cm.viridis(i / 3)
    plt.barh(range(y_lower, y_upper), cluster_silhouette_vals, height=1.0, 
            edgecolor='none', color=color)
    
    y_ticks.append((y_lower + y_upper) / 2)
    y_lower += len(cluster_silhouette_vals)

plt.axvline(silhouette_avg, color="red", linestyle="--")
plt.yticks(y_ticks, [f"Shluk {i+1}" for i in range(3)])
plt.xlabel("Siluetový koeficient")
plt.ylabel("Shluk")
plt.title(f"Siluetový graf (Průměrné skóre: {silhouette_avg:.3f})")
plt.show()
```

### Externí hodnocení
Pokud máte skutečné označení dat, můžete použít metriky jako:

```python
from sklearn.metrics import adjusted_rand_score, normalized_mutual_info_score

# Upravený Randův index
ari = adjusted_rand_score(y_iris, kmeans.labels_)
print("Upravený Randův index:", ari)

# Normalizovaná vzájemná informace
nmi = normalized_mutual_info_score(y_iris, kmeans.labels_)
print("Normalizovaná vzájemná informace:", nmi)
```

## 8. Omezení a úvahy

K-means má několik omezení, kterých byste si měli být vědomi:

### 1. Předpokládá sférické shluky podobné velikosti a hustoty

```python
# Vytvoření dat s nesférickými shluky
X_moons, _ = make_moons(n_samples=200, noise=0.05, random_state=42)

# Aplikace K-means
kmeans_moons = KMeans(n_clusters=2, random_state=42)
y_moons_pred = kmeans_moons.fit_predict(X_moons)

# Vykreslení výsledků
plt.figure(figsize=(10, 6))
plt.scatter(X_moons[:, 0], X_moons[:, 1], c=y_moons_pred, cmap='viridis', alpha=0.7)
plt.scatter(kmeans_moons.cluster_centers_[:, 0], kmeans_moons.cluster_centers_[:, 1], 
           c='red', s=200, alpha=0.75, marker='X')
plt.title('K-means s nesférickými shluky')
plt.show()

# Zkuste DBSCAN, který zvládne nesférické shluky
from sklearn.cluster import DBSCAN
dbscan = DBSCAN(eps=0.2, min_samples=5)
y_dbscan = dbscan.fit_predict(X_moons)

plt.figure(figsize=(10, 6))
```

### 2. Citlivost na inicializaci a odlehlé hodnoty

```python
# Ukázka citlivosti na inicializaci
def run_kmeans_multiple_times(X, n_clusters=3, n_runs=10):
    inertias = []
    for i in range(n_runs):
        kmeans = KMeans(n_clusters=n_clusters, init='random', random_state=i)
        kmeans.fit(X)
        inertias.append(kmeans.inertia_)
    return inertias

# Spuštění K-means vícekrát
inertias = run_kmeans_multiple_times(X_iris_scaled)

plt.figure(figsize=(10, 6))
plt.bar(range(1, len(inertias) + 1), inertias)
plt.xlabel('Běh')
plt.ylabel('Inertia')
plt.title('Výsledky K-means s různými inicializacemi')
plt.grid(True, alpha=0.3)
plt.show()

print(f"Minimální inertia: {min(inertias):.2f}, Maximální inertia: {max(inertias):.2f}")
print(f"Variace: {(max(inertias) - min(inertias)) / min(inertias) * 100:.2f}%")
```

### 3. Vyžaduje předem určit počet shluků

```python
# Použití ansámblového přístupu k odhadu počtu shluků
from sklearn.cluster import KMeans

def consensus_clustering(X, k_range=range(2, 11), n_runs=20):
    best_score = -1
    best_k = None
    
    for k in k_range:
        avg_silhouette = 0
        for i in range(n_runs):
            kmeans = KMeans(n_clusters=k, random_state=i*10)
            labels = kmeans.fit_predict(X)
            score = silhouette_score(X, labels)
            avg_silhouette += score
        
        avg_silhouette /= n_runs
        print(f"k={k}, Průměrné siluetové skóre: {avg_silhouette:.4f}")
        
        if avg_silhouette > best_score:
            best_score = avg_silhouette
            best_k = k
    
    return best_k, best_score

best_k, best_score = consensus_clustering(X_iris_scaled, k_range=range(2, 6))
print(f"\nNejlepší počet shluků: {best_k} s průměrným siluetovým skóre: {best_score:.4f}")
```

## 9. Shrnutí

Shlukování K-means je základním algoritmem učení bez učitele, který pomáhá najít strukturu v neoznačených datech. Klíčové body k zapamatování:

- K-means rozděluje data do K shluků minimalizací součtu čtverců vzdáleností uvnitř shluku
- Nejlépe funguje pro sférické shluky podobné velikosti a hustoty
- Určení optimálního počtu shluků je výzvou, kterou lze řešit metodami jako metoda lokte nebo siluetová analýza
- Předzpracování, zejména škálování příznaků, je pro správné fungování K-means důležité
- K-means má několik variant jako K-means++ (pro lepší inicializaci) a Mini-Batch K-means (pro velké datasety)
- Hodnocení lze provádět pomocí interních metrik (silueta, inertia) nebo externích metrik, pokud jsou k dispozici skutečná označení
- K-means má omezení: předpokládá sférické shluky, je citlivý na inicializaci a vyžaduje specifikaci K

Pro další téma zvažte prozkoumání pokročilejších shlukovacích algoritmů jako DBSCAN, hierarchické shlukování nebo Gaussovské směsové modely, které řeší některá z omezení K-means.
