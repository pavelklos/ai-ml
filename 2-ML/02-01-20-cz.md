## 1. Úvod do etiky ve strojovém učení

Systémy strojového učení stále více ovlivňují klíčové aspekty našich životů, od rozhodnutí o přijetí do zaměstnání a schvalování půjček až po zdravotní diagnózy a trestní řízení. S tímto rostoucím vlivem přichází významná etická odpovědnost. Etika v ML zahrnuje rozpoznávání a řešení morálních důsledků a společenských dopadů těchto technologií.

```python
# Jednoduchý příklad demonstrující, jak strojové učení může ovlivnit životy lidí
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

# Hypotetický dataset schvalování půjček
np.random.seed(42)
n_samples = 1000

# Vytvoření syntetického datasetu s potenciální zaujatostí
data = {
    'income': np.random.normal(50000, 20000, n_samples),
    'credit_score': np.random.normal(700, 100, n_samples),
    'age': np.random.normal(40, 12, n_samples),
    'gender': np.random.choice(['male', 'female'], n_samples),
    'loan_approved': None
}

# Zavedení zaujatosti: nižší míra schválení pro mladší žadatele a ženy
df = pd.DataFrame(data)
for i in range(n_samples):
    base_probability = 0.7
    if df.loc[i, 'age'] < 30:
        base_probability -= 0.3
    if df.loc[i, 'gender'] == 'female':
        base_probability -= 0.2
    df.loc[i, 'loan_approved'] = np.random.choice([1, 0], p=[base_probability, 1-base_probability])

print("Dataset s potenciální zaujatostí:")
print(df.head())
print("\nMíra schválení podle pohlaví:")
print(df.groupby('gender')['loan_approved'].mean())
print("\nMíra schválení podle věkové skupiny:")
print(df.groupby(pd.cut(df['age'], [0, 30, 45, 100]))['loan_approved'].mean())
```

Etické aspekty v ML nejsou jen filozofické otázky – zahrnují praktická rozhodnutí v oblasti sběru dat, návrhu algoritmů, nasazení modelů a hodnocení dopadů. Jako praktici ML musíme uznat, že naše technická rozhodnutí v sobě zahrnují hodnoty a mohou zesilovat společenské zaujatosti.

## 2. Zaujatost a spravedlnost v ML

Modely ML mohou uchovávat a zesilovat existující zaujatosti ve společnosti, pokud jsou trénovány na zaujatých datech nebo navrženy bez pečlivého zvážení spravedlnosti. Mohou se objevit různé typy zaujatosti:

- Výběrová zaujatost: Když trénovací data nereprezentují populaci
- Předsudková zaujatost: Když modely zahrnují existující společenské předsudky
- Měřicí zaujatost: Když sběr dat měří různé skupiny odlišně
- Algoritmická zaujatost: Když samotný algoritmus produkuje nespravedlivé výsledky

```python
# Detekce a měření zaujatosti v ML modelech
from sklearn.preprocessing import OneHotEncoder
from sklearn.metrics import confusion_matrix
import matplotlib.pyplot as plt
import seaborn as sns

# Příprava dat (konverze kategorických na číselné)
X = df.drop('loan_approved', axis=1)
y = df['loan_approved']

# One-hot kódování kategorických proměnných
encoder = OneHotEncoder(sparse_output=False, drop='first')
gender_encoded = encoder.fit_transform(X[['gender']])
X_encoded = pd.concat([
    X.drop('gender', axis=1),
    pd.DataFrame(gender_encoded, columns=['gender_female'])
], axis=1)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X_encoded, y, test_size=0.3, random_state=42)

# Trénování jednoduchého modelu
model = LogisticRegression()
model.fit(X_train, y_train)

# Vytvoření predikcí
y_pred = model.predict(X_test)

# Analýza spravedlnosti napříč skupinami pohlaví
test_with_gender = X_test.copy()
test_with_gender['gender'] = encoder.inverse_transform(X_test[['gender_female']])
test_with_gender['prediction'] = y_pred
test_with_gender['actual'] = y_test.values

# Výpočet metrik spravedlnosti
def calculate_fairness_metrics(df, group_col, pred_col, actual_col):
    """Výpočet různých metrik spravedlnosti napříč skupinami"""
    metrics = {}
    for group in df[group_col].unique():
        group_df = df[df[group_col] == group]
        tn, fp, fn, tp = confusion_matrix(group_df[actual_col], group_df[pred_col]).ravel()
        
        # True positive rate (Recall)
        tpr = tp / (tp + fn) if (tp + fn) > 0 else 0
        # False positive rate
        fpr = fp / (fp + tn) if (fp + tn) > 0 else 0
        # Accuracy
        acc = (tp + tn) / (tp + tn + fp + fn)
        
        metrics[group] = {'TPR': tpr, 'FPR': fpr, 'Accuracy': acc}
    
    return metrics

fairness_metrics = calculate_fairness_metrics(test_with_gender, 'gender', 'prediction', 'actual')
print("\nMetriky spravedlnosti napříč skupinami pohlaví:")
for group, metrics in fairness_metrics.items():
    print(f"{group}: {metrics}")

# Vizualizace rozdílů v metrikách
groups = list(fairness_metrics.keys())
tpr_values = [metrics['TPR'] for metrics in fairness_metrics.values()]
fpr_values = [metrics['FPR'] for metrics in fairness_metrics.values()]
acc_values = [metrics['Accuracy'] for metrics in fairness_metrics.values()]

plt.figure(figsize=(10, 6))
width = 0.25
x = np.arange(len(groups))
plt.bar(x - width, tpr_values, width, label='True Positive Rate')
plt.bar(x, fpr_values, width, label='False Positive Rate')
plt.bar(x + width, acc_values, width, label='Accuracy')
plt.xlabel('Pohlaví')
plt.ylabel('Hodnota')
plt.title('Metriky spravedlnosti podle pohlaví')
plt.xticks(x, groups)
plt.legend()
plt.tight_layout()
plt.show()
```

### Zmírnění zaujatosti

Existuje několik přístupů k zmírnění zaujatosti:

1. **Techniky před zpracováním**: Úprava trénovacích dat k odstranění zaujatosti
2. **Techniky během zpracování**: Začlenění omezení spravedlnosti během trénování modelu
3. **Techniky po zpracování**: Úprava výstupů modelu pro zajištění spravedlivých predikcí

```python
# Příklad techniky spravedlnosti při předzpracování: Převážení
from sklearn.utils.class_weight import compute_sample_weight

# Výpočet vah pro vyvážení tříd napříč pohlavím
combined = X_train.copy()
combined['gender'] = encoder.inverse_transform(X_train[['gender_female']])
combined['target'] = y_train.values

# Výpočet vzorkovacích vah pro vyvážení míry schválení napříč pohlavími
weights = np.ones(len(combined))
gender_groups = combined.groupby('gender')
for gender, group in gender_groups:
    pos_rate = group['target'].mean()
    target_pos_rate = 0.5  # Cílová míra schválení 50 % (vyvážená)
    
    # Úprava vah
    pos_indices = group.index[group['target'] == 1]
    neg_indices = group.index[group['target'] == 0]
    
    if pos_rate > 0 and pos_rate < 1:
        weights[pos_indices] = target_pos_rate / pos_rate
        weights[neg_indices] = (1 - target_pos_rate) / (1 - pos_rate)

# Trénování modelu s vahami
weighted_model = LogisticRegression()
weighted_model.fit(X_train, y_train, sample_weight=weights)

# Vyhodnocení na testovací sadě
weighted_preds = weighted_model.predict(X_test)

# Porovnání původního a váženého modelu
test_with_both_preds = test_with_gender.copy()
test_with_both_preds['weighted_pred'] = weighted_preds

# Výpočet metrik spravedlnosti pro oba modely
fairness_before = calculate_fairness_metrics(
    test_with_both_preds, 'gender', 'prediction', 'actual')
fairness_after = calculate_fairness_metrics(
    test_with_both_preds, 'gender', 'weighted_pred', 'actual')

print("\nPorovnání spravedlnosti před a po zmírnění:")
for group in fairness_before.keys():
    print(f"{group} - Před: TPR={fairness_before[group]['TPR']:.3f}, Po: TPR={fairness_after[group]['TPR']:.3f}")
```

## 3. Soukromí a ochrana dat

Obavy o soukromí v ML zahrnují:

- Použití citlivých osobních údajů bez informovaného souhlasu
- Únik dat prostřednictvím výstupů modelu
- Riziko opětovné identifikace z anonymizovaných dat
- Bezpečnostní zranitelnosti v ML systémech

```python
# Příklad ochrany soukromí pomocí diferenciální soukromí
import numpy as np
from sklearn.linear_model import LinearRegression

# Syntetický citlivý dataset (predikce příjmů)
np.random.seed(42)
n = 1000
X_sensitive = np.random.normal(size=(n, 5))  # 5 příznaků
true_coef = np.array([3.5, 1.2, -2.1, 0.8, -0.5])
y_sensitive = X_sensitive.dot(true_coef) + np.random.normal(scale=1.0, size=n)

# Funkce pro přidání šumu diferenciální soukromí
def add_differential_privacy(data, epsilon=1.0, sensitivity=1.0):
    """Přidání Laplaceova šumu pro diferenciální soukromí"""
    # Parametr měřítka pro Laplaceovo rozdělení
    scale = sensitivity / epsilon
    noise = np.random.laplace(0, scale, data.shape)
    return data + noise

# Aplikace diferenciálního soukromí na příznaky a cílovou proměnnou
epsilon = 0.5  # Parametr soukromí (menší = více soukromí, méně přesné)
X_private = add_differential_privacy(X_sensitive, epsilon)
y_private = add_differential_privacy(y_sensitive, epsilon)

# Trénování modelů na původních i soukromých datech
model_original = LinearRegression().fit(X_sensitive, y_sensitive)
model_private = LinearRegression().fit(X_private, y_private)

# Porovnání koeficientů
print("Koeficienty původního modelu:", model_original.coef_)
print("Koeficienty soukromého modelu:", model_private.coef_)
print("Skutečné koeficienty:", true_coef)

# Vyhodnocení kompromisu mezi soukromím a užitečností
from sklearn.metrics import mean_squared_error

# Vygenerování testovacích dat (neprivatizovaných)
X_test = np.random.normal(size=(500, 5))
y_test = X_test.dot(true_coef) + np.random.normal(scale=1.0, size=500)

# Porovnání predikcí
mse_original = mean_squared_error(y_test, model_original.predict(X_test))
mse_private = mean_squared_error(y_test, model_private.predict(X_test))

print(f"MSE s původními daty: {mse_original:.4f}")
print(f"MSE s privatizovanými daty: {mse_private:.4f}")
print(f"Cena soukromí: {(mse_private - mse_original)/mse_original:.2%} zvýšení chyby")
```

### Techniky strojového učení zachovávající soukromí

Několik technik může pomoci chránit soukromí:

- **Federované učení**: Trénování modelů napříč více zařízeními bez centralizace dat
- **Diferenciální soukromí**: Přidání šumu k datům nebo modelům pro ochranu jednotlivců
- **Zabezpečený výpočet více stran**: Umožňuje více stranám společně vypočítat funkci bez odhalení vstupů
- **Homomorfní šifrování**: Provádění výpočtů na šifrovaných datech

## 4. Transparentnost a vysvětlitelnost

Modely ML typu černé skříňky mohou být obtížně srozumitelné a důvěryhodné. Vysvětlitelná umělá inteligence (XAI) si klade za cíl učinit rozhodnutí modelů srozumitelná pro lidi.

```python
# Příklad interpretovatelnosti modelu pomocí SHAP hodnot
import shap
from sklearn.ensemble import RandomForestClassifier

# Vytvoření složitějšího modelu
X_train_scaled = (X_train - X_train.mean()) / X_train.std()
X_test_scaled = (X_test - X_train.mean()) / X_train.std()

rf_model = RandomForestClassifier(n_estimators=100, random_state=42)
rf_model.fit(X_train_scaled, y_train)

# Vytvoření SHAP vysvětlení
explainer = shap.TreeExplainer(rf_model)
shap_values = explainer.shap_values(X_test_scaled.iloc[:100])  # Pro efektivitu beru prvních 100

# Vizualizace důležitosti příznaků
plt.figure(figsize=(10, 6))
shap.summary_plot(shap_values, X_test_scaled.iloc[:100], plot_type="bar", show=False)
plt.title("Důležitost příznaků na základě SHAP hodnot")
plt.tight_layout()
plt.show()

# Vizualizace vlivu příznaků na predikci pro jeden příklad
plt.figure(figsize=(10, 6))
sample_idx = 0
shap.force_plot(explainer.expected_value[1], shap_values[1][sample_idx,:], 
                X_test_scaled.iloc[sample_idx], matplotlib=True, show=False)
plt.title("SHAP Force Plot pro jednu predikci")
plt.tight_layout()
plt.show()
```

Transparentnost zahrnuje jak technické, tak organizační přístupy:

- **Dokumentace modelu**: Jasné informace o trénovacích datech, omezeních a výkonu
- **Interpretovatelné modely**: Použití jednodušších modelů nebo technik k vysvětlení složitých modelů
- **Transparentnost procesu**: Jasné informace o tom, jak a kdy jsou ML systémy nasazovány
- **Auditní záznamy**: Vedení záznamů o rozhodnutích modelů a jejich zdůvodnění

## 5. Odpovědnost v ML systémech

Odpovědnost znamená stanovení zodpovědnosti za ML systémy a jejich dopady. To zahrnuje:

- Identifikaci odpovědných osob, když ML systémy způsobí škodu
- Vytvoření mechanismů pro řešení stížností
- Udržování lidského dohledu nad automatizovanými rozhodnutími
- Stanovení řídících rámců pro vývoj a nasazení ML

```python
# Příklad monitorování modelu a upozornění na posun dat
from scipy.stats import ks_2samp

# Funkce pro detekci posunu v distribuci dat
def detect_distribution_drift(reference_data, current_data, threshold=0.05):
    """
    Detekuje posun mezi referenčními a aktuálními distribucemi dat pomocí KS testu
    Vrací názvy příznaků s významným posunem
    """
    drifted_features = []
    
    for column in reference_data.columns:
        # Provedení Kolmogorov-Smirnov testu
        ks_statistic, p_value = ks_2samp(reference_data[column], current_data[column])
        
        # Pokud je p-hodnota pod prahem, distribuce jsou významně odlišné
        if p_value < threshold:
            drifted_features.append((column, p_value, ks_statistic))
            
    return drifted_features

# Simulace posunu dat (změna rozložení příznaků)
X_train_reference = X_train.copy()
X_drifted = X_test.copy()

# Zavedení umělého posunu ve věku a příjmu
X_drifted['age'] = X_drifted['age'] * 1.2  # Věk zvýšen o 20 %
X_drifted['income'] = X_drifted['income'] * 0.8  # Příjem snížen o 20 %

# Detekce posunu
drifts = detect_distribution_drift(X_train_reference, X_drifted)

# Vykazování zjištění
if drifts:
    print("Posun dat byl detekován v následujících příznacích:")
    for feature, p_value, statistic in drifts:
        print(f"- {feature}: KS statistika = {statistic:.4f}, p-hodnota = {p_value:.6f}")
    
    # Implementace výstražného systému
    if any(stat > 0.3 for _, _, stat in drifts):
        print("KRITICKÉ UPOZORNĚNÍ: Byl detekován významný posun dat! Doporučuje se přetrénování modelu.")
else:
    print("Nebyl detekován žádný významný posun dat.")

# Vizualizace posunu v distribucích
plt.figure(figsize=(15, 5))

plt.subplot(1, 2, 1)
sns.histplot(X_train_reference['age'], kde=True, color='blue', label='Reference')
sns.histplot(X_drifted['age'], kde=True, color='red', label='Aktuální')
plt.title('Porovnání distribuce věku')
plt.legend()

plt.subplot(1, 2, 2)
sns.histplot(X_train_reference['income'], kde=True, color='blue', label='Reference')
sns.histplot(X_drifted['income'], kde=True, color='red', label='Aktuální')
plt.title('Porovnání distribuce příjmu')
plt.legend()

plt.tight_layout()
plt.show()
```

## 6. Environmentální dopad ML

Velké ML modely, zejména hluboké učení, mohou mít významné environmentální náklady z důvodu:

- Vysoké spotřeby energie během trénování
- Uhlíkové stopy výpočetních zdrojů
- Životního cyklu hardwaru a elektronického odpadu ze specializovaného ML hardwaru

```python
# Odhad uhlíkové stopy trénování modelu
import time
import psutil
import pandas as pd
import numpy as np
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.model_selection import GridSearchCV

def estimate_carbon_emissions(power_consumption_watts, duration_hours, carbon_intensity=475):
    """
    Odhad emisí uhlíku ze spotřeby energie
    
    Args:
        power_consumption_watts: Spotřeba energie ve wattech
        duration_hours: Doba trvání v hodinách
        carbon_intensity: Intenzita uhlíku v gCO2/kWh (liší se podle regionu)
    
    Returns:
        Emise uhlíku v kg CO2
    """
    energy_kwh = power_consumption_watts * duration_hours / 1000
    emissions_kg = energy_kwh * carbon_intensity / 1000
    return emissions_kg

# Funkce pro sledování využití CPU během trénování
def train_with_metrics(model, X, y, params=None):
    """Trénování modelu a sledování výpočetních metrik"""
    start_time = time.time()
    
    if params:
        # Použití grid search s křížovou validací
        grid_search = GridSearchCV(model, params, cv=3)
        grid_search.fit(X, y)
        best_model = grid_search.best_estimator_
    else:
        # Trénování jednoho modelu
        model.fit(X, y)
        best_model = model
    
    duration = time.time() - start_time
    
    # Odhad spotřeby energie (velmi hrubá aproximace)
    # Lepší by bylo s aktuálním monitorováním energie
    avg_cpu_percent = psutil.cpu_percent()
    estimated_power = avg_cpu_percent * 1.5  # Hrubý odhad: 1,5 W na % využití CPU
    
    metrics = {
        'duration_seconds': duration,
        'duration_hours': duration / 3600,
        'avg_cpu_percent': avg_cpu_percent,
        'estimated_power_watts': estimated_power,
        'estimated_carbon_kg': estimate_carbon_emissions(
            estimated_power, duration / 3600)
    }
    
    return best_model, metrics

# Simulace trénování jednoduchého vs. komplexního modelu
simple_model = GradientBoostingClassifier(n_estimators=50)
complex_model = GradientBoostingClassifier(n_estimators=500)

# Trénování obou modelů a sledování metrik
simple_model, simple_metrics = train_with_metrics(simple_model, X_train, y_train)
complex_model, complex_metrics = train_with_metrics(complex_model, X_train, y_train)

# Porovnání metrik
print("Metriky jednoduchého modelu:")
for key, value in simple_metrics.items():
    print(f"- {key}: {value:.6f}")

print("\nMetriky komplexního modelu:")
for key, value in complex_metrics.items():
    print(f"- {key}: {value:.6f}")

print(f"\nZvýšení uhlíku: {complex_metrics['estimated_carbon_kg']/simple_metrics['estimated_carbon_kg']:.1f}x")

# Porovnání výkonu modelu
simple_accuracy = simple_model.score(X_test, y_test)
complex_accuracy = complex_model.score(X_test, y_test)

print(f"\nPřesnost jednoduchého modelu: {simple_accuracy:.4f}")
print(f"Přesnost komplexního modelu: {complex_accuracy:.4f}")
print(f"Zlepšení přesnosti: {(complex_accuracy-simple_accuracy)*100:.2f} procentních bodů")

# Výpočet "efektivity" (přesnost na kg CO2)
simple_efficiency = simple_accuracy / simple_metrics['estimated_carbon_kg']
complex_efficiency = complex_accuracy / complex_metrics['estimated_carbon_kg']

print(f"\nEfektivita jednoduchého modelu: {simple_efficiency:.4f} přesnost/kg CO2")
print(f"Efektivita komplexního modelu: {complex_efficiency:.4f} přesnost/kg CO2")
```

```python
# Příklad použití AI Fairness 360 toolkitu
from aif360.datasets import BinaryLabelDataset
from aif360.metrics import BinaryLabelDatasetMetric
from aif360.algorithms.preprocessing import Reweighing

# Konverze našich dat do formátu AIF360
train_data = X_train.copy()
train_data['gender'] = encoder.inverse_transform(X_train[['gender_female']])

# Definice chráněného atributu (pohlaví) a privilegované skupiny (muž)
privileged_groups = [{'gender': 'male'}]

# Konverze na dataset AIF360

                                        privileged_groups=privileged_groups)

# Aplikace algoritmu spravedlnosti
rw = Reweighing(unprivileged_groups=unprivileged_groups,
                privileged_groups=privileged_groups)
dataset_transformed = rw.fit_transform(dataset)

# Měření metrik po zmírnění
metrics_after = BinaryLabelDatasetMetric(dataset_transformed, 
                                       unprivileged_groups=unprivileged_groups,
                                       privileged_groups=privileged_groups)

# Zobrazení metrik
print("Metriky spravedlnosti před zmírněním:")
print("- Disparate impact:", metrics_before.disparate_impact())
print("- Statistical parity difference:", metrics_before.statistical_parity_difference())

print("\nMetriky spravedlnosti po zmírnění:")
print("- Disparate impact:", metrics_after.disparate_impact())
print("- Statistical parity difference:", metrics_after.statistical_parity_difference())
```

## 9. Shrnutí

Etické aspekty ve strojovém učení se dotýkají každého aspektu životního cyklu ML:

1. **Zaujatost a spravedlnost**: Modely mohou uchovávat a zesilovat společenské zaujatosti, pokud nejsou pečlivě navrženy a monitorovány.
   
2. **Soukromí a ochrana dat**: ML systémy musí respektovat soukromí jednotlivců a zabezpečit jejich data.
   
3. **Transparentnost a vysvětlitelnost**: Zainteresované strany potřebují porozumět, jak a proč ML systémy činí rozhodnutí.
   
4. **Odpovědnost**: Pro důvěryhodné ML jsou nezbytné jasné struktury odpovědnosti a řízení.
   
5. **Environmentální dopad**: Uhlíková stopa trénování a inferenční fáze ML vyžaduje pozornost.

Jak ML nadále transformuje společnost, etická implementace není volitelná, ale nezbytná. To znamená:

- Přijetí etických rámců a principů již na začátku vývoje
- Využívání nástrojů, které pomáhají detekovat a zmírňovat problémy zaujatosti, soukromí a transparentnosti
- Zavedení procesů pro průběžné monitorování a zlepšování
- Zapojení různých zainteresovaných stran do návrhu a hodnocení systému

V konečném důsledku vyžaduje etické ML jak technická řešení, tak organizační závazek. Integrací etických aspektů v rámci celého životního cyklu ML můžeme budovat systémy, které posunují technologie vpřed při respektování lidských práv, podporují spravedlnost a získávají důvěru veřejnosti.
