## Úvod do transfer learningu

Transfer learning je technika strojového učení, při které je model vyvinutý pro jeden úkol znovu použit jako výchozí bod pro model na jiný úkol. Tento přístup využívá znalosti získané při řešení jednoho problému a aplikuje je na jiný, ale související problém, čímž výrazně zkracuje čas, výpočetní zdroje a množství dat potřebných pro trénink.

### Klíčové výhody transfer learningu

1. **Kratší doba tréninku**: Začátek s předtrénovanými váhami konverguje rychleji než náhodná inicializace
2. **Menší požadavky na data**: Učení z menších datasetů díky využití předtrénovaných funkcí
3. **Lepší výkon**: Často dosahuje vyšší přesnosti než trénink od základu
4. **Ekologické přínosy**: Nižší výpočetní zdroje a spotřeba energie

### Hlavní strategie transfer learningu

1. **Extrakce příznaků**: Zmrazení předtrénovaných vrstev a trénování pouze nového klasifikátoru na vrchu
2. **Fine-tuning posledních vrstev**: Zmrazení prvních vrstev a opětovný trénink pozdějších vrstev
3. **Progresivní fine-tuning**: Postupné odmrazování vrstev odshora dolů
4. **Kompletní fine-tuning**: Opětovný trénink celé sítě s malou learning rate

## Techniky fine-tuningu

Fine-tuning přizpůsobuje předtrénovaný model specifickému úkolu pokračováním tréninku s novým datasetem. Různé techniky mohou zlepšit efektivitu fine-tuningu.

```python
# Příklad technik fine-tuningu v TensorFlow/Keras

import tensorflow as tf
from tensorflow.keras.applications import ResNet50
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.callbacks import ReduceLROnPlateau, EarlyStopping

def create_fine_tuned_model(num_classes=10, learning_rate=0.0001, 
                          fine_tune_layers=3, input_shape=(224, 224, 3)):
    """
    Vytvoření fine-tuned modelu s použitím ResNet50 jako základního modelu
    
    Args:
        num_classes: Počet cílových tříd
        learning_rate: Počáteční learning rate
        fine_tune_layers: Počet horních vrstev k odmrazení 
        input_shape: Vstupní tvar obrázků
    
    Returns:
        Zkompilovaný model připravený na fine-tuning
    """
    # Načtení předtrénovaného modelu bez horní klasifikační vrstvy
    base_model = ResNet50(weights='imagenet', include_top=False, 
                         input_shape=input_shape)
    
    # Zmrazení všech vrstev
    for layer in base_model.layers:
        layer.trainable = False
    
    # Odmrazení posledních n vrstev pro fine-tuning
    if fine_tune_layers > 0:
        for layer in base_model.layers[-fine_tune_layers:]:
            layer.trainable = True
    
    # Přidání nového klasifikátoru na vrch
    x = base_model.output
    x = GlobalAveragePooling2D()(x)
    x = Dense(1024, activation='relu')(x)
    predictions = Dense(num_classes, activation='softmax')(x)
    
    # Vytvoření fine-tuned modelu
    model = Model(inputs=base_model.input, outputs=predictions)
    
    # Použití diskriminativní learning rate
    # Nižší learning rate pro předtrénované vrstvy, vyšší pro nové vrstvy
    model.compile(optimizer=Adam(learning_rate=learning_rate),
                 loss='categorical_crossentropy',
                 metrics=['accuracy'])
    
    return model

# Vytvoření modelu s odmrazenými posledními 3 vrstvami
model = create_fine_tuned_model(num_classes=10, fine_tune_layers=3)

# Nastavení callbacks pro lepší fine-tuning
callbacks = [
    ReduceLROnPlateau(monitor='val_loss', factor=0.2, patience=3, min_lr=1e-6),
    EarlyStopping(monitor='val_loss', patience=5, restore_best_weights=True)
]

# Příklad tréninku modelu (zakomentováno, aby nedošlo k provedení)
"""
model.fit(
    train_dataset,
    validation_data=val_dataset,
    epochs=20,
    callbacks=callbacks
)
"""

# Výpis architektury modelu pro vizualizaci trénovatelných vs. netrénovatelných vrstev
print(f"Celkový počet vrstev: {len(model.layers)}")
print(f"Trénovatelné váhy: {len(model.trainable_weights)}")
print(f"Netrénovatelné váhy: {len(model.non_trainable_weights)}")
```

### Klíčové techniky fine-tuningu

1. **Diskriminativní learning rates**: Použití menších learning rates pro předtrénované vrstvy a větších pro nové vrstvy
2. **Postupné odmrazování**: Začátek trénování pouze horních vrstev, pak postupné odmrazování dřívějších vrstev
3. **Plánování learning rate**: Snižování learning rate v průběhu tréninku
4. **Weight decay**: Aplikace regularizace k prevenci katastrofického zapomínání
5. **Early stopping**: Zastavení tréninku, když se výkon validace přestane zlepšovat

## Příklad transfer learningu v počítačovém vidění

Počítačové vidění je jednou z nejběžnějších oblastí pro transfer learning, využívající modely předtrénované na velkých datasetech obrázků jako ImageNet.

```python
# Kompletní příklad: Transfer learning pro klasifikaci obrázků s TensorFlow/Keras

import tensorflow as tf
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.applications import MobileNetV2
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam

# Parametry
IMG_SIZE = (224, 224)
BATCH_SIZE = 32
NUM_CLASSES = 5  # Příklad: 5 typů květin
EPOCHS = 10

# 1. Příprava dat s augmentací
train_datagen = ImageDataGenerator(
    rescale=1./255,
    rotation_range=20,
    width_shift_range=0.2,
    height_shift_range=0.2,
    horizontal_flip=True,
    validation_split=0.2
)

# Příklad cesty - nahraďte svou cestou k datům
data_dir = "path/to/flower/dataset" 

# Vytvoření trénovacích a validačních datasetů
train_dataset = train_datagen.flow_from_directory(
    data_dir,
    target_size=IMG_SIZE,
    batch_size=BATCH_SIZE,
    class_mode='categorical',
    subset='training'
)

validation_dataset = train_datagen.flow_from_directory(
    data_dir,
    target_size=IMG_SIZE,
    batch_size=BATCH_SIZE,
    class_mode='categorical',
    subset='validation'
)

# 2. Vytvoření základního modelu MobileNetV2
base_model = MobileNetV2(weights='imagenet', include_top=False, 
                        input_shape=(224, 224, 3))

# 3. Zmrazení základního modelu
base_model.trainable = False

# 4. Vytvoření nového modelu na vrchu
inputs = tf.keras.Input(shape=(224, 224, 3))
x = base_model(inputs, training=False)
x = GlobalAveragePooling2D()(x)
x = Dense(128, activation='relu')(x)
outputs = Dense(NUM_CLASSES, activation='softmax')(x)
model = Model(inputs, outputs)

# 5. Kompilace
model.compile(
    optimizer=Adam(learning_rate=0.001),
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# 6. Trénink horní vrstvy
model.fit(
    train_dataset,
    steps_per_epoch=train_dataset.samples // BATCH_SIZE,
    validation_data=validation_dataset,
    validation_steps=validation_dataset.samples // BATCH_SIZE,
    epochs=5
)

# 7. Fine-tuning
# Odmrazení horních vrstev základního modelu
base_model.trainable = True
for layer in base_model.layers[:-4]:
    layer.trainable = False
    
# Rekompilace s nižším learning rate
model.compile(
    optimizer=Adam(learning_rate=0.0001),  # Mnohem nižší learning rate
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# Pokračování tréninku
model.fit(
    train_dataset,
    steps_per_epoch=train_dataset.samples // BATCH_SIZE,
    validation_data=validation_dataset,
    validation_steps=validation_dataset.samples // BATCH_SIZE,
    epochs=EPOCHS
)

# Uložení fine-tuned modelu
model.save('fine_tuned_flower_classifier.h5')

# 8. Vyhodnocení modelu
loss, accuracy = model.evaluate(validation_dataset)
print(f"Validační přesnost: {accuracy:.4f}")
```

## Příklad transfer learningu v NLP

Zpracování přirozeného jazyka (NLP) zaznamenalo revoluční pokroky díky transfer learningu s modely jako BERT, GPT a RoBERTa.

```python
# Transfer learning pro klasifikaci textu s Hugging Face transformers

import torch
from torch.utils.data import Dataset, DataLoader
from transformers import BertTokenizer, BertForSequenceClassification, AdamW
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report
import numpy as np
import pandas as pd

# Příklad datasetu (nahraďte vlastním)
texts = [
    "Tento film jsem naprosto miloval, byl fantastický!",
    "Služby v této restauraci byly hrozné.",
    "Produkt funguje podle očekávání, jsem celkem spokojený.",
    "Nejhorší nákup, který jsem kdy udělal, naprostá ztráta peněz.",
    "Je to ucházející, nic zvláštního, ale svůj účel splní."
]
labels = [1, 0, 1, 0, 1]  # 1: pozitivní, 0: negativní

# Rozdělení dat
train_texts, val_texts, train_labels, val_labels = train_test_split(
    texts, labels, test_size=0.2, random_state=42
)

# Načtení předtrénovaného tokenizeru
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')

# Tokenizace dat
train_encodings = tokenizer(train_texts, truncation=True, padding=True, max_length=128)
val_encodings = tokenizer(val_texts, truncation=True, padding=True, max_length=128)

# Vytvoření torch datasetu
class SentimentDataset(Dataset):
    def __init__(self, encodings, labels):
        self.encodings = encodings
        self.labels = labels

    def __getitem__(self, idx):
        item = {key: torch.tensor(val[idx]) for key, val in self.encodings.items()}
        item['labels'] = torch.tensor(self.labels[idx])
        return item

    def __len__(self):
        return len(self.labels)

train_dataset = SentimentDataset(train_encodings, train_labels)
val_dataset = SentimentDataset(val_encodings, val_labels)

# Vytvoření dataloaderů
train_loader = DataLoader(train_dataset, batch_size=2, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=2)

# Načtení předtrénovaného modelu
model = BertForSequenceClassification.from_pretrained('bert-base-uncased', num_labels=2)

# Nastavení optimizeru s weight decay
optimizer = AdamW(model.parameters(), lr=5e-5, weight_decay=0.01)

# Příprava na trénink
device = torch.device('cuda') if torch.cuda.is_available() else torch.device('cpu')
model.to(device)

# Trénovací smyčka
model.train()
for epoch in range(3):  # 3 epochy
    for batch in train_loader:
        # Forward pass
        optimizer.zero_grad()
        input_ids = batch['input_ids'].to(device)
        attention_mask = batch['attention_mask'].to(device)
        labels = batch['labels'].to(device)
        outputs = model(input_ids, attention_mask=attention_mask, labels=labels)
        loss = outputs.loss
        
        # Backward pass
        loss.backward()
        optimizer.step()

# Evaluace
model.eval()
predictions = []
references = []

for batch in val_loader:
    input_ids = batch['input_ids'].to(device)
    attention_mask = batch['attention_mask'].to(device)
    labels = batch['labels'].to(device)
    
    with torch.no_grad():
        outputs = model(input_ids, attention_mask=attention_mask)
    
    logits = outputs.logits
    pred = torch.argmax(logits, dim=1).cpu().numpy()
    predictions.extend(pred)
    references.extend(labels.cpu().numpy())

# Tisk výsledků
print(f"Přesnost: {accuracy_score(references, predictions):.4f}")
print(classification_report(references, predictions))

# Uložení fine-tuned modelu
model.save_pretrained("fine_tuned_bert_sentiment")
tokenizer.save_pretrained("fine_tuned_bert_sentiment")
```

## Transfer learning v oblasti zvuku a časových řad

I když je transfer learning nejčastěji spojován s obrázky a textem, stále častěji se aplikuje i na jiné domény, jako je zpracování zvuku a analýza časových řad.

```python
# Příklad transfer learningu pro klasifikaci zvuku s TensorFlow

import tensorflow as tf
import tensorflow_hub as hub
import tensorflow_io as tfio
import numpy as np
import matplotlib.pyplot as plt

# Funkce pro načtení a předzpracování zvukových souborů
def load_audio(file_path, target_sample_rate=16000):
    """Načtení zvukového souboru a převod na pevnou vzorkovací frekvenci"""
    # Čtení souboru
    audio_binary = tf.io.read_file(file_path)
    
    # Dekódování zvuku
    audio, sample_rate = tf.audio.decode_wav(audio_binary)
    audio = tf.squeeze(audio, axis=-1)
    
    # Převzorkování, pokud je potřeba
    if sample_rate != target_sample_rate:
        audio = tfio.audio.resample(audio, rate_in=sample_rate, rate_out=target_sample_rate)
        
    return audio, target_sample_rate

# Funkce pro převod zvuku na spektrogram
def get_spectrogram(audio, sample_rate=16000, frame_length=255, frame_step=128):
    """Převod zvuku na spektrogram"""
    # Převod na spektrogram
    spectrogram = tf.signal.stft(
        audio, frame_length=frame_length, frame_step=frame_step
    )
    
    # Převod na magnitudový spektrogram
    spectrogram = tf.abs(spectrogram)
    
    # Převod na mel spektrogram
    num_spectrogram_bins = spectrogram.shape[-1]
    lower_edge_hertz, upper_edge_hertz = 80.0, 7600.0
    num_mel_bins = 128
    linear_to_mel_weight_matrix = tf.signal.linear_to_mel_weight_matrix(
        num_mel_bins, num_spectrogram_bins, sample_rate, lower_edge_hertz,
        upper_edge_hertz)
    mel_spectrogram = tf.tensordot(
        spectrogram, linear_to_mel_weight_matrix, 1)
    
    # Převod na logaritmický mel spektrogram
    log_mel_spectrogram = tf.math.log(mel_spectrogram + 1e-6)
    
    # Přidání dimenzí dávky a kanálu
    log_mel_spectrogram = tf.expand_dims(log_mel_spectrogram, axis=0)  # Přidání dimenze dávky
    log_mel_spectrogram = tf.expand_dims(log_mel_spectrogram, axis=-1)  # Přidání dimenze kanálu
    
    return log_mel_spectrogram

# Načtení předtrénovaného zvukového modelu z TensorFlow Hub
yamnet_model = hub.load('https://tfhub.dev/google/yamnet/1')

# Extrakce části pro extrakci příznaků
def extract_embedding(audio_data, sample_rate):
    """Extrahuje embedding ze zvuku pomocí YAMNet"""
    # Zajištění, že audio je float a normalizované
    audio_data = tf.cast(audio_data, tf.float32) / 32768.0
    
    # Získání embeddingů
    scores, embeddings, log_mel_spectrogram = yamnet_model(audio_data)
    return embeddings

# Vytvoření nového modelu s využitím předtrénovaných embeddingů
def build_audio_classifier(num_classes=10, trainable_base=False):
    """Vytvoření klasifikátoru na základě YAMNet embeddingů"""
    # Vstup pro surový zvuk
    input_audio = tf.keras.layers.Input(shape=(None,), dtype=tf.float32, name='audio')
    
    # Vlastní vrstva pro extrakci embeddingů
    class YAMNetEmbedding(tf.keras.layers.Layer):
        def __init__(self, trainable=False):
            super(YAMNetEmbedding, self).__init__()
            self.yamnet = hub.load('https://tfhub.dev/google/yamnet/1')
            self.trainable = trainable
            
        def call(self, audio):
            # Normalizace zvuku
            audio = tf.cast(audio, tf.float32) / 32768.0
            
            # Získání embeddingů (vrací scores, embeddings, spectrograms)
            _, embeddings, _ = self.yamnet(audio)
            
            # Průměrování embeddingů v čase
            embeddings = tf.reduce_mean(embeddings, axis=0)
            embeddings = tf.expand_dims(embeddings, 0)
            
            return embeddings
    
    # Extrakce embeddingů
    embedding_layer = YAMNetEmbedding(trainable=trainable_base)
    embeddings = embedding_layer(input_audio)
    
    # Klasifikační hlavice
    x = tf.keras.layers.Dense(512, activation='relu')(embeddings)
    x = tf.keras.layers.Dropout(0.2)(x)
    outputs = tf.keras.layers.Dense(num_classes, activation='softmax')(x)
    
    # Vytvoření modelu
    model = tf.keras.Model(inputs=input_audio, outputs=outputs)
    
    return model

# Vytvoření a kompilace modelu
audio_model = build_audio_classifier(num_classes=5)
audio_model.compile(
    optimizer=tf.keras.optimizers.Adam(1e-4),
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)
```

## Nejlepší postupy a časté chyby

Úspěšný transfer learning vyžaduje znalost častých chyb a osvědčených postupů.

```python
# Příklad kódu: Implementace nejlepších postupů

import tensorflow as tf
from tensorflow.keras.applications import ResNet50V2
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D, Dropout
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.callbacks import (
    EarlyStopping, 
    ReduceLROnPlateau, 
    ModelCheckpoint,
    TensorBoard
)
from sklearn.metrics import classification_report
import datetime
import os

def transfer_learn_best_practices(
    train_data, 
    val_data,
    test_data=None,
    base_model_name="ResNet50V2",
    num_classes=10,
    img_size=(224, 224, 3),
    batch_size=32,
    initial_lr=1e-4,
    min_lr=1e-7,
    dropout_rate=0.3,
    output_dir="model_output"
):
    """
    Implementace transfer learningu s nejlepšími postupy
    
    Args:
        train_data: Trénovací data (tf.data.Dataset nebo podobné)
        val_data: Validační data
        test_data: Testovací data (volitelné)
        base_model_name: Název základního modelu k použití
        num_classes: Počet cílových tříd
        img_size: Rozměry vstupního obrázku
        batch_size: Velikost dávky pro trénink
        initial_lr: Počáteční learning rate
        min_lr: Minimální learning rate pro plánovač
        dropout_rate: Míra dropout pro regularizaci
        output_dir: Adresář pro ukládání modelů a logů
    
    Returns:
        Trénovaný model a historii tréninku
    """
    # 1. Vytvoření výstupního adresáře
    os.makedirs(output_dir, exist_ok=True)
    log_dir = os.path.join(output_dir, "logs", datetime.datetime.now().strftime("%Y%m%d-%H%M%S"))
    model_dir = os.path.join(output_dir, "models")
    os.makedirs(model_dir, exist_ok=True)
    
    # 2. Načtení předtrénovaného základního modelu
    if base_model_name == "ResNet50V2":
        base_model = ResNet50V2(weights='imagenet', include_top=False, input_shape=img_size)
    else:
        # Přidání podpory pro další modely podle potřeby
        raise ValueError(f"Nepodporovaný základní model: {base_model_name}")
    
    # 3. Vytvoření architektury modelu s regularizací
    x = base_model.output
    x = GlobalAveragePooling2D()(x)
    x = Dense(512, activation='relu')(x)
    x = Dropout(dropout_rate)(x)
    x = Dense(256, activation='relu')(x)
    x = Dropout(dropout_rate/2)(x)
    predictions = Dense(num_classes, activation='softmax')(x)
    model = Model(inputs=base_model.input, outputs=predictions)
    
    # 4. Zmrazení vrstev základního modelu (fáze extrakce příznaků)
    for layer in base_model.layers:
        layer.trainable = False
    
    # 5. Nastavení callbacks
    callbacks = [
        # Early stopping pro prevenci přetrénování
        EarlyStopping(
            monitor='val_loss',
            patience=5,
            restore_best_weights=True,
            verbose=1
        ),
        # Snížení learning rate při stagnaci tréninku
        ReduceLROnPlateau(
            monitor='val_loss',
            factor=0.2,
            patience=3,
            min_lr=min_lr,
            verbose=1
        ),
        # Uložení nejlepšího modelu
        ModelCheckpoint(
            filepath=os.path.join(model_dir, 'best_model.h5'),
            monitor='val_loss',
            save_best_only=True,
            verbose=1
        ),
        # TensorBoard pro vizualizaci
        TensorBoard(log_dir=log_dir)
    ]
    
    # 6. Kompilace modelu - fáze extrakce příznaků
    model.compile(
        optimizer=Adam(learning_rate=initial_lr),
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # 7. Trénink fáze extrakce příznaků
    print("Fáze 1: Extrakce příznaků (trénování pouze horních vrstev)")
    history_feature_extraction = model.fit(
        train_data,
        validation_data=val_data,
        epochs=10,
        callbacks=callbacks,
        verbose=1
    )
    
    # 8. Fáze fine-tuningu
    print("Fáze 2: Fine-tuning (trénování horních vrstev základního modelu)")
    
    # Odmrazení některých vrstev základního modelu
    for layer in base_model.layers[-20:]:  # Odmrazení posledních 20 vrstev
        layer.trainable = True
    
    # Rekompilace s nižším learning rate pro fine-tuning
    model.compile(
        optimizer=Adam(learning_rate=initial_lr/10),
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    
    # Trénink s fine-tuningem
    history_fine_tuning = model.fit(
        train_data,
        validation_data=val_data,
        epochs=20,
        callbacks=callbacks,
        verbose=1
    )
    
    # 9. Vyhodnocení na testovacích datech, jsou-li k dispozici
    if test_data is not None:
        print("Vyhodnocení na testovacích datech...")
        test_loss, test_acc = model.evaluate(test_data)
        print(f"Testovací přesnost: {test_acc:.4f}")
        
        # Získání klasifikační zprávy
        y_true = []
        y_pred = []
        for x, y in test_data:
            y_true.extend(tf.argmax(y, axis=1).numpy())
            y_pred.extend(tf.argmax(model.predict(x), axis=1))
        
        print(classification_report(y_true, y_pred))
    
    # 10. Uložení finálního modelu
    model.save(os.path.join(model_dir, 'final_model.h5'))
    
    # Kombinace historií
    combined_history = {}
    for k in history_feature_extraction.history.keys():
        combined_history[k] = (
            history_feature_extraction.history[k] + 
            history_fine_tuning.history[k]
        )
    
    return model, combined_history

# Příklad použití (zakomentováno)

)
```

### Časté chyby, kterým je třeba se vyhnout

1. **Katastrofické zapomínání**: Když fine-tuning zničí cenné předtrénované funkce
2. **Použití nevhodných předtrénovaných modelů**: Výběr modelů trénovaných na nesouvisejících doménách
3. **Přeskočení normalizace dat**: Nepoužití stejného předzpracování jako u předtrénovaného modelu
4. **Přetrénování na malých datasetech**: I s transfer learningem mohou velmi malé datasety vést k přetrénování
5. **Příliš vysoká learning rate**: Použití nevhodných learning rates během fine-tuningu
6. **Zmrazení špatných vrstev**: Nepochopení, které vrstvy zmrazit vs. fine-tunovat

## Shrnutí

Transfer learning je mocná technika, která využívá znalosti z předtrénovaných modelů ke zlepšení výkonu na nových úlohách, zejména když je omezené množství označených dat. Klíčové poznatky zahrnují:

1. **Efektivita**: Transfer learning výrazně zkracuje dobu tréninku a snižuje výpočetní zdroje, přičemž často zlepšuje výkon modelu.

2. **Strategie**: Vyberte vhodnou strategii transfer learningu na základě velikosti vašeho datasetu a podobnosti s předtrénovanou doménou - od extrakce příznaků po kompletní fine-tuning.

3. **Techniky fine-tuningu**: Aplikujte techniky jako diskriminativní learning rates, postupné odmrazování a vhodnou regularizaci k optimalizaci fine-tuningu.

4. **Aplikace**: Transfer learning funguje napříč doménami, od počítačového vidění (CNN) přes NLP (BERT, GPT), zpracování zvuku až po analýzu časových řad.

5. **Hodnocení**: Správně vyhodnoťte modely transfer learningu v porovnání s modely trénovanými od základu, abyste pochopili výhody a omezení.

6. **Nejlepší postupy**: Dodržujte osvědčené postupy jako správné předzpracování, vhodné learning rates a pečlivé zmrazování vrstev, abyste se vyhnuli častým chybám.

Transfer learning představuje jeden z nejdůležitějších posunů paradigmatu ve strojovém učení, umožňující vývoj výkonných modelů s omezenými daty a výpočetními zdroji. Je základním kamenem moderní praxe hlubokého učení a nadále se vyvíjí s novými předtrénovanými modely a technikami.
