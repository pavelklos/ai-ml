## Convolutional Neural Networks (CNNs)

CNNs are specialized for processing grid-like data such as images. They use convolutional layers to automatically learn spatial hierarchies of features.

### CNN Key Components

1. **Convolutional layers**: Apply filters to detect features
2. **Pooling layers**: Reduce dimensionality and extract dominant features
3. **Fully connected layers**: Combine features for classification/regression

## Recurrent Neural Networks (RNNs)

RNNs process sequential data by maintaining a hidden state that captures information about previous elements in the sequence.

### RNN Key Components

1. **Recurrent cells**: Process sequential inputs by updating a hidden state
2. **Long Short-Term Memory (LSTM)**: Addresses vanishing gradient with gates
3. **Gated Recurrent Unit (GRU)**: Simplified LSTM with fewer parameters

```python
class RNNPyTorch(nn.Module):
    def __init__(self, vocab_size, embedding_dim=128, hidden_dim=128, num_layers=2, dropout=0.3):
        super(RNNPyTorch, self).__init__()
        
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        
        # LSTM layer
        self.lstm = nn.LSTM(
            embedding_dim, 
            hidden_dim, 
            num_layers=num_layers, 
            dropout=dropout if num_layers > 1 else 0,
            batch_first=True,
            bidirectional=False
        )
        
        # Output layer
        self.fc = nn.Sequential(
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, 64),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(64, 1),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        # x shape: (batch_size, sequence_length)
        
        # Apply embedding layer
        x = self.embedding(x)  # (batch_size, sequence_length, embedding_dim)
        
        # Apply LSTM
        lstm_out, _ = self.lstm(x)  # (batch_size, sequence_length, hidden_dim)
        
        # Use the last output for classification
        out = lstm_out[:, -1, :]  # (batch_size, hidden_dim)
        
        # Apply fully connected layer
        out = self.fc(out)  # (batch_size, 1)
        
        return out
```

## Transformer Architectures

Transformers use self-attention mechanisms to process sequential data, enabling parallel processing and capturing long-range dependencies more effectively than RNNs.

### Transformer Key Components

1. **Self-attention**: Computes attention weights between all positions in a sequence
2. **Multi-head attention**: Runs multiple self-attention operations in parallel
3. **Position encoding**: Adds positional information to tokens
4. **Encoder-decoder structure**: Processes input and generates output

```python
# Simple Transformer implementation using TensorFlow/Keras
def transformer_encoder(inputs, head_size, num_heads, ff_dim, dropout=0):
    # Multi-head self-attention
    x = layers.LayerNormalization(epsilon=1e-6)(inputs)
    x = layers.MultiHeadAttention(
        key_dim=head_size, num_heads=num_heads, dropout=dropout
    )(x, x)
    x = layers.Dropout(dropout)(x)
    res = x + inputs

    # Feed Forward Network
    x = layers.LayerNormalization(epsilon=1e-6)(res)
    x = layers.Dense(ff_dim, activation="relu")(x)
    x = layers.Dropout(dropout)(x)
    x = layers.Dense(inputs.shape[-1])(x)
    x = layers.Dropout(dropout)(x)
    
    return x + res

def create_transformer_model_keras(
    input_length=100, 
    vocab_size=10000, 
    embedding_dim=128,
    num_heads=8,
    ff_dim=512,
    num_transformer_blocks=4,
    dropout=0.1
):
    inputs = layers.Input(shape=(input_length,))
    embedding_layer = layers.Embedding(vocab_size, embedding_dim)
    x = embedding_layer(inputs)
    
    # Add positional encoding (simplified version)
    positions = tf.range(start=0, limit=input_length, delta=1)
    positions = layers.Embedding(input_length, embedding_dim)(positions)
    x = x + positions
    
    # Transformer blocks
    for _ in range(num_transformer_blocks):
        x = transformer_encoder(x, embedding_dim//num_heads, num_heads, ff_dim, dropout)
    
    # Classification head
    x = layers.GlobalAveragePooling1D()(x)
    x = layers.Dense(64, activation="relu")(x)
    x = layers.Dropout(0.1)(x)
    outputs = layers.Dense(1, activation="sigmoid")(x)
    
    model = models.Model(inputs=inputs, outputs=outputs)
    model.compile(
        optimizer="adam", 
        loss="binary_crossentropy", 
        metrics=["accuracy"]
    )
    return model
```

```python
# Transformer implementation using PyTorch
class TransformerEncoderLayer(nn.Module):
    def __init__(self, embed_dim, num_heads, ff_dim, dropout=0.1):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(embed_dim, num_heads, dropout=dropout, batch_first=True)
        
        self.feed_forward = nn.Sequential(
            nn.Linear(embed_dim, ff_dim),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(ff_dim, embed_dim),
            nn.Dropout(dropout)
        )
        
        self.norm1 = nn.LayerNorm(embed_dim)
        self.norm2 = nn.LayerNorm(embed_dim)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # Self attention
        attn_output, _ = self.self_attn(x, x, x, attn_mask=mask)
        x = x + self.dropout(attn_output)
        x = self.norm1(x)
        
        # Feed forward
        ff_output = self.feed_forward(x)
        x = x + ff_output
        x = self.norm2(x)
        
        return x

class TransformerPyTorch(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, num_heads=8, ff_dim=512, 
                 num_layers=4, max_len=100, dropout=0.1):
        super().__init__()
        
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.pos_embedding = nn.Embedding(max_len, embed_dim)
        
        self.transformer_blocks = nn.ModuleList(
            [TransformerEncoderLayer(embed_dim, num_heads, ff_dim, dropout) 
             for _ in range(num_layers)]
        )
        
        self.classifier = nn.Sequential(
            nn.Linear(embed_dim, 64),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(64, 1),
            nn.Sigmoid()
        )
        
        self.dropout = nn.Dropout(dropout)
        self.max_len = max_len
    
    def forward(self, x):
        # x shape: (batch_size, seq_len)
        
        # Generate position indices
        batch_size, seq_len = x.size()
        positions = torch.arange(0, seq_len, device=x.device).expand(batch_size, seq_len)
        
        # Apply embeddings
        x = self.embedding(x)  # (batch_size, seq_len, embed_dim)
        pos = self.pos_embedding(positions)  # (batch_size, seq_len, embed_dim)
        x = x + pos
        x = self.dropout(x)
        
        # Apply transformer blocks
        for block in self.transformer_blocks:
            x = block(x)
        
        # Global average pooling
        x = x.mean(dim=1)
        
        # Apply classifier
        x = self.classifier(x)
        
        return x
```

## Hybrid Architectures

Many modern deep learning systems combine elements from different architectures to leverage their strengths.

```python
# Example of a CNN-LSTM hybrid model for video analysis
def create_cnn_lstm_model(frames=10, height=64, width=64, channels=3):
    # Input shape: (frames, height, width, channels)
    inputs = layers.Input(shape=(frames, height, width, channels))
    
    # Apply CNN to each frame independently
    x = layers.TimeDistributed(layers.Conv2D(32, (3, 3), activation='relu'))(inputs)
    x = layers.TimeDistributed(layers.MaxPooling2D((2, 2)))(x)
    x = layers.TimeDistributed(layers.Conv2D(64, (3, 3), activation='relu'))(x)
    x = layers.TimeDistributed(layers.MaxPooling2D((2, 2)))(x)
    x = layers.TimeDistributed(layers.Flatten())(x)
    
    # Apply LSTM to the sequence of extracted features
    x = layers.LSTM(128, return_sequences=True)(x)
    x = layers.LSTM(64)(x)
    
    # Classification head
    x = layers.Dense(32, activation='relu')(x)
    outputs = layers.Dense(10, activation='softmax')(x)  # 10 classes
    
    model = models.Model(inputs=inputs, outputs=outputs)
    model.compile(
        optimizer='adam',
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    return model
```

```python
# Example of a CNN-Transformer hybrid for image captioning
def create_cnn_transformer_model(
    image_shape=(224, 224, 3), 
    vocab_size=10000, 
    embedding_dim=128,
    max_caption_len=50,
    num_heads=8,
    ff_dim=512
):
    # Image encoder (CNN)
    image_input = layers.Input(shape=image_shape)
    cnn_base = tf.keras.applications.ResNet50(
        include_top=False, 
        weights='imagenet', 
        input_shape=image_shape
    )
    cnn_base.trainable = False  # Freeze weights
    
    image_features = cnn_base(image_input)
    image_features = layers.GlobalAveragePooling2D()(image_features)
    image_features = layers.Dense(embedding_dim)(image_features)
    
    # Expand dimensions to make it compatible with transformer
    image_features = tf.expand_dims(image_features, 1)
    
    # Caption input and processing
    caption_input = layers.Input(shape=(max_caption_len,))
    caption_embedding = layers.Embedding(vocab_size, embedding_dim)(caption_input)
    
    # Combine image features with caption embeddings
    x = layers.Concatenate(axis=1)([image_features, caption_embedding])
    
    # Add positional encoding
    positions = tf.range(start=0, limit=max_caption_len+1, delta=1)
    position_embedding = layers.Embedding(max_caption_len+1, embedding_dim)(positions)
    x = x + position_embedding
    
    # Transformer blocks
    for _ in range(4):
        x = transformer_encoder(x, embedding_dim//num_heads, num_heads, ff_dim, 0.1)
    
    # Output prediction
    x = layers.Dense(vocab_size, activation='softmax')(x[:, 1:, :])
    
    model = models.Model([image_input, caption_input], x)
    model.compile(
        optimizer='adam',
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
    return model
```

### Memory and Computational Efficiency

```python
# Techniques for optimizing memory usage
def implement_gradient_accumulation(model, batch_size, sub_batch_size):
    """
    Example of gradient accumulation to handle large models with limited GPU memory
    
    Args:
        model: Keras model
        batch_size: Target effective batch size
        sub_batch_size: Actual batch size to use (should be smaller)
    """
    # Assuming model and data are defined elsewhere
    # We're just showing the concept here
    
    # Number of sub-batches to accumulate
    accumulation_steps = batch_size // sub_batch_size
    
    # Customize training step with gradient accumulation
    @tf.function
    def train_step(x_batch, y_batch):
        # Split batch into sub-batches
        sub_batches_x = tf.split(x_batch, accumulation_steps)
        sub_batches_y = tf.split(y_batch, accumulation_steps)
        
        # Process each sub-batch
        for i in range(accumulation_steps):
            with tf.GradientTape() as tape:
                pred = model(sub_batches_x[i], training=True)
                loss = loss_fn(sub_batches_y[i], pred) / accumulation_steps
            
            # Accumulate gradients
            gradients = tape.gradient(loss, model.trainable_variables)
            
            if i == 0:
                accumulated_gradients = [g for g in gradients]
            else:
                accumulated_gradients = [ag + g for ag, g in zip(accumulated_gradients, gradients)]
        
        # Apply accumulated gradients
        optimizer.apply_gradients(zip(accumulated_gradients, model.trainable_variables))
    
    return train_step
```

```python
# For PyTorch
def setup_mixed_precision_pytorch(model):
    """
    Set up mixed precision training in PyTorch using Automatic Mixed Precision (AMP)
    """
    # Using PyTorch's AMP
    from torch.cuda.amp import GradScaler, autocast
    
    # Create gradient scaler
    scaler = GradScaler()
    
    # Training loop with mixed precision (conceptual example)
    def train_step(model, inputs, targets, optimizer):
        # Move data to device
        inputs = inputs.to('cuda')
        targets = targets.to('cuda')
        
        # Forward pass with autocast
        with autocast():
            outputs = model(inputs)
            loss = nn.functional.cross_entropy(outputs, targets)
        
        # Backward and optimize with scaled gradients
        optimizer.zero_grad()
        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()
        
        return loss.item()
    
    return train_step
```

## Model Selection Guidelines

Choosing the right architecture depends on your data type, task requirements, and computational constraints.

| Data Type | Recommended Architecture | Example Task |
|-----------|--------------------------|--------------|
| Images | CNNs (ResNet, EfficientNet) | Image classification, object detection |
| Short sequences | RNNs (LSTM, GRU) | Time series forecasting, simple text classification |
| Long sequences | Transformers | Machine translation, document summarization |
| Text | Transformers (BERT, GPT) | NLP tasks, text generation |
| Speech | CNNs + RNNs or Transformers | Speech recognition, voice commands |
| Video | 3D CNNs or CNN+RNN hybrids | Action recognition, video classification |
| Graphs | Graph Neural Networks | Molecular property prediction, social network analysis |

```python
# Example of linear attention implementation
def linear_attention(q, k, v):
    """
    Efficient linear attention mechanism that scales linearly with sequence length
    
    Args:
        q, k, v: Query, Key, Value tensors
    
    Returns:
        Attention output
    """
    # Apply feature maps to queries and keys
    # This is a simplification of linear attention techniques
    q = tf.nn.elu(q) + 1
    k = tf.nn.elu(k) + 1
    
    # Compute attention weights using the kernel trick
    # Instead of (q * k^T) * v, compute q * (k^T * v)
    kv = tf.matmul(k, v, transpose_a=True)
    qkv = tf.matmul(q, kv)
    
    # Normalization factor
    z = tf.matmul(q, tf.reduce_sum(k, axis=-2, keepdims=True), transpose_a=True)
    
    # Apply normalization
    output = qkv / (z + 1e-8)
    
    return output
```

## Summary

Deep learning architectures have revolutionized machine learning across various domains. Each architecture type has distinct characteristics:

1. **CNNs** excel at extracting spatial patterns from grid-like data, making them ideal for images and video.

2. **RNNs** (including LSTM and GRU variants) process sequential data by maintaining a hidden state, suitable for time series and text when order matters.

3. **Transformers** use self-attention mechanisms to model long-range dependencies in sequential data, enabling parallel processing and achieving state-of-the-art results in NLP and increasingly in computer vision.

4. **Hybrid architectures** combine elements from different architectures to handle complex data types and tasks.

Key considerations when working with these architectures include:

- Matching the architecture to your data type and problem
- Understanding computational requirements and memory constraints
- Implementing appropriate regularization techniques
- Leveraging pre-trained models through transfer learning
- Interpreting and visualizing model behavior

The field continues to evolve rapidly with research directions focused on efficiency, scalability, and multimodal capabilities. For practical applications, consider starting with established architectures and adapting them to your specific needs.
