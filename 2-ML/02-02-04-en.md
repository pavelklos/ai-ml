## Introduction to Cross-validation

Cross-validation is a statistical method used to estimate the performance of machine learning models. It helps assess how well a model will generalize to an independent dataset and prevents overfitting. By using different subsets of data for training and validation, cross-validation provides a more robust evaluation than a simple train-test split.

```python
# Required libraries for cross-validation
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split, cross_val_score, KFold
from sklearn.model_selection import StratifiedKFold, LeaveOneOut, TimeSeriesSplit
from sklearn.model_selection import GridSearchCV, cross_validate
from sklearn.metrics import accuracy_score, mean_squared_error, make_scorer
from sklearn.datasets import load_iris, load_boston, fetch_california_housing
from sklearn.linear_model import LogisticRegression, LinearRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC
import warnings
warnings.filterwarnings('ignore')

# For reproducibility
np.random.seed(42)
```

## Train-Test Split and Its Limitations

The simplest form of model validation is the train-test split, where we divide the dataset into training and testing sets. While straightforward, this approach can suffer from high variance depending on the specific data points that end up in the training and test sets.

```python
# Load a sample dataset
iris = load_iris()
X = iris.data
y = iris.target

# Simple train-test split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Train a model
model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)

# Evaluate on the test set
y_pred = model.predict(X_test)
accuracy = accuracy_score(y_test, y_pred)
print(f"Model accuracy with simple train-test split: {accuracy:.4f}")

# Trying a different random state shows variability in results
X_train2, X_test2, y_train2, y_test2 = train_test_split(X, y, test_size=0.3, random_state=123)
model.fit(X_train2, y_train2)
y_pred2 = model.predict(X_test2)
accuracy2 = accuracy_score(y_test2, y_pred2)
print(f"Model accuracy with different split: {accuracy2:.4f}")
print(f"Difference in accuracy: {abs(accuracy - accuracy2):.4f}")
```

## K-Fold Cross-validation

K-Fold cross-validation divides the dataset into K equally sized folds. The model is trained on K-1 folds and validated on the remaining fold. This process is repeated K times, with each fold used exactly once as the validation data. The results are then averaged to produce a single performance estimation.

```python
# Setting up K-Fold cross-validation
k_folds = 5
kf = KFold(n_splits=k_folds, shuffle=True, random_state=42)

# Model to evaluate
model = LogisticRegression(max_iter=200)

# Perform cross-validation
cv_results = cross_val_score(model, X, y, cv=kf, scoring='accuracy')

# Display results
print(f"K-Fold Cross-validation results (K={k_folds}):")
print(f"Individual fold accuracies: {cv_results}")
print(f"Mean accuracy: {cv_results.mean():.4f}")
print(f"Standard deviation: {cv_results.std():.4f}")

# Visualizing the K-Fold process
plt.figure(figsize=(10, 6))
for fold, (train_idx, val_idx) in enumerate(kf.split(X)):
    plt.scatter(range(len(train_idx)), [fold] * len(train_idx), c='blue', alpha=0.2, s=10, label='Train' if fold == 0 else "")
    plt.scatter(range(len(val_idx)), [fold] * len(val_idx), c='red', alpha=0.5, s=10, label='Validation' if fold == 0 else "")

plt.yticks(range(k_folds))
plt.xlabel("Data Points")
plt.ylabel("Fold")
plt.title("K-Fold Cross-validation (K=5)")
plt.legend()
plt.tight_layout()
plt.show()
```

## Stratified K-Fold Cross-validation

Stratified K-Fold is a variation of K-Fold that ensures each fold preserves the percentage of samples for each class. This is particularly important for imbalanced datasets or when the target variable has a skewed distribution.

```python
# Create an imbalanced dataset
# Taking subset of iris with only two classes and making it imbalanced
X_imb = X[y != 2]  # Excluding the third class
y_imb = y[y != 2]  # Classes 0 and 1 only
indices = np.where(y_imb == 1)[0]  # Indices of class 1
remove_indices = np.random.choice(indices, size=int(0.7 * len(indices)), replace=False)
mask = np.ones(len(y_imb), bool)
mask[remove_indices] = False
X_imb = X_imb[mask]
y_imb = y_imb[mask]

# Check class distribution
unique, counts = np.unique(y_imb, return_counts=True)
print("Class distribution in imbalanced dataset:")
for class_label, count in zip(unique, counts):
    print(f"Class {class_label}: {count} samples ({count/len(y_imb):.2%})")

# Regular K-Fold
kf = KFold(n_splits=5, shuffle=True, random_state=42)
folds_class_counts = []
for train_idx, test_idx in kf.split(X_imb):
    _, test_counts = np.unique(y_imb[test_idx], return_counts=True)
    if len(test_counts) < 2:  # If a fold is missing a class
        test_counts = np.append(test_counts, 0)
    folds_class_counts.append(test_counts / len(test_idx))

print("\nClass distribution in each fold using standard KFold:")
for i, counts in enumerate(folds_class_counts):
    print(f"Fold {i+1}: Class 0: {counts[0]:.2%}, Class 1: {counts[1]:.2%}")

# Stratified K-Fold
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
strat_folds_class_counts = []
for train_idx, test_idx in skf.split(X_imb, y_imb):
    _, test_counts = np.unique(y_imb[test_idx], return_counts=True)
    strat_folds_class_counts.append(test_counts / len(test_idx))

print("\nClass distribution in each fold using StratifiedKFold:")
for i, counts in enumerate(strat_folds_class_counts):
    print(f"Fold {i+1}: Class 0: {counts[0]:.2%}, Class 1: {counts[1]:.2%}")

# Comparing model performance
model = LogisticRegression(max_iter=200)
standard_cv = cross_val_score(model, X_imb, y_imb, cv=kf, scoring='accuracy')
stratified_cv = cross_val_score(model, X_imb, y_imb, cv=skf, scoring='accuracy')

print(f"\nStandard K-Fold CV accuracy: {standard_cv.mean():.4f} ± {standard_cv.std():.4f}")
print(f"Stratified K-Fold CV accuracy: {stratified_cv.mean():.4f} ± {stratified_cv.std():.4f}")
```

## Leave-One-Out Cross-validation (LOOCV)

Leave-One-Out cross-validation is an extreme case of K-Fold where K equals the number of data points. In each iteration, a single observation is used as the validation set while all others are used for training. While computationally expensive, it is useful for small datasets.

```python
# Create a small dataset for demonstration
housing = fetch_california_housing()
X_small = housing.data[:100]  # Using only 100 samples for efficiency
y_small = housing.target[:100]

# Set up Leave-One-Out cross-validation
loo = LeaveOneOut()

# Model for regression
model = LinearRegression()

# Store predictions
y_pred = np.zeros_like(y_small)
for train_idx, test_idx in loo.split(X_small):
    X_train, X_test = X_small[train_idx], X_small[test_idx]
    y_train = y_small[train_idx]
    model.fit(X_train, y_train)
    y_pred[test_idx] = model.predict(X_test)

# Evaluate the model
mse = mean_squared_error(y_small, y_pred)
print(f"Leave-One-Out Cross-Validation MSE: {mse:.4f}")

# Comparison with 5-fold CV for computational efficiency perspective
start_time = pd.Timestamp.now()
loo_cv = cross_val_score(model, X_small, y_small, cv=loo, scoring='neg_mean_squared_error')
loo_time = (pd.Timestamp.now() - start_time).total_seconds()

start_time = pd.Timestamp.now()
kf5_cv = cross_val_score(model, X_small, y_small, cv=5, scoring='neg_mean_squared_error')
kf5_time = (pd.Timestamp.now() - start_time).total_seconds()

print(f"\nLOOCV computation time: {loo_time:.2f} seconds")
print(f"5-fold CV computation time: {kf5_time:.2f} seconds")
print(f"LOOCV is {loo_time/kf5_time:.1f}x slower than 5-fold CV")
```

## Time Series Cross-validation

Time series data requires special cross-validation methods because of the temporal ordering. Random splitting would cause data leakage as future data would be used to predict past events. Time series cross-validation ensures that training data always precedes validation data.

```python
# Generate a simple time series dataset
np.random.seed(42)
n_samples = 100
time = np.arange(n_samples)
trend = 0.1 * time
noise = np.random.normal(0, 0.5, size=n_samples)
y_time = trend + noise
X_time = time.reshape(-1, 1)

# Visualize the time series
plt.figure(figsize=(10, 6))
plt.plot(time, y_time, label='Time Series Data')
plt.xlabel('Time')
plt.ylabel('Value')
plt.title('Simulated Time Series Data with Trend')
plt.legend()
plt.grid(True)
plt.show()

# Set up TimeSeriesSplit
tscv = TimeSeriesSplit(n_splits=5)

# Visualizing the time series splits
plt.figure(figsize=(12, 8))
for i, (train_idx, test_idx) in enumerate(tscv.split(X_time)):
    fold_color = plt.cm.viridis(i/5)  # Different color for each fold
    
    # Plot the indices for each training/test set
    plt.scatter(time[train_idx], [i] * len(train_idx), 
                c=[fold_color], marker='_', s=60, alpha=0.7, label=f'Train Fold {i+1}' if i == 0 else "")
    plt.scatter(time[test_idx], [i] * len(test_idx), 
                c=[fold_color], marker='x', s=60, alpha=1, label=f'Test Fold {i+1}' if i == 0 else "")

plt.yticks(range(5))
plt.xlabel('Time')
plt.ylabel('CV Iteration')
plt.title('Time Series Cross-validation')
plt.legend()
plt.tight_layout()
plt.show()

# Performing time series cross-validation
model = LinearRegression()
cv_results = cross_val_score(model, X_time, y_time, 
                              cv=tscv, scoring='neg_mean_squared_error')

print(f"Time Series Cross-validation results:")
print(f"MSE per fold: {-cv_results}")  # Negative sign because of sklearn's scoring convention
print(f"Mean MSE: {-cv_results.mean():.4f}")
print(f"Standard deviation: {cv_results.std():.4f}")
```

## Nested Cross-validation

Nested cross-validation is used when you need to both tune hyperparameters and estimate the model's performance. It consists of an inner loop for hyperparameter tuning and an outer loop for performance estimation, which prevents the information leakage that can occur when using the same data for both tasks.

```python
# Load dataset
iris = load_iris()
X, y = iris.data, iris.target

# Define the model and parameter grid
model = SVC()
param_grid = {
    'C': [0.1, 1, 10, 100],
    'gamma': [0.001, 0.01, 0.1, 1],
    'kernel': ['rbf', 'linear']
}

# Set up outer and inner cross-validation
outer_cv = KFold(n_splits=5, shuffle=True, random_state=42)
inner_cv = KFold(n_splits=3, shuffle=True, random_state=42)

# Set up nested cross-validation
nested_scores = np.zeros(outer_cv.get_n_splits())
best_params = []

for i, (train_idx, test_idx) in enumerate(outer_cv.split(X)):
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]
    
    # Inner loop for hyperparameter tuning
    grid_search = GridSearchCV(estimator=model, param_grid=param_grid, cv=inner_cv)
    grid_search.fit(X_train, y_train)
    
    # Store best parameters from this fold
    best_params.append(grid_search.best_params_)
    
    # Test the best model on the outer fold
    y_pred = grid_search.predict(X_test)
    nested_scores[i] = accuracy_score(y_test, y_pred)

# Print results
print("Nested Cross-Validation Results:")
print(f"Accuracy per fold: {nested_scores}")
print(f"Mean accuracy: {nested_scores.mean():.4f}")
print(f"Standard deviation: {nested_scores.std():.4f}")

print("\nBest Parameters in Each Outer Fold:")
for i, params in enumerate(best_params):
    print(f"Fold {i+1}: {params}")

# Compare with non-nested cross-validation (which can overestimate performance)
grid_search = GridSearchCV(estimator=model, param_grid=param_grid, cv=5)
grid_search.fit(X, y)
non_nested_scores = cross_val_score(grid_search.best_estimator_, X, y, cv=5)

print("\nComparison with Non-Nested Cross-Validation:")
print(f"Nested CV Mean Accuracy: {nested_scores.mean():.4f}")
print(f"Non-Nested CV Mean Accuracy: {non_nested_scores.mean():.4f}")
```

## Cross-validation with Hyperparameter Tuning

GridSearchCV and RandomizedSearchCV are convenient tools for both hyperparameter tuning and cross-validation. They perform an exhaustive search over a parameter space, evaluating model performance using cross-validation.

```python
# Load dataset
iris = load_iris()
X, y = iris.data, iris.target

# Create a model with hyperparameters to tune
rf_model = RandomForestClassifier(random_state=42)

# Define parameter grid
param_grid = {
    'n_estimators': [50, 100, 200],
    'max_depth': [None, 10, 20, 30],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 2, 4]
}

# To make the example run faster, let's use a smaller grid
small_param_grid = {
    'n_estimators': [50, 100],
    'max_depth': [None, 20],
    'min_samples_split': [2, 5]
}

# Set up GridSearchCV
grid_search = GridSearchCV(
    estimator=rf_model,
    param_grid=small_param_grid,
    cv=5,
    scoring='accuracy',
    return_train_score=True,
    verbose=1,
    n_jobs=-1
)

# Fit the model
grid_search.fit(X, y)

# Display results
print("Best Parameters:", grid_search.best_params_)
print("Best CV Score:", grid_search.best_score_)

# Let's examine the results in a DataFrame for better visualization
results_df = pd.DataFrame(grid_search.cv_results_)
cols = ['param_n_estimators', 'param_max_depth', 'param_min_samples_split', 
        'mean_test_score', 'std_test_score', 'mean_train_score', 'std_train_score']
results_summary = results_df[cols].sort_values(by='mean_test_score', ascending=False)
print("\nResults sorted by test score (top 5):")
print(results_summary.head())

# Visualize the parameter impact
plt.figure(figsize=(12, 8))

# Group by n_estimators and max_depth
grouped_results = results_df.groupby(['param_n_estimators', 'param_max_depth']).mean()
pivoted = grouped_results.reset_index().pivot('param_n_estimators', 'param_max_depth', 'mean_test_score')

plt.tight_layout()
plt.show()
```

## Evaluation Metrics in Cross-validation

Different metrics can be used for cross-validation depending on the problem type (classification vs regression) and specific requirements. Using appropriate metrics is crucial for model selection and evaluation.

```python
# Load datasets for classification and regression
iris = load_iris()
X_class, y_class = iris.data, iris.target

housing = fetch_california_housing()
X_reg = housing.data[:500]  # Using subset for efficiency
y_reg = housing.target[:500]

# Classification metrics
classification_metrics = ['accuracy', 'precision_macro', 'recall_macro', 'f1_macro', 'roc_auc_ovr']
model_class = RandomForestClassifier(random_state=42)

# Cross-validation with multiple metrics
class_results = cross_validate(model_class, X_class, y_class, cv=5, scoring=classification_metrics)

# Display classification results
print("Classification Cross-Validation Results:")
for metric in classification_metrics:
    scores = class_results[f'test_{metric}']
    print(f"{metric}: {scores.mean():.4f} ± {scores.std():.4f}")

# Regression metrics
regression_metrics = ['r2', 'neg_mean_squared_error', 'neg_mean_absolute_error']
model_reg = LinearRegression()

# Cross-validation with multiple metrics
reg_results = cross_validate(model_reg, X_reg, y_reg, cv=5, scoring=regression_metrics)

# Display regression results
print("\nRegression Cross-Validation Results:")
for metric in regression_metrics:
    scores = reg_results[f'test_{metric}']
    print(f"{metric}: {scores.mean():.4f} ± {scores.std():.4f}")

# Using custom scoring metric
def custom_rmse(y_true, y_pred):
    return np.sqrt(mean_squared_error(y_true, y_pred))

rmse_scorer = make_scorer(custom_rmse, greater_is_better=False)

custom_results = cross_validate(model_reg, X_reg, y_reg, cv=5, 
                               scoring={'rmse': rmse_scorer, 'r2': 'r2'})

print("\nCustom Metric Cross-Validation Results:")
print(f"RMSE: {-custom_results['test_rmse'].mean():.4f} ± {custom_results['test_rmse'].std():.4f}")
print(f"R²: {custom_results['test_r2'].mean():.4f} ± {custom_results['test_r2'].std():.4f}")
```

## Summary and Best Practices

Cross-validation is a critical component of machine learning workflows. It provides a robust estimate of model performance and helps to detect and prevent overfitting. Here are the key takeaways and best practices:

```python
# Summary example: Comparing different CV strategies on a classification problem
iris = load_iris()
X, y = iris.data, iris.target

# Define model
model = LogisticRegression(max_iter=200)

# Various cross-validation strategies
cv_strategies = {
    'Train-Test Split': ShuffleSplit(n_splits=1, test_size=0.3, random_state=42),
    '5-Fold CV': KFold(n_splits=5, shuffle=True, random_state=42),
    'Stratified 5-Fold CV': StratifiedKFold(n_splits=5, shuffle=True, random_state=42),
    'Leave-One-Out CV': LeaveOneOut(),
    '5-Fold Time Series CV': TimeSeriesSplit(n_splits=5)
}

# Evaluate each strategy
results = {}
for name, cv in cv_strategies.items():
    try:
        scores = cross_val_score(model, X, y, cv=cv, scoring='accuracy')
        results[name] = (scores.mean(), scores.std())
    except Exception as e:
        print(f"Error with {name}: {e}")

# Print results
print("Comparison of Cross-validation Strategies:")
for name, (mean, std) in results.items():
    print(f"{name}: {mean:.4f} ± {std:.4f}")

# Visualization of key points
plt.figure(figsize=(12, 8))

# Plot mean and std of accuracies
names = list(results.keys())
means = [results[name][0] for name in names]
stds = [results[name][1] for name in names]

x_pos = np.arange(len(names))
plt.bar(x_pos, means, yerr=stds, align='center', alpha=0.7, capsize=10)
plt.xticks(x_pos, names, rotation=45, ha='right')
plt.ylabel('Accuracy')
plt.title('Comparison of Cross-validation Strategies')
plt.ylim(0.8, 1.0)  # Adjust based on your results

plt.tight_layout()
plt.show()
```

**Best Practices for Cross-validation:**

1. **Choose the Right Strategy**: Select the cross-validation method based on the dataset characteristics (size, balance, temporal structure).

2. **Stratification**: For classification problems with imbalanced classes, use stratified sampling.

3. **Number of Folds**: 
   - 5-10 folds generally provide a good balance between bias and variance
   - Use more folds (or LOOCV) for very small datasets
   - Use fewer folds for large datasets to save computation time

4. **Nested CV**: Use nested cross-validation when you need to both tune hyperparameters and estimate performance.

5. **Appropriate Metrics**: Select evaluation metrics that align with your problem objectives.

6. **Data Preprocessing**: Ensure that data preprocessing steps are included within the cross-validation loop to prevent data leakage.

7. **Reproducibility**: Set random seeds for reproducible results.

8. **Computational Efficiency**: Consider the computational cost, especially for large datasets or complex models.

By applying these cross-validation strategies and best practices, you can build more robust models with reliable performance estimates, leading to better generalization on new, unseen data.
