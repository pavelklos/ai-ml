## Introduction to Clustering

Clustering is an unsupervised machine learning technique that groups similar data points together based on their features, without requiring labeled data. The goal is to discover inherent groups or structures within the data.

Key characteristics of clustering:
- Unsupervised learning - no labels required
- Groups similar data points into clusters
- Data points within a cluster are more similar to each other than to those in other clusters
- Different algorithms use different similarity metrics and definitions of a "cluster"

## Understanding K-means Clustering

K-means is one of the simplest and most popular clustering algorithms. It partitions data into K clusters, where each data point belongs to the cluster with the nearest mean (centroid).

### K-means Algorithm:
1. Randomly initialize K centroids
2. Assign each data point to the nearest centroid
3. Recalculate centroids as the mean of all points in the cluster
4. Repeat steps 2-3 until convergence (centroids no longer move significantly)

```python
# Applying K-means to the blobs dataset
kmeans = KMeans(n_clusters=4, random_state=42)
kmeans_labels = kmeans.fit_predict(X_blobs)
kmeans_centroids = kmeans.cluster_centers_

# Visualize K-means clustering result
plt.figure(figsize=(12, 5))

plt.subplot(121)
plt.scatter(X_blobs[:, 0], X_blobs[:, 1], c=y_blobs, cmap='viridis', alpha=0.8)
plt.title('Original Blobs')

plt.subplot(122)
plt.scatter(X_blobs[:, 0], X_blobs[:, 1], c=kmeans_labels, cmap='viridis', alpha=0.8)
plt.scatter(kmeans_centroids[:, 0], kmeans_centroids[:, 1], marker='X', s=200, color='red')
plt.title('K-means Clustering (k=4)')

plt.tight_layout()
plt.show()
```

### Limitations of K-means:
- Requires the number of clusters (K) to be specified beforehand
- Assumes clusters are spherical and equally sized
- Sensitive to initial centroid positions
- Doesn't work well with non-convex clusters (like moons or circles)

## Hierarchical Clustering Methods

Hierarchical clustering builds a tree of clusters by either:
- **Agglomerative** (bottom-up): Start with each point as its own cluster and merge them successively
- **Divisive** (top-down): Start with all points in one cluster and split them successively

### Agglomerative Clustering Process:
1. Start with each data point as a separate cluster
2. Merge the two closest clusters based on a linkage criterion
3. Repeat step 2 until only one cluster remains

Common linkage criteria:
- **Single linkage**: Distance between the closest points in two clusters
- **Complete linkage**: Distance between the farthest points in two clusters
- **Average linkage**: Average distance between all pairs of points in two clusters
- **Ward's method**: Minimizes the increase in the sum of squared distances

```python
# Apply hierarchical clustering to blobs dataset
hierarchical = AgglomerativeClustering(n_clusters=4, linkage='ward')
hierarchical_labels = hierarchical.fit_predict(X_blobs)

# Compute the linkage matrix for the dendrogram
Z = linkage(X_blobs, method='ward')

# Visualize hierarchical clustering results
plt.figure(figsize=(15, 10))

# Plot dendrogram
plt.subplot(121)
dendrogram(Z, truncate_mode='level', p=3)
plt.title('Hierarchical Clustering Dendrogram')
plt.xlabel('Sample index')
plt.ylabel('Distance')

# Plot clusters
plt.subplot(122)
plt.scatter(X_blobs[:, 0], X_blobs[:, 1], c=hierarchical_labels, cmap='viridis', alpha=0.8)
```


## Density-Based Spatial Clustering (DBSCAN)

DBSCAN identifies clusters as areas of high density separated by areas of low density. It doesn't require specifying the number of clusters beforehand and can find arbitrarily shaped clusters.

### DBSCAN Key Concepts:
- **Core point**: A point with at least `min_samples` points within a distance of `eps`
- **Border point**: A point within `eps` distance of a core point but has fewer than `min_samples` points within `eps`
- **Noise point**: A point that is neither a core nor a border point

### DBSCAN Algorithm:
1. For each point, find all points within distance `eps`
2. Identify core points that have at least `min_samples` points within `eps`
3. Form clusters by connecting core points that are within `eps` of each other
4. Assign border points to their respective clusters
5. Label points that are not assigned to any cluster as noise

```python
# Apply DBSCAN to the moons and circles datasets
dbscan_moons = DBSCAN(eps=0.2, min_samples=5)
dbscan_circles = DBSCAN(eps=0.2, min_samples=5)

dbscan_circles_labels = dbscan_circles.fit_predict(X_circles)

# Visualize the results
plt.figure(figsize=(15, 5))
```

### Finding optimal eps parameter:
The `eps` parameter is crucial for DBSCAN. A common approach is to use the "elbow method" with k-distance graphs:

```python
def find_optimal_eps(X, k=5):
    # Compute distances to k nearest neighbors
    neigh = NearestNeighbors(n_neighbors=k)
    neigh.fit(X)
    distances, _ = neigh.kneighbors(X)
    
    # Sort distances to kth neighbor
    k_distances = np.sort(distances[:, k-1])
    
    # Plot k-distances
    plt.figure(figsize=(10, 6))
    plt.plot(np.arange(len(k_distances)), k_distances)
    plt.xlabel('Points sorted by distance')
    plt.ylabel(f'Distance to {k}th nearest neighbor')
    plt.title('K-distance Graph')
    plt.grid(True)
    plt.show()
    
# Find optimal eps for moons dataset
find_optimal_eps(X_moons)
```

## Evaluating Clustering Performance

Evaluating clustering performance is challenging because we don't have ground truth labels in unsupervised learning. However, there are internal evaluation metrics that measure how well the clusters are defined:

### Common Clustering Evaluation Metrics:
1. **Silhouette Score**: Measures how similar a point is to its own cluster compared to other clusters (-1 to +1, higher is better)
2. **Calinski-Harabasz Index**: Ratio of between-cluster variance to within-cluster variance (higher is better)
3. **Davies-Bouldin Index**: Average similarity between clusters (lower is better)

```python
# Function to evaluate clustering performance
def evaluate_clustering(X, labels):
    if len(np.unique(labels)) > 1 and -1 not in np.unique(labels):  # Silhouette requires at least 2 valid clusters
        silhouette = silhouette_score(X, labels)
    else:
        silhouette = float('nan')
    
    if len(np.unique(labels)) > 1:  # CH and DB require at least 2 clusters
        calinski = calinski_harabasz_score(X, labels)
        davies = davies_bouldin_score(X, labels)
    else:
        calinski = float('nan')
        davies = float('nan')
        
    return {
        'Silhouette Score': silhouette,
        'Calinski-Harabasz Index': calinski,
        'Davies-Bouldin Index': davies
    }

# Compare clustering algorithms on the blobs dataset
algorithms = {
    'K-means': KMeans(n_clusters=4, random_state=42),
    'Hierarchical': AgglomerativeClustering(n_clusters=4),
    'DBSCAN': DBSCAN(eps=0.3, min_samples=5)
}

results = {}
for name, algorithm in algorithms.items():
    labels = algorithm.fit_predict(X_blobs)
    results[name] = evaluate_clustering(X_blobs, labels)

# Display results in a table
results_df = pd.DataFrame(results).T
print("Clustering Evaluation on Blobs Dataset:")
print(results_df)

# Similarly for moons dataset
algorithms_moons = {
    'K-means': KMeans(n_clusters=2, random_state=42),
    'Hierarchical (Single)': AgglomerativeClustering(n_clusters=2, linkage='single'),
    'Hierarchical (Complete)': AgglomerativeClustering(n_clusters=2, linkage='complete'),
    'DBSCAN': DBSCAN(eps=0.2, min_samples=5)
}

results_moons = {}
for name, algorithm in algorithms_moons.items():
    labels = algorithm.fit_predict(X_moons)
    results_moons[name] = evaluate_clustering(X_moons, labels)

print("\nClustering Evaluation on Moons Dataset:")
print(pd.DataFrame(results_moons).T)
```

## Determining Optimal Number of Clusters

For algorithms like K-means and hierarchical clustering, we need to determine the optimal number of clusters. Several methods can help:

### 1. Elbow Method
Plot the sum of squared distances (inertia) against the number of clusters. The "elbow" point indicates a good choice for k.

```python
# Elbow method for K-means
def plot_elbow_method(X, max_k=10):
    inertias = []
    for k in range(1, max_k + 1):
        kmeans = KMeans(n_clusters=k, random_state=42)
        kmeans.fit(X)
        inertias.append(kmeans.inertia_)
    
    plt.figure(figsize=(10, 6))
    plt.plot(range(1, max_k + 1), inertias, 'o-')
    plt.xlabel('Number of clusters (k)')
    plt.ylabel('Inertia (Sum of squared distances)')
    plt.title('Elbow Method for Optimal k')
    plt.grid(True)
    plt.show()

# Apply elbow method to blobs dataset
plot_elbow_method(X_blobs)
```

### 2. Silhouette Method
Plot the average silhouette score for different numbers of clusters. The highest score indicates the optimal number.

```python
# Silhouette method for optimal number of clusters
def plot_silhouette_method(X, max_k=10):
    silhouette_scores = []
    for k in range(2, max_k + 1):  # Silhouette requires at least 2 clusters
        kmeans = KMeans(n_clusters=k, random_state=42)
        labels = kmeans.fit_predict(X)
        silhouette_scores.append(silhouette_score(X, labels))
    
    plt.figure(figsize=(10, 6))
    plt.plot(range(2, max_k + 1), silhouette_scores, 'o-')
    plt.xlabel('Number of clusters (k)')
    plt.ylabel('Silhouette score')
    plt.title('Silhouette Method for Optimal k')
    plt.grid(True)
    plt.show()

# Apply silhouette method to blobs dataset
plot_silhouette_method(X_blobs)
```

### 3. Dendrogram Analysis for Hierarchical Clustering
Analyze the dendrogram to determine where to "cut" the tree to get the optimal number of clusters.

```python
# Visualize dendrogram for hierarchical clustering
plt.figure(figsize=(12, 6))

plt.title('Hierarchical Clustering Dendrogram')
plt.xlabel('Sample index')
```

```python
plt.show()
```

## Visualizing Clustering Results

Effective visualization is key to interpreting clustering results. Here are some useful techniques:

### 1. Basic Scatter Plots for 2D Data

```python
# Function to create a comprehensive visualization of clustering results
def visualize_clustering(X, true_labels=None, cluster_labels=None, title=None, show_centroids=False, centroids=None):
    plt.figure(figsize=(12, 6))
    
    n_plots = 1 if true_labels is None else 2
    
    if true_labels is not None:
        plt.subplot(1, n_plots, 1)
        plt.scatter(X[:, 0], X[:, 1], c=true_labels, cmap='viridis', alpha=0.8)
        plt.title('Original Data')
    
    plt.subplot(1, n_plots, n_plots)
    plt.scatter(X[:, 0], X[:, 1], c=cluster_labels, cmap='viridis', alpha=0.8)
    
    if show_centroids and centroids is not None:
        plt.scatter(centroids[:, 0], centroids[:, 1], marker='X', s=200, color='red')
    
    if title:
        plt.title(title)
    
    plt.tight_layout()
    plt.show()

# Use the function to visualize K-means clustering on blobs
```

### 3. Visualizing Hierarchical Clustering with Dendrograms

```python
# Create a fancy dendrogram with colored branches
def plot_colored_dendrogram(X, n_clusters=4):
    Z = linkage(X, method='ward')
    
    plt.figure(figsize=(14, 8))
    plt.title('Hierarchical Clustering Dendrogram')
    plt.xlabel('Sample index')
    plt.ylabel('Distance')
    
    # Calculate color threshold
    threshold = (Z[-n_clusters+1, 2] + Z[-n_clusters, 2]) / 2
    
    dendrogram(
        Z,
        leaf_rotation=90.,  # rotates the x axis labels
        leaf_font_size=8.,  # font size for the x axis labels
        color_threshold=threshold,
        above_threshold_color='grey'
    )
    
    plt.axhline(y=threshold, color='r', linestyle='--')
    plt.text(len(X)/2, threshold + 0.5, f'Threshold for {n_clusters} clusters', 
             ha='center', va='center', fontsize=12)
    plt.show()

# Plot colored dendrogram for blobs dataset
```

```python
from sklearn.datasets import load_sample_image
from skimage import io
import numpy as np

china = load_sample_image("china.jpg")

w, h, d = china.shape
china_reshaped = china.reshape(w * h, d)

# Apply K-means to compress the image
n_colors = 16
kmeans_image = KMeans(n_clusters=n_colors, random_state=42, n_init=10)
kmeans_image.fit(china_reshaped)

# Replace each pixel with its nearest centroid
compressed_image = kmeans_image.cluster_centers_[kmeans_image.labels_]
compressed_image = compressed_image.reshape(w, h, d).astype(np.uint8)

# Display original and compressed images
plt.figure(figsize=(15, 8))

plt.subplot(121)
plt.imshow(china)
plt.title(f'Original Image ({china.shape[0]}x{china.shape[1]}, {256**3} colors)')
plt.axis('off')

plt.subplot(122)
plt.imshow(compressed_image)
plt.title(f'Compressed Image (K-means, {n_colors} colors)')
plt.axis('off')

plt.tight_layout()
plt.show()

# Calculate compression ratio
original_size = china.shape[0] * china.shape[1] * 3  # RGB values
compressed_size = n_colors * 3 + china.shape[0] * china.shape[1]  # color palette + pixel indices
compression_ratio = original_size / compressed_size
print(f"Compression ratio: {compression_ratio:.2f}x")
```

## Summary and Best Practices

### Comparison of Clustering Algorithms:

1. **K-means**:
   - **Pros**: Simple, fast, works well with large datasets, clearly defined clusters
   - **Cons**: Requires specifying k, assumes spherical clusters, sensitive to outliers
   - **Best for**: Well-separated, spherical clusters with similar sizes

2. **Hierarchical Clustering**:
   - **Pros**: No need to specify number of clusters, creates a dendrogram, more flexible than k-means
   - **Cons**: Computationally intensive for large datasets, sensitive to linkage criteria
   - **Best for**: Small to medium-sized datasets, when hierarchy or nested clusters are important

3. **DBSCAN**:
   - **Pros**: No need to specify number of clusters, can find arbitrarily shaped clusters, robust to outliers
   - **Cons**: Sensitive to parameters eps and min_samples, struggles with varying density clusters
   - **Best for**: Spatial data, irregularly shaped clusters, datasets with noise

### Best Practices for Clustering:

1. **Preprocessing**:
   - Always scale your data (StandardScaler or MinMaxScaler)
   - Handle missing values (imputation or removal)
   - Consider dimensionality reduction for high-dimensional data

2. **Algorithm Selection**:
   - Understand your data distribution and expected cluster shapes
   - Consider computational constraints for large datasets
   - Try multiple algorithms and compare results

3. **Parameter Selection**:
   - For k-means: use elbow method or silhouette analysis to find optimal k
   - For DBSCAN: use k-distance graphs to determine eps
   - For hierarchical: experiment with different linkage methods

4. **Evaluation**:
   - Use internal validation measures (silhouette, Calinski-Harabasz, Davies-Bouldin)
   - Visualize results whenever possible
   - Ensure clusters are meaningful in the domain context

5. **Interpretation**:
   - Analyze cluster profiles (centroids, distributions)
   - Use domain knowledge to label and understand clusters
   - Consider cluster stability across multiple runs

```python
# Final example: A comprehensive clustering workflow

# 1. Load and explore data
from sklearn.datasets import fetch_openml
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans, AgglomerativeClustering, DBSCAN
from sklearn.metrics import silhouette_score

# Load Wisconsin breast cancer dataset
breast_cancer = fetch_openml(name='breast-cancer-wisconsin', version=1)
X = breast_cancer.data.astype(float)
y = breast_cancer.target

print(f"Data shape: {X.shape}")
print(f"Target distribution: {pd.Series(y).value_counts()}")

# 2. Preprocess data
# Handle missing values
X_filled = X.fillna(X.median())

# Scale features
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_filled)

# 3. Dimensionality reduction for visualization
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
print(f"Explained variance ratio: {pca.explained_variance_ratio_.sum():.3f}")

# 4. Apply multiple clustering algorithms
clustering_algorithms = {
    "K-means (k=2)": KMeans(n_clusters=2, random_state=42),
    "Agglomerative (k=2)": AgglomerativeClustering(n_clusters=2),
    "DBSCAN": DBSCAN(eps=0.5, min_samples=5)
}

# 5. Compare results
plt.figure(figsize=(20, 5))
plt.subplot(141)
plt.scatter(X_pca[:, 0], X_pca[:, 1], c=(y == 'malignant').astype(int), cmap='viridis', alpha=0.8)
plt.title("Original Data (PCA)")
plt.xlabel("PC1")
plt.ylabel("PC2")

for i, (name, algorithm) in enumerate(clustering_algorithms.items()):
    # Apply clustering
    labels = algorithm.fit_predict(X_scaled)
    
    # Plot clusters
    plt.subplot(1, 4, i+2)
    plt.scatter(X_pca[:, 0], X_pca[:, 1], c=labels, cmap='viridis', alpha=0.8)
    plt.title(name)
    plt.xlabel("PC1")
    plt.ylabel("PC2")
    
    # Calculate silhouette score if more than one cluster is found
    n_clusters = len(np.unique(labels))
    if n_clusters > 1 and -1 not in np.unique(labels):
        score = silhouette_score(X_scaled, labels)
        print(f"{name} - Silhouette Score: {score:.3f}")
    elif -1 in np.unique(labels):
        n_noise = np.sum(labels == -1)
        print(f"{name} - Found {n_clusters - 1} clusters and {n_noise} noise points")
    else:
        print(f"{name} - Found only one cluster")

plt.tight_layout()
plt.show()

# 6. Analyze cluster characteristics
# Let's use K-means for the final analysis
kmeans = KMeans(n_clusters=2, random_state=42)
cluster_labels = kmeans.fit_predict(X_scaled)

# Convert original data to DataFrame for analysis
df = pd.DataFrame(X_filled, columns=breast_cancer.feature_names)
df['cluster'] = cluster_labels
df['diagnosis'] = y

# Compare clusters with actual diagnosis
cluster_diagnosis = pd.crosstab(
    df['cluster'], df['diagnosis'], 
    rownames=['Cluster'], colnames=['Diagnosis']
)
print("\nCluster vs. Diagnosis:")
print(cluster_diagnosis)

# Analyze feature distributions by cluster
plt.figure(figsize=(15, 10))
for i, feature in enumerate(breast_cancer.feature_names[:6]):  # Show first 6 features
    plt.subplot(2, 3, i+1)
    sns.boxplot(x='cluster', y=feature, data=df)
    plt.title(feature)

plt.tight_layout()
plt.show()
```
