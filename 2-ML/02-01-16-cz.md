## 1. Úvod do výběru příznaků

Výběr příznaků je proces selekce relevantních příznaků (proměnných, prediktorů) pro použití při tvorbě modelu. Cílem je redukovat dimenzionalitu, snížit dobu učení, předejít přetrénování a zlepšit výkon modelu odstraněním irelevantních, redundantních nebo zašuměných příznaků.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score
from sklearn.feature_selection import SelectKBest, f_classif, RFE, SelectFromModel
from sklearn.pipeline import Pipeline

# Načtení datasetu pro demonstraci výběru příznaků
data = load_breast_cancer()
X = pd.DataFrame(data.data, columns=data.feature_names)
y = data.target

print(f"Původní tvar datasetu: {X.shape}")
print(f"Počet příznaků: {X.shape[1]}")
print(f"Názvy příznaků: {data.feature_names[:5]}...")  # Zobrazení prvních 5 příznaků
```

Potřeba výběru příznaků typicky vzniká z:
- Datasetů s velkým počtem příznaků
- Příznaků, které mohou být irelevantní pro cílovou proměnnou
- Redundantních příznaků, které poskytují podobné informace
- "Prokletí dimenzionality", které ovlivňuje výkon modelu

## 2. Filtrační metody

Filtrační metody hodnotí příznaky nezávisle na jakémkoli algoritmu strojového učení. Používají statistické testy nebo metriky pro skórování a řazení každého příznaku podle jeho vztahu s cílovou proměnnou.

### Jednorozměrný výběr příznaků

```python
# Použití korelace pro výběr příznaků
plt.figure(figsize=(12, 10))
correlation_matrix = X.corr()
sns.heatmap(correlation_matrix, annot=False, cmap='coolwarm')
plt.title('Korelační matice příznaků')
plt.tight_layout()
plt.show()

# Výběr vysoce korelovaných příznaků s cílovou proměnnou
def correlation_selector(X, y, num_feats):
    # Výpočet korelace mezi příznaky a cílem
    cor_list = []
    feature_names = X.columns.tolist()
    # Výpočet korelace
    for i in feature_names:
        cor = np.corrcoef(X[i], y)[0, 1]
        cor_list.append(cor)
    # Vytvoření dataframe příznak-korelace
    cor_feature = pd.DataFrame(
        {'příznak': feature_names, 'korelace': cor_list})
    cor_feature = cor_feature.sort_values(by=['korelace'], ascending=False)
    # Výběr nejlepších příznaků
    selected_features = cor_feature['příznak'][:num_feats].tolist()
    
    return selected_features

# Výběr 10 nejlepších příznaků na základě korelace
selected_features = correlation_selector(X, y, 10)
print("10 nejlepších příznaků podle korelace:")
print(selected_features)

# Použití SelectKBest s f_classif (ANOVA F-statistika)
selector = SelectKBest(f_classif, k=10)
X_new = selector.fit_transform(X, y)

# Získání názvů vybraných příznaků
mask = selector.get_support()
selected_features_f = X.columns[mask]
print("\nPříznaky vybrané pomocí SelectKBest:")
print(selected_features_f)
print(f"Nový tvar datasetu: {X_new.shape}")

# Vizualizace skóre příznaků
plt.figure(figsize=(12, 6))
plt.bar(X.columns[mask], selector.scores_[mask])
plt.xticks(rotation=90)
plt.title('Skóre příznaků z SelectKBest')
plt.tight_layout()
plt.show()
```

Další běžné filtrační metody zahrnují:
- Chi-kvadrát test (pro kategorické příznaky)
- Informační zisk
- Vzájemná informace
- Fisherovo skóre
- Prahování rozptylu (odstranění příznaků s nízkým rozptylem)

## 3. Obalové metody

Obalové metody používají prediktivní model k hodnocení podmnožin příznaků. Trénují nový model pro každou podmnožinu a vybírají příznaky na základě výkonu modelu.

### Rekurzivní eliminace příznaků (RFE)

```python
# Rekurzivní eliminace příznaků s modelem logistické regrese
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Škálování příznaků
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# Vytvoření a konfigurace RFE
model = LogisticRegression(max_iter=1000, solver='liblinear')
rfe = RFE(estimator=model, n_features_to_select=10, step=1)

# Trénování RFE
rfe.fit(X_train_scaled, y_train)

# Získání vybraných příznaků
selected_features_rfe = X_train.columns[rfe.support_]
print("Příznaky vybrané pomocí RFE:")
print(selected_features_rfe)

# Trénování modelu s vybranými příznaky
X_train_rfe = X_train_scaled[:, rfe.support_]
X_test_rfe = X_test_scaled[:, rfe.support_]

model.fit(X_train_rfe, y_train)
y_pred = model.predict(X_test_rfe)
print(f"Přesnost modelu s příznaky vybranými pomocí RFE: {accuracy_score(y_test, y_pred):.4f}")

# Vizualizace hodnocení příznaků pomocí RFE
plt.figure(figsize=(12, 6))
plt.bar(X.columns, rfe.ranking_)
plt.xticks(rotation=90)
plt.title('Hodnocení příznaků z RFE (nižší je lepší)')
plt.tight_layout()
plt.show()
```

### Dopředný a zpětný výběr

```python
from sklearn.feature_selection import SequentialFeatureSelector

# Dopředný výběr
forward_selector = SequentialFeatureSelector(
    model, n_features_to_select=10, direction='forward', scoring='accuracy'
)
forward_selector.fit(X_train_scaled, y_train)

# Získání vybraných příznaků
forward_features = X_train.columns[forward_selector.get_support()]
print("Příznaky vybrané dopředným výběrem:")
print(forward_features)

# Zpětný výběr
backward_selector = SequentialFeatureSelector(
    model, n_features_to_select=10, direction='backward', scoring='accuracy'
)
backward_selector.fit(X_train_scaled, y_train)

# Získání vybraných příznaků
backward_features = X_train.columns[backward_selector.get_support()]
print("Příznaky vybrané zpětným výběrem:")
print(backward_features)

# Porovnání výkonu
X_train_fwd = forward_selector.transform(X_train_scaled)
X_test_fwd = forward_selector.transform(X_test_scaled)
model.fit(X_train_fwd, y_train)
fwd_accuracy = accuracy_score(y_test, model.predict(X_test_fwd))

X_train_bwd = backward_selector.transform(X_train_scaled)
X_test_bwd = backward_selector.transform(X_test_scaled)
model.fit(X_train_bwd, y_train)
bwd_accuracy = accuracy_score(y_test, model.predict(X_test_bwd))

print(f"Přesnost dopředného výběru: {fwd_accuracy:.4f}")
print(f"Přesnost zpětného výběru: {bwd_accuracy:.4f}")
```

## 4. Vestavěné metody

## 5. Redukce dimenzionality vs. výběr příznaků

Zatímco výběr příznaků vybírá podmnožinu původních příznaků, redukce dimenzionality vytváří nové příznaky, které jsou transformacemi původních.

```python
from sklearn.decomposition import PCA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis as LDA

# PCA pro redukci dimenzionality
pca = PCA(n_components=10)
X_train_pca = pca.fit_transform(X_train_scaled)
X_test_pca = pca.transform(X_test_scaled)

# Poměr vysvětlené variance
plt.figure(figsize=(10, 6))
plt.plot(np.cumsum(pca.explained_variance_ratio_), marker='o')
plt.xlabel('Počet komponent')
plt.ylabel('Kumulativní vysvětlená variance')
plt.axhline(y=0.95, color='r', linestyle='-')
plt.title('PCA - Vysvětlená variance')
plt.grid(True)
plt.show()

print(f"Počet komponent potřebných pro 95% variance: {np.argmax(np.cumsum(pca.explained_variance_ratio_) >= 0.95) + 1}")

# LDA pro supervizovanou redukci dimenzionality
lda = LDA(n_components=1)  # Binární klasifikace, takže max. 1 komponenta
X_train_lda = lda.fit_transform(X_train_scaled, y_train)
X_test_lda = lda.transform(X_test_scaled)

# Trénování modelů a porovnání výkonu
models = {
    "Původní příznaky": (X_train_scaled, X_test_scaled),
    "PCA příznaky": (X_train_pca, X_test_pca),
    "LDA příznaky": (X_train_lda, X_test_lda.reshape(-1, 1))
}

results = []
for name, (X_tr, X_te) in models.items():
    model = LogisticRegression(max_iter=1000)
    model.fit(X_tr, y_train)
    accuracy = accuracy_score(y_test, model.predict(X_te))
    results.append({"Metoda": name, "Přesnost": accuracy, "Příznaky": X_tr.shape[1]})
    
results_df = pd.DataFrame(results)
print(results_df)

# Vykreslení porovnání
plt.figure(figsize=(10, 6))
sns.barplot(x='Metoda', y='Přesnost', data=results_df)
plt.title('Porovnání výkonu modelu')
plt.ylim(0.9, 1.0)  # Přizpůsobte podle potřeby
plt.tight_layout()
plt.show()
```

## 6. Výběr příznaků pomocí scikit-learn

Scikit-learn poskytuje komplexní sadu nástrojů pro výběr příznaků, které lze integrovat do strojového učení.

```python
# Vytvoření pipeline s výběrem příznaků
from sklearn.pipeline import Pipeline
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV

# Vytvoření pipeline s výběrem příznaků a klasifikátorem
pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('feature_selection', SelectKBest(f_classif)),
    ('classifier', RandomForestClassifier(random_state=42))
])

# Definice mřížky parametrů pro ladění
param_grid = {
    'feature_selection__k': [5, 10, 15, 20],
    'classifier__n_estimators': [50, 100],
    'classifier__max_depth': [None, 10, 20]
}

# Vyhledávání nejlepších parametrů pomocí grid search
grid_search = GridSearchCV(
    pipeline, param_grid, cv=5, scoring='accuracy', verbose=1, n_jobs=-1
)
grid_search.fit(X_train, y_train)

# Nejlepší parametry a skóre
print(f"Nejlepší parametry: {grid_search.best_params_}")
print(f"Nejlepší CV skóre: {grid_search.best_score_:.4f}")

# Vyhodnocení na testovacím setu
y_pred_pipeline = grid_search.predict(X_test)
print(f"Přesnost na testovacím setu: {accuracy_score(y_test, y_pred_pipeline):.4f}")

# Získání nejlepšího počtu příznaků
best_k = grid_search.best_params_['feature_selection__k']
print(f"Optimální počet příznaků: {best_k}")

# Získání vybraných příznaků
best_pipeline = grid_search.best_estimator_
feature_selector = best_pipeline.named_steps['feature_selection']
selected_indices = feature_selector.get_support()
selected_features = X.columns[selected_indices]
print(f"Vybrané příznaky: {selected_features}")
```

## 7. Výběr příznaků pro různé modely

Různé modely mohou těžit z různých přístupů k výběru příznaků. Zde je postup pro výběr příznaků pro různé algoritmy:

```python
from sklearn.svm import SVC
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier

# Definice různých modelů
models = {
    'Logistická regrese': LogisticRegression(max_iter=1000),
    'Náhodný les': RandomForestClassifier(random_state=42),
    'SVM': SVC(probability=True),
    'K-nejbližší sousedé': KNeighborsClassifier(),
    'Rozhodovací strom': DecisionTreeClassifier(random_state=42)
}

# Metody výběru příznaků
feature_selectors = {
    'Filtr (SelectKBest)': SelectKBest(f_classif, k=10),
    'Obalová metoda (RFE)': RFE(estimator=LogisticRegression(max_iter=1000), n_features_to_select=10),
    'Vestavěná metoda (Náhodný les)': SelectFromModel(RandomForestClassifier(random_state=42))
}

# Otestování každé kombinace
results = []

for model_name, model in models.items():
    # Výchozí (bez výběru příznaků)
    model.fit(X_train_scaled, y_train)
    baseline_accuracy = accuracy_score(y_test, model.predict(X_test_scaled))
    results.append({
        'Model': model_name,
        'Metoda výběru': 'Žádná (Výchozí)',
        'Přesnost': baseline_accuracy,
        'Příznaky': X_train_scaled.shape[1]
    })
    
    # Otestování každé metody výběru příznaků
    for selector_name, selector in feature_selectors.items():
        selector.fit(X_train_scaled, y_train)
        X_train_selected = selector.transform(X_train_scaled)
        X_test_selected = selector.transform(X_test_scaled)
        
        model.fit(X_train_selected, y_train)
        accuracy = accuracy_score(y_test, model.predict(X_test_selected))
        
        results.append({
            'Model': model_name,
            'Metoda výběru': selector_name,
            'Přesnost': accuracy,
            'Příznaky': X_train_selected.shape[1]
        })

# Převedení výsledků do DataFrame pro analýzu
results_df = pd.DataFrame(results)
print(results_df)

# Vizualizace výsledků
plt.figure(figsize=(15, 10))
sns.barplot(x='Model', y='Přesnost', hue='Metoda výběru', data=results_df)
plt.title('Výkon modelu s různými metodami výběru příznaků')
plt.ylim(0.9, 1.0)  # Přizpůsobte podle potřeby
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

## 8. Hodnocení dopadu výběru příznaků

Je důležité vyhodnotit, jak výběr příznaků ovlivňuje výkon modelu napříč různými metrikami:

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score
from sklearn.model_selection import cross_val_score

# Definice funkce pro vyhodnocení modelu
def evaluate_model(model, X_train, X_test, y_train, y_test):
    # Trénování modelu
    model.fit(X_train, y_train)
    
    # Predikce
    y_pred = model.predict(X_test)
    
    # Výpočet metrik
    accuracy = accuracy_score(y_test, y_pred)
    precision = precision_score(y_test, y_pred)
    recall = recall_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred)
    
    # Pro ROC AUC potřebujeme pravděpodobnostní predikce
    if hasattr(model, "predict_proba"):
        y_pred_proba = model.predict_proba(X_test)[:, 1]
        roc_auc = roc_auc_score(y_test, y_pred_proba)
    else:
        roc_auc = None
        
    # Cross-validation skóre
    cv_scores = cross_val_score(model, X_train, y_train, cv=5, scoring='accuracy')
    cv_mean = cv_scores.mean()
    cv_std = cv_scores.std()
    
    return {
        'Přesnost': accuracy,
        'Preciznost': precision,
        'Úplnost': recall,
        'F1 skóre': f1,
        'ROC AUC': roc_auc,
        'CV průměr': cv_mean,
        'CV směr.odch.': cv_std
    }

# Základní model bez výběru příznaků
base_model = RandomForestClassifier(random_state=42)
base_results = evaluate_model(base_model, X_train_scaled, X_test_scaled, y_train, y_test)

# Model s SelectKBest
kbest_selector = SelectKBest(f_classif, k=10)
X_train_kbest = kbest_selector.fit_transform(X_train_scaled, y_train)
X_test_kbest = kbest_selector.transform(X_test_scaled)
kbest_model = RandomForestClassifier(random_state=42)
kbest_results = evaluate_model(kbest_model, X_train_kbest, X_test_kbest, y_train, y_test)

# Model s RFE
rfe_selector = RFE(estimator=LogisticRegression(max_iter=1000), n_features_to_select=10)
X_train_rfe = rfe_selector.fit_transform(X_train_scaled, y_train)
X_test_rfe = rfe_selector.transform(X_test_scaled)
rfe_model = RandomForestClassifier(random_state=42)
rfe_results = evaluate_model(rfe_model, X_train_rfe, X_test_rfe, y_train, y_test)

# Kompilace výsledků
all_results = pd.DataFrame({
    'Bez výběru': base_results,
    'SelectKBest': kbest_results,
    'RFE': rfe_results
})

print(all_results.T)

# Vizualizace porovnání
plt.figure(figsize=(14, 10))
for i, metric in enumerate(['Přesnost', 'Preciznost', 'Úplnost', 'F1 skóre', 'ROC AUC']):
    plt.subplot(2, 3, i+1)
    
    if metric in all_results.columns:
        values = [all_results[metric]['Bez výběru'], 
                  all_results[metric]['SelectKBest'], 
                  all_results[metric]['RFE']]
        
        plt.bar(['Bez výběru', 'SelectKBest', 'RFE'], values)
        plt.title(f'Porovnání {metric}')
        plt.ylim(0.9, 1.0)  # Upravte podle potřeby

plt.tight_layout()
plt.show()

# Porovnání času trénování
import time

methods = ['Bez výběru', 'SelectKBest', 'RFE', 'Důležitost náhodného lesa']
times = []
n_features = []
```

## 9. Shrnutí

Výběr příznaků je klíčovým krokem v procesu strojového učení, který pomáhá:

1. **Zlepšit výkon modelu** odstraněním irelevantních nebo redundantních příznaků
2. **Snížit přetrénování** snížením složitosti modelu
3. **Zlepšit interpretovatelnost** zaměřením se na nejdůležitější příznaky
4. **Urychlit trénování** snížením dimenzionality
5. **Snížit výpočetní náklady** jak pro trénování, tak pro inferenci

Klíčové přístupy k výběru příznaků:

- **Filtrační metody**: Rychlé techniky nezávislé na modelu, které vybírají příznaky na základě statistických měřítek
- **Obalové metody**: Výpočetně náročnější, ale potenciálně přesnější, protože používají výkon modelu k výběru příznaků
- **Vestavěné metody**: Začleňují výběr příznaků do procesu trénování modelu

Osvědčené postupy:

1. **Začněte s průzkumnou analýzou dat** pro pochopení vztahů mezi příznaky
2. **Použijte více metod výběru příznaků** a porovnejte výsledky
3. **Ověřte výběr příznaků** pomocí křížové validace
4. **Vezměte v úvahu znalosti o doméně** při interpretaci vybraných příznaků
5. **Vyvažte výkon modelu a interpretovatelnost** při volbě počtu příznaků
