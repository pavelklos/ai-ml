## Úvod do křížové validace

Křížová validace je statistická metoda používaná k odhadu výkonnosti modelů strojového učení. Pomáhá posoudit, jak dobře se model bude generalizovat na nezávislý dataset a zabraňuje přetrénování. Využitím různých podmnožin dat pro trénink a validaci poskytuje křížová validace robustnější hodnocení než jednoduché rozdělení na trénovací a testovací data.

```python
# Potřebné knihovny pro křížovou validaci
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split, cross_val_score, KFold
from sklearn.model_selection import StratifiedKFold, LeaveOneOut, TimeSeriesSplit
from sklearn.model_selection import GridSearchCV, cross_validate
from sklearn.metrics import accuracy_score, mean_squared_error, make_scorer
from sklearn.datasets import load_iris, load_boston, fetch_california_housing
from sklearn.linear_model import LogisticRegression, LinearRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC
import warnings
warnings.filterwarnings('ignore')

# Pro reprodukovatelnost
np.random.seed(42)
```

## Rozdělení na trénovací a testovací data a jeho omezení

Nejjednodušší formou validace modelu je rozdělení datasetu na trénovací a testovací část. Ačkoli je tento přístup přímočarý, může trpět vysokou variancí v závislosti na konkrétních datových bodech, které se dostanou do trénovací a testovací množiny.

```python
# Načtení ukázkového datasetu
iris = load_iris()
X = iris.data
y = iris.target

# Jednoduché rozdělení na trénink a test
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Trénování modelu
model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)

# Vyhodnocení na testovací množině
y_pred = model.predict(X_test)
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost modelu s jednoduchým rozdělením na trénink a test: {accuracy:.4f}")

# Vyzkoušení jiného náhodného rozdělení ukazuje variabilitu výsledků
X_train2, X_test2, y_train2, y_test2 = train_test_split(X, y, test_size=0.3, random_state=123)
model.fit(X_train2, y_train2)
y_pred2 = model.predict(X_test2)
accuracy2 = accuracy_score(y_test2, y_pred2)
print(f"Přesnost modelu s jiným rozdělením: {accuracy2:.4f}")
print(f"Rozdíl v přesnosti: {abs(accuracy - accuracy2):.4f}")
```

## K-násobná křížová validace

K-násobná křížová validace rozděluje dataset na K stejně velkých částí (foldů). Model je trénován na K-1 foldech a validován na zbývajícím foldu. Tento proces se opakuje K krát, přičemž každý fold je použit přesně jednou jako validační data. Výsledky jsou pak zprůměrovány k získání jediného odhadu výkonnosti.

```python
# Nastavení K-násobné křížové validace
k_folds = 5
kf = KFold(n_splits=k_folds, shuffle=True, random_state=42)

# Model k vyhodnocení
model = LogisticRegression(max_iter=200)

# Provedení křížové validace
cv_results = cross_val_score(model, X, y, cv=kf, scoring='accuracy')

# Zobrazení výsledků
print(f"Výsledky K-násobné křížové validace (K={k_folds}):")
print(f"Přesnost jednotlivých foldů: {cv_results}")
print(f"Průměrná přesnost: {cv_results.mean():.4f}")
print(f"Směrodatná odchylka: {cv_results.std():.4f}")

# Vizualizace procesu K-násobné křížové validace
plt.figure(figsize=(10, 6))
for fold, (train_idx, val_idx) in enumerate(kf.split(X)):
    plt.scatter(range(len(train_idx)), [fold] * len(train_idx), c='blue', alpha=0.2, s=10, label='Trénink' if fold == 0 else "")
    plt.scatter(range(len(val_idx)), [fold] * len(val_idx), c='red', alpha=0.5, s=10, label='Validace' if fold == 0 else "")

plt.yticks(range(k_folds))
plt.xlabel("Datové body")
plt.ylabel("Fold")
plt.title("K-násobná křížová validace (K=5)")
plt.legend()
plt.tight_layout()
plt.show()
```

## Stratifikovaná K-násobná křížová validace

Stratifikovaná K-násobná validace je varianta K-násobné validace, která zajišťuje, že každý fold zachovává procentuální zastoupení vzorků pro každou třídu. To je zvlášť důležité pro nevyvážené datasety nebo když má cílová proměnná asymetrické rozložení.

```python
# Vytvoření nevyváženého datasetu
# Vybrání podsady iris pouze se dvěma třídami a jejím nevyvážením
X_imb = X[y != 2]  # Vyloučení třetí třídy
y_imb = y[y != 2]  # Pouze třídy 0 a 1
indices = np.where(y_imb == 1)[0]  # Indexy třídy 1
remove_indices = np.random.choice(indices, size=int(0.7 * len(indices)), replace=False)
mask = np.ones(len(y_imb), bool)
mask[remove_indices] = False
X_imb = X_imb[mask]
y_imb = y_imb[mask]

# Kontrola rozložení tříd
unique, counts = np.unique(y_imb, return_counts=True)
print("Rozložení tříd v nevyváženém datasetu:")
for class_label, count in zip(unique, counts):
    print(f"Třída {class_label}: {count} vzorků ({count/len(y_imb):.2%})")

# Běžná K-násobná validace
kf = KFold(n_splits=5, shuffle=True, random_state=42)
folds_class_counts = []
for train_idx, test_idx in kf.split(X_imb):
    _, test_counts = np.unique(y_imb[test_idx], return_counts=True)
    if len(test_counts) < 2:  # Pokud fold neobsahuje některou třídu
        test_counts = np.append(test_counts, 0)
    folds_class_counts.append(test_counts / len(test_idx))

print("\nRozložení tříd v každém foldu při použití standardní KFold:")
for i, counts in enumerate(folds_class_counts):
    print(f"Fold {i+1}: Třída 0: {counts[0]:.2%}, Třída 1: {counts[1]:.2%}")

# Stratifikovaná K-násobná validace
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
strat_folds_class_counts = []
for train_idx, test_idx in skf.split(X_imb, y_imb):
    _, test_counts = np.unique(y_imb[test_idx], return_counts=True)
    strat_folds_class_counts.append(test_counts / len(test_idx))

print("\nRozložení tříd v každém foldu při použití StratifiedKFold:")
for i, counts in enumerate(strat_folds_class_counts):
    print(f"Fold {i+1}: Třída 0: {counts[0]:.2%}, Třída 1: {counts[1]:.2%}")

# Porovnání výkonu modelů
model = LogisticRegression(max_iter=200)
standard_cv = cross_val_score(model, X_imb, y_imb, cv=kf, scoring='accuracy')
stratified_cv = cross_val_score(model, X_imb, y_imb, cv=skf, scoring='accuracy')

print(f"\nStandardní K-násobná CV přesnost: {standard_cv.mean():.4f} ± {standard_cv.std():.4f}")
print(f"Stratifikovaná K-násobná CV přesnost: {stratified_cv.mean():.4f} ± {stratified_cv.std():.4f}")
```

## Křížová validace s vynecháním jednoho prvku (LOOCV)

Křížová validace s vynecháním jednoho prvku (Leave-One-Out) je extrémním případem K-násobné validace, kde K se rovná počtu datových bodů. V každé iteraci je jediné pozorování použito jako validační sada, zatímco všechna ostatní jsou použita pro trénování. Ačkoliv je výpočetně náročná, je užitečná pro malé datasety.

```python
# Vytvoření malého datasetu pro demonstraci
housing = fetch_california_housing()
X_small = housing.data[:100]  # Použití pouze 100 vzorků pro efektivitu
y_small = housing.target[:100]

# Nastavení Leave-One-Out křížové validace
loo = LeaveOneOut()

# Model pro regresi
model = LinearRegression()

# Ukládání predikcí
y_pred = np.zeros_like(y_small)
for train_idx, test_idx in loo.split(X_small):
    X_train, X_test = X_small[train_idx], X_small[test_idx]
    y_train = y_small[train_idx]
    model.fit(X_train, y_train)
    y_pred[test_idx] = model.predict(X_test)

# Vyhodnocení modelu
mse = mean_squared_error(y_small, y_pred)
print(f"Leave-One-Out střední kvadratická chyba: {mse:.4f}")

# Porovnání s 5-násobnou CV z pohledu výpočetní efektivity
start_time = pd.Timestamp.now()
loo_cv = cross_val_score(model, X_small, y_small, cv=loo, scoring='neg_mean_squared_error')
loo_time = (pd.Timestamp.now() - start_time).total_seconds()

start_time = pd.Timestamp.now()
kf5_cv = cross_val_score(model, X_small, y_small, cv=5, scoring='neg_mean_squared_error')
kf5_time = (pd.Timestamp.now() - start_time).total_seconds()

print(f"\nLOOCV doba výpočtu: {loo_time:.2f} sekund")
print(f"5-násobná CV doba výpočtu: {kf5_time:.2f} sekund")
print(f"LOOCV je {loo_time/kf5_time:.1f}x pomalejší než 5-násobná CV")
```

## Křížová validace pro časové řady

Data časových řad vyžadují speciální metody křížové validace kvůli jejich časovému uspořádání. Náhodné rozdělení by způsobilo únik dat, protože budoucí data by byla použita k predikci minulých událostí. Křížová validace pro časové řady zajišťuje, že trénovací data vždy předcházejí validačním datům.

```python
# Vygenerování jednoduchého datasetu časové řady
np.random.seed(42)
n_samples = 100
time = np.arange(n_samples)
trend = 0.1 * time
noise = np.random.normal(0, 0.5, size=n_samples)
y_time = trend + noise
X_time = time.reshape(-1, 1)

# Vizualizace časové řady
plt.figure(figsize=(10, 6))
plt.plot(time, y_time, label='Data časové řady')
plt.xlabel('Čas')
plt.ylabel('Hodnota')
plt.title('Simulovaná data časové řady s trendem')
plt.legend()
plt.grid(True)
plt.show()

# Nastavení TimeSeriesSplit
tscv = TimeSeriesSplit(n_splits=5)

# Vizualizace rozdělení časové řady
plt.figure(figsize=(12, 8))
for i, (train_idx, test_idx) in enumerate(tscv.split(X_time)):
    fold_color = plt.cm.viridis(i/5)  # Různé barvy pro každý fold
    
    # Vykreslení indexů pro každou trénovací/testovací sadu
    plt.scatter(time[train_idx], [i] * len(train_idx), 
                c=[fold_color], marker='_', s=60, alpha=0.7, label=f'Trénovací fold {i+1}' if i == 0 else "")
    plt.scatter(time[test_idx], [i] * len(test_idx), 
                c=[fold_color], marker='x', s=60, alpha=1, label=f'Testovací fold {i+1}' if i == 0 else "")

plt.yticks(range(5))
plt.xlabel('Čas')
plt.ylabel('CV Iterace')
plt.title('Křížová validace časových řad')
plt.legend()
plt.tight_layout()
plt.show()

# Provedení křížové validace pro časové řady
model = LinearRegression()
cv_results = cross_val_score(model, X_time, y_time, 
                              cv=tscv, scoring='neg_mean_squared_error')

print(f"Výsledky křížové validace časových řad:")
print(f"MSE jednotlivých foldů: {-cv_results}")  # Záporné znaménko kvůli konvenci sklearn pro skórovací funkce
print(f"Průměrná MSE: {-cv_results.mean():.4f}")
print(f"Směrodatná odchylka: {cv_results.std():.4f}")
```

## Vnořená křížová validace

Vnořená křížová validace se používá, když potřebujete ladit hyperparametry a zároveň odhadovat výkon modelu. Sestává z vnitřní smyčky pro ladění hyperparametrů a vnější smyčky pro odhad výkonu, což zabraňuje úniku informací, ke kterému může dojít při použití stejných dat pro oba úkoly.

```python
# Načtení datasetu
iris = load_iris()
X, y = iris.data, iris.target

# Definování modelu a mřížky parametrů
model = SVC()
param_grid = {
    'C': [0.1, 1, 10, 100],
    'gamma': [0.001, 0.01, 0.1, 1],
    'kernel': ['rbf', 'linear']
}

# Nastavení vnější a vnitřní křížové validace
outer_cv = KFold(n_splits=5, shuffle=True, random_state=42)
inner_cv = KFold(n_splits=3, shuffle=True, random_state=42)

# Nastavení vnořené křížové validace
nested_scores = np.zeros(outer_cv.get_n_splits())
best_params = []

for i, (train_idx, test_idx) in enumerate(outer_cv.split(X)):
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]
    
    # Vnitřní smyčka pro ladění hyperparametrů
    grid_search = GridSearchCV(estimator=model, param_grid=param_grid, cv=inner_cv)
    grid_search.fit(X_train, y_train)
    
    # Uložení nejlepších parametrů z tohoto foldu
    best_params.append(grid_search.best_params_)
    
    # Testování nejlepšího modelu na vnějším foldu
    y_pred = grid_search.predict(X_test)
    nested_scores[i] = accuracy_score(y_test, y_pred)

# Vypsání výsledků
print("Výsledky vnořené křížové validace:")
print(f"Přesnost jednotlivých foldů: {nested_scores}")
print(f"Průměrná přesnost: {nested_scores.mean():.4f}")
print(f"Směrodatná odchylka: {nested_scores.std():.4f}")

print("\nNejlepší parametry v každém vnějším foldu:")
for i, params in enumerate(best_params):
    print(f"Fold {i+1}: {params}")

# Porovnání s nevnořenou křížovou validací (která může nadhodnocovat výkon)
grid_search = GridSearchCV(estimator=model, param_grid=param_grid, cv=5)
grid_search.fit(X, y)
non_nested_scores = cross_val_score(grid_search.best_estimator_, X, y, cv=5)

print("\nPorovnání s nevnořenou křížovou validací:")
print(f"Vnořená CV průměrná přesnost: {nested_scores.mean():.4f}")
print(f"Nevnořená CV průměrná přesnost: {non_nested_scores.mean():.4f}")
```

## Křížová validace s laděním hyperparametrů

GridSearchCV a RandomizedSearchCV jsou užitečné nástroje pro ladění hyperparametrů a křížovou validaci. Provádějí vyčerpávající prohledávání prostoru parametrů a hodnotí výkon modelu pomocí křížové validace.

```python
# Načtení datasetu
iris = load_iris()
X, y = iris.data, iris.target

# Vytvoření modelu s hyperparametry k ladění
rf_model = RandomForestClassifier(random_state=42)

# Definování mřížky parametrů
param_grid = {
    'n_estimators': [50, 100, 200],
    'max_depth': [None, 10, 20, 30],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 2, 4]
}

# Pro rychlejší běh příkladu použijeme menší mřížku
small_param_grid = {
    'n_estimators': [50, 100],
    'max_depth': [None, 20],
    'min_samples_split': [2, 5]
}

# Nastavení GridSearchCV
grid_search = GridSearchCV(
    estimator=rf_model,
    param_grid=small_param_grid,
    cv=5,
    scoring='accuracy',
    return_train_score=True,
    verbose=1,
    n_jobs=-1
)

# Trénování modelu
grid_search.fit(X, y)

# Zobrazení výsledků
print("Nejlepší parametry:", grid_search.best_params_)
print("Nejlepší CV skóre:", grid_search.best_score_)

# Prozkoumání výsledků v DataFrame pro lepší vizualizaci
results_df = pd.DataFrame(grid_search.cv_results_)
cols = ['param_n_estimators', 'param_max_depth', 'param_min_samples_split', 
        'mean_test_score', 'std_test_score', 'mean_train_score', 'std_train_score']
results_summary = results_df[cols].sort_values(by='mean_test_score', ascending=False)
print("\nVýsledky seřazené podle testovacího skóre (top 5):")
print(results_summary.head())

# Vizualizace vlivu parametrů
plt.figure(figsize=(12, 8))

# Seskupení podle n_estimators a max_depth
grouped_results = results_df.groupby(['param_n_estimators', 'param_max_depth']).mean()
pivoted = grouped_results.reset_index().pivot('param_n_estimators', 'param_max_depth', 'mean_test_score')

plt.figure(figsize=(10, 6))
sns.heatmap(pivoted, annot=True, cmap='viridis', fmt='.3f')
plt.title('Vliv n_estimators a max_depth na CV skóre')
plt.tight_layout()
plt.show()
```

## Evaluační metriky v křížové validaci

Pro křížovou validaci lze použít různé metriky v závislosti na typu problému (klasifikace vs. regrese) a specifických požadavcích. Použití vhodných metrik je klíčové pro výběr a hodnocení modelu.

```python
# Načtení datasetů pro klasifikaci a regresi
iris = load_iris()
X_class, y_class = iris.data, iris.target

housing = fetch_california_housing()
X_reg = housing.data[:500]  # Používáme podmnožinu pro efektivitu
y_reg = housing.target[:500]

# Klasifikační metriky
classification_metrics = ['accuracy', 'precision_macro', 'recall_macro', 'f1_macro', 'roc_auc_ovr']
model_class = RandomForestClassifier(random_state=42)

# Křížová validace s více metrikami
class_results = cross_validate(model_class, X_class, y_class, cv=5, scoring=classification_metrics)

# Zobrazení výsledků klasifikace
print("Výsledky křížové validace pro klasifikaci:")
for metric in classification_metrics:
    scores = class_results[f'test_{metric}']
    print(f"{metric}: {scores.mean():.4f} ± {scores.std():.4f}")

# Regresní metriky
regression_metrics = ['r2', 'neg_mean_squared_error', 'neg_mean_absolute_error']
model_reg = LinearRegression()

# Křížová validace s více metrikami
reg_results = cross_validate(model_reg, X_reg, y_reg, cv=5, scoring=regression_metrics)

# Zobrazení výsledků regrese
print("\nVýsledky křížové validace pro regresi:")
for metric in regression_metrics:
    scores = reg_results[f'test_{metric}']
    print(f"{metric}: {scores.mean():.4f} ± {scores.std():.4f}")

# Použití vlastní skórovací metriky
def custom_rmse(y_true, y_pred):
    return np.sqrt(mean_squared_error(y_true, y_pred))

rmse_scorer = make_scorer(custom_rmse, greater_is_better=False)

custom_results = cross_validate(model_reg, X_reg, y_reg, cv=5, 
                               scoring={'rmse': rmse_scorer, 'r2': 'r2'})

print("\nVýsledky křížové validace s vlastní metrikou:")
print(f"RMSE: {-custom_results['test_rmse'].mean():.4f} ± {custom_results['test_rmse'].std():.4f}")
print(f"R²: {custom_results['test_r2'].mean():.4f} ± {custom_results['test_r2'].std():.4f}")
```

## Shrnutí a osvědčené postupy

Křížová validace je kritickou součástí workflow ve strojovém učení. Poskytuje robustní odhad výkonu modelu a pomáhá detekovat a předcházet přetrénování. Zde jsou klíčové poznatky a osvědčené postupy:

```python
# Shrnutí příkladů: Porovnání různých strategií CV na klasifikačním problému
iris = load_iris()
X, y = iris.data, iris.target

# Definování modelu
model = LogisticRegression(max_iter=200)

# Různé strategie křížové validace
cv_strategies = {
    'Rozdělení trénink-test': ShuffleSplit(n_splits=1, test_size=0.3, random_state=42),
    '5-násobná CV': KFold(n_splits=5, shuffle=True, random_state=42),
    'Stratifikovaná 5-násobná CV': StratifiedKFold(n_splits=5, shuffle=True, random_state=42),
    'Leave-One-Out CV': LeaveOneOut(),
    '5-násobná CV pro časové řady': TimeSeriesSplit(n_splits=5)
}

# Vyhodnocení každé strategie
results = {}
for name, cv in cv_strategies.items():
    try:
        scores = cross_val_score(model, X, y, cv=cv, scoring='accuracy')
        results[name] = (scores.mean(), scores.std())
    except Exception as e:
        print(f"Chyba u {name}: {e}")

# Vypsání výsledků
print("Porovnání strategií křížové validace:")
for name, (mean, std) in results.items():
    print(f"{name}: {mean:.4f} ± {std:.4f}")

# Vizualizace klíčových bodů
plt.figure(figsize=(12, 8))
```

**Osvědčené postupy pro křížovou validaci:**

1. **Zvolte správnou strategii**: Vyberte metodu křížové validace na základě charakteristik datasetu (velikost, vyváženost, časová struktura).

2. **Stratifikace**: U klasifikačních problémů s nevyváženými třídami použijte stratifikovaný sampling.

3. **Počet foldů**: 
   - 5-10 foldů obecně poskytuje dobrý kompromis mezi zkreslením a variancí
   - Pro velmi malé datasety použijte více foldů (nebo LOOCV)
   - Pro velké datasety použijte méně foldů k úspoře výpočetního času

4. **Vnořená CV**: Použijte vnořenou křížovou validaci, když potřebujete ladit hyperparametry i odhadovat výkon.

5. **Vhodné metriky**: Vyberte evaluační metriky, které odpovídají cílům vašeho problému.

6. **Zpracování dat**: Zajistěte, aby kroky předzpracování dat byly zahrnuty v rámci křížové validace, aby nedocházelo k úniku dat.

7. **Reprodukovatelnost**: Nastavte náhodné seedy pro reprodukovatelné výsledky.

8. **Výpočetní efektivita**: Zvažte výpočetní náročnost, zejména u velkých datasetů nebo komplexních modelů.

Aplikací těchto strategií a osvědčených postupů křížové validace můžete vybudovat robustnější modely se spolehlivými odhady výkonu, což vede k lepší generalizaci na nová, neviděná data.
