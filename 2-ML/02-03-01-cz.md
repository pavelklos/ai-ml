## Konvoluční neuronové sítě (CNN)

CNN jsou specializované pro zpracování mřížkových dat, jako jsou obrázky. Používají konvoluční vrstvy k automatickému učení prostorových hierarchií příznaků.

### Klíčové komponenty CNN

1. **Konvoluční vrstvy**: Aplikují filtry k detekci příznaků
2. **Pooling vrstvy**: Snižují dimenzionalitu a extrahují dominantní příznaky
3. **Plně propojené vrstvy**: Kombinují příznaky pro klasifikaci/regresi

```python

def create_cnn_model_keras(input_shape=(28, 28, 1), num_classes=10):
    model = models.Sequential([
        # První konvoluční blok
        layers.Conv2D(32, (3, 3), activation='relu', padding='same', input_shape=input_shape),
        layers.BatchNormalization(),
        layers.Conv2D(32, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),
        
        # Druhý konvoluční blok
        layers.Conv2D(64, (3, 3), activation='relu', padding='same'),

        layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),

        layers.Dense(512, activation='relu'),
        layers.BatchNormalization(),
        layers.Dropout(0.5),
        layers.Dense(num_classes, activation='softmax')
    ])
    
    model.compile(
        optimizer='adam',
        loss='categorical_crossentropy',

    )
    
    return model
```

## Rekurentní neuronové sítě (RNN)

RNN zpracovávají sekvenční data udržováním skrytého stavu, který zachycuje informace o předchozích prvcích v sekvenci.

### Klíčové komponenty RNN

1. **Rekurentní buňky**: Zpracovávají sekvenční vstupy aktualizací skrytého stavu
2. **Long Short-Term Memory (LSTM)**: Řeší problém mizejícího gradientu pomocí bran
3. **Gated Recurrent Unit (GRU)**: Zjednodušená LSTM s méně parametry

```python
# Implementace RNN pomocí PyTorch
class RNNPyTorch(nn.Module):
    def __init__(self, vocab_size, embedding_dim=128, hidden_dim=128, num_layers=2, dropout=0.3):
        super(RNNPyTorch, self).__init__()
        
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        
        # LSTM vrstva
        self.lstm = nn.LSTM(
            embedding_dim, 
            hidden_dim, 
            num_layers=num_layers, 
            dropout=dropout if num_layers > 1 else 0,
            batch_first=True,
            bidirectional=False
        )
        
        # Výstupní vrstva
        self.fc = nn.Sequential(
            nn.Dropout(dropout),
            nn.Linear(hidden_dim, 64),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(64, 1),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        # x tvar: (batch_size, sequence_length)
        
        # Aplikace embedding vrstvy
        x = self.embedding(x)  # (batch_size, sequence_length, embedding_dim)
        
        # Aplikace LSTM
        lstm_out, _ = self.lstm(x)  # (batch_size, sequence_length, hidden_dim)
        
        # Použití posledního výstupu pro klasifikaci
        out = lstm_out[:, -1, :]  # (batch_size, hidden_dim)
        
        # Aplikace plně propojené vrstvy
        out = self.fc(out)  # (batch_size, 1)
        
        return out
```

## Architektura Transformer

Transformery používají mechanismy self-attention ke zpracování sekvenčních dat, což umožňuje paralelní zpracování a účinnější zachycení dlouhodobých závislostí než RNN.

### Klíčové komponenty Transformeru

1. **Self-attention**: Počítá váhy pozornosti mezi všemi pozicemi v sekvenci
2. **Multi-head attention**: Provozuje více operací self-attention paralelně
3. **Position encoding**: Přidává poziční informace k tokenům
4. **Encoder-decoder struktura**: Zpracovává vstup a generuje výstup

```python
# Jednoduchá implementace Transformeru pomocí TensorFlow/Keras
def transformer_encoder(inputs, head_size, num_heads, ff_dim, dropout=0):
    # Multi-head self-attention
    x = layers.LayerNormalization(epsilon=1e-6)(inputs)
    x = layers.MultiHeadAttention(
        key_dim=head_size, num_heads=num_heads, dropout=dropout
    )(x, x)
    x = layers.Dropout(dropout)(x)
    res = x + inputs

    # Feed Forward síť
    x = layers.LayerNormalization(epsilon=1e-6)(res)
    x = layers.Dense(ff_dim, activation="relu")(x)
    x = layers.Dropout(dropout)(x)
    x = layers.Dense(inputs.shape[-1])(x)
    x = layers.Dropout(dropout)(x)
    
    return x + res

def create_transformer_model_keras(
    input_length=100, 
    vocab_size=10000, 
    embedding_dim=128,
    num_heads=8,
    ff_dim=512,
    num_transformer_blocks=4,
    dropout=0.1
):
    inputs = layers.Input(shape=(input_length,))
    embedding_layer = layers.Embedding(vocab_size, embedding_dim)
    x = embedding_layer(inputs)
    
    # Přidání pozičního kódování (zjednodušená verze)
    positions = tf.range(start=0, limit=input_length, delta=1)
    positions = layers.Embedding(input_length, embedding_dim)(positions)
    x = x + positions
    
    # Transformer bloky
    for _ in range(num_transformer_blocks):
        x = transformer_encoder(x, embedding_dim//num_heads, num_heads, ff_dim, dropout)
    
    # Klasifikační hlavice
    x = layers.GlobalAveragePooling1D()(x)
    x = layers.Dense(64, activation="relu")(x)
    x = layers.Dropout(0.1)(x)
    outputs = layers.Dense(1, activation="sigmoid")(x)
    
    model = models.Model(inputs=inputs, outputs=outputs)
    model.compile(
        optimizer="adam", 
        loss="binary_crossentropy", 
        metrics=["accuracy"]
    )
    return model
```

```python
# Implementace Transformeru pomocí PyTorch
class TransformerEncoderLayer(nn.Module):
    def __init__(self, embed_dim, num_heads, ff_dim, dropout=0.1):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(embed_dim, num_heads, dropout=dropout, batch_first=True)
        
        self.feed_forward = nn.Sequential(
            nn.Linear(embed_dim, ff_dim),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(ff_dim, embed_dim),
            nn.Dropout(dropout)
        )
        
        self.norm1 = nn.LayerNorm(embed_dim)
        self.norm2 = nn.LayerNorm(embed_dim)
        self.dropout = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # Self attention
        attn_output, _ = self.self_attn(x, x, x, attn_mask=mask)
        x = x + self.dropout(attn_output)
        x = self.norm1(x)
        
        # Feed forward
        ff_output = self.feed_forward(x)
        x = x + ff_output
        x = self.norm2(x)
        
        return x

class TransformerPyTorch(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, num_heads=8, ff_dim=512, 
                 num_layers=4, max_len=100, dropout=0.1):
        super().__init__()
        
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.pos_embedding = nn.Embedding(max_len, embed_dim)
        
        self.transformer_blocks = nn.ModuleList(
            [TransformerEncoderLayer(embed_dim, num_heads, ff_dim, dropout) 
             for _ in range(num_layers)]
        )
        
        self.classifier = nn.Sequential(
            nn.Linear(embed_dim, 64),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(64, 1),
            nn.Sigmoid()
        )
        
        self.dropout = nn.Dropout(dropout)
        self.max_len = max_len
    
    def forward(self, x):
        # x tvar: (batch_size, seq_len)
        
        # Generování pozičních indexů
        batch_size, seq_len = x.size()
        positions = torch.arange(0, seq_len, device=x.device).expand(batch_size, seq_len)
        
        # Aplikace embeddingů
        x = self.embedding(x)  # (batch_size, seq_len, embed_dim)
        pos = self.pos_embedding(positions)  # (batch_size, seq_len, embed_dim)
        x = x + pos
        x = self.dropout(x)
        
        # Aplikace transformer bloků
        for block in self.transformer_blocks:
            x = block(x)
        
        # Globální průměrné poolování
        x = x.mean(dim=1)
        
        # Aplikace klasifikátoru
        x = self.classifier(x)
        
        return x
```

```python
def create_cnn_lstm_model(frames=10, height=64, width=64, channels=3):
    # Vstupní tvar: (frames, height, width, channels)
    inputs = layers.Input(shape=(frames, height, width, channels))
    
    # Aplikace CNN na každý snímek nezávisle
    x = layers.TimeDistributed(layers.Conv2D(32, (3, 3), activation='relu'))(inputs)
    x = layers.TimeDistributed(layers.MaxPooling2D((2, 2)))(x)
    x = layers.TimeDistributed(layers.Conv2D(64, (3, 3), activation='relu'))(x)

    x = layers.LSTM(128, return_sequences=True)(x)
    x = layers.LSTM(64)(x)
    
    # Klasifikační hlavice
    x = layers.Dense(32, activation='relu')(x)
    outputs = layers.Dense(10, activation='softmax')(x)  # 10 tříd
    
    model = models.Model(inputs=inputs, outputs=outputs)
```

```python
# Příklad CNN-Transformer hybridu pro popisování obrázků
def create_cnn_transformer_model(
    image_shape=(224, 224, 3), 
    vocab_size=10000, 
    embedding_dim=128,
    max_caption_len=50,
    num_heads=8,
    ff_dim=512
):
    # Kodér obrazu (CNN)
    image_input = layers.Input(shape=image_shape)
    cnn_base = tf.keras.applications.ResNet50(
        include_top=False, 
        weights='imagenet', 
        input_shape=image_shape
    )
    cnn_base.trainable = False  # Zamrazení vah
    
    image_features = cnn_base(image_input)
    image_features = layers.GlobalAveragePooling2D()(image_features)
    image_features = layers.Dense(embedding_dim)(image_features)
    
    # Rozšíření dimenzí pro kompatibilitu s transformer
    image_features = tf.expand_dims(image_features, 1)
    
    # Vstup a zpracování popisku
    caption_input = layers.Input(shape=(max_caption_len,))
    caption_embedding = layers.Embedding(vocab_size, embedding_dim)(caption_input)
    
    # Kombinace příznaků obrazu s embeddingy popisu
    x = layers.Concatenate(axis=1)([image_features, caption_embedding])
    
    # Přidání pozičního kódování
    positions = tf.range(start=0, limit=max_caption_len+1, delta=1)
    position_embedding = layers.Embedding(max_caption_len+1, embedding_dim)(positions)
    x = x + position_embedding
    
    # Transformer bloky
    for _ in range(4):
        x = transformer_encoder(x, embedding_dim//num_heads, num_heads, ff_dim, 0.1)
    
    # Výstupní predikce
    x = layers.Dense(vocab_size, activation='softmax')(x[:, 1:, :])
    
    model = models.Model([image_input, caption_input], x)
    model.compile(
        optimizer='adam',
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )
    return model
```

### Paměťová a výpočetní efektivita

```python
# Techniky pro optimalizaci využití paměti
def implement_gradient_accumulation(model, batch_size, sub_batch_size):
    """
    Příklad akumulace gradientu pro práci s velkými modely s omezenou pamětí GPU
    
    Argumenty:
        model: Keras model
        batch_size: Cílová efektivní velikost dávky
        sub_batch_size: Skutečná velikost dávky, která se použije (měla by být menší)
    """
    # Předpokládáme, že model a data jsou definovány jinde
    # Ukazujeme pouze koncept
    
    # Počet poddávek k akumulaci
    accumulation_steps = batch_size // sub_batch_size
    
    # Přizpůsobení trénovacího kroku s akumulací gradientů
    @tf.function
    def train_step(x_batch, y_batch):
        # Rozdělení dávky do poddávek
        sub_batches_x = tf.split(x_batch, accumulation_steps)
        sub_batches_y = tf.split(y_batch, accumulation_steps)
        
        # Zpracování každé poddávky
        for i in range(accumulation_steps):
            with tf.GradientTape() as tape:
                pred = model(sub_batches_x[i], training=True)
                loss = loss_fn(sub_batches_y[i], pred) / accumulation_steps
            
            # Akumulace gradientů
            gradients = tape.gradient(loss, model.trainable_variables)
            
            if i == 0:
                accumulated_gradients = [g for g in gradients]
            else:
                accumulated_gradients = [ag + g for ag, g in zip(accumulated_gradients, gradients)]
        
        # Aplikace akumulovaných gradientů
        optimizer.apply_gradients(zip(accumulated_gradients, model.trainable_variables))
    
    return train_step

# Příklad kvantizace modelu pro nasazení
def quantize_model(model_path, quantized_model_path):
    """
    Příklad kvantizace TensorFlow modelu pro nasazení
    
    Argumenty:
        model_path: Cesta k uloženému TensorFlow modelu
        quantized_model_path: Výstupní cesta pro kvantizovaný model
    """
    # Konverze modelu na model vědomý kvantizace
    converter = tf.lite.TFLiteConverter.from_saved_model(model_path)
    
    # Povolení kvantizace
    converter.optimizations = [tf.lite.Optimize.DEFAULT]
    
    # Volitelně: Definice přesnosti kvantizace
    # converter.target_spec.supported_types = [tf.float16]
    
    # Konverze modelu
    quantized_model = converter.convert()
    
    # Uložení modelu
    with open(quantized_model_path, 'wb') as f:
        f.write(quantized_model)
    
    # Získání informací o velikosti modelu
    original_size = os.path.getsize(model_path)
    quantized_size = os.path.getsize(quantized_model_path)
    print(f"Velikost původního modelu: {original_size / 1024:.2f} KB")
    print(f"Velikost kvantizovaného modelu: {quantized_size / 1024:.2f} KB")
    print(f"Redukce velikosti: {(1 - quantized_size / original_size) * 100:.2f}%")
```

```python
# Trénování s mixed precision pomocí TensorFlow
def setup_mixed_precision():
    """
    Nastavení tréninku s mixed precision v TensorFlow
    """
    # Import modulu pro mixed precision
    from tensorflow.keras import mixed_precision
    
    # Nastavení politiky na mixed precision
    policy = mixed_precision.Policy('mixed_float16')
    mixed_precision.set_global_policy(policy)
    
    print(f"Výpočetní datový typ: {policy.compute_dtype}")
    print(f"Datový typ proměnných: {policy.variable_dtype}")
    
    # Poznámka: Při použití mixed precision byste měli škálovat ztrátu, abyste předešli podtečení
    # Příklad s optimalizátorem se škálováním ztráty:
    optimizer = tf.keras.optimizers.Adam(1e-4)
    optimizer = mixed_precision.LossScaleOptimizer(optimizer)
    
    # Použijte tento optimalizátor v model.compile()

# Pro PyTorch
def setup_mixed_precision_pytorch(model):
    """
    Nastavení tréninku s mixed precision v PyTorch pomocí Automatic Mixed Precision (AMP)
    """
    # Použití PyTorch AMP
    from torch.cuda.amp import GradScaler, autocast
    
    # Vytvoření škálovače gradientu
    scaler = GradScaler()
    
    # Trénovací smyčka s mixed precision (konceptuální příklad)
    def train_step(model, inputs, targets, optimizer):
        # Přesun dat na zařízení
        inputs = inputs.to('cuda')
        targets = targets.to('cuda')
        
        # Dopředný průchod s autocast
        with autocast():
            outputs = model(inputs)
            loss = nn.functional.cross_entropy(outputs, targets)
        
        # Zpětný průchod a optimalizace se škálovanými gradienty
        optimizer.zero_grad()
        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()
        
        return loss.item()
    
    return train_step
```

```python
# Příklad implementace lineární pozornosti
def linear_attention(q, k, v):
    """
    Efektivní mechanismus lineární pozornosti, který škáluje lineárně s délkou sekvence
    
    Argumenty:
        q, k, v: Query, Key, Value tenzory
    
    Vrací:
        Výstup pozornosti
    """
    # Aplikace mapování příznaků na queries a keys
    # Toto je zjednodušení technik lineární pozornosti
    q = tf.nn.elu(q) + 1
    k = tf.nn.elu(k) + 1
    
    # Výpočet vah pozornosti pomocí kernel triku
    # Namísto (q * k^T) * v, vypočítáme q * (k^T * v)
    kv = tf.matmul(k, v, transpose_a=True)
    qkv = tf.matmul(q, kv)
    
    # Normalizační faktor
    z = tf.matmul(q, tf.reduce_sum(k, axis=-2, keepdims=True), transpose_a=True)
    
    # Aplikace normalizace
    output = qkv / (z + 1e-8)
    
    return output
```

## Shrnutí

Architektury hlubokého učení způsobily revoluci ve strojovém učení napříč různými obory. Každý typ architektury má odlišné charakteristiky:

1. **CNN** vynikají v extrakci prostorových vzorů z mřížkových dat, což je ideální pro obrázky a video.

2. **RNN** (včetně variant LSTM a GRU) zpracovávají sekvenční data udržováním skrytého stavu, což je vhodné pro časové řady a text, kde záleží na pořadí.

3. **Transformery** používají mechanismy self-attention k modelování dlouhodobých závislostí v sekvenčních datech, což umožňuje paralelní zpracování a dosahují state-of-the-art výsledků v NLP a stále častěji i v počítačovém vidění.

4. **Hybridní architektury** kombinují prvky z různých architektur pro řešení komplexních typů dat a úloh.

Klíčové aspekty při práci s těmito architekturami zahrnují:

- Přizpůsobení architektury vašemu typu dat a problému
- Pochopení výpočetních požadavků a paměťových omezení
- Implementace vhodných technik regularizace
- Využití předtrénovaných modelů prostřednictvím transfer learningu
- Interpretace a vizualizace chování modelu

Oblast se i nadále rychle vyvíjí se zaměřením výzkumu na efektivitu, škálovatelnost a multimodální schopnosti. Pro praktické aplikace zvažte zahájení se zavedenými architekturami a jejich přizpůsobení vašim specifickým potřebám.
