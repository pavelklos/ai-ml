## Úvod do Support Vector Machines

Support Vector Machines (SVM) jsou výkonné modely strojového učení s učitelem, které se používají pro klasifikační a regresní úlohy. Fungují na principu hledání optimální nadroviny, která maximálně odděluje různé třídy v prostoru příznaků.

Hlavní myšlenkou SVM je najít rozhodovací hranici, která maximalizuje okraj mezi třídami, což činí SVM odolné vůči odlehlým hodnotám a efektivní ve vysokodimenzionálních prostorech.

```python
# Základní knihovny potřebné pro implementaci SVM
import numpy as np
import matplotlib.pyplot as plt
from sklearn import svm, datasets
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report
```

## Matematické základy

SVM hledají nadrovinu, která maximalizuje okraj mezi třídami. Pro lineárně separovatelná data chceme najít:

- Nadrovinu definovanou jako w·x + b = 0
- Kde w je normálový vektor k nadrovině
- A b je bias

Okraj je definován jako vzdálenost mezi nadrovinou a nejbližším datovým bodem z obou tříd, kterou se snažíme maximalizovat.

```python
# Vizualizace rozhodovací hranice SVM a okrajů
def plot_svm_boundary(X, y, clf):
    # Vytvoření mřížky pro vykreslení
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    h = 0.02  # velikost kroku v mřížce
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                         np.arange(y_min, y_max, h))
    
    # Vykreslení rozhodovací hranice
    Z = clf.predict(np.c_[xx.ravel(), yy.ravel()])
    Z = Z.reshape(xx.shape)
    plt.contourf(xx, yy, Z, alpha=0.8)
    
    # Vykreslení trénovacích bodů
    plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k')
    
    # Vykreslení podpůrných vektorů
    plt.scatter(clf.support_vectors_[:, 0], clf.support_vectors_[:, 1],
                s=100, linewidth=1, facecolors='none', edgecolors='k')
    
    plt.xlim(xx.min(), xx.max())
    plt.ylim(yy.min(), yy.max())
    plt.xlabel('Příznak 1')
    plt.ylabel('Příznak 2')
    plt.title('Rozhodovací hranice SVM s podpůrnými vektory')
    plt.show()
```

## Implementace lineárního SVM

Implementujme lineární SVM klasifikátor pomocí knihovny scikit-learn:

```python
# Vygenerování ukázkových dat
from sklearn.datasets import make_classification

# Vytvoření binárního klasifikačního datasetu
X, y = make_classification(n_samples=100, n_features=2, n_redundant=0,
                           n_informative=2, random_state=42, n_clusters_per_class=1)

# Rozdělení dat na trénovací a testovací množiny
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření a trénování lineárního SVM klasifikátoru
linear_svm = svm.SVC(kernel='linear', C=1.0)
linear_svm.fit(X_train, y_train)

# Predikce
y_pred = linear_svm.predict(X_test)

# Vyhodnocení modelu
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost: {accuracy:.4f}")
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred))

# Vizualizace rozhodovací hranice
plot_svm_boundary(X_train, y_train, linear_svm)
```

## Kernel trik pro nelineární data

Když data nejsou lineárně separovatelná, používáme kernel trik k implicitnímu mapování dat do vyšších dimenzí, kde se stávají separovatelnými.

Běžné kernely zahrnují:
- Lineární: K(x, y) = x · y
- Polynomiální: K(x, y) = (γx · y + r)^d
- RBF (Gaussovský): K(x, y) = exp(-γ||x - y||²)
- Sigmoid: K(x, y) = tanh(γx · y + r)

```python
# Vytvoření nelineárních dat
from sklearn.datasets import make_circles

X, y = make_circles(n_samples=100, noise=0.1, factor=0.2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření a trénování SVM s různými kernely
kernels = ['linear', 'poly', 'rbf', 'sigmoid']
plt.figure(figsize=(16, 4))

for i, kernel in enumerate(kernels):
    clf = svm.SVC(kernel=kernel, gamma='scale')
    clf.fit(X_train, y_train)
    accuracy = clf.score(X_test, y_test)
    
    plt.subplot(1, 4, i+1)
    x_min, x_max = X[:, 0].min() - 0.5, X[:, 0].max() + 0.5
    y_min, y_max = X[:, 1].min() - 0.5, X[:, 1].max() + 0.5
    h = 0.02
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h), np.arange(y_min, y_max, h))
    Z = clf.predict(np.c_[xx.ravel(), yy.ravel()])
    Z = Z.reshape(xx.shape)
    
    plt.contourf(xx, yy, Z, alpha=0.8)
    plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k')
    plt.title(f"{kernel.capitalize()} Kernel\nPřesnost: {accuracy:.4f}")
    plt.xlabel('Příznak 1')
    plt.ylabel('Příznak 2')

plt.tight_layout()
plt.show()
```

## Ladění hyperparametrů SVM

Výkon SVM významně závisí na ladění hyperparametrů, zejména:
- C: Regularizační parametr (menší hodnoty = silnější regularizace)
- gamma: Koeficient kernelu pro 'rbf', 'poly' a 'sigmoid' kernely
- degree: Stupeň polynomiální jádrové funkce

```python
from sklearn.model_selection import GridSearchCV

# Definice mřížky parametrů
param_grid = {
    'C': [0.1, 1, 10, 100],
    'gamma': [1, 0.1, 0.01, 0.001],
    'kernel': ['rbf']
}

# Vytvoření grid search s křížovou validací
grid_search = GridSearchCV(
    svm.SVC(),
    param_grid,
    cv=5,
    scoring='accuracy',
    verbose=0,
    n_jobs=-1
)

# Trénování grid search na datech
grid_search.fit(X_train, y_train)

# Výpis nejlepších parametrů a skóre
print("Nejlepší parametry:", grid_search.best_params_)
print("Nejlepší skóre křížové validace: {:.4f}".format(grid_search.best_score_))

# Vyhodnocení nejlepšího modelu na testovací sadě
best_svm = grid_search.best_estimator_
best_accuracy = best_svm.score(X_test, y_test)
print(f"Testovací přesnost nejlepšího modelu: {best_accuracy:.4f}")
```

## Multiclass klasifikace pomocí SVM

SVM jsou přirozeně binární klasifikátory, ale lze je rozšířit na víceúrovňové problémy pomocí:
1. One-vs-Rest (OvR): Trénujeme N klasifikátorů, každý rozlišuje jednu třídu od všech ostatních
2. One-vs-One (OvO): Trénujeme N(N-1)/2 klasifikátorů, jeden pro každou dvojici tříd

```python
# Načtení datasetu Iris
iris = datasets.load_iris()
X = iris.data[:, :2]  # Použijeme pouze první dva příznaky pro vizualizaci
y = iris.target

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření a trénování SVM s podporou multiclass klasifikace
multi_svm = svm.SVC(decision_function_shape='ovr', kernel='rbf', gamma='scale')
multi_svm.fit(X_train, y_train)

# Predikce a vyhodnocení
y_pred = multi_svm.predict(X_test)
accuracy = accuracy_score(y_test, y_pred)
print(f"Multiclass přesnost: {accuracy:.4f}")
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred, target_names=iris.target_names))

# Vizualizace rozhodovacích hranic
plt.figure(figsize=(10, 8))
# Vytvoření mřížky
x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
h = 0.02
xx, yy = np.meshgrid(np.arange(x_min, x_max, h), np.arange(y_min, y_max, h))

# Vykreslení rozhodovací hranice
Z = multi_svm.predict(np.c_[xx.ravel(), yy.ravel()])
Z = Z.reshape(xx.shape)
plt.contourf(xx, yy, Z, alpha=0.8)

# Vykreslení trénovacích bodů
scatter = plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k')
plt.xlabel('Délka kališního lístku')
plt.ylabel('Šířka kališního lístku')
plt.title('Multiclass SVM na datasetu Iris')
plt.legend(handles=scatter.legend_elements()[0], labels=iris.target_names)
plt.show()
```

## Support Vector Regression

SVM lze adaptovat pro regresní úlohy pomocí Support Vector Regression (SVR):

```python
from sklearn.svm import SVR
from sklearn.metrics import mean_squared_error, r2_score

# Vygenerování regresních dat
np.random.seed(42)
X = np.sort(5 * np.random.rand(100, 1), axis=0)
y = np.sin(X).ravel() + 0.1 * np.random.randn(100)

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření a trénování SVR s různými kernely
svr_models = {
    'Lineární': SVR(kernel='linear', C=100, gamma='auto'),
    'RBF': SVR(kernel='rbf', C=100, gamma=0.1),
    'Polynomiální': SVR(kernel='poly', C=100, gamma='auto', degree=3)
}

plt.figure(figsize=(15, 10))
for i, (name, model) in enumerate(svr_models.items()):
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)
    
    # Výpočet metrik
    mse = mean_squared_error(y_test, y_pred)
    r2 = r2_score(y_test, y_pred)
    
    # Vykreslení výsledků
    plt.subplot(2, 2, i+1)
    plt.scatter(X_test, y_test, color='darkorange', label='data')
    
    # Seřazení pro vykreslení
    X_plot = np.linspace(0, 5, 100).reshape(-1, 1)
    y_plot = model.predict(X_plot)
    
    plt.plot(X_plot, y_plot, color='navy', label=f'{name} model')
    plt.xlabel('X')
    plt.ylabel('y')
    plt.title(f'{name} SVR (MSE: {mse:.4f}, R²: {r2:.4f})')
    plt.legend()

plt.tight_layout()
plt.show()
```

## Praktické aplikace

SVM mají rozmanité aplikace v různých oblastech:

```python
# Příklad: Klasifikace textu pomocí SVM
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn import datasets

# Načtení ukázkových textových dat
categories = ['alt.atheism', 'talk.religion.misc', 'comp.graphics', 'sci.space']
newsgroups = datasets.fetch_20newsgroups(subset='train', categories=categories)

# Konverze textu na TF-IDF příznaky
vectorizer = TfidfVectorizer(stop_words='english', max_features=1000)
X = vectorizer.fit_transform(newsgroups.data)
y = newsgroups.target

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Trénování SVM pro klasifikaci textu
text_clf = svm.SVC(kernel='linear', C=1.0)
text_clf.fit(X_train, y_train)

# Vyhodnocení
y_pred = text_clf.predict(X_test)
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost klasifikace textu: {accuracy:.4f}")
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred, target_names=categories))
```

## Silné stránky a omezení

### Silné stránky
- Efektivní ve vysokodimenzionálních prostorech
- Paměťově efektivní (používá podmnožinu trénovacích bodů)
- Všestranný díky různým jádrovým funkcím
- Odolný vůči přetrénování ve vysokodimenzionálních prostorech

### Omezení
- Neposkytuje přímo odhady pravděpodobnosti
- Výpočetně náročný pro velké datasety
- Citlivý na ladění hyperparametrů
- Výkon se zhoršuje při překrývajících se třídách

```python
# Demonstrace omezení SVM s překrývajícími se třídami
from sklearn.datasets import make_blobs

# Vygenerování překrývajících se shluků
X, y = make_blobs(n_samples=300, centers=2, random_state=42, cluster_std=3.0)

# Trénování SVM s různými hodnotami C
plt.figure(figsize=(15, 5))
C_values = [0.1, 1.0, 10.0]

for i, C in enumerate(C_values):
    model = svm.SVC(kernel='linear', C=C)
    model.fit(X, y)
    
    # Rozhodovací hranice
    plt.subplot(1, 3, i+1)
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    h = 0.02
    xx, yy = np.meshgrid(np.arange(x_min, x_max, h), np.arange(y_min, y_max, h))
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
    Z = Z.reshape(xx.shape)
    
    plt.contourf(xx, yy, Z, alpha=0.8)
    plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k')
    plt.title(f"C = {C}")
    plt.xlabel('Příznak 1')
    plt.ylabel('Příznak 2')
    
plt.tight_layout()
plt.show()
```

## Shrnutí

Support Vector Machines jsou všestranné a výkonné algoritmy strojového učení s těmito klíčovými charakteristikami:

1. **Základní koncept**: Najít optimální nadrovinu, která maximalizuje okraj mezi třídami
2. **Kernel trik**: Umožňuje zpracování nelineárních dat pomocí implicitního mapování do vyšších dimenzí
3. **Klíčové hyperparametry**: C (regularizace), gamma (koeficient kernelu), typ kernelu
4. **Typy**: Podporuje jak klasifikační (SVC), tak regresní (SVR) úlohy
5. **Podpora multiclass klasifikace**: Implementována pomocí strategií one-vs-rest nebo one-vs-one
6. **Nejlepší případy použití**: Vysokodimenzionální data, malé až střední datasety a případy, kdy je kritická rozhodovací hranice
7. **Omezení**: Výpočetně náročné pro velké datasety a vyžaduje pečlivé ladění hyperparametrů

SVM jsou stále relevantní v moderním strojovém učení navzdory vzestupu hlubokého učení a nabízejí vynikající výkon pro určité typy strukturovaných datových problémů, zejména při omezeném množství trénovacích vzorků.
