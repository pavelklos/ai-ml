## Úvod do metrik hodnocení modelů

Hodnocení výkonu modelu strojového učení je klíčové pro pochopení jeho efektivity a porovnání s alternativními modely. Přestože přesnost (accuracy) je často první metrikou, která přichází na mysl, může být zavádějící, zejména při práci s nevyváženými datasety. Přesnost (precision), úplnost (recall) a F1-skóre poskytují komplexnější hodnocení klasifikačních modelů.

```python
# Požadované knihovny pro hodnocení modelu
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score
from sklearn.metrics import confusion_matrix, classification_report, precision_recall_curve
from sklearn.metrics import roc_curve, roc_auc_score
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.datasets import load_breast_cancer, make_classification

# Nastavení náhodného seedu pro reprodukovatelnost
np.random.seed(42)
```

## Přehled klasifikačních metrik

Při hodnocení klasifikačních modelů potřebujeme metriky, které jdou nad rámec jednoduché přesnosti (accuracy). Tyto metriky nám pomáhají pochopit různé aspekty výkonu modelu, jako například:

- Jak dobře model identifikuje pozitivní případy
- Jak často model vyvolává falešné poplachy
- Jak dobře model vyvažuje různé typy chyb

Volba metriky závisí na konkrétní doméně problému a relativních nákladech různých typů chyb.

```python
# Vytvoříme binární klasifikační dataset pro demonstraci
X, y = make_classification(
    n_samples=1000, 
    n_features=20, 
    n_informative=10, 
    n_redundant=5, 
    n_classes=2, 
    weights=[0.7, 0.3],  # Vytvoření nevyváženosti tříd: 70 % třída 0, 30 % třída 1
    random_state=42
)

# Rozdělení dat na trénovací a testovací sady
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)

# Trénování jednoduchého modelu
model = LogisticRegression(random_state=42)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# Výpočet základních metrik
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost modelu (accuracy): {accuracy:.4f}")

# Rozložení tříd v testovací sadě
print("\nRozložení tříd v testovací sadě:")
unique, counts = np.unique(y_test, return_counts=True)
for value, count in zip(unique, counts):
    print(f"Třída {value}: {count} vzorků ({count/len(y_test):.2%})")
```

## Matice záměn: Základ

Matice záměn (confusion matrix) je základem mnoha klasifikačních metrik. Tabulkově zobrazuje počty skutečně pozitivních (TP), falešně pozitivních (FP), skutečně negativních (TN) a falešně negativních (FN) případů.

- **Skutečně pozitivní (TP)**: Správně predikováno jako pozitivní
- **Falešně pozitivní (FP)**: Nesprávně predikováno jako pozitivní (chyba typu I)
- **Skutečně negativní (TN)**: Správně predikováno jako negativní
- **Falešně negativní (FN)**: Nesprávně predikováno jako negativní (chyba typu II)

```python
# Výpočet a vizualizace matice záměn
conf_matrix = confusion_matrix(y_test, y_pred)

plt.figure(figsize=(8, 6))
sns.heatmap(conf_matrix, annot=True, fmt='d', cmap='Blues',
            xticklabels=['Predikováno 0', 'Predikováno 1'],
            yticklabels=['Skutečně 0', 'Skutečně 1'])
plt.ylabel('Skutečná třída')
plt.xlabel('Predikovaná třída')
plt.title('Matice záměn')
plt.tight_layout()
plt.show()

# Extrakce hodnot z matice záměn
tn, fp, fn, tp = conf_matrix.ravel()
print(f"Skutečně negativní (TN): {tn}")
print(f"Falešně pozitivní (FP): {fp}")
print(f"Falešně negativní (FN): {fn}")
print(f"Skutečně pozitivní (TP): {tp}")
```

## Přesnost (Precision): Když záleží na falešných pozitivech

Přesnost (precision) měří přesnost pozitivních predikcí. Odpovídá na otázku: "Ze všech instancí predikovaných jako pozitivní, kolik jich je skutečně pozitivních?"

Přesnost je zvláště důležitá, když jsou náklady falešných pozitiv vysoké. Například při detekci spamu falešné pozitivum znamená, že legitimní e-mail je označen jako spam, což může být problematické.

Vzorec: 
\[ \text{Přesnost (Precision)} = \frac{TP}{TP + FP} = \frac{\text{Skutečně pozitivní}}{\text{Celkové predikované pozitivní}} \]

```python
# Ruční výpočet přesnosti z matice záměn
precision_manual = tp / (tp + fp) if (tp + fp) > 0 else 0
print(f"Přesnost (precision, ruční výpočet): {precision_manual:.4f}")

# Použití funkce precision_score ze scikit-learn
precision = precision_score(y_test, y_pred)
print(f"Přesnost (precision, sklearn): {precision:.4f}")

# Příklad: Scénář detekce spamu
print("\nPříklad: Detekce spamu")
print("Při detekci spamu vysoká přesnost (precision) znamená, že méně legitimních")
print("e-mailů je chybně klasifikováno jako spam (méně falešných pozitiv).")
```

## Úplnost (Recall): Když záleží na falešných negativech

Úplnost (recall), také známá jako senzitivita nebo míra skutečně pozitivních, měří schopnost modelu nalézt všechny pozitivní instance. Odpovídá na otázku: "Ze všech skutečných pozitivních instancí, kolik jich model správně identifikoval?"

Úplnost je kritická, když jsou náklady falešných negativ vysoké. Například v lékařské diagnostice by falešné negativum mohlo znamenat přehlédnutí nemoci, což může být život ohrožující.

Vzorec:
\[ \text{Úplnost (Recall)} = \frac{TP}{TP + FN} = \frac{\text{Skutečně pozitivní}}{\text{Celkové skutečně pozitivní}} \]

```python
# Ruční výpočet úplnosti z matice záměn
recall_manual = tp / (tp + fn) if (tp + fn) > 0 else 0
print(f"Úplnost (recall, ruční výpočet): {recall_manual:.4f}")

# Použití funkce recall_score ze scikit-learn
recall = recall_score(y_test, y_pred)
print(f"Úplnost (recall, sklearn): {recall:.4f}")

# Příklad: Scénář lékařské diagnostiky
print("\nPříklad: Detekce nemoci")
print("Při detekci nemoci vysoká úplnost (recall) znamená, že méně pacientů s nemocí")
print("je chybně klasifikováno jako zdraví (méně falešných negativ).")
```

## F1-skóre: Vyvážení přesnosti a úplnosti

F1-skóre je harmonický průměr přesnosti (precision) a úplnosti (recall). Poskytuje jednu metriku, která vyvažuje oba zájmy. Harmonický průměr dává větší váhu nižším hodnotám, takže F1-skóre bude blíže k nižší z hodnot přesnosti nebo úplnosti.

F1-skóre je užitečné, když chcete vyvážit přesnost a úplnost a nemáte silnou preferenci pro jednu či druhou.

Vzorec:
\[ \text{F1-skóre} = 2 \times \frac{\text{Přesnost} \times \text{Úplnost}}{\text{Přesnost} + \text{Úplnost}} = \frac{2TP}{2TP + FP + FN} \]

```python
# Ruční výpočet F1-skóre
f1_manual = 2 * precision_manual * recall_manual / (precision_manual + recall_manual) if (precision_manual + recall_manual) > 0 else 0
print(f"F1-skóre (ruční výpočet): {f1_manual:.4f}")

# Použití funkce f1_score ze scikit-learn
f1 = f1_score(y_test, y_pred)
print(f"F1-skóre (sklearn): {f1:.4f}")

# Porovnání všech metrik
print("\nPorovnání metrik:")
print(f"Přesnost (precision): {precision:.4f}")
print(f"Úplnost (recall): {recall:.4f}")
print(f"F1-skóre: {f1:.4f}")
```

## Kompromis mezi přesností a úplností

U mnoha klasifikačních problémů existuje kompromis mezi přesností (precision) a úplností (recall). Úpravou klasifikačního prahu (pravděpodobnostní hranice pro predikci pozitivní třídy) můžete upřednostnit jednu metriku před druhou.

- Vyšší práh → Vyšší přesnost, nižší úplnost
- Nižší práh → Nižší přesnost, vyšší úplnost

Vizualizace tohoto kompromisu pomocí křivek precision-recall pomáhá při výběru vhodného prahu pro vaši konkrétní aplikaci.

```python
# Získání predikovaných pravděpodobností namísto tříd
y_scores = model.predict_proba(X_test)[:, 1]  # Pravděpodobnost pozitivní třídy

# Výpočet křivky precision-recall
precision_values, recall_values, thresholds = precision_recall_curve(y_test, y_scores)

# Vykreslení křivky precision-recall
plt.figure(figsize=(10, 6))
plt.plot(recall_values, precision_values, marker='.', label='Křivka Precision-Recall')
plt.xlabel('Úplnost (Recall)')
plt.ylabel('Přesnost (Precision)')
plt.title('Křivka Precision-Recall')
plt.grid(True)
plt.legend()
plt.show()

# Ukázka vlivu prahu na přesnost a úplnost
print("\nVliv prahu na přesnost a úplnost:")
for threshold in [0.3, 0.5, 0.7, 0.9]:
    y_pred_threshold = (y_scores >= threshold).astype(int)
    precision = precision_score(y_test, y_pred_threshold)
    recall = recall_score(y_test, y_pred_threshold)
    f1 = f1_score(y_test, y_pred_threshold)
    print(f"Práh: {threshold:.1f}, Přesnost: {precision:.4f}, Úplnost: {recall:.4f}, F1: {f1:.4f}")
```

## Další související metriky

Kromě přesnosti (precision), úplnosti (recall) a F1-skóre existuje několik dalších metrik, které poskytují užitečné perspektivy na výkon modelu:

1. **Specificita (True Negative Rate)**: Měří podíl skutečných negativních případů, které jsou správně identifikovány.
2. **ROC křivka a AUC**: Zobrazuje míru skutečně pozitivních proti míře falešně pozitivních při různých prazích.
3. **Průměrná přesnost**: Oblast pod křivkou precision-recall.
4. **Matthewsův korelační koeficient**: Vyvážená metrika i při nevyvážených třídách.

```python
# Výpočet specificity (míra skutečně negativních)
specificity = tn / (tn + fp) if (tn + fp) > 0 else 0
print(f"Specificita: {specificity:.4f}")

# Výpočet a vykreslení ROC křivky
fpr, tpr, thresholds = roc_curve(y_test, y_scores)
roc_auc = roc_auc_score(y_test, y_scores)

plt.figure(figsize=(10, 6))
plt.plot(fpr, tpr, marker='.', label=f'ROC křivka (AUC = {roc_auc:.4f})')
plt.plot([0, 1], [0, 1], 'k--', label='Náhodný klasifikátor')
plt.xlabel('Míra falešně pozitivních (False Positive Rate)')
plt.ylabel('Míra skutečně pozitivních (True Positive Rate)')
plt.title('ROC křivka (Receiver Operating Characteristic)')
plt.grid(True)
plt.legend()
plt.show()

# Výpočet Matthewsova korelačního koeficientu
from sklearn.metrics import matthews_corrcoef
mcc = matthews_corrcoef(y_test, y_pred)
print(f"Matthewsův korelační koeficient: {mcc:.4f}")
```

## Implementace metrik v praxi

V reálných scénářích často používáte kombinaci metrik k hodnocení vašich modelů. Funkce `classification_report` v knihovně scikit-learn poskytuje praktický přehled hlavních klasifikačních metrik.

```python
# Zobrazení klasifikační zprávy
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred))

# Práce s různými typy datasetů - příklad s nevyváženým datasetem
# Načtení datasetu rakoviny prsu
cancer = load_breast_cancer()
X_cancer = cancer.data
y_cancer = cancer.target

X_train_c, X_test_c, y_train_c, y_test_c = train_test_split(
    X_cancer, y_cancer, test_size=0.25, random_state=42
)

# Vytvoření a trénování složitějšího modelu
pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('classifier', RandomForestClassifier(n_estimators=100, random_state=42))
])
pipeline.fit(X_train_c, y_train_c)
y_pred_c = pipeline.predict(X_test_c)

# Vyhodnocení pomocí všech metrik
print("\nVyhodnocení datasetu rakoviny prsu:")
print(classification_report(y_test_c, y_pred_c))

# Makro vs. vážené průměry
print("\nRůzné metody průměrování:")
print(f"Makro-průměrovaná přesnost: {precision_score(y_test_c, y_pred_c, average='macro'):.4f}")
print(f"Váženě-průměrovaná přesnost: {precision_score(y_test_c, y_pred_c, average='weighted'):.4f}")
```

## Shrnutí a osvědčené postupy

Při hodnocení klasifikačních modelů je výběr vhodných metrik klíčový pro informované rozhodování:

1. **Používejte přesnost (accuracy)**, když jsou třídy vyvážené a všechny typy chyb mají podobné náklady.
2. **Zaměřte se na přesnost (precision)**, když jsou falešná pozitiva nákladnější (např. detekce spamu, alokace zdrojů).
3. **Upřednostněte úplnost (recall)**, když jsou falešná negativa nákladnější (např. lékařská diagnostika, detekce podvodů).
4. **Používejte F1-skóre**, když potřebujete vyvážit přesnost a úplnost.
5. **Zvažte ROC křivku a AUC** pro hodnocení výkonu nezávislé na prahu.
6. **Vždy zkoumejte matici záměn**, abyste pochopili konkrétní typy chyb, které váš model dělá.
7. **Pro nevyvážené datasety** může být přesnost (accuracy) zavádějící; preferujte přesnost (precision), úplnost (recall), F1-skóre nebo MCC.
8. **Používejte křížovou validaci** k zajištění stabilních a spolehlivých odhadů metrik.
9. **Porovnejte metriky napříč různými modely** pro výběr nejlepšího pro váš konkrétní případ použití.
10. **Zvažte obchodní kontext** při nastavování klasifikačních prahů a výběru metrik.

```python
# Příklad křížové validace s více metrikami
from sklearn.model_selection import cross_validate

models = {
    "Logistická regrese": LogisticRegression(random_state=42),
    "Random Forest": RandomForestClassifier(n_estimators=100, random_state=42)
}

metrics = ['accuracy', 'precision', 'recall', 'f1']
cv_results = {}

# Provedení křížové validace pro každý model
for name, model in models.items():
    cv_result = cross_validate(
        model, X, y, 
        cv=5,
        scoring=['accuracy', 'precision', 'recall', 'f1']
    )
    cv_results[name] = {
        'accuracy': cv_result['test_accuracy'].mean(),
        'precision': cv_result['test_precision'].mean(),
        'recall': cv_result['test_recall'].mean(),
        'f1': cv_result['test_f1'].mean()
    }

# Zobrazení výsledků v DataFrame
cv_df = pd.DataFrame(cv_results).T
print("\nVýsledky křížové validace:")
print(cv_df)

# Vykreslení výsledků
plt.figure(figsize=(12, 6))
cv_df.plot(kind='bar', rot=0)
plt.title('Porovnání výkonu modelů')
plt.ylabel('Skóre')
plt.grid(axis='y')
plt.tight_layout()
plt.show()

print("\nNejlepší model podle různých metrik:")
for metric in metrics:
    best_model = cv_df[metric].idxmax()
    print(f"Nejlepší model podle {metric}: {best_model} ({cv_df.loc[best_model, metric]:.4f})")
```

Porozuměním a správným použitím těchto metrik pro hodnocení modelů můžete činit informovanější rozhodnutí o vašich modelech strojového učení a lépe řešit specifické požadavky vašich aplikací.
