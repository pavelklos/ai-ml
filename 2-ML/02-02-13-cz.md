## Co je hluboké učení?

Hluboké učení je podmnožinou strojového učení, která využívá neuronové sítě s mnoha vrstvami (proto "hluboké"), aby postupně extrahovaly stále složitější příznaky ze vstupních dat. Na rozdíl od tradičních algoritmů strojového učení, které vyžadují ruční vytváření příznaků, hluboké učení dokáže automaticky objevit reprezentace potřebné pro detekci nebo klasifikaci přímo ze surových dat.

Klíčové koncepty:
- Neuronové sítě s mnoha skrytými vrstvami
- Schopnost automaticky se učit hierarchické příznaky
- Učení end-to-end od surových dat až po finální výstup
- Specializované architektury pro různé typy dat (obrázky, text atd.)

```python
# Import základních knihoven pro hluboké učení
import numpy as np
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras

np.random.seed(42)
```

## Přehled TensorFlow a Keras

TensorFlow je open-source framework pro strojové učení vyvinutý týmem Google Brain, který poskytuje komplexní ekosystém nástrojů pro hluboké učení. Keras je vysokoúrovňové API pro neuronové sítě, které běží na TensorFlow a je navrženo s důrazem na rychlé experimentování.

Klíčové výhody:
- **TensorFlow**: Efektivní numerické výpočty, distribuované výpočty a možnosti nasazení
- **Keras**: Uživatelsky přívětivé, modulární architektura a snadné vytváření modelů

```python
# Keras je integrován do TensorFlow jako tf.keras
# V Keras existují dvě hlavní API:

# 1. Sequential API (jednodušší, lineární stack vrstev)
model_sequential = keras.Sequential([
    keras.layers.Dense(64, activation='relu', input_shape=(784,)),
    keras.layers.Dense(64, activation='relu'),
    keras.layers.Dense(10, activation='softmax')
])

# 2. Functional API (flexibilnější, umožňuje složité topologie modelů)
inputs = keras.Input(shape=(784,))
x = keras.layers.Dense(64, activation='relu')(inputs)
x = keras.layers.Dense(64, activation='relu')(x)
outputs = keras.layers.Dense(10, activation='softmax')(x)
model_functional = keras.Model(inputs=inputs, outputs=outputs)

# Obě API vytvářejí v tomto jednoduchém případě ekvivalentní modely
print("Souhrn sekvenčního modelu:")
model_sequential.summary()

print("\nSouhrn funkcionálního modelu:")
model_functional.summary()
```

## Základy neuronových sítí

Neuronové sítě jsou složeny z vrstev neuronů, které zpracovávají vstupní data pro vytváření predikcí. Pojďme prozkoumat základní stavební bloky:

```python
# Základní komponenty neuronových sítí

# 1. Neurony a aktivační funkce
x = np.linspace(-10, 10, 100)
activations = {
    'Sigmoid': tf.keras.activations.sigmoid(x),
    'Tanh': tf.keras.activations.tanh(x),
    'ReLU': tf.keras.activations.relu(x),
    'Leaky ReLU': tf.keras.activations.relu(x, alpha=0.1),
    'Softmax': tf.keras.activations.softmax(np.array([x, -x])).T
}

plt.figure(figsize=(12, 8))
for i, (name, values) in enumerate(activations.items(), 1):
    if name == 'Softmax':
        plt.subplot(2, 3, i)
        plt.plot(x, values[:, 0], label='Třída 1')
        plt.plot(x, values[:, 1], label='Třída 2')
        plt.title(f'Aktivace {name}')
        plt.legend()
    else:
        plt.subplot(2, 3, i)
        plt.plot(x, values)
        plt.title(f'Aktivace {name}')
plt.tight_layout()
plt.show()

# 2. Vrstvy
# Dense (plně propojená) vrstva
dense = keras.layers.Dense(32, activation='relu', input_shape=(10,))
print(f"Tvar výstupu dense vrstvy: {dense.compute_output_shape((None, 10))}")

# Konvoluční vrstva
conv = keras.layers.Conv2D(32, kernel_size=(3, 3), activation='relu', input_shape=(28, 28, 1))
print(f"Tvar výstupu Conv2D vrstvy: {conv.compute_output_shape((None, 28, 28, 1))}")

# Pooling vrstva
maxpool = keras.layers.MaxPooling2D(pool_size=(2, 2))
print(f"Tvar výstupu MaxPooling2D vrstvy: {maxpool.compute_output_shape((None, 28, 28, 32))}")

# Dropout vrstva
dropout = keras.layers.Dropout(0.5)
print(f"Dropout zachovává tvar: {dropout.compute_output_shape((None, 10)) == (None, 10)}")

# 3. Ztrátové funkce
losses = {
    'Binární křížová entropie': keras.losses.BinaryCrossentropy(),
    'Kategorická křížová entropie': keras.losses.CategoricalCrossentropy(),
    'Střední kvadratická chyba': keras.losses.MeanSquaredError()
}

# Příklad výpočtu ztrát
y_true = tf.constant([[0, 1], [0, 0], [1, 1]])
y_pred = tf.constant([[0.2, 0.8], [0.1, 0.2], [0.9, 0.7]])

for name, loss_fn in losses.items():
    loss_value = loss_fn(y_true, y_pred)
    print(f"Ztráta {name}: {loss_value.numpy():.4f}")
```

## Vytvoření vaší první neuronové sítě

Pojďme vytvořit jednoduchou neuronovou síť pro klasifikaci datasetu MNIST ručně psaných číslic:

```python
# Načtení datasetu MNIST
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()

# Předzpracování dat
x_train = x_train.astype('float32') / 255.0  # Normalizace hodnot pixelů na [0, 1]
x_test = x_test.astype('float32') / 255.0

# Přetvarování dat pro model
x_train = x_train.reshape(-1, 28*28)  # Zploštění obrázků 28x28
x_test = x_test.reshape(-1, 28*28)

# One-hot kódování štítků
y_train = keras.utils.to_categorical(y_train, 10)
y_test = keras.utils.to_categorical(y_test, 10)

# Vytvoření jednoduché dopředné neuronové sítě
model = keras.Sequential([
    keras.layers.Dense(128, activation='relu', input_shape=(28*28,)),
    keras.layers.Dropout(0.2),  # Přidání dropoutu pro regularizaci
    keras.layers.Dense(64, activation='relu'),
    keras.layers.Dropout(0.2),
    keras.layers.Dense(10, activation='softmax')  # 10 výstupních tříd (číslice 0-9)
])

# Kompilace modelu
model.compile(
    optimizer='adam',  # Optimalizátor Adam
    loss='categorical_crossentropy',  # Ztrátová funkce pro multi-klasifikaci
    metrics=['accuracy']  # Sledování přesnosti během tréninku
)

# Zobrazení architektury modelu
model.summary()

# Vizualizace modelu (volitelné)
if 'google.colab' in str(get_ipython()):
    from tensorflow.keras.utils import plot_model
    plot_model(model, show_shapes=True, show_layer_names=True)
```

## Trénování a vyhodnocení

Jakmile je náš model definován, musíme ho natrénovat na našich datech a vyhodnotit jeho výkon:

```python
# Trénování modelu
history = model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=5,  # Obvykle byste použili více epoch, sníženo pro demonstraci
    validation_split=0.1  # Použití 10% trénovacích dat pro validaci
)

# Vyhodnocení na testovací množině
test_loss, test_acc = model.evaluate(x_test, y_test)
print(f"Testovací přesnost: {test_acc:.4f}")

# Vykreslení historie tréninku
plt.figure(figsize=(12, 4))

# Vykreslení přesnosti tréninku a validace
plt.subplot(1, 2, 1)
plt.plot(history.history['accuracy'])
plt.plot(history.history['val_accuracy'])
plt.title('Přesnost modelu')
plt.ylabel('Přesnost')
plt.xlabel('Epocha')
plt.legend(['Trénink', 'Validace'], loc='lower right')

# Vykreslení ztráty tréninku a validace
plt.subplot(1, 2, 2)
plt.plot(history.history['loss'])
plt.plot(history.history['val_loss'])
plt.title('Ztráta modelu')
plt.ylabel('Ztráta')
plt.xlabel('Epocha')
plt.legend(['Trénink', 'Validace'], loc='upper right')

plt.tight_layout()
plt.show()

# Vytvoření predikcí
predictions = model.predict(x_test)
predicted_classes = np.argmax(predictions, axis=1)
true_classes = np.argmax(y_test, axis=1)

# Zobrazení některých predikcí
plt.figure(figsize=(12, 8))
for i in range(25):  # Zobrazení prvních 25 obrázků
    plt.subplot(5, 5, i+1)
    plt.imshow(x_test[i].reshape(28, 28), cmap='gray')
    plt.title(f"Pred: {predicted_classes[i]}, Skut: {true_classes[i]}")
    plt.axis('off')
plt.tight_layout()
plt.show()

# Matice záměn
from sklearn.metrics import confusion_matrix
import seaborn as sns

cm = confusion_matrix(true_classes, predicted_classes)
plt.figure(figsize=(10, 8))
sns.heatmap(cm, annot=True, fmt="d", cmap="Blues")
plt.title("Matice záměn")
plt.ylabel("Skutečný štítek")
plt.xlabel("Predikovaný štítek")
plt.show()
```

## Úvod do CNN

Konvoluční neuronové sítě (CNN) jsou specializované pro zpracování mřížkových dat, jako jsou obrázky:

```python
# Načtení datasetu MNIST ve formátu obrázků
(x_train, y_train), (x_test, y_test) = keras.datasets.mnist.load_data()

# Přetvarování pro vstup CNN (přidání dimenze kanálu)
x_train = x_train.reshape(-1, 28, 28, 1).astype('float32') / 255.0
x_test = x_test.reshape(-1, 28, 28, 1).astype('float32') / 255.0

# One-hot kódování štítků
y_train = keras.utils.to_categorical(y_train, 10)
y_test = keras.utils.to_categorical(y_test, 10)

# Vytvoření jednoduché CNN
cnn_model = keras.Sequential([
    # Konvoluční vrstvy
    keras.layers.Conv2D(32, kernel_size=(3, 3), activation='relu', input_shape=(28, 28, 1)),
    keras.layers.MaxPooling2D(pool_size=(2, 2)),
    
    keras.layers.Conv2D(64, kernel_size=(3, 3), activation='relu'),
    keras.layers.MaxPooling2D(pool_size=(2, 2)),
    
    # Zploštění a plně propojené vrstvy
    keras.layers.Flatten(),
    keras.layers.Dense(128, activation='relu'),
    keras.layers.Dropout(0.5),
    keras.layers.Dense(10, activation='softmax')
])

# Kompilace CNN modelu
cnn_model.compile(
    optimizer='adam',
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# Zobrazení architektury modelu
cnn_model.summary()

# Trénování CNN
cnn_history = cnn_model.fit(
    x_train, y_train,
    batch_size=128,
    epochs=5,
    validation_split=0.1
)

# Vyhodnocení na testovací množině
cnn_test_loss, cnn_test_acc = cnn_model.evaluate(x_test, y_test)
print(f"Přesnost CNN na testovacích datech: {cnn_test_acc:.4f}")

# Vizualizace příznakových map (mezilehlé aktivace)
def visualize_feature_maps(model, img_index):
    img = x_test[img_index:img_index+1]  # Získání jednoho obrázku
    
    # Vytvoření modelu, který vrací aktivace z mezilehlých vrstev
    layer_outputs = [layer.output for layer in model.layers if isinstance(layer, keras.layers.Conv2D)]
    activation_model = keras.Model(inputs=model.input, outputs=layer_outputs)
    
    # Získání všech aktivací pro obrázek
    activations = activation_model.predict(img)
    
    # Vizualizace prvních několika příznakových map z každé konvoluční vrstvy
    plt.figure(figsize=(15, 8))
    
    # Zobrazení vstupního obrázku
    plt.subplot(1, len(activations) + 1, 1)
    plt.title("Vstupní obrázek")
    plt.imshow(img[0, :, :, 0], cmap='gray')
    plt.axis('off')
    
    # Zobrazení příznakových map
    for i, layer_activations in enumerate(activations):
        n_features = min(8, layer_activations.shape[-1])  # Zobrazení až 8 příznakových map
        
        for j in range(n_features):
            plt.subplot(n_features, len(activations) + 1, (j * (len(activations) + 1)) + i + 2)
            plt.title(f"Vrstva {i+1}, Mapa {j+1}")
            plt.imshow(layer_activations[0, :, :, j], cmap='viridis')
            plt.axis('off')
    
    plt.tight_layout()
    plt.show()

# Vizualizace příznakových map pro ukázkový obrázek
if np.argmax(y_test[0]) == 5:  # Pokud je první testovací obrázek číslice 5
    visualize_feature_maps(cnn_model, 0)
else:
    # Nalezení příkladu číslice 5
    for i in range(len(y_test)):
        if np.argmax(y_test[i]) == 5:
            visualize_feature_maps(cnn_model, i)
            break
```

## Práce s předtrénovanými modely

Transfer learning nám umožňuje využít předtrénované modely k efektivnějšímu řešení nových problémů:

```python
# Import potřebných knihoven pro transfer learning
from tensorflow.keras.applications import VGG16, ResNet50
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D
from tensorflow.keras.models import Model

# Načtení předtrénovaného modelu bez vrchní klasifikační vrstvy
base_model = VGG16(weights='imagenet', include_top=False, input_shape=(224, 224, 3))

# Zmrazení vrstev základního modelu
for layer in base_model.layers:
    layer.trainable = False

# Přidání vlastních vrstev na vrchol
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(256, activation='relu')(x)
predictions = Dense(10, activation='softmax')(x)  # 10 tříd pro ukázku

# Vytvoření nového modelu
transfer_model = Model(inputs=base_model.input, outputs=predictions)

# Kompilace modelu
transfer_model.compile(
    optimizer='adam',
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# Zobrazení struktury modelu
print("Souhrn modelu pro transfer learning:")
print(f"Celkový počet vrstev: {len(transfer_model.layers)}")
print(f"Trénovatelné vrstvy: {sum(1 for layer in transfer_model.layers if layer.trainable)}")
print(f"Netrénovatelné vrstvy: {sum(1 for layer in transfer_model.layers if not layer.trainable)}")

# Příklad předzpracování dat pro předtrénované modely
def preprocess_for_vgg(image):
    """Předzpracování obrázků pro VGG16"""
    # Změna velikosti na 224x224 (pokud je potřeba)
    # Převod na RGB (pokud je potřeba)
    # Odečtení průměrných hodnot pixelů z ImageNet
    return tf.keras.applications.vgg16.preprocess_input(image)

# Příklad augmentace dat pro trénink
train_datagen = ImageDataGenerator(
    preprocessing_function=preprocess_for_vgg,
    rotation_range=20,
    width_shift_range=0.2,
    height_shift_range=0.2,
    shear_range=0.2,
    zoom_range=0.2,
    horizontal_flip=True,
    fill_mode='nearest'
)

# Poznámka: Pro dokončení procesu transfer learning byste typicky:
# 1. Připravili svůj dataset (např. pomocí flow_from_directory)
# 2. Natrénovali model s vašimi daty
# 3. Provedli doladění odmrazením některých vrstev a tréninkem s malou learning rate

# Pro demonstraci transfer learning na obrázcích různých velikostí vytvoříme také flexibilnější přístup
def create_transfer_learning_model(input_shape, num_classes, base_model_name='resnet50'):
    """Vytvoření modelu pro transfer learning s flexibilní vstupní velikostí"""
    if base_model_name.lower() == 'vgg16':
        base_model = VGG16(weights='imagenet', include_top=False, input_shape=input_shape)
        preprocess_func = tf.keras.applications.vgg16.preprocess_input
    elif base_model_name.lower() == 'resnet50':
        base_model = ResNet50(weights='imagenet', include_top=False, input_shape=input_shape)
        preprocess_func = tf.keras.applications.resnet50.preprocess_input
    else:
        raise ValueError("Nepodporovaný základní model")
    
    # Zmrazení vrstev základního modelu
    for layer in base_model.layers:
        layer.trainable = False
    
    # Přidání klasifikační hlavy
    x = base_model.output
    x = GlobalAveragePooling2D()(x)
    x = Dense(512, activation='relu')(x)
    x = keras.layers.Dropout(0.5)(x)
    predictions = Dense(num_classes, activation='softmax')(x)
    
    model = Model(inputs=base_model.input, outputs=predictions)
    
    return model, preprocess_func

# Příklad použití flexibilní funkce pro transfer learning
custom_model, preprocess_function = create_transfer_learning_model(
    input_shape=(150, 150, 3),  # Vlastní vstupní tvar
    num_classes=5,              # Počet cílových tříd
    base_model_name='resnet50'  # Architektura základního modelu
)

custom_model.compile(
    optimizer=keras.optimizers.Adam(1e-4),  # Nižší learning rate pro transfer learning
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

print("Vlastní model pro transfer learning vytvořen!")
```
