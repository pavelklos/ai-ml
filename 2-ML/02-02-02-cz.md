## Úvod do rozhodovacích stromů a náhodných lesů

Rozhodovací stromy a náhodné lesy jsou populární algoritmy strojového učení pro klasifikační i regresní úlohy. Jsou intuitivní, snadno interpretovatelné a mohou pracovat s numerickými i kategorickými daty bez nutnosti rozsáhlé přípravy dat.

- **Rozhodovací stromy**: Hierarchické modely, které rozhodují na základě série otázek
- **Náhodné lesy**: Ensemble modely, které kombinují více rozhodovacích stromů pro zlepšení přesnosti predikce a kontrolu přetrénování

```python
# Potřebné knihovny pro rozhodovací stromy a náhodné lesy
import numpy as np

from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor, plot_tree
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor
from sklearn.model_selection import train_test_split, cross_val_score, GridSearchCV
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix
from sklearn.metrics import mean_squared_error, r2_score
from sklearn.datasets import load_iris, load_boston, fetch_california_housing
import warnings
warnings.filterwarnings('ignore')

# Nastavení náhodného seedu pro reprodukovatelnost
np.random.seed(42)
```

## Základy rozhodovacích stromů

Rozhodovací stromy fungují rekurzivním rozdělováním datasetu na podmnožiny na základě hodnot vstupních příznaků. Cílem je vytvořit podskupiny, které jsou z hlediska cílové proměnné co možná nejhomogennější.

### Klíčové koncepty:

- **Uzel**: Místo, kde se dataset rozděluje
- **Kořen**: Nejvyšší uzel (počáteční bod)
- **List**: Koncové uzly poskytující predikce
- **Kritéria dělení**: Metriky používané pro určení nejlepšího rozdělení
  - Klasifikace: Gini nečistota, Informační zisk (entropie)
  - Regrese: Střední kvadratická chyba, Střední absolutní chyba

```python
# Načtení ukázkového datasetu - Iris pro klasifikaci
iris = load_iris()
X_iris = pd.DataFrame(iris.data, columns=iris.feature_names)
y_iris = iris.target

print("Tvar datasetu Iris:", X_iris.shape)
print("Příznaky:", iris.feature_names)
print("Cílové třídy:", iris.target_names)

# Načtení ukázkového datasetu - California Housing pro regresi
housing = fetch_california_housing()
X_housing = pd.DataFrame(housing.data, columns=housing.feature_names)
y_housing = housing.target

print("\nTvar datasetu California Housing:", X_housing.shape)
print("Příznaky:", housing.feature_names)
```

## Tvorba rozhodovacích stromů v Pythonu

Vytvoříme modely rozhodovacích stromů jak pro klasifikační, tak pro regresní úlohy pomocí knihovny scikit-learn:

### Rozhodovací strom pro klasifikaci

```python
# Rozdělení datasetu Iris
X_train, X_test, y_train, y_test = train_test_split(
    X_iris, y_iris, test_size=0.3, random_state=42
)

# Vytvoření klasifikátoru rozhodovacího stromu
dt_clf = DecisionTreeClassifier(random_state=42)

# Trénování modelu
dt_clf.fit(X_train, y_train)

# Predikce
y_pred = dt_clf.predict(X_test)

# Vyhodnocení modelu
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost klasifikace: {accuracy:.4f}")
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred, target_names=iris.target_names))

# Zobrazení matice záměn
cm = confusion_matrix(y_test, y_pred)
plt.figure(figsize=(8, 6))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
            xticklabels=iris.target_names,
            yticklabels=iris.target_names)
plt.xlabel('Predikované')
plt.ylabel('Skutečné')
plt.title('Matice záměn')
plt.show()
```

### Rozhodovací strom pro regresi

```python
# Rozdělení datasetu housing
X_train, X_test, y_train, y_test = train_test_split(
    X_housing, y_housing, test_size=0.3, random_state=42
)

# Vytvoření regresního rozhodovacího stromu
```

## Vizualizace rozhodovacích stromů

Vizualizace rozhodovacích stromů pomáhá pochopit, jak model rozhoduje:

```python
# Vytvoření jednoduššího rozhodovacího stromu pro vizualizaci (omezení max_depth)
dt_viz = DecisionTreeClassifier(max_depth=3, random_state=42)
dt_viz.fit(X_train, y_train)

# Vizualizace rozhodovacího stromu
plt.figure(figsize=(15, 10))
plot_tree(dt_viz, feature_names=iris.feature_names, 
          class_names=iris.target_names, filled=True, 
          rounded=True, fontsize=10)
plt.title("Vizualizace rozhodovacího stromu")
plt.show()

# Rozhodovací cesty pro vzorek
sample_idx = 5
sample = X_test.iloc[sample_idx:sample_idx+1]
path = dt_viz.decision_path(sample)

# Zobrazení rozhodovací cesty
feature_importances = []
node_indicator = path.indices
for i, node_index in enumerate(node_indicator):
    if i == 0:  # Přeskočit kořen
        continue
    if i < len(node_indicator) - 1:  # Není listový uzel
        feature = dt_viz.tree_.feature[node_index]
        threshold = dt_viz.tree_.threshold[node_index]
        feature_name = iris.feature_names[feature]
        feature_value = sample.iloc[0, feature]
        feature_importances.append((feature_name, feature_value, threshold))

print("\nRozhodovací cesta pro vzorek:")
for feat, val, thresh in feature_importances:
    comparison = "<=" if val <= thresh else ">"
    print(f"- {feat} = {val:.2f} {comparison} {thresh:.2f}")
print(f"Predikovaná třída: {iris.target_names[dt_viz.predict(sample)[0]]}")
```

## Náhodné lesy: Ensemble learning

Náhodné lesy kombinují více rozhodovacích stromů ke zlepšení přesnosti predikce a snížení přetrénování. Každý strom je postaven na náhodném podvzorku dat a příznaků.

### Klíčové charakteristiky:

- **Bagging (Bootstrap Aggregating)**: Každý strom používá náhodný vzorek datových bodů
- **Náhodnost příznaků**: Každý strom používá náhodnou podmnožinu příznaků
- **Hlasování/Průměrování**: Klasifikace používá většinové hlasování, regrese používá průměr

```python
# Vytvoření klasifikátoru náhodného lesa
rf_clf = RandomForestClassifier(n_estimators=100, random_state=42)

# Trénování modelu
rf_clf.fit(X_train, y_train)

# Predikce
y_pred_rf = rf_clf.predict(X_test)

# Vyhodnocení náhodného lesa
rf_accuracy = accuracy_score(y_test, y_pred_rf)
print(f"Přesnost klasifikace náhodného lesa: {rf_accuracy:.4f}")
print("\nKlasifikační zpráva náhodného lesa:")
print(classification_report(y_test, y_pred_rf, target_names=iris.target_names))

# Porovnání s jedním rozhodovacím stromem
print(f"\nPřesnost rozhodovacího stromu: {accuracy:.4f}")
print(f"Přesnost náhodného lesa: {rf_accuracy:.4f}")
print(f"Zlepšení: {(rf_accuracy - accuracy) * 100:.2f}%")
```

## Tvorba náhodných lesů v Pythonu

Implementujme úlohy klasifikace i regrese pomocí náhodných lesů:

### Náhodný les pro regresi

```python
# Vytvoření regresoru náhodného lesa
rf_reg = RandomForestRegressor(n_estimators=100, random_state=42)

# Trénování modelu
rf_reg.fit(X_train, y_train)

# Predikce
y_pred_rf_reg = rf_reg.predict(X_test)

# Vyhodnocení regresoru náhodného lesa
rf_mse = mean_squared_error(y_test, y_pred_rf_reg)
rf_r2 = r2_score(y_test, y_pred_rf_reg)
print(f"Střední kvadratická chyba náhodného lesa: {rf_mse:.4f}")
print(f"R² náhodného lesa: {rf_r2:.4f}")

# Porovnání s regresorem rozhodovacího stromu
print(f"\nStřední kvadratická chyba rozhodovacího stromu: {mse:.4f}")
print(f"Střední kvadratická chyba náhodného lesa: {rf_mse:.4f}")
print(f"Zlepšení: {(mse - rf_mse) / mse * 100:.2f}%")

# Vizualizace skutečných vs. predikovaných hodnot pro náhodný les
plt.figure(figsize=(10, 6))
plt.scatter(y_test, y_pred_rf_reg, alpha=0.5, color='green')
plt.plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], 'r--')
plt.xlabel('Skutečné hodnoty')
plt.ylabel('Predikované hodnoty')
plt.title('Regrese náhodným lesem: Skutečné vs. Predikované')
plt.show()
```

## Ladění hyperparametrů

Jak rozhodovací stromy, tak náhodné lesy mají více hyperparametrů, které lze ladit pro lepší výkon:

```python
# Definování mřížky hyperparametrů pro náhodný les
param_grid = {
    'n_estimators': [50, 100, 200],
    'max_depth': [None, 10, 20, 30],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 2, 4]
}

# Vytvoření menší mřížky pro demonstrační účely
small_param_grid = {
    'n_estimators': [50, 100],
    'max_depth': [None, 10],
    'min_samples_split': [2, 5]
}

# Prohledávání mřížky s křížovou validací
grid_search = GridSearchCV(
    estimator=RandomForestClassifier(random_state=42),
    param_grid=small_param_grid,
    cv=5,
    scoring='accuracy',
    verbose=1,
    n_jobs=-1
)

# Provedení prohledávání mřížky
grid_search.fit(X_train, y_train)

# Nejlepší parametry a skóre
print("Nejlepší parametry:", grid_search.best_params_)
print("Nejlepší skóre křížové validace: {:.4f}".format(grid_search.best_score_))

# Vyhodnocení nejlepšího modelu
best_rf = grid_search.best_estimator_
best_accuracy = best_rf.score(X_test, y_test)
print(f"Testovací přesnost nejlepšího modelu: {best_accuracy:.4f}")

# Křížová validace pro posouzení robustnosti modelu
cv_scores = cross_val_score(best_rf, X_iris, y_iris, cv=5)
print("Skóre křížové validace:", cv_scores)
print(f"Průměrná přesnost křížové validace: {cv_scores.mean():.4f}")
print(f"Směrodatná odchylka přesnosti křížové validace: {cv_scores.std():.4f}")
```

## Praktické aplikace

Rozhodovací stromy a náhodné lesy mají mnoho praktických aplikací:

```python
# Načtení reálného datasetu - rakovina prsu
from sklearn.datasets import load_breast_cancer

cancer = load_breast_cancer()
X_cancer = pd.DataFrame(cancer.data, columns=cancer.feature_names)
y_cancer = cancer.target

print("Tvar datasetu rakoviny:", X_cancer.shape)
print("Počet příznaků:", X_cancer.shape[1])
print("Třídy:", cancer.target_names)
print("Rozložení tříd:", np.bincount(y_cancer))

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(
    X_cancer, y_cancer, test_size=0.3, random_state=42
)

# Trénování a vyhodnocení náhodného lesa na datasetu rakoviny
rf_cancer = RandomForestClassifier(n_estimators=100, random_state=42)
rf_cancer.fit(X_train, y_train)
y_pred = rf_cancer.predict(X_test)

# Vyhodnocení
accuracy = accuracy_score(y_test, y_pred)
print(f"Přesnost klasifikace rakoviny: {accuracy:.4f}")
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred, target_names=cancer.target_names))

# Důležitost příznaků pro predikci rakoviny
cancer_importances = pd.DataFrame({
    'Příznak': cancer.feature_names,
    'Důležitost': rf_cancer.feature_importances_
}).sort_values(by='Důležitost', ascending=False).head(10)

plt.figure(figsize=(12, 8))
sns.barplot(x='Důležitost', y='Příznak', data=cancer_importances)
plt.title('Top 10 příznaků pro predikci rakoviny prsu')
plt.tight_layout()
plt.show()

# Pravděpodobnostní predikce
y_proba = rf_cancer.predict_proba(X_test)
print("\nPravděpodobnostní predikce pro prvních 5 vzorků:")
for i in range(5):
    print(f"Vzorek {i+1}: Maligní {y_proba[i,0]:.4f}, Benigní {y_proba[i,1]:.4f}")
```

## Shrnutí

Rozhodovací stromy a náhodné lesy jsou výkonné a všestranné algoritmy strojového učení:

1. **Rozhodovací stromy**:
   - Intuitivní, snadné na pochopení a vizualizaci
   - Mohou pracovat s numerickými i kategorickými příznaky
   - Vyžadují minimální předzpracování dat
   - Náchylné k přetrénování na komplexních datasetech
   - Poskytují metriky důležitosti příznaků

2. **Náhodné lesy**:
   - Ensemble technika kombinující více rozhodovacích stromů
   - Výrazně snižuje přetrénování oproti jednotlivým stromům
   - Typicky poskytuje lepší přesnost predikce
   - Zachovává schopnost určení důležitosti příznaků
   - Robustnější vůči šumu v datech

3. **Hlavní výhody**:
   - Minimální požadavky na předzpracování
   - Dobře zvládají nelineární vztahy
   - Vestavěný výběr příznaků
   - Fungují jak pro klasifikaci, tak pro regresi
   - Přirozené zpracování chybějících hodnot

4. **Hlavní omezení**:
   - Náhodné lesy mohou být výpočetně náročné
   - Méně interpretovatelné než jednotlivé rozhodovací stromy
   - Zkreslení vůči příznakům s více úrovněmi v kategorických datech
   - Mohou mít problémy s vysoce nevyváženými datasety

5. **Kdy je použít**:
   - Když potřebujete model, který je snadno interpretovatelný (rozhodovací strom)
   - Když potřebujete vysokou predikční přesnost (náhodný les)
   - Při práci s komplexními interakcemi příznaků
   - Když je potřeba důležitost příznaků
   
Náhodné lesy zůstávají jedním z nejšířeji používaných algoritmů strojového učení v praxi díky jejich robustnímu výkonu napříč mnoha doménami a relativně přímočaré implementaci.
