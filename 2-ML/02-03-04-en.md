## Introduction to Reinforcement Learning

Reinforcement Learning (RL) is a type of machine learning where an agent learns to make decisions by taking actions in an environment to maximize cumulative reward. Unlike supervised learning, RL doesn't require labeled data; instead, it learns through trial and error interactions with the environment.

The key characteristics that distinguish reinforcement learning from other machine learning approaches include:

- **Trial and error exploration**: The agent must discover which actions yield the best rewards through experimentation
- **Delayed rewards**: Actions may affect not only immediate rewards but also future states and rewards
- **Sequential decision making**: RL tackles problems that involve making a sequence of decisions over time

## Key Components of RL

The reinforcement learning framework consists of several key components:

1. **Agent**: The learner or decision-maker
2. **Environment**: Everything the agent interacts with
3. **State (S)**: The current situation of the agent in the environment
4. **Action (A)**: A move the agent can make
5. **Reward (R)**: Feedback from the environment (positive or negative)
6. **Policy (π)**: The strategy that the agent employs to determine the next action
7. **Value Function (V)**: Expected long-term return with discount

## Markov Decision Processes

Reinforcement learning problems are commonly formalized using Markov Decision Processes (MDPs), which provide a mathematical framework for modeling decision-making in situations where outcomes are partly random and partly under the control of a decision-maker.

An MDP is defined by:
- A set of states S
- A set of actions A
- Transition probabilities P(s'|s,a)
- Reward function R(s,a,s')
- Discount factor γ (gamma)

The goal in an MDP is to find a policy π that maximizes the expected cumulative discounted reward:

$$V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R_t \mid S_0 = s, \pi \right]$$

```python
# Simple implementation of a Markov Decision Process

class SimpleMDP:
    def __init__(self):
        # States: 0=start, 1=intermediate, 2=goal
        self.num_states = 3
        self.num_actions = 2  # Actions: 0=left, 1=right
        
        # Transition probabilities: P[s][a][s'] = probability
        self.transition_probs = [
            # From state 0
            [[0.7, 0.3, 0.0],  # Action 0
             [0.1, 0.9, 0.0]], # Action 1
            
            # From state 1
            [[0.8, 0.2, 0.0],  # Action 0
             [0.0, 0.1, 0.9]], # Action 1
            
            # From state 2 (terminal state)
            [[0.0, 0.0, 1.0],  # Action 0
             [0.0, 0.0, 1.0]]  # Action 1
        ]
        
        # Rewards: R[s][a][s'] = reward
        self.rewards = [
            # From state 0
            [[0, 0, 0],  # Action 0
             [0, 1, 0]], # Action 1
            
            # From state 1
            [[0, 0, 0],  # Action 0
             [0, 0, 10]], # Action 1
            
            # From state 2
            [[0, 0, 0],  # Action 0
             [0, 0, 0]]  # Action 1
        ]
        
    def value_iteration(self, gamma=0.9, epsilon=1e-6):
        """
        Find the optimal value function and policy using value iteration.
        
        Args:
            gamma: Discount factor
            epsilon: Convergence threshold
            
        Returns:
            tuple: (optimal value function, optimal policy)
        """
        # Initialize value function
        V = [0] * self.num_states
        
        while True:
            delta = 0
            for s in range(self.num_states):
                v = V[s]
                
                # Compute the value of each action in this state
                action_values = []
                for a in range(self.num_actions):
                    value = 0
                    for s_prime in range(self.num_states):
                        reward = self.rewards[s][a][s_prime]
                        prob = self.transition_probs[s][a][s_prime]
                        value += prob * (reward + gamma * V[s_prime])
                    action_values.append(value)
                
                # Select the maximum value
                V[s] = max(action_values)
                
                # Calculate the maximum change in value
                delta = max(delta, abs(v - V[s]))
            
            # Check if we've converged
            if delta < epsilon:
                break
        
        # Compute the optimal policy
        policy = [0] * self.num_states
        for s in range(self.num_states):
            action_values = []
            for a in range(self.num_actions):
                value = 0
                for s_prime in range(self.num_states):
                    reward = self.rewards[s][a][s_prime]
                    prob = self.transition_probs[s][a][s_prime]
                    value += prob * (reward + gamma * V[s_prime])
                action_values.append(value)
            policy[s] = action_values.index(max(action_values))
        
        return V, policy

# Create and solve the MDP
mdp = SimpleMDP()
optimal_values, optimal_policy = mdp.value_iteration()

print("Optimal Value Function:", optimal_values)
print("Optimal Policy:", optimal_policy)
```

## Q-Learning Algorithm

Q-Learning is a model-free reinforcement learning algorithm that seeks to find the optimal action-selection policy using a Q-function that assigns values to state-action pairs. The Q-function represents the expected utility of taking a given action in a given state and following the optimal policy thereafter.

The Q-learning update rule is:

$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$$

Where:
- Q(s, a) is the value of taking action a in state s
- α (alpha) is the learning rate
- γ (gamma) is the discount factor
- r is the reward
- s' is the next state

```python
# Q-Learning implementation for the grid world

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.table import Table

def q_learning_grid_world():
    # Environment parameters
    grid_size = 4
    actions = ['up', 'right', 'down', 'left']
    
    # Learning parameters
    alpha = 0.1  # Learning rate
    gamma = 0.9  # Discount factor
    epsilon = 0.1  # Exploration rate
    
    # Initialize Q-table with zeros
    q_table = np.zeros((grid_size, grid_size, len(actions)))
    
    # Define the rewards
    rewards = np.full((grid_size, grid_size), -0.04)  # Small negative reward for each step
    rewards[grid_size-1, grid_size-1] = 1  # Goal state
    rewards[grid_size-1, 0] = -1  # Negative terminal state
    terminal_states = [(grid_size-1, grid_size-1), (grid_size-1, 0)]
    
    # Define valid moves for each state
    def get_valid_actions(state):
        valid = []
        row, col = state
        if row > 0:  # Can move up
            valid.append(0)
        if col < grid_size - 1:  # Can move right
            valid.append(1)
        if row < grid_size - 1:  # Can move down
            valid.append(2)
        if col > 0:  # Can move left
            valid.append(3)
        return valid
    
    # Define the next state function
    def get_next_state(state, action):
        row, col = state
        if action == 0:  # Up
            return (max(0, row-1), col)
        elif action == 1:  # Right
            return (row, min(grid_size-1, col+1))
        elif action == 2:  # Down
            return (min(grid_size-1, row+1), col)
        elif action == 3:  # Left
            return (row, max(0, col-1))
    
    # Training the agent
    n_episodes = 5000
    
    for episode in range(n_episodes):
        # Start at a random non-terminal state
        while True:
            state = (np.random.randint(0, grid_size), np.random.randint(0, grid_size))
            if state not in terminal_states:
                break
        
        done = False
        
        while not done:
            # Epsilon-greedy action selection
            valid_actions = get_valid_actions(state)
            
            if np.random.uniform(0, 1) < epsilon:
                # Explore: choose a random action from valid actions
                action = np.random.choice(valid_actions)
            else:
                # Exploit: choose the best action based on Q-values
                # (but only consider valid actions)
                valid_q_values = [q_table[state[0], state[1], a] if a in valid_actions else -np.inf 
                                 for a in range(len(actions))]
                action = np.argmax(valid_q_values)
            
            # Get next state and reward
            next_state = get_next_state(state, action)
            reward = rewards[next_state[0], next_state[1]]
            
            # Check if this is a terminal state
            done = next_state in terminal_states
            
            # Q-learning update
            old_q = q_table[state[0], state[1], action]
            next_max = np.max(q_table[next_state[0], next_state[1]])
            
            new_q = (1 - alpha) * old_q + alpha * (reward + gamma * next_max * (not done))
            q_table[state[0], state[1], action] = new_q
            
            # Move to the next state
            state = next_state
    
    # Visualize the policy
    policy = np.zeros((grid_size, grid_size), dtype=int)
    arrows = ['↑', '→', '↓', '←']
    
    for i in range(grid_size):
        for j in range(grid_size):
            if (i, j) not in terminal_states:
                policy[i, j] = np.argmax(q_table[i, j])
    
    # Create a figure and axis
    fig, ax = plt.subplots(figsize=(8, 8))
    ax.set_axis_off()
    
    # Add a table at the bottom of the axis
    tb = Table(ax, bbox=[0, 0, 1, 1])
    
    # Add cells
    cell_width = 1.0 / grid_size
    cell_height = 1.0 / grid_size
    
    for i in range(grid_size):
        for j in range(grid_size):
            if (i, j) in terminal_states:
                # Terminal states
                if rewards[i, j] > 0:
                    value = 'Goal'
                    color = 'green'
                else:
                    value = 'Fail'
                    color = 'red'
            else:
                value = arrows[policy[i, j]]
                max_q = np.max(q_table[i, j])
                color = 'white'
            
            tb.add_cell(i, j, cell_width, cell_height, text=value,
                       loc='center', facecolor=color)
    
    # Row and column labels...
    for i in range(grid_size):
        tb.add_cell(i, -1, cell_width, cell_height, text=i+1,
                   loc='right', edgecolor='none', facecolor='none')
        tb.add_cell(-1, i, cell_width, cell_height, text=i+1,
                   loc='center', edgecolor='none', facecolor='none')
    
    ax.add_table(tb)
    plt.title('Learned Policy')
    plt.show()
    
    return q_table, policy

# Run Q-learning
q_table, policy = q_learning_grid_world()
```

## Deep Q-Networks (DQN)

Deep Q-Networks (DQN) combine Q-Learning with deep neural networks to handle high-dimensional observation spaces. DQN has been a breakthrough in RL, demonstrating human-level control in Atari games using only raw pixels as input.

Key innovations in DQN include:
- Experience replay: Storing past experiences and sampling them randomly for training
- Target networks: Using a separate network for generating the targets in the Q-learning update
- Convolutional networks: Processing image inputs effectively

```python
# Deep Q-Network implementation using TensorFlow

import tensorflow as tf
import numpy as np
from collections import deque
import random

class DQN:
    def __init__(self, state_size, action_size):
        self.state_size = state_size
        self.action_size = action_size
        self.memory = deque(maxlen=2000)
        self.gamma = 0.95  # Discount factor
        self.epsilon = 1.0  # Exploration rate
        self.epsilon_min = 0.01
        self.epsilon_decay = 0.995
        self.learning_rate = 0.001
        self.model = self._build_model()
        self.target_model = self._build_model()
        self.update_target_model()
        
    def _build_model(self):
        """Neural network for Q-function approximation"""
        model = tf.keras.models.Sequential()
        model.add(tf.keras.layers.Dense(24, input_dim=self.state_size, activation='relu'))
        model.add(tf.keras.layers.Dense(24, activation='relu'))
        model.add(tf.keras.layers.Dense(self.action_size, activation='linear'))
        model.compile(loss='mse', optimizer=tf.keras.optimizers.Adam(lr=self.learning_rate))
        return model
    
    def update_target_model(self):
        """Copy weights from model to target_model"""
        self.target_model.set_weights(self.model.get_weights())
    
    def remember(self, state, action, reward, next_state, done):
        """Store experience in replay memory"""
        self.memory.append((state, action, reward, next_state, done))
    
    def act(self, state):
        """Epsilon-greedy action selection"""
        if np.random.rand() <= self.epsilon:
            return random.randrange(self.action_size)
        act_values = self.model.predict(state)
        return np.argmax(act_values[0])
    
    def replay(self, batch_size):
        """Train model using experience replay"""
        minibatch = random.sample(self.memory, batch_size)
        for state, action, reward, next_state, done in minibatch:
            target = reward
            if not done:
                target = reward + self.gamma * np.amax(self.target_model.predict(next_state)[0])
            target_f = self.model.predict(state)
            target_f[0][action] = target
            self.model.fit(state, target_f, epochs=1, verbose=0)
        
        if self.epsilon > self.epsilon_min:
            self.epsilon *= self.epsilon_decay
    
    def load(self, name):
        self.model.load_weights(name)
    
    def save(self, name):
        self.model.save_weights(name)
```

## Policy Gradient Methods

While value-based methods like Q-learning focus on finding the optimal value function and then deriving a policy, policy gradient methods directly optimize the policy. These methods are particularly useful for continuous action spaces and stochastic policies.

The basic idea is to adjust the parameters θ of a policy πθ in the direction of the gradient of the expected return:

$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta(\tau)}[\nabla_\theta \log \pi_\theta(a_t|s_t) \cdot R(\tau)]$$

```python
# Simple implementation of REINFORCE (Monte Carlo Policy Gradient)
import numpy as np
import tensorflow as tf
import gym

class PolicyGradient:
    def __init__(self, state_size, action_size, learning_rate=0.01):
        self.state_size = state_size
        self.action_size = action_size
        self.gamma = 0.99
        
        # Build policy network
        self.model = self._build_policy_network(learning_rate)
        
        # Episode memory
        self.states = []
        self.actions = []
        self.rewards = []
    
    def _build_policy_network(self, learning_rate):
        """Build the policy network that outputs action probabilities"""
        model = tf.keras.Sequential([
            tf.keras.layers.Dense(24, input_dim=self.state_size, activation='relu'),
            tf.keras.layers.Dense(24, activation='relu'),
            tf.keras.layers.Dense(self.action_size, activation='softmax')
        ])
        
        model.compile(
            loss='categorical_crossentropy',
            optimizer=tf.keras.optimizers.Adam(learning_rate=learning_rate)
        )
        return model
    
    def choose_action(self, state):
        """Choose an action based on the current policy"""
        state = np.reshape(state, [1, self.state_size])
        probabilities = self.model.predict(state)[0]
        # Sample action based on probabilities
        action = np.random.choice(self.action_size, p=probabilities)
        return action
    
    def store_transition(self, state, action, reward):
        """Store state, action, reward for the current episode"""
        self.states.append(state)
        
        # Convert action to one-hot encoding
        action_onehot = np.zeros(self.action_size)
        action_onehot[action] = 1
        self.actions.append(action_onehot)
        
        self.rewards.append(reward)
    
    def learn(self):
        """Update policy network based on returns"""
        # Calculate discounted returns for each time step
        discounted_returns = []
        cumulative_reward = 0
        
        for reward in reversed(self.rewards):
            cumulative_reward = reward + self.gamma * cumulative_reward
            discounted_returns.insert(0, cumulative_reward)
        
        # Normalize returns
        discounted_returns = np.array(discounted_returns)
        discounted_returns = (discounted_returns - np.mean(discounted_returns)) / (np.std(discounted_returns) + 1e-8)
        
        # Prepare training data
        states = np.vstack(self.states)
        actions = np.vstack(self.actions)
        
        # Train the model - using actions as targets, scaled by returns
        self.model.fit(
            states, 
            actions * np.expand_dims(discounted_returns, axis=1),
            epochs=1, verbose=0
        )
        
        # Clear episode data
        self.states = []
        self.actions = []
        self.rewards = []

# Demo usage with CartPole
def run_policy_gradient():
    env = gym.make('CartPole-v1')
    state_size = env.observation_space.shape[0]
    action_size = env.action_space.n
    agent = PolicyGradient(state_size, action_size)
    
    episodes = 1000
    scores = []
    
    for e in range(episodes):
        state = env.reset()
        state = np.reshape(state, [state_size])
        score = 0
        done = False
        
        while not done:
            action = agent.choose_action(state)
            next_state, reward, done, _ = env.step(action)
            agent.store_transition(state, action, reward)
            state = next_state
            score += reward
            
            if done:
                # Train at the end of each episode
                agent.learn()
                scores.append(score)
                print(f"Episode: {e+1}/{episodes}, Score: {score}")
                break
                
        # If average of last 100 episodes is > 195, consider solved
        if len(scores) > 100 and np.mean(scores[-100:]) > 195:
            print("Environment solved!")
            break
    
    return scores

# To run the demo: scores = run_policy_gradient()
```

```python
# Create a simple custom environment
class SimpleGridEnv(gym.Env):
    """
    A simple 2D grid environment where an agent moves to reach a goal.
    """
    def __init__(self, grid_size=5):
        super(SimpleGridEnv, self).__init__()
        
        self.grid_size = grid_size
        
        # Define the action space (0: up, 1: right, 2: down, 3: left)
        self.action_space = gym.spaces.Discrete(4)

        self.reset()
        
    def reset(self):
        # Agent starts at (0, 0)
        self.agent_pos = np.array([0, 0])
        
        # Goal is at the opposite corner
        self.goal_pos = np.array([self.grid_size-1, self.grid_size-1])
        
        # Return the observation
        return self._get_observation()
    
    def step(self, action):
        # Move according to action
        if action == 0:  # Up
            self.agent_pos[1] = min(self.grid_size-1, self.agent_pos[1]+1)
        elif action == 1:  # Right
            self.agent_pos[0] = min(self.grid_size-1, self.agent_pos[0]+1)
        elif action == 2:  # Down
            self.agent_pos[1] = max(0, self.agent_pos[1]-1)
        elif action == 3:  # Left
            self.agent_pos[0] = max(0, self.agent_pos[0]-1)
        
        # Check if the agent has reached the goal
        done = np.array_equal(self.agent_pos, self.goal_pos)
        
        # Calculate reward
        if done:
            reward = 1.0  # Positive reward for reaching the goal
        else:
            # Negative reward based on distance to goal
            distance = np.sum(np.abs(self.agent_pos - self.goal_pos))
            reward = -0.1 * distance / (2 * self.grid_size)
        
        # Return observation, reward, done flag, and info
        return self._get_observation(), reward, done, {}
    
    def _get_observation(self):
        return self.agent_pos.copy()
    
    def render(self, mode='human'):
        if mode == 'human':
            grid = np.zeros((self.grid_size, self.grid_size, 3))
            
            # Mark the agent position (red)
            grid[self.agent_pos[1], self.agent_pos[0]] = [1.0, 0.0, 0.0]
            
            # Mark the goal position (green)
            grid[self.goal_pos[1], self.goal_pos[0]] = [0.0, 1.0, 0.0]
            
            plt.imshow(grid)
            plt.grid(True)
            plt.show()
        
        # Return an RGB array for rgb_array mode
        elif mode == 'rgb_array':
            grid = np.zeros((self.grid_size, self.grid_size, 3))
            grid[self.agent_pos[1], self.agent_pos[0]] = [1.0, 0.0, 0.0]
            grid[self.goal_pos[1], self.goal_pos[0]] = [0.0, 1.0, 0.0]
            
            # Upscale the grid for better visualization
            return np.repeat(np.repeat(grid, 50, axis=0), 50, axis=1)
```

## Multi-Armed Bandits

The multi-armed bandit problem is a simplified reinforcement learning scenario with only one state and multiple actions (arms). The agent must decide which arm to pull to maximize cumulative rewards over time, balancing exploration (trying different arms) and exploitation (playing the best-known arm).

```python
# Implementation of epsilon-greedy and UCB algorithms for the multi-armed bandit problem

import numpy as np
import matplotlib.pyplot as plt

class MultiArmedBandit:
    def __init__(self, n_arms, true_rewards=None):
        self.n_arms = n_arms
        
        # If true rewards are not provided, generate them randomly
        if true_rewards is None:
            self.true_rewards = np.random.normal(0, 1, n_arms)
        else:
            self.true_rewards = true_rewards
            
    def pull(self, arm):
        """Pull an arm and get a reward"""
        # The observed reward is the true reward plus some noise
        return np.random.normal(self.true_rewards[arm], 1)

class EpsilonGreedy:
    def __init__(self, n_arms, epsilon=0.1):
        self.n_arms = n_arms
        self.epsilon = epsilon
        self.q_values = np.zeros(n_arms)  # Estimated value for each arm
        self.arm_counts = np.zeros(n_arms)  # How many times each arm was pulled
        
    def select_arm(self):
        """Select an arm using epsilon-greedy strategy"""
        # With probability epsilon, explore
        if np.random.random() < self.epsilon:
            return np.random.randint(self.n_arms)
        # Otherwise, exploit the best arm
        else:
            return np.argmax(self.q_values)
    
    def update(self, arm, reward):
        """Update Q-values based on observed reward"""
        self.arm_counts[arm] += 1
        # Incremental averaging
        self.q_values[arm] += (reward - self.q_values[arm]) / self.arm_counts[arm]

class UCB:
    def __init__(self, n_arms, c=2.0):
        self.n_arms = n_arms
        self.c = c  # Exploration parameter
        self.q_values = np.zeros(n_arms)
        self.arm_counts = np.zeros(n_arms)
        self.total_count = 0
        
    def select_arm(self):
        """Select an arm using UCB strategy"""
        # Pull each arm at least once
        for arm in range(self.n_arms):
            if self.arm_counts[arm] == 0:
                return arm
        
        # Calculate UCB values
        ucb_values = self.q_values + self.c * np.sqrt(
            np.log(self.total_count) / self.arm_counts)
        
        # Return arm with maximum UCB value
        return np.argmax(ucb_values)
    
    def update(self, arm, reward):
        """Update Q-values and counts based on observed reward"""
        self.arm_counts[arm] += 1
        self.total_count += 1
        self.q_values[arm] += (reward - self.q_values[arm]) / self.arm_counts[arm]

def run_bandit_experiment(n_arms=10, n_steps=1000, n_runs=100):
    """Run multi-armed bandit experiments with different strategies"""
    # Create bandits with the same true rewards for fair comparison
    true_rewards = np.random.normal(0, 1, n_arms)
    
    # Strategies to compare
    strategies = {
        'Epsilon-Greedy (ε=0.1)': EpsilonGreedy(n_arms, epsilon=0.1),
        'Epsilon-Greedy (ε=0.01)': EpsilonGreedy(n_arms, epsilon=0.01),
        'UCB (c=2.0)': UCB(n_arms, c=2.0)
    }
    
    # Store results
    rewards = {name: np.zeros((n_runs, n_steps)) for name in strategies}
    optimal_actions = {name: np.zeros((n_runs, n_steps)) for name in strategies}
    
    for run in range(n_runs):
        # Create a new bandit for this run
        bandit = MultiArmedBandit(n_arms, true_rewards.copy())
        optimal_arm = np.argmax(true_rewards)
        
        # Reset strategies
        for name, strategy in strategies.items():
            if isinstance(strategy, EpsilonGreedy):
                strategies[name] = EpsilonGreedy(n_arms, strategy.epsilon)
            elif isinstance(strategy, UCB):
                strategies[name] = UCB(n_arms, strategy.c)
        
        # Run experiment for each strategy
        for name, strategy in strategies.items():
            for step in range(n_steps):
                # Select an arm
                arm = strategy.select_arm()
                
                # Get reward
                reward = bandit.pull(arm)
                
                # Update strategy
                strategy.update(arm, reward)
                
                # Store results
                rewards[name][run, step] = reward
                optimal_actions[name][run, step] = 1 if arm == optimal_arm else 0
    
    # Plot average rewards
    plt.figure(figsize=(12, 5))
    
    plt.subplot(1, 2, 1)
    for name in strategies:
        plt.plot(np.mean(rewards[name], axis=0), label=name)
    plt.xlabel('Steps')
    plt.ylabel('Average Reward')
    plt.title('Average Reward Over Time')
    plt.legend()
    
    plt.subplot(1, 2, 2)
    for name in strategies:
        plt.plot(np.mean(optimal_actions[name], axis=0), label=name)
    plt.xlabel('Steps')
    plt.ylabel('Optimal Action %')
    plt.title('Probability of Selecting Optimal Action')
    plt.legend()
    
    plt.tight_layout()
    plt.show()
```

```python
# Simple example of a trading agent using RL
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from gym import spaces
import gym

class StockTradingEnv(gym.Env):
    """A simple stock trading environment for reinforcement learning"""
    metadata = {'render.modes': ['human']}

    def __init__(self, df, initial_balance=10000):
        super(StockTradingEnv, self).__init__()
        
        self.df = df
        self.initial_balance = initial_balance
        self.reward_range = (-np.inf, np.inf)
        
        # Actions: 0=sell, 1=hold, 2=buy
        self.action_space = spaces.Discrete(3)
        
        # Observations: [balance, shares_held, stock_price, % change]
        self.observation_space = spaces.Box(
            low=np.array([0, 0, 0, -1]), 
            high=np.array([np.inf, np.inf, np.inf, 1]), 
            dtype=np.float32
        )
        
        self.reset()
    
    def reset(self):
        # Reset the state
        self.balance = self.initial_balance
        self.shares_held = 0
        self.current_step = 0
        self.net_worth = self.balance
        self.prev_net_worth = self.initial_balance
        
        return self._get_observation()
    
    def _get_observation(self):
        stock_price = self.df.iloc[self.current_step]['close']
        stock_pct_change = self.df.iloc[self.current_step]['pct_change']
        
        obs = np.array([
            self.balance,
            self.shares_held,
            stock_price,
            stock_pct_change
        ])
        
        return obs
    
    def step(self, action):
        # Get current price and define transaction cost
        current_price = self.df.iloc[self.current_step]['close']
        transaction_cost_pct = 0.001  # 0.1% transaction cost
        
        # Execute action
        if action == 0:  # Sell
            if self.shares_held > 0:
                # Calculate transaction cost
                sell_amount = self.shares_held * current_price
                transaction_cost = sell_amount * transaction_cost_pct
                
                # Update balance and shares
                self.balance += sell_amount - transaction_cost
                self.shares_held = 0
        
        elif action == 2:  # Buy
            # Calculate max shares we can buy
            max_shares = self.balance // (current_price * (1 + transaction_cost_pct))
            
            if max_shares > 0:
                # Calculate transaction cost
                buy_amount = max_shares * current_price
                transaction_cost = buy_amount * transaction_cost_pct
                
                # Update balance and shares
                self.balance -= buy_amount + transaction_cost
                self.shares_held += max_shares
        
        # Action 1 is hold, so we do nothing
        
        # Move to the next step
        self.current_step += 1
        
        # Calculate reward (change in net worth)
        self.net_worth = self.balance + self.shares_held * current_price
        reward = self.net_worth - self.prev_net_worth
        self.prev_net_worth = self.net_worth
        
        # Check if episode is done
        done = self.current_step >= len(self.df) - 1
        
        return self._get_observation(), reward, done, {}
    
    def render(self, mode='human'):
        """Render the environment to the screen"""
        if mode == 'human':
            profit = self.net_worth - self.initial_balance
            print(f'Step: {self.current_step}')
            print(f'Balance: {self.balance}')
            print(f'Shares held: {self.shares_held}')
            print(f'Net worth: {self.net_worth}')
            print(f'Profit: {profit}')
        
        return np.array([])
```

## Summary

Reinforcement Learning (RL) represents a powerful approach to machine learning that enables agents to learn optimal behaviors through interactions with an environment. Key takeaways from this overview include:

1. **Core Concept**: RL is based on the idea of learning through trial and error, where an agent takes actions in an environment to maximize cumulative rewards.

2. **MDP Framework**: Markov Decision Processes provide the mathematical foundation for RL, formalizing the concepts of states, actions, rewards, and transitions.

3. **Value vs Policy Methods**: RL algorithms can be broadly categorized into value-based methods (like Q-learning) that estimate the value of states or actions, and policy-based methods that directly optimize the policy.

4. **Classic Algorithms**: Q-learning is a foundational algorithm that learns action values for each state and gradually improves the policy through exploration and exploitation.

5. **Deep RL**: Deep Q-Networks (DQN) extend classic RL by using neural networks as function approximators, enabling RL to work with high-dimensional state spaces like images.

6. **Policy Gradients**: These methods directly optimize policy parameters using gradients of expected returns, which is particularly effective for continuous action spaces and stochastic policies.

7. **Exploration vs Exploitation**: RL algorithms must balance exploring new actions to discover better strategies and exploiting known good actions to maximize rewards.

8. **OpenAI Gym**: This toolkit provides a standardized interface for RL environments and a collection of benchmark problems to develop and test algorithms.

9. **Practical Applications**: RL has been successfully applied to various domains including game playing, robotics, finance, and healthcare.

RL continues to be an active area of research with new algorithms and applications emerging regularly. Its ability to learn complex behaviors from simple reward signals makes it a powerful approach for solving sequential decision-making problems.
