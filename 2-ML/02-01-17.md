# Úvod do Neuronových Sítí - Shrnutí

## Hlavní body

1. **Základní komponenty neuronových sítí**
   - **Neurony**: Základní výpočetní jednotky přijímající vstupy, zpracovávající je a generující výstupy
   - **Váhy**: Parametry určující sílu spojení mezi neurony
   - **Bias**: Dodatečné parametry umožňující lepší přizpůsobení modelu datům
   - **Aktivační funkce**: Nelineární funkce zavádějící nelinearitu do sítě
   - **Vrstvy**: Skupiny neuronů, které zpracovávají informace podobným způsobem

2. **Běžné aktivační funkce**
   - **Sigmoid**: Mapuje hodnoty do rozsahu mezi 0 a 1, používá se pro binární klasifikaci
   - **Tanh**: Mapuje hodnoty do rozsahu mezi -1 a 1, má centrovaný výstup kolem nuly
   - **ReLU (Rectified Linear Unit)**: Vrací x pro x > 0, jinak 0, řeší problém mizejícího gradientu
   - **Leaky ReLU**: Vrací x pro x > 0, jinak αx (kde α je malá konstanta), předchází problému "mrtvého ReLU"

3. **Implementace neuronové sítě od základů**
   - Dopředná propagace: Průchod dat skrz síť od vstupní po výstupní vrstvu
   - Výpočet ztrátové funkce: Měření rozdílu mezi predikovanými a skutečnými hodnotami
   - Zpětná propagace: Výpočet gradientů pro aktualizaci vah
   - Optimalizace gradientním sestupem: Iterativní aktualizace parametrů sítě

4. **Trénování a vyhodnocení neuronových sítí**
   - Rozdělení dat na trénovací a testovací sady
   - Standardizace vstupních hodnot
   - Monitorování ztrátové funkce a přesnosti během trénování
   - Evaluace výkonu pomocí metrik jako přesnost, precision, recall a F1 skóre

5. **Architektury neuronových sítí**
   - **Feedforward Neural Networks (FNN)**: Informace teče jedním směrem, používá se pro klasifikaci a regresi
   - **Convolutional Neural Networks (CNN)**: Specializované pro zpracování obrazových dat, používá konvoluční vrstvy
   - **Recurrent Neural Networks (RNN)**: Navržené pro sekvenční data, obsahuje zpětnovazební připojení
   - **Long Short-Term Memory (LSTM)**: Speciální typ RNN pro zachycení dlouhodobých závislostí
   - **Transformers**: Využívá mechanismy self-attention pro paralelní zpracování sekvencí

6. **Implementace pomocí TensorFlow/Keras**
   - Vytvoření modelu pomocí vysokoúrovňového API
   - Kompilace modelu s definicí optimalizátoru a ztrátové funkce
   - Trénování a validace s využitím vestavěných funkcí
   - Porovnání výkonu s implementací od základů

7. **Běžné problémy a jejich řešení**
   - **Přeučení (Overfitting)**: Síť si pamatuje trénovací data, ale špatně generalizuje
     - Řešení: Regularizace (L1/L2), Dropout, Early stopping, Augmentace dat
   - **Mizející/explodující gradienty**: Gradienty se stávají příliš malými nebo velkými během zpětné propagace
     - Řešení: Správná inicializace, Batch normalizace, Gradient clipping, ReLU aktivace
   - **Ladění hyperparametrů**: Hledání optimálních hodnot pro learning rate, velikost dávky, architekturu sítě
     - Řešení: Grid/Random search, Bayesovská optimalizace
   - **Doba trénování**: Hluboké sítě mohou trvat dny/týdny
     - Řešení: Transfer learning, GPUs/TPUs, Distribuované trénování
   - **Interpretovatelnost modelu**: Neuronové sítě jsou "černé skříňky"
     - Řešení: Vizualizační techniky, Attention mechanismy, SHAP hodnoty

8. **Evaluace výkonu neuronových sítí**
   - **Přesnost (Accuracy)**: Podíl správných predikcí
   - **Precision**: True positives / (True positives + False positives)
   - **Recall**: True positives / (True positives + False negatives)
   - **F1 skóre**: Harmonický průměr precision a recall
   - **Matice záměn (Confusion Matrix)**: Vizuální reprezentace chyb predikce
   - **ROC křivka a AUC**: Výkon napříč klasifikačními prahy

## Závěrečné shrnutí v češtině

Neuronové sítě představují základ moderního hlubokého učení (deep learning) a umožnily značný pokrok v oblasti umělé inteligence. Jsou mimořádně účinné pro úlohy zahrnující rozpoznávání vzorů, včetně klasifikace obrazů, zpracování přirozeného jazyka a predikce časových řad.

Základní stavební kameny neuronové sítě jsou neurony, váhy, biasy a aktivační funkce. Neurony jsou organizovány do vrstev, kde každá vrstva transformuje svoje vstupy pomocí nastavitelných parametrů (vah) a nelineárních aktivačních funkcí. Mezi běžné aktivační funkce patří sigmoid, tanh, ReLU a Leaky ReLU, každá s vlastními výhodami a nevýhodami.

Trénování neuronové sítě zahrnuje dopřednou propagaci (výpočet výstupu sítě), výpočet ztrátové funkce (měření chyby) a zpětnou propagaci (aktualizace vah). Tento proces se opakuje mnohokrát, dokud síť nedosáhne požadované přesnosti.

Existuje několik architektur neuronových sítí, každá navržená pro specifické typy problémů. Feedforward sítě jsou nejjednodušší a používají se pro základní klasifikaci a regresi. Konvoluční neuronové sítě (CNN) jsou specializované pro zpracování obrazu. Rekurentní neuronové sítě (RNN) a LSTM sítě jsou určeny pro sekvenční data. Transformery využívají mechanismy self-attention a jsou velmi efektivní pro úlohy zpracování přirozeného jazyka.

Implementace neuronových sítí může být provedena od základů pomocí NumPy nebo s využitím vysokoúrovňových knihoven jako TensorFlow/Keras. Tyto knihovny poskytují mnoho vestavěných funkcí, které usnadňují vývoj a trénink modelů.

Při práci s neuronovými sítěmi se často setkáváme s problémy jako přeučení, mizející/explodující gradienty a obtížné ladění hyperparametrů. Existuje však mnoho technik pro řešení těchto problémů, včetně regularizace, batch normalizace a pokročilých optimalizačních algoritmů.

Hodnocení výkonu neuronových sítí vyžaduje použití vhodných metrik, jako jsou přesnost, precision, recall, F1 skóre a matice záměn. Tyto metriky poskytují komplexní pohled na výkon modelu a pomáhají identifikovat oblasti pro zlepšení.

Pro další rozvoj v oblasti neuronových sítí je vhodné hlouběji prozkoumat pokročilé architektury, optimalizační techniky a aplikace v reálném světě. S rostoucím výpočetním výkonem a dostupností dat se možnosti neuronových sítí neustále rozšiřují, což otevírá nové horizonty pro řešení složitých problémů.
