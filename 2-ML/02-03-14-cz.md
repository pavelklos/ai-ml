## Úvod do grafových neuronových sítí

Grafové neuronové sítě (GNN) jsou třídou modelů hlubokého učení navržených pro práci s daty strukturovanými jako grafy. Na rozdíl od standardních neuronových sítí, které pracují s pravidelnými mřížkovými daty (jako jsou obrázky nebo sekvence), GNN mohou zpracovávat data reprezentovaná jako grafy s uzly (vrcholy) a hranami.

Grafy jsou mocným způsobem reprezentace mnoha reálných systémů:
- Sociální sítě (uživatelé jako uzly, přátelství jako hrany)
- Molekuly (atomy jako uzly, vazby jako hrany)
- Citační sítě (články jako uzly, citace jako hrany)
- Znalostní grafy (entity jako uzly, vztahy jako hrany)
- Sítě proteinových interakcí
- Dopravní sítě

GNN se mohou naučit reprezentace (embeddingy) uzlů, hran a celých grafů při zachování strukturálních informací.


## Reprezentace grafů ve strojovém učení

Než se ponoříme do GNN, je důležité pochopit, jak mohou být grafy reprezentovány ve formátu vhodném pro strojové učení.

### Matice sousednosti

Matice sousednosti A je maticí n×n (kde n je počet uzlů) s hodnotami A[i,j]=1, pokud existuje hrana z uzlu i do uzlu j, a 0 v opačném případě.

### Příznaky uzlů

Každý uzel v grafu může mít přidružené příznaky reprezentované jako vektor. Pro celý graf to dává matici příznaků uzlů X o velikosti n×d, kde d je dimenze příznaků.

### Příznaky hran

Podobně hrany mohou mít příznaky reprezentované jako tenzor o velikosti m×c, kde m je počet hran a c je dimenze příznaků hrany.

```python
# Vytvoření matice sousednosti a příznaků uzlů pro graf karate klubu
def create_graph_data(G):
    # Vytvoření matice sousednosti
    A = nx.to_numpy_array(G)
    
    # Vytvoření náhodných příznaků uzlů (v reálných aplikacích by byly smysluplné)
    num_nodes = G.number_of_nodes()
    feature_dim = 10
    X = np.random.randn(num_nodes, feature_dim)
    
    return A, X

A, X = create_graph_data(G)
print(f"Tvar matice sousednosti: {A.shape}")
print(f"Tvar matice příznaků uzlů: {X.shape}")

# Zobrazení části matice sousednosti
plt.figure(figsize=(8, 8))
plt.imshow(A[:10, :10], cmap='Blues')
plt.colorbar()
plt.title("Částečná matice sousednosti (prvních 10 uzlů)")
plt.show()
```

## Typy grafových neuronových sítí

Bylo vyvinuto několik typů GNN, každá s vlastním přístupem k učení z dat strukturovaných jako grafy:

### Grafové konvoluční sítě (GCN)

GCN zobecňují konvoluční operace na grafová data. Provádějí lokalizované průměrování příznaků s využitím struktury grafu.

### Grafové pozornostní sítě (GAT)

GAT začleňují mechanismy pozornosti pro vážení důležitosti různých sousedních uzlů při agregaci informací.

### GraphSAGE

GraphSAGE (Sample and AggreGatE) používá techniky vzorkování a agregace sousedství pro induktivní učení reprezentací na velkých grafech.

### Grafové izomorfní sítě (GIN)

GIN jsou navrženy tak, aby měly maximální diskriminační sílu mezi GNN pro rozlišování různých grafových struktur.

```python
# Zjednodušený pseudokód demonstrující různé vrstvy GNN
import torch.nn as nn
import torch.nn.functional as F

# Jednoduchá vrstva GCN
class GCNLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super(GCNLayer, self).__init__()
        self.linear = nn.Linear(in_features, out_features)
        
    def forward(self, x, adj):
        # Normalizace matice sousednosti
        D_inv_sqrt = torch.diag(torch.pow(torch.sum(adj, dim=1), -0.5))
        adj_normalized = D_inv_sqrt @ adj @ D_inv_sqrt
        
        # Grafová konvoluce
        support = self.linear(x)
        output = torch.matmul(adj_normalized, support)
        return F.relu(output)

# Jednoduchá vrstva GAT (pseudo-implementace)
class GATLayer(nn.Module):
    def __init__(self, in_features, out_features, dropout, alpha, concat=True):
        super(GATLayer, self).__init__()
        self.linear = nn.Linear(in_features, out_features)
        self.attention = nn.Linear(2 * out_features, 1)
        
    def forward(self, x, adj):
        # Lineární transformace
        h = self.linear(x)
        
        # Výpočet koeficientů pozornosti
        # (zjednodušená implementace)
        N = h.size()[0]
        a_input = torch.cat([h.repeat(1, N).view(N * N, -1), 
                             h.repeat(N, 1)], dim=1).view(N, N, -1)
        e = F.leaky_relu(self.attention(a_input).squeeze(2))
        
        # Maskování koeficientů pozornosti pomocí matice sousednosti
        zero_vec = -9e15 * torch.ones_like(e)
        attention = torch.where(adj > 0, e, zero_vec)
        attention = F.softmax(attention, dim=1)
        
        # Aplikace pozornosti
        h_prime = torch.matmul(attention, h)
        
        return F.elu(h_prime)
```

## Neuronové sítě s předáváním zpráv

Jádrem většiny GNN je koncept předávání zpráv, kde uzly iterativně aktualizují své reprezentace agregací informací od svých sousedů. Obecný rámec předávání zpráv se skládá z:

1. **Generování zpráv**: Výpočet zpráv na základě příznaků uzlů a hran
2. **Agregace zpráv**: Kombinování zpráv od sousedů
3. **Funkce aktualizace**: Aktualizace reprezentací uzlů na základě agregovaných zpráv

Tento proces je typicky prováděn v několika kolech (vrstvách), což umožňuje šíření informací skrz graf.

```python
# Implementace obecné vrstvy pro předávání zpráv
class MessagePassingLayer(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(MessagePassingLayer, self).__init__()
        self.message_fn = nn.Linear(in_channels * 2, out_channels)  # Funkce zpráv
        self.update_fn = nn.Linear(in_channels + out_channels, out_channels)  # Funkce aktualizace
        
    def forward(self, x, edge_index):
        # x: Příznaky uzlů [počet_uzlů, in_channels]
        # edge_index: Konektivita grafu [2, počet_hran]
        
        num_nodes = x.size(0)
        
        # Krok 1: Generování zpráv
        source_nodes, target_nodes = edge_index
        source_features = x[source_nodes]
        target_features = x[target_nodes]
        edge_features = torch.cat([source_features, target_features], dim=1)
        messages = F.relu(self.message_fn(edge_features))
        
        # Krok 2: Agregace zpráv (suma)
        aggregated_messages = torch.zeros(num_nodes, messages.size(1)).to(x.device)
        aggregated_messages.index_add_(0, target_nodes, messages)
        
        # Krok 3: Aktualizace příznaků uzlů
        combined = torch.cat([x, aggregated_messages], dim=1)
        updated_features = F.relu(self.update_fn(combined))
        
        return updated_features
```

PyTorch Geometric (PyG) je knihovna postavená na PyTorch pro snadnou implementaci grafových neuronových sítí. Poskytuje mnoho vestavěných vrstev GNN, datasetů a nástrojů pro práci s grafovými daty.

```python
# Definice grafové konvoluční sítě
class GCN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
        
    def forward(self, x, edge_index):
        # První grafová konvoluce
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        
        # Druhá grafová konvoluce
        x = self.conv2(x, edge_index)
        
        return x

# Definice grafové pozornostní sítě
class GAT(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, heads=8):
        super(GAT, self).__init__()
        self.conv1 = GATConv(in_channels, hidden_channels, heads=heads)
        self.conv2 = GATConv(hidden_channels * heads, out_channels)
        
    def forward(self, x, edge_index):
        # První vrstva grafové pozornosti
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.6, training=self.training)
        
        # Druhá vrstva grafové pozornosti
        x = self.conv2(x, edge_index)
        
        return x
```

## Úlohy klasifikace uzlů

Jednou z primárních aplikací GNN je klasifikace uzlů, kde cílem je předpovědět štítky uzlů v grafu. Například v citační síti můžeme chtít předpovědět výzkumnou kategorii každého článku.

```python
# Kompletní příklad klasifikace uzlů s GCN
import torch
import torch.nn.functional as F
from torch_geometric.nn import GCNConv
from torch_geometric.datasets import Planetoid
import matplotlib.pyplot as plt

# Načtení datasetu
dataset = Planetoid(root='./data/Cora', name='Cora')
data = dataset[0]

# Definice modelu GCN
class GCN(torch.nn.Module):
    def __init__(self):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(dataset.num_features, 16)
        self.conv2 = GCNConv(16, dataset.num_classes)

    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)

# Inicializace modelu, optimalizátoru
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCN().to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

# Trénovací funkce
def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    return loss.item()

# Hodnotící funkce
def test():
    model.eval()
    logits, accs = model(data.x, data.edge_index), []
    for _, mask in data('train_mask', 'val_mask', 'test_mask'):
        pred = logits[mask].max(1)[1]
        acc = pred.eq(data.y[mask]).sum().item() / mask.sum().item()
        accs.append(acc)
    return accs

# Trénovací smyčka
best_val_acc = 0
train_losses = []
for epoch in range(200):
    loss = train()
    train_losses.append(loss)
    train_acc, val_acc, test_acc = test()
    if val_acc > best_val_acc:
        best_val_acc = val_acc
        best_test_acc = test_acc
    
    if epoch % 20 == 0:
        print(f'Epocha: {epoch}, Ztráta: {loss:.4f}, Trénink: {train_acc:.4f}, '
              f'Validace: {val_acc:.4f}, Test: {test_acc:.4f}')

print(f'Nejlepší validační přesnost: {best_val_acc:.4f}')
print(f'Testovací přesnost: {best_test_acc:.4f}')

# Vykreslení trénovací ztráty
plt.figure(figsize=(8, 6))
plt.plot(train_losses)
plt.xlabel('Epocha')
plt.ylabel('Ztráta')
plt.title('Trénovací ztráta')
plt.show()

# Vizualizace embeddingů uzlů pomocí t-SNE
from sklearn.manifold import TSNE

model.eval()
with torch.no_grad():
    embeds = model.conv1(data.x, data.edge_index).cpu().numpy()

# Provedení redukce dimenzionality t-SNE
tsne = TSNE(n_components=2, random_state=42)
node_embeddings = tsne.fit_transform(embeds)

# Vykreslení embeddingů
plt.figure(figsize=(10, 8))
scatter = plt.scatter(node_embeddings[:, 0], node_embeddings[:, 1], 
                     c=data.y.cpu().numpy(), cmap='rainbow', alpha=0.7, s=50)
plt.colorbar(scatter)
plt.title('t-SNE vizualizace embeddingů uzlů')
plt.show()
```

## Úlohy klasifikace grafů

Klasifikace grafů zahrnuje předpovídání vlastností celých grafů spíše než jednotlivých uzlů. Příklady zahrnují předpovídání vlastností molekul (např. toxicity nebo rozpustnosti) nebo klasifikaci funkce proteinů.

```python
# Klasifikace grafů s PyTorch Geometric
import torch
from torch.nn import Linear
import torch.nn.functional as F
from torch_geometric.nn import GCNConv, global_mean_pool
from torch_geometric.datasets import TUDataset
from torch_geometric.loader import DataLoader

# Načtení molekulárního datasetu (MUTAG)
dataset = TUDataset(root='./data/TUDataset', name='MUTAG')

# Rozdělení datasetu
torch.manual_seed(42)
dataset = dataset.shuffle()
train_dataset = dataset[:150]
test_dataset = dataset[150:]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

print(f"Dataset: {dataset}:")
print(f"Počet grafů: {len(dataset)}")
print(f"Počet příznaků: {dataset.num_features}")
print(f"Počet tříd: {dataset.num_classes}")
print(f"Průměrný počet uzlů na graf: {sum(data.num_nodes for data in dataset) / len(dataset):.2f}")

# Definice modelu pro klasifikaci grafů
class GCNGraph(torch.nn.Module):
    def __init__(self):
        super(GCNGraph, self).__init__()
        self.conv1 = GCNConv(dataset.num_features, 32)
        self.conv2 = GCNConv(32, 64)
        self.lin = Linear(64, dataset.num_classes)
        
    def forward(self, x, edge_index, batch):
        # Extrakce příznaků uzlů
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        
        # Readout: pooling na úrovni grafu
        x = global_mean_pool(x, batch)  # [batch_size, hidden_channels]
        
        # Finální klasifikátor
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.lin(x)
        return x

# Inicializace modelu, optimalizátoru
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCNGraph().to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

def train():
    model.train()
    total_loss = 0
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = F.cross_entropy(out, data.y)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * data.num_graphs
    return total_loss / len(train_dataset)

def test(loader):
    model.eval()
    correct = 0
    for data in loader:
        data = data.to(device)
        out = model(data.x, data.edge_index, data.batch)
        pred = out.argmax(dim=1)
        correct += int((pred == data.y).sum())
    return correct / len(loader.dataset)

# Trénovací smyčka
for epoch in range(1, 101):
    loss = train()
    train_acc = test(train_loader)
    test_acc = test(test_loader)
    if epoch % 10 == 0:
        print(f'Epocha: {epoch:03d}, Ztráta: {loss:.4f}, '
              f'Trénovací přesnost: {train_acc:.4f}, Testovací přesnost: {test_acc:.4f}')
```

## Predikce spojení pomocí GNN

Predikce spojení se zaměřuje na předpověď chybějících spojení nebo budoucích spojení v grafu. To je užitečné pro doporučovací systémy, doplňování znalostních grafů a předpovídání proteinových interakcí.

```python
# Predikce spojení s GNN
import torch
from torch_geometric.nn import GCNConv
from torch_geometric.utils import train_test_split_edges, negative_sampling
from torch_geometric.datasets import Planetoid
import torch.nn.functional as F

# Načtení datasetu
dataset = Planetoid(root='./data/Cora', name='Cora')
data = dataset[0]

# Rozdělení hran pro trénování, validaci a testování
data = train_test_split_edges(data)

# Definice modelu pro predikci spojení
class LinkPredictionGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(LinkPredictionGNN, self).__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
    
    def encode(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        x = self.conv2(x, edge_index)
        return x
    
    def decode(self, z, edge_index):
        # Skalární součin mezi embeddingy uzlů pro předpověď spojení
        row, col = edge_index
        return (z[row] * z[col]).sum(dim=1)
    
    def decode_all(self, z):
        # Výpočet párových vzdáleností mezi všemi embeddingy uzlů
        prob_adj = torch.matmul(z, z.t())
        return prob_adj

# Inicializace modelu, optimalizátoru
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = LinkPredictionGNN(dataset.num_features, 128, 64).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
data = data.to(device)

def get_link_labels(pos_edge_index, neg_edge_index):
    # Štítky spojení: pozitivní spojení jsou 1, negativní jsou 0
    E = pos_edge_index.size(1) + neg_edge_index.size(1)
    link_labels = torch.zeros(E, dtype=torch.float, device=device)
    link_labels[:pos_edge_index.size(1)] = 1.
    return link_labels

def train():
    model.train()
    optimizer.zero_grad()
    
    # Embeddingy uzlů
    z = model.encode(data.x, data.train_pos_edge_index)
    
    # Vzorkování negativních hran
    neg_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=data.train_pos_edge_index.size(1))
    
    edge_index = torch.cat([data.train_pos_edge_index, neg_edge_index], dim=-1)
    link_logits = model.decode(z, edge_index)
    link_labels = get_link_labels(data.train_pos_edge_index, neg_edge_index)
    
    loss = F.binary_cross_entropy_with_logits(link_logits, link_labels)
    loss.backward()
    optimizer.step()
    
    return loss

@torch.no_grad()
def test():
    model.eval()
    z = model.encode(data.x, data.train_pos_edge_index)
    
    results = []
    for prefix in ['val', 'test']:
        pos_edge_index = data[f'{prefix}_pos_edge_index']
        neg_edge_index = data[f'{prefix}_neg_edge_index']
        edge_index = torch.cat([pos_edge_index, neg_edge_index], dim=-1)
        link_logits = model.decode(z, edge_index)
        link_probs = link_logits.sigmoid()
        link_labels = get_link_labels(pos_edge_index, neg_edge_index)
        
        # Výpočet AUC skóre
        from sklearn.metrics import roc_auc_score
        results.append(roc_auc_score(link_labels.cpu(), link_probs.cpu()))
    
    return results

# Trénovací smyčka
best_val_auc = 0
for epoch in range(1, 101):
    loss = train()
    val_auc, test_auc = test()
    if val_auc > best_val_auc:
        best_val_auc = val_auc
        best_test_auc = test_auc
    if epoch % 10 == 0:
        print(f'Epocha: {epoch:03d}, Ztráta: {loss:.4f}, '
              f'Validační AUC: {val_auc:.4f}, Testovací AUC: {test_auc:.4f}')

print(f'Nejlepší validační AUC: {best_val_auc:.4f}')
print(f'Testovací AUC: {best_test_auc:.4f}')
```

## Praktické aplikace GNN

Grafové neuronové sítě našly uplatnění napříč mnoha oblastmi:

### Chemie a objevování léčiv

GNN se používají k předpovídání vlastností molekul, designu nových molekul a urychlení objevování léčiv modelováním grafové struktury molekul.

### Analýza sociálních sítí

GNN pomáhají analyzovat interakce uživatelů, detekovat komunity a předpovídat budoucí spojení v sociálních sítích.

### Doporučovací systémy

Grafové doporučovací systémy používají GNN k modelování interakcí mezi uživateli a položkami a poskytování personalizovaných doporučení.

### Počítačové vidění

GNN mohou být aplikovány na generování grafů scén, zpracování bodových mračen a klasifikaci obrázků reprezentací vizuálních dat jako grafů.

### Zpracování přirozeného jazyka

Text může být reprezentován jako grafy (např. syntaktické nebo sémantické závislosti), což umožňuje GNN vylepšovat různé úlohy NLP.

```python
# Příklad: Predikce vlastností molekul pomocí GNN
from torch_geometric.datasets import MoleculeNet
from torch_geometric.nn import GCNConv, global_add_pool
import torch.nn.functional as F
import torch

# Načtení molekulárního datasetu pro predikci vlastností
dataset = MoleculeNet(root='./data/MoleculeNet', name='ESOL')
print(f"Dataset: {dataset}")
print(f"Počet grafů: {len(dataset)}")
print(f"Počet příznaků: {dataset.num_features}")
print(f"Počet úloh: {dataset.num_tasks}")

# Rozdělení datasetu
train_dataset = dataset[:1128]
val_dataset = dataset[1128:1288]
test_dataset = dataset[1288:]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

# Definice GNN modelu pro regresi
class MoleculeGNN(torch.nn.Module):
    def __init__(self):
        super(MoleculeGNN, self).__init__()
        self.conv1 = GCNConv(dataset.num_features, 64)
        self.conv2 = GCNConv(64, 64)
        self.conv3 = GCNConv(64, 64)
        self.lin = Linear(64, dataset.num_tasks)
        
    def forward(self, x, edge_index, batch):
        # Embedding uzlů
        x = F.relu(self.conv1(x, edge_index))
        x = F.relu(self.conv2(x, edge_index))
        x = self.conv3(x, edge_index)
        
        # Pooling grafu
        x = global_add_pool(x, batch)
        
        # Predikční hlavička
        x = self.lin(x)
        return x

# Inicializace modelu, optimalizátoru
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = MoleculeGNN().to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# Ztrátová funkce střední kvadratické chyby pro regresi
loss_fn = torch.nn.MSELoss()

def train():
    model.train()
    total_loss = 0
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = loss_fn(out, data.y)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * data.num_graphs
    return total_loss / len(train_loader.dataset)

def evaluate(loader):
    model.eval()
    total_error = 0
    with torch.no_grad():
        for data in loader:
            data = data.to(device)
            out = model(data.x, data.edge_index, data.batch)
            total_error += F.mse_loss(out, data.y).item() * data.num_graphs
    return total_error / len(loader.dataset)

# Trénovací smyčka
best_val_error = float('inf')
for epoch in range(1, 101):
    loss = train()
    val_error = evaluate(val_loader)
    if val_error < best_val_error:
        best_val_error = val_error
        test_error = evaluate(test_loader)
    if epoch % 10 == 0:
        print(f'Epocha: {epoch:03d}, Ztráta: {loss:.4f}, '
              f'Validační chyba: {val_error:.4f}, Testovací chyba: {test_error:.4f}')

print(f'Nejlepší validační chyba: {best_val_error:.4f}')
print(f'Testovací chyba: {test_error:.4f}')
```

## Shrnutí a budoucí směry

Grafové neuronové sítě poskytují výkonný rámec pro učení z dat strukturovaných jako grafy, což umožňuje pokročilé aplikace napříč mnoha oblastmi. Klíčové poznatky:

1. GNN využívají grafovou strukturu k učení reprezentací uzlů, hran a úrovně celého grafu
2. Základním mechanismem za GNN je předávání zpráv mezi uzly
3. Existuje několik typů GNN, včetně GCN, GAT, GraphSAGE a GIN
4. Běžné aplikace zahrnují klasifikaci uzlů, klasifikaci grafů a predikci spojení
5. PyTorch Geometric poskytuje vhodný rámec pro implementaci GNN

Budoucí směry výzkumu v oblasti GNN zahrnují:

- **Škálovatelnost**: Zvládání extrémně velkých grafů
- **Expresivita**: Vývoj výkonnějších architektur GNN
- **Vysvětlitelnost**: Porozumění tomu, proč GNN dělají konkrétní predikce
- **Dynamické grafy**: Lepší modelování grafů, které se vyvíjejí v čase
- **Integrace s dalšími modely**: Kombinování GNN s transformery, posilovaným učením atd.

S tím, jak se oblast vyvíjí, budou grafové neuronové sítě nepochybně hrát stále důležitější roli v aplikacích strojového učení zahrnujících strukturovaná data.
