## 1. Introduction to Feature Selection

Feature selection is the process of selecting a subset of relevant features (variables, predictors) to use in model building. It aims to reduce dimensionality, decrease training time, avoid overfitting, and improve model performance by removing irrelevant, redundant, or noisy features.

```python
# Import essential libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score
from sklearn.feature_selection import SelectKBest, f_classif, RFE, SelectFromModel
from sklearn.pipeline import Pipeline

# Load a dataset to demonstrate feature selection
data = load_breast_cancer()
X = pd.DataFrame(data.data, columns=data.feature_names)
y = data.target

print(f"Original dataset shape: {X.shape}")
print(f"Number of features: {X.shape[1]}")
print(f"Feature names: {data.feature_names[:5]}...")  # Showing first 5 features
```

The need for feature selection typically arises from:
- Datasets with a large number of features
- Features that may be irrelevant to the target variable
- Redundant features that provide similar information
- The "curse of dimensionality" which affects model performance

## 2. Filter Methods

Filter methods evaluate features independently of any machine learning algorithm. They use statistical tests or metrics to score and rank each feature according to its relationship with the target variable.

### Univariate Feature Selection

```python
# Using correlation for feature selection
plt.figure(figsize=(12, 10))
correlation_matrix = X.corr()
sns.heatmap(correlation_matrix, annot=False, cmap='coolwarm')
plt.title('Correlation Matrix of Features')
plt.tight_layout()
plt.show()

# Select highly correlated features with the target
def correlation_selector(X, y, num_feats):
    # Calculate correlation between features and target
    cor_list = []
    feature_names = X.columns.tolist()
    # Calculate correlation
    for i in feature_names:
        cor = np.corrcoef(X[i], y)[0, 1]
        cor_list.append(cor)
    # Create feature-correlation dataframe
    cor_feature = pd.DataFrame(
        {'feature': feature_names, 'correlation': cor_list})
    cor_feature = cor_feature.sort_values(by=['correlation'], ascending=False)
    # Select top features
    selected_features = cor_feature['feature'][:num_feats].tolist()
    
    return selected_features

# Select top 10 features based on correlation
selected_features = correlation_selector(X, y, 10)
print("Top 10 features based on correlation:")
print(selected_features)

# Using SelectKBest with f_classif (ANOVA F-statistic)
selector = SelectKBest(f_classif, k=10)
X_new = selector.fit_transform(X, y)

# Get selected feature names
mask = selector.get_support()
selected_features_f = X.columns[mask]
print("\nFeatures selected by SelectKBest:")
print(selected_features_f)
print(f"New dataset shape: {X_new.shape}")

# Visualize feature scores
plt.figure(figsize=(12, 6))
plt.bar(X.columns[mask], selector.scores_[mask])
plt.xticks(rotation=90)
plt.title('Feature Scores from SelectKBest')
plt.tight_layout()
plt.show()
```

Other common filter methods include:
- Chi-squared test (for categorical features)
- Information gain
- Mutual information
- Fisher's score
- Variance threshold (removing features with low variance)

## 3. Wrapper Methods

Wrapper methods use a predictive model to evaluate feature subsets. They train a new model for each subset and select features based on model performance.

### Recursive Feature Elimination (RFE)

```python
# Recursive Feature Elimination with a logistic regression model
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Scale features
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# Create and configure RFE
model = LogisticRegression(max_iter=1000, solver='liblinear')
rfe = RFE(estimator=model, n_features_to_select=10, step=1)

# Fit RFE
rfe.fit(X_train_scaled, y_train)

# Get selected features
selected_features_rfe = X_train.columns[rfe.support_]
print("Features selected by RFE:")
print(selected_features_rfe)

# Train a model with selected features
X_train_rfe = X_train_scaled[:, rfe.support_]
X_test_rfe = X_test_scaled[:, rfe.support_]

model.fit(X_train_rfe, y_train)
y_pred = model.predict(X_test_rfe)
print(f"Model accuracy with RFE selected features: {accuracy_score(y_test, y_pred):.4f}")

# Visualize RFE feature ranking
plt.figure(figsize=(12, 6))
plt.bar(X.columns, rfe.ranking_)
plt.xticks(rotation=90)
plt.title('Feature Ranking from RFE (lower is better)')
plt.tight_layout()
plt.show()
```

### Forward and Backward Selection

```python
from sklearn.feature_selection import SequentialFeatureSelector

# Forward Selection
forward_selector = SequentialFeatureSelector(
    model, n_features_to_select=10, direction='forward', scoring='accuracy'
)
forward_selector.fit(X_train_scaled, y_train)

# Get selected features
forward_features = X_train.columns[forward_selector.get_support()]
print("Features selected by Forward Selection:")
print(forward_features)

# Backward Selection
backward_selector = SequentialFeatureSelector(
    model, n_features_to_select=10, direction='backward', scoring='accuracy'
)
backward_selector.fit(X_train_scaled, y_train)

# Get selected features
backward_features = X_train.columns[backward_selector.get_support()]
print("Features selected by Backward Selection:")
print(backward_features)

# Compare performance
X_train_fwd = forward_selector.transform(X_train_scaled)
X_test_fwd = forward_selector.transform(X_test_scaled)
model.fit(X_train_fwd, y_train)
fwd_accuracy = accuracy_score(y_test, model.predict(X_test_fwd))

X_train_bwd = backward_selector.transform(X_train_scaled)
X_test_bwd = backward_selector.transform(X_test_scaled)
model.fit(X_train_bwd, y_train)
bwd_accuracy = accuracy_score(y_test, model.predict(X_test_bwd))

print(f"Forward Selection Accuracy: {fwd_accuracy:.4f}")
print(f"Backward Selection Accuracy: {bwd_accuracy:.4f}")
```

## 4. Embedded Methods

Embedded methods perform feature selection during the model training process. They incorporate feature selection as part of the model building process.

### Lasso Regression (L1 Regularization)

```python
from sklearn.linear_model import Lasso, LogisticRegression

# Lasso for feature selection in regression
lasso = Lasso(alpha=0.01)
lasso.fit(X_train_scaled, y_train)

# Get feature importance
feature_importance = np.abs(lasso.coef_)
feature_names = X.columns

# Create DataFrame for visualization
lasso_feature_importance = pd.DataFrame(
    {'Feature': feature_names, 'Importance': feature_importance})
lasso_feature_importance = lasso_feature_importance.sort_values(
    by='Importance', ascending=False)

# Visualize feature importance
plt.figure(figsize=(12, 6))
plt.bar(lasso_feature_importance['Feature'][:15], 
        lasso_feature_importance['Importance'][:15])
plt.xticks(rotation=90)
plt.title('Feature Importance from Lasso Regression')
plt.tight_layout()
plt.show()

# For classification, use L1 regularization with logistic regression
logreg_l1 = LogisticRegression(penalty='l1', solver='liblinear', C=0.1)
logreg_l1.fit(X_train_scaled, y_train)

# Get feature importance
feature_importance_logreg = np.abs(logreg_l1.coef_[0])

# Create DataFrame for visualization
logreg_feature_importance = pd.DataFrame(
    {'Feature': feature_names, 'Importance': feature_importance_logreg})
logreg_feature_importance = logreg_feature_importance.sort_values(
    by='Importance', ascending=False)

# Visualize feature importance
plt.figure(figsize=(12, 6))
plt.bar(logreg_feature_importance['Feature'][:15], 
        logreg_feature_importance['Importance'][:15])
plt.xticks(rotation=90)
plt.title('Feature Importance from Logistic Regression (L1)')
plt.tight_layout()
plt.show()
```

### Tree-Based Feature Selection

```python
# Random Forest feature importance
rf = RandomForestClassifier(n_estimators=100, random_state=42)
rf.fit(X_train_scaled, y_train)

# Get feature importance
feature_importance_rf = rf.feature_importances_

# Create DataFrame for visualization
rf_feature_importance = pd.DataFrame(
    {'Feature': feature_names, 'Importance': feature_importance_rf})
rf_feature_importance = rf_feature_importance.sort_values(
    by='Importance', ascending=False)

# Visualize feature importance
plt.figure(figsize=(12, 6))
plt.bar(rf_feature_importance['Feature'][:15], 
        rf_feature_importance['Importance'][:15])
plt.xticks(rotation=90)
plt.title('Feature Importance from Random Forest')
plt.tight_layout()
plt.show()

# Select features based on importance threshold
selector = SelectFromModel(rf, threshold='median')
selector.fit(X_train_scaled, y_train)

# Get selected features
selected_features_rf = X_train.columns[selector.get_support()]
print("Features selected by Random Forest importance:")
print(selected_features_rf)

# Test performance with selected features
X_train_rf = selector.transform(X_train_scaled)
X_test_rf = selector.transform(X_test_scaled)

rf.fit(X_train_rf, y_train)
y_pred_rf = rf.predict(X_test_rf)
print(f"Model accuracy with RF selected features: {accuracy_score(y_test, y_pred_rf):.4f}")
```

## 5. Dimensionality Reduction vs. Feature Selection

While feature selection selects a subset of original features, dimensionality reduction creates new features that are transformations of the original ones.

```python
from sklearn.decomposition import PCA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis as LDA

# PCA for dimensionality reduction
pca = PCA(n_components=10)
X_train_pca = pca.fit_transform(X_train_scaled)
X_test_pca = pca.transform(X_test_scaled)

# Explained variance ratio
plt.figure(figsize=(10, 6))
plt.plot(np.cumsum(pca.explained_variance_ratio_), marker='o')
plt.xlabel('Number of Components')
plt.ylabel('Cumulative Explained Variance')
plt.axhline(y=0.95, color='r', linestyle='-')
plt.title('PCA - Explained Variance')
plt.grid(True)
plt.show()

print(f"Number of components needed for 95% variance: {np.argmax(np.cumsum(pca.explained_variance_ratio_) >= 0.95) + 1}")

# LDA for supervised dimensionality reduction
lda = LDA(n_components=1)  # Binary classification, so max 1 component
X_train_lda = lda.fit_transform(X_train_scaled, y_train)
X_test_lda = lda.transform(X_test_scaled)

# Train models and compare performance
models = {
    "Original Features": (X_train_scaled, X_test_scaled),
    "PCA Features": (X_train_pca, X_test_pca),
    "LDA Features": (X_train_lda, X_test_lda.reshape(-1, 1))
}

results = []
for name, (X_tr, X_te) in models.items():
    model = LogisticRegression(max_iter=1000)
    model.fit(X_tr, y_train)
    accuracy = accuracy_score(y_test, model.predict(X_te))
    results.append({"Method": name, "Accuracy": accuracy, "Features": X_tr.shape[1]})
    
results_df = pd.DataFrame(results)
print(results_df)

# Plot comparison
plt.figure(figsize=(10, 6))
sns.barplot(x='Method', y='Accuracy', data=results_df)
plt.title('Model Performance Comparison')
plt.ylim(0.9, 1.0)  # Adjust as needed
plt.tight_layout()
plt.show()
```

## 6. Feature Selection with scikit-learn

Scikit-learn provides a comprehensive suite of tools for feature selection that can be integrated into machine learning pipelines.

```python
# Building a pipeline with feature selection
from sklearn.pipeline import Pipeline
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV

# Create a pipeline with feature selection and a classifier
pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('feature_selection', SelectKBest(f_classif)),
    ('classifier', RandomForestClassifier(random_state=42))
])

# Define a parameter grid for tuning
param_grid = {
    'feature_selection__k': [5, 10, 15, 20],
    'classifier__n_estimators': [50, 100],
    'classifier__max_depth': [None, 10, 20]
}

# Grid search for the best parameters
grid_search = GridSearchCV(
    pipeline, param_grid, cv=5, scoring='accuracy', verbose=1, n_jobs=-1
)
grid_search.fit(X_train, y_train)

# Best parameters and score
print(f"Best parameters: {grid_search.best_params_}")
print(f"Best CV score: {grid_search.best_score_:.4f}")

# Evaluate on test set
y_pred_pipeline = grid_search.predict(X_test)
print(f"Test accuracy: {accuracy_score(y_test, y_pred_pipeline):.4f}")

# Get the best number of features
best_k = grid_search.best_params_['feature_selection__k']
print(f"Optimal number of features: {best_k}")

# Get the selected features
best_pipeline = grid_search.best_estimator_
feature_selector = best_pipeline.named_steps['feature_selection']
selected_indices = feature_selector.get_support()
selected_features = X.columns[selected_indices]
print(f"Selected features: {selected_features}")
```

## 7. Feature Selection for Different Models

Different models may benefit from different feature selection approaches. Here's how to select features for various algorithms:

```python
from sklearn.svm import SVC
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier

# Define different models
models = {
    'Logistic Regression': LogisticRegression(max_iter=1000),
    'Random Forest': RandomForestClassifier(random_state=42),
    'SVM': SVC(probability=True),
    'KNN': KNeighborsClassifier(),
    'Decision Tree': DecisionTreeClassifier(random_state=42)
}

# Feature selection methods
feature_selectors = {
    'Filter (SelectKBest)': SelectKBest(f_classif, k=10),
    'Wrapper (RFE)': RFE(estimator=LogisticRegression(max_iter=1000), n_features_to_select=10),
    'Embedded (Random Forest)': SelectFromModel(RandomForestClassifier(random_state=42))
}

# Test each combination
results = []

for model_name, model in models.items():
    # Baseline (no feature selection)
    model.fit(X_train_scaled, y_train)
    baseline_accuracy = accuracy_score(y_test, model.predict(X_test_scaled))
    results.append({
        'Model': model_name,
        'Selection Method': 'None (Baseline)',
        'Accuracy': baseline_accuracy,
        'Features': X_train_scaled.shape[1]
    })
    
    # Test each feature selection method
    for selector_name, selector in feature_selectors.items():
        selector.fit(X_train_scaled, y_train)
        X_train_selected = selector.transform(X_train_scaled)
        X_test_selected = selector.transform(X_test_scaled)
        
        model.fit(X_train_selected, y_train)
        accuracy = accuracy_score(y_test, model.predict(X_test_selected))
        
        results.append({
            'Model': model_name,
            'Selection Method': selector_name,
            'Accuracy': accuracy,
            'Features': X_train_selected.shape[1]
        })

# Convert results to DataFrame for analysis
results_df = pd.DataFrame(results)
print(results_df)

# Visualize results
plt.figure(figsize=(15, 10))
sns.barplot(x='Model', y='Accuracy', hue='Selection Method', data=results_df)
plt.title('Model Performance with Different Feature Selection Methods')
plt.ylim(0.9, 1.0)  # Adjust as needed
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

## 8. Evaluating Feature Selection Impact

It's important to evaluate how feature selection affects model performance across different metrics:

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score
from sklearn.model_selection import cross_val_score

# Define evaluation function
def evaluate_model(model, X_train, X_test, y_train, y_test):
    # Train model
    model.fit(X_train, y_train)
    
    # Predict
    y_pred = model.predict(X_test)
    
    # Calculate metrics
    accuracy = accuracy_score(y_test, y_pred)
    precision = precision_score(y_test, y_pred)
    recall = recall_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred)
    
    # For ROC AUC, we need probability predictions
    if hasattr(model, "predict_proba"):
        y_pred_proba = model.predict_proba(X_test)[:, 1]
        roc_auc = roc_auc_score(y_test, y_pred_proba)
    else:
        roc_auc = None
        
    # Cross-validation score
    cv_scores = cross_val_score(model, X_train, y_train, cv=5, scoring='accuracy')
    cv_mean = cv_scores.mean()
    cv_std = cv_scores.std()
    
    return {
        'Accuracy': accuracy,
        'Precision': precision,
        'Recall': recall,
        'F1 Score': f1,
        'ROC AUC': roc_auc,
        'CV Mean': cv_mean,
        'CV Std': cv_std
    }

# Base model without feature selection
base_model = RandomForestClassifier(random_state=42)
base_results = evaluate_model(base_model, X_train_scaled, X_test_scaled, y_train, y_test)

# Model with SelectKBest
kbest_selector = SelectKBest(f_classif, k=10)
X_train_kbest = kbest_selector.fit_transform(X_train_scaled, y_train)
X_test_kbest = kbest_selector.transform(X_test_scaled)
kbest_model = RandomForestClassifier(random_state=42)
kbest_results = evaluate_model(kbest_model, X_train_kbest, X_test_kbest, y_train, y_test)

# Model with RFE
rfe_selector = RFE(estimator=LogisticRegression(max_iter=1000), n_features_to_select=10)
X_train_rfe = rfe_selector.fit_transform(X_train_scaled, y_train)
X_test_rfe = rfe_selector.transform(X_test_scaled)
rfe_model = RandomForestClassifier(random_state=42)
rfe_results = evaluate_model(rfe_model, X_train_rfe, X_test_rfe, y_train, y_test)

# Compile results
all_results = pd.DataFrame({
    'No Selection': base_results,
    'SelectKBest': kbest_results,
    'RFE': rfe_results
})

print(all_results.T)

# Visualize comparison
plt.figure(figsize=(14, 10))
for i, metric in enumerate(['Accuracy', 'Precision', 'Recall', 'F1 Score', 'ROC AUC']):
    plt.subplot(2, 3, i+1)
    
    if metric in all_results.columns:
        values = [all_results[metric]['No Selection'], 
                  all_results[metric]['SelectKBest'], 
                  all_results[metric]['RFE']]
        
        plt.bar(['No Selection', 'SelectKBest', 'RFE'], values)
        plt.title(f'{metric} Comparison')
        plt.ylim(0.9, 1.0)  # Adjust as needed

plt.tight_layout()
plt.show()

# Training time comparison
import time

methods = ['No Selection', 'SelectKBest', 'RFE', 'Random Forest Importance']
times = []
n_features = []

# Time for no selection
start = time.time()
model = RandomForestClassifier(random_state=42)
model.fit(X_train_scaled, y_train)
times.append(time.time() - start)
n_features.append(X_train_scaled.shape[1])

# Time for SelectKBest
start = time.time()
selector = SelectKBest(f_classif, k=10)
X_train_selected = selector.fit_transform(X_train_scaled, y_train)
model = RandomForestClassifier(random_state=42)
model.fit(X_train_selected, y_train)
times.append(time.time() - start)
n_features.append(X_train_selected.shape[1])

# Time for RFE
start = time.time()
selector = RFE(estimator=LogisticRegression(max_iter=1000), n_features_to_select=10)
X_train_selected = selector.fit_transform(X_train_scaled, y_train)
model = RandomForestClassifier(random_state=42)
model.fit(X_train_selected, y_train)
times.append(time.time() - start)
n_features.append(X_train_selected.shape[1])

# Time for Random Forest Importance
start = time.time()
selector = SelectFromModel(RandomForestClassifier(random_state=42))
X_train_selected = selector.fit_transform(X_train_scaled, y_train)
model = RandomForestClassifier(random_state=42)
model.fit(X_train_selected, y_train)
times.append(time.time() - start)
n_features.append(X_train_selected.shape[1])

# Plot time comparison
plt.figure(figsize=(12, 6))
plt.subplot(1, 2, 1)
plt.bar(methods, times)
plt.title('Training Time Comparison')
plt.xticks(rotation=45)
plt.ylabel('Time (seconds)')
```

## 9. Summary

Feature selection is a crucial step in the machine learning pipeline that helps:

1. **Improve model performance** by removing irrelevant or redundant features
2. **Reduce overfitting** by decreasing model complexity
3. **Enhance interpretability** by focusing on the most important features
4. **Speed up training** by reducing dimensionality
5. **Lower computational costs** for both training and inference

Key feature selection approaches:

- **Filter methods**: Fast, model-agnostic techniques that select features based on statistical measures
- **Wrapper methods**: More computationally intensive but potentially more accurate as they use the model's performance to select features
- **Embedded methods**: Incorporate feature selection into the model training process

Best practices:

1. **Start with exploratory data analysis** to understand feature relationships
2. **Use multiple feature selection methods** and compare results
3. **Validate feature selection** with cross-validation
4. **Consider the domain knowledge** when interpreting selected features
5. **Balance model performance and interpretability** when choosing the number of features
