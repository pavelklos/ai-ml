## Úvod do GANs

Generativní adversariální sítě (GANs) představují revoluční přístup ke generativnímu modelování, který představil Ian Goodfellow a jeho kolegové v roce 2014. GANy se skládají ze dvou neuronových sítí, které spolu soutěží v tzv. hře s nulovým součtem, kde zisk jedné sítě je ztrátou druhé.

Klíčovou inovací GANů je adversariální proces tréninku, kde:

- **Generátor** se učí vytvářet data, která se podobají cílové distribuci
- **Diskriminátor** se učí rozlišovat mezi skutečnými daty a falešnými daty z generátoru
- Obě sítě se zlepšují prostřednictvím soutěže, což vede k generátoru, který produkuje stále realističtější výstupy

Na rozdíl od tradičních generativních modelů, GANy explicitně nemodelují pravděpodobnostní rozdělení dat. Místo toho se učí generovat vzorky, které jsou nerozlišitelné od reálných dat.

## Architektura GAN: Generátor a diskriminátor

Rámec GANu se skládá ze dvou odlišných neuronových sítí s různými rolemi:

### Generátor
- Přijímá náhodný šum (latentní vektor) jako vstup
- Mapuje šum do prostoru dat prostřednictvím série upsampling vrstev
- Cílem je produkovat výstupy nerozeznatelné od reálných dat
- Typicky používá transponované konvoluce nebo upsampling + konvoluční vrstvy

### Diskriminátor
- Přijímá data (reálná nebo generovaná) jako vstup
- Na výstupu vrací pravděpodobnost, že vstup pochází z reálných dat
- Funguje jako binární klasifikátor
- Typicky používá standardní konvoluční vrstvy pro obrazy

```python
# Definice jednoduché architektury GANu pro generování a rozlišování MNIST číslic

def build_generator(latent_dim):
    """Vytvořit síť generátoru"""
    model = models.Sequential(name="Generator")
    
    # První plně propojená vrstva
    model.add(layers.Dense(7*7*256, use_bias=False, input_shape=(latent_dim,)))
    model.add(layers.BatchNormalization())
    model.add(layers.LeakyReLU(alpha=0.2))
    
    # Přetvarování pro začátek konvoluční sekvence
    model.add(layers.Reshape((7, 7, 256)))
    
    # První upsampling blok
    model.add(layers.Conv2DTranspose(128, (5, 5), strides=(1, 1), padding='same', use_bias=False))
    model.add(layers.BatchNormalization())
    model.add(layers.LeakyReLU(alpha=0.2))
    
    # Druhý upsampling blok
    model.add(layers.Conv2DTranspose(64, (5, 5), strides=(2, 2), padding='same', use_bias=False))
    model.add(layers.BatchNormalization())
    model.add(layers.LeakyReLU(alpha=0.2))
    
    # Výstupní vrstva s tanh aktivací
    model.add(layers.Conv2DTranspose(1, (5, 5), strides=(2, 2), padding='same', use_bias=False, 
                                    activation='tanh'))
    
    return model

def build_discriminator():
    """Vytvořit síť diskriminátoru"""
    model = models.Sequential(name="Discriminator")
    
    # První konvoluční vrstva
    model.add(layers.Conv2D(64, (5, 5), strides=(2, 2), padding='same', 
                           input_shape=[28, 28, 1]))
    model.add(layers.LeakyReLU(alpha=0.2))
    model.add(layers.Dropout(0.3))
    
    # Druhá konvoluční vrstva
    model.add(layers.Conv2D(128, (5, 5), strides=(2, 2), padding='same'))
    model.add(layers.LeakyReLU(alpha=0.2))
    model.add(layers.Dropout(0.3))
    
    # Flatten a výstupní vrstva
    model.add(layers.Flatten())
    model.add(layers.Dense(1))  # Binární klasifikace (reálný/falešný)
    
    return model

# Vytvoření modelů
latent_dim = 100
generator = build_generator(latent_dim)
discriminator = build_discriminator()

# Výpis shrnutí modelů
print("Shrnutí modelu generátoru:")
generator.summary()

print("\nShrnutí modelu diskriminátoru:")
discriminator.summary()
```

## Ztrátové funkce a dynamika tréninku

Trénování GANu zahrnuje jedinečnou minimax hru mezi generátorem a diskriminátorem:

### Teoretický rámec
- Diskriminátor se snaží maximalizovat svou schopnost identifikovat reálné a falešné vzorky
- Generátor se snaží minimalizovat schopnost diskriminátoru identifikovat jeho falešné vzorky
- Tento adversariální proces je formulován jako minimax objektivní funkce:

$$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_z(z)}[\log (1 - D(G(z)))]$$

### Praktický proces tréninku
1. Trénování diskriminátoru na reálných a falešných datech (s fixními váhami generátoru)
2. Trénování generátoru, aby oklamal diskriminátor (s fixními váhami diskriminátoru)
3. Opakování tohoto procesu iterativně

```python
# Implementace ztrátových funkcí GANu a procesu tréninku
cross_entropy = tf.keras.losses.BinaryCrossentropy(from_logits=True)

def discriminator_loss(real_output, fake_output):
    """Výpočet ztráty diskriminátoru"""
    # Reálné vzorky by měly být klasifikovány jako 1
    real_loss = cross_entropy(tf.ones_like(real_output), real_output)
    
    # Falešné vzorky by měly být klasifikovány jako 0
    fake_loss = cross_entropy(tf.zeros_like(fake_output), fake_output)
    
    # Celková ztráta je součtem
    total_loss = real_loss + fake_loss
    return total_loss

def generator_loss(fake_output):
    """Výpočet ztráty generátoru"""
    # Generátor chce, aby falešné vzorky byly klasifikovány jako 1 (reálné)
    return cross_entropy(tf.ones_like(fake_output), fake_output)

# Definice optimalizátorů
generator_optimizer = tf.keras.optimizers.Adam(1e-4)
discriminator_optimizer = tf.keras.optimizers.Adam(1e-4)

# Funkce kroku trénování
@tf.function
def train_step(images, batch_size, latent_dim):
    # Generování náhodného šumu pro vstup generátoru
    noise = tf.random.normal([batch_size, latent_dim])
    
    with tf.GradientTape() as gen_tape, tf.GradientTape() as disc_tape:
        # Generování falešných obrázků
        generated_images = generator(noise, training=True)
        
        # Získání výstupů diskriminátoru pro reálné i falešné obrázky
        real_output = discriminator(images, training=True)
        fake_output = discriminator(generated_images, training=True)
        
        # Výpočet ztrát
        gen_loss = generator_loss(fake_output)
        disc_loss = discriminator_loss(real_output, fake_output)
    
    # Výpočet gradientů
    gradients_of_generator = gen_tape.gradient(gen_loss, generator.trainable_variables)
    gradients_of_discriminator = disc_tape.gradient(disc_loss, discriminator.trainable_variables)
    
    # Aplikace gradientů
    generator_optimizer.apply_gradients(zip(gradients_of_generator, generator.trainable_variables))
    discriminator_optimizer.apply_gradients(zip(gradients_of_discriminator, discriminator.trainable_variables))
    
    return gen_loss, disc_loss

# Funkce pro vizualizaci průběhu tréninku grafy
def plot_training_progress(g_losses, d_losses, epochs):
    plt.figure(figsize=(10, 6))
    plt.plot(range(1, epochs+1), g_losses, label='Ztráta generátoru')
    plt.plot(range(1, epochs+1), d_losses, label='Ztráta diskriminátoru')
    plt.title('Průběh tréninku')
    plt.xlabel('Epocha')
    plt.ylabel('Ztráta')
    plt.legend()
    plt.grid(alpha=0.3)
    plt.show()
```

Implementujme kompletní model GANu pro generování ručně psaných číslic podobných MNIST.

```python
@tf.function
def train_step(images):

    with tf.GradientTape() as gen_tape, tf.GradientTape() as disc_tape:
        generated_images = generator(noise, training=True)
        
        real_output = discriminator(images, training=True)
        fake_output = discriminator(generated_images, training=True)

    gradients_of_discriminator = disc_tape.gradient(disc_loss, discriminator.trainable_variables)
    
    generator_optimizer.apply_gradients(zip(gradients_of_generator, generator.trainable_variables))
    discriminator_optimizer.apply_gradients(zip(gradients_of_discriminator, discriminator.trainable_variables))

    fig = plt.figure(figsize=(8, 8))
    
    for i in range(16):
        plt.subplot(4, 4, i+1)
        plt.imshow(predictions[i, :, :, 0] * 0.5 + 0.5, cmap='gray')
        plt.axis('off')

    plt.savefig(f'image_at_epoch_{epoch:04d}.png')

    seed = tf.random.normal([16, LATENT_DIM])
    
    g_losses = []
    d_losses = []
    
    for epoch in range(epochs):
        start = time.time()
        
        epoch_g_loss = 0
        epoch_d_loss = 0
        num_batches = 0
        
        for image_batch in dataset:
            gen_loss, disc_loss = train_step(image_batch)
            epoch_g_loss += gen_loss
            epoch_d_loss += disc_loss
            num_batches += 1
        
        avg_g_loss = epoch_g_loss / num_batches
        avg_d_loss = epoch_d_loss / num_batches
        g_losses.append(avg_g_loss)
        d_losses.append(avg_d_loss)
            
        # Výpis postupu každou epochu

        # Generování a ukládání obrázků každých 10 epoch
        if (epoch + 1) % 10 == 0:
            generate_and_save_images(generator, epoch + 1, seed)
    
    # Vykreslení křivek ztrát
    plot_training_progress(g_losses, d_losses, epochs)
    
    # Generování finálních obrázků
    generate_and_save_images(generator, epochs, seed)
```

## Běžné výzvy GANů a jejich řešení

GANy jsou notoricky obtížné na trénování kvůli několika výzvám:

### Zhroucení módu (Mode Collapse)
**Problém**: Generátor produkuje omezené varianty vzorků
**Řešení**:
- Minibatch diskriminace
- Wasserstein GAN (WGAN)
- Unrolled GANy

### Nestabilita tréninku
**Problém**: Oscilace a selhání konvergence
**Řešení**:
- Feature matching
- Historické průměrování
- Penalizace gradientu (WGAN-GP)
- Spektrální normalizace

### Mizející gradienty
**Problém**: Diskriminátor se stává příliš dobrým, neposkytuje užitečný gradient
**Řešení**:
- Vyhlazování labelů
- Různé ztrátové funkce (např. least squares)
- Pravidlo aktualizace se dvěma časovými měřítky (TTUR)

```python
# Implementace Wasserstein GANu s penalizací gradientu (WGAN-GP)
# Populární řešení pro nestabilitu tréninku GANů

class WGAN_GP(tf.keras.Model):
    def __init__(self, discriminator, generator, latent_dim, gp_weight=10.0):
        super(WGAN_GP, self).__init__()
        self.discriminator = discriminator
        self.generator = generator
        self.latent_dim = latent_dim
        self.gp_weight = gp_weight
        
    def compile(self, d_optimizer, g_optimizer):
        super(WGAN_GP, self).compile()
        self.d_optimizer = d_optimizer
        self.g_optimizer = g_optimizer
    
    def gradient_penalty(self, batch_size, real_images, fake_images):
        """Výpočet penalizace gradientu pro WGAN-GP"""
        # Generování náhodných interpolačních faktorů
        alpha = tf.random.uniform([batch_size, 1, 1, 1], 0.0, 1.0)
        
        # Vytvoření interpolovaných obrázků mezi reálnými a falešnými
        interpolated = alpha * real_images + (1 - alpha) * fake_images
        
        with tf.GradientTape() as gp_tape:
            gp_tape.watch(interpolated)
            # Získání predikce diskriminátoru na interpolovaných obrázcích
            pred = self.discriminator(interpolated, training=True)
        
        # Výpočet gradientů vzhledem ke vstupům
        grads = gp_tape.gradient(pred, interpolated)
        # Výpočet normy gradientů
        norm = tf.sqrt(tf.reduce_sum(tf.square(grads), axis=[1, 2, 3]))
        # Výpočet penalizace gradientu
        gp = tf.reduce_mean((norm - 1.0) ** 2)
        return gp
    
    @tf.function
    def train_step(self, real_images):
        batch_size = tf.shape(real_images)[0]
        
        # Trénování diskriminátoru - kritici v WGAN jsou trénováni více než generátory
        for _ in range(5):  # Extra aktualizace D na jednu aktualizaci G
            # Získání náhodného šumu
            random_latent_vectors = tf.random.normal(shape=(batch_size, self.latent_dim))
            
            with tf.GradientTape() as tape:
                # Generování falešných obrázků
                fake_images = self.generator(random_latent_vectors, training=True)
                
                # Získání predikcí kritika
                fake_preds = self.discriminator(fake_images, training=True)
                real_preds = self.discriminator(real_images, training=True)
                
                # Výpočet ztráty kritika (Wasserstein loss)
                d_loss = tf.reduce_mean(fake_preds) - tf.reduce_mean(real_preds)
                
                # Výpočet penalizace gradientu
                gp = self.gradient_penalty(batch_size, real_images, fake_images)
                
                # Přidání penalizace gradientu ke ztrátě
                d_loss += self.gp_weight * gp
            
            # Získání gradientů a aktualizace diskriminátoru
            d_gradients = tape.gradient(d_loss, self.discriminator.trainable_variables)
            self.d_optimizer.apply_gradients(
                zip(d_gradients, self.discriminator.trainable_variables)
            )
        
        # Trénování generátoru
        random_latent_vectors = tf.random.normal(shape=(batch_size, self.latent_dim))
        
        with tf.GradientTape() as tape:
            # Generování falešných obrázků
            fake_images = self.generator(random_latent_vectors, training=True)
            
            # Získání predikcí kritika
            fake_preds = self.discriminator(fake_images, training=True)
            
            # Výpočet ztráty generátoru (negativ výstupu diskriminátoru pro falešné vzorky)
            g_loss = -tf.reduce_mean(fake_preds)
        
        # Získání gradientů a aktualizace generátoru
        g_gradients = tape.gradient(g_loss, self.generator.trainable_variables)
        self.g_optimizer.apply_gradients(
            zip(g_gradients, self.generator.trainable_variables)
        )
        
        return {"d_loss": d_loss, "g_loss": g_loss}

# Vytvoření modelu WGAN-GP (příklad použití)
discriminator = build_discriminator()
# Pro WGAN odstraníme sigmoid aktivaci z diskriminátoru
discriminator.layers[-1].activation = None  # Lineární aktivace pro Wasserstein GAN

generator = build_generator(LATENT_DIM)

wgan = WGAN_GP(discriminator, generator, LATENT_DIM)
wgan.compile(
    d_optimizer=tf.keras.optimizers.Adam(learning_rate=0.0001, beta_1=0.5, beta_2=0.9),
    g_optimizer=tf.keras.optimizers.Adam(learning_rate=0.0001, beta_1=0.5, beta_2=0.9)
)

print("Model WGAN-GP definován a připraven k tréninku")
```

## Pokročilé architektury GANů

Od svého vzniku se GANy vyvinuly do mnoha specializovaných architektur:

### Deep Convolutional GAN (DCGAN)
- Používá konvoluční a transponované konvoluční vrstvy
- Batch normalizace v obou sítích
- Odstraňuje plně propojené skryté vrstvy
- Používá ReLU v generátoru a LeakyReLU v diskriminátoru

### Conditional GAN (cGAN)
- Podmiňuje generátor a diskriminátor na dodatečných informacích (např. třída)
- Umožňuje kontrolovanou generaci na základě specifikovaných atributů

### CycleGAN
- Provádí překlad obrázek-na-obrázek bez párovaných tréninkových dat
- Používá loss cyklické konzistence k zachování obsahu při změně stylu

### StyleGAN
- Odděluje vysokoúrovňové atributy od stochastické variace
- Používá adaptivní instanční normalizaci pro kontrolu stylu
- Umožňuje vysoce kvalitní syntézu obrazu s jemnou kontrolou

```python
# Implementace podmíněného GANu (cGAN) pro MNIST
# Umožňuje kontrolovat, která číslice je generována, přidáním informace o třídě

def build_conditional_generator(latent_dim, num_classes=10):
    # Vstup pro vektor latentního prostoru
    latent_input = layers.Input(shape=(latent_dim,))
    # Vstup pro label
    label_input = layers.Input(shape=(1,))
    
    # Embedding pro kategorický vstup
    label_embedding = layers.Embedding(num_classes, latent_dim)(label_input)
    # Zploštění embeddingu
    label_embedding = layers.Flatten()(label_embedding)
    
    # Násobení po prvcích
    joined_representation = layers.Multiply()([latent_input, label_embedding])
    
    # První plně propojená vrstva
    x = layers.Dense(7*7*256, use_bias=False)(joined_representation)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(alpha=0.2)(x)
    
    # Přetvarování
    x = layers.Reshape((7, 7, 256))(x)
    
    # Transponované konvoluční vrstvy
    x = layers.Conv2DTranspose(128, (5, 5), strides=(1, 1), padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(alpha=0.2)(x)
    
    x = layers.Conv2DTranspose(64, (5, 5), strides=(2, 2), padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(alpha=0.2)(x)
    
    # Výstupní vrstva
    output = layers.Conv2DTranspose(1, (5, 5), strides=(2, 2), padding='same', 
                                   use_bias=False, activation='tanh')(x)
    
    # Definice modelu
    model = models.Model([latent_input, label_input], output, name='conditional_generator')
    return model

def build_conditional_discriminator(num_classes=10):
    # Vstup pro obrázek
    img_input = layers.Input(shape=(28, 28, 1))
    # Vstup pro label
    label_input = layers.Input(shape=(1,))
    
    # Embedding pro kategorický vstup
    label_embedding = layers.Embedding(num_classes, 28*28)(label_input)
    # Přetvarování na dimenzi obrázku
    label_embedding = layers.Reshape((28, 28, 1))(label_embedding)
    
    # Konkatenace obrázku a labelu
    concatenated = layers.Concatenate(axis=3)([img_input, label_embedding])
    
    # Konvoluční vrstvy
    x = layers.Conv2D(64, (5, 5), strides=(2, 2), padding='same')(concatenated)
    x = layers.LeakyReLU(alpha=0.2)(x)
    x = layers.Dropout(0.3)(x)
    
    x = layers.Conv2D(128, (5, 5), strides=(2, 2), padding='same')(x)
    x = layers.LeakyReLU(alpha=0.2)(x)
    x = layers.Dropout(0.3)(x)
    
    # Flatten a výstup
    x = layers.Flatten()(x)
    output = layers.Dense(1)(x)
    
    # Definice modelu
    model = models.Model([img_input, label_input], output, name='conditional_discriminator')
    return model
```

## Metriky hodnocení GANů

Hodnocení GANů je náročné, protože explicitně nemodelují pravděpodobnostní rozdělení. Bylo vyvinuto několik metod:

### Vizuální inspekce
- Manuální hodnocení vygenerovaných vzorků
- Omezeno subjektivitou a škálou

### Statistické míry
- **Inception Score (IS)**: Měří jak kvalitu, tak diverzitu
- **Fréchet Inception Distance (FID)**: Porovnává statistiky reálných a generovaných vzorků
- **Precision and Recall**: Měří kvalitu vzorků a pokrytí módů

### Hodnocení specifické pro úlohu
- Výkon na downstream úlohách (např. klasifikace s generovanými daty)
- Lidské hodnocení a percepční studie

```python
# Implementace Fréchet Inception Distance (FID) pro hodnocení GANu
from tensorflow.keras.applications.inception_v3 import InceptionV3, preprocess_input
import scipy.linalg

def calculate_fid(real_images, generated_images, batch_size=32):
    """
    Výpočet Fréchet Inception Distance (FID) mezi reálnými a generovanými obrázky.
    
    Args:
        real_images: Dataset reálných obrázků
        generated_images: Dataset generovaných obrázků
        batch_size: Velikost dávky pro zpracování
        
    Returns:
        FID skóre (nižší je lepší)
    """
    # Načtení modelu InceptionV3 pro extrakci příznaků
    inception_model = InceptionV3(include_top=False, pooling='avg', input_shape=(299, 299, 3))
    
    def preprocess_images(images):
        # Změna velikosti a případný převod do RGB
        images = tf.image.resize(images, (299, 299))
        if images.shape[-1] == 1:  # Pokud jsou černobílé, převést na RGB
            images = tf.tile(images, [1, 1, 1, 3])
        # Preprocessing pro InceptionV3
        images = preprocess_input(images * 127.5 + 127.5)  # Převod z [-1, 1] do [0, 255]
        return images
    
    def get_features(images):
        # Zpracování obrázků v dávkách a extrakce příznaků
        features = []
        for i in range(0, len(images), batch_size):
            batch = images[i:i + batch_size]
            batch = preprocess_images(batch)
            batch_features = inception_model.predict(batch)
            features.append(batch_features)
        return np.concatenate(features, axis=0)
    
    # Extrakce příznaků pro reálné a generované obrázky
    real_features = get_features(real_images)
    gen_features = get_features(generated_images)
    
    # Výpočet střední hodnoty a kovariance
    mu_real = np.mean(real_features, axis=0)
    mu_gen = np.mean(gen_features, axis=0)
    sigma_real = np.cov(real_features, rowvar=False)
    sigma_gen = np.cov(gen_features, rowvar=False)
    
    # Výpočet FID
    ssdiff = np.sum((mu_real - mu_gen) ** 2)
    covmean = scipy.linalg.sqrtm(sigma_real.dot(sigma_gen))
    if np.iscomplexobj(covmean):
        covmean = covmean.real
        
    fid = ssdiff + np.trace(sigma_real + sigma_gen - 2 * covmean)
    return fid

# Také implementace Inception Score pro porovnání
def calculate_inception_score(images, batch_size=32, splits=10):
    """
    Výpočet Inception Score (IS) pro generované obrázky.
    
    Args:
        images: Dataset generovaných obrázků
        batch_size: Velikost dávky pro zpracování
        splits: Počet rozdělení pro výpočet průměru a std
        
    Returns:
        Průměr a směrodatná odchylka Inception Score (vyšší je lepší)
    """
    # Načtení modelu InceptionV3 pro klasifikaci
    inception_model = tf.keras.applications.InceptionV3(
        include_top=True, weights='imagenet'
    )
    
    def preprocess_images(images):
        # Změna velikosti a převod do RGB, pokud je potřeba
        images = tf.image.resize(images, (299, 299))
        if images.shape[-1] == 1:  # Pokud jsou černobílé, převést na RGB
            images = tf.tile(images, [1, 1, 1, 3])
        # Preprocessing pro InceptionV3
        images = preprocess_input(images * 127.5 + 127.5)  # Převod z [-1, 1] do [0, 255]
        return images
    
    # Získání predikcí z InceptionV3
    def get_predictions(images):
        preds = []
        for i in range(0, len(images), batch_size):
            batch = images[i:i + batch_size]
            batch = preprocess_images(batch)
            batch_preds = inception_model.predict(batch)
            # Převod logitů na pravděpodobnosti
            batch_preds = tf.nn.softmax(batch_preds)
            preds.append(batch_preds)
        return np.concatenate(preds, axis=0)
    
    # Získání všech predikcí
    preds = get_predictions(images)
    
    # Výpočet skóre pro každé rozdělení
    scores = []
    n_images = preds.shape[0]
    split_size = n_images // splits
    
    for i in range(splits):
        split_preds = preds[i * split_size:(i + 1) * split_size]
        
        # Výpočet KL divergence
        p_y = np.mean(split_preds, axis=0)
        kl = split_preds * (np.log(split_preds + 1e-10) - np.log(p_y + 1e-10))
        kl = np.mean(np.sum(kl, axis=1))
        
        # Výpočet skóre jako exp(kl)
        scores.append(np.exp(kl))
    
    return np.mean(scores), np.std(scores)
```

```python
# Příklad překladu obrázek-na-obrázek s CycleGAN (konceptuální implementace)
def build_generator_resnet(input_shape=(256, 256, 3)):
    """Vytvoření generátoru založeného na ResNet pro překlad obrázků"""
    
    def residual_block(x, filters, kernel_size=3):
        """Reziduální blok s přeskakujícím spojením"""
        shortcut = x
        
        x = layers.Conv2D(filters, kernel_size, padding='same', use_bias=False)(x)
        x = layers.BatchNormalization()(x)
        x = layers.ReLU()(x)
        
        x = layers.Conv2D(filters, kernel_size, padding='same', use_bias=False)(x)
        x = layers.BatchNormalization()(x)
        
        x = layers.Add()([shortcut, x])  # Přeskakující spojení
        return x
    
    # Vstupní vrstva
    input_img = layers.Input(shape=input_shape)
    
    # Počáteční konvoluce
    x = layers.Conv2D(64, 7, padding='same', use_bias=False)(input_img)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    
    # Downsampling
    x = layers.Conv2D(128, 3, strides=2, padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    
    x = layers.Conv2D(256, 3, strides=2, padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    
    # Reziduální bloky
    for _ in range(9):  # 9 reziduálních bloků pro obrázky 256x256
        x = residual_block(x, 256)
    
    # Upsampling
    x = layers.Conv2DTranspose(128, 3, strides=2, padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    
    x = layers.Conv2DTranspose(64, 3, strides=2, padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    
    # Výstupní vrstva
    output_img = layers.Conv2D(3, 7, padding='same', activation='tanh')(x)
    
    return models.Model(input_img, output_img)

def build_discriminator_patch(input_shape=(256, 256, 3)):
    """Vytvoření PatchGAN diskriminátoru pro CycleGAN"""
    
    input_img = layers.Input(shape=input_shape)
    
    # Série konvolučních vrstev
    x = layers.Conv2D(64, 4, strides=2, padding='same')(input_img)
    x = layers.LeakyReLU(0.2)(x)
    
    x = layers.Conv2D(128, 4, strides=2, padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(0.2)(x)
    
    x = layers.Conv2D(256, 4, strides=2, padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(0.2)(x)
    
    x = layers.Conv2D(512, 4, strides=1, padding='same', use_bias=False)(x)
    x = layers.BatchNormalization()(x)
    x = layers.LeakyReLU(0.2)(x)
    
    # Výstupní vrstva - mapuje na 30x30 PatchGAN
    x = layers.Conv2D(1, 4, strides=1, padding='same')(x)
    
    return models.Model(input_img, x)

# Definice modelu CycleGAN
class CycleGAN(tf.keras.Model):
    def __init__(self, input_shape=(256, 256, 3)):
        super(CycleGAN, self).__init__()
        
        # Generátory
        self.g_AB = build_generator_resnet(input_shape)  # Překládá A -> B
        self.g_BA = build_generator_resnet(input_shape)  # Překládá B -> A
        
        # Diskriminátory
        self.d_A = build_discriminator_patch(input_shape)  # Rozlišuje reálné/falešné A
        self.d_B = build_discriminator_patch(input_shape)  # Rozlišuje reálné/falešné B
        
        # Váhy ztrát
        self.lambda_cycle = 10.0  # Váha pro ztrátu cyklické konzistence
        self.lambda_identity = 0.5  # Váha pro ztrátu identitního mapování
    
    def compile(self, gen_optimizer, disc_optimizer):
        super(CycleGAN, self).compile()
        self.gen_optimizer = gen_optimizer
        self.disc_optimizer = disc_optimizer
        
        # Ztrátové funkce
        self.gen_loss_fn = tf.keras.losses.MeanSquaredError()
        self.disc_loss_fn = tf.keras.losses.MeanSquaredError()
    
    @tf.function
    def train_step(self, batch_data):
        # Rozbalení dat
        real_A, real_B = batch_data
        
        with tf.GradientTape(persistent=True) as tape:
            # Generování falešných obrázků
            fake_B = self.g_AB(real_A, training=True)
            fake_A = self.g_BA(real_B, training=True)
            
            # Rekonstrukce obrázků (cyklická konzistence)
            reconstructed_A = self.g_BA(fake_B, training=True)
            reconstructed_B = self.g_AB(fake_A, training=True)
            
            # Identitní mapování 
            identity_A = self.g_BA(real_A, training=True)
            identity_B = self.g_AB(real_B, training=True)
            
            # Získání výstupů diskriminátoru
            disc_real_A = self.d_A(real_A, training=True)
            disc_fake_A = self.d_A(fake_A, training=True)
            
            disc_real_B = self.d_B(real_B, training=True)
            disc_fake_B = self.d_B(fake_B, training=True)
            
            # Výpočet ztrát generátoru
            gen_loss_A2B = self.gen_loss_fn(tf.ones_like(disc_fake_B), disc_fake_B)
            gen_loss_B2A = self.gen_loss_fn(tf.ones_like(disc_fake_A), disc_fake_A)
            
            # Ztráty cyklické konzistence
            cycle_loss_A = self.lambda_cycle * tf.reduce_mean(tf.abs(real_A - reconstructed_A))
            cycle_loss_B = self.lambda_cycle * tf.reduce_mean(tf.abs(real_B - reconstructed_B))
            
            # Ztráty identity
            identity_loss_A = self.lambda_identity * self.lambda_cycle * tf.reduce_mean(tf.abs(real_A - identity_A))
            identity_loss_B = self.lambda_identity * self.lambda_cycle * tf.reduce_mean(tf.abs(real_B - identity_B))
            
            # Celková ztráta generátoru
            total_gen_loss = gen_loss_A2B + gen_loss_B2A + cycle_loss_A + cycle_loss_B + identity_loss_A + identity_loss_B
            
            # Ztráty diskriminátoru
            disc_loss_A_real = self.disc_loss_fn(tf.ones_like(disc_real_A), disc_real_A)
            disc_loss_A_fake = self.disc_loss_fn(tf.zeros_like(disc_fake_A), disc_fake_A)
            disc_loss_A = (disc_loss_A_real + disc_loss_A_fake) * 0.5
            
            disc_loss_B_real = self.disc_loss_fn(tf.ones_like(disc_real_B), disc_real_B)
            disc_loss_B_fake = self.disc_loss_fn(tf.zeros_like(disc_fake_B), disc_fake_B)
            disc_loss_B = (disc_loss_B_real + disc_loss_B_fake) * 0.5
            
            # Celková ztráta diskriminátoru
            total_disc_loss = disc_loss_A + disc_loss_B
        
        # Získání gradientů
        gen_grads = tape.gradient(total_gen_loss, 
                                 self.g_AB.trainable_variables + self.g_BA.trainable_variables)
        disc_grads = tape.gradient(total_disc_loss, 
                                  self.d_A.trainable_variables + self.d_B.trainable_variables)
        
        # Aplikace gradientů
        self.gen_optimizer.apply_gradients(
            zip(gen_grads, self.g_AB.trainable_variables + self.g_BA.trainable_variables))
        self.disc_optimizer.apply_gradients(
            zip(disc_grads, self.d_A.trainable_variables + self.d_B.trainable_variables))
        
        return {
            "gen_loss": total_gen_loss,
            "disc_loss": total_disc_loss
        }
```

## Shrnutí

Generativní adversariální sítě (GANs) transformovaly oblast generativního modelování svým inovativním adversariálním tréninkovým rámcem. Zde jsou klíčové poznatky:

1. **Základní koncept**: GANy sestávají ze dvou soupeřících sítí: generátoru, který vytváří syntetická data, a diskriminátoru, který hodnotí autenticitu dat.

2. **Proces tréninku**: GANy se učí prostřednictvím adversariálního tréninku, kde se generátor snaží oklamat diskriminátor, zatímco diskriminátor se snaží správně identifikovat reálné a falešné vzorky.

3. **Výzvy**: GANy čelí výzvám jako zhroucení módu, nestabilita tréninku a mizející gradienty, což vedlo k architektonickým inovacím jako Wasserstein GANy a penalizace gradientů.

4. **Varianty architektur**: Ekosystém GANů zahrnuje varianty jako DCGAN pro generování obrazů, podmíněné GANy pro kontrolovanou generaci a CycleGANy pro nepárovaný překlad obrázek-na-obrázek.

5. **Hodnocení**: Hodnocení GANů používá metriky jako Inception Score a Fréchet Inception Distance, spolu s lidským hodnocením a výkonem v navazujících úlohách.

6. **Aplikace**: GANy našly široké uplatnění v syntéze obrazů, přenosu stylu, augmentaci dat a vědeckých oblastech, jako je objevování léků.

7. **Etické obavy**: Deepfakes a syntetická média představují výzvy, které by měly být řešeny pomocí detekčních nástrojů a postupů zodpovědného vývoje.

GANy se nadále rychle vyvíjejí, výzkum se zaměřuje na zlepšenou stabilitu tréninku, výstupy s vyšším rozlišením a přesnější kontrolu nad procesem generování. S pokrokem výpočetních zdrojů a algoritmů se GANy pravděpodobně rozšíří do nových domén a aplikací, což z nich činí základní nástroj v moderním toolkitu strojového učení.
