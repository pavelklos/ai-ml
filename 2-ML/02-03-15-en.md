## Introduction to Anomaly Detection

Anomaly detection (also known as outlier detection) is the identification of rare items, events, or observations that deviate significantly from the majority of the data. Anomalies can indicate critical incidents such as bank fraud, structural defects, medical problems, or errors in text.

Key concepts in anomaly detection:
- **Point anomalies**: Individual instances that are anomalous
- **Contextual anomalies**: Instances anomalous in a specific context
- **Collective anomalies**: Collections of instances anomalous together

Common challenges:
- Defining what constitutes "normal" behavior
- Dealing with evolving normal behavior
- Different anomaly types in different domains
- Availability of labeled data for training/validation

## Statistical Methods for Anomaly Detection

Statistical approaches assume that normal data instances occur in high probability regions of a stochastic model, while anomalies occur in low probability regions. These methods typically establish a statistical model of normality and then flag as anomalies any observations that deviate from this model.

### Z-Score Method

The Z-score measures how many standard deviations an element is from the mean. Data points with a Z-score beyond a certain threshold (often ±3) are considered anomalies.

```python
# Z-Score Method for Anomaly Detection
from scipy import stats

def detect_anomalies_zscore(data, threshold=3):
    """
    Detect anomalies using Z-score method
    
    Parameters:
    -----------
    data : array-like
        Input data
    threshold : float
        Z-score threshold for anomaly detection
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    """
    mean = np.mean(data)
    std = np.std(data)
    z_scores = [(y - mean) / std for y in data]
    return np.abs(z_scores) > threshold

# Generate sample data with anomalies
np.random.seed(42)
normal_data = np.random.normal(loc=0, scale=1, size=1000)
anomalies = np.random.uniform(low=5, high=10, size=20)
data = np.concatenate([normal_data, anomalies])

# Detect anomalies using Z-score
anomaly_indices = detect_anomalies_zscore(data, threshold=3)
print(f"Number of detected anomalies: {np.sum(anomaly_indices)}")

# Visualize the results
plt.figure(figsize=(12, 6))
plt.scatter(range(len(data)), data, c=['blue' if not x else 'red' for x in anomaly_indices], alpha=0.6)
plt.axhspan(mean - 3*std, mean + 3*std, alpha=0.2, color='green', label='Normal Range')
plt.title('Z-Score Anomaly Detection', fontsize=15)
plt.xlabel('Index')
plt.ylabel('Value')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### Modified Z-Score

The modified Z-score uses the median and Median Absolute Deviation (MAD) instead of mean and standard deviation, making it more robust to the presence of outliers.

```python
def detect_anomalies_modified_zscore(data, threshold=3.5):
    """
    Detect anomalies using Modified Z-score method
    
    Parameters:
    -----------
    data : array-like
        Input data
    threshold : float
        Modified Z-score threshold for anomaly detection
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    """
    median = np.median(data)
    # MAD = median(|x_i - median(x)|)
    mad = np.median(np.abs(data - median))
    
    # To make MAD comparable to standard deviation
    # for normal distribution, multiply by 1.4826
    mad_factor = 1.4826
    
    modified_z_scores = mad_factor * np.abs(data - median) / mad if mad else np.zeros_like(data)
    return modified_z_scores > threshold

# Apply modified Z-score
anomaly_indices_mod = detect_anomalies_modified_zscore(data, threshold=3.5)
print(f"Number of detected anomalies (Modified Z-score): {np.sum(anomaly_indices_mod)}")
```

### Tukey's Method (IQR Method)

This method uses the Interquartile Range (IQR) to identify outliers. Data points falling outside 1.5×IQR beyond the upper and lower quartiles are considered anomalies.

```python
def detect_anomalies_iqr(data, factor=1.5):
    """
    Detect anomalies using IQR method (Tukey's method)
    
    Parameters:
    -----------
    data : array-like
        Input data
    factor : float
        Factor for IQR range multiplier
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    """
    q1 = np.percentile(data, 25)
    q3 = np.percentile(data, 75)
    iqr = q3 - q1
    
    lower_bound = q1 - factor * iqr
    upper_bound = q3 + factor * iqr
    
    return (data < lower_bound) | (data > upper_bound)

# Apply IQR method
anomaly_indices_iqr = detect_anomalies_iqr(data, factor=1.5)
print(f"Number of detected anomalies (IQR method): {np.sum(anomaly_indices_iqr)}")

# Visualize IQR method results
plt.figure(figsize=(12, 6))
plt.boxplot(data, vert=False, widths=0.6)
plt.scatter(data, np.ones(len(data)), c=['blue' if not x else 'red' for x in anomaly_indices_iqr], alpha=0.6)
plt.title('IQR Method for Anomaly Detection', fontsize=15)
plt.yticks([])
plt.xlabel('Value')
plt.grid(True, alpha=0.3)
plt.show()
```

## Distance-based Methods

Distance-based methods detect anomalies by measuring the distance between data points. Points that are far from their nearest neighbors are considered anomalies.

### K-Nearest Neighbors (KNN) for Anomaly Detection

```python
from sklearn.neighbors import NearestNeighbors

def knn_anomaly_detection(data, k=5, threshold=None, method='distance'):
    """
    Detect anomalies using KNN method
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    k : int
        Number of neighbors to consider
    threshold : float or None
        Threshold for anomaly detection. If None, the 95th percentile is used
    method : str
        'distance' or 'score', determines how anomalies are calculated
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    scores : array-like
        Anomaly scores
    """
    # Fit the nearest neighbors algorithm
    nbrs = NearestNeighbors(n_neighbors=k+1).fit(data)
    
    # For each point, compute distances to its k nearest neighbors
    distances, _ = nbrs.kneighbors(data)
    
    # The distance to the kth neighbor is the anomaly score
    # We exclude the first distance (which is the distance to itself = 0)
    anomaly_scores = distances[:, 1:].mean(axis=1)
    
    # Set threshold as 95th percentile if not provided
    if threshold is None:
        threshold = np.percentile(anomaly_scores, 95)
    
    return anomaly_scores > threshold, anomaly_scores

# Create a dataset for KNN anomaly detection
X_normal, _ = make_blobs(n_samples=400, centers=3, cluster_std=0.7, random_state=42)
X_outliers = np.random.uniform(low=-7, high=7, size=(20, 2))
X_combined = np.vstack([X_normal, X_outliers])

# Apply KNN anomaly detection
anomaly_indices, anomaly_scores = knn_anomaly_detection(X_combined, k=10)
print(f"Number of detected anomalies (KNN): {np.sum(anomaly_indices)}")

# Visualize the results
plt.figure(figsize=(12, 8))

# Plot the data points
plt.scatter(X_combined[:, 0], X_combined[:, 1], 
            c=['blue' if not x else 'red' for x in anomaly_indices],
            s=[30 if not x else 100 for x in anomaly_indices],
            alpha=0.7)

# Plot contour of anomaly scores
x_min, x_max = X_combined[:, 0].min() - 1, X_combined[:, 0].max() + 1
y_min, y_max = X_combined[:, 1].min() - 1, X_combined[:, 1].max() + 1
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100), np.linspace(y_min, y_max, 100))
grid_points = np.c_[xx.ravel(), yy.ravel()]

# Get anomaly scores for grid points
nbrs = NearestNeighbors(n_neighbors=10).fit(X_combined)
distances, _ = nbrs.kneighbors(grid_points)
grid_scores = distances[:, 1:].mean(axis=1)

# Reshape for contour plot
grid_scores = grid_scores.reshape(xx.shape)

# Plot contour
plt.contourf(xx, yy, grid_scores, cmap='Blues', alpha=0.3)
plt.colorbar(label='Anomaly Score')

plt.title('KNN Anomaly Detection', fontsize=15)
plt.grid(True, alpha=0.3)
plt.show()
```

### Local Outlier Factor (LOF)

LOF compares the local density of a point with the local densities of its neighbors. Points with much lower density than their neighbors are considered anomalies.

```python
from sklearn.neighbors import LocalOutlierFactor

def lof_anomaly_detection(data, k=5):
    """
    Detect anomalies using Local Outlier Factor (LOF)
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    k : int
        Number of neighbors to consider
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    scores : array-like
        LOF scores (higher = more anomalous)
    """
    # Initialize and fit LOF
    lof = LocalOutlierFactor(n_neighbors=k, contamination='auto')
    # fit_predict returns 1 for inliers and -1 for outliers
    predictions = lof.fit_predict(data)
    # Negative of LOF scores (higher = more anomalous)
    scores = -lof.negative_outlier_factor_
    
    return predictions == -1, scores

# Apply LOF anomaly detection
anomaly_indices_lof, lof_scores = lof_anomaly_detection(X_combined, k=10)
print(f"Number of detected anomalies (LOF): {np.sum(anomaly_indices_lof)}")

# Visualize the LOF results
plt.figure(figsize=(12, 8))
scatter = plt.scatter(X_combined[:, 0], X_combined[:, 1], 
                     c=lof_scores, cmap='plasma', s=50, alpha=0.8)
plt.colorbar(scatter, label='LOF Score')
plt.title('Local Outlier Factor (LOF) Anomaly Detection', fontsize=15)
plt.grid(True, alpha=0.3)
plt.show()
```

## Density-based Methods

Density-based methods identify anomalies by estimating the probability density function of the data. Points in regions of low density are flagged as anomalies.

### Gaussian Mixture Models (GMM)

GMM assumes that the data is generated from a mixture of several Gaussian distributions and can identify points with low probability under the fitted model.

```python
from sklearn.mixture import GaussianMixture

def gmm_anomaly_detection(data, n_components=3, threshold=None):
    """
    Detect anomalies using Gaussian Mixture Model
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    n_components : int
        Number of Gaussian components
    threshold : float or None
        Probability threshold for anomaly detection
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    scores : array-like
        Negative log probability density (higher = more anomalous)
    """
    # Initialize and fit GMM
    gmm = GaussianMixture(n_components=n_components, random_state=42)
    gmm.fit(data)
    
    # Calculate log probability density for each point
    log_probs = gmm.score_samples(data)
    # Negative log probability (higher = more anomalous)
    scores = -log_probs
    
    # Set threshold if not provided
    if threshold is None:
        threshold = np.percentile(scores, 95)
    
    return scores > threshold, scores

# Create a dataset for GMM anomaly detection
X_norm1, _ = make_blobs(n_samples=200, centers=[(0, 0)], cluster_std=0.5, random_state=42)
X_norm2, _ = make_blobs(n_samples=200, centers=[(4, 4)], cluster_std=0.5, random_state=42)
X_normal = np.vstack([X_norm1, X_norm2])
X_outliers = np.random.uniform(low=-2, high=6, size=(20, 2))
X_combined = np.vstack([X_normal, X_outliers])

# Apply GMM anomaly detection
anomaly_indices_gmm, gmm_scores = gmm_anomaly_detection(X_combined, n_components=2)
print(f"Number of detected anomalies (GMM): {np.sum(anomaly_indices_gmm)}")

# Visualize GMM results
plt.figure(figsize=(12, 8))

# Data points
plt.scatter(X_combined[:, 0], X_combined[:, 1], 
            c=['blue' if not x else 'red' for x in anomaly_indices_gmm],
            s=50, alpha=0.7)

# Decision boundary contours
x_min, x_max = X_combined[:, 0].min() - 1, X_combined[:, 0].max() + 1
y_min, y_max = X_combined[:, 1].min() - 1, X_combined[:, 1].max() + 1
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100), np.linspace(y_min, y_max, 100))
grid_points = np.c_[xx.ravel(), yy.ravel()]

# Fit GMM for visualization
gmm = GaussianMixture(n_components=2, random_state=42)
gmm.fit(X_combined)
log_probs = gmm.score_samples(grid_points)
grid_scores = -log_probs
grid_scores = grid_scores.reshape(xx.shape)

plt.contourf(xx, yy, grid_scores, levels=10, cmap='Blues', alpha=0.3)
plt.colorbar(label='Anomaly Score (Negative Log Probability)')

plt.title('Gaussian Mixture Model Anomaly Detection', fontsize=15)
plt.grid(True, alpha=0.3)
plt.show()
```

## Clustering-based Approaches

Clustering-based anomaly detection methods first cluster the data and then identify anomalies as points that either do not belong to any cluster or are far from their cluster centroid.

### DBSCAN for Anomaly Detection

Density-Based Spatial Clustering of Applications with Noise (DBSCAN) naturally identifies outliers as points that do not belong to any cluster.

```python
from sklearn.cluster import DBSCAN

def dbscan_anomaly_detection(data, eps=0.5, min_samples=5):
    """
    Detect anomalies using DBSCAN clustering
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    eps : float
        Maximum distance between two samples for them to be considered neighbors
    min_samples : int
        Number of samples in a neighborhood for a point to be considered as a core point
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies (-1 = anomaly)
    """
    # Initialize and fit DBSCAN
    dbscan = DBSCAN(eps=eps, min_samples=min_samples)
    clusters = dbscan.fit_predict(data)
    
    # Points labeled as -1 are considered outliers/anomalies
    return clusters == -1, clusters

# Generate a dataset for DBSCAN
X_normal, _ = make_blobs(n_samples=400, centers=3, cluster_std=0.5, random_state=42)
X_outliers = np.random.uniform(low=-7, high=7, size=(20, 2))
X_combined = np.vstack([X_normal, X_outliers])

# Apply DBSCAN anomaly detection
anomaly_indices_dbscan, cluster_labels = dbscan_anomaly_detection(X_combined, eps=0.7, min_samples=10)
print(f"Number of detected anomalies (DBSCAN): {np.sum(anomaly_indices_dbscan)}")

# Visualize DBSCAN results
plt.figure(figsize=(12, 8))

# Create color mapping for clusters (-1 = red for outliers)
unique_labels = np.unique(cluster_labels)
colors = plt.cm.rainbow(np.linspace(0, 1, len(unique_labels) - 1))
cluster_colors = {}

# Assign red to outliers (-1) and rainbow colors to valid clusters
for i, label in enumerate(unique_labels):
    if label == -1:  # Outliers
        cluster_colors[label] = 'red'
    else:
        cluster_colors[label] = colors[i - (1 if -1 in unique_labels else 0)]

# Plot points with cluster colors
for label in unique_labels:
    mask = cluster_labels == label
    plt.scatter(
        X_combined[mask, 0], X_combined[mask, 1],
        color=cluster_colors[label],
        label=f"Cluster {label}" if label != -1 else "Anomalies",
        s=60 if label == -1 else 40,
        marker='x' if label == -1 else 'o',
        alpha=0.7
    )

plt.title('DBSCAN Clustering for Anomaly Detection', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### K-Means for Anomaly Detection

K-means clustering can be used for anomaly detection by measuring the distance of each point to its nearest cluster centroid.

```python
from sklearn.cluster import KMeans

def kmeans_anomaly_detection(data, n_clusters=3, threshold=None):
    """
    Detect anomalies using K-means clustering
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    n_clusters : int
        Number of clusters
    threshold : float or None
        Distance threshold for anomaly detection
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    scores : array-like
        Distance to nearest centroid (higher = more anomalous)
    """
    # Initialize and fit K-means
    kmeans = KMeans(n_clusters=n_clusters, random_state=42)
    kmeans.fit(data)
    
    # Predict cluster for each point
    cluster_labels = kmeans.predict(data)
    
    # Calculate distance to assigned cluster center
    distances = np.min(
        [np.linalg.norm(data - center, axis=1) for center in kmeans.cluster_centers_],
        axis=0
    )
    
    # Set threshold if not provided
    if threshold is None:
        threshold = np.percentile(distances, 95)
    
    return distances > threshold, distances

# Apply K-means anomaly detection
anomaly_indices_kmeans, kmeans_distances = kmeans_anomaly_detection(X_combined, n_clusters=3)
print(f"Number of detected anomalies (K-means): {np.sum(anomaly_indices_kmeans)}")

# Visualize K-means results
plt.figure(figsize=(12, 8))

# Plot the points
plt.scatter(
    X_combined[:, 0], X_combined[:, 1], 
    c=['blue' if not x else 'red' for x in anomaly_indices_kmeans],
    s=[40 if not x else 80 for x in anomaly_indices_kmeans],
    alpha=0.7
)

# Plot the centroids
kmeans = KMeans(n_clusters=3, random_state=42)
kmeans.fit(X_combined)

    centroids[:, 0], centroids[:, 1],

plt.grid(True, alpha=0.3)
```

## Machine Learning-based Methods

Various supervised and unsupervised machine learning algorithms can be adapted for anomaly detection.

### One-Class SVM

One-Class SVM (Support Vector Machine) learns a boundary around normal data and identifies points outside this boundary as anomalies.

```python
from sklearn.svm import OneClassSVM

def oneclass_svm_anomaly_detection(data, nu=0.05):
    """
    Detect anomalies using One-Class SVM
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    nu : float
        An upper bound on the fraction of training errors and a lower bound on
        the fraction of support vectors
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies (1 = normal, -1 = anomaly)
    """
    # Initialize and fit One-Class SVM
    ocsvm = OneClassSVM(nu=nu, kernel='rbf', gamma='auto')
    predictions = ocsvm.fit_predict(data)
    
    # One-Class SVM returns 1 for inliers and -1 for outliers
    return predictions == -1, ocsvm.decision_function(data)

# Generate a dataset for One-Class SVM
X_normal, _ = make_blobs(n_samples=300, centers=1, cluster_std=1.0, random_state=42)
```

### Isolation Forest

Isolation Forest explicitly isolates anomalies instead of profiling normal data points. It builds an ensemble of isolation trees and anomalies are those instances that have shorter average path lengths.

```python
from sklearn.ensemble import IsolationForest

def isolation_forest_anomaly_detection(data, contamination=0.05):
    """
    Detect anomalies using Isolation Forest
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    contamination : float
        Expected proportion of outliers in the data
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies (1 = normal, -1 = anomaly)
    """
    # Initialize and fit Isolation Forest
    iso_forest = IsolationForest(contamination=contamination, random_state=42)
    predictions = iso_forest.fit_predict(data)
    
    # Isolation Forest returns 1 for inliers and -1 for outliers
    return predictions == -1, iso_forest.decision_function(data)
```

## Deep Learning for Anomaly Detection

Deep learning approaches can learn complex representations for anomaly detection, particularly useful for high-dimensional data.

### Autoencoders for Anomaly Detection

Autoencoders are neural networks that learn to compress and reconstruct data. Anomalies typically have higher reconstruction errors.

```python
import tensorflow as tf
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense
from tensorflow.keras.optimizers import Adam
from sklearn.preprocessing import StandardScaler

def autoencoder_anomaly_detection(data, hidden_dim=8, epochs=50, threshold=None):
    """
    Detect anomalies using an autoencoder
    
    Parameters:
    -----------
    data : array-like
        Input data (n_samples, n_features)
    hidden_dim : int
        Dimension of the encoding layer
    epochs : int
        Number of training epochs
    threshold : float or None
        Reconstruction error threshold for anomaly detection
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    scores : array-like
        Reconstruction errors (higher = more anomalous)
    model : object
        Trained autoencoder model
    """
    # Scale the data
    scaler = StandardScaler()
    scaled_data = scaler.fit_transform(data)
    
    # Define the input dimension
    input_dim = scaled_data.shape[1]
    
    # Define model architecture
    input_layer = Input(shape=(input_dim,))
    # Encoder
    encoded = Dense(hidden_dim * 2, activation='relu')(input_layer)
    encoded = Dense(hidden_dim, activation='relu')(encoded)
    # Decoder
    decoded = Dense(hidden_dim * 2, activation='relu')(encoded)
    decoded = Dense(input_dim, activation='linear')(decoded)
    
    # Create and compile model
    autoencoder = Model(input_layer, decoded)
    autoencoder.compile(optimizer=Adam(learning_rate=0.001), loss='mse')
    
    # Train the autoencoder
    autoencoder.fit(scaled_data, scaled_data, 
                   epochs=epochs, batch_size=32, 
                   verbose=0, shuffle=True)
    
    # Get reconstruction errors
    reconstructions = autoencoder.predict(scaled_data)
    reconstruction_errors = np.mean(np.square(scaled_data - reconstructions), axis=1)
    
    # Set threshold if not provided
    if threshold is None:
        threshold = np.percentile(reconstruction_errors, 95)
    
    return reconstruction_errors > threshold, reconstruction_errors, autoencoder
```

### Moving Average-based Anomaly Detection

Moving average methods can identify anomalies by detecting points that deviate significantly from the local trend.

```python
def moving_average_anomaly_detection(time_series, window_size=10, n_sigma=3):
    """
    Detect anomalies in time series using moving average
    
    Parameters:
    -----------
    time_series : array-like
        Input time series
    window_size : int
        Window size for moving average
    n_sigma : float
        Number of standard deviations for threshold
        
    Returns:
    --------
    anomalies : array-like
        Boolean array indicating anomalies
    """
    # Calculate rolling mean and standard deviation
    rolling_mean = pd.Series(time_series).rolling(window=window_size).mean()
    rolling_std = pd.Series(time_series).rolling(window=window_size).std()
    
    # Fill NaN values (at the beginning) with first valid values
    rolling_mean = rolling_mean.fillna(method='bfill')
    rolling_std = rolling_std.fillna(method='bfill')
    
    # Calculate upper and lower bounds
    upper_bound = rolling_mean + n_sigma * rolling_std
    lower_bound = rolling_mean - n_sigma * rolling_std
    
    # Detect anomalies
    anomalies = (time_series > upper_bound) | (time_series < lower_bound)
    
    return anomalies, rolling_mean, upper_bound, lower_bound
```

```python
    time_series : array-like
        Input time series

        Period of the seasonal component
    n_sigma : float
        Number of standard deviations for threshold

    threshold_low = residual_mean - n_sigma * residual_std
    
    # Detect anomalies
    anomalies = (residual > threshold_high) | (residual < threshold_low)
    
    return anomalies, decomposition
```

## Evaluation Metrics for Anomaly Detection

Evaluating anomaly detection algorithms requires specialized metrics due to the typically imbalanced nature of the problem.

```python
from sklearn.metrics import precision_recall_curve, auc, roc_curve, confusion_matrix

def evaluate_anomaly_detection(y_true, anomaly_scores, threshold=None):
    """
    Evaluate anomaly detection performance
    
    Parameters:
    -----------
    y_true : array-like
        True anomaly labels (1 for anomaly, 0 for normal)
    anomaly_scores : array-like
        Anomaly scores (higher = more anomalous)
    threshold : float or None
        Threshold for anomaly detection
        
    Returns:
    --------
    metrics : dict
        Dictionary of evaluation metrics
    """
    # Calculate ROC curve and AUC
    fpr, tpr, roc_thresholds = roc_curve(y_true, anomaly_scores)
    roc_auc = auc(fpr, tpr)
    
    # Calculate Precision-Recall curve and AUC
    precision, recall, pr_thresholds = precision_recall_curve(y_true, anomaly_scores)
    pr_auc = auc(recall, precision)
    
    # Use default threshold if not provided
    if threshold is None:
        # Find threshold that maximizes F1 score
        f1_scores = 2 * (precision * recall) / (precision + recall + 1e-10)
        best_idx = np.argmax(f1_scores)
        threshold = pr_thresholds[best_idx] if best_idx < len(pr_thresholds) else np.median(anomaly_scores)
    
    # Calculate predictions using threshold
    y_pred = anomaly_scores >= threshold
    
    # Calculate confusion matrix
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred).ravel()
    
    # Calculate metrics
    accuracy = (tp + tn) / (tp + tn + fp + fn)
    precision_val = tp / (tp + fp) if (tp + fp) > 0 else 0
    recall_val = tp / (tp + fn) if (tp + fn) > 0 else 0
    f1 = 2 * (precision_val * recall_val) / (precision_val + recall_val) if (precision_val + recall_val) > 0 else 0
    
    return {
        'accuracy': accuracy,
        'precision': precision_val,
        'recall': recall_val,
        'f1': f1,
        'roc_auc': roc_auc,
        'pr_auc': pr_auc,
        'confusion_matrix': {
            'tn': tn, 'fp': fp,
            'fn': fn, 'tp': tp
        }
    }
```

## Summary and Best Practices

Anomaly detection is a crucial task in many domains, from fraud detection to system health monitoring. The choice of method depends on the nature of the data and the specific application requirements.

### Key Takeaways

1. **Statistical methods** (Z-score, IQR) are simple and interpretable but may struggle with complex patterns.

2. **Distance-based methods** (KNN, LOF) excel at detecting local anomalies but can be computationally expensive for large datasets.

3. **Density-based methods** (GMM, KDE) work well when data follows specific distributions but may struggle with high-dimensional data.

4. **Clustering-based approaches** (DBSCAN, K-means) naturally identify outliers and are often intuitive, but require careful parameter tuning.

5. **Machine learning-based methods** (One-Class SVM, Isolation Forest) can model complex patterns and are generally more robust, but may be less interpretable.

6. **Deep learning approaches** (Autoencoders) handle high-dimensional data well but require substantial amounts of data and computational resources.

7. **Time series anomaly detection** requires specialized techniques that account for temporal dependencies, seasonality, and trends.

### Best Practices

1. **Understand your data**: Different types of anomalies (global, contextual, collective) may require different detection approaches.

2. **Feature engineering**: For complex data, creating meaningful features can significantly improve anomaly detection performance.

3. **Ensemble methods**: Combining multiple anomaly detection techniques often yields better results than any single method.

4. **Proper evaluation**: Use appropriate metrics (precision, recall, F1-score) and visualization techniques to assess performance.

5. **Parameter tuning**: Most methods require careful parameter selection (e.g., number of neighbors, contamination rate).

6. **Domain knowledge integration**: Incorporate domain-specific knowledge to improve detection and reduce false positives.

7. **Semi-supervised approaches**: When some labeled anomalies are available, using them can significantly improve detection accuracy.

8. **Scalability considerations**: For large datasets, choose methods with reasonable time and space complexity.

Anomaly detection remains an active area of research, with new techniques constantly being developed to address specific challenges and data types. The best approach often involves experimenting with multiple methods and ensembling them to leverage their complementary strengths.
