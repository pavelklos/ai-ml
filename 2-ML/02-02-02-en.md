## Introduction to Decision Trees and Random Forests

Decision Trees and Random Forests are popular machine learning algorithms for both classification and regression tasks. They are intuitive, easy to interpret, and can handle both numerical and categorical data without much preprocessing.

- **Decision Trees**: Hierarchical models that make decisions based on asking a series of questions
- **Random Forests**: Ensemble models that combine multiple decision trees to improve prediction accuracy and control overfitting


## Decision Tree Fundamentals

Decision trees work by recursively splitting the dataset into subsets based on the value of input features. The goal is to create subsets that are as homogeneous as possible with respect to the target variable.

### Key Concepts:

- **Node**: A point where the dataset is split
- **Root**: The topmost node (starting point)
- **Leaf**: Terminal nodes that provide predictions
- **Splitting Criteria**: Metrics used to determine the best split
  - Classification: Gini impurity, Information gain (entropy)
  - Regression: Mean squared error, Mean absolute error

## Building Decision Trees in Python

Let's build decision tree models for both classification and regression tasks using scikit-learn:

### Decision Tree for Classification

```python
# Split the iris dataset
X_train, X_test, y_train, y_test = train_test_split(
    X_iris, y_iris, test_size=0.3, random_state=42
)

# Create a decision tree classifier
dt_clf = DecisionTreeClassifier(random_state=42)

# Train the model
dt_clf.fit(X_train, y_train)

# Make predictions
y_pred = dt_clf.predict(X_test)

# Evaluate the model
accuracy = accuracy_score(y_test, y_pred)
print(f"Classification accuracy: {accuracy:.4f}")
print("\nClassification Report:")
print(classification_report(y_test, y_pred, target_names=iris.target_names))

# Display confusion matrix
cm = confusion_matrix(y_test, y_pred)
plt.figure(figsize=(8, 6))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', 
            xticklabels=iris.target_names,
            yticklabels=iris.target_names)
plt.xlabel('Predicted')
plt.ylabel('Actual')
plt.title('Confusion Matrix')
plt.show()
```

### Decision Tree for Regression

```python
# Split the housing dataset
X_train, X_test, y_train, y_test = train_test_split(
```

## Decision Tree Visualization

Visualizing decision trees helps in understanding how the model makes decisions:

```python
# Create a simpler decision tree for visualization (limiting max_depth)
dt_viz = DecisionTreeClassifier(max_depth=3, random_state=42)
dt_viz.fit(X_train, y_train)

# Visualize the decision tree
plt.figure(figsize=(15, 10))
plot_tree(dt_viz, feature_names=iris.feature_names, 
          class_names=iris.target_names, filled=True, 
          rounded=True, fontsize=10)
plt.title("Decision Tree Visualization")
plt.show()

# Decision paths for a sample
sample_idx = 5
sample = X_test.iloc[sample_idx:sample_idx+1]
path = dt_viz.decision_path(sample)

# Display decision path
feature_importances = []
node_indicator = path.indices
for i, node_index in enumerate(node_indicator):
    if i == 0:  # Skip the root
        continue
    if i < len(node_indicator) - 1:  # Not a leaf node
        feature = dt_viz.tree_.feature[node_index]
        threshold = dt_viz.tree_.threshold[node_index]
        feature_name = iris.feature_names[feature]
        feature_value = sample.iloc[0, feature]
        feature_importances.append((feature_name, feature_value, threshold))

print("\nDecision path for sample:")
for feat, val, thresh in feature_importances:
    comparison = "<=" if val <= thresh else ">"
    print(f"- {feat} = {val:.2f} {comparison} {thresh:.2f}")
print(f"Predicted class: {iris.target_names[dt_viz.predict(sample)[0]]}")
```

## Random Forests: Ensemble Learning

Random Forests combine multiple decision trees to improve prediction accuracy and reduce overfitting. Each tree is built on a random subset of the data and features.

### Key Characteristics:

- **Bagging (Bootstrap Aggregating)**: Each tree uses a random sample of data points
- **Feature Randomness**: Each tree uses a random subset of features
- **Voting/Averaging**: Classification uses majority vote, regression uses average

```python
# Create a Random Forest Classifier
rf_clf = RandomForestClassifier(n_estimators=100, random_state=42)

# Train the model
rf_clf.fit(X_train, y_train)

# Make predictions
y_pred_rf = rf_clf.predict(X_test)

# Evaluate the Random Forest
rf_accuracy = accuracy_score(y_test, y_pred_rf)
print(f"Random Forest Classification Accuracy: {rf_accuracy:.4f}")
print("\nRandom Forest Classification Report:")
print(classification_report(y_test, y_pred_rf, target_names=iris.target_names))

# Compare with single decision tree
print(f"\nDecision Tree Accuracy: {accuracy:.4f}")
print(f"Random Forest Accuracy: {rf_accuracy:.4f}")
print(f"Improvement: {(rf_accuracy - accuracy) * 100:.2f}%")
```

## Tuning Hyperparameters

Both Decision Trees and Random Forests have multiple hyperparameters that can be tuned for better performance:

```python
# Define hyperparameter grid for Random Forest
param_grid = {
    'n_estimators': [50, 100, 200],
    'max_depth': [None, 10, 20, 30],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 2, 4]
}

# Create a smaller grid for demonstration purposes
small_param_grid = {
    'n_estimators': [50, 100],
    'max_depth': [None, 10],
    'min_samples_split': [2, 5]
}

# Grid search with cross-validation
grid_search = GridSearchCV(
    estimator=RandomForestClassifier(random_state=42),
    param_grid=small_param_grid,
    cv=5,
    scoring='accuracy',
    verbose=1,
    n_jobs=-1
)

# Fit grid search
grid_search.fit(X_train, y_train)

# Best parameters and score
print("Best parameters:", grid_search.best_params_)
print("Best cross-validation score: {:.4f}".format(grid_search.best_score_))

# Evaluate the best model
best_rf = grid_search.best_estimator_
best_accuracy = best_rf.score(X_test, y_test)
print(f"Test accuracy with best model: {best_accuracy:.4f}")

# Cross-validation to assess model robustness
cv_scores = cross_val_score(best_rf, X_iris, y_iris, cv=5)
print("Cross-validation scores:", cv_scores)
print(f"Mean CV accuracy: {cv_scores.mean():.4f}")
print(f"CV accuracy standard deviation: {cv_scores.std():.4f}")
```

## Practical Applications

Decision Trees and Random Forests have numerous real-world applications:

```python
# Load a real-world dataset - breast cancer
from sklearn.datasets import load_breast_cancer

cancer = load_breast_cancer()
X_cancer = pd.DataFrame(cancer.data, columns=cancer.feature_names)
y_cancer = cancer.target

print("Cancer dataset shape:", X_cancer.shape)
print("Number of features:", X_cancer.shape[1])
print("Classes:", cancer.target_names)
print("Class distribution:", np.bincount(y_cancer))

# Split the data
X_train, X_test, y_train, y_test = train_test_split(
    X_cancer, y_cancer, test_size=0.3, random_state=42
)

# Train and evaluate Random Forest on cancer dataset
rf_cancer = RandomForestClassifier(n_estimators=100, random_state=42)
rf_cancer.fit(X_train, y_train)
y_pred = rf_cancer.predict(X_test)

# Evaluation
accuracy = accuracy_score(y_test, y_pred)
print(f"Cancer classification accuracy: {accuracy:.4f}")
print("\nClassification Report:")
print(classification_report(y_test, y_pred, target_names=cancer.target_names))

# Feature importance for cancer prediction
cancer_importances = pd.DataFrame({
    'Feature': cancer.feature_names,
    'Importance': rf_cancer.feature_importances_
}).sort_values(by='Importance', ascending=False).head(10)

plt.figure(figsize=(12, 8))
sns.barplot(x='Importance', y='Feature', data=cancer_importances)
plt.title('Top 10 Features for Breast Cancer Prediction')

plt.show()

# Probability predictions
y_proba = rf_cancer.predict_proba(X_test)
print("\nProbability predictions for first 5 samples:")
for i in range(5):
    print(f"Sample {i+1}: Malignant {y_proba[i,0]:.4f}, Benign {y_proba[i,1]:.4f}")
```

## Summary

Decision Trees and Random Forests are powerful and versatile machine learning algorithms:

1. **Decision Trees**:
   - Intuitive, easy to understand and visualize
   - Can handle both numerical and categorical features
   - Require minimal data preprocessing
   - Prone to overfitting on complex datasets
   - Provide feature importance metrics

2. **Random Forests**:
   - Ensemble technique combining multiple decision trees
   - Significantly reduces overfitting compared to single trees
   - Typically provides better prediction accuracy
   - Retains feature importance capabilities
   - More robust against noisy data

3. **Key Advantages**:
   - Minimal preprocessing requirements
   - Handles non-linear relationships well
   - Built-in feature selection
   - Works for both classification and regression
   - Natural handling of missing values

4. **Main Limitations**:
   - Random Forests can be computationally expensive
   - Less interpretable than single decision trees
   - Biased towards features with more levels in categorical data
   - May struggle with highly imbalanced datasets

5. **When to Use**:
   - When you need a model that's easy to interpret (Decision Tree)
   - When you need high predictive accuracy (Random Forest)
   - When dealing with complex feature interactions
   - When feature importance is needed
   
Random Forests remain one of the most widely used machine learning algorithms in practice due to their robust performance across many domains and relatively straightforward implementation.
