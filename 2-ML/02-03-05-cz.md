## Úvod do předpovídání časových řad

Předpovídání časových řad zahrnuje předpověď budoucích hodnot na základě dříve pozorovaných hodnot. Na rozdíl od tradičních regresních problémů mají data časových řad časové uspořádání, které je klíčové zohlednit. Předpovídání časových řad má aplikace v různých oblastech včetně financí, předpovědi počasí, předpovědi prodeje a plánování zdrojů.

## Komponenty časových řad a předzpracování

Časové řady se typicky skládají z několika komponent:
1. **Trend**: Celkový vzor řady
2. **Sezónnost**: Pravidelný vzor vzestupných a sestupných výkyvů
3. **Cykličnost**: Dlouhodobější změny, které nemají pevnou frekvenci
4. **Nepravidelnost**: Náhodné odchylky nebo šum

Kroky předzpracování dat časových řad zahrnují:
- Zpracování chybějících hodnot
- Převzorkování na jinou frekvenci
- Rozklad řady na komponenty
- Transformace k dosažení stacionarity

## Přístupy strojového učení pro časové řady

Mnoho tradičních algoritmů strojového učení lze adaptovat pro předpovídání časových řad:

1. **Lineární regrese**
2. **Náhodný les**
3. **Gradient boosting**
4. **Support Vector Regression**

Klíčem je transformovat data časových řad do problému učení s učitelem vytvořením příznaků z hodnot zpoždění.

```python
# Vytvoření funkce pro transformaci časové řady na problém učení s učitelem
def series_to_supervised(data, n_in=1, n_out=1, dropnan=True):
    """
    Transformuje časovou řadu na dataset pro učení s učitelem.
    - data: Sekvence pozorování
    - n_in: Počet zpožděných pozorování jako vstup (X)
    - n_out: Počet pozorování jako výstup (y)
    - dropnan: Boolean, zda odstranit řádky s NaN hodnotami
    """
    n_vars = 1 if type(data) is list else data.shape[1]
    df = pd.DataFrame(data)
    cols, names = list(), list()
    
    # Vstupní sekvence (t-n, ... t-1)
    for i in range(n_in, 0, -1):
        cols.append(df.shift(i))
        names += [f'var{j+1}(t-{i})' for j in range(n_vars)]
    
    # Sekvence předpovědi (t, t+1, ... t+n)
    for i in range(0, n_out):
        cols.append(df.shift(-i))
        if i == 0:
            names += [f'var{j+1}(t)' for j in range(n_vars)]
        else:
            names += [f'var{j+1}(t+{i})' for j in range(n_vars)]
    
    # Spojení všeho dohromady
    agg = pd.concat(cols, axis=1)
    agg.columns = names
    
    # Odstranění řádků s NaN hodnotami
    if dropnan:
        agg.dropna(inplace=True)
    return agg

# Aplikace transformace na naše data
supervised_data = series_to_supervised(df[['Passengers']], n_in=12, n_out=1)
supervised_data.head()

# Rozdělení na vstupní a výstupní data
X = supervised_data.iloc[:, :-1].values
y = supervised_data.iloc[:, -1].values

train_size = int(len(X) * 0.8)

y_train, y_test = y[:train_size], y[train_size:]

# Trénování různých modelů ML
from sklearn.ensemble import RandomForestRegressor, GradientBoostingRegressor
from sklearn.linear_model import LinearRegression
from sklearn.svm import SVR

# Lineární regrese
lr = LinearRegression()
lr.fit(X_train, y_train)
y_pred_lr = lr.predict(X_test)

# Náhodný les
rf = RandomForestRegressor(n_estimators=100, random_state=42)
rf.fit(X_train, y_train)
y_pred_rf = rf.predict(X_test)

# Gradient Boosting
gb = GradientBoostingRegressor(n_estimators=100, random_state=42)
gb.fit(X_train, y_train)
y_pred_gb = gb.predict(X_test)

# SVR
svr = SVR(kernel='rbf')
svr.fit(X_train, y_train)
y_pred_svr = svr.predict(X_test)

# Vyhodnocení modelů
models = {
    'Lineární regrese': y_pred_lr,
    'Náhodný les': y_pred_rf,
    'Gradient Boosting': y_pred_gb,
    'SVR': y_pred_svr
}

for name, predictions in models.items():
    rmse = math.sqrt(mean_squared_error(y_test, predictions))
    print(f'{name} RMSE: {rmse:.2f}')

# Vykreslení předpovědí

    plt.plot(predictions, label=f'{name} předpovědi')

plt.legend()
plt.grid(True)
plt.show()
```

## Tvorba příznaků pro časové řady

Tvorba příznaků je klíčová pro úspěšné předpovídání časových řad. Mezi běžné přístupy patří:

1. **Příznaky zpoždění**: Předchozí hodnoty cílové proměnné
2. **Statistiky plovoucího okna**: Průměr, std, min, max přes okna
3. **Sezónní příznaky**: Měsíc, den v týdnu, hodina dne
4. **Fourierovy příznaky**: Sinus a cosinus transformace pro sezónnost

```python
# Vytvoření pokročilých příznaků pro časové řady
def create_features(df):
    """
    Vytvoření příznaků pro časové řady na základě datetime indexu.
    """
    df = df.copy()
    
    # Příznaky založené na datu
    df['dayofweek'] = df.index.dayofweek
    df['quarter'] = df.index.quarter
    df['month'] = df.index.month
    df['year'] = df.index.year
    df['dayofyear'] = df.index.dayofyear
    
    # Příznaky zpoždění
    for lag in [1, 2, 3, 6, 12]:
        df[f'lag_{lag}'] = df['Passengers'].shift(lag)
    
    # Příznaky plovoucího okna
    for window in [3, 6, 12]:
        df[f'rolling_mean_{window}'] = df['Passengers'].rolling(window=window).mean()
        df[f'rolling_std_{window}'] = df['Passengers'].rolling(window=window).std()
        df[f'rolling_min_{window}'] = df['Passengers'].rolling(window=window).min()
        df[f'rolling_max_{window}'] = df['Passengers'].rolling(window=window).max()
    
    # Fourierovy příznaky pro sezónnost
    for period in [12]:  # Roční sezónnost pro měsíční data
        for order in range(1, 4):
            df[f'sin_{period}_{order}'] = np.sin(2 * np.pi * order * df.index.month / period)
            df[f'cos_{period}_{order}'] = np.cos(2 * np.pi * order * df.index.month / period)
    
    return df

# Aplikace tvorby příznaků
featured_df = create_features(df)
featured_df = featured_df.dropna()
print(featured_df.head())

# Rozdělení na příznaky a cílovou proměnnou
X = featured_df.drop('Passengers', axis=1)
y = featured_df['Passengers']

# Rozdělení na trénovací a testovací sady

X_train, X_test = X[:train_size], X[train_size:]
y_train, y_test = y[:train_size], y[train_size:]

# Trénování modelu s vytvořenými příznaky
from sklearn.ensemble import RandomForestRegressor

model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# Vyhodnocení
rmse = math.sqrt(mean_squared_error(y_test, y_pred))
print(f'Náhodný les s vytvořenými příznaky RMSE: {rmse:.2f}')

# Důležitost příznaků
feature_importance = pd.DataFrame({
    'feature': X.columns,
    'importance': model.feature_importances_
}).sort_values('importance', ascending=False)

plt.figure(figsize=(12, 6))
plt.barh(feature_importance['feature'][:10], feature_importance['importance'][:10])
plt.title('Top 10 důležitosti příznaků')
plt.xlabel('Důležitost')

plt.show()
```

## Hodnocení modelů pro předpovídání časových řad

Hodnocení modelů časových řad vyžaduje speciální přístupy:

1. **Validace na základě času**: Použití walk-forward validace
2. **Vhodné metriky**: RMSE, MAE, MAPE
3. **Statistické testy**: Porovnání vlastností reziduí předpovědi

```python
# Křížová validace časových řad pomocí TimeSeriesSplit
from sklearn.model_selection import TimeSeriesSplit
from sklearn.metrics import mean_absolute_error, mean_absolute_percentage_error

# Inicializace TimeSeriesSplit
tscv = TimeSeriesSplit(n_splits=5)

# Aplikace křížové validace s modelem Náhodného lesa
model = RandomForestRegressor(n_estimators=100, random_state=42)

# Ukládání výsledků
cv_results = {
    'RMSE': [],
    'MAE': [],
    'MAPE': []
}

# Vizualizace rozdělení
plt.figure(figsize=(12, 8))
for i, (train_index, test_index) in enumerate(tscv.split(X)):
    X_train_cv, X_test_cv = X.iloc[train_index], X.iloc[test_index]
    y_train_cv, y_test_cv = y.iloc[train_index], y.iloc[test_index]
    
    # Trénování modelu
    model.fit(X_train_cv, y_train_cv)
    
    # Vytvoření předpovědí
    y_pred_cv = model.predict(X_test_cv)
    
    # Výpočet metrik
    rmse = math.sqrt(mean_squared_error(y_test_cv, y_pred_cv))
    mae = mean_absolute_error(y_test_cv, y_pred_cv)
    mape = mean_absolute_percentage_error(y_test_cv, y_pred_cv)
    
    cv_results['RMSE'].append(rmse)
    cv_results['MAE'].append(mae)
    cv_results['MAPE'].append(mape)
    
    # Vykreslení tohoto rozdělení
    plt.subplot(5, 1, i+1)
    plt.plot(y.index[:len(y)], [None] * len(y), 'k-', label='Všechna data')
    plt.plot(y.index[train_index], y.iloc[train_index], 'b-', label='Trénovací sada')
    plt.plot(y.index[test_index], y.iloc[test_index], 'r-', label='Testovací sada')
    plt.title(f'Rozdělení {i+1}')
    if i == 0:
        plt.legend()

plt.tight_layout()
plt.show()

# Výpis průměrných výsledků metrik
for metric, values in cv_results.items():
    print(f'Průměrná {metric}: {np.mean(values):.4f}')

# Vyhodnocení reziduí pro statistické vlastnosti
residuals = y_test - y_pred

# Vykreslení reziduí
plt.figure(figsize=(12, 8))

# Graf časové řady reziduí
plt.subplot(2, 2, 1)
plt.plot(residuals)
plt.title('Rezidua v čase')
plt.axhline(y=0, color='r', linestyle='-')

# Histogram reziduí
plt.subplot(2, 2, 2)
plt.hist(residuals, bins=20)
plt.title('Distribuce reziduí')

# QQ graf reziduí
from scipy import stats
plt.subplot(2, 2, 3)
stats.probplot(residuals, dist="norm", plot=plt)
plt.title('Q-Q Plot')

# Autokorelace reziduí
from statsmodels.graphics.tsaplots import plot_acf
plt.subplot(2, 2, 4)

plt.tight_layout()
plt.show()
```

## Hluboké učení pro předpovídání časových řad

Přístupy hlubokého učení ukázaly vynikající výsledky pro předpovídání časových řad:

1. **Rekurentní neuronové sítě (RNN)**
2. **Long Short-Term Memory (LSTM)**
3. **Konvoluční neuronové sítě pro časové řady**
4. **Modely založené na transformerech**

```python
# LSTM pro předpovídání časových řad
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, LSTM
from sklearn.preprocessing import MinMaxScaler

# Normalizace dat
scaler = MinMaxScaler(feature_range=(0, 1))
scaled_data = scaler.fit_transform(df['Passengers'].values.reshape(-1, 1))

# Vytvoření sekvencí pro LSTM
def create_sequences(data, seq_length):
    X, y = [], []
    for i in range(len(data) - seq_length):
        X.append(data[i:i + seq_length])
        y.append(data[i + seq_length])
    return np.array(X), np.array(y)

# Nastavení délky sekvence
seq_length = 12
X, y = create_sequences(scaled_data, seq_length)

# Rozdělení na trénovací/testovací data
train_size = int(len(X) * 0.8)
X_train, X_test = X[:train_size], X[train_size:]
y_train, y_test = y[:train_size], y[train_size:]

# Vytvoření modelu LSTM
model = Sequential()
model.add(LSTM(50, activation='relu', input_shape=(X_train.shape[1], X_train.shape[2])))
model.add(Dense(1))
model.compile(optimizer='adam', loss='mse')

# Trénování modelu
history = model.fit(
    X_train, y_train,
    epochs=50,
    batch_size=32,
    validation_split=0.2,
    verbose=1
)

# Vykreslení křivek učení
plt.figure(figsize=(12, 6))
plt.plot(history.history['loss'], label='Trénovací ztráta')
plt.plot(history.history['val_loss'], label='Validační ztráta')
plt.title('Ztráta modelu LSTM')
plt.xlabel('Epochy')
plt.ylabel('Ztráta')
plt.legend()
plt.grid(True)
plt.show()

# Vytvoření předpovědí
y_pred_scaled = model.predict(X_test)

# Inverzní transformace do původního měřítka
y_pred = scaler.inverse_transform(y_pred_scaled)
y_test_actual = scaler.inverse_transform(y_test)

# Výpočet RMSE
lstm_rmse = math.sqrt(mean_squared_error(y_test_actual, y_pred))
print(f'LSTM RMSE: {lstm_rmse:.2f}')

# Vykreslení předpovědí vs. skutečnost
plt.figure(figsize=(12, 6))
plt.plot(df.index[train_size+seq_length:], y_test_actual, label='Skutečnost')
plt.plot(df.index[train_size+seq_length:], y_pred, label='LSTM předpovědi')
plt.title('Výsledky předpovědi LSTM')
plt.xlabel('Datum')
plt.ylabel('Cestující')
plt.legend()
plt.grid(True)
plt.show()
```

## Práce s více časovými řadami

```python
# Shlukování časových řad

X_for_clustering = np.column_stack([df_multi[col].values for col in df_multi.columns]).T

# Aplikace K-means shlukování
kmeans = KMeans(n_clusters=2, random_state=42)
clusters = kmeans.fit_predict(X_for_clustering)

# Vizualizace shluků
plt.figure(figsize=(12, 6))
for i, col in enumerate(df_multi.columns):
    plt.plot(df_multi.index, df_multi[col], label=f'{col} (Shluk {clusters[i]})', 
             color=f'C{clusters[i]}')
plt.title('Shluky časových řad')
plt.legend()
plt.grid(True)
plt.show()

# Globální model pro více časových řad
# Poskládání všech řad do jednoho dataframe s identifikátorem řady
stacked_df = pd.DataFrame()
for col in df_multi.columns:
    temp_df = pd.DataFrame({
        'value': df_multi[col],
        'series_id': col
    })
    stacked_df = pd.concat([stacked_df, temp_df])

# Vytvoření časových příznaků
stacked_df['dayofweek'] = stacked_df.index.dayofweek
stacked_df['month'] = stacked_df.index.month
stacked_df['year'] = stacked_df.index.year

# One-hot kódování identifikátoru řady
stacked_df = pd.get_dummies(stacked_df, columns=['series_id'])

# Trénování globálního modelu
train_size = int(len(df_multi) * 0.8)
train_idx = stacked_df.index.unique()[:train_size]
test_idx = stacked_df.index.unique()[train_size:]

train = stacked_df.loc[train_idx]
test = stacked_df.loc[test_idx]

X_train = train.drop('value', axis=1)
y_train = train['value']
X_test = test.drop('value', axis=1)
y_test = test['value']

from sklearn.ensemble import RandomForestRegressor
global_model = RandomForestRegressor(n_estimators=100, random_state=42)
global_model.fit(X_train, y_train)

# Vytvoření předpovědí
y_pred_global = global_model.predict(X_test)

# Výpočet RMSE pro každou řadu
test_with_pred = test.copy()
test_with_pred['prediction'] = y_pred_global

for col in df_multi.columns:
    series_mask = test_with_pred[f'series_id_{col}'] == 1
    y_true = test_with_pred.loc[series_mask, 'value']
    y_pred = test_with_pred.loc[series_mask, 'prediction']
    rmse = math.sqrt(mean_squared_error(y_true, y_pred))
    print(f'Globální model RMSE pro {col}: {rmse:.4f}')
```

```python
# Příklad: Předpověď cen akcií
import yfinance as yf

# Stažení dat akcií
stock_data = yf.download('AAPL', start='2018-01-01', end='2023-01-01')
stock_df = stock_data[['Close']].copy()

# Vytvoření příznaků pro předpovídání cen akcií
def create_stock_features(df):
    df = df.copy()
    
    # Technické indikátory
    # Klouzavé průměry
    for window in [5, 20, 50]:
        df[f'ma_{window}'] = df['Close'].rolling(window=window).mean()
    
    # Volatilita (směrodatná odchylka)
    for window in [5, 20]:
        df[f'volatility_{window}'] = df['Close'].rolling(window=window).std()
    
    # Relative Strength Index (RSI)
    delta = df['Close'].diff()
    gain = delta.where(delta > 0, 0)
    loss = -delta.where(delta < 0, 0)
    avg_gain = gain.rolling(window=14).mean()
    avg_loss = loss.rolling(window=14).mean()
    rs = avg_gain / avg_loss
    df['rsi_14'] = 100 - (100 / (1 + rs))
    
    # Momentum ceny
    for window in [5, 20]:
        df[f'momentum_{window}'] = df['Close'] - df['Close'].shift(window)
    
    # Příznaky data
    df['dayofweek'] = df.index.dayofweek
    df['month'] = df.index.month
    df['year'] = df.index.year
    
    # Cíl: uzavírací cena následujícího dne
    df['target'] = df['Close'].shift(-1)
    
    return df

# Aplikace tvorby příznaků
stock_features = create_stock_features(stock_df)
stock_features = stock_features.dropna()

# Příprava dat
X = stock_features.drop(['Close', 'target'], axis=1)
y = stock_features['target']

# Rozdělení na trénovací a testovací data
train_size = int(len(X) * 0.8)
X_train, X_test = X[:train_size], X[train_size:]
y_train, y_test = y[:train_size], y[train_size:]

# Trénování modelu
from sklearn.ensemble import GradientBoostingRegressor
stock_model = GradientBoostingRegressor(n_estimators=100, random_state=42)
stock_model.fit(X_train, y_train)
stock_pred = stock_model.predict(X_test)

# Vyhodnocení
stock_rmse = math.sqrt(mean_squared_error(y_test, stock_pred))
print(f'RMSE předpovědi cen akcií: {stock_rmse:.2f}')

# Vykreslení předpovědí vs. skutečnost
plt.figure(figsize=(12, 6))
plt.plot(y_test.index, y_test, label='Skutečná cena akcie')
plt.plot(y_test.index, stock_pred, label='Předpovězená cena akcie')
plt.title('Předpovídání cen akcií')
plt.xlabel('Datum')
plt.ylabel('Cena akcie')
plt.legend()
plt.grid(True)
plt.show()

# Důležitost příznaků pro předpovídání cen akcií
stock_importance = pd.DataFrame({
    'feature': X.columns,
    'importance': stock_model.feature_importances_
}).sort_values('importance', ascending=False)

plt.figure(figsize=(12, 6))
plt.barh(stock_importance['feature'][:10], stock_importance['importance'][:10])
plt.title('Top 10 příznaků pro predikci cen akcií')
plt.xlabel('Důležitost')
plt.tight_layout()
plt.show()
```

4. **Metody hodnocení**: Předpovídání časových řad vyžaduje specializované strategie hodnocení, jako je křížová validace časových řad a metriky vhodné pro daný úkol.

6. **Předpovídání více řad**: Při práci s více souvisejícími časovými řadami mohou globální modely nebo hierarchické přístupy zlepšit přesnost předpovědi.
