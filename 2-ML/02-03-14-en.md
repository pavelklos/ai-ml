## Introduction to Graph Neural Networks

Graph Neural Networks (GNNs) are a class of deep learning models designed to work with graph-structured data. Unlike standard neural networks that operate on regular grid-like data (such as images or sequences), GNNs can process data represented as graphs with nodes (vertices) and edges.

Graphs are a powerful way to represent many real-world systems:
- Social networks (users as nodes, friendships as edges)
- Molecules (atoms as nodes, bonds as edges)
- Citation networks (papers as nodes, citations as edges)
- Knowledge graphs (entities as nodes, relationships as edges)
- Protein interaction networks
- Transportation networks

GNNs can learn representations (embeddings) of nodes, edges, and entire graphs while preserving the structural information.

## Graph Representation in Machine Learning

Before diving into GNNs, it's important to understand how graphs can be represented in a format suitable for machine learning.

### Adjacency Matrix

The adjacency matrix A is an n×n matrix (where n is the number of nodes) with entries A[i,j]=1 if there is an edge from node i to node j, and 0 otherwise.

### Node Features

Each node in the graph can have associated features represented as a vector. For the entire graph, this gives us a node feature matrix X of size n×d, where d is the feature dimension.

### Edge Features

Similarly, edges can have features represented as a tensor of size m×c, where m is the number of edges and c is the edge feature dimension.

## Types of Graph Neural Networks

Several types of GNNs have been developed, each with their own approach to learning from graph-structured data:

### Graph Convolutional Networks (GCNs)

GCNs generalize convolutional operations to graph data. They perform localized feature averaging using the graph structure.

### Graph Attention Networks (GATs)

GATs incorporate attention mechanisms to weigh the importance of different neighboring nodes when aggregating information.

### GraphSAGE

GraphSAGE (Sample and AggreGatE) uses neighborhood sampling and aggregation techniques for inductive representation learning on large graphs.

### Graph Isomorphism Networks (GINs)

GINs are designed to have the maximum discriminative power among GNNs for distinguishing different graph structures.

```python
# Simplified pseudocode demonstrating different GNN layers
import torch.nn as nn
import torch.nn.functional as F

# Simple GCN layer
class GCNLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super(GCNLayer, self).__init__()
        self.linear = nn.Linear(in_features, out_features)
        
    def forward(self, x, adj):
        # Normalize adjacency matrix
        D_inv_sqrt = torch.diag(torch.pow(torch.sum(adj, dim=1), -0.5))
        adj_normalized = D_inv_sqrt @ adj @ D_inv_sqrt
        
        # Graph convolution
        support = self.linear(x)
        output = torch.matmul(adj_normalized, support)
        return F.relu(output)

# Simple GAT layer (pseudo-implementation)
class GATLayer(nn.Module):
    def __init__(self, in_features, out_features, dropout, alpha, concat=True):
        super(GATLayer, self).__init__()
        self.linear = nn.Linear(in_features, out_features)
        self.attention = nn.Linear(2 * out_features, 1)
        
    def forward(self, x, adj):
        # Linear transformation
        h = self.linear(x)
        
        # Compute attention coefficients
        # (simplified implementation)
        N = h.size()[0]
        a_input = torch.cat([h.repeat(1, N).view(N * N, -1), 
                             h.repeat(N, 1)], dim=1).view(N, N, -1)
        e = F.leaky_relu(self.attention(a_input).squeeze(2))
        
        # Mask attention coefficients using adjacency matrix
        zero_vec = -9e15 * torch.ones_like(e)
        attention = torch.where(adj > 0, e, zero_vec)
        attention = F.softmax(attention, dim=1)
        
        # Apply attention
        h_prime = torch.matmul(attention, h)
        
        return F.elu(h_prime)
```

## Message Passing Neural Networks

At the core of most GNNs is the concept of message passing, where nodes iteratively update their representations by aggregating information from their neighbors. The general message passing framework consists of:

1. **Message generation**: Computing messages based on node features and edges
2. **Message aggregation**: Combining messages from neighbors
3. **Update function**: Updating node representations based on aggregated messages

This process is typically performed for multiple rounds (layers), allowing information to propagate through the graph.

```python
# Generic message passing layer implementation
class MessagePassingLayer(nn.Module):
    def __init__(self, in_channels, out_channels):
        super(MessagePassingLayer, self).__init__()
        self.message_fn = nn.Linear(in_channels * 2, out_channels)  # Message function
        self.update_fn = nn.Linear(in_channels + out_channels, out_channels)  # Update function
        
    def forward(self, x, edge_index):
        # x: Node features [num_nodes, in_channels]
        # edge_index: Graph connectivity [2, num_edges]
        
        num_nodes = x.size(0)
        
        # Step 1: Message generation
        source_nodes, target_nodes = edge_index
        source_features = x[source_nodes]
        target_features = x[target_nodes]
        edge_features = torch.cat([source_features, target_features], dim=1)
        messages = F.relu(self.message_fn(edge_features))
        
        # Step 2: Message aggregation (sum)
        aggregated_messages = torch.zeros(num_nodes, messages.size(1)).to(x.device)
        aggregated_messages.index_add_(0, target_nodes, messages)
        
        # Step 3: Update node features
        combined = torch.cat([x, aggregated_messages], dim=1)
        updated_features = F.relu(self.update_fn(combined))
        
        return updated_features
```

```python
        self.conv2 = GCNConv(hidden_channels, out_channels)

class GAT(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels, heads=8):
        super(GAT, self).__init__()
        self.conv1 = GATConv(in_channels, hidden_channels, heads=heads)
        self.conv2 = GATConv(hidden_channels * heads, out_channels)
        
    def forward(self, x, edge_index):
        # First Graph Attention layer
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.6, training=self.training)
        
        # Second Graph Attention layer
        x = self.conv2(x, edge_index)
        
        return x
```

## Node Classification Tasks

One of the primary applications of GNNs is node classification, where the goal is to predict the labels of nodes in a graph. For example, in a citation network, we might want to predict the research category of each paper.

```python
# Complete example of node classification with GCN
import torch
import torch.nn.functional as F
from torch_geometric.nn import GCNConv
from torch_geometric.datasets import Planetoid
import matplotlib.pyplot as plt

# Load dataset
dataset = Planetoid(root='./data/Cora', name='Cora')
data = dataset[0]

# Define GCN model
class GCN(torch.nn.Module):
    def __init__(self):
        super(GCN, self).__init__()
        self.conv1 = GCNConv(dataset.num_features, 16)
        self.conv2 = GCNConv(16, dataset.num_classes)

    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)

# Initialize model, optimizer
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCN().to(device)
data = data.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)

# Training function
def train():
    model.train()
    optimizer.zero_grad()
    out = model(data.x, data.edge_index)
    loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
    loss.backward()
    optimizer.step()
    return loss.item()

# Evaluation function
def test():
    model.eval()
    logits, accs = model(data.x, data.edge_index), []
    for _, mask in data('train_mask', 'val_mask', 'test_mask'):
        pred = logits[mask].max(1)[1]
        acc = pred.eq(data.y[mask]).sum().item() / mask.sum().item()
        accs.append(acc)
    return accs

# Training loop
best_val_acc = 0
train_losses = []
for epoch in range(200):
    loss = train()
    train_losses.append(loss)
    train_acc, val_acc, test_acc = test()
    if val_acc > best_val_acc:
        best_val_acc = val_acc
        best_test_acc = test_acc
    
    if epoch % 20 == 0:
        print(f'Epoch: {epoch}, Loss: {loss:.4f}, Train: {train_acc:.4f}, '
              f'Val: {val_acc:.4f}, Test: {test_acc:.4f}')

print(f'Best validation accuracy: {best_val_acc:.4f}')
print(f'Test accuracy: {best_test_acc:.4f}')

# Plot training loss
plt.figure(figsize=(8, 6))
plt.plot(train_losses)
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('Training Loss')
plt.show()

    embeds = model.conv1(data.x, data.edge_index).cpu().numpy()

# Perform t-SNE dimensionality reduction
```

## Graph Classification Tasks

Graph classification involves predicting properties of entire graphs rather than individual nodes. Examples include molecular property prediction (e.g., toxicity or solubility) or protein function classification.

```python
# Graph classification with PyTorch Geometric
import torch
from torch.nn import Linear
import torch.nn.functional as F
from torch_geometric.nn import GCNConv, global_mean_pool
from torch_geometric.datasets import TUDataset
from torch_geometric.loader import DataLoader

# Load a molecular dataset (MUTAG)
dataset = TUDataset(root='./data/TUDataset', name='MUTAG')

# Split dataset
torch.manual_seed(42)
dataset = dataset.shuffle()
train_dataset = dataset[:150]
test_dataset = dataset[150:]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

print(f"Dataset: {dataset}:")
print(f"Number of graphs: {len(dataset)}")
print(f"Number of features: {dataset.num_features}")
print(f"Number of classes: {dataset.num_classes}")
print(f"Average nodes per graph: {sum(data.num_nodes for data in dataset) / len(dataset):.2f}")

# Define a graph classification model
class GCNGraph(torch.nn.Module):
    def __init__(self):
        super(GCNGraph, self).__init__()
        self.conv1 = GCNConv(dataset.num_features, 32)
        self.conv2 = GCNConv(32, 64)
        self.lin = Linear(64, dataset.num_classes)
        
    def forward(self, x, edge_index, batch):
        # Node feature extraction
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.conv2(x, edge_index)
        
        # Readout: graph-level pooling
        x = global_mean_pool(x, batch)  # [batch_size, hidden_channels]
        
        # Final classifier
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.lin(x)
        return x

# Initialize model, optimizer
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = GCNGraph().to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

def train():
    model.train()
    total_loss = 0
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = F.cross_entropy(out, data.y)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * data.num_graphs
    return total_loss / len(train_dataset)

def test(loader):
    model.eval()
    correct = 0
    for data in loader:
        data = data.to(device)
        out = model(data.x, data.edge_index, data.batch)
        pred = out.argmax(dim=1)
        correct += int((pred == data.y).sum())
    return correct / len(loader.dataset)

# Training loop
for epoch in range(1, 101):
    loss = train()
    train_acc = test(train_loader)
    test_acc = test(test_loader)
    if epoch % 10 == 0:
        print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, '
              f'Train Acc: {train_acc:.4f}, Test Acc: {test_acc:.4f}')
```

## Link Prediction with GNNs

Link prediction aims to predict missing links or future connections in a graph. This is useful for recommendation systems, knowledge graph completion, and predicting protein interactions.

```python
# Link prediction with GNNs
import torch
from torch_geometric.nn import GCNConv
from torch_geometric.utils import train_test_split_edges, negative_sampling
from torch_geometric.datasets import Planetoid
import torch.nn.functional as F

# Load dataset
dataset = Planetoid(root='./data/Cora', name='Cora')
data = dataset[0]

# Split edges for training, validation and testing
data = train_test_split_edges(data)

# Define the link prediction model
class LinkPredictionGNN(torch.nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super(LinkPredictionGNN, self).__init__()
        self.conv1 = GCNConv(in_channels, hidden_channels)
        self.conv2 = GCNConv(hidden_channels, out_channels)
    
    def encode(self, x, edge_index):
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, p=0.2, training=self.training)
        x = self.conv2(x, edge_index)
        return x
    
    def decode(self, z, edge_index):
        # Inner product between node embeddings to predict links
        row, col = edge_index
        return (z[row] * z[col]).sum(dim=1)
    
    def decode_all(self, z):
        # Compute pairwise distances between all node embeddings
        prob_adj = torch.matmul(z, z.t())
        return prob_adj

# Initialize model, optimizer
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model = LinkPredictionGNN(dataset.num_features, 128, 64).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
data = data.to(device)

def get_link_labels(pos_edge_index, neg_edge_index):
    # Link labels: positive links are 1, negative links are 0
    E = pos_edge_index.size(1) + neg_edge_index.size(1)
    link_labels = torch.zeros(E, dtype=torch.float, device=device)
    link_labels[:pos_edge_index.size(1)] = 1.
    return link_labels

def train():
    model.train()
    optimizer.zero_grad()
    
    # Node embeddings
    z = model.encode(data.x, data.train_pos_edge_index)
    
    # Sample negative edges
    neg_edge_index = negative_sampling(
        edge_index=data.train_pos_edge_index,
        num_nodes=data.num_nodes,
        num_neg_samples=data.train_pos_edge_index.size(1))
    
    edge_index = torch.cat([data.train_pos_edge_index, neg_edge_index], dim=-1)
    link_logits = model.decode(z, edge_index)
    link_labels = get_link_labels(data.train_pos_edge_index, neg_edge_index)
    
    loss = F.binary_cross_entropy_with_logits(link_logits, link_labels)
    loss.backward()
    optimizer.step()
    
    return loss

@torch.no_grad()
def test():
    model.eval()
    z = model.encode(data.x, data.train_pos_edge_index)
    
    results = []
    for prefix in ['val', 'test']:
        pos_edge_index = data[f'{prefix}_pos_edge_index']
        neg_edge_index = data[f'{prefix}_neg_edge_index']
        edge_index = torch.cat([pos_edge_index, neg_edge_index], dim=-1)
        link_logits = model.decode(z, edge_index)
        link_probs = link_logits.sigmoid()
        link_labels = get_link_labels(pos_edge_index, neg_edge_index)
        
        # Compute AUC score
        from sklearn.metrics import roc_auc_score
        results.append(roc_auc_score(link_labels.cpu(), link_probs.cpu()))
    
    return results

# Training loop
best_val_auc = 0
for epoch in range(1, 101):
    loss = train()
    val_auc, test_auc = test()
    if val_auc > best_val_auc:
        best_val_auc = val_auc
        best_test_auc = test_auc
    if epoch % 10 == 0:
        print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, '
              f'Val AUC: {val_auc:.4f}, Test AUC: {test_auc:.4f}')

print(f'Best validation AUC: {best_val_auc:.4f}')
print(f'Test AUC: {best_test_auc:.4f}')

# Visualize link predictions (only a subset for clarity)
import numpy as np
import networkx as nx
import matplotlib.pyplot as plt

model.eval()
z = model.encode(data.x, data.train_pos_edge_index)
prob_adj = model.decode_all(z).cpu().detach().numpy()

# Create a NetworkX graph from the predicted adjacency matrix
G_pred = nx.from_numpy_array(prob_adj[:20, :20])  # Only show first 20 nodes

plt.figure(figsize=(10, 8))
pos = nx.spring_layout(G_pred, seed=42)
edges = nx.draw_networkx_edges(
    G_pred, pos, width=[G_pred[u][v]['weight'] * 5 for u, v in G_pred.edges()]
)
nodes = nx.draw_networkx_nodes(G_pred, pos, node_color='lightblue', node_size=500)
labels = nx.draw_networkx_labels(G_pred, pos)
plt.title("Link Prediction Visualization (Higher Edge Width = Higher Probability)")
plt.show()
```

## Real-world Applications of GNNs

Graph Neural Networks have found applications across numerous domains:

GNNs help analyze user interactions, detect communities, and predict future connections in social networks.

Text can be represented as graphs (e.g., syntactic or semantic dependencies), allowing GNNs to enhance various NLP tasks.

```python
# Example: Molecular property prediction with GNNs
from torch_geometric.datasets import MoleculeNet
from torch_geometric.nn import GCNConv, global_add_pool
import torch.nn.functional as F
import torch

# Load a molecular dataset for property prediction
dataset = MoleculeNet(root='./data/MoleculeNet', name='ESOL')

train_dataset = dataset[:1128]
val_dataset = dataset[1128:1288]
test_dataset = dataset[1288:]

train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=32, shuffle=False)

# Define GNN model for regression
class MoleculeGNN(torch.nn.Module):
    def __init__(self):
        super(MoleculeGNN, self).__init__()
        self.conv1 = GCNConv(dataset.num_features, 64)
        self.conv2 = GCNConv(64, 64)
        self.conv3 = GCNConv(64, 64)
        self.lin = Linear(64, dataset.num_tasks)

        # Node embedding
        x = F.relu(self.conv1(x, edge_index))
        x = F.relu(self.conv2(x, edge_index))
        x = self.conv3(x, edge_index)
        
        # Graph pooling
        x = global_add_pool(x, batch)
        
        # Prediction head
        x = self.lin(x)
        return x

# Initialize model, optimizer

loss_fn = torch.nn.MSELoss()

    total_loss = 0
    for data in train_loader:
        data = data.to(device)
        optimizer.zero_grad()
        out = model(data.x, data.edge_index, data.batch)
        loss = loss_fn(out, data.y)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * data.num_graphs
    return total_loss / len(train_loader.dataset)

def evaluate(loader):
    model.eval()
    total_error = 0
    with torch.no_grad():
        for data in loader:
            data = data.to(device)
            out = model(data.x, data.edge_index, data.batch)
            total_error += F.mse_loss(out, data.y).item() * data.num_graphs
    return total_error / len(loader.dataset)

# Training loop
best_val_error = float('inf')
for epoch in range(1, 101):
    loss = train()
    val_error = evaluate(val_loader)
    if val_error < best_val_error:
        best_val_error = val_error
        test_error = evaluate(test_loader)
    if epoch % 10 == 0:
        print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, '
              f'Val Error: {val_error:.4f}, Test Error: {test_error:.4f}')

print(f'Best validation error: {best_val_error:.4f}')
print(f'Test error: {test_error:.4f}')
```

Graph Neural Networks provide a powerful framework for learning from graph-structured data, enabling advanced applications across numerous domains. Key takeaways:

1. GNNs leverage the graph structure to learn node, edge, and graph-level representations
2. The core mechanism behind GNNs is message passing between nodes
3. Several types of GNNs exist, including GCNs, GATs, GraphSAGE, and GINs
4. Common applications include node classification, graph classification, and link prediction
5. PyTorch Geometric provides a convenient framework for implementing GNNs

Future research directions in GNNs include:

- **Scalability**: Handling extremely large graphs
- **Expressiveness**: Developing more powerful GNN architectures
- **Explainability**: Understanding why GNNs make specific predictions
- **Dynamic graphs**: Better modeling of graphs that evolve over time
- **Integration with other models**: Combining GNNs with transformers, reinforcement learning, etc.

As the field continues to evolve, Graph Neural Networks will undoubtedly play an increasingly important role in machine learning applications involving structured data.
