## Úvod do redukce dimenzionality

Redukce dimenzionality označuje techniky pro snížení počtu příznaků v datovém souboru při zachování co největšího množství informací. Řeší "prokletí dimenzionality" - fenomén, kdy data s rostoucím počtem dimenzí řídnou, což ztěžuje jejich analýzu.

Klíčové výhody:
- Snížení výpočetní složitosti
- Odstranění multikolinearity
- Lepší možnosti vizualizace
- Zmírnění přeučení
- Redukce šumu

## Analýza hlavních komponent (PCA)

PCA je neřízená lineární technika redukce dimenzionality, která identifikuje směry (hlavní komponenty), které maximalizují rozptyl v datech. Tyto komponenty jsou navzájem ortogonální, přičemž první komponenta zachycuje největší rozptyl.

Klíčové koncepty:
- **Hlavní komponenty**: Ortogonální osy, které maximalizují rozptyl
- **Vlastní hodnoty**: Představují množství rozptylu vysvětleného každou komponentou
- **Poměr vysvětleného rozptylu**: Procento celkového rozptylu vysvětlené každou komponentou

Algoritmus PCA:
1. Standardizace dat
2. Výpočet kovarianční matice
3. Výpočet vlastních hodnot a vlastních vektorů
4. Seřazení vlastních vektorů podle klesajících vlastních hodnot
5. Výběr prvních k vlastních vektorů k vytvoření projekční matice
6. Transformace původních dat

```python
# Jednoduchá demonstrace PCA
# Generování korelovaných dat
n_samples = 1000
mean = [0, 0]
cov = [[2, 1.5], [1.5, 3]]  # Kovarianční matice (pozitivní korelace)
X = np.random.multivariate_normal(mean, cov, n_samples)

# Provedení PCA ručně
# Krok 1: Standardizace dat
X_std = (X - np.mean(X, axis=0)) / np.std(X, axis=0)

# Krok 2: Výpočet kovarianční matice
cov_matrix = np.cov(X_std.T)
print("Kovarianční matice:\n", cov_matrix)

# Krok 3: Výpočet vlastních hodnot a vlastních vektorů
eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)
print("\nVlastní hodnoty:", eigenvalues)
print("Vlastní vektory:\n", eigenvectors)

# Krok 4: Seřazení vlastních vektorů podle klesajících vlastních hodnot
# Vytvoření dvojic (vlastní hodnota, vlastní vektor)
eig_pairs = [(np.abs(eigenvalues[i]), eigenvectors[:, i]) for i in range(len(eigenvalues))]
# Seřazení dvojic podle vlastní hodnoty sestupně
eig_pairs.sort(key=lambda x: x[0], reverse=True)

# Krok 5: Výpočet poměru vysvětleného rozptylu
total_variance = sum(eigenvalues)
explained_variance_ratio = [eigval / total_variance for eigval in sorted(eigenvalues, reverse=True)]
print("\nPoměr vysvětleného rozptylu:", explained_variance_ratio)

# Krok 6: Transformace dat
projection_matrix = np.hstack([eig_pairs[0][1].reshape(2, 1), eig_pairs[1][1].reshape(2, 1)])
X_pca = X_std.dot(projection_matrix)

# Vizualizace původních dat a hlavních komponent
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.scatter(X[:, 0], X[:, 1], alpha=0.3)
plt.title('Původní data')
plt.xlabel('Příznak 1')
plt.ylabel('Příznak 2')

# Vykreslení os odpovídajících vlastním vektorům
for eigenvector, color in zip(eigenvectors.T, ['red', 'green']):
    plt.quiver(0, 0, eigenvector[0]*eigenvalues[0], eigenvector[1]*eigenvalues[0], 
               angles='xy', scale_units='xy', scale=1, color=color, label=f'PC{i+1}')

plt.subplot(1, 2, 2)
plt.scatter(X_pca[:, 0], X_pca[:, 1], alpha=0.3)
plt.title('Data transformovaná pomocí PCA')
plt.xlabel('Hlavní komponenta 1')
plt.ylabel('Hlavní komponenta 2')
plt.tight_layout()
plt.show()
```

## Lineární diskriminační analýza (LDA)

Na rozdíl od PCA je Lineární diskriminační analýza (LDA) řízenou technikou redukce dimenzionality. Snaží se najít lineární kombinaci příznaků, která maximalizuje oddělení různých tříd.

Klíčové koncepty:
- **Matice mezitřídního rozptylu**: Měří rozptyl mezi středními hodnotami tříd
- **Matice vnitrotřídního rozptylu**: Měří rozptyl uvnitř každé třídy
- **Diskriminační osy**: Směry, které maximalizují mezitřídní rozptyl a minimalizují vnitrotřídní rozptyl

Algoritmus LDA:
1. Výpočet středních vektorů pro každou třídu
2. Výpočet matic mezitřídního a vnitrotřídního rozptylu
3. Výpočet vlastních hodnot a vlastních vektorů matice SW^(-1)SB
4. Seřazení vlastních vektorů podle klesajících vlastních hodnot
5. Výběr prvních k vlastních vektorů k vytvoření projekční matice
6. Transformace původních dat

```python
# Načtení datasetu iris pro demonstraci
iris = load_iris()
X = iris.data
y = iris.target
class_names = iris.target_names

# Standardizace dat
scaler = StandardScaler()
X_std = scaler.fit_transform(X)

# Výpočet středních vektorů pro každou třídu
mean_vectors = []
for cl in range(len(class_names)):
    mean_vectors.append(np.mean(X_std[y==cl], axis=0))
    print(f"Střední vektor {class_names[cl]}: {mean_vectors[cl]}")

# Výpočet matice vnitrotřídního rozptylu
S_W = np.zeros((X_std.shape[1], X_std.shape[1]))
for cl, mv in zip(range(len(class_names)), mean_vectors):
    class_sc_mat = np.zeros((X_std.shape[1], X_std.shape[1]))
    for row in X_std[y == cl]:
        row, mv = row.reshape(X_std.shape[1], 1), mv.reshape(X_std.shape[1], 1)
        class_sc_mat += (row - mv).dot((row - mv).T)
    S_W += class_sc_mat

# Výpočet matice mezitřídního rozptylu
overall_mean = np.mean(X_std, axis=0)
S_B = np.zeros((X_std.shape[1], X_std.shape[1]))
for i, mean_vec in enumerate(mean_vectors):
    n = X_std[y==i].shape[0]
    mean_vec = mean_vec.reshape(X_std.shape[1], 1)
    overall_mean = overall_mean.reshape(X_std.shape[1], 1)
    S_B += n * (mean_vec - overall_mean).dot((mean_vec - overall_mean).T)

# Výpočet vlastních hodnot a vlastních vektorů
eigen_values, eigen_vectors = np.linalg.eig(np.linalg.inv(S_W).dot(S_B))

# Seřazení vlastních vektorů podle klesajících vlastních hodnot
eigen_pairs = [(np.abs(eigen_values[i]), eigen_vectors[:,i]) for i in range(len(eigen_values))]
eigen_pairs = sorted(eigen_pairs, key=lambda k: k[0], reverse=True)

print('Vlastní hodnoty v sestupném pořadí:\n')
for eigen_val in eigen_pairs:
    print(eigen_val[0])

# Vytvoření projekční matice (první 2 vlastní vektory)
W = np.hstack((eigen_pairs[0][1].reshape(4,1), eigen_pairs[1][1].reshape(4,1)))

# Transformace dat
X_lda = X_std.dot(W)

# Vykreslení transformovaných dat
plt.figure()
colors = ['navy', 'turquoise', 'darkorange']
for color, i, target_name in zip(colors, [0, 1, 2], class_names):
    plt.scatter(X_lda[y == i, 0], X_lda[y == i, 1], alpha=.8, color=color, label=target_name)
plt.title('LDA datasetu Iris')
plt.xlabel('LD1')
plt.ylabel('LD2')
plt.legend(loc='best')
plt.show()
```

## Porovnání PCA a LDA

PCA a LDA se liší ve svých cílech a přístupu:

| Aspekt | PCA | LDA |
|--------|-----|-----|
| Typ | Neřízené učení | Řízené učení |
| Cíl | Maximalizace rozptylu | Maximalizace oddělení tříd |
| Vstup | Pouze příznaky | Příznaky a štítky |
| Transformace | Ortogonální | Ne nutně ortogonální |
| Max. počet komponent | min(n_samples, n_features) - 1 | n_classes - 1 |
| Nejvhodnější pro | Komprese dat, redukce šumu | Klasifikační úlohy |

```python
# Načtení datasetu Wine
wine = load_wine()
X = wine.data
y = wine.target
feature_names = wine.feature_names
target_names = wine.target_names

# Rozdělení dat pro vyhodnocení
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Vytvoření pipeline pro porovnání
pca_pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('pca', PCA(n_components=2)),
    ('classifier', RandomForestClassifier(random_state=42))
])

lda_pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('lda', LDA(n_components=2)),
    ('classifier', RandomForestClassifier(random_state=42))
])

# Trénování a vyhodnocení
pca_pipeline.fit(X_train, y_train)
lda_pipeline.fit(X_train, y_train)

y_pred_pca = pca_pipeline.predict(X_test)
y_pred_lda = lda_pipeline.predict(X_test)

print("Přesnost PCA + RandomForest:", accuracy_score(y_test, y_pred_pca))
print("Přesnost LDA + RandomForest:", accuracy_score(y_test, y_pred_lda))

print("\nKlasifikační zpráva PCA + RandomForest:")
print(classification_report(y_test, y_pred_pca))

print("\nKlasifikační zpráva LDA + RandomForest:")
print(classification_report(y_test, y_pred_lda))
```

## Implementace PCA v Pythonu

Scikit-learn poskytuje efektivní implementaci PCA, kterou je snadné použít:

```python
# Načtení vysokodimenzionálního datasetu (obličeje)
faces = fetch_olivetti_faces()
X = faces.data
y = faces.target

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Škálování dat
scaler = StandardScaler()
X_train_std = scaler.fit_transform(X_train)
X_test_std = scaler.transform(X_test)

# Aplikace PCA s různým počtem komponent
n_components_list = [10, 20, 50, 100, 200]
accuracies = []

for n_components in n_components_list:
    # Aplikace PCA
    pca = PCA(n_components=n_components)
    X_train_pca = pca.fit_transform(X_train_std)
    X_test_pca = pca.transform(X_test_std)
    
    # Výpočet kumulativního vysvětleného rozptylu
    cumulative_variance = np.cumsum(pca.explained_variance_ratio_)
    print(f"PCA s {n_components} komponentami vysvětluje {cumulative_variance[-1]*100:.2f}% rozptylu")
    
    # Trénování klasifikátoru
    clf = RandomForestClassifier(random_state=42)
    clf.fit(X_train_pca, y_train)
    
    # Vyhodnocení
    y_pred = clf.predict(X_test_pca)
    acc = accuracy_score(y_test, y_pred)
    accuracies.append(acc)
    print(f"Přesnost s {n_components} komponentami: {acc:.4f}")

# Vykreslení výsledků
plt.figure(figsize=(10, 6))
plt.plot(n_components_list, accuracies, marker='o')
plt.title('Přesnost vs. počet PCA komponent')
plt.xlabel('Počet komponent')
plt.ylabel('Přesnost')
plt.grid(True)
plt.show()

# Nalezení optimálního počtu komponent pomocí poměru vysvětleného rozptylu
pca = PCA().fit(X_train_std)
plt.figure(figsize=(10, 6))
plt.plot(np.cumsum(pca.explained_variance_ratio_), marker='o')
plt.axhline(y=0.95, color='r', linestyle='--', label='95% vysvětleného rozptylu')
plt.grid(True)
plt.xlabel('Počet komponent')
plt.ylabel('Kumulativní vysvětlený rozptyl')
plt.title('Vysvětlený rozptyl vs. počet komponent')
plt.legend()
plt.show()

# Získání počtu komponent potřebných k vysvětlení 95% rozptylu
n_components_95 = np.argmax(np.cumsum(pca.explained_variance_ratio_) >= 0.95) + 1
print(f"Počet komponent potřebných k vysvětlení 95% rozptylu: {n_components_95}")

# Aplikace PCA s optimálním počtem komponent
pca_optimal = PCA(n_components=n_components_95)
X_train_pca_optimal = pca_optimal.fit_transform(X_train_std)
X_test_pca_optimal = pca_optimal.transform(X_test_std)

# Trénování a vyhodnocení
clf = RandomForestClassifier(random_state=42)
clf.fit(X_train_pca_optimal, y_train)
y_pred = clf.predict(X_test_pca_optimal)
print(f"Přesnost s {n_components_95} komponentami: {accuracy_score(y_test, y_pred):.4f}")
```

## Implementace LDA v Pythonu

Scikit-learn také poskytuje implementaci LDA, kterou lze použít pro redukci dimenzionality:

```python
# Opět načtení datasetu Iris
iris = load_iris()
X = iris.data
y = iris.target

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Škálování dat
scaler = StandardScaler()
X_train_std = scaler.fit_transform(X_train)
X_test_std = scaler.transform(X_test)

# Aplikace LDA (n_components může být nejvýše n_classes - 1)
lda = LDA(n_components=2)
X_train_lda = lda.fit_transform(X_train_std, y_train)
X_test_lda = lda.transform(X_test_std)

# Kontrola poměru vysvětleného rozptylu
print("Poměr vysvětleného rozptylu:", lda.explained_variance_ratio_)
print("Součet poměru vysvětleného rozptylu:", sum(lda.explained_variance_ratio_))

# Trénování klasifikátoru
clf = RandomForestClassifier(random_state=42)
clf.fit(X_train_lda, y_train)

# Vyhodnocení
y_pred = clf.predict(X_test_lda)
print("Přesnost:", accuracy_score(y_test, y_pred))
print("\nKlasifikační zpráva:")
print(classification_report(y_test, y_pred))

# Porovnání s původními daty
clf_original = RandomForestClassifier(random_state=42)
clf_original.fit(X_train_std, y_train)
y_pred_original = clf_original.predict(X_test_std)
print("\nPřesnost s původními daty:", accuracy_score(y_test, y_pred_original))
```

## Aplikace ve strojovém učení

Techniky redukce dimenzionality mají četné aplikace ve strojovém učení:

### 1. Předzpracování pro ML modely

```python
# Použití PCA jako kroku předzpracování v pipeline
from sklearn.pipeline import Pipeline
from sklearn.svm import SVC

# Vytvoření pipeline s PCA a SVM
pca_svm_pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('pca', PCA(n_components=5)),  # Redukce na 5 komponent
    ('svm', SVC(kernel='rbf', probability=True))
])

# Trénování a vyhodnocení
pca_svm_pipeline.fit(X_train, y_train)
y_pred = pca_svm_pipeline.predict(X_test)
print("Přesnost s PCA předzpracováním:", accuracy_score(y_test, y_pred))
```

### 2. Zpracování multikolinearity

```python
# Generování vysoce korelovaných dat
n_samples = 1000
n_features = 10
X_corr = np.random.randn(n_samples, 2)  # Generování 2 nezávislých příznaků
# Vytvoření 8 příznaků, které jsou lineárními kombinacemi prvních 2
X_dependent = np.hstack([X_corr, 
                        np.dot(X_corr, np.random.randn(2, 8)) + 0.1*np.random.randn(n_samples, 8)])

# Vytvoření cílové proměnné

# Výpočet korelační matice
corr_matrix = np.corrcoef(X_dependent.T)
plt.figure(figsize=(10, 8))
sns.heatmap(corr_matrix, annot=True, fmt=".2f", cmap='coolwarm')

# Trénování modelů s a bez PCA
# Model bez PCA
model_no_pca = LogisticRegression(solver='liblinear', random_state=42)

y_pred_no_pca = model_no_pca.predict(X_test)
```

## Shrnutí a osvědčené postupy

Redukce dimenzionality je klíčovou technikou ve strojovém učení, která pomáhá řešit prokletí dimenzionality při zachování důležitých informací v datech.

Klíčové body:
1. **PCA** je neřízená metoda a maximalizuje rozptyl, což ji činí ideální pro kompresi dat a vizualizaci.
2. **LDA** je řízená metoda a maximalizuje oddělitelnost tříd, což ji činí vhodnou pro klasifikační úlohy.
3. **Počet komponent** by měl být zvolen na základě poměru vysvětleného rozptylu nebo křížové validace.
4. **Předzpracování** (zejména škálování) je nezbytné před aplikací redukce dimenzionality.
5. **Nelineární metody** (Kernel PCA, t-SNE, UMAP) mohou zpracovat komplexní datové struktury, kde PCA a LDA selhávají.

Osvědčené postupy:
1. Vždy standardizujte data před aplikací redukce dimenzionality.
2. Použijte poměr vysvětleného rozptylu jako vodítko pro výběr komponent.
3. Zvažte kompromis mezi redukcí dimenzionality a ztrátou informací.
4. Použijte křížovou validaci k vyhodnocení dopadu redukce dimenzionality na výkon modelu.
5. Pro klasifikační úlohy porovnejte PCA i LDA a identifikujte nejlepší přístup.
6. Vizualizujte výsledky, abyste získali vhled do struktury dat a ověřili, že důležité vzory jsou zachovány.

```python
# Kompletní workflow redukce dimenzionality
def dimensionality_reduction_workflow(X, y, test_size=0.3, random_state=42):
    """
    Kompletní workflow pro redukci dimenzionality a vyhodnocení modelu
    """
    # Rozdělení dat
    X_train, X_test, y_train, y_test = train_test_split(
        X, y, test_size=test_size, random_state=random_state
    )
    
    # Standardizace dat
    scaler = StandardScaler()
    X_train_std = scaler.fit_transform(X_train)
    X_test_std = scaler.transform(X_test)
    
    # Nalezení optimálního počtu PCA komponent
    pca = PCA()
    pca.fit(X_train_std)
    
    # Vykreslení poměru vysvětleného rozptylu
    plt.figure(figsize=(10, 6))
    cum_var = np.cumsum(pca.explained_variance_ratio_)
    plt.plot(range(1, len(cum_var) + 1), cum_var, marker='o', linestyle='-')
    plt.grid(True)
    plt.xlabel('Počet komponent')
    plt.ylabel('Kumulativní vysvětlený rozptyl')
    plt.axhline(y=0.95, color='r', linestyle='--', label='95% rozptylu')
    plt.title('PCA: Kumulativní vysvětlený rozptyl vs počet komponent')
    plt.legend()
    plt.show()
    
    # Určení počtu komponent pro 95% rozptylu
    n_components_95 = np.argmax(cum_var >= 0.95) + 1
    print(f"Počet PCA komponent pro 95% rozptylu: {n_components_95}")
    
    # Aplikace PCA s optimálním počtem komponent
    pca = PCA(n_components=n_components_95)
    X_train_pca = pca.fit_transform(X_train_std)
    X_test_pca = pca.transform(X_test_std)
    
    # Aplikace LDA (maximálně n_classes - 1 komponent)
    n_classes = len(np.unique(y))
    n_lda_components = min(n_classes - 1, X_train_std.shape[1])
    lda = LDA(n_components=n_lda_components)
    X_train_lda = lda.fit_transform(X_train_std, y_train)
    X_test_lda = lda.transform(X_test_std)
    
    print(f"Počet LDA komponent: {n_lda_components}")
    print(f"LDA poměr vysvětleného rozptylu: {lda.explained_variance_ratio_}")
    
    # Vytvoření a vyhodnocení klasifikátorů
    classifiers = {
        "Původní data": (X_train_std, X_test_std),
        "PCA": (X_train_pca, X_test_pca),
        "LDA": (X_train_lda, X_test_lda)
    }
    
    results = {}
    
    for name, (X_tr, X_te) in classifiers.items():
        # Trénování klasifikátoru
        clf = RandomForestClassifier(random_state=random_state)
        clf.fit(X_tr, y_train)
        
        # Predikce
        y_pred = clf.predict(X_te)
        
        # Výpočet metrik
        results[name] = {
            'accuracy': accuracy_score(y_test, y_pred),
            'report': classification_report(y_test, y_pred, output_dict=True)
        }
        
        print(f"\n--- Výsledky {name} ---")
        print(f"Přesnost: {results[name]['accuracy']:.4f}")
        print("Klasifikační zpráva:")
        print(classification_report(y_test, y_pred))
        
    return results

# Příklad použití
from sklearn.datasets import load_wine
wine = load_wine()
results = dimensionality_reduction_workflow(wine.data, wine.target)
```

Redukce dimenzionality je mocným nástrojem pro datové vědce a praktiky strojového učení. Správným porozuměním a aplikací technik jako PCA a LDA můžete zlepšit výkon modelu, snížit výpočetní nároky a získat hlubší pohled do vašich dat.
