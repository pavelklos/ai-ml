## Úvod do posilovaného učení

Posilované učení (Reinforcement Learning, RL) je typ strojového učení, ve kterém se agent učí rozhodovat tak, že provádí akce v prostředí s cílem maximalizovat kumulativní odměnu. Na rozdíl od učení s učitelem nevyžaduje RL označená data; místo toho se učí prostřednictvím interakcí s prostředím metodou pokus-omyl.

## Klíčové komponenty RL

Rámec posilovaného učení se skládá z několika klíčových komponent:

1. **Agent**: Učící se nebo rozhodující subjekt
2. **Prostředí**: Vše, s čím agent interaguje
3. **Stav (S)**: Aktuální situace agenta v prostředí
4. **Akce (A)**: Pohyb, který agent může provést
5. **Odměna (R)**: Zpětná vazba z prostředí (pozitivní nebo negativní)
6. **Strategie (π)**: Strategie, kterou agent používá k určení další akce
7. **Hodnotová funkce (V)**: Očekávaný dlouhodobý výnos s diskontem

```python
# Jednoduchý příklad ilustrující komponenty RL v mřížkovém světě

import numpy as np
import matplotlib.pyplot as plt

# Prostředí: 5x5 mřížkový svět
# Stavy: souřadnice (x, y)
# Akce: nahoru, vpravo, dolů, vlevo (0, 1, 2, 3)
# Odměny: -1 za každý krok, +10 za cíl, -10 za překážku

class GridWorldEnv:
    def __init__(self):
        self.grid_size = 5
        self.agent_pos = [0, 0]  # Počáteční pozice
        self.goal_pos = [4, 4]   # Cílová pozice
        self.obstacles = [[2, 2], [2, 3], [3, 2]]  # Pozice překážek
        
    def reset(self):
        self.agent_pos = [0, 0]
        return self.agent_pos.copy()
    
    def step(self, action):
        # Akce: 0=nahoru, 1=vpravo, 2=dolů, 3=vlevo
        
        # Pohyb agenta
        if action == 0 and self.agent_pos[1] < self.grid_size - 1:
            self.agent_pos[1] += 1
        elif action == 1 and self.agent_pos[0] < self.grid_size - 1:
            self.agent_pos[0] += 1
        elif action == 2 and self.agent_pos[1] > 0:
            self.agent_pos[1] -= 1
        elif action == 3 and self.agent_pos[0] > 0:
            self.agent_pos[0] -= 1
        
        # Kontrola, zda agent dosáhl cíle
        if self.agent_pos == self.goal_pos:
            reward = 10
            done = True
        # Kontrola, zda agent narazil na překážku
        elif any(self.agent_pos == obstacle for obstacle in self.obstacles):
            reward = -10
            done = True
        else:
            reward = -1  # Malá negativní odměna za každý krok
            done = False
            
        return self.agent_pos.copy(), reward, done
    
    def render(self):
        grid = np.zeros((self.grid_size, self.grid_size))
        
        # Označení pozice agenta
        grid[self.agent_pos[1], self.agent_pos[0]] = 1
        
        # Označení cílové pozice
        grid[self.goal_pos[1], self.goal_pos[0]] = 2
        
        # Označení překážek
        for obs in self.obstacles:
            grid[obs[1], obs[0]] = -1
            
        # Zobrazení mřížky
        plt.figure(figsize=(6, 6))
        plt.imshow(grid, cmap='coolwarm')
        plt.title('Mřížkový svět')
        plt.colorbar(ticks=[-1, 0, 1, 2], 
                     labels=['Překážka', 'Prázdné', 'Agent', 'Cíl'])
        plt.grid(True)
        plt.show()

# Vytvoření a vykreslení prostředí
env = GridWorldEnv()
state = env.reset()
env.render()
```

## Markovovy rozhodovací procesy

Problémy posilovaného učení jsou běžně formalizovány pomocí Markovových rozhodovacích procesů (MDP), které poskytují matematický rámec pro modelování rozhodování v situacích, kdy jsou výsledky částečně náhodné a částečně pod kontrolou rozhodovatele.

MDP je definován pomocí:
- Množiny stavů S
- Množiny akcí A
- Pravděpodobnosti přechodů P(s'|s,a)
- Funkce odměn R(s,a,s')
- Diskontního faktoru γ (gamma)

Cílem v MDP je najít strategii π, která maximalizuje očekávanou kumulativní diskontovanou odměnu:

$$V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R_t \mid S_0 = s, \pi \right]$$

```python
# Jednoduchá implementace Markovova rozhodovacího procesu

class SimpleMDP:
    def __init__(self):
        # Stavy: 0=počátek, 1=mezistanice, 2=cíl
        self.num_states = 3
        self.num_actions = 2  # Akce: 0=vlevo, 1=vpravo
        
        # Pravděpodobnosti přechodů: P[s][a][s'] = pravděpodobnost
        self.transition_probs = [
            # Ze stavu 0
            [[0.7, 0.3, 0.0],  # Akce 0
             [0.1, 0.9, 0.0]], # Akce 1
            
            # Ze stavu 1
            [[0.8, 0.2, 0.0],  # Akce 0
             [0.0, 0.1, 0.9]], # Akce 1
            
            # Ze stavu 2 (koncový stav)
            [[0.0, 0.0, 1.0],  # Akce 0
             [0.0, 0.0, 1.0]]  # Akce 1
        ]
        
        # Odměny: R[s][a][s'] = odměna
        self.rewards = [
            # Ze stavu 0
            [[0, 0, 0],  # Akce 0
             [0, 1, 0]], # Akce 1
            
            # Ze stavu 1
            [[0, 0, 0],  # Akce 0
             [0, 0, 10]], # Akce 1
            
            # Ze stavu 2
            [[0, 0, 0],  # Akce 0
             [0, 0, 0]]  # Akce 1
        ]
        
    def value_iteration(self, gamma=0.9, epsilon=1e-6):
        """
        Najde optimální hodnotovou funkci a strategii pomocí value iteration.
        
        Args:
            gamma: Diskontní faktor
            epsilon: Práh konvergence
            
        Returns:
            tuple: (optimální hodnotová funkce, optimální strategie)
        """
        # Inicializace hodnotové funkce
        V = [0] * self.num_states
        
        while True:
            delta = 0
            for s in range(self.num_states):
                v = V[s]
                
                # Výpočet hodnoty každé akce v tomto stavu
                action_values = []
                for a in range(self.num_actions):
                    value = 0
                    for s_prime in range(self.num_states):
                        reward = self.rewards[s][a][s_prime]
                        prob = self.transition_probs[s][a][s_prime]
                        value += prob * (reward + gamma * V[s_prime])
                    action_values.append(value)
                
                # Výběr maximální hodnoty
                V[s] = max(action_values)
                
                # Výpočet maximální změny hodnoty
                delta = max(delta, abs(v - V[s]))
            
            # Kontrola, zda jsme konvergovali
            if delta < epsilon:
                break
        
        # Výpočet optimální strategie
        policy = [0] * self.num_states
        for s in range(self.num_states):
            action_values = []
            for a in range(self.num_actions):
                value = 0
                for s_prime in range(self.num_states):
                    reward = self.rewards[s][a][s_prime]
                    prob = self.transition_probs[s][a][s_prime]
                    value += prob * (reward + gamma * V[s_prime])
                action_values.append(value)
            policy[s] = action_values.index(max(action_values))
        
        return V, policy

# Vytvoření a řešení MDP
mdp = SimpleMDP()
optimal_values, optimal_policy = mdp.value_iteration()

print("Optimální hodnotová funkce:", optimal_values)
print("Optimální strategie:", optimal_policy)
```

## Algoritmus Q-Learning

Q-Learning je model-free algoritmus posilovaného učení, který se snaží najít optimální strategii výběru akcí pomocí Q-funkce, která přiřazuje hodnoty párům stav-akce. Q-funkce představuje očekávaný užitek provedení dané akce v daném stavu a následování optimální strategie poté.

Pravidlo aktualizace pro Q-learning je:

$$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$$

Kde:
- Q(s, a) je hodnota provedení akce a ve stavu s
- α (alpha) je rychlost učení
- γ (gamma) je diskontní faktor
- r je odměna
- s' je následující stav

```python
# Implementace Q-Learningu pro mřížkový svět

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.table import Table

def q_learning_grid_world():
    # Parametry prostředí
    grid_size = 4
    actions = ['nahoru', 'vpravo', 'dolů', 'vlevo']
    
    # Parametry učení
    alpha = 0.1  # Rychlost učení
    gamma = 0.9  # Diskontní faktor
    epsilon = 0.1  # Míra průzkumu
    
    # Inicializace Q-tabulky nulami
    q_table = np.zeros((grid_size, grid_size, len(actions)))
    
    # Definice odměn
    rewards = np.full((grid_size, grid_size), -0.04)  # Malá negativní odměna za každý krok
    rewards[grid_size-1, grid_size-1] = 1  # Cílový stav
    rewards[grid_size-1, 0] = -1  # Negativní koncový stav
    terminal_states = [(grid_size-1, grid_size-1), (grid_size-1, 0)]
    
    # Definice platných akcí pro každý stav
    def get_valid_actions(state):
        valid = []
        row, col = state
        if row > 0:  # Může se pohybovat nahoru
            valid.append(0)
        if col < grid_size - 1:  # Může se pohybovat vpravo
            valid.append(1)
        if row < grid_size - 1:  # Může se pohybovat dolů
            valid.append(2)
        if col > 0:  # Může se pohybovat vlevo
            valid.append(3)
        return valid
    
    # Definice funkce pro následující stav
    def get_next_state(state, action):
        row, col = state
        if action == 0:  # Nahoru
            return (max(0, row-1), col)
        elif action == 1:  # Vpravo
            return (row, min(grid_size-1, col+1))
        elif action == 2:  # Dolů
            return (min(grid_size-1, row+1), col)
        elif action == 3:  # Vlevo
            return (row, max(0, col-1))
    
    # Trénování agenta
    n_episodes = 5000
    
    for episode in range(n_episodes):
        # Začínáme v náhodném nekoncovém stavu
        while True:
            state = (np.random.randint(0, grid_size), np.random.randint(0, grid_size))
            if state not in terminal_states:
                break
        
        done = False
        
        while not done:
            # Výběr akce pomocí epsilon-greedy
            valid_actions = get_valid_actions(state)
            
            if np.random.uniform(0, 1) < epsilon:
                # Průzkum: volba náhodné akce z platných akcí
                action = np.random.choice(valid_actions)
            else:
                # Využití: volba nejlepší akce na základě Q-hodnot
                # (ale pouze z platných akcí)
                valid_q_values = [q_table[state[0], state[1], a] if a in valid_actions else -np.inf 
                                 for a in range(len(actions))]
                action = np.argmax(valid_q_values)
            
            # Získání následujícího stavu a odměny
            next_state = get_next_state(state, action)
            reward = rewards[next_state[0], next_state[1]]
            
            # Kontrola, zda je tento stav koncový
            done = next_state in terminal_states
            
            # Aktualizace Q-learning
            old_q = q_table[state[0], state[1], action]
            next_max = np.max(q_table[next_state[0], next_state[1]])
            
            new_q = (1 - alpha) * old_q + alpha * (reward + gamma * next_max * (not done))
            q_table[state[0], state[1], action] = new_q
            
            # Přechod do dalšího stavu
            state = next_state
    
    # Vizualizace strategie
    policy = np.zeros((grid_size, grid_size), dtype=int)
    arrows = ['↑', '→', '↓', '←']
    
    for i in range(grid_size):
        for j in range(grid_size):
            if (i, j) not in terminal_states:
                policy[i, j] = np.argmax(q_table[i, j])
    
    # Vytvoření obrázku a osy
    fig, ax = plt.subplots(figsize=(8, 8))
    ax.set_axis_off()
    
    # Přidání tabulky na spodní část osy
    tb = Table(ax, bbox=[0, 0, 1, 1])
    
    # Přidání buněk
    cell_width = 1.0 / grid_size
    cell_height = 1.0 / grid_size
    
    for i in range(grid_size):
        for j in range(grid_size):
            if (i, j) in terminal_states:
                # Koncové stavy
                if rewards[i, j] > 0:
                    value = 'Cíl'
                    color = 'green'
                else:
                    value = 'Prohra'
                    color = 'red'
            else:
                value = arrows[policy[i, j]]
                max_q = np.max(q_table[i, j])
                color = 'white'
            
            tb.add_cell(i, j, cell_width, cell_height, text=value,
                       loc='center', facecolor=color)
    
    # Označení řádků a sloupců...
    for i in range(grid_size):
        tb.add_cell(i, -1, cell_width, cell_height, text=i+1,
                   loc='right', edgecolor='none', facecolor='none')
        tb.add_cell(-1, i, cell_width, cell_height, text=i+1,
                   loc='center', edgecolor='none', facecolor='none')
    
    ax.add_table(tb)
    plt.title('Naučená strategie')
    plt.show()
    
    return q_table, policy

# Spuštění Q-learningu
q_table, policy = q_learning_grid_world()
```

## Deep Q-Networks (DQN)

Deep Q-Networks (DQN) kombinují Q-Learning s hlubokými neuronovými sítěmi pro zpracování vysokodimenzionálních prostorů pozorování. DQN představoval průlom v RL, kdy demonstroval schopnost ovládat hry Atari na lidské úrovni pouze s použitím surových pixelů jako vstupu.

Klíčové inovace v DQN zahrnují:
- Experience replay: Ukládání minulých zkušeností a jejich náhodné vzorkování pro trénink
- Target networks: Použití oddělené sítě pro generování cílů při aktualizaci Q-learning
- Konvoluční sítě: Efektivní zpracování obrazových vstupů

```python
# Implementace Deep Q-Network pomocí TensorFlow

import tensorflow as tf
import numpy as np
from collections import deque
import random

class DQN:
    def __init__(self, state_size, action_size):
        self.state_size = state_size
        self.action_size = action_size
        self.memory = deque(maxlen=2000)
        self.gamma = 0.95  # Diskontní faktor
        self.epsilon = 1.0  # Míra průzkumu
        self.epsilon_min = 0.01
        self.epsilon_decay = 0.995
        self.learning_rate = 0.001
        self.model = self._build_model()
        self.target_model = self._build_model()
        self.update_target_model()
        
    def _build_model(self):
        """Neuronová síť pro aproximaci Q-funkce"""
        model = tf.keras.models.Sequential()
        model.add(tf.keras.layers.Dense(24, input_dim=self.state_size, activation='relu'))
        model.add(tf.keras.layers.Dense(24, activation='relu'))
        model.add(tf.keras.layers.Dense(self.action_size, activation='linear'))
        model.compile(loss='mse', optimizer=tf.keras.optimizers.Adam(lr=self.learning_rate))
        return model
    
    def update_target_model(self):
        """Zkopíruje váhy z modelu do target_model"""
        self.target_model.set_weights(self.model.get_weights())
    
    def remember(self, state, action, reward, next_state, done):
        """Uloží zkušenost do replay memory"""
        self.memory.append((state, action, reward, next_state, done))
    
    def act(self, state):
        """Výběr akce pomocí epsilon-greedy"""
        if np.random.rand() <= self.epsilon:
            return random.randrange(self.action_size)
        act_values = self.model.predict(state)
        return np.argmax(act_values[0])
    
    def replay(self, batch_size):
        """Trénování modelu pomocí experience replay"""
        minibatch = random.sample(self.memory, batch_size)
        for state, action, reward, next_state, done in minibatch:
            target = reward
            if not done:
                target = reward + self.gamma * np.amax(self.target_model.predict(next_state)[0])
            target_f = self.model.predict(state)
            target_f[0][action] = target
            self.model.fit(state, target_f, epochs=1, verbose=0)
        
        if self.epsilon > self.epsilon_min:
            self.epsilon *= self.epsilon_decay
    
    def load(self, name):
        self.model.load_weights(name)
    
    def save(self, name):
        self.model.save_weights(name)
```

## Metody Policy Gradient

Zatímco metody založené na hodnotách jako Q-learning se zaměřují na nalezení optimální hodnotové funkce a následné odvození strategie, metody policy gradient přímo optimalizují strategii. Tyto metody jsou obzvláště užitečné pro spojité akční prostory a stochastické strategie.

Základní myšlenkou je upravit parametry θ strategie πθ ve směru gradientu očekávaného zisku:

$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta(\tau)}[\nabla_\theta \log \pi_\theta(a_t|s_t) \cdot R(\tau)]$$

```python
# Jednoduchá implementace REINFORCE (Monte Carlo Policy Gradient)
import numpy as np
import tensorflow as tf
import gym

class PolicyGradient:
    def __init__(self, state_size, action_size, learning_rate=0.01):
        self.state_size = state_size
        self.action_size = action_size
        self.gamma = 0.99
        
        # Vytvoření sítě strategie
        self.model = self._build_policy_network(learning_rate)
        
        # Paměť pro epizody
        self.states = []
        self.actions = []
        self.rewards = []
    
    def _build_policy_network(self, learning_rate):
        """Vytvoření sítě strategie, která generuje pravděpodobnosti akcí"""
        model = tf.keras.Sequential([
            tf.keras.layers.Dense(24, input_dim=self.state_size, activation='relu'),
            tf.keras.layers.Dense(24, activation='relu'),
            tf.keras.layers.Dense(self.action_size, activation='softmax')
        ])
        
        model.compile(
            loss='categorical_crossentropy',
            optimizer=tf.keras.optimizers.Adam(learning_rate=learning_rate)
        )
        return model
    
    def choose_action(self, state):
        """Výběr akce na základě současné strategie"""
        state = np.reshape(state, [1, self.state_size])
        probabilities = self.model.predict(state)[0]
        # Výběr akce na základě pravděpodobnosti
        action = np.random.choice(self.action_size, p=probabilities)
        return action
    
    def store_transition(self, state, action, reward):
        """Uložení stavu, akce, odměny pro aktuální epizodu"""
        self.states.append(state)
        
        # Převod akce na one-hot kódování
        action_onehot = np.zeros(self.action_size)
        action_onehot[action] = 1
        self.actions.append(action_onehot)
        
        self.rewards.append(reward)
    
    def learn(self):
        """Aktualizace sítě strategie na základě výnosů"""
        # Výpočet diskontovaných výnosů pro každý časový krok
        discounted_returns = []
        cumulative_reward = 0
        
        for reward in reversed(self.rewards):
            cumulative_reward = reward + self.gamma * cumulative_reward
            discounted_returns.insert(0, cumulative_reward)
        
        # Normalizace výnosů
        discounted_returns = np.array(discounted_returns)
        discounted_returns = (discounted_returns - np.mean(discounted_returns)) / (np.std(discounted_returns) + 1e-8)
        
        # Příprava trénovacích dat
        states = np.vstack(self.states)
        actions = np.vstack(self.actions)
        
        # Trénování modelu - použití akcí jako cílů, vážených výnosy
        self.model.fit(
            states, 
            actions * np.expand_dims(discounted_returns, axis=1),
            epochs=1, verbose=0
        )
        
        # Vyčištění dat epizody
        self.states = []
        self.actions = []
        self.rewards = []

# Demo použití s CartPole
def run_policy_gradient():
    env = gym.make('CartPole-v1')
    state_size = env.observation_space.shape[0]
    action_size = env.action_space.n
    agent = PolicyGradient(state_size, action_size)
    
    episodes = 1000
    scores = []
    
    for e in range(episodes):
        state = env.reset()
        state = np.reshape(state, [state_size])
        score = 0
        done = False
        
        while not done:
            action = agent.choose_action(state)
            next_state, reward, done, _ = env.step(action)
            agent.store_transition(state, action, reward)
            state = next_state
            score += reward
            
            if done:
                # Trénování na konci každé epizody
                agent.learn()
                scores.append(score)
                print(f"Epizoda: {e+1}/{episodes}, Skóre: {score}")
                break
                
        # Pokud průměr posledních 100 epizod je > 195, považujeme za vyřešené
        if len(scores) > 100 and np.mean(scores[-100:]) > 195:
            print("Prostředí vyřešeno!")
            break
    
    return scores
```

```python
class SimpleGridEnv(gym.Env):
    """
    Jednoduché 2D mřížkové prostředí, kde se agent pohybuje k cíli.
    """
    def __init__(self, grid_size=5):
        super(SimpleGridEnv, self).__init__()
        
        self.grid_size = grid_size
        
        # Definice akčního prostoru (0: nahoru, 1: vpravo, 2: dolů, 3: vlevo)
        self.action_space = gym.spaces.Discrete(4)
        
        # Definice prostoru pozorování (x, y pozice agenta)
        self.observation_space = gym.spaces.Box(
            low=0, high=self.grid_size-1, shape=(2,), dtype=np.int32)
        
        # Inicializace stavu
        self.reset()
        
    def reset(self):
        # Agent začíná v (0, 0)
        self.agent_pos = np.array([0, 0])
        
        # Cíl je v protilehlém rohu
        self.goal_pos = np.array([self.grid_size-1, self.grid_size-1])
        
        # Vrácení pozorování
        return self._get_observation()
    
    def step(self, action):
        # Pohyb podle akce
        if action == 0:  # Nahoru
            self.agent_pos[1] = min(self.grid_size-1, self.agent_pos[1]+1)
        elif action == 1:  # Vpravo
            self.agent_pos[0] = min(self.grid_size-1, self.agent_pos[0]+1)
        elif action == 2:  # Dolů
            self.agent_pos[1] = max(0, self.agent_pos[1]-1)
        elif action == 3:  # Vlevo
            self.agent_pos[0] = max(0, self.agent_pos[0]-1)
        
        # Kontrola, zda agent dosáhl cíle
        done = np.array_equal(self.agent_pos, self.goal_pos)
        
        # Výpočet odměny
        if done:
            reward = 1.0  # Pozitivní odměna za dosažení cíle
        else:
            # Negativní odměna založená na vzdálenosti k cíli
            distance = np.sum(np.abs(self.agent_pos - self.goal_pos))
            reward = -0.1 * distance / (2 * self.grid_size)
        
        # Vrácení pozorování, odměny, indikátoru dokončení a info
        return self._get_observation(), reward, done, {}
    
    def _get_observation(self):
        return self.agent_pos.copy()
    
    def render(self, mode='human'):
        if mode == 'human':
            grid = np.zeros((self.grid_size, self.grid_size, 3))
            
            # Označení pozice agenta (červená)
            grid[self.agent_pos[1], self.agent_pos[0]] = [1.0, 0.0, 0.0]
            
            # Označení pozice cíle (zelená)
            grid[self.goal_pos[1], self.goal_pos[0]] = [0.0, 1.0, 0.0]
            
            plt.imshow(grid)
            plt.grid(True)
            plt.show()
        
        # Vrácení pole RGB pro režim rgb_array
        elif mode == 'rgb_array':
            grid = np.zeros((self.grid_size, self.grid_size, 3))
            grid[self.agent_pos[1], self.agent_pos[0]] = [1.0, 0.0, 0.0]
            grid[self.goal_pos[1], self.goal_pos[0]] = [0.0, 1.0, 0.0]
            
            # Zvětšení mřížky pro lepší vizualizaci
            return np.repeat(np.repeat(grid, 50, axis=0), 50, axis=1)
```

## Multi-Armed Bandits (Více-ramenní bandité)

Problém více-ramenního bandity je zjednodušený scénář posilovaného učení s pouze jedním stavem a více akcemi (rameny). Agent se musí rozhodnout, které rameno zatáhnout, aby maximalizoval kumulativní odměny v čase, balancujíc mezi průzkumem (zkoušením různých ramen) a využíváním (hraní nejlépe známého ramene).

```python
# Implementace epsilon-greedy a UCB algoritmů pro problém více-ramenních banditů

import numpy as np
import matplotlib.pyplot as plt

class MultiArmedBandit:
    def __init__(self, n_arms, true_rewards=None):
        self.n_arms = n_arms
        
        # Pokud nejsou poskytnuty skutečné odměny, vygeneruj je náhodně
        if true_rewards is None:
            self.true_rewards = np.random.normal(0, 1, n_arms)
        else:
            self.true_rewards = true_rewards
            
    def pull(self, arm):
        """Zatáhni za rameno a získej odměnu"""
        # Pozorovaná odměna je skutečná odměna plus nějaký šum
        return np.random.normal(self.true_rewards[arm], 1)

class EpsilonGreedy:
    def __init__(self, n_arms, epsilon=0.1):
        self.n_arms = n_arms
        self.epsilon = epsilon
        self.q_values = np.zeros(n_arms)  # Odhadovaná hodnota pro každé rameno
        self.arm_counts = np.zeros(n_arms)  # Kolikrát bylo každé rameno zataženo
        
    def select_arm(self):
        """Vyber rameno pomocí epsilon-greedy strategie"""
        # S pravděpodobností epsilon proveď průzkum
        if np.random.random() < self.epsilon:
            return np.random.randint(self.n_arms)
        # Jinak využij nejlepší rameno
        else:
            return np.argmax(self.q_values)
    
    def update(self, arm, reward):
        """Aktualizuj Q-hodnoty na základě pozorované odměny"""
        self.arm_counts[arm] += 1
        # Inkrementální průměrování
        self.q_values[arm] += (reward - self.q_values[arm]) / self.arm_counts[arm]

class UCB:
    def __init__(self, n_arms, c=2.0):
        self.n_arms = n_arms
        self.c = c  # Parametr průzkumu
        self.q_values = np.zeros(n_arms)
        self.arm_counts = np.zeros(n_arms)
        self.total_count = 0
        
    def select_arm(self):
        """Vyber rameno pomocí UCB strategie"""
        # Zatáhni každé rameno alespoň jednou
        for arm in range(self.n_arms):
            if self.arm_counts[arm] == 0:
                return arm
        
        # Vypočítej UCB hodnoty
        ucb_values = self.q_values + self.c * np.sqrt(
            np.log(self.total_count) / self.arm_counts)
        
        # Vrať rameno s maximální UCB hodnotou
        return np.argmax(ucb_values)
    
    def update(self, arm, reward):
        """Aktualizuj Q-hodnoty a počty na základě pozorované odměny"""
        self.arm_counts[arm] += 1
        self.total_count += 1
        self.q_values[arm] += (reward - self.q_values[arm]) / self.arm_counts[arm]

def run_bandit_experiment(n_arms=10, n_steps=1000, n_runs=100):
    """Spusť experimenty s více-ramenními bandity s různými strategiemi"""
    # Vytvoření banditů se stejnými skutečnými odměnami pro spravedlivé srovnání
    true_rewards = np.random.normal(0, 1, n_arms)
    
    # Strategie k porovnání
    strategies = {
        'Epsilon-Greedy (ε=0.1)': EpsilonGreedy(n_arms, epsilon=0.1),
        'Epsilon-Greedy (ε=0.01)': EpsilonGreedy(n_arms, epsilon=0.01),
        'UCB (c=2.0)': UCB(n_arms, c=2.0)
    }
    
    # Uložení výsledků
    rewards = {name: np.zeros((n_runs, n_steps)) for name in strategies}
    optimal_actions = {name: np.zeros((n_runs, n_steps)) for name in strategies}
    
    for run in range(n_runs):
        # Vytvoření nového bandity pro tento běh
        bandit = MultiArmedBandit(n_arms, true_rewards.copy())
        optimal_arm = np.argmax(true_rewards)
        
        # Reset strategií
        for name, strategy in strategies.items():
            if isinstance(strategy, EpsilonGreedy):
                strategies[name] = EpsilonGreedy(n_arms, strategy.epsilon)
            elif isinstance(strategy, UCB):
                strategies[name] = UCB(n_arms, strategy.c)
        
        # Spuštění experimentu pro každou strategii
        for name, strategy in strategies.items():
            for step in range(n_steps):
                # Výběr ramene
                arm = strategy.select_arm()
                
                # Získání odměny
                reward = bandit.pull(arm)
                
                # Aktualizace strategie
                strategy.update(arm, reward)
                
                # Uložení výsledků
                rewards[name][run, step] = reward
                optimal_actions[name][run, step] = 1 if arm == optimal_arm else 0
    
    # Vykreslení průměrných odměn
    plt.figure(figsize=(12, 5))
    
    plt.subplot(1, 2, 1)
    for name in strategies:
        plt.plot(np.mean(rewards[name], axis=0), label=name)
    plt.xlabel('Kroky')
    plt.ylabel('Průměrná odměna')
    plt.title('Průměrná odměna v čase')
    plt.legend()
    
    plt.subplot(1, 2, 2)
    for name in strategies:
        plt.plot(np.mean(optimal_actions[name], axis=0), label=name)
    plt.xlabel('Kroky')
    plt.ylabel('Optimální akce %')
    plt.title('Pravděpodobnost výběru optimální akce')
    plt.legend()
    
    plt.tight_layout()
    plt.show()
```

```python

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from gym import spaces
import gym

class StockTradingEnv(gym.Env):
    """Jednoduché prostředí pro obchodování s akciemi pomocí posilovaného učení"""
    metadata = {'render.modes': ['human']}

    def __init__(self, df, initial_balance=10000):
        super(StockTradingEnv, self).__init__()
        
        self.df = df
        self.initial_balance = initial_balance
        self.reward_range = (-np.inf, np.inf)
        
        # Akce: 0=prodej, 1=držení, 2=nákup
        self.action_space = spaces.Discrete(3)
        
        # Pozorování: [zůstatek, držené_akcie, cena_akcie, % změna]
        self.observation_space = spaces.Box(
            low=np.array([0, 0, 0, -1]), 
            high=np.array([np.inf, np.inf, np.inf, 1]), 
            dtype=np.float32
        )
        
        self.reset()
    
    def reset(self):
        # Reset stavu
        self.balance = self.initial_balance
        self.shares_held = 0
        self.current_step = 0
        self.net_worth = self.balance
        self.prev_net_worth = self.initial_balance
        
        return self._get_observation()
    
    def _get_observation(self):
        stock_price = self.df.iloc[self.current_step]['close']
        stock_pct_change = self.df.iloc[self.current_step]['pct_change']
        
        obs = np.array([
            self.balance,
            self.shares_held,
            stock_price,
            stock_pct_change
        ])
        
        return obs
    
    def step(self, action):
        # Získat aktuální cenu a definovat transakční náklady
        current_price = self.df.iloc[self.current_step]['close']
        transaction_cost_pct = 0.001  # 0,1% transakční náklady
        
        # Provést akci
        if action == 0:  # Prodat
            if self.shares_held > 0:
                # Výpočet transakčních nákladů
                sell_amount = self.shares_held * current_price
                transaction_cost = sell_amount * transaction_cost_pct
                
                # Aktualizace zůstatku a akcií
                self.balance += sell_amount - transaction_cost
                self.shares_held = 0
        
        elif action == 2:  # Koupit
            # Výpočet maximálního počtu akcií, které můžeme koupit
            max_shares = self.balance // (current_price * (1 + transaction_cost_pct))
            
            if max_shares > 0:
                # Výpočet transakčních nákladů
                buy_amount = max_shares * current_price
                transaction_cost = buy_amount * transaction_cost_pct
                
                # Aktualizace zůstatku a akcií
                self.balance -= buy_amount + transaction_cost
                self.shares_held += max_shares
        
        # Akce 1 je držení, takže nic neděláme
        
        # Přechod na další krok
        self.current_step += 1
        
        # Výpočet odměny (změna čisté hodnoty)
        self.net_worth = self.balance + self.shares_held * current_price
        reward = self.net_worth - self.prev_net_worth
        self.prev_net_worth = self.net_worth
        
        # Kontrola, zda je epizoda dokončena
        done = self.current_step >= len(self.df) - 1
        
        return self._get_observation(), reward, done, {}
    
    def render(self, mode='human'):
        """Vizualizace prostředí na obrazovku"""
        if mode == 'human':
            profit = self.net_worth - self.initial_balance
            print(f'Krok: {self.current_step}')
            print(f'Zůstatek: {self.balance}')
            print(f'Držené akcie: {self.shares_held}')
            print(f'Čistá hodnota: {self.net_worth}')
            print(f'Zisk: {profit}')
        
        return np.array([])
```

## Shrnutí

Posilované učení (RL) představuje výkonný přístup strojového učení, který umožňuje agentům učit se optimální chování prostřednictvím interakcí s prostředím. Klíčové poznatky z tohoto přehledu zahrnují:

1. **Základní koncept**: RL je založeno na myšlence učení pomocí metody pokus-omyl, kde agent provádí akce v prostředí s cílem maximalizovat kumulativní odměny.

2. **Rámec MDP**: Markovovy rozhodovací procesy poskytují matematický základ pro RL, formalizující koncepty stavů, akcí, odměn a přechodů.

3. **Metody založené na hodnotě vs. metodách založených na strategii**: Algoritmy RL lze široce kategorizovat do metod založených na hodnotě (jako Q-learning), které odhadují hodnotu stavů nebo akcí, a metod založených na strategii, které přímo optimalizují strategii.

4. **Klasické algoritmy**: Q-learning je základní algoritmus, který se učí hodnoty akcí pro každý stav a postupně zlepšuje strategii prostřednictvím průzkumu a využívání.

5. **Deep RL**: Deep Q-Networks (DQN) rozšiřují klasické RL využitím neuronových sítí jako aproximátorů funkcí, což umožňuje RL pracovat s vysokodimenzionálními stavovými prostory, jako jsou obrazy.

6. **Policy Gradients**: Tyto metody přímo optimalizují parametry strategie pomocí gradientů očekávaných výnosů, což je obzvláště efektivní pro spojité akční prostory a stochastické strategie.

7. **Průzkum vs. využívání**: Algoritmy RL musí vyvažovat průzkum nových akcí za účelem objevení lepších strategií a využívání známých dobrých akcí k maximalizaci odměn.

8. **OpenAI Gym**: Tento toolkit poskytuje standardizované rozhraní pro prostředí RL a sbírku referenčních problémů pro vývoj a testování algoritmů.

9. **Praktické aplikace**: RL bylo úspěšně aplikováno v různých oblastech včetně hraní her, robotiky, financí a zdravotnictví.

RL nadále zůstává aktivní oblastí výzkumu s pravidelně vznikajícími novými algoritmy a aplikacemi. Jeho schopnost učit se složitému chování z jednoduchých signálů odměny z něj činí silný přístup k řešení problémů sekvenčního rozhodování.
