## 1. Pochopení křížové validace

Křížová validace je technika přerozdělovacího vzorkování používaná k vyhodnocení modelů strojového učení na omezených datech. Pomáhá posoudit, jak dobře se model generalizuje na nezávislém datovém souboru, a řeší omezení jednoduchých rozdělení na trénovací a testovací sadu.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import train_test_split, cross_val_score, KFold, StratifiedKFold
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, confusion_matrix
from sklearn.datasets import load_iris, load_breast_cancer, load_digits
```

Hlavní koncept spočívá v rozdělení datového souboru na více trénovacích a validačních sad, vícenásobném trénování modelu a zprůměrování výsledků, čímž získáme spolehlivější odhad výkonu modelu.

## 2. Proč je křížová validace důležitá

Bez křížové validace riskujeme několik úskalí při vyhodnocování modelů:

- **Detekce přeučení**: Model může náhodou dobře fungovat na jediné testovací sadě
- **Odhad rozptylu**: Výkon se může výrazně lišit v závislosti na tom, které datové body jsou použity pro trénování vs. testování
- **Využití dat**: Tradiční rozdělení na trénovací a testovací sadu plýtvá daty, která by mohla být použita pro trénování

```python
# Ukázka rozptylu ve výkonu modelu s různými rozděleními trénovacích a testovacích dat

# Načtení datové sady
data = load_breast_cancer()
X, y = data.data, data.target

# Inicializace modelu
model = KNeighborsClassifier(n_neighbors=5)

# Provedení více rozdělení na trénovací a testovací data a vyhodnocení
results = []
np.random.seed(42)  # Pro reprodukovatelnost
for i in range(5):
    X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)
    model.fit(X_train, y_train)
    acc = model.score(X_test, y_test)
    results.append(acc)

print("Skóre přesnosti pro 5 různých rozdělení trénovací-testovací data:")
for i, acc in enumerate(results, 1):
    print(f"Rozdělení {i}: {acc:.4f}")
print(f"Průměr: {np.mean(results):.4f}, Sm. odchylka: {np.std(results):.4f}")

# Toto demonstruje, jak se může výkon lišit s různými rozděleními
```

Křížová validace nám dává větší jistotu při vyhodnocování modelu tím, že používá více rozdělení a poskytuje rozložení metrik výkonu.

## 3. K-násobná křížová validace

K-násobná křížová validace je nejběžnějším přístupem, kdy je datový soubor rozdělen na k stejně velkých částí (foldů). Model je trénován na k-1 foldech a testován na zbývajícím foldu. Tento proces se opakuje k-krát, přičemž každý fold je použit přesně jednou jako validační data.

```python
# Implementace K-násobné křížové validace
X, y = load_iris(return_X_y=True)

# Definice modelu
model = LogisticRegression(max_iter=200)

# Definice K-násobného cross-validátoru
kf = KFold(n_splits=5, shuffle=True, random_state=42)

# Provedení K-násobné křížové validace manuálně
fold_scores = []
for fold, (train_idx, val_idx) in enumerate(kf.split(X, y)):
    X_train, X_val = X[train_idx], X[val_idx]
    y_train, y_val = y[train_idx], y[val_idx]
    
    # Trénování modelu
    model.fit(X_train, y_train)
    
    # Vyhodnocení na validačním foldu
    score = model.score(X_val, y_val)
    fold_scores.append(score)
    print(f"Fold {fold+1}: {score:.4f}")

# Výpočet a zobrazení průměrného skóre
print(f"Průměrné skóre: {np.mean(fold_scores):.4f}")

# Použití vestavěné funkce scikit-learn
cv_scores = cross_val_score(model, X, y, cv=5)
print(f"Skóre křížové validace: {cv_scores}")
print(f"Průměrné CV skóre: {cv_scores.mean():.4f}")
```

## 4. Stratifikovaná křížová validace

Stratifikovaná křížová validace zajišťuje, že každý fold zachovává stejnou distribuci tříd jako původní datový soubor. To je zvláště důležité pro nevyvážené datové sady nebo sady s malým počtem vzorků v určitých třídách.

```python
# Porovnání standardní vs. stratifikované K-násobné křížové validace
# Vytvoření nevyvážené datové sady
X, y = load_breast_cancer(return_X_y=True)
# Uměle vytvoříme ještě větší nevyváženost
indices_to_keep = np.where(y == 1)[0][:50]  # Ponecháme pouze 50 pozitivních vzorků
indices_to_keep = np.concatenate([indices_to_keep, np.where(y == 0)[0]])  # Ponecháme všechny negativní vzorky
X_imb = X[indices_to_keep]
y_imb = y[indices_to_keep]

# Počet instancí v jednotlivých třídách
print(f"Distribuce tříd: {np.bincount(y_imb)}")

# Standardní K-Fold
kf = KFold(n_splits=5, shuffle=True, random_state=42)
# Stratifikovaný K-Fold
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# Porovnání distribuce foldů
print("\nDistribuce tříd ve foldech:")
print("{:<15} {:<15} {:<15}".format("Fold", "Standardní K-Fold", "Stratifikovaný K-Fold"))
print("-" * 45)

for i, ((_, test_idx_kf), (_, test_idx_skf)) in enumerate(zip(kf.split(X_imb), skf.split(X_imb, y_imb))):
    kf_dist = np.bincount(y_imb[test_idx_kf])
    skf_dist = np.bincount(y_imb[test_idx_skf])
    print(f"Fold {i+1:<12} {kf_dist[0]}/{kf_dist[1]:<12} {skf_dist[0]}/{skf_dist[1]:<12}")

# Porovnání výkonu
model = SVC(kernel='linear')
cv_kf = cross_val_score(model, X_imb, y_imb, cv=kf)
cv_skf = cross_val_score(model, X_imb, y_imb, cv=skf)

print(f"\nSkóre standardní K-Fold CV: {cv_kf}")
print(f"Skóre stratifikované K-Fold CV: {cv_skf}")
print(f"Standardní K-Fold průměr: {cv_kf.mean():.4f}, sm. odchylka: {cv_kf.std():.4f}")
print(f"Stratifikovaný K-Fold průměr: {cv_skf.mean():.4f}, sm. odchylka: {cv_skf.std():.4f}")
```

## 5. Metoda leave-one-out pro křížovou validaci

Metoda leave-one-out (LOOCV) je extrémním případem k-násobné křížové validace, kde k se rovná počtu vzorků. Každý model je trénován na všech datových bodech kromě jednoho, který je použit pro validaci. Tato technika je výpočetně náročná, ale může být cenná pro malé datové soubory.

```python
# Implementace metody leave-one-out pro křížovou validaci
from sklearn.model_selection import LeaveOneOut

# Vytvoření malé datové sady pro ukázku
X, y = load_iris(return_X_y=True)
X, y = X[:30], y[:30]  # Použijeme pouze 30 vzorků kvůli efektivitě

# Definice modelu
model = KNeighborsClassifier(n_neighbors=3)

# Definice LOOCV
loo = LeaveOneOut()

# Provedení LOOCV
loo_scores = []
for train_idx, test_idx in loo.split(X):
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]
    
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    correct = (pred == y_test)
    loo_scores.append(correct[0])

# Výpočet přesnosti
loo_accuracy = np.mean(loo_scores)
print(f"Přesnost Leave-One-Out CV: {loo_accuracy:.4f}")

# Použití cross_val_score ze scikit-learn
cv_scores = cross_val_score(model, X, y, cv=loo)
print(f"Přesnost Leave-One-Out CV (pomocí cross_val_score): {cv_scores.mean():.4f}")
```

## 6. Křížová validace pro časové řady

Standardní techniky křížové validace mohou být problematické pro časové řady, protože mohou zavést únik dat tím, že trénují na budoucích datech a testují na minulých datech. Metody křížové validace pro časové řady respektují časové pořadí pozorování.

```python
# Křížová validace pro časové řady
from sklearn.model_selection import TimeSeriesSplit
import datetime as dt
from sklearn.linear_model import LinearRegression

# Vytvoření jednoduché datové sady časových řad
dates = pd.date_range(start='1/1/2020', periods=100, freq='D')
values = np.sin(np.arange(100) * 0.1) + np.random.randn(100) * 0.2
ts_df = pd.DataFrame({'date': dates, 'value': values})

# Vytvoření příznaků a cílové proměnné
ts_df['lag1'] = ts_df['value'].shift(1)
ts_df['lag2'] = ts_df['value'].shift(2)
ts_df['lag3'] = ts_df['value'].shift(3)
ts_df.dropna(inplace=True)

X = ts_df[['lag1', 'lag2', 'lag3']].values
y = ts_df['value'].values

# Inicializace TimeSeriesSplit
tscv = TimeSeriesSplit(n_splits=5)

# Vizualizace rozdělení
plt.figure(figsize=(15, 8))
for i, (train_idx, test_idx) in enumerate(tscv.split(X)):
    plt.scatter(train_idx, [i+0.5]*len(train_idx), 
                c='blue', marker='_', lw=6, label='Trénovací' if i == 0 else "")
    plt.scatter(test_idx, [i+0.5]*len(test_idx), 
                c='red', marker='_', lw=6, label='Testovací' if i == 0 else "")

plt.yticks(np.arange(5) + 0.5, [f"Rozdělení {i+1}" for i in range(5)])
plt.title("Křížová validace pro časové řady")
plt.legend()
plt.tight_layout()
plt.show()

# Provedení křížové validace pro časové řady
model = LinearRegression()
scores = []

for train_idx, test_idx in tscv.split(X):
    X_train, X_test = X[train_idx], X[test_idx]
    y_train, y_test = y[train_idx], y[test_idx]
    
    model.fit(X_train, y_train)
    score = model.score(X_test, y_test)
    scores.append(score)

print(f"Skóre křížové validace pro časové řady: {scores}")
print(f"Průměrné R²: {np.mean(scores):.4f}")
```

## 7. Křížová validace s knihovnou scikit-learn

Scikit-learn poskytuje komplexní nástroje pro implementaci křížové validace ve vašem workflow strojového učení:

```python
# Křížová validace s knihovnou scikit-learn
from sklearn.model_selection import cross_val_score, cross_validate
from sklearn.model_selection import GridSearchCV, RandomizedSearchCV

# Načtení datové sady
X, y = load_digits(return_X_y=True)

# Základní křížová validace s různými metrikami skórování
model = RandomForestClassifier(random_state=42)

# Jedna metrika
accuracy_scores = cross_val_score(model, X, y, cv=5, scoring='accuracy')
print(f"Skóre přesnosti: {accuracy_scores}")
print(f"Průměrná přesnost: {accuracy_scores.mean():.4f}")

# Více metrik
scoring = ['accuracy', 'precision_macro', 'recall_macro', 'f1_macro']
cv_results = cross_validate(model, X, y, cv=5, scoring=scoring)

for metric in scoring:
    scores = cv_results[f'test_{metric}']
    print(f"{metric}: {scores.mean():.4f} ± {scores.std():.4f}")

# Křížová validace s laděním hyperparametrů
param_grid = {
    'n_estimators': [50, 100, 200],
    'max_depth': [None, 10, 20],
    'min_samples_split': [2, 5, 10]
}

# Prohledávání parametrů s křížovou validací
grid_search = GridSearchCV(
    estimator=RandomForestClassifier(random_state=42),
    param_grid=param_grid,
    cv=5,
    scoring='accuracy',
    n_jobs=-1  # Použití všech dostupných jader
)

grid_search.fit(X, y)

print("\nVýsledky prohledávání parametrů:")
print(f"Nejlepší parametry: {grid_search.best_params_}")
print(f"Nejlepší skóre křížové validace: {grid_search.best_score_:.4f}")

# Trénování s nejlepšími parametry
best_model = grid_search.best_estimator_
best_model.fit(X, y)
```

## 8. Úskalí křížové validace a osvědčené postupy

I když je křížová validace výkonnou technikou, existuje několik úskalí, kterým je třeba se vyhnout, a osvědčených postupů, které je třeba dodržovat:

```python
# Příklad demonstrující únik dat
from sklearn.preprocessing import StandardScaler

# Nesprávný přístup - škálování před křížovou validací
X, y = load_breast_cancer(return_X_y=True)

# Škálování celé datové sady
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Křížová validace (nesprávně) s předem škálovanými daty
cv_scores_incorrect = cross_val_score(
    LogisticRegression(max_iter=1000),
    X_scaled, y, cv=5
)

# Správný přístup - škálování uvnitř křížové validace
from sklearn.pipeline import Pipeline

# Vytvoření pipeline, která škáluje data v rámci každého foldu
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('model', LogisticRegression(max_iter=1000))
])

# Křížová validace s pipeline
cv_scores_correct = cross_val_score(pipe, X, y, cv=5)

print("Nesprávná CV skóre (únik dat):", cv_scores_incorrect)
print(f"Průměr: {cv_scores_incorrect.mean():.4f}")

print("\nSprávná CV skóre (bez úniku dat):", cv_scores_correct)
print(f"Průměr: {cv_scores_correct.mean():.4f}")
```

Osvědčené postupy:
1. **Vyhněte se úniku dat**: Předzpracování by mělo být provedeno uvnitř smyčky křížové validace
2. **Zvolte vhodné k**: Často funguje dobře 5 nebo 10 foldů; použijte větší k pro menší datové soubory
3. **Stratifikujte v případě potřeby**: Pro klasifikační problémy nebo nevyvážené datové sady
4. **Zvažte výpočetní náklady**: Vyšší k znamená více trénovacích iterací
5. **Použijte vnořenou křížovou validaci** pro výběr modelu a ladění hyperparametrů

## 9. Shrnutí

Křížová validace je nezbytnou technikou ve strojovém učení, která pomáhá:

- Vyhodnotit výkon modelu spolehlivěji než jediné rozdělení na trénovací a testovací sadu
- Detekovat a předcházet přeučení
- Efektivně využívat omezená data
- Budovat robustnější modely, které se dobře generalizují na neviděná data

Klíčové metody křížové validace zahrnují:
- **K-násobnou křížovou validaci**: Rozděluje data na k stejně velkých foldů
- **Stratifikovanou K-násobnou křížovou validaci**: Zachovává distribuci tříd v každém foldu
- **Metodu leave-one-out**: Extrémní případ, kdy každý vzorek má svůj vlastní fold
- **Křížovou validaci pro časové řady**: Respektuje časové pořadí v časových řadách

Scikit-learn poskytuje komplexní nástroje pro implementaci křížové validace, od základního hodnocení výkonu až po pokročilé ladění hyperparametrů pomocí GridSearchCV. Při implementaci křížové validace nezapomeňte správně zpracovat předzpracování dat, abyste předešli úniku dat, a zvolte vhodné validační strategie na základě charakteristik vašeho datového souboru.
