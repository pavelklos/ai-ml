# Nejužitečnější zdroje datasetů pro strojové učení

## Obecné repozitáře datasetů

- **[Kaggle Datasets](https://www.kaggle.com/datasets)** - Tisíce datasetů z různých oblastí s aktivní komunitní diskuzí a dokumentací. Mnoho datasetů obsahuje startovací notebooky.

- **[Google Dataset Search](https://datasetsearch.research.google.com/)** - Vyhledávač Google speciálně určený pro vyhledávání datasetů na webu.

- **[UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/index.php)** - Jeden z nejstarších a nejcitovanějších repozitářů datasetů ve výzkumu strojového učení.

- **[Hugging Face Datasets](https://huggingface.co/datasets)** - Rozsáhlá sbírka NLP datasetů a dalších, se snadnou integrací s knihovnami pro strojové učení.

- **[AWS Open Data Registry](https://registry.opendata.aws/)** - Veřejné datasety hostované na AWS, včetně satelitních snímků, genomiky a dat o dopravě.

## Vládní a vědecká data

- **[NASA Open Data Portal](https://data.nasa.gov/)** - Datasety z oblasti vědy o Zemi, klimatu a vesmírného výzkumu.

- **[Data.gov](https://www.data.gov/)** - Otevřená data vlády USA s více než 200 000 datasety pokrývajícími zemědělství, klima, vzdělávání, energetiku a další oblasti.

- **[EU Open Data Portal](https://data.europa.eu/en)** - Data z institucí, agentur a orgánů Evropské unie.

- **[WHO Data Collections](https://www.who.int/data/collections)** - Globální zdravotní statistiky a datasety.

- **[CERN Open Data Portal](http://opendata.cern.ch/)** - Data z částicové fyziky z experimentů CERN.

## Oborově specifické repozitáře

### Zpracování přirozeného jazyka

- **[NLTK Data](https://www.nltk.org/nltk_data/)** - Korpusy, lexikony a další lingvistické zdroje.

- **[Common Crawl](https://commoncrawl.org/)** - Petabajty dat z webu používané pro velké jazykové modely.

### Počítačové vidění

- **[ImageNet](https://www.image-net.org/)** - Rozsáhlá vizuální databáze navržená pro výzkum rozpoznávání vizuálních objektů.

- **[COCO Dataset](https://cocodataset.org/)** - Rozsáhlý dataset pro detekci objektů, segmentaci a popisování obrázků.

### Časové řady a finanční data

- **[Yahoo Finance](https://finance.yahoo.com/)** - Data finančních trhů, přístupná přes různá API.

- **[Quandl](https://www.quandl.com/)** - Finanční, ekonomické a alternativní datasety.

### Zdravotnictví a biologie

- **[UK Biobank](https://www.ukbiobank.ac.uk/)** - Rozsáhlá biomedicínská databáze a výzkumný zdroj.

- **[NIH Data Sharing Repositories](https://www.nlm.nih.gov/NIHbmic/nih_data_sharing_repositories.html)** - Různé biomedicínské repozitáře dat.

## Platformy pro ML soutěže

- **[Kaggle Competitions](https://www.kaggle.com/competitions)** - Soutěže v datové vědě s reálnými datasety a cenami.

- **[DrivenData](https://www.drivendata.org/)** - Soutěže v datové vědě zaměřené na společenský dopad.

- **[AIcrowd](https://www.aicrowd.com/)** - Soutěže v oblasti reinforcement learningu, NLP a počítačového vidění.

## Cloudové služby s datasety

- **[Google Cloud Public Datasets](https://cloud.google.com/datasets)** - Veřejné datasety dostupné na Google Cloud s integrací s BigQuery.

- **[Azure Open Datasets](https://azure.microsoft.com/en-us/services/open-datasets/)** - Kurátované datasety dostupné na Azure.

## Výzkumné organizace

- **[Papers With Code Datasets](https://paperswithcode.com/datasets)** - Datasety spojené s výzkumnými články o strojovém učení a benchmarky.

- **[TensorFlow Datasets](https://www.tensorflow.org/datasets)** - Datasety připravené k použití pro TensorFlow se standardizovanými formáty.

- **[PyTorch Datasets](https://pytorch.org/vision/stable/datasets.html)** - Datasety, které se dobře integrují s PyTorch.

## Specializovaná data

- **[OpenStreetMap](https://www.openstreetmap.org/)** - Geografická data přispívaná komunitou mapovačů.

- **[Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets)** - GitHub repozitář s kategorizovanými tématy vysoce kvalitních veřejných datasetů.

- **[Earth Engine Data Catalog](https://developers.google.com/earth-engine/datasets)** - Geoprostorové datasety včetně satelitních snímků a geofyzikálních dat.

## Tržiště s daty

- **[Data.World](https://data.world/)** - Platforma pro sdílení a spolupráci na datech.

- **[Snowflake Data Marketplace](https://www.snowflake.com/data-marketplace/)** - Živé, připravené k dotazování datasety od poskytovatelů dat třetích stran.

## Etika a soukromí

Při práci s datasety vždy zajistěte:
- Kontrolu licencí a podmínek použití
- Nakládání s osobními údaji v souladu s předpisy (GDPR, CCPA atd.)
- Zvážení potenciálních zkreslení v datech
- Vhodné citování zdrojů datasetů ve vašem výzkumu a aplikacích
