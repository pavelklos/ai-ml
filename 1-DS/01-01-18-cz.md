## 1. Úvod do EDA

Průzkumná analýza dat (EDA) je klíčovým prvním krokem v každém projektu datové vědy. Zahrnuje analýzu a vizualizaci dat s cílem porozumět jejich hlavním charakteristikám, identifikovat vzory, odhalit anomálie a formulovat hypotézy. EDA pomáhá datovým vědcům činit informovaná rozhodnutí o předzpracování dat, inženýrství příznaků a strategiích modelování.

```python
# Import základních knihoven pro EDA
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení stylu vizualizace

# Konfigurace možností zobrazení pandas
pd.set_option('display.max_columns', 50)
pd.set_option('display.width', 1000)
```

## 8. Detekce odlehlých hodnot

Identifikace a analýza odlehlých hodnot pomáhá pochopit neobvyklé vzory a potenciální problémy s daty.

```python
# Metoda Z-skóre pro detekci odlehlých hodnot
from scipy import stats

def detect_outliers_zscore(data, threshold=3):
    """Detekce odlehlých hodnot pomocí metody Z-skóre"""
    z_scores = np.abs(stats.zscore(data.dropna()))
    return data[z_scores > threshold].index

# Metoda IQR pro detekci odlehlých hodnot
def detect_outliers_iqr(data):
    """Detekce odlehlých hodnot pomocí metody IQR"""
    Q1 = data.quantile(0.25)
    Q3 = data.quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    return data[(data < lower_bound) | (data > upper_bound)].index

# Nalezení odlehlých hodnot ve sloupci 'fare'
fare_zscore_outliers = detect_outliers_zscore(titanic['fare'])
fare_iqr_outliers = detect_outliers_iqr(titanic['fare'])

print(f"Odlehlé hodnoty v 'fare' pomocí Z-skóre: {len(fare_zscore_outliers)}")
print(f"Odlehlé hodnoty v 'fare' pomocí IQR: {len(fare_iqr_outliers)}")

# Vizualizace odlehlých hodnot v bodovém grafu
plt.figure(figsize=(12, 6))
scatter = plt.scatter(titanic.index, titanic['fare'], c='b', alpha=0.5)
plt.scatter(fare_iqr_outliers, titanic.loc[fare_iqr_outliers, 'fare'], c='r')
plt.title('Odlehlé hodnoty jízdného pomocí metody IQR')
plt.xlabel('Index')
plt.ylabel('Jízdné')
plt.legend(['Normální', 'Odlehlá hodnota'])
plt.tight_layout()
plt.show()

# Krabicový graf pro vizualizaci odlehlých hodnot
plt.figure(figsize=(10, 6))
sns.boxplot(data=titanic[['age', 'fare']])
plt.title('Krabicový graf pro detekci odlehlých hodnot')
plt.tight_layout()
plt.show()
```

## 10. Shrnutí

Průzkumná analýza dat je základním krokem v každém workflow datové vědy, který pomáhá pochopit charakteristiky dat a identifikovat vzory. Klíčové aspekty EDA zahrnují:

1. **Prvotní kontrola dat**: Porozumění struktuře dat, typům a kvalitě
2. **Souhrnné statistiky**: Kvantifikace centrálních tendencí a rozptylu
3. **Analýza chybějících hodnot**: Identifikace a vizualizace chybějících hodnot
4. **Analýza distribucí**: Porozumění distribucím proměnných a odhalení zešikmení
5. **Korelační analýza**: Identifikace vztahů mezi proměnnými
6. **Průzkum kategorických dat**: Analýza kategorií a jejich vztahů
7. **Detekce odlehlých hodnot**: Nalezení a zpracování neobvyklých pozorování
8. **Vizualizace**: Vytváření informativních grafů pro získání vhledu
9. **Automatizované nástroje**: Urychlení analýzy pomocí reportovacích knihoven

EDA tvoří základ pro inženýrství příznaků, předzpracování dat a rozhodnutí o výběru modelu. Důkladná EDA pomáhá vyhnout se běžným modelovacím problémům a vede k robustnějším a interpretovatelným modelům.

Iterativní povaha EDA umožňuje datovým vědcům neustále zdokonalovat jejich porozumění datům a rozvíjet cílenější analýzy, jak se objevují nové poznatky. Nezapomeňte, že EDA není univerzální přístup; konkrétní použité techniky by měly být vždy přizpůsobeny vašemu datasetu a doméně problému.
