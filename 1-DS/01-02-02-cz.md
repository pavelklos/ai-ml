## Úvod do pokročilého indexování

Pandas nabízí výkonné možnosti indexování, které přesahují prostý výběr řádků a sloupců. Porozumění pokročilému indexování je nezbytné pro efektivní manipulaci s daty, zejména při práci s komplexními datovými sadami.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

# Vytvoření vzorového DataFrame
df = pd.DataFrame({
    'A': range(1, 6),
    'B': range(10, 15),
    'C': ['a', 'b', 'c', 'd', 'e']
}, index=['row1', 'row2', 'row3', 'row4', 'row5'])

print("Vzorový DataFrame:")
print(df)

# Základní operace indexování
print("\nPrvní dva řádky:")
print(df[:2])  # Řezání založené na popisku (label)

print("\nSloupec 'A':")
print(df['A'])  # Výběr sloupce
```

## Porozumění loc a iloc

Pandas poskytuje dva základní indexery: `loc` (založený na popisku) a `iloc` (založený na celočíselné pozici). Porozumění jejich rozdílům je klíčové pro správný výběr dat.

```python
# Vytvoření DataFrame s vlastním indexem
df = pd.DataFrame({
    'A': range(1, 6),
    'B': range(10, 15),
    'C': ['a', 'b', 'c', 'd', 'e']
}, index=[10, 20, 30, 40, 50])

print("DataFrame s vlastním indexem:")
print(df)

# loc: indexování založené na popisku
print("\nloc[10] - Výběr řádku s popiskem 10:")
print(df.loc[10])

print("\nloc[10:30] - Výběr řádků s popisky od 10 do 30 (včetně):")
print(df.loc[10:30])

print("\nloc[:, 'B'] - Výběr sloupce 'B':")
print(df.loc[:, 'B'])

print("\nloc[20, 'C'] - Výběr hodnoty na řádku 20, sloupec 'C':")
print(df.loc[20, 'C'])

# iloc: indexování založené na celočíselné pozici
print("\niloc[0] - Výběr prvního řádku:")
print(df.iloc[0])

print("\niloc[0:2] - Výběr řádků na pozicích 0 a 1:")
print(df.iloc[0:2])

print("\niloc[:, 1] - Výběr druhého sloupce:")
print(df.iloc[:, 1])

print("\niloc[1, 2] - Výběr hodnoty na druhém řádku, třetím sloupci:")
print(df.iloc[1, 2])

# Kombinování booleovského výběru s loc
print("\nVýběr řádků, kde A > 3 a sloupec 'B':")
print(df.loc[df['A'] > 3, 'B'])

# Častá chyba: míchání sémantiky popisku a pozice
try:
    # Toto selže
    result = df.loc[0]
    print(result)
except KeyError as e:
    print(f"KeyError: {e} - protože 0 není popiskem řádku v našem DataFrame")
```

## Základy MultiIndexu

MultiIndex (hierarchické indexování) umožňuje mít více úrovní indexů, což umožňuje komplexnější reprezentaci dat a operace.

```python
# Základy MultiIndexu
# Vytvoření Series s MultiIndexem
multi_idx = pd.MultiIndex.from_tuples([
    ('A', 'x'), ('A', 'y'), ('B', 'x'), ('B', 'y'), ('C', 'x')
], names=['level_0', 'level_1'])

s = pd.Series(range(1, 6), index=multi_idx)
print("Series s MultiIndexem:")
print(s)

# Struktura MultiIndexu
print("\nStruktura MultiIndexu:")
print(f"Počet úrovní: {s.index.nlevels}")
print(f"Názvy úrovní: {s.index.names}")
print(f"Hodnoty úrovně 0: {s.index.get_level_values(0)}")
print(f"Hodnoty úrovně 1: {s.index.get_level_values(1)}")

# Přístup k jednotlivým úrovním
print("\nUnikátní hodnoty na úrovni 0:")
print(s.index.get_level_values('level_0').unique())
```

## Vytváření DataFrames s MultiIndexem

Existuje více způsobů, jak vytvořit DataFrames s MultiIndexem, každý s vlastními výhodami v závislosti na zdroji dat.

```python
# Metoda 1: Z polí
arrays = [
    ['A', 'A', 'B', 'B', 'C'],
    ['x', 'y', 'x', 'y', 'x']
]
df1 = pd.DataFrame({
    'value': range(1, 6),
    'count': range(10, 15)
}, index=pd.MultiIndex.from_arrays(arrays, names=('first', 'second')))

print("Metoda 1 - Z polí:")
print(df1)

# Metoda 2: Z n-tic
tuples = [('A', 'x'), ('A', 'y'), ('B', 'x'), ('B', 'y'), ('C', 'x')]
df2 = pd.DataFrame({
    'value': range(1, 6),
    'count': range(10, 15)
}, index=pd.MultiIndex.from_tuples(tuples, names=('first', 'second')))

print("\nMetoda 2 - Z n-tic:")
print(df2)

# Metoda 3: Z kartézského součinu
df3 = pd.DataFrame({
    'value': [1, 2, 3, 4, 5, 6],
    'count': [10, 11, 12, 13, 14, 15]
}, index=pd.MultiIndex.from_product([['A', 'B'], ['x', 'y', 'z']], 
                                   names=('first', 'second')))

print("\nMetoda 3 - Z kartézského součinu:")
print(df3)

# Metoda 4: Z DataFrame pomocí set_index
df4 = pd.DataFrame({
    'first': ['A', 'A', 'B', 'B', 'C'],
    'second': ['x', 'y', 'x', 'y', 'x'],
    'value': range(1, 6),
    'count': range(10, 15)
})
df4_multi = df4.set_index(['first', 'second'])

print("\nMetoda 4 - Pomocí set_index:")
print(df4_multi)
```

## Výběr dat z MultiIndexu

Přístup k datům z DataFrame s MultiIndexem vyžaduje porozumění tomu, jak specifikovat hodnoty na různých úrovních.

```python
# Vytvoření složitějšího DataFrame s MultiIndexem
idx = pd.MultiIndex.from_product([
    ['Region1', 'Region2', 'Region3'],
    [2020, 2021, 2022],
    ['Q1', 'Q2', 'Q3', 'Q4']
], names=['Region', 'Rok', 'Čtvrtletí'])

# Vytvoření dat
np.random.seed(42)
data = np.random.randint(100, 1000, size=(36, 2))

sales_df = pd.DataFrame(
    data,
    index=idx,
    columns=['Prodeje', 'Náklady']
)

print("DataFrame prodejů s třístupňovým MultiIndexem:")
print(sales_df.head(10))

# Základní příklady výběru
print("\nVšechna data pro Region1:")
print(sales_df.loc['Region1'])

print("\nData Region1 pro rok 2020:")
print(sales_df.loc[('Region1', 2020)])

print("\nData pro Region1, 2020, Q1:")
print(sales_df.loc[('Region1', 2020, 'Q1')])

# Výběr pomocí řezů (slice)
print("\nVšechny regiony, rok 2021:")
print(sales_df.loc[(slice(None), 2021), :])

# Metoda xs pro průřezová data
print("\nVšechna data Q1 napříč všemi regiony a roky:")
print(sales_df.xs('Q1', level='Čtvrtletí'))

print("\nVšechna data roku 2020 pro každý region:")
print(sales_df.xs(2020, level='Rok'))
```

## Pokročilé techniky výběru

Kombinace různých metod výběru a použití booleovského indexování s daty MultiIndexu poskytuje výkonné možnosti filtrování.

```python
# Vytvoření vzorového víceúrovňového DataFrame
dates = pd.date_range('20230101', periods=6)
regions = ['Východ', 'Západ']
categories = ['A', 'B', 'C']

# Vytvoření multi-indexu pomocí kartézského součinu
idx = pd.MultiIndex.from_product([regions, dates], names=['Region', 'Datum'])
cols = pd.MultiIndex.from_product([categories, ['Prodeje', 'Reklamace']], 
                                 names=['Kategorie', 'Metrika'])

# Generování vzorových dat
np.random.seed(42)
data = np.random.randint(10, 100, size=(12, 6))
df = pd.DataFrame(data, index=idx, columns=cols)

print("Pokročilý DataFrame s MultiIndexem:")
print(df)

# Výběr všech dat prodejů
print("\nVšechna data prodejů napříč všemi kategoriemi:")
print(df.loc[:, (slice(None), 'Prodeje')])

# Výběr konkrétního regionu, všech dat, prodeje kategorie A
print("\nVýchodní region, všechna data, Prodeje kategorie A:")
print(df.loc[('Východ', slice(None)), ('A', 'Prodeje')])

# Použití booleovských podmínek s loc
print("\nŘádky, kde Prodeje kategorie A > 50:")
mask = df[('A', 'Prodeje')] > 50
print(df.loc[mask])

# Průřezy na více úrovních
print("\nData prodejů pro všechny kategorie k prvnímu datu:")
first_date = dates[0]
print(df.xs((first_date), level='Datum')[('A', 'Prodeje')])

# Kombinace loc s xs
print("\nKategorie B pro Východní region:")
print(df.loc['Východ'].xs('B', axis=1, level=0))
```

## Manipulace a transformace indexů

Práce s MultiIndexem často vyžaduje restrukturalizaci indexu nebo transformaci organizace dat.

```python
# Vytvoření vzorového DataFrame s MultiIndexem
data = {
    ('A', 2020): [1, 2, 3],
    ('A', 2021): [4, 5, 6],
    ('B', 2020): [7, 8, 9],
    ('B', 2021): [10, 11, 12],
}
df = pd.DataFrame(data, index=['X', 'Y', 'Z'])

print("Původní DataFrame:")
print(df)

# Výměna řádků a úrovní sloupců
stacked = df.stack()
print("\nNaskládaný DataFrame:")
print(stacked)

# Zpětné rozložení (unstacking)
unstacked = stacked.unstack()
print("\nZpětně rozloženo do původního stavu:")
print(unstacked)

# Prohození úrovní indexu
df_multirow = stacked.copy()
print("\nProhození úrovní:")
print(df_multirow.swaplevel())

# Přeuspořádání úrovní
df_reordered = df.T  # Transpozice pro získání MultiIndexu v řádcích
print("\nTransponováno:")
print(df_reordered)

print("\nPřeuspořádané úrovně:")
print(df_reordered.reorder_levels([1, 0], axis=0))

# Reset indexu na sloupce
print("\nReset indexu (převod na sloupce):")
print(stacked.reset_index())

# Nastavení nového indexu ze sloupců
reset_df = stacked.reset_index()
print("\nOpětovné nastavení indexu:")
print(reset_df.set_index(['level_0', 0]))
```

## Výkonnostní aspekty

Při práci s velkými datovými sadami je klíčové porozumění výkonnostním dopadům různých metod indexování.

```python
import time

# Vytvoření velkého DataFrame
large_df = pd.DataFrame(np.random.rand(100000, 5), columns=list('ABCDE'))

# Přidání několika kategorických sloupců pro indexování
large_df['cat1'] = np.random.choice(['X', 'Y', 'Z'], size=100000)
large_df['cat2'] = np.random.choice(['P', 'Q', 'R', 'S'], size=100000)

# Časové porovnání pro různé operace
def time_operation(operation, name):
    start = time.time()
    result = operation()
    end = time.time()
    print(f"{name}: {end - start:.4f} sekund")
    return result

# Běžné indexování vs MultiIndex
print("Porovnání výkonu:")

# Měření času nastavení indexu
regular_df = large_df.copy()
time_operation(lambda: regular_df.set_index('cat1'), "Nastavení jednoduchého indexu")

multi_df = large_df.copy()
time_operation(lambda: multi_df.set_index(['cat1', 'cat2']), "Nastavení MultiIndexu")

# Vytvoření indexovaných verzí pro testování
regular_indexed = large_df.set_index('cat1')
multi_indexed = large_df.set_index(['cat1', 'cat2'])

# Měření času operací výběru
time_operation(lambda: regular_indexed.loc['X'], "Běžný výběr .loc")
time_operation(lambda: multi_indexed.loc['X'], "Výběr úrovně 0 v MultiIndexu")
time_operation(lambda: multi_indexed.loc[('X', 'P')], "Úplný výběr v MultiIndexu")

# Měření času metody xs
time_operation(lambda: multi_indexed.xs('P', level='cat2'), "Použití metody .xs")

# Ukázka důležitosti seřazeného indexu pro výkon
sorted_multi = multi_indexed.sort_index()
print("\nSeřazený vs. Neseřazený MultiIndex:")
time_operation(lambda: multi_indexed.loc['X'], "Výběr v neseřazeném MultiIndexu")
time_operation(lambda: sorted_multi.loc['X'], "Výběr v seřazeném MultiIndexu")
```

## Praktické aplikace

Prozkoumejme některé praktické aplikace pokročilého indexování v úlohách analýzy dat.

```python
# Vytvoření datasetu maloobchodních prodejů
np.random.seed(42)
dates = pd.date_range('20230101', periods=100)
products = ['Produkt A', 'Produkt B', 'Produkt C', 'Produkt D']
stores = ['Obchod 1', 'Obchod 2', 'Obchod 3']

# Generování dat
data = []
for date in dates:
    for product in products:
        for store in stores:
            sales = np.random.randint(10, 100)
            price = np.random.uniform(5.0, 25.0)
            cost = price * 0.6  # 60 % ceny jsou náklady
            data.append([date, product, store, sales, price, cost])

# Vytvoření DataFrame
retail_df = pd.DataFrame(
    data, 
    columns=['Datum', 'Produkt', 'Obchod', 'Jednotky', 'Cena', 'Náklady']
)

# Nastavení MultiIndexu pro analýzu
sales_idx = retail_df.set_index(['Datum', 'Produkt', 'Obchod'])
print("Maloobchodní prodeje s MultiIndexem:")
print(sales_idx.head())

# Aplikace 1: Analýza časových řad podle produktu
product_sales = sales_idx['Jednotky'].unstack(level=['Produkt', 'Obchod']).fillna(0)
print("\nDenní prodeje podle produktu a obchodu:")
print(product_sales.head())

# Převzorkování na týdenní data
weekly_sales = product_sales.resample('W').sum()
print("\nTýdenní prodeje:")
print(weekly_sales.head())

# Aplikace 2: Analýza výkonu produktů
# Výpočet výnosů a zisků
sales_idx['Výnos'] = sales_idx['Jednotky'] * sales_idx['Cena']
sales_idx['Zisk'] = sales_idx['Výnos'] - (sales_idx['Jednotky'] * sales_idx['Náklady'])

# Agregace podle produktu
product_performance = sales_idx.groupby('Produkt').agg({
    'Jednotky': 'sum',
    'Výnos': 'sum',
    'Zisk': 'sum'
})
print("\nSouhrnný výkon produktů:")
print(product_performance)

# Aplikace 3: Průřezová analýza
# Získání průměrných denních prodejů podle obchodu
store_daily_avg = sales_idx.groupby(['Obchod', pd.Grouper(level='Datum')])['Jednotky'].sum().unstack(level=0)
store_daily_avg = store_daily_avg.resample('D').mean()
print("\nPrůměrné denní prodeje podle obchodu:")
print(store_daily_avg.head())

# Vykreslení výsledků
plt.figure(figsize=(12, 6))
store_daily_avg.plot()
plt.title('Průměrné denní prodeje podle obchodu')
plt.ylabel('Prodané jednotky')
plt.grid(True)
plt.tight_layout()
```

## Shrnutí

Pokročilé indexování v Pandas pomocí `loc`, `iloc` a MultiIndexu poskytuje výkonné nástroje pro analýzu a manipulaci s daty:

1. **loc vs iloc**: `loc` používá popisky pro indexování, zatímco `iloc` používá celočíselné pozice. Porozumění jejich rozdílům je klíčové pro správný výběr dat.

2. **MultiIndex**: Hierarchické indexování umožňuje reprezentaci vícerozměrných dat ve dvourozměrném DataFrame, což umožňuje komplexní analýzy.

3. **Výběr dat**: Pokročilé techniky jako průřezový výběr pomocí `xs`, řezání pomocí `slice()` a booleovské indexování poskytují flexibilní způsoby přístupu k datům.

4. **Manipulace s indexy**: Metody jako `stack()`, `unstack()`, `swaplevel()` a `reorder_levels()` pomáhají při restrukturalizaci dat pro různé analytické potřeby.

5. **Výkon**: Řazení indexů, správné metody výběru a porozumění režii MultiIndexu může významně ovlivnit výkon u velkých datových sad.

Klíčové osvědčené postupy:
- Udržujte úrovně MultiIndexu seřazené pro lepší výkon
- Používejte `xs` pro průřezový výběr, když je to vhodné
- Používejte smysluplné názvy pro úrovně indexu
- Buďte explicitní ohledně názvů úrovní při výběru, abyste zlepšili čitelnost kódu
- Zvažte použití `IndexSlice` pro komplexní výběry

Zvládnutím pokročilých technik indexování v Pandas můžete psát stručnější, efektivnější a výraznější kód pro analýzu dat, zejména při práci s komplexními vícerozměrnými datovými sadami.
