## Introduction to Exploratory Data Analysis

Exploratory Data Analysis (EDA) is a critical first step in any data science project. It involves analyzing and summarizing data sets to gain insights, identify patterns, detect anomalies, and test hypotheses. EDA helps data scientists understand the structure and characteristics of the data before applying complex modeling techniques.


## Distribution Analysis

Examining the distributions of variables helps identify patterns, skewness, and potential issues in the data.

```python
# Numerical distribution analysis
numerical_features = titanic.select_dtypes(include=['int64', 'float64']).columns.tolist()

# Function to plot distributions of numerical features
def plot_numerical_distributions(df, features, n_cols=3):
    """Plot histograms and KDE plots for numerical features"""
    n_features = len(features)
    n_rows = (n_features + n_cols - 1) // n_cols
    
    fig, axes = plt.subplots(n_rows, n_cols, figsize=(15, n_rows * 5))
    axes = axes.flatten()
    
    for i, feature in enumerate(features):
        if i < len(axes):
            sns.histplot(df[feature], kde=True, ax=axes[i])
            axes[i].set_title(f'Distribution of {feature}')
            axes[i].set_xlabel(feature)
            axes[i].set_ylabel('Frequency')
    
    # Hide unused subplots
    for j in range(i + 1, len(axes)):
        fig.delaxes(axes[j])
    
    plt.tight_layout()
    plt.show()

plot_numerical_distributions(titanic, numerical_features)
```

```python
# Function to calculate and visualize categorical correlations using Cramer's V
def categorical_correlations(df, categorical_features):
    """Calculate Cramer's V correlation between categorical variables"""
    from scipy.stats import chi2_contingency
    
    def cramers_v(x, y):
        confusion_matrix = pd.crosstab(x, y)
        chi2 = chi2_contingency(confusion_matrix)[0]
        n = confusion_matrix.sum().sum()
        phi2 = chi2 / n
        r, k = confusion_matrix.shape
        phi2corr = max(0, phi2 - ((k-1)*(r-1))/(n-1))
        r_corr = r - ((r-1)**2)/(n-1)
        k_corr = k - ((k-1)**2)/(n-1)
        return np.sqrt(phi2corr / min((k_corr-1), (r_corr-1)))
    
    corr_matrix = pd.DataFrame(np.zeros((len(categorical_features), len(categorical_features))), 
                              index=categorical_features, columns=categorical_features)
    
    for i, feat1 in enumerate(categorical_features):
        for j, feat2 in enumerate(categorical_features):
            if i > j:  # Calculate only for the lower triangle
                corr_matrix.loc[feat1, feat2] = cramers_v(df[feat1], df[feat2])
    
    # Make the matrix symmetric
    for i, feat1 in enumerate(categorical_features):
        for j, feat2 in enumerate(categorical_features):
            if i < j:  # Fill the upper triangle
                corr_matrix.loc[feat1, feat2] = corr_matrix.loc[feat2, feat1]
            elif i == j:  # Set diagonal to 1
                corr_matrix.loc[feat1, feat2] = 1.0
    
    return corr_matrix

# Get only categorical features with 10 or fewer unique values
suitable_cat_features = [col for col in categorical_features 
                        if titanic[col].nunique() <= 10 and titanic[col].isnull().sum() == 0]

if suitable_cat_features:
    # Calculate categorical correlations
    cat_corr = categorical_correlations(titanic, suitable_cat_features)
    
    # Plot categorical correlation heatmap
    plt.figure(figsize=(10, 8))
    sns.heatmap(cat_corr, annot=True, cmap='coolwarm', vmin=0, vmax=1)
    plt.title("Cramer's V Correlation Between Categorical Features")
    plt.tight_layout()
    plt.show()
```

## Outlier Detection and Treatment

Identifying and handling outliers is crucial for building robust models.

```python
# Function to detect outliers using IQR method
def detect_outliers_iqr(df, feature):
    """Detect outliers using the Interquartile Range (IQR) method"""
    Q1 = df[feature].quantile(0.25)
    Q3 = df[feature].quantile(0.75)
    IQR = Q3 - Q1
    
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    
    outliers = df[(df[feature] < lower_bound) | (df[feature] > upper_bound)][feature]
    return outliers, lower_bound, upper_bound

# Visualize outliers for a numerical feature (e.g., 'fare')
feature = 'fare'
outliers, lower_bound, upper_bound = detect_outliers_iqr(titanic, feature)

print(f"Outliers in '{feature}' using IQR method:")
print(f"Number of outliers: {len(outliers)}")
print(f"Percentage of outliers: {(len(outliers) / len(titanic)) * 100:.2f}%")
print(f"Lower bound: {lower_bound:.2f}")
print(f"Upper bound: {upper_bound:.2f}")

# Box plot with highlighted outliers
plt.figure(figsize=(10, 6))
ax = sns.boxplot(x=titanic[feature])
plt.title(f'Box Plot of {feature} with Outliers')
plt.tight_layout()
plt.show()

# Scatter plot of age vs fare with potential outliers highlighted
plt.figure(figsize=(12, 8))
sns.scatterplot(x='age', y='fare', data=titanic, alpha=0.6)

# Highlight outliers in fare
outlier_indices = titanic[titanic['fare'] > upper_bound].index
sns.scatterplot(x='age', y='fare', data=titanic.loc[outlier_indices], 
                color='red', s=100, label='Fare Outliers')

plt.title('Scatter Plot of Age vs Fare with Outliers Highlighted')
plt.legend()
plt.tight_layout()
plt.show()

# Treating outliers by capping
def cap_outliers(df, feature, lower_bound, upper_bound):
    """Cap outliers to the bounds"""
    df_capped = df.copy()
    df_capped[feature] = df_capped[feature].clip(lower=lower_bound, upper=upper_bound)
    return df_capped

# Cap the 'fare' outliers
titanic_capped = cap_outliers(titanic, feature, lower_bound, upper_bound)

# Compare original vs capped distribution
plt.figure(figsize=(15, 6))

plt.subplot(1, 2, 1)
sns.histplot(titanic[feature], kde=True)
plt.title(f'Original {feature} Distribution')

plt.subplot(1, 2, 2)
sns.histplot(titanic_capped[feature], kde=True)
plt.title(f'Capped {feature} Distribution')

plt.tight_layout()
plt.show()
```

```python
def plot_violin_grid(df, cat_vars, num_vars, n_cols=2):
```

```python
        'missing': missing_info,
```

## Summary

Exploratory Data Analysis is a crucial phase in the data science workflow that helps understand data before applying complex modeling techniques. Key aspects of effective EDA include:

1. **Initial Data Overview**: Understanding the basic structure, size, and content of your dataset through summary statistics and data type analysis.

2. **Distribution Analysis**: Examining the distributions of individual variables to identify patterns, skewness, and potential data anomalies.

3. **Correlation Analysis**: Identifying relationships between variables, which is crucial for feature selection and understanding potential predictive factors.

4. **Outlier Detection**: Identifying and potentially treating unusual data points that could affect model performance.

5. **Missing Value Analysis**: Understanding patterns in missing data and implementing appropriate imputation strategies.

6. **Feature Relationships**: Visualizing interactions between features to identify complex patterns and dependencies.

7. **Time Series Analysis**: Specialized techniques for time-dependent data to identify trends, seasonality, and other temporal patterns.

8. **Categorical Data Analysis**: Specific approaches for analyzing and visualizing categorical variables and their relationships.

9. **Automation Tools**: Leveraging automated EDA tools to accelerate the analysis process and ensure consistency.

10. **Iterative Process**: EDA is not a one-time activity but an iterative process that continues throughout the data science project, informing decisions at each stage.

Effective EDA combines statistical techniques with visualization to build a comprehensive understanding of the data, facilitating better feature engineering, data preprocessing, and model selection in the subsequent phases of a data science project.
