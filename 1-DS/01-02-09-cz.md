## Etické a právní aspekty

Před scrapováním jakékoli webové stránky je zásadní porozumět právním a etickým důsledkům. Vždy zkontrolujte:

1. Podmínky služby webové stránky
2. Soubor robots.txt pro povolené/zakázané oblasti
3. Omezení rychlosti dotazů, aby nedošlo k přetížení serveru
4. Otázky ochrany osobních údajů

```python
# Kontrola souboru robots.txt před scrapováním
import requests
from urllib.parse import urlparse

def check_robots_txt(url):
    """Kontrola, zda je scrapování povoleno v robots.txt"""
    parsed_url = urlparse(url)
    robots_url = f"{parsed_url.scheme}://{parsed_url.netloc}/robots.txt"
    
    try:
        response = requests.get(robots_url)
        if response.status_code == 200:
            print(f"Obsah robots.txt pro {parsed_url.netloc}:")
            print(response.text)
        else:
            print(f"Pro {parsed_url.netloc} nebyl nalezen soubor robots.txt")
    except Exception as e:
        print(f"Chyba při kontrole robots.txt: {e}")

# Příklad použití
check_robots_txt('https://example.com')
```

## Použití knihovny Requests pro načítání webových stránek

Knihovna `requests` je standardem pro provádění HTTP požadavků v Pythonu. Umožňuje načítat obsah webových stránek pro následné scrapování.

```python
import requests
import time

def fetch_page(url, headers=None, delay=1):
    """
    Načtení webové stránky s vhodnými hlavičkami a omezením rychlosti
    
    Parametry:
        url (str): URL adresa ke stažení
        headers (dict): Volitelné HTTP hlavičky
        delay (float): Čas čekání v sekundách před požadavkem
    
    Vrací:
        requests.Response: Objekt odpovědi
    """
    # Výchozí hlavičky pro napodobení prohlížeče
    if headers is None:
        headers = {
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36',
            'Accept': 'text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8',
            'Accept-Language': 'en-US,en;q=0.5',
        }
    
    # Omezení rychlosti
    time.sleep(delay)
    
    try:
        response = requests.get(url, headers=headers)
        response.raise_for_status()  # Vyvolá výjimku pro stavové kódy 4XX/5XX
        return response
    except requests.exceptions.RequestException as e:
        print(f"Chyba při načítání {url}: {e}")
        return None

# Příklad použití
response = fetch_page('https://quotes.toscrape.com/')
if response:
    print(f"Stavový kód: {response.status_code}")
    print(f"Typ obsahu: {response.headers.get('content-type')}")
    print(f"Prvních 100 znaků: {response.text[:100].strip()}")
```

## Web scraping s Beautiful Soup

Beautiful Soup je knihovna Pythonu, která usnadňuje parsování HTML a extrakci dat. Poskytuje praktické metody pro hledání prvků podle názvů tagů, atributů nebo CSS selektorů.

```python
from bs4 import BeautifulSoup
import requests

# Scrapování citátů z ukázkové webové stránky
url = 'https://quotes.toscrape.com/'
response = requests.get(url)
soup = BeautifulSoup(response.text, 'html.parser')

# Extrakce citátů a autorů
quotes = []
for quote_div in soup.select('.quote'):
    text = quote_div.select_one('.text').get_text()
    author = quote_div.select_one('.author').get_text()
    tags = [tag.get_text() for tag in quote_div.select('.tag')]
    
    quotes.append({
        'text': text,
        'author': author,
        'tags': tags
    })

# Zobrazení výsledků
print(f"Extrahováno {len(quotes)} citátů:")
for i, quote in enumerate(quotes[:3], 1):  # Zobrazit první 3 citáty
    print(f"\n--- Citát {i} ---")
    print(f"Text: {quote['text']}")
    print(f"Autor: {quote['author']}")
    print(f"Tagy: {', '.join(quote['tags'])}")

# Převod na DataFrame pro analýzu
import pandas as pd
quotes_df = pd.DataFrame(quotes)
print("\nShrnutí DataFrame:")
print(quotes_df.info())
```

## Práce s dynamickými webovými stránkami pomocí Selenia

Mnoho moderních webových stránek načítá obsah dynamicky pomocí JavaScriptu. Pro tyto stránky je Selenium nezbytné, protože dokáže automatizovat prohlížeč pro vykreslení JavaScriptového obsahu před scrapováním.

from selenium.webdriver.chrome.service import Service
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from webdriver_manager.chrome import ChromeDriverManager
import time

def scrape_dynamic_page(url, wait_time=10):
    """Scrapování obsahu z JavaScriptem vykreslené stránky pomocí Selenia"""
    
    # Nastavení možností Chromu
    chrome_options = Options()
    chrome_options.add_argument("--headless")  # Spustit Chrome v režimu bez UI
    chrome_options.add_argument("--disable-gpu")
    chrome_options.add_argument("--window-size=1920,1080")
    
    try:
        # Inicializace ovladače
        driver = webdriver.Chrome(
            service=Service(ChromeDriverManager().install()), 
            options=chrome_options
        )
        
        # Navigace na URL
        driver.get(url)
        
        # Čekání na načtení stránky (upravte selektor podle potřeby)
        WebDriverWait(driver, wait_time).until(
            EC.presence_of_element_located((By.CSS_SELECTOR, ".content"))
        )
        
        # Získání zdrojového kódu stránky po provedení JavaScriptu

        # Vytvoření objektu BeautifulSoup

        # Příklad: extrakce dat z dynamické stránky

        title = soup.title.string if soup.title else "Nenalezen žádný titulek"
        
        # Další extrakce dat by byla zde
        
        # Zavření prohlížeče
        driver.quit()
        
        return {
            "title": title,

        }
        
    except Exception as e:
        print(f"Chyba při scrapování dynamické stránky: {e}")

## Extrakce a čištění dat

Extrakce dat je pouze začátek. Často budete muset sesbíraná data vyčistit a předzpracovat, aby byla užitečná pro analýzu.

```python
import pandas as pd
import re
from bs4 import BeautifulSoup

# Ukázkové HTML s nepořádnými daty
messy_html = """
<div class="product">
    <h2>Laptop XYZ-2023   </h2>
    <p class="price">Cena: 29 999 Kč</p>
    <div class="specs">
        <p>RAM: 16GB</p>
        <p>Úložiště: 512GB SSD</p>
        <p>Hodnocení: 4.7/5 (243 recenzí)</p>
    </div>
</div>
<div class="product">
    <h2>  Smartphone ABC </h2>
    <p class="price">Cena: 18 990 Kč</p>
    <div class="specs">
        <p>RAM: 8GB</p>
        <p>Úložiště: 256GB</p>
        <p>Hodnocení: 4.5/5 (1,892 recenzí)</p>
    </div>
</div>
"""

# Parsování HTML
soup = BeautifulSoup(messy_html, 'html.parser')
products = []

for product_div in soup.select('.product'):
    # Extrakce základních informací
    name = product_div.find('h2').get_text(strip=True)
    
    # Extrakce ceny a její vyčištění
    price_text = product_div.select_one('.price').get_text()
    # Odstranění "Cena: " a mezer, převod na číslo
    price = float(re.search(r'(\d+[ ]?\d+)', price_text).group(1).replace(' ', ''))
    
    # Extrakce specifikací
    specs = {}
    for spec in product_div.select('.specs p'):
        spec_text = spec.get_text()
        if 'RAM:' in spec_text:
            specs['ram'] = spec_text.replace('RAM:', '').strip()
        elif 'Úložiště:' in spec_text:
            specs['storage'] = spec_text.replace('Úložiště:', '').strip()
        elif 'Hodnocení:' in spec_text:
            # Extrakce hodnoty hodnocení a počtu recenzí
            rating_match = re.search(r'([0-9.]+)/5 \(([0-9,]+) recenzí\)', spec_text)
            if rating_match:
                specs['rating'] = float(rating_match.group(1))
                specs['review_count'] = int(rating_match.group(2).replace(',', ''))
    
    # Vytvoření slovníku pro tento produkt
    product = {
        'name': name,
        'price': price,
        'ram': specs.get('ram'),
        'storage': specs.get('storage'),
        'rating': specs.get('rating'),
        'review_count': specs.get('review_count')
    }
    products.append(product)

# Převod na DataFrame pro analýzu
df = pd.DataFrame(products)
print("Vyčištěná data produktů:")
print(df)

# Příklad základní analýzy dat
print("\nPrůměrná cena produktů:", df['price'].mean())
print("Průměrné hodnocení:", df['rating'].mean())
```

## Ukládání sesbíraných dat

Po scrapování a čištění dat je potřeba je uložit pro budoucí použití. Mezi běžné formáty patří CSV, JSON a databáze.

```python
import pandas as pd
import sqlite3
import json
import csv
import os

# Vzorová data (předpokládejme, že máme tento DataFrame ze scrapování)
data = [
    {'product': 'Laptop', 'price': 29999, 'brand': 'Dell', 'rating': 4.5},
    {'product': 'Telefon', 'price': 18990, 'brand': 'Apple', 'rating': 4.8},
    {'product': 'Tablet', 'price': 9990, 'brand': 'Samsung', 'rating': 4.3}
]
df = pd.DataFrame(data)

# 1. Uložení do CSV
def save_to_csv(dataframe, filename):
    dataframe.to_csv(filename, index=False)
    print(f"Data uložena do {filename}")

# 2. Uložení do JSON
def save_to_json(dataframe, filename):
    dataframe.to_json(filename, orient='records')
    print(f"Data uložena do {filename}")

# 3. Uložení do SQLite databáze
def save_to_sqlite(dataframe, db_name, table_name):
    conn = sqlite3.connect(db_name)
    dataframe.to_sql(table_name, conn, if_exists='replace', index=False)
    print(f"Data uložena do {db_name} v tabulce '{table_name}'")
    conn.close()

# Příklad použití
save_to_csv(df, 'scrapovane_produkty.csv')
save_to_json(df, 'scrapovane_produkty.json')
save_to_sqlite(df, 'databaze_produktu.db', 'produkty')

# Příklady čtení dat zpět
print("\nČtení dat zpět:")
# Z CSV
csv_data = pd.read_csv('scrapovane_produkty.csv')
print("\nZ CSV:")
print(csv_data)

# Z JSON
json_data = pd.read_json('scrapovane_produkty.json')
print("\nZ JSON:")
print(json_data)

# Z SQLite
conn = sqlite3.connect('databaze_produktu.db')
sqlite_data = pd.read_sql_query("SELECT * FROM produkty", conn)
conn.close()
print("\nZ SQLite:")
print(sqlite_data)
```

## Vytváření robustních scraperů

Vytváření odolných scraperů zahrnuje ošetření chyb, používání proxy serverů, omezení rychlosti a strategie pro zvládání změn na webových stránkách.

```python
import requests
import random
import time
from bs4 import BeautifulSoup
import logging

# Nastavení logování
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s',
    filename='scraper.log'
)

class RobustnyScraper:
    def __init__(self, base_url, max_retries=3, backoff_factor=0.3, proxy_list=None):
        self.base_url = base_url
        self.max_retries = max_retries
        self.backoff_factor = backoff_factor
        self.proxy_list = proxy_list or []
        self.session = requests.Session()
        
        # Nastavení výchozích hlaviček
        self.session.headers.update({
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36',
            'Accept-Language': 'cs-CZ,cs;q=0.9,en-US;q=0.8,en;q=0.7',
        })
    
    def _get_random_proxy(self):
        """Vrátí náhodné proxy, pokud je k dispozici"""
        if not self.proxy_list:
            return None
        return random.choice(self.proxy_list)
    
    def fetch_page(self, url, params=None):
        """Načtení stránky s logikou opakování a ošetřením chyb"""
        for attempt in range(self.max_retries):
            try:
                # Použití exponenciálního backoff
                if attempt > 0:
                    sleep_time = self.backoff_factor * (2 ** attempt)
                    logging.info(f"Opakování {attempt+1}/{self.max_retries}. Čekám {sleep_time:.2f}s")
                    time.sleep(sleep_time)
                
                # Výběr proxy, pokud je k dispozici
                proxy = self._get_random_proxy()
                proxies = {'http': proxy, 'https': proxy} if proxy else None
                
                # Provedení požadavku
                response = self.session.get(
                    url, 
                    params=params,
                    proxies=proxies,
                    timeout=10
                )
                
                # Kontrola, zda byl požadavek úspěšný
                response.raise_for_status()
                
                return response
                
            except requests.exceptions.HTTPError as e:
                logging.error(f"HTTP chyba: {e}")
                if response.status_code == 404:
                    logging.error("Stránka nenalezena (404)")
                    return None
                elif response.status_code == 403:
                    logging.error("Přístup zakázán (403) - IP může být blokována")
                
            except requests.exceptions.ConnectionError:
                logging.error("Chyba připojení")
            
            except requests.exceptions.Timeout:
                logging.error("Vypršel časový limit požadavku")
                
            except requests.exceptions.RequestException as e:
                logging.error(f"Požadavek selhal: {e}")
        
        logging.error(f"Všechny {self.max_retries} pokusy selhaly pro URL: {url}")
        return None
    
    def extract_data(self, soup):
        """
        Extrakce dat z objektu BeautifulSoup
        Tuto metodu je třeba přepsat v podtřídách
        """
        raise NotImplementedError("Podtřídy musí implementovat extract_data()")
    
    def scrape(self, url_path="", params=None):
        """Hlavní metoda scrapování"""
        full_url = f"{self.base_url}/{url_path}".rstrip('/')
        logging.info(f"Scrapování URL: {full_url}")
        
        response = self.fetch_page(full_url, params)
        if not response:
            logging.error("Nepodařilo se načíst stránku")
            return None
        
        soup = BeautifulSoup(response.text, 'html.parser')
        return self.extract_data(soup)

# Příklad implementace pro quotes.toscrape.com
class CitatyScraper(RobustnyScraper):
    def extract_data(self, soup):
        citaty = []
        for quote_div in soup.select('.quote'):
            try:
                text = quote_div.select_one('.text').get_text()
                author = quote_div.select_one('.author').get_text()
                tags = [tag.get_text() for tag in quote_div.select('.tag')]
                
                citaty.append({
                    'text': text,
                    'author': author,
                    'tags': tags
                })
            except AttributeError as e:
                logging.error(f"Chyba při extrakci dat citátu: {e}")
                continue
        
        return citaty

# Příklad použití
scraper = CitatyScraper('https://quotes.toscrape.com')
citaty = scraper.scrape()

print(f"Scrapováno {len(citaty) if citaty else 0} citátů")
if citaty:
    print("První citát:")
    print(f"'{citaty[0]['text']}'")
    print(f"- {citaty[0]['author']}")
```

## Shrnutí

Web scraping je mocná technika pro sběr dat v projektech datové vědy. Klíčové poznatky zahrnují:

1. **Etické aspekty** jsou prvořadé - vždy respektujte robots.txt, podmínky služby a omezení rychlosti.
2. **Beautiful Soup a Requests** tvoří základ scrapování statických webových stránek.
3. **Selenium** je nezbytné pro webové stránky s vysokým obsahem JavaScriptu.
4. **Čištění dat** je kritickým krokem po extrakci pro přípravu dat k analýze.
5. **Robustní scrapery** potřebují ošetření chyb, logiku opakování a schopnost přizpůsobit se změnám na webu.
6. **Více možností ukládání** (CSV, JSON, databáze) je k dispozici podle vašich potřeb.
7. **Regulární výrazy** jsou často potřebné pro extrahování specifických vzorů z textu.
8. **Automatizované prohlížeče** jako Selenium umožňují programově interagovat s webovými stránkami.
9. **Strukturované přístupy** s třídami a funkcemi pomáhají vytvářet udržitelné scrapery.
10. **Logování a monitorování** jsou nezbytné pro řešení problémů a zajištění nepřetržitého provozu.

Při správné implementaci umožňuje web scraping datovým vědcům přístup k obrovskému množství dat, která by jinak nebyla dostupná, což umožňuje komplexnější analýzy a lépe informovaná rozhodnutí.
