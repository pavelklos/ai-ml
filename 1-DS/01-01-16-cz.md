## 1. Základy pravděpodobnosti

Pravděpodobnost je odvětví matematiky, které se zabývá měřením pravděpodobnosti výskytu událostí. V datové vědě poskytuje pravděpodobnost teoretický základ pro statistické odvozování, algoritmy strojového učení a rozhodování založené na datech.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
import random

# Nastavení náhodného semínka pro reprodukovatelnost
np.random.seed(42)
random.seed(42)

# Jednoduchý příklad pravděpodobnosti: hod mincí
n_flips = 1000
# Simulace 1000 hodů spravedlivou mincí (0=rub, 1=líc)
coin_flips = np.random.binomial(1, 0.5, n_flips)

# Výpočet experimentální pravděpodobnosti
heads_probability = np.mean(coin_flips)

print(f"Počet hodů: {n_flips}")
print(f"Počet lícových stran: {sum(coin_flips)}")
print(f"Experimentální pravděpodobnost líce: {heads_probability:.4f}")
print(f"Teoretická pravděpodobnost líce: 0.5000")

# Vizualizace konvergence k teoretické pravděpodobnosti
plt.figure(figsize=(10, 6))
cumulative_heads = np.cumsum(coin_flips)
cumulative_probability = [sum(coin_flips[:i+1])/(i+1) for i in range(n_flips)]

plt.plot(range(1, n_flips+1), cumulative_probability)
plt.axhline(y=0.5, color='r', linestyle='--', label='Teoretická pravděpodobnost')
plt.xlabel('Počet hodů')
plt.ylabel('Pravděpodobnost líce')
plt.title('Konvergence k teoretické pravděpodobnosti')
plt.legend()
plt.grid(True)
plt.show()
```

## 2. Náhodné proměnné a distribuce

Náhodná proměnná je proměnná, jejíž hodnota závisí na výsledku náhodného jevu. Náhodné proměnné mohou být diskrétní (nabývající specifických hodnot) nebo spojité (nabývající libovolné hodnoty v určitém rozsahu).


## 4. Funkce pravděpodobnostní hmoty a hustoty

Funkce pravděpodobnostní hmoty (PMF) popisují pravděpodobnost každé možné hodnoty pro diskrétní náhodné proměnné, zatímco funkce hustoty pravděpodobnosti (PDF) slouží ke stejnému účelu pro spojité náhodné proměnné.

```python
# Demonstrace PMF a PDF
# Příklad PMF: Hod dvěma kostkami a součet výsledků
def roll_two_dice_pmf():
    # Všechny možné kombinace dvou kostek
    outcomes = [(i, j) for i in range(1, 7) for j in range(1, 7)]
    
    # Výpočet součtu pro každý výsledek
    sums = [sum(outcome) for outcome in outcomes]
    
    # Počet výskytů každého součtu
    unique_sums = sorted(set(sums))
    counts = [sums.count(s) for s in unique_sums]
    
    # Výpočet pravděpodobností
    probabilities = [count / len(sums) for count in counts]
    
    return unique_sums, probabilities

sums, probabilities = roll_two_dice_pmf()
print("\nPMF pro součet dvou kostek:")
for s, p in zip(sums, probabilities):
    print(f"P(Součet = {s}) = {p:.4f}")

# Vizualizace PMF
plt.figure(figsize=(10, 6))
plt.bar(sums, probabilities)
plt.title('PMF pro součet dvou kostek')
plt.xlabel('Součet')
plt.ylabel('Pravděpodobnost')
plt.xticks(sums)
plt.grid(True, alpha=0.3)
plt.show()

# Příklad PDF: Standardní normální rozdělení
x = np.linspace(-4, 4, 1000)
pdf_values = stats.norm.pdf(x)

plt.figure(figsize=(10, 6))
plt.plot(x, pdf_values)
plt.title('PDF standardního normálního rozdělení')
plt.xlabel('x')
plt.ylabel('Hustota')
plt.grid(True, alpha=0.3)
plt.fill_between(x, pdf_values, where=(x >= -1) & (x <= 1), alpha=0.2, color='red')
plt.text(0, 0.05, f"P(-1 ≤ X ≤ 1) = {stats.norm.cdf(1) - stats.norm.cdf(-1):.4f}")
plt.show()
```

## 5. Střední hodnota a rozptyl

Střední hodnota je dlouhodobý průměr náhodné proměnné, zatímco rozptyl měří rozptýlení hodnot kolem střední hodnoty.

```python
# Výpočet střední hodnoty a rozptylu

# Pro diskrétní náhodnou proměnnou: vážený součet hodnot
# Příklad: Spravedlivá šestistěnná kostka
die_values = [1, 2, 3, 4, 5, 6]
die_probs = [1/6] * 6

# Výpočet střední hodnoty
exp_value = sum(x * p for x, p in zip(die_values, die_probs))

# Výpočet rozptylu
variance = sum(p * (x - exp_value)**2 for x, p in zip(die_values, die_probs))

print(f"\nStřední hodnota spravedlivé kostky: {exp_value}")
print(f"Rozptyl spravedlivé kostky: {variance}")
print(f"Směrodatná odchylka spravedlivé kostky: {np.sqrt(variance)}")

# Simulace mnoha hodů kostkou a porovnání s teoretickými hodnotami
n_simulations = 10000
die_rolls = np.random.choice(die_values, size=n_simulations, p=die_probs)

print("\nVýsledky simulace:")
print(f"Průměr vzorku: {np.mean(die_rolls):.4f} (Teoretický: {exp_value})")
print(f"Rozptyl vzorku: {np.var(die_rolls):.4f} (Teoretický: {variance})")
print(f"Směr. odchylka vzorku: {np.std(die_rolls):.4f} (Teoretická: {np.sqrt(variance):.4f})")

# Vizualizace konvergence průměru vzorku ke střední hodnotě
plt.figure(figsize=(10, 6))
sample_sizes = np.logspace(1, 4, 100, dtype=int)
sample_means = [np.mean(die_rolls[:size]) for size in sample_sizes]
plt.semilogx(sample_sizes, sample_means, 'b-', label='Průměr vzorku')
plt.axhline(y=exp_value, color='r', linestyle='--', label='Střední hodnota')
plt.xlabel('Velikost vzorku (logaritmická škála)')
plt.ylabel('Průměr')
plt.title('Konvergence průměru vzorku ke střední hodnotě')
plt.grid(True)
plt.legend()
plt.show()
```

## 6. Sdružená, marginální a podmíněná pravděpodobnost

Tyto koncepty se vztahují k pravděpodobnostem více událostí a jejich vzájemnému vztahu.

```python
# Vytvoření sdruženého rozdělení pravděpodobnosti
# Příklad: Průzkum 1000 lidí podle pohlaví a úrovně vzdělání

# Vytvoření kontingenční tabulky
education_levels = ['Střední škola', 'Bakalář', 'Magistr', 'PhD']
genders = ['Muž', 'Žena']

# Simulace dat průzkumu
np.random.seed(42)
n_people = 1000
genders_sampled = np.random.choice(genders, n_people, p=[0.48, 0.52])
education_probs = {
    'Muž': [0.45, 0.35, 0.15, 0.05],
    'Žena': [0.40, 0.38, 0.17, 0.05]
}

education_sampled = []
for gender in genders_sampled:
    education_sampled.append(np.random.choice(education_levels, p=education_probs[gender]))

# Vytvoření DataFrame ze vzorkovaných dat
survey_data = pd.DataFrame({
    'Pohlaví': genders_sampled,
    'Vzdělání': education_sampled
})

# Vytvoření kontingenční tabulky
contingency_table = pd.crosstab(survey_data['Pohlaví'], survey_data['Vzdělání'])
print("\nKontingenční tabulka (počty):")
print(contingency_table)

# Převod na sdružené rozdělení pravděpodobnosti
joint_prob = contingency_table / n_people
print("\nSdružené rozdělení pravděpodobnosti:")
print(joint_prob)

# Marginální pravděpodobnosti
gender_marginal = joint_prob.sum(axis=1)
education_marginal = joint_prob.sum(axis=0)

print("\nMarginální pravděpodobnosti pro pohlaví:")
print(gender_marginal)

print("\nMarginální pravděpodobnosti pro vzdělání:")
print(education_marginal)

# Podmíněné pravděpodobnosti: P(Vzdělání | Pohlaví)
conditional_prob = joint_prob.div(gender_marginal, axis=0)
print("\nPodmíněná pravděpodobnost P(Vzdělání | Pohlaví):")
print(conditional_prob)

# Vizualizace sdruženého rozdělení
plt.figure(figsize=(12, 6))
sns.heatmap(joint_prob, annot=True, fmt='.3f', cmap='Blues')
plt.title('Sdružené rozdělení pravděpodobnosti')
plt.tight_layout()
plt.show()

# Kontrola nezávislosti: P(A a B) = P(A) * P(B) pro všechny A, B
independence_check = pd.DataFrame(index=genders, columns=education_levels)
for gender in genders:
    for edu in education_levels:
        # Výpočet P(A) * P(B)
        expected = gender_marginal[gender] * education_marginal[edu]
        # Porovnání se skutečnou P(A a B)
        actual = joint_prob.loc[gender, edu]
        independence_check.loc[gender, edu] = actual - expected

print("\nRozdíl mezi skutečnou sdruženou pravděpodobností a součinem marginálních:")
print(independence_check)
print("\nPokud jsou tyto hodnoty blízko nuly, proměnné jsou nezávislé.")
```

## 7. Bayesova věta a aplikace

Bayesova věta poskytuje způsob, jak aktualizovat pravděpodobnosti na základě nových důkazů, což je nezbytné pro mnoho aplikací v datové vědě.

```python
# Demonstrace Bayesovy věty
# Příklad: Scénář lékařského testování

# Apriorní pravděpodobnosti
p_disease = 0.01  # 1% populace má nemoc
p_no_disease = 1 - p_disease  # 99% nemoc nemá

# Podmíněné pravděpodobnosti (přesnost testu)
p_positive_given_disease = 0.95  # Sensitivita: 95% nemocných má pozitivní test
p_negative_given_no_disease = 0.90  # Specificita: 90% zdravých má negativní test
p_positive_given_no_disease = 1 - p_negative_given_no_disease  # 10% falešně pozitivních

# Výpočet P(disease | positive test) pomocí Bayesovy věty
# P(A|B) = P(B|A) * P(A) / P(B)
# P(disease|positive) = P(positive|disease) * P(disease) / P(positive)

# Výpočet P(positive) pomocí věty o úplné pravděpodobnosti
p_positive = p_positive_given_disease * p_disease + p_positive_given_no_disease * p_no_disease

# Aplikace Bayesovy věty
p_disease_given_positive = (p_positive_given_disease * p_disease) / p_positive

print("\nPříklad Bayesovy věty: Lékařské testování")
print(f"Apriorní pravděpodobnost nemoci: {p_disease:.4f}")
print(f"Pravděpodobnost pozitivního testu při nemoci (sensitivita): {p_positive_given_disease:.4f}")
print(f"Pravděpodobnost negativního testu bez nemoci (specificita): {p_negative_given_no_disease:.4f}")
print(f"Pravděpodobnost pozitivního testu: {p_positive:.4f}")
print(f"Aposteriorní pravděpodobnost nemoci při pozitivním testu: {p_disease_given_positive:.4f}")
print(f"Navzdory vysoké přesnosti testu, pouze {p_disease_given_positive*100:.1f}% pozitivních testů indikuje nemoc!")

# Vizualizace změny aposteriorní pravděpodobnosti s různými apriorními pravděpodobnostmi
prior_values = np.linspace(0.001, 0.1, 100)  # Apriorní pravděpodobnosti od 0.1% do 10%
posterior_values = []

for prior in prior_values:
    p_positive = p_positive_given_disease * prior + p_positive_given_no_disease * (1 - prior)
    posterior = (p_positive_given_disease * prior) / p_positive
    posterior_values.append(posterior)

plt.figure(figsize=(10, 6))
plt.plot(prior_values, posterior_values)
plt.xlabel('Apriorní pravděpodobnost nemoci P(Nemoc)')
plt.ylabel('Aposteriorní pravděpodobnost P(Nemoc|Pozitivní)')
plt.title('Vliv apriorní pravděpodobnosti na aposteriorní pravděpodobnost')
plt.grid(True)
plt.tight_layout()
plt.show()
```

## 8. Simulace a náhodné vzorkování

Simulace je mocnou technikou pro studium problémů pravděpodobnosti, zejména když jsou analytická řešení složitá nebo nemožná.

```python
# Demonstrace simulačních technik pro pravděpodobnostní problémy
# Příklad 1: Metoda Monte Carlo pro odhad π

def monte_carlo_pi(n_samples):
    # Generování náhodných bodů ve čtverci od (0,0) do (1,1)
    points = np.random.uniform(0, 1, size=(n_samples, 2))
    
    # Výpočet vzdálenosti od počátku
    distances = np.sqrt(points[:, 0]**2 + points[:, 1]**2)
    
    # Počítání bodů uvnitř jednotkové čtvrt-kružnice
    inside_circle = np.sum(distances <= 1)
    
    # Poměr bodů uvnitř kružnice k celkovému počtu bodů přibližuje π/4
    pi_estimate = 4 * inside_circle / n_samples
    
    return pi_estimate, points, distances <= 1

# Spuštění simulace
n_samples = 10000
pi_estimate, points, inside = monte_carlo_pi(n_samples)

# Vizualizace simulace
plt.figure(figsize=(10, 10))
plt.scatter(points[inside, 0], points[inside, 1], color='blue', s=1, alpha=0.5)
plt.scatter(points[~inside, 0], points[~inside, 1], color='red', s=1, alpha=0.5)
plt.title(f'Monte Carlo odhad π ≈ {pi_estimate:.6f} (Skutečná hodnota: {np.pi:.6f})')
plt.xlabel('x')
plt.ylabel('y')
plt.axis('equal')
plt.grid(True)
plt.show()

# Příklad 2: Bootstrap vzorkování pro odhad intervalu spolehlivosti střední hodnoty

# Generování populace se známou distribucí
population = np.random.gamma(shape=2, scale=2, size=1000)
true_mean = np.mean(population)

# Výběr vzorku z populace
np.random.seed(42)
sample_size = 50
sample = np.random.choice(population, size=sample_size, replace=False)
sample_mean = np.mean(sample)

# Bootstrap pro odhad intervalu spolehlivosti střední hodnoty
n_bootstraps = 10000
bootstrap_means = []

for _ in range(n_bootstraps):
    # Vzorkování s vracením z původního vzorku
    bootstrap_sample = np.random.choice(sample, size=sample_size, replace=True)
    bootstrap_means.append(np.mean(bootstrap_sample))

# Výpočet 95% intervalu spolehlivosti
confidence_interval = np.percentile(bootstrap_means, [2.5, 97.5])

# Vizualizace bootstrap distribuce
plt.figure(figsize=(10, 6))
sns.histplot(bootstrap_means, kde=True)
plt.axvline(x=sample_mean, color='red', linestyle='--', label='Průměr vzorku')
plt.axvline(x=confidence_interval[0], color='green', linestyle='--', label='2.5. percentil')
plt.axvline(x=confidence_interval[1], color='green', linestyle='--', label='97.5. percentil')
plt.axvline(x=true_mean, color='black', label='Skutečný průměr populace')
plt.title('Bootstrap distribuce průměru vzorku')
plt.xlabel('Průměr')
plt.ylabel('Četnost')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

print("\nVýsledky bootstrapu:")
print(f"Skutečný průměr populace: {true_mean:.4f}")
print(f"Průměr vzorku: {sample_mean:.4f}")
print(f"95% interval spolehlivosti: [{confidence_interval[0]:.4f}, {confidence_interval[1]:.4f}]")
```

## 9. Shrnutí

Pochopení konceptů pravděpodobnosti je základem datové vědy:

1. **Základy pravděpodobnosti** poskytují matematický rámec pro kvantifikaci nejistoty, což je nezbytné při analýze dat a strojovém učení.

2. **Náhodné proměnné** a jejich distribuce pomáhají modelovat reálné jevy a předpovídat na základě dat.

3. **Běžné pravděpodobnostní distribuce** jako normální, binomické a Poissonovo rozdělení mají specifické aplikace při modelování různých typů dat.

4. **Funkce pravděpodobnostní hmoty a hustoty** popisují pravděpodobnost různých výsledků pro diskrétní a spojité náhodné proměnné.

5. **Střední hodnota a rozptyl** pomáhají shrnout distribuce a pochopit centrální tendenci a rozptýlení dat.

6. **Sdružená, marginální a podmíněná pravděpodobnost** poskytují nástroje pro analýzu vztahů mezi více proměnnými.

7. **Bayesova věta** nabízí mocnou metodu aktualizace pravděpodobností na základě nových důkazů a je základem mnoha algoritmů strojového učení.

8. **Simulační techniky** jako metody Monte Carlo a bootstrap vzorkování nám umožňují řešit složité pravděpodobnostní problémy a kvantifikovat nejistotu našich odhadů.

Teorie pravděpodobnosti je základem mnoha metod datové vědy, včetně:
- Statistického usuzování a testování hypotéz
- Algoritmů strojového učení (zejména bayesovských metod)
- Kvantifikace nejistoty
- Hodnocení rizik
- A/B testování a experimentálního designu

Zvládnutím těchto konceptů mohou datoví vědci lépe interpretovat data, budovat přesnější modely a dělat informovanější rozhodnutí v podmínkách nejistoty.
