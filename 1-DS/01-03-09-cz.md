## Úvod do analýzy grafů

Analýza grafů je výkonný přístup k pochopení komplexních vztahů mezi entitami. V datové vědě poskytují grafy přirozený způsob reprezentace a analýzy propojených dat, odhalující vzory a poznatky, které by mohlo být obtížné objevit pomocí tradičních tabulkových metod.

Graf se skládá z:
- **Uzlů** (nebo vrcholů): Reprezentující entity
- **Hran**: Reprezentující vztahy mezi entitami
- **Vlastností**: Atributů, které mohou být připojeny k uzlům a hranám

## Základy teorie grafů

Před ponořením se do nástrojů je důležité porozumět některým základním konceptům teorie grafů, které tvoří základ analýzy grafů.

### Typy grafů

```python
# Vytvoření různých typů grafů
# Neorientovaný graf
G_undirected = nx.Graph()

# Orientovaný graf
G_directed = nx.DiGraph()

# Vážený graf
G_weighted = nx.Graph()
G_weighted.add_edge('A', 'B', weight=0.6)
G_weighted.add_edge('B', 'C', weight=0.2)

# Multi-graf (umožňuje více hran mezi stejnými uzly)
G_multi = nx.MultiGraph()
G_multi.add_edge('A', 'B', key='relation1')
G_multi.add_edge('A', 'B', key='relation2')

# Zobrazení informací o grafu
print(f"Neorientovaný graf: {G_undirected}")
print(f"Orientovaný graf: {G_directed}")
print(f"Vážený graf hrany: {G_weighted.edges(data=True)}")
print(f"Multi-graf hrany: {G_multi.edges(data=True)}")
```

### Důležité vlastnosti grafů

- **Konektivita**: Zda jsou všechny uzly spojeny
- **Cesta**: Posloupnost uzlů, kde každý sousední pár je spojen hranou
- **Cyklus**: Cesta, která začíná a končí ve stejném uzlu
- **Stupeň**: Počet hran spojených s uzlem
- **Centralita**: Míra důležitosti uzlu v síti

```python
# Vytvoření jednoduchého grafu pro demonstraci vlastností
G = nx.Graph()
edges = [('A', 'B'), ('B', 'C'), ('C', 'D'), ('D', 'A'), ('A', 'E')]
G.add_edges_from(edges)

# Kontrola konektivity
is_connected = nx.is_connected(G)
print(f"Je graf spojitý? {is_connected}")

# Nalezení nejkratší cesty
shortest_path = nx.shortest_path(G, 'A', 'C')
print(f"Nejkratší cesta z A do C: {shortest_path}")

# Kontrola cyklů
cycles = list(nx.simple_cycles(nx.DiGraph(G)))
print(f"Cykly v grafu: {cycles}")

# Výpočet stupně pro každý uzel
for node in G.nodes():
    print(f"Uzel {node} má stupeň {G.degree(node)}")
```

## Úvod do Neo4j

Neo4j je systém pro správu grafových databází, který ukládá data v uzlech a vztazích místo tabulek. Je optimalizován pro procházení vztahů, což je ideální pro vysoce propojená data.

### Klíčové koncepty

- **Uzly**: Entity s štítky a vlastnostmi
- **Vztahy**: Propojení mezi uzly s typy a vlastnostmi
- **Štítky**: Seskupení uzlů do množin
- **Vlastnosti**: Páry klíč-hodnota uložené v uzlech a vztazích
- **Cypher**: Deklarativní dotazovací jazyk pro Neo4j

```python
def neo4j_to_networkx(conn):
    # Dotaz na všechny uzly a vztahy
    nodes = conn.query("""
        MATCH (n) 
        RETURN id(n) as id, labels(n) as labels, properties(n) as props
    """)
    
    relationships = conn.query("""
        MATCH (n)-[r]->(m)
        RETURN id(n) as source, id(m) as target, type(r) as type, properties(r) as props
    """)
    
    # Vytvoření NetworkX grafu
    G = nx.DiGraph()
    
    # Přidání uzlů s atributy
    for node in nodes:
        G.add_node(node['id'], labels=node['labels'], **node['props'])
    
    # Přidání hran s atributy
    for rel in relationships:
        G.add_edge(rel['source'], rel['target'], type=rel['type'], **rel['props'])
    
    return G
```

## Praktické aplikace analýzy grafů

Podívejme se na některé běžné aplikace analýzy grafů v datové vědě.

### Analýza sociálních sítí

```python
# Načtení skutečného datasetu sociální sítě
# Zacharyho Karate klub
G_karate = nx.karate_club_graph()

# Výpočet klíčových metrik sociální sítě
# Betweenness centralita - identifikuje mosty mezi komunitami
betweenness = nx.betweenness_centrality(G_karate)
top_betweenness = sorted(betweenness.items(), key=lambda x: x[1], reverse=True)[:5]
print("Top 5 uzlů podle betweenness centrality:", top_betweenness)

# Closeness centralita - identifikuje uzly, které mohou rychle dosáhnout ostatních
closeness = nx.closeness_centrality(G_karate)
top_closeness = sorted(closeness.items(), key=lambda x: x[1], reverse=True)[:5]
print("Top 5 uzlů podle closeness centrality:", top_closeness)

# Koeficient shlukování - míra tendence uzlů shlukovat se dohromady
clustering = nx.average_clustering(G_karate)
print(f"Průměrný koeficient shlukování: {clustering:.4f}")
```

```python
# Vytvoření grafu pro doporučování filmů

# Přidání uzlů filmů
movies = ['Movie1', 'Movie2', 'Movie3', 'Movie4', 'Movie5', 'Movie6']
G_movies.add_nodes_from(movies, type='movie')

# Přidání hran reprezentujících hodnocení uživatelů (uživatel sledoval film)
ratings = [
    ('User1', 'Movie1', {'rating': 5}),
    ('User1', 'Movie2', {'rating': 4}),
    ('User1', 'Movie4', {'rating': 3}),
    ('User2', 'Movie2', {'rating': 5}),
    ('User2', 'Movie3', {'rating': 4}),
    ('User2', 'Movie5', {'rating': 3}),
    ('User3', 'Movie1', {'rating': 2}),
    ('User3', 'Movie3', {'rating': 5}),
    ('User3', 'Movie6', {'rating': 4}),
    ('User4', 'Movie1', {'rating': 3}),
    ('User4', 'Movie4', {'rating': 5}),
    ('User4', 'Movie5', {'rating': 4}),
    ('User5', 'Movie2', {'rating': 3}),
    ('User5', 'Movie5', {'rating': 5}),
    ('User5', 'Movie6', {'rating': 4}),
]
G_movies.add_edges_from(ratings)

# Funkce pro nalezení doporučení filmů pro uživatele
def recommend_movies(G, user, n=2):
    # Získání filmů, které uživatel již sledoval
    watched_movies = [neighbor for neighbor in G.neighbors(user)
                     if G.nodes[neighbor]['type'] == 'movie']
    
    # Nalezení uživatelů s podobnými preferencemi
    similar_users = []
    for movie in watched_movies:
        for other_user in G.neighbors(movie):
            if other_user != user and G.nodes[other_user]['type'] == 'user':
                similar_users.append(other_user)
    
    # Počítání frekvence podobných uživatelů
    from collections import Counter
    user_counts = Counter(similar_users)
    most_similar = [user for user, count in user_counts.most_common(2)]
    
    # Nalezení filmů sledovaných podobnými uživateli, ale ne cílovým uživatelem
    recommendations = set()
    for similar_user in most_similar:
        movies_by_similar = [m for m in G.neighbors(similar_user) 
                            if G.nodes[m]['type'] == 'movie']
        for movie in movies_by_similar:
            if movie not in watched_movies:
                # Získání hodnocení od podobného uživatele
                edge_data = G.get_edge_data(similar_user, movie)
                rating = edge_data.get('rating', 0)
                recommendations.add((movie, rating))
    
    # Vrácení top N doporučení podle hodnocení
    top_recommendations = sorted(recommendations, key=lambda x: x[1], reverse=True)[:n]
    return top_recommendations

# Získání doporučení pro uživatele
for user in users:
    recommendations = recommend_movies(G_movies, user)
    print(f"Doporučení pro {user}: {recommendations}")
```

```python
# Vytvoření sítě finančních transakcí pro detekci podvodů
G_finance = nx.DiGraph()

# Přidání uzlů účtů
accounts = [f'Account{i}' for i in range(1, 11)]
G_finance.add_nodes_from(accounts, type='account')

# Přidání hran transakcí
import random
random.seed(42)

# Normální transakce
normal_transactions = []
for i in range(30):
    source = random.choice(accounts)
    target = random.choice([a for a in accounts if a != source])
    amount = round(random.uniform(10, 1000), 2)
    timestamp = f"2023-{random.randint(1,12):02d}-{random.randint(1,28):02d}"
    normal_transactions.append((source, target, {'amount': amount, 'timestamp': timestamp, 'type': 'normal'}))

G_finance.add_edges_from(normal_transactions)

# Přidání podezřelého vzoru - kruhové transakce
suspicious_circle = [
    ('Account1', 'Account3', {'amount': 5000, 'timestamp': '2023-05-01', 'type': 'suspicious'}),
    ('Account3', 'Account7', {'amount': 4800, 'timestamp': '2023-05-01', 'type': 'suspicious'}),
    ('Account7', 'Account1', {'amount': 4700, 'timestamp': '2023-05-02', 'type': 'suspicious'})
]
G_finance.add_edges_from(suspicious_circle)

# Detekce cyklů jako potenciálních indikátorů podvodů
cycles = list(nx.simple_cycles(G_finance))
print(f"Nalezeno {len(cycles)} cyklů v transakční síti:")
for cycle in cycles:
    print(f"  Cyklus: {' -> '.join(cycle)}")
    # Výpočet celkového toku v cyklu
    total_amount = 0
    for i in range(len(cycle)):
        source = cycle[i]
        target = cycle[(i + 1) % len(cycle)]
        edge_data = G_finance.get_edge_data(source, target)
        if edge_data:
            total_amount += edge_data.get('amount', 0)
    print(f"  Celková částka transakcí v cyklu: ${total_amount:.2f}")

# Výpočet PageRank pro identifikaci důležitých účtů
pagerank = nx.pagerank(G_finance)
top_pagerank = sorted(pagerank.items(), key=lambda x: x[1], reverse=True)[:3]
print("\nTop 3 účty podle PageRank:")
for account, score in top_pagerank:
    print(f"  {account}: {score:.4f}")

# Vizualizace transakční sítě
plt.figure(figsize=(12, 10))
pos = nx.spring_layout(G_finance, seed=42)

# Vykreslení uzlů
nx.draw_networkx_nodes(G_finance, pos, node_size=500, node_color='lightblue')

normal_edges = [(u, v) for u, v, d in G_finance.edges(data=True) if d['type'] == 'normal']
nx.draw_networkx_edges(G_finance, pos, edgelist=normal_edges, edge_color='gray', arrows=True)

suspicious_edges = [(u, v) for u, v, d in G_finance.edges(data=True) if d['type'] == 'suspicious']

                      width=2.0, arrows=True)

nx.draw_networkx_labels(G_finance, pos, font_size=10)

plt.tight_layout()
plt.show()
```

### Klíčové poznatky:

   - **Míry centrality**: Identifikace důležitých uzlů v síti
   - **Detekce komunit**: Nalezení skupin hustě propojených uzlů
   - **Analýza cest**: Studium propojení a toků v grafu
   - **Grafové algoritmy**: Aplikace specializovaných algoritmů pro získání poznatků

4. **Vizualizace**: Použijte vizualizační techniky k získání intuitivního pochopení struktury grafu.

   - Detekce podvodů
   - Znalostní grafy
   - Optimalizace sítí

4. **Vizualizace**: Použijte umístění uzlů, barvy a velikosti k zvýraznění důležitých vzorů
5. **Integrace**: Kombinujte analýzu grafů s tradičními technikami strojového učení
6. **Validace**: Ověřte poznatky pomocí doménových znalostí a více metrik
