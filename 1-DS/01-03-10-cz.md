## Úvod do geoprostorových dat

Analýza geoprostorových dat zahrnuje analýzu dat, která mají geografické nebo prostorové komponenty. Může se jednat o souřadnice (zeměpisná šířka/délka), adresy, poštovní směrovací čísla nebo geografické hranice. Geoprostorová analýza nám umožňuje odpovídat na otázky založené na lokaci a objevovat prostorové vzory, které by mohly být neviditelné v tradičních tabulkových datech.

Klíčové koncepty v geoprostorové analýze zahrnují:
- **Geografické souřadnice**: Hodnoty zeměpisné šířky a délky, které určují polohu
- **Projekce**: Metody pro reprezentaci zakřiveného povrchu Země na ploché mapě
- **Prostorové vztahy**: Jak spolu prvky souvisejí (vzdálenost, obsažení, sousednost)
- **Vektorová data**: Body, linie a polygony reprezentující diskrétní prvky
- **Rastrová data**: Data založená na mřížce reprezentující spojité jevy

```python
# Pochopení základních geografických souřadnic
import pandas as pd

# Ukázková data o lokacích
locations = pd.DataFrame({
    'name': ['New York', 'Los Angeles', 'Chicago', 'Houston', 'Phoenix'],
    'latitude': [40.7128, 34.0522, 41.8781, 29.7604, 33.4484],
    'longitude': [-74.0060, -118.2437, -87.6298, -95.3698, -112.0740]
})

print("Ukázková data o lokacích:")
print(locations)

# Výpočet vzdálenosti mezi dvěma body (zjednodušeno pro příklad)
from math import radians, cos, sin, sqrt, asin

def haversine_distance(lat1, lon1, lat2, lon2):
    # Převod desetinných stupňů na radiány
    lat1, lon1, lat2, lon2 = map(radians, [lat1, lon1, lat2, lon2])
    
    # Haversinův vzorec
    dlon = lon2 - lon1
    dlat = lat2 - lat1
    a = sin(dlat/2)**2 + cos(lat1) * cos(lat2) * sin(dlon/2)**2
    c = 2 * asin(sqrt(a))
    r = 6371  # Poloměr Země v kilometrech
    return c * r

# Výpočet vzdálenosti mezi New Yorkem a Los Angeles
ny = locations.iloc[0]
la = locations.iloc[1]
distance = haversine_distance(ny['latitude'], ny['longitude'], la['latitude'], la['longitude'])
print(f"Vzdálenost mezi {ny['name']} a {la['name']}: {distance:.2f} kilometrů")
```

## Formáty geoprostorových dat

Geoprostorová data přicházejí v různých formátech, každý se svými vlastními silnými stránkami a případy použití:

- **Shapefiles**: Tradiční formát s soubory .shp, .shx a .dbf
- **GeoJSON**: Lehký formát založený na JSON
- **KML**: Formát založený na XML, používaný v Google Earth
- **GeoTIFF**: Rastrový formát s geografickými metadaty
- **PostGIS/Spatialite**: Rozšíření prostorových databází


## Základní geoprostorové operace

GeoPandas rozšiřuje Pandas o geometrické operace. Zde jsou některé základní operace pro práci s geoprostorovými daty:

```python
# Vytváření geometrických objektů
from shapely.geometry import Point, LineString, Polygon
import geopandas as gpd

# Vytvoření bodu
point = Point(0, 0)
print(f"Bod: {point}")

# Vytvoření linie
line = LineString([(0, 0), (1, 1), (2, 0)])
print(f"Linie: {line}")

# Vytvoření polygonu
polygon = Polygon([(0, 0), (1, 0), (1, 1), (0, 1)])
print(f"Polygon: {polygon}")

# Vytvoření GeoDataFrame s různými geometriemi
geometry = [Point(0, 0), Point(1, 1), Point(2, 2)]
gdf = gpd.GeoDataFrame(geometry=geometry)
print("\nGeoDataFrame s body:")
print(gdf)

# Základní prostorové operace
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# Filtrování pro získání pouze USA
us = world[world.name == "United States of America"]
print("\nData USA:")
print(us)

# Výpočet rozlohy (ve čtverečních stupních, ne příliš užitečné, ale demonstruje koncept)
us['area_deg'] = us.geometry.area
print(f"Rozloha USA polygonu: {us['area_deg'].values[0]:.4f} čtverečních stupňů")

# Operace buffer (vytvoření zóny kolem prvků)
us_buffer = us.copy()
us_buffer.geometry = us.geometry.buffer(2)  # 2 stupně buffer
print(f"Původní rozloha: {us.geometry.area.values[0]:.4f}")
print(f"Rozloha s bufferem: {us_buffer.geometry.area.values[0]:.4f}")

# Zjednodušení geometrií (užitečné pro složité polygony)
us_simple = us.copy()
us_simple.geometry = us.geometry.simplify(0.1)
print(f"Původní počet vrcholů: {len(next(iter(us.geometry)).exterior.coords)}")
print(f"Počet vrcholů po zjednodušení: {len(next(iter(us_simple.geometry)).exterior.coords)}")
```

```python
# Zobrazení mapy
m

m.save('world_map.html')
```

## Techniky prostorové analýzy

Prostorová analýza zahrnuje zkoumání umístění, atributů a vztahů prvků v geografických datech. Běžné techniky zahrnují:

```python
# Prostorové spojování, překryvy a výpočty vzdáleností
import geopandas as gpd
import matplotlib.pyplot as plt
from shapely.geometry import Point

# Načtení hranic světa
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# Vytvoření náhodných bodů
import numpy as np
np.random.seed(42)
n_points = 100
lon = np.random.uniform(-180, 180, n_points)
lat = np.random.uniform(-90, 90, n_points)
points = gpd.GeoDataFrame(
    {'id': range(n_points)},
    geometry=[Point(xy) for xy in zip(lon, lat)]
)
points.crs = world.crs  # Zajištění stejného CRS jako má svět

# Prostorové spojení: která země obsahuje každý bod?
joined = gpd.sjoin(points, world, op='within')
print("Body spojené se zeměmi (prvních 5 řádků):")
print(joined[['id', 'name', 'continent']].head())

# Počítání bodů podle zemí
point_counts = joined.groupby('name').size().reset_index(name='point_count')
point_counts = point_counts.sort_values('point_count', ascending=False)
print("\nTop 5 zemí podle počtu náhodných bodů:")
print(point_counts.head())

# Sloučení dat o počtu zpět do světa pro mapování
world_with_counts = world.merge(point_counts, on='name', how='left')
world_with_counts['point_count'] = world_with_counts['point_count'].fillna(0)

# Vytvoření choroplethové mapy
fig, ax = plt.subplots(figsize=(12, 6))
world_with_counts.plot(
    column='point_count',
    cmap='OrRd',
    legend=True,
    ax=ax,
    legend_kwds={'label': 'Počet bodů', 'orientation': 'horizontal'}
)
ax.set_title('Náhodné body na zemi')
ax.set_axis_off()
plt.tight_layout()
plt.show()

# Prostorový překryv - průsečík geometrií
# Najdeme země v určitém ohraničujícím rámečku
bbox = Polygon([(-50, 0), (50, 0), (50, 50), (-50, 50), (-50, 0)])
bbox_gdf = gpd.GeoDataFrame({'id': [1]}, geometry=[bbox], crs=world.crs)

# Průsečík bbox se zeměmi
intersected = gpd.overlay(world, bbox_gdf, how='intersection')

# Zobrazení protnutých zemí
print("\nZemě protínající se s ohraničujícím rámečkem:")
print(intersected[['name', 'continent']])

# Vykreslení výsledků
fig, ax = plt.subplots(figsize=(12, 6))
world.plot(ax=ax, color='lightgray', edgecolor='black')
intersected.plot(ax=ax, color='red', alpha=0.5)
bbox_gdf.boundary.plot(ax=ax, color='blue', linewidth=2)
ax.set_title('Země protínající se s ohraničujícím rámečkem')
plt.axis('off')
plt.tight_layout()
plt.show()

# Operace založené na vzdálenosti
# Najít země do 5 stupňů od bodu
point_location = Point(0, 0)  # Nulový ostrov
buffer_distance = 20  # stupňů
buffer = gpd.GeoDataFrame(
    {'id': [1]}, 
    geometry=[point_location.buffer(buffer_distance)], 
    crs=world.crs
)

# Země, které se protínají s bufferem
countries_near_point = gpd.overlay(world, buffer, how='intersection')
print("\nZemě v rámci vzdálenosti bufferu od bodu:")
print(countries_near_point[['name']].head())

# Vizualizace
fig, ax = plt.subplots(figsize=(12, 6))
world.plot(ax=ax, color='lightgray', edgecolor='black')
buffer.plot(ax=ax, color='blue', alpha=0.2)
countries_near_point.plot(ax=ax, color='red', alpha=0.5)
ax.scatter(0, 0, color='black', s=50)  # Střední bod
ax.set_title(f'Země do {buffer_distance} stupňů od (0, 0)')
plt.axis('off')
plt.tight_layout()
plt.show()
```

## Integrace se strojovým učením

Geoprostorové vlastnosti mohou být silnými prediktory v modelech strojového učení. Zde je návod, jak integrovat geoprostorová data do pracovního postupu strojového učení:

```python
# Integrace geoprostorových dat se strojovým učením
import geopandas as gpd
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error
import matplotlib.pyplot as plt

# Načtení světových dat
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# Vytvoření syntetických dat pro demonstraci
# Předvídáme HDP na základě geografických a demografických vlastností
np.random.seed(42)
world['gdp_per_capita'] = (
    world['pop_est'] / 1e7 +  # Populační faktor
    np.abs(world.geometry.centroid.x) / 50 +  # Faktor zeměpisné délky
    np.abs(world.geometry.centroid.y) / 20 +  # Faktor zeměpisné šířky
    world.geometry.area / 30 +  # Faktor rozlohy
    np.random.normal(0, 5, len(world))  # Náhodný šum
)

# Extrakce vlastností z geoprostorových dat
world['centroid_x'] = world.geometry.centroid.x
world['centroid_y'] = world.geometry.centroid.y
world['area'] = world.geometry.area
world['bbox_width'] = world.geometry.bounds.maxx - world.geometry.bounds.minx
world['bbox_height'] = world.geometry.bounds.maxy - world.geometry.bounds.miny
world['perimeter'] = world.geometry.length

# One-hot kódování kontinentu
world_with_dummies = pd.get_dummies(world, columns=['continent'], prefix='cont')

# Výběr vlastností a cíle
features = [
    'pop_est', 'centroid_x', 'centroid_y', 'area', 
    'bbox_width', 'bbox_height', 'perimeter'
] + [col for col in world_with_dummies.columns if col.startswith('cont_')]

X = world_with_dummies[features]
y = world_with_dummies['gdp_per_capita']

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Trénování modelu náhodného lesa
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

# Predikce
y_pred = model.predict(X_test)

# Vyhodnocení modelu
mse = mean_squared_error(y_test, y_pred)
print(f"Střední kvadratická chyba: {mse:.2f}")
print(f"RMSE: {np.sqrt(mse):.2f}")

# Důležitost vlastností
feature_importance = pd.DataFrame({
    'Feature': features,
    'Importance': model.feature_importances_
}).sort_values('Importance', ascending=False)

print("\n5 nejdůležitějších vlastností:")
print(feature_importance.head())

# Vykreslení důležitosti vlastností
plt.figure(figsize=(10, 6))
plt.barh(feature_importance['Feature'][:10], feature_importance['Importance'][:10])
plt.xlabel('Důležitost')
plt.title('Top 10 důležitých vlastností')
plt.gca().invert_yaxis()  # Zobrazení odshora dolů
plt.tight_layout()
plt.show()

# Vytvoření mapy skutečných vs. předpovídaných hodnot
# Přidání predikcí zpět do testovacích dat
world_with_dummies['test_set'] = False
test_indices = world_with_dummies.index.isin(X_test.index)
world_with_dummies.loc[test_indices, 'test_set'] = True
world_with_dummies.loc[test_indices, 'predicted_gdp'] = y_pred

# Vytvoření mapy
fig, axs = plt.subplots(1, 2, figsize=(18, 6))

# Mapa skutečných hodnot
world_test = world_with_dummies[world_with_dummies['test_set']]
world_test.plot(
    column='gdp_per_capita',
    cmap='viridis',
    legend=True,
    ax=axs[0],
    legend_kwds={'label': 'Skutečné HDP na obyvatele'},
    missing_kwds={'color': 'lightgrey'}
)
axs[0].set_title('Skutečné HDP na obyvatele')
axs[0].set_axis_off()

# Mapa předpovídaných hodnot
world_test.plot(
    column='predicted_gdp',
    cmap='viridis',
    legend=True,
    ax=axs[1],
    legend_kwds={'label': 'Předpovídané HDP na obyvatele'},
    missing_kwds={'color': 'lightgrey'}
)
axs[1].set_title('Předpovídané HDP na obyvatele')
axs[1].set_axis_off()

plt.tight_layout()
plt.show()
```

## Případové studie: Aplikace v reálném světě

Prozkoumejme aplikaci v reálném světě analýzou dostupnosti veřejné dopravy ve městě:

```python
# Případová studie: Analýza dostupnosti veřejné dopravy
import geopandas as gpd
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np
from shapely.geometry import Point, LineString
import contextily as ctx

# Vytvoření ukázkových dat pro fiktivní město
# 1. Čtvrti města
coordinates = [
    [(-1, -1), (-1, 1), (1, 1), (1, -1)],  # Centrum
    [(-3, -1), (-3, 1), (-1, 1), (-1, -1)],  # Západ
    [(-1, 1), (-1, 3), (1, 3), (1, 1)],  # Sever
    [(1, -1), (1, 1), (3, 1), (3, -1)],  # Východ
    [(-1, -3), (-1, -1), (1, -1), (1, -3)]   # Jih
]
neighborhoods = gpd.GeoDataFrame({
    'name': ['Centrum', 'Západ', 'Sever', 'Východ', 'Jih'],
    'population': [12000, 25000, 18000, 15000, 22000]
}, geometry=[Polygon(coords) for coords in coordinates], crs="EPSG:3857")

# 2. Zastávky autobusů
np.random.seed(42)
n_stops = 40
x = np.random.uniform(-3, 3, n_stops)
y = np.random.uniform(-3, 3, n_stops)
bus_stops = gpd.GeoDataFrame({
    'stop_id': range(1, n_stops + 1),
    'name': [f'Zastávka {i}' for i in range(1, n_stops + 1)]
}, geometry=[Point(x[i], y[i]) for i in range(n_stops)], crs="EPSG:3857")

# 3. Autobusové trasy (zjednodušeno pro příklad)
routes = []
route_names = []

# Trasa 1: Východ-Západ
route1 = LineString([(-3, 0), (3, 0)])
routes.append(route1)
route_names.append("Trasa 1: V-Z")

# Trasa 2: Sever-Jih
route2 = LineString([(0, -3), (0, 3)])
routes.append(route2)
route_names.append("Trasa 2: S-J")

# Trasa 3: Okružní
route3 = LineString([(-2, -2), (-2, 2), (2, 2), (2, -2), (-2, -2)])
routes.append(route3)
route_names.append("Trasa 3: Okruh")

bus_routes = gpd.GeoDataFrame({
    'route_name': route_names,
    'frequency': [10, 15, 20]  # minuty mezi autobusy
}, geometry=routes, crs="EPSG:3857")

# Výpočet metrik přístupu:
# 1. Zastávky na čtvrť
neighborhood_stops = gpd.sjoin(neighborhoods, bus_stops, op='contains')
stops_per_neighborhood = neighborhood_stops.groupby('name').size().rename('stop_count')
neighborhoods = neighborhoods.merge(stops_per_neighborhood, left_on='name', right_index=True, how='left')
neighborhoods['stop_count'] = neighborhoods['stop_count'].fillna(0)

# 2. Frekvence služby (průměrná frekvence tras v rámci vzdálenosti bufferu od středu čtvrti)
neighborhoods['center_point'] = neighborhoods.geometry.centroid
stops_with_routes = gpd.sjoin(bus_stops, bus_routes.to_crs(bus_stops.crs), op='intersects', rsuffix='_route')

# Výpočet průměrné frekvence
avg_freq = stops_with_routes.groupby('name')['frequency'].mean().rename('avg_frequency')
neighborhoods = neighborhoods.merge(avg_freq, left_on='name', right_index=True, how='left')
neighborhoods['avg_frequency'] = neighborhoods['avg_frequency'].fillna(0)

# 3. Výpočet skóre dostupnosti
neighborhoods['stops_per_1000'] = 1000 * neighborhoods['stop_count'] / neighborhoods['population']
neighborhoods['accessibility_score'] = (
    neighborhoods['stops_per_1000'] * 10 +  # Více zastávek je lepší
    (30 - neighborhoods['avg_frequency']) / 5  # Nižší frekvence (minuty) je lepší
)

# Vizualizace výsledků
fig, axes = plt.subplots(2, 2, figsize=(15, 12))

# 1. Zastávky a trasy autobusů
ax = axes[0, 0]
```

## Výkonnostní aspekty

Při práci s velkými geoprostorovými datovými sadami se výkon stává kritickým problémem. Zde jsou strategie pro zlepšení výkonu:

```python
# Výkonnostní aspekty pro geoprostorová data
import geopandas as gpd
import pandas as pd
import time
from shapely.geometry import box
import psutil
import os

# Funkce pro měření doby provádění a využití paměti
def measure_performance(func):
    def wrapper(*args, **kwargs):
        # Paměť před
        process = psutil.Process(os.getpid())
        mem_before = process.memory_info().rss / 1024 / 1024  # MB
        
        # Čas provádění
        start_time = time.time()
        result = func(*args, **kwargs)
        execution_time = time.time() - start_time
        
        # Paměť po
        mem_after = process.memory_info().rss / 1024 / 1024  # MB
        mem_used = mem_after - mem_before
        
        print(f"Funkce {func.__name__}:")
        print(f"  Doba provádění: {execution_time:.4f} sekund")
        print(f"  Použitá paměť: {mem_used:.2f} MB")
        return result
    return wrapper

# Načtení ukázkových dat
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# Technika 1: Zjednodušení geometrií
@measure_performance
def analyze_original():
    # Výpočet oblasti a obvodu pro všechny země
    areas = world.geometry.area
    perimeters = world.geometry.length
    return areas, perimeters

@measure_performance
def analyze_simplified():
    # Nejprve zjednodušte geometrie, pak počítejte
    simple_world = world.copy()
    simple_world.geometry = world.geometry.simplify(0.1)
    areas = simple_world.geometry.area
    perimeters = simple_world.geometry.length
    return areas, perimeters

print("Porovnání výkonu s původními vs. zjednodušenými geometriemi:")
orig_results = analyze_original()
simp_results = analyze_simplified()

# Kontrola rozdílu přesnosti
area_diff_pct = abs(orig_results[0] - simp_results[0]).mean() / orig_results[0].mean() * 100
print(f"Průměrný rozdíl plochy: {area_diff_pct:.2f}%")

# Technika 2: Prostorové indexování pro efektivní dotazování
@measure_performance
def query_without_index():
    # Vytvořte ohraničující rámeček
    query_box = box(-50, -50, 50, 50)
    
    # Najděte země, které se protínají s rámečkem bez indexu
    results = []
    for idx, country in world.iterrows():
        if country.geometry.intersects(query_box):
            results.append(idx)
    return results

@measure_performance
def query_with_index():
    # Vytvořte ohraničující rámeček
    query_box = box(-50, -50, 50, 50)
    
    # Najděte země pomocí prostorového indexu
    spatial_index = world.sindex
    possible_matches_index = list(spatial_index.intersection(query_box.bounds))
    possible_matches = world.iloc[possible_matches_index]
    precise_matches = possible_matches[possible_matches.intersects(query_box)]
    return precise_matches.index.tolist()

print("\nPorovnání výkonu dotazu s a bez prostorového indexu:")
without_index_results = query_without_index()
with_index_results = query_with_index()
print(f"Počet výsledků: {len(with_index_results)}")

# Technika 3: Optimalizace operací atributů před prostorovými
@measure_performance
def inefficient_workflow():
    # Nejprve proveďte prostorové filtrování, pak filtrování atributů
    europe = world[world.geometry.intersects(box(-30, 35, 40, 70))]
    result = europe[europe.pop_est > 1000000]
    return result

@measure_performance
def efficient_workflow():
    # Nejprve proveďte filtrování atributů, pak prostorové filtrování
    large_countries = world[world.pop_est > 1000000]
    result = large_countries[large_countries.geometry.intersects(box(-30, 35, 40, 70))]
    return result

print("\nPorovnání efektivity pracovního postupu:")
inefficient_result = inefficient_workflow()
efficient_result = efficient_workflow()
print(f"Počet výsledků: {len(efficient_result)}")

# Technika 4: Použití spojení atributů namísto prostorových spojení, když je to možné
countries_df = pd.DataFrame({
    'name': world.name,
    'continent': world.continent,
    'population': world.pop_est
})

cities = gpd.GeoDataFrame({
    'city': ['New York', 'London', 'Tokyo', 'Rio'],
    'country': ['United States of America', 'United Kingdom', 'Japan', 'Brazil'],
    'population': [8.4, 8.9, 13.5, 6.7]
}, geometry=gpd.points_from_xy([-74.0, 0.1, 139.7, -43.2], [40.7, 51.5, 35.7, -22.9]))

@measure_performance
def spatial_join_approach():
    # Použití prostorového spojení (pomalejší)
    return gpd.sjoin(cities, world, op='within')

@measure_performance
def attribute_join_approach():
    # Použití spojení atributů (rychlejší)
    return cities.merge(countries_df, left_on='country', right_on='name')

print("\nPorovnání metod spojení:")
spatial_result = spatial_join_approach()
attribute_result = attribute_join_approach()
```

## Shrnutí a osvědčené postupy

Analýza geoprostorových dat je silným doplňkem k sadě nástrojů datového vědce, umožňující poznatky, které by byly nemožné pouze s tradičními tabulkovými daty. Zde jsou klíčové poznatky a osvědčené postupy:

1. **Příprava dat**:
   - Vždy zkontrolujte a standardizujte souřadnicový referenční systém (CRS)
   - Zjednodušte geometrie, když není potřeba vysoká přesnost
   - Pro velké datové sady používejte vhodné prostorové indexy

2. **Pracovní postup analýzy**:
   - Filtrujte podle neprostorových atributů před prováděním prostorových operací
   - Vyberte správné geometrické operace pro vaše analytické potřeby
   - Kombinujte prostorové a tradiční datové vlastnosti pro bohatší vhled

3. **Vizualizace**:
   - Používejte statické mapy pro zprávy a interaktivní mapy pro průzkum
   - Vyberte vhodná barevná schémata pro choropletové mapy
   - Přidejte kontextové vrstvy, jako jsou podkladové mapy, když je to vhodné

4. **Integrace s ML**:
   - Extrahujte smysluplné geometrické vlastnosti (těžiště, plochy atd.)
   - Zvažte prostorové vztahy jako vlastnosti
   - Ověřte modely pomocí vhodné prostorové křížové validace

5. **Optimalizace výkonu**:
   - Používejte prostorové indexy pro dotazy
   - Zjednodušte geometrie, když není kritická přesnost
   - Preferujte spojení atributů před prostorovými spojeními, když je to možné
   - Pracujte s projektovanými daty pro přesná měření

