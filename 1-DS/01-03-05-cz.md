## Úvod do bayesovské statistiky

Bayesovská statistika je matematický přístup, který nám umožňuje aktualizovat naše přesvědčení o parametrech nebo hypotézách na základě dostupných dat. Je pojmenována po Thomasi Bayesovi, statistikovi a teologovi z 18. století, který položil základy tohoto přístupu.

V jádru bayesovské statistiky jsou:
- Začátek s **apriorním rozdělením** představujícím naše počáteční přesvědčení
- Sběr dat
- Aktualizace našich přesvědčení na **posteriorní rozdělení** pomocí Bayesovy věty

```python
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

# Nastavení stylu grafů
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Vytvoření jednoduchého grafu demonstrující apriorní, věrohodnostní a posteriorní rozdělení
def plot_bayesian_updating(prior_mean, prior_std, likelihood_mean, likelihood_std):
    x = np.linspace(0, 10, 1000)
    
    # Apriorní rozdělení
    prior = stats.norm.pdf(x, prior_mean, prior_std)
    
    # Funkce věrohodnosti
    likelihood = stats.norm.pdf(x, likelihood_mean, likelihood_std)
    
    # Výpočet posteriorního rozdělení (nenormalizovaného)
    posterior_unnorm = prior * likelihood
    # Normalizace posteriorního rozdělení
    posterior = posterior_unnorm / np.trapz(posterior_unnorm, x)
    
    # Analytický výpočet posteriorního rozdělení
    posterior_mean = (prior_mean/prior_std**2 + likelihood_mean/likelihood_std**2) / \
                    (1/prior_std**2 + 1/likelihood_std**2)
    posterior_std = np.sqrt(1 / (1/prior_std**2 + 1/likelihood_std**2))
    
    # Vytvoření grafu
    plt.figure(figsize=(12, 8))
    plt.plot(x, prior, 'b-', label='Apriorní')
    plt.plot(x, likelihood, 'r-', label='Věrohodnostní')
    plt.plot(x, posterior, 'g-', label='Posteriorní')
    plt.fill_between(x, 0, posterior, color='green', alpha=0.2)
    
    plt.axvline(prior_mean, color='b', linestyle='--', alpha=0.5, label='Apriorní průměr')
    plt.axvline(likelihood_mean, color='r', linestyle='--', alpha=0.5, label='Průměr dat')
    plt.axvline(posterior_mean, color='g', linestyle='--', alpha=0.5, label='Posteriorní průměr')
    
    plt.title('Proces bayesovské aktualizace')
    plt.xlabel('Hodnota parametru')
    plt.ylabel('Hustota pravděpodobnosti')
    plt.legend()
    plt.show()
    
    print(f"Apriorní průměr: {prior_mean:.2f}, směrodatná odchylka: {prior_std:.2f}")
    print(f"Věrohodnostní průměr: {likelihood_mean:.2f}, směrodatná odchylka: {likelihood_std:.2f}")
    print(f"Posteriorní průměr: {posterior_mean:.2f}, směrodatná odchylka: {posterior_std:.2f}")

# Příklad: Aktualizace přesvědčení o parametru
plot_bayesian_updating(prior_mean=4.0, prior_std=2.0, likelihood_mean=6.0, likelihood_std=1.0)
```

Klíčovým poznatkem je, že s rostoucím množstvím pozorovaných dat se naše posteriorní rozdělení stává koncentrovanějším kolem skutečné hodnoty parametru a vliv našeho apriorního rozdělení se zmenšuje.

## Bayesovský vs. frekventistický přístup

Bayesovský a frekventistický statistický přístup představují dva odlišné filozofické směry statistické inference:

| Aspekt | Frekventistický | Bayesovský |
|--------|------------|----------|
| **Parametry** | Pevné, neznámé konstanty | Náhodné veličiny s rozdělením |
| **Pravděpodobnost** | Dlouhodobá frekvence | Míra přesvědčení |
| **Inference** | P-hodnoty, intervaly spolehlivosti | Posteriorní rozdělení, kredibilní intervaly |
| **Předchozí znalosti** | Obecně nezahrnuty | Explicitně zahrnuty |

Porovnejme tyto přístupy na příkladu odhadu pravděpodobnosti:

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# Nastavení generátoru náhodných čísel pro reprodukovatelnost
np.random.seed(42)

# Řekněme, že hážeme mincí a chceme určit, zda je férová
# Skutečná pravděpodobnost padnutí hlavy
true_p = 0.7  # Mince je ve skutečnosti vychýlená

# Simulace hodů mincí
num_flips = 20
flips = np.random.binomial(1, true_p, num_flips)
num_heads = np.sum(flips)

# Frekventistický přístup
p_hat = num_heads / num_flips
se = np.sqrt(p_hat * (1 - p_hat) / num_flips)
ci_lower = max(0, p_hat - 1.96 * se)
ci_upper = min(1, p_hat + 1.96 * se)

print("--- Frekventistický přístup ---")
print(f"Odhad metodou maximální věrohodnosti: {p_hat:.3f}")
print(f"95% interval spolehlivosti: ({ci_lower:.3f}, {ci_upper:.3f})")

# Bayesovský přístup s Beta apriorním rozdělením
# Beta(1,1) je uniformní apriorní rozdělení
alpha_prior = 1
beta_prior = 1

# Výpočet posteriorního rozdělení
alpha_posterior = alpha_prior + num_heads
beta_posterior = beta_prior + (num_flips - num_heads)

# Výpočet posteriorního průměru a kredibilního intervalu
posterior_mean = alpha_posterior / (alpha_posterior + beta_posterior)
cred_interval = stats.beta.interval(0.95, alpha_posterior, beta_posterior)

print("\n--- Bayesovský přístup ---")
print(f"Apriorní rozdělení: Beta({alpha_prior}, {beta_prior})")
print(f"Posteriorní rozdělení: Beta({alpha_posterior}, {beta_posterior})")
print(f"Posteriorní průměr: {posterior_mean:.3f}")
print(f"95% kredibilní interval: ({cred_interval[0]:.3f}, {cred_interval[1]:.3f})")

# Vykreslení apriorního a posteriorního rozdělení
x = np.linspace(0, 1, 1000)
prior = stats.beta.pdf(x, alpha_prior, beta_prior)
posterior = stats.beta.pdf(x, alpha_posterior, beta_posterior)

plt.figure(figsize=(12, 8))
plt.plot(x, prior, 'b-', label='Apriorní - Beta(1,1)')
plt.plot(x, posterior, 'r-', label=f'Posteriorní - Beta({alpha_posterior}, {beta_posterior})')
plt.axvline(true_p, color='g', linestyle='--', label=f'Skutečná pravděpodobnost: {true_p}')
plt.axvline(p_hat, color='k', linestyle='--', label=f'Frekv. odhad: {p_hat:.3f}')
plt.axvline(posterior_mean, color='r', linestyle='--', label=f'Bayes. odhad: {posterior_mean:.3f}')

# Přidání intervalu spolehlivosti a kredibilního intervalu
plt.axvspan(ci_lower, ci_upper, alpha=0.2, color='gray', label=f'95% interval spolehlivosti')
plt.axvspan(cred_interval[0], cred_interval[1], alpha=0.2, color='red', label=f'95% kredibilní interval')

plt.title('Bayesovský vs. frekventistický odhad vychýlení mince')
plt.xlabel('Pravděpodobnost padnutí hlavy (p)')
plt.ylabel('Hustota pravděpodobnosti')
plt.legend()
plt.show()
```

Klíčové rozdíly zde ilustrované:
- Frekventisté zacházejí s pravděpodobností jako s pevnou hodnotou a poskytují interval spolehlivosti
- Bayesovci poskytují úplné rozdělení možných hodnot a kredibilní interval
- Bayesovský přístup může zahrnout předchozí znalosti a přirozeně se aktualizuje s novými daty

## Bayesova věta a její aplikace

Bayesova věta je základní pravidlo bayesovské statistiky. Popisuje, jak aktualizovat pravděpodobnost hypotézy na základě nových důkazů:

$$P(H|E) = \frac{P(E|H) \times P(H)}{P(E)}$$

Kde:
- P(H|E) je posteriorní pravděpodobnost hypotézy H za předpokladu důkazu E
- P(E|H) je věrohodnost pozorování důkazu E za předpokladu, že hypotéza H je pravdivá
- P(H) je apriorní pravděpodobnost hypotézy H
- P(E) je marginální věrohodnost nebo důkaz

Implementujme jednoduchou aplikaci Bayesovy věty pro lékařské testování:

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Scénář lékařského testu
# Řekněme, že máme test na nemoc s těmito vlastnostmi:
prevalence = 0.01  # 1 % populace má nemoc
sensitivity = 0.95  # Test správně identifikuje 95 % těch, kteří mají nemoc
specificity = 0.90  # Test správně identifikuje 90 % těch, kteří nemoc nemají

# Výpočet pravděpodobnosti, že někdo, kdo má pozitivní test, skutečně má nemoc
# Použití Bayesovy věty: P(Nemoc|Pozitivní) = P(Pozitivní|Nemoc) * P(Nemoc) / P(Pozitivní)

# P(Pozitivní|Nemoc) je senzitivita
p_positive_given_disease = sensitivity

# P(Nemoc) je prevalence
p_disease = prevalence

# P(Pozitivní) = P(Pozitivní|Nemoc)*P(Nemoc) + P(Pozitivní|Není nemoc)*P(Není nemoc)
p_positive = (p_positive_given_disease * p_disease) + ((1 - specificity) * (1 - p_disease))

# Aplikace Bayesovy věty
p_disease_given_positive = (p_positive_given_disease * p_disease) / p_positive

print(f"Pravděpodobnost nemoci při pozitivním testu: {p_disease_given_positive:.4f} ({p_disease_given_positive*100:.1f}%)")

# Podívejme se, jak se tato pravděpodobnost mění s různou prevalencí
prevalence_range = np.linspace(0.001, 0.1, 100)
p_disease_given_positive_range = []

for prev in prevalence_range:
    p_disease = prev
    p_positive = (sensitivity * p_disease) + ((1 - specificity) * (1 - p_disease))
    p_disease_given_positive_range.append((sensitivity * p_disease) / p_positive)

# Vykreslení vztahu
plt.figure(figsize=(10, 6))
plt.plot(prevalence_range, p_disease_given_positive_range)
plt.fill_between(prevalence_range, 0, p_disease_given_positive_range, alpha=0.2)
plt.axhline(y=0.5, color='r', linestyle='--', label='50% pravděpodobnost')
plt.title('Pravděpodobnost nemoci při pozitivním testu')
plt.xlabel('Prevalence nemoci')
plt.ylabel('Pravděpodobnost nemoci při pozitivním testu')
plt.grid(True)
plt.legend()
plt.show()

# Vytvoření kontingenční tabulky pro výsledky testu
population_size = 10000
has_disease = int(prevalence * population_size)
no_disease = population_size - has_disease

# Pravdivě pozitivní, falešně negativní, falešně pozitivní, pravdivě negativní
TP = int(sensitivity * has_disease)
FN = has_disease - TP
FP = int((1 - specificity) * no_disease)
TN = no_disease - FP

conf_matrix = pd.DataFrame({
    'Má nemoc': [TP, FN],
    'Nemá nemoc': [FP, TN]
}, index=['Test pozitivní', 'Test negativní'])

print("\nKontingenční tabulka:")
print(conf_matrix)

# Vizualizace kontingenční tabulky
plt.figure(figsize=(10, 8))
sns.heatmap(conf_matrix, annot=True, fmt='d', cmap='Blues', cbar=False)
plt.title('Kontingenční tabulka pro lékařský test')
plt.show()
```

Tento příklad demonstruje "chybu základní míry" - když je stav vzácný, i vysoce přesný test může produkovat více falešně pozitivních než skutečně pozitivních výsledků, což je důvod, proč je bayesovské uvažování tak důležité v lékařské diagnostice.

## Úvod do pravděpodobnostního programování

Pravděpodobnostní programování kombinuje programovací jazyky s bayesovskou statistikou, což nám umožňuje vytvářet a řešit pravděpodobnostní modely pomocí kódu. Klíčové vlastnosti zahrnují:

1. Explicitní reprezentace nejistoty
2. Automatické mechanismy inference
3. Skládatelné pravděpodobnostní modely
4. Schopnost začlenit doménové znalosti

Populární knihovny pro pravděpodobnostní programování v Pythonu zahrnují:

- TensorFlow Probability
- Stan (prostřednictvím PyStan)
- Edward
- Pyro

Představme si PyMC, široce používanou knihovnu pro pravděpodobnostní programování:

```python
# Instalace PyMC, pokud je potřeba
# !pip install pymc arviz

import pymc as pm
import arviz as az
import numpy as np
import matplotlib.pyplot as plt

# Nastavení generátoru náhodných čísel pro reprodukovatelnost
np.random.seed(42)

# Generování syntetických dat
true_mu = 5.0
true_sigma = 2.0
data = np.random.normal(true_mu, true_sigma, size=100)

# Vytvoření našeho prvního PyMC modelu
with pm.Model() as basic_model:
    # Apriorní rozdělení pro parametry
    mu = pm.Normal('mu', mu=0, sigma=10)  # Apriorní rozdělení pro průměr
    sigma = pm.HalfNormal('sigma', sigma=10)  # Apriorní rozdělení pro směrodatnou odchylku
    
    # Funkce věrohodnosti
    y = pm.Normal('y', mu=mu, sigma=sigma, observed=data)
    
    # Inference - vzorkování z posteriorního rozdělení
    trace = pm.sample(1000, return_inferencedata=True, tune=1000)

# Vizualizace výsledků
az.plot_trace(trace)
plt.tight_layout()
plt.show()

# Souhrnné statistiky posteriorního rozdělení
summary = az.summary(trace)
print("\nSouhrnné statistiky posteriorního rozdělení:")
print(summary)

# Vykreslení posteriorních rozdělení
az.plot_posterior(trace)
plt.tight_layout()
plt.show()

# Porovnání našich odvozených hodnot se skutečnými hodnotami
print(f"\nSkutečný mu: {true_mu}, Odvozený mu: {summary.loc['mu', 'mean']:.3f}")
print(f"Skutečný sigma: {true_sigma}, Odvozený sigma: {summary.loc['sigma', 'mean']:.3f}")
```

Tento jednoduchý příklad ukazuje, jak můžeme použít pravděpodobnostní programování k odvození průměru a směrodatné odchylky normálního rozdělení. Krása tohoto přístupu spočívá v tom, že poskytuje úplná posteriorní rozdělení, nikoli pouze bodové odhady.

## Implementace bayesovských modelů pomocí PyMC

Nyní prozkoumejme praktičtější příklad s využitím PyMC k řešení reálného problému: bayesovská lineární regrese.

```python
import pymc as pm
import arviz as az
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení stylu
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Generování syntetických dat pro lineární regresi
np.random.seed(42)
n = 100
x = np.linspace(0, 10, n)
true_alpha = 2.5
true_beta = 0.5
true_sigma = 1.0
# y = α + βx + ε, ε ~ N(0, σ²)
y = true_alpha + true_beta * x + np.random.normal(0, true_sigma, size=n)

# Vizualizace dat
plt.figure(figsize=(10, 6))
plt.scatter(x, y, alpha=0.7)
plt.plot(x, true_alpha + true_beta * x, 'r', alpha=0.5)
plt.title('Syntetická data pro bayesovskou lineární regresi')
plt.xlabel('x')
plt.ylabel('y')
plt.show()

# Vytvoření bayesovského modelu lineární regrese pomocí PyMC
with pm.Model() as linear_model:
    # Apriorní rozdělení pro neznámé parametry modelu
    alpha = pm.Normal('alpha', mu=0, sigma=10)
    beta = pm.Normal('beta', mu=0, sigma=10)
    sigma = pm.HalfNormal('sigma', sigma=10)
    
    # Očekávaná hodnota výstupu
    mu = alpha + beta * x
    
    # Věrohodnostní funkce (vzorkovací rozdělení) pozorování
    y_obs = pm.Normal('y_obs', mu=mu, sigma=sigma, observed=y)
    
    # Inference - vzorkování z posteriorního rozdělení
    trace = pm.sample(1000, tune=1000, return_inferencedata=True)

# Tisk shrnutí posteriorních vzorků
summary = az.summary(trace)
print(summary)

# Trasovací graf
az.plot_trace(trace)
plt.tight_layout()
plt.show()

# Vykreslení posteriorních rozdělení
az.plot_posterior(trace)
plt.tight_layout()
plt.show()

# Vizualizace přizpůsobení modelu s nejistotou
plt.figure(figsize=(10, 6))

# Vykreslení původních datových bodů
plt.scatter(x, y, alpha=0.6, label='Data')

# Vykreslení skutečné přímky
plt.plot(x, true_alpha + true_beta * x, 'r', label='Skutečná přímka', alpha=0.5)

# Získání posteriorních vzorků
alpha_samples = trace.posterior['alpha'].values.flatten()
beta_samples = trace.posterior['beta'].values.flatten()

# Vykreslení podmnožiny posteriorních vzorků
n_samples = 100
rand_idx = np.random.randint(0, len(alpha_samples), n_samples)
for i in rand_idx:
    plt.plot(x, alpha_samples[i] + beta_samples[i] * x, 'g', alpha=0.05)

# Vykreslení posteriorního průměru
alpha_mean = alpha_samples.mean()
beta_mean = beta_samples.mean()
plt.plot(x, alpha_mean + beta_mean * x, 'b--', label='Posteriorní průměr', linewidth=2)

plt.title('Bayesovská lineární regrese s nejistotou')
plt.xlabel('x')
plt.ylabel('y')
plt.legend()
plt.show()

# Tisk porovnání skutečných vs. odvozených parametrů
print(f"Skutečný alpha: {true_alpha}, Odvozený alpha: {alpha_mean:.3f}")
print(f"Skutečný beta: {true_beta}, Odvozený beta: {beta_mean:.3f}")
print(f"Skutečný sigma: {true_sigma}, Odvozený sigma: {summary.loc['sigma', 'mean']:.3f}")

# Provádění predikcí s nejistotou
# Generování nových hodnot x
x_new = np.linspace(0, 15, 100)

# Získání vzorků z posteriorní prediktivní distribuce
with linear_model:
    pm.set_data({"x": x_new})  # Pro PyMC 5.0+
    posterior_pred = pm.sample_posterior_predictive(trace)

# Extrakce průměru a kredibilních intervalů
y_pred_mean = posterior_pred.posterior_predictive['y_obs'].mean(dim=['chain', 'draw']).values
y_pred_hdi = az.hdi(posterior_pred.posterior_predictive['y_obs'], hdi_prob=0.95)

# Vykreslení predikcí s nejistotou
plt.figure(figsize=(12, 7))
plt.scatter(x, y, alpha=0.6, label='Pozorovaná data')
plt.plot(x_new, y_pred_mean, 'b', label='Predikovaný průměr')
plt.fill_between(x_new, y_pred_hdi['y_obs'].sel(hdi='lower'), y_pred_hdi['y_obs'].sel(hdi='higher'), 
                alpha=0.3, label='95% kredibilní interval')
plt.axvline(x=10, color='k', linestyle='--', alpha=0.3, label='Hranice dat')
plt.title('Bayesovské lineární regresní predikce s nejistotou')
plt.xlabel('x')
plt.ylabel('y')
plt.legend()
plt.show()
```

Tento příklad demonstruje několik klíčových výhod bayesovské regrese:
1. Získáme úplná posteriorní rozdělení pro všechny parametry
2. Můžeme snadno zahrnout apriorní znalosti
3. Přirozeně kvantifikujeme nejistotu v predikcích
4. Můžeme provádět pravděpodobnostní predikce pro nové datové body

## Markov Chain Monte Carlo (MCMC) vzorkování

Metody Markov Chain Monte Carlo (MCMC) jsou výpočetní techniky používané k aproximaci složitých posteriorních rozdělení, když nejsou možná analytická řešení. Tyto metody generují vzorky z posteriorního rozdělení, které lze použít k odhadu různých charakteristik rozdělení.

Běžné MCMC algoritmy zahrnují:
- Metropolis-Hastings
- Gibbsovo vzorkování
- Hamiltonovské Monte Carlo (HMC)
- No-U-Turn Sampler (NUTS)

Vytvořme jednoduchou implementaci algoritmu Metropolis-Hastings pro pochopení základů:

```python
import numpy as np
import matplotlib.pyplot as plt
import scipy.stats as stats
import seaborn as sns

# Nastavení stylu grafů
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Definice cílového rozdělení (to, co se snažíme vzorkovat)
def target_pdf(x):
    # Toto může být jakékoli složité rozdělení
    # Zde použijeme směs dvou normálních rozdělení
    return 0.3 * stats.norm.pdf(x, -3, 1) + 0.7 * stats.norm.pdf(x, 2, 2)

# Implementace algoritmu Metropolis-Hastings
def metropolis_hastings(target_pdf, proposal_width, n_samples, initial_value=0):
    """
    Implementace algoritmu Metropolis-Hastings.
    
    Parametry:
    -----------
    target_pdf : function
        Cílová funkce hustoty pravděpodobnosti, ze které chceme vzorkovat
    proposal_width : float
        Směrodatná odchylka gaussovského návrhového rozdělení
    n_samples : int
        Počet vzorků, které chceme vygenerovat
    initial_value : float, optional
        Počáteční bod řetězce
        
    Vrací:
    --------
    samples : numpy.ndarray
        Pole vzorků z cílového rozdělení
    acceptance_rate : float
        Podíl návrhů, které byly přijaty
    """
    samples = np.zeros(n_samples)
    current_value = initial_value
    n_accepted = 0
    
    for i in range(n_samples):
        # Generování návrhu
        proposal = current_value + np.random.normal(0, proposal_width)
        
        # Výpočet poměru přijetí
        target_current = target_pdf(current_value)
        target_proposal = target_pdf(proposal)
        
        # Ochrana proti dělení nulou
        if target_current == 0:
            acceptance_ratio = np.inf
        else:
            acceptance_ratio = target_proposal / target_current
        
        # Přijetí nebo odmítnutí návrhu
        if np.random.uniform() < acceptance_ratio:
            current_value = proposal
            n_accepted += 1
        
        # Uložení aktuální hodnoty
        samples[i] = current_value
    
    acceptance_rate = n_accepted / n_samples
    return samples, acceptance_rate

# Spuštění algoritmu Metropolis-Hastings
n_samples = 10000
proposal_width = 2.0
samples, acceptance_rate = metropolis_hastings(target_pdf, proposal_width, n_samples)

print(f"Míra přijetí: {acceptance_rate:.2f}")

# Vykreslení výsledků
plt.figure(figsize=(12, 8))

# Vykreslení stopy řetězce
```

## Hierarchické bayesovské modely

Hierarchické bayesovské modely (také nazývané víceúrovňové modely) nám umožňují modelovat parametry, které přirozeně spadají do skupin nebo hierarchií. Tyto modely jsou mocné, protože mohou "půjčovat sílu" napříč skupinami, což vede k robustnějším inferencím, zejména když jsou data omezená.

Implementujme hierarchický model pro analýzu výsledků testů z různých škol:

```python
import pymc as pm
import arviz as az
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení generátoru náhodných čísel pro reprodukovatelnost
np.random.seed(42)

# Generování syntetických dat
n_schools = 8
n_students_per_school = np.random.randint(20, 50, size=n_schools)
total_students = np.sum(n_students_per_school)

# Skutečné parametry
mu = 75  # Celkový průměrný výsledek
sigma_school = 7  # Variace mezi školami
sigma_student = 15  # Variace mezi studenty

# Generování skutečných efektů škol (odchylky od celkového průměru)
school_effects = np.random.normal(0, sigma_school, n_schools)

# Generování dat studentů
school_ids = np.repeat(np.arange(n_schools), n_students_per_school)
student_scores = np.zeros(total_students)

idx = 0
for i, n_students in enumerate(n_students_per_school):
    true_school_mean = mu + school_effects[i]
    student_scores[idx:idx+n_students] = np.random.normal(true_school_mean, sigma_student, n_students)
    idx += n_students

# Vytvoření dataframe
df = pd.DataFrame({
    'school': school_ids,
    'score': student_scores
})

# Výpočet statistik škol
school_stats = df.groupby('school').agg(['mean', 'std', 'count'])['score'].reset_index()
school_stats.columns = ['school', 'mean_score', 'std_score', 'n_students']

print("Statistiky škol:")
print(school_stats)

# Vykreslení průměrů škol s jejich standardními chybami
plt.figure(figsize=(12, 6))
plt.errorbar(
    school_stats['school'], 
    school_stats['mean_score'],
    yerr=school_stats['std_score'] / np.sqrt(school_stats['n_students']),
    fmt='o', capsize=5
)
plt.axhline(mu, color='r', linestyle='--', alpha=0.7, label='Skutečný celkový průměr')
plt.axhline(np.mean(student_scores), color='g', linestyle=':', alpha=0.7, label='Vzorkový celkový průměr')
plt.title('Průměrné výsledky škol se standardními chybami')
plt.xlabel('ID školy')
plt.ylabel('Průměrný výsledek')
plt.legend()
plt.show()

# Vytvoření hierarchického bayesovského modelu
with pm.Model() as hierarchical_model:
    # Hyperpriorní rozdělení
    mu = pm.Normal('mu', mu=75, sigma=10)  # Celkový průměrný výsledek
    sigma_school = pm.HalfNormal('sigma_school', sigma=10)  # Variace mezi školami
    sigma_student = pm.HalfNormal('sigma_student', sigma=20)  # Variace mezi studenty
    
    # Parametry na úrovni škol
    theta = pm.Normal('theta', mu=mu, sigma=sigma_school, shape=n_schools)
    
    # Věrohodnostní funkce na úrovni studentů
    scores = pm.Normal('scores', mu=theta[school_ids], sigma=sigma_student, observed=student_scores)
    
    # Vzorkování z posteriorního rozdělení
    trace = pm.sample(1000, tune=1000, return_inferencedata=True)

# Prozkoumání stopy vzorkování
az.plot_trace(trace, var_names=['mu', 'sigma_school', 'sigma_student'])
plt.tight_layout()
plt.show()

# Shrnutí posteriorního rozdělení
summary = az.summary(trace, var_names=['mu', 'sigma_school', 'sigma_student'])
print("\nPosteriorní shrnutí:")
print(summary)

# Porovnání odhadnutých efektů škol se skutečnými efekty škol
theta_posterior = trace.posterior['theta'].mean(dim=['chain', 'draw']).values
school_effects_estimated = theta_posterior - trace.posterior['mu'].mean(dim=['chain', 'draw']).values

plt.figure(figsize=(10, 6))
plt.scatter(school_effects, school_effects_estimated, s=100*school_stats['n_students']/np.max(school_stats['n_students']))
plt.plot([-15, 15], [-15, 15], 'k--')
plt.title('Skutečné vs. odhadnuté efekty škol')
plt.xlabel('Skutečné efekty škol')
plt.ylabel('Odhadnuté efekty škol')
plt.grid(True)
plt.show()

# Vizualizace efektu smršťování
plt.figure(figsize=(12, 8))

# Surové průměry škol
plt.subplot(1, 2, 1)
raw_means = school_stats['mean_score'].values
plt.scatter(np.arange(n_schools), raw_means, s=80, label='Surové průměry škol')
plt.axhline(np.mean(student_scores), color='g', linestyle='-', label='Celkový vzorkový průměr')
plt.title('Surové průměry škol')
plt.xlabel('ID školy')
plt.ylabel('Průměrný výsledek')
plt.ylim(50, 100)
plt.legend()

# Odhady hierarchického modelu
plt.subplot(1, 2, 2)
plt.scatter(np.arange(n_schools), theta_posterior, s=80, color='r', label='Hierarchické odhady')
plt.axhline(summary.loc['mu', 'mean'], color='b', linestyle='-', label='Odhadnutý celkový průměr')

# Spojení surových průměrů s hierarchickými odhady
for i in range(n_schools):
    plt.plot([i, i], [raw_means[i], theta_posterior[i]], 'k--', alpha=0.5)

plt.title('Hierarchické odhady (se smršťováním)')
plt.xlabel('ID školy')
plt.ylabel('Průměrný výsledek')
plt.ylim(50, 100)
plt.legend()

plt.tight_layout()
plt.show()
```

Tento příklad ilustruje několik klíčových aspektů hierarchických bayesovských modelů:

1. **Částečné sdílení**: Odhady škol jsou váženým průměrem surových dat školy a celkového průměru
2. **Smršťování**: Odhady pro školy s malým množstvím dat jsou "smrštěny" směrem k celkovému průměru
3. **Sdílení informací**: Školy si půjčují sílu od sebe navzájem prostřednictvím hierarchické struktury
4. **Regularizace**: Hierarchická struktura přirozeně zabraňuje přeučení na šum v malých vzorcích

Hierarchické modely jsou zvláště užitečné, když:
- Máte seskupená nebo klastrovaná data
- Některé skupiny mají omezená data
- Chcete modelovat variaci na více úrovních
- Potřebujete provádět predikce pro nové skupiny

## Bayesovské A/B testování

A/B testování je běžnou aplikací statistických metod pro porovnávání dvou variant. Bayesovský přístup k A/B testování nabízí několik výhod:

1. Interpretovatelnost - přímá pravděpodobnostní tvrzení o tom, která varianta je lepší
2. Flexibilita v kritériích zastavení - není potřeba pevně stanovené velikosti vzorku
3. Zahrnutí apriorních znalostí
4. Přirozené zacházení s nejistotou

Implementujme bayesovský A/B test pro míry konverzí:

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

# Nastavení stylu grafů
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Generování syntetických dat pro A/B test
np.random.seed(42)

# Skutečné míry konverzí
p_A = 0.10  # Varianta A (kontrolní) míra konverze
p_B = 0.12  # Varianta B (testovací) míra konverze

# Velikosti vzorků
n_A = 1000  # Uživatelů, kterým byla zobrazena varianta A
n_B = 1000  # Uživatelů, kterým byla zobrazena varianta B

# Simulace pozorování
conversions_A = np.random.binomial(1, p_A, n_A)
conversions_B = np.random.binomial(1, p_B, n_B)

# Výpočet pozorovaných měr konverzí
obs_p_A = np.sum(conversions_A) / n_A
obs_p_B = np.sum(conversions_B) / n_B

print(f"Varianta A: {np.sum(conversions_A)} konverzí z {n_A} ({obs_p_A:.1%} míra konverze)")
print(f"Varianta B: {np.sum(conversions_B)} konverzí z {n_B} ({obs_p_B:.1%} míra konverze)")
print(f"Pozorované zlepšení: {(obs_p_B - obs_p_A) / obs_p_A:.1%}")

# Bayesovská analýza s Beta apriorním rozdělením
# Parametry apriorního rozdělení (Beta distribuce)
alpha_prior = 1
beta_prior = 1

# Parametry posteriorního rozdělení (přidání úspěchů a neúspěchů k apriornímu rozdělení)
alpha_A = alpha_prior + np.sum(conversions_A)
beta_A = beta_prior + n_A - np.sum(conversions_A)

alpha_B = alpha_prior + np.sum(conversions_B)
beta_B = beta_prior + n_B - np.sum(conversions_B)

print("\nParametry posteriorního Beta rozdělení:")
print(f"Varianta A: Beta({alpha_A}, {beta_A})")
print(f"Varianta B: Beta({alpha_B}, {beta_B})")

# Výpočet pravděpodobnosti, že B je lepší než A
def prob_B_better_than_A(alpha_A, beta_A, alpha_B, beta_B, samples=100000):
    # Generování vzorků z posteriorních rozdělení
    samples_A = np.random.beta(alpha_A, beta_A, samples)
    samples_B = np.random.beta(alpha_B, beta_B, samples)
    
    # Výpočet pravděpodobnosti, že B > A
    prob_B_better = np.mean(samples_B > samples_A)
    
    return prob_B_better

prob_B_better = prob_B_better_than_A(alpha_A, beta_A, alpha_B, beta_B)
print(f"\nPravděpodobnost, že varianta B je lepší než varianta A: {prob_B_better:.1%}")

# Výpočet očekávaného zlepšení
def expected_lift(alpha_A, beta_A, alpha_B, beta_B, samples=100000):
    # Generování vzorků z posteriorních rozdělení
    samples_A = np.random.beta(alpha_A, beta_A, samples)
    samples_B = np.random.beta(alpha_B, beta_B, samples)
    
    # Výpočet relativních zlepšení
    lifts = (samples_B - samples_A) / samples_A
    
    # Výpočet průměru a kredibilního intervalu
    mean_lift = np.mean(lifts)
    ci_lift = np.percentile(lifts, [2.5, 97.5])
    
    return mean_lift, ci_lift

mean_lift, ci_lift = expected_lift(alpha_A, beta_A, alpha_B, beta_B)
print(f"Očekávané zlepšení: {mean_lift:.1%} (95% CI: {ci_lift[0]:.1%} až {ci_lift[1]:.1%})")

# Vizualizace posteriorních rozdělení
x = np.linspace(0, 0.2, 1000)
posterior_A = stats.beta.pdf(x, alpha_A, beta_A)
posterior_B = stats.beta.pdf(x, alpha_B, beta_B)

plt.figure(figsize=(12, 6))
plt.plot(x, posterior_A, 'b-', label=f'Varianta A: Beta({alpha_A}, {beta_A})')
plt.plot(x, posterior_B, 'r-', label=f'Varianta B: Beta({alpha_B}, {beta_B})')
plt.axvline(p_A, color='b', linestyle='--', alpha=0.5, label=f'Skutečná A: {p_A:.1%}')
plt.axvline(p_B, color='r', linestyle='--', alpha=0.5, label=f'Skutečná B: {p_B:.1%}')
plt.fill_between(x, 0, posterior_A, color='blue', alpha=0.1)
plt.fill_between(x, 0, posterior_B, color='red', alpha=0.1)
plt.title('Posteriorní rozdělení měr konverzí')
plt.xlabel('Míra konverze')
plt.ylabel('Hustota pravděpodobnosti')
plt.legend()
plt.show()

# Vizualizace rozdělení zlepšení
samples_A = np.random.beta(alpha_A, beta_A, 100000)
samples_B = np.random.beta(alpha_B, beta_B, 100000)
lifts = (samples_B - samples_A) / samples_A

plt.figure(figsize=(12, 6))
sns.histplot(lifts, bins=50, kde=True)
plt.axvline(0, color='k', linestyle='--', alpha=0.7, label='Žádný efekt')
plt.axvline(mean_lift, color='r', linestyle='-', alpha=0.7, label=f'Průměrné zlepšení: {mean_lift:.1%}')
plt.axvline(ci_lift[0], color='r', linestyle=':', alpha=0.7, label=f'95% CI Dolní mez: {ci_lift[0]:.1%}')
plt.axvline(ci_lift[1], color='r', linestyle=':', alpha=0.7, label=f'95% CI Horní mez: {ci_lift[1]:.1%}')
plt.title('Posteriorní rozdělení zlepšení (B vs. A)')
plt.xlabel('Zlepšení = (B-A)/A')
plt.ylabel('Hustota pravděpodobnosti')
plt.legend()
plt.show()

# Simulace sekvenční analýzy (data přicházejí v průběhu času)
def sequential_bayesian_ab_test(p_A, p_B, max_samples=5000, batch_size=100, threshold=0.95):
    """
    Simulace sekvenčního bayesovského A/B testu.
    
    Parametry:
    -----------
    p_A : float
        Skutečná míra konverze pro variantu A
    p_B : float
        Skutečná míra konverze pro variantu B
    max_samples : int
        Maximální počet vzorků k získání na variantu
    batch_size : int
        Počet vzorků k získání v každé dávce
    threshold : float
        Práh pravděpodobnosti pro rozhodnutí
        
    Vrací:
    --------
    results : pandas.DataFrame
        DataFrame s výsledky v každém kroku
    """
    results = []
    
    # Parametry apriorního rozdělení
    alpha_prior = 1
    beta_prior = 1
    
    # Inicializace parametrů posteriorního rozdělení
    alpha_A = alpha_prior
    beta_A = beta_prior
    alpha_B = alpha_prior
    beta_B = beta_prior
    
    n_A = 0
    n_B = 0
    
    while (n_A < max_samples) and (n_B < max_samples):
        # Sběr dávky dat pro každou variantu
        new_A = np.random.binomial(1, p_A, batch_size)
        new_B = np.random.binomial(1, p_B, batch_size)
        
        # Aktualizace počtů
        n_A += batch_size
        n_B += batch_size
        
        # Aktualizace parametrů posteriorního rozdělení
        alpha_A += np.sum(new_A)
        beta_A += batch_size - np.sum(new_A)
        alpha_B += np.sum(new_B)
        beta_B += batch_size - np.sum(new_B)
        
        # Výpočet pravděpodobností
        prob_B_better = prob_B_better_than_A(alpha_A, beta_A, alpha_B, beta_B)
        prob_A_better = 1 - prob_B_better
        
        # Uložení výsledků
        results.append({
            'samples': n_A,  # Vzorky na variantu
            'conversions_A': alpha_A - alpha_prior,
            'conversions_B': alpha_B - alpha_prior,
            'conversion_rate_A': (alpha_A - alpha_prior) / n_A,
            'conversion_rate_B': (alpha_B - alpha_prior) / n_B,
            'prob_B_better': prob_B_better,
            'prob_A_better': prob_A_better,
            'decision': 'pokračovat'
        })
        
        # Kontrola, zda jsme dosáhli rozhodovacího prahu
        if prob_B_better >= threshold:
            results[-1]['decision'] = 'B vyhrává'
            break
        elif prob_A_better >= threshold:
            results[-1]['decision'] = 'A vyhrává'
            break
    
    # Pokud jsme dosáhli maximálního počtu vzorků bez rozhodnutí
    if n_A >= max_samples:
        if prob_B_better > 0.5:
            results[-1]['decision'] = 'B vede, ale neprůkazně'
        else:
            results[-1]['decision'] = 'A vede, ale neprůkazně'
    
    return pd.DataFrame(results)

# Spuštění sekvenčního testu
sequential_results = sequential_bayesian_ab_test(p_A, p_B, max_samples=10000, batch_size=50, threshold=0.95)

# Tisk konečného výsledku
final_result = sequential_results.iloc[-1]
print("\nVýsledky sekvenčního testování:")
print(f"Celkový počet vzorků na variantu: {final_result['samples']}")
print(f"Konečné pravděpodobnosti: P(B > A) = {final_result['prob_B_better']:.1%}, " +
      f"P(A > B) = {final_result['prob_A_better']:.1%}")
print(f"Rozhodnutí: {final_result['decision']}")

# Vizualizace sekvenčního testu
plt.figure(figsize=(15, 10))

# Vykreslení měr konverzí v průběhu času
plt.subplot(2, 1, 1)
plt.plot(sequential_results['samples'], sequential_results['conversion_rate_A'], 'b-', label='Varianta A')
plt.plot(sequential_results['samples'], sequential_results['conversion_rate_B'], 'r-', label='Varianta B')
plt.axhline(p_A, color='b', linestyle='--', alpha=0.5, label=f'Skutečná A: {p_A:.1%}')
plt.axhline(p_B, color='r', linestyle='--', alpha=0.5, label=f'Skutečná B: {p_B:.1%}')
plt.title('Pozorované míry konverzí')
plt.xlabel('Počet vzorků na variantu')
plt.ylabel('Míra konverze')
plt.legend()

# Vykreslení pravděpodobnosti, že B je lepší než A
plt.subplot(2, 1, 2)
plt.plot(sequential_results['samples'], sequential_results['prob_B_better'], 'g-')
plt.axhline(0.95, color='r', linestyle='--', alpha=0.7, label='Rozhodovací práh (95%)')
plt.axhline(0.5, color='k', linestyle=':', alpha=0.5, label='Rovná pravděpodobnost (50%)')
plt.title('Pravděpodobnost, že B je lepší než A')
plt.xlabel('Počet vzorků na variantu')
plt.ylabel('P(B > A)')
plt.ylim(0, 1)
plt.legend()

plt.tight_layout()
plt.show()
```

Tento komplexní příklad demonstruje několik výhod bayesovského A/B testování:

1. **Přímá pravděpodobnostní interpretace**: Získáme přesnou pravděpodobnost, že B je lepší než A.
2. **Úplné rozdělení efektů**: Vidíme celé rozdělení možných hodnot zlepšení.
3. **Sekvenční testování**: Můžeme sledovat výsledky, jak data přicházejí, a potenciálně zastavit dříve.
4. **Rámec pro rozhodování**: Jasná kritéria pro to, kdy prohlásit vítěze.

Bayesovské A/B testování je zvláště cenné, když:
- Potřebujete činit rozhodnutí s omezenými daty
- Chcete komunikovat výsledky v intuitivních pravděpodobnostních termínech
- Potřebujete flexibilitu v tom, kdy experiment zastavit
- Máte smysluplné apriorní informace o mírách konverzí

## Bayesovská analýza časových řad

Bayesovské metody jsou velmi vhodné pro analýzu časových řad, protože přirozeně zohledňují nejistotu, dokáží pracovat s chybějícími daty a modelovat komplexní časové vzory. Pojďme implementovat bayesovský strukturální model časových řad:

```python
import pymc as pm
import arviz as az
import numpy as np
import pandas as pd

# Vykreslení modelu a jeho komponent
def plot_model_fit(trace, df, ci_width=0.95):
    # Extrahování posteriorních vzorků
    trend_samples = trace.posterior['trend'].stack(samples=("chain", "draw")).values
    seasonality_samples = trace.posterior['seasonality'].stack(samples=("chain", "draw")).values
    mu_samples = trace.posterior['mu'].stack(samples=("chain", "draw")).values
    
    # Výpočet průměrů a kredibilních intervalů
    trend_mean = np.mean(trend_samples, axis=0)
    trend_lower = np.percentile(trend_samples, 100 * (1 - ci_width) / 2, axis=0)
    trend_upper = np.percentile(trend_samples, 100 * (1 + ci_width) / 2, axis=0)
    
    seasonality_mean = np.mean(seasonality_samples, axis=0)
    seasonality_lower = np.percentile(seasonality_samples, 100 * (1 - ci_width) / 2, axis=0)
    seasonality_upper = np.percentile(seasonality_samples, 100 * (1 + ci_width) / 2, axis=0)
    
    mu_mean = np.mean(mu_samples, axis=0)
    mu_lower = np.percentile(mu_samples, 100 * (1 - ci_width) / 2, axis=0)
    mu_upper = np.percentile(mu_samples, 100 * (1 + ci_width) / 2, axis=0)
    
    # Vytvoření grafu
    fig, axes = plt.subplots(3, 1, figsize=(12, 12), sharex=True)
    
    # Vykreslení dat a celkového modelu
    axes[0].plot(df['time'], df['value'], 'o', alpha=0.5, label='Pozorovaná data')
    axes[0].plot(df['time'], mu_mean, 'k-', label='Posteriorní průměr')
    axes[0].fill_between(df['time'], mu_lower, mu_upper, color='k', alpha=0.2, label=f'{ci_width*100:.0f}% KI')
    axes[0].set_title('Fit modelu')
    axes[0].set_ylabel('Hodnota')
    axes[0].legend()
    
    # Vykreslení trendové komponenty
    axes[1].plot(df['time'], df['trend'], 'b-', label='Skutečný trend')
    axes[1].plot(df['time'], trend_mean, 'r-', label='Odhadovaný trend')
    axes[1].fill_between(df['time'], trend_lower, trend_upper, color='r', alpha=0.2, label=f'{ci_width*100:.0f}% KI')
    axes[1].set_title('Trendová komponenta')
    axes[1].set_ylabel('Hodnota')
    axes[1].legend()
    
    # Vykreslení sezónní komponenty
    axes[2].plot(df['time'], df['seasonality'], 'b-', label='Skutečná sezónnost')
    axes[2].plot(df['time'], seasonality_mean, 'g-', label='Odhadovaná sezónnost')

    axes[2].set_xlabel('Čas')
    axes[2].set_ylabel('Hodnota')
    axes[2].legend()
    
    plt.tight_layout()
    return fig, axes
```

## Shrnutí

Bayesovská statistika a pravděpodobnostní programování poskytují mocný rámec pro datovou vědu a modelování v podmínkách nejistoty. Klíčové koncepty a výhody uvedené v tomto tutoriálu zahrnují:

1. **Bayesovská inference**: Rámec, který aktualizuje přesvědčení o parametrech na základě pozorovaných dat, kombinuje předchozí znalosti s důkazy.

2. **Bayesova věta**: Matematický základ, který nám umožňuje vypočítat posteriorní pravděpodobnosti kombinací apriorních pravděpodobností a věrohodností.

3. **Pravděpodobnostní programování**: Moderní nástroje jako PyMC, které nám umožňují vyjádřit a řešit bayesovské modely pomocí kódu, přičemž automaticky řeší složité matematické detaily.

4. **Úplná posteriorní rozdělení**: Namísto bodových odhadů poskytují bayesovské metody celá pravděpodobnostní rozdělení parametrů, umožňující bohatou kvantifikaci nejistoty.

5. **MCMC vzorkování**: Výpočetní techniky, které generují vzorky z posteriorních rozdělení, když analytická řešení nejsou k dispozici.

6. **Hierarchické modely**: Mocné víceúrovňové modely umožňující "částečné sdílení" informací mezi skupinami, což vede k robustnější inferenci.

7. **Bayesovské A/B testování**: Principiální přístup k analýze experimentů, který poskytuje přímá pravděpodobnostní tvrzení a umožňuje flexibilní kritéria pro ukončení.

8. **Bayesovské časové řady**: Metody pro analýzu časových dat, které přirozeně zohledňují nejistotu a mohou rozložit časové řady na interpretovatelné komponenty.

Výhody bayesovských metod:
- Přirozené začlenění předchozích znalostí
- Explicitní reprezentace nejistoty
- Intuitivní pravděpodobnostní interpretace výsledků
- Flexibilita ve specifikaci modelu
- Robustnost při malých velikostech vzorků
- Sekvenční aktualizace při příchodu nových dat

Bayesovský přístup přináší i výzvy, včetně výpočetních nároků a potřeby specifikovat apriorní rozdělení. Nicméně, moderní knihovny pro pravděpodobnostní programování jako PyMC spolu s rostoucím výpočetním výkonem učinily bayesovské metody dostupnější než kdy předtím.
