## 1. Úvod do popisné statistiky

Popisná statistika zahrnuje metody pro uspořádání, shrnutí a prezentaci dat přehledným a informativním způsobem. Na rozdíl od inferenční statistiky, která se snaží vyvozovat závěry o populaci, se popisná statistika zaměřuje na shrnutí obsahu vašeho datasetu bez širších závěrů.

```python
# Import základních knihoven pro popisnou statistiku
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení stylování pro lepší vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Vytvoření vzorového datasetu pro demonstraci
np.random.seed(42)  # Pro reprodukovatelnost
data = {
    'Věk': np.random.normal(35, 10, 200).round().astype(int),
    'Příjem': np.random.lognormal(mean=10.5, sigma=0.5, size=200).round(),
    'Zkušenosti': np.random.normal(10, 5, 200).round().astype(int),
    'Spokojenost': np.random.choice(['Nízká', 'Střední', 'Vysoká'], size=200, 
                                  p=[0.2, 0.5, 0.3]),
    'Oddělení': np.random.choice(['Prodej', 'Marketing', 'HR', 'Vývoj', 'Finance'], 
                                size=200)
}

# Vytvoření DataFrame
df = pd.DataFrame(data)

# Zobrazení prvních několika řádků datasetu
print("Vzorová data:")
print(df.head())

# Základní informace o datasetu
print("\nInformace o datasetu:")
print(df.info())
```

Popisná statistika pomáhá odpovědět na otázky jako:
- Jaký je průměrný věk zaměstnanců?
- Jak se liší příjem mezi zaměstnanci?
- Které oddělení má nejvyšší průměrnou spokojenost?
- Existuje vztah mezi zkušenostmi a příjmem?

## 2. Míry centrální tendence

Míry centrální tendence pomáhají identifikovat "střed" nebo typickou hodnotu datasetu. Tři hlavní míry jsou:

- **Průměr**: Aritmetický průměr hodnot
- **Medián**: Prostřední hodnota při seřazení dat
- **Modus**: Nejčastěji se vyskytující hodnota

```python
# Výpočet měr centrální tendence pro numerické sloupce
print("\nPrůměrné hodnoty:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].mean())

print("\nMediánové hodnoty:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].median())

print("\nModální hodnoty:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].mode().iloc[0])  # Vezme první modus, pokud jich existuje více

# Pro kategoriální data je modus obzvláště užitečný
print("\nModus kategoriálních sloupců:")
print(f"Nejčastější úroveň spokojenosti: {df['Spokojenost'].mode()[0]}")
print(f"Nejčastější oddělení: {df['Oddělení'].mode()[0]}")

# Vizualizace centrální tendence
plt.figure(figsize=(12, 6))

plt.subplot(1, 2, 1)
sns.histplot(df['Věk'], kde=True)
plt.axvline(df['Věk'].mean(), color='red', linestyle='--', label=f'Průměr: {df["Věk"].mean():.1f}')
plt.axvline(df['Věk'].median(), color='green', linestyle='-.', label=f'Medián: {df["Věk"].median():.1f}')
plt.legend()
plt.title('Rozložení věku s centrální tendencí')

plt.subplot(1, 2, 2)
sns.histplot(df['Příjem'], kde=True)
plt.axvline(df['Příjem'].mean(), color='red', linestyle='--', label=f'Průměr: {df["Příjem"].mean():.1f}')
plt.axvline(df['Příjem'].median(), color='green', linestyle='-.', label=f'Medián: {df["Příjem"].median():.1f}')
plt.legend()
plt.title('Rozložení příjmu s centrální tendencí')

plt.tight_layout()
plt.show()
```

Kdy použít kterou míru:
- **Průměr**: Nejlepší pro symetrická rozdělení bez odlehlých hodnot
- **Medián**: Robustnější vůči odlehlým hodnotám; lepší pro zešikmená rozdělení
- **Modus**: Užitečný pro kategoriální data nebo diskrétní hodnoty s jasnými vrcholy

## 3. Míry rozptylu

Zatímco centrální tendence nám říká o typických hodnotách, míry rozptylu nám říkají, jak rozptýlená data jsou:

- **Rozpětí**: Rozdíl mezi maximální a minimální hodnotou
- **Rozptyl**: Průměrná kvadratická odchylka od průměru
- **Směrodatná odchylka**: Odmocnina rozptylu; představuje typickou odchylku od průměru
- **Mezikvartilové rozpětí (IQR)**: Rozsah prostředních 50 % dat

```python
# Výpočet rozpětí
def calculate_range(series):
    return series.max() - series.min()

print("\nHodnoty rozpětí:")
print(f"Rozpětí věku: {calculate_range(df['Věk'])}")
print(f"Rozpětí příjmu: {calculate_range(df['Příjem'])}")
print(f"Rozpětí zkušeností: {calculate_range(df['Zkušenosti'])}")

# Výpočet rozptylu
print("\nHodnoty rozptylu:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].var())

# Výpočet směrodatné odchylky
print("\nHodnoty směrodatné odchylky:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].std())

# Výpočet mezikvartilového rozpětí (IQR)
q1 = df[['Věk', 'Příjem', 'Zkušenosti']].quantile(0.25)
q3 = df[['Věk', 'Příjem', 'Zkušenosti']].quantile(0.75)
iqr = q3 - q1
print("\nMezikvartilové rozpětí (IQR):")
print(iqr)

# Vizualizace rozptylu
plt.figure(figsize=(14, 6))

plt.subplot(1, 2, 1)
sns.boxplot(y=df['Věk'])
plt.title('Krabicový graf věku')
plt.ylabel('Věk')

plt.subplot(1, 2, 2)
sns.boxplot(y=df['Příjem'])
plt.title('Krabicový graf příjmu')
plt.ylabel('Příjem')

plt.tight_layout()
plt.show()
```

Směrodatná odchylka je obzvláště užitečná, protože:
- Je ve stejných jednotkách jako původní data
- Přibližně 68 % hodnot leží v rozmezí 1 směrodatné odchylky od průměru v normálním rozdělení
- Přibližně 95 % hodnot leží v rozmezí 2 směrodatných odchylek

## 4. Analýza rozložení

Pochopení tvaru rozložení vašich dat poskytuje cenné poznatky:

- **Šikmost**: Měří asymetrii (pozitivní/pravostranná nebo negativní/levostranná)
- **Špičatost**: Měří "těžkost ocasů" (jak těžké jsou ocasy ve srovnání s normálním rozdělením)
- **Normalita**: Zda data sledují normální rozdělení

```python
from scipy import stats

# Výpočet šikmosti
print("\nŠikmost:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].skew())

# Výpočet špičatosti
print("\nŠpičatost:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].kurtosis())

# Vizualizace rozdělení
plt.figure(figsize=(15, 10))

# Rozložení věku
plt.subplot(2, 2, 1)
sns.histplot(df['Věk'], kde=True)
plt.title(f'Rozložení věku (Šikmost: {df["Věk"].skew():.2f})')

# Rozložení příjmu
plt.subplot(2, 2, 2)
sns.histplot(df['Příjem'], kde=True)
plt.title(f'Rozložení příjmu (Šikmost: {df["Příjem"].skew():.2f})')

# Rozložení zkušeností
plt.subplot(2, 2, 3)
sns.histplot(df['Zkušenosti'], kde=True)
plt.title(f'Rozložení zkušeností (Šikmost: {df["Zkušenosti"].skew():.2f})')

# Q-Q Graf pro kontrolu normality (Věk)
plt.subplot(2, 2, 4)
stats.probplot(df['Věk'], plot=plt)
plt.title('Q-Q Graf pro věk')

plt.tight_layout()
plt.show()

# Shapiro-Wilk test na normalitu
print("\nShapiro-Wilk test na normalitu (p-hodnota):")
print(f"Věk: {stats.shapiro(df['Věk'])[1]:.6f}")
print(f"Příjem: {stats.shapiro(df['Příjem'])[1]:.6f}")
print(f"Zkušenosti: {stats.shapiro(df['Zkušenosti'])[1]:.6f}")
# Pokud p-hodnota < 0.05, data nemají normální rozdělení
```

Interpretace charakteristik rozdělení:
- **Šikmost**: Hodnoty > 0 indikují pravostranné zešikmení; hodnoty < 0 indikují levostranné zešikmení
- **Špičatost**: Hodnoty > 3 indikují těžké ocasy (leptokurtické); hodnoty < 3 indikují lehké ocasy (platykurtické)
- Shapiro-Wilk test pomáhá určit, zda mají data normální rozdělení (p-hodnota > 0.05 naznačuje normalitu)

## 5. Percentily a kvartily

Percentily a kvartily rozdělují váš dataset na segmenty, což pomáhá pochopit rozdělení dat:

- **Percentily**: Hodnoty, které dělí data na 100 stejných částí
- **Kvartily**: Hodnoty, které dělí data na 4 stejné části (25 %, 50 %, 75 %)

```python
# Výpočet běžných percentilů
percentiles = [0.1, 0.25, 0.5, 0.75, 0.9]
print("\nPercentily pro numerické sloupce:")
print(df[['Věk', 'Příjem', 'Zkušenosti']].quantile(percentiles))

# Výpočet kvartilů
print("\nKvartily:")
print("První kvartil (25%):")
print(df[['Věk', 'Příjem', 'Zkušenosti']].quantile(0.25))

print("\nDruhý kvartil (50% - medián):")
print(df[['Věk', 'Příjem', 'Zkušenosti']].quantile(0.5))

print("\nTřetí kvartil (75%):")
print(df[['Věk', 'Příjem', 'Zkušenosti']].quantile(0.75))

# Vizualizace metodami založenými na percentilech
plt.figure(figsize=(14, 6))

plt.subplot(1, 2, 1)
sns.boxplot(y=df['Věk'])
plt.title('Krabicový graf zobrazující kvartily věku')
plt.ylabel('Věk')

plt.subplot(1, 2, 2)
# Houslový graf ukazuje tvar rozdělení a kvartily
sns.violinplot(y=df['Věk'], inner='quartile')
plt.title('Houslový graf s kvartily věku')
plt.ylabel('Věk')

plt.tight_layout()
plt.show()
```

Kvartily a percentily jsou užitečné pro:
- Identifikaci odlehlých hodnot (hodnoty za hranicí 1,5 × IQR od Q1 nebo Q3)
- Porozumění rozložení a koncentraci dat
- Nastavení prahových hodnot pro kategorizaci dat (např. nízký/střední/vysoký příjem)

## 6. Korelace a kovariance

Korelace a kovariance pomáhají identifikovat vztahy mezi proměnnými:

- **Kovariance**: Měří, jak se dvě proměnné mění společně
- **Korelace**: Standardizovaná míra síly vztahu (-1 až 1)

```python
# Výpočet kovarianční matice
covariance_matrix = df[['Věk', 'Příjem', 'Zkušenosti']].cov()
print("\nKovarianční matice:")
print(covariance_matrix)

# Výpočet korelační matice
correlation_matrix = df[['Věk', 'Příjem', 'Zkušenosti']].corr()
print("\nKorelační matice:")
print(correlation_matrix)

# Vizualizace korelací
plt.figure(figsize=(10, 8))
sns.heatmap(correlation_matrix, annot=True, cmap='coolwarm', vmin=-1, vmax=1)
plt.title('Heatmapa korelační matice')
plt.tight_layout()
plt.show()

# Bodové grafy k vizualizaci vztahů
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
sns.regplot(x='Zkušenosti', y='Příjem', data=df)
plt.title(f'Zkušenosti vs Příjem\nKorelace: {correlation_matrix.loc["Zkušenosti", "Příjem"]:.2f}')

plt.subplot(1, 2, 2)
sns.regplot(x='Věk', y='Zkušenosti', data=df)
plt.title(f'Věk vs Zkušenosti\nKorelace: {correlation_matrix.loc["Věk", "Zkušenosti"]:.2f}')

plt.tight_layout()
plt.show()

# Pearsonova korelace s p-hodnotou pro test významnosti
from scipy.stats import pearsonr

corr_exp_income, p_value = pearsonr(df['Zkušenosti'], df['Příjem'])
print(f"\nPearsonova korelace mezi Zkušenostmi a Příjmem: {corr_exp_income:.3f}")
print(f"P-hodnota: {p_value:.6f}")
if p_value < 0.05:
    print("Korelace je statisticky významná.")
else:
    print("Korelace není statisticky významná.")
```

Interpretace korelačních koeficientů:
- Hodnoty blízko 1: Silná pozitivní korelace
- Hodnoty blízko -1: Silná negativní korelace
- Hodnoty blízko 0: Slabá nebo žádná korelace

## 9. Použití pandas describe() a statistických funkcí

pandas nabízí vestavěné funkce pro rychlé generování popisné statistiky:

```python
# Metoda describe() poskytuje mnoho statistik v jednom volání
numeric_summary = df.describe()
print("\nSouhrnné statistiky pro numerické sloupce:")
print(numeric_summary)

# Zahrnutí všech sloupců (včetně kategoriálních)
all_summary = df.describe(include='all')
print("\nSouhrnné statistiky pro všechny sloupce:")
print(all_summary)

# Použití describe() na seskupená data
grouped_summary = df.groupby('Oddělení')['Příjem'].describe()
print("\nSouhrnné statistiky pro Příjem podle Oddělení:")
print(grouped_summary)

# Další užitečné statistické funkce pandas
print("\nŠikmost a špičatost:")
print(df.skew())
print(df.kurtosis())

# Agregace více statistik najednou
custom_stats = df.agg({
    'Věk': ['min', 'max', 'mean', 'median', 'std'],
    'Příjem': ['min', 'max', 'mean', 'median', 'std', 'skew'],
    'Zkušenosti': ['min', 'max', 'mean', 'median', 'std'],
    'Spokojenost': ['count', 'nunique', pd.Series.mode],
    'Oddělení': ['count', 'nunique']
})
print("\nVlastní agregované statistiky:")
print(custom_stats)

# Vytvoření komplexního statistického souhrnného reportu
def generate_stats_report(df, numeric_cols):
    """Vygeneruje komplexní statistický report pro numerické sloupce"""
    # Základní statistiky
    basic_stats = df[numeric_cols].describe()
    
    # Další statistiky
    additional_stats = pd.DataFrame({
        'Rozsah': df[numeric_cols].max() - df[numeric_cols].min(),
        'IQR': df[numeric_cols].quantile(0.75) - df[numeric_cols].quantile(0.25),
        'Šikmost': df[numeric_cols].skew(),
        'Špičatost': df[numeric_cols].kurtosis(),
        'Variační koeficient': df[numeric_cols].std() / df[numeric_cols].mean() * 100
    }).T
    
    # Kombinace všech statistik
    all_stats = pd.concat([basic_stats, additional_stats])
    
    return all_stats.round(2)

numeric_cols = ['Věk', 'Příjem', 'Zkušenosti']
report = generate_stats_report(df, numeric_cols)
print("\nKomplexní statistický report:")
print(report)
```

Funkce pandas `describe()` je rychlý způsob, jak získat:
- Počet nenulových hodnot
- Průměr, směrodatnou odchylku
- Minimální, maximální hodnoty
- Kvartily (25 %, 50 %, 75 %)

Můžete ji přizpůsobit nebo vytvořit vlastní funkce statistického shrnutí podle potřeby.

## 10. Shrnutí

Popisná statistika poskytuje základ pro analýzu dat tím, že shrnuje a popisuje klíčové charakteristiky vašeho datasetu:

- **Míry centrální tendence** (průměr, medián, modus) identifikují typické hodnoty
- **Míry rozptylu** (směrodatná odchylka, rozpětí, IQR) popisují rozptyl dat
- **Analýza rozložení** (šikmost, špičatost) charakterizuje tvar dat
- **Percentily a kvartily** pomáhají segmentovat a porozumět rozdělení dat
- **Korelace** identifikuje vztahy mezi proměnnými
- **Kategoriální souhrny** poskytují poznatky o nenumerických datech

Popisná statistika je nezbytná pro:
- Počáteční průzkum a pochopení dat
- Identifikaci vzorů, trendů a anomálií
- Komunikaci klíčových poznatků o vašich datech
- Poskytnutí základu pro pokročilejší analýzu
- Rozhodování na základě dat podpořené jasnými souhrny

Python knihovny jako pandas, numpy a scipy.stats usnadňují výpočet popisné statistiky, zatímco matplotlib a seaborn pomáhají efektivně vizualizovat tyto poznatky. Vždy kombinujte numerické souhrny s vhodnými vizualizacemi, abyste získali úplné pochopení vašich dat.
