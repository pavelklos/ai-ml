## 1. Introduction to EDA

Exploratory Data Analysis (EDA) is a crucial first step in any data science project. It involves analyzing and visualizing data to understand its main characteristics, identify patterns, detect anomalies, and formulate hypotheses. EDA helps data scientists make informed decisions about data preprocessing, feature engineering, and modeling strategies.

```python
# Import essential libraries for EDA

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

sns.set_style("whitegrid")

# Configure pandas display options
```


## 3. Summary Statistics

Calculating summary statistics provides a quantitative overview of the data distribution, central tendencies, and dispersion.

```python
# Basic descriptive statistics
print("Summary statistics for numerical columns:")
print(titanic.describe())

# Include categorical columns in summary
print("\nSummary statistics for all columns:")
print(titanic.describe(include='all'))

# Custom aggregate statistics
custom_stats = titanic.agg({
    'age': ['min', 'max', 'mean', 'median'],
    'fare': ['min', 'max', 'mean', 'median'],
    'survived': ['mean', 'sum'],
    'sex': ['count', 'first', 'last']
})
print("\nCustom aggregate statistics:")
print(custom_stats)

# Group by statistics
print("\nSurvival rate by passenger class:")
print(titanic.groupby('pclass')['survived'].mean())

# Quantiles for deeper distribution understanding
print("\nAge distribution quantiles:")
print(titanic['age'].quantile([0.1, 0.25, 0.5, 0.75, 0.9, 0.95, 0.99]))
```

## 4. Missing Data Analysis

Understanding and visualizing missing data is essential for determining appropriate imputation strategies or feature removal.

```python

missing_values = titanic.isnull().sum()

# Percentage of missing values
missing_percentage = (titanic.isnull().sum() / len(titanic)) * 100
print("\nPercentage of missing values by column:")
```

## 8. Outlier Detection

Identifying and analyzing outliers helps understand unusual patterns and potential data issues.

```python
# Z-score method for detecting outliers
from scipy import stats

def detect_outliers_zscore(data, threshold=3):
    """Detect outliers using Z-score method"""
    z_scores = np.abs(stats.zscore(data.dropna()))
    return data[z_scores > threshold].index

# IQR method for detecting outliers
def detect_outliers_iqr(data):
    """Detect outliers using IQR method"""
    Q1 = data.quantile(0.25)
    Q3 = data.quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    return data[(data < lower_bound) | (data > upper_bound)].index

# Find outliers in the fare column
fare_zscore_outliers = detect_outliers_zscore(titanic['fare'])
fare_iqr_outliers = detect_outliers_iqr(titanic['fare'])

print(f"Outliers in 'fare' using Z-score: {len(fare_zscore_outliers)}")
print(f"Outliers in 'fare' using IQR: {len(fare_iqr_outliers)}")

# Visualize outliers in a scatter plot
plt.figure(figsize=(12, 6))
scatter = plt.scatter(titanic.index, titanic['fare'], c='b', alpha=0.5)
plt.scatter(fare_iqr_outliers, titanic.loc[fare_iqr_outliers, 'fare'], c='r')
plt.title('Fare Outliers Using IQR Method')
plt.xlabel('Index')
plt.ylabel('Fare')
plt.legend(['Normal', 'Outlier'])
plt.tight_layout()
plt.show()

# Box plot for outlier visualization
plt.figure(figsize=(10, 6))
sns.boxplot(data=titanic[['age', 'fare']])
plt.title('Box Plot for Outlier Detection')
plt.tight_layout()
plt.show()
```

## 10. Summary

Exploratory Data Analysis is a fundamental step in any data science workflow that helps understand data characteristics and identify patterns. Key aspects of EDA include:

1. **Initial Data Inspection**: Understanding data structure, types, and quality
2. **Summary Statistics**: Quantifying central tendencies and dispersion
3. **Missing Data Analysis**: Identifying and visualizing missing values
4. **Distribution Analysis**: Understanding variable distributions and detecting skewness
5. **Correlation Analysis**: Identifying relationships between variables
6. **Categorical Data Exploration**: Analyzing categories and their relationships
7. **Outlier Detection**: Finding and handling unusual observations
8. **Visualization**: Creating informative plots to gain insights
9. **Automated Tools**: Accelerating analysis with reporting libraries

EDA forms the foundation for feature engineering, data preprocessing, and model selection decisions. A thorough EDA helps avoid common modeling pitfalls and leads to more robust and interpretable models.

The iterative nature of EDA allows data scientists to continuously refine their understanding of the data and develop more targeted analyses as insights emerge. Remember that EDA is not a one-size-fits-all approach; the specific techniques used should always be tailored to your dataset and problem domain.
