## 1. Introduction to Pandas DataFrame

Pandas is a powerful Python library for data manipulation and analysis. The DataFrame is its primary data structure, providing a flexible 2-dimensional table with labeled axes (rows and columns). DataFrames are similar to Excel spreadsheets or SQL tables, making them intuitive for data analysis.

```python
# Install pandas (if you haven't already)
# pip install pandas

# Import the pandas library
import pandas as pd

# Display pandas version
print(f"Pandas version: {pd.__version__}")
```

Key features of Pandas DataFrames include:
- Column-oriented structure for different data types
- Size mutability (columns can be inserted and deleted)
- Automatic and explicit data alignment
- Powerful group by functionality
- Flexible handling of missing data
- Easy merging and joining of datasets

## 2. Creating DataFrames

There are multiple ways to create a pandas DataFrame:

```python
import pandas as pd
import numpy as np

# 1. Creating a DataFrame from a dictionary of lists
data_dict = {
    'Name': ['John', 'Anna', 'Peter', 'Linda'],
    'Age': [28, 34, 29, 42],
    'City': ['New York', 'Paris', 'Berlin', 'London'],
    'Salary': [65000, 70000, 62000, 85000]
}

df1 = pd.DataFrame(data_dict)
print("DataFrame from dictionary:")
print(df1)
print("\n")

# 2. Creating a DataFrame from a list of dictionaries
data_list = [
    {'Name': 'John', 'Age': 28, 'City': 'New York', 'Salary': 65000},
    {'Name': 'Anna', 'Age': 34, 'City': 'Paris', 'Salary': 70000},
    {'Name': 'Peter', 'Age': 29, 'City': 'Berlin', 'Salary': 62000},
    {'Name': 'Linda', 'Age': 42, 'City': 'London', 'Salary': 85000}
]

df2 = pd.DataFrame(data_list)
print("DataFrame from list of dictionaries:")
print(df2)
print("\n")

# 3. Creating a DataFrame from a NumPy array
array_data = np.array([['John', 28, 'New York', 65000],
                       ['Anna', 34, 'Paris', 70000],
                       ['Peter', 29, 'Berlin', 62000],
                       ['Linda', 42, 'London', 85000]])

df3 = pd.DataFrame(array_data, columns=['Name', 'Age', 'City', 'Salary'])
print("DataFrame from NumPy array:")
print(df3)
print("\n")

# 4. Creating an empty DataFrame and adding data
df4 = pd.DataFrame()
df4['Name'] = ['John', 'Anna', 'Peter', 'Linda']
df4['Age'] = [28, 34, 29, 42]
df4['City'] = ['New York', 'Paris', 'Berlin', 'London']
df4['Salary'] = [65000, 70000, 62000, 85000]

print("DataFrame created by adding columns:")
print(df4)
print("\n")

# 5. Creating a DataFrame with specific index
df5 = pd.DataFrame(data_dict, index=['A', 'B', 'C', 'D'])
print("DataFrame with custom index:")
print(df5)
```

## 3. Exploring DataFrames: Basic Attributes and Methods


## 4. Indexing and Selection

Pandas provides multiple ways to select and access data from DataFrames:

```python
# Create a sample DataFrame
data = {
    'Name': ['John', 'Anna', 'Peter', 'Linda', 'Bob'],
    'Age': [28, 34, 29, 42, 35],
    'City': ['New York', 'Paris', 'Berlin', 'London', 'Madrid'],
    'Salary': [65000, 70000, 62000, 85000, 72000]
}
df = pd.DataFrame(data)
print("Original DataFrame:")
print(df)
print("\n")

# Selecting columns
print("Selecting columns:")
print("\nSingle column as Series:")
print(df['Name'])
print("\nMultiple columns:")
print(df[['Name', 'Salary']])
print("\n")

# Selecting rows using loc (label-based)
print("Using loc (label-based):")
print("\nSingle row by index label:")
print(df.loc[2])
print("\nMultiple rows by index labels:")
print(df.loc[1:3])
print("\nSpecific rows and columns:")
print(df.loc[1:3, ['Name', 'Salary']])
print("\n")

# Selecting rows using iloc (position-based)
print("Using iloc (position-based):")
print("\nSingle row by position:")
print(df.iloc[2])
print("\nMultiple rows by position:")
print(df.iloc[1:3])
print("\nSpecific rows and columns by position:")
print(df.iloc[1:3, [0, 3]])
print("\n")

# Boolean indexing
print("Boolean indexing:")
print("\nRows where Age > 30:")
print(df[df['Age'] > 30])
print("\nRows where City is 'London' or 'Paris':")
print(df[df['City'].isin(['London', 'Paris'])])
print("\nComplex condition (Age > 30 and Salary > 70000):")
print(df[(df['Age'] > 30) & (df['Salary'] > 70000)])
```

## 5. Basic DataFrame Operations

DataFrames support various mathematical and statistical operations:

```python
import pandas as pd
import numpy as np

# Create a sample DataFrame
data = {
    'A': [10, 20, 30, 40, 50],
    'B': [5, 10, 15, 20, 25],
    'C': [2, 4, 6, 8, 10]
}
df = pd.DataFrame(data)
print("Original DataFrame:")
print(df)
print("\n")

# Mathematical operations
print("Mathematical operations:")
print("\nA + B (adding columns):")
print(df['A'] + df['B'])
print("\nMultiplying column by a scalar:")
print(df['A'] * 2)
print("\nAdding a constant to the entire DataFrame:")
print(df + 5)
print("\n")

# Statistical operations
print("Statistical operations:")
print(f"Mean of each column:\n{df.mean()}")
print(f"Sum of each column:\n{df.sum()}")
print(f"Minimum values:\n{df.min()}")
print(f"Maximum values:\n{df.max()}")
print(f"Standard deviation:\n{df.std()}")
print("\n")

# Applying functions
print("Applying functions:")
print("\nApply a function to each element (square root):")
print(np.sqrt(df))
print("\nApply a custom function to a column:")
print(df['A'].apply(lambda x: x**2))
print("\nApply a function to rows (sum across columns):")
print(df.apply(sum, axis=1))
print("\n")

# Cumulative operations
print("Cumulative operations:")
print("\nCumulative sum:")
print(df.cumsum())
print("\nCumulative product:")
print(df.cumprod())
```

## 6. Handling Columns

Pandas makes it easy to manipulate columns in a DataFrame:

```python
import pandas as pd

# Create a sample DataFrame
data = {
    'Name': ['John', 'Anna', 'Peter', 'Linda', 'Bob'],
    'Age': [28, 34, 29, 42, 35],
    'City': ['New York', 'Paris', 'Berlin', 'London', 'Madrid']
}
df = pd.DataFrame(data)
print("Original DataFrame:")
print(df)
print("\n")

# Adding a new column
print("Adding new columns:")
df['Country'] = ['USA', 'France', 'Germany', 'UK', 'Spain']
print("\nAdding a single column:")
print(df)

# Adding a column based on other columns
df['Age in Months'] = df['Age'] * 12
print("\nAdding a column derived from another column:")
print(df)

# Adding a column with a single value
df['Status'] = 'Active'
print("\nAdding a column with a constant value:")
print(df)
print("\n")

# Renaming columns
print("Renaming columns:")
df = df.rename(columns={'Name': 'Full Name', 'Age': 'Age (years)'})
print(df)

# Alternatively, rename all columns at once
df.columns = ['Full Name', 'Age (years)', 'City', 'Country', 'Age in Months', 'Status']
print("\n")

# Deleting columns
print("Deleting columns:")
df_temp = df.copy()  # Create a copy to not modify the original

# Drop a single column
df_temp = df_temp.drop('Status', axis=1)
print("\nAfter dropping 'Status' column:")
print(df_temp)

# Drop multiple columns
df_temp = df_temp.drop(['Age in Months', 'Country'], axis=1)
print("\nAfter dropping multiple columns:")
print(df_temp)
print("\n")

# Selecting specific columns and reordering
print("Reordering columns:")
df_reordered = df[['City', 'Country', 'Full Name', 'Age (years)', 'Age in Months', 'Status']]
print(df_reordered)
```

## 7. Handling Rows

Manipulating rows in a DataFrame is just as important as handling columns:

```python
import pandas as pd

# Create a sample DataFrame
data = {
    'Name': ['John', 'Anna', 'Peter', 'Linda', 'Bob'],
    'Age': [28, 34, 29, 42, 35],
    'City': ['New York', 'Paris', 'Berlin', 'London', 'Madrid']
}
df = pd.DataFrame(data)
print("Original DataFrame:")
print(df)
print("\n")

# Adding a new row using append (deprecated in newer pandas versions but still common)
new_row = pd.DataFrame({'Name': ['Sara'], 'Age': [31], 'City': ['Rome']})

# In newer pandas versions, use concat instead of append
df_new = pd.concat([df, new_row], ignore_index=True)
print("After adding a new row:")
print(df_new)
print("\n")

# Adding multiple rows
more_rows = pd.DataFrame({
    'Name': ['Mike', 'Emma'],
    'Age': [45, 27],
    'City': ['Chicago', 'Amsterdam']
})
df_new = pd.concat([df_new, more_rows], ignore_index=True)
print("After adding multiple rows:")
print(df_new)
print("\n")

# Deleting rows
print("Deleting rows:")
df_temp = df_new.copy()  # Create a copy to not modify the original

# Drop a row by index
df_temp = df_temp.drop(1)  # Drop the row with index 1
print("\nAfter dropping row with index 1:")
print(df_temp)

# Drop multiple rows
df_temp = df_new.drop([3, 5])
print("\nAfter dropping rows with indexes 3 and 5:")
print(df_temp)

# Dropping rows based on a condition
df_filtered = df_new[df_new['Age'] >= 30]
print("\nKeeping only rows where Age >= 30:")
print(df_filtered)

# Reset index after dropping rows
df_filtered = df_filtered.reset_index(drop=True)
print("\nAfter resetting index:")
print(df_filtered)
```

## 8. Data Sorting and Filtering

Sorting and filtering are essential operations for data analysis:

```python
import pandas as pd

# Create a sample DataFrame
data = {
    'Name': ['John', 'Anna', 'Peter', 'Linda', 'Bob', 'Emma'],
    'Age': [28, 34, 29, 42, 35, 34],
    'City': ['New York', 'Paris', 'Berlin', 'London', 'Madrid', 'Paris'],
    'Salary': [65000, 70000, 62000, 85000, 72000, 68000]
}
df = pd.DataFrame(data)
print("Original DataFrame:")
print(df)
print("\n")

# Sorting by a single column
print("Sorting data:")
print("\nSort by Age (ascending):")
print(df.sort_values('Age'))

print("\nSort by Age (descending):")
print(df.sort_values('Age', ascending=False))

# Sorting by multiple columns
print("\nSort by City (ascending) and then by Age (descending):")
print(df.sort_values(['City', 'Age'], ascending=[True, False]))
print("\n")

# Basic filtering
print("Filtering data:")
print("\nRows where Age > 30:")
print(df[df['Age'] > 30])

print("\nRows where City is 'Paris':")
print(df[df['City'] == 'Paris'])

# Complex filtering with multiple conditions
print("\nRows where Age > 30 AND Salary > 70000:")
print(df[(df['Age'] > 30) & (df['Salary'] > 70000)])

print("\nRows where City is 'Paris' OR City is 'London':")
print(df[(df['City'] == 'Paris') | (df['City'] == 'London')])

# Using isin for multiple value matching
print("\nRows where City is one of ['Paris', 'London', 'Berlin']:")
print(df[df['City'].isin(['Paris', 'London', 'Berlin'])])

# Negation with ~
print("\nRows where City is NOT 'Paris':")
print(df[~(df['City'] == 'Paris')])
# Alternatively: df[df['City'] != 'Paris']

# String filtering
print("\nNames that start with 'P':")
print(df[df['Name'].str.startswith('P')])

print("\nCities containing the letter 'o':")
print(df[df['City'].str.contains('o')])
```

## 9. Basic Data Cleaning with DataFrames

Data cleaning is a crucial step in data analysis. Pandas provides various tools for handling common data quality issues:

```python
import pandas as pd
import numpy as np

# Create a sample DataFrame with some issues
data = {
    'Name': ['John', 'Anna', np.nan, 'Linda', 'Bob'],
    'Age': [28, 34, 29, np.nan, 35],
    'City': ['new york', 'PARIS', 'Berlin', 'London', None],
    'Salary': [65000, 70000, 62000, '85000', 72000],
    'ID': [' ID001 ', 'ID002', 'ID003 ', 'ID004', ' ID005']
}
df = pd.DataFrame(data)
print("DataFrame with issues:")
print(df)
print(df.info())
print("\n")

# 1. Handling missing values
print("Handling missing values:")
print("\nCheck for missing values:")
print(df.isnull().sum())

# Fill missing values
df_filled = df.copy()
df_filled['Name'] = df_filled['Name'].fillna('Unknown')
df_filled['Age'] = df_filled['Age'].fillna(df_filled['Age'].mean())
df_filled['City'] = df_filled['City'].fillna('Unknown')
print("\nAfter filling missing values:")
print(df_filled)

# Drop rows with missing values
df_dropped = df.dropna()
print("\nAfter dropping rows with missing values:")
print(df_dropped)
print("\n")

# 2. Data type conversion
print("Data type conversion:")
print("\nBefore conversion:")
print(df.dtypes)

# Convert Salary to numeric
df['Salary'] = pd.to_numeric(df['Salary'], errors='coerce')
print("\nAfter converting Salary to numeric:")
print(df.dtypes)
print("\n")

# 3. String cleaning
print("String cleaning:")
# Strip whitespace
df['ID'] = df['ID'].str.strip()
print("\nIDs after stripping whitespace:")
print(df['ID'])

# Convert city names to title case
df['City'] = df['City'].str.title()
print("\nCity names in title case:")
print(df['City'])
print("\n")

# 4. Duplicate handling
# Add some duplicates
duplicated_df = pd.concat([df, df.iloc[1:3]], ignore_index=True)
print("DataFrame with duplicates:")
print(duplicated_df)

# Check for duplicates
print("\nDuplicate rows:")
print(duplicated_df.duplicated().sum())

# Remove duplicates
deduped_df = duplicated_df.drop_duplicates()
print("\nAfter removing duplicates:")
print(deduped_df)

# 5. Value replacement
print("\nReplacing values:")
df['City'] = df['City'].replace('New York', 'NYC')
print(df['City'])
```
