## Úvod do časových řad

Časové řady se skládají z pozorování zaznamenaných v pravidelných časových intervalech. Pochopení a analýza časových řad jsou klíčové pro prognózování, detekci anomálií a rozpoznávání vzorů.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from statsmodels.tsa.seasonal import seasonal_decompose
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
from statsmodels.tsa.stattools import adfuller
from statsmodels.tsa.arima.model import ARIMA
from sklearn.metrics import mean_squared_error, mean_absolute_error
import warnings
warnings.filterwarnings('ignore')

# Načtení a příprava vzorových dat časových řad
# Možnost 1: Použití zabudovaného datasetu
from statsmodels.datasets import macrodata
data = macrodata.load_pandas().data
data.index = pd.date_range(start='1959-01-01', periods=len(data), freq='Q')
ts = data['realcons']

# Možnost 2: Vytvoření syntetických dat časových řad
dates = pd.date_range(start='2020-01-01', periods=365, freq='D')
np.random.seed(42)
trend = np.linspace(0, 10, 365)
seasonal = 5 * np.sin(np.linspace(0, 2 * np.pi * 4, 365))
noise = np.random.normal(0, 1, 365)
synthetic_ts = pd.Series(trend + seasonal + noise, index=dates)

# Zobrazení dat
plt.figure(figsize=(12, 6))
plt.plot(synthetic_ts)
plt.title('Syntetická časová řada')
plt.xlabel('Datum')
plt.ylabel('Hodnota')
plt.grid(True)
plt.tight_layout()
plt.show()

print("Charakteristiky časové řady:")
print(f"- Datový typ: {type(synthetic_ts)}")
print(f"- Frekvence: {synthetic_ts.index.freq}")
print(f"- Počáteční datum: {synthetic_ts.index.min()}")
print(f"- Koncové datum: {synthetic_ts.index.max()}")
print(f"- Délka: {len(synthetic_ts)}")
print(f"- Průměr: {synthetic_ts.mean():.2f}")
print(f"- Směrodatná odchylka: {synthetic_ts.std():.2f}")
```

## Komponenty časových řad

Časové řady se obvykle skládají ze čtyř hlavních komponent:
1. **Trend**: Dlouhodobý pohyb v datech
2. **Sezónnost**: Opakující se vzory v pevných intervalech
3. **Cykličnost**: Výkyvy bez pevné frekvence
4. **Reziduální/Náhodná složka**: Náhodné variace, které nelze přičíst trendu, sezónnosti nebo cyklickým složkám

```python
# Rozklad časové řady na její komponenty
from statsmodels.tsa.seasonal import seasonal_decompose

# Použijeme měsíční data leteckých pasažérů (klasický příklad časové řady)
airline = pd.read_csv('https://raw.githubusercontent.com/jbrownlee/Datasets/master/airline-passengers.csv', 
                     parse_dates=['Month'], index_col='Month')
airline.columns = ['Passengers']

# Vizualizace původních dat
plt.figure(figsize=(12, 4))
plt.plot(airline)
plt.title('Měsíční počet mezinárodních leteckých pasažérů (1949-1960)')
plt.ylabel('Počet pasažérů (tisíce)')
plt.grid(True)
plt.tight_layout()
plt.show()

# Provedení sezónní dekompozice
decomposition = seasonal_decompose(airline['Passengers'], model='multiplicative', period=12)

# Vykreslení dekompozice
fig, (ax1, ax2, ax3, ax4) = plt.subplots(4, 1, figsize=(12, 10))
decomposition.observed.plot(ax=ax1)
ax1.set_title('Původní časová řada')
ax1.grid(True)

decomposition.trend.plot(ax=ax2)
ax2.set_title('Trendová komponenta')
ax2.grid(True)

decomposition.seasonal.plot(ax=ax3)
ax3.set_title('Sezónní komponenta')
ax3.grid(True)

decomposition.resid.plot(ax=ax4)
ax4.set_title('Reziduální komponenta')
ax4.grid(True)

plt.tight_layout()
plt.show()

print("Sezónní vzory se opakují každých:", 12, "měsíců")
print("Průměrné sezónní faktory:")
seasonal_factors = decomposition.seasonal.groupby(decomposition.seasonal.index.month).mean()
for month, factor in enumerate(seasonal_factors, 1):
    print(f"  Měsíc {month}: {factor:.4f}")
```

## Stacionarita a testování

Stacionární časová řada je taková, jejíž statistické vlastnosti (průměr, rozptyl, autokorelace) zůstávají konstantní v čase. Většina modelů časových řad vyžaduje stacionaritu.

```python
# Testování stacionarity pomocí rozšířeného Dickey-Fullerova testu
def test_stationarity(timeseries, window=12, title=''):
    # Klouzavé statistiky
    rolling_mean = timeseries.rolling(window=window).mean()
    rolling_std = timeseries.rolling(window=window).std()
    
    # Vykreslení klouzavých statistik
    plt.figure(figsize=(12, 6))
    plt.plot(timeseries, label='Původní')
    plt.plot(rolling_mean, label=f'Klouzavý průměr (okno={window})')
    plt.plot(rolling_std, label=f'Klouzavá st. odchylka (okno={window})')
    plt.legend(loc='best')
    plt.title(f'Klouzavý průměr a směrodatná odchylka - {title}')
    plt.grid(True)
    plt.tight_layout()
    plt.show()
    
    # Rozšířený Dickey-Fullerův test
    print('Výsledky rozšířeného Dickey-Fullerova testu:')
    adf_result = adfuller(timeseries.dropna())
    
    adf_output = pd.Series(adf_result[0:4], index=['ADF Statistika', 'p-hodnota', 
                                                  'Použité zpoždění', 'Počet pozorování'])
    
    for key, value in adf_result[4].items():
        adf_output[f'Kritická hodnota ({key})'] = value
        
    print(adf_output)
    
    if adf_result[1] <= 0.05:
        print("\nZávěr: Časová řada JE STACIONÁRNÍ")
    else:
        print("\nZávěr: Časová řada NENÍ STACIONÁRNÍ")

# Testování dat leteckých pasažérů na stacionaritu
test_stationarity(airline['Passengers'], title='Letečtí pasažéři')

# Transformace nestacionární řady na stacionární
# 1. Diferencování
airline_diff = airline['Passengers'].diff().dropna()
test_stationarity(airline_diff, title='První diference počtu leteckých pasažérů')

# 2. Logaritmická transformace následovaná diferencováním
airline_log = np.log(airline['Passengers'])
airline_log_diff = airline_log.diff().dropna()
test_stationarity(airline_log_diff, title='Logaritmus a první diference počtu leteckých pasažérů')
```

```python

dates = pd.date_range(start='2018-01-01', periods=1000, freq='D')

# 2. Kalendářní teplotní mapa (užitečná pro denní data)
# Přeformátování dat tak, aby dny byly ve sloupcích a týdny v řádcích
def plot_calendar_heatmap(series, year=None):
    if year is not None:
        series = series[series.index.year == year]
    
    # Vytvoření pivotní tabulky pro kalendářní pohled
    calendar_data = pd.DataFrame({
        'year': series.index.year,
        'month': series.index.month,
        'day': series.index.day,
        'dayofweek': series.index.dayofweek,  # Pondělí=0, Neděle=6
        'value': series.values
    })
    
    # Vytvoření pivotní tabulky
    pivot_data = calendar_data.pivot_table(
        index='dayofweek', 
        columns=['year', 'month', 'day'], 
        values='value'
    )
    
    # Vykreslení teplotní mapy
    plt.figure(figsize=(16, 4))
    sns.heatmap(pivot_data, cmap='viridis', linewidths=0.1, linecolor='white')
    plt.title(f'Kalendářní teplotní mapa pro {year if year else "všechna data"}')
    plt.ylabel('Den v týdnu (0=Pondělí, 6=Neděle)')
    plt.yticks(np.arange(7) + 0.5, ['Pondělí', 'Úterý', 'Středa', 'Čtvrtek', 'Pátek', 'Sobota', 'Neděle'])
    plt.tight_layout()
    plt.show()

plot_calendar_heatmap(complex_ts, year=2018)
```

## Klouzavé průměry a exponenciální vyhlazování

Klouzavé průměry a exponenciální vyhlazování jsou jednoduché, ale účinné metody pro identifikaci trendů a vyhlazení šumu v datech časových řad.

```python
# Vytvoření zašuměné časové řady
np.random.seed(42)
dates = pd.date_range(start='2020-01-01', periods=200, freq='D')
signal = 10 + 0.05 * np.arange(200) + 5 * np.sin(np.linspace(0, 4*np.pi, 200))
noise = np.random.normal(0, 1, 200)
ts_noisy = pd.Series(signal + noise, index=dates)

# Výpočet různých typů klouzavých průměrů
ma_7 = ts_noisy.rolling(window=7, center=True).mean()
ma_30 = ts_noisy.rolling(window=30, center=True).mean()
ewm_alpha_0_1 = ts_noisy.ewm(alpha=0.1).mean()
ewm_alpha_0_3 = ts_noisy.ewm(alpha=0.3).mean()

# Vykreslení původních dat a klouzavých průměrů
plt.figure(figsize=(14, 7))

plt.subplot(2, 1, 1)
plt.plot(ts_noisy, label='Původní', alpha=0.5)
plt.plot(ma_7, label='7-denní KP', linewidth=2)
plt.plot(ma_30, label='30-denní KP', linewidth=2)
plt.title('Jednoduché klouzavé průměry')
plt.legend()
plt.grid(True)

plt.subplot(2, 1, 2)
plt.plot(ts_noisy, label='Původní', alpha=0.5)
plt.plot(ewm_alpha_0_1, label='EWM (α=0.1)', linewidth=2)
plt.plot(ewm_alpha_0_3, label='EWM (α=0.3)', linewidth=2)
plt.title('Exponenciálně vážené klouzavé průměry')
plt.legend()
plt.grid(True)

plt.tight_layout()
plt.show()

# Jednoduché exponenciální vyhlazování
from statsmodels.tsa.holtwinters import SimpleExpSmoothing

# Vytvoření modelu jednoduchého exponenciálního vyhlazování
ses_model = SimpleExpSmoothing(ts_noisy).fit(smoothing_level=0.2)
ses_pred = ses_model.fittedvalues

# Holt-Winters exponenciální vyhlazování (s trendem)
from statsmodels.tsa.holtwinters import ExponentialSmoothing

# Vytvoření modelu Holt-Winters (trend, ale bez sezónnosti)
hw_model = ExponentialSmoothing(ts_noisy, trend='add', seasonal=None).fit()
hw_pred = hw_model.fittedvalues

# Vykreslení výsledků exponenciálního vyhlazování
plt.figure(figsize=(14, 7))
plt.plot(ts_noisy, label='Původní', alpha=0.5)
plt.plot(ses_pred, label='Jednoduché exponenciální vyhlazování', linewidth=2)
plt.plot(hw_pred, label='Holt-Winters (Trend)', linewidth=2)
plt.title('Metody exponenciálního vyhlazování')
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()

# Prognózování budoucích hodnot
forecast_steps = 30
ses_forecast = ses_model.forecast(forecast_steps)
hw_forecast = hw_model.forecast(forecast_steps)

# Vykreslení prognóz
plt.figure(figsize=(14, 7))
plt.plot(ts_noisy, label='Historická data', alpha=0.5)
plt.plot(ses_pred, label='SES Proložené', linewidth=1.5, alpha=0.8)
plt.plot(hw_pred, label='H-W Proložené', linewidth=1.5, alpha=0.8)

# Přidání prognóz
future_dates = pd.date_range(start=ts_noisy.index[-1] + pd.Timedelta('1 day'), 
                           periods=forecast_steps, freq='D')
plt.plot(future_dates, ses_forecast, label='SES Prognóza', linewidth=2, linestyle='--')
plt.plot(future_dates, hw_forecast, label='H-W Prognóza', linewidth=2, linestyle='--')

plt.title('Exponenciální vyhlazování: Proložené hodnoty a prognózy')
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Autokorelace a parciální autokorelace

Funkce autokorelace a parciální autokorelace (ACF/PACF) jsou kritické nástroje pro identifikaci vzorů a určení parametrů pro modelování časových řad.

```python
# Vytvoření vzorku časové řady se silnou autokorelací
np.random.seed(42)
ar_params = [0.7, -0.2]  # AR(2) proces
ma_params = [0.3, 0.1]   # MA(2) proces

from statsmodels.tsa.arima_process import ArmaProcess
ar = np.r_[1, -np.array(ar_params)]  # Přidání 1 na začátek
ma = np.r_[1, np.array(ma_params)]   # Přidání 1 na začátek

arma_process = ArmaProcess(ar, ma)
arma_sample = arma_process.generate_sample(nsample=200)
arma_ts = pd.Series(arma_sample, index=pd.date_range(start='2020-01-01', periods=200, freq='D'))

# Vykreslení ARMA procesu
plt.figure(figsize=(10, 6))
plt.plot(arma_ts)
plt.title('ARMA(2,2) Proces')
plt.grid(True)
plt.tight_layout()
plt.show()

# Vykreslení ACF a PACF
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 8))

# Autokorelační funkce (ACF)
plot_acf(arma_ts, lags=30, ax=ax1)
ax1.set_title('Autokorelační funkce (ACF)')

# Parciální autokorelační funkce (PACF)
plot_pacf(arma_ts, lags=30, ax=ax2)
ax2.set_title('Parciální autokorelační funkce (PACF)')

plt.tight_layout()
plt.show()

# Interpretace ACF a PACF
print("Interpretace grafů ACF a PACF:")
print("1. ACF zobrazuje korelace mezi časovou řadou a jejími zpožděními.")
print("2. PACF zobrazuje korelace mezi časovou řadou a jejími zpožděními, s kontrolou pro mezilehlá zpoždění.")
print("3. V AR(p) procesu se PACF odřízne po zpoždění p, zatímco ACF postupně klesá.")
print("4. V MA(q) procesu se ACF odřízne po zpoždění q, zatímco PACF postupně klesá.")
print("5. V ARMA(p,q) procesu postupně klesá jak ACF, tak PACF.")
```

## ARIMA modely

Autoregresní integrovaný klouzavý průměr (ARIMA) modely jsou jedním z nejčastěji používaných přístupů k prognózování časových řad.

```python
# Vytvoření ARIMA modelu pro data leteckých pasažérů
import warnings
warnings.filterwarnings('ignore')  # Potlačení varování o konvergenci

# Použijeme logaritmicky transformovaná data pro stabilizaci rozptylu
airline_log = np.log(airline['Passengers'])

# Rozdělení dat na trénovací a testovací množiny
train_size = int(len(airline_log) * 0.8)
train, test = airline_log[:train_size], airline_log[train_size:]

# Vytvoření ARIMA modelu
# p=1 (řád AR), d=1 (diferencování), q=1 (řád MA)
arima_model = ARIMA(train, order=(1, 1, 1))
arima_fit = arima_model.fit()

# Shrnutí modelu
print(arima_fit.summary())

# Prognóza
forecast_steps = len(test)
forecast_result = arima_fit.forecast(steps=forecast_steps)

# Vytvoření DataFrame pro prognózy
forecast_index = test.index
forecast_series = pd.Series(forecast_result, index=forecast_index)

# Výpočet intervalů spolehlivosti
from scipy import stats
alpha = 0.05  # 95% interval spolehlivosti
forecast_std_err = np.sqrt(arima_fit.params['sigma2'])
z_critical = stats.norm.ppf(1 - alpha/2)
ci_lower = forecast_series - z_critical * forecast_std_err
ci_upper = forecast_series + z_critical * forecast_std_err

# Výpočet přesnosti prognózy
mse = mean_squared_error(test, forecast_series)
mae = mean_absolute_error(test, forecast_series)
rmse = np.sqrt(mse)

print(f"Střední kvadratická chyba: {mse:.4f}")
print(f"Střední absolutní chyba: {mae:.4f}")
print(f"Odmocnina střední kvadratické chyby: {rmse:.4f}")

# Vykreslení výsledků
plt.figure(figsize=(12, 6))
plt.plot(train, label='Trénovací data')
plt.plot(test, label='Testovací data')
plt.plot(forecast_series, label='ARIMA Prognóza', linestyle='--')
plt.fill_between(forecast_index, ci_lower, ci_upper, color='pink', alpha=0.3, label='95% Interval spolehlivosti')
plt.title('ARIMA Prognóza počtu leteckých pasažérů (logaritmická škála)')
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()

# Auto ARIMA - Automatické nalezení nejlepších parametrů
try:
    import pmdarima as pm
    
    # Vytvoření auto ARIMA modelu
    auto_arima_model = pm.auto_arima(
        train,
        seasonal=True,
        m=12,  # Měsíční sezónnost
        start_p=0, start_q=0,
        max_p=3, max_q=3, max_d=2,
        information_criterion='aic',
        trace=True
    )
    
    print("\nNejlepší parametry ARIMA modelu:")
    print(f"ARIMA({auto_arima_model.order[0]}, {auto_arima_model.order[1]}, {auto_arima_model.order[2]})({auto_arima_model.seasonal_order[0]}, {auto_arima_model.seasonal_order[1]}, {auto_arima_model.seasonal_order[2]}, {auto_arima_model.seasonal_order[3]})")
    
    # Prognóza s auto ARIMA
    auto_forecast = auto_arima_model.predict(n_periods=forecast_steps)
    auto_forecast_series = pd.Series(auto_forecast, index=forecast_index)
    
    # Výpočet přesnosti prognózy
    auto_mse = mean_squared_error(test, auto_forecast_series)
    auto_rmse = np.sqrt(auto_mse)
    
    print(f"Auto ARIMA RMSE: {auto_rmse:.4f}")
    
    # Vykreslení výsledků
    plt.figure(figsize=(12, 6))
    plt.plot(train, label='Trénovací data')
    plt.plot(test, label='Testovací data')
    plt.plot(auto_forecast_series, label='Auto ARIMA Prognóza', linestyle='--')
    plt.title('Auto ARIMA Prognóza počtu leteckých pasažérů (logaritmická škála)')
    plt.legend()
    plt.grid(True)
    plt.tight_layout()
    plt.show()
    
except ImportError:
    print("Balíček pmdarima není nainstalován. Pro použití Auto ARIMA nainstalujte pomocí: pip install pmdarima")
```

## Sezónní dekompozice

Sezónní dekompozice pomáhá pochopit základní vzory v datech časových řad tím, že je rozdělí na trend, sezónní a reziduální komponenty.

```python
# Generování syntetické časové řady se silnou sezónností
dates = pd.date_range(start='2018-01-01', periods=730, freq='D')  # 2 roky
trend = np.linspace(10, 30, 730)  # Rostoucí trend
annual_seasonality = 10 * np.sin(np.linspace(0, 4*np.pi, 730))  # 2 kompletní cykly
weekly_seasonality = 3 * np.sin(np.linspace(0, 2*np.pi*104, 730))  # 104 týdnů
noise = np.random.normal(0, 2, 730)

ts_seasonal = pd.Series(trend + annual_seasonality + weekly_seasonality + noise, index=dates)

# Vykreslení časové řady
plt.figure(figsize=(12, 6))
plt.plot(ts_seasonal)
plt.title('Časová řada s vícenásobnými sezónními vzory')
plt.grid(True)
plt.tight_layout()
plt.show()

# Sezónní dekompozice s ročním cyklem (365 dnů)
decomposition_annual = seasonal_decompose(ts_seasonal, model='additive', period=365)

# Vykreslení roční dekompozice
```

## Prognózování a vyhodnocení

Prognózování budoucích hodnot je konečným cílem většiny analýz časových řad. Správné vyhodnocení pomáhá určit nejlepší model pro danou úlohu.

```python
# Použití klasického datasetu časové řady pro ukázku prognózování
# Dataset AirPassengers (měsíční mezinárodní letečtí pasažéři od 1949 do 1960)

# Rozdělení dat na trénovací a testovací množiny
airline_data = airline['Passengers']
split_point = len(airline_data) - 12  # Použití posledních 12 měsíců jako testovací množiny
train_data = airline_data[:split_point]
test_data = airline_data[split_point:]

print(f"Velikost trénovacích dat: {train_data.shape} (od {train_data.index.min()} do {train_data.index.max()})")
print(f"Velikost testovacích dat: {test_data.shape} (od {test_data.index.min()} do {test_data.index.max()})")

# Implementace různých metod prognózování

# 1. Naivní prognóza (použití poslední hodnoty trénovací množiny pro všechny prognózy)
naive_forecast = pd.Series([train_data.iloc[-1]] * len(test_data), index=test_data.index)

# 2. Sezónní naivní prognóza (použití hodnoty ze stejného měsíce předchozího roku)
seasonal_naive_forecast = pd.Series(train_data.iloc[-(12):].values, index=test_data.index)

# 3. Jednoduchý klouzavý průměr (posledních 12 měsíců)
ma_12_values = train_data.rolling(window=12).mean().iloc[-1]
ma_forecast = pd.Series([ma_12_values] * len(test_data), index=test_data.index)

# 4. Exponenciální vyhlazování
from statsmodels.tsa.holtwinters import ExponentialSmoothing

# Multiplikativní Holt-Winters (exponenciální vyhlazování s trendem a sezónností)
hw_model = ExponentialSmoothing(
    train_data, 
    trend='mul',        # Multiplikativní trend
    seasonal='mul',     # Multiplikativní sezónnost
    seasonal_periods=12 # Měsíční data
).fit()

hw_forecast = hw_model.forecast(len(test_data))

# 5. SARIMA Model (Sezónní ARIMA)
from statsmodels.tsa.statespace.sarimax import SARIMAX

# SARIMA parametry: (p,d,q)x(P,D,Q,s)
# p, d, q: Nesezónní komponenty
# P, D, Q: Sezónní komponenty
# s: Sezónní perioda
sarima_model = SARIMAX(
    train_data,
    order=(1, 1, 1),            # Nesezónní část (p,d,q)
    seasonal_order=(1, 1, 1, 12) # Sezónní část (P,D,Q,s)
).fit(disp=False)

sarima_forecast = sarima_model.forecast(len(test_data))

# Výpočet chyb prognózy
def calculate_metrics(actual, forecast):
    mse = mean_squared_error(actual, forecast)
    rmse = np.sqrt(mse)
    mae = mean_absolute_error(actual, forecast)
    mape = np.mean(np.abs((actual - forecast) / actual)) * 100
    return {
        'MSE': mse,
        'RMSE': rmse,
        'MAE': mae,
        'MAPE': f"{mape:.2f}%"
    }

# Vyhodnocení všech prognóz
methods = {
    'Naivní': naive_forecast,
    'Sezónní naivní': seasonal_naive_forecast,
    'Klouzavý průměr': ma_forecast,
    'Holt-Winters': hw_forecast,
    'SARIMA': sarima_forecast
}

results = {}
for name, forecast in methods.items():
    results[name] = calculate_metrics(test_data, forecast)

# Zobrazení výsledků jako DataFrame
results_df = pd.DataFrame(results).T
print("\nMetriky vyhodnocení prognóz:")
print(results_df)

# Vykreslení všech prognóz
plt.figure(figsize=(14, 8))

# Vykreslení trénovacích a testovacích dat
plt.plot(train_data, label='Trénovací data', color='black')
plt.plot(test_data, label='Testovací data (Skutečnost)', color='blue', linestyle='-')

# Vykreslení prognóz
colors = ['red', 'green', 'purple', 'orange', 'brown']
for i, (name, forecast) in enumerate(methods.items()):
    plt.plot(forecast, label=f'Prognóza {name}', color=colors[i], linestyle='--')

plt.legend()
plt.title('Porovnání metod prognózování')
plt.ylabel('Počet leteckých pasažérů')
plt.grid(True)
plt.tight_layout()
plt.show()
```

## Shrnutí

Analýza časových řad je základní technikou v datové vědě pro pochopení a prognózování sekvenčních dat. Hlavní poznatky zahrnují:

1. **Komponenty časových řad**: Porozumění trendu, sezónnosti, cyklickým a reziduálním komponentám pomáhá při budování vhodných modelů.

2. **Stacionarita**: Většina modelů časových řad vyžaduje stacionaritu; techniky jako diferencování a transformace mohou převést nestacionární data na stacionární.

3. **Vizualizace**: Efektivní vizualizační techniky pomáhají identifikovat vzory, anomálie a charakteristiky dat časových řad.

4. **Klouzavé průměry a vyhlazování**: Jednoduché, ale účinné techniky pro detekci trendu a redukci šumu.

5. **Analýza autokorelace**: Grafy ACF a PACF pomáhají identifikovat časové závislosti a navádět výběr parametrů modelu.

6. **ARIMA modely**: Autoregresní integrované modely klouzavých průměrů jsou všestranné a široce používané pro prognózování časových řad.

7. **Sezónní dekompozice**: Rozložení časové řady na komponenty odhaluje základní vzory.

8. **Různé metody prognózování**: Různé metody (naivní, exponenciální vyhlazování, ARIMA) mají silné a slabé stránky v závislosti na datech.

9. **Hodnocení modelů**: Metriky jako RMSE, MAE a MAPE pomáhají porovnávat a vybírat nejvhodnější prognostický model.

Analýza časových řad nachází uplatnění v různých oblastech včetně financí, ekonomie, prognózy prodeje, předpovědi počasí a analýzy dat z IoT senzorů. Zvládnutí těchto základů poskytuje pevný základ pro pokročilé techniky modelování a prognózování časových řad.
