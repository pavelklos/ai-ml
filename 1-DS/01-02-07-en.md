## Introduction to Imbalanced Datasets

Imbalanced datasets occur when the classes in a classification problem are not equally represented. This is common in many real-world scenarios like fraud detection, disease diagnosis, and anomaly detection, where the class of interest (positive class) is rare compared to the negative class.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import confusion_matrix, classification_report, roc_curve, auc, precision_recall_curve, average_precision_score
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from collections import Counter

# Set random seed for reproducibility
np.random.seed(42)
```

## Detecting and Visualizing Class Imbalance

Before addressing imbalance, it's important to understand the extent of the problem in your dataset. Let's create a synthetic imbalanced dataset and visualize the class distribution.

```python
# Create a synthetic imbalanced dataset (90% class 0, 10% class 1)
X, y = make_classification(
    n_samples=10000,
    n_features=10,
    n_informative=5,
    n_redundant=5,
    n_clusters_per_class=1,
    weights=[0.9, 0.1],  # Class distribution: 90% class 0, 10% class 1
    random_state=42
)

# Convert to DataFrame for easier manipulation
df = pd.DataFrame(X, columns=[f'feature_{i}' for i in range(X.shape[1])])
df['target'] = y

# Check class distribution
class_counts = pd.Series(y).value_counts()
print("Class distribution:")
print(class_counts)
print(f"Class imbalance ratio: 1:{class_counts[0]/class_counts[1]:.1f}")

# Visualize class imbalance
plt.figure(figsize=(10, 6))
ax = sns.countplot(x='target', data=df)
plt.title('Class Distribution')
plt.xlabel('Class')
plt.ylabel('Count')
for p in ax.patches:
    ax.annotate(f'{p.get_height()}', (p.get_x() + p.get_width() / 2., p.get_height()),
                ha='center', va='bottom')
plt.tight_layout()
plt.show()

# Split the data into training and testing sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)
print(f"Training set class distribution: {Counter(y_train)}")
print(f"Testing set class distribution: {Counter(y_test)}")
```

## Resampling Techniques

Resampling techniques modify the dataset to balance class distribution. The two main approaches are:

1. **Undersampling**: Removing samples from the majority class
2. **Oversampling**: Adding more samples of the minority class

```python
from imblearn.under_sampling import RandomUnderSampler
from imblearn.over_sampling import RandomOverSampler

# Random undersampling
rus = RandomUnderSampler(random_state=42)
X_train_under, y_train_under = rus.fit_resample(X_train, y_train)

# Random oversampling
ros = RandomOverSampler(random_state=42)
X_train_over, y_train_over = ros.fit_resample(X_train, y_train)

# Compare class distributions after resampling
print("Original class distribution:", Counter(y_train))
print("After undersampling:", Counter(y_train_under))
print("After oversampling:", Counter(y_train_over))

# Visualize the resampled distributions
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# Original data
sns.countplot(x=y_train, ax=axes[0]).set_title('Original')
axes[0].set_xlabel('Class')
axes[0].set_ylabel('Count')

# Undersampled data
sns.countplot(x=y_train_under, ax=axes[1]).set_title('Undersampled')
axes[1].set_xlabel('Class')
axes[1].set_ylabel('Count')

# Oversampled data
sns.countplot(x=y_train_over, ax=axes[2]).set_title('Oversampled')
axes[2].set_xlabel('Class')
axes[2].set_ylabel('Count')

plt.tight_layout()
plt.show()
```

## SMOTE and Advanced Oversampling

Synthetic Minority Over-sampling Technique (SMOTE) creates synthetic samples for the minority class instead of simply duplicating existing samples. This helps to address the overfitting problem that can occur with simple oversampling.

```python
from imblearn.over_sampling import SMOTE, ADASYN, BorderlineSMOTE

# Apply SMOTE
smote = SMOTE(random_state=42)
X_train_smote, y_train_smote = smote.fit_resample(X_train, y_train)

# Apply BorderlineSMOTE (focuses on harder examples)
bsmote = BorderlineSMOTE(random_state=42)
X_train_bsmote, y_train_bsmote = bsmote.fit_resample(X_train, y_train)

# Apply ADASYN (Adaptive Synthetic Sampling)
adasyn = ADASYN(random_state=42)
X_train_adasyn, y_train_adasyn = adasyn.fit_resample(X_train, y_train)

print("Original class distribution:", Counter(y_train))
print("After SMOTE:", Counter(y_train_smote))
print("After BorderlineSMOTE:", Counter(y_train_bsmote))
print("After ADASYN:", Counter(y_train_adasyn))

# Visualize the effect of SMOTE on a 2D subset of the data
def plot_2d_space(X, y, title):
    # Use only the first two features for visualization
    plt.figure(figsize=(10, 6))
    plt.scatter(X[y == 0, 0], X[y == 0, 1], label='Class 0', alpha=0.5)
    plt.scatter(X[y == 1, 0], X[y == 1, 1], label='Class 1', alpha=0.5)
    plt.title(title)
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.legend()
    plt.tight_layout()

# Plot original data
plot_2d_space(X_train, y_train, 'Original Data')
plt.show()

# Plot SMOTE-oversampled data
plot_2d_space(X_train_smote, y_train_smote, 'SMOTE Oversampling')
plt.show()
```

## Algorithm-Level Approaches

Some machine learning algorithms can be adapted to handle imbalanced datasets without modifying the data itself.

```python
# Using class weights in logistic regression
clf_weighted = LogisticRegression(class_weight='balanced', random_state=42, max_iter=1000)
clf_weighted.fit(X_train, y_train)

# Using class weights in random forest
rf_weighted = RandomForestClassifier(class_weight='balanced', random_state=42)
rf_weighted.fit(X_train, y_train)

# Predict on the test set
y_pred_weighted_lr = clf_weighted.predict(X_test)
y_pred_weighted_rf = rf_weighted.predict(X_test)

# Compare with unweighted models
clf_unweighted = LogisticRegression(random_state=42, max_iter=1000)
clf_unweighted.fit(X_train, y_train)
y_pred_unweighted_lr = clf_unweighted.predict(X_test)

# Print classification reports
print("Unweighted Logistic Regression:")
print(classification_report(y_test, y_pred_unweighted_lr))
print("\nWeighted Logistic Regression:")
print(classification_report(y_test, y_pred_weighted_lr))
print("\nWeighted Random Forest:")
print(classification_report(y_test, y_pred_weighted_rf))
```

## Ensemble Methods for Imbalanced Data

Ensemble methods can be particularly effective for imbalanced datasets.

```python
from imblearn.ensemble import BalancedRandomForestClassifier, EasyEnsembleClassifier, RUSBoostClassifier

# Balanced Random Forest
brf = BalancedRandomForestClassifier(random_state=42)
brf.fit(X_train, y_train)
y_pred_brf = brf.predict(X_test)

# EasyEnsemble (Bagging with undersampling)
eec = EasyEnsembleClassifier(random_state=42)
eec.fit(X_train, y_train)
y_pred_eec = eec.predict(X_test)

# RUSBoost (Boosting with undersampling)
rusboost = RUSBoostClassifier(random_state=42)
rusboost.fit(X_train, y_train)
y_pred_rusboost = rusboost.predict(X_test)

# Compare the ensemble methods
print("Balanced Random Forest:")
print(classification_report(y_test, y_pred_brf))
print("\nEasyEnsemble Classifier:")
print(classification_report(y_test, y_pred_eec))
print("\nRUSBoost Classifier:")
print(classification_report(y_test, y_pred_rusboost))
```

## Evaluation Metrics for Imbalanced Datasets

Traditional accuracy is not a good metric for imbalanced datasets. Better metrics include:
- Precision, Recall, F1-Score
- ROC Curve & AUC
- Precision-Recall Curve & Average Precision
- Balanced Accuracy

```python
# Train a model on differently balanced datasets
lr_original = LogisticRegression(max_iter=1000)
lr_original.fit(X_train, y_train)

lr_smote = LogisticRegression(max_iter=1000)
lr_smote.fit(X_train_smote, y_train_smote)

# Get predictions and probabilities
y_pred_orig = lr_original.predict(X_test)
y_proba_orig = lr_original.predict_proba(X_test)[:, 1]

y_pred_smote = lr_smote.predict(X_test)
y_proba_smote = lr_smote.predict_proba(X_test)[:, 1]

# Confusion matrices
cm_orig = confusion_matrix(y_test, y_pred_orig)
cm_smote = confusion_matrix(y_test, y_pred_smote)

# Visualize confusion matrices
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
sns.heatmap(cm_orig, annot=True, fmt='d', cmap='Blues', ax=ax1)
ax1.set_title('Confusion Matrix - Original Data')
ax1.set_xlabel('Predicted')
ax1.set_ylabel('True')

sns.heatmap(cm_smote, annot=True, fmt='d', cmap='Blues', ax=ax2)
ax2.set_title('Confusion Matrix - SMOTE')
ax2.set_xlabel('Predicted')
ax2.set_ylabel('True')

plt.tight_layout()
plt.show()

# ROC curve
fpr_orig, tpr_orig, _ = roc_curve(y_test, y_proba_orig)
roc_auc_orig = auc(fpr_orig, tpr_orig)

fpr_smote, tpr_smote, _ = roc_curve(y_test, y_proba_smote)
roc_auc_smote = auc(fpr_smote, tpr_smote)

plt.figure(figsize=(10, 6))
plt.plot(fpr_orig, tpr_orig, label=f'Original (AUC = {roc_auc_orig:.2f})')
plt.plot(fpr_smote, tpr_smote, label=f'SMOTE (AUC = {roc_auc_smote:.2f})')
plt.plot([0, 1], [0, 1], 'k--')
plt.xlabel('False Positive Rate')
plt.ylabel('True Positive Rate')
plt.title('ROC Curve')
plt.legend()
plt.show()

# Precision-Recall curve
precision_orig, recall_orig, _ = precision_recall_curve(y_test, y_proba_orig)
ap_orig = average_precision_score(y_test, y_proba_orig)

precision_smote, recall_smote, _ = precision_recall_curve(y_test, y_proba_smote)
ap_smote = average_precision_score(y_test, y_proba_smote)

plt.figure(figsize=(10, 6))
plt.plot(recall_orig, precision_orig, label=f'Original (AP = {ap_orig:.2f})')
plt.plot(recall_smote, precision_smote, label=f'SMOTE (AP = {ap_smote:.2f})')
plt.xlabel('Recall')
plt.ylabel('Precision')
plt.title('Precision-Recall Curve')
plt.legend()
plt.show()

# Print classification reports
print("Classification Report - Original Data:")
print(classification_report(y_test, y_pred_orig))
print("\nClassification Report - SMOTE:")
print(classification_report(y_test, y_pred_smote))
```

## Cost-Sensitive Learning

Cost-sensitive learning involves modifying the learning algorithm to consider the costs associated with misclassifying samples.

```python
# Define a cost matrix where misclassifying the minority class is more expensive
# For example, in a fraud detection scenario:
# - False Negative (missing a fraud) might cost $1000
# - False Positive (false alarm) might cost $10

from sklearn.ensemble import RandomForestClassifier

# Class weights give higher importance to the minority class
# The weights are inversely proportional to class frequencies
class_weights = {0: 1, 1: 9}  # Assuming a 90:10 class ratio

# Cost-sensitive Random Forest
rf_cost = RandomForestClassifier(
    random_state=42,
    class_weight=class_weights
)
rf_cost.fit(X_train, y_train)
y_pred_cost = rf_cost.predict(X_test)

# Predict probabilities
y_proba_cost = rf_cost.predict_proba(X_test)[:, 1]

# Create a threshold-adjusted prediction 
# (Lowering the threshold to increase recall for the positive class)
custom_threshold = 0.3  # Standard is 0.5
y_pred_threshold = (y_proba_cost >= custom_threshold).astype(int)

# Evaluate
print("Standard Random Forest:")
print(classification_report(y_test, y_pred_weighted_rf))
print("\nCost-Sensitive Random Forest:")
print(classification_report(y_test, y_pred_cost))
print("\nThreshold-Adjusted Predictions (t=0.3):")
print(classification_report(y_test, y_pred_threshold))
```

## Case Studies: Credit Fraud Detection

Let's work through a simplified credit card fraud detection case study:

```python
# Load a common dataset for imbalanced learning 
# (if you have access to the web, otherwise use the synthetic data)

try:
    # Try to load the credit card fraud dataset (if available)
    from sklearn.datasets import fetch_openml
    dataset = fetch_openml("credit-card-fraud", version=1, as_frame=True)
    
    # Use a subset for demonstration
    credit_data = dataset.data.sample(10000, random_state=42)
    credit_target = dataset.target.loc[credit_data.index]
    credit_target = credit_target.astype(int)
    
    print(f"Dataset shape: {credit_data.shape}")
    print(f"Class distribution: {Counter(credit_target)}")
    
except:
    # Create a synthetic fraud dataset if the real one is not available

    X_fraud, y_fraud = make_classification(
        n_samples=10000,
        n_features=30,
        n_informative=15,
        n_redundant=10,
        n_clusters_per_class=1,
        weights=[0.995, 0.005],  # 0.5% fraud
        random_state=42
    )
    
    credit_data = pd.DataFrame(X_fraud, columns=[f'feature_{i}' for i in range(X_fraud.shape[1])])
    credit_target = pd.Series(y_fraud)
    
    print(f"Synthetic dataset shape: {credit_data.shape}")
    print(f"Class distribution: {Counter(credit_target)}")

# Split the data
X_train, X_test, y_train, y_test = train_test_split(
    credit_data, credit_target, test_size=0.3, 
    random_state=42, stratify=credit_target
)

# Apply SMOTE
smote = SMOTE(random_state=42)
X_train_smote, y_train_smote = smote.fit_resample(X_train, y_train)

# Train models
rf_baseline = RandomForestClassifier(random_state=42)
rf_baseline.fit(X_train, y_train)

rf_smote = RandomForestClassifier(random_state=42)
rf_smote.fit(X_train_smote, y_train_smote)

rf_weighted = RandomForestClassifier(class_weight='balanced', random_state=42)
rf_weighted.fit(X_train, y_train)

# Get predictions
y_pred_baseline = rf_baseline.predict(X_test)
y_pred_smote = rf_smote.predict(X_test)
y_pred_weighted = rf_weighted.predict(X_test)

# Compare results
print("\nBaseline Random Forest:")
print(classification_report(y_test, y_pred_baseline))
print("\nSMOTE Random Forest:")
print(classification_report(y_test, y_pred_smote))
print("\nWeighted Random Forest:")
print(classification_report(y_test, y_pred_weighted))

# Show ROC curves
plt.figure(figsize=(10, 6))
for model, name, y_pred in [
    (rf_baseline, 'Baseline', y_pred_baseline), 
    (rf_smote, 'SMOTE', y_pred_smote), 
    (rf_weighted, 'Weighted', y_pred_weighted)
]:
    proba = model.predict_proba(X_test)[:, 1]
    fpr, tpr, _ = roc_curve(y_test, proba)
    roc_auc = auc(fpr, tpr)
    plt.plot(fpr, tpr, label=f'{name} (AUC = {roc_auc:.3f})')

plt.plot([0, 1], [0, 1], 'k--')
plt.xlabel('False Positive Rate')
plt.ylabel('True Positive Rate')
plt.title('ROC Curve Comparison')
plt.legend()
plt.show()
```

## Summary

Handling imbalanced datasets is crucial for building effective models in scenarios where the minority class is often the class of interest. Key approaches include:

1. **Data-Level Methods**:
   - Random undersampling and oversampling
   - SMOTE and its variants (BorderlineSMOTE, ADASYN)
   - Hybrid methods combining undersampling and oversampling

2. **Algorithm-Level Methods**:
   - Class weight adjustment
   - Cost-sensitive learning
   - Threshold moving
   - Specialized ensemble methods (BalancedRandomForest, EasyEnsemble, RUSBoost)

3. **Evaluation Strategies**:
   - Precision, Recall, F1-Score instead of accuracy
   - ROC curves and AUC
   - Precision-Recall curves
   - Balanced accuracy

When dealing with imbalanced datasets:
- Always explore your data to understand the extent of imbalance
- Use stratified sampling for train/test splits to maintain class proportions
- Choose appropriate evaluation metrics
- Consider the business impact of false positives vs. false negatives
- Experiment with multiple approaches and compare results
- Be careful about overfitting, especially with oversampling techniques

Imbalanced learning remains an active research area, with new techniques continually being developed to address this common but challenging problem in real-world machine learning applications.
