## Úvod do datových pipeline

Datové pipeline jsou sekvence prvků zpracování dat, kde výstup jednoho prvku je vstupem pro další. V datové vědě pipeline automatizují tok dat od sběru přes transformaci, analýzu až po vizualizaci nebo nasazení modelu.

Hlavní výhody datových pipeline:
- **Automatizace**: Omezení manuálních zásahů
- **Reprodukovatelnost**: Zajištění konzistentních výsledků
- **Škálovatelnost**: Zvládání rostoucích objemů dat
- **Správa závislostí**: Koordinace komplexních pracovních postupů
- **Zpracování chyb**: Robustní detekce a zotavení z chyb

```python
# Jednoduchá konceptuální datová pipeline
def extract():
    """Extrakce dat ze zdroje"""
    print("Extrahuji data...")
    return {"data": [1, 2, 3, 4, 5]}

def transform(raw_data):
    """Transformace extrahovaných dat"""
    print("Transformuji data...")
    transformed = [x * 10 for x in raw_data["data"]]
    return {"transformed_data": transformed}

def load(transformed_data):
    """Nahrání transformovaných dat"""
    print("Nahrávám data...")
    print(f"Data nahrána: {transformed_data['transformed_data']}")

# Spuštění pipeline
def run_pipeline():
    raw_data = extract()
    transformed_data = transform(raw_data)
    load(transformed_data)

run_pipeline()
```

## Seznámení s Apache Airflow

Apache Airflow je open-source platforma pro orchestraci komplexních výpočetních pracovních postupů a pipeline pro zpracování dat. Byl vyvinut společností Airbnb v roce 2014 a později se stal projektem Apache Software Foundation.

### Klíčové koncepty v Airflow:

1. **DAG (Directed Acyclic Graph)**: Kolekce úkolů se závislostmi mezi nimi
2. **Operátory**: Šablony pro úkoly (např. PythonOperator, BashOperator)
3. **Úkoly**: Instance operátorů
4. **Instance úkolů**: Konkrétní běhy úkolu v určitém čase
5. **Plánovač**: Monitoruje DAG a spouští provádění úkolů
6. **Executor**: Určuje, jak jsou úkoly prováděny
7. **Webový server**: Poskytuje UI pro vizualizaci a monitoring

### Instalace a nastavení:

```bash
# Instalace Airflow
pip install apache-airflow

# Inicializace databáze Airflow
airflow db init

# Vytvoření uživatele
airflow users create \
    --username admin \
    --password admin \
    --firstname First \
    --lastname Last \
    --role Admin \
    --email admin@example.com

# Spuštění webového serveru Airflow
airflow webserver --port 8080

# V novém terminálu spusťte plánovač
airflow scheduler
```

## Vytváření DAG v Airflow

DAG v Airflow jsou definovány v Python souborech, které specifikují strukturu pracovního toku.

```python
# dags/example_dag.py
from datetime import datetime, timedelta
from airflow import DAG
from airflow.operators.python import PythonOperator

# Výchozí argumenty pro všechny úkoly v DAG
default_args = {
    'owner': 'data_scientist',
    'depends_on_past': False,
    'start_date': datetime(2023, 1, 1),
    'email': ['data_scientist@example.com'],
    'email_on_failure': False,
    'email_on_retry': False,
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}

# Definice DAG
dag = DAG(
    'example_etl_pipeline',
    default_args=default_args,
    description='Jednoduchý ETL DAG',
    schedule_interval=timedelta(days=1),
    catchup=False
)

# Definice úkolů
def extract_data(**kwargs):
    """Extrakce dat ze zdroje"""
    print("Extrahuji data...")
    data = [1, 2, 3, 4, 5]
    kwargs['ti'].xcom_push(key='extracted_data', value=data)

def transform_data(**kwargs):
    """Transformace extrahovaných dat"""
    ti = kwargs['ti']
    data = ti.xcom_pull(key='extracted_data', task_ids='extract')
    print("Transformuji data...")
    transformed_data = [x * 10 for x in data]
    ti.xcom_push(key='transformed_data', value=transformed_data)

def load_data(**kwargs):
    """Nahrání transformovaných dat"""
    ti = kwargs['ti']
    data = ti.xcom_pull(key='transformed_data', task_ids='transform')
    print("Nahrávám data...")
    print(f"Data nahrána: {data}")

# Vytvoření instancí úkolů
extract_task = PythonOperator(
    task_id='extract',
    python_callable=extract_data,
    provide_context=True,
    dag=dag,
)

transform_task = PythonOperator(
    task_id='transform',
    python_callable=transform_data,
    provide_context=True,
    dag=dag,
)

load_task = PythonOperator(
    task_id='load',
    python_callable=load_data,
    provide_context=True,
    dag=dag,
)

# Nastavení závislostí úkolů
extract_task >> transform_task >> load_task
```

## Závislosti úkolů a plánování v Airflow

Airflow nabízí několik způsobů definování závislostí úkolů a plánování běhů:

```python
# dags/advanced_dag.py
from datetime import datetime, timedelta
from airflow import DAG
from airflow.operators.python import PythonOperator
from airflow.operators.bash import BashOperator
from airflow.utils.dates import days_ago

# Výchozí argumenty
default_args = {
    'owner': 'data_scientist',
    'depends_on_past': False,
    'start_date': days_ago(1),
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}

# Vytvoření DAG s cron-plánováním
dag = DAG(
    'advanced_pipeline',
    default_args=default_args,
    description='Pokročilý příklad datové pipeline',
    # Běh v 7:00 každý den
    schedule_interval='0 7 * * *',
    catchup=False
)

# Úkol 1: Stažení dat
download_data = BashOperator(
    task_id='download_data',
    bash_command='echo "Stahuji data z API..." && sleep 3',
    dag=dag,
)

# Úkol 2: Zpracování dat
def process_data(**context):
    print("Zpracovávám stažená data...")
    # Simulace zpracování
    processed_data = {"processed": True, "timestamp": datetime.now().isoformat()}
    return processed_data

process_data_task = PythonOperator(
    task_id='process_data',
    python_callable=process_data,
    provide_context=True,
    dag=dag,
)

# Úkol 3: Trénování modelu
def train_model(**context):
    processed_data = context['ti'].xcom_pull(task_ids='process_data')
    print(f"Trénuji model s daty zpracovanými v {processed_data['timestamp']}...")
    accuracy = 0.85
    context['ti'].xcom_push(key='model_accuracy', value=accuracy)
    
train_model_task = PythonOperator(
    task_id='train_model',
    python_callable=train_model,
    provide_context=True,
    dag=dag,
)

# Úkoly 4a a 4b: Dva paralelní úkoly po tréninku
evaluate_model = PythonOperator(
    task_id='evaluate_model',
    python_callable=lambda **kwargs: print(f"Vyhodnocení modelu dokončeno. "
                                         f"Přesnost: {kwargs['ti'].xcom_pull(task_ids='train_model', key='model_accuracy')}"),
    provide_context=True,
    dag=dag,
)

save_model = BashOperator(
    task_id='save_model',
    bash_command='echo "Ukládám model do úložiště..." && sleep 2 && echo "Model uložen"',
    dag=dag,
)

# Definování pracovního toku
download_data >> process_data_task >> train_model_task >> [evaluate_model, save_model]
```

## Úvod do Luigi

Luigi je další populární framework pro vytváření datových pipeline, vyvinutý a open-source vydaný společností Spotify. Zaměřuje se na řešení závislostí, správu pracovních toků a zvládání chyb.

### Klíčové koncepty v Luigi:

1. **Úkoly (Tasks)**: Třídy v Pythonu reprezentující jednotky práce
2. **Cíle (Targets)**: Výsledky úkolů (často soubory)
3. **Parametry (Parameters)**: Vstupy definující chování úkolu
4. **Závislosti (Dependencies)**: Vztahy mezi úkoly
5. **Centrální plánovač (Central Scheduler)**: Orchestruje provádění úkolů

### Instalace:

```bash
pip install luigi
```

## Vytváření úkolů a pracovních toků v Luigi

```python
# pipeline/luigi_example.py
import luigi
import pandas as pd
import numpy as np
from datetime import datetime

# 1. Úkol stažení dat
class DownloadDataTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def output(self):
        return luigi.LocalTarget(f"data/raw_{self.date}.csv")
    
    def run(self):
        # Simulace stahování dat generováním náhodných dat
        print("Stahuji data...")
        df = pd.DataFrame({
            'user_id': range(1000),
            'value': np.random.randn(1000)
        })
        
        # Ujistíme se, že adresář existuje
        os.makedirs(os.path.dirname(self.output().path), exist_ok=True)
        
        # Uložení dat
        df.to_csv(self.output().path, index=False)
        print("Data úspěšně stažena")

# 2. Úkol zpracování dat
class ProcessDataTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return DownloadDataTask(date=self.date)
    
    def output(self):
        return luigi.LocalTarget(f"data/processed_{self.date}.csv")
    
    def run(self):
        # Načtení vstupních dat
        df = pd.read_csv(self.input().path)
        
        # Zpracování dat
        print("Zpracovávám data...")
        df['processed_value'] = df['value'] * 2 + 1
        df['status'] = df['processed_value'].apply(lambda x: 'high' if x > 0 else 'low')
        
        # Uložení zpracovaných dat
        df.to_csv(self.output().path, index=False)
        print("Data úspěšně zpracována")

# 3. Úkol agregace dat
class AggregateDataTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return ProcessDataTask(date=self.date)
    
    def output(self):
        return luigi.LocalTarget(f"data/aggregated_{self.date}.csv")
    
    def run(self):
        # Načtení zpracovaných dat
        df = pd.read_csv(self.input().path)
        
        # Agregace dat
        print("Agreguji data...")
        agg_df = df.groupby('status').agg(
            count=('user_id', 'count'),
            avg_value=('processed_value', 'mean'),
            min_value=('processed_value', 'min'),
            max_value=('processed_value', 'max')
        ).reset_index()
        
        # Uložení agregovaných dat
        agg_df.to_csv(self.output().path, index=False)
        print("Data úspěšně agregována")

# 4. Úkol generování reportu
class GenerateReportTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return AggregateDataTask(date=self.date)
    
    def output(self):
        return luigi.LocalTarget(f"reports/report_{self.date}.txt")
    
    def run(self):
        # Načtení agregovaných dat
        agg_df = pd.read_csv(self.input().path)
        
        # Generování reportu
        print("Generuji report...")
        with self.output().open('w') as f:
            f.write(f"DATOVÝ REPORT PRO {self.date}\n")
            f.write("=" * 50 + "\n\n")
            
            for _, row in agg_df.iterrows():
                f.write(f"Status: {row['status']}\n")
                f.write(f"  Počet: {row['count']}\n")
                f.write(f"  Průměrná hodnota: {row['avg_value']:.2f}\n")
                f.write(f"  Rozsah: {row['min_value']:.2f} až {row['max_value']:.2f}\n\n")
                
            f.write("Konec reportu")
        
        print("Report úspěšně vygenerován")

# Spuštění pipeline
if __name__ == "__main__":
    import os
    os.makedirs("data", exist_ok=True)
    os.makedirs("reports", exist_ok=True)
    luigi.build([GenerateReportTask()], local_scheduler=True)
```

## Osvědčené postupy pro datové pipeline

1. **Idempotence**: Pipeline by měly při opakovaném spuštění s stejnými vstupy produkovat stejné výsledky
2. **Atomicita**: Úkoly by měly být buď plně dokončené, nebo plně selhat, bez částečných aktualizací
3. **Izolace**: Úkoly by se neměly navzájem ovlivňovat
4. **Monitoring a logování**: Sledování výkonu pipeline a chyb
5. **Zpracování chyb**: Implementace opakovaných pokusů a mechanismů pro elegantní selhání
6. **Správa verzí**: Sledování změn v kódu pipeline
7. **Testování**: Vytváření jednotkových a integračních testů pro pipeline
8. **Dokumentace**: Dokumentování chování a požadavků pipeline

Příklad implementace idempotentních, atomických úkolů se zpracováním chyb:

```python
# Příklad implementace osvědčených postupů v úkolu Airflow
from airflow.operators.python import PythonOperator
import logging
import tempfile
import os
import shutil
from atomicwrites import atomic_write

def process_data_safely(**context):
    logger = logging.getLogger(__name__)
    execution_date = context['execution_date']
    
    # Použití unikátního identifikátoru pro tento běh úkolu
    run_id = f"process_data_{execution_date.isoformat()}"
    logger.info(f"Začátek úkolu s run_id: {run_id}")
    
    try:
        # Vytvoření dočasného adresáře pro zpracování
        with tempfile.TemporaryDirectory() as temp_dir:
            # Zpracování v dočasném adresáři
            temp_output_path = os.path.join(temp_dir, 'output.csv')
            
            # Získání vstupních dat
            logger.info("Získávám vstupní data")
            # ... kód pro získání dat ...
            
            # Zpracování dat
            logger.info("Zpracovávám data")
            # ... kód pro zpracování ...
            
            # Zápis výsledků do dočasného souboru
            logger.info("Zapisuji dočasné výsledky")
            # ... zápis do temp_output_path ...
            
            # Atomický přesun do konečného umístění
            final_path = f"/path/to/outputs/data_{run_id}.csv"
            logger.info(f"Přesouvám výsledky do konečného umístění: {final_path}")
            
            # Zajištění existence adresáře
            os.makedirs(os.path.dirname(final_path), exist_ok=True)
            
            # Atomický zápis pro zajištění žádných částečných souborů
            with atomic_write(final_path, overwrite=True) as f:
                with open(temp_output_path, 'r') as source:
                    shutil.copyfileobj(source, f)
            
        logger.info(f"Úkol úspěšně dokončen: {run_id}")
        return final_path
    
    except Exception as e:
        logger.error(f"Chyba v úkolu {run_id}: {str(e)}")
        # Opětovné vyhození výjimky, aby Airflow mohl zpracovat opakované pokusy
        raise

# Vytvoření úkolu
safe_process_task = PythonOperator(
    task_id='safe_data_processing',
    python_callable=process_data_safely,
    provide_context=True,
    dag=dag,
    retries=3,
    retry_delay=timedelta(minutes=5)
)
```

## Porovnání Airflow a Luigi

| Funkce | Apache Airflow | Luigi |
|---------|---------------|-------|
| **Základní koncept** | Directed Acyclic Graphs (DAG) | Závislosti úkolů |
| **UI** | Bohaté webové rozhraní s monitoringem | Jednoduchá vizualizace |
| **Plánování** | Vestavěný plánovač s různými spouštěči | Vyžadován externí plánovač |
| **Definice úkolů** | Definice úkolů a operátorů | Definice úkolů založená na třídách |
| **Řešení závislostí** | Explicitní pomocí operátorů | Definováno metodou requires() |
| **Paralelismus** | Více executorů (Local, Celery, Kubernetes) | Omezená vestavěná podpora |
| **Ekosystém** | Velký ekosystém pluginů | Menší ekosystém |
| **Použití** | Komplexní pracovní toky s potřebami monitoringu | Pipeline pro zpracování dat |

Kdy zvolit Airflow:
- Komplexní pracovní toky s propracovanými potřebami plánování
- Potřeba rozsáhlého monitoringu a vizualizace
- Integrace s více systémy a službami
- Podnikové případy použití vyžadující škálovatelnost

Kdy zvolit Luigi:
- Jednodušší pipeline pro zpracování dat
- Zaměření na řešení závislostí
- Lehká orchestrace
- Preference pro explicitní definice úkolů

```python
# Implementace ETL pipeline pro analytická data v Airflow
from airflow import DAG
from airflow.operators.python import PythonOperator
from airflow.providers.postgres.operators.postgres import PostgresOperator
from airflow.providers.amazon.aws.transfers.s3_to_redshift import S3ToRedshiftOperator
from datetime import datetime, timedelta
import pandas as pd
import boto3

default_args = {
    'owner': 'data_team',
    'depends_on_past': False,
    'start_date': datetime(2023, 1, 1),
    'email': ['data_alerts@example.com'],
    'email_on_failure': True,
    'retries': 3,
    'retry_delay': timedelta(minutes=5),
}

dag = DAG(
    'analytics_etl_pipeline',
    default_args=default_args,
    description='ETL pipeline pro analytická data',
    schedule_interval='@daily',
    catchup=False,
)

# 1. Extrakce dat z API
def extract_api_data(**context):
    execution_date = context['execution_date']
    date_str = execution_date.strftime('%Y-%m-%d')
    
    # Volání API pro získání dat
    # (používá se falešná data pro tento příklad)
    data = {
        'user_id': range(100),
        'event': ['view', 'click', 'purchase'] * 33 + ['view'],
        'timestamp': [execution_date - timedelta(minutes=i*30) for i in range(100)]
    }
    df = pd.DataFrame(data)
    
    # Uložení do CSV
    csv_path = f"/tmp/events_{date_str}.csv"
    df.to_csv(csv_path, index=False)
    
    # Uložení cesty pro další úkol
    context['ti'].xcom_push(key='events_csv_path', value=csv_path)
    return csv_path

# 2. Transformace dat
def transform_data(**context):
    ti = context['ti']
    csv_path = ti.xcom_pull(key='events_csv_path')
    
    # Načtení dat
    df = pd.read_csv(csv_path)
    
    # Transformace
    df['date'] = pd.to_datetime(df['timestamp']).dt.date
    df['hour'] = pd.to_datetime(df['timestamp']).dt.hour
    
    # Výpočet agregátů
    event_counts = df.groupby(['date', 'hour', 'event']).size().reset_index(name='count')
    
    # Uložení transformovaných dat
    transformed_path = csv_path.replace('.csv', '_transformed.csv')
    event_counts.to_csv(transformed_path, index=False)
    
    # Uložení cesty pro další úkol
    context['ti'].xcom_push(key='transformed_csv_path', value=transformed_path)
    return transformed_path

# 3. Nahrání do S3
def upload_to_s3(**context):
    ti = context['ti']
    execution_date = context['execution_date']
    date_str = execution_date.strftime('%Y-%m-%d')
    
    transformed_csv_path = ti.xcom_pull(key='transformed_csv_path')
    
    # Vytvoření S3 klienta a nahrání
    s3_client = boto3.client('s3', 
                            aws_access_key_id='VAS_KLIC',
                            aws_secret_access_key='VASE_TAJEMSTVI')
    
    s3_key = f"analytics/events/{date_str}/events_transformed.csv"
    s3_client.upload_file(transformed_csv_path, 'your-bucket-name', s3_key)
    
    # Uložení S3 cesty
    context['ti'].xcom_push(key='s3_key', value=s3_key)
    return s3_key

# Vytvoření úkolů
extract_task = PythonOperator(
    task_id='extract_api_data',
    python_callable=extract_api_data,
    provide_context=True,
    dag=dag,
)

transform_task = PythonOperator(
    task_id='transform_data',
    python_callable=transform_data,
    provide_context=True,
    dag=dag,
)

upload_s3_task = PythonOperator(
    task_id='upload_to_s3',
    python_callable=upload_to_s3,
    provide_context=True,
    dag=dag,
)

# 4. Nahrání do Redshift
copy_to_redshift_task = S3ToRedshiftOperator(
    task_id='copy_to_redshift',
    schema='analytics',
    table='events_summary',
    s3_bucket='your-bucket-name',
    s3_key="{{ ti.xcom_pull(key='s3_key') }}",
    copy_options=['CSV', 'IGNOREHEADER 1'],
    redshift_conn_id='redshift_conn',
    aws_conn_id='aws_default',
    dag=dag,
)

# Nastavení závislostí
extract_task >> transform_task >> upload_s3_task >> copy_to_redshift_task
```

```python
        X = np.random.randn(n_samples, 5)
        
        # Cílová proměnná (binární klasifikace)
        y = (X[:, 0] + X[:, 1]**2 + np.random.randn(n_samples) * 0.1) > 0
        
        # Vytvoření dataframe
        df = pd.DataFrame(X, columns=[f"feature_{i}" for i in range(5)])
        df['target'] = y.astype(int)
        
        # Uložení datasetu
        df.to_csv(self.output().path, index=False)
        print(f"Dataset vytvořen s {len(df)} vzorky")

# Úkol 2: Rozdělení datasetu
class SplitDatasetTask(MLPipelineTask):
    test_size = luigi.FloatParameter(default=0.2)
    random_state = luigi.IntParameter(default=42)
    
    def requires(self):
        return PrepareDatasetTask(data_date=self.data_date)
    
    def output(self):
        return {
            'train': luigi.LocalTarget(f"{self.data_path}/train_data.csv"),
            'test': luigi.LocalTarget(f"{self.data_path}/test_data.csv")
        }
    
    def run(self):
        self.setup_directories()
        
        # Načtení datasetu
        df = pd.read_csv(self.input().path)
        
        # Rozdělení příznaků a cílové proměnné
        X = df.drop('target', axis=1)
        y = df['target']
        
        # Rozdělení na trénovací a testovací data
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=self.test_size, random_state=self.random_state
        )
        
        # Uložení rozdělených dat
        train_df = pd.concat([X_train, y_train], axis=1)
        test_df = pd.concat([X_test, y_test], axis=1)
        
        train_df.to_csv(self.output()['train'].path, index=False)
        test_df.to_csv(self.output()['test'].path, index=False)
        
        print(f"Dataset rozdělen na {len(train_df)} trénovacích a {len(test_df)} testovacích vzorků")

# Úkol 3: Předzpracování dat
class PreprocessDataTask(MLPipelineTask):
    def requires(self):
        return SplitDatasetTask(data_date=self.data_date)
    
    def output(self):
        return {
            'train_processed': luigi.LocalTarget(f"{self.data_path}/train_processed.csv"),
            'test_processed': luigi.LocalTarget(f"{self.data_path}/test_processed.csv"),
            'scaler': luigi.LocalTarget(f"{self.model_path}/scaler.pkl")
        }
    
    def run(self):
        self.setup_directories()
        
        # Načtení datasetů
        train_df = pd.read_csv(self.input()['train'].path)
        test_df = pd.read_csv(self.input()['test'].path)
        
        # Rozdělení příznaků a cílové proměnné
        X_train = train_df.drop('target', axis=1)
        y_train = train_df['target']
        
        X_test = test_df.drop('target', axis=1)
        y_test = test_df['target']
        
        # Standardizace příznaků
        scaler = StandardScaler()
        X_train_scaled = scaler.fit_transform(X_train)
        X_test_scaled = scaler.transform(X_test)
        
        # Uložení zpracovaných dat
        train_processed = pd.DataFrame(X_train_scaled, columns=X_train.columns)
        train_processed['target'] = y_train.values
        
        test_processed = pd.DataFrame(X_test_scaled, columns=X_test.columns)
        test_processed['target'] = y_test.values
        
        train_processed.to_csv(self.output()['train_processed'].path, index=False)
        test_processed.to_csv(self.output()['test_processed'].path, index=False)
        
        # Uložení scaleru
        with open(self.output()['scaler'].path, 'wb') as f:
            pickle.dump(scaler, f)
        
        print("Předzpracování dat dokončeno")

# Úkol 4: Trénování modelu
class TrainModelTask(MLPipelineTask):
    n_estimators = luigi.IntParameter(default=100)
    
    def requires(self):
        return PreprocessDataTask(data_date=self.data_date)
    
    def output(self):
        return luigi.LocalTarget(f"{self.model_path}/random_forest_model.pkl")
    
    def run(self):
        self.setup_directories()
        
        # Načtení předzpracovaných trénovacích dat
        train_df = pd.read_csv(self.input()['train_processed'].path)
        
        # Rozdělení příznaků a cílové proměnné
        X_train = train_df.drop('target', axis=1)
        y_train = train_df['target']
        
        # Trénování modelu
        print("Trénuji model Random Forest...")
        model = RandomForestClassifier(
            n_estimators=self.n_estimators,
            random_state=42
        )
        model.fit(X_train, y_train)
        
        # Uložení modelu
        with open(self.output().path, 'wb') as f:
            pickle.dump(model, f)
        
        print(f"Trénování modelu dokončeno s {self.n_estimators} stromy")

# Úkol 5: Vyhodnocení modelu
class EvaluateModelTask(MLPipelineTask):
    def requires(self):
        return {
            'model': TrainModelTask(data_date=self.data_date),
            'data': PreprocessDataTask(data_date=self.data_date)
        }
    
    def output(self):
        return luigi.LocalTarget(f"{self.model_path}/evaluation_report.txt")
    
    def run(self):
        self.setup_directories()
        
        # Načtení modelu
        with open(self.input()['model'].path, 'rb') as f:
            model = pickle.load(f)
        
        # Načtení testovacích dat
        test_df = pd.read_csv(self.input()['data']['test_processed'].path)
        
        # Rozdělení příznaků a cílové proměnné
        X_test = test_df.drop('target', axis=1)
        y_test = test_df['target']
        
        # Predikce
        y_pred = model.predict(X_test)
        
        # Generování hodnotící zprávy
        report = classification_report(y_test, y_pred)
        feature_importances = pd.Series(
            model.feature_importances_,
            index=X_test.columns
        ).sort_values(ascending=False)
        
        # Uložení zprávy
        with self.output().open('w') as f:
            f.write("ZPRÁVA O VYHODNOCENÍ MODELU\n")
            f.write("======================\n\n")
            f.write("Klasifikační zpráva:\n")
            f.write(report)
            f.write("\n\nDůležitost příznaků:\n")
            for feature, importance in feature_importances.items():
                f.write(f"{feature}: {importance:.4f}\n")
        
        print("Vyhodnocení modelu dokončeno")

# Hlavní úkol pipeline
class MLPipeline(luigi.WrapperTask):
    data_date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return EvaluateModelTask(data_date=self.data_date)

if __name__ == "__main__":
    luigi.build([MLPipeline()], local_scheduler=True)
```
