## 1. Introduction to Data Cleaning

Data cleaning, also known as data cleansing, is the process of identifying and correcting (or removing) errors, inconsistencies, and inaccuracies in datasets. Clean data is essential for accurate analysis and effective machine learning models. Common issues that require cleaning include missing values, duplicates, outliers, inconsistent formats, and incorrect data types.

```python
# Import essential libraries for data cleaning

import matplotlib.pyplot as plt

# Create a sample "messy" dataset to demonstrate cleaning techniques

    'customer_id': [1001, 1002, 1003, 1004, 1005, 1005, None, 1007, 1008, 1009],
    'name': ['John Smith', 'Jane Doe', 'Robert Johnson', 'Lisa Brown', 'Michael Davis', 'Michael Davis', 'Sarah Wilson', 'James Miller', 'Patricia Moore', 'ROBERT TAYLOR'],
```

## 2. Identifying Missing Values

The first step in data cleaning is to identify missing values. Missing values can occur for various reasons, such as data entry errors, system failures, or simply because the information wasn't available.

```python
# Check for missing values in the dataset
print("Missing values per column:")
print(df.isnull().sum())

# Visualize missing values
plt.figure(figsize=(10, 6))
sns.heatmap(df.isnull(), cbar=False, cmap='viridis', yticklabels=False)
plt.title('Missing Values Heatmap')
plt.tight_layout()
plt.show()

# Calculate percentage of missing values per column
missing_percentage = (df.isnull().sum() / len(df)) * 100
print("\nMissing values percentage per column:")
print(missing_percentage)

# Identify columns with missing values above a threshold
missing_threshold = 30  # 30% threshold
columns_to_check = missing_percentage[missing_percentage > missing_threshold].index
print(f"\nColumns with more than {missing_threshold}% missing values:")
print(columns_to_check.tolist())

# Check for implicit missing values (like placeholders)
missing_placeholders = ['na', 'n/a', 'not available', 'unknown', '-999']
for column in df.columns:
    if df[column].dtype == 'object':
        placeholder_count = df[column].str.lower().isin([p.lower() for p in missing_placeholders]).sum()
        if placeholder_count > 0:
            print(f"\nColumn '{column}' has {placeholder_count} potential missing value placeholders")
```

## 3. Handling Missing Values

After identifying missing values, there are several strategies to handle them:
- Delete rows with missing values
- Delete columns with too many missing values
- Impute missing values (with mean, median, mode, or predicted values)
- Keep the missing values if the algorithm can handle them

```python
# Create a copy of the dataframe to avoid modifying the original
df_clean = df.copy()

# 1. Drop rows with missing values
df_drop_rows = df.dropna()
print("After dropping rows with missing values:")
print(f"Original shape: {df.shape}, New shape: {df_drop_rows.shape}")

# 2. Drop columns with too many missing values (e.g., > 50%)
df_drop_cols = df.dropna(axis=1, thresh=len(df) * 0.5)
print("\nAfter dropping columns with >50% missing values:")
print(f"Original shape: {df.shape}, New shape: {df_drop_cols.shape}")

# 3. Fill missing values with mean, median, or mode
# For numeric columns: use mean or median
df_clean['age'] = df_clean['age'].replace(-999, np.nan)  # Replace placeholder with NaN
df_clean['age'] = pd.to_numeric(df_clean['age'], errors='coerce')  # Convert to numeric
df_clean['age'] = df_clean['age'].fillna(df_clean['age'].median())

# For categorical columns: use mode
df_clean['customer_id'] = df_clean['customer_id'].fillna(df_clean['customer_id'].mode()[0])

# For text columns: use a placeholder or most common value
df_clean['income'] = df_clean['income'].fillna("Unknown")

# 4. Forward fill or backward fill (for time series or ordered data)
df_clean['purchase_date'] = df_clean['purchase_date'].replace('Not Available', np.nan)
df_clean['purchase_date'] = df_clean['purchase_date'].fillna(method='ffill')  # forward fill

print("\nAfter handling missing values:")
print(df_clean[['age', 'customer_id', 'income', 'purchase_date']].head(10))

# 5. Advanced: Impute missing values using KNN or other models
from sklearn.impute import KNNImputer, SimpleImputer

# For demonstration, we'll convert age to numeric and impute
numeric_df = df_clean[['age']].copy()
imputer = KNNImputer(n_neighbors=3)
numeric_df_imputed = imputer.fit_transform(numeric_df)
print("\nAfter KNN imputation of age:")
print(numeric_df_imputed)
```

## 4. Removing Duplicates

Duplicate records can skew analysis and modeling results. Identifying and removing duplicates is an important data cleaning step.

```python
# Check for duplicate rows
duplicate_rows = df.duplicated()
print(f"Number of duplicate rows: {duplicate_rows.sum()}")

# Display duplicate rows
print("\nDuplicate rows:")
print(df[duplicate_rows])

# Remove duplicate rows and keep the first occurrence
df_clean = df.drop_duplicates()
print(f"\nDataset shape after removing duplicates: {df_clean.shape}")

# Remove duplicates based on specific columns
df_clean = df.drop_duplicates(subset=['customer_id', 'name'], keep='first')
print(f"Dataset shape after removing duplicates based on customer_id and name: {df_clean.shape}")

# Check for duplicates in specific columns
print("\nDuplicate customer IDs:")
print(df_clean['customer_id'].value_counts()[df_clean['customer_id'].value_counts() > 1])

# Advanced: Fuzzy matching to identify near-duplicates in string columns
from fuzzywuzzy import fuzz

def find_fuzzy_duplicates(df, column, threshold=80):
    potential_duplicates = []
    values = df[column].dropna().tolist()
    
    for i in range(len(values)):
        for j in range(i+1, len(values)):
            similarity = fuzz.ratio(str(values[i]).lower(), str(values[j]).lower())
            if similarity >= threshold:
                potential_duplicates.append((values[i], values[j], similarity))
    
    return potential_duplicates

# Find potential duplicate names using fuzzy matching
fuzzy_duplicates = find_fuzzy_duplicates(df_clean, 'name', threshold=80)
print("\nPotential duplicate names (fuzzy matching):")
for item in fuzzy_duplicates:
    print(f"{item[0]} and {item[1]} - Similarity: {item[2]}%")
```

## 5. Handling Outliers

Outliers are data points that differ significantly from other observations. They can be legitimate extreme values or the result of data entry errors.

```python
# Create a copy of the dataframe to work with
df_clean = df.copy()

# Convert age column to numeric
df_clean['age'] = pd.to_numeric(df_clean['age'], errors='coerce')
df_clean['age'] = df_clean['age'].replace(-999, np.nan)  # Replace placeholder with NaN

# Identify outliers using statistical methods
def find_outliers_iqr(data):
    q1 = data.quantile(0.25)
    q3 = data.quantile(0.75)
    iqr = q3 - q1
    lower_bound = q1 - (1.5 * iqr)
    upper_bound = q3 + (1.5 * iqr)
    outliers = (data < lower_bound) | (data > upper_bound)
    return outliers, lower_bound, upper_bound

# Find outliers in age
outliers_age, lower_bound, upper_bound = find_outliers_iqr(df_clean['age'])
print(f"Age outliers: {outliers_age.sum()} points")
print(f"Age boundaries: {lower_bound} to {upper_bound}")
print("Outlier values in age:")
print(df_clean.loc[outliers_age, 'age'])

# Visualize outliers with a box plot
plt.figure(figsize=(10, 6))
sns.boxplot(x=df_clean['age'])
plt.title('Age Distribution with Outliers')
plt.tight_layout()
plt.show()

# Handle outliers by capping
def cap_outliers(data, lower_bound, upper_bound):
    data_capped = data.copy()
    data_capped[data_capped < lower_bound] = lower_bound
    data_capped[data_capped > upper_bound] = upper_bound
    return data_capped

# Cap age outliers
df_clean['age_capped'] = cap_outliers(df_clean['age'], lower_bound, upper_bound)
print("\nOriginal vs. Capped ages:")
print(pd.DataFrame({
    'Original': df_clean['age'],
    'Capped': df_clean['age_capped']
}))

# Handle outliers by removing
df_no_outliers = df_clean[~outliers_age]
print(f"\nDataset shape after removing outliers: {df_no_outliers.shape}")

# Advanced: Using Z-score for outlier detection
from scipy import stats

# Calculate Z-scores for age
z_scores = stats.zscore(df_clean['age'].dropna())
abs_z_scores = np.abs(z_scores)
outliers_z = abs_z_scores > 3  # Using threshold of 3 standard deviations
print(f"\nOutliers using Z-score: {outliers_z.sum()} points")
```

## 6. String Manipulation and Text Cleaning

Text data often requires cleaning to ensure consistency. This includes handling case sensitivity, removing extra spaces, and standardizing formats.

```python
# Text cleaning methods for the name and is_member columns
df_clean = df.copy()

# Standardize text case
df_clean['name'] = df_clean['name'].str.title()  # Convert to title case
print("Names after standardizing case:")
print(df_clean['name'])

# Strip leading/trailing whitespace
df_clean['name'] = df_clean['name'].str.strip()

# Standardize formats (e.g., membership status)
# Convert various yes/no formats to boolean
yes_values = ['yes', 'y', 'true', '1']
no_values = ['no', 'n', 'false', '0']

df_clean['is_member_clean'] = df_clean['is_member'].str.lower()
df_clean.loc[df_clean['is_member_clean'].isin(yes_values), 'is_member_clean'] = True
df_clean.loc[df_clean['is_member_clean'].isin(no_values), 'is_member_clean'] = False

print("\nStandardized membership status:")
print(pd.DataFrame({
    'Original': df_clean['is_member'],
    'Cleaned': df_clean['is_member_clean']
}))

# Format dates consistently
def standardize_date(date_str):
    if pd.isna(date_str) or date_str == 'Not Available':
        return np.nan
    
    # Try different date formats
    formats = ['%Y-%m-%d', '%m/%d/%Y', '%m-%d-%Y']
    for fmt in formats:
        try:
            return pd.to_datetime(date_str, format=fmt).strftime('%Y-%m-%d')
        except:
            continue
    return date_str

df_clean['purchase_date_clean'] = df_clean['purchase_date'].apply(standardize_date)
print("\nStandardized dates:")
print(pd.DataFrame({
    'Original': df_clean['purchase_date'],
    'Cleaned': df_clean['purchase_date_clean']
}))

# Clean currency values
def clean_currency(value):
    if pd.isna(value):
        return np.nan
    return float(str(value).replace('$', '').replace(',', ''))

df_clean['income_clean'] = df_clean['income'].apply(clean_currency)
print("\nCleaned income values:")
print(pd.DataFrame({
    'Original': df_clean['income'],
    'Cleaned': df_clean['income_clean']
}))
```

## 7. Data Type Conversion

Ensuring that each column has the appropriate data type is crucial for proper analysis and to avoid errors in calculations or functions.

```python
df_clean = df.copy()

# Display current data types
print("Original data types:")
print(df_clean.dtypes)

# Convert customer_id to integer
df_clean['customer_id'] = pd.to_numeric(df_clean['customer_id'], errors='coerce')

# Convert age to integer (after handling missing values)
df_clean['age'] = pd.to_numeric(df_clean['age'], errors='coerce').fillna(-1).astype(int)
df_clean.loc[df_clean['age'] == -1, 'age'] = np.nan  # Convert placeholder back to NaN

# Convert income to numeric (after removing $ and commas)
df_clean['income'] = df_clean['income'].str.replace('$', '').str.replace(',', '')
df_clean['income'] = pd.to_numeric(df_clean['income'], errors='coerce')

# Convert purchase_date to datetime
df_clean['purchase_date'] = pd.to_datetime(df_clean['purchase_date'], errors='coerce',
                                         format='mixed')

# Convert is_member to boolean
yes_values = ['yes', 'y', 'true', '1']
df_clean['is_member'] = df_clean['is_member'].str.lower().isin(yes_values)

print("\nCleaned data types:")
print(df_clean.dtypes)
print("\nCleaned dataframe head:")
print(df_clean.head())

# Check for conversion issues
print("\nAny remaining non-numeric values in age:", 
      df_clean['age'].map(type).map(lambda t: t != int and t != float).any())
```

## 8. Standardizing and Normalizing Data

Standardization and normalization are techniques used to scale numeric variables to a similar range, which is important for many machine learning algorithms.

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# Create sample numeric data
df_numeric = pd.DataFrame({
    'income': [45000, 62000, 55000, 0, 72000, 72000, 61000, 42000, 82000, 76000],
    'age': [28, 34, 40, 41, 22, 22, 35, 39, 45, 36]
})

# Standardization (Z-score normalization)
# Transforms data to have a mean of 0 and a standard deviation of 1
scaler = StandardScaler()
df_standardized = pd.DataFrame(
    scaler.fit_transform(df_numeric),
    columns=df_numeric.columns
)

print("Original data:")
print(df_numeric.describe())
print("\nStandardized data:")
print(df_standardized.describe())

# Min-Max scaling
# Transforms data to range from 0 to 1
min_max_scaler = MinMaxScaler()
df_normalized = pd.DataFrame(
    min_max_scaler.fit_transform(df_numeric),
    columns=df_numeric.columns
)

print("\nNormalized data (Min-Max):")
print(df_normalized.describe())

# Visualize the effect of scaling
plt.figure(figsize=(15, 5))

plt.subplot(1, 3, 1)
plt.scatter(df_numeric['age'], df_numeric['income'])
plt.title('Original Data')
plt.xlabel('Age')
plt.ylabel('Income')

plt.subplot(1, 3, 2)
plt.scatter(df_standardized['age'], df_standardized['income'])
plt.title('Standardized Data')
plt.xlabel('Age (z-score)')
plt.ylabel('Income (z-score)')

plt.subplot(1, 3, 3)

plt.title('Normalized Data (Min-Max)')
plt.xlabel('Age (0-1)')
plt.ylabel('Income (0-1)')

plt.tight_layout()
plt.show()

# Example: Standardizing only specific columns in a mixed dataframe
df_mixed = df_clean.copy()
numeric_cols = df_mixed.select_dtypes(include=[np.number]).columns.tolist()
df_mixed[numeric_cols] = StandardScaler().fit_transform(df_mixed[numeric_cols].fillna(0))

print(df_mixed[numeric_cols].describe())
```

## 9. Data Validation

Data validation ensures that your cleaned data meets the required standards for analysis. This involves checking for logical consistency, value ranges, and relationship rules.

```python
df_clean = df.copy()

# Validate data types
def validate_types(df, type_dict):
    issues = []
    for column, expected_type in type_dict.items():
        if column not in df.columns:
            issues.append(f"Column '{column}' not found in dataframe")
            continue
            
        # Convert to the expected type and check for errors
        try:
            if expected_type == 'numeric':
                pd.to_numeric(df[column], errors='raise')
            elif expected_type == 'datetime':
                pd.to_datetime(df[column], errors='raise')
            elif expected_type == 'boolean':
                df[column].astype(bool)
            else:
                df[column].astype(expected_type)
        except Exception as e:
            issues.append(f"Column '{column}' has type issues: {e}")
    
    return issues

# Define expected types
type_expectations = {
    'customer_id': 'numeric',
    'age': 'numeric',
    'purchase_date': 'datetime',
    'is_member': 'boolean'
}

type_issues = validate_types(df_clean, type_expectations)
print("Type validation issues:")
for issue in type_issues:
    print(f"- {issue}")

# Validate value ranges
def validate_ranges(df, range_dict):
    issues = []
    for column, (min_val, max_val) in range_dict.items():
        if column not in df.columns:
            issues.append(f"Column '{column}' not found in dataframe")
            continue
            
        # Check if values are within range
        try:
            # Convert to numeric for comparison
            col_vals = pd.to_numeric(df[column], errors='coerce')
            out_of_range = df.loc[(col_vals < min_val) | (col_vals > max_val), column]
            if not out_of_range.empty:
                issues.append(f"Column '{column}' has {len(out_of_range)} values outside range {min_val}-{max_val}")
        except Exception as e:
            issues.append(f"Error validating range for '{column}': {e}")
    
    return issues

# Define expected ranges
range_expectations = {
    'age': (0, 120),  # Reasonable age range
    'income': (0, 1000000)  # Reasonable income range
}

range_issues = validate_ranges(df_clean, range_expectations)
print("\nRange validation issues:")
for issue in range_issues:
    print(f"- {issue}")

# Validate logical relationships
def validate_relationships(df, rules):
    issues = []
    for rule_name, rule_func in rules.items():
        try:
            valid = rule_func(df)
            if not valid:
                issues.append(f"Rule '{rule_name}' violated")
        except Exception as e:
            issues.append(f"Error checking rule '{rule_name}': {e}")
    
    return issues

# Define relationship rules
def purchase_date_not_future(df):
    if 'purchase_date' not in df.columns:
        return True
    dates = pd.to_datetime(df['purchase_date'], errors='coerce')
    today = pd.Timestamp.today()
    return not (dates > today).any()

relationship_rules = {
    'purchase_date_not_in_future': purchase_date_not_future
}

relationship_issues = validate_relationships(df_clean, relationship_rules)
print("\nRelationship validation issues:")
for issue in relationship_issues:
    print(f"- {issue}")
```

## 10. Summary

Data cleaning is a critical and often time-consuming part of any data science project. This guide covered the essential techniques:

1. **Identifying Missing Values**: Using methods like `isnull()` to find missing data in your dataset.
2. **Handling Missing Values**: Multiple strategies including dropping rows/columns, imputation with mean/median/mode, or advanced methods like KNN imputation.
3. **Removing Duplicates**: Detecting and eliminating identical or nearly identical records to prevent bias.
4. **Handling Outliers**: Methods to identify and deal with extreme values using IQR, Z-scores, or capping.
5. **String Manipulation**: Standardizing text data by handling case, spaces, and formats.
6. **Data Type Conversion**: Ensuring each column has the appropriate data type for analysis.
7. **Standardizing and Normalizing**: Scaling numerical data using standardization or min-max normalization.
8. **Data Validation**: Verifying that your cleaned data meets expectations for types, ranges, and logical relationships.

The data cleaning process is iterative and often requires going back and forth between steps as you uncover more issues. Properly cleaned data forms the foundation for accurate analysis, visualization, and modeling in data science projects.

Good data cleaning practices include:
- Documenting all cleaning steps and decisions
- Creating reusable cleaning pipelines for similar datasets
- Validating results after each major cleaning step
- Backing up your raw data before cleaning

Remember that the specific cleaning techniques will vary depending on your dataset and the requirements of your analysis or model.
