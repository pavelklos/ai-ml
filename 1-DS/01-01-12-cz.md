## 1. Co jsou Jupyter Notebooks?

Jupyter Notebooks jsou interaktivní webové výpočetní prostředí, které umožňují vytvářet a sdílet dokumenty obsahující živý kód, rovnice, vizualizace a popisný text. Staly se nezbytným nástrojem pro datové vědce, protože umožňují iterativní, explorativní přístup k analýze dat a usnadňují sdílení výsledků s ostatními.

Klíčové vlastnosti Jupyter Notebooks:

- **Interaktivní výpočty**: Spouštění bloků kódu a okamžité zobrazení výsledků
- **Smíšený obsah**: Kombinace kódu, textu, rovnic a vizualizací v jediném dokumentu
- **Jazyková flexibilita**: Podpora pro Python, R, Julii a mnoho dalších jazyků
- **Sdílitelný formát**: Snadné sdílení s kolegy nebo publikování online
- **Bohatý výstup**: Zobrazení různých typů výstupů včetně grafů, tabulek a interaktivních widgetů

```python
# Toto je vaše první buňka s kódem v Jupyter notebooku!
print("Hello, Jupyter!")

# Můžete spouštět jednoduché výpočty
result = 5 * 10
print(f"5 × 10 = {result}")

# Nebo importovat knihovny a používat je
import numpy as np
numbers = np.array([1, 2, 3, 4, 5])
print(f"Pole: {numbers}")
print(f"Průměr: {np.mean(numbers)}")
```

## 3. Rozhraní a navigace v Notebooku

Když spustíte Jupyter Notebook, otevře se ve vašem webovém prohlížeči s rozhraním pro procházení souborů.

- **Notebook Dashboard**: Zobrazuje soubory a složky v aktuálním adresáři
- **Nástrojová lišta**: Obsahuje tlačítka pro běžné operace jako ukládání, vytváření buněk atd.
- **Menu**: Poskytuje přístup k různým funkcím uspořádaným podle kategorie
- **Buňky**: Jednotlivé bloky, které obsahují kód nebo text
- **Jádro**: Výpočetní engine, který spouští kód

```python
# Můžete zkontrolovat informace o vašem aktuálním notebooku
import os
import platform

print(f"Operační systém: {platform.system()} {platform.release()}")
print(f"Aktuální pracovní adresář: {os.getcwd()}")

# Výpis souborů v aktuálním adresáři
files = os.listdir('.')
print(f"Soubory v tomto adresáři: {files[:5] if len(files) > 5 else files}")
```

## 4. Práce s buňkami

Jupyter notebooky se skládají z buněk, které mohou obsahovat kód nebo text. Existují tři hlavní typy buněk:

- **Kódové buňky**: Obsahují spustitelný kód
- **Markdown buňky**: Obsahují formátovaný text s použitím syntaxe Markdown
- **Raw buňky**: Obsahují neformátovaný text, který není notebookem zpracován

Buňky můžete přidávat, mazat, přesouvat nebo měnit jejich typ pomocí nástrojové lišty nebo klávesových zkratek.

Běžné klávesové zkratky:
- `Shift + Enter`: Spustí aktuální buňku a přesune se na další
- `Ctrl + Enter`: Spustí aktuální buňku a zůstane na ní
- `Alt + Enter`: Spustí aktuální buňku a vloží novou buňku pod ní
- `Esc + A`: Vloží buňku nad
- `Esc + B`: Vloží buňku pod
- `Esc + M`: Změní typ buňky na Markdown
- `Esc + Y`: Změní typ buňky na kód

```python
# Toto je buňka s kódem
# Zkuste spustit jednoduchý výpočet
import time

start_time = time.time()
result = sum(range(1, 1000001))
end_time = time.time()

print(f"Součet celých čísel od 1 do 1 000 000: {result}")
print(f"Výpočet trval {end_time - start_time:.4f} sekund")

# Můžete přiřazovat proměnné a používat je v následujících buňkách
data_size = 1000000
```

## 5. Spouštění kódu a správa jádra

Jádro (kernel) je výpočetní engine, který spouští kód ve vašem notebooku. Pochopení správy jádra je důležité pro efektivní práci:

- **Stav jádra**: Proměnné přetrvávají mezi buňkami, dokud jádro běží
- **Restart jádra**: Vymaže všechny proměnné a stavy
- **Přerušení jádra**: Zastaví dlouho běžící operaci
- **Spustit vše**: Spustí všechny buňky v sekvenci

```python
# Definice proměnné
x = 42

# Vytvoření funkce
def square(number):
    return number ** 2

# Tato funkce bude dostupná v jiných buňkách, dokud jádro běží
```

```python
# V nové buňce můžete používat dříve definované proměnné a funkce
print(f"x = {x}")
print(f"x na druhou = {square(x)}")

# Můžete zkontrolovat proměnné ve vaší aktuální relaci
import whos as who_var
who_var

# Pokud restartujete jádro, všechny tyto proměnné budou vymazány
```

## 6. Magické příkazy

Magické příkazy jsou speciální příkazy s prefixem `%` (řádkové magické příkazy) nebo `%%` (buňkové magické příkazy), které poskytují v Jupyter noteboocích další funkcionalitu.

```python
# Řádkové magické příkazy (s prefixem %)
%time sum(range(1000000))  # Změří čas provedení jednoho příkazu

# Vypíše všechny dostupné magické příkazy
%lsmagic

# Operace s adresáři
%pwd  # Vypíše pracovní adresář
%ls   # Vypíše soubory

# Externí systémové příkazy
!echo "Hello from the command line"
!python --version

# Měření času provedení
%%time
import numpy as np
large_array = np.random.random((1000, 1000))
result = np.dot(large_array, large_array)
```

## 8. Vizualizace dat v Noteboocích

Jupyter notebooky vynikají v integraci vizualizací přímo do vašeho analytického pracovního postupu.

```python
# Základní vizualizace s matplotlib
import matplotlib.pyplot as plt
import numpy as np
%matplotlib inline  # Tento magický příkaz zobrazí grafy přímo v notebooku

# Generování dat
x = np.linspace(0, 10, 100)
y = np.sin(x)

# Vytvoření grafu
plt.figure(figsize=(10, 6))
plt.plot(x, y, 'b-', label='sin(x)')
plt.title('Sinusová vlna')
plt.xlabel('x')
plt.ylabel('sin(x)')
plt.grid(True)
plt.legend()
plt.show()

# Interaktivní vizualizace s Plotly
import plotly.express as px

# Ukázková data
df = px.data.iris()

# Vytvoření interaktivního bodového grafu
fig = px.scatter(df, x="sepal_width", y="sepal_length", 
                 color="species", size="petal_length",
                 hover_data=["petal_width"])
fig.show()
```

## 9. Osvědčené postupy pro datovou vědu

Pro maximální využití Jupyter notebooků pro datovou vědu:

1. **Organizujte notebooky logicky**: Dodržujte jasnou strukturu vaší analýzy
2. **Dokumentujte svou práci**: Přidávejte markdown buňky vysvětlující kroky analýzy
3. **Modularizujte kód**: Vytvářejte funkce pro opakující se operace
4. **Restart a spuštění všeho**: Pravidelně testujte, že váš notebook běží od začátku do konce
5. **Verzování**: Používejte Git ke sledování změn ve vašich noteboocích
6. **Správa prostředí**: Používejte virtuální prostředí nebo conda prostředí

```python
# Příklad modulárního kódu v noteboocích

def load_data(filepath):
    """Načte data z CSV souboru."""
    import pandas as pd
    return pd.read_csv(filepath)

def preprocess_data(df):
    """Předzpracuje dataframe."""
    # Zpracování chybějících hodnot
    df = df.fillna(df.mean())
    # Normalizace numerických prvků
    from sklearn.preprocessing import StandardScaler
    scaler = StandardScaler()
    num_columns = df.select_dtypes(include=['float64', 'int64']).columns
    df[num_columns] = scaler.fit_transform(df[num_columns])
    return df

def visualize_data(df, x_col, y_col, color_col=None):
    """Vytvoří bodový graf dat."""
    import matplotlib.pyplot as plt
    plt.figure(figsize=(10, 6))
    if color_col:
        for color in df[color_col].unique():
            subset = df[df[color_col] == color]
            plt.scatter(subset[x_col], subset[y_col], label=color)
        plt.legend()
    else:
        plt.scatter(df[x_col], df[y_col])
    plt.xlabel(x_col)
    plt.ylabel(y_col)
    plt.title(f'{y_col} vs {x_col}')
    plt.grid(True)
    plt.show()
```

## 10. Shrnutí

Jupyter notebooky způsobily revoluci v datové vědě tím, že poskytují interaktivní výpočetní prostředí, kde kód, vizualizace a popisný text mohou koexistovat v jediném dokumentu. Klíčové poznatky:

- Jupyter notebooky kombinují spouštění kódu, formátovaný text a vizualizace v jednom dokumentu
- Struktura založená na buňkách umožňuje iterativní, explorativní analýzu dat
- Kódové buňky spouštějí Python (nebo jiné jazyky) s okamžitou zpětnou vazbou
- Markdown buňky umožňují dokumentaci a vysvětlení
- Magické příkazy poskytují speciální funkcionalitu pro notebooky
- Vizualizace se integrují přímo do vašeho pracovního postupu
- Notebooky lze sdílet, převádět do jiných formátů nebo nasadit jako aplikace

Jupyter notebooky jsou obzvláště cenné pro:
- Explorativní analýzu dat
- Čištění a transformaci dat
- Prototypování modelů
- Vytváření reprodukovatelného výzkumu
- Výuku a učení se datové vědy
- Sdílení výsledků analýzy s technickými i netechnickými publikem

Zvládnutím Jupyter notebooků výrazně vylepšíte svůj pracovní postup v datové vědě, což jej učiní produktivnějším, více spolupracujícím a reprodukovatelnějším.
