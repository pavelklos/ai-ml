## 1. Úvod do filtrování a výběru dat

Filtrování a výběr dat jsou základní operace při analýze dat, které vám umožňují zaměřit se na specifické podmnožiny vašich dat. Tyto techniky vám pomohou extrahovat smysluplné informace a mohou výrazně snížit složitost velkých datasetů. V pandas existuje několik způsobů, jak filtrovat a vybírat data z DataFrame.

```python
# Import potřebných knihoven
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Vytvoření vzorového datasetu
data = {
    'Name': ['John', 'Anna', 'Peter', 'Linda', 'Bob', 'Mary', 'Chris', 'David'],
    'Age': [28, 34, 29, 42, 35, 31, 27, 40],
    'City': ['New York', 'Los Angeles', 'Chicago', 'Boston', 'New York', 'Chicago', 'Boston', 'Los Angeles'],
    'Salary': [65000, 72000, 59000, 82000, 68000, 61000, 55000, 78000],
    'Experience': [3, 6, 2, 9, 5, 4, 2, 7],
    'Department': ['Sales', 'HR', 'Marketing', 'IT', 'Sales', 'Marketing', 'IT', 'HR']
}

# Vytvoření DataFrame
df = pd.DataFrame(data)
print("Původní DataFrame:")
print(df)
```

## 2. Základní metody výběru DataFrame

Nejzákladnější operace výběru v pandas vám umožňují vybírat sloupce, řádky nebo jednotlivé buňky z DataFrame.

```python
# Výběr jednoho sloupce (vrací Series)
age_column = df['Age']
print("\nSloupec Age:")
print(age_column)

# Výběr více sloupců (vrací DataFrame)
subset = df[['Name', 'City', 'Salary']]
print("\nPodmnožina sloupců:")
print(subset)

# Výběr řádků podle pozice pomocí řezů (vrací DataFrame)
first_three_rows = df[:3]
print("\nPrvní tři řádky:")
print(first_three_rows)

# Výběr konkrétního řádku (vrací Series)
second_row = df.iloc[1]
print("\nDruhý řádek:")
print(second_row)

# Výběr konkrétní hodnoty buňky
specific_cell = df.iloc[2, 1]  # Hodnota na řádku 2, sloupci 1 (indexováno od 0)
print(f"\nHodnota na řádku 2, sloupci 1: {specific_cell}")
```

## 3. Filtrování pomocí booleovského indexování

Booleovské indexování je výkonná funkce, která vám umožňuje filtrovat data na základě podmínek. Vytvoříte booleovskou masku (Series hodnot True/False) a použijete ji k filtrování vašeho DataFrame.

```python
# Vytvoření booleovské masky pro filtrování
mask = df['Age'] > 35
print("\nBooleovská maska pro Age > 35:")
print(mask)

# Aplikace masky pro filtrování DataFrame
filtered_df = df[mask]
print("\nFiltrovaný DataFrame (Age > 35):")
print(filtered_df)

# Filtrování v jednom řádku
high_salary = df[df['Salary'] > 70000]
print("\nZaměstnanci s platem > 70000:")
print(high_salary)

# Filtrování na základě kategoriálních dat
sales_dept = df[df['Department'] == 'Sales']
print("\nZaměstnanci v oddělení Sales:")
print(sales_dept)

# Použití .isin() pro filtrování s více hodnotami
selected_cities = df[df['City'].isin(['New York', 'Boston'])]
print("\nZaměstnanci z New Yorku nebo Bostonu:")
print(selected_cities)

# Použití metod .str pro filtrování textu
starts_with_m = df[df['Department'].str.startswith('M')]
print("\nOddělení začínající na 'M':")
print(starts_with_m)
```

## 4. Použití .loc a .iloc pro výběr

Metody `.loc` a `.iloc` poskytují přesnější způsob výběru dat:
- `.loc`: Výběr založený na názvech (používá názvy řádků/sloupců)
- `.iloc`: Výběr založený na pozici (používá číselné indexy)

```python
# Použití .loc s popisky řádků a názvy sloupců
# V tomto případě jsou popisky řádků výchozí celočíselné indexy
subset_loc = df.loc[2:4, ['Name', 'Age', 'Department']]
print("\nPoužití .loc pro výběr řádků 2-4 se specifickými sloupci:")
print(subset_loc)

# Použití .iloc s celočíselnými pozicemi
subset_iloc = df.iloc[1:5, [0, 2, 4]]  # Řádky 1-4, sloupce 0, 2, 4
print("\nPoužití .iloc s celočíselnými pozicemi:")
print(subset_iloc)

# Výběr jedné hodnoty pomocí .loc
value_loc = df.loc[3, 'City']
print(f"\nMěsto osoby na indexu 3: {value_loc}")

# Výběr jedné hodnoty pomocí .iloc
value_iloc = df.iloc[3, 2]
print(f"\nHodnota na řádku 3, sloupci 2: {value_iloc}")

# Nastavení indexu na sloupec pro lepší demonstraci .loc
df_indexed = df.set_index('Name')
print("\nDataFrame s Name jako indexem:")
print(df_indexed)

# Nyní může .loc vybírat podle jména osoby
anna_data = df_indexed.loc['Anna']
print("\nData Anny pomocí .loc:")
print(anna_data)

# Reset indexu zpět na výchozí
df_indexed = df_indexed.reset_index()
```

## 5. Kombinování více podmínek

Můžete kombinovat více filtrovacích podmínek pomocí logických operátorů (`&` pro AND, `|` pro OR, `~` pro NOT).

```python
# Podmínka AND: Age > 30 A Salary > 70000
condition1 = (df['Age'] > 30) & (df['Salary'] > 70000)
result1 = df[condition1]
print("\nZaměstnanci nad 30 let s platem > 70000:")
print(result1)

# Podmínka OR: Department je Sales NEBO HR
condition2 = (df['Department'] == 'Sales') | (df['Department'] == 'HR')
result2 = df[condition2]
print("\nZaměstnanci v Sales nebo HR:")
print(result2)

# Podmínka NOT: Není v New Yorku
condition3 = ~(df['City'] == 'New York')
result3 = df[condition3]
print("\nZaměstnanci, kteří nejsou v New Yorku:")
print(result3)

# Komplexní podmínka: Věk mezi 30-40 A zkušenosti > 5
condition4 = (df['Age'].between(30, 40)) & (df['Experience'] > 5)
result4 = df[condition4]
print("\nZaměstnanci ve věku 30-40 se zkušenostmi > 5:")
print(result4)
```

## 6. Práce s textovými daty

Pandas poskytuje výkonné metody pro filtrování textových dat prostřednictvím přístupu `.str`.

```python
# Filtrování jmen, která obsahují písmeno 'a'
contains_a = df[df['Name'].str.contains('a')]
print("\nJména obsahující 'a':")
print(contains_a)

# Filtrování bez rozlišení velkých a malých písmen
contains_A = df[df['Name'].str.contains('A', case=False)]
print("\nJména obsahující 'A' nebo 'a' (bez rozlišení velkých a malých písmen):")
print(contains_A)

# Filtrování pomocí regulárních výrazů
import re
pattern = r'^[JM]'  # Jména začínající na J nebo M
regex_filter = df[df['Name'].str.match(pattern)]
print("\nJména začínající na J nebo M:")
print(regex_filter)

# Filtrování podle délky řetězce
long_city_names = df[df['City'].str.len() > 8]
print("\nZaměstnanci z měst s délkou názvu více než 8 znaků:")
print(long_city_names)

# Nahrazování hodnot v textových sloupcích a následné filtrování
df_temp = df.copy()
df_temp['Department'] = df_temp['Department'].str.replace('HR', 'Human Resources')
hr_dept = df_temp[df_temp['Department'] == 'Human Resources']
print("\nZaměstnanci v Human Resources (po nahrazení):")
print(hr_dept)
```

## 7. Pokročilé techniky filtrování

Kromě základního filtrování nabízí pandas pokročilejší metody pro výběr a filtrování dat.

```python
# Filtrování na základě vlastností indexu
df_indexed = df.set_index('Name')
first_half_alphabet = df_indexed[df_indexed.index.str[0] <= 'M']
print("\nZaměstnanci se jmény v první polovině abecedy:")
print(first_half_alphabet.reset_index())

# Získání N nejvyšších hodnot podle sloupce
top_3_salaries = df.nlargest(3, 'Salary')
print("\n3 nejvyšší platy:")
print(top_3_salaries)

# Získání N nejnižších hodnot podle sloupce
bottom_3_experience = df.nsmallest(3, 'Experience')
print("\n3 nejnižší podle zkušeností:")
print(bottom_3_experience)

# Filtrování řádků, kde alespoň jeden sloupec obsahuje NaN (nejprve přidání nějakých hodnot NaN)
df_with_nan = df.copy()
df_with_nan.loc[1, 'Experience'] = np.nan
df_with_nan.loc[3, 'Salary'] = np.nan
rows_with_nan = df_with_nan[df_with_nan.isna().any(axis=1)]
print("\nŘádky s alespoň jednou hodnotou NaN:")
print(rows_with_nan)

# Filtrování řádků na základě duplicitních hodnot
df_with_duplicates = pd.concat([df, df.iloc[:2]])  # Přidání prvních 2 řádků znovu
print("\nDataFrame s duplicitními řádky:")
print(df_with_duplicates)

# Získání pouze duplicitních řádků
duplicated_rows = df_with_duplicates[df_with_duplicates.duplicated()]
print("\nPouze duplicitní řádky:")
print(duplicated_rows)

# Získání unikátních hodnot ve sloupci
unique_departments = df['Department'].unique()
print("\nUnikátní oddělení:", unique_departments)
```

## 8. Metoda Query

Metoda `.query()` poskytuje stručnější a čitelnější způsob filtrování pandas DataFrame, zejména pro komplexní podmínky.

```python
# Základní dotaz
high_salary_query = df.query('Salary > 70000')
print("\nZaměstnanci s platem > 70000 pomocí query:")
print(high_salary_query)

# Použití proměnných v dotazu
min_age = 30
max_age = 40
age_range_query = df.query('Age >= @min_age and Age <= @max_age')
print("\nZaměstnanci ve věku 30-40 pomocí query:")
print(age_range_query)

# Kombinování podmínek pomocí query
complex_query = df.query('Experience > 5 and Department == "HR" or City == "New York"')
print("\nVýsledek komplexního dotazu:")
print(complex_query)

# Použití metod řetězce v dotazu (všimněte si zpětných apostrofů pro názvy sloupců s mezerami)
name_query = df.query('Name.str.startswith("A") or Name.str.endswith("d")')
print("\nJména, která začínají na 'A' nebo končí na 'd':")
print(name_query)

# Dotaz s operátorem IN
cities_list = ['New York', 'Boston']
city_query = df.query('City in @cities_list')
print("\nZaměstnanci v New Yorku nebo Bostonu pomocí query:")
print(city_query)
```

## 9. Výběr a transformace dat

Často budete chtít data nejen vybrat, ale také je transformovat v průběhu procesu.

```python
# Výběr a současná transformace dat
salary_in_thousands = df['Salary'] / 1000
print("\nPlaty v tisících:")
print(salary_in_thousands)

# Použití .map() pro transformaci sloupce na základě slovníku
department_code = {
    'Sales': 'S',
    'HR': 'H',
    'Marketing': 'M',
    'IT': 'I'
}
df['Dept_Code'] = df['Department'].map(department_code)
print("\nDataFrame s kódy oddělení:")
print(df)

# Použití .apply() pro transformaci dat pomocí funkce
def experience_category(years):
    if years < 3:
        return 'Junior'
    elif years < 7:
        return 'Mid-level'
    else:
        return 'Senior'

df['Experience_Level'] = df['Experience'].apply(experience_category)
print("\nDataFrame s úrovněmi zkušeností:")
print(df)

# Filtrování a následná transformace
high_earners = df[df['Salary'] > 70000].copy()
high_earners['Bonus'] = high_earners['Salary'] * 0.10
print("\nVysokopříjmoví zaměstnanci s vypočteným bonusem:")
print(high_earners)

# Použití .transform() pro aplikaci funkce, která zachovává index
mean_age_by_dept = df.groupby('Department')['Age'].transform('mean')
print("\nPrůměrný věk podle oddělení (zachovaný index):")
print(pd.DataFrame({
    'Department': df['Department'],
    'Age': df['Age'],
    'Mean Age in Department': mean_age_by_dept
}))

# Odstranění sloupců, které jsme přidali pro demonstraci
df = df.drop(['Dept_Code', 'Experience_Level'], axis=1)
```

## 10. Shrnutí

Filtrování a výběr dat jsou základními dovednostmi v datové vědě, které vám umožňují:

- Extrahovat specifické podmnožiny dat, které splňují určité podmínky
- Zaměřit vaši analýzu na relevantní informace
- Připravit data pro vizualizaci nebo modelování

Klíčové techniky popsané v této příručce zahrnují:

- Základní výběr sloupců a řádků pomocí hranatých závorek `[]`
- Booleovské indexování pro filtrování založené na podmínkách
- Použití `.loc` a `.iloc` pro přesný výběr
- Kombinování více filtračních podmínek pomocí logických operátorů (`&`, `|`, `~`)
- Filtrování založené na textu pomocí metod řetězců (`.str`)
- Pokročilé techniky jako `.nlargest()`, `.nsmallest()` a `.duplicated()`
- Metodu `.query()` pro čitelnější výrazy filtrování
- Transformaci dat při výběru pomocí `.map()`, `.apply()` a `.transform()`

Zvládnutí těchto technik výrazně zlepší vaši schopnost efektivně manipulovat a analyzovat data. Správným filtrováním dat můžete získat zaměřenější poznatky a vytvářet relevantnější vizualizace a modely.
