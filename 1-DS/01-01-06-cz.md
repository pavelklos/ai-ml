## 1. Úvod do čištění dat

Čištění dat, také známé jako vyčištění dat, je proces identifikace a opravy (nebo odstranění) chyb, nekonzistencí a nepřesností v datových souborech. Čistá data jsou nezbytná pro přesnou analýzu a efektivní strojové učení. Mezi běžné problémy, které vyžadují čištění, patří chybějící hodnoty, duplicity, odlehlé hodnoty, nekonzistentní formáty a nesprávné datové typy.

```python
# Import základních knihoven pro čištění dat
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Vytvoření ukázkového "neupraveného" datasetu pro demonstraci technik čištění
data = {
    'customer_id': [1001, 1002, 1003, 1004, 1005, 1005, None, 1007, 1008, 1009],
    'name': ['John Smith', 'Jane Doe', 'Robert Johnson', 'Lisa Brown', 'Michael Davis', 'Michael Davis', 'Sarah Wilson', 'James Miller', 'Patricia Moore', 'ROBERT TAYLOR'],
    'age': [28, 34, np.nan, 41, 22, 22, 35, np.nan, '45', -999],
    'income': ['$45,000', '$62,000', '$55,000', None, '$72,000', '$72,000', '$61,000', '$42,000', '$82,000', '$76,000'],
    'purchase_date': ['2023-01-15', '01/25/2023', '2023-02-10', '03-15-2023', '2023-04-05', '2023-04-05', '2023-04-22', 'Not Available', '2023-05-30', '2023-06-12'],
    'is_member': ['Yes', 'No', 'Y', 'N', 'yes', 'yes', 'no', 'NO', 'True', '1']
}

df = pd.DataFrame(data)
print("Původní dataset:")
print(df)

# Základní přehled datasetu
print("\nInformace o datasetu:")
df.info()

# Statistické shrnutí
print("\nStatistické shrnutí:")
print(df.describe(include='all'))
```

## 2. Identifikace chybějících hodnot

Prvním krokem při čištění dat je identifikace chybějících hodnot. Chybějící hodnoty se mohou vyskytnout z různých důvodů, jako jsou chyby při zadávání dat, selhání systému nebo prostě proto, že informace nebyla k dispozici.

```python
# Kontrola chybějících hodnot v datasetu
print("Chybějící hodnoty podle sloupců:")
print(df.isnull().sum())

# Vizualizace chybějících hodnot
plt.figure(figsize=(10, 6))
sns.heatmap(df.isnull(), cbar=False, cmap='viridis', yticklabels=False)
plt.title('Heatmapa chybějících hodnot')
plt.tight_layout()
plt.show()

# Výpočet procenta chybějících hodnot podle sloupců
missing_percentage = (df.isnull().sum() / len(df)) * 100
print("\nProcento chybějících hodnot podle sloupců:")
print(missing_percentage)

# Identifikace sloupců s chybějícími hodnotami nad určitou hranicí
missing_threshold = 30  # 30% hranice
columns_to_check = missing_percentage[missing_percentage > missing_threshold].index
print(f"\nSloupce s více než {missing_threshold}% chybějících hodnot:")
print(columns_to_check.tolist())

# Kontrola implicitně chybějících hodnot (jako jsou zástupné hodnoty)
missing_placeholders = ['na', 'n/a', 'not available', 'unknown', '-999']
for column in df.columns:
    if df[column].dtype == 'object':
        placeholder_count = df[column].str.lower().isin([p.lower() for p in missing_placeholders]).sum()
        if placeholder_count > 0:
            print(f"\nSloupec '{column}' má {placeholder_count} potenciálně chybějících hodnot (zástupné symboly)")
```

## 3. Zpracování chybějících hodnot

Po identifikaci chybějících hodnot existuje několik strategií, jak s nimi naložit:
- Odstranění řádků s chybějícími hodnotami
- Odstranění sloupců s příliš mnoha chybějícími hodnotami
- Doplnění chybějících hodnot (průměrem, mediánem, modem nebo odhadnutými hodnotami)
- Ponechání chybějících hodnot, pokud je algoritmus dokáže zpracovat

```python
# Vytvoření kopie dataframu, abychom neupravovali originál
df_clean = df.copy()

# 1. Odstranění řádků s chybějícími hodnotami
df_drop_rows = df.dropna()
print("Po odstranění řádků s chybějícími hodnotami:")
print(f"Původní tvar: {df.shape}, Nový tvar: {df_drop_rows.shape}")

# 2. Odstranění sloupců s příliš mnoha chybějícími hodnotami (např. > 50%)
df_drop_cols = df.dropna(axis=1, thresh=len(df) * 0.5)
print("\nPo odstranění sloupců s >50% chybějících hodnot:")
print(f"Původní tvar: {df.shape}, Nový tvar: {df_drop_cols.shape}")

# 3. Doplnění chybějících hodnot průměrem, mediánem nebo modem
# Pro numerické sloupce: použití průměru nebo mediánu
df_clean['age'] = df_clean['age'].replace(-999, np.nan)  # Nahrazení zástupných hodnot za NaN
df_clean['age'] = pd.to_numeric(df_clean['age'], errors='coerce')  # Převod na čísla
df_clean['age'] = df_clean['age'].fillna(df_clean['age'].median())

# Pro kategoriální sloupce: použití modu
df_clean['customer_id'] = df_clean['customer_id'].fillna(df_clean['customer_id'].mode()[0])

# Pro textové sloupce: použití zástupné hodnoty nebo nejčastější hodnoty
df_clean['income'] = df_clean['income'].fillna("Neznámý")

# 4. Dopředné nebo zpětné vyplnění (pro časové řady nebo seřazená data)
df_clean['purchase_date'] = df_clean['purchase_date'].replace('Not Available', np.nan)
df_clean['purchase_date'] = df_clean['purchase_date'].fillna(method='ffill')  # dopředné vyplnění

print("\nPo zpracování chybějících hodnot:")
print(df_clean[['age', 'customer_id', 'income', 'purchase_date']].head(10))

# 5. Pokročilé: Doplnění chybějících hodnot pomocí KNN nebo jiných modelů
from sklearn.impute import KNNImputer, SimpleImputer

# Pro demonstraci převedeme věk na číslo a doplníme chybějící hodnoty
numeric_df = df_clean[['age']].copy()
imputer = KNNImputer(n_neighbors=3)
numeric_df_imputed = imputer.fit_transform(numeric_df)
print("\nPo KNN doplnění hodnot pro věk:")
print(numeric_df_imputed)
```

## 4. Odstranění duplicit

Duplicitní záznamy mohou zkreslit výsledky analýzy a modelování. Identifikace a odstranění duplicit je důležitým krokem při čištění dat.

```python
# Kontrola duplicitních řádků
duplicate_rows = df.duplicated()
print(f"Počet duplicitních řádků: {duplicate_rows.sum()}")

# Zobrazení duplicitních řádků
print("\nDuplicitní řádky:")
print(df[duplicate_rows])

# Odstranění duplicitních řádků a ponechání prvního výskytu
df_clean = df.drop_duplicates()
print(f"\nTvar datasetu po odstranění duplicit: {df_clean.shape}")

# Odstranění duplicit na základě konkrétních sloupců
df_clean = df.drop_duplicates(subset=['customer_id', 'name'], keep='first')
print(f"Tvar datasetu po odstranění duplicit na základě customer_id a name: {df_clean.shape}")

# Kontrola duplicit v konkrétních sloupcích
print("\nDuplicitní ID zákazníků:")
print(df_clean['customer_id'].value_counts()[df_clean['customer_id'].value_counts() > 1])

# Pokročilé: Fuzzy porovnávání pro identifikaci téměř duplicitních hodnot v textových sloupcích
from fuzzywuzzy import fuzz

def find_fuzzy_duplicates(df, column, threshold=80):
    potential_duplicates = []
    values = df[column].dropna().tolist()
    
    for i in range(len(values)):
        for j in range(i+1, len(values)):
            similarity = fuzz.ratio(str(values[i]).lower(), str(values[j]).lower())
            if similarity >= threshold:
                potential_duplicates.append((values[i], values[j], similarity))
    
    return potential_duplicates

# Hledání potenciálních duplicit jmen pomocí fuzzy porovnávání
fuzzy_duplicates = find_fuzzy_duplicates(df_clean, 'name', threshold=80)
print("\nPotenciální duplicitní jména (fuzzy porovnávání):")
for item in fuzzy_duplicates:
    print(f"{item[0]} a {item[1]} - Podobnost: {item[2]}%")
```

## 5. Zpracování odlehlých hodnot

Odlehlé hodnoty jsou datové body, které se výrazně liší od ostatních pozorování. Mohou to být legitimní extrémní hodnoty nebo důsledek chyb při zadávání dat.

```python
# Vytvoření kopie dataframu pro práci
df_clean = df.copy()

# Převod sloupce věku na čísla
df_clean['age'] = pd.to_numeric(df_clean['age'], errors='coerce')
df_clean['age'] = df_clean['age'].replace(-999, np.nan)  # Nahrazení zástupné hodnoty za NaN

# Identifikace odlehlých hodnot pomocí statistických metod
def find_outliers_iqr(data):
    q1 = data.quantile(0.25)
    q3 = data.quantile(0.75)
    iqr = q3 - q1
    lower_bound = q1 - (1.5 * iqr)
    upper_bound = q3 + (1.5 * iqr)
    outliers = (data < lower_bound) | (data > upper_bound)
    return outliers, lower_bound, upper_bound

# Hledání odlehlých hodnot ve věku
outliers_age, lower_bound, upper_bound = find_outliers_iqr(df_clean['age'])
print(f"Odlehlé hodnoty věku: {outliers_age.sum()} bodů")
print(f"Hranice věku: {lower_bound} až {upper_bound}")
print("Odlehlé hodnoty ve věku:")
print(df_clean.loc[outliers_age, 'age'])

# Vizualizace odlehlých hodnot krabicovým grafem
plt.figure(figsize=(10, 6))
sns.boxplot(x=df_clean['age'])
plt.title('Distribuce věku s odlehlými hodnotami')
plt.tight_layout()
plt.show()

# Zpracování odlehlých hodnot ořezáním
def cap_outliers(data, lower_bound, upper_bound):
    data_capped = data.copy()
    data_capped[data_capped < lower_bound] = lower_bound
    data_capped[data_capped > upper_bound] = upper_bound
    return data_capped

# Oříznutí odlehlých hodnot věku
df_clean['age_capped'] = cap_outliers(df_clean['age'], lower_bound, upper_bound)
print("\nPůvodní vs. ořezané hodnoty věku:")
print(pd.DataFrame({
    'Původní': df_clean['age'],
    'Ořezané': df_clean['age_capped']
}))

# Zpracování odlehlých hodnot odstraněním
df_no_outliers = df_clean[~outliers_age]
print(f"\nTvar datasetu po odstranění odlehlých hodnot: {df_no_outliers.shape}")

# Pokročilé: Použití Z-skóre pro detekci odlehlých hodnot
from scipy import stats

# Výpočet Z-skóre pro věk
z_scores = stats.zscore(df_clean['age'].dropna())
abs_z_scores = np.abs(z_scores)
outliers_z = abs_z_scores > 3  # Použití hranice 3 směrodatných odchylek
print(f"\nOdlehlé hodnoty pomocí Z-skóre: {outliers_z.sum()} bodů")
```

## 6. Manipulace s řetězci a čištění textu

Textová data často vyžadují čištění, aby byla zajištěna konzistence. To zahrnuje zpracování velikosti písmen, odstranění nadbytečných mezer a standardizaci formátů.

```python
# Metody čištění textu pro sloupce name a is_member
df_clean = df.copy()

# Standardizace velikosti písmen
df_clean['name'] = df_clean['name'].str.title()  # Převod na formát s velkými počátečními písmeny
print("Jména po standardizaci velikosti písmen:")
print(df_clean['name'])

# Odstranění úvodních/koncových mezer
df_clean['name'] = df_clean['name'].str.strip()

# Standardizace formátů (např. stav členství)
# Převod různých formátů ano/ne na boolean
yes_values = ['yes', 'y', 'true', '1']
no_values = ['no', 'n', 'false', '0']

df_clean['is_member_clean'] = df_clean['is_member'].str.lower()
df_clean.loc[df_clean['is_member_clean'].isin(yes_values), 'is_member_clean'] = True
df_clean.loc[df_clean['is_member_clean'].isin(no_values), 'is_member_clean'] = False

print("\nStandardizovaný stav členství:")
print(pd.DataFrame({
    'Původní': df_clean['is_member'],
    'Vyčištěné': df_clean['is_member_clean']
}))

# Konzistentní formátování datumů
def standardize_date(date_str):
    if pd.isna(date_str) or date_str == 'Not Available':
        return np.nan
    
    # Zkouška různých formátů data
    formats = ['%Y-%m-%d', '%m/%d/%Y', '%m-%d-%Y']
    for fmt in formats:
        try:
            return pd.to_datetime(date_str, format=fmt).strftime('%Y-%m-%d')
        except:
            continue
    return date_str

df_clean['purchase_date_clean'] = df_clean['purchase_date'].apply(standardize_date)
print("\nStandardizovaná data:")
print(pd.DataFrame({
    'Původní': df_clean['purchase_date'],
    'Vyčištěné': df_clean['purchase_date_clean']
}))

# Čištění měnových hodnot
def clean_currency(value):
    if pd.isna(value):
        return np.nan
    return float(str(value).replace('$', '').replace(',', ''))

df_clean['income_clean'] = df_clean['income'].apply(clean_currency)
print("\nVyčištěné hodnoty příjmů:")
print(pd.DataFrame({
    'Původní': df_clean['income'],
    'Vyčištěné': df_clean['income_clean']
}))
```

## 7. Konverze datových typů

Zajištění, že každý sloupec má vhodný datový typ, je klíčové pro správnou analýzu a prevenci chyb při výpočtech nebo funkcích.

```python
df_clean = df.copy()

# Zobrazení současných datových typů
print("Původní datové typy:")
print(df_clean.dtypes)

# Převod customer_id na celé číslo
df_clean['customer_id'] = pd.to_numeric(df_clean['customer_id'], errors='coerce')

# Převod age na celé číslo (po zpracování chybějících hodnot)
df_clean['age'] = pd.to_numeric(df_clean['age'], errors='coerce').fillna(-1).astype(int)

df_clean['income'] = df_clean['income'].str.replace('$', '').str.replace(',', '')
df_clean['income'] = pd.to_numeric(df_clean['income'], errors='coerce')

# Převod purchase_date na datetime
df_clean['purchase_date'] = pd.to_datetime(df_clean['purchase_date'], errors='coerce',

# Převod is_member na boolean
yes_values = ['yes', 'y', 'true', '1']
df_clean['is_member'] = df_clean['is_member'].str.lower().isin(yes_values)

print("\nVyčištěné datové typy:")

print(df_clean.head())

# Kontrola problémů s konverzí
```

## 8. Standardizace a normalizace dat

Standardizace a normalizace jsou techniky používané ke škálování numerických proměnných do podobného rozsahu, což je důležité pro mnoho algoritmů strojového učení.

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# Vytvoření vzorových numerických dat
df_numeric = pd.DataFrame({
    'income': [45000, 62000, 55000, 0, 72000, 72000, 61000, 42000, 82000, 76000],
    'age': [28, 34, 40, 41, 22, 22, 35, 39, 45, 36]
})

# Standardizace (Z-skóre normalizace)
# Transformuje data tak, aby měla průměr 0 a směrodatnou odchylku 1
scaler = StandardScaler()
df_standardized = pd.DataFrame(
    scaler.fit_transform(df_numeric),
    columns=df_numeric.columns
)

print("Původní data:")
print(df_numeric.describe())
print("\nStandardizovaná data:")
print(df_standardized.describe())

# Min-Max škálování
# Transformuje data do rozsahu od 0 do 1
min_max_scaler = MinMaxScaler()
df_normalized = pd.DataFrame(
    min_max_scaler.fit_transform(df_numeric),
    columns=df_numeric.columns
)

print("\nNormalizovaná data (Min-Max):")
print(df_normalized.describe())

# Vizualizace efektu škálování
plt.figure(figsize=(15, 5))

plt.subplot(1, 3, 1)
plt.scatter(df_numeric['age'], df_numeric['income'])
plt.title('Původní data')
plt.xlabel('Věk')
plt.ylabel('Příjem')

plt.subplot(1, 3, 2)
plt.scatter(df_standardized['age'], df_standardized['income'])
```

## 9. Validace dat

Validace dat zajišťuje, že vaše vyčištěná data splňují požadované standardy pro analýzu. To zahrnuje kontrolu logické konzistence, rozsahů hodnot a relačních pravidel.

```python
df_clean = df.copy()

# Validace datových typů
def validate_types(df, type_dict):
    issues = []
    for column, expected_type in type_dict.items():
        if column not in df.columns:
            issues.append(f"Sloupec '{column}' nenalezen v dataframu")
            continue
            
        # Převod na očekávaný typ a kontrola chyb
        try:
            if expected_type == 'numeric':
                pd.to_numeric(df[column], errors='raise')
            elif expected_type == 'datetime':
                pd.to_datetime(df[column], errors='raise')
            elif expected_type == 'boolean':
                df[column].astype(bool)
            else:
                df[column].astype(expected_type)
        except Exception as e:
            issues.append(f"Sloupec '{column}' má problémy s typem: {e}")
    
    return issues

# Definice očekávaných typů
type_expectations = {
    'customer_id': 'numeric',
    'age': 'numeric',
    'purchase_date': 'datetime',
    'is_member': 'boolean'
}

type_issues = validate_types(df_clean, type_expectations)
print("Problémy s validací typů:")
for issue in type_issues:
    print(f"- {issue}")

# Validace rozsahů hodnot
def validate_ranges(df, range_dict):
    issues = []
    for column, (min_val, max_val) in range_dict.items():
        if column not in df.columns:
            issues.append(f"Sloupec '{column}' nenalezen v dataframu")
            continue
            
        # Kontrola, zda jsou hodnoty v rozsahu
        try:
            # Převod na čísla pro porovnání
            col_vals = pd.to_numeric(df[column], errors='coerce')
            out_of_range = df.loc[(col_vals < min_val) | (col_vals > max_val), column]
            if not out_of_range.empty:
                issues.append(f"Sloupec '{column}' má {len(out_of_range)} hodnot mimo rozsah {min_val}-{max_val}")
        except Exception as e:
            issues.append(f"Chyba při validaci rozsahu pro '{column}': {e}")
    
    return issues

# Definice očekávaných rozsahů
range_expectations = {
    'age': (0, 120),  # Rozumný rozsah věku
    'income': (0, 1000000)  # Rozumný rozsah příjmu
}

range_issues = validate_ranges(df_clean, range_expectations)
print("\nProblémy s validací rozsahů:")
for issue in range_issues:
    print(f"- {issue}")

# Validace logických vztahů
def validate_relationships(df, rules):
    issues = []
    for rule_name, rule_func in rules.items():
        try:
            valid = rule_func(df)
            if not valid:
                issues.append(f"Pravidlo '{rule_name}' porušeno")
        except Exception as e:
            issues.append(f"Chyba při kontrole pravidla '{rule_name}': {e}")
    
    return issues

# Definice relačních pravidel
def purchase_date_not_future(df):
    if 'purchase_date' not in df.columns:
        return True
    dates = pd.to_datetime(df['purchase_date'], errors='coerce')
    today = pd.Timestamp.today()
    return not (dates > today).any()

relationship_rules = {
    'purchase_date_not_in_future': purchase_date_not_future
}

relationship_issues = validate_relationships(df_clean, relationship_rules)
print("\nProblémy s validací vztahů:")
for issue in relationship_issues:
    print(f"- {issue}")
```

## 10. Shrnutí

Čištění dat je kritickou a často časově náročnou součástí každého projektu datové vědy. Tato příručka pokryla základní techniky:

1. **Identifikace chybějících hodnot**: Použití metod jako `isnull()` k nalezení chybějících údajů v datasetu.
2. **Zpracování chybějících hodnot**: Více strategií včetně odstranění řádků/sloupců, doplnění průměrem/mediánem/modem nebo pokročilými metodami jako KNN.
3. **Odstranění duplicit**: Detekce a eliminace identických nebo téměř identických záznamů pro prevenci zkreslení.
4. **Zpracování odlehlých hodnot**: Metody identifikace a řešení extrémních hodnot pomocí IQR, Z-skóre nebo ořezání.
5. **Manipulace s řetězci**: Standardizace textových dat úpravou velikosti písmen, mezer a formátů.
6. **Konverze datových typů**: Zajištění, aby každý sloupec měl vhodný datový typ pro analýzu.
7. **Standardizace a normalizace**: Škálování numerických dat pomocí standardizace nebo min-max normalizace.
8. **Validace dat**: Ověření, že vaše vyčištěná data splňují očekávání ohledně typů, rozsahů a logických vztahů.

Proces čištění dat je iterativní a často vyžaduje přechod mezi jednotlivými kroky, jak objevujete další problémy. Správně vyčištěná data tvoří základ pro přesnou analýzu, vizualizaci a modelování v projektech datové vědy.

Osvědčené postupy při čištění dat zahrnují:
- Dokumentaci všech kroků čištění a rozhodnutí
- Vytváření opakovaně použitelných pipeline pro čištění podobných datasetů
- Validaci výsledků po každém hlavním kroku čištění
- Zálohování původních dat před čištěním

Mějte na paměti, že konkrétní techniky čištění se budou lišit v závislosti na vašem datasetu a požadavcích vaší analýzy nebo modelu.
