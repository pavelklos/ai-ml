## 1. Úvod do agregace a seskupování dat

Agregace a seskupování dat jsou základní techniky při analýze dat, které zahrnují kategorizaci dat do skupin a výpočet souhrnných statistik pro každou skupinu. Tyto operace vám umožňují extrahovat smysluplné vzory a poznatky z vašich dat zkoumáním chování různých segmentů.

```python
# Import potřebných knihoven
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Nastavení estetických parametrů pro lepší vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Vytvoření vzorového datasetu
data = {
    'Category': ['A', 'B', 'A', 'B', 'A', 'C', 'C', 'B', 'C', 'A'],
    'Region': ['East', 'West', 'West', 'East', 'East', 'West', 'East', 'West', 'East', 'West'],
    'Sales': [100, 200, 150, 250, 120, 180, 220, 190, 130, 110],
    'Quantity': [10, 15, 12, 18, 8, 16, 20, 14, 11, 9],
    'Date': pd.date_range(start='1/1/2023', periods=10)
}

# Vytvoření DataFrame
df = pd.DataFrame(data)
print("Vzorový DataFrame:")
print(df)
```

Operace agregace a seskupování následují metodologii "rozděl-aplikuj-kombinuj":
1. **Rozděl**: Data jsou rozdělena do skupin na základě jedné nebo více proměnných
2. **Aplikuj**: Na každou skupinu zvlášť se aplikuje funkce (jako součet, průměr, počet)
3. **Kombinuj**: Výsledky jsou kombinovány do nové datové struktury

## 2. Základní operace GroupBy

Metoda `.groupby()` v pandas je základem pro agregaci dat. Rozděluje data na základě zadaných sloupců a připravuje je pro další operace.

```python
# Seskupení dat podle Category
grouped = df.groupby('Category')

# Aplikace agregace - výpočet průměru každého numerického sloupce podle kategorie
category_means = grouped.mean()
print("\nPrůměrné hodnoty seskupené podle Category:")
print(category_means)

# Počet položek v každé skupině
group_counts = grouped.size()
print("\nPočet položek v každé kategorii:")
print(group_counts)

# Základní statistiky pro každou skupinu
category_summary = grouped.describe()
print("\nSouhrnné statistiky podle Category:")
print(category_summary)

# Přístup k určité skupině
group_A = grouped.get_group('A')
print("\nData pro Category A:")
print(group_A)

# Iterace přes skupiny
print("\nIterace přes každou skupinu Category:")
for name, group in grouped:
    print(f"\nKategorie: {name}")
    print(f"Velikost skupiny: {len(group)}")
    print(group)
```

## 3. Agregační funkce

Agregační funkce shrnují data v rámci každé skupiny. Můžete použít vestavěné funkce jako `sum()`, `mean()` nebo `count()`, nebo definovat vlastní agregační funkce.

```python
# Vestavěné agregační funkce
print("\nSoučet hodnot podle Category:")
print(grouped.sum())

print("\nMinimální hodnoty podle Category:")
print(grouped.min())

print("\nMaximální hodnoty podle Category:")
print(grouped.max())

# Aplikace více agregačních funkcí najednou pomocí metody agg()
agg_funcs = grouped.agg(['min', 'max', 'mean', 'count'])
print("\nVíce agregačních funkcí najednou:")
print(agg_funcs)

# Aplikace různých funkcí na různé sloupce
custom_agg = grouped.agg({
    'Sales': ['sum', 'mean', 'max'],
    'Quantity': ['min', 'mean', 'max']
})
print("\nRůzné agregace pro různé sloupce:")
print(custom_agg)

# Definování vlastní agregační funkce
def sales_per_item(x):
    return x['Sales'].sum() / x['Quantity'].sum()

print("\nVlastní agregační funkce (Tržby na položku):")
print(grouped.apply(sales_per_item))
```

## 4. Vícenásobné agregace

Můžete provádět více agregačních operací současně, čímž vytvoříte bohaté souhrnné pohledy na vaše data.

```python
# Použití agg() s více funkcemi
print("\nVíce agregací s agg():")
agg_results = df.groupby('Category').agg({
    'Sales': ['sum', 'mean', 'median', 'std'],
    'Quantity': ['sum', 'mean', 'median', 'max']
})
print(agg_results)

# Použití pojmenovaných agregací (pandas 0.25+)
print("\nPojmenované agregace:")
named_agg = df.groupby('Region').agg(
    total_sales=('Sales', 'sum'),
    avg_sales=('Sales', 'mean'),
    total_qty=('Quantity', 'sum'),
    max_qty=('Quantity', 'max')
)
print(named_agg)

# Vlastní agregační funkce s lambda funkcemi
print("\nVlastní agregace s lambda funkcemi:")
custom_agg = df.groupby('Category').agg({
    'Sales': ['sum', 'mean', lambda x: x.max() - x.min()],
    'Quantity': ['sum', lambda x: x.mean() / x.std() if x.std() > 0 else 0]
})
# Přejmenování sloupců lambda funkcí
custom_agg.columns = ['Sales_Sum', 'Sales_Mean', 'Sales_Range', 'Quantity_Sum', 'Quantity_Coef_Var']
print(custom_agg)
```

## 5. Seskupování podle více sloupců

Data můžete seskupit podle více sloupců a vytvořit tak specifičtější agregace. To umožňuje hierarchickou analýzu vašich dat.

```python
# Seskupení podle více sloupců
multi_group = df.groupby(['Category', 'Region'])

# Výpočet průměru pro každou kombinaci
print("\nPrůměrné hodnoty seskupené podle Category a Region:")
print(multi_group.mean())

# Počet pozorování v každé skupině
print("\nPočet podle Category a Region:")
print(multi_group.size().reset_index(name='Count'))

# Aplikace agregačních funkcí
print("\nSoučet Sales podle Category a Region:")
print(multi_group['Sales'].sum())

# Rozložení výsledků pro získání formátu podobného kontingenční tabulce
sales_by_cat_region = multi_group['Sales'].sum().unstack()
print("\nSales podle Category a Region (rozložené):")
print(sales_by_cat_region)

# Vizualizace výsledků
plt.figure(figsize=(10, 6))
sales_by_cat_region.plot(kind='bar')
plt.title('Celkové tržby podle Category a Region')
plt.xlabel('Category')
plt.ylabel('Sales')
plt.tight_layout()
plt.show()
```

## 6. Hierarchické indexování s GroupBy

Při seskupování podle více sloupců vytváří pandas hierarchickou (MultiIndex) strukturu, která umožňuje složitější analýzu.

```python
# Vytvoření hierarchického indexu pomocí groupby
hierarchical_index = df.groupby(['Category', 'Region']).mean()
print("\nHierarchický index z groupby:")
print(hierarchical_index)

# Přístup k datům na různých úrovních hierarchie
print("\nData pro kategorii 'A':")
print(hierarchical_index.loc['A'])

# Přístup ke specifickým kombinacím
print("\nData pro kategorii 'A', Region 'East':")
print(hierarchical_index.loc[('A', 'East')])

# Rozložení pro převod hierarchického indexu na sloupce
print("\nRozložení první úrovně:")
print(hierarchical_index.unstack(level=0))

print("\nRozložení druhé úrovně:")
print(hierarchical_index.unstack(level=1))

# Rozložení všech úrovní pro získání běžného DataFrame
print("\nRozložení všech úrovní:")
print(hierarchical_index.unstack())

# Resetování indexu
print("\nResetování hierarchického indexu:")
print(hierarchical_index.reset_index())
```

## 7. Kontingenční tabulky a křížové tabulace

Kontingenční tabulky a křížové tabulace poskytují alternativní způsoby, jak shrnout a přetvarovat seskupená data pro analýzu.

```python
# Vytvoření kontingenční tabulky
pivot_table = pd.pivot_table(
    df, 
    values='Sales', 
    index='Category', 
    columns='Region', 
    aggfunc='sum',
    fill_value=0
)

print("\nKontingenční tabulka - Sales podle Category a Region:")
print(pivot_table)

# Více hodnot a agregačních funkcí
multi_pivot = pd.pivot_table(
    df,
    values=['Sales', 'Quantity'],
    index='Category',
    columns='Region',
    aggfunc={'Sales': 'sum', 'Quantity': 'mean'},
    margins=True  # Přidání součtů řádků a sloupců
)

print("\nKontingenční tabulka s více hodnotami a agregacemi:")
print(multi_pivot)

# Křížová tabulace (frekvenční tabulka)
cross_tab = pd.crosstab(
    df['Category'], 
    df['Region'], 
    values=df['Sales'], 
    aggfunc='sum', 
    normalize=False  # Nastavte na True pro podíly
)

print("\nKřížová tabulace Sales podle Category a Region:")
print(cross_tab)

# Vizualizace kontingenční tabulky
plt.figure(figsize=(10, 6))
pivot_table.plot(kind='bar', stacked=True)
plt.title('Tržby podle Category a Region')
plt.xlabel('Category')
plt.ylabel('Sales')
plt.legend(title='Region')
plt.tight_layout()
plt.show()
```

## 8. Transformace a filtrace

Kromě jednoduchých agregací pandas také podporuje skupinové transformace a filtrační operace.

```python
# Transformace: aplikace funkce na každou hodnotu v každé skupině
# Příklad: Standardizace hodnot v rámci každé kategorie
def standardize(x):
    return (x - x.mean()) / x.std() if x.std() > 0 else 0

print("\nStandardizované Sales v rámci každé Category:")
standardized = df.groupby('Category')['Sales'].transform(standardize)
print(pd.DataFrame({'Původní': df['Sales'], 'Standardizované': standardized}))

# Výpočet procenta celkových tržeb pro každou položku v rámci její kategorie
category_total = df.groupby('Category')['Sales'].transform('sum')
percentage = df['Sales'] / category_total * 100
print("\nTržby jako procento celkových tržeb kategorie:")
print(pd.DataFrame({'Tržby': df['Sales'], 'Celkem_kategorie': category_total, 'Procento': percentage}))

# Filtrace: výběr skupin, které splňují podmínku
# Příklad: Kategorie, kde průměrné tržby > 150
high_sales_categories = df.groupby('Category').filter(lambda x: x['Sales'].mean() > 150)
print("\nData z kategorií s průměrnými tržbami > 150:")
print(high_sales_categories)

# Příklad: Kategorie s alespoň 3 záznamy
large_categories = df.groupby('Category').filter(lambda x: len(x) >= 3)
print("\nData z kategorií s alespoň 3 záznamy:")
print(large_categories)
```

## 9. Praktické aplikace

Pojďme prozkoumat několik praktických aplikací agregace a seskupování dat.

```python
# Vytvoříme realističtější dataset
np.random.seed(42)
dates = pd.date_range('1/1/2023', periods=1000)
products = ['Product_A', 'Product_B', 'Product_C', 'Product_D', 'Product_E']
regions = ['North', 'South', 'East', 'West']
channels = ['Online', 'Retail', 'Direct']

sales_data = pd.DataFrame({
    'Date': np.random.choice(dates, 1000),
    'Product': np.random.choice(products, 1000),
    'Region': np.random.choice(regions, 1000),
    'Channel': np.random.choice(channels, 1000),
    'Units': np.random.randint(1, 50, 1000),
    'Price': np.random.uniform(10, 100, 1000).round(2)
})

# Výpočet celkových tržeb
sales_data['Revenue'] = sales_data['Units'] * sales_data['Price']
print("\nVzorová prodejní data:")
print(sales_data.head())

# Příklad 1: Měsíční analýza prodejů
# Přidání sloupce měsíce pro seskupování
sales_data['Month'] = sales_data['Date'].dt.month_name()
sales_data['Quarter'] = sales_data['Date'].dt.quarter

monthly_sales = sales_data.groupby('Month')['Revenue'].sum().reindex(['January', 'February', 'March', 'April', 'May', 'June', 'July', 'August', 'September', 'October', 'November', 'December'])
print("\nMěsíční analýza prodejů:")
print(monthly_sales)

plt.figure(figsize=(12, 6))
monthly_sales.plot(kind='bar', color='skyblue')
plt.title('Měsíční tržby')
plt.ylabel('Tržby')
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Příklad 2: Výkonnost produktu podle kanálu
product_channel = sales_data.pivot_table(
    values='Revenue',
    index='Product',
    columns='Channel',
    aggfunc='sum',
    fill_value=0
)
print("\nVýkonnost produktu podle prodejního kanálu:")
print(product_channel)

# Příklad 3: Analýza výkonnosti podle regionu s více metrikami
regional_performance = sales_data.groupby('Region').agg({
    'Revenue': ['sum', 'mean'],
    'Units': 'sum',
    'Price': 'mean'
})
regional_performance.columns = ['Celkové_tržby', 'Průměr_transakce', 'Celkové_jednotky', 'Průměrná_cena']
regional_performance['Tržby_na_jednotku'] = regional_performance['Celkové_tržby'] / regional_performance['Celkové_jednotky']
print("\nAnalýza výkonnosti podle regionu:")
print(regional_performance)

# Příklad 4: Identifikace nejlepších produktů podle čtvrtletí
top_products = sales_data.pivot_table(
    values='Revenue',
    index='Product',
    columns='Quarter',
    aggfunc='sum'
)
print("\nVýkonnost produktů podle čtvrtletí:")
print(top_products)

# Heatmap vizualizace výkonnosti produktů podle čtvrtletí
plt.figure(figsize=(10, 8))
sns.heatmap(top_products, annot=True, fmt='.0f', cmap='YlGnBu')
plt.title('Tržby produktů podle čtvrtletí')
plt.tight_layout()
plt.show()
```

## 10. Shrnutí

Agregace a seskupování dat jsou základní techniky v analýze dat, které vám umožňují segmentovat data a počítat souhrnné statistiky pro každou skupinu. Tyto operace jsou klíčové pro odhalování vzorů, provádění srovnání a získávání poznatků z vašich dat.

Klíčové koncepty uvedené v této příručce:

- **Základní operace GroupBy**: Použití pandas `.groupby()` pro rozdělení dat do skupin na základě kategoriálních proměnných
- **Agregační funkce**: Aplikace souhrnných funkcí jako `sum()`, `mean()` nebo vlastních funkcí na seskupená data
- **Vícenásobné agregace**: Provádění různých agregací současně pro bohatší analýzu
- **Víceúrovňové seskupování**: Seskupování podle více sloupců pro vytvoření hierarchických pohledů na data
- **Hierarchické indexování**: Práce se strukturami MultiIndex, které jsou výsledkem operací groupby
- **Kontingenční tabulky**: Vytváření přehledů dat ve stylu tabulkových procesorů
- **Transformace a filtrace**: Aplikace funkcí, které zachovávají původní tvar dat, nebo filtrování na základě vlastností skupiny
- **Praktické aplikace**: Praktické příklady použití groupby pro obchodní analytiku

Zvládnutí technik agregace a seskupování dat umožňuje sofistikovanější analýzu dat a pomáhá odhalit vztahy a vzory, které nemusí být viditelné v surových datech. Efektivním používáním těchto technik můžete transformovat surová data do užitečných poznatků pro rozhodování.
