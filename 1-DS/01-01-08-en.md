## 1. Introduction to Data Filtering and Selection

Data filtering and selection are essential operations in data analysis that allow you to focus on specific subsets of your data. These techniques help you extract meaningful information and can significantly reduce the complexity of large datasets. In pandas, there are multiple ways to filter and select data from DataFrames.

```python
# Import necessary libraries
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Create a sample dataset
data = {
    'Name': ['John', 'Anna', 'Peter', 'Linda', 'Bob', 'Mary', 'Chris', 'David'],
    'Age': [28, 34, 29, 42, 35, 31, 27, 40],
    'City': ['New York', 'Los Angeles', 'Chicago', 'Boston', 'New York', 'Chicago', 'Boston', 'Los Angeles'],
    'Salary': [65000, 72000, 59000, 82000, 68000, 61000, 55000, 78000],
    'Experience': [3, 6, 2, 9, 5, 4, 2, 7],
    'Department': ['Sales', 'HR', 'Marketing', 'IT', 'Sales', 'Marketing', 'IT', 'HR']
}

# Create DataFrame
df = pd.DataFrame(data)
print("Original DataFrame:")
print(df)
```

## 2. Basic DataFrame Selection Methods

The most basic selection operations in pandas allow you to select columns, rows, or individual cells from a DataFrame.

```python
# Select a single column (returns a Series)
age_column = df['Age']
print("\nAge column:")
print(age_column)

# Select multiple columns (returns a DataFrame)
subset = df[['Name', 'City', 'Salary']]
print("\nSubset of columns:")
print(subset)

# Select rows by position using slicing (returns a DataFrame)
first_three_rows = df[:3]
print("\nFirst three rows:")
print(first_three_rows)

# Select a specific row (returns a Series)
second_row = df.iloc[1]
print("\nSecond row:")
print(second_row)

# Select a specific cell value
specific_cell = df.iloc[2, 1]  # Value at row 2, column 1 (0-indexed)
print(f"\nValue at row 2, column 1: {specific_cell}")
```

## 3. Filtering with Boolean Indexing

Boolean indexing is a powerful feature that allows you to filter data based on conditions. You create a boolean mask (a Series of True/False values) and use it to filter your DataFrame.

```python
# Create a boolean mask for filtering
mask = df['Age'] > 35
print("\nBoolean mask for Age > 35:")
print(mask)

# Apply the mask to filter the DataFrame
filtered_df = df[mask]
print("\nFiltered DataFrame (Age > 35):")
print(filtered_df)

# One-line filtering
high_salary = df[df['Salary'] > 70000]
print("\nEmployees with salary > 70000:")
print(high_salary)

# Filtering based on categorical data
sales_dept = df[df['Department'] == 'Sales']
print("\nEmployees in Sales department:")
print(sales_dept)

# Using .isin() for filtering with multiple values
selected_cities = df[df['City'].isin(['New York', 'Boston'])]
print("\nEmployees from New York or Boston:")
print(selected_cities)

# Using .str methods for text filtering
starts_with_m = df[df['Department'].str.startswith('M')]
print("\nDepartments starting with 'M':")
print(starts_with_m)
```

## 4. Using .loc and .iloc for Selection

The `.loc` and `.iloc` methods provide a more precise way to select data:
- `.loc`: Label-based indexing (uses row/column names)
- `.iloc`: Integer position-based indexing (uses numerical indices)

```python
# Using .loc with row labels and column names
# In this case row labels are the default integer indices
subset_loc = df.loc[2:4, ['Name', 'Age', 'Department']]
print("\nUsing .loc to select rows 2-4 with specific columns:")
print(subset_loc)

# Using .iloc with integer positions
subset_iloc = df.iloc[1:5, [0, 2, 4]]  # Rows 1-4, columns 0, 2, 4
print("\nUsing .iloc with integer positions:")
print(subset_iloc)

# Select a single value with .loc
value_loc = df.loc[3, 'City']
print(f"\nCity of person at index 3: {value_loc}")

# Select a single value with .iloc
value_iloc = df.iloc[3, 2]
print(f"\nValue at row 3, column 2: {value_iloc}")

# Set the index to a column for better .loc demonstration
df_indexed = df.set_index('Name')
print("\nDataFrame with Name as index:")
print(df_indexed)

# Now .loc can select by person's name
anna_data = df_indexed.loc['Anna']
print("\nAnna's data using .loc:")
print(anna_data)

# Reset index back to default
df_indexed = df_indexed.reset_index()
```

## 5. Combining Multiple Conditions

You can combine multiple filtering conditions using logical operators (`&` for AND, `|` for OR, `~` for NOT).

```python
# AND condition: Age > 30 AND Salary > 70000
condition1 = (df['Age'] > 30) & (df['Salary'] > 70000)
result1 = df[condition1]
print("\nEmployees over 30 with salary > 70000:")
print(result1)

# OR condition: Department is Sales OR HR
condition2 = (df['Department'] == 'Sales') | (df['Department'] == 'HR')
result2 = df[condition2]
print("\nEmployees in Sales or HR:")
print(result2)

# NOT condition: Not in New York
condition3 = ~(df['City'] == 'New York')
result3 = df[condition3]
print("\nEmployees not in New York:")
print(result3)

# Complex condition: Age between 30-40 AND Experience > 5
condition4 = (df['Age'].between(30, 40)) & (df['Experience'] > 5)
result4 = df[condition4]
print("\nEmployees aged 30-40 with experience > 5:")
print(result4)
```

## 6. Working with Text Data

Pandas provides powerful string methods for filtering text data through the `.str` accessor.

```python
# Filter names that contain the letter 'a'
contains_a = df[df['Name'].str.contains('a')]
print("\nNames containing 'a':")
print(contains_a)

# Case-insensitive filtering
contains_A = df[df['Name'].str.contains('A', case=False)]
print("\nNames containing 'A' or 'a' (case-insensitive):")
print(contains_A)

# Filter using regular expressions
import re
pattern = r'^[JM]'  # Names starting with J or M
regex_filter = df[df['Name'].str.match(pattern)]
print("\nNames starting with J or M:")
print(regex_filter)

# String length filtering
long_city_names = df[df['City'].str.len() > 8]
print("\nEmployees from cities with names longer than 8 characters:")
print(long_city_names)

# Replacing values in text columns and then filtering
df_temp = df.copy()
df_temp['Department'] = df_temp['Department'].str.replace('HR', 'Human Resources')
hr_dept = df_temp[df_temp['Department'] == 'Human Resources']
print("\nEmployees in Human Resources (after replacement):")
print(hr_dept)
```

## 7. Advanced Filtering Techniques

Beyond basic filtering, pandas offers more advanced methods to select and filter data.

```python
# Filter based on index properties
df_indexed = df.set_index('Name')
first_half_alphabet = df_indexed[df_indexed.index.str[0] <= 'M']
print("\nEmployees with names in first half of alphabet:")
print(first_half_alphabet.reset_index())

# Get top N values by a column
top_3_salaries = df.nlargest(3, 'Salary')
print("\nTop 3 highest salaries:")
print(top_3_salaries)

# Get bottom N values by a column
bottom_3_experience = df.nsmallest(3, 'Experience')
print("\nBottom 3 by experience:")
print(bottom_3_experience)

# Filter rows where at least one column contains NaN (first adding some NaN values)
df_with_nan = df.copy()
df_with_nan.loc[1, 'Experience'] = np.nan
df_with_nan.loc[3, 'Salary'] = np.nan
rows_with_nan = df_with_nan[df_with_nan.isna().any(axis=1)]
print("\nRows with at least one NaN value:")
print(rows_with_nan)

# Filter rows based on duplicated values
df_with_duplicates = pd.concat([df, df.iloc[:2]])  # Add first 2 rows again
print("\nDataFrame with duplicated rows:")
print(df_with_duplicates)

# Get only duplicated rows
duplicated_rows = df_with_duplicates[df_with_duplicates.duplicated()]
print("\nOnly duplicated rows:")
print(duplicated_rows)

# Get unique values in a column
unique_departments = df['Department'].unique()
print("\nUnique departments:", unique_departments)
```

## 8. The Query Method

The `.query()` method provides a more concise and readable way to filter pandas DataFrames, especially for complex conditions.

```python
# Basic query
high_salary_query = df.query('Salary > 70000')
print("\nEmployees with salary > 70000 using query:")
print(high_salary_query)

# Using variables in query
min_age = 30
max_age = 40
age_range_query = df.query('Age >= @min_age and Age <= @max_age')
print("\nEmployees aged 30-40 using query:")
print(age_range_query)

# Combining conditions using query
complex_query = df.query('Experience > 5 and Department == "HR" or City == "New York"')
print("\nComplex query result:")
print(complex_query)

# Using string methods in query (notice the backticks for column names with spaces)
name_query = df.query('Name.str.startswith("A") or Name.str.endswith("d")')
print("\nNames that start with 'A' or end with 'd':")
print(name_query)

# Query with IN operator
cities_list = ['New York', 'Boston']
city_query = df.query('City in @cities_list')
print("\nEmployees in New York or Boston using query:")
print(city_query)
```

## 9. Selecting and Transforming Data

Often, you'll want to not only select data but also transform it in the process.

```python
# Select and simultaneously transform data
salary_in_thousands = df['Salary'] / 1000
print("\nSalaries in thousands:")
print(salary_in_thousands)

# Using .map() to transform a column based on a dictionary
department_code = {
    'Sales': 'S',
    'HR': 'H',
    'Marketing': 'M',
    'IT': 'I'
}
df['Dept_Code'] = df['Department'].map(department_code)
print("\nDataFrame with department codes:")
print(df)

# Using .apply() to transform data with a function
def experience_category(years):
    if years < 3:
        return 'Junior'
    elif years < 7:
        return 'Mid-level'
    else:
        return 'Senior'

df['Experience_Level'] = df['Experience'].apply(experience_category)
print("\nDataFrame with experience levels:")
print(df)

# Filtering and then transforming
high_earners = df[df['Salary'] > 70000].copy()
high_earners['Bonus'] = high_earners['Salary'] * 0.10
print("\nHigh earners with bonus calculated:")
print(high_earners)

# Using .transform() to apply a function that maintains the index
mean_age_by_dept = df.groupby('Department')['Age'].transform('mean')
print("\nMean age by department (preserved index):")
print(pd.DataFrame({
    'Department': df['Department'],
    'Age': df['Age'],
    'Mean Age in Department': mean_age_by_dept
}))

# Remove the columns we added for demonstration
df = df.drop(['Dept_Code', 'Experience_Level'], axis=1)
```

## 10. Summary

Data filtering and selection are fundamental skills in data science that allow you to:

- Extract specific subsets of data that meet certain conditions
- Focus your analysis on relevant information
- Prepare data for visualization or modeling

Key techniques covered in this guide include:

- Basic column and row selection using brackets `[]`
- Boolean indexing for condition-based filtering
- Using `.loc` and `.iloc` for precise selections
- Combining multiple filtering conditions with logical operators (`&`, `|`, `~`)
- Text-based filtering with string methods (`.str`)
- Advanced techniques like `.nlargest()`, `.nsmallest()`, and `.duplicated()`
- The `.query()` method for more readable filtering expressions
- Transforming data while selecting with `.map()`, `.apply()`, and `.transform()`

Mastering these techniques will significantly improve your ability to manipulate and analyze data effectively. By filtering data properly, you can gain more focused insights and create more relevant visualizations and models.

Remember to always consider the impact of filtering on your analysis. Filtering out certain data points can introduce bias or change the statistical properties of your dataset. Always document your filtering decisions and understand how they might affect your conclusions.
