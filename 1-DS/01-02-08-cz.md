## Úvod do integrace SQL a pandas

SQL (Structured Query Language) je nezbytný pro práci s relačními databázemi, zatímco pandas je výkonná knihovna Pythonu pro manipulaci s daty. Integrace SQL s pandas umožňuje datovým vědcům využít silné stránky obou nástrojů: robustní databázové funkce SQL a flexibilní funkce analýzy dat v pandas.


## Načítání SQL dat do DataFrames

Jednou z nejběžnějších operací je načítání SQL dat do pandas DataFrames pro analýzu.

```python
# Nejprve vytvoříme vzorovou tabulku v SQLite pro demonstraci
sqlite_conn.execute('''
CREATE TABLE IF NOT EXISTS customers (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    age INTEGER,
    email TEXT,
    signup_date DATE,
    purchases INTEGER
)
''')

# Vložení vzorových dat
sample_data = [
    (1, 'Alice Smith', 28, 'alice@example.com', '2022-03-15', 12),
    (2, 'Bob Johnson', 35, 'bob@example.com', '2022-01-10', 5),
    (3, 'Charlie Brown', 42, 'charlie@example.com', '2021-11-20', 20),
    (4, 'Diana Miller', 31, 'diana@example.com', '2022-04-05', 8),
    (5, 'Edward Davis', 25, 'edward@example.com', '2022-02-28', 15)
]

sqlite_conn.executemany(
    "INSERT INTO customers VALUES (?, ?, ?, ?, ?, ?)",
    sample_data
)
sqlite_conn.commit()

# Metoda 1: Načtení výsledků SQL dotazu do DataFrame
query = "SELECT * FROM customers WHERE age > 30"
df_query = pd.read_sql(query, sqlite_conn)
print("Zákazníci starší 30 let:")
print(df_query)

# Metoda 2: Načtení celé tabulky do DataFrame
df_table = pd.read_sql_table("customers", sqlite_engine)
print("\nVšichni zákazníci (pomocí read_sql_table):")
print(df_table)

# Metoda 3: Použití funkce read_sql_query pro explicitnější dotazy
df_detailed = pd.read_sql_query(
    "SELECT name, age, purchases FROM customers ORDER BY purchases DESC",
    sqlite_conn
)
print("\nZákazníci seřazení podle nákupů:")
print(df_detailed)

# Metoda 4: Parametrizované dotazy pro bezpečnost a flexibilitu
min_age = 25
max_age = 40
df_params = pd.read_sql_query(
    "SELECT * FROM customers WHERE age BETWEEN ? AND ?",
    sqlite_conn,
    params=(min_age, max_age)
)
print(f"\nZákazníci ve věku mezi {min_age} a {max_age} let:")
print(df_params)
```

## Zápis DataFrames do SQL databází

pandas usnadňuje zápis DataFrames do SQL databází, což je užitečné pro ukládání zpracovaných dat nebo výsledků analýz.

```python
# Vytvoření nového DataFrame pro zápis do databáze
new_customers = pd.DataFrame({
    'id': [6, 7, 8],
    'name': ['Frank Wilson', 'Grace Lee', 'Henry Martin'],
    'age': [29, 34, 45],
    'email': ['frank@example.com', 'grace@example.com', 'henry@example.com'],
    'signup_date': ['2022-05-10', '2022-05-12', '2022-05-15'],
    'purchases': [3, 7, 2]
})

# Metoda 1: Zápis DataFrame do nové tabulky
new_customers.to_sql('new_customers', sqlite_conn, index=False, if_exists='replace')

# Metoda 2: Přidání dat do existující tabulky
new_customers.to_sql('customers', sqlite_conn, index=False, if_exists='append')

# Ověření, že data byla zapsána, jejich načtením zpět
df_all = pd.read_sql("SELECT * FROM customers", sqlite_conn)
print("Všichni zákazníci po přidání:")
print(df_all)

# Metoda 3: Nahrazení existující tabulky
modified_df = pd.DataFrame({
    'id': [1, 2, 3],
    'name': ['Alice Aktualizovaná', 'Bob Aktualizovaný', 'Charlie Aktualizovaný'],
    'age': [29, 36, 43],
    'email': ['alice.novy@example.com', 'bob.novy@example.com', 'charlie.novy@example.com'],
    'signup_date': ['2022-03-15', '2022-01-10', '2021-11-20'],
    'purchases': [15, 8, 25]
})

modified_df.to_sql('customers_v2', sqlite_conn, index=False, if_exists='replace')

# Další běžné možnosti pro if_exists:
# - 'fail': Vyvolá ValueError, pokud tabulka existuje (výchozí)
# - 'replace': Odstraní tabulku před vložením nových hodnot
# - 'append': Vloží nové hodnoty do existující tabulky
```

## Používání SQL dotazů s pandas

S pandas můžete přímo používat SQL dotazy k využití výkonných dotazovacích schopností SQL před načtením dat do pandas.

```python
# Vytvoření složitějšího schématu databáze pro tento příklad
sqlite_conn.execute('''
CREATE TABLE IF NOT EXISTS orders (
    order_id INTEGER PRIMARY KEY,
    customer_id INTEGER,
    order_date DATE,
    total_amount REAL,
    FOREIGN KEY (customer_id) REFERENCES customers (id)
)
''')

# Vzorová data objednávek
orders_data = [
    (101, 1, '2022-04-10', 120.50),
    (102, 2, '2022-03-22', 85.25),
    (103, 1, '2022-04-18', 220.00),
    (104, 3, '2022-02-15', 65.75),
    (105, 5, '2022-05-01', 160.30),
    (106, 3, '2022-03-10', 40.20),
    (107, 4, '2022-04-30', 95.60),
    (108, 1, '2022-05-05', 185.40)
]

sqlite_conn.executemany(
    "INSERT INTO orders VALUES (?, ?, ?, ?)",
    orders_data
)
sqlite_conn.commit()

# Dotaz s připojením tabulek
join_query = """
SELECT 
    c.name, 
    c.email, 
    COUNT(o.order_id) as order_count, 
    SUM(o.total_amount) as total_spent,
    AVG(o.total_amount) as avg_order_value
FROM 
    customers c
JOIN 
    orders o ON c.id = o.customer_id
GROUP BY 
    c.id
ORDER BY 
    total_spent DESC
"""

customer_analysis = pd.read_sql_query(join_query, sqlite_conn)
print("Analýza objednávek zákazníků:")
print(customer_analysis)

# Složitý SQL dotaz s agregacemi, filtrováním a řazením
advanced_query = """
WITH monthly_stats AS (
    SELECT 
        customer_id,
        strftime('%Y-%m', order_date) as month,
        SUM(total_amount) as monthly_spent
    FROM 
        orders
    GROUP BY 
        customer_id, month
)
SELECT 
    c.name,
    COUNT(DISTINCT ms.month) as active_months,
    SUM(ms.monthly_spent) as total_spent,
    AVG(ms.monthly_spent) as avg_monthly_spent
FROM 
    customers c
JOIN 
    monthly_stats ms ON c.id = ms.customer_id
GROUP BY 
    c.id
HAVING 
    active_months > 1
ORDER BY 
    avg_monthly_spent DESC
"""

monthly_analysis = pd.read_sql_query(advanced_query, sqlite_conn)
print("\nAnalýza měsíčních výdajů:")
print(monthly_analysis)
```

```python
    print(f"\nBlok {i+1}:")

    # Zpracování bloku zde...
    # Například: chunk['age_squared'] = chunk['age'] ** 2

# Čtení konkrétních sloupců pro snížení využití paměti
columns_of_interest = pd.read_sql_query(
    "SELECT name, email, purchases FROM customers",
```

## Integrace SQLAlchemy

SQLAlchemy poskytuje robustnější a flexibilnější způsob práce s databázemi v pandas.

```python
# Vytvoření tabulky prostřednictvím SQLAlchemy
from sqlalchemy import Column, Integer, String, Float, Date, MetaData, Table, ForeignKey

metadata = MetaData()

# Definice tabulky produktů
products = Table(
    'products', 
    metadata,
    Column('product_id', Integer, primary_key=True),
    Column('name', String),
    Column('category', String),
    Column('price', Float),
    Column('stock', Integer)
)

# Vytvoření tabulky v databázi
metadata.create_all(sqlite_engine)

# Vytvoření DataFrame s daty produktů
products_df = pd.DataFrame({
    'product_id': [1, 2, 3, 4, 5],
    'name': ['Notebook', 'Smartphone', 'Tablet', 'Sluchátka', 'Monitor'],
    'category': ['Elektronika', 'Elektronika', 'Elektronika', 'Příslušenství', 'Elektronika'],
    'price': [1200.00, 800.00, 350.00, 150.00, 300.00],
    'stock': [15, 25, 30, 40, 20]
})

# Zápis DataFrame do tabulky produktů
products_df.to_sql('products', sqlite_engine, if_exists='append', index=False)

# Čtení tabulky produktů pomocí SQLAlchemy
result_df = pd.read_sql_table('products', sqlite_engine)
print("Tabulka produktů:")
print(result_df)

# Provedení složitějšího dotazu pomocí SQLAlchemy
from sqlalchemy import select, func

query = select([
    products.c.category,
    func.count(products.c.product_id).label('product_count'),
    func.avg(products.c.price).label('avg_price'),
    func.sum(products.c.stock).label('total_stock')
]).group_by(products.c.category)

result = pd.read_sql(query, sqlite_engine)
print("\nAnalýza kategorií produktů:")
print(result)
```

## Operace s databázovým schématem

pandas může také pomoci s prohlížením a správou schématu databáze.

```python
# Seznam všech tabulek v databázi
def list_tables(engine):
    inspector = sqlalchemy.inspect(engine)
    return inspector.get_table_names()

tables = list_tables(sqlite_engine)
print(f"Tabulky v databázi: {tables}")

# Získání informací o schématu pro tabulku
def get_schema(engine, table_name):
    inspector = sqlalchemy.inspect(engine)
    columns = inspector.get_columns(table_name)
    return pd.DataFrame([{
        'name': col['name'],
        'type': str(col['type']),
        'nullable': col['nullable'],
        'primary_key': col.get('primary_key', False)
    } for col in columns])

customers_schema = get_schema(sqlite_engine, 'customers')
print("\nSchéma tabulky customers:")
print(customers_schema)

# Získání informací o cizích klíčích
def get_foreign_keys(engine, table_name):
    inspector = sqlalchemy.inspect(engine)
    foreign_keys = inspector.get_foreign_keys(table_name)
    return pd.DataFrame(foreign_keys) if foreign_keys else "Žádné cizí klíče"

orders_fk = get_foreign_keys(sqlite_engine, 'orders')
print("\nCizí klíče tabulky orders:")
print(orders_fk)
```

## Osvědčené postupy a tipy pro výkon

Zde jsou některé osvědčené postupy a tipy pro výkon při integraci SQL s pandas:

```python
# 1. Použití vhodných datových typů při vytváření tabulek
from sqlalchemy import create_engine, Column, Integer, String, Float, Date
from sqlalchemy.ext.declarative import declarative_base

Base = declarative_base()

class OptimizedCustomer(Base):
    __tablename__ = 'optimized_customers'
    
    id = Column(Integer, primary_key=True)
    name = Column(String(100), nullable=False)  # Určení délky řetězce
    age = Column(Integer)
    email = Column(String(100), index=True)     # Přidání indexu pro rychlejší vyhledávání
    signup_date = Column(Date)
    purchases = Column(Integer, default=0)

# Vytvoření optimalizované tabulky
Base.metadata.create_all(sqlite_engine)

# 2. Použití vázání parametrů pro bezpečnost a výkon
def get_customers_by_age_range(min_age, max_age, connection):
    query = "SELECT * FROM customers WHERE age BETWEEN ? AND ?"
    return pd.read_sql_query(query, connection, params=(min_age, max_age))

filtered_customers = get_customers_by_age_range(30, 40, sqlite_conn)
print("\nZákazníci mezi 30 a 40 lety (pomocí vázání parametrů):")
print(filtered_customers)

# 3. Správná správa připojení
def safe_db_operation():
    # Vytvoření nového připojení
    conn = sqlite3.connect('sample_database.db')
    try:
        # Provedení databázových operací
        df = pd.read_sql("SELECT * FROM customers LIMIT 3", conn)
        print("\nBezpečně načtená data:")
        print(df)
    finally:
        # Zajištění uzavření připojení i v případě chyby
        conn.close()

safe_db_operation()

# 4. Použití hromadných operací pro lepší výkon
def bulk_insert_example(engine, data, table_name):
    # Převedení seznamu n-tic na DataFrame
    df = pd.DataFrame(data, columns=['id', 'name', 'age', 'email', 'signup_date', 'purchases'])
    
    # Použití to_sql s method='multi' pro hromadné vložení
    df.to_sql(table_name, engine, if_exists='append', index=False, method='multi')
    
    print(f"Hromadně vloženo {len(df)} řádků do {table_name}")

new_data = [
    (9, 'Ian Johnson', 38, 'ian@example.com', '2022-05-20', 4),
    (10, 'Julia Smith', 27, 'julia@example.com', '2022-05-21', 9),
    (11, 'Kevin Lee', 33, 'kevin@example.com', '2022-05-22', 6)
]

bulk_insert_example(sqlite_engine, new_data, 'customers')

# 5. Použití vhodného indexu při dotazování
# Vytvoření indexu na často dotazovaném sloupci
sqlite_conn.execute("CREATE INDEX IF NOT EXISTS idx_customer_age ON customers(age)")
sqlite_conn.commit()

# Dotaz nyní využívá index
indexed_query = pd.read_sql_query(
    "SELECT * FROM customers WHERE age > 30",
    sqlite_conn
)
print("\nDotaz využívající index na sloupci age:")
print(indexed_query)
```

## Shrnutí

Integrace SQL s pandas poskytuje datovým vědcům výkonný pracovní postup, který kombinuje silné stránky robustních databázových systémů s flexibilními možnostmi analýzy dat v pandas. Klíčové poznatky zahrnují:

1. **Připojení**: Několik způsobů připojení k databázím (sqlite3, pymysql, SQLAlchemy)
2. **Čtení dat**: Funkce `read_sql`, `read_sql_query` a `read_sql_table` pro import databázových dat
3. **Zápis dat**: Metoda `to_sql` pro export DataFrames do databází
4. **Složité dotazy**: Možnost využít výkonné dotazovací schopnosti SQL s pandas
5. **Velké datové sady**: Nástroje jako chunking a filtrování pro efektivní práci s velkými daty
6. **Integrace SQLAlchemy**: Robustnější interakce s databázemi pomocí SQLAlchemy
7. **Operace se schématy**: Prohlížení a správa databázových schémat
8. **Osvědčené postupy**: Tipy pro výkon včetně správné správy připojení, vázání parametrů a indexování

Tato integrace umožňuje plynulé pracovní postupy od ukládání dat až po analýzu, což datovým vědcům umožňuje efektivně pracovat jak se strukturovanými databázovými daty, tak s flexibilnějšími pandas DataFrames podle potřeby během procesu datové vědy.
