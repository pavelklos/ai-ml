## Úvod do zpracování a transformace dat

Zpracování dat (nebo data munging) je proces transformace surových dat do užitečnějšího formátu pro analýzu. Často je považováno za časově nejnáročnější část datové vědy, typicky zabírající 60-80 % času datového vědce.

```python

from sklearn import preprocessing

np.random.seed(42)

    'customer_id': range(1, 101),
    'age': np.random.randint(18, 90, size=100),
    'income': np.random.normal(50000, 15000, size=100),

    'purchase_amount': np.random.lognormal(mean=4.0, sigma=0.5, size=100),
    'customer_category': np.random.choice(['A', 'B', 'C', None], size=100, p=[0.6, 0.2, 0.15, 0.05]),
    'feedback': np.random.choice(['Positive', 'Negative', 'Neutral', None], size=100, p=[0.7, 0.1, 0.15, 0.05])
}

print(df.info())

print("\nShrnutí chybějících hodnot:")

print("\nZákladní statistiky:")
print(df.describe())
```

## Techniky čištění dat

Čištění dat zahrnuje zpracování chybějících hodnot, odstranění duplicit, opravy strukturálních chyb a řešení odlehlých hodnot.

```python
# 1. Zpracování chybějících hodnot
def handle_missing_values(df):
    print("Před zpracováním chybějících hodnot:")
    print(df.isnull().sum())
    
    # Doplnění chybějícího věku mediánem
    df['age'] = df['age'].fillna(df['age'].median())
    
    # Doplnění chybějícího příjmu průměrem
    df['income'] = df['income'].fillna(df['income'].mean())
    
    # Doplnění chybějících kategorických hodnot
    df['customer_category'] = df['customer_category'].fillna('Unknown')
    df['feedback'] = df['feedback'].fillna('No Feedback')
    
    print("\nPo zpracování chybějících hodnot:")
    print(df.isnull().sum())
    
    return df

# 2. Odstranění duplicit
def remove_duplicates(df):
    duplicate_count = df.duplicated().sum()
    print(f"Nalezeno {duplicate_count} duplicitních řádků")
    
    df = df.drop_duplicates()
    
    return df

# 3. Zpracování odlehlých hodnot
def handle_outliers(df, column, method='iqr'):
    if method == 'iqr':
        # Metoda IQR pro detekci odlehlých hodnot
        Q1 = df[column].quantile(0.25)
        Q3 = df[column].quantile(0.75)
        IQR = Q3 - Q1
        
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR
        
        print(f"Sloupec: {column}")
        print(f"Hranice IQR: [{lower_bound:.2f}, {upper_bound:.2f}]")
        
        outliers = df[(df[column] < lower_bound) | (df[column] > upper_bound)]
        print(f"Nalezeno {len(outliers)} odlehlých hodnot")
        
        # Omezení odlehlých hodnot
        df[column] = np.where(df[column] < lower_bound, lower_bound, df[column])
        df[column] = np.where(df[column] > upper_bound, upper_bound, df[column])
    
    return df

# 4. Validace a oprava dat
def validate_data(df):
    # Zajištění, že věk je v rozumném rozsahu
    df['age'] = np.where((df['age'] < 18) | (df['age'] > 100), df['age'].median(), df['age'])
    
    # Zajištění, že nákupní částka je kladná
    df['purchase_amount'] = np.where(df['purchase_amount'] <= 0, df['purchase_amount'].median(), df['purchase_amount'])
    
    return df

# Aplikace funkcí čištění na dataset
df_cleaned = df.copy()
df_cleaned = handle_missing_values(df_cleaned)
df_cleaned = remove_duplicates(df_cleaned)
df_cleaned = handle_outliers(df_cleaned, 'purchase_amount')
df_cleaned = validate_data(df_cleaned)

# Porovnání před a po čištění
print("\nPřed čištěním:")
print(df.describe())
print("\nPo čištění:")
print(df_cleaned.describe())
```

## Tvorba příznaků a transformace

Tvorba příznaků je proces vytváření nových proměnných z existujících za účelem zlepšení výkonu modelu.

```python
# Pokračujeme s našim vyčištěným datasetem
df = df_cleaned.copy()

# 1. Škálování numerických příznaků
def scale_features(df, columns, method='standard'):
    df_scaled = df.copy()
    
    if method == 'standard':
        # Standardizace (průměr=0, std=1)
        scaler = preprocessing.StandardScaler()
        df_scaled[columns] = scaler.fit_transform(df_scaled[columns])
    
    elif method == 'minmax':
        # Min-Max škálování (rozsah 0 až 1)
        scaler = preprocessing.MinMaxScaler()
        df_scaled[columns] = scaler.fit_transform(df_scaled[columns])
    
    elif method == 'robust':
        # Robustní škálování (medián=0, IQR=1)
        scaler = preprocessing.RobustScaler()
        df_scaled[columns] = scaler.fit_transform(df_scaled[columns])
    
    return df_scaled

# 2. Vytváření polynomiálních příznaků
def create_polynomial_features(df, columns, degree=2):
    poly = preprocessing.PolynomialFeatures(degree=degree, include_bias=False)
    poly_features = poly.fit_transform(df[columns])
    
    feature_names = poly.get_feature_names_out(columns)
    poly_df = pd.DataFrame(poly_features, columns=feature_names)
    
    # Kombinace s původním dataframe
    result = pd.concat([df.drop(columns, axis=1).reset_index(drop=True), poly_df], axis=1)
    
    return result

# 3. Binning spojitých proměnných
def bin_continuous_variable(df, column, n_bins=4, strategy='quantile'):
    df_binned = df.copy()
    
    if strategy == 'quantile':
        df_binned[f'{column}_binned'] = pd.qcut(df_binned[column], q=n_bins, labels=False)
    elif strategy == 'uniform':
        df_binned[f'{column}_binned'] = pd.cut(df_binned[column], bins=n_bins, labels=False)
    
    return df_binned

# 4. Vytváření interakčních příznaků
def create_interactions(df, col1, col2):
    df_interact = df.copy()
    df_interact[f'{col1}_{col2}_interaction'] = df_interact[col1] * df_interact[col2]
    return df_interact

# 5. Extrakce příznaků z dat
def extract_date_features(df, date_column):
    df_date = df.copy()
    df_date[f'{date_column}_year'] = df_date[date_column].dt.year
    df_date[f'{date_column}_month'] = df_date[date_column].dt.month
    df_date[f'{date_column}_day'] = df_date[date_column].dt.day
    df_date[f'{date_column}_dayofweek'] = df_date[date_column].dt.dayofweek
    df_date[f'{date_column}_quarter'] = df_date[date_column].dt.quarter
    
    return df_date

# Aplikace transformací na náš dataset
# Škálování numerických příznaků
num_cols = ['age', 'income', 'purchase_amount']
df_scaled = scale_features(df, num_cols, method='standard')

# Vytvoření polynomiálních příznaků
df_poly = create_polynomial_features(df, ['age', 'income'], degree=2)

# Binning proměnné příjem
df_binned = bin_continuous_variable(df, 'income', n_bins=4)

# Vytvoření interakčního příznaku
df_interact = create_interactions(df, 'age', 'purchase_amount')

# Extrakce příznaků z data
df_date = extract_date_features(df, 'purchase_date')

# Zobrazení příkladů transformovaných dat
print("Původní data:")
print(df[['age', 'income', 'purchase_amount']].head())

print("\nŠkálovaná data:")
print(df_scaled[['age', 'income', 'purchase_amount']].head())

print("\nBinnovaný příjem:")
print(df_binned[['income', 'income_binned']].head())

print("\nPříznaky extrahované z data:")
print(df_date[['purchase_date', 'purchase_date_year', 'purchase_date_month', 
               'purchase_date_day', 'purchase_date_dayofweek']].head())
```

## Práce s kategorickými daty

Kategorická data vyžadují speciální zpracování, aby mohla být použita v modelech strojového učení.

```python
# 1. One-hot kódování
def one_hot_encode(df, columns):
    df_encoded = pd.get_dummies(df, columns=columns, drop_first=False)
    return df_encoded

# 2. Label kódování
def label_encode(df, columns):
    df_encoded = df.copy()
    label_encoders = {}
    
    for col in columns:
        le = preprocessing.LabelEncoder()
        df_encoded[col] = le.fit_transform(df_encoded[col])
        label_encoders[col] = le
    
    return df_encoded, label_encoders

# 3. Ordinální kódování
def ordinal_encode(df, column, categories, ordered=True):
    df_encoded = df.copy()
    
    # Vytvoření kategorického datového typu se specifikovaným pořadím
    cat_type = pd.CategoricalDtype(categories=categories, ordered=ordered)
    df_encoded[column] = df_encoded[column].astype(cat_type)
    
    # Převod na kódy (0, 1, 2, ...)
    df_encoded[f'{column}_code'] = df_encoded[column].cat.codes
    
    return df_encoded

# 4. Target kódování
def target_encode(df, categorical_cols, target_col, smoothing=10):
    df_encoded = df.copy()
    
    # Globální průměr cílové proměnné
    global_mean = df_encoded[target_col].mean()
    
    for col in categorical_cols:
        # Seskupení podle kategorického sloupce a výpočet průměru cílové proměnné
        category_means = df_encoded.groupby(col)[target_col].agg(['mean', 'count'])
        
        # Aplikace vyhlazování
        smoothed_means = (category_means['mean'] * category_means['count'] + 
                         global_mean * smoothing) / (category_means['count'] + smoothing)
        
        # Mapování vyhlazených průměrů zpět do dataframe
        df_encoded[f'{col}_encoded'] = df_encoded[col].map(smoothed_means)
    
    return df_encoded

# Aplikace kategorických transformací
# One-hot kódování
df_onehot = one_hot_encode(df, ['customer_category', 'feedback'])

# Label kódování
df_label, label_encoders = label_encode(df, ['customer_category'])

# Ordinální kódování 
feedback_categories = ['Negative', 'Neutral', 'No Feedback', 'Positive']
df_ordinal = ordinal_encode(df, 'feedback', feedback_categories)

# Target kódování
# Nejprve vytvoříme binární cílovou proměnnou pro demonstraci
df['high_purchase'] = (df['purchase_amount'] > df['purchase_amount'].median()).astype(int)
df_target = target_encode(df, ['customer_category'], 'high_purchase')

# Zobrazení výsledků
print("Původní kategorická data:")
print(df[['customer_category', 'feedback']].head())

print("\nOne-hot kódovaná data:")
print(df_onehot.filter(like='customer_category_').head())
print(df_onehot.filter(like='feedback_').head())

print("\nLabel kódovaná data:")
print(df_label[['customer_category']].head())
print("Mapování:", {i: cat for i, cat in enumerate(label_encoders['customer_category'].classes_)})

print("\nOrdinálně kódovaná data:")
print(df_ordinal[['feedback', 'feedback_code']].head())

print("\nTarget kódovaná data:")
print(df_target[['customer_category', 'customer_category_encoded', 'high_purchase']].head())
```

## Operace agregace a seskupování

Seskupování dat a výpočet agregací je klíčovou operací při analýze dat a tvorbě příznaků.

```python
# Vytvoření vzorového maloobchodního datasetu
np.random.seed(42)
retail_data = {
    'date': pd.date_range(start='2023-01-01', periods=1000),
    'customer_id': np.random.randint(1, 101, size=1000),
    'store_id': np.random.choice(['S001', 'S002', 'S003', 'S004', 'S005'], size=1000),
    'product_category': np.random.choice(['Electronics', 'Clothing', 'Food', 'Home', 'Beauty'], size=1000),
    'product_id': np.random.randint(1, 51, size=1000),
    'quantity': np.random.randint(1, 11, size=1000),
    'unit_price': np.random.uniform(5, 100, size=1000).round(2)
}

retail_df = pd.DataFrame(retail_data)
retail_df['total_price'] = retail_df['quantity'] * retail_df['unit_price']

print("Ukázkový maloobchodní dataset:")
print(retail_df.head())

# 1. Základní agregace
# Seskupení podle obchodu a výpočet statistik
store_stats = retail_df.groupby('store_id').agg({
    'total_price': ['sum', 'mean', 'count'],
    'quantity': ['sum', 'mean']
})

print("\nStatistiky obchodů:")
print(store_stats)

# Zploštění názvů sloupců pro lepší čitelnost
store_stats.columns = ['_'.join(col).strip() for col in store_stats.columns.values]
print("\nStatistiky obchodů (zploštěné sloupce):")
print(store_stats)

# 2. Víceúrovňové seskupování
# Seskupení podle obchodu a kategorie produktu
store_category_stats = retail_df.groupby(['store_id', 'product_category']).agg({
    'total_price': 'sum',
    'quantity': 'sum',
})

print("\nStatistiky obchodů a kategorií:")
print(store_category_stats.head(10))

# 3. Seskupování a filtrování
# Nalezení transakcí s vysokou hodnotou (horních 5 % podle celkové ceny)
high_value_threshold = retail_df['total_price'].quantile(0.95)
high_value_transactions = retail_df[retail_df['total_price'] >= high_value_threshold]

print(f"\nTransakce s vysokou hodnotou (>= {high_value_threshold:.2f}):")
print(high_value_transactions.head())

# 4. Seskupování s vlastními agregačními funkcemi
def price_range(series):
    """Výpočet rozsahu mezi max a min"""
    return series.max() - series.min()

custom_agg = retail_df.groupby('product_category').agg({
    'unit_price': [np.mean, np.median, price_range],
    'quantity': [np.sum, np.mean, np.max],
    'total_price': [np.sum, np.mean, lambda x: np.percentile(x, 95)]
})

# Zploštění názvů sloupců
custom_agg.columns = ['_'.join(col).strip() for col in custom_agg.columns.values]
print("\nVlastní agregace podle kategorie produktu:")
print(custom_agg)

# 5. Rolling a Expanding agregace
# Časově založená agregace na měsíční úroveň
retail_df['month'] = retail_df['date'].dt.to_period('M')
monthly_sales = retail_df.groupby(['month', 'store_id'])['total_price'].sum().unstack()

print("\nMěsíční prodeje podle obchodu:")
print(monthly_sales.head())

# 6. Transform pro vytvoření skupinových příznaků
# Přidání sloupce pro procentuální podíl každého zákazníka na celkových útratách
customer_total = retail_df.groupby('customer_id')['total_price'].transform('sum')
total_sales = retail_df['total_price'].sum()

retail_df['customer_pct_of_total'] = (customer_total / total_sales) * 100

print("\nProcentuální podíl zákazníka na celkových útratách:")
print(retail_df[['customer_id', 'total_price', 'customer_pct_of_total']].head())

# Vizualizace výsledků agregace
plt.figure(figsize=(12, 5))

# Vykreslení prodejů podle obchodu a kategorie
plt.subplot(1, 2, 1)
store_category_pivot = pd.pivot_table(retail_df, 
                                     values='total_price',
                                     index='store_id',
                                     columns='product_category',
                                     aggfunc='sum')
store_category_pivot.plot(kind='bar', ax=plt.gca())
plt.title('Celkové prodeje podle obchodu a kategorie')
plt.ylabel('Celkové prodeje')
plt.xticks(rotation=45)
plt.legend(title='Kategorie', bbox_to_anchor=(1.05, 1), loc='upper left')

# Vykreslení trendu měsíčních celkových prodejů
plt.subplot(1, 2, 2)
monthly_sales.sum(axis=1).plot()
plt.title('Trend měsíčních prodejů')
plt.ylabel('Celkové prodeje')
plt.tight_layout()

plt.show()
```

## Práce s časovými řadami

Časové řady vyžadují specifické techniky pro zpracování a vytváření příznaků.

```python
# Vytvoření datasetu časové řady
date_rng = pd.date_range(start='2020-01-01', end='2022-12-31', freq='D')
n_dates = len(date_rng)

# Sezónní komponenta (roční sezónnost)
seasonal = 10 * np.sin(2 * np.pi * np.arange(n_dates) / 365)

# Trendová komponenta
trend = np.linspace(0, 30, n_dates)

# Náhodný šum
noise = np.random.normal(0, 5, n_dates)

# Kombinace komponent
ts_values = trend + seasonal + noise

# Vytvoření dataframe
ts_df = pd.DataFrame({
    'date': date_rng,
    'value': ts_values
})

print("Data časové řady:")
print(ts_df.head())

# 1. Převzorkování časové řady
# Seskupení na měsíční průměry
monthly_avg = ts_df.resample('M', on='date').mean()
print("\nMěsíční průměry:")
print(monthly_avg.head())

# Převzorkování na 6-hodinové intervaly a výplň dopředu
ts_df_hourly = ts_df.set_index('date').resample('6H').ffill()
print("\nPřevzorkováno na 6-hodinové intervaly (prvních 24 hodin):")
print(ts_df_hourly.head(4))

# 2. Příznaky založené na čase
def add_time_features(df, date_col='date'):
    df_time = df.copy()
    
    # Extrakce datových příznaků
    df_time['year'] = df_time[date_col].dt.year
    df_time['month'] = df_time[date_col].dt.month
    df_time['day'] = df_time[date_col].dt.day
    df_time['dayofweek'] = df_time[date_col].dt.dayofweek
    df_time['quarter'] = df_time[date_col].dt.quarter
    
    # Je víkend
    df_time['is_weekend'] = df_time[date_col].dt.dayofweek >= 5
    
    # Měsíc a den v roce pro sezónnost
    df_time['dayofyear'] = df_time[date_col].dt.dayofyear
    
    # Cyklické kódování měsíce a dne v týdnu
    df_time['month_sin'] = np.sin(2 * np.pi * df_time['month'] / 12)
    df_time['month_cos'] = np.cos(2 * np.pi * df_time['month'] / 12)
    df_time['dayofweek_sin'] = np.sin(2 * np.pi * df_time['dayofweek'] / 7)
    df_time['dayofweek_cos'] = np.cos(2 * np.pi * df_time['dayofweek'] / 7)
    
    return df_time

ts_df_features = add_time_features(ts_df)
print("\nČasová řada s dodatečnými příznaky:")
```

```python
def log_transform(df, columns):
    df_transformed = df.copy()

    return df_transformed

    return df.drop(columns=cols_to_drop)

        # Odstranění původního datového sloupce
        X_transformed.drop(self.date_column, axis=1, inplace=True)
        
        return X_transformed
```

```python
    )

def clean_and_transform_data(df, replace_missing=True, handle_outliers=True, 
                           create_features=True, drop_duplicates=True):
    """
    Čištění a transformace datasetu s konfigurovatelným nastavením.
    
    Parametry
    ----------
    df : pandas.DataFrame
        Vstupní dataframe k zpracování
    replace_missing : bool, default=True
        Zda nahradit chybějící hodnoty
    handle_outliers : bool, default=True
        Zda zpracovat odlehlé hodnoty v numerických sloupcích
    create_features : bool, default=True
        Zda vytvořit dodatečné příznaky
    drop_duplicates : bool, default=True
        Zda odstranit duplicitní řádky
        
    Vrací
    --------
    pandas.DataFrame
        Zpracovaný dataframe
    """
    result = df.copy()
    
    # Dokumentace důležitých kroků s komentáři
    if replace_missing:
        # Nahrazení chybějících hodnot vhodnými strategiemi pro každý sloupec
        result['age'] = result['age'].fillna(result['age'].median())  # Pro věk použít medián
        result['income'] = result['income'].fillna(result['income'].mean())  # Pro příjem průměr
        result['customer_category'] = result['customer_category'].fillna('Unknown')  # Pro kategorie "Unknown"
    
    if handle_outliers:
        # Omezení odlehlých hodnot na 3 standardní odchylky od průměru
        for col in ['age', 'income', 'purchase_amount']:
            mean_val = result[col].mean()
            std_val = result[col].std()
            lower_bound = mean_val - 3 * std_val
            upper_bound = mean_val + 3 * std_val
            result[col] = result[col].clip(lower=lower_bound, upper=upper_bound)
    
    if create_features:
        # Vytvoření základních příznaků, které pomáhají při analýze
        if 'purchase_date' in result.columns:
            result['purchase_month'] = result['purchase_date'].dt.month
            result['purchase_dayofweek'] = result['purchase_date'].dt.dayofweek
    
    if drop_duplicates:
        # Odstranění duplicitních řádků pro prevenci zkreslení analýzy
        initial_rows = len(result)
        result = result.drop_duplicates()
        dropped = initial_rows - len(result)
        print(f"Odstraněno {dropped} duplicitních řádků")
    
    return result

def optimize_dataframe_memory(df):
    """Optimalizace využití paměti pandas DataFrame"""
    optimized_df = df.copy()
    
    for col in optimized_df.columns:
        col_type = optimized_df[col].dtype
        
        # Numerické sloupce
        if col_type in ['int64', 'float64']:
            max_val = optimized_df[col].max()
            min_val = optimized_df[col].min()
            
            # Downcast celých čísel
            if col_type == 'int64':
                if min_val >= 0:  # Neznaménková celá čísla
                    if max_val < 256:
                        optimized_df[col] = optimized_df[col].astype('uint8')
                    elif max_val < 65536:
                        optimized_df[col] = optimized_df[col].astype('uint16')
                    elif max_val < 4294967296:
                        optimized_df[col] = optimized_df[col].astype('uint32')
                else:  # Znaménková celá čísla
                    if min_val > -128 and max_val < 128:
                        optimized_df[col] = optimized_df[col].astype('int8')
                    elif min_val > -32768 and max_val < 32768:
                        optimized_df[col] = optimized_df[col].astype('int16')
                    elif min_val > -2147483648 and max_val < 2147483648:
                        optimized_df[col] = optimized_df[col].astype('int32')
            
            # Downcast desetinných čísel
            elif col_type == 'float64':
                optimized_df[col] = pd.to_numeric(optimized_df[col], downcast='float')
        
        # Kategorické sloupce
        elif col_type == 'object':
            if len(optimized_df[col].unique()) / len(optimized_df) < 0.5:  # Pokud méně než 50% unikátních hodnot
                optimized_df[col] = optimized_df[col].astype('category')
    
    # Výpis porovnání využití paměti
    original_memory = df.memory_usage(deep=True).sum() / 1024**2
    optimized_memory = optimized_df.memory_usage(deep=True).sum() / 1024**2
    
    print(f"Původní využití paměti: {original_memory:.2f} MB")
    print(f"Optimalizované využití paměti: {optimized_memory:.2f} MB")
    print(f"Paměť zredukována o: {100 * (1 - optimized_memory/original_memory):.2f}%")
    
    return optimized_df
```

## Shrnutí

Zpracování a transformace dat jsou klíčovými kroky v pracovním postupu datové vědy, které mohou výrazně ovlivnit úspěšnost vaší analýzy. Zde jsou hlavní poznatky:

1. **Čištění dat** je často časově nejnáročnější část datové vědy, ale je kritické pro přesnou analýzu. Klíčové techniky zahrnují zpracování chybějících hodnot, odstranění duplicit a řešení odlehlých hodnot.

2. **Přeskupování dat** transformuje strukturu vašich dat podle požadavků analýzy, s využitím operací jako kontingenční tabulky, meltování a stacking/unstacking.

3. **Tvorba příznaků** vytváří nové proměnné, které mohou výrazně zlepšit výkon modelu pomocí škálování, binningu, interakcí a polynomiálních příznaků.

4. **Kódování kategorických dat** převádí kategorické proměnné na číselné reprezentace, které mohou algoritmy strojového učení zpracovat, pomocí technik jako one-hot kódování, label kódování a target kódování.

5. **Agregace a seskupování** operace umožňují sumarizaci dat a odhalení vzorů na různých úrovních granularity.

6. **Transformace časových řad** využívá specializované techniky jako převzorkování, příznaky zpoždění a klouzavé statistiky k extrakci časových vzorů.

7. **Datové pipeline** vytvářejí reprodukovatelné, automatizované pracovní postupy, které zjednodušují cestu dat od surových dat k datům připraveným pro analýzu.

8. **Osvědčené postupy** zdůrazňují efektivní, dobře zdokumentovaný a udržitelný kód pro úlohy zpracování dat.

Zvládnutím těchto technik zpracování a transformace dat můžete efektivněji připravit vaše data pro vizualizaci, modelování a analýzu, což vede k přesnějším a smysluplnějším poznatkům.
