## 1. Úvod do datové etiky a ochrany osobních údajů

Datová etika zahrnuje morální závazky a odpovědné postupy týkající se sběru, zpracování a analýzy dat. Jako datoví vědci je pochopení těchto principů klíčové pro udržení důvěry a zajištění toho, aby naše práce přinášela společnosti prospěch.

## 2. Klíčové etické principy v datové vědě

Několik základních etických principů řídí odpovědnou datovou vědu:

- **Transparentnost**: Otevřenost ohledně způsobu sběru a využití dat
- **Spravedlnost**: Zajištění, že algoritmy nediskriminují určité skupiny
- **Odpovědnost**: Přebírání zodpovědnosti za výsledky rozhodnutí založených na datech
- **Soukromí**: Ochrana citlivých informací a respektování práv jednotlivců
- **Prospěšnost**: Usilování o pozitivní dopad prostřednictvím práce v datové vědě

```python
# Příklad: Dokumentace původu a kroků zpracování dat
def dokumentace_zpracovani_dat(data, zdroj, transformace=None, ucel=None):
    """
    Dokumentuje zdroj a transformace datasetu pro zajištění transparentnosti.
    
    Parametry:
    -----------
    data : DataFrame
        Dokumentovaný dataset
    zdroj : str
        Odkud data pocházejí
    transformace : list
        Seznam transformací aplikovaných na data
    ucel : str
        Zamýšlené použití dat
    
    Vrací:
    --------
    dict
        Metadata o datasetu
    """
    if transformace is None:
        transformace = []
    
    metadata = {
        "zdroj": zdroj,
        "datum_sbehu": pd.Timestamp.now().strftime("%Y-%m-%d"),
        "radky": len(data),
        "sloupce": list(data.columns),
        "transformace": transformace,
        "ucel": ucel
    }
    
    return metadata

# Příklad použití

    print(f"{klic}: {hodnota}")
```

## 3. Předpisy o ochraně osobních údajů a dodržování předpisů

Datoví vědci musí být obeznámeni s klíčovými předpisy upravujícími ochranu osobních údajů, včetně:

- **GDPR** (Obecné nařízení o ochraně osobních údajů) v Evropě
- **CCPA** (Kalifornský zákon o ochraně soukromí spotřebitelů) v Kalifornii
- **HIPAA** (Zákon o přenositelnosti a odpovědnosti za zdravotní pojištění) pro zdravotnická data
- **FERPA** (Zákon o právech rodiny na vzdělání a soukromí) pro vzdělávací data

```python
# Příklad: Jednoduchý kontrolní nástroj pro dodržování GDPR
def kontrola_souladu_s_gdpr(dataframe, kategorie_sloupcu=None):
    """
    Základní kontrola potenciálně citlivých polí v dataframe z hlediska GDPR.
    
    Parametry:
    -----------
    dataframe : pandas DataFrame
        Dataset ke kontrole
    column_categories : dict
        Slovník mapující názvy sloupců na kategorie dat
        
    Vrací:
    --------
    dict
        Zpráva o souladu s potenciálními problémy
    """
    if kategorie_sloupcu is None:
        # Výchozí kategorizace podle běžných názvů sloupců
        kategorie_sloupcu = {}
        
        for sloupec in dataframe.columns:
            sloupec_lower = sloupec.lower()
            if any(term in sloupec_lower for term in ['jmeno', 'uzivatel', 'zakaznik', 'klient']):
                kategorie_sloupcu[sloupec] = 'PII'
            elif any(term in sloupec_lower for term in ['email', 'telefon', 'adresa', 'psc', 'mesto']):
                kategorie_sloupcu[sloupec] = 'Kontakt'
            elif any(term in sloupec_lower for term in ['rc', 'rodne', 'id', 'prukaz']):
                kategorie_sloupcu[sloupec] = 'Státní ID'
            elif any(term in sloupec_lower for term in ['zdravotni', 'nemoc', 'stav', 'lecba']):
                kategorie_sloupcu[sloupec] = 'Zdraví'
            elif any(term in sloupec_lower for term in ['rasa', 'nabozenstvi', 'politika', 'odbory', 'orientace']):
                kategorie_sloupcu[sloupec] = 'Zvláštní kategorie'
    
    # Generování zprávy
    citlive_kategorie = {
        'PII': 'Osobní identifikační informace',
        'Kontakt': 'Kontaktní informace',
        'Státní ID': 'Čísla státních průkazů',
        'Zdraví': 'Zdravotní informace',
        'Zvláštní kategorie': 'Data zvláštních kategorií'
    }
    
    zprava = {
        'potencialne_citlive_sloupce': [],
        'doporucene_akce': [],
        'prava_subjektu_udaju': [
            'Právo na informace',
            'Právo na přístup',
            'Právo na opravu',
            'Právo na výmaz',
            'Právo na omezení zpracování',
            'Právo na přenositelnost údajů',
            'Právo vznést námitku'
        ]
    }
    
    for sloupec, kategorie in kategorie_sloupcu.items():
        if kategorie in citlive_kategorie:
            zprava['potencialne_citlive_sloupce'].append({
                'sloupec': sloupec,
                'kategorie': kategorie,
                'popis': citlive_kategorie.get(kategorie, 'Jiná citlivá data')
            })
            
            if kategorie == 'PII' or kategorie == 'Kontakt':
                zprava['doporucene_akce'].append(f"Zvažte anonymizaci {sloupec}")
            elif kategorie == 'Státní ID':
                zprava['doporucene_akce'].append(f"Šifrujte {sloupec} a omezte přístup")
            elif kategorie == 'Zdraví' or kategorie == 'Zvláštní kategorie':
                zprava['doporucene_akce'].append(f"Získejte výslovný souhlas pro {sloupec} a zdůvodněte účel")
    
    return zprava

# Příklad použití
zprava_o_souladu = kontrola_souladu_s_gdpr(citliva_data)
print("\nZpráva o kontrole souladu s GDPR:")
print(f"Potenciální citlivé sloupce: {len(zprava_o_souladu['potencialne_citlive_sloupce'])}")
for sloupec in zprava_o_souladu['potencialne_citlive_sloupce']:
    print(f"- {sloupec['sloupec']} ({sloupec['kategorie']}): {sloupec['popis']}")
print("\nDoporučené akce:")
for akce in zprava_o_souladu['doporucene_akce']:
    print(f"- {akce}")
```

## 4. Techniky anonymizace dat

Anonymizační techniky pomáhají chránit soukromí jednotlivců a zároveň umožňují smysluplnou analýzu dat.

```python
# Příklad: Základní anonymizační techniky
def anonymizovat_data(df):
    """
    Aplikace základních anonymizačních technik na dataframe.
    
    Parametry:
    -----------
    df : pandas DataFrame
        Původní dataframe s citlivými daty
        
    Vrací:
    --------
    pandas DataFrame
        Anonymizovaná verze dataframe
    """
    df_anon = df.copy()
    
    # 1. Maskování identifikátorů
    if 'jmeno' in df_anon.columns:
        df_anon['jmeno'] = ['Osoba_' + str(i+1) for i in range(len(df_anon))]
    
    if 'email' in df_anon.columns:
        df_anon['email'] = ['uzivatel' + str(i+1) + '@example.com' for i in range(len(df_anon))]
    
    # 2. Generalizace - snížení přesnosti numerických dat
    if 'vek' in df_anon.columns:
        # Věk do skupin
        bins = [0, 18, 30, 45, 60, 100]
        labels = ['<18', '18-30', '31-45', '46-60', '60+']
        df_anon['vek'] = pd.cut(df_anon['vek'], bins=bins, labels=labels)
    
    if 'prijem' in df_anon.columns:
        # Příjem do skupin
        bins = [0, 50000, 75000, 100000, 150000, float('inf')]
        labels = ['<50k', '50k-75k', '75k-100k', '100k-150k', '150k+']
        df_anon['prijem'] = pd.cut(df_anon['prijem'], bins=bins, labels=labels)
    
    # 3. Potlačení dat - nahrazení citlivých zdravotních dat obecnějšími kategoriemi
    if 'zdravotni_stav' in df_anon.columns:
        stav_mapa = {
            'Žádný': 'Žádný stav',
            'Hypertenze': 'Kardiovaskulární',
            'Diabetes': 'Metabolický',
            'Astma': 'Respirační',
        }
        df_anon['zdravotni_stav'] = df_anon['zdravotni_stav'].map(
            lambda x: stav_mapa.get(x, 'Jiný stav')
        )
    
    return df_anon

# Anonymizovat naše citlivá data
anonymizovana_data = anonymizovat_data(citliva_data)
print("\nAnonymizovaná data:")
print(anonymizovana_data)

# Porovnání původních a anonymizovaných dat pro ověření ochrany soukromí
print("\nPůvodní vs. anonymizovaná data (zvýrazněné rozdíly):")
for sloupec in citliva_data.columns:
    rozdilne = citliva_data[sloupec] != anonymizovana_data[sloupec]
    pocet_rozdilnych = rozdilne.sum()
    print(f"Sloupec '{sloupec}': {pocet_rozdilnych}/{len(citliva_data)} hodnot změněno")
```

## 5. Identifikace a zmírnění předpojatosti

Předpojatost v datech může vést k nespravedlivým nebo diskriminačním výsledkům v rozhodnutích založených na datech.

```python
# Import knihoven pro detekci předpojatosti
from aif360.datasets import BinaryLabelDataset
from aif360.metrics import BinaryLabelDatasetMetric
import pandas as pd

# Příklad: Vytvoření předpojatého datasetu
np.random.seed(42)

# Generování syntetických dat s předpojatostí
predpojata_data = pd.DataFrame({

    predpojata_data['vek'] * 0.1 +
    np.random.normal(0, 5, velikost)

schvaleni_podle_pohlavi = predpojata_data.groupby('pohlavi')['pujcka_schvalena'].mean()
print("Míra schválení podle pohlaví:")
print(schvaleni_podle_pohlavi)

# Výpočet metrik předpojatosti
def vypocitat_metriky_predpojatosti(data, chraneny_atribut, vysledek):
    """
    Výpočet základních metrik předpojatosti pro dataset.
    
    Parametry:
    -----------
    data : pandas DataFrame
        Dataset k analýze
    chraneny_atribut : str
        Název sloupce chráněného atributu (např. 'pohlavi')
    vysledek : str
        Název sloupce výsledkové proměnné (např. 'pujcka_schvalena')
        
    Vrací:
    --------
    dict
        Slovník metrik předpojatosti
    """
    skupiny = data[chraneny_atribut].unique()
    metriky = {}
    
    # Výpočet míry schválení podle skupiny
    mira_podle_skupiny = {}
    for skupina in skupiny:
        skupina_data = data[data[chraneny_atribut] == skupina]
        mira_schvaleni = skupina_data[vysledek].mean()
        mira_podle_skupiny[skupina] = mira_schvaleni
    
    # Výpočet disparit
    if len(skupiny) >= 2:
        zakladni_skupina = skupiny[0]
        for skupina in skupiny[1:]:
            disparita = mira_podle_skupiny[skupina] / mira_podle_skupiny[zakladni_skupina]
            metriky[f'disparita_{zakladni_skupina}_vs_{skupina}'] = disparita
    
    # Výpočet celkových metrik
    metriky['mira_podle_skupiny'] = mira_podle_skupiny
    metriky['max_disparita'] = max(mira_podle_skupiny.values()) / min(mira_podle_skupiny.values())
    metriky['rozdil_statisticke_parity'] = max(mira_podle_skupiny.values()) - min(mira_podle_skupiny.values())
    
    return metriky

# Výpočet metrik předpojatosti
metriky_predpojatosti = vypocitat_metriky_predpojatosti(predpojata_data, 'pohlavi', 'pujcka_schvalena')
print("\nMetriky předpojatosti:")
for metrika, hodnota in metriky_predpojatosti.items():
    if metrika == 'mira_podle_skupiny':
        print(f"{metrika}:")
        for skupina, mira in hodnota.items():
            print(f"  {skupina}: {mira:.4f}")
    else:
        print(f"{metrika}: {hodnota:.4f}")

# Příklad: Jednoduché zmírnění předpojatosti pomocí převážení
def zmirit_predpojatost_prevazenim(data, chraneny_atribut, vysledek):
    """
    Aplikuje jednoduché převážení k zmírnění předpojatosti.
    
    Parametry:
    -----------
    data : pandas DataFrame
        Dataset ke zpracování
    chraneny_atribut : str
        Název sloupce chráněného atributu (např. 'pohlavi')
    vysledek : str
        Název sloupce výsledkové proměnné (např. 'pujcka_schvalena')
        
    Vrací:
    --------
    pandas DataFrame
        Převážený dataset s váhovým sloupcem
    """
    # Výpočet celkové míry schválení
    celkova_mira = data[vysledek].mean()
    
    # Výpočet vah pro každou skupinu
    vysledek = data.copy()
    skupiny = data[chraneny_atribut].unique()
    
    for skupina in skupiny:
        maska = (data[chraneny_atribut] == skupina)
        skupina_data = data[maska]
        mira_skupiny = skupina_data[vysledek].mean()
        
        # Výpočet vah pro vyrovnání míry schválení
        if mira_skupiny > 0:
            vaha_schvaleno = celkova_mira / mira_skupiny
            vaha_zamitnuto = (1 - celkova_mira) / (1 - mira_skupiny)
            
            # Aplikace vah
            vysledek.loc[maska & (data[vysledek] == 1), 'vaha'] = vaha_schvaleno
            vysledek.loc[maska & (data[vysledek] == 0), 'vaha'] = vaha_zamitnuto
    
    return vysledek

# Aplikace zmírnění předpojatosti
zmirnena_data = zmirit_predpojatost_prevazenim(predpojata_data, 'pohlavi', 'pujcka_schvalena')
print("\nUkázka převážených dat:")
print(zmirnena_data[['pohlavi', 'pujcka_schvalena', 'vaha']].head(10))

# Ověření účinnosti zmírnění
print("\nEfektivní míry schválení po převážení:")
for skupina in predpojata_data['pohlavi'].unique():
    skupina_data = zmirnena_data[zmirnena_data['pohlavi'] == skupina]
    vazene_schvaleno = (skupina_data['pujcka_schvalena'] * skupina_data['vaha']).sum()
    celkova_vaha = skupina_data['vaha'].sum()
    efektivni_mira = vazene_schvaleno / celkova_vaha
    print(f"{skupina}: {efektivni_mira:.4f}")
```

## 6. Etický sběr dat a souhlas

Správné mechanismy souhlasu a transparentní postupy sběru dat jsou základem etické datové vědy.

```python
# Příklad: Základní systém správy souhlasů
class SpravaSouhlasu:
    """Jednoduchý systém pro správu souhlasu uživatelů se zpracováním dat."""
    
    def __init__(self):
        self.zaznamy_souhlasu = {}
        self.ucely_zpracovani = [
            "analyza", 
            "marketing", 
            "zlepseni_produktu",
            "vyzkum"
        ]
    
    def zaznam_souhlasu(self, id_uzivatele, ucely, casove_razitko=None, doba_platnosti_dny=365):
        """
        Zaznamenat souhlas uživatele pro konkrétní účely zpracování dat.
        
        Parametry:
        -----------
        id_uzivatele : str
            Jedinečný identifikátor uživatele
        ucely : list
            Seznam účelů, ke kterým uživatel udělil souhlas
        casove_razitko : datetime, volitelné
            Kdy byl souhlas udělen (výchozí hodnota je nyní)
        doba_platnosti_dny : int, volitelné
            Počet dnů do vypršení platnosti souhlasu
        
        Vrací:
        --------
        bool
            True, pokud byl souhlas úspěšně zaznamenán
        """
        if casove_razitko is None:
            casove_razitko = pd.Timestamp.now()
            
        doba_platnosti = casove_razitko + pd.Timedelta(days=doba_platnosti_dny)
        
        # Validace účelů
        platne_ucely = [u for u in ucely if u in self.ucely_zpracovani]
        
        self.zaznamy_souhlasu[id_uzivatele] = {
            'casove_razitko': casove_razitko,
            'doba_platnosti': doba_platnosti,
            'ucely': platne_ucely,
            'aktivni': True
        }
        
        return True
    
    def odvolat_souhlas(self, id_uzivatele, ucely=None):
        """Odvolat souhlas pro všechny nebo konkrétní účely."""
        if id_uzivatele not in self.zaznamy_souhlasu:
            return False
            
        if ucely is None:
            # Odvolat všechny souhlasy
            self.zaznamy_souhlasu[id_uzivatele]['aktivni'] = False
        else:
            # Odvolat souhlas pro konkrétní účely
            aktualni_ucely = self.zaznamy_souhlasu[id_uzivatele]['ucely']
            self.zaznamy_souhlasu[id_uzivatele]['ucely'] = [
                u for u in aktualni_ucely if u not in ucely
            ]
            
        return True
    
    def kontrola_souhlasu(self, id_uzivatele, ucel):
        """Zkontrolovat, zda uživatel udělil souhlas ke konkrétnímu účelu."""
        if id_uzivatele not in self.zaznamy_souhlasu:
            return False
            
        zaznam = self.zaznamy_souhlasu[id_uzivatele]
        
        # Zkontrolovat, zda je souhlas aktivní a nevypršel
        if not zaznam['aktivni'] or pd.Timestamp.now() > zaznam['doba_platnosti']:
            return False
            
        # Zkontrolovat, zda je účel zahrnutý
        return ucel in zaznam['ucely']
    
    def ziskat_stav_souhlasu_uzivatele(self, id_uzivatele):
        """Získat úplný stav souhlasu uživatele."""
        if id_uzivatele not in self.zaznamy_souhlasu:
            return None
            
        return self.zaznamy_souhlasu[id_uzivatele]

# Příklad použití
system_souhlasu = SpravaSouhlasu()

# Zaznamenat souhlas pro některé uživatele
system_souhlasu.zaznam_souhlasu('uzivatel1', ['analyza', 'zlepseni_produktu'])
system_souhlasu.zaznam_souhlasu('uzivatel2', ['analyza', 'marketing', 'vyzkum'])
system_souhlasu.zaznam_souhlasu('uzivatel3', ['vyzkum'])

# Zkontrolovat souhlas před zpracováním dat
uzivatele_ke_zpracovani = ['uzivatel1', 'uzivatel2', 'uzivatel3', 'uzivatel4']
ucel = 'analyza'

print(f"\nKontrola souhlasu uživatelů pro účel '{ucel}':")
```

## 7. Diferenciální soukromí

Diferenciální soukromí je technika, která přidává statistický šum k datům pro ochranu soukromí jednotlivců při zachování celkové statistické platnosti.

```python
# Import knihoven
import numpy as np
import matplotlib.pyplot as plt

# Příklad: Jednoduchá implementace diferenciálního soukromí
def pridat_laplaceuv_sum(data, citlivost, epsilon):
    """
    Přidá Laplaceův šum k datům pro diferenciální soukromí.
    
    Parametry:
    -----------
    data : array-like
        Původní hodnoty dat
    citlivost : float
        Maximální změna ve funkci, pokud se změní jeden záznam
    epsilon : float
        Parametr soukromí (menší = větší soukromí)
        
    Vrací:
    --------
    array-like
        Data s přidaným šumem pro zachování soukromí
    """
    meritko = citlivost / epsilon
    sum = np.random.laplace(0, meritko, size=len(data))
    return data + sum

# Vytvoření vzorových citlivých dat
np.random.seed(42)
puvodni_veky = np.random.normal(35, 10, 1000).astype(int)
puvodni_veky = np.clip(puvodni_veky, 18, 80)  # Omezení na realistický rozsah věku

# Výpočet skutečného průměrného věku
skutecny_prumer = np.mean(puvodni_veky)

# Aplikace diferenciálního soukromí s různými úrovněmi soukromí
hodnoty_epsilon = [0.01, 0.1, 0.5, 1.0, 10.0]
citlivost = 1  # Předpokládáme, že změna věku jedné osoby změní výsledek maximálně o 1
privatni_prumery = []

for epsilon in hodnoty_epsilon:
    # Přidání šumu ke všem věkům
    privatni_veky = pridat_laplaceuv_sum(puvodni_veky, citlivost, epsilon)
    # Výpočet zašuměného průměru
    privatni_prumer = np.mean(privatni_veky)
    privatni_prumery.append(privatni_prumer)

# Zobrazení výsledků
print("\nVýsledky diferenciálního soukromí:")
print(f"Skutečný průměrný věk: {skutecny_prumer:.2f}")
print("\nOdhady průměrného věku s diferenciálním soukromím:")
for epsilon, prumer in zip(hodnoty_epsilon, privatni_prumery):
    chyba = abs(prumer - skutecny_prumer)
    print(f"Epsilon = {epsilon:5.2f}: {prumer:.2f} (chyba: {chyba:.2f})")

# Vizualizace
plt.figure(figsize=(10, 6))
plt.hist(puvodni_veky, bins=30, alpha=0.5, label="Původní")

# Přidání histogramu dat s různými úrovněmi soukromí
epsilon_k_zobrazeni = 0.1

plt.hist(privatni_data, bins=30, alpha=0.5, label=f"ε = {epsilon_k_zobrazeni}")

plt.axvline(skutecny_prumer, color='black', linestyle='--', label=f"Skutečný průměr: {skutecny_prumer:.2f}")
plt.axvline(np.mean(privatni_data), color='red', linestyle='--', 
            label=f"Soukromý průměr: {np.mean(privatni_data):.2f}")

plt.title("Vliv diferenciálního soukromí na data o věku")
plt.xlabel("Věk")
plt.ylabel("Počet")
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Příklad: Dotazy na počet s ochranou soukromí
def pocet_s_ochranou_soukromi(data, dotazovaci_funkce, epsilon=0.1):
    """
    Provádí dotazy na počet s diferenciálním soukromím.
    
    Parametry:
    -----------
    data : DataFrame
        Dataset pro dotazování
    dotazovaci_funkce : function
        Funkce, která vrací booleovskou masku pro záznamy k započítání
    epsilon : float
        Parametr soukromí
    
    Vrací:
    --------
    int
        Počet s ochranou soukromí
    """
    # Spočítat záznamy odpovídající dotazu
    skutecny_pocet = dotazovaci_funkce(data).sum()
    
    # Přidat Laplaceův šum
    citlivost = 1  # Jedna osoba může změnit počet maximálně o 1
    sum = np.random.laplace(0, citlivost / epsilon)
    
    # Vrátit zašuměný počet (zaokrouhlit a zajistit nezápornost)
    zasumeny_pocet = max(0, round(skutecny_pocet + sum))
    return zasumeny_pocet

# Příklady dotazů na naše citlivá data
data_platu = pd.DataFrame({

    "prijem > 200k": lambda df: df['prijem'] > 200000,
    "prijem < 50k": lambda df: df['prijem'] < 50000
}

# Spustit každý dotaz s ochranou soukromí
print("\nDotazy na počet s ochranou soukromí:")

    # Skutečný počet
    skutecny_pocet = dotaz(data_platu).sum()
    
    # Počty s ochranou soukromí s různými hodnotami epsilon
    for epsilon in [0.1, 1.0, 10.0]:
        soukromy_pocet = pocet_s_ochranou_soukromi(data_platu, dotaz, epsilon)
        chyba = abs(soukromy_pocet - skutecny_pocet)
        print(f"Dotaz: {nazev}, ε = {epsilon:4.1f}: Skutečný: {skutecny_pocet}, Soukromý: {soukromy_pocet}, Chyba: {chyba}")
```

## 8. Zodpovědné ukládání a sdílení dat

Správné postupy ukládání, zabezpečení a sdílení dat jsou nezbytné pro ochranu citlivých informací.

```python
# Příklad: Jednoduché šifrování a bezpečné zpracování dat
import hashlib
import os
import base64
from cryptography.fernet import Fernet
import json

class BezpecneZpracovaniDat:
    """Jednoduchá třída pro bezpečné zpracování, ukládání a sdílení dat."""
    
    def __init__(self, sifrovaci_klic=None):
        """Inicializace s volitelným šifrovacím klíčem nebo generování nového."""
        if sifrovaci_klic is None:
            self.klic = Fernet.generate_key()
        else:
            self.klic = sifrovaci_klic
        
        self.sifra = Fernet(self.klic)
    
    def zasifrovat_data(self, data):
        """Zašifrovat data (řetězec nebo serializovatelný objekt)."""
        if not isinstance(data, str):
            # Nejprve převést na JSON řetězec
            data = json.dumps(data)
            
        # Převést na bajty a zašifrovat
        data_bajty = data.encode('utf-8')
        zasifrovana_data = self.sifra.encrypt(data_bajty)
        
        # Vrátit jako base64 řetězec pro snazší ukládání
        return base64.b64encode(zasifrovana_data).decode('utf-8')
    
    def desifrovat_data(self, zasifrovana_data, jako_json=False):
        """Dešifrovat data z base64 řetězce do původní formy."""
        # Převést z base64 řetězce na bajty
        zasifrovane_bajty = base64.b64decode(zasifrovana_data)
        
        # Dešifrovat
        desifrovane_bajty = self.sifra.decrypt(zasifrovane_bajty)
        desifrovana_data = desifrovane_bajty.decode('utf-8')
        
        # Převést z JSON, pokud je potřeba
        if jako_json:
            return json.loads(desifrovana_data)
        return desifrovana_data
    
    def hashovat_identifikator(self, identifikator):
        """Vytvořit bezpečný jednosměrný hash identifikátoru."""
        # Přidat sůl pro zabránění útokům vyhledáváním
        sul = os.urandom(32)
        
        # Vytvořit hash
        klic = hashlib.pbkdf2_hmac(
            'sha256',
            identifikator.encode('utf-8'),
            sul,
            100000  # Počet iterací
        )
        
        # Kombinovat sůl a klíč pro ukládání
        return base64.b64encode(sul + klic).decode('utf-8')
    
    def ulozit_zasifrovana_data(self, data, soubor):
        """Uložit zašifrovaná data do souboru."""
        zasifrovana_data = self.zasifrovat_data(data)
        with open(soubor, 'w') as f:
            f.write(zasifrovana_data)
        return True
    
    def nacist_zasifrovana_data(self, soubor, jako_json=False):
        """Načíst a dešifrovat data ze souboru."""
        with open(soubor, 'r') as f:
            zasifrovana_data = f.read()
        return self.desifrovat_data(zasifrovana_data, jako_json)
    
    def bezpecne_sdilet_data(self, data, uroven_soukromi='vysoka'):
        """
        Připraví data pro bezpečné sdílení na základě úrovně soukromí.
        
        Parametry:
        -----------
        data : DataFrame
            Data ke sdílení
        uroven_soukromi : str
            'nízká', 'střední' nebo 'vysoká'
            
        Vrací:
        --------
        dict
            Připravená data a pokyny pro sdílení
        """
        kopie_dat = data.copy()
        
        if uroven_soukromi == 'vysoka':
            # Odstranit všechny přímé identifikátory a zašifrovat citlivá pole
            if 'jmeno' in kopie_dat:
                kopie_dat = kopie_dat.drop(columns=['jmeno'])
            if 'email' in kopie_dat:
                kopie_dat = kopie_dat.drop(columns=['email'])
            
            # Přidat šum k numerickým polím
            for sloupec in kopie_dat.select_dtypes(include=[np.number]).columns:
                # Přidat malé množství šumu (1% směrodatné odchylky)
                sum = np.random.normal(0, kopie_dat[sloupec].std() * 0.01, len(kopie_dat))
                kopie_dat[sloupec] = kopie_dat[sloupec] + sum
            
            # Generovat zašifrovanou verzi
            zasifrovano = self.zasifrovat_data(kopie_dat.to_dict())
            
            return {
                'data': zasifrovano,
                'typ': 'zasifrovano',
                'pokyny': """
                Tato data jsou zašifrována a byly z nich odstraněny identifikátory.
                K dešifrování použijte bezpečný klíč sdílený samostatně.
                Nepokoušejte se znovu identifikovat jednotlivce v tomto datasetu.
                """
            }
            
        elif uroven_soukromi == 'stredni':
            # Pseudonymizace identifikátorů
            if 'jmeno' in kopie_dat:
                kopie_dat['jmeno'] = [f"Subjekt_{i}" for i in range(len(kopie_dat))]
                
            # Generalizace některých polí
            if 'vek' in kopie_dat:
                bins = [0, 18, 30, 45, 60, 100]
                labels = ['<18', '18-30', '31-45', '46-60', '60+']
                kopie_dat['vek'] = pd.cut(kopie_dat['vek'], bins=bins, labels=labels)
                
            return {
                'data': kopie_dat.to_dict(),
                'typ': 'pseudonymizovano',
                'pokyny': """
                Tato data byla pseudonymizována.
                Nepokoušejte se znovu identifikovat jednotlivce.
                Používejte pouze pro dohodnutý účel.
                """
            }
            
        else:  # 'nizká'
            # Jen základní agregace
            agregovano = {}
            
            # Agregace numerických sloupců
            for sloupec in kopie_dat.select_dtypes(include=[np.number]).columns:
                agregovano[sloupec] = {
                    'prumer': kopie_dat[sloupec].mean(),
                    'median': kopie_dat[sloupec].median(),
                    'min': kopie_dat[sloupec].min(),
                    'max': kopie_dat[sloupec].max(),
                    'std': kopie_dat[sloupec].std()
                }
            
            # Agregace kategorických sloupců
            for sloupec in kopie_dat.select_dtypes(include=['object', 'category']).columns:
                if len(kopie_dat[sloupec].unique()) < 20:  # Pouze pokud nemá příliš mnoho kategorií
                    agregovano[sloupec] = kopie_dat[sloupec].value_counts().to_dict()
            
            return {
                'data': agregovano,
                'typ': 'agregovano',
                'pokyny': """
                Tato data jsou agregována a neobsahují žádné individuální záznamy.
                """
            }

# Příklad použití
spravce = BezpecneZpracovaniDat()

# Zašifrovat a dešifrovat jednoduchá data
citliva_zprava = "Toto obsahuje osobní údaje: RČ 123-45-6789"
zasifrovano = spravce.zasifrovat_data(citliva_zprava)
print("\nPříklad šifrování:")
print(f"Původní: {citliva_zprava}")
print(f"Zašifrováno: {zasifrovano}")
print(f"Dešifrováno: {spravce.desifrovat_data(zasifrovano)}")

# Hashování identifikátorů pro pseudonymizaci
email_zakaznika = "zakaznik@example.com"
hashovany_id = spravce.hashovat_identifikator(email_zakaznika)
print(f"\nHashovaný identifikátor: {hashovany_id[:20]}...")  # Ukázat jen část

# Příklad s našimi citlivými daty
sdileno_vysoka = spravce.bezpecne_sdilet_data(citliva_data, 'vysoka')
sdileno_stredni = spravce.bezpecne_sdilet_data(citliva_data, 'stredni')
sdileno_nizka = spravce.bezpecne_sdilet_data(citliva_data, 'nizka')

print("\nPříklady sdílení dat:")
print(f"Vysoké soukromí - typ: {sdileno_vysoka['typ']}")
print(f"Střední soukromí - typ: {sdileno_stredni['typ']}")
print(f"Nízké soukromí - typ: {sdileno_nizka['typ']}")

# Ukázat data se střední úrovní soukromí
if sdileno_stredni['typ'] == 'pseudonymizovano':
    stredni_df = pd.DataFrame.from_dict(sdileno_stredni['data'])
    print("\nStřední úroveň soukromí - pseudonymizovaná data:")
    print(stredni_df)

# Ukázat agregovaná data s nízkou úrovní soukromí
if sdileno_nizka['typ'] == 'agregovano':
    print("\nNízká úroveň soukromí - agregovaná data:")
    for sloupec, statistiky in sdileno_nizka['data'].items():
        print(f"\nStatistiky sloupce {sloupec}:")
        for nazev_stat, hodnota_stat in statistiky.items():
            print(f"  {nazev_stat}: {hodnota_stat}")
```

## 10. Shrnutí

Datová etika a ochrana osobních údajů jsou základními aspekty odpovědné datové vědy. Klíčové principy zahrnují:

1. **Ochrana soukromí**: Používání technik jako anonymizace, diferenciální soukromí a bezpečné zpracování dat k ochraně citlivých informací.

2. **Spravedlnost a nediskriminace**: Identifikace a zmírnění předpojatosti v datech a algoritmech k zajištění spravedlivých výsledků.

3. **Transparentnost**: Udržování jasné dokumentace o zdrojích dat, metodách zpracování a rozhodovacích procesech modelů.

4. **Souhlas a kontrola**: Zajištění, aby jednotlivci měli informace a kontrolu nad tím, jak jsou jejich data používána.

5. **Dodržování předpisů**: Dodržování nařízení jako GDPR, CCPA a HIPAA pro udržení právních a etických standardů.

6. **Etický vývoj AI**: Budování modelů s ohledem na spravedlnost, odpovědnost a transparentnost jako základní prvky.

7. **Bezpečnost**: Implementace řádných opatření pro zabezpečení dat, aby se zabránilo neoprávněnému přístupu nebo únikům.

Jako datoví vědci máme odpovědnost zvážit etické důsledky naší práce a upřednostňovat soukromí a spravedlnost. To zahrnuje činit vědomá rozhodnutí v průběhu celého životního cyklu dat - od sběru přes ukládání, analýzu až po sdílení - abychom zajistili, že naše práce přináší společnosti prospěch a zároveň respektuje práva jednotlivců.

Oblast datové etiky se neustále vyvíjí a pro každého datového profesionála je nezbytné být informován o nejlepších postupech a vznikajících standardech. Začleněním etických úvah do našich pracovních postupů můžeme budovat důvěryhodnější a prospěšnější aplikace datové vědy.
