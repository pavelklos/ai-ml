## 1. Úvod do načítání dat

Načítání dat je jedním z prvních kroků v každém projektu datové vědy. Schopnost importovat data z různých zdrojů je základem pro provádění analýz a vytváření modelů. Python nabízí mnoho knihoven, které umožňují jednoduché a efektivní načítání dat z různých zdrojů.

Mezi nejčastější formáty dat v datové vědě patří:
- CSV (hodnoty oddělené čárkami)
- Excel tabulky
- JSON (JavaScript Object Notation)
- SQL databáze
- Webová API

V této příručce prozkoumáme, jak načítat data z těchto různých zdrojů pomocí populárních knihoven Pythonu jako pandas, requests a SQLAlchemy.

```python
# Běžně používané knihovny pro načítání dat
import pandas as pd
import numpy as np
import json
import requests
import sqlite3
from sqlalchemy import create_engine
import os

# Kontrola verze pandas
print(f"Verze Pandas: {pd.__version__}")
```

## 2. Načítání souborů CSV

CSV (hodnoty oddělené čárkami) je jedním z nejběžnějších formátů pro tabulková data. Pandas poskytuje funkci `read_csv()` pro snadný import CSV souborů.

```python
# Základní načítání CSV
df_csv = pd.read_csv('data.csv')
print("Základní import CSV:")
print(df_csv.head())

# CSV s vlastním oddělovačem
df_custom = pd.read_csv('data.txt', delimiter='\t')  # Soubor oddělený tabulátory
print("\nSoubor oddělený tabulátory:")
print(df_custom.head())

# Specifikace datových typů sloupců
df_types = pd.read_csv('data.csv', dtype={'ID': str, 'Value': float})
print("\nSpecifikace datových typů sloupců:")
print(df_types.dtypes)

# Zpracování datumů
df_dates = pd.read_csv('data.csv', parse_dates=['Date'])
print("\nParsování datumů:")
print(df_dates.dtypes)

# Načtení pouze určitých sloupců
df_cols = pd.read_csv('data.csv', usecols=['Name', 'Value'])
print("\nVýběr konkrétních sloupců:")
print(df_cols.head())

# Přeskočení řádků
df_skip = pd.read_csv('data.csv', skiprows=2)  # Přeskočí první dva řádky
print("\nPřeskočení řádků:")
print(df_skip.head())

# Nastavení indexového sloupce
df_index = pd.read_csv('data.csv', index_col='ID')
print("\nNastavení indexového sloupce:")
print(df_index.head())

# Čtení CSV z URL
url = "https://raw.githubusercontent.com/datasets/iris/master/data/iris.csv"
df_url = pd.read_csv(url)
print("\nČtení z URL:")
print(df_url.head())
```

## 4. Načítání souborů JSON

JSON (JavaScript Object Notation) je populární formát pro výměnu dat na webu a konfiguraci. Pandas poskytuje funkci `read_json()` pro práci s JSON soubory.

```python
# Základní načítání JSON
df_json = pd.read_json('data.json')
print("Základní import JSON:")
print(df_json.head())

# JSON s vnořenými strukturami
with open('nested_data.json', 'r') as f:
    nested_json = json.load(f)

# Převod vnořeného JSON na DataFrame
df_nested = pd.json_normalize(nested_json)
print("\nNormalizovaný vnořený JSON:")
print(df_nested.head())

# Načítání JSON z řetězce
json_str = '''
[
    {"name": "Jan", "age": 30, "city": "Praha"},
    {"name": "Anna", "age": 25, "city": "Paříž"},
    {"name": "Petr", "age": 35, "city": "Berlín"}
]
'''
df_json_str = pd.read_json(json_str)
print("\nJSON z řetězce:")
print(df_json_str)

# Načítání JSON z URL
json_url = "https://api.github.com/repos/pandas-dev/pandas/issues?per_page=5"
df_json_url = pd.read_json(json_url)
print("\nJSON z URL:")
print(df_json_url[['number', 'title']].head())

# Práce s komplexním JSON
response = requests.get(json_url)
issues = response.json()

# Extrakce konkrétních polí
df_issues = pd.DataFrame([{
    'number': issue['number'],
    'title': issue['title'],
    'state': issue['state'],
    'comments': issue['comments'],
    'created_at': issue['created_at']
} for issue in issues])

print("\nVlastní parsování JSON:")
print(df_issues.head())
```

## 5. Načítání dat z databází (SQL)

SQL databáze jsou běžným zdrojem strukturovaných dat. Pandas poskytuje integraci s SQL prostřednictvím `read_sql()`.

```python
# Vytvoření vzorové SQLite databáze
conn = sqlite3.connect('example.db')
c = conn.cursor()

# Vytvoření tabulky
c.execute('''
    CREATE TABLE IF NOT EXISTS employees
    (id INTEGER PRIMARY KEY, name TEXT, department TEXT, salary REAL)
''')

# Vložení vzorových dat
employees = [
    (1, 'Jan Novák', 'IT', 75000),
    (2, 'Jana Nováková', 'HR', 65000),
    (3, 'Petr Svoboda', 'Finance', 80000),
    (4, 'Alena Procházková', 'Marketing', 70000),
    (5, 'Karel Veselý', 'IT', 85000)
]

c.executemany('INSERT OR REPLACE INTO employees VALUES (?,?,?,?)', employees)
conn.commit()

# Čtení dat pomocí pandas
df_sql = pd.read_sql('SELECT * FROM employees', conn)
print("Základní SQL dotaz:")
print(df_sql)

# Čtení s komplexnějším dotazem
df_filtered = pd.read_sql('''
    SELECT department, AVG(salary) as avg_salary
    FROM employees
    GROUP BY department
    ORDER BY avg_salary DESC
''', conn)

print("\nSQL s agregací:")
print(df_filtered)

# Použití SQLAlchemy pro složitější připojení k databázi
engine = create_engine('sqlite:///example.db')
df_alchemy = pd.read_sql('employees', engine)
print("\nPoužití SQLAlchemy:")
print(df_alchemy)

# Uzavření připojení
conn.close()
```

## 6. Načítání dat z webových API

Webová API poskytují přístup k dynamickým zdrojům dat po celém internetu. Knihovna `requests` v kombinaci s pandas usnadňuje načítání a zpracování těchto dat.

```python
# Jednoduchý API požadavek
response = requests.get('https://jsonplaceholder.typicode.com/posts')
posts = response.json()

# Převod na DataFrame
df_posts = pd.DataFrame(posts)
print("Data z API - Příspěvky:")
print(df_posts.head())

# API s autentizací (pomocí ukázkového endpointu)
def get_authenticated_data(api_url, api_key):
    """Funkce pro načtení dat z API vyžadujícího autentizaci"""
    headers = {'Authorization': f'Bearer {api_key}'}
    response = requests.get(api_url, headers=headers)
    if response.status_code == 200:
        return pd.DataFrame(response.json())
    else:
        print(f"Chyba: {response.status_code}")
        return pd.DataFrame()

# Ukázka použití (zakomentováno, protože vyžaduje skutečný API klíč)
# df_auth = get_authenticated_data('https://api.example.com/data', 'your_api_key')
# print("\nAutentizovaný API požadavek:")
# print(df_auth.head())

# Zpracování stránkovaných API odpovědí
def get_paginated_data(base_url, params=None, max_pages=3):
    """Funkce pro zpracování stránkovaných API odpovědí"""
    all_data = []
    current_page = 1
    
    if params is None:
        params = {}
    
    while current_page <= max_pages:
        params['page'] = current_page
        response = requests.get(base_url, params=params)
        
        if response.status_code != 200:
            print(f"Chyba na stránce {current_page}: {response.status_code}")
            break
        
        page_data = response.json()
        
        # Kontrola, zda jsme dosáhli konce dat
        if not page_data:
            break
        
        all_data.extend(page_data)
        current_page += 1
    
    return pd.DataFrame(all_data)

# Ukázka použití
comments_df = get_paginated_data(
    'https://jsonplaceholder.typicode.com/comments',
    params={'_limit': 10},
    max_pages=2
)
print("\nStránkovaná data z API:")
print(f"Celkem záznamů: {len(comments_df)}")
print(comments_df.head())
```

## 7. Práce s různými kódováními souborů

Při práci se soubory z různých zdrojů se můžete setkat s různými kódováními textu. Pandas umožňuje specifikovat kódování při čtení souborů.

```python
# Čtení souboru se specifickým kódováním
try:
    # Běžná kódování: utf-8, latin-1, iso-8859-1, cp1252
    df_encoded = pd.read_csv('data_special_chars.csv', encoding='utf-8')
    print("Soubor s kódováním UTF-8:")
    print(df_encoded.head())
except UnicodeDecodeError:
    print("UTF-8 selhalo, zkouším latin-1")
    df_encoded = pd.read_csv('data_special_chars.csv', encoding='latin-1')
    print("Soubor s kódováním latin-1:")
    print(df_encoded.head())

# Funkce pro detekci kódování
def detect_encoding(file_path):
    """Pokus o detekci kódování souboru"""
    encodings = ['utf-8', 'latin-1', 'iso-8859-1', 'cp1252']
    
    for encoding in encodings:
        try:
            with open(file_path, 'r', encoding=encoding) as f:
                f.read()
            return encoding
        except UnicodeDecodeError:
            continue
    
    return None
```

## 8. Práce s velkými soubory

Při práci s velkými datovými sadami nemusí být možné načíst celý soubor do paměti. Pandas poskytuje nástroje pro efektivnější práci s velkými soubory.

```python
# Čtení velkého CSV souboru po částech
chunk_size = 1000  # Počet řádků na jednu část
chunks = []

for chunk in pd.read_csv('large_file.csv', chunksize=chunk_size):
    # Zpracování každé části
    # Například filtrování řádků, agregace nebo transformace
    processed_chunk = chunk[chunk['value'] > 100]
    chunks.append(processed_chunk)

# Spojení zpracovaných částí
df_large = pd.concat(chunks)
print("Zpracování velkého souboru po částech:")
print(f"Konečná velikost: {df_large.shape}")

# Použití generátoru pro zpracování velkých souborů
def process_large_file(filename, chunk_size=1000):
    """Generátorová funkce pro zpracování velkých souborů po částech"""
    for chunk in pd.read_csv(filename, chunksize=chunk_size):
        # Zpracování části
        yield chunk

# Ukázka použití
def analyze_large_dataset(filename):
    """Analýza velké datové sady bez jejího úplného načtení do paměti"""
    total_rows = 0
    column_sums = None
    
    for chunk in process_large_file(filename):
        total_rows += len(chunk)
        
        # Výpočet součtů sloupců pro numerické sloupce
        if column_sums is None:
            column_sums = chunk.select_dtypes(include=[np.number]).sum()
        else:
            column_sums += chunk.select_dtypes(include=[np.number]).sum()
    
    return total_rows, column_sums
```

## 9. Zpracování chyb a validace dat

Při načítání dat je zásadní validovat integritu dat a správně zpracovávat chyby.

```python
# Zpracování chyb pomocí try-except
try:
    df = pd.read_csv('nonexistent_file.csv')
except FileNotFoundError:
    print("Soubor nebyl nalezen. Místo toho používám výchozí prázdný DataFrame.")
    df = pd.DataFrame()

# Validace načtených dat
def validate_dataframe(df, required_columns, numeric_columns=None):
    """Validace struktury a obsahu DataFrame"""
    validation_errors = []
    
    # Kontrola požadovaných sloupců
    for col in required_columns:
        if col not in df.columns:
            validation_errors.append(f"Chybí požadovaný sloupec: {col}")
    
    # Kontrola numerických sloupců
    if numeric_columns:
        for col in numeric_columns:
            if col in df.columns:
                if not pd.api.types.is_numeric_dtype(df[col]):
                    validation_errors.append(f"Sloupec {col} by měl být numerický")
    
    # Kontrola prázdného DataFrame
    if df.empty:
        validation_errors.append("DataFrame je prázdný")
    
    return validation_errors

# Ukázka použití
sample_df = pd.DataFrame({
    'ID': [1, 2, 3],
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Value': ['10', '20', '30']  # Řetězec místo číselného typu
})

errors = validate_dataframe(
    sample_df,
    required_columns=['ID', 'Name', 'Value', 'Category'],
    numeric_columns=['ID', 'Value']
)

print("\nChyby validace dat:")
for error in errors:
    print(f"- {error}")

# Konverze problematických sloupců
if 'Value' in sample_df:
    try:
        sample_df['Value'] = pd.to_numeric(sample_df['Value'], errors='coerce')
        print("\nSloupec Value převeden na číselný typ:")
        print(sample_df.dtypes)
    except Exception as e:
        print(f"Chyba při konverzi sloupce: {e}")
```

## 10. Shrnutí

V této příručce jsme prozkoumali různé metody načítání dat z různých zdrojů v Pythonu:

1. **Soubory CSV**: Nejběžnější formát pro tabulková data, snadno načitatelný pomocí `pd.read_csv()`.
2. **Soubory Excel**: Podniková data často přicházejí ve formátu Excel, který lze načíst pomocí `pd.read_excel()`.
3. **Soubory JSON**: Webová data často používají JSON, který lze zpracovat pomocí `pd.read_json()` a `json_normalize()`.
4. **SQL databáze**: Strukturovaná data jsou často uložena v databázích, přístupných přes `pd.read_sql()`.
5. **Webová API**: Online zdroje dat lze načítat pomocí knihovny `requests` a převádět na DataFrame.
6. **Velké soubory**: Techniky jako dělení na části pomáhají zpracovávat soubory příliš velké pro načtení do paměti.
7. **Kódování**: Různá kódování znaků lze řešit zadáním parametru `encoding`.
8. **Validace**: Po načtení je vždy důležité validovat data, aby byla zajištěna jejich integrita.

Schopnost načítat, čistit a předzpracovávat data z různých zdrojů je základem datové vědy. Zvládnutím těchto technik můžete vytvářet robustní datové pipeline, které promění surová data v praktické poznatky.

Klíčové aspekty při načítání dat zahrnují:
- Pochopení struktury datového zdroje
- Zpracování chybějících nebo poškozených dat
- Efektivní správu velkých datových sad
- Validaci integrity dat
- Vhodnou konverzi datových typů

S těmito dovednostmi můžete s jistotou pracovat s daty z jakéhokoli zdroje a připravit je pro analýzu a modelování.
