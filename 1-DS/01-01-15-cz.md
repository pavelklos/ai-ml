## 1. Úvod do datových distribucí

Pochopení datových distribucí je základem datové vědy. Distribuce popisuje, jak jsou data rozložena nebo uspořádána, a poskytuje vhled do základních vzorů a charakteristik vašeho datasetu.

```python
# Import základních knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
import warnings
warnings.filterwarnings('ignore')

# Nastavení stylu vizualizace
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_style("whitegrid")
```

Vytvořme několik vzorových dat pro zkoumání distribucí:

```python
# Nastavení náhodného semínka pro reprodukovatelnost
np.random.seed(42)

# Vygenerování normální distribuce
normal_data = np.random.normal(loc=0, scale=1, size=1000)

# Vygenerování rovnoměrné distribuce
uniform_data = np.random.uniform(low=-3, high=3, size=1000)

# Vygenerování zešikmené distribuce (log-normální)
lognormal_data = np.random.lognormal(mean=0, sigma=0.5, size=1000)

# Vytvoření pandas DataFrame pro uložení našich distribucí
distributions_df = pd.DataFrame({
    'Normal': normal_data,
    'Uniform': uniform_data,
    'LogNormal': lognormal_data
})

# Zobrazení základních statistik pro každou distribuci
print(distributions_df.describe())
```

## 2. Běžné pravděpodobnostní distribuce

V datové vědě se často setkáváme s několika pravděpodobnostními distribucemi:

1. **Normální (Gaussova) distribuce**: Slavná křivka ve tvaru zvonu, která se objevuje v mnoha přírodních jevech
2. **Rovnoměrná distribuce**: Stejná pravděpodobnost napříč všemi hodnotami v rozsahu
3. **Binomická distribuce**: Diskrétní distribuce pro počet úspěchů v n nezávislých pokusech
4. **Poissonova distribuce**: Diskrétní distribuce pro počet událostí v pevném intervalu
5. **Exponenciální distribuce**: Spojitá distribuce pro čas mezi událostmi
6. **Log-normální distribuce**: Distribuce proměnné, jejíž logaritmus sleduje normální rozdělení

```python
# Vygenerování příkladů různých distribucí
n_samples = 1000

# Normální distribuce
normal = np.random.normal(loc=0, scale=1, size=n_samples)

# Rovnoměrná distribuce
uniform = np.random.uniform(low=-3, high=3, size=n_samples)

# Binomická distribuce (10 pokusů, 0.5 pravděpodobnost úspěchu)
binomial = np.random.binomial(n=10, p=0.5, size=n_samples)

# Poissonova distribuce (lambda = 3)
poisson = np.random.poisson(lam=3, size=n_samples)

# Exponenciální distribuce (scale = 1/lambda = 1/0.5 = 2)
exponential = np.random.exponential(scale=2, size=n_samples)

# Log-normální distribuce
lognormal = np.random.lognormal(mean=0, sigma=0.5, size=n_samples)

# Vizualizace těchto distribucí pomocí histogramů
fig, axs = plt.subplots(3, 2, figsize=(14, 12))
axs = axs.ravel()

distributions = [normal, uniform, binomial, poisson, exponential, lognormal]
titles = ['Normální', 'Rovnoměrná', 'Binomická', 'Poissonova', 'Exponenciální', 'Log-normální']

for i, (data, title) in enumerate(zip(distributions, titles)):
    sns.histplot(data, kde=True, ax=axs[i])
    axs[i].set_title(f'{title} distribuce')
    axs[i].set_ylabel('Četnost')

plt.tight_layout()
plt.show()
```

## 3. Vizualizace distribucí

Existuje mnoho způsobů, jak vizualizovat distribuce, přičemž každý zdůrazňuje různé aspekty dat:

1. **Histogramy**: Zobrazují frekvenční rozdělení datasetu
2. **Grafy hustoty jádra**: Vyhlazená reprezentace distribuce
3. **Krabicové grafy (Box plots)**: Zvýrazňují medián, kvartily a odlehlé hodnoty
4. **Q-Q grafy**: Porovnávají distribuci vzorku s teoretickou distribucí
5. **ECDF (Empirická kumulativní distribuční funkce)**: Zobrazuje kumulativní pravděpodobnost

```python
# Vytvoření většího datasetu pro vizualizaci
np.random.seed(42)
data = np.concatenate([
    np.random.normal(0, 1, 1000),    # Standardní normální
    np.random.normal(4, 1, 500)      # Posunutá normální
])

fig, axs = plt.subplots(2, 3, figsize=(18, 10))

# Histogram
sns.histplot(data, kde=False, ax=axs[0, 0])
axs[0, 0].set_title('Histogram')

# Graf hustoty jádra
sns.kdeplot(data, ax=axs[0, 1])
axs[0, 1].set_title('Graf hustoty jádra')

# Krabicový graf
sns.boxplot(y=data, ax=axs[0, 2])
axs[0, 2].set_title('Krabicový graf')

# Houslový graf
sns.violinplot(y=data, ax=axs[1, 0])
axs[1, 0].set_title('Houslový graf')

# Q-Q graf
from scipy import stats
stats.probplot(data, plot=axs[1, 1])
axs[1, 1].set_title('Q-Q graf')

# ECDF
def ecdf(data):
    x = np.sort(data)
    y = np.arange(1, len(data) + 1) / len(data)
    return x, y

x, y = ecdf(data)
axs[1, 2].plot(x, y, marker='.', linestyle='none')
axs[1, 2].set_title('ECDF graf')
axs[1, 2].set_xlabel('Hodnota')
axs[1, 2].set_ylabel('Kumulativní pravděpodobnost')

plt.tight_layout()
plt.show()
```

## 4. Testování normality

Mnoho statistických metod předpokládá, že data sledují normální rozdělení. Pro kontrolu, zda jsou vaše data normálně rozdělena, lze použít několik testů:

1. **Vizuální metody**: Histogramy, Q-Q grafy
2. **Statistické testy**: Shapiro-Wilkův test, Anderson-Darlingův test, D'Agostino-Pearsonův test

```python
# Vygenerování několika vzorových datových distribucí pro testování
np.random.seed(42)
normal_sample = np.random.normal(loc=0, scale=1, size=100)
skewed_sample = np.random.exponential(scale=1, size=100)
bimodal_sample = np.concatenate([np.random.normal(-2, 0.5, 50), np.random.normal(2, 0.5, 50)])

# Funkce pro testování normality pomocí více metod
def test_normality(data, name):
    print(f"Testování normality pro distribuci {name}:")
    
    # Shapiro-Wilkův test
    stat, p_value = stats.shapiro(data)
    print(f"Shapiro-Wilkův test: statistika={stat:.4f}, p-hodnota={p_value:.4f}")
    print(f"{'Data vypadají normálně' if p_value > 0.05 else 'Data nevypadají normálně'} (Shapiro-Wilk)")
    
    # Anderson-Darlingův test
    result = stats.anderson(data, dist='norm')
    print(f"Anderson-Darlingův test: statistika={result.statistic:.4f}")
    
    # D'Agostino and Pearsonův test
    stat, p_value = stats.normaltest(data)
    print(f"D'Agostino-Pearsonův test: statistika={stat:.4f}, p-hodnota={p_value:.4f}")
    print(f"{'Data vypadají normálně' if p_value > 0.05 else 'Data nevypadají normálně'} (D'Agostino-Pearson)")
    
    # Vizuální kontrola pomocí Q-Q grafu
    plt.figure(figsize=(12, 4))
    plt.subplot(1, 2, 1)
    sns.histplot(data, kde=True)
    plt.title(f'{name} - Histogram s KDE')
    
    plt.subplot(1, 2, 2)
    stats.probplot(data, plot=plt)
    plt.title(f'{name} - Q-Q graf')
    plt.tight_layout()
    plt.show()
    print("\n")

# Otestování našich distribucí
test_normality(normal_sample, "Normální")
test_normality(skewed_sample, "Zprava zešikmená")
test_normality(bimodal_sample, "Bimodální")
```

## 5. Práce se zešikmenými distribucemi

Zešikmené distribuce jsou asymetrické, s daty koncentrovanými na jedné straně. Dva běžné přístupy ke zpracování zešikmených dat jsou:

1. **Transformace**: Převedení zešikmených dat na distribuce podobnější normálnímu rozdělení
2. **Robustní statistiky**: Použití metrik méně ovlivněných zešikmením (medián vs průměr)

```python
# Vygenerování zprava zešikmených dat
np.random.seed(42)
skewed_data = np.random.lognormal(mean=0, sigma=1, size=1000)

# Funkce pro zobrazení distribuce před a po transformaci
def plot_transformation(original_data, transformed_data, transform_name):
    fig, axs = plt.subplots(1, 2, figsize=(14, 5))
    
    # Původní distribuce
    sns.histplot(original_data, kde=True, ax=axs[0])
    axs[0].set_title('Původní zešikmená distribuce')
    axs[0].set_ylabel('Četnost')
    
    # Zobrazení statistik původních dat
    mean = np.mean(original_data)
    median = np.median(original_data)
    skew = stats.skew(original_data)
    axs[0].axvline(mean, color='red', linestyle='--', label=f'Průměr: {mean:.2f}')
    axs[0].axvline(median, color='green', linestyle='--', label=f'Medián: {median:.2f}')
    axs[0].legend()
    axs[0].text(0.7, 0.85, f'Šikmost: {skew:.2f}', transform=axs[0].transAxes)
    
    # Transformovaná distribuce
    sns.histplot(transformed_data, kde=True, ax=axs[1])
    axs[1].set_title(f'Po {transform_name} transformaci')
    
    # Zobrazení statistik transformovaných dat
    mean = np.mean(transformed_data)
    median = np.median(transformed_data)
    skew = stats.skew(transformed_data)
    axs[1].axvline(mean, color='red', linestyle='--', label=f'Průměr: {mean:.2f}')
    axs[1].axvline(median, color='green', linestyle='--', label=f'Medián: {median:.2f}')
    axs[1].legend()
    axs[1].text(0.7, 0.85, f'Šikmost: {skew:.2f}', transform=axs[1].transAxes)
    
    plt.tight_layout()
    plt.show()

# Aplikace a vizualizace různých transformací
# 1. Logaritmická transformace
log_transformed = np.log1p(skewed_data)  # log(1+x) pro zvládnutí nul
plot_transformation(skewed_data, log_transformed, 'logaritmické')

# 2. Odmocninová transformace
sqrt_transformed = np.sqrt(skewed_data)
plot_transformation(skewed_data, sqrt_transformed, 'odmocninové')

# 3. Box-Cox transformace
boxcox_transformed, lambda_val = stats.boxcox(skewed_data)
plot_transformation(skewed_data, boxcox_transformed, f'Box-Cox (lambda={lambda_val:.2f})')
```

## 6. Identifikace odlehlých hodnot

Odlehlé hodnoty jsou extrémní hodnoty, které se výrazně odchylují od ostatních pozorování. Mohou ovlivnit statistické analýzy a měly by být identifikovány a vhodně zpracovány.

```python
# Vygenerování dat s odlehlými hodnotami
np.random.seed(42)
data = np.random.normal(loc=0, scale=1, size=100)
# Přidání několika odlehlých hodnot
outliers = np.array([6, 7, -8, 9, -7.5])
contaminated_data = np.concatenate([data, outliers])

# Definice funkcí pro detekci odlehlých hodnot
def detect_outliers_zscore(data, threshold=3):
    """Detekce odlehlých hodnot pomocí Z-skóre"""
    z_scores = np.abs(stats.zscore(data))
    return np.where(z_scores > threshold)[0], z_scores

def detect_outliers_iqr(data):
    """Detekce odlehlých hodnot pomocí metody IQR"""
    q1 = np.percentile(data, 25)
    q3 = np.percentile(data, 75)
    iqr = q3 - q1
    lower_bound = q1 - (1.5 * iqr)
    upper_bound = q3 + (1.5 * iqr)
    return np.where((data < lower_bound) | (data > upper_bound))[0]

# Detekce odlehlých hodnot pomocí různých metod
zscore_outliers, z_scores = detect_outliers_zscore(contaminated_data)
iqr_outliers = detect_outliers_iqr(contaminated_data)

print("Odlehlé hodnoty detekované pomocí metody Z-skóre:")
print(f"Indexy odlehlých hodnot: {zscore_outliers}")
print(f"Odlehlé hodnoty: {contaminated_data[zscore_outliers]}")

print("\nOdlehlé hodnoty detekované pomocí metody IQR:")
print(f"Indexy odlehlých hodnot: {iqr_outliers}")
print(f"Odlehlé hodnoty: {contaminated_data[iqr_outliers]}")

# Vizualizace dat s zvýrazněnými odlehlými hodnotami
plt.figure(figsize=(12, 6))

# Krabicový graf
plt.subplot(1, 2, 1)
sns.boxplot(y=contaminated_data)
plt.title('Krabicový graf s odlehlými hodnotami')
plt.ylabel('Hodnota')

# Bodový graf s zvýrazněnými odlehlými hodnotami
plt.subplot(1, 2, 2)
plt.scatter(range(len(contaminated_data)), contaminated_data, alpha=0.7, label='Normální')
plt.scatter(zscore_outliers, contaminated_data[zscore_outliers], color='red', 
            label='Z-skóre odlehlé hodnoty', s=100, edgecolor='k')
plt.title('Detekce odlehlých hodnot pomocí Z-skóre')
plt.xlabel('Index')
plt.ylabel('Hodnota')
plt.legend()

plt.tight_layout()
plt.show()
```

## 7. Porovnávání distribucí

Často potřebujeme porovnat různé distribuce, abychom zjistili, zda pocházejí ze stejné základní populace nebo zda měla léčba nějaký efekt.

```python
# Vygenerování dvou vzorových distribucí
np.random.seed(42)
sample1 = np.random.normal(loc=0, scale=1, size=100)
sample2 = np.random.normal(loc=0.5, scale=1.2, size=100)

# Vizualizace vzorků pro porovnání
plt.figure(figsize=(12, 6))

# Překrývající se histogramy
plt.subplot(1, 2, 1)
sns.histplot(sample1, kde=True, color='blue', alpha=0.5, label='Vzorek 1')
sns.histplot(sample2, kde=True, color='red', alpha=0.5, label='Vzorek 2')
plt.title('Porovnání histogramů')
plt.legend()

# Empirická kumulativní distribuční funkce (ECDF)
plt.subplot(1, 2, 2)
# Výpočet ECDF
x1, y1 = ecdf(sample1)
x2, y2 = ecdf(sample2)
plt.plot(x1, y1, marker='.', markersize=5, linestyle='none', alpha=0.5, label='Vzorek 1')
plt.plot(x2, y2, marker='.', markersize=5, linestyle='none', alpha=0.5, label='Vzorek 2')
plt.title('Porovnání ECDF')
plt.xlabel('Hodnota')
plt.ylabel('Kumulativní pravděpodobnost')
plt.legend()

plt.tight_layout()
plt.show()

# Statistické testy pro porovnání distribucí

# 1. Studentův t-test (pro porovnání průměrů dvou vzorků)
t_stat, t_pvalue = stats.ttest_ind(sample1, sample2)
print(f"Studentův t-test: statistika={t_stat:.4f}, p-hodnota={t_pvalue:.4f}")
print(f"{'Průměry se významně liší' if t_pvalue < 0.05 else 'Průměry se významně neliší'}")

# 2. Kolmogorov-Smirnov test (porovnává celé distribuce)
ks_stat, ks_pvalue = stats.ks_2samp(sample1, sample2)
print(f"\nKolmogorov-Smirnov test: statistika={ks_stat:.4f}, p-hodnota={ks_pvalue:.4f}")
print(f"{'Distribuce se významně liší' if ks_pvalue < 0.05 else 'Distribuce se významně neliší'}")

# 3. Mann-Whitney U test (porovnává distribuce bez předpokladu normality)
mw_stat, mw_pvalue = stats.mannwhitneyu(sample1, sample2)
print(f"\nMann-Whitney U test: statistika={mw_stat:.4f}, p-hodnota={mw_pvalue:.4f}")
print(f"{'Distribuce se významně liší' if mw_pvalue < 0.05 else 'Distribuce se významně neliší'}")
```

## 8. Přizpůsobování distribucí

Přizpůsobování distribucí je proces hledání statistické distribuce, která nejlépe odpovídá vašim datům. To vám může pomoci pochopit základní proces generování dat a dělat lepší statistické závěry.

```python
# Vygenerování vzorového datasetu
np.random.seed(42)
data = np.random.gamma(shape=2, scale=2, size=1000)

# Vykreslení histogramu dat
plt.figure(figsize=(12, 6))
counts, bins, _ = plt.hist(data, bins=30, density=True, alpha=0.6, color='g', label='Skutečná data')
plt.title('Přizpůsobování distribucí datům')
plt.xlabel('Hodnota')
plt.ylabel('Hustota')

# Pokus o přizpůsobení několika distribucí
distributions = [
    stats.norm, stats.gamma, stats.lognorm, stats.expon
]
dist_names = ['Normální', 'Gamma', 'Log-normální', 'Exponenciální']
colors = ['r', 'b', 'purple', 'orange']

# Vykreslení přizpůsobených distribucí
for dist, name, color in zip(distributions, dist_names, colors):
    # Přizpůsobení distribuce datům
    params = dist.fit(data)
    
    # Získání přizpůsobeného PDF
    arg_params = params[:-2]
    loc = params[-2]
    scale = params[-1]
    
    # Výpočet AIC (Akaikeho informační kritérium) pro dobrotu přizpůsobení
    log_likelihood = np.sum(dist.logpdf(data, *arg_params, loc=loc, scale=scale))
    n_params = len(params)
    aic = 2 * n_params - 2 * log_likelihood
    
    # Generování bodů pro přizpůsobený PDF
    x = np.linspace(min(bins), max(bins), 100)
    pdf = dist.pdf(x, *arg_params, loc=loc, scale=scale)
    
    # Vykreslení přizpůsobeného PDF
    plt.plot(x, pdf, color=color, lw=2, label=f'{name} (AIC: {aic:.2f})')

plt.legend()
plt.tight_layout()
plt.show()

# Provedení Kolmogorov-Smirnov testu k nalezení nejlépe odpovídající distribuce
print("Testy dobré shody:")
print("=====================")

for dist, name in zip(distributions, dist_names):
    params = dist.fit(data)
    arg_params = params[:-2]
    loc = params[-2]
    scale = params[-1]
    
    # K-S test
    ks_stat, ks_pval = stats.kstest(data, lambda x: dist.cdf(x, *arg_params, loc=loc, scale=scale))
    print(f"{name} distribuce:")
    print(f"  K-S statistika: {ks_stat:.4f}")
    print(f"  p-hodnota: {ks_pval:.4f}")
    print(f"  {'Dobrá shoda (nelze zamítnout H0)' if ks_pval > 0.05 else 'Špatná shoda (zamítnutí H0)'}")
    print()
```

## 9. Praktické aplikace

Pochopení distribucí má mnoho praktických aplikací v datové vědě:

1. **Detekce anomálií**: Identifikace neobvyklých pozorování v datech
2. **Testování hypotéz**: Tvorba statistických závěrů o populacích
3. **Modelování rizik**: Odhad pravděpodobnosti extrémních událostí
4. **Řízení kvality**: Monitorování procesů pro konzistentnost
5. **Simulace**: Generování realistických syntetických dat

```python
# Příklad: Detekce anomálií v datasetu teplotního senzoru
np.random.seed(42)

# Vygenerování normálních teplotních hodnot s občasnými anomáliemi
n_days = 365
temp_mean = 22
temp_std = 3

# Vygenerování základní teploty (denní fluktuace + sezónní trend)
t = np.arange(n_days)
seasonal_component = 5 * np.sin(2 * np.pi * t / 365)  # Roční cyklus
temperatures = temp_mean + seasonal_component + np.random.normal(0, temp_std, size=n_days)

# Přidání několika anomálií (poruchy senzoru nebo extrémní počasí)
anomaly_indices = [20, 80, 150, 230, 300]
anomaly_values = [38, 40, 5, 3, 42]
for idx, val in zip(anomaly_indices, anomaly_values):
    temperatures[idx] = val

# Vytvoření DataFrame pro lepší manipulaci
dates = pd.date_range(start='2023-01-01', periods=n_days, freq='D')
temp_df = pd.DataFrame({'date': dates, 'temperature': temperatures})

# Detekce anomálií pomocí metody Z-skóre
temp_df['z_score'] = stats.zscore(temp_df['temperature'])
temp_df['is_anomaly'] = np.abs(temp_df['z_score']) > 2.5  # Prahová hodnota

# Vizualizace dat se zvýrazněnými anomáliemi
plt.figure(figsize=(14, 6))
plt.plot(temp_df['date'], temp_df['temperature'], color='blue', alpha=0.7, label='Teplota')
plt.scatter(
    temp_df.loc[temp_df['is_anomaly'], 'date'],
    temp_df.loc[temp_df['is_anomaly'], 'temperature'],
    color='red', s=50, label='Anomálie'
)
plt.title('Časová řada teplot s anomáliemi')
plt.xlabel('Datum')
plt.ylabel('Teplota (°C)')
plt.legend()
plt.grid(True)
plt.show()

print("Detekované anomálie:")
print(temp_df[temp_df['is_anomaly']].sort_values('z_score', ascending=False)[['date', 'temperature', 'z_score']])
```

## 10. Shrnutí

Pochopení datových distribucí je základem datové vědy a statistiky. Klíčové poznatky zahrnují:

1. **Typy distribucí**: Různá data sledují různé vzory distribucí - normální, rovnoměrné, log-normální atd.

2. **Nástroje vizualizace**: Histogramy, grafy hustoty jádra, krabicové grafy, Q-Q grafy a ECDF pomáhají vizualizovat a pochopit distribuce.

3. **Testování normality**: Jak vizuální metody, tak statistické testy (Shapiro-Wilk, Anderson-Darling) mohou ověřit, zda data sledují normální rozdělení.

4. **Zpracování zešikmených dat**: Transformace (logaritmické, odmocninové, Box-Cox) mohou pomoci normalizovat zešikmená data.

5. **Detekce odlehlých hodnot**: Metody Z-skóre a IQR identifikují pozorování, která se výrazně odchylují od zbytku dat.

6. **Porovnání distribucí**: Statistické testy pomáhají určit, zda vzorky pocházejí ze stejné distribuce.

7. **Přizpůsobování distribucí**: Nalezení teoretické distribuce, která nejlépe odpovídá vašim empirickým datům.

8. **Praktické aplikace**: Detekce anomálií, testování hypotéz, modelování rizik a simulace.

Pochopení distribucí vám pomáhá vybrat vhodné statistické metody, identifikovat neobvyklé vzory a činit lepší rozhodnutí založená na datech. Je to základní dovednost pro každého datového vědce nebo analytika.
