## Úvod do zpracování dat ve velkém měřítku

S rostoucím objemem dat přes hranice zpracovatelné na jednom stroji potřebují datoví vědci frameworky navržené pro distribuovaná výpočetní prostředí. Frameworky pro zpracování dat ve velkém měřítku umožňují analýzu terabajtů nebo petabajtů dat rozdělením práce mezi klastry počítačů.

Klíčové výzvy řešené těmito frameworky zahrnují:
- Zpracování dat, která přesahují paměť jednoho stroje
- Snižování výpočetního času pomocí paralelního zpracování
- Zajištění odolnosti proti chybám a obnovy
- Správa komplexních distribuovaných systémů
- Udržování škálovatelnosti s rostoucími daty

```python
# Jednoduché srovnání velikostí dat
import pandas as pd
import numpy as np

# Malá data: Snadno se vejdou do paměti jednoho stroje
small_data = pd.DataFrame(np.random.rand(10000, 10))  # ~800 KB

# Střední data: Stále se vejdou do paměti, ale zpracování může být pomalé
medium_data = pd.DataFrame(np.random.rand(1000000, 100))  # ~800 MB

# Velká data: Nemusí se vejít do paměti jednoho stroje
# large_data = pd.DataFrame(np.random.rand(1000000000, 100))  # ~800 GB - způsobilo by havárii!
print(f"Malá data: {small_data.memory_usage().sum() / 1024**2:.2f} MB")
print(f"Střední data: {medium_data.memory_usage().sum() / 1024**2:.2f} MB")
print(f"Velká data: Vyžadovala by ~800 GB (nelze vytvořit v paměti)")
```

## Základy Apache Spark a PySpark

Apache Spark je jedním z nejpopulárnějších frameworků pro zpracování velkých dat, poskytující rozhraní pro programování celých klastrů s implicitním datovým paralelismem a odolností proti chybám.

### Klíčové koncepty:
- **Resilient Distributed Datasets (RDDs)**: Neměnné distribuované kolekce
- **DataFrames a Datasets**: Abstrakce vyšší úrovně
- **Transformace a Akce**: Operace, které budují nebo spouštějí výpočty
- **Líné vyhodnocování**: Výpočty jsou provedeny pouze tehdy, když je to potřeba

```python
# Nejprve nainstalujte PySpark:
# pip install pyspark

# Základní příklad PySpark
from pyspark.sql import SparkSession
import pyspark.sql.functions as F

# Inicializace Spark session
spark = SparkSession.builder \
    .appName("PySpark Example") \
    .config("spark.executor.memory", "4g") \
    .getOrCreate()

# Vytvoření DataFrame
data = [("Alice", 34), ("Bob", 45), ("Charlie", 29), ("Diana", 37)]
df = spark.createDataFrame(data, ["Name", "Age"])

# Transformace
filtered_df = df.filter(df.Age > 30).select("Name", "Age")
grouped_df = df.groupBy("Age").count()

# Akce
print("Filtrovaná data:")
filtered_df.show()

print("Počet podle věku:")
grouped_df.show()

# SQL dotazy
df.createOrReplaceTempView("people")
spark_sql_df = spark.sql("SELECT * FROM people WHERE Age > 30 ORDER BY Age")
spark_sql_df.show()

# Ukončení Spark session
spark.stop()
```

### Spark pro strojové učení

Spark obsahuje MLlib, škálovatelnou knihovnu pro strojové učení:

```python
from pyspark.ml.classification import RandomForestClassifier
from pyspark.ml.feature import VectorAssembler
from pyspark.ml.evaluation import MulticlassClassificationEvaluator
from pyspark.ml import Pipeline

# Vytvoření vzorových dat
data = [(1.0, 0.0, 1.1, 0), (0.2, 1.0, 1.0, 1), (0.7, 0.8, 0.0, 1), 
        (1.0, 0.5, 0.5, 0), (0.1, 0.4, 0.7, 1), (0.0, 0.9, 0.8, 1)]
df = spark.createDataFrame(data, ["feature1", "feature2", "feature3", "label"])

# Příprava příznaků
assembler = VectorAssembler(
    inputCols=["feature1", "feature2", "feature3"], 
    outputCol="features")
train_data = assembler.transform(df)

# Vytvoření a trénování modelu
rf = RandomForestClassifier(labelCol="label", featuresCol="features", numTrees=10)
pipeline = Pipeline(stages=[assembler, rf])
model = pipeline.fit(df)

# Vytváření předpovědí
predictions = model.transform(df)
predictions.select("features", "label", "probability", "prediction").show()

# Vyhodnocení modelu
evaluator = MulticlassClassificationEvaluator(
    labelCol="label", predictionCol="prediction", metricName="accuracy")
accuracy = evaluator.evaluate(predictions)
print(f"Přesnost: {accuracy}")
```

## Datový paralelismus s Dask

Dask poskytuje pokročilý paralelismus pro analýzu dat, umožňující paralelní výpočty pomocí známých API jako NumPy, pandas a scikit-learn.

### Klíčové vlastnosti:
- **Dynamické plánování úloh**: Inteligentně přiděluje úlohy pracovním uzlům
- **Známá API**: Funguje jako náhrada za pandas a NumPy
- **Nativní integrace s Pythonem**: Dobře spolupracuje s ekosystémem Pythonu
- **Menší křivka učení** ve srovnání se Sparkem

```python
# Instalace Dask a souvisejících knihoven
# pip install dask distributed "dask[dataframe]" "dask[array]"

import dask
import dask.dataframe as dd
import dask.array as da
import numpy as np
import pandas as pd

# Vytvoření velkého Dask DataFrame z pandas
df = pd.DataFrame({
    'x': np.random.random(10000),
    'y': np.random.random(10000),
    'z': np.random.random(10000)
})

# Převod na Dask DataFrame s oddíly
dask_df = dd.from_pandas(df, npartitions=4)

# Provedení operací (tyto jsou líné)
result = (dask_df.x + dask_df.y).mean()

# Spuštění výpočtu
print(f"Průměrná hodnota: {result.compute()}")

# Čtení dat větších než paměť
# dask_df = dd.read_csv('very_large_file.csv', blocksize='64MB')
```

## Distribuované výpočty s Ray

Ray je framework pro škálování aplikací v Pythonu od notebooku až po klastr, se zaměřením na AI a ML úlohy.

### Klíčové komponenty:
- **Ray Core**: Poskytuje primitivy pro distribuované výpočty
- **Ray Tasks**: Pro bezstavové paralelní výpočty
- **Ray Actors**: Pro stavové paralelní výpočty
- **Knihovny**: Ray zahrnuje nástroje specifické pro ML jako Ray Tune a RLlib

```python
# Instalace Ray
# pip install ray

import ray
import numpy as np
import time

# Inicializace Ray
ray.init()

# Definice Ray úlohy pomocí dekorátoru @ray.remote
@ray.remote
def process_chunk(chunk):
    # Simulace nějakého zpracování
    time.sleep(1)
    return chunk.sum()

# Zpracování dat paralelně
data = np.random.rand(10, 1000000)
chunks = np.array_split(data, 10)

# Spuštění úloh paralelně
results = ray.get([process_chunk.remote(chunk) for chunk in chunks])

print(f"Součet všech částí: {sum(results)}")
print(f"Ověření s numpy: {data.sum()}")

# Stavové výpočty s Ray actors
@ray.remote
class Counter:
    def __init__(self):
        self.value = 0
    
    def increment(self):
        self.value += 1
        return self.value
    
    def get_value(self):
        return self.value

# Vytvoření aktora
counter = Counter.remote()

# Provedení operací
results = ray.get([counter.increment.remote() for _ in range(10)])
print(f"Výsledky inkrementace: {results}")
print(f"Konečná hodnota čítače: {ray.get(counter.get_value.remote())}")

# Vypnutí Ray
ray.shutdown()
```

### Ray pro strojové učení

```python
import ray
from ray import tune
from ray.tune.schedulers import ASHAScheduler

# Spuštění Ray
ray.init()

# Definice trénovatelné funkce pro ladění hyperparametrů
def train_model(config):
    # Zjednodušený příklad (v praxi by se použil TensorFlow, PyTorch, atd.)
    accuracy = 0.9 + 0.1 * config["learning_rate"] - 0.1 * (config["learning_rate"] ** 2)
    for i in range(10):  # Iterace tréninku
        tune.report(accuracy=accuracy * (1 + i/100))  # Reportování metrik

# Konfigurace prohledávání hyperparametrů
search_space = {
    "learning_rate": tune.loguniform(1e-4, 1e-1),
    "batch_size": tune.choice([16, 32, 64, 128])
}

# Spuštění ladění hyperparametrů
analysis = tune.run(
    train_model,
    config=search_space,
    num_samples=10,
    scheduler=ASHAScheduler(metric="accuracy", mode="max"),
    resources_per_trial={"cpu": 1}
)

# Získání nejlepšího běhu
best_trial = analysis.get_best_trial("accuracy", "max", "last")
print(f"Nejlepší konfigurace běhu: {best_trial.config}")
print(f"Konečná přesnost nejlepšího běhu: {best_trial.last_result['accuracy']}")
```

## Strategie dělení dat

Efektivní dělení dat je klíčové pro distribuované zpracování dat, ovlivňující výkon, využití paměti a operace přeskupení (shuffle).

### Běžné strategie:
- **Range Partitioning**: Rozdělení dat do přibližně stejně velkých rozsahů
- **Hash Partitioning**: Distribuce podle hash hodnoty klíče
- **Round-Robin**: Jednoduché rozdělení mezi oddíly
- **Dynamické dělení**: Úprava oddílů na základě charakteristik dat

```python
# Příklady dělení s PySpark
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("Partitioning").getOrCreate()

# Vytvoření vzorových dat
data = [(i, f"value_{i}") for i in range(100)]
df = spark.createDataFrame(data, ["id", "value"])

# Kontrola výchozího dělení
print(f"Výchozí počet oddílů: {df.rdd.getNumPartitions()}")

# Přerozdělení na konkrétní počet
repartitioned_df = df.repartition(5)
print(f"Po přerozdělení: {repartitioned_df.rdd.getNumPartitions()}")

# Hash dělení (podle konkrétního sloupce)
hash_partitioned = df.repartition(5, "id")
print(f"Počet hash oddílů: {hash_partitioned.rdd.getNumPartitions()}")

# Range dělení
range_partitioned = df.orderBy("id").coalesce(5)
print(f"Počet rozsahových oddílů: {range_partitioned.rdd.getNumPartitions()}")

# Zobrazení distribuce oddílů (zjednodušené)
def count_by_partition(df):
    def count_in_partition(iterator):
        count = 0
        for _ in iterator:
            count += 1
        yield count
    
    counts = df.rdd.mapPartitions(count_in_partition).collect()
    for i, count in enumerate(counts):
        print(f"Oddíl {i}: {count} záznamů")

print("Distribuce hash oddílů:")
count_by_partition(hash_partitioned)

print("Distribuce rozsahových oddílů:")
count_by_partition(range_partitioned)

spark.stop()
```

## Optimalizační techniky pro velká data

Při práci s velkými datovými sadami je optimalizace kritická pro výkon a nákladovou efektivitu.

### Klíčové oblasti optimalizace:
- **Správa paměti**: Řízení využití paměti
- **Optimalizace I/O**: Efektivní čtení/zápis dat
- **Optimalizace dotazů**: Zlepšení prováděcího plánu
- **Strategie kešování**: Inteligentní opětovné využití mezivýsledků
- **Serializace**: Efektivní serializace/deserializace dat

```python
# Příklady optimalizace PySpark
from pyspark.sql import SparkSession
from pyspark.sql.functions import col

spark = SparkSession.builder \
    .appName("Optimization") \
    .config("spark.sql.shuffle.partitions", 5) \
    .config("spark.executor.memory", "2g") \
    .getOrCreate()

# Vytvoření vzorových dat
df = spark.range(0, 100000).selectExpr("id", "id % 100 as category")

# 1. Kešování
cached_df = df.cache()
cached_df.count()  # Materializace keše
print("DataFrame je kešován:", cached_df.is_cached)

# 2. Predicate pushdown
filtered = cached_df.filter(col("id") < 1000).filter(col("category") == 10)
print("Plán provádění s filtr pushdown:")
filtered.explain()

# 3. Projection pushdown (výběr jen potřebných sloupců)
projected = cached_df.select("id")
print("\nPlán provádění s projekčním pushdown:")
projected.explain()

# 4. Partition pruning
partitioned_df = df.repartition(10, "category")
category_10 = partitioned_df.filter(col("category") == 10)
print("\nPlán provádění s ořezáváním oddílů:")
category_10.explain()

# 5. Broadcast joins pro malé tabulky
small_df = spark.range(0, 100).selectExpr("id as small_id")
large_df = spark.range(0, 100000).selectExpr("id as large_id", "id % 100 as key")

# Ruční broadcast hint
broadcast_join = large_df.join(small_df.hint("broadcast"), 
                               large_df.key == small_df.small_id)
print("\nPlán provádění s broadcast join:")
broadcast_join.explain()

# Úklid
spark.catalog.clearCache()
spark.stop()
```

## Škálování pracovních postupů strojového učení

Strojové učení na velkých datových sadách přináší jedinečné výzvy nad rámec standardního zpracování dat.

### Strategie škálování:
- **Distribuované trénování modelů**
- **Parametrické servery**
- **Ladění hyperparametrů ve velkém měřítku**
- **Paralelismus modelů vs. datový paralelismus**
- **Online učení a inkrementální trénování**

```python
# Příklad použití Spark MLlib pro škálování ML pracovních postupů
from pyspark.sql import SparkSession
from pyspark.ml.classification import LogisticRegression
from pyspark.ml.feature import VectorAssembler, StandardScaler
from pyspark.ml.evaluation import BinaryClassificationEvaluator
from pyspark.ml import Pipeline
from pyspark.ml.tuning import ParamGridBuilder, CrossValidator

# Inicializace Spark
spark = SparkSession.builder.appName("ML Scaling").getOrCreate()

# Generování syntetických dat
from pyspark.sql.functions import rand, when
data = spark.range(0, 100000) \
    .withColumn("feature1", rand(42)) \
    .withColumn("feature2", rand(43)) \
    .withColumn("feature3", rand(44)) \
    .withColumn("label", when(rand(45) > 0.7, 1.0).otherwise(0.0))

# Rozdělení dat
train_data, test_data = data.randomSplit([0.8, 0.2], seed=42)

# Vytvoření pipeline příznaků
feature_cols = ["feature1", "feature2", "feature3"]
assembler = VectorAssembler(inputCols=feature_cols, outputCol="features_unscaled")
scaler = StandardScaler(inputCol="features_unscaled", outputCol="features")

# Vytvoření modelu
lr = LogisticRegression(maxIter=10, regParam=0.01, elasticNetParam=0.8)

# Vytvoření pipeline
pipeline = Pipeline(stages=[assembler, scaler, lr])

# Parametrická mřížka pro ladění hyperparametrů
paramGrid = ParamGridBuilder() \
    .addGrid(lr.regParam, [0.01, 0.1, 1.0]) \
    .addGrid(lr.elasticNetParam, [0.0, 0.5, 1.0]) \
    .build()

# Křížová validace
cv = CrossValidator(
    estimator=pipeline,
    estimatorParamMaps=paramGrid,
    evaluator=BinaryClassificationEvaluator(),
    numFolds=3)

# Trénování modelu s křížovou validací
print("Trénování modelu s distribuovanou křížovou validací...")
cv_model = cv.fit(train_data)

# Získání nejlepšího modelu
best_model = cv_model.bestModel
best_lr = best_model.stages[-1]
print(f"Nejlepší parametr regularizace: {best_lr.getRegParam()}")
print(f"Nejlepší parametr elasticNet: {best_lr.getElasticNetParam()}")

# Vyhodnocení modelu
predictions = best_model.transform(test_data)
evaluator = BinaryClassificationEvaluator()
auc = evaluator.evaluate(predictions)
print(f"AUC na testovacích datech: {auc}")

spark.stop()
```

## Srovnání frameworků

Různé frameworky mají různé přednosti a kompromisy. Výběr správného závisí na vašem konkrétním případu použití, stávající infrastruktuře a zkušenostech týmu.

| Framework | Nejlepší pro | Křivka učení | Integrace | Škálovatelnost |
|-----------|----------|---------------|------------|-------------|
| **Apache Spark** | Obecné dávkové zpracování, ML, SQL | Střední | Rozsáhlá | Velmi vysoká |
| **Dask** | Pracovní toky zaměřené na Python, uživatelé NumPy/pandas | Nízká | Vynikající s Pythonem | Vysoká |
| **Ray** | ML pracovní toky, posilované učení, ladění hyperparametrů | Nízká-Střední | Dobrá s ML frameworky | Vysoká |
| **Hadoop MapReduce** | Dávkové zpracování, starší systémy | Vysoká | Omezená | Vysoká |
| **Flink** | Streamové zpracování, aplikace řízené událostmi | Střední | Dobrá | Velmi vysoká |

```python
# Srovnávací příklad: Stejný výpočet napříč frameworky
import time
import numpy as np

# Nejprve vygenerujme nějaká syntetická data
data_size = 10_000_000
data = pd.DataFrame({
    'id': range(data_size),
    'value1': np.random.random(data_size),
    'value2': np.random.random(data_size),
    'category': np.random.choice(['A', 'B', 'C', 'D'], data_size)
})

# Uložení dat pro použití frameworky
data.to_csv('large_dataset.csv', index=False)
print("Data vygenerována")

# Pandas (základní verze na jednom stroji)
def pandas_computation():
    start = time.time()
    df = pd.read_csv('large_dataset.csv')
    result = df.groupby('category').agg({
        'value1': 'mean',
        'value2': ['min', 'max', 'std']
    })
    duration = time.time() - start
    print(f"Doba trvání Pandas: {duration:.2f} sekund")
    return result

# PySpark výpočet
def spark_computation():
    from pyspark.sql import SparkSession
    import pyspark.sql.functions as F
    
    start = time.time()
    spark = SparkSession.builder.appName("Comparison").getOrCreate()
    
    df = spark.read.csv('large_dataset.csv', header=True, inferSchema=True)
    result = df.groupBy("category").agg(
        F.mean("value1").alias("value1_mean"),
        F.min("value2").alias("value2_min"),
        F.max("value2").alias("value2_max"),
        F.stddev("value2").alias("value2_std")
    )
    
    pd_result = result.toPandas()
    duration = time.time() - start
    print(f"Doba trvání Spark: {duration:.2f} sekund")
    spark.stop()
    return pd_result

    import dask.dataframe as dd
    
    start = time.time()

    })
    pd_result = result.compute()
    duration = time.time() - start
    print(f"Doba trvání Dask: {duration:.2f} sekund")
    return pd_result

# Spuštění srovnání (odkomentujte podle potřeby)
```

## Případy použití v reálném světě

Pochopení, jak se tyto frameworky aplikují v reálných scénářích, pomáhá při výběru správného nástroje pro danou úlohu.

### Případová studie 1: Pipeline pro analýzu logů
Zpracování terabajtů serverových logů denně pro extrakci metrik a detekci anomálií.

```python
# Příklad analýzy logů s PySpark
from pyspark.sql import SparkSession
from pyspark.sql.functions import regexp_extract, col, window, count, avg, stddev

spark = SparkSession.builder.appName("LogAnalysis").getOrCreate()

# Čtení dat logů (příklad formátu)
logs_schema = "timestamp STRING, ip STRING, url STRING, status INT, response_time DOUBLE"
logs = spark.read.csv("logs_sample.csv", schema=logs_schema)

# Parsování časového razítka
logs = logs.withColumn("timestamp", col("timestamp").cast("timestamp"))

# Extrakce příznaků z logů
logs_processed = logs \
    .withColumn("hour", regexp_extract(col("url"), r"/hour/(\d+)", 1).cast("int")) \
    .withColumn("endpoint", regexp_extract(col("url"), r"^/([^/]+)", 1))

# Výpočet hodinových metrik
hourly_metrics = logs_processed \
    .withWatermark("timestamp", "1 hour") \
    .groupBy(window("timestamp", "1 hour"), "endpoint") \
    .agg(
        count("*").alias("request_count"),
        avg("response_time").alias("avg_response_time"),
        stddev("response_time").alias("std_response_time")
    )

# Detekce anomálií (zjednodušeno)
anomalies = hourly_metrics.filter(
    (col("avg_response_time") > 0.5) | 
    (col("request_count") < 10)
)

anomalies.show()
spark.stop()
```

```python
# Příklad genomické analýzy s Dask (zjednodušeno)
import dask.array as da
import dask.dataframe as dd

# Načtení genomických dat (zjednodušeno)
# Ve skutečnosti by to mohlo využívat specializované bioinformatické knihovny
sequences = da.random.randint(0, 4, size=(1000, 1000000), chunks=(100, 100000))

# Spočítání frekvencí nukleotidů
frequencies = da.zeros((4, sequences.shape[1]), chunks=(4, 100000))
for i in range(4):
    frequencies[i] = (sequences == i).sum(axis=0)

# Nalezení hotspotů mutací (oblasti s vysokou variancí)
variance = frequencies.var(axis=0)
hotspots = variance > variance.mean() + 2 * variance.std()
hotspot_indices = da.where(hotspots)[0]

print(f"Počet hotspotů: {hotspot_indices.compute().size}")
print(f"Ukázkové lokace hotspotů: {hotspot_indices.compute()[:10]}")
```

```python
# Závěrečný příklad: Vytvoření robustní datové pipeline se Spark
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, when, udf
from pyspark.sql.types import StringType, StructType, StructField, IntegerType, DoubleType
import datetime

# Inicializace Spark s užitečnými konfiguracemi
spark = SparkSession.builder \
    .appName("Production Pipeline") \
    .config("spark.sql.shuffle.partitions", 100) \
    .config("spark.executor.memory", "4g") \
    .config("spark.driver.memory", "2g") \
    .config("spark.sql.autoBroadcastJoinThreshold", "10m") \
    .config("spark.sql.caseSensitive", "true") \
    .config("spark.speculation", "true") \
    .getOrCreate()

# Definice schématu pro lepší výkon a validaci
user_schema = StructType([
    StructField("user_id", StringType(), False),
    StructField("name", StringType(), True),
    StructField("age", IntegerType(), True),
    StructField("signup_date", StringType(), True),
    StructField("last_activity", StringType(), True),
    StructField("purchases", IntegerType(), True)
])

# Čtení se schématem a vhodnými možnostmi
users = spark.read \
    .format("parquet") \
    .schema(user_schema) \
    .option("pathGlobFilter", "*.parquet") \
    .option("recursiveFileLookup", "true") \
    .load("user_data/")

# Vytvoření adresáře pro kontrolní body pro zkrácení odvození
spark.sparkContext.setCheckpointDir("checkpoint")

# UDF s řádným ošetřením chyb
@udf(StringType())
def calculate_user_status(age, purchases):
    try:
        if age is None or purchases is None:
            return "Unknown"
        if age < 25:
            return "Young" if purchases > 5 else "Young Potential"
        else:
            return "Established" if purchases > 10 else "Growing"
    except:
        return "Error"

# Zpracování dat s kontrolními body pro komplexní pracovní postupy
processed_users = users \
    .filter(col("age").isNotNull()) \
    .withColumn("days_since_activity", 
                datediff(current_date(), to_date(col("last_activity"), "yyyy-MM-dd"))) \
    .withColumn("user_status", calculate_user_status(col("age"), col("purchases"))) \
    .checkpoint()

# Efektivní zápis výsledků
processed_users.write \
    .format("parquet") \
    .partitionBy("user_status") \
    .mode("overwrite") \
    .option("compression", "snappy") \
    .save("processed_users/")

# Zaznamenání dokončení
current_time = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
print(f"Pipeline dokončena v {current_time}")
print(f"Zpracováno {processed_users.count()} uživatelských záznamů")

spark.stop()
```
