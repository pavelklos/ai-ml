## Introduction to Geospatial Data

Geospatial data analysis involves analyzing data that has geographic or spatial components. This can include coordinates (latitude/longitude), addresses, postal codes, or geographic boundaries. Geospatial analysis allows us to answer location-based questions and discover spatial patterns that might be invisible in traditional tabular data.

Key concepts in geospatial analysis include:
- **Geographic coordinates**: Latitude and longitude values that pinpoint locations
- **Projections**: Methods for representing Earth's curved surface on a flat map
- **Spatial relationships**: How features relate to each other (distance, containment, adjacency)
- **Vector data**: Points, lines, and polygons representing discrete features
- **Raster data**: Grid-based data representing continuous phenomena

```python
# Understanding basic geographic coordinates
import pandas as pd

# Sample location data
locations = pd.DataFrame({
    'name': ['New York', 'Los Angeles', 'Chicago', 'Houston', 'Phoenix'],
    'latitude': [40.7128, 34.0522, 41.8781, 29.7604, 33.4484],
    'longitude': [-74.0060, -118.2437, -87.6298, -95.3698, -112.0740]
})

print("Sample location data:")
print(locations)

# Calculate distance between two points (simplified for example)
from math import radians, cos, sin, sqrt, asin

def haversine_distance(lat1, lon1, lat2, lon2):
    # Convert decimal degrees to radians
    lat1, lon1, lat2, lon2 = map(radians, [lat1, lon1, lat2, lon2])
    
    # Haversine formula
    dlon = lon2 - lon1
    dlat = lat2 - lat1
    a = sin(dlat/2)**2 + cos(lat1) * cos(lat2) * sin(dlon/2)**2
    c = 2 * asin(sqrt(a))
    r = 6371  # Radius of Earth in kilometers
    return c * r

# Calculate distance between New York and Los Angeles
ny = locations.iloc[0]
la = locations.iloc[1]
distance = haversine_distance(ny['latitude'], ny['longitude'], la['latitude'], la['longitude'])
print(f"Distance between {ny['name']} and {la['name']}: {distance:.2f} kilometers")
```

## Geospatial Data Formats

Geospatial data comes in various formats, each with its own strengths and use cases:

- **Shapefiles**: Traditional format with .shp, .shx, and .dbf files
- **GeoJSON**: Lightweight format based on JSON
- **KML**: XML-based format used by Google Earth
- **GeoTIFF**: Raster format with geographic metadata
- **PostGIS/Spatialite**: Spatial database extensions

## Spatial Analysis Techniques

Spatial analysis involves examining locations, attributes, and relationships of features in geographic data. Common techniques include:

```python
# Spatial joins, overlays, and distance calculations
import geopandas as gpd
import matplotlib.pyplot as plt
from shapely.geometry import Point

# Load world borders
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# Create some random points
import numpy as np
np.random.seed(42)
n_points = 100
lon = np.random.uniform(-180, 180, n_points)
lat = np.random.uniform(-90, 90, n_points)
points = gpd.GeoDataFrame(
    {'id': range(n_points)},
    geometry=[Point(xy) for xy in zip(lon, lat)]
)
points.crs = world.crs  # Ensure same CRS as world

# Spatial join: which country contains each point?
joined = gpd.sjoin(points, world, op='within')
print("Points joined with countries (first 5 rows):")
print(joined[['id', 'name', 'continent']].head())

# Count points by country
point_counts = joined.groupby('name').size().reset_index(name='point_count')
point_counts = point_counts.sort_values('point_count', ascending=False)
print("\nTop 5 countries by random point count:")
print(point_counts.head())

# Merge count data back to world for mapping
world_with_counts = world.merge(point_counts, on='name', how='left')
world_with_counts['point_count'] = world_with_counts['point_count'].fillna(0)

# Create a choropleth map
fig, ax = plt.subplots(figsize=(12, 6))
world_with_counts.plot(
    column='point_count',
    cmap='OrRd',
    legend=True,
    ax=ax,
    legend_kwds={'label': 'Point Count', 'orientation': 'horizontal'}
)
ax.set_title('Random Points per Country')
ax.set_axis_off()
plt.tight_layout()
plt.show()

# Spatial overlay - intersection of geometries
# Let's find countries within a specific bounding box
bbox = Polygon([(-50, 0), (50, 0), (50, 50), (-50, 50), (-50, 0)])
bbox_gdf = gpd.GeoDataFrame({'id': [1]}, geometry=[bbox], crs=world.crs)

# Intersect the bbox with countries
intersected = gpd.overlay(world, bbox_gdf, how='intersection')

# Show the intersected countries
print("\nCountries intersecting with bounding box:")
print(intersected[['name', 'continent']])

# Plot the results
fig, ax = plt.subplots(figsize=(12, 6))
world.plot(ax=ax, color='lightgray', edgecolor='black')
intersected.plot(ax=ax, color='red', alpha=0.5)
bbox_gdf.boundary.plot(ax=ax, color='blue', linewidth=2)
ax.set_title('Countries Intersecting with Bounding Box')
plt.axis('off')
plt.tight_layout()
plt.show()

# Distance-based operations
# Find countries within 5 degrees of a point
point_location = Point(0, 0)  # Null Island
buffer_distance = 20  # degrees
buffer = gpd.GeoDataFrame(
    {'id': [1]}, 
    geometry=[point_location.buffer(buffer_distance)], 
    crs=world.crs
)

# Countries that intersect with the buffer
countries_near_point = gpd.overlay(world, buffer, how='intersection')
print("\nCountries within buffer distance of the point:")
print(countries_near_point[['name']].head())

# Visualize
fig, ax = plt.subplots(figsize=(12, 6))
world.plot(ax=ax, color='lightgray', edgecolor='black')
buffer.plot(ax=ax, color='blue', alpha=0.2)
countries_near_point.plot(ax=ax, color='red', alpha=0.5)
ax.scatter(0, 0, color='black', s=50)  # The center point
ax.set_title(f'Countries within {buffer_distance} degrees of (0, 0)')
plt.axis('off')
plt.tight_layout()
plt.show()
```

## Integration with Machine Learning

Geospatial features can be powerful predictors in machine learning models. Here's how to integrate geospatial data into a machine learning workflow:

```python
# Integrating geospatial data with machine learning
import geopandas as gpd
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error
import matplotlib.pyplot as plt

# Load world data
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# Create some synthetic data for demonstration
# Let's predict GDP based on geographic and demographic features
np.random.seed(42)
world['gdp_per_capita'] = (
    world['pop_est'] / 1e7 +  # Population factor
    np.abs(world.geometry.centroid.x) / 50 +  # Longitude factor
    np.abs(world.geometry.centroid.y) / 20 +  # Latitude factor
    world.geometry.area / 30 +  # Area factor
    np.random.normal(0, 5, len(world))  # Random noise
)

# Extract features from geospatial data
world['centroid_x'] = world.geometry.centroid.x
world['centroid_y'] = world.geometry.centroid.y
world['area'] = world.geometry.area
world['bbox_width'] = world.geometry.bounds.maxx - world.geometry.bounds.minx
world['bbox_height'] = world.geometry.bounds.maxy - world.geometry.bounds.miny
world['perimeter'] = world.geometry.length

# One-hot encode continent
world_with_dummies = pd.get_dummies(world, columns=['continent'], prefix='cont')

# Select features and target
features = [
    'pop_est', 'centroid_x', 'centroid_y', 'area', 
    'bbox_width', 'bbox_height', 'perimeter'
] + [col for col in world_with_dummies.columns if col.startswith('cont_')]

X = world_with_dummies[features]
y = world_with_dummies['gdp_per_capita']

# Split the data
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Train a random forest model
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

# Make predictions
y_pred = model.predict(X_test)

# Evaluate the model
mse = mean_squared_error(y_test, y_pred)
print(f"Mean Squared Error: {mse:.2f}")
print(f"RMSE: {np.sqrt(mse):.2f}")

# Feature importance
feature_importance = pd.DataFrame({
    'Feature': features,
    'Importance': model.feature_importances_
}).sort_values('Importance', ascending=False)

print("\nTop 5 most important features:")
print(feature_importance.head())

# Plot feature importance
plt.figure(figsize=(10, 6))
plt.barh(feature_importance['Feature'][:10], feature_importance['Importance'][:10])
plt.xlabel('Importance')
plt.title('Top 10 Feature Importances')
plt.gca().invert_yaxis()  # Display from top to bottom
plt.tight_layout()
plt.show()

# Create a map of actual vs predicted values
# Add predictions back to test data
world_with_dummies['test_set'] = False
test_indices = world_with_dummies.index.isin(X_test.index)
world_with_dummies.loc[test_indices, 'test_set'] = True
world_with_dummies.loc[test_indices, 'predicted_gdp'] = y_pred

# Create the map
fig, axs = plt.subplots(1, 2, figsize=(18, 6))

# Actual values map
world_test = world_with_dummies[world_with_dummies['test_set']]
world_test.plot(
    column='gdp_per_capita',
    cmap='viridis',
    legend=True,
    ax=axs[0],
    legend_kwds={'label': 'Actual GDP per capita'},
    missing_kwds={'color': 'lightgrey'}
)
axs[0].set_title('Actual GDP per Capita')
axs[0].set_axis_off()

# Predicted values map
world_test.plot(
    column='predicted_gdp',
    cmap='viridis',
    legend=True,
    ax=axs[1],
    legend_kwds={'label': 'Predicted GDP per capita'},
    missing_kwds={'color': 'lightgrey'}
)
axs[1].set_title('Predicted GDP per Capita')
axs[1].set_axis_off()

plt.tight_layout()
plt.show()
```

## Case Studies: Real-world Applications

```python
# Case study: Public transportation accessibility analysis
import geopandas as gpd
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np
from shapely.geometry import Point, LineString
import contextily as ctx

# Create sample data for a fictional city
# 1. City neighborhoods
coordinates = [
    [(-1, -1), (-1, 1), (1, 1), (1, -1)],  # Downtown
    [(-3, -1), (-3, 1), (-1, 1), (-1, -1)],  # West Side
    [(-1, 1), (-1, 3), (1, 3), (1, 1)],  # North Side
    [(1, -1), (1, 1), (3, 1), (3, -1)],  # East Side
    [(-1, -3), (-1, -1), (1, -1), (1, -3)]   # South Side
]
neighborhoods = gpd.GeoDataFrame({
    'name': ['Downtown', 'West Side', 'North Side', 'East Side', 'South Side'],
    'population': [12000, 25000, 18000, 15000, 22000]
}, geometry=[Polygon(coords) for coords in coordinates], crs="EPSG:3857")

# 2. Bus stops
np.random.seed(42)
n_stops = 40
x = np.random.uniform(-3, 3, n_stops)
y = np.random.uniform(-3, 3, n_stops)
bus_stops = gpd.GeoDataFrame({
    'stop_id': range(1, n_stops + 1),
    'name': [f'Stop {i}' for i in range(1, n_stops + 1)]
}, geometry=[Point(x[i], y[i]) for i in range(n_stops)], crs="EPSG:3857")

# 3. Bus routes (simplified for example)
routes = []
route_names = []

# Route 1: East-West
route1 = LineString([(-3, 0), (3, 0)])
routes.append(route1)
route_names.append("Route 1: E-W")

# Route 2: North-South
route2 = LineString([(0, -3), (0, 3)])
routes.append(route2)
route_names.append("Route 2: N-S")

# Route 3: Circular
route3 = LineString([(-2, -2), (-2, 2), (2, 2), (2, -2), (-2, -2)])
routes.append(route3)
route_names.append("Route 3: Circle")

bus_routes = gpd.GeoDataFrame({
    'route_name': route_names,
    'frequency': [10, 15, 20]  # minutes between buses
}, geometry=routes, crs="EPSG:3857")

# Calculate access metrics:
# 1. Stops per neighborhood
neighborhood_stops = gpd.sjoin(neighborhoods, bus_stops, op='contains')
stops_per_neighborhood = neighborhood_stops.groupby('name').size().rename('stop_count')
neighborhoods = neighborhoods.merge(stops_per_neighborhood, left_on='name', right_index=True, how='left')
neighborhoods['stop_count'] = neighborhoods['stop_count'].fillna(0)

# 2. Service frequency (avg frequency of routes within buffer distance of neighborhood center)
neighborhoods['center_point'] = neighborhoods.geometry.centroid
stops_with_routes = gpd.sjoin(bus_stops, bus_routes.to_crs(bus_stops.crs), op='intersects', rsuffix='_route')

# Calculate average frequency
avg_freq = stops_with_routes.groupby('name')['frequency'].mean().rename('avg_frequency')
neighborhoods = neighborhoods.merge(avg_freq, left_on='name', right_index=True, how='left')
neighborhoods['avg_frequency'] = neighborhoods['avg_frequency'].fillna(0)

# 3. Calculate accessibility score
neighborhoods['stops_per_1000'] = 1000 * neighborhoods['stop_count'] / neighborhoods['population']
neighborhoods['accessibility_score'] = (
    neighborhoods['stops_per_1000'] * 10 +  # More stops is better
    (30 - neighborhoods['avg_frequency']) / 5  # Lower frequency (minutes) is better
)

# Visualize the results
fig, axes = plt.subplots(2, 2, figsize=(15, 12))

# 1. Bus stops and routes
ax = axes[0, 0]
neighborhoods.plot(ax=ax, color='lightgray', edgecolor='black')
bus_routes.plot(ax=ax, color=['red', 'blue', 'green'], linewidth=2)
bus_stops.plot(ax=ax, color='black', markersize=20)
ax.set_title('Bus Stops and Routes')

# 2. Stops per neighborhood
ax = axes[0, 1]
neighborhoods.plot(
    column='stop_count',
    ax=ax,
    legend=True,
    cmap='YlOrRd',
    legend_kwds={'label': 'Number of Bus Stops'}
)
ax.set_title('Bus Stops per Neighborhood')

# 3. Average frequency
ax = axes[1, 0]
neighborhoods.plot(
    column='avg_frequency',
    ax=ax,
    legend=True,
    cmap='YlGnBu_r',  # Reversed so darker is better (lower minutes)
    legend_kwds={'label': 'Avg. Minutes Between Buses'}
)
ax.set_title('Average Service Frequency')

# 4. Accessibility score
ax = axes[1, 1]
neighborhoods.plot(
    column='accessibility_score',
    ax=ax,
    legend=True,
    cmap='viridis',
    legend_kwds={'label': 'Accessibility Score'}
)
ax.set_title('Transit Accessibility Score')

for ax in axes.flat:
    ax.set_axis_off()

plt.tight_layout()
plt.show()

print("Neighborhood accessibility metrics:")
print(neighborhoods[['name', 'population', 'stop_count', 'stops_per_1000', 
                     'avg_frequency', 'accessibility_score']])
```

## Performance Considerations

When working with large geospatial datasets, performance becomes a critical concern. Here are strategies to improve performance:

```python
# Performance considerations for geospatial data
import geopandas as gpd
import pandas as pd
import time
from shapely.geometry import box
import psutil
import os

# Function to measure execution time and memory usage
def measure_performance(func):
    def wrapper(*args, **kwargs):
        # Memory before
        process = psutil.Process(os.getpid())
        mem_before = process.memory_info().rss / 1024 / 1024  # MB
        
        # Time execution
        start_time = time.time()
        result = func(*args, **kwargs)
        execution_time = time.time() - start_time
        
        # Memory after
        mem_after = process.memory_info().rss / 1024 / 1024  # MB
        mem_used = mem_after - mem_before
        
        print(f"Function {func.__name__}:")
        print(f"  Execution time: {execution_time:.4f} seconds")
        print(f"  Memory used: {mem_used:.2f} MB")
        return result
    return wrapper

# Load sample data
world = gpd.read_file(gpd.datasets.get_path('naturalearth_lowres'))

# Technique 1: Simplify geometries
@measure_performance
def analyze_original():
    # Calculate area and perimeter for all countries
    areas = world.geometry.area
    perimeters = world.geometry.length
    return areas, perimeters

@measure_performance
def analyze_simplified():
    # Simplify geometries first, then calculate
    simple_world = world.copy()
    simple_world.geometry = world.geometry.simplify(0.1)
    areas = simple_world.geometry.area
    perimeters = simple_world.geometry.length
    return areas, perimeters

print("Comparing performance with original vs simplified geometries:")
orig_results = analyze_original()
simp_results = analyze_simplified()

# Check accuracy difference
area_diff_pct = abs(orig_results[0] - simp_results[0]).mean() / orig_results[0].mean() * 100
print(f"Average area difference: {area_diff_pct:.2f}%")

# Technique 2: Spatial indexing for efficient querying
@measure_performance
def query_without_index():
    # Create a bounding box
    query_box = box(-50, -50, 50, 50)
    
    # Find countries intersecting with the box without index
    results = []
    for idx, country in world.iterrows():
        if country.geometry.intersects(query_box):
            results.append(idx)
    return results

@measure_performance
def query_with_index():
    # Create a bounding box
    query_box = box(-50, -50, 50, 50)
    
    # Find countries using spatial index
    spatial_index = world.sindex
    possible_matches_index = list(spatial_index.intersection(query_box.bounds))
    possible_matches = world.iloc[possible_matches_index]
    precise_matches = possible_matches[possible_matches.intersects(query_box)]
    return precise_matches.index.tolist()

print("\nComparing query performance with and without spatial index:")
without_index_results = query_without_index()
with_index_results = query_with_index()
print(f"Number of results: {len(with_index_results)}")

# Technique 3: Optimize attribute operations before spatial ones
@measure_performance
def inefficient_workflow():
    # First do spatial filtering, then attribute filtering
    europe = world[world.geometry.intersects(box(-30, 35, 40, 70))]
    result = europe[europe.pop_est > 1000000]
    return result

@measure_performance
def efficient_workflow():
    # First do attribute filtering, then spatial filtering
    large_countries = world[world.pop_est > 1000000]
    result = large_countries[large_countries.geometry.intersects(box(-30, 35, 40, 70))]
    return result

print("\nComparing workflow efficiency:")
inefficient_result = inefficient_workflow()
efficient_result = efficient_workflow()
print(f"Result count: {len(efficient_result)}")

# Technique 4: Use attribute joins instead of spatial joins when possible
countries_df = pd.DataFrame({
    'name': world.name,
    'continent': world.continent,
    'population': world.pop_est
})

cities = gpd.GeoDataFrame({
    'city': ['New York', 'London', 'Tokyo', 'Rio'],
    'country': ['United States of America', 'United Kingdom', 'Japan', 'Brazil'],
    'population': [8.4, 8.9, 13.5, 6.7]
}, geometry=gpd.points_from_xy([-74.0, 0.1, 139.7, -43.2], [40.7, 51.5, 35.7, -22.9]))

@measure_performance
def spatial_join_approach():
    # Using spatial join (slower)
    return gpd.sjoin(cities, world, op='within')

@measure_performance
def attribute_join_approach():
    # Using attribute join (faster)
    return cities.merge(countries_df, left_on='country', right_on='name')

print("\nComparing join methods:")
spatial_result = spatial_join_approach()
attribute_result = attribute_join_approach()
```

## Summary and Best Practices

Geospatial data analysis is a powerful addition to the data scientist's toolkit, enabling insights that would be impossible with traditional tabular data alone. Here are the key takeaways and best practices:

1. **Data preparation**:
   - Always check and standardize the Coordinate Reference System (CRS)
   - Simplify geometries when high precision isn't needed
   - Use appropriate spatial indices for large datasets

2. **Analysis workflow**:
   - Filter by non-spatial attributes before performing spatial operations
   - Choose the right geometric operations for your analysis needs
   - Combine spatial and traditional data features for richer insights

3. **Visualization**:
   - Use static maps for reports and interactive maps for exploration
   - Choose appropriate color schemes for choropleth maps
   - Add contextual layers like basemaps when appropriate

4. **Integration with ML**:
   - Extract meaningful geometric features (centroids, areas, etc.)
   - Consider spatial relationships as features
   - Validate models with appropriate spatial cross-validation

5. **Performance optimization**:
   - Use spatial indices for queries
   - Simplify geometries when precision isn't critical
   - Prefer attribute joins over spatial joins when possible
   - Work with projected data for accurate measurements
