## Ethical and Legal Considerations

Before scraping any website, it's crucial to understand the legal and ethical implications. Always check:

1. Terms of Service of the website
2. robots.txt file for allowed/disallowed areas
3. Rate limiting to prevent server overload
4. Data privacy concerns

```python
# Checking robots.txt before scraping
import requests
from urllib.parse import urlparse

def check_robots_txt(url):
    """Check if scraping is allowed in robots.txt"""
    parsed_url = urlparse(url)
    robots_url = f"{parsed_url.scheme}://{parsed_url.netloc}/robots.txt"
    
    try:
        response = requests.get(robots_url)
        if response.status_code == 200:
            print(f"robots.txt content for {parsed_url.netloc}:")
            print(response.text)
        else:
            print(f"No robots.txt found for {parsed_url.netloc}")
    except Exception as e:
        print(f"Error checking robots.txt: {e}")

# Example usage
check_robots_txt('https://example.com')
```

## Using Requests to Fetch Web Pages

The `requests` library is the standard for making HTTP requests in Python. It allows you to fetch web page content for scraping.

```python
import requests
import time

def fetch_page(url, headers=None, delay=1):
    """
    Fetch a web page with proper headers and rate limiting
    
    Parameters:
        url (str): URL to fetch
        headers (dict): Optional HTTP headers
        delay (float): Time to wait in seconds before request
    
    Returns:
        requests.Response: Response object
    """
    # Default headers to mimic a browser
    if headers is None:
        headers = {
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36',
            'Accept': 'text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8',
            'Accept-Language': 'en-US,en;q=0.5',
        }
    
    # Rate limiting
    time.sleep(delay)
    
    try:
        response = requests.get(url, headers=headers)
        response.raise_for_status()  # Raise exception for 4XX/5XX status codes
        return response
    except requests.exceptions.RequestException as e:
        print(f"Error fetching {url}: {e}")
        return None

# Example usage
response = fetch_page('https://quotes.toscrape.com/')
if response:
    print(f"Status Code: {response.status_code}")
    print(f"Content Type: {response.headers.get('content-type')}")
    print(f"First 100 characters: {response.text[:100].strip()}")
```

## Web Scraping with Beautiful Soup

Beautiful Soup is a Python library that makes it easy to parse HTML and extract data. It provides convenient methods for finding elements by tag names, attributes, or CSS selectors.

```python
from bs4 import BeautifulSoup
import requests

# Scrape quotes from a sample scraping website

    text = quote_div.select_one('.text').get_text()
```

## Data Extraction and Cleaning

Extracting data is only the beginning. You'll often need to clean and preprocess the scraped data to make it useful for analysis.

```python
import pandas as pd
import re
from bs4 import BeautifulSoup

# Sample HTML with messy data
messy_html = """
<div class="product">
    <h2>Laptop XYZ-2023   </h2>
    <p class="price">Price: $1,299.99</p>
    <div class="specs">
        <p>RAM: 16GB</p>
        <p>Storage: 512GB SSD</p>
        <p>Rating: 4.7/5 (243 reviews)</p>
    </div>
</div>
<div class="product">
    <h2>  Smartphone ABC </h2>
    <p class="price">Price: $899.99</p>
    <div class="specs">
        <p>RAM: 8GB</p>
        <p>Storage: 256GB</p>
        <p>Rating: 4.5/5 (1,892 reviews)</p>
    </div>
</div>
"""

# Parse the HTML
soup = BeautifulSoup(messy_html, 'html.parser')
products = []

for product_div in soup.select('.product'):
    # Extract basic information
    name = product_div.find('h2').get_text(strip=True)
    
    # Extract price and clean it
    price_text = product_div.select_one('.price').get_text()
    # Remove "Price: $" and commas, then convert to float
    price = float(re.search(r'\$([0-9,]+\.[0-9]+)', price_text).group(1).replace(',', ''))
    
    # Extract specifications
    specs = {}
    for spec in product_div.select('.specs p'):
        spec_text = spec.get_text()
        if 'RAM:' in spec_text:
            specs['ram'] = spec_text.replace('RAM:', '').strip()
        elif 'Storage:' in spec_text:
            specs['storage'] = spec_text.replace('Storage:', '').strip()
        elif 'Rating:' in spec_text:
            # Extract rating value and review count
            rating_match = re.search(r'([0-9.]+)/5 \(([0-9,]+) reviews\)', spec_text)
            if rating_match:
                specs['rating'] = float(rating_match.group(1))
                specs['review_count'] = int(rating_match.group(2).replace(',', ''))
    
    # Create a dictionary for this product
    product = {
        'name': name,
        'price': price,
        'ram': specs.get('ram'),
        'storage': specs.get('storage'),
        'rating': specs.get('rating'),
        'review_count': specs.get('review_count')
    }
    products.append(product)

# Convert to DataFrame for analysis
df = pd.DataFrame(products)
print("Cleaned product data:")
print(df)

# Basic data analysis example
print("\nAverage product price:", df['price'].mean())
print("Average rating:", df['rating'].mean())
```

## Storing Scraped Data

After scraping and cleaning data, you'll need to store it for future use. Common formats include CSV, JSON, and databases.

```python
import pandas as pd
import sqlite3
import json
import csv
import os

# Sample data (let's assume we have this DataFrame from scraping)
data = [
    {'product': 'Laptop', 'price': 1299.99, 'brand': 'Dell', 'rating': 4.5},
    {'product': 'Phone', 'price': 899.99, 'brand': 'Apple', 'rating': 4.8},
    {'product': 'Tablet', 'price': 499.99, 'brand': 'Samsung', 'rating': 4.3}
]
df = pd.DataFrame(data)

# 1. Save to CSV
def save_to_csv(dataframe, filename):
    dataframe.to_csv(filename, index=False)
    print(f"Data saved to {filename}")

# 2. Save to JSON
def save_to_json(dataframe, filename):
    dataframe.to_json(filename, orient='records')
    print(f"Data saved to {filename}")

# 3. Save to SQLite database
def save_to_sqlite(dataframe, db_name, table_name):
    conn = sqlite3.connect(db_name)
    dataframe.to_sql(table_name, conn, if_exists='replace', index=False)
    print(f"Data saved to {db_name} in table '{table_name}'")
    conn.close()

# Example usage
save_to_csv(df, 'scraped_products.csv')
save_to_json(df, 'scraped_products.json')
save_to_sqlite(df, 'products_database.db', 'products')

# Read back data examples
print("\nReading data back:")
# From CSV
csv_data = pd.read_csv('scraped_products.csv')
print("\nFrom CSV:")
print(csv_data)

# From JSON
json_data = pd.read_json('scraped_products.json')
print("\nFrom JSON:")
print(json_data)

# From SQLite
conn = sqlite3.connect('products_database.db')
sqlite_data = pd.read_sql_query("SELECT * FROM products", conn)

print("\nFrom SQLite:")
print(sqlite_data)
```

## Building Robust Scrapers

Creating resilient scrapers involves error handling, proxies, rate limiting, and strategies for handling site changes.

```python
import requests
import random
import time
from bs4 import BeautifulSoup
import logging

# Set up logging
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s',
    filename='scraper.log'
)

class RobustScraper:
    def __init__(self, base_url, max_retries=3, backoff_factor=0.3, proxy_list=None):
        self.base_url = base_url
        self.max_retries = max_retries
        self.backoff_factor = backoff_factor
        self.proxy_list = proxy_list or []
        self.session = requests.Session()
        
        # Set default headers
        self.session.headers.update({
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36',
            'Accept-Language': 'en-US,en;q=0.9',
        })
    
    def _get_random_proxy(self):
        """Return a random proxy if available"""
        if not self.proxy_list:
            return None
        return random.choice(self.proxy_list)
    
    def fetch_page(self, url, params=None):
        """Fetch a page with retry logic and error handling"""
        for attempt in range(self.max_retries):
            try:
                # Apply exponential backoff
                if attempt > 0:
                    sleep_time = self.backoff_factor * (2 ** attempt)
                    logging.info(f"Retry {attempt+1}/{self.max_retries}. Waiting {sleep_time:.2f}s")
                    time.sleep(sleep_time)
                
                # Select a proxy if available
                proxy = self._get_random_proxy()
                proxies = {'http': proxy, 'https': proxy} if proxy else None
                
                # Make the request
                response = self.session.get(
                    url, 
                    params=params,
                    proxies=proxies,
                    timeout=10
                )
                
                # Check if request was successful
                response.raise_for_status()
                
                return response
                
            except requests.exceptions.HTTPError as e:
                logging.error(f"HTTP error: {e}")
                if response.status_code == 404:
                    logging.error("Page not found (404)")
                    return None
                elif response.status_code == 403:
                    logging.error("Forbidden (403) - IP might be blocked")
                
            except requests.exceptions.ConnectionError:
                logging.error("Connection error")
            
            except requests.exceptions.Timeout:
                logging.error("Request timed out")
                
            except requests.exceptions.RequestException as e:
                logging.error(f"Request failed: {e}")
        
        logging.error(f"All {self.max_retries} attempts failed for URL: {url}")
        return None
    
    def extract_data(self, soup):
        """
        Extract data from BeautifulSoup object
        Override this method in subclasses
        """
        raise NotImplementedError("Subclasses must implement extract_data()")
    
    def scrape(self, url_path="", params=None):
        """Main scraping method"""
        full_url = f"{self.base_url}/{url_path}".rstrip('/')
        logging.info(f"Scraping URL: {full_url}")
        
        response = self.fetch_page(full_url, params)
        if not response:
            logging.error("Failed to fetch page")
            return None
        
        soup = BeautifulSoup(response.text, 'html.parser')
        return self.extract_data(soup)

# Example implementation for quotes.toscrape.com
class QuoteScraper(RobustScraper):
    def extract_data(self, soup):
        quotes = []
        for quote_div in soup.select('.quote'):
            try:
                text = quote_div.select_one('.text').get_text()
                author = quote_div.select_one('.author').get_text()
                tags = [tag.get_text() for tag in quote_div.select('.tag')]
                
                quotes.append({
                    'text': text,
                    'author': author,
                    'tags': tags
                })
            except AttributeError as e:
                logging.error(f"Error extracting quote data: {e}")
                continue
        
        return quotes

# Example usage
scraper = QuoteScraper('https://quotes.toscrape.com')
quotes = scraper.scrape()

print(f"Scraped {len(quotes) if quotes else 0} quotes")
if quotes:
    print("First quote:")
    print(f"'{quotes[0]['text']}'")
    print(f"- {quotes[0]['author']}")
```

## Summary

Web scraping is a powerful technique for data collection in data science projects. Key takeaways include:

1. **Ethical considerations** are paramount - always respect robots.txt, terms of service, and rate limiting.
2. **Beautiful Soup and Requests** form the backbone of static website scraping.
3. **Selenium** is essential for JavaScript-heavy websites.
4. **Data cleaning** is a critical step after extraction to prepare the data for analysis.
5. **Robust scrapers** need error handling, retry logic, and the ability to adapt to site changes.
6. **Multiple storage options** (CSV, JSON, databases) are available depending on your needs.
7. **Regular expressions** are often needed for extracting specific patterns from text.
8. **Automated browsers** like Selenium allow interaction with web pages programmatically.
9. **Structured approaches** with classes and functions help build maintainable scrapers.
10. **Logging and monitoring** are essential for troubleshooting and ensuring continuous operation.

When implemented correctly, web scraping allows data scientists to access vast amounts of data that would otherwise be unavailable, enabling more comprehensive analyses and better-informed decisions.
