## Introduction to Advanced Indexing

Pandas offers powerful indexing capabilities that go beyond simple row and column selection. Understanding advanced indexing is essential for efficient data manipulation, especially when working with complex datasets.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

# Create a sample DataFrame
df = pd.DataFrame({
    'A': range(1, 6),
    'B': range(10, 15),
    'C': ['a', 'b', 'c', 'd', 'e']
}, index=['row1', 'row2', 'row3', 'row4', 'row5'])

print("Sample DataFrame:")
print(df)

# Basic indexing operations
print("\nFirst two rows:")
print(df[:2])  # Label-based slicing

print("\nColumn 'A':")
print(df['A'])  # Column selection
```

## Understanding loc and iloc

Pandas provides two primary indexers: `loc` (label-based) and `iloc` (integer position-based). Understanding their differences is crucial for correct data selection.

```python
# Create a DataFrame with non-default index
df = pd.DataFrame({
    'A': range(1, 6),
    'B': range(10, 15),
    'C': ['a', 'b', 'c', 'd', 'e']
}, index=[10, 20, 30, 40, 50])

print("DataFrame with custom index:")
print(df)

# loc: label-based indexing
print("\nloc[10] - Selects row with label 10:")
print(df.loc[10])

print("\nloc[10:30] - Selects rows with labels from 10 to 30 (inclusive):")
print(df.loc[10:30])

print("\nloc[:, 'B'] - Selects column 'B':")
print(df.loc[:, 'B'])

print("\nloc[20, 'C'] - Selects value at row 20, column 'C':")
print(df.loc[20, 'C'])

# iloc: integer position-based indexing
print("\niloc[0] - Selects first row:")
print(df.iloc[0])

print("\niloc[0:2] - Selects rows at positions 0 and 1:")
print(df.iloc[0:2])

print("\niloc[:, 1] - Selects second column:")
print(df.iloc[:, 1])

print("\niloc[1, 2] - Selects value at second row, third column:")
print(df.iloc[1, 2])

# Combining boolean selection with loc
print("\nSelecting rows where A > 3 and column 'B':")
print(df.loc[df['A'] > 3, 'B'])

# Common mistake: mixing label and position semantics
try:
    # This will fail
    result = df.loc[0]
    print(result)
except KeyError as e:
    print(f"KeyError: {e} - because 0 is not a row label in our DataFrame")
```

## MultiIndex Fundamentals

MultiIndex (hierarchical indexing) allows you to have multiple levels of indexes, enabling more complex data representation and operations.

```python
# MultiIndex basics
# Create a Series with MultiIndex
multi_idx = pd.MultiIndex.from_tuples([
    ('A', 'x'), ('A', 'y'), ('B', 'x'), ('B', 'y'), ('C', 'x')
], names=['level_0', 'level_1'])

s = pd.Series(range(1, 6), index=multi_idx)
print("Series with MultiIndex:")
print(s)

# Structure of a MultiIndex
print("\nMultiIndex structure:")
print(f"Number of levels: {s.index.nlevels}")
print(f"Level names: {s.index.names}")
print(f"Level values at level 0: {s.index.get_level_values(0)}")
print(f"Level values at level 1: {s.index.get_level_values(1)}")

# Accessing individual levels
print("\nUnique values at level 0:")
print(s.index.get_level_values('level_0').unique())
```

## Creating MultiIndex DataFrames

There are multiple ways to create DataFrames with MultiIndex, each with its own advantages depending on your data source.

```python
# Method 1: From arrays
arrays = [
    ['A', 'A', 'B', 'B', 'C'],
    ['x', 'y', 'x', 'y', 'x']
]
df1 = pd.DataFrame({
    'value': range(1, 6),
    'count': range(10, 15)
}, index=pd.MultiIndex.from_arrays(arrays, names=('first', 'second')))

print("Method 1 - From arrays:")
print(df1)

# Method 2: From tuples
tuples = [('A', 'x'), ('A', 'y'), ('B', 'x'), ('B', 'y'), ('C', 'x')]
df2 = pd.DataFrame({
    'value': range(1, 6),
    'count': range(10, 15)
}, index=pd.MultiIndex.from_tuples(tuples, names=('first', 'second')))

print("\nMethod 2 - From tuples:")
print(df2)

# Method 3: From product
df3 = pd.DataFrame({
    'value': [1, 2, 3, 4, 5, 6],
    'count': [10, 11, 12, 13, 14, 15]
}, index=pd.MultiIndex.from_product([['A', 'B'], ['x', 'y', 'z']], 
                                   names=('first', 'second')))

print("\nMethod 3 - From product:")
print(df3)

# Method 4: From a DataFrame using set_index
df4 = pd.DataFrame({
    'first': ['A', 'A', 'B', 'B', 'C'],
    'second': ['x', 'y', 'x', 'y', 'x'],
    'value': range(1, 6),
    'count': range(10, 15)
})
df4_multi = df4.set_index(['first', 'second'])

print("\nMethod 4 - From set_index:")
print(df4_multi)
```

## Selecting Data from MultiIndex

Accessing data from a MultiIndex DataFrame requires understanding how to specify values at different levels.

```python
# Create a more complex MultiIndex DataFrame
idx = pd.MultiIndex.from_product([
    ['Region1', 'Region2', 'Region3'],
    [2020, 2021, 2022],
    ['Q1', 'Q2', 'Q3', 'Q4']
], names=['Region', 'Year', 'Quarter'])

# Create data
np.random.seed(42)
data = np.random.randint(100, 1000, size=(36, 2))

sales_df = pd.DataFrame(
    data,
    index=idx,
    columns=['Sales', 'Expenses']
)

print("Sales DataFrame with 3-level MultiIndex:")
print(sales_df.head(10))

# Basic selection examples
print("\nAll data for Region1:")
print(sales_df.loc['Region1'])

print("\nRegion1 data for 2020:")
print(sales_df.loc[('Region1', 2020)])

print("\nRegion1, 2020, Q1 data:")
print(sales_df.loc[('Region1', 2020, 'Q1')])

# Slice selection
print("\nAll regions, year 2021:")
print(sales_df.loc[(slice(None), 2021), :])

# The xs method for cross-sectional data
print("\nAll Q1 data across all regions and years:")
print(sales_df.xs('Q1', level='Quarter'))

print("\nAll 2020 data for each region:")
print(sales_df.xs(2020, level='Year'))
```

## Advanced Selection Techniques

Combining different selection methods and using boolean indexing with MultiIndex data provides powerful filtering capabilities.

```python
# Create a sample multi-level DataFrame
dates = pd.date_range('20230101', periods=6)
regions = ['East', 'West']
categories = ['A', 'B', 'C']

# Create multi-index using product
idx = pd.MultiIndex.from_product([regions, dates], names=['Region', 'Date'])
cols = pd.MultiIndex.from_product([categories, ['Sales', 'Returns']], 
                                 names=['Category', 'Metric'])

# Generate sample data
np.random.seed(42)
data = np.random.randint(10, 100, size=(12, 6))
df = pd.DataFrame(data, index=idx, columns=cols)

print("Advanced MultiIndex DataFrame:")
print(df)

# Select all sales data
print("\nAll Sales data across all categories:")
print(df.loc[:, (slice(None), 'Sales')])

# Select specific region, all dates, category A sales
print("\nEast region, all dates, Category A Sales:")
print(df.loc[('East', slice(None)), ('A', 'Sales')])

# Using boolean conditions with loc
print("\nRows where Category A Sales > 50:")
mask = df[('A', 'Sales')] > 50
print(df.loc[mask])

# Cross-sections at multiple levels
print("\nSales data for all categories on first date:")
first_date = dates[0]
print(df.xs((first_date), level='Date')[('A', 'Sales')])

# Combining loc with xs
print("\nCategory B for East region:")
print(df.loc['East'].xs('B', axis=1, level=0))
```

## Index Manipulation and Transformations

Working with MultiIndex often requires restructuring the index or transforming the data organization.

```python
# Create a sample DataFrame with MultiIndex
data = {
    ('A', 2020): [1, 2, 3],
    ('A', 2021): [4, 5, 6],
    ('B', 2020): [7, 8, 9],
    ('B', 2021): [10, 11, 12],
}
df = pd.DataFrame(data, index=['X', 'Y', 'Z'])

print("Original DataFrame:")
print(df)

# Swapping row and column levels
stacked = df.stack()
print("\nStacked DataFrame:")
print(stacked)

# Unstacking back
unstacked = stacked.unstack()
print("\nUnstacked back to original:")
print(unstacked)

# Swapping index levels
df_multirow = stacked.copy()
print("\nSwapping levels:")
print(df_multirow.swaplevel())

# Reordering levels
df_reordered = df.T  # Transpose to get MultiIndex in rows
print("\nTransposed:")
print(df_reordered)

print("\nReordered levels:")
print(df_reordered.reorder_levels([1, 0], axis=0))

# Reset index to columns
print("\nReset index (convert to columns):")
print(stacked.reset_index())

# Set new index from columns
reset_df = stacked.reset_index()
print("\nSet index again:")
print(reset_df.set_index(['level_0', 0]))
```

## Performance Considerations

When working with large datasets, understanding performance implications of different indexing methods is crucial.

```python
import time

# Create a large DataFrame
large_df = pd.DataFrame(np.random.rand(100000, 5), columns=list('ABCDE'))

# Add some categorical columns for indexing
large_df['cat1'] = np.random.choice(['X', 'Y', 'Z'], size=100000)
large_df['cat2'] = np.random.choice(['P', 'Q', 'R', 'S'], size=100000)

# Time comparison for different operations
def time_operation(operation, name):
    start = time.time()
    result = operation()
    end = time.time()
    print(f"{name}: {end - start:.4f} seconds")
    return result

# Regular indexing vs MultiIndex
print("Performance comparison:")

# Time setting index
regular_df = large_df.copy()
time_operation(lambda: regular_df.set_index('cat1'), "Setting single index")

multi_df = large_df.copy()
time_operation(lambda: multi_df.set_index(['cat1', 'cat2']), "Setting MultiIndex")

# Create indexed versions for testing
regular_indexed = large_df.set_index('cat1')
multi_indexed = large_df.set_index(['cat1', 'cat2'])

# Time selection operations
time_operation(lambda: regular_indexed.loc['X'], "Regular .loc selection")
time_operation(lambda: multi_indexed.loc['X'], "MultiIndex level 0 selection")
time_operation(lambda: multi_indexed.loc[('X', 'P')], "MultiIndex full selection")

# Time xs method
time_operation(lambda: multi_indexed.xs('P', level='cat2'), "Using .xs method")

# Demonstrate the importance of sorted index for performance
sorted_multi = multi_indexed.sort_index()
print("\nSorted vs Unsorted MultiIndex:")
time_operation(lambda: multi_indexed.loc['X'], "Unsorted MultiIndex selection")
time_operation(lambda: sorted_multi.loc['X'], "Sorted MultiIndex selection")
```

## Practical Applications

Let's explore some real-world applications of advanced indexing in data analysis tasks.

```python
# Create a dataset of retail sales
np.random.seed(42)
dates = pd.date_range('20230101', periods=100)
products = ['Product A', 'Product B', 'Product C', 'Product D']
stores = ['Store 1', 'Store 2', 'Store 3']

# Generate data
data = []
for date in dates:
    for product in products:
        for store in stores:
            sales = np.random.randint(10, 100)
            price = np.random.uniform(5.0, 25.0)
            cost = price * 0.6  # 60% of price is cost
            data.append([date, product, store, sales, price, cost])

# Create DataFrame
retail_df = pd.DataFrame(
    data, 
    columns=['Date', 'Product', 'Store', 'Units', 'Price', 'Cost']
)

# Set MultiIndex for analysis
sales_idx = retail_df.set_index(['Date', 'Product', 'Store'])
print("Retail sales with MultiIndex:")
print(sales_idx.head())

# Application 1: Time series analysis by product
product_sales = sales_idx['Units'].unstack(level=['Product', 'Store']).fillna(0)
print("\nDaily sales by product and store:")
print(product_sales.head())

# Resample to weekly data
weekly_sales = product_sales.resample('W').sum()
print("\nWeekly sales:")
print(weekly_sales.head())

# Application 2: Product performance analysis
# Calculate revenue and profit
sales_idx['Revenue'] = sales_idx['Units'] * sales_idx['Price']
sales_idx['Profit'] = sales_idx['Revenue'] - (sales_idx['Units'] * sales_idx['Cost'])

# Aggregate by product
product_performance = sales_idx.groupby('Product').agg({
    'Units': 'sum',
    'Revenue': 'sum',
    'Profit': 'sum'
})
print("\nProduct performance summary:")
print(product_performance)

# Application 3: Cross-sectional analysis
# Get average daily sales by store
store_daily_avg = sales_idx.groupby(['Store', pd.Grouper(level='Date')])['Units'].sum().unstack(level=0)
store_daily_avg = store_daily_avg.resample('D').mean()
print("\nAverage daily sales by store:")
print(store_daily_avg.head())

# Plot the results
plt.figure(figsize=(12, 6))
store_daily_avg.plot()
plt.title('Average Daily Sales by Store')
plt.ylabel('Units Sold')
plt.grid(True)
plt.tight_layout()
```

## Summary

Pandas advanced indexing with `loc`, `iloc`, and MultiIndex provides powerful tools for data analysis and manipulation:

1. **loc vs iloc**: `loc` uses labels for indexing while `iloc` uses integer positions. Understanding their differences is crucial for correct data selection.

2. **MultiIndex**: Hierarchical indexing allows representation of higher-dimensional data in a two-dimensional DataFrame, enabling complex analyses.

3. **Data Selection**: Advanced techniques like cross-sectional selection with `xs`, slicing with `slice()`, and boolean indexing provide flexible ways to access data.

4. **Index Manipulation**: Methods like `stack()`, `unstack()`, `swaplevel()`, and `reorder_levels()` help in restructuring data for different analytical needs.

5. **Performance**: Index sorting, proper selection methods, and understanding the overhead of MultiIndex can significantly affect performance with large datasets.

Key best practices:
- Keep your MultiIndex levels sorted for better performance
- Use `xs` for cross-sectional selection when appropriate
- Use meaningful names for index levels
- Be explicit about level names in selection to improve code readability
- Consider using `IndexSlice` for complex selections

By mastering advanced pandas indexing techniques, you can write more concise, efficient, and expressive data analysis code, especially when working with complex multidimensional datasets.
