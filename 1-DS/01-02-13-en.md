## Introduction to Data Wrangling and Transformation

Data wrangling (or data munging) is the process of transforming raw data into a more useful format for analysis. It's often considered the most time-consuming part of data science, typically taking 60-80% of a data scientist's time.

## Data Cleaning Techniques

Data cleaning involves handling missing values, removing duplicates, correcting structural errors, and dealing with outliers.

```python
# 1. Handling Missing Values
def handle_missing_values(df):
    print("Before handling missing values:")
    print(df.isnull().sum())
    
    # Fill missing age with median
    df['age'] = df['age'].fillna(df['age'].median())
    
    # Fill missing income with mean
    df['income'] = df['income'].fillna(df['income'].mean())
    
    # Fill categorical missing values
    df['customer_category'] = df['customer_category'].fillna('Unknown')
    df['feedback'] = df['feedback'].fillna('No Feedback')
    
    print("\nAfter handling missing values:")
    print(df.isnull().sum())
    
    return df

# 2. Removing Duplicates
def remove_duplicates(df):
    duplicate_count = df.duplicated().sum()
    print(f"Found {duplicate_count} duplicate rows")
    
    df = df.drop_duplicates()
    
    return df

# 3. Handling Outliers
def handle_outliers(df, column, method='iqr'):
    if method == 'iqr':
        # IQR method for outlier detection
        Q1 = df[column].quantile(0.25)
        Q3 = df[column].quantile(0.75)
        IQR = Q3 - Q1
        
        lower_bound = Q1 - 1.5 * IQR
        upper_bound = Q3 + 1.5 * IQR
        
        print(f"Column: {column}")
        print(f"IQR bounds: [{lower_bound:.2f}, {upper_bound:.2f}]")
        
        outliers = df[(df[column] < lower_bound) | (df[column] > upper_bound)]
        print(f"Found {len(outliers)} outliers")
        
        # Cap the outliers
        df[column] = np.where(df[column] < lower_bound, lower_bound, df[column])
        df[column] = np.where(df[column] > upper_bound, upper_bound, df[column])
    
    return df

# 4. Data Validation and Correction
def validate_data(df):
    # Ensure age is within reasonable range
    df['age'] = np.where((df['age'] < 18) | (df['age'] > 100), df['age'].median(), df['age'])
    
    # Ensure purchase amount is positive
    df['purchase_amount'] = np.where(df['purchase_amount'] <= 0, df['purchase_amount'].median(), df['purchase_amount'])
    
    return df

# Apply cleaning functions to the dataset
df_cleaned = df.copy()
df_cleaned = handle_missing_values(df_cleaned)
df_cleaned = remove_duplicates(df_cleaned)
df_cleaned = handle_outliers(df_cleaned, 'purchase_amount')
df_cleaned = validate_data(df_cleaned)

# Compare before and after
print("\nBefore cleaning:")
print(df.describe())
print("\nAfter cleaning:")
print(df_cleaned.describe())
```

## Feature Engineering and Transformation

Feature engineering is the process of creating new variables from existing ones to improve model performance.

```python
# Continue with our cleaned dataset
df = df_cleaned.copy()

# 1. Scaling Numerical Features
def scale_features(df, columns, method='standard'):
    df_scaled = df.copy()
    
    if method == 'standard':
        # Standardization (mean=0, std=1)
        scaler = preprocessing.StandardScaler()
        df_scaled[columns] = scaler.fit_transform(df_scaled[columns])
    
    elif method == 'minmax':
        # Min-Max Scaling (0 to 1 range)
        scaler = preprocessing.MinMaxScaler()
        df_scaled[columns] = scaler.fit_transform(df_scaled[columns])
    
    elif method == 'robust':
        # Robust Scaling (median=0, IQR=1)
        scaler = preprocessing.RobustScaler()
        df_scaled[columns] = scaler.fit_transform(df_scaled[columns])
    
    return df_scaled

# 2. Creating Polynomial Features
def create_polynomial_features(df, columns, degree=2):
    poly = preprocessing.PolynomialFeatures(degree=degree, include_bias=False)
    poly_features = poly.fit_transform(df[columns])
    
    feature_names = poly.get_feature_names_out(columns)
    poly_df = pd.DataFrame(poly_features, columns=feature_names)
    
    # Combine with original dataframe
    result = pd.concat([df.drop(columns, axis=1).reset_index(drop=True), poly_df], axis=1)
    
    return result

# 3. Binning Continuous Variables
def bin_continuous_variable(df, column, n_bins=4, strategy='quantile'):
    df_binned = df.copy()
    
    if strategy == 'quantile':
        df_binned[f'{column}_binned'] = pd.qcut(df_binned[column], q=n_bins, labels=False)
    elif strategy == 'uniform':
        df_binned[f'{column}_binned'] = pd.cut(df_binned[column], bins=n_bins, labels=False)
    
    return df_binned

# 4. Creating Interaction Features
def create_interactions(df, col1, col2):
    df_interact = df.copy()
    df_interact[f'{col1}_{col2}_interaction'] = df_interact[col1] * df_interact[col2]
    return df_interact

# 5. Extracting Date Features
def extract_date_features(df, date_column):
    df_date = df.copy()
    df_date[f'{date_column}_year'] = df_date[date_column].dt.year
    df_date[f'{date_column}_month'] = df_date[date_column].dt.month
    df_date[f'{date_column}_day'] = df_date[date_column].dt.day
    df_date[f'{date_column}_dayofweek'] = df_date[date_column].dt.dayofweek
    df_date[f'{date_column}_quarter'] = df_date[date_column].dt.quarter
    
    return df_date

# Apply transformations to our dataset
# Scale numerical features
num_cols = ['age', 'income', 'purchase_amount']
df_scaled = scale_features(df, num_cols, method='standard')

# Create polynomial features
df_poly = create_polynomial_features(df, ['age', 'income'], degree=2)

# Bin the income variable
df_binned = bin_continuous_variable(df, 'income', n_bins=4)

# Create an interaction feature
df_interact = create_interactions(df, 'age', 'purchase_amount')

# Extract date features
df_date = extract_date_features(df, 'purchase_date')

# Display examples of transformed data
print("Original data:")
print(df[['age', 'income', 'purchase_amount']].head())

print("\nScaled data:")

print("\nBinned income:")
```

## Handling Categorical Data

Categorical data requires special handling to be used in machine learning models.

```python
# 1. One-hot Encoding
def one_hot_encode(df, columns):
    df_encoded = pd.get_dummies(df, columns=columns, drop_first=False)
    return df_encoded

# 2. Label Encoding
def label_encode(df, columns):
    df_encoded = df.copy()
    label_encoders = {}
    
    for col in columns:
        le = preprocessing.LabelEncoder()
        df_encoded[col] = le.fit_transform(df_encoded[col])
        label_encoders[col] = le
    
    return df_encoded, label_encoders

# 3. Ordinal Encoding
def ordinal_encode(df, column, categories, ordered=True):
    df_encoded = df.copy()
    
    # Create a categorical data type with specified order
    cat_type = pd.CategoricalDtype(categories=categories, ordered=ordered)
    df_encoded[column] = df_encoded[column].astype(cat_type)
    
    # Convert to codes (0, 1, 2, ...)
    df_encoded[f'{column}_code'] = df_encoded[column].cat.codes
    
    return df_encoded

# 4. Target Encoding
def target_encode(df, categorical_cols, target_col, smoothing=10):
    df_encoded = df.copy()
    
    # Global mean of the target
    global_mean = df_encoded[target_col].mean()
    
    for col in categorical_cols:
        # Group by the categorical column and calculate mean of target
        category_means = df_encoded.groupby(col)[target_col].agg(['mean', 'count'])
        
        # Apply smoothing
        smoothed_means = (category_means['mean'] * category_means['count'] + 
                         global_mean * smoothing) / (category_means['count'] + smoothing)
        
        # Map the smoothed means back to the dataframe
        df_encoded[f'{col}_encoded'] = df_encoded[col].map(smoothed_means)
    
    return df_encoded

# Apply categorical transformations
# One-hot encoding
df_onehot = one_hot_encode(df, ['customer_category', 'feedback'])

# Label encoding
df_label, label_encoders = label_encode(df, ['customer_category'])

# Ordinal encoding 
feedback_categories = ['Negative', 'Neutral', 'No Feedback', 'Positive']
df_ordinal = ordinal_encode(df, 'feedback', feedback_categories)

# Target encoding
# First create a binary target variable for demonstration
df['high_purchase'] = (df['purchase_amount'] > df['purchase_amount'].median()).astype(int)
df_target = target_encode(df, ['customer_category'], 'high_purchase')

# Display results
print("Original categorical data:")
print(df[['customer_category', 'feedback']].head())

print("\nOne-hot encoded data:")
print(df_onehot.filter(like='customer_category_').head())
print(df_onehot.filter(like='feedback_').head())

print("\nLabel encoded data:")
print(df_label[['customer_category']].head())
print("Mapping:", {i: cat for i, cat in enumerate(label_encoders['customer_category'].classes_)})

print("\nOrdinal encoded data:")
print(df_ordinal[['feedback', 'feedback_code']].head())

print("\nTarget encoded data:")
print(df_target[['customer_category', 'customer_category_encoded', 'high_purchase']].head())
```

## Working with Time Series Data

Time series data requires specific techniques for processing and feature engineering.

```python
# Create a time series dataset
date_rng = pd.date_range(start='2020-01-01', end='2022-12-31', freq='D')
n_dates = len(date_rng)

# Seasonal component (yearly seasonality)
seasonal = 10 * np.sin(2 * np.pi * np.arange(n_dates) / 365)

# Trend component
trend = np.linspace(0, 30, n_dates)

# Random noise
noise = np.random.normal(0, 5, n_dates)

# Combine components
ts_values = trend + seasonal + noise

# Create dataframe
ts_df = pd.DataFrame({
    'date': date_rng,
    'value': ts_values
})

print("Time series data:")
print(ts_df.head())

# 1. Resampling Time Series
# Downsample to monthly average
monthly_avg = ts_df.resample('M', on='date').mean()
print("\nMonthly average:")
print(monthly_avg.head())

# Upsample to 6-hour intervals and fill with forward fill
ts_df_hourly = ts_df.set_index('date').resample('6H').ffill()
print("\nUpsampled to 6-hour intervals (first 24 hours):")
print(ts_df_hourly.head(4))

# 2. Time-based Features
def add_time_features(df, date_col='date'):
    df_time = df.copy()
    
    # Extract date features
    df_time['year'] = df_time[date_col].dt.year
    df_time['month'] = df_time[date_col].dt.month
    df_time['day'] = df_time[date_col].dt.day
    df_time['dayofweek'] = df_time[date_col].dt.dayofweek
    df_time['quarter'] = df_time[date_col].dt.quarter
    
    # Is weekend
    df_time['is_weekend'] = df_time[date_col].dt.dayofweek >= 5
    
    # Month and day of year for seasonality
    df_time['dayofyear'] = df_time[date_col].dt.dayofyear
    
    # Cyclical encoding of month and day of week
    df_time['month_sin'] = np.sin(2 * np.pi * df_time['month'] / 12)
    df_time['month_cos'] = np.cos(2 * np.pi * df_time['month'] / 12)
    df_time['dayofweek_sin'] = np.sin(2 * np.pi * df_time['dayofweek'] / 7)
    df_time['dayofweek_cos'] = np.cos(2 * np.pi * df_time['dayofweek'] / 7)
    
    return df_time

ts_df_features = add_time_features(ts_df)
print("\nTime series with additional features:")
print(ts_df_features.head())

# 3. Rolling Window Statistics
window_size = 7  # 7-day window

ts_df_rolling = ts_df.set_index('date').copy()
ts_df_rolling['rolling_mean_7d'] = ts_df_rolling['value'].rolling(window=window_size).mean()

print(ts_df_rolling.head(10))

def add_lag_features(df, value_col, lags=[1, 7, 30]):
    df_lag = df.copy()
    
    for lag in lags:
        df_lag[f'lag_{lag}'] = df_lag[value_col].shift(lag)
    
    return df_lag

ts_df_lag = add_lag_features(ts_df.set_index('date'), 'value', lags=[1, 7, 30])
print("\nTime series with lag features:")
print(ts_df_lag.head(10))

# 5. Difference Features
ts_df_diff = ts_df.set_index('date').copy()
ts_df_diff['diff_1'] = ts_df_diff['value'].diff(1)
ts_df_diff['diff_7'] = ts_df_diff['value'].diff(7)

plt.figure(figsize=(15, 10))
```

## Creating Data Pipelines

Data pipelines automate and streamline the process of data transformation, making your workflows reproducible and efficient.

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler, FunctionTransformer
from sklearn.impute import SimpleImputer
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

# Let's create a pipeline using our original messy dataset
df = raw_data.copy()
df = pd.DataFrame(df)

# Define numeric and categorical columns
numeric_features = ['age', 'income', 'purchase_amount']
categorical_features = ['customer_category', 'feedback']

# 1. Define Preprocessing Functions for Pipeline
def extract_date_features_pipeline(X):
    X_transformed = X.copy()
    # Convert to datetime if not already
    if not pd.api.types.is_datetime64_any_dtype(X_transformed):
        X_transformed = pd.to_datetime(X_transformed)
    
    # Extract features
    return np.column_stack([
        X_transformed.dt.year,
        X_transformed.dt.month,
        X_transformed.dt.dayofweek
    ])

# 2. Create a Preprocessing Pipeline
numeric_transformer = Pipeline(steps=[
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])

categorical_transformer = Pipeline(steps=[
    ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
    ('onehot', OneHotEncoder(handle_unknown='ignore'))
])

date_transformer = FunctionTransformer(extract_date_features_pipeline)

# 3. Combine Transformers with ColumnTransformer
preprocessor = ColumnTransformer(
    transformers=[
        ('num', numeric_transformer, numeric_features),
        ('cat', categorical_transformer, categorical_features),
        ('date', date_transformer, ['purchase_date'])
    ],
    remainder='drop'  # Drop other columns
)

# 4. Create Full Pipeline with Preprocessing and Model
full_pipeline = Pipeline(steps=[
    ('preprocessor', preprocessor),
    ('model', LinearRegression())
])

# 5. Use Pipeline in ML Workflow
# Create target variable (for example, predicting purchase amount)

def log_transform(df, columns):
```

```python
def clean_and_transform_data(df, replace_missing=True, handle_outliers=True, 
                           create_features=True, drop_duplicates=True):
    """
    Clean and transform a dataset with configurable options.
    
    Parameters
    ----------
    df : pandas.DataFrame
        The input dataframe to process
    replace_missing : bool, default=True
        Whether to replace missing values
    handle_outliers : bool, default=True
        Whether to handle outliers in numerical columns
    create_features : bool, default=True
        Whether to create additional features
    drop_duplicates : bool, default=True
        Whether to drop duplicate rows
        
    Returns
    -------
    pandas.DataFrame
        The processed dataframe
    """
    result = df.copy()
    
    # Document important steps with comments
    if replace_missing:
        # Replace missing values with appropriate strategies for each column
        result['age'] = result['age'].fillna(result['age'].median())  # Use median for age
        result['income'] = result['income'].fillna(result['income'].mean())  # Mean for income
        result['customer_category'] = result['customer_category'].fillna('Unknown')  # Unknown for categories
    
    if handle_outliers:
        # Cap outliers at 3 standard deviations from the mean
        for col in ['age', 'income', 'purchase_amount']:
            mean_val = result[col].mean()
            std_val = result[col].std()
            lower_bound = mean_val - 3 * std_val
            upper_bound = mean_val + 3 * std_val
            result[col] = result[col].clip(lower=lower_bound, upper=upper_bound)
    
    if create_features:
        # Create basic features that help with analysis
        if 'purchase_date' in result.columns:
            result['purchase_month'] = result['purchase_date'].dt.month
            result['purchase_dayofweek'] = result['purchase_date'].dt.dayofweek
    
    if drop_duplicates:
        # Remove duplicate rows to prevent bias in analysis
        initial_rows = len(result)
        result = result.drop_duplicates()
        dropped = initial_rows - len(result)
        print(f"Dropped {dropped} duplicate rows")
    
    return result

def optimize_dataframe_memory(df):
    """Optimize the memory usage of a pandas DataFrame"""
    optimized_df = df.copy()
    
    for col in optimized_df.columns:
        col_type = optimized_df[col].dtype
        
        # Numeric columns
        if col_type in ['int64', 'float64']:
            max_val = optimized_df[col].max()
            min_val = optimized_df[col].min()
            
            # Downcast integers
            if col_type == 'int64':
                if min_val >= 0:  # Unsigned integers
                    if max_val < 256:
                        optimized_df[col] = optimized_df[col].astype('uint8')
                    elif max_val < 65536:
                        optimized_df[col] = optimized_df[col].astype('uint16')
                    elif max_val < 4294967296:
                        optimized_df[col] = optimized_df[col].astype('uint32')
                else:  # Signed integers
                    if min_val > -128 and max_val < 128:
                        optimized_df[col] = optimized_df[col].astype('int8')
                    elif min_val > -32768 and max_val < 32768:
                        optimized_df[col] = optimized_df[col].astype('int16')
                    elif min_val > -2147483648 and max_val < 2147483648:
                        optimized_df[col] = optimized_df[col].astype('int32')
            
            # Downcast floats
            elif col_type == 'float64':
                optimized_df[col] = pd.to_numeric(optimized_df[col], downcast='float')
        
        # Categorical columns
        elif col_type == 'object':
            if len(optimized_df[col].unique()) / len(optimized_df) < 0.5:  # If less than 50% unique values
                optimized_df[col] = optimized_df[col].astype('category')
    
    # Print memory usage comparison
    original_memory = df.memory_usage(deep=True).sum() / 1024**2
    optimized_memory = optimized_df.memory_usage(deep=True).sum() / 1024**2
    
    print(f"Original memory usage: {original_memory:.2f} MB")
    print(f"Optimized memory usage: {optimized_memory:.2f} MB")
    print(f"Memory reduced by: {100 * (1 - optimized_memory/original_memory):.2f}%")
    
    return optimized_df
```

## Summary

Data wrangling and transformation are crucial steps in the data science workflow that can make or break your analysis. Here are the key takeaways:

1. **Data Cleaning** is often the most time-consuming part of data science but is critical for accurate analysis. Key techniques include handling missing values, removing duplicates, and addressing outliers.

2. **Data Reshaping** transforms your data structure to meet analysis requirements, using operations like pivot tables, melting, and stacking/unstacking.

3. **Feature Engineering** creates new variables that can significantly improve model performance through scaling, binning, interactions, and polynomial features.

4. **Categorical Data Encoding** converts categorical variables into numeric representations that machine learning algorithms can process using techniques like one-hot encoding, label encoding, and target encoding.

5. **Aggregation and Grouping** operations allow for data summarization and revealing patterns at different levels of granularity.

6. **Time Series Transformation** uses specialized techniques like resampling, lag features, and rolling statistics to extract temporal patterns.

7. **Data Pipelines** create reproducible, automated workflows that streamline the data processing journey from raw data to analysis-ready datasets.

8. **Best Practices** emphasize efficient, well-documented, and maintainable code for data wrangling tasks.

By mastering these data wrangling and transformation techniques, you can more effectively prepare your data for visualization, modeling, and analysis, leading to more accurate and meaningful insights.
