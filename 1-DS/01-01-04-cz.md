## 1. Úvod do Pandas DataFrame

Pandas je výkonná knihovna jazyka Python pro manipulaci s daty a jejich analýzu. DataFrame je její hlavní datovou strukturou, která poskytuje flexibilní 2-rozměrnou tabulku s označenými osami (řádky a sloupci). DataFrames jsou podobné tabulkám v Excelu nebo SQL tabulkám, což je činí intuitivními pro analýzu dat.

```python
# Instalace pandas (pokud jste ji ještě nenainstalovali)
# pip install pandas

# Import knihovny pandas
import pandas as pd

# Zobrazení verze pandas
print(f"Verze Pandas: {pd.__version__}")
```

Klíčové vlastnosti Pandas DataFrames zahrnují:
- Sloupcově orientovaná struktura pro různé datové typy
- Proměnlivá velikost (sloupce lze vkládat a mazat)
- Automatické a explicitní zarovnání dat
- Výkonná funkcionalita pro seskupování
- Flexibilní práce s chybějícími daty
- Snadné slučování a spojování datových sad

## 2. Vytváření DataFrames

Existuje několik způsobů, jak vytvořit pandas DataFrame:

```python
import pandas as pd
import numpy as np

# 1. Vytvoření DataFrame ze slovníku seznamů
data_dict = {
    'Jméno': ['Jan', 'Anna', 'Petr', 'Linda'],
    'Věk': [28, 34, 29, 42],
    'Město': ['Praha', 'Paříž', 'Berlín', 'Londýn'],
    'Plat': [65000, 70000, 62000, 85000]
}

df1 = pd.DataFrame(data_dict)
print("DataFrame ze slovníku:")
print(df1)
print("\n")

# 2. Vytvoření DataFrame ze seznamu slovníků
data_list = [
    {'Jméno': 'Jan', 'Věk': 28, 'Město': 'Praha', 'Plat': 65000},
    {'Jméno': 'Anna', 'Věk': 34, 'Město': 'Paříž', 'Plat': 70000},
    {'Jméno': 'Petr', 'Věk': 29, 'Město': 'Berlín', 'Plat': 62000},
    {'Jméno': 'Linda', 'Věk': 42, 'Město': 'Londýn', 'Plat': 85000}
]

df2 = pd.DataFrame(data_list)
print("DataFrame ze seznamu slovníků:")
print(df2)
print("\n")

# 3. Vytvoření DataFrame z NumPy pole
array_data = np.array([['Jan', 28, 'Praha', 65000],
                       ['Anna', 34, 'Paříž', 70000],
                       ['Petr', 29, 'Berlín', 62000],
                       ['Linda', 42, 'Londýn', 85000]])

df3 = pd.DataFrame(array_data, columns=['Jméno', 'Věk', 'Město', 'Plat'])
print("DataFrame z NumPy pole:")
print(df3)
print("\n")

# 4. Vytvoření prázdného DataFrame a přidání dat
df4 = pd.DataFrame()
df4['Jméno'] = ['Jan', 'Anna', 'Petr', 'Linda']
df4['Věk'] = [28, 34, 29, 42]
df4['Město'] = ['Praha', 'Paříž', 'Berlín', 'Londýn']
df4['Plat'] = [65000, 70000, 62000, 85000]

print("DataFrame vytvořený přidáním sloupců:")
print(df4)
print("\n")

# 5. Vytvoření DataFrame se specifickým indexem
df5 = pd.DataFrame(data_dict, index=['A', 'B', 'C', 'D'])
print("DataFrame s vlastním indexem:")
print(df5)
```

## 3. Prozkoumávání DataFrames: Základní atributy a metody

Po vytvoření DataFrame můžete použít různé atributy a metody k prozkoumání jeho struktury a obsahu:

```python
# Vytvoření vzorového DataFrame
data = {
    'Jméno': ['Jan', 'Anna', 'Petr', 'Linda', 'Bob'],
    'Věk': [28, 34, 29, 42, 35],
    'Pohlaví': ['M', 'Ž', 'M', 'Ž', 'M'],
    'Město': ['Praha', 'Paříž', 'Berlín', 'Londýn', 'Madrid'],
    'Plat': [65000, 70000, 62000, 85000, 72000]
}
df = pd.DataFrame(data)

# Základní atributy
print("Základní atributy DataFrame:")
print(f"Tvar (řádky, sloupce): {df.shape}")
print(f"Počet dimenzí: {df.ndim}")
print(f"Velikost (celkový počet prvků): {df.size}")
print(f"Datové typy sloupců:\n{df.dtypes}")
print(f"Názvy sloupců: {list(df.columns)}")
print(f"Index (označení řádků): {list(df.index)}")
print("\n")

# Základní informační metody
print("Základní informační metody:")
print("Informace o DataFrame:")
df.info()
print("\nPrvní 3 řádky:")
print(df.head(3))
print("\nPoslední 2 řádky:")
print(df.tail(2))
print("\nNáhodný vzorek 2 řádků:")
print(df.sample(2))
print("\nSouhrnné statistiky:")
print(df.describe())
print("\nZákladní hodnoty dat:")
print(df.values)
```

## 4. Indexování a výběr dat

Pandas poskytuje více způsobů, jak vybírat a přistupovat k datům v DataFrame:

```python
# Vytvoření vzorového DataFrame
data = {
    'Jméno': ['Jan', 'Anna', 'Petr', 'Linda', 'Bob'],
    'Věk': [28, 34, 29, 42, 35],
    'Město': ['Praha', 'Paříž', 'Berlín', 'Londýn', 'Madrid'],
    'Plat': [65000, 70000, 62000, 85000, 72000]
}
df = pd.DataFrame(data)
print("Původní DataFrame:")
print(df)
print("\n")

# Výběr sloupců
print("Výběr sloupců:")
print("\nJeden sloupec jako Series:")
print(df['Jméno'])
print("\nVíce sloupců:")
print(df[['Jméno', 'Plat']])
print("\n")

# Výběr řádků pomocí loc (založeno na označeních)
print("Použití loc (založeno na označeních):")
print("\nJeden řádek podle indexu:")
print(df.loc[2])
print("\nVíce řádků podle indexů:")
print(df.loc[1:3])
print("\nKonkrétní řádky a sloupce:")
print(df.loc[1:3, ['Jméno', 'Plat']])
print("\n")

# Výběr řádků pomocí iloc (založeno na pozici)
print("Použití iloc (založeno na pozici):")
print("\nJeden řádek podle pozice:")
print(df.iloc[2])
print("\nVíce řádků podle pozice:")
print(df.iloc[1:3])
print("\nKonkrétní řádky a sloupce podle pozice:")
print(df.iloc[1:3, [0, 3]])
print("\n")

# Booleovské indexování
print("Booleovské indexování:")
print("\nŘádky kde Věk > 30:")
print(df[df['Věk'] > 30])
print("\nŘádky kde Město je 'Londýn' nebo 'Paříž':")
print(df[df['Město'].isin(['Londýn', 'Paříž'])])
print("\nKomplexní podmínka (Věk > 30 a Plat > 70000):")
print(df[(df['Věk'] > 30) & (df['Plat'] > 70000)])
```

## 5. Základní operace s DataFrame

DataFrames podporují různé matematické a statistické operace:

```python
import pandas as pd
import numpy as np

# Vytvoření vzorového DataFrame
data = {
    'A': [10, 20, 30, 40, 50],
    'B': [5, 10, 15, 20, 25],
    'C': [2, 4, 6, 8, 10]
}
df = pd.DataFrame(data)
print("Původní DataFrame:")
print(df)
print("\n")

# Matematické operace
print("Matematické operace:")
print("\nA + B (sčítání sloupců):")
print(df['A'] + df['B'])
print("\nNásobení sloupce skalárem:")
print(df['A'] * 2)
print("\nPřidání konstanty k celému DataFrame:")
print(df + 5)
print("\n")

# Statistické operace
print("Statistické operace:")
print(f"Průměr každého sloupce:\n{df.mean()}")
print(f"Součet každého sloupce:\n{df.sum()}")
print(f"Minimální hodnoty:\n{df.min()}")
print(f"Maximální hodnoty:\n{df.max()}")
print(f"Směrodatná odchylka:\n{df.std()}")
print("\n")

# Aplikace funkcí
print("Aplikace funkcí:")
print("\nAplikace funkce na každý prvek (odmocnina):")
print(np.sqrt(df))
print("\nAplikace vlastní funkce na sloupec:")
print(df['A'].apply(lambda x: x**2))
print("\nAplikace funkce na řádky (součet napříč sloupci):")
print(df.apply(sum, axis=1))
print("\n")

# Kumulativní operace
print("Kumulativní operace:")
print("\nKumulativní součet:")
print(df.cumsum())
print("\nKumulativní součin:")
print(df.cumprod())
```

## 6. Práce se sloupci

Pandas usnadňuje manipulaci se sloupci v DataFrame:

```python
import pandas as pd

# Vytvoření vzorového DataFrame
data = {
    'Jméno': ['Jan', 'Anna', 'Petr', 'Linda', 'Bob'],
    'Věk': [28, 34, 29, 42, 35],
    'Město': ['Praha', 'Paříž', 'Berlín', 'Londýn', 'Madrid']
}
df = pd.DataFrame(data)
print("Původní DataFrame:")
print(df)
print("\n")

# Přidání nového sloupce
print("Přidání nových sloupců:")
df['Země'] = ['Česko', 'Francie', 'Německo', 'UK', 'Španělsko']
print("\nPřidání jednoho sloupce:")
print(df)

# Přidání sloupce založeného na jiných sloupcích
df['Věk v měsících'] = df['Věk'] * 12
print("\nPřidání sloupce odvozeného z jiného sloupce:")
print(df)

# Přidání sloupce s jedinou hodnotou
df['Status'] = 'Aktivní'
print("\nPřidání sloupce s konstantní hodnotou:")
print(df)
print("\n")

# Přejmenování sloupců
print("Přejmenování sloupců:")
df = df.rename(columns={'Jméno': 'Celé jméno', 'Věk': 'Věk (roky)'})
print(df)

# Alternativně, přejmenování všech sloupců najednou
df.columns = ['Celé jméno', 'Věk (roky)', 'Město', 'Země', 'Věk v měsících', 'Status']
print("\n")

# Mazání sloupců
print("Mazání sloupců:")
df_temp = df.copy()  # Vytvoření kopie, abychom nemodifikovali originál

# Smazání jednoho sloupce
df_temp = df_temp.drop('Status', axis=1)
print("\nPo smazání sloupce 'Status':")
print(df_temp)

# Smazání více sloupců
df_temp = df_temp.drop(['Věk v měsících', 'Země'], axis=1)
print("\nPo smazání více sloupců:")
print(df_temp)
print("\n")

# Výběr specifických sloupců a změna pořadí
print("Změna pořadí sloupců:")
df_reordered = df[['Město', 'Země', 'Celé jméno', 'Věk (roky)', 'Věk v měsících', 'Status']]
print(df_reordered)
```

## 7. Práce s řádky

Manipulace s řádky v DataFrame je stejně důležitá jako práce se sloupci:

```python
import pandas as pd

# Vytvoření vzorového DataFrame
data = {
    'Jméno': ['Jan', 'Anna', 'Petr', 'Linda', 'Bob'],
    'Věk': [28, 34, 29, 42, 35],
    'Město': ['Praha', 'Paříž', 'Berlín', 'Londýn', 'Madrid']
}
df = pd.DataFrame(data)
print("Původní DataFrame:")
print(df)
print("\n")

# Přidání nového řádku pomocí append (zastaralé v novějších verzích pandas, ale stále běžné)
nový_řádek = pd.DataFrame({'Jméno': ['Sara'], 'Věk': [31], 'Město': ['Řím']})

# V novějších verzích pandas použijte místo append concat
df_new = pd.concat([df, nový_řádek], ignore_index=True)
print("Po přidání nového řádku:")
print(df_new)
print("\n")

# Přidání více řádků
více_řádků = pd.DataFrame({
    'Jméno': ['Mike', 'Emma'],
    'Věk': [45, 27],
    'Město': ['Chicago', 'Amsterdam']
})
df_new = pd.concat([df_new, více_řádků], ignore_index=True)
print("Po přidání více řádků:")
print(df_new)
print("\n")

# Mazání řádků
print("Mazání řádků:")
df_temp = df_new.copy()  # Vytvoření kopie, abychom nemodifikovali originál

# Smazání řádku podle indexu
df_temp = df_temp.drop(1)  # Smazání řádku s indexem 1
print("\nPo smazání řádku s indexem 1:")
print(df_temp)

# Smazání více řádků
df_temp = df_new.drop([3, 5])
print("\nPo smazání řádků s indexy 3 a 5:")
print(df_temp)

# Mazání řádků na základě podmínky
df_filtered = df_new[df_new['Věk'] >= 30]
print("\nPonechání pouze řádků, kde Věk >= 30:")
print(df_filtered)

# Resetování indexu po smazání řádků
df_filtered = df_filtered.reset_index(drop=True)
print("\nPo resetování indexu:")
print(df_filtered)
```

## 8. Třídění a filtrování dat

Třídění a filtrování jsou základní operace pro analýzu dat:

```python
import pandas as pd

# Vytvoření vzorového DataFrame
data = {
    'Jméno': ['Jan', 'Anna', 'Petr', 'Linda', 'Bob', 'Emma'],
    'Věk': [28, 34, 29, 42, 35, 34],
    'Město': ['Praha', 'Paříž', 'Berlín', 'Londýn', 'Madrid', 'Paříž'],
    'Plat': [65000, 70000, 62000, 85000, 72000, 68000]
}
df = pd.DataFrame(data)
print("Původní DataFrame:")
print(df)
print("\n")

# Třídění podle jednoho sloupce
print("Třídění dat:")
print("\nTřídění podle Věku (vzestupně):")
print(df.sort_values('Věk'))

print("\nTřídění podle Věku (sestupně):")
print(df.sort_values('Věk', ascending=False))

# Třídění podle více sloupců
print("\nTřídění podle Města (vzestupně) a poté podle Věku (sestupně):")
print(df.sort_values(['Město', 'Věk'], ascending=[True, False]))
print("\n")

# Základní filtrování
print("Filtrování dat:")
print("\nŘádky kde Věk > 30:")
print(df[df['Věk'] > 30])

print("\nŘádky kde Město je 'Paříž':")
print(df[df['Město'] == 'Paříž'])

# Komplexní filtrování s více podmínkami
print("\nŘádky kde Věk > 30 A Plat > 70000:")
print(df[(df['Věk'] > 30) & (df['Plat'] > 70000)])

print("\nŘádky kde Město je 'Paříž' NEBO Město je 'Londýn':")
print(df[(df['Město'] == 'Paříž') | (df['Město'] == 'Londýn')])

# Použití isin pro porovnání s více hodnotami
print("\nŘádky kde Město je jedno z ['Paříž', 'Londýn', 'Berlín']:")
print(df[df['Město'].isin(['Paříž', 'Londýn', 'Berlín'])])

# Negace s ~
print("\nŘádky kde Město NENÍ 'Paříž':")
print(df[~(df['Město'] == 'Paříž')])
# Alternativně: df[df['Město'] != 'Paříž']

# Filtrování podle řetězců
print("\nJména začínající na 'P':")
print(df[df['Jméno'].str.startswith('P')])

print("\nMěsta obsahující písmeno 'o':")
print(df[df['Město'].str.contains('o')])
```

## 9. Základní čištění dat s DataFrame

Čištění dat je klíčový krok v analýze dat. Pandas poskytuje různé nástroje pro řešení běžných problémů s kvalitou dat:

```python
import pandas as pd
import numpy as np

# Vytvoření vzorového DataFrame s několika problémy
data = {
    'Jméno': ['Jan', 'Anna', np.nan, 'Linda', 'Bob'],
    'Věk': [28, 34, 29, np.nan, 35],
    'Město': ['praha', 'PAŘÍŽ', 'Berlín', 'Londýn', None],
    'Plat': [65000, 70000, 62000, '85000', 72000],
    'ID': [' ID001 ', 'ID002', 'ID003 ', 'ID004', ' ID005']
}
df = pd.DataFrame(data)
print("DataFrame s problémy:")
print(df)
print(df.info())
print("\n")

# 1. Řešení chybějících hodnot
print("Řešení chybějících hodnot:")
print("\nKontrola chybějících hodnot:")
print(df.isnull().sum())

# Doplnění chybějících hodnot
df_filled = df.copy()
df_filled['Jméno'] = df_filled['Jméno'].fillna('Neznámý')
df_filled['Věk'] = df_filled['Věk'].fillna(df_filled['Věk'].mean())
df_filled['Město'] = df_filled['Město'].fillna('Neznámé')
print("\nPo doplnění chybějících hodnot:")
print(df_filled)

# Odstranění řádků s chybějícími hodnotami
df_dropped = df.dropna()
print("\nPo odstranění řádků s chybějícími hodnotami:")
print(df_dropped)
print("\n")

# 2. Konverze datových typů
print("Konverze datových typů:")
print("\nPřed konverzí:")
print(df.dtypes)

# Převod Platu na číselný typ
df['Plat'] = pd.to_numeric(df['Plat'], errors='coerce')
print("\nPo převodu Platu na číselný typ:")
print(df.dtypes)
print("\n")

# 3. Čištění řetězců
print("Čištění řetězců:")
# Odstranění mezer
df['ID'] = df['ID'].str.strip()
print("\nID po odstranění mezer:")
print(df['ID'])

# Převod názvů měst na formát s velkým počátečním písmenem
df['Město'] = df['Město'].str.title()
print("\nNázvy měst s velkým počátečním písmenem:")
print(df['Město'])
print("\n")

# 4. Ošetření duplicit
# Přidání některých duplicit
duplicated_df = pd.concat([df, df.iloc[1:3]], ignore_index=True)
print("DataFrame s duplicitami:")
print(duplicated_df)

# Kontrola duplicit
print("\nDuplicitní řádky:")
print(duplicated_df.duplicated().sum())

# Odstranění duplicit
deduped_df = duplicated_df.drop_duplicates()
print("\nPo odstranění duplicit:")
print(deduped_df)

# 5. Náhrada hodnot
print("\nNáhrada hodnot:")
df['Město'] = df['Město'].replace('Praha', 'PHA')
print(df['Město'])
```

## 10. Shrnutí

V tomto úvodu do Pandas DataFrames jsme probrali:

1. **Vytváření DataFrames**: Ze slovníků, seznamů, polí a postupným přidáváním sloupců
2. **Prozkoumávání DataFrames**: Použití atributů a metod k pochopení struktury DataFrame
3. **Indexování a výběr dat**: Použití různých metod pro výběr dat ([], loc, iloc, booleovské indexování)
4. **Základní operace**: Aplikace matematických, statistických a vlastních funkcí na DataFrames
5. **Práce se sloupci**: Přidávání, úprava, přejmenování a mazání sloupců
6. **Práce s řádky**: Přidávání a odstraňování řádků a resetování indexů
7. **Třídění a filtrování**: Uspořádání dat a filtrování na základě různých podmínek
8. **Čištění dat**: Řešení chybějících hodnot, konverze datových typů a čištění řetězců

Pandas DataFrames jsou základem manipulace s daty v Pythonu a jsou nezbytné pro jakýkoliv pracovní postup v oblasti datové vědy. Jakmile se s těmito základy seznámíte, můžete prozkoumat pokročilejší funkce jako seskupování, slučování, pivotování a analýzu časových řad.

Nezapomeňte nahlédnout do [oficiální dokumentace Pandas](https://pandas.pydata.org/docs/) pro podrobné informace o všech funkcích a metodách DataFrame.
