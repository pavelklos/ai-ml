## Introduction to Feature Selection

Feature selection is the process of identifying and selecting a subset of input features that are most relevant to the target variable. Properly selected features can improve model performance, reduce training time, decrease model complexity, and mitigate overfitting.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# Load a dataset to demonstrate feature selection
cancer = load_breast_cancer()
X = pd.DataFrame(cancer.data, columns=cancer.feature_names)
y = cancer.target

print(f"Dataset shape: {X.shape}")
print(f"Number of features: {X.shape[1]}")
print(f"Feature names: {cancer.feature_names[:5]}...")

# Basic statistics about features
feature_stats = pd.DataFrame({
    'Mean': X.mean(),
    'Std': X.std(),
    'Min': X.min(),
    'Max': X.max()
}).round(2)

print("\nFeature Statistics:")
print(feature_stats.head())

# Visualize feature correlations
plt.figure(figsize=(10, 8))
correlation_matrix = X.corr().abs()
sns.heatmap(correlation_matrix, cmap='viridis', annot=False)
plt.title('Feature Correlation Matrix')
plt.tight_layout()
plt.show()

# Split the data for later use
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Standardize features
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

## Understanding Recursive Feature Elimination

Recursive Feature Elimination (RFE) is a feature selection method that works by recursively removing attributes and building a model on those attributes that remain. It uses the model accuracy to identify which attributes (and combinations of attributes) contribute the most to predicting the target attribute.

Key characteristics of RFE:
- **Wrapper method**: Uses a machine learning algorithm to evaluate feature subsets
- **Recursive elimination**: Starts with all features and gradually removes the least important ones
- **Ranking criteria**: Features are ranked based on their importance according to the model

```python
# Conceptual illustration of RFE algorithm
def conceptual_rfe(X, y, estimator, n_features_to_select):
    """
    Conceptual implementation of RFE algorithm (for illustration purposes only)
    """
    # Start with all features
    remaining_features = list(range(X.shape[1]))
    ranking = [0] * X.shape[1]
    
    while len(remaining_features) > n_features_to_select:
        # Train the model with current features
        model = clone(estimator)
        model.fit(X[:, remaining_features], y)
        
        # Get feature importances (depends on the model)
        if hasattr(model, 'coef_'):
            importances = np.abs(model.coef_[0])
        elif hasattr(model, 'feature_importances_'):
            importances = model.feature_importances_
        else:
            raise ValueError("Model doesn't have feature importance attribute")
            
        # Find the feature with the lowest importance
        min_idx = np.argmin(importances)
        least_important = remaining_features[min_idx]
        
        # Update ranking for this feature
        ranking[least_important] = len(remaining_features)
        
        # Remove the feature
        remaining_features.pop(min_idx)
        
    return remaining_features, ranking

# Note: This is just a conceptual implementation; 
# In practice, we use sklearn's RFE implementation
```

## Implementation with scikit-learn

scikit-learn provides a robust implementation of RFE through the `RFE` class. We'll demonstrate how to use it with different estimators.

```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC

# Setup a base estimator - can be any model with .fit() method and feature_importances_ or coef_
base_estimator = RandomForestClassifier(n_estimators=100, random_state=42)

# Create the RFE model and select attributes
n_features_to_select = 10  # Number of features to select
rfe = RFE(estimator=base_estimator, n_features_to_select=n_features_to_select, step=1)

# Fit RFE
rfe.fit(X_train_scaled, y_train)

# Get the selected features
selected_features = X.columns[rfe.support_]
print(f"Selected features: {selected_features.tolist()}")

# Get the feature ranking (lower rank = more important)
feature_ranking = pd.DataFrame({
    'Feature': X.columns,
    'Ranking': rfe.ranking_
}).sort_values('Ranking')
print("\nFeature Ranking:")
print(feature_ranking)

# Transform the dataset to keep only selected features
X_train_rfe = rfe.transform(X_train_scaled)
X_test_rfe = rfe.transform(X_test_scaled)

print(f"Original feature count: {X_train_scaled.shape[1]}")
print(f"Reduced feature count: {X_train_rfe.shape[1]}")

# Let's evaluate with a simple model to see the impact
from sklearn.metrics import accuracy_score

# Model with all features
model_all = LogisticRegression(max_iter=1000)
model_all.fit(X_train_scaled, y_train)
y_pred_all = model_all.predict(X_test_scaled)
accuracy_all = accuracy_score(y_test, y_pred_all)

# Model with selected features
model_rfe = LogisticRegression(max_iter=1000)
model_rfe.fit(X_train_rfe, y_train)
y_pred_rfe = model_rfe.predict(X_test_rfe)
accuracy_rfe = accuracy_score(y_test, y_pred_rfe)

print(f"Accuracy with all features: {accuracy_all:.4f}")
print(f"Accuracy with {n_features_to_select} selected features: {accuracy_rfe:.4f}")
```

## Recursive Feature Elimination with Cross-Validation

Instead of manually specifying the number of features to select, we can use cross-validation to determine the optimal number of features automatically. This is done using the `RFECV` class.

```python
from sklearn.feature_selection import RFECV
from sklearn.model_selection import StratifiedKFold

# Setup cross-validation
cv = StratifiedKFold(5, shuffle=True, random_state=42)

# Create the RFECV model
estimator = RandomForestClassifier(n_estimators=100, random_state=42)
rfecv = RFECV(
    estimator=estimator,
    step=1,
    cv=cv,
    scoring='accuracy',
    min_features_to_select=5
)

# Fit RFECV
rfecv.fit(X_train_scaled, y_train)

# Number of optimal features
print(f"Optimal number of features: {rfecv.n_features_}")
print(f"Best features: {X.columns[rfecv.support_].tolist()}")

# Plot number of features versus cross-validation scores
plt.figure(figsize=(10, 6))
plt.xlabel("Number of features selected")
plt.ylabel("Cross validation score (accuracy)")
plt.plot(range(rfecv.min_features_to_select,
                len(rfecv.cv_results_['mean_test_score']) + rfecv.min_features_to_select),
         rfecv.cv_results_['mean_test_score'])
plt.title("RFECV: Performance vs Number of Features")
plt.grid(True)
plt.show()

# Transform the dataset to keep only the optimal features
X_train_rfecv = rfecv.transform(X_train_scaled)
X_test_rfecv = rfecv.transform(X_test_scaled)

# Evaluate model with optimal feature set
model_rfecv = LogisticRegression(max_iter=1000)
model_rfecv.fit(X_train_rfecv, y_train)
y_pred_rfecv = model_rfecv.predict(X_test_rfecv)
accuracy_rfecv = accuracy_score(y_test, y_pred_rfecv)

print(f"Accuracy with all features: {accuracy_all:.4f}")
print(f"Accuracy with {rfecv.n_features_} optimal features: {accuracy_rfecv:.4f}")
```

## Visualization of Feature Selection Results

Visualizing the feature selection process helps us understand the importance of different features and their impact on model performance.

```python
# Plot feature importance and selection status
def plot_feature_selection_results(feature_names, support, ranking):
    """Visualize RFE results with sorted feature importance"""
    # Create a dataframe for easier handling
    results = pd.DataFrame({
        'Feature': feature_names,
        'Selected': support,
        'Ranking': ranking
    })
    
    # Sort by ranking (lower rank = more important)
    results = results.sort_values('Ranking')
    
    # Plot
    plt.figure(figsize=(12, 8))
    
    # Differentiate selected vs non-selected features
    selected = results[results['Selected']]
    not_selected = results[~results['Selected']]
    
    plt.barh(range(len(results)), 1/results['Ranking'], align='center', 
             color=[('green' if s else 'red') for s in results['Selected']])
    plt.yticks(range(len(results)), results['Feature'])
    plt.xlabel('1/Ranking (higher = more important)')
    plt.title('Feature Importance based on RFE')
    
    # Add a legend
    import matplotlib.patches as patches
    selected_patch = patches.Patch(color='green', label='Selected')
    not_selected_patch = patches.Patch(color='red', label='Not Selected')
    plt.legend(handles=[selected_patch, not_selected_patch])
    
    plt.gca().invert_yaxis()  # Display the most important feature at the top
    plt.tight_layout()
    plt.grid(axis='x')
    plt.show()

# Visualize RFE results
plot_feature_selection_results(X.columns, rfe.support_, rfe.ranking_)

# Visualize RFECV results
```

## Feature Selection for Different ML Algorithms

Different machine learning algorithms may benefit from different features. Let's compare RFE with various base estimators.

```python
def compare_rfe_with_models(X_train, X_test, y_train, y_test, feature_names, n_features=10):
    """Compare RFE with different base estimators"""
    # Define the models to use as base estimators
    models = {
        'Random Forest': RandomForestClassifier(n_estimators=100, random_state=42),
        'Logistic Regression': LogisticRegression(max_iter=1000, random_state=42),
        'SVM': SVC(kernel='linear', random_state=42)
    }
    
    results = {}
    selected_features = {}
    
    for name, model in models.items():
        # Create RFE
        rfe = RFE(estimator=model, n_features_to_select=n_features, step=1)
        
        # Fit RFE
        rfe.fit(X_train, y_train)
        
        # Get selected features
        features = feature_names[rfe.support_].tolist()
        selected_features[name] = features
        
        # Transform data
        X_train_rfe = rfe.transform(X_train)
        X_test_rfe = rfe.transform(X_test)
        
        # Train and evaluate
        model.fit(X_train_rfe, y_train)
        accuracy = model.score(X_test_rfe, y_test)
        results[name] = accuracy
    
    return results, selected_features

# Compare RFE with different base estimators
comparison_results, comparison_features = compare_rfe_with_models(
    X_train_scaled, X_test_scaled, y_train, y_test, X.columns, n_features=10
)

# Display the results
print("Accuracy with different base estimators:")
for model_name, accuracy in comparison_results.items():
    print(f"{model_name}: {accuracy:.4f}")
    print(f"  Selected features: {comparison_features[model_name]}")
    print()

# Visualize the comparison
plt.figure(figsize=(10, 6))
bars = plt.bar(comparison_results.keys(), comparison_results.values())
plt.ylim(0.9, 1.0)  # Adjust based on your results
plt.ylabel('Accuracy')
plt.title('RFE Performance with Different Base Estimators')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

# Find common features across all models
common_features = set(comparison_features['Random Forest'])
for features in comparison_features.values():
    common_features = common_features.intersection(set(features))

print(f"Common features across all models: {list(common_features)}")
```

## RFE vs Other Feature Selection Methods

RFE is just one of many feature selection methods. Let's compare it with other popular approaches.

```python
from sklearn.feature_selection import SelectKBest, f_classif, SelectFromModel
from sklearn.feature_selection import mutual_info_classif, chi2

def compare_feature_selection_methods(X_train, X_test, y_train, y_test, feature_names, n_features=10):
    """Compare different feature selection methods"""
    results = {}
    selected_features = {}
    
    # 1. RFE with Random Forest
    rfe = RFE(RandomForestClassifier(n_estimators=100, random_state=42), 
              n_features_to_select=n_features)
    rfe.fit(X_train, y_train)
    X_train_rfe = rfe.transform(X_train)
    X_test_rfe = rfe.transform(X_test)
    
    model_rfe = LogisticRegression(max_iter=1000)
    model_rfe.fit(X_train_rfe, y_train)
    accuracy_rfe = model_rfe.score(X_test_rfe, y_test)
    
    results['RFE'] = accuracy_rfe
    selected_features['RFE'] = feature_names[rfe.support_].tolist()
    
    # 2. Filter Method: SelectKBest with ANOVA F-value
    selector_f = SelectKBest(f_classif, k=n_features)
    selector_f.fit(X_train, y_train)
    X_train_f = selector_f.transform(X_train)
    X_test_f = selector_f.transform(X_test)
    
    model_f = LogisticRegression(max_iter=1000)
    model_f.fit(X_train_f, y_train)
    accuracy_f = model_f.score(X_test_f, y_test)
    
    results['ANOVA F-value'] = accuracy_f
    selected_features['ANOVA F-value'] = feature_names[selector_f.get_support()].tolist()
    
    # 3. Filter Method: SelectKBest with Mutual Information
    selector_mi = SelectKBest(mutual_info_classif, k=n_features)
    selector_mi.fit(X_train, y_train)
    X_train_mi = selector_mi.transform(X_train)
    X_test_mi = selector_mi.transform(X_test)
    
    model_mi = LogisticRegression(max_iter=1000)
    model_mi.fit(X_train_mi, y_train)
    accuracy_mi = model_mi.score(X_test_mi, y_test)
    
    results['Mutual Information'] = accuracy_mi
    selected_features['Mutual Information'] = feature_names[selector_mi.get_support()].tolist()
    
    # 4. Embedded Method: SelectFromModel with Random Forest
    selector_rf = SelectFromModel(RandomForestClassifier(n_estimators=100, random_state=42), 
                                max_features=n_features, threshold=-np.inf)
    selector_rf.fit(X_train, y_train)
    X_train_rf = selector_rf.transform(X_train)
    X_test_rf = selector_rf.transform(X_test)
    
    model_rf = LogisticRegression(max_iter=1000)
    model_rf.fit(X_train_rf, y_train)
    accuracy_rf = model_rf.score(X_test_rf, y_test)
    
    results['Random Forest Importance'] = accuracy_rf
    selected_features['Random Forest Importance'] = feature_names[selector_rf.get_support()].tolist()
    
    return results, selected_features

# Compare different feature selection methods
fs_comparison_results, fs_comparison_features = compare_feature_selection_methods(
    X_train_scaled, X_test_scaled, y_train, y_test, X.columns, n_features=10
)

# Display the results
print("Accuracy with different feature selection methods:")
for method_name, accuracy in fs_comparison_results.items():
    print(f"{method_name}: {accuracy:.4f}")
    print(f"  Selected features: {fs_comparison_features[method_name]}")
    print()

# Visualize the comparison
plt.figure(figsize=(12, 6))
bars = plt.bar(fs_comparison_results.keys(), fs_comparison_results.values())
plt.ylim(0.9, 1.0)  # Adjust based on your results
plt.ylabel('Accuracy')
plt.title('Comparison of Feature Selection Methods')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

## Practical Considerations and Best Practices

When implementing recursive feature elimination, consider these best practices to ensure effective feature selection:

```python
# Best practices for RFE
"""
1. Scale your features before applying RFE
2. Choose appropriate base estimator for your problem
3. Consider the computational cost for large datasets
4. Use RFECV to automatically select the optimal number of features
5. Beware of feature correlation
6. Consider domain knowledge when interpreting results
7. Combine with other feature selection methods for robust results
"""

# Handling highly correlated features
def handle_correlations(X, threshold=0.8):
    """Identify and handle highly correlated features"""
    corr_matrix = X.corr().abs()
    
    # Extract upper triangle of correlation matrix
    upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool))
    
    # Find features with correlation greater than threshold
    to_drop = [column for column in upper.columns if any(upper[column] > threshold)]
    
    print(f"Found {len(to_drop)} highly correlated features to drop")
    print(f"Features to drop: {to_drop}")
    
    return to_drop

# Example of handling correlated features before RFE
correlated_features = handle_correlations(X, threshold=0.8)
X_uncorrelated = X.drop(columns=correlated_features)

print(f"Original shape: {X.shape}")
print(f"Shape after removing correlated features: {X_uncorrelated.shape}")

# Then apply RFE on the uncorrelated features
X_train_uncorr, X_test_uncorr, y_train, y_test = train_test_split(
    X_uncorrelated, y, test_size=0.3, random_state=42
)

# Scale features
scaler = StandardScaler()
X_train_uncorr_scaled = scaler.fit_transform(X_train_uncorr)
X_test_uncorr_scaled = scaler.transform(X_test_uncorr)

# Apply RFE on uncorrelated features
rfe_uncorr = RFE(
    RandomForestClassifier(n_estimators=100, random_state=42),
    n_features_to_select=min(10, X_uncorrelated.shape[1]),  # In case we have fewer than 10 features left
    step=1
)
rfe_uncorr.fit(X_train_uncorr_scaled, y_train)

# Show selected features
selected_uncorr = X_uncorrelated.columns[rfe_uncorr.support_].tolist()
print(f"Selected features after correlation handling: {selected_uncorr}")
```

## Case Study: Real-world Application

Let's apply RFE to a more complex real-world dataset to demonstrate its practical application.

```python
from sklearn.datasets import fetch_california_housing
import time

# Load a larger dataset
housing = fetch_california_housing()
X_housing = pd.DataFrame(housing.data, columns=housing.feature_names)
y_housing = housing.target

print(f"Dataset shape: {X_housing.shape}")
print(f"Features: {housing.feature_names}")

# See basic statistics
print(X_housing.describe())

# Split the data
X_h_train, X_h_test, y_h_train, y_h_test = train_test_split(
    X_housing, y_housing, test_size=0.3, random_state=42
)

# Scale features
scaler = StandardScaler()
X_h_train_scaled = scaler.fit_transform(X_h_train)
X_h_test_scaled = scaler.transform(X_h_test)

# Baseline model without feature selection
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error, r2_score

start_time = time.time()
baseline_model = RandomForestRegressor(n_estimators=100, random_state=42)
baseline_model.fit(X_h_train_scaled, y_h_train)
y_h_pred_baseline = baseline_model.predict(X_h_test_scaled)
baseline_time = time.time() - start_time

# Evaluate baseline model
baseline_mse = mean_squared_error(y_h_test, y_h_pred_baseline)
baseline_r2 = r2_score(y_h_test, y_h_pred_baseline)

print(f"Baseline Model (all features):")
print(f"  Training Time: {baseline_time:.2f} seconds")
print(f"  MSE: {baseline_mse:.4f}")
print(f"  R²: {baseline_r2:.4f}")

# Apply RFECV for feature selection
start_time = time.time()
rfecv_housing = RFECV(
    estimator=RandomForestRegressor(n_estimators=50, random_state=42),  # Using lighter model for speed
    step=1,
    cv=5,
    scoring='neg_mean_squared_error',
    min_features_to_select=3
)

rfecv_housing.fit(X_h_train_scaled, y_h_train)
rfecv_time = time.time() - start_time

# Transform data with selected features
X_h_train_rfecv = rfecv_housing.transform(X_h_train_scaled)
X_h_test_rfecv = rfecv_housing.transform(X_h_test_scaled)

# Train model with selected features
start_time = time.time()
rfecv_model = RandomForestRegressor(n_estimators=100, random_state=42)
rfecv_model.fit(X_h_train_rfecv, y_h_train)
y_h_pred_rfecv = rfecv_model.predict(X_h_test_rfecv)
rfecv_model_time = time.time() - start_time

# Evaluate model with selected features
rfecv_mse = mean_squared_error(y_h_test, y_h_pred_rfecv)
rfecv_r2 = r2_score(y_h_test, y_h_pred_rfecv)

print(f"\nRFECV Model ({rfecv_housing.n_features_} selected features):")
print(f"  Feature Selection Time: {rfecv_time:.2f} seconds")
print(f"  Training Time: {rfecv_model_time:.2f} seconds")
print(f"  MSE: {rfecv_mse:.4f}")
print(f"  R²: {rfecv_r2:.4f}")
print(f"  Selected Features: {[housing.feature_names[i] for i in np.where(rfecv_housing.support_)[0]]}")

# Visualize the RFECV results
plt.figure(figsize=(10, 6))
plt.xlabel("Number of features selected")
plt.ylabel("Mean Squared Error (negative)")
plt.plot(range(rfecv_housing.min_features_to_select,
                len(rfecv_housing.cv_results_['mean_test_score']) + rfecv_housing.min_features_to_select),
         rfecv_housing.cv_results_['mean_test_score'])
plt.title("RFECV Results: Performance vs Number of Features")
plt.grid(True)
plt.show()
```

## Summary

Recursive Feature Elimination is a powerful technique for feature selection that can significantly improve model performance while reducing complexity. Here are the key takeaways:

1. **Importance of Feature Selection**: Reducing dimensionality by selecting relevant features can improve model performance, interpretability, and computational efficiency.

2. **RFE Mechanism**: RFE works by recursively removing the least important features based on a model's feature importance or coefficients.

3. **Cross-Validation Integration**: RFECV automatically identifies the optimal number of features using cross-validation, balancing model performance against complexity.

4. **Base Estimator Selection**: The choice of base estimator affects which features are selected, as different models value features differently.

5. **Complementary Methods**: RFE often works best when combined with other feature selection techniques and domain knowledge.

6. **Preprocessing Importance**: Feature scaling and correlation analysis are important preprocessing steps before applying RFE.

7. **Performance Benefits**: Well-executed feature selection can lead to:
   - Faster training and inference
   - Better generalization
   - Simpler models that are easier to interpret
   - Lower memory footprint

8. **Practical Considerations**: For large datasets, RFE can be computationally expensive, but strategies like increasing the step size can help.

Feature selection with RFE is not just about improving model performance but also about gaining insights into what drives your target variable. The selected features often provide valuable domain knowledge and can guide further data collection efforts.
