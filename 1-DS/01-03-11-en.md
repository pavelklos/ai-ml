## Introduction to Data Pipelines

Data pipelines are sequences of data processing elements where the output of one element is the input to the next. In data science, pipelines automate the flow of data from collection through transformation, analysis, and ultimately to visualization or model deployment.

Key benefits of data pipelines:
- **Automation**: Reduce manual intervention
- **Reproducibility**: Ensure consistent results
- **Scalability**: Handle increasing data volumes
- **Dependency Management**: Coordinate complex workflows
- **Error Handling**: Robust failure detection and recovery

```python
# Simple conceptual data pipeline
def extract():
    """Extract data from source"""
    print("Extracting data...")
    return {"data": [1, 2, 3, 4, 5]}

def transform(raw_data):
    """Transform the extracted data"""
    print("Transforming data...")
    transformed = [x * 10 for x in raw_data["data"]]
    return {"transformed_data": transformed}

def load(transformed_data):
    """Load the transformed data"""
    print("Loading data...")
    print(f"Data loaded: {transformed_data['transformed_data']}")

# Execute the pipeline
def run_pipeline():
    raw_data = extract()
    transformed_data = transform(raw_data)
    load(transformed_data)

run_pipeline()
```

## Understanding Apache Airflow

Apache Airflow is an open-source platform for orchestrating complex computational workflows and data processing pipelines. It was developed by Airbnb in 2014 and later became an Apache Software Foundation project.

### Key Concepts in Airflow:

1. **DAG (Directed Acyclic Graph)**: A collection of tasks with dependencies between them
2. **Operators**: Templates for tasks (e.g., PythonOperator, BashOperator)
3. **Tasks**: Instances of operators
4. **Task Instances**: Specific runs of a task at a point in time
5. **Scheduler**: Monitors DAGs and triggers task execution
6. **Executor**: Determines how tasks are executed
7. **Web Server**: Provides a UI for visualization and monitoring

### Installation and Setup:

## Creating DAGs in Airflow

DAGs in Airflow are defined in Python files that specify the structure of the workflow.

```python
# dags/example_dag.py
from datetime import datetime, timedelta
from airflow import DAG
from airflow.operators.python import PythonOperator

# Default arguments for all tasks in the DAG
default_args = {
    'owner': 'data_scientist',
    'depends_on_past': False,
    'start_date': datetime(2023, 1, 1),
    'email': ['data_scientist@example.com'],
    'email_on_failure': False,
    'email_on_retry': False,
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}

# Define the DAG
dag = DAG(
    'example_etl_pipeline',
    default_args=default_args,
    description='A simple ETL DAG',
    schedule_interval=timedelta(days=1),
    catchup=False
)

# Define the tasks
def extract_data(**kwargs):
    """Extract data from source"""
    print("Extracting data...")
    data = [1, 2, 3, 4, 5]
    kwargs['ti'].xcom_push(key='extracted_data', value=data)

def transform_data(**kwargs):
    """Transform the extracted data"""
    ti = kwargs['ti']
    data = ti.xcom_pull(key='extracted_data', task_ids='extract')
    print("Transforming data...")
    transformed_data = [x * 10 for x in data]
    ti.xcom_push(key='transformed_data', value=transformed_data)

def load_data(**kwargs):
    """Load the transformed data"""
    ti = kwargs['ti']
    data = ti.xcom_pull(key='transformed_data', task_ids='transform')
    print("Loading data...")
    print(f"Data loaded: {data}")

# Create task instances
extract_task = PythonOperator(
    task_id='extract',
    python_callable=extract_data,
    provide_context=True,
    dag=dag,
)

transform_task = PythonOperator(
    task_id='transform',
    python_callable=transform_data,
    provide_context=True,
    dag=dag,
)

load_task = PythonOperator(
    task_id='load',
    python_callable=load_data,
    provide_context=True,
    dag=dag,
)

# Set task dependencies
extract_task >> transform_task >> load_task
```

## Task Dependencies and Scheduling in Airflow

Airflow offers multiple ways to define task dependencies and schedule executions:

```python
# dags/advanced_dag.py
from datetime import datetime, timedelta
from airflow import DAG
from airflow.operators.python import PythonOperator
from airflow.operators.bash import BashOperator
from airflow.utils.dates import days_ago

# Default arguments
default_args = {
    'owner': 'data_scientist',
    'depends_on_past': False,
    'start_date': days_ago(1),
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}

# Create the DAG with a cron-based schedule
dag = DAG(
    'advanced_pipeline',
    default_args=default_args,
    description='Advanced data pipeline example',
    # Run at 7 AM every day
    schedule_interval='0 7 * * *',
    catchup=False
)

# Task 1: Download data
download_data = BashOperator(
    task_id='download_data',
    bash_command='echo "Downloading data from API..." && sleep 3',
    dag=dag,
)

# Task 2: Process data
def process_data(**context):
    print("Processing downloaded data...")
    # Simulate processing
    processed_data = {"processed": True, "timestamp": datetime.now().isoformat()}
    return processed_data

process_data_task = PythonOperator(
    task_id='process_data',
    python_callable=process_data,
    provide_context=True,
    dag=dag,
)

# Task 3: Train model
def train_model(**context):
    processed_data = context['ti'].xcom_pull(task_ids='process_data')
    print(f"Training model with data processed at {processed_data['timestamp']}...")
    accuracy = 0.85
    context['ti'].xcom_push(key='model_accuracy', value=accuracy)
    
train_model_task = PythonOperator(
    task_id='train_model',
    python_callable=train_model,
    provide_context=True,
    dag=dag,
)

# Task 4a and 4b: Two parallel tasks after training
evaluate_model = PythonOperator(
    task_id='evaluate_model',
    python_callable=lambda **kwargs: print(f"Model evaluation complete. "
                                         f"Accuracy: {kwargs['ti'].xcom_pull(task_ids='train_model', key='model_accuracy')}"),
    provide_context=True,
    dag=dag,
)

save_model = BashOperator(
    task_id='save_model',
    bash_command='echo "Saving model to storage..." && sleep 2 && echo "Model saved"',
    dag=dag,
)

# Define the workflow
download_data >> process_data_task >> train_model_task >> [evaluate_model, save_model]
```

## Introduction to Luigi

Luigi is another popular framework for building data pipelines, developed and open-sourced by Spotify. It focuses on dependency resolution, workflow management, and failure handling.

### Key Concepts in Luigi:

1. **Tasks**: Python classes representing units of work
2. **Targets**: Results of tasks (often files)
3. **Parameters**: Inputs that define task behavior
4. **Dependencies**: Relationships between tasks
5. **Central Scheduler**: Orchestrates task execution

## Building Luigi Tasks and Workflows

```python
# pipeline/luigi_example.py
import luigi
import pandas as pd
import numpy as np
from datetime import datetime

# 1. Download data task
class DownloadDataTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def output(self):
        return luigi.LocalTarget(f"data/raw_{self.date}.csv")
    
    def run(self):
        # Simulate data download by generating random data
        print("Downloading data...")
        df = pd.DataFrame({
            'user_id': range(1000),
            'value': np.random.randn(1000)
        })
        
        # Ensure the directory exists
        os.makedirs(os.path.dirname(self.output().path), exist_ok=True)
        
        # Save the data
        df.to_csv(self.output().path, index=False)
        print("Data downloaded successfully")

# 2. Process data task
class ProcessDataTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return DownloadDataTask(date=self.date)
    
    def output(self):
        return luigi.LocalTarget(f"data/processed_{self.date}.csv")
    
    def run(self):
        # Read input data
        df = pd.read_csv(self.input().path)
        
        # Process data
        print("Processing data...")
        df['processed_value'] = df['value'] * 2 + 1
        df['status'] = df['processed_value'].apply(lambda x: 'high' if x > 0 else 'low')
        
        # Save processed data
        df.to_csv(self.output().path, index=False)
        print("Data processed successfully")

# 3. Aggregate data task
class AggregateDataTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return ProcessDataTask(date=self.date)
    
    def output(self):
        return luigi.LocalTarget(f"data/aggregated_{self.date}.csv")
    
    def run(self):
        # Read processed data
        df = pd.read_csv(self.input().path)
        
        # Aggregate data
        print("Aggregating data...")
        agg_df = df.groupby('status').agg(
            count=('user_id', 'count'),
            avg_value=('processed_value', 'mean'),
            min_value=('processed_value', 'min'),
            max_value=('processed_value', 'max')
        ).reset_index()
        
        # Save aggregated data
        agg_df.to_csv(self.output().path, index=False)
        print("Data aggregated successfully")

# 4. Generate report task
class GenerateReportTask(luigi.Task):
    date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return AggregateDataTask(date=self.date)
    
    def output(self):
        return luigi.LocalTarget(f"reports/report_{self.date}.txt")
    
    def run(self):
        # Read aggregated data
        agg_df = pd.read_csv(self.input().path)
        
        # Generate report
        print("Generating report...")
        with self.output().open('w') as f:
            f.write(f"DATA REPORT FOR {self.date}\n")
            f.write("=" * 50 + "\n\n")
            
            for _, row in agg_df.iterrows():
                f.write(f"Status: {row['status']}\n")
                f.write(f"  Count: {row['count']}\n")
                f.write(f"  Average value: {row['avg_value']:.2f}\n")
                f.write(f"  Range: {row['min_value']:.2f} to {row['max_value']:.2f}\n\n")
                
            f.write("End of Report")
        
        print("Report generated successfully")

# Run the pipeline
if __name__ == "__main__":
    import os
    os.makedirs("data", exist_ok=True)
    os.makedirs("reports", exist_ok=True)
    luigi.build([GenerateReportTask()], local_scheduler=True)
```

## Data Pipeline Best Practices

1. **Idempotency**: Pipelines should produce the same result when run multiple times with the same inputs
2. **Atomicity**: Tasks should fully complete or fully fail, no partial updates
3. **Isolation**: Tasks should not interfere with each other
4. **Monitoring and Logging**: Track pipeline performance and errors
5. **Error Handling**: Implement retries and graceful failure mechanisms
6. **Version Control**: Track changes to pipeline code
7. **Testing**: Create unit and integration tests for pipelines
8. **Documentation**: Document pipeline behavior and requirements

Example of implementing idempotent, atomic tasks with error handling:

```python
# Example of implementing best practices in an Airflow task
from airflow.operators.python import PythonOperator
import logging
import tempfile
import os
import shutil
from atomicwrites import atomic_write

def process_data_safely(**context):
    logger = logging.getLogger(__name__)
    execution_date = context['execution_date']
    
    # Use a unique identifier for this task run
    run_id = f"process_data_{execution_date.isoformat()}"
    logger.info(f"Starting task with run_id: {run_id}")
    
    try:
        # Create a temporary directory for processing
        with tempfile.TemporaryDirectory() as temp_dir:
            # Do processing in the temporary directory
            temp_output_path = os.path.join(temp_dir, 'output.csv')
            
            # Fetch input data
            logger.info("Fetching input data")
            # ... fetching code here ...
            
            # Process data
            logger.info("Processing data")
            # ... processing code here ...
            
            # Write results to temporary file
            logger.info("Writing temporary results")
            # ... write to temp_output_path ...
            
            # Atomically move to final destination
            final_path = f"/path/to/outputs/data_{run_id}.csv"
            logger.info(f"Moving results to final destination: {final_path}")
            
            # Ensure directory exists
            os.makedirs(os.path.dirname(final_path), exist_ok=True)
            
            # Atomic write to ensure no partial files
            with atomic_write(final_path, overwrite=True) as f:
                with open(temp_output_path, 'r') as source:
                    shutil.copyfileobj(source, f)
            
        logger.info(f"Task completed successfully: {run_id}")
        return final_path
    
    except Exception as e:
        logger.error(f"Error in task {run_id}: {str(e)}")
        # Re-raise the exception so Airflow can handle retries
        raise

# Create the task
safe_process_task = PythonOperator(
    task_id='safe_data_processing',
    python_callable=process_data_safely,
    provide_context=True,
    dag=dag,
    retries=3,
    retry_delay=timedelta(minutes=5)
)
```

## Comparing Airflow and Luigi

| Feature | Apache Airflow | Luigi |
|---------|---------------|-------|
| **Core Concept** | Directed Acyclic Graphs (DAGs) | Task dependencies |
| **UI** | Rich web interface with monitoring | Simple visualization |
| **Scheduling** | Built-in scheduler with various triggers | External scheduler required |
| **Task Definition** | Task and operators definition | Class-based task definition |
| **Dependency Resolution** | Explicit using operators | Defined by requires() method |
| **Parallelism** | Multiple executors (Local, Celery, Kubernetes) | Limited built-in support |
| **Ecosystem** | Large plugin ecosystem | Smaller ecosystem |
| **Use Case** | Complex workflows with monitoring needs | Data processing pipelines |

When to choose Airflow:
- Complex workflows with intricate scheduling needs
- Need for extensive monitoring and visualization
- Integration with multiple systems and services
- Enterprise use cases requiring scalability

When to choose Luigi:
- Simpler data processing pipelines
- Focus on dependency resolution
- Lightweight orchestration
- Preference for explicit task definitions

```python
# Airflow implementation of an ETL pipeline for analytics data
from airflow import DAG
from airflow.operators.python import PythonOperator
from airflow.providers.postgres.operators.postgres import PostgresOperator
from airflow.providers.amazon.aws.transfers.s3_to_redshift import S3ToRedshiftOperator
from datetime import datetime, timedelta
import pandas as pd
import boto3

default_args = {
    'owner': 'data_team',
    'depends_on_past': False,
    'start_date': datetime(2023, 1, 1),
    'email': ['data_alerts@example.com'],
    'email_on_failure': True,

    'retry_delay': timedelta(minutes=5),
}

dag = DAG(

    catchup=False,
)

def extract_api_data(**context):

    date_str = execution_date.strftime('%Y-%m-%d')
    
    # API call to get data
    # (using fake data for this example)
    data = {
        'user_id': range(100),
        'event': ['view', 'click', 'purchase'] * 33 + ['view'],
        'timestamp': [execution_date - timedelta(minutes=i*30) for i in range(100)]
    }
    df = pd.DataFrame(data)
    
    # Save to CSV
    csv_path = f"/tmp/events_{date_str}.csv"
    df.to_csv(csv_path, index=False)
    
    # Store the path for the next task
    context['ti'].xcom_push(key='events_csv_path', value=csv_path)
    return csv_path

# 2. Transform data
def transform_data(**context):
    ti = context['ti']
    csv_path = ti.xcom_pull(key='events_csv_path')
    
    # Load data
    df = pd.read_csv(csv_path)
    
    # Transform
    df['date'] = pd.to_datetime(df['timestamp']).dt.date
    df['hour'] = pd.to_datetime(df['timestamp']).dt.hour
    
    # Calculate aggregates
    event_counts = df.groupby(['date', 'hour', 'event']).size().reset_index(name='count')
    
    # Save transformed data
    transformed_path = csv_path.replace('.csv', '_transformed.csv')
    event_counts.to_csv(transformed_path, index=False)
    
    # Store path for next task
    context['ti'].xcom_push(key='transformed_csv_path', value=transformed_path)
    return transformed_path

# 3. Upload to S3
def upload_to_s3(**context):
    ti = context['ti']
    execution_date = context['execution_date']
    date_str = execution_date.strftime('%Y-%m-%d')
    
    transformed_csv_path = ti.xcom_pull(key='transformed_csv_path')
    
    # Create S3 client and upload

                            aws_access_key_id='YOUR_KEY',
                            aws_secret_access_key='YOUR_SECRET')
    
    s3_key = f"analytics/events/{date_str}/events_transformed.csv"
    s3_client.upload_file(transformed_csv_path, 'your-bucket-name', s3_key)
    
    # Store S3 path
    context['ti'].xcom_push(key='s3_key', value=s3_key)
    return s3_key

    task_id='extract_api_data',

    provide_context=True,
    dag=dag,

    provide_context=True,
```

### Example 2: Machine Learning Training Pipeline with Luigi

```python
# Luigi implementation of a machine learning pipeline
import luigi
import pandas as pd
import numpy as np
import pickle
import os
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report

# Base task with common parameters
class MLPipelineTask(luigi.Task):
    data_date = luigi.DateParameter()
    
    @property
    def data_path(self):
        return f"ml_pipeline/data/{self.data_date}"
    
    @property
    def model_path(self):
        return f"ml_pipeline/models/{self.data_date}"
    
    def setup_directories(self):
        os.makedirs(self.data_path, exist_ok=True)
        os.makedirs(self.model_path, exist_ok=True)

# Task 1: Generate or download dataset
class PrepareDatasetTask(MLPipelineTask):
    def output(self):
        return luigi.LocalTarget(f"{self.data_path}/raw_data.csv")
    
    def run(self):
        self.setup_directories()
        
        # Generate synthetic dataset for this example
        np.random.seed(42)
        n_samples = 1000
        
        # Features
        X = np.random.randn(n_samples, 5)
        
        # Target (binary classification)
        y = (X[:, 0] + X[:, 1]**2 + np.random.randn(n_samples) * 0.1) > 0
        
        # Create dataframe
        df = pd.DataFrame(X, columns=[f"feature_{i}" for i in range(5)])
        df['target'] = y.astype(int)
        
        # Save dataset
        df.to_csv(self.output().path, index=False)
        print(f"Dataset created with {len(df)} samples")

# Task 2: Split dataset
class SplitDatasetTask(MLPipelineTask):
    test_size = luigi.FloatParameter(default=0.2)
    random_state = luigi.IntParameter(default=42)
    
    def requires(self):
        return PrepareDatasetTask(data_date=self.data_date)
    
    def output(self):
        return {
            'train': luigi.LocalTarget(f"{self.data_path}/train_data.csv"),
            'test': luigi.LocalTarget(f"{self.data_path}/test_data.csv")
        }
    
    def run(self):
        self.setup_directories()
        
        # Load dataset
        df = pd.read_csv(self.input().path)
        
        # Split features and target
        X = df.drop('target', axis=1)
        y = df['target']
        
        # Split into train and test
        X_train, X_test, y_train, y_test = train_test_split(
            X, y, test_size=self.test_size, random_state=self.random_state
        )
        
        # Save splits
        train_df = pd.concat([X_train, y_train], axis=1)
        test_df = pd.concat([X_test, y_test], axis=1)
        
        train_df.to_csv(self.output()['train'].path, index=False)
        test_df.to_csv(self.output()['test'].path, index=False)
        
        print(f"Split dataset into {len(train_df)} training and {len(test_df)} testing samples")

# Task 3: Preprocess data
class PreprocessDataTask(MLPipelineTask):
    def requires(self):
        return SplitDatasetTask(data_date=self.data_date)
    
    def output(self):
        return {
            'train_processed': luigi.LocalTarget(f"{self.data_path}/train_processed.csv"),
            'test_processed': luigi.LocalTarget(f"{self.data_path}/test_processed.csv"),
            'scaler': luigi.LocalTarget(f"{self.model_path}/scaler.pkl")
        }
    
    def run(self):
        self.setup_directories()
        
        # Load datasets
        train_df = pd.read_csv(self.input()['train'].path)
        test_df = pd.read_csv(self.input()['test'].path)
        
        # Split features and target
        X_train = train_df.drop('target', axis=1)
        y_train = train_df['target']
        
        X_test = test_df.drop('target', axis=1)
        y_test = test_df['target']
        
        # Standardize features
        scaler = StandardScaler()
        X_train_scaled = scaler.fit_transform(X_train)
        X_test_scaled = scaler.transform(X_test)
        
        # Save processed data
        train_processed = pd.DataFrame(X_train_scaled, columns=X_train.columns)
        train_processed['target'] = y_train.values
        
        test_processed = pd.DataFrame(X_test_scaled, columns=X_test.columns)
        test_processed['target'] = y_test.values
        
        train_processed.to_csv(self.output()['train_processed'].path, index=False)
        test_processed.to_csv(self.output()['test_processed'].path, index=False)
        
        # Save scaler
        with open(self.output()['scaler'].path, 'wb') as f:
            pickle.dump(scaler, f)
        
        print("Data preprocessing complete")

# Task 4: Train model
class TrainModelTask(MLPipelineTask):
    n_estimators = luigi.IntParameter(default=100)
    
    def requires(self):
        return PreprocessDataTask(data_date=self.data_date)
    
    def output(self):
        return luigi.LocalTarget(f"{self.model_path}/random_forest_model.pkl")
    
    def run(self):
        self.setup_directories()
        
        # Load preprocessed training data
        train_df = pd.read_csv(self.input()['train_processed'].path)
        
        # Split features and target
        X_train = train_df.drop('target', axis=1)
        y_train = train_df['target']
        
        # Train model
        print("Training Random Forest model...")
        model = RandomForestClassifier(
            n_estimators=self.n_estimators,
            random_state=42
        )
        model.fit(X_train, y_train)
        
        # Save model
        with open(self.output().path, 'wb') as f:
            pickle.dump(model, f)
        
        print(f"Model training complete with {self.n_estimators} trees")

# Task 5: Evaluate model
class EvaluateModelTask(MLPipelineTask):
    def requires(self):
        return {
            'model': TrainModelTask(data_date=self.data_date),
            'data': PreprocessDataTask(data_date=self.data_date)
        }
    
    def output(self):
        return luigi.LocalTarget(f"{self.model_path}/evaluation_report.txt")
    
    def run(self):
        self.setup_directories()
        
        # Load model
        with open(self.input()['model'].path, 'rb') as f:
            model = pickle.load(f)
        
        # Load test data
        test_df = pd.read_csv(self.input()['data']['test_processed'].path)
        
        # Split features and target
        X_test = test_df.drop('target', axis=1)
        y_test = test_df['target']
        
        # Make predictions
        y_pred = model.predict(X_test)
        
        # Generate evaluation report
        report = classification_report(y_test, y_pred)
        feature_importances = pd.Series(
            model.feature_importances_,
            index=X_test.columns
        ).sort_values(ascending=False)
        
        # Save report
        with self.output().open('w') as f:
            f.write("MODEL EVALUATION REPORT\n")
            f.write("======================\n\n")
            f.write("Classification Report:\n")
            f.write(report)
            f.write("\n\nFeature Importances:\n")
            for feature, importance in feature_importances.items():
                f.write(f"{feature}: {importance:.4f}\n")
        
        print("Model evaluation complete")

# Main pipeline task
class MLPipeline(luigi.WrapperTask):
    data_date = luigi.DateParameter(default=datetime.now().date())
    
    def requires(self):
        return EvaluateModelTask(data_date=self.data_date)

if __name__ == "__main__":
    luigi.build([MLPipeline()], local_scheduler=True)
```

## Summary and Resources

### Key Takeaways

1. Data pipelines automate data workflows, improving reliability and scalability.
2. Apache Airflow is well-suited for complex, time-scheduled workflows with rich monitoring.
3. Luigi focuses on dependency resolution and is more lightweight for data processing pipelines.
4. Best practices include making pipelines idempotent, atomic, and with proper error handling.
5. Choose the right tool based on your specific needs: complexity, scaling, monitoring, etc.
