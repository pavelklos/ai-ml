## 1. Úvod do transformace dat

Transformace dat je proces převodu dat z jednoho formátu nebo struktury do jiného. V datové vědě se transformace aplikují pro přípravu dat k analýze, vizualizaci nebo modelování. Správná transformace dat může výrazně zlepšit výkon algoritmů strojového učení a zviditelnit vzory v datech.

```python
# Import základních knihoven
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn import preprocessing
from scipy import stats

# Nastavení stylu grafu
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(style="whitegrid")

# Vzorový dataset
data = {
    'age': [25, 30, 35, 40, 45, 50, 55, 60, 65, 70],
    'income': [38000, 45000, 55000, 60000, 75000, 82000, 85000, 90000, 92000, 94000],
    'satisfaction': [3, 3.5, 4, 4.5, 4.2, 4.8, 3.9, 4.1, 4.5, 4.7]
}

# Vytvoření DataFrame
df = pd.DataFrame(data)

# Zobrazení původních dat
print("Původní data:")
print(df.head())
```

## 2. Běžné techniky transformace dat

Existuje mnoho různých technik transformace, každá slouží jinému účelu. Mezi běžné transformace patří:

- **Matematické transformace**: Sčítání, odčítání, násobení, dělení
- **Statistické transformace**: Standardizace, normalizace
- **Funkční transformace**: Logaritmické, odmocninové, exponenciální transformace
- **Konverze typů**: Změna datových typů (např. řetězec na datum)
- **Strukturální transformace**: Změna tvaru, pivotování, tavení dat

```python
# Jednoduché matematické transformace
df['income_thousands'] = df['income'] / 1000
df['age_squared'] = df['age'] ** 2
df['income_age_ratio'] = df['income'] / df['age']

# Příklad konverze typu
df['age_category'] = df['age'].astype(str) + ' let'

print("\nPo základních transformacích:")
print(df.head())
```

## 3. Škálování a normalizace

Škálování a normalizace jsou nezbytné, když vlastnosti mají různé rozsahy. Mezi běžné metody patří:

- **Min-Max škálování**: Škáluje hodnoty mezi 0 a 1
- **Standardizace (Z-skóre)**: Transformuje data tak, aby měla nulový průměr a jednotkový rozptyl
- **Robustní škálování**: Používá statistiky, které jsou robustní vůči odlehlým hodnotám (medián a kvartily)
- **Normalizace**: Škáluje vzorky tak, aby měly jednotkovou normu

```python
# Min-Max škálování
min_max_scaler = preprocessing.MinMaxScaler()
df['income_minmax'] = min_max_scaler.fit_transform(df[['income']])

# Standardizace (Z-skóre normalizace)
df['income_zscore'] = stats.zscore(df['income'])

# Robustní škálování
robust_scaler = preprocessing.RobustScaler()
df['income_robust'] = robust_scaler.fit_transform(df[['income']])

# Normalizace dat (L2 norma)
df['income_normalized'] = preprocessing.normalize(df[['income']], norm='l2')[0]

print("\nPo škálovacích transformacích:")
print(df[['income', 'income_minmax', 'income_zscore', 'income_robust', 'income_normalized']].head())

# Vizualizace efektu různých metod škálování
plt.figure(figsize=(12, 6))
plt.subplot(1, 4, 1)
plt.title('Původní')
sns.histplot(df['income'], kde=True)

plt.subplot(1, 4, 2)
plt.title('Min-Max škálování')
sns.histplot(df['income_minmax'], kde=True)

plt.subplot(1, 4, 3)
plt.title('Z-skóre')
sns.histplot(df['income_zscore'], kde=True)

plt.subplot(1, 4, 4)
plt.title('Robustní škálování')
sns.histplot(df['income_robust'], kde=True)

plt.tight_layout()
plt.show()
```

## 4. Logaritmické a mocninné transformace

Logaritmické a mocninné transformace jsou užitečné pro zpracování zešikmených dat a pro linearizaci vztahů.

```python
# Generování zešikmených dat pro demonstraci
skewed_data = np.random.exponential(scale=2.0, size=1000)
df_skewed = pd.DataFrame({'original': skewed_data})

# Logaritmická transformace
df_skewed['log'] = np.log1p(df_skewed['original'])  # log1p je log(1+x) pro zvládnutí nul

# Odmocninová transformace
df_skewed['sqrt'] = np.sqrt(df_skewed['original'])

# Box-Cox transformace
df_skewed['boxcox'], _ = stats.boxcox(df_skewed['original'] + 1)  # Přidání 1 pro zvládnutí nul

# Yeo-Johnson transformace (funguje i se zápornými hodnotami)
df_skewed['yeojohnson'], _ = stats.yeojohnson(df_skewed['original'])

# Vizualizace transformací
fig, axs = plt.subplots(2, 3, figsize=(15, 8))
sns.histplot(df_skewed['original'], kde=True, ax=axs[0, 0])
axs[0, 0].set_title('Původní (zešikmená) data')

sns.histplot(df_skewed['log'], kde=True, ax=axs[0, 1])
axs[0, 1].set_title('Logaritmická transformace')

sns.histplot(df_skewed['sqrt'], kde=True, ax=axs[0, 2])
axs[0, 2].set_title('Odmocninová transformace')

sns.histplot(df_skewed['boxcox'], kde=True, ax=axs[1, 0])
axs[1, 0].set_title('Box-Cox transformace')

sns.histplot(df_skewed['yeojohnson'], kde=True, ax=axs[1, 1])
axs[1, 1].set_title('Yeo-Johnson transformace')

axs[1, 2].axis('off')  # Prázdný subplot
plt.tight_layout()
plt.show()

print("\nHodnoty šikmosti po transformacích:")
print(f"Původní: {stats.skew(df_skewed['original']):.4f}")
print(f"Logaritmická: {stats.skew(df_skewed['log']):.4f}")
print(f"Odmocninová: {stats.skew(df_skewed['sqrt']):.4f}")
print(f"Box-Cox: {stats.skew(df_skewed['boxcox']):.4f}")
print(f"Yeo-Johnson: {stats.skew(df_skewed['yeojohnson']):.4f}")
```

## 5. Binování a diskretizace

Binování (nebo diskretizace) převádí spojité proměnné na kategorické rozdělením rozsahu do intervalů.

```python
# Vytvoření vzorových dat
np.random.seed(42)
ages = np.random.normal(40, 10, 100).astype(int)
df_ages = pd.DataFrame({'age': ages})

# Binování se stejnou šířkou (4 biny)
df_ages['age_bins_equal_width'] = pd.cut(df_ages['age'], bins=4)

# Binování se stejnou četností (kvartily)
df_ages['age_bins_equal_freq'] = pd.qcut(df_ages['age'], q=4)

# Vlastní binování
custom_bins = [0, 30, 40, 50, 100]
bin_labels = ['Mladý', 'Dospělý', 'Střední věk', 'Senior']
df_ages['age_category'] = pd.cut(df_ages['age'], bins=custom_bins, labels=bin_labels)

print("\nVýsledky binování:")
print(df_ages.head(10))

# Vizualizace distribuce po binování
plt.figure(figsize=(12, 6))

plt.subplot(1, 3, 1)
sns.countplot(y='age_bins_equal_width', data=df_ages)
plt.title('Binování se stejnou šířkou')

plt.subplot(1, 3, 2)
sns.countplot(y='age_bins_equal_freq', data=df_ages)
plt.title('Binování se stejnou četností')

plt.subplot(1, 3, 3)
sns.countplot(y='age_category', data=df_ages)
plt.title('Vlastní binování')

plt.tight_layout()
plt.show()
```

## 6. Vytváření nových vlastností

Feature engineering často zahrnuje vytváření nových vlastností z existujících, aby lépe zachytily vztahy v datech.

```python
# Načtení realističtějšího datasetu
from sklearn.datasets import fetch_california_housing
housing = fetch_california_housing()
df_housing = pd.DataFrame(housing.data, columns=housing.feature_names)
df_housing['target'] = housing.target

print("\nDataset California Housing:")
print(df_housing.head())

# Vytváření nových vlastností pomocí matematických operací
df_housing['BEDROOM_RATIO'] = df_housing['AveBedrms'] / df_housing['AveRooms']
df_housing['ROOMS_PER_HOUSEHOLD'] = df_housing['AveRooms'] / df_housing['HouseHold']
df_housing['POPULATION_PER_HOUSEHOLD'] = df_housing['Population'] / df_housing['HouseHold']

# Vytváření interakčních vlastností
df_housing['INCOME_PER_ROOM'] = df_housing['MedInc'] / df_housing['AveRooms']

# Vytváření polynomiálních vlastností
df_housing['MEDINC_SQUARED'] = df_housing['MedInc'] ** 2
df_housing['MEDINC_CUBED'] = df_housing['MedInc'] ** 3

print("\nPo vytvoření nových vlastností:")
print(df_housing.head())

# Vizualizace vztahu mezi původními a odvozenými vlastnostmi
plt.figure(figsize=(14, 5))

plt.subplot(1, 3, 1)
plt.scatter(df_housing['MedInc'], df_housing['target'], alpha=0.5)
plt.title('MedInc vs. Target')
plt.xlabel('MedInc')
plt.ylabel('Target')

plt.subplot(1, 3, 2)
plt.scatter(df_housing['INCOME_PER_ROOM'], df_housing['target'], alpha=0.5)
plt.title('Příjem na pokoj vs. Target')
plt.xlabel('Příjem na pokoj')
plt.ylabel('Target')

plt.subplot(1, 3, 3)
plt.scatter(df_housing['POPULATION_PER_HOUSEHOLD'], df_housing['target'], alpha=0.5)
plt.title('Populace na domácnost vs. Target')
plt.xlabel('Populace na domácnost')
plt.ylabel('Target')

plt.tight_layout()
plt.show()
```

## 7. Kódování kategorických proměnných

Kategorické proměnné je třeba zakódovat do numerické podoby, než mohou být použity v mnoha algoritmech strojového učení.

```python
# Vytvoření vzorového datasetu s kategorickými proměnnými
data = {
    'color': ['red', 'blue', 'green', 'red', 'green', 'blue', 'red', 'green'],
    'size': ['small', 'medium', 'large', 'medium', 'small', 'large', 'large', 'small'],
    'material': ['wood', 'metal', 'plastic', 'wood', 'metal', 'plastic', 'metal', 'wood'],
    'price': [10.5, 15.3, 20.0, 11.2, 14.7, 19.9, 12.5, 9.8]
}

df_cat = pd.DataFrame(data)
print("\nKategorická data:")
print(df_cat.head())

# One-hot kódování
df_onehot = pd.get_dummies(df_cat, columns=['color', 'size', 'material'], drop_first=False)
print("\nPo one-hot kódování:")
print(df_onehot.head())

# Label kódování
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df_label = df_cat.copy()
for col in ['color', 'size', 'material']:
    df_label[col + '_encoded'] = le.fit_transform(df_cat[col])
print("\nPo label kódování:")
print(df_label.head())

# Target kódování (mean encoding)
for col in ['color', 'size', 'material']:
    means = df_cat.groupby(col)['price'].mean()
    df_cat[col + '_mean_encoded'] = df_cat[col].map(means)
print("\nPo target kódování:")
print(df_cat.head())
```

## 8. Transformace datumů a časů

Práce s daty o datumech a časech často vyžaduje extrakci komponent nebo vytvoření vlastností založených na čase.

```python
# Vytvoření vzorového časového datasetu
dates = pd.date_range(start='2021-01-01', end='2022-12-31', freq='D')
np.random.seed(42)
values = np.random.normal(loc=0, scale=1, size=len(dates))
values = np.cumsum(values)  # Vytvoření náhodné procházky

df_time = pd.DataFrame({'date': dates, 'value': values})
print("\nData časových řad:")
print(df_time.head())

# Extrakce komponent datumu
df_time['year'] = df_time['date'].dt.year
df_time['month'] = df_time['date'].dt.month
df_time['day'] = df_time['date'].dt.day
df_time['dayofweek'] = df_time['date'].dt.dayofweek
df_time['quarter'] = df_time['date'].dt.quarter
df_time['dayofyear'] = df_time['date'].dt.dayofyear
df_time['is_weekend'] = df_time['dayofweek'].isin([5, 6]).astype(int)
df_time['is_month_end'] = df_time['date'].dt.is_month_end.astype(int)

# Vytvoření cyklických vlastností pro měsíc a den v týdnu
df_time['month_sin'] = np.sin(2 * np.pi * df_time['month'] / 12)
df_time['month_cos'] = np.cos(2 * np.pi * df_time['month'] / 12)
df_time['dayofweek_sin'] = np.sin(2 * np.pi * df_time['dayofweek'] / 7)
df_time['dayofweek_cos'] = np.cos(2 * np.pi * df_time['dayofweek'] / 7)

print("\nPo transformaci datumů:")
print(df_time.head())

# Vizualizace dat časových řad s různými komponentami data
plt.figure(figsize=(15, 10))

plt.subplot(2, 2, 1)
sns.lineplot(x='date', y='value', data=df_time)
plt.title('Původní časová řada')

plt.subplot(2, 2, 2)
sns.boxplot(x='month', y='value', data=df_time)
plt.title('Distribuce hodnot podle měsíce')

plt.subplot(2, 2, 3)
sns.boxplot(x='dayofweek', y='value', data=df_time)
plt.title('Distribuce hodnot podle dne v týdnu')
plt.xlabel('Den v týdnu (0=Pondělí, 6=Neděle)')

plt.subplot(2, 2, 4)
sns.scatterplot(x='month_sin', y='month_cos', hue='month', data=df_time, palette='viridis')
plt.title('Cyklické kódování měsíce')
plt.xlabel('sin(měsíc)')
plt.ylabel('cos(měsíc)')

plt.tight_layout()
plt.show()
```

## 9. Transformace textových dat

Textová data vyžadují speciální metody předzpracování, než mohou být použita v modelech strojového učení.

```python
# Vytvoření jednoduchého datasetu s textem
texts = [
    "Python je skvělý programovací jazyk",
    "Datová věda je s Pythonem zábavná",
    "Algoritmy strojového učení vyžadují kvalitní data",
    "Zpracování textu je důležitý krok v NLP",
    "Python má mnoho knihoven pro datovou analýzu"
]
df_text = pd.DataFrame({'text': texts})
print("\nTextová data:")
print(df_text)

# Základní textové transformace
df_text['text_lower'] = df_text['text'].str.lower()
df_text['text_count'] = df_text['text'].str.len()
df_text['word_count'] = df_text['text'].str.split().str.len()
df_text['contains_python'] = df_text['text'].str.contains('Python', case=True).astype(int)

# Tokenizace
df_text['tokens'] = df_text['text_lower'].str.split()

# Odstranění stop slov
import nltk
from nltk.corpus import stopwords
try:
    nltk.data.find('corpora/stopwords')
except LookupError:
    nltk.download('stopwords')
stop_words = set(stopwords.words('english'))  # Pro češtinu by bylo 'czech', ale je třeba nejprve stáhnout česká stop slova

df_text['tokens_no_stopwords'] = df_text['tokens'].apply(
    lambda x: [word for word in x if word not in stop_words]
)

print("\nPo textových transformacích:")
print(df_text[['text', 'text_count', 'word_count', 'contains_python']])
print("\nTokeny bez stop slov:")
for i, tokens in enumerate(df_text['tokens_no_stopwords']):
    print(f"{i+1}: {tokens}")

# Reprezentace Bag of Words
from sklearn.feature_extraction.text import CountVectorizer
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(df_text['text_lower'])
bow_df = pd.DataFrame(X.toarray(), columns=vectorizer.get_feature_names_out())
print("\nReprezentace Bag of Words:")
print(bow_df)

# TF-IDF transformace
from sklearn.feature_extraction.text import TfidfVectorizer
tfidf = TfidfVectorizer()
X_tfidf = tfidf.fit_transform(df_text['text_lower'])
tfidf_df = pd.DataFrame(X_tfidf.toarray(), columns=tfidf.get_feature_names_out())
print("\nTF-IDF reprezentace:")
print(tfidf_df)
```

## 10. Shrnutí

Transformace dat je klíčovým krokem v procesu datové vědy, který zajišťuje, že vaše data jsou v optimálním formátu pro analýzu nebo modelování. Klíčové poznatky:

1. **Škálování a normalizace**: Nezbytné pro vlastnosti s různými rozsahy, pomáhají algoritmům, které jsou citlivé na měřítko vlastností.

2. **Logaritmické a mocninné transformace**: Obzvláště užitečné pro zešikmená data, činí distribuce symetričtějšími a vztahy lineárnějšími.

3. **Binování a diskretizace**: Pomáhají při převodu spojitých proměnných na kategorické, což může odhalit nelineární vztahy.

4. **Feature Engineering**: Vytváření nových smysluplných vlastností může výrazně zlepšit výkon modelu zachycením doménových znalostí.

5. **Kódování kategorických proměnných**: Existují různé metody pro převod kategorických proměnných na numerickou reprezentaci.

6. **Transformace datumů a časů**: Vlastnosti založené na čase mohou zachytit časové vzory a sezónnost v datech.

7. **Transformace textu**: Od základního čištění po složité vektorizace, textová data vyžadují speciální zpracování.

Jednoduché transformace dat často významně ovlivňují kvalitu analýzy a mohou dramaticky zlepšit přesnost modelů strojového učení. Aplikací vhodných transformací můžete odhalit skryté vzory, opravit zešikmené distribuce, standardizovat měřítka a připravit data pro širokou škálu analytických technik.

Při aplikaci transformací nezapomeňte:
- Zvážit požadavky vaší analytické metody nebo algoritmu
- Myslet na dopad na interpretovatelnost
- Aplikovat transformace konzistentně na trénovací a testovací data
- Dokumentovat váš transformační proces pro reprodukovatelnost

S těmito postupy se transformace dat stává mocným nástrojem ve vašem arzenálu datové vědy.
