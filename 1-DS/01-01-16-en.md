## 1. Probability Fundamentals

Probability is the branch of mathematics that deals with measuring the likelihood of events occurring. In data science, probability provides the theoretical foundation for statistical inference, machine learning algorithms, and data-driven decision making.

```python
# Import essential libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
import random

# Set random seed for reproducibility
np.random.seed(42)
random.seed(42)

# Simple probability example: coin flipping
n_flips = 1000
# Simulate 1000 fair coin flips (0=tails, 1=heads)
coin_flips = np.random.binomial(1, 0.5, n_flips)

# Calculate the experimental probability
heads_probability = np.mean(coin_flips)

print(f"Number of flips: {n_flips}")
print(f"Number of heads: {sum(coin_flips)}")
print(f"Experimental probability of heads: {heads_probability:.4f}")
print(f"Theoretical probability of heads: 0.5000")

# Visualize the convergence to the theoretical probability
plt.figure(figsize=(10, 6))
cumulative_heads = np.cumsum(coin_flips)
cumulative_probability = [sum(coin_flips[:i+1])/(i+1) for i in range(n_flips)]

plt.plot(range(1, n_flips+1), cumulative_probability)
plt.axhline(y=0.5, color='r', linestyle='--', label='Theoretical probability')
plt.xlabel('Number of flips')
plt.ylabel('Probability of heads')
plt.title('Convergence to the Theoretical Probability')
plt.legend()
plt.grid(True)
plt.show()
```

## 2. Random Variables and Distributions

A random variable is a variable whose value depends on the outcome of a random event. Random variables can be discrete (taking specific values) or continuous (taking any value within a range).

```python
# Creating and visualizing discrete and continuous random variables

# Discrete random variable: rolling a fair six-sided die 1000 times
dice_rolls = np.random.randint(1, 7, size=1000)

# Continuous random variable: drawing from normal distribution
normal_samples = np.random.normal(loc=0, scale=1, size=1000)

# Visualize the distributions
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))

# Discrete distribution
sns.histplot(dice_rolls, bins=np.arange(0.5, 7.5, 1), ax=ax1, discrete=True)
ax1.set_title('Discrete Random Variable: Die Rolls')
ax1.set_xlabel('Outcome')
ax1.set_ylabel('Frequency')
ax1.set_xticks(range(1, 7))

# Continuous distribution
sns.histplot(normal_samples, kde=True, ax=ax2)
ax2.set_title('Continuous Random Variable: Normal Distribution')
ax2.set_xlabel('Value')
ax2.set_ylabel('Frequency')

plt.tight_layout()
plt.show()

# Creating a probability distribution from discrete data
dice_counts = pd.Series(dice_rolls).value_counts().sort_index()
dice_probabilities = dice_counts / len(dice_rolls)

print("\nEmpirical probability distribution of die rolls:")
print(dice_probabilities)
```

Data science frequently uses several probability distributions to model various phenomena:

## 4. Probability Mass and Density Functions

Probability Mass Functions (PMFs) describe the probability of each possible value for discrete random variables, while Probability Density Functions (PDFs) serve the same purpose for continuous random variables.

```python
# Demonstrating PMF and PDF
# PMF example: Rolling two dice and summing the results
def roll_two_dice_pmf():
    # All possible combinations of two dice
    outcomes = [(i, j) for i in range(1, 7) for j in range(1, 7)]
    
    # Calculate the sum for each outcome
    sums = [sum(outcome) for outcome in outcomes]
    
    # Count occurrences of each sum
    unique_sums = sorted(set(sums))
    counts = [sums.count(s) for s in unique_sums]
    
    # Calculate probabilities
    probabilities = [count / len(sums) for count in counts]
    
    return unique_sums, probabilities

sums, probabilities = roll_two_dice_pmf()
print("\nPMF for sum of two dice:")
for s, p in zip(sums, probabilities):
    print(f"P(Sum = {s}) = {p:.4f}")

# Visualize the PMF
plt.figure(figsize=(10, 6))
plt.bar(sums, probabilities)
plt.title('PMF for Sum of Two Dice')
plt.xlabel('Sum')
plt.ylabel('Probability')
plt.xticks(sums)
plt.grid(True, alpha=0.3)
plt.show()

# PDF example: Standard normal distribution
x = np.linspace(-4, 4, 1000)
pdf_values = stats.norm.pdf(x)

plt.figure(figsize=(10, 6))
plt.plot(x, pdf_values)
plt.title('PDF of Standard Normal Distribution')
plt.xlabel('x')
plt.ylabel('Density')
plt.grid(True, alpha=0.3)
plt.fill_between(x, pdf_values, where=(x >= -1) & (x <= 1), alpha=0.2, color='red')
plt.text(0, 0.05, f"P(-1 ≤ X ≤ 1) = {stats.norm.cdf(1) - stats.norm.cdf(-1):.4f}")
plt.show()
```

## 5. Expected Value and Variance

The expected value is the long-run average of a random variable, while variance measures the spread or dispersion of the values around the expected value.

```python
# Calculating expected value and variance

# For a discrete random variable: weighted sum of values
# Example: Fair six-sided die
die_values = [1, 2, 3, 4, 5, 6]
die_probs = [1/6] * 6

# Expected value calculation
exp_value = sum(x * p for x, p in zip(die_values, die_probs))

# Variance calculation 
variance = sum(p * (x - exp_value)**2 for x, p in zip(die_values, die_probs))

print(f"\nExpected value of a fair die: {exp_value}")
print(f"Variance of a fair die: {variance}")
print(f"Standard deviation of a fair die: {np.sqrt(variance)}")

# Simulate many die rolls and compare with theoretical values
n_simulations = 10000
die_rolls = np.random.choice(die_values, size=n_simulations, p=die_probs)

print("\nSimulation results:")
print(f"Sample mean: {np.mean(die_rolls):.4f} (Theoretical: {exp_value})")
print(f"Sample variance: {np.var(die_rolls):.4f} (Theoretical: {variance})")
print(f"Sample std dev: {np.std(die_rolls):.4f} (Theoretical: {np.sqrt(variance):.4f})")

# Visualize the convergence of sample mean to expected value
plt.figure(figsize=(10, 6))
sample_sizes = np.logspace(1, 4, 100, dtype=int)
sample_means = [np.mean(die_rolls[:size]) for size in sample_sizes]
plt.semilogx(sample_sizes, sample_means, 'b-', label='Sample Mean')
plt.axhline(y=exp_value, color='r', linestyle='--', label='Expected Value')
plt.xlabel('Sample Size (log scale)')
plt.ylabel('Mean')
plt.title('Convergence of Sample Mean to Expected Value')
plt.grid(True)
plt.legend()
plt.show()
```

## 6. Joint, Marginal, and Conditional Probabilities

These concepts relate to the probabilities of multiple events and how they interact.

```python
# Creating a joint probability distribution 
# Example: Survey of 1000 people by gender and educational level

# Create a contingency table
education_levels = ['High School', 'Bachelor', 'Master', 'PhD']
genders = ['Male', 'Female']

# Simulate survey data
np.random.seed(42)
n_people = 1000
genders_sampled = np.random.choice(genders, n_people, p=[0.48, 0.52])
education_probs = {
    'Male': [0.45, 0.35, 0.15, 0.05],
    'Female': [0.40, 0.38, 0.17, 0.05]
}

education_sampled = []
for gender in genders_sampled:
    education_sampled.append(np.random.choice(education_levels, p=education_probs[gender]))

# Create a DataFrame from the sampled data
survey_data = pd.DataFrame({
    'Gender': genders_sampled,
    'Education': education_sampled
})

# Create the contingency table
contingency_table = pd.crosstab(survey_data['Gender'], survey_data['Education'])
print("\nContingency Table (Counts):")
print(contingency_table)

# Convert to joint probability distribution
joint_prob = contingency_table / n_people
print("\nJoint Probability Distribution:")
print(joint_prob)

# Marginal probabilities
gender_marginal = joint_prob.sum(axis=1)
education_marginal = joint_prob.sum(axis=0)

print("\nMarginal Probabilities for Gender:")
print(gender_marginal)

print("\nMarginal Probabilities for Education:")
print(education_marginal)

# Conditional probabilities: P(Education | Gender)
conditional_prob = joint_prob.div(gender_marginal, axis=0)
print("\nConditional Probability P(Education | Gender):")
print(conditional_prob)

# Visualize the joint distribution
plt.figure(figsize=(12, 6))
sns.heatmap(joint_prob, annot=True, fmt='.3f', cmap='Blues')
plt.title('Joint Probability Distribution')
plt.tight_layout()
plt.show()

# Check for independence: P(A and B) = P(A) * P(B) for all A, B
independence_check = pd.DataFrame(index=genders, columns=education_levels)
for gender in genders:
    for edu in education_levels:
        # Calculate P(A) * P(B)
        expected = gender_marginal[gender] * education_marginal[edu]
        # Compare with actual P(A and B)
        actual = joint_prob.loc[gender, edu]
        independence_check.loc[gender, edu] = actual - expected

print("\nDifference between actual joint probability and product of marginals:")
print(independence_check)
print("\nIf these values are close to zero, the variables are independent.")
```

## 7. Bayes' Theorem and Applications

Bayes' theorem provides a way to update probabilities based on new evidence, making it essential for many data science applications.

```python
# Demonstrating Bayes' Theorem
# Example: Medical testing scenario

# Prior probabilities
p_disease = 0.01  # 1% of population has the disease
p_no_disease = 1 - p_disease  # 99% do not have the disease

# Conditional probabilities (test accuracy)
p_positive_given_disease = 0.95  # Sensitivity: 95% of sick people test positive
p_negative_given_no_disease = 0.90  # Specificity: 90% of healthy people test negative
p_positive_given_no_disease = 1 - p_negative_given_no_disease  # 10% false positive

# Calculate P(disease | positive test) using Bayes' theorem
# P(A|B) = P(B|A) * P(A) / P(B)
# P(disease|positive) = P(positive|disease) * P(disease) / P(positive)

# Calculate P(positive) using the law of total probability
p_positive = p_positive_given_disease * p_disease + p_positive_given_no_disease * p_no_disease

# Apply Bayes' theorem
p_disease_given_positive = (p_positive_given_disease * p_disease) / p_positive

print("\nBayes' Theorem Example: Medical Testing")
print(f"Prior probability of disease: {p_disease:.4f}")
print(f"Probability of positive test given disease (sensitivity): {p_positive_given_disease:.4f}")
print(f"Probability of negative test given no disease (specificity): {p_negative_given_no_disease:.4f}")
print(f"Probability of a positive test: {p_positive:.4f}")
print(f"Posterior probability of disease given positive test: {p_disease_given_positive:.4f}")
print(f"Despite the high test accuracy, only {p_disease_given_positive*100:.1f}% of positive tests indicate disease!")

# Visualize how the posterior probability changes with different priors
prior_values = np.linspace(0.001, 0.1, 100)  # Prior probabilities from 0.1% to 10%
posterior_values = []

for prior in prior_values:
    p_positive = p_positive_given_disease * prior + p_positive_given_no_disease * (1 - prior)
    posterior = (p_positive_given_disease * prior) / p_positive
    posterior_values.append(posterior)

plt.figure(figsize=(10, 6))
plt.plot(prior_values, posterior_values)
plt.xlabel('Prior Probability of Disease P(Disease)')
plt.ylabel('Posterior Probability P(Disease|Positive)')
plt.title('Effect of Prior Probability on Posterior Probability')
plt.grid(True)
plt.tight_layout()
plt.show()
```

## 8. Simulation and Random Sampling

Simulation is a powerful technique for studying probability problems, especially when analytical solutions are complex or impossible.

```python
# Demonstrating simulation techniques for probability problems
# Example 1: Monte Carlo method to estimate π

def monte_carlo_pi(n_samples):
    # Generate random points in a square from (0,0) to (1,1)
    points = np.random.uniform(0, 1, size=(n_samples, 2))
    
    # Calculate distance from origin
    distances = np.sqrt(points[:, 0]**2 + points[:, 1]**2)
    
    # Count points inside the unit quarter-circle
    inside_circle = np.sum(distances <= 1)
    
    # The ratio of points inside the circle to total points approximates π/4
    pi_estimate = 4 * inside_circle / n_samples
    
    return pi_estimate, points, distances <= 1

# Run the simulation
n_samples = 10000
pi_estimate, points, inside = monte_carlo_pi(n_samples)

# Visualize the simulation
plt.figure(figsize=(10, 10))
plt.scatter(points[inside, 0], points[inside, 1], color='blue', s=1, alpha=0.5)
plt.scatter(points[~inside, 0], points[~inside, 1], color='red', s=1, alpha=0.5)
plt.title(f'Monte Carlo Estimation of π ≈ {pi_estimate:.6f} (Actual: {np.pi:.6f})')
plt.xlabel('x')
plt.ylabel('y')
plt.axis('equal')
plt.grid(True)
plt.show()

# Example 2: Bootstrap sampling for estimating the confidence interval of the mean

# Generate a population with a known distribution
population = np.random.gamma(shape=2, scale=2, size=1000)
true_mean = np.mean(population)

# Take a sample from the population
np.random.seed(42)
sample_size = 50
sample = np.random.choice(population, size=sample_size, replace=False)
sample_mean = np.mean(sample)

# Bootstrap to estimate the confidence interval for the mean
n_bootstraps = 10000
bootstrap_means = []

for _ in range(n_bootstraps):
    # Sample with replacement from the original sample
    bootstrap_sample = np.random.choice(sample, size=sample_size, replace=True)
    bootstrap_means.append(np.mean(bootstrap_sample))

# Calculate 95% confidence interval
confidence_interval = np.percentile(bootstrap_means, [2.5, 97.5])

# Visualize the bootstrap distribution
plt.figure(figsize=(10, 6))
sns.histplot(bootstrap_means, kde=True)
plt.axvline(x=sample_mean, color='red', linestyle='--', label='Sample Mean')
plt.axvline(x=confidence_interval[0], color='green', linestyle='--', label='2.5th Percentile')
plt.axvline(x=confidence_interval[1], color='green', linestyle='--', label='97.5th Percentile')
plt.axvline(x=true_mean, color='black', label='True Population Mean')
plt.title('Bootstrap Distribution of Sample Mean')
plt.xlabel('Mean')
plt.ylabel('Frequency')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

print("\nBootstrap Results:")
print(f"True population mean: {true_mean:.4f}")
print(f"Sample mean: {sample_mean:.4f}")
print(f"95% Confidence interval: [{confidence_interval[0]:.4f}, {confidence_interval[1]:.4f}]")
```

## 9. Summary

Understanding probability concepts is fundamental to data science:

1. **Probability Fundamentals** provide the mathematical framework for quantifying uncertainty, which is essential in data analysis and machine learning.

2. **Random Variables** and their distributions help model real-world phenomena and make predictions based on data.

3. **Common Probability Distributions** such as normal, binomial, and Poisson have specific applications in modeling different types of data.

4. **Probability Mass and Density Functions** describe the likelihood of different outcomes for discrete and continuous random variables.

5. **Expected Value and Variance** help summarize distributions and understand the central tendency and spread of data.

6. **Joint, Marginal, and Conditional Probabilities** provide tools for analyzing relationships between multiple variables.

7. **Bayes' Theorem** offers a powerful method for updating probabilities based on new evidence, forming the basis for many machine learning algorithms.

8. **Simulation techniques** like Monte Carlo methods and bootstrap sampling allow us to solve complex probability problems and quantify uncertainty in our estimates.

Probability theory underpins many data science methods, including:
- Statistical inference and hypothesis testing
- Machine learning algorithms (especially Bayesian methods)
- Uncertainty quantification
- Risk assessment
- A/B testing and experimental design

By mastering these concepts, data scientists can better interpret data, build more accurate models, and make more informed decisions in the face of uncertainty.
