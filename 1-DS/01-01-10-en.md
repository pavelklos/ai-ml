## 1. Introduction to Data Aggregation and Grouping

Data aggregation and grouping are fundamental techniques in data analysis that involve categorizing data into groups and computing summary statistics for each group. These operations allow you to extract meaningful patterns and insights from your data by examining how different segments behave.

```python
# Import necessary libraries
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Set aesthetic parameters for better visualizations
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Create a sample dataset
data = {
    'Category': ['A', 'B', 'A', 'B', 'A', 'C', 'C', 'B', 'C', 'A'],
    'Region': ['East', 'West', 'West', 'East', 'East', 'West', 'East', 'West', 'East', 'West'],
    'Sales': [100, 200, 150, 250, 120, 180, 220, 190, 130, 110],
    'Quantity': [10, 15, 12, 18, 8, 16, 20, 14, 11, 9],
    'Date': pd.date_range(start='1/1/2023', periods=10)
}

# Create DataFrame
df = pd.DataFrame(data)
print("Sample DataFrame:")
print(df)
```

Aggregation and grouping operations follow a "split-apply-combine" methodology:
1. **Split**: Data is divided into groups based on one or more variables
2. **Apply**: A function (like sum, mean, count) is applied to each group separately
3. **Combine**: The results are combined into a new data structure

## 2. Basic GroupBy Operations

The `.groupby()` method in pandas is the foundation for data aggregation. It splits the data based on specified columns and prepares it for further operations.

```python
# Group data by Category
grouped = df.groupby('Category')

# Apply aggregation - compute the mean of each numeric column by category
category_means = grouped.mean()
print("\nMean values grouped by Category:")
print(category_means)

# Count the number of items in each group
group_counts = grouped.size()
print("\nCount of items in each Category:")
print(group_counts)

# Basic statistics for each group
category_summary = grouped.describe()
print("\nSummary statistics by Category:")
print(category_summary)

# Accessing a specific group
group_A = grouped.get_group('A')
print("\nData for Category A:")
print(group_A)

# Iterating through groups
print("\nIterating through each Category group:")
for name, group in grouped:
    print(f"\nCategory: {name}")
    print(f"Group size: {len(group)}")
    print(group)
```

## 3. Aggregate Functions

Aggregate functions summarize data within each group. You can use built-in functions like `sum()`, `mean()`, or `count()`, or define your own custom aggregation functions.

```python
# Built-in aggregate functions
print("\nSum of values by Category:")
print(grouped.sum())

print("\nMinimum values by Category:")
print(grouped.min())

print("\nMaximum values by Category:")
print(grouped.max())

# Apply multiple aggregation functions at once using the agg() method
agg_funcs = grouped.agg(['min', 'max', 'mean', 'count'])
print("\nMultiple aggregation functions at once:")
print(agg_funcs)

# Apply different functions to different columns
custom_agg = grouped.agg({
    'Sales': ['sum', 'mean', 'max'],
    'Quantity': ['min', 'mean', 'max']
})
print("\nDifferent aggregations for different columns:")
print(custom_agg)

# Define a custom aggregation function
def sales_per_item(x):
    return x['Sales'].sum() / x['Quantity'].sum()

print("\nCustom aggregation function (Sales per Item):")
print(grouped.apply(sales_per_item))
```

## 4. Multiple Aggregations

You can perform multiple aggregation operations simultaneously, creating rich summary views of your data.

```python
# Using agg() with multiple functions
print("\nMultiple aggregations with agg():")
agg_results = df.groupby('Category').agg({
    'Sales': ['sum', 'mean', 'median', 'std'],
    'Quantity': ['sum', 'mean', 'median', 'max']
})
print(agg_results)

# Using named aggregations (pandas 0.25+)
print("\nNamed aggregations:")
named_agg = df.groupby('Region').agg(
    total_sales=('Sales', 'sum'),
    avg_sales=('Sales', 'mean'),
    total_qty=('Quantity', 'sum'),
    max_qty=('Quantity', 'max')
)
print(named_agg)

# Custom aggregation functions with lambda
print("\nCustom aggregations with lambda functions:")
custom_agg = df.groupby('Category').agg({
    'Sales': ['sum', 'mean', lambda x: x.max() - x.min()],
    'Quantity': ['sum', lambda x: x.mean() / x.std() if x.std() > 0 else 0]
})
# Rename the lambda function columns
custom_agg.columns = ['Sales_Sum', 'Sales_Mean', 'Sales_Range', 'Quantity_Sum', 'Quantity_Coef_Var']
print(custom_agg)
```

## 5. Grouping by Multiple Columns

You can group data by multiple columns to create more specific aggregations. This allows for hierarchical analysis of your data.

```python
# Group by multiple columns
multi_group = df.groupby(['Category', 'Region'])

# Compute mean for each combination
print("\nMean values grouped by Category and Region:")
print(multi_group.mean())

# Count observations in each group
print("\nCount by Category and Region:")
print(multi_group.size().reset_index(name='Count'))

# Apply aggregation functions
print("\nSum of Sales by Category and Region:")
print(multi_group['Sales'].sum())

# Unstack the results to get a pivot-like format
sales_by_cat_region = multi_group['Sales'].sum().unstack()
print("\nSales by Category and Region (unstacked):")
print(sales_by_cat_region)

# Visualize the results
plt.figure(figsize=(10, 6))
sales_by_cat_region.plot(kind='bar')
plt.title('Total Sales by Category and Region')
plt.xlabel('Category')
plt.ylabel('Sales')
plt.tight_layout()
plt.show()
```

## 6. Hierarchical Indexing with GroupBy

When grouping by multiple columns, pandas creates a hierarchical (MultiIndex) structure that allows for more complex analysis.

```python
# Create a hierarchical index through groupby
hierarchical_index = df.groupby(['Category', 'Region']).mean()
print("\nHierarchical index from groupby:")
print(hierarchical_index)

# Access data at different levels of hierarchy
print("\nData for Category 'A':")
print(hierarchical_index.loc['A'])

# Access specific combinations
print("\nData for Category 'A', Region 'East':")
print(hierarchical_index.loc[('A', 'East')])

# Unstacking to convert hierarchical index to columns
print("\nUnstacking the first level:")
print(hierarchical_index.unstack(level=0))

print("\nUnstacking the second level:")
print(hierarchical_index.unstack(level=1))

# Unstacking all levels to get a regular DataFrame
print("\nUnstacking all levels:")
print(hierarchical_index.unstack())

# Resetting the index
print("\nResetting the hierarchical index:")
print(hierarchical_index.reset_index())
```

## 7. Pivot Tables and Cross-Tabulations

Pivot tables and cross-tabulations provide alternative ways to summarize and reshape grouped data for analysis.

```python
# Create a pivot table
pivot_table = pd.pivot_table(
    df, 
    values='Sales', 
    index='Category', 
    columns='Region', 
    aggfunc='sum',
    fill_value=0
)

print("\nPivot Table - Sales by Category and Region:")
print(pivot_table)

# Multiple values and aggregation functions
multi_pivot = pd.pivot_table(
    df,
    values=['Sales', 'Quantity'],
    index='Category',
    columns='Region',
    aggfunc={'Sales': 'sum', 'Quantity': 'mean'},
    margins=True  # Add row and column totals
)

print("\nPivot Table with multiple values and aggregations:")
print(multi_pivot)

# Cross-tabulation (frequency table)
cross_tab = pd.crosstab(
    df['Category'], 
    df['Region'], 
    values=df['Sales'], 
    aggfunc='sum', 
    normalize=False  # Set to True for proportions
)

print("\nCross-tabulation of Sales by Category and Region:")
print(cross_tab)

# Visualize the pivot table
plt.figure(figsize=(10, 6))
pivot_table.plot(kind='bar', stacked=True)
plt.title('Sales by Category and Region')
plt.xlabel('Category')
plt.ylabel('Sales')
plt.legend(title='Region')
plt.tight_layout()
plt.show()
```

## 8. Transformation and Filtration

Beyond simple aggregations, pandas also supports group-wise transformations and filtering operations.

```python
# Transformation: apply a function to each value in each group
# Example: Standardizing values within each category
def standardize(x):
    return (x - x.mean()) / x.std() if x.std() > 0 else 0

print("\nStandardized Sales within each Category:")
standardized = df.groupby('Category')['Sales'].transform(standardize)
print(pd.DataFrame({'Original': df['Sales'], 'Standardized': standardized}))

# Calculate the percentage of total sales for each item within its category
category_total = df.groupby('Category')['Sales'].transform('sum')
percentage = df['Sales'] / category_total * 100
print("\nSales as percentage of category total:")
print(pd.DataFrame({'Sales': df['Sales'], 'Category_Total': category_total, 'Percentage': percentage}))

# Filtering: select groups that satisfy a condition
# Example: Categories where average sales > 150
high_sales_categories = df.groupby('Category').filter(lambda x: x['Sales'].mean() > 150)
print("\nData from categories with average sales > 150:")
print(high_sales_categories)

# Example: Categories with at least 3 entries
large_categories = df.groupby('Category').filter(lambda x: len(x) >= 3)
print("\nData from categories with at least 3 entries:")
print(large_categories)
```

## 9. Practical Applications

Let's explore some real-world applications of data aggregation and grouping.

```python
# Let's create a more realistic dataset
np.random.seed(42)
dates = pd.date_range('1/1/2023', periods=1000)
products = ['Product_A', 'Product_B', 'Product_C', 'Product_D', 'Product_E']
regions = ['North', 'South', 'East', 'West']
channels = ['Online', 'Retail', 'Direct']

sales_data = pd.DataFrame({
    'Date': np.random.choice(dates, 1000),
    'Product': np.random.choice(products, 1000),
    'Region': np.random.choice(regions, 1000),
    'Channel': np.random.choice(channels, 1000),
    'Units': np.random.randint(1, 50, 1000),
    'Price': np.random.uniform(10, 100, 1000).round(2)
})

# Calculate Total Revenue
sales_data['Revenue'] = sales_data['Units'] * sales_data['Price']
print("\nSample sales data:")
print(sales_data.head())

# Example 1: Monthly sales analysis
# Add month column for grouping
sales_data['Month'] = sales_data['Date'].dt.month_name()
sales_data['Quarter'] = sales_data['Date'].dt.quarter

monthly_sales = sales_data.groupby('Month')['Revenue'].sum().reindex(['January', 'February', 'March', 'April', 'May', 'June', 'July', 'August', 'September', 'October', 'November', 'December'])
print("\nMonthly Sales Analysis:")
print(monthly_sales)

plt.figure(figsize=(12, 6))
monthly_sales.plot(kind='bar', color='skyblue')
plt.title('Monthly Sales Revenue')
plt.ylabel('Revenue')
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Example 2: Product performance by channel
product_channel = sales_data.pivot_table(
    values='Revenue',
    index='Product',
    columns='Channel',
    aggfunc='sum',
    fill_value=0
)
print("\nProduct Performance by Sales Channel:")
print(product_channel)

# Example 3: Regional performance analysis with multiple metrics
regional_performance = sales_data.groupby('Region').agg({
    'Revenue': ['sum', 'mean'],
    'Units': 'sum',
    'Price': 'mean'
})
regional_performance.columns = ['Total_Revenue', 'Avg_Transaction_Revenue', 'Total_Units', 'Avg_Price']
regional_performance['Revenue_per_Unit'] = regional_performance['Total_Revenue'] / regional_performance['Total_Units']
print("\nRegional Performance Analysis:")
print(regional_performance)

# Example 4: Identifying top products by quarter
top_products = sales_data.pivot_table(
    values='Revenue',
    index='Product',
    columns='Quarter',
    aggfunc='sum'
)
print("\nProduct Performance by Quarter:")
print(top_products)

# Heatmap visualization of product performance by quarter
plt.figure(figsize=(10, 8))
sns.heatmap(top_products, annot=True, fmt='.0f', cmap='YlGnBu')
plt.title('Product Revenue by Quarter')
plt.tight_layout()
plt.show()
```

## 10. Summary

Data aggregation and grouping are fundamental techniques in data analysis that allow you to segment data and compute summary statistics for each group. These operations are crucial for uncovering patterns, making comparisons, and drawing insights from your data.

Key concepts covered in this guide:

- **Basic Groupby Operations**: Using pandas' `.groupby()` to split data into groups based on categorical variables
- **Aggregation Functions**: Applying summary functions like `sum()`, `mean()`, or custom functions to grouped data
- **Multiple Aggregations**: Performing various aggregations simultaneously for richer analysis
- **Multi-level Grouping**: Grouping by multiple columns to create hierarchical views of data
- **Hierarchical Indexing**: Working with the MultiIndex structures that result from groupby operations
- **Pivot Tables**: Creating spreadsheet-like summaries of your data
- **Transformation & Filtration**: Applying functions that preserve the original data shape or filter based on group properties
- **Practical Applications**: Real-world examples of using groupby for business analytics

Mastering data aggregation and grouping techniques enables more sophisticated data analysis and helps uncover relationships and patterns that might not be visible in the raw data. By effectively applying these techniques, you can transform raw data into actionable insights for decision-making.
