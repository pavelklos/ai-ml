## 1. Introduction to Data Loading

Data loading is one of the first steps in any data science project. The ability to import data from different sources is fundamental to performing analysis and building models. Python offers many libraries that make loading data from various sources straightforward and efficient.

The most common data formats encountered in data science include:
- CSV (Comma-Separated Values)
- Excel spreadsheets
- JSON (JavaScript Object Notation)
- SQL databases
- Web APIs

In this guide, we'll explore how to load data from these different sources using popular Python libraries like pandas, requests, and SQLAlchemy.


## 2. Loading CSV Files

CSV (Comma-Separated Values) is one of the most common formats for tabular data. Pandas provides the `read_csv()` function to easily import CSV files.

```python
# Basic CSV loading
df_csv = pd.read_csv('data.csv')
print("Basic CSV import:")
print(df_csv.head())

# CSV with custom delimiter
df_custom = pd.read_csv('data.txt', delimiter='\t')  # Tab-delimited file
print("\nTab-delimited file:")
print(df_custom.head())

# Specifying column types
df_types = pd.read_csv('data.csv', dtype={'ID': str, 'Value': float})
print("\nSpecifying column types:")
print(df_types.dtypes)

# Handling dates
df_dates = pd.read_csv('data.csv', parse_dates=['Date'])
print("\nParsing dates:")
print(df_dates.dtypes)

# Loading only specific columns
df_cols = pd.read_csv('data.csv', usecols=['Name', 'Value'])
print("\nSelecting specific columns:")
print(df_cols.head())

# Skipping rows
df_skip = pd.read_csv('data.csv', skiprows=2)  # Skip first two rows
print("\nSkipping rows:")
print(df_skip.head())

# Setting an index column
df_index = pd.read_csv('data.csv', index_col='ID')
print("\nSetting index column:")
print(df_index.head())

# Reading a CSV from a URL
url = "https://raw.githubusercontent.com/datasets/iris/master/data/iris.csv"
df_url = pd.read_csv(url)
print("\nReading from URL:")
print(df_url.head())
```

## 4. Loading JSON Files

JSON (JavaScript Object Notation) is a popular format for web-based data exchange and configuration. Pandas provides `read_json()` to handle JSON files.

```python
# Basic JSON loading
df_json = pd.read_json('data.json')
print("Basic JSON import:")
print(df_json.head())

# JSON with nested structures
with open('nested_data.json', 'r') as f:
    nested_json = json.load(f)

# Converting nested JSON to DataFrame
df_nested = pd.json_normalize(nested_json)
print("\nNormalized nested JSON:")
print(df_nested.head())

# Loading JSON from a string
json_str = '''
[
    {"name": "John", "age": 30, "city": "New York"},
    {"name": "Anna", "age": 25, "city": "Paris"},
    {"name": "Peter", "age": 35, "city": "Berlin"}
]
'''
df_json_str = pd.read_json(json_str)
print("\nJSON from string:")
print(df_json_str)

# Loading JSON from a URL
json_url = "https://api.github.com/repos/pandas-dev/pandas/issues?per_page=5"
df_json_url = pd.read_json(json_url)
print("\nJSON from URL:")
print(df_json_url[['number', 'title']].head())

# Working with complex JSON
response = requests.get(json_url)
issues = response.json()

# Extract specific fields
df_issues = pd.DataFrame([{
    'number': issue['number'],
    'title': issue['title'],
    'state': issue['state'],
    'comments': issue['comments'],
    'created_at': issue['created_at']
} for issue in issues])

print("\nCustom JSON parsing:")
print(df_issues.head())
```

## 5. Loading Data from Databases (SQL)

SQL databases are a common source of structured data. Pandas provides integration with SQL through `read_sql()`.

```python
# Create a sample SQLite database
conn = sqlite3.connect('example.db')
c = conn.cursor()

# Create a table
c.execute('''
    CREATE TABLE IF NOT EXISTS employees
    (id INTEGER PRIMARY KEY, name TEXT, department TEXT, salary REAL)
''')

# Insert sample data
employees = [
    (1, 'John Doe', 'IT', 75000),
    (2, 'Jane Smith', 'HR', 65000),
    (3, 'Bob Johnson', 'Finance', 80000),
    (4, 'Alice Brown', 'Marketing', 70000),
    (5, 'Charlie Wilson', 'IT', 85000)
]

c.executemany('INSERT OR REPLACE INTO employees VALUES (?,?,?,?)', employees)
conn.commit()

# Read data using pandas
df_sql = pd.read_sql('SELECT * FROM employees', conn)
print("Basic SQL query:")
print(df_sql)

# Read with a more complex query
df_filtered = pd.read_sql('''
    SELECT department, AVG(salary) as avg_salary
    FROM employees
    GROUP BY department
    ORDER BY avg_salary DESC
''', conn)

print("\nSQL with aggregation:")
print(df_filtered)

# Using SQLAlchemy for more complex database connections
engine = create_engine('sqlite:///example.db')
df_alchemy = pd.read_sql('employees', engine)
print("\nUsing SQLAlchemy:")
print(df_alchemy)

# Close the connection
conn.close()
```

## 6. Loading Data from Web APIs

Web APIs provide access to dynamic data sources across the internet. The `requests` library combined with pandas makes it easy to fetch and process this data.

```python
# Simple API request
response = requests.get('https://jsonplaceholder.typicode.com/posts')
posts = response.json()

# API with authentication (using a sample endpoint)
def get_authenticated_data(api_url, api_key):
    """Function to fetch data from an API requiring authentication"""
    headers = {'Authorization': f'Bearer {api_key}'}
    response = requests.get(api_url, headers=headers)
    if response.status_code == 200:
        return pd.DataFrame(response.json())
    else:
        print(f"Error: {response.status_code}")
        return pd.DataFrame()

# Handling paginated API responses
def get_paginated_data(base_url, params=None, max_pages=3):
    """Function to handle paginated API responses"""
    all_data = []
    current_page = 1
    
    if params is None:
        params = {}
    
    while current_page <= max_pages:
        params['page'] = current_page
        response = requests.get(base_url, params=params)
        
        if response.status_code != 200:
            print(f"Error on page {current_page}: {response.status_code}")
            break
        
        page_data = response.json()
        
        # Check if we've reached the end of data
        if not page_data:
            break
        
        all_data.extend(page_data)
        current_page += 1
    
    return pd.DataFrame(all_data)

# Example usage
comments_df = get_paginated_data(
    'https://jsonplaceholder.typicode.com/comments',
    params={'_limit': 10},
    max_pages=2
)
print("\nPaginated API data:")
print(f"Total records: {len(comments_df)}")
print(comments_df.head())
```

## 7. Handling Different File Encodings

When working with files from various sources, you may encounter different text encodings. Pandas allows specifying encodings when reading files.

```python
# Reading a file with specific encoding
try:
    # Common encodings: utf-8, latin-1, iso-8859-1, cp1252
    df_encoded = pd.read_csv('data_special_chars.csv', encoding='utf-8')
    print("File with UTF-8 encoding:")
    print(df_encoded.head())
except UnicodeDecodeError:
    print("UTF-8 failed, trying with latin-1")
    df_encoded = pd.read_csv('data_special_chars.csv', encoding='latin-1')
    print("File with latin-1 encoding:")
    print(df_encoded.head())

# Function to detect encoding
def detect_encoding(file_path):
    """Try to detect the encoding of a file"""
    encodings = ['utf-8', 'latin-1', 'iso-8859-1', 'cp1252']
    
    for encoding in encodings:
        try:
            with open(file_path, 'r', encoding=encoding) as f:
                f.read()
            return encoding
        except UnicodeDecodeError:
            continue
    
    return None
```

## 8. Working with Large Files

When dealing with large datasets, loading the entire file into memory may not be feasible. Pandas provides tools to work with large files more efficiently.

```python
# Reading a large CSV file in chunks
chunk_size = 1000  # Number of rows per chunk
chunks = []

for chunk in pd.read_csv('large_file.csv', chunksize=chunk_size):
    # Process each chunk
    # For example, filter rows, aggregate, or transform
    processed_chunk = chunk[chunk['value'] > 100]
    chunks.append(processed_chunk)

# Combine processed chunks
df_large = pd.concat(chunks)
print("Processing large file in chunks:")
print(f"Final size: {df_large.shape}")

# Using a generator to process large files
def process_large_file(filename, chunk_size=1000):
    """Generator function to process large files chunk by chunk"""
    for chunk in pd.read_csv(filename, chunksize=chunk_size):
        # Process chunk
        yield chunk

# Example usage
def analyze_large_dataset(filename):
    """Analyze a large dataset without loading it entirely in memory"""
    total_rows = 0
    column_sums = None
    
    for chunk in process_large_file(filename):
        total_rows += len(chunk)
        
        # Compute column sums for numeric columns
        if column_sums is None:
            column_sums = chunk.select_dtypes(include=[np.number]).sum()
        else:
            column_sums += chunk.select_dtypes(include=[np.number]).sum()
    
    return total_rows, column_sums
```

## 9. Error Handling and Data Validation

When loading data, it's crucial to validate the data integrity and handle errors appropriately.

```python
# Error handling with try-except
try:
    df = pd.read_csv('nonexistent_file.csv')
except FileNotFoundError:
    print("File not found. Using a default empty DataFrame instead.")
    df = pd.DataFrame()

# Validating loaded data
def validate_dataframe(df, required_columns, numeric_columns=None):
    """Validate a DataFrame structure and content"""
    validation_errors = []
    
    # Check for required columns
    for col in required_columns:
        if col not in df.columns:
            validation_errors.append(f"Missing required column: {col}")
    
    # Check numeric columns
    if numeric_columns:
        for col in numeric_columns:
            if col in df.columns:
                if not pd.api.types.is_numeric_dtype(df[col]):
                    validation_errors.append(f"Column {col} should be numeric")
    
    # Check for empty DataFrame
    if df.empty:
        validation_errors.append("DataFrame is empty")
    
    return validation_errors

# Example usage
sample_df = pd.DataFrame({
    'ID': [1, 2, 3],
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Value': ['10', '20', '30']  # String instead of numeric
})

errors = validate_dataframe(
    sample_df,
    required_columns=['ID', 'Name', 'Value', 'Category'],
    numeric_columns=['ID', 'Value']
)

print("\nData validation errors:")
for error in errors:
    print(f"- {error}")

# Converting problematic columns
if 'Value' in sample_df:
    try:
        sample_df['Value'] = pd.to_numeric(sample_df['Value'], errors='coerce')
        print("\nConverted Value to numeric:")
        print(sample_df.dtypes)
    except Exception as e:
        print(f"Error converting column: {e}")
```

## 10. Summary

In this guide, we've explored various methods for loading data from different sources in Python:

1. **CSV Files**: The most common format for tabular data, easily loaded using `pd.read_csv()`.
2. **Excel Files**: Business data often comes in Excel format, which can be loaded with `pd.read_excel()`.
3. **JSON Files**: Web-based data commonly uses JSON, which can be processed with `pd.read_json()` and `json_normalize()`.
4. **SQL Databases**: Structured data is often stored in databases, accessible via `pd.read_sql()`.
5. **Web APIs**: Online data sources can be accessed using the `requests` library and converted to DataFrames.
6. **Large Files**: Techniques like chunking help process files too large to fit in memory.
7. **Encodings**: Different character encodings can be handled by specifying the `encoding` parameter.
8. **Validation**: Always validate your data after loading to ensure integrity.
