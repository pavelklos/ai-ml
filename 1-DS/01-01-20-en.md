## 2. Key Ethical Principles in Data Science

Several fundamental ethical principles guide responsible data science:

- **Transparency**: Being open about how data is collected and used
- **Fairness**: Ensuring algorithms don't discriminate against certain groups
- **Accountability**: Taking responsibility for the outcomes of data-driven decisions
- **Privacy**: Protecting sensitive information and respecting individuals' rights
- **Beneficence**: Striving for positive impact through data science work

```python
# Example: Documenting data provenance and processing steps
def document_data_processing(data, source, transformations=None, purpose=None):
    """
    Document the source and transformations of a dataset for transparency.
    
    Parameters:
    -----------
```

## 3. Privacy Regulations and Compliance

Data scientists must be aware of key regulations governing data privacy, including:

- **GDPR** (General Data Protection Regulation) in Europe
- **CCPA** (California Consumer Privacy Act) in California
- **HIPAA** (Health Insurance Portability and Accountability Act) for healthcare data
- **FERPA** (Family Educational Rights and Privacy Act) for educational data

```python
# Example: Simple GDPR compliance checker
def gdpr_compliance_check(dataframe, column_categories=None):
    """
    Basic check for potential GDPR-sensitive fields in a dataframe.
    
    Parameters:
    -----------
    dataframe : pandas DataFrame
        The dataset to check
    column_categories : dict
        Dictionary mapping column names to data categories
        
    Returns:
    --------
    dict
        Compliance report with potential issues
    """
    if column_categories is None:
        # Default categorization by common column names
        column_categories = {}
        
        for col in dataframe.columns:
            col_lower = col.lower()
            if any(term in col_lower for term in ['name', 'user', 'customer', 'client']):
                column_categories[col] = 'PII'
            elif any(term in col_lower for term in ['email', 'phone', 'address', 'zip', 'post']):
                column_categories[col] = 'Contact'
            elif any(term in col_lower for term in ['ssn', 'social', 'id', 'passport']):
                column_categories[col] = 'Government ID'
            elif any(term in col_lower for term in ['medical', 'health', 'condition', 'treatment']):
                column_categories[col] = 'Health'
            elif any(term in col_lower for term in ['race', 'religion', 'political', 'union', 'orientation']):
                column_categories[col] = 'Special Category'
    
    # Generate report
    sensitive_categories = {
        'PII': 'Personal Identifiable Information',
        'Contact': 'Contact Information',
        'Government ID': 'Government ID Numbers',
        'Health': 'Health Information',
        'Special Category': 'Special Category Data'
    }
    
    report = {
        'potential_sensitive_columns': [],
        'recommended_actions': [],
        'data_subject_rights': [
            'Right to be informed',
            'Right of access',
            'Right to rectification',
            'Right to erasure',
            'Right to restrict processing',
            'Right to data portability',
            'Right to object'
        ]
    }
    
    for col, category in column_categories.items():
        if category in sensitive_categories:
            report['potential_sensitive_columns'].append({
                'column': col,
                'category': category,
                'description': sensitive_categories.get(category, 'Other Sensitive Data')
            })
            
            if category == 'PII' or category == 'Contact':
                report['recommended_actions'].append(f"Consider anonymizing {col}")
            elif category == 'Government ID':
                report['recommended_actions'].append(f"Encrypt {col} and restrict access")
            elif category == 'Health' or category == 'Special Category':
                report['recommended_actions'].append(f"Obtain explicit consent for {col} and justify purpose")
    
    return report

# Example usage
compliance_report = gdpr_compliance_check(sensitive_data)
print("\nGDPR Compliance Check Report:")
print(f"Potential sensitive columns: {len(compliance_report['potential_sensitive_columns'])}")
for col in compliance_report['potential_sensitive_columns']:
    print(f"- {col['column']} ({col['category']}): {col['description']}")
print("\nRecommended actions:")
for action in compliance_report['recommended_actions']:
    print(f"- {action}")
```

## 4. Data Anonymization Techniques

Anonymization techniques help protect individual privacy while still allowing for meaningful data analysis.

```python
# Example: Basic anonymization techniques
def anonymize_data(df):
    """
    Apply basic anonymization techniques to a dataframe.
    
    Parameters:
    -----------
    df : pandas DataFrame
        Original dataframe with sensitive data
        
    Returns:
    --------
    pandas DataFrame
        Anonymized version of the dataframe
    """
    df_anon = df.copy()
    
    # 1. Masking identifiers
    if 'name' in df_anon.columns:
        df_anon['name'] = ['Person_' + str(i+1) for i in range(len(df_anon))]
    
    if 'email' in df_anon.columns:
        df_anon['email'] = ['user' + str(i+1) + '@example.com' for i in range(len(df_anon))]
    
    # 2. Generalization - reduce precision of numeric data
    if 'age' in df_anon.columns:
        # Age bucketing
        bins = [0, 18, 30, 45, 60, 100]
        labels = ['<18', '18-30', '31-45', '46-60', '60+']
        df_anon['age'] = pd.cut(df_anon['age'], bins=bins, labels=labels)
    
    if 'income' in df_anon.columns:
        # Income bucketing
        bins = [0, 50000, 75000, 100000, 150000, float('inf')]
        labels = ['<50k', '50k-75k', '75k-100k', '100k-150k', '150k+']
        df_anon['income'] = pd.cut(df_anon['income'], bins=bins, labels=labels)
    
    # 3. Data suppression - replace sensitive medical data with more general categories
    if 'medical_condition' in df_anon.columns:
        condition_map = {
            'None': 'No Condition',
            'Hypertension': 'Cardiovascular',
            'Diabetes': 'Metabolic',
            'Asthma': 'Respiratory',
        }
        df_anon['medical_condition'] = df_anon['medical_condition'].map(
            lambda x: condition_map.get(x, 'Other Condition')
        )
    
    return df_anon

# Anonymize our sensitive data
anonymized_data = anonymize_data(sensitive_data)
print("\nAnonymized data:")
print(anonymized_data)

# Compare original and anonymized data to verify privacy protection
print("\nOriginal vs Anonymized Data (differences highlighted):")
for col in sensitive_data.columns:
    different = sensitive_data[col] != anonymized_data[col]
    different_count = different.sum()
    print(f"Column '{col}': {different_count}/{len(sensitive_data)} values changed")
```

Bias in data can lead to unfair or discriminatory outcomes in data-driven decisions.

```python
# Calculate disparity metrics
def calculate_bias_metrics(data, protected_attribute, outcome):
    """
    Calculate basic bias metrics for a dataset.
    
    Parameters:
    -----------
    data : pandas DataFrame
        The dataset to analyze
    protected_attribute : str
        Column name of the protected attribute (e.g., 'gender')
    outcome : str
        Column name of the outcome variable (e.g., 'loan_approved')
        
    Returns:
    --------
    dict
        Dictionary of bias metrics
    """
    groups = data[protected_attribute].unique()
    metrics = {}
    
    # Calculate approval rates by group
    group_rates = {}
    for group in groups:
        group_data = data[data[protected_attribute] == group]
        approval_rate = group_data[outcome].mean()
        group_rates[group] = approval_rate
    
    # Calculate disparities
    if len(groups) >= 2:
        base_group = groups[0]
        for group in groups[1:]:
            disparity = group_rates[group] / group_rates[base_group]
            metrics[f'disparity_{base_group}_vs_{group}'] = disparity
    
    # Calculate overall metrics
    metrics['group_rates'] = group_rates
    metrics['max_disparity'] = max(group_rates.values()) / min(group_rates.values())
    metrics['statistical_parity_difference'] = max(group_rates.values()) - min(group_rates.values())
    
    return metrics

# Calculate bias metrics
bias_metrics = calculate_bias_metrics(biased_data, 'gender', 'loan_approved')
print("\nBias metrics:")
for metric, value in bias_metrics.items():
    if metric == 'group_rates':
        print(f"{metric}:")
        for group, rate in value.items():
            print(f"  {group}: {rate:.4f}")
    else:
        print(f"{metric}: {value:.4f}")

# Example: Simple bias mitigation with reweighing
def mitigate_bias_with_reweighing(data, protected_attribute, outcome):
    """
    Apply simple reweighing to mitigate bias.
    
    Parameters:
    -----------
    data : pandas DataFrame
        The dataset to process
    protected_attribute : str
        Column name of the protected attribute (e.g., 'gender')
    outcome : str
        Column name of the outcome variable (e.g., 'loan_approved')
        
    Returns:
    --------
    pandas DataFrame
        Reweighed dataset with weights column
    """
    # Calculate overall approval rate
    overall_rate = data[outcome].mean()
    
    # Calculate weights for each group
    result = data.copy()
    groups = data[protected_attribute].unique()
    
    for group in groups:
        mask = (data[protected_attribute] == group)
        group_data = data[mask]
        group_rate = group_data[outcome].mean()
        
        # Calculate weights to equalize approval rates
        if group_rate > 0:
            weight_approved = overall_rate / group_rate
            weight_rejected = (1 - overall_rate) / (1 - group_rate)
            
            # Apply weights
            result.loc[mask & (data[outcome] == 1), 'weight'] = weight_approved
            result.loc[mask & (data[outcome] == 0), 'weight'] = weight_rejected
    
    return result

# Apply bias mitigation
mitigated_data = mitigate_bias_with_reweighing(biased_data, 'gender', 'loan_approved')
print("\nSample of reweighed data:")
print(mitigated_data[['gender', 'loan_approved', 'weight']].head(10))

# Verify effectiveness of mitigation
print("\nEffective approval rates after reweighing:")
for group in biased_data['gender'].unique():
    group_data = mitigated_data[mitigated_data['gender'] == group]
    weighted_approved = (group_data['loan_approved'] * group_data['weight']).sum()
    total_weight = group_data['weight'].sum()
    effective_rate = weighted_approved / total_weight
    print(f"{group}: {effective_rate:.4f}")
```

## 6. Ethical Data Collection and Consent

Proper consent mechanisms and transparent data collection practices are fundamental to ethical data science.

```python
# Example: Basic consent management system
class ConsentManager:
    """A simple system to manage user consent for data processing."""
    
    def __init__(self):
        self.consent_records = {}
        self.processing_purposes = [
            "analytics", 
            "marketing", 
            "product_improvement",
            "research"
        ]
    
    def record_consent(self, user_id, purposes, timestamp=None, expiration_days=365):
        """
        Record user consent for specific data processing purposes.
        
        Parameters:
        -----------
        user_id : str
            Unique identifier for the user
        purposes : list
            List of purposes the user consented to
        timestamp : datetime, optional
            When consent was given (defaults to now)
        expiration_days : int, optional
            Days until consent expires
        
        Returns:
        --------
        bool
            True if consent was successfully recorded
        """
        if timestamp is None:
            timestamp = pd.Timestamp.now()
            
        expiration = timestamp + pd.Timedelta(days=expiration_days)
        
        # Validate purposes
        valid_purposes = [p for p in purposes if p in self.processing_purposes]
        
        self.consent_records[user_id] = {
            'timestamp': timestamp,
            'expiration': expiration,
            'purposes': valid_purposes,
            'active': True
        }
        
        return True
    
    def withdraw_consent(self, user_id, purposes=None):
        """Withdraw consent for all or specific purposes."""
        if user_id not in self.consent_records:
            return False
            
        if purposes is None:
            # Withdraw all consent
            self.consent_records[user_id]['active'] = False
        else:
            # Withdraw consent for specific purposes
            current_purposes = self.consent_records[user_id]['purposes']
            self.consent_records[user_id]['purposes'] = [
                p for p in current_purposes if p not in purposes
            ]
            
        return True
    
    def check_consent(self, user_id, purpose):
        """Check if user has consented to a specific purpose."""
        if user_id not in self.consent_records:
            return False
            
        record = self.consent_records[user_id]
        
        # Check if consent is active and not expired
        if not record['active'] or pd.Timestamp.now() > record['expiration']:
            return False
            
        # Check if purpose is included
        return purpose in record['purposes']
    
    def get_user_consent_status(self, user_id):
        """Get complete consent status for a user."""
        if user_id not in self.consent_records:
            return None
            
        return self.consent_records[user_id]

# Example usage
consent_system = ConsentManager()

# Record consent for some users
consent_system.record_consent('user1', ['analytics', 'product_improvement'])
consent_system.record_consent('user2', ['analytics', 'marketing', 'research'])
consent_system.record_consent('user3', ['research'])

# Check consent before processing data
users_to_process = ['user1', 'user2', 'user3', 'user4']
purpose = 'analytics'

print(f"\nChecking user consent for '{purpose}':")
for user in users_to_process:

# Example: User withdraws consent
consent_system.withdraw_consent('user2', ['marketing'])
print("\nAfter user2 withdraws marketing consent:")
```

## 7. Differential Privacy

Differential Privacy is a technique that adds statistical noise to data to protect individual privacy while maintaining overall statistical validity.

```python
# Import libraries
import numpy as np
import matplotlib.pyplot as plt

# Example: Simple implementation of differential privacy
def add_laplace_noise(data, sensitivity, epsilon):
    """
    Add Laplace noise to data for differential privacy.
    
    Parameters:
    -----------
    data : array-like
        Original data values
    sensitivity : float
        Maximum change in the function if one record changes
    epsilon : float
        Privacy parameter (smaller = more privacy)
        
    Returns:
    --------
    array-like
        Data with privacy-preserving noise added
    """
    scale = sensitivity / epsilon
    noise = np.random.laplace(0, scale, size=len(data))
    return data + noise

# Create sample sensitive data
np.random.seed(42)
original_ages = np.random.normal(35, 10, 1000).astype(int)
original_ages = np.clip(original_ages, 18, 80)  # Clip to realistic age range

# Calculate true average age
true_average = np.mean(original_ages)

# Apply differential privacy with different privacy levels
epsilon_values = [0.01, 0.1, 0.5, 1.0, 10.0]
sensitivity = 1  # Assuming changing one person's age changes result by at most 1
private_averages = []

for epsilon in epsilon_values:
    # Add noise to all ages
    private_ages = add_laplace_noise(original_ages, sensitivity, epsilon)
    # Calculate noisy average
    private_avg = np.mean(private_ages)
    private_averages.append(private_avg)

# Display results
print("\nDifferential Privacy Results:")
print(f"True average age: {true_average:.2f}")
print("\nPrivate average age estimates:")
for epsilon, avg in zip(epsilon_values, private_averages):
    error = abs(avg - true_average)
    print(f"Epsilon = {epsilon:5.2f}: {avg:.2f} (error: {error:.2f})")

# Example: Privacy-preserving count queries
def count_with_privacy(data, query_function, epsilon=0.1):
    """
    Perform count queries with differential privacy.
    
    Parameters:
    -----------
    data : DataFrame
        Dataset to query
    query_function : function
        Function that returns boolean mask for records to count
    epsilon : float
        Privacy parameter
    
    Returns:
    --------
    int
        Privacy-protected count
    """
    # Count records matching the query
    true_count = query_function(data).sum()
    
    # Add Laplace noise
    sensitivity = 1  # One person can change count by at most 1
    noise = np.random.laplace(0, sensitivity / epsilon)
    
    # Return noisy count (round and ensure non-negative)
    noisy_count = max(0, round(true_count + noise))
    return noisy_count

})

queries = {

    "income > 200k": lambda df: df['income'] > 200000,
    "income < 50k": lambda df: df['income'] < 50000
}

# Run each query with privacy
print("\nPrivacy-preserving count queries:")
for name, query in queries.items():
    # True count
    true_count = query(salary_data).sum()
    
    # Private counts with different epsilon values
    for epsilon in [0.1, 1.0, 10.0]:
        private_count = count_with_privacy(salary_data, query, epsilon)
        error = abs(private_count - true_count)
        print(f"Query: {name}, ε = {epsilon:4.1f}: True: {true_count}, Private: {private_count}, Error: {error}")
```

## 8. Responsible Data Storage and Sharing

Proper data storage, security, and sharing practices are essential for protecting sensitive information.

```python
# Example: Simple encryption and secure data handling
import hashlib
import os
import base64
from cryptography.fernet import Fernet
import json

class SecureDataHandler:
    """A simple class for secure data handling, storage and sharing."""
    
    def __init__(self, encryption_key=None):
        """Initialize with optional encryption key or generate a new one."""
        if encryption_key is None:
            self.key = Fernet.generate_key()
        else:
            self.key = encryption_key
        
        self.cipher = Fernet(self.key)
    
    def encrypt_data(self, data):
        """Encrypt data (string or serializable object)."""
        if not isinstance(data, str):
            # Convert to JSON string first
            data = json.dumps(data)
            
        # Convert to bytes and encrypt
        data_bytes = data.encode('utf-8')
        encrypted_data = self.cipher.encrypt(data_bytes)
        
        # Return as base64 string for easier storage
        return base64.b64encode(encrypted_data).decode('utf-8')
    
    def decrypt_data(self, encrypted_data, as_json=False):
        """Decrypt data from base64 string to original form."""
        # Convert from base64 string to bytes
        encrypted_bytes = base64.b64decode(encrypted_data)
        
        # Decrypt
        decrypted_bytes = self.cipher.decrypt(encrypted_bytes)
        decrypted_data = decrypted_bytes.decode('utf-8')
        
        # Convert from JSON if needed
        if as_json:
            return json.loads(decrypted_data)
        return decrypted_data
    
    def hash_identifier(self, identifier):
        """Create a secure one-way hash of an identifier."""
        # Add salt to prevent lookup attacks
        salt = os.urandom(32)
        
        # Create hash
        key = hashlib.pbkdf2_hmac(
            'sha256',
            identifier.encode('utf-8'),
            salt,
            100000  # Number of iterations
        )
        
        # Combine salt and key for storage
        return base64.b64encode(salt + key).decode('utf-8')
    
    def save_encrypted_data(self, data, filename):
        """Save encrypted data to file."""
        encrypted_data = self.encrypt_data(data)
        with open(filename, 'w') as f:
            f.write(encrypted_data)
        return True
    
    def load_encrypted_data(self, filename, as_json=False):
        """Load and decrypt data from file."""
        with open(filename, 'r') as f:
            encrypted_data = f.read()
        return self.decrypt_data(encrypted_data, as_json)
    
    def share_data_securely(self, data, privacy_level='high'):
        """
        Prepares data for secure sharing based on privacy level.
        
        Parameters:
        -----------
        data : DataFrame
            Data to be shared
        privacy_level : str
            'low', 'medium', or 'high'
            
        Returns:
        --------
        dict
            Prepared data and sharing instructions
        """
        data_copy = data.copy()
        
        if privacy_level == 'high':
            # Remove all direct identifiers and encrypt sensitive fields
            if 'name' in data_copy:
                data_copy = data_copy.drop(columns=['name'])
            if 'email' in data_copy:
                data_copy = data_copy.drop(columns=['email'])
            
            # Add noise to numeric fields
            for col in data_copy.select_dtypes(include=[np.number]).columns:
                # Add small amount of noise (1% standard deviation)
                noise = np.random.normal(0, data_copy[col].std() * 0.01, len(data_copy))
                data_copy[col] = data_copy[col] + noise
            
            # Generate encrypted version
            encrypted = self.encrypt_data(data_copy.to_dict())
            
            return {
                'data': encrypted,
                'type': 'encrypted',
                'instructions': """
                This data is encrypted and has had identifiers removed.
                To decrypt, use the secure key shared separately.
                Do not attempt to re-identify individuals in this dataset.
                """
            }
            
        elif privacy_level == 'medium':
            # Pseudonymize identifiers
            if 'name' in data_copy:
                data_copy['name'] = [f"Subject_{i}" for i in range(len(data_copy))]
                
            # Generalize some fields
            if 'age' in data_copy:
                bins = [0, 18, 30, 45, 60, 100]
                labels = ['<18', '18-30', '31-45', '46-60', '60+']
                data_copy['age'] = pd.cut(data_copy['age'], bins=bins, labels=labels)
                
            return {
                'data': data_copy.to_dict(),
                'type': 'pseudonymized',
                'instructions': """
                This data has been pseudonymized.
                Do not attempt to re-identify individuals.
                Use only for the agreed-upon purpose.
                """
            }
            
        else:  # 'low'
            # Just basic aggregation
            aggregated = {}
            
            # Aggregate numeric columns
            for col in data_copy.select_dtypes(include=[np.number]).columns:
                aggregated[col] = {
                    'mean': data_copy[col].mean(),
                    'median': data_copy[col].median(),
                    'min': data_copy[col].min(),
                    'max': data_copy[col].max(),
                    'std': data_copy[col].std()
                }
            
            # Aggregate categorical columns
            for col in data_copy.select_dtypes(include=['object', 'category']).columns:
                if len(data_copy[col].unique()) < 20:  # Only if not too many categories
                    aggregated[col] = data_copy[col].value_counts().to_dict()
            
            return {
                'data': aggregated,
                'type': 'aggregated',
                'instructions': """
                This data is aggregated and contains no individual records.
                """
            }
```

```python
    # Transparency checks
    if model_info.get('interpretable', False):
        evaluation['transparency']['score'] += 2
    else:
        evaluation['transparency']['issues'].append("Black box model with limited interpretability")
        evaluation['transparency']['recommendations'].append("Consider more interpretable model or use explanation tools")
    
    if model_info.get('documentation', False):
        evaluation['transparency']['score'] += 2
    else:
        evaluation['transparency']['issues'].append("Insufficient model documentation")
        evaluation['transparency']['recommendations'].append("Create comprehensive model documentation")
    
    # Privacy checks
    if dataset_info.get('anonymization', False):
        evaluation['privacy']['score'] += 2
    else:
        evaluation['privacy']['issues'].append("Data not anonymized")
        evaluation['privacy']['recommendations'].append("Apply proper anonymization techniques")
    
    if dataset_info.get('consent', False):
        evaluation['privacy']['score'] += 3
    else:
        evaluation['privacy']['issues'].append("Consent for data usage not verified")
        evaluation['privacy']['recommendations'].append("Ensure proper consent for data usage")
    
    # Robustness checks
    if model_info.get('adversarial_testing', False):
        evaluation['robustness']['score'] += 2
    else:
        evaluation['robustness']['issues'].append("No adversarial testing")
        evaluation['robustness']['recommendations'].append("Conduct adversarial testing")
    
    if model_info.get('edge_case_handling', 0) > 0.5:
        evaluation['robustness']['score'] += 2
    else:
        evaluation['robustness']['issues'].append("Poor handling of edge cases")
        evaluation['robustness']['recommendations'].append("Test and improve handling of edge cases")
    
    # Accountability checks
    if model_info.get('human_oversight', False):
        evaluation['accountability']['score'] += 2
    else:
        evaluation['accountability']['issues'].append("No human oversight")
        evaluation['accountability']['recommendations'].append("Implement human oversight for critical decisions")
    
    if model_info.get('impact_assessment', False):
        evaluation['accountability']['score'] += 2
    else:
        evaluation['accountability']['issues'].append("No impact assessment conducted")
        evaluation['accountability']['recommendations'].append("Conduct thorough impact assessment")
    
    # Calculate overall score
    max_score = 5 * 5  # 5 categories, max 5 points each

    else:
        evaluation['overall_recommendation'] = "Generally ethical. Continue monitoring and improving ethical performance."
    
    return evaluation
```

## 10. Summary

Data ethics and privacy are foundational aspects of responsible data science. Key principles include:

1. **Privacy Protection**: Using techniques like anonymization, differential privacy, and secure data handling to protect sensitive information.

2. **Fairness and Non-discrimination**: Identifying and mitigating bias in data and algorithms to ensure equitable outcomes.

3. **Transparency**: Maintaining clear documentation about data sources, processing methods, and model decision-making.

4. **Consent and Control**: Ensuring individuals have knowledge of and control over how their data is used.

5. **Regulatory Compliance**: Following regulations like GDPR, CCPA, and HIPAA to maintain legal and ethical standards.

6. **Ethical AI Development**: Building models with fairness, accountability, and transparency as core considerations.

7. **Security**: Implementing proper data security measures to prevent unauthorized access or breaches.

As data scientists, we have a responsibility to consider the ethical implications of our work and to prioritize privacy and fairness. This involves making deliberate choices throughout the data lifecycle—from collection to storage, analysis, and sharing—to ensure our work benefits society while respecting individual rights.

The field of data ethics continues to evolve, and staying informed about best practices and emerging standards is essential for any data professional. By incorporating ethical considerations into our workflows, we can build more trustworthy and beneficial data science applications.
