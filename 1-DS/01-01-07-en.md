## 1. Introduction to Descriptive Statistics

Descriptive statistics consists of methods for organizing, summarizing, and presenting data in a convenient and informative way. Unlike inferential statistics, which aims to draw conclusions about a population, descriptive statistics focuses on summarizing what's in your dataset without making broader inferences.

```python
# Import essential libraries for descriptive statistics
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set styling for better visualizations
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(font_scale=1.2)

# Create a sample dataset for demonstration
np.random.seed(42)  # For reproducibility
data = {
    'Age': np.random.normal(35, 10, 200).round().astype(int),
    'Income': np.random.lognormal(mean=10.5, sigma=0.5, size=200).round(),
    'Experience': np.random.normal(10, 5, 200).round().astype(int),
    'Satisfaction': np.random.choice(['Low', 'Medium', 'High'], size=200, 
                                  p=[0.2, 0.5, 0.3]),
    'Department': np.random.choice(['Sales', 'Marketing', 'HR', 'Engineering', 'Finance'], 
                                size=200)
}

# Create a DataFrame
df = pd.DataFrame(data)

# Display first few rows of the dataset
print("Sample data:")
print(df.head())

# Basic information about the dataset
print("\nDataset information:")
print(df.info())
```

Descriptive statistics helps answer questions like:
- What's the average age of employees?
- How much does income vary among employees?
- Which department has the highest average satisfaction?
- Is there a relationship between experience and income?

## 2. Measures of Central Tendency

Measures of central tendency help identify the "center" or typical value of a dataset. The three main measures are:

- **Mean**: The arithmetic average of values
- **Median**: The middle value when data is ordered
- **Mode**: The most frequently occurring value

```python
# Calculate measures of central tendency for numerical columns
print("\nMean values:")
print(df[['Age', 'Income', 'Experience']].mean())

print("\nMedian values:")
print(df[['Age', 'Income', 'Experience']].median())

print("\nMode values:")
print(df[['Age', 'Income', 'Experience']].mode().iloc[0])  # Take first mode if multiple exist

# For categorical data, mode is particularly useful
print("\nMode of categorical columns:")
print(f"Most common satisfaction level: {df['Satisfaction'].mode()[0]}")
print(f"Most common department: {df['Department'].mode()[0]}")

# Visualize central tendency
plt.figure(figsize=(12, 6))

plt.subplot(1, 2, 1)
sns.histplot(df['Age'], kde=True)
plt.axvline(df['Age'].mean(), color='red', linestyle='--', label=f'Mean: {df["Age"].mean():.1f}')
plt.axvline(df['Age'].median(), color='green', linestyle='-.', label=f'Median: {df["Age"].median():.1f}')
plt.legend()
plt.title('Age Distribution with Central Tendency')

plt.subplot(1, 2, 2)
sns.histplot(df['Income'], kde=True)
plt.axvline(df['Income'].mean(), color='red', linestyle='--', label=f'Mean: {df["Income"].mean():.1f}')
plt.axvline(df['Income'].median(), color='green', linestyle='-.', label=f'Median: {df["Income"].median():.1f}')
plt.legend()
plt.title('Income Distribution with Central Tendency')

plt.tight_layout()
plt.show()
```

When to use each measure:
- **Mean**: Best for symmetrical distributions without outliers
- **Median**: More robust to outliers; better for skewed distributions
- **Mode**: Useful for categorical data or discrete values with clear peaks

## 3. Measures of Dispersion

While central tendency tells us about typical values, dispersion measures tell us how spread out the data is:

- **Range**: The difference between maximum and minimum values
- **Variance**: The average squared deviation from the mean
- **Standard Deviation**: The square root of variance; represents typical deviation from the mean
- **Interquartile Range (IQR)**: The range of the middle 50% of data

```python
# Calculate range
def calculate_range(series):
    return series.max() - series.min()

print("\nRange values:")
print(f"Age range: {calculate_range(df['Age'])}")
print(f"Income range: {calculate_range(df['Income'])}")
print(f"Experience range: {calculate_range(df['Experience'])}")

# Calculate variance
print("\nVariance values:")
print(df[['Age', 'Income', 'Experience']].var())

# Calculate standard deviation
print("\nStandard deviation values:")
print(df[['Age', 'Income', 'Experience']].std())

# Calculate IQR
q1 = df[['Age', 'Income', 'Experience']].quantile(0.25)
q3 = df[['Age', 'Income', 'Experience']].quantile(0.75)
iqr = q3 - q1
print("\nInterquartile Range (IQR):")
print(iqr)

# Visualize dispersion
plt.figure(figsize=(14, 6))

plt.subplot(1, 2, 1)
sns.boxplot(y=df['Age'])
plt.title('Boxplot of Age')
plt.ylabel('Age')

plt.subplot(1, 2, 2)
sns.boxplot(y=df['Income'])
plt.title('Boxplot of Income')
plt.ylabel('Income')

plt.tight_layout()
plt.show()
```

Standard deviation is particularly useful because:
- It's in the same units as the original data
- About 68% of values lie within 1 standard deviation of the mean in a normal distribution
- About 95% of values lie within 2 standard deviations

## 4. Distribution Analysis

Understanding the shape of your data distribution provides valuable insights:

- **Skewness**: Measures asymmetry (positive/right-skewed or negative/left-skewed)
- **Kurtosis**: Measures "tailedness" (how heavy the tails are compared to a normal distribution)
- **Normality**: Whether data follows a normal distribution

```python
from scipy import stats

# Calculate skewness
print("\nSkewness:")
print(df[['Age', 'Income', 'Experience']].skew())

# Calculate kurtosis
print("\nKurtosis:")
print(df[['Age', 'Income', 'Experience']].kurtosis())

# Visualize distributions
plt.figure(figsize=(15, 10))

# Age distribution
plt.subplot(2, 2, 1)
sns.histplot(df['Age'], kde=True)
plt.title(f'Age Distribution (Skewness: {df["Age"].skew():.2f})')

# Income distribution
plt.subplot(2, 2, 2)
sns.histplot(df['Income'], kde=True)
plt.title(f'Income Distribution (Skewness: {df["Income"].skew():.2f})')

# Experience distribution
plt.subplot(2, 2, 3)
sns.histplot(df['Experience'], kde=True)
plt.title(f'Experience Distribution (Skewness: {df["Experience"].skew():.2f})')

# Q-Q Plot to check for normality (Age)
plt.subplot(2, 2, 4)
stats.probplot(df['Age'], plot=plt)
plt.title('Q-Q Plot for Age')

plt.tight_layout()
plt.show()

# Shapiro-Wilk test for normality
print("\nShapiro-Wilk Test for Normality (p-value):")
print(f"Age: {stats.shapiro(df['Age'])[1]:.6f}")
print(f"Income: {stats.shapiro(df['Income'])[1]:.6f}")
print(f"Experience: {stats.shapiro(df['Experience'])[1]:.6f}")
# If p-value < 0.05, the data is not normally distributed
```

Interpreting distribution characteristics:
- **Skewness**: Values > 0 indicate right skew; values < 0 indicate left skew
- **Kurtosis**: Values > 3 indicate heavy tails (leptokurtic); values < 3 indicate light tails (platykurtic)
- The Shapiro-Wilk test helps determine if data is normally distributed (p-value > 0.05 suggests normality)

## 5. Percentiles and Quartiles

Percentiles and quartiles divide your dataset into segments, helping understand data distribution:

- **Percentiles**: Values that divide the data into 100 equal parts
- **Quartiles**: Values that divide the data into 4 equal parts (25%, 50%, 75%)

```python
# Calculate common percentiles
percentiles = [0.1, 0.25, 0.5, 0.75, 0.9]
print("\nPercentiles for numerical columns:")
print(df[['Age', 'Income', 'Experience']].quantile(percentiles))

# Calculate quartiles
print("\nQuartiles:")
print("First quartile (25%):")
print(df[['Age', 'Income', 'Experience']].quantile(0.25))

print("\nSecond quartile (50% - median):")
print(df[['Age', 'Income', 'Experience']].quantile(0.5))

print("\nThird quartile (75%):")
print(df[['Age', 'Income', 'Experience']].quantile(0.75))

# Visualize with percentile-based methods
plt.figure(figsize=(14, 6))

plt.subplot(1, 2, 1)
sns.boxplot(y=df['Age'])
plt.title('Boxplot showing Quartiles of Age')
plt.ylabel('Age')

plt.subplot(1, 2, 2)
# Violin plot shows distribution shape and quartiles
sns.violinplot(y=df['Age'], inner='quartile')
plt.title('Violin Plot with Quartiles of Age')
plt.ylabel('Age')

plt.tight_layout()
plt.show()
```

Quartiles and percentiles are useful for:
- Identifying outliers (values beyond 1.5 × IQR from Q1 or Q3)
- Understanding data spread and concentration
- Setting thresholds for categorizing data (e.g., low/medium/high income groups)

## 6. Correlation and Covariance

Correlation and covariance help identify relationships between variables:

- **Covariance**: Measures how two variables change together
- **Correlation**: Standardized measure of relationship strength (-1 to 1)

```python
# Calculate covariance matrix
covariance_matrix = df[['Age', 'Income', 'Experience']].cov()
print("\nCovariance Matrix:")
print(covariance_matrix)

# Calculate correlation matrix
correlation_matrix = df[['Age', 'Income', 'Experience']].corr()
print("\nCorrelation Matrix:")
print(correlation_matrix)

# Visualize correlations
plt.figure(figsize=(10, 8))
sns.heatmap(correlation_matrix, annot=True, cmap='coolwarm', vmin=-1, vmax=1)
plt.title('Correlation Matrix Heatmap')
plt.tight_layout()
plt.show()

# Scatter plots to visualize relationships
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
sns.regplot(x='Experience', y='Income', data=df)
plt.title(f'Experience vs Income\nCorrelation: {correlation_matrix.loc["Experience", "Income"]:.2f}')

plt.subplot(1, 2, 2)
sns.regplot(x='Age', y='Experience', data=df)
plt.title(f'Age vs Experience\nCorrelation: {correlation_matrix.loc["Age", "Experience"]:.2f}')

plt.tight_layout()
plt.show()

# Pearson correlation with p-value to test significance
from scipy.stats import pearsonr

corr_exp_income, p_value = pearsonr(df['Experience'], df['Income'])
print(f"\nPearson correlation between Experience and Income: {corr_exp_income:.3f}")
print(f"P-value: {p_value:.6f}")
if p_value < 0.05:
    print("The correlation is statistically significant.")
else:
    print("The correlation is not statistically significant.")
```

Interpreting correlation coefficients:
- Values close to 1: Strong positive correlation
- Values close to -1: Strong negative correlation
- Values close to 0: Weak or no correlation

## 7. Summarizing Categorical Data

Categorical data requires different summary techniques than numerical data:

```python
# Frequency counts
satisfaction_counts = df['Satisfaction'].value_counts()
print("\nSatisfaction level counts:")
print(satisfaction_counts)

department_counts = df['Department'].value_counts()
print("\nDepartment counts:")
print(department_counts)

# Proportions
satisfaction_props = df['Satisfaction'].value_counts(normalize=True)
print("\nSatisfaction level proportions:")
print(satisfaction_props)

# Cross-tabulation for two categorical variables
cross_tab = pd.crosstab(df['Department'], df['Satisfaction'])
print("\nCross-tabulation of Department and Satisfaction:")
print(cross_tab)

# Proportions within each department
cross_tab_prop = pd.crosstab(df['Department'], df['Satisfaction'], normalize='index')
print("\nProportion of satisfaction levels within each department:")
print(cross_tab_prop)

# Visualize categorical data
plt.figure(figsize=(14, 10))

plt.subplot(2, 2, 1)
satisfaction_counts.plot(kind='bar')
plt.title('Frequency of Satisfaction Levels')
plt.ylabel('Count')

plt.subplot(2, 2, 2)
department_counts.plot(kind='bar')
plt.title('Frequency of Departments')
plt.ylabel('Count')

plt.subplot(2, 2, 3)
sns.heatmap(cross_tab, annot=True, fmt='d', cmap='Blues')
plt.title('Department vs Satisfaction (Counts)')

plt.subplot(2, 2, 4)
sns.heatmap(cross_tab_prop, annot=True, fmt='.2f', cmap='Blues')
plt.title('Department vs Satisfaction (Proportions)')

plt.tight_layout()
plt.show()
```

Categorical data summaries help:
- Identify dominant categories or classes
- Understand the distribution of categorical variables
- Explore relationships between categorical variables

## 8. Visual Exploration of Descriptive Statistics

Visualizations make it easier to understand and communicate statistical insights:

# Create more advanced visualizations for descriptive statistics

    plt.text(i, mean + 100, f'{mean:.0f}', ha='center')

Effective visualizations help:
- Spot patterns, trends, and outliers
- Compare different groups or categories
- Communicate findings to non-technical audiences

## 9. Using pandas describe() and Statistical Functions

pandas offers built-in functions to quickly generate descriptive statistics:

```python
# The describe() method provides many statistics in one call
numeric_summary = df.describe()
print("\nSummary statistics for numeric columns:")
print(numeric_summary)

# Include all columns (categorical too)
all_summary = df.describe(include='all')
print("\nSummary statistics for all columns:")
print(all_summary)

# Apply describe() to grouped data
grouped_summary = df.groupby('Department')['Income'].describe()
print("\nSummary statistics for Income by Department:")
print(grouped_summary)

# Other useful pandas statistical functions
print("\nSkewness and kurtosis:")
print(df.skew())
print(df.kurtosis())

# Aggregating multiple statistics at once
custom_stats = df.agg({
    'Age': ['min', 'max', 'mean', 'median', 'std'],
    'Income': ['min', 'max', 'mean', 'median', 'std', 'skew'],
    'Experience': ['min', 'max', 'mean', 'median', 'std'],
    'Satisfaction': ['count', 'nunique', pd.Series.mode],
    'Department': ['count', 'nunique']
})
print("\nCustom aggregated statistics:")
print(custom_stats)

# Create a comprehensive statistical summary report
def generate_stats_report(df, numeric_cols):
    """Generate a comprehensive statistical report for numeric columns"""
    # Basic stats
    basic_stats = df[numeric_cols].describe()
    
    # Additional stats
    additional_stats = pd.DataFrame({
        'Range': df[numeric_cols].max() - df[numeric_cols].min(),
        'IQR': df[numeric_cols].quantile(0.75) - df[numeric_cols].quantile(0.25),
        'Skewness': df[numeric_cols].skew(),
        'Kurtosis': df[numeric_cols].kurtosis(),
        'Coefficient of Variation': df[numeric_cols].std() / df[numeric_cols].mean() * 100
    }).T
    
    # Combine all stats
    all_stats = pd.concat([basic_stats, additional_stats])
    
    return all_stats.round(2)

numeric_cols = ['Age', 'Income', 'Experience']
report = generate_stats_report(df, numeric_cols)
print("\nComprehensive Statistical Report:")
print(report)
```

The pandas `describe()` function is a quick way to get:
- Count of non-null values
- Mean, standard deviation
- Minimum, maximum values
- Quartiles (25%, 50%, 75%)

You can customize it or build your own statistical summary functions as needed.

## 10. Summary

Descriptive statistics provide the foundation for data analysis by summarizing and describing your dataset's key characteristics:

- **Central tendency measures** (mean, median, mode) identify typical values
- **Dispersion measures** (standard deviation, range, IQR) describe data spread
- **Distribution analysis** (skewness, kurtosis) characterizes data shape
- **Percentiles and quartiles** help segment and understand data distribution
- **Correlation** identifies relationships between variables
- **Categorical summaries** provide insights into non-numerical data

Descriptive statistics are essential for:
- Initial data exploration and understanding
- Identifying patterns, trends, and anomalies
- Communicating key insights about your data
- Providing the foundation for more advanced analysis
- Making data-driven decisions based on clear summaries

Python libraries like pandas, numpy, and scipy.stats make it easy to calculate descriptive statistics, while matplotlib and seaborn help visualize these insights effectively. Always combine numerical summaries with appropriate visualizations to gain a complete understanding of your data.
