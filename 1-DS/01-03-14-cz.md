## Úvod do výběru příznaků

Výběr příznaků je proces identifikace a výběru podmnožiny vstupních příznaků, které jsou nejvíce relevantní pro cílovou proměnnou. Správně vybrané příznaky mohou zlepšit výkon modelu, zkrátit dobu tréninku, snížit složitost modelu a zmírnit přetrénování.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# Načtení datasetu pro demonstraci výběru příznaků
cancer = load_breast_cancer()
X = pd.DataFrame(cancer.data, columns=cancer.feature_names)
y = cancer.target

print(f"Rozměr datasetu: {X.shape}")
print(f"Počet příznaků: {X.shape[1]}")
print(f"Názvy příznaků: {cancer.feature_names[:5]}...")

# Základní statistiky o příznacích
feature_stats = pd.DataFrame({
    'Průměr': X.mean(),
    'Směr.odchylka': X.std(),
    'Min': X.min(),
    'Max': X.max()
}).round(2)

print("\nStatistiky příznaků:")
print(feature_stats.head())

# Vizualizace korelací příznaků
plt.figure(figsize=(10, 8))
correlation_matrix = X.corr().abs()
sns.heatmap(correlation_matrix, cmap='viridis', annot=False)
plt.title('Korelační matice příznaků')
plt.tight_layout()
plt.show()

# Rozdělení dat pro pozdější použití

# Standardizace příznaků
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)
```

## Porozumění rekurzivní eliminaci příznaků

Rekurzivní eliminace příznaků (RFE) je metoda výběru příznaků, která pracuje rekurzivním odstraňováním atributů a vytvářením modelu na základě zbývajících atributů. Používá přesnost modelu k identifikaci, které atributy (a jejich kombinace) nejvíce přispívají k predikci cílového atributu.

Klíčové charakteristiky RFE:
- **Wrapper metoda**: Používá algoritmus strojového učení k vyhodnocení podmnožin příznaků
- **Rekurzivní eliminace**: Začíná se všemi příznaky a postupně odstraňuje ty nejméně důležité
- **Kritéria hodnocení**: Příznaky jsou hodnoceny podle jejich důležitosti pro model

```python
# Konceptuální ilustrace algoritmu RFE
def konceptualni_rfe(X, y, estimator, n_features_to_select):
    """
    Konceptuální implementace algoritmu RFE (pouze pro ilustrační účely)
    """
    # Začínáme se všemi příznaky
    remaining_features = list(range(X.shape[1]))
    ranking = [0] * X.shape[1]
    
    while len(remaining_features) > n_features_to_select:
        # Natrénování modelu se současnými příznaky
        model = clone(estimator)
        model.fit(X[:, remaining_features], y)
        
        # Získání důležitosti příznaků (závisí na modelu)
        if hasattr(model, 'coef_'):
            importances = np.abs(model.coef_[0])
        elif hasattr(model, 'feature_importances_'):
            importances = model.feature_importances_
        else:
            raise ValueError("Model nemá atribut pro důležitost příznaků")
            
        # Nalezení příznaku s nejnižší důležitostí
        min_idx = np.argmin(importances)
        least_important = remaining_features[min_idx]
        
        # Aktualizace hodnocení pro tento příznak
        ranking[least_important] = len(remaining_features)
        
        # Odstranění příznaku
        remaining_features.pop(min_idx)
        
    return remaining_features, ranking

# Poznámka: Toto je pouze konceptuální implementace;
# V praxi používáme implementaci RFE ze scikit-learn
```

## Implementace pomocí scikit-learn

Scikit-learn poskytuje robustní implementaci RFE prostřednictvím třídy `RFE`. Ukážeme si, jak ji použít s různými estimátory.

```python
from sklearn.feature_selection import RFE
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC

# Nastavení základního estimátoru - může být jakýkoli model s metodou .fit() a feature_importances_ nebo coef_
base_estimator = RandomForestClassifier(n_estimators=100, random_state=42)

# Vytvoření RFE modelu a výběr atributů
n_features_to_select = 10  # Počet příznaků, které chceme vybrat
rfe = RFE(estimator=base_estimator, n_features_to_select=n_features_to_select, step=1)

# Učení RFE
rfe.fit(X_train_scaled, y_train)

# Získání vybraných příznaků
selected_features = X.columns[rfe.support_]
print(f"Vybrané příznaky: {selected_features.tolist()}")

# Získání hodnocení příznaků (nižší hodnocení = důležitější)
feature_ranking = pd.DataFrame({
    'Příznak': X.columns,
    'Hodnocení': rfe.ranking_
}).sort_values('Hodnocení')
print("\nHodnocení příznaků:")
print(feature_ranking)

# Transformace datasetu pro zachování pouze vybraných příznaků
X_train_rfe = rfe.transform(X_train_scaled)
X_test_rfe = rfe.transform(X_test_scaled)

print(f"Původní počet příznaků: {X_train_scaled.shape[1]}")
print(f"Redukovaný počet příznaků: {X_train_rfe.shape[1]}")

# Vyhodnoťme s jednoduchým modelem, abychom viděli vliv
from sklearn.metrics import accuracy_score

# Model se všemi příznaky
model_all = LogisticRegression(max_iter=1000)
model_all.fit(X_train_scaled, y_train)
y_pred_all = model_all.predict(X_test_scaled)
accuracy_all = accuracy_score(y_test, y_pred_all)

# Model s vybranými příznaky
model_rfe = LogisticRegression(max_iter=1000)
model_rfe.fit(X_train_rfe, y_train)
y_pred_rfe = model_rfe.predict(X_test_rfe)
accuracy_rfe = accuracy_score(y_test, y_pred_rfe)

print(f"Přesnost se všemi příznaky: {accuracy_all:.4f}")
print(f"Přesnost s {n_features_to_select} vybranými příznaky: {accuracy_rfe:.4f}")
```

## Rekurzivní eliminace příznaků s křížovou validací

Místo ručního určování počtu příznaků, které chceme vybrat, můžeme použít křížovou validaci k automatickému určení optimálního počtu příznaků. K tomu slouží třída `RFECV`.

```python
from sklearn.feature_selection import RFECV
from sklearn.model_selection import StratifiedKFold

# Nastavení křížové validace
cv = StratifiedKFold(5, shuffle=True, random_state=42)

# Vytvoření RFECV modelu
estimator = RandomForestClassifier(n_estimators=100, random_state=42)
rfecv = RFECV(
    estimator=estimator,
    step=1,
    cv=cv,
    scoring='accuracy',
    min_features_to_select=5
)

# Učení RFECV
rfecv.fit(X_train_scaled, y_train)

# Optimální počet příznaků
print(f"Optimální počet příznaků: {rfecv.n_features_}")
print(f"Nejlepší příznaky: {X.columns[rfecv.support_].tolist()}")

# Vykreslení počtu příznaků versus skóre křížové validace
plt.figure(figsize=(10, 6))
plt.xlabel("Počet vybraných příznaků")
plt.ylabel("Skóre křížové validace (přesnost)")
plt.plot(range(rfecv.min_features_to_select,
                len(rfecv.cv_results_['mean_test_score']) + rfecv.min_features_to_select),
         rfecv.cv_results_['mean_test_score'])
plt.title("RFECV: Výkon vs. počet příznaků")
plt.grid(True)
plt.show()

# Transformace datasetu pro zachování pouze optimálních příznaků
X_train_rfecv = rfecv.transform(X_train_scaled)
X_test_rfecv = rfecv.transform(X_test_scaled)

# Vyhodnocení modelu s optimální sadou příznaků
model_rfecv = LogisticRegression(max_iter=1000)
model_rfecv.fit(X_train_rfecv, y_train)
y_pred_rfecv = model_rfecv.predict(X_test_rfecv)
accuracy_rfecv = accuracy_score(y_test, y_pred_rfecv)

print(f"Přesnost se všemi příznaky: {accuracy_all:.4f}")
print(f"Přesnost s {rfecv.n_features_} optimálními příznaky: {accuracy_rfecv:.4f}")
```

## Vizualizace výsledků výběru příznaků

Vizualizace procesu výběru příznaků nám pomáhá pochopit důležitost různých příznaků a jejich vliv na výkon modelu.

```python
# Vykreslení důležitosti příznaků a stavu výběru
def plot_feature_selection_results(feature_names, support, ranking):
    """Vizualizace výsledků RFE se seřazenou důležitostí příznaků"""
    # Vytvoření dataframe pro snazší manipulaci
    results = pd.DataFrame({
        'Příznak': feature_names,
        'Vybrán': support,
        'Hodnocení': ranking
    })
    
    # Seřazení podle hodnocení (nižší hodnocení = důležitější)
    results = results.sort_values('Hodnocení')
    
    # Vykreslení
    plt.figure(figsize=(12, 8))
    
    # Rozlišení vybraných a nevybraných příznaků
    selected = results[results['Vybrán']]
    not_selected = results[~results['Vybrán']]
    
    plt.barh(range(len(results)), 1/results['Hodnocení'], align='center', 
             color=[('green' if s else 'red') for s in results['Vybrán']])
    plt.yticks(range(len(results)), results['Příznak'])
    plt.xlabel('1/Hodnocení (vyšší = důležitější)')
    plt.title('Důležitost příznaků na základě RFE')
    
    # Přidání legendy
    import matplotlib.patches as patches
    selected_patch = patches.Patch(color='green', label='Vybraný')
    not_selected_patch = patches.Patch(color='red', label='Nevybraný')
    plt.legend(handles=[selected_patch, not_selected_patch])
    
    plt.gca().invert_yaxis()  # Zobrazení nejdůležitějšího příznaku nahoře
    plt.tight_layout()
    plt.grid(axis='x')
    plt.show()

# Vizualizace výsledků RFE
plot_feature_selection_results(X.columns, rfe.support_, rfe.ranking_)

# Vizualizace výsledků RFECV
plot_feature_selection_results(X.columns, rfecv.support_, rfecv.ranking_)
```

## Výběr příznaků pro různé ML algoritmy

Různé algoritmy strojového učení mohou těžit z různých příznaků. Porovnejme RFE s různými základními estimátory.

```python
def compare_rfe_with_models(X_train, X_test, y_train, y_test, feature_names, n_features=10):
    """Porovnání RFE s různými základními estimátory"""
    # Definice modelů, které se použijí jako základní estimátory
    models = {
        'Náhodný les': RandomForestClassifier(n_estimators=100, random_state=42),
        'Logistická regrese': LogisticRegression(max_iter=1000, random_state=42),
        'SVM': SVC(kernel='linear', random_state=42)
    }
    
    results = {}
    selected_features = {}
    
    for name, model in models.items():
        # Vytvoření RFE
        rfe = RFE(estimator=model, n_features_to_select=n_features, step=1)
        
        # Učení RFE
        rfe.fit(X_train, y_train)
        
        # Získání vybraných příznaků
        features = feature_names[rfe.support_].tolist()
        selected_features[name] = features
        
        # Transformace dat
        X_train_rfe = rfe.transform(X_train)
        X_test_rfe = rfe.transform(X_test)
        
        # Trénování a vyhodnocení
        model.fit(X_train_rfe, y_train)
        accuracy = model.score(X_test_rfe, y_test)
        results[name] = accuracy
    
    return results, selected_features

# Porovnání RFE s různými základními estimátory
comparison_results, comparison_features = compare_rfe_with_models(
    X_train_scaled, X_test_scaled, y_train, y_test, X.columns, n_features=10
)

# Zobrazení výsledků
print("Přesnost s různými základními estimátory:")
for model_name, accuracy in comparison_results.items():
    print(f"{model_name}: {accuracy:.4f}")
    print(f"  Vybrané příznaky: {comparison_features[model_name]}")
    print()

# Vizualizace porovnání
plt.figure(figsize=(10, 6))
bars = plt.bar(comparison_results.keys(), comparison_results.values())
plt.ylim(0.9, 1.0)  # Úprava podle vašich výsledků
plt.ylabel('Přesnost')
plt.title('Výkon RFE s různými základními estimátory')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

# Nalezení společných příznaků napříč všemi modely
common_features = set(comparison_features['Náhodný les'])
for features in comparison_features.values():
    common_features = common_features.intersection(set(features))

print(f"Společné příznaky napříč všemi modely: {list(common_features)}")
```

## RFE vs jiné metody výběru příznaků

RFE je pouze jednou z mnoha metod výběru příznaků. Porovnejme ji s jinými populárními přístupy.

```python
from sklearn.feature_selection import SelectKBest, f_classif, SelectFromModel
from sklearn.feature_selection import mutual_info_classif, chi2

def compare_feature_selection_methods(X_train, X_test, y_train, y_test, feature_names, n_features=10):
    """Porovnání různých metod výběru příznaků"""
    results = {}
    selected_features = {}
    
    # 1. RFE s náhodným lesem
    rfe = RFE(RandomForestClassifier(n_estimators=100, random_state=42), 
              n_features_to_select=n_features)
    rfe.fit(X_train, y_train)
    X_train_rfe = rfe.transform(X_train)
    X_test_rfe = rfe.transform(X_test)
    
    model_rfe = LogisticRegression(max_iter=1000)
    model_rfe.fit(X_train_rfe, y_train)
    accuracy_rfe = model_rfe.score(X_test_rfe, y_test)
    
    results['RFE'] = accuracy_rfe
    selected_features['RFE'] = feature_names[rfe.support_].tolist()
    
    # 2. Filtrační metoda: SelectKBest s ANOVA F-value
    selector_f = SelectKBest(f_classif, k=n_features)
    selector_f.fit(X_train, y_train)
    X_train_f = selector_f.transform(X_train)
    X_test_f = selector_f.transform(X_test)
    
    model_f = LogisticRegression(max_iter=1000)
    model_f.fit(X_train_f, y_train)
    accuracy_f = model_f.score(X_test_f, y_test)
    
    results['ANOVA F-value'] = accuracy_f
    selected_features['ANOVA F-value'] = feature_names[selector_f.get_support()].tolist()
    
    # 3. Filtrační metoda: SelectKBest s Mutual Information
    selector_mi = SelectKBest(mutual_info_classif, k=n_features)
    selector_mi.fit(X_train, y_train)
    X_train_mi = selector_mi.transform(X_train)
    X_test_mi = selector_mi.transform(X_test)
    
    model_mi = LogisticRegression(max_iter=1000)
    model_mi.fit(X_train_mi, y_train)
    accuracy_mi = model_mi.score(X_test_mi, y_test)
    
    results['Mutual Information'] = accuracy_mi
    selected_features['Mutual Information'] = feature_names[selector_mi.get_support()].tolist()
    
    # 4. Vestavěná metoda: SelectFromModel s náhodným lesem
    selector_rf = SelectFromModel(RandomForestClassifier(n_estimators=100, random_state=42), 
                                max_features=n_features, threshold=-np.inf)
    selector_rf.fit(X_train, y_train)
    X_train_rf = selector_rf.transform(X_train)
    X_test_rf = selector_rf.transform(X_test)
    
    model_rf = LogisticRegression(max_iter=1000)
    model_rf.fit(X_train_rf, y_train)
    accuracy_rf = model_rf.score(X_test_rf, y_test)
    
    results['Důležitost náhodného lesa'] = accuracy_rf
    selected_features['Důležitost náhodného lesa'] = feature_names[selector_rf.get_support()].tolist()
    
    return results, selected_features

# Porovnání různých metod výběru příznaků
fs_comparison_results, fs_comparison_features = compare_feature_selection_methods(
    X_train_scaled, X_test_scaled, y_train, y_test, X.columns, n_features=10
)

# Zobrazení výsledků
print("Přesnost s různými metodami výběru příznaků:")
for method_name, accuracy in fs_comparison_results.items():
    print(f"{method_name}: {accuracy:.4f}")
    print(f"  Vybrané příznaky: {fs_comparison_features[method_name]}")
    print()

# Vizualizace porovnání
plt.figure(figsize=(12, 6))
bars = plt.bar(fs_comparison_results.keys(), fs_comparison_results.values())
plt.ylim(0.9, 1.0)  # Úprava podle vašich výsledků
plt.ylabel('Přesnost')
plt.title('Porovnání metod výběru příznaků')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

## Praktická doporučení a osvědčené postupy

Při implementaci rekurzivní eliminace příznaků zvažte tyto osvědčené postupy pro zajištění efektivního výběru příznaků:

```python
# Osvědčené postupy pro RFE
"""
1. Škálujte své příznaky před aplikací RFE
2. Zvolte vhodný základní estimátor pro váš problém
3. Zvažte výpočetní náročnost pro velké datasety
4. Použijte RFECV pro automatický výběr optimálního počtu příznaků
5. Dejte pozor na korelace příznaků
6. Při interpretaci výsledků zvažte doménové znalosti
7. Kombinujte s jinými metodami výběru příznaků pro robustní výsledky
"""

# Práce s vysoce korelovanými příznaky
def handle_correlations(X, threshold=0.8):
    """Identifikace a zpracování vysoce korelovaných příznaků"""
    corr_matrix = X.corr().abs()
    
    # Extrakce horního trojúhelníku korelační matice
    upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool))
    
    # Nalezení příznaků s korelací větší než práh
    to_drop = [column for column in upper.columns if any(upper[column] > threshold)]
    
    print(f"Nalezeno {len(to_drop)} vysoce korelovaných příznaků k odstranění")
    print(f"Příznaky k odstranění: {to_drop}")
    
    return to_drop

# Příklad zpracování korelovaných příznaků před RFE
correlated_features = handle_correlations(X, threshold=0.8)
X_uncorrelated = X.drop(columns=correlated_features)

print(f"Původní rozměr: {X.shape}")
print(f"Rozměr po odstranění korelovaných příznaků: {X_uncorrelated.shape}")

# Poté aplikujte RFE na nekorelované příznaky
X_train_uncorr, X_test_uncorr, y_train, y_test = train_test_split(
    X_uncorrelated, y, test_size=0.3, random_state=42
)

# Škálování příznaků
scaler = StandardScaler()
X_train_uncorr_scaled = scaler.fit_transform(X_train_uncorr)
X_test_uncorr_scaled = scaler.transform(X_test_uncorr)

# Aplikace RFE na nekorelované příznaky
rfe_uncorr = RFE(
    RandomForestClassifier(n_estimators=100, random_state=42),
    n_features_to_select=min(10, X_uncorrelated.shape[1]),  # Pro případ, že bychom měli méně než 10 příznaků
    step=1
)
rfe_uncorr.fit(X_train_uncorr_scaled, y_train)

# Zobrazení vybraných příznaků
selected_uncorr = X_uncorrelated.columns[rfe_uncorr.support_].tolist()
print(f"Vybrané příznaky po zpracování korelací: {selected_uncorr}")
```

## Případová studie: Praktická aplikace

Aplikujme RFE na složitější reálný dataset pro demonstraci jeho praktického využití.

```python
from sklearn.datasets import fetch_california_housing
import time

# Načtení většího datasetu
housing = fetch_california_housing()
X_housing = pd.DataFrame(housing.data, columns=housing.feature_names)
y_housing = housing.target

print(f"Rozměr datasetu: {X_housing.shape}")
print(f"Příznaky: {housing.feature_names}")

# Podívejme se na základní statistiky
print(X_housing.describe())

# Rozdělení dat
X_h_train, X_h_test, y_h_train, y_h_test = train_test_split(
    X_housing, y_housing, test_size=0.3, random_state=42
)

# Škálování příznaků
scaler = StandardScaler()
X_h_train_scaled = scaler.fit_transform(X_h_train)
X_h_test_scaled = scaler.transform(X_h_test)

# Základní model bez výběru příznaků
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error, r2_score

start_time = time.time()
baseline_model = RandomForestRegressor(n_estimators=100, random_state=42)
baseline_model.fit(X_h_train_scaled, y_h_train)
```

## Shrnutí

Rekurzivní eliminace příznaků je mocnou technikou pro výběr příznaků, která může výrazně zlepšit výkon modelu a zároveň snížit jeho složitost. Zde jsou klíčové poznatky:

1. **Důležitost výběru příznaků**: Snížení dimenzionality výběrem relevantních příznaků může zlepšit výkon modelu, interpretovatelnost a výpočetní efektivitu.

2. **Mechanismus RFE**: RFE pracuje rekurzivním odstraňováním nejméně důležitých příznaků na základě důležitosti příznaků nebo koeficientů modelu.

3. **Integrace křížové validace**: RFECV automaticky identifikuje optimální počet příznaků pomocí křížové validace, vyvažuje výkon modelu proti složitosti.

4. **Výběr základního estimátoru**: Volba základního estimátoru ovlivňuje, které příznaky jsou vybrány, protože různé modely hodnotí příznaky odlišně.

5. **Komplementární metody**: RFE často funguje nejlépe v kombinaci s jinými technikami výběru příznaků a doménovými znalostmi.

6. **Důležitost předzpracování**: Škálování příznaků a analýza korelací jsou důležité kroky předzpracování před aplikací RFE.

7. **Přínosy výkonu**: Dobře provedený výběr příznaků může vést k:
   - Rychlejšímu tréninku a inferenci
   - Lepší generalizaci
   - Jednodušším modelům, které jsou snáze interpretovatelné
   - Nižší paměťové náročnosti

8. **Praktické úvahy**: Pro velké datasety může být RFE výpočetně náročná, ale strategie jako zvýšení velikosti kroku mohou pomoci.

Výběr příznaků pomocí RFE není jen o zlepšení výkonu modelu, ale také o získání vhledu do toho, co ovlivňuje vaši cílovou proměnnou. Vybrané příznaky často poskytují cenné doménové znalosti a mohou vést další úsilí při sběru dat.
