## Úvod do kauzální inference

Kauzální inference je proces určování skutečného vlivu léčby nebo intervence na výsledek. Na rozdíl od tradičních statistických metod, které se zaměřují na korelaci, kauzální inference se snaží odpovědět na otázky "co kdyby": Co by se stalo, kdybychom změnili X?

Klíčové koncepty v kauzální inferenci:

- **Korelace vs. kauzalita**: Známá fráze "korelace neznamená kauzalitu" zdůrazňuje, že pozorování vztahu mezi proměnnými nutně neznamená, že jedna způsobuje druhou.
- **Kontrafaktuální uvažování**: Přemýšlení o tom, co by se stalo v alternativním scénáři.
- **Confounding (zkreslení)**: Když proměnné ovlivňují jak léčbu, tak výsledek, což vytváří falešné asociace.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Příklad falešné korelace
np.random.seed(42)
n = 1000

# Confounding: teplota ovlivňuje prodej zmrzliny i plavání
teplota = np.random.normal(75, 10, n)

# Prodej zmrzliny roste s teplotou (s určitým šumem)
prodej_zmrzliny = 100 + 7 * teplota + np.random.normal(0, 50, n)

# Plavání roste s teplotou (s určitým šumem)
plavani = 50 + 5 * teplota + np.random.normal(0, 40, n)

data = pd.DataFrame({
    'Teplota': teplota,
    'Prodej_zmrzliny': prodej_zmrzliny,
    'Plavani': plavani
})

# Výpočet korelace
korelace = data['Prodej_zmrzliny'].corr(data['Plavani'])

# Vizualizace vztahu
plt.figure(figsize=(10, 6))
sns.scatterplot(x='Prodej_zmrzliny', y='Plavani', data=data)
plt.title(f'Prodej zmrzliny vs. Plavání (r = {korelace:.2f})')
plt.xlabel('Prodej zmrzliny (Kč)')
plt.ylabel('Počet plavajících lidí')
plt.show()

print(f"Korelace mezi prodejem zmrzliny a plaváním: {korelace:.2f}")
print("Navzdory silné korelaci, prodej zmrzliny nezpůsobuje plavání.")
print("Obě jsou zapříčiněny společným faktorem: teplotou (confounder).")
```

Proč je kauzální inference důležitá v datové vědě:
- Informuje rozhodování a politiky
- Umožňuje predikci efektů intervencí
- Poskytuje porozumění základním mechanismům
- Pomáhá vyhnout se nákladným rozhodnutím založeným na korelačních vzorech

## Rámec potenciálních výsledků

Rubinův kauzální model (rámec potenciálních výsledků) poskytuje matematický základ pro kauzální inferenci:

- Y(1) = Výsledek při léčbě
- Y(0) = Výsledek bez léčby
- Kauzální efekt = Y(1) - Y(0)

Základní problém kauzální inference spočívá v tom, že pro každou jednotku můžeme pozorovat pouze jeden potenciální výsledek.

```python
# Simulace jednoduchého randomizovaného experimentu
np.random.seed(123)
n = 1000

# Generování přiřazení léčby
léčba = np.random.binomial(1, 0.5, n)

# Generování potenciálních výsledků (nepozorovatelné v reálných podmínkách)
# Průměrný efekt léčby je 10
y0 = 50 + np.random.normal(0, 10, n)  # Výsledek bez léčby
y1 = 60 + np.random.normal(0, 10, n)  # Výsledek při léčbě

# Skutečný kauzální efekt (obvykle neznámý)
skutečný_efekt = np.mean(y1 - y0)

# Pozorované výsledky
pozorované_y = léčba * y1 + (1 - léčba) * y0

# Vytvoření DataFrame
df = pd.DataFrame({
    'léčba': léčba,
    'pozorované_y': pozorované_y,
    'y0': y0,  # Nepozorovatelné v reálných podmínkách
    'y1': y1   # Nepozorovatelné v reálných podmínkách
})

# Naivní odhad (funguje v randomizovaných experimentech)
odhadovaný_efekt = df[df['léčba'] == 1]['pozorované_y'].mean() - df[df['léčba'] == 0]['pozorované_y'].mean()

print(f"Skutečný kauzální efekt: {skutečný_efekt:.2f}")
print(f"Odhadovaný kauzální efekt: {odhadovaný_efekt:.2f}")

# Vizualizace
plt.figure(figsize=(10, 6))
sns.histplot(data=df, x='pozorované_y', hue='léčba', bins=30, alpha=0.6)
plt.axvline(df[df['léčba'] == 1]['pozorované_y'].mean(), color='blue', linestyle='--')
plt.axvline(df[df['léčba'] == 0]['pozorované_y'].mean(), color='orange', linestyle='--')
plt.title('Distribuce výsledků podle skupiny léčby')
plt.xlabel('Výsledek')
plt.legend(['Průměr léčby', 'Průměr kontroly', 'Léčba', 'Kontrola'])
plt.show()
```

## Observační metody: Párování a propensity skóre

Když není možné náhodné přiřazení, metody párování mohou pomoci vytvořit srovnatelné skupiny léčby a kontroly.

```python
# pip install causalinference

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression

# Simulace observačních dat s confoundingem
np.random.seed(123)
n = 2000

# Confoundersy: věk a zdravotní stav
věk = np.random.normal(45, 15, n)
zdravotní_stav = np.random.normal(70, 20, n)

# Přiřazení léčby (ovlivněné confoundery)
# Starší a zdravější lidé mají vyšší pravděpodobnost léčby
propensity = 1 / (1 + np.exp(-(věk/50 - 1 + zdravotní_stav/100)))
léčba = np.random.binomial(1, propensity)

# Výsledek ovlivněný léčbou a confoundery
výsledek = 50 + 10 * léčba + 0.5 * věk - 0.2 * zdravotní_stav + np.random.normal(0, 10, n)

# Vytvoření DataFrame
data = pd.DataFrame({
    'věk': věk,
    'zdravotní_stav': zdravotní_stav,
    'léčba': léčba,
    'výsledek': výsledek
})

# Naivní odhad (zkreslený kvůli confoundingu)
naivní_efekt = data[data['léčba'] == 1]['výsledek'].mean() - data[data['léčba'] == 0]['výsledek'].mean()
print(f"Naivní efekt léčby (zkreslený): {naivní_efekt:.2f}")

# Párování pomocí propensity skóre
# 1. Odhad propensity skóre
X = data[['věk', 'zdravotní_stav']]
y = data['léčba']
ps_model = LogisticRegression()
ps_model.fit(X, y)
data['propensity_skóre'] = ps_model.predict_proba(X)[:, 1]

# 2. Vytvoření spárovaných vzorků pomocí párování nejbližšího souseda
def najdi_pár(prop_skóre, status_léčby, data):
    """Najít nejbližší párování z opačné skupiny léčby."""
    jiná_skupina = data[data['léčba'] != status_léčby]
    vzdálenosti = abs(jiná_skupina['propensity_skóre'] - prop_skóre)
    párovaný_index = vzdálenosti.idxmin()
    return párovaný_index

# Vytvoření párů pro léčené jednotky
np.random.seed(42)
léčení = data[data['léčba'] == 1].copy()
léčení['párovaný_index'] = léčení.apply(
    lambda row: najdi_pár(row['propensity_skóre'], 1, data), axis=1)

# Vytvoření párovaného datasetu
kontrolní_páry = data.loc[léčení['párovaný_index']]
párovaná_data = pd.concat([léčení, kontrolní_páry.reset_index(drop=True)], axis=0)

# Výpočet efektu léčby na párovaných datech
párovaný_efekt = (párovaná_data[párovaná_data['léčba'] == 1]['výsledek'].mean() - 
                  párovaná_data[párovaná_data['léčba'] == 0]['výsledek'].mean())

print(f"Párovaný efekt léčby: {párovaný_efekt:.2f}")
print(f"Skutečný efekt léčby (z generování dat): 10.00")

# Vizualizace distribuce propensity skóre před a po párování
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))

# Před párováním
sns.histplot(data=data, x='propensity_skóre', hue='léčba', bins=30, alpha=0.6, ax=ax1)
ax1.set_title('Distribuce propensity skóre (před párováním)')
ax1.set_xlabel('Propensity skóre')

# Po párování
sns.histplot(data=párovaná_data, x='propensity_skóre', hue='léčba', bins=30, alpha=0.6, ax=ax2)
ax2.set_title('Distribuce propensity skóre (po párování)')
ax2.set_xlabel('Propensity skóre')

plt.tight_layout()
plt.show()
```

## Analýza rozdílů v rozdílech

Difference-in-Differences (DiD) je kvazi-experimentální metoda, která porovnává změny ve výsledcích v čase mezi skupinou léčby a kontrolní skupinou.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from statsmodels.formula.api import ols

# Vytvoření simulovaných panelových dat
np.random.seed(123)

# Parametry
n_léčba = 100  # Počet jednotek v léčené skupině
n_kontrola = 100  # Počet jednotek v kontrolní skupině
pre_periods = 3  # Počet období před léčbou
post_periods = 3  # Počet období po léčbě
efekt_léčby = 5  # Skutečný efekt léčby

# Generování dat
data = []

for i in range(n_léčba + n_kontrola):
    je_léčen = i < n_léčba
    efekt_jednotky = np.random.normal(0, 2)  # Náhodný fixní efekt jednotky
    
    for t in range(pre_periods + post_periods):
        časový_efekt = t * 1.5  # Časový trend
        post = t >= pre_periods  # Indikátor období po léčbě
        
        # Generování výsledné proměnné
        # Y = efekt jednotky + časový efekt + (efekt léčby pokud je léčena a je po-období) + šum
        výsledek = efekt_jednotky + časový_efekt + (efekt_léčby * je_léčen * post) + np.random.normal(0, 3)
        
        data.append({
            'jednotka': i,
            'období': t,
            'léčena': je_léčen,
            'post': post,
            'výsledek': výsledek
        })

df = pd.DataFrame(data)

# Výpočet průměrů skupin podle období
průměry_podle_skupin_období = df.groupby(['léčena', 'post'])['výsledek'].mean().reset_index()
průměry_podle_skupin_období['skupina'] = průměry_podle_skupin_období['léčena'].map({True: 'Léčba', False: 'Kontrola'})
průměry_podle_skupin_období['čas'] = průměry_podle_skupin_období['post'].map({True: 'Po', False: 'Před'})

# Tisk průměrů
print("Průměry skupin podle období:")
print(průměry_podle_skupin_období)

# Výpočet DiD odhadu ručně
léčba_před = průměry_podle_skupin_období[(průměry_podle_skupin_období['léčena'] == True) & 
                                 (průměry_podle_skupin_období['post'] == False)]['výsledek'].values[0]
léčba_po = průměry_podle_skupin_období[(průměry_podle_skupin_období['léčena'] == True) & 
                                  (průměry_podle_skupin_období['post'] == True)]['výsledek'].values[0]
kontrola_před = průměry_podle_skupin_období[(průměry_podle_skupin_období['léčena'] == False) & 
                                 (průměry_podle_skupin_období['post'] == False)]['výsledek'].values[0]
kontrola_po = průměry_podle_skupin_období[(průměry_podle_skupin_období['léčena'] == False) & 
                                  (průměry_podle_skupin_období['post'] == True)]['výsledek'].values[0]

did_odhad = (léčba_po - léčba_před) - (kontrola_po - kontrola_před)

print(f"\nOdhad Difference-in-Differences: {did_odhad:.2f}")
print(f"Skutečný efekt léčby: {efekt_léčby:.2f}")

# Spuštění DiD regrese
df['léčena_post'] = df['léčena'] * df['post']  # Interakční člen
did_model = ols('výsledek ~ léčena + post + léčena_post', data=df).fit()
print("\nVýsledky regrese:")
print(did_model.summary().tables[1])

# Vytvoření vizualizace
plt.figure(figsize=(10, 6))

# Přeformátování dat pro vizualizaci
plot_data = df.groupby(['léčena', 'období'])['výsledek'].mean().reset_index()
plot_data['skupina'] = plot_data['léčena'].map({True: 'Léčba', False: 'Kontrola'})

# Graf
sns.lineplot(data=plot_data, x='období', y='výsledek', hue='skupina', marker='o')

# Přidání svislé čáry v čase léčby
plt.axvline(x=pre_periods-0.5, color='red', linestyle='--', alpha=0.5)
plt.text(pre_periods-0.5, plot_data['výsledek'].min(), 'Léčba', rotation=90, verticalalignment='bottom')

plt.title('Vizualizace Difference-in-Differences')
plt.xlabel('Časové období')
plt.ylabel('Výsledek')
plt.grid(True, alpha=0.3)
plt.show()
```

## Instrumentální proměnné

Odhad instrumentálních proměnných (IV) lze použít, když není možná přímá úprava pro confounding, ale existuje proměnná (nástroj), která ovlivňuje léčbu, ale ne přímo výsledek.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.linear_model import LinearRegression

# Nastavení random seed
np.random.seed(42)
n = 5000

# Generování dat s nepozorovaným confoundingem
# U = nepozorovaný confounder
u = np.random.normal(0, 1, n)

# Z = nástroj (ovlivňuje léčbu, ale ne přímo výsledek)
z = np.random.binomial(1, 0.5, n)

# X = léčba (ovlivněná Z a U)
x = 0.5 * z + 0.5 * u + np.random.normal(0, 1, n)

# Y = výsledek (ovlivněný X a U)
skutečný_efekt = 1.5  # Skutečný kauzální efekt X na Y
y = skutečný_efekt * x + 2 * u + np.random.normal(0, 1, n)

# Vytvoření dataframe
data = pd.DataFrame({
    'z': z,  # Nástroj
    'x': x,  # Léčba
    'y': y   # Výsledek
    # Poznámka: U je nepozorované v reálných podmínkách
})

# 1. OLS odhad (zkreslený kvůli nepozorovanému confoundingu)
X = sm.add_constant(data['x'])
ols_model = sm.OLS(data['y'], X).fit()

# 2. Two-Stage Least Squares (2SLS) odhad
# První fáze: Regrese léčby na nástroj
X_první = sm.add_constant(data['z'])
první_fáze = sm.OLS(data['x'], X_první).fit()
x_predikované = první_fáze.predict()

# Druhá fáze: Regrese výsledku na predikovanou léčbu
X_druhá = sm.add_constant(x_predikované)
druhá_fáze = sm.OLS(data['y'], X_druhá).fit()

print("OLS odhad (zkreslený):", round(ols_model.params[1], 2))
print("IV/2SLS odhad:", round(druhá_fáze.params[1], 2))
print("Skutečný kauzální efekt:", skutečný_efekt)

# Vizualizace vztahu mezi nástrojem, léčbou a výsledkem
fig, axes = plt.subplots(1, 3, figsize=(18, 5))

# Nástroj -> Léčba
sns.regplot(x='z', y='x', data=data, ax=axes[0], scatter_kws={'alpha':0.1})
axes[0].set_title('První fáze: Nástroj → Léčba')
axes[0].set_xlabel('Nástroj (Z)')
axes[0].set_ylabel('Léčba (X)')

# Léčba -> Výsledek (OLS, zkreslený)
sns.regplot(x='x', y='y', data=data, ax=axes[1], scatter_kws={'alpha':0.1})
axes[1].set_title('OLS: Léčba → Výsledek (Zkreslený)')
axes[1].set_xlabel('Léčba (X)')
axes[1].set_ylabel('Výsledek (Y)')

# Predikovaná léčba -> Výsledek (IV)
sns.regplot(x=x_predikované, y=data['y'], ax=axes[2], scatter_kws={'alpha':0.1})
axes[2].set_title('IV: Predikovaná léčba → Výsledek')
axes[2].set_xlabel('Predikovaná léčba (X̂)')
axes[2].set_ylabel('Výsledek (Y)')

plt.tight_layout()
plt.show()

# Kontrola platnosti nástroje
print("\nRelevance nástroje (F-statistika první fáze):")
print(f"F-statistika: {první_fáze.fvalue:.2f}, p-hodnota: {první_fáze.f_pvalue:.6f}")
print("Vysoká F-statistika (>10) indikuje silný nástroj.")
```

## Design regresní diskontinuity

Design regresní diskontinuity (RDD) využívá situace, kdy je přiřazení léčby určeno hraniční hodnotou spojité proměnné.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import statsmodels.api as sm
import statsmodels.formula.api as smf

# Nastavení random seed
np.random.seed(42)
n = 2000

# Generování běžící proměnné (např. testové skóre)
běžící_prom = np.random.normal(50, 15, n)

# Léčba je přiřazena, pokud běžící proměnná překročí hraniční hodnotu
hranice = 50
léčba = (běžící_prom >= hranice).astype(int)

# Generování výsledku s efektem léčby 10
efekt_léčby = 10
šum = np.random.normal(0, 10, n)
výsledek = 30 + 0.5 * běžící_prom + efekt_léčby * léčba + šum

# Vytvoření dataframe
data = pd.DataFrame({
    'běžící_prom': běžící_prom,
    'léčba': léčba,
    'výsledek': výsledek
})

# Přidání centrované běžící proměnné pro snadnější interpretaci
data['centrovaná_bp'] = data['běžící_prom'] - hranice

# Vytvoření kategorií pro vizualizaci
```

### Knihovna DoWhy

```python
# pip install dowhy

import dowhy
from dowhy import CausalModel
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Generování syntetických dat
np.random.seed(123)
size = 2000
x = np.random.normal(size=size)
z = np.random.normal(size=size)
# Léčba částečně určena confounderem z
léčba = 0.5 * z + np.random.normal(size=size) > 0
# Výsledek ovlivněný jak léčbou, tak confounderem
y = 2 * léčba + 0.8 * z + np.random.normal(size=size)

# Vytvoření DataFrame
data = pd.DataFrame({'x': x, 'z': z, 'léčba': léčba.astype(int), 'y': y})

# Vytvoření kauzálního modelu pomocí DoWhy
model = CausalModel(
    data=data,
    treatment='léčba',
    outcome='y',
    common_causes=['z'],
    instruments=['x'] # Pro demonstraci, ačkoli x není zde platným nástrojem
)

# 1. Modelování kauzálních vztahů pomocí grafů
model.view_model()

# 2. Identifikace kauzálního efektu
identified_estimand = model.identify_effect(proceed_when_unidentifiable=True)
print(identified_estimand)

# 3. Odhad kauzálního efektu pomocí různých metod
causal_estimate = model.estimate_effect(identified_estimand,
                                       method_name="backdoor.linear_regression")
print("Kauzální odhad (lineární regrese):", causal_estimate.value)

causal_estimate = model.estimate_effect(identified_estimand,
                                       method_name="backdoor.propensity_score_matching")
print("Kauzální odhad (párování pomocí propensity skóre):", causal_estimate.value)

# 4. Zpochybnění získaného odhadu
refute_random = model.refute_estimate(identified_estimand, causal_estimate,
                                     method_name="random_common_cause")
print("Zpochybnění s náhodným společným příčinou:", refute_random)

refute_subset = model.refute_estimate(identified_estimand, causal_estimate,
                                    method_name="data_subset_refuter", 
                                    subset_fraction=0.8)
print("Zpochybnění s podmnožinou dat:", refute_subset)
```

## A/B testování a kauzální inference

A/B testování (randomizované kontrolované experimenty) je zlatým standardem pro kauzální inferenci v online prostředí.

```python
import numpy as np
import pandas as pd
import scipy.stats as stats
import matplotlib.pyplot as plt
import seaborn as sns

# Funkce pro simulaci A/B testu
def simuluj_ab_test(n_kontrola, n_léčba, konverzní_míra_kontrola, efekt_léčby, random_seed=None):
    """
    Simuluje A/B test s binárním výsledkem (např. konverze)
    
    Parametry:
    -----------
    n_kontrola: Počet uživatelů v kontrolní skupině
    n_léčba: Počet uživatelů v léčené skupině
    konverzní_míra_kontrola: Konverzní míra v kontrolní skupině
    efekt_léčby: Absolutní nárůst konverzní míry pro léčbu
    random_seed: Random seed pro reprodukovatelnost
    
    Vrací:
    --------
    pandas DataFrame s výsledky simulace
    """
    if random_seed is not None:
        np.random.seed(random_seed)
    
    # Generování dat pro kontrolní skupinu
    kontrolní_data = pd.DataFrame({
        'skupina': 'kontrola',
        'konvertováno': np.random.binomial(1, konverzní_míra_kontrola, size=n_kontrola)
    })
    
    # Generování dat pro léčenou skupinu
    léčená_data = pd.DataFrame({
        'skupina': 'léčba',
        'konvertováno': np.random.binomial(1, konverzní_míra_kontrola + efekt_léčby, size=n_léčba)
    })
    
    # Kombinace datasetů
    return pd.concat([kontrolní_data, léčená_data], ignore_index=True)

# Simulace A/B testu
ab_data = simuluj_ab_test(
    n_kontrola=5000,
    n_léčba=5000,
    konverzní_míra_kontrola=0.10,  # 10% základní konverze
    efekt_léčby=0.02,   # 2 procentní body nárůst
    random_seed=42
)

# Analýza výsledků
výsledky = ab_data.groupby('skupina').agg(
    konverzní_míra=('konvertováno', 'mean'),
    počet_uživatelů=('konvertováno', 'count'),
    počet_konverzí=('konvertováno', 'sum')
).reset_index()

print("Výsledky A/B testu:")
print(výsledky)

# Výpočet nárůstu a statistické významnosti
kontrolní_míra = výsledky[výsledky['skupina'] == 'kontrola']['konverzní_míra'].values[0]
léčba_míra = výsledky[výsledky['skupina'] == 'léčba']['konverzní_míra'].values[0]
relativní_nárůst = (léčba_míra - kontrolní_míra) / kontrolní_míra * 100

# Chí-kvadrát test nezávislosti
chi2, p_hodnota, _, _ = stats.chi2_contingency([
    [výsledky[výsledky['skupina'] == 'kontrola']['počet_konverzí'].values[0],
     výsledky[výsledky['skupina'] == 'kontrola']['počet_uživatelů'].values[0] - výsledky[výsledky['skupina'] == 'kontrola']['počet_konverzí'].values[0]],
    [výsledky[výsledky['skupina'] == 'léčba']['počet_konverzí'].values[0],
     výsledky[výsledky['skupina'] == 'léčba']['počet_uživatelů'].values[0] - výsledky[výsledky['skupina'] == 'léčba']['počet_konverzí'].values[0]]
])

print(f"\nAbsolutní nárůst: {léčba_míra - kontrolní_míra:.4f}")
print(f"Relativní nárůst: {relativní_nárůst:.2f}%")
print(f"p-hodnota: {p_hodnota:.6f}")
print(f"Statisticky významné na 5% hladině: {p_hodnota < 0.05}")

# Vizualizace výsledků
plt.figure(figsize=(10, 6))
sns.barplot(x='skupina', y='konverzní_míra', data=výsledky)
plt.title('Výsledky A/B testu: Konverzní míra podle skupiny')
plt.xlabel('Skupina')
plt.ylabel('Konverzní míra')

# Přidání anotací
for i, row in výsledky.iterrows():
    plt.text(i, row['konverzní_míra']/2, f"{row['konverzní_míra']:.1%}\nn={int(row['počet_uživatelů'])}", 
             ha='center', fontweight='bold', color='white')

plt.ylim(0, max(výsledky['konverzní_míra']) * 1.2)
plt.show()

# Analýza síly testu pro design A/B testu
from statsmodels.stats.power import TTestIndPower

def velikost_vzorku_ab_test(základní_míra, minimální_detekovatelný_efekt, alpha=0.05, power=0.8):
    """
    Výpočet požadované velikosti vzorku na skupinu pro A/B test
    
    Parametry:
    -----------
    základní_míra: Základní konverzní míra (kontrola)
    minimální_detekovatelný_efekt: Nejmenší smysluplný relativní efekt k detekci
    alpha: Hladina významnosti
    power: Požadovaná statistická síla
    
    Vrací:
    --------
    Požadovaná velikost vzorku na skupinu
    """
    # Velikost efektu (Cohen's d) pro rozdíl proporcí
    p1 = základní_míra
    p2 = základní_míra * (1 + minimální_detekovatelný_efekt)
    
    # Sdružený rozptyl
    pooled_var = p1 * (1 - p1) + p2 * (1 - p2)
    pooled_sd = np.sqrt(pooled_var / 2)
    
    # Cohen's d
    effect_size = abs(p2 - p1) / pooled_sd
    
    # Výpočet velikosti vzorku
    power_analysis = TTestIndPower()
    sample_size = power_analysis.solve_power(
        effect_size=effect_size,
        power=power,
        alpha=alpha,
        ratio=1.0  # Stejně velké skupiny
    )
    
    return int(np.ceil(sample_size))

# Výpočet požadované velikosti vzorku pro různé velikosti efektu
velikosti_efektu = [0.01, 0.02, 0.05, 0.10]  # 1%, 2%, 5%, 10% relativní nárůsty
základní = 0.10  # 10% základní konverze

for efekt in velikosti_efektu:
    velikost_vzorku = velikost_vzorku_ab_test(základní, efekt)
    print(f"Pro detekci {efekt*100:.1f}% relativního nárůstu z {základní:.1%} základu, " 
          f"potřebujeme {velikost_vzorku:,} uživatelů na skupinu")
```

## Shrnutí a osvědčené postupy

Metody kauzální inference umožňují datovým vědcům překročit korelaci a porozumět vztahům příčin a následků, což je klíčové pro informované rozhodování a návrh efektivních intervencí.

### Klíčové poznatky:

1. **Korelace není kauzalita**: Statistická souvislost neznamená kauzální vztahy.

2. **Kauzální rámce jsou důležité**: Jasná specifikace kauzálních otázek a předpokladů pomocí nástrojů jako jsou DAGs pomáhá vyhnout se metodologickým chybám.

3. **Randomizované experimenty** jsou zlatým standardem pro kauzální inferenci, ale často nejsou proveditelné.

4. **Observační metody** jako párování, difference-in-differences, RDD a instrumentální proměnné mohou poskytovat kauzální poznatky, když experimenty nejsou možné.

5. **Vícero metod**: Použití několika komplementárních přístupů kauzální inference posiluje platnost závěrů.

6. **Specializované nástroje**: Python knihovny jako DoWhy, EconML a CausalML poskytují implementace metod kauzální inference.

7. **Analýza citlivosti**: Vždy testujte, jak citlivé jsou vaše závěry na netestovatelné předpoklady.

8. **Doménová znalost** je zásadní pro kauzální inferenci - čistě datově řízené přístupy jsou nedostatečné.

### Osvědčené postupy:

1. **Jasně definujte** kauzální otázku a hypotetizované mechanismy.
2. **Kreslete a analyzujte** kauzální grafy k identifikaci confounderů a vhodných strategií úpravy.
3. **Kontrolujte předpoklady** zvolené metody a provádějte analýzy citlivosti.
4. **Používejte více metod**, když je to možné, pro ověření konzistence výsledků.
5. **Uvádějte nejistotu** v kauzálních odhadech pomocí intervalů spolehlivosti.
6. **Buďte transparentní** ohledně omezení a netestovatelných předpokladů.
7. **Kombinujte** doménovou expertízu s datovou analýzou pro robustnější závěry.

Kauzální inference překlenuje mezeru mezi prediktivními modely a akčním rozhodováním, což umožňuje datovým vědcům odpovídat na otázky "co kdyby", které jsou klíčové pro politická a obchodní rozhodnutí.
