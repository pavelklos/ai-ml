## Úvod do statistické analýzy v SciPy

Modul `scipy.stats` poskytuje širokou škálu statistických nástrojů pro analýzu dat. Zahrnuje funkce pro popisnou statistiku, pravděpodobnostní rozdělení, statistické testy a další. Tento modul je nezbytný pro datové vědce, kteří potřebují získat smysluplné poznatky z dat pomocí statistické analýzy.

```python
# Import potřebných knihoven
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
import warnings

# Nastavení stylu grafů a ignorování varování pro čistší výstup
plt.style.use('seaborn-v0_8-whitegrid')
warnings.filterwarnings('ignore')

# Vytvoření vzorového datového souboru
np.random.seed(42)
sample_data = np.random.normal(loc=50, scale=10, size=1000)

# Základní informace o scipy.stats
print(f"Verze SciPy: {stats.__version__}")
print(f"Počet rozdělení v scipy.stats: {len([dist for dist in dir(stats) if isinstance(getattr(stats, dist), stats._distn_infrastructure.rv_frozen)])}")

# Rychlá vizualizace našich vzorových dat
plt.figure(figsize=(10, 6))
plt.hist(sample_data, bins=30, alpha=0.7, color='skyblue', edgecolor='black')
plt.title('Vzorová data s normálním rozdělením')
plt.xlabel('Hodnota')
plt.ylabel('Četnost')
plt.grid(True, alpha=0.3)
plt.show()
```

## Funkce popisné statistiky

Popisná statistika pomáhá shrnout a popsat hlavní charakteristiky datového souboru. Modul `scipy.stats` poskytuje různé funkce pro výpočet měr centrální tendence, rozptýlení a tvaru rozdělení.

```python
# Generování vzorových dat z různých rozdělení
np.random.seed(42)
normal_data = np.random.normal(loc=50, scale=10, size=1000)
skewed_data = np.random.exponential(scale=5, size=1000)
bimodal_data = np.concatenate([
    np.random.normal(loc=40, scale=5, size=500),
    np.random.normal(loc=70, scale=8, size=500)
])

# Výpočet popisných statistik pomocí scipy.stats
def calculate_stats(data, name):
    results = {
        'Název': name,
        'Průměr': stats.tmean(data),
        'Medián': stats.median_abs_deviation(data),
        'Modus': stats.mode(data).mode[0],
        'Směr. odchylka': stats.tstd(data),
        'Rozptyl': stats.tvar(data),
        'Šikmost': stats.skew(data),
        'Špičatost': stats.kurtosis(data),
        'Rozsah': np.ptp(data),
        'Minimum': np.min(data),
        'Maximum': np.max(data),
        'Q1': stats.scoreatpercentile(data, 25),
        'Q3': stats.scoreatpercentile(data, 75),
        'IQR': stats.iqr(data)
    }
    return results

# Vytvoření DataFrame se statistikami
stats_df = pd.DataFrame([
    calculate_stats(normal_data, 'Normální'),
    calculate_stats(skewed_data, 'Zešikmené'),
    calculate_stats(bimodal_data, 'Bimodální')
])

print(stats_df.round(3).T)  # Transpozice pro lepší čitelnost

# Vizualizace rozdělení
plt.figure(figsize=(15, 5))

plt.subplot(1, 3, 1)
sns.histplot(normal_data, kde=True, color='blue')
plt.title('Normální rozdělení')

plt.subplot(1, 3, 2)
sns.histplot(skewed_data, kde=True, color='green')
plt.title('Zešikmené rozdělení')

plt.subplot(1, 3, 3)
sns.histplot(bimodal_data, kde=True, color='red')
plt.title('Bimodální rozdělení')

plt.tight_layout()
plt.show()

# Krabicové grafy pro porovnání rozdělení
plt.figure(figsize=(10, 6))
plt.boxplot([normal_data, skewed_data, bimodal_data], 
            labels=['Normální', 'Zešikmené', 'Bimodální'],
            patch_artist=True,
            boxprops=dict(facecolor='skyblue'))
plt.title('Porovnání rozdělení pomocí krabicových grafů')
plt.grid(True, alpha=0.3)
plt.show()
```

## Pravděpodobnostní rozdělení

SciPy poskytuje komplexní sadu pravděpodobnostních rozdělení spolu s metodami pro generování vzorků z těchto rozdělení a výpočet jejich statistických vlastností. Pochopení těchto rozdělení je klíčové pro statistické modelování a testování hypotéz.

```python
# Zkoumání běžných pravděpodobnostních rozdělení v scipy.stats
distributions = {
    'Normální': stats.norm,
    'Studentovo t': stats.t(df=5),
    'Chí-kvadrát': stats.chi2(df=5),
    'Exponenciální': stats.expon,
    'Beta': stats.beta(a=2, b=5),
    'Gamma': stats.gamma(a=2),
    'Rovnoměrné': stats.uniform,
    'Poissonovo': stats.poisson(mu=5)
}

# Generování hodnot x pro vykreslení
x = np.linspace(-5, 15, 1000)

# Vykreslení PDF (funkce hustoty pravděpodobnosti) pro spojitá rozdělení
plt.figure(figsize=(15, 10))
for i, (name, dist) in enumerate(distributions.items()):
    if name != 'Poissonovo':  # Poissonovo rozdělení je diskrétní
        plt.subplot(3, 3, i+1)
        try:
            plt.plot(x, dist.pdf(x), label=f'{name} PDF')
            plt.fill_between(x, dist.pdf(x), alpha=0.2)
        except:
            # Pro rozdělení, která nepodporují určité hodnoty x
            valid_x = x[x > 0] if name in ['Chí-kvadrát', 'Exponenciální', 'Gamma'] else x
            plt.plot(valid_x, dist.pdf(valid_x), label=f'{name} PDF')
            plt.fill_between(valid_x, dist.pdf(valid_x), alpha=0.2)
        plt.title(name)
        plt.grid(True, alpha=0.3)

# Pro Poissonovo rozdělení (diskrétní)
plt.subplot(3, 3, 8)
x_discrete = np.arange(0, 20)
plt.stem(x_discrete, distributions['Poissonovo'].pmf(x_discrete), label='Poisson PMF', basefmt=' ')
plt.title('Poissonovo')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Generování náhodných vzorků z rozdělení
sample_size = 1000
samples = {name: dist.rvs(size=sample_size) for name, dist in distributions.items()}

# Vizualizace vzorků z různých rozdělení
plt.figure(figsize=(15, 10))
for i, (name, sample) in enumerate(samples.items()):
    plt.subplot(3, 3, i+1)
    sns.histplot(sample, kde=True)
    plt.title(f'{name} vzorky')
    plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Práce s konkrétním rozdělením - Normální rozdělení
mu, sigma = 100, 15
dist = stats.norm(loc=mu, scale=sigma)

# Generování vzorků
normal_samples = dist.rvs(size=1000)

# Výpočet hodnot PDF a CDF
x_range = np.linspace(mu - 4*sigma, mu + 4*sigma, 1000)
pdf_values = dist.pdf(x_range)
cdf_values = dist.cdf(x_range)

# Výpočet statistických vlastností
print(f"Střední hodnota: {dist.mean()}")
print(f"Rozptyl: {dist.var()}")
print(f"Šikmost: {dist.stats(moments='s')}")
print(f"Špičatost: {dist.stats(moments='k')}")
print(f"Entropie: {dist.entropy()}")

# Percentilové body (inverzní CDF)
print(f"10. percentil: {dist.ppf(0.1)}")
print(f"50. percentil (medián): {dist.ppf(0.5)}")
print(f"90. percentil: {dist.ppf(0.9)}")

# Vykreslení PDF a CDF
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(x_range, pdf_values)
plt.fill_between(x_range, pdf_values, alpha=0.2)
plt.title('PDF normálního rozdělení')
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.plot(x_range, cdf_values)
plt.title('CDF normálního rozdělení')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Testování hypotéz

Testování hypotéz je statistická metoda používaná k vyvození závěrů o parametrech populace na základě vzorku dat. SciPy poskytuje různé testy k posouzení, zda jsou pozorované rozdíly statisticky významné.

```python
# Generování vzorových dat
np.random.seed(42)
group_a = np.random.normal(loc=50, scale=10, size=100)
group_b = np.random.normal(loc=53, scale=10, size=100)  # Mírně vyšší průměr
group_c = np.random.normal(loc=50, scale=15, size=100)  # Stejný průměr, ale vyšší variabilita

# 1. Jednovýběrový t-test
# Testování, zda se průměr group_a liší od 45
t_stat, p_val = stats.ttest_1samp(group_a, popmean=45)
print("Jednovýběrový t-test:")
print(f"t-statistika: {t_stat:.4f}")
print(f"p-hodnota: {p_val:.4f}")
print(f"Závěr: {'Zamítáme' if p_val < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 2. Dvouvýběrový t-test
# Testování, zda se průměry group_a a group_b liší
t_stat, p_val = stats.ttest_ind(group_a, group_b)
print("Dvouvýběrový t-test (group_a vs group_b):")
print(f"t-statistika: {t_stat:.4f}")
print(f"p-hodnota: {p_val:.4f}")
print(f"Závěr: {'Zamítáme' if p_val < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 3. Dvouvýběrový t-test s nestejnými rozptyly
# Testování, zda se průměry group_a a group_c liší
t_stat, p_val = stats.ttest_ind(group_a, group_c, equal_var=False)
print("Welchův t-test (nestejné rozptyly, group_a vs group_c):")
print(f"t-statistika: {t_stat:.4f}")
print(f"p-hodnota: {p_val:.4f}")
print(f"Závěr: {'Zamítáme' if p_val < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 4. Párový t-test
# Simulace měření před a po určité intervenci
before = np.random.normal(loc=25, scale=5, size=50)
after = before + np.random.normal(loc=2, scale=3, size=50)  # Po intervenci s malým efektem

t_stat, p_val = stats.ttest_rel(before, after)
print("Párový t-test (před vs po):")
print(f"t-statistika: {t_stat:.4f}")
print(f"p-hodnota: {p_val:.4f}")
print(f"Závěr: {'Zamítáme' if p_val < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 5. Chí-kvadrát test nezávislosti
# Kontingenční tabulka
observed = np.array([[30, 15, 5], 
                    [20, 20, 10]])
chi2, p_val, dof, expected = stats.chi2_contingency(observed)
print("Chí-kvadrát test nezávislosti:")
print(f"chi2 hodnota: {chi2:.4f}")
print(f"p-hodnota: {p_val:.4f}")
print(f"Stupně volnosti: {dof}")
print("Očekávané četnosti:")
print(expected)
print(f"Závěr: {'Zamítáme' if p_val < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 6. Shapiro-Wilk test normality
stat, p_val = stats.shapiro(group_a)
print("Shapiro-Wilk test normality (group_a):")
print(f"Testová statistika: {stat:.4f}")
print(f"p-hodnota: {p_val:.4f}")
print(f"Závěr: {'Data nemají normální rozdělení' if p_val < 0.05 else 'Data se jeví jako normálně rozdělená'}")

# Vizualizace výsledků
plt.figure(figsize=(15, 5))

# Vizualizace t-testu
plt.subplot(1, 3, 1)
sns.histplot(group_a, color='blue', alpha=0.5, kde=True, label='Skupina A')
sns.histplot(group_b, color='red', alpha=0.5, kde=True, label='Skupina B')
plt.title('Dvouvýběrový t-test')
plt.legend()

# Vizualizace párového t-testu
plt.subplot(1, 3, 2)
plt.scatter(before, after, alpha=0.5)
plt.plot([min(before), max(before)], [min(before), max(before)], 'r--')  # Přímka y=x
plt.title('Párový t-test')
plt.xlabel('Před')
plt.ylabel('Po')

# Vizualizace chí-kvadrát testu
plt.subplot(1, 3, 3)
sns.heatmap(observed, annot=True, fmt='d', cmap='Blues')
plt.title('Chí-kvadrát test\nPozorované četnosti')

plt.tight_layout()
plt.show()
```

## Korelační a regresní analýza

Korelační a regresní analýza nám pomáhá porozumět vztahům mezi proměnnými. `scipy.stats` poskytuje funkce pro výpočet korelačních koeficientů a provádění lineární regrese.

```python
# Generování syntetických dat s korelací
np.random.seed(42)
x = np.random.uniform(0, 10, 100)
noise = np.random.normal(0, 2, 100)

# Vytvoření tří různých vztahů
y_linear = 2 * x + 5 + noise  # Lineární vztah
y_quadratic = x**2 + noise    # Kvadratický vztah
y_uncorrelated = np.random.uniform(0, 20, 100)  # Nekorelovaná data

# Výpočet Pearsonova korelačního koeficientu
pearson_r, p_value = stats.pearsonr(x, y_linear)
print(f"Pearsonova korelace (lineární): r = {pearson_r:.4f}, p-hodnota = {p_value:.4f}")

pearson_r, p_value = stats.pearsonr(x, y_quadratic)
print(f"Pearsonova korelace (kvadratická): r = {pearson_r:.4f}, p-hodnota = {p_value:.4f}")

pearson_r, p_value = stats.pearsonr(x, y_uncorrelated)
print(f"Pearsonova korelace (nekorelovaná): r = {pearson_r:.4f}, p-hodnota = {p_value:.4f}")

# Výpočet Spearmanova korelačního koeficientu pořadí
spearman_r, p_value = stats.spearmanr(x, y_linear)
print(f"Spearmanova korelace (lineární): r = {spearman_r:.4f}, p-hodnota = {p_value:.4f}")

spearman_r, p_value = stats.spearmanr(x, y_quadratic)
print(f"Spearmanova korelace (kvadratická): r = {spearman_r:.4f}, p-hodnota = {p_value:.4f}")

# Lineární regrese s scipy.stats
slope, intercept, r_value, p_value, std_err = stats.linregress(x, y_linear)
print("\nVýsledky lineární regrese:")
print(f"Směrnice: {slope:.4f}")
print(f"Úsek: {intercept:.4f}")
print(f"R-kvadrát: {r_value**2:.4f}")
print(f"P-hodnota: {p_value:.4f}")
print(f"Standardní chyba: {std_err:.4f}")

# Vytvoření funkce pro predikované hodnoty
def linear_func(x, slope=slope, intercept=intercept):
    return slope * x + intercept

# Vizualizace dat a regresní přímky
plt.figure(figsize=(15, 5))

# Lineární vztah
plt.subplot(1, 3, 1)
plt.scatter(x, y_linear, alpha=0.7)
x_line = np.linspace(0, 10, 100)
y_pred = linear_func(x_line)
plt.plot(x_line, y_pred, 'r--')
plt.title(f'Lineární vztah\nR-kvadrát: {r_value**2:.4f}')
plt.xlabel('x')
plt.ylabel('y')
plt.grid(True, alpha=0.3)

# Kvadratický vztah
plt.subplot(1, 3, 2)
plt.scatter(x, y_quadratic, alpha=0.7)
plt.title('Kvadratický vztah\nPearsonovo r nemůže plně zachytit')
plt.xlabel('x')
plt.ylabel('y')
plt.grid(True, alpha=0.3)

# Nekorelovaná data
plt.subplot(1, 3, 3)
plt.scatter(x, y_uncorrelated, alpha=0.7)
plt.title('Nekorelovaná data')
plt.xlabel('x')
plt.ylabel('y')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Korelační matice - teplotní mapa
data = np.column_stack((x, y_linear, y_quadratic, y_uncorrelated))
df = pd.DataFrame(data, columns=['x', 'y_linear', 'y_quadratic', 'y_uncorrelated'])
corr_matrix = df.corr()

plt.figure(figsize=(8, 6))
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', vmin=-1, vmax=1)
plt.title('Korelační matice')
plt.show()
```

## Neparametrické testy

Neparametrické testy jsou užitečné, když data nesplňují předpoklady požadované pro parametrické testy, jako je normalita. SciPy poskytuje různé neparametrické testy pro různé scénáře.

```python
# Generování vzorků dat s různými rozděleními
np.random.seed(42)
normal_sample = np.random.normal(loc=50, scale=10, size=100)
skewed_sample = np.random.exponential(scale=10, size=100)
uniform_sample = np.random.uniform(30, 70, size=100)

# Vytvoření dvou skupin s různými rozděleními
group1 = np.random.normal(loc=50, scale=10, size=50)
group2 = np.random.normal(loc=55, scale=10, size=60)  # Odlišný průměr
group3 = np.random.normal(loc=50, scale=15, size=40)  # Stejný průměr, ale odlišný rozptyl

# 1. Mann-Whitney U test (neparametrická alternativa k t-testu)
u_stat, p_value = stats.mannwhitneyu(group1, group2)
print("Mann-Whitney U test (group1 vs group2):")
print(f"U statistika: {u_stat:.4f}")
print(f"P-hodnota: {p_value:.4f}")
print(f"Závěr: {'Zamítáme' if p_value < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 2. Wilcoxonův znaménkový test (neparametrická alternativa k párovému t-testu)
# Simulace měření před a po
before = np.random.normal(25, 5, 30)
after = before + np.random.normal(2, 3, 30)  # Po intervenci s malým efektem

w_stat, p_value = stats.wilcoxon(before, after)
print("Wilcoxonův znaménkový test (před vs po):")
print(f"W statistika: {w_stat:.4f}")
print(f"P-hodnota: {p_value:.4f}")
print(f"Závěr: {'Zamítáme' if p_value < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 3. Kruskal-Wallis H test (neparametrická alternativa k ANOVA)
h_stat, p_value = stats.kruskal(group1, group2, group3)
print("Kruskal-Wallis H test (group1 vs group2 vs group3):")
print(f"H statistika: {h_stat:.4f}")
print(f"P-hodnota: {p_value:.4f}")
print(f"Závěr: {'Zamítáme' if p_value < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 4. Kolmogorov-Smirnov test normality
ks_stat, p_value = stats.kstest(normal_sample, 'norm', args=(np.mean(normal_sample), np.std(normal_sample)))
print("Kolmogorov-Smirnov test normality (normal_sample):")
print(f"KS statistika: {ks_stat:.4f}")
print(f"P-hodnota: {p_value:.4f}")
print(f"Závěr: {'Data nemají normální rozdělení' if p_value < 0.05 else 'Data se jeví jako normálně rozdělená'}")
print()

# 5. Kolmogorov-Smirnov test normality pro nenormální data
ks_stat, p_value = stats.kstest(skewed_sample, 'norm', args=(np.mean(skewed_sample), np.std(skewed_sample)))
print("Kolmogorov-Smirnov test normality (skewed_sample):")
print(f"KS statistika: {ks_stat:.4f}")
print(f"P-hodnota: {p_value:.4f}")
print(f"Závěr: {'Data nemají normální rozdělení' if p_value < 0.05 else 'Data se jeví jako normálně rozdělená'}")
print()

# 6. Kolmogorov-Smirnov test pro porovnání dvou vzorků
ks_stat, p_value = stats.ks_2samp(group1, group2)
print("Dvouvýběrový Kolmogorov-Smirnov test (group1 vs group2):")
print(f"KS statistika: {ks_stat:.4f}")
print(f"P-hodnota: {p_value:.4f}")
print(f"Závěr: {'Vzorky pocházejí z různých rozdělení' if p_value < 0.05 else 'Nelze zamítnout, že vzorky pocházejí ze stejného rozdělení'}")

# Vizualizace rozdělení
plt.figure(figsize=(15, 5))

plt.subplot(1, 3, 1)
sns.histplot(normal_sample, kde=True, color='blue', alpha=0.5)
sns.histplot(skewed_sample, kde=True, color='red', alpha=0.5)
plt.title('Normální vs. zešikmené')
plt.legend(['Normální', 'Zešikmené'])

plt.subplot(1, 3, 2)
sns.histplot(group1, kde=True, color='green', alpha=0.5)
sns.histplot(group2, kde=True, color='orange', alpha=0.5)
plt.title('Skupina1 vs Skupina2')
plt.legend(['Skupina1', 'Skupina2'])

plt.subplot(1, 3, 3)
sns.histplot(before, kde=True, color='purple', alpha=0.5)
sns.histplot(after, kde=True, color='pink', alpha=0.5)
plt.title('Před vs Po')
plt.legend(['Před', 'Po'])

plt.tight_layout()
plt.show()

# Vizualizace Q-Q grafů pro posouzení normality
plt.figure(figsize=(15, 5))

plt.subplot(1, 3, 1)
stats.probplot(normal_sample, dist="norm", plot=plt)
plt.title('Q-Q Graf: Normální vzorek')

plt.subplot(1, 3, 2)
stats.probplot(skewed_sample, dist="norm", plot=plt)
plt.title('Q-Q Graf: Zešikmený vzorek')

plt.subplot(1, 3, 3)
stats.probplot(uniform_sample, dist="norm", plot=plt)
plt.title('Q-Q Graf: Rovnoměrný vzorek')

plt.tight_layout()
plt.show()
```

## Analýza rozptylu (ANOVA)

Analýza rozptylu (ANOVA) se používá k určení, zda existují statisticky významné rozdíly mezi průměry tří nebo více nezávislých skupin. SciPy poskytuje funkce pro jednocestnou i vícecestnou ANOVA.

```python
# Generování dat pro tři skupiny
np.random.seed(42)
group_a = np.random.normal(loc=50, scale=5, size=30)
group_b = np.random.normal(loc=53, scale=5, size=30)  # Mírně odlišný průměr
group_c = np.random.normal(loc=48, scale=5, size=30)  # Mírně odlišný průměr

# Sloučení dat pro ANOVA
data = np.concatenate([group_a, group_b, group_c])
groups = np.repeat(['A', 'B', 'C'], [30, 30, 30])

# Vytvoření DataFrame pro snadnější manipulaci
df = pd.DataFrame({
    'hodnota': data,
    'skupina': groups
})

# 1. Jednocestná ANOVA pomocí scipy.stats.f_oneway
f_stat, p_value = stats.f_oneway(group_a, group_b, group_c)
print("Jednocestná ANOVA:")
print(f"F-statistika: {f_stat:.4f}")
print(f"p-hodnota: {p_value:.4f}")
print(f"Závěr: {'Zamítáme' if p_value < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 2. Provedení ANOVA s výrazně odlišným průměrem v jedné skupině
group_d = np.random.normal(loc=60, scale=5, size=30)  # Mnohem vyšší průměr
f_stat, p_value = stats.f_oneway(group_a, group_b, group_d)
print("Jednocestná ANOVA s výrazně odlišnými průměry:")
print(f"F-statistika: {f_stat:.4f}")
print(f"p-hodnota: {p_value:.4f}")
print(f"Závěr: {'Zamítáme' if p_value < 0.05 else 'Nezamítáme'} nulovou hypotézu")
print()

# 3. Post-hoc Tukeyho HSD test pomocí statsmodels
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# Přidání group_d do DataFrame
df_extended = pd.DataFrame({
    'hodnota': np.concatenate([group_a, group_b, group_c, group_d]),
    'skupina': np.repeat(['A', 'B', 'C', 'D'], [30, 30, 30, 30])
})

# Provedení Tukeyho testu
tukey = pairwise_tukeyhsd(df_extended['hodnota'], df_extended['skupina'], alpha=0.05)
print("Tukeyho HSD test:")
print(tukey)

# 4. Dvoufaktorová ANOVA pomocí statsmodels
from statsmodels.formula.api import ols
from statsmodels.stats.anova import anova_lm

# Vytvoření datasetu se dvěma faktory
np.random.seed(42)
n = 20
df_twoway = pd.DataFrame({
    'hodnota': np.random.normal(loc=50, scale=5, size=n*2*2),
    'faktor1': np.repeat(['úroveň1', 'úroveň2'], n*2),
    'faktor2': np.tile(np.repeat(['úroveň1', 'úroveň2'], n), 2)
})

# Přidání efektů
df_twoway.loc[df_twoway['faktor1'] == 'úroveň2', 'hodnota'] += 5  # Hlavní efekt faktoru1
df_twoway.loc[df_twoway['faktor2'] == 'úroveň2', 'hodnota'] += 3  # Hlavní efekt faktoru2
# Interakční efekt
df_twoway.loc[(df_twoway['faktor1'] == 'úroveň2') & 
              (df_twoway['faktor2'] == 'úroveň2'), 'hodnota'] += 2  

# Vytvoření modelu
model = ols('hodnota ~ C(faktor1) * C(faktor2)', data=df_twoway).fit()
anova_table = anova_lm(model, typ=2)

print("\nDvoufaktorová ANOVA:")
print(anova_table)

# Vizualizace dat
plt.figure(figsize=(15, 5))

# Krabicové grafy pro jednocestnou ANOVA
plt.subplot(1, 3, 1)
sns.boxplot(x='skupina', y='hodnota', data=df)
plt.title('Jednocestná ANOVA: Skupiny A, B, C')
plt.grid(True, alpha=0.3)

# Krabicové grafy s výrazně odlišnou skupinou
plt.subplot(1, 3, 2)
sns.boxplot(x='skupina', y='hodnota', data=df_extended)
plt.title('Jednocestná ANOVA: Skupiny A, B, C, D')
plt.grid(True, alpha=0.3)

# Interakční graf pro dvoufaktorovou ANOVA
plt.subplot(1, 3, 3)
sns.pointplot(x='faktor1', y='hodnota', hue='faktor2', data=df_twoway)
plt.title('Dvoufaktorová ANOVA: Interakční graf')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Intervaly spolehlivosti

Intervaly spolehlivosti poskytují rozmezí hodnot, ve kterém pravděpodobně leží skutečný parametr populace s určitou úrovní spolehlivosti. SciPy poskytuje funkce pro výpočet intervalů spolehlivosti pro různé statistiky.

```python
# Generování vzorových dat
np.random.seed(42)
sample = np.random.normal(loc=50, scale=10, size=100)

# Výpočet průměru a standardní chyby
mean = np.mean(sample)
std_err = stats.sem(sample)

# 1. Interval spolehlivosti pro průměr pomocí t-rozdělení
conf_level = 0.95
dof = len(sample) - 1  # stupně volnosti
t_crit = stats.t.ppf((1 + conf_level) / 2, dof)
ci_lower = mean - t_crit * std_err
ci_upper = mean + t_crit * std_err

print(f"{conf_level*100}% interval spolehlivosti pro průměr:")
print(f"Průměr vzorku: {mean:.4f}")
print(f"Standardní chyba: {std_err:.4f}")
print(f"Interval spolehlivosti: ({ci_lower:.4f}, {ci_upper:.4f})")
print()

# 2. Interval spolehlivosti pomocí bootstrapu
def bootstrap_ci(data, n_resamples=10000, conf_level=0.95):
    bootstrap_means = np.empty(n_resamples)
    n = len(data)
    for i in range(n_resamples):
        bootstrap_sample = np.random.choice(data, size=n, replace=True)
        bootstrap_means[i] = np.mean(bootstrap_sample)
    
    lower_percentile = (1 - conf_level) / 2 * 100
    upper_percentile = (1 + conf_level) / 2 * 100
    
    ci_lower = np.percentile(bootstrap_means, lower_percentile)
    ci_upper = np.percentile(bootstrap_means, upper_percentile)
    
    return ci_lower, ci_upper, bootstrap_means

ci_lower_boot, ci_upper_boot, bootstrap_means = bootstrap_ci(sample, conf_level=conf_level)

print(f"{conf_level*100}% bootstrap interval spolehlivosti pro průměr:")
print(f"Průměr vzorku: {mean:.4f}")
print(f"Bootstrap interval spolehlivosti: ({ci_lower_boot:.4f}, {ci_upper_boot:.4f})")
print()

# 3. Interval spolehlivosti pro rozptyl
chi2_lower = stats.chi2.ppf((1 - conf_level) / 2, dof)
chi2_upper = stats.chi2.ppf((1 + conf_level) / 2, dof)

var = np.var(sample, ddof=1)  # výběrový rozptyl
ci_var_lower = dof * var / chi2_upper
ci_var_upper = dof * var / chi2_lower

print(f"{conf_level*100}% interval spolehlivosti pro rozptyl:")
print(f"Výběrový rozptyl: {var:.4f}")
print(f"Interval spolehlivosti: ({ci_var_lower:.4f}, {ci_var_upper:.4f})")
print()

# 4. Interval spolehlivosti pro podíl
# Simulace binárního výsledku
binary_sample = np.random.binomial(1, 0.7, size=500)
p_hat = np.mean(binary_sample)
n = len(binary_sample)

# Použití normální aproximace
z_crit = stats.norm.ppf((1 + conf_level) / 2)
stderr_prop = np.sqrt(p_hat * (1 - p_hat) / n)

ci_prop_lower = p_hat - z_crit * stderr_prop
ci_prop_upper = p_hat + z_crit * stderr_prop

print(f"{conf_level*100}% interval spolehlivosti pro podíl:")
print(f"Výběrový podíl: {p_hat:.4f}")
print(f"Interval spolehlivosti: ({ci_prop_lower:.4f}, {ci_prop_upper:.4f})")

# Vizualizace intervalů spolehlivosti
plt.figure(figsize=(15, 10))

# Vizualizace intervalu spolehlivosti pro průměr
plt.subplot(2, 2, 1)
plt.hist(sample, bins=20, alpha=0.5, color='skyblue', density=True)
xmin, xmax = plt.xlim()
x = np.linspace(xmin, xmax, 100)
plt.plot(x, stats.norm.pdf(x, mean, np.std(sample, ddof=1)), 'r-')
plt.axvline(mean, color='red', linestyle='-', label=f'Průměr = {mean:.2f}')
plt.axvline(ci_lower, color='green', linestyle='--', label=f'Dolní IS = {ci_lower:.2f}')
plt.axvline(ci_upper, color='green', linestyle='--', label=f'Horní IS = {ci_upper:.2f}')
plt.title('Interval spolehlivosti pro průměr')
plt.legend()
plt.grid(True, alpha=0.3)

# Vizualizace bootstrap rozdělení
plt.subplot(2, 2, 2)
plt.hist(bootstrap_means, bins=50, alpha=0.7, color='lightgreen')
plt.axvline(mean, color='red', linestyle='-', label=f'Výběrový průměr = {mean:.2f}')
plt.axvline(ci_lower_boot, color='green', linestyle='--', label=f'Dolní IS = {ci_lower_boot:.2f}')
plt.axvline(ci_upper_boot, color='green', linestyle='--', label=f'Horní IS = {ci_upper_boot:.2f}')
plt.title('Bootstrap rozdělení průměrů')
plt.legend()
plt.grid(True, alpha=0.3)

# Vizualizace intervalu spolehlivosti pro rozptyl
plt.subplot(2, 2, 3)
x = np.linspace(0.5 * var, 2 * var, 1000)
chi2_pdf = stats.chi2.pdf(x * dof / var, dof)
plt.plot(x, chi2_pdf, 'b-')
plt.axvline(var, color='red', linestyle='-', label=f'Výběrový rozptyl = {var:.2f}')
plt.axvline(ci_var_lower, color='green', linestyle='--', label=f'Dolní IS = {ci_var_lower:.2f}')
plt.axvline(ci_var_upper, color='green', linestyle='--', label=f'Horní IS = {ci_var_upper:.2f}')
plt.title('Interval spolehlivosti pro rozptyl')
plt.legend()
plt.grid(True, alpha=0.3)

# Vizualizace intervalu spolehlivosti pro podíl
plt.subplot(2, 2, 4)
counts = np.bincount(binary_sample, minlength=2)
plt.bar(['0', '1'], counts, alpha=0.7, color='lightblue')
plt.axhline(p_hat * n, color='red', linestyle='-', label=f'p-hat = {p_hat:.2f}')
plt.title('Binární vzorek s podílem p-hat')
plt.ylabel('Počet')
plt.grid(True, alpha=0.3)
plt.legend()

plt.tight_layout()
plt.show()
```

## Práce s reálnými datovými soubory

Aplikace statistické analýzy na reálné datové soubory je klíčovou dovedností pro datové vědce. V této části použijeme SciPy k analýze reálného datasetu a interpretaci výsledků.

```python
# Načtení reálného datasetu (Iris dataset pro demonstraci)
from sklearn.datasets import load_iris

iris = load_iris()
iris_df = pd.DataFrame(data=iris.data, columns=iris.feature_names)
iris_df['druh'] = pd.Categorical.from_codes(iris.target, iris.target_names)

print("Prvních několik řádků datasetu Iris:")
print(iris_df.head())
print("\nInformace o datasetu:")
print(iris_df.info())
print("\nSouhrnné statistiky:")
print(iris_df.describe())

# 1. Základní statistická analýza
print("\nStatistická analýza podle druhu:")
grouped_stats = iris_df.groupby('druh').agg(['mean', 'std', 'min', 'max'])
print(grouped_stats)

# 2. Test normality
print("\nShapiro-Wilk test normality:")
for feature in iris.feature_names:
    stat, p = stats.shapiro(iris_df[feature])
    print(f"{feature}: p-hodnota = {p:.6f} - {'Není normální' if p < 0.05 else 'Normální'}")

# 3. ANOVA: Existují rozdíly v délce kališních lístků mezi druhy?
sepal_length_by_species = [
    iris_df[iris_df['druh'] == 'setosa']['sepal length (cm)'].values,
    iris_df[iris_df['druh'] == 'versicolor']['sepal length (cm)'].values,
    iris_df[iris_df['druh'] == 'virginica']['sepal length (cm)'].values
]

f_stat, p_value = stats.f_oneway(*sepal_length_by_species)
print("\nANOVA pro délku kališních lístků podle druhu:")
print(f"F-statistika: {f_stat:.4f}")
print(f"p-hodnota: {p_value:.8f}")
print("Závěr: Existují významné rozdíly v délce kališních lístků mezi druhy" if p_value < 0.05 
      else "Závěr: Nebyly zjištěny významné rozdíly")

# 4. Post-hoc test k identifikaci, které druhy se liší
posthoc = pairwise_tukeyhsd(
    iris_df['sepal length (cm)'], 
    iris_df['druh'],
    alpha=0.05
)
print("\nTukeyho HSD post-hoc test pro délku kališních lístků:")
print(posthoc)

# 5. Korelační analýza: jsou měření Iris korelovaná?
corr_matrix = iris_df.iloc[:, :-1].corr()
print("\nKorelační matice příznaků Iris:")
print(corr_matrix)

# 6. Testování signifikance korelací
print("\nTestování signifikance korelací (Pearson):")
for i, feature1 in enumerate(iris.feature_names):
    for j, feature2 in enumerate(iris.feature_names):
        if i < j:  # Vyhneme se duplicitním kombinacím a autokorelacím
            r, p = stats.pearsonr(iris_df[feature1], iris_df[feature2])
            print(f"{feature1} vs {feature2}: r = {r:.4f}, p-hodnota = {p:.8f}")

# 7. Analýza hlavních komponent (PCA)
from sklearn.decomposition import PCA

pca = PCA(n_components=2)
principal_components = pca.fit_transform(iris.data)
pca_df = pd.DataFrame(data=principal_components, columns=['PC1', 'PC2'])
pca_df['druh'] = iris_df['druh']

print("\nPCA - podíl vysvětlené variance:")
print(pca.explained_variance_ratio_)
print(f"Celková vysvětlená variance: {sum(pca.explained_variance_ratio_):.4f}")

# Vizualizace datasetu
plt.figure(figsize=(15, 10))

# 1. Krabicový graf délky kališních lístků podle druhu
plt.subplot(2, 2, 1)
sns.boxplot(x='druh', y='sepal length (cm)', data=iris_df)
plt.title('Délka kališních lístků podle druhu')
plt.grid(True, alpha=0.3)

# 2. Matice bodových grafů
plt.subplot(2, 2, 2)
pd.plotting.scatter_matrix(iris_df.iloc[:, :-1], diagonal='kde', figsize=(10, 10), alpha=0.8)
plt.tight_layout()

# 3. Teplotní mapa korelací
plt.subplot(2, 2, 3)
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm', linewidths=0.5)
plt.title('Korelační matice příznaků')

# 4. Vizualizace PCA
plt.subplot(2, 2, 4)
for species in iris.target_names:
    subset = pca_df[pca_df['druh'] == species]
    plt.scatter(subset['PC1'], subset['PC2'], label=species, alpha=0.8)
plt.title('PCA: První dvě hlavní komponenty')
plt.xlabel(f'PC1 ({pca.explained_variance_ratio_[0]:.2%} variance)')
plt.ylabel(f'PC2 ({pca.explained_variance_ratio_[1]:.2%} variance)')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Shrnutí

Statistická analýza s využitím knihovny `scipy.stats` je základní dovedností pro datové vědce. Tento modul nabízí komplexní sadu nástrojů pro provádění statistických výpočtů, od základní popisné statistiky až po pokročilé testování hypotéz a modelování.

Hlavní poznatky z tohoto tématu zahrnují:

1. **Popisná statistika**: `scipy.stats` poskytuje funkce pro shrnutí dat prostřednictvím měr centrální tendence, rozptýlení a tvaru.

2. **Pravděpodobnostní rozdělení**: Modul zahrnuje širokou škálu pravděpodobnostních rozdělení s metodami pro generování vzorků, výpočet pravděpodobností a další.

3. **Testování hypotéz**: K dispozici jsou různé statistické testy pro testování hypotéz o průměrech, rozptylech, podílech a vztazích mezi proměnnými.

4. **Korelační a regresní analýza**: Nástroje pro analýzu vztahů mezi proměnnými prostřednictvím korelačních koeficientů a lineární regrese.

5. **Neparametrické testy**: Alternativní testy, které nepředpokládají, že data sledují konkrétní rozdělení, užitečné, když nejsou splněny předpoklady pro parametrické testy.

6. **ANOVA**: Funkce pro porovnání průměrů napříč více skupinami a identifikaci statisticky významných rozdílů.

7. **Intervaly spolehlivosti**: Metody pro odhad rozmezí, ve kterém pravděpodobně leží populační parametry.

8. **Aplikace v reálném světě**: Aplikace statistických metod na skutečné datové soubory pomáhá vyvozovat smysluplné závěry a přijímat rozhodnutí založená na datech.

Zvládnutí těchto statistických konceptů a nástrojů je nezbytné pro provádění robustní datové analýzy, vyvozování platných závěrů a efektivní komunikaci výsledků. Modul `scipy.stats` poskytuje vynikající framework pro implementaci statistických metod v Pythonu, což z něj činí nepostradatelný nástroj v sadě nástrojů datového vědce.
