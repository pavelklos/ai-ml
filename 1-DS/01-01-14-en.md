## 1. Introduction to Data Transformation

Data transformation is the process of converting data from one format or structure into another. In data science, transformations are applied to prepare data for analysis, visualization, or modeling. Proper data transformation can significantly improve the performance of machine learning algorithms and make patterns in the data more apparent.

```python
# Import essential libraries
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn import preprocessing
from scipy import stats

# Set plotting style
plt.style.use('seaborn-v0_8-whitegrid')
sns.set(style="whitegrid")

# Sample dataset
data = {
    'age': [25, 30, 35, 40, 45, 50, 55, 60, 65, 70],
    'income': [38000, 45000, 55000, 60000, 75000, 82000, 85000, 90000, 92000, 94000],
    'satisfaction': [3, 3.5, 4, 4.5, 4.2, 4.8, 3.9, 4.1, 4.5, 4.7]
}

# Create a DataFrame
df = pd.DataFrame(data)

# Display the original data
print("Original data:")
print(df.head())
```

## 2. Common Data Transformation Techniques

There are various transformation techniques, each serving different purposes. Some common transformations include:

- **Mathematical transformations**: Addition, subtraction, multiplication, division
- **Statistical transformations**: Standardization, normalization
- **Functional transformations**: Log, square root, exponential transforms
- **Type conversions**: Changing data types (e.g., string to datetime)
- **Structural transformations**: Reshaping, pivoting, melting data

```python
# Simple mathematical transformations
df['income_thousands'] = df['income'] / 1000
df['age_squared'] = df['age'] ** 2
df['income_age_ratio'] = df['income'] / df['age']

# Type conversion example
df['age_category'] = df['age'].astype(str) + ' years'

print("\nAfter basic transformations:")
print(df.head())
```

## 3. Scaling and Normalization

Scaling and normalization are essential when features have different ranges. Common methods include:

- **Min-Max Scaling**: Scales values between 0 and 1
- **Standardization (Z-score)**: Transforms data to have zero mean and unit variance
- **Robust Scaling**: Uses statistics that are robust to outliers (median and quartiles)
- **Normalization**: Scales samples to have unit norm

```python
# Min-Max scaling
min_max_scaler = preprocessing.MinMaxScaler()
df['income_minmax'] = min_max_scaler.fit_transform(df[['income']])

# Standardization (Z-score normalization)
df['income_zscore'] = stats.zscore(df['income'])

# Robust scaling
robust_scaler = preprocessing.RobustScaler()
df['income_robust'] = robust_scaler.fit_transform(df[['income']])

# Normalizing data (L2 norm)
df['income_normalized'] = preprocessing.normalize(df[['income']], norm='l2')[0]

print("\nAfter scaling transformations:")
print(df[['income', 'income_minmax', 'income_zscore', 'income_robust', 'income_normalized']].head())

# Visualizing the effect of different scaling methods
plt.figure(figsize=(12, 6))
plt.subplot(1, 4, 1)
plt.title('Original')
sns.histplot(df['income'], kde=True)

plt.subplot(1, 4, 2)
plt.title('Min-Max Scaled')
sns.histplot(df['income_minmax'], kde=True)

plt.subplot(1, 4, 3)
plt.title('Z-Score')
sns.histplot(df['income_zscore'], kde=True)

plt.subplot(1, 4, 4)
plt.title('Robust Scaled')
sns.histplot(df['income_robust'], kde=True)

plt.tight_layout()
plt.show()
```

## 4. Log and Power Transformations

Log and power transformations are useful for handling skewed data and making relationships more linear.

```python
# Generate skewed data for demonstration
skewed_data = np.random.exponential(scale=2.0, size=1000)
df_skewed = pd.DataFrame({'original': skewed_data})

# Log transformation
df_skewed['log'] = np.log1p(df_skewed['original'])  # log1p is log(1+x) to handle zeros

# Square root transformation
df_skewed['sqrt'] = np.sqrt(df_skewed['original'])

# Box-Cox transformation
df_skewed['boxcox'], _ = stats.boxcox(df_skewed['original'] + 1)  # Adding 1 to handle zeros

# Yeo-Johnson transformation (works with negative values too)
df_skewed['yeojohnson'], _ = stats.yeojohnson(df_skewed['original'])

# Visualize transformations
fig, axs = plt.subplots(2, 3, figsize=(15, 8))
sns.histplot(df_skewed['original'], kde=True, ax=axs[0, 0])
axs[0, 0].set_title('Original (Skewed) Data')

sns.histplot(df_skewed['log'], kde=True, ax=axs[0, 1])
axs[0, 1].set_title('Log Transformation')

sns.histplot(df_skewed['sqrt'], kde=True, ax=axs[0, 2])
axs[0, 2].set_title('Square Root Transformation')

sns.histplot(df_skewed['boxcox'], kde=True, ax=axs[1, 0])
axs[1, 0].set_title('Box-Cox Transformation')

sns.histplot(df_skewed['yeojohnson'], kde=True, ax=axs[1, 1])
axs[1, 1].set_title('Yeo-Johnson Transformation')

axs[1, 2].axis('off')  # Empty subplot
plt.tight_layout()
plt.show()

print("\nSkewness values after transformations:")
print(f"Original: {stats.skew(df_skewed['original']):.4f}")
print(f"Log: {stats.skew(df_skewed['log']):.4f}")
print(f"Square Root: {stats.skew(df_skewed['sqrt']):.4f}")
print(f"Box-Cox: {stats.skew(df_skewed['boxcox']):.4f}")
print(f"Yeo-Johnson: {stats.skew(df_skewed['yeojohnson']):.4f}")
```

## 5. Binning and Discretization

Binning (or discretization) converts continuous variables into categorical ones by dividing the range into intervals.

```python
# Create sample data
np.random.seed(42)
ages = np.random.normal(40, 10, 100).astype(int)
df_ages = pd.DataFrame({'age': ages})

# Equal-width binning (4 bins)
df_ages['age_bins_equal_width'] = pd.cut(df_ages['age'], bins=4)

# Equal-frequency binning (quartiles)
df_ages['age_bins_equal_freq'] = pd.qcut(df_ages['age'], q=4)

# Custom binning
custom_bins = [0, 30, 40, 50, 100]
bin_labels = ['Young', 'Adult', 'Middle-aged', 'Senior']
df_ages['age_category'] = pd.cut(df_ages['age'], bins=custom_bins, labels=bin_labels)

print("\nBinning results:")
print(df_ages.head(10))

# Visualize the distribution after binning
plt.figure(figsize=(12, 6))

plt.subplot(1, 3, 1)
sns.countplot(y='age_bins_equal_width', data=df_ages)
plt.title('Equal-Width Binning')

plt.subplot(1, 3, 2)
sns.countplot(y='age_bins_equal_freq', data=df_ages)
plt.title('Equal-Frequency Binning')

plt.subplot(1, 3, 3)
sns.countplot(y='age_category', data=df_ages)
plt.title('Custom Binning')

plt.tight_layout()
plt.show()
```

## 6. Creating New Features

Feature engineering often involves creating new features from existing ones to better capture relationships in the data.

```python
# Load a more realistic dataset
from sklearn.datasets import fetch_california_housing
housing = fetch_california_housing()
df_housing = pd.DataFrame(housing.data, columns=housing.feature_names)
df_housing['target'] = housing.target

print("\nCalifornia Housing dataset:")
print(df_housing.head())

# Creating new features through mathematical operations
df_housing['BEDROOM_RATIO'] = df_housing['AveBedrms'] / df_housing['AveRooms']
df_housing['ROOMS_PER_HOUSEHOLD'] = df_housing['AveRooms'] / df_housing['HouseHold']

# Creating interaction features
df_housing['INCOME_PER_ROOM'] = df_housing['MedInc'] / df_housing['AveRooms']

# Creating polynomial features
df_housing['MEDINC_SQUARED'] = df_housing['MedInc'] ** 2
df_housing['MEDINC_CUBED'] = df_housing['MedInc'] ** 3

print("\nAfter creating new features:")
print(df_housing.head())

# Visualize the relationship between original and derived features
plt.figure(figsize=(14, 5))

plt.subplot(1, 3, 1)
plt.scatter(df_housing['MedInc'], df_housing['target'], alpha=0.5)
plt.title('MedInc vs. Target')
plt.xlabel('MedInc')
plt.ylabel('Target')

plt.subplot(1, 3, 2)
plt.scatter(df_housing['INCOME_PER_ROOM'], df_housing['target'], alpha=0.5)
plt.title('Income per Room vs. Target')
plt.xlabel('Income per Room')
plt.ylabel('Target')

plt.scatter(df_housing['POPULATION_PER_HOUSEHOLD'], df_housing['target'], alpha=0.5)

```

## 7. Encoding Categorical Variables

Categorical variables need to be encoded into numerical form before they can be used in many machine learning algorithms.

```python
# Create a sample dataset with categorical variables
data = {
    'color': ['red', 'blue', 'green', 'red', 'green', 'blue', 'red', 'green'],
    'size': ['small', 'medium', 'large', 'medium', 'small', 'large', 'large', 'small'],
    'material': ['wood', 'metal', 'plastic', 'wood', 'metal', 'plastic', 'metal', 'wood'],
    'price': [10.5, 15.3, 20.0, 11.2, 14.7, 19.9, 12.5, 9.8]
}

df_cat = pd.DataFrame(data)
print("\nCategorical data:")
print(df_cat.head())

# One-hot encoding
df_onehot = pd.get_dummies(df_cat, columns=['color', 'size', 'material'], drop_first=False)
print("\nAfter one-hot encoding:")
print(df_onehot.head())

# Label encoding
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df_label = df_cat.copy()
for col in ['color', 'size', 'material']:
    df_label[col + '_encoded'] = le.fit_transform(df_cat[col])
print("\nAfter label encoding:")
print(df_label.head())

# Target encoding (mean encoding)
for col in ['color', 'size', 'material']:
    means = df_cat.groupby(col)['price'].mean()
    df_cat[col + '_mean_encoded'] = df_cat[col].map(means)
print("\nAfter target encoding:")
print(df_cat.head())
```

## 8. Date and Time Transformations

Working with date and time data often requires extracting components or creating time-based features.

```python
# Create a sample time series dataset
dates = pd.date_range(start='2021-01-01', end='2022-12-31', freq='D')
np.random.seed(42)
values = np.random.normal(loc=0, scale=1, size=len(dates))
values = np.cumsum(values)  # Create a random walk

df_time = pd.DataFrame({'date': dates, 'value': values})
print("\nTime series data:")
print(df_time.head())

# Extract date components
df_time['year'] = df_time['date'].dt.year
df_time['month'] = df_time['date'].dt.month
df_time['day'] = df_time['date'].dt.day
df_time['dayofweek'] = df_time['date'].dt.dayofweek
df_time['quarter'] = df_time['date'].dt.quarter
df_time['dayofyear'] = df_time['date'].dt.dayofyear
df_time['is_weekend'] = df_time['dayofweek'].isin([5, 6]).astype(int)
df_time['is_month_end'] = df_time['date'].dt.is_month_end.astype(int)

# Create cyclical features for month and day of week
df_time['month_sin'] = np.sin(2 * np.pi * df_time['month'] / 12)
df_time['month_cos'] = np.cos(2 * np.pi * df_time['month'] / 12)
df_time['dayofweek_sin'] = np.sin(2 * np.pi * df_time['dayofweek'] / 7)
df_time['dayofweek_cos'] = np.cos(2 * np.pi * df_time['dayofweek'] / 7)

print("\nAfter date transformations:")
print(df_time.head())

# Visualize time series data with different date components
plt.figure(figsize=(15, 10))

plt.subplot(2, 2, 1)
sns.lineplot(x='date', y='value', data=df_time)
plt.title('Original Time Series')

plt.subplot(2, 2, 2)
sns.boxplot(x='month', y='value', data=df_time)
plt.title('Value Distribution by Month')

plt.subplot(2, 2, 3)
sns.boxplot(x='dayofweek', y='value', data=df_time)
plt.title('Value Distribution by Day of Week')
plt.xlabel('Day of Week (0=Monday, 6=Sunday)')

plt.subplot(2, 2, 4)
sns.scatterplot(x='month_sin', y='month_cos', hue='month', data=df_time, palette='viridis')
plt.title('Cyclical Encoding of Month')
plt.xlabel('sin(month)')
plt.ylabel('cos(month)')

plt.tight_layout()
plt.show()
```

## 9. Text Data Transformations

Text data requires special preprocessing techniques before it can be used in machine learning models.

```python
# Create a simple dataset with text
texts = [
    "Python is a great programming language",
    "Data science is fun with Python",
    "Machine learning algorithms require good data",
    "Text processing is an important step in NLP",
    "Python has many libraries for data analysis"
]
df_text = pd.DataFrame({'text': texts})
print("\nText data:")
print(df_text)

# Basic text transformations
df_text['text_lower'] = df_text['text'].str.lower()
df_text['text_count'] = df_text['text'].str.len()
df_text['word_count'] = df_text['text'].str.split().str.len()
df_text['contains_python'] = df_text['text'].str.contains('Python', case=True).astype(int)

# Tokenization
df_text['tokens'] = df_text['text_lower'].str.split()

# Remove stopwords
import nltk
from nltk.corpus import stopwords
try:
    nltk.data.find('corpora/stopwords')
except LookupError:
    nltk.download('stopwords')
stop_words = set(stopwords.words('english'))

df_text['tokens_no_stopwords'] = df_text['tokens'].apply(
    lambda x: [word for word in x if word not in stop_words]
)

print("\nAfter text transformations:")
print(df_text[['text', 'text_count', 'word_count', 'contains_python']])
print("\nTokens without stopwords:")
for i, tokens in enumerate(df_text['tokens_no_stopwords']):
    print(f"{i+1}: {tokens}")

# Bag of Words representation
from sklearn.feature_extraction.text import CountVectorizer
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(df_text['text_lower'])
bow_df = pd.DataFrame(X.toarray(), columns=vectorizer.get_feature_names_out())
print("\nBag of Words representation:")
print(bow_df)

# TF-IDF transformation
from sklearn.feature_extraction.text import TfidfVectorizer
tfidf = TfidfVectorizer()
X_tfidf = tfidf.fit_transform(df_text['text_lower'])
tfidf_df = pd.DataFrame(X_tfidf.toarray(), columns=tfidf.get_feature_names_out())
print("\nTF-IDF representation:")
print(tfidf_df)
```

## 10. Summary

Data transformation is a crucial step in the data science pipeline that ensures your data is in the optimal format for analysis or modeling. Key takeaways:

1. **Scaling and Normalization**: Essential for features with different ranges, helping algorithms that are sensitive to the scale of features.

2. **Log and Power Transformations**: Particularly useful for skewed data, making distributions more symmetric and relationships more linear.

3. **Binning and Discretization**: Helps in converting continuous variables to categorical ones, which can reveal non-linear relationships.

4. **Feature Engineering**: Creating new meaningful features can significantly improve model performance by capturing domain knowledge.

5. **Categorical Encoding**: Various methods exist to convert categorical variables into numerical representations.

6. **Date/Time Transformations**: Time-based features can capture temporal patterns and seasonality in the data.

7. **Text Transformations**: From basic cleaning to complex vectorization, text data requires special treatment.

Simple data transformations often make a significant difference in the quality of analysis and can dramatically improve the accuracy of machine learning models. By applying appropriate transformations, you can uncover hidden patterns, fix skewed distributions, standardize scales, and prepare your data for a wide range of analytical techniques.

When applying transformations, remember to:
- Consider the requirements of your analytical method or algorithm
- Be mindful of the impact on interpretability
- Apply transformations consistently to training and test data
- Document your transformation process for reproducibility

With these practices, data transformation becomes a powerful tool in your data science toolkit.
