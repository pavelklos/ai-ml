## Introduction to Bayesian Statistics

Bayesian statistics is a mathematical approach that allows us to update our beliefs about parameters or hypotheses as more data becomes available. It's named after Thomas Bayes, an 18th-century statistician and theologian who formulated the basis of this approach.

At its core, Bayesian statistics involves:
- Starting with a **prior distribution** representing our initial beliefs
- Collecting data
- Updating our beliefs to form a **posterior distribution** using Bayes' theorem

```python
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

# Set styling for plots
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Generate a simple plot to demonstrate prior, likelihood, and posterior
def plot_bayesian_updating(prior_mean, prior_std, likelihood_mean, likelihood_std):
    x = np.linspace(0, 10, 1000)
    
    # Prior distribution
    prior = stats.norm.pdf(x, prior_mean, prior_std)
    
    # Likelihood function
    likelihood = stats.norm.pdf(x, likelihood_mean, likelihood_std)
    
    # Calculate posterior (unnormalized)
    posterior_unnorm = prior * likelihood
    # Normalize posterior
    posterior = posterior_unnorm / np.trapz(posterior_unnorm, x)
    
    # Calculate posterior analytically
    posterior_mean = (prior_mean/prior_std**2 + likelihood_mean/likelihood_std**2) / \
                    (1/prior_std**2 + 1/likelihood_std**2)
    posterior_std = np.sqrt(1 / (1/prior_std**2 + 1/likelihood_std**2))
    
    # Create plot
    plt.figure(figsize=(12, 8))
    plt.plot(x, prior, 'b-', label='Prior')
    plt.plot(x, likelihood, 'r-', label='Likelihood')
    plt.plot(x, posterior, 'g-', label='Posterior')
    plt.fill_between(x, 0, posterior, color='green', alpha=0.2)
    
    plt.axvline(prior_mean, color='b', linestyle='--', alpha=0.5, label='Prior Mean')
    plt.axvline(likelihood_mean, color='r', linestyle='--', alpha=0.5, label='Data Mean')
    plt.axvline(posterior_mean, color='g', linestyle='--', alpha=0.5, label='Posterior Mean')
    
    plt.title('Bayesian Updating Process')
    plt.xlabel('Parameter Value')
    plt.ylabel('Probability Density')
    plt.legend()
    plt.show()
    
    print(f"Prior mean: {prior_mean:.2f}, std: {prior_std:.2f}")
    print(f"Likelihood mean: {likelihood_mean:.2f}, std: {likelihood_std:.2f}")
    print(f"Posterior mean: {posterior_mean:.2f}, std: {posterior_std:.2f}")

# Example: Updating beliefs about a parameter
plot_bayesian_updating(prior_mean=4.0, prior_std=2.0, likelihood_mean=6.0, likelihood_std=1.0)
```

The key insight here is that as we observe more data, our posterior becomes more concentrated around the true value of the parameter, and the influence of our prior diminishes.

## Bayesian vs Frequentist Approaches

Bayesian and Frequentist statistical approaches represent two distinct philosophies for statistical inference:

| Aspect | Frequentist | Bayesian |
|--------|------------|----------|
| **Parameters** | Fixed, unknown constants | Random variables with distributions |
| **Probability** | Long-run frequency | Degree of belief |
| **Inference** | P-values, confidence intervals | Posterior distributions, credible intervals |
| **Prior knowledge** | Generally not incorporated | Explicitly incorporated |

Let's compare these approaches with an example of estimating a probability:

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# Set random seed for reproducibility
np.random.seed(42)

# Let's say we're flipping a coin and want to determine if it's fair
# True probability of heads
true_p = 0.7  # The coin is actually biased

# Simulate coin flips
num_flips = 20
flips = np.random.binomial(1, true_p, num_flips)
num_heads = np.sum(flips)

# Frequentist approach
p_hat = num_heads / num_flips
se = np.sqrt(p_hat * (1 - p_hat) / num_flips)
ci_lower = max(0, p_hat - 1.96 * se)
ci_upper = min(1, p_hat + 1.96 * se)

print("--- Frequentist Approach ---")
print(f"Maximum Likelihood Estimate: {p_hat:.3f}")
print(f"95% Confidence Interval: ({ci_lower:.3f}, {ci_upper:.3f})")

# Bayesian approach with Beta prior
# Beta(1,1) is a uniform prior
alpha_prior = 1
beta_prior = 1

# Compute posterior
alpha_posterior = alpha_prior + num_heads
beta_posterior = beta_prior + (num_flips - num_heads)

# Calculate posterior mean and credible interval
posterior_mean = alpha_posterior / (alpha_posterior + beta_posterior)
cred_interval = stats.beta.interval(0.95, alpha_posterior, beta_posterior)

print("\n--- Bayesian Approach ---")
print(f"Prior: Beta({alpha_prior}, {beta_prior})")
print(f"Posterior: Beta({alpha_posterior}, {beta_posterior})")
print(f"Posterior Mean: {posterior_mean:.3f}")
print(f"95% Credible Interval: ({cred_interval[0]:.3f}, {cred_interval[1]:.3f})")

# Plot prior and posterior distributions
x = np.linspace(0, 1, 1000)
prior = stats.beta.pdf(x, alpha_prior, beta_prior)
posterior = stats.beta.pdf(x, alpha_posterior, beta_posterior)

plt.figure(figsize=(12, 8))
plt.plot(x, prior, 'b-', label='Prior - Beta(1,1)')
plt.plot(x, posterior, 'r-', label=f'Posterior - Beta({alpha_posterior}, {beta_posterior})')
plt.axvline(true_p, color='g', linestyle='--', label=f'True Probability: {true_p}')
plt.axvline(p_hat, color='k', linestyle='--', label=f'Freq. Estimate: {p_hat:.3f}')
plt.axvline(posterior_mean, color='r', linestyle='--', label=f'Bayes Estimate: {posterior_mean:.3f}')

# Add confidence interval and credible interval
plt.axvspan(ci_lower, ci_upper, alpha=0.2, color='gray', label=f'95% Confidence Interval')
plt.axvspan(cred_interval[0], cred_interval[1], alpha=0.2, color='red', label=f'95% Credible Interval')

plt.title('Bayesian vs. Frequentist Estimation of Coin Bias')
plt.xlabel('Probability of Heads (p)')
plt.ylabel('Probability Density')
plt.legend()
plt.show()
```

The key differences illustrated here:
- Frequentists treat the probability as a fixed value and provide a confidence interval
- Bayesians provide a full distribution over possible values and a credible interval
- The Bayesian approach can incorporate prior knowledge and naturally updates with new data

## Bayes' Theorem and Its Applications

Bayes' theorem is the foundational rule for Bayesian statistics. It describes how to update the probability of a hypothesis based on new evidence:

$$P(H|E) = \frac{P(E|H) \times P(H)}{P(E)}$$

Where:
- P(H|E) is the posterior probability of hypothesis H given evidence E
- P(E|H) is the likelihood of observing evidence E given hypothesis H is true
- P(H) is the prior probability of hypothesis H
- P(E) is the marginal likelihood or evidence

Let's implement a simple application of Bayes' theorem for medical testing:

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Medical test scenario
# Let's say we have a test for a disease with these properties:
prevalence = 0.01  # 1% of the population has the disease
sensitivity = 0.95  # Test correctly identifies 95% of those with the disease
specificity = 0.90  # Test correctly identifies 90% of those without the disease

# Calculate the probability that someone who tests positive actually has the disease
# Using Bayes' theorem: P(Disease|Positive) = P(Positive|Disease) * P(Disease) / P(Positive)

# P(Positive|Disease) is the sensitivity
p_positive_given_disease = sensitivity

# P(Disease) is the prevalence
p_disease = prevalence

# P(Positive) = P(Positive|Disease)*P(Disease) + P(Positive|No Disease)*P(No Disease)
p_positive = (p_positive_given_disease * p_disease) + ((1 - specificity) * (1 - p_disease))

# Applying Bayes' theorem
p_disease_given_positive = (p_positive_given_disease * p_disease) / p_positive

print(f"Probability of disease given positive test: {p_disease_given_positive:.4f} ({p_disease_given_positive*100:.1f}%)")

# Let's see how this probability changes with different prevalence rates
prevalence_range = np.linspace(0.001, 0.1, 100)
p_disease_given_positive_range = []

for prev in prevalence_range:
    p_disease = prev
    p_positive = (sensitivity * p_disease) + ((1 - specificity) * (1 - p_disease))
    p_disease_given_positive_range.append((sensitivity * p_disease) / p_positive)

# Plot the relationship
plt.figure(figsize=(10, 6))
plt.plot(prevalence_range, p_disease_given_positive_range)
plt.fill_between(prevalence_range, 0, p_disease_given_positive_range, alpha=0.2)
plt.axhline(y=0.5, color='r', linestyle='--', label='50% probability')
plt.title('Probability of Having Disease Given Positive Test')
plt.xlabel('Disease Prevalence')
plt.ylabel('Probability of Disease Given Positive Test')
plt.grid(True)
plt.legend()
plt.show()

# Create a confusion matrix for the test results
population_size = 10000
has_disease = int(prevalence * population_size)
no_disease = population_size - has_disease

# True positives, false negatives, false positives, true negatives
TP = int(sensitivity * has_disease)
FN = has_disease - TP
FP = int((1 - specificity) * no_disease)
TN = no_disease - FP

conf_matrix = pd.DataFrame({
    'Has Disease': [TP, FN],
    'No Disease': [FP, TN]
}, index=['Test Positive', 'Test Negative'])

print("\nConfusion Matrix:")
print(conf_matrix)

# Visualize the confusion matrix
plt.figure(figsize=(10, 8))
sns.heatmap(conf_matrix, annot=True, fmt='d', cmap='Blues', cbar=False)
plt.title('Confusion Matrix for Medical Test')
plt.show()
```

This example demonstrates the "base rate fallacy" - when a condition is rare, even a highly accurate test can produce more false positives than true positives, which is why Bayesian reasoning is so important in medical diagnostics.

## Introduction to Probabilistic Programming

Probabilistic programming combines programming languages with Bayesian statistics, allowing us to build and solve probabilistic models using code. Key features include:

1. Explicit representation of uncertainty
2. Automatic inference mechanisms
3. Composable probabilistic models
4. Ability to incorporate domain knowledge

Popular probabilistic programming libraries in Python include:
- PyMC3/PyMC
- TensorFlow Probability
- Stan (via PyStan)
- Edward
- Pyro

Let's introduce PyMC, a widely-used probabilistic programming library:

```python
# Install PyMC if needed
# !pip install pymc arviz

import pymc as pm
import arviz as az
import numpy as np
import matplotlib.pyplot as plt

# Set the random seed for reproducibility
np.random.seed(42)

# Generate some synthetic data
true_mu = 5.0
true_sigma = 2.0
data = np.random.normal(true_mu, true_sigma, size=100)

# Creating our first PyMC model
with pm.Model() as basic_model:
    # Prior distributions for the parameters
    mu = pm.Normal('mu', mu=0, sigma=10)  # Prior for mean
    sigma = pm.HalfNormal('sigma', sigma=10)  # Prior for standard deviation
    
    # Likelihood function
    y = pm.Normal('y', mu=mu, sigma=sigma, observed=data)
    
    # Inference - sample from the posterior distribution
    trace = pm.sample(1000, return_inferencedata=True, tune=1000)

# Visualize the results
az.plot_trace(trace)
plt.tight_layout()
plt.show()

# Summary statistics of the posterior
summary = az.summary(trace)
print("\nPosterior Summary Statistics:")
print(summary)

# Plotting posterior distributions
az.plot_posterior(trace)
plt.tight_layout()
plt.show()

# Compare our inferred values to the true values
print(f"\nTrue mu: {true_mu}, Inferred mu: {summary.loc['mu', 'mean']:.3f}")
print(f"True sigma: {true_sigma}, Inferred sigma: {summary.loc['sigma', 'mean']:.3f}")
```

This simple example demonstrates how we can use probabilistic programming to infer the mean and standard deviation of a normal distribution. The beauty of this approach is that it provides full posterior distributions, not just point estimates.

## Implementing Bayesian Models with PyMC3

Now let's explore a more practical example using PyMC to solve a real-world problem: Bayesian linear regression.

```python
import pymc as pm
import arviz as az
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set style
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Generate synthetic data for linear regression
np.random.seed(42)
n = 100
x = np.linspace(0, 10, n)
true_alpha = 2.5
true_beta = 0.5
true_sigma = 1.0
# y = α + βx + ε, ε ~ N(0, σ²)
y = true_alpha + true_beta * x + np.random.normal(0, true_sigma, size=n)

# Visualize the data
plt.figure(figsize=(10, 6))
plt.scatter(x, y, alpha=0.7)
plt.plot(x, true_alpha + true_beta * x, 'r', alpha=0.5)
plt.title('Synthetic Data for Bayesian Linear Regression')
plt.xlabel('x')
plt.ylabel('y')
plt.show()

# Building a Bayesian linear regression model with PyMC
with pm.Model() as linear_model:
    # Priors for unknown model parameters
    alpha = pm.Normal('alpha', mu=0, sigma=10)
    beta = pm.Normal('beta', mu=0, sigma=10)
    sigma = pm.HalfNormal('sigma', sigma=10)
    
    # Expected value of outcome
    mu = alpha + beta * x
    
    # Likelihood (sampling distribution) of observations
    y_obs = pm.Normal('y_obs', mu=mu, sigma=sigma, observed=y)
    
    # Inference - sample from the posterior
    trace = pm.sample(1000, tune=1000, return_inferencedata=True)

# Print summary of posterior samples
summary = az.summary(trace)
print(summary)

# Traceplot
az.plot_trace(trace)
plt.tight_layout()
plt.show()

# Plot posterior distributions
az.plot_posterior(trace)
plt.tight_layout()
plt.show()

# Visualize the model fit with uncertainty
plt.figure(figsize=(10, 6))

# Plot the original data points
plt.scatter(x, y, alpha=0.6, label='Data')

# Plot the true line
plt.plot(x, true_alpha + true_beta * x, 'r', label='True Line', alpha=0.5)

# Get posterior samples
alpha_samples = trace.posterior['alpha'].values.flatten()
beta_samples = trace.posterior['beta'].values.flatten()

# Plot a subset of posterior samples
n_samples = 100
rand_idx = np.random.randint(0, len(alpha_samples), n_samples)
for i in rand_idx:
    plt.plot(x, alpha_samples[i] + beta_samples[i] * x, 'g', alpha=0.05)

# Plot the posterior mean
alpha_mean = alpha_samples.mean()
beta_mean = beta_samples.mean()
plt.plot(x, alpha_mean + beta_mean * x, 'b--', label='Posterior Mean', linewidth=2)

plt.title('Bayesian Linear Regression with Uncertainty')
plt.xlabel('x')
plt.ylabel('y')
plt.legend()
plt.show()

# Print comparison of true vs. inferred parameters
print(f"True alpha: {true_alpha}, Inferred alpha: {alpha_mean:.3f}")
print(f"True beta: {true_beta}, Inferred beta: {beta_mean:.3f}")
print(f"True sigma: {true_sigma}, Inferred sigma: {summary.loc['sigma', 'mean']:.3f}")

# Make predictions with uncertainty
# Generate some new x values
x_new = np.linspace(0, 15, 100)

# Get posterior predictive samples
with linear_model:
    pm.set_data({"x": x_new})  # For PyMC 5.0+
    posterior_pred = pm.sample_posterior_predictive(trace)

# Extract the mean and credible intervals
y_pred_mean = posterior_pred.posterior_predictive['y_obs'].mean(dim=['chain', 'draw']).values
y_pred_hdi = az.hdi(posterior_pred.posterior_predictive['y_obs'], hdi_prob=0.95)

# Plot predictions with uncertainty
plt.figure(figsize=(12, 7))
plt.scatter(x, y, alpha=0.6, label='Observed Data')
plt.plot(x_new, y_pred_mean, 'b', label='Predicted Mean')
plt.fill_between(x_new, y_pred_hdi['y_obs'].sel(hdi='lower'), y_pred_hdi['y_obs'].sel(hdi='higher'), 
                alpha=0.3, label='95% Credible Interval')
plt.axvline(x=10, color='k', linestyle='--', alpha=0.3, label='Data Boundary')
plt.title('Bayesian Linear Regression Predictions with Uncertainty')
plt.xlabel('x')
plt.ylabel('y')
plt.legend()
plt.show()
```

This example demonstrates several key advantages of Bayesian regression:
1. We get full posterior distributions for all parameters
2. We can easily incorporate prior knowledge
3. We naturally quantify uncertainty in predictions
4. We can make probabilistic predictions for new data points

## Markov Chain Monte Carlo (MCMC) Sampling

Markov Chain Monte Carlo (MCMC) methods are computational techniques used to approximate complex posterior distributions when analytical solutions are not possible. These methods generate samples from the posterior distribution that can be used to estimate various characteristics of the distribution.

Common MCMC algorithms include:
- Metropolis-Hastings
- Gibbs Sampling
- Hamiltonian Monte Carlo (HMC)
- No-U-Turn Sampler (NUTS)

Let's create a simple implementation of the Metropolis-Hastings algorithm to understand the basics:

```python
import numpy as np
import matplotlib.pyplot as plt
import scipy.stats as stats
import seaborn as sns

# Set styling for plots
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Define a target distribution (what we're trying to sample from)
def target_pdf(x):
    # This could be any complex distribution
    # Here we'll use a mixture of two Gaussians
    return 0.3 * stats.norm.pdf(x, -3, 1) + 0.7 * stats.norm.pdf(x, 2, 2)

# Metropolis-Hastings algorithm implementation
def metropolis_hastings(target_pdf, proposal_width, n_samples, initial_value=0):
    """
    Implement the Metropolis-Hastings algorithm.
    
    Parameters:
    -----------
    target_pdf : function
        The target probability density function to sample from
    proposal_width : float
        Standard deviation of the Gaussian proposal distribution
    n_samples : int
        Number of samples to generate
    initial_value : float, optional
        Starting point of the chain
        
    Returns:
    --------
    samples : numpy.ndarray
        Array of samples from the target distribution
    acceptance_rate : float
        Fraction of proposals that were accepted
    """
    samples = np.zeros(n_samples)
    current_value = initial_value
    n_accepted = 0
    
    for i in range(n_samples):
        # Generate proposal
        proposal = current_value + np.random.normal(0, proposal_width)
        
        # Compute acceptance ratio
        target_current = target_pdf(current_value)
        target_proposal = target_pdf(proposal)
        
        # Guard against division by zero
        if target_current == 0:
            acceptance_ratio = np.inf
        else:
            acceptance_ratio = target_proposal / target_current
        
        # Accept or reject proposal
        if np.random.uniform() < acceptance_ratio:
            current_value = proposal
            n_accepted += 1
        
        # Store the current value
        samples[i] = current_value
    
    acceptance_rate = n_accepted / n_samples
    return samples, acceptance_rate

# Run the Metropolis-Hastings algorithm
n_samples = 10000
proposal_width = 2.0
samples, acceptance_rate = metropolis_hastings(target_pdf, proposal_width, n_samples)

print(f"Acceptance rate: {acceptance_rate:.2f}")

# Plot results
plt.figure(figsize=(12, 8))

# Plot the chain trace
plt.subplot(2, 1, 1)
plt.plot(samples)
plt.title('MCMC Chain Trace')
plt.xlabel('Iteration')
plt.ylabel('Value')

# Plot the histogram of samples vs. true distribution
plt.subplot(2, 1, 2)
x = np.linspace(-10, 10, 1000)
true_pdf = [target_pdf(xi) for xi in x]
sns.histplot(samples, stat='density', alpha=0.6, bins=50, label='MCMC Samples')
plt.plot(x, true_pdf, 'r', linewidth=2, label='True PDF')
plt.title('MCMC Sample Distribution vs. True Distribution')
plt.xlabel('Value')
plt.ylabel('Probability Density')
plt.legend()

plt.tight_layout()
plt.show()

# Let's look at the effect of the proposal width on mixing and convergence
proposal_widths = [0.1, 1.0, 5.0]
n_samples = 5000

plt.figure(figsize=(12, 8))
for i, width in enumerate(proposal_widths):
    samples, acceptance = metropolis_hastings(target_pdf, width, n_samples)
    
    plt.subplot(3, 1, i+1)
    plt.plot(samples)
    plt.title(f'Proposal Width: {width}, Acceptance Rate: {acceptance:.2f}')
    plt.xlabel('Iteration')
    plt.ylabel('Value')
    plt.ylim(-10, 10)

plt.tight_layout()
plt.show()
```

This demonstration shows how MCMC methods allow us to sample from complex distributions. In practice, we typically use libraries like PyMC that implement advanced MCMC algorithms like NUTS, which automatically tune parameters to achieve good mixing and convergence.

## Hierarchical Bayesian Models

Hierarchical Bayesian models (also called multilevel models) allow us to model parameters that naturally fall into groups or hierarchies. These models are powerful because they can "borrow strength" across groups, leading to more robust inferences, especially when data is limited.

Let's implement a hierarchical model for analyzing test scores from different schools:

```python
import pymc as pm
import arviz as az
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set seed for reproducibility
np.random.seed(42)

# Generate synthetic data
n_schools = 8
n_students_per_school = np.random.randint(20, 50, size=n_schools)
total_students = np.sum(n_students_per_school)

# True parameters
mu = 75  # Overall mean score
sigma_school = 7  # Between-school variation
sigma_student = 15  # Within-school variation

# Generate true school effects (deviations from overall mean)
school_effects = np.random.normal(0, sigma_school, n_schools)

# Generate student data
school_ids = np.repeat(np.arange(n_schools), n_students_per_school)
student_scores = np.zeros(total_students)

idx = 0
for i, n_students in enumerate(n_students_per_school):
    true_school_mean = mu + school_effects[i]
    student_scores[idx:idx+n_students] = np.random.normal(true_school_mean, sigma_student, n_students)
    idx += n_students

# Create a dataframe
df = pd.DataFrame({
    'school': school_ids,
    'score': student_scores
})

# Calculate school statistics
school_stats = df.groupby('school').agg(['mean', 'std', 'count'])['score'].reset_index()
school_stats.columns = ['school', 'mean_score', 'std_score', 'n_students']

print("School Statistics:")
print(school_stats)

# Plot the school means with their standard errors
plt.figure(figsize=(12, 6))
plt.errorbar(
    school_stats['school'], 
    school_stats['mean_score'],
    yerr=school_stats['std_score'] / np.sqrt(school_stats['n_students']),
    fmt='o', capsize=5
)
plt.axhline(mu, color='r', linestyle='--', alpha=0.7, label='True Overall Mean')
plt.axhline(np.mean(student_scores), color='g', linestyle=':', alpha=0.7, label='Sample Overall Mean')
plt.title('School Mean Scores with Standard Errors')
plt.xlabel('School ID')
plt.ylabel('Mean Score')
plt.legend()
plt.show()

# Build a hierarchical Bayesian model
with pm.Model() as hierarchical_model:
    # Hyperpriors
    mu = pm.Normal('mu', mu=75, sigma=10)  # Overall mean score
    sigma_school = pm.HalfNormal('sigma_school', sigma=10)  # Between-school variation
    sigma_student = pm.HalfNormal('sigma_student', sigma=20)  # Within-school variation
    
    # School-level parameters
    theta = pm.Normal('theta', mu=mu, sigma=sigma_school, shape=n_schools)
    
    # Student-level likelihood
    scores = pm.Normal('scores', mu=theta[school_ids], sigma=sigma_student, observed=student_scores)
    
    # Sample from the posterior
    trace = pm.sample(1000, tune=1000, return_inferencedata=True)

# Examine the trace
az.plot_trace(trace, var_names=['mu', 'sigma_school', 'sigma_student'])
plt.tight_layout()
plt.show()

# Summary of the posterior
summary = az.summary(trace, var_names=['mu', 'sigma_school', 'sigma_student'])
print("\nPosterior Summary:")
print(summary)

# Compare estimated school effects with true school effects
theta_posterior = trace.posterior['theta'].mean(dim=['chain', 'draw']).values
school_effects_estimated = theta_posterior - trace.posterior['mu'].mean(dim=['chain', 'draw']).values

plt.figure(figsize=(10, 6))
plt.scatter(school_effects, school_effects_estimated, s=100*school_stats['n_students']/np.max(school_stats['n_students']))
plt.plot([-15, 15], [-15, 15], 'k--')
plt.title('True vs. Estimated School Effects')
plt.xlabel('True School Effects')
plt.ylabel('Estimated School Effects')
plt.grid(True)
plt.show()

# Visualize the shrinkage effect
plt.figure(figsize=(12, 8))

# Raw school means
plt.subplot(1, 2, 1)
raw_means = school_stats['mean_score'].values
plt.scatter(np.arange(n_schools), raw_means, s=80, label='Raw School Means')
plt.axhline(np.mean(student_scores), color='g', linestyle='-', label='Overall Sample Mean')
plt.title('Raw School Means')
plt.xlabel('School ID')
plt.ylabel('Mean Score')
plt.ylim(50, 100)
plt.legend()

# Hierarchical model estimates
plt.subplot(1, 2, 2)
plt.scatter(np.arange(n_schools), theta_posterior, s=80, color='r', label='Hierarchical Estimates')
plt.axhline(summary.loc['mu', 'mean'], color='b', linestyle='-', label='Estimated Overall Mean')

# Connect the raw means to the hierarchical estimates
for i in range(n_schools):
    plt.plot([i, i], [raw_means[i], theta_posterior[i]], 'k--', alpha=0.5)

plt.title('Hierarchical Estimates (with Shrinkage)')
plt.xlabel('School ID')
plt.ylabel('Mean Score')
plt.ylim(50, 100)
plt.legend()

plt.tight_layout()
plt.show()
```

This example illustrates several key aspects of hierarchical Bayesian models:

1. **Partial pooling**: School estimates are a weighted average of the raw school data and the overall mean
2. **Shrinkage**: Estimates for schools with little data are "shrunk" toward the overall mean
3. **Information sharing**: Schools borrow strength from one another through the hierarchical structure
4. **Regularization**: The hierarchical structure naturally prevents overfitting to noise in small samples

Hierarchical models are especially useful when:
- You have grouped or clustered data
- Some groups have limited data
- You want to model variation at multiple levels
- You need to make predictions for new groups

## Bayesian A/B Testing

A/B testing is a common application of statistical methods for comparing two variants. The Bayesian approach to A/B testing offers several advantages:

1. Interpretability - direct probability statements about which variant is better
2. Flexibility in stopping criteria - no need for fixed sample sizes
3. Incorporation of prior knowledge
4. Natural handling of uncertainty

Let's implement a Bayesian A/B test for conversion rates:

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats

# Set styling for plots
plt.style.use('seaborn-whitegrid')
sns.set_context("talk")

# Generate synthetic data for A/B test
np.random.seed(42)

# True conversion rates
p_A = 0.10  # Variant A (control) conversion rate
p_B = 0.12  # Variant B (treatment) conversion rate

# Sample sizes
n_A = 1000  # Users shown variant A
n_B = 1000  # Users shown variant B

# Simulate observations
conversions_A = np.random.binomial(1, p_A, n_A)
conversions_B = np.random.binomial(1, p_B, n_B)

# Calculate observed conversion rates
obs_p_A = np.sum(conversions_A) / n_A
obs_p_B = np.sum(conversions_B) / n_B

print(f"Variant A: {np.sum(conversions_A)} conversions out of {n_A} ({obs_p_A:.1%} conversion rate)")
print(f"Variant B: {np.sum(conversions_B)} conversions out of {n_B} ({obs_p_B:.1%} conversion rate)")
print(f"Observed lift: {(obs_p_B - obs_p_A) / obs_p_A:.1%}")

# Bayesian analysis with Beta prior
# Prior parameters (Beta distribution)
alpha_prior = 1
beta_prior = 1

# Posterior parameters (adding successes and failures to prior)
alpha_A = alpha_prior + np.sum(conversions_A)
beta_A = beta_prior + n_A - np.sum(conversions_A)

alpha_B = alpha_prior + np.sum(conversions_B)
beta_B = beta_prior + n_B - np.sum(conversions_B)

print("\nPosterior Beta distribution parameters:")
print(f"Variant A: Beta({alpha_A}, {beta_A})")
print(f"Variant B: Beta({alpha_B}, {beta_B})")

# Calculate probability that B is better than A
def prob_B_better_than_A(alpha_A, beta_A, alpha_B, beta_B, samples=100000):
    # Generate samples from posterior distributions
    samples_A = np.random.beta(alpha_A, beta_A, samples)
    samples_B = np.random.beta(alpha_B, beta_B, samples)
    
    # Calculate probability that B > A
    prob_B_better = np.mean(samples_B > samples_A)
    
    return prob_B_better

prob_B_better = prob_B_better_than_A(alpha_A, beta_A, alpha_B, beta_B)
print(f"\nProbability that Variant B is better than Variant A: {prob_B_better:.1%}")

# Calculate expected lift
def expected_lift(alpha_A, beta_A, alpha_B, beta_B, samples=100000):
    # Generate samples from posterior distributions
    samples_A = np.random.beta(alpha_A, beta_A, samples)
    samples_B = np.random.beta(alpha_B, beta_B, samples)
    
    # Calculate relative lifts
    lifts = (samples_B - samples_A) / samples_A
    
    # Calculate mean and credible interval
    mean_lift = np.mean(lifts)
    ci_lift = np.percentile(lifts, [2.5, 97.5])
    
    return mean_lift, ci_lift

mean_lift, ci_lift = expected_lift(alpha_A, beta_A, alpha_B, beta_B)
print(f"Expected lift: {mean_lift:.1%} (95% CI: {ci_lift[0]:.1%} to {ci_lift[1]:.1%})")

# Visualize posterior distributions
x = np.linspace(0, 0.2, 1000)
posterior_A = stats.beta.pdf(x, alpha_A, beta_A)
posterior_B = stats.beta.pdf(x, alpha_B, beta_B)

plt.figure(figsize=(12, 6))
plt.plot(x, posterior_A, 'b-', label=f'Variant A: Beta({alpha_A}, {beta_A})')
plt.plot(x, posterior_B, 'r-', label=f'Variant B: Beta({alpha_B}, {beta_B})')
plt.axvline(p_A, color='b', linestyle='--', alpha=0.5, label=f'True A: {p_A:.1%}')
plt.axvline(p_B, color='r', linestyle='--', alpha=0.5, label=f'True B: {p_B:.1%}')
plt.fill_between(x, 0, posterior_A, color='blue', alpha=0.1)
plt.fill_between(x, 0, posterior_B, color='red', alpha=0.1)
plt.title('Posterior Distributions of Conversion Rates')
plt.xlabel('Conversion Rate')
plt.ylabel('Probability Density')
plt.legend()
plt.show()

# Visualize distribution of lifts
samples_A = np.random.beta(alpha_A, beta_A, 100000)
samples_B = np.random.beta(alpha_B, beta_B, 100000)
lifts = (samples_B - samples_A) / samples_A

plt.figure(figsize=(12, 6))
sns.histplot(lifts, bins=50, kde=True)
plt.axvline(0, color='k', linestyle='--', alpha=0.7, label='No Effect')
plt.axvline(mean_lift, color='r', linestyle='-', alpha=0.7, label=f'Mean Lift: {mean_lift:.1%}')
plt.axvline(ci_lift[0], color='r', linestyle=':', alpha=0.7, label=f'95% CI Lower: {ci_lift[0]:.1%}')
plt.axvline(ci_lift[1], color='r', linestyle=':', alpha=0.7, label=f'95% CI Upper: {ci_lift[1]:.1%}')
plt.title('Posterior Distribution of Lift (B vs A)')
plt.xlabel('Lift = (B-A)/A')
plt.ylabel('Probability Density')
plt.legend()
plt.show()

# Simulate sequential analysis (data arriving over time)
def sequential_bayesian_ab_test(p_A, p_B, max_samples=5000, batch_size=100, threshold=0.95):
    """
    Simulate a sequential Bayesian A/B test.
    
    Parameters:
    -----------
    p_A : float
        True conversion rate for variant A
    p_B : float
        True conversion rate for variant B
    max_samples : int
        Maximum number of samples to collect per variant
    batch_size : int
        Number of samples to collect in each batch
    threshold : float
        Probability threshold for making a decision
        
    Returns:
    --------
    results : pandas.DataFrame
        DataFrame with the results at each step
    """
    results = []
    
    # Prior parameters
    alpha_prior = 1
    beta_prior = 1
    
    # Initialize posterior parameters
    alpha_A = alpha_prior
    beta_A = beta_prior
    alpha_B = alpha_prior
    beta_B = beta_prior
    
    n_A = 0
    n_B = 0
    
    while (n_A < max_samples) and (n_B < max_samples):
        # Collect a batch of data for each variant
        new_A = np.random.binomial(1, p_A, batch_size)
        new_B = np.random.binomial(1, p_B, batch_size)
        
        # Update counts
        n_A += batch_size
        n_B += batch_size
        
        # Update posterior parameters
        alpha_A += np.sum(new_A)
        beta_A += batch_size - np.sum(new_A)
        alpha_B += np.sum(new_B)
        beta_B += batch_size - np.sum(new_B)
        
        # Calculate probabilities
        prob_B_better = prob_B_better_than_A(alpha_A, beta_A, alpha_B, beta_B)
        prob_A_better = 1 - prob_B_better
        
        # Store results
        results.append({
            'samples': n_A,  # Samples per variant
            'conversions_A': alpha_A - alpha_prior,
            'conversions_B': alpha_B - alpha_prior,
            'conversion_rate_A': (alpha_A - alpha_prior) / n_A,
            'conversion_rate_B': (alpha_B - alpha_prior) / n_B,
            'prob_B_better': prob_B_better,
            'prob_A_better': prob_A_better,
            'decision': 'continue'
        })
        
        # Check if we've reached a decision threshold
        if prob_B_better >= threshold:
            results[-1]['decision'] = 'B wins'
            break
        elif prob_A_better >= threshold:
            results[-1]['decision'] = 'A wins'
            break
    
    # If we've reached max samples without a decision
    if n_A >= max_samples:
        if prob_B_better > 0.5:
            results[-1]['decision'] = 'B ahead but inconclusive'
        else:
            results[-1]['decision'] = 'A ahead but inconclusive'
    
    return pd.DataFrame(results)

# Run sequential test
sequential_results = sequential_bayesian_ab_test(p_A, p_B, max_samples=10000, batch_size=50, threshold=0.95)

# Print the final result
final_result = sequential_results.iloc[-1]
print("\nSequential Testing Results:")
print(f"Total samples per variant: {final_result['samples']}")
print(f"Final probabilities: P(B > A) = {final_result['prob_B_better']:.1%}, " +
      f"P(A > B) = {final_result['prob_A_better']:.1%}")
print(f"Decision: {final_result['decision']}")

# Visualize the sequential test
plt.figure(figsize=(15, 10))

# Plot conversion rates over time
plt.subplot(2, 1, 1)
plt.plot(sequential_results['samples'], sequential_results['conversion_rate_A'], 'b-', label='Variant A')
plt.plot(sequential_results['samples'], sequential_results['conversion_rate_B'], 'r-', label='Variant B')
plt.axhline(p_A, color='b', linestyle='--', alpha=0.5, label=f'True A: {p_A:.1%}')
plt.axhline(p_B, color='r', linestyle='--', alpha=0.5, label=f'True B: {p_B:.1%}')
plt.title('Observed Conversion Rates')
plt.xlabel('Number of Samples per Variant')
plt.ylabel('Conversion Rate')
plt.legend()

# Plot probability of B being better than A
plt.subplot(2, 1, 2)
plt.plot(sequential_results['samples'], sequential_results['prob_B_better'], 'g-')
plt.axhline(0.95, color='r', linestyle='--', alpha=0.7, label='Decision Threshold (95%)')
plt.axhline(0.5, color='k', linestyle=':', alpha=0.5, label='Equal Probability (50%)')
plt.title('Probability that B is Better than A')
plt.xlabel('Number of Samples per Variant')
plt.ylabel('P(B > A)')
plt.ylim(0, 1)
plt.legend()

plt.tight_layout()
plt.show()
```

This comprehensive example demonstrates several advantages of Bayesian A/B testing:

1. **Direct probability interpretation**: We get the exact probability that B is better than A.
2. **Full distribution of effects**: We see the entire distribution of possible lift values.
3. **Sequential testing**: We can monitor results as data comes in and potentially stop early.
4. **Decision-making framework**: Clear criteria for when to declare a winner.

Bayesian A/B testing is especially valuable when:
- You need to make decisions with limited data
- You want to communicate results in intuitive probability terms
- You need flexibility in when to stop an experiment
- You have meaningful prior information about conversion rates

## Bayesian Time Series Analysis

Bayesian methods are well-suited for time series analysis, as they can naturally incorporate uncertainty, handle missing data, and model complex temporal patterns. Let's implement a Bayesian structural time series model:

```python
import pymc as pm
import arviz as az
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Set seed for reproducibility
np.random.seed(42)

# Generate synthetic time series data with trend, seasonality, and noise
n_points = 200
time = np.arange(n_points)

# Components
trend = 0.05 * time
seasonality = 5 * np.sin(2 * np.pi * time / 50)
noise = np.random.normal(0, 1, n_points)

# Combine components
y = trend + seasonality + noise

# Create a DataFrame
df = pd.DataFrame({
    'time': time,
    'value': y,
    'trend': trend,
    'seasonality': seasonality,
    'noise': noise
})

# Visualize the data and its components
plt.figure(figsize=(12, 8))

plt.subplot(2, 1, 1)
plt.plot(df['time'], df['value'], label='Observed Data')
plt.title('Synthetic Time Series Data')
plt.ylabel('Value')
plt.legend()

plt.subplot(2, 1, 2)
plt.plot(df['time'], df['trend'], label='Trend Component')
plt.plot(df['time'], df['seasonality'], label='Seasonal Component')
plt.fill_between(df['time'], -2, 2, alpha=0.2, color='gray', label='Noise Range (±2σ)')
plt.title('True Components')
plt.xlabel('Time')
plt.ylabel('Value')
plt.legend()

plt.tight_layout()
plt.show()

# Define a Bayesian structural time series model
with pm.Model() as time_series_model:
    # Trend component
    trend_level = pm.Normal('trend_level', mu=0, sigma=5)
    trend_slope = pm.Normal('trend_slope', mu=0, sigma=0.1)
    
    # Seasonality component
    period = 50
    n_harmonics = 4  # Number of harmonics for the Fourier series
    
    # Create seasonal components
    harmonics = []
    for h in range(1, n_harmonics + 1):
        cos_coef = pm.Normal(f'cos_coef_{h}', mu=0, sigma=5)
        sin_coef = pm.Normal(f'sin_coef_{h}', mu=0, sigma=5)
        
        cos_term = cos_coef * np.cos(2 * np.pi * h * time / period)
        sin_term = sin_coef * np.sin(2 * np.pi * h * time / period)
        
        harmonics.append(cos_term + sin_term)
    
    # Combine harmonics
    seasonality = pm.Deterministic('seasonality', sum(harmonics))
    
    # Observation noise
    sigma = pm.HalfNormal('sigma', sigma=5)
    
    # Model trend and seasonality
    trend = pm.Deterministic('trend', trend_level + trend_slope * time)
    mu = pm.Deterministic('mu', trend + seasonality)
    
    # Likelihood
    y_obs = pm.Normal('y_obs', mu=mu, sigma=sigma, observed=y)
    
    # Inference
    trace = pm.sample(1000, tune=1000, return_inferencedata=True)

# Plot traces for key parameters
az.plot_trace(trace, var_names=['trend_level', 'trend_slope', 'sigma'])
plt.tight_layout()
plt.show()

# Summary of parameters
summary = az.summary(trace, var_names=['trend_level', 'trend_slope', 'sigma', 
                                        'cos_coef_1', 'sin_coef_1'])
print("\nParameter Summary:")
print(summary)

# Compare true parameters with estimated ones
print("\nComparison of True vs. Estimated Parameters:")
print(f"True trend slope: 0.05, Estimated: {summary.loc['trend_slope', 'mean']:.4f}")
print(f"True noise std: 1.0, Estimated: {summary.loc['sigma', 'mean']:.4f}")

# Plot the model fit and components
def plot_model_fit(trace, df, ci_width=0.95):
    # Extract posterior samples
    trend_samples = trace.posterior['trend'].stack(samples=("chain", "draw")).values
    seasonality_samples = trace.posterior['seasonality'].stack(samples=("chain", "draw")).values
    mu_samples = trace.posterior['mu'].stack(samples=("chain", "draw")).values
    
    # Calculate means and credible intervals
    trend_mean = np.mean(trend_samples, axis=0)
    trend_lower = np.percentile(trend_samples, 100 * (1 - ci_width) / 2, axis=0)
    trend_upper = np.percentile(trend_samples, 100 * (1 + ci_width) / 2, axis=0)
    
    seasonality_mean = np.mean(seasonality_samples, axis=0)
    seasonality_lower = np.percentile(seasonality_samples, 100 * (1 - ci_width) / 2, axis=0)
    seasonality_upper = np.percentile(seasonality_samples, 100 * (1 + ci_width) / 2, axis=0)
    
    mu_mean = np.mean(mu_samples, axis=0)
    mu_lower = np.percentile(mu_samples, 100 * (1 - ci_width) / 2, axis=0)
    mu_upper = np.percentile(mu_samples, 100 * (1 + ci_width) / 2, axis=0)
    
    # Create the plot
    fig, axes = plt.subplots(3, 1, figsize=(12, 12), sharex=True)
    
    # Plot the data and overall fit
    axes[0].plot(df['time'], df['value'], 'o', alpha=0.5, label='Observed Data')
    axes[0].plot(df['time'], mu_mean, 'k-', label='Posterior Mean')
    axes[0].fill_between(df['time'], mu_lower, mu_upper, color='k', alpha=0.2, label=f'{ci_width*100:.0f}% CI')
    axes[0].set_title('Model Fit')
    axes[0].set_ylabel('Value')
    axes[0].legend()
    
    # Plot the trend component
    axes[1].plot(df['time'], df['trend'], 'b-', label='True Trend')
    axes[1].plot(df['time'], trend_mean, 'r-', label='Estimated Trend')

    axes[1].set_title('Trend Component')
    axes[1].set_ylabel('Value')
    axes[1].legend()
    
    # Plot the seasonal component
    axes[2].plot(df['time'], df['seasonality'], 'b-', label='True Seasonality')
    axes[2].plot(df['time'], seasonality_mean, 'g-', label='Estimated Seasonality')
    axes[2].fill_between(df['time'], seasonality_lower, seasonality_upper, color='g', alpha=0.2, label=f'{ci_width*100:.0f}% CI')
    axes[2].set_title('Seasonal Component')
    axes[2].set_xlabel('Time')
    axes[2].set_ylabel('Value')
    axes[2].legend()
    
    plt.tight_layout()
    return fig, axes

# Plot the model components
fig, axes = plot_model_fit(trace, df)
plt.show()

# Make forecasts with the model
forecast_steps = 50
forecast_time = np.arange(n_points, n_points + forecast_steps)

# Generate true future values for comparison

        forecast_harmonics.append(cos_term + sin_term)

        trace,
        var_names=['forecast', 'forecast_mu', 'forecast_seasonality'],

forecast_values = forecast_samples.posterior_predictive['forecast'].mean(dim=['chain', 'draw']).values

plt.figure(figsize=(15, 8))

# Add a vertical line separating history from forecast
plt.axvline(x=n_points-1, color='k', linestyle='--', alpha=0.5, label='Forecast Start')

plt.title('Time Series Forecast')
plt.xlabel('Time')
plt.ylabel('Value')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

1. **Decomposition**: We can separate the series into interpretable components (trend, seasonality, noise)

## Summary

Bayesian statistics and probabilistic programming provide a powerful framework for data science and modeling under uncertainty. Key concepts and advantages covered in this tutorial include:

1. **Bayesian Inference**: A framework that updates beliefs about parameters based on observed data, combining prior knowledge with evidence.

2. **Bayes' Theorem**: The mathematical foundation that allows us to compute posterior probabilities by combining prior probabilities and likelihoods.

3. **Probabilistic Programming**: Modern tools like PyMC that allow us to express and solve Bayesian models using code, handling the complex mathematical details automatically.

4. **Full Posterior Distributions**: Rather than point estimates, Bayesian methods provide entire probability distributions over parameters, enabling rich uncertainty quantification.

5. **MCMC Sampling**: Computational techniques that generate samples from posterior distributions when analytical solutions aren't available.

6. **Hierarchical Models**: Powerful multi-level models that allow for "partial pooling" of information across groups, resulting in more robust inference.

7. **Bayesian A/B Testing**: A principled approach to experiment analysis that provides direct probability statements and allows for flexible stopping criteria.

8. **Bayesian Time Series**: Methods for analyzing temporal data that naturally incorporate uncertainty and can decompose series into interpretable components.

Advantages of Bayesian methods:
- Natural incorporation of prior knowledge
- Explicit representation of uncertainty
- Intuitive probabilistic interpretation of results
- Flexibility in model specification
- Robustness with small sample sizes
- Sequential updating as new data arrives

The Bayesian approach does come with challenges, including computational demands and the need to specify prior distributions. However, modern probabilistic programming libraries like PyMC, along with increasing computational power, have made Bayesian methods more accessible than ever before.
