## Úvod do nevyvážených datových sad

Nevyvážené datové sady se vyskytují, když třídy v klasifikačním problému nejsou rovnoměrně zastoupeny. To je běžné v mnoha reálných scénářích, jako je detekce podvodů, diagnostika nemocí a detekce anomálií, kde je třída zájmu (pozitivní třída) vzácná ve srovnání s negativní třídou.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.metrics import confusion_matrix, classification_report, roc_curve, auc, precision_recall_curve, average_precision_score
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from collections import Counter

# Nastavení náhodného seedu pro reprodukovatelnost
np.random.seed(42)
```

## Detekce a vizualizace nevyváženosti tříd

Před řešením nevyváženosti je důležité porozumět rozsahu problému v datové sadě. Vytvořme syntetickou nevyváženou datovou sadu a vizualizujme rozložení tříd.

```python
# Vytvoření syntetické nevyvážené datové sady (90% třída 0, 10% třída 1)
X, y = make_classification(
    n_samples=10000,
    n_features=10,
    n_informative=5,
    n_redundant=5,
    n_clusters_per_class=1,
    weights=[0.9, 0.1],  # Rozložení tříd: 90% třída 0, 10% třída 1
    random_state=42
)

# Převod na DataFrame pro snadnější manipulaci
df = pd.DataFrame(X, columns=[f'feature_{i}' for i in range(X.shape[1])])
df['target'] = y

# Kontrola rozložení tříd
class_counts = pd.Series(y).value_counts()
print("Rozložení tříd:")
print(class_counts)
print(f"Poměr nevyváženosti tříd: 1:{class_counts[0]/class_counts[1]:.1f}")

# Vizualizace nevyváženosti tříd
plt.figure(figsize=(10, 6))
ax = sns.countplot(x='target', data=df)
plt.title('Rozložení tříd')
plt.xlabel('Třída')
plt.ylabel('Počet')
for p in ax.patches:
    ax.annotate(f'{p.get_height()}', (p.get_x() + p.get_width() / 2., p.get_height()),
                ha='center', va='bottom')
plt.tight_layout()
plt.show()

# Rozdělení dat na trénovací a testovací množiny
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)
print(f"Rozložení tříd v trénovací množině: {Counter(y_train)}")
print(f"Rozložení tříd v testovací množině: {Counter(y_test)}")
```

## Techniky převzorkování

Techniky převzorkování upravují datovou sadu k vyvážení rozložení tříd. Dva hlavní přístupy jsou:

1. **Podvzorkování**: Odstranění vzorků z majoritní třídy
2. **Nadvzorkování**: Přidání více vzorků minoritní třídy

```python
from imblearn.under_sampling import RandomUnderSampler
from imblearn.over_sampling import RandomOverSampler

# Náhodné podvzorkování
rus = RandomUnderSampler(random_state=42)
X_train_under, y_train_under = rus.fit_resample(X_train, y_train)

# Náhodné nadvzorkování
ros = RandomOverSampler(random_state=42)
X_train_over, y_train_over = ros.fit_resample(X_train, y_train)

# Porovnání rozložení tříd po převzorkování
print("Původní rozložení tříd:", Counter(y_train))
print("Po podvzorkování:", Counter(y_train_under))
print("Po nadvzorkování:", Counter(y_train_over))

# Vizualizace převzorkovaných rozložení
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# Původní data
sns.countplot(x=y_train, ax=axes[0]).set_title('Původní')
axes[0].set_xlabel('Třída')
axes[0].set_ylabel('Počet')

# Podvzorkovaná data
sns.countplot(x=y_train_under, ax=axes[1]).set_title('Podvzorkovaná')
axes[1].set_xlabel('Třída')
axes[1].set_ylabel('Počet')

# Nadvzorkovaná data
sns.countplot(x=y_train_over, ax=axes[2]).set_title('Nadvzorkovaná')
axes[2].set_xlabel('Třída')
axes[2].set_ylabel('Počet')

plt.tight_layout()
plt.show()
```

## SMOTE a pokročilé metody nadvzorkování

Synthetic Minority Over-sampling Technique (SMOTE) vytváří syntetické vzorky pro minoritní třídu namísto pouhého duplikování existujících vzorků. To pomáhá řešit problém přetrénování, který může nastat při jednoduchém nadvzorkování.

```python
from imblearn.over_sampling import SMOTE, ADASYN, BorderlineSMOTE

# Aplikace SMOTE
smote = SMOTE(random_state=42)
X_train_smote, y_train_smote = smote.fit_resample(X_train, y_train)

# Aplikace BorderlineSMOTE (zaměřuje se na obtížnější příklady)
bsmote = BorderlineSMOTE(random_state=42)
X_train_bsmote, y_train_bsmote = bsmote.fit_resample(X_train, y_train)

# Aplikace ADASYN (Adaptive Synthetic Sampling)
adasyn = ADASYN(random_state=42)
X_train_adasyn, y_train_adasyn = adasyn.fit_resample(X_train, y_train)

print("Původní rozložení tříd:", Counter(y_train))
print("Po SMOTE:", Counter(y_train_smote))
print("Po BorderlineSMOTE:", Counter(y_train_bsmote))
print("Po ADASYN:", Counter(y_train_adasyn))

# Vizualizace účinku SMOTE na 2D podmnožině dat
def plot_2d_space(X, y, title):
    # Použití pouze prvních dvou příznaků pro vizualizaci
    plt.figure(figsize=(10, 6))
    plt.scatter(X[y == 0, 0], X[y == 0, 1], label='Třída 0', alpha=0.5)
    plt.scatter(X[y == 1, 0], X[y == 1, 1], label='Třída 1', alpha=0.5)
    plt.title(title)
    plt.xlabel('Příznak 1')
    plt.ylabel('Příznak 2')
    plt.legend()
    plt.tight_layout()

# Vykreslení původních dat
plot_2d_space(X_train, y_train, 'Původní data')
plt.show()

# Vykreslení dat nadvzorkovaných pomocí SMOTE
plot_2d_space(X_train_smote, y_train_smote, 'Nadvzorkování metodou SMOTE')
plt.show()
```

## Přístupy na úrovni algoritmů

Některé algoritmy strojového učení lze přizpůsobit pro práci s nevyváženými datovými sadami bez úpravy samotných dat.

```python
# Použití vah tříd v logistické regresi
clf_weighted = LogisticRegression(class_weight='balanced', random_state=42, max_iter=1000)
clf_weighted.fit(X_train, y_train)

# Použití vah tříd v náhodném lese
rf_weighted = RandomForestClassifier(class_weight='balanced', random_state=42)
rf_weighted.fit(X_train, y_train)

# Predikce na testovací množině
y_pred_weighted_lr = clf_weighted.predict(X_test)
y_pred_weighted_rf = rf_weighted.predict(X_test)

# Porovnání s modely bez vah
clf_unweighted = LogisticRegression(random_state=42, max_iter=1000)
clf_unweighted.fit(X_train, y_train)
y_pred_unweighted_lr = clf_unweighted.predict(X_test)

# Vypsání klasifikačních reportů
print("Logistická regrese bez vah:")
print(classification_report(y_test, y_pred_unweighted_lr))
print("\nLogistická regrese s vahami:")
print(classification_report(y_test, y_pred_weighted_lr))
print("\nNáhodný les s vahami:")
print(classification_report(y_test, y_pred_weighted_rf))
```

## Ansámblové metody pro nevyvážená data

Ansámblové metody mohou být obzvláště účinné pro nevyvážené datové sady.

```python
from imblearn.ensemble import BalancedRandomForestClassifier, EasyEnsembleClassifier, RUSBoostClassifier

# Balanced Random Forest
brf = BalancedRandomForestClassifier(random_state=42)
brf.fit(X_train, y_train)
y_pred_brf = brf.predict(X_test)

# EasyEnsemble (Bagging s podvzorkováním)
eec = EasyEnsembleClassifier(random_state=42)
eec.fit(X_train, y_train)
y_pred_eec = eec.predict(X_test)

# RUSBoost (Boosting s podvzorkováním)
rusboost = RUSBoostClassifier(random_state=42)
rusboost.fit(X_train, y_train)
y_pred_rusboost = rusboost.predict(X_test)

# Porovnání ansámblových metod
print("Balanced Random Forest:")
print(classification_report(y_test, y_pred_brf))
print("\nEasyEnsemble Classifier:")
print(classification_report(y_test, y_pred_eec))
print("\nRUSBoost Classifier:")
print(classification_report(y_test, y_pred_rusboost))
```

## Evaluační metriky pro nevyvážené datové sady

Tradiční přesnost (accuracy) není dobrou metrikou pro nevyvážené datové sady. Lepší metriky zahrnují:
- Preciznost (Precision), Úplnost (Recall), F1-skóre
- ROC křivku a AUC
- Křivku přesnost-úplnost a průměrnou preciznost
- Vyváženou přesnost

```python
# Trénování modelu na různě vyvážených datových sadách
lr_original = LogisticRegression(max_iter=1000)
lr_original.fit(X_train, y_train)

lr_smote = LogisticRegression(max_iter=1000)
lr_smote.fit(X_train_smote, y_train_smote)

# Získání predikcí a pravděpodobností
y_pred_orig = lr_original.predict(X_test)
y_proba_orig = lr_original.predict_proba(X_test)[:, 1]

y_pred_smote = lr_smote.predict(X_test)
y_proba_smote = lr_smote.predict_proba(X_test)[:, 1]

# Matice záměn
cm_orig = confusion_matrix(y_test, y_pred_orig)
cm_smote = confusion_matrix(y_test, y_pred_smote)

# Vizualizace matic záměn
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
sns.heatmap(cm_orig, annot=True, fmt='d', cmap='Blues', ax=ax1)
ax1.set_title('Matice záměn - Původní data')
ax1.set_xlabel('Predikce')
ax1.set_ylabel('Skutečnost')

sns.heatmap(cm_smote, annot=True, fmt='d', cmap='Blues', ax=ax2)
ax2.set_title('Matice záměn - SMOTE')
ax2.set_xlabel('Predikce')
ax2.set_ylabel('Skutečnost')

plt.tight_layout()
plt.show()

# ROC křivka
fpr_orig, tpr_orig, _ = roc_curve(y_test, y_proba_orig)
roc_auc_orig = auc(fpr_orig, tpr_orig)

fpr_smote, tpr_smote, _ = roc_curve(y_test, y_proba_smote)
roc_auc_smote = auc(fpr_smote, tpr_smote)

plt.figure(figsize=(10, 6))
plt.plot(fpr_orig, tpr_orig, label=f'Původní (AUC = {roc_auc_orig:.2f})')
plt.plot(fpr_smote, tpr_smote, label=f'SMOTE (AUC = {roc_auc_smote:.2f})')
plt.plot([0, 1], [0, 1], 'k--')
plt.xlabel('Míra falešně pozitivních případů')
plt.ylabel('Míra skutečně pozitivních případů')
plt.title('ROC křivka')
plt.legend()
plt.show()

# Křivka preciznost-úplnost
precision_orig, recall_orig, _ = precision_recall_curve(y_test, y_proba_orig)
ap_orig = average_precision_score(y_test, y_proba_orig)

precision_smote, recall_smote, _ = precision_recall_curve(y_test, y_proba_smote)
ap_smote = average_precision_score(y_test, y_proba_smote)

plt.figure(figsize=(10, 6))
plt.plot(recall_orig, precision_orig, label=f'Původní (AP = {ap_orig:.2f})')
plt.plot(recall_smote, precision_smote, label=f'SMOTE (AP = {ap_smote:.2f})')
plt.xlabel('Úplnost')
plt.ylabel('Preciznost')
plt.title('Křivka preciznost-úplnost')
plt.legend()
plt.show()

# Výpis klasifikačních reportů
print("Klasifikační report - Původní data:")
print(classification_report(y_test, y_pred_orig))
print("\nKlasifikační report - SMOTE:")
print(classification_report(y_test, y_pred_smote))
```

## Učení citlivé na náklady

Učení citlivé na náklady zahrnuje úpravu učícího algoritmu tak, aby zohledňoval náklady spojené s chybnou klasifikací vzorků.

```python
# Definice matice nákladů, kde chybná klasifikace minoritní třídy je dražší
# Například v případě detekce podvodů:
# - Falešně negativní (přehlédnutý podvod) může stát 1000 Kč
# - Falešně pozitivní (falešný poplach) může stát 10 Kč

from sklearn.ensemble import RandomForestClassifier

# Váhy tříd dávají vyšší důležitost minoritní třídě
# Váhy jsou nepřímo úměrné frekvencím tříd
class_weights = {0: 1, 1: 9}  # Za předpokladu poměru tříd 90:10

# Náhodný les citlivý na náklady
rf_cost = RandomForestClassifier(
    random_state=42,
    class_weight=class_weights
)
rf_cost.fit(X_train, y_train)
y_pred_cost = rf_cost.predict(X_test)

# Predikce pravděpodobností
y_proba_cost = rf_cost.predict_proba(X_test)[:, 1]

# Vytvoření predikce upravené prahem
# (Snížení prahu pro zvýšení úplnosti pro pozitivní třídu)
custom_threshold = 0.3  # Standardně je 0.5
y_pred_threshold = (y_proba_cost >= custom_threshold).astype(int)

# Vyhodnocení
print("Standardní náhodný les:")
print(classification_report(y_test, y_pred_weighted_rf))
print("\nNáhodný les citlivý na náklady:")
print(classification_report(y_test, y_pred_cost))
print("\nPredikce upravené prahem (t=0.3):")
print(classification_report(y_test, y_pred_threshold))
```

## Případové studie: Detekce úvěrových podvodů

Projděme si zjednodušenou případovou studii detekce úvěrových podvodů:

```python
# Načtení běžné datové sady pro nevyvážené učení
# (pokud máte přístup k internetu, jinak použijte syntetická data)

try:
    # Pokus o načtení datové sady o podvodech s kreditními kartami (je-li k dispozici)
    from sklearn.datasets import fetch_openml
    dataset = fetch_openml("credit-card-fraud", version=1, as_frame=True)
    
    # Použití podmnožiny pro demonstraci
    credit_data = dataset.data.sample(10000, random_state=42)
    credit_target = dataset.target.loc[credit_data.index]
    credit_target = credit_target.astype(int)
    
    print(f"Tvar datové sady: {credit_data.shape}")
    print(f"Rozložení tříd: {Counter(credit_target)}")
    
except:
    # Vytvoření syntetické datové sady o podvodech, pokud skutečná není k dispozici
    print("Používám syntetickou datovou sadu o podvodech...")
    
    # Vytvoření realističtějších dat o podvodech (0.5% podvodů)
    X_fraud, y_fraud = make_classification(
        n_samples=10000,
        n_features=30,
        n_informative=15,
        n_redundant=10,
        n_clusters_per_class=1,
        weights=[0.995, 0.005],  # 0.5% podvodů
        random_state=42
    )
    
    credit_data = pd.DataFrame(X_fraud, columns=[f'feature_{i}' for i in range(X_fraud.shape[1])])
    credit_target = pd.Series(y_fraud)
    
    print(f"Tvar syntetické datové sady: {credit_data.shape}")
    print(f"Rozložení tříd: {Counter(credit_target)}")

# Rozdělení dat
X_train, X_test, y_train, y_test = train_test_split(
    credit_data, credit_target, test_size=0.3, 
    random_state=42, stratify=credit_target
)

# Aplikace SMOTE
smote = SMOTE(random_state=42)
X_train_smote, y_train_smote = smote.fit_resample(X_train, y_train)

# Trénování modelů
rf_baseline = RandomForestClassifier(random_state=42)
rf_baseline.fit(X_train, y_train)

rf_smote = RandomForestClassifier(random_state=42)
rf_smote.fit(X_train_smote, y_train_smote)

rf_weighted = RandomForestClassifier(class_weight='balanced', random_state=42)
rf_weighted.fit(X_train, y_train)

# Získání predikcí
y_pred_baseline = rf_baseline.predict(X_test)
y_pred_smote = rf_smote.predict(X_test)
y_pred_weighted = rf_weighted.predict(X_test)

# Porovnání výsledků
print("\nZákladní náhodný les:")
print(classification_report(y_test, y_pred_baseline))
print("\nSMOTE náhodný les:")
print(classification_report(y_test, y_pred_smote))
print("\nVážený náhodný les:")
print(classification_report(y_test, y_pred_weighted))

# Zobrazení ROC křivek
plt.figure(figsize=(10, 6))
for model, name, y_pred in [
    (rf_baseline, 'Základní', y_pred_baseline), 
    (rf_smote, 'SMOTE', y_pred_smote), 
    (rf_weighted, 'Vážený', y_pred_weighted)
]:
    proba = model.predict_proba(X_test)[:, 1]
    fpr, tpr, _ = roc_curve(y_test, proba)
    roc_auc = auc(fpr, tpr)
    plt.plot(fpr, tpr, label=f'{name} (AUC = {roc_auc:.3f})')

plt.plot([0, 1], [0, 1], 'k--')
plt.xlabel('Míra falešně pozitivních případů')
plt.ylabel('Míra skutečně pozitivních případů')
plt.title('Porovnání ROC křivek')
plt.legend()
plt.show()
```

## Shrnutí

Řešení nevyvážených datových sad je klíčové pro vytváření efektivních modelů v situacích, kde je minoritní třída často třídou zájmu. Klíčové přístupy zahrnují:

1. **Metody na úrovni dat**:
   - Náhodné podvzorkování a nadvzorkování
   - SMOTE a jeho varianty (BorderlineSMOTE, ADASYN)
   - Hybridní metody kombinující podvzorkování a nadvzorkování

2. **Metody na úrovni algoritmů**:
   - Úprava vah tříd
   - Učení citlivé na náklady
   - Přizpůsobení prahové hodnoty
   - Specializované ansámblové metody (BalancedRandomForest, EasyEnsemble, RUSBoost)

3. **Strategie vyhodnocení**:
   - Preciznost, úplnost, F1-skóre místo přesnosti
   - ROC křivky a AUC
   - Křivky preciznost-úplnost
   - Vyvážená přesnost

Při práci s nevyváženými datovými sadami:
- Vždy prozkoumejte svá data, abyste pochopili rozsah nevyváženosti
- Používejte stratifikované vzorkování pro rozdělení dat na trénovací a testovací množiny, aby byl zachován poměr tříd
- Vyberte vhodné evaluační metriky
- Zvažte obchodní dopad falešně pozitivních vs. falešně negativních výsledků
- Experimentujte s více přístupy a porovnávejte výsledky
- Buďte opatrní ohledně přetrénování, zejména při technikách nadvzorkování

Učení s nevyváženými daty zůstává aktivní oblastí výzkumu, přičemž nové techniky jsou neustále vyvíjeny k řešení tohoto běžného, ale náročného problému v aplikacích strojového učení v reálném světě.
