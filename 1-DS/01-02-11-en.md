## Introduction to A/B Testing

A/B testing, also known as split testing, is a randomized controlled experiment used to compare two or more versions of a variable to determine which one performs better. In data science, A/B testing is widely used to make data-driven decisions in marketing, product development, UX design, and more.


## Statistical Foundations

A/B testing relies on statistical hypothesis testing to determine if observed differences between variants are statistically significant. The process typically involves:

1. Formulating a null hypothesis (H₀): There's no difference between variants
2. Setting an alternative hypothesis (H₁): There's a significant difference
3. Collecting data
4. Calculating p-values
5. Making a decision based on a predetermined significance level (usually α = 0.05)

```python
import scipy.stats as stats

# Continuing from our sample data
# Extract conversion data for each group
conversions_a = ab_data[ab_data['group'] == 'A']['converted']
conversions_b = ab_data[ab_data['group'] == 'B']['converted']

# Perform a two-proportion z-test
count_a = sum(conversions_a)
count_b = sum(conversions_b)
nobs_a = len(conversions_a)
nobs_b = len(conversions_b)

z_stat, p_value = stats.proportions_ztest([count_b, count_a], [nobs_b, nobs_a], alternative='larger')

print(f"Z-statistic: {z_stat:.3f}")
print(f"P-value: {p_value:.3f}")

# Interpret the results
alpha = 0.05
if p_value < alpha:
    print("Reject the null hypothesis: Version B performs better than Version A")
else:
    print("Fail to reject the null hypothesis: No significant evidence that Version B is better")

# Calculate confidence intervals
def confidence_interval(successes, trials, confidence=0.95):
    """Calculate confidence interval for a proportion."""
    p = successes / trials
    z = stats.norm.ppf(1 - (1 - confidence) / 2)
    std_err = np.sqrt(p * (1 - p) / trials)
    margin = z * std_err
    return (p - margin, p + margin)

ci_a = confidence_interval(count_a, nobs_a)
ci_b = confidence_interval(count_b, nobs_b)

print(f"\nGroup A 95% confidence interval: ({ci_a[0]:.3f}, {ci_a[1]:.3f})")
print(f"Group B 95% confidence interval: ({ci_b[0]:.3f}, {ci_b[1]:.3f})")
```

## Setting Up an A/B Test

Proper experimental design is crucial for valid A/B testing. This includes:
- Defining clear metrics
- Ensuring random assignment
- Controlling for external factors
- Determining the experiment duration

```python
import random
from datetime import datetime, timedelta

# Example of setting up an A/B test experiment
class ABTestSetup:
    def __init__(self, user_ids, test_name, start_date=None, duration_days=14):
        self.user_ids = user_ids
        self.test_name = test_name
        self.start_date = start_date or datetime.now()
        self.end_date = self.start_date + timedelta(days=duration_days)
        self.assignments = {}
        self.results = pd.DataFrame()
        
    def assign_users(self, variants=None, split=None):
        """Randomly assign users to test variants."""
        if variants is None:
            variants = ['control', 'treatment']
        
        if split is None:
            split = [0.5, 0.5]  # Equal split by default
            
        if len(variants) != len(split) or sum(split) != 1.0:
            raise ValueError("Split proportions must sum to 1.0 and match variants count")
            
        # Shuffle user IDs to ensure randomness
        random.shuffle(self.user_ids)
        
        # Calculate user counts for each variant
        total_users = len(self.user_ids)
        user_counts = [int(total_users * proportion) for proportion in split]
        user_counts[-1] += total_users - sum(user_counts)  # Ensure all users are assigned
        
        # Assign users to variants
        start_idx = 0
        for variant, count in zip(variants, user_counts):
            end_idx = start_idx + count
            variant_users = self.user_ids[start_idx:end_idx]
            for user_id in variant_users:
                self.assignments[user_id] = variant
            start_idx = end_idx
            
        # Create assignment DataFrame
        self.assignment_df = pd.DataFrame({
            'user_id': list(self.assignments.keys()),
            'variant': list(self.assignments.values())
        })
        
        return self.assignment_df
        
    def get_test_info(self):
        """Return test information."""
        variant_counts = self.assignment_df['variant'].value_counts().to_dict()
        return {
            'test_name': self.test_name,
            'start_date': self.start_date,
            'end_date': self.end_date,
            'total_users': len(self.user_ids),
            'variant_distribution': variant_counts
        }

# Example usage
user_ids = list(range(1000, 2000))
test = ABTestSetup(user_ids, "Homepage Redesign", duration_days=21)
assignments = test.assign_users(variants=['old_design', 'new_design'], split=[0.5, 0.5])
test_info = test.get_test_info()

print("A/B Test Setup:")
print(f"Test name: {test_info['test_name']}")
print(f"Duration: {test_info['start_date']} to {test_info['end_date']}")
print(f"Total users: {test_info['total_users']}")
print("Variant distribution:")
for variant, count in test_info['variant_distribution'].items():
    print(f"  {variant}: {count} users ({count/test_info['total_users']*100:.1f}%)")
```

## Sample Size Calculation

Determining the appropriate sample size before running an A/B test is crucial. It ensures the test has enough statistical power to detect meaningful differences.

```python
from statsmodels.stats.power import TTestIndPower, proportion_effectsize

def calculate_sample_size_for_proportions(baseline_rate, mde, alpha=0.05, power=0.8):
    """
    Calculate sample size needed for detecting a minimum detectable effect (MDE)
    in a proportion or conversion rate test.
    
    Parameters:
    baseline_rate: Current conversion rate (control group)
    mde: Minimum detectable effect (relative change, e.g., 0.1 for 10% improvement)
    alpha: Significance level (Type I error rate)
    power: 1 - Type II error rate (probability of detecting an effect if it exists)
    
    Returns:
    required_sample_size: Sample size required per group
    """
    # Calculate the expected conversion rate for the treatment group
    expected_rate = baseline_rate * (1 + mde)
    
    # Calculate effect size using cohens_h
    effect_size = proportion_effectsize(baseline_rate, expected_rate)
    
    # Initialize power analysis
    analysis = TTestIndPower()
    
    # Calculate sample size
    result = analysis.solve_power(effect_size=effect_size, 
                                  alpha=alpha, 
                                  power=power, 
                                  alternative='two-sided')
    
    return int(np.ceil(result))

# Example usage
baseline_conv_rate = 0.05  # 5% baseline conversion rate
minimum_detectable_effect = 0.2  # Want to detect a 20% relative improvement
alpha = 0.05  # 5% significance level
power = 0.8  # 80% power

sample_size = calculate_sample_size_for_proportions(
    baseline_conv_rate, 
    minimum_detectable_effect, 
    alpha, 
    power
)

print(f"Baseline conversion rate: {baseline_conv_rate:.1%}")
print(f"Minimum detectable effect: {minimum_detectable_effect:.1%}")
print(f"Required sample size per group: {sample_size:,} users")

# Visualize the relationship between MDE and required sample size
mde_values = np.linspace(0.05, 0.5, 10)  # 5% to 50% MDE
sample_sizes = [calculate_sample_size_for_proportions(baseline_conv_rate, mde) 
               for mde in mde_values]

plt.figure(figsize=(10, 6))
plt.plot(mde_values * 100, sample_sizes, marker='o', linestyle='-')
plt.title('Sample Size vs. Minimum Detectable Effect')
plt.xlabel('Minimum Detectable Effect (%)')
plt.ylabel('Required Sample Size per Group')
plt.grid(True, linestyle='--', alpha=0.7)
plt.xticks(mde_values * 100)
plt.ticklabel_format(style='plain', axis='y')
plt.tight_layout()
plt.show()
```

```python
# Simulate a more realistic A/B test dataset
np.random.seed(42)

def simulate_user_data(n_users, days=14):
    """Simulate user data for an A/B test"""
    # User IDs
    user_ids = range(1, n_users + 1)
    
    # Randomly assign users to groups
    groups = np.random.choice(['A', 'B'], size=n_users)
    
    # Probability of converting is higher in Group B
    p_convert_a = 0.05  # 5% baseline conversion rate
    p_convert_b = 0.065  # 6.5% conversion rate in treatment
    
    # Generate conversion data
    conversions = []
    for group in groups:
        if group == 'A':
            conversions.append(1 if np.random.random() < p_convert_a else 0)
        else:
            conversions.append(1 if np.random.random() < p_convert_b else 0)
    
    # Generate revenue data (only for converting users)
    revenues = []
    for conv in conversions:
        if conv == 1:
            # Group B has slightly higher average order value
            if groups[len(revenues)] == 'A':
                revenues.append(np.random.normal(50, 15))
            else:
                revenues.append(np.random.normal(55, 15))
        else:
            revenues.append(0)
    
    # Dates of experiment
    start_date = pd.Timestamp('2023-01-01')
    dates = []
    for _ in range(n_users):
        days_offset = np.random.randint(0, days)
        dates.append(start_date + pd.Timedelta(days=days_offset))
    
    # Create DataFrame
    df = pd.DataFrame({
        'user_id': user_ids,
        'date': dates,
        'group': groups,
        'converted': conversions,
        'revenue': revenues
    })
    
    return df

nobs_b = len(group_b)

print(f"\nZ-test for proportion difference:")
print(f"z-statistic: {z_stat:.3f}")
print(f"p-value: {p_value:.3f}")
print(f"Statistically significant difference? {'Yes' if p_value < 0.05 else 'No'}")

ci_b = proportion_confint(count_b, nobs_b)
print(f"\nGroup A conversion rate: {count_a/nobs_a:.3f} [{ci_a[0]:.3f}, {ci_a[1]:.3f}]")
```

## Common Pitfalls and Challenges

A/B testing comes with several challenges that can lead to incorrect conclusions if not addressed properly:

1. Peeking at results before test completion
2. Multiple testing problem
3. Simpson's paradox
4. Selection bias
5. External validity concerns

```python
# Demonstrate the "peeking problem" with simulated data
np.random.seed(123)

def simulate_ab_test_over_time(n_days=30, daily_users=200, true_diff=0):
    """
    Simulate an A/B test over time to demonstrate the peeking problem
    
    Parameters:
    n_days: Number of days to run the test
    daily_users: Number of users per day
    true_diff: True difference in conversion rates
    """
    results = []
    
    # Baseline conversion rate
    p_a = 0.10
    p_b = p_a + true_diff
    
    for day in range(1, n_days + 1):
        # Generate daily data
        group_a_users = int(daily_users / 2)
        group_b_users = daily_users - group_a_users
        
        conv_a = np.random.binomial(1, p_a, size=group_a_users)
        conv_b = np.random.binomial(1, p_b, size=group_b_users)
        
        # Calculate daily metrics
        daily_conv_a = conv_a.mean()
        daily_conv_b = conv_b.mean()
        
        # Add to results
        results.append({
            'day': day,
            'group_a_conv': daily_conv_a,
            'group_b_conv': daily_conv_b,
            'group_a_users': group_a_users,
            'group_b_users': group_b_users,
            'group_a_total': np.sum(conv_a),
            'group_b_total': np.sum(conv_b)
        })
    
    # Convert to DataFrame
    results_df = pd.DataFrame(results)
    
    # Calculate cumulative metrics
    results_df['cum_a_users'] = results_df['group_a_users'].cumsum()
    results_df['cum_b_users'] = results_df['group_b_users'].cumsum()
    results_df['cum_a_conv'] = results_df['group_a_total'].cumsum()
    results_df['cum_b_conv'] = results_df['group_b_total'].cumsum()
    results_df['cum_a_rate'] = results_df['cum_a_conv'] / results_df['cum_a_users']
    results_df['cum_b_rate'] = results_df['cum_b_conv'] / results_df['cum_b_users']
    
    # Calculate p-values over time
    p_values = []
    
    for idx, row in results_df.iterrows():
        count_a = row['cum_a_conv']
        count_b = row['cum_b_conv']
        nobs_a = row['cum_a_users']
        nobs_b = row['cum_b_users']
        
        # Calculate p-value
        z, p_value = proportions_ztest([count_b, count_a], [nobs_b, nobs_a])
        p_values.append(p_value)
    
    results_df['p_value'] = p_values
    results_df['significant'] = results_df['p_value'] < 0.05
    
    return results_df

# Run simulation with no true difference (should not be significant)
```

## Bayesian A/B Testing

While classical frequentist A/B testing focuses on hypothesis testing and p-values, Bayesian A/B testing offers an alternative approach based on probability distributions and direct estimates of the difference between variants.

```python
import pymc3 as pm
import arviz as az

# Simulated data (using our previous dataset)
a_trials = len(group_a)
a_successes = group_a['converted'].sum()
b_trials = len(group_b)
b_successes = group_b['converted'].sum()

# Bayesian A/B test using PyMC3
with pm.Model() as model:
    # Priors
    p_a = pm.Beta('p_a', alpha=1, beta=1)  # Uniform prior
    p_b = pm.Beta('p_b', alpha=1, beta=1)  # Uniform prior
    
    # Likelihood
    obs_a = pm.Binomial('obs_a', n=a_trials, p=p_a, observed=a_successes)
    obs_b = pm.Binomial('obs_b', n=b_trials, p=p_b, observed=b_successes)
    
    # Derived quantities
    delta = pm.Deterministic('delta', p_b - p_a)  # Absolute difference
    rel_lift = pm.Deterministic('rel_lift', (p_b - p_a) / p_a)  # Relative lift
    
    # Sample from the posterior
    trace = pm.sample(5000, tune=1000, cores=1, random_seed=42)

# Analyze results
summary = az.summary(trace)
print("\nBayesian A/B Test Results:")
print(summary)

# Probability that B is better than A
prob_b_better = (trace['delta'] > 0).mean()
print(f"\nProbability that B is better than A: {prob_b_better:.1%}")

# Expected lift
expected_abs_lift = trace['delta'].mean()
expected_rel_lift = trace['rel_lift'].mean()
print(f"Expected absolute lift: {expected_abs_lift:.4f}")
print(f"Expected relative lift: {expected_rel_lift:.2%}")

# Plot posterior distributions
plt.figure(figsize=(12, 6))

plt.subplot(1, 2, 1)
az.plot_posterior(trace, var_names=['p_a', 'p_b'], hdi_prob=0.95)
plt.title('Conversion Rate Posteriors')

plt.subplot(1, 2, 2)
az.plot_posterior(trace, var_names=['delta'], hdi_prob=0.95)
plt.axvline(x=0, color='r', linestyle='--')
plt.title('Posterior Distribution of Difference (B - A)')

plt.tight_layout()
plt.show()
```

## Multivariate Testing

Multivariate testing extends A/B testing by testing multiple variables simultaneously, allowing for the investigation of interaction effects between different elements.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols
import matplotlib.pyplot as plt
import seaborn as sns

# Simulate multivariate test data
np.random.seed(42)

def simulate_multivariate_test(n_users=5000):
    """
    Simulate data for a multivariate test with 2 factors:
    - Button Color: Blue vs. Green
    - Headline: Short vs. Long
    """
    # Factors
    button_color = np.random.choice(['Blue', 'Green'], size=n_users)
    headline = np.random.choice(['Short', 'Long'], size=n_users)
    
    # Base conversion rate
    base_rate = 0.05
    
    # Define effects
    color_effect = {'Blue': 0, 'Green': 0.01}  # Green gives +1% conversion
    headline_effect = {'Short': 0, 'Long': 0.015}  # Long gives +1.5% conversion
    
    # Interaction effect (additional effect when both Green and Long)
    interaction_effect = 0.005  # +0.5% extra when both Green and Long
    
    # Calculate conversion probabilities
    conversion_probs = []
    
    for i in range(n_users):
        prob = base_rate + color_effect[button_color[i]] + headline_effect[headline[i]]
        # Add interaction effect if applicable
        if button_color[i] == 'Green' and headline[i] == 'Long':
            prob += interaction_effect
        conversion_probs.append(prob)
    
    # Generate conversions
```

## Summary

A/B testing is a fundamental technique in data science that enables data-driven decision making through controlled experiments. Key takeaways include:

1. **Foundation**: A/B testing allows comparing two or more variants to identify which performs better based on defined metrics.

2. **Statistical Rigor**: Proper A/B testing requires understanding of statistical concepts such as hypothesis testing, p-values, and confidence intervals.

3. **Experimental Design**: Careful design is crucial, including random assignment, adequate sample size determination, and selection of appropriate metrics.

4. **Implementation**: Python provides robust libraries for implementing A/B tests, from simple proportion tests to more complex multivariate analyses.

5. **Analysis**: Proper analysis includes not only determining statistical significance but also estimating effect sizes and confidence intervals.

6. **Pitfalls**: Common challenges include peeking at results too early, multiple testing problems, and various biases that can affect result validity.

7. **Bayesian Approach**: Bayesian A/B testing offers an alternative framework focused on probability distributions rather than hypothesis testing.

8. **Multivariate Testing**: Extending beyond simple A/B tests allows testing multiple variables simultaneously and identifying interaction effects.

9. **Business Impact**: Effective A/B testing translates statistical findings into actionable business decisions and measurable improvements.

10. **Iteration**: A/B testing is not a one-time effort but an ongoing process of experimentation and refinement guided by data.

When implemented correctly, A/B testing provides a scientific framework for making improvements to products, websites, marketing campaigns, and more, ultimately leading to better user experiences and business outcomes.
