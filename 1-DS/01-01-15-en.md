## 1. Introduction to Data Distributions

Understanding data distributions is fundamental to data science. A distribution describes how data is spread out or arranged, providing insights into the underlying patterns and characteristics of your dataset.

```python
# Import essential libraries
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
import warnings
warnings.filterwarnings('ignore')

# Set visualization style
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_style("whitegrid")
```

Let's create some sample data to explore distributions:

```python
# Set random seed for reproducibility
np.random.seed(42)

# Generate a normal distribution
normal_data = np.random.normal(loc=0, scale=1, size=1000)

# Generate a uniform distribution
uniform_data = np.random.uniform(low=-3, high=3, size=1000)

# Generate a skewed distribution (log-normal)
lognormal_data = np.random.lognormal(mean=0, sigma=0.5, size=1000)

# Create a pandas DataFrame to store our distributions
distributions_df = pd.DataFrame({
    'Normal': normal_data,
    'Uniform': uniform_data,
    'LogNormal': lognormal_data
})

# Display basic statistics for each distribution
print(distributions_df.describe())
```

## 2. Common Probability Distributions

Several probability distributions are commonly encountered in data science:

1. **Normal (Gaussian) Distribution**: The famous bell curve that appears in many natural phenomena
2. **Uniform Distribution**: Equal probability across all values in a range
3. **Binomial Distribution**: Discrete distribution for number of successes in n independent trials
4. **Poisson Distribution**: Discrete distribution for number of events in a fixed interval
5. **Exponential Distribution**: Continuous distribution for time between events
6. **Log-Normal Distribution**: Distribution of a variable whose logarithm follows a normal distribution

```python
# Generate examples of different distributions
n_samples = 1000

# Normal distribution
normal = np.random.normal(loc=0, scale=1, size=n_samples)

# Uniform distribution
uniform = np.random.uniform(low=-3, high=3, size=n_samples)

# Binomial distribution (10 trials, 0.5 probability of success)
binomial = np.random.binomial(n=10, p=0.5, size=n_samples)

# Poisson distribution (lambda = 3)
poisson = np.random.poisson(lam=3, size=n_samples)

# Exponential distribution (scale = 1/lambda = 1/0.5 = 2)
exponential = np.random.exponential(scale=2, size=n_samples)

# Log-normal distribution
lognormal = np.random.lognormal(mean=0, sigma=0.5, size=n_samples)

# Visualize these distributions using histograms
fig, axs = plt.subplots(3, 2, figsize=(14, 12))
axs = axs.ravel()

distributions = [normal, uniform, binomial, poisson, exponential, lognormal]
titles = ['Normal', 'Uniform', 'Binomial', 'Poisson', 'Exponential', 'Log-Normal']

for i, (data, title) in enumerate(zip(distributions, titles)):
    sns.histplot(data, kde=True, ax=axs[i])
    axs[i].set_title(f'{title} Distribution')
    axs[i].set_ylabel('Frequency')

plt.tight_layout()
plt.show()
```

## 3. Visualizing Distributions

There are various ways to visualize distributions, each highlighting different aspects of your data:

1. **Histograms**: Show the frequency distribution of a dataset
2. **Kernel Density Plots**: Smooth representation of the distribution
3. **Box Plots**: Highlight the median, quartiles, and outliers
4. **Q-Q Plots**: Compare a sample distribution to a theoretical distribution
5. **ECDF (Empirical Cumulative Distribution Function)**: Plot the cumulative probability

```python
# Create a larger dataset for visualization
np.random.seed(42)
data = np.concatenate([
    np.random.normal(0, 1, 1000),    # Standard normal
    np.random.normal(4, 1, 500)      # Shifted normal
])

fig, axs = plt.subplots(2, 3, figsize=(18, 10))

# Histogram
sns.histplot(data, kde=False, ax=axs[0, 0])
axs[0, 0].set_title('Histogram')

# Kernel Density Plot
sns.kdeplot(data, ax=axs[0, 1])
axs[0, 1].set_title('Kernel Density Plot')

# Box Plot
sns.boxplot(y=data, ax=axs[0, 2])
axs[0, 2].set_title('Box Plot')

# Violin Plot
sns.violinplot(y=data, ax=axs[1, 0])
axs[1, 0].set_title('Violin Plot')

# Q-Q Plot
from scipy import stats
stats.probplot(data, plot=axs[1, 1])
axs[1, 1].set_title('Q-Q Plot')

# ECDF
def ecdf(data):
    x = np.sort(data)
    y = np.arange(1, len(data) + 1) / len(data)
    return x, y

x, y = ecdf(data)
axs[1, 2].plot(x, y, marker='.', linestyle='none')
axs[1, 2].set_title('ECDF Plot')
axs[1, 2].set_xlabel('Value')
axs[1, 2].set_ylabel('Cumulative Probability')

plt.tight_layout()
plt.show()
```

## 4. Testing for Normality

Many statistical methods assume that data follows a normal distribution. Several tests can check if your data is normally distributed:

1. **Visual methods**: Histograms, Q-Q plots
2. **Statistical tests**: Shapiro-Wilk test, Anderson-Darling test, D'Agostino-Pearson test

```python
# Generate some sample data distributions to test
np.random.seed(42)
normal_sample = np.random.normal(loc=0, scale=1, size=100)
skewed_sample = np.random.exponential(scale=1, size=100)
bimodal_sample = np.concatenate([np.random.normal(-2, 0.5, 50), np.random.normal(2, 0.5, 50)])

# Function to test normality using multiple methods
def test_normality(data, name):
    print(f"Testing normality for {name} distribution:")
    
    # Shapiro-Wilk test
    stat, p_value = stats.shapiro(data)
    print(f"Shapiro-Wilk test: statistic={stat:.4f}, p-value={p_value:.4f}")
    print(f"{'Data looks normal' if p_value > 0.05 else 'Data does not look normal'} (Shapiro-Wilk)")
    
    # Anderson-Darling test
    result = stats.anderson(data, dist='norm')
    print(f"Anderson-Darling test: statistic={result.statistic:.4f}")
    
    # D'Agostino and Pearson's test
    stat, p_value = stats.normaltest(data)
    print(f"D'Agostino-Pearson test: statistic={stat:.4f}, p-value={p_value:.4f}")
    print(f"{'Data looks normal' if p_value > 0.05 else 'Data does not look normal'} (D'Agostino-Pearson)")
    
    # Visual inspection with Q-Q plot
    plt.figure(figsize=(12, 4))
    plt.subplot(1, 2, 1)
    sns.histplot(data, kde=True)
    plt.title(f'{name} - Histogram with KDE')
    
    plt.subplot(1, 2, 2)
    stats.probplot(data, plot=plt)
    plt.title(f'{name} - Q-Q Plot')
    plt.tight_layout()
    plt.show()
    print("\n")

# Test our distributions
test_normality(normal_sample, "Normal")
test_normality(skewed_sample, "Right-skewed")
test_normality(bimodal_sample, "Bimodal")
```

## 5. Working with Skewed Distributions

Skewed distributions are asymmetric, with the data concentrated on one side. Two common approaches to handle skewed data are:

1. **Transformations**: Convert skewed data to more normal-like distributions
2. **Robust statistics**: Use metrics less affected by skewness (median vs mean)

```python
# Generate right-skewed data
np.random.seed(42)
skewed_data = np.random.lognormal(mean=0, sigma=1, size=1000)

# Function to show distribution before and after transformation
def plot_transformation(original_data, transformed_data, transform_name):
    fig, axs = plt.subplots(1, 2, figsize=(14, 5))
    
    # Original distribution
    sns.histplot(original_data, kde=True, ax=axs[0])
    axs[0].set_title('Original Skewed Distribution')
    axs[0].set_ylabel('Frequency')
    
    # Display original data statistics
    mean = np.mean(original_data)
    median = np.median(original_data)
    skew = stats.skew(original_data)
    axs[0].axvline(mean, color='red', linestyle='--', label=f'Mean: {mean:.2f}')
    axs[0].axvline(median, color='green', linestyle='--', label=f'Median: {median:.2f}')
    axs[0].legend()
    axs[0].text(0.7, 0.85, f'Skewness: {skew:.2f}', transform=axs[0].transAxes)
    
    # Transformed distribution
    sns.histplot(transformed_data, kde=True, ax=axs[1])
    axs[1].set_title(f'After {transform_name} Transformation')
    
    # Display transformed data statistics
    mean = np.mean(transformed_data)
    median = np.median(transformed_data)
    skew = stats.skew(transformed_data)
    axs[1].axvline(mean, color='red', linestyle='--', label=f'Mean: {mean:.2f}')
    axs[1].axvline(median, color='green', linestyle='--', label=f'Median: {median:.2f}')
    axs[1].legend()
    axs[1].text(0.7, 0.85, f'Skewness: {skew:.2f}', transform=axs[1].transAxes)
    
    plt.tight_layout()
    plt.show()

# Apply and visualize different transformations
# 1. Log transformation
log_transformed = np.log1p(skewed_data)  # log(1+x) to handle zeros
plot_transformation(skewed_data, log_transformed, 'Log')

# 2. Square root transformation
sqrt_transformed = np.sqrt(skewed_data)
plot_transformation(skewed_data, sqrt_transformed, 'Square Root')

# 3. Box-Cox transformation
boxcox_transformed, lambda_val = stats.boxcox(skewed_data)
plot_transformation(skewed_data, boxcox_transformed, f'Box-Cox (lambda={lambda_val:.2f})')
```

## 6. Identifying Outliers

Outliers are extreme values that deviate significantly from other observations. They can affect statistical analyses and should be identified and handled appropriately.

```python
# Generate data with outliers
np.random.seed(42)
data = np.random.normal(loc=0, scale=1, size=100)
# Add some outliers
outliers = np.array([6, 7, -8, 9, -7.5])
contaminated_data = np.concatenate([data, outliers])

# Define functions to detect outliers
def detect_outliers_zscore(data, threshold=3):
    """Detect outliers using Z-score"""
    z_scores = np.abs(stats.zscore(data))
    return np.where(z_scores > threshold)[0], z_scores

def detect_outliers_iqr(data):
    """Detect outliers using IQR method"""
    q1 = np.percentile(data, 25)
    q3 = np.percentile(data, 75)
    iqr = q3 - q1
    lower_bound = q1 - (1.5 * iqr)
    upper_bound = q3 + (1.5 * iqr)
    return np.where((data < lower_bound) | (data > upper_bound))[0]

# Detect outliers using different methods
zscore_outliers, z_scores = detect_outliers_zscore(contaminated_data)
iqr_outliers = detect_outliers_iqr(contaminated_data)

print("Outliers detected using Z-score method:")
print(f"Outlier indices: {zscore_outliers}")
print(f"Outlier values: {contaminated_data[zscore_outliers]}")

print("\nOutliers detected using IQR method:")
print(f"Outlier indices: {iqr_outliers}")
print(f"Outlier values: {contaminated_data[iqr_outliers]}")

# Visualize the data with outliers highlighted
plt.figure(figsize=(12, 6))

# Boxplot
plt.subplot(1, 2, 1)
sns.boxplot(y=contaminated_data)
plt.title('Boxplot with Outliers')
plt.ylabel('Value')

# Scatter plot with outliers highlighted
plt.subplot(1, 2, 2)
plt.scatter(range(len(contaminated_data)), contaminated_data, alpha=0.7, label='Normal')
plt.scatter(zscore_outliers, contaminated_data[zscore_outliers], color='red', 
            label='Z-score Outliers', s=100, edgecolor='k')
plt.title('Outliers Detection using Z-score')
plt.xlabel('Index')
plt.ylabel('Value')
plt.legend()

plt.tight_layout()
plt.show()
```

## 7. Comparing Distributions

Often, you need to compare different distributions to determine if they come from the same underlying population or if a treatment had an effect.

```python
# Generate two sample distributions
np.random.seed(42)
sample1 = np.random.normal(loc=0, scale=1, size=100)
sample2 = np.random.normal(loc=0.5, scale=1.2, size=100)

# Visualize samples for comparison
plt.figure(figsize=(12, 6))

# Histograms overlaid
plt.subplot(1, 2, 1)
sns.histplot(sample1, kde=True, color='blue', alpha=0.5, label='Sample 1')
sns.histplot(sample2, kde=True, color='red', alpha=0.5, label='Sample 2')
plt.title('Histogram Comparison')
plt.legend()

# Empirical Cumulative Distribution Function (ECDF)
plt.subplot(1, 2, 2)
# Calculate ECDF
x1, y1 = ecdf(sample1)
x2, y2 = ecdf(sample2)
plt.plot(x1, y1, marker='.', markersize=5, linestyle='none', alpha=0.5, label='Sample 1')
plt.plot(x2, y2, marker='.', markersize=5, linestyle='none', alpha=0.5, label='Sample 2')
plt.title('ECDF Comparison')
plt.xlabel('Value')
plt.ylabel('Cumulative Probability')
plt.legend()

plt.tight_layout()
plt.show()

# Statistical tests for comparing distributions

# 1. Student's t-test (for comparing means of two samples)
t_stat, t_pvalue = stats.ttest_ind(sample1, sample2)
print(f"Student's t-test: statistic={t_stat:.4f}, p-value={t_pvalue:.4f}")
print(f"{'Means are significantly different' if t_pvalue < 0.05 else 'Means are not significantly different'}")

# 2. Kolmogorov-Smirnov test (compares entire distributions)
ks_stat, ks_pvalue = stats.ks_2samp(sample1, sample2)
print(f"\nKolmogorov-Smirnov test: statistic={ks_stat:.4f}, p-value={ks_pvalue:.4f}")
print(f"{'Distributions are significantly different' if ks_pvalue < 0.05 else 'Distributions are not significantly different'}")

# 3. Mann-Whitney U test (compares distributions without assuming normality)
mw_stat, mw_pvalue = stats.mannwhitneyu(sample1, sample2)
print(f"\nMann-Whitney U test: statistic={mw_stat:.4f}, p-value={mw_pvalue:.4f}")
print(f"{'Distributions are significantly different' if mw_pvalue < 0.05 else 'Distributions are not significantly different'}")
```

## 8. Distribution Fitting

Distribution fitting is the process of finding a statistical distribution that best fits your data. This can help you understand the underlying data generation process and make better statistical inferences.

```python
# Generate a sample dataset
np.random.seed(42)
data = np.random.gamma(shape=2, scale=2, size=1000)

# Plot the histogram of the data
plt.figure(figsize=(12, 6))
counts, bins, _ = plt.hist(data, bins=30, density=True, alpha=0.6, color='g', label='Actual data')
plt.title('Fitting Distributions to Data')
plt.xlabel('Value')
plt.ylabel('Density')

# Try to fit several distributions
distributions = [
    stats.norm, stats.gamma, stats.lognorm, stats.expon
]
dist_names = ['Normal', 'Gamma', 'Log-Normal', 'Exponential']
colors = ['r', 'b', 'purple', 'orange']

# Plot the fitted distributions
for dist, name, color in zip(distributions, dist_names, colors):
    # Fit distribution to data
    params = dist.fit(data)
    
    # Get the fitted PDF
    arg_params = params[:-2]
    loc = params[-2]
    scale = params[-1]
    
    # Calculate AIC (Akaike Information Criterion) for goodness of fit
    log_likelihood = np.sum(dist.logpdf(data, *arg_params, loc=loc, scale=scale))
    n_params = len(params)
    aic = 2 * n_params - 2 * log_likelihood
    
    # Generate points for the fitted PDF
    x = np.linspace(min(bins), max(bins), 100)
    pdf = dist.pdf(x, *arg_params, loc=loc, scale=scale)
    
    # Plot the fitted PDF
    plt.plot(x, pdf, color=color, lw=2, label=f'{name} (AIC: {aic:.2f})')

plt.legend()
plt.tight_layout()
plt.show()

# Perform Kolmogorov-Smirnov test to find the best fitting distribution
print("Goodness of Fit Tests:")
print("=====================")

for dist, name in zip(distributions, dist_names):
    params = dist.fit(data)
    arg_params = params[:-2]
    loc = params[-2]
    scale = params[-1]
    
    # K-S test
    ks_stat, ks_pval = stats.kstest(data, lambda x: dist.cdf(x, *arg_params, loc=loc, scale=scale))
    print(f"{name} distribution:")
    print(f"  K-S statistic: {ks_stat:.4f}")
    print(f"  p-value: {ks_pval:.4f}")
    print(f"  {'Good fit (fail to reject H0)' if ks_pval > 0.05 else 'Poor fit (reject H0)'}")
    print()
```

## 9. Practical Applications

Understanding distributions has many practical applications in data science:

1. **Anomaly detection**: Identifying unusual observations in data
2. **Hypothesis testing**: Making statistical inferences about populations
3. **Risk modeling**: Estimating the probability of extreme events
4. **Quality control**: Monitoring processes for consistency
5. **Simulation**: Generating realistic synthetic data

```python
# Example: Anomaly detection in a temperature sensor dataset
np.random.seed(42)

# Generate normal temperature readings with occasional anomalies
n_days = 365
temp_mean = 22
temp_std = 3

# Generate baseline temperature (daily fluctuations + seasonal trend)
t = np.arange(n_days)
seasonal_component = 5 * np.sin(2 * np.pi * t / 365)  # Yearly cycle
temperatures = temp_mean + seasonal_component + np.random.normal(0, temp_std, size=n_days)

# Add some anomalies (sensor malfunctions or extreme weather)
anomaly_indices = [20, 80, 150, 230, 300]
anomaly_values = [38, 40, 5, 3, 42]
for idx, val in zip(anomaly_indices, anomaly_values):
    temperatures[idx] = val

# Create a DataFrame for better handling
dates = pd.date_range(start='2023-01-01', periods=n_days, freq='D')
temp_df = pd.DataFrame({'date': dates, 'temperature': temperatures})

# Detect anomalies using Z-score method
temp_df['z_score'] = stats.zscore(temp_df['temperature'])
temp_df['is_anomaly'] = np.abs(temp_df['z_score']) > 2.5  # Threshold

# Visualize the data with anomalies highlighted
plt.figure(figsize=(14, 6))
plt.plot(temp_df['date'], temp_df['temperature'], color='blue', alpha=0.7, label='Temperature')
plt.scatter(
    temp_df.loc[temp_df['is_anomaly'], 'date'],
    temp_df.loc[temp_df['is_anomaly'], 'temperature'],
    color='red', s=50, label='Anomalies'
)
plt.title('Temperature Time Series with Anomalies')
plt.xlabel('Date')
plt.ylabel('Temperature (°C)')
plt.legend()
plt.grid(True)
plt.show()

print("Detected anomalies:")
print(temp_df[temp_df['is_anomaly']].sort_values('z_score', ascending=False)[['date', 'temperature', 'z_score']])
```

## 10. Summary

Understanding data distributions is fundamental to data science and statistics. Key takeaways include:

1. **Distribution types**: Different data follow different distribution patterns - normal, uniform, log-normal, etc.

2. **Visualization tools**: Histograms, kernel density plots, box plots, Q-Q plots, and ECDFs help visualize and understand distributions.

3. **Normality testing**: Both visual methods and statistical tests (Shapiro-Wilk, Anderson-Darling) can verify if data follows a normal distribution.

4. **Skewed data handling**: Transformations (log, square root, Box-Cox) can help normalize skewed data.

5. **Outlier detection**: Z-score and IQR methods identify observations that deviate significantly from the rest of the data.

6. **Distribution comparison**: Statistical tests help determine if samples come from the same distribution.

7. **Distribution fitting**: Finding which theoretical distribution best matches your empirical data.

8. **Practical applications**: Anomaly detection, hypothesis testing, risk modeling, and simulation.

Understanding distributions helps you choose appropriate statistical methods, identify unusual patterns, and make better data-driven decisions. It's a cornerstone skill for any data scientist or analyst.
