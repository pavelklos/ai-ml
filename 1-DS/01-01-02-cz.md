Klíčové komponenty prostředí datové vědy zahrnují:
- Základní programovací jazyk (Python je nejpopulárnější volbou)
- Správa balíčků a závislostí

- Nástroje pro vizualizaci
- Vývojová prostředí a notebooky
- Správa verzí pro řízení kódu

## 2. Instalace Pythonu

Python je základem vašeho prostředí pro datovou vědu. Hlavní verze Pythonu, které je třeba zvážit, jsou Python 3.8+ (doporučeno pro většinu současné práce s datovou vědou).

### Instalace Pythonu na Windows

```bash
# Stáhněte instalační program z python.org a nainstalujte
# Nebo použijte Windows Package Manager (winget)
winget install Python
```

### Instalace Pythonu na macOS

```bash
# Použití Homebrew
brew install python

# Nebo použití pyenv pro správu verzí
brew install pyenv
pyenv install 3.10.4
pyenv global 3.10.4
```

### Instalace Pythonu na Linux

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# Fedora
sudo dnf install python3 python3-pip
```

### Ověření instalace Pythonu

```bash
# Kontrola verze Pythonu
python --version
# nebo
python3 --version
```

## 3. Správa balíčků pomocí pip a conda

Balíčky Pythonu se spravují prostřednictvím správců balíčků, přičemž `pip` a `conda` jsou nejpopulárnější možnosti.

### Použití pip

Pip je výchozí instalační program balíčků pro Python a je dodáván s instalacemi Pythonu.

```bash
# Aktualizace samotného pip
python -m pip install --upgrade pip

# Instalace balíčků
pip install numpy pandas matplotlib scikit-learn

# Instalace konkrétní verze
pip install numpy==1.23.5

# Seznam nainstalovaných balíčků
pip list

# Export požadavků
pip freeze > requirements.txt

# Instalace z requirements souboru
pip install -r requirements.txt
```

### Použití conda

Conda je multiplatformní správce balíčků a prostředí, který je zvláště populární v datové vědě.

```bash
# Instalace Miniconda (minimální instalace conda)
# Stáhněte z: https://docs.conda.io/en/latest/miniconda.html

# Vytvoření nového prostředí
conda create -n datasci python=3.10

# Aktivace prostředí
conda activate datasci

# Instalace balíčků
conda install numpy pandas matplotlib scikit-learn

# Instalace z kanálu conda-forge
conda install -c conda-forge xgboost

# Export prostředí
conda env export > environment.yml

# Vytvoření prostředí ze souboru
conda env create -f environment.yml
```

## 4. Vytváření virtuálních prostředí

Virtuální prostředí izolují závislosti projektu a předcházejí konfliktům mezi různými projekty.

### Použití venv (vestavěný nástroj Pythonu)

```bash
# Vytvoření virtuálního prostředí
python -m venv mojeprostredi

# Aktivace na Windows
mojeprostredi\Scripts\activate

# Aktivace na macOS/Linux
source mojeprostredi/bin/activate

# Deaktivace
deactivate
```

### Použití conda prostředí

```bash
# Vytvoření conda prostředí
conda create -n mujprojekt

# S konkrétní verzí Pythonu
conda create -n mujprojekt python=3.9

# Aktivace
conda activate mujprojekt

# Deaktivace
conda deactivate

# Seznam prostředí
conda env list
```

### Použití virtualenv s virtualenvwrapper

```bash
# Instalace
pip install virtualenv virtualenvwrapper

# Na Windows
pip install virtualenvwrapper-win

# Vytvoření prostředí (s virtualenvwrapper)
mkvirtualenv datasci

# Aktivace
workon datasci

# Deaktivace
deactivate
```

### Příklad: Test vašeho prostředí s jednoduchou analýzou

```python

from sklearn.datasets import load_iris
iris = load_iris()
X = iris.data
y = iris.target

# Vytvoření DataFrame
df = pd.DataFrame(X, columns=iris.feature_names)
df['target'] = y

# Základní statistiky
print(df.describe())

# Jednoduchá vizualizace
plt.figure(figsize=(10, 6))
sns.scatterplot(x='sepal length (cm)', y='sepal width (cm)', 
                hue='target', data=df, palette='viridis')
plt.title('Dataset Iris - Rozměry kališních lístků')
plt.show()
```

## 7. Nastavení Jupyter Notebooks

Jupyter Notebooks jsou interaktivní dokumenty kombinující kód, text a vizualizace, což je ideální pro průzkum a reportování v datové vědě.

### Instalace Jupyter

```bash
# Použití pip
pip install jupyter notebook jupyterlab

# Použití conda
conda install -c conda-forge jupyter jupyterlab
```

### Spuštění Jupyter

```bash
# Spuštění Jupyter Notebook
jupyter notebook

# Spuštění JupyterLab (novější rozhraní)
jupyter lab
```

### Příklad použití notebooku

```python
# V buňce Jupyter

# Import knihoven
import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# Vytvoření nějakých dat
x = np.linspace(0, 10, 100)
y = np.sin(x)

# Vytvoření vizualizace
plt.figure(figsize=(10, 6))
plt.plot(x, y, 'b-', linewidth=2)
plt.title('Sinusová vlna')
plt.xlabel('x')
plt.ylabel('sin(x)')
plt.grid(True)
plt.show()
```

### Instalace Jupyter rozšíření

```bash
# Instalace rozšíření pro vylepšenou funkcionalitu
pip install jupyter_contrib_nbextensions
jupyter contrib nbextension install --user

# Pro JupyterLab
pip install jupyterlab-git
jupyter lab build
```

## 10. Shrnutí

Nastavení správného prostředí pro datovou vědu zahrnuje:

1. **Instalace Pythonu**: Zvolte vhodnou verzi (doporučeno 3.8+).

2. **Správa balíčků**: Používejte pip nebo conda pro instalaci a správu balíčků.

3. **Virtuální prostředí**: Izolujte závislosti projektů pomocí venv, conda prostředí nebo virtualenvwrapper.

4. **Základní knihovny**: Nainstalujte základní balíček pro datovou vědu včetně NumPy, Pandas, Matplotlib a Scikit-learn.

5. **Vývojové prostředí**: Zvolte a nakonfigurujte IDE nebo editor kódu, který vyhovuje vašemu pracovnímu postupu.

6. **Jupyter Notebooks**: Nastavte interaktivní výpočetní prostředí s Jupyter Notebook nebo JupyterLab.

7. **Konfigurace prostředí**: Používejte soubory požadavků nebo soubory prostředí pro reprodukovatelná nastavení.

8. **Správa verzí**: Integrujte Git pro sledování změn a spolupráci s ostatními.

Dobře nakonfigurované prostředí zjednoduší váš pracovní postup, zkrátí čas nastavení nových projektů a zajistí reprodukovatelnost. S postupem vaší cesty datovou vědou můžete toto prostředí rozšířit o specializované nástroje a knihovny pro specifické domény jako hluboké učení, zpracování přirozeného jazyka nebo počítačové vidění.
