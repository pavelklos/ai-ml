## Time Series Components

Time series data typically consists of four main components:
1. **Trend**: The long-term movement in the data
2. **Seasonality**: Repeating patterns at fixed intervals
3. **Cyclical**: Fluctuations not of fixed frequency
4. **Residual/Irregular**: Random variations that cannot be attributed to trend, seasonality, or cyclical patterns


## Stationarity and Testing

A stationary time series is one whose statistical properties (mean, variance, autocorrelation) remain constant over time. Most time series models require stationarity.

```python
# Testing for stationarity using the Augmented Dickey-Fuller test
def test_stationarity(timeseries, window=12, title=''):
    # Rolling statistics
    rolling_mean = timeseries.rolling(window=window).mean()
    rolling_std = timeseries.rolling(window=window).std()
    
    # Plot rolling statistics
    plt.figure(figsize=(12, 6))
    plt.plot(timeseries, label='Original')
    plt.plot(rolling_mean, label=f'Rolling Mean (window={window})')
    plt.plot(rolling_std, label=f'Rolling Std (window={window})')
    plt.legend(loc='best')
    plt.title(f'Rolling Mean & Standard Deviation - {title}')
    plt.grid(True)
    plt.tight_layout()
    plt.show()
    
    # Augmented Dickey-Fuller test
    print('Results of Augmented Dickey-Fuller Test:')
    adf_result = adfuller(timeseries.dropna())
    
    adf_output = pd.Series(adf_result[0:4], index=['ADF Statistic', 'p-value', 
                                                  'Lags Used', 'Number of Observations'])
    
    for key, value in adf_result[4].items():
        adf_output[f'Critical Value ({key})'] = value
        
    print(adf_output)
    
    if adf_result[1] <= 0.05:
        print("\nConclusion: The time series is STATIONARY")
    else:
        print("\nConclusion: The time series is NON-STATIONARY")

# Test the airline passenger data for stationarity
test_stationarity(airline['Passengers'], title='Airline Passengers')

# Transforming a non-stationary series to make it stationary
# 1. Differencing
airline_diff = airline['Passengers'].diff().dropna()
test_stationarity(airline_diff, title='First Difference of Airline Passengers')

# 2. Log transformation followed by differencing
airline_log = np.log(airline['Passengers'])
airline_log_diff = airline_log.diff().dropna()
test_stationarity(airline_log_diff, title='Log and First Difference of Airline Passengers')
```

## Moving Averages and Exponential Smoothing

Moving averages and exponential smoothing are simple yet effective methods for identifying trends and smoothing out noise in time series data.

```python
# Create a noisy time series
np.random.seed(42)
dates = pd.date_range(start='2020-01-01', periods=200, freq='D')
signal = 10 + 0.05 * np.arange(200) + 5 * np.sin(np.linspace(0, 4*np.pi, 200))
noise = np.random.normal(0, 1, 200)
ts_noisy = pd.Series(signal + noise, index=dates)

# Calculate different types of moving averages
ma_7 = ts_noisy.rolling(window=7, center=True).mean()
ma_30 = ts_noisy.rolling(window=30, center=True).mean()
ewm_alpha_0_1 = ts_noisy.ewm(alpha=0.1).mean()
ewm_alpha_0_3 = ts_noisy.ewm(alpha=0.3).mean()

# Plot the original data and moving averages
plt.figure(figsize=(14, 7))

plt.subplot(2, 1, 1)
plt.plot(ts_noisy, label='Original', alpha=0.5)
plt.plot(ma_7, label='7-day MA', linewidth=2)
plt.plot(ma_30, label='30-day MA', linewidth=2)
plt.title('Simple Moving Averages')
plt.legend()
plt.grid(True)

plt.subplot(2, 1, 2)
plt.plot(ts_noisy, label='Original', alpha=0.5)
plt.plot(ewm_alpha_0_1, label='EWM (α=0.1)', linewidth=2)
plt.plot(ewm_alpha_0_3, label='EWM (α=0.3)', linewidth=2)
plt.title('Exponential Weighted Moving Averages')
plt.legend()
plt.grid(True)

plt.tight_layout()
plt.show()

# Simple Exponential Smoothing
from statsmodels.tsa.holtwinters import SimpleExpSmoothing

# Fit Simple Exponential Smoothing model

ses_pred = ses_model.fittedvalues

# Holt-Winters Exponential Smoothing (with trend)

# Fit Holt-Winters model (trend but no seasonality)

# Plot exponential smoothing results

                           periods=forecast_steps, freq='D')

plt.plot(future_dates, hw_forecast, label='H-W Forecast', linewidth=2, linestyle='--')
```

## Autocorrelation and Partial Autocorrelation

Autocorrelation and Partial Autocorrelation Functions (ACF/PACF) are critical tools for identifying patterns and determining parameters for time series modeling.

```python
# Create a sample time series with strong autocorrelation
np.random.seed(42)
ar_params = [0.7, -0.2]  # AR(2) process
ma_params = [0.3, 0.1]   # MA(2) process

from statsmodels.tsa.arima_process import ArmaProcess
ar = np.r_[1, -np.array(ar_params)]  # Add 1 at the beginning
ma = np.r_[1, np.array(ma_params)]   # Add 1 at the beginning

arma_process = ArmaProcess(ar, ma)
arma_sample = arma_process.generate_sample(nsample=200)
arma_ts = pd.Series(arma_sample, index=pd.date_range(start='2020-01-01', periods=200, freq='D'))

# Plot the ARMA process
plt.figure(figsize=(10, 6))
plt.plot(arma_ts)
plt.title('ARMA(2,2) Process')
plt.grid(True)
plt.tight_layout()
plt.show()

# Plot ACF and PACF
fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 8))

# Autocorrelation Function (ACF)
plot_acf(arma_ts, lags=30, ax=ax1)
ax1.set_title('Autocorrelation Function (ACF)')

# Partial Autocorrelation Function (PACF)
plot_pacf(arma_ts, lags=30, ax=ax2)
ax2.set_title('Partial Autocorrelation Function (PACF)')

plt.tight_layout()
plt.show()

# Interpreting ACF and PACF
print("Interpreting ACF and PACF plots:")
print("1. ACF shows correlations between a time series and its lags.")
print("2. PACF shows correlations between a time series and its lags, controlling for intermediate lags.")
print("3. In an AR(p) process, the PACF cuts off after lag p, while ACF tails off.")
print("4. In an MA(q) process, the ACF cuts off after lag q, while PACF tails off.")
print("5. In an ARMA(p,q) process, both ACF and PACF tail off.")
```

## ARIMA Models

Autoregressive Integrated Moving Average (ARIMA) models are one of the most widely used approaches for time series forecasting.

```python
# Fitting an ARIMA model to the airline passenger data
import warnings
warnings.filterwarnings('ignore')  # Suppress convergence warnings

# We'll use log-transformed data to stabilize variance
airline_log = np.log(airline['Passengers'])

# Split data into train and test sets
train_size = int(len(airline_log) * 0.8)
train, test = airline_log[:train_size], airline_log[train_size:]

# Fit ARIMA model
# p=1 (AR order), d=1 (differencing), q=1 (MA order)
arima_model = ARIMA(train, order=(1, 1, 1))
arima_fit = arima_model.fit()

# Summary of the model
print(arima_fit.summary())

# Forecast
forecast_steps = len(test)
forecast_result = arima_fit.forecast(steps=forecast_steps)

# Create a DataFrame for the forecasts
forecast_index = test.index
forecast_series = pd.Series(forecast_result, index=forecast_index)

# Calculate confidence intervals
from scipy import stats
alpha = 0.05  # 95% confidence interval
forecast_std_err = np.sqrt(arima_fit.params['sigma2'])
z_critical = stats.norm.ppf(1 - alpha/2)
ci_lower = forecast_series - z_critical * forecast_std_err
ci_upper = forecast_series + z_critical * forecast_std_err

# Calculate forecast accuracy
mse = mean_squared_error(test, forecast_series)
mae = mean_absolute_error(test, forecast_series)
rmse = np.sqrt(mse)

print(f"Mean Squared Error: {mse:.4f}")
print(f"Mean Absolute Error: {mae:.4f}")
print(f"Root Mean Squared Error: {rmse:.4f}")

# Plot the results
plt.figure(figsize=(12, 6))
plt.plot(train, label='Training Data')
plt.plot(test, label='Test Data')
plt.plot(forecast_series, label='ARIMA Forecast', linestyle='--')
plt.fill_between(forecast_index, ci_lower, ci_upper, color='pink', alpha=0.3, label='95% Confidence Interval')
plt.title('ARIMA Forecast of Airline Passengers (Log Scale)')
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()

# Auto ARIMA - Automatically finding the best parameters
try:
    import pmdarima as pm
    
    # Fit auto ARIMA
    auto_arima_model = pm.auto_arima(
        train,
        seasonal=True,
        m=12,  # Monthly seasonality
        start_p=0, start_q=0,
        max_p=3, max_q=3, max_d=2,
        information_criterion='aic',
        trace=True
    )
    
    print("\nBest ARIMA model parameters:")
    print(f"ARIMA({auto_arima_model.order[0]}, {auto_arima_model.order[1]}, {auto_arima_model.order[2]})({auto_arima_model.seasonal_order[0]}, {auto_arima_model.seasonal_order[1]}, {auto_arima_model.seasonal_order[2]}, {auto_arima_model.seasonal_order[3]})")
    
    # Forecast with auto ARIMA
    auto_forecast = auto_arima_model.predict(n_periods=forecast_steps)
    auto_forecast_series = pd.Series(auto_forecast, index=forecast_index)
    
    # Calculate forecast accuracy
    auto_mse = mean_squared_error(test, auto_forecast_series)
    auto_rmse = np.sqrt(auto_mse)
    
    print(f"Auto ARIMA RMSE: {auto_rmse:.4f}")
    
    # Plot the results
    plt.figure(figsize=(12, 6))
    plt.plot(train, label='Training Data')
    plt.plot(test, label='Test Data')
    plt.plot(auto_forecast_series, label='Auto ARIMA Forecast', linestyle='--')
    plt.title('Auto ARIMA Forecast of Airline Passengers (Log Scale)')
    plt.legend()
    plt.grid(True)
    plt.tight_layout()
    plt.show()
    
except ImportError:
    print("pmdarima package not installed. To use Auto ARIMA, install with: pip install pmdarima")
```

## Forecasting and Evaluation

Forecasting future values is the ultimate goal of most time series analyses. Proper evaluation helps determine the best model for the task.

```python
# Use a classic time series dataset for forecasting demonstration
# AirPassengers dataset (monthly international airline passengers from 1949 to 1960)

# Split the data into training and test sets
airline_data = airline['Passengers']
split_point = len(airline_data) - 12  # Use last 12 months as test set
train_data = airline_data[:split_point]
test_data = airline_data[split_point:]

print(f"Training data shape: {train_data.shape} (from {train_data.index.min()} to {train_data.index.max()})")
print(f"Test data shape: {test_data.shape} (from {test_data.index.min()} to {test_data.index.max()})")

# Implement different forecasting methods

# 1. Naive Forecast (use the last value of the training set for all forecasts)
naive_forecast = pd.Series([train_data.iloc[-1]] * len(test_data), index=test_data.index)

# 2. Seasonal Naive Forecast (use value from same month in previous year)
seasonal_naive_forecast = pd.Series(train_data.iloc[-(12):].values, index=test_data.index)

# 3. Simple Moving Average (last 12 months)
ma_12_values = train_data.rolling(window=12).mean().iloc[-1]
ma_forecast = pd.Series([ma_12_values] * len(test_data), index=test_data.index)

# 4. Exponential Smoothing
from statsmodels.tsa.holtwinters import ExponentialSmoothing

# Multiplicative Holt-Winters (exponential smoothing with trend and seasonality)
hw_model = ExponentialSmoothing(
    train_data, 
    trend='mul',        # Multiplicative trend
    seasonal='mul',     # Multiplicative seasonality
    seasonal_periods=12 # Monthly data
).fit()

hw_forecast = hw_model.forecast(len(test_data))

# 5. SARIMA Model (Seasonal ARIMA)
from statsmodels.tsa.statespace.sarimax import SARIMAX

# SARIMA parameters: (p,d,q)x(P,D,Q,s)
# p, d, q: Non-seasonal components
# P, D, Q: Seasonal components
# s: Seasonal period
sarima_model = SARIMAX(
    train_data,
    order=(1, 1, 1),            # Non-seasonal part (p,d,q)
    seasonal_order=(1, 1, 1, 12) # Seasonal part (P,D,Q,s)
).fit(disp=False)

sarima_forecast = sarima_model.forecast(len(test_data))

# Calculate forecast errors
def calculate_metrics(actual, forecast):
    mse = mean_squared_error(actual, forecast)
    rmse = np.sqrt(mse)
    mae = mean_absolute_error(actual, forecast)
    mape = np.mean(np.abs((actual - forecast) / actual)) * 100
    return {
        'MSE': mse,
        'RMSE': rmse,
        'MAE': mae,
        'MAPE': f"{mape:.2f}%"
    }

# Evaluate all forecasts
methods = {
    'Naive': naive_forecast,
    'Seasonal Naive': seasonal_naive_forecast,
    'Moving Average': ma_forecast,
    'Holt-Winters': hw_forecast,
    'SARIMA': sarima_forecast
}

results = {}
for name, forecast in methods.items():
    results[name] = calculate_metrics(test_data, forecast)

# Display results as a DataFrame
results_df = pd.DataFrame(results).T
print("\nForecast Evaluation Metrics:")
print(results_df)

# Plot all forecasts
plt.figure(figsize=(14, 8))

# Plot training and test data
plt.plot(train_data, label='Training Data', color='black')
plt.plot(test_data, label='Test Data (Actual)', color='blue', linestyle='-')

# Plot forecasts
colors = ['red', 'green', 'purple', 'orange', 'brown']
for i, (name, forecast) in enumerate(methods.items()):
    plt.plot(forecast, label=f'{name} Forecast', color=colors[i], linestyle='--')

plt.legend()
plt.title('Forecasting Methods Comparison')
```

## Summary

Time series analysis is a fundamental technique in data science for understanding and forecasting sequential data. Key takeaways include:

1. **Time Series Components**: Understanding the trend, seasonality, cyclical, and residual components helps in building appropriate models.

2. **Stationarity**: Most time series models require stationarity; techniques like differencing and transformations can convert non-stationary data to stationary.

3. **Visualization**: Effective visualization techniques help identify patterns, anomalies, and characteristics of time series data.

4. **Moving Averages & Smoothing**: Simple yet powerful techniques for trend detection and noise reduction.

5. **Autocorrelation Analysis**: ACF and PACF plots help identify temporal dependencies and guide model parameter selection.

6. **ARIMA Models**: Autoregressive Integrated Moving Average models are versatile and widely used for time series forecasting.

7. **Seasonal Decomposition**: Breaking down time series into components reveals underlying patterns.

8. **Multiple Forecasting Methods**: Different methods (naive, exponential smoothing, ARIMA) have strengths and weaknesses depending on the data.

9. **Model Evaluation**: Metrics like RMSE, MAE, and MAPE help compare and select the most appropriate forecasting model.

Time series analysis finds applications in various domains including finance, economics, sales forecasting, weather prediction, and IoT sensor data analysis. Mastering these fundamentals provides a strong foundation for advanced time series modeling and forecasting techniques.
