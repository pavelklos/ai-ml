# Načítání dat z různých zdrojů (CSV, Excel, JSON) - Shrnutí

## Hlavní body

1. **Zdroje dat pro datovou vědu**
   - **CSV** (Comma Separated Values): Jednoduchý, běžný formát pro strukturovaná data
   - **Excel**: Formáty .xlsx, .xls používané v obchodním prostředí a analýze dat
   - **JSON** (JavaScript Object Notation): Populární formát pro konfigurační soubory a webové služby

2. **Načítání CSV souborů**
   - Základní použití funkce `pd.read_csv()`
   - Pokročilé možnosti: specifikace oddělovačů, hlaviček, přeskakování řádků
   - Výběr konkrétních sloupců pomocí parametru `usecols`
   - Definování datových typů pomocí parametru `dtype`
   - Konverze datumů pomocí `parse_dates`

3. **Načítání Excel souborů**
   - Základní použití funkce `pd.read_excel()`
   - Práce s více listy pomocí parametru `sheet_name`
   - Čtení specifických sloupců a řádků 
   - Manipulace s komplexními strukturami
   - Extrakce dat z různých listů najednou

4. **Načítání JSON dat**
   - Základní použití funkce `pd.read_json()`
   - Různé JSON struktury a jejich interpretace (`orient`)
   - Práce s JSON Lines formátem (`lines=True`)
   - Zpracování vnořených JSON struktur pomocí `json_normalize()`
   - Řešení složitých JSON hierarchií

5. **Zpracování různých datových zdrojů**
   - Porovnání a zajištění konzistence dat z různých zdrojů
   - Řešení problémů s odlišnými datovými typy
   - Standardizace datových typů napříč různými zdroji
   - Kontrola duplicit a chybějících hodnot

6. **Techniky čištění dat**
   - Zpracování chybějících hodnot (NaN)
   - Odstraňování duplicitních záznamů
   - Konverze a standardizace datových typů
   - Normalizace textových hodnot (velká/malá písmena, odstranění přebytečných mezer)
   - Řešení různých formátů datumů a čísel

7. **Ukládání dat v různých formátech**
   - Základní export do CSV, Excel a JSON
   - Pokročilé možnosti exportu (formátování, oddělování)
   - Stylování Excel výstupu pomocí openpyxl
   - Vytváření filtrovaných výstupů
   - Export dat do HTML tabulky

8. **Optimalizace práce s velkými datasety**
   - Použití správných datových typů pro úsporu paměti
   - Výběr pouze potřebných sloupců
   - Efektivní zpracování a agregace dat
   - Správné použití formátů pro rychlý přístup a analýzu

## Závěrečné shrnutí v češtině

Načítání dat z různých zdrojů je základním krokem v každém projektu datové vědy. Tato dovednost umožňuje pracovat s daty v nejrůznějších formátech a připravit je pro další analýzu.

Pandas poskytuje robustní nástroje pro práci s různými formáty dat. Funkce `read_csv()` nabízí mnoho parametrů pro zpracování CSV souborů, včetně specifikace oddělovačů, zpracování hlaviček a nastavení datových typů. Pro Excel soubory slouží `read_excel()`, která umožňuje pracovat s více listy a komplexními strukturami. JSON data lze načítat pomocí `read_json()` s možností zpracovat různé struktury a hierarchie.

Při práci s různými zdroji dat je důležité zajistit konzistenci. Různé formáty mohou vést k odlišným interpretacím datových typů, což může způsobit problémy při analýze. Proto je nezbytné standardizovat datové typy napříč zdroji a ověřit, že data jsou konzistentní.

Čištění dat je klíčovou součástí procesu. Zahrnuje zpracování chybějících hodnot, odstranění duplicit, konverzi datových typů a normalizaci textových hodnot. Tyto kroky zajišťují kvalitu dat pro přesnou analýzu a modelování.

Po zpracování a vyčištění je často potřeba data uložit zpět na disk v různých formátech. Pandas nabízí funkce jako `to_csv()`, `to_excel()` a `to_json()` s mnoha možnostmi pro přizpůsobení výstupu.

Pro větší datasety je důležité optimalizovat práci s daty, včetně využití správných datových typů pro úsporu paměti a efektivního zpracování dat.

Tyto dovednosti jsou nezbytné pro každého datového analytika nebo vědce, jelikož většina projektů datové analýzy začíná načtením a předzpracováním dat z různých zdrojů. Správné zvládnutí těchto technik umožňuje efektivní práci s různorodými daty a je základem pro úspěšnou analýzu a modelování.
