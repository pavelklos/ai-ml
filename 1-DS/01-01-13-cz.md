## 1. Úvod do kategoriálních dat

Kategoriální data reprezentují charakteristiky nebo vlastnosti, které lze rozdělit do skupin nebo kategorií. Na rozdíl od numerických dat nemají kategoriální proměnné matematický význam a nemohou být přímo použity v mnoha algoritmech strojového učení. Pochopení, jak správně pracovat s kategoriálními daty, je zásadní pro efektivní analýzu dat a modelování.

```python
# Import potřebných knihoven
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.preprocessing import LabelEncoder, OneHotEncoder, OrdinalEncoder

# Nastavení stylu pro grafy

sns.set(style="whitegrid")

# Vytvoření vzorového datasetu s kategoriálními proměnnými
data = {
    'Product': ['Laptop', 'Phone', 'Tablet', 'Laptop', 'Phone', 'Tablet', 'Laptop', 'Phone'],
    'Color': ['Red', 'Blue', 'Green', 'Red', 'Green', 'Blue', 'Blue', 'Red'],
    'Size': ['Large', 'Small', 'Medium', 'Large', 'Small', 'Medium', 'Large', 'Medium'],
    'Price': [1200, 800, 600, 1300, 850, 620, 1150, 780],
    'Rating': [4.5, 4.8, 4.2, 4.7, 4.3, 4.0, 4.9, 4.6]
}

# Vytvoření DataFrame
df = pd.DataFrame(data)

# Zobrazení prvních několika řádků
print("Ukázkový dataset s kategoriálními proměnnými:")
print(df.head())

# Základní informace o datasetu
print("\nInformace o datasetu:")
print(df.info())
```

## 2. Typy kategoriálních dat

Existují dva hlavní typy kategoriálních dat:

1. **Nominální kategoriální data**: Kategorie bez přirozeného pořadí (např. barvy, názvy produktů)
2. **Ordinální kategoriální data**: Kategorie se smysluplným pořadím (např. velikost: malá, střední, velká)

Pochopení typu kategoriálních dat je klíčové pro výběr vhodné metody kódování.

```python
# Identifikace kategoriálních sloupců v našem datasetu
cat_columns = df.select_dtypes(include=['object']).columns
```

## 3. Kódování kategoriálních proměnných

Pro použití kategoriálních dat v modelech strojového učení je potřeba převést je do numerické podoby pomocí kódování. Běžné metody kódování zahrnují:

1. **Label Encoding**: Přiřazení jedinečného celého čísla každé kategorii
2. **One-Hot Encoding**: Vytvoření binárních sloupců pro každou kategorii
3. **Ordinal Encoding**: Přiřazení uspořádaných celých čísel na základě pořadí kategorie

```python
# Vytvoříme kopii našich dat, abychom nemodifikovali originál
df_encoded = df.copy()

# 1. Label Encoding (vhodné pro ordinální data nebo když nezáleží na pořadí)
le = LabelEncoder()
df_encoded['Color_Label'] = le.fit_transform(df['Color'])

print("\nLabelově kódovaná data:")
print(df_encoded[['Color', 'Color_Label']].drop_duplicates())

# 2. One-Hot Encoding (vhodné pro nominální data)
# Použití metody pandas get_dummies
df_onehot = pd.get_dummies(df, columns=['Color'], prefix=['Color'])

print("\nOne-hot kódovaná data (pomocí pandas):")
print(df_onehot.head())

# Použití OneHotEncoder ze scikit-learn
ohe = OneHotEncoder(sparse_output=False, drop='first')  # vynechání první kategorie pro zabránění multikolinearity
color_encoded = ohe.fit_transform(df[['Color']])
color_encoded_df = pd.DataFrame(
    color_encoded, 
    columns=[f"Color_{cat}" for cat in ohe.get_feature_names_out(['Color'])[1:]],
    index=df.index
)

# Spojení s původními daty
df_sklearn_onehot = pd.concat([df, color_encoded_df], axis=1)

print("\nOne-hot kódovaná data (pomocí scikit-learn, s vynecháním první kategorie):")
print(df_sklearn_onehot.head())

# 3. Ordinal Encoding (vhodné pro ordinální data)
# Definice pořadí kategorií
size_categories = ['Small', 'Medium', 'Large']

# Použití OrdinalEncoder ze scikit-learn
oe = OrdinalEncoder(categories=[size_categories])
df_encoded['Size_Ordinal'] = oe.fit_transform(df[['Size']])

print("\nOrdinálně kódovaná data:")
print(df_encoded[['Size', 'Size_Ordinal']].drop_duplicates().sort_values('Size_Ordinal'))

# 4. Vlastní mapování (další způsob pro ordinální kódování)
size_mapping = {'Small': 1, 'Medium': 2, 'Large': 3}
df_encoded['Size_Custom'] = df['Size'].map(size_mapping)

print("\nVlastní mapovaná ordinální data:")
print(df_encoded[['Size', 'Size_Custom']].drop_duplicates().sort_values('Size_Custom'))
```

## 5. Statistická analýza s kategoriálními proměnnými

Statistické testy pro kategoriální data pomáhají určit, zda existují významné vztahy mezi proměnnými.

```python
# Import knihoven pro statistické testování
from scipy import stats
import statsmodels.api as sm
from statsmodels.formula.api import ols

# Chi-kvadrát test nezávislosti mezi dvěma kategoriálními proměnnými
contingency_table = pd.crosstab(large_df['Category'], large_df['Department'])
chi2, p_value, dof, expected = stats.chi2_contingency(contingency_table)

print("\nChi-kvadrát test nezávislosti mezi Category a Department:")
print(f"Hodnota Chi-kvadrát: {chi2}")
print(f"p-hodnota: {p_value}")
print(f"Interpretace: {'Kategorie a oddělení jsou závislé' if p_value < 0.05 else 'Kategorie a oddělení jsou nezávislé'}")

# ANOVA pro testování, zda se průměrná hodnota liší napříč kategoriemi
formula = 'Value ~ C(Category)'
model = ols(formula, data=large_df).fit()
anova_table = sm.stats.anova_lm(model, typ=2)

print("\nANOVA test pro Value napříč různými kategoriemi:")
print(anova_table)
print(f"Interpretace: {'Průměrné hodnoty se významně liší mezi kategoriemi' if anova_table['PR(>F)'][0] < 0.05 else 'Průměrné hodnoty se významně neliší mezi kategoriemi'}")

# Korelace mezi kategoriálními proměnnými (pomocí Cramerova V)
def cramers_v(x, y):
    confusion_matrix = pd.crosstab(x, y)
    chi2, _, dof, _ = stats.chi2_contingency(confusion_matrix)
    n = confusion_matrix.sum().sum()
    phi2 = chi2 / n
    r, k = confusion_matrix.shape
    phi2corr = max(0, phi2 - ((k-1)*(r-1))/(n-1))
    rcorr = r - ((r-1)**2)/(n-1)
    kcorr = k - ((k-1)**2)/(n-1)
    return np.sqrt(phi2corr / min((kcorr-1), (rcorr-1)))

cramer_v = cramers_v(large_df['Category'], large_df['Department'])
print(f"\nCramerova V korelace mezi Category a Department: {cramer_v:.4f}")
print(f"Interpretace: {'Silná asociace' if cramer_v > 0.25 else 'Slabá až střední asociace'}")
```

## 6. Feature engineering pro kategoriální data

Feature engineering může vytvořit informativnější reprezentace kategoriálních dat pro modely strojového učení.

```python
# Vytvoření nového datasetu pro příklady feature engineeringu
np.random.seed(42)
sales_data = pd.DataFrame({
    'Product_ID': np.random.randint(1000, 9999, 100),
    'Category': np.random.choice(['Electronics', 'Clothing', 'Home', 'Books', 'Toys'], 100),
    'Subcategory': np.random.choice(['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H'], 100),
    'Store_Location': np.random.choice(['North', 'South', 'East', 'West'], 100),
    'Sales_Channel': np.random.choice(['Online', 'In-Store', 'Phone'], 100),
    'Sales': np.random.normal(1000, 300, 100).round(2),
    'Date': pd.date_range(start='2023-01-01', periods=100)
})

print("\nUkázka prodejních dat:")
print(sales_data.head())

# 1. Vytváření skupinových příznaků
# Průměrný prodej podle kategorie
category_avg = sales_data.groupby('Category')['Sales'].mean().to_dict()
sales_data['Category_Avg_Sales'] = sales_data['Category'].map(category_avg)

# 2. Extrahování informací z kategoriálních proměnných
# Extrakce prvního písmene podkategorie jako nový příznak
sales_data['Subcategory_First_Letter'] = sales_data['Subcategory'].str[0]

# 3. Kombinování kategoriálních příznaků
# Vytvoření nového příznaku kombinujícího umístění obchodu a prodejní kanál
sales_data['Location_Channel'] = sales_data['Store_Location'] + '_' + sales_data['Sales_Channel']

# 4. Vytváření frekvenčně kódovaných příznaků
category_counts = sales_data['Category'].value_counts(normalize=True).to_dict()
sales_data['Category_Frequency'] = sales_data['Category'].map(category_counts)

# 5. Target encoding: nahrazení kategorie průměrem cílové proměnné pro každou kategorii
target_means = sales_data.groupby('Category')['Sales'].mean().to_dict()
sales_data['Category_Target_Encoded'] = sales_data['Category'].map(target_means)

# 6. Binární příznaky založené na podmínkách
sales_data['Is_Electronics'] = (sales_data['Category'] == 'Electronics').astype(int)
sales_data['High_Value_Sale'] = (sales_data['Sales'] > sales_data['Sales'].mean()).astype(int)

# Zobrazení vylepšeného datasetu
print("\nDataset s vytvořenými příznaky:")
print(sales_data.head())

# Vizualizace vlivu kategoriálního příznaku na cílovou proměnnou
plt.figure(figsize=(14, 6))
sns.boxplot(data=sales_data, x='Category', y='Sales')
plt.title('Distribuce tržeb podle kategorie produktu')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

## 7. Zpracování kategoriálních znaků s vysokou kardinalitou

Příznaky s vysokou kardinalitou mají mnoho jedinečných hodnot, což může být náročné pro efektivní kódování.

```python
# Vytvoření datasetu s příznaky s vysokou kardinalitou
np.random.seed(42)
n = 1000

# Generování dat o produktech s příznaky s vysokou kardinalitou
products = [f"Product_{i}" for i in range(200)]  # 200 jedinečných produktů
countries = [f"Country_{i}" for i in range(50)]  # 50 jedinečných zemí
stores = [f"Store_{i}" for i in range(30)]       # 30 jedinečných obchodů

high_card_df = pd.DataFrame({
    'Product': np.random.choice(products, n),
    'Country': np.random.choice(countries, n),
    'Store': np.random.choice(stores, n),
    'Sales': np.random.normal(1000, 300, n).round(2)
})

# Kontrola kardinality každého kategoriálního příznaku
print("\nKardinalita kategoriálních příznaků:")
for col in ['Product', 'Country', 'Store']:
    print(f"{col}: {high_card_df[col].nunique()} jedinečných hodnot")

# 1. Přístup Top-K hodnot (ponechání pouze nejčastějších kategorií)
def top_k_encoding(series, k=10, other_value='Other'):
    top_k = series.value_counts().nlargest(k).index
    return series.apply(lambda x: x if x in top_k else other_value)

# Aplikace Top-10 kódování na Product
high_card_df['Product_Top10'] = top_k_encoding(high_card_df['Product'], k=10)

print("\nPůvodní vs Top-10 kódované hodnoty Product:")
print(f"Původní jedinečné hodnoty: {high_card_df['Product'].nunique()}")
print(f"Po Top-10 kódování jedinečné hodnoty: {high_card_df['Product_Top10'].nunique()}")
print(high_card_df['Product_Top10'].value_counts())

# 2. Feature hashing (neboli hashovací trik)
def hash_feature(series, n_components=10):
    return series.apply(lambda x: hash(x) % n_components)

# Aplikace hash kódování na Country
high_card_df['Country_Hashed'] = hash_feature(high_card_df['Country'], n_components=10)

print("\nHashované hodnoty Country:")
print(high_card_df['Country_Hashed'].value_counts())

# 3. Frekvenční kódování
for col in ['Product', 'Country', 'Store']:
    # Výpočet frekvence každé hodnoty
    freq = high_card_df[col].value_counts(normalize=True)
    # Mapování frekvence zpět do dataframe
    high_card_df[f'{col}_Freq'] = high_card_df[col].map(freq)

print("\nFrekvenčně kódované příznaky (prvních 5 řádků):")
print(high_card_df[['Product', 'Product_Freq', 'Country', 'Country_Freq']].head())

# 4. Target encoding s křížovou validací pro prevenci úniku dat
from sklearn.model_selection import KFold

def target_encode_cv(df, feature, target, n_folds=5):
    df_result = df.copy()
    df_result[f'{feature}_Target_Encoded'] = np.nan
    kf = KFold(n_splits=n_folds, shuffle=True, random_state=42)
    
    for train_idx, test_idx in kf.split(df):
        target_means = df.iloc[train_idx].groupby(feature)[target].mean()
        df_result.iloc[test_idx, df_result.columns.get_loc(f'{feature}_Target_Encoded')] = \
            df_result.iloc[test_idx][feature].map(target_means)
    
    # Zpracování chybějících hodnot (kvůli kategoriím neviděným v trénovacích datech)
    overall_mean = df[target].mean()
    df_result[f'{feature}_Target_Encoded'].fillna(overall_mean, inplace=True)
    
    return df_result

# Aplikace target encoding s křížovou validací
high_card_df = target_encode_cv(high_card_df, 'Store', 'Sales')

print("\nTarget encoded Store příznak (prvních 5 řádků):")
print(high_card_df[['Store', 'Store_Target_Encoded', 'Sales']].head())

# Vizualizace vztahu mezi původními a kódovanými příznaky
plt.figure(figsize=(14, 6))
plt.scatter(high_card_df['Country_Freq'], high_card_df['Sales'], alpha=0.5)
plt.title('Tržby vs Frekvenční kódování zemí')
plt.xlabel('Frekvence zemí')
plt.ylabel('Tržby')
plt.tight_layout()
plt.show()
```

## 8. Práce s datovým typem Categorical v Pandas

Pandas poskytuje specializovaný datový typ `category`, který nabízí paměťovou efektivitu a další funkčnost pro práci s kategoriálními daty.

```python
# Vytvoření vzorového datasetu s kategoriálními příznaky
data = {
    'ID': range(1000),
    'Gender': np.random.choice(['Male', 'Female'], 1000),
    'Education': np.random.choice(['High School', 'Bachelor', 'Master', 'PhD'], 1000),
    'City': np.random.choice(['New York', 'Chicago', 'Los Angeles', 'Houston', 'Phoenix', 
                             'Philadelphia', 'San Antonio', 'San Diego', 'Dallas', 'San Jose'], 1000),
    'Score': np.random.normal(75, 15, 1000).clip(0, 100).round(2)
}

cat_df = pd.DataFrame(data)

# Kontrola využití paměti před konverzí na kategorický typ
print("\nVyužití paměti před konverzí na kategorický typ:")
print(cat_df.memory_usage(deep=True))

# Konverze objektových sloupců na kategorické
cat_columns = ['Gender', 'Education', 'City']
for col in cat_columns:
    cat_df[col] = cat_df[col].astype('category')

# Kontrola využití paměti po konverzi na kategorický typ
print("\nVyužití paměti po konverzi na kategorický typ:")
print(cat_df.memory_usage(deep=True))

# Prozkoumání vlastností kategorického datového typu
print("\nKategorie v 'Education':")
print(cat_df['Education'].cat.categories)

# Kontrola, zda jsou kategorie seřazené
print("\nJsou kategorie Education seřazeny?", cat_df['Education'].cat.ordered)

# Vytvoření seřazené kategorické proměnné
education_order = ['High School', 'Bachelor', 'Master', 'PhD']
cat_df['Education'] = pd.Categorical(cat_df['Education'], categories=education_order, ordered=True)

# Nyní zkontrolujte, zda jsou kategorie seřazeny
print("\nJsou nyní kategorie Education seřazeny?", cat_df['Education'].cat.ordered)

# Třídění dat podle seřazené kategorické proměnné
print("\nUkázkové řádky seřazené podle úrovně vzdělání:")
print(cat_df.sort_values('Education').head())

# Přidání nové kategorie
cat_df['Education'] = cat_df['Education'].cat.add_categories(['Post Doc'])

# Přejmenování kategorií
cat_df['Gender'] = cat_df['Gender'].cat.rename_categories({'Male': 'M', 'Female': 'F'})
print("\nPřejmenované kategorie pohlaví:")
print(cat_df['Gender'].cat.categories)

# Odstranění nepoužívaných kategorií
cat_df = cat_df[cat_df['City'] != 'San Jose']
print("\nPočet kategorií před odstraněním nepoužívaných:", cat_df['City'].cat.categories.size)
cat_df['City'] = cat_df['City'].cat.remove_unused_categories()
print("Počet kategorií po odstranění nepoužívaných:", cat_df['City'].cat.categories.size)

# Změna pořadí kategorií
cat_df['Education'] = cat_df['Education'].cat.reorder_categories(['PhD', 'Master', 'Bachelor', 'High School', 'Post Doc'], 
                                                                ordered=True)
print("\nPřeuspořádané kategorie vzdělání:")
print(cat_df['Education'].cat.categories)
```

## 9. Implementace kategoriálních proměnných ve strojovém učení

Naučte se efektivně využívat kategoriální proměnné v modelech strojového učení a porovnat různé strategie kódování.

```python
# Import potřebných knihoven pro strojové učení
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error, r2_score

# Vytvoření datasetu pro strojové učení
np.random.seed(42)
n_samples = 1000

ml_data = pd.DataFrame({
    'Category_A': np.random.choice(['A1', 'A2', 'A3'], n_samples),
    'Category_B': np.random.choice(['B1', 'B2', 'B3', 'B4', 'B5'], n_samples),
    'Ordinal_Feature': np.random.choice(['Low', 'Medium', 'High'], n_samples),

categorical_features = ['Category_A', 'Category_B', 'Ordinal_Feature']

# 3. Porovnání důležitosti příznaků
def get_feature_names(column_transformer, feature_names):
    output_features = []
    
    for name, pipe, features in column_transformer.transformers_:
        if name == 'cat_nominal':
            # Pro one-hot kódované příznaky
            for i, category in enumerate(pipe.categories_[0]):
                if i > 0:  # Přeskočit vynechanou kategorii
                    output_features.append(f"{features[0]}_{category}")
            for i, category in enumerate(pipe.categories_[1]):
                if i > 0:  # Přeskočit vynechanou kategorii
                    output_features.append(f"{features[1]}_{category}")
        elif name == 'cat_ordinal':
            # Pro ordinálně kódované příznaky
            output_features.append(features[0])
        else:
            # Pro numerické příznaky
            for f in features:
                output_features.append(f)
    
    return output_features
```
