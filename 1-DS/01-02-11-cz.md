## Úvod do A/B testování

A/B testování, známé také jako split testování, je randomizovaný kontrolovaný experiment používaný k porovnání dvou nebo více variant proměnné s cílem určit, která funguje lépe. V datové vědě se A/B testování široce používá k rozhodování založeném na datech v marketingu, vývoji produktů, UX designu a dalších oblastech.

```python
# Základní ilustrace konceptu
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Jednoduchá simulace dat pro A/B test
np.random.seed(42)

# Kontrolní skupina (Verze A) - 5% míra konverze
group_a_size = 1000
group_a_conversions = np.random.binomial(1, 0.05, size=group_a_size)

# Testovaná skupina (Verze B) - 6% míra konverze
group_b_size = 1000
group_b_conversions = np.random.binomial(1, 0.06, size=group_b_size)

# Vytvoření DataFrame pro uložení dat
ab_data = pd.DataFrame({
    'user_id': range(1, group_a_size + group_b_size + 1),
    'group': ['A'] * group_a_size + ['B'] * group_b_size,
    'converted': np.concatenate([group_a_conversions, group_b_conversions])
})

print(ab_data.head())
print("\nMíra konverze podle skupiny:")
print(ab_data.groupby('group')['converted'].mean())

plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.show()
```

## Statistické základy

A/B testování se opírá o statistické testování hypotéz k určení, zda jsou pozorované rozdíly mezi variantami statisticky významné. Proces typicky zahrnuje:

1. Formulaci nulové hypotézy (H₀): Neexistuje rozdíl mezi variantami
2. Stanovení alternativní hypotézy (H₁): Existuje významný rozdíl
3. Sběr dat
4. Výpočet p-hodnot
5. Rozhodnutí na základě předem stanovené hladiny významnosti (obvykle α = 0,05)

```python
import scipy.stats as stats

# Pokračování z našich vzorových dat
# Extrakce dat o konverzích pro každou skupinu
conversions_a = ab_data[ab_data['group'] == 'A']['converted']
conversions_b = ab_data[ab_data['group'] == 'B']['converted']

# Provedení z-testu pro dva podíly
count_a = sum(conversions_a)
count_b = sum(conversions_b)
nobs_a = len(conversions_a)
nobs_b = len(conversions_b)

z_stat, p_value = stats.proportions_ztest([count_b, count_a], [nobs_b, nobs_a], alternative='larger')

print(f"Z-statistika: {z_stat:.3f}")
print(f"P-hodnota: {p_value:.3f}")

# Interpretace výsledků
alpha = 0.05
if p_value < alpha:
    print("Zamítáme nulovou hypotézu: Verze B funguje lépe než verze A")
else:
    print("Nezamítáme nulovou hypotézu: Nemáme významné důkazy, že verze B je lepší")

# Výpočet intervalů spolehlivosti
def confidence_interval(successes, trials, confidence=0.95):
    """Výpočet intervalu spolehlivosti pro podíl."""
    p = successes / trials
    z = stats.norm.ppf(1 - (1 - confidence) / 2)
    std_err = np.sqrt(p * (1 - p) / trials)
    margin = z * std_err
    return (p - margin, p + margin)

ci_a = confidence_interval(count_a, nobs_a)
ci_b = confidence_interval(count_b, nobs_b)

print(f"\n95% interval spolehlivosti pro skupinu A: ({ci_a[0]:.3f}, {ci_a[1]:.3f})")
print(f"95% interval spolehlivosti pro skupinu B: ({ci_b[0]:.3f}, {ci_b[1]:.3f})")
```

## Nastavení A/B testu

Správný experimentální design je klíčový pro platné A/B testování. Zahrnuje:
- Definování jasných metrik
- Zajištění náhodného přiřazení
- Kontrolu externích faktorů
- Stanovení doby trvání experimentu

```python
import random
from datetime import datetime, timedelta

# Příklad nastavení A/B testu
class ABTestSetup:
    def __init__(self, user_ids, test_name, start_date=None, duration_days=14):
        self.user_ids = user_ids
        self.test_name = test_name
        self.start_date = start_date or datetime.now()
        self.end_date = self.start_date + timedelta(days=duration_days)
        self.assignments = {}
        self.results = pd.DataFrame()
        
    def assign_users(self, variants=None, split=None):
        """Náhodně přiřadí uživatele k testovaným variantám."""
        if variants is None:
            variants = ['control', 'treatment']
        
        if split is None:
            split = [0.5, 0.5]  # Standardně rovnoměrné rozdělení
            
        if len(variants) != len(split) or sum(split) != 1.0:
            raise ValueError("Součet poměrů rozdělení musí být 1.0 a musí odpovídat počtu variant")
            
        # Zamíchání ID uživatelů pro zajištění náhodnosti
        random.shuffle(self.user_ids)
        
        # Výpočet počtu uživatelů pro každou variantu
        total_users = len(self.user_ids)
        user_counts = [int(total_users * proportion) for proportion in split]
        user_counts[-1] += total_users - sum(user_counts)  # Zajištění, že všichni uživatelé jsou přiřazeni
        
        # Přiřazení uživatelů k variantám
        start_idx = 0
        for variant, count in zip(variants, user_counts):
            end_idx = start_idx + count
            variant_users = self.user_ids[start_idx:end_idx]
            for user_id in variant_users:
                self.assignments[user_id] = variant
            start_idx = end_idx
            
        # Vytvoření DataFrame s přiřazeními
        self.assignment_df = pd.DataFrame({
            'user_id': list(self.assignments.keys()),
            'variant': list(self.assignments.values())
        })
        
        return self.assignment_df
        
    def get_test_info(self):
        """Vrátí informace o testu."""
        variant_counts = self.assignment_df['variant'].value_counts().to_dict()
        return {
            'test_name': self.test_name,
            'start_date': self.start_date,
            'end_date': self.end_date,
            'total_users': len(self.user_ids),
            'variant_distribution': variant_counts
        }

# Příklad použití
user_ids = list(range(1000, 2000))
test = ABTestSetup(user_ids, "Redesign hlavní stránky", duration_days=21)
assignments = test.assign_users(variants=['starý_design', 'nový_design'], split=[0.5, 0.5])
test_info = test.get_test_info()

print("Nastavení A/B testu:")
print(f"Název testu: {test_info['test_name']}")
print(f"Doba trvání: {test_info['start_date']} až {test_info['end_date']}")
print(f"Celkový počet uživatelů: {test_info['total_users']}")
print("Rozdělení variant:")
for variant, count in test_info['variant_distribution'].items():
    print(f"  {variant}: {count} uživatelů ({count/test_info['total_users']*100:.1f}%)")
```

## Výpočet velikosti vzorku

Stanovení vhodné velikosti vzorku před spuštěním A/B testu je zásadní. Zajišťuje, že test má dostatečnou statistickou sílu k detekci smysluplných rozdílů.

```python
from statsmodels.stats.power import TTestIndPower, proportion_effectsize

def calculate_sample_size_for_proportions(baseline_rate, mde, alpha=0.05, power=0.8):
    """
    Výpočet velikosti vzorku potřebného pro detekci minimálního zjistitelného efektu (MDE)
    v testu proporce nebo konverzního poměru.
    
    Parametry:
    baseline_rate: Aktuální míra konverze (kontrolní skupina)
    mde: Minimální zjistitelný efekt (relativní změna, např. 0.1 pro 10% zlepšení)
    alpha: Hladina významnosti (chyba I. typu)
    power: 1 - chyba II. typu (pravděpodobnost detekce efektu, pokud existuje)
    
    Vrací:
    required_sample_size: Požadovaná velikost vzorku na skupinu
    """
    # Výpočet očekávané míry konverze pro testovanou skupinu
    expected_rate = baseline_rate * (1 + mde)
    
    # Výpočet velikosti efektu pomocí cohens_h
    effect_size = proportion_effectsize(baseline_rate, expected_rate)
    
    # Inicializace analýzy síly testu
    analysis = TTestIndPower()
    
    # Výpočet velikosti vzorku
    result = analysis.solve_power(effect_size=effect_size, 
                                  alpha=alpha, 
                                  power=power, 
                                  alternative='two-sided')
    
    return int(np.ceil(result))

# Příklad použití
baseline_conv_rate = 0.05  # 5% základní míra konverze
minimum_detectable_effect = 0.2  # Chceme detekovat 20% relativní zlepšení
alpha = 0.05  # 5% hladina významnosti
power = 0.8  # 80% síla testu

sample_size = calculate_sample_size_for_proportions(
    baseline_conv_rate, 
    minimum_detectable_effect, 
    alpha, 
    power
)

print(f"Základní míra konverze: {baseline_conv_rate:.1%}")
print(f"Minimální zjistitelný efekt: {minimum_detectable_effect:.1%}")
print(f"Požadovaná velikost vzorku na skupinu: {sample_size:,} uživatelů")

# Vizualizace vztahu mezi MDE a požadovanou velikostí vzorku
mde_values = np.linspace(0.05, 0.5, 10)  # 5% až 50% MDE
sample_sizes = [calculate_sample_size_for_proportions(baseline_conv_rate, mde) 
               for mde in mde_values]

plt.figure(figsize=(10, 6))
plt.plot(mde_values * 100, sample_sizes, marker='o', linestyle='-')
plt.title('Velikost vzorku vs. Minimální zjistitelný efekt')
plt.xlabel('Minimální zjistitelný efekt (%)')
plt.ylabel('Požadovaná velikost vzorku na skupinu')
plt.grid(True, linestyle='--', alpha=0.7)
plt.xticks(mde_values * 100)
plt.ticklabel_format(style='plain', axis='y')
plt.tight_layout()
plt.show()
```

## Implementace v Pythonu

Python nabízí několik knihoven pro implementaci a analýzu A/B testů. Zde si ukážeme kompletní implementaci A/B testu s využitím simulovaných dat i dat podobných reálnému světu.

```python
# Komplexnější příklad A/B testu s využitím statsmodels
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
import statsmodels.stats.api as sms

# Simulace realističtějšího datasetu pro A/B test
np.random.seed(42)

def simulate_user_data(n_users, days=14):
    """Simulace uživatelských dat pro A/B test"""
    # ID uživatelů
    user_ids = range(1, n_users + 1)
    
    # Náhodné přiřazení uživatelů do skupin
    groups = np.random.choice(['A', 'B'], size=n_users)
    
    # Pravděpodobnost konverze je vyšší ve skupině B
    p_convert_a = 0.05  # 5% základní míra konverze
    p_convert_b = 0.065  # 6.5% míra konverze v testované skupině
    
    # Generování dat o konverzích
    conversions = []
    for group in groups:
        if group == 'A':
            conversions.append(1 if np.random.random() < p_convert_a else 0)
        else:
            conversions.append(1 if np.random.random() < p_convert_b else 0)
    
    # Generování dat o příjmech (pouze pro konvertující uživatele)
    revenues = []
    for conv in conversions:
        if conv == 1:
            # Skupina B má mírně vyšší průměrnou hodnotu objednávky
            if groups[len(revenues)] == 'A':
                revenues.append(np.random.normal(50, 15))
            else:
                revenues.append(np.random.normal(55, 15))
        else:
            revenues.append(0)
    
    # Datumy experimentu
    start_date = pd.Timestamp('2023-01-01')
    dates = []
    for _ in range(n_users):
        days_offset = np.random.randint(0, days)
        dates.append(start_date + pd.Timedelta(days=days_offset))
    
    # Vytvoření DataFrame
    df = pd.DataFrame({
        'user_id': user_ids,
        'date': dates,
        'group': groups,
        'converted': conversions,
        'revenue': revenues
    })
    
    return df

# Simulace 5000 uživatelů
ab_data = simulate_user_data(5000)
print(ab_data.head())
print("\nSouhrnné statistiky dat:")
print(ab_data.describe())
print("\nKonverze podle skupin:")

# Provedení testu hypotézy pro rozdíl v míře konverze
group_a = ab_data[ab_data['group'] == 'A']
group_b = ab_data[ab_data['group'] == 'B']

count_a = group_a['converted'].sum()
count_b = group_b['converted'].sum()
nobs_a = len(group_a)
nobs_b = len(group_b)

# Z-test pro podíly
z_stat, p_value = proportions_ztest([count_b, count_a], [nobs_b, nobs_a])
print(f"\nZ-test pro rozdíl podílů:")
print(f"z-statistika: {z_stat:.3f}")
print(f"p-hodnota: {p_value:.3f}")
print(f"Statisticky významný rozdíl? {'Ano' if p_value < 0.05 else 'Ne'}")

# Intervaly spolehlivosti
ci_a = proportion_confint(count_a, nobs_a)
ci_b = proportion_confint(count_b, nobs_b)
print(f"\nMíra konverze skupiny A: {count_a/nobs_a:.3f} [{ci_a[0]:.3f}, {ci_a[1]:.3f}]")
print(f"Míra konverze skupiny B: {count_b/nobs_b:.3f} [{ci_b[0]:.3f}, {ci_b[1]:.3f}]")
```

```python
# Výpočet intervalů spolehlivosti pro příjmy
def mean_confidence_interval(data, confidence=0.95):
    """Výpočet intervalu spolehlivosti pro průměr"""
    n = len(data)
    mean = np.mean(data)
    se = stats.sem(data)
    h = se * stats.t.ppf((1 + confidence) / 2, n-1)
    return mean, mean - h, mean + h
```

## Časté problémy a výzvy

A/B testování přináší několik výzev, které mohou vést k nesprávným závěrům, pokud nejsou řádně řešeny:

1. Nahlížení do výsledků před dokončením testu
2. Problém vícenásobného testování
3. Simpsonův paradox
4. Selekční zkreslení
5. Problémy s externí validitou

```python
# Demonstrace "problému nahlížení" se simulovanými daty
np.random.seed(123)

def simulate_ab_test_over_time(n_days=30, daily_users=200, true_diff=0):
    """
    Simulace A/B testu v průběhu času pro demonstraci problému nahlížení
    
    Parametry:
    n_days: Počet dní trvání testu
    daily_users: Počet uživatelů za den
    true_diff: Skutečný rozdíl v míře konverze
    """
    results = []
    
    # Základní míra konverze
    p_a = 0.10
    p_b = p_a + true_diff
    
    for day in range(1, n_days + 1):
        # Generování denních dat
        group_a_users = int(daily_users / 2)
        group_b_users = daily_users - group_a_users
        
        conv_a = np.random.binomial(1, p_a, size=group_a_users)
        conv_b = np.random.binomial(1, p_b, size=group_b_users)
        
        # Výpočet denních metrik
        daily_conv_a = conv_a.mean()
        daily_conv_b = conv_b.mean()
        
        # Přidání do výsledků
        results.append({
            'day': day,
            'group_a_conv': daily_conv_a,
            'group_b_conv': daily_conv_b,
            'group_a_users': group_a_users,
            'group_b_users': group_b_users,
            'group_a_total': np.sum(conv_a),
            'group_b_total': np.sum(conv_b)
        })
    
    # Převod na DataFrame
    results_df = pd.DataFrame(results)
    
    # Výpočet kumulativních metrik
    results_df['cum_a_users'] = results_df['group_a_users'].cumsum()
    results_df['cum_b_users'] = results_df['group_b_users'].cumsum()
    results_df['cum_a_conv'] = results_df['group_a_total'].cumsum()
    results_df['cum_b_conv'] = results_df['group_b_total'].cumsum()
    results_df['cum_a_rate'] = results_df['cum_a_conv'] / results_df['cum_a_users']
    results_df['cum_b_rate'] = results_df['cum_b_conv'] / results_df['cum_b_users']
    
    # Výpočet p-hodnot v průběhu času
    p_values = []
    
    for idx, row in results_df.iterrows():
        count_a = row['cum_a_conv']
        count_b = row['cum_b_conv']
        nobs_a = row['cum_a_users']
        nobs_b = row['cum_b_users']
        
        # Výpočet p-hodnoty
        z, p_value = proportions_ztest([count_b, count_a], [nobs_b, nobs_a])
        p_values.append(p_value)
    
    results_df['p_value'] = p_values
    results_df['significant'] = results_df['p_value'] < 0.05
    
    return results_df
```

## Bayesovské A/B testování

Zatímco klasické frekventistické A/B testování se zaměřuje na testování hypotéz a p-hodnoty, bayesovské A/B testování nabízí alternativní přístup založený na pravděpodobnostních distribucích a přímých odhadech rozdílu mezi variantami.

```python
import pymc3 as pm
import arviz as az

# Simulovaná data (použití našeho předchozího datasetu)
a_trials = len(group_a)
a_successes = group_a['converted'].sum()
b_trials = len(group_b)
b_successes = group_b['converted'].sum()

# Bayesovský A/B test pomocí PyMC3
with pm.Model() as model:
    # Priory
    p_a = pm.Beta('p_a', alpha=1, beta=1)  # Uniformní prior
    p_b = pm.Beta('p_b', alpha=1, beta=1)  # Uniformní prior
    
    # Věrohodnostní funkce
    obs_a = pm.Binomial('obs_a', n=a_trials, p=p_a, observed=a_successes)
    obs_b = pm.Binomial('obs_b', n=b_trials, p=p_b, observed=b_successes)
    
    # Odvozené veličiny
    delta = pm.Deterministic('delta', p_b - p_a)  # Absolutní rozdíl
    rel_lift = pm.Deterministic('rel_lift', (p_b - p_a) / p_a)  # Relativní zlepšení
    
    # Vzorkování z posteriorní distribuce
    trace = pm.sample(5000, tune=1000, cores=1, random_seed=42)

# Analýza výsledků
summary = az.summary(trace)
print("\nVýsledky bayesovského A/B testu:")
print(summary)

# Pravděpodobnost, že B je lepší než A
prob_b_better = (trace['delta'] > 0).mean()
print(f"\nPravděpodobnost, že B je lepší než A: {prob_b_better:.1%}")

# Očekávané zlepšení
expected_abs_lift = trace['delta'].mean()
expected_rel_lift = trace['rel_lift'].mean()
print(f"Očekávané absolutní zlepšení: {expected_abs_lift:.4f}")
print(f"Očekávané relativní zlepšení: {expected_rel_lift:.2%}")

# Vizualizace posteriorních distribucí
plt.figure(figsize=(12, 6))

plt.subplot(1, 2, 1)
az.plot_posterior(trace, var_names=['p_a', 'p_b'], hdi_prob=0.95)
plt.title('Posteriorní distribuce míry konverze')

plt.subplot(1, 2, 2)
az.plot_posterior(trace, var_names=['delta'], hdi_prob=0.95)
plt.axvline(x=0, color='r', linestyle='--')
plt.title('Posteriorní distribuce rozdílu (B - A)')

plt.tight_layout()
plt.show()
```

## Multivariační testování

Multivariační testování rozšiřuje A/B testování testováním více proměnných současně, což umožňuje zkoumání interakčních efektů mezi různými prvky.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols
import matplotlib.pyplot as plt
import seaborn as sns

# Simulace dat pro multivariační test
np.random.seed(42)

def simulate_multivariate_test(n_users=5000):
    """
    Simulace dat pro multivariační test se 2 faktory:
    - Barva tlačítka: Modrá vs. Zelená
    - Nadpis: Krátký vs. Dlouhý
    """
    # Faktory
    button_color = np.random.choice(['Modrá', 'Zelená'], size=n_users)
    headline = np.random.choice(['Krátký', 'Dlouhý'], size=n_users)
    
    # Základní míra konverze
    base_rate = 0.05
    
    # Definice efektů
    color_effect = {'Modrá': 0, 'Zelená': 0.01}  # Zelená dává +1% konverzi
    headline_effect = {'Krátký': 0, 'Dlouhý': 0.015}  # Dlouhý dává +1.5% konverzi
    
    # Interakční efekt (dodatečný efekt, když je zároveň Zelená a Dlouhý)
    interaction_effect = 0.005  # +0.5% navíc, když je zároveň Zelená a Dlouhý
    
    # Výpočet pravděpodobností konverze
    conversion_probs = []
    
    for i in range(n_users):
        prob = base_rate + color_effect[button_color[i]] + headline_effect[headline[i]]
        # Přidání interakčního efektu, pokud je to vhodné
        if button_color[i] == 'Zelená' and headline[i] == 'Dlouhý':
            prob += interaction_effect
        conversion_probs.append(prob)
    
    # Generování konverzí
    conversions = np.random.binomial(1, conversion_probs)
    
    # Vytvoření DataFrame
    df = pd.DataFrame({
        'user_id': range(1, n_users + 1),
        'button_color': button_color,
        'headline': headline,
        'converted': conversions
    })
    
    return df

# Generování dat pro multivariační test
mv_data = simulate_multivariate_test()
print(mv_data.head())

# Analýza základní míry konverze podle skupin
print("\nCelková míra konverze:", mv_data['converted'].mean())

# Výpočet míry konverze pro každou kombinaci
conversion_table = pd.pivot_table(
    mv_data, 
    values='converted', 
    index='button_color',
    columns='headline',
    aggfunc='mean'
)
print("\nMíra konverze podle skupin:")
print(conversion_table)

# Vizualizace míry konverze
plt.figure(figsize=(10, 6))
ax = sns.barplot(x='button_color', y='converted', hue='headline', data=mv_data)
plt.title('Míra konverze podle barvy tlačítka a nadpisu')
plt.xlabel('Barva tlačítka')
plt.ylabel('Míra konverze')
plt.ylim(0, 0.1)
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.tight_layout()
plt.show()

# Provedení logistické regrese pro analýzu hlavních efektů a interakcí
model = sm.formula.glm(
    formula='converted ~ button_color + headline + button_color:headline',
    data=mv_data,
    family=sm.families.Binomial()
)
result = model.fit()
print("\nVýsledky logistické regrese:")
print(result.summary())

# Převod log-odds na poměry šancí pro snazší interpretaci
odds_ratios = np.exp(result.params)
print("\nPoměry šancí:")
print(odds_ratios)
```

## Shrnutí

A/B testování je základní technika v datové vědě, která umožňuje rozhodování založené na datech prostřednictvím kontrolovaných experimentů. Klíčové poznatky zahrnují:

1. **Základ**: A/B testování umožňuje porovnávat dvě nebo více variant a identifikovat, která funguje lépe na základě definovaných metrik.

2. **Statistická přísnost**: Správné A/B testování vyžaduje pochopení statistických konceptů jako testování hypotéz, p-hodnoty a intervaly spolehlivosti.

3. **Experimentální design**: Pečlivý design je klíčový, včetně náhodného přiřazení, stanovení adekvátní velikosti vzorku a výběru vhodných metrik.

4. **Implementace**: Python poskytuje robustní knihovny pro implementaci A/B testů, od jednoduchých testů podílů až po složitější multivariační analýzy.

5. **Analýza**: Správná analýza zahrnuje nejen určení statistické významnosti, ale také odhad velikosti efektu a intervalů spolehlivosti.

6. **Problémy**: Mezi běžné výzvy patří nahlížení do výsledků příliš brzy, problém vícenásobného testování a různá zkreslení, která mohou ovlivnit platnost výsledků.

7. **Bayesovský přístup**: Bayesovské A/B testování nabízí alternativní rámec zaměřený na pravděpodobnostní distribuce spíše než na testování hypotéz.

8. **Multivariační testování**: Rozšíření za hranice jednoduchých A/B testů umožňuje testovat více proměnných současně a identifikovat interakční efekty.

9. **Obchodní dopad**: Efektivní A/B testování překládá statistické výsledky do realizovatelných obchodních rozhodnutí a měřitelných zlepšení.

10. **Iterace**: A/B testování není jednorázové úsilí, ale průběžný proces experimentování a zdokonalování na základě dat.

Při správné implementaci poskytuje A/B testování vědecký rámec pro zlepšování produktů, webových stránek, marketingových kampaní a dalších oblastí, což v konečném důsledku vede k lepším uživatelským zkušenostem a obchodním výsledkům.
