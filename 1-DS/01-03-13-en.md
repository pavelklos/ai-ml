## Introduction to Causal Inference

Causal inference is the process of determining the actual effect of a treatment or intervention on an outcome. Unlike traditional statistical methods that focus on correlation, causal inference seeks to answer "what if" questions: What would happen if we change X?

Key concepts in causal inference:

- **Correlation vs. Causation**: The famous phrase "correlation does not imply causation" highlights that observing a relationship between variables doesn't necessarily mean one causes the other.
- **Counterfactual reasoning**: Thinking about what would have happened in an alternative scenario.
- **Confounding**: When variables influence both the treatment and outcome, creating spurious associations.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Example of a spurious correlation
np.random.seed(42)
n = 1000

# Confounder: temperature affects both ice cream sales and swimming
temperature = np.random.normal(75, 10, n)

# Ice cream sales increase with temperature (with some noise)
ice_cream_sales = 100 + 7 * temperature + np.random.normal(0, 50, n)

# Swimming increases with temperature (with some noise)
swimming = 50 + 5 * temperature + np.random.normal(0, 40, n)

data = pd.DataFrame({
    'Temperature': temperature,
    'Ice_Cream_Sales': ice_cream_sales,
    'Swimming': swimming
})

# Calculate correlation
correlation = data['Ice_Cream_Sales'].corr(data['Swimming'])

# Plot the relationship
plt.figure(figsize=(10, 6))
sns.scatterplot(x='Ice_Cream_Sales', y='Swimming', data=data)
plt.title(f'Ice Cream Sales vs. Swimming (r = {correlation:.2f})')
plt.xlabel('Ice Cream Sales ($)')
plt.ylabel('Number of People Swimming')
plt.show()

print(f"Correlation between ice cream sales and swimming: {correlation:.2f}")
print("Despite the strong correlation, ice cream sales do not cause swimming.")
print("Both are caused by a common factor: temperature (a confounder).")
```

Why causal inference matters in data science:
- Informs decision-making and policy
- Enables prediction of intervention effects
- Provides understanding of underlying mechanisms
- Helps avoid costly decisions based on correlational patterns

## Potential Outcomes Framework

The Rubin Causal Model (potential outcomes framework) provides a mathematical foundation for causal inference:

- Y(1) = Outcome if treated
- Y(0) = Outcome if not treated
- Causal effect = Y(1) - Y(0)

The fundamental problem of causal inference is that we can only observe one potential outcome for each unit.

```python
# Simulate a simple randomized experiment
np.random.seed(123)
n = 1000

# Generate treatment assignment
treatment = np.random.binomial(1, 0.5, n)

# Generate potential outcomes (not observable in real settings)
# Average treatment effect is 10
y0 = 50 + np.random.normal(0, 10, n)  # Outcome if not treated
y1 = 60 + np.random.normal(0, 10, n)  # Outcome if treated

# True causal effect (usually unknown)
true_effect = np.mean(y1 - y0)

# Observed outcomes
observed_y = treatment * y1 + (1 - treatment) * y0

# Create DataFrame
df = pd.DataFrame({
    'treatment': treatment,
    'observed_y': observed_y,
    'y0': y0,  # Not observable in real settings
    'y1': y1   # Not observable in real settings
})

# Naive estimate (this works in randomized experiments)
est_effect = df[df['treatment'] == 1]['observed_y'].mean() - df[df['treatment'] == 0]['observed_y'].mean()

print(f"True causal effect: {true_effect:.2f}")
print(f"Estimated causal effect: {est_effect:.2f}")

# Visualize
plt.figure(figsize=(10, 6))
sns.histplot(data=df, x='observed_y', hue='treatment', bins=30, alpha=0.6)
plt.axvline(df[df['treatment'] == 1]['observed_y'].mean(), color='blue', linestyle='--')
plt.axvline(df[df['treatment'] == 0]['observed_y'].mean(), color='orange', linestyle='--')
plt.title('Distribution of Outcomes by Treatment Group')
plt.xlabel('Outcome')
plt.legend(['Treated Mean', 'Control Mean', 'Treated', 'Control'])
plt.show()
```

## Observational Methods: Matching and Propensity Scores

When random assignment isn't possible, matching methods can help create comparable treatment and control groups.

```python
# pip install causalinference

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression

# Simulate observational data with confounding
np.random.seed(123)
n = 2000

# Confounders: age and health status
age = np.random.normal(45, 15, n)
health_status = np.random.normal(70, 20, n)

# Treatment assignment (biased by confounders)
# Older and healthier people are more likely to get treatment
propensity = 1 / (1 + np.exp(-(age/50 - 1 + health_status/100)))
treatment = np.random.binomial(1, propensity)

# Outcome affected by treatment and confounders
outcome = 50 + 10 * treatment + 0.5 * age - 0.2 * health_status + np.random.normal(0, 10, n)

# Create DataFrame
data = pd.DataFrame({
    'age': age,
    'health_status': health_status,
    'treatment': treatment,
    'outcome': outcome
})

# Naive estimate (biased due to confounding)
naive_effect = data[data['treatment'] == 1]['outcome'].mean() - data[data['treatment'] == 0]['outcome'].mean()
print(f"Naive treatment effect (biased): {naive_effect:.2f}")

# Propensity score matching
# 1. Estimate propensity scores
X = data[['age', 'health_status']]
y = data['treatment']
ps_model = LogisticRegression()
ps_model.fit(X, y)
data['propensity_score'] = ps_model.predict_proba(X)[:, 1]

# 2. Create matched samples using nearest neighbor matching
def find_match(prop_score, treatment_status, data):
    """Find closest match from opposite treatment group."""
    other_group = data[data['treatment'] != treatment_status]
    distances = abs(other_group['propensity_score'] - prop_score)
    matched_index = distances.idxmin()
    return matched_index

# Create matches for treated units
np.random.seed(42)
treated = data[data['treatment'] == 1].copy()
treated['matched_index'] = treated.apply(
    lambda row: find_match(row['propensity_score'], 1, data), axis=1)

# Create matched dataset
control_matches = data.loc[treated['matched_index']]
matched_data = pd.concat([treated, control_matches.reset_index(drop=True)], axis=0)

# Compute treatment effect on matched data
matched_effect = (matched_data[matched_data['treatment'] == 1]['outcome'].mean() - 
                  matched_data[matched_data['treatment'] == 0]['outcome'].mean())

print(f"Matched treatment effect: {matched_effect:.2f}")
print(f"True treatment effect (from data generation): 10.00")

# Visualize propensity score distributions before and after matching
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))

# Before matching
sns.histplot(data=data, x='propensity_score', hue='treatment', bins=30, alpha=0.6, ax=ax1)
ax1.set_title('Propensity Score Distribution (Before Matching)')
ax1.set_xlabel('Propensity Score')

# After matching
sns.histplot(data=matched_data, x='propensity_score', hue='treatment', bins=30, alpha=0.6, ax=ax2)
ax2.set_title('Propensity Score Distribution (After Matching)')
ax2.set_xlabel('Propensity Score')

plt.tight_layout()
plt.show()
```

## Difference-in-Differences Analysis

Difference-in-Differences (DiD) is a quasi-experimental method that compares the changes in outcomes over time between a treatment group and a control group.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from statsmodels.formula.api import ols

# Create simulated panel data
np.random.seed(123)

# Parameters
n_treatment = 100  # Number of treatment units
n_control = 100  # Number of control units
pre_periods = 3  # Number of pre-treatment periods
post_periods = 3  # Number of post-treatment periods
treatment_effect = 5  # True treatment effect

# Generate data
data = []

for i in range(n_treatment + n_control):
    is_treated = i < n_treatment
    unit_effect = np.random.normal(0, 2)  # Random unit fixed effect
    
    for t in range(pre_periods + post_periods):
        time_effect = t * 1.5  # Time trend
        post = t >= pre_periods  # Indicator for post-treatment period
        
        # Generate outcome variable
        # Y = unit effect + time effect + (treatment effect if treated and post-period) + noise
        outcome = unit_effect + time_effect + (treatment_effect * is_treated * post) + np.random.normal(0, 3)
        
        data.append({
            'unit': i,
            'period': t,
            'treated': is_treated,
            'post': post,
            'outcome': outcome
        })

df = pd.DataFrame(data)

# Calculate group means by period
mean_by_group_period = df.groupby(['treated', 'post'])['outcome'].mean().reset_index()
mean_by_group_period['group'] = mean_by_group_period['treated'].map({True: 'Treated', False: 'Control'})
mean_by_group_period['time'] = mean_by_group_period['post'].map({True: 'Post', False: 'Pre'})

# Print the means
print("Group means by period:")
print(mean_by_group_period)

# Calculate DID estimate manually
treated_pre = mean_by_group_period[(mean_by_group_period['treated'] == True) & 
                                 (mean_by_group_period['post'] == False)]['outcome'].values[0]
treated_post = mean_by_group_period[(mean_by_group_period['treated'] == True) & 
                                  (mean_by_group_period['post'] == True)]['outcome'].values[0]
control_pre = mean_by_group_period[(mean_by_group_period['treated'] == False) & 
                                 (mean_by_group_period['post'] == False)]['outcome'].values[0]
control_post = mean_by_group_period[(mean_by_group_period['treated'] == False) & 
                                  (mean_by_group_period['post'] == True)]['outcome'].values[0]

did_estimate = (treated_post - treated_pre) - (control_post - control_pre)

print(f"\nDifference-in-Differences Estimate: {did_estimate:.2f}")
print(f"True Treatment Effect: {treatment_effect:.2f}")

# Run DID regression
df['treated_post'] = df['treated'] * df['post']  # Interaction term
did_model = ols('outcome ~ treated + post + treated_post', data=df).fit()
print("\nRegression Results:")
print(did_model.summary().tables[1])

# Create a visualization
plt.figure(figsize=(10, 6))

# Reshape data for plotting
plot_data = df.groupby(['treated', 'period'])['outcome'].mean().reset_index()
plot_data['group'] = plot_data['treated'].map({True: 'Treated', False: 'Control'})

# Plot
sns.lineplot(data=plot_data, x='period', y='outcome', hue='group', marker='o')

# Add vertical line at treatment time
plt.axvline(x=pre_periods-0.5, color='red', linestyle='--', alpha=0.5)
plt.text(pre_periods-0.5, plot_data['outcome'].min(), 'Treatment', rotation=90, verticalalignment='bottom')

plt.title('Difference-in-Differences Visualization')
plt.xlabel('Time Period')
plt.ylabel('Outcome')
plt.grid(True, alpha=0.3)
plt.show()
```

## Instrumental Variables

Instrumental Variables (IV) estimation can be used when direct adjustment for confounding is not possible, but there exists a variable (the instrument) that affects the treatment but not the outcome directly.

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.linear_model import LinearRegression

# Set random seed
np.random.seed(42)
n = 5000

# Generate data with unmeasured confounding
# U = unmeasured confounder
u = np.random.normal(0, 1, n)

# Z = instrument (affects treatment but not outcome directly)
z = np.random.binomial(1, 0.5, n)

# X = treatment (affected by Z and U)
x = 0.5 * z + 0.5 * u + np.random.normal(0, 1, n)

# Y = outcome (affected by X and U)
true_effect = 1.5  # True causal effect of X on Y
y = true_effect * x + 2 * u + np.random.normal(0, 1, n)

# Create dataframe
data = pd.DataFrame({
    'z': z,  # Instrument
    'x': x,  # Treatment
    'y': y   # Outcome
    # Note: U is unobserved in real settings
})

# 1. OLS estimation (biased due to unmeasured confounding)
X = sm.add_constant(data['x'])
ols_model = sm.OLS(data['y'], X).fit()

# 2. Two-Stage Least Squares (2SLS) estimation
# First stage: Regress treatment on instrument
X_first = sm.add_constant(data['z'])
first_stage = sm.OLS(data['x'], X_first).fit()
x_predicted = first_stage.predict()

# Second stage: Regress outcome on predicted treatment
X_second = sm.add_constant(x_predicted)
second_stage = sm.OLS(data['y'], X_second).fit()

print("OLS Estimate (biased):", round(ols_model.params[1], 2))
print("IV/2SLS Estimate:", round(second_stage.params[1], 2))
print("True causal effect:", true_effect)

# Visualize the relationship between instrument, treatment, and outcome
fig, axes = plt.subplots(1, 3, figsize=(18, 5))

# Instrument -> Treatment
sns.regplot(x='z', y='x', data=data, ax=axes[0], scatter_kws={'alpha':0.1})
axes[0].set_title('First Stage: Instrument → Treatment')
axes[0].set_xlabel('Instrument (Z)')
axes[0].set_ylabel('Treatment (X)')

# Treatment -> Outcome (OLS, biased)
sns.regplot(x='x', y='y', data=data, ax=axes[1], scatter_kws={'alpha':0.1})
axes[1].set_title('OLS: Treatment → Outcome (Biased)')
axes[1].set_xlabel('Treatment (X)')
axes[1].set_ylabel('Outcome (Y)')

# Predicted Treatment -> Outcome (IV)
sns.regplot(x=x_predicted, y=data['y'], ax=axes[2], scatter_kws={'alpha':0.1})
axes[2].set_title('IV: Predicted Treatment → Outcome')
axes[2].set_xlabel('Predicted Treatment (X̂)')
axes[2].set_ylabel('Outcome (Y)')

plt.tight_layout()
plt.show()

# Check instrument validity conditions
print("\nInstrument Relevance (First Stage F-statistic):")
print(f"F-statistic: {first_stage.fvalue:.2f}, p-value: {first_stage.f_pvalue:.6f}")
print("A high F-statistic (>10) indicates a strong instrument.")
```

## Regression Discontinuity Design

Regression Discontinuity Design (RDD) exploits situations where treatment assignment is determined by a cutoff value of a continuous variable.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import statsmodels.api as sm
import statsmodels.formula.api as smf

# Set random seed
np.random.seed(42)
n = 2000

# Generate running variable (e.g., test score)
running_var = np.random.normal(50, 15, n)

# Treatment is assigned if running variable exceeds the cutoff
cutoff = 50
treatment = (running_var >= cutoff).astype(int)

# Generate outcome with a treatment effect of 10
treatment_effect = 10
noise = np.random.normal(0, 10, n)
outcome = 30 + 0.5 * running_var + treatment_effect * treatment + noise

# Create dataframe
data = pd.DataFrame({
    'running_var': running_var,
    'treatment': treatment,
    'outcome': outcome
})

# Add centered running variable for easier interpretation
data['centered_rv'] = data['running_var'] - cutoff

# Create bins for visualization
bin_width = 2
max_bin = int(max(abs(data['centered_rv'].min()), abs(data['centered_rv'].max())))
bins = range(-max_bin, max_bin + bin_width, bin_width)
data['bin'] = pd.cut(data['centered_rv'], bins, labels=[(b+b+bin_width)/2 for b in bins[:-1]])

# Calculate average outcome by bin
bin_means = data.groupby(['bin', 'treatment'])['outcome'].mean().reset_index()
bin_means_wide = bin_means.pivot(index='bin', columns='treatment', values='outcome').reset_index()
bin_means_wide['bin'] = bin_means_wide['bin'].astype(float)

# Visualize RDD
plt.figure(figsize=(12, 6))
# Scatter for mean by bin
plt.scatter(bin_means_wide[bin_means_wide['bin'] < 0]['bin'], 
            bin_means_wide[bin_means_wide['bin'] < 0][0], 
            s=50, alpha=0.8, label='Control')
plt.scatter(bin_means_wide[bin_means_wide['bin'] >= 0]['bin'], 
            bin_means_wide[bin_means_wide['bin'] >= 0][1], 
            s=50, alpha=0.8, label='Treated')

# Individual data points with low alpha
sns.scatterplot(x='centered_rv', y='outcome', hue='treatment', 
                data=data, alpha=0.1, palette=['blue', 'red'], legend=False)

# Add vertical line at cutoff
plt.axvline(x=0, linestyle='--', color='black', alpha=0.5)

# Fit and plot local linear regression models
control_data = data[data['treatment'] == 0]
treated_data = data[data['treatment'] == 1]

# Restrict bandwidth for local linear regression
bandwidth = 20
control_local = control_data[control_data['centered_rv'] >= -bandwidth]
treated_local = treated_data[treated_data['centered_rv'] <= bandwidth]

# Fit local linear models
control_model = sm.OLS(control_local['outcome'], 
                      sm.add_constant(control_local['centered_rv'])).fit()
treated_model = sm.OLS(treated_local['outcome'], 
                      sm.add_constant(treated_local['centered_rv'])).fit()

# Generate predictions
x_control = np.linspace(-bandwidth, 0, 100)
x_treated = np.linspace(0, bandwidth, 100)

y_control = control_model.params[0] + control_model.params[1] * x_control
y_treated = treated_model.params[0] + treated_model.params[1] * x_treated

# Plot the regression lines
plt.plot(x_control, y_control, 'b-', linewidth=2)
plt.plot(x_treated, y_treated, 'r-', linewidth=2)

plt.title('Regression Discontinuity Design')
plt.xlabel('Running Variable (centered at cutoff)')
plt.ylabel('Outcome')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Estimate treatment effect at the cutoff
rdd_estimate = treated_model.params[0] - control_model.params[0]
print(f"RDD Treatment Effect Estimate: {rdd_estimate:.2f}")
print(f"True Treatment Effect: {treatment_effect:.2f}")

# Formal RDD regression with interaction term
bandwidth = 20
rdd_data = data[(data['centered_rv'] >= -bandwidth) & (data['centered_rv'] <= bandwidth)]

rdd_model = smf.ols('outcome ~ centered_rv + treatment + centered_rv:treatment', data=rdd_data).fit()
print("\nRDD Regression Results:")
print(rdd_model.summary().tables[1])
```

## Causal Inference Libraries in Python

Several specialized Python libraries exist for causal inference tasks, making implementation more straightforward.

### DoWhy Library

```python
# pip install dowhy

import dowhy
from dowhy import CausalModel
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Generate synthetic data
np.random.seed(123)
size = 2000
x = np.random.normal(size=size)
z = np.random.normal(size=size)
# Treatment partly determined by confounder z
treatment = 0.5 * z + np.random.normal(size=size) > 0
# Outcome influenced by both treatment and confounder
y = 2 * treatment + 0.8 * z + np.random.normal(size=size)

# Create DataFrame
data = pd.DataFrame({'x': x, 'z': z, 'treatment': treatment.astype(int), 'y': y})

# Create a causal model using DoWhy
model = CausalModel(
    data=data,
    treatment='treatment',
    outcome='y',
    common_causes=['z'],
    instruments=['x'] # For demonstration, though x is not a valid instrument here
)

# 1. Model the causal relationships using graphs
model.view_model()

# 2. Identify the causal effect
identified_estimand = model.identify_effect(proceed_when_unidentifiable=True)
print(identified_estimand)

# 3. Estimate the causal effect using different methods
causal_estimate = model.estimate_effect(identified_estimand,
                                       method_name="backdoor.linear_regression")
print("Causal Estimate (Linear Regression):", causal_estimate.value)

causal_estimate = model.estimate_effect(identified_estimand,
                                       method_name="backdoor.propensity_score_matching")
print("Causal Estimate (Propensity Score Matching):", causal_estimate.value)

# 4. Refute the obtained estimate
refute_random = model.refute_estimate(identified_estimand, causal_estimate,
                                     method_name="random_common_cause")
print("Refute with Random Common Cause:", refute_random)

refute_subset = model.refute_estimate(identified_estimand, causal_estimate,
                                    method_name="data_subset_refuter", 
                                    subset_fraction=0.8)
print("Refute with Data Subset:", refute_subset)
```

## A/B Testing and Causal Inference

A/B testing (randomized controlled trials) is the gold standard for causal inference in online settings.

```python
import numpy as np
import pandas as pd
import scipy.stats as stats
import matplotlib.pyplot as plt
import seaborn as sns

# Function to simulate an A/B test
def simulate_ab_test(n_control, n_treatment, control_conv_rate, treatment_effect, random_seed=None):
    """
    Simulate an A/B test with binary outcome (e.g., conversion)
    
    Parameters:
    -----------
    n_control: Number of users in control group
    n_treatment: Number of users in treatment group
    control_conv_rate: Conversion rate in control group
    treatment_effect: Absolute increase in conversion rate for treatment
    random_seed: Random seed for reproducibility
    
    Returns:
    --------
    pandas DataFrame with simulation results
    """
    if random_seed is not None:
        np.random.seed(random_seed)
    
    # Generate control group data
    control_data = pd.DataFrame({
        'group': 'control',

# Power analysis for A/B test design
from statsmodels.stats.power import TTestIndPower

def ab_test_sample_size(baseline_rate, minimum_detectable_effect, alpha=0.05, power=0.8):
    """
    Calculate required sample size per group for an A/B test
    
    Parameters:
    -----------
    baseline_rate: Baseline conversion rate (control)
    minimum_detectable_effect: Smallest meaningful relative effect to detect
    alpha: Significance level
    power: Desired statistical power
    
    Returns:
    --------
    Required sample size per group
    """
    # Effect size (Cohen's d) for proportion difference
    p1 = baseline_rate
    p2 = baseline_rate * (1 + minimum_detectable_effect)
    
    # Pooled standard deviation
    pooled_var = p1 * (1 - p1) + p2 * (1 - p2)
    pooled_sd = np.sqrt(pooled_var / 2)
    
    # Cohen's d
    effect_size = abs(p2 - p1) / pooled_sd
    
    # Calculate sample size
    power_analysis = TTestIndPower()
    sample_size = power_analysis.solve_power(
        effect_size=effect_size,
        power=power,
        alpha=alpha,
        ratio=1.0  # Equal sized groups
    )
    
    return int(np.ceil(sample_size))

# Calculate required sample size for different effect sizes

baseline = 0.10  # 10% baseline conversion

for effect in effect_sizes:
    sample_size = ab_test_sample_size(baseline, effect)
    print(f"To detect a {effect*100:.1f}% relative lift from {baseline:.1%} baseline, "
```

## Summary and Best Practices

Causal inference methods allow data scientists to move beyond correlation to understand cause-effect relationships, which is critical for making informed decisions and designing effective interventions.

### Key Takeaways:

1. **Correlation is not causation**: Statistical association doesn't imply causal relationships.

2. **Causal frameworks matter**: Clearly specifying causal questions and assumptions using tools like DAGs helps avoid methodological errors.

3. **Randomized experiments** are the gold standard for causal inference but often not feasible.

4. **Observational methods** like matching, difference-in-differences, RDD, and instrumental variables can provide causal insights when experiments aren't possible.

5. **Multiple methods**: Using several complementary causal inference approaches strengthens the validity of conclusions.

6. **Specialized tools**: Python libraries like DoWhy, EconML, and CausalML provide implementations of causal inference methods.

7. **Sensitivity analysis**: Always test how sensitive your conclusions are to untestable assumptions.

8. **Domain knowledge** is essential for causal inference - pure data-driven approaches are insufficient.

### Best Practices:

1. **Clearly define** the causal question and hypothesized mechanisms.
2. **Draw and analyze** causal graphs to identify confounders and appropriate adjustment strategies.
3. **Check assumptions** of your chosen method and conduct sensitivity analyses.
4. **Use multiple methods** when possible to verify consistency of results.
5. **Report uncertainty** in causal estimates through confidence intervals.
6. **Be transparent** about limitations and untestable assumptions.
7. **Combine** domain expertise with data analysis for more robust conclusions.

Causal inference bridges the gap between predictive models and actionable decision-making, enabling data scientists to answer "what if" questions crucial for policy and business decisions.
