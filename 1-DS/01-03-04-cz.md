## Úvod do systémů doporučování

Systémy doporučování jsou algoritmy, které uživatelům navrhují relevantní položky na základě jejich preferencí, minulého chování nebo podobnosti s jinými uživateli. Setkáváme se s nimi všude v digitálním světě - od doporučení produktů na e-shopech po návrhy obsahu na streamovacích platformách a sociálních sítích.

```python
# Základní knihovny pro systémy doporučování
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Pro vytváření a vyhodnocování modelů
from sklearn.metrics.pairwise import cosine_similarity
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split

# Pro faktorizaci matic a specializované algoritmy doporučování
from surprise import Dataset, Reader, SVD
from surprise.model_selection import cross_validate
```

Cíl systémů doporučování lze formulovat jako:
- Nalezení položek, které by se uživateli mohly líbit, ale ještě je neobjevil
- Predikce hodnocení uživatelů pro položky, se kterými ještě neinteragovali
- Poskytování personalizovaných zážitků pro zvýšení zapojení a spokojenosti

## Typy systémů doporučování

Existuje několik hlavních přístupů k budování systémů doporučování, každý se svými silnými a slabými stránkami.

Mezi hlavní typy patří:

1. **Kolaborativní filtrování**: Doporučuje položky na základě preferencí podobných uživatelů
   - Založené na uživatelích: "Uživatelé, kteří jsou vám podobní, měli rádi..."
   - Založené na položkách: "Uživatelé, kterým se líbila tato položka, měli také rádi..."

2. **Filtrování založené na obsahu**: Doporučuje položky s atributy podobnými položkám, které uživatel v minulosti hodnotil pozitivně

3. **Znalostní systémy**: Provádí doporučení na základě explicitních znalostí o uživatelích, položkách a jejich vztazích

4. **Hybridní systémy**: Kombinují více přístupů pro využití jejich silných stránek

## Kolaborativní filtrování

Kolaborativní filtrování vytváří doporučení shromažďováním a analýzou chování, aktivit nebo preferencí uživatelů k predikci toho, co se bude líbit jiným uživatelům s podobnými zájmy.

### Kolaborativní filtrování založené na uživatelích

```python
# Příklad kolaborativního filtrování založeného na uživatelích
import pandas as pd
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

# Ukázková matice hodnocení uživatel-položka
data = {
    'Alice': {'Film1': 5, 'Film2': 3, 'Film3': 4, 'Film4': None, 'Film5': 1},
    'Bob': {'Film1': 3, 'Film2': 1, 'Film3': 2, 'Film4': 3, 'Film5': None},
    'Charlie': {'Film1': 4, 'Film2': 3, 'Film3': 4, 'Film4': 5, 'Film5': None},
    'Dave': {'Film1': 1, 'Film2': 5, 'Film3': 5, 'Film4': 2, 'Film5': None}
}

# Převod na DataFrame
ratings_df = pd.DataFrame(data)
print("Matice hodnocení uživatel-položka:")
print(ratings_df)

# Převod na matici podobnosti uživatel-uživatel
user_similarity = cosine_similarity(ratings_df.fillna(0).T)
user_similarity_df = pd.DataFrame(user_similarity, index=ratings_df.columns, columns=ratings_df.columns)
print("\nMatice podobnosti uživatel-uživatel:")
print(user_similarity_df)

# Funkce pro doporučení položek uživateli
def recommend_user_based(user, ratings, similarity_matrix, n_recommendations=2):
    # Získání skóre podobnosti pro uživatele
    sim_scores = similarity_matrix[user].drop(user)
    
    # Získání položek, které uživatel hodnotil
    user_ratings = ratings[user].dropna()
    
    # Získání položek, které uživatel nehodnotil
    unrated_items = ratings.index[ratings[user].isna()]
    
    # Výpočet váženého průměrného hodnocení pro každou nehodnocenou položku
    recommendations = {}
    
    for item in unrated_items:
        weighted_sum = 0
        similarity_sum = 0
        
        for other_user in sim_scores.index:
            if not pd.isna(ratings.loc[item, other_user]):
                weighted_sum += sim_scores[other_user] * ratings.loc[item, other_user]
                similarity_sum += sim_scores[other_user]
        
        if similarity_sum > 0:
            recommendations[item] = weighted_sum / similarity_sum
    
    # Seřazení a vrácení nejlepších n doporučení
    top_recommendations = sorted(recommendations.items(), key=lambda x: x[1], reverse=True)[:n_recommendations]
    return top_recommendations

# Získání doporučení pro Alici
alice_recs = recommend_user_based('Alice', ratings_df, user_similarity_df)
print("\nDoporučení pro Alici:")
for movie, score in alice_recs:
    print(f"{movie}: Předpovězené hodnocení = {score:.2f}")
```

### Kolaborativní filtrování založené na položkách

```python
# Příklad kolaborativního filtrování založeného na položkách
# Výpočet matice podobnosti položka-položka
item_similarity = cosine_similarity(ratings_df.fillna(0))
item_similarity_df = pd.DataFrame(item_similarity, index=ratings_df.index, columns=ratings_df.index)
print("Matice podobnosti položka-položka:")
print(item_similarity_df)

# Funkce pro doporučení položek pomocí kolaborativního filtrování založeného na položkách
def recommend_item_based(user, ratings, similarity_matrix, n_recommendations=2):
    # Získání hodnocení uživatele
    user_ratings = ratings[user].dropna()
    
    # Výpočet skóre pro nehodnocené položky
    scores = {}
    
    for item in ratings.index[ratings[user].isna()]:
        weighted_sum = 0
        similarity_sum = 0
        
        for rated_item, rating in user_ratings.items():
            sim = similarity_matrix.loc[item, rated_item]
            weighted_sum += sim * rating
            similarity_sum += abs(sim)
        
        if similarity_sum > 0:
            scores[item] = weighted_sum / similarity_sum
    
    # Vrácení nejlepších n doporučení
    top_recommendations = sorted(scores.items(), key=lambda x: x[1], reverse=True)[:n_recommendations]
    return top_recommendations

# Získání doporučení založených na položkách pro Alici
alice_item_recs = recommend_item_based('Alice', ratings_df, item_similarity_df)
print("\nDoporučení založená na položkách pro Alici:")
for movie, score in alice_item_recs:
    print(f"{movie}: Předpovězené hodnocení = {score:.2f}")
```

## Filtrování založené na obsahu

Filtrování založené na obsahu doporučuje položky porovnáním obsahu položek, nikoli interakcí uživatelů nebo hodnocení. Využívá vlastnosti položek a preference uživatelů pro tyto vlastnosti.

```python
# Příklad filtrování založeného na obsahu
import pandas as pd
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

# Ukázková data filmů s popisky
movies_data = {
    'Film1': 'Sci-fi dobrodružství ve vesmíru s mimozemšťany a pokročilou technologií',
    'Film2': 'Romantická komedie o dvou lidech, kteří se do sebe zamilují v New Yorku',
    'Film3': 'Akční thriller plný špionů a mezinárodních intrik',
    'Film4': 'Sci-fi film o cestování časem a změnách budoucnosti',
    'Film5': 'Komedie o přátelství a dospívání na střední škole'
}

# Hodnocení filmů uživatelem
user_ratings = {
    'Film1': 5,  # Uživatel miloval tento sci-fi film
    'Film3': 4,  # Uživateli se líbil tento akční film
    'Film5': 2   # Uživateli se moc nelíbila tato komedie
}

# Převod popisků filmů do DataFrame
movies_df = pd.DataFrame.from_dict(movies_data, orient='index', columns=['description'])
print("Popisy filmů:")
print(movies_df)

# Vytvoření TF-IDF matice popisů filmů
tfidf = TfidfVectorizer(stop_words='english')
tfidf_matrix = tfidf.fit_transform(movies_df['description'])
print("\nTvar TF-IDF matice:", tfidf_matrix.shape)

# Výpočet kosinové podobnosti mezi filmy
cosine_sim = cosine_similarity(tfidf_matrix, tfidf_matrix)
cosine_sim_df = pd.DataFrame(cosine_sim, index=movies_df.index, columns=movies_df.index)
print("\nMatice podobnosti obsahu filmů:")
print(cosine_sim_df)

# Funkce pro doporučování filmů na základě podobnosti obsahu a preferencí uživatelů
def content_based_recommendations(user_ratings, similarity_matrix, n_recommendations=2):
    # Výpočet váženého skóre pro každý film na základě hodnocení uživatelů a podobnosti obsahu
    scores = {}
    
    # Získání filmů, které uživatel nehodnotil
    unrated_movies = set(similarity_matrix.index) - set(user_ratings.keys())
    
    for movie in unrated_movies:
        weighted_score = 0
        
        # Pro každý film hodnocený uživatelem přidáme váženou podobnost
        for rated_movie, rating in user_ratings.items():
            # Normalizace hodnocení kolem 0 (předpokládáme hodnocení 1-5)
            norm_rating = rating - 3
            # Přidání vážené podobnosti (kladné pro oblíbené filmy, záporné pro neoblíbené)
            weighted_score += similarity_matrix.loc[movie, rated_movie] * norm_rating
        
        scores[movie] = weighted_score
    
    # Seřazení podle skóre a vrácení nejlepších n doporučení
    recommendations = sorted(scores.items(), key=lambda x: x[1], reverse=True)[:n_recommendations]
    return recommendations

# Získání doporučení založených na obsahu
cb_recommendations = content_based_recommendations(user_ratings, cosine_sim_df)
print("\nDoporučení založená na obsahu:")
for movie, score in cb_recommendations:
    print(f"{movie}: Skóre = {score:.2f}")
    print(f"Popis: {movies_data[movie]}")
```

## Hybridní systémy doporučování

Hybridní systémy kombinují více přístupů doporučování pro překonání omezení jednotlivých metod.

```python
# Jednoduchý příklad hybridního systému doporučování kombinujícího kolaborativní filtrování a filtrování založené na obsahu
def hybrid_recommendations(user, ratings_df, content_sim_matrix, item_sim_matrix, 
                          alpha=0.5, n_recommendations=2):
    """
    Generuje hybridní doporučení kombinací filtrování založeného na obsahu a kolaborativního filtrování.
    
    Parametry:
    - user: ID uživatele
    - ratings_df: DataFrame s hodnoceními uživatel-položka
    - content_sim_matrix: Matice podobnosti založená na obsahu
    - item_sim_matrix: Matice podobnosti položek založená na kolaborativním filtrování
    - alpha: Váha pro kolaborativní filtrování (1-alpha pro filtrování založené na obsahu)
    - n_recommendations: Počet doporučení k vrácení
    """
    # Získání hodnocení uživatele
    user_ratings = ratings_df[user].dropna()
    
    # Získání nehodnocených položek
    unrated_items = ratings_df.index[ratings_df[user].isna()]
    
    # Výpočet hybridních skóre
    hybrid_scores = {}
    
    for item in unrated_items:
        # Výpočet skóre založeného na obsahu
        content_score = 0
        content_sim_sum = 0
        
        for rated_item, rating in user_ratings.items():
            norm_rating = rating - 3  # Normalizace kolem 0
            content_sim = content_sim_matrix.loc[item, rated_item]
            content_score += content_sim * norm_rating
            content_sim_sum += abs(content_sim)
        
        if content_sim_sum > 0:
            content_score /= content_sim_sum
        
        # Výpočet skóre kolaborativního filtrování
        collab_score = 0
        collab_sim_sum = 0
        
        for rated_item, rating in user_ratings.items():
            collab_sim = item_sim_matrix.loc[item, rated_item]
            collab_score += collab_sim * rating
            collab_sim_sum += abs(collab_sim)
        
        if collab_sim_sum > 0:
            collab_score /= collab_sim_sum
            
        # Kombinace skóre s váhami
        hybrid_scores[item] = alpha * collab_score + (1 - alpha) * content_score
    
    # Vrácení nejlepších n doporučení
    top_recommendations = sorted(hybrid_scores.items(), key=lambda x: x[1], reverse=True)[:n_recommendations]
    return top_recommendations

# Příklad volání (předpokládáme, že máme požadované matice)
# hybrid_recs = hybrid_recommendations('Alice', ratings_df, cosine_sim_df, item_similarity_df)
```

Běžné hybridní přístupy zahrnují:
- Vážené: Kombinování skóre z více doporučovacích systémů
- Přepínací: Volba mezi metodami na základě určitých kritérií
- Kombinace vlastností: Využití vlastností z různých typů doporučovacích systémů
- Kaskádové: Využití jednoho doporučovacího systému k upřesnění výstupu jiného systému

## Techniky faktorizace matic

Přístupy faktorizace matic rozkládají matici interakcí uživatel-položka na matice nižší dimenze, které zachycují latentní faktory.

```python
# Příklad singulárního rozkladu hodnot (SVD) pomocí knihovny Surprise
from surprise import Dataset, Reader, SVD
from surprise.model_selection import cross_validate

# Vytvoření DataFrame s hodnoceními uživatelů
ratings_list = [
    ['Uživatel1', 'Položka1', 5],
    ['Uživatel1', 'Položka2', 3],
    ['Uživatel1', 'Položka3', 4],
    ['Uživatel2', 'Položka1', 3],
    ['Uživatel2', 'Položka3', 1],
    ['Uživatel2', 'Položka4', 5],
    ['Uživatel3', 'Položka1', 4],
    ['Uživatel3', 'Položka2', 4],
    ['Uživatel3', 'Položka3', 5],
    ['Uživatel3', 'Položka4', 3],
    ['Uživatel4', 'Položka2', 2],
    ['Uživatel4', 'Položka3', 4],
    ['Uživatel4', 'Položka4', 4],
]

df = pd.DataFrame(ratings_list, columns=['userId', 'itemId', 'rating'])
print("DataFrame hodnocení:")
print(df)

# Načtení dat do formátu Surprise
reader = Reader(rating_scale=(1, 5))
data = Dataset.load_from_df(df[['userId', 'itemId', 'rating']], reader)

# Použití algoritmu SVD
svd = SVD(n_factors=2, random_state=42)

# Vyhodnocení modelu pomocí cross-validace
cv_results = cross_validate(svd, data, measures=['RMSE', 'MAE'], cv=3, verbose=False)

# Tisk výsledků vyhodnocení
print("\nVýsledky vyhodnocení modelu SVD:")
print(f"Průměrná RMSE: {cv_results['test_rmse'].mean():.4f}")
print(f"Průměrná MAE: {cv_results['test_mae'].mean():.4f}")

# Trénování na celém datasetu
trainset = data.build_full_trainset()
svd.fit(trainset)

# Provádění predikcí
# Získání všech uživatelů a položek
all_users = df['userId'].unique()
all_items = df['itemId'].unique()

# Predikce hodnocení pro Uživatele1 u Položky4 (kterou ještě nehodnotil)
user = 'Uživatel1'
item = 'Položka4'
pred = svd.predict(user, item)
print(f"\nPředpovězené hodnocení pro {user} u položky {item}: {pred.est:.2f}")

# Generování 2 nejlepších doporučení pro Uživatele1
user1_rated_items = df[df['userId'] == 'Uživatel1']['itemId'].tolist()
user1_unrated_items = [item for item in all_items if item not in user1_rated_items]

user1_predictions = [svd.predict('Uživatel1', item) for item in user1_unrated_items]
user1_predictions.sort(key=lambda x: x.est, reverse=True)

print(f"\nNejlepší doporučení pro Uživatel1:")
for pred in user1_predictions[:2]:
    print(f"{pred.iid}: Předpovězené hodnocení = {pred.est:.2f}")

# Vizualizace latentních faktorů
user_factors = pd.DataFrame(svd.pu, index=trainset._raw2inner_id_users.keys(), 
                           columns=['factor1', 'factor2'])
item_factors = pd.DataFrame(svd.qi, index=trainset._raw2inner_id_items.keys(), 
                           columns=['factor1', 'factor2'])

plt.figure(figsize=(12, 6))

# Vykreslení faktorů uživatelů
plt.subplot(1, 2, 1)
plt.scatter(user_factors['factor1'], user_factors['factor2'])
for user in user_factors.index:
    plt.annotate(user, (user_factors.loc[user, 'factor1'], user_factors.loc[user, 'factor2']))
plt.title('Latentní faktory uživatelů')
plt.xlabel('Faktor 1')
plt.ylabel('Faktor 2')

# Vykreslení faktorů položek
plt.subplot(1, 2, 2)
plt.scatter(item_factors['factor1'], item_factors['factor2'])
for item in item_factors.index:
    plt.annotate(item, (item_factors.loc[item, 'factor1'], item_factors.loc[item, 'factor2']))
plt.title('Latentní faktory položek')
plt.xlabel('Faktor 1')
plt.ylabel('Faktor 2')

plt.tight_layout()
plt.show()
```

Mezi populární techniky faktorizace matic patří:
- Singulární rozklad hodnot (SVD)
- Nezáporná faktorizace matic (NMF)
- Střídavé nejmenší čtverce (ALS)
- Přístupy založené na neuronových sítích

## Vyhodnocování systémů doporučování

Vyhodnocování systémů doporučování vyžaduje metriky, které jdou nad rámec standardních metrik pro klasifikaci nebo regresi.

```python
# Příklad vyhodnocení systému doporučování
from surprise import Dataset, Reader
from surprise.model_selection import train_test_split
from surprise import SVD, KNNBasic
from surprise import accuracy
import matplotlib.pyplot as plt

# Vytvoření ukázkového datasetu
ratings_list = [
    ['Uživatel1', 'Položka1', 5],
    ['Uživatel1', 'Položka2', 3],
    ['Uživatel1', 'Položka3', 4],
    ['Uživatel2', 'Položka1', 3],
    ['Uživatel2', 'Položka3', 1],
    ['Uživatel2', 'Položka4', 5],
    ['Uživatel3', 'Položka1', 4],
    ['Uživatel3', 'Položka2', 4],
    ['Uživatel3', 'Položka3', 5],
    ['Uživatel3', 'Položka4', 3],
    ['Uživatel4', 'Položka2', 2],
    ['Uživatel4', 'Položka3', 4],
    ['Uživatel4', 'Položka4', 4],
]

# Načtení dat
reader = Reader(rating_scale=(1, 5))
data = Dataset.load_from_df(pd.DataFrame(ratings_list, columns=['userId', 'itemId', 'rating']), reader)

# Rozdělení na trénovací a testovací sady
trainset, testset = train_test_split(data, test_size=0.25, random_state=42)

# Trénování modelů
models = {
    'SVD': SVD(random_state=42),
    'KNN': KNNBasic(sim_options={'name': 'cosine', 'user_based': False})
}

results = {}

for name, model in models.items():
    # Trénování modelu
    model.fit(trainset)
    
    # Provádění predikcí
    predictions = model.test(testset)
    
    # Výpočet RMSE a MAE
    rmse = accuracy.rmse(predictions)
    mae = accuracy.mae(predictions)
    
    results[name] = {'RMSE': rmse, 'MAE': mae}
    
    print(f"{name} - RMSE: {rmse:.4f}, MAE: {mae:.4f}")

# Vizualizace výsledků
plt.figure(figsize=(10, 6))
metrics = ['RMSE', 'MAE']
x = np.arange(len(metrics))
width = 0.35

for i, (name, result) in enumerate(results.items()):
    plt.bar(x + i*width - width/2, [result[metric] for metric in metrics], width, label=name)

plt.ylabel('Chyba')
plt.title('Porovnání modelů systémů doporučování')
plt.xticks(x, metrics)
plt.legend()
plt.tight_layout()
plt.show()
```

Mezi běžné metriky vyhodnocení patří:
- Metriky predikce hodnocení: RMSE, MAE
- Metriky pořadí: Precision@k, Recall@k, nDCG (normalizovaný diskontovaný kumulativní zisk)
- Pokrytí, různorodost, novost
- A/B testování pro obchodní dopad

## Vytvoření jednoduchého systému doporučování

Zde vytvoříme kompletní systém doporučování pomocí datasetu MovieLens.

```python
# Příklad vytvoření kompletního systému doporučování pomocí datasetu MovieLens
from surprise import Dataset, Reader
from surprise.model_selection import train_test_split
from surprise import SVD, accuracy

def get_top_n_recommendations(model, user_id, n=10):
    # Získání seznamu všech ID filmů
    all_movie_ids = movies_df['item_id'].tolist()
    
    # Získání filmů, které uživatel již hodnotil
    user_data = data.raw_ratings
    user_rated_movies = [int(rating[1]) for rating in user_data if rating[0] == user_id]
    
    # Filmy, které uživatel nehodnotil
    unseen_movies = [movie_id for movie_id in all_movie_ids if movie_id not in user_rated_movies]
    
    # Predikce hodnocení neviděných filmů
    predictions = [model.predict(str(user_id), str(movie_id)) for movie_id in unseen_movies]
    
    # Seřazení predikcí podle odhadovaného hodnocení
    predictions.sort(key=lambda x: x.est, reverse=True)
    
    # Získání nejlepších N filmů
    top_n = predictions[:n]
    top_movies = [(int(pred.iid), pred.est) for pred in top_n]
    
    # Přidání názvů filmů
    top_movies_with_titles = []
    for movie_id, est_rating in top_movies:
        title = movies_df[movies_df['item_id'] == movie_id]['title'].values[0]
        top_movies_with_titles.append((movie_id, title, est_rating))
    
    return top_movies_with_titles
```

```python
# Příklad použití hlubokého učení pro doporučování pomocí TensorFlow
import tensorflow as tf

from tensorflow.keras.models import Model

# Vytvoření syntetických dat interakcí uživatel-položka
np.random.seed(42)
n_users = 1000
n_items = 500
n_interactions = 20000

# Generování náhodných interakcí uživatel-položka
user_ids = np.random.randint(0, n_users, n_interactions)

ratings = np.clip(ratings, 1, 5)  # Omezení hodnocení mezi 1 a 5

# Vytvoření dataframe
interactions_df = pd.DataFrame({
    'user_id': user_ids,
    'item_id': item_ids,
    'rating': ratings
})

# Rozdělení dat na trénovací a testovací sady
train_data, test_data = train_test_split(interactions_df, test_size=0.2, random_state=42)

# Neuronový embeddingový model pro doporučování

# Parametry modelu
embedding_dim = 50
n_users_model = n_users
n_items_model = n_items

# Vstupní vrstvy
user_input = Input(shape=(1,), name='user_input')
item_input = Input(shape=(1,), name='item_input')

# Embedding vrstvy
user_embedding = Embedding(output_dim=embedding_dim, input_dim=n_users_model, 
                          input_length=1, name='user_embedding')(user_input)
item_embedding = Embedding(output_dim=embedding_dim, input_dim=n_items_model, 
                          input_length=1, name='item_embedding')(item_input)

# Zploštění embeddingů
user_vect = Flatten()(user_embedding)
item_vect = Flatten()(item_embedding)

# Spojení embeddingů
concat = Concatenate()([user_vect, item_vect])

# Husté vrstvy
dense1 = Dense(128, activation='relu')(concat)
dense2 = Dense(64, activation='relu')(dense1)
output = Dense(1)(dense2)

# Definice modelu
model = Model(inputs=[user_input, item_input], outputs=output)
model.compile(loss='mse', optimizer=Adam(learning_rate=0.001))
```
