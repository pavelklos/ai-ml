## Úvod do pokročilého prognózování časových řad

Prognózování časových řad je kritickým aspektem datové vědy, který zahrnuje předpovídání budoucích hodnot na základě dříve pozorovaných hodnot. Pokročilé prognózování časových řad jde za rámec jednoduchých metod, aby zvládalo komplexní vzory a zlepšovalo přesnost předpovědí.

## Modely ARIMA a SARIMA

ARIMA (AutoRegressive Integrated Moving Average) a SARIMA (Seasonal ARIMA) jsou výkonné klasické přístupy k prognózování časových řad.

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX
from pmdarima import auto_arima

# Rozdělení dat na trénovací a testovací sady
train_size = int(len(air_data) * 0.8)
train_data = air_data.iloc[:train_size]
test_data = air_data.iloc[train_size:]

# Použití auto_arima pro nalezení optimálních parametrů
auto_model = auto_arima(train_data['Passengers'],
                       seasonal=True,
                       m=12,  # Měsíční data
                       suppress_warnings=True,
                       stepwise=True,
                       trace=False)

print(f"Nejlepší model SARIMA: {auto_model.order}, {auto_model.seasonal_order}")

# Ruční sestavení modelu SARIMA s identifikovanými parametry
sarima_model = SARIMAX(train_data['Passengers'],
                      order=auto_model.order,
                      seasonal_order=auto_model.seasonal_order,
                      enforce_stationarity=False,
                      enforce_invertibility=False)

sarima_results = sarima_model.fit()
print(sarima_results.summary())

# Prognóza
forecast_steps = len(test_data)
sarima_forecast = sarima_results.get_forecast(steps=forecast_steps)
sarima_mean = sarima_forecast.predicted_mean
sarima_conf_int = sarima_forecast.conf_int()

# Vykreslení výsledků
plt.figure(figsize=(14, 7))
plt.plot(train_data.index, train_data['Passengers'], label='Trénovací data')
plt.plot(test_data.index, test_data['Passengers'], label='Skutečná testovací data')
plt.plot(test_data.index, sarima_mean, color='red', label='SARIMA prognóza')
plt.fill_between(test_data.index, 
                sarima_conf_int.iloc[:, 0], 
                sarima_conf_int.iloc[:, 1], 
                color='red', alpha=0.3, label='95% interval spolehlivosti')
plt.title('Prognóza modelu SARIMA', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Vyhodnocení prognózy
from sklearn.metrics import mean_absolute_error, mean_squared_error
import math

def evaluate_forecast(actual, forecast):
    mse = mean_squared_error(actual, forecast)
    rmse = math.sqrt(mse)
    mae = mean_absolute_error(actual, forecast)
    mape = np.mean(np.abs((actual - forecast) / actual)) * 100
    print(f'RMSE: {rmse:.2f}')
    print(f'MAE: {mae:.2f}')
    print(f'MAPE: {mape:.2f}%')

evaluate_forecast(test_data['Passengers'].values, sarima_mean.values)
```

Klíčové koncepty pro modely ARIMA/SARIMA:
- Autoregrese (AR): Použití minulých hodnot pro předpovídání budoucnosti
- Integrace (I): Diferencování pro dosažení stacionarity časové řady
- Klouzavý průměr (MA): Použití minulých chyb předpovědi
- Sezónní komponenty (S): Zachycení opakujících se vzorů
- Výběr parametrů pomocí kritérií AIC/BIC

## Prophet pro prognózování časových řad

Facebookův Prophet je navržen pro prognózování časových řad se silnými sezónními efekty a s několika sezónami historických dat.

```python
from prophet import Prophet

# Příprava dat pro Prophet (vyžaduje sloupce 'ds' a 'y')
prophet_data = air_data.reset_index().rename(columns={'index': 'ds', 'Passengers': 'y'})

# Rozdělení na trénovací a testovací data
prophet_train = prophet_data.iloc[:train_size]
prophet_test = prophet_data.iloc[train_size:]

# Inicializace a trénování modelu Prophet
model = Prophet(
    yearly_seasonality=True,
    weekly_seasonality=False,
    daily_seasonality=False,
    seasonality_mode='multiplicative',  # Použití multiplikativní sezónnosti pro tento dataset
    interval_width=0.95  # 95% intervaly předpovědi
)

model.fit(prophet_train)

# Vytvoření dataframe pro budoucí datumy k prognóze
future = model.make_future_dataframe(periods=len(prophet_test), freq='MS')
forecast = model.predict(future)

# Vykreslení komponent
fig = model.plot_components(forecast)
plt.tight_layout()
plt.show()

# Vykreslení prognózy
fig = model.plot(forecast)
plt.scatter(prophet_test['ds'], prophet_test['y'], color='red', alpha=0.5, label='Skutečná testovací data')
plt.legend()
plt.title('Prognóza Prophetu', fontsize=15)
plt.tight_layout()
plt.show()

# Vyhodnocení přesnosti prognózy na testovací sadě
prophet_predictions = forecast.iloc[-len(prophet_test):]['yhat'].values
evaluate_forecast(prophet_test['y'].values, prophet_predictions)

# Vizualizace prognózy s nejistotou
plt.figure(figsize=(14, 7))
plt.plot(prophet_train['ds'], prophet_train['y'], label='Trénovací data')
plt.plot(prophet_test['ds'], prophet_test['y'], label='Skutečná testovací data')
plt.plot(forecast.iloc[-len(prophet_test):]['ds'], forecast.iloc[-len(prophet_test):]['yhat'], 
         color='red', label='Prophet prognóza')
plt.fill_between(forecast.iloc[-len(prophet_test):]['ds'],
                forecast.iloc[-len(prophet_test):]['yhat_lower'],
                forecast.iloc[-len(prophet_test):]['yhat_upper'],
                color='red', alpha=0.3, label='95% interval spolehlivosti')
plt.title('Prognóza modelu Prophet', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

Klíčové výhody Prophetu:
- Zpracovává chybějící data a odlehlé hodnoty
- Přizpůsobuje se změnám trendu a sezónním efektům
- Integruje svátky a speciální události
- Poskytuje intervaly nejistoty
- Jednoduché API s minimálním laděním parametrů

## Hluboké učení pro časové řady

Přístupy hlubokého učení jako LSTM (Long Short-Term Memory) sítě se staly populárními pro prognózování časových řad.

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout
from sklearn.preprocessing import MinMaxScaler

# Předzpracování dat pro LSTM
def create_sequences(data, seq_length):
    xs, ys = [], []
    for i in range(len(data) - seq_length):
        x = data[i:i+seq_length]
        y = data[i+seq_length]
        xs.append(x)
        ys.append(y)
    return np.array(xs), np.array(ys)

# Škálování dat
scaler = MinMaxScaler(feature_range=(0, 1))
scaled_data = scaler.fit_transform(air_data[['Passengers']])

# Definice délky sekvence
seq_length = 12  # Použití posledních 12 měsíců k předpovědi dalšího měsíce

# Vytvoření sekvencí
x, y = create_sequences(scaled_data, seq_length)

# Rozdělení na trénovací a testovací sady
train_size = int(len(x) * 0.8)
x_train, x_test = x[:train_size], x[train_size:]
y_train, y_test = y[:train_size], y[train_size:]

# Sestavení modelu LSTM
model = Sequential()
model.add(LSTM(50, return_sequences=True, input_shape=(seq_length, 1)))
model.add(Dropout(0.2))
model.add(LSTM(50))
model.add(Dropout(0.2))
model.add(Dense(1))

model.compile(optimizer='adam', loss='mse')

# Trénování modelu
history = model.fit(
    x_train, y_train,
    epochs=50,
    batch_size=32,
    validation_split=0.2,
    verbose=0
)

# Vykreslení historie trénování
plt.figure(figsize=(10, 6))
plt.plot(history.history['loss'], label='Trénovací ztráta')
plt.plot(history.history['val_loss'], label='Validační ztráta')
plt.title('Ztráta modelu LSTM', fontsize=15)
plt.xlabel('Epocha', fontsize=12)
plt.ylabel('Ztráta', fontsize=12)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Vytvoření předpovědí
y_pred = model.predict(x_test)

# Inverzní transformace předpovědí a skutečných hodnot
y_test_inv = scaler.inverse_transform(y_test)
y_pred_inv = scaler.inverse_transform(y_pred)

# Příprava časové osy pro vykreslení
test_dates = air_data.index[train_size+seq_length:][:len(y_test)]

# Vykreslení výsledků
plt.figure(figsize=(14, 7))
plt.plot(air_data.index[:train_size+seq_length], air_data['Passengers'][:train_size+seq_length], 
         label='Trénovací data')
plt.plot(test_dates, y_test_inv, label='Skutečná testovací data')
plt.plot(test_dates, y_pred_inv, color='red', label='LSTM prognóza')
plt.title('Prognóza modelu LSTM', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Vyhodnocení prognózy
evaluate_forecast(y_test_inv.flatten(), y_pred_inv.flatten())
```

Další přístupy hlubokého učení pro časové řady:
- Konvoluční neuronové sítě (CNN)
- Temporální konvoluční sítě (TCN)
- Modely založené na transformerech
- Hybridní modely kombinující CNN a LSTM

## Modely stavového prostoru a strukturální časové řady

Modely stavového prostoru poskytují flexibilní rámec pro modelování a prognózování časových řad.

```python
from statsmodels.tsa.statespace.structural import UnobservedComponents

# Definice strukturálního modelu časové řady
# Komponenty: trend, sezónnost a nepravidelnost
ucm_model = UnobservedComponents(
    air_data.iloc[:train_size]['Passengers'],
    level='local linear trend',  # Trendová komponenta
    seasonal=12,                 # Sezónní komponenta (12 měsíců)
    stochastic_level=True,
    stochastic_trend=True,
    stochastic_seasonal=True
)

# Trénování modelu
ucm_results = ucm_model.fit(disp=False)
print(ucm_results.summary())

# Vytvoření předpovědí
ucm_forecast = ucm_results.get_forecast(steps=len(test_data))
ucm_mean = ucm_forecast.predicted_mean
ucm_conf_int = ucm_forecast.conf_int()

# Vykreslení rozložených komponent
ucm_states = ucm_results.states.filtered
fig, axes = plt.subplots(3, 1, figsize=(14, 10))

# Vykreslení úrovně/trendu
axes[0].plot(air_data.index[:train_size], ucm_states[0][:train_size])
axes[0].set_title('Komponenta úrovně')
axes[0].grid(True, alpha=0.3)

# Vykreslení sklonu
axes[1].plot(air_data.index[:train_size], ucm_states[1][:train_size])
axes[1].set_title('Komponenta sklonu')
axes[1].grid(True, alpha=0.3)

# Vykreslení sezónnosti
axes[2].plot(air_data.index[:train_size], 
             np.sum(np.column_stack([ucm_states[i][:train_size] for i in range(2, 14)]), axis=1))
axes[2].set_title('Sezónní komponenta')
axes[2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Vykreslení prognózy
plt.figure(figsize=(14, 7))
plt.plot(train_data.index, train_data['Passengers'], label='Trénovací data')
plt.plot(test_data.index, test_data['Passengers'], label='Skutečná testovací data')
plt.plot(test_data.index, ucm_mean, color='red', label='UCM prognóza')
plt.fill_between(test_data.index, 
                ucm_conf_int.iloc[:, 0], 
                ucm_conf_int.iloc[:, 1], 
                color='red', alpha=0.3, label='95% interval spolehlivosti')
plt.title('Prognóza strukturálního modelu časové řady', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Vyhodnocení prognózy
evaluate_forecast(test_data['Passengers'].values, ucm_mean.values)
```

Klíčové výhody modelů stavového prostoru:
- Explicitní modelování jednotlivých komponent (trend, sezónnost)
- Zpracování chybějících hodnot a nepravidelného vzorkování
- Začlenění exogenních proměnných a intervencí
- Bayesovský odhad pro kvantifikaci nejistoty

## Prognózování vícenásobných časových řad

Vícenásobné časové řady zahrnují prognózování několika vzájemně závislých proměnných časových řad.

```python
from statsmodels.tsa.api import VAR
from statsmodels.tsa.statespace.varmax import VARMAX

# Vygenerování syntetického datasetu vícenásobné časové řady
np.random.seed(42)
dates = pd.date_range(start='2015-01-01', periods=365, freq='D')

# Vytvoření tří korelovaných časových řad
ts1 = np.sin(np.arange(365) * 0.05) * 10 + np.random.normal(0, 1, 365)
ts2 = np.sin(np.arange(365) * 0.05 + 1) * 5 + ts1 * 0.5 + np.random.normal(0, 1, 365)
ts3 = np.cos(np.arange(365) * 0.05) * 7 + ts1 * 0.3 - ts2 * 0.2 + np.random.normal(0, 1, 365)

# Vytvoření DataFrame
multi_ts = pd.DataFrame({
    'Series1': ts1,
    'Series2': ts2,
    'Series3': ts3
}, index=dates)

# Vizualizace vícenásobné časové řady
plt.figure(figsize=(14, 8))
for col in multi_ts.columns:
    plt.plot(multi_ts.index, multi_ts[col], label=col)
plt.title('Příklad vícenásobné časové řady', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Rozdělení na trénovací a testovací sady
train_size_multi = int(len(multi_ts) * 0.8)
train_multi = multi_ts.iloc[:train_size_multi]
test_multi = multi_ts.iloc[train_size_multi:]

# Trénování modelu VAR
var_model = VAR(train_multi)
var_result = var_model.fit(maxlags=15)
print(var_result.summary())

# Prognóza
var_forecast = var_result.forecast(train_multi.values, steps=len(test_multi))

# Převod prognózy na DataFrame
var_forecast_df = pd.DataFrame(var_forecast, 
                              index=test_multi.index, 
                              columns=multi_ts.columns)

# Vykreslení VAR prognózy pro každou řadu
fig, axes = plt.subplots(3, 1, figsize=(14, 10), sharex=True)

for i, col in enumerate(multi_ts.columns):
    axes[i].plot(train_multi.index, train_multi[col], label='Trénovací data')
    axes[i].plot(test_multi.index, test_multi[col], label='Skutečná testovací data')
    axes[i].plot(test_multi.index, var_forecast_df[col], color='red', label='VAR prognóza')
    axes[i].set_title(f'VAR prognóza pro {col}', fontsize=12)
    axes[i].legend()
    axes[i].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Vyhodnocení modelu VAR
for col in multi_ts.columns:
    print(f"\nVyhodnocení pro {col}:")
    evaluate_forecast(test_multi[col].values, var_forecast_df[col].values)
```

Pokročilé přístupy pro prognózování vícenásobných časových řad:
- Vektorová autoregrese (VAR)
- Modely korekce vektorových chyb (VECM)
- Dynamické faktorové modely
- Vícenásobné LSTM/CNN modely

## Inženýrství příznaků pro data časových řad

Inženýrství příznaků je klíčové pro zlepšení přesnosti prognózování časových řad.

```python
# Vytvoření komplexnějšího příkladu s inženýrstvím příznaků
def create_features(df):
    """
    Vytvoření příznaků pro časovou řadu na základě indexu časové řady.
    """
    df = df.copy()
    df['hour'] = df.index.hour
    df['dayofweek'] = df.index.dayofweek
    df['dayofmonth'] = df.index.day
    df['month'] = df.index.month
    df['quarter'] = df.index.quarter
    df['year'] = df.index.year
    df['dayofyear'] = df.index.dayofyear
    df['weekofyear'] = df.index.isocalendar().week
    df['is_weekend'] = df['dayofweek'].isin([5, 6]).astype(int)
    
    # Přidání zpožděných hodnot
    for lag in range(1, 4):
        df[f'lag_{lag}'] = df['Passengers'].shift(lag)
    
    # Přidání klouzavých příznaků
    for window in [7, 14, 30]:
        df[f'rolling_mean_{window}'] = df['Passengers'].rolling(window=window).mean()
        df[f'rolling_std_{window}'] = df['Passengers'].rolling(window=window).std()
        df[f'rolling_min_{window}'] = df['Passengers'].rolling(window=window).min()
        df[f'rolling_max_{window}'] = df['Passengers'].rolling(window=window).max()
    
    # Přidání datumových příznaků
    holidays = ['1949-01-01', '1950-01-01', '1951-01-01', '1952-01-01', 
               '1953-01-01', '1954-01-01', '1955-01-01', '1956-01-01',
               '1957-01-01', '1958-01-01', '1959-01-01', '1960-01-01']
    holidays = pd.to_datetime(holidays)
    df['is_holiday'] = df.index.isin(holidays).astype(int)
    
    return df

# Aplikace inženýrství příznaků na data leteckých společností
air_features = create_features(air_data)
air_features = air_features.dropna()  # Odstranění hodnot NaN po vytvoření zpožděných příznaků

# Zobrazení příznaků
print(air_features.head())

# Rozdělení na příznaky (X) a cíl (y)
X = air_features.drop('Passengers', axis=1)
y = air_features['Passengers']

# Rozdělení na trénovací a testovací data
train_size_feat = int(len(X) * 0.8)
X_train, X_test = X[:train_size_feat], X[train_size_feat:]
y_train, y_test = y[:train_size_feat], y[train_size_feat:]

# Trénování modelu strojového učení (Random Forest)
from sklearn.ensemble import RandomForestRegressor

rf_model = RandomForestRegressor(n_estimators=100, random_state=42)
rf_model.fit(X_train, y_train)

# Vytvoření předpovědí
y_pred_rf = rf_model.predict(X_test)

# Vykreslení výsledků
plt.figure(figsize=(14, 7))
plt.plot(y_train.index, y_train, label='Trénovací data')
plt.plot(y_test.index, y_test, label='Skutečná testovací data')
plt.plot(y_test.index, y_pred_rf, 'r--', label='RF předpovědi')
plt.title('Random Forest s inženýrstvím příznaků', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Vyhodnocení modelu s inženýrstvím příznaků
evaluate_forecast(y_test.values, y_pred_rf)

# Důležitost příznaků
feature_importance = pd.DataFrame({
```

## Shrnutí

Pokročilé prognózování časových řad vyžaduje sofistikovaný soubor metod pro zvládnutí složitosti dat z reálného světa. V tomto průzkumu jsme pokryli více přístupů:

1. **Klasické statistické metody**: Modely ARIMA a SARIMA poskytují základ pro prognózování časových řad, nabízejí interpretovatelnost a solidní výkon pro mnoho datasetů. Fungují zvláště dobře pro data s jasnými sezónními vzory, pokud jsou správně nakonfigurovány.

2. **Moderní inovace**: Prophet poskytuje flexibilní rámec, který automaticky zpracovává sezónnost a může zahrnovat doménové znalosti prostřednictvím speciálních událostí a svátků. Jeho rozložitelná struktura je interpretovatelná a zároveň nabízí vynikající výkon.

3. **Přístupy hlubokého učení**: LSTM sítě a další metody hlubokého učení mohou zachytit složité nelineární vzory v datech časových řad. Vynikají s velkými datasety, ale vyžadují pečlivé ladění a významné výpočetní zdroje.

4. **Modely stavového prostoru**: Tyto modely nabízejí flexibilní rámec pro explicitní modelování komponent časových řad, poskytují jasné rozložení a schopnost zpracovat chybějící data a nepravidelné vzorkování.

5. **Vícenásobné metody**: Při práci s více souvisejícími časovými řadami nám techniky jako VAR umožňují modelovat jejich vzájemné závislosti, což potenciálně zlepšuje přesnost prognózy využitím korelací.

6. **Inženýrství příznaků**: Vytváření smysluplných příznaků může významně zlepšit výkonnost prognózování, zejména při použití tradičních algoritmů strojového učení.

7. **Metody ensemblů**: Kombinování více metod prognózování často vede k robustnějším a přesnějším predikcím než jakýkoli jednotlivý model.

Klíčové osvědčené postupy pro prognózování časových řad:

- Vždy vizualizujte svá data a porozumějte jejich komponentám
- Testujte více metod prognózování pro každý problém
- Věnujte pečlivou pozornost přístupu validace (vyhněte se úniku dat)
- Zvažte inženýrství příznaků pro zahrnutí doménových znalostí
- Používejte ensembly pro zlepšenou robustnost a přesnost
- Kvantifikujte nejistotu ve svých prognózách
- Pravidelně přetrénujte modely, jak jsou k dispozici nová data

Pokročilé prognózování časových řad se nadále vyvíjí s inovacemi v hlubokém učení, pravděpodobnostním modelování a hybridních přístupech. Nejefektivnější strategie prognózování často zahrnuje kombinaci více metod a začlenění odborných znalostí domény k vytvoření robustních, přesných predikcí.
