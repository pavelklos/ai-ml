## Introduction to Advanced Time Series Forecasting

Time series forecasting is a critical aspect of data science that involves predicting future values based on previously observed values. Advanced time series forecasting goes beyond simple methods to handle complex patterns and improve prediction accuracy.

```python
# Install required packages
# pip install numpy pandas matplotlib statsmodels scikit-learn prophet tensorflow pmdarima xgboost lightgbm

# Import standard libraries

plt.rcParams['figure.dpi'] = 100

# Load sample time series data
def load_airline_data():
    """Load classic airline passengers dataset"""
    from statsmodels.datasets import get_rdataset
    air = get_rdataset('AirPassengers').data
    air.index = pd.date_range(start='1949-01-01', periods=len(air), freq='MS')
    air.columns = ['Passengers']

```

- Uncertainty quantification

## ARIMA and SARIMA Models

ARIMA (AutoRegressive Integrated Moving Average) and SARIMA (Seasonal ARIMA) are powerful classical approaches to time series forecasting.

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX
from pmdarima import auto_arima

# Split data into train and test sets
train_size = int(len(air_data) * 0.8)
train_data = air_data.iloc[:train_size]
test_data = air_data.iloc[train_size:]

# Use auto_arima to find optimal parameters
auto_model = auto_arima(train_data['Passengers'],
                       seasonal=True,
                       m=12,  # Monthly data
                       suppress_warnings=True,
                       stepwise=True,
                       trace=False)

print(f"Best SARIMA model: {auto_model.order}, {auto_model.seasonal_order}")

# Manually build a SARIMA model with identified parameters
sarima_model = SARIMAX(train_data['Passengers'],
                      order=auto_model.order,
                      seasonal_order=auto_model.seasonal_order,
                      enforce_stationarity=False,
                      enforce_invertibility=False)

sarima_results = sarima_model.fit()
print(sarima_results.summary())

# Forecast
forecast_steps = len(test_data)
sarima_forecast = sarima_results.get_forecast(steps=forecast_steps)
sarima_mean = sarima_forecast.predicted_mean
sarima_conf_int = sarima_forecast.conf_int()

# Plot results
plt.figure(figsize=(14, 7))
plt.plot(train_data.index, train_data['Passengers'], label='Training Data')
plt.plot(test_data.index, test_data['Passengers'], label='True Test Data')
plt.plot(test_data.index, sarima_mean, color='red', label='SARIMA Forecast')
plt.fill_between(test_data.index, 
                sarima_conf_int.iloc[:, 0], 
                sarima_conf_int.iloc[:, 1], 
                color='red', alpha=0.3, label='95% Confidence Interval')
plt.title('SARIMA Model Forecast', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Evaluate forecast
from sklearn.metrics import mean_absolute_error, mean_squared_error
import math

def evaluate_forecast(actual, forecast):
    mse = mean_squared_error(actual, forecast)
    rmse = math.sqrt(mse)
    mae = mean_absolute_error(actual, forecast)
    mape = np.mean(np.abs((actual - forecast) / actual)) * 100
    print(f'RMSE: {rmse:.2f}')
    print(f'MAE: {mae:.2f}')
    print(f'MAPE: {mape:.2f}%')

evaluate_forecast(test_data['Passengers'].values, sarima_mean.values)
```

Key concepts for ARIMA/SARIMA models:
- Autoregression (AR): Using past values to predict the future
- Integration (I): Differencing to make the time series stationary
- Moving Average (MA): Using past forecast errors
- Seasonal components (S): Capturing recurring patterns
- Parameter selection using AIC/BIC criteria

## Prophet for Time Series Forecasting

Facebook's Prophet is designed for forecasting time series with strong seasonal effects and several seasons of historical data.

```python
from prophet import Prophet

# Prepare data for Prophet (requires 'ds' and 'y' columns)
prophet_data = air_data.reset_index().rename(columns={'index': 'ds', 'Passengers': 'y'})

# Split into train and test
prophet_train = prophet_data.iloc[:train_size]
prophet_test = prophet_data.iloc[train_size:]

# Initialize and fit Prophet model
model = Prophet(
    yearly_seasonality=True,
    weekly_seasonality=False,
    daily_seasonality=False,
    seasonality_mode='multiplicative',  # Use multiplicative seasonality for this dataset
    interval_width=0.95  # 95% prediction intervals
)

model.fit(prophet_train)

# Create a dataframe for future dates to forecast
future = model.make_future_dataframe(periods=len(prophet_test), freq='MS')
forecast = model.predict(future)

# Plot components
fig = model.plot_components(forecast)
plt.tight_layout()
plt.show()

# Plot forecast
fig = model.plot(forecast)
plt.scatter(prophet_test['ds'], prophet_test['y'], color='red', alpha=0.5, label='Actual Test Data')
plt.legend()
plt.title('Prophet Forecast', fontsize=15)
plt.tight_layout()
plt.show()

# Evaluate forecast accuracy on test set
prophet_predictions = forecast.iloc[-len(prophet_test):]['yhat'].values
evaluate_forecast(prophet_test['y'].values, prophet_predictions)

# Visualize forecast with uncertainty
plt.figure(figsize=(14, 7))
plt.plot(prophet_train['ds'], prophet_train['y'], label='Training Data')

         color='red', label='Prophet Forecast')
plt.fill_between(forecast.iloc[-len(prophet_test):]['ds'],
                forecast.iloc[-len(prophet_test):]['yhat_lower'],
                forecast.iloc[-len(prophet_test):]['yhat_upper'],
```

Key advantages of Prophet:

## Deep Learning for Time Series

Deep learning approaches like LSTM (Long Short-Term Memory) networks have become popular for time series forecasting.

```python
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout
from sklearn.preprocessing import MinMaxScaler

# Data preprocessing for LSTM
def create_sequences(data, seq_length):
    xs, ys = [], []
    for i in range(len(data) - seq_length):
        x = data[i:i+seq_length]
        y = data[i+seq_length]
        xs.append(x)
        ys.append(y)
    return np.array(xs), np.array(ys)

# Scale data
scaler = MinMaxScaler(feature_range=(0, 1))
scaled_data = scaler.fit_transform(air_data[['Passengers']])

# Define sequence length
seq_length = 12  # Use last 12 months to predict next month

# Create sequences
x, y = create_sequences(scaled_data, seq_length)

# Split into train and test sets
train_size = int(len(x) * 0.8)
x_train, x_test = x[:train_size], x[train_size:]
y_train, y_test = y[:train_size], y[train_size:]

# Build LSTM model
model = Sequential()
model.add(LSTM(50, return_sequences=True, input_shape=(seq_length, 1)))
model.add(Dropout(0.2))
model.add(LSTM(50))
model.add(Dropout(0.2))
model.add(Dense(1))

model.compile(optimizer='adam', loss='mse')

# Train the model
history = model.fit(
    x_train, y_train,
    epochs=50,
    batch_size=32,
    validation_split=0.2,
    verbose=0
)

# Plot training history
plt.figure(figsize=(10, 6))
plt.plot(history.history['loss'], label='Training Loss')
plt.plot(history.history['val_loss'], label='Validation Loss')
plt.title('LSTM Model Loss', fontsize=15)
plt.xlabel('Epoch', fontsize=12)
plt.ylabel('Loss', fontsize=12)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Make predictions
y_pred = model.predict(x_test)

# Inverse transform predictions and actual values
y_test_inv = scaler.inverse_transform(y_test)
y_pred_inv = scaler.inverse_transform(y_pred)

# Prepare time axis for plotting
test_dates = air_data.index[train_size+seq_length:][:len(y_test)]

# Plot results
plt.figure(figsize=(14, 7))
plt.plot(air_data.index[:train_size+seq_length], air_data['Passengers'][:train_size+seq_length], 
         label='Training Data')
plt.plot(test_dates, y_test_inv, label='True Test Data')
plt.plot(test_dates, y_pred_inv, color='red', label='LSTM Forecast')
plt.title('LSTM Model Forecast', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Evaluate forecast
evaluate_forecast(y_test_inv.flatten(), y_pred_inv.flatten())
```

Other deep learning approaches for time series:
- Convolutional Neural Networks (CNNs)
- Temporal Convolutional Networks (TCNs)
- Transformer-based models
- Hybrid models combining CNN and LSTM

## State Space Models and Structural Time Series

State space models provide a flexible framework for time series modeling and forecasting.

```python
from statsmodels.tsa.statespace.structural import UnobservedComponents

# Define structural time series model
# Components: trend, seasonal, and irregular
ucm_model = UnobservedComponents(
    air_data.iloc[:train_size]['Passengers'],
    level='local linear trend',  # Trend component
    seasonal=12,                 # Seasonal component (12 months)
    stochastic_level=True,
    stochastic_trend=True,
    stochastic_seasonal=True
)

# Fit model
ucm_results = ucm_model.fit(disp=False)
print(ucm_results.summary())

# Make predictions
ucm_forecast = ucm_results.get_forecast(steps=len(test_data))
ucm_mean = ucm_forecast.predicted_mean
ucm_conf_int = ucm_forecast.conf_int()

# Plot decomposed components
ucm_states = ucm_results.states.filtered
fig, axes = plt.subplots(3, 1, figsize=(14, 10))

# Plot level/trend
axes[0].plot(air_data.index[:train_size], ucm_states[0][:train_size])
axes[0].set_title('Level component')
axes[0].grid(True, alpha=0.3)

# Plot slope
axes[1].plot(air_data.index[:train_size], ucm_states[1][:train_size])
axes[1].set_title('Slope component')
axes[1].grid(True, alpha=0.3)

# Plot seasonal
axes[2].plot(air_data.index[:train_size], 
             np.sum(np.column_stack([ucm_states[i][:train_size] for i in range(2, 14)]), axis=1))
axes[2].set_title('Seasonal component')
axes[2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Plot forecast
plt.figure(figsize=(14, 7))
plt.plot(train_data.index, train_data['Passengers'], label='Training Data')
plt.plot(test_data.index, test_data['Passengers'], label='True Test Data')
plt.plot(test_data.index, ucm_mean, color='red', label='UCM Forecast')
plt.fill_between(test_data.index, 
                ucm_conf_int.iloc[:, 0], 
                ucm_conf_int.iloc[:, 1], 
                color='red', alpha=0.3, label='95% Confidence Interval')
plt.title('Structural Time Series Model Forecast', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Evaluate forecast
evaluate_forecast(test_data['Passengers'].values, ucm_mean.values)
```

Key benefits of state space models:
- Explicit modeling of individual components (trend, seasonality)
- Handling missing values and irregular sampling
- Incorporation of exogenous variables and interventions
- Bayesian estimation for uncertainty quantification

## Multivariate Time Series Forecasting

Multivariate time series involve forecasting multiple interdependent time series variables.

```python
from statsmodels.tsa.api import VAR
from statsmodels.tsa.statespace.varmax import VARMAX

# Generate a synthetic multivariate time series dataset
np.random.seed(42)
dates = pd.date_range(start='2015-01-01', periods=365, freq='D')

# Create three correlated time series
ts1 = np.sin(np.arange(365) * 0.05) * 10 + np.random.normal(0, 1, 365)
ts2 = np.sin(np.arange(365) * 0.05 + 1) * 5 + ts1 * 0.5 + np.random.normal(0, 1, 365)
ts3 = np.cos(np.arange(365) * 0.05) * 7 + ts1 * 0.3 - ts2 * 0.2 + np.random.normal(0, 1, 365)

# Create DataFrame
multi_ts = pd.DataFrame({
    'Series1': ts1,
    'Series2': ts2,
    'Series3': ts3
}, index=dates)

# Visualize multivariate time series
plt.figure(figsize=(14, 8))
for col in multi_ts.columns:
    plt.plot(multi_ts.index, multi_ts[col], label=col)
plt.title('Multivariate Time Series Example', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Split into train and test sets
train_size_multi = int(len(multi_ts) * 0.8)
train_multi = multi_ts.iloc[:train_size_multi]
test_multi = multi_ts.iloc[train_size_multi:]

# Fit VAR model
var_model = VAR(train_multi)
var_result = var_model.fit(maxlags=15)

# Forecast

# Evaluate VAR model

    print(f"\nEvaluation for {col}:")
    evaluate_forecast(test_multi[col].values, var_forecast_df[col].values)
```

Advanced multivariate forecasting approaches:

## Feature Engineering for Time Series Data

Feature engineering is crucial for improving time series forecasting accuracy.

```python
# Create a more comprehensive example with feature engineering
def create_features(df):
    """
    Create time series features based on time series index.
    """
    df = df.copy()
    df['hour'] = df.index.hour
    df['dayofweek'] = df.index.dayofweek
    df['dayofmonth'] = df.index.day
    df['month'] = df.index.month
    df['quarter'] = df.index.quarter
    df['year'] = df.index.year
    df['dayofyear'] = df.index.dayofyear
    df['weekofyear'] = df.index.isocalendar().week
    df['is_weekend'] = df['dayofweek'].isin([5, 6]).astype(int)
    
    # Add lags
    for lag in range(1, 4):
        df[f'lag_{lag}'] = df['Passengers'].shift(lag)
    
    # Add rolling features
    for window in [7, 14, 30]:
        df[f'rolling_mean_{window}'] = df['Passengers'].rolling(window=window).mean()
        df[f'rolling_std_{window}'] = df['Passengers'].rolling(window=window).std()
        df[f'rolling_min_{window}'] = df['Passengers'].rolling(window=window).min()
        df[f'rolling_max_{window}'] = df['Passengers'].rolling(window=window).max()
    
    # Add date features
    holidays = ['1949-01-01', '1950-01-01', '1951-01-01', '1952-01-01', 
               '1953-01-01', '1954-01-01', '1955-01-01', '1956-01-01',
               '1957-01-01', '1958-01-01', '1959-01-01', '1960-01-01']
    holidays = pd.to_datetime(holidays)
    df['is_holiday'] = df.index.isin(holidays).astype(int)
    
    return df

# Apply feature engineering to airline data
air_features = create_features(air_data)
air_features = air_features.dropna()  # Remove NaN values after creating lagged features

# Display the features
print(air_features.head())

# Split into features (X) and target (y)
X = air_features.drop('Passengers', axis=1)
y = air_features['Passengers']

# Split into train and test
train_size_feat = int(len(X) * 0.8)
X_train, X_test = X[:train_size_feat], X[train_size_feat:]
y_train, y_test = y[:train_size_feat], y[train_size_feat:]

# Train a machine learning model (Random Forest)
from sklearn.ensemble import RandomForestRegressor

rf_model = RandomForestRegressor(n_estimators=100, random_state=42)
rf_model.fit(X_train, y_train)

# Make predictions
y_pred_rf = rf_model.predict(X_test)

# Plot results
plt.figure(figsize=(14, 7))
plt.plot(y_train.index, y_train, label='Training Data')
plt.plot(y_test.index, y_test, label='True Test Data')
plt.plot(y_test.index, y_pred_rf, 'r--', label='RF Predictions')
plt.title('Random Forest with Feature Engineering', fontsize=15)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Evaluate feature-engineered model
evaluate_forecast(y_test.values, y_pred_rf)

# Feature importance
feature_importance = pd.DataFrame({
    'Feature': X_train.columns,
    'Importance': rf_model.feature_importances_
}).sort_values('Importance', ascending=False)

plt.figure(figsize=(14, 6))
sns.barplot(x='Importance', y='Feature', data=feature_importance.head(15))
plt.title('Top 15 Feature Importances for Time Series Prediction', fontsize=15)
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

Important time series features:
- Lagged values
- Rolling statistics
- Calendar features (day, month, etc.)
- Holidays and special events
- Cyclical features (sin/cos transforms)
- External regressors and exogenous variables

## Evaluating Time Series Forecasts

Proper evaluation is essential for comparing different forecasting methods.

```python
import matplotlib.dates as mdates
from sklearn.metrics import r2_score, mean_absolute_percentage_error

# Compile results from different models
actual_values = test_data['Passengers'].values
model_results = {
    'SARIMA': sarima_mean.values,
    'Prophet': prophet_predictions,
    'LSTM': y_pred_inv.flatten()[:len(actual_values)],
    'UCM': ucm_mean.values
}

# Calculate metrics for all models
metrics = {}
for model_name, predictions in model_results.items():
    predictions = predictions[:len(actual_values)]  # Ensure same length
    rmse = np.sqrt(mean_squared_error(actual_values, predictions))
    mae = mean_absolute_error(actual_values, predictions)
    mape = mean_absolute_percentage_error(actual_values, predictions) * 100
    r2 = r2_score(actual_values, predictions)
    
    metrics[model_name] = {
        'RMSE': rmse,
        'MAE': mae,
        'MAPE': mape,
        'R²': r2
    }

# Convert to DataFrame for display
metrics_df = pd.DataFrame(metrics).T
print(metrics_df)

# Plot comparison of all models
plt.figure(figsize=(16, 8))
plt.plot(test_data.index, actual_values, 'k-', label='Actual', linewidth=2)

colors = ['red', 'blue', 'green', 'purple']
for i, (model_name, predictions) in enumerate(model_results.items()):
    plt.plot(test_data.index, predictions[:len(actual_values)], 
             color=colors[i], linestyle='--', label=f'{model_name}')

plt.gca().xaxis.set_major_formatter(mdates.DateFormatter('%Y-%m'))
plt.gca().xaxis.set_major_locator(mdates.MonthLocator(interval=2))
plt.title('Comparison of All Forecasting Methods', fontsize=16)
plt.xlabel('Date', fontsize=12)
plt.ylabel('Passengers (thousands)', fontsize=12)
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

# Residual analysis
plt.figure(figsize=(16, 12))

for i, (model_name, predictions) in enumerate(model_results.items()):
    predictions = predictions[:len(actual_values)]
    residuals = actual_values - predictions
    
    plt.subplot(2, 2, i+1)
    plt.scatter(predictions, residuals, alpha=0.5)
    plt.axhline(y=0, color='r', linestyle='-')
    plt.title(f'{model_name} Residuals', fontsize=14)
    plt.xlabel('Predicted Values', fontsize=12)
    plt.ylabel('Residuals', fontsize=12)
    plt.grid(True, alpha=0.3)
    
plt.tight_layout()
plt.show()
```

Key evaluation metrics for time series forecasting:
- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)
- MAPE (Mean Absolute Percentage Error)
- R-squared
- Residual analysis
- Direction accuracy
- Forecast bias

## Ensemble Methods for Time Series

## Summary

Advanced time series forecasting requires a sophisticated toolkit of methods to handle the complexity of real-world data. Through this exploration, we covered multiple approaches:

1. **Classical Statistical Methods**: ARIMA and SARIMA models provide a foundation for time series forecasting, offering interpretability and solid performance for many datasets. They work particularly well for data with clear seasonal patterns when appropriately configured.

2. **Modern Innovations**: Prophet provides a flexible framework that automatically handles seasonality and can incorporate domain knowledge through special events and holidays. Its decomposable structure makes it interpretable while offering excellent performance.

3. **Deep Learning Approaches**: LSTM networks and other deep learning methods can capture complex nonlinear patterns in time series data. They excel with large datasets but require careful tuning and significant computational resources.

4. **State Space Models**: These models offer a flexible framework for modeling time series components explicitly, providing clear decomposition and the ability to handle missing data and irregular sampling.

5. **Multivariate Methods**: When working with multiple related time series, techniques like VAR allow us to model their interdependencies, potentially improving forecast accuracy by leveraging correlations.

6. **Feature Engineering**: Creating meaningful features can significantly enhance forecasting performance, especially when using traditional machine learning algorithms.

7. **Ensemble Methods**: Combining multiple forecasting methods often results in more robust and accurate predictions than any single model.

Key best practices for time series forecasting:

- Always visualize your data and understand its components
- Test multiple forecasting methods for each problem
- Pay careful attention to validation approach (avoid data leakage)
- Consider feature engineering to incorporate domain knowledge
- Use ensembles for improved robustness and accuracy
- Quantify uncertainty in your forecasts
- Regularly refit models as new data becomes available

Advanced time series forecasting continues to evolve with innovations in deep learning, probabilistic modeling, and hybrid approaches. The most effective forecasting strategy often involves combining multiple methods and incorporating domain expertise to create robust, accurate predictions.
